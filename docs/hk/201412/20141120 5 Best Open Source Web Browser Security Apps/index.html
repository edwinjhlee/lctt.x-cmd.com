5個最佳開源的瀏覽器安全應用 ​

瀏覽器是現在各種在線服務的入口。電腦安全問題迄今仍未得到解決，技術進步為惡意軟件提供了新的途徑，感染我們的設備、入侵商業網絡。例如，智能手機與平板為惡意軟件--及其同夥“惡意廣告”--帶來一片全新天地，它們在其中騰挪作亂。

惡意廣告在合法廣告與合法網絡中注入惡意軟件。當然你可能會認為“合法”廣告與網絡與非法廣告與網絡之間僅有一線之隔。但是請不要偏題哦。隱私與安全天生就是一對兄弟，保護隱私也就是保護你的安全。

Firefox, Chrome, 以及 Opera 當仁不讓屬最棒的瀏覽器：性能最佳、兼容性最好、以及安全性最優。以下五個開源安全應用安裝於瀏覽器後會助你抵禦種種威脅。

保護隱私： 開源瀏覽器安全應用 ​

1. AdBlock ​

廣告網絡為惡意軟件提供了肥沃的土壤。一個廣告網絡可以覆蓋數千站點，因此攻陷一個廣告網絡就相當於攻陷數千台機器。AdBlock及其衍生品—AdBlock Plus, AdBlock Pro, 與 AdBlock Edge--都是屏蔽廣告的優秀工具，可以讓那些充斥煩人廣告的網站重新還你一片清靜。

當然，凡事都有兩面性：上述做法損害了依靠廣告收入的站點的利益。這些工具一鍵式白名單功能，對於那些你希望支持的網站，你可以通過白名單功能關閉這些網站的廣告屏蔽。（真的，我親愛的站長們，如果你不希望網站訪問者屏蔽你的廣告，那麼就適可而止，不要讓人反感。當然，作為粉絲，也請您支持您喜愛的站點，將它們放到白名單吧。）

圖1:在Ad Blocker中添加其它過濾規則。

Ad Blocker們不僅能屏蔽廣告；它們還能屏蔽網站跟蹤爬蟲與惡意域名。要打開額外過濾規則，點擊ad blocker圖標 > 點擊首選項，轉至過濾規則訂閲標籤。點擊按紐添加訂閲過濾規則，然後加入Easy Privacy + EasyList規則。加入惡意域名過濾也是個不錯的選擇；它會屏蔽那些供惡意軟件與間諜軟件寄生的域名。Adblock可在Firefox, Chrome, Opera, Safari, IE, 以及Android平台下工作。

2. HTTPS Everywhere ​

瀏覽器擴展HTTPS Everywhere可確保在網站HTTPS可用的時候，總是以HTTPS方式連接到站點。HTTPS意味着你的連接是以SSL（安全套接層）方式加密的，SSL協議通常用於加密網站與電子郵件連接。HTTPS Everywhere可在Firefox, Chrome, 及Opera下使用。

安裝了HTTPS Everywhere之後，它會詢問你是否希望啓用SSL檢測程序。點擊“是”，因為SSL檢測程序會提供額外保護，防止中間人攻擊與虛假SSL證書攻擊。HTTPS Everywhere可在Firefox, Chrome, Opera, Safari, IE, 以及Android平台下工作。

3. Social Fixer ​

Social Fixer馴服Facebook。它給了你一把尚方寶劍，你可以用它過濾“動態彙總”，從而只看到你想看的動態、生成按主題分類的標籤動態、隱藏不想查看的動態、鼠標懸停圖片時顯示完整尺寸的圖片、禁止影院方式瀏覽圖像，還有其它更多功能。

Social Fixer本身不是安全工具，但它具有兩個重要的安全特性：

  • 它可以將Facebook網頁截圖中你的個人資料頭像以通用圖標代替，並以虛假名字替代你的用户名，從而起到匿名作用。
  • 它可以很可靠地屏蔽Facebook遊戲，而Facebook遊戲正是盡人皆知的麻煩製造者。

4. Privacy Badger ​

電子前線基金會出品的Privacy Badger是一款優秀的反跟蹤與反間諜廣告的攔截工具。現在的網頁內容來源可謂五花八門：廣告服務器、評論服務器、圖片工場、第三方登陸服務器，以及其它種種不一而足。

AdBlock也能攔截這些烏七八糟的東西，不過Privacy Badger在此方面更勝一籌。Privacy Badger依靠算法與策略方法而非過濾規則，這樣如果攔截出錯的話，可以輕易重寫，而過濾規則需要專人維護。Privacy Badger在Firefox與Chrome下均可工作。

圖3: Privacy Badger攔截跟蹤站點。

Privacy Badger裝好後就能使用了。點擊圖標，看看它對你瀏覽的網頁都攔截了哪些東西。你可以試試訪問Huffingtonpost.com，這是一家不在每一個頁面塞滿第三方組件誓不罷休的網站（圖3）。

滑塊顯示每個站點的狀態：紅色表示該站點被徹底攔截，不能設置cookies（緩衝數據），或者向你提供任何內容。黃色意味着第三方域名正試圖跟蹤，但是它列於Privacy Badger的允許域名的白名單之中。綠色表示第三方目前還未歸入跟蹤者之列，但是在你訪問若干網站之後，Privacy Badger會觀察其行為，並決定是否將其歸為跟蹤者。

你也可以根據你的偏好來設置滑塊；例如，在我訪問的某個網站，我用Privacy Badger攔截了bazaarvoice.com，一些購物網站使用這家站點來託管他們的客户評論。

5. Disconnect ​

Disconnect是另外一款反跟蹤反cookie工具，擁有眾多功能。它可在Firefox, Chrome, IE, Safari下工作，並且為iOS與Android平台打造了特殊的版本。Disconnect不但能反跟蹤，而且它使用自己的虛擬專用網絡（VPN），防止竊聽與惡意廣告，使你的無線傳輸（Wi-fi, 3G, 4G）更安全。它可以防止部件劫持，而部件劫持是攻擊者用於在需要登陸的網站獲得訪問權限的技術。通過部件劫持，攻擊者無需密碼，而只要使用竊取的cookies，就能獲得網站訪問權限。

Disconnect還有安全搜索功能，可以阻止搜索引擎愛挖數據的癖好，你可以安心無虞地使用你中意的搜索引擎。

想像一下，網頁上所有東西都騰空而出，奔你而去。當然這一切都是抽象的且在幕後悄然發生，不象有人正在猛擊窗户試圖進入你家那麼明顯罷了。但是，威脅倒是實實在在的，而且數不勝數，所以你必須採取預防措施，來保護自己。
