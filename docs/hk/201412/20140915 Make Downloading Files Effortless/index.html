讓下載更方便 ​

下載管理器是一個電腦程序，專門處理下載文件，優化帶寬佔用，以及讓下載更有條理等任務。有些網頁瀏覽器，例如Firefox，也集成了一個下載管理器作為功能，但是它們的使用方式還是沒有專門的下載管理器（或者瀏覽器插件）那麼專業，沒有最佳地使用帶寬，也沒有好用的文件管理功能。

對於那些經常下載的人，使用一個好的下載管理器會更有幫助。它能夠最大化下載速度（加速下載），斷點續傳以及制定下載計劃，讓下載更安全也更有價值。下載管理器已經沒有之前流行了，但是最好的下載管理器還是很實用，包括和瀏覽器的緊密結合，支持類似YouTube的主流網站，以及更多。

有好幾個能在Linux下工作都非常優秀的開源下載管理器，以至於讓人無從選擇。我整理了一個摘要，是我喜歡的下載管理器，以及Firefox裏的一個非常好用的下載插件。這裏列出的每一個程序都是開源許可發佈的。

###uGet

uGet是一個輕量級，容易使用，功能完備的開源下載管理器。uGet允許用户從不同的源並行下載來加快速度，添加文件到下載序列，暫停或繼續下載，提供高級分類管理，和瀏覽器集成，監控剪貼板，批量下載，支持26種語言，以及其他許多功能。

uGet是一個成熟的軟件；持續開發超過了11年。在這段時間裏，它發展成一個非常多功能的下載管理器，擁有一套很高價值的功能集，還保持了易用性。

uGet是用C語言開發的，使用了cURL作為底層支持，以及應用庫libcurl。uGet有非常好的平台兼容性。它一開始是Linux系統下的項目，但是被移植到在Mac OS X，FreeBSD，Android和Windows平台運行。

功能點： ​

  • 容易使用
  • 下載隊列可以讓下載任務按任意數量或你希望的數量同時進行。
  • 斷點續傳
  • 默認分類
  • 完美實現的剪貼板監控功能
  • 批量下載
  • 支持從HTML文件導入下載任務
  • 支持通過HTTP，HTTPS，FTP，BitTorrent和Metalink下載
  • 多線程下載（也被稱為分塊下載）：每個下載任務支持最多20個線程同時連接，支持自適應的分塊管理，意味着如果某個下載塊中斷了，那麼會其他連接會把它撿起來，以時刻保證最佳的下載速度。
  • 多鏡像下載
  • FTP登錄和匿名FTP
  • 強大的計劃任務
  • 通過FlashGot和FireFox集成
  • Aria2插件
  • 多變的主題
  • 安靜模式
  • 鍵盤快捷鍵
  • 支持命令列/終端控制
  • 自動創建目錄
  • 下載歷史管理
  • 支持GnuTLS
  • 支持26種語言，包括：阿拉伯語，白俄羅斯語，簡體中文，繁體中文，捷克語，丹麥語，英語（默認），法語，格魯吉亞語，德語，匈牙利語，印尼語，意大利語，波蘭語，葡萄牙語（巴西），俄語，西班牙語，土耳其語，烏克蘭語，以及越南語。
  • 網站：ugetdm.com
  • 開發人員：C.H. Huang and contributors
  • 許可：GNU LGPL 2.1
  • 版本：1.10.5

###DownThemAll!

DownThemAll!是一個小巧可靠的、易用的開源下載管理器／加速器，是Firefox的一個組件。它可以讓用户下載一個頁面上所有鏈接和圖片，還有更多功能。它可以讓用户完全控制下載任務，隨時分配下載速度以及同時下載的任務數量。通過使用Metalinks或者手動添加鏡像的方式，可以同時從不同的服務器下載同一個文件。

DownThemAll會根據你要下載的文件大小，切割成不同的部分，然後並行下載。

功能點： ​

  • 和Firefox的完全集成
  • 分塊下載，允許用户下載不同的文件塊，完成之後再拼接成完整的文件；這樣的話當連接到一個緩慢的服務器的時候可以加快下載速度。
  • 支持Metalink，允許發送下載文件的多個URL以及它的校驗值和其他信息到DTA
  • 支持爬蟲方式通過一個單獨的鏈接遍歷整個網頁
  • 下載過濾
  • 高級重命名選項
  • 暫停和繼續下載任務
  • 網站：addons.mozilla.org/en-US/firefox/addon/downthemall
  • 開發人員：Federico Parodi, Stefano Verna, Nils Maier
  • 許可：GNU GPL v2
  • 版本：2.0.17

###JDownloader

JDownloader是一個免費，開源的下載管理工具，擁有一個大型社區的開發者支持，讓下載更簡單和快捷。用户可以開始，停止或暫停下載，設置帶寬限制，自動解壓縮包，以及更多功能。它提供了一個容易擴展的框架。

JDownloader簡化了從一鍵下載網站下載文件。它還支持從不同並行資源下載、手勢識別、自動文件解壓縮以及更多功能。另外，還支持許多“加密鏈接”網站－所以你只需要複製粘貼“加密的”鏈接，然後JDownloader會處理剩下的事情。JDownloader還能導入CCF，RSDF和DLC文件。

功能點： ​

  • 一次下載多個文件
  • 從多個連接同時下載
  • JD有一個自己實現的強大的OCR模組
  • 自動解壓（包括密碼搜索）（RAR壓縮包）
  • 支持主題
  • 支持多國語言
  • 大約110個站點以及超過300個解密插件
  • 通過JDLiveHeaderScripts重連：（支持1400路由）
  • 網頁更新
  • 集成包管理器支持額外模組（例如，Webinterface，Shutdown）
  • 網站：jdownloader.org
  • 開發人員：AppWork UG
  • 許可：GNU GPL v3
  • 版本：0.9.581

###FreeRapid Downloader

FreeRapid Downloader是一個易用的開源下載程序，支持從Rapidshare，Youtube，Facebook，Picasa和其他文件分享網站下載。他的下載引擎基於一些插件，所以可以從那些特別的站點下載。

對於需要針對特定文件分享網站的下載管理器用户來説，FreeRapid Downloader是理想的選擇。

FreeRapid Downloader使用Java語言編寫。需要至少Sun Java 7.0版本才可以運行。

功能點： ​

  • 容易使用
  • 支持從不同服務站點並行下載
  • 支持斷點續傳
  • 支持通過代理列表下載
  • 支持流視頻或圖片
  • 下載歷史
  • 聰明的剪貼板監控
  • 自動檢查服務器文件後綴
  • 自動關機選項
  • 插件自動更新
  • 簡單驗證碼識別
  • 支持跨平台
  • 支持多國語言：英語，保加利亞語，捷克語，芬蘭語，葡萄牙語，斯洛伐克語，匈牙利語，簡體中文，以及其他
  • 支持超過700個站點
  • 網站：wordrider.net/freerapid/
  • 開發人員：Vity and contributors
  • 許可：GNU GPL v2
  • 版本：0.9u4

###FlashGot

FlashGot是一個Firefox和Thunderbird的免費組件，旨在通過外置下載管理器來處理單個和大規模（“所有”和“已選”）下載。

FlashGot把所支持的所有下載管理器統一成Firefox中的一個下載管理器。

功能點： ​

  • Linux下支持：Aria, Axel Download Accelerator, cURL, Downloader 4 X, FatRat, GNOME Gwget, FatRat, JDownloader, KDE KGet, pyLoad, SteadyFlow, uGet, wxDFast 和 wxDownload Fast
  • 支持圖庫功能，可以幫助把原來分散在不同頁面的系列資源，整合到一個所有媒體庫頁面中，然後可以輕鬆迅速地“下載所有”
  • FlashGot Link會使用默認下載管理器下載當前鼠標選中的鏈接
  • FlashGot Selection
  • FlashGot All
  • FlashGot Tabs
  • FlashGot Media
  • 抓取頁面裏所有鏈接
  • 抓取所有標籤欄的所有鏈接
  • 鏈接過濾（例如只下載指定類型文件）
  • 在網頁上抓取點擊所產生的所有鏈接
  • 支持從大多數鏈接保護和文件託管服務器直接和批量下載
  • 隱私選項
  • 支持國際化
  • 網站：flashgot.net
  • 開發人員：Giorgio Maone
  • 許可：GNU GPL v2
  • 版本：1.5.6.5
