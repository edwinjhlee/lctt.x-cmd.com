Linux Journal雜誌2014讀者選擇獎 ​

又到了Linux Journal雜誌刊發2014讀者選擇獎的時候了！鑑於去年的形式好評如潮，因此我們仍沿續舊年格式，讓你的意見再次得到迴響。雖然有些地方我們會稍加評論，不過基本上還是以報道結果為主。以下敬請欣賞本年度讀者選擇獎名單！

我們希望讀者選擇獎一年好似一年。如果你對新分類有任何建議，或者有任何評價與反饋，都可以通過以下方式聯繫我們：http://www.linuxjournal.com/contact

如欲瞭解完整獲獎名單，請查閲本雜誌2014年12月刊。

###你用Linux做過的最酷的事情 ###

這是讀者選擇獎裏我最鍾愛的新分類。想像一下你參加某次Linux會議，期間詢問人們他們用Linux做過的最酷的事情。這裏所做的與之大同小異！這裏我們僅列出部分我們比較喜歡的，如欲瞭解完整列表，請訪問：http://www.linuxjournal.com/rc2014/coolest。

注：最常見的答案是：“使用它”；“挽救數據/照片/導致Windows 機器罷工的任何東西”；“説服朋友/家人/業務轉向使用Linux”；“學習”；“講授”；“獲得工作”；“家庭自動化”；“構建家庭媒體服務器”。下表是我們選出的並非最常見的答案，而是一些比較具體與有個性的答案。

  • 在上世紀90年代中期建立procmail垃圾郵件預過濾規則。
  • 450-節點計算集羣。
  • 7.1 通道前置放大器（集成Mopidy音樂播放器）。
  • Linux機器人 （參加Eurobot年度比賽）。
  • 無意間打印到錯誤的大陸。
  • 視頻同步時增加音頻通道。
  • 使用自已編寫的代碼分析NASA衞星數據。
  • 遠程逗着貓玩。
  • 通過聲音以及移動應用自動控制家裏整個燈光設置。
  • 窗台植物自動澆水系統。
  • 浴室收音機。
  • 配製啤酒。
  • 創建了一個運行在國際空間站的應用。
  • 為某大型收費高速公路系統建立一套實時收費系統。
  • 自己裝配智能手機。
  • 使用樹莓派建立基於網絡的家庭報警系統。
  • 樹莓派集羣破解加密的辦公文檔。
  • 控制我的Parrot無人機。
  • 控制186颱風力渦輪機的通信。
  • 在Linux下使用Stellarium控制我的米德望遠鏡。
  • 用一台十幾年的老筆記本轉換卡帶式家庭視頻的格式。
  • 在靠近北極地區創建網狀網絡。
  • 使用無線數據發射器創建海洋環境下的傳感器浮標。
  • 發現新行星。
  • 修復位於美國丹佛的jabber服務器， 而我當時卻身在約丹安曼一家酒店大堂。
  • 得到一張Linus親筆簽名的Red Hat 5.0 CD。
  • 入侵我的咖啡機，在咖啡做好後給我一條消息。
  • 給我女兒介紹樂高機器人EV3。
  • 監控酒窖温度與濕度，過熱或過温時開門。
  • 用樹莓派代替温泉浴缸上的控制器。
  • 使用腳本連接四天每隔15秒開關一次同事的CD托盤。
  • 使用LFS系統為一家全國性石油公司遷移ACH自動轉帳系統。
  • 身在其它城市衝我家裏的馬桶。
  • 遠程控制雞舍門。
  • 使用樹莓派為16個站點部署基於網絡的灑水器控制器（並控制水池與庭院燈光）。
  • 鏈接SSH通道通過三級跳連接家與工作（因網絡設置方面的限制）。
  • 建立一套系統，監控可再生能源的安裝部分：兩套固定的太陽能電池陣，一套兩軸太陽跟蹤太陽能電池陣，以及一台風力渦輪機。生產以及天氣數據實時顯示在網絡站點。
  • 還是在“貓”時代，我用電腦每天早上叫醒我女朋友去上班。
  • 使用一個Wii搖控器，通過藍牙將我的筆記本作為紅外攝像機，偵測我女兒的旋轉木馬的運動，以及控制視頻遊戲。
