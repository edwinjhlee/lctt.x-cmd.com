扫码关注官方微信公众号获取开源软件和 x-cmd 的最新用法与独家资讯

當微軟離去時 ​

開源.Net，“這與Linux無關——它與SaaS相關，也和一位並不偏執和狂熱的90後CEO相關，”SoylentNews博主hairyfeet道，“納德拉很明智，而且意識到了編程語言的價值不在於專利或OS排他性，而在於服務和對語言的支持……越多的平台使用該語言，它就會越好。”

如果自由和開源軟件迷們在過去的那些日子裏感到有些許困惑的話，這也許是可以理解的，即便是頭昏、頭痛以及頭暈也算是常見的。

你或許會問，這又是什麼新的病症？

好吧，Linux女孩很高興告訴你，它不是什麼病症。不過，然而它並不意味着它很容易治癒。

原因無他，而是微軟開源.Net並讓它可以在Linux或Mac OS上運行的消息。

是的，你沒聽錯：史蒂夫·鮑爾默曾經可能稱Linux為“癌症”，但今天雷蒙德（微軟總部，代稱微軟）有個新發現，曾經不被包容的，但是卻轉頭“愛”上了Linux!

它讓微軟看起來很奇怪——它也驅使FOSS迷們聚攏到Blog圈的破敗的Broken Windows Lounge，而去的人的數量更是空前的。

一杯龍舌蘭可以讓你不再頭疼麼？這是現在眾多探究的問題之一。

‘繁榮的機遇’ ​

“這是個重大的消息，雖然有點過時了，”克里斯·特拉弗斯，一位博主，他為LedgerSMB項目工作，告訴Linux女孩。

“我們生活的世界中，即使沒有大的商業公司支持，新的開源編程語言也很興旺，而閉源的編程語言僅能在大的商業公司的幫助下得到支持，”特拉弗斯説，“例如，Bing閉源殺死了REBOL 2.x。”

“這項運動很明顯醖釀已久——一家像微軟這樣龐大的公司不會有‘突然開源’這種複雜的東西——而我想，在某種程度上，微軟一定看到了Sun開源OpenJDK時的一些前兆了。”他暗示道。

同時，“這也為諸如C#和F#這樣的語言提供了比當前市場更為興盛的機會，”特拉弗斯説。

‘我仍然不相信你’ ​

“我首先想説，‘謝謝你，微軟！’”Linux Rants博主麥克·斯通開篇説，“我們真的很欣賞你開源.Net並推動它跨平台，這是邁向正確方向的一步！”

“然而，我仍然不相信你。”他補充道。

“我很喜歡微軟在考慮開源，但是我沒有見到它向GPL邁進，”斯通告訴Linux女孩，“這讓我想到了這麼個可能性，微軟提供了多個平台的軟件供你使用，但卻會把開發者和它捆綁起來。”

此外，微軟不會作出任何保證，保證.Net常年開源，他指出。

“這意味着微軟可以退出，並讓開發出來的應用程序成為跨平台的Windows專有軟件，”他警告道，“我不會相信微軟的承諾，我會翹首期盼微軟他們的突然而必然的背叛。”

‘留心不懷好意的禮物’ ​

該運動明顯帶有失望的氣息，Google+博主阿里桑德羅·埃伯索爾暗示道。

“他們來得太晚了，”埃伯索爾説，“Java已經先下手為強了，當.Net還是Windows/Microsoft專有產品時，Java已經遍佈四處了。試着讓人採用，希望好運吧。”

此外，“如果它打上GPL烙印來保護代碼創建者的話我才會相信它，”他補充道，“一個脆弱的MIT許可證任何時候都是逆天而行的。”

無論如何，“在該公司產生的對FLOSS社區的全部的敵意下，他們會過河拆橋，”埃伯索爾總結道，“底線是：送禮的希臘人也很可畏——仔細留心希臘人不懷好意的禮物……”

‘就像貓愛上老鼠’ ​

微軟愛上Linux“就像貓愛上老鼠，”博主羅伯特·伯格森打趣道，“當然，他們會玩玩*/Linux，但是他們不是我們的朋友。”

所發生的事情是，FOSS和LInux社區已經擊潰了“MS自從和IBM達成提供OS的交易後放置在競爭道路入口上的所有障礙，”伯格森説，“MS肯定是在絕望地試着和‘敵人’‘做朋友’，因為它們的位置被侵佔了。”

“一切都會好的，”他補充道，“MS仍然可以通過愚蠢地花大量的金錢來製造麻煩，或者他們可以進行常規商業運作並在價格/性能上開展競爭。那不是‘愛’——那是接受現實。”

適應或者滅亡 ​

對於微軟而言，問題在於“開源開發包對於開發者而言開始變得足夠好用了，”參團顧問和Slashdot博主格哈德·麥克。

“在我的最後一份職業中，大多數的程序員想要Eclipse，而不是Visual Studio，即使客户端軟件是Windows專用的。用Windows做測試的開發者們遷移到Linux的數量在緩慢增長。”麥克回憶道。

“很要有人想被固定在一個平台中，因此單一平台的語言的份額會越來越少，”他補充道，“微軟現在必須在適應與滅亡中作出選擇。”

這裏沒有温暖的毛球 ​

驅動此項運動的策略也在於“各種雲大量地在Linux上部署，即便在微軟自己的Azure雲，Linux也被大量部署，”Google+博主凱文·奧布萊恩暗示道。

“納德拉清楚地指出，他正將微軟向雲方向推進，因為他幾乎不得不如此，以期繼續將遊戲玩下去。”奧布萊恩堅信。

那就是説，不管怎樣，“我都不期待微軟變得可愛又善意——他們將做所有他們認為能獲得最佳公司利益的事情。”他説。

事實上，“根本沒Linux什麼事——它只和SaaS相關，也和一位並不偏執和狂熱的90後CEO相關，”SoylentNews博主hairyfeet告訴Linux女孩。

“納德拉很明智，而且意識到了編程語言的價值不在於專利或OS排他性，而在於服務和對語言的支持，”hairyfeet解釋道，“考慮到這一點，越多的平台使用該語言，它就會越好，因為那會增加該語言的價值，並且為你的服務帶來更多客户。”

帝國的沒落 ​

總得來説，一切都很明瞭，那就是“微軟帝國正在搖搖欲墜，”Google+博主貢薩洛·維拉斯科 C説。

“我不知道，或者不關心他們為什麼會説謊，説他們熱愛Linux，”他補充道，“我只希望GNU/Linux社區變得比現今更聰明些（咳，Systemd，咳咳），拒絕微軟.Net和其它產生影響的東西。GNU/Linux必須只用FLOSS工具。”
