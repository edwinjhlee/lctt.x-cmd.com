如何在Linux命令列中下載GOG遊戲 ​

如果你是一個遊戲玩家同時也是一個Linux用户，你可能很高興在GOG在幾個月前宣佈它會在你最喜歡的操作系統上推出遊戲。如果你之前從來沒有聽説過GOG，我鼓勵你看看他們的產品目錄中的“很棒的老遊戲”，價格合理，無DRM限制，而且充滿了很棒的東西。雖然Windows上的GOG客户端已經存在了很長的時間，但是官方的Linux版本客户端卻是無處可見。因此，如果你不想等待官方的正式版本，一個名為LGOGDownloader非官方的開放源碼計劃能讓你在命令列中訪問你的庫。

在Linux中安裝 LGOGDownloader ​

對於Ubuntu用户來説，其官方頁面建議您下載源代碼並執行：

$ sudo apt-get install build-essential libcurl4-openssl-dev liboauth-dev libjsoncpp-dev libhtmlcxx-dev libboost-system-dev libboost-filesystem-dev libboost-regex-dev libboost-program-options-dev libboost-date-time-dev libtinyxml-dev librhash-dev help2man
$ tar -xvzf lgogdownloader-2.17.tar.gz
$ cd lgogdownloader-2.17
$ make release
$ sudo make install

如果你是ArchLinux用户。有一個AUR 包等着你：

LGOGDownloader 的使用### ​

一旦安裝了該程序，你需要用下面的命令登錄：

$ lgogdownloader --login

如果你需要配置文件，那它在這裏：~/.config/lgogdownloader/config.cfg

驗證通過後，你可以列出你庫中所有的遊戲：

$ lgogdownloader --list

用下面的命令下載遊戲：

$ lgogdownloader --download --game [game name]

你可以注意到lgogdownloader允許你恢復之前中斷的下載，這當下載的遊戲並不小時是很有用的。

像每一個可敬的命令列實用程序，您可以添加各種選項：

  • --platform [number] 選擇您的操作系統，1是 Windows， 4是Linux。
  • --directory [destination] 下載安裝包到指定的目錄。
  • --language [number] 下載特定的語言包 (根據你的語言查閲手冊上對應的數字)。
  • --limit-rate [speed] 限制下載速度。

一個額外的福利，lgogdownloader同樣可以檢查GOG網站上的更新：

$ lgogdownloader --update-check

結果將列出論壇上收到的私人郵件的數量以及更新的遊戲數量。

最後，lgogdownloader是非常標準的命令列實用工具。我甚至可以説，它是清晰和連貫性的一個縮影。我們距離Steam Linux客户端的確還差的很遠，但在另一方面，官方GOG Windows客户端不會做的比這個非官方的Linux版本更多。換句話説lgogdownloader是一個完美的替代品。我等不及要看到GOG上更多的Linux兼容遊戲，尤其是在他們最近公告稱會提供的無DRM電影，會有視頻遊戲的專題。希望在電影目錄中有遊戲庫時能在客户端看到更新。

你覺得GOG怎麼樣？你會使用非官方的Linux客户端麼？讓我們在評論中知道你的想法。
