Linux 上一些很好用的文獻目錄管理工具 ​

你是否寫過一些很長很長的文章，以至於你會認為你永遠都看不到它的結束？那麼你會很明白最糟糕的不是你投入了多少的時間，而是一旦你完成，你仍然要制定和格式化你的所引用的一些參考文獻。很幸運的是，Linux 有很多的解決方案：參考書目和文獻管理工具。藉助BibTex的力量，這些工具可以幫你導入引用源，然後自動生成一個結構化文獻目錄。這裏給大家提供了一些Linux上參考文獻管理工具的不完全列表。

1. Zotero ​

這應該是最著名的參考文獻聚集工具，Zotero作為一個瀏覽器的擴展插件。當然，它也有一個方便的Linux 獨立工具。擁有強大的性能，Zotero 很容易上手，並且也可以和LibreOffice 或者是其他的文本編輯器配套使用來管理文檔的參考文獻。我個人很欣賞其操作界面和插件管理器。可惜的是，如果你對參考文獻有很多不同的需求的話，很快就會發現 Zotero 功能有限。

2. JabRef ​

JabRef 是最先進的文獻管理工具之一。你可以導入大量的格式，可以在其外部的資料庫裏查找相應的條目（像Google Scholar），並且能直接輸出到你喜歡的編輯器。JabRef 可以很好的兼容你的運行環境，甚至也支持插件。最後還有一點，JabRef可以連接你自己的SQL 資料庫。而唯一的缺點就是其學習使用的難度。

3. KBibTex ​

對於 KDE 使用者，這個桌面環境也擁有它自己專有的文獻管理工具KBibTex。這個程序的品質，正如你所期望。程序可高度定製，通過快捷鍵就可以很好的操作和體驗。你可以很容易找到副本、可以預覽結果、也可以直接輸出到LaTex 編輯器。而我認為這款軟件最大的特色在於它集成了Bigsonomy ，Google Scholar ，甚至是你的Zotero賬號。唯一的缺憾是界面看起來實在是有點亂。多花點時間設置軟件可以讓你使用起來得心應手。

4. Bibfilex ​

可以運行在Gtk 和Qt 環境中，Bibfilex是一個基於 Biblatex 的界面友好的工具。相對於JabRef 和KBibTex ，缺少了一些高級的功能，但這也讓他更加的快速和輕巧。不用想太多，這絕對是快速做文獻目錄的一個聰明的選擇。界面很舒服，僅僅反映了一些必要的功能。我給出了其使用的完全手冊，你可以從官方的下載頁面去獲得。

5. Pybliographer ​

正如它的名字一樣，Pybliographer是一個用 Python 寫的非圖形化的文獻目錄管理工具。我個人比較喜歡把Pybiographic 當做是圖形化的前端。它的界面極其簡潔和抽象。如果你僅僅需要輸出少數的參考文獻，而且也確實沒有時間去學習更多的工具軟件，那麼 Pybliographer 確實是一個不錯的選擇。有一點點像 Bibfilex 的是，它是以讓用户方便、快速的使用為目標的。

6. Referencer ​

這應該是我歸納這些時候的一個最大的驚喜，Referencer 確實是讓人眼前一亮。完美兼容 Gnome ，它可以查找和導入你的文檔，然後在網上查詢他們的參考文獻，並且輸出到 LyX ，非常的漂亮和設計良好。為數不多的幾個快捷鍵和插件讓它擁有了圖書館的風格。

總的來説，很感謝這些工具軟件，有了它們，你就可以不用再擔心長長的文章了，至少是不用再擔心參考文獻的部分了。那麼我們還有什麼遺漏的嗎？是否還有其他的文獻管理工具你很喜歡？請在評論裏告訴我們。
