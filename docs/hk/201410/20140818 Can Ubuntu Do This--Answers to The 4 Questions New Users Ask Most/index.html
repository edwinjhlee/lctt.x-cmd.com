Ubuntu 有這功能嗎？－回答4個新用户最常問的問題 ​

**在谷歌輸入‘Can Ubunt[u]’，一系列的自動建議會展現在你面前。這些建議都是根據最近搜索用户最頻繁檢索而形成的。

對於Linux老用户來説，他們都胸有成竹的回答這些問題。但是對於新用户或者那些還在探索類似Ubuntu這樣的發行版是否適合的人來説，他們不是十分清楚這些答案。這都是中肯，真實而且是基本的問題。

所以，在這片文章，我將會去回答4個最常會被搜索到的"Can Ubuntu...?"問題。

Ubuntu可以取代Windows嗎？### ​

Windows 並不是每個人都喜歡或都必須的

是的。Ubuntu（和其他Linux發行版）是可以安裝到任何一台有能力運行微軟系統的電腦。

無論你覺得應不應該取代它，要不要替換隻取決於你自己的需求。

例如，你在上大學，所需的軟件都只是Windows而已。暫時而言，你是不需要完全更換你的系統。對於工作也是同樣的道理。如果你工作所用到的軟件只是微軟Office, Adobe Creative Suite 或者是一個AutoCAD應用程序，不是很建議你更換系統，堅持你現在所用的軟件就足夠了。

但是對於那些用Ubuntu完全取代微軟系統的我們，Ubuntu 提供了一個安全的桌面工作環境。這個桌面工作環境可以運行與支持很廣的硬件環境。基本上，每個東西都有軟件的支持，從辦公套件到網頁瀏覽器，視頻應用程序，音樂應用程序到遊戲。

Ubuntu 可以運行 .exe文件嗎？### ​

你可以在Ubuntu運行一些Windows應用程序

是可以的，儘管這些程序不是一步到位，或者不能保證運行成功。這是因為這些軟件原本就是在Windows下運行的，本來就與其他桌面操作系統不兼容，包括Mac OS X 或者 Android （安卓系統）。

那些專門為Ubuntu（和其他 Debian 系列的 Linux 發行版本）的軟件安裝包都是帶有“.deb”的文件後綴名。它們的安裝過程與安裝 .exe 的程序是一樣的 －雙擊安裝包，然後根據屏幕提示完成安裝。 （LCTT 譯註：RedHat 系統採用.rpm 文件，其它的也有各種不同的安裝包格式，等等，作為初學者，你可以當成是各種壓縮包格式來理解）

但是Linux是很多樣化的。它使用一個名為"Wine"的兼容層，可以運行許多當下很流行的應用程序。 (Wine不是一個模擬器，但是簡單來看可以當成一個快捷方式。）這些程序不會像在Windows下運行得那麼順暢，或者有着出色的用户界面。然而，它足以滿足日常的工作要求。

一些很出名的Windows軟件是可以通過Wine來運行在Ubuntu操作系統上，這包括老版本的Photoshop和微軟辦公室軟件。 有關兼容軟件的列表，參照Wine應用程序資料庫。

Ubuntu會有病毒嗎？### ​

它可能有錯誤，但是它並有病毒

理論上，它會有病毒。但是，實際上它沒有。

Linux發行版本是建立在一個病毒，蠕蟲，隱匿程序都很難被安裝，運行或者造成很大影響的環境之下的。

例如，很多應用程序都是在沒有特別管理權限要求，以普通用户權限運行的。病毒要訪問系統關鍵部分的請求也是需要用户管理權限的。很多軟件的提供都是從那些維護良好的而且集中的資源庫，例如Ubuntu軟件中心，而不是一些不知名的網站。 由於這樣的管理使得安裝一些受感染的軟件的幾率可以忽略不計。

你應不應該在Ubuntu系統安裝殺毒軟件？這取決於你自己。為了自己的安心，或者如果你經常通過Wine來使用Windows軟件，或者雙系統，你可以安裝ClamAV。它是一個免費的開源的病毒掃描應用程序。你可以在Ubuntu軟件中心找到它。

你可以在Ubuntu維基百科瞭解更多關於病毒在Linux或者Ubuntu的信息。 Ubuntu 維基百科。

在Ubuntu上可以玩遊戲嗎？### ​

Steam有着上百個專門為Linux設計的高質量遊戲

當然可以！Ubuntu有着多樣化的遊戲，從傳統簡單的2D象棋，拼字遊戲和掃雷遊戲，到很現代化的AAA級別的要求顯卡很強的遊戲。

你首先可以去 Ubuntu 軟件中心。這裏你會找到很多免費的，開源的和收費的遊戲，包括廣受好評的獨立製作遊戲，像World of Goo 和Braid。當然也有其他傳統遊戲的提供，例如，Pychess(國際象棋)，four-in-a-row（四子棋）和Scrabble clones（猜字拼字遊戲）。

對於遊戲狂熱愛好者，你可以安裝Steam for Linux。在這裏你可以找到各種這樣最新最好玩的遊戲。

另外，記得留意這個網站：Humble Bundle。每個月都會有兩週的這種“只買你想要的”的套餐。作為遊戲平台，它是對Linux特別友好的支持者。因為每當一些新遊戲出來的時候，它都保證可以在Linux下搜索到。
