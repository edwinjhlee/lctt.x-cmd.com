一款很棒的GTK桌面主題：Arc ​

距離本站上次推薦的GTK主題已經過了很久了。但是看到上圖中的Arc主題後，就值得打破冷場了。我們不能不推薦它！

Arc GTK主題 ​

透明，並不符合每個人的口味

Arc是一個扁平化主題並有微妙的配色方案，窗口的選中區域是透明的，如GTK的頂欄和Nautilus的側邊欄。

它的效果不像我們之前介紹的主題那樣將程序渲染的像那麼混亂。有點像 OSX Yosemite，效果用的不多但是很好。

與之伴隨的圖標集（稱為Vertex）同樣工作的很好。

是的它支持Unity

Arc主題支持基於GTK3和GTK2桌面環境，包含Gnome Shell(當然了)和標準的Ubuntu Unity。

它可以很好地遊刃於輕量級的Budgie和elementary的Pantheon桌面之間，並且與Cinnamon配合也不錯。

Arc中的開關、滑塊和小掛件

它並不容易下載與安裝- understatement klaxon - 因為它還在密集開發中。

安裝包需要GTK 3.14及以上，這意味着Ubuntu 14.04 LTS和14.10的用户無法使用了。

那些使用Ubuntu 15.04的用户可以使用這個主題。你可以添加ppa或者雙擊.deb包來安裝。

如果你喜歡它，你需要捲起你的袖子並查看github上的編譯指導。

更新6/7：現在可以使用軟件庫來安裝它（由 openSUSE 用户 Horst1380 創建，也可用於 Ubuntu 用户），也可以下載預打包的 .deb 文件。
