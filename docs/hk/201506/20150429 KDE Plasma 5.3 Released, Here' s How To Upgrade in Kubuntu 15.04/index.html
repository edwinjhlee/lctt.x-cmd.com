在 Kubuntu 15.04 中升級 KDE Plasma 5.3 ​

KDE已經發布了Plasma 5.3的穩定版，它包含了一個新的電源管理方面的穩定特性。

先前四月份的beta版已經讓我們印象深刻，甚至躍躍欲試了，Plasma 5桌面環境的穩定版更新的最新更新已經穩定，並且可以下載了。

Plasma 5.3繼續改善和細化了全新的KDE桌面，它添加了大量的特性供桌面用户體驗。同時也修復了多達400個錯誤，這對性能和穩定性方面也進行了大量改善。

Plasma 5.3中的新東西 ​

Plasma 5.3中更好的藍牙管理

而在早期關於Plasma 5.3的文章中，我們觸及了大量新特性，這其中很多都值得反覆説道説道。

加強的電源管理特性和配置選項，包括新的電源小程序、能源使用監控和動態屏幕亮度變化，將有助於讓KDE在移動設備上加強續航能力。

在連接了外部監視器的時候合上筆記本蓋子時，不會再觸發‘掛起’操作。這個新的行為被稱之為‘影院模式’，並且默認開啓。但是，可以通功過電源管理設置中的相關選項禁用。

藍牙功能被改善，帶來了一個全新的面板小程序，使得在連接到並配置配對的藍牙設備，如智能手機、鍵盤和揚聲器時，比以往更為便捷。

同樣，對於Plasma 5.3，KDE中的軌跡板配置更為方便，這多虧了新的安裝和設置模組。

軌跡板、觸控板。Tomato, Tomayto。

對於Plasma小部件狂熱者，它帶來了一個按住並鎖定手勢。當啓用該功能，會隱藏移動鼠標時出現的設置處理。取而代之的是，它只會在長點擊小部件時發生該行為。

談到widget-y這類事情時，該發佈版中再次引入了幾個舊的Plasmoid中最受歡迎的東西，包括一個有用的系統監視器、便利的硬盤驅動器統計和一個漫畫閲讀器。

瞭解更多&嘗試 ​

一張全部內容的完整列表——我説全部內容——是指Plasma 5.3中在官方修改日誌中列出的新的和改進的內容。

你可以從KDE社區獲取Live鏡像，試用Kubuntu上的Plasma 5.3，而不會影響到你自己的系統：

  • 下載KDE Plasma Live鏡像

如果你需要超級穩定的系統，你可以使用這些鏡像來嘗試新特性，但是你可以繼續使用你的主要計算機上與你的版本對應的KDE版本。

不過，如果你對實驗版滿意——請注意：能夠處理任何包衝突，或者由嘗試升級桌面環境而導致的系統問題——那麼你可以安裝。

安裝Plasma 5.3到Kubuntu 15.04 ​

要安裝Plasma 5.3到Kubuntu 15.04中，你需要添加KDE 移植PPA，運行軟件更新器工具並安裝任何可用的更新。

Kubuntu移植PPA可能也會升級除了安裝在你係統上的Plasma外的其它KDE平台組件，包括KDE應用程序、框架和Kubuntu特定配置文件。

目前為止，使用命令列來升級Kubuntu中的到Plasma 5.3是最快速的方法：

sudo add-apt-repository ppa:kubuntu-ppa/backports    
sudo apt-get update && sudo apt-get dist-upgrade

在升級過程完成後，如果一切順利，你應該重啓計算機。

如果你正在使用一個備用桌面環境，比如LXDE、Unity或者GNOME，則你需要在運行完上面的兩個命令後安裝Kubuntu桌面包（你可以在Ubuntu軟件中心找到）。

要降級到15.04中自帶的 Plasma 版本的話，你可以使用 PPA-Purge 工具：

sudo apt-get install ppa-purge
sudo ppa-purge ppa:kubuntu-ppa/backports
