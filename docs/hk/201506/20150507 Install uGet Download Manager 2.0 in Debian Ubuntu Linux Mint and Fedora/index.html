在 Debian, Ubuntu, Linux Mint 及 Fedora 中安裝 uGet 下載管理器 2.0 ​

在經歷了一段漫長的開發期後，併發布了超過 11 個開發版本，最終 uGet 項目小組高興地宣佈 uGet 的最新穩定版本 uGet 2.0 已經可以下載使用了。最新版本包含許多吸引人的特點，例如一個新的設定對話框，改進了 aria2 插件對 BitTorrent 和 Metalink 協議的支持，同時對位於橫幅中的 uGet RSS 信息提供了更好的支持，其他特點包括：

  • 新增一個 “檢查更新” 按鈕，提醒您有關新的發行版本的信息;
  • 增添新的語言支持並升級了現有的語言;
  • 新增一個 “信息橫幅” ，可以讓開發者輕鬆地向所有的用户提供有關 uGet 的信息;
  • 增強了幫助菜單，包括文檔、提交反饋和錯誤報告等內容的鏈接;
  • 將 uGet 下載管理器集成到了 Linux 平台下的兩個主要的瀏覽器 Firefox 和 Google Chrome 中；
  • 改進了對 Firefox 插件 ‘FlashGot’ 的支持;

何為 uGet ​

uGet (先前名為 UrlGfe) 是一個開源，免費，且極其強大的基於 GTK 的多平台下載管理器應用程序，它用 C 語言寫就，在 GPL 協議下發布。它提供了大量功能，如恢復先前的下載任務，支持多點下載，使用一個獨立的配置來支持分類，剪貼板監視，下載隊列，從 HTML 文件中導出 URL 地址，集成在 Firefox 中的 Flashgot 插件中，使用集成在 uGet 中的 aria2(一個命令列下載管理器) 來下載 torrent 和 metalink 文件。

我已經在下面羅列出了 uGet 下載管理器的所有關鍵特點，並附帶了詳細的解釋。

uGet 下載管理器的關鍵特點 ​

  • 下載隊列: 將你的下載任務放入一個隊列中。當某些下載任務完成後，將會自動開始下載隊列中餘下的文件；
  • 恢復下載: 假如在某些情況下，你的網絡中斷了，不要擔心，你可以從先前停止的地方繼續下載或重新開始；
  • 下載分類: 支持多種分類來管理下載；
  • 剪貼板監視: 將要下載的文件類型複製到剪貼板中，便會自動彈出下載提示框以下載剛才複製的文件；
  • 批量下載: 允許你輕鬆地一次性下載多個文件；
  • 支持多種協議: 允許你輕鬆地使用 aria2 命令列插件通過 HTTP, HTTPS, FTP, BitTorrent 及 Metalink 等協議下載文件；
  • 多連接: 使用 aria2 插件，每個下載同時支持多達 20 個連接；
  • 支持 FTP 登錄或 FTP 匿名登錄: 同時支持使用用户名和密碼來登錄 FTP 或匿名 FTP ；
  • 隊列下載: 新增隊列下載，現在你可以對你的所有下載進行安排調度；
  • 通過 FlashGot 與 FireFox 集成: 與作為一個獨立支持的 Firefox 插件的 FlashGot 集成，從而可以處理單個或大量的下載任務；
  • CLI 界面或虛擬終端支持: 提供命令列或虛擬終端選項來下載文件；
  • 自動創建目錄: 假如你提供了一個先前並不存在的保存路徑，uGet 將會自動創建這個目錄；
  • 下載歷史管理: 跟蹤記錄已下載和已刪除的下載任務的條目，每個列表支持 9999 個條目，比當前默認支持條目數目更早的條目將會被自動刪除；
  • 多語言支持: uGet 默認使用英語，但它可支持多達 23 種語言；
  • Aria2 插件: uGet 集成了 Aria2 插件，來為你提供更友好的 GUI 界面；

如若你想了解更加完整的特點描述，請訪問 uGet 官方的 特點頁面.

在 Debian, Ubuntu, Linux Mint 及 Fedora 中安裝 uGet ​

uGet 開發者在 Linux 平台下的各種軟件倉庫中添加了 uGet 的最新版本，所以你可以在你使用的 Linux 發行版本下使用受支持的軟件倉庫來安裝或升級 uGet 。

當前，一些 Linux 發行版本下的 uGet 可能不是最新的，但你可以到 uGet 下載頁面 去了解你所用發行版本的支持狀態，在那裏選擇你喜愛的發行版本來了解更多的信息。

在 Debian 下 ​

在 Debian Jessie 和Sid 中，你可以使用官方軟件倉庫輕易地安裝和升級可靠的 uGet 軟件包。

$ sudo apt-get update
$ sudo apt-get install uget

在 Ubuntu 和 Linux Mint 下 ​

在 Ubuntu 和 Linux Mint 下，你可以使用官方的 PPA ppa:plushuang-tw/uget-stable 安裝和升級 uGet ，通過使用這個 PPA，你可以自動地與最新版本保持同步。

$ sudo add-apt-repository ppa:plushuang-tw/uget-stable
$ sudo apt-get update
$ sudo apt-get install uget

在 Fedora 下 ​

在 Fedora 20 – 21 下，最新版本的 uGet(2.0) 可以從官方軟件倉庫中獲得可靠的軟件包。

$ sudo yum install uget

注: 在舊版本的 Debian, Ubuntu, Linux Mint 和 Fedora 下，用户也可以安裝 uGet ， 但可獲取的版本為 1.10.4 。假如你期待使用升級版本(例如 2.0 版本)，你需要升級你的系統並添加 uGet 的 PPA 以此來獲取最新的穩定版本。

安裝 aria2 插件 ​

aria2 是一個卓越的命令列下載管理應用，在 uGet 中它作為一個 aria2 插件，為 uGet 增添了更為強大的功能，如下載 toorent，metalinks 文件，支持多種協議和多來源下載等功能。

默認情況下，uGet 在當今大多數的 Linux 系統中使用 curl 來作為後端，但 aria2 插件將 curl 替換為 aria2 來作為 uGet 的後端。

aria2 是一個單獨的軟件包，需要獨立安裝。你可以在你的 Linux 發行版下，使用受支持的軟件倉庫來輕易地安裝 aria2 的最新版本，或根據 下載 aria2 頁面 來安裝它，該頁面詳細解釋了在各個發行版本中如何安裝 aria2 。

在 Debian, Ubuntu 和 Linux Mint 下 ​

利用下面的命令，使用 aria2 的個人軟件倉庫來安裝最新版本的 aria2 ：

$ sudo add-apt-repository ppa:t-tujikawa/ppa
$ sudo apt-get update
$ sudo apt-get install aria2

在 Fedora 下 ​

Fedora 的官方軟件倉庫中已經添加了 aria2 軟件包，所以你可以輕易地使用下面的 yum 命令來安裝它：

$ sudo yum install aria2
