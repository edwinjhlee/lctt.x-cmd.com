用 Tails 1.4 Linux 系統來保護隱私和保持匿名 ​

在這個互聯網世界和互聯網的世界中，我們在線執行我們的大多數任務，無論是訂票，匯款，研究，商務，娛樂，社交網絡，還是其它。每天我們花費大部分時間在網絡上。在過去這些的日子裏，在網絡中保持匿名變得越來越難，尤其是在被某些機構例如 NSA (National Security Agency) 植入後門的情況下，他們嗅探着我們在網絡中的所有動作。在網絡中，我們有着極少的，或者説根本就沒有隱私。基於用户瀏覽網絡的活動和機器的活動的搜索都被記錄了下來。

一款來自於 Tor 項目的絕妙瀏覽器正被上百萬人使用，它幫助我們匿名地瀏覽網絡，即使這樣，跟蹤你的瀏覽習慣也並不難，所以只使用 Tor 並不能保證你的網絡安全。你可以從下面的鏈接中查看 Tor 的特點及安裝指南。

  • 使用 Tor 來進行匿名網絡瀏覽

Tor 項目中有一個名為 Tails 的操作系統。Tails (The Amnesic Incognito Live System) 是一個 live 操作系統，基於 Debian Linux 發行版本，主要着眼於在瀏覽網絡時在網絡中保護隱私和匿名，這意味着所有的外向連接都強制通過 Tor 來連接，直接的(非匿名的) 連接請求都會被阻擋。該系統被設計為可在任何可啓動介質上運行，例如 USB 棒或 DVD。

Tails OS 的最新穩定發行版本為 1.4 ， 於 2015 年 5 月 12 日發行。Tails 由開源的 Linux 宏內核所驅動，構建在 Debian GNU/Linux 之上，着眼於個人電腦市場， 使用 GNOME 3 作為其默認的用户界面。

Tails OS 1.4 的特點 ​

  • Tails 是一個 free 的操作系統, free 的意義不僅是免費(free)啤酒的免費，也是言論自由(free) 中的自由
  • 構建在 Debian/GNU Linux 操作系統之上， Debian 是使用最廣泛的通用操作系統
  • 着眼於安全的發行版本
  • 偽裝成 Windows 8 外觀
  • 不必安裝就可以使用 Live Tails CD/DVD 來匿名瀏覽網絡
  • 當 Tails 運行時，不會在計算機上留下任何痕跡
  • 使用先進的加密工具來加密任何相關文件，郵件等內容
  • 通過 Tor 網絡來發送和接收流量
  • 真正意義地無論何時何處保護隱私
  • 在 Live 環境中帶有一些立即可用的應用
  • 系統自帶的所有軟件都預先配置好只通過 Tor 網絡來連接到互聯網
  • 任何不通過 Tor 網絡而嘗試連接網絡的應用都將被自動阻攔
  • 限制那些想查看你正在瀏覽什麼網站的人的行動，並限制網站獲取你的地理位置
  • 連接到那些被牆或被審查的網站
  • 特別設計不使用主操作系統的空間，即便是 swap 空間也不用
  • 整個操作系統加載在內存中，在每次重啓或關機後會自動擦除掉，所以不會留下任何運行的痕跡。
  • 先進的安全實現，通過加密 USB 磁盤， HTTPS 應答加密和對郵件，文檔進行簽名。

在 Tails 1.4 中所期待的東西 ​

  • 帶有安全滑塊的 Tor 瀏覽器 4.5
  • Tor 被升級到版本 0.2.6.7
  • 修補了幾個安全漏洞
  • 針對諸如 curl、 OpenJDK 7、 tor Network、 openldap 等應用， 許多漏洞被修復並打上了補丁

要得到完整的更改記錄，你需要訪問 這裏

注意: 假如你使用 Tails 的任何舊版本，強烈建議升級到 Tails 1.4 。

為什麼我應該使用 Tails 操作系統 ​

你需要 Tails 因為你想：

  • 在網絡監控下保持自由
  • 捍衞自由，隱私和秘密
  • 流量分析下保持安全

這個教程將帶你瞭解 Tails 1.4 操作系統的安裝並給出一個簡短的評論。

Tails 1.4 安裝指南 ​

  1. 為了下載最新的 Tails OS 1.4，你可以使用 wget 命令來直接下載它

    $ wget http://dl.amnesia.boum.org/tails/stable/tails-i386-1.4/tails-i386-1.4.iso

或者你可以直接下載 Tails 1.4 的 ISO 鏡像文件，或使用一個 Torrent 客户端來為你獲取 ISO 鏡像文件：

  • tails-i386-1.4.iso
  • tails-i386-1.4.torrent

  1. 下載後，可使用 sha256sum 來獲取 ISO 文件的哈希值並與官方提供的值相比較，以核實 ISO 文件的完整性

    $ sha256sum tails-i386-1.4.iso

    339c8712768c831e59c4b1523002b83ccb98a4fe62f6a221fee3a15e779ca65d

假如你熟悉 OpenPGP ，將 Tails 的簽名密鑰與 Debian 的 keyring 相比較以驗證其簽名，若想了解任何有關 Tails 的加密簽名，請用瀏覽器訪問 這裏

  1. 下一步，你需要將鏡像寫入 USB 棒或 DVD ROM 中。或許你需要看看這篇文章 “如何創建一個 Live 可啓動的 USB棒 ”以瞭解如何使得一個閃存盤變得可啓動並向它寫入 ISO 鏡像文件。

  2. 插入 Tails OS 的可啓動閃存盤或 DVD ROM，並從那裏啓動 (在 BIOS 中選擇該介質來啓動)。第一個屏幕中會有兩個選項 'Live' 和 'Live (failsafe)' 讓你選擇。選擇 'Live' 並確定。

  1. 在登錄之前，你有兩個選項， 假如你想配置並設定高級選項，點擊 '更多選項' 否則點擊 'NO'。

Tails 歡迎界面

另外，若你想開啓 Windows 偽裝，假如你想在一個公共場所運行這個操作系統，這將使得看起來你正在運行 Windows 8 操作系統。這真是一個好的選項！不是嗎？另外，你還有一個選項來配置網絡和 Mac 地址，當一切準備完畢後，點擊 '登錄' ！

Tails 適合我嗎？#### ​

要想得到上面問題的答案，首先回答如下的問題：

  • 在上網時，你想你的隱私不被觸動嗎？
  • 你想在竊取身份信息的人的眼皮底下保持隱身嗎？
  • 你想在你的網上私人聊天過程中被他人嗅探嗎？
  • 你真的想向任何人展示你的地理位置嗎？
  • 你開展銀行網上交易嗎？
  • 你願意受政府和 ISP的審查嗎？

假如以上問題中，任意一個問題的答案為 'YES'，則你最好需要 Tails。假如上面所有的問題的答案都是 'NO'，則或許你不需要它。

總結 ​

對於那些工作在不安全環境中的人來説，Tails 是一個必需的操作系統。Tails 還是一個着眼於安全的操作系統，現在為止，包含了一大批應用 – Gnome 桌面、Tor、 Firefox (Iceweasel)、 Network Manager、 Pidgin、 Claws mail、 Liferea feed addregator、 Gobby、 Aircrack-ng、 I2P。

同時，它含有一些有關加密和隱私的工具，即 UKS、 GnuPG、 PWGen、 Shamir's Secret Sharing、 Virtual Keyboard (對付硬件的鍵盤記錄器)、 MAT、 KeePassX Password Manager 等。

這就是全部了。關注我們。請分享你的有關 Tails GNU/Linux 操作系統的想法。對於這個項目的未來，你怎麼看？同時在實際中測試它，並讓我們獲知你的體驗感受。

你也可以在 Virtualbox 中運行它。 Tails 在內存中加載整個操作系統，所以在虛擬機中你需要給定足夠的內存來運行 Tails。

我在 1GB 內存的環境中測試了 Tails，它工作起來毫無滯後感。謝謝我們的所有用户的支持。使我們成為一個包含所有 Linux 相關信息的地方，你的支持是必需的。 Kudos！
