在家工作的十大開源工具 ​

無論你是在家工作的資深人士還是遠程工作的新手，這些工具都可以使交流和協作變得輕而易舉。

如果你在家工作work from home（WFH），你就會知道擁有一系列實用的工具是很重要的，這些工具可以讓你遠離煩惱，專注於重要的事情。在工作期間工作越努力，工作日結束後，你就越容易放鬆。

我已經在家工作多年了，這是我精選的遠程工作者必備的最佳開源工具。

視頻會議：Jitsi ​

當你不在同事身邊時，每週保持連接幾次非常重要，甚至只是這樣也可以保持人與人之間的聯繫，否則你就會變得孤獨。市場上有很多視頻會議系統，但以我的經驗，最簡單、最好的是開源的 Jitsi。

通過易於記憶的 URL（meet.jit.si）和按需會議室，Jitsi 使得召開即席會議非常簡單。而且更好的是，無需註冊。你只需進入 meet.jit.si，找到一個帶有友好的、隨機生成的 URL（此處沒有字母和數字的隨機組合） 的會議室，你就可以立即開始聊天。如果你選擇註冊，那麼還可以與幾種日曆進行集成。

在現實生活中，我參加了許多來自新西蘭最偏遠地區的會議，而 Jitsi 無疑是我迄今為止擁有的最好的視頻聊天體驗。不需要浪費一半的會議時間在迷宮般的虛擬會議室中尋找彼此，也不用在尷尬的滯後時間中坐着發呆，更不用努力地為聊天應用程序安裝更新。使用開源和符合標準的 webRTC 協議的 Jitsi 可以讓你有個愉悦的開會體驗。

白板：Drawpile ​

有時，白板非常適合解釋事情、跟蹤想法或只是散佈一下瘋狂的想法。白板是辦公室會議室的常見物品，但在數字世界中卻很難獲得。幸運的是，有了 Drawpile，這是一個實時協作的繪圖應用程序。你可以在自己的計算機上託管繪圖會話並邀請其他用户，也可以在 Drawpile 的服務器上託管會話。

它易於使用，足夠精簡、直觀而功能強大，當你的粗略想法開始逐漸成型時，它是使其成為可行的作品的應用程序。

看板：Taiga ​

想要保持有序並與你的部門保持同步嗎？你應該試試 Taiga，這是一個虛擬的“便利貼”面板，可以幫助團隊跟蹤各個任務。這種組織和項目計劃方法被稱為看板kanban，在軟件開發中很流行，而它也流行於從假期規劃到家庭裝修項目的所有計劃之中。

Taiga 的優點是它是一個在線共享空間。與你進行協作或與之合作的任何人都可以把任務放到面板上，並且隨着每個人的進展，他們將任務從左列（起點）移到右邊（終點線）。Taiga 具有令人愉悦的圖形化和交互性，沒有什麼比從一列移動到另一列的拖放任務令人感到舒適的了。

如果你的團隊有 Taiga 無法滿足的特定需求，那麼你應該看看我們挑選的最佳開源看板。

個人筆記本：Joplin ​

我在辦公桌旁放着一個紙質筆記本，這樣我就可以隨時記下思考或想法了。想要捕捉這種簡單動作的感受和便利是很棘手的，但 Joplin 卻做的很好。

你可以在 Joplin 中創建虛擬筆記本，每個筆記本可以有任意數量的條目。這些條目可以是簡單的文本，也可以是帶有圖形、任務列表、超鏈接等的複雜的動態文檔。最重要的是，你可以將 Joplin 與所有的在線存儲服務同步，包括開源的 Nextcloud 服務，這樣你可以在任何計算機和任何設備上使用筆記本。這是使你的工作日井井有條、專心致志並保持活動順暢的好方法。

如果 Joplin 不太滿足你的要求，請查看一些我們最喜歡的筆記本應用。

羣聊：Riot ​

並非所有內容都需要視頻聊天或語音通話，但是有些事情比電子郵件更緊急。這就是團隊聊天發揮作用的地方。一個好的羣聊應用程序應該具有這些功能：即時消息傳遞、支持表情符號、支持 GIF 和圖像，按需聊天室或“頻道”、廣泛的兼容性和隱私性。Matrix 是一個用於實時通信的開放標準和輕量級協議，如果你厭煩於鍵入大段消息，則可以使用相同的協議快速切換到 VOIP。你將獲得世界上最好的羣聊體驗。

Matrix 是一種協議，並且有許多應用程序可以接駁到它（就像使用 Internet 協議一樣，Firefox 是使人類可以訪問的應用程序）。最受歡迎的客户端之一是 Riot.im。你可以為你的計算機和手機下載 Riot，並且只是短時間使用的話，可以通過 Web 瀏覽器連接到 Riot。你的團隊總是會近在咫尺，但永遠不會近到讓你感到不舒服。

共享文檔：Etherpad ​

如果你想與他人協作處理文檔或與開會，則僅需 Etherpad 就行。Etherpad 是一個實時共享的文字處理器。可以邀請一個或多個人訪問文檔，並在每個人進行添加和編輯時進行觀察。這是一種快速有效的方法，可將想法記入“紙上”並一起迭代修訂。

有幾種使用 Etherpad 的方法。如果你擁有良好的 IT 支持，則可以要求你的 IT 部門為你的組織託管一個 Etherpad 實例。否則，將有來自開源支持者的在線公共實例，例如 Riseup 和 Etherpad 本身所提供的。

共享電子表格：Ethercalc ​

與 Etherpad 相似，在線 Ethercalc 編輯器允許多個用户同時在同一屏幕上遠程地在電子表格上工作。Ethercalc 甚至可以從現有電子表格和定界文本文件中導入數據。你可能會也可能不會丟失大部分格式，具體取決於要導入的內容的複雜性，但是我從來沒有弄壞過我的數據，因此導入文件總是一個好的開始。 下次需要複雜公式的幫助時，或者需要在最新預算中輸入收據時，或者只是需要某人在格子上的輸入時，請將其輸入到 Ethercalc。

共享存儲與日曆：Nextcloud ​

Nextcloud 是一個心存遠志的應用程序。顧名思義，它是你自己的個人雲。它最明顯的切入點是在線共享存儲，它可以與台式機和移動設備上的文件夾同步。將文件放入文件中，文件會上傳到存儲空間，然後當一切內容都同步後，它們會出現在所有設備上。為組織中的每個人提供一個帳户，你馬上便擁有了共享的存儲空間，可以通過單擊鼠標單擊以共享帶有或不帶有密碼的文件和文件夾。

但是，除了充當共享數據的保管箱之外，Nextcloud 還有很多其他功能。由於其插件式結構，你可以將無數的 Web 應用程序安裝到 Nextcloud 中，例如聊天客户端、電子郵件客户端、視頻聊天等等。並非所有插件都是“官方的”，因此其支持服務各不相同，但是有幾個非常好的官方插件。值得注意的是，有一個官方的日曆應用程序，你和你的同事可以用它安排會議並跟蹤即將發生的重要事件。該日曆使用 CalDAV 協議，因此你所做的一切都可以與任何 CalDAV 客户端兼容。

LibreOffice ​

如果你習慣於每天一整天都在辦公室裏工作，那麼你也可能習慣整天在辦公套件裏工作。包含所有常用功能的面面俱到的應用程序會令人感到某種程度的舒適，而在開源辦公世界中的這樣的應用程序就是 LibreOffice。它具有辦公套件所應有的一切：文字處理器、電子表格和幻燈片演示。它還具有超出預期的功能，例如基於矢量的繪圖應用程序，它還可以編輯 PDF 文件，還有一個帶有圖形界面構建器的關係型資料庫。如果你正在尋找一個好的辦公應用程序，那麼 LibreOffice 是你應該首先看一看的，因為一旦你使用它，你就再也不用看別的了。

Linux ​

如果你不熟悉遠程工作，而可能是由於某種原因而正在經歷一場重大變革。對於某些人來説，變革的時光是一個極好的動力，它可以一勞永逸地改變一切。如果你是其中的一員，那麼可能是時候更改一下整個操作系統了。Windows 和 Mac 可能在過去為你提供了很好的服務，但是如果你希望從非開源軟件轉向開源軟件，為什麼不換一下運行所有這些應用程序的平台呢？

有許多出色的 Linux 發行版可以讓你認真地工作、認真地自我管理和認真地進階。獲取一份 Linux 副本，不論是 Fedora、Elementary 還是 Red Hat Enterprise Linux 的長期支持訂購，去嘗試使用自由的開源操作系統吧。等你熟悉了遠程人的生活時，你最終將成為一名 Linux 專家！
