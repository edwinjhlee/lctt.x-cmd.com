可在 Linux 桌面使用的 3 個電子書閲讀器應用 ​

任意一個開源電子書應用都能使你在大屏設備上的閲讀體驗得到提升。

我通常使用手機或 Kobo 閲讀器閲讀電子書，總是沒有在大屏設備上閲讀書籍那麼爽。很多人經常在自己的筆記本或桌面電腦上閲讀電子書，如果你有這種需求（或者你認為以後會遇到這種情況），我想向你介紹三種 Linux 桌面下的電子書閲讀器。

Bookworm（書蟲） ​

Bookworm 意在成為一個“簡潔、專注的電子書閲讀器”。事實證明它也確實做到了。Bookworm 內置一系列基礎功能，有人抱怨它太過簡單，缺少功能性（雖然這詞顯然有點指意不明）。Bookworm 起到了應有的作用而沒有無關的花哨功能。

該應用的界面整潔乾淨。

你可通過以下方式查看書籍：

  • 空格鍵前往下一頁
  • 上下方向鍵按行移動
  • 左右方向鍵跳轉至前後章節

你也可以通過添加註釋或書籤跳轉至特定頁面。

Bookworm 沒有太多設置選項。你能調整書籍字體大小及間距，開啓雙頁模式或夜間模式。在應用中添加新文件夾後，Bookworm 會自動掃描文件夾中的電子書。

Bookworm 支持常用的電子書格式：EPUB、PDF、MOBI、FB2，你還能用它閲讀 CBR 和 CBZ 格式的數字版漫畫。我只在 Bookworm 上測試了前三種格式，PDF 倒是能打開，但加載速度很慢，格式也很難看。

Foliate ​

單從功能上來説，Foliate 確實比 Bookworm 強上一些。Foliate 不僅功能更強，它還有更多設置選項。這個功能多樣、簡單幹淨的應用滿足了所有要求。

在 Foliate 中可以通過空格、方向鍵、向上或向下翻頁鍵瀏覽電子書，這裏沒什麼特別的。

你還可以在書籍中添加註釋、查找以及翻譯字句、查詢字詞含義。如果你電腦上安裝了智能語音應用， Foliate 還能將文本朗讀出來。

Foliate 與 Bookworm 相比有更多自定義選項。你能在應用中修改字體類型及大小、行間距、電子書頁邊距，也可以調高或降低屏幕亮度，從應用內置的四個主題中選擇一個等。

你可以在 Foliate 上閲讀 EPUB、MOBI、AZW、AZW3 格式的電子書。如果你不瞭解，我可以提前告訴你，後三種格式是亞馬遜 Kindle 閲讀器上架的書籍的閉源格式。

Calibre 電子書閲讀器 ​

這個電子書閲讀器是 Calibre 電子書管理工具的一個組件，就像它的前代一樣，電子書閲讀器這部分並不是軟件整體最棒的部分。

不過別被上面的話嚇到，它也的確是個桌面電子書閲讀器。

在 Calibre 電子書閲讀器中，你可以通過方向鍵、向上/向下翻頁鍵以及空格瀏覽書籍，還能在在線字典中查找詞語含義，添加書籤。這一閲讀器沒有註釋功能，但內置的搜索引擎卻很好用，你還能將書籍保存為 PDF 格式（雖然我不太明白你為什麼要這麼做）。

不過參數設置這裏確是它出彩的地方，它的可選設置比 Bookworm 和 Foliate 加起來都多，從字體到文本佈局，頁面分割方式你都能改。除此之外，你還能自定義應用按鍵設置，將你喜歡的詞典網站添加進來，方便閲讀查找。

Calibre 電子書閲讀器一個很有用的功能，就是把自行設置的 CSS 配置文件效果應用到電子書上。贅言一句，CSS 是一種調整網頁格式的方法（這類文件就是許多電子書的一個組成部分）。如果你是使用 CSS 的高手，你可以將自己的 CSS 文件複製粘貼到配置窗口的 “User stylesheet” 部分，這就是個性化的究極辦法。

據開發者描述，這一電子書閲讀器“能支持所有主流電子書格式”。如果你想知道具體支持格式是什麼，這是列表鏈接。我測試了列表中的一小部分格式，沒有發現問題。

留在最後的話 ​

不管你只是單純想找個電子書閲讀器，還是有個更多複雜功能的應用，上文提到的三個選擇都很不錯，而且它們都能提升你在大屏設備上的閲讀體驗。
