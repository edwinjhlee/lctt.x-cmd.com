10 篇對初學者和專家都有用的 Linux 命令教程 ​

在這有關 Linux 命令的十大文章中，瞭解如何使 Linux 發揮所需的作用。

很好地使用 Linux 意味着瞭解有哪些命令以及它們可以為你執行的功能。

《在 Linux 命令列下使用“原力”》 ​

原力force有光明的一面和黑暗的一面。正確理解這個對於真正掌握它至關重要。Alan Formy-Duval 在他的文章《在 Linux 命令列下使用“原力”》中，解釋了一些流行的、有時是危險的命令的 -f 選項（也稱為 --force）。

《Linux useradd 命令介紹》 ​

共享帳户是一個壞主意。相反，請使用典型的 useradd 命令為不同的人（甚至是不同的角色）分配單獨的帳户。作為其經典的 Linux 管理基礎系列的一部分，Alan Formy-Duval 提供了《Linux useradd 命令介紹》，並且像往常一樣，他用樸實明白的語言對其進行了解釋，以便新老管理員都可以理解。

《用 Linux 命令顯示硬件信息》 ​

機器裏面是什麼？有時不使用螺絲刀檢查硬件很有用。無論是你正在使用的計算機，還是在商店購買前進行測試的計算機、或者是正在嘗試維修的計算機，在《用 Linux 命令顯示硬件信息》中，Howard Fosdick 提供了或流行或晦澀難懂的命令，以幫助你深入瞭解計算機的硬件信息。

《如何在 Linux 上使用 gocryptfs 加密文件》 ​

從社會保險號到個人信件再到親人，我們的文件中包含了許多私人數據。在《如何在 Linux 上使用 gocryptfs 加密文件》中，Brian "Bex" Exelbierd 解釋瞭如何保持**隱私*的私密性。此外，他展示了一種加密文件的方式，這種方式對你現有的工作流程幾乎沒有影響。這不是複雜的 PGP 風格的密鑰管理和後台密鑰代理的難題，這是快速、無縫和安全的文件加密。

《如何使用 rsync 的高級用法進行大型備份》 ​

在新的一年中，許多人會下定決心要更加努力地進行備份。Alan Formy-Duval 早在幾年前就已經做出瞭解決方案，因為在《如何使用 rsync 的高級用法進行大型備份》中，他表現出對文件同步命令的極其熟悉。你可能不會馬上記住所有語法，但其思路是讀取和處理選項、構造備份命令，然後使其自動化。這是使用 rsync 的明智方法，也是可靠地執行備份的唯一方法。

《在 Linux 命令列使用 more 查看文本文件》 ​

在 Scott Nesbitt 的文章《在 Linux 命令列使用 more 查看文本文件》中，古老而良好的默認分頁器 more 引起了人們的關注。許多人安裝和使用 less，因為它比 more 更靈活。但是，隨着越來越多的系統在新出現的容器中實現，有時甚至不存在像 less 或 most 之類的新穎的豪華工具。瞭解和使用more 很簡單，這是常見的默認設置，並且是生產系統最後的調試工具。

《關於 sudo 你可能不知道的》 ​

sudo 命令因其過失而聞名。人們知道 sudo 一詞，我們大多數人認為我們知道它的作用。我們的觀點是正確的，但是正如 Peter Czanik 在他的文章《關於 sudo 你可能不知道的》中所揭示的那樣，該命令所包含的不僅僅是“西蒙説的Simon says”（LCTT 譯註：國外的一個兒童遊戲）。就像這個經典的童年遊戲一樣，sudo 命令功能強大，也容易犯愚蠢的錯誤 —— 有更多的可能產生可怕都後果，而這是你絕不想遇上的事情！

《怎樣用 Bash 編程：語法和工具》 ​

如果你是 Linux、BSD 或 Mac（以及近來的 Windows）用户，你也許使用過交互式 Bash shell。它是快速的、一次性命令的絕佳 shell，這就是為什麼這麼多 Linux 用户喜歡將其用作主要用户界面的原因。但是，Bash 不僅僅是個命令提示符。它也是一種編程語言，如果你已經在使用 Bash 命令，那麼自動化的道路從未如此簡單過。在 David Both 的出色作品《怎樣用 Bash 編程：語法和工具》中對其進行全面瞭解。

《精通 Linux 的 ls 命令》 ​

ls 命令是那些兩個字母的命令之一。單字母命令是針對慢速終端的優化，因為慢速終端的輸入的每個字母都會導致明顯的延遲，而這對於懶惰的打字員來説也是不錯的獎勵。一如既往地，Seth Kenlon 清晰實用地解釋了你可以怎樣《精通 Linux 的 ls 命令》。最重要的是，在“一切都是文件”的系統中，列出文件至關重要。

《Linux cat 命令入門》 ​

cat 命令（concatenate 的縮寫）看似簡單。無論是使用它來快速查看文件的內容還是將內容通過管道傳輸到另一個命令，你都可能沒有充分利用 cat 的功能。Alan Formy-Duval 的《Linux cat 命令入門》提供了一些新思路，可以使你沒有打開文件的感覺就可以看到文件內容。另外，瞭解各種有關 zcat 的知識，這樣你就可以無需解壓縮就可以得到壓縮文件的內容！這是一件小而簡單的事情，但是這是使 Linux 很棒的原因。

繼續旅程 ​

不要讓這些關於 Linux 命令的 10 篇最佳文章成為你的旅程終點。關於 Linux 及其多才多藝的提示符，還有更多值得去發現，因此，請繼續關注以獲取更多知識。而且，如果你想讓我們介紹一個 Linux 命令，請在評論中告訴我們。
