Netflix支持 Ubuntu 上原生回放 ​

**我們上個月説的Netflix 的原生Linux支持很接近了，現在終於有了，我們只需幾個簡單的步驟就可以在Ubuntu桌面上啓用HTML 5視頻流了。

現在Netflix更近一步提供了支持。它希望給Ubuntu帶來真正的開箱即用的Netflix回放。現在只需要更新網絡安全（Network Security Services，NSS）服務庫就行。

原生Netflix? Neato. ​

在一封發給Ubuntu開發者郵件列表的郵件中，Netflix的Paul Adolph解釋了現在的情況：

“如果NSS的版本是3.16.2或者更高的話，Netflix可以在Ubuntu 14.04的穩定版Chrome中播放。如果版本超過了14.04，Netflix會作出一些調整，以避免用户必須對瀏覽器的 User-Agent 參數進行一些修改才能播放。”

[LCTT 譯註：此處原文是“14.02”，疑是筆誤，應該是指Ubuntu 14.04。]

很快要發佈的Ubuntu 14.10提供了更新的NSS v3.17, 而目前大多數用户使用的版本 Ubuntu 14.04 LTS 提供的是 v3.15.x。

NSS是一系列支持多種安全功能的客户端和服務端應用的庫，包括SSL，TLS，PKCS和其他安全標準。為了讓Ubuntu LTS用户可以儘快用上原生的HTML5 Netflix， Paul 問道：

”讓一個新的NSS版本進入更新流的過程是什麼？或者有人可以給我提供正確的聯繫方式麼？“

Netflix今年早期時在Windows 8.1和OSX Yosemite上提供了HTML5視頻回放，而不需要任何額外的下載或者插件。現在可以通過加密媒體擴展特性來使用。

雖然我們等待這討論取得進展（並且希望可以完全解決），但是你仍可以在Ubuntu上下面的指導來修改HTML5 Netflix。

更新：9/19

本文發表後，Canonical 已經確認所需版本的NSS 庫會按計劃在下個“安全更新”中更新，預計 Ubuntu 14.04 LTS 將在兩週內得到更新。

這個新聞讓 Netflix 的Paul Adolph 很高興，作為回應，他説當軟件包更新後，他將“去掉 Chrome 中回放 Netflix HTML5 視頻時的User-Agent 過濾，不再需要修改UA 了”。
