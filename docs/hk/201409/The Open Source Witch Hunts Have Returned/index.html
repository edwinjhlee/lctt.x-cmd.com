扫码关注官方微信公众号获取开源软件和 x-cmd 的最新用法与独家资讯

開源女巫狩獵歸來！ ​

開源軟件社區已經做出了改變，就像之前的美好時光。

開源已經變的温和了，之前我們有過各種不同的思潮，但是最近我們對分享代碼和創新卻有種奇怪的迷戀。

幸運的是，這一系列的使用主義註定要結束了。在過去的一段時間裏，我們團結在Mozilla身邊支持DRM版權保護以及嘲笑Red Hat和OpenStack之間的競爭。開源社區那些年僅有的幾個開源軟件明星和Open Core 這種商業模式產生了衝突而被反噬了。

噢，怎麼變成這樣了！

Red Hat 退回到2003年 ​

Red Hat，開源軟件理想主義的典範，在幾周前拒絕支持它的競爭對手。Jodi Mardesich出色的揭露了真相，而Red Hat在努力辯護，這個真相就是：

Red Hat不想支持它的競爭對手，它的OpenStack的競爭對手也不想這樣做。

在另外世界上這算是新聞嗎？

Mozilla變成了麻瓜 ​

Red Hat作為開源軟件理想主義的典範代表很容易成為各種帶顏色攻擊的目標，Mozilla其實是更大的一個目標。

Mozilla致力於為用户服務，它最近進行了一場自我犧牲似的CEO 下台，同意加入DRM的技術，即純Firefox瀏覽器源碼可以使用户觀看視頻。

人們想看視頻，Mozilla傾向於在它的瀏覽器中觀看。

總是找到別人的思想滑坡的問題，開源軟件組織批評了 Mozilla，深切表達了自己對於Mozilla的失望，因為這種“為減輕市場份額的流失而妥協重要原則的決定”令人擔憂。

但是，Mozilla為什麼要做這樣的傻事呢，為了用户，你懂的。

拋開道德説教的部分不説，電子前沿基金會哀嘆，“開放網絡最後的抗爭已經失敗了”。它對Mozilla投降的做法爭論道：“接受DRM會改變這個行業”！DRM的倡導者一再妥協，一個公司又一個公司(PC行業)演變成一個行業，它通過鎖定裝置，監視器，接受每一個人的管理建立自己的利益關係。

Mitchell Bake解釋道，Mozilla可能並沒有投降：“Firefox用户會需要使用另外的瀏覽器來觀看他們自己想看的視頻，這會讓人懷疑Firfox做一一個產品是否真的有用”。

嗯，好吧。

回到我們的思想源頭 ​

我們或許希望其它人都按照我們的想法來，但事實上他們卻有着不同的考慮。免費的軟件讓步給更加務實的開源軟件，認為只有“不二法門”的想法也逐漸消亡了。

這種意識在目前還是有用的，但它並不總是方便和舒服。我崇尚開源軟件的實用主義和Apache軟件基金會，這樣有很大的好處提醒GPL組織在意識形態上的危機感。軟件自由真的很重要。

這麼多悲觀的言論，我自己也感到了恐懼，希望回到一個不斷會自我鞭策的免費的開軟軟件的組織。這使開源軟件協作變少而且更難駕馭，但是會變得更有力而且關乎未來。
