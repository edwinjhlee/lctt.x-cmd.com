“雲”是怎麼影響着每一位linux用户的？ ​

“雲”簡介 ​

不論是報紙、在線資訊、播客、科技Blog、科技門户網站，甚至是電台和電視。“雲計算”永遠都是人們津津樂道的主題。

然而，因為“雲計算”包含了太多的東西，現在並沒有一個明確的定義，所以你認為“雲計算”應該是什麼呢？

雲計算 過去常常被當做是網絡計算的一個模型，網絡計算就是把用户程序或者是應用運行在一個聯網的服務器或是一個服務器集羣，而不是像個人電腦、平板以及智能手機這一類運算設備。比如像傳統的client-server (客户機-服務器模型) 和老一代的大型機，^[1] 用户通過連接服務器來執行一項任務。這和“雲計算”是不同的，“雲計算”是利用虛擬化的技術，把運算進程運行在一個或多個服務器上。利用虛擬技術，越來越多的物理化的服務器被配置和劃分成多個獨立的“虛擬”服務器，每個服務獨立運行，對於用户來説，就像是運行在一個獨立的物理服務器上一樣。虛擬服務器本質上還是從他們的物理服務器中分離出來的，由於這種靈活的配置方式，使得人們可以按照意願移動服務器和按比例分配資源而不影響最終的用户體驗。計算機資源已成“顆粒”，給用户和管理人員提供方便，包括提供按需自助服務，支持更廣泛的跨平台之間的訪問，資源共享，快速重新部署，可被監控與量測服務。^[2]

以上引用摘自維基百科。

在過去，我們要麼用啞終端連接大型電腦主機，要麼近年來使用桌面電腦連接運行在內部服務器上的應用，就像網站連接資料庫一樣。

現在，所有桌面、應用和服務器的管理都已經本地化，都需要來自它們所屬公司的技術支持。

然而這隻對軟件公司等少數的公司有利，卻對其他的一些商業公司不利，比如説銀行、保險公司和石油公司。信息技術公司沒有銀行的職能，就好像是做餐飲的鑽不出地下的石油一樣。

大公司早已把很多服務外包給專業的公司。例如，讓餐飲公司為他們的員工提供食堂，以及我們所熟知的離岸呼叫中心處理銀行業務的客户電話。

IT 行業的很多服務也逐漸轉向外包，許多的技術支持和開發的業務都被打包給中國、印度、馬來西亞和東歐。

雲計算與傳統的典型模型有很大不同的一方面在於虛擬化，這種虛擬化的技術把服務運行於虛擬服務器上，服務器可以被放置在同一個地方或者是相隔千山萬水，但是，這並不重要，你也不用擔心，因為那不是你該擔心的事情。

現在，“雲計算”已經成為雲計算基礎設施的簡稱。^[4] 這個術語來源於早年一些網絡工程師用雲狀的符號表示那些對他們來説未知的網絡。^[5] 後來，營銷者普及了這個雲的概念，指的是軟件、平台和一些可以買賣的基礎設施。比如，遠程登錄互聯網。

因此，這篇文章講述了和雲相關的所有，對於linux的用户來説，這意味着你想用它做什麼和它能為自己做些什麼，當然，這有可能也會給我們造成一些誤區。

從一個終端用户和家庭使用者的角度來看，雲計算最基本的就是提供在線服務。

所以，讓我們來説一説雲能到底能給每一位linux用户提供些什麼有用的服務？

電子郵件 ​

當你讀到這裏的時候，如果你還沒有一個電子郵箱，我只能説你OUT了。

據PC雜誌顧問統計分析，截至2014三月份，電子郵箱的用户最多的前六名分別是Outlook、GMail、Yahoo、icloud、AOL和GMX。

辦公套件 ​

和電子郵件客户端一樣，對於每個人來説，另一個最常用的工具之一就是辦公套件。

在以前，當人們剛剛進入電腦世界的時候，買一個電腦會帶回一個超大型的機器和半打子CD，刻着幾個沒用的 Microsoft Works ( 微軟工作軟件 )。 (LCTT譯註：Microsoft Works Mirosoft Works是微軟的一種家用綜合軟件，它主要面向低端的家庭用户,提供基本的能提高生活效率的工具,比如提供簡單的文檔處理、資料庫、電子表格的入門級辦公包功能。) 微軟工作軟件是一個廉價，而且無用到幾乎要被砍掉的微軟office版本。

而現在，你甚至不需要在你的電腦上安裝任何的辦公套件，即便是有LibreOffice和Kingsoft這樣好的軟件供選擇。

最好的選擇當然是Google Docs和Office 365。對於Office 365能否很好的運行於Linux平台，這篇來自2012期專業電腦的文章似乎説明了這個問題。

有人説這怎麼可能呢，我不相信，所以，我註冊並登錄了Office 365，想看看到底是什麼情況。

註冊，可以免費試用一個月，並且會贈送包括Word、Excel、和Outlook等一些在線應用。

一切看起來都挺好，我打開了Microsoft Word，選擇了一個模板來使用，當然根本就沒有打開成功。

Office 365 並沒有很好的支持linux設備，況且，説實話，你也不需要這東西。so，咱們繼續。

Google Docs對於一般的辦公支持非常完美，它能完成很多的事情，並且有很多的模板針對文字處理，演示工具，電子表格等。即使它始終也代替不了Excel，因為他並沒有成百上千的開發人員為其創建宏和編寫VBA腳本。

另一個可供選擇的辦公套件是Zoho。

和Google Docs一樣，Zoho也包含有文字處理工具，演示程序，電子表格程序和電子郵件。

此外，還有很多金融和客户管理系統。

這個工具的界面看起來真的很簡潔，很棒。

它和Google Docs和Zoho這些在線服務一樣，給予了人們相互協作的便利。

很多文檔被不同的人分享，然後在不同的地方被不同的人修改完善。

這裏會給出一些理由來幫助你從Google Docs和Zoho中選擇一個適合你的辦公套件。

在線文件存儲 ​

Google Docs和Zoho給我們提供了其他一些很好的服務，就是很好的線上存儲能力，你們可以線上存儲很多文檔和創建很多文件。

也有一些其他的服務,比如説Dropbox,僅僅只提供在雲存儲服務。

像Dropbox這樣的雲存儲的好處是如果你的東西被偷了或者是不小心房子着火了，而這時，你仍然有一份離岸備份是安好無缺的。你仍然可以在任何地方獲取你的文件。

Dropbox對於前2G的容量是免費的，如果你還有更多的東西要存儲，每天還有更多的事情要做，每個月只要9.9美刀，你就能擁有100G的存儲空間，另外，Dropbox也提供商務版本，每個月15美刀。

當然，並不是説Dropbox沒有可替代的方案，這個網站也提供了很多很好的一些在線備份的方案。

相冊 ​

自從有了數碼照相機和智能手機，現在越來越多的人們利用存儲卡來保存照片。

我相信肯定有人因為電話壞了而丟失照片，因為他的照片是存儲在電話上的，而不是其他的存儲設備，甚至，有些因為丟失了電話而丟失了他們孩子的運動會照片或者是其他一些具有紀念意義的照片資料。

丟失電話肯定不是什麼好事情，如果你放機靈一點，情況可能要好一點，因為很多人的電話和email，facebook，Twitter的賬户是同步的，甚至在線存儲也是。

當然，丟失手機時，我們可以更改以上那些賬户的密碼，可是丟失的照片卻是再也找不回來了，這讓人有一點點傷心。

備份資料到電腦當然是一種很好的解決方法，不過要是你的筆記本哪天不小心壞了，你也只能變得一無所有，從頭再來。

在線照片存儲的網站是一個很好的資源，因為他們不止要保證你的照片的安全，你也可以很方便的把照片分享給你選擇的人。省去了那些把同樣的照片做無數次的拷貝分別發給媽媽，奶奶，妹妹，阿姨和岳母等各種親戚朋友的麻煩。

我常用的一個是谷歌的Picasa相冊工具，但是大家也可能聽説過像Flickr這樣的網絡相冊。

Lifehacker給出了最好的5個網絡分享的相冊。

請記住，他們僅僅是被稱作相冊分享工具，並不是説你一定要分享，你也可以自己保留他們。

音樂 ​

我得到的第一個唱片是20世紀80年代初“Adam and the Ants”的"Kings of the wild frontier"裏的一個12英寸的碟子。

在20世紀80年代後的很長一段時間裏，唱片逐漸被磁帶所取代，就好像是我積累了很多的磁帶以後，磁帶卻被CD所取代。

後來，成百上千的CD和MP3越來越普遍，直至成為了一種潮流。

而音頻流媒體始終也跟着潮流一起進步，比如像Spotify。

Spotify是一個免費的軟件，但是裏面包含廣告，對於使用的人們而言，它就像是一個你可以定製的私人電台，當然你也可以交月費來去除廣告。

Grooveshark和last.fm也有提供很多相似的服務。

Techradar給出了7種Spotify的替代方案。

電影 ​

小飛象 (Dumbo) 是我最早在電影院看的一部電影。而我最早接觸錄像是“Krull”，它講述了Dulph Lundgren的年輕時候的經歷，錄像的格式是Beta Max。(當時我的鄰居就有一個) 。

有一天，爸爸從收音機租賃處帶回來一個錄像機，我和我的姐姐就輪流去錄像店租帶子看。我清楚的記得，我第一次租的帶子名字叫“黑洞”(The Black Hole)。

直到有聲電影的出現，你就不得不拿一個很大的東西來裝電影帶子，所以有些天才就發明了DVD，甚至是製造出了藍光碟片。

現在，流媒體已經充斥着我們生活的每一天，要是你有個牛X的網絡就更完美了。

其中，最出名的流媒體提供商是Netflix和Lovefilm (Netflix和Lovefilm都是在線的影片租賃公司)。

linuxnews給了我們一些更好的選擇來替代Netflix，因為並不是所有的服務都能無縫的在linux上工作，包括Netflix。

遊戲 ​

繼音樂，電影搬到線上以後，遊戲也登上了在線的舞台。

對遊戲來説就要困難一些，因為音樂只佔用很少的帶寬，而電影的要求相對高一點，但是也僅僅是為了得到一幅清晰的畫面。

遊戲始終需要很高的幀速支持，不然即使你手上有一個很好玩的遊戲，可能也不值得去嘗試。

當前，很多遊戲服務商都有提供基於雲的遊戲，包括OnLive和StreamMyGame也有提供。

linuxnews給出了6個和OnLive競爭的遊戲服務提供商。

爭議 ​

雲計算也並不是沒有爭議。

首先，最大的問題就是安全問題，如果有人進入了你的在線存儲空間和你的電子郵箱，並盜取了你的個人信息。

那麼在線存儲你都會存些什麼呢？像Megaupload.com這樣的網站，上面都有很多有價值的客户資料。

Megaupload.com這個網站本來提供的大容量文件的存儲，而問題卻是，很多人用它來分享一些有版權的資料，美國的當局就不依不饒的下來檢查，所以這個服務被迫關掉了。

現在，因為很多人丟失了資料，當局的這樣做也是無可厚非的，但是對於那些沒有做錯事的人來説，他們的數據資料也丟失了，美國當局拒絕還給本人。

最後給出了一個服務正在維護的答覆，如果你的電子郵件停了一天你能應付，那麼3天呢？甚至是一個月你還能應付得了嗎，那麼你也就只能任由服務提供商擺佈了。

很多大公司已經取回了丟失的數據，但是仍然有很多心臟病漏洞(openssl的heartbleed安全漏洞)的消息在，這是ssl應用多年中發現的一個重大的安全漏洞。

所以説，如果你用了別人提供的在線服務，那麼你必須信賴他們技術支持人員，你也必須相信他們不會出現被黑客攻擊，硬件故障，缺乏備份和無法恢復系統這樣的情況。

總結 ​

現在雲計算早已成了充斥着在線服務的主題，你的瀏覽器就是一個客户端，連接世界上任意一個地方的服務器或者是服務器集羣。重點是你沒必要去關注，而且你也不需要知道。

一般來説，我們僅僅觸及的是它的表面，所有我們每天接觸到的雲，對於我們大多數人來説甚至都不用去關注它。

至於説雲到底是怎樣影響着每一位linux用户，事實去證明是有很多的。

雲到底是好是壞？又或許什麼都不是。每一種服務的好壞都要看它的優勢。

或許雲僅僅是營銷人員炒起來的一個概念，也只會讓技術新聞感到興奮。是否還有人記得我們一直在用的“Web 2.0”？
