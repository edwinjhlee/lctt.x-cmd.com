也許是有史以來最好的遊戲：NetHack ​

這款遊戲非常容易讓你上癮。你可能需要花費一生的時間來掌握它。許多人玩了幾十年也沒有通關。歡迎來到 NetHack 的世界...

不管你信不信，在 NetHack 裏你見到字母 D 的時候你會被嚇着。但是當你看見一個 % 的時候，你將會欣喜若狂。（忘了説 ^，你看見它將會更激動）在你尋思我們的腦子是不是燒壞了並準備關閉瀏覽器標籤之前，請給我們一點時間解釋：這些符號分別代表龍、食物以及陷阱。歡迎來到 NetHack 的世界，在這裏你的想像力需要發揮巨大的作用。

如你所見，NetHack 是一款文字模式的遊戲：它僅僅使用標準終端字符集來刻畫玩家、敵人、物品還有環境。遊戲的圖形版是存在的，不過 NetHack 的骨灰級玩家們都傾向於不去使用它們，問題在於假如你使用圖形界面，當你通過 SSH 登錄到你的古董級的運行着 NetBSD 的 Amiga 3000 上時，你還能進行遊戲嗎？在某些方面，NetHack 和 Vi 非常相似 - 幾乎被移植到了現存的所有的操作系統上，並且依賴都非常少。

那麼問題來了，和現代遊戲相比如此簡陋的畫面，是什麼造就了 NetHack 如此巨大的吸引力的呢？ 事實上，這款地牢探險類神作有着令人難以置信的豐富細節。有太多的東西等着你去發掘：法術釋放、怪物戰鬥以及技巧學習 - 以及隨機生成的地牢。有太多的東西等着你去探索，幾乎沒有哪兩局遊戲會是完全一樣的。許多人玩了幾十年也沒有通關，每次遊戲依然能發現一些以前不知道的秘密。

接下來，我們會向你講述 NetHack 的歷史，給你地牢探險的基本指導，再告訴你一些技巧。免責： 在你繼續閲讀本文之前，視為你已經自動同意了當你沉溺於 NetHack 以致影響到你的現實生活時，你不會起訴我們。

NetHack 界面

也許是最古老的仍在開發的遊戲裏 ​

名非其實，NetHack 並不是一款網絡遊戲。它只不過是基於一款出現較早的名為 Hack 的地牢探險類遊戲開發出來的，而這款 Hack 遊戲是 1980 年的遊戲 Rogue 的後代。NetHack 在 1987 年發佈了第一個版本，並於 2003 年發佈了 3.4.3 版本，儘管在這期間一直沒有加入新的功能，但各種補丁、插件，以及衍生作品還是在網絡上瘋狂流傳。這使得它可以説是最古老的、擁有眾多對遊戲樂此不疲的粉絲的遊戲。當你訪問 www.reddit.com/r/nethack 之後，你就會了解我們的意思了 - 骨灰級的 NetHack 的玩家們仍然聚集在一起討論新的策略、發現和技巧。偶爾你也可以發現 NetHack 的元老級玩家在歷經千辛萬苦終於通關之後發出的歡呼。

但怎樣才能通關呢？首先，NetHack 被設定在既大又深的地牢中。遊戲開始時你在最頂層 - 第 1 層 - 你的目標是不斷往下深入直到你找到一個非常寶貴的物品，護身符 Yendor。通常來説 Yendor 在 第 20 層或者更深的地方，但它是可以變化的。隨着你在地牢的不斷深入，你會遇到各種各樣的怪物、陷阱以及 NPC；有些會試圖殺掉你，有些會擋在你前進的路上，還有些... 總而言之，在你靠近 TA 們之前你永遠不知道 TA 們會怎樣。

要學習的有太多太多，絕大多數物品只有在和其他物品同時使用的情況下才會發揮最好的效果。

使 NetHack 如此引人入勝的原因是遊戲中所加入的大量物品。武器、盔甲、附魔書、戒指、寶石 - 要學習的有太多太多，絕大多數物品只有在和其他物品同時使用的情況下才會發揮最好的效果。怪物在死亡後經常會掉落一些有用的物品，以及某些物品如果你不正確使用的話會產生及其不良的作用。你可以在地牢找到商店，裏面有許多看似平凡實則非常有用的物品，不過別指望店主能給你詳細的描述。你只能靠自己的經驗來了解各個物品的用途。有些物品確實沒有太大用處，NetHack 中有很多的惡搞元素 - 比如你可以把一塊奶油砸到自己的臉上。

不過在你踏入地牢之前，NetHack 會詢問你要選擇哪種角色進行遊戲。你可以為你接下來的地牢之行選擇騎士、修道士、巫師，或者卑微的旅者，還有許多其他的角色類型。每種角色都有其獨特的優勢與弱點，NetHack 的重度玩家喜歡選擇那些相對較弱的角色來挑戰遊戲。你懂的，這樣可以向其他玩家炫耀自己的實力。

情報不會降低遊戲的樂趣

用 NetHack 的説法來講，“情報員”給指其他玩家提供關於怪物、物品、武器和盔甲信息的玩家。理論上來説，完全可以不借助任何外來信息而通關，但幾乎沒有幾個玩家能做到，遊戲實在是太難了。因此使用情報並不會被視為一件糟糕的事情 - 但是一開始由你自己來探索遊戲和解決難題，這樣才會獲得更多的樂趣，只有當你遇到瓶頸的時候再去使用那些情報。

在這裏給出一個比較有名的情報站點 www.statslab.cam.ac.uk/~eva/nethack/spoilerlist.html，其中的情報被分為了不同的類別。遊戲中隨機發生的事，比如在噴泉旁飲水可能導致的不同結果，從這裏你可以得知已確定的不同結果的發生概率。

你的首次地牢之行 ​

NetHack 幾乎可以在所有的主流操作系統以及 Linux 發行版上運行，因此你可以通過 "apt-get install nethack" 或者 "yum install nethack" 等適合你用的發行版的命令來安裝遊戲。安裝完畢後，在一個命令列窗口中鍵入 "nethack" 就可以開始遊戲了。遊戲開始時系統會詢問是否為你隨機挑選一位角色 - 但作為一個新手，你最好自己從裏面挑選一位比較強的角色。所以，你應該點 "n"，然後點 "v" 以選取女武神（Valkyrie），而點 "d" 會選擇成為侏儒（dwarf）。

接着 NetHack 上會顯示出劇情，説你的神正在尋找護身符 Yendor，你的目標就是找到它並將它帶給神。閲讀完畢後點擊空格鍵（其他任何時候當你見到屏幕上的 "-More-" 時都可以這樣）。接着就讓我們出發 - 開始地牢之行吧！

先前已經介紹過了，你的角色用 @ 來表示。你可以看見角色所出房間周圍的牆壁，房間裏顯示“點”的那些地方是你可以移動的空間。首先，你得明白怎樣移動角色：h、j、k 以及 l。（是的，和 Vim 中移動光標的操作相同）這些操作分別會使角色向向左、向下、向上以及向右移動。你也可以通過 y、u、b 和 n 來使角色斜向移動。在你熟悉如何控制角色移動前你最好在房間裏來回移動你的角色。

NetHack 採用了回合制，因此即使你不進行任何動作，遊戲仍然在進行。這是你可以提前計劃你的行動。你可以看見一個 "d" 字符或者 "f" 字符在房間裏來回移動：這是你的寵物狗/貓，（通常情況下）它們不會傷害你而是幫助你擊殺怪物。但是寵物也會被惹怒 - 它們偶爾也會搶在你接近食物或者怪物屍體之前吃掉它們。

點擊 “i” 列出你當前攜帶的物品清單

門後有什麼？ ​

接下來，讓我們離開房間。房間四周的牆壁某處會有縫隙，可能是 "+" 號。"+" 號表示一扇關閉的門，這時你應該靠近它然後點擊 "o" 來開門。接着系統會詢問你開門的方向，假如門在你的左方，就點擊 "h"。（如果門被卡住了，就多試幾次）然後你就可以看見門後的走廊了，它們由 "#" 號表示，沿着走廊前進直到你找到另一個房間。

地牢之行中你會見到各種各樣的物品。某些物品，比如金幣（由 "$" 號表示）會被自動撿起來；至於另一些物品，你只能站在上面按下逗號鍵手動拾起。如果同一位置有多個物品，系統會給你顯示一個列表，你只要通過合適的按鍵選擇列表中你想要的物品最後按下 "Enter" 鍵即可。任何時間你都可以點擊 "i" 鍵在屏幕上列出你當前攜帶的物品清單。

如果看見了怪物該怎麼辦？在遊戲早期，你可能會遇到的怪物會用符號 "d"、"x" 和 ":" 表示。想要攻擊的話，只要簡單地朝怪物的方向移動即可。系統會在屏幕頂部通過信息顯示來告訴你攻擊是否成功 - 以及怪物做出了何種反應。早期的怪物很容易擊殺，所以你可以毫不費力地打敗他們，但請留意底部狀態欄裏顯示的角色的 HP 值。

早期的怪物很容易擊殺，但請留意角色的 HP 值。

如果怪物死後掉落了一具屍體（"%"），你可以點擊逗號進行拾取，並點擊 "e" 來食用。（在任何時候系統提示你選擇一件物品，你都可以從物品列表中點擊相應的按鍵，或者點擊 "?" 來查詢迷你菜單。）注意！有些屍體是有毒的，這些知識你將在日後的冒險中逐漸學會掌握。

如果你在走廊裏行進時遇到了死衚衕，你可以點擊 "s" 進行搜尋直到找到一扇門。這會花費時間，但是你可以這樣加速遊戲進程：輸入 "10" 並點擊 "s" 你將一下搜索 10 次。這將花費遊戲中進行 10 次動作的時間，不過如果你正在飢餓狀態，你將有可能會被餓死！

通常你可以在地牢頂部找到 "{"（噴泉）以及 "!"（藥水）。當你找到噴泉的時候，你可以站在上面並點擊 "q" 鍵開始 “暢飲（quaff）” - 引用後會得到從振奮的到致命的多種效果。當你找到藥水的時候，將其拾起並點擊 "q" 來飲用。如果你找到一個商店，你可以拾取其中的物品並在離開前點擊 "p" 鍵進行支付。當你負重過大時，你可以點擊 "d" 鍵丟掉一些東西。

現在已經有帶音效的 3D 版 Nethack 了，如：Falcon’s Eye

愚蠢的死法

在 NetHack 玩家中流行着一個縮寫詞 "YASD" - 又一種愚蠢的死法（Yet Another Stupid Death）。這個縮寫詞表示了玩家由於自身的的愚蠢或者粗心大意導致了角色的死亡。我們蒐集了很多這類死法，但我們最喜歡的是下面這種死法：

我們正在商店瀏覽商品，這時一條蛇突然從藥劑後面跳了出來。在殺死蛇之後，系統彈出一條信息提醒我們角色飢餓值過低了，因此我們順手食用了蛇的屍體。壞事了！這使得我們的角色失明，導致我們的角色再也不能看見商店裏的其他角色及地上的商品了。我們試圖離開商店，但在慌亂中卻撞在了店主身上並攻擊了他。這種做法激怒了店主：他立即向我們的角色使用了火球術。我們試圖逃到商店外的走廊上，但卻在逃亡的過程中被燒死。

如果你有類似的死法，一定要來我們的論壇告訴我們。不要擔心 - 沒有人會嘲笑你。經歷這樣的死法也是你在 NetHack 的世界裏不斷成長的一部分。哈哈。

武裝自己 ​

地牢裏，尤其是在你擊殺怪物後，你可能會發現武器或盔甲。在這裏再説一次，點擊逗號把它們拾起，接着點擊 "w"（小寫的）來使用武器或者點擊 "W"（大寫的）來穿上盔甲。你可以用 "T" 來脱掉盔甲或者 "t" 來取下武器 - 如果你陷入了困境，請確保你總是在使用最好的裝備。

在靠近掉在地下的裝備之前最好檢查一下身上的東西。點擊 ";"（分號）後，"Pick an object"（選擇一樣物品）選項將出現在屏幕頂部。選擇該選項，使用移動鍵直到選中你想要檢查的物品，然後點擊 ":"（冒號）。接着屏幕頂部將出現這件物品的描述。

因為你的目標是不斷深入地牢直到找到護身符 Yendor，所以請隨時留意周圍的 "<" 和 ">" 符號。這兩個符號分別表示向上和向下的樓梯，你可以用與之對應的按鍵來上樓或下樓。注意！如果你想讓寵物跟隨你進入下/上一層地牢，下/上樓前請確保你的寵物在你鄰近的方格內。若果你想退出，點擊 "S"（大寫的）來保存進度，輸入 #quit 退出遊戲。當你再次運行 NetHack 時，系統將會自動讀取你上次退出時的遊戲進度。

我們就不繼續劇透了，地牢深處還有更多的神秘細節、陌生的 NPC 以及不為人知的秘密等着你去發掘。那麼，我們再給你點建議：當你遇到了讓你困惑不已的物品時，你可以嘗試去 NetHack 維基 http://nethack.wikia.com 進行搜索。你也可以在 www.nethack.org/v343/Guidebook.html 找到一本非常不錯（儘管很長）的指導手冊。最後，祝遊戲愉快！
