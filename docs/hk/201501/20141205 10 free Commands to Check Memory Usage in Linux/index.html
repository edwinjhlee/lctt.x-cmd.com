檢測 Linux 內存使用情況的 free 命令的10個例子 ​

Linux是最有名的開源操作系統之一，它擁有着極其巨大的命令集。確定物理內存和交換內存所有可用空間的最重要、也是唯一的方法是使用“free”命令。

Linux “free”命令可以給出類Linux/Unix操作系統中物理內存和交換內存的總使用量、可用量及內核使用的緩衝區情況。

這篇文章提供一些各種參數選項的“free”命令，這些命令對於你更好地利用你的內存會有幫助。

1. 顯示你的系統內存 ​

free命令用於檢測物理內存和交換內存已使用量和可用量（默認單位為KB）。下面演示命令的使用情況。

# free

             total       used       free     shared    buffers     cached
Mem:       1021628     912548     109080          0     120368     655548
-/+ buffers/cache:     136632     884996
Swap:      4194296          0    4194296

2. 以字節為單位顯示內存 ​

加上-b參數的free命令，以字節為單位顯示內存的大小。

# free -b

             total       used       free     shared    buffers     cached
Mem:    1046147072  934420480  111726592          0  123256832  671281152
-/+ buffers/cache:  139882496  906264576
Swap:   4294959104          0 4294959104

3. 以千字節為單位顯示內存 ​

加上-k參數的free命令（默認單位，所以可以不用使用它），以(KB)千字節為單位顯示內存大小。

# free -k

             total       used       free     shared    buffers     cached
Mem:       1021628     912520     109108          0     120368     655548
-/+ buffers/cache:     136604     885024
Swap:      4194296          0    4194296

4. 以兆字節為單位顯示內存 ​

想以(兆字節)顯示內存大小，使用-m參數。

# free -m

             total       used       free     shared    buffers     cached
Mem:           997        891        106          0        117        640
-/+ buffers/cache:        133        864
Swap:         4095          0       4095

5. 以千兆字節為單位顯示內存 ​

使用-g為參數，將會以GB(千兆字節)為單位顯示內存大小。

# free -g
             total       used       free     shared    buffers     cached
Mem:             0          0          0          0          0          0
-/+ buffers/cache:          0          0
Swap:            3          0          3

6. 顯示總計行 ​

加上-t選項，將會在屏幕最後列出總計一行。

# free -t

             total       used       free     shared    buffers     cached
Mem:       1021628     912520     109108          0     120368     655548
-/+ buffers/cache:     136604     885024
Swap:      4194296          0    4194296
Total: 5215924 912520 4303404

7. 關閉顯示緩衝區調整一行 ​

默認情況下，free命令是顯示“緩衝區調整”一行的，為了關閉顯示，可以加上-o參數。

# free -o                                                              

             total       used       free     shared    buffers     cached                                                                          
Mem:       1021628     912520     109108          0     120368     655548                                                                         
Swap:      4194296          0    4194296

8. 定期時間間隔更新內存狀態 ​

-s選項加上一個整數，用來在定期時間間隔內更新free命令。舉個例子，下面的命令將會在每5秒更新一個free命令。

# free -s 5

             total       used       free     shared    buffers     cached
Mem:       1021628     912368     109260          0     120368     655548
-/+ buffers/cache:     136452     885176
Swap:      4194296          0    4194296

9. 顯示底和高內存統計信息 ​

-l選項顯示了具體的高和低內存的使用統計情況。

# free -l

             total       used       free     shared    buffers     cached
Mem:       1021628     912368     109260          0     120368     655548
Low:        890036     789064     100972
High:       131592     123304       8288
-/+ buffers/cache:     136452     885176
Swap:      4194296          0    4194296

10. 檢查free命令版本 ​

-V選項，顯示free命令版本信息。

# free -V

procps version 3.2.8
