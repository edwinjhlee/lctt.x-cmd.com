怎樣在 Ubuntu 14.10 Server 上安裝 Cacti ​

Cacti 是一個完善的網絡監控的圖形化解決方案，它被設計用來發揮 RRDTool （一個 Linux 數據存儲和繪圖工具）的數據存儲和繪圖的強大功能。Cacti 提供一個快速的輪詢器，高級的繪圖模版，多種數據獲取方法和用户管理功能，並且可以開箱即用。所有的這些都被打包進一個直觀，易用的界面，可用於監控簡單的 LAN 網絡，乃至包含成百上千設備的複雜網絡。

功能 ​

繪圖 ​

沒有數量限制的監控圖條目（graph item），每個圖形可以視情況使用 Cacti 中的 CDEFs （Calculation Define，可以對圖形輸出結果進行計算）或者數據源。

自動將 GPRINT 條目分組至 AREA，STACK 和 LINE[1-3] 中，來對監控圖條目進行快速重排序。

自動填充功能支持整齊排列圖形內的説明項。

可以使用 RRDTool 中內置的 CDEF 數學函數對圖形數據進行處理。這些 CDEF 函數可以定義在 Cacti 中，並且每一個圖形都可以使用它們。

支持所有的 RRDTool 圖形類型，包括 AREA，STACK，LINE[1-3]，GPRINT，COMMENT，VRULE 和 HRULE。

數據源 ​

數據源可以使用 RRDTool 的 "create" 和 "update" 功能創建。每一個數據源可以用來收集本地或者遠程的數據，並將數據輸出成圖形。

支持包含多個數據源的 RRD 文件，並可以使用存儲在本地文件系統中任何位置的 RRD 文件。

可以自定義輪詢歸檔（RRA）設置，用户可以在存儲數據時使用非標準的時間間隔（標準時間間隔是5分鐘，30分鐘，2小時和 1天）。

數據收集 ​

Cacti 包含一個 "data input" 機制，可以讓用户定義自定義的腳本用來收集數據。每個腳本可以包含調用參數，每次調用此腳本的創建數據源時必須輸入相應的調用參數（如 IP 地址）。

支持 SNMP 功能，可以使用 php-snmp，ucd-snmp 或者 net-snmp。

可以基於索引來使用 SNMP 或者腳本收集數據。例如，可以列出一個服務器上所有網卡接口或者已掛載分區的索引列表。其集成的繪圖模版可以用來為主機一鍵創建圖形。

提供了一個基於 PHP 的輪詢器執行腳本，可以收集 SNMP數據並更新數據至 RRD 文件中。

模版 ​

繪圖模版可以將相同圖形分組到為一類。圖形中的每一個條目都可以使用模版的默認值或者自定義。

數據源模版可以通過將相同數據源類型分組為一類。數據源中每一個條目都可以使用模版的默認值或者自定義。

主機模版是一組圖形和數據源模版，可以用來定義某一類型的主機。創建主機時，它會自動使用相應模版的屬性。

圖形展示 ​

圖形樹模式允許用户創建「圖形層次結構」並將圖形放至樹中。這種方法可以方便的管理大量圖形。

列表模式將所有圖形的鏈接在一個大列表中展示出來，鏈接指向用户創建的圖形。

預覽模式將所有圖形在一個大列表中展示出來。這有點類似於 RRDTool/MRTG 的默認視圖。

用户管理 ​

用户管理功能允許管理員創建用户並分配給用户訪問 Cacti 接口的不同級別的權限。

權限可以為每個用户指定其對每個圖形的權限，這適用於主機租用的場景。

每個用户可以保存他自己的圖形顯示模式。

安裝 ​

系統準備 ​

在安裝 cacti 之前，確保你已經安裝了 Ubuntu 14.10 LAMP server。

在 Ubuntu 14.10 Server 上安裝 Cacti ​

打開終端，運行下面的命令

sudo apt-get install cacti-spine

上面的命令開始 Cacti 的安裝，你會看到下圖中 PHP 路徑的更改，選擇 ok 按回車

選擇你想使用的 Web 服務器 (我使用的是 apache2)

Cacti 資料庫配置，選 yes

輸入資料庫管理員賬户密碼

輸入 Cacti 訪問資料庫的密碼

確認密碼

現在 Cacti 已經安裝了，我們可以開始配置它了。

Cacti 配置 ​

在瀏覽器中訪問 http://你的服務器IP/cacti/install/ 來進行初始化設置，點擊 next 下一步

選擇 New install，點擊 next 下一步

下一個界面中，你需要確保所有的路徑都是正確的，點擊 finish 完成

現在以 admin/admin 登錄 Cacti，修改管理員的默認密碼
