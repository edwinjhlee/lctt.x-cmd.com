如何在Ubuntu上轉換圖像、音頻和視頻格式 ​

如果你的工作中需要接觸到各種不同編碼格式的圖像、音頻和視頻，那麼你很有可能正在使用多個工具來轉換這些多種多樣的媒體格式。如果存在一個能夠處理所有圖像/音頻/視頻格式的多合一轉換工具，那就太好了。

Format Junkie 就是這樣一個多合一的媒體轉換工具，它有着極其友好的用户界面。更棒的是它是一個免費軟件。你可以使用 Format Junkie 來轉換幾乎所有的流行格式的圖像、音頻、視頻和歸檔文件（或稱壓縮文件），所有這些只需要簡單地點擊幾下鼠標而已。

在Ubuntu 12.04, 12.10 和 13.04 上安裝 Format Junkie ​

Format Junkie 可以通過 Ubuntu PPA format-junkie-team 進行安裝。這個PPA支持Ubuntu 12.04, 12.10 和 13.04。在以上任意一種Ubuntu版本中安裝Format Junkie的話，簡單的執行以下命令即可：

$ sudo add-apt-repository ppa:format-junkie-team/release
$ sudo apt-get update
$ sudo apt-get install formatjunkie
$ sudo ln -s /opt/extras.ubuntu.com/formatjunkie/formatjunkie /usr/bin/formatjunkie

將 Format Junkie 安裝到 Ubuntu 13.10 ​

如果你正在運行Ubuntu 13.10 (Saucy Salamander)，你可以按照以下步驟下載 .deb 安裝包來進行安裝。由於Format Junkie 的 .deb 安裝包只有很少的依賴包，所以使用 gdebi deb installer 來安裝它。

在32位版Ubuntu 13.10上：

$ wget https://launchpad.net/~format-junkie-team/+archive/release/+files/formatjunkie_1.07-1~raring0.2_i386.deb
$ sudo gdebi formatjunkie_1.07-1~raring0.2_i386.deb
$ sudo ln -s /opt/extras.ubuntu.com/formatjunkie/formatjunkie /usr/bin/formatjunkie

在32位版Ubuntu 13.10上：

$ wget https://launchpad.net/~format-junkie-team/+archive/release/+files/formatjunkie_1.07-1~raring0.2_amd64.deb
$ sudo gdebi formatjunkie_1.07-1~raring0.2_amd64.deb
$ sudo ln -s /opt/extras.ubuntu.com/formatjunkie/formatjunkie /usr/bin/formatjunkie

將 Format Junkie 安裝到 Ubuntu 14.04 或之後版本 ​

現有可供使用的官方 Format Junkie .deb 文件需要 libavcodec-extra-53，不過它從Ubuntu 14.04開始就已經過時了。所以如果你想在Ubuntu 14.04或之後版本上安裝Format Junkie，可以使用以下的第三方PPA來代替。

$ sudo add-apt-repository ppa:jon-severinsson/ffmpeg
$ sudo add-apt-repository ppa:noobslab/apps
$ sudo apt-get update
$ sudo apt-get install formatjunkie

如何使用 Format Junkie ​

安裝完成後，只需運行以下命令即可啓動 Format Junkie：

$ formatjunkie

使用 Format Junkie 來轉換音頻、視頻、圖像和歸檔格式 ​

就像下方展示的一樣，Format Junkie 的用户界面簡單而且直觀。在頂部的音頻、視頻、圖像和iso媒體四個標籤當中點擊你需要的那個。你可以根據需要添加任意數量的文件用於批量轉換。添加文件後，選擇輸出格式，直接點擊 "Start Converting" 按鈕進行轉換。

Format Junkie支持以下媒體格式間的轉換：

  • Audio: mp3, wav, ogg, wma, flac, m4r, aac, m4a, mp2.
  • Video: avi, ogv, vob, mp4, 3gp, wmv, mkv, mpg, mov, flv, webm.
  • Image: jpg, png, ico, bmp, svg, tif, pcx, pdf, tga, pnm.
  • Archive: iso, cso.

用 Format Junkie 進行字幕編碼 ​

除了媒體轉換，Format Junkie 可提供了字幕編碼的圖形界面。實際的字幕編碼是由MEncoder來完成的。為了使用Format Junkie的字幕編碼接口，首先你需要安裝MEencoder。

$ sudo apt-get install mencoder
