ChromeOS 對戰 Linux : 孰優孰劣，仁者見仁，智者見智 ​

在 ChromeOS 和 Linux 的鬥爭過程中，兩個桌面環境都有強有弱，這兩者到底怎樣呢？

只要稍加留意，任何人都會相信，Google 在桌面領域絕不是“玩玩而已”。在近幾年，我們見到的 ChromeOS 製造的 Google Chromebook 相當的轟動。和同期人氣火爆的 Amazon 一樣，ChromeOS 似乎勢不可擋。

在本文中，我們要了解的是 ChromeOS 的概念市場，ChromeOS 怎麼影響着Linux 的份額，整個 ChromeOS 對於Linux 社區來説，是好事還是壞事。另外，我將會談到一些重大問題，以及為什麼沒人針對這些問題做點什麼。

ChromeOS 並非真正的Linux ​

每當有朋友問我説 ChromeOS 是否是 Linux 的一個發行版時，我都會這樣回答：ChromeOS 之於 Linux 就如同 OS X 之於 BSD。換句話説，我認為，ChromeOS 是 Linux 的一個派生操作系統，運行於 Linux 內核的引擎之下。而這個操作系統的大部分由 Google 的專利代碼及軟件組成。

儘管 ChromeOS 是利用了 Linux 的內核引擎，但是和現在流行的 Linux 分支版本相比，它仍然有很大的不同。

其實，ChromeOS 的差異化越來越明顯的原因，是在於它給終端用户提供的包括 Web 應用在內的 app。因為ChromeOS 的每一個操作都是開始於瀏覽器窗口，這對於 Linux 用户來説，可能會有很多不一樣的感受，但是，對於沒有 Linux 經驗的用户來説，這與他們使用的舊電腦並沒有什麼不同。

比方説，每一個以“依賴 Google 產品”為生活方式的人來説，在 ChromeOS 上的感覺將會非常良好，就好像是回家一樣，特別是這個人已經接受了 Chrome 瀏覽器、Google Drive 雲存儲和Gmail 的話。久而久之，他們使用ChromeOS 也就是很自然的事情了，因為他們很容易接受使用早已習慣的 Chrome 瀏覽器。

然而，對於 Linux 愛好者來説，這樣的約束就立即帶來了不適應。因為軟件的選擇是被限制、被禁錮的，再加上要想玩遊戲和 VoIP 是完全不可能的。對不起，因為 GooglePlus Hangouts 是代替不了VoIP 軟件的。甚至這種情況將持續很長一段時間。

ChromeOS 還是 Linux 桌面 ​

有人斷言，ChromeOS 要是想在桌面系統的浪潮中對 Linux 產生影響，只有在 Linux 停下來浮出水面喘氣的時候，或者是滿足某個非技術用户的時候。

是的，桌面 Linux 對於大多數休閒型的用户來説絕對是一個好東西。然而，它必須有專人幫助你安裝操作系統，並且提供“維修”服務，就如同我們在 Windows 和 OS X 陣營看到的一樣。但是，令人失望的是，在美國， Linux 恰恰在這個方面很缺乏。所以，我們看到，ChromeOS 正慢慢的走入我們的視線。

我發現 Linux 桌面系統最適合那些能夠提供在線技術支持的環境中。比如説：可以在家裏操作和處理更新的高級用户、政府和學校的 IT 部門等等。這些環境中，Linux 桌面系統可以被配置給任何技能水平和背景的人使用。

相比之下，ChromeOS 是建立在完全免維護的初衷之下的，因此，不需要第三者的幫忙，你只需要允許更新，然後讓他靜默完成即可。這在一定程度上可能是由於 ChromeOS 是為某些特定的硬件結構設計的，這與蘋果開發自己的PC 電腦也有異曲同工之妙。因為 Google 的 ChromeOS 伴隨着其硬件一起提供，大部分情況下都無需擔心錯誤的驅動、適配什麼的問題。對於某些人來説，這太好了。

然而有些人則認為這是一個很嚴重的問題，不過滑稽的是，對 ChomeOS 來説，這些人壓根就不在它的目標市場裏。簡言之，這只是一些狂熱的 Linux 愛好者在對 ChomeOS 雞蛋裏挑骨頭罷了。要我説，還是停止這些沒必要的批評吧。

問題的關鍵在於：ChromeOS 的市場份額和 Linux 桌面系統在很長的一段時間內是不同的。這個局面可能會在將來被打破，然而在現在，仍然會是兩軍對峙的局面。

ChromeOS 的使用率正在增長 ​

不管你對ChromeOS 有怎麼樣的看法，事實是，ChromeOS 的使用率正在增長。專門針對 ChromeOS 的電腦也一直有發佈。最近，戴爾（Dell）也發佈了一款針對 ChromeOS 的電腦。命名為 Dell Chromebox，這款 ChromeOS 設備將會是對傳統設備的又一次衝擊。它沒有軟件光驅，沒有反病毒軟件，能夠提供無縫的幕後自動更新。對於一般的用户，Chromebox 和 Chromebook 正逐漸成為那些工作在 Web 瀏覽器上的人們的一個可靠選擇。

儘管增長速度很快，ChromeOS 設備仍然面臨着一個很嚴峻的問題 - 存儲。受限於有限的硬盤大小和嚴重依賴於雲存儲，ChromeOS 對於那些需要使用基本的瀏覽器功能之外的人們來説還不夠用。

ChromeOS 和 Linux 的異同點 ​

以前，我注意到 ChromeOS 和 Linux 桌面系統分別佔有着兩個完全不同的市場。出現這樣的情況是源於 Linux 社區在線下的桌面支持上一直都有着極其糟糕的表現。

是的，偶然的，有些人可能會第一時間發現這個“Linux特點”。但是，並沒有一個人接着跟進這些問題，確保得到問題的答案，以讓他們得到 Linux 方面更多的幫助。

事實上，線下問題的出現可能是這樣的：

  • 有些用户偶然的在當地的 Linux 活動中發現了 Linux。
  • 他們帶回了 DVD/USB 設備，並嘗試安裝這個操作系統。
  • 當然，有些人很幸運的成功完成了安裝過程，但是，據我所知大多數的人並沒有那麼幸運。
  • 令人失望的是，這些人只能寄希望於在網上論壇裏搜索幫助。他們很難通過主流的計算機網絡經驗或視頻教程解決這些問題。 -於是這些人受夠了。後來有很多失望的用户拿着他們的電腦到 Windows 商店來“維修”。除了重裝一個 Windows 操作系統，他們很多時候都會聽到一句話，“Linux 並不適合你們”，應該儘量避免。

有些人肯定會説，上面的舉例肯定誇大其詞了。讓我來告訴你：這是發生在我身邊的真事，而且是經常發生。醒醒吧，Linux 社區的人們，我們的推廣模式早已過期無力了。

偉大的平台，糟糕的營銷和最終結論 ​

如果非要找一個 ChromeOS 和 Linux 桌面系統的共同點，除了它們都使用了 Linux 內核，那就是它們都是偉大的產品卻擁有極其差勁的市場營銷。對此，Google 認為自己的優勢是，它能投入大量的資金在網上構建大面積存儲空間。

Google 相信他們擁有“網上的優勢”，而線下的問題不是很重要。這真是一個讓人難以置信的目光短淺，這也成了Google 最嚴重的失誤之一。而當地的 Linux 零售商則堅信，對於不怎麼上網的人，自然不必擔心他們會受到 Google巨大的在線存儲的誘惑。

我的建議是：Linux 可以通過線下的努力，提供桌面系統，滲透 ChromeOS 市場。這就意味着 Linux 社區需要在節假日籌集資金來出席博覽會、商場展覽，並且在社區中進行免費的教學課程。這會立即使 Linux 桌面系統走入人們的視線，否則，最終將會是一個 ChromeOS 設備出現在人們的面前。

如果説本地的線下市場並沒有像我説的這樣，別擔心。Linux 桌面系統的市場仍然會像 ChromeOS 一樣增長。最壞也能保持現在這種兩軍對峙的市場局面。
