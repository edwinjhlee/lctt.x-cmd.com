Linux 下五款出色的流媒體客户端 ​

數字流媒體這幾天幾乎佔據了我音樂收聽的全部時間。近年來我為了收藏 CD 花費了數量可觀的費用；但它們中的大部分現在正靜靜地躺在滿是灰塵的角落裏。基本上所有的音樂流媒體服務所提供的的音質都不如 CD 的，但它們受歡迎的原因很大程度上在於其便捷性，而非高度保真的音質再現。音樂流媒體不僅造成了 CD 銷量的大幅減少；也使數字音樂的下載開始緩慢下滑。這種趨勢還會繼續下去。音樂發燒友現在或許也想要擁抱音樂流媒體服務了，某些音樂流媒體服務商如 Tidal 提供了無損的音樂流媒體服務，其中包含了 25 萬首比特率為 1411kbps 的 FLAC 格式的音樂。

儘管 CD 暫時不會消失，但音樂流媒體服務商卻無法調和那些不滿從音樂託管服務中收取的租金的唱片公司及音樂家之間的問題。這一切仍然處於變化之中；我們看到了今年 Led Zeppelin, Pink Floyd, Metallica 簽名支持流媒體服務，但仍然有部分知名的老牌樂隊如 Beatles, Radiohead 以及 AC/DC 拒絕將自己的作品放到流媒體上供粉絲收聽。即使當某個唱片公司或者音樂家已經授權給流媒體服務商訪問自己的作品，但只要音樂家發表聲明就可以在第一時間將其作品從流媒體服務下架。本月（2014 年 11 月），Taylor Swift 請求將她的所有音樂作品從 Spotify 的流媒體服務下架。有些人還是更偏向於“擁有”他們的音樂，但這看起來像是一種快要過時了的欣賞音樂的方式。

使用 Linux 平台來收聽流媒體音樂服務的方法已經逐漸成熟。在 Linux 平台下，你可以找到許多客户端，通過它們你可以使用大部分的音樂流媒體服務；我希望 TIDAL 能在今後合適的時候發行 Linux 桌面客户端，而不是僅僅依賴 web 播放器。本文精選的這些應用都是非常出色的。另外 Amarok，pianobar 還有 Tomahawk 也表現得很不錯。

Spotify ​

Spotify 是一種專有的 P2P 音樂流媒體服務，允許用户收聽點播曲目或專輯。Spotify 將自己描述為“音樂聖殿。快捷、簡易、免費的服務”。Spotify 分別為普通的移動端和桌面端用户提供了 96kbps 和 160kbps 比特率的流媒體服務，並且為高級用户提供了 Ogg Vorbis 格式的 320kbps 比特率的流媒體服務。Spotify 為普通用户提供了免費但是有廣告的服務，以及無廣告的訂閲賬户服務。

Spotify 是很奇妙的服務，向用户們提供了涵蓋各種類型的數量眾多的音樂，如：流行樂、另類搖滾、古典樂、鐵克諾電音、搖滾樂等。這是發現新音樂的好方法。Spotify 得到了包括 Sony BMG，EMI，Universal 以及 Warner Music 在內的主流唱片公司，以及 Labrador Records，The Orchard，Alligator Records，Merlin，CD Baby，INgrooves 等獨立唱片唱片公司和分銷網絡，甚至 Chandos，Naxos，EMI Classic，Warner Classics，Denon Essentials 這些古典唱片公司的支持，還有更多的公司在這裏就不一一列舉了。

Spotify 的音樂涵蓋範圍還在繼續以驚人的步伐擴張着。

Spotify 現在並沒有發行官方版的 Linux 客户端。不過，開發團隊已經推出了針對 Linux 的客户端預覽版，並且表現得還不錯。因為仍然是預覽版，所以沒有得到官方的支持。

Spotify 流媒體服務現已支持以下地區/國家：安道爾，阿根廷，澳大利亞，奧地利，比利時，保加利亞，哥倫比亞，塞浦路斯，丹麥，愛沙尼亞，芬蘭，法國，德國，希臘，香港，冰島，愛爾蘭，意大利，拉脱維亞，列支敦士登，立陶宛，盧森堡，馬來西亞，馬耳他，墨西哥，摩納哥，荷蘭，新西蘭，挪威，菲律賓，波蘭，葡萄牙，西班牙，新加坡，瑞典，瑞士，台灣，土耳其，英國，美國，烏拉圭等。

特色包括：

  • 精心設計的界面，導航時非常方便

  • 創建和編輯播放列表

  • 發現新的音樂

  • 共享音樂及播放列表

  • 電台功能

  • 最受歡迎的的列表

  • 額外功能及種類繁多的應用

  • 網址：www.spotify.com/uk/download/previews

  • 開發者：Spotify

  • 許可證：專有許可證

  • 當前版本：預覽版

Pithos ​

Pithons 是一款開源的的本地 Pandora 電台 Linux 客户端。它提供了一個輕量級的界面以替代 Pandora.com 的 web 客户端。其圖形用户界面上集成了多媒體快捷鍵、通知中心以及聲音菜單。

Pandora 音樂服務只能通過美國的 IP 地址使用。不過，非美國用户可以通過 VPN 連接來使用 Pandora。

特色包括：

  • 播放/暫停/下一首

  • 切換電台

  • 記住用户名和密碼

  • 給喜歡的音樂和藝術家添加書籤

  • 獲取封面

  • 喜歡/討厭/不再播放這首音樂

  • 在通知中心中彈出歌曲信息

  • 跳轉到 pandora.com 歌曲信息頁面/電台頁面

  • 超時後重連 pandora

  • QuickMix 編輯

  • 創建電台

  • 多媒體按鍵

  • 代理連接

  • Last.fm 歌曲記錄

  • 音量控制

  • 屏保暫停等插件

  • DBUS 接口：MPRIS 和 Pithos

  • 網址：pithos.github.io

  • 開發者：Kevin Mehall

  • 許可證：GNU GPL v3

  • 當前版本：1.0.0

Clementine ​

Clementine 基於 Amarok 開發，是一款跨平台的輕量級現代化音樂播放器和媒體庫管理工具。Clementine 致力於打造快捷簡易的界面，使你可以輕鬆搜索和播放音樂。

Clementine 在 Amarok 1.4 的基礎上開發。

特色包括：

  • 檢索、播放本地音樂庫

  • 從 Last.fm 和 SomaFM 收聽互聯網電台

  • 標籤式播放列表，支持導入導出 M3U，XSPF，PLS 及 ASX 格式的播放列表

  • 創建智能播放列表和動態播放列表

  • 載入 M3U 和 XSPF 播放列表

  • 對播放列表的撤銷和重做

  • 編輯 MP3 和 OGG 文件的信息，管理媒體庫

  • 從 Last.fm 下載缺失的專輯封面

  • 集成 gpodder.net 播客

  • 圖形化均衡器

  • 支持 Windows，Mac OS X 及 Linux

  • 支持 Linux（libnotify）及 Mac OS X（Growl）本地桌面通知中心

  • 從 MusicBrainz 獲取缺失的信息

  • 炫彩屏幕顯示

  • 隊列管理

  • 支持 Linux 下的 MPRIS，以及命令列遠程控制

  • 支持索引和播放 Google Drive 中的音樂

  • 支持 Soundcloud

  • 支持 jazzradio.com

  • 支持 Moodbar

  • 基於 projectM 的可視化技術

  • 拷貝音樂至 iPod，iPhone，MTP 或者 大容量 USB 設備

  • 遠程控制

  • 轉碼音樂至 MP3，Ogg Vorbis，Ogg Speex，FLAC 以及 AAC

  • 網址：www.clementine-player.org

  • 開發者：David Sansome，John Maguire

  • 許可證：GNU GPL v3

  • 當前版本：1.2

Nuvola Player ​

Nuvola Player 是一個免費的開源項目，能夠整合雲端音樂到你的桌面中（支持托盤圖標、Ubuntu 聲音菜單、dock 菜單以及通知中心）。

為了使用全部的流媒體服務，你需要安裝 Flash 和 HTML5 的音頻支持。某些基於 Web 的流媒體服務可以使用 HTML5 的音頻技術播放音樂，而非使用 Flash 插件。Nuvola Player 需要 GStreamr 和 MP3 解碼器插件來提供 HTML5 音頻支持。

支持的流媒體服務：

  • 集成了 MP3 商店的亞馬遜雲播放器，允許用户在亞馬遜雲端驅動器中存儲他們的音樂，並且在任何支持的瀏覽器上播放音樂
  • Bandcamp，是一家在線音樂商店，也是藝人宣傳平台，主要適於獨立藝術家
  • Deezer，一家法國的基於 Web 的音樂流媒體服務商。Deezer 允許用户在多台設備上在線或者離線播放音樂，現在擁有 1800 萬的曲目，超過 30000 的電台以及 2200 萬的用户（150 萬訂閲用户）
  • 8tracks，是一家融合了互聯網電台和社交元素的網站，堅持至少 8 個曲目的為用户量身定製的流媒體播放列表
  • Google Play，谷歌運營的一家數字服務商店，其經營項目包括音樂、電影、書籍，以及 Android 應用和遊戲，其雲端播放器支持播放用户自己上傳的音樂和在 Google Play 裏購買的音樂
  • Grooveshark，提供了國際化在線音樂搜索引擎、音樂流媒體服務以及音樂推薦服務，允許用户進行搜索、使用流媒體以及上傳音樂，並且能把這些音樂進行立即播放或者添加到一個播放列表中
  • Grooveshark Mobile，基於 HTML5 的 Grooveshark 移動版，不需要 Flash 插件的支持
  • Hype Machine，Pandora Radio 和 Pitchfork Media 的融合產物。它從音樂Blog上精選了最近發佈的歌曲（約 1500 首），並在網站主頁上列出了這些歌曲的信息
  • Jango，一款免費的在線音樂流媒體服務，允許用户創建和分享自己創建的電台
  • Logitech Media Server，是 Logitech Squeezebox devices 的開源流媒體服務。支持許多插件以及如 Deezer 和 Spotify 等其他流媒體服務
  • Pandora，智能化音樂推薦服務以及音樂基因組計劃“託管人”，服務僅針對美國地區
  • Rdio，有廣告的音樂訂閲服務
  • Spotify，商業化流媒體服務，提供來自唱片公司的被嚴格限制的數字版權內容
  • This is My Jam，你可以存放某一刻你非常喜歡的音樂，並且每天都可以收聽由朋友們精挑細選的音樂

特色包括：

  • 多媒體快捷鍵

  • 顯示桌面通知

  • 集成了眾多聲音菜單、小程序以及啓動器，甚至更多

  • Last FM 以及 Libre FM 歌曲記錄

  • 獲取歌詞

  • 支持 Amazon Music Prime streaming

  • 網址：tiliado.eu/nuvolaplayer

  • 開發者：Jiří Janoušek and service maintainers

  • 許可證：2-Clause BSD license

  • 當前版本：2.4.3

Atraci ​

Atraci 是一款多平台的開源流媒體應用，允許用户收聽超過 6000 萬首音樂。Atraci 仍然處於基礎開發階段，所以很多功能暫時還未完善。

Atraci 使用 iTunes，Last.fm 以及 SoundCLoud 顯示歌曲信息 —— 專輯封面、歌曲名稱以及藝術家。Atraci 在 YouTube 上搜索最匹配這首音樂信息的視頻，並使用其中質量最高的。

特色包括：

  • 無廣告、無需註冊

  • 直觀的用户界面

  • 智能匹配搜索任何音樂、藝術家或者專輯。Atraci 會在線校對其信息，以顯示正確的歌曲名稱、專輯封面以及音軌等等，同時列出最高質量的視頻流媒體

  • 自動修正所屬專輯與藝術家

  • 通過默認方式、藝術家姓名或者曲目名稱對結果排序

  • 以網格或列表模式查詢結果

  • 檢索視頻可以全屏模式觀看

  • 以隨機或重複模式創建播放列表

  • 應用程序內的音量調整滑塊、音軌調節以及專輯封面

  • 播放歷史

  • 網址：atraci.github.io/Atraci-website

  • 開發者：The Atraci Team

  • 許可證：The MIT License

  • 當前版本：0.7.0
