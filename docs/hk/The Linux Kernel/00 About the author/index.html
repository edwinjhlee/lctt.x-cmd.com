我每週為Linux.org寫兩篇文章。一篇是Linux內核系列而另一篇是任何隨機的Linux話題。﻿隨時可以發郵件建議你想看到的“隨機文章”。我樂意在站上寫一些能夠吸引大量讀者的東西。我的目標是每週寫一篇擁有1萬以上讀者的文章。

很快我會寫一些關於如何安裝流行Linux發行版的文章，因此，如果你想要閲讀某個特定發行版文章，請給我發郵件。

戴文.科利爾.約翰遜(Devyn Collier Johnson)在家接受了他偉大的父母的家庭式培養，現在已從一所大學畢業，正在讀另外一所大學。他的父親，傑瑞特.韋恩.布斯(Jarret Wayne Buse)擁有很多的計算機認證，並且他已經撰寫並出版了許多關於計算機的書籍。他也做一些編程，並給了戴文的人工智能程序提供過一些幫助和點子。他的媽媽，卡桑德拉.安.約翰遜(Cassandra Ann Johnson)，是一名家庭主婦，在家培養了他的許多兄弟姐妹。戴文.科利爾.約翰遜和他的父母住在印第安納，他的時間主要用在大學和個人的電腦編程上。

戴文.科利爾.約翰遜十六歲畢業於一所高中。他作為一名走讀生進入大學並一直保持在優秀學生名單上。他的專業是電氣技術工程。他已經學習了很多計算機語言。一些是他自學的而有的則是他父親教導並且幫助他學會的。一些他了解的語言包括Xaiml、AIML、Unix Shell、Python3、VPython、PyQT、PyGTK、Coffeescript、GEL、SED、HTML4/5、CSS3、SVG和XML。此外還了解一點其他的語言。他在2012年4月獲取了4項計算機證書他們是NCLA、Linux+、LPIC-1、和DCTS。 他的Linux專家認證ID是LPI000254694。

在2012年7月，戴文.科利爾.約翰遜決定從頭開始做他的聊天機器人。他設計了自己的標記語言(Xaiml)和AI引擎(ProgramPY-SH 或者 Pysh)。在2013年3月，戴文在Launchpad.net上發佈了他的機器人。這個機器人名為Neo，取自原始印歐語中單詞的“new”。

戴文還維護了其他幾個項目。他製作Opera和Firebox的主題 (https://addons.mozilla.org/en-US/firefox/user/DevynCJohnson/) (https://my.opera.com/devyncjohnson/account/); 他還有許多其他的圖形設計項目。他的大多數編程項目託管在 https://launchpad.net/~devyncjohnson-d, 另外在Sourceforge.net上也有鏡像，其他的一些雜項可以通過下面的鏈接找到。
