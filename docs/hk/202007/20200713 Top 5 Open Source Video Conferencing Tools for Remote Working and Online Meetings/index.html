5 個流行的用於遠程工作和在線會議的開源視頻會議工具 ​

你會發現網上有一些視頻會議工具。一些是為專業用户量身定製的，另一些是為了日常閒聊的。

然而面對着成百上千的選擇，當選擇視頻會議應用或服務時，安全和隱私是往往是一個重要的點。在眾多選擇中，哪些是最好最安全的？

所有這些（或大多數）都宣稱要提供最好的安全和隱私。但是，你要知道這可不能只看表面。

幸運的是在這裏，我們專注於開源和隱私友好的解決方案，所以，讓我們看看你可以使用的開源視頻會議工具列表。

頂級開源視頻會議解決方案 ​

如果你是商企用户，大多數視頻會議解決方案可以被安裝在你自己的服務器上。

對於不是系統管理員的普通人來説，其中一些解決方案還提供了現成的、免費的、基於 Web 的視頻會議服務。我將在列表中每個項目的描述中提及此信息。

備註： 列表中的排名不分先後。

1、Jitsi Meet ​

Jitsi Meet 是一個令人印象深刻的開源視頻會議服務。你可以在我們關於 Jitsi Meet 的單獨報道中輕鬆找到更多信息。

為了給你一個好的開始，Jitsi Meet 提供免費官方公共實例來測試它，只要你需要，就可以免費使用它。

如果你需要將其託管在你的服務器上，同時根據你的需求定製一些選項，你可以從它的官網下載到你的服務器。

儘管他們在 Linux 上提供了一個基於 Electron 的應用，其實你不必下載一個應用到你的桌面上來設置它。你只需要一個瀏覽器就足夠了。在移動端，安卓和 iOS 都有應用。

  • Jitsi Meet

2、Jami ​

Jami 是一個基於點對點的開源視頻會議解決方案。很高興看到分佈式的服務，這意味着不依靠服務器，而只是點對點的連接。

當然了，分佈式的服務有優點也有缺點。但是它是自由而開源的，那才是最重要的。

Jami 之前被稱為 Ring messenger，但它改了名字，現在是一個 GNU 項目。

Jami 有 Linux、Windows、macOS、Android 和 iOS 的版本，所以它是一個完全跨平台的安全傳送信息和視頻會議的解決方案。你可以看看他們的 GitLab 頁面瀏覽更多信息。

  • Jami

3、Nextcloud Talk ​

Nextcloud 毫無疑問是開源遠程辦公工具的瑞士軍刀。我們就在使用 Nextcloud。所以如果你已經配置了服務器，Nextcloud Talk 顯然是一個優秀的視頻會議和聊天工具。

當然了，如果你還沒有自己的 Nextcloud 服務器，你需要一些技術知識來進行設置它，然後才能開始使用 Nextcloud Talk。

  • Nextcloud Talk

4、Riot.im ​

Riot.im（不久會更名）已經是 Slack 最好的開源替代品之一。

它能讓你可以創建社區、發送信息，並在一個小組/社區中開始視頻會議。你可以通過任何可用的公共 Matrix 服務器來免費使用它。

如果你想要自己專用的去中心化的 Matrix 網絡，你也可以在 Modular.im 上選擇付費託管計劃。

  • Riot.im

5、BigBlueButton ​

BigBlueButton 是一個有趣的開源視頻會議方案，專門為線上學習打造。

如果你是老師或者經營着一個學校，你也許會想試試。雖然你可以免費試用，但免費演示使用會有一定的限制。所以，最好將其託管到自己的服務器上，並且，如果你有其他的產品/服務的話，你也可以把它整合進其中。

它提供了一套很好的功能，能讓你很輕鬆的教學生。你可以瀏覽它的 GitHub 頁面以瞭解更多信息。

  • BigBlueButton

補充：Wire ​

Wire 是一個十分流行的開源的安全消息平台，為商企用户量身打造。它也提供視頻電話或者網絡會議選項。

如果你想要一個為你的企業或團隊提供的商業開源方案，你可以試試 Wire，並在試用 30 天后決定是否升級它。

就個人而言，我喜歡它的用户體驗，但它是要付費的。所以我建議你決定之前，先試試看並瀏覽它的 GitHub 頁面。

  • Wire
