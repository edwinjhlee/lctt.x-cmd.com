我的 Linux 故事：從用户到貢獻者 ​

開源社區歡迎來自不同背景和技能的貢獻者。

我是一名 IT 專業人士，擁有超過 15 年經驗，擔任過不同職位 —— 包括系統管理員、高級 Linux 管理員、DevOps 工程師、自動化顧問和高級敏捷專家scrum master。我開始是在 Ubuntu 上學習 Linux，但是後來作為系統管理員轉到 CentOS，然後我又轉到 Fedora 作為個人使用。但是我對技術的喜愛要遠比我使用第一個 Linux 發行版要早的多，而且是來自於一部電影。

我最喜歡的電影是《黑客Hackers》。最精彩的一幕發生在電影的開頭。電影一開始，一羣特工衝進一所房子抓捕臭名昭著的黑客 Zero Cool。我們馬上發現 Zero Cool 其實是 11 歲的 Dade Murphy，他在一天之內成功癱瘓了 1507 台計算機系統。他被指控犯罪，他的家人被處以重罰。而且，在他 18 歲之前，他都被禁止使用電腦或按鍵式電話。

勞倫斯·梅森Laurence Mason扮演的 Paul Cook，又名 Nikon 勳爵，是我最喜歡角色。其中一個主要原因是，我從沒有看過一個黑客電影裏面的人物長的像我，所以我被他的形象深深吸引了。他很神秘。這讓我耳目一新，並且感到自豪，我對 IT 充滿了熱情，我也是一個和他很像的極客。

成為一個 Linux 貢獻者 ​

15 年前，我開始使用 Linux。當我成為一個 Linux 管理員的時候，Linux 就成了我的激情所在。我一直嘗試找到某種方式能夠為開源作出貢獻，當時我還不知道該從哪開始。因為這個社區實在是太大了，我不知道自己能否真正成為一個有影響力的人，但當我發現一些人認可我的興趣，還對我進行指導，我開始徹底打開心扉，問各種問題，並且從社區中學習。自從那以後，Fedora 社區一直是我做貢獻的最主要社區。

我現在對於向開源做貢獻還是有點稚嫩。當我意識到我可以用代碼以外的方式來貢獻時，我對開源的想法發生了改變。我更喜歡通過文檔做一些貢獻，因為我本質上不是一個軟件開發人員，而且社區裏面最迫切的需求正是文檔。請記住：用户的技能和開發人員的技能同樣重要。

我的硬件是什麼？ ​

硬件也很重要，而且現在幾乎所有東西都可以運行 Linux。現在，我家裏的配置包括：

  • 聯想 Thinksever TS140，64 GB 內存，4 x 1 TB SSD 和一個存儲數據的 1 TB 機械硬盤
  • 使用 RAID 5 配置的 164 TB Synology NAS
  • 輸入輸出使用羅技 MX Master 和 MX Master 2S
  • 一個定製的並且符合人體工學的 Kinesis Advantage 2 鍵盤
  • 兩個 38 寸 LG 超寬曲面顯示器和一個 34 寸 LG 超寬顯示器
  • 一台配備 i7 六核十二線程 CPU 和 16.1 英寸 IPS 顯示器的 System76 筆記本

我很喜歡 Fedora 處理外置設備的方式，比如説我的鼠標和鍵盤。一切都完美融合。即插即用工作正常，性能從來不受影響。

軟件是什麼？ ​

使用開源軟件對我的工作非常重要。我依賴於：

  • Fedora 30 作為我日常使用的 Linux 發行版
  • Wekan 作為我的項目的開源看板kanban
  • Atom 作為我的文本編輯器
  • Terminator 作為我日常使用的終端，因為它的網格佈局以及豐富的鍵盤快捷鍵
  • Neofetch 用來顯示每次登錄到終端時的系統信息

最後同樣重要的是，我把 Powerline、Powerlevel9k 和 Vim-Powerline 搞到我的終端上來跟別人裝酷。

Linux 讓我們走到一起 ​

美國是個大熔爐，我也是這麼看待 Linux 和像 Fedora 項目這樣的特定社區的。在每個 Linux 社區中，對於不同的貢獻都有很大的空間。也有很多方式可以參與進來，而且對於新的想法，也總是有發揮的空間。通過分享我過去 15 年在開源方面的經驗，我希望幫助更多在科技領域的少數族裔體會到來自開源社區對多樣性和包容性的認同感。
