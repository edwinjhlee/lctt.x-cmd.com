OWL 項目：物聯網正嘗試在災難中讓一切保持聯絡 ​

當自然災害破壞了傳統的通信連接時，配置在多跳網絡mesh network的物聯網設備可以迅速部署以提供基本的連接。

OWL 項目負責人在最近的開源峯會上説，一個以多跳網絡、物聯網和 LoRa 連接為中心的開源項目可以幫助急救和受災人員在自然災害之後保持聯繫。

OWL 項目的應用場景是當在自然災害之後頻繁發生的通信中斷時。無論是蜂窩網絡還是有線網絡，大範圍的中斷會頻繁阻礙急救服務、供應和在暴風雨或其他重大災難後必須解決關鍵問題的信息流。

該項目通過一大羣“鴨子duck”（便宜、易於部署且不需要現有基礎設施支持的小型無線模組）實現這個目的。一些“鴨子”是太陽能的，其它一些則用的是耐用電池。每隻“鴨子”配備一個 LoRa 無線電，用於在網絡上和其它“鴨子”進行通信，同時還配備有 Wi-Fi，而且可能配備藍牙和 GPS 來實現其他功能。

這個想法是這樣的，當網絡癱瘓時，用户可以使用他們的智能手機或者筆記本電腦與“鴨子”建立一個 Wi-Fi 連接，這個“鴨子”可以將小塊的信息傳遞到網絡的其他部分。信息向網絡後端傳遞，直到到達“鴨子爸爸papaduck”，“鴨子爸爸”裝備了可以與雲上的 OWL 數據管理系統連接的衞星系統（OWL 代表 ”組織organization、位置whereabouts和物流logistics”）。信息可以通過雲在智能手機或者網頁上進行可視化，甚至可以通過 API 插入到現有的系統中。

秘密在於“鴨羣ClusterDuck” 協議，這是一個開源固件，即使在一些模組不能正常工作的網絡中，它仍然能保持信息流通。它就是設計用來工作在大量便宜且容易獲取的計算硬件上，類似樹莓派的硬件，這樣可以更容易且更快捷的建立一個“鴨羣”網絡。

創始人 Bryan Knouse 表示，這個項目的創建，是因為在 2017 年和 2018 年的毀滅性颶風中，要與受影響社區進行有效的通信而採取救援措施，面臨着巨大的困難。

“我們的一些創始成員經歷了這些災難，然後我們會問‘我們該做些什麼？’”，他説道。

在馬亞圭斯，該項目有一批來自波多黎各大學的學生和教授，大多數的系統測試都在那裏進行。Knouse 説，校園中目前有 17 個太陽能“鴨子”，分佈在屋頂和樹上，並且計劃增加數量。

他説，“這種關係實際上創建了一個開源社區，這些學生和教授正在幫助我們開發這個項目。”
