你是否已經準備好從 Mac 切換到 Linux 了？ ​

你幾乎可以在 Linux 上做任何你在 Mac 上可以做的事情 —— 這是你擁有一個開源操作系統的自由。

我從 Mac 轉到 Linux 已經兩年了。在使用 Linux 之前，我用的 Apple 的系統用了 15 年，而當我在 2018 年安裝第一個 Linux 發行版時，還只是一個純粹的新手。

這些日子以來，我只用 Linux，我可以用它完成任何任務。瀏覽網頁、觀看 Netflix 影片、寫作以及編輯我的 Wordpress Blog，甚至還在上面跑我的開源網頁分析項目。

我甚至還不是一個開發者！Linux 被認為不適合日常使用，對非技術人員也不夠友好的日子已經一去不返了。

最近有很多關於 Mac 的討論，越來越多的人已經在考慮轉到 Linux。我打算分享我的切換過程中的一些經驗，幫助其它新手也能從容轉移。

你該不該換？ ​

在換系統之前，最好想清楚，因為有時候 Linux 可能跟你預期不一樣。如果你仍希望跟 Apple Watch 無縫配對、可以用 FaceTime 給朋友打電話、或者你想打開 iMovie 看視頻，那最好還是不要換了。這些都是 Apple 的專有產品，你只能在 Apple 的“圍牆花園”裏面使用。如果離不開 Apple 的生態系統，那麼 Linux 可能不太適合你。

我對 Apple 生態沒有太多掛念，我不用 iPhone，所以跟手機的協作沒那麼必要。我也不用 iCloud、FaceTime，當然也包括 Siri。我早就對開源充滿興趣，只是一直沒有行動。

檢查你的必備軟件清單 ​

我還在使用 Mac 的時候，就已經開始探索開源軟件，我發現大部分在 Mac 上使用的軟件，在 Linux 也可以運行。

很熟悉用火狐瀏覽網頁嗎？在 Linux 上它也可以運行。想用 VLC 看視頻？它也有 Linux 版本。喜歡用 Audacity 錄製、編輯音頻？它正在 Linux 上等着你呢。你用 OBS Studio 直播？在 Linux 直接下載安裝吧。一直用 Telegram 跟朋友和家人保持聯繫嗎？Linux 上當然少不了它。

此外，Linux 不僅僅意味着開源軟件。你最喜歡的大部分（也可能是所有）非 Apple 專有軟件，都能在 Linux 見到它們的身影。Spotify、Slack、Zoom、Stream、Discord、Skype、Chrome 以及很多閉源軟件，都可以使用。而且，在你 Mac 瀏覽器裏面運行的任何東西，同樣能夠運行在 Linux 瀏覽器。

你能在 Linux 找到你的必備軟件，或者更好的替代品嗎？請再三確認，做到有備無患。用你最常用的搜索引擎，在網上檢索一下。搜索“軟件名 + Linux” 或者“軟件名 + Linux 替代品”，然後再去 Flathub 網站查看你能在 Linux 用 Flatpak 安裝的專有軟件有哪些。

請牢記：Linux 不等於 Mac ​

如果你希望能夠從 Mac 輕鬆轉移到 Linux，我相信有一點很重要，你需要保持包容的思想以及願意學習新操作系統的心態。Linux 並不等於 Mac，所以你需要給自己一些時間去接觸並瞭解它。

如果你想讓 Linux 用起來、看起來跟你習慣的 macOS 一模一樣，那麼 Linux 可能也不適合你。儘管你可以通過各種方法把 Linux 桌面環境打造得跟 macOS 相似，但我覺得要想成功轉移到 Linux，最好的辦法是從擁抱 Linux 開始。

試試新的工作流，該怎麼用就怎麼用。不要總想着把 Linux 變成其它東西。你會跟我一樣，像享受 Mac 一樣享受 Linux，甚至能有更好的體驗感。

還記得你第一次使用 Mac 吧：你肯定花了不少時間去習慣它的用法。那麼請給 Linux 同樣多的時間和關懷。

選擇一個 Linux 發行版 ​

有別於 Windows 和 macOS，Linux 不止一個單一的操作系統。不同的 Linux 操作系統被稱作發行版，開始使用 Linux 之後，我嘗試過好幾個不同的發行版。我也用過不同的桌面環境，或者圖形界面。在美觀度、易用性、工作流以及集成軟件上，它們有很大差異。

儘管作為 Mac 的替代品，被提及最多的是 ElementaryOS 和 Pop!_OS，但我仍建議從 Fedora 工作站 開始，理由如下：

  • 使用 Fedora 介質寫入器，容易安裝
  • 幾乎可以支持你所有的硬件，開箱即用
  • 支持最新的 Linux 軟件
  • 運行原生無改動的 GNOME 桌面環境
  • 有一個大型開發團隊以及一個龐大的社區在背後支持

在我看來，對從 macOS 過來的新手來説，GNOME 是易用性、一致性、流暢性和用户體驗最好的桌面環境。它擁有 Linux 世界中最多的開發資源和用户基數，所以你的使用體驗會很好。

Fedora 可以為你打開一扇 Linux 的大門，當你適應之後，就可以開始進一步探索各個發行版、桌面環境，甚至窗口管理器之類的玩意了。

熟悉 GNOME ​

GNOME 是 Fedora 和許多其它 Linux 發行版的默認窗口管理器。它最近 升級到 GNOME 3.36，帶來了 Mac 用户會喜歡的現代設計。

一定要做好心理準備，Linux、Fedora 工作站和 GNOME 並不是 Apple 和 macOS。GNOME 非常乾淨、簡約、現代、獨創。它不會分散你的注意力，沒有桌面圖標，沒有可見的塢站，窗口上甚至沒有最小化和最大化按鈕。但是不要慌張，如果你去嘗試，它會證明這是你用過最好、最有生產力的操作系統。

GNOME 不會給你帶來困擾。啓動之後，你唯一能看到的東西只有頂欄和背景圖片。頂欄由這幾樣東西組成，“活動”在左邊，時間和日期在中間（這也是你的通知中心），右邊是網絡、藍牙、VPN、聲音、亮度、電池等托盤圖標之類的東西。

為什麼 GNOME 像 Mac ​

你會注意到一些跟 macOS 的相似之處，例如窗口吸附、空格預覽（用起來跟 “Quick Look” 一模一樣）。

如果你把鼠標光標移動到左上角，點擊頂欄的“活動”，或者按下鍵盤上超級鍵（Super 鍵，也就是 Mac 上的 ஐ 鍵），你會看到“活動概覽”。它有點像 macOS 系統上“調度中心”和“聚焦搜索”的結合體。它會在屏幕中間展示已打開軟件和窗口的概覽。在左手邊，你可以看到塢站，上面有你打開的軟件和常用軟件。所有打開的軟件下面會有一個指示標誌，在右手邊，你可以看到不同的工作區。

在頂欄中間，有一個搜索框。只要你開始輸入，焦點就會轉移到搜索框。它能搜索你已經安裝的軟件和文件內容，可以在軟件中心搜索指定的軟件、進行計算、向你展示時間或者天氣，當然它能做的還有很多。它就像“聚焦”一樣。只需開始輸入你要搜索的內容，按下回車就可以打開軟件或者文件。

你也能看到一列安裝好的軟件（更像 Mac 上的“啓動台”），點擊塢站中的“顯示應用”圖標，或者按 Super + A 就行。

總體來説，Linux 是一個輕量級的系統，即使在很老的硬件上也能跑得很順暢，跟 macOS 比起來僅僅佔用很少的磁盤空間。並且不像 macOS，你可以刪除任何你不想要或不需要的預裝軟件。

自定義你的 GNOME 設置 ​

瀏覽一下 GNOME 設置，熟悉它的選項，做一些更改，讓它用起來更舒服。下面是一些我裝好 GNOME 必做的事情。

  • 在“鼠標和觸摸板”中，我禁用“自然滾動”、啓用“輕觸點擊”。
  • 在“顯示”中，我打開“夜光”功能，在晚上，屏幕會讓顏色變暖，減少眼睛疲勞。
  • 我也安裝了 GNOME 優化，因為它可以更改額外的設置選項。
  • 在“GNOME 優化”中，我啓用了 “Over-Amplification” 設置，這樣就能獲得更高的音量。
  • 在“GNOME 優化”中，相比默認的亮色主題，我更喜歡 “Adwaita Dark” 主題。

習慣使用鍵盤操作 ​

GNOME 是以一個極度以鍵盤為中心的操作系統，所以儘量多使用鍵盤。在 GNOME 設置中的“鍵盤快捷鍵”部分，你可以找到各個快捷鍵。

你也可以根據自己的理想工作流程來設置鍵盤快捷鍵。我將我最常用的應用程序設置為使用超級鍵打開。比如説，Super + B 打開我的瀏覽器，Super + F 打開“文件”，Super + T 打開終端。我還把 Ctrl + Q 設置成關閉窗口。

我使用 Super + Tab 在打開的應用程序之間切換，Super + H 隱藏一個窗口，F11 全屏打開軟件，Super + Left 把窗口吸附到屏幕左邊，Super + Right 把窗口吸附到屏幕左邊，等等。

在 Mac 上嘗試 Linux 之後再做決定 ​

在完全安裝 Linux 之前，在你的 Mac 上先嚐試 Fedora。從 Fefora 官網下載 ISO 鏡像。使用 Etcher 將 ISO 鏡像寫入 USB 驅動器，然後在啓動時點擊 Option 鍵，這樣你就可以在即用模式下嘗試了。

現在您無需在 Mac 上安裝任何東西就可以探索 Fedora 工作站了。試試各種東西，能否正常工作：能不能連接 WiFi？觸控板是否正常？有沒有聲音？等等。

也記得花時間來嘗試 GNOME。測試我上面提到的不同功能。打開一些安裝好的軟件。如果一切看起來都還不錯，如果你喜歡這樣的 Fedora 工作站和 GNOME，並且很肯定這就是你想要的，那麼把它安裝到你的 Mac 吧。

盡情探索 Linux 世界吧！
