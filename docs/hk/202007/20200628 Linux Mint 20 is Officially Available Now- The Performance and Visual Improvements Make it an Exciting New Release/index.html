Linux Mint 20 正式發佈了！你該升級嗎？ ​

Linux Mint 20 “Ulyana” 終於發佈了，可以下載了。

Linux Mint 19 基於 Ubuntu 18.04 LTS，而 Mint 20 則基於 Ubuntu 20.04 LTS —— 所以你會發現很多不同的地方、改進的地方，可能更棒了。

既然它來了，讓我們來看看它的新功能，在哪裏下載它，以及如何升級你的系統。

Linux Mint 20：有什麼新東西？ ​

我們製作了一段關於 Linux Mint 20 的初步視覺印象的視頻，讓大家更好地瞭解。

  • video

説到 Linux Mint 20 的發佈，有很多事情要談。雖然我們已經介紹了 Linux Mint 20 的新的關鍵功能，但我還是在這裏提幾點，讓大家一目瞭然。

  • Nemo 文件管理器在生成縮略圖方面的性能提升
  • 一些重新設計的顏色主題
  • Linux Mint 20 將禁止 APT 使用 Snapd
  • 一個新的圖形用户界面工具，用於通過本地網絡共享文件
  • 改進對多顯示器的支持
  • 改進對筆記本電腦的混合圖形支持
  • 不再有 32 位版本

除了這些變化之外，你還會注意到 Cinnamon 4.6 桌面更新後的一些視覺變化。

以下是 Linux Mint 20 Cinnamon 版的一些截圖。

升級到 Linux Mint 20：你需要知道什麼？ ​

如果你已經在使用 Linux Mint，你可以選擇升級到 Linux Mint 20。

  • 如果你使用的是 Linux Mint 20 測試版，你可以升級到 Mint 20 穩定版。
  • 如果你正在使用 Linux Mint 19.3（這是 Mint 19 的最新迭代），你可以將系統升級到 Linux Mint 20，而不需要進行重新安裝
  • Linux Mint 20 沒有 32 位版本。如果你使用 32 位的 Mint 19 系列，你將無法升級到 Mint 20
  • 如果你使用的是 Linux Mint 18 系列，你必須先通過 Mint 19 系列升級。在我看來，重新安裝 Mint 20 會比較省時省事
  • 如果你使用的是 Linux Mint 17、16、15 或更低版本，你一定不要再使用它們了。這些版本已經不支持了

我們有一個詳細的指南，展示了從 18.3 到 19 升級 Linux Mint 版本的步驟。我猜測 Mint 20 的步驟應該也是一樣的。我們的團隊會對 Mint 19.3 到 Mint 20 的升級做一些測試，並在適用的情況下更新這個指南。

在你繼續升級之前，請確保備份你的數據和使用 Timeshift 創建系統快照。

下載Linux Mint 20 ​

你可以簡單地前往其官方下載頁面，為自己抓取最新的穩定 ISO。你會發現官方支持的桌面環境的 ISO，即 Cinnamon、MATE 和 Xfce。

此外，還為那些網絡連接緩慢或不穩定的用户提供了 Torrent鏈接。
