5 款值得擁有的 Linux 媒體播放器 ​

無論是電影還是音樂，Linux 都能為你提供一些優秀的媒體播放器。

在 2021 年，人們有更多的理由喜歡 Linux。在這個系列中，我將分享 21 個使用 Linux 的不同理由。媒體播放是我最喜歡使用 Linux 的理由之一。

你可能更喜歡黑膠唱片和卡帶，或者錄像帶和激光影碟，但你很有可能還是在數字設備上播放你喜歡的大部分媒體。電腦上的媒體有一種無法比擬的便利性，這主要是因為我們大多數人一天中的大部分時間都在電腦附近。許多現代電腦用户並沒有過多考慮有哪些應用可以用來聽音樂和看電影，因為大多數操作系統都默認提供了媒體播放器，或者因為他們訂閲了流媒體服務，因此並沒有把媒體文件放在自己身邊。但如果你的口味超出了通常的熱門音樂和節目列表，或者你以媒體工作為樂趣或利潤，那麼你就會有你想要播放的本地文件。你可能還對現有用户界面有意見。在 Linux 上，選擇是一種權利，因此你可以選擇無數種播放媒體的方式。

以下是我在 Linux 上必備的五個媒體播放器。

1、mpv ​

一個現代、乾淨、簡約的媒體播放器。得益於它的 Mplayer、ffmpeg 和 libmpv 後端，它可以播放你可能會扔給它的任何類型媒體。我説“扔給它”，是因為播放一個文件的最快捷、最簡單的方法就是把文件拖到 mpv 窗口中。如果你拖動多個文件，mpv 會為你創建一個播放列表。

當你把鼠標放在上面時，它提供了直觀的覆蓋控件，但最好還是通過鍵盤操作界面。例如，Alt+1 會使 mpv 窗口變成全尺寸，而 Alt+0 會使其縮小到一半大小。你可以使用 , 和 . 鍵逐幀瀏覽視頻，[ 和 ] 鍵調整播放速度，/ 和 * 調整音量，m 靜音等等。這些主控功能可以讓你快速調整，一旦你學會了這些功能，你幾乎可以在想到要調整播放的時候快速調整。無論是工作還是娛樂，mpv 都是我播放媒體的首選。

2、Kaffeine 和 Rhythmbox ​

KDE Plasma 和 GNOME 桌面都提供了音樂應用（Kaffeine 和 [Rhythmbox][]），可以作為你個人音樂庫的前端。它們會讓你為你的音樂文件提供一個標準的位置，然後掃描你的音樂收藏，這樣你就可以根據專輯、藝術家等來瀏覽。這兩款軟件都很適合那些你無法完全決定你想聽什麼，而又想用一種簡單的方式來瀏覽現有音樂的時候。

Kaffeine 其實不僅僅是一個音樂播放器。它可以播放視頻文件、DVD、CD，甚至數字電視（假設你有輸入信號）。我已經整整幾天沒有關閉 Kaffeine 了，因為不管我是想聽音樂還是看電影，Kaffeine 都能讓我輕鬆地開始播放。

3、Audacious ​

Audacious 媒體播放器是一個輕量級的應用，它可以播放你的音樂文件（甚至是 MIDI 文件）或來自互聯網的流媒體音樂。對我來説，它的主要吸引力在於它的模組化架構，它鼓勵開發插件。這些插件可以播放幾乎所有你能想到的音頻媒體格式，用圖形均衡器調整聲音，應用效果，甚至可以重塑整個應用，改變其界面。

很難把 Audacious 僅僅看作是一個應用，因為它很容易讓它變成你想要的應用。無論你是 Linux 上的 XMMS、Windows 上的 WinAmp，還是任何其他替代品，你大概都可以用 Audacious 來近似它們。Audacious 還提供了一個終端命令，audtool，所以你可以從命令列控制一個正在運行的 Audacious 實例，所以它甚至可以近似於一個終端媒體播放器!

4、VLC ​

VLC 播放器可能是向用户介紹開源的應用之首。作為一款久經考驗的多媒體播放器，VLC 可以播放音樂、視頻、光盤。它還可以通過網絡攝像頭或麥克風進行流式傳輸和錄製，從而使其成為捕獲快速視頻或語音消息的簡便方法。像 mpv 一樣，大多數情況下都可以通過按單個字母的鍵盤操作來控制它，但它也有一個有用的右鍵菜單。它可以將媒體從一種格式轉換為另一種格式、創建播放列表、跟蹤你的媒體庫等。VLC 是最好的，大多數播放器甚至無法在功能上與之匹敵。無論你在什麼平台上，它都是一款必備的應用。

5、Music player daemon ​

music player daemon（mpd） 是一個特別有用的播放器，因為它在服務器上運行。這意味着你可以在 樹莓派 上啓動它，然後讓它處於空閒狀態，這樣你就可以在任何時候播放一首曲子。mpd 的客户端有很多，但我用的是 ncmpc。有了 ncmpc 或像 netjukebox 這樣的 Web 客户端，我可以從本地主機或遠程機器上連接 mpd，選擇一張專輯，然後從任何地方播放它。

Linux 上的媒體播放 ​

在 Linux 上播放媒體是很容易的，這要歸功於它出色的編解碼器支持和驚人的播放器選擇。我只提到了我最喜歡的五個播放器，但還有更多的播放器供你探索。試試它們，找到最好的，然後坐下來放鬆一下。
