初級：在 Linux 中自定義 Cinnamon 桌面的 7 種方法 ​

Linux Mint 是最好的 適合初學者的 Linux 發行版 之一。尤其是想 轉戰 Linux 的 Windows 用户，會發現它的 Cinnamon 桌面環境非常熟悉。

Cinnamon 給人一種傳統的桌面體驗，很多用户喜歡它的樣子。這並不意味着你必須滿足於它提供的東西。Cinnamon 提供了幾種自定義桌面的方式。

在閲讀了 MATE 和 KDE 自定義 指南後，很多讀者要求為 Linux Mint Cinnamon 也提供類似的教程。因此，我創建了這個關於調整 Cinnamon 桌面的外觀和感覺的基本指南。

7 種自定義 Cinnamon 桌面的不同方法 ​

在本教程中，我使用的是 Linux Mint Debian Edition（LMDE 4）。你可以在任何運行 Cinnamon 的 Linux 發行版上使用這篇文章的方法。如果你不確定，這裏有 如何檢查你使用的桌面環境。

當需要改變 Cinnamon 桌面外觀時，我發現非常簡單，因為只需點擊兩下即可。如下圖所示，點擊菜單圖標，然後點擊“設置”。

所有的外觀設置都放在該窗口的頂部。在“系統設置”窗口上的一切都顯得整齊劃一。

1、效果 ​

效果選項簡單，不言自明，一目瞭然。你可以開啓或關閉桌面不同元素的特效，或者通過改變特效風格來改變窗口過渡。如果你想改變效果的速度，可以通過自定義標籤來實現。

2、字體選擇 ​

在這個部分，你可以區分整個系統中使用的字體大小和類型，通過字體設置，你可以對外觀進行微調。

3、主題和圖標 ​

我曾經做了幾年的 Linux Mint 用户，一個原因是你不需要到處去改變你想要的東西。窗口管理器、圖標和麪板定製都在一個地方！

你可以將面板改成深色或淺色，窗口邊框也可以根據你要的而改變。默認的 Cinnamon 外觀設置在我眼裏是最好的，我甚至在測試 Ubuntu Cinnamon Remix 時也應用了一模一樣的設置，不過是橙色的。

4、Cinnamon 小程序 ​

Cinnamon 小程序是所有包含在底部面板的元素，如日曆或鍵盤佈局切換器。在管理選項卡中，你可以添加/刪除已經安裝的小程序。

你一定要探索一下可以下載的小程序，如天氣和 CPU 温度指示小程序是我額外選擇的。

5、Cinnamon Desklets ​

Cinnamon Desklets 是可以直接放置在桌面上的應用。和其他所有的自定義選項一樣，Desklets 可以從設置菜單中訪問，各種各樣的選擇可以吸引任何人的興趣。谷歌日曆是一個方便的應用，可以直接在桌面上跟蹤你的日程安排。

6、桌面壁紙 ​

要改變 Cinnamon 桌面的背景，只需在桌面上點擊右鍵，選擇“改變桌面背景”。它將打開一個簡單易用的窗口，在左側列出了可用的背景系統文件夾，右側有每個文件夾內的圖片預覽。

你可以通過點擊加號（+）並選擇路徑來添加自己的文件夾。在“設置”選項卡中，你可以選擇你的背景是靜態還是幻燈片，以及背景在屏幕上的位置。

7、自定義桌面屏幕上的內容 ​

背景並不是你唯一可以改變的桌面元素。如果你在桌面上點擊右鍵，然後點擊“自定義”，你可以找到更多的選項。

你可以改變圖標的大小，將擺放方式從垂直改為水平，並改變它們在兩個軸上的間距。如果你不喜歡你所做的，點擊重置網格間距回到默認值。

此外，如果你點擊“桌面設置”，將顯示更多的選項。你可以禁用桌面上的圖標，將它們放在主顯示器或副顯示器上，甚至兩個都可以。如你所見，你可以選擇一些圖標出現在桌面上。

總結 ​

Cinnamon 桌面是最好的選擇之一，尤其是當你正在 從 windows 切換到 Linux 的時候，同時對一個簡單而優雅的桌面追求者也是如此。

Cinnamon 桌面非常穩定，在我手上從來沒有崩潰過，這也是在各種 Linux 發行版之間，我使用它這麼久的主要原因之一。

我沒有講得太詳細，但給了你足夠的指導，讓你自己去探索設置。歡迎反饋你對 Cinnamon 的定製。
