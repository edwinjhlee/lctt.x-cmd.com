EndeavourOS：填補 Antergos 在 ArchLinux 世界留下的空白 ​

我相信我們的大多數讀者都知道 Antergos 項目的終結。在這一消息宣佈之後，Antergos 社區的成員創建了幾個發行版來繼承 Antergos。今天，我們將着眼於 Antergos 的“精神繼承人”之一：EndeavourOS。

EndeavourOS 不是 Antergos 的分支 ​

在我們開始之前，我想非常明確地指出，EndeavourOS 並不是一個 Antergos 的復刻版本。開發者們以 Antergos 為靈感，創建了一個基於 Arch 的輕量級發行版。

根據 這個項目網站 的説法，EndeavourOS 的誕生是因為 Antergos 社區的人們想要保持 Antergos 的精神。他們的目標很簡單：“讓 Arch 擁有一個易於使用的安裝程序和一個友好、有幫助的社區，在掌握系統的過程中能夠有一個社區可以依靠。”

與許多基於 Arch 的發行版不同，EndeavourOS 打算像 原生 Arch 那樣使用，“所以沒有一鍵式安裝你喜歡的應用程序的解決方案，也沒有一堆你最終不需要的預裝應用程序。”對於大多數人來説，尤其是那些剛接觸 Linux 和 Arch 的人，會有一個學習曲線，但 EndeavourOS 的目標是建立一個大型友好的社區，鼓勵人們提出問題並瞭解他們的系統。

正在進行的工作 ​

EndeavourOS 在 2019 年 5 月 23 日首次宣佈成立 隨後 在 7 月 15 日發佈第一個版本。不幸的是，這意味着開發人員無法將他們計劃的所有功能全部整合進來。（LCTT 譯註：本文原文發表於 2019 年，而現在，EndeavourOS 還在持續活躍着。）

例如，他們想要一個類似於 Antergos 的在線安裝，但卻遇到了當前選項的問題。“Cnchi 運行在 Antergos 生態系統之外會造成嚴重的問題，需要徹底重寫才能發揮作用。RebornOS 的 Fenix 安裝程序還沒有完全成型，需要更多時間才能正常運行。”於是現在，EndeavourOS 將會和 Calamares 安裝程序 一起發佈。

EndeavourOS 會提供 比 Antergos 少的東西：它的存儲庫比 Antergos 小，儘管他們會附帶一些 AUR 包。他們的目標是提供一個接近 Arch 卻不是原生 Arch 的系統。

開發者進一步聲明 :

“Linux，特別是 Arch，核心精神是自由選擇，我們提供了一個基本的安裝，讓你在一個精細的層面上方便地探索各項選擇。我們永遠不會強行為你作決定，比如為你安裝 GUI 應用程序，如 Pamac，甚至採用沙盒解決方案，如 Flatpak 或 Snaps。想安裝成什麼樣子完全取決於你，這是我們與 Antergos 或 Manjaro 的主要區別，但與 Antergos 一樣，如果你安裝的軟件包遇到問題，我們會盡力幫助你。”

體驗 EndeavourOS ​

我在 VirtualBox 中安裝了 EndeavourOS，並且研究了一番。當我第一次啓動時，我看到一個窗口，裏面有關於安裝的 EndeavourOS 網站的鏈接。它還有一個安裝按鈕和一個手動分區工具。Calamares 安裝程序的安裝過程非常順利。

在我重新啓動到新安裝的 EndeavourOS 之後，迎接我的是一個彩色主題的 XFCE 桌面。我還收到了一堆通知消息。我使用過的大多數基於 Arch 的發行版都帶有一個 GUI 包管理器，比如 pamac 或 octopi，以進行系統更新。EndeavourOS 配有 kalu（kalu 是 “Keeping Arch Linux Up-to-date” 的縮寫）。它可以更新軟件包、可以看 Archlinux 新聞、可以更新 AUR 包等等。一旦它檢查到有更新，它就會顯示通知消息。

我瀏覽了一下菜單，看看默認安裝了什麼。默認的安裝並不多，連辦公套件都沒有。他們想讓 EndeavourOS 成為一塊空白畫布，讓任何人都可以創建他們想要的系統。他們正朝着正確的方向前進。

總結思考 ​

EndeavourOS 還很年輕。第一個穩定版本都沒有發佈多久。它缺少一些東西，最重要的是一個在線安裝程序。這就是説，我們無法估計他能夠走到哪一步。（LCTT 譯註：本文發表於 2019 年）

雖然它不是 Antergos 的精確復刻，但 EndeavourOS 希望複製 Antergos 最重要的部分——熱情友好的社區。很多時候，Linux 社區對初學者似乎是不受歡迎甚至是完全敵對的。我看到越來越多的人試圖與這種消極情緒作鬥爭，並將更多的人引入 Linux。隨着 EndeavourOS 團隊把焦點放在社區建設上，我相信一個偉大的發行版將會誕生。

如果你當前正在使用 Antergos，有一種方法可以讓你不用重裝系統就切換到 EndeavourOS

如果你想要一個 Antergos 的精確復刻，我建議你去看看 RebornOS。他們目前正在開發一個名為 Fenix 的 Cnchi 安裝程序的替代品。

你試過 EndeavourOS 了嗎？你的感受如何？
