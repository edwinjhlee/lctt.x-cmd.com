9 個易用的基於 Arch 的用户友好型 Linux 發行版 ​

在 Linux 社區中，Arch Linux 有一羣狂熱的追隨者。這個輕量級的發行版以 DIY 的態度提供了最前沿的更新。

但是，Arch 的目標用户是那些更有經驗的用户。因此，它通常被認為是那些技術不夠（或耐心不夠）的人所無法觸及的。

事實上，只是最開始的步驟，安裝 Arch Linux 就足以把很多人嚇跑。與大多數其他發行版不同，Arch Linux 沒有一個易於使用的圖形安裝程序。安裝過程中涉及到的磁盤分區，連接到互聯網，掛載驅動器和創建文件系統等只用命令列工具來操作。

對於那些不想經歷複雜的安裝和設置的人來説，有許多用户友好的基於 Arch 的發行版。

在本文中，我將向你展示一些 Arch 替代發行版。這些發行版附帶了圖形安裝程序、圖形包管理器和其他工具，比它們的命令列版本更容易使用。

更容易設置和使用的基於 Arch 的 Linux 發行版 ​

請注意，這不是一個排名列表。這些數字只是為了計數的目的。排第二的發行版不應該被認為比排第七的發行版好。

1、Manjaro Linux ​

Manjaro 不需要任何介紹。它是幾年來最流行的 Linux 發行版之一，它值得擁有。

Manjaro 提供了 Arch Linux 的所有優點，同時注重用户友好性和可訪問性。Manjaro 既適合新手，也適合有經驗的 Linux 用户。

對於新手，它提供了一個用户友好的安裝程序，系統本身也設計成可以在你最喜愛的桌面環境 （DE）或窗口管理器中直接“開箱即用”。

對於更有經驗的用户，Manjaro 還提供多種功能，以滿足每個個人的口味和喜好。Manjaro Architect 提供了安裝各種 Manjaro 風格的選項，併為那些想要完全自由地塑造系統的人提供了各種桌面環境、文件系統（最近推出的 ZFS） 和引導程序的選擇。

Manjaro 也是一個滾動發佈的前沿發行版。然而，與 Arch 不同的是，Manjaro 首先測試更新，然後將其提供給用户。穩定在這裏也很重要。

2、ArcoLinux ​

ArcoLinux（以前稱為 ArchMerge）是一個基於 Arch Linux 的發行版。開發團隊提供了三種變體。ArcoLinux、ArcoLinuxD 和 ArcoLinuxB。

ArcoLinux 是一個功能齊全的發行版，附帶有 Xfce 桌面、Openbox 和 i3 窗口管理器。

ArcoLinuxD 是一個精簡的發行版，它包含了一些腳本，可以讓高級用户安裝任何桌面和應用程序。

ArcoLinuxB 是一個讓用户能夠構建自定義發行版的項目，同時還開發了幾個帶有預配置桌面的社區版本，如 Awesome、bspwm、Budgie、Cinnamon、Deepin、GNOME、MATE 和 KDE Plasma。

ArcoLinux 還提供了各種視頻教程，因為它非常注重學習和獲取 Linux 技能。

3、Archlabs Linux ​

ArchLabs Linux 是一個輕量級的滾動版 Linux 發行版，基於最精簡的 Arch Linux，帶有 Openbox 窗口管理器。ArchLabs 在觀感設計中受到 BunsenLabs 的影響和啓發，主要考慮到中級到高級用户的需求。

4、Archman Linux ​

Archman 是一個獨立的項目。Arch Linux 發行版對於沒有多少 Linux 經驗的用户來説通常不是理想的操作系統。要想在最小的挫折感下讓事情變得更有意義，必須要有相當的背景知識。Archman Linux 的開發人員正試圖改變這種評價。

Archman 的開發是基於對開發的理解，包括用户反饋和體驗組件。根據團隊過去的經驗，將用户的反饋和要求融合在一起，確定路線圖並完成構建工作。

5、EndeavourOS ​

當流行的基於 Arch 的發行版 Antergos 在 2019 結束 時，它留下了一個友好且非常有用的社區。Antergos 項目結束的原因是因為該系統對於開發人員來説太難維護了。

在宣佈結束後的幾天內，一些有經驗的用户通過創建一個新的發行版來填補 Antergos 留下的空白，從而維護了以前的社區。這就是 EndeavourOS 的誕生。

EndeavourOS 是輕量級的，並且附帶了最少數量的預裝應用程序。一塊近乎空白的畫布，隨時可以個性化。

6、RebornOS ​

RebornOS 開發人員的目標是將 Linux 的真正威力帶給每個人，一個 ISO 提供了 15 個桌面環境可供選擇，並提供無限的定製機會。

RebornOS 還聲稱支持 Anbox，它可以在桌面 Linux 上運行 Android 應用程序。它還提供了一個簡單的內核管理器 GUI 工具。

再加上 Pacman、AUR，以及定製版本的 Cnchi 圖形安裝程序，Arch Linux 終於可以讓最沒有經驗的用户也能夠使用了。

7、Chakra Linux ​

一個社區開發的 GNU/Linux 發行版，它的亮點在 KDE 和 Qt 技術。Chakra Linux 不在特定日期安排發佈，而是使用“半滾動發佈”系統。

這意味着 Chakra Linux 的核心包被凍結，只在修復安全問題時才會更新。這些軟件包是在最新版本經過徹底測試後更新的，然後再轉移到永久軟件庫（大約每六個月更新一次）。

除官方軟件庫外，用户還可以安裝 Chakra 社區軟件庫 （CCR） 的軟件包，該庫為官方存儲庫中未包含的軟件提供用户製作的 PKGINFOs 和 PKGBUILD 腳本，其靈感來自於 Arch 用户軟件庫（AUR）。

8、Artix Linux ​

Artix Linux 也是一個基於 Arch Linux 的滾動發行版，它使用 OpenRC、runit 或 s6 作為初始化工具而不是 systemd。

Artix Linux 有自己的軟件庫，但作為一個基於 pacman 的發行版，它可以使用 Arch Linux 軟件庫或任何其他衍生發行版的軟件包，甚至可以使用明確依賴於 systemd 的軟件包。也可以使用 Arch 用户軟件庫（AUR）。

9、BlackArch Linux ​

BlackArch 是一個基於 Arch Linux 的 滲透測試發行版，它提供了大量的網絡安全工具。它是專門為滲透測試人員和安全研究人員創建的。該軟件庫包含 2400 多個黑客和滲透測試工具 ，可以單獨安裝，也可以分組安裝。BlackArch Linux 兼容現有的 Arch Linux 包。

想要真正的原版 Arch Linux 嗎？可以使用圖形化 Arch 安裝程序簡化安裝 ​

如果你想使用原版的 Arch Linux，但又被它困難的安裝所難倒。幸運的是，你可以下載一個帶有圖形安裝程序的 Arch Linux ISO。

Arch 安裝程序基本上是 Arch Linux ISO 的一個相對容易使用的基於文本的安裝程序。它比裸奔的 Arch 安裝容易得多。

Anarchy Installer ​

Anarchy installer 打算為新手和有經驗的 Linux 用户提供一種簡單而無痛苦的方式來安裝 ArchLinux。在需要的時候安裝，在需要的地方安裝，並且以你想要的方式安裝。這就是 Anarchy 的哲學。

啓動安裝程序後，將顯示一個簡單的 TUI 菜單，列出所有可用的安裝程序選項。

Zen Installer ​

Zen Installer 為安裝 Arch Linux 提供了一個完整的圖形（點擊式）環境。它支持安裝多個桌面環境 、AUR 以及 Arch Linux 的所有功能和靈活性，並且易於圖形化安裝。

ISO 將引導一個臨場環境，然後在你連接到互聯網後下載最新穩定版本的安裝程序。因此，你將始終獲得最新的安裝程序和更新的功能。

總結 ​

對於許多用户來説，基於 Arch 的發行版會是一個很好的無憂選擇，而像 Anarchy 這樣的圖形化安裝程序至少離原版的 Arch Linux 更近了一步。

在我看來，Arch Linux 的真正魅力在於它的安裝過程，對於 Linux 愛好者來説，這是一個學習的機會，而不是麻煩。Arch Linux 及其衍生產品有很多東西需要你去折騰，但是在折騰的過程中你就會進入到開源軟件的世界，這裏是神奇的新世界。下次再見！
