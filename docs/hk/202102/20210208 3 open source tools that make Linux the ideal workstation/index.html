讓 Linux 成為理想的工作站的 3 個開源工具 ​

Linux 不但擁有你認為所需的一切，還有更多可以讓你高效工作的工具。

在 2021 年，有更多讓人們喜歡 Linux 的理由。在這個系列中，我將分享 21 種使用 Linux 的不同理由。今天，我將與你分享為什麼 Linux 是你工作的最佳選擇。

每個人都希望在工作期間提高工作效率。如果你的工作通常涉及到文檔、演示文稿和電子表格的工作，那麼你可能已經習慣了特定的例行工作。問題在於，這個慣常的例行工作通常是由一兩個特定的應用程序決定的，無論是某個辦公套件還是桌面操作系統。當然，習慣並不意味着它是理想的，但是它往往會毫無疑義地持續存在，甚至影響到企業的運作架構。

更聰明地工作 ​

如今，許多辦公應用程序都在雲端運行，因此如果你願意的話，你可以在 Linux 上使用相同的方式。然而，由於許多典型的知名辦公應用程序並不符合 Linux 上的文化預期，因此你可能會發現自己受到啓發，想去探索其他的選擇。正如任何渴望走出“舒適區”的人所知道的那樣，這種微妙的打破可能會出奇的有用。很多時候，你不知道自己效率低下，因為你實際上並沒有嘗試過以不同的方式做事。強迫自己去探索其他方式，你永遠不知道會發現什麼。你甚至不必完全知道要尋找的內容。

LibreOffice ​

Linux（或任何其他平台）上顯而易見的開源辦公主力之一是 LibreOffice。它具有多個組件，包括文字處理器、演示軟件、電子表格、關係型資料庫界面、矢量繪圖等。它可以從其他流行的辦公應用程序中導入許多文檔格式，因此從其他工具過渡到 LibreOffice 通常很容易。

然而，LibreOffice 不僅僅是一個出色的辦公套件。LibreOffice 支持宏，所以機智的用户可以自動完成重複性任務。它還具有終端命令的功能，因此你可以在不啓動 LibreOffice 界面的情況下執行許多任務。

想像一下，比如要打開 21 個文檔，導航到文件菜單，到導出或打印菜單項，並將文件導出為 PDF 或 EPUB。這至少需要 84 次以上的點擊，可能要花費一個小時的時間。相比之下，打開一個文檔文件夾，並轉換所有文件為 PDF 或 EPUB，只需要執行一個迅速的命令或菜單操作。轉換將在後台運行，而你可以處理其他事情。只需要四分之一的時間，可能更少。

$ libreoffice --headless --convert-to epub *.docx

這是一個小改進，是由 Linux 工具集和你可以自定義環境和工作流程的便利性所潛在帶來的鼓勵。

Abiword 和 Gnumeric ​

有時，你並不需要一個大而全的辦公套件。如果你喜歡簡化你的辦公室工作，那麼使用一個輕量級和針對特定任務的應用程序可能更好。例如，我大部分時間都是用文本編輯器寫文章，因為我知道在轉換為 HTML 的過程中，所有的樣式都會被丟棄。但有些時候，文字處理器是很有用的，無論是打開別人發給我的文檔，還是因為我想用一種快速簡單的方法來生成一些樣式漂亮的文本。

Abiword 是一款簡單的文字處理器，它基本支持流行的文檔格式，並具備你所期望的文字處理器的所有基本功能。它並不意味着是一個完整的辦公套件，這是它最大的特點。雖然沒有太多的選擇，但我們仍然處於信息過載的時代，這正是一個完整的辦公套件或文字處理器有時會犯的錯誤。如果你想避免這種情況，那就用一些簡單的東西來代替。

同樣，Gnumeric 項目提供了一個簡單的電子表格應用程序。Gnumeric 避免了任何嚴格意義上的電子表格所不需要的功能，所以你仍然可以獲得強大的公式語法、大量的函數，以及樣式和操作單元格的所有選項。我不怎麼使用電子表格，所以我發現自己在極少數需要查看或處理分類賬中的數據時，對 Gnumeric 相當滿意。

Pandoc ​

通過專門的命令和文件處理程序，可以最小化。pandoc 命令專門用於文件轉換。它就像 libreoffice --headless 命令一樣，只是要處理的文檔格式數量是它的十倍。你甚至可以用它來生成演示文稿! 如果你的工作之一是從一個文檔中提取源文本，並以多種格式交付它，那麼 Pandoc 是必要的，所以你應該下載我們的攻略看看。

廣義上講，Pandoc 代表的是一種完全不同的工作方式。它讓你脱離了辦公應用的束縛。它將你從試圖將你的想法寫成文字，並同時決定這些文字應該使用什麼字體的工作中分離出來。在純文本中工作，然後轉換為各種交付格式，讓你可以使用任何你想要的應用程序，無論是移動設備上的記事本，還是你碰巧坐在電腦前的簡單文本編輯器，或者是雲端的文本編輯器。

尋找替代品 ​

Linux 有很多意想不到的替代品。你可以從你正在做的事情中退後一步，分析你的工作流程，評估你所需的結果，並調查那些聲稱可以完全你的需求的新應用程序來找到它們。

改變你所使用的工具、工作流程和日常工作可能會讓你迷失方向，特別是當你不知道你要找的到底是什麼的時候。但 Linux 的優勢在於，你有機會重新評估你在多年的計算機使用過程中潛意識裏形成的假設。如果你足夠努力地尋找答案，你最終會意識到問題所在。通常，你最終會欣賞你學到的東西。
