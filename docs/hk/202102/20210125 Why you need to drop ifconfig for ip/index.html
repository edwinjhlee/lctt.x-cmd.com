放棄 ifconfig，擁抱 ip 命令 ​

開始使用現代方法配置 Linux 網絡接口。

在很長一段時間內，ifconfig 命令是配置網絡接口的默認方法。它為 Linux 用户提供了很好的服務，但是網絡很複雜，所以配置網絡的命令必須健壯。ip 命令是現代系統中新的默認網絡命令，在本文中，我將向你展示如何使用它。

ip 命令工作在 OSI 網絡棧 的兩個層上：第二層（數據鏈路層）和第三層（網絡 或 IP）層。它做了之前 net-tools 包的所有工作。

安裝 ip ​

ip 命令包含在 iproute2util 包中，它可能已經在你的 Linux 發行版中安裝了。如果沒有，你可以從發行版的倉庫中進行安裝。

ifconfig 和 ip 使用對比 ​

ip 和 ifconfig 命令都可以用來配置網絡接口，但它們做事方法不同。接下來，作為對比，我將用它們來執行一些常見的任務。

添加 IP 地址 ​

使用 ifconfig 命令添加 IP 地址命令為：

$ ifconfig eth0 add 192.9.203.21

ip 類似：

$ ip address add 192.9.203.21 dev eth0

ip 中的子命令可以縮短，所以下面這個命令同樣有效：

$ ip addr add 192.9.203.21 dev eth0

你甚至可以更短些：

$ ip a add 192.9.203.21 dev eth0

移除一個 IP 地址 ​

添加 IP 地址與刪除 IP 地址正好相反。

使用 ifconfig，命令是：

$ ifconfig eth0 del 192.9.203.21

ip 命令的語法是：

$ ip a del 192.9.203.21 dev eth0

啓用或禁用組播 ​

使用 ifconfig 接口來啓用或禁用 組播multicast：

# ifconfig eth0 multicast

對於 ip，使用 set 子命令與設備（dev）以及一個布爾值和 multicast 選項：

# ip link set dev eth0 multicast on

啓用或禁用網絡 ​

每個系統管理員都熟悉“先關閉，然後打開”這個技巧來解決問題。對於網絡接口來説，即打開或關閉網絡。

ifconfig 命令使用 up 或 down 關鍵字來實現：

# ifconfig eth0 up

或者你可以使用一個專用命令：

# ifup eth0

ip 命令使用 set 子命令將網絡設置為 up 或 down 狀態：

# ip link set eth0 up

開啓或關閉地址解析功能（ARP） ​

使用 ifconfig，你可以通過聲明它來啓用：

# ifconfig eth0 arp

使用 ip，你可以將 arp 屬性設置為 on 或 off：

# ip link set dev eth0 arp on

ip 和 ipconfig 的優缺點 ​

ip 命令比 ifconfig 更通用，技術上也更有效，因為它使用的是 Netlink 套接字，而不是 ioctl 系統調用。

ip 命令可能看起來比 ifconfig 更詳細、更復雜，但這是它擁有更多功能的一個原因。一旦你開始使用它，你會了解它的內部邏輯（例如，使用 set 而不是看起來隨意混合的聲明或設置）。

最後，ifconfig 已經過時了（例如，它缺乏對網絡命名空間的支持），而 ip 是為現代網絡而生的。嘗試並學習它，使用它，你會由衷高興的！
