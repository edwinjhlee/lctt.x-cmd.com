不習慣在終端使用 youtube-dl？可以使用這些 GUI 應用 ​

如果你一直在關注我們，可能已經知道 youtube-dl 項目曾被 GitHub 暫時下架 以合規。但它現在已經恢復並完全可以訪問，可以説它並不是一個非法的工具。

它是一個非常有用的命令列工具，可以讓你 從 YouTube 和其他一些網站下載視頻。使用 youtube-dl 並不複雜，但我明白使用命令來完成這種任務並不是每個人都喜歡的方式。

好在有一些應用為 youtube-dl 工具提供了 GUI 前端。

使用 youtube-dl GUI 應用的先決條件 ​

在你嘗試下面提到的一些選擇之前，你可能需要在你的系統上安裝 youtube-dl 和 FFmpeg，才能夠下載/選擇不同的格式進行下載。

你可以按照我們的 ffmpeg 使用完整指南 進行設置，並探索更多關於它的內容。

要安裝 youtube-dl，你可以在 Linux 終端輸入以下命令：

sudo curl -L https://yt-dl.org/downloads/latest/youtube-dl -o /usr/local/bin/youtube-dl

下載最新版本後，你只需要輸入以下內容使其可執行就可使用：

sudo chmod a+rx /usr/local/bin/youtube-dl

如果你需要其他方法安裝它，也可以按照官方安裝説明進行安裝。

Youtube-dl GUI 應用 ​

大多數 Linux 上的下載管理器也允許你從 YouTube 和其他網站下載視頻。然而，youtube-dl GUI 應用可能有額外的選項，如只提取音頻或下載特定分辨率和視頻格式。

請注意，下面的列表沒有特別的排名順序。你可以根據你的要求選擇。

1、AllTube Download ​

主要特點：

  • Web GUI
  • 開源
  • 可以自託管

AllTube 是一個開源的 web GUI，你可以通過 https://alltubedownload.net/ 來訪問。

如果你選擇使用這款軟件，你不需要在系統上安裝 youtube-dl 或 ffmpeg。它提供了一個簡單的用户界面，你只需要粘貼視頻的 URL，然後繼續選擇你喜歡的文件格式下載。你也可以選擇將其部署在你的服務器上。

請注意，你不能使用這個工具提取視頻的 MP3 文件，它只適用於視頻。你可以通過他們的 GitHub 頁面探索更多關於它的信息。

  • AllTube Download Web GUI

2、youtube-dl GUI ​

主要特點：

  • 跨平台
  • 顯示預計下載大小
  • 有音頻和視頻下載選擇

一個使用 electron 和 node.js 製作的有用的跨平台 GUI 應用。你可以很容易地下載音頻和視頻，以及選擇各種可用的文件格式的選項。

如果你願意的話，你還可以下載一個頻道或播放列表的部分內容。特別是當你下載高質量的視頻文件時，預計的下載大小絕對是非常方便的。

如上所述，它也適用於 Windows 和 MacOS。而且，你會在它的 GitHub 發佈中得到一個適用於 Linux 的 AppImage 文件。

  • Youtube-dl GUI

3、Videomass ​

主要特點：

  • 跨平台
  • 轉換音頻/視頻格式
  • 支持多個 URL
  • 適用於也想使用 FFmpeg 的用户

如果你想從 YouTube 下載視頻或音頻，並將它們轉換為你喜歡的格式，Videomass 可以是一個不錯的選擇。

要做到這點，你需要在你的系統上同時安裝 youtube-dl 和 ffmpeg。你可以輕鬆的添加多個 URL 來下載，還可以根據自己的喜好設置輸出目錄。

你還可以獲得一些高級設置來禁用 youtube-dl，改變文件首選項，以及隨着你的探索，還有一些更方便的選項。

它為 Ubuntu 用户提供了一個 PPA，為任何其他 Linux 發行版提供了一個 AppImage 文件。在它的 Github 頁面探索更多信息。

  • Videomass

附送：Haruna Video Player ​

主要特點：

  • 播放/流式傳輸 YouTube 視頻

Haruna Video Player 原本是 MPV 的前端。雖然使用它不能下載 YouTube 視頻，但可以通過 youtube-dl 觀看/流式傳輸 YouTube 視頻。

你可以在我們的文章中探索更多關於視頻播放器的內容。

總結 ​

儘管你可能會在 GitHub 和其他平台上找到更多的 youtube-dl GUI，但它們中的大多數都不能很好地運行，最終會顯示出多個錯誤，或者不再積極開發。

Tartube 就是這樣的一個選擇，你可以嘗試一下，但可能無法達到預期的效果。我用 Pop!_OS 和 Ubuntu MATE 20.04（全新安裝）進行了測試。每次我嘗試下載一些東西時，無論我怎麼做都會失敗（即使系統中安裝了 youtube-dl 和 ffmpeg）。

所以，我個人最喜歡的似乎是 Web GUI（AllTube Download），它不依賴於安裝在你係統上的任何東西，也可以自託管。

如果我錯過了你最喜歡的選擇，請在評論中告訴我什麼是最適合你的。
