如何在 Ubuntu 16.04 和 Fedora 22-24 上安裝最新的 XFCE 桌面？ ​

Xfce 是一款針對 Linux 系統的現代化輕型開源桌面環境，它在其他的類 Unix 系統上，比如 Mac OS X、 Solaries、 *BSD 以及其它幾種上也能工作得很好。它非常快並以簡潔而優雅的用户界面展現了用户友好性。

在服務器上安裝一個桌面環境有時還是有用的，因為某些應用程序可能需要一個桌面界面，以便高效而可靠的管理。 Xfce 的一個卓越的特性是其內存消耗等系統資源佔用率很低，因此，如果服務器需要一個桌面環境的話它會是首選。

XFCE 桌面的功能特性 ​

另外，它的一些值得注意的組件和功能特性列在下面：

  • Xfwm 窗口管理器
  • Thunar 文件管理器
  • 用户會話管理器：用來處理用户登錄、電源管理之類
  • 桌面管理器：用來設置背景圖片、桌面圖標等等
  • 應用管理器
  • 它的高度可連接性以及一些其他次要功能特性

Xfce 的最新穩定發行版是 Xfce 4.12，它所有的功能特性和與舊版本的變化都列在了這兒。

在 Ubuntu 16.04 上安裝 Xfce 桌面 ​

Linux 發行版，比如 Xubuntu、Manjaro、OpenSUSE、Fedora Xfce Spin、Zenwalk 以及許多其他發行版都提供它們自己的 Xfce 桌面安裝包，但你也可以像下面這樣安裝最新的版本。

$ sudo apt update
$ sudo apt install xfce4

等待安裝過程結束，然後退出當前會話，或者你也可以選擇重啓系統。在登錄界面，選擇 Xfce 桌面，然後登錄，截圖如下：

在 Fedora 22-24 上安裝 Xfce 桌面 ​

如果你已經有一個安裝好的 Linux 發行版 Fedora，想在上面安裝 xfce 桌面，那麼你可以使用如下所示的 yum 或 dnf 命令。

-------------------- 在 Fedora 22 上 --------------------
# yum install @xfce
-------------------- 在 Fedora 23-24 上 --------------------
# dnf install @xfce-desktop-environment

安裝 Xfce 以後，你可以從會話菜單選擇 Xfce 登錄或者重啓系統。

如果你不再想要 Xfce 桌面留在你的系統上，那麼可以使用下面的命令來卸載它：

-------------------- 在 Ubuntu 16.04 上 -------------------- 
$ sudo apt purge xfce4
$ sudo apt autoremove
-------------------- 在 Fedora 22 上 -------------------- 
# yum remove @xfce
-------------------- 在 Fedora 23-24 上 --------------------
# dnf remove @xfce-desktop-environment

在這個簡單的入門指南中，我們講解了如何安裝最新版 Xfce 桌面的步驟，我相信這很容易掌握。如果一切進行良好，你可以享受一下使用 xfce —— 這個 Linux 系統上最佳桌面環境之一。
