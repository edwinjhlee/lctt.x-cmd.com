對比 Android 和 iPhone 的優缺點 ​

當我們比較 Android 與 iPhone 的時候，很顯然 Android 具有一定的優勢，而 iPhone 則在一些關鍵方面更好。但是，究竟哪個比較好呢？

對 Android 與 iPhone 比較是個個人的問題。

就好比我來説，我兩個都用。我深知這兩個平台的優缺點。所以，我決定分享我關於這兩個移動平台的觀點。另外，然後談談我對新的 Ubuntu 移動平台的印象和它的優勢。

iPhone 的優點 ​

雖然這些天我是個十足的 Android 用户，但我必須承認 iPhone 在某些方面做的是不錯。首先，蘋果公司在他們的設備更新方面有更好的成績。這對於運行着 iOS 的舊設備來説尤其是這樣。反觀 Android ，如果不是谷歌親生的 Nexus，它最好也不過是一個更高端的運營商支持的手機，你將發現它們的更新少的可憐或者根本沒有。

其中 iPhone 做得很好的另一個領域是應用程序的可用性。展開來説，iPhone 應用程序幾乎總是有一個簡潔的外觀。這並不是説 Android 應用程序就是醜陋的，而是，它們可能只是沒有像 iOS 上一樣的保持不變的操控習慣和一以貫之的用户體驗。兩個典型的例子， Dark Sky (天氣)和 Facebook Paper 很好表現了 iOS 獨有的佈局。

再有就是備份過程。 Android 可以備份，默認情況下是備份到谷歌。但是對應用數據起不了太大作用。對比 iPhone ，iCloud 基本上可以對你的 iOS 設備進行了完整備份。

iPhone 令我失望的地方 ​

對 iPhone 來説，最無可爭辯的問題是它的硬件限制要比軟件限制更大，換句話來説，就是存儲容量問題。

你看，對於大多數 Android 手機，我可以買一個容量較小的手機，然後以後可以添加 SD 卡。這意味着兩件事：第一，我可以使用 SD 卡來存儲大量的媒體文件。其次，我甚至可以用 SD 卡來存儲“一些”我的應用程序。而蘋果完全不能這麼做。

另一個 iPhone 讓我失望的地方是它提供的選擇很少。備份您的設備？希望你喜歡 iTunes 或 iCloud 吧。但對一些像我一樣用 Linux 的人，那就意味着，我唯一的選擇便是使用 iCloud。

要公平的説，如果你願意越獄，你的 iPhone 還有一些其他解決方案的，但這並不是這篇文章所講的。 Android 的 解鎖 root 也一樣。本文章針對的是兩個平台的原生設置。

最後，讓我們不要忘記這件看起來很小的事—— iTunes 會刪掉用户的音樂，因為它認為和蘋果音樂的內容重複了……或者因為一些其它的類似規定。這不是 iPhone 特有的情況？我不同意，因為那些音樂最終就是在 iPhone 上沒有了。我能十分肯定地這麼説，是因為不管在哪裏我都不會説這種謊話。

Android 和 iPhone 的對決取決於什麼功能對你來説最重要。

Android 的優點 ​

Android 給我最大的好處就是 iPhone 所提供不了的：選擇。這包括對應用程序、設備以及手機是整體如何工作的選擇。

我愛桌面小工具！對於 iPhone 用户來説，它們也許看上去很蠢。但我可以告訴你，它們可以讓我不用打開應用程序就可以看到所需的數據，而無需額外的麻煩。另一個類似的功能，我喜歡安裝定製的桌面界面，而不是我的手機默認的那個！

最後，我可以通過像 Airdroid 和 Tasker 這樣的工具給我的智能手機添加計算機級的完整功能。AirDroid 可以讓我把我的 Android 手機當成帶有一個文件管理和通信功能的計算機——這可以讓我可以輕而易舉的使用鼠標和鍵盤。Tasker 更厲害，我可以用它讓我手機根據環境變得可聯繫或不可聯繫，當我設置好了之後，當我到會議室之後我的手機就會自己進入會議模式，甚至變成省電模式。我還可以設置它當我到達特定的目的地時自動啓動某個應用程序。

Android 讓我失望的地方 ​

Android 備份選項僅限於特定的用户數據，而不是手機的完整克隆。如果不解鎖 root，要麼你只能聽之任之，要麼你必須用 Android SDK 來解決。期望普通用户會解鎖 root 或運行 SDK 來完成備份（我的意思是一切都備份）顯然是一個笑話。

是的，谷歌的備份服務會備份谷歌應用程序的數據、以及其他相關的自定義設置。但它是遠不及我們所看到的蘋果服務一樣完整。為了完成類似於蘋果那樣的功能，我發現你就要麼必須解鎖 root ，要麼將其連接到一個在 PC 機上使用一些不知道是什麼的軟件來幹這個。

不過，公平的説，我知道使用 Nexus 的人能從該設備特有的完整備份服務中得到幫助。對不起，但是谷歌的默認備份方案是不行的。對於通過在 PC 上使用 adb (Android Debug Bridge) 來備份也是一樣的——不會總是如預期般的恢復。

等吧，它會變好的。經過了很多失敗的失望和挫折之後，我發現有一個應用程序，看起來它“可能”提供了一點點微小的希望，它叫 Helium 。它不像我發現的其他應用程序那樣擁有誤導性的和令人沮喪的侷限性，Helium 最初看起來像是谷歌應該一直提供的備份應用程序——注意，只是“看起來像”。可悲的是，它絆了我一跤。第一次運行時，我不僅需要將它連接到我的計算機上，甚至使用他們提供的 Linux 腳本都不工作。在刪除他們的腳本後，我弄了一個很好的老式 adb 來備份到我的 Linux PC 上。你可能要知道的是：你需要在開發工具裏打開一籮筐東西，而且如果你運行 Twilight 應用的話還要關閉它。當 adb 的備份選項在我的手機上不起作用時，我花了一點時間把這個搞好了。

最後，Android 為非 root 用户也提供了可以輕鬆備份一些如聯繫人、短信等簡單東西的選擇。但是，要深度手機備份的話，以我經驗還是通過有線連接和 adb。

Ubuntu 能拯救我們嗎？ ​

在手機領域，通過對這兩大玩家之間的優劣比較，我們很期望從 Ubuntu 看到更好的表現。但是，迄今為止，它的表現相當低迷。

我喜歡開發人員基於這個操作系統正在做的那些努力，我當然想在 iPhone 和 Android 手機之外有第三種選擇。但是不幸的是，它在手機和平板上並不受歡迎，而且由於硬件的低端以及在 YouTube 上的糟糕的演示，有很多不好的傳聞。

公平來説，我在以前也用過 iPhone 和 Android 的低端機，所以這不是對 Ubuntu 的挖苦。但是它要表現出準備與 iPhone 和 Android 相競爭的功能生態時，那就另説了，這還不是我現在特別感興趣的東西。在以後的日子裏，也許吧，我會覺得 Ubuntu 手機可以滿足我的需要了。

###Android 與 iPhone 之爭：為什麼 Android 將終究贏得勝利

忽視 Android 那些痛苦的缺點，它起碼給我了選擇。它並沒有把我限制在只有兩種備份數據的方式上。是的，一些 Android 的限制事實上是由於它的關注點在於讓我選擇如何處理我的數據。但是，我可以選擇我自己的設備，想加內存就加內存。Android 可以我讓做很多很酷的東西，而 iPhone 根本就沒有能力這些事情。

從根本上來説， Android 給非 root 用户提供了訪問手機功能的更大自由。無論是好是壞，這是人們想要的一種自由。現在你們其中有很多 iPhone 的粉絲應該感謝像 libimobiledevice 這樣項目帶來的影響。看看蘋果阻止 Linux 用户所做的事情……然後問問你自己：作為一個 Linux 用户這真的值得嗎？
