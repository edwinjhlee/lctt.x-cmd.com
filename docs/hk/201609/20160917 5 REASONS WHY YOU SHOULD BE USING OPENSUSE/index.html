你該選擇 openSUSE 的五大理由 ​

多數的的桌面 Linux 用户都會選擇三種發行版本：Debian/Ubuntu、Fedora 或者 Arch Linux。但是今天，我將給出你需要使用 openSUSE 的五大理由。

相比其他的 Linux 發行版，我總能在 openSUSE 上看到一些令人耳目一新的東西。我説不太好，但它總是如此的閃亮和個性鮮明。這綠色的大蜥蜴是看起來如此的令人驚歎！但這並不是 openSUSE 即便不是最好也是要比其它發行版更好的原因！

請別誤解我。我在各種場合用過許多不同的 Linux 發行版，同時也很敬佩在這些發行版背後默默工作的開發者，是他們讓計算變成一件快樂的事情。但是 openSUSE 一直讓人感覺，嗯，令人崇敬——你是不是也這樣覺得？

openSUSE 比其他 Linux 發行版要好的五大理由 ​

你是不是認為我在説 openSUSE 是最好的 Linux 發行版？不，我並不是要表達這個意思。其實沒有任何一個 Linux 發行版是最好的。它真的可以滿足你尋找 “靈魂伴侶” 的需求。

但在這裏，我準備給大家説説，openSUSE 比其他發行版做得要好的五件事。如下：

#1 社區規則 ​

openSUSE 是一個典型的社區驅動型項目。我經常看到很多用户在升級後抱怨開發人員改變了他們喜歡的發行版。但在 openSUSE 不是這樣，openSUSE 是純社區驅動的項目，並且任何時候都朝着用户所希望的方向發展。

#2 系統的健壯性 ​

另外一個是操作系統的集成程度。我可以在同一個 openSUSE 系統上安裝所有的最好的 Linux 桌面環境，而在 Ubuntu 上則因為系統的穩定性，堅決不允許用户這樣做。而這恰好體現了一個系統的健壯程度。因此，對於那些喜歡自己動手完成每一件事的用户，openSUSE 還是很誘人的。

#3 易於安裝軟件 ​

在 Linux 的世界裏有很多非常好用的包管理工具。從 Debian 的 apt-get 到 Fedora 的 DNF，它們無不吸引着用户，而且在這些發行版成為流行版本的過程中扮演着重要角色。

openSUSE 同樣有一個將軟件傳遞到桌面的好方法。software.opensuse.org 是一個 Web 界面，你可以用它從倉庫中獲取安裝軟件。你所需要做的就是打開這個鏈接 (當然，是在 openSUSE 系統上)，在搜索框中輸入你想要的軟件，點擊“直接安裝”即可。就是這麼簡單，不是嗎？

聽起來就像是在使用 Google 商店一樣，是嗎？

#4 YAST ​

毫不誇張的説，YaST (LCTT 譯註: YaST 是 openSUSE 和 SUSE Linux 企業版的安裝和配置工具) 絕對是世界上有史以來操作系統上最好的控制中心。並且毫無疑問地，你可以使用它來操控系統上的一切：網絡、軟件升級以及所有的基礎設置等。無論是 openSUSE 的個人版或是 SUSE Linux 企業版，你都能在 YaST 的強力支撐下，輕鬆的完成安裝。總之，一個工具，方便而無所不能。

#5 開箱即用的極致體驗 ​

SUSE 的團隊是 Linux 內核中最大的貢獻者團體之一。他們辛勤的努力也意味着，他們有足夠的經驗來應付不同的硬件條件。

有着良好的硬件支持，一定會有很棒的開箱即用的體驗。

#6 他們做了一些搞笑視頻 ​

等等，不是説好了是五個理由嗎？怎麼多了一個！

但因為 Abhishek 逼着我加進來，因為他們做的 Linux 的搞笑視頻才使 openSUSE 成為了最好的發行版。

開了個玩笑，不過還是看看 Uptime Funk，你將會知道為什麼 SUSE 是最酷的 Linux 。

LEAP 還是 TUMBLEWEED？該用哪一個！ ​

如果你現在想要使用 openSUSE 了，讓我來告訴你，這兩個 openSUSE 版本：LEAP 和 TUMBLEWEED。哪一個更合適你一點。

儘管兩者都提供了相似的體驗和相似的環境，但還是需要你自行決定安裝那個版本到你硬盤上。

OPENSUSE : LEAP ​

openSUSE Leap 是一個普通的大眾版本，基本上每八個月更新一次。目前最新的版本是 openSUSE 42.1。它所有的軟件都是穩定版，給用户提供最順暢的體驗。

對於家庭用户、辦公和商業用户，是再合適不過的了。它合適那些想要一個穩定系統，而不必事事親為，可以讓他們安心工作的用户。只要進行正確的設置之後，你就不必擔心其他事情，然後專心投入工作就好。同時，我也強烈建議圖書館和學校使用 Leap。

OPENSUSE: TUMBLEWEED ​

Tumbleweed version of openSUSE 是滾動式更新的版本。它定期更新系統中所使用的軟件集的最新版本。對於想要使用最新軟件以及想向 openSUSE 做出貢獻的開發者和高級用户來説，這個版本絕對值得一試。

需要指出的是，Tumbleweed 並不是 Leap 的 beta 和 測試版本 。它是最新鋭的 Linux 穩定發行版。

Tumbleweed 給了你最快的更新，但是僅在開發者確定某個包的穩定性之後才行。
