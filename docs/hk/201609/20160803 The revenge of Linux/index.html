Linux 的逆襲 ​

Linux 系統在早期的時候被人們嘲笑，它什麼也幹不了。而現在，Linux 無處不在！

我當時還是個在巴西學習計算機工程的大三學生，並同時在一個全球審計和顧問公司兼職系統管理員。公司決定用 Oracle 資料庫開發一些企業資源計劃（ERP）軟件。因此，我得以在 Digital UNIX OS (DEC Alpha) 進行訓練，這個訓練顛覆了我的三觀。

UNIX 系統非常的強大，而且給予了我們對機器上包括存儲系統、網絡、應用和其他一切的絕對控制權。

我開始在 ksh 和 Bash 裏編寫大量的腳本讓系統進行自動備份、文件傳輸、提取轉換加載（ETL）操作、自動化 DBA 日常工作，還為各種不同的項目創建了許多服務。此外，調整資料庫和操作系統的工作讓我更好的理解了如何讓服務器以最佳方式運行。在那時，我在自己的個人電腦上使用的是 Windows 95 系統，而我非常想要在我的個人電腦裏放進一個 Digital UNIX，或者哪怕是 Solaris 或 HP-UX 也行，但是那些 UNIX 系統都得在特定的硬件才能上運行。我閲讀了所有的系統文檔，還找過其它的書籍以求獲得更多的信息，也在我們的開發環境裏對這些瘋狂的想法進行了實驗。

後來在大學裏，我從我的同事那聽説了 Linux。我那時非常激動的從還在用撥號方式連接的因特網上下載了它。在我的正宗的個人電腦裏裝上 UNIX 這類系統的這個想法真是太酷了！

Linux 不同於 UNIX 系統，它設計用來在各種常見個人電腦硬件上運行，在起初，讓它開始工作確實有點困難，Linux 針對的用户羣只有系統管理員和極客們。我為了讓它能運行，甚至用 C 語言修改了驅動軟件。我之前使用 UNIX 的經歷讓我在編譯 Linux 內核，排錯這些過程中非常的順手。由於它不同於那些只適合特定硬件配置的封閉系統，所以讓 Linux 跟各種意料之外的硬件配置一起工作真的是件非常具有挑戰性的事。

我曾見過 Linux 在數據中心獲得一席之地。一些具有冒險精神的系統管理員使用它來幫他們完成每天監視和管理基礎設施的工作，隨後，Linux 作為 DNS 和 DHCP 服務器、打印管理和文件服務器等贏得了更多的使用。企業曾對 Linux 有着很多顧慮（恐懼，不確定性，懷疑(FUD:fear, uncertainty and doubt)）和詬病：誰是它的擁有者？由誰來支持它？有適用於它的應用嗎？

但現在看來，Linux 在各個地方進行着逆襲！從開發者的個人電腦到大企業的服務器；我們能在智能手機、智能手錶以及像樹莓派這樣的物聯網（IoT）設備裏找到它。甚至 Mac OS X 有些命令跟我們所熟悉的命令一樣。微軟在製造它自己的發行版，在 Azure 上運行，然後…… Windows 10 要裝備 Bash。

有趣的是 IT 市場會不斷地創造並迅速的用新技術替代，但是我們所掌握的 Digital UNIX、HP-UX 和 Solaris 這些舊系統的知識還依然有效並跟 Linux 息息相關，不論是為了工作還是玩。現在我們能完全的掌控我們的系統，並使它發揮最大的效用。此外，Linux 有個充滿熱情的社區。

我真的建議想在計算機方面發展的年輕人學習 Linux，不論你處於 IT 界裏的哪個分支。如果你深入瞭解了一個普通的家用個人電腦是如何工作的，你就可以以基本相同的方式來面對任何機器。你可以通過 Linux 學習最基本的計算機知識，並通過它建立能在 IT 界任何地方都有用的能力！

via: https://opensource.com/life/16/8/revenge-linux
