9 個提高系統運行速度的輕量級 Linux 應用 ​

簡介： 加速 Ubuntu 系統有很多方法，辦法之一是使用輕量級應用來替代一些常用應用程序。我們之前之前發佈過一篇 Linux 必備的應用程序，如今將分享這些應用程序在 Ubuntu 或其他 Linux 發行版的輕量級替代方案。

9 個常用 Linux 應用程序的輕量級替代方案 ​

你的 Linux 系統很慢嗎？應用程序是不是很久才能打開？你最好的選擇是使用輕量級的 Linux 系統。但是重裝系統並非總是可行，不是嗎？

所以如果你想堅持使用你現在用的 Linux 發行版，但是想要提高性能，你應該使用更輕量級應用來替代你一些常用的應用。這篇文章會列出各種 Linux 應用程序的輕量級替代方案。

由於我使用的是 Ubuntu，因此我只提供了基於 Ubuntu 的 Linux 發行版的安裝説明。但是這些應用程序可以用於幾乎所有其他 Linux 發行版。你只需去找這些輕量級應用在你的 Linux 發行版中的安裝方法就可以了。

1. Midori： Web 瀏覽器 ​

Midori 是與現代互聯網環境具有良好兼容性的最輕量級網頁瀏覽器之一。它是開源的，使用與 Google Chrome 最初所基於的相同的渲染引擎 —— WebKit。並且超快速，最小化但高度可定製。

Midori 瀏覽器有很多可以定製的擴展和選項。如果你有最高權限，使用這個瀏覽器也是一個不錯的選擇。如果在瀏覽網頁的時候遇到了某些問題，請查看其網站上常見問題部分 -- 這包含了你可能遇到的常見問題及其解決方案。

在基於 Ubuntu 的發行版上安裝 Midori ​

在 Ubuntu 上，可通過官方源找到 Midori 。運行以下指令即可安裝它：

sudo apt install midori

2. Trojita：電子郵件客户端 ​

Trojita 是一款開源強大的 IMAP 電子郵件客户端。它速度快，資源利用率高。我可以肯定地稱它是 Linux 最好的電子郵件客户端之一。如果你只需電子郵件客户端提供 IMAP 支持，那麼也許你不用再進一步考慮了。

Trojita 使用各種技術 —— 按需電子郵件加載、離線緩存、帶寬節省模式等 —— 以實現其令人印象深刻的性能。

在基於 Ubuntu 的發行版上安裝 Trojita ​

Trojita 目前沒有針對 Ubuntu 的官方 PPA 。但這應該不成問題。您可以使用以下命令輕鬆安裝它:

sudo sh -c "echo 'deb http://download.opensuse.org/repositories/home:/jkt-gentoo:/trojita/xUbuntu_16.04/ /' > /etc/apt/sources.list.d/trojita.list"
wget http://download.opensuse.org/repositories/home:jkt-gentoo:trojita/xUbuntu_16.04/Release.key
sudo apt-key add - < Release.key
sudo apt update
sudo apt install trojita

3. GDebi：包安裝程序 ​

有時您需要快速安裝 DEB 軟件包。Ubuntu 軟件中心是一個消耗資源嚴重的應用程序，僅用於安裝 .deb 文件並不明智。

Gdebi 無疑是一款可以完成同樣目的的漂亮工具，而它只有個極簡的圖形界面。

GDebi 是完全輕量級的，完美無缺地完成了它的工作。你甚至應該讓 Gdebi 成為 DEB 文件的默認安裝程序。

在基於 Ubuntu 的發行版上安裝 GDebi ​

只需一行指令，你便可以在 Ubuntu 上安裝 GDebi：

sudo apt install gdebi

4. App Grid：軟件中心 ​

如果您經常在 Ubuntu 上使用軟件中心搜索、安裝和管理應用程序，則 App Grid 是必備的應用程序。它是默認的 Ubuntu 軟件中心最具視覺吸引力且速度最快的替代方案。

App Grid 支持應用程序的評分、評論和屏幕截圖。

在基於 Ubuntu 的發行版上安裝 App Grid ​

App Grid 擁有 Ubuntu 的官方 PPA。使用以下指令安裝 App Grid：

sudo add-apt-repository ppa:appgrid/stable
sudo apt update
sudo apt install appgrid

5. Yarock：音樂播放器 ​

Yarock 是一個優雅的音樂播放器，擁有現代而最輕量級的用户界面。儘管在設計上是輕量級的，但 Yarock 有一個全面的高級功能列表。

Yarock 的主要功能包括多種音樂收藏、評級、智能播放列表、多種後端選項、桌面通知、音樂剪輯、上下文獲取等。

在基於 Ubuntu 的發行版上安裝 Yarock ​

您得通過 PPA 使用以下指令在 Ubuntu 上安裝 Yarock：

sudo add-apt-repository ppa:nilarimogard/webupd8
sudo apt update
sudo apt install yarock

6. VLC：視頻播放器 ​

誰不需要視頻播放器？誰還從未聽説過 VLC？我想並不需要對它做任何介紹。

VLC 能滿足你在 Ubuntu 上播放各種媒體文件的全部需求，而且它非常輕便。它甚至可以在非常舊的 PC 上完美運行。

在基於 Ubuntu 的發行版上安裝 VLC ​

VLC 為 Ubuntu 提供官方 PPA。可以輸入以下命令來安裝它：

sudo apt install vlc

7. PCManFM：文件管理器 ​

PCManFM 是 LXDE 的標準文件管理器。與 LXDE 的其他應用程序一樣，它也是輕量級的。如果您正在為文件管理器尋找更輕量級的替代品，可以嘗試使用這個應用。

儘管來自 LXDE，PCManFM 也同樣適用於其他桌面環境。

在基於 Ubuntu 的發行版上安裝 PCManFM ​

在 Ubuntu 上安裝 PCManFM 只需要一條簡單的指令：

sudo apt install pcmanfm

8. Mousepad：文本編輯器 ​

在輕量級方面，沒有什麼可以擊敗像 nano、vim 等命令列文本編輯器。但是，如果你想要一個圖形界面，你可以嘗試一下 Mousepad -- 一個最輕量級的文本編輯器。它非常輕巧，速度非常快。帶有簡單的可定製的用户界面和多個主題。

Mousepad 支持語法高亮顯示。所以，你也可以使用它作為基礎的代碼編輯器。

在基於 Ubuntu 的發行版上安裝 Mousepad ​

想要安裝 Mousepad ，可以使用以下指令：

sudo apt install mousepad

9. GNOME Office：辦公軟件 ​

許多人需要經常使用辦公應用程序。通常，大多數辦公應用程序體積龐大且很耗資源。Gnome Office 在這方面非常輕便。Gnome Office 在技術上不是一個完整的辦公套件。它由不同的獨立應用程序組成，在這之中 AbiWord＆Gnumeric 脱穎而出。

AbiWord 是文字處理器。它比其他替代品輕巧並且快得多。但是這樣做是有代價的 —— 你可能會失去宏、語法檢查等一些功能。AdiWord 並不完美，但它可以滿足你基本的需求。

Gnumeric 是電子表格編輯器。就像 AbiWord 一樣，Gnumeric 也非常快速，提供了精確的計算功能。如果你正在尋找一個簡單輕便的電子表格編輯器，Gnumeric 已經能滿足你的需求了。

在 Gnome Office 下面還有一些其它應用程序。你可以在官方頁面找到它們。

在基於 Ubuntu 的發行版上安裝 AbiWord＆Gnumeric ​

要安裝 AbiWord＆Gnumeric，只需在終端中輸入以下指令：

sudo apt install abiword gnumeric
