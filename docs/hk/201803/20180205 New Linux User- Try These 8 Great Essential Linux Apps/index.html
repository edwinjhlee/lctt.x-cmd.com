Linux 新用户？來試試這 8 款重要的軟件 ​

即便您不是計算機的新手，剛接觸 Linux 時，通常都會面臨選擇使用應用軟件的問題。在數百萬 Linux 應用程序中，做起選擇來並不輕鬆。本文中，您將能發現八個重要的 Linux 應用，幫助您快速選擇應用程序。

下面這些應用程序大多不是 Linux 獨有的。如果有過使用 Windows/Mac 的經驗，您很可能會熟悉其中一些軟件。根據興趣和需求，下面的程序可能不全符合您的要求，但是在我看來，清單裏大多數甚至全部的軟件，對於新用户開啓 Linux 之旅都是有幫助的。

相關鏈接 : 每一個 Linux 用户都應該使用的 11 個可移植軟件

1. Chromium 網頁瀏覽器 ​

幾乎不會不需要使用網頁瀏覽器的用户。您可以看到陳舊的 Linux 發行版幾乎都會附帶 Firefox（火狐瀏覽器）或者其他 Linux 瀏覽器，關於瀏覽器，強烈建議您嘗試 Chromium。它是谷歌瀏覽器的開源版。Chromium 的主要優點是速度和安全性。它同樣擁有大量的附加組件。

2. LibreOffice ​

LibreOffice 是一個開源辦公套件，其包括文字處理（Writer）、電子表格（Calc）、演示（Impress）、資料庫（Base）、公式編輯器（Math）、矢量圖和流程圖（Draw）應用程序。它與 Microsoft Office 文檔兼容，如果其基本功能不能滿足需求，您可以使用 LibreOffice 拓展。

LibreOffice 顯然是 Linux 應用中至關重要的一員，如果您使用 Linux 的計算機，安裝它是有必要的。

3. GIMP（GUN 圖像處理程序GNU Image Manipulation Program） ​

GIMP 是一款非常強大的開源圖片處理程序，它類似於 Photoshop。通過 GIMP，您可以編輯或是創建用於 Web 或是打印的光柵圖（位圖）。如果您對專業的圖片處理沒有概念，Linux 自然提供有更簡單的圖像編輯器，GIMP 看上去可能會複雜一點。GIMP 並不單純提供圖片裁剪和大小調整，它更覆蓋了圖層、濾鏡、遮罩、路徑和其他一些高級功能。

4. VLC 媒體播放器 ​

VLC 也許就是最好的影音播放器了。它是跨平台的，所以您可能在 Windows 上也聽説過它。VLC 最特殊的地方是其擁有大量解碼器（並不是所有的解碼器都開放源代碼），所以它幾乎可以播放所有的影音文件。

5. Jitsy ​

Jitsy 完全是關於通訊的。您可以藉助它使用 Google talk、Facebook chat、Yahoo、ICQ 和 XMPP。它是用於音視頻通話（包括電話會議），桌面流desktop streaming和羣組聊天的多用户工具。會話會被加密。Jistsy 同樣能幫助您傳輸文件或記錄電話。

6. Synaptic ​

Synaptic 是一款基於 Debian 系統發行版的另一款應用程序安裝程序。並不是所有基於 Debian 的 Linux 都安裝有它，如果您使用基於 Debian 的 Linux 操作系統沒有預裝，也許您可以試一試。Synaptic 是一款用於添加或移除系統應用的 GUI 工具，甚至相對於許多發行版默認安裝的 軟件中心包管理器 ，經驗豐富的 Linux 用户更親睞於 Sunaptic。

相關鏈接 : 10 款您沒聽説過的 Linux 生產力應用程序

7. VirtualBox ​

VirtualBox 能支持您在計算機上運行虛擬機。當您想在當前 Linux 發行版上安裝其他發行版或操作系統時，使用虛擬機會方便許多。您同樣可以通過它運行 Windows 應用程序，性能可能會稍弱，但是如果您有一台強大的計算機，就不會那麼糟。

8. AisleRiot Solitaire（紙牌遊戲） ​

對於 Linux 的新用户來説，一款紙牌遊戲並不是剛需，但是它真的太有趣了。當您進入這款紙牌遊戲，您會發現，這是一款極好的紙牌遊戲包。AisleRiot 是 Linux 標誌性的應用程序，原因是 - 它涵蓋超過八十種紙牌遊戲，包括流行的 Klondike、Bakers Dozen、Camelot 等等，作為預警 - 它是會上癮的，您可能會花很長時間沉迷於此！

根據您所使用的發行版，這些軟件會有不同的安裝方法。但是大多數都可以通過您使用的發行版中的包管理器安裝使用，甚至它們可能會預裝在您的發行版上。安裝並且嘗試它們想必是最好的，如果不合您的胃口，您可以輕鬆地刪除它們。
