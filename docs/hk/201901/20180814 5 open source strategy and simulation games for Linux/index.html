5 款開源的 Linux 策略模擬遊戲 ​

用這些開源遊戲來挑戰你的戰略技能，探索新世界。

長久以來，遊戲都是 Linux 的軟肋。近些年，Steam、GOG 等遊戲發佈平台上不少商業遊戲都開始支持 Linux，這對於 Linux 的遊戲生態來説是件好事，但是我們能在這些平台上玩到的遊戲通常是不開源的商業作品。當然，這些遊戲在一個開源的操作系統上運行，但對於一個開源提倡者來説這似乎還不夠純粹。

那麼，我們能找到既自由開源又能給玩家帶來完整遊戲體驗的優質遊戲嗎？當然！雖然絕大多數的開源遊戲很難和 3A 商業遊戲大作競爭，但仍然有不少各種類型的開源遊戲，不僅內容有趣而且直接可以通過幾大 Linux 發行版本庫中直接安裝。就算某個遊戲在不在某個發行版本的庫中，我們也可以在這個遊戲項目的網站上找到直接的安裝方法。

本篇文章將會介紹策略和模擬類遊戲。我已經寫了街機遊戲、桌面卡牌遊戲、解謎遊戲、競速飛行遊戲以及角色扮演遊戲。

開源版“文明”（Freeciv） ​

Freeciv 可以被視為是文明系列遊戲的開源版本。遊戲玩法和文明系列最早期的遊戲十分類似，Freeciv 可以讓玩家選擇選用文明 1 或者文明 2 中的遊戲規則設置。Freeciv 中包含了很多元素，例如建造城市、探索世界地圖、發展科技以及和其他擴張中的文明競爭。勝利條件包括打敗所有其他的文明或建立一個外星殖民地，如果在前兩者都沒有達成的話，在遊戲時間期限前存活下來也可以算作勝利。這個遊戲可以和其他玩家聯機也可以和 AI 對戰，不同的地圖集可以改變遊戲的外觀。

安裝 Freeciv，你只需要在終端下運行以下指令。

  • Fedora 用户： dnf install freeciv
  • Debian/Ubuntu 用户：apt install freeciv

MegaGlest ​

MegaGlest 是一個開源的實時戰略遊戲，類似暴雪公司製作的遊戲魔獸世界和星際爭霸。玩家控制不同派別的人員、建造新建築、招募士兵、拓展領土並與敵人作戰。在遊戲比賽的最開始，玩家僅能建造最基礎的建築和招募最基礎的士兵。為了建造更高級的建築並招募級別更高的人員，玩家必須通過增加建築和人員從而一路提高科技樹、解鎖更加高級的選項。當敵人進入國土領域之中，戰鬥單元將會迎戰。但是最好的應對策略是，通過控制戰鬥單元直接操控每一場戰鬥。在管理新建築的建立，新人員的招募的同時控制戰鬥局勢聽上去十分困難，但是這就是 RTS（實時戰略遊戲）遊戲的精華所在。MegaGlest 這個遊戲提供了大量的人員派別，玩家可以不斷嘗試這些不同的技巧。

安裝 MegaGlest，你只需要在終端下運行以下指令：

  • Fedora 用户： dnf install megaglest
  • Debian/Ubuntu 用户：apt install megaglest

開源版“運輸大亨”（OpenTTD） ​

OpenTTD（見我們的 評測 ）是一個開源實現的 運輸大亨 。該遊戲的目的在於創建一個交通運輸網絡並獲得金錢，從而建立更加複雜的運輸網絡。這個運輸網絡包括了船隻、巴士、火車、貨車和飛機。默認的遊戲時間在 1950 和 2050 之間，玩家的目標就是在規定時間內拿到最高的遊戲分數。遊戲的最終分數基於很多因素，例如貨物運輸的數量、玩家所擁有的汽車數量以及他們賺到的錢。

安裝 OpenTTD，你只需要在終端運行以下指令：

  • Fedora 用户： dnf install openttd
  • Debian/Ubuntu 用户 apt install openttd

韋諾之戰The Battle for Wesnoth ​

韋諾之戰 是目前最完善的開源遊戲之一。這個回合制遊戲在一個奇幻的故事設定下。遊戲在一個六角形網格中進行，各個單元可以互相操作進行戰鬥。每個類型的單元都有它獨特的能力和弱點，因此玩家需要根據這些特點來設計不同的行動。韋諾之戰中有很多不同的行動分支，每個行動分支都有它特別的故事線和目標。韋諾之戰同時也有一個地圖編輯器，感興趣的玩家可以創作自己的地圖以及行動分支。

安裝韋諾之戰，你只需要在終端運行以下指令：

  • Fedora 用户： dnf install wesnoth
  • Debian/Ubuntu 用户： apt install wesnoth

UFO：外星入侵UFO: Alien Invasion ​

UFO: Alien Invasion 是一個開源策略遊戲，基於 幽浮系列X-COM。 有兩個不同的遊戲模式： geoscape 和 tactical。在 geoscape 模式下，玩家控制大局、管理基地、開發新技術以及掌控整體策略。 在 tactical 遊戲模式下，玩家控制一羣士兵並且以回合制的形式直接迎戰外星侵略者。兩個遊戲模式提供了不同的遊戲玩法，兩者都需要相當複雜的策略和戰術。

安裝這個遊戲，你只需要在終端下運行以下指令：

  • Debian/Ubuntu 用户： apt install ufoai

遺憾的是，UFO: 外星入寢不支持 Fedora 發行版。

如果你知道除了這些以外的開源策略模擬遊戲的話，歡迎在評論中分享。
