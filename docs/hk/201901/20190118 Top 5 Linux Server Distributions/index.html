5 個用於 SOHO 的 Linux 服務器發行版 ​

Jack Wallen 為 Linux 服務器發行版提供了一些可靠的選擇，絕對值回票價。

啊，這個古老的問題：哪種 Linux 發行版最適合做服務器？通常，問這種問題時，所浮現出來的標準的答覆就是：

  • RHEL
  • SUSE
  • Ubuntu 服務器
  • Debian
  • CentOS

然而，假如你將眼界放得更寬（不將服務器只看做是 IDC 託管的那種互聯網服務器時），可能答案會有點不同。我準備稍微來點不同的。我想做出一個滿足入選標準的發行版列表，這些發行版不僅是優秀的候選者，而且易於使用，可以為你的業務中的許多功能提供服務。在某些情況下，我選擇的是一些替代品，可以取代其它需要一些工作才能達成要求的操作系統。

我的一些選擇是企業級服務器的社區版本，它們可以被視為購買更強大平台的入門級產品。你甚至可以在這裏找到一兩個作為特定任務平台的候選者。然而，最重要的是，你在此列表中找到的並非尋常的泛泛之輩。

ClearOS ​

什麼是 ClearOS？對於家庭和小型企業用途，你可能找不到比它更好的解決方案。ClearOS 開箱即用，包括了入侵檢測、強大的防火牆、帶寬管理工具、郵件服務器、域控制器等工具。其目的是將服務器作為一個簡單的家庭和 SOHO 服務器，並具有用户友好的基於 Web 的圖形化界面，這使得 ClearOS 在某些評比中脱穎而出。從其界面中，你可以找到一個應用程序市場（圖 1），其中包含數百個應用程序（其中一些是免費的，而另一些則具有相關費用），這使得擴展 ClearOS 功能集非常容易。換句話説，你可以將 ClearOS 作為你的家庭和小型企業所需的平台。最重要的是，與許多其他替代方案不同，你只需支付所需的軟件和支持。

圖 1：ClearOS 應用程序市場

有三種版本的 ClearOS：

  • ClearOS Community - 免費版 ClearOS
  • ClearOS Home - 適於家庭辦公
  • ClearOS Business - 適於小型企業，包括了付費支持。

為了使軟件安裝更加容易，ClearOS 應用市場允許你通過以下方式進行選擇軟件：

* 按功能（根據任務顯示應用程序）    * 按類別（顯示相關應用程序組）    * 快速選擇文件（允許你按預先配置的模板選擇，以幫助你快速啓動和運行）

換句話説，如果你正在尋找 Linux 的家庭、SOHO 或 SMB 服務器，ClearOS 是一個出色的選擇（特別是如果你沒有啓動和運行標準的 Linux 服務器的能力時）。

Fedora 服務器 ​

你肯定聽説過 Fedora Linux。它是市場上最好的前沿發行版之一。但是你知道這個出色的 Fedora 桌面發行版的開發者們也開發了服務器版嗎？Fedora 服務器平台是一個短生命週期的、社區支持的服務器操作系統。這使得經驗豐富的、或對任何類型的 Linux（或任何操作系統）有經驗的系統管理員，可以使用開源社區中提供的最新技術。在這段描述中有三個關鍵詞：

  • 經驗豐富
  • 系統
  • 管理員

換言之，新用户就不要考慮了。雖然 Fedora 服務器完全能夠處理你拋出的任何任務，但它需要一些擁有更多的 Linux 功夫的人來使它工作並且運行良好。Fedora 服務器非常好的一點是，開箱即用，它包括了市場上用於服務器的開源的基於 Web 的最好的界面之一。通過 Cockpit（圖 2），你可以快速瀏覽系統資源、日誌、存儲、網絡以及擁有管理帳户、服務、應用程序和更新的能力。

圖 2：運行在 Fedora 服務器上的 Cockpit

如果你可以使用最前沿的軟件，並想要一個出色的管理儀表板，Fedora 服務器可能就是你要的平台。

NethServer ​

正如你所發現的那樣，NethServer 是每個人都知道的簡單 SMB Linux 服務器。通過 NethServer 的最新版本，你的小型企業將得到：

  • 內置 Samba 活動目錄控制器    * 與 Nextcloud 的無縫集成    * 證書管理    * HTTPS 透明代理    * 防火牆    * 郵件服務器和過濾器    * Web 服務器和過濾器    * 羣件    * IPS / IDS 或 VPN

所有包含的功能都可以通過用户友好的基於 Web 的界面輕鬆配置，包括單擊安裝模組以擴展 NethServer 功能集（圖 3）。NethServer 與 ClearOS 的區別在於它的設計目的是使管理工作更輕鬆。換句話説，這個平台提供了更多的靈活性和功能。與面向家庭辦公室和 SOHO 部署的 ClearOS 不同，NethServer 在小型商業環境中用起來就像在家庭裏使用一樣方便。

圖 3：給 NethServer 添加模組

Rockstor ​

Rockstor 是採用 Linux 和 Btfrs 的高級網絡附加存儲（NAS）和雲存儲服務器，可部署用於家庭、SOHO 以及中小型企業。藉助 Rockstor，你可以獲得一個完整的 NAS /雲解決方案，其中包含一個用户友好的基於 Web 的 GUI 工具，管理員可以像普通用户一樣輕鬆使用它來設置。一旦部署好了 Rockstor，你就可以創建存儲池、共享、快照、管理複製和用户、共享文件（藉助 Samba、NFS、SFTP 和 AFP），甚至擴展它的功能集，這要歸功於附加組件（稱為 Rock-ons）。Rock-ons 列表包括：

  • CouchPotato（Usenet 和 BitTorrent 用户的下載器）
  • Deluge（BitTorrent 用户的電影下載器）
  • EmbyServer（Emby 媒體服務器）
  • Ghost（專業博主的發佈平台）
  • GitLab CE（Git 倉庫託管和協作）
  • Gogs Go Git Service（輕量級 Git 版本控制服務器和前端）
  • Headphones（NZB 和 Torrent 的音樂自動下載器）
  • 用於 Squeezebox 設備的羅技 Squeezebox 服務器
  • MariaDB（關係型數據管理系統）
  • NZBGet（高效的 usenet 下載器）
  • OwnCloud-Official（安全的文件共享和託管）
  • Plexpy（基於 Python 的 Plex 用量跟蹤器）
  • Rocket.Chat（開源聊天平台）
  • SaBnzbd（Usenet 下載器）
  • Sickbeard（用於電視節目的互聯網個人視頻錄像機）
  • Sickrage（電視節目的自動視頻庫管理器）
  • Sonarr（Usenet 和 BitTorrent 用户的個人視頻錄像機）
  • Symform（備份設備）

Rockstor 還包括了一目瞭然的儀表板，使管理員可以快速訪問他們所需的有關其服務器的所有信息（圖 4）。

圖 4： Rockstor 面板

Zentyal ​

Zentyal 是另一個小型企業服務器，可以很好地處理多個任務。如果你正在尋找可以處理以下內容的 Linux 發行版：

  • 目錄和域服務器
  • 郵件服務器
  • 網關
  • DHCP、DNS 和 NTP 服務器
  • 認證機構（CA）
  • VPN
  • 實時消息（IM）
  • FTP 服務器
  • 反病毒
  • SSO 認證
  • 文件共享
  • RADIUS 認證
  • 虛擬化管理
  • 等等

Zentyal 可能是你的新選擇。從 2004 年 Zentyal 就存在了，它基於 Ubuntu Server，因此它擁有堅實的基礎和豐富的應用程序。在 Zentyal 儀表板的幫助下（圖 5），管理員可以輕鬆管理：

  • 系統
  • 網絡
  • 日誌
  • 軟件更新和安裝
  • 用户/組
  • 域
  • 文件共享
  • 郵件
  • DNS
  • 防火牆
  • 證書
  • 等等

圖 5：Zentyal 儀表板

向 Zentyal 服務器添加新組件只需要打開儀表板，單擊“軟件管理” -> “Zentyal 組件”，選擇要添加的組件，然後單擊安裝。Zentyal 可能會遇到的一個問題是，它提供不了與 Nethserver 和 ClearOS 一樣多的插件。但它提供的服務，則做得非常好。

更多來自於 ​

這個 Linux 服務器列表顯然不是詳盡無遺的。然而，這是一種對你可能沒有聽説過的五大服務器發行版的獨特視角。當然，如果你更願意使用更傳統的 Linux 服務器發行版，你可以隨時堅持使用 CentOS、Ubuntu 服務器、SUSE、RHEL 或 Debian……它們大多都出現在市場上最好的服務器發行版列表中。但是，如果你正在尋找一些不同的東西，那麼試試這五個發行版中的一個。

通過 Linux 基金會和 edX 的免費“Linux 簡介”課程瞭解有關 Linux 的更多信息。
