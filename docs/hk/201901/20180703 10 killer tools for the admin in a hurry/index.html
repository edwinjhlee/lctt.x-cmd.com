10 個供管理員救急的殺手級工具 ​

可以讓你趕快離開辦公室的網絡管理技巧和工具。

當工作任務堆積成山時，管理網絡和系統就變得十分有壓力了。沒有人能真正意識到需要花費多長時間，每個人都希望在昨天就完成他們的工作。

所以難怪我們這麼多人都被致力於找出有效的方法並與大家分享的開源精神所吸引。因為，當截止日期來臨，並且當天沒有足夠多的時間時，如果你可以找到立刻施行的免費答案，那會非常有幫助。

因此，閒話少敍，下述是我的瑞士軍刀，可以保證你在晚飯前離開辦公室。

服務器配置和腳本 ​

讓我們看一看！

  • NixCraft

    使用該網站的搜索功能。經過十多年的定期更新，這裏遍地是黃金！有用的腳本和方便的技巧可以立刻解決你的問題。這是我一般使用 Google 後的第二個選項。

  • Webmin

    它提供給你了一個很好的 Web 界面來幫助你遠程編輯配置文件。它減少了在處理目錄路徑和 sudo nano 上花費的大量時間，在你處理多個客户時，非常方便。

  • Windows 下的 Linux 子系統

    現代工作場所的現實是大多數員工都運行着 Windows，而服務器機房中不斷增長的設備則運行着 Linux 。因此，有些時候你會發現嘗試在 Windows 桌面上執行管理任務。

    你怎麼做？裝一個虛擬機？如果安裝目前 Windows 10 中免費提供的 Linux 子系統的兼容層，實際上要快得多，配置要少的多。

    這為你提供了一個 Bash 終端窗口，你可以在這個窗口中執行本地計算機上的 Bash 腳本和 Linux 二進制文件，可以完全訪問 Windows 和 Linux 文件系統，以及安裝網絡驅動器。它包含 Ubuntu 、OpenSUSE、SLES、Debian 和 Kali 發行版。

  • mRemoteNG

    當你有 100 多個服務器需要去管理時，這會是一個出色的 SSH 和遠程桌面客户端。

設置網絡，這樣你就無需再這樣做了。 ​

一個設計不周的網絡是厭惡加班的管理員的死敵。

  • 可拓展的 IP 尋址方案

    IP 地址耗盡的可怕之處在於，當 IP 地址耗盡時，網絡已經變的足夠大，而新的尋址方案是眾所周知的昂貴、令人痛苦的耗時。

    沒有人有時間做這件事！

    到了某個時候，IPv6 終將到來，來拯救這世界。但在那之前，無論世界向我們扔了多少可穿戴設備、平板電腦、智能鎖、燈、安全攝像頭、VoIP 耳機和濃縮咖啡機，這些以不變應萬變的 IP 尋址方案都應該讓我們繼續前行。

  • Linux Chmod 權限備忘錄

    一個簡短但是有用的 Bash 命令備忘錄可以幫助你通過網絡設置權限。所以，客户服務部的賬單落入到勒索軟件騙局時，你可以只恢復他們的文件，而不是整個公司的文件。

  • VLSM 子網計算器

    只需要輸入你想要從地址空間中創建的網絡的數量，以及每個網絡所需要的主機數量，它就可以計算出所有的子網掩碼應該是什麼。

單一用途的 Linux 發行版 ​

需要一個只做一件事的 Linux 容器？如果其他人已經在一個操作系統上搞好了一個小東西，你就可以快速安裝它並馬上投入使用。

下面這些每一個都使得我的工作變得輕鬆了許多。

  • Porteus Kiosk

    這個工具用來幫你把一台電腦上鎖定到一個瀏覽器上。通過稍稍一些調整，你甚至可以把瀏覽器鎖定在一個特定的網站上。它對於公共訪問機器來説非常方便。它可以與觸摸屏或鍵盤鼠標配合使用。

  • Parted Magic

    這是一個你可以從 USB 驅動器啓動的，可以用來劃分磁盤驅動器、恢復數據並運行基準測試工具的操作系統。

  • IPFire

    啊哈～我還是不敢相信有人把路由器/防火牆/代理組合成為“我尿火”（LCTT 譯註：IPFire 和 “I pee Fire“ 同音)。這是我在這個 Linux 發行版中第二喜歡的東西。我最喜歡的是它是一個非常可靠的軟件套件，設置和配置十分容易，而且有一系列的插件可以拓展它。

那麼，你呢？你發現了哪些工具、資源和備忘錄可以讓我們的工作日更加的輕鬆？我很高興知道，請在評論中分享您的工具。
