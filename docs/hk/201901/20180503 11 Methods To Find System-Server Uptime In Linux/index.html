Linux 上查看系統/服務器運行時間的 11 種方法 ​

你是否想知道自己的 Linux 系統正常運行了多長時間而沒有宕機？系統是什麼時候啓動的？

Linux 上有多個查看服務器/系統運行時間的命令，大多數用户喜歡使用標準並且很有名的 uptime 命令獲取這些具體的信息。

服務器的運行時間對一些用户來説不那麼重要，但是當服務器運行諸如在線商城門户portal、網上銀行門户等關鍵任務應用mission-critical applications時，它對於服務器管理員server adminstrators來説就至關重要。

它必須做到零宕機，因為一旦停機就會影響到數百萬用户。

正如我所説，許多命令都可以讓用户看到 Linux 服務器的運行時間。在這篇教程裏我會教你如何使用下面 11 種方式來查看。

正常運行時間uptime指的是服務器自從上次關閉或重啓以來經過的時間。

uptime 命令獲取 /proc 文件中的詳細信息並輸出正常運行時間，而 /proc 文件並不適合人直接看。

以下這些命令會輸出系統運行和啓動的時間。也會顯示一些額外的信息。

方法 1：使用 uptime 命令 ​

uptime 命令會告訴你係統運行了多長時間。它會用一行顯示以下信息。

當前時間、系統運行時間、當前登錄用户的數量、過去 1 分鐘/5 分鐘/15 分鐘系統負載的均值。

# uptime

 08:34:29 up 21 days,  5:46,  1 user,  load average: 0.06, 0.04, 0.00

方法 2：使用 w 命令 ​

w 命令為每個登錄進系統的用户，每個用户當前所做的事情，所有活動的負載對計算機的影響提供了一個快速的概要。這個單一命令結合了多個 Unix 程序：who、uptime，和 ps -a 的結果。

# w

 08:35:14 up 21 days,  5:47,  1 user,  load average: 0.26, 0.09, 0.02
USER     TTY      FROM              LOGIN@   IDLE   JCPU   PCPU WHAT
root     pts/1    103.5.134.167    08:34    0.00s  0.01s  0.00s w

方法 3：使用 top 命令 ​

top 命令是 Linux 上監視實時系統進程的基礎命令之一。它顯示系統信息和運行進程的信息，例如正常運行時間、平均負載、運行的任務、登錄用户數量、CPU 數量 & CPU 利用率、內存 & 交換空間信息。

方法 4：使用 who 命令 ​

who 命令列出當前登錄進計算機的用户。who 命令與 w 命令類似，但後者還包含額外的數據和統計信息。

# who -b
system boot 2018-04-12 02:48

方法 5：使用 last 命令 ​

last 命令列出最近登錄過的用户。last 回溯 /var/log/wtmp 文件並顯示自從文件創建後登錄進（出）的用户。

# last reboot -F | head -1 | awk '{print $5,$6,$7,$8,$9}'
Thu Apr 12 02:48:04 2018

方法 6：使用 /proc/uptime 文件 ​

這個文件中包含系統上次啓動後運行時間的詳細信息。/proc/uptime 的輸出相當精簡。

第一個數字是系統自從啓動的總秒數。第二個數字是總時間中系統空閒所花費的時間，以秒為單位。

# cat /proc/uptime
1835457.68 1809207.16

方法 7：使用 tuptime 命令 ​

tuptime 是一個彙報系統運行時間的工具，輸出歷史信息並作以統計，保留重啓之間的數據。和 uptime 命令很像，但輸出更有意思一些。

$ tuptime

方法 8：使用 htop 命令 ​

htop 是運行在 Linux 上的一個交互式進程查看器，是 Hisham 使用 ncurses 庫開發的。htop 比起 top 有很多的特性和選項。

方法 9：使用 glances 命令 ​

glances 是一個跨平台的基於 curses 庫的監控工具，它是使用 python 編寫的。可以説它非常強大，僅用一點空間就能獲得很多信息。它使用 psutil 庫從系統中獲取信息。

glances 可以監控 CPU、內存、負載、進程、網絡接口、磁盤 I/O、磁盤陣列RAID、傳感器、文件系統（與文件夾）、容器、監視器、Alert 日誌、系統信息、運行時間、快速查看Quicklook（CPU，內存、負載）等。

方法 10：使用 stat 命令 ​

stat 命令顯示指定文件或文件系統的詳細狀態。

# stat /var/log/dmesg | grep Modify
Modify: 2018-04-12 02:48:04.027999943 -0400

方法 11：使用 procinfo 命令 ​

procinfo 從 /proc 文件夾下收集一些系統數據並將其很好的格式化輸出在標準輸出設備上。

# procinfo | grep Bootup
Bootup: Fri Apr 20 19:40:14 2018 Load average: 0.16 0.05 0.06 1/138 16615
