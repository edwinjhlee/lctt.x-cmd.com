使用 Xfce Linux 桌面環境的 8 個理由 ​

整體上很優雅的 Xfce 桌面所具備的足夠輕巧和快速的特性能夠讓它很容易地知道如何做好一件事。

由於某些原因（也包括好奇），幾周前我開始使用 Xfce 作為我的 Linux 桌面。促使我更換 Linux 桌面環境的原因之一是桌面相關的守護進程佔據了我的性能非常強大的主工作站的絕大部分 CPU 資源和 I/O 帶寬。當然，有些不穩定性可能是因為我刪除了提供這些守護進程的 RPM 包。然而，事實是在我刪除這些 RPM 包之前，KDE 就已經很不穩定了而且還導致了一系列其他方面的性能和穩定性問題。所以我需要換一個桌面來避免這些問題。

在回顧了我為 Linux 桌面所寫的一系列文章後我才意識到我忽略了 Xfce。這篇文章也是力圖能夠糾正彌補這個疏忽。我非常喜歡 Xfce 也很享受它所帶給我超乎預期的快速、輕量的體驗。

作為研究的一部分，我有嘗試過在 Google 上查詢 Xfce 對應什麼意思。有個歷史參考是它對應着 “XForms Common Environment”，但 Xfce 早已不在使用 XForms 工具。幾年前，我找到另一個參考是 “Xtra fine computing environment” 而且我也很喜歡這個解釋。我將會用它作為 Xfce 的全稱（儘管再也找不到這個參考頁面）。

推薦 Xfce 的 8 個理由 ​

1、輕量級架構 ​

Xfce 相對於其他的桌面如 KDE 和 GNOME，不管是內存還是 CPU 的佔用率都非常小。在我的系統中，組成 Xfce 桌面的程序僅佔用了少量內存就構成一個如此強大的桌面。超低的 CPU 佔用率也是 Xfce 桌面的一個特點。瞭解到 Xfce 內存佔用特別低後，我對它的 CPU 佔用率也非常低這個特性自然而言也就不感到奇怪了。

2、簡潔 ​

Xfce 桌面很簡單，就像絨毛整潔的動物讓人一目瞭然、賞心悦目。基礎的桌面有兩個面板和一條在左邊垂直的圖標行。面板 0 在底部，並由一些基礎的應用啓動程序和能訪問到系統裏對應程序的圖標組成。面板 1 在頂部，由一個應用程序啓動器和一個能夠允許用户在多個工作區之間來回切換的工作區切換器組成。面板可以通過補充項自定義修改，比如增加個新的應用啓動器或者更改它們的寬高。

桌面左側的圖標對應是家目錄和垃圾桶。它也可以顯示其他的圖標，如完整的文件系統目錄樹和已連接上系統的可插拔的任意 USB 存儲設備。這些圖標可以用來掛載和卸載設備，也可以用來打開默認的文件管理器。如果你願意，它們都可以被隱藏，同時文件系統、垃圾箱、家目錄對應的圖標都可以逐個控制管理。所有的可移動設備也可以被隱藏或作為一個組顯示。

3、文件管理 ​

作為 Xfce 的默認文件管理器 Thunar，它很簡單，既易於使用和配置也非常容易學習。儘管它並不像其他的文件管理器比如 Konqueror 或者 Dolphin 那樣效果華麗，但它很強大也很快。Thunar 並不能在一個窗口裏面打開多個面板，但它提供了選項卡來支持多個目錄的同時打開。Thunar 也有一個非常漂亮的側邊欄，其上同樣的圖標就像桌面那樣能夠顯示完整的文件系統目錄樹和所有已連接的 USB 存儲設備。設備能夠被掛載和卸載，可移動媒介如 CD 也能夠被彈出。Thunar 也可以使用類似 Ark 這種幫助軟件來在你點擊歸檔文件的時候打開它們。比如 ZIP、TAR、RPM 這種歸檔文件都可以被瀏覽也可以從中複製單個文件。

Xfce 桌面及 Thunar 和 Xfce 下的終端模擬器。

在我的文件管理器系列文章中，我已經使用體驗過很多不同的文件管理器軟件，我不得不説 Thunar 的簡單易用讓你無法不喜歡上它。它可以讓你通過使用側邊欄來很容易地瀏覽文件系統。

4、穩定 ​

Xfce 桌面非常穩定。新版本的發佈週期似乎是三年，但也會根據需要發佈相關更新。最新的版本是於 2015 年 2 月發佈的 4.12。在使用 KDE 遇到一系列問題後，穩如磐石的 Xfce 桌面環境顯得讓人格外放心。在我使用 Xfce 的過程中，它從來沒有崩潰過，也不會產生額外的守護進程佔據過多的系統資源。這正是我想要的：它安安靜靜地工作，不會給你帶來額外的困擾。

5、優雅 ​

Xfce 簡單優雅。在我的今年秋天將面世的新書《系統管理員的 Linux 哲學》中我談到了關於簡單的一系列好處，包括簡單事實上也是優雅的諸多標誌之一。很明確能夠確定的就是 Xfce 及相關組件程序的開發者和維護者也是極力推崇簡單至上。這種簡單特性很可能也是 Xfce 如此穩定的主要原因，但它也給用户帶來了一個整潔的桌面外觀，一個反應靈敏的操作界面，一個會讓人感覺很自然也很易用的導航結構，而且 Xfce 整體上的優雅特性也會讓用户的使用過程中充滿愉悦感。

6、終端仿真程序 ​

Xfce4 的終端仿真程序非常強大，而且和其他很多終端仿真程序一樣可以允許你使用多個選項卡來讓多個終端在一個單獨窗口裏共存。儘管它與 Tilix、Terminator、Konsole 這種終端仿真程序比起來相對簡陋，但它也能很好的完成工作。選項卡的名字可以更改，而且選項卡也可以通過拖放或者工具欄的箭頭圖標或者菜單欄的選項重新排列。我特別喜歡 Xfce 的終端仿真程序的一點就是不管你連接了多少主機，相對應的選項卡都會顯示對應的主機名，比如，從 host1=>host2=>host3=>host4，會準確地在選項卡顯示了 “host4”。但其他的終端仿真程序最多也就顯示 “host2”。

至於這個終端仿真程序功能和外觀的其他方面都可以根據你的需要很容易配置成你想要的。當然同 Xfce 的其他組件一樣，這款終端仿真程序佔用了系統資源的很少一部分。

7、可配置性 ​

Xfce 能夠配置的範圍極大。雖然 Xfce 桌面的可配置性比不上 KDE，但依舊遠超 GNOME，而且比它更容易配置。比如，我發現設置管理器是 Xfce 配置一切的入口。雖然每個配置程序都可以單獨使用，但是設置管理器把他們都放在一個窗口裏以便快速訪問。關於 Xfce 桌面很多重要的部分都可以通過配置來滿足我的需求。

8、模組化 ​

Xfce 是由一系列單個的項目組成的整體，而且在你的 Linux 桌面發行版中也未必安裝了 Xfce 的所有組件。Xfce 項目 的主頁列出了主要的項目，所以你可以根據需要安裝你想安裝的附加組件。比如在我的 Fedora 28 workstation 版本上我安裝的 Xfce 組時就沒有 Xfce 項目 主頁最下面的説明的一些程序。

這裏還有個關於 Xfce 的 文檔頁面 和 一個被稱為 Xfce 超值項目 的 wiki 列舉了其他的 Xfce 相關的項目，它們為 Xfce 的面板及 Thunar 提供了很多不錯的應用程序、精美的插圖、好用的插件。

總結 ​

整體上很優雅的 Xfce 桌面所具備的足夠輕巧和快速的特性能夠讓它很容易地知道如何做好一件事。它的輕量級的結構也節省了大量的 CPU 和內存資源。這也使得 Xfce 非常適合那種由於硬件有限而無法分配給桌面太多資源的舊主機。然而，Xfce 又是足夠的靈活和強大的，能夠滿足高級用户的需要。

我知道，更換到一個新的 Linux 桌面環境需要你自己按照你想要的做些對應的自定義設置：比如面板上顯示你最愛用的程序對應的啓動器，設置下你最喜歡的桌面背景壁紙等一系列工作。這些年來我已經在切換到新桌面環境或更新舊桌面環境折騰很多次了。這需要時間也需要耐心。

我覺得切換 Linux 的桌面環境就像我在工作中換個辦公工位或者辦公室一樣。別人把我的東西裝箱從舊辦公室搬到新辦公室，然後我在我的新辦公室裏組裝連接好我的電腦，打開箱子再把裏面的東西放在合適的位置。而切換到 Xfce 桌面大概就是我做過的最簡單省事容易的桌面環境更換了。
