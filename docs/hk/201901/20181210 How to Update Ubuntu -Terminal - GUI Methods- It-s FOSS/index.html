初級：如何在終端及圖形界面中更新 Ubuntu ​

這篇教程將向你展示如何更新服務器版本或者桌面版本的 Ubuntu。它還解釋了更新和升級之間的區別以及你應該瞭解的有關於 Ubuntu Linux 中的更新的一些其他內容。

如果你是一個新手並已經體驗 Ubuntu 數天或幾周，你可能想知道如何更新你的 Ubuntu 系統以獲取安全補丁，錯誤修復和應用升級。

更新 Ubuntu 非常簡單。我並不是瞎説。它簡單得只要運行兩個命令。讓我來告訴你這兩個命令的更多細節。

請注意，本教程適用於 Ubuntu 18.04、16.04 或任何其他版本。命令列方式也適用於基於 Ubuntu 的發行版如 Linux Mint、Linux Lite、elementary OS 等。

通過命令列更新 Ubuntu ​

在桌面上，打開終端。你可以在菜單裏找到它或者使用 Ctrl+Alt+T 快捷鍵。如果你是登錄到一台 Ubuntu 服務器，那你已經在訪問一個終端了。

在終端裏，你只需要使用以下命令：

sudo apt update && sudo apt upgrade -y

它將詢問你密碼，而你可以使用你的賬號密碼。輸入時，你將不會看到任何內容在屏幕上，所以請繼續輸入你的密碼並按回車鍵。

現在，我來解釋下上面的命令。

事實上，這不是一條命令。它由兩條命令組成。符號 && 是合併兩條命令的一個方法，第二條命令僅在前一條命令執行成功時執行。

當命令 apt upgrade 要求你在安裝更新前確認時，末尾的參數 -y 會自動輸入 yes。

請注意，你也可以逐條使用這兩條命令：

sudo apt update
sudo apt upgrade

這將花費更長的時間，因為你必須等待第一條命令執行完成後才能輸入第二條命令。

説明：sudo apt update ​

這條命令更新了可用軟件包的本地資料庫。如果你沒運行這條命令，本地資料庫將不會被更新，而你的系統將不會知道是否有可用的新版本。

這就是為什麼當你運行 sudo apt update，你會在輸出中看到大量的 URL。這條命令會從對應的儲存庫（你在輸出中看到的 URL）中獲取軟件包信息。

在命令的末尾，它告訴你有多少個軟件包可以被更新。你可以使用下列命令查看這些軟件包：

apt list --upgradable

補充閲讀： 閲讀這篇文章瞭解命令 apt update 的輸出中的 Ign、Hit 和 Get 是什麼。

説明：sudo apt upgrade ​

這條命令將已安裝的軟件包版本與本地資料庫進行匹配。它收集全部信息，然後列出所有具有更新版本的軟件包。此時，它會詢問您是否要升級（已安裝的軟件包更新到新版本）。

你可以鍵入 yes、y 或者只敲回車鍵去確認安裝這些更新。

所以總的來説，sudo apt update 會檢查可用的新版本，而 sudo apt upgrade 實際上會執行更新。

命令 update 可能會令人困惑，因為你可能期望通過命令 apt update 安裝更新來更新系統，但這並不會發生。

通過 GUI 更新 Ubuntu（適用於桌面用户） ​

如果你使用桌面版 Ubuntu，你並不需要為了更新系統而打開終端。你可以仍可以使用命令列更新，但這只是一個選擇。

在菜單裏，找到 “軟件更新” 並運行它。

它將檢查你的系統是否有可用的更新。

如果有可用的更新，它將給你提供安裝更新的選擇。

現在，點擊 “安裝”，它可能會向你詢問密碼。

一旦你輸入你的密碼，它將開始安裝更新。

在某些情況下，你可能需要重啓系統才能使已安裝的更新正常工作。如果需要重啓系統，你將在更新結束時收到通知。

如果你不希望馬上重啓你的系統，可以選擇稍後重啓。

提示：如果“軟件更新”返回一個錯誤，你需要在終端是使用命令 sudo apt update。輸出的最後幾行將包含真正的錯誤信息。你可以在因特網上搜索該錯誤並解決問題。

更新 Ubuntu 時要記住幾件事 ​

你剛學習瞭如何更新你的 Ubuntu 系統。如果你感興趣，你還需要了解一些關於 Ubuntu 更新的內容。

更新後清理 ​

你的系統將會有一些更新後不再需要的軟件包。你可用使用這條命令刪除這些軟件包並釋放空間：

sudo apt autoremove

在 Ubuntu Server 中內核熱修復以避免重啓 ​

如果是 Linux 內核更新，你將需要在系統更新後重啓。當你不希望服務器停機時，這將會是一個問題。

熱修復功能允許 Linux 內核在持續運行時打補丁。換句話説就是你不需要重啓你的系統。

如果你在管理服務器，你可能需要在 Ubuntu 中啓用熱修復。

版本升級是不同的 ​

本文討論的更新是使你安裝的 Ubuntu 保持最新。但它不包括版本升級（例如從 Ubuntu 16.04 升級到 18.04）。

Ubuntu 版本 升級完全是另一回事。它更新整個操作系統核心。你需要在這個漫長的過程開始前做好備份。

總結 ​

我希望你喜歡這個關於 Ubuntu 系統更新的教程並學到一些新東西。

如果你有其他問題，請隨時提出。如果你是一位經驗豐富的 Linux 用户並且有些更好的技巧，請同我們分享。
