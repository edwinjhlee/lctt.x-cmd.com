扫码关注官方微信公众号获取开源软件和 x-cmd 的最新用法与独家资讯

#: author: (Kevin Sonney https://opensource.com/users/ksonney (Kevin Sonney))

開始使用 CryptPad 吧，一個開源的協作文檔編輯器 ​

使用 CryptPad 安全地共享你的筆記、文檔、看板等，這是我們在開源工具系列中的第 5 個工具，它將使你在 2019 年更高效。

每年年初似乎都有瘋狂的衝動想提高工作效率。新年的決心，渴望開啓新的一年，當然，“拋棄舊的，擁抱新的”的態度促成了這一切。通常這時的建議嚴重偏向閉源和專有軟件，但事實上並不用這樣。

這是我挑選出的 19 個新的（或者對你而言新的）開源工具中的第 5 個工具來幫助你在 2019 年更有效率。

CryptPad ​

我們已經介紹過 Joplin，它能很好地保存自己的筆記，但是，你可能已經注意到，它沒有任何共享或協作功能。

CryptPad 是一個安全、可共享的筆記應用和文檔編輯器，它能夠安全地協作編輯。與 Joplin 不同，它是一個 NodeJS 應用，這意味着你可以在桌面或其他服務器上運行它，並使用任何現代 Web 瀏覽器訪問。它開箱即用，它支持富文本、Markdown、投票、白板，看板和 PPT。

它支持不同的文檔類型且功能齊全。它的富文本編輯器涵蓋了你所期望的所有基礎功能，並允許你將文件導出為 HTML。它的 Markdown 的編輯能與 Joplin 相提並論，它的看板雖然不像 Wekan 那樣功能齊全，但也做得不錯。其他支持的文檔類型和編輯器也很不錯，並且有你希望在類似應用中看到的功能，儘管投票功能顯得有些粗糙。

然而，CryptPad 的真正強大之處在於它的共享和協作功能。共享文檔只需在“共享”選項中獲取可共享 URL，CryptPad 支持使用 <iframe> 標籤嵌入其他網站的文檔。可以在“編輯”或“查看”模式下使用密碼和會過期的鏈接共享文檔。內置聊天能夠讓編輯者相互交談（請注意，具有瀏覽權限的人也可以看到聊天但無法發表評論）。

所有文件都使用用户密碼加密存儲。服務器管理員無法讀取文檔，這也意味着如果你忘記或丟失了密碼，文件將無法恢復。因此，請確保將密碼保存在安全的地方，例如放在密碼保險箱中。

當它在本地運行時，CryptPad 是一個用於創建和編輯文檔的強大應用。當在服務器上運行時，它成為了用於多用户文檔創建和編輯的出色協作平台。在我的筆記本電腦上安裝它不到五分鐘，並且開箱即用。開發者還加入了在 Docker 中運行 CryptPad 的説明，並且還有一個社區維護用於方便部署的 Ansible 角色。CryptPad 不支持任何第三方身份驗證，因此用户必須創建自己的帳户。如果你不想運行自己的服務器，CryptPad 還有一個社區支持的託管版本。

via: https://opensource.com/article/19/1/productivity-tool-cryptpad
