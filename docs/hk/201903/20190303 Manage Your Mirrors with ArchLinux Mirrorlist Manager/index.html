使用 Arch Linux 鏡像列表管理器來管理你的鏡像 ​

Arch Linux 鏡像列表管理器是一個簡單的圖形化程序，它讓你可以方便地管理 Arch Linux 中的鏡像。

對於 Linux 用户來説，保持鏡像列表規整非常重要。今天我們來介紹一個用來管理 Arch 鏡像列表的應用程序。

Arch Linux Mirrorlist Manager

什麼是鏡像？ ​

給新手的話，Linux 操作系統有賴於分佈全球的的一系列服務器。這些服務器包含了特定發行版的所有可用的軟件包的一樣的副本。這就是為什麼它們被稱為“鏡像”。

這些服務器的最終目標時讓每個國家都有多個鏡像。這樣就能讓當地的用户可以快速升級系統。然而，這並不絕對。有時別國的鏡像反而更快。

ArchLinux 鏡像列表管理器讓在 Arch Linux 中管理鏡像更簡單 ​

主界面

在 Arch 中管理並對有效鏡像進行排序 不是個簡單的事情。它需要用到很長的命令。還好，有人想出了一個解決方案。

去年，RizwanHasan 用 Python 編寫了一個名為 Arch Linux 鏡像列表管理器 的 Qt 應用程序。你可能對 Rizwan 這個名字感到眼熟，因為這不是第一次我們在本站介紹他做的玩意了。一年多前，我介紹過一個名為 MagpieOS 的基於 Arch 的新 Linux 發行版就是 Rizwan 創造的。我想 Rizwan 創造 MagpieOS 的經歷激勵了他創建了這個程序。

Arch Linux 鏡像列表管理器的功能並不多。它讓你根據回應速度對鏡像進行排序，並可以根據數量和國家進行過濾。

也就是説，若你在德國，你可以限制只保留在位於德國的最快的 3 個鏡像。

安裝 Arch Linux 鏡像列表管理器 ​

它僅適用於 Arch Linux 用户

注意! Arch Linux 鏡像列表管理器只能應用於 Arch linux 發行版. 不要在其他基於 Arch 的發行版中使用它，除非你能確定該發行版使用的是 Arch 鏡像。否則，你將會遇到我在 Manjaro 中遇到的問題(在下面章節解釋).

Manjaro 中的鏡像管理器替代品

當使用類 Arch 的系統時, 我選擇了 Manjaro。在開始本文之前，我在 Manjaro 及其上安裝了 Arch Linux 鏡像列表管理器。它很快就對有效鏡像進行了排序並保存到我的鏡像列表中。

然後我嘗試進行系統更新卻立即遇到了問題。當 ArchLinux 鏡像列表管理器對我係統使用的鏡像進行排序時，它使用普通的 Arch 鏡像替換了我的 Manjaro 鏡像。（Manjaro 基於 Arch，但卻有着自己的鏡像，這是因為開發團隊會在推送軟件包之前對所有這些軟件包進行測試以保證不會出現系統崩潰的 BUG。）還好，Manjaro 論壇幫我修復了這個錯誤。

若你是 Manjaro 用户，請不要重蹈我的覆轍。Arch Linux 鏡像列表管理器 僅適用於 Arch 以及使用 Arch 鏡像的衍生版本。

幸運的是，manjaro 有一個簡單易用的終端程序來管理鏡像列表。那就是 Pacman-mirrors。跟 ArchLinux 鏡像列表管理器一樣，你可以根據回應速度進行排序。只需要運行 sudo pacman-mirrors --fasttrack 即可。若你像將結果侷限在最快的 5 個鏡像，可以運行 sudo pacman-mirrors --fasttrack 5。要像將結果侷限在某個或某幾個國家，運行 sudo pacman-mirrors --country Germany,Spain,Austria。你可以通過運行 sudo pacman-mirrors --geoip 來將結果侷限在自己國家。更多關於 Pacman-mirrors 的信息請參見 Manjaro wiki。

運行 Pacman-mirrors 後，你還需要運行 sudo pacman -Syyu 來同步軟件包資料庫並升級系統。

注意：Pacman-mirrors 僅僅適用於 Manjaro。

Arch Linux 鏡像列表管理器包含在 ArchUserRepository 中。高級 Arch 用户可以直接從 theGitHubpage 下載 PKGBUILD。

對 Arch Linux Mirrorlist Manager 的最後思考 ​

雖然 Arch Linux 鏡像列表管理器 對我不太有用，我很高興有它的存在。這説明 Linux 用户正在努力讓 Linux 更加易於使用。正如我之前説過的，在 Arch 中管理鏡像並不容易。Rizwan 的小工具可以讓 Arch 對新手更加友好。
