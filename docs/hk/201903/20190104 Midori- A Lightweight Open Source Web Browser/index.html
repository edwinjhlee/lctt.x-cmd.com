Midori：輕量級開源 Web 瀏覽器 ​

這是一個對再次迴歸的輕量級、快速、開源的 Web 瀏覽器 Midori 的快速回顧。

如果你正在尋找一款輕量級網絡瀏覽器替代品，請試試 Midori。

Midori是一款開源的網絡瀏覽器，它更注重輕量級而不是提供大量功能。

如果你從未聽説過 Midori，你可能會認為它是一個新的應用程序，但實際上 Midori 首次發佈於 2007 年。

因為它專注於速度，所以 Midori 很快就聚集了一羣愛好者，併成為了 Bodhi Linux、SilTaz 等輕量級 Linux 發行版的默認瀏覽器。

其他發行版如 elementary OS 也使用了 Midori 作為其默認瀏覽器。但 Midori 的開發在 2016 年左右停滯了，它的粉絲開始懷疑 Midori 已經死了。由於這個原因，elementary OS 從最新版本中刪除了它。

好消息是 Midori 還沒有死。經過近兩年的不活躍，開發工作在 2018 年的最後一個季度恢復了。在後來的版本中添加了一些包括廣告攔截器的擴展。

Midori 網絡瀏覽器的功能 ​

以下是 Midori 瀏覽器的一些主要功能

  • 使用 Vala 編寫，使用 GTK+3 和 WebKit 渲染引擎。   * 標籤、窗口和會話管理。   * 快速撥號。   * 默認保存下一個會話的選項卡。   * 使用 DuckDuckGo 作為默認搜索引擎。可以更改為 Google 或 Yahoo。   * 書籤管理。   * 可定製和可擴展的界面。   * 擴展模組可以用 C 和 Vala 編寫。   * 支持 HTML5。   * 少量的擴展程序包括廣告攔截器、彩色標籤等。沒有第三方擴展程序。   * 表單歷史。   * 隱私瀏覽。   * 可用於 Linux 和 Windows。

小知識：Midori 是日語單詞，意思是綠色。如果你因此而猜想的話，但 Midori 的開發者實際不是日本人。

體驗 Midori ​

這幾天我一直在使用 Midori。體驗基本很好。它支持 HTML5 並能快速渲染網站。廣告攔截器也沒問題。正如你對任何標準 Web 瀏覽器所期望的那樣，瀏覽體驗挺順滑。

缺少擴展一直是 Midori 的弱點，所以​​我不打算談論這個。

我注意到的是它不支持國際語言。我找不到添加新語言支持的方法。它根本無法渲染印地語字體，我猜對其他非羅曼語言也是一樣。

我也在 YouTube 中也遇到了麻煩。有些視頻會拋出播放錯誤而其他視頻沒問題。

Midori 沒有像 Chrome 那樣吃我的內存，所以這是一個很大的優勢。

如果你想嘗試 Midori，讓我們看下你該如何安裝。

在 Linux 上安裝 Midori ​

在 Ubuntu 18.04 倉庫中不再提供 Midori。但是，可以使用 Snap 包輕鬆安裝較新版本的 Midori。

如果你使用的是 Ubuntu，你可以在軟件中心找到 Midori（Snap 版）並從那裏安裝。

對於其他 Linux 發行版，請確保你已啓用 Snap 支持，然後你可以使用以下命令安裝 Midori：

sudo snap install midori

你可以選擇從源代碼編譯。你可以從 Midori 的網站下載它的代碼。
