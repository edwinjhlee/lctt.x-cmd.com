FinalCrypt：一個開源文件加密應用 ​

我通常不會加密文件，但如果我打算整理我的重要文件或憑證，加密程序就會派上用場。

你可能已經在使用像 GnuPG 這樣的程序來幫助你加密/解密 Linux 上的文件。還有 EncryptPad 也可以加密你的筆記。

但是，我看到了一個名為 FinalCrypt 的新的免費開源加密工具。你可以在 GitHub 頁面上查看其最新的版本和源碼。

在本文中，我將分享使用此工具的經驗。請注意，我不會將它與其他程序進行比較 —— 因此，如果你想要多個程序之間的詳細比較，請在評論中告訴我們。

使用 FinalCrypt 加密文件 ​

FinalCrypt 使用一次性密碼本密鑰生成密碼來加密文件。換句話説，它會生成一個 OTP 密鑰，你將使用該密鑰加密或解密你的文件。

根據你指定的密鑰大小，密鑰是完全隨機的。因此，沒有密鑰文件就無法解密文件。

雖然 OTP 密鑰用於加密/解密簡單而有效，但管理或保護密鑰文件對某些人來説可能是不方便的。

如果要使用 FinalCrypt，可以從它的網站下載 DEB/RPM 文件。FinalCrypt 也可用於 Windows 和 macOS。

  • 下載 FinalCrypt

下載後，只需雙擊該 deb 或 rpm 文件就能安裝。如果需要，你還可以從源碼編譯。

如何保護你的 OTP 密鑰？ ​

加密/解密你想要保護的文件很容易。但是，你應該在哪裏保存你的 OTP 密鑰？

如果你未能將 OTP 密鑰保存在安全的地方，那麼它幾乎沒用。

嗯，最好的方法之一是使用專門的 USB 盤保存你的密鑰。只需要在解密文件時將它插入即可。

除此之外，如果你認為足夠安全，你可以將密鑰保存在雲服務中。

有關 FinalCrypt 的更多信息，請訪問它的網站。
