Linux 上 10 個最好的 Markdown 編輯器 ​

在這篇文章中，我們會點評一些可以在 Linux 上安裝使用的最好的 Markdown 編輯器。 你可以找到非常多的 Linux 平台上的 Markdown 編輯器，但是在這裏我們將盡可能地為您推薦那些最好的。

Best Linux Markdown Editors

對於不瞭解 Markdown 的人做個簡單介紹，Markdown 是由著名的 Aaron Swartz 和 John Gruber 發明的標記語言，其最初的解析器是一個用 Perl 寫的簡單、輕量的同名工具。它可以將用户寫的純文本轉為可用的 HTML（或 XHTML）。它實際上是一門易讀，易寫的純文本語言，以及一個用於將文本轉為 HTML 的轉換工具。

希望你先對 Markdown 有一個稍微的瞭解，接下來讓我們逐一列出這些編輯器。

1. Atom ​

Atom 是一個現代的、跨平台、開源且強大的文本編輯器，它可以運行在 Linux、Windows 和 MAC OS X 等操作系統上。用户可以在它的基礎上進行定製，刪減修改任何配置文件。

它包含了一些非常傑出的特性：

  • 內置軟件包管理器
  • 智能自動補全功能
  • 提供多窗口操作
  • 支持查找替換功能
  • 包含一個文件系統瀏覽器
  • 輕鬆自定義主題
  • 開源、高度擴展性的軟件包等

Atom Markdown Editor for Linux

訪問主頁: https://atom.io/

2. GNU Emacs ​

Emacs 是 Linux 平台上一款的流行文本編輯器。它是一個非常棒的、具備高擴展性和定製性的 Markdown 語言編輯器。

它綜合了以下這些神奇的特性：

  • 帶有豐富的內置文檔，包括適合初學者的教程
  • 有完整的 Unicode 支持，可顯示所有的人類符號
  • 支持內容識別的文本編輯模式
  • 包括多種文件類型的語法高亮
  • 可用 Emacs Lisp 或 GUI 對其進行高度定製
  • 提供了一個包系統可用來下載安裝各種擴展等

Emacs Markdown Editor for Linux

訪問主頁: https://www.gnu.org/software/emacs/

3. Remarkable ​

Remarkable 可能是 Linux 上最好的 Markdown 編輯器了，它也適用於 Windows 操作系統。它的確是是一個卓越且功能齊全的 Markdown 編輯器，為用户提供了一些令人激動的特性。

一些卓越的特性：

  • 支持實時預覽
  • 支持導出 PDF 和 HTML
  • 支持 Github Markdown 語法
  • 支持定製 CSS
  • 支持語法高亮
  • 提供鍵盤快捷鍵
  • 高可定製性和其他

Remarkable Markdown Editor for Linux

訪問主頁: https://remarkableapp.github.io

4. Haroopad ​

Haroopad 是為 Linux，Windows 和 Mac OS X 構建的跨平台 Markdown 文檔處理程序。用户可以用它來書寫許多專家級格式的文檔，包括電子郵件、報告、Blog、演示文稿和Blog文章等等。

功能齊全且具備以下的亮點：

  • 輕鬆導入內容
  • 支持導出多種格式
  • 廣泛支持Blog和郵件
  • 支持許多數學表達式
  • 支持 Github Markdown 擴展
  • 為用户提供了一些令人興奮的主題、皮膚和 UI 組件等等

Haroopad Markdown Editor for Linux

訪問主頁: http://pad.haroopress.com/

5. ReText ​

ReText 是為 Linux 和其它幾個 POSIX 兼容操作系統提供的簡單、輕量、強大的 Markdown 編輯器。它還可以作為一個 reStructuredText 編輯器，並且具有以下的特性：

  • 簡單直觀的 GUI
  • 具備高定製性，用户可以自定義語法文件和配置選項
  • 支持多種配色方案
  • 支持使用多種數學公式
  • 啓用導出擴展等等

ReText Markdown Editor for Linux

訪問主頁: https://github.com/retext-project/retext

6. UberWriter ​

UberWriter 是一個簡單、易用的 Linux Markdown 編輯器。它的開發受 Mac OS X 上的 iA writer 影響很大，同樣它也具備這些卓越的特性：

  • 使用 pandoc 進行所有的文本到 HTML 的轉換
  • 提供了一個簡潔的 UI 界面
  • 提供了一種專心（distraction free）模式，高亮用户最後的句子
  • 支持拼寫檢查
  • 支持全屏模式
  • 支持用 pandoc 導出 PDF、HTML 和 RTF
  • 啓用語法高亮和數學函數等等

UberWriter Markdown Editor for Linux

訪問主頁: http://uberwriter.wolfvollprecht.de/

7. Mark My Words ​

Mark My Words 同樣也是一個輕量、強大的 Markdown 編輯器。它是一個相對比較新的編輯器，因此提供了包含語法高亮在內的大量的功能，簡單和直觀的 UI。

下面是一些棒極了，但還未捆綁到應用中的功能：

  • 實時預覽
  • Markdown 解析和文件 IO
  • 狀態管理
  • 支持導出 PDF 和 HTML
  • 監測文件的修改
  • 支持首選項設置

MarkMyWords Markdown Editor for-Linux

訪問主頁: https://github.com/voldyman/MarkMyWords

8. Vim-Instant-Markdown 插件 ​

Vim 是 Linux 上的一個久經考驗的強大、流行而開源的文本編輯器。它用於編程極棒。它也高度支持插件功能，可以讓用户為其增加一些其它功能，包括 Markdown 預覽。

有好幾種 Vim 的 Markdown 預覽插件，但是 Vim-Instant-Markdown 的表現最佳。

###9. Bracket-MarkdownPreview 插件

Brackets 是一個現代、輕量、開源且跨平台的文本編輯器。它特別為 Web 設計和開發而構建。它的一些重要功能包括：支持內聯編輯器、實時預覽、預處理支持及更多。

它也是通過插件高度可擴展的，你可以使用 Bracket-MarkdownPreview 插件來編寫和預覽 Markdown 文檔。

Brackets Markdown Plugin Preview

10. SublimeText-Markdown 插件 ​

Sublime Text 是一個精心打造的、流行的、跨平台文本編輯器，用於代碼、markdown 和普通文本。它的表現極佳，包括如下令人興奮的功能：

  • 簡潔而美觀的 GUI
  • 支持多重選擇
  • 提供專心模式
  • 支持窗體分割編輯
  • 通過 Python 插件 API 支持高度插件化
  • 完全可定製化，提供命令查找模式

SublimeText-Markdown 插件是一個支持格式高亮的軟件包，帶有一些漂亮的顏色方案。

SublimeText Markdown Plugin Preview

結論 ​

通過上面的列表，你大概已經知道要為你的 Linux 桌面下載、安裝什麼樣的 Markdown 編輯器和文檔處理程序了。

請注意，這裏提到的最好的 Markdown 編輯器可能對你來説並不是最好的選擇。因此你可以通過下面的反饋部分，為我們展示你認為列表中未提及的，並且具備足夠的資格的，令人興奮的 Markdown 編輯器。
