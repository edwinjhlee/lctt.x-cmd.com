替代 Copy 的 Linux 最佳雲服務 ​

雲存儲服務 Copy 已經關閉，我們 Linux 用户是時候該尋找其他優秀的** Copy 之外的 Linux 雲存儲服務**。

全部文件會在 2016年5月1號 被刪除。如果你是 Copy 的用户，你應該保存你的文件並將它們移至其他地方。

在過去的兩年裏，Copy 已經成為了我最喜愛的雲存儲。它為我提供了大量的免費空間並且帶有桌面平台的原生應用程序，包括 Linux 和移動平台如 iOS 和 Android。

對我來説，它是一個非常棒的雲存儲，在應用中我獲得了大量的免費存儲空間（380 GB）並且享受着桌面系統和移動系統之間的無縫體驗。但是這些'方便免費的存儲'，15 GB 為註冊，5 GB 為每次推薦，使我想到如果 Copy 沒有獲得商業用户，他們將會馬上停業。如此巨大的免費存儲空間僅意味着他們沒有像 Dropbox 所做的一樣針對個別用户。

當我從 Copy.com 看到它即將關閉的消息，我的擔憂成真了。事實上，Copy 並不孤獨。它的母公司 Barracuda Networks正經歷一段困難時期並且已經僱傭 Morgan Stanely 尋找 合適的賣家(s)

無論什麼理由，我們所知道的是 Copy 將會成為歷史，我們需要尋找相似的優秀的 Linux 雲服務。我之所以強調 Linux 是因為其他流行的雲存儲服務，如微軟的 OneDrive 和 Google Drive 都沒有提供本地 Linux 客户端。微軟並沒有出乎我們的預料，但是谷歌對 Linux 的冷漠令人震驚。

Linux 下 Copy 的最佳替代者 ​

什麼樣的雲服務才適合作為 Linux 下的存儲服務？讓我們猜猜：

  • 大量的免費空間。畢竟，個人用户無法支付每月的鉅額款項。
  • 原生的 Linux 客户端。以便你能夠方便的在服務器之間同步文件，而不用做一些特殊的調整或者定時執行腳本。
  • 其他桌面系統的客户端，比如 Windows 和 OS X。移動性是必要的，並且同步設備間的文件也很有必要。
  • 基於 Android 和 iOS 的移動應用程序。在今天的現代世界裏，你需要連接所有設備。

我不將自託管的雲服務計算在內，比如 OwnCloud 或 Seafile ，因為它們需要自己建立和運行一個服務器。這不適合所有想要類似 Copy 的雲服務的家庭用户。

讓我們看看可以用於替代 Linux 下 Copy.com 的服務有什麼。

Mega ​

如果你是一個 It’s FOSS 的普通讀者，你可能已經看過我之前的一篇有關 Mega on Linux的文章。這種雲服務由 Megaupload scandal 公司下臭名昭著的 Kim Dotcom 提供。這也使一些用户懷疑它，因為 Kim Dotcom 已經很長一段時間成為美國當局的目標。

Mega 擁有方便免費雲服務下你所期望的一切。它給每個個人用户提供 50 GB 的免費存儲空間。提供Linux 和其他平台下的原生客户端，並帶有端到端的加密。原生的 Linux 客户端運行良好，可以無縫地跨平台同步。你也能在瀏覽器上查看操作你的文件。

優點: ​

  • 50 GB 的免費存儲空間
  • 端到端的加密
  • Linux 和其他平台下的原生客户端，例如 Windows，Mac OS X，Android，iOS

缺點: ​

  • Mega 擁有者見不得人的過去

Mega

Hubic ​

Hubic 是一個來自法國公司的雲服務。Hubic 在註冊時也提供了 25 GB 免費存儲空間。你可以通過推薦Hubic給朋友將空間擴大至 50 GB （對免費用户來説）。

Hubic 提供 Linux 客户端，其還是 beta 版本（至今已經兩年了）。Hubic 擁有官方的 Linux 客户端，但是它侷限在命令列。我沒有去測試移動版本。

Hubic 擁有一些不錯的功能。除了簡單的用户界面、文件共享等等，它還有備份的功能，你可以定期地歸檔你的重要文件。

優點: ​

  • 25 GB 免費存儲空間，可擴大至 50 GB
  • 支持多個平台
  • 備份功能

缺點: ​

  • beta 版本的 Linux 客户端，只支持命令列

Hubic

pCloud ​

pCloud 是另一款歐洲的發行軟件，但這一次跨過了法國邊境，它來自瑞士。專注於加密和安全，pCloud 為每一個註冊者提供 10 GB 的免費存儲空間。你可以通過邀請好友、在社交媒體上分享鏈接等方式將空間增加至 20 GB。

它擁有云服務的所有標準特性，例如文件共享、同步、選擇性同步等等。pCloud 也有跨平台原生客户端，當然包括 Linux。

Linux 客户端 容易使用，並在 Linux Mint 17.3 下的有限測試中表現良好。

優點: ​

  • 10 GB 免費存儲空間，可擴大至 20 GB
  • 運行良好的帶有 GUI 的 Linux 客户端

缺點: ​

  • 加密是一個付費功能

pCloud

Yandex Disk ​

俄羅斯互聯網巨人 Yandex 擁有 Google 所擁有的一切東西。搜索引擎、分析學、網站管理工具、郵箱、網頁瀏覽器和雲存儲服務。

Yandex Disk 在註冊時提供了 10 GB 的免費雲存儲空間。它有多平台的原生客户端，包括 Linux。然而，官方的 Linux 客户端只是命令列而已。你可以獲取非官方的 GUI 版本的 Yandex Disk 客户端。Yandex Disk 支持文件共享鏈接，同時帶有其他標準的雲存儲特性。

優點: ​

  • 10 GB 的免費存儲空間，可通過推薦的方式擴大至 20 GB

缺點: ​

  • 只有命令列客户端

Yandex Disk

公正而深思熟慮的刪節 ​

我從列表中刪減了Dropbox、SpiderOak。Dropbox 對 Linux 來説非常優秀，但是它的免費存儲空間限制在 2 GB。在過去的幾年裏，我已設法將其擴大超過 21 GB，但那又是另一件事了。

SpiderOak 也僅提供了 2 GB 的免費存儲空間，你無法在網頁瀏覽器上操作文件。

OwnCloud 需要屬於自己的服務器包括建立，因此它並非人見人愛。並且它確切不符合一個典型雲服務的標準。

結論 ​

如果你問我應該使用什麼替代 Copy，我的答案是 Mega。它帶有大量的免費雲存儲空間和優秀的 Linux 客户端。在** Linux 下最佳雲存儲服務**的列表中，你的選擇是什麼？你更喜歡哪一個呢？
