為什麼 Ubuntu 家族會佔據 Linux 發行版的主導地位？ ​

在過去的數年中，我體驗了一些優秀的 Linux 發行版。給我印象最深刻的是那些由強大的社區維護的發行版，而流行的發行版比強大的社區給我的印象更深。流行的 Linux 發行版往往能吸引新用户，這通常是由於其流行而使得使用該發行版會更加容易。並非絕對如此，但一般來説是這樣的。

説到這裏，首先映入我腦海的一個發行版是 Ubuntu。其基於健壯的 Debian 發行版構建，它不僅成為了一個非常受歡迎的 Linux 發行版，而且它也衍生出了不可計數的其他分支，比如 Linux Mint 就是一個例子。在本文中，我會探討為何我認為 Ubuntu 會贏得 Linux 發行版之戰的原因，以及它是怎樣影響到了整個 Linux 桌面領域。

Ubuntu 易於使用 ​

在我幾年前首次嘗試使用 Ubuntu 前，我更喜歡使用 KED 桌面。在那個時期，我接觸的大多是這種 KDE 桌面環境。主要原因還是 KDE 是大多數新手容易入手的 Linux 發行版中最受歡迎的。這些新手友好的發行版有 Knoppix、Simply Mepis、Xandros、Linspire 以及其它的發行版等等，這些發行版都推薦他們的用户去使用廣受歡迎的 KDE。

現在 KDE 能滿足我的需求，我也沒有什麼理由去折騰其他的桌面環境。有一天我的 Debian 安裝失敗了（由於我個人的操作不當），我決定嘗試開發代號為 Dapper Drake 的 Ubuntu 版本（LCTT 譯註：Ubuntu 6.06 - Dapper Drake，發佈日期：2006 年 6 月 1 日），每個人都對它讚不絕口。那個時候，我對於它的印象僅限於屏幕截圖，但是我想試試也挺有趣的。

Ubuntu Dapper Drake 給我的最大的印象是它讓我很清楚地知道每個東西都在哪兒。記住，我是來自於 KDE 世界的用户，在 KDE 上要想改變菜單的設置就有 15 種方法 ！而 Ubuntu 上的 GNOME 實現極具極簡主義的。

時間來到 2016 年，最新的版本號是 16.04：我們有了好幾種 Ubuntu 特色版本，也有一大堆基於 Ubuntu 的發行版。所有的 Ubuntu 特色版和衍生發行版的共同具有的核心都是為易用而設計。發行版想要增大用户基數時，這就是最重要的原因。

Ubuntu LTS ​

過去，我幾乎一直堅持使用 LTS（Long Term Support）發行版作為我的主要桌面系統。10月份的發行版很適合我測試硬盤驅動器，甚至把它用在一個老舊的手提電腦上。我這樣做的原因很簡單——我沒有興趣在一個正式使用的電腦上折騰短期發行版。我是個很忙的傢伙，我覺得這樣會浪費我的時間。

對於我來説，我認為 Ubuntu 提供 LTS 發行版是 Ubuntu 能夠變得流行的最大的原因。這樣説吧———給普羅大眾提供一個桌面 Linux 發行版，這個發行版能夠得到長期的有效支持就是它的優勢。事實上，不只 Ubuntu 是這樣，其他的分支在這一點上也做的很好。長期支持策略以及對新手的友好環境，我認為這就為 Ubuntu 的普及帶來了莫大的好處。

Ubuntu Snap 軟件包 ​

以前，用户會誇讚可以在他們的系統上使用 PPA（personal package archive 個人軟件包檔案）獲得新的軟件。不好的是，這種技術也有缺點。當它用在各種軟件名稱時， PPA 經常會找不到，這種情況很常見。

現在有了 Snap 軟件包 。當然這不是一個全新的概念，過去已經進行了類似的嘗試。用户可以在一個長期支持版本上運行最新的軟件，而不必去使用最新的 Ubuntu 發行版。雖然我認為目前還處於 Snap 軟件包的早期，但是我很期待可以在一個穩定的發行版上運行的嶄新的軟件。

最明顯的問題是，如果你要運行很多軟件，那麼 Snap 包實際會佔用很多硬盤空間。不僅如此，大多數 Ubuntu 軟件仍然需要由官方從 deb 包進行轉換。第一個問題可以通過使用更大的硬盤空間得到解決，而後一個問題的解決則需要等待。

Ubuntu 社區 ​

首先，我承認大多數主要的 Linux 發行版都有強大的社區。然而，我堅信 Ubuntu 社區的成員是最多樣化的，他們來自各行各業。例如，我們的論壇包括從蘋果硬件支持到遊戲等不同分類。特別是這些專業的討論話題還非常廣泛。

除過論壇，Ubuntu 也提供了一個很正式的社區組織。這個組織包括一個理事會、技術委員會、本地社區團隊和開發者成員委員會。還有很多，但是這些都是我知道的社區組織部分。

我們還有一個 Ubuntu 問答版塊。我認為，這種功能可以代替人們從論壇尋求幫助的方式，我發現在這個網站你得到有用信息的可能性更大。不僅如此，那些提供的解決方案中被選出的最精準的答案也會被寫入到官方文檔中。

Ubuntu 的未來 ​

我認為 Ubuntu 的 Unity 界面（LCTT 譯註：Unity 是 Canonical 公司為 Ubuntu 操作系統的 GNOME 桌面環境開發的圖形化界面）在提升桌面佔有率上少有作為。我能理解其中的緣由，現在它主要做一些諸如可以使開發團隊的工作更輕鬆的事情。但是最終，我還是認為 Unity 為 Ubuntu MATE 和 Linux Mint 的普及鋪平道路。

我最好奇的一點是 Ubuntu's IRC 和郵件列表的發展（LCTT 譯註：可以在 Ubuntu LoCo Teams 的 IRC Chat 上提問關於地方團隊和計劃的事件的問題，也可以和一些不同團隊的成員進行交流）。事實是，他們都不能像 Ubuntu 問答板塊那樣文檔化。至於郵件列表，我一直認為這對於合作是一種很痛苦的過時方法，但這僅僅是我的個人看法——其他人可能有不同的看法，也可能會認為它很好。

你怎麼看？你認為 Ubuntu 將來會佔據主要的份額嗎？也許你會認為 Arch 和 Linux Mint 或者其他的發行版會在普及度上打敗 Ubuntu？ 既然這樣，那請大聲説出你最喜愛的發行版。如果這個發行版是 Ubuntu 衍生版 ，説説你為什麼更喜歡它而不是 Ubuntu 本身。如果不出意外，Ubuntu 會成為構建其他發行版的基礎，我想很多人都是這樣認為的。
