GNU KHATA：開源的會計管理軟件 ​

作為一個活躍的 Linux 愛好者，我經常向我的朋友們介紹 Linux，幫助他們選擇最適合他們的發行版本，同時也會幫助他們安裝一些適用於他們工作的開源軟件。

但是在這一次，我就變得很無奈。我的叔叔，他是一個自由職業的會計師。他會有一系列的為了會計工作的漂亮而成熟的付費軟件。我不那麼確定我能在在開源軟件中找到這麼一款可以替代的軟件——直到昨天。

Abhishek 給我推薦了一些很酷的軟件，而其中 GNU Khata 脱穎而出。

GNU Khata 是一個會計工具。 或者，我應該説成是一系列的會計工具集合？它就像經濟管理方面的 Evernote 一樣。它的應用是如此之廣，以至於它不但可以用於個人的財務管理，也可以用於大型公司的管理，從店鋪存貨管理到税率計算，都可以有效處理。

有個有趣的地方，Khata 這個詞在印度或者是其他的印度語國家中意味着賬户，所以這個會計軟件叫做 GNU Khata。

安裝 ​

互聯網上有很多關於舊的 Web 版本的 Khata 安裝介紹。現在，GNU Khata 只能用在 Debian/Ubuntu 和它們的衍生版本中。我建議你按照 GNU Khata 官網給出的如下步驟來安裝。我們來快速過一下。

  • 從這裏下載安裝器。
  • 在下載目錄打開終端。
  • 粘貼複製以下的代碼到終端，並且執行。
sudo chmod 755 GNUKhatasetup.run
sudo ./GNUKhatasetup.run

這就結束了，從你的 Dash 或者是應用菜單中啓動 GNU Khata 吧。

第一次啓動 ​

GNU Khata 在瀏覽器中打開，並且展現以下的畫面。

填寫組織的名字、組織形式，財務年度並且點擊 proceed 按鈕進入管理設置頁面。

仔細填寫你的用户名、密碼、安全問題及其答案，並且點擊“create and login”。

你已經全部設置完成了。使用菜單欄來開始使用 GNU Khata 來管理你的財務吧。這很容易。

移除 GNU KHATA ​

如果你不想使用 GNU Khata 了，你可以執行如下命令移除：

sudo apt-get remove --auto-remove gnukhata-core-engine

你也可以通過新立得軟件管理來刪除它。

GNU KHATA 真的是市面上付費會計應用的競爭對手嗎？ ​

首先，GNU Khata 以簡化為設計原則。頂部的菜單欄組織的很方便，可以幫助你有效的進行工作。你可以選擇管理不同的賬户和項目，並且切換非常容易。它們的官網表明，GNU Khata 可以“像説印度語一樣方便”（LCTT 譯註：原諒我，這個軟件作者和本文作者是印度人……）。同時，你知道 GNU Khata 也可以在雲端使用嗎？

所有的主流的賬户管理工具，比如分類賬簿、項目報表、財務報表等等都用專業的方式整理，並且支持自定義格式和即時展示。這讓會計和倉儲管理看起來如此的簡單。

這個項目正在積極的發展，正在尋求實操中的反饋以幫助這個軟件更加進步。考慮到軟件的成熟性、使用的便利性還有免費的情況，GNU Khata 可能會成為你最好的賬簿助手。

請在評論框裏留言吧，讓我們知道你是如何看待 GNU Khata 的。
