ReactOS 新手指南 ​

ReactOS 是一個比較年輕的開源操作系統，它提供了一個和 Windows NT 類似的圖形界面，並且它的目標也是提供一個與 NT 功能和應用程序兼容性差不多的系統。這個項目在沒有使用任何 Unix 架構的情況下實現了一個類似 Wine 的用户模式。它的開發者們從頭實現了 NT 的架構以及對於 FAT32 的兼容，因此它也不需要負任何法律責任。這也就是説，它不是又雙叒叕一個 Linux 發行版，而是一個獨特的類 Windows 系統，並且是開源世界的一部分。這份快速指南是給那些想要一個易於使用的 Windows 的開源替代品的人準備的。

安裝系統 ​

在開始安裝這個系統之前，我需要説明一下，ReactOS 的最低硬件要求是 500MB 硬盤以及僅僅 96MB 內存。我會在一個 32 位的虛擬機裏面演示安裝過程。

現在，你需要使用箭頭鍵來選擇你想要語言，而後通過回車鍵來確認。

之後，再次敲擊回車鍵來繼續安裝。你也可以選擇按“R”鍵來修復現有的系統。

在第三屏中，你將看到一個警告説這個系統還是早期開發版本。再次敲擊回車鍵，你將看到一個需要你最後確認的配置概覽。如果你認為沒問題，就按回車。

然後，我們就到了分區這一步，在這裏，你可以使用“D”鍵刪除高亮分區，分別使用“P”鍵、“E”鍵以及“L”鍵來添加一個主分區、拓展分區或邏輯分區。如果你想要自己添加一個分區，你需要輸入這個分區的大小（以 MB 為單位），然後通過回車來確認。

但是，如果你有未使用的硬盤空間，在分區過程直接敲擊回車鍵可以自動在你選中的分區上安裝 ReactOS。

再下一步是選擇安裝文件夾。我就使用默認的“/ReactOS”了，應該沒有問題。

然後就是等待...

最後，我們要選擇啓動程序的安裝位置。如果你是在實機上操作的話，第一個選項應該是最安全的。

總地來説，我認為 ReactOS 的安裝嚮導很直接。儘管安裝程序的界面可能看起來一點也不現代、不友好，但是大多數情況下作為用户的我們只需要狂敲回車就能安個差不多。這就是説，ReactOS 的開發版安裝起來也是相對簡單方便的。

ReactOS 之內 ​

當我們歷經千辛萬苦，終於首次進入 ReactOS 的界面時，系統會檢測硬件並自動幫助我們安裝驅動。

在上一張圖片裏你看到的是 ReactOS 的“應用管理器”，這東西是 Linux 的標配。不過你不會在這裏找到任何與 Linux 有關係的東西。只有在這個系統裏工作良好的開源軟件才會在這個管理器中出現。這就導致了管理器中有的分類下擠得滿滿當當，有的卻冷清異常。

我試着通過軟件中心安裝了 Firefox 以及通過直接下載 exe 文件雙擊安裝 Notepad++。這兩個應用都能完美運行：它們的圖標出現在了桌面上，在菜單中也出現了它們的名字，Notepad++ 也出現在了軟件中心右側的分類欄裏。

我沒有嘗試運行任何現代的 Windows 遊戲，如果你想配置 Direct 3D 的話，你可以轉到 “我的電腦/控制選項/WineD3D 配置”。在那裏，你能看到很多 Direct3D 選項，大致與 dx 8 的選項類似。

ReactOS 還有一個好的地方，就是我們可以通過“我的電腦”來操作註冊表。

如果你需要一個簡單點的工具，你可以在應用菜單裏打開註冊表編輯器。

最後，如果你認為 ReactOS 看起來有點過時了的話，你可以在桌面右擊選擇“屬性”，之後在“外觀”那裏選擇你喜歡的主題和顏色。

結論 ​

老實説，我對 ReactOS 的工作方式印象深刻。它相當穩定、連貫、快速，並且真正人性化。拋開 Windows 的陰影（過時的應用菜單，不合理的菜單結構）不談的話，ReactOS 幾乎做到了盡善盡美。它可能不會有太多應用可供選擇，現有的功能也可能不夠強大，但是我確信它將會繁榮壯大。關於它的數據顯示出了它的人氣，我確定將要圍繞它建立起來的社區將會很快就壯大到能把這個項目帶往成功之路的地步。如今，ReactOS 的最新版本是 0.4.1。如果想要以開源的方式運行 Windows 的應用，那麼它就是你的菜！
