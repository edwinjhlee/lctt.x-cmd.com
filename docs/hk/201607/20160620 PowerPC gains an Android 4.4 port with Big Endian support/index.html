Android 4.4 移植到了 PowerPC 架構，支持大端架構 ​

eInfochips（一家軟件廠商） 已將將 Android 4.4 系統移植到 PowerPC 架構，它將用於一家航空電子客户用來監視引擎的健康狀況的人機界面（HMI:Human Machine Interface）。

eInfochips 已經開發了第一個面向 PowerPC 架構的 CPU 的 Android 移植版本，並支持大端（Big Endian）架構。此移植基於 Android 開源項目 [Android Open Source Project (AOSP)] 中 Android 4.4 (KitKat) 的代碼，其功能內核的版本號為 3.12.19。

Android 開始興起的時候，PowerPC 正在快速丟失和 ARM 架構共同角逐的市場。高端的網絡客户和其它的企業級的嵌入式工具大多運行在諸如飛思卡爾（Freescale）的 PowerQUICC 和 QorIQ 這樣的 PowerPC 處理器上，但是並不是 Linux 系統。不過，有幾個 Android 的移植計劃。在 2009 年，飛思卡爾和 Embedded Alley（一家軟件廠商，當前是 Mentor Graphics 的 Linux 團隊的一部分）宣佈了針對 PowerQUICC 和 QorIQ 芯片的移植版本，當前由 NXP 公司構建。另一個名為 Android-PowerPC 的項目也作出了相似的工作。

這些努力來的都並不容易，然而，當航空公司找到 eInfochips，希望能夠為他們那些基於 PowerPC 的引擎監控系統添加 Android 應用程序以改善人機界面。該公司找出了這些早期的移植版本，然而，它們都相距甚遠。所以，他們不得不從頭開始新的移植。

最主要的問題是這些移植的 Android 版本實在是太老了，和現在的 Android 差別太大了。Embedded Alley 移植的版本為 Android 1.5 (Cupcake)，它於 2009 年發佈，Linux 內核版本為 2.6.28。而 Android-PowerPC 項目最後一版的移植是 Android 2.2 (Froyo)，它於 2010 年發佈，內核版本為 2.6.32。此外，航空公司還有一些額外的技術訴求，例如對大端架構（Big Endian）的支持，這種老式的內存訪問方式仍舊應用於網絡通信和電信行業。然而那些早期的移植版本僅能夠支持小端（Little Endian）的內存訪問。

來自 eInfochips 的全新 PowerPC 架構移植 ​

eInfochips, 它最為出名的應該是那些基於 ARM/驍龍處理器的模組計算機板卡，例如 Eragon 600。 它已經完成了基於 QorIQ 的 Android 4.4 系統移植，且發佈了白皮書介紹了該項目。採用該項目的航空電子設備客户仍舊不願透露名稱，目前仍舊不清楚什麼時候會公開此該移植版本。

圖片來自 eInfochips 的Blog日誌

全新的 PowerPC Android 項目包括：

  • 基於 PowerPC e5500 仿生定製
  • 基於 Android KitKat 的大端支持
  • 使用 GCC 5.2 工具鏈開發
  • Android 4.4 框架的 PowerPC 支持
  • PowerPC e5500 的 Android 內核版本為 3.12.19

根據 eInfochips 的銷售經理 Sooryanarayanan Balasubramanian 描述，該航空電子客户想要使用 Android 主要是因為熟悉的界面能夠縮減培訓的時間，並且讓程序更新和增加新程序變得更加容易。他繼續解釋説：“這次成功的移植了 Android，使得今後的工作僅僅需要在應用層作出修修改改，而不再向以前一樣需要在所有層面之間作相互的校驗。”，“這是第一次在航空航天工業作出這些嘗試，這需要在設計時儘量認真。”

通過白皮書，可以知道將 Android 移植到 PowerPC 上需要對框架、核心庫、開發工具鏈、運行時鏈接器、對象鏈接器和開源編譯工具作出大量的修改。在字節碼生成階段，移植團隊決定使用便攜模式（portable mode）而不是快速解釋模式（fast interpreter mode）。這是因為還沒有 PowerPC 可用的快速解釋模式，而使用開源的 libffi 的便攜模式能夠支持 PowerPC。

同時，團隊還面臨着在 Android 運行時 (ART) 環境和 Dalvik 虛擬機 (DVM) 環境之間的選擇。他們發現，ART 環境下的便攜模式還未經測試且缺乏良好的文檔支持，所以最終選擇了 DVM 環境下的便攜模式。

白皮書中還提及了其它的一些在移植過程中遇到的困難，包括重新開發工具鏈，重寫腳本以解決 AOSP 對編譯器標誌“非標準”使用的問題。最終完成的移植版本提供了 37 個服務，以及提供了無界面的 Android 部署，在前端使用用户空間的模擬 UI。

目標硬件 ​

感謝來自 eInfochips Blog日誌 的圖片（如下圖所示），讓我們能夠確認此 PowerPC 的 Android 移植項目的硬件平台。這個板卡為 X-ES Xpedite 6101，它是一個加固級 XMC/PrPMC 夾層模組。

X-ES Xpedite 6101 照片和框圖

X-ES Xpedite 6101 板卡擁有一個可選的 NXP 公司基於 QorIQ T 系列通信處理器（T2081、T1042 和 T1022），它們分別集成了 8 個、4 個和 2 個 e6500 核心，稍有不同的是，T2081 的處理器主頻為 1.8GHz，T1042/22 的處理器主頻為 1.4GHz。所有的核心都集成了 AltiVec SIMD 引擎，這也就意味着它能夠提供 DSP 級別的浮點運算性能。所有以上 3 款 X-ES 板卡都能夠支持最高 8GB 的 DDR3-1600 ECC SDRAM 內存。外加 512MB NOR 和 32GB 的 NAND 閃存。

NXP T2081 框圖

板卡的 I/O 包括一個 x4 PCI Express Gen2 通道，以及雙工的千兆級網卡、 RS232/422/485 串口和 SATA 3.0 接口。此外，它可選 3 款 QorIQ 處理器，Xpedite 6101 提供了三種 X-ES 加固等級，分別是額定工作温度 0 ~ 55°C, -40 ~ 70°C, 或者是 -40 ~ 85°C，且包含 3 類衝擊和抗振類別。

此外，我們已經介紹過的基於 X-ES QorIQ 的 XMC/PrPMC 板卡包括 XPedite6401 和 XPedite6370，它們支持已有的板卡級 Linux 、風河的 VxWorks（一種實時操作系統） 和 Green Hills 的 Integrity（也是一種操作系統）。
