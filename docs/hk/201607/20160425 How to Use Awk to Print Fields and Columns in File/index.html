如何使用 Awk 打印文件中的字段和列 ​

在 Linux Awk 命令系列介紹 的這部分，我們來看一下 awk 最重要的功能之一，字段編輯。

首先我們要知道 Awk 會自動把輸入的行切分為字段，字段可以定義為是一些字符集，這些字符集和其它字段被內部字段分隔符分離。

Awk 輸出字段和列

如果你熟悉 Unix/Linux 或者懂得 bash shell 編程，那麼你也應該知道內部字段分隔符（IFS）變量。Awk 默認的 IFS 是 tab 和空格。

Awk 字段切分的工作原理如下：當獲得一行輸入時，根據定義的 IFS，第一個字符集是字段一，用 $1 表示，第二個字符集是字段二，用 $2 表示，第三個字符集是字段三，用 $3 表示，以此類推直到最後一個字符集。

為了更好的理解 Awk 的字段編輯，讓我們來看看下面的例子：

事例 1:： 我創建了一個名為 tecmintinfo.txt 的文件。

# vi tecmintinfo.txt
# cat tecmintinfo.txt

在 Linux 中創建文件

然後在命令列中使用以下命令打印 tecmintinfo.txt 文件中的第一、第二和第三個字段。

$ awk '//{print $1 $2 $3 }' tecmintinfo.txt
TecMint.comisthe

從上面的輸出中你可以看到，三個字段中的第一個是按照定義的 IFS，也就是空格，打印的。

  • 字段一 “TecMint.com” 使用 $1 訪問。
  • 字段二 “is” 通過 $2 訪問。
  • 字段三 “the” 通過 $3 訪問。

如果你注意打印的輸出，可以看到字段值之間並沒有分隔開，這是 print 默認的方式。

為了在字段值之間加入空格，你需要像下面這樣添加（,）分隔符：

$ awk '//{print $1, $2, $3; }' tecmintinfo.txt

TecMint.com is the

很重要而且必須牢記的一點是，Awk 中 （$） 的使用和在 shell 腳本中不一樣。

在 shell 腳本中 （$） 用於獲取變量的值，而在 Awk 中 （$） 只用於獲取一個字段的內容，而不能用於獲取變量的值。

事例2： 讓我們再看一個使用多行文件 my_shoping.list 的例子。

No	Item_Name		Unit_Price	Quantity	Price
1	Mouse			#20,000		   1		#20,000
2 	Monitor			#500,000	   1		#500,000
3	RAM_Chips		#150,000	   2		#300,000
4	Ethernet_Cables	        #30,000		   4		#120,000

假設你只想打印購物清單中每個物品的 Unit_Price，你需要允許下面的命令：

$ awk '//{print $2, $3 }' my_shopping.txt 

Item_Name Unit_Price
Mouse #20,000
Monitor #500,000
RAM_Chips #150,000
Ethernet_Cables #30,000

Awk 也有一個 printf 命令，它能幫助你用更好的方式格式化輸出，正如你可以看到上面的輸出並不清晰。

使用 printf 格式化輸出 Item_Name 和 Unit_Price：

$ awk '//{printf "%-10s %s\n",$2, $3 }' my_shopping.txt 

Item_Name  Unit_Price
Mouse      #20,000
Monitor    #500,000
RAM_Chips  #150,000
Ethernet_Cables #30,000

總結 ​

使用 Awk 進行文本和字符串過濾時字段編輯功能非常重要，它能幫助你從列表中獲取列的特定數據。同時需要記住 Awk 中 （$） 操作符和 shell 腳本中不一樣。
