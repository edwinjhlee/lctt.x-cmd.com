Ubuntu Linux 的 7 個最佳應用塢 ​

看看以下哪個 Linux 應用塢最適合你。

應用塢Dock 在提升 Ubuntu 或其他 Linux 發行版上的用户體驗和生產力方面起着至關重要的作用。憑藉其流線型和直觀的設計，應用塢可快速訪問經常使用的應用程序、系統設置和工作區管理。

應用塢是個複雜的應用程序，在 Linux 生態系統中僅有少數活躍項目可用。這可能是因為桌面環境提供了將相應的默認面板轉換為應用塢的內置功能。

然而，以下是適用於 Ubuntu 和其他 Linux 發行版的 7 個最佳應用塢。

Linux 的最佳應用塢 ​

Plank ​

最受歡迎和知名的應用塢是 Plank，許多發行版將其作為默認應用塢。例如，elementary OS 使用 Plank 做為其 Pantheon 桌面環境的應用塢。

Plank 的最佳特性是其完備性，無需進行任何自定義。它在默認設置下外觀出色，並能適應任何發行版。

你可以使用以下命令在 Ubuntu、Linux Mint 及相關發行版上安裝 Plank：

sudo apt install plank

安裝完成後，你可以通過命令提示符中輸入 plank，或通過應用程序菜單啓動它。如果你在 Ubuntu 上使用它，請確保使用任何 GNOME 擴展（例如 Just Perfection）隱藏默認的左側 啓動器Dash。

注意： Plank 在 Wayland 上無法工作。你需要使用 X.Org 會話。

Dash to Dock 擴展 ​

如果你正在使用最新的 Ubuntu GNOME 桌面環境，則可以嘗試 “Dash to Dock” 擴展。它不是獨立的應用程序，但可以將你的啓動器轉換為簡單的應用塢。

該擴展還提供了幾個功能，如在多個監視器上顯示應用塢、設置大小/圖標大小和位置。你還可以自定義其不透明度，使用內置主題並更改應用塢的顏色。

要安裝此擴展，先安裝 擴展管理器，然後搜索 “Dash to Dock” 並安裝。

Dock from Dash 擴展 ​

還有另一個 GNOME 擴展，稱為 “Dock from Dash”。乍一看，它與 “Dash to Dock” 看起來可能完全相同，但存在一些區別。

與 “Dash to Dock” 相比，此擴展輕量，使用的資源較少。它也僅提供了一些選項，只提供簡單的應用塢功能。

此外，它還可以自動隱藏應用塢，並可自定義延遲和行為。

因此，如果你想要一個輕量級的 GNOME 擴展，僅具有應用塢功能，請選擇它。

要安裝此擴展，先安裝 擴展管理器，然後搜索 “Dock from Dash” 並安裝。

Latte Dock ​

Latte Dock 以其龐大的自定義選項而聞名。它是 KDE 系統的一部分，並帶有許多依賴項。我將其添加到此列表的主要原因是它是目前最好的應用塢。

然而，問題在於該項目目前沒有在維護。Latte Dock 的開發者已經 離開了該項目。KDE 的自動化機制使該項目保持維護模式。因此，如果需要，只需進行少量調整，它就能正常工作。

許多發行版，如 Garuda Linux，曾將其作為默認選項的一部分。但現在已經不再使用 Latte Dock。

你可以使用以下命令安裝 Latte Dock。如果你在 Ubuntu 上安裝它，請記住它將下載大量的 KDE 生態系統的軟件包。因此，建議你在任何 基於 KDE Plasma 的 Linux 發行版 上使用 Latte 應用塢以獲得最佳體驗。

sudo apt install latte-dock

Docky ​

如果你想要一個類似 macOS 風格的應用塢，可以嘗試使用 Docky。Docky 是一個簡單易用的應用塢，與 GNOME 桌面環境緊密集成。它是一個輕量、快速和可自定義的應用塢，可用於啓動應用程序、訪問文件和管理窗口。

總體而言，Docky 提供了一個視覺吸引力強、可自定義且高效的解決方案，可用於管理應用程序並提升桌面體驗。

但是有一個問題。

Docky 的開發已經停滯。其最後一次發佈是在 2015 年，目前它處於最低限度的維護模式。但是，你仍然可以在 Ubuntu 上安裝它，需要進行一些額外的步驟，因為你需要手動下載依賴項並安裝它們。

在 Ubuntu 中打開終端，並按順序運行以下命令以安裝 Docky。

wget -c http://archive.ubuntu.com/ubuntu/pool/universe/g/gnome-sharp2/libgconf2.0-cil_2.24.2-4_all.deb
wget -c http://archive.ubuntu.com/ubuntu/pool/main/g/glibc/multiarch-support_2.27-3ubuntu1_amd64.deb
wget -c http://archive.ubuntu.com/ubuntu/pool/universe/libg/libgnome-keyring/libgnome-keyring-common_3.12.0-1build1_all.deb
wget -c http://archive.ubuntu.com/ubuntu/pool/universe/libg/libgnome-keyring/libgnome-keyring0_3.12.0-1build1_amd64.deb
wget -c http://archive.ubuntu.com/ubuntu/pool/universe/g/gnome-keyring-sharp/libgnome-keyring1.0-cil_1.0.0-5_amd64.deb

sudo apt install *.deb

wget -c http://archive.ubuntu.com/ubuntu/pool/universe/d/docky/docky_2.2.1.1-1_all.deb
sudo apt install ./docky_2.2.1.1-1_all.deb

安裝之後，你可以在應用菜單中找到它。

DockbarX ​

如果你是 Xfce 桌面的忠實用户，可能聽説過 DockbarX。它在 Xfce 上運行得很好，但你也可以在 Ubuntu、Linux Mint 或 Arch Linux 上安裝它。

DockbarX 帶有大量的自定義選項和調整，可以讓你的桌面看起來令人驚豔。此外，它還支持內置主題，省去了你調整應用塢的功夫。

DockbarX 的一個獨特功能是從應用塢直接顯示正在運行應用程序的窗口預覽。

以下是在 Ubuntu 中安裝的步驟：

sudo add-apt-repository ppa:xuzhen666/dockbarx
sudo apt update
sudo apt install dockbarx
sudo apt install dockbarx-themes-extra

如果你使用的是 Arch Linux，你可以設置任何 AUR 輔助工具，如 Yay，並使用以下命令安裝它。

yay -S dockbarx

KSmoothDock ​

如果你喜歡在應用塢中顯示更多的界面動畫效果，那麼你可以考慮使用 KSmoothDock。它具備所有常見的應用塢功能，並附加了一些額外的特性。

KSmoothDock 的主要吸引力在於“拋物線縮放效果”，如果你喜歡動畫效果，這是一種非常不錯的體驗。

此外，它還提供了圖標和麪板大小、透明度等自定義選項。它是一個構建良好的應用塢，在 KDE Plasma 系列的發行版中應該非常完美。

它提供了一個預編譯的 deb 文件進行安裝，你可以從 KDE 商店下載：

下載 KSmoothDock

一些不活躍的 Linux 應用塢 ​

除了上述的選項外，還有一些非常受歡迎的應用塢已經停止了開發。這些應用塢當前已經無法正常工作，並且安裝它們需要很多努力。你可以查看它們的源代碼進行實驗。

Cairo Dock: 對於最新的 Ubuntu 發行版，目前已不可用。最後一個穩定版本發佈於 2015 年。

Avant Window Navigator: 目前無法正常工作。最後一個發佈版 發佈於 2013 年。

總結 ​

無論你是喜歡簡約的應用塢還是喜歡帶有動畫效果的重型應用塢，希望上述列表可以幫助你選擇最適合你需求的應用塢。不幸的是，幾乎大多數應用塢都沒有積極的開發，而且也沒有新的應用塢在開發。

探索這些選項，嘗試不同的應用塢，並找到一個能夠增強你的 Ubuntu 或其他 Linux 桌面體驗的應用塢。請在評論中告訴我你使用和喜歡的 Linux 應用塢！
