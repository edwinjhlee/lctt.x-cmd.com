什麼是 KDE Connect？怎麼用？ ​

什麼是 KDE Connect？它的主要特性是什麼？它應該如何安裝？本文提供了基本的使用指南。

科技日新月異。有各種軟件、硬件和不同外形的設備。未來，不同設備之間將無縫集成，工作流程會跨越多個設備。每一天，我們都在向跨所有聯網設備發送和接收數據的狀態邁進。而 KDE Connect 就是引領 Linux 桌面系統向這一天進展的一面旗幟。

什麼是 KDE Connect？ ​

KDE Connect 是由 KDE 桌面團隊開發的，提供了 Linux 系統與其他系統，如 Windows、MacOS、Android 及 Linux，的無縫連接。

KDE Connect 安裝後會使你擁有接收電話的通知、發送或接受短信、瀏覽文件、發送或接受文件等許多功能。

此外，KDE Connect 在無線網絡上遵循安全協議，以防止任何隱私泄露。它是自由開源的軟件，出現任何隱患的可能性微乎其微。組合了這些優良特性，KDE Connect 是一款出色的工具。

下文介紹你如何安裝和使用它。

安裝 KDE Connect ​

本文將為你展示如何在 Linux 發行版和安卓智能手機之間連接。Windows 與安卓的連接也應是如此。

KDE Connect 的設置是一個雙向過程。你必須在你的 Linux 發行版和你的安卓智能手機都安裝 KDE Connect。

在 Linux 發行版上安裝 ​

在你的 Linux 發行版上安裝 KDE Connect 很簡單。其在所有的主流 Linux 發行版的官方倉庫中都可用。如果你在用 Ubuntu，並且想在終端安裝，運行如下指令：

sudo apt install kdeconnect

Fedora：

sudo dnf install kdeconnect

Arch Linux：

pacman -S kdeconnect

或在 “軟件Software” 應用中搜索並安裝。

對於 Windows 和其他 Linux 發行版，請參考 這個頁面 的其他幾種下載安裝方式。

在安卓智能手機上安裝 ​

在安卓設備中，在谷歌 Play 商店中搜索 “KDE Connect” 並安裝。

谷歌 Play 商店中的 KDE Connect

如果你在使用某個自由版本的安卓，你可以用下面的鏈接來通過 F-droid 安裝。（感謝我們的讀者提出這一條）。

F-droid 商店中的 KDE Connect

設置 KDE Connect ​

KDE Connect 可以連接相同網絡中的設備。因此，確保你的 Linux 系統和安卓設備都連接到了同一個無線網絡中。

打開你手機裏的 KDE Connect。你應該可以見到你的 Linux 系統的名稱。如果沒有看到任何內容，確保你的設備和 Linux 都連接到了同一個網絡後點擊“刷新Refresh”。

打開 Linux 中的 KDE Connect，你應當見到你的手機進入了下圖展示的樣子。

現在，點開你手機的名稱然後點擊 “配對Pair”。

緊接着你的手機就會收到一個提醒：是否接受配對。選擇 “接受Accept”。

代表你的手機的圖標應當轉為綠色 ，這表示你的手機和 Linux 系統都已經連接且配對。

默認情況下，程序會開啓以下特性：

  • 多媒體控制
  • 遠程輸入
  • 遠程演示
  • 搜尋設備
  • 分享文件

以下的特性需要你的安卓設備的額外權限。因為它們與隱私相關，這意味着你需要手動啓用它們。

  • 短信發送及接收
  • 控制媒體播放器
  • 手機上接受電腦的鍵盤輸入
  • 提醒同步
  • 來電提醒
  • 聯繫人同步
  • 接受鼠標操作

對於這些特性，你需要去手動打開選項，並在安卓手機中授予權限。然後你就可以在 Linux 設備中享受這些服務了。

示例：提醒同步 ​

我將為你演示提醒同步選項應在何處打開。打開你安卓手機中的 KDE Connect 程序，進入 “已連接設備Connected Device” 部分。打開 “提醒同步Notification Sync” 並選擇 “打開設置應用OPEN SETTINGS”。

對 KDE Connect 啓用通知訪問，然後點擊 “允許Allow”。

之後將展示你手機上的提醒到你的 Linux 設備。例如，下面的提醒是我在我的測試安卓設備中收到的。

同樣的信息也展現在了 Linux 系統中的 KDE Connect。

同樣地，在給 KDE Connect 權限後，你可以啓動對你可用的其他服務。

總結 ​

我希望這個指南可以幫助你在你的 Linux 系統和手機中設置 KDE Connect。

你可以在給與一些主要權限後，輕鬆地設置幾個特性，以使 KDE Connect 應用程序發揮最大優勢。配置完成後，你不再需要一直看你的手機。因為你可以在工作時輕易地在你的台式電腦或筆記本上閲讀提示、回消息。
