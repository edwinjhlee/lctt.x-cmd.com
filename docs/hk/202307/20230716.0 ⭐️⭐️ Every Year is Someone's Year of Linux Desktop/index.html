每年都是某個人的 “Linux 桌面之年” ​

當我的第一部特別電影獲得批准時，我正處於為期兩年的 Linux 實驗中。我是如何使用（大多數）開源軟件技術製作我的電影的呢？

我在 2020 年愛上了 Linux。時機不可能更尷尬了。

世界衞生組織宣佈我們這一生中的第一次大流行病降臨。我剛剛從工作中休假，打算利用這段時間完成碩士學位，並完成我處女作《第一次言辭》的續集。

但作家是一羣善變的人。有時我們的注意力可以持續數週，鋭利無比。有時，我們的注意力卻像金魚一樣短暫。

那時我處在金魚模式中。

我需要一些東西來逃離我日復一日的生活：醒來，寫幾個小時，開始學習，完成課程作業，重複。

互聯網上的某個地方有人提到，大流行病為人們提供了在日常計算中嘗試 Linux 的最佳機會。

立刻，金魚般的大腦被吸引住了。

這是有充分理由的：

20 年前，我放棄了電影學院，選擇攻讀計算機科學學士學位。

令我驚訝的是，我發現自己喜歡上了大部分課程（直到我們學習《Java 編程入門》時，我因此退學了，但這是另外一個故事）；《計算機體系結構》、《網絡》和《系統管理》模組真的引起了我的興趣，我發現自己在學校實驗室裏花更多時間在安裝了 Linux 的機器上。

關鍵是我和 Linux 之間有歷史。

而在 2020 年，時機剛剛好。

疫情期間的技術愛好者生活 ​

在我退學後的幾年裏，我遠離了計算機引發我內心的那些好奇心。

作為對電影學院的替代，我成為了一名小説家。

我從信息技術轉向了市場營銷，並花費了 20 多年的時間為平面、電視、廣播和數字平台撰寫廣告文案。

我創辦了自己的廣告代理公司。

在這 20 年裏，我們目睹了社交媒體與互聯網變得同義。

到了 2020 年，我決定永遠離開廣告界，其中很大一部分原因是我對技術的幻想破滅，尤其是對社交媒體的失望，特別是社交媒體以冷漠的方式傷害我們，無論是個人還是整個社會。

雖然我知道社交媒體並不等同於互聯網，但在我的腦海中很難將它們分開。作為一個廣告人，我也覺得自己在使社交媒體無處不在方面起到了一定的作用。

擁有自己的 Linux 桌面之年，在整個大流行期間讓我保持理智。

2022 年：我首部特別電影 ​

到了 2022 年，我已經在我的筆記本電腦上日常使用 Linux。我還買了一台舊的 ThinkPad T420，安裝了 Ubuntu Server，並開始運行 Plex 和 NextCloud 的實例。

我在 Linux 上感到很自在，幾乎將所有的寫作工作都從 MS Word 和雲存儲轉移到了 Vim 和 GitHub 上。

就在這時，我接到了一位製片人的電話，批准了我的首部特別電影。

此時，我需要做一個決定。在片場剪輯鏡頭時，我需要使用行業標準的非線性編輯器（NLE）。我對 Adobe Premiere 很熟悉，但我知道沒有 Linux 版本。我已經嘗試過 Kden Live 和其他幾個自由開源軟件的替代品，包括內置 NLE 的 Blender，但都不太滿意。

更重要的是，我擔心我的寫作流程 —— 完全基於（Neo）Vim 和 Git ——對我的合作作者來説太陌生。

你好，Windows？ ​

此時，我不得不問自己 Linux 是否準備好應對我未來的電影工作。為了回答這個問題，我提醒自己以下幾點：

Linux 對非技術人員/非程序員來説是開放的（且易於接觸） ​

我已經足夠老了，記得當年 Ubuntu Linux 免費向世界上的任何人寄送安裝光盤。那時，我遇到了一系列我無法解決的硬件問題，而且在我主要工具（MS Word）的高質量替代品方面非常匱乏。

到了 2020 年代，Linux 已經變得截然不同。安裝過程非常簡單，幫助文檔非常詳盡，還有 Linux 的 YouTube 資源，使過渡變得更加順利，我所有的硬件都完美地工作，我準備徹底放棄 MS Word。

Git 是作家的（秘密）好朋友 ​

自從我第一次理解了 Git 的含義和它的用途以來，我就一直這樣認為：不向作家教授 Git 是一種罪過。Linus Torvalds 無意間創造了作家的好朋友。

是的，我知道當 Git 無法正常工作時會有多麼令人沮喪，但是將軟件工程師處理大型代碼庫、多人貢獻的複雜 Git 工作流程剝離後，你會發現它核心的功能似乎剛好為數字時代的作家量身定製。

與此同時，我和我的合作作者面臨兩個問題。由於我們位於不同的大陸，我們需要一個滿足以下條件的系統：

以一種不會將文件弄得一團糟而無法閲讀的方式追蹤更改（這樣在 MS Word、谷歌文檔上進行協作會非常痛苦）；

以行業標準格式格式化劇本，而無需購買 Final Draft 等劇本撰寫軟件。

Git 和 GitHub 滿足了第一個要求。而專門為劇本撰寫創建的標記語法 Fountain 解決了第二個問題。

Linux 和好萊塢 ​

這可能會讓很多人感到驚訝，但自上世紀 90 年代以來，Linux 已經牢固地融入了好萊塢的後期製作工作流程中。

早在 1998 年，《泰坦尼克號》這樣具有標誌性的電影的後期製作中，Linux 就扮演了至關重要的角色。BlackMagic 的 達芬奇調色軟件aVinci Resolve 最初是一款在基於 CentOS 或 RHEL 的系統上運行的首選色彩分級工具。

如今，達芬奇調色軟件已成為一款功能完備的編輯器，是電影製片人和 YouTuber 們的首選工具。對我們 Linux 用户而言，該公司繼續提供其軟件的免費版本以供 Fedora 和基於 Debian 的系統使用。對於 Arch 用户，AUR 中也提供了一個達芬奇調色軟件版本，儘管我沒有親自測試過。具體效果可能因人而異。

如何在大部分 FOSS 技術的支持下完成我的電影 ​

讓我分享一下我的電影製作工作流程。

前期製作 ​

影片概念説明 ​

我使用 NeoVim 和 Org 模式語法編寫了 影片概念説明。Org 模式對於編寫類似報告的文檔結構非常有用。Vim-org 能夠輕鬆將文檔導出為 PDF、LaTeX、HTML 和 doc 格式。我喜歡將我的文檔保存為開放文件標準，以確保在各種設備間的可移植性，所以我選擇了 PDF 格式。下面的截圖是電影拍攝前的最終影片概念説明：

劇本 ​

我與合作作者商定了一種簡單的工作流程。我在一天的時間裏向她介紹了 VSCode、Fountain、Git 和 GitHub 的基本知識，之後她就得心應手了。此後的合作過程基本上是無縫的，基於 Git 的工作流程對我們兩個人來説幾乎成為自然而然的事情。請記住，我們兩個人都不具備軟件背景。下面的圖片顯示了 NeoVim 上正在編輯的 Fountain 劇本文件，而右側的屏幕上是 Zathura PDF 閲讀器 即時渲染的劇本。

製作 ​

每日鏡頭回顧 ​

我們在錫哈拉加雨林進行了主要拍攝，這是該國最古老的森林之一。我們在那裏待了一個星期。我帶上了我的日常使用機（一台運行 Ubuntu Studio 20.04 的 Dell XPS 9750），在一天的拍攝結束後使用達芬奇調色軟件來回顧當天的鏡頭。

使用 Rsync 進行備份 ​

負責備份每日鏡頭素材的工作人員會在主硬盤上進行備份，然後在其他外部存儲設備上進行二次備份。由於我也帶了我的 ThinkPad 服務器，我使用 Rsync 自動化進行備份。

後期製作 ​

編輯 ​

儘管我的 XPS 筆記本內部配置足以處理這個項目，但我並不打算在上面進行影片編輯。最初，我是在工作室的一台運行達芬奇調色軟件的 Windows 機器上進行編輯的。不幸的是，2022 年第二季度，斯里蘭卡經濟陷入了自由落體，該國已經無法償還債務。燃料短缺和停電使得我無法前往工作室進行編輯工作，增加了我的困擾。

就在這時，我的調色師建議我們將項目轉移到我的筆記本電腦上，這樣我就可以在家工作。他多年來一直在 CentOS 上運行達芬奇調色軟件，他認為在 Ubuntu 機器上做同樣的工作沒有問題。為了確保我可以進行快速編輯，他將代理素材轉碼為 ProRes 422 720p。

一旦我們克服了這些小問題，編輯本身就是非常穩定和無壓力的操作。完成後，我的電影製作人朋友們都在問我一台運行 Linux 的筆記本電腦是如何處理這個項目的。

結論：我們到達目的地了嗎？ ​

在某個時刻，每個最近轉向 Linux 的人都會參與到“Linux 桌面之年”的辯論中。

三年過去了，我的觀念發生了變化：從理想主義（大約在 2030 年左右），到現實主義（永遠不會發生），再到我目前的立場：《Linux 桌面之年》掌握在“技術探索者”的手中。

“技術探索者”被技術所吸引，有時超出主流的範疇。

而作為對社交媒體技術和大型科技公司感到幻滅的人，我正好處於嘗試 Linux 桌面的理想狀態。

如果以我的經驗為例，大多數精通技術的人都可以實現 “Linux 桌面之年”。通過使用其他自由開源軟件工具（如 Git、Fountain、Markdown、LaTeX、Org 模式和（Neo）Vim），我相信像我這樣的小説家和電影製片人類型的人有足夠的理由轉向 Linux。

當然，如果 Black Magic 沒有推出達芬奇調色軟件的 Linux 版本，我就不能説這番話，但幸運的是，他們不是 Adobe 或微軟。

要讓人們接受 Linux 桌面，關鍵是專有軟件的開發者們也要加入進來，承認 Linux 領域有一些用户需要與 Windows 和 Mac 領域同樣的工具。如果這種情況發生，我們可能會看到 “Linux 桌面” 從梗成為現實。
