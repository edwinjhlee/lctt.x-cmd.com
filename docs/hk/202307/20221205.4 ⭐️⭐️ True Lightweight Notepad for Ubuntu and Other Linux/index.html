真正輕量級的 Linux 記事本 ​

輕量級、資源友好的基於 GUI 的基本記事本列表，適用於 Ubuntu 和其他 Linux。

Linux 是一個因其速度、穩定性和靈活性而廣受歡迎的操作系統。Linux 的一個關鍵特點是能夠根據你的需求自定義和配置系統。這包括選擇適合你係統的正確應用程序和工具。本教程將介紹一些適用於 Linux 的最佳輕量級記事本。我們將查看它們的特點、優缺點，並提供選擇適合你需求的正確記事本的建議。無論你是學生、程序員，還是喜歡做筆記的普通用户，一款優秀的記事本對於任何 Linux 用户來説都是必不可少的工具。

Ubuntu 和其他發行版的最佳輕量級記事本 ​

1、Mousepad ​

該列表中的第一個是流行的文本編輯器 - Mousepad。它是 Xfce 桌面環境的默認文本編輯器，使用 GTK 開發。它簡單輕便，但與本列表中的 Leafpad 相比，它具有更多的設置和功能。

你可以將其視為具有一些額外功能的 Leafpad。

其關鍵特點包括深淺色主題、標籤式編輯、字體和插件功能。你可以在安裝後和使用過程中發現更多類似的設置。

由於 Mousepad 在所有主要的 Linux 發行版倉庫中都可用，所以安裝非常簡單。

對於 Ubuntu、Linux Mint 和相關發行版，使用以下命令進行安裝。

sudo apt install mousepad

對於 Fedora Linux，請使用以下命令：

sudo dnf install mousepad

而 Arch Linux 用户可以使用以下命令進行安裝：

sudo pacman -S mousepad

2、Featherpad ​

FeatherPad 是一個獨立於桌面環境的基於 Qt 的輕量級文本編輯器，適用於 Ubuntu 和其他 Linux 發行版。它的一些關鍵特性包括拖放支持、分離和附加標籤、虛擬桌面感知，以及一個可選的固定搜索欄，並有每個標籤的入口。

此外，它可以在搜索時立即突出顯示找到的匹配項，提供了一個停靠窗口用於文本替換，並支持顯示行號和跳轉到特定行。

此外，Featherpad 可以檢測文本編碼，為常見的編程語言提供語法高亮，並支持會話管理。它還具有拼寫檢查（使用 Hunspell）、文本縮放、打印和自動保存等功能。

安裝 Featherpad 很簡單。

對於 Ubuntu 和相關的發行版，你可以使用終端中的以下命令進行安裝：

sudo apt install featherpad

對於 Fedora Linux，請使用以下命令進行安裝：

sudo dnf install featherpad

Arch Linux 用户可以使用以下命令進行安裝：

sudo pacman -S featherpad

3、Leafpad ​

Leafpad 是一個基於 GTK 的簡單的輕量級 Linux 文本編輯器。它旨在快速、易於使用，並且需要最少的資源。Leafpad 具有乾淨直觀的用户界面，提供了你所需的所有基本文本編輯工具，如剪切、複製和粘貼，並支持撤消和重做。此外，它還支持多種編程語言的語法高亮，使其成為程序員的有用工具。

由於其簡單和高效性，Leafpad 是 Linux 用户的熱門選擇。它可能是 Windows 記事本應用程序的完美替代品。它具有所有基本功能，包括自動換行、行號、字體選擇和自動縮進。

但是，在 Ubuntu 上安裝 Leafpad 有些棘手。不幸的是，它在 Universe 倉庫中不可用，只能作為 Snap 軟件包而不是 Flatpak 軟件包使用。

但是，你可以從 Debian 倉庫中獲取並在 Ubuntu 中安裝它。

從 Debian 倉庫下載 deb 文件，並使用以下命令進行安裝。

wget http://ftp.us.debian.org/debian/pool/main/l/leafpad/leafpad_0.8.18.1-5_amd64.deb
sudo dpkg -i leafpad_0.8.18.1-5_amd64.deb

Fedora 用户可以使用以下命令進行安裝：

sudo dnf install leafpad

Arch Linux 用户可以使用以下命令進行安裝：

sudo pacman -S leafpad

4、Beaver 編輯器 ​

Beaver 編輯器是一個輕量級、啓動快速的文本編輯器，具有極少的依賴性。它是基於 GTK+2 庫構建的，不需要額外安裝的庫，非常適合在較舊的計算機和小型 Linux 發行版上使用。Beaver 的核心功能包括基本功能和語法高亮，還可以通過插件添加額外功能。其界面簡潔高效，並包含高質量的 Tango 美術作品。

這是一個有些老舊的應用程序，但它仍然正常工作。目前，它僅適用於 Ubuntu 和相關的發行版。你可以下載預編譯的 deb 文件，並使用以下命令進行安裝：

wget https://www.bristolwatch.com/debian/packages/beaver_amd64.deb
sudo dpkg -i beaver_amd64.deb

5、Gedit ​

Gedit 文本編輯器 是 GNOME 桌面環境的默認文本編輯器，被數百萬用户在諸如 Ubuntu 和 Fedora 等各種 Linux 發行版上使用。它是核心 GNOME 應用程序的一部分，旨在成為一個輕量級的通用文本編輯器。然而，通過其設置和已安裝的插件，Gedit 也包含許多增強生產力的功能，使得它能夠與其他流行的文本編輯器競爭。

儘管如此，它最近已經從 GNOME 桌面的默認編輯器標籤中“降級”。基於現代 GTK4 的 GNOME 文本編輯器 已取而代之。

但它仍然是最好的編輯器之一，你可以通過插件和 各種技巧 將其從簡單的編輯器擴展為更高級的編輯器。

要安裝它，請使用以下命令（針對 Ubuntu 和相關發行版）：

sudo apt install gedit

對於 Fedora Linux 用户，請使用以下命令進行安裝。

sudo dnf install gedit

最後，Arch Linux 用户可以使用以下命令進行安裝：

sudo pacman -S gedit

6. Xed ​

如果你使用 Linux Mint，那麼你可能聽説過 Xed。Xed 是 Linux Mint 的默認文本編輯器，它非常輕量級。作為一個 “Xapp” 應用程序，它遵循 Linux Mint 的設計和功能指南，提供簡單的用户界面、強大的菜單、工具欄和功能。

Xed 的一些主要特點包括：

  • 傳統的用户界面，保持簡潔易用
  • 強大的工具欄和上下文菜單選項，增強功能的能力
  • 語法高亮顯示
  • 配置選項，如標籤、編碼等
  • 支持 UTF-8 文本
  • 編輯遠程服務器文件
  • 廣泛的插件支持，可根據需要添加更多高級功能
  • 支持概覽地圖
  • 可縮放的編輯窗口

Xed 是最好的編輯器之一，可作為 Linux 系統上輕量級記事本的替代品。

如果你使用的是 Linux Mint，它應該是默認安裝的。然而，在 Ubuntu 中安裝它需要運行一系列命令。打開終端並運行以下命令來在 Ubuntu 中安裝 Xed。

wget http://packages.linuxmint.com/pool/import/i/inxi/inxi_3.0.32-1-1_all.deb
wget http://packages.linuxmint.com/pool/backport/x/xapp/xapps-common_2.4.2+vera_all.deb
wget http://packages.linuxmint.com/pool/backport/x/xapp/libxapp1_2.4.2+vera_amd64.deb
wget http://packages.linuxmint.com/pool/backport/x/xed/xed-common_3.2.8+vera_all.deb
wget http://packages.linuxmint.com/pool/backport/x/xed/xed_3.2.8+vera_amd64.deb
sudo dpkg -i inxi_3.0.32-1-1_all.deb
sudo dpkg -i xapps-common_2.4.2+vera_all.deb
sudo dpkg -i libxapp1_2.4.2+vera_amd64.deb
sudo dpkg -i xed-common_3.2.8+vera_all.deb
sudo dpkg -i xed_3.2.8+vera_amd64.deb

有關更多詳情，請訪問 Xed 的 GitHub 存儲庫。

總結 ​

總之，在 Linux 上選擇一個輕量級的記事本對於各種用途至關重要。無論你是需要記筆記、編寫代碼還是編輯文本，輕量級記事本可以讓你的工作更快、更輕鬆、更高效。Linux 操作系統提供了各種記事本應用程序，每個應用程序都具有其獨特的功能和能力。

這份輕量級 Linux 記事本的前幾名（應用程序）列表探討了一些應用程序，包括 Leafpad、Gedit、Mousepad 和其他應用程序。

無論你選擇哪個記事本，你可以確信它將提供你在 Linux 系統上完成工作所需的功能。
