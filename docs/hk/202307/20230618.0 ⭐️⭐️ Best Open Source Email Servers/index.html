最佳開源電子郵件服務器 ​

這是一份可以用於發送/接收電子郵件並存儲郵件的開源郵件服務器列表。

無論你使用何種 電子郵件客户端，使用像 Gmail、Proton Mail 和 Outlook 這樣的電子郵件服務非常方便。

為了實現這一切，你利用的是它們的郵件服務器進行電子郵件傳輸。因此，你的電子郵件的安全性、可靠性和隱私性取決於他人。

但是，如果你希望擁有自己的電子郵件基礎設施並控制數據，那麼你需要一個開源電子郵件服務器來解決這個問題。

讓我解釋得更清楚一些，電子郵件服務器可以讓你：

  • 構建自己的郵件後端以存儲電子郵件帳户
  • 通過自託管來掌控安全性和可靠性
  • 在你首選的服務器架構上進行託管
  • 讓你能夠創建無限數量的帳户

當然，這些並不適用於終端用户。中小型企業的系統管理員和自託管者才能用得上這些軟件。

考慮到你現在對開源電子郵件服務器的好處有了一定了解，下面是一些你可以找到的最佳選項：

📋 這個列表包括郵件服務器和一些能夠構建/創建郵件服務器的解決方案。其中一些可能提供託管服務，而另一些可以進行自託管。

1、Postal ​

Postal 是一個功能豐富的郵件服務器，可供網站和服務器使用。它專為出站郵件而設計，沒有郵箱管理功能。（LCTT 譯註：出站郵件指外發郵件，入站郵件指接收郵件供郵件客户端收取。）

它的 文檔 對於入門非常有幫助。你可以使用 Docker 在服務器上配置 Postal。

使用 Postal，你可以為多個組織創建郵件服務器/用户，訪問出站/入站消息隊列，實時的遞交信息，並使用內置功能確保電子郵件能夠傳遞。

主要亮點：

  • 實時的遞交信息
  • 點擊和打開追蹤
  • 專為出站郵件設計

🚧 維護和配置你的電子郵件服務器並非易事。只有在全面瞭解可靠地發送/接收電子郵件所需的一切情況下，才應繼續設置郵件服務器。

2、mailcow ​

mailcow 是一個郵件服務器套件，其中包含幫助你構建 Web 服務器、管理郵箱等工具。

如果你不打算發送交易性電子郵件，mailcow 可以助你一臂之力。你可以將其視為一個團隊協作工具。

（LCTT 譯註：交易性電子郵件是指促進商業交易或關係的電子郵件，或提供關於正在進行的商業交易的最新信息。常見的例子包括： 訂單確認、通知電子郵件等，例如，運輸確認和更新，或訂單退款。）

與其他郵件服務器一樣，它與 Docker 搭配使用，每個容器是一個應用程序，它們之間相互連接。

mailcow 的 Web 用户界面可讓你在一個地方完成所有操作。你可以在其 GitHub 頁面 或 文檔 中瞭解更多關於該項目的信息。

主要亮點：

  • 易於管理和更新
  • 可提供經濟實惠的付費支持
  • 如果需要，可以與其他郵件服務器配合使用

3、Cuttlefish ​

想要一個簡單的交易性郵件服務器嗎？Cuttlefish 是一個簡單易用的開源郵件服務器。

你可以通過簡單的 Web 用户界面查看統計數據，監控出站郵件。

與一些完整的電子郵件服務（如 SendGrid 或 Mailgun）相比，Cuttlefish 在功能方面可能沒有那麼全面，它目前仍處於測試階段（beta）。如果你需要超級簡單且可靠的解決方案，可以選擇它。

在其 GitHub 頁面 上了解更多信息。

主要亮點：

  • 簡單的交易性郵件服務器
  • 簡單易用

4、Apache James ​

James 是 “Java Apache Mail Enterprise Server” 的縮寫。

顧名思義，James 是一個使用 Java 構建的面向企業的開源郵件服務器。根據需求，你可以將該郵件服務器用作 SMTP 中繼或 IMAP 服務器。

與其他郵件服務器相比，James 可能不是最容易配置或安裝的。但是，你可以查看其 文檔 或 GitHub 頁面 來自行評判。

主要亮點：

  • 配置完成後易於管理
  • 可靠，並被開源企業使用
  • 分佈式服務器

5、Haraka ​

Haraka 是一個使用 Node.js 構建的現代開源 SMTP 服務器。如果你可以為你的業務/網站構建它，你就不需要尋找其他 SMTP 服務。

這個郵件服務器專為提供最佳性能而設計。Haraka 的一個亮點是，它具有模組化插件系統，允許程序員根據需要更改服務器的行為。

你可以將其視為一款出色的可擴展的出站郵件遞交服務器。一些知名的網站如 Craigslist 和 DuckDuckGo Email Protection 就使用了 Haraka。

在其 GitHub 頁面 上可以瞭解更多信息。

主要亮點：

  • 使用 Node.js 構建
  • 插件系統以擴展功能

6、Modoboa ​

Modoboa 是一個多合一的開源解決方案。

它可以幫助你構建郵件服務器，併為你管理電子郵件帳户。你可以創建日曆，無限制添加域名，創建過濾規則和訪問 Webmail。如果你希望獲得專業幫助來設置和管理系統，Modoboa 還提供付費維護選項。

除了是一個多功能解決方案外，它還提供了一種快速入門的方式來構建你的電子郵件基礎架構。

主要亮點：

  • 全能選項
  • 提供付費幫助
  • 內置監控功能

7、Postfix ​

Postfix 是一種 郵件傳輸代理Mail Transfer Agent（MTA）。它本身可能不是一個獨立的服務器，但它可以與其他一些解決方案配合使用來構建電子郵件服務器。

雖然 mailcow 包含了 Postfix（你可以將其配置與類似的解決方案一起使用），但你也可以根據你的使用情況選擇單獨使用它。在 Ubuntu 服務器中，Postfix 也是默認的郵件傳輸代理。

Postfix 可以用作外部 SMTP。不要忘記，你還可以設置 Postfix 與 Gmail 配合使用。Postfix 容易配置，並且其文檔對於使用它非常有用。

主要亮點：

  • 易於配置
  • 靈活

8、Maddy ​

Maddy 是一個輕量級郵件服務器實現的不錯選擇。官方描述稱它是一款“可組合的一體化郵件服務器”。

與 mailcow 相比較，你會發現 Maddy 提供了一些與 mailcow 相同的功能，也就是説它不僅僅侷限於出站郵件等功能。

Maddy 在使用場景上非常受歡迎，它可以用單一實現替代多個選項，如 Postfix。你可以通過 SMTP 和 IMAP 使用 Maddy 進行發送、接收和存儲消息。文章撰寫時，存儲功能仍處於測試階段（beta）。

主要亮點：

  • 輕量級
  • 替代多種用例，比如 Postfix 等選項
  • 不依賴 Docker

9、Dovecot ​

Dovecot 是一個開源的 IMAP 服務器，作為 郵件傳遞代理Mail Delivery Agent（MDA）發揮作用。它可以與 Postfix 一起工作，因為它們執行不同的任務。

與其他解決方案相比，Dovecot 提供了易於管理、可靠的電子郵件發送功能和自我修復能力。

對於大型基礎設施，Dovecot 提供了專業支持的高級方案。

主要亮點：

  • 易於管理
  • 自我修復能力
  • 專注於性能

10、Poste.io ​

Poste.io 使用了郵件服務器解決方案，如 Haraku、Dovecot 和其他開源組件。從垃圾郵件過濾工具到防病毒引擎，應有盡有。

如果你想使用其中一些組件設置一個開源郵件服務器，並能夠輕鬆管理和保護系統，Poste.io 是一個很好的選擇。

主要亮點：

  • 使用多個開源郵件服務器組件進行易管理和構建
  • 管理面板界面

11、iRedMail ​

iRedMail 類似於 mailcow，它幫助你使用各種開源組件構建郵件服務器。你還可以使用創建的郵件服務器管理你的日曆。

儘管你可以自行設置，但如果需要，它也提供付費的專業支持。

你將獲得一個 Web 面板，在支持的 Linux 發行版上進行託管，並能夠創建無限數量的賬户。

主要亮點：

  • 簡單易用
  • Web 面板進行易管理

12、Mailu ​

Mailu 是一個基於 Docker 的郵件服務器，可以為你提供最好的服務，同時限制了一些功能。

這並不意味着它不好；Mailu 的目標是專注於必要功能，而不添加對大多數人無用的許多功能。即便如此，它仍然通過添加 ARM 支持、Kubernetes 支持和其他一些功能而脱穎而出。

你將獲得一個標準的郵件服務器、高級電子郵件功能、Web 管理界面和注重隱私的功能。

主要亮點：

  • 簡單的界面
  • 關注於功能而不是花俏的解決方案
  • ARM 支持

準備構建和管理你的郵件服務器了嗎？ ​

使用開源工具和郵件服務器，你可以掌握你的數據，併為你的業務或網站管理/優化電子郵件通信。

正如我所提到的，這需要很多工作。因此，如果你希望擁有定製化的體驗並且有一個可以負責的團隊，那麼開源自託管的郵件服務器是可行的選擇。

💬 當然，還有很多其他選項可供選擇，比如 mail in a box，可以幫助你快速部署郵件服務器。

在這裏，我們嘗試為你挑選最佳選擇以供參考。你最喜歡的開源郵件服務器是什麼？
