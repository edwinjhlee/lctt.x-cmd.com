15 個最佳 GTK 主題 ​

我們為各種 Linux 發行版提供了一個全新的最佳 GTK 主題列表。

桌面外觀在你的 Linux 整體體驗中起着重要作用。GTK 主題提供了一種簡單而強大的方式來定製你的桌面環境的外觀。應用 GTK 主題使你可以更改顏色、窗口裝飾和整體樣式，以適應你的喜好。

除了 KDE Plasma 和 LXQt 之外，大多數受歡迎的桌面環境都基於 GTK。因此，瞭解當今最好的 GTK 主題是很重要的。

在 Linux 上安裝 GTK 主題相對簡單。安裝説明通常在主題的官方網站上。通常，它包括下載主題文件並將它們（提取後）放置在主目錄下的 ~/.themes 文件夾中。

讓我們深入瞭解在 2023 年最流行的前 15 個 GTK 主題。

2023 年最佳 GTK 主題 ​

Orchis ​

Orchis 是一款備受推崇的 GTK 主題，因其清新獨特的設計而廣受歡迎。受到 macOS Big Sur 外觀的啓發，Orchis 為 Linux 桌面帶來了流暢而現代的外觀。

Orchis 因其將 macOS Big Sur 的優雅引入 Linux 生態系統而受到認可。通過結合現代設計和 Fluent Design 語言的元素，Orchis 提供了一個視覺吸引力和一致性的用户界面，增強了整體桌面體驗。無論你喜歡淺色還是深色變體，Orchis 都為你的 Linux 桌面提供了一種清新而精緻的外觀。

注意：該主題支持 libadwaita/GTK4 主題。因此，適用於 GNOME 40+ 桌面。

WhiteSur ​

WhiteSur 是一個受到 macOS Big Sur 流暢設計啓發的 GTK 主題。以下是其主要特點：

  • 採用了 macOS Big Sur 的美學設計，帶有圓角和半透明窗口。
  • 提供了淺色和深色模式以滿足不同偏好。
  • 在基於 GTK 的應用程序中保持一致的設計。
  • 注重細節，具有平滑動畫和清晰的陰影。
  • 可自定義選項，包括強調色、窗口裝飾和按鈕樣式。

WhiteSur 兼容多種 Linux 桌面環境，如 GNOME、Xfce 和 Cinnamon，使其能夠受到廣大用户的喜愛。通過 WhiteSur 乾淨統一的界面，在你的 Linux 桌面上體驗 macOS Big Sur 的優雅。

注意：該主題還支持 GTK4/libadwaita 主題。

下載 WhiteSur 主題

Vimix ​

Vimix 是一款受歡迎的 GTK 主題，為 Linux 桌面環境提供時尚現代的外觀。以下是它的主要特點：

  • Vimix 採用了時尚現代的設計風格，具有扁平界面、簡潔線條和細微漸變。
  • 該主題提供了多種顏色變體，包括淺色的 Vimix Light 和深色的 Vimix Dark。
  • Vimix 兼容多種 Linux 桌面環境，包括 GNOME、Xfce、Cinnamon 等，適用於各種 Linux 用户。

Vimix 通過現代設計元素的結合、顏色的多樣性以及與各種桌面環境的兼容性而受到歡迎。其時尚的外觀和自定義選項使其成為尋求視覺上愉悦和一致用户界面的 Linux 用户的絕佳選擇。

注意：它支持現代的 GTK4/libadwaita 主題。

你可以從下面的頁面下載 Vimix 主題。

Prof-GNOME-theme ​

Prof-GNOME-theme 是一個著名的 GTK 主題，為 Linux 桌面環境（特別是 GNOME）帶來了專業而精緻的外觀。以下是其主要特點：

  • Prof-GNOME-theme 採用了簡潔而專業的設計，呈現出極簡主義的風格、優雅的線條和精緻的美學。
  • 該主題採用了細膩而優雅的調色板，專注於中性色調和柔和的變化，營造出寧靜而專業的氛圍。
  • 該主題確保在基於 GTK 的應用程序中保持一致，為整個桌面環境提供了協調和和諧的體驗。

Prof-GNOME-theme 受到專業人士和欣賞乾淨精緻桌面環境的用户的青睞。它注重細節，專注於專業主義，使它成為那些尋求精緻而優雅外觀的 Linux 桌面用户的絕佳選擇。

Ant ​

Ant 是一款受歡迎的 GTK 主題，以其簡潔和極簡主義的設計而聞名。其主要特點包括：

  • 清爽而扁平的美學，帶有微妙的陰影。
  • 一致且清晰的圖標。
  • 色彩平衡而悦目。
  • 支持淺色和深色變體。
  • 與 GNOME 桌面環境無縫集成。

用户可以在其 Linux 系統上享受到 Ant 主題帶來的現代且視覺上愉悦的體驗。其簡約和優雅外觀，使其成為尋求 GTK 應用程序和桌面的精緻外觀的人士的首選。

Flat Remix ​

Flat Remix 是一款備受讚譽的 GTK 主題，為 Linux 桌面提供了清新現代的外觀。它的主要特點包括：

  • 扁平和極簡主義的設計，色彩鮮明。
  • 在基於 GTK 的應用程序中保持一致和統一的外觀。
  • 全面的圖標集，提供精細的視覺體驗。
  • 支持淺色和深色變體。

Flat Remix 為 Linux 桌面環境帶來了愉悦的觸感，提升了整體美學和用户體驗。其鮮明的色彩和協調的設計使其受到喜歡清潔和現代界面的用户的歡迎。

注意：該主題不支持 GTK4/libadwaita。

Fluent ​

Fluent GTK 主題是一款現代時尚的主題，受到了微軟的 Fluent Design System 的啓發。以下是其主要特點：

  • 光滑和精緻的外觀，融入了 Fluent Design 的深度、動態和透明度原則。
  • 基於 Fluent 的圖標提供了一致和統一的外觀。
  • 與基於 GTK 的應用程序無縫集成，提供一致的用户體驗。
  • 支持淺色和深色模式，允許用户個性化他們的桌面。
  • 持續開發和定期更新，確保與最新的 GTK 版本兼容。

Fluent GTK 主題為 Linux 桌面帶來了微軟設計的優雅風采，吸引了欣賞現代和精緻視覺體驗的用户。其遵循 Fluent Design 指南並持續發展，使其成為尋求現代和精緻 GTK 主題的人士的理想選擇。

注意：該主題支持 GTK4/libadwaita 主題。

Grvbox ​

Grvbox 是一款受 Vim 著名配色方案 gruvbox 啓發的熱門 GTK 主題。以下是其主要特點：

  • 温暖復古的調色板讓人想起老式終端界面。
  • 經過精心設計，提供舒適和愉悦的視覺體驗。
  • 提供淺色和深色變體，讓用户選擇其喜好的風格。
  • 與基於 GTK 的應用程序無縫集成，確保一致和統一的外觀。
  • 定期更新和社區支持，確保與最新的 GTK 版本兼容。

Grvbox 主題為 Linux 桌面帶來了懷舊的魅力，喚起了熟悉和簡約的感覺。其精心選擇的顏色和注重細節，使其受到那些欣賞基於 GTK 的應用程序和桌面環境的復古魅力的愛好者的喜愛。

注意：該主題支持 GTK4/libadwaita 主題。

Graphite ​

Graphite 是適用於基於 GTK 的桌面環境的深色主題。它旨在簡約而優雅，非常適合希望擁有乾淨、無干擾界面的用户。

Graphite 主題基於 Adwaita 主題，並擁有許多相同的功能。但是，Graphite 具有更暗的色彩調色板和更加簡約的設計。

如果你正在尋找一款既簡約又優雅的深色主題，那麼 Graphite 主題是一個很好的選擇。它易於安裝和使用，並與許多桌面環境兼容。

Material ​

Material 是一款受到 Material for Neovim 和 Graphite 主題（上面有提到）啓發的廣為人知的 GTK 主題。以下是其主要特點：

  • 清爽現代的美學，採用扁平設計元素和鮮明色彩。
  • 一致且協調的圖標設計，符合 Material Design 的指南。
  • 提供淺色和深色變體，讓用户自定義視覺體驗。
  • 與基於 GTK 的應用程序無縫集成，確保統一的外觀和感覺。
  • 定期更新和社區支持，確保與最新的 GTK 版本兼容。

Material 主題將流行的 Material Design 風格帶到了 Linux 桌面，提供了視覺上令人愉悦且直觀的用户體驗。憑藉其時尚的設計和與各種 GTK 環境的兼容性，Material 主題受到喜歡現代和和諧界面的用户的歡迎。

注意：該主題支持現代的 GTK4/libadwaita 主題。

你可以從下面的頁面下載並安裝 Material 主題：

下載 Material 主題

Arc ​

Arc 主題是 Linux 社區中受歡迎的 GTK 主題，以其流線型和現代的設計而聞名。它提供了乾淨、簡約的外觀，與各種桌面環境（特別是 GNOME）相得益彰。以下是 Arc 主題的一些主要特點：

  • 美觀的設計，擁有平滑曲線和扁平界面
  • 多種顏色變體，包括 Arc、Arc-Darker 和 Arc-Dark
  • 可更改按鈕樣式、標題欄佈局和窗口邊框的選項

Arc 主題將美學和功能性融為一體，成為許多尋求視覺上愉快和一致用户界面的 Linux 用户的首選。

然而，當前版本的主題不支持現代的 GTK4/libadwaita。

你可以從下面的官方倉庫中下載 Arc 主題（這是原始 Arc 主題的另一個分支）：

下載 Arc 主題

Nordic ​

Nordic 是一款備受讚譽的 GTK 主題，受到北歐地區寧靜景色的啓發。以下是其主要特點：

  • 細膩而舒緩的調色板讓人想起極光和雪景。
  • 淺色和深色元素的和諧組合，提供最佳的對比度和可讀性。
  • 高度精心設計的圖標完美地補充了整體美學。
  • 跨平台兼容，使用户可以在各種基於 GTK 的環境中享受 Nord 主題。
  • 定期更新和社區支持，確保持續的改進和兼容性。

Nordic 主題為 Linux 桌面帶來了寧靜和優雅的氛圍，讓用户沉浸在一個視覺上迷人的環境中。其精心選擇的顏色和對細節的關注，使其在尋求視覺上愉快和放鬆的 GTK 主題的 Linux 系統用户中廣受歡迎。

它還附帶了一個適用於 Firefox 的主題，以獲得更好的外觀和集成。

注意：該主題支持現代的 GTK4/libadwaita 主題。

Adapta ​

Adapta 是一款備受讚譽的 GTK 主題，以其多功能性和現代設計而聞名。

Adapta 主題增強了 Linux 桌面的時尚和適應性風格，允許用户在保持精緻和統一外觀的同時個性化他們的界面。它的靈活性和持續發展使其成為那些尋求現代且可定製的 GTK 主題的人們的首選。

Equilux ​

Equilux 是一款適用於基於 GTK+ 的桌面環境的暗色主題。它的設計旨在中性且不分散注意力，非常適合在低光環境下使用或對亮色敏感的人士。

Equilux 主題基於 Materia 主題，並擁有許多相同的功能。然而，Equilux 使用了更柔和的調色板，使其更適合於暗環境。

如果你正在尋找一款既中性又不分散注意力的暗色主題，那麼 Equilux 主題是一個很好的選擇。它易於安裝和使用，並且與各種桌面環境兼容。

注意：該主題的開發已經 停止。不會有進一步的更新。

Paper ​

Paper 是一款廣為人知的 GTK 主題，以其簡約而優雅的設計而聞名。以下是其主要特點：

  • 乾淨而扁平的視覺風格，具有微妙的陰影效果。
  • 精心設計的圖標提供了一致且精緻的外觀。
  • 提供多種顏色變體，包括淺色和深色主題。
  • 維護良好且積極開發，確保與最新的 GTK 版本兼容。
  • 支持 GNOME、Xfce 和 Unity 等流行的桌面環境。

Paper 以其極簡的風格和注重細節的特點，為用户提供了視覺上愉悦和和諧的桌面體驗。其多樣的顏色選項和與多種桌面環境的兼容性，使其成為尋求時尚和現代外觀的 Linux 愛好者的熱門選擇。

注意：該主題的開發在 2016 年已結束。不支持現代的 GTK4+。

關於 Adwaita 的説明 ​

流行的 Adwaita 主題是最好和最穩定的 GTK 主題之一。我之前沒有將其列入上述列表的原因是它已經作為默認主題包含在許多發行版中，用户已經在其系統中安裝了該主題。

總結 ​

上述 GTK 主題代表了各種風格的不同口味，從現代設計到充滿活力和豐富多彩的美學。無論你偏好極簡的外觀還是視覺上驚豔的界面，都可以找到適合你口味的 GTK 主題。我鼓勵你嘗試上述主題並搭配各種圖標和鼠標主題，以獲得更好的體驗。
