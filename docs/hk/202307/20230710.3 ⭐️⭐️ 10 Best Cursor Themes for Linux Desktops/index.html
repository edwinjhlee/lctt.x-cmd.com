Linux 桌面的十個最佳光標主題 ​

一個用於各種 Linux 桌面的最佳光標主題的混合列表。

在 定製 Linux 桌面 時，我們經常忽視光標主題。一個經過深思熟慮選擇的光標主題可以提升你的 Linux 桌面，增添個性化的風格並提升整體美感。從簡約而精緻的設計到奇妙而有趣的動畫，這裏是十個適合每個人的最佳光標主題。

如何在 Linux 桌面下載和安裝光標主題 ​

對於下面列出的所有主題，在相應頁面上找到下載鏈接。下載壓縮文件並解壓縮。然後，將頂層的主題文件夾複製到 Linux 發行版中的 ~/.icons 或 /usr/share/icons 目錄中。然後按照下面的步驟進行相應桌面的設置。

Xfce ​

從應用菜單中選擇 “設置Settings > 設置管理Settings manager > 鼠標和觸摸板Mouse and Touchpad”。然後轉到 “主題Themes” 選項卡並選擇相應的光標主題。你還可以選擇光標大小。

KDE Plasma ​

從 KDE 應用菜單打開 “系統設置System Settings”。然後選擇 “工作空間主題Workspace theme > 光標Cursors”。選擇主題並點擊 “應用Apply”。

GNOME ​

對於 GNOME 桌面，請安裝 GNOME “調整Tweaks” 工具。你可以在基於 Debian 的系統上使用以下命令進行安裝。

sudo apt install gnome-tweak-tool

安裝後，你可以打開 GNOME 調整工具並選擇 “外觀Appearance”。然後從下拉菜單中選擇光標。

Linux 的最佳光標主題 ​

Bibata ​

Bibata 是一套備受讚譽的光標主題，已成為尋求個性化體驗的用户的最愛。這個主題因其獨特的圓角外觀和各種顏色選項而最近變得流行起來。

這個多功能主題有各種變體，包括 Bibata Original Amber 和 Bibata Modern Amber，分別具有帶有黃色調的尖鋭或圓角邊緣。同樣，Bibata Original Classic 和 Bibata Modern Classic 提供帶有尖鋭或圓角邊緣的黑色光標。而 Bibata Original Ice 和 Bibata Modern Ice 提供帶有尖鋭或圓角邊緣的白色光標。

你可以從下面的頁面下載這個主題。

下載 Bibata 光標（Ice）

Phinger ​

Phinger 光標以其複雜的設計和精心的工程而聞名，是最複雜和“過度設計”的光標主題之一。它與 GNOME、MATE 和 Xfce 桌面環境兼容，併為不同 Linux 發行版的用户提供了多功能選項。該主題擁有黑白兩種變體，確保簡約而精緻的光標體驗。

你可以從下面的頁面下載它，並按照上面給出的説明進行安裝。

下載 Phinger 光標

Comix ​

Comix 光標是個早期的光標主題，為你的 Linux 桌面注入了令人愉悦的漫畫風格。這個 X11 鼠標主題包含 12 個獨特的光標主題，每個主題都設計成在提升桌面工作流程的同時喚起一種活潑有趣的氛圍。

Comix 光標提供了六種顏色選擇（黑色、藍色、綠色、橙色、紅色和白色），為用户提供了一系列選擇，以適應他們的個人風格和桌面美學。Comix 主題中的每個光標都具有微妙的陰影效果，為其注入活力和深度。這種動態元素增強了光標的視覺吸引力，併為桌面工作流程增添了一種動感。

你可以從下面的頁面下載這個光標主題。

下載 Comix 光標

McMojave ​

McMojave 光標從 macOS 獲得靈感，是一個 x-cursor 主題，它基於流行的 capitaine-cursors 主題。這個主題旨在重新創建在 macOS 中找到的熟悉的光標樣式，讓 Linux 用户在他們的桌面上享受一絲 Mac 的體驗。

（LCTT 譯註：x-cursor 是一種標準，用於描述和命名光標主題的文件格式和規範。x-cursor 主題通常用於 Linux 操作系統中的桌面環境，如 GNOME、KDE 和 Xfce。）

儘管 McMojave 光標旨在重現 macOS 的光標體驗，但它也為喜歡添加個人特色的用户提供了自定義選項。用户可以根據自己的喜好進行調整和修改，從而在 Linux 上實現個性化的光標體驗。

你可以從下面的頁面下載 McMojave 光標。

下載 McMojave 光標

Layan ​

Layan 光標是一個 x-cursor 主題，靈感來自受歡迎的 Layan GTK 主題，並融入了成熟的 capitaine-cursors 的元素。這個獨特的光標主題給 Linux 桌面體驗增添了一絲時髦感。

與傳統的箭頭形狀光標不同，Layan 光標採用了獨特的橢圓形狀設計。這種非傳統的形狀為整體光標體驗增添了一種活潑和時髦的元素，使它與更傳統的主題有所區別。

你可以使用下面的鏈接進行下載。

下載 Layan 光標

Material ​

Material 光標是 Linux 用户長期以來的最愛，提供了一個視覺上吸引人的光標主題，得到了無數忠實用户的認可。該光標主題有三種顏色變體，即 Material（藍灰）、Dark 和 Light，以及從 24 像素到 64 像素的多種尺寸選項，適應了各種偏好和桌面環境。

成千上萬的人每天都依賴於這個光標主題，展示了它持久的吸引力和可靠性。

憑藉其三種顏色變體、多樣的尺寸選項和廣泛的採用，這個光標主題旨在提升你 Linux 桌面的美學，提供令人愉悦和沉浸式的光標體驗。

你可以使用下面的鏈接下載這個光標主題。

下載 Material 光標

Oreo ​

Oreo 光標以其豐富多彩的材質設計和迷人的動畫為你的 Linux 桌面增添了令人愉悦的元素。這些光標旨在為你的光標體驗增添一絲奇趣和個性。

Oreo 光標的獨特之處在於其迷人的動畫效果。這些動畫光標註入了一種活潑和生動的元素，使你與桌面的交互感覺更具吸引力和愉悦感。

此外，這個主題通過提供自定義顏色生成器更進一步。用户可以使用配置文件創建自己的光標顏色方案，為光標設計帶來無限的可能性和個性化。

你可以使用下面的鏈接下載這個主題。

下載 Oreo 光標

Bibata Rainbow ​

Bibata Rainbow 光標擴展自受歡迎的 Bibata 光標主題，引入了半動畫的彩虹顏色，增強了你的 Linux 桌面體驗。這些光標是使用 clickgen 精心製作，並用 puppeteer 渲染的，確保高質量的視覺效果和平滑的動畫。

Bibata Rainbow 中的每個光標包含大約 23 個幀，即使在 HiDPI（高像素密度）環境下，也能實現平滑的動畫效果。這確保了具有高分辨率顯示屏的用户可以享受無縫和視覺上令人愉悦的光標體驗。

你可以使用下面的鏈接下載 Bibata Rainbow 光標主題。

Miniature ​

Miniature 光標是從一個同名 Windows 光標主題移植的，它提供了一種以小尺寸為特點的獨特光標體驗。顧名思義，這些光標被設計成緊湊型，可能非常適合各種用途。該主題整體採用清晰的白色，並提供了一個扁平設計和一個帶有微妙陰影效果的變體。

你可以從下面的鏈接下載這個光標主題。

下載 Miniature 光標

Capitaine ​

Capitaine 光標是一個 x-cursor 主題，靈感來自 macOS，基於 KDE Breeze 圖標包，提供了一種視覺上協調的光標體驗。這個光標主題旨在與 La Capitaine 圖標包完美配合，為你的 Linux 桌面創建一個統一的視覺風格。

Capitaine 光標提供了白色和黑色兩種變體，讓用户可以根據自己的桌面環境或個人偏好選擇最合適的顏色。無論你喜歡淺色還是深色光標，Capitaine 光標都能滿足你的需求。

結論 ​

在本文中，我們介紹了一些令人着迷的 Linux 光標主題，展示了一系列受歡迎的選擇，可以改變你與桌面的交互方式。我希望你能找適合你 Linux 桌面上喜愛的主題或圖標包的完美光標。
