UC 瀏覽器最大的問題 ​

在我們開始談論缺點之前，我要確定的事實是過去 3 年來，我一直是一個忠實的 UC 瀏覽器用户。我真的很喜歡它的下載速度，超時尚的用户界面和工具上引人注目的圖標。我一開始是 Android 上的 Chrome 用户，但我在朋友的推薦下開始使用 UC。但在過去的一年左右，我看到了一些東西讓我重新思考我的選擇，現在我感覺我要重新回到 Chrome。

不需要的通知 ​

我相信我不是唯一一個每幾個小時內就收到這些不需要的通知的人。這些欺騙點擊的文章真的很糟糕，最糟糕的部分是你每隔幾個小時就會收到一次。

我試圖從通知設置裏關閉他們，但它們仍然以一個更低頻率出現。

新聞主頁 ​

另一個不需要的部分是完全無用的。我們完全理解 UC 瀏覽器是免費下載，可能需要資金，但並不應該這麼做。這個主頁上的新聞文章是非常讓人分心且不需要的。有時當你在一個專業或家庭環境中的一些誘騙點擊甚至可能會導致尷尬。

而且他們甚至有這樣的設置。將 UC 新聞顯示打開/關閉。我也試過，猜猜看發生了什麼。在下圖中，左側你可以看到我的嘗試，右側可以看到結果。

而且不止誘騙點擊新聞，他們已經開始添加一些不必要的功能。所以我也列出它們。

UC 音樂 ​

UC 瀏覽器在瀏覽器中集成了一個音樂播放器來播放音樂。它只是能用，沒什麼特別的東西。那為什麼還要呢？有什麼原因呢？誰需要瀏覽器中的音樂播放器？

它甚至不是在後台直接播放來自網絡的音頻。相反，它是一個播放離線音樂的音樂播放器。所以為什麼要它？我的意思是，它甚至沒有好到可以作為主要音樂播放器。即使它足夠好，它也不能獨立於 UC 瀏覽器運行。所以為什麼會有人運行將他/她的瀏覽器只是為了使用你的音樂播放器？

快速訪問欄 ​

我已經看到平均有 90% 的用户在通知區域掛着這欄，因為它默認安裝，並且它們不知道如何擺脱它。右側的設置可以擺脱它。

但是我還是想問一下，“為什麼它是默認的？”。這讓大多數用户很頭痛。如果我們需要它，就會去啓用它。為什麼要強迫用户。

總結 ​

UC 瀏覽器仍然是最大的玩家之一。它提供了一個最好的體驗，但是，我不知道 UC 通過在瀏覽中打包進將越來越多的功能並強迫用户使用它們是要證明什麼。

我喜歡 UC 的速度和設計。但最近的體驗導致我再次考慮我的主要瀏覽器。
