在命令列中使用 DuckDuckGo 搜索 ​

此前我們介紹了如何在命令列中使用 Google 搜索。許多讀者反饋説他們平時使用 Duck Duck Go，這是一個功能強大而且保密性很強的搜索引擎。

正巧，最近出現了一款能夠從命令列搜索 DuckDuckGo 的工具。它叫做 ddgr（我把它讀作 “dodger”），非常好用。

像 Googler 一樣，ddgr 是一個完全開源而且非官方的工具。沒錯，它並不屬於 DuckDuckGo。所以，如果你發現它返回的結果有些奇怪，請先詢問這個工具的開發者，而不是搜索引擎的開發者。

DuckDuckGo 命令列應用 ​

DuckDuckGo Bangs（DuckDuckGo 快捷搜索） 可以幫助你輕易地在 DuckDuckGo 上找到想要的信息（甚至 本網站 omgubuntu 都有快捷搜索）。ddgr 非常忠實地呈現了這個功能。

和網頁版不同的是，你可以更改每頁返回多少結果。這比起每次查詢都要看三十多條結果要方便一些。默認界面經過了精心設計，在不影響可讀性的情況下儘量減少了佔用空間。

ddgr 有許多功能和亮點，包括：

  • 更改搜索結果數
  • 支持 Bash 自動補全
  • 使用 DuckDuckGo Bangs
  • 在瀏覽器中打開鏈接
  • ”手氣不錯“選項
  • 基於時間、地區、文件類型等的篩選功能
  • 極少的依賴項

你可以從 Github 的項目頁面上下載支持各種系統的 ddgr：

  • 從 Github 下載 “ddgr”

另外，在 Ubuntu 16.04 LTS 或更新版本中，你可以使用 PPA 安裝 ddgr。這個倉庫由 ddgr 的開發者維護。如果你想要保持在最新版本的話，推薦使用這種方式安裝。

需要提醒的是，在本文創作時，這個 PPA 中的 ddgr 並不是 最新版本，而是一個稍舊的版本（缺少 -num 選項）。

使用以下命令添加 PPA：

sudo add-apt-repository ppa:twodopeshaggy/jarun
sudo apt-get update

如何使用 ddgr 在命令列中搜索 DuckDuckGo ​

安裝完畢後，你只需打開你的終端模擬器，並運行：

ddgr

然後輸入查詢內容：

search-term

你可以限制搜索結果數：

ddgr --num 5 search-term

或者自動在瀏覽器中打開第一條搜索結果：

ddgr -j search-term

你可以使用參數和選項來提高搜索精確度。使用以下命令來查看所有的參數：

ddgr -h
