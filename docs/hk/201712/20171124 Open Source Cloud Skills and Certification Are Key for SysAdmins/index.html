開源雲技能認證：系統管理員的核心競爭力 ​

2017年開源工作報告（以下簡稱“報告”）顯示，具有開源雲技術認證的系統管理員往往能獲得更高的薪酬。

報告調查的受訪者中，53% 認為系統管理員是僱主們最期望被填補的職位空缺之一，因此，技術嫺熟的系統管理員更受青睞而收穫高薪職位，但這一職位，並沒想像中那麼容易填補。

系統管理員主要負責服務器和其他電腦操作系統的安裝、服務支持和維護，及時處理服務中斷和預防其他問題的出現。

總的來説，今年的報告指出開源領域人才需求最大的有開源雲（47%），應用開發（44%），大數據（43%），開發運營和安全（42%）。

此外，報告對人事經理的調查顯示，58% 期望招攬更多的開源人才，67% 認為開源人才的需求增長會比業內其他領域更甚。有些單位視開源人才為招聘最優選則，它們招聘的開源人才較上年增長了 2 個百分點。

同時，89% 的人事經理認為很難找到頗具天賦的開源人才。

為什麼要獲取認證 ​

報告顯示，對系統管理員的需求刺激着人事經理為 53% 的組織/機構提供正規的培訓和專業技術認證，而這一比例去年為 47%。

對系統管理方面感興趣的 IT 人才考慮獲取 Linux 認證已成為行業規律。隨便查看幾個知名的招聘網站，你就能發現：CompTIA Linux+ 認證是入門級 Linux 系統管理員的最高認證；如果想勝任高級別的系統管理員職位，獲取紅帽認證工程師（RHCE）和紅帽認證系統管理員（RHCSA）則是不可或缺的。

戴士（Dice）2017 技術行業薪資調查顯示，2016 年系統管理員的薪水為 79,538 美元，較上年下降了 0.8%；系統架構師的薪水為 125,946 美元，同比下降 4.7%。儘管如此，該調查發現“高水平專業人才仍最受歡迎，特別是那些精通支持產業轉型發展所需技術的人才”。

在開源技術方面，HBase（一個開源的分佈式資料庫）技術人才的薪水在戴士 2017 技術行業薪資調查中排第一。在計算機網絡和資料庫領域，掌握 OpenVMS 操作系統技術也能獲得高薪。

成為出色的系統管理員 ​

出色的系統管理員須在問題出現時馬上處理，這意味着你必須時刻準備應對可能出現的狀況。這個職位追求“零責備的、精益的、流程或技術上交互式改進的”思維方式和善於自我完善的人格，成為一個系統管理員意味着“你必將與開源軟件如 Linux、BSD 甚至開源 Solaris 等結下不解之緣”，Paul English ^譯註1 在 opensource.com 上發文指出。

Paul English 認為，現在的系統管理員較以前而言，要更多地與軟件打交道，而且要能夠編寫腳本來協助系統管理。

譯註1：Paul English，計算機科學學士，UNIX/Linux 系統管理員，PreOS Security Inc. 公司 CEO，2015-2017 年於為推動系統管理員發展實踐的非盈利組織——專業系統管理員聯盟League of Professional System Administrator擔任董事會成員。

展望 2018 ​

Robert Half 2018 年技術人才薪資導覽預測 2018 年北美地區許多單位將聘用大量系統管理方面的專業人才，同時個人軟實力和領導力水平作為優秀人才的考量因素，越來越受到重視。

該報告指出：“良好的聆聽能力和批判性思維能力對於理解和解決用户的問題和擔憂至關重要，也是 IT 從業者必須具備的重要技能，特別是從事服務枱和桌面支持工作相關的技術人員。”

這與Linux基金會^譯註2 提出的不同階段的系統管理員必備技能相一致，都強調了強大的分析能力和快速處理問題的能力。

譯註2：Linux 基金會The Linux Foundation，成立於 2000 年，致力於圍繞開源項目構建可持續發展的生態系統，以加速開源項目的技術開發和商業應用；它是世界上最大的開源非盈利組織，在推廣、保護和推進 Linux 發展，協同開發，維護“歷史上最大的共享資源”上功勳卓越。

如果想逐漸爬上系統管理員職位的金字塔上層，還應該對系統配置的結構化方法充滿興趣；且擁有解決系統安全問題的經驗；用户身份驗證管理的經驗；與非技術人員進行非技術交流的能力；以及優化系統以滿足最新的安全需求的能力。
