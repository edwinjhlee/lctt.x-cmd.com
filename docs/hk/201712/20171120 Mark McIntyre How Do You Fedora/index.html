Mark McIntyre：與 Fedora 的那些事 ​

最近我們採訪了 Mark McIntyre，談了他是如何使用 Fedora 系統的。這也是 Fedora 雜誌上系列文章的一部分。該系列簡要介紹了 Fedora 用户，以及他們是如何用 Fedora 把事情做好的。如果你想成為採訪對象，請通過反饋表與我們聯繫。

Mark McIntyre 是誰? ​

Mark McIntyre 為極客而生，以 Linux 為樂趣。他説：“我在 13 歲開始編程，當時自學 BASIC 語言，我體會到其中的樂趣，並在樂趣的引導下，一步步成為專業的碼農。” Mark 和他的侄女都是披薩餅的死忠粉。“去年秋天，我和我的侄女開始了一個任務，去嘗試諾克斯維爾的許多披薩餅連鎖店。點擊這裏可以瞭解我們的進展情況。”Mark 也是一名業餘的攝影愛好者，並且在 Flickr 上 發佈自己的作品。

作為一名開發者，Mark 有着豐富的工作背景。他用過 Visual Basic 編寫應用程序，用過 LotusScript、 PL/SQL（Oracle）、 Tcl/TK 編寫代碼，也用過基於 Python 的 Django 框架。他的強項是 Python。這也是目前他作為系統工程師的工作語言。“我經常使用 Python。由於我的工作變得更像是自動化工程師， Python 用得就更頻繁了。”

McIntyre 自稱是個書呆子，喜歡科幻電影，但他最喜歡的一部電影卻不是科幻片。“儘管我是個書呆子，喜歡看《星際迷航Star Trek》、《星球大戰Star Wars》之類的影片，但《光榮戰役Glory》或許才是我最喜歡的電影。”他還提到，電影《衝出寧靜號Serenity》是一個著名電視劇的精彩後續（指《螢火蟲》）。

Mark 比較看重他人的謙遜、知識與和氣。他欣賞能夠設身處地為他人着想的人。“如果你決定為另一個人服務，那麼你會選擇自己願意親近的人，而不是讓自己備受折磨的人。”

McIntyre 目前在 Scripps Networks Interactive 工作，這家公司是 HGTV、Food Network、Travel Channel、DIY、GAC 以及其他幾個有線電視頻道的母公司。“我現在是一名系統工程師，負責非線性視頻內容，這是所有媒體要開展線上消費所需要的。”他為一些開發團隊提供支持，他們編寫應用程序，將線性視頻從有線電視發佈到線上平台，比如亞馬遜、葫蘆。這些系統既包含預置系統，也包含雲系統。Mark 還開發了一些自動化工具，將這些應用程序主要部署到雲基礎結構中。

Fedora 社區 ​

Mark 形容 Fedora 社區是一個富有活力的社區，充滿着像 Fedora 用户一樣熱愛生活的人。“從設計師到封包人，這個團體依然非常活躍，生機勃勃。” 他繼續説道：“這使我對該操作系統抱有一種信心。”

2002 年左右，Mark 開始經常使用 IRC 上的 #fedora 頻道：“那時候，Wi-Fi 在啓用適配器和配置模組功能時，有許多還是靠手工實現的。”為了讓他的 Wi-Fi 能夠工作，他不得不重新去編譯 Fedora 內核。

McIntyre 鼓勵他人蔘與 Fedora 社區。“這裏有許多來自不同領域的機會。前端設計、測試部署、開發、應用程序打包以及新技術實現。”他建議選擇一個感興趣的領域，然後向那個團體提出疑問。“這裏有許多機會去奉獻自己。”

對於幫助他起步的社區成員，Mark 讚道：“Ben Williams 非常樂於助人。在我第一次接觸 Fedora 時，他幫我搞定了一些 #fedora 支持頻道中的安裝補丁。” Ben 也鼓勵 Mark 去做 Fedora 大使。

什麼樣的硬件和軟件? ​

McIntyre 將 Fedora Linux 系統用在他的筆記本和台式機上。在服務器上他選擇了 CentOS，因為它有更長的生命週期支持。他現在的台式機是自己組裝的，配有 Intel 酷睿 i5 處理器，32GB 的內存和2TB 的硬盤。“我裝了個 4K 的顯示屏，有足夠大的地方來同時查看所有的應用。”他目前工作用的筆記本是戴爾靈越二合一，配備 13 英寸的屏，16 GB 的內存和 525 GB 的 m.2 固態硬盤。

Mark 現在將 Fedora 26 運行在他過去幾個月裝配的所有機器中。當一個新版本正式發佈的時候，他傾向於避開這個高峯期。“除非在它即將發行的時候，我的工作站中有個正在運行下一代測試版本，通常情況下，一旦它發展成熟，我都會試着去獲取最新的版本。”他經常採取就地更新：“這種就地更新方法利用 dnf 系統升級插件，目前表現得非常好。”

為了搞攝影，McIntyre 用上了 GIMP、Darktable，以及其他一些照片查看包和快速編輯包。當不用 Web 電子郵件時，Mark 會使用 Geary，還有GNOME Calendar。Mark 選用 HexChat 作為 IRC 客户端，HexChat 與在 Fedora 服務器實例上運行的 ZNC bouncer 聯機。他的部門通過 Slave 進行溝通交流。

“我從來都不是 IDE 粉，所以大多數的編輯任務都是在 vim 上完成的。”Mark 偶爾也會打開一個簡單的文本編輯器，如 gedit，或者 xed。他用 GPaste 做複製和粘貼工作。“對於終端的選擇，我已經變成 Tilix 的忠粉。”McIntyre 通過 Rhythmbox 來管理他喜歡的播客，並用 Epiphany 實現快速網絡查詢。
