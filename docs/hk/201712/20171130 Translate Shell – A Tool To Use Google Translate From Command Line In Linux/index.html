Translate Shell ：一款在 Linux 命令列中使用谷歌翻譯的工具 ​

我對 CLI 應用非常感興趣，因此熱衷於使用並分享 CLI 應用。 我之所以更喜歡 CLI 很大原因是因為我在大多數的時候都使用的是字符界面（black screen），已經習慣了使用 CLI 應用而不是 GUI 應用。

我寫過很多關於 CLI 應用的文章。 最近我發現了一些谷歌的 CLI 工具，像 “Google Translator”、“Google Calendar” 和 “Google Contacts”。 這裏，我想在給大家分享一下。

今天我們要介紹的是 “Google Translator” 工具。 由於我的母語是泰米爾語，我在一天內用了很多次才理解了它的意義。

谷歌翻譯為其它語系的人們所廣泛使用。

什麼是 Translate Shell ​

Translate Shell (之前叫做 Google Translate CLI) 是一款藉助谷歌翻譯（默認）、必應翻譯、Yandex.Translate 以及 Apertium 來翻譯的命令列翻譯器。它讓你可以在終端訪問這些翻譯引擎。 Translate Shell 在大多數 Linux 發行版中都能使用。

如何安裝 Translate Shell ​

有三種方法安裝 Translate Shell。

  • 下載自包含的可執行文件
  • 手工安裝
  • 通過包管理器安裝

方法 1 : 下載自包含的可執行文件 ​

下載自包含的可執行文件放到 /usr/bin 目錄中。

$ wget git.io/trans
$ chmod +x ./trans
$ sudo mv trans /usr/bin/

方法 2 : 手工安裝 ​

克隆 Translate Shell 的 GitHub 倉庫然後手工編譯。

$ git clone https://github.com/soimort/translate-shell && cd translate-shell
$ make
$ sudo make install

方法 3 : 通過包管理器 ​

有些發行版的官方倉庫中包含了 Translate Shell，可以通過包管理器來安裝。

對於 Debian/Ubuntu， 使用 APT-GET 命令 或者 APT 命令來安裝。

$ sudo apt-get install translate-shell

對於 Fedora, 使用 DNF 命令 來安裝。

$ sudo dnf install translate-shell

對於基於 Arch Linux 的系統, 使用 Yaourt 命令 或 Packer 明快 來從 AUR 倉庫中安裝。

$ yaourt -S translate-shell
or
$ packer -S translate-shell

如何使用 Translate Shell ​

安裝好後，打開終端閉關輸入下面命令。 谷歌翻譯會自動探測源文本是哪種語言，並且在默認情況下將之翻譯成你的 locale 所對應的語言。

$ trans [Words]

下面我將泰米爾語中的單詞 “நன்றி” (Nanri) 翻譯成英語。 這個單詞的意思是感謝別人。

$ trans நன்றி
நன்றி
(Naṉṟi)

Thanks

$ trans -b :ta thanks
நன்றி

使用下面格式可以使用 Translate Shell 來翻譯文件。

$ trans :ta file:///home/magi/gtrans.txt
உங்கள் வாழ்க்கையில் என்ன நடக்கிறது?
