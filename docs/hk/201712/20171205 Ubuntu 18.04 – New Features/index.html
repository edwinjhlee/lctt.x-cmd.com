Ubuntu 18.04 新功能、發行日期和更多信息 ​

我們一直都在翹首以盼 —— 新的 Ubuntu 的 LTS 版本 —— 18.04。瞭解有關新功能，發行日期以及更多信息。

提示：我們將經常在這篇文章中更新新的信息，所以請為此頁面添加書籤，然後再回來查看。

關於 Ubuntu 18.04 的基本信息 ​

讓我們以一些基本信息開始。

  • 這是一個新的 LTS（長期支持）版本。所以對桌面版和服務器版有 5 年的支持。
  • 被命名為 “Bionic Beaver”（仿生河狸）。Canonical 的創始人 Mark Shuttleworth 解釋了這個名字背後的含義。吉祥物是一個河狸，因為它充滿活力，勤勞，並且是一個很棒工程師 —— 這完美地描述了一個典型的 Ubuntu 用户，以及新的 Ubuntu 發行版本身。使用 “Bionic”（仿生）這個形容詞是由於在 Ubuntu Core 上運行的機器人數量的增加。

Ubuntu 18.04 發行日期和日程 ​

如果你是 Ubuntu 的新手，你可能並不熟悉實際的版本號意味着什麼。它指的是官方發行的年份和月份。所以 Ubuntu 18.04 正式發佈將在 2018 年的第 4 個月。Ubuntu 17.10 於 2017 年發佈，也就是今年的第 10 個月。

對進一步的細節，這裏是有關 Ubuntu 18.04 LTS 的重要日期和需要知道的：

  • 2017 年 11 月 30 日 - 功能定義凍結。
  • 2018 年 1 月 4 日 - 第一個 Alpha 版本。所以，如果您選擇接收新的 Alpha 版本，那麼您將在這天獲得 Alpha 1 更新。
  • 2018 年 2 月 1 日 - 第二個 Alpha 版本。
  • 2018 年 3 月 1 日 - 功能凍結。將不會引入或發佈新功能。所以開發團隊只會在改進現有功能和修復錯誤上努力。當然也有例外。如果您不是開發人員或有經驗的用户，但仍想嘗試新的 Ubuntu ASAP，那麼我個人建議從此版本開始。
  • 2018 年 3 月 8 日 - 第一個 Bata 版本。如果您選擇接收 Bata 版更新，則會在當天得到更新。
  • 2018 年 3 月 22 日 - 用户界面凍結。這意味着不會對實際的用户界面做進一步的更改或更新，因此，如果您編寫文檔，教程，並使用屏幕截圖，那時開始是可靠的。
  • 2018 年 3 月 29 日 - 文檔字符串凍結。將不會有任何編輯或新的東西（字符串）添加到文檔中，所以翻譯者可以開始翻譯文檔。
  • 2018 年 4 月 5 日 - 最終 Beta 版本。這也是開始使用新版本的好日子。
  • 2018 年 4 月 19 日 - 最終凍結。現在一切都已經完成了。版本的圖像被創建和分發，並且可能不會有任何更改。
  • 2018 年 4 月 26 日 - 官方最終版本的 Ubuntu 18.04。每個人都可以從這一天開始使用它，即使在生產服務器上。我們建議從 Vultr 獲得 Ubuntu 18.04 服務器並測試新功能。Vultr 的服務器每月起價為 2.5 美元。（LCTT 譯註：這是原文廣告！）

Ubuntu 18.04 的新功能 ​

在 Ubuntu 18.04 LTS 上的所有新功能：

現已支持彩色表情符號 ​

在以前的版本中，Ubuntu 只支持單色（黑和白）表情符號，坦白地説，它看起來不是太好。Ubuntu 18.04 將使用Noto Color Emoji font 來支持彩色表情符號。隨着 18.04，你可以在任何地方輕鬆查看和添加顏色表情符號。它們是原生支持的 —— 所以你可以使用它們，而不用使用第三方應用程序或安裝/配置任何額外的東西。你可以隨時通過刪除該字體來禁用彩色表情符號。

GNOME 桌面環境 ​

Ubuntu 從 Ubuntu 17.10 開始使用 GNOME 桌面環境，而不是默認的 Unity 環境。Ubuntu 18.04 將繼續使用 GNOME。這是 Ubuntu 的一個重要的變化。

Ubuntu 18.04 桌面將有一個新的默認主題 ​

Ubuntu 18.04 正在用新的 GTK 主題以告別舊的默認主題 “Ambience”。如果你想幫助新的主題，看看一些截圖甚至更多，去這裏。

到目前為止，有人猜測 Suru 將成 為 Ubuntu 18.04 的新默認圖標主題。這裏有一個截圖：

值得注意的是：Ubuntu 16.10，17.04 和 17.10 中的所有新功能都將滾動到 Ubuntu 18.04 中，這些更新，如右邊的窗口按鈕、更好的登錄屏幕，改進的藍牙支持等將推送到 Ubuntu 18.04。對此我們不會特別説明，因為它對 Ubuntu 18.04 本身並不新鮮。如果您想了解更多關於從 16.04 到 18.04 的所有變化，請谷歌搜索它們之間的每個版本。

下載 Ubuntu 18.04 ​

首先，如果你已經使用 Ubuntu，你可以升級到 Ubuntu 18.04。

如果你需要下載 Ubuntu 18.04：

在最終發佈之後，請進入官方 Ubuntu 下載頁面。

對於每日構建（alpha，beta 和 non-final 版本），請轉到這裏。

常見問題解答 ​

現在是一些經常被問到的問題（附帶答案），這應該能給你關於這一切的更多信息。

什麼時候切換到 Ubuntu 18.04 是安全的？ ​

當然是在正式的最終發佈日期。但是，如果您等不及，請開始使用 2018 年 3 月 1 日的桌面版本，並在 2018 年 4 月 5 日開始測試服務器版本。但是為了確保安全，您需要等待最終發佈，甚至更長時間，使得您正在使用的第三方服務和應用程序經過測試，並在新版本上進行良好運行。

如何將我的服務器升級到 Ubuntu 18.04？ ​

這個過程相當簡單，但潛在風險很大。我們可能會在不久的將來發佈一個教程，但你基本上需要使用 do-release-upgrade。同樣，升級你的服務器也有潛在的風險，並且如果在生產服務器上，我會在升級之前再三考慮。特別是如果你在 16.04 上還剩有幾年的支持。

我怎樣才能幫助 Ubuntu 18.04？ ​

即使您不是一個經驗豐富的開發人員和 Ubuntu 用户，您仍然可以通過以下方式提供幫助：

  • 宣傳它。讓人們瞭解 Ubuntu 18.04。在社交媒體上的一個簡單的分享也有點幫助。
  • 使用和測試版本。開始使用該版本並進行測試。同樣，您不必是一個開發人員。您仍然可以查找和報告錯誤，或發送反饋。
  • 翻譯。加入翻譯團隊，開始翻譯文檔或應用程序。
  • 幫助別人。加入一些在線 Ubuntu 社區，並幫助其他人解決他們對 Ubuntu 18.04 的問題。有時候人們需要幫助，一些簡單的事如“我在哪裏可以下載 Ubuntu？”

Ubuntu 18.04 對其他發行版如 Lubuntu 意味着什麼？ ​

所有基於 Ubuntu 的發行版都將具有相似的新功能和類似的發行計劃。你需要檢查你的發行版的官方網站來獲取更多信息。

Ubuntu 18.04 是一個 LTS 版本嗎? ​

是的，Ubuntu 18.04 是一個 LTS（長期支持）版本，所以你將得到 5 年的支持。

我能從 Windows/OS X 切換到 Ubuntu 18.04 嗎？ ​

當然可以！你很可能也會體驗到性能的提升。從不同的操作系統切換到 Ubuntu 相當簡單，有相當多的相關教程。你甚至可以設置一個雙引導，來使用多個操作系統，所以 Windows 和 Ubuntu 18.04 你都可以使用。

我可以嘗試 Ubuntu 18.04 而不安裝它嗎？ ​

當然。你可以使用像 VirtualBox 這樣的東西來創建一個“虛擬桌面” —— 你可以在你的本地機器上安裝它，並且使用 Ubuntu 18.04 而不需要真正地安裝 Ubuntu。

或者你可以在 Vultr 上以每月 2.5 美元的價格嘗試 Ubuntu 18.04 服務器。如果你使用一些免費賬户（free credits），那麼它本質上是免費的。（LCTT 譯註：廣告！）

為什麼我找不到 Ubuntu 18.04 的 32 位版本？ ​

因為沒有 32 位版本。Ubuntu 的 17.10 版本便放棄了 32 位版本。如果你使用的是舊硬件，那麼最好使用不同的輕量級 Linux 發行版而不是 Ubuntu 18.04。

還有其他問題嗎？ ​

在下面留言！分享您的想法，我們會非常激動，並且一旦有新信息發佈，我們就會更新這篇文章。敬請期待，耐心等待！
