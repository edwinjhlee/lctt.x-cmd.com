Trinity 桌面環境 R14.0.13 版發佈更新 ​

懷念美好的舊式 KDE？Trinity 桌面環境新發布的小版本（TDE R14.0.13）帶來了一些新功能和錯誤修復。以下是發佈摘要。

如果你是那些懷念美好的舊式 KDE（3.5）外觀的人，那麼你可以通過 Trinity 桌面環境（TDE）獲得它。TDE 是一個由志願者組成的小團隊開發的一個復刻版的 KDE 3.5 桌面環境。它是 KDE 3 桌面理念的延續，為那些欣賞其功能和設計的人提供了更新和錯誤修復。

儘管是一個小而獨立的項目，TDE 仍然在積極地開發和維護，為用户提供了一個主流桌面環境的替代品。而繼 之前的 R14.0.12 版本 之後，第 13 個小版本帶來了一些好東西。

Trinity 桌面環境 R14.0.13 的新內容 ​

桌面易用性得到了更新 ​

這個版本引入了使用 Ctrl + 鼠標滾輪 來增加或減少字體大小的功能，這可以用在 Konsole、Kate、KWrite、TDevelop 和其他使用 Kate 嵌入編輯器的應用程序中。此外，Kate 文本編輯器現在包括 Markdown 文件的語法高亮，使其更容易閲讀和編輯這些類型的文檔。

這些增強功能使用户對文本編輯器的外觀有更多的控制，並改善了整體的用户體驗。

此外，Trinity 桌面環境 R14.0.13 還改進了用户設置牆紙的方式，使其更容易設置，也更直觀。Konqueror 的動作菜單現在提供了設置圖像作為背景的各種選項，為用户提供了更多的靈活性和控制力。這些改進提高了設置牆紙時的整體用户體驗，使用户更加方便。

除此之外，這個版本還改進了 khotkeys 輸入動作，為用户提供了更多的控制和靈活性。它的用於創建和編輯動作的圖形用户界面現在包括新的上移/下移按鈕，使其更容易重新排列動作。此外，該版本還包括對圖形用户界面的修復，以提高其整體可用性和性能。這些改進提高了用户在使用 khotkeys 輸入動作時的體驗，使用户更方便地定製他們的鍵盤快捷鍵。這個版本還包括一個新的等待動作組件，允許用户在步驟之間引入一個延遲。

核心和支持 ​

SFTP tdeioslave 已經更新，現在使用 libssh，它提供了更安全和穩定的連接。任務欄現在包括移動任務和拖放分組任務按鈕，增強了用户體驗。

這個版本包括了改進的 API 可視化和增強的 Python3 支持。整個版本使用的語言已經更新為性別中立。這些改進提高了整體的用户體驗，使 TDE 更具包容性和可及性。

除此之外，在核心應用程序方面，TDE R14.0.13 版本包括了幾個更新，以提高與流行的多媒體和文件處理庫的兼容性。這包括對 ffmpeg 5.0、Jasper 3.x 和 Poppler >= 22.04 的支持。這些更新使 TDE 能夠利用這些庫的最新功能和性能改進。此外，這個版本包括了幾個 TDE 應用程序的手冊頁，為用户提供了關於如何使用這些程序的更詳細的文檔和信息。這些改進提高了 TDE 的整體功能和性能。

下載並安裝 Trinity 桌面環境 R14.0.13 ​

如果你使用的是 Ubuntu 22.04 LTS Jammy Jellyfish，你可以運行下面的命令將其安裝在你現有的 Ubuntu 上：

sudo gedit /etc/apt/sources.list

添加以下行並保存文件：

deb http://mirror.ppa.trinitydesktop.org/trinity/deb/trinity-sb jammy deps-r14 main-r14
deb-src http://mirror.ppa.trinitydesktop.org/trinity/deb/trinity-sb jammy deps-r14 main-r14
wget http://mirror.ppa.trinitydesktop.org/trinity/deb/trinity-keyring.deb
sudo dpkg -i trinity-keyring.deb
sudo apt update
sudo apt install kubuntu-default-settings-trinity kubuntu-desktop-trinity

安裝完成後，重新啓動你的系統，在登錄界面選擇 Trinity。注意：截至發稿時，針對 Ubuntu 22.10 Kinetic Kudu 的倉庫還不可用。

對於 Arch Linux 用户，你可以通過以下命令安裝它。

使用管理員權限打開 /etc/pacman.conf，在最後添加以下幾行並保存好：

[trinity]
Server = https://mirror.ppa.trinitydesktop.org/trinity/archlinux/$arch

然後打開一個終端，運行以下內容：

pacman-key --recv-key D6D6FAA25E9A3E4ECD9FBDBEC93AF1698685AD8B
pacman-key --lsign-key D6D6FAA25E9A3E4ECD9FBDBEC93AF1698685AD8B

最後，用下面的方法來安裝：

pacman -Sy
pacman -S td-meta

對於其他發行版，你可以在 本頁 找到 TDE 的詳細下載和安裝指南。
