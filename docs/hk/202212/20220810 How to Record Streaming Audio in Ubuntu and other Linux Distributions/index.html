如何在 Ubuntu 中錄製流媒體音頻 ​

如何在 Ubuntu 和其他 Linux 發行版中錄製音頻？

如果你想通過計算機的麥克風錄製語音，可以使用 GNOME 錄音機Sound Recorder 或 Audacity。

使用 GNOME 錄音機很簡單，但它功能不足。Audacity 最初可能會讓人無從入手，但它有很多專業級錄音的功能。不過，在本教程中，我不打算詳細討論這個問題。

GNOME 錄音機能與麥克風配合使用。還有一個叫做 Audio recorder 的工具，除了麥克風輸入，你可以使用它來錄製流媒體音樂（來自 Sptify、YouTube、互聯網廣播、Skype 和其他大多數來源）。

總而言之，我將向你展示以下步驟：

  • 使用 GNOME 錄音機錄製聲音
  • 使用 Audio Recorder 錄製流音頻

使用 GNOME 錄音機從麥克風錄製音頻 ​

GNOME 桌面環境有很多有用的應用程序，錄音機就是其中之一。

你可以從 Ubuntu 軟件中心安裝 錄音機。

或者，你可以在終端中使用此命令來安裝它：

sudo apt install gnome-sound-recorder

安裝後，你可以在系統菜單中找到它，並從那裏啓動它。

在開始使用它之前，應確保在系統設置中選擇了正確的輸入源：

打開錄音機，它將顯示如下界面：

點擊“錄製Record”按鈕，它立即開始錄製音頻。錄製時，你可以選擇暫停、停止或取消錄製。

你的錄音將保存並可從應用程序界面本身獲得。單擊保存的錄音以突出顯示。

你可以回放或刪除該錄音。你可以通過單擊“保存/下載”按鈕選擇將其保存到其他位置。你也可以使用“編輯”按鈕重命名該錄音。

這很方便，對吧？你可以選擇以 MP3、FLAC 和多種格式錄製。

刪除 GNOME 錄音機 ​

不喜歡它或發現它缺乏功能？

你可以從 Ubuntu 軟件中心刪除 GNOME 錄音機，或使用以下命令：

sudo apt remove gnome-sound-recorder

GNOME 錄音機應用功能有限，它只從麥克風錄製，在某些情況下這不是你想要的。

想像一下你想錄制 Skype 通話或在應用程序或網絡瀏覽器中播放的內容？在這種情況下，漂亮的 Audio Recorder 會有所幫助。

使用 Audio Recorder 來錄製流媒體音頻 ​

你可以使用 官方 PPA 在 Ubuntu 和 LinuxMint 中安裝 Audio Recorder。在終端中依次使用以下命令：

sudo apt-add-repository ppa:audio-recorder/ppa
sudo apt update
sudo apt install audio-recorder

或者，你可以從 啓動台 下載源代碼。安裝後，你可以從“活動概述Activity Overview”裏啓動應用程序：

記錄不同來源的各種聲音 ​

Audio Recorder 記錄計算機產生的各種聲音。

它記錄通過系統聲卡、麥克風、瀏覽器、網絡攝像頭等播放的音頻。

換句話説，即使你的系統打噴嚏，它也會記錄（如果你想記錄的話）。它允許你選擇錄製設備，如網絡攝像頭、麥克風、Skype 等。

要錄製流媒體音樂，請選擇適當的源。例如，如果你正在 Rhythmbox 中播放流媒體廣播，請選擇 Rythmbox。

在你方便的時候錄製 ​

Audio Recorder 還提供了設置計時器的選項。你可以在給定的時鐘時間或預定義的間隔開始、停止或暫停錄製。你還可以設置錄製文件大小的限制。

此外，你可以在沒有音頻（或聲音很低）時暫停（和停止），並在聲音恢復時繼續。

你所要做的就是編輯計時器面板中的文本。註釋掉你不想應用的“規則”，並根據你的要求編輯這些規則。

它提供了其他設置，如登錄時自動啓動、顯示托盤圖標和其他記錄設置。

以各種文件格式保存錄制的音樂文件 ​

另一個寶藏。你可以將錄製的文件保存為你喜愛的文件格式。支持的文件格式有 OGG 音頻、Flac、MP3、SPX 和 WAV。我錄音時更喜歡用 MP3 格式。

錄製的文件存儲在 ~/Audio 中，即主目錄中的“音頻”文件夾中。

Audio Recorder 有多好？ ​

我在 Ubuntu 中使用 Audio Recorder 錄製 YouTube 上播放的音樂。我用 MP3 格式保存了一段 2 分鐘的視頻，佔用了 934 KB 的空間。但我必須説，我沒想到錄製的音質會這麼好。老實説，我無法將它與 YouTube 上的原始歌曲區分開來。

刪除 Audio Recorder ​

如果你不喜歡 Audio Recorder，可以使用以下命令將其刪除：

sudo apt remove audio-recorder

同時刪除 PPA 是個好主意：

sudo apt-add-repository -r ppa:audio-recorder/ppa

結論 ​

Linux 中可能還有其他幾種用於音頻錄製的工具。像 GNOME 一樣，其他桌面環境也可能有錄音應用程序。我知道深度操作系統肯定有一個。

GNOME 錄音機是一個不錯的工具，用於從麥克風錄製聲音。對於錄製各種來源的聲音，Audio Recorder 是一個不錯的選擇。

我希望這篇文章能滿足你的錄音需求。如果你有什麼建議，請告訴我。
