2023 年值得期待的 5 款最佳 Linux 手機 ​

以下是一份可能在 2023 年成為主流的最佳 Linux 手機榜單，並介紹了各個 Linux 手機的特點和價格。

安卓和 iOS 智能手機是世界上最流行的手機。然而，還有許多人都想要更“開放”、且在隱私方面做得更好的手機。如果你使用安卓手機，那麼你就是放棄了你的隱私。在個人隱私保護方面，蘋果的 iOS 手機表現得要好一點，但它也僅提供了有限的隱私保護。

這就是現在 Linux 手機變得很流行的原因，因為它們為開發者和終端用户提供了許多選擇。雖然目前有各種類型的 Linux 手機，但是要選擇最好的 Linux 手機仍然令人困惑。從 2022 年的趨勢來看，以下是一些可能在 2023 年成為主流的 Linux 手機。

關於 Linux 手機，你需要知道的事情 ​

當你瀏覽或者計劃購買一部 Linux 手機之前，你應該先了解以下關於 Linux 手機的事情：

  • Linux 手機使用的是主流 Linux 發行版的修改版，它有一個適合手機的桌面環境。這對今天的大多數手機（例如安卓、蘋果 iOS）來説，也是類似的。
  • 如果你打算買一部 Linux 手機，並將其作為你日常所使用的手機的話，請不要太期待這個 Linux 手機。因為 Linux 手機的操作系統、功能和應用生態系統仍處於早期發展階段，遠遠比不上與安卓或 iOS 手機。
  • 然而，Linux 手機的操作系統提供了最好的隱私功能，這會成為你想要出手買一部 Linux 手機的原因。

最好的 Linux 手機 ​

1、Librem🥇 ​

Purism 公司是 Linux 手機市場上一個相當著名的品牌。Purism 公司推出的 Librem 5 Linux 智能手機支持 PureOS。PureOS 是一個專為 Linux 手機設計的操作系統，不基於安卓或 iOS 系統，它是一個原生設計的自由開源的操作系統；它還支持 融合 convergence ，這意味着你可以通過 USB 集線器將手機插入電腦顯示器，並將其作為一個桌面操作系統使用🆒。

這款手機擁有優質的硬件和手感，還十分注重安全和隱私。但是，這款令人印象深刻的智能手機價格有點貴，售價為 1299 美元💔。

Librem 5 Linux 的主要特點和規格：

  • 完全的自由開源，基於 Linux 的移動操作系統：PureOS
  • 擁有獨立的調製解調器、Wi-Fi 和藍牙芯片
  • 擁有 3 個專門的硬件鍵，來啓用和禁用互聯網、相機、Wi-Fi 和藍牙
  • 擁有智能卡讀卡器
  • 擁有 SD 卡讀卡器
  • 電池可更換

2、Pinephone🥈 ​

Linux 手機榜單的第 2 名是 Pinephone。Pinephone 也許是市場上最完善、最實用的 Linux 手機了。它由 Pine64 公司開發，具有出色的功能，並是支持多種 Linux ARM 的移動發行版。

此外，PinePhone 同時有很多個版本，其中包括專業版本。PinePhone 的價格比較便宜，並且十分注重用户的隱私和可擴展性，如果你是第一次使用 Linux 手機，PinePhone 將會是一個不錯的選擇😌。

Pinephone 的主要特點和規格：

  • 支持的操作系統有 KDE Plasma mobile、Manjaro mobile、Sailfish OS 和 Ubuntu touch。
  • 配備啓用和禁用 LTE、攝像頭、Wifi/BT 和麥克風的 5 個開關
  • 可啓動的 microSD 和 16GB/32GB eMMC 的內存空間
  • Type C 接口（可用於電源、數據和視頻輸出）
  • 擁有 6 個 Pogo 引腳，允許自定義硬件擴展，如熱像儀、無線充電、NFC、擴展電池盒或鍵盤盒。
  • 擁有 3.5 毫米耳機插孔
  • 支持融合，可將其插到一台電腦上
  • 價格實惠，2 種型號的售價分別為 149 美元和 199 美元起

3、Pro 1 X – F(X)tec🥉 ​

Pro 1 X – F(X)tec 是一款提供各種操作系統選擇的智能手機，因此它是 Linux 手機榜單中十分令人激動的一項產品。

Pro 1 X 支持各種操作系統，例如 LineageOS、安卓、Ubuntu Touch 等。此外，一個內置的滑出式鍵盤使它看起來更加獨特且十分有吸引力。

Pro 1 X 由倫敦的 F(x)tec 公司開發。它是 Linux 手機市場上新出的產品，很有前景。然而，這個手機還沒有上市，計劃在 2022 年 12 月開始發貨。因此，你可能需要等待幾天，才能看到別人對這部手機的評價。

Pro 1 X 的主要特點和規格：

  • 首款基於 Linux 的、有內置滑出式的 QUERTY 鍵盤的智能手機
  • 支持 Ubuntu touch 操作系統，並有安卓選項
  • 已解鎖的啓動程序
  • 擁有 3.5 毫米耳機插孔
  • 擁有 AMOLED 顯示屏
  • 128 GB 存儲/6 GB 內存：售價為 829 美元起
  • 256 GB 存儲/8 GB 內存：售價為 899 美元起

4、Volla Phone ​

Volla Phone 可以同時運行兩個操作系統：Ubuntu Touch 和 VollaOS。

VollaOS 是一個安卓操作系統的修改版，沒有谷歌專有的部分，同時也很注重用户的隱私；Ubuntu Touch 是一個流行的 Linux 手機發行版。

Volla Phone 的主要特點和規格：

  • 沒有谷歌專有部分及其服務
  • 不依賴雲計算
  • 加密的設備存儲
  • 使用安卓操作系統的修改版：Volla OS
  • 支持的操作系統有 Ubuntu Touch，Manjaro，Sailfish OS
  • 擁有 USB C 充電口
  • 擁有 3.5 毫米耳機插孔
  • 可以用指紋解鎖
  • 擁有離線地圖

Fairphone 4 是另一款具有模組化硬件的 Linux 智能手機。它支持 PostmarketOS 操作系統，並使用安卓操作系統的修改版本：FairPhone OS。這個手機的主要賣點是它的 模組化 modularity ，你可以替換手機的任何模組：你可以毫不費力地更換它的電池🔋；此外，不僅僅是更換電池，你還可以簡單地用螺絲刀來更換它的顯示屏等部件。

是否有支持 Linux 操作系統的主流安卓手機呢？ ​

如果你不想購買上述現成的 Linux 手機，那麼你也可以在安卓手機上使用 Linux 移動操作系統，因為安卓是基於 Linux 內核上修改的。因此，這些手機應該也能使用 Ubuntu Touch 或 PostmarketOS 操作系統。

  • Google Pixel 3a/3a XL
  • Sony Xperia X (F5121 & F5122)
  • Google Nexus 5
  • OnePlus One
  • 支持 Ubuntu Touch OS 操作系統的 完整列表
  • Xiaomi Redmi 2
  • Xiaomi Mi Note 2
  • OnePlus GT
  • OnePlus 6
  • 支持 PostmarketOS 操作系統的 完整列表

結語 ​

以上就是關於如今市場上最好的 Linux 手機的全部內容了。你可以從這些手機的官方網站上了解更多信息。因為手機的隱私保護在當下變得越來越重要了，我相信在未來會有越來越多的人使用 Linux 手機。

誠然，Linux 手機本身的功能及其操作系統比不上安卓和蘋果 iOS 手機。但是，對於 Linux 手機來説，更重要的是它的標準的設立、全球購買的可行性、在這一新興市場的低入門價格以及對 Linux 手機應用生態系統的大力投資。在 Linux 手機的生態系統中需要更簡化的界面，沒有簡單的界面，Linux 手機將變得更加零散，就像台式機一樣。Linux 手機的製造商還需要和自由及開源軟件（FOSS）參與者一起合作，最終才能使 Linux 手機廣受歡迎。
