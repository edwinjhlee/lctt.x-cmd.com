如何在Ubuntu 14.04 / 15.04中設置IonCube Loaders ​

IonCube Loaders是一個PHP中用於加解密的工具，並帶有加速頁面運行的功能。它也可以保護你的PHP代碼不會查看和運行在未授權的計算機上。要使用ionCube編碼、加密的PHP文件，需要在web服務器上安裝一個叫ionCube Loader的文件，並需要讓 PHP 可以訪問到，很多 PHP 應用都在用它。它可以在運行時讀取並執行編碼過後的代碼。PHP只需在‘php.ini’中添加一行就可以使用這個loader。

前提條件 ​

在這篇文章中，我們將在Ubuntu14.04/15.04安裝Ioncube Loader ，以便它可以在所有PHP模式中使用。本教程的唯一要求就是你係統安裝了LEMP，並有“php.ini”文件。

下載 IonCube Loader ​

根據你係統的架構是32位或者64位來下載最新的IonCube loader包。你可以用超級用户權限或者root用户運行下面的命令。

# wget http://downloads3.ioncube.com/loader_downloads/ioncube_loaders_lin_x86-64.tar.gz

下載完成後用下面的命令解壓到“/usr/local/src/"。

# tar -zxvf ioncube_loaders_lin_x86-64.tar.gz -C /usr/local/src/

解壓完成後我們就可以看到所有提供的模組。但是我們只需要我們所安裝的PHP版本的對應模組。

要檢查PHP版本，你可以運行下面的命令來找出相應的模組。

# php -v

根據上面的命令我們知道我們安裝的是PHP 5.6.4，因此我們需要拷貝合適的模組到PHP模組目錄下。

首先我們在“/usr/local/”創建一個叫“ioncube”的目錄並複製所需的ioncube loader到這裏。

root@ubuntu-15:/usr/local/src/ioncube# mkdir /usr/local/ioncube
root@ubuntu-15:/usr/local/src/ioncube# cp ioncube_loader_lin_5.6.so ioncube_loader_lin_5.6_ts.so /usr/local/ioncube/

PHP 配置 ​

我們要在位於"/etc/php5/cli/"文件夾下的"php.ini"中加入如下的配置行並重啓web服務和php模組。

# vim /etc/php5/cli/php.ini

此時我們安裝的是nginx，因此我們用下面的命令來重啓服務。

# service php5-fpm restart
# service nginx restart

測試 IonCube Loader ​

要為我們的網站測試ioncube loader。用下面的內容創建一個"info.php"文件並放在網站的web目錄下。

# vim /usr/share/nginx/html/info.php

加入phpinfo的腳本後重啓web服務後用域名或者ip地址訪問“info.php”。

你會在最下面的php模組信息裏看到下面這段。

在終端中運行下面的命令來驗證php版本並顯示PHP Loader已經啓用了。

# php -v

上面的php版本輸出明顯地顯示了IonCube loader已經成功與PHP集成了。

總結 ​

教程的最後你已經瞭解瞭如何在安裝有nginx的Ubuntu中安裝和配置ionCube Loader，如果你正在使用其他的web服務，這與其他服務沒有明顯的差別。因此安裝Loader是很簡單的，並且在大多數服務器上的安裝都不會有問題。然而並沒有一個所謂的“標準PHP安裝”，服務可以通過許多方式安裝，並啓用或者禁用功能。

如果你是在共享服務器上，那麼確保運行了ioncube-loader-helper.php腳本，並點擊鏈接來測試運行時安裝。如果安裝時你仍然遇到了問題，歡迎聯繫我們及給我們留下評論。
