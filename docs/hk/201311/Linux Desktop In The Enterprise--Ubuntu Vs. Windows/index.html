Linux企業級桌面版：Ubuntu Vs Windows ​

過去的10年中，Linux的眾多支持者幾乎每年都預言當年會是“linux桌面版之年”。對微軟主導的企業來説，這曾經是一個崇高的目標，但時代在變。在智能手機和雲計算市場領域，Linux已經發展壯大成為一個頑強的競爭對手，打了微軟一個措手不及。更重要的是，Google，IBM，Red Hat，Facebook, 還有Netflix等公司正在對linux的研發創新投入巨資。

現在， 隨着技術預算縮水，微軟授權費上漲，IT界是時候應該認真考慮一下了，部署桌面版Linux，替代Windows。這是個最佳時機，Windows 8.1剛發佈，Ubuntu 13.10也同時發佈。對Windows XP的支持也只剩下5個月時間。IT公司需要切換到新的環境。Ubuntu利用企業的需求來支持他們桌面版操作系統的需求。我研究了幾個促成向桌面版linux轉換的因素，包括培訓和支持，還有一些潛在的複雜性問題。

我知道Ubuntu已經失去了它曾經在開源社區享有的青睞。Canonical，Ubuntu的開創者，做出了幾個不受歡迎的決策，包括改變屏幕管理器（linux圖形界面的基本組件），用內部開發的Mir替換掉Wayland。然而，Ubuntu仍然是完全開源的，並提供任何Linux發行版甚至Windows版本的軟件，安裝起來最為省事。Canonical還提供付費支持，這可能是企業級環境所需要的。

一直存在這樣的爭論，如果切換到一個新的桌面的話，最終用户需要再培訓。微軟做出了爭議性決策，針對Windows 8.1，對熟悉的界面全面整改，這種舉措造成的影響就是，比轉向linux需要更多的培訓。 Ubuntu Unity 桌面已經演變為用户友好的界面，比之Windows 8.1，更易於被終端用户所理解。

例如，比較一下用户在各個操作系統中關閉系統的方式。所有最近的Ubuntu版本，關閉系統只需點擊一下屏幕右上角打開-關閉的圖標。Windows 8.1則需要右擊開始按鈕，然後出現一個下拉菜單，從中找到關閉電源的選項。相較於Windows 8，這是個巨大的進步。Windows 8還得費勁去找相關的入口。總不如屏幕上只需一個圖標來得直接。

多虧了許多流行的開源應用的Windows版本，對使用這些應用軟件的終端用户的培訓過也不是什麼複雜的任務。用户已經熟悉了Windows上的Firefox, LibreOffice, Pidgin, 以及VLC媒體播放器。用於商業的應用，比如Skype和Adobe Acrobat，功能實現跟Windows上的基本相同。基於雲的應用，比如Google Drive 和 Microsoft Office 365，在Ubuntu上都可以正常使用。

傳統的Windows應用程序可以通過熟悉的Citrix或者開源RDP的客户端來使用。公司也可以使用開源的虛擬產品，比如VirtualBox，運行一些頑固的老掉牙的Windows應用。

在最新硬件的支持上，許多技術人員還記得，在Linux剛剛起步的那些時日，硬件支持極其有限。如今形勢已經轉變了。

如今對Linux的硬件支持通常比對最新的Windows版本的支持還要理想。許多硬件供應商已經放棄了對Windows新版本的驅動支持。Linux下的硬件驅動可以由開源社區的任何一個人維護更新，因此許多支持許多舊的硬件在最新版Ubuntu中得到了完全的支持。有基於此，再加上Ubuntu較低的系統需求，公司可以延長都已經進了回收站的硬件的使用壽命。

雖然Linux的桌面替代品存在它的優勢，但是企業也應該考慮到一些潛在的困難。儘管許多技術人員正在使用linux，也為學習新的技術而歡欣鼓舞，但是仍有一部分技術人員用Windows進行開發工作很長時間了，已經習慣了，再去擁抱新的變化，對他們來説，或許不是那麼得情願。

援引薪酬增長的趨勢是一個解決潛在的問題的辦法。相比於其他專業技術人員，要求Linux技能的職位薪酬上漲近一倍的速度，這是來自Dice的説法。

對嚴格遵守合規性的公司來説，切換到Linux可能會遇到困難。例如，HIPAA要求加密，以滿足FIPS-140-2的要求。大多數開源加密項目沒有贊助商幫助他們通過NIST認證以滿足這一要求。開源代碼實際上可能因為有許多人已審查，會比專有軟件更安全，但令人驚訝的是，在合規性的世界中，這一點無關緊要。

在決定全面遷移之前，企業需要了解他們的規則要求，並制定一個計劃，培訓IT人員。但總體而言，相比於企業級私有操作系統，作為一個切實可行的選擇，Ubuntu Linux已然成熟。考慮到版權費用的花銷，公司在Linux桌面替換項目中的投入是值得的。下一年或許就是“linux桌面版之年”。
