在Ubuntu下用Python搭建桌面算法交易研究環境 ​

這篇文章將討論在ubuntu下，使用Python編程語言來搭建一個強大、高效和易交互的算法交易策略研究環境。我們後繼的算法交易文章都將利用此環境。

搭建此環境需要安裝以下軟件,它們都是開源且免費下載的:

  • Oracle VirtualBox - 用於虛擬操作系統
  • Ubuntu Desktop Linux - 作為我們的虛擬操作系統
  • Python - 核心編程環境
  • NumPy/SciPy - 用於快速、高效的數組和矩陣運算
  • IPython - 用於Python的可視化交互開發
  • matplotlib - 用於數據的圖形可視化
  • pandas - 用於數據“衝突”和時間序列分析
  • scikit-learn - 用於機器學習和人工智能算法

這些工具（配合合適的 證券master資料庫），將使我們能夠創建一個快速可交互的策略研究環境。Pandas是專為數據“衝突”設計的，它可以高效地導入和清洗時間序列數據。NumPy/SciPy在底層運行，使得系統被很好的優化。IPython/matplotlib (以及qtconsole，詳見下文)使結果可視化可交互並快速迭代。scikit-learn可讓我們將機器學習技術應用到我們的策略中，以進一步提高性能。

請注意，我寫這篇教程是為了那些無法或不願意直接安裝ubuntu系統的windows或Mac OSX用户，通過VirtualBox來搭建此環境。VirtualBox使我們可在主控操作系統中創建一個虛擬機，可模擬guest操作系統，而絲毫不影響主控操作系統。由此我們可以在完整安裝Ubuntu前練習Ubuntu和Python工具。如果已經安裝Ubuntu桌面系統，可直接跳到“在Ubuntu下安裝Python研究環境包”這一節。

##安裝VirtualBoX和Ubuntu Linux##

Mac OSX操作系統上關於VirtualBox安裝的部分已經寫過了，這裏將簡單的移到Windows環境中。一旦各種主控操作系統下的VirtualBox安裝完畢，其它過程就都一樣了。

開始安裝前，我們需要先下載Ubuntu和VirtualBox。

下載Ubuntu桌面磁盤鏡像

打開Web瀏覽器，導航到Ubuntu 桌面主頁，然後選擇Ubuntu 13.04：

下載Ubuntu13.04（64位（如適用））

你會被問及是否願意捐贈一些money，不過這個是可選的。進入下載頁面後選擇Ubuntu 13.04。你需要選擇是否要下載32位或64位版本。很可能你是64位系統，但如果你有疑問，那麼選擇32位。在Mac OSX系統上，Ubuntu桌面ISO磁盤鏡像將保存到Downloads目錄下。安裝VirtualBox後我們就要用到它了。

下載和安裝VirtualBox

現在，我們已經下載了Ubuntu ，接下來需要去獲取最新版本的Oracle的VirtualBox軟件。點擊這裏訪問該網站，選擇你的特定主機的版本（本教程要求Mac OSX版本）

Oracle VirtualBox下載頁面

一旦文件下載完畢，我們點擊安裝包圖標運行（Windows上會有些不同，但是類似）：

雙擊安裝包圖標，安裝VirtualBox

打開後，按照安裝説明操作，保持默認（除非你覺得有必要修改他們！）。VirtualBox安裝完畢後，可從Applications文件夾中打開（可通過Finder搜索到）。VirtualBox運行過程中它的圖標將出現在下面的Dock欄裏,如果你以後想經常以虛擬機方式使用Ubuntu,你可以將VirtualBox圖標永久保存在Dock欄中:

還沒有磁盤鏡像的VirtualBox

點擊“新建”（類似齒輪的圖標）,創建一個新的“virtual box”(例如，虛擬操作系統),命名為"Ubuntu Desktop 13.04 Algorithmic Trading"(你可以使用別的類似的描述):

命名我們的新虛擬環境

分配虛擬機內存.因為是測試系統,所以我只分配了512Mb.一個實際的backtesting引擎因為效率原因可能需要本地安裝(因此需分配多的多的內存):

選擇虛擬磁盤的RAM量

創建虛擬硬盤,大小為推薦的8Gb,動態生成VirtualBox磁盤鏡像,名字同上:

選擇鏡像所使用的硬盤類型

完整系統的詳細信息如下:

已經創建的虛擬鏡像

現在我們需要在VirtualBox中為新的磁盤鏡像包含一個虛擬的'CD驅動器',這樣就可以假裝從這張光盤驅動器引導我們的Ubuntu磁盤鏡像。在Settings裏點擊“Storage”選項卡，並添加一個磁盤。選擇Downloads目錄下的Ubuntu磁盤鏡像ISO文件（或者其他你下載Ubuntu的目錄），選擇Ubuntu ISO鏡像，並保存設置。

在第一次啓動時選擇Ubuntu桌面ISO

一切就緒，準備啓動Ubuntu鏡像並安裝。點擊“Start”，當出現主機捕獲鼠標或鍵盤消息時點擊“Ok”。在我的Mac OSX系統中，主機捕獲鍵是左邊的Cmd鍵（即左Apple鍵）。現在出現在你眼前的就是Ubuntu桌面安裝界面，點擊“Install Ubuntu”：

點擊 "Install Ubuntu "開始安裝

確保勾選兩個框，安裝專有的MP3和Wi-Fi驅動程序：

安裝MP3和Wi-Fi的專用驅動程序

現在，您將看到一個界面，詢問你想如何保存操作系統創建過程中的的數據。不要驚慌於“Erase Disk and Install Ubuntu”的選項。這並不意味着它會刪除你的普通硬盤！它實際上指的是運行Ubuntu的虛擬磁盤，這是安全擦除（反正裏面沒有什麼內容，因為是我們剛剛創建的）。繼續進行安裝，將出現詢問位置的界面，隨後，又將出現選擇鍵盤佈局的界面：

選擇您所在的地理位置

輸入您的用户憑據，請務必記住您的密碼，以後安裝軟件包的時候需要它：

輸入您的用户名和密碼（此密碼是管理員密碼）

現在， Ubuntu將安裝文件。它應該是比較快的，因為它是從硬盤複製到硬盤！完成後VirtualBox將重啓。如果不自行重啓，你可以去菜單強制重啓。接下來將回到Ubuntu的登錄界面：

Ubuntu桌面登錄界面

用您的用户名和密碼登錄，你將看到閃亮的新的Ubuntu桌面：

Ubuntu桌面登錄後的整體界面

最後需要做的事是點擊火狐圖標，通過訪問一個網站（我選擇QuantStart.com，有意思吧！），來測試互聯網/網絡功能正常：

*Ubuntu中的火狐瀏覽器

現在Ubuntu桌面已經安裝完畢，接下來，我們就可以開始安裝算法交易研究環境軟件包。

在Ubuntu上安裝Python研究環境軟件包 ​

點擊左上角的搜索按鈕，在輸入框裏輸入“Terminal”，彈出命令列界面。雙擊終端圖標啓動終端：

*Ubuntu中的終端界面

所有後續的命令都在此終端輸入。

任何嶄新的Ubuntu Linux系統上做的第一件事就是更新和升級軟件包。前者告訴Ubuntu可用的新軟件包有哪些，後者用新版的軟件包替換舊版的。運行下列命令（你將被提示輸入您的密碼） ：

sudo apt-get -y update
sudo apt-get -y upgrade

-y前綴告訴Ubuntu接受所有回答“是/否”的問題為'是'。 “sudo”是一個Ubuntu/Debian Linux的命令，允許以管理員權限執行其他命令。由於我們將在站點範圍安裝軟件包，我們需要機器的root權限，因此必須使用'sudo'

你可能會在這裏得到一個錯誤消息：

E: Could not get lock /var/lib/dpkg/lock - open (11: Resource temporarily unavailable)

為了解決這個問題，再次運行"sudo apt-get -y update"，如果它不起作用，你可以在該站點(http://penreturns.rc.my/2012/02/could-not-get-lock-varlibaptlistslock.html)上查看是否有其他的命令。

一旦這兩個更新命令成功執行，接下來我們需要安裝Python，NumPy/SciPy，matplotlib，pandas，scikit-learn和IPython。我們將從Python開發包和編譯器開始安裝，編譯器將在編譯所有軟件的時候用到：

sudo apt-get install python-pip python-dev python2.7-dev build-essential liblapack-dev libblas-dev

一旦必要的軟件包已安裝，我們就可以通過pip，即Python包管理器，安裝NumPy。pip將下載NumPy的zip包，然後從源代碼編譯。請記住，編譯需要花費一些時間，大概10-20分鐘！

sudo pip install numpy

NumPy安裝完了後,我們需要在繼續之前檢查它是否可用。如果你仔細看終端，你會發現計算機名後面跟了你的用户名。比如我的是mhallsmoore@algobox，隨後是提示符。在提示符下鍵入python，然後試着導入NumPy。我們將計算一個列表的平均值,以測試NumPy是否可用:

mhallsmoore@algobox:~$ python
Python 2.7.4 (default, Sep 26 2013, 03:20:26)
[GCC 4.7.3] on linux2
Type "help", "copyright", "credits" or "license" for more information.
>>> import numpy
>>> from numpy import mean
>>> mean([1,2,3])
2.0
>>> exit()

現在，我們已成功安裝NumPy，接下來要安裝Python的科學庫,即SciPy。然而，它有一些依賴的軟件包，包括ATLAS庫和GNU Fortran編譯器：

sudo apt-get install libatlas-base-dev gfortran

現在,我們將通過pip安裝SciPy.這將需要相當長的時間（約20分鐘，這取決於你的電腦），所以也許你可以去喝杯咖啡先：

sudo pip install scipy

唷！現在已安裝SciPy。讓我們通過計算一個整數列表的標準差來測試SciPy是否可以正常使用：

mhallsmoore@algobox:~$ python
Python 2.7.4 (default, Sep 26 2013, 03:20:26)
[GCC 4.7.3] on linux2
Type "help", "copyright", "credits" or "license" for more information.
>>> import scipy
>>> from scipy import std
>>> std([1,2,3])
0.81649658092772603
>>> exit()

接下來我們需要安裝matplotlib的依賴包，Python的圖形庫。 由於matplotlib是一個Python包，無法使用pip去安裝以下PNG，JPEG文件和FreeType字體庫相關的庫，所以我們需要Ubuntu為我們安裝：

sudo apt-get install libpng-dev libjpeg8-dev libfreetype6-dev

現在我們可以安裝matplotlib了:

sudo pip install matplotlib

我們將安裝數據分析和機器學習庫,pandas和scikit-learn.這步不需要安裝額外的依賴庫, 因為NumPy和SciPy已經將依賴都覆蓋了.

sudo pip install -U scikit-learn
sudo pip install pandas

我需要測試scikit-learn:

mhallsmoore@algobox:~$ python
Python 2.7.4 (default, Sep 26 2013, 03:20:26)
[GCC 4.7.3] on linux2
Type "help", "copyright", "credits" or "license" for more information.
>>> from sklearn load datasets
>>> iris = datasets.load_iris()
>>> iris
..
..
'petal width (cm)']}
>>>

另外,我們需要測試pandas:

>>> from pandas import DataFrame
>>> pd = DataFrame()
>>> pd
Empty DataFrame
Columns: []
Index: []
>>> exit()

最後, 我們需要安裝IPython.這是一個交互式的Python解釋器，它相比標準的Python控制台，提供了一個更精簡的工作流。在以後的教程中，我將講述IPython在算法交易開發中的完整用途：

sudo pip install ipython

雖然IPython本身已經相當有用，它通過包含qtconsole可以有更強大的能力,qtconsole提供了內聯matplotlib可視化的能力。儘管如此，它需要多一點點的工作以使它啓動和運行。

首先，我們需要安裝Qt庫。對於這一點，你可能需要更新你的軟件包（我做了！）：

sudo apt-get update

現在我們可以安裝Qt了:

sudo apt-get install libqt4-core libqt4-gui libqt4-dev

qtconsole有一些附加的包,即ZMQ和Pygments庫:

sudo apt-get install libzmq-dev
sudo pip install pyzmq
sudo pip install pygments

最後我們準備啓動帶有qtconsole的IPython:

ipython qtconsole --pylab=inline

然後我們可以做一個圖（非常簡單的！）, 鍵入下列命令（我已經包含了IPython編號的輸入/輸出,你不需要再輸入）：

In [1]: x=np.array([1,2,3])

In [2]: plot(x)
Out[2]: [<matplotlib.lines.Line2D at 0x392a1d0>]

這將產生以下內嵌圖表：

帶有qtconsole的IPython顯示一幅內嵌的圖表

這就是它的安裝過程。現在，我們手頭就有一個非常強大的，高效和互動的算法交易的科研環境。我會在後續的文章中詳細介紹如何結合IPython,matplotlib,pandas和scikit-learn,以一種直觀的方式, 成功地研究和回溯測試量化交易策略。
