如何使用安卓設備控制你的Linux PC ​

下面的教程會指導所有的Linux用户如何在系統上安裝SSH，以便通過安卓智能手機遠程訪問他們的電腦。

如今我們所有人都擁有一台平板或觸屏手機，我們經常使用它們在深夜裏看電影或電視節目，聽歌或者讀一本好書。你可以把本文稱作是“懶人教程”，它是專門為那些在大晚上因為太過疲憊而懶得去開啓他們電腦上的某些應用程序，移動、刪除，複製或重命名某些文件，甚至懶得去關掉PC的人準備的。

的確，已經有各種各樣的遠程桌面解決方案，但是許多方案費用很高，或者實現效果很糟糕，無法像預期一樣運行，迫使你最終還是得去電腦上做你原本想做的事情。

在這個教程裏面，我們將使用一種簡單、安全、高效的協議，它被稱為SSH (Secure Shell)，很容易從默認的軟件倉庫中安裝（在Arch linx中是openssh，在Ubuntu中是openssh-server）。

配置SSH服務器 ​

在安裝完成後，你需要為SSH服務器進行基本配置。為此，你需要使用文本編輯器編輯/etc/ssh/sshd_config這個文件。

1.在文件尾部添加下面一行（下面的yourusername使用你的Linux機器上存在的用户名代替）

AllowUsers yourusername

2.取消"#PermitRootLogin"這行註釋，把"no"替換成"yes"（譯註：下面的選項修改和是否允許ssh登錄無關，只是允許root直接登錄，一般而言，並不建議如下這樣的遠程root直接登錄。）：

PermitRootLogin no

3.為了安全起見，你需要修改SSH 連接默認的22端口到一個更大編號的端口，譬如在我們的例子中是55441 （但不要使用55441，這是我舉個列子，可以找另一個四位或者五位數字）。因此，取消註釋並編輯"#Port 22"如下（譯註：你可以選擇任何一個大於1024並小於65535的端口，只要他沒有被別的程序佔用，為什麼不試試你的幸運數字呢？）：

   Port 55441

開啓SSH服務器### ​

在Ubuntu上，SSH服務通過下面的命令啓動：

sudo /etc/init.d/ssh start

當你每次修改上述配置文件時，都需要通過下面的命令重啓：

sudo /etc/init.d/ssh restart

在Arch Linux上，你可以使用下面的命令啓動SSH服務：

sudo systemctl start sshd

配置安卓設備上的SSH客户端### ​

JuiceSSH似乎是安卓上最好的SSH客户端之一，而且是免費的。同時，如果你認為它的功能比較簡單，可以花費少量的錢來得到更多高級的特性，譬如亞馬遜 AWS/EC2 集成，團隊協作，以及更多其它的特性。

一旦軟件安裝完畢，開啓它，然後你會要求輸入一個加密的密碼以保證連接的安全。這個密碼由AES-256進行加密，因此除非你的設備被偷，否則沒有人能夠獲取它們。

現在，添加一個新連接，為你的電腦選擇名稱、IP地址，上面設定的端口號以及一個需要被創建的身份。

這就是我的Arch Linux機器，這是通過我的安卓平板上的JuiceSSH客户端訪問到的界面。如果在這個教程中你遇到問題，請在下面進行評論。
