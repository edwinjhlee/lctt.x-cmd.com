Linux中grep命令的12個實踐例子 ​

你是否遇到過需要在文件中查找一個特定的字符串或者樣式，但是不知道從哪兒開始？那麼,就請grep來幫你吧。

grep是每個Linux發行版都預裝的一個強有力的文件模式搜索工具。無論何種原因，如果你的系統沒有預裝它的話，你可以很容易的通過系統的包管理器來安裝它（Debian/Ubuntu系中的apt-get和RHEl/CentOS/Fedora系中的yum）。

 $ sudo apt-get install grep               #Debian/Ubuntu
 
 $ sudo yum install grep                   #RHEL/CentOS/Fedora

我發現使用現實世界中的真實例子讓你投身其中是讓你接觸grep命令的最容易方式。

###1.搜索和尋找文件

假設你已經在你的電腦上安裝了一個全新的Ubuntu，然後你打算卸載Python。你瀏覽網頁尋找教程，但是你發現存在兩個不同版本的Python在使用，而你不知道你的Ubuntu安裝器到底在你的系統中安裝了哪個版本的Python，也不知道它安裝了哪些模組。解決這個煩惱只需簡單的運行以下命令：

  $ sudo dpkg -l | grep -i python

####輸出例子 ii python2.7 2.7.3-0ubuntu3.4 Interactive high-level object-oriented language (version 2.7) ii python2.7-minimal 2.7.3-0ubuntu3.4 Minimal subset of the Python language (version 2.7) ii python-openssl 0.12-1ubuntu2.1 Python wrapper around the OpenSSL library ii python-pam 0.4.2-12.2ubuntu4 A Python interface to the PAM library

首先，我們運行dpkg -l列出你係統上安裝的.deb包。接着，我們使用管道將輸出結果傳輸給命令grep -i python，這一步可以簡單解釋為把結果傳輸給grep然後過濾出所有含有python的項，並返回結果。–i選項用於忽略大小寫,因為 grep 是大小寫敏感的。使用選項-i是個好習慣，除非你打算進行更細節的搜索。

###2.搜索和過濾文件

grep還可以在一個或多個文件裏用於搜索和過濾。讓我們來看一個這樣的情景：

你的Apache網頁服務器出現了問題，你不得不從許多專業網站裏找一個發帖詢問。好心回覆你的人讓你粘貼上來你的/etc/apache2/sites-available/default-ssl文件內容。假如你能移除掉所有的註釋行，那麼對你，對幫你的人，以及所有閲讀該文件的人，不是更容易發現問題嗎？你當然可以很容易的做到！只需這樣做就可以了：

 $ sudo grep -v "#" /etc/apache2/sites-available/default-ssl

選項-v是告訴grep命令反轉它的輸出結果，意思就是不輸出匹配的項，做相反的事，打印出所有不匹配的項。這個例子中，有#的是註釋行（譯註：其實這個命令並不準確，包含“#”的行不全是註釋行。關於如何精確匹配註釋行，可以瞭解更多的關於正則表達式的內容。）。

###3.找出所有的mp3文件

grep命令對於過濾來自於標準輸出的結果非常有用。例如，假設你的一個文件夾裏面全是各種格式的音樂文件。你要找出藝術家jayZ的所有mp3格式的音樂文件，裏面也不要有任何混合音軌。使用find命令再結合管道使用grep就可以完成這個魔法：

 $ sudo find . -name ".mp3" | grep -i JayZ | grep -vi "remix""

在這個例子中，我們使用find命令打印出所有以.mp3為後綴名的文件，接着將其使用管道傳遞給grep -i過濾和打印出名字為“JayZ”的文件,再使用管道傳送給grep -vi以便過濾掉含有“remix”的項。

###4.在搜索字符串前面或者後面顯示行號

另外兩個選項是-A和-B之間的切換，是用以顯示匹配的行以及行號，分別控制在字符串前或字符串後顯示的行數。Man頁給出了更加詳細的解釋，我發現一個記憶的小竅門：-A=after、-B=before。

 $ sudo ifconfig | grep -A 4 etho
 $ sudo ifconfig | grep -B 2 UP

###5.在匹配字符串周圍打印出行號

grep命令的-C選項和例4中的很相似，不過打印的並不是在匹配字符串的前面或後面的行，而是打印出兩個方向都匹配的行（譯註：同上面的記憶竅門一樣：-C=center，以此為中心）： $ sudo ifconfig | grep -C 2 lo

###6.計算匹配項的數目

這個功能類似於將grep輸出的結果用管道傳送給計數器（wc程序），grep內建的選項可以達到同樣的目的：

$ sudo ifconfig | grep -c inet6

###7.按給定字符串搜索文件中匹配的行號

當你在編譯出錯時需要調試時，grep命令的-n選項是個非常有用的功能。它能告訴你所搜索的內容在文件的哪一行：

$ sudo grep -n "main" setup.py

###8.在所有目錄裏遞歸的搜索

假若你要在當前文件夾裏搜索一個字符串，而當前文件夾裏又有很多子目錄，你可以指定一個-r選項以便於遞歸的搜索： $ sudo grep -r "function" *

###9.進行精確匹配搜索

傳遞-w選項給grep命令可以在字符串中進行精確匹配搜索（譯註：包含要搜索的單詞，而不是通配）。例如，像下面這樣輸入：

$ sudo ifconfig | grep -w “RUNNING”

將打印出含有引號內匹配項的行。另外，你還可以試一下這個：

$ sudo ifconfig | grep -w “RUN”

搜索這個匹配項時，若搜索的東西里面沒有這樣的一個單獨的單詞，將什麼也不會返回。

###10.在Gzip壓縮文件中搜索

我們還要關注一下grep的衍生應用。第一個是zgrep，這個與zcat很相似，可以用於gzip壓縮過的文件。它有與grep相似的命令選項，使用方式也一樣：

$ sudo zgrep -i error /var/log/syslog.2.gz

###11.在文件中匹配正則表達式

egrep是另一個衍生應用，代表着“擴展全局正則表達式”。它可以識別更多的正則表達式元字符，例如at + ? | 和（）。在搜索源代碼文件時，egrep是一個非常有用的工具，還有其他的一些零碎代碼文件的搜索需要，使得這樣的搜索能力成為必需。可以在grep命令中使用選項-E來啓用它。

$ sudo grep -E

###12.搜索一個固定匹配字符串

fgrep用於在一個文件或文件列表中搜索固定樣式的字符串。功能與grep -F同。fgrep的一個通常用法為傳遞一個含有樣式的文件給它：

$ sudo fgrep -f file_full_of_patterns.txt file_to_search.txt

這僅僅是grep命令的開始，你可能已經注意到，它對於實現各種各樣的需求簡直是太有用了。除了這種我們運行的這種只有一行的命令，grep還可以寫成cron任務或者自動的shell腳本去執行。保持好奇心，試驗一下man頁的各個選項，為實現你的目的寫出一些grep表達式吧。
