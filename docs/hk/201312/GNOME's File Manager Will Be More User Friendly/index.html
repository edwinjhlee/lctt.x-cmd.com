GNOME的文件管理器將對用户更加友好 ​

幾天前，GNOME的設計師Allan Day在Blog裏發佈了一篇超長博文，介紹了GNOME桌面環境下的下一代Nautilus文件管理器。

本文將為讀者簡短介紹即將發佈的Nautilus都實現了哪些新的設計功能，這些新功能也將成為GNOME3.12桌面環境的組成部分。

很顯然，GNOME開發小組對大家一直關注的桌面環境的默認文件管理器進行了美化改進，另外將一些後台功能改放到了顯著位置，使其對新用户更加明顯。

不管你是否相信，事實是，有非常多的新用户嘗試探索Linux世界之奧秘的時候，面對Nautilus卻一籌莫展，他們不知道如何複製、粘貼、重命名、移動，甚至不知道如何訪問他們的文件…… 這是一個非常窘迫、亟待解決的大問題！

因此，Nautilus文件管理器的未來版本將着重解決這些問題，包括圖標響應、列表視圖、更大更清晰的縮略圖，以及更好用的縮放層級等等，通過這些，你可以更容易地組織你的文件。同時，更新後的視圖菜單也實現了更優秀的控制操作。

Nautilus列表視圖

Nautilus圖標視圖

Nautilus齒輪菜單

Nautilus將要實現的另一個重要特性是各種各樣好用的按鈕。例如“複製到…、移動到…、創建新文件夾、以…打開”等等，它們將使文件操作變得更加友好。同時，文件預覽將變得更加直接，包括一個備受期待的導航功能，它能使照片或文檔瀏覽變得更加容易。

不僅如此，側邊欄的可定製化程度也會更高，它將允許用户添加或刪除網絡設備、網絡分區，或着是與它們的遠程連接，使整個側邊欄變得更加整潔（這一改進對於像本譯者這樣的強迫症患者來説多麼福音啊~）。新增加的“收藏”標籤可用於訪問所有你最喜歡的文件，還有改進後的“內容選擇功能”，允許用户從多個來源選擇項目。
