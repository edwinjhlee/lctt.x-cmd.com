如何在 VirtualBox 中安裝 SteamOS ​

下面的教程將指導 Linuxer 在 VirtualBox 中全新安裝 SteamOS GNU/Linux。

如你已經瞭解的那樣，SteamOS Linux 已經在12月13日正式發佈了。作為一款基於 Debian GNU/Linux 的操作系統，它默認使用了 GNOME 作為桌面環境，當然這是可選的。

如果硬件上沒有問題的話，比如你的電腦擁有強大遊戲顯卡，且支持UEFI的，那麼安裝 SteamOS 將是一件非常容易的事情，然而，因為 Valve 並沒有發佈 SteamOS 的 ISO 鏡像，在安裝過程中可能並不是那麼順利。

下面的教程由兩個重要的部分組成，第一部分將會幫助你用 Valve 官方的 SteamOSInstaller.zip 來創建一個 ISO 鏡像；如果你不希望在自己的電腦上真正安裝，那麼第二部分將會告訴你如何在 VirtualBox 中來體驗 SteamOS。

在一開始你需要一個已經正確安裝的最新的 VirtualBox。當然，你還需要一款叫做GNUxorriso的軟件用來製作 ISO 鏡像。

第一步，製作 SteamISO 鏡像 ​

從 Softpedia 下載 SteamOSInstaller.zip，將它保存到你的 home 目錄下並解壓縮。完畢之後你將會看到 SteamOSInstaller 文件夾。現在，從終端裏打開它並執行下面的命令（譯註：命令較長，請勿敲錯）：

xorriso -as mkisofs -r -checksum_algorithm_iso md5,sha1 -V 'Steam OS' -o ~/SteamOSInstaller.iso -J -joliet-long -cache-inodes -no-emul-boot -boot-load-size 4 -boot-info-table -eltorito-alt-boot --efi-boot boot/grub/efi.img -append_partition 2 0x01 ~/SteamOSInstaller/boot/grub/efi.img -partition_offset 16 ~/SteamOSInstaller

稍等幾秒鐘之後，SteamOS.iso 文件將會在你的 home 目錄下出現，大約有 1GB。好了，這一步就完成了，下面進入第二步。

第二步，在 VirtualBox 中安裝 SteamOS ​

如果你已經正確安裝了 VirtualBox 並且瞭解它的正確用法，那麼我們下面需要來建立一個擁有 UEFI 支持的全新虛擬機。在 VirtualBox 的主窗口，點擊 New 按鈕來開始安裝吧。

在 Name 框輸入 SteamOS，在操作系統類型種選擇 Linux，並在下拉框的版本列表中選擇 Debain 64-bit，點擊 Next 繼續。Memory Size 中設置1024或者2048MB（當然，這取決於你的計算機實際內存大小），我們創建一個 VDI 格式的虛擬硬盤驅動器，將大小固定為15GB。點擊 Continue 來繼續，並等待創建過程結束。

創建一個新的虛擬機

設置內存大小

現在我們的虛擬機已經創建完畢了，接下來讓我們來為 SteamOS 做一些小小的調整。來到 Settings 選項，點擊邊欄的 System，然後在 Boot Order 中取消選擇 "Floppy"，並檢查確認已經選擇 "Enable EFI (special OSes only)" 選項。

允許 EFI 並移除 Floppy

接下來，點擊邊欄中的 Display 按鈕，將 Video Memory 設置為128MB，並勾上 "Enable 3D Acceleration" 選項。然後，進入邊欄的 Storage 部分，點擊 "Controller: IDE" 下面的 "Empty"，並點擊 CD/DVD 驅動下拉欄旁邊小 CD 圖標來添加上一步製作的 SteamOSInstall.iso 鏡像文件。當一切完成之後，點擊 OK。

設置 Video Memory 大小 和 3D 加速

那麼現在，讓我們按下主窗口中的 "Start" 按鈕來啓動虛擬機。你將會立即看到 SteamOS 啓動畫面。只需要高亮 "Automated install (WILL ERASE DISK)" 後按下 Enter 鍵即可。接下來可以稍微休息一下，直到我們的安裝結束。整個安裝過程可能需要一段時間，當然這取決於你的電腦。

準備安裝 SteamOS

只要我們的安裝過程結束，你就可以關閉虛擬機，然後從 Storage 中移除 ISO 鏡像，然後啓動進入全新的 SteamOS。但是，在我們正式進入 SteamOS 的世界之前，還需要安裝 VirtualBox Guest Additions。先點擊開始 SteamOS 虛擬機，選擇 GRUB 啓動器中的第二個選項（恢復模式），然後在 SteamOS 的命令列提示後輸入下面的命令：

dpkg --get-selections | grep nvidia
apt-get purge <name of the packages outputted by the above command>
rm /usr/share/X11/xorg.conf.d/55-nvidia.conf
dpkg-reconfigure xserver-xorg

進入到 Devices 中然後點擊 Insert Guest Additions CD 鏡像。根據提示來下載 Guest Additions 鏡像，掛載它並執行下面的命令：

   sh /media/cdrom/VBoxLinuxAdditions.run

等待 Guest Additions 安裝完驅動，用下面的命令來重啓我們的虛擬機：

   shutdown now -r

SteamOS 命令列提示

接下來我們的虛擬機會重啓，讓它啓動進入 SteamOS。當我們抵達登錄提示界面之後，使用 desktop/desktop 或者 steam/steam 作為用户名和密碼來登錄。
