洞悉需求最高的三大IT技能組 ​

據IT技能清單調查報告結果顯示，僱主所需的Linux人才應具備的IT技能可分成相對獨立的組羣。本文將着重介紹在上一個季度（2013年7月-9月）需求度最高的3組IT技能，這些技能在包括美國在內的被選國家招聘廣告中都有所提及，同時結果表明這三組技能可以和Linux相關的工作領域需求相匹配。

報告指出在上一季度具有嵌入式開發人員相關技能的人才是Linux專業僱主亟需的一類。排在第二位和第三位涉及的技能領域分別對應虛擬化技術和LAMP管理。本文將基於這三類工作清單涉及到的技能需求加以討論，並對分析後的三組技能間的依賴結構關係加以洞悉。

如果您尚未閲讀IT技能清單，我們強烈建議您在閲讀以下內容前先熟悉這篇文章。它詳細闡明瞭本次研究中用到的方法，本文也是基於IT技能清單的材料才得以進一步分析。

2013年8月IT技能分類更新 ​

在IT技能清單這篇文章中，LinuxCareer.com分析了2013年5月到6月底的Linux工作清單，我們在這個基礎上將2013年7月到9月底這個時間段的更新也加至分類分析中。10類相關的IT技能在Linux招聘廣告中出現的比率列於如上條形圖中。IT分類圖表表明如何基於分類設計出此條形圖。我們可以看到，IT技能需求前三組為：佔據27%的Linux就業市場份額的嵌入式開發人員需求，佔20%就業份額的虛擬化技術工程師和佔12%Linux就業份額的LAMP管理員。文章接下來的三部分將圍繞這三項IT技能需求組及三者的相互關係展開詳細的討論。例如，MySQL和PHP這兩項技能有強關聯性，通常僱主都會一起考慮。另外要指出的是，LinuxCareer.com的這項調查裏掌握Linux的基礎知識已默認存在於任一招聘需求中。

嵌入式開發人員及程序員 ​

需求最高的第一類技能組是針對嵌入式開發人員及程序員的。如下的依賴圖詳細闡明瞭技能間的關聯關係，尤其表明了哪幾項技能更可能同時出現在Linux招聘需求中。例如，嵌入式開發非常需要C/C++/C#相關技能，而這些語言要麼在圖表下部的深色矩形區域，要麼在圖表上部的對應圓形陰影中聚集。

總體來説，這組技能可以進一步細分成如下三類：

  1. Android, Embedded, C/C++/C# 和 Java。如果您準備在嵌入式領域發展，這些是你需要掌握的核心技能，而C/C++/C#或Java掌握其一便可滿足僱主需求，因為Java是基於部分C/C++/C#性能的擴展性語言。如果您閲讀了8月的IT技能表，就會發現，Java以9513分居於編程語言的榜首，而C/C++/C#是5403分。如果您尚在猶豫是掌握C/C++/C#還是Java，從技能表得分看起來Java應該是更好的選擇。但根據如下圖表顯示，C/C++/C#似乎在嵌入式領域的招聘需求中更受歡迎。總結可得儘管Java在IT技能表中有更高的得分，但在嵌入式開發職位上掌握C/C++/C#會比Java更有用。

  2. Python, Perl 和 Bash。這些是對腳本編程語言技能的補充。對Perl和Python語言的需求經常會在招聘中同時出現，當然，也可以理解成這兩種語言技能都是需要掌握的。

  3. Git, Subversion 和 Jira。這些軟件知識會應用到源碼管理、調試和項目管理中，同時瞭解這幾個方面的知識對相關項目的編程大有裨益。目前，主流開源項目和大量合作項目都在用類似的軟件管理他們的源碼。

涉及數據倉儲及管理的虛擬化技術工程師 ​

目前第二大需求技能組是如下依賴圖所示與虛擬化技術工程師相關的技能。這一組可進一步細分成兩部分，第一部分是Redhat, VMware, vSphere, ESX/ESXi, XenServer 和 Citrix，這些技能對尋求虛擬化技術工程師的工作很重要；第二部分是同Unix系統、數據倉儲及管理相關的技能。同時這兩部分是緊密聯繫的。顯然VMware和ESX/ESXi及vSphere是相關的，因為ESX/ESXi是VMware虛擬機下提供的虛擬產品，而vSphere是VMware虛擬機的雲端虛擬操作系統。Redhat和VMware、Citrix產品被分到同一部分同樣有其原因。這裏Solaris和AIX具有密切關係的原因可以理解為它們都是專有的Unix系統，掌握其一便可。

LAMP管理員 ​

最後，第三大技能組是如下依賴圖中顯示僱主需求的LAMP管理員應具備的技能。LAMP是Linux、Apache、MySQL和PHP的簡稱，所有這四項內容是作為一名LAMP管理員所要了解的核心。這是一組相對來説小規模卻會引領你至在Linux路途中發展更遠的技能。實際上，PHP和MySQL的密切關係表明這些技能中的任一項都不能脱離其它技能來單獨掌握。

總結 ​

本文基於就業能力和Linux專業人員需求技能分組闡明瞭兩點。第一點是對經常出現的IT技能通過集羣分析劃出了10類IT技能組；第二點是基於Linux工作需求與相應技能組的對應結果，嵌入式程序員在Linux招聘需求比率最高，第二及第三技能需求比率最高的領域分別對應虛擬化技術工程師及LAMP管理員領域。這三大技能組即為上一季度分析出的Linux技能需求的核心。
