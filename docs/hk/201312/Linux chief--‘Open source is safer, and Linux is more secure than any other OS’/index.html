Linux領袖説：‘開源很安全，Linux比其它任何系統都安全’ ​

在對Linux基金會執行官，Jim Zemlin 的採訪中，VentureBeat 展望了2014年開源操作系統的未來。

訪談中我們也探討了爭議性的話題，就是政府部門的監聽事件以及‘後門’-那些邪惡的窗口，窺探我們網上的私生活，最近公眾發現我們經常使用的大多數服務都有類似的遭遇。

Zemlin 為我們解釋了 GNU/Linux 為什麼以及如何使它成為內心有些擔憂的消費者的最安全的選擇。還有就是為什麼選擇GNU/Linux作為能源汽車、手機、TV以及其它新興設備的操作系統。

以下是我們完整的e-mail訪談實錄

VentureBeat: 安全和隱私一直是本年度最熱門的話題，我們聽到的謠言，Linus[Torvalds, Linux 創始人]對政府部門是否有植入後門的要求點頭稱是。

Zemlin: 如果Linux真有後門，你應該知道的。

全世界的用户都可以看到Linux的每一行代碼。這也是linux要比其他操作系統更安全、開源整體要比閉源更安全的原因之一。代碼的透明度保證了它的安全性。

必須明確指出：Linux沒有後門。

VentureBeat: Linux基金會如何保證Linux用户的隱私和自由，使其免於遭受追蹤和監視？

Zemlin: 對此，我們一以貫之。向內核插入違反隱私權和背離自由精神的代碼而不被成千上萬的開發者注意到，這是很難的。Linux的本性就是自我定製。

VentureBeat: 今年的隱私/安全/監視事件會不會促使, 或者將會促使更多的消費者傾向於Linux，對此你作何感想？

Zemlin: 世界範圍內，我聽到人們都在説，“用開源保證隱私是必須的。”的確，那會促使更多的使用者選擇Linux。

除了他們對linux平台下的隱私和安全持自信、信任的態度以外， 我認為消費者會基於多種原因選擇Linux。 代碼的透明性以及開發過程逐漸給予日漸博學和警覺的消費者一個選擇，一個會讓他們對linux感覺良好的選擇。

[視頻遊戲發行商] Valve 及其SteamOS下的工作 正在促使更多的消費者走進Linux，就像逐漸佔據主導地位的Android和其他運行Linux的電子設備一樣，比如電視、家電、汽車等，當然還有更多。

VentureBeat: 針對手機的Ubuntu Edge, 對它有何看法？ 對於2014-2015年Linux/Ubuntu手機市場走勢，你作何預測？

Zemlin:我希望看到潛在的有趣的新產品進入市場，尤其是基於Linux的產品。很難説每年哪款產品會成為手機市場的新寵。

我認為預測基於Linux的手機將佔據主導地位，不算誇大事實。Android, Tizen, Ubuntu, Firefox，等等等等，都顯示出Linux可以驅動手機市場的創新，並且為消費者創造新的體驗，為開發者和OEMs創造機會。

明年令人振奮的發展，也是我所關注的就是linux和開源界如何把這些設備、對象和服務關聯到一起。

VentureBeat: 目前為止，你看到的linux嵌入式車載系統的最令人激動的使用案例是什麼？

Zemlin: 毫無疑問，就是，Cadillac, Tesla, Toyota, Jaguar, Land Rover等都搭建了車載信息娛樂系統。

比如，今年贏得了 “年度汽車族”獎項的Tesla Model S，裝備了一個17英寸平面、運行着定製Linux的電腦。這真的是太酷了。

2014年度汽車族剛剛揭曉 -- Cadillac CTS sedan, 也是使用linux作為車載信息娛樂系統。汽車製造商有能力使用linux進行創新並區別使用這些系統。

Linux的成功也能從來自IHS汽車的最新數據上看到，IHS本月報告稱，在全球車載信息娛樂市場，基於linux的汽車銷量2020年有望達到5370萬，超過微軟和黑莓QNX。

Linux基金會協同汽車級Linux工作組在該領域做了許多工作。通過在Linux內核社區，其他開源社區，以及汽車行業，營造一箇中立、支持性的環境，我們能夠幫助一些世界級巨頭汽車製造商提高汽車Linux技術，如日產，捷豹，路虎，豐田，等等。

VentureBeat: 在硬核開發者市場以外，Linux是如何發展壯大的，尤其是考慮到消費者和遊戲玩家？

Zemlin:可以肯定的是，對遊戲玩家來説，今年確實是linux的一個轉折點。Valve, 一個基於Steam網絡平台的一個遊戲廠商，在linux上構建並運行所有的源代碼和動畫。Valve的CEO Gabe Newell 稱，今年的LinuxCon大會上他們在linux平台運行了198個遊戲，隨着引進基於linux的Steam，這個數字還會上升。這是Linux和遊戲界新趨勢的開端。

用户每天都在用linux。軟件支撐着我們的日常生活。像Google，Facebook還有Twitter等公司，都建立在Linux和開源軟件之上。去年10月份LinuxCon歐洲大會上，來自Twitter的Chris Aniszczyk告訴聽眾： “Twitter 理所當然完全運行在linux上。為什麼你們還需要其他的東西？”(譯註：言外之意就是有linux就夠了，不需要別的什麼東西了。)

如今Linux驅動着130萬台日常所用Android手機，每天近60萬基於linux的新電視售出。新的家電以及汽車都建立在linux之上。主要交通系統也都在使用linux。最受歡迎的GoPro 使用linux和開源軟件。這樣的例子層出不窮。

Linux和開源理念將會逐漸融入主流消費者的生活。三星使用linux內核以及基於linux的產品充實它的產品線，從電視機到手機，再到家電，等等等等。

敬請關注 - 未來你將看到更多實例，展現了Linux和開源軟件，以及協同開發在日常生活中發揮越來越大的作用。

VentureBeat: 在你看來，到2014年，免費和開源軟件最大的機遇會是什麼？

Zemlin: 我們已經談到遊戲和電子設備，但是企業將會繼續為linux呈現更多的機會。雲計算的興起為開發者帶來新的機遇和挑戰。你可以試着去找找不運行在linux上的公共雲。

軟件定義的網絡（SDN）實現將成為2014年的主要活動之一。人們並沒有期望着軟件定義網絡以及網絡功能虛擬化變得多麼大。想想吧。數十億美元花費在硬件上，交換機，路由，負載均衡器，防火牆等等。這些都抽象成了軟件。更更重要的是,它是在開源軟件的基礎架構甜蜜點OSS層被抽象。我認為你會看到，像OpenDaylight項目以及其他項目，在2014年都會有大的突破。

當然，這只是實現協同發展的大趨勢的一部分，你的讀者應該會對此感興趣。我的推測是再過一個20年，幾乎所有的基礎軟件都會以協同開發的方式進行構建。2014年開發者需要學習如何以協同方式構建軟件，要學會如何參與開源項目並且貢獻代碼。如果開發者能夠理解協同開發和開源的原則和理念，那麼他們職業生涯中的機遇將會是無窮的。

參與到linux的世界中來是一個激動人心的時刻。從智能手錶到電視機，到汽車，只要你能想到，Linux就能為你實現。
