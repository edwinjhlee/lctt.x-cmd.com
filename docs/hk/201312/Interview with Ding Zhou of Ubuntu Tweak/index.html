專訪Ubuntu Tweak的作者周鼎 ​

Ubuntu tweak 是一款知名度很高的應用程序軟件，Ubuntu 用户可以用它來調整系統的性能、功能等各個細節。項目的創始人，周鼎又名 Tualatrix Chou ，正與我們分享 Ubuntu Tweak 的特性、使用感覺以及它跟 Canonical 的關係，並且勾勒了項目的未來計劃藍圖。享受吧！

你什麼時候開始使用 Linux 的，並基於什麼使你決定開發 Ubuntu tweak ？

我開始使用 Linux 是在2006年底，那時剛開始我的大學生活。當時我正在學 C 編程語言，一個朋友建議説要學習編程的話 Linux 是最好的平台環境，所以我就開始了我的 Linux 生涯，是從 Fedora Core 6 開始的。但用了僅僅只有一週的時間，我就換成 Ubuntu 6.10，因為Ubuntu在中國有更好的社區，也有更好更快的源庫/鏡像。我立馬就愛上了 Ubuntu，就一週時間，就從 Windows 環境完全切換到 Ubuntu 環境。

在苦樂參半的半年使用時間後，我意識到 Ubuntu 對中國用户來説不是太友好，因為全新安裝系統後，用户必須得自己配置字體、輸入法以及其它很多很多設置。所以，我決定開發出一款應用程序來幫助新手，讓他們很簡單的就可以對系統做相應配置。

因此在2007年7月，我就開始開發 Ubuntu Tweak，剛開始的時候，僅僅提供了漢語版本的，但很快就考慮了 Ubuntu Tweak 的國際版本，並且在2007年9月份就發佈了首個國際版本。

Ubuntu tweak 已經是非常成功的項目了。很多 Ubuntu 用户用它來調整系統的性能、功能等各個細節。能給我們談論下 Ubuntu Tweak 能做些什麼嗎？

Ubuntu Tweak 可以用來切換桌面圖標的顯示方式、設置字體、啓用/禁用多用户切換功能以及登陸的標識（logo）等等。

在最新的 Ubuntu Tweak 0.6版本中，你也可以調整你的 Unity 桌面以及關機功能。

你也能使用 Ubuntu Tweak 來清理系統的垃圾以釋放空間和使系統保持乾淨。

Canonical 在他們的默認發佈源中不考慮加入 Ubuntu Tweak。這意味着什麼？這對那些沒有經驗，但又想要使用你的應用程序來調整他們的系統的用户來説，存在某些風險嗎？

對的。因為在以前的 Ubuntu Tweak 發佈版本中，為流行的 PPA 都提供了可用源，但我不能保證所有的 PPA 都是安全的，所以 Ubuntu Tweak 會有一些安全風險。

如你們所見，從0.6版本後 Ubuntu Tweak 就已經移除了源中心（Source Center）。但請不要混淆“Ubuntu默認包含”和“加入源倉庫”這兩個概念。Ubuntu Tweak 首先應該要被加入通用資源倉庫，然後才能被 Ubuntu 默認包含。

從錯誤報告和用户反饋來看，Ubuntu Tweak 已經比老版本更加穩定及更易使用。

你有收到來自 Canonical 和 Ubuntu 開發者的支持或有跟他們合作（不論什麼）的事項嗎，是哪些方面的？

當然，我得到 Canonical 公司的一些幫助，他們試着幫我把 Ubuntu Tweak 放入源倉庫。這工作現在仍然在進行。

也得到社區的很多熱心幫助，他們幫我翻譯、設計、測試、報告錯誤，甚至提交代碼分支。

開發 Ubuntu Tweak 的有多少人？

如果你説的是“代碼開發者”，就僅僅我一個，但我們有很多設計人員：logo 是M.Sharp設計的，Kevin Chou 幫助設計了 Ubuntu Tweak 的用户界面(UI)原型，就是0.6版本的樣子。現在 Jeonkwan Chan 正在幫我重新美化用户界面，將會用在0.7版本上。任何人，只要願意就可以加入到 Ubuntu Tweak 的開發中來:)

在Ubuntu11.04版本中當 Unity 出現時，許多 Ubuntu 用户抱怨其可配置性不好，您對這個怎麼看的？這個特殊的桌面環境能有些什麼多適用性的配置能力呢？

我喜歡桌面系統的可配置高適應性，這是 Linux 系統的優點，不是嗎？

例如，我不喜歡 Unity Launcher 的自動隱藏功能，所以我設置讓他不會隱藏。

事實上，Unity 是可配置的，僅僅是它缺少 CompizConfig 設置管理器，所以你不能把 Unity Launcher 放到桌面底部或右面，這對左撇子來説很不友好。哈哈，開玩笑的。

如大家所見，Ubuntu 12.04已經增加了隱藏/顯示切換功能，Launcher 的大小在系統設置中也可以自定義設置。我認為 Unity 將會有更多的可配置功能。

一般來説，你認為 Canonical 公司開發 Unity 桌面環境是正確的決策嗎？他們與 Gnome 開發者之間有合作爭議，這有些是不可避免的嗎？

是的，對於 Canonical 公司來説，我覺得他們的決策很正確。回顧三年前，當 Ubuntu 首次引入基於 GNOME Panel 的Indicator ，它的設計就要比原來直接的 GNOME Panel 小程序更優雅。但 Canonical 開發者和 GNOME 開發者之間合作有些問題，因為他們從來沒有着眼於 GNOME。直到 GNOME 3 的面世，情況才有所好轉，它的 GNOME Shell 已經從 GNOME Panel 移出來了，並且 GNOME Shell 的面板已經和上面提到的 Indicator 用的是同一套設計方式。如果他們之間共用相同的 API 的話，桌面Linux應該會更好用。

所以來自於公司、社區、GNOME 桌面等的不同的關於用户界面的見解，綜合起來最終就形成了 Unity。

我認為這是好事。至少，到目前為至，比起 GNOME Shell 來説，我更喜歡 Unity。

雖然你正在開發的是一款 Ubuntu 系統專用的程序，但我假設你為了使用更多的高級用户功能，會使用其它的發行版本。你會選擇哪些發行版本呢？為什麼？

當然，我已經玩過 Fedora、Arch、 OpenSUSE，特別是 Gentoo，我已經整整使用了一年。它是我第二喜歡的 Linux 發行系統，因為它擁有一個最先進的包管理系統。

但現在我僅僅只使用 Ubuntu 的桌面版本和服務版，也使用 Mac OS X，很多的設計靈感就來自於它 😃

Ubuntu Tweak 能被優化或做幾個分支或者改變一點點，以便能在其它的 linux 發行版本比如 Fedora、OpenSue 或者 Debian 上使用嗎？有做成統一的一個叫做“Linux Tweak”的應用程序，用户不管選擇什麼樣的發佈版本或桌面環境都可以用這種想法嗎？不知道是否可行？

可以的，要讓 Ubuntu Tweak 在其它發行版本中運行非常容易。它是模組化的，很輕鬆的就可以改造(hack)。

2008年的時候，我就發佈了一版 Fedora 的“Ubuntu Tweak for Fedora”，但最終我放棄維護這個版本了，因為我主要關注 Ubuntu 版本的，所以沒有那麼多精力。

那 Ubuntu Tweak 的未來計劃是什麼？也許 Canonical 公司會內嵌進系統，然後把它做為發佈版本默認的工具或者他們會基於他們自己的系統調整工具來使用它。您認為呢？您的下一步計劃會是什麼的呢？

Ubuntu Tweak 的未來當然會一片光明。哈哈。

我已經開始實現把 Ubuntu Tweak 加入軟件中心這個工作了。如果用户能從軟件中心直接安裝 Ubuntu Tweak，它會更容易。

現在我正在開發0.7版本的，它將更美觀，並且與 Unity 桌面的集成度更好，也加入了一些很有用的新功能。我想使Ubuntu Tweak 在 Unity 桌面環境下儘可能的發揮作用。

跟隨着 Ubuntu 12.04的發佈，我也計劃發佈新的版本，希望大家喜歡 😃

還有一件事要透露下，我已經加入 Canonical 北京公司，負責處理 OEM 的事情。雖然 Ubuntu Tweak 仍是一個個人項目，我還沒有參與進 Ubuntu 的開發任務，但有可能話我會試着加入開發團隊 😃

太偉大了！謝謝 Tualatrix。
