Linux date命令 - 顯示和設置系統日期與時間 ​

操作系統上的時間也許只是當做一個時鐘。特別在控制台下, 我們通常並不認為時間有什麼重要的。但是對於管理員，這種認識是錯誤的。你知道錯誤的日期和時間會導致你不能編譯程序麼?

因為日期和時間很重要，這或許就是開發網絡時間協議(NTP:Network Time Protocol)的原因。讓我們瞭解下date命令是如何工作的。

顯示系統日期 ​

要顯示系統日期,只要輸入:

$ date
Thu Dec 5 22:55:41 WIB 2013

格式化顯示日期 ​

日期有很多格式。如果你不喜歡默認的格式，你可以換一種格式。你可能會想"為什麼我需要改變格式? 默認的輸出對我足夠了。"

是的，你説的對，但是當你在編程時，默認輸出或許無法滿足你的需求，因此需要一些自定義輸出。

RFC 2822 的日期與時間輸出格式 ​

$ date -R
Thu, 05 Dec 2013 23:40:53 +0700

RFC 2822 的格式像這樣 : 星期, 日-月-年, 小時:分鐘:秒 時區

時區 +0700 等同於 GMT +7。

默認上date使用的是定義在/etc/localtime的時區。有效時區數據定義在/usr/share/timezones。

顯示或者設置協調世界時 ​

在 Wikipedia上, UTC 意思是

世界上主要的時鐘和時間的標準。這是格林位置標準時間幾個非常相近的替代者之一。

以UTC形式顯示日期和時間, 使用 -u 參數

$ date -u
Thu Dec 5 16:45:58:UTC 2013

使用格式化選項 ​

要自定義你的日期格式, 使用加號 (+)

$ date +”Day : %d Month : %m Year : %Y”
Day: 05 Month: 12 Year: 2013
  • $ date +%D 12/05/13

%D 格式是 年/月/日 的格式.

如果你想的話，你可以輸出日期的名字。下面是一些例子:

$ date +”%a %b %d %y”
Fri 06 Dec 2013

$ date +”%A %B %d %Y”
Friday December 06 2013

$ date +”%A %B %d %Y %T”
Friday December 06 2013 00:30:37 

$ date +”%A %B-%d-%Y %c”
Friday December-06-2013 12:30:37 AM WIB

還有很多的日期格式。只要輸入:

$ date –help

或者

$ man date

來顯示date命令的語法和參數。

基本上，date命令會翻譯所有所有的百分號(%)開頭的格式和輸出在引號("")內所有的內容。

設置系統日期和時間 ​

通常地，你希望你的系統日期和時間是自動設置的。如果由於一些原因，你想要手動修改它，我們可以使用這個命令。

# date –set=”20140125 09:17:00”

這會設置你當前的系統日期和時間到一月 25, 2014 and 09:17:00 AM。請注意,你必須擁有root特權來這麼做。不然你會得到這樣一個錯誤。

date: cannot set date: Operation not permitted
Sat Jan 25 09:17:00 WIB 2014

重置你的時間 ​

如果你希望重置你的系統日期和時間到原始值，你可以用這個技巧。

# hwclock
Fri 06 Dec 2013 03:44:10 AM WIB -0.314082 seconds

這回設置你的系統日期和時間到hwclock命令的輸出的樣子。

在腳本中使用date命令 ​

還記得我之前説為什麼你需要改變date的輸出麼?一個答案是你或許需要編程。讓我們看下bash腳本下的一個例子。

$ vi display.date

#! /bin/bash
DATETIME=$(date +”DATE: %a %b-%d-%Y TIME: %T WEEK NUMBER: %W”)
echo $DATETIME

保存並運行它:

$ ./display.date
DATE : Fri Dec-06-2013 TIME: 03:08:19 WEEK Number :40

如果你發現權限拒絕錯誤信息,輸入:

$ chmod 755 display.date

在備份流程中使用date ​

另外一個例子是子你備份流程中使用date。

$ date +%F
2013-12-06

$ tar zcfv /daily_backup/backup-`date +%F`.tar.gz /home/pungki/Documents

它會壓縮文件夾/home/pungki/Documents到一個位於/daily_backup folder的文件backup-2013-12-06.tar.gz中。（譯註：通過“` 命令 `”來在命令列內嵌其它命令，這個字符不是單引號，而是和波浪號~同一個鍵位的那個符號。）

總結 ​

date可能被認為在某些方面不重要。但是date扮演了一個重要的角色。要想知道關於date命令更多的細節，在你的控制台下輸入man date訪問man頁面。
