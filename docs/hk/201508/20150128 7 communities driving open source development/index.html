7 個驅動開源發展的社區 ​

不久前，開源模式還被成熟的工業級廠商以懷疑的態度認作是叛逆小孩的玩物。如今，開源的促進會和基金會在一長列的供應商提供者的支持下正蓬勃發展，而他們將開源模式視作創新的關鍵。

技術的開放發展驅動着創新 ​

在過去的 20 幾年間，技術的開源推進已被視作驅動創新的關鍵因素。即使那些以前將開源視作威脅的公司也開始接受這個觀點 — 例如微軟，如今它在一系列的開源的促進會中表現活躍。到目前為止，大多數的開源推進都集中在軟件方面，但甚至這個也正在改變，因為社區已經開始向開源硬件倡議方面聚攏。這裏介紹 7 個成功地在硬件和軟件方面同時促進和發展開源技術的組織。

OpenPOWER 基金會 ​

OpenPOWER 基金會 由 IBM, Google, Mellanox, Tyan 和 NVIDIA 於 2013 年共同創建，在與開源軟件發展相同的精神下，旨在驅動開放協作硬件的發展，在過去的 20 幾年間，開源軟件發展已經找到了肥沃的土壤。

IBM 通過開放其基於 Power 架構的硬件和軟件技術，向使用 Power IP 的獨立硬件產品提供許可證等方式為基金會的建立播下種子。如今超過 70 個成員共同協作來為基於 Linux 的數據中心提供自定義的開放服務器，組件和硬件。

去年四月，在比最新基於 x86 系統快 50 倍的數據分析能力的新的 POWER8 處理器的服務器的基礎上， OpenPOWER 推出了一個技術路線圖。七月， IBM 和 Google 發佈了一個固件堆棧。去年十月見證了 NVIDIA GPU 帶來加速 POWER8 系統的能力和來自 Tyan 的第一個 OpenPOWER 參考服務器。

Linux 基金會 ​

於 2000 年建立的 Linux 基金會 如今成為掌控着歷史上最大的開源協同開發成果，它有着超過 180 個合作成員和許多獨立成員及學生成員。它贊助 Linux 核心開發者的工作並促進、保護和推進 Linux 操作系統，並協調軟件的協作開發。

它最為成功的協作項目包括 Code Aurora Forum (一個擁有為移動無線產業服務的企業財團)，MeeGo (一個為移動設備和 IVI [注:指的是車載消息娛樂設備，為 In-Vehicle Infotainment 的簡稱] 構建一個基於 Linux 內核的操作系統的項目) 和 Open Virtualization Alliance (開放虛擬化聯盟，它促進自由和開源軟件虛擬化解決方案的採用)。

開放虛擬化聯盟 ​

開放虛擬化聯盟(OVA) 的存在目的為：通過提供使用案例和對具有互操作性的通用接口和 API 的發展提供支持，來促進自由、開源軟件的虛擬化解決方案，例如 KVM 的採用。KVM 將 Linux 內核轉變為一個虛擬機管理程序。

如今， KVM 已成為和 OpenStack 共同使用的最為常見的虛擬機管理程序。

OpenStack 基金會 ​

原本作為一個 IaaS(基礎設施即服務) 產品由 NASA 和 Rackspace 於 2010 年啓動，OpenStack 基金會 已成為最大的開源項目聚居地之一。它擁有超過 200 家公司成員，其中包括 AT&T, AMD, Avaya, Canonical, Cisco, Dell 和 HP。

大約以 6 個月為一個發行週期，基金會的 OpenStack 項目開發用於通過一個基於 Web 的儀表盤，命令列工具或一個 RESTful 風格的 API 來控制或調配流經一個數據中心的處理存儲池和網絡資源。至今為止，基金會支持的協同開發已經孕育出了一系列 OpenStack 組件，其中包括 OpenStack Compute(一個雲計算網絡控制器，它是一個 IaaS 系統的主要部分)，OpenStack Networking(一個用以管理網絡和 IP 地址的系統) 和 OpenStack Object Storage(一個可擴展的冗餘存儲系統)。

OpenDaylight ​

作為來自 Linux 基金會的另一個協作項目， OpenDaylight 是一個由諸如 Dell, HP, Oracle 和 Avaya 等行業廠商於 2013 年 4 月建立的聯合倡議。它的任務是建立一個由社區主導、開源、有工業支持的針對軟件定義網絡（ SDN: Software-Defined Networking）的包含代碼和藍圖的框架。其思路是提供一個可直接部署的全功能 SDN 平台，而不需要其他組件，供應商可提供附件組件和增強組件。

Apache 軟件基金會 ​

Apache 軟件基金會 (ASF) 是將近 150 個頂級項目的聚居地，這些項目涵蓋從開源的企業級自動化軟件到與 Apache Hadoop 相關的分佈式計算的整個生態系統。這些項目分發企業級、可免費獲取的軟件產品，而 Apache 協議則是為了讓無論是商業用户還是個人用户更方便地部署 Apache 的產品。

ASF 是 1999 年成立的一個會員制，非盈利公司，以精英為其核心 — 要成為它的成員，你必須首先在基金會的一個或多個協作項目中做出積極貢獻。

開放計算項目 ​

作為 Facebook 重新設計其 Oregon 數據中心的副產物， 開放計算項目 旨在發展針對數據中心的開源硬件解決方案。 OCP 是一個由廉價無浪費的服務器、針對 Open Rack(為數據中心設計的機架標準，來讓機架集成到數據中心的基礎設施中) 的模組化 I/O 存儲和一個相對 "綠色" 的數據中心設計方案等構成。

OCP 董事會成員包括來自 Facebook，Intel，Goldman Sachs，Rackspace 和 Microsoft 的代表。

OCP 最近宣佈了有兩種可選的許可證： 一個類似 Apache 2.0 的允許衍生工作的許可證，和一個更規範的鼓勵將更改回饋到原有軟件的許可證。
