Tickr：一個開源的 Linux 桌面 RSS 新聞速遞應用 ​

最新的！最新的！閲讀關於它的一切！

好了，我們今天要推薦的應用程序可不是舊式報紙的二進制版本——它會以一種漂亮的方式將最新的新聞推送到你的桌面上。

Tickr 是一個基於 GTK 的 Linux 桌面新聞速遞應用，能夠以橫條方式滾動顯示最新頭條新聞以及你最愛的RSS資訊文章標題，當然你可以放置在你桌面的任何地方。

請叫我 Joey Calamezzo；我把它放在底部，就像電視新聞台的滾動字幕一樣。 （LCTT 譯註： Joan Callamezzo 是 Pawnee Today 的主持人，一位 Pawnee 的本地新聞/脱口秀主持人。而本文作者是 Joey。）

“到你了，副標題”。

RSS -還記得嗎？ ​

“謝謝，這段結束了。”

在一個充斥着推送通知、社交媒體、標題黨，以及哄騙人們點擊的清單體的時代，RSS看起來有一點過時了。

對我來説呢？恩，RSS是名副其實的真正簡單的聚合（RSS ： Really Simple Syndication）。這是將消息通知給我的最簡單、最易於管理的方式。我可以在我願意的時候，管理和閲讀一些東西；沒必要匆忙的去看，以防這條微博消失在信息流中，或者推送通知消失。

tickr的美在於它的實用性。你可以不斷地有新聞滾動在屏幕的底部，然後不時地瞥一眼。

你不會有“閲讀”或“標記所有為已讀”的壓力。當你看到一些你想讀的東西，你只需點擊它，將它在Web瀏覽器中打開。

開始設置 ​

儘管雖然tickr可以從Ubuntu軟件中心安裝，然而它已經很久沒有更新了。當你打開笨拙的不直觀的控制面板的時候，沒有什麼能夠比這更讓人感覺被遺棄的了。

要打開它：

  1. 右鍵單擊tickr條
  2. 轉至編輯>首選項
  3. 調整各種設置

選項和設置行的後面，有些似乎是容易理解的。但是詳細瞭解這些你才能夠掌握一切，包括：

  • 設置滾動速度
  • 選擇鼠標經過時的行為
  • 資訊更新頻率
  • 字體，包括字體大小和顏色
  • 消息分隔符（“delineator”）
  • tickr在屏幕上的位置
  • tickr條的顏色和不透明度
  • 選擇每種資訊顯示多少文章

有個值得一提的“怪癖”是，當你點擊“應用”按鈕，只會更新tickr的屏幕預覽。當您退出“首選項”窗口時，請單擊“確定”。

想要得到完美的顯示效果， 你需要一點點調整，特別是在 Unity 上。

按下“全寬按鈕”，能夠讓應用程序自動檢測你的屏幕寬度。默認情況下，當放置在頂部或底部時，會留下25像素的間距（應用程序以前是在GNOME2.x桌面上創建的）。只需添加額外的25像素到輸入框，來彌補這個問題。

其他可供選擇的選項包括：選擇文章在哪個瀏覽器打開；tickr是否以一個常規的窗口出現；是否顯示一個時鐘；以及應用程序多久檢查一次文章資訊。

添加資訊 ​

tickr自帶的有超過30種不同的資訊列表，從技術Blog到主流新聞服務。

你可以選擇很多你想在屏幕上顯示的新聞提要。如果你想添加自己的資訊，你可以：—

  1. 右鍵單擊tickr條
  2. 轉至文件>打開資訊
  3. 輸入資訊網址
  4. 點擊“添加/更新”按鈕
  5. 單擊“確定”（選擇）

如果想設置每個資訊在ticker中顯示多少條文章，可以去另一個首選項窗口修改“每個資訊最大讀取N條文章”

在Ubuntu 14.04 LTS或更高版本上安裝Tickr ​

這就是 Tickr，它不會改變世界，但是它能讓你知道世界上發生了什麼。

在Ubuntu 14.04 LTS或更高版本中安裝，點擊下面的按鈕轉到Ubuntu軟件中心。
