有了 Linux，你就可以搭建自己的超級計算機 ​

幾乎所有超級計算機上運行的系統都是 Linux，其中包括那些由樹莓派（Raspberry Pi）板卡和 PlayStation 3遊戲機組成的計算機。

題圖來源：By Michel Ngilen,[ CC BY 2.0 ], via Wikimedia Commons

超級計算機是一種嚴肅的工具，做的都是高大上的計算。它們往往從事於嚴肅的用途，比如原子彈模擬、氣候模擬和高等物理學。當然，它們的花費也很高大上。在最新的超級計算機 Top500 排名中，中國國防科技大學研製的天河 2 號位居第一，而天河 2 號的建造耗資約 3.9 億美元！

但是，也有一個超級計算機，是由博伊西州立大學電氣和計算機工程系的一名在讀博士 Joshua Kiepert 用樹莓派構建完成的，其建造成本低於2000美元。

不，這不是我編造的。它一個真實的超級計算機，由超頻到 1GHz 的 B 型樹莓派的 ARM11 處理器與 VideoCore IV GPU 組成。每個都配備了 512MB 的內存、一對 USB 端口和 1 個 10/100 BaseT 以太網端口。

那麼天河 2 號和博伊西州立大學的超級計算機有什麼共同點嗎？它們都運行 Linux 系統。世界最快的超級計算機前 500 強中有 486 個也同樣運行的是 Linux 系統。這是從 20 多年前就開始的格局。而現在的趨勢是超級計算機開始由廉價單元組成，因為 Kiepert 的機器並不是唯一一個無所謂預算的超級計算機。

麻省大學達特茅斯分校的物理學副教授 Gaurav Khanna 創建了一台超級計算機僅用了不足 200 台的 PlayStation3 視頻遊戲機。

PlayStation 遊戲機由一個 3.2 GHz 的基於 PowerPC 的 Power 處理器所驅動。每個都配有 512M 的內存。你現在仍然可以花 200 美元買到一個，儘管索尼將在年底逐步淘汰它們。Khanna 僅用了 16 個 PlayStation 3 構建了他第一台超級計算機，所以你也可以花費不到 4000 美元就擁有你自己的超級計算機。

這些機器可能是用玩具建成的，但他們不是玩具。Khanna 已經用它做了嚴肅的天體物理學研究。一個白帽子黑客組織使用了類似的 PlayStation 3 超級計算機在 2008 年破解了 SSL 的 MD5 哈希算法。

兩年後，美國空軍研究實驗室研製的 Condor Cluster，使用了 1760 個索尼的 PlayStation 3 的處理器和168 個通用的圖形處理單元。這個低廉的超級計算機，每秒運行約 500 TFLOP ，即每秒可進行 500 萬億次浮點運算。

其他的一些便宜且適用於構建家庭超級計算機的構件包括，專業並行處理板卡，比如信用卡大小的 99 美元的 Parallella 板卡，以及高端顯卡，比如 Nvidia 的 Titan Z 和 AMD 的 FirePro W9100。這些高端板卡的市場零售價約 3000 美元，一些想要一台夢幻般的機器的玩家為此參加了英特爾極限大師賽：英雄聯盟世界錦標賽，要是甚至有機會得到了第一名的話，能獲得超過 10 萬美元獎金。另一方面，一個能夠自己提供超過 2.5TFLOPS 計算能力的計算機，對於科學家和研究人員來説，這為他們提供了一個可以擁有自己專屬的超級計算機的經濟的方法。

而超級計算機與 Linux 的連接，這一切都始於 1994 年戈達德航天中心的第一個名為 Beowulf 超級計算機。

按照我們的標準，Beowulf 不能算是最優越的。但在那個時期，作為第一台自制的超級計算機，它的 16 個英特爾486DX 處理器和 10Mbps 的以太網總線，是個偉大的創舉。Beowulf 是由美國航空航天局的承建商 Don Becker 和 Thomas Sterling 所設計的，是第一台“創客”超級計算機。它的“計算部件” 486DX PC，成本僅有幾千美元。儘管它的速度只有個位數的 GFLOPS （吉拍，每秒10億次）浮點運算，Beowulf 表明了你可以用商用現貨（COTS）硬件和 Linux 創建超級計算機。

我真希望我參與創建了一部分，但是我 1994 年就離開了戈達德，開始了作為一名全職的科技記者的職業生涯。該死。

但是儘管我只是使用筆記本的記者，我依然能夠體會到 COTS 和開源軟件是如何永遠的改變了超級計算機。我希望現在讀這篇文章的你也能。因為，無論是 Raspberry Pi 集羣，還是超過 300 萬個英特爾的 Ivy Bridge 和 Xeon Phi 芯片的龐然大物，幾乎所有當代的超級計算機都可以追溯到 Beowulf。
