Ubuntu 下五個最好的 BT 客户端 ​

在尋找 Ubuntu 中最好的 BT 客户端嗎？事實上，Linux 桌面平台中有許多 BT 客户端，但是它們中的哪些才是最好的 Ubuntu 客户端呢？

我將會列出 Linux 上最好的五個 BT 客户端，它們都擁有着體積輕盈，功能強大的特點，而且還有令人印象深刻的用户界面。自然，易於安裝和使用也是特性之一。

Ubuntu 下最好的 BT 客户端 ​

考慮到 Ubuntu 默認安裝了 Transmission，所以我將會從這個列表中排除了 Transmission。但是這並不意味着 Transmission 沒有資格出現在這個列表中，事實上，Transmission 是一個非常好的BT客户端，這也正是它被包括 Ubuntu 在內的多個發行版默認安裝的原因。

Deluge ​

Deluge 被 Lifehacker 評選為 Linux 下最好的 BT 客户端，這説明了 Deluge 是多麼的有用。而且，並不僅僅只有 Lifehacker 是 Deluge 的粉絲，縱觀多個論壇，你都會發現不少 Deluge 的忠實擁躉。

快速，時尚而直觀的界面使得 Deluge 成為 Linux 用户的摯愛。

Deluge 可在 Ubuntu 的倉庫中獲取，你能夠在 Ubuntu 軟件中心中安裝它，或者使用下面的命令：

sudo apt-get install deluge

qBittorrent ​

正如它的名字所暗示的，qBittorrent 是著名的 Bittorrent 應用的 Qt 版本。如果曾經使用過它，你將會看到和 Windows 下的 Bittorrent 相似的界面。同樣輕巧並且有着 BT 客户端的所有標準功能， qBittorrent 也可以在 Ubuntu 的默認倉庫中找到。

它可以通過 Ubuntu 軟件倉庫安裝，或者使用下面的命令：

sudo apt-get install qbittorrent

Tixati ​

Tixati 是另一個不錯的 Ubuntu 下的 BT 客户端。它有着一個默認的黑暗主題，儘管很多人喜歡，但是我例外。它擁有着一切你能在 BT 客户端中找到的功能。

除此之外，它還有着數據分析的額外功能。你可以在美觀的圖表中分析流量以及其它數據。

  • 下載 Tixati

Vuze ​

Vuze 是許多 Linux 以及 Windows 用户最喜歡的 BT 客户端。除了標準的功能，你可以直接在應用程序中搜索種子，也可以訂閲系列片源，這樣就無需再去尋找新的片源了，因為你可以在側邊欄中的訂閲看到它們。

它還配備了一個視頻播放器，可以播放帶有字幕的高清視頻等等。但是我不認為你會用它來代替那些更好的視頻播放器，比如 VLC。

Vuze 可以通過 Ubuntu 軟件中心安裝或者使用下列命令：

sudo apt-get install vuze

Frostwire ​

Frostwire 是一個你應該試一下的應用。它不僅僅是一個簡單的 BT 客户端，它還可以應用於安卓，你可以用它通過 Wifi 來共享文件。

你可以在應用中搜索種子並且播放他們。除了下載文件，它還可以瀏覽本地的影音文件，並且將它們有條理的呈現在播放器中。這同樣適用於安卓版本。

還有一個特點是：Frostwire 提供了獨立音樂人的合法音樂下載。你可以下載並且欣賞它們，免費而且合法。

  • 下載 Frostwire

榮譽獎 ​

在 Windows 中，uTorrent（發音：mu torrent）是我最喜歡的 BT 應用。儘管 uTorrent 可以在 Linux 下運行，但是我還是特意忽略了它。因為在 Linux 下使用 uTorrent 不僅困難，而且無法獲得完整的應用體驗（運行在瀏覽器中）。

可以在這裏閲讀 Ubuntu下uTorrent 的安裝教程。

快速提示: ​

大多數情況下，BT 應用不會默認自動啓動。如果想改變這一行為，請閲讀如何管理 Ubuntu 下的自啓動程序來學習。

你最喜歡的是什麼？ ​

這些是我對於 Ubuntu 下最好的 BT 客户端的意見。你最喜歡的是什麼呢？請發表評論。也可以查看與本主題相關的Ubuntu 最好的下載管理器。如果使用 Popcorn Time，試試 Popcorn Time 技巧
