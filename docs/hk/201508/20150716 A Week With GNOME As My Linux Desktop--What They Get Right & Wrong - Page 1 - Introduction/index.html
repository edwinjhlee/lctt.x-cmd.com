一週 GNOME 之旅：品味它和 KDE 的是是非非（第一節 介紹） ​

作者聲明:　如果你是因為某種神蹟而在沒看標題的情況下點開了這篇文章，那麼我想再重申一些東西……這是一篇評論文章，文中的觀點都是我自己的，不代表 Phoronix 網站和 Michael 的觀點。它們完全是我自己的想法。

另外，沒錯……這可能是一篇引戰的文章。我希望 KDE 和 Gnome 社團變得更好一些，因為我想發起一個討論並反饋給他們。為此，當我想指出（我所看到的）一個瑕疵時，我會盡量地做到具體而直接。這樣，相關的討論也能做到同樣的具體和直接。再次聲明：本文另一可選標題為“死於成千上萬的紙割”（LCTT 譯註：paper cuts——紙割，被紙片割傷——指易修復但煩人的缺陷。Ubuntu 從 9.10 開始，發起了 One Hundred Papercuts 項目，用於修復那些小而煩人的易用性問題）。

現在，重申完畢……文章開始。

當我把《評價 Fedora 22 KDE 》一文發給 Michael 時，感覺很不是滋味。不是因為我不喜歡 KDE，或者不待見 Fedora，遠非如此。事實上，我剛開始想把我的 T450s 的系統換為 Arch Linux 時，馬上又決定放棄了，因為我很享受 fedora 在很多方面所帶來的便捷性。

我感覺很不是滋味的原因是 Fedora 的開發者花費了大量的時間和精力在他們的“工作站”產品上，但是我卻一點也沒看到。在使用 Fedora 時，我並沒用採用那些主要開發者希望用户採用的那種使用方式，因此我也就體驗不到所謂的“ Fedora 體驗”。它感覺就像一個人評價 Ubuntu 時用的卻是 Kubuntu，評價 OS X 時用的卻是 Hackintosh，或者評價 Gentoo 時用的卻是 Sabayon。根據論壇裏大量讀者對 Michael 的説法，他們在評價各種發行版時都是使用的默認設置——我也不例外。但是我還是認為這些評價應該在“真實”配置下完成，當然我也知道在給定的情況下評論某些東西也的確是有價值的——無論是好是壞。

正是在懷着這種態度的情況下，我決定跳到 Gnome 這個水坑裏來泡泡澡。

但是，我還要在此多加一個聲明……我在這裏所看到的 KDE 和 Gnome 都是打包在 Fedora 中的。OpenSUSE、 Kubuntu、 Arch等發行版的各個桌面可能有不同的實現方法，使得我這裏所説的具體的“痛點”跟你所用的發行版有所不同。還有，雖然用了這個標題，但這篇文章將會是一篇“很 KDE”的重量級文章。之所以這樣稱呼，是因為我在“使用” Gnome 之後，才知道 KDE 的“紙割”到底有多麼的多。

登錄界面 ​

我一般情況下都不會介意發行版帶着它們自己的特別主題，因為一般情況下桌面看起來會更好看。可我今天可算是找到了一個例外。

第一印象很重要，對吧？那麼，GDM（LCTT 譯註： Gnome Display Manage：Gnome 顯示管理器。）絕對幹得漂亮。它的登錄界面看起來極度簡潔，每一部分都應用了一致的設計風格。使用通用圖標而不是文本框為它的簡潔加了分。

這並不是説 Fedora 22 KDE ——現在已經是 SDDM 而不是 KDM 了——的登錄界面不好看，但是看起來絕對沒有它這樣和諧。

問題到底出來在哪？頂部欄。看看 Gnome 的截圖——你選擇一個用户，然後用一個很小的齒輪簡單地選擇想登入哪個會話。設計很簡潔，一點都不礙事，實話講，如果你沒注意的話可能完全會看不到它。現在看看那藍色（ LCTT 譯註：blue，有憂鬱之意，一語雙關）的 KDE 截圖，頂部欄看起來甚至不像是用同一個工具渲染出來的，它的整個位置的安排好像是某人想着：“哎喲媽呀，我們需要把這個選項扔在哪個地方……”之後決定下來的。

對於右上角的重啓和關機選項也一樣。為什麼不單單用一個電源按鈕，點擊後會下拉出一個菜單，裏面包括重啓，關機，掛起的功能？按鈕的顏色跟背景色不同肯定會讓它更加突兀和顯眼……但我可不覺得這樣子有多好。同樣，這看起來可真像“苦思”後的決定。

從實用觀點來看，GDM 還要遠遠實用的多，再看看頂部一欄。時間被列了出來，還有一個音量控制按鈕，如果你想保持周圍安靜，你甚至可以在登錄前設置靜音，還有一個可用性按鈕來實現高對比度、縮放、語音轉文字等功能，所有可用的功能通過簡單的一個開關按鈕就能得到。

切換到上游（KDE 自帶）的 Breeve 主題……突然間，我抱怨的大部分問題都被解決了。通用圖標，所有東西都放在了屏幕中央，但不是那麼重要的被放到了一邊。因為屏幕頂部和底部都是同樣的空白，在中間也就醖釀出了一種美好的和諧。還是有一個文本框來切換會話，但既然電源按鈕被做成了通用圖標，那麼這點還算可以原諒。當前時間以一種漂亮的感覺呈現，旁邊還有電量指示器。當然 gnome 還是有一些很好的附加物，例如音量小程序和可用性按鈕，但 Breeze 總歸要比 Fedora 的 KDE 主題進步。

到 Windows（Windows 8和10之前）或者 OS X 中去，你會看到類似的東西——非常簡潔的，“不礙事”的鎖屏與登錄界面，它們都沒有文本框或者其它分散視覺的小工具。這是一種有效的不分散人注意力的設計。Fedora……默認帶有 Breeze 主題。VDG 在 Breeze 主題設計上幹得不錯。可別糟蹋了它。
