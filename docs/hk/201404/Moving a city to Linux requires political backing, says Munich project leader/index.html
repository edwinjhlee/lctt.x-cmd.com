慕尼黑市項目負責人稱“將整個城市遷移到 Linux 需要政策支持” ​

慕尼黑市政府已將接近 15,000 台 PC 從 Windows NT 操作系統遷移到了其自有的 Linux 發行版

來自IDG 新聞 ： 慕尼黑市十年前開始向 Linux 遷移，今年我們見證了這項工程竣工。“我們學到的最深一課是，你無法在沒有持續政策支持的情況下完成這樣的項目。”LiMux 項目的負責人 Peter Hofmann 在總結經驗時説。

慕尼黑市政府將他們網絡上 15,000 台 PC 中大約 14,800 台遷移到了他們自有的基於 Ubuntu 的 Linux——LiMux 上。這超出了他們原定遷移 12,000 台桌面計算機的計劃。

慕尼黑市是在 Microsoft 聲明將不再為 Windows NT 4.0 提供支持的時候決心遷移他們的 IT 系統的，因為他們使用的就是 Windows NT 4.0。當時，該市不得不在遷移到新版 Windows 和尋找一個替代平台之間做出抉擇，因為新的軟件以及現存軟件的新版本都將無法在 Windows NT 上使用。市議會決定與 Linux 攜手，和軟件供應商們保持更加獨立的關係。

Hofmann 説，政策支持是遷移成功的關鍵。

“我們從始至終都擁有政策的支持。我們得讓政府官員們時刻掌握項目最新信息，就像對待股東一樣。”他説。

藉助這樣的手段，這些政客們從未喪失對項目的興趣，也始終能瞭解到項目執行人在做什麼，他説。“我目睹過很多開源項目流產，”因為它們要麼未得到、要麼失去了政策支持，他説。

市政府原定 2009 年完成遷移計劃，但事實上從最初作出決定到 LiMux 項目遷移完工大約耗費了十年時間。項目全程也經歷了幾次延期。

遷移工作在原計劃一年之後才真正開始，這是第一次延期，Hofmann 説。第二次延期緣於 2007 年市議會的一個決定：慕尼黑市的 IT 部門也要負責 Linux 客户端基礎設施所必須的標準化工作，他説。但是慕尼黑市既沒有正確的程序也沒有正確的組織來實現這種標準化，他説。

項目第三次延期是在 2010 年，當時市議會決定擴大項目規模，Hofmann 説。風險管理、測試管理和需求工程作為三個附加任務目標被加進了項目裏。

儘管困難重重，Hofmann 説他仍然願意下次再做一次。

慕尼黑市 IT 組織的異質性基礎設施曾是該項目最大的問題之一，Hofmann 説。項目啓動之初，22 個組織都有自己獨有的配置、軟硬件、進程、Windows 客户端知識以及相應投入使用的基礎設施，他説。“我們想建設一個標準化的、集中交付和開發的 Linux 客户端，”他説。

Hofmann 預計，四分五裂的基礎設施會造成問題。事實證明，不論從技術因素還是組織因素來看，標準化客户端的工作都比他預想的還要艱難。

幸運的是，他有足夠的自由度重建整個城市的 IT 基礎設施。

“任何人在打算遷移之前都要重新審視他們的整個 IT 組織。遷移到 Linux 遠非節省開支和使用免費軟件那麼簡單。”他補充道。

但慕尼黑市的遷移工作確確實實省錢了。2012 年 11 月，一名市議員答覆道，慕尼黑市計算出遷移到 LiMux 會比更新已有 Microsoft 軟件節省超過 1100 萬歐元！

這項計算橫向對比了 LiMux、Windows 7 + Microsoft Office、Windows 7 + OpenOffice（慕尼黑市為 LiMux 選擇的生產力套件） 三種方案，包含必要的硬件升級、培訓、外部遷移支持和優化事務以及其他指標。兩個 Windows 方案都明顯比 LiMux 方案昂貴很多，這主要緣於微軟對軟件使用許可收取的費用。

Hofmann 説，LiMux 不存在支持合同。“你要支持合同幹什麼？實際上你並沒有得到支持，你得到的是新版本。你需要它的唯一理由來自於你的律師，他讓你這麼做以便日後出現問題有責任人可以追究。我們不追究任何人，我們自己會搞定那些問題，”他説。

如果慕尼黑市的 IT 人員不能自己修復 bug，他們可以尋求專家解決特定的 bug，Hofmann 説。“你不再依賴從軟件供應商那裏買來的服務，你依靠你自己和你掌握的信息，”他説。

儘管這樣，抱怨依然存在。從外部組織收到的 Word 和 Excel 文檔有時候不得不做些更改再發回去，這樣一來會給互通性造成麻煩，他説。慕尼黑市正在説服與他們通信的人員使用 OpenOffice 的 ODF 格式文檔，或者對不需要修改的文檔使用 PDF 格式，Hofmann 説。慕尼黑市已經藉助這一途徑協助了互通工具在金融業的推廣。

作為 OpenOffice 遷移計劃的一部分，慕尼黑市還開發了 WollMux。這是一個用於模板和表單的 Office 擴展，於 2008 年以自由軟件的形式發佈，如今已經被少數其他組織採用，他説。

清除 Microsoft Office 的工作中還存在其他一些障礙——該市內部應用程序對數以千計的 Microsoft Office 和 Visual Basic 宏的依賴就是其中之一，Hofmann 説。

如今仍然有約 100 個這樣的宏在為數不多的 Windows PC 上使用。

“我們的目標從來都不是徹底清除 Windows，”他説，儘管該市已經超出了遷移 80% PC 的最初目標並且一直運轉良好。

以財政部門為例，三台 Windows PC 仍然在運行特殊的銀行軟件。如果要遷移到 LiMux，市政府得付錢讓軟件供應商為這三台機器上運行的應用程序開發 LiMux 版本，Hofmann 説。

該市與德國政府印刷護照的“聯邦印刷”打交道時也面臨類似的問題。聯邦印刷要求使用一個 Windows 應用程序發送護照所需的個人數據，他説。

Hofmann 在對這個城市的未來信心滿懷的時候也認識到並不是所有人都適合遷移到 Linux。但即使不想遷移到 Linux 的人也一樣可以從慕尼黑市的經驗中得益：“曾有人對我説，‘從你啓動項目那時起，我就可以和 Microsoft 談判了。’”
