10個在隨機出現在面試中的Linux問題及答案 ​

為了給你們帶來一些小驚喜，這次我們準備了一些在面試中隨機出現的問題而不是專門關於某個領域的問題。這些問題肯定會在不深入學習新知識的前提下使你在面試中脱穎而出。

1.假設你在為你工作的公司維護一份日常的備份。這份備份是以壓縮後的格式而被維護着。現在你需要檢查一份兩個月之前的日誌，你應該提出什麼樣的建議從而可以在不解壓這份備份的前提下完成檢查日誌的任務？

答案： 在不解壓文件的前提下檢查文件內容，我們需要用到'zcat'。zcat這個工具可以輕鬆完成這個任務。

# zcat ­f phpshell­2.4.tar.gz

2.你需要追蹤你係統中發生的事件，你應該怎麼做？

答案： 為了追蹤系統中發生的事件，我們需要用到叫做syslogd的這個後台程序。syslogd這個後台程序可以追蹤系統信息並將其保存到指定的日誌文件中。

啓用'syslogd'這個後台進程會在路徑'/var/log/syslog'中生成一個日誌文件。syslogd應用對解決Linux系統中的問題十分有用。標準生成的日誌文件和下面這個例子很像。

3.如何禁止特定IP訪問FTP服務器？

答案： 我們可以通過運用tcp_wrapper來禁止可疑的IP訪問。首先在路徑'/etc/vsftpd.conf'的配置文件中，將tcp_wrapper這個參數設置為"tcp_wrapper=YES"，然後在'/etc/host.deny'文件中加入可疑的IP地址。

禁止訪問的IP地址

打開'/etc/hosts.deny'文件。

# vi /etc/hosts.deny

在文件底端加入拒絕訪問的IP地址

#
# hosts.deny    This file contains access rules which are used to
#               deny connections to network services that either use
#               the tcp_wrappers library or that have been
#               started through a tcp_wrappers-enabled xinetd.
#
#               The rules in this file can also be set up in
#               /etc/hosts.allow with a 'deny' option instead.
#
#               See 'man 5 hosts_options' and 'man 5 hosts_access'
#               for information on rule syntax.
#               See 'man tcpd' for information on tcp_wrappers
#
vsftpd:172.16.16.1

4.告訴我們Telnet和SSH之間的區別？

答案： Telnet和SSH都是用來遠程管理系統的協議。與Telnet直接傳輸數據正好相反，安全的SSH通信協議需要通信中有密鑰的交換，這説明telnet相比較於SSH不安全。

5.你需要終止你的X server，但當你嘗試殺進程的時候，你遇到了表示不能退出X server的錯誤信息。你準備怎麼做？

答案： 當你嘗試殺X server的進程時，系統不會讓你像使用'/etc/init.d/gdm stop'一樣正常的退出X server。我們需要執行一個使X server重啓的特別的鍵位組合'Ctrl+ Alt+ BackSpace'。

6.告訴我命令'ping'和'ping6'的區別？

答案： 這兩個命令有同樣的功能，但'ping6'命令可被用於ipv6的IP地址。

7.你想要在Home目錄下尋找*.tar文件並一次性刪除，你會怎麼做？

答案： 我們要同時用到find和rm命令來刪除所有*.tar文件

# find /home/ ­name '*.tar' | xargs rm ­rf

8.locate和slocate命令的區別？

答案： slocate(secure locate)會尋找所有用户有權限訪問的文件，然而locate會搜索（它的資料庫裏面的）所有更新過的結果。

9.你要在當前目錄中所有“.txt”文件中搜索“Tecmint”這個字符串，你怎麼做？

答案： 用find命令在當前目錄遞歸尋找文件中的“Tecmint”字符串。

# find ­name “*.txt” | xargs grep “Tecmint”

10.你要向所有已連接的用户發送“Server is going down for maintenance”這樣一條信息，你怎麼做？

答案： 運用wall命令就可以很容易地實現，wall命令可以向所有已連接服務器的用户發送信息。

# echo please save your work, immediately. The server is going down for Maintenance at 12:30 Pm, sharply. | wall
