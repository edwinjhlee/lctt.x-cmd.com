30個Linux上的益智小遊戲 ​

在Linux環境下有大量的免費遊戲，其中還有許多是開源的，其中相當一部分非常引人注目。現在的主流遊戲一般包含了全動態影像，矢量圖形，3D圖形，3D渲染，動畫，紋理貼圖，物理引擎，以及其他的技術。而早期的電腦遊戲還沒有使用這些圖形技術，最早的電腦遊戲是文字遊戲或者基於文字的遊戲，它們使用字符作為基本工具而不是矢量或點陣圖像。

諺語'不要根據封面去評價一本書'可以擴展成'不要根據界面來評價一款電腦遊戲'。儘管在這篇文章中提到的很多遊戲都只有非常普通的界面，它們從其他方面來彌補，包括挑戰性的玩法，以及鍛鍊腦力。

本文的目的是找出那些受歡迎的益智遊戲，這些遊戲可以促進智力，或用做日常消遣。

本文的重點是那些不太受關注的免費Linux遊戲，而不是Steam平台的類似商業遊戲。這裏列出來的所有遊戲都值得一玩，儘管它們大多沒有像商業同類應用那樣精心美化，可玩性仍然不錯。

這個列表中所包含的遊戲，需要達到以下的要求：

  • 免費（沒有下載費用，沒有月度費用）
  • 不需要通過Wine來執行。Wine是一個運行Windows軟件的兼容層。
  • 必須有可玩性和有趣。

現在，讓我們來檢查一下手上的30款遊戲。我們為每一款遊戲做了一個頁面，裏面有遊戲截圖，遊戲的完整描述，遊戲特性的深度分析，以及相關資源和評論的鏈接。
