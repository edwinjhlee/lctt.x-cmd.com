從 XP 遷移到 Linux 的入門指南 ​

Microsoft 已經不再支持 Windows XP 了。大多數人也許並不關心這事兒，但對於知道使用服務終止的軟件會有麻煩的你來説，做點兒改變的時候到了。你可以安裝同樣落伍的 Windows 7，或者安裝沒人喜歡的 Windows 8。或者，你可以從風格眾多的 Linux 中選擇一款來安裝，化身成為 Linux 用户這個精英團體的一員。

和 Windows 可不一樣，你不需要為了讓系統啓動運行而支付數百美元。Linux 是免費的，並且未來也不會收費。Linux 附帶一切必要的應用程序，比如互聯網瀏覽器、電子郵件客户端、視頻播放器、照片編輯器等一大堆同樣免費的軟件，但要想享用這些軟件，你首先得説服自己遷移到 Linux。你可能會想，我本來可以好好兒地繼續用我舊版的 Windows，幹嘛要費神用別的東西。聽我解釋，這花不了多長時間。

Linux 和 Windows 不一樣，它可不是 Microsoft 花錢僱人做的，而是在像 Red Hat、IBM、HP、Samsung 等眾多 Linux 基金會領導下的技術巨頭以及全世界成千上萬的志願者的協作下開發的。所以，你可以確信你在用的不是個別大牛工程師的小眾作品，而是開發人員遍佈全球的堅實的操作系統。

這一點使得 Linux 躋身全世界最安全的操作系統之列。好吧，百分之百的安全是不存在的，但使用 Linux 能保證安全在你身邊寸步不離，這是 Google、Facebook、Twitter、IBM、NASA 等公司使用 Linux 的唯一理由。這裏列出了使用 Linux 的世界頂級公司和組織。Linux 是個非常輕量級的操作系統，卻既能支持最前沿的新硬件，也能支持幾十年前的老硬件。

現在，如果關於 Linux 的概念已經勾起了你的興致，我們來看看房間裏的下一頭大象（譯註：原文是 the next elephant in the room。the elephant in the room 通常指顯而易見卻避而不談的問題）—— 你在 Windows XP 下最愛的應用程序。Linux 環境有你在 Windows 下愛用的絕大部分應用程序，包括 Firefox、Chrome、Steam、VLC、Skype 和 Team Viewer。如果你找不到你某個你在 Windows 上用過的軟件，那麼試試 Linux 環境下數量龐大的替代品吧。與你的 Windows 應用程序相比，它們的功能更強大，而且都是協作開發的。

列舉幾個常見的替代方案：Libre Office 可以代替 Microsoft Office，Thunderbird 可以替代 Outlook，Gimp 可以替代 Adobe Photoshop，它們全都永久免費，而且你不用為每年的小更新升級支付數百美元。你不會像用 Windows 那樣只有很少的幾種應用程序可供選擇（這是 Microsoft 的壟斷行為造成的），也就是説，任何時候如果你對 Libre Office 不滿意，你都可以改用另一個非常可靠的辦公軟件套件 Open Office。

使用 Linux 最好的事情是，你根本不用擔心病毒，也完全沒必要安裝昂貴且耗費資源嚴重的網絡安全程序，因為它們幾乎保護不了你。Windows 立足於讓整個網絡安全事業有利潤可榨取，這麼看來，反病毒公司真是幹得不錯。相反，Linux 並不鼓勵這種行為，它本就是全世界最安全的操作系統之一。這也解釋了為什麼大部分全球防務系統和股票交易系統運行的是 Linux。

好吧，如果你因為從沒見過有人用 Linux 所以還是不服的話，看看你和你身邊人的安卓手機吧，它就是在 Linux 上構建的。電視、空調、洗衣機和你鍾愛的咖啡機運行的也是 Linux。你已經生活在了一個運行 Linux 的世界裏，但你卻拒絕成為這個世界的一部分。再前進一小步吧，你馬上就會變成 Linux 精英用户了。

別説教了，咱們開始用用 Linux 吧。首先我們要選擇一款 Linux，這是最有意思的部分了。初次選擇 Linux 就像哈利·波特選擇魔杖一樣。每個風格不同的 Linux 都運行在相同的我們稱之為“內核（Kernel）”的堅實基礎之上，不同風格的 Linux 我們稱之為“發行版”。

Linux 目前有數百個發行版，Distrowatch 按流行度順序列出了所有發行版。Ubuntu、Linux Mint、Fedora、Debian 以及 Open Suse 是幾個比較著名的 Linux 發行版。如果你懷念 Windows XP 的感覺，那最好選擇 Linux Mint。如果你想體驗一下新奇的東西，嘗試一下 Ubuntu 的 Unity 界面、Fedora 的 Gnome 界面或者 Open Suse 的 KDE 界面。Unity、Gnome、KDE 是不同的用户界面的名字，我們稱之為“桌面環境（Desktop Environment）”。這些桌面環境在很老的系統上也能使用，但如果你真的要在很古老的機器上使用 Linux，你可以試試輕量級的桌面環境，比如 XFCE 和 LXDE，它們很輕量級，用户界面要簡單一些。

好了，選擇一款你喜歡的 Linux 發行版並開始使用吧。Linux 是免費、穩定並且安全的，如果還有什麼説的，那就是，如果你用着開心，就為 Linux 基金會那些傢伙的出色工作捐點錢吧。我不打算寫安裝教程，因為那些東西網上到處都是。我在線上和線下幫助我的朋友遷移到 Linux，你也應該幫助你的朋友遷移到 Linux。
