Linux基礎：分析 Ubuntu 磁盤使用情況 ​

親愛的linux極客們，

在這篇文章中，我將指導你們如何在 Ubuntu 中對磁盤使用情況進行分析。為了確保系統的健康，運行的流暢，時常關心機器的硬盤，適當的運行一些分析是非常重要的，當然，運行這些分析是很容易的。為了完成分析，我們將使用一款非常棒的圖形工具，名叫Baobab。

在下一步操作之前，我可以告訴你們，它的使用非常簡單，功能齊全，我確定它能夠滿足你的需求。Baobab 是 gnome-utils 的一部分，但是自從Gnome3.4版本後，已經作為獨立應用。通過使用這個磁盤分析工具，你可以輕鬆掃描文件夾，文件系統，不單是本地，遠程目錄一樣可以輕鬆分析。

只需輕輕點擊，便可以搞定一切！想要停止掃描？簡單，在 baobab 用户界面的頂部，輕點 Stop scanning 按鈕，完成。

我喜歡這個工具的簡單性並且可以圖形化表示數據，像餅狀圖和樹形圖。那麼，現在你們在自己的機子上安裝使用如何呢？

據我所知，ubuntu已經默認安裝，如果沒有，打開一個新終端（CTRL+ALT+T）,然後運行下列命令來安裝它。

sudo apt-get install baobab

安裝完畢後，會分類至應用程序, 系統工具, 磁盤分析器，或者，直接使用下列命令，在終端中運行baobab。

baobab

下列圖片顯示了當它在你的機器運行時的界面。

如需掃描 Home 目錄，點擊 Scan Home 或者 Analyzer->Scan Home Folder 選項。完成掃描後，工具會做很多分析，耐心等待分析結果吧！

正如上圖所見，baobab 掃描結果提供給我們很多信息，包括 Home 目錄中每一個文件夾的使用情況、大小，以及所擁有文件數。右邊有一個餅狀示意圖。如果你喜歡，選擇上方的 View as Treemap Chart，你可以輕鬆地把它換成樹狀圖。

下圖顯示的是，選擇樹狀圖代替默認的餅狀圖的界面。

如需掃描文件系統，選擇 Analyzer->Scan Filesystem ,如果你懶得去點擊這些，有一個簡單方法，快捷鍵CTRL+F。

選擇你喜歡的方式，兩個方法都會起效並做同樣的掃描。快捷鍵的確易用省時，但是如果不是天天用這個工具，也很難同時記住所有快捷鍵。

如何掃描文件夾？簡單！Analyzer-> Scan A Folder -> 選擇你想要掃描的文件夾，快捷鍵是 CTRL+O 。是不是非常簡單？是的！看見 Scan a Folder 按鈕了嗎？點擊它掃描就開始了！

下圖顯示了掃描完 python-nmap-0.1.4 後的結果。我用簡單的方法得到了有用的信息列表。

你已經學會了如何掃描 Home 目錄、文件系統和指定文件夾。有一個重要的功能，我還沒有告訴你，但我確定你一定可以自己學會。是不是有遠程文件夾需要掃描？好好發揮一下腦力吧！
