5個需要更多關愛的Linux發行版 ​

就像我以前在文章裏寫的, Linux 無處不在，所以即使沒有數千種，也有數百種之多的發行版。有一些發行版非常有名，其中一些擁有上千萬的用户基礎，而有一些卻只能生活在這些光輝閃耀的發行版的陰影之中。有一些發行版在大的發行版輕鬆享受的影響力的連接處掙扎求存，同時每年都有一些觸手可及的發行版滅亡。但是我們今天在這裏討論幾個還沒有得到他們應得的關愛的發行版。不論這個發行版是原始的或分支或基於其他的發行版的，如果它工作起來對於日常使用是足夠穩定的，同時沒有得到應得的關愛，它就可以放到這個列表中。

5. Rosa ​

ROSA Desktop, 是一個擁有高度定製性的KDE桌面發行版，它有大量來自 ROSA 的改動旨在加強工作環境開發的用户友好性。ROSA是一家俄國公司，他還提供了一個基於紅帽的企業版的企業服務器版ROSA給開發者。這是你在網上能找到的最具有定製性的發行版之一，它擁有大量的的家用特性，像一個完全重新設計的登錄窗口，一個叫做“TimeFrame”的日程管理軟件，大量改動的“Dolhpin”文件管理器，Rocket Bar，Simple Welcome，Rosa Media Player和很多其他的軟件。

4. Korora ​

Korora 是基於讓 Linux新手用起來更容易，但同時也是一個對專家很有用的願景而產生的系統。最初是2005年基於Gentoo Linux 的系統 ，korora在2010年作為一個Fedora 的混音版重新出世，它搭載 tweaks和一些額外的功能以使系統可以開箱即用。korora擁有一個融合的Fedora + RPM Fusion+ korora的包系統。其中korora提供尖端和一個紅帽發行版的穩定，讓它可以毫不費力的實現開箱即用。許多人抱怨Fedora太麻煩，但是 Fedora就是這樣設計的啊。對於喜歡 Fedora 同時仍希望可以開箱即用的人們，korora就是為你準備的。

3. Chakra Linux ​

如果你是KDE的鐵桿粉絲而且你無法忍受長達幾個月的等待時間才能用上最新的軟件，那麼你有一款天堂般的選擇，他們管它叫Chakra Linux。這個發行版最初是Arch Linux的一個分支，但是現在已經是一個獨立的發行版了，它擁有自己的倉庫、包、內核和半/滾動發佈週期。

Chakra Linux 工作性能很好而且擁有Arch Linux的所有優點。有些人可能爭論為什麼不直接用Arch Linux，然後用KDE代替 Chakra Linux。首先是安裝過程，無論每個人如何證明你自己裝起來多容易，事實上並非如此。一個OS應該很容易使用同時安裝起來更容易，而不是別的樣。

Chakra Linux 是很少的一個可以獲得的、真正的KDE發行版，因此可以保證你可以擁有到最好的KDE體驗在你使用 Chakra Linux的時候。

2. Ubuntu Gnome ​

Ubuntu 可能是近些年頗受關注和爭論的一個版本，尤其是轉到 Unity 的決定，但是我個人對 Unity 感覺很好。另一方面，我在裝 Nivida的時候它的錯誤是如此的多，而且我經常看到有人抱怨 Unity 糟糕的表現。還有其他的半官方的的版本可以選擇但是沒有一個真的很像Ubuntu的體驗，直到Ubuntu Gnome 出現。

關於這個不需要説太多, Ubuntu Gnome 就是一個披着 Gnome Shell 外殼的 Ubuntu, （“之所以列出來是因為”）我覺得它應該在名單上。Ubuntu 曾經因為 Canonical 極少犯錯誤而風靡一時，這個發行版也不該太慘。我可以很高興的告訴你，你可以從 Ubuntu Gnome 中感受到原始的 Ubuntu 的每一項優點同時避開 Canonical 的那些粗魯的暴力措施。

1. Sabayon Linux ​

Sabayon Linux 是一個基於 Gentoo 的發行版的、遵循開箱即用的哲學，而且它做的很踏實一步都沒有跳過。這聽起來有點偏，但 Sabayon 在大量的系統中是極少數的真正可以開箱即用的發行版 。

Sabayon 遵循不説廢話的哲學，一切按它應該是的方式運行，你不需要關心終端是否把事情做好了，你不需要添加額外的庫增加最明顯的功能，一切都在它應該在的地方，順道説一下，如果你願意你可以做，但問題是你不能強迫用户做所有的這些事情。如果我想用Arch Linux但是不想用終端使我痛苦的撞頭，我就應該能做到。

Sabayon 是一個尖端的，快速的和令人驚訝的穩定發行版，歸功於堅實的Gentoo的核心。它讓你選擇的桌面環境很容易使用，安裝更方便，開箱即用，擁有一個很簡單的功能和很強大的包管理器，配備所需的大部分應用程序，然後它仍然可以被深度定製，就像任何其他的分佈。
