2021 總結：Linux 方面的 10 篇好文章 ​

以下是 10 篇最受歡迎的 Linux 文章。

2021 年，我們發表了遠超 150 篇的 Linux 方面的文章。從桌面 Linux 用户小工具的文章到將 Linux 作為服務器操作系統的教程，以及介乎於兩者之間的各種場景，這些文章已經涵蓋了 Linux 生態系統的許多方面。所有這些文章都值得你花時間去閲讀，但你可以從今年發表的這十篇好文章開始閲讀。

3 個開源工具，使 Linux 成為理想的工作站 ​

在這篇文章中，Seth Kenlon 介紹了 LibreOffice、AbiWord、Gnumeric 和 Pandoc，涵蓋了 使 Linux 成為理想工作站的工具。他解釋了在使用 Linux 作為桌面操作系統時，這些應用程序如何使你的工作效率提高。文章探討了一些高級功能，如 LibreOffice 的無頭模式，並提供瞭如何充分利用每個應用程序的小技巧。

為什麼我在 Linux 上使用 exa 而不是 ls ​

ls 命令是 Linux 中最常用的終端命令之一，但你知道它有一個現代的替代品，提供了許多有益的改進嗎？Sudeshna Sur 的 文章 介紹了 exa 命令以及它相比 ls 的優勢，討論了 exa 如何跟蹤添加到 Git 倉庫的新文件、顯示目錄和文件樹等等。

我喜歡在 Linux 上編碼的 5 個原因 ​

像許多人一樣，Seth Kenlon 喜歡在 Linux 上編碼。在這篇文章中，他分享了這樣做的 五個原因。他喜歡在 Linux 上編碼，因為它建立在邏輯的基礎上，可以讓你欣賞代碼之間的關聯，提供了源代碼，並提供直接訪問外設和抽象層的能力，使編寫代碼更容易。

在 Linux 上使用可啓動的 USB 驅動器來拯救 Windows 用户 ​

即使你喜歡 Linux，但有時你可能需要修復一台 Windows 電腦或為某人安裝 Windows。在 Linux 上從 Windows ISO 創建一個可啓動的 U 盤，並不像為 Linux 發行版製作一個可啓動的 U 盤那樣簡單明瞭。在這個教程中，Don Watkins 演示了 如何使用 WoeUSB，這個工具可以為用户處理這個過程中所有棘手的部分。

4 個用於運行 Linux 服務器的開源工具 ​

當使用 Linux 作為服務器操作系統時，Seth Kenlon 推薦了這 四個開源工具： Samba、Snapdrop、VLC 和 PulseAudio。正如 Seth 在他的文章中所指出的，這四個工具使得用 Linux 進行文件共享和流媒體變得很容易。

3 個你需要嘗試的 Linux 終端 ​

Linux 有許多不同的終端模擬器。Seth Kenlon 的這篇文章推薦了 3 個 Linux 終端，值得一試：Xfce 終端、rxvt-unicode 和 Konsole。他提供了每一個的簡要概述，並指出了每個終端模擬器的優勢。

在你的 Linux 家庭實驗室中運行 Kubernetes 的另外 5 個理由 ​

在 Seth Kenlon 2020 年的文章《在樹莓派家庭實驗室上運行 Kubernetes 的五個理由》的續篇中，他給出了 在 Linux 家庭實驗室中運行 Kubernetes 的另外五個理由：Kubernetes 建立在Linux 的基礎上，它很靈活，學習它可以為你提供個人發展，它使容器變得有意義，而且它有利於雲原生開發。他還提供了一個額外的理由：因為它很有趣。

6 個開源工具和技巧，為初學者保障 Linux 服務器的安全 ​

Sahana Sreeram 提供了 保證 Linux 服務器安全的六個優秀技巧。這個教程着眼於更新軟件、啓用防火牆、加強密碼保護、禁用非必要的服務、檢查監聽端口，以及掃描惡意軟件。Sahana 提供的技巧可以幫助 Linux 初學者學習保持 Linux 服務器安全的基本知識。

Linux 如何使一所學校為大流行病做好準備 ​

Don Watkins 採訪了威斯康星州莫諾納市 聖心瑪利亞學校 的教師 Robert Maynord，介紹了該校 將他們的電腦換成 Linux 的情況。Maynord 分享了關於他是如何對 Linux 感興趣的軼事，他為把學校的計算機換成 Linux 所採取的第一個步驟，Linux 如何使學校受益等等。Don 在這次採訪中提出了許多很好的問題，Maynord 為有意採用 Linux 的學校提供了許多有用的信息。

在 Linux 上運行你喜歡的 Windows 應用程序 ​

有時，在切換到 Linux 之後，你仍然需要那個只在 Windows 下運行的特定應用程序，或者真的想玩那個只能在 Windows 下運行的遊戲。在這篇文章中，Seth Kenlon 提供了一個關於如何 在 Linux 上運行你喜歡的 Windows 應用程序 的教程。做到這一點的工具是 WINE。Seth 解釋了什麼是 WINE，它是如何工作的，以及如何在你的 Linux 計算機上安裝它，以便你可以運行你最喜歡的 Windows 應用程序。
