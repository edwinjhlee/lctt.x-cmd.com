2021 年我最喜歡的五個 Linux 應用程序 ​

這些應用程序可能不是絕對的必需品，但我很高興在 2021 年發現了它們。

在這個 2021 年，我目睹了數百個有趣的 Linux 應用程序的開發取得了進展，並因此獲得了更多用户。雖然其中一些已經止步，但其它的應用還在繼續發展，不斷地獲得更多的關注和新功能。

雖然我希望我可以對所有這些應用都有所瞭解，但顯然這是不可能的。不過，我已經挑選了 5 個我最喜歡的應用，並在這裏與你分享它們。它們可能不會被列入 必需的 Linux 應用程序名單，但我卻十分青睞它們。

在開始之前，應該注意的是，所有這些應用程序，除了 EverSticky 之外，都是融合性的，這意味着它們同樣適用於桌面和移動 Linux 設備。隨着 PinePhone 和 Librem 5 等設備變得越來越流行，我認為融合性應用是相當重要的，看到這麼多的此類應用正在開發中，真是太好了。

言歸正傳，讓我們來看看第一個應用程序。

Index ​

早在 2016 年，當 KDE 發佈 Kirigami 時，很明顯，它是 KDE 的應用程序的未來。不幸的是，將成千上萬的應用程序轉換到一個新的 UI 工具包是相當困難的，這導致了 KDE 應用程序之間嚴重的不一致。

五年後的今天，作為桌面級應用的 UI 工具包，我們終於看到 Kirigami 被真正重視起來，這在文件管理器 Index 中得到了完美的體現。這個漂亮的應用程序能成為 Plasma Mobile 和 Nitrix Linux 的默認文件管理器，自然有原因的。

雖然不像 KDE 的默認文件管理器 Dolphin 那樣功能豐富，但它有集成終端、文件預覽、標籤和分割視圖模式等功能。這使得它可以和 Gnome 的 Nautilus 相提並論，同時它還有融合性和基於 Kirigami 的明顯優勢。

自從發現了它，我就只用它了，甚至沒有想過要換回 Dolphin 或 Nautilus。我強烈推薦給任何想嘗試新文件管理器的人。

  • 獲取 Index

Vakzination ​

我相信大家都會這樣認為，過去的兩年是艱難的，但是在隧道的盡頭有一道光。隨着疫苗的推出，我們似乎終於接近了這場大流行病的終點。

不幸的是，這也意味着許多人不得不習慣於疫苗證書的概念，其中許多現在是數字證書。這對 Linux 用户來説可能是個問題，因為衞生部門很少有資源為 Linux 開發疫苗接種證書應用程序。

然而，這並沒有阻止一些社區成員致力於開發一個自由開源的替代方案，從而產生了 Vakzination。作為一個 KDE 應用程序，它使用 Kirigami 和 Qt Quick 創建了一個快速、現代和用户友好的疫苗接種證書應用程序，使用起來非常方便和快捷。

它目前支持以下證書格式：

  • 印度疫苗接種證書
  • 歐盟 “數字綠色證書”（DCG）疫苗接種、測試和康復證書

老實説，我覺得社區在這個應用程序上取得的成就相當不可思議，在此希望他們能儘快增加更多的格式支持。

  • 獲取 Vakzination

Elisa ​

Elisa 是另一個基於 Kirigami 的應用程序，是一個來自 KDE 的快速而漂亮的音樂播放器。它支持所有主要的音頻格式，並集成到 Baloo 文件索引器中，以確保你所有的音樂都被收錄。

Elisa 是一個由 KDE 社區開發的音樂播放器，努力做到簡單和好用。我們也認識到，我們需要一個靈活的產品來考慮用户的不同工作流程和使用情況。我們專注於與 KDE 社區的 Plasma 桌面進行良好整合，而不影響對其他平台（其他 Linux 桌面環境、Windows 和 Android）的支持。

據 Elisa 網站

總的來説，對於任何平台來説，它都是一個偉大的音樂播放器，對於 KDE Plasma 和 Plasma Mobile 用户來説更是如此。

  • 獲取 Elisa

Fractal ​

繼續看看 Gnome 應用程序，Fractal 已經迅速成為我最喜歡的信息應用。它使用了成熟的 Matrix 通信協議，並支持用户可能期望的現代消息應用程序的所有功能。

它有些值得注意的功能，如圖像和視頻預覽，以及對所有 Matrix 功能的支持。此外，它使用 LibHandy 庫，這意味着它可以在移動設備上完美地工作，如 PinePhone 和 Librem 5。

總的來説，我對這個應用程序非常滿意，因為它幾乎適合任何希望與朋友或家人交流的人。

  • 獲取 Fractal

EverSticky ​

到目前為止，EverSticky 是這個名單上最小的項目，它是一個類似於 Windows 11 的便籤應用Sticky Notes 的小型記事應用。與許多其他可用於 Linux 的便籤應用不同，EverSticky 有一個關鍵優勢，它能夠同步到印象筆記。

這意味着所有在 EverSticky 上做的筆記也會出現在任何其他登錄到印象筆記的設備上。為了幫助儘量減少用户界面混亂（用 Qt 構建），它利用了一個托盤圖標，類似於所有最近版本的 Windows 中的圖標。

從我的使用經驗來看，它工作得非常好，我的所有筆記都能在我的所有設備之間無縫同步。我強烈建議你自己嘗試一下。

  • 獲取 EverSticky

總的來説，我對 Linux 上的應用程序的未來感到興奮。隨着越來越多的人開始關注對開源項目的貢獻，我希望我們能得到更多像這樣不可思議的應用程序。
