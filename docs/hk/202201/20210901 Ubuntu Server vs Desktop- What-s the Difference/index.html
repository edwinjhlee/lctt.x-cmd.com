Ubuntu 服務器版與桌面版有什麼區別？ ​

當你點擊 Ubuntu 網站 上的下載按鈕時，它會給你幾個選項。其中兩個分別是 Ubuntu 桌面版和 Ubuntu 服務器版。

這可能會讓新用户感到困惑。為什麼會有兩個（實際上是四個）？應該下載哪一個？Ubuntu 桌面版還是服務器版？它們是一樣的嗎？有什麼區別？

我將解釋 Ubuntu 的桌面版和服務器版的區別。我還會解釋你應該使用哪個變體。

Ubuntu 桌面版與 Ubuntu 服務器版 ​

要了解 Ubuntu 桌面版和服務器版的區別，你應該瞭解桌面操作系統和服務器操作系統的區別。

桌面操作系統 ​

桌面電腦Desktop是指個人電腦（PC）。桌面電腦操作系統帶有一個圖形用户界面，以便用户可以使用鼠標和鍵盤操作。桌面電腦的主要目的是給你一個系統，可以用來瀏覽網頁、編輯文檔、查看/編輯圖片和視頻、編碼和遊戲。基本上，就是為個人、終端用户或家庭成員提供了一個通用的計算機。

我在這裏使用桌面電腦這個術語，但這並不意味着它不能用於筆記本電腦。桌面電腦是個人電腦的通用術語。

服務器操作系統 ​

另一方面，服務器操作系統是專門為託管網站、應用程序、媒體服務器、資料庫等網絡服務而打造的。

通常情況下，服務器操作系統不帶有圖形界面。如果是基於 Linux 的操作系統，你就得通過終端的命令來使用該系統。

這裏的好處是，服務器操作系統不需要（浪費）大量的內存和計算能力，因為它們不使用 圖形化桌面環境。除此以外，服務器操作系統的軟件包配置也不同。

現在你對服務器和桌面的區別有了一些瞭解，讓我們看看 Ubuntu 服務器版和桌面版的區別。

用户界面 ​

Ubuntu 服務器版和桌面版之間最明顯的區別是用户界面。

Ubuntu 桌面版的特點是採用 GNOME 桌面環境的圖形化用户界面。這使得它在鼠標點擊的幫助下更容易使用。

Ubuntu 服務器版採用無頭方式headless運行。你只有在登錄後才會看到一個終端界面。你經常會從其他電腦上通過 SSH 來遠程管理它。

安裝 ​

由於有了圖形化的安裝程序，將 Ubuntu 作為桌面電腦是很容易的。你可以創建一個臨場 USBLive USB，無需安裝即可體驗桌面版。如果你喜歡，你可以按照屏幕上的指示在幾分鐘內安裝它。

將 Ubuntu 作為服務器安裝並不像桌面版那樣簡單。你只能使用終端界面。如果你不熟悉這個流程，即使是最簡單的任務，如連接到 Wi-Fi，也可能是一個困難的任務。

應用程序 ​

在 Ubuntu 桌面版中，默認的應用程序集主要針對普通計算機用户。因此，你會發現網頁瀏覽器、辦公套件、媒體播放器、遊戲等。

Ubuntu 服務器版的應用程序更多的是為運行網絡服務而定製的。而這還不是全部。有些應用程序的配置也是不同的。以 SSH 為例。Ubuntu 服務器預設了 SSH，這樣你就可以輕鬆地從遠程系統連接到它。而在 Ubuntu 桌面版上，你必須明確啓用 SSH 才行。

硬件要求 ​

由於桌面版具有圖形用户界面，你需要至少 4GB 的內存來運行 Ubuntu 桌面版。磁盤空間至少要有 20GB。

這就是 Ubuntu 服務器的有趣之處。它沒有圖形化的界面。命令列界面不會消耗大量的系統資源。因此，你可以在 512MB 和 5GB 磁盤空間的機器上輕鬆運行 Ubuntu 服務器。（LCTT 譯註：當然，對於服務器環境來説，內存和磁盤空間是多多益善。）

服務器上的內存和磁盤空間受制於你所運行的網絡服務。如果一個網絡應用需要至少 2GB 的內存，你就應該有這麼多的內存。但在最簡單的情況下，即使是 512MB 或 1GB 的內存也可以工作。

用途 ​

這是 Ubuntu 桌面版和服務器版之間的主要區別。問問自己，你想把 Ubuntu 用於什麼目的？

如果是專門用於部署網絡服務，那就選擇 Ubuntu 服務器。請記住，你需要有基本的 Linux 命令列知識來使用終端。

如果你想把 Ubuntu 作為像 Windows 一樣的普通電腦使用，那就選擇 Ubuntu 桌面版。如果你想用它來學習 Linux 命令，或用於學習的 Docker 或者甚至是簡單的（但是本地的）LAMP 服務器環境，請繼續使用 Ubuntu 桌面。

對於服務器來説，Ubuntu 服務器版要比 Ubuntu 桌面版好。對於常規的計算機使用，Ubuntu 桌面版是更好的選擇。

你應該在服務器上使用 Ubuntu 桌面版還是在服務器上安裝圖形界面？ ​

是這樣的，Ubuntu 桌面版和服務器版都是 Linux，你可以用 Ubuntu 桌面版作為服務器來託管網頁服務。這沒問題。

同樣地，你可以在 Ubuntu 服務器上安裝圖形界面，並以圖形方式使用它。這也是可行的。

但僅僅因為它可行，並不意味着你應該這麼做。它違背了為服務器和桌面電腦創建不同版本的全部目的。

你必須付出額外的努力來將服務器版轉換為桌面版，反之亦然。為什麼要承受這種痛苦呢？

如果你使用 Ubuntu 的目的很明確，那就下載並安裝合適的 Ubuntu 版本。

我希望這能使圍繞 Ubuntu 桌面版和服務器版的選擇現在更清楚一些。如果你有問題或建議，請利用評論區。
