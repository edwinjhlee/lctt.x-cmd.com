我希望在 GNOME 中看到的 5 個微小而有用的功能 ​

我知道對於聖誕願望清單來説已經太晚了，但我仍然想分享我希望在 GNOME 中看到的東西。

GNOME 是許多 Linux 發行版的默認桌面環境。它也是我最喜歡的一個，因為它提供了一種現代的桌面體驗。

但這並不意味着 GNOME 是完美的，不需要改進。事實上，這裏有幾個建議可以改善整個用户體驗。

1、方便的應用程序卸載選項 ​

桌面 Linux 是碎片化的。為了增加混亂，連軟件包也是零零散散的。而最糟糕的是當你從系統中刪除一個應用程序時。

舉個例子，你要通過 DEB 包安裝一個應用程序，並使用 GNOME 軟件中心界面來安裝它。

但如果你不喜歡這個應用程序，想把它刪除呢？

你不會在軟件中心中找到該應用程序。相反，你得必須使用命令列的方法。

這還沒完。還有 Snap 和 Flatpak 軟件包。如果你已經使用了其中之一，你必須先找出來，然後使用正確的命令才行。

GNOME 採用了類似於 Android/iOS 的方法，將應用程序顯示在一個網格中，並將它們組織在文件夾中。移動操作系統為用户提供了一種方式，即按住圖標並刪除應用程序。如果能有一個類似的選項，右鍵點擊應用程序圖標並選擇卸載，那就更好了。

這樣，終端用户就不用管所安裝的應用程序是 Deb 包還是 Snap 包。沒有必要為此進入終端，而且它就發生在訪問應用程序地方，這不是挺好嗎？

Linux Mint Cinnamon 版有這樣的功能，你在菜單中右鍵點擊一個應用程序條目，選擇刪除它。

如果 Cinnamon 能做到，GNOME 應該也能做到，對嗎？

2、在應用程序商店中設置默認軟件源 ​

如果一個應用程序有多種格式，GNOME 軟件中心可以讓你選擇軟件源。至少這是我在 Fedora 的 GNOME 軟件中看到的，但在 Ubuntu 中沒有。

假設有人在軟件中心同時添加了 Flatpak 和 Snap 支持，而一個應用程序在 Flatpak、Snap 和軟件包管理器（apt、DNF 等）中都可用，它可能會在搜索結果中顯示多次。

如果能夠設置一個默認的打包格式，使其優先於其他格式，那就更好了。如果你把 Flatpak 作為默認，它就不會顯示 Snap 版本，默認只安裝 Flatpak 版本。

3、跨系統同步安裝的應用程序 ​

這一點可能取決於發行版情況，從技術和策略的角度看都比較複雜。

安卓、iOS、macOS 和 Windows 都有這個功能，這樣可以更容易開始使用新設備或重置的同一設備。你從他們的官方應用程序商店安裝的應用程序與你的個人資料相關聯。你重新安裝/重置操作系統，或者在一個新系統上，登錄應用程序商店，它就會顯示你以前使用過的應用程序。

在 Linux 上，如果你由於某種原因重新安裝系統，你就會失去你所安裝的應用程序。當然，你可以重新安裝它們，但你也必須回憶起你以前安裝的應用程序。

我記得 Ubuntu 曾經有個 Ubuntu One 雲，我以為他們會推出這個功能，但他們關閉了這個雲服務。然而，Ubuntu One 仍然活着，並被用作 SSO 登錄。事實上，你可以在 Ubuntu 軟件中心看到 Ubuntu One 的登錄選項，但它並沒有做任何事情。

知道你之前從 GNOME 軟件中心安裝了哪些軟件，將使電腦的格式化和在電腦之間的移動更加容易。你不覺得嗎？

當然，許多 Linux 用户不一定依靠軟件中心來獲取應用程序，但這對一些人來説可能是一個有用的功能。

4、面部解鎖和/或指紋登錄 ​

我喜歡用密碼登錄並解鎖 Windows 的方式。是的，我偶爾會使用 Windows。不，不是用來玩遊戲，而是用超高清觀看流媒體內容。過去幾周我用得比較頻繁，因為我在另一個城市，我必須依靠我的筆記本電腦來觀看 4K 的 Netflix，而不是使用我的電視。

輸入整個 8 到 10 個字符的長密碼，加上特殊字符，總覺得是件麻煩事。值得慶幸的是，我的筆記本電腦有一個指紋識別器，但不是每個人都有這種奢侈。

對於許多已經習慣於在移動設備上使用這些方法的用户來説，使用指紋或面部來解鎖設備可能會很好。

已經有一些項目允許你在 Linux 上使用面部解鎖，GNOME 確實可以考慮將其加入到其產品中。

5、帶回“添加新文檔”選項 ​

幾年前，GNOME 刪除了從右鍵菜單中創建一個新文檔的功能。

現在仍然可以實現這個功能。你必須先在你的主目錄的 Templates 文件夾中創建一個模板文檔。然後所有的模板文檔都可以在右鍵菜單中找到。

但這本應是一個默認功能。人們不應該胡亂擺弄而試圖找出“創建新文檔”選項的去處。

現在是時候讓 GNOME 恢復這個功能了。

你希望在 GNOME 中看到什麼功能？ ​

由於我主要使用 Ubuntu，它的定製 GNOME 與原生 GNOME 不同。原生 GNOME 也應該把小程序指示器帶回來，這樣像 Dropbox 等應用程序就可以快速訪問。

GNOME 開發者不太可能關注像我們這樣的普通 Linux 用户的想法，但我還是要問問你怎麼看。

你希望在 GNOME 或桌面 Linux 中看到什麼新功能？你也可以分享一些你最喜歡的、已經從 GNOME 中刪除的，但你希望它們能重新出現的功能。
