OpenBoard：面向教育工作者的開源交互式白板 ​

OpenBoard 是為中小學和大學定製的交互式開源白板。讓我們來看看它提供了什麼。

有幾個可用於教育的開源工具，但是，並非所有這些面向中小學和大學的軟件都能達到商業軟件級的良好維護。

OpenBoard 就是這樣一個不同凡響的自由開源工具，它可以不打折扣地為教育服務。它是一個交互式白板程序，具有所有基本功能，並支持各種硬件。

OpenBoard：自由及開源的交互式白板 ​

作為一個自由開源的程序，OpenBoard 看起來是一個令人印象深刻的選擇。

瑞士日內瓦州的教育部門（DIP）與 GitHub 上的社區一起維護該工具。

通過交互式白板促進簡單的數字教學不應該花費很多，這就是 OpenBoard 的優勢所在。

它提供的一系列功能對大多數中小學和大學來説應該是足夠的。

雖然我無法在中小學/大學環境中測試它，但我會重點介紹它提供的主要功能。

OpenBoard 的特點 ​

交互式白板沒有眾多花哨的功能，但足以使教師能夠儘可能輕鬆地表達自己。

我注意到的一些特點包括：

  • 跨平台支持
  • 能夠自由地寫寫畫畫
  • 能夠添加註釋
  • 能夠刪除註釋
  • 可以使用熒光筆高亮顯示你的白板的部分區域
  • 單獨互動和移動創建/繪製的項目
  • 按順序添加多個頁面，可以繼續教學而不需要擦除
  • 能夠在頁面間滾動瀏覽
  • 繪製線條（從三種不同線寬中選擇）
  • 切換手寫筆模式（如果你使用的是手寫板或類似的東西）
  • 輕鬆擦除在白板上創建的項目
  • 可以從一組不同的背景中選擇，包括把它變成黑板或帶網格線的背景
  • 各種必要的應用，包括計算器、地圖、尺子等，都可以通過拖放使用
  • 提供的一些形狀，可以使繪圖更容易
  • 能夠向你的白板添加音頻/視頻，並無縫播放，以獲得更好的體驗
  • 虛擬激光筆
  • 可放大和縮小
  • 書寫文字，調整大小，並克隆它
  • 從白板中對屏幕進行截圖
  • 需要時可使用虛擬鍵盤

在我簡短的測試中，用户界面和可用的選項工作得非常好，沒有任何故障。

當然，你的體驗將取決於設備的類型和你的設置。你可以用 Wacom 平板、雙顯示器設置，或者通過支持觸摸的筆記本電腦使用投影儀來嘗試。

在 Linux 中安裝 OpenBoard ​

更好的是，它可以在多個平台上使用，包括 Windows、macOS 和 Linux。

如果你使用的是 Ubuntu，你可以到官方網站下載 DEB 文件。另外對於其他 Linux 發行版，你可以選擇通過 Flathub 安裝 Flatpak 軟件包。

  • OpenBoard

結語 ​

總的來説，我發現它在使用和導航方面毫不費力。你可以在多個頁面之間快速切換，無縫擦除/添加項目，同時還可以在白板上添加豐富的元素。

通過虛擬激光筆以及一些應用，使得它適合在各種中小學和大學中使用而沒有任何障礙。

我不知道它是否可以被稱為谷歌課堂或 Miro 白板功能的替代品，但對於更簡單的使用，OpenBoard 可以勝任。
