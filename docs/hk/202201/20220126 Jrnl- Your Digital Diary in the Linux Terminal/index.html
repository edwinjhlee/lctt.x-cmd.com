Jrnl：你的 Linux 終端數字日記 ​

想像一下：有人傷了你的心，而你想要的是心無旁騖地在日記中寫下你的感受。你明白這種感受嗎？沒有嗎？我也不知道。我沒有心碎過（或者也許我心碎了，但我不想告訴你）。

但我還是想向你展示一個奇妙的極簡的開源的記事應用來保存日記。

這個方便的小程序是 Jrnl，它可以讓你在終端中直接創建、搜索和查看日記條目。

用 Jrnl 創建新的筆記就像下面一樣簡單：

jrnl yesterday: I read an amazing article on It’s FOSS. I learn about a minimalist app called Jrnl, I should try it.

看起來很簡單，不是嗎？關鍵字 “yesterday” 在這裏是一個觸發器，它把你的筆記保存到昨天的日期。記住，它被稱為 Jrnl（日記）是有原因的。它的主要目的是保存日記。

如果你喜歡把你的想法寫成日記，或者只是想嘗試一下，讓我分享一下安裝和使用的一些細節。

在你的 Linux 系統上安裝和使用 Jnrl ​

Jrnl 可以用 pipx 或 Homebrew 包管理器安裝。

我在測試中使用了 Homebrew，所以我將列出這些步驟。首先獲取 Homebrew：

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

這就好了！如果你需要更多的信息，我們有一個關於 在 Linux 上安裝 Homebrew 的詳細教程。

當你安裝了 Homebrew 包管理器後，用它來安裝 Jrnl：

brew install jrnl

安裝後，只要初始化 jrnl 並開始寫你的隨機想法。

你還記得本文開頭的第一個例子嗎？讓我們再來看看它吧！

jrnl yesterday: I read an amazing article in It’s FOSS. I learn about a minimalist app called Jrnl, I should try it.

在這一行中，我用命令 jrnl 在一個時間戳旁啓動程序，在這個例子中是 yesterday。我寫了一個冒號 :，表示我將開始寫一些東西，在第一個句子標記 .?!:（在這裏是句號 .）之前包含的所有內容將是標題。最後，這個句號旁邊的所有內容將被視為文件的主體。

目前，Jnrl 有兩種模式：撰寫和查看；前面的步驟用於撰寫條目，但如果你想查看，例如，之前寫過的條目，語法也很簡單，你只需輸入下一行。

jrnl -on yesterday

認為有人可能會閲讀你的日記和想法？你也可以對你的條目進行加密。

這就好了！ 當然，Jrnl 還有很多功能，你可以通過下面這行輕鬆找到：

jrnl --help

你也可以參考 其官方網站 上的文檔。記住，在這樣的一個開源項目中，文檔是你最好的朋友。享受它吧！

總結 ​

當然，Jrnl 並不適合所有人。大多數命令列工具都不適合。但如果你在終端中生活和呼吸，並喜歡記錄你的想法，它就適合你。

請不要忘記在評論中與我們分享你的個人經驗，或者更好的是，如果你想讓更多的人瞭解這個項目，你可以在各個社區和論壇上分享這個帖子。
