扫码关注官方微信公众号获取开源软件和 x-cmd 的最新用法与独家资讯

2021 總結：經營小型企業的開源工具 ​

這些文章顯示了開源作為工具、平台或集成點在商業中的力量。

今年，我們刊登了幾篇關注商業中的開源的好文章。這些文章展示了開源作為工具、平台或集成點在商業中的力量。讓我們回顧一下 2021 年的一些頂級開源商業故事。

《我最喜歡的開源項目管理工具》 ​

如果你在辦公環境中管理過項目，你很可能使用微軟 Project 來跟蹤任務和分配。然而，開源社區已經創造了許多跟蹤項目的選項。對於你的 項目管理需求，Frank Bergmann 寫了關於使用 Redmine、project-open、ProjectLibre、GanttProject、TaskJuggler 和 ProjeQtOr。

《使用 Apache Superset 進行開源商業智能報告》 ​

通過商業智能，你可以通過對數據進行分類、安排結果和顯示上下文信息來更好地瞭解你的信息。對於任何想要做出“數據驅動”決策的組織來説，商業智能（BI）是一項關鍵技術。Maxime Beauchemin 的文章討論了 Apache Superset，以及它如何成熟地成為一個領先的開源 BI 解決方案。

《6 個用於餐館和零售商的 WordPress 插件》 ​

這場大流行病可能永久性地改變了許多人喜歡做生意的方式。餐館和其他當地的零售機構不能再像以前那樣依賴上門交易了。網上訂購食品和其他物品已經成為一種常態和期望。當大流行結束後，消費者不太可能背棄電子商務的便利。Don Watkins 寫了 六個開源插件，幫助你創建一個 WordPress 網站，滿足你的客户對網上購物、路邊取貨和送貨的偏好。它還可以建立你的品牌和你的客户羣。

《試試 Chatwoot，一個開源的客户關係平台》 ​

在任何有面向客户的業務中，保持與客户的互動是至關重要的。我們最後一次接觸這個客户是什麼時候，或者他們最後一次接觸我們是什麼時候？我們的組織中誰做了回應？什麼服務水平協議制約着這種關係？這些和其他問題最好在客户關係管理系統（CRM）中進行管理。Nitish Tiwari 介紹了 Chatwoot，一個用 Ruby 和 Vue.js 構建的開源客户關係平台。Chatwoot 是從零開始寫的，目的是讓客户關係團隊建立端到端的票據管理和支持平台。本文將介紹 Chatwoot 的架構、安裝和主要功能。

《試試 Dolibarr，一個開源的客户關係管理平台》 ​

無論你是經營零售店、餐廳、酒吧、超市、健身房還是其他業務，你都需要一個可靠的方式來與你的客户保持聯繫。畢竟，他們是客户，因為他們喜歡你做的事情，如果他們與你分享了他們的聯繫信息，他們想聽到更多關於你所提供的東西。Pradeep Vijayakumar 介紹了 Dolibarr 項目，一個開源的企業資源規劃（ERP）和客户關係管理（CRM）軟件。Dolibarr 提供了一整套 ERP 功能，包括銷售點（POS）、發票、存貨和庫存管理、銷售訂單、採購訂單和人力資源管理。

《微軟 Exchange 的一個開源替代品》 ​

多年來，微軟 Exchange 作為羣件環境的必然選擇。然而，在 2020 年末，一個奧地利的開源軟件開發商推出了 grommunio，它是一個羣件服務器和客户端，其外觀和感覺為 Exchange 和 Outlook 用户所熟悉。Markus Feilner 寫了關於 grommunio 如何在企業中取代 Exchange，成為羣件的一個強大而功能齊全的選擇。

《用這個開源工具簡化發票的指南》 ​

許多 IT 項目在開發過程中會延遲、超出預算，並出現巨大的變化。這些問題使開具發票成為 IT 領域最費力的活動之一。Frank Bergmann 寫了一篇關於開源項目如何 簡化開票過程 的文章。如果你決定成為自僱人士或成立一個創業公司，Frank 的文章也可以作為處理財務工作的指南。

開源是好生意 ​

開源軟件不僅僅是為開發者服務的。企業也可以利用開源軟件的力量。事實上，開源是許多商業領域的一個主要驅動力。你今天使用的工具可能本身就是開源軟件，或者使用開源作為堆棧的一部分。
