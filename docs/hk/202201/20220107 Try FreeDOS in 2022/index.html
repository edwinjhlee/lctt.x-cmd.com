2021 總結：嘗試 FreeDOS ​

為這個自由操作系統的新用户和老用户提供 15 種資源。

在整個上世紀 80 年代和 90 年代，DOS 是桌面之王。世界各地的程序員不滿足於 DOS 的專有版本，他們共同創建了一個名為 FreeDOS 的開源版本，該版本於 1994 年首次推出。FreeDOS 項目 在 2021 年及以後還在繼續發展。

我們發表了幾篇關於 FreeDOS 的文章，以幫助新用户開始使用 FreeDOS 和學習新程序。以下是去年我們最受歡迎的幾篇 FreeDOS 文章。

初學 FreeDOS ​

你是 FreeDOS 的新手嗎？如果你想了解如何啓動和運行 FreeDOS 的基本知識，請查看這些文章：

  • 開始使用 FreeDOS：它看起來像復古計算時代，但 FreeDOS 是一個現代的操作系統，你可以用它來完成事情。
  • FreeDOS 如何啓動：瞭解你的計算機是如何引導和啓動 FreeDOS 的，從開機到命令列提示符。
  • 用純文本配置 FreeDOS：學習如何用 fdconfig.sys 文件來配置 FreeDOS。
  • 如何用 CD 和 DIR 瀏覽 FreeDOS：只需掌握兩個命令，DIR 和 CD，你就可以在命令列中瀏覽你的 FreeDOS 系統。
  • 在 FreeDOS 中設置和使用環境變量：環境變量在幾乎所有的命令列環境中都有用，包括 FreeDOS。

Linux 用户的 FreeDOS ​

如果你已經熟悉了 Linux 的命令列，你可能想試試這些在 FreeDOS 上創造類似環境的命令和程序：

  • 給 Linux 愛好者的 FreeDOS 命令：如果你已經熟悉了 Linux 的命令列，可以試試這些命令來幫助你輕鬆進入 FreeDOS。
  • 在 FreeDOS 中像 Emacs 一樣編輯文本：如果你已經熟悉了 GNU Emacs，你應該在 Freemacs 中感到很自在。
  • 在 Linux 和 FreeDOS 之間複製文件：學習如何在 FreeDOS 虛擬機和 Linux 桌面系統之間傳輸文件。
  • 如何在 FreeDOS 上歸檔文件：這是 FreeDOS 版本的 tar，在 DOS 上歸檔的標準方法是 Zip 和 Unzip。
  • 在 FreeDOS 上使用這個懷舊的文本編輯器：讓人聯想到 Linux ed(1)，當你想用老式的方法編輯文本時，Edlin 是一種樂趣。

使用 FreeDOS ​

當你啓動進入 FreeDOS，你可以使用這些很棒的工具和應用來完成工作或安裝其他軟件：

  • 如何使用 FreeDOS 的文本編輯器：FreeDOS 提供了一個用户友好的文本編輯器，叫做 FreeDOS Edit。
  • 在 FreeDOS 上聽音樂：Mplayer 是一個開源的媒體播放器，通常可以在 Linux、Windows、Mac 和 DOS 上找到。
  • 在 FreeDOS 上安裝和刪除軟件包：瞭解如何使用 FDIMPLES，即 FreeDOS 包管理器，在你的 FreeDOS 系統上安裝和刪除軟件包。
  • 為什麼我喜歡用 GW-BASIC 在 FreeDOS 上編程：BASIC 是我進入計算機編程的起點。我已經很多年沒有寫過 BASIC 代碼了，但我對 BASIC 和 GW-BASIC 永遠懷有好感。
  • 用 Bywater BASIC 在 FreeDOS 上編程：在你的 FreeDOS 系統上安裝 Bywater BASIC，並開始嘗試使用 BASIC 編程。

在其近 30 年的歷程中，FreeDOS 一直試圖成為一個現代 DOS。如果你想了解更多，你可以在 FreeDOS 簡史 中閲讀關於 FreeDOS 的起源和發展。另外，請看 Don Watkins 關於 FreeDOS 的採訪：一個大學生是如何創立一個自由和開源的操作系統。

如果你想嘗試 FreeDOS，請下載 2021 年 12 月發佈的 FreeDOS 1.3 RC5。這個版本有大量的新變化和改進，包括更新的內核和命令 shell，新的程序和遊戲，更好的國際支持，以及網絡支持。從 FreeDOS 網站下載 FreeDOS 1.3 RC5。
