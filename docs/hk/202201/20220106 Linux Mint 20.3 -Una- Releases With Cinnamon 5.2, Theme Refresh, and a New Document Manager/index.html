Linux Mint 20.3 “Una” 發佈 ​

Linux Mint 20.3 “Una” 有一些細微的視覺變化，彌補了現代外觀，以及新的應用改進。

代號為 “Una” 的 Linux Mint 20.3 終於來了。官方公告應該很快就會跟進，但它現在已經可以下載了！

雖然 Linux Mint 20.2 有一些令人印象深刻的改進，但 Linux Mint 20.3 看起來也是一個不錯的版本。

在這裏，我會重點指出 Linux Mint 20.3 的關鍵變化。

Linux Mint 20.3 的新變化 ​

在這個版本中，Linux Mint 20.3 包含了最新的 Cinnamon 5.2，一些細微的視覺變化，以及其他各種改進。

請注意，在 Xfce 和 MATE 版中的變化是一樣的（不包括桌面環境的具體改進）。

Cinnamon 5.2 桌面環境 ​

在 Cinnamon 5 中，增加了一些調整和管理桌面環境所消耗資源的功能。

這一次，升級的重點是幾個新功能。日曆小程序增強了功能，當你點擊系統時間/日期圖標時，可以直接從系統托盤上顯示事件。

如果你使用 GNOME 日曆或在線賬户（如 Google 日曆），這些事件應該是同步的。

除此以外，你還會發現 Nemo 文件管理器的改進和窗口動畫的細微變化。

還有一些必要的錯誤修復和總體上的小改進。

新的背景 ​

新的版本、新的壁紙，總是令人耳目一新。而且，Mint 20.3 也不會讓你失望。

你會得到一個精心策劃的美妙的壁紙集，你可以選擇使用。

視覺主題刷新及深色模式 ​

在 Linux Mint 20.3 中，主題已經進行了改造，對重點顏色輕微進行了重新處理（使其更時尚一些），並從一些小部件中刪除了它。

與窗口的圓角一起，這構成了一個更乾淨和現代的外觀。

總的來説，包括新的圖標，Linux Mint 20.3 帶來了一個新的主題包。

如果你想要同樣的外觀，同時保持其他的優點，你可以簡單地從倉庫安裝傳統主題包並應用它。

一旦你安裝了傳統主題包，就可以在選擇中找到它了。

不僅如此，你可以注意到，我更喜歡用深色模式的截圖來寫文章，因為 Linux Mint 20.3 終於把更多的注意力放在深色模式上！

一些默認的應用程序，如 Hypnotix、Gnome 終端、Celluloid，都是在啓用深色模式的情況下啓動的。如果你願意，你可以永久地禁用它們。

新的 Thingy 應用程序 ​

當 Clem（Linux Mint 的首席開發者）暗示會有一個新的驚喜應用時，我們 很快就在 Linux Mint 20.3 裏發現了它。

在穩定版更新之前，測試版就已經確認了它。

新的 Thingy 應用程序也被稱為 “Library”，它實際上是 Linux Mint 默認的文檔管理器。你可以下載電子書和其他 PDF 文件，Library 應用應該會自動從下載目錄中檢測到它。

應用程序的改進 ​

一些默認的應用程序，如 Hypnotix IPTV 播放器和便籤現在可以分別讓你搜索頻道或便籤。

其他改進 ​

其他一些改進有助於提高性能，更好地節省電力，以及更多。

考慮到它是基於 Ubuntu 20.04.3 的，帶有 Linux 內核 5.4 LTS。

你可以在官方公告帖子中找到更多關於這些變化的信息。

下載 Linux Mint 20.3 ​

你可以從官方主頁上下載 ISO。他們還沒有更新下載頁面，但你可以從他們的 Torrent 下載頁面 找到最新的 ISO。

如果你想要直接的下載鏈接，你可以看一下 全球鏡像 來獲得所有的 Linux Mint 版本。
