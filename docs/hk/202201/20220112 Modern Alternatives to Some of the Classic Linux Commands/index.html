一些經典 Linux 命令的現代替代品 ​

當你 開始學習 Linux 時，最初學習的是一套標準的 Linux 命令，這些命令從 UNIX 時代就已經存在了。隨着你作為一個 Linux 用户的年齡增長，你會不斷地掌握這套標準命令。

但是，這些標準的、傳統的命令是幾十年前創建的，雖然它們完成了預定的工作，但是它們的功能還可以改進，結構還可以簡化。

這就是為什麼存在 “替代” 工具，以加強傳統的 UNIX/Linux 命令。在這篇文章中，我將列出一些新的命令列工具，你可以用這些工具來代替舊式的經典 Linux 命令。

請注意，你不應該過分依賴這些替代品，特別是如果你管理（或計劃管理）許多 Linux 服務器時。傳統的 Linux 命令在所有的 Linux 發行版和 Linux 服務器上都可以找到。這些現代的替代方案很有可能在遠程服務器上無法使用。

在你的個人能力範圍內，你可以學習瞭解這些新的工具，以幫助你更有效率。

聽起來不錯？讓我們看看你是否能在這裏找到你下一個最喜歡的命令列工具。

HTTPie: wget 和 curl 的替代品 ​

在終端下載文件 時，wget 和 curl 是兩個最常用的工具。有趣的是，並不是所有的發行版都默認安裝了 curl 和 wget。

HTTPie（http）以一種更人性化的方式做同樣的工作。你會看到彩色的、格式化的輸出，這使得它更容易理解和調試。

蝙蝠：貓的替代品 ​

cat 命令可能是你最先學會的命令之一。它可以完成查看小型文本文件內容的工作。

但 bat 命令 更上一層樓，添加了語法高亮和 Git 集成等功能，並且還提供了分頁選項。

ncdu: du 命令的替代品 ​

Linux 中的 du 命令 用來檢查一個目錄的大小。這不是一個非常直觀的命令，當然它的默認輸出也不算非常好。

與此相比，ncdu 要好得多，它能及時提供相關信息。

它還有其他一些功能，比如用圖表顯示磁盤使用情況，對顯示進行排序，甚至可以交互式地刪除目錄。

它是基於 ncurses 的，因此 “nc” 這個前綴被加到 du 中。此外，還有一個類似的 CLI 工具：gdu，也是一個 du 的替代品，因為是使用 Go 編寫的，這使得它的性能得到了提升。

htop: top 命令的替代品 ​

top 命令是 Linux 終端中的任務管理器。它是一個查看運行進程和資源消耗的好工具，但是 理解和使用 top 命令 可能很複雜。

另一方面，htop 有一個漂亮的彩色輸出，並且界面比 top 命令更直觀。你可以垂直和水平滾動，以圖形方式配置顯示的信息。你可以在 htop 的輸出屏幕上交互式地殺死進程。

fd：find 命令的替代品 ​

find 命令是最強大和最常用的 Linux 命令之一。不能想像一個系統管理員可以不使用 find 命令就能生存下去。

但是，find 命令的結構奇怪，如果你進行大量的查找操作，它可能會很慢。

一個更好、更快的替代方案是 fd 命令。fd 是用 Rust 編寫的，它比其傳統的競爭對手更簡單、更快速。

exa：ls 命令的替代品 ​

exa 命令列工具不止可以列出目錄內容。它的默認設置更好，使用顏色來區分文件類型和元數據。exa 還可以顯示一個文件的擴展屬性，以及標準的文件系統信息，如 inode、塊數，以及文件的各種日期和時間。

你可以使用樹狀視圖來查看目錄結構。它也有內置的 Git 支持，可以看到哪些文件被修改、提交和暫存等。

duf：df 命令的替代品 ​

Linux 中的 df 命令 用來檢查磁盤空間。雖然它在大多數情況下都不錯，但一個更簡單、更好的替代方法是 duf，這是一個用 Go 編寫的工具。

它提供了一個所有掛載設備的概覽，這很容易理解。你還可以指定一個目錄/文件名並檢查該掛載點的可用空間。

通過 duf，你可以對輸出進行排序、列出 indoe 信息，甚至將輸出保存為 JSON 格式。

太長不讀：男人的替代品 ​

我知道對於純粹主義者來説，Linux 中的手冊頁 是不二之選。但是，手冊頁有時會過於詳細和複雜，難以閲讀和理解。

這就是 tldr 登場的時機。“TLDR” 是流行的互聯網行話，意思是“太長不讀to long didn't read”。這就是他們創建 tldr 的想法。如果你覺得手冊頁太長而不想閲讀，tldr 通過提供命令的實際例子而將其簡化了。

Neovim：Vim 的替代品 ​

我希望我在這裏沒有冒犯誰，但更好的 Vim 不是 Emacs，而是 Neovim。

幾年前，作為對傳統的 Vi 編輯器的改進，Vim 出現了。又是幾年過去了，Neovim 提出了將 Vim 擴展為一個 IDE 的想法。

它增加了現代終端的功能，如光標樣式、焦點事件、括號內粘貼等，並內置了一個終端模擬器。最重要的是，你不需要忘卻 Vim 的習慣就可以開始使用 Neovim。

你的選擇呢？ ​

再次強調，這些替代命令還不能完全替代原來的命令，特別是如果你管理許多 Linux 系統的話。你可能無法在所有的系統上找到並安裝它們。只有你可以完全控制你的 Linux 機器時，它們才是好東西。

除此以外，你是否在這個列表中找到了一些好的替代命令列工具？是哪一個呢？另外，你知道其他一些可以 “替代” 傳統 UNIX 命令的工具嗎？為什麼不在評論區與我們分享呢？
