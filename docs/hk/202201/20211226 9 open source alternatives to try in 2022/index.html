2021 總結：值得嘗試的 9 個開源替代品 ​

無論你在尋找什麼工具，都有大量的開源軟件的替代品供你選擇。

2021 年又是一個主要在網上度過的年份，但這對開源世界來説並不新鮮。在任何地方工作的能力是我們的 DNA，在大流行之前，遠程工作就已經進入了主流。

然而，今年在屏幕前的所有時間使我們的社區考慮開源的替代方案。無論你需要什麼樣的工具，許多流行的供應商都不是你唯一的選擇。

如果你對 Zoom 感到厭倦，想要一個非 Salesforce 家的 CRM，或者想要一個非谷歌的分析工具，請繼續閲讀。我們有推薦了 2021 年最受讀者喜愛的開源替代品的文章。

我最喜歡的開源項目管理工具 ​

如果你在管理一個項目，可能看起來你有無窮無盡的工具可以選擇。隨着甘特圖跨入敏捷領域，現在更常見的是看到它們被部署在大型項目的服務中。

如果你認為微軟 Project 是你唯一的選擇，別擔心，Frank Bergmann 分享了幾個 開源替代品，供單個用户計劃和跟蹤大型單一項目。Redmine、ProjectLibre 和 TaskJuggler 都是這個列表中涉及的開源替代品。

微軟 Exchange 的一個開源替代品 ​

微軟 Exchange 在羣件中的主導地位可能即將結束。2020年，一位奧地利的開源開發者建立了 grommunio，作為 Exchange 的開源替代品。

在 Markus Feilner 的 對 grommunio 的評論中，他分享了該工具提供的大量功能清單。集成的原生 exchange 協議使 Outlook 和智能手機能夠像連接到 Exchange 一樣連接到 grommunio。在這個強大的列表中，日曆管理、視頻會議和會議功能是由 Jitsi 提供的。

用這個開源的財務工具在 Linux 上管理你的預算 ​

當涉及到資金管理時，Linux 可能不是你想到的第一個工具平台。然而，事實證明，有許多建立在 Linux 上的應用可以幫助保持你的個人財務狀況良好。

像 HomeBank 和 KMyMoney 這樣的產品可以讓你從銀行導入數據，並根據你的預算審查支出。本文作者 Seth Kenlon 更喜歡 Skrooge，並分享了他如何使用它。如果你正在尋找一個追蹤支出的開源工具，這可能是一個。

5 個替代 Zoom 的開源工具 ​

在大流行的近兩年時間裏，可以説我們中的大多數人都被 Zoom 困住了。對我們中的許多人來説，大多數工作和社會活動都完全在網上進行。但正如 Seth Kenlon 敏鋭地指出的那樣，開源最大的好處之一就是可以遠程工作。因此，如果你對 Zoom 感到厭煩，開源愛好者有幾個選擇。

像 Jitsi 這樣受歡迎的名字也在這個名單上，還有一些令人驚訝的名字。例如，你知道 Signal 在其功能列表中增加了小組視頻通話嗎？P2p.chart、BigBlueButton 和 Wire 也進入了這個從小型團體電話到公司會議的各種視頻需求的工具列表。

用 Doodle 的開源替代品來安排約會 ​

像 Doodle 這樣的約會安排應用省去了很多挑選互不衝突日期的麻煩。對於像 Kevin Sonney 這樣主持播客的人來説，這些工具可以幫助他和每個客人輕鬆找到適合他們雙方的日期。

雖然 Doodle 贏得了大眾投票，但 Sonney 在這篇文章 分享了他使用 Easy!Appointments 的經驗。它旨在幫助服務機構，Easy!Appointments 有一個 WordPress 插件，讓用户把請求表格放在頁面或帖子上。該應用還與谷歌日曆同步，並有添加與其他後端同步的支持。

為什麼選擇 Plausible 作為谷歌分析的開源替代品 ​

如果你需要使用網絡分析，似乎谷歌分析是你唯一的選擇。Uku Taht 和 Marko Saric 在建立 Plausible.io 時，就着手改變這種情況，以提供一個開源的分析工具，可以管理大量的數據而不會出現性能下降。發佈兩年後，Plausible 每月可以抓取超過 8000 萬條記錄。

在這篇文章中，Ben Rometsch 分享了 Plausible 的歷程，從帶有敏感代碼的軟件到 AGPL 下的開源選擇。如果你想知道這個小小的分析引擎是如何在 GitHub 上從 500 顆星發展到 4300 顆星的，那麼這篇文章很值得一讀。

試試 Chatwoot，一個開源的客户關係平台 ​

想找一個涵蓋客服管理/支持的開源端到端平台？如果你想要 Salesforce 或 Zendesk 以外的東西，用 Ruby 和 Vue.js 構建的 Chatwoot 可能是一個可行的選擇。

Nitish Tiwari 在 這篇文章 中分享了 Chatwoot 的架構、安裝和主要功能。它可以在幾個平台上使用，包括 Linux 和 Docker。這篇文章分享了使用 Docker 的安裝過程，以及渠道和集成等功能。

開始使用開源的客户數據平台 ​

如果你正在管理大規模數據，你很可能使用或正在尋找一個數據倉庫。那些尋找開源倉庫的人可以考慮 RudderStack，它在數據倉庫上建立客户數據湖之前收集和路由事件流數據。

Amey Varangaonkar 分享瞭如何獲得 RudderStack 的工作空間令牌，然後在 Docker 或 Kubernetes 上安裝和部署。該工具的 rudder-server 倉庫和目標集成是開源的，讓用户看到該工具如何完成複雜的任務。在一個充滿風險的黑盒子時代，擁有這種透明度是一個很大的好處。

試試 Dolibarr，一個開源的客户關係管理平台 ​

你沒有看錯：這是另一篇關於客户關係管理的開源替代品的文章。Pradeep Vijayakumar 的這篇文章 涵蓋了 Dolibarr，它在擁有 CRM 功能的同時還擁有強大的 ERP 功能。

Vijayakumar 就在做 Dolibarr 開發工作，所以他對安裝它的 CRM、添加客户數據和設置活動的知識是非常豐富的。截圖顯示了每個過程的細節，並提供了優化工具的有用提示。
