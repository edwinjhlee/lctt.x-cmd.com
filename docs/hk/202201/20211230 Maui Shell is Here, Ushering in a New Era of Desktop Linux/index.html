Maui Shell 來了，開啓 Linux 桌面新時代 ​

除了 System76 宣佈了基於 RUST 的新桌面環境之外，還有別的團隊也給桌面 Linux 用户帶來了一些新東西。

過去的幾年裏，我們很欣慰地看到 Nitrux Linux 背後的團隊正在擴大他們對 Linux 社區的影響。如今，伴隨着全新 Maui Shell 的發佈，他們的影響也已經得到了進一步擴大。

讓我們一起來看看吧！

關於 Maui 項目的一些背景介紹 ​

作為由 Nitrux Linux 團隊原班人馬創建、開發、維護的項目，Maui 項目已經開發了許多基礎應用。實際上，他們的文件管理器 Index 甚至成功進入了我們的 2021 年五大應用列表 之中！

他們的所有應用均使用 MauiKit 這款定製框架開發。基於 Kirigami 的 MauiKit 專注於跨終端融合性，因此開發出來的應用可以在電腦和手機端擁有一致的體驗。此外，它為開發者提供了更多的預置組件，因此創建應用可以更加便捷。

目前 Maui 項目開發的部分應用包括：

  • Index（文件管理器）
  • Nota（文本編輯器）
  • VVave（音樂播放器）
  • Clip（視頻播放器）
  • Pix（圖片查看器）

雖然這些自制應用本身質量不錯，但它們在 Nitrux Linux 的默認桌面環境 KDE Plasma 裏總顯得不合羣。因此，Maui Shell 應運而生。

Maui Shell 介紹 ​

藉助與 Maui 應用相同的 MauiKit 和 Qt 技術底層，Maui Shell 是 Nitrux 在桌面環境領域的一個新嘗試。從上面的截圖可以看出，它在很大程度上受到了 GNOME Shell 的啓發，這在使用過程中也確實有所體現。

但，這並不意味着 Maui Shell 沒有原創的地方。從底部上滑可打開類似於 GNOME “活動”的概覽界面。與此相鄰的是一個小 Dock，可以通過相當美觀的啓動器來啓動應用。右上角有一個與 macOS 相似的控制中心，內有精心設計的菜單和許多控制功能。

在我使用它的過程中，一切都是如此精緻、自然。我感覺這與它極致現代、扁平的設計美學有關，我甚至認為 Maui Shell 已經超越了 GNOME 和 KDE Plasma 等同類軟件。説到 Plasma，與 Nitrux 的默認 Plasma 版本相比，Maui Shell 在低端設備（和虛擬機）上的反應更加靈敏。

總的來説，我預測 Maui Shell 將依靠其實用性成為 “Linux 桌面環境之王”。然而，我還沒談到 Maui Shell 最核心的特性：跨終端自適應性Convergence。

主流之中的融合 ​

許多人可能還記得 2010 年 Canonical 開發了一款類似的跨終端桌面環境 Unity，它最終以失敗落幕，到 2018 年則被完全淘汰了。但是，Unity 和 Maui Shell 有一個共同特性 —— 那就是跨終端融合性。

隨着 Linux 在移動端的開發力度逐漸加大，跨終端支持變得尤為重要。由此來看，一個新的桌面環境竟能同時支持桌面端和移動端，的確不可思議。

這一點必須依靠大量的跨終端應用實現，而 Maui 已經處在了完美的銜接點上。這僅僅是我相信 Maui Shell 能成為 Linux 桌面未來的原因之一。

立即試用 Maui Shell ​

與其他新發布的軟件不同，Maui Shell 已經預裝於新發布的 Nitrux 1.8。如果你想親自嘗試一下，那請隨時從下方鏈接中獲取 ISO 鏡像。但是，在嘗試之前，請務必知曉：Maui Shell 仍處於早期開發階段。

儘管 Maui Shell 擁有許多特色功能，但部分功能可能存在問題、尚未實現，要麼就是缺失了，其中包括：

  • 藍牙支持
  • PulseAudio 支持
  • 網絡開關
  • 媒體控制（MPRIs）
  • 拖放支持
  • 多顯示器支持
  • 設置應用
  • XWayland Shell 插件

因此，我暫時不能建議你使用 Maui Shell 作為主力桌面環境。為此，你可能需要等待 2022 年秋季發佈的正式版本。

在此之前，我仍將持續關注 Maui Shell。對於這款桌面環境，你的評價如何？歡迎在評論區説出你的想法！
