給開源愛好者的 10 個節日禮物創意 ​

從 DIY 項目到電腦再到書籍，這份清單提供了培養創造力、學習和探索的禮物創意。

你是否正在為你的節日購物清單上的人尋找很酷的禮物，或者為你自己的願望清單尋找建議？如果是這樣，請考慮以下十條建議。這些禮物建議中的每一個都以某種方式與開源精神相聯繫。從 DIY 項目到電腦再到書籍，這份清單提供了培養創造力、學習和探索的禮物建議。

System76 電腦 ​

你身邊的某人需要一個新的台式機、筆記本電腦或服務器嗎？System76 應該是你首先應該尋找的地方之一。想找一些輕巧的移動設備嗎？輕巧的 14 英寸 Lemur Pro 筆記本電腦是一個很好的選擇。需要一個有大量處理能力、內存和存儲空間的台式機？各種 Thelio 台式機中就有一款是你要找的。還有很多介於兩者之間的其他選擇。他們的電腦配備了 Ubuntu 或 Pop!_OS，這是該公司自己的基於 Ubuntu 的 Linux 發行版，並有終身支持。System76 也支持 維修權法案。雖然不是唯一一家銷售安裝 Linux 系統的電腦的廠商，但他們肯定是最受歡迎的廠商之一。

  • 價格不一

樹莓派 400 個人電腦套件 ​

樹莓派幾乎不需要介紹。自從 2012 年第一款樹莓派風靡全球以來，樹莓派一直是最受歡迎的單板計算機之一，可用於教育、業餘愛好者和手工愛好者們。樹莓派 400 個人電腦套件 延續了這一趨勢。除了一個顯示器之外，這個套件包含了人們開始使用所需的一切。花 100.00 美元，你就可以得到樹莓派 400（樹莓派 4 系列的一個變種，內置於一個鍵盤外殼中）、一隻鼠標、電源、micro HDMI 轉 HDMI 電纜、一張預裝樹莓派操作系統的 SD 卡，以及一本《樹莓派初學者指南》。雖然樹莓派 400 不是世界上最強大的計算機，但對於你的禮物清單上的孩子來説，樹莓派 400 完全可以作為一個得當的入門計算機。

  • 價格：100.00 美元

樹莓派 Build HAT ​

樹莓派的諸多優勢之一是它能夠通過各種附加板進行擴展。最近推出的一款附加板 —— 樹莓派 Build HAT，可以用樹莓派來控制多達四個樂高技術電機或 樂高教育 SPIKE 產品系列的傳感器。Build HAT 適用於任何帶有 40 針 GPIO 接頭的樹莓派。你可以使用專門開發的 Python 庫對項目進行編碼。Build HAT 可以使用外部 8V 直流電源（如 官方 Built HAT 電源）或 7.5V 電池組為自身、樹莓派板以及樂高電機和傳感器供電。

  • 價格：25.00 美元（加上一個項目所需的零件和配件的費用）

CrowPi2 ​

CrowPi2 是一個 STEM 學習項目集合，放在一個由樹莓派驅動的筆記本電腦式的機箱裏。CrowPi2 套件有三種尺寸：基本型、高級型和豪華型。基本型套件包括一些附件，但不包括樹莓派。高級套裝配備了一個擁有 4GB 內存的樹莓派 4B，並有比基本套裝更多的配件選擇。豪華套裝配備了最多的配件和一個擁有 8GB 內存的樹莓派 4B。所有三個套件都有太空灰或銀色可供選擇。一個可選的移動電源可以在不插入電源插座時為 CrowPi2 提供電源。如果你想了解更多關於 CrowPi2 的信息，你可以閲讀 Seth Kenlon 的 對 CrowPi2 的點評。

  • 基本套件：339.99 美元
  • 高級套件：469.99 美元
  • 豪華套裝：529.99 美元
  • 可選的移動電源：19.00 美元

Keebio Quefrency 鍵盤 ​

推薦人：John Hall

Keebio Quefrency 鍵盤 對於任何想組裝自己的鍵盤的人來説，都是一個很好的節日禮物！它是一款 65% 鍵盤，這可能是大多數人願意去做的最小的鍵盤，因為它有 Home、PgUp、PgDn 和方向鍵。它是一個分體式的人體工程學鍵盤，但如果你難以適應分體式的鍵盤，你可以將兩半重新組合起來。最重要的是，最新版本的 Quefrency 有熱插拔插座，所以你可以在不需要焊接任何東西的情況下組裝它。

下面是一個廉價的 Quefrency 鍵盤組件：

  • Quefrency rev4 PCBs 帶有熱插拔插座，加上 FR4 板（左邊沒有宏，右邊有 65%）
    • 80 + 28 美元
  • 2u 穩定器（5 個）
    • 10 美元
  • 按鍵開關（70 個）
    • 16 美元
  • 鍵帽
    • 45 美元
  • 2.25u G20 左空格鍵 和 2.75u G20 右空格鍵
    • 8 + 8 美元
  • USB C 到 USB C 鍵盤連接器
    • 4 美元
  • 共計 199 美元（不包括運費）

正如零件清單中指出的，Keebio Quefrency rev4 需要五個穩定器：

  1. 左 Shift 鍵
  2. 左空格鍵
  3. 右空格鍵
  4. 回車鍵
  5. 退格鍵

Keebio Quefrency rev4 目標是構建 65% 鍵盤，它有一個縮短的右 Shift 鍵，不需要穩定器。許多鍵帽套裝，甚至是相對便宜的套裝，如 Artifact Bloom 和 Glorious GPBT，包括一個縮短的右 Shift 鍵，適合大多數像這樣的鍵盤。難的是找到匹配的分體式空格鍵鍵帽。但你可以從 Pimp My Keyboard 等地方買到空格鍵的鍵帽，效果很好。不幸的是，幾乎不可能從不同的製造商那裏得到匹配的顏色。即使你選擇白色鍵帽和白色空格鍵，其中一個也可能比另一個更灰。為什麼不接受這種差異呢？試着將白色和灰色的鍵帽與紅色或藍色的空格鍵配對一下。

Petoi Nybble 開源機器貓 ​

Petoi Nybble 開源機器貓 是一個用於建造機器寵物貓的套件。該套件包含了建造該項目所需的一切，但不包括電池。Nybble 需要兩塊 14500 鋰離子可充電 3.7V 電池，可提供約 45 分鐘的遊戲時間。一旦組裝完成，可以使用 Arduino IDE、Python API 或 Android/iOS 應用程序對該貓進行編程/控制。查看 Nybble 用户手冊 瞭解更多細節。

  • 價格：249.00 美元

《蒼穹浩瀚》小説系列 ​

James S.A. Corey 的《蒼穹浩瀚Expanse》系列的最後一部小説正好在假日送禮季節推出。定於 11 月 30 日發行的《利維坦瀑布Leviathan Falls》將結束這個史詩般的九部科幻小説系列的主要敍事，探索人類在太空的未來。按順序，該系列的九本書是《利維坦覺醒Leviathan Wakes》、《卡利班之戰Caliban's War》、《阿巴頓之門Abaddon's Gate》、《西波拉燃燒Cibola Burn》、《復仇遊戲Nemesis Games》、《巴比倫的灰燼Babylon's Ashes》、《波斯波利斯的崛起Persepolis Rising》、《提亞馬特之怒Tiamat's Wrath》和《利維坦瀑布Leviathan Falls》。明年還將出版一本短篇小説和長篇小説集。這些故事和長篇小説中的大部分已經有了電子書格式，但這是第一次的印刷合集。給你身邊的科幻小説讀者購買該系列的第一本書，讓他們開始閲讀，或者給他們購買整個系列。

  • 第一至第六本：17.99 美元（平裝本）
  • 第七本和第八本：18.99 美元（平裝本）
  • 第九本：30.00 美元（精裝本）

書籍 ​

如果你正在尋找書籍推薦，而《蒼穹浩瀚》的推薦並不符合你的需求，可以考慮 這份 2021 年夏季閲讀清單 中的書籍。這份清單包含八本適合各種閲讀口味的書籍推薦。從《貝奧武夫Beowulf》的現代翻譯到關於技術的非小説類書籍，那裏應該有適合你生活中的讀者的東西。如果 2021 年夏季閲讀清單中沒有你要找的東西，這篇文章還包含了以前所有夏季閲讀清單的鏈接，其中提供了十多份建議清單。

  • 價格不一

貼紙 ​

大流行期間的虛擬會議的一個缺點是，你無法帶走從各個供應商攤位上收集的貼紙。對於那些喜歡用貼紙裝飾筆記本電腦的人來説，這可能意味着他們最新的筆記本電腦目前還沒有通常的裝飾品。如果這聽起來像你生活中的某個人，考慮給他們買一個來自 Sticker Mule 的 Unixstickers 包。該包有三種不同的尺寸：專業版，包含十張貼紙；精英版，包含專業版中的所有貼紙，再加十張貼紙；終極版，包含精英版中的所有內容，再加十張貼紙。這些貼紙涵蓋了許多開源項目，使這些捆綁包成為參觀供應商展位和親臨會議的貼紙交換台的下一個最佳選擇。

  • 專業包：1.00 美元
  • 精英包：19.00 美元
  • 終極包：24.00 美元

向開源組織慈善捐贈 ​

如果你購物清單上的人已經擁有了一切（或者不想要任何有形的禮物），可以考慮以他們的名義向開源項目進行慈善捐贈。這個 開源組織 列表中有很多組織供你選擇。你、以其名義捐款的人和收到你捐款的組織都會很高興，你的禮物有助於使開源變得更好。
