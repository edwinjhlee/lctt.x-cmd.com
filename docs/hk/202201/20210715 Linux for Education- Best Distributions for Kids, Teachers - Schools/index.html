給兒童、教師和學校的最佳 Linux 發行版 ​

孩子們可以使用 Linux 發行版嗎？它又是否適合學校使用呢？

嗯，這取決於你有什麼選擇，以及你想選擇的是什麼。不管你是想給孩子還是學校老師用，都有不少選擇。

因此，為了給你一個良好的開端，我們策劃了一個為教育量身定做的 最佳 Linux 發行版 列表。

最適合兒童的 Linux 發行版 ​

對於一個孩子來説，發行版必須提供一個用户友好的用户界面，而不是高級功能。

你可能會説，任何主流的、像 Ubuntu、Mint 或 Zorin 這樣適合初學者的發行版都可以做到這一點。沒錯，但是如果一個發行版帶有了 基本工具 並易於使用，孩子們會很快學會使用它並喜歡上它。

1、Endless OS ​

Endless OS 是一個流行的選擇，是為教育量身定做的 Linux 發行版。

它以 Debian 為基礎，使用 GNOME 桌面環境。儘管它限制了一年內在超過 500 台電腦上使用其操作系統，但它是免費下載的。

它的用户界面很容易使用，看起來很有吸引力，適合安裝在現代電腦上。你可以得到各種預裝的應用程序。因此，這對沒有互聯網接入的電腦來説是很方便的。

2、Ubermix ​

Ubermix 是一個基於 Ubuntu 的 Linux 發行版，旨在通過調整用户界面，擺脱不必要的應用程序，以及增加用於教育的必要工具/應用程序來降低複雜性。

它還提供了一種方法，在出現問題的情況下可以輕鬆地從系統問題中恢復。在內容過濾和 屏幕時間控制 方面有一個可選的家長控制功能，這確實很有用。

Ubermix 得到了積極的維護，並在其官方網站上提供了大量關於安裝和故障排除的説明。

3、Kano OS（用於樹莓派） ​

Kano OS 是為 6 至 14 歲的兒童教育而量身定做的計算套件。它就像高級版的樹莓派，為年輕人提供了大量的 DIY 和編碼活動。

Kano OS 也有基於 Debian 的 用於樹莓派的操作系統。你不需要為此而購買 Kano 套件。你可以在你的樹莓派上使用它。

它的目的是在與他們的計算機套件結合時，提供它所策劃的教育的好處。從編碼應用程序到遊戲，應該有適合每個人的東西。

你還會發現有用的家長控制設置，可以為你的孩子限制/調整體驗。如果需要更多的幫助，官方幫助資源 也會派上用場。

4、AcademiX GNU/Linux ​

AcademiX 是另一個基於 Debian 的發行版，主要用於學習。

不僅僅是初級教育，該操作系統中包含的程序對大學生也應該是有用的。它還包括虛擬互動實驗室和虛擬顯微鏡。

雖然它通過預裝的實用程序使學習變得簡單，但教師也可以用它來創建內容和發佈。

因此，它可以成為很多潛在的學習者和學校教師的一個全能選擇。

5、Sugar（使任何發行版都對兒童友好） ​

Sugar 不是一個成熟的操作系統，而是一個學習平台（環境），它可以安裝在任何 Linux 發行版之上，為學習而設置。

不僅僅是幫助你的孩子用一個易於使用的界面學習，它還有有助於協作、分享和學習而預裝的軟件工具。

它也可用於樹莓派。而且提供了 Flatpak 包，可以讓你在任何 Linux 發行版中輕鬆安裝它的一些學習活動。

6、Li-f-e ​

Linux for education（Li-f-e）最初是 OpenSUSE 的一個項目，這是它的一個延續。

儘管它現在沒有 OpenSUSE 的支持（我找不到任何參考資料），但它對孩子和學校來説可能是一個有用的選擇。

這款軟件基於 Ubuntu MATE，按照一些教科書的説法，它提供了幾個內置的應用程序。它並沒有提供什麼特別的東西，而更像是 Ubuntu 教育版，在寫這篇文章的時候，它正在積極維護。

最適合學校的 Linux 發行版 ​

到目前為止，我提到的那些都是為孩子們的教育和學習而定製的。但教育有兩個部分：學生和教師。

這就是為什麼這個列表分為兩部分。這第二部分列出了一些可能適合學校管理者、管理層和教師的選項。

當然，如果你想利用一個穩定可靠的 Linux 桌面操作系統來管理你的學校（或）內容創作，你總是可以使用 Linux Mint、elementary OS 或 Ubuntu。然而，有一些選項是為這種目的而定製的。

1、Debian Edu/Skolelinux ​

Skolelinux 是一個基於 Debian 的發行版，包含了一些適合學校師生使用的應用程序和網頁服務。

它也被稱為 Debian Edu。你可以通過下載所需的 ISO 或基本系統來選擇離線安裝，其餘的可以在線安裝。

儘管孩子們在安裝後就可以使用它，但它需要一些學習過程來進行配置和維護。因此，這更傾向於學校管理人員或教師，而不是孩子。

2、Linux Schools（Karoshi 服務器） ​

一個具有 Ubuntu LTS 優點的 Linux 發行版，為學校服務器而建。如果你想建立一個服務器並監視/控制一個連接的服務器網絡，Linux Schools（或 Karoshi 服務器）是一個很好的選擇。

它可以讓你使用網頁界面管理一個服務器網絡。你不需要 Linux 系統管理的深入知識來利用它。

3、Escuelas Linux ​

Escuelas Linux 是基於 Bodhi Linux 的。它內置了幾個適合教育環境的應用程序。

它有自定義的工具，可以在幾秒鐘內將發行版重設為安裝後的狀態。也有恢復用户身份的選項。除此之外，它還帶有在網絡中分發教育材料、屏幕廣播、鏡像、遠程命令執行、信息發送、屏幕鎖定和對學生的計算機進行靜音的應用程序。

考慮到它基於 Bodhi Linux，而 Bodhi Linux 是 最好的輕量級 Linux 發行版 之一，這對舊系統來説是個不錯的選擇。

如果你需要 NetBeans、Git、Android Studio 等高級工具，你還可以得到一個額外的開發者包，這是可選安裝的。

除了這些選擇之外，還有 EduBOSS，這是 BOSS Linux 的教育版，是為印度學校量身定做的。

總結 ​

雖然有一百多個 Linux 發行版，但只有少數幾個是專門為教育而設計的。

對於學生、教師和學校管理來説，有一些可行的選擇是件好事。

畢竟，Linux 可以到處使用，任何人都可以使用。我説的對嗎？
