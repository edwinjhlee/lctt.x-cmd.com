Brave vs. Google Chrome：哪個瀏覽器更適合你？ ​

Google Chrome 無疑是 可用於 Linux 的最佳網頁瀏覽器 之一。無論你在什麼平台上使用它，它都提供了用户體驗和功能集的良好融合。

另一方面，Brave 作為跨平台可用的、以隱私為中心的開源選項而廣受歡迎。

那麼，你應該選擇哪一個作為首選網頁瀏覽器呢？Chrome 適合你嗎？誰應該使用 Brave？

在這裏，我們比較了兩種瀏覽器的所有重要方面（包括基準測試），以幫助你做出決定。

用户界面 ​

Google Chrome 用户界面乾淨、開箱即用，沒有不必要的干擾。

根據我的經驗，默認情況下，它與 Linux 上的（GTK）系統主題融為一體。因此，根據你的自定義設置，它可能看起來有點不同。

如果你不在 Linux 上使用它，那麼除了配色方案外，其他所有界面都基本相似。

而對於 Brave，它並不能開箱即用地適應你的系統配色方案。但是，你可以在它的外觀設置裏啓用 GTK 主題。

Brave 與 Chrome 的用户界面接近，但有一些獨有的調整/選項。

就用户界面而言，兩者都不錯，都很容易使用。

但是，Brave 提供了一些自定義外觀的附加選項，例如刪除選項卡搜索按鈕（左側到最小化按鈕）、顯示完整的 URL 等。

如果你覺得這對你有用，Brave 就更適合你。使用 Google Chrome，你在 UI 定製方面沒有太多控制權。

開源與專有 ​

Brave 是一個基於 Chromium 的開源網頁瀏覽器。順便説一句，我們還有一份 不基於 Chromium 的開源瀏覽器 的列表。

Google Chrome 也基於 Chromium，但它添加了幾個專有元素，使其成為一個閉源產品。

雖然你可以期待 Brave 的開源和透明度帶來的好處，但考慮到 Google 有專門的安全團隊，他們在修補問題時可以非常快。

對於普通用户來説，這些都是不太關注的地方。但是，如果你更在意開源和具有透明度的軟件，那麼 Brave 應該是首選。另一方面，如果你不在意是否是專有代碼，並且信任 Google 的產品，那麼 Google Chrome 是一個選擇。

如果你想要一個與 Chrome 具有相似 UI 的開源瀏覽器，你可能想要看看我們對 Chrome 和 Chromium 的比較來選擇一個。

功能差異 ​

你應該會發現兩個瀏覽器的所有基本功能都是相似的。

但是，兩者之間存在一些顯著差異。

如上所述，你會注意到自定義外觀的能力存在差異。

在多個設備之間同步瀏覽器數據的能力也存在很大差異。

使用 Google Chrome，你可以快速登錄你的 Google 賬户並將所有內容同步到你的手機和其他設備。

Brave 也可以讓你同步，但對某些人來説可能不方便。你需要訪問你已經使用 Brave 成功同步的設備之一。

你的同步數據並未存儲在雲中。因此，你必須使用二維碼或密碼授權將瀏覽數據傳輸/同步到另一台設備。

因此，你必須導出書籤和其他相關數據以進行外部備份。

值得慶幸的是，如果你既想要方便的同步，也想要開源瀏覽器，還有另一種選擇。看看我們的 Firefox 和 Brave 比較 文章，瞭解為什麼這對你來説是一個不錯的選擇。

除了這些差異之外，Brave 還支持 IPFS 協議，這是一種旨在對抗審查的點對點安全協議。

也不要忘記，Brave 默認帶有 Brave Search 作為其搜索引擎。所以，如果你更喜歡它而不是將谷歌作為 私人搜索引擎，那也是一件好事。

Brave Rewards 也是一個有趣的附加功能，你可以通過啓用 Brave 的隱私友好型廣告獲得獎勵，並將其回饋給你經常訪問的網站。

如果雲存儲服務或任何在線平台阻止了這些，你可以將使用它的資源直接共享給接收者。

總的來説，Brave 提供了許多有趣的東西。但是，Chrome 瀏覽器是一個更簡單的選擇，對許多人來説是一個方便的選擇。

隱私角度 ​

Brave 的跟蹤保護應該有利於注重隱私的人。你可以使用 Shield 功能阻止廣告和跟蹤器。除此之外，如果你想要更積極阻止廣告（這可能會破壞網站顯示和功能），還有幾個可切換使用的過濾器。

Chrome 瀏覽器不提供此功能。但是，你總可以使用一些以隱私為重點的 Chrome 擴展程序，而 Google 的安全瀏覽功能應該可以保護你免受惡意網站的侵害。

一般來説，如果你不訪問黑幕網站，應該可以使用 Chrome 瀏覽器。而如果你關注隱私，Brave 可能是更好的選擇。

表現 ​

雖然 Brave 通常被認為是最快的，但在我的基準測試中似乎並非如此。這真令人吃驚！

但是，對於大多數人來説，實際的差異應該不明顯。

我使用了流行的基準測試：JetStream 2、Speedometer 2.0 和 Basemark Web 3.0。

請注意，我使用的 Linux 發行版是 Pop!_OS 21.10，測試的瀏覽器版本是 Chrome 97.0.4692.71 和 Brave 97.0.4692.71。

當然，除了瀏覽器之外，我沒有在後台運行任何東西。我的 PC 是由 Intel i5-11600k @4.7 GHz、32 GB 3200 MHz RAM 和 1050ti Nvidia Graphics 驅動的。

安裝 ​

Chrome 瀏覽器提供的 DEB/RPM 軟件包以在 Ubuntu、Debian、Fedora 或 openSUSE 上下載和安裝。

Brave 也支持相同的 Linux 發行版，但你必須使用終端，並按照下載頁面中提到的命令進行安裝。

你可以按照我們的安裝指南 在 Fedora 中安裝 Brave。

它們都不能通過軟件中心安裝。此外，你也找不到任何 Flatpak 包 或 Snap 包。

如果你想要直接從軟件中心安裝，或找到一個 flatpak 包或 Snap 包，Firefox 可以滿足你的需求。

你應該選擇什麼？ ​

如果你想要更多自定義和高級功能，Brave 應該是一個令人印象深刻的選擇。但是，如果你對在 Linux 發行版上使用專有瀏覽器沒有問題，並且想要稍微更好的性能，那麼 Google Chrome 是一個可行的選擇。

對於注重隱私的用户來説，答案是顯而易見的。但是，你必須考慮同步的便利性。因此，如果你對自己到底最在意什麼感到困惑，我建議你先評估你的要求並決定你想要什麼。
