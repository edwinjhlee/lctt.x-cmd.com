值得考慮的 9 個開源 ERP 系統 ​

有一些使用靈活、功能豐富而物有所值的開源 ERP 系統，這裏有 9 個值得你看看。

擁有一定數量員工的企業就需要大量的協調工作，包括制定價格、計劃生產、會計和財務、管理支出、管理存貨等等。把一套截然不同的工具拼接到一起去處理這些工作，是一種粗製濫造和無價值的做法。

那種方法沒有任何彈性。並且那樣在各種各樣的自組織系統之間高效移動數據是非常困難的。同樣，它也很難維護。

因此，大多數成長型企業都轉而使用一個 企業資源計劃 （ERP）系統。

在這個行業中的大咖有 Oracle、SAP、以及 Microsoft Dynamics。它們都提供了一個綜合的系統，但同時也很昂貴。如果你的企業支付不起如此昂貴的大系統，或者你僅需要一個簡單的系統，怎麼辦呢？你可以使用開源的產品來作為替代。

一個 ERP 系統中有什麼東西 ​

顯然，你希望有一個滿足你需要的系統。基於那些需要，更多的功能並不意味着就更好。但是，你的需要會根據你的業務的增長而變化的，因此，你希望能夠找到一個 ERP 系統，它能夠根據你新的需要而擴展它。那就意味着系統有額外的模組或者支持插件和附加功能。

大多數的開源 ERP 系統都是 web 應用程序。你可以下載並將它們安裝到你的服務器上。但是，如果你不希望（或者沒有相應技能或者人員）自己去維護系統，那麼應該確保它們的應用程序提供託管版本。

最後，你還應該確保應用程序有良好的文檔和支持 —— 要麼是付費支持或者有一個活躍的用户社區。

有很多彈性很好的、功能豐富的、很划算的開源 ERP 系統。如果你正打算購買這樣的系統，這裏有我們挑選出來的 9 個。

ADempiere ​

像大多數其它開源 ERP 解決方案，ADempiere 的目標客户是中小企業。它已經存在一段時間了 — 這個項目出現於 2006，它是 Compiere ERP 軟件的一個分支。

它的意大利語名字的意思是“實現”或者“滿足”，它“涉及多個方面”的 ERP 特性，旨在幫企業去滿足各種需求。它在 ERP 中增加了供應鏈管理（SCM）和客户關係管理（CRM）功能，能夠讓該 ERP 套件在一個軟件中去管理銷售、採購、庫存以及帳務處理。它的最新版本是 v.3.9.0，更新了用户界面、POS、人力資源、工資以及其它的特性。

因為是一個跨平台的、基於 Java 的雲解決方案，ADempiere 可以運行在Linux、Unix、Windows、MacOS、智能手機、平板電腦上。它使用 GPLv2 授權。如果你想了解更多信息，這裏有一個用於測試的 demo，或者也可以在 GitHub 上查看它的 源代碼。

Apache OFBiz ​

Apache OFBiz 的業務相關的套件是構建在通用的架構上的，它允許企業根據自己的需要去定製 ERP。因此，它是有內部開發資源的大中型企業的最佳套件，可以去修改和集成它到它們現有的 IT 和業務流程。

OFBiz 是一個成熟的開源 ERP 系統；它的網站上説它是一個有十年曆史的頂級 Apache 項目。可用的 模組 有會計、生產製造、人力資源、存貨管理、目錄管理、客户關係管理，以及電子商務。你可以在它的 demo 頁面 上試用電子商務的網上商店以及後端的 ERP 應用程序。

Apache OFBiz 的源代碼能夠在它的 項目倉庫 中找到。它是用 Java 寫的，它在 Apache 2.0 license 下可用。

Dolibarr ​

Dolibarr 提供了中小型企業端到端的業務管理，從發票跟蹤、合同、存貨、訂單，以及支付，到文檔管理和電子化 POS 系統支持。它的全部功能封裝在一個清晰的界面中。

如果你擔心不會使用 Dolibarr，這裏有一些關於它的文檔。

另外，還有一個 在線演示，Dolibarr 也有一個 插件商店，你可以在那是購買一些軟件來擴展它的功能。你可以在 GitHub 上查看它的 源代碼；它在 GPLv3 或者任何它的最新版本許可下面使用。

ERPNext ​

ERPNext 是這類開源項目中的其中一個；實際上它最初在 2014 年就被 Opensource.com 推薦了。它被設計用於打破一個陳舊而昂貴的專用 ERP 系統的壟斷局面。

ERPNext 適合於中小型企業。它包含的模組有會計、存貨管理、銷售、採購、以及項目管理。ERPNext 是表單驅動的應用程序 — 你可以在一組字段中填入信息，然後讓應用程序去完成剩餘部分。整個套件非常易用。

如果你感興趣，在你考慮參與之前，你可以請求獲取一個 demo，去 下載它 或者在託管服務上 購買一個訂閲。

Metasfresh ​

Metasfresh 的名字表示它承諾軟件的代碼始終保持“新鮮”。它自 2015 年以來每週發行一個更新版本，那時，它的代碼是由創始人從 ADempiere 項目中分叉的。與 ADempiere 一樣，它是一個基於 Java 的開源 ERP，目標客户是中小型企業。

雖然，相比在這裏介紹的其它軟件來説，它是一個很 “年青的” 項目，但是它早早就引起了一起人的注意，獲得很多積極的評價，比如，被提名為“最佳開源”的 IT 創新獎入圍者。

Metasfresh 在自託管系統上或者在雲上單用户使用時是免費的，或者可以按月交納訂閲費用。它的 源代碼 在 GitHub 上，可以在遵守 GPLv2 許可的情況下使用，它的雲版本是以 GPLv3 方式授權使用。

Odoo ​

Odoo 是一個應用程序集成解決方案，它包含的模組有項目管理、帳單、存貨管理、生產製造、以及採購。這些模組之間可以相互通訊，實現高效平滑地信息交換。

雖然 ERP 可能很複雜，但是，Odoo 通過簡單的，甚至是簡潔的界面使它變得很友好。這個界面讓人聯想到谷歌雲盤，它只讓你需要的功能可見。在你決定簽定採購合同之前，你可以 得到一個 Odoo 去試用。

Odoo 是基於 web 的工具。按單個模組來訂閲的話，每個模組每月需要支付 20 美元。你也可以 下載它，或者可以從 GitHub 上獲得 源代碼，它以 LGPLv3 方式授權。

Opentaps ​

Opentaps 是專為大型業務設計的幾個開源 ERP 解決方案之一，它的功能強大而靈活。這並不奇怪，因為它是在 Apache OFBiz 基礎之上構建的。

你可以得到你所希望的模組組合，來幫你管理存貨、生產製造、財務，以及採購。它也有分析功能，幫你去分析業務的各個方面。你可以藉助這些信息讓未來的計劃做的更好。Opentaps 也包含一個強大的報表功能。

在它的基礎之上，你還可以 購買一些插件和附加模組 去增強 Opentaps 的功能。包括與 Amazon Marketplace Services 和 FedEx 的集成等。在你 下載 Opentaps 之前，你可以到 在線 demo 上試用一下。它遵守 GPLv3 許可。

WebERP ​

WebERP 是一個如它的名字所表示的那樣：一個通過 Web 瀏覽器來使用的 ERP 系統。另外還需要的其它軟件只有一個，那就是查看報告所使用的 PDF 閲讀器。

具體來説，它是一個面向批發、分銷、生產製造業務的賬務和業務管理解決方案。它也可以與 第三方的業務軟件 集成，包括多地點零售管理的銷售點系統、電子商務模組、以及構建業務知識庫的 wiki 軟件。它是用 PHP 寫的，並且它致力於成為低資源佔用、高效、快速、以及平台無關的、普通商業用户易於使用的 ERP 系統。

WebERP 正在積極地進行開發，並且它有一個活躍的 論壇，在那裏你可以諮詢問題或者學習關於如何使用這個應用程序的相關知識。你也可以試用一個 demo，或者在 GitHub 上下載它的 源代碼（遵守 GPLv2 許可）

xTuple PostBooks ​

如果你的生產製造、分銷、電子商務業務已經從小規模業務成長起來了，並且正在尋找一個適合你的成長型企業的 ERP 系統，那麼，你可以去了解一下 xTuple PostBooks。它是圍繞核心 ERP 功能、帳務、以及可以添加存貨、分銷、採購、以及供應商報告等 CRM 功能構建的全面解決方案的系統。

xTuple 在通用公共屬性許可證（CPAL）下使用，並且這個項目歡迎開發者去分叉它，然後為基於存貨的生產製造型企業開發其它的業務軟件。它的基於 web 的核心是用 JavaScript 寫的，它的 源代碼 可以在 GitHub 上找到。你可以去在 xTuple 的網站上註冊一個免費的 demo 去了解它。

還有許多其它的開源 ERP 可供你選擇 — 另外你可以去了解的還有 Tryton，它是用 Python 寫的，並且使用的是 PostgreSQL 資料庫引擎，或者基於 Java 的 Axelor，它的好處是用户可以使用拖放界面來創建或者修改業務應用。如果還有在這裏沒有列出的你喜歡的開源 ERP 解決方案，請在下面的評論區共享出來。你也可以去查看我們的 供應鏈管理工具 榜單。
