獻給寫作者的 Linux 工具 ​

這些易用的開源應用可以幫助你打磨你的寫作技巧、使研究更高效、更具有條理。

如果你已經閲讀過我關於如何切換到 Linux 的文章，那麼你就知道我是一個超級用户。另外，我不是任何方面的“專家”，目前仍然如此。但是在過去幾年裏我學到了很多有用的東西，我想將這些技巧傳給其他新的 Linux 用户。

今天，我將討論我寫作時使用的工具，基於三個標準來選擇：

  1. 當我提交作品或文章時，我的主要寫作工具必須與任何發佈者兼容。
  2. 該軟件使用起來必須簡單快捷。
  3. 免費（自由）是很棒的。

有一些很棒的一體化免費解決方案，比如：

  1. bibisco
  2. Manuskript
  3. oStorybook

但是，當我試圖尋找信息時，我往往會迷失方向並失去思路，所以我選擇了適合我需求的多個應用程序。另外，我不想依賴互聯網，以免服務下線。我把這些程序放在顯示器桌面上，以便我一下全看到它們。

請考慮以下工具建議 ： 每個人的工作方式都不相同，並且你可能會發現一些更適合你工作方式的其他應用程序。以下這些工具是目前的寫作工具：

文字處理器 ​

LibreOffice 6.0.1。直到最近，我使用了 WPS，但由於字體渲染問題（Times New Roman 總是以粗體顯示）而否定了它。LibreOffice 的最新版本非常適應 Microsoft Office，而且事實上它是開源的，這對我來説很重要。

詞庫 ​

Artha 可以給出同義詞、反義詞、派生詞等等。它外觀整潔、速度快。例如，輸入 “fast” 這個詞，你會得到字典定義以及上面列出的其他選項。Artha 是送給開源社區的一個巨大的禮物，人們應該試試它，因為它似乎是一個冷僻的小程序。如果你使用 Linux，請立即安裝此應用程序，你不會後悔的。

記筆記 ​

Zim 標榜自己是一個桌面維基，但它也是你所能找到的最簡單的多層級筆記應用程序。還有其它更漂亮的筆記程序，但 Zim 正是那種我需要管理角色、地點、情節和次要情節的程序。

投稿跟蹤 ​

我曾經使用過一款名為 FileMaker Pro 的專有軟件，它慣壞了我。有很多資料庫應用程序，但在我看來，最容易使用的某過於 Glom 了。它以圖形方式滿足我的需求，讓我以表單形式輸入信息而不是表格。在 Glom 中，你可以創建你需要的表單，這樣你就可以立即看到相關信息（對於我來説，通過電子表格來查找信息就像將我的眼球拖到玻璃碎片上）。儘管 Glom 不再處於開發階段，但它仍然是很棒的。

搜索 ​

我已經開始使用 StartPage.com 作為我的默認搜索引擎。當然，當你寫作時，Google 可以成為你最好的朋友之一。但我不喜歡每次我想了解特定人物、地點或事物時，Google 都會跟蹤我。所以我使用 StartPage.com 來代替。它速度很快，並且不會跟蹤你的搜索。我也使用 DuckDuckGo.com 作為 Google 的替代品。

其他的工具 ​

Chromium 瀏覽器 是 Google Chrome 的開源版本，帶有隱私插件。

儘管來自 Mozilla 的 Thunderbird 是一個很棒的程序，但我發現 Geary 是一個更快更輕的電子郵件應用程序。有關開源電子郵件應用程序的更多信息，請閲讀 Jason Baker 的優秀文章：6 個開源的桌面電子郵件客户端。

正如你可能已經注意到，我對應用程序的喜愛趨向於將最好的 Windows、MacOS 都能運行，以及此處提到的開源 Linux 替代品融合在一起。我希望這些建議能幫助你發現有用的新方法來撰寫並跟蹤你的寫作（謝謝你，Artha！）。

寫作愉快！
