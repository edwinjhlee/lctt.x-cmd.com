Oracle Linux 系統如何去註冊使用堅不可摧 Linux 網絡（ULN） ​

大多數人都知道 RHEL 的訂閲 ，但是知道 Oracle 訂閲及細節的人卻很少。

甚至我也不知道關於它的信息，我是最近才瞭解了有關它的信息，想將這些內容共享給其他人。因此寫了這篇文章，它將指導你去註冊 Oracle Linux 系統去使用堅不可摧 Linux 網絡（ULN） 。

這將允許你去註冊系統以儘快獲得軟件更新和其它的補丁。

什麼是堅不可摧 Linux 網絡 ​

ULN 代表堅不可摧 Linux 網絡Unbreakable Linux Network，它是由 Oracle 所擁有的。如果你去 Oracle OS 支持中去激活這個訂閲，你就可以註冊你的系統去使用堅不可摧 Linux 網絡（ULN）。

ULN 為 Oracle Linux 和 Oracle VM 提供軟件補丁、更新、以及修復，這些信息同時提供在 yum、Ksplice、並提供支持策略。你也可以通過它來下載原始發行版中沒有包含的有用的安裝包。

ULN 的告警提示工具會週期性地使用 ULN 進行檢查，當有更新的時候它給你發送警報信息。

如果你想在 yum 上使用 ULN 倉庫去管理你的系統，需要確保你的系統已經註冊到 ULN 上，並且訂閲了一個或多個 ULN 頻道。當你註冊一個系統使用 ULN，它將基於你的系統架構和操作系統去自動選擇頻道中最新的版本。

如何註冊為一個 ULN 用户 ​

要註冊為一個 ULN 用户，需要你有一個 Oracle Linux 支持或者 Oracle VM 支持的有效客户支持代碼（CSI）。

請按以下步驟去註冊為一個 ULN 用户。

請訪問 linux.oracle.com：

如果你已經有一個 SSO 帳户，請點擊 “Sign On”。

如果你沒有帳户，點擊 “Create New Single Signon Account” 然後按屏幕上的要求去創建一個帳户。

驗證你的電子郵件地址以完成帳户設置。

使用你的 SSO 帳户的用户名和密碼去登入。在 “Create New ULN User” 頁面上，輸入你的 CSI 然後點擊 “Create New User”。

注意：

  • 如果當前沒有分配管理員去管理 CSI，將會提示你去點擊確認讓你成為 CSI 管理員。
  • 如果你的用户名已經在系統上存在，你將被提示通過點擊堅不可摧 Linux 網絡的鏈接去操作 ULN。

如何註冊 Oracle Linux 6/7 系統使用 ULN ​

只需要運行下列的命令，並按隨後的指令提示去註冊系統。

# uln_register

確保你的系統有一個激活的因特網連接。同時準備好你的 Oracle 單點登錄帳户（SSO）的用户名和密碼，然後點擊 Next。

另外，你也可以在 ULN 網站上查看到相同的信息。轉到 System 標籤頁去查看已註冊的系統列表。

去查看已經啓用的倉庫列表。轉到 System 標籤頁，然後點擊相應的系統。另外，你也能夠看到系統勘誤及可用更新。

去管理訂閲的頻道。轉到 System 標籤頁，然後點擊有關的 system name，最後點擊 Manage Subscriptions。
