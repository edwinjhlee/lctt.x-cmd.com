讓孩子愛上計算機和編程的 15 本書 ​

以及，還有三本是給寶寶的。

在工作之餘，我聽説不少技術專家透露出讓他們自己的孩子學習更多關於 Linux 和 開源知識的意願，他們中有的來自高管層，有的來自普通崗位。其中一些似乎時間比較充裕，伴隨其孩子一步一步成長。另一些人可能沒有充足的時間讓他們的孩子看到為何 Linux 和 開源如此之酷。也許他們能抽出時間，但這不一定。在這個大世界中，有太多有趣、有價值的事物。

不論是哪種方式，如果你的或你認識的孩子願意學習使用編程和硬件，實現遊戲或機器人之類東西，那麼這份書單很適合你。

面向兒童 Linux 和 開源愛好者的 15 本書 ​

《零基礎學 Raspberry Pi》，作者 Carrie Anne Philbin

在對編程感興趣的兒童和成人中，體積小小的、僅信用卡一般大的樹莓派引起了強烈的反響。你台式機能做的事情它都能做，具備一定的基礎編程技能後，你可以讓它做更多的事情。本書操作簡明、項目風趣、技能紮實，是一本兒童可用的終極編程指南。（Joshua Allen Holm 推薦，評論節選於本書的內容提要）

《Python 編程快速上手：讓繁瑣工作自動化》，作者 Al Sweigart

這是一本經典的編程入門書，行文足夠清晰，11 歲及以上的編程愛好者都可以讀懂本書並從中受益。讀者很快就會投入到真實且實用的任務中，在此過程中順便掌握了優秀的編程實踐。最好的一點是，如果你願意，你可以在互聯網上閲讀本書。（DB Clinton 推薦並評論）

《Scratch 遊戲編程》，作者 Jon Woodcock

本書適用於 8-12 歲沒有或僅有有限編程經驗的兒童。作為一本直觀的可視化入門書，它使用有趣的圖形和易於理解的操作，教導年輕的讀者如何使用 Scratch 這款流行的自由編程語言構建他們自己的編程項目。（Joshua Allen Holm 推薦，評論節選於本書的內容提要）

《用 Python 巧學數學》，作者 Amit Saha

無論你是一名學生還是教師，只要你對使用 Python 學習數學感興趣，不妨讀讀本書。在邏輯上，本書帶領讀者一步一步地從基礎到更為複雜的操作，從最開始簡單的 Python shell 數字運算，到使用類似 matplotlib 這樣的 Python 庫實現數據可視化，讀者可以很容易跟上作者的思路。本書充分調動你的好奇心，感嘆 Python 與 數學結合的威力。（Don Watkins 推薦並評論）

《編程女生：學習編程，改變世界》，作者 Reshma Saujani

作者是 Girls Who Code 運動的發起人，該運動得到 Sheryl Sandberg、 Malala Yousafzai 和 John Legend 支持。本書一部分是編程介紹，一部分女生賦能，這兩部分都寫得很有趣。本書包括動態藝術作品、零基礎的編程原理講解以及在 Pixar 和 NASA 等公司工作的女生的真實故事。這本書形象生動，向讀者展示了計算機科學在我們生活中發揮的巨大作用以及其中的趣味。（Joshua Allen Holm 推薦，評論節選於本書的內容提要）

《Python 遊戲編程快速上手》，作者 Al Sweigart

本書將讓你學會如何使用流行的 Python 編程語言編寫計算機遊戲，不要求具有編程經驗！入門階段編寫劊子手Hangman，猜數字，井字遊戲Tic-Tac-Toe這樣的經典遊戲，後續更進一步編寫高級一些的遊戲，例如文字版尋寶遊戲，以及帶音效和動畫的碰撞與閃避collision-dodgoing遊戲。（Joshua Allen Holm 推薦，評論節選於本書的內容提要）

《Lauren Ipsum：關於計算機科學和一些不可思議事物的故事》，作者 Carlos Bueno

本書採用愛麗絲夢遊仙境的風格，女主角 Lauren Ipsum 來到一個稍微具有魔幻色彩的世界。世界的自然法則是邏輯學和計算機科學，世界謎題只能通過學習計算機編程原理並編寫代碼完成。書中沒有提及計算機，但其作為世界的核心存在。（DB Clinton 推薦並評論）

《Java 輕鬆學》，作者 Bryson Payne

Java 是全世界最流行的編程語言，但眾所周知上手比較難。本書讓 Java 學習不再困難，通過若干實操項目，讓你馬上學會構建真實可運行的應用。（Joshua Allen Holm 推薦，評論節選於本書的內容提要）

《終身幼兒園》，作者 Mitchell Resnick

幼兒園正變得越來越像學校。在本書中，學習專家 Mitchel Resnick 提出相反的看法：學校（甚至人的一生）應該更像幼兒園。要適應當今快速變化的世界，各個年齡段的人們都必須學會開創性思維和行動；想要達到這個目標，最好的方式就是更加專注於想像、創造、玩耍、分享和反饋，就像孩子在傳統幼兒園中那樣。基於在 MIT 媒體實驗室Media Lab 30 多年的經歷， Resnick 討論了新的技術和策略，可以讓年輕人擁有開創性的學習體驗。（Don Watkins 推薦，評論來自 Amazon 書評）

《趣學 Python：教孩子學編程》，作者 Jason Briggs

在本書中，Jason Briggs 將 Python 編程教學藝術提升到新的高度。我們可以很容易地將本書用作入門書，適用羣體可以是教師/學生，也可以是父母/兒童。通過一步步引導的方式介紹複雜概念，讓編程新手也可以成功完成，進一步激發學習慾望。本書是一本極為易讀、寓教於樂但又強大的 Python 編程入門書。讀者將學習基礎數據結構，包括元組turple、列表list和映射map等，學習如何創建函數、重用代碼或者使用包括循環和條件語句在內的控制結構。孩子們還將學習如何創建遊戲和動畫，體驗 Tkinter 的強大並創建高級圖形。（Don Watkins 推薦並評論）

《Scratch 編程園地》，作者 Al Sweigart

Scratch 編程一般被視為一種寓教於樂的教年輕人編程的方式。在本書中，Al Sweigart 告訴我們 Scratch 是一種超出絕大多數人想像的強大編程語言。獨特的風格，大師級的編寫和呈現。Al 讓孩子通過創造複雜圖形和動畫，短時間內認識到 Scratch 的強大之處。（Don Watkins 推薦並評論）

《秘密編程者》，作者 Gene Luen Yang，插圖作者 Mike Holmes

Gene Luen Yang 是漫畫小説超級巨星，也是一所高中的計算機編程教師。他推出了一個非常有趣的系列作品，將邏輯謎題、基礎編程指令與引入入勝的解謎情節結合起來。故事發生在 Stately Academy 這所學校，其中充滿有待解開的謎團。（Joshua Allen Holm 推薦，評論節選於本書的內容提要）

《想成為編程者嗎？編程、視頻遊戲製作、機器人等職業終極指南！》，作者 Jane Bedell

酷愛編程？這本書易於理解，描繪了以編程為生的完整圖景，激發你的熱情，磨練你的專業技能。（Joshua Allen Holm 推薦，評論節選於本書的內容提要）

《教孩子編程》，作者 Bryson Payne

你是否在尋找一種寓教於樂的方式教你的孩子 Python 編程呢？Bryson Payne 已經寫了這本大師級的書。本書通過烏龜圖形打比方，引導你編寫一些簡單程序，為高級 Python 編程打下基礎。如果你打算教年輕人編程，這本書不容錯過。（Don Watkins 推薦並評論）

《圖解 Kubernetes（兒童版）》，作者 Matt Butcher, 插畫作者 Bailey Beougher

介紹了 Phippy 這個勇敢的 PHP 小應用及其 Kubernetes 之旅。（Chris Short 推薦，評論來自 Matt Butcher 的Blog）

給寶寶的福利書 ​

《寶寶的 CSS》、《寶寶的 Javascript》、《寶寶的 HTML》，作者 Sterling Children's

這本概念書讓寶寶熟悉圖形和顏色的種類，這些是互聯網編程語言的基石。這本漂亮的書用富有色彩的方式介紹了編程和互聯網，對於技術人士的家庭而言，本書是一份絕佳的禮物。（Chris Short 推薦，評論來自 Amazon 書評）
