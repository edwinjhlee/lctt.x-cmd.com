讓我們從 GitHub 中遷移出來 ​

正如你們之前聽到的那樣，微軟收購了 GitHub。這對 GitHub 的未來意味着什麼尚不清楚，但 Gitlab 的人認為微軟的最終目標是將 GitHub 整合到他們的 Azure 帝國。對我來説，這很有道理。

儘管我仍然不情願地將 GitHub 用於某些項目，但我前一段時間將所有個人倉庫遷移到了 Gitlab 中。現在是時候讓你做同樣的事情，並拋棄 GitHub。

有些人可能認為微軟的收購沒有問題，但對我來説，這是壓垮駱駝的最後一根稻草。幾年來，微軟一直在開展一場關於他們如何熱愛 Linux 的大型營銷活動，並突然決定用所有它的形式擁抱自由軟件。更像 MS BS 給我​​的。

讓我們花點時間提醒自己：

  • Windows 仍然是一個巨大的專有怪物，數十億人每天都喪失了他們的隱私和權利中。
  • 微軟公司（曾經）以傳播自由軟件的“危害”聞名，以防止政府和學校放棄 Windows，轉而支持 FOSS。
  • 為了確保他們的壟斷地位，微軟通過向全世界的小學頒發“免費”許可證來吸引孩子使用 Windows。毒品經銷商使用相同的策略並提供免費樣品來獲取新客户。
  • 微軟的 Azure 平台 - 即使它可以運行 Linux 虛擬機 - 它仍然是一個巨大的專有管理程序。

我知道移動 git 倉庫看起來像是一件痛苦的事情，但是 Gitlab 的員工正在乘着人們離開 GitHub 的浪潮，並通過提供 GitHub 導入器使遷移變得容易。

如果你不想使用 Gitlab 的主實例（gitlab.org），下面是另外兩個你可以用於自由軟件項目的備選實例：

  • Debian Gitlab 實例適用於每個 FOSS 項目，它不僅適用於與 Debian 相關的項目。只要項目符合 Debian 自由軟件指南，你就可以使用該實例及其 CI。
  • Riseup 為名為 0xacab 的激進項目維護了一個 Gitlab 實例。如果你的理念與 Riseup 的一致，他們很樂意在那裏託管你的項目。

朋友不要再讓人使用 Github 了。
