在 Arch Linux 中降級一個包 ​

在 Arch Linux 中，有一個名為 “downgrade” 的實用程序，可幫助你將安裝的軟件包降級為任何可用的舊版本。此實用程序將檢查你的本地緩存和遠程服務器（Arch Linux 倉庫）以查找所需軟件包的舊版本。你可以從該列表中選擇任何一箇舊的穩定的軟件包並進行安裝。

該軟件包在官方倉庫中不可用，你需要添加非官方的 archlinuxfr 倉庫。

為此，請編輯 /etc/pacman.conf 文件：

$ sudo nano /etc/pacman.conf

添加以下行：

[archlinuxfr]
SigLevel = Never
Server = http://repo.archlinux.fr/$arch

保存並關閉文件。

使用以下命令來更新倉庫：

$ sudo pacman -Sy

然後在終端中使用以下命令安裝 “Downgrade” 實用程序：

$ sudo pacman -S downgrade

示例輸出：

resolving dependencies...
 looking for conflicting packages...

Packages (1) downgrade-5.2.3-1

Total Download Size: 0.01 MiB
 Total Installed Size: 0.10 MiB

:: Proceed with installation? [Y/n]

“downgrade” 命令的典型用法是：

$ sudo downgrade [PACKAGE, ...] [-- [PACMAN OPTIONS]]

讓我們假設你想要將 opera web 瀏覽器 降級到任何可用的舊版本。

為此，運行：

$ sudo downgrade opera

此命令將從本地緩存和遠程鏡像列出所有可用的 opera 包（新舊兩種版本）。

那麼，如何避免已損壞的軟件包並使 Arch Linux 更加穩定？ ​

在更新 Arch Linux 之前查看 Arch Linux 新聞和論壇，看看是否有任何已報告的問題。過去幾周我一直在使用 Arch Linux 作為我的主要操作系統，以下是我在這段時間內發現的一些簡單提示，以避免在 Arch Linux 中安裝不穩定的軟件包。

  1. 避免部分升級。這意味着永遠不要運行 pacman -Sy <軟件包名稱>。此命令將在安裝軟件包時部分升級你的系統。相反，優先使用 pacman -Syu 來更新系統，然後使用 package -S <軟件包名稱> 安裝軟件包。
  2. 避免使用 pacman -Syu -force 命令。-force 標誌將忽略程序包和文件衝突，並且可能會以破損的程序包或損壞的系統結束。
  3. 不要跳過依賴性檢查。這意味着不要使用 pacman -Rdd <軟件包名稱>。此命令將在刪除軟件包時避免依賴性檢查。如果你運行這個命令，另一個重要的包所需的關鍵依賴也可以被刪除。最終，它會損壞你的 Arch Linux。
  4. 定期備份重要數據和配置文件以避免數據丟失總是一個好習慣。
  5. 安裝第三方軟件包和 AUR 等非官方軟件包時要小心。不要安裝那些正在經歷重大發展的軟件包。

有關更多詳細信息，請查看 Arch Linux 維護指南。
