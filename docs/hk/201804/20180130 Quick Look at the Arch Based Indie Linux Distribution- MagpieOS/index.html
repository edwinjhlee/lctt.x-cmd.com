一個基於 Arch 的獨立 Linux 發行版 MagpieOS ​

目前使用的大多數 Linux 發行版都是由歐美創建和開發的。一位來自孟加拉國的年輕開發人員想要改變這一切。

誰是 Rizwan？ ​

Rizwan 是來自孟加拉國的計算機科學專業的學生。他目前正在學習成為一名專業的 Python 程序員。他在 2015 年開始使用 Linux。使用 Linux 啓發他創建了自己的 Linux 發行版。他還希望讓世界其他地方知道孟加拉國正在升級到 Linux。

他還致力於從頭創建 LFS 的 live 版本。

什麼是 MagpieOS？ ​

Rizwan 的新發行版被命名為 MagpieOS。 MagpieOS 非常簡單。它基本上是 GNOME3 桌面環境的 Arch。 MagpieOS 還包括一個自定義的倉庫，其中包含圖標和主題（據稱）在其他基於 Arch 的發行版或 AUR 沒有。

下面是 MagpieOS 包含的軟件列表：Firefox、LibreOffice、Uget、Bleachbit、Notepadqq、SUSE Studio Image Writer、Pamac 軟件包管理器、Gparted、Gimp、Rhythmbox、簡單屏幕錄像機等包括 Totem 視頻播放器在內的所有默認 GNOME 軟件，以及一套新的定製壁紙。

目前，MagpieOS 僅支持 GNOME 桌面環境。Rizwan 選擇它是因為這是他的最愛。但是，他計劃在未來添加更多的桌面環境。

不幸的是，MagpieOS 不支持孟加拉語或任何其他當地語言。它支持 GNOME 的默認語言，如英語、印地語等。

Rizwan 命名他的發行為 MagpieOS，因為喜鵲magpie 是孟加拉國的官方鳥。

為什麼選擇 Arch？ ​

和大多數人一樣，Rizwan 通過使用 Ubuntu 開始了他的 Linux 旅程。一開始，他對此感到滿意。但是，有時他想安裝的軟件在倉庫中沒有，他不得不通過 Google 尋找正確的 PPA。他決定切換到 Arch，因為 Arch 有許多在 Ubuntu 上沒有的軟件包。Rizwan 也喜歡 Arch 是一個滾動版本，並且始終是最新的。

Arch 的問題在於它的安裝非常複雜和耗時。所以，Rizwan 嘗試了幾個基於 Arch 的發行版，並且對任何一個都不滿意。他不喜歡 Manjaro，因為它們沒有權限使用 Arch 的倉庫。此外，Arch 倉庫鏡像比 Manjaro 更快並且擁有更多軟件。他喜歡 Antergos，但要安裝需要一個持續的互聯網連接。如果在安裝過程中連接失敗，則必須重新開始。

由於這些問題，Rizwan 決定創建一個簡單的發行版，讓他和其他人無需麻煩地安裝 Arch。他還希望通過使用他的發行版讓他的祖國的開發人員從 Ubuntu 切換到 Arch。

如何通過 MagpieOS 幫助 Rizwan ​

如果你有興趣幫助 Rizwan 開發 MagpieOS，你可以通過 MagpieOS 網站與他聯繫。你也可以查看該項目的 GitHub 頁面。Rizwan 表示，他目前不尋求財政支持。

最後的想法 ​

我快速地安裝過一次 MagpieOS。它使用 Calamares 安裝程序，這意味着安裝它相對快速輕鬆。重新啓動後，我聽到一封歡迎我來到 MagpieOS 的音頻消息。

説實話，這是我第一次聽到安裝後的問候。（Windows 10 可能也有，但我不確定）屏幕底部還有一個 Mac OS 風格的應用程序停靠欄。除此之外，它感覺像我用過的其他任何 GNOME 3 桌面。

考慮到這是一個剛剛起步的獨立項目，我不會推薦它作為你的主要操作系統。但是，如果你是一個發行版嘗試者，你一定會試試看。

話雖如此，對於一個想把自己的國家放在技術地圖上的學生來説，這是一個不錯的嘗試。做得很好，Rizwan。
