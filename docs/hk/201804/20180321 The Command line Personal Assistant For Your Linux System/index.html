Yoda：您的 Linux 系統命令列個人助理 ​

不久前，我們介紹了一個名為 “Betty” 的命令列虛擬助手。今天，我偶然發現了一個類似的實用程序，叫做 “Yoda”。Yoda 是一個命令列個人助理，可以幫助您在 Linux 中完成一些瑣碎的任務。它是用 Python 編寫的一個自由開源應用程序。在本指南中，我們將瞭解如何在 GNU/Linux 中安裝和使用 Yoda。

安裝 Yoda，命令列私人助理。 ​

Yoda 需要 Python 2 和 PIP 。如果在您的 Linux 中沒有安裝 PIP，請參考下面的指南來安裝它。只要確保已經安裝了 python2-pip 。Yoda 可能不支持 Python 3。

  • 如何使用 pip 管理 Python 包

注意：我建議你在 Python 虛擬環境下試用 Yoda。 不僅僅是 Yoda，應該總在虛擬環境中嘗試任何 Python 應用程序，讓它們不會干擾全局安裝的軟件包。 您可以按照上文鏈接中標題為“創建虛擬環境”一節中所述設置虛擬環境。

在您的系統上安裝了 pip 之後，使用下面的命令克隆 Yoda 庫。

$ git clone https://github.com/yoda-pa/yoda

上面的命令將在當前工作目錄中創建一個名為 yoda 的目錄，並在其中克隆所有內容。轉到 yoda 目錄：

$ cd yoda/

運行以下命令安裝 Yoda 應用程序。

$ pip install .

請注意最後的點（.）。 現在，所有必需的軟件包將被下載並安裝。

配置 Yoda ​

首先，設置配置以將您的信息保存在本地系統上。

運行下面的命令：

$ yoda setup new

填寫下列的問題：

Enter your name:
Senthil Kumar
What's your email id?
[email protected]
What's your github username?
sk
Enter your github password:
Password:
Where shall your config be stored? (Default: ~/.yoda/)

A configuration file already exists. Are you sure you want to overwrite it? (y/n)
y

你的密碼在加密後保存在配置文件中，所以不用擔心。

要檢查當前配置，請運行：

$ yoda setup check

你會看到如下的輸出。

Name: Senthil Kumar
Email: sk@senthilkumar.com
Github username: sk

默認情況下，您的信息存儲在 ~/.yoda 目錄中。

要刪除現有配置，請執行以下操作：

$ yoda setup delete

用法 ​

Yoda 包含一個簡單的聊天機器人。您可以使用下面的聊天命令與它交互。

$ yoda chat who are you

樣例輸出:

Yoda speaks:
I'm a virtual agent

$ yoda chat how are you
Yoda speaks:
I'm doing very well. Thanks!

以下是我們可以用 Yoda 做的事情：

測試網絡速度 ​

讓我們問一下 Yoda 關於互聯網速度的問題。運行：

$ yoda speedtest
Speed test results:
Ping: 108.45 ms
Download: 0.75 Mb/s
Upload: 1.95 Mb/s

縮短和展開網址 ​

Yoda 還有助於縮短任何網址：

$ yoda url shorten https://www.ostechnix.com/
Here's your shortened URL:
https://goo.gl/hVW6U0

要展開縮短的網址：

$ yoda url expand https://goo.gl/hVW6U0
Here's your original URL:
https://www.ostechnix.com/

閲讀 Hacker News ​

我是 Hacker News 網站的常客。 如果你像我一樣，你可以使用 Yoda 從下面的 Hacker News 網站閲讀新聞。

$ yoda hackernews
News-- 1/513

Title-- Show HN: a Yelp for iOS developers
Description-- I came up with this idea "a Yelp for developers" when talking with my colleagues. My hypothesis is that, it would be very helpful if we know more about a library before choosing to use it. It's similar to that we want to know more about a restaurant by checki…
url-- https://news.ycombinator.com/item?id=16636071

Continue? [press-"y"]

Yoda 將一次顯示一個項目。 要閲讀下一條新聞，只需輸入 y 並按下回車。

管理個人日記 ​

我們也可以保留個人日記以記錄重要事件。

使用命令創建一個新的日記：

$ yoda diary nn
Input your entry for note:
Today I learned about Yoda

要創建新筆記，請再次運行上述命令。

查看所有筆記：

$ yoda diary notes
Today's notes:
----------------
 Time | Note
--------|-----
16:41:41| Today I learned about Yoda

不僅僅是筆記，Yoda 還可以幫助你創建任務。

要創建新任務，請運行：

$ yoda diary nt
Input your entry for task:
Write an article about Yoda and publish it on OSTechNix

要查看任務列表，請運行：

$ yoda diary tasks
Today's agenda:
----------------
Status | Time | Text
-------|---------|-----
 O | 16:44:03: Write an article about Yoda and publish it on OSTechNix
----------------

Summary:
----------------
Incomplete tasks: 1
Completed tasks: 0

正如你在上面看到的，我有一個未完成的任務。 要將其標記為已完成，請運行以下命令並輸入已完成的任務序列號並按下回車鍵：

$ yoda diary ct
Today's agenda:
----------------
Number | Time | Task
-------|---------|-----
 1 | 16:44:03: Write an article about Yoda and publish it on OSTechNix
Enter the task number that you would like to set as completed
1

您可以隨時使用命令分析當前月份的任務：

$ yoda diary analyze
Percentage of incomplete task : 0
Percentage of complete task : 100
Frequency of adding task (Task/Day) : 3

有時候，你可能想要記錄一個關於你愛的或者敬佩的人的個人資料。

記錄關於愛人的筆記 ​

首先，您需要設置配置來存儲朋友的詳細信息。 請運行：

$ yoda love setup

輸入你的朋友的詳細信息：

Enter their name:
Abdul Kalam
Enter sex(M/F):
M
Where do they live?
Rameswaram

要查看此人的詳細信息，請運行：

$ yoda love status
{'place': 'Rameswaram', 'name': 'Abdul Kalam', 'sex': 'M'}

要添加你的愛人的生日：

$ yoda love addbirth
Enter birthday
15-10-1931

查看生日：

$ yoda love showbirth
Birthday is 15-10-1931

你甚至可以添加關於該人的筆記：

$ yoda love note
Avul Pakir Jainulabdeen Abdul Kalam better known as A. P. J. Abdul Kalam, was the 11th President of India from 2002 to 2007.

您可以使用命令查看筆記：

$ yoda love notes
Notes:
1: Avul Pakir Jainulabdeen Abdul Kalam better known as A. P. J. Abdul Kalam, was the 11th President of India from 2002 to 2007.

你也可以寫下這個人喜歡的東西：

$ yoda love like
Add things they like
Physics, Aerospace
Want to add more things they like? [y/n]
n

要查看他們喜歡的東西，請運行：

$ yoda love likes
Likes:
1: Physics, Aerospace

您不需要單獨的工具來維護您的財務支出。 Yoda 會替您處理好。

首先，使用命令設置您的金錢支出配置：

$ yoda money setup

輸入您的貨幣代碼和初始金額：

$ yoda money status

$ yoda money exp

創建想法列表 ​

創建一個新的想法：

$ yoda ideas add --task <task_name> --inside <project_name>

列出想法：

$ yoda ideas show

從任務中移除一個想法：

$ yoda ideas remove --task <task_name> --inside <project_name>

要完全刪除這個想法，請運行：

$ yoda ideas remove --project <project_name>

學習英語詞彙 ​

Yoda 幫助你學習隨機英語單詞並追蹤你的學習進度。

要學習一個新單詞，請輸入：

$ yoda vocabulary word

它會隨機顯示一個單詞。 按回車鍵顯示單詞的含義。 再一次，Yoda 問你是否已經知道這個詞的意思。 如果您已經知道，請輸入“是”。 如果您不知道，請輸入“否”。 這可以幫助你跟蹤你的進度。 使用以下命令來了解您的進度。

$ yoda vocabulary accuracy

此外，Yoda 可以幫助您做其他一些事情，比如找到單詞的定義和創建插卡以輕鬆學習任何內容。 有關更多詳細信息和可用選項列表，請參閲幫助部分。

$ yoda --help

更多好的東西來了。請繼續關注!
