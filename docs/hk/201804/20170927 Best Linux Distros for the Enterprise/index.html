面向企業的最佳 Linux 發行版 ​

在這篇文章中，我將分享企業環境下頂級的 Linux 發行版。其中一些發行版用於服務器和雲環境以及桌面任務。所有這些可選的 Linux 具有的一個共同點是它們都是企業級 Linux 發行版 —— 所以你可以期待更高程度的功能性，當然還有支持程度。

什麼是企業級的 Linux 發行版？ ​

企業級的 Linux 發行版可以歸結為以下內容 —— 穩定性和支持。在企業環境中，使用的 Linux 版本必須滿足這兩點。穩定性意味着所提供的軟件包既穩定又可用，同時仍然保持預期的安全性。

企業級的支持因素意味着有一個可靠的支持機制。有時這是單一的（官方）來源，如公司。在其他情況下，它可能是一個非營利性的治理機構，向優秀的第三方支持供應商提供可靠的建議。很明顯，前者是最好的選擇，但兩者都可以接受。

Red Hat 企業級 Linux（RHEL） ​

Red Hat 有很多很棒的產品，都有企業級的支持來保證可用。其核心重點如下：

  • Red Hat 企業級 Linux 服務器：這是一組服務器產品，包括從容器託管到 SAP 服務的所有內容，還有其他衍生的服務器。
  • Red Hat 企業級 Linux 桌面：這些是嚴格控制的用户環境，運行 Red Hat Linux，提供基本的桌面功能。這些功能包括訪問最新的應用程序，如 web 瀏覽器、電子郵件、LibreOffice 等。
  • Red Hat 企業級 Linux 工作站：這基本上是 Red Hat 企業級 Linux 桌面，但針對高性能任務進行了優化。它也非常適合於大型部署和持續管理。

為什麼選擇 Red Hat 企業級 Linux？ ​

Red Hat 是一家非常成功的大型公司，銷售圍繞 Linux 的服務。基本上，Red Hat 從那些想要避免供應商鎖定和其他相關問題的公司賺錢。這些公司認識到聘用開源軟件專家和管理他們的服務器和其他計算需求的價值。一家公司只需要購買訂閲來讓 Red Hat 做支持工作就行。

Red Hat 也是一個可靠的社會公民。他們贊助開源項目以及像 OpenSource.com 這樣的 FoSS 支持網站（LCTT 譯註：FoSS 是 Free and Open Source Software 的縮寫，意為自由及開源軟件），併為 Fedora 項目提供支持。Fedora 不是由 Red Hat 所有的，而是由它贊助開發的。這使 Fedora 得以發展，同時也使 Red Hat 受益匪淺。Red Hat 可以從 Fedora 項目中獲得他們想要的，並將其用於他們的企業級 Linux 產品中。 就目前來看，Fedora 充當了紅帽企業 Linux 的上游渠道。

SUSE Linux 企業版本 ​

SUSE 是一家非常棒的公司，為企業用户提供了可靠的 Linux 選擇。SUSE 的產品類似於 Red Hat，桌面和服務器都是該公司所關注的。從我自己使用 SUSE 的經驗來看，我相信 YaST 已經證明了，對於希望在工作場所使用 Linux 操作系統的非 Linux 管理員而言，它擁有巨大的優勢。YaST 為那些需要一些基本的 Linux 命令列知識的任務提供了一個友好的 GUI。

SUSE 的核心重點如下：

  • SUSE Linux 企業級服務器（SLES）：包括任務特定的解決方案，從雲到 SAP，以及任務關鍵計算和基於軟件的數據存儲。
  • SUSE Linux 企業級桌面：對於那些希望為員工提供可靠的 Linux 工作站的公司來説，SUSE Linux 企業級桌面是一個不錯的選擇。和 Red Hat 一樣，SUSE 通過訂閲模式來對其提供支持。你可以選擇三個不同級別的支持。

為什麼選擇 SUSE Linux 企業版？ ​

SUSE 是一家圍繞 Linux 銷售服務的公司，但他們仍然通過專注於簡化操作來實現這一目標。從他們的網站到其提供的 Linux 發行版，重點是易用性，而不會犧牲安全性或可靠性。儘管在美國毫無疑問 Red Hat 是服務器的標準，但 SUSE 作為公司和開源社區的貢獻成員都做得很好。

我還會繼續説，SUSE 不會太嚴肅，當你在 IT 領域建立聯繫的時候，這是一件很棒的事情。從他們關於 Linux 的有趣音樂視頻到 SUSE 貿易展位中使用的 Gecko 以獲得有趣的照片機會，SUSE 將自己描述成簡單易懂和平易近人的形象。

Ubuntu LTS Linux ​

Ubuntu Long Term Release （LTS） Linux 是一個簡單易用的企業級 Linux 發行版。Ubuntu 看起來比上面提到的其他發行版更新更頻繁（有時候也更不穩定）。但請不要誤解，Ubuntu LTS 版本被認為是相當穩定的，不過，我認為一些專家可能不太同意它們是安全可靠的。

Ubuntu 的核心重點如下： ​

  • Ubuntu 桌面版：毫無疑問，Ubuntu 桌面非常簡單，可以快速地學習並運行。也許在高級安裝選項中缺少一些東西，但這使得其更簡單直白。作為額外的獎勵，Ubuntu 相比其他版本有更多的軟件包（除了它的父親，Debian 發行版）。我認為 Ubuntu 真正的亮點在於，你可以在網上找到許多銷售 Ubuntu 的廠商，包括服務器、台式機和筆記本電腦。
  • Ubuntu 服務器版：這包括服務器、雲和容器產品。Ubuntu 還提供了 Juju 雲“應用商店”這樣一個有趣的概念。對於任何熟悉 Ubuntu 或 Debian 的人來説，Ubuntu 服務器都很有意義。對於這些人來説，它就像手套一樣，為你提供了你已經熟知並喜愛的命令列工具。
  • Ubuntu IoT：最近，Ubuntu 的開發團隊已經把目標瞄準了“物聯網”（IoT）的創建解決方案。包括數字標識、機器人技術和物聯網網關。我的猜測是，我們將在 Ubuntu 中看到大量增長的物聯網用户來自企業，而不是普通家庭用户。

為什麼選擇 Ubuntu LTS？ ​

社區是 Ubuntu 最大的優點。除了在已經擁擠的服務器市場上的巨大增長之外，它還與普通用户在一起。Ubuntu 的開發和用户社區是堅如磐石的。因此，雖然它可能被認為比其他企業版更不穩定，但是我發現將 Ubuntu LTS 安裝鎖定到 “security updates only” 模式下提供了非常穩定的體驗。

CentOS 或者 Scientific Linux 怎麼樣呢？ ​

首先，讓我們把 CentOS 作為一個企業發行版，如果你有自己的內部支持團隊來維護它，那麼安裝 CentOS 是一個很好的選擇。畢竟，它與 Red Hat 企業級 Linux 兼容，並提供了與 Red Hat 產品相同級別的穩定性。不幸的是，它不能完全取代 Red Hat 支持訂閲。

那麼 Scientific Linux 呢？它的發行版怎麼樣？好吧，它就像 CentOS，它是基於 Red Hat Linux 的。但與 CentOS 不同的是，它與 Red Hat 沒有任何隸屬關係。 Scientific Linux 從一開始就有一個目標 —— 為世界各地的實驗室提供一個通用的 Linux 發行版。今天，Scientific Linux 基本上是 Red Hat 減去所包含的商標資料。

這兩種發行版都不能真正地與 Red Hat 互換，因為它們缺少 Red Hat 支持組件。

哪一個是頂級企業發行版？我認為這取決於你需要為自己確定的許多因素：訂閲範圍、可用性、成本、服務和提供的功能。這些是每個公司必須自己決定的因素。就我個人而言，我認為 Red Hat 在服務器上獲勝，而 SUSE 在桌面環境中輕鬆獲勝，但這只是我的意見 —— 你不同意？點擊下面的評論部分，讓我們來談談它。
