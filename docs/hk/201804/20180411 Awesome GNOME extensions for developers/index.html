開發者的最佳 GNOME 擴展 ​

擴展給予 GNOME3 桌面環境以非常大的靈活性，這種靈活性賦予了用户在定製化桌面上的優勢，從而使他們的工作流程變得更加舒適和有效率。Fedora Magazine 已經介紹了一些很棒的桌面擴展，例如 EasyScreenCast、 gTile 和 OpenWeather ，本文接下來會重點報道這些為開發者而改變的擴展。

如果你需要幫助來安裝 GNOME 擴展，那麼可以參考《如何安裝一個 GNOME Shell 擴展》這篇文章。

Docker 集成（Docker Integration） ​

對於為自己的應用使用 Docker 的開發者而言，這個 Docker 集成 擴展是必不可少的。這個狀態菜單提供了一個帶着啓動、停止、暫停、甚至刪除它們的選項的 Docker 容器列表，這個列表會在新容器加入到這個系統時自動更新。

在安裝完這個擴展後，Fedora 用户可能會收到這麼一條消息：“Error occurred when fetching containers.（獲取容器時發生錯誤）”。這是因為 Docker 命令默認需要 sudo 或 root 權限。要設置你的用户權限來運行 Docker，可以參考 Fedora 開發者門户網站上的 Docker 安裝這一頁。

你可以在該擴展的站點上找到更多的信息。

Jenkins CI 服務器指示器（Jenkins CI Server Indicator） ​

Jenkins CI 服務器指示器這個擴展可以使開發者在 Jenkins CI 服務器建立應用很簡單，它展示了一個菜單，包含有任務列表及那些任務的狀態。它也包括了一些如輕鬆訪問 Jenkins 網頁前端、任務完成提示、以及觸發和過濾任務等特性。

如果想要更多的信息，請去瀏覽開發者站點。

安卓工具（android-tool） ​

安卓工具對於 Android 開發者來説會是一個非常有價值的擴展，它的特性包括捕獲錯誤報告、設備截屏和屏幕錄像。它可以通過 usb 和 tcp 連接兩種方式來連接 Android 設備。

這個擴展需要 adb 的包，從 Fedora 官方倉庫安裝 adb 只需要運行這條命令：

sudo dnf install android-tools

你可以在這個擴展的 GitHub 網頁裏找到更多信息。

GnomeHub ​

對於自己的項目使用 GitHub 的 GNOME 用户來説，GnomeHub 是一個非常好的擴展，它可以顯示 GitHub 上的倉庫，還可以通知用户有新提交的拉取請求。除此之外，用户可以把他們最喜歡的倉庫加在這個擴展的設置裏。

如果想要更多信息，可以參考一下這個項目的 GitHub 頁面。

gistnotes ​

簡單地説，gistnotes 為 gist 用户提供了一種創建、存儲和管理註釋和代碼片段的簡單方式。如果想要更多的信息，可以參考這個項目的網站。

Arduino 控制器（Arduino Control） ​

這個 Arduino 控制器擴展允許用户去連接或者控制他們自己的 Arduino 電路板，它同樣允許用户在狀態菜單裏增加滑塊或者開關。除此之外，開發者放在擴展目錄裏的腳本可以通過以太網或者 usb 來連接 Arduino 電路板。

最重要的是，這個擴展可以被定製化來適合你的項目，在器 README 文件裏的提供例子是，它能夠“通過網絡上任意的電腦來控制你房間裏的燈”。

你可以從這個項目的 GitHub 頁面上得到更多的產品信息並安裝這個擴展。

Hotel Manager ​

使用 Hotel 進程管理器開發網站的開發人員，應該嘗試一下 Hotel Manager 這個擴展。它展示了一個增加到 Hotel 裏的網頁應用的列表，並給與了用户開始、停止和重啓這些應用的能力。此外，還可以通過右邊的電腦圖標快速打開、瀏覽這些網頁應用。這個擴展同樣可以啓動、停止或重啓 Hotel 的後台程序。

本文發佈時，GNOME 3.26 版本的 Hotel Manager 版本 4 沒有在該擴展的下拉式菜單裏列出網頁應用。版本 4 還會在 Fedora 28 (GNOME 3.28) 上安裝時報錯。然而，版本 3 工作在 Fedora 27 和 Fedora 28。

如果想要更多細節，可以去看這個項目在 GitHub 上的網頁。

VSCode 搜索插件（VSCode Search Provider） ​

VSCode 搜索插件是一個簡單的擴展，它能夠在 GNOME 綜合搜索結果裏展示 Visual Studio Code 項目。對於重度 VSCode 用户來説，這個擴展可以讓用户快速連接到他們的項目，從而節省時間。你可以從這個項目在 GitHub 上的頁面來得到更多的信息。

在開發環境方面，你有沒有一個最喜歡的擴展呢？發在評論區裏，一起來討論下吧。
