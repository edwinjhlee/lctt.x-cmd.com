Godot 4.2 發佈：讓開源遊戲引擎更上一層樓 ​

Godot 的又一次更新，其中包含了一些有用的更改，以更接近 Unreal、Unity 等專有引擎。

Godot，社區最喜歡的 Unreal 和 Unity 等專有遊戲引擎的替代品，有一個新的重大更新！

Godot 4.2 “閃亮登場”，全面更新大量內容。它繼續沿着 Godot 4.0 版本 鋪平的道路，並在此基礎上進行構建。

拿上你的飲料，讓我來重點介紹一下這次發佈的優點。☕

Godot 4.2：有什麼新內容？ ​

Godot 4.2 版本有很多新東西。但是，我們將關注關鍵亮點：

  • Linux 上的官方 ARM 支持
  • 編輯器改進
  • 更多版本控制友好
  • 增強的圖塊地圖
  • 多人遊戲/網絡的改進
  • 更好的導航系統

Linux 上的官方 ARM 支持 ​

儘管可以在 Linux 上為基於 ARM 的設備手動構建 Godot，但從來沒有針對 Linux 的官方 ARM 構建。

然而，隨着 Godot 4.2 的發佈，這種情況發生了變化。他們在下載頁面上提供了 32 位和 64 位版本的 Godot for ARM。

請記住，這是一項實驗性工作，因此可能會出現錯誤和問題。

編輯器改進 ​

Godot 的編輯器方面有很多改進。

如上面的截圖所示，第一個是代碼編輯器中的新添加項，名為“創建代碼區域Create Code Region”。它允許你將腳本分解為命名塊，然後可以將其最小化以減少混亂。

Godot 的另一個新功能是能夠在編輯器視口中單獨擴展方框圖形的每一側。以前，這僅限於中心點和對稱範圍。

項目管理器也進行了更新，改進了一般項目導入工作流程，並重新排列了按鈕。

更多版本控制友好 ​

Godot 4.2 修復了在“就緒”期間更改場景或重命名節點會導致崩潰的問題，還修復了與重命名/移動文件相關的各種問題。

開發人員還補充道：

此外，場景中資源 ID 偶爾更改的一些情況已得到解決（GH-65011）。仍有改進的空間，但這已經使 4.2 的版本控制更加友好。

增強的圖塊地圖 ​

除了 Godot 的圖塊/圖塊地圖系統的主要性能優化之外，還有一項新功能允許你在將圖塊/圖塊圖案放置在任何地方時旋轉或翻轉它們。

多人遊戲/網絡的改進 ​

此版本還具有高級多人遊戲系統的改進。“MultiplayerSynchronizer” 節點現在支持同步變換組件、子資源屬性和其他類型的索引數據。

還有針對拒絕服務漏洞的安全修復，該漏洞之前在 Godot 4.0.4 RC1 版本中已披露。

📋 開發人員建議用户升級到 Godot 4.0.4、4.1.2 或 4.2 以避免出現問題。

更好的導航系統 ​

Godot 4.2 帶來了 2D 導航網格烘焙，它可以處理物理體、網格實例、普通多邊形等。

此外，添加了對 2D 和 3D 導航網格烘焙的多線程支持，以提高性能並減少卡頓。

🛠️ 其他更改和改進 ​

還有許多其他值得注意的變化：

  • 改進了 GDExtension 系統。
  • 支持 AMD 的 FSR 2.2 技術。
  • 圖形構建節點的重大修改。
  • 適用於 Linux、Windows 和 macOS 的原生文件選擇對話框。
  • 現在可以為附加組件和資產指定不同的安裝文件夾。
  • 修復了 Steam 輸入問題，該問題導致某些遊戲手柄事件被處理兩次。

有關此版本的更多詳細信息，你可以通過 官方發行説明 瞭解。
