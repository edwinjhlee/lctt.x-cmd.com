Celeste：Rust 開發的多雲端開源 GUI 文件同步客户端 ​

一個簡單而優雅的 GUI 同步客户端，提供雙向同步。

當談到與雲文件同步時，我們有 Insync、FreeFileSync 等選項，以及 rclone 等幾個命令列工具。

無論哪種情況，你也可以使用雲存儲提供商的同步客户端（如果他們有適用於 Linux 或任何其他平台的同步客户端）。但是，這並不是與多個雲存儲服務同步內容的最佳方式。

Insync 是一款付費工具，而 FreeFileSync 或 rclone 對於 Linux 新用户來説可能是一種難以接受的選擇。。

Celeste，一個簡單的 GUI 同步客户端，支持多個雲提供商。

📋 該應用正在積極開發中。目前它可能沒有足夠的功能和貢獻者。歡迎你探索並幫助該項目。

適用於 Linux 的基於 Rust 的同步客户端 ​

Celeste 是一款用 Rust 編寫的應用，可確保你獲得快速的體驗。它在底層利用 rclone 來可靠地將數據與雲同步。

與某些現有選項不同，它沒有為你提供很多選擇。雖然一些用户可能會發現它有所欠缺，但其他用户可能會發現它是他們一直想要的簡單工具。

Celeste 僅支持雙向同步，目前沒有其他同步方式。

如果你想要單向同步（雲到本地，或本地到雲），那麼這不適合你。

該工具的工作機制很簡單。你只需從列表中添加雲提供商，或添加任何 WebDAV 服務器。

默認選項包括：Google Drive、Dropbox、Proton Drive、pCloud、ownCloud、 和 Nextcloud。

你可以自定義該工具的服務器名稱，然後點擊“登錄Log in”開始授權過程。pCloud 的情況如下：

當你授權應用訪問雲文件，它會提示你設置本地文件夾和雲之間的同步。

如果還沒有正斜槓（/） 符號，那麼只需輸入它即可，它應該開始以下拉樣式列出你擁有的遠程文件夾。

💡 這將是雙向同步。因此，你的雲文件將被下載到遠程文件夾（如果有）。同步後，從雲中刪除的任何內容都不會從本地文件夾中消失。而且，你從系統中刪除的任何內容都將從雲中刪除。

此同步過程定期發生。 我沒有找到強制啓動或停止同步的方法。如果此應用的未來版本中提供類似的選項，它應該會有所幫助。

在大多數情況下，每當本地/遠程中發生文件更改時，同步都會確保你能夠儘快訪問最新的更改。

有一次，很長一段時間沒有同步，所以我不得不重新啓動應用來修復它。

不幸的是，如果雲提供商的令牌過期，該應用不能很好地處理錯誤，並且你必須重新授權和重新同步。

它會顯示錯誤，但沒有使用 GUI 刷新令牌的選項。我不想嘗試命令列方式，因為這違背了 GUI 工具的目的。

因此，你可以選擇再次重新添加相同的同步服務器，重新進行所有授權和同步。這就是目前的解決方案。

總結 ​

Celeste 似乎是一個非常有用且簡單的 GUI 同步客户端。

儘管它缺乏某些功能，但用户體驗對於它已經提供的功能來説還是很好的。

考慮到它是一個相當新的應用，有更多的貢獻者和用户嘗試它，Celeste 可以憑藉其堅實的基礎發展成更多的東西。
