Jami：一款多功能開源分佈式通訊應用 ​

下面將引導你安裝和使用 Jami，讓你對其工作原理和你能從中獲取的內容有更深入的理解。

不管你是為了聯繫親愛的人，還是為了職業需求與同事/團隊溝通，一個安全的通訊平台都是大家的需求。Jami 就是其中一款通訊平台，利用分佈式網絡來實現視頻通話、文件分享、聊天等功能全都不經過服務器。

這個工具完全免費且開源，具有多樣的功能。

然而，它的表現如何呢？用户體驗會好麼？使用體驗能像其他已有的專有平台那麼流暢麼？或者，你能在手機上使用嗎？

在這篇文章裏，我們將仔細研究 Jami。我們試用了一下以助你作出更明智的決定。

Jami 的特性 ​

對很多用户來説，體驗的好壞取決於功能的全面性。

所以，在深入研究 Jami 之前，讓我概述一下，你可以期待從它得到什麼樣的功能：

  • 即時發送消息
  • 羣聊
  • 視頻會議
  • 音頻通話
  • 音頻和視頻信息
  • 屏幕共享
  • 文件分享
  • 增強功能的擴展
  • 作為 SIP（會話啓動協議）客户端

看起來，Jami 是一款在考慮分佈式解決方案時值得考慮的全能選項。

聽上去挺刺激的，對吧？

那我們現在就來細看一下，看看它是如何工作的，以及我們能從中獲得什麼。

使用 Jami 的入門步驟 ​

在你的系統上安裝 Jami 是相當簡單的。

你可以直接從它的網站下載最新的官方版本，或者直接在你的包管理器中（對於 Linux）搜索它。

它可以跨平台使用，包括：Linux、Windows、macOS、安卓和 iOS。

對於安卓用户，你可以在 Play Store 或 F-Droid 中安裝。至本文撰寫之時，Jami 支持所有最新和最棒的操作系統版本，所以，從這個層面上看，它的維護工作做得相當好。

在安裝完成之後，就開始了註冊過程。不像其他一些平台，它並不需要任何私人信息，只需要你創建一個你喜歡的獨特用户名。

完成之後，你只需要把這個用户名與其他用户分享，就可以開始對話了。你也可以展現出 QR 碼讓其他人連接你。就是這麼簡單。

在註冊時，你可以選擇加密你的帳户，以在設備上保護它，並自定義顯示名。

使用 Jami 作為通訊平台 ​

使用這類平台時，我們的首要關心點通常是發送 / 接收消息的響應速度，以及語音 / 視頻通話的質量。

好消息是：使用體驗快捷順暢。不管你是要發送一個視頻信息，進行一個音頻通話，還是發送文本，Jami 都像你想像的一樣響應靈敏。

當我們談及 用户界面，每個人的看法可能都會不同。我發現它的用户界面簡明扼要，乾淨利落。

然而，當你調窄應用窗口的寬度時，事情可能會有所不同。它失去了適應較小尺寸的能力，忽視了重要的元素，甚至難以順暢地訪問設置，這降低了使用體驗。

不要誤會，你仍可以正常導航至所有選項。然而，體驗感會顯得有些生硬。

當把 Jami 的窗口縮小時，我點擊了“設置Settings”，結果直接進入了“賬户管理Manage Account”選項，而沒有給我任何下拉菜單，也沒有為我打開“賬户Accounts”/“一般General”或“音頻/視頻Audio/Video”部分。

假設我想要進入“音頻/視頻”設置，我就會進入賬户設置。接下來，我需要再次導航到其他設置。這並不是一個讓人感到方便的體驗。

如果你不會經常調小 Jami 的窗口，或者你更喜歡大一點的窗口，那麼你應該不會遇到此類問題。總結一下，如果你希望所有東西都有現代化的設計風格，那它可能會有些失望。

當你第一次發送/接收文本或通話時，會被視作一次邀請。一旦你接受了邀請，用户就會出現在你的會話列表中。

發送短信，添加新朋友的體驗是無縫連接的，我沒有遇到任何問題。

📋 在撰寫本文時進行的最新版本測試中，我無法關閉捐款消息。我答覆的同事也遇到這個問題。

在信息中，你會有標記“正在輸入中”的提示，你也可以回覆一個特定的消息，用一個表情符號做出反應，附加文件，或發送語音或者視頻消息。

這些消息都可以被編輯和刪除。

上面的對話截圖是一個通過選擇多個用户創建的羣聊。

這樣，當你創建這樣的羣聊時，一個新的邀請會被髮送到用户那裏，這是好的（不是強制他們加入羣聊）。如果他們接受了邀請，他們就能加入你創建的羣聊。

默認情況下，創建羣組的設備將會默認承載羣組內的任何音頻 / 視頻通話。

如果你連接的賬户有多個設備，你可以選擇你想要作為主機的那個設備。

通話體驗有些不盡人意，具體來説，音頻通話體驗十分出色，音頻清晰。

然而，視頻通話的音頻方面就有些令人失望。

當然了，用直連的方式，視頻質量會嚴重依賴網絡連接，然而，和網絡連接相比，我們得到的質量並沒有那麼好。（主機是我，網速是 200 Mbps）。

視頻質量可能是由於優化不佳或網絡不佳導致的，但是，雙方的音頻並不清晰，音量在整個通話中都在上下波動。

雖然我的一些同事能分享他們的屏幕，但是在帶有 AMD Radeon 集成 GPU 的 Ubuntu 22.04 LTS 上，應用崩潰了。

默認情況下，你無法添加綠幕效果，這和一些專有的視頻通話應用不同。然而，你可以安裝擴展增加此類功能。

另外，為了增強你的體驗，你可以調整通話設置，包括自動接聽電話，將你的賬户作為接入點，切換正在輸入中的指示等。

總結 ​

如果 Jami 能在現代化用户界面這方面投入更多努力，那麼它應該能成為像微軟 Teams、Slack 和 Zoom 這樣的應用的熱門選擇。

當然了，因為 P2P 連接原因，視頻質量可能不如其他專有選項那麼穩定。但在音頻通話、視頻/音頻信息、文字輸入、文件發送等方面你應該不會有任何問題，同時享受私密的通訊體驗。

總的來説，Jami 為你提供了所有基本的需求，在一個更快的體驗上提供了基本的用户界面。

探究 Jami

它可能不能給你最好的用户體驗，但是考慮到它在分佈式網絡連接、開源應用和隱私保護方面的優勢，對於注重隱私的用户來説，它仍是個極好的選擇。
