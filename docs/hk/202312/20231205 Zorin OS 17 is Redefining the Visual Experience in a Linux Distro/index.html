Zorin OS 17 正在重新定義 Linux 發行版的視覺體驗 ​

這款即將推出的 Zorin OS 17 能為你帶來什麼樣的視覺盛宴？你有何感想？

作為公認 最美的 Linux 發行版 之一，Zorin OS 的下一輪升級近在眼前。

在正式推出之前，他們已經公開了 Zorin 17 的各項新功能和首個測試版的發佈時間。

那麼，讓我們一起來探索 Zorin 17 的新增內容吧。

Zorin OS 17：最好的部分 ​

Zorin OS 17 將成為一個主要版本，它是一個長期支持版本（直到 2027 年 6 月），並且包含許多令人興奮的新改進。

據開發人員稱，Zorin OS 17 的設計初衷是為他們提供“迄今為止最卓越且最精緻的計算體驗”，而且這一説法似乎有理有據。

比如，Zorin OS 17 引入了“空間桌面”的設計理念，用以提升用户對於桌面活動的認知。

在 Zorin OS 17 的測試版中，展現出了新穎的 “桌面立方體” 效果，用户可以通過富有深度感的 3D 立方視角在工作區之間切換。它運用了視差效果，使應用窗口呈現出獨特的懸浮感。

此外，還引入了全新的 “空間窗口切換器”，以整潔的 3D 切換效果替代了標準的平面 / 2D 的 Alt+Tab 和 Super+Tab 窗口切換。

在我看來，這些看起來確實不錯。然而，這些效果可能不是每個人都喜歡，好在默認情況下這些“空間特性”是不啓用的。

儘管如此，這確實是大膽的一步。Linux 發行版引入了更多的視覺交互特性，這實在不常見。鑑於 Zorin OS 原本就是顏值出眾的發行版，新的多任務處理流程和空間桌面無疑將其視覺體驗提升了一個檔次。

macOS 用户或 Windows 用户可能不喜歡典型的 Linux 發行版用户界面，他們可能會考慮嘗試使用 Zorin OS 的可視化方法來使用 Linux。

雖然這可能並不是科技突破，但我堅信，它對於把視覺體驗視為優先的大量用户來説，其改變是實實在在的。

與此同時，Zorin OS 依然保持了驕人的核心優勢——“賦予用户對自己體驗的掌控”。看得出，他們將這些視覺元素融入進去，並使得計算體驗充滿了樂趣。

你必須從 Zorin 外觀Appearance 設置下的新“效果Effects”部分手動啓用這些功能。

然後是高級窗口平鋪體驗，這是社區最需要的功能之一。

現在，你可以輕鬆實現窗口在屏幕四分之一角落的平鋪，甚至可以用鍵盤快捷鍵調整窗口在屏幕上的排布。這使得無痛的多任務處理變得觸手可及。

甚至軟件商店也進行了改進，速度更快，並採用了新設計和更新的主頁，以非常直觀的方式列出了應用。應用詳細信息頁面也得到了改進，以顯示更大的截圖和新信息。

同樣，引入了新的快速設置菜單，使你可以方便地訪問重要設置，並且允許你使用新的電源模式選項（性能/平衡）調整系統性能。電源模式應該對筆記本電腦用户有幫助。

開發人員還展示了一種新的截圖和屏幕錄製工具，如果你使用過 GNOME 的原生工具，那用這個工具會讓你感覺非常得心應手。

他們還提到了兩種新的桌面佈局，一種是類似 ChromeOS 佈局，另一種是類似 GNOME 2 佈局。

這些佈局將在 Zorin OS 17 Pro 發佈時提供。

總的來説，看到 Zorin OS 在追求的高質量用户體驗，這的確是 Linux 發行版中少有的。這應當能讓 Zorin 在眾多發行版中脱穎而出，並有可能吸引更多的 Windows 和 macOS 用户嘗試 Linux。

有關即將發佈的 Zorin OS 17 版本的更多詳細信息，你可以參考 官方Blog。
