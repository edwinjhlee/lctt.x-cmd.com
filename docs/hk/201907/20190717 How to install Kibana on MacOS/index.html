如何在 MacOS 上安裝 Kibana ​

Elasticsearch 當安裝好了之後，Kibana 插件可以為這個功能強大的搜索工具添加可視化功能。

在我之前的文章中，我向 Mac 用户介紹了安裝 Elasticsearch 的步驟，這是世界上最受歡迎的企業級搜索引擎。（這裏有一篇針對 Linux 用户的單獨文章。）其自然語言處理能力使得 Elasticsearch 在數據集中查找細節方面表現出色。一旦你發現了你需要的數據，如果你已經安裝了 Kibana，你可以將它提升到一個新的水平。

Kibana 是 Elasticsearch 的開源的數據可視化插件。當你在 Elasticsearch 中找到了數據，Kibana 就會幫助你將其放入折線圖、時間序列查詢、地理空間地圖等。該工具非常適合於必須展示其研究成果的數據科學家，尤其是那些使用開源數據的人。

安裝 Kibana ​

你需要在 Elasticsearch 之外單獨安裝 Kibana。因為我安裝了 Elasticsearch 7.1.1，所以我將安裝 Kibana 1.1。版本的匹配非常重要，Kibana 需要針對相同版本的 Elasticsearch 節點運行。 （Kibana 運行在 node.js 上。）

以下是我為 MacOS 安裝 Kibana 7.1.1 時所遵循的步驟：

1、確保 Elasticsearch 已下載並運行。如果需要，請參閲上一篇文章。

注意：你至少需要先安裝 Elasticsearch 1.4.4 或更高版本才能使用 Kibana。這是因為你需要向 Kibana 提供要連接的 Elasticsearch 實例的 URL 以及你要搜索的 Elasticsearch 索引。通常，最好安裝兩者的最新版本。

2、單擊此處下載 Kibana。你將看到如下的網頁，它會提示你在下載部分的右上角下載 Kibana for Mac：

3、在你的 Downloads 文件夾中，打開 .tar 文件以展開它。此操作將創建一個具有相同名稱的文件夾（例如，kibana-7.1.1-darwin-x86_64）。

4、如果你希望 Kibana 放在另一個文件夾中，請立即移動它。

仔細檢查 Elasticsearch 是否正在運行，如果沒有，請在繼續之前啓動它。（如果你需要説明，請參閲上一篇文章。）

打開 Kibana 插件 ​

Elasticsearch 運行起來後，你現在可以啓動 Kibana 了。該過程類似於啓動 Elasticsearch：

1、從 Mac 的 Downloads 文件夾（或 Kibana 移動到的新文件夾）裏，打開 Kibana 文件夾（即 ~Downloads/kibana-7.1.1-darwin-x86_64）。

2、打開 bin 子文件夾。

3、運行 kibana-plugin。你可能會遇到上一篇文章中出現的相同安全警告：   

通常，如果收到此警告，請按照那篇文章中的説明清除警告並打開 Kibana。請注意，如果我在終端中沒有運行 Elasticsearch 的情況下打開該插件，我會收到相同的安全警告。要解決此問題，如上一篇文章中所述，打開 Elasticsearch 並在終端中運行它。使用 GUI 啓動 Elasticsearch 也應該打開終端。

然後，我右鍵單擊 kibana-plugin 並選擇“打開”。這個解決方案對我有用，但你可能需要嘗試幾次。 我的 Elasticsearch 聚會中的幾個人在他們的設備上打開 Kibana 時遇到了一些麻煩。

總結 ​

Elasticsearch 和 Kibana 是佔用大量存儲空間的大型軟件包。有這麼多人一次下載這兩個軟件包，當我的Elasticsearch 會員和我下載它們兩個時，我平均要下載幾分鐘。這可能是由於 WiFi 不佳和/或用户數量太多，但如果發生同樣的事情，請記住這種可能性。

之後，由於我的筆記本電腦存儲空間不足，我無法上傳我們正在使用的 JSON 文件。我能夠按照講師的可視化進行操作，但無法實時使用 Kibana。因此，在下載 Elasticsearch 和 Kibana 之前，請確保設備上有足夠的空間（至少幾千兆字節）來上傳和使用這些工具搜索文件。

要了解有關 Kibana 的更多信息，他們的用户指南簡介是理想的。（你可以根據你正在使用的 Kibana 版本配置該指南。）他們的演示還向你展示瞭如何在幾分鐘內構建儀表板，然後進行首次部署。

玩得開心！
