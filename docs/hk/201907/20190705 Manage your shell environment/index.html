管理你的 shell 環境 ​

前段時間，Fedora Magazine 發表了一篇 介紹 ZSH 的文章，它是 Fedora 默認的 bash shell 的替代品。這一次，我們將着重定製它來更有效地使用它。本文中顯示的所有概念也適用於其他 shell，例如 bash。

別名 ​

別名是命令的快捷方式。為那些需要經常執行，但需要很長時間輸入的長命令創建快捷方式很有用。語法是：

$ alias yourAlias='complex command with arguments'

它們並不總是用來縮短長命令。重要的是，你將它們用於你經常執行的任務。可能的例子：

$ alias dnfUpgrade='dnf -y upgrade'

這樣，為了進行系統升級，我只需輸入 dnfUpgrade 而不用輸入完整的 dnf 命令。

在終端中設置別名的問題是，一旦終端會話關閉，別名就會丟失。要永久設置它們，請使用資源文件。

資源文件 ​

資源文件（即 rc 文件）是在會話或進程開始時（每個用户在開啓新終端窗口或啓動 vim 等新程序時）加載的配置文件。對於 ZSH，資源文件是 .zshrc，對於 bash，它是 .bashrc。

要使別名成為永久別名，你可以將它們放入資源文件中。你可以使用你選擇的文本編輯器編輯資源文件。這裏使用 vim：

$ vim $HOME/.zshrc

或者對於 bash：

$ vim $HOME/.bashrc

請注意，資源文件的位置是相對於家目錄指定的。這是 ZSH（或 bash）默認為每個用户查找該文件的位置。

還有一種是將你的配置放在任何其他文件中，然後讀取它：

$ source /path/to/your/rc/file

同樣，在會話中直接讀取它只會將其應用於會話，因此要使其永久化，請將 source 命令添加到資源文件中。將文件放在不同位置的優點是你可以隨時讀取它。這在共享環境中很有用。

環境變量 ​

環境變量是分配了特定名稱的值，你可以在腳本和命令中調用它們。它們以美元符號（$）開始。其中最常見的是指向主目錄的 $HOME。

顧名思義，環境變量是你環境的一部分。使用以下語法設置變量：

$ http_proxy="http://your.proxy"

要使其成為環境變量，請使用以下命令將其導出：

$ export $http_proxy

要查看當前設置的所有環境變量，請使用 env 命令：

$ env

該命令輸出會話中可用的所有變量。要演示如何在命令中使用它們，請嘗試運行以下 echo 命令：

$ echo $PWD
/home/fedora
$ echo $USER
fedora

這裏發生了變量擴展，即存儲在變量中的值在命令中使用。

另一個有用的變量是 $PATH，它定義了 shell 查找二進制文件的目錄。

$PATH 變量 ​

有許多對於操作系統很重要的目錄或文件夾（在圖形環境中調用它們的方式）。某些目錄設置為保存可直接在 shell 中使用的二進制文件。這些目錄在 $PATH 變量中定義。

$ echo $PATH
/usr/lib64/qt-3.3/bin:/usr/share/Modules/bin:/usr/lib64/ccache:/usr/local/bin:/usr/bin:/bin:/usr/local/sbin:/usr/sbin:/usr/libexec/sdcc:/usr/libexec/sdcc:/usr/bin:/bin:/sbin:/usr/sbin:/opt/FortiClient

當你希望在 shell 中訪問自己的二進制文件（或腳本）時，這會有幫助。
