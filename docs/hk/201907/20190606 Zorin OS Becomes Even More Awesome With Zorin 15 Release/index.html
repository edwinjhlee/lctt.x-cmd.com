隨着 Zorin 15 的發佈，Zorin OS 變得更為強大 ​

長久以來 Zorin OS 一直在 初學者適用的Linux發行版排行 中佔有一席之地。的確，它可能不是最受歡迎的，但是對於從 Windows 陣營轉向 Linux 的用户而言，它一定是最好的一個發行版。

我還記得，在幾年前，我的一位朋友一直堅持讓我安裝 Zorin OS。就我個人而言，當時我並不喜歡它的 UI 風格。但是，現如今 Zorin OS 15 發佈了，這也讓我有了更多的理由安裝並將它作為我日常的操作系統。

不要擔心，在這篇文章裏，我會向你介紹你所需要了解的一切。

Zorin 15 中的新特性 ​

讓我們來看一下最新版本的 Zorin 有哪些主要的改變。Zorin 15 是基於 Ubuntu 18.04.2 的，因此帶來了許多性能上的提升。除此之外，也有許多 UI（用户界面）的改進。

Zorin Connect ​

Zorin OS 15 最主要的一個亮點就是 —— Zorin Connect。如果你使用的是安卓設備，那你一定會喜歡這一功能。類似於 PushBullet（LCTT 譯註：PushBullet，子彈推送，一款跨平台推送工具）， Zorin Connect 會提升你的手機和桌面一體化的體驗。

你可以在桌面上同步智能手機的通知，同時還可以回覆它。甚至，你可以回覆短信並查看對話。

總的來説，你可以體驗到以下功能：

  • 在設備間分享文件或鏈接
  • 將你的手機作為電腦的遙控器
  • 使用手機控制電腦上媒體的播放，並且當有來電接入時自動停止播放

正如他們在官方公告中提到的, 數據的傳輸僅限於本地網絡之間，並且不會有數據被上傳到雲端服務器。通過以下操作體驗 Zorin Connect ，找到：Zorin menu （Zorin 菜單） > System Tools （系統工具） > Zorin Connect。

新的桌面主題（包含夜間模式！） ​

一提到 “夜間模式” 我就毫無抵抗力。對我而言，這是Zorin OS 15 自帶的最好的功能。

當我啓用了界面的深色模式時，我的眼睛感到如此舒適，你不想來試試麼？

它不單單是一個深色的主題，而是 UI 更乾淨直觀，並且帶有恰到好處的新動畫。你可以從 Zorin 內置的外觀應用程序裏找到所有的相關設置。

自適應背景調整 & 深色淺色模式 ​

你可以選擇讓桌面背景根據一天中每小時的環境亮度進行自動調整。此外，如果你想避免藍光給眼睛帶來傷害，你可以使用夜間模式。

代辦事項應用 ​

我一直希望支持這個功能，這樣我就不必使用其他 Linux 客户端程序來添加任務。很高興看到內置的應用程序集成並支持谷歌任務和 Todoist。

還有更多麼？ ​

是的！其他主要的變化包括對 Flatpak 的支持，支持平板筆記本二合一電腦的觸摸佈局，DND 模式，以及一些重新設計的應用程序（設置、Libre Office），以此來給你更好的用户體驗。

如果你想要了解所有更新和改動的詳細信息，你可以查看官方公告。如果你已經是 Zorin 的用户，你應該已經注意到他們的網站也已經啓用了一個全新的外觀。

下載 Zorin OS 15 ​

註釋 : 今年的晚些時候將會推出從 Zorin OS 12 直升 15 版本而不需要重新安裝的升級包。

提示一下，Zorin OS 有三個版本：旗艦版本、核心板和輕量版。

如果你想支持開發者和項目，同時解鎖 Zorin OS 全部的功能，你可以花 39 美元購買旗艦版本。

如果你只是想要一些基本功能，核心版就可以了（你可以免費下載）。如果是這種情況，比如你有一台舊電腦，那麼你可以使用輕量版。
