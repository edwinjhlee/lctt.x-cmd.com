Epic Games 給予 Blender 基金會 120 萬美元的撥款支持 ​

Epic MegaGrants 是 Epic Games 的一個計劃，用於支持遊戲開發人員、企業專業人士、內容創建者和工具開發人員使用虛幻引擎Unreal Engine（UE）做出神奇的作品或增強 3D 圖形社區的開源功能。

作為該計劃的一部分，Epic Games 給予 Blender 基金會 120 萬美元撥款以幫助改善他們的發展。如果你還不知道，Blender 是最好的開源視頻編輯之一，特別是以創建專業的 3D 計算機圖形而聞名。

Tim Sweeney（Epic Games 的創始人兼首席執行官）這樣評論這筆授予：

“開放式工具、庫和平台對數字內容生態系統的未來至關重要。……Blender 是藝術社區持久的資源，我們的目標是確保其進步，造福所有創作者。”

即使這是個好消息，也有人對此不滿意。在本文中，我們將看一下得到該撥款後的 Blender 基金會的計劃，以及人們對此的看法。

Blender 基金會的改進計劃 ​

在新聞稿當中，Blender 基金會提到了如何利用這筆資金以及用於何種目的：

“Epic MegaGrant 將在未來三年內逐步交付，並將為 Blender 的專業 Blender 發展計劃Professionalizing Blender Development Initiative做出貢獻。”

所以，沒錯，這筆財務幫助將以現金提供 —— 但是，它要在 3 年內完成。也就是説，我們要期待 Blender 基金會及其軟件質量得到重大改進還有很長時間。

這是 Ton Roosendaal（Blender 基金會的創始人）需要説明的它將如何被利用：

“Epic Games 的支持對 Blender 是一個重要里程碑，”Blender 基金會的創始人兼董事長 Ton Roosendaal 説道。“由於這項撥款，我們將對我們的項目組織進行大量投入，以改善支持、協作和代碼質量實踐。因此，我們期望更多來自該行業的貢獻者加入我們的項目。”

為什麼人們對此不是很喜歡？ ​

讓我澄清一下，就我個人而言，我不喜歡用 Epic Game 的市場或客户端玩遊戲。

由於各種原因（功能、隱私等），我更喜歡 Steam 而不是 Epic Games。

Epic Games 被稱為遊戲社區中的壞人，因為它最近幾款遊戲專屬於其平台 —— 儘管很多人警告用户該平台上的隱私問題。

不僅如此，Epic Games 的首席執行官在過去發過這樣的推特：

安裝 Linux 相當於人們不喜歡美國的政治趨勢時就搬到加拿大。

不，我們必須為今天的自由而戰，如今我們擁有自由。

  • Tim Sweeney（@TimSweeneyEpic）2018年2月15日

嗯，這並不直接暗示他討厭 Linux 或者沒有積極推動 Linux 的遊戲開發 —— 但是隻是因為很多歷史情況，人們並不真正信任 Epic Games 的決策。所以，他們並不欣賞與 Blender 基金會的聯繫（即使這個財務幫助是積極的）。

這與財務幫助無關。但是，Epic Games 缺乏良好的聲譽（當然是主觀的），因此，人們對此的看法是消極的。看看撥款公告後的一些推文：

希望不要走向排它……這可能會破壞你的聲譽。

  • Ray（@ Epicshadow1994）2019年7月15日

我對將來會變成什麼樣感到懷疑。EPIC 最近一直在採取敵對戰術。

  • acrid Heartwood（@acrid_heartwood）2019年7月15日

總而言之 ​

你仍然可以通過 Lutris 在 Linux 上運行 Epic Games，但這是很單薄的非官方嘗試。Epic Games 沒有表示有興趣正式支持該項目。

所以，很明顯不是每個人都信任 Epic Games。因此，這個消息帶來了各種消極反應。

但是，這筆撥款肯定會幫助 Blender 基金會改善其組織和軟件質量。
