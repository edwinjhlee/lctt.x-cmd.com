Linux 入門十法 ​

想要進入 Linux 之門，試試這十個方法。

文章《什麼是 Linux 用户？》的作者 Anderson Silva 明確表示，現今人們使用 Linux（在某種程度上）就像使用 Windows 一樣，只要你對“使用 Linux”這個事情定義得足夠廣義。儘管如此，如果你的生活中沒有太多的使用 Linux 的機會，現在正是以前所未有的方式嘗試 Linux 的好時機。

以下是 Linux 入門的十種方法。你可以試試其中一個或者全部試試。

1、加入免費 shell 計劃 ​

有很多人在用不上的服務器上運行 Linux （請記住，“Linux 服務器”可以是從最新的超級計算機到丟棄的、已經用了 12 年的筆記本電腦中的任何一個）。為了充分利用多餘的計算機，許多管理員用這些備用的機器提供了免費的 shell 帳户。

如果你想要登錄到 Linux 終端中學習命令、shell 腳本、Python 以及 Web 開發的基礎知識，那麼免費的 shell 帳户是一種簡單、免費的入門方式。下面是一個可以體驗一下的簡短列表：

  • Freeshell.de 是一個自 2002 年以來一直在線服務的公用 Linux 系統。你可以通過 SSH、IPv6 和 OpenSSL 進行訪問，以獲得 Linux shell 體驗，並且可以使用 MySQL 資料庫。
  • Blinkenshell 提供了一個學習 Unix、使用 IRC、託管簡單網站和共享文件的 Linux shell。它自 2006 年以來一直在線服務。
  • SDF 公用 Unix 系統成立於 1987 年，提供了免費的 NetBSD 賬户。當然，NetBSD 不是 Linux，但它是開源的 Unix，因此它提供了類似的體驗。它也有幾個自制應用程序，因此它不但有普通的免費 shell，還提供了老派 BBS。

免費 shell 帳户常會受到濫用，因此你表現出的可信程度和積極參與協作的意願越多，你的體驗就越好。你可以通過專門請求或小額捐贈來證明你的誠意，通常可以訪問資料庫引擎、編譯器和高級編程語言。你還可以要求安裝其他軟件或庫，但需經管理員批准。

如何使用 ​

公用 shell 帳户是嘗試真正的 Linux 系統的好方法。你無法獲得 root 權限這一事實意味着你可以學習本地軟件管理，而無需做更多的維護工作。你可以做很多實際操作，以完成真正的工作，儘管它們對於學習關鍵任務還不夠。

2、試試 Windows WSL 2 裏面的 Linux ​

不管你信不信，微軟從 2019 年 6 月開始在 Windows 裏面帶上了 Linux，這意味着你可以從 Windows 運行 Linux 應用程序，這是 Windows 裏的 Linux 子系統的第二版（WSL 2）。雖然它主要針對開發人員，但 Windows 用户可以發現 WSL 2 是一個來自於他們熟悉的桌面上的 Linux 環境，而沒有被任何虛擬化佔用額外資源。這是一個以進程方式運行在 Windows 機器上的 Linux。現階段，它仍然是一個新的動向和正在進行中的工作，因此它可能會發生變化。如果你試圖用它承擔重任，你可能會遇到一兩個錯誤，但是如果你只是想入門 Linux、學習一些命令，並感受在基於文本的環境如何完成工作，那麼 WSL 2 可能正是你所需要的。

如何使用 ​

WSL 還沒有明確的用途或目的，但它在 Windows 機器上提供了 Linux 環境。你可以獲得 root 訪問權限，並可以運行 Linux 發行版和應用程序，因此這是一種簡單而無縫的學習方式。但是，即使 WSL 是Linux，它也不能給你典型的 Linux 體驗。它是由 Windows 提供的 Linux，而這不太會是你在現實世界中遇到的情況。WSL 是一個開發和教育工具，但如果你可以使用它，那麼你應該試試它。

3、把 Linux 放到可啓動的 U 盤上 ​

便攜 Linux 可以安裝到 U 盤上隨身攜帶，並用該 U 盤啓動你遇到的任何計算機。你可以獲得個性化的 Linux 桌面，而無需擔心所用於啓動的主機上的數據。該計算機上原有的系統不會與你的 Linux 系統相接觸，並且你的 Linux 操作系統也不會影響計算機。它非常適合酒店商務中心、圖書館、學校的公共計算機，或者只是給自己一個不時啓動 Linux 的藉口。

與許多其他快速獲得的 Linux shell 不同，此方法為你提供了一個完整而強大的 Linux 系統，包括桌面環境，可訪問你需要的任何軟件以及持久的數據存儲。

這個系統永遠不會改變。你要保存的任何數據都將寫入壓縮的文件系統中，然後在引導時將其作為覆蓋層應用於該系統。這種靈活性允許你選擇是以持久模式啓動，將所有數據保存回 U 盤；還是以臨時模式啓動，以便一旦關閉電源，你所做的一切都會消失。換句話説，你可以將其用作不受信任的計算機上的安全信息亭或你信任的計算機上的便攜式操作系統。

你可以嘗試很多 U 盤發行版，有些帶有精簡的桌面環境，適用於低功耗計算機，而另一些帶有完整的桌面環境。我偏愛 Porteus Linux。在過去的八年裏，我每天都把它放在我的鑰匙鏈上，在商務旅行中使用它作為我的主要計算平台，如果在工作場所或家中計算機發生問題，它也會用作工具盤。它是一個可靠而穩定的操作系統，有趣且易於使用。

在 Mac 或 Windows 上，下載 Fedora Media Writer 以創建你下載的任何便攜式發行版的可啓動 U 盤。

如何使用 ​

從 U 盤啓動一個 “實時 Linux” 可提供完整的 Linux 發行版環境。雖然數據存儲與你安裝到硬盤驅動器的系統略有不同，但其它的所有內容都與你在 Linux 桌面上所期望的一樣。在便攜式 Linux 操作系統上你幾乎沒有什麼不能做的，所以在你的鑰匙串上掛上一個以解鎖你遇到的每台計算機的全部潛力吧。

4、在線遊覽 ​

Ubuntu 的某個人想到了在瀏覽器中託管 Ubuntu GNOME 桌面的好主意。如果想要自己嘗試一下，可以打開 Web 瀏覽器並導航到 tour.ubuntu.com。你可以選擇要演示的活動，也可以跳過單個課程並單擊 “四處看看Show Yourself Around” 按鈕。

即使你是 Linux 桌面的新用户，你也可能會發現“四處看看”功能比你想像的更還簡單。在線遊覽中，你可以四處看看，查看可用的應用程序，以及查看典型的默認 Linux 桌面。你不能在 Firefox 中調整設置或啓動另一個在線遊覽（這是我嘗試過的第一件事），雖然你可以完成安裝應用程序的動作，但你無法啓動它們。但是，如果你之前從未使用過 Linux 桌面，並且想要看到各種新奇的東西，那這就是一場旋風之旅。

如何使用 ​

在線遊覽真的只是一次旅行。如果你從未見過 Linux 桌面，那麼這是一個瞭解它的情況的機會。這不是一個正式的使用，而是一個吸引過客的展示。

5、在瀏覽器中用 JavaScript 運行 Linux ​

就在不久之前，虛擬化的計算成本還很高，還僅限於使用先進的硬件的用户。而現在虛擬化已被優化到可以由 JavaScript 引擎執行的程度，這要歸功於 Fabrice Bellard，它是優秀的開源 QEMU 機器仿真器和虛擬器的創建者。

Bellard 還啓動了 JSLinux 項目，該項目允許你在瀏覽器中運行 Linux 和其他操作系統，這算是閒暇時間的一個樂趣。它仍然是一個實驗性項目，但它是一個技術奇蹟。打開 Web 瀏覽器導航到 JSLinux 頁面，你可以啓動基於文本的 Linux shell 或精簡的圖形 Linux 環境。你可以上傳和下載文件到 JSLinux 主機上或（在理論上可以）將文件發送到一個網絡備份位置，因為 JSLinux 可以通過 VPN 套接字訪問互聯網（儘管上限速度取決於 VPN 服務）。

如何使用 ​

你不會在 JSLinux 上正經使用多少時間，這個環境可能太不尋常了，無法學習 Linux 正常工作的廣泛課程。但是，如果你厭倦了在一台普通的 PC 上運行 Linux 並想在一個真正獨特的平台上試用 Linux，那麼 JSLinux 就屬於這種。

6、閲讀關於它的書 ​

並非每種 Linux 體驗都要用到計算機。也許你是那種喜歡在開始新事物之前保持距離先觀察和研究的人，或者你可能還不清楚 “Linux” 所包含的內容，或者你喜歡全情投入其中。關於 Linux 如何工作、運行 Linux 的方式以及 Linux 世界中有什麼，有很多書可以讀。

你越熟悉開源世界，就越容易理解常用術語，將城市神話與實際經驗區分開來。我們不時會發布[圖書清單] 17，但我的最愛之一是 Hazel Russman 的《The Charm of Linux》。這是一個從不同角度巡覽 Linux 的過程，是由一位獨立作者在發現 Linux 時興奮之餘寫作的。

如何使用 ​

沒有什麼能比一本好書更好。這是體驗 Linux 的最不傳統的方法，但對於喜歡印刷文字的人來説，它既舒適又有效。

7、弄塊樹莓派 ​

如果你正在使用樹莓派，那麼你就正在運行 Linux。Linux 和低功耗計算很容易上手。關於樹莓派的好處，除了價格低於 100 美元之外，它的網站是專為教育而設計的。你可以瞭解樹莓派所能做的一切，當你瞭解之後，就知道了 Linux 可以為你做些什麼。

如何使用 ​

樹莓派被設計為低功耗計算機。這意味着你不能像過去那樣做那麼多的多任務處理，但這是一種避免不堪重負的方便方法。樹莓派是學習 Linux 及其附帶的所有可能性的好方法，它是發現環保、小型、簡化計算能力的有趣方式。並且一定要關注 Opensource.com 上的提示、技巧和有趣的[活動] 25，特別是在每年三月份的樹莓派之周的期間。

8、趕上容器熱潮 ​

如果你從事於神話般的雲服務的後端工作，那麼你已經聽説過容器熱潮。雖然你可以在 Windows、Azure、Mac 和 Linux 上運行 Docker 和 Kubernetes，但你可能不知道容器本身就是 Linux。雲計算應用和基礎設施實際上是精簡的 Linux 系統，部分虛擬化，部分基於裸機。如果啓動容器，則會啓動微型的超特定的 Linux 發行版。

容器與虛擬機或物理服務器不同。它們不打算用作通用操作系統。但是，如果你在容器中進行開發，你可以停下來四處打量一下，你將瞭解到 Linux 系統的結構、保存重要文件的位置以及最常見的命令。你甚至可以在線嘗試容器，你可以在我的文章中深入到 Linux 容器的背後瞭解它們如何工作的。

如何使用 ​

根據設計，容器特定於一個單一任務，但它們是 Linux，因此它們非常靈活。你可以如你預期的使用它們，也可以在你的 Linux 實驗當中將容器構建到大部分完整系統中。它雖然不提供桌面 Linux 體驗，但它是完整的 Linux 體驗。

9、以虛擬機方式安裝 Linux ​

虛擬化是嘗試操作系統的簡便方法，VirtualBox 是一種很好的開源虛擬化方法。VirtualBox 可以在 Windows 和 Mac 上運行，因此你可以將 Linux 安裝為虛擬機（VM）並使用它，就好像它只是一個應用程序一樣。如果你不習慣安裝操作系統，VirtualBox 也是一種嘗試 Linux 的非常安全的方式，而不會意外地將其安裝覆蓋在你通常的操作系統上。

如何使用 ​

將 Linux 作為虛擬機運行既方便又簡單，既可以作為試運行使用，也可以在需要 Linux 環境時進行雙啓動或重啓進入。它功能齊全，因為它使用虛擬硬件，宿主操作系統負責驅動你的外圍設備。將 Linux 作為虛擬機運行的唯一缺點主要是心理上的。如果你打算使用 Linux 作為主要操作系統，但最終默認在宿主操作系統上做除了特定於 Linux 的大多數任務，那麼虛擬機就會讓你失望。否則，虛擬機是現代技術的勝利，在 VirtualBox 中使用 Linux 可以為你提供 Linux 所提供的所有最佳功能。

10、安裝一個 Linux ​

如果對上述方式有疑問，那麼總會有傳統的方式。如果你想給予 Linux 應有的關注，你可以下載 Linux，將安裝程序刻錄到 U 盤（或 DVD，如果你更喜歡光學介質的話），並將其安裝在你的計算機上。Linux 是開源的，所以任何想要花時間打包 Linux 的人都可以分發 Linux，並且可以將所有可用的部分分配到通常稱為發行版的內容中。無論問哪一個 Linux 用户什麼發行版是“最好的”，你必然都會得到一個不同的答案（主要是因為這個術語“最佳”通常是尚未定義的）。大多數人都認可：你應該使用適合你的 Linux 發行版，這意味着你應該測試一些流行的發行版，並堅持使你的計算機按照你期望的行為行事。這是一種務實和功能性的方法。例如，如果發行版無法識別你的網絡攝像頭而你希望它可以正常工作，則可以使用一個可識別該網絡攝像頭的發行版。

如果你之前從未安裝過操作系統，你會發現大多數 Linux 發行版都包含一個友好且簡單的安裝程序。只需下載一個發行版（它們以 ISO 文件提供），然後下載 Fedora Media Writer 來創建一個可啓動的安裝 U 盤。

如何使用 ​

安裝 Linux 並將其用作操作系統是邁向熟悉它的一步。怎麼使用它都可以。你可能會發現一些你從未了解過的所需的必備功能，你可能會比你想像的更多地瞭解計算機，並且可能會改變你的世界觀。你使用一個 Linux 桌面，或者是因為它易於下載和安裝，或者是因為你想要削弱公司中某些人的霸主地位，或者只是因為它可以幫助你完成工作。

無論你的原因是什麼，只需嘗試使用上面這些任何（或所有）這些方式。
