最適合於初學者的 Linux 發行版 ​

在本文中，我們將看到最適合於初學者的 Linux 發行版。這將有助於 Linux 新用户選擇他們的第一個發行版。

讓我們面對現實，Linux 可能會給新用户帶來巨大的複雜性。但是，帶來這種複雜性的並不是 Linux 本身。相反，是“新奇”因素導致了這種情況。並不是懷舊，但我記得第一次使用 Linux 時，我甚至不知道會發生什麼。我喜歡它，但最初這對我來説像是逆流游泳一樣。

不知道從何處着手可能是一個令人沮喪的原因，特別是對於那些在 PC 上運行 Windows 之外的其它系統沒有概念的人來説。

Linux 不僅僅是一個操作系統，而是一個理念：在這裏大家共同成長，也適合於每個人的不同需要。我們已經介紹過：

  • Windows 用户的最佳 Linux 發行版
  • 最佳輕量級 Linux 發行版
  • 黑客攻擊的最佳 Linux 發行版
  • 最佳 Linux 遊戲發行版
  • 隱私和匿名的最佳 Linux 發行版
  • 看起來像 MacOS 的最佳 Linux 發行版

除此之外，還有一些能夠特別滿足新人需求的發行版。這裏有一些這樣的適合初學者的 Linux 發行版。你也可以在視頻中觀看並訂閲我們的 YouTube 頻道以獲取更多與 Linux 相關的視頻。

最適合於初學者的 Linux 發行版 ​

請記住，此列表沒有特別的順序。編制此列表的主要標準是易於安裝、開箱即用的硬件和軟件、易用性和軟件包的可用性。

1、Ubuntu ​

如果你在互聯網上研究過 Linux，那麼你很可能遇到過 Ubuntu。Ubuntu 是領先的 Linux 發行版之一，它也是開始 Linux 之旅的完美之選。

Ubuntu 被視為人性化的 Linux，這是因為 Ubuntu 在通用可用性上付出了很多努力。Ubuntu 並不要求你在技術方面懂得很多才能使用它。它打破了 “Linux = 命令列麻煩”這一概念。這是 Ubuntu 飆升到今天的主要優勢之一。

Ubuntu 提供了非常方便的安裝程序。這個安裝程序以簡單的英語（或你想要的任何主要語言）描述安裝過程。你甚至可以在實際執行安裝過程之前嘗試使用 Ubuntu。安裝程序提供了簡單的選項：

  • 刪除舊操作系統以安裝 Ubuntu。
  • 與 Windows 或任何其他現有操作系統一起安裝 Ubuntu（每次啓動時都會提供要啓動的操作系統的選擇列表）。
  • 讓高級用户自行配置分區。

初學者提示：如果你不確定該怎麼做，請選擇第二個選項。

Ubuntu 的用户界面採用 GNOME。它簡單、高效。你可以通過按 Windows 鍵搜索從應用程序到文件的任何內容。有什麼比這更簡單的嗎？

沒有驅動程序安裝問題，因為 Ubuntu 附帶硬件檢測器，可以檢測、下載和安裝適用於你的 PC 的最佳驅動程序。此外，安裝會附帶所有基本軟件，如音樂播放器、視頻播放器、辦公套件和一些消磨時間的遊戲。

Ubuntu 擁有出色的文檔和社區支持。Ubuntu 論壇和 Ask Ubuntu 幾乎在 Ubuntu 的所有方面都提供了可觀的高質量支持。你的一些問題很有可能已經得到了回答，這些答案是適合初學者的。

請在官方網站查看並下載 Ubuntu。

2、Linux Mint Cinnamon ​

多年來，Linux Mint 一直是 Distrowatch 上的排名第一的 Linux 發行版。我必須説，這是當之無愧的寶座。Linux Mint 是我個人的最愛之一。它優雅、秀氣，提供了卓越的計算體驗（開箱即用）。

Linux Mint 帶有 Cinnamon 桌面環境。仍處於熟悉 Linux 軟件階段的 Linux 新用户會發現 Cinnamon 非常有用。所有軟件都按類別分組，非常易於訪問。雖然這不是一個令人興奮的功能，但對於不瞭解 Linux 軟件名稱的新用户來説，這是一個巨大的好處。

Linux Mint 很快，在舊電腦上也運行良好。Linux Mint 建立在堅如磐石的 Ubuntu 基礎之上。它使用與 Ubuntu 相同的軟件存儲庫。而對於 Ubuntu 軟件存儲庫，僅在廣泛測試後 Ubuntu 才會將軟件推送在其中。這意味着用户不必處理某些新軟件容易出現的意外崩潰和故障，對於新的 Linux 用户來説這可能是一個真正不可接受的。

Windows 7 愛好者如果沒有真的升級到微軟 Windows 10 的話，那將會發現 Linux Mint 的可愛。 Linux Mint 桌面非常類似於 Windows 7 桌面。類似的工具欄、類似的菜單、類似的托盤圖標都絕對會使 Windows 用户感到十分熟悉。

就個人而言，我更傾向於向 Linux 世界的新人推薦 Linux Mint，因為 Linux Mint 確實給用户留下了足夠的印象，會讓他們接受它。對我來説，Linux Mint 應該是面向初學者的 Linux 列表中的首位。

請在這裏查看 Linux Mint，看看 Cinnamon 版。

3、Zorin OS ​

大多數計算機用户是 Windows 用户。當 Windows 用户拿到一個 Linux 時，他必須經歷相當多的“去知識過程”。大量的操作已經固定在我們的肌肉記憶當中。例如，每次要啓動應用程序時，鼠標都會移動屏幕的左下角（“開始”菜單）。因此，如果我們能夠在 Linux 上找到一些可以緩解這些問題的東西，那就成功了一半了。進入 Zorin OS。

Zorin OS 是一款基於 Ubuntu 的高度打磨的 Linux 發行版，完全是為 Windows 難民製作的。儘管幾乎每個 Linux 發行版都可供任何人使用，但是當桌面看起來太陌生時，有些人可能會不情願使用。Zorin OS 避開了這個障礙，因為它與 Windows 外觀明顯相似。

對 Linux 新手來説，軟件包管理器是一個新概念。這就是為什麼 Zorin OS 帶有一個巨大的（我的意思是真的很大）預安裝軟件列表。你需要的任何東西，很有可能都已經安裝在 Zorin OS 上了。好像這還不夠，Wine 和 PlayOnLinux 也預先安裝好了，所以你也可以在這裏運行你喜愛的 Windows 軟件和遊戲。

Zorin OS 配備了一款名為 “Zorin look changer” 的驚人的主題引擎。它提供了一些重要的自定義選項和預設，可以使你的操作系統看起來像 Windows 7、XP、2000 甚至是 Mac，你會有賓至如歸的感覺。

正是這些功能使 Zorin OS 成為適合初學者的最佳 Linux 發行版。查看 Zorin OS 網站以瞭解更多信息和下載該操作系統。

4、Elementary OS ​

我們已經看過了給 Windows 用户準備的 Linux 發行版，讓我們為 MacOS 用户也提供一些東西。Elementary OS 成名非常迅速，現在總是被列入頂級發行列表之中，這一切都歸功於其美學本質。其靈感來自於 MacOS，Elementary OS 是最美麗的 Linux 發行版之一。

Elementary OS 是又一個基於 Ubuntu 的操作系統，這意味着操作系統本身無疑是穩定的。Elementary OS 帶有 Pantheon 桌面環境。你馬上就會注意到它與 MacOS 桌面的相似之處。這對於轉換到 Linux 的 MacOS 用户來説是一個優勢，因為他們會對桌面非常適應，這確實簡化了應對此變化的過程。

它的菜單簡單，可根據用户喜好自定義。該操作系統是零侵入性的，因此你可以真正專注於工作。它附帶了非常少量的預安裝軟件。因此，新用户都不會被龐雜的內容嚇跑。但是，嘿，它具備開箱即用所需要的一切。如果需要更多軟件，Elementary OS 提供了一個整潔的 AppCenter。它易於訪問且簡單易用，一切都在一個地方，你可以一鍵獲得所需的所有軟件和升級。

經驗表明，Elementary OS 真的是一個很棒的軟件。絕對值得試一試。

5、Linux Mint Mate ​

許多來了解 Linux 的人都希望讓舊電腦煥發新生。隨着 Windows 10 的普及，幾年前許多具有不錯配置的計算機已經變得無力應對。在谷歌上快速搜索一下會建議你在這樣的電腦上安裝 Linux。通過這種方式，你可以讓它們在之後一段時間仍舊能保持水準。如果你正在尋找可以運行在舊計算機上的操作系統，Linux Mint Mate 是一個很棒的 Linux 發行版。

Linux Mint Mate 非常輕便，資源利用效率高，而仍然是一個漂亮的發行版。它可以在計算能力較弱的計算機上平穩運行。桌面環境沒有各種花哨的東西。但它在功能上和任何其他桌面環境相比毫不遜色。這個操作系統是非侵入式的，允許你獲得高效的計算體驗而不會妨礙你。

同樣，Linux Mint Mate 基於 Ubuntu，具有巨大而堅實的 Ubuntu 軟件存儲庫的優勢。它預裝了最少數量的必需軟件。提供了簡便的驅動程序安裝和設置管理。

即使你只有 512 MB 的內存和 9 GB 的硬盤空間（當然是越多越好），你也可以運行 Linux Mint Mate。

Mate 桌面環境非常簡單易用，沒有什麼費解的地方。對於 Linux 初學者來説，這確實是一個巨大的優勢，更有理由 嘗試 Linux Mint Mate。

6、Manjaro Linux ​

好吧。任何一個 Linux 的老用户都會説，即使只是在大方向上，引導新手接觸 Arch Linux 都是一種罪過。但是聽我説。

Arch 被認為是專家級 Linux，因為它的安裝過程非常複雜。Manajro 和 Arch Linux 有着共同的起源，但它們在其他方面存在很大差異。

Manajro Linux 具有非常適合初學者的安裝程序。許多事情都是自動化的，比如使用“硬件檢測”進行驅動程序安裝。Manjaro 極大地解決了困擾許多其它 Linux 發行版的硬件驅動程序的麻煩。即使你遇到任何問題，Manjaro 也有很棒的社區支持。

Manjaro 擁有自己的軟件存儲庫，其維護了最新的軟件。雖然優先向用户提供最新軟件，但它是以保證穩定性不會受到損害為前提的。這是 Arch 和 Manjaro 之間的主要區別之一。Manjaro 延遲軟件包的發佈以確保它們絕對穩定並且不會導致回退。你還可以訪問 Manjaro 上的 Arch User Repository（AUR），因此你可以隨時獲得所需的一切。

如果你想了解更多有關 Manjaro 功能的信息，請閲讀我的同事 John 的 Manjaro Linux 經歷以及為什麼他會被它迷住。

Manjaro Linux 有 XFCE、KDE、Gnome、Cinnamon 以及更多桌面環境，請查看官方網站。

要安裝上述 6 個操作系統中的任何一個，你需要創建一個可啓動的 U 盤。如果你當前正在使用 Windows 請使用本指南。Mac OS 用户可以遵循本指南。

你選擇哪個最適合初學者的 Linux 發行版？ ​

Linux 可能會有學習曲線，但這是一件不會讓每個人都感到後悔的事情。進一步獲得一個 ISO 文件並體驗一下 Linux 吧。如果你已經是 Linux 用户，請分享這篇文章，並幫助人們在這個愛的季節愛上 Linux 吧。加油！
