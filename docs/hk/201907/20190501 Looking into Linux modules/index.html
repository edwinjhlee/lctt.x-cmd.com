深入學習 Linux 內核模組 ​

lsmod 命令能夠告訴你當前系統上加載了哪些內核模組，以及關於使用它們的一些有趣的細節。

什麼是 Linux 內核模組？ ​

內核模組是可以根據需要加載到內核中或從內核中卸載的代碼塊，因此無需重啓就可以擴展內核的功能。事實上，除非用户使用類似 lsmod 這樣的命令來查詢模組信息，否則用户不太可能知道內核發生的任何變化。

需要知道的重要一點是，在你的 Linux 系統上總會有很多可用的模組，並且如果你可以深入其中瞭解到很多細節。

lsmod 的主要用途之一是在系統不能正常工作時檢查模組。然而，大多數情況下，模組會根據需要加載的，而且用户不需要知道它們如何運作。

在上面的輸出中：

  • Module 顯示每個模組的名稱
  • Size 顯示每個模組的大小（並不是它們佔的內存大小）
  • Used by 顯示每個模組被使用的次數和使用它們的模組

顯然，這裏有很多模組。加載的模組數量取決於你的系統和版本以及正在運行的內容。我們可以這樣計數：

$ lsmod | wc -l
67

要查看系統中可用的模組數（不止運行當中的），試試這個命令：

$ modprobe -c | wc -l
41272

與內核模組相關的其他命令 ​

Linux 提供了幾條用於羅列、加載及卸載、測試，以及檢查模組狀態的命令。

  • depmod —— 生成 modules.dep 和映射文件
  • insmod —— 一個往 Linux 內核插入模組的程序
  • lsmod —— 顯示 Linux 內核中模組狀態
  • modinfo —— 顯示 Linux 內核模組信息
  • modprobe —— 添加或移除 Linux 內核模組
  • rmmod —— 一個從 Linux 內核移除模組的程序

顯示內置的內核模組 ​

正如前文所説，lsmod 命令是顯示內核模組最方便的命令。然而，也有其他方式可以顯示它們。modules.builtin 文件中列出了所有構建在內核中的模組，在 modprobe 命令嘗試添加文件中的模組時會使用它。注意，以下命令中的 $(uname -r) 提供了內核版本的名稱。

$ more /lib/modules/$(uname -r)/modules.builtin | head -10
kernel/arch/x86/crypto/crc32c-intel.ko
kernel/arch/x86/events/intel/intel-uncore.ko
kernel/arch/x86/platform/intel/iosf_mbi.ko
kernel/mm/zpool.ko
kernel/mm/zbud.ko
kernel/mm/zsmalloc.ko
kernel/fs/binfmt_script.ko
kernel/fs/mbcache.ko
kernel/fs/configfs/configfs.ko
kernel/fs/crypto/fscrypto.ko

你可以使用 modinfo 獲得一個模組的更多細節，雖然沒有對模組提供的服務的簡單説明。下面輸出內容中省略了冗長的簽名。

$ modinfo floppy | head -16

alias:          block-major-2-*
license:        GPL
author:         Alain L. Knaff
srcversion:     EBEAA26742DF61790588FD9
alias:          acpi*:PNP0700:*
alias:          pnp:dPNP0700*

你可以使用 modprobe 命令加載或卸載模組。使用下面這條命令，你可以找到特定模組關聯的內核對象：

$ find /lib/modules/$(uname -r) -name floppy*
/lib/modules/5.0.0-13-generic/kernel/drivers/block/floppy.ko

如果你想要加載模組，你可以使用這個命令：

$ sudo modprobe floppy

總結 ​

很明顯，內核模組的加載和卸載非常重要。它使得 Linux 系統比使用通用內核運行時更加靈活和高效。這同樣意味着你可以進行重大更改而無需重啓，例如添加硬件。
