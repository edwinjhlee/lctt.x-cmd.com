100 個最佳 Ubuntu 應用 ​

今年早些時候我們發佈了一個 2018 年最好的 20 個 Ubuntu 應用列表，可能對很多用户來説都很有用。現在我們幾乎到 2018 年下半年了（LCTT 譯註：好吧，我們翻譯的有些晚了，順便打個廣告，LCTT 歡迎你，有志於通過翻譯為開源做些貢獻的同學！），所以今天我們打算看一下 Ubuntu 上最好的 100 個應用，你可能會覺得有幫助。

很多用户最近從 Microsoft Windows 轉換到了 Ubuntu，可能面臨着這樣一個困境：尋找它們之前使用了數年的操作系統上的應用軟件的最好替代應用。Ubuntu 擁有上千個免費使用和開源應用軟件，比 Windows 和其它 OS 上的付費軟件運行的更好。

下列列表歸納了各種分類下很多應用軟件的功能特點，因此，你可以找到匹配你的需求的最好的應用。

1、Google Chrome 瀏覽器 ​

幾乎所有 Linux 發行版都默認安裝了 Mozilla Firefox 網絡瀏覽器，它是 Google Chrome 的強力競爭對手。但是 Chrome 相對 Firefox 而言有它自己的優點，比如它可以讓你直接訪問你的 Google 賬户，你可以通過它來同步你在其它操作系統和手機上的 Chrome 瀏覽器的書籤、瀏覽歷史、擴展等等。

Google Chrome 為 Linux 集成了最新的 Flash 播放器，其它 Linux 上的瀏覽器像 Mozilla Firefox 和 Opera 網絡瀏覽器則不是這樣。如果你在 Windows 上經常使用 Chrome，那麼在 Linux 上也用它是最好的選擇。

2、Steam ​

現在在 Linux 上玩遊戲已經不是問題了，這在很多年前還是一個遙不可及的夢。在 2013 年，Valve 發佈了 Linux 上的 Steam 遊戲客户端，此後一切都變了。早期用户猶豫着從 Windows 轉到 Linux，只是因為他們不能在 Ubuntu 上玩它們最喜歡的遊戲，但是現在已經不是這樣了。

一些用户可能發現在 Linux 上安裝 Steam 有點棘手，但如果能在 Linux 上玩上千的 Steam 遊戲這麼做就是值得的。一些流行的高端遊戲，如《反恐精英：全球攻勢》、《Hitman》、《Dota 2》在 Linux 上都能獲取，你只需要確保你滿足玩這些遊戲的最小硬件需求。

$ sudo add-apt-repository multiverse
$ sudo apt-get update
$ sudo apt-get install steam

3、WordPress 桌面客户端 ​

是的，沒錯，WordPress 有它專屬的 Ubuntu 平台的客户端，你可以用來管理你的 WordPress 站點。你可以在桌面客户端上撰寫和設計你的站點而不用轉到瀏覽器。

如果你擁有使用 WordPress 建立的站點，那麼這個桌面客户端就是你必備的應用，它能夠讓你在單個窗口內追蹤所有的 WordPress 通知。你也可以查看你的站點上的Blog數據。桌面客户端可以在 Ubuntu 軟件中心中獲取，你可以在那裏下載和安裝。

4、VLC 媒體播放器 ​

VLC 是一個非常流行的跨平台的開源媒體播放器，同樣在 Ubuntu 中可以獲取。使得 VLC 成為一個最好的媒體播放器的原因是它能夠毫無問題地播放世界上任何音頻視頻格式。

VLC 有一個平滑的用户界面，易於使用，除此之外，它提供了很多功能，包括在線視頻流、音頻和視頻自定義等。

$ sudo add-apt-repository ppa:videolan/master-daily
$ sudo apt update
$ sudo apt-get install vlc qtwayland5

5、Atom 文本編輯器 ​

由 GitHub 開發的 Atom 是一個自由開源的文本編輯器，它同樣能夠被用做集成開發環境（IDE）來進行主流編程語言的編碼和編輯。Atom 開發者聲稱它是完全可魔改的 21 世紀文本編輯器。

Atom 文本編輯器擁有最佳的用户界面，它是一個富文本編輯器，提供了自動補全、語法高亮，支持擴展與插件。

$ sudo add-apt-repository ppa:webupd8team/atom
$ sudo apt-get update
$ sudo apt-get install atom

6、GIMP 圖像編輯器 ​

GIMP（GNU 圖形操作程序）是 Ubuntu 上的自由開源的圖像編輯器。無疑它是 Windows 上 Adobe Photoshop 的最好替代品。如果你過去經常用 Adobe Photoshop，會覺得很難習慣 GIMP，但是你可以自定義 GIMP 使它看起來與 Photoshop 非常相似。

GIMP 是一個功能豐富的圖片編輯器，你可以隨時通過安裝擴展和插件來使用附加的功能。

$ sudo apt-get install gimp

7、Google Play 音樂桌面播放器 ​

Google Play 音樂桌面播放器是一個開源的音樂播放器，它是 Google Play 音樂的一個複製品，或者説比它更好。Google 一直少個桌面的音樂客户端，但第三方的應用完美的填充了空白。

就像你在上面的截屏裏看到的，它的界面在外觀和感覺上都是首屈一指的。你只需要登錄 Google 賬户，之後就會導入你的所有音樂和收藏到桌面客户端裏。你可以從它的官方站點下載安裝文件並使用軟件中心安裝它。

8、Franz ​

Franz 是一個即時消息客户端，它將聊天和信息服務結合到了一個應用中。它是一個現代化的即時消息平台，在單個應用中支持了 Facebook Messenger、WhatsApp、Telegram、微信、Google Hangouts、 Skype。

Franz 是一個完備的消息平台，你可以用於商業中管理大量的客户服務。要安裝 Franz，你需要從它的網站下載安裝包，在軟件中心中打開。

9、新立得包管理器 ​

新立得包管理器是 Ubuntu 上必有工具之一，因為它為我們通常在終端裏安裝軟件的 apt-get 命令提供了用户圖形界面。它是各種 Linux 發行版中的默認應用商店的強力對手。

新立得擁有非常簡單的用户圖形界面，相比其它的應用商店非常快並易於使用。在左手邊你可以瀏覽不同分類的各種應用，也可以輕鬆安裝和卸載。

$ sudo apt-get install synaptic

10、Skype ​

Skype 是一個非常流行的跨平台視頻電話應用，如今在 Linux 系統可以以 Snap 應用方式獲取。Skype 是一個即時通信應用，它提供了視頻和音頻通話、桌面共享等功能。

Skype 有一個優秀的用户圖形界面，與 Windows 上的桌面客户端非常相似，易於使用。它對於從 Windows 上轉換來的用户來説非常有用。

$ sudo snap install skype

11、VirtualBox ​

VirtualBox 是由 Oracle 公司開發的跨平台的虛擬化軟件應用（LCTT 譯註：實際上是由被 Oracle 公司收購的 Sun 公司開發的，包括 Java、Solaris 也是）。如果你喜歡嘗試新的操作系統，那麼 VirtualBox 是你必備的 Ubuntu 應用。你可以在 Windows 內嘗試 Linux、Mac，也可以在 Linux 系統內嘗試 Windows 和 Mac。

VirtualBox 實際做的是讓你在宿機操作系統裏可視化地運行訪客操作系統。它可以創建虛擬硬盤並在上面安裝訪客操作系統。你可以在 Ubuntu 軟件中心直接下載和安裝它。

12、Unity Tweak 工具 ​

Unity Tweak 工具（Gnome Tweak 工具）對於每個 Linux 用户都是必須擁有的，因為它給了用户根據需要自定義桌面的能力。你可以嘗試新的 GTK 主題、設置桌面熱角、自定義圖標集、調整 unity 啓動器等等。

Unity Tweak 工具對於用户來説可能非常有用，因為它包含了從基礎到高級配置的所有內容。

$ sudo apt-get install unity-tweak-tool

13、Ubuntu Cleaner ​

Ubuntu Cleaner 是一個系統管理工具，其被特別設計用來移除不再使用的包、不需要的應用和清理瀏覽器緩存。Ubuntu Cleaner 有易於使用的簡單用户界面。

Ubuntu Cleaner 是 BleachBit 最好的替代品之一，BleachBit 是 Linux 發行版上的相當好的清理工具。

$ sudo add-apt-repository ppa:gerardpuig/ppa
$ sudo apt-get update
$ sudo apt-get install ubuntu-cleaner

14、Visual Studio Code ​

Visual Studio Code 是一個代碼編輯器，你會發現它與你可能曾用過的 Atom 文本編輯器和 Sublime Text 非常相似。Visual Studio Code 被證明是非常好的教育工具，因為它可以對編程中的從 HTML 標籤到語法的所有東西做出解釋。

Visual Studio 自身集成了 Git，它有優秀的用户界面，你會發現它與 Atom Text Editor 和 Sublime Text 非常相似。你可以從 Ubuntu 軟件中心下載和安裝它。

15、Corebird ​

如果你在找你可以使用 Twitter 的桌面客户端，那 Corebird Twitter 客户端就是你在找的。它被視為 Linux 發行版下可獲得的最好的 Twitter 客户端，它提供了與你手機上的 Twitter 應用非常相似的功能。

當有人喜歡或者轉發你的 tweet 或者給你發消息時，Corebird Twitter 客户端同樣會給你通知。你同樣可以在這個客户端上添加多個 Twitter 賬户。

$ sudo snap install corebird

16、Pixbuf ​

Pixbuf 是來自 Pixbuf 圖片社區中心的一個桌面客户端，可以讓你上傳、分享和出售你的相片。它支持圖片共享，如像 Facebook、Pinterest、Instagram、Twitter 等社交媒體，以及像 Flickr、500px 和 Youpic 等相片服務。

Pixbuf 提供了分析等功能，可以讓你統計點擊量、轉發量、照片的回覆數、定時發帖、iOS 專有的擴展信息。它同樣有移動應用，因此你可以在任何地方連接到你的 Pixbuf 賬户。Pixbuf 可以在 Ubuntu 軟件中心以 Snap 包的形式獲得。

17、Clementine 音樂播放器 ​

Clementine 是一個跨平台的音樂播放器，並且是 Ubuntu 上默認音樂播放器 Rhythmbox 的良好競爭者。它是一個快速而易用的音樂播放器，其用户界面友好。它支持所有主流音頻文件格式的回放。

除了可以播放本地庫中的音樂，你也可以在線聽 Spotify、SKY.fm、Soundcloud 等的廣播。它也支持其它的功能像智能和動態播放列表，可以從像 Dropbox、Google Drive 這樣的雲存儲中同步音樂。

$ sudo add-apt-repository ppa:me-davidsansome/clementine 
$ sudo apt-get update
$ sudo apt-get install clementine

18、Blender ​

Blender 是一個自由開源的 3D 創建應用軟件，你可以用來創建 3D 打印模型、動畫電影、視頻遊戲等。它自身集成了遊戲引擎，你可以用來開發和測試視頻遊戲。

Blender 擁有賞心悦目的用户界面，易於使用，它包括了內置的渲染引擎、數字雕刻、仿真工具、動畫工具，還有很多。考慮到它免費和它的特點，你甚至會認為它可能是 Ubuntu 上最好的應用之一。

19、Audacity ​

Audacity 是一個開源的音頻編輯應用，你可以用來記錄、編輯音頻文件。你可以從各種輸入中錄入音頻，包括麥克風、電子吉它等等。它提供了根據你的需要編輯和裁剪音頻的能力。

最近 Audacity 發佈了 Ubuntu 上的新版本，新特點包括主題改進、放縮命令等。除了這些，它還提供了降噪等音頻效果的功能。

$ sudo add-apt-repository ppa:ubuntuhandbook1/audacity
$ sudo apt-get update 
$ sudo apt-get install audacity

20、Vim ​

Vim 是一個集成開發環境，你可以以一個獨立應用或 CLI 程序使用它，用於各種像 Python 等主流編程語言的編程。

大多數程序員喜歡在 Vim 中編寫代碼，因為它快速並且是一個可高度定製的集成開發環境。最初你可能覺得有點難用，但你會很快習慣它。

$ sudo apt-get install vim

21、Inkscape ​

Inkscape 是一個開源和跨平台的矢量圖形編輯器，你會覺得它和 Corel Draw 和 Adobe Illustrator 很相似。用它可以創建和編輯矢量圖形例如柱形圖、徽標、圖表、插圖等。

Inkscape 使用可縮放矢量圖形（SVG），這是一個基於 XML 的 W3C 標準格式。它支持各種格式，包括 JPEG、PNG、GIF、PDF、AI（Adobe Illustrator 格式）、VSD 等等。

$ sudo add-apt-repository ppa:inkscape.dev/stable
$ sudo apt-get update
$ sudo apt-get install inkscape

22、Shotcut ​

Shotcut 是一個 Meltytech, LLC 在 MLT 多媒體框架下開發的自由開源的跨平台視頻編輯應用。你會發現它是 Linux 發行版上最強大的視頻編輯器之一，它支持所有主要的音頻、視頻、圖片格式。

它提供了非線性編輯多軌編輯各種文件格式的視頻的能力。它支持 4K 視頻分辨率和各種音頻、視頻過濾、語氣生成、音頻混合和很多其它的。

snap install shotcut -- classic

23、SimpleScreenRecorder ​

SimpleScreenRecorder 是 Ubuntu 上的一個免費而輕量級的屏幕錄製工具。如果你是 YouTube 創作者或應用開發者，屏幕錄製功能非常有用。

它可以捕獲桌面屏幕的視頻/音頻記錄或直接錄製視頻遊戲。在錄製屏幕前，你可以設置視頻分辨率、幀率等。它有簡單的用户界面，你會發現非常易用。

$ sudo add-apt-repository ppa:marten-baert/simplescreenrecorder
$ sudo apt-get update
$ sudo apt-get install simplescreenrecorder

24、Telegram ​

Telegram 是一個基於雲的即時通信和網絡電話平台，近年來非常流行。它是開源和跨平台的，用户可以用來發送消息，共享視頻、圖片、音頻和其它文件。

Telegram 中容易注意到的特點是加密聊天、語音信息、機器人、遠程視頻通話、在線位置和社交登錄。在 Telegram 中隱私和安全擁有最高優先級，因此，所有你發送和接收的是端對端加密的。

$ sudo snap install telegram-desktop

25、ClamTk ​

正如我們知道的，危害 Windows PC 的病毒不能危害 Ubuntu，但是可能被來自包含破壞性文件的 Windows PC 中的郵件所感染。因此，在 Linux 上有一些抗病毒應用是安全的。

ClamTk 是一個輕量級的病毒掃描器，可以掃描系統中的文件和文件夾並清理發現的有害文件。ClamTk 可以 Snap 包的形式獲得，可以從 Ubuntu 軟件中心下載。

26、MailSpring ​

MailSpring 早期名為 Nylas Mail 或 Nylas N1，是開源的郵件客户端。它在電腦本地保存所有的郵件，因此你可以在任何需要的時候訪問它。它提供了高級搜索的功能，可以使用“與”和“或”操作，因此你可以基於不同的參數搜索郵件。

MailSpring 有着和其它易於上手的郵件客户端同樣優秀的用户界面。MailSpring 同樣提供了私密性、安全性、日程、通訊錄管理、日曆等功能特點。

27、PyCharm ​

繼 Vim 之後，PyCharm 是我最喜歡的的 Python IDE 之一，因為它有優雅的用户界面，有很多擴展和插件支持。基本上，它有兩個版本，一個是自由開源的社區版，另一個是付費的專業版。

PyCharm 是可高度自定義的 IDE 並且有很多功能，如錯誤高亮、代碼分析、集成單元測試和 Python 調試器等。PyCharm 對於大多數 Python 程序員和開發者來説是首選 IDE。

28、咖啡因 ​

想像一下你在 Youtube 上看視頻或閲讀一篇新文章，突然你的 Ubuntu 鎖屏了，我知道它很煩人。我們很多人都會遇到這種情況，所以咖啡因是一個阻止 Ubuntu 鎖屏或屏幕保護程序的工具。

咖啡因指示器是一個輕量級的工具，它添加圖標到通知欄，你可以在那裏輕鬆的激活或禁止它。不需要額外的設置。

$ sudo add-apt-repository ppa:eugenesan/ppa
$ sudo apt-get update
$ sudo apt-get install caffeine -y

29、Etcher USB 鏡像寫入器 ​

Etcher 是一個由 resin.io 開發的 USB 鏡像寫入器。它是一個跨平台的應用，可以幫助你將 ZIP、ISO、IMG 格式的鏡像文件寫入到 USB 存儲中。如果你經常嘗試新的操作系統，那麼 Ethcher 是你必有的簡單可靠的工具。

Etcher 有乾淨的用户界面，可以指導你在三步內燒錄鏡像到 USB 驅動或 SD 卡的過程。步驟包括選擇鏡像文件、選擇 USB 驅動 和最終的燒錄（寫文件到 USB 驅動）。你可以從它的官網下載和安裝 Etcher。

30、Neofetch ​

Neofetch 是一個酷炫的系統信息工具，通過在終端中運行 neofetch 命令，它會給你關於你的系統的所有信息。它酷是因為它可以給你關於桌面環境、內核版本、bash 版本和你正在運行的 GTK 主題的信息。

與其它系統信息工具比較，Nefetch 是高度自定義的工具。你可以使用命令列進行各種自定義。

$ sudo add-apt-repository ppa:dawidd0811/neofetch
$ sudo apt-get update
$ sudo apt-get update install neofetch

31、Liferea ​

Liferea（Linux 訂閲閲讀器）是一個自由開源的新聞聚合工具，用於在線新聞訂閲。使用新的聚合非常快捷和簡單，支持各種格式例如 RSS/RDF，Atom 等。

Liferea 自帶與 TinyTinyRSS 的同步支持，它給了你離線閲讀的能力。你會發現，就可靠性和靈活性而言，它是 Linux 上最好的訂閲工具之一。

$ sudo add-apt-repository ppa:ubuntuhandbook1/apps
$ sudo apt-get update
$ sudo apt-get install liferea

32、Shutter ​

在 Ubuntu 中很容易截屏，但當需要編輯截屏時 Shutter 是你必不可少的應用。它幫助你捕獲、編輯和輕鬆的共享截屏。使用 Shutter 的選擇工具，你可以選擇屏幕的特定區域來截屏。

Shutter 是一個功能強大的截圖工具，提供了添加截圖效果、畫線等功能。它同樣給你上傳截屏到各種圖像託管站點的選項。你可以直接在 Ubuntu 軟件中心中下載和安裝。

33、Weather ​

Weather 是一個小的應用，可以給你關於你的城市或世界上其它位置的實時天氣信息。它簡單而且輕量級，可以給你最多 7 天的詳細天氣預報和今明兩天的每個小時的細節信息。

它集成在 GNOME shell 中，給你關於最近搜索位置的當前天氣狀態。它有極簡的用户界面，在最小硬件需求下運行很順暢。

34、Ramme ​

Ramme 是一個很酷的非官方的 Instagram 桌面客户端，給你帶來 Instagram 移動端的感覺。它是基於 Electron 開發的客户端，所以它復現了 Instagram 應用的功能，並提供了主題自定義的功能。

但是由於 Instagram 的 API 限制，你不能使用 Ramme 客户端上傳圖像，但你可以訂閲 Instagram 流、喜歡和評論文章，給好友發消息。你可以從 Github 下載 Ramme 安裝文件。

35、Thunderbird ​

73、TeXstudio ​

Texstudio 是一個創建和編輯 LaTex 文件的集成寫作環境。它是開源的編輯器，提供了語法高亮、集成的查看器、交互式拼寫檢查、代碼摺疊、拖放等特點。

它是跨平台的編輯器，有簡單輕量級的用户界面，易於使用。它集成了 BibTex 和 BibLatex 目錄管理器，同樣有集成的 PDF 查看器。你可以從官網和 Ubuntu 軟件中心下載 Texstudio。

74、QtQR ​

QtQR 是一個基於 Qt 的應用，讓你在 Ubuntu 中創建和讀取二維碼。它是用 Python 和 Qt 開發的，有簡單和輕量級的用户界面，你可以編碼網站地址、郵件、文本、短消息等。你也可以用網絡相機解碼二維碼。

如果你經常處理產品銷售和服務，QtQR 會證明是有用的工具，我覺得沒有能在如此低硬件的要求下能和 QtQR 一樣提供類似功能順暢運行的應用了。

$ sudo add-apt-repository ppa: qr-tools-developers/qr-tools-stable
$ sudo apt-get update
$ sudo apt-get install qtqr

75、Kontact ​

Kontact 是一個為 KDE 桌面環境開發的集成的個人信息管理器（PIM）。它集成了多個軟件到一個集合中，在一個用户界面集成了 KMail、KOrganizer和 KAddressBook，你可以管理所有的郵件、通訊錄、日程表等。

它可能是 Microsoft Outlook 的非常好的替代品，因為它是快速且高度高配置的消息管理工具。它有很好的用户界面，你會發現很容易上手。

$ sudo apt-get install kontact

76、NitroShare ​

NitroShare 是一個跨平台、開源的網絡文件共享應用。它讓你輕鬆的在局域網的多個操作系統中共享文件。它簡單而強大，當在局域網中運行 NitroShare 時，它會自動偵查其它設備。

文件傳輸速度讓 NitroShare 成為一個傑出的文件共享應用，它在能夠勝任的硬件中能夠達到 GB 級的傳輸速度。沒有必要額外配置，安裝完成後你就可以開始文件傳輸。

$ sudo apt-add-repository ppa:george-edison55/nitroshare
$ sudo apt-get update
$ sudo apt-get install nitroshare

77、Konversation ​

Konversation 是一個為 KDE 桌面環境開發的開源的網絡中繼聊天（IRC）客户端。它給了你到 Freenode 網絡頻道的快速入口，你可以為大多數發行版找到支持。

它是一個簡單的聊天客户端，支持 IPv6 鏈接、SSL 服務器支持、書籤、屏幕通知、UTF-8 檢測和另外的主題。它易於使用的 GUI 是高度可配置的。

$ sudo apt-get install konversation

78、Discord ​

如果你是硬核遊戲玩家，經常玩在線遊戲，我有一個很棒的應用推薦給你。Discord 是一個免費的網絡電話應用，尤其是為在線遊戲者們設計的。它是一個跨平台的應用，可用來文字或語音聊天。

Discord 是一個非常流行的語音通話應用遊戲社區，因為它是完全免費的，它是 Skype、Ventrilo、Teamspeak 的很好的競爭者。它同樣提供清晰的語音質量、現代的文本聊天，你可以共享圖片、視頻和鏈接。

79、QuiteRSS ​

QuiteRSS是一個開源的 RSS 和 Atom 新聞摘要的聚合應用。它是跨平台的摘要閲讀器，用 Qt 和 C++ 寫的。它有簡單的用户界面，你可以改變為經典或者報紙模式。它集成了 webkit 瀏覽器，因此，你可以在單個窗口執行所有任務。

QuiteRSS 自帶了很多功能，像內容過濾、自動規劃摘要、導入/導出 OPML、系統托盤集成了很多其它摘要閲讀器有的特點。

$ sudo apt-get install quiterss

80、MPV Media Player ​

MPV 是一個自由開源的媒體播放器，基於 MPlayer 和 MPlayer 2。它有簡單的用户界面，用户只需要拖放音/視頻文件來播放，因為在 GUI 上沒有添加媒體文件的選項。

關於 MPV 的一件事是它可以輕鬆播放 4K 視頻，Linux 發行版中的其它媒體播放器可能做不到。它同樣給了用户播放在線視頻流站點如 YouTube 和 Dailymotion 的能力。

$ sudo add-apt-repository ppa:mc3man/mpv-tests
$ sudo apt-get update
$ sudo apt-get install -y mpv

81、Plume Creator ​

如果你是一個作家，那麼 Plume Creator 是你必不可少的應用，因為你在 Ubuntu 上找不到其它應用像 Plume Creater 這樣。寫作和編輯故事、章節是繁重的任務，在 Plume Creator 這個令人驚奇的工具的幫助下，將大大幫你簡化這個任務。

它是一個開源的應用，擁有精簡的用户界面，開始你可能覺得困惑，但不久你就會習慣的。它提供的功能有：編輯筆記、摘要、導出 HTML 和 ODT 格式、富文本編輯。

$ sudo apt-get install plume-creator

82、Chromium Web 瀏覽器 ​

Chromium 是一個由 Google 開發和發佈的開源 Web 瀏覽器。Chromium 就其外觀和特點而言，很容易被誤認為是 Chrome。它是輕量級和快速的網絡瀏覽器，擁有最小用户界面。

如果你經常在 Windows 上使用 Google Chrome，而想在 Linux 上尋找一個類似的瀏覽器，那麼 Chromium 就是你的最佳選擇，你可以登錄到你的 Google 賬户以訪問包括 Gmail 在內的所有 Google 服務。

83、簡單天氣指示器 ​

簡單天氣指示器是用 Python 開發的開源天氣提示應用。它自動偵查你的位置，並顯示你天氣信息像温度，下雨的可能性，濕度，風速和可見度。

簡單天氣指示器自帶一些可配置項，例如位置檢測、温度單位、位置可見度開關等等。它是一個還酷的應用，可以根據你的桌面來調整。

84、SpeedCrunch ​

SpeedCrunch 是一個快速和高精度的科學計算器。它預置了數學函數、用户定義函數、複數和單位轉換支持。它有簡單的用户界面並易於使用。

這個科學計算器有令人吃驚的特點，如結果預覽、語法高亮和自動補全。它是跨平台的，並有多語言支持。

85、Scribus ​

Scribus 是一個自由開源的桌面出版應用，允許你創建宣傳海報、雜誌和圖書。它是基於 Qt 工具器的跨平台應用，在 GNU 通用公共許可證下發布。它是一個專業的應用，擁有 CMYK 和 ICC 顏色管理的功能、基於 Python 的腳本引擎，和 PDF 創建功能。

Scribus 有相當好的用户界面，易於使用，可以在低配置下輕鬆使用。在所有的最新的 Linux 發行版的軟件中心可以下載它。

86. Cura ​

Cura 是一個由 David Braam 開發的開源的 3D 打印應用。Ultimaker Cura 是 3D 打印世界最流行的軟件，世界範圍有百萬用户在使用。它遵守 3D 打印模型的 3 步：設計、準備、打印。

它是功能豐富的 3D 打印應用，為 CAD 插件和擴展提供了無縫支持。它是一款簡單易於使用的工具，新手藝術家可以馬上開始了。它支持主流的文件格式像 STL、3MF 和 OBJ。

87、Nomacs ​

Nomacs 是一款開源、跨平台的圖像瀏覽器，支持所有主流的圖片格式包括 RAW 和 psd 圖像。它可以瀏覽 zip 文件中的圖像或者 Microsoft Office 文件並提取到目錄。

Nomacs 擁有非常簡單的用户界面，圖像縮略圖在頂部，它提供了一些基本的圖像操作特點像修改、調整大小、旋轉、顏色糾正等。

$ sudo add-apt-repository ppa:nomacs/stable
$ sudo apt-get update
$ sudo apt-get install nomacs

88、BitTicker ​

BitTicker 是一個 Ubuntu 上的在線的 BTC-USDT 價格接收器。它是一個簡單的工具，能夠連接到 bittrex.com　市場，提取最新的　BTC-USDT 價格，並在系統托盤顯示 Ubuntu 時鐘。

它是簡單但有用的工具，如果你經常有規律的投資比特幣並且必須瞭解價格波動的話。

89、Organize My Files ​

Organize My Files 是一個跨平台的一鍵點擊文件組織工具，它在 Ubuntu 中以 Snap 包的形式獲得。它簡單而強大，可以幫助你找到未組織的文件，通過簡單點擊來掌控它們。

它有易於理解的用户界面，強大且快速。它提供了很多功能：自動組織、遞歸組織、智能過濾和多層文件夾組織等。

90、GnuCash ​

GnuCash 是一個金融賬户軟件，在 GNU 公共證書下自由使用。它是個人和商業賬户的理想軟件。它有簡單的用户界面允許你追蹤銀行賬户、股票、收入和花費。

GnuCash 實現了雙入口記賬系統，基於專業的賬户原則來確保帳薄的平衡和報告的精確。

91、Calibre ​

Calibre 是一個跨平台的開源的面向電子書需求的解決方案。它是一個簡單的電子書管理器，提供顯示、創建、編輯電子書、組織已存在的電子書到虛擬書庫、同步和其它更多功能。

Calibre 同樣可以幫你轉換電子書到你需要的格式併發送到你的電子書閲讀設備。Calibre 是一個很棒的工具，如果你經常閲讀和管理電子書的話。

92、MATE 詞典 ​

MATE 詞典是一個簡單的詞典，基本上是為 MATE 桌面環境開發的。你可以僅僅輸入字然後這個字典會顯示意思和引用。

它是簡單和輕量級的在線詞典，有極簡的用户界面。

93、Converseen ​

Converseen 是免費的跨平台的批量圖片處理應用，允許你轉換、編輯、調整、旋轉、裁剪大量圖像，而僅僅需要一次鼠標點擊。它提供了使用前綴或後綴圖像批量重命名和從一個 Windows 圖標文件提取圖像等功能。

它有很好的用户界面，易於使用，即時你是一個新手。它也能夠轉換整個 PDF 文件為圖像集合。

94、貼片地圖編輯器 ​

貼片地圖編輯器是一個免費的關卡地圖編輯器，允許你以正交、等軸、和六角等方向編輯地圖。這個工具對於遊戲開發者在遊戲引擎開發階段內可能非常有用。

它是一個通用的地圖編輯器，讓你創建升級位置、地圖佈局、碰撞區域和敵人位置。它保存所有的數據為 tmx 格式。

95. Qmmp ​

Qmmp 是一個自由開源的音頻播放器，用 C++ 和 Qt 開發的。它是跨平台的音頻播放器，界面與 Winamp 很相似。 它有簡單的直觀的用户界面，可以用 Winamp 皮膚替代默認的 UI。

它提供了自動唱片集封面獲取、支持多藝術家，另外的插件和擴展支持和其它與 Winamp 相似的特點。

$ sudo add-apt-repository ppa:forkotov02/ppa
$ sudo apt-get update
$ sudo apt-get install qmmp qmmp-q4 qmmp-plugin-pack-qt4

96、Arora ​

Arora 是一個免費開源的 web 瀏覽器，提供了專有的下載管理器、書籤、私密模式、選項卡式瀏覽。

Arora web 瀏覽器由 Benjamin C. Meyer 開發，它由於它的輕量自然靈活的特點在 Linux 用户間很受歡迎。

97、XnSketch ​

XnSketch 是一個 Ubuntu 上的酷應用，只需要幾次點擊，就能幫你轉換你的圖片為卡通或素描圖。它展現了 18 個不同的效果，例如：鋭化、白描、鉛筆畫等等。

它有優秀的用户界面，易於使用。一些額外的特點包括透明度和邊緣鋭化調整、對比度、亮度、飽和度調整。

98、Geany ​

Geany 是一個簡單而輕量級的文本編輯器，像一個集成開發環境。它是跨平台的文本編輯器，支持所有主流編程語言包括 Python、C++、LaTex、Pascal、C#、etc。

Geany 有個類似於 Notepad++ 編程編輯器的簡單用户界面。它提供了 IDE 的功能，如代碼導航、自動補完、格式高亮，並支持擴展。

$ sudo apt-get install geany

99、Mumble ​

Mumble 是又一個 VoIP 應用，與 Discord 類似。Mumble 同樣最初是為在線遊戲玩家設計的，使用客户端-服務器架構提供了端到端的聊天。在 Mumble 上的聲音質量非常好，它提供了端到端的加密來確保私密性。

Mumble 是一個開源應用，有簡單的用户界面，易於使用。Mumble 在 Ubuntu 軟件中心可以下載。

$ sudo apt-get install mumble-server

100、Deluge ​

Deluge 是一個跨平台的輕量級的 BitTorrent 客户端，能夠用來在 Ubuntu 上下載文件。BitTorrent 客户端與很多 Linux 發行版一起發行，但 Deluge 是最好的 BitTorrent 客户端，界面簡單、易於使用。

Deluge 擁有你可以在其它 BitTorrent 客户端上發現的所有功能，但是一個功能特別突出，它給了用户從其它設備訪問客户端的能力，這樣你可以遠程下載文件了。

$ sudo add-apt-repository ppa:deluge-team/ppa
$ sudo apt-get update
$ sudo apt-get install deluge

所以這些就是 2018 年我為大家選擇的 Ubuntu 上最好的 100 個應用了。所有列出的應用都在 Ubuntu 18.04 上測試了，肯定在老版本上也能運行。
