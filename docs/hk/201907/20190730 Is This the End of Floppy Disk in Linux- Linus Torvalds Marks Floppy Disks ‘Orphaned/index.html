Linux 中的軟盤走向終結了嗎？Torvalds 將軟盤的驅動標記為“孤兒” ​

在 Linux 內核最近的提交當中，Linus Torvalds 將軟盤的驅動程序標記為孤兒。這標誌着軟盤在 Linux 中步入結束了嗎？

有可能你很多年沒見過真正的軟盤了。如果你正在尋找帶軟盤驅動器的計算機，可能需要去博物館裏看看。

在二十多年前，軟盤是用於存儲數據和運行操作系統的流行介質。早期的 Linux 發行版使用軟盤進行“分發”。軟盤也廣泛用於保存和傳輸數據。

你有沒有想過為什麼許多應用程序中的保存圖標看起來像軟盤？因為它就是軟盤啊！軟盤常用於保存數據，因此許多應用程序將其用作保存圖標，並且這個傳統一直延續至今。

今天我為什麼要説起軟盤？因為 Linus Torvalds 在一個 Linux 內核代碼的提交裏標記軟盤的驅動程序為“孤兒”。

在 Linux 內核中被標記為“孤兒”的軟盤驅動程序 ​

正如你可以在 GitHub 鏡像上的提交中看到的那樣，開發人員 Jiri 不再使用帶有軟驅的工作計算機了。而如果沒有正確的硬件，Jiri 將無法繼續開發。這就是 Torvalds 將其標記為孤兒的原因。

越來越難以找到可以實際工作的軟盤的物理硬件，雖然 Willy 能夠對此進行測試，但我認為從實際的硬件角度來看，這個驅動程序幾乎已經死了。目前仍然銷售的硬件似乎主要是基於 USB 的，根本不使用這種傳統的驅動器。

“孤兒”在 Linux 內核中意味着什麼？ ​

“孤兒”意味着沒有開發人員能夠或願意支持這部分代碼。如果沒有其他人出現繼續維護和開發它，孤兒模組可能會被棄用並最終刪除。

它沒有被立即刪除 ​

Torvalds 指出，各種虛擬環境模擬器仍在使用軟盤驅動器。所以軟盤的驅動程序不會被立即丟棄。

各種 VM 環境中仍然在仿真舊的軟盤控制器，因此該驅動程序不會消失，但讓我們看看是否有人有興趣進一步維護它。

為什麼不永遠保持內核中的軟盤驅動器支持呢？因為這將構成安全威脅。即使沒有真正的計算機使用軟盤驅動程序，虛擬機仍然擁有它，這將使虛擬機容易受到攻擊。

一個時代的終結？ ​

這將是一個時代的結束還是會有其他人出現並承擔起在 Linux 中繼續維護軟盤驅動程序的責任？只有時間會給出答案。

在 Linux 內核中，軟盤驅動器成為孤兒我不覺得有什麼可惜的。

在過去的十五年裏我沒有使用過軟盤，我懷疑很多人也是如此。那麼你呢？你有沒有用過軟盤？如果是的話，你最後一次使用它的時間是什麼時候？
