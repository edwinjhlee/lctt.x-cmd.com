在線試用 200 多種 Linux 和 Unix 操作系統 ​

不久前我們介紹過OSBoxes，該網站提供了一系列免費且開箱即用的 Linux 和 Unix 虛擬機。你可以在你的 Linux 系統中下載這些虛擬機並用 VirtualBox 或 VMWare workstation 試用。今天，我偶然發現一個名叫 “DistroTest” 的類似服務。與 OSBoxes 不同之處在於 DistroTest 讓你免費試用現場版 Linux 和 Unix 操作系統。你可以在線試用 200 多種 Linux 和 Unix 操作系統而無需在本地安裝它們。只要打開該網站，選擇你需要的 Linux/Unix 發行版，然後開始試用！

兩個名為 Klemann Andy 和 Forster Tobias 的好心人用 Qemu 在 Debian 上運行了這項網絡服務。這裏列出的公開發行版在使用上沒有任何限制。你可以象使用本地系統一樣使用系統的所有功能。你可以安裝和卸載軟件。你可以測試安裝的程序，甚至刪除或格式化硬盤，刪除系統文件。簡而言之，DistroTest讓喜歡嘗試不同發行版的的人自行決定：

  • 最適合他們的發行版
  • 想要哪種圖形界面
  • 他們可以選擇哪些配置

本文撰寫之時，DistroTest 提供了 227 種操作系統的 711 個版本。我已經使用 Linux 很多年，但我從未聽説過這裏列出的一些發行版。説實話我甚至不知道 Linux 操作系統有如此之多的版本。

如何使用？ ​

要試用任何操作系統，點擊下面的鏈接： https://distrotest.net/

在這個網站，你會看到可用的操作系統列表。單擊你想了解的發行版名稱即可。

用 DistroTest 試用 200 多種Linux和Unix操作系統

本文中我會試用 Arch Linux。

單擊發行版鏈接後，在跳轉到的頁面單擊 “System start” 按鈕即可啓動所選操作系統。

此現場版操作系統會在新瀏覽器窗口中啓動。你可以通過內建的 noVNC viewer 訪問它。請在瀏覽器中啓用/允許 DistroTest 網站的彈出窗口，否則無法看到彈出的 noVNC 窗口。

按回車啓動現場版系統。

這就是 Arch Linux 現場版系統：

你可以免費使用這個系統 1 小時。你可以試用該現場版操作系統、安裝應用、卸載應用、刪除或修改系統文件、測試配置或腳本。每次關機後，一切都會恢復成默認配置。

一旦試用結束，回到 DistroTest 頁面並停止你試用的系統。如果你不想啓用 DistroTest 頁面的彈出窗口，用你本地系統安裝的任意 VNC 客户端也可以。VNC 登錄信息可在同一頁面找到。

DistroTest 服務對兩類用户比較實用：想在線試用 Linux/Unix 系統，或是沒有喜歡的操作系統現場版 ISO 鏡像文件的人。我在 4G 網絡上測試的結果一切正常。

實際上，我沒法在這個虛擬機裏安裝新軟件 ​

試用期間我注意到的一個問題是這個虛擬機沒有聯網。除了本地環回接口之外沒有其他網絡接口。沒有聯網也沒有本地鏡像源的情況下我沒法下載和安裝新軟件。我不知道為何網站聲稱可以安裝軟件。也許在這點上我遺漏了什麼。我在 DistroTest 上能做的只是看看現成的系統，試用現場版而不能安裝任何軟件。

推薦閲讀：

  • 免費在線學習和練習 Linux命令！
  • 在瀏覽器中運行 Linux 和其他操作系統

暫時就這樣了。我不知道 DistroTest 團隊如何設法託管了這麼多操作系統。我肯定這會花不少時間。這的確是件值得稱讚的工作。我非常感激項目成員的無私行為。榮譽歸於你們。加油！
