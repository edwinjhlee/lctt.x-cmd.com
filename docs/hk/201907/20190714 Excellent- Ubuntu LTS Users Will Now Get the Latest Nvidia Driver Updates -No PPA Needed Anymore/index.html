好消息！Ubuntu LTS 用户不需要 PPA 也可以獲得最新的 Nvidia 驅動更新 ​

要在 Ubuntu LTS 上獲得的最新 Nvidia 驅動程序，你不必再使用 PPA 了。最新的驅動程序現在將在 Ubuntu LTS 版本的存儲庫中提供。

你可能已經注意到在 Ubuntu 上安裝最新和最好的 Nvidia 二進制驅動程序更新的麻煩。

默認情況下，Ubuntu 提供開源的 Nvidia Nouveau 驅動程序，這有時會導致 Ubuntu 卡在啓動屏幕上。

你也可以輕鬆地在 Ubuntu 中安裝專有的 Nvidia 驅動程序。問題是默認 Ubuntu 存儲庫中的 Nvidia 驅動程序不是最新的。為此，幾年前 Ubuntu 引入了一個專門的 PPA以解決這個問題。

使用官方 PPA 仍然是安裝閉源圖形驅動程序的一個不錯的解決方法。但是，它絕對不是最方便的選擇。

但是，現在，Ubuntu 同意將最新的 Nvidia 驅動程序更新作為 SRU（StableReleaseUpdates）的一部分提供。所以，你將在使用 Ubuntu LTS 版本時也擁有 Nvidia 驅動程序了。

好吧，這意味着你不再需要在 Ubuntu LTS 版本上單獨下載/安裝 Nvidia 圖形驅動程序。

就像你會獲得瀏覽器或核心操作系統更新（或安全更新）的更新包一樣，你將獲得所需的 Nvidia 二進制驅動程序的更新包。

這個最新的 Nvidia 顯卡驅動程序可靠嗎？ ​

SRU 字面上指的是 Ubuntu（或基於 Ubuntu 的發行版）的穩定更新。因此，要獲得最新的圖形驅動程序，你應該等待它作為穩定更新釋出，而不是選擇預先發布的更新程序。

當然，沒有人能保證它能在所有時間內都正常工作 —— 但安裝起來比預先發布的更安全。

怎樣獲得最新的 Nvidia 驅動程序？ ​

你只需從軟件更新選項中的其他驅動程序部分啓用“使用 NVIDIA 驅動程序元數據包……”。

最初，The Linux Experiment 通過視頻分享了這個消息 —— 然後 Ubuntu 的官方 Twitter 作為公告重新推送了它。你可以觀看下面的視頻以獲取更多詳細信息：

  • https://youtu.be/NFdeWTQIpjo

支持哪些 Ubuntu LTS 版本？ ​

目前，Ubuntu 18.04 LTS 已經可用了，它也將很快在 Ubuntu 16.04 LTS 上可用（隨後的 LTS 也將次第跟上）。

總結 ​
