Linux 下易用的光盤鏡像管理工具 ​

磁盤鏡像包括了整個磁盤卷的文件或者是全部的存儲設備的數據，比如説硬盤，光盤（DVD,CD,藍光光碟），磁帶機，USB閃存，軟盤。一個完整的磁盤鏡像應該包含與原來的存儲設備上一樣完整、準確，包括數據和結構信息。

磁盤鏡像文件格式可以是採用開放的標準，像ISO格式的光盤鏡像，或者是專有的軟件應用程序的特定格式。"ISO"這個名字來源於用CD存儲的ISO 9660文件系統。但是，當用户轉向Linux的時候，經常遇到這樣的問題，需要把專有的的鏡像格式轉換為開放的格式。

磁盤鏡像有很多不同的用處，像燒錄光盤，系統備份，數據恢復，硬盤克隆，電子取證和提供操作系統（即LiveCD/DVDs）。

有很多不同的方法可以把ISO鏡像掛載到Linux系統下。強大的mount 命令給我們提供了一個簡單的解決方案。但是如果你需要很多工具來操作磁盤鏡像，你可以試一試下面的這些強大的開源工具。

很多工具還沒有看到最新的版本，所以如果你正在尋找一個很好用的開源工具，你也可以加入，一起來為開源做出一點貢獻。

Furius ISO Mount ​

Furius ISO Mount是一個簡單易用的開源應用程序，可以用來掛載鏡像文件，它支持直接打開ISO,IMG,BIN,MDF和NRG格式的鏡像而不用把他們燒錄到磁盤。

特性：

  • 支持自動掛載ISO, IMG, BIN, MDF and NRG鏡像文件
  • 支持通過 loop 方式掛載 UDF 鏡像
  • 自動在根目錄創建掛載點
  • 自動解掛鏡像文件
  • 自動刪除掛載目錄，並返回到主目錄之前的狀態
  • 自動記錄最近10次掛載歷史
  • 支持掛載多個鏡像文件
  • 支持燒錄ISO文件及IMG文件到光盤
  • 支持MD5校驗和SHA1校驗
  • 自動檢索之前解掛的鏡像
  • 自動創建手動掛載和解掛的日誌文件
  • 語言支持（目前支持保加利亞語，中文（簡體），捷克語，荷蘭語，法語，德語，匈牙利語，意大利語，希臘語，日語，波蘭語，葡萄牙語，俄語，斯洛文尼亞語，西班牙語，瑞典語和土耳其語）
  • 項目網址： launchpad.net/furiusisomount/
  • 開發者: Dean Harris (Marcus Furius)
  • 許可： GNU GPL v3
  • 版本號： 0.11.3.1

###fuseiso

fuseiso 是用來掛載ISO文件系統的一個開源的安全模組。

使用FUSE，我們完全可以在用户空間裏運行一個完整的文件系統。

特性：

  • 支持讀ISO,BIN和NRG鏡像，包括ISO 9660文件系統
  • 支持普通的ISO 9660級別1和級別2
  • 支持一些常用的擴展，想Joliet，RockRidge和zisofs
  • 支持非標準的鏡像，包括CloneCD's IMGs 、Alcohol 120%'s MDFs 因為他們的格式看起來恰好像BIN鏡像一樣
  • 項目網址： sourceforge.net/projects/fuseiso
  • 開發者： Dmitry Morozhnikov
  • 許可： GNU GPL v2
  • 版本號： 20070708

###iat

iat（Iso 9660分析工具）是一個通用的開源工具，能夠檢測很多不同鏡像格式文件的結構，包括BIN,MDF,PDI,CDI,NRG和B5I,並轉化成ISO 9660格式.

特性：

  • 支持讀取（輸入）NRG,MDF,PDI,CDI,BIN,CUE 和B5I鏡像
  • 支持用 cd 刻錄機直接燒錄光盤鏡像
  • 輸出信息包括：進度條，塊大小，ECC扇形分區（大小），頭分區（大小），鏡像偏移地址等等
  • 項目網址： sourceforge.net/projects/iat.berlios
  • 開發者： Salvatore Santagati
  • 許可： GNU GPL v2
  • 版本號： 0.1.3

###AcetoneISO

AcetoneISO 是一個功能豐富的開源圖形化應用程序，用來掛載和管理CD/DVD鏡像。

當你打開這個程序，你就會看到一個圖形化的文件管理器用來掛載鏡像文件，包括專有的鏡像格式，也包括像ISO, BIN, NRG, MDF, IMG 等等，並且允許您執行一系列的操作。

AcetoneISO是用QT 4寫的，也就是説，對於基於QT的桌面環境能很好的兼容，像KDE，LXQT或是Razor-qt。

這個軟件適用於所有正在尋找Linux版本的Daemon Tools的人。

特性：

  • 支持掛載大多數windows 鏡像，界面簡潔易用
  • 可以將其所有支持鏡像格式轉換到ISO,或者是從中提取內容
  • 加密，壓縮，解壓任何類型的鏡像
  • 轉換DVD成xvid avi，支持將各種常規視頻格式轉換成xvid avi
  • 從視頻裏提取聲音
  • 從不同格式中提取鏡像中的文件，包括bin mdf nrg img daa dmg cdi b5i bwi pdi
  • 用Kaffeine / VLC / SMplayer播放DVD鏡像，可以從Amazon 自動下載封面。
  • 從文件夾或者是CD/DVD生成ISO鏡像
  • 可以做鏡像的MD5校驗，或者是生成鏡像的MD5校驗碼
  • 計算鏡像的ShaSums（128,256和384位）
  • 支持加密，解密一個鏡像文件
  • 按兆數分拆和合並鏡像
  • 以高壓縮比將鏡像壓縮成7z 格式
  • 翻錄PSX CD成BIN格式，以便在ePSXe/pSX模擬器裏運行
  • 為BIN和IMG格式恢復丟失的 CUE 文件
  • 把MAC OS的DMG鏡像轉換成可掛載的鏡像
  • 從指定的文件夾中掛載鏡像
  • 創建資料庫來管理一個大的鏡像集合
  • 從CD/DVD 或者是ISO鏡像中提取啓動文件
  • 備份CD成BIN鏡像
  • 簡單快速的把DVD翻錄成Xvid AVI
  • 簡單快速的把常見的視頻（avi, mpeg, mov, wmv, asf）轉換成Xvid AVI
  • 簡單快速的把FLV 換換成AVI 格式
  • 從YouTube和一些視頻網站下載視頻
  • 提取一個有密碼的RAR存檔
  • 支持轉換任何的視頻到PSP上
  • 國際化的語言支持支持（英語，意大利語，波蘭語，西班牙語，羅馬尼亞語，匈牙利語，德語，捷克語和俄語）
  • 項目網址: sourceforge.net/projects/acetoneiso
  • 開發者: Marco Di Antonio
  • 許可: GNU GPL v3
  • 版本號: 2.3

###ISO Master

ISO Master是一個開源、易用的、圖形化CD 鏡像編輯器，適用於Linux 和BSD 。可以從ISO 裏提取文件，給ISO 裏面添加文件，創建一個可引導的ISO，這些都是在一個可視化的用户界面完成的。可以打開ISO，NRG 和一些MDF文件，但是隻能保存成ISO 格式。

ISO Master 是基於bkisofs 創建的，這是一個簡單、穩定的閲讀，修改和編寫ISO 鏡像的軟件庫，支持Joliet, RockRidge 和EL Torito擴展，

特性：

  • 支持讀ISO 格式文件（ISO9660, Joliet, RockRidge 和 El Torito），大多數的NRG 格式文件和一些單軌道的MDF文件，但是，只能保存成ISO 格式
  • 創建和修改一個CD/DVD 格式文件
  • 支持CD 格式文件的添加或刪除文件和目錄
  • 支持創建可引導的CD/DVD
  • 國際化的支持
  • 項目網址: www.littlesvr.ca/isomaster/
  • 開發者: Andrew Smith
  • 許可: GNU GPL v2
  • 版本號: 1.3.11
