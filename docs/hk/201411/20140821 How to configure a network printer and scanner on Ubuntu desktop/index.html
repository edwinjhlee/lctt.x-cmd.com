如何在ubuntu桌面配置一個網絡打印機和掃描儀 ​

在之前的文章中, 我們討論過如何在Linux服務器安裝各種各樣的打印機（當然也包括網絡掃描儀）。今天我們將來處理另一端：如何通過桌面客户端來訪問網絡打印機/掃描儀。

網絡環境 ​

在這個安裝教程中，我們的服務器（Debian Wheezy 7.2版本）的IP地址是192.168.0.10，我們的客户端(Ubuntu 12.04版本)的IP地址是192.168.0.105.注意這兩台機器是在同一個網段（192.168.0.0/24).如果我們想允許打印機訪問其它網段，我們需要在服務器上修改cupsd.conf文件的以下部分：

<Location />
  Order allow,deny
  Allow localhost
  Allow from XXX.YYY.ZZZ.*
</Location>

（在上述例子中，我們授予打印機從本地或者任何系統能夠訪問打印機，這些系統的IPv4地址以XXX.YYY.ZZZ開始。

為了驗證哪些打印機可以在我們的服務器上適用，我們也可以在服務器上使用lpstat命令，或者瀏覽網頁https://192.168.0.10:631/printers page.

root@debian:~# lpstat -a 

EPSON_Stylus_CX3900 accepting requests since Mon 18 Aug 2014 10:49:33 AM WARST
PDF accepting requests since Mon 06 May 2013 04:46:11 PM WARST
SamsungML1640Series accepting requests since Wed 13 Aug 2014 10:13:47 PM WARST

在Ubuntu桌面安裝網絡打印機 ​

在我們的Ubuntu 12.04的客户端，我們將打開"Printing"菜單(Dash -> Printing).你會注意到在其它發行版中，這個名字也許會有一點差別（例如會叫做"Printers" 或者 "Print & Fax"）:

還沒有打印機添加到我們的客户端：

下面是在Ubuntu桌面客户端安裝一台網絡打印機的一些步驟。

1) “Add”按鈕將彈出 "New Printer" 菜單。我們將選擇"Network printer" -> "Find Network Printer"並輸入我們服務器的IP地址，接着點擊"Find":

2) 在最下面我們將會看到可使用的打印機的名稱。我們來選擇這台三星打印機並按"Forward":

3) 我們將會被要求填寫一些關於我們打印機的信息。當我們輸入完成時，將點擊 "Apply"按鈕。

4) 我們接下來將被詢問是否打印一張測試頁。讓我們點擊"Print test page"吧:

這個打印任務將被創建為本地id 2：

5)適用我們服務器上的CUPS網絡藉口，我們可以觀察到打印任務已經提交成功了（打印機 -> SamsungML1640系列 -> 顯示完成任務):

我們也可以通過在打印機服務器上運行以下命令顯示同樣信息：

 root@debian:~# cat /var/log/cups/page_log | grep -i samsung 

SamsungML1640Series root 27 [13/Aug/2014:22:15:34 -0300] 1 1 - localhost Test Page - -
SamsungML1640Series gacanepa 28 [18/Aug/2014:11:28:50 -0300] 1 1 - 192.168.0.105 Test Page - -
SamsungML1640Series gacanepa 29 [18/Aug/2014:11:45:57 -0300] 1 1 - 192.168.0.105 Test Page - -

這個page_log日誌顯示每一頁被打印過的信息，只包括哪些用户發送這些打印任務，打印日期&時間，以及客户端的IPv4地址。

要安裝Epson噴墨和PDF打印機，我們只需重複第1-5的步驟即可，並每一次選擇左邊的打印隊列。例如，在下圖中選擇PDF打印機：

然而，請注意到根據CUPS-PDF 文檔中，根據默認：

PDF文件將會被放置在打印作業的所有者命名的子目錄內。在這個案例中，打印作業的所有者不能被識別（i.e.不會存在服務器中）輸出的內容被放置在匿名操作的文件中。

這些默認的文件夾可以通過改變在/etc/cups/cups-pdf目錄中的Out值和AnonDirName變量來修改。這裏，${HOME}被擴展到用户的家目錄中：

Out ${HOME}/PDF
AnonDirName /var/spool/cups-pdf/ANONYMOUS

網絡打印實例 ​

實例 #1 ​

從Ubuntu12.04中打印，通常在本地用gacanepa（具有相同名字存在打印機服務器上）。

打印到PDF打印機之後，讓我們來檢查打印機服務器上的/home/gacanepa/PDF目錄下的內容：

root@debian:~# ls -l /home/gacanepa/PDF 

total 368
-rw------- 1 gacanepa gacanepa 279176 Aug 18 13:49 Test_Page.pdf
-rw------- 1 gacanepa gacanepa   7994 Aug 18 13:50 Untitled1.pdf
-rw------- 1 gacanepa gacanepa  74911 Aug 18 14:36 Welcome_to_Conference_-_Thomas_S__Monson.pdf

這個PDF文件被創建時的，權限已經設置為600(-rw-------)，這意味着只有打印任務的所有者(在這個例子中是gacanepa )可以訪問它們。我們可以通過修改the /etc/cups/cups-pdf.conf文件UserUMask變量的值來改變這種行為。例如，0033的umask值將可以使PDF打印者以及其它所有者擁有創建文件的權限，但是隻讀權限也會賦予給其它所有者。

 root@debian:~# grep -i UserUMask /etc/cups/cups-pdf.conf 

### Key: UserUMask
UserUMask 0033

對於那些不熟悉umask（有名用户文件創建模式掩碼），它作為一組可以用於控制那些為新文件創建時修改默認權限。給予特定的umask值，在計算最終文件的許可權限時，在文件基本權限(0666)和umask的單項按位補碼之間進行按位布爾 AND 運算。因此，如果設置一個umask值為0033，那麼新文件默認的權限將不是（0033）AND 0666 = 644的值（文件擁有者具有讀/寫/執行的權限，其他人擁有隻讀權限）。

實例 #2 ​

在Ubuntu12.04執行打印，本地登錄用户為jdoe（同樣的帳號名稱但是服務器上是不存在的）。

 root@debian:~# ls -l /var/spool/cups-pdf/ANONYMOUS 

total 5428
-rw-rw-rw- 1 nobody nogroup 5543070 Aug 18 15:57 Linux_-_Wikipedia__the_free_encyclopedia.pdf

這個PDF被創建時賦予的權限是666(-rw-rw-rw-)，這意味着每個人都可以訪問它們。我們可以通過編輯在/etc/cups/cups-pdf.conf文件中的AnonUMask值來改變這種行為。

在這一點上，你也許會疑惑：為什麼同樣安裝一台網絡打印機，大多數（當然不是全部）當前的Linux桌面發行版都會內置一個"打印到文件"的功能來允許用户動態創建PDF文件？

使用一台網絡PDF打印機有以下好處：

  • 一個網絡打印機（任何類型的）允許你直接從命令列直接打印，無需首先打開文件。

  • 在其它操作系統上安裝一個網絡客户端，一個PDF網絡打印機備件，於是系統管理員不必再單獨需要安裝PDF創建者實用程序（也避免了最終用户安裝這些工具存在的風險）。

  • 網絡PDF打印機允許通過配置權限直接打印一個網絡共享，如我們所見的例子。

在Ubuntu桌面安裝一個網絡掃描儀 ​

這裏是通過Ubuntu桌面客户端安裝和訪問一台網絡掃描儀的一些步驟。假設網絡掃描儀服務器已經啓動並運行所述here.

總結 ​

擁有一或多台網絡打印機或掃描儀在任何辦公和家庭網絡中都是非常方便適用的，並同時提供了許多好處。例舉如下：

  • 多用户（從不同的平台/地方）都能夠向打印機發送打印作業的隊列。

  • 由於硬件共享達到了節約成本和維護的作用。

我希望這篇文章可以幫助你更充分地利用這些有點。
