7個Linux桌面需要改進之處 ​

在過去的15年內，Linux桌面從一個還算湊合的邊緣化解決方案集合發展為一個獨特的創新來源和選擇之一。它的標準特點中有許多是要麼不適用於Windows系統，要麼就只適合作為一個專有的擴展軟件。因此，使用Linux愈發變得不僅是一個原則問題，也是一種偏好。

然而，儘管Linux桌面不停在進步，但是仍然存在差距。一些特點正在丟失，而一些已經丟失了，還有一些令人驚喜的附加功能可以輕易地提升桌面體驗，而不用挑戰用户的容忍度。

比如説，以下是7個有利於Linux桌面發展的改善建議：

7. 簡單的Email加密技術 ​

如今，各種Email閲讀器從Alpine到Thunderbird再到Kmail，都帶有Email加密技術。然而，關於它們的文檔手冊通常是不存在或者非常簡陋。

但是，即使你瞭解加密理論，但是使用起來仍然很困難。這些控件通常分散在配置菜單和選項卡中，需要為所有你需要和想要的設置進行一次徹底的搜索才行。如果你未能進行適當的加密設置，通常你找不到任何有用的反饋。

易用性方面最接近的是 Enigmail ，它是一個帶有面向初學者的設置嚮導的Thunderbird擴展。但是你一定要知道怎麼用Enigmail，新的加密設置菜單埋藏在撰寫窗口裏一級菜單下，和其他選項混在一起，這讓日常用户很迷惑。

不管是那種桌面環境，如你所知的，你應該對郵件加密，今天對安全和隱私的媒體不斷報道讓你知道加密有多重要。

6. 虛擬工作空間縮略圖 ​

不需要額外的顯示器，虛擬工作空間提供了更多桌面空間。然而，儘管它們很實用，但是虛擬工作空間的管理並沒有在過去十年發生改變。在大多數桌面上，你能通過每個工作空間上的pager程序（一個提供很少指示除了它的名字和數字的簡單矩形框）來控制它們 -- 或者，在Ubuntu的Unity 環境中，可以指出哪個工作空間是當前激活的。

確實，GNOME和Cinnamon能提供出不錯的視圖，但是它們的實用性受限於它們需要顯示屏大小的事實。而 KDE 寫出內容列表則和主流的圖形桌面不太協調。

一個比較不錯的解決方案應該是鼠標懸停在足夠大的縮略圖上來獲取正常的視圖，這樣就精確地查看每個工作空間上的東西了。

5. 一個合用的菜單 ​

現代型桌面很久之前就已經捨棄了級聯子菜單鋪滿整個桌面的經典型菜單了。如今，一般的電腦都有太多的應用程序以至於不能適應這樣的模式。

糟糕的是，沒有什麼主要的替代品能與經典型菜單一樣方便。把菜單根植於一個單一的窗口，其效果是不理想的，因為你要麼必須截掉子菜單要麼就用鼠標不斷地調整窗口大小。

但是全屏幕菜單的產品還要差，這意味着你甚至要在開始工作之前就調整屏幕，並且哪個搜索框其實只在你已經知道什麼應用程序可用的情況下才有用 -- 這種情況下你還不如直接用命令列。

坦白地説，我不知道拿什麼來解決這個問題，OS X下的spinner racks嗎？我可以肯定地説，所有現代型菜單產品在桌面上呈現出一個個精心構造的圖標似乎更是一個合理的選擇。

4. 一個專業的、實惠的視頻編輯器 ​

多年來，Linux已經慢慢地填充了軟件生產力上的空白。然而即便如此，它仍然缺少價格合理的視頻編輯軟件。

問題不在於沒有這樣的自由軟件。Maya 是動畫產業的標準之一，但是問題在於這樣的軟件的售價達數千美金。

另一邊，比如Pitivi或者是Blender這樣的免費軟件, 它們的功能性 -- 儘管它們的開發者足夠的努力 -- 只能保證基本功能。雖然取得了進步，但還是和用户們所期望的相去甚遠。

儘管我聽説一些非主流的廠家使用的是原生態Linux視頻編輯器，原因通常是因為他們抱怨其它編輯器不好，但其餘的人更願意減少麻煩，從而在其它操作系統上對視頻進行編輯。

3. 一個文檔處理器 ​

有一個極端是，那些需要進行文字處理的用户，Google Docs就讓他們滿意了；而另一個極端是對於那些排版設計的專家來説，Scribus是唯一比較可行的應用。

這兩種極端之間還有一層，是那些比如那些寫作很長的文本的文件的出版商和作家。這類用户有些是由基於Windows的 Adobe FrameMaker 來服務, 有些則由基於Linux的LibreOffice Writer來服務。

不幸的是，這些用户顯然不會優先考慮LibreOffice，Calligra Words， AbiWord或者是任何其它的辦公套件。應該提供給用户的辦公套件的特色功能包括：

  • 為每個文件建立引用書目資料庫。
  • 表格的樣式能和段落與字符保持一致。
  • 除了頁眉和頁腳，帶有持續性內容的頁面樣式，在每次使用樣式時都一樣。
  • 交叉引用存儲格式，以便不需要每次都手動創建。

無論是LibreOffice還是其它同類應用，提供這些特色功能與它們是否可用是並不相干的。但是沒有它們，Linux桌面對於一羣潛在的用户來説就是個不完善的東西。

2.彩色標題欄 ​

瀏覽器的擴展軟件向我們展示了彩色編碼標籤對於工作空間的作用。打開了八九個標籤後，它的標題欄就看不全了，所以顏色通常是最快區分標籤關係的方法。

同樣的系統也能用到桌面上。更好的是，彩色編碼也許可以按會話保存，允許用户同時打開某個任務所需的所有應用。到目前為止，我知道沒有任何一個桌面有這個特點。

1. 圖標欄 ​

多年以來，Stardock公司一直銷售着一個名叫 Fences 的擴展軟件,它用來分類和組織桌面上的圖標，你能用它給每個組取名並且可以把每個圖標都放在一起。另外，你可以指定不同的文件類型自動加入到一個組裏，並且按個人需要來隱藏和整理。

換句話説，fences讓用户整天在桌面上乾的事情自動有序地分組排列。然而，除了一兩個小功能與KDE的文件夾視圖類似之外，fences的功能仍然沒有出現在Linux桌面上。這也許是因為開發人員把注意力放到移動設備上作為靈感來源，而使用fences無疑是傳統工作站桌面的一大特徵。

我個人的列表 ​

我做了這種列表之後，讓我震驚的是這些不多的改進都是普適性的，其中幾項改進將會吸引大量特定的用户，只有一個是來自專有軟件的移植，其中一個至少是修飾性的而不是功能性的。

這一觀察表明，對於普通用户來説，Linux能添加的功能已經所剩無幾了。作為一個通用的桌面，Linux從幾年前到現在都很多元化，到今天，用户能從超過半打的主流桌面中選擇出一個來使用。

當然這不意味着，一些專家就不會有其它意見。另外，沒有人會關心不斷變化的需求會不會使改進令人滿意。但是它意味着這份充斥着改進建議的名單上的許多項目將會高度個人化。

所有這些都是為了拋磚引玉：你認為還有什麼其它的對桌面有益的建議嗎？
