假期志願服務的 4 種方式 ​

想要灑播些節日的快樂嗎？為開源組織做貢獻，幫助有需要的社區。

當領導者們配置人員和資源以做出積極改變時，就會產生社會影響。但是，許多社會努力都缺乏能夠為這些改變者提供服務的技術資源。然而，有些組織通過將想要做出改變的開發人員與迫切需要更好技術的社區和非營利組織聯繫起來，來促進技術進步。這些組織通常為特定的受眾提供服務，並招募特定種類的技術人員，它們有一個共同點：開源。

作為開發人員，我們出於各種原因試圖加入開源社區。有些是為了專業發展，有些是為了能夠與廣闊的網絡上令人印象深刻的技術人員合作，還有其他人則是因為他們清楚自己的貢獻對於項目的成功的必要性。為什麼不將你作為開發人員的才華投入到需要它的地方，而同時又為開源組織做貢獻呢？以下組織是實現此目標的一些主要事例。

Code for America ​

“Code for America” 是在數字時代，政府如何依靠人民為人民服務的一個例子。通過其 Brigade Network，該組織在美國各個城市中組織了一個由志願程序員、數據科學家、相關公民和設計師組成的全國聯盟。這些本地分支機構定期舉行聚會，向社區開放。這樣既可以向小組推出新項目，又可以協調正在進行的工作。為了使志願者與項目相匹配，該網站經常列出項目所需的特定技能，例如數據分析、內容創建和JavaScript。同時，Brigade 網站也會關注當地問題，分享自然災害等共同經驗，這些都可以促進成員之間的合作。例如，新奧爾良、休斯敦和坦帕灣團隊合作開發了一個颶風響應網站，當災難發生時，該網站可以快速響應不同的城市災難情況。

想要加入該組織，請訪問 該網站 獲取 70 多個 Brigade 的清單，以及個人加入組織的指南。

Code for Change ​

“Code for Change” 顯示了即使在高中時期，也可以為社會做貢獻。印第安納波利斯的一羣高中開發愛好者成立了自己的俱樂部，他們通過創建針對社區問題的開源軟件解決方案來回饋當地組織。“Code for Change” 鼓勵當地組織提出項目構想，學生團體加入並開發完全自由和開源的解決方案。該小組已經開發了諸如“藍寶石”之類的項目，該項目優化了當地難民組織的志願者管理系統，並建立了民權委員會的投訴表格，方便公民就他們所關心的問題在網上發表意見。

有關如何在你自己的社區中創建 “Code for Change”，訪問他們的網站。

Python for Good/Ruby for Good ​

“Python for Good” 和 “Ruby for Good” 是在俄勒岡州波特蘭市和弗吉尼亞州費爾法克斯市舉辦的雙年展活動，該活動將人們聚集在一起，為各自的社區開發和制定解決方案。

在週末，人們聚在一起聆聽當地非營利組織的建議，並通過構建開源解決方案來解決他們的問題。 2017 年，“Ruby For Good” 參與者創建了 “Justice for Juniors”，該計劃指導當前和以前被監禁的年輕人，並將他們重新融入社區。參與者還創建了 “Diaperbase”，這是一種庫存管理系統，為美國各地的尿布庫diaper bank所使用。這些活動的主要目標之一是將看似不同的行業和思維方式的組織和個人聚集在一起，以謀求共同利益。公司可以贊助活動，非營利組織可以提交項目構想，各種技能的人都可以註冊參加活動並做出貢獻。通過兩岸（美國大西洋和太平洋東西海岸）的努力，“Ruby for Good” 和 “Python for Good” 一直恪守“使世界變得更好”的座右銘。

“Ruby for Good” 在夏天舉行，舉辦地點在弗吉尼亞州費爾法克斯的喬治•梅森大學。

Social Coder ​

英國的 Ed Guiness 創建了 “Social Coder”，將志願者和慈善機構召集在一起，為六大洲的非營利組織創建和使用開源項目。“Social Coder” 積極招募來自世界各地的熟練 IT 志願者，並將其與通過 Social Coder 註冊的慈善機構和非營利組織進行匹配。項目範圍從簡單的網站更新到整個移動應用程序的開發。

例如，PHASE Worldwide 是一個在尼泊爾支持工作的小型非政府組織，因為 “Social Coder”，它獲得了利用開源技術的關鍵支持和專業知識。

有許多慈善機構已經與英國的 “Social Coder”進行了合作，也歡迎其它國家的組織加入。通過他們的網站，個人可以註冊為社會軟件項目工作，找到尋求幫助的組織和慈善機構。

對 “Social Coder” 的志願服務感興趣的個人可以 在此註冊.
