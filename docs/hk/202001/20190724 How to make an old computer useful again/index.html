如何把你的老爺機重新利用起來 ​

按照下面各個步驟，讓你的老爺機煥然一新。

你的地下室裏是不是有一台用來落灰的舊電腦？為什麼不把它利用起來呢？如果你常用的電腦壞了，又想用一個比手機更大的屏幕上網，這時候一台備用電腦可能就派上用場了。或者，它也可以充當一台全家人共用的廉價備用電腦，甚至還可以改造為一台復古遊戲機。

哪怕是一台有十餘年曆史的老爺機，只要選對了軟件，也可以勝任很多新電腦能夠完成的任務。其中的關鍵在於，要使用開源軟件。

我進行電腦翻新已經有二十年了。在這篇文章裏，我會分享一下電腦翻新的技巧。此處討論的範圍包括雙核筆記本，以及機齡在 5 到 12 年之間的台式機。

檢查硬件 ​

第一步是檢查硬件是否運轉正常。如果在這個環節忽略了一個問題，後面可能會讓你非常頭疼。

灰塵是電子器件的天敵，所以第一件事應該是打開機箱，清除灰塵。壓縮空氣設備這時候可能會派上用場。請注意，進行任何接觸電腦的操作時，都應該確保接地。此外，不要用清潔布擦拭任何東西。即使是一次小到你無法察覺的靜電放電，也可能會導致電路損毀。

清潔工作完成之後，關閉機箱，檢查是否所有硬件都可以正常工作。需要測試的項目包括：

  • 內存
  • 硬盤
  • 主板
  • 外圍設備（DVD 驅動器、USB 接口、聲卡，等等）

首先，將計算機啓動界面（UEFI 或者是 BIOS 界面）上的診斷測試依次運行一遍。如果不知道按哪個功能鍵進入你電腦的啓動界面，可以參考 這份列表。

此外，也可以使用諸如 Hirens BootCD 和 Ultimate Boot CD 之類的免費資源工具包，進行啓動界面覆蓋不到的測試。這些資源工具包涵蓋了數百個測試程序，並且都是免費的，儘管不都開源。運行這些工具包無需安裝任何軟件，因為它們都是從 U 盤或者 DVD 驅動器啓動的。

測試一定要徹底！對於內存和硬盤來説，基礎測試還不夠，應該運行深度測試，哪怕是運行一整夜也無妨。只有這樣，才能夠查出那些不易發現的瞬時故障。

如果發現了問題，可以參考我的硬件故障排除快速指南，可以幫你解決最常見的硬件問題。

選擇軟件 ​

電腦翻新的關鍵在於，根據手頭的硬件資源，恰如其分地安裝軟件。最核心的三種硬件資源分別是：

  1. 處理器（內核數、速度）
  2. 內存
  3. 顯存

可以在啓動時的 UEFI/BIOS 界面上，弄清楚你電腦的硬件資源。記得抄下數據，以免遺忘。接下來，可以在 CPU Benchmark 網站上查看你的處理器，該網站除了提供 CPU 的背景資料，還提供一個 CPU 的性能分數。

瞭解了硬件性能之後，就可以選擇能夠在硬件上高效運行的軟件了。軟件的選擇涉及四個重要的層面：

  1. 操作系統（OS）
  2. 桌面環境（DE）
  3. 瀏覽器
  4. 應用

一個優秀的 Linux 發行版可以滿足上述全部四個層面。不要試圖使用已經停止維護的 Windows 版本，例如 Windows 8、Vista 或者 XP，哪怕已經安裝在電腦上了。惡意軟件的風險你是承受不起的。明智的做法是，使用一個更抗病毒的最新版本操作系統。

那 Windows 7 呢？維護寬限期至 2020 年 1 月 14 日結束，也就是説，在此日期之前你還可以獲得安全補丁，之後就想都別想了。現在正是遷出 Windows 7 的絕佳時機。

Linux 的巨大優勢在於，有許多專門為過時硬件設計的發行版。此外，桌面環境和操作系統在 Linux 的設計中是分開的，你可以自行選擇搭配。這一點非常重要，因為桌面環境對低端系統的性能有很大影響。（對於 Windows 和 MacOS 來説，你選擇的操作系統版本決定了桌面環境，沒得可選。）

Linux 的另一個好處是，擁有數以千計自由且開源的應用，不需要擔心激活或者許可的問題。此外，Linux 是可移植的，可以在不同的分區、硬盤、設備或計算機之間，對操作系統和應用進行復制、移動或克隆。（Windows 則不然，使用註冊表將系統捆綁在了所安裝的計算機上。）

翻新後的電腦能夠做什麼？ ​

這裏討論的是大約在 2006 年到 2013 年之間生產的雙核計算機，尤其是裝載了 Intel 酷睿 2 CPU 或 AMD 速龍 64 X2 系列處理器的計算機。它們的 CPU 分數 大多在 1000 到 4000 分之間。這種電腦賣不了幾個錢，但用在運行輕量級 Linux 軟件上，性能還是足夠的。

有一點需要注意：你的電腦應該至少擁有 2 GB 內存，如果不夠就進行升級。就我翻新過的電腦來説，使用者用到的內存（不包括數據緩存）一般在 0.5 到 2 GB 之間，很少超過 2 GB。如果將內存升級到 2GB，系統就不至於進行內存交換，即將硬盤當做內存使用。如果想要獲得良好性能，這一點十分關鍵。

以我自己為例，我用來寫作這篇文章的是一台有十年機齡的翻新電腦。取下 1 GB 內存條之後，它只剩下了 1 GB 內存，然後就慢得像一隻烏龜。用它瀏覽網頁，或者是做類似的事情，都讓人感到灰心，甚至痛苦。一旦把內存條重新裝回去，有了 2 GB 內存，它就立馬回到了可以使用的狀態。

一台 2 GB 的雙核計算機可以滿足大多數人的需求，只要安裝的是輕量級發行版和瀏覽器。你可以用它瀏覽網頁、發送電子郵件、編輯文檔和電子表格、觀看 YouTube 視頻、參與 eBay 拍賣競標、在社交網絡上發帖、聽播客、查看相簿、管理家庭收支和個人日程、玩遊戲，等等。

翻新電腦的侷限 ​

那麼，這些老爺機又有什麼侷限呢？由於它們的併發性能比不上最先進的計算機，所以應該使用輕量級瀏覽器，同時攔截廣告（廣告正是讓網頁加載變慢的罪魁禍首）。如果可以使用虛擬專用網絡（VPN）攔截廣告，為處理器免除加載廣告的負荷，那就再好不過。此外，還需要禁用視頻自動播放、Flash 以及網頁動畫效果；將瀏覽器上的標籤頁控制在少數幾個，不要同時打開 20 個；以及下載可以開啓/禁用 JavaScript 的瀏覽器擴展。

讓處理器專注於你目前正在做的事情吧，不要同時打開一堆應用，也不要在後台運行很多程序。圖像編輯和視頻編輯的高級工具可能會很慢；至於運行虛擬機，還是別想了吧。

那遊戲呢？開源軟件倉庫提供了數以千計的遊戲。這就是我為什麼將顯存列為三種核心硬件資源之一。如果你的電腦沒有獨立顯卡，那很可能只有 32 或者 64 MB 的顯存。可以增加一張顯卡，將顯存提升到 256 或者 512 MB，這樣一來，處理器密集型的遊戲就會順暢很多了。如果不確定你的電腦有多少顯存，可以參考這裏。請注意，需要確保顯卡與電腦的顯卡插槽（AGP、PCI-Express 或者 PCI）相匹配，同時使用正確的連接線（VGA、DVI 或者 HDMI）。

與 Windows 系統的兼容性如何？ ​

許多人關心 Linux 與 Windows 系統的兼容性如何。首先，對於任何一個 Windows 程序，都有一個 Linux 版本的替代品。

退一步説，即使你真的必須要運行某個特定的 Windows 程序，通常也可以藉助 Wine 在 Linux 上運行。可以在 Wine 資料庫 裏查找一下你的應用，看看是否可以在 Wine 上運行，順便學一些特殊安裝技巧。Winetricks 和 PlayOnLinux 這兩個輔助工具可以幫助你進行安裝和配置。

Wine 的另一個優勢是可以運行舊版本 Windows（例如 Vista、XP、ME/98/95 和 3.1）上的程序。我認識一個傢伙，搭建了一台特別讚的遊戲電腦，然後用來玩 XP 上的老遊戲。藉助 DOSBox，你甚至還可以運行數以千計的免費 DOS 程序。但是有一點需要注意，如果 Windows 程序可以運行，那麼 Windows 病毒也同樣可以。你需要保護 Linux 上的 Wine 環境，正如保護任何其他 Windows 環境一樣。

對了，與 Microsoft Office 的兼容性又如何呢？我使用的是 LibreOffice，經常編輯並交換 Word 和 Excel 文件，完全沒有問題。不過，你應該避免使用隱晦或者過於專業的功能。

如何選擇發行版？ ​

假設選擇了 Linux 作為操作系統，那麼你還需要選擇桌面環境、瀏覽器和各種應用。最簡單的方法是，安裝一個包含了你所需要的一切的發行版。

通過從 live USB U 盤或者 DVD 啓動，你無需安裝任何程序，就可以嘗試不同的發行版。關於在 Linux 或 Windows 上創建可啓動的 Linux 的方法，可以參考這裏。

我進行電腦翻新的目的是做慈善，所以無法指望電腦使用者具備任何相應知識。我需要的發行版應該具有以下特性：

  • 用户友好
  • 具有輕量級界面
  • 自帶各種輕量級應用
  • 擁有足夠大的軟件倉庫
  • 歷史表現良好
  • 擁有龐大的用户社區和活躍的論壇
  • 通過長期維護版本（而不是滾動發佈版本）確保穩定性
  • 更重視可靠性，而不是尖端功能
  • 可以通過圖形化用户界面進行設置，而不是隻能通過文本文件進行設置

許多發行版都能夠滿足上面的要求。我曾經嘗試成功的有 Mint/Xfce、Xubuntu 和 Lubuntu。前兩個發行版使用 Xfce 桌面環境，第三個使用 LXQt。相比 GNOME、Unity、KDE、MATE 和 Cinnamon 這些桌面環境，運行上面這兩種桌面環境只需要更少的處理器和內存資源。

Xfce 和 LXQt 用起來非常簡單，我的客户們之前從未見過 Linux，但是都可以自如使用這些簡單的、菜單驅動的用户界面。

對於舊電腦來説，運行最快速、最高效的瀏覽器是一件非常重要的事情。很多人覺得 Chromium 是最好的瀏覽器；此外，我還安裝了 Firefox Quantum，因為大家比較熟悉它，並且它的性能可以和 Chromium 的性能媲美。我還加上了 Opera，因為它速度快，而且有一些獨特功能，比如內置的廣告攔截，以及免費的虛擬專用網絡。Opera 是免費的，但並非開源。

無論你使用什麼瀏覽器，一定要攔截廣告和追蹤器，儘量降低瀏覽器的負荷。此外，除非得到你的明確批准，否則視頻和 Flash 都不應該被允許運行。

至於應用，我使用的是 Mint/Xfce、Xubuntu 和 Lubuntu 自帶的輕量級應用。它們足以滿足一切需求了。

行動起來吧 ​

你是否會對翻新後的電腦感到滿意呢？就我來説，我所使用的兩台電腦的機齡都已經超過十年了，其中一個裝載的是 Intel 雙核處理器（eMachines T5274a），另一個裝載的是 AMD 速龍 64 x2 處理器（HP dc5750），兩台電腦都有 2 GB 內存。它們和我的另一台具備四核 i5 處理器和 16 GB 內存的電腦一樣，完全能夠勝任我的辦公工作。如果説有什麼功能是這兩台電腦缺失的，那就是運行虛擬機了。

我們生活在一個非常神奇的年代。只需要付出一點努力，就可以將一台機齡在 5 到 12 年之間的舊電腦，翻新為一台具備實用價值的機器。還有什麼比這更有趣嗎？
