Pop!_OS 與 Ubuntu：哪個更棒？ ​

好吧，你可能會發現從最佳 Linux 發行版列表中選擇一個發行版很容易，但是，將兩個類似的 Linux 發行版進行比較通常會令人困惑，就像 Pop!_OS 與 Ubuntu 一樣。

有趣的是，Pop!_OS 是基於 Ubuntu 的。那麼，Pop!_OS 和 Ubuntu 之間有什麼區別呢？為什麼要從中選擇一個呢？

在本文中，我將比較 Pop!_OS 和 Ubuntu（兩者都是我的最愛）。

注意：你可能會發現一些武斷的觀點，而本文只是一份比較的參考。隨着 Linux 發行版的不斷開發和更新，隨着時間的流逝，很多事情都會改變。

比較 Ubuntu 和 Pop!_OS ​

發現相似之處可幫助你區分其他差異之處。因此，讓我們從一些明顯的相似之處開始。

就像我提到的，Pop!_OS 是基於 Ubuntu 之上的 Linux 發行版。因此，當你使用 Pop!_OS 時，你將獲得使用 Ubuntu 的所有好處（從技術上説，其核心是一樣的）。

它們都默認帶有 GNOME 桌面環境，因此它們具有相似的用户界面（UI）。

在不討論所有底層差異的情況下，我將在這裏重點介紹一些重要的差異。

用户體驗及主題 ​

許多用户認為 Pop!_OS 只是具有不同外觀的 Ubuntu。

根據我的經驗，我覺得這並非完全正確。

是的，它們倆都很喜歡 GNOME 桌面環境 —— 但是，Pop!_OS 讓人感覺更加優美。

除了外觀之外，Ubuntu 還通過添加程序塢和其他一些小花巧來定製了 GNOME 的體驗。如果你喜歡定製的 GNOME 體驗，可能會發現它更好。

但是，如果你更喜歡純粹的 GNOME 體驗，Pop!_OS 默認情況下為你提供的就是這樣。

在你親自嘗試之前，我無法説服你。但是，Pop!_OS 中的總體配色方案、圖標和主題可以説是令人愉悦的高級用户體驗。

這可能是一個主觀的事情，但這是我所觀察到的。你還可以查看 Ubuntu 19.10 的視頻教程，親自感受一下。

易於安裝第三方應用 ​

Ubuntu 非常重視 Snap 軟件包。這增加了它提供的應用程序的數量。

但是 Snap 軟件包存在一些重要的問題。它們佔用了過多的磁盤空間，並且啓動要花費大量的時間。

這就是為什麼我更喜歡使用應用程序的 APT 版本的原因。

我為什麼要説這個呢？

因為 Pop!_OS 具有其自己的官方 PPA，並已默認啓用。你會在此處找到一些有用的應用程序，例如 Android Studio、TensorFlow。無需下載 Android Studio 的 1GB 大的 Snap 程序包。只需使用 apt-get install就可以了。

預裝應用 ​

對於某些人來説，它可能不是最大的問題，但是擁有大量預安裝的應用程序可能會影響體驗和性能。即使不影響性能，某些用户也只喜歡較少的預裝應用程序。

與 Ubuntu 相比，Pop!_OS 捆綁了更少的默認應用程序（潛在地減少了胖軟件）。

再一次提醒，這是主觀的看法。如果你希望預安裝更多應用程序，則可以考慮使用 Ubuntu 而不是 Pop!_OS。

Snap 軟件包支持 ​

對於熟悉 Snap 程序包的用户來説，Ubuntu 的軟件中心是比 Pop!_OS 商店更好的解決方案，因為你可以在軟件中心中列出 Snap 程序包。

你無法在軟件中心中過濾 Snap 軟件包，但是當你在軟件中心中發現一個 Snap 軟件包（查看應用程序來源的詳細信息為 “Snap store”/“Snapcraft”）時安裝它就更容易了。

可能你會感到困惑，Pop!_OS 也確實支持 Snap 軟件包。但是，你不會在 Pop!_OS 商店中找到它們，這是唯一的區別。

如果不確定什麼是 Snap 軟件包及其功能，可以查看我們的文章《在 Linux 上安裝 Snap 應用》。

單獨的 NVIDIA/AMD ISO 文件 ​

從技術上講，它不是內部比較的一部分，而是某些用户關心的一個因素。

因此，值得強調的是 Pop!_OS 提供了單獨的 ISO。一個用於帶 NVIDIA 顯卡的系統，另一個用於帶/不帶 AMD 顯卡的系統。

使用 Ubuntu 19.10，你可以在 Ubuntu ISO 上獲得 NVIDIA 驅動程序，但 AMD 顯卡沒有這個。

可靠性與問題 ​

毫無疑問，這兩個發行版都適合初學者，並且相當可靠。如果你想要更好的可靠性和更少的問題，則可能希望一直使用長期支持（LTS）版本。

當出現新版本的 Ubuntu 時，Pop!_OS 將在其上開發，並有可能解決用户在 Ubuntu 原始發行版上遇到的問題，然後再進行新的升級。這給它們帶來了一點優勢，但這沒什麼實質性的不同，因為這些修復最終都可以運用於 Ubuntu。

性能 ​

性能將高度取決於你所安裝的內容以及所安裝的硬件配置。

除非你有一個超級舊的系統，否則這兩個發行版似乎都表現良好。

我的機器是 i5-7400 處理器和 16GB 的 RAM（帶有 GTX 1050ti 顯卡），我發現兩種發行版上的體驗都足夠好。

當然，你可以手動進行一些優化調整以滿足要求——無論它們中的哪個不滿足你的硬件配置。

但是，如果你想使用 System76 筆記本電腦，那麼 Pop!_OS 將可以證明自己是 Linux 領域的蘋果，因為 Pop!_OS 是針對其硬件量身定製的，與 Ubuntu 有所不同。

硬件兼容性 ​

在比較其他 Linux 發行版時，這絕對是要考慮的事情。但是，在這種情況下，實際上並沒有太大的區別。

你可能會考慮 Pop!_OS 一直在使用較新的硬件配置，因為他們主要是為他們的筆記本電腦量身定製具有各種配置的 OS。而且，這只是一個觀察，而不是事實。

結語 ​

我知道在不親自嘗試的情況下從兩個流行的 Linux 發行版中選擇一個並不容易。如果可能的話，我建議你在進行比較的同時嘗試兩者，以供參考。

你在這兩者之間有何選擇？我在比較中錯過了什麼嗎？在下面的評論中讓我知道。
