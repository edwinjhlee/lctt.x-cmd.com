Wine 5.0 發佈了！ ​

Wine 的一個新的主要版本發佈了。使用 Wine 5.0，在 Linux 上運行 Windows 應用程序和遊戲的體驗得到進一步改進。

通過一些努力，你可以使用 Wine 在 Linux 上運行 Windows 應用程序。當你必須使用一個僅在 Windows 上可用的軟件時，Wine 是一個可以嘗試的工具。它支持許多這樣的軟件。

Wine 的一個新的主要發佈版本已經降臨，即 Wine 5.0，幾乎距它的 4.0 發佈一年之後。

Wine 5.0 發佈版本引進了幾個主要特性和很多顯著的更改/改進。在這篇文章中，我將重點介紹新的特性是什麼，並且也將提到安裝説明。

在 Wine 5.0 中有什麼新的特性？ ​

如他們的官方聲明所述，這是 5.0 發佈版本中的關鍵更改：

  • PE 格式的內置模組。
  • 支持多顯示器。
  • 重新實現了 XAudio2。
  • 支持 Vulkan 1.1。
  • 支持微軟安裝程序（MSI）補丁文件。
  • 性能提升。

因此，隨着 Vulkan 1.1 和對多顯示器的支持 —— Wine 5.0 發佈版本是一件大事。

除了上面強調的這些關鍵內容以外，在新的版本中包含成千上萬的更改/改進中，你還可以期待對控制器的支持更好。

值得注意的是，此版本特別紀念了 Józef Kucia（vkd3d 項目的首席開發人員）。

他們也已經在發佈説明中提到這一點：

這個發佈版本特別紀念了 Józef Kucia，他於 2019 年 8 月去世，年僅 30 歲。Józef 是 Wine 的 Direct3D 實現的一個主要貢獻者，並且是 vkd3d 項目的首席開發人員。我們都非常懷念他的技能和友善。

如何在 Ubuntu 和 Linux Mint 上安裝 Wine 5.0 ​

注意：

如果你在以前安裝過 Wine，你應該將其完全移除，以（如你希望的）避免一些衝突。此外，WineHQ 存儲庫的密鑰最近已被更改，針對你的 Linux 發行版的更多的操作指南，你可以參考它的下載頁面。

Wine 5.0 的源碼可在它的官方網站上獲得。為了使其工作，你可以閲讀更多關於構建 Wine 的信息。基於 Arch 的用户應該很快就會得到它。

在這裏，我將向你展示在 Ubuntu 和其它基於 Ubuntu 的發行版上安裝 Wine 5.0 的步驟。請耐心，並按照步驟一步一步安裝和使用 Wine。這裏涉及幾個步驟。

請記住，Wine 安裝了太多軟件包。你會看到大量的軟件包列表，下載大小約為 1.3 GB。

在 Ubuntu 上安裝 Wine 5.0（不適用於 Linux Mint） ​

首先，使用這個命令來移除現存的 Wine：

sudo apt remove winehq-stable wine-stable wine1.6 wine-mono wine-geco winetricks

然後確保添加 32 位體系結構支持：

sudo dpkg --add-architecture i386

下載並添加官方 Wine 存儲庫密鑰：

wget -qO - https://dl.winehq.org/wine-builds/winehq.key | sudo apt-key add -

現在，接下來的步驟需要添加存儲庫，為此, 你需要首先知道你的 Ubuntu 版本。

對於 Ubuntu 18.04 和 19.04，用這個 PPA 添加 FAudio 依賴， Ubuntu 19.10 不需要它：

sudo add-apt-repository ppa:cybermax-dexter/sdl2-backport

現在使用此命令添加存儲庫：

sudo apt-add-repository "deb https://dl.winehq.org/wine-builds/ubuntu $(lsb_release -cs) main"

現在你已經添加了正確的存儲庫，可以使用以下命令安裝 Wine 5.0：

sudo apt update && sudo apt install --install-recommends winehq-stable

請注意，儘管在軟件包列表中將 Wine 5 列為穩定版，但你仍可能會看到 winehq-stable 的 wine 4.0.3。也許它不會傳播到所有地理位置。從今天早上開始，我可以看到 Wine 5.0。

在 Linux Mint 19.1、19.2 和 19.3 中安裝 Wine 5.0 ​

正如一些讀者通知我的那樣，apt-add 存儲庫命令不適用於 Linux Mint 19.x 系列。

這是添加自定義存儲庫的另一種方法。你必須執行與 Ubuntu 相同的步驟。如刪除現存的 Wine 包：

sudo apt remove winehq-stable wine-stable wine1.6 wine-mono wine-geco winetricks

添加 32 位支持：

sudo dpkg --add-architecture i386

然後添加 GPG 密鑰：

wget -qO - https://dl.winehq.org/wine-builds/winehq.key | sudo apt-key add -

添加 FAudio 依賴：

sudo add-apt-repository ppa:cybermax-dexter/sdl2-backport

現在為 Wine 存儲庫創建一個新條目：

sudo sh -c "echo 'deb https://dl.winehq.org/wine-builds/ubuntu/ bionic main' >> /etc/apt/sources.list.d/winehq.list"

更新軟件包列表並安裝Wine：

sudo apt update && sudo apt install --install-recommends winehq-stable
