你有什麼喜歡的 Linux 終端技巧？ ​

告訴我們你最喜歡的終端技巧，無論是提高生產率的快捷方式還是有趣的彩蛋。

新年伊始始終是評估提高效率的新方法的好時機。許多人嘗試使用新的生產力工具，或者想找出如何優化其最常用的流程。終端是一個需要評估的領域，尤其是在開源世界中，有無數種方法可以通過快捷鍵和命令使終端上的生活更加高效（又有趣！）。

我們向作者們詢問了他們最喜歡的終端技巧。他們分享了一些節省時間的技巧，甚至還有一個有趣的終端彩蛋。你會採用這些鍵盤快捷鍵或命令列技巧嗎？你有喜歡分享的最愛嗎？請發表評論來告訴我們。

“我找不出哪個是我最喜歡的；每天我都會使用這三個：

  • Ctrl + L 來清除屏幕（而不是鍵入 clear）。
  • sudo !! 以 sudo 特權運行先前的命令。
  • grep -Ev '^#|^$' <file> 將顯示文件內容，不帶註釋或空行。” —Mars Toktonaliev

“對我來説，如果我正在使用終端文本編輯器，並且希望將其丟開，以便可以快速執行其他操作，則可以使用 Ctrl + Z 將其放到後台，接着執行我需要做的一切，然後用 fg 將其帶回前台。有時我也會對 top 或 htop 做同樣的事情。我可以將其丟到後台，並在我想檢查當前性能時隨時將其帶回前台。我不會將通常很快能完成的任務在前後台之間切換，它確實可以增強終端上的多任務處理能力。” —Jay LaCroix

“我經常在某一天在終端中做很多相同的事情，有兩件事是每天都不變的：

  • Ctrl + R 反向搜索我的 Bash 歷史記錄以查找我已經運行並且希望再次執行的命令。
  • 插入號（^）替換是最好的，因為我經常做諸如 sudo dnf search <package name> 之類的事情，然後，如果我以這種方式找到合適的軟件包，則執行 ^search^install 來重新運行該命令，以 install 替換 search。

這些東西肯定是很基本的，但是對我來説卻節省了時間。” —Steve Morris

“我的炫酷終端技巧不是我在終端上執行的操作，而是我使用的終端。有時候我只是想要使用 Apple II 或舊式琥珀色終端的感覺，那我就啓動了 Cool-Retro-Term。它的截屏可以在這個網站上找到。” —Jim Hall

“可能是用 ssh -X 來在其他計算機上運行圖形程序。（在某些終端仿真器上，例如 gnome-terminal）用 C-S c 和 C-S v 複製/粘貼。我不確定這是否有價值（因為它有趣的是以 ssh 啓動的圖形化）。最近，我需要登錄另一台計算機，但是我的孩子們可以在筆記本電腦的大屏幕上看到它。這個鏈接向我展示了一些我從未見過的內容：通過局域網從我的筆記本電腦上鏡像來自另一台計算機屏幕上的活動會話（x11vnc -desktop），並能夠同時從兩台計算機上進行控制。” —Kyle R. Conway

“你可以安裝 sl（$ sudo apt install sl 或 $ sudo dnf install sl），並且當在 Bash 中輸入命令 sl 時，一個基於文本的蒸汽機車就會在顯示屏上移動。” —Don Watkins
