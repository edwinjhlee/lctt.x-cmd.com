Ledger-複式記賬的一個功能強大的命令列工具 ​

無論你是一個電腦極客還是普通用户，記錄賬户開銷總是必不可少的。雖然在Linux上有很多基於GUI的記賬工具（比如 - GNUCash）受到大家歡迎，但是工作在命令列的記賬工具是很多用户難以想像的。在本文中，我們將討論一個功能強大的命令列記賬工具-Ledger。

###Ledger - 複式記賬工具

Ledger是複式記賬的一個功能強大的命令列工具。對於那些不瞭解“複式（Double-Entry）”的用户，它這意味着每筆交易都必須有一個源。站在一個外行的角度來看，這意味着，每做成一筆賬户信貸，一個賬户必須有一個借記卡。所以，Ledger跟蹤資金運轉並且幫助你瞭解你的開支。

Ledger沒有自己的資料庫，它依賴於通過用户維護一個開支表（一個簡單的文本文件）。不過開支表有一種Ledger能夠理解的特殊格式。

幾個值得注意的要點：

  • 分類之下的所有行是tab縮進（例如 - Shopping，Leisure或EMI）。
  • 同樣，所有的開支金額也是tab縮進（包括：$）。
  • 作為複式記賬工具，制定信用卡和借記卡是很重要的，否則Ledger將會報錯。

優點

  • 強大且功能豐富的記賬工具
  • 便於使用
  • 彩色輸出

缺點

  • 開支文件需要分別維護
  • 有一定的學習曲線

###總結

Ledger是一個智能小巧的命令列實用程序用來管理你的開支。你可以用它來管理日常以及複雜的業務賬户。雖然它有一定的學習曲線，但是它擁有各種功能，在學習使用Ledger中投入一點努力是值得的。
