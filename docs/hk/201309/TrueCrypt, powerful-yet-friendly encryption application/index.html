功能強大界面友好的加密程序，TrueCrypt ​

TrueCrypt是一款免費的開源加密程序，擁具有強大、多樣、先進、高質量的加密能力，它具有友好、易懂的用户界面和功能。

TrueCrypt允許用户通過密碼訪問加密後的文件，其本質上是將文件解密後再像常規文件一樣訪問。完全加密後的文件，非用户以外的人是無法訪問的。

TrueCrypt的各項 特性 如下：

  • 能夠建立加密文件夾並將其呈現為真實的硬盤
  • 支持加密存儲設備（例如U盤）或整個分區
  • 自動根據需要進行實時動態加密
  • 充分利用系統資源，能夠快速讀取加密數據，速度接近訪問未加密數據時的速度

TrueCrypt的 實時動態加密 ，意指：

  • 數據在存儲之前就已經被自動加密
  • 數據在加載之後會自動解密
  • 例如，播放一個加密文件夾裏的小電影，TrueCrypt會直接在內存中將密數據一部分一部分解密後再送入指定的內存塊（或播放器）。也就是説“TrueCrypt從不會將明數據放在硬盤上，這些明數據只會暫時存在於內存裏”。

下面幾個步驟教你如何用TrueCrypt 新建 一個加密文件夾：

  • 下載TrueCrypt 7.1

  • 解壓縮後在終端中輸入以下命令（假設你解壓在了Downloads文件夾下）

      cd Downloads
  ./truecrypt-7.1a-setup-x64

（如果你的操作系統是32位，將上面的x64改為x32）

  • 然後根據提示，點擊鼠標，輕鬆完成安裝
  • 在Dash搜索欄中鍵入truecrypt,啓動TrueCrypt
  • 依次點擊TrueCrypt-->Volumes-->Create New Volume，建立一個新的“待加密文件夾”
  • 選中 Create an encrypted file container然後點擊Next

  • 選中Standard Truecrypt volume 並點擊 Next

點擊Select File，在你認為合適的位置新建目錄/條目（例如，在Music目錄下建立一個123條目），然後點擊Next

  • 再次點擊Next （此時默認選擇的加密算法是AES）

  • 選擇大小（例如要建立一個100MB的文件夾，就在輸入框中填入100，後面的複選框選中MB）

  • 設置一個密碼

  • 選擇一個文件系統類型（例如Linux Ext4)

  • 選中I will mount the volume only on Linux（這裏請根據實際情況選擇）

  • 接下來，持續猛烈晃動你的鼠標幾秒鐘（譯者注：該步驟用來生成密鑰，晃動越無規律時間越長越好），然後點擊Format，最後輸入剛才設置的密碼，整個加密條目的創建過程就完成了。

使用

到此為止，剛剛建立的那個加密文件夾就已經在TrueCrypt的保護下了，點擊 Select File，找到剛建立的加密條目，再點擊底部的Mount，掛載/打開該加密文件夾。

接下來，用户就可以把這個加密目錄當做一個常規目錄正常使用，可以複製圖像、重命名文件、雙擊打開圖像等等。

下圖中，點擊Dismount按鈕，就可以卸載該加密文件夾，卸載後剛才掛載的盤符就不見了，同時裏面的文件自然也就禁止訪問了。
