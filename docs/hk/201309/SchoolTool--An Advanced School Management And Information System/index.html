SchoolTool：先進的學院管理和信息系統 ​

SchoolTool是一個基於網頁的開源免費學生信息系統，為世界各地的學校而設計。它是由Shuttleworth研發併發布，基於翻譯、定位和自動化部署的有力支持，通過 Ubuntu Linux 安裝程序 和 包管理系統 更新。

SchoolTool是經GPL2許可，使用 Zope 3 框架並用 Python 語言編寫。這個項目的主要目標是創建一個簡單的turnkey模式（譯者注：一個“交鑰匙”的“工程項目管理模式”）學生管理和信息系統，包括中小學人數統計、學分表、出勤、日曆和報告。

###功能

  • 可定製學生和教師的人數統計和其他個人的數據
  • 為教師，學生和監護人提供聯人管理
  • 教師學分表
  • 全校評估數據收集和報告卡
  • 班級到場人數和每日出勤分數
  • 學校，羣組，個人和資源預定日曆
  • 跟蹤和管理學生的干預措施

###安裝SchoolTool

SchoolTool核心開發團隊強烈建議和推薦在Ubuntu 12.04或之後版本安裝SchoolTool。他們為多個系統創建了軟件包，但其核心開發團隊不支持它們。

SchoolTool是在官方軟件倉庫中找到的，所以，我們可以用命令來安裝它：

$ sudo apt-get install schooltool

另外，可以用PPA來獲取更新版本和開發版本。

$ sudo add-apt-repository ppa:schooltool-owners/ppa

或者

$ sudo add-apt-repository ppa:schooltool-owners/dev

使用命令更新軟件源列表並最後用命令安裝SchoolTool：

$ sudo apt-get install schooltool

###訪問SchoolTool

打開你的瀏覽器在地址欄中輸入 http://localhost:7080 。

如果你想通過遠程客户端打開它，編輯文件 /etc/schooltool/standard/paste.ini 。

$ sudo nano /etc/schooltool/standard/paste.ini

設置主機值為0.0.0.0 如下所示。

host = 0.0.0.0

保存並關閉文件。重啓schoolTool服務。

$ sudo service schooltool restart

現在，你可以從你的瀏覽器上用URL http://ip-address:7080 來訪問SchoolTool網頁控制台。你將看到一個空白的日曆，如下圖所示。

###初始化配置，更改管理員密碼

SchoolTool默認的管理員賬户是“ manger ”，密碼是“ schooltool ”。登錄使用以上認證。

在上面定位到 Home 按鈕。點擊 Password 下方的 Setting 部分。輸入兩次舊密碼和新密碼並單擊Apply。

###服務設置

登錄管理員賬户。在Server部分，你將發現你的SchoolTool服務器的細節。

###設置外發郵件

SchoolTool並不像Sendmail或Postfix扮演着郵件服務器的工作。它將像郵件客户端一樣發送郵件，如Thunderbird, Evolution。

若要在SchoolTool中啓用郵件功能，登錄管理賬户並轉到Server列表。點擊 Outgoing Email 鏈接。在那之後，點擊黃色鉛筆圖標去更改郵件設置。填充smtp，Email和password並單擊apply。

###設置日曆

按照你的區域位置設置日曆很重要。點擊Server部分的 Calendar 列表。選擇你的時區，我的設置是 Asia/Kolkatta 。

轉到其他鏈接，如Errors，Tabs和Pack Database。管理操作系統是不言而喻的。按照你的需求閲讀和改變設置。

###設置學校

現在我們來介紹簡明又重要的部分，它需要我們花費更多的時間和精力來完成。本文並不能覆含所有內容，所以我推薦你去訪問SchoolTool官方文檔，一個接一個仔細瀏覽每一部分，按照要求設置你的學校。完成整個學校的設置需要花費可能會花費幾個小時甚至幾天的時間。別害怕，它並不困難：SchoolTool團隊在其網站為用户充分準備了自我幫助的文檔和截圖。你不必去其他任何地方學習SchoolTool，通過SchoolTool文檔頁就能學習並DIY。
