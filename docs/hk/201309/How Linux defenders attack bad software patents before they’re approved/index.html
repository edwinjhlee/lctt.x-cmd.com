Linux Defenders怎樣先發制人阻止惡意軟件專利被批准 ​

這個小組識別危險的專利並且試着還原它們的本來面目。

儘管那些“專利蟑螂”發起影響開源軟件的訴訟數目與日俱增，但還有一線希望。2011年9月簽署了一部法律-《美國發明法案》，它提供了新的途徑來阻止未來可能引起訴訟的過於寬泛的軟件專利。

今天的 LinuxCon的一個會議中，Linux Defenders 的負責人Andrea Casillas解釋了這個組織是如何利用新法律賦予的權利來對抗專利申請。Open Invention Network 的一個項目 Software Freedom Law Center，Linux 基金會以及 Linux Defenders 對每週公佈的6000項專利做檢查，試圖識別出那些對Linux和開源的潛在威脅。然後，這個組織查找一些至少能夠廢止其中一部分專利申請的先例。

下一步就是協同Linux技術專家編纂防禦性公共出版物，雖然它們本身不是專利，但它們描述了一項發明，並放入公開檔案以阻止覆含該技術的新專利的批准。這些出版物通常有2-3頁的技術描述，美國專利商標局的審查員可以在管理可能會失效的先例或者限制新專利申請的範圍時閲讀參考。

“我們將與作者、發明者或者開發者攜手合作編寫這些出版物，使它們更加有效。” Casillas 説。他一直主張 Linux 社區幫助這個小組發現危險專利並尋找先例。

防禦性公共出版物是舊的策略，但它將會因為 America Ivents Act 而越來越接近公眾的生活。Casillas 解釋説：“這是審查人員第一次歡迎公眾的互動。任何個人都可以免費遞交電子版的關於先例的申請。”

Linux Defenders 已經編纂好了與來自 Microsoft，Apple和其它公司的專利申請有關的防禦性公共出版物。概括來説，Casillas 説防禦性公共出版物不是要去迫使某家公司放棄某一專利，而是要迫使某家公司縮小它們申請的專利包括的範圍。

當被問起 Linux Defenders 能否説出因為這個過程而受限的專利申請的案例時，Casillas 和她的同事們説他們仍然在尋找評估它的有效性的方法。在6到9個月裏，他們希望能找到一個工具來跟蹤記錄專利研究者們在複審中使用防禦性公共出版物的情況。

Linux Denfenders 同時也把矛頭指向已經通過的專利。但 Casillas 提醒説要推倒已經批准的專利的法律標準非常高。

###專利訴訟“能讓 Red Hat掃地出門”

昨天 LinuxCon 的一個單獨的會議上，Red Hat 的 Fedora 項目經理 Tom Callaway 討論了開源的法律威脅。

Red Hat 批評了“專利蟑螂”並且採取多種措施保護自己和用户。Callaway 説不能小看這些威脅。“我不是説大話，Red Hat在我們開源產業裏不是一個小公司，我們可能是最大的。一個關鍵專利訴訟的失利可以讓 Red Hat在這行幹不下去。這就是專利的重要性，也足見在業界它是多麼讓人聞風喪膽。”

各種可能性中，Red Hat不會被掃地出門的。它有一個保護自己及用户的在法庭上對抗專利“專利蟑螂”的良好跟蹤記錄。它把保障用户權益、對抗訴訟當做它的軟件程序，而且已經建立起了一系列防禦專利。

儘管付費的 RHEL 會員資格給了用户額外的保護，Red Hat也正在保證Fedora這個免費的系統遠離法律糾紛。它是這麼做的：分析所有代碼，確保每段代碼都使用合適的許可，有時移除或重寫有嫌疑的代碼。這會導致軟件產生負面的結果。“我們在 Fedora 中遇到了很多問題。專利使我們不能按照我們所想要的方式去做事。”Callaway 這麼説。

在最近的與 Rackspace 和 Red Hat 有關的案子裏，一個叫做 Uniloc 公司想要從 Rackspace 處獲得費用，因為後者使用了Red Hat的基於 Linux 的服務器。Uniloc的案子以其敗訴告終。法官宣判它的專利聲明無效，因為它僅描述了一個相對簡單的數學操作。

但是應對這些訴訟很費錢。甚至 Red Hat 有時付專利費避免打官司。

Callaway在過分寬泛的專利面前流露出了挫敗感。某些專利是“如此的模糊以至於它們可以指任何東西，”他説，“它們可以被應用到幾乎任何地方，並且專利持有者打賭認定你不會去計較。”

###幫助專利審查人員識別惡意專利

Casillas告訴我們，那些過分寬泛的專利，正是 Linux Defenders 想要去阻止的。模糊的專利經常能夠通過專利申請，部分原因是因為專利審查人員用在每個申請上的時間不會超過20小時。

總的時間是“相當難以置信，它考慮到這個過程所需時間長短以及這個專利發佈的重要性。”他説。那20小時“包括了瀏覽申請，確定它按格式編輯，你的基本合法需求，而且這段時間決定着這個發明的前景。”

專利審查人員用7到8個小時搜索先例，不論是專利形式的還是其它公共可及的技術描述，她説。

通過提交防禦性公共出版物，提取標籤以使專利審查人員更容易找到，Linux Defenders 希望使美國專利商標局更加起到實際作用。

Casillas 説：“我們不是在增加他們的工作量，而是幫助他們一起完成這些相關出版物”
