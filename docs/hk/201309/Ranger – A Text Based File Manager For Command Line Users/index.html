Ranger – 給命令列用户一個基於文本的文件管理器 ​

圖形文件管理器是每個人日常電腦工作的一部分。多數用户都樂於使用默認的文件管理器，並且沒有那麼多困擾讓他們去探索替代的文件管理器。但是，當使用命令列（CLI）的文件管理器，用户在找到一個最好的之前，可能有興趣嘗試各種可用的文件管理器，以適合他們的需求。在這篇文章中，我們將來看看Ranger，一個基於命令列的文件管理器。

註釋：這篇文章中的所有示例和使用説明在ubuntu13.04上已通過測試。

###Ranger - 命令列文件管理器

Ranger是一個基於ncurses庫的命令列文件管理器，有一個簡單而簡約的用户界面。它使用基本的vi式的導航鍵，能夠預覽文件和用默認程序打開它們。

###如何使用Ranger

只需在命令列裏鍵入命令ranger去執行這個程序。這是在我係統上從/home/himanshu目錄執行時的ranger快照。

你可以看到在單獨的列上ranger顯示了目錄，子目錄和目錄裏的內容。例如，如上圖所示，在窗口最左邊一列，代表我的系統在/home/目錄下有三個目錄。在這三種目錄裏，himanhu目錄是當前已被選擇的。

第二列代表himanshu目錄的子目錄。這裏，Pictures子目錄是當前被選擇的。同樣的，第三列代表呈現在圖片目錄的所有文件。

註釋：你可以使用左右鍵選擇一個特定的列並且使用上下鍵穿梭於這些列中。

Ranger使用默認程序去顯示不同類型的文件。例如，當我導航到第三列如之前的截圖並且按下我選擇的文件workspace_switcher.png。下面會出現：

所以，你可以看到ranger在圖像瀏覽器中打開文件。這個文件管理器另一個功能是，被選擇的文件如果可能的話，可以在文件管理器中預覽文件。

所以你可以看到當CMS文件被選中時，預覽它的內容被顯示在窗口的右邊。如果想要讀取完整文件，只需點擊右鍵頭，文件將在vi/vim編輯器中打開。退出vi/vim編輯器使用：q 回到文件管理器。

這是關於使用ranger的一些提示：

  • 選擇一個文件，按y複製它，然後導航到目標目錄再按p粘貼。
  • 提示：delete鍵去刪除當前被選中的文件。
  • 在文件管理器裏使用問號（？）打開ranger的man手冊頁並且按q回到文件管理器。
  • 基於ncurses，可以很容易的通過鼠標上下滾動。

###下載/安裝

這是相關ranger文件管理器的重要鏈接：

  • 主頁
  • 下載

我通過apt-get在命令列下載並安裝這個程序。Ubuntu用户也可以使用Ubuntu軟件中心下載安裝這個程序。本文使用的版本是1.5.4-1。

沒有其他問題的話,下載和安裝能夠順利完成。

優點

  • 輕鬆導航
  • 簡約的UI
  • 使用vi/vim風格命令控制

缺點

  • 只適用於基本的文件管理操作
  • 預覽功能需要依賴關係被滿足

總結

Ranger是一個很好的實用程序。我將推薦這個程序給那些工作在服務器上的用户（不含GUI）。如果你主要使用命令列，並且在尋找一個好的命令列管理器，Ranger可能是一個好的選擇。如果你的期望不是太高，ranger不會使你失望。
