十個非常有趣的 Linux 彩蛋 ​

製作 Adventure 的程序員悄悄的把一個秘密的功能塞進了遊戲裏。Atari 並沒有對此感到生氣，而是給這類“秘密功能”起了個名字——“彩蛋”，因為——你懂的——你會像找復活節彩蛋一樣尋找它們。

圖片來自： Wikipedia

在1979年的時候，公司為 Atari 2600 開發了一個電子遊戲——Adventure。

製作 Adventure 的程序員悄悄的把這樣的一個功能放進了遊戲裏，當用户把一個“隱形方塊”移動到特定的一面牆上時，會讓用户進入一個“密室”。那個房間裏只有一句話：“Created by Warren Robinett”——意思是，由 Warren Robinett 創建。

Atari 有一項反對作者將自己的名字放進他們的遊戲裏的政策，所以這個無畏的程序員只能偷偷的把自己的名字放進遊戲裏。Atari 在 Warren Robinett 離開公司之後才發現這個“密室”。Atari 並沒有對此感到生氣，而是給這類“秘密功能”起了個名字——“彩蛋”，因為——你懂的——你會尋找它們。Atari 還宣佈將在之後的遊戲中加入更多的“彩蛋”。

這種軟件裏的“隱藏功能”並不是第一次出現（這類特性的首次出現是在1966年PDP-10的操作系統上），但這是它第一次有了名字，同時也是第一次真正的被眾多電腦用户和遊戲玩家所注意。

Linux（以及和Linux相關的軟件）也沒有被遺忘。這些年來，人們為這個倍受喜愛的操作系統創作了很多非常有趣的彩蛋。下面將介紹我個人最喜愛的彩蛋——以及如何找到它們。

你很快就會想到這些彩蛋大多需要通過終端才能體驗到。這是故意的。因為終端比較酷。【我應該藉此機機會提醒你一下，如果你想運行我所列出的應用，然而你卻還沒有安裝它們，你是絕對無法運行成功的。你應該先安裝好它們的。因為……畢竟只是計算機。】

Arch : 包管理器（pacman）裏的吃豆人（Pac-Man） ​

為了廣大的 Arch Linux 粉絲，我們將以此開篇。你們可以將“pacman” (Arch 的包管理器)的進度條變成吃豆人吃豆的樣子。別問我為什麼這不是默認設置。

你需要在你最喜歡的文本編輯器裏編輯“/etc/pacman.conf”文件。在“# Misc options”區下面，刪除“Color”前的“#”，添加一行“ILoveCandy”。因為吃豆人喜歡糖豆。

沒錯，這樣就行了！下次你在終端裏運行pacman管理器時，你就會讓這個黃顏色的小傢伙吃到些午餐（至少能吃些糖豆）。

GNU Emacs : 俄羅斯方塊（Tetris）以及…… ​

我不喜歡 emacs。一點也不喜歡。但是它確實能玩俄羅斯方塊。

我要坦白一件事：我不喜歡emacs。一點也不喜歡。

有些東西讓我滿心歡喜。有些東西能帶走我所有傷痛。有些東西能解決我的煩惱。這些絕對跟 emacs 無關。

但是它確實能玩俄羅斯方塊。這可不是件小事。方法如下：

第一步）打開 emacs。（有疑問？輸入“emacs”。）

第二步）按下鍵盤上的Esc和X鍵。

第三步）輸入“tetris”然後按下“Enter”。

玩膩了俄羅斯方塊？試試“pong”、“snake”還有其他一堆小遊戲（或奇怪的東西）。在“/usr/share/emacs/*/lisp/play”文件中可以看見完整的清單。

動物説話了 ​

讓動物在終端裏説話在 Linux 世界裏有着悠久而輝煌的歷史。下面這些真的是最應該知道的。

在用基於 Debian 的發行版？試試輸入“apt-get moo"。

apt-get moo

簡單？的確。但這是隻會説話的牛，所以惹我們喜歡。再試試“aptitude moo”。他會告訴你“There are no Easter Eggs in this program（這個程序裏沒有彩蛋）”。

關於 aptitude 有一件事你一定要知道，它是個骯髒、下流的騙子。如果 aptitude 是匹諾曹，那它的鼻子能刺穿月球。在這條命令中添加“-v”選項。不停的添加 v，直到它被逼得投降。

我猜大家都同意，這是 aptitude 中最重要的功能。

我猜大家都同意，這是 aptitude 中最重要的功能。但是萬一你想把自己的話讓一頭牛説出來怎麼辦？這時我們就需要“cowsay”了。

還有，別讓“cowsay（牛説）”這個名字把你給騙了。你可以讓你的話從各種東西的嘴裏説出來。比如一頭大象，Calvin，Beavis 甚至可以是 Ghostbusters（捉鬼敢死隊）的標誌。只需在終端輸入“cowsay -l”就能看到所有選項的列表。

想玩高端點的？你可以用管道把其他應用的輸出放到 cowsay 中。試試“fortune | cowsay”。非常有趣。

Sudo 請無情的侮辱我 ​

當你做錯事時希望你的電腦罵你的人請舉手。反正，我這樣想過。試試這個：

輸入“sudo visudo”以打開“sudoers”文件。在文件的開頭你很可能會看見幾行以“Defaults”開頭的文字。在那幾行後面添加“Defaults insults”並保存文件。

現在，只要你輸錯了你的 sudo 密碼，你的系統就會罵你。這些可以提高自信的語句包括“聽着，煎餅腦袋，我可沒時間聽這些垃圾。”，“你吃錯藥了吧？”以及“你被電過以後大腦就跟以前不太一樣了是不是？”

把這個設在同事的電腦上會有非常有趣。

Firefox 是個厚臉皮 ​

這一個不需要終端！太棒了！

打開火狐瀏覽器。在地址欄填上“about:about”。你將得到火狐瀏覽器中所有的“about”頁。一點也不炫酷，是不是？

現在試試“about:mozilla”，瀏覽器就會回應你一條從“Book of Mozilla（Mozilla 之書）”——這本瀏覽網頁的聖經——裏引用的話。我的另一個最愛是“about:robots”，這個也很有趣。

“Book of Mozilla（Mozilla 之書）”——瀏覽網頁的聖經。

精心調製的混搭日曆 ​

是否厭倦了千百年不變的 Gregorian Calendar（羅馬教歷）？準備好亂入了嗎？試試輸入“ddate”。這樣會把當前日曆以Discordian Calendar（不和教歷）的方式顯示出來。你會遇見這樣的語句：

“今天是Sweetmorn（甜美的清晨），3181年Discord（不和）季的第18天。”

我聽見你在説什麼了，“但這根本不是什麼彩蛋！”噓~，閉嘴。只要我想，我就可以把它叫做彩蛋。

快速進入黑客行話模式 ​

想不想嘗試一下電影裏超級黑客的感覺？試試（通過添加“-oS”）把掃描器設置成“Script Kiddie”模式。然後所有的輸出都會變成最3l33t的黑客範。

例如: “nmap -oS - google.com”

趕快試試。我知道你有多想這麼做。你一定會讓安吉麗娜·朱莉（Angelina Jolie）印象深刻

lolcat彩虹 ​

在你的Linux終端裏有很多彩蛋真真是極好的……但是如果你還想要變得……更有魅力些怎麼辦？輸入：lolcat。把任何一個程序的文本輸出通過管道輸入到lolcat裏。你會得到它的超級無敵彩虹版。

追光標的小傢伙 ​

“Oneko” -- 經典 “Neko”的Linux移植版本。

接下來是“Oneko” -- 經典 “Neko”的Linux移植版本。基本上就是個滿屏幕追着你的光標跑的小貓。

雖然嚴格來它並不算是“彩蛋”，它還是很有趣的。而且感覺上也是很彩蛋的。

你還可以用不同的選項（比如“oneko -dog”）把小貓替代成小狗，或是調成其他樣式。用這個對付討厭的同事有着無限的可能。

就是這些了！一個我最喜歡的Linux彩蛋（或是類似東西）的清單。請盡情的的在下面的評論區留下你的最愛。因為這是互聯網。你就能做這些事。
