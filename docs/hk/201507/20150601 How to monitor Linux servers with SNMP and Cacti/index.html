使用 SNMP 和 Cacti 監控 Linux 服務器 ​

SNMP（簡單網絡管理協議）用於收集設備內部發生的數據，如負載、磁盤狀態、帶寬之類。像Cacti這樣的網絡監控工具用這些數據來生成圖標以達到監控的目的。

在一個典型的Cacti和SNMP部署中，會有一台或多台啓用了SNMP的設備，以及一台獨立的用來從那些設備收集SNMP回饋的監控服務器。請記住，所有需要監控的設備必須啓用SNMP。在本教程中，出於演示目的，我們將在同一台Linux服務器上配置Cacti和SNMP。

在Debian或Ubuntu上配置SNMP ​

要在基於Debian的系統上安裝SNMP代理（snmpd），請運行以下命令：

root@server:~# apt-get install snmpd

然後，如下編輯配置文件。

root@server:~# vim /etc/snmp/snmpd.conf

# 使snmpd 監聽再所有接口上
agentAddress  udp:161

# 定義一個只讀的 community 'myCommunity' 和源網絡
rocommunity myCommunity 172.17.1.0/24

sysLocation    Earth
sysContact     email@domain.tld

在編輯完配置文件後，重啓snmpd。

root@server:~# service snmpd restart

在CentOS或RHEL上配置SNMP ​

要安裝SNMP工具和庫，請運行以下命令。

root@server:~# sudo yum install net-snmp

然後，如下編輯SNMP配置文件。

root@server:~# vim /etc/snmp/snmpd.conf

# 定義一個使用 community 'myCommunity' 和源網絡 172.17.1.0/24 的用户 'myUser'
com2sec myUser 172.17.1.0/24 myCommunity

# 將 myUser 加到 'myGroup' 組，定義組權限
group    myGroup    v1        myUser
group    myGroup    v2c        myUser
view all included .1
access myGroup    ""    any    noauth     exact    all    all    none

root@server:~# service snmpd restart
root@server:~# chkconfig snmpd on

重啓snmpd服務，然後添加到啓動服務列表。

測試SNMP ​

SNMP可以通過運行snmpwalk命令進行測試。如果SNMP已經配置成功，該命令會生成大量輸出。

配置帶有SNMP的Cacti ​

在本教程中，我們將在同一台Linux服務器上設置Cacti和SNMP。所以，到剛剛配置SNMP的Linux服務器上去[安裝Cacti][2]吧。

安裝完後，Cacti網頁界面可以通過“http://172.17.1.44/cacti ”來訪問，當然，在你的環境中，請將IP地址換成你的服務器的地址。

安裝過程中Cacti的路徑一般都是正確的，但是如有必要，請再次檢查以下。

在首次安裝過程中，Cacti默認的用户名和密碼是“admin”和“admin”。在首次登錄後會強制你修改密碼。

添加設備到Cacti並管理 ​

Cacti將根據先前配置的SNMP字符串註冊設備。在本教程中，我們將只添加啓用了SNMP的本地服務器。

要添加設備，我們必須以管理員登錄，然後轉到Cacti管理員面板中的控制台。點擊 控制台 > 設備。

那裏可能已經有一個名為‘localhost’的設備。我們不需要它，因為我們要創建全新的圖表。我們可以將該設備從列表中刪除，使用“添加”按鈕來添加新設備。

然後，我們繼續來創建圖表。

這裏，我們創建用於平均負載、RAM和硬盤、處理器的圖表。

接口的圖表和64位計數器 ​

默認情況下，Cacti在SNMP查詢中使用32位計數器。32位計數器對於大多數帶寬圖表而言已經足夠了，但是對於超過100Mbps的帶寬，它就無能為力了。如果已經知道帶寬會超過100Mbps，建議你使用64位計數器。使用64位計數器一點也不麻煩。

注意： Cacti會花費大約15分鐘來產生新圖表，除了耐心等待，你別無選擇。

用户管理 ​

最後，我們創建一個只具有查看我們剛創建的圖表權限的用户。Cacti內建了用户管理系統，而且是高度可定製的。

在完成這些步驟後，我們可以使用‘user1’來登錄進去，並驗證只有該用户可以查看該圖表。

至此，我們在網絡監控系統中部署了一台Cacti服務器。Cacti服務器比較穩定，可以處理大量圖表而不會出問題。
