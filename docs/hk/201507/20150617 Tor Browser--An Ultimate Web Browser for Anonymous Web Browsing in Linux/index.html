Tor瀏覽器：Linux下用於匿名Web瀏覽的終極瀏覽器 ​

我們大多數人都在上網方面花費很多時間。上網使用的應用程序主要是瀏覽器，更確切的説是一個Web瀏覽器。我們在網絡上的大部分活動要以客户端/服務器的方式登錄，這個過程會包括IP地址、地理信息、搜索、活動以及許多潛在的信息，這些信息如果以其他方式被故意使用，會存在潛在的危險性。

Tor瀏覽器：匿名瀏覽器

此外，美國國家安全局（NSA）這樣的國際間諜機構會記錄我們的數字足跡。更不必説受到控制的代理服務器也會被用來做為數據蒐集服務器。並且大多數企業和公司不會允許您訪問代理服務器（使您能保障自己的隱私）。

因此，我們需要的最好是一個小型、獨立、可攜帶的應用程序，它能達到匿名的效果。Tor瀏覽器便是這樣的一個應用，它擁有上面提到的所有功能，甚至不止於此。

這篇文章裏我們會討論Tor瀏覽器，它的功能、使用方式、領域、安裝以及其他關於Tor瀏覽器的重要方面。

什麼是Tor瀏覽器？ ​

Tor是一個自由分發的應用軟件，以BSD許可證發佈，通過其安全可靠的洋葱式的結構，允許用户匿名的進行網絡瀏覽。從前，由於它的結構和運作機制，Tor被稱為‘洋葱路由器’。這個應用是由C語言寫成的。

Tor瀏覽器的功能 ​

  • 跨平台可用。例如，這個應用程序在Linux、Windows和Mac下都可用。
  • 在發送數據到因特網前進行復雜的數據加密。
  • 在客户端進行數據自動解密。
  • 它是火狐瀏覽器和Tor工程的結合。
  • 對服務器和網站提供匿名性。
  • 可以訪問被限制的網站。
  • 無需暴露源IP便可以執行任務。
  • 可以將數據路由至/從防火牆後隱藏的服務和應用程序。
  • 便攜性 - 可以直接從USB存儲棒上運行一個預配置的web瀏覽器。無需本地安裝。
  • 在x86和x86_64平台均可用
  • 可以配置為一個運行在“localhost”的“9050”端口上的“socks4a”代理來讓FTP跑在Tor 上。
  • Tor擁有處理上千的中繼和上百萬用户的能力。

Tor瀏覽器如何工作？ ​

Tor的工作方式基於洋葱路由的概念。洋葱路由的結構類似洋葱，它的每一層都嵌套在另一層裏面，就像洋葱一樣。這種嵌套的結構負責多次加密數據並將其通過虛擬電路進行發送。在客户端一側每一層都在將他傳遞到下一層之前解密數據。最後一層在將原始數據傳遞到目的地前解密最裏面一層的加密數據。

在這個過程裏，這種解密整個層的功能設計的如此高明以至於無法追蹤IP以及用户的地理位置，因此可以限制任何人觀察您訪問站點的網絡連接。

所有這些過程看起來有些複雜，但用户使用Tor瀏覽器時沒有必要擔心。實際上，Tor瀏覽器的功能像其他瀏覽器一樣（尤其是Mozilla的Firefox）。

在Linux中安裝Tor瀏覽器 ​

就像上面討論的一樣，Tor瀏覽器在Linux和Windows以及Mac下都可用。用户需要根據系統和架構的不同在下面的鏈接處下載最新的版本（例如，Tor瀏覽器4.0.4）。

  • https://www.torproject.org/download/download-easy.html.en

在下載Tor瀏覽器後，按説我們需要安裝它，但是Tor的好處是我們不需要安裝它。它能直接從隨身設備中運行，並且該瀏覽器可以被預配置。這意味着插件和運行的特性可以完美的移植。

下載打包文件（*.tar.xz）後我們需要解壓它。

32位系統

$ wget https://www.torproject.org/dist/torbrowser/4.0.4/tor-browser-linux32-4.0.4_en-US.tar.xz
$ tar xpvf tor-browser-linux32-4.0.4_en-US.tar.xz

64位系統

$ wget https://www.torproject.org/dist/torbrowser/4.0.4/tor-browser-linux64-4.0.4_en-US.tar.xz
$ tar -xpvf tor-browser-linux64-4.0.4_en-US.tar.xz

注意 : 在上面的命令中，我們使用‘$‘意味着這個壓縮包應以普通用户而不是root用户來解壓。我們強烈建議您不要以root用户解壓和運行Tor瀏覽器。

###開始使用Tor瀏覽器###

在成功的解壓後，我們便可以將解壓後的瀏覽器移動到任何地方/USB存儲設備中。並從解壓的文件夾以非root用户直接運行‘start-tor-browser’。

$ cd tor-browser_en-US
$ ./start-tor-browser

####6. 我們需要在解壓的文件夾中創建tor.desktop####

$ touch tor.desktop

接着使用您喜歡的編輯器編輯這個文件，加入下面的文本，這裏我使用nano。

$ nano tor.desktop 

#!/usr/bin/env xdg-open
[Desktop Entry]
Encoding=UTF-8
Name=Tor
Comment=Anonymous Browse
Type=Application
Terminal=false
Exec=/home/avi/Downloads/tor-browser_en-US/start-tor-browser
Icon=/home/avi/Downloads/tor-browser_en-US/Browser/browser/icons/mozicon128.png
StartupNotify=true
Categories=Network;WebBrowser;

注意: 確保將上面的tor瀏覽器的路徑替換為您的環境中的路徑。

關於Tor瀏覽器

注意: 如果您在使用舊版本的Tor，您可以從上面的窗口更新它。

應用的可用性和領域 ​

  • 匿名使用網絡。
  • 瀏覽被封鎖的頁面。
  • 連接其他應用，即（FTP）來保證網絡安全的訪問。

關於Tor瀏覽器的爭論 ​

  • 在Tor應用的邊界上並沒有什麼安全措施。比如，數據入口點和出口點。
  • 一項2011年的研究發現一種特殊的針對Tor瀏覽器的攻擊可以得到BitTorrent用户的IP地址。
  • 在一些研究中發現某些特定的協議有泄漏IP地址的傾向。
  • 早些的Tor版本綁定了舊版本的Firefox瀏覽器，這被證明較易受JavaScript攻擊。
  • Tor瀏覽器運行起來比較慢。

真實世界中Tor瀏覽器的實現 ​

  • Vuze BitTorrent Client
  • Anonymous Os
  • Os’es from Scratch
  • whonix 等

Tor瀏覽器的未來 ​

Tor瀏覽器是前途無量的。也許第一個該類應用程序的實現是非常出色的，但Tor瀏覽器必須加大對支持、伸縮性、以及對近期的攻擊進行數據安全的研究的投入。這個應用程序是未來的需要。

結論 ​

如果您工作的部門不允許您訪問某網站，或者如果您不希望別人知道您的私人事務，或您不想向NSA提供您的個人數字足跡，那麼Tor瀏覽器在目前是必須的。
