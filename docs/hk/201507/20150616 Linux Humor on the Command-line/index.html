Linux命令列中的幽默 ​

圖形桌面總是很養眼的，它增強了可視化體驗，有時也能夠提升了某些軟件的功能，讓軟件變得更有趣。但是，在命令列下工作也不需要總是很古板，如果您想在命令列下尋找些樂趣，那麼有很多命令給您帶來趣味。

Linux是個有趣的操作系統。它提供大量的小型開源工具，從平淡無奇的軟件到稀奇古怪的應用。正是這些工具的功能和琳琅滿目的選擇幫助Linux脱穎而出。讓我們一起來看看下面這七個小工具吧。

七彩虹：lolcat ​

lolcat是一個用於將文件或標準輸入連接到標準輸出（類似常見的cat）的程序，但是它會為輸出添加七彩的顏色。

lolcat通常和其他諸如toilet或figlet等生成文本的應用結合使用。這個軟件不應被誤認為是一個或多個貓的圖像的宏。

lolcat由Moe編寫。

網址: github.com

牛郎的牛：cowsay ​

cowsay是一個可配置的開源軟件，它用ASCII碼生成奶牛的圖片，並可以在對話氣泡中顯示消息。cowsay是用Perl寫的。

cowsay並不僅僅只能顯示奶牛。它能生成預先製作的圖片或者其他動物，包括鴨子、考拉、麋鹿、小馬、綿羊、劍龍和火雞，以及奶酪、雪人和骷髏。

有一個叫cowthink的應用，與對話的氣泡不同，它能在生成奶牛的同時生成思考的氣泡。

功能包括：

  • 讓腳本變得更有趣
  • Borg模式
  • 可以更改奶牛看起來的樣子，比如讓奶牛看起來貪婪、偏執、固執、疲倦、古怪、年輕等
  • 圖形版變體：xcowsay

網址: nog.net

傻狗：doge ​

doge是一個簡單的每日信息腳本，它基於有些愚蠢但很有趣的doge的梗。它隨機的打印一些在語法上有誤的句子，有時這些句子基於您電腦中的東西。

doge是一個在2013年非常流行的互聯網潮流元素（梗）。這個梗通常由一幅日本柴犬的圖片和彩色的文字組成。這些文字故意用一種蹩腳的語氣寫成了一些互聯網的獨白。

  • 隨機的用不同的顏色和蹩腳的英語寫下隨機的句子
  • 終端中的柴犬效果非常棒
  • 可以獲得系統數據，比如主機名、運行中的程序、當前用户、$EDITOR
  • 如果您安裝了lolcat，您可以用它作為點綴: while true; do doge | lolcat -a -d 100 -s 100 -p 1; done
  • 支持標準輸入: ls /usr/bin | doge 將顯示一些 /usr/bin下的可執行文件。哇噢，還有許多命令列的開關可以過濾詞語以及控制詞語的頻率。

網址: github.com/thiderman/doge

水族箱：ASCIIQuarium ​

ASCIIQuarium是一個以ASCII碼方式畫出的水族館/海洋動畫。享受生活在您電腦中水底的奇妙生物吧。

想運行ASCIIQuarium，您需要安裝Perl的curses包以及Term::Animation模組。請使用sudo apt-get install libcurses-perl來安裝前者，使用sudo cpan Term::Animation來安裝後者。兩個命令都需要在終端中運行。

功能包括：

  • 五彩的魚兒
  • 有趣的動畫，包括釣魚鈎
  • 還有許多的天鵝、鴨子、海豚和船隻

網址: www.robobunny.com

蒸汽機車：sl ​

sl是一個有趣的終端應用，它為那些意外的錯將ls輸成sl的用户顯示一個動畫。

我打字通常非常草率，更喜歡速度而不是準確性。但錯別字在命令列中是非常危險的。因此sl扮演了一個提醒者，提醒我們注意錯誤輸入的這種壞習慣。它總是會讓人咯咯的笑。

功能包括：

  • 使用 -F, 火車在飛翔
  • 使用 -l, 顯示一個小型的火車
  • 使用 -a, 看上去發生了意外

網址: github.com/mtoyoda/sl

火焰：aafire ​

aafire在終端中顯示燃燒的ASCII火焰。它展示了aalib庫的強大能力，一個ascii藝術庫顯示出來。

網址: aa-project.sourceforge.net/aalib

矩陣：CMatrix ​

CMatrix是一個基於ncurses的程序，它模擬《黑客帝國》（一部電影）中的畫面。如果您在一個山洞裏度過了上個15年，那麼您可能不知道這部1999年的美國科幻電影，主角為 Keanu Reeves, Laurence Fishburne, Carrie-Anne Moss, Hugo Weaving和 Joe Pantoliano。

它可以在終端設置為132x300的情況下工作，並且可以以同樣的速率進行滾動或者以用户定義的速度進行異步的滾動。

功能包括：

  • 修改文本顏色
  • 使用粗體字符
  • 異步滾動
  • 使用老式的滾動效果
  • 屏幕保護程序模式

網址: www.asty.org/cmatrix
