用這些專用工具讓你截圖更簡單 ​

“一圖勝千言”，這句二十世紀早期在美國應運而生的名言，説的是一張單一的靜止圖片所藴含的信息足以匹敵大量的描述性文字。本質上説，圖片所傳遞的信息量的確是比文字更有效更高效。

截圖（或抓幀）是一種捕捉自計算機的快照或圖片，用來記錄可視設備的輸出。屏幕捕捉軟件能從計算機中獲取到截圖。此類軟件有很多用處，因為一張圖片能很好地説明計算機軟件的操作，截圖在軟件開發過程和文檔中扮演了一個很重要的角色。或者，如果你的電腦有了技術性問題，一張截圖能讓技術支持理解你碰到的這個問題。要寫好計算機相關的文章、文檔和教程，沒有一款好的截圖工具是幾乎不可能的。如果你想保存你放在屏幕上的一些零星的信息，特別是不方便打字時，截圖也很有用。

在開源世界，Linux有許多專注於截圖功能的工具供選擇，基於圖形的和控制台的都有。如果要説一個功能豐富的專用截圖工具，看起來沒有能超過Shutter的。這款工具是小型開源工具的傑出代表，但是也有其它的不錯替代品可以選擇。

屏幕捕捉功能不僅僅只有專門的工具提供，GIMP和ImageMagick這兩款主攻圖像處理的工具，也能提供像樣的屏幕捕捉功能。

Shutter ​

Shutter是一款功能豐富的截圖軟件。你可以對特定區域、窗口、整個屏幕甚至是網站截圖 - 併為其應用不同的效果，比如用高亮的點在上面繪圖，然後上傳至一個圖片託管網站，一切盡在這個小窗口內。

包含特性：

  • 截圖範圍：
    • 一個特定區域
    • 窗口
    • 完整的桌面
    • 腳本生成的網頁
  • 在截圖中應用不同效果
  • 熱鍵
  • 打印
  • 直接截圖或指定延遲時間截圖
  • 將截圖保存至一個指定目錄並用一個簡便方法重命名它（用指定通配符）
  • 完全集成在GNOME桌面中（TrayIcon等等）
  • 當你截了一張圖並根據尺寸的百分比直接生成縮略圖
  • Shutter會話集：
    • 跟蹤會話中所有的截圖
    • 複製截圖至剪貼板
    • 打印截圖
    • 刪除截圖
    • 重命名文件
  • 直接上傳你的文件至圖像託管網站（比如 http://ubuntu-pics.de ），得到鏈接並將它們與其他人分享
  • 用內置的繪畫工具直接編輯截圖
  • 主頁： shutter-project.org
  • 開發者： Mario Kemper和Shutter團隊
  • 許可證： GNU GPL v3
  • 版本號： 0.93.1

HotShots ​

HotShots是一款捕捉屏幕並能以各種圖片格式保存的軟件，同時也能添加註釋和圖形數據（箭頭、行、文本 ...）。

你也可以把你的作品上傳到網上（FTP/一些web服務），HotShots是用Qt開發而成的。

HotShots無法從Ubuntu的Software Center中獲取，不過用以下命令可以輕鬆地來安裝它：

sudo add-apt-repository ppa:ubuntuhandbook1/apps     
sudo apt-get update
sudo apt-get install hotshots

包含特性：

  • 簡單易用
  • 功能完整
  • 內置編輯器
  • 熱鍵
  • 內置放大功能
  • 手動控制和多屏捕捉
  • 支持輸出格式：Black & Whte (bw), Encapsulated PostScript (eps, epsf), Encapsulated PostScript Interchange (epsi), OpenEXR (exr), PC Paintbrush Exchange (pcx), Photoshop Document (psd), ras, rgb, rgba, Irix RGB (sgi), Truevision Targa (tga), eXperimental Computing Facility (xcf), Windows Bitmap (bmp), DirectDraw Surface (dds), Graphic Interchange Format (gif), Icon Image (ico), Joint Photographic Experts Group 2000 (jp2), Joint Photographic Experts Group (jpeg, jpg), Multiple-image Network Graphics (mng), Portable Pixmap (ppm), Scalable Vector Graphics (svg), svgz, Tagged Image File Format (tif, tiff), webp, X11 Bitmap (xbm), X11 Pixmap (xpm), and Khoros Visualization (xv)
  • 國際化支持：巴斯克語、中文、捷克語、法語、加利西亞語、德語、希臘語、意大利語、日語、立陶宛語、波蘭語、葡萄牙語、羅馬尼亞語、俄羅斯語、塞爾維亞語、僧伽羅語、斯洛伐克語、西班牙語、土耳其語、烏克蘭語和越南語
  • 主頁： thehive.xbee.net
  • 開發者 xbee
  • 許可證： GNU GPL v2
  • 版本號： 2.2.0

ScreenCloud ​

ScreenCloud是一款易於使用的開源截圖工具。

在這款軟件中，用户可以用三個熱鍵之一或只需點擊ScreenCloud托盤圖標就能進行截圖，用户也可以自行選擇保存截圖的地址。

如果你選擇上傳你的截圖到screencloud網站，鏈接會自動複製到你的剪貼板上，你能通過email或在一個聊天對話框裏和你的朋友同事分享它，他們肯定會點擊這個鏈接來看你的截圖的。

包含特性：

  • 捕捉整個屏幕，窗口和截選區域
  • 快速又簡單：截取圖片，粘貼鏈接，完成
  • 免費託管你的截圖
  • 熱鍵
  • 設置定時器延遲
  • 允許 '捕捉窗口邊框'
  • 啓用/禁用通知
  • 設置開機自啓動
  • 調整賬户/上傳/文件名/快捷方式的設置
  • 跨平台工具
  • 插件支持：保存至Dropbox，Imgur等等
  • 支持上傳至FTP和SFTP服務器
  • 主頁： screencloud.net
  • 開發者： Olav S Thoresen
  • 許可證： GNU GPL v2
  • 版本號： 1.2.1

KSnapshot ​

KSnapshot也是一款易於使用的截圖工具，它能給整個桌面、單一窗口、窗口的一部分或一塊所選區域捕捉圖像。圖像能以各種不同格式保存。

KSnapshot也允許用户用熱鍵來進行截圖。除了保存截圖之外，它也可以被複制到剪貼板或用任何與圖像文件關聯的程序打開。

KSnapshot是KDE 4圖形模組的一部分。

包含特性：

  • 以多種格式保存截圖
  • 延遲截圖
  • 剔除窗口裝飾（邊框、菜單等）
  • 複製截圖至剪貼板
  • 熱鍵
  • 能用它的D-Bus接口進行腳本化
  • 主頁： www.kde.org
  • 開發者： KDE, Richard J. Moore, Aaron J. Seigo, Matthias Ettrich
  • 許可證： GNU GPL v2
  • 版本號： 0.8.2

via: http://www.linuxlinks.com/article/2015062316235249/ScreenCapture.html
