20 款優秀的 Linux 終端仿真器 ​

終端仿真器是一款用其它顯示架構重現可視終端的計算機程序。換句話説就是終端仿真器能使啞終端看似像一台連接上了服務器的客户機。終端仿真器允許最終用户用文本用户界面和命令列來訪問控制台和應用程序。（LCTT 譯註：終端仿真器原意指對大型機-啞終端方式的模擬，不過在當今的 Linux 環境中，通常指通過遠程或本地方式連接的偽終端，俗稱“終端”。）

20款Linux終端仿真器

你能從開源世界中找到大量的終端仿真器，它們有些擁有大量的特性而有些則反之。為了能更好地瞭解它們的特性，我們收集了一份優秀的Linux終端仿真器清單。每一款都列出了它們各自的描述和特性以及軟件界面截圖和下載鏈接。

1. Terminator ​

Terminator是一款先進且強大的終端仿真器，它支持多終端窗口。這款仿真器可以完全自定義。你可以更改它的界面尺寸、顏色，給它設置不同的形狀。擁有高用户友好性且使用起來很有樂趣。

Terminator的特性 ​

  • 自定義配置和配色方案，根據你的需要設置尺寸。
  • 使用插件來提供更多功能。
  • 快捷鍵可以加快普通操作。
  • 可以把終端窗口分割成幾個虛擬終端並把它們根據需要重新調整尺寸。

Terminator 終端

  • Terminator 主頁
  • 下載和安裝指引

2. Tilda ​

Tilda是一款漂亮的下拉式終端，基於GTK+，一鍵單擊你就可以呼出一個新的或隱藏着的Tilda窗口。你也可以用你所選擇的顏色來更改文本顏色和終端背景顏色。

Tilda的特性 ​

  • 高度定製的選項界面設置。
  • 你可以給Tilda設置透明度。
  • 優秀的嵌入式配色方案。

Tilda 終端

  • Tilda 主頁

3. Guake ​

Guake是一款基於python的下拉式終端，誕生於GNOME桌面環境。一鍵調出，再按一下就能隱藏。它的設計構思來源於FPS (第一人稱射擊) 遊戲 Quake，其主要目標是容易訪問。

Guake與Yakuaka和Tilda非常相似，不過它是一個集上述二者的優點於一體的基於GTK的程序。Guake完全是用Python和C的片段寫成的(全局熱鍵部分)。

Guake 終端

  • Guake 主頁

4. Yakuake ​

Yakuake (Yet Another Kuake) 是一款基於KDE的下拉式終端仿真器，它與Guake在功能上非常相似。它的設計構思也是受FPS遊戲Quake的啓發。

Yakuake從根本上説是一款KDE應用程序，它能非常輕鬆地安裝在KDE桌面上，但是如果你試着將它安裝在GNOME桌面上，你將會安裝大量的依賴包。

Yakuake的特性 ​

  • 順暢地從屏幕頂端彈出
  • 標籤式界面
  • 可配置的尺寸和動畫速度
  • 可定製

Yakuake 終端

  • Yakuake 主頁

5. ROXTerm ​

ROXterm是又一款輕量級終端仿真器，旨在提供與“GNOME終端”相似的特性。它原本創造出來是為了避免使用Gnome庫從而更少佔用空間和更快啓動，並使用獨立的小程序來顯示配置界面(GUI), 但是隨着時間的流逝，它的角色就轉變為給那些高級用户帶來更高層次的特性。

然而，它比GNOME終端更加具有可制定性，並且對於那些經常使用終端的高級用户更令人期望。它能和GNOME桌面環境完美結合並在終端中提供像拖拽項目那樣的特性。

Roxterm 終端

  • ROXTerm 主頁

6. Eterm ​

Eterm是最輕量級的一款彩色終端仿真器，是作為xterm的替代品而被設計出來。它是以一種自由選擇的理念設計的，帶來了更強大、靈活、用户自主把控的終端。

Eterm 終端

  • Eterm 主頁

7. Rxvt ​

Rxvt 的意思是擴展虛擬終端，它是一款彩色終端仿真器，是為那些不需要一些諸如Tektronix 4014仿真和toolkit-style可配置性等特性的高級用户而生的xterm替代品。

Rxvt 終端

  • Rxvt 主頁

8. Wterm ​

Wterm是另一款以rxvt項目為基礎的輕量級彩色終端仿真器。它所包含的特性包括設置背景圖片、透明度、反向透明度和大量的設置或運行環境選項讓它成為一款可高度自定義的終端仿真器。

wterm 終端

  • Wterm 主頁

9. LXTerminal ​

LXTerminal是一款基於VTE的終端仿真器，默認運行於沒有任何多餘依賴的LXDE(輕量級X桌面環境)下。這款終端有很多很棒的特性。

LXTerminal的特性 ​

  • 多標籤式支持
  • 支持常規命令如cp, cd, dir, mkdir, mvdir
  • 隱藏菜單欄以保證足夠界面空間
  • 更改配色方案

lxterminal 終端

  • LXTerminal 主頁

10. Konsole ​

Konsole是另一款強大的基於KDE的免費終端仿真器，最初由Lars Doelle創造。

Konsole的特性 ​

  • 多標籤式終端
  • 半透明背景
  • 支持拆分視圖模式
  • 目錄和SSH書籤化
  • 可定製的配色方案
  • 可定製的按鍵綁定
  • 終端中的活動通知警告
  • 增量搜索
  • 支持Dolphin文件管理器
  • 支持導出顯示為普通文本和HTML格式

Konsole 終端

  • Konsole 主頁

11. TermKit ​

TermKit是一款漂亮簡潔的終端，其目標是用WebKit渲染引擎在基於應用程序的命令列中構建出GUI視圖（LCTT 譯註：這個描述比較模糊，請參考截圖，或安裝一個體驗下），WebKit渲染引擎在Google Chrome和Chromium中廣泛使用。TermKit起初是為Mac和Windows設計的，但是由於Floby對TermKit 構建了分支，現在你可以將它安裝在Linux發行版上並感受TermKit帶來的魅力。

12. st ​

st是一款簡單的X Window終端。

st 終端

  • st 主頁

13. Gnome 終端 ​

GNOME終端是一款在GNOME桌面環境下自帶的終端仿真器，由Havoc Pennington和其他一些人共同開發。它允許用户在GNOME環境下可以使用一個真實的Linux shell來運行命令。GNOME終端是模仿了xterm終端仿真器，並有一些相似的特性。

Gnome終端支持多配置文件，用户可以為他們的賬户創建多個配置文件，每個配置文件能自定義配置選項，如字體、顏色、背景圖片、行為習慣等等，並能分別給每個配置文件取名。它也支持鼠標事件、url探測、多標籤等。

14. Final Term ​

Final Term是一款漂亮的開源終端仿真器，在這一個單獨的界面裏藴藏着一些令人激動的特性和方便的功能。雖然它仍然有待改進，但是它提供了一些重要的特性比如“語義”文本菜單、智能的命令列補全、GUI終端控制、全能的快捷鍵、彩色支持等等。以下動圖抓取並演示了它們的一些特性，點開來看看吧。

15. Terminology ​

Terminology是又一款新的現代化終端仿真器，為Enlightenment桌面創造，但也能用於其它桌面環境。它有一些獨一無二的棒極了的特性，這是其它終端仿真器所不具備的。

拋開這些特性，terminology甚至還提供了你無法從其它仿真器看到的東西，比如圖像、視頻和文檔的縮略圖預覽，它允許你從Terminology直接就能看到那些文件。

16. Xfce4 終端 ​

Xfce終端是一款輕量級的現代化終端仿真器，它簡單易用，為Xfce桌面環境設計。它最新的一個版本有許多新的炫酷特性，比如搜索對話框、標籤顏色轉換器、像Guake或Yakuake一樣的下拉式控制台等等。

  • Xfce4 終端

17. xterm ​

xterm應用是一款標準的在X Window系統上的終端仿真器。它保持了對DEC VT102和Tektronix 4014終端的兼容，以支持那些不能直接使用窗口系統的應用。

xterm 終端

  • xterm

18. LilyTerm ​

LilyTerm是一款基於libvte的開源終端仿真器，這款不太出名的仿真器追求的是快速和輕量級。LilyTerm也包括一些關鍵特性：

  • 支持標籤、彩色以及標籤重新排序
  • 通過快捷鍵管理標籤
  • 支持背景透明化和飽和度調整
  • 支持用户創建配置文件
  • 若干個自定義選項
  • 廣泛支持UTF-8

Lilyterm 終端

  • LilyTerm

19. Sakura ​

Sakura是另一款不知名的Unix風格終端仿真器，是為命令列模式和基於文本的終端程序開發的。Sakura基於GTK和livte，自身特性不多，不過還是有一些自定義選項，比如多標籤支持、自定義文本顏色、字體和背景圖片、快速命令處理等等。

Sakura 終端

  • Sakura

20. rxvt-unicode ​

rxvt-unicode (也稱為urxvt) 是另一個高度可定製、輕量級和快速的終端仿真器，支持xft和unicode，由Marc Lehmann開發。它有許多顯著特性，比如通過Unicode支持國際化語言，能顯示多種字體類型並支持Perl擴展。
