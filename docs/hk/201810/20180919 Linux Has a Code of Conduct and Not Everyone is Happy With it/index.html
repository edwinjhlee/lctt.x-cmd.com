Linux 擁有了新的行為準則，但是許多人都對此表示不滿 ​

Linux 內核有了新的行為準則Code of Conduct(CoC)。但在這條行為準則被簽署以及發佈僅僅 30 分鐘之後，Linus Torvalds 就暫時離開了 Linux 內核的開發工作。因為新行為準則的作者那富有爭議的過去，現在這件事成為了熱點話題。許多人都對這新的行為準則表示不滿。

如果你還不瞭解這件事，請參閲 Linus Torvalds 對於自己之前的不良態度致歉並開始休假，以改善自己的行為態度

Linux 內核開發遵守的新行為準則 ​

Linux 內核開發者並不是以前沒有需要遵守的行為準則，但是之前的衝突準則code of conflict現在被替換成了以“給內核開發社區營造更加熱情，更方便他人蔘與的氛圍”為目的的行為準則。

“為營造一個開放並且熱情的社區環境，我們，貢獻者與維護者，許諾讓每一個參與進我們項目和社區的人享受一個沒有騷擾的體驗。無關於他們的年紀、體型、身體殘疾、種族、性別、性別認知與表達、社會經驗、教育水平、社會或者經濟地位、國籍、外表、人種、信仰、性認同和性取向。”

你可以在這裏閲讀整篇行為準則：Linux 行為準則。

Linus Torvalds 是被迫道歉並且休假的嗎？ ​

這個新的行為準則由 Linus Torvalds 和 Greg Kroah-Hartman (僅次於 Torvalds 的二把手）簽發。來自 Intel 的 Dan Williams 和來自 Facebook 的 Chris Mason 也是該準則的簽署者之一。

如果我正確地解讀了時間線，在簽署這個行為準則的半小時之後，Torvalds 發送了一封郵件，對自己之前的不良態度致歉。他同時宣佈會進行休假，以改善自己的行為態度。

不過有些人開始閲讀這封郵件的話外之音，並對如下文字報以特別關注：

在這周，許多社區成員批評了我之前種種不解人意的行為。我以前在郵件裏進行的，對他人輕率的批評是非專業以及不必要的。這種情況在我將事情放在私人渠道處理的時候尤為嚴重。我理解這件事情的嚴重性，這是不好的行為，我對此感到十分抱歉。

他是否是因為新的行為準則被強迫做出道歉，並且決定休假，可以通過這幾行來判斷。這也可以讓我們採取一些措施，避免 Torvalds 被新的行為準則傷害。

有關貢獻者盟約作者 Coraline Ada Ehmke 的爭議 ​

Linux 的行為準則基於貢獻者盟約Contributor Convenant1.4 版本。貢獻者盟約被上百個開源項目所接納，包括 Eclipse、Angular、Ruby、Kubernetes 等項目。

貢獻者盟約由 Coraline Ada Ehmke 創作，她是一個軟件工程師，開源支持者，以及 LGBT 活動家。她對於促進開源世界的多樣性做了顯著的貢獻。

Coraline 對於精英主義的反對立場同樣十分鮮明。精英主義meritocracy這個詞語源自拉丁文，本意為系統內的進步取決於“精英”，例如智力水平、取得的證書以及教育程度。但類似 Coraline 的活動家們認為唯才是用是個糟糕的體系，因為它只是通過人的智力產出來度量一個人，而並不重視他們的人性。

圖片來源：推特用户@nickmon1112

Linus Torvalds 不止一次地説到，他在意的只是代碼而並非寫代碼的人。所以很明顯，這忤逆了 Coraline 有關唯才是用體系的觀點。

具體來説，Coraline 那被人關注飽受爭議的過去，是一個關於 Opal 項目貢獻者的事件。那是一個發生在推特上的討論，Elia，來自意大利的 Opal 項目核心開發者説“（那些變性人）不接受現實才是問題所在。”

Coraline 並沒有參加討論，也不是 Opal 項目的貢獻者。不過作為 LGBT 活動家，她以 Elia 發表“冒犯變性人羣體的發言”為由，要求他退出 Opal 項目。 Coraline 和她的支持者——他們給這個項目做過貢獻，通過在 GitHub 倉庫平台上冗長且激烈的爭論，試圖將 Elia——此項目的核心開發者移出項目。

雖然 Elia 並沒有離開這個項目，不過 Opal 項目的維護者同意實行一個行為準則。這個行為準則就是 Coraline 不停向維護者們宣揚的，她那著名的貢獻者盟約。

不過故事到這裏並沒有結束。貢獻者盟約稍後被更改，加入了一些針對 Elia 的新條款。這些新條款將行為準則的管束範圍擴展到公共領域。不過這些更改稍後被維護者們標記為惡意篡改。最後 Opal 項目擺脱了貢獻者盟約，並用自己的行為準則取而代之。

這個例子非常好的説明了，某些被冒犯的少數人羣——哪怕他們並沒有給這個項目做過一點貢獻，是怎樣試圖去驅逐這個項目的核心開發者的。

人們對於 Linux 新的行為準則的以及 Torvalds 道歉的反映。 ​

Linux 行為準則以及 Torvalds 的道歉一發布，社交媒體與論壇上就開始盛傳種種謠言與推測。雖然很多人對新的行為準則感到滿意，但仍有些人認為這是 SJW 嘗試滲透 Linux 社區的陰謀。（LCTT 譯註：SJW——Social Justice Warrior 所謂“為社會正義而戰的人”。）

Caroline 發佈的一個富有嘲諷意味的推特讓爭論愈發激烈。

Nick 並不是唯一一個反對 Linux 新的行為準則的人。SJW 的參與引發了更多的陰謀論猜測。

我猜今天關於 Linux 的大新聞就是現在，Linux 內核被一個 “後精英政治post meritocracy” 世界觀下的行為準則給掌控了。

這個行為準則的宗旨看起來不錯。不過在實際操作中，它們通常被當作 SJW 分子攻擊他們不喜之人的工具。況且，很多人都被 SJW 分子所厭惡。

我是不是唯一一個認為 Linus Torvalds 這十幾年來的態度恰好就是 Linux 和開源“社區”特有的那種，居高臨下，粗魯，鄙視一切新人的行為作風？反正作為一個新用户，我從來沒有在 Linux 社區裏感受到自己是受歡迎的。

你對於 Linux 行為準則怎麼看？ ​

如果你問我的觀點，我認為目前社區的確是需要一個行為準則。它能指導人們尊重他人，不因為他人的種族、宗教信仰、國籍、政治觀點（左派或者右派）而歧視，營造出一個積極向上的社區氛圍。

對於這個事件，你怎麼看？你認為這個行為準則能夠幫助 Linux 內核的開發，或者説因為 SJW 成員們的加入，情況會變得更糟？

在 FOSS 裏我們沒有行為準則，不過我們都會持着文明友好的態度討論問題。
