5 個給孩子的非常好的 Linux 遊戲和教育軟件 ​

Linux 是一個非常強大的操作系統，因此因特網上的大多數服務器都使用它。儘管它算不上是對用户友好的最佳操作系統，但它的多元化還是值的稱讚的。對於 Linux 來説，每個人都能在它上面找到他們自己的所需。不論你是用它來寫代碼、還是用於教學或物聯網（IoT），你總能找到一個適合你用的 Linux 發行版。為此，許多人認為 Linux 是未來計算的最佳操作系統。

未來是屬於孩子們的，讓孩子們瞭解 Linux 是他們掌控未來的最佳方式。這個操作系統上或許並沒有一些像 FIFA 或 PES 那樣的聲名赫赫的遊戲；但是，它為孩子們提供了一些非常好的教育軟件和遊戲。這裏有五款最好的 Linux 教育軟件，可以讓你的孩子遠離遊戲。

相關閲讀：使用一個 Linux 發行版的新手指南

1、GCompris ​

如果你正在為你的孩子尋找一款最佳的教育軟件，GCompris 將是你的最好的開端。這款軟件專門為 2 到 10 歲的孩子所設計。作為所有的 Linux 教育軟件套裝的巔峯之作，GCompris 為孩子們提供了大約 100 項活動。它囊括了你期望你的孩子學習的所有內容，從閲讀材料到科學、地理、繪畫、代數、測驗等等。

GCompris 甚至有一項活動可以幫你的孩子學習計算機的相關知識。如果你的孩子還很小，你希望他去學習字母、顏色和形狀，GCompris 也有這方面的相關內容。更重要的是，它也為孩子們準備了一些益智類遊戲，比如國際象棋、井字棋、好記性、以及猜詞遊戲。GCompris 並不是一個僅在 Linux 上可運行的遊戲。它也可以運行在 Windows 和 Android 上。

2、TuxMath ​

很多學生認為數學是門非常難的課程。你可以通過 Linux 教育軟件如 TuxMath 來讓你的孩子瞭解數學技能，從而來改變這種看法。TuxMath 是為孩子開發的頂級的數學教育輔助遊戲。在這個遊戲中，你的角色是在如雨點般下降的數學問題中幫助 Linux 企鵝 Tux 來保護它的星球。

在它們落下來毀壞 Tux 的星球之前，找到問題的答案，就可以使用你的激光去幫助 Tux 拯救它的星球。數字問題的難度每過一關就會提升一點。這個遊戲非常適合孩子，因為它可以讓孩子們去開動腦筋解決問題。而且還有助他們學好數學，以及幫助他們開發智力。

3、Sugar on a Stick ​

Sugar on a Stick 是獻給孩子們的學習程序 —— 一個廣受好評的全新教學法。這個程序為你的孩子提供一個成熟的教學平台，在那裏，他們可以收穫創造、探索、發現和思考方面的技能。和 GCompris 一樣，Sugar on a Stick 為孩子們帶來了包括遊戲和謎題在內的大量學習資源。

關於 Sugar on a Stick 最大的一個好處是你可以將它配置在一個 U 盤上。你只要有一台 X86 的 PC，插入那個 U 盤，然後就可以從 U 盤引導這個發行版。Sugar on a Stick 是由 Sugar 實驗室提供的一個項目 —— 這個實驗室是一個由志願者運作的非盈利組織。

4、KDE Edu Suite ​

KDE Edu Suite 是一個用途與眾不同的軟件包。帶來了大量不同領域的應用程序，KDE 社區已經證實，它不僅可以給成年人授權；它還關心年青一代如何適應他們周圍的一切。它囊括了一系列孩子們使用的應用程序，從科學到數學、地理等等。

KDE Edu 套件根據長大後所必需的知識為基礎，既能夠用作學校的教學軟件，也能夠作為孩子們的學習 APP。它提供了大量的可免費下載的軟件包。KDE Edu 套件在主流的 GNU/Linux 發行版都能安裝。

5、Tux Paint ​

Tux Paint 是給孩子們的另一個非常好的 Linux 教育軟件。這個屢獲殊榮的繪畫軟件在世界各地被用於幫助培養孩子們的繪畫技能，它有一個簡潔的、易於使用的界面和有趣的音效，可以高效地幫助孩子去使用這個程序。它也有一個卡通吉祥物去鼓勵孩子們使用這個程序。Tux Paint 中有許多繪畫工具，它們可以幫助孩子們放飛他們的創意。

總結 ​

由於這些教育軟件深受孩子們的歡迎，許多學校和幼兒園都使用這些程序進行輔助教學。典型的一個例子就是 Edubuntu，它是兒童教育領域中廣受老師和家長們歡迎的一個基於 Ubuntu 的發行版。

Tux Paint 是另一個非常好的例子，它在這些年越來越流行，它大量地用於學校中教孩子們如何繪畫。以上的這個清單並不很詳細。還有成百上千的對孩子有益的其它 Linux 教育軟件和遊戲。

如果你還知道給孩子們的其它非常好的 Linux 教育軟件和遊戲，在下面的評論區分享給我們吧。
