CPU 電源管理器：Linux 系統中 CPU 主頻的控制和管理 ​

你使用筆記本的話，可能知道 Linux 系統的電源管理做的很不好。雖然有 TLP、Laptop Mode Tools 和 powertop 這些工具來輔助減少電量消耗，但跟 Windows 和 Mac OS 系統比較起來，電池的整個使用週期還是不盡如意。此外，還有一種降低功耗的辦法就是限制 CPU 的頻率。這是可行的，然而卻需要編寫很複雜的終端命令來設置，所以使用起來不太方便。幸好，有一款名為 CPU Power Manager 的 GNOME 擴展插件，可以很容易的就設置和管理你的 CPU 主頻。GNOME 桌面系統中，CPU Power Manager 使用名為 intel_pstate 的頻率調整驅動程序（幾乎所有的 Intel CPU 都支持）來控制和管理 CPU 主頻。

使用這個擴展插件的另一個原因是可以減少系統的發熱量，因為很多系統在正常使用中的發熱量總讓人不舒服，限制 CPU 的主頻就可以減低發熱量。它還可以減少 CPU 和其他組件的磨損。

安裝 CPU Power Manager ​

首先，進入擴展插件主頁面，安裝此擴展插件。

安裝好插件後，在 GNOME 頂部欄的右側會出現一個 CPU 圖標。點擊圖標，會出現安裝此擴展一個選項提示，如下示：

功能特性 ​

  • 查看 CPU 主頻： 顯然，你可以通過這個提示窗口看到 CPU 的當前運行頻率。
  • 設置最大、最小主頻： 使用此擴展，你可以根據列出的最大、最小頻率百分比進度條來分別設置其頻率限制。一旦設置，CPU 將會嚴格按照此設置範圍運行。
  • 開/關 Turbo Boost： 這是我最喜歡的功能特性。大多數 Intel CPU 都有 “Turbo Boost” 特性，為了提高額外性能，其中的一個內核為自動進行超頻。此功能雖然可以使系統獲得更高的性能，但也大大增加功耗。所以，如果不做 CPU 密集運行的話，為節約電能，最好關閉 Turbo Boost 功能。事實上，在我電腦上，我大部分時間是把 Turbo Boost 關閉的。
  • 生成配置文件： 可以生成最大和最小頻率的配置文件，就可以很輕鬆打開/關閉，而不是每次手工調整設置。

結論 ​

正如我在開始時所説的，Linux 系統的電源管理並不是最好的，許多人總是希望他們的 Linux 筆記本電腦電池能多用幾分鐘。如果你也是其中一員，就試試此擴展插件吧。為了省電，雖然這是非常規的做法，但有效果。我確實喜歡這個插件，到現在已經使用了好幾個月了。
