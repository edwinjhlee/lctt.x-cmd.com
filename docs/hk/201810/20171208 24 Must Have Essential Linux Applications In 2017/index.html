24 個必備的 Linux 應用程序 ​

提要：Linux 上必備的應用程序是什麼呢？這個答案具有主觀性並取決於你使用 Linux 桌面的目的是什麼。但確實存在一些必備的並且大部分 Linux 用户都會安裝的應用程序。接下來我們會列舉出那些在所有 Linux 發行版上你都會安裝的最優秀的 Linux 應用程序。

在 Linux 的世界中，所有東西都由你選擇。你要選擇一個發行版？你能找到一大把。你想要找到一個稱心的音樂播放器？同樣會有許多選擇。

但它們並非全部遵循相同的設計理念 —— 其中一些可能追求極致輕量化而另一些會提供數不清的特性。因此想要找到正中需求的應用程序會成為相當令人頭疼的繁重任務。那就讓我們來緩解你的頭疼吧。

對於 Linux 用户來説最優秀的自由軟件 ​

接下來我將羅列一系列在不同應用場景下我偏愛的必備 Linux 自由軟件。當然此處我並非在説它們是最好的，但確實是在特定類別下我嘗試的一系列軟件中最喜歡的。也同樣歡迎你在評論區介紹你最喜歡的應用程序。

同時我們也製作了關於此次應用清單的視頻。在 YouTube 上訂閲我們的頻道獲取更多的 Linux 視頻。

網頁瀏覽器 ​

網頁瀏覽器

Google Chrome ​

Google Chrome 是一個強大並且功能完善的瀏覽器解決方案，它擁有完美的同步功能以及豐富的擴展。如果你喜歡 Google 的生態系統那麼 Google Chrome 毫無疑問會是你的菜。如果你想要更加開源的解決方案，你可以嘗試 Chromium，它是 Google Chrome 的上游項目。

Firefox ​

如果你不是 Google Chrome 的粉絲，你可以嘗試 Firefox。它一直以來都是一個非常穩定並且健壯的網頁瀏覽器。

Vivaldi ​

當然，如果你想要嘗試點不同的新東西，你可以嘗試 Vivaldi。Vivaldi 是一個完全重新設計的網頁瀏覽器，它由 Opera 瀏覽器項目的前成員基於 Chromium 項目而創建。Vivaldi 輕量並且可定製，雖然它還非常年輕並且在某些特性上仍不完善，但它仍能讓你眼前一亮並且優雅地工作。

  • 推薦閲讀：[回顧] Otter 瀏覽器為 Opera 愛好者帶來了希望

下載管理器 ​

下載管理器

uGet ​

uGet 是我遇到過最棒的下載管理器，它是開源的並且能滿足你對於一款下載管理器的一切期許。uGet 提供一系列便於管理下載的高級設置。你能夠管理下載隊列並且斷點續傳，針對大文件使用多連接下載，根據不同列表將文件下載至不同路徑，等等。

XDM ​

Xtreme 下載管理器（XDM）是一個 Java 開發的強大並且開源的下載工具。它擁有下載管理器的所有基本特性，包括視頻抓取、智能計劃任務以及瀏覽器集成。

  • 推薦閲讀：Linux 下最好的 4 個下載管理器

BitTorrent 客户端 ​

BitTorrent 客户端

Deluge ​

Deluge 是一個擁有漂亮用户界面的開源 BitTorrent 客户端。如果你習慣在 Windows 上使用 uTorrent，那麼 Deluge 的界面會讓你倍感親切。它擁有豐富的設置項和針對不同任務的插件支持。

Transmission ​

Transmission 力求精簡，它是用户界面最精簡的 BitTorrent 客户端之一。Transmission 是許多 Linux 發行版的預裝軟件。

  • 推薦閲讀：Ubuntu Linux 上前 5 名的 Torrent 客户端

雲存儲 ​

雲存儲

Dropbox ​

Dropbox 是目前最流行的雲存儲服務之一，它為新用户提供了 2GB 的免費存儲空間，以及一個健壯並且易於使用的 Linux 客户端。

MEGA ​

MEGA 提供了 50GB 的免費存儲，但這還並不是它最大的優點，MEGA 還為你的文件提供了端到端的加密支持。MEGA 提供一個名為 MEGAsync 的可靠的 Linux 客户端。

  • 推薦閲讀：2017 年 Linux 上最優秀的免費雲服務

通訊工具 ​

通訊工具

Pidgin ​

Pidgin 是一款開源的即時通訊工具，它支持許多聊天平台，包括 Google Talk、Yahoo 甚至 IRC。Pidgin 可通過第三方插件進行擴展，能提供許多附加功能。

你也可以使用 Franz 或 Rambox 來在一個應用中使用多個通訊服務。

Skype ​

我們都知道 Skype 是最流行的視頻聊天平台之一，它發佈了全新的 Linux 桌面客户端。

  • 推薦閲讀：2017 年 Linux 平台上最優秀的 6 款消息應用

辦公套件 ​

辦公套件

LibreOffice ​

LibreOffice 是 Linux 平台上開發最為活躍的開源辦公套件，主要包括 Writer、Calc、Impress、Draw、Math、Base 六個主要模組，並且每個模組都提供廣泛的文件格式支持。同時 LibreOffice 也支持第三方的擴展，以上優勢使它成為許多 Linux 發行版的默認辦公套件。

WPS Office ​

如果你想要嘗試除 LibreOffice 以外的辦公套件，WPS Office 值得一試。WPS Office 套件包括了寫作、演示和數據表格支持。

  • 推薦閲讀：Linux 平台 6 款最優秀的 Microsoft Office 替代品

音樂播放器 ​

音樂播放器

Lollypop ​

Lollypop 是一款相對較新的開源音樂播放器，擁有漂亮又不失簡潔的用户界面。它提供優秀的音樂管理、歌曲推薦、在線廣播和派對模式支持。雖然它是一款不具有太多特性的簡潔音樂播放器，但仍值得我們去嘗試。

Rhythmbox ​

Rhythmbox 是一款主要為 GNOME 桌面環境開發的音樂播放器，當然它也可以在其他桌面環境運行。它能完成所有作為一款音樂播放器的基礎功能，包括 CD 抓取和燒製、亂序播放，等等。它也提供了 iPod 支持。

cmus ​

如果你想要最輕量，並且喜歡命令列的話，cmus 適合你。個人來講，我是它的粉絲用户。cmus 是一款面向類 Unix 平台的小巧、快速並且強大的命令音樂播放器。它包含所有基礎的音樂播放器特性，並且你能夠通過擴展和腳本來增強它的功能。

  • 推薦閲讀：如何在 Ubuntu 14.04 和 Linux Mint 17 上安裝 Tomahawk 播放器

視頻播放器 ​

視頻播放器

VLC ​

VLC 是一款簡潔、快速、輕量並且非常強大的開源媒體播放器，它能夠直接播放幾乎所有格式的媒體文件，同時也能夠播放在線的流媒體。它也能夠安裝一些時髦的擴展來完成不同的任務，比如直接在播放器內下載字幕。

Kodi ​

Kodi 是一款成熟並且開源的媒體中心，在它的用户羣中非常受歡迎。它能夠處理來自本地或者網絡媒體存儲的視頻、音樂、圖片、播客甚至遊戲，更強大的是你還能用它來錄製電視節目。Kodi 可由附加組件和皮膚進行定製。

  • 推薦閲讀:Linux 平台上的 4 款格式工廠替代品

照片編輯器 ​

照片編輯器

GIMP ​

GIMP 是 Linux 平台上 Photoshop 的替代品，它是一款開源、全功能並且專業的照片編輯軟件。它打包了各式各樣的工具用來編輯圖片，更強大的是，它包含豐富的自定義設置以及第三方插件來增強體驗。

Krita ​

Krita 主要是作為一款繪圖工具，但也可以作為照片編輯軟件。它是開源的並且打包了非常多複雜的高級工具。

  • 推薦閲讀:Linux 平台最好的照片應用

文字編輯器 ​

每個 Linux 發行版都擁有自己的文字編緝器解決方案，當然大體上它們都非常簡潔並且沒有太多功能。但是也有一些文字編輯器具有更強大的功能。

文字編輯器

Atom ​

Atom 是由 GitHub 開發的一款現代高度可配置的文字編輯器，它是完全開源的並且能夠提供所有你能想到的文字編輯器功能。你可以開箱即用，也可以將其配置成你想要的樣子。並且你可以從它的社區安裝大量的擴展和主題。

Sublime Text ​

Sublime Text 是最受歡迎的文字編輯器之一，雖然它並不是免費的，但你可以無限地試用該款軟件。Sublime Text 是一款特性豐富並且高度模組化的軟件，當然它也提供插件和主題支持。

  • 推薦閲讀：Linux 平台最優秀的 4 款現代開源代碼編輯器

（LCTT 譯註：當然，我知道你們也忘記不了 VSCode。）

啓動器 ​

啓動器

Albert ​

Albert 是一款快速、可擴展、可定製的生產力工具，受 Alfred（Mac 平台上一個非常好的生產力工具）啓發並且仍處於開發階段，它的目標是“使所有觸手可及”。它能夠與你的 Linux 發行版非常好的集成，幫助你提高生產力。

Synapse ​

Synapse 已經有些年頭了，它是一個能夠搜索和運行程序的簡單啓動器。它也同時能夠加速一些工作流，譬如音樂控制、文件搜索、路徑切換、書籤、運行命令，等等。
