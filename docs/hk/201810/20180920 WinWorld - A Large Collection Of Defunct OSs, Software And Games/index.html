WinWorld：大型的廢棄操作系統、軟件、遊戲的博物館 ​

有一天，我正在測試 Dosbox -- 這是一個在 Linux 平台上運行 MS-DOS 遊戲與程序的軟件。當我在搜索一些常用的軟件，例如 Turbo C++ 時，我意外留意到了一個叫做 WinWorld 的網站。我查看了這個網站上的某些內容，並且着實被驚豔到了。WinWorld 收集了非常多經典的，但已經被它們的開發者所拋棄許久的操作系統、軟件、應用、開發工具、遊戲以及各式各樣的工具。它是一個以保存和分享古老的、已經被廢棄的或者預發佈版本程序為目的的線上博物館，由社區成員和志願者運營。

WinWorld 於 2013 年開始運營。它的創始者聲稱是被 Yahoo birefcases 激發了靈感並以此構建了這個網站。這個網站原目標是保存並且分享老舊軟件。多年來，許多志願者以不同方式提供了幫助，WinWorld 收集的老舊軟件增長迅速。整個 WinWorld 倉庫都是自由開源的，所有人都可以使用。

WinWorld 保存了大量的廢棄操作系統、軟件、系統應用以及遊戲 ​

就像我剛才説的那樣， WinWorld 存儲了大量的被拋棄並且不再被開發的軟件。

Linux 與 Unix：

這裏我給出了完整的 UNIX 和 LINUX 操作系統的列表，以及它們各自的簡要介紹、首次發行的年代。

  • A/UX - 於 1988 年推出，移植到蘋果的 68k Macintosh 平台的 Unix 系統。
  • AIX - 於 1986 年推出，IBM 移植的 Unix 系統。
  • AT &T System V Unix - 於 1983 年推出，最早的商業版 Unix 之一。
  • Banyan VINES - 於 1984 年推出，專為 Unix 設計的網絡操作系統。
  • Corel Linux - 於 1999 年推出，商業 Linux 發行版。
  • DEC OSF-1 - 於 1991 年推出，由 DEC 公司開發的 Unix 版本。
  • Digital UNIX - 由 DEC 於 1995 年推出，OSF-1 的重命名版本。
  • FreeBSD 1.0 - 於 1993 年推出，FreeBSD 的首個發行版。這個系統是基於 4.3BSD 開發的。
  • Gentus Linux - 由 ABIT 於 2000 年推出，未遵守 GPL 協議的 Linux 發行版。
  • HP-UX - 於 1992 年推出，UNIX 的變種系統。
  • IRIX - 由硅谷圖形公司（SGI）於 1988 年推出的操作系統。
  • Lindows - 於 2002 年推出，與 Corel Linux 類似的商業操作系統。
  • Linux Kernel - 0.01 版本於 90 年代早期推出，Linux 源代碼的副本。
  • Mandrake Linux - 於 1999 年推出。基於 Red Hat Linux 的 Linux 發行版，稍後被重新命名為 Mandriva。
  • NEWS-OS - 由 Sony 於 1989 年推出，BSD 的變種。
  • NeXTStep - 由史蒂夫·喬布斯創立的 NeXT 公司於 1987 年推出，基於 Unix 的操作系統。
  • PC/IX - 於 1984 年推出，為 IBM 個人電腦服務的基於 Unix 的操作系統。
  • Red Hat Linux 5.0 - 由 Red Hat 推出，商業 Linux 發行版。
  • Sun Solaris - 由 Sun Microsystem 於 1992 年推出，基於 Unix 的操作系統。
  • SunOS - 由 Sun Microsystem 於 1982 年推出，衍生自 BSD 基於 Unix 的操作系統。
  • Tru64 UNIX - 由 DEC 開發，舊稱 OSF/1。
  • Ubuntu 4.10 - 基於 Debian 的知名操作系統。這是早期的 beta 預發佈版本，比第一個 Ubuntu 正式發行版更早推出。
  • Ultrix - 由 DEC 開發， UNIX 克隆。
  • UnixWare - 由 Novell 推出， UNIX 變種。
  • Xandros Linux - 首個版本於 2003 年推出。基於 Corel Linux 的專有 Linux 發行版。
  • Xenix - 最初由微軟於 1984 推出，UNIX 變種操作系統。

不僅僅是 Linux/Unix，你還能找到例如 DOS、Windows、Apple/Mac、OS 2、Novell netware 等其他的操作系統與 shell。

於此同時，WinWorld 也收集了大量的舊軟件、系統應用、開發工具和遊戲。你也可以一起看看它們。

説實話，這個網站列出的絕大部分東西，我甚至都不知道它們存在過。其中列出的某些工具發佈於我出生之前。

如果您需要或者打算去測試一個經典的程序（例如遊戲、軟件、操作系統），並且在其他地方找不到它們，那麼來 WinWorld 資源庫看看，下載它們然後開始你的探險吧。祝您好運！
