Linux vs Mac：Linux 比 Mac 好的 7 個原因 ​

最近我們談論了一些為什麼 Linux 比 Windows 好的原因。毫無疑問，Linux 是個非常優秀的平台。但是它和其它操作系統一樣也會有缺點。對於某些專門的領域，像是遊戲，Windows 當然更好。而對於視頻編輯等任務，Mac 系統可能更為方便。這一切都取決於你的偏好，以及你想用你的系統做些什麼。在這篇文章中，我們將會介紹一些 Linux 相對於 Mac 更好的一些地方。

如果你已經在用 Mac 或者打算買一台 Mac 電腦，我們建議你仔細考慮一下，看看是改為使用 Linux 還是繼續使用 Mac。

Linux 比 Mac 好的 7 個原因 ​

Linux 和 macOS 都是類 Unix 操作系統，並且都支持 Unix 命令、bash 和其它 shell，相比於 Windows，它們所支持的應用和遊戲比較少。但也就是這點比較相似。

平面設計師和視頻剪輯師更加傾向於使用 Mac 系統，而 Linux 更加適合做開發、系統管理、運維的工程師。

那要不要使用 Linux 呢，為什麼要選擇 Linux 呢？下面是根據實際經驗和理性分析給出的一些建議。

1、價格 ​

假設你只是需要瀏覽文件、看電影、下載圖片、寫文檔、製作報表或者做一些類似的工作，並且你想要一個更加安全的系統。

那在這種情況下，你覺得花費幾百美金買個系統完成這項工作，或者花費更多直接買個 MacBook 更好？當然，最終的決定權還是在你。

買個裝好 Mac 系統的電腦？還是買個便宜的電腦，然後自己裝上免費的 Linux 系統？這個要看你自己的偏好。就我個人而言，除了音視頻剪輯創作之外，Linux 都非常好地用，而對於音視頻方面，我更傾向於使用 Final Cut Pro（專業的視頻編輯軟件）和 Logic Pro X（專業的音樂製作軟件）（LCTT 譯註：這兩款軟件都是蘋果公司推出的）。

2、硬件支持 ​

Linux 支持多種平台。無論你的電腦配置如何，你都可以在上面安裝 Linux，無論性能好或者差，Linux 都可以運行。即使你的電腦已經使用很久了，你仍然可以通過選擇安裝合適的發行版讓 Linux 在你的電腦上流暢的運行。

而 Mac 不同，它是蘋果機專用系統。如果你希望買個便宜的電腦，然後自己裝上 Mac 系統，這幾乎是不可能的。一般來説 Mac 都是和蘋果設備配套的。

這有一些在非蘋果系統上安裝 Mac OS 的教程。這裏面需要用到的專業技術以及可能遇到的一些問題將會花費你許多時間，你需要想好這樣做是否值得。

總之，Linux 所支持的硬件平台很廣泛，而 MacOS 相對而言則非常少。

3、安全性 ​

很多人都説 iOS 和 Mac 是非常安全的平台。的確，或許相比於 Windows，它確實比較安全，可並不一定有 Linux 安全。

我不是在危言聳聽。Mac 系統上也有不少惡意軟件和廣告，並且數量與日俱增。我認識一些不太懂技術的用户使用着很慢的 Mac 電腦並且為此深受折磨。一項快速調查顯示瀏覽器惡意劫持軟件是罪魁禍首。

從來沒有絕對安全的操作系統，Linux 也不例外。Linux 也有漏洞，但是 Linux 發行版提供的及時更新彌補了這些漏洞。另外，到目前為止在 Linux 上還沒有自動運行的病毒或瀏覽器劫持惡意軟件的案例發生。

這可能也是一個你應該選擇 Linux 而不是 Mac 的原因。

4、可定製性與靈活性 ​

如果你有不喜歡的東西，自己定製或者修改它都行。

舉個例子，如果你不喜歡 Ubuntu 18.04.1 的 Gnome 桌面環境，你可以換成 KDE Plasma。你也可以嘗試一些 Gnome 擴展豐富你的桌面選擇。這種靈活性和可定製性在 Mac OS 是不可能有的。

除此之外，你還可以根據需要修改一些操作系統的代碼（但是可能需要一些專業知識）來打造適合你的系統。這個在 MacOS 上可以做嗎?

另外你可以根據需要從一系列的 Linux 發行版進行選擇。比如説，如果你喜歡 MacOS 上的工作方式，Elementary OS 可能是個不錯的選擇。你想在你的舊電腦上裝上一個輕量級的 Linux 發行版系統嗎？這裏有一個輕量級 Linux 發行版列表。相比較而言，MacOS 缺乏這種靈活性。

5、使用 Linux 有助於你的職業生涯（針對 IT 行業和科學領域的學生） ​

對於 IT 領域的學生和求職者而言，這是有爭議的但是也是有一定的幫助的。使用 Linux 並不會讓你成為一個優秀的人，也不一定能讓你得到任何與 IT 相關的工作。

但是當你開始使用 Linux 並且探索如何使用的時候，你將會積累非常多的經驗。作為一名技術人員，你遲早會接觸終端，學習通過命令列操作文件系統以及安裝應用程序。你可能不會知道這些都是一些 IT 公司的新員工需要培訓的內容。

除此之外，Linux 在就業市場上還有很大的發展空間。Linux 相關的技術有很多（雲計算、Kubernetes、系統管理等），你可以學習、考取專業技能證書並獲得一份相關的高薪工作。要學習這些，你必須使用 Linux。

6、可靠 ​

想想為什麼服務器上用的都是 Linux 系統，當然是因為它可靠。

但是它為什麼可靠呢，相比於 MacOS，它的可靠體現在什麼方面呢？

答案很簡單 —— 給用户更多的控制權，同時提供更好的安全性。在 MacOS 上，你並不能完全控制它，這樣做是為了讓操作變得更容易，同時提高你的用户體驗。使用 Linux，你可以做任何你想做的事情 —— 這可能會導致（對某些人來説）糟糕的用户體驗 —— 但它確實使其更可靠。

7、開源 ​

開源並不是每個人都關心的。但對我來説，Linux 最重要的優勢在於它的開源特性。上面討論的大多數觀點都是開源軟件的直接優勢。

簡單解釋一下，如果是開源軟件，你可以自己查看或者修改源代碼。但對 Mac 來説，蘋果擁有獨家控制權。即使你有足夠的技術知識，也無法查看 MacOS 的源代碼。

形象點説，Mac 驅動的系統可以讓你得到一輛車，但缺點是你不能打開引擎蓋看裏面是什麼。那可太差勁了!

如果你想深入瞭解開源軟件的優勢，可以在 OpenSource.com 上瀏覽一下 Ben Balter 的文章。

總結 ​
