2018 年最好的 Linux 發行版 ​

Jack Wallen 分享他挑選的 2018 年最好的 Linux 發行版。

這是新的一年，Linux 仍有無限可能。而且許多 Linux 發行版在 2017 年都帶來了許多重大的改變，我相信在 2018 年它在服務器和桌面上將會帶來更加穩定的系統和市場份額的增長。

對於那些期待遷移到開源平台（或是那些想要切換到）的人對於即將到來的一年，什麼是最好的選擇？如果你去 Distrowatch 找一下，你可能會因為眾多的發行版而感到頭暈，其中一些的排名在上升，而還有一些則恰恰相反。

因此，哪個 Linux 發行版將在 2018 年得到偏愛？我有我的看法。事實上，我現在就要和你們分享它。

跟我做的 去年清單 相似，我將會打破那張清單，使任務更加輕鬆。普通的 Linux 用户，至少包含以下幾個類別：系統管理員，輕量級發行版，桌面，為物聯網和服務器發行的版本。

根據這些，讓我們開始 2018 年最好的 Linux 發行版清單吧。

對系統管理員最好的發行版 ​

Debian 不常出現在“最好的”列表中。但它應該出現，為什麼呢？如果瞭解到 Ubuntu 是基於 Debian 構建的（其實有很多的發行版都基於 Debian），你就很容易理解為什麼這個發行版應該在許多“最好”清單中。但為什麼是對管理員最好的呢？我想這是由於兩個非常重要的原因：

  • 容易使用
  • 非常穩定

因為 Debain 使用 dpkg 和 apt 包管理，它使得使用該環境非常簡單。而且因為 Debian 提供了最穩定的 Linux 平台之一，它為許多事物提供了理想的環境：桌面、服務器、測試、開發。雖然 Debian 可能不包括去年本分類的優勝者 Parrot Linux 所帶有的大量應用程序，但添加完成任務所需的任何或全部必要的應用程序都非常容易。而且因為 Debian 可以根據你的選擇安裝不同的桌面（Cinnamon、GNOME、KDE、LXDE、Mate 或者 Xfce），肯定可以滿足你對桌面的需求。

圖 1：在 Debian 9.3 上運行的 GNOME 桌面。

同時，Debain 在 Distrowatch 上名列第二。下載、安裝，然後讓它為你的工作而服務吧。Debain 儘管不那麼華麗，但是對於管理員的工作來説十分有用。

最輕量級的發行版 ​

輕量級的發行版有其特殊的用途：給予一些老舊或是性能低下的機器以新生。但是這不意味着這些特別的發行版僅僅只為了老舊的硬件機器而生。如果你想要的是運行速度，你可能會想知道在你的現代機器上這類發行版的運行速度能有多快。

在 2018 年上榜的最輕量級的發行版是 Lubuntu。儘管在這個類別裏還有很多選擇，而且儘管 Lubuntu 的資源佔用與 Puppy Linux 一樣小，但得益於它是 Ubuntu 家庭的一員，其易用性為它加了分。但是不要擔心，Lubuntu 對於硬件的要求並不高：

  • CPU：奔騰 4 或者奔騰 M 或者 AMD K8 以上
  • 對於本地應用，512 MB 的內存就可以了，對於網絡使用（Youtube、Google+、Google Drive、Facebook），建議 1 GB 以上。

Lubuntu 使用的是 LXDE 桌面（圖 2），這意味着新接觸 Linux 的用户在使用這個發行版時不會有任何問題。這份簡短清單中包含的應用（例如：Abiword、Gnumeric 和 Firefox）都是非常輕量的，且對用户友好的。

圖 2：LXDE桌面。

Lubuntu 能讓十年以上的電腦如獲新生。

最好的桌面發行版 ​

Elementary OS 連續兩年都是我清單中最好的桌面發行版。對於許多人，Linux Mint （也是一個非常棒的分支）都是桌面發行版的領袖。但是，於我來説，它在易用性和穩定性上很難打敗 Elementary OS。例如，我確信是 Ubuntu 17.10 的發佈讓我遷移回了 Canonical 的發行版。遷移到新的使用 GNOME 桌面的 Ubuntu 不久之後，我發現我缺少了 Elementary OS 外觀、可用性和感覺（圖 3）。在使用 Ubuntu 兩週以後，我又換回了 Elementary OS。

圖 3：Pantheon 桌面是一件像藝術品一樣的桌面。

使用 Elementary OS 的任何一個人都會覺得賓至如歸。Pantheon 桌面是將操作順滑和用户友好結合的最完美的桌面。每次更新，它都會變得更好。

儘管 Elementary OS 在 Distrowatch 頁面訪問量中排名第六，但我預計到 2018 年末，它將至少上升至第三名。Elementary 開發人員非常關注用户的需求。他們傾聽並且改進，這個發行版目前的狀態是如此之好，似乎他們一切都可以做的更好。 如果您需要一個具有出色可靠性和易用性的桌面，Elementary OS 就是你的發行版。

能夠證明自己的最好的發行版 ​

很長一段時間內，Gentoo 都穩坐“展現你技能”的發行版的首座。但是，我認為現在 Gentoo 是時候讓出“證明自己”的寶座給 Linux From Scratch（LFS）。你可能認為這不公平，因為 LFS 實際上不是一個發行版，而是一個幫助用户創建自己的 Linux 發行版的項目。但是，有什麼能比你自己創建一個自己的發行版更能證明自己所學的 Linux 知識的呢？在 LFS 項目中，你可以從頭開始構建自定義的 Linux 系統，而且是從源代碼開始。 所以，如果你真的想證明些什麼，請下載 Linux From Scratch Book 並開始構建。

對於物聯網最好的發行版 ​

Ubuntu Core 已經是第二年贏得了該項的冠軍。Ubuntu Core 是 Ubuntu 的一個小型的、事務型版本，專為嵌入式和物聯網設備而構建。使 Ubuntu Core 如此完美支持物聯網的原因在於它將重點放在 snap 包上 —— 這種通用包可以安裝到一個平台上而不會干擾其基本系統。這些 snap 包包含它們運行所需的所有內容（包括依賴項），因此不必擔心安裝它會破壞操作系統（或任何其他已安裝的軟件）。 此外，snap 包非常容易升級，並運行在隔離的沙箱中，這使它們成為物聯網的理想解決方案。

Ubuntu Core 內置的另一個安全領域是登錄機制。Ubuntu Core 使用Ubuntu One ssh密鑰，這樣登錄系統的唯一方法是通過上傳的 ssh 密鑰到 Ubuntu One帳户（圖 4）。這為你的物聯網設備提供了更高的安全性。

圖 4：Ubuntu Core屏幕指示通過Ubuntu One用户啓用遠程訪問。

最好的服務器發行版 ​

這裏有點意見不統一。主要原因是支持。如果你需要商業支持，乍一看，你最好的選擇可能是 Red Hat Enterprise Linux。紅帽年復一年地證明了自己不僅是全球最強大的企業服務器平台之一，而且是單一最賺錢的開源業務（年收入超過 20 億美元）。

但是，Red Hat 並不是唯一的服務器發行版。 實際上，Red Hat 甚至並不能壟斷企業服務器計算的各個方面。如果你關注亞馬遜 Elastic Compute Cloud 上的雲統計數據，Ubuntu 就會打敗紅帽企業 Linux。根據雲市場的報告，EC2 統計數據顯示 RHEL 的部署率低於 10 萬，而 Ubuntu 的部署量超過 20 萬。

最終的結果是，Ubuntu 幾乎已經成為雲計算的領導者。如果你將它與 Ubuntu 對容器的易用性和可管理性結合起來，就會發現 Ubuntu Server 是服務器類別的明顯贏家。而且，如果你需要商業支持，Canonical 將為你提供 Ubuntu Advantage。

對使用 Ubuntu Server 的一個警告是它默認為純文本界面（圖 5）。如果需要，你可以安裝 GUI，但使用 Ubuntu Server 命令列非常簡單（每個 Linux 管理員都應該知道）。

圖 5：Ubuntu 服務器登錄，通知更新。

你怎麼看 ​

正如我之前所説，這些選擇都非常主觀，但如果你正在尋找一個好的開始，那就試試這些發行版。每一個都可以用於非常特定的目的，並且比大多數做得更好。雖然你可能不同意我的個別選擇，但你可能會同意 Linux 在每個方面都提供了驚人的可能性。並且，請繼續關注下週更多“最佳發行版”選秀。

通過 Linux 基金會和 edX 的免費“Linux 簡介”課程瞭解有關Linux的更多信息。
