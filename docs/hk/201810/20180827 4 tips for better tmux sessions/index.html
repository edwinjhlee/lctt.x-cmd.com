更好利用 tmux 會話的 4 個技巧 ​

tmux 是一個終端多路複用工具，它可以讓你係統上的終端支持多面板。你可以排列面板位置，在每個面板運行不同進程，這通常可以更好的地利用你的屏幕。我們在 這篇早期的文章 中向讀者介紹過這一強力工具。如果你已經開始使用 tmux 了，那麼這裏有一些技巧可以幫你更好地使用它。

本文假設你當前的前綴鍵是 Ctrl+b。如果你已重新映射該前綴，只需在相應位置替換為你定義的前綴即可。

設置終端為自動使用 tmux ​

使用 tmux 的一個最大好處就是可以隨意的從會話中斷開和重連。這使得遠程登錄會話功能更加強大。你有沒有遇到過丟失了與遠程系統的連接，然後好希望能夠恢復在遠程系統上做過的那些工作的情況？tmux 能夠解決這一問題。

然而，有時在遠程系統上工作時，你可能會忘記開啓會話。避免出現這一情況的一個方法就是每次通過交互式 shell 登錄系統時都讓 tmux 啓動或附加上一個會話。

在你遠程系統上的 ~/.bash_profile 文件中加入下面內容：

if [ -z "$TMUX" ]; then
    tmux attach -t default || tmux new -s default
fi

然後註銷遠程系統，並使用 SSH 重新登錄。你會發現你處在一個名為 default 的 tmux 會話中了。如果退出該會話，則下次登錄時還會重新生成此會話。但更重要的是，若您正常地從會話中分離，那麼下次登錄時你會發現之前工作並沒有丟失 - 這在連接中斷時非常有用。

你當然也可以將這段配置加入本地系統中。需要注意的是，大多數 GUI 界面的終端並不會自動使用這個 default 會話，因此它們並不是登錄 shell。雖然你可以修改這一行為，但它可能會導致終端嵌套執行附加到 tmux 會話這一動作，從而導致會話不太可用，因此當進行此操作時請一定小心。

使用縮放功能使注意力專注於單個進程 ​

雖然 tmux 的目的就是在單個會話中提供多窗口、多面板和多進程的能力，但有時候你需要專注。如果你正在與一個進程進行交互並且需要更多空間，或需要專注於某個任務，則可以使用縮放命令。該命令會將當前面板擴展，佔據整個當前窗口的空間。

縮放在其他情況下也很有用。比如，想像你在圖形桌面上運行一個終端窗口。面板會使得從 tmux 會話中拷貝和粘帖多行內容變得相對困難。但若你縮放了面板，就可以很容易地對多行數據進行拷貝/粘帖。

要對當前面板進行縮放，按下 Ctrl+b, z。需要恢復的話，按下相同按鍵組合來恢復面板。

綁定一些有用的命令 ​

tmux 默認有大量的命令可用。但將一些更常用的操作綁定到容易記憶的快捷鍵會很有用。下面一些例子可以讓會話變得更好用，你可以添加到 ~/.tmux.conf 文件中：

bind r source-file ~/.tmux.conf \; display "Reloaded config"

該命令重新讀取你配置文件中的命令和鍵綁定。添加該條綁定後，退出任意一個 tmux 會話然後重啓一個會話。現在你做了任何更改後，只需要簡單的按下 Ctrl+b, r 就能將修改的內容應用到現有的會話中了。

bind V split-window -h
bind H split-window

這些命令可以很方便地對窗口進行橫向切分（按下 Shift+V）和縱向切分（Shift+H）。

若你想查看所有綁定的快捷鍵，按下 Ctrl+B, ? 可以看到一個列表。你首先看到的應該是複製模式下的快捷鍵綁定，表示的是當你在 tmux 中進行復制粘帖時對應的快捷鍵。你添加的那兩個鍵綁定會在前綴模式prefix mode中看到。請隨意把玩吧！

使用 powerline 更清晰 ​

如前文所示，powerline 工具是對 shell 的絕佳補充。而且它也兼容在 tmux 中使用。由於 tmux 接管了整個終端空間，powerline 窗口能提供的可不僅僅是更好的 shell 提示那麼簡單。

如果你還沒有這麼做，按照 這篇文章 中的指示來安裝該工具。然後使用 sudo 來安裝附件：

sudo dnf install tmux-powerline

接着重啓會話，就會在底部看到一個漂亮的新狀態欄。根據終端的寬度，默認的狀態欄會顯示你當前會話 ID、打開的窗口、系統信息、日期和時間，以及主機名。若你進入了使用 git 進行版本控制的項目目錄中還能看到分支名和用色彩標註的版本庫狀態。

當然，這個狀態欄具有很好的可配置性。享受你新增強的 tmux 會話吧，玩的開心點。
