5 個很酷的音樂播放器 ​

你喜歡音樂嗎？那麼 Fedora 中可能有你正在尋找的東西。本文介紹在 Fedora 上運行的各種音樂播放器。無論你有龐大的音樂庫，還是小一些的，抑或根本沒有，你都可以用到音樂播放器。這裏有四個圖形程序和一個基於終端的音樂播放器，可以讓你挑選。

Quod Libet ​

Quod Libet 是一個完備的大型音頻庫管理器。如果你有一個龐大的音頻庫，你不想只是聽，也想要管理，Quod Libet 可能是一個很好的選擇。

Quod Libet 可以從磁盤上的多個位置導入音樂，並允許你編輯音頻文件的標籤 —— 因此一切都在你的控制之下。此外，它還有各種插件可用，從簡單的均衡器到 last.fm 同步。你也可以直接從 Soundcloud 搜索和播放音樂。

Quod Libet 在 HiDPI 屏幕上工作得很好，它有 Fedora 的 RPM 包，如果你運行 Silverblue，它在 Flathub 中也有。使用 Gnome Software 或命令列安裝它：

$ sudo dnf install quodlibet

Audacious ​

如果你喜歡簡單的音樂播放器，甚至可能看起來像傳説中的 Winamp，Audacious 可能是你的不錯選擇。

Audacious 可能不直接管理你的所有音樂，但你如果想將音樂按文件組織起來，它能做得很好。你還可以導出和導入播放列表，而無需重新組織音樂文件本身。

此外，你可以讓它看起來像 Winamp。要讓它與上面的截圖相同，請進入 “Settings/Appearance”，選擇頂部的 “Winamp Classic Interface”，然後選擇右下方的 “Refugee” 皮膚。就這麼簡單。

Audacious 在 Fedora 中作為 RPM 提供，可以使用 Gnome Software 或在終端運行以下命令安裝：

$ sudo dnf install audacious

Lollypop ​

Lollypop 是一個音樂播放器，它與 GNOME 集成良好。如果你喜歡 GNOME 的外觀，並且想要一個集成良好的音樂播放器，Lollypop 可能適合你。

除了與 GNOME Shell 的良好視覺集成之外，它還可以很好地用於 HiDPI 屏幕，並支持暗色主題。

額外地，Lollypop 有一個集成的封面下載器和一個所謂的派對模式（右上角的音符按鈕），它可以自動選擇和播放音樂。它還集成了 last.fm 或 libre.fm 等在線服務。

它有 Fedora 的 RPM 也有用於 Silverblue 工作站的 Flathub，使用 Gnome Software 或終端進行安裝：

$ sudo dnf install lollypop

Gradio ​

如果你沒有任何音樂但仍想聽怎麼辦？或者你只是喜歡收音機？Gradio 就是為你準備的。

Gradio 是一個簡單的收音機，它允許你搜索和播放網絡電台。你可以按國家、語言或直接搜索找到它們。額外地，它可視化地集成到了 GNOME Shell 中，可以與 HiDPI 屏幕配合使用，並且可以選擇黑暗主題。

可以在 Flathub 中找到 Gradio，它同時可以運行在 Fedora Workstation 和 Silverblue 中。使用 Gnome Software 安裝它。

sox ​

你喜歡使用終端在工作時聽一些音樂嗎？多虧有了 sox，你不必離開終端。

sox 是一個非常簡單的基於終端的音樂播放器。你需要做的就是運行如下命令：

$ play file.mp3

接着 sox 就會為你播放。除了單獨的音頻文件外，sox 還支持 m3u 格式的播放列表。

此外，因為 sox 是基於終端的程序，你可以通過 ssh 運行它。你有一個帶揚聲器的家用服務器嗎？或者你想從另一台電腦上播放音樂嗎？嘗試將它與 tmux 一起使用，這樣即使會話關閉也可以繼續聽。

sox 在 Fedora 中以 RPM 提供。運行下面的命令安裝：

$ sudo dnf install sox
