在 Linux 命令列中使用 ls 列出文件的技巧 ​

學習一些 Linux ls 命令最有用的變化。

我在 Linux 中最先學到的命令之一就是 ls。瞭解系統中文件所在目錄中的內容非常重要。能夠查看和修改不僅僅是一些文件還有所有文件也很重要。

我的第一個 Linux 備忘錄是單頁 Linux 手冊，它於 1999 年發佈，成了我的首選參考資料。當我開始探索 Linux 時，我把它貼在桌子上並經常參考它。它在第一頁第一列的底部介紹了 ls -l 列出文件的命令。

之後，我將學習這個最基本命令的其它迭代。通過 ls 命令，我開始瞭解 Linux 文件權限的複雜性，以及哪些是我的文件，哪些需要 root 或者 sudo 權限來修改。隨着時間的推移，我習慣了使用命令列，雖然我仍然使用 ls -l 來查找目錄中的文件，但我經常使用 ls -al，這樣我就可以看到可能需要更改的隱藏文件，比如那些配置文件。

根據 Eric Fischer 在 Linux 文檔項目中關於 ls 命令的文章，該命令的起源可以追溯到 1961 年 MIT 的相容分時系統Compatible Time-Sharing System（CTSS）上的 listf 命令。當 CTSS 被 Multics 代替時，命令變為 list，並有像 list -all 的開關。根據維基百科，ls 出現在 AT&T Unix 的原始版本中。我們今天在 Linux 系統上使用的 ls 命令來自 GNU Core Utilities。

大多數時候，我只使用幾個迭代的命令。我通常用 ls 或 ls -al 查看目錄內容，但是你還應該熟悉許多其它選項。

以下是我認為有用且有趣的一些其它選項：

  • 僅列出目錄中的 .txt 文件：ls *.txt
  • 按文件大小列出：ls -s
  • 按時間和日期排序：ls -t
  • 按擴展名排序：ls -X
  • 按文件大小排序：ls -S
  • 帶有文件大小的長格式：ls -ls

要生成指定格式的目錄列表並將其定向到文件供以後查看，請輸入 ls -al > mydirectorylist。最後，我找到的一個更奇特的命令是 ls -R，它提供了計算機上所有目錄及其內容的遞歸列表。

有關 ls 命令的所有迭代的完整列表，請參閲 GNU Core Utilities。
