如何在 Linux 中擴展/增加 LVM 大小（邏輯卷調整） ​

擴展邏輯卷非常簡單，只需要很少的步驟，而且不需要卸載某個邏輯卷就可以在線完成。

LVM 的主要目的是靈活的磁盤管理，當你需要的時候，可以很方便地調整、擴展和縮小邏輯卷的大小。

如果你是邏輯卷管理（LVM） 新手，我建議你從我們之前的文章開始學習。

  • 第一部分：如何在 Linux 中創建/配置 LVM（邏輯卷管理）

擴展邏輯卷涉及到以下步驟：

  • 檢查邏輯卷（LV）所在的卷組中是否有足夠的未分配磁盤空間
  • 如果有，你可以使用這些空間來擴展邏輯卷
  • 如果沒有，請向系統中添加新的磁盤或 LUN
  • 將物理磁盤轉換為物理卷（PV）
  • 擴展卷組
  • 增加邏輯卷大小
  • 擴大文件系統
  • 檢查擴展的文件系統大小

如何創建 LVM 物理卷？ ​

使用 pvcreate 命令創建 LVM 物理卷。

當在操作系統中檢測到磁盤，使用 pvcreate 命令初始化 LVM 物理卷：

# pvcreate /dev/sdc
Physical volume "/dev/sdc" successfully created

請注意：

  • 上面的命令將刪除磁盤 /dev/sdc 上的所有數據。
  • 物理磁盤可以直接添加到 LVM 物理卷中，而不是磁盤分區。

使用 pvdisplay 命令來顯示你所創建的物理卷：

# pvdisplay /dev/sdc

"/dev/sdc" is a new physical volume of "10.00 GiB"

如何擴展卷組 ​

使用以下命令在現有的卷組（VG）中添加一個新的物理卷：

# vgextend vg01 /dev/sdc
Volume group "vg01" successfully extended

使用 vgdisplay 命令來顯示你所創建的物理卷：

# vgdisplay vg01

如何擴展邏輯卷？ ​

使用以下命令增加現有邏輯卷大小。

邏輯卷擴展（lvextend）的常用語法：

lvextend [要增加的額外空間] [現有邏輯卷名稱]

使用下面的命令將現有的邏輯卷增加 10GB：

# lvextend -L +10G /dev/mapper/vg01-lv002
Rounding size to boundary between physical extents: 5.90 GiB
Size of logical volume vg01/lv002 changed from 5.00 GiB (1280 extents) to 15.00 GiB (3840 extents).
Logical volume var successfully resized

使用 PE 大小來擴展邏輯卷：

# lvextend -l +2560 /dev/mapper/vg01-lv002

要使用百分比（%）擴展邏輯卷，請使用以下命令：

# lvextend -l +40%FREE /dev/mapper/vg01-lv002

現在，邏輯卷已經擴展，你需要調整文件系統的大小以擴展邏輯卷內的空間：

對於基於 ext3 和 ext4 的文件系統，運行以下命令：

# resize2fs /dev/mapper/vg01-lv002

對於 xfs 文件系統，使用以下命令：

# xfs_growfs /dev/mapper/vg01-lv002

使用 df 命令查看文件系統大小：

# df -h /lvmtest1
Filesystem Size Used Avail Use% Mounted on
/dev/mapper/vg01-lv002 15360M 34M 15326M 4% /lvmtest1
