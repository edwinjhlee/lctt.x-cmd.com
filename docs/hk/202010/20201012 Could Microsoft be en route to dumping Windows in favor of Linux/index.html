微軟能否放棄 Windows 轉向 Linux？ ​

Jack Wallen 認為，Microsoft Linux 是 Microsoft 桌面操作系統的下一個演進方向。他解釋了為什麼這將是一個對 Microsoft、IT 專業人士、用户和 Linux 社區的雙贏。

我尊敬的同事 Steven J. Vaughan-Nichols 在姊妹網站 ZDNet 上發表了一篇出色的文章，名為《基於 Linux 的 Windows 非常有意義》，他在文中討論了 Eric S. Raymond 的觀點，即我們正接近桌面戰爭的最後階段。Vaughan-Nichols 猜測，下一個合乎邏輯的步驟是在 Linux 內核上運行的 Windows 界面。

這是有道理的，尤其是考慮到微軟在 Windows 的 Linux 子系統（WSL） 上的努力。然而，從我過去幾年所目睹的一切來看，我認為可以得出一個對微軟更有意義的結論。

Microsoft Linux: 為什麼它是最好的解決方案 ​

一度，微軟的最大搖錢樹是軟件，確切地説是 Windows 和 Microsoft Office。但是，就像科技行業中的所有事物一樣，進化也在發生，而拒絕進化的科技公司失敗了。

微軟明白這一點，並且它已經進化了。一個恰當的例子是：Microsoft Azure。微軟的雲計算服務，以及 AWS 和 Google Cloud 已經成為這個不斷變化的行業的巨大推動力。Azure 已成為微軟新世界的搖錢樹 —— 多到以至於這家在桌面電腦市場上享有壟斷地位的公司已經開始意識到，或許還有更好的方式來利用桌面計算機。

這種優勢很容易通過 Linux 來實現，但不是你可能想到的 Linux。Vaughan-Nichols 所建議的 Microsoft Linux 對於微軟來説可能是一個很好的墊腳石，但我相信該公司需要做出一個更大的飛躍。我説的是登月規模的飛躍 —— 這將使所有參與者的生活變得更加輕鬆。

我説的是深入 Linux 領域。忘掉在 Linux 內核上運行 Windows 10 界面的桌面版本吧，最後承認 Microsoft Linux 可能是當今世界的最佳解決方案。

微軟發佈一個完整的 Linux 發行版將對所有參與者來説意味着更少的挫敗感。微軟可以將其在 Windows 10 桌面系統上的開發工作轉移到一個更穩定、更可靠、更靈活、更經考驗的桌面系統上來。微軟可以從任意數量的桌面系統中選擇自己的官方風格：GNOME、KDE、Pantheon、Xfce、Mint、Cinnamon... 不勝枚舉。微軟可以按原樣使用桌面，也可以為它們做出貢獻，創造一些更符合用户習慣的東西。

開發：微軟並沒有擺脱困境 ​

這並不意味着微軟在開發方面將擺脱困境。微軟也希望對 Wine 做出重大貢獻，以確保其所有產品均可在兼容層上順暢運行，並且默認集成到操作系統中，這樣最終用户就不必為安裝 Windows 應用程序做任何額外的工作。

Windows 用户需要 Defender ​

微軟開發團隊也希望將 Windows Defender 移植到這個新的發行版中。等一等。什麼？我真的是在暗示 Microsoft Linux 需要 Windows Defender 嗎？是的，我確定。為什麼？

最終用户仍然需要防範 網絡釣魚 詐騙phishing scams、惡意 URL 和其他類型的攻擊。普通的 Windows 用户可能不會意識到，Linux 和安全使用實踐的結合遠比 Windows 10 和 Windows Defender 要安全得多。所以，是的，將 Windows Defender 移植到 Microsoft Linux 將是保持用户基礎舒適的一個很好的步驟。

這些用户將很快了解在台式計算機上工作的感覺，而不必處理 Windows 操作系統帶來的日常困擾。更新更流暢、更值得信賴、更安全，桌面更有意義。

微軟、用户和 IT 專業人士的雙贏 ​

微軟一直在盡其所能將用户從標準的基於客户端的軟件遷移到雲和其他託管解決方案，並且其軟件搖錢樹已經變成了以網絡為中心和基於訂閲的軟件。所有這些 Linux 用户仍然可以使用 Microsoft 365 和它必須提供的任何其他 軟件即服務Software as a Service（SaaS）解決方案——所有這些都來自於 Linux 操作系統的舒適性和安全性。

這對微軟和消費者而言是雙贏的，因為這樣 Windows 沒有那麼多令人頭疼的事情要處理（通過捕獲漏洞和對其專有解決方案進行安全補丁），消費者可以得到一個更可靠的解決方案而不會錯過任何東西。 如果微軟打對了牌，他們可以對 KDE 或幾乎任何 Linux 桌面環境重新設置主題，使其與 Windows 10 界面沒有太大區別。

如果佈局得當，消費者甚至可能都不知道其中的區別——“Windows 11” 將僅僅是 Microsoft 桌面操作系統的下一個演進版本。

説到勝利，IT 專業人員將花費更少的時間來處理病毒、惡意軟件和操作系統問題，而把更多的時間用於保持網絡（以及為該網絡供動力的服務器）的運行和安全上。

大賣場怎麼辦？ ​

這是個關鍵的地方。為了讓這一做法真正發揮作用，微軟將不得不完全放棄 Windows，轉而使用自己風格的 Linux。基於同樣的思路，微軟需要確保大賣場裏的 PC 都安裝了 Microsoft Linux 系統。沒有半途而廢的餘地——微軟必須全力以赴，以確保這次轉型的成功。

一旦大賣場開始銷售安裝了 Microsoft Linux 的 PC 和筆記本電腦，我預測這一舉措對所有相關人員來説將會是一個巨大的成功。微軟會被視為終於推出了一款值得消費者信賴的操作系統；消費者將擁有一個這樣的桌面操作系統，它不會帶來太多令人頭疼的事情，而會帶來真正的生產力和樂趣；Linux 社區最終將主導桌面計算機。

Microsoft Linux：時機已到 ​

你可能會認為這個想法很瘋狂，但如果你真的仔細想想，微軟 Windows 的演進就是朝着這個方向發展的。為什麼不繞過這個時間線的中途部分，而直接跳到一個為所有參與者帶來成功的終極遊戲呢？ Microsoft Linux 正當其時。
