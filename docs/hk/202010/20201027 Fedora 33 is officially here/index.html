Fedora 33 正式發佈了 ​

本文譯自 Fedora 官方發佈公告。

今天，我很興奮地與大家分享數千名 Fedora 項目貢獻者辛勤工作的成果：我們的最新版本 Fedora 33 來了! 這是一個有着很多變化的大版本，但我相信所有這些工作也會讓您感到舒適，實現我們的目標：即為您帶來最新的穩定、強大、健壯的自由和開源軟件，並提供許多易於使用的產品。

如果您不想耽誤時間，直接體驗，現在就去 https://getfedora.org/ 下載吧，欲瞭解詳情請繼續閲讀！

找到適合您的 Fedora 風味！ ​

Fedora Edition 是針對桌面、服務器和雲環境中各種“體現”特定用途的目標產品，現在它也適用於物聯網。

Fedora Workstation 專注於桌面，尤其是面向那些想要“只管去用”的 Linux 操作系統體驗的軟件開發者。這個版本的特點是 GNOME 3.38，它一如既往地有很多很棒的改進。新增的 Tour 應用可以幫助新用户學習它們的操作方式。和我們所有其他面向桌面的變體一樣，Fedora Workstation 現在使用 BTRFS 作為默認文件系統。這些發佈的版本中帶來了很多偉大的增強功能，這個先進的文件系統為之奠定了基礎。為了您的視覺享受，Fedora 33 Workstation 現在默認提供了一個動畫背景（它會基於一天中的時間變化）。

Fedora CoreOS 是一個新興的 Fedora 版本。它是一個自動更新的、最小化的操作系統，用於安全地、大規模地運行容器化工作負載。它提供了幾個更新流，可以遵循大致每兩週一次的自動更新。目前 next 流是基於 Fedora 33 的，testing 和 stable 流後繼也會跟進。您可以從下載頁面中找到關於跟隨 next 流發佈的工件的信息，並在 Fedora CoreOS 文檔中找到關於如何使用這些工件的信息。

新晉升為 Edition 狀態的 Fedora IoT，為物聯網生態系統和邊緣計算用例提供了堅實的基礎。在許多功能之外，Fedora 33 IoT 還引入了平台抽象安全Platform AbstRaction for SECurity（PARSEC），這是一個開源倡議，以平台無關的方式為硬件安全和加密服務提供了通用 API。

當然，我們製作的不僅僅是“官方版本”，還有 Fedora Spin和 Lab。Fedora Spin 和 Lab 針對不同的受眾和用例，包括 Fedora CompNeuro，它為神經科學帶來了大量的開源計算建模工具，以及 KDE Plasma 和 Xfce等桌面環境。

此外，別忘了我們還有備用架構：ARM AArch64、Power 和 S390x。在 Fedora 33 中提供的新功能，AArch64 用户可以使用 .NET Core 語言進行跨平台開發。我們改進了對 Pine64 設備、NVidia Jetson 64 位平台以及 Rockchip 片上系統（SoC）設備的支持，包括 Rock960、RockPro64 和 Rock64。（不過，有個最新的説明：在其中一些設備上可能會出現啓動問題。從現有的 Fedora 32 升級是沒問題的。更多信息將在常見錯誤頁面上公佈。）

我們也很高興地宣佈，Fedora 雲鏡像和 Fedora CoreOS 將首次與 Fedora 33 一起在亞馬遜的 AWS 市場 中提供。Fedora 雲鏡像在亞馬遜雲中已經存在了十多年，您可以通過 AMI ID 或點擊一下來啓動我們的官方鏡像。該市場提供了獲得同樣東西的另一種方式，顯著擴大了 Fedora 的知名度。這也將使我們的雲鏡像可以更快地在新的 AWS 區域中可用。特別感謝 David Duncan 讓這一切成為現實！

常規改進 ​

無論您使用的是哪種版本的 Fedora，您都會得到開源世界提供的最新版本。遵循我們的 First 原則，我們更新了關鍵的編程語言和系統庫包，包括 Python 3.9、Ruby on Rails 6.0 和 Perl 5.32。在 Fedora KDE 中，我們沿用了 Fedora 32 Workstation 中的工作，默認啓用了 EarlyOOM 服務，以改善低內存情況下的用户體驗。

為了讓 Fedora 的默認體驗更好，我們將 nano 設置為默認編輯器。nano 是一個對新用户友好的編輯器。當然，那些想要像 vi 這樣強大的編輯器的用户可以自己設置默認編輯器。

我們很高興您能試用新版本! 前往 https://getfedora.org/ 並立即下載它。或者如果您已經在運行 Fedora 操作系統，請按照這個簡單的升級説明進行升級。關於 Fedora 33 新特性的更多信息，請參見發佈説明。

關於安全啓動的説明 ​

安全啓動Secure Boot是一種安全標準，它確保只有官方簽署的操作系統軟件才能加載到您的計算機上。這對於防止持久惡意軟件非常重要，因為這些惡意軟件可能會隱藏在您的計算機固件中，甚至在重新安裝操作系統時也能存活。然而，在 Boot Hole 漏洞發生後，用於簽署 Fedora 引導加載器Bootloader軟件的加密證書將被撤銷，並被新的證書取代。由於這將產生大範圍的影響，撤銷應該要到 2021 年第二季度或更晚才會廣泛推行。

然而，一些用户可能已經從其他操作系統或固件更新中收到了這種撤銷。在這種情況下，Fedora 將不能在啓用了安全啓動時進行安裝。要説明的是，這不會影響大多數用户。如果它確實影響到了您，您可以暫時禁用安全啓動。我們會在大範圍的證書撤銷之前發佈一個用新證書籤署的更新，在所有支持的版本上都可以使用，到那時，安全啓動應該可以重新啓用。

萬一出現問題時…… ​

如果您遇到問題，請查看 Fedora 33 常見錯誤頁面；如果您有疑問，請訪問我們的 Ask Fedora 用户支持平台。

謝謝大家 ​

感謝在這個發佈週期中為 Fedora 項目做出貢獻的成千上萬的人，尤其是那些在疫情大流行期間為使這個版本準時發佈而付出額外努力的人。Fedora 是一個社區，很高興看到我們如此互相支持。
