所有官方的 Ubuntu 特色版決定默認停止使用 Flatpak ​

Ubuntu 各特色版已同意停止使用 Flatpak 作為其操作系統的默認打包系統，而選擇替代的打包管理器。

這是一個令人驚訝的舉動，Canonical 宣佈，所有官方的 Ubuntu 特色版將不會默認支持 Flatpak。這個決定是在與所有官方 Ubuntu 特色版的團隊/維護者達成一致後做出的。這一變化計劃從 2023 年 4 月發佈的 “Lunar Lobster” 開始，該版本將在幾周後發佈。

Ubuntu 官方特色版將停止默認安裝 Flatpak ​

基於 Ubuntu 的官方特色版（Kubuntu、Lubuntu、Xubuntu 等）將不再將 Flatpak 作為其默認的打包解決方案，而選擇其他方案，如 Snap 和本地 deb 格式。這樣做是為了 “在尊重現有用户個性化他們自己的體驗方式的同時，改善新用户開箱即用的 Ubuntu 體驗”。

雖然這個決定得到了 Canonical 的支持，為了提供更好的用户體驗，阻止軟件包生態系統的碎片化，並給用户一個穩定的應用產品的選擇。但顯然，有幾個問題冒了出來。

為什麼是現在？Flatpak 和 Snap 都已經存在多年了。Flatpak 正變得越來越流行，它作為一種包格式在積極開發和維護，一些現代功化的功能也正在開發中，比如即將出現的 “經過驗證的應用程序”。而同時，由於 Snap 的 “啓動時間慢”，以及被 Canonical 的封閉服務器所控制等其他原因，它在桌面應用部署領域無法得到很大普及。

Ubuntu 發行版本身從來沒有默認提供過 Flatpak。但是特色版的維護者應該有選擇自己的產品的自由，並在 Ubuntu 基礎上進行創新。這也是成為一個特色版的主要原因，而不只是一個不同的桌面環境。

給用户造成的困難 ​

雖然你總是可以手動安裝 Flatpak 並配置 Flathub，但顯然，這可能會給用户帶來一些問題。我相信這個公告是徹底阻止 Flatpak 安裝方式的第一步。

還記得 Firefox Snap 的情況嗎？要刪除 Firefox Snap，你必須做複雜的命令列操作，才能安裝 deb 版本。這些對於普通的 Ubuntu 用户來説是非常複雜的。此外，一些流行的桌面應用程序在發佈後會立即推出 Flatpak 軟件包。對於許多流行的 Linux 桌面應用程序來説，有時甚至沒有提供 Snap 軟件包。

我相信讓用户來決定哪種打包格式是容易和遵循的。Canonical 應該通過解決 Snap 的核心問題、應用程序的可用性和閉門造車的性質來自行改進 Snap，而不是強行做出決定。此外，在為一個社區貢獻的發行版推送決定之前，應該與特色版維護者一起發起投票，以獲得來自社區的反饋。

結束語 ​

如果我們曾經從歷史中吸取教訓的話，它永遠不會以好的方式結束。也就是説，這一變化將從 2023 年 4 月 23 日 Ubuntu 23.04 “Lunar Lobster” 發佈時開始。

讓我用 Ubuntu 的座右銘來結束這篇文章，在這一舉措之後，這聽起來很奇怪：

“Ubuntu 是一個古老的非洲語單詞，意思是‘以人道善待他人Humanity to Others’。它經常被描述為提醒我們，‘羣在故我在’。我們把 Ubuntu 的精神帶到了計算機和軟件的世界裏。Ubuntu 發行版代表了世界軟件社區與世界分享的最好的東西。”
