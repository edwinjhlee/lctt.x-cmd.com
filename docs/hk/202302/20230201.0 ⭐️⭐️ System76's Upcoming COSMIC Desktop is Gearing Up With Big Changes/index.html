System76 即將推出的 COSMIC 桌面正在醖釀大變化 ​

System76 介紹了其即將推出的由 Rust 開發的 COSMIC 桌面環境的開發細節。讓我們來看看。

Pop!_OS 的開發者們 早在 2021 年 就開始着手開發他們基於 Rust 的桌面環境 COSMIC。

其目標是製作一些你已經熟悉的 Pop!_OS 的東西，但為你提供一個更快和更可擴展的桌面環境。

System76 也決定 不發佈 Pop!_OS 22.10，以專注於它的開發。

另外，我們的一個社區貢獻者嘗試了它的一個早期版本，它看起來很有希望：

建議閲讀 📖

我試用了 System76 新的基於 Rust 的 COSMIC 桌面！如果你還不知道，System76 的開發者一直在開發一個新的桌面環境（被稱為 COSMIC），它是用 Rust 編寫的：一種內存安全和超快的編程語言。從頭開始創建一個桌面環境並不是一件簡單的事。這涉及到創建從合成器、...

時間過去了一年，我們現在對這個桌面環境有了更多的期待。

讓我們來探索一下 System76 為我們準備了什麼。

COSMIC 桌面的 3 項關鍵性的改進 ​

📋 我們討論的這些變化和草圖在最終發佈時可能會有變化。

在 最近的一篇博文 中，來自 System76 的 Alex 讓我們看到了 COSMIC 桌面環境的發展狀況。

讓我帶你看看其中值得注意的亮點：

  • 新的用户界面功能
  • 重新打造的設置應用
  • 新的壁紙功能

1、新的用户界面功能 ​

一個新的 SegmentedButton 部件被用來處理 COSMIC 桌面環境中各處的標籤和分段式按鈕。

它的目的是給人一種簡潔、有條理、更集中的菜單體驗，而分段式按鈕則允許在選擇時進行操作。

他們還舉了一個例子來解釋這對用户界面有什麼幫助：

當你定製你的桌面以使用水平工作區而不是垂直工作區時，例如，你的選擇將導致桌面反映這種行為。

2、重新打造的設置應用 ​

首先，“設置” 應用得到了徹底的整改，現在搜索結果顯示為一個連續的、可滾動的、來自不同設置面板的結果列表。

🗒️ 在最新幾輪的內部用户（UX）測試後，具體設置進行了調整。

然後是各種設置面板本身的改造。讓我帶你瞭解一下。

顯示調整 ​

開發人員將圖形模式和深淺色選項移至顯示設置面板。在測試過程中，他們發現大多數用户到顯示設置中去是希望找到這些設置。

此外，當使用多個顯示器時，顯示設置將根據顯示器被組織到專門的選項卡中，並有改變或添加顏色配置文件的選項。

電源選項 ​

這個設置面板現在可以顯示連接的無線設備的電池電量和所有連接設備的概覽。

你還可以根據你的要求選擇電源配置文件，並限制筆記本電腦的電池充電，以保護電池壽命。

地區和語言選擇 ​

該設置已被劃分為不同的類別，以便於訪問。它們被分為幾個的類別，以選擇日曆、日期、温度和測量的區域格式。

聲音 ​

聲音設置中增加了一個新的選項，可以讓你調整個別警報和應用程序的音量。

此外，擁有兩個或更多揚聲器的用户現在可以使用新的揚聲器測試工具來優化其設置。

3、新的壁紙功能 ​

COSMIC 桌面環境可以讓你設置一張壁紙，每個顯示器一張，或者讓你以幻燈片的形式循環播放多張壁紙。這是給多顯示器用户的一個好消息！

你還可以對每張壁紙在切換到下一張之前在屏幕上停留的時間進行精細控制。

🛠️ 其他改進措施 ​

除了上面提到的面向用户的變化之外，還有一些內在的改進，包括：

  • 一個新的動態渲染器，iced-dyrend 已經由 System76 首席工程師實現，旨在動態調整你的 GPU 應該使用什麼渲染程序。如果你有 GPU，它可以在 OpenGL 或 Vulkan 之間切換；如果你沒有，則可以在 Softbuffer 之間切換。
  • 通過 cosmic-text 進行的文本渲染已經與 Softbuffer 0.2.0 配對，允許 libcosmic 部件庫的軟件渲染後端在任何操作系統上使用。
  • 開發者還測試了 XWayland 的實現，使 COSMIC 桌面環境能夠運行使用 X11 窗口系統的應用程序。
  • COSMIC 桌面環境已經通過 cosmic-time 動畫庫加入了對動畫的支持。它包含了默認應用程序所使用的動畫，並使用 Iced 工具箱構建。

開發者還提到：

雖然 COSMIC 桌面環境是為 Pop!_OS 開發的，但我們的目標是讓它的元素也能在其他操作系統上使用。

這是很好的消息！如果你想知道 COSMIC 桌面環境是否是 Pop!_OS 獨有的東西，也許你也可以在發行版上試試它，希望如此！ 😊
