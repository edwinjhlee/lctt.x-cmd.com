Mozilla 放棄的 Servo 瀏覽器引擎將在 2023 年重新迴歸 ​

根據其開發規劃，開源的 Rust 驅動的 Servo 瀏覽器引擎計劃返回該領域。

Servo 是一個基於 Rust 的實驗性瀏覽器引擎，最初由 Mozilla 的研究部門開發，但後來 轉移 到 Linux 基金會 作為一個社區維護的項目。

從那時起，儘管參與的成員一直在努力，但沒有重大的發展。

直到現在。

隨着團隊發佈了一份充滿希望的規劃，2023 年 Servo 的前景正在改善。

讓我帶你瞭解一下。

📢 2023 年路線圖：概覽 ​

由於在 1 月份獲得了 新的資金，Servo 項目 復活 了。

為了確保目標的明確，開發團隊發佈了今年的路線圖，以展示其計劃的良好前景。

關於這一點，他們還補充説：

我們正在重啓所有通常的活動，包括 PR 整理和審查、項目的公共溝通、安排 TSC 會議。我們還將進行一些外部宣傳，以吸引更多的協作者、合作伙伴，和有興趣合作、參與與資助項目的潛在贊助商。

他們還共享了 7 個他們想要在 2023 年實現的目標：

重新激活項目：這是第一階段，將持續到 2023 年底，涉及重新激活整個 Servo 項目。

項目推廣：在項目重新活躍起來的 GitHub 頁面的推動下，他們計劃宣傳該項目，進行一些推廣努力。這將吸引更多的協作者、公司和夥伴，他們可能對貢獻或資助項目感興趣。

主要依賴項升級：Servo 的幾個依賴項將得到改進，因為它們比較陳舊，需要升級，例如 WebRender 和 Stylo。

佈局引擎選擇：Servo 目前有兩個佈局引擎：2013（原引擎）和2020（新引擎）。他們將與貢獻者和社區一起決定選擇哪個作為長期發展的引擎。

對基本 CSS2 支持的進展：在完成上述兩件事後，他們計劃朝着基本的 CSS2 符合性 努力。

探索安卓支持：他們希望探索支持安卓平台以及其他平台的可能性，因為他們已經在過去對該平台進行了試驗。

可嵌入的瀏覽器引擎實驗：對於路線圖的最後階段，他們的目標是將 Servo 變成一個“可嵌入的瀏覽器渲染引擎”。團隊也在探索這方面的可能性，讓某種 Servo 演示在嵌入式設備上運行，或者研究現有的項目，如 Tauri。

你可以通過 官方公告 瞭解更多關於該路線圖的信息。

總結 ​

一個用 Rust 開發的網頁引擎可以產生奇蹟，比基於 Blink 或 Gecko 的替代品更優秀。

此外，我們幾乎每天使用的瀏覽器再多一個開源替代品不應該是一件壞事，它將讓我們有更多選擇。
