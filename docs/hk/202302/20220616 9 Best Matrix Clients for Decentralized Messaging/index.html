9 款最佳的去中心化通訊軟件 Matrix 的客户端 ​

Matrix 是一套開放的網絡標準，專用於去中心化實時加密通訊。

這套標準由 Matrix.org 基金會發布和維護。Matrix.org 基金會是一個非營利性組織，致力於創建一個開放、獨立且不斷演進的通訊平台。

如果一款應用支持 Matrix 協議，那就可以視它為 Matrix 客户端。

為何要選用 Matrix 客户端？ ​

Matrix 客户端致力於安全性和隱私性，並且提供了一個去中心化的網絡，令許多特性得以實現。

自 2019 年（正式版本發佈）以來，部分組織以及政府機構便開始逐漸採用 Matrix 協議，從而搭建安全、隱私、可靠的通訊平台。

就實際而言，去中心化的協議實現了不同組織間的相互通訊，同時也使得這個通訊協議得以抵抗審查。

如果你想要逃脱科技巨頭的魔爪，那 Matrix 就是正確的選擇。

不僅如此，你還可以運行自己的服務器，並加入 Matrix 網絡。換言之，通訊的基礎設施是去中心化的，但你仍然能夠根據需要，對其進行部署和配置。

如果你好奇的話，Matrix 協議具備了你需要的所有基本功能：

  • 去中心化交流
  • 端到端加密
  • WebRTC 語音通話 / 視頻通話
  • 實時同步
  • 消息已讀用户顯示
  • “正在輸入中” 提示
  • 羣組聊天

而且，我還要再強調一次：這個項目是開源的！

所以，Matrix 客户端已經是不二之選了。對那些注重隱私和安全的用户來説，則更是如此。

LCTT 譯註：實際上，Matrix 只是在隱私和便利之間達成了一種相對的平衡。它是將類似 Mastodon 的 聯邦federated 網絡結構用在了聊天中，也就是説，雖然整個網絡去中心化成了許多節點，但節點服務器的運營者仍然能對其用户進行少量掌控。但總的來説，相對那些中心化的聊天應用而言，Matrix 是個值得考慮的替代品。

9 款最佳的開源 Matrix 客户端 ​

本文中，我將介紹一些最好用的 Matrix 客户端，其中主要是桌面客户端（Linux、Windows、macOS），同時也推薦一些移動客户端和終端客户端。

1、Element ​

Element 是最佳的 Slack 開源替代品之一。它可以用於個人通訊，也能用於羣組聊天。

你可以免費使用，不過你也可以選擇自己搭建服務器，或者付費使用託管的家庭服務器。Element 提供了許多有用的功能，讓你能夠高效協作，並與你的團隊或好友加密通訊。

LCTT 譯註：如同 Mastodon 一樣，自費搭建服務器或者付費使用服務器，對大部分用户而言都是不必要的。初學者建議前往 https://joinmatrix.org/servers/，並選擇一個現有的服務器進行註冊，其中許多服務器都是免費開放註冊，並且國內可以連接的。下述的訂閲功能也並不是必要的。

如果你選擇付費訂閲，你還能將 Signal、WhatsApp 和 Telegram 聊天併入其中。

它支持 Linux、Windows 和 macOS，同時還提供 Android 和 iOS 的手機客户端。並且，你還能在網頁瀏覽器中使用它。因此，這是個方便的選擇。

LCTT 譯註：國內用户可能會在桌面客户端遇到錯誤，導致無法使用 Element。這是因為它在首次啓動會連接 matrix.org，但是國內用户無法訪問這個地址。要解決此問題，須手動修改配置文件（篇幅有限，詳見相關教程）。實在無法解決，可使用基於 Element 的 SchildiChat，或下文列出的其他客户端。

Element

2、Rocket.Chat ​

Rocket.Chat 是另一個 Slack 替代品，我們更喜歡把它當成團隊內部的通訊工具。

你可以在 Linux、Windows 和 macOS 上使用它，也可以獲取 Android 和 iOS 的手機應用。

儘管你可以選擇自建服務器或付費訂閲，但它也宣佈正在添加 Matrix 協議的支持。

本文創作之時，已經可以在 alpha 版中使用 Matrix 網絡。不過，穩定版應該很快就會發布了。所以，如果你已經在使用 Rocket.Chat，或者想把它當作 Matrix 客户端來使用，那麼敬請關注後續版本的發佈。

Rocket.Chat

3、NeoChat ​

NeoChat 是一個簡單的 Matrix 客户端，目前在 KDE 社區的管理下積極開發。

與 Element 不同，它只支持 Linux 和 Windows，特別是為 KDE Plasma 量身定做。你也可以在其他桌面環境使用它。

你可以在 KDE 的 “發現Discover” 軟件中心、Flathub 以及 Snap 商店安裝它。它不支持手機平台。所以，如果有桌面用户想要一個簡單的 Matrix 客户端，那 NeoChat 也是一個不錯的選擇。

LCTT 譯註：糾正一下，NeoChat 也支持安卓，可直接下載二進制，也可在 F-Droid 中添加 KDE 倉庫後下載。除此之外，它還支持 macOS。詳見其源代碼倉庫。

瞭解更多，可以查看它的 源代碼。

NeoChat

4、FluffyChat ​

FluffyChat 在用户體驗方面，是一個美觀（可愛）的 Matrix 客户端。

如果你想要一個簡單又直觀的 Matrix 客户端，並且支持桌面和手機（安卓和 iOS），那麼 FluffyChat 是一個不錯的選擇。

Linux 用户可以從 Snap 商店或 Flathub 安裝它。它並不提供 Windows 和 macOS 的原生應用支持，但你可以在網頁瀏覽器中使用它。

如果你好奇的話，可以從它的 GitLab 頁面 瞭解更多。

FluffyChat

5、Fractal ​

Fractal 是一款用於 GNOME 桌面的 Matrix 聊天客户端，使用 Rust 編寫。正如其描述所説，它的界面經過優化，適合大型團隊的協作。

由於它以 Flatpak 的形式發佈，你可以在任何 Linux 發行版上安裝它，無論桌面環境如何。

如果你喜歡能夠在系統上快速運行的應用，那 Fractal 可能是不錯的選擇。可以前往它的 GitLab 頁面 瞭解更多。

Fractal

6、Hydrogen Web（實驗性） ​

在找其它的精簡的（專注性能）Matrix 客户端嗎？

Hydrogen 聊天客户端提供輕量級體驗、離線功能，並有着廣泛的瀏覽器支持。

雖然仍未完工，但 Element 背後的同一支團隊正在開發着它。所以，如果你期待看到一個輕量的 Matrix 客户端替代品，你可以在它的 GitHub 頁面 跟進該項目。

Hydrogen

7、Matrix Commander（基於命令列） ​

如果你想要用終端在 Matrix 網絡上來收發文字消息，這個命令列工具就十分不錯。

當然，並非一切都能在終端完成。所以，最好創建 cron 任務來實現消息提醒、機器人等用例。

你可以在 PyPi 或者 Docker Hub 上找到它。

Matrix Commander

8、Gomuks（基於命令列） ​

想試試用 Go 寫的終端 Matrix 客户端？

並非每個人都可以嘗試。不過，如果你喜歡用 Go 寫的命令列工具，可以用 Gomuks 這個簡單的 Matrix 客户端來進行基本聊天。

你可以在它的 GitHub Releases 部分 找到其 Linux、Windows 和 macOS 的二進制文件。

Gomuks

9、Syphon（Alpha 版） ​

我們通常會避免列出仍處於早期開發的程序。但是，Syphon 作為一個手機專用的 Matrix 客户端，是一個有趣的選擇。

如果你想要為你的安卓 / iOS 設備安裝一個類似 Signal 的開源 Matrix 客户端，那選擇 Syphon 也不錯。用户界面看起來很熟悉（但並不是完全照抄的）。如果你想實驗一下，那可以試試。

Syphon

總結 ​

Matrix 協議也許沒能流行於所有組織和人羣之中。但是，可以證明的是，作為一個開源項目，它能稱得上是一個隱私可靠的去中心化網絡。

最好的一點在於，你可以選擇你想要的客户端，而不必被迫使用特定的應用才能在多個設備之間進行通信。

所以，你會選擇什麼作為你最喜歡的 Matrix客户端？
