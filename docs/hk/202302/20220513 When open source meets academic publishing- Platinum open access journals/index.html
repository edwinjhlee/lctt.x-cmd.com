當開源遇到學術出版：白金開放獲取期刊 ​

學者現在可以免費發表（文章），免費閲讀（文章），與此同時仍然能夠在專業成就的道路上持續進步。

學者們經常將他們的作品免費提供給公司，然後卻要花錢購買它！你能想像農民在免費送出他們的食物之後再重新花錢買回來做晚餐嗎？可能不能吧。像我這樣的學者陷入這樣的陰謀中幾十年了，我們以工作保障為交換免費提供我們的作品，然後卻要每年花幾百萬美元來閲讀我們自己的文章。

幸運的是，情況正在發生改變。我剛剛完成的一項 研究 的結果顯示：對於學者來説，獲得工作保障的同時而不對此付出代價是可能的。我的研究發現數百種期刊是 白金開放獲取platinum open access（LCTT 譯註：譯名源自中文網絡）的 —— 也就是説，它們不需要作者或者讀者為同行評議的工作付費，卻仍然擁有幫助學者在他們的職業生涯中取得成功的聲望和讀者羣。

這一趨勢正在擴張：開放獲取期刊目錄 羅列了超過 17300 種期刊，這些期刊均提供了某種程度上的 開放獲取open access（OA）方式。該目錄還提供了超過 12250 種無須 文章處理費article-processing charges（APC）的期刊。我使用一段簡易的開源 Python 腳本 來將該列表與另一按照期刊發表的文章被其他文章引用的頻次排名的期刊列表（期刊影響因子列表）進行比較。很明顯，最近幾年來，總體的開放獲取期刊與白金開放獲取期刊均呈上升趨勢。這一趨勢可能有助於在避免學術奴役的同時加速科學發展。

學者的窘境 ​

學者們通常是相當聰慧的，那麼他們為什麼如此長時間地投身於這種不利體系中呢？簡而言之，學者陷於這樣一個陷阱中：為了維繫他們的工作和獲得終身教職，他們需要在高 影響因子impact factor 的期刊上發表文章。影響因子是一種基於最近兩年間在給定期刊上發表的文章的平均引用數量的衡量指標。影響因子由 Web of Science 索引。對學者而言，影響因子是一個有影響力的衡量指標。

歷史上，學術出版一直由一小部分主要出版商統治。他們採用基於訂閲制的商業模式。在這樣的商業模式中，學術作者撰寫文章，評審同行的文章，也經常對這些文章進行編輯。這些工作都是沒有任何報酬的。這些文章出版了，它們的版權則由那些主要的出版公司所有。即使是參與上述工作的學者也需要個人付費閲讀這些文章（每篇文章大約 35 美元），或者由他們所在學校的圖書館付費訂閲期刊上的所有文章。（訂閲）所花的費用是相當可觀的：單是一個出版商的所有文章的訂閲費用通常超過一百萬每年。

有很多顯然的理由都説明這一體制是毫無意義的。由於限制對隱匿在付費專區後的受版權保護的科學文獻的訪問，使得科學進程陷於停滯。如果你因為無法查看而不知道前沿科技是什麼的話，你就無法進行相應的前沿技術研究。科學家被劃分為能夠負擔訪問這些文章的費用的人，以及不能負擔（這些費用的人）。發展中國家的學者往往難以支付，不過即使是財力雄厚的 哈佛大學 也已經採取行動控制它的年度期刊費用。

文章作者的花費也同樣高昂。每篇文章的文章處理費從幾百美元到駭人聽聞的幾千美元不等。文章處理費對一些資金不足的學科尤其有害，比如人文學科與社會學科（與物理學、醫學和工程學相比而言）。大量的文章處理費也強化了學術界的貧富差距，使得（學者的）專業成就依賴於是否有收入投入文章發表。還有哪種職業要求從業者付費為他人制造產品？

開放獲取，解決之道！ ​

開放獲取行動可以解決上述問題，開放獲取行動倡導使所有的學術文獻對任何人都能自由自由獲取。開放獲取的出版量有明顯上升：它佔了當前同行評議文章的將近三分之一。

開放獲取的優勢分兩個方面。首先，開放獲取有利於科學整體，因為它提供了一個不受阻礙地閲讀前沿技術的方式。這些技術有助於進一步做出重要的認知進步。其次，就學者個人層面而言，通過讓他們的作品在網絡上輕而易舉地免費獲得，提供了最大化他們作品的潛在受眾的實際優勢。

基於上述原因，資助者已經開始要求開放獲取，尤其是科學領域的公共資助者。如果一項研究的公共資助者還需要在閲讀研究內容時二次付費，這種做法很難站得住腳。

學術出版目前身處何方，以後又去向何處？ ​

傳統出版商仍然掌控着目前的局面，主要是因為認為他們壟斷了具有影響因子的期刊這一認知。很多學者無視傳統出版方式的缺點，仍然持續在基於訂閲制的期刊上發表文章或者支付高昂的文章處理費，因為他們知道在高影響因子的期刊上發表文章是至關重要的，它能夠提供賴以獲取補助、終身教職與職位晉升的專業性的證明。

多年以前，學術界完全沒有選擇的餘地：要麼在具有影響因子的期刊上發表，要麼在通過開放獲取方式發表。現在他們可以通過開放獲取方式發表並仍然能夠通過以下三種方式之一享受影響因子的益處：

  • 綠色開放獲取模式Green OA：以傳統方式出版後，再通過上傳預印版或者接受版論文至開放倉庫或者服務器完成自行歸檔。一些高校擁有用於上述目的的公共倉庫。舉例而言，韋仕敦大學Western University 擁用 Scholarship@Western 公共倉庫，該校的任何教師都可以在上面分享他們的作品。而沒有自己機構的公共倉庫的學者可以使用諸如 preprints.org、arXiv 或 OSF preprints 等網絡服務器。我也會將社交媒體用於學術，比如將 Academia 或 ResearchGate 用於自行存檔。由於不同的出版商設計了不同的規則，這是不方便查閲的，而且某種程度上是耗時耗時耗力的。
  • 金色開放獲取模式Gold OA：在日益壯大的具有影響因子的期刊列表上選一份期刊發表，它將使你的文章發表後可以自由獲取但是需要文章處理費。這種方式易於查閲：開放獲取設置內建於出版過程中，只需要像往常一樣進行學術出版。這種方式的缺點是可能會從研究活動中拿出一部分資金用於文章處理的費用。
  • 白金開放獲取模式Platinum OA：在具有影響因子的白金開放獲取期刊上發表。不需要為出版和閲讀付費。挑戰在於在你的學科中找到符合上述標準的期刊，不過情況正在持續變化。

有數以萬計的期刊，但是隻有幾百種具有影響因子的白金開放獲取期刊。對於學者，困難可能在於在他們的研究與符合他們預期的期刊之間找到一個合適的平衡。你可以在我的研究報告附錄中找到本文提到的列表，或者使用上文提到的 Python 腳本自行更新列表數量。白金開放獲取期刊的數量正在快速增長，因此如果你目前尚未找到合適的期刊，仍然可能在不久以後擁有一些可靠的期刊以供選擇。祝你享受出版的樂趣！
