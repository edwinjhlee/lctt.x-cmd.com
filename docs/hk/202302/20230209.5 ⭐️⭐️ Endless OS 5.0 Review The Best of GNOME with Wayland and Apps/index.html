Endless OS 5.0：帶有 Wayland 和豐富應用程序的最佳 GNOME 桌面 ​

新版本的 Endless OS 5.0 已經發布，帶來了更多的功能和穩定性。下面是對這個版本的簡要點評。

在不變性成為炒作對象之前，Endless OS 已經提供了一種基於 OSTree 的高效桌面體驗。它基於 Debian 和 Ubuntu，但正在獨立開發。由於其底層基於 OSTree，Endless OS 運行在其用户空間中，同時給你最好的桌面體驗。

它是一個適合學校、小規模部署、實驗室和離線使用情況的完美髮行版。

新版本的 Endless OS 5.0 現在已經推出。下面是對其功能的快速回顧和深入點評。

我們相信，個人計算對生產力、學習和工作技能至關重要。

我們在過去 10 年中致力於設計和提供操作系統和工具，使人們能夠獲得和控制他們的技術。

藉助我們的工具，我們可以通過使用和發現來提高生產力、創造力和學習，我們幫助各種背景的人以更有意義的方式參與數字經濟。

—— Endless OS 使命宣言

Endless OS 5 點評 ​

由於這個操作系統的目的是為不太富裕的人提供數字計算的機會，所以它提供了 Windows 安裝程序。你可以直接下載它並在 Windows 環境中試用。

此外，它還提供了一個專門的獨立 ISO 鏡像，可以通過 U 盤進行安裝。

上次我在 2021 年點評 Endless OS 時，它並沒有提供 ARM 版本。我很驚訝地發現，它現在有一個 ARM 鏡像，你可以在樹莓派和其他 ARM 板上試用。

在我的測試安裝中，一切都很順利。它使用一個自定義的安裝程序，類似於 Fedora 的 Anaconda 安裝程序。然而，安裝它需要一個完整的磁盤。如果你喜歡雙啓動，在此 有一個詳細的指南。但是，我覺得它的設置有點複雜。

登錄和第一印象 ​

這個版本基於 Debian 11 “bullseye”，帶有 Linux 主線 內核 5.15。此外，它還為該團隊的原生應用程序提供了單獨的軟件倉庫。其桌面基於 GNOME 41。

這個版本在外觀感受方面有一些改變。首先，底部面板被改變為顯示基本的 GNOME 風格的停靠區。它總是可見的，當你把一個窗口移到它上面時，它就會消失。早些時候，它是一個固定的標準面板，有一個應用程序圖標、系統托盤和正在運行的應用程序部件。

其次，它引入了一個新的頂部面板，遵循 GNOME 的設計。它包含活動、應用程序啓動器和系統托盤。

和 Endless OS 4.0 的外觀相比，它有很多改變：

對 GNOME 桌面和工作區的獨特定製 ​

默認外觀保持不變，包括帶有搜索框的桌面應用程序視圖。頂部面板上的應用程序是對運行中的應用程序和桌面視圖的切換。

超級鍵（Super）也可以切換到正在運行的應用程序和工作區視圖，這一點非常方便。窗口在右上方有最小化、最大化和關閉按鈕；它們不需要調整。

然而，在這個版本中，有一個喜歡的功能被放棄了。在 Endless OS 4.0 中，當你點擊桌面的空白部分時，它會立即將所有打開的窗口最小化，並向你顯示桌面。然而，這個功能已經不再可用了。這是一個多麼方便的功能，可以使工作流程更加順暢。

在 Endless OS 5.0 中引入 Wayland ​

現代顯示服務器 Wayland 在這個版本中首次出現在 Endless OS 中。默認登錄是 Wayland。然而，你可以從登錄界面切換到 X.Org。得益於 Wayland，你可以感受到 Endless OS 操作系統中流暢的動畫、手勢和性能。

手勢支持 ​

Endless OS 5.0 還引入了多手勢支持。你現在可以通過觸控板/觸摸板使用三指左右輕掃來瀏覽工作區。此外，三指向上滑動可以切換應用程序網格和工作空間。

支持的應用程序也可以使用捏合縮放，包括雙指滾動。

這是一個非常需要的更新，以進一步提高你在 Endless OS 中的生產力。

應用程序中心、Flatpak 和應用程序 ​

Endless OS 作為一個不可變的發行版，你所有的應用程序都運行在一個獨立的用户空間。默認情況下，它只支持 Flatpak 軟件包。默認配置了世界上最大的 Flatpak 倉庫 Flathub。你可以直接從 AppCenter 搜索並安裝任何 Flatpak 應用程序。

然而，在默認情況下，幾乎所有需要的應用程序都已經預裝。如果你想處理文件，一個完整的 LibreOffice 包就在那裏。它還包括預裝了 Ad-Block 的 Chromium 網絡瀏覽器！此外，你還得到了 Gedit 文本編輯器、Shotwell 圖像查看器、Brasero 磁盤刻錄應用程序、文件Files應用作為文件管理器、管理你的學校/家庭工作流程的 Kolibri。

所有原生的 GNOME 應用程序現在都默認是 Flatpak 版本，而不是 APT 軟件包。這是 Endless OS 5.0 的關鍵變化之一。

幫助中心 ​

Endless OS 的偉大功能之一是可以從幫助應用程序中獲得離線幫助。你也可以通過桌面搜索功能訪問它。

任何學生或首次使用的用户都可以快速瞭解桌面的基本功能，如 “如何更改密碼” 或 “如何創建賬户” 之類的問題。所有這些都可以作為離線幫助文件使用。

總結 ​

Endless OS 5.0 帶來了非常需要的變化，如 Wayland 和手勢支持，同時堅持其原則，成為一個易於使用的大眾發行版。它是一個設計良好、考慮周到的發行版，非常適合離線/遠程使用、實驗室、學校和社區。如果配置正確，Linux 可以影響數百萬人 —— 對那些買不起昂貴軟件的人來説。

另外，對於普通用户來説，如果你打算運行多年，這可能是一個完美的發行版。你可以把自己從升級、系統故障、命令、依賴性問題等的麻煩中解救出來。
