Linux 系統是否適合於您？ ​

並非人人都適合使用 Linux --對許多用户來説，Windows 或 OSX 會是更好的選擇。

我喜歡使用 Linux 桌面系統，並不是因為軟件的政治性質，也不是不喜歡其它操作系統。我喜歡 Linux 系統因為它能滿足我的需求並且確實適合使用。

我的經驗是，並非人人都適合切換至“Linux 的生活方式”。本文將幫助您通過分析使用 Linux 系統的利弊來供您自行判斷使用 Linux 是否真正適合您。

什麼時候更換系統？ ​

當有充分的理由時，將系統切換到 Linux 系統是很有意義的。這對 Windows 用户將系統更換到 OSX 或類似的情況都同樣適用。為讓您的系統轉變成功，您必須首先確定為什麼要做這種轉換。

對某些人來説，更換系統通常意味着他們不滿於當前的系統操作平台。也許是最新的升級給了他們糟糕的用户體驗，而他們也已準備好更換到別的系統，也許僅僅是因為對某個系統好奇。不管動機是什麼，必須要有充分的理由支撐您做出更換操作系統的決定。如果沒有一個充足的原因讓您這樣做，往往不會成功。

然而事事都有例外。如果您確實對 Linux 桌面非常感興趣，或許可以選擇一種折衷的方式。

放慢起步的腳步 ​

第一次嘗試運行 Linux 系統後，我看到就有人開始批判 Windows 安裝過程的費時，完全是因為他們20分鐘就用閃存安裝好 Ubuntu 的良好體驗。但是夥伴們，這並不只是一次測驗。相反，我有如下建議：

  • 用一週的時間嘗試在虛擬機上運行 Linux 系統。這意味着您將在該系統上執行所有的瀏覽器工作、郵箱操作和其它想要完成的任務。
  • 如果運行虛擬機資源消耗太大，您可以嘗試用提供了一些持久存儲的 USB 驅動器來運行 Linux，您的主操作系統將不受任何影響。與此同時，您仍可以運行 Linux 系統。
  • 運行 Linux 系統一週後，如果一切進展順利，下一步您可以計算一下這周內登入 Windows 的次數。如果只是偶爾登錄 Windows 系統，下一步就可以嘗試運行 Windows 和 Linux 的雙系統。對那些只運行了 Linux 系統的用户，可以考慮嘗試將系統真正更換為 Linux 系統。
  • 在你完全刪除 Windows 分區前，更應該購買一個新硬盤來安裝 Linux 系統。這樣有了充足的硬盤空間，您就可以使用雙系統。如果必須要啓動 Windows 系統做些事情的話，Windows 系統也是可以運行的。

使用 Linux 系統的好處是什麼？ ​

將系統更換到 Linux 有什麼好處呢？一般而言，這種好處對大多數人來説可以歸結到釋放個性自由。在使用 Linux 系統的時候，如果您不喜歡某些設置，可以自行更改它們。同時使用 Linux 可以為用户節省大量的硬件升級開支和不必要的軟件開支。另外，您不需再費力找尋已丟失的軟件許可證密鑰，而且如果您不喜歡即將發佈的系統版本，大可輕鬆地更換到別的版本。

在 Linux 桌面方面可以選擇的桌面種類是驚人的多，看起來對新手來説做這種選擇非常困難。但是如果您發現了喜歡的一款 Linux 版本（Debian、Fedora、Arch等），最困難的工作其實已經完成了，您需要做的就是找到各版本的區別並選擇出您最喜歡的系統版本環境。

如今我聽到的最常見的抱怨之一是用户發現沒有太多的軟件能適用於 Linux 系統。然而，這並不是事實。儘管別的操作系統可能會提供更多軟件，但是如今的 Linux 也已經提供了足夠多應用程序滿足您的各種需求，包括視頻剪輯（家用和專業級）、攝影、辦公管理軟件、遠程訪問、音樂軟件、等等等等。

使用 Linux 系統您會失去些什麼？ ​

雖然我喜歡使用 Linux，但我妻子的家庭辦公依然依賴於 OS X。對於用 Linux 系統完成一些特定的任務她心滿意足，但是她需要 OS X 來運行一些不支持 Linux 的軟件。這是許多想要更換系統的用户會遇到的一個常見的問題。如果要更換系統，您需要考慮是否願意失去一些關鍵的軟件工具。

有時這個問題是因為軟件的數據只能用該軟件打開。別的情況下，是傳統應用程序的工作流和功能並不適用於在 Linux 系統上可運行的軟件。我自己並沒有遇到過這類問題，但是我知道確實存在這些問題。許多 Linux 上的軟件在其它操作系統上也都可以用。所以如果擔心這類軟件兼容問題，建議您先嚐試在已有的系統上操作一下幾款類似的應用程序。

更換成 Linux 系統後，另一件您可能會失去的是本地系統支持服務。人們通常會嘲笑這種愚蠢行徑，但我知道，無數的新手在使用 Linux 時會發現解決 Linux 上各種問題的唯一資源就是來自網絡另一端的陌生人提供的幫助。如果只是他們的 PC 遇到了一些問題，這將會比較麻煩。Windows 和 OS X 的用户已經習慣各城市遍佈了支持他們操作系統的各項技術服務。

如何開啓新旅程？ ​

這裏建議大家要記住最重要的就是總要有個回退方案。如果您將 Windows 10 從硬盤中擦除，您會發現重新安裝它又會花費金錢。對那些從其它 Windows 發佈版本升級的用户來説尤其會遇到這種情況。請接受這個建議，對新手來説使用閃存安裝 Linux 或使用 Windows 和 Linux 雙系統都是更值得提倡的做法。您也許會如魚得水般使用 Linux系統，但是有了一份回退方案，您將高枕無憂。

相反，如果數週以來您一直依賴於使用雙操作系統，但是已經準備好冒險去嘗試一下單操作系統，那麼就去做吧。格式化您的驅動器，重新安裝您喜愛的 Linux 發行版。數年來我一直都是“全職” Linux 使用愛好者，這裏可以確定地告訴您，使用 Linux 系統感覺棒極了。這種感覺會持續多久？我第一次的 Linux 系統使用經驗還是來自早期的 Red Hat 系統，最終在2003年，我在自己的筆記本上整個安裝了 Linux 系統。

Linux 愛好者們，你們什麼時候開始使用 Linux 的？您在最初更換成 Linux 系統時是興奮還是焦慮呢？歡迎點擊評論分享你們的經驗。
