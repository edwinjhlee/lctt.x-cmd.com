Linux 小技巧：Chrome 小遊戲，讓文字説話，計劃作業，重複執行命令 ​

重要的事情説兩遍，我完成了一個Linux提示與彩蛋系列，讓你的Linux獲得更多創造和娛樂。

Linux提示與彩蛋系列

本文，我將會講解Google-chrome內建小遊戲，在終端中如何讓文字説話，使用‘at’命令設置作業和使用watch命令重複執行命令。

1. Google Chrome 瀏覽器小遊戲彩蛋 ​

網線脱掉或者其他什麼原因連不上網時，Google Chrome就會出現一個小遊戲。聲明，我並不是遊戲玩家，因此我的電腦上並沒有安裝任何第三方的惡意遊戲。安全是第一位。

所以當Internet發生出錯，會出現一個這樣的界面：

不能連接到互聯網

按下空格鍵來激活Google-chrome彩蛋遊戲。遊戲沒有時間限制。並且還不需要浪費時間安裝使用。

不需要第三方軟件的支持。同樣支持Windows和Mac平台，但是我的平台是Linux，我也只談論Linux。當然在Linux，這個遊戲運行很好。遊戲簡單，但也很花費時間。

使用空格/向上方向鍵來跳躍。請看下列截圖：

Google Chrome中玩遊戲

2. Linux 終端中朗讀文字 ​

對於那些不能文字朗讀的設備，有個小工具可以實現文字説話的轉換器。用各種語言寫一些東西，espeak就可以朗讀給你。

系統應該默認安裝了Espeak，如果你的系統沒有安裝，你可以使用下列命令來安裝：

# apt-get install espeak   (Debian)
# yum install espeak       (CentOS)
# dnf install espeak       (Fedora 22 及其以後)

你可以讓espeak接受標準輸入的交互輸入並及時轉換成語音朗讀出來。如下：

$ espeak [按回車鍵]

更詳細的輸出你可以這樣做：

$ espeak --stdout | aplay [按回車鍵][再次回車]

espeak設置靈活，也可以朗讀文本文件。你可以這樣設置：

$ espeak --stdout /path/to/text/file/file_name.txt  | aplay [Hit Enter]

espeak可以設置朗讀速度。默認速度是160詞每分鐘。使用-s參數來設置。

設置每分鐘30詞的語速：

$ espeak -s 30 -f /path/to/text/file/file_name.txt | aplay

設置每分鐘200詞的語速：

$ espeak -s 200 -f /path/to/text/file/file_name.txt | aplay

説其他語言，比如北印度語（作者母語），這樣設置：

$ espeak -v hindi --stdout 'टेकमिंट विश्व की एक बेहतरीन लाइंक्स आधारित वेबसाइट है|' | aplay

你可以使用各種語言，讓espeak如上面説的以你選擇的語言朗讀。使用下列命令來獲得語言列表：

$ espeak --voices

3. 快速調度任務 ​

我們已經非常熟悉使用cron守護進程執行一個計劃命令。

Cron是一個Linux系統管理的高級命令，用於計劃定時任務如備份或者指定時間或間隔的任何事情。

但是，你是否知道at命令可以讓你在指定時間調度一個任務或者命令？at命令可以指定時間執行指定內容。

例如，你打算在早上11點2分執行uptime命令，你只需要這樣做：

$ at 11:02
uptime >> /home/$USER/uptime.txt 
Ctrl+D

Linux中計劃任務

檢查at命令是否成功設置，使用：

$ at -l

瀏覽計劃任務

at支持計劃多個命令，例如：

$ at 12:30
Command – 1
Command – 2
…
command – 50
…
Ctrl + D

4. 特定時間重複執行命令 ​

有時，我們可以需要在指定時間間隔執行特定命令。例如，每3秒，想打印一次時間。

查看現在時間，使用下列命令。

$ date +"%H:%M:%S

Linux中查看日期和時間

為了每三秒查看一下這個命令的輸出，我需要運行下列命令：

$ watch -n 3 'date +"%H:%M:%S"'

Linux中watch命令

watch命令的‘-n’開關設定時間間隔。在上述命令中，我們定義了時間間隔為3秒。你可以按你的需求定義。同樣watch 也支持其他命令或者腳本。
