4 個開源的命令列郵件客户端 ​

無論你承認與否，email並沒有消亡。對那些對命令列至死不渝的 Linux 高級用户而言，離開 shell 轉而使用傳統的桌面或網頁版郵件客户端並不適應。歸根結底，命令列最善於處理文件，特別是文本文件，能使效率倍增。

幸運的是，也有不少的命令列郵件客户端，而它們的用户大都樂於幫助你入門並回答你使用中遇到的問題。但別説我沒警告過你：一旦你完全掌握了其中一個客户端，你會發現很難回到基於圖形界面的客户端！

要安裝下述四個客户端中的任何一個是非常容易的；主要的 Linux 發行版的軟件倉庫中都提供此類軟件，並可通過包管理器進行安裝。你也可以在其它的操作系統中尋找並安裝這類客户端，但我並未嘗試過也沒有相關的經驗。

Mutt ​

  • 項目主頁
  • 源代碼
  • 授權協議: GPLv2

許多終端愛好者都聽説過甚至熟悉 Mutt 和 Alpine， 他們已經存在多年。讓我們先看看 Mutt。

Mutt 支持許多你所期望 email 系統支持的功能：會話，顏色區分，支持多語言，同時還有很多設置選項。它支持 POP3 和 IMAP 這兩個主要的郵件傳輸協議，以及許多郵箱格式。自從1995年誕生以來， Mutt 就擁有了一個活躍的開發社區，但最近幾年，新版本更多的關注於修復問題和安全更新而非提供新功能。這對大多數 Mutt 用户而言並無大礙，他們鍾愛這樣的界面，並支持此項目的口號：“所有郵件客户端都很爛，只是這個爛的沒那麼徹底。”

Alpine ​

  • 項目主頁
  • 源代碼
  • 授權協議: Apache 2.0

Alpine 是另一款知名的終端郵件客户端，它由華盛頓大學開發，設計初衷是作為一個開源的、支持 unicode 的 Pine （也來自華盛頓大學）的替代版本。

Alpine 不僅容易上手，還為高級用户提供了很多特性，它支持很多協議 —— IMAP, LDAP, NNTP, POP, SMTP 等，同時也支持不同的郵箱格式。Alpine 內置了一款名為 Pico 的可獨立使用的簡易文本編輯工具，但你也可以使用你常用的文本編輯器： vi, Emacs等。

儘管 Alpine 的升級並不頻繁，不過有個名為 re-alpine 的分支為不同的開發者提供了開發此項目的機會。

Alpine 支持在屏幕上顯示上下文幫助，但一些用户會喜歡 Mutt 式的獨立説明手冊，不過它們兩個的文檔都很完善。用户可以同時嘗試 Mutt 和 Alpine，並由個人喜好作出決定，也可以嘗試以下的幾個新選擇。

Sup ​

  • 項目主頁
  • 源代碼
  • 授權協議: GPLv2

Sup 是我們列表中能被稱為“大容量郵件客户端”的二者之一。自稱“為郵件較多的人設計的命令列客户端”，Sup 的目標是提供一個支持層次化設計並允許為會話添加標籤進行簡單整理的界面。

由於採用 Ruby 編寫，Sup 能提供十分快速的搜索並能自動管理聯繫人列表，同時還允許自定義插件。對於使用 Gmail 作為網頁郵件客户端的人們，這些功能都是耳熟能詳的，這就使得 Sup 成為一種比較現代的命令列郵件管理方式。

Notmuch ​

  • 項目主頁
  • 源代碼
  • 授權協議: GPLv3

"Sup? Notmuch." Notmuch 作為 Sup 的回應，最初只是重寫了 Sup 的一小部分來提高性能。最終，這個項目逐漸變大併成為了一個獨立的郵件客户端。

Notmuch 是一款相當精簡的軟件。它並不能獨立的收發郵件，啓用 Notmuch 的快速搜索功能的代碼實際上是設計成一個程序可以調用的獨立庫。但這樣的模組化設計也使得你能使用你最愛的工具進行寫信，發信和收信，集中精力做好一件事情並有效瀏覽和管理你的郵件。

這個列表並不完整，還有很多 email 客户端，它們或許才是你的最佳選擇。你喜歡什麼客户端呢？
