Debian GNU/Linux，22 年未完的美妙旅程 ​

在2015年8月16日， Debian項目組慶祝了 Debian 的22週年紀念日；這也是開源世界歷史最悠久、熱門的發行版之一。 Debian項目於1993年由Ian Murdock創立。彼時，Slackware 作為最早的 Linux 發行版已經名聲在外。

22歲生日快樂! Debian Linux!

Ian Ashly Murdock， 一個美國職業軟件工程師， 在他還是普渡大學的學生時構想出了 Debian 項目的計劃。他把這個項目命名為 Debian 是由於這個名字組合了他彼時女友的名字 Debra Lynn 和他自己的名字 Ian。 他之後和 Lynn 結婚並在2008年1月離婚。

Debian 創始人:Ian Murdock

Ian 目前是 ExactTarget 的平台與開發社區的副總裁。

Debian (如同Slackware一樣) 都是由於當時缺乏滿足合乎標準的發行版才應運而生的。 Ian 在一次採訪中説：“免費提供一流的產品會是 Debian 項目的唯一使命。 儘管過去的 Linux 發行版均不盡然可靠抑或是優秀。 我印象裏...比如在不同的文件系統間移動文件， 處理大型文件經常會導致內核出錯。 但是 Linux 其實是很可靠的， 自由的源代碼讓這個項目本質上很有前途。”

"我記得過去我像其他想解決問題的人一樣， 想在家裏運行一個像 UNIX 的東西。 但那是不可能的， 無論是經濟上還是法律上或是別的什麼角度。 然後我就聽聞了 GNU 內核開發項目， 以及這個項目是如何沒有任何法律紛爭"， Ian 補充到。 他早年在開發 Debian 時曾被自由軟件基金會(FSF)資助， 這份資助幫助 Debian 取得了長足的發展； 儘管一年後由於學業原因 Ian 退出了 FSF 轉而去完成他的學位。

Debian開發歷史 ​

  • Debian 0.01 – 0.09 : 發佈於 1993 年八月 – 1993 年十二月。
  • Debian 0.91 : 發佈於 1994 年一月。 有了原始的包管理系統， 沒有依賴管理機制。
  • Debian 0.93 rc5 : 發佈於 1995 年三月。 “現代”意義的 Debian 的第一次發佈， 在基礎系統安裝後會使用dpkg 安裝以及管理其他軟件包。
  • Debian 0.93 rc6: 發佈於 1995 年十一月。 最後一次 a.out 發佈， deselect 機制第一次出現， 有60位開發者在彼時維護着軟件包。
  • Debian 1.1: 發佈於 1996 年六月。 項目代號 – Buzz， 軟件包數量 – 474， 包管理器 dpkg， 內核版本 2.0， ELF 二進制。
  • Debian 1.2: 發佈於 1996 年十二月。 項目代號 – Rex， 軟件包數量 – 848， 開發者數量 – 120。
  • Debian 1.3: 發佈於 1997 年七月。 項目代號 – Bo， 軟件包數量 974， 開發者數量 – 200。
  • Debian 2.0: 發佈於 1998 年七月。 項目代號 - Hamm， 支持構架 – Intel i386 以及 Motorola 68000 系列， 軟件包數量: 1500+， 開發者數量: 400+， 內置了 glibc。
  • Debian 2.1: 發佈於1999 年三月九日。 項目代號 – slink， 支持構架 - Alpha 和 Sparc， apt 包管理器開始成型， 軟件包數量 – 2250。
  • Debian 2.2: 發佈於 2000 年八月十五日。 項目代號 – Potato， 支持構架 – Intel i386， Motorola 68000 系列， Alpha， SUN Sparc， PowerPC 以及 ARM 構架。 軟件包數量: 3900+ (二進制) 以及 2600+ (源代碼)， 開發者數量 – 450。 有一羣人在那時研究並發表了一篇論文， 論文展示了自由軟件是如何在被各種問題包圍的情況下依然逐步成長為優秀的現代操作系統的。
  • Debian 3.0: 發佈於 2002 年七月十九日。 項目代號 – woody， 支持構架新增 – HP， PA_RISC， IA-64， MIPS 以及 IBM， 首次以DVD的形式發佈， 軟件包數量 – 8500+， 開發者數量 – 900+， 支持加密。
  • Debian 3.1: 發佈於 2005 年六月六日。 項目代號 – sarge， 支持構架 – 新增 AMD64（非官方渠道發佈）， 內核 – 2.4 以及 2.6 系列， 軟件包數量: 15000+， 開發者數量 : 1500+， 增加了諸如 OpenOffice 套件， Firefox 瀏覽器， Thunderbird， Gnome 2.8， 支持: RAID， XFS， LVM， Modular Installer。
  • Debian 4.0: 發佈於 2007 年四月八日。 項目代號 – etch， 支持構架 – 如前，包括 AMD64。 軟件包數量: 18，200+ 開發者數量 : 1030+， 圖形化安裝器。
  • Debian 5.0: 發佈於 2009 年二月十四日。 項目代號 – lenny， 支持構架 – 新增 ARM。 軟件包數量: 23000+， 開發者數量: 1010+。
  • Debian 6.0: 發佈於 2009 年七月二十九日。 項目代號 – squeeze， 包含的軟件包: 內核 2.6.32， Gnome 2.3. Xorg 7.5， 同時包含了 DKMS， 基於依賴包支持。 支持構架 : 新增 kfreebsd-i386 以及 kfreebsd-amd64， 基於依賴管理的啓動過程。
  • Debian 7.0: 發佈於 2013 年五月四日。 項目代號: wheezy， 支持 Multiarch， 私有云工具， 升級了安裝器， 移除了第三方軟件依賴， 全功能多媒體套件-codec， 內核版本 3.2， Xen Hypervisor 4.1.4 ，軟件包數量: 37400+。
  • Debian 8.0: 發佈於 2015 年五月二十五日。 項目代號: Jessie， 將 Systemd 作為默認的初始化系統， 內核版本 3.16， 增加了快速啓動(fast booting)， service進程所依賴的 cgroups 使隔離部分 service 進程成為可能， 43000+ 軟件包。 Sysvinit 初始化工具在 Jessie 中可用。

注意: Linux的內核第一次是在1991 年十月五日被髮布， 而 Debian 的首次發佈則在1993 年九月十三日。 所以 Debian 已經在只有24歲的 Linux 內核上運行了整整22年了。

Debian 的那些事 ​

1994年管理和重整了 Debian 項目以使得其他開發者能更好地加入，所以在那一年並沒有發佈面向用户的更新， 當然， 內部版本肯定是有的。

Debian 1.0 從來就沒有被髮布過。 一家 CD-ROM 的生產商錯誤地把某個未發佈的版本標註為了 1.0， 為了避免產生混亂， 原本的 Debian 1.0 以1.1的面貌發佈了。 從那以後才有了所謂的官方CD-ROM的概念。

每個 Debian 新版本的代號都是玩具總動員裏某個角色的名字哦。

Debian 有四種可用版本: 舊穩定版(old stable)， 穩定版(stable)， 測試版(testing) 以及 試驗版(experimental)。 始終如此。

Debian 項目組一直工作在不穩定發行版上， 這個不穩定版本始終被叫做Sid(玩具總動員裏那個邪惡的臭小孩)。 Sid是unstable版本的永久名稱， 同時Sid也取自'Still In Development"(譯者:還在開發中)的首字母。 Sid 將會成為下一個穩定版， 當前的穩定版本代號為 jessie。

Debian 的官方發行版只包含開源並且自由的軟件， 絕無其他東西. 不過 contrib 和非自由軟件包使得安裝那些本身自由但是其依賴的軟件包不自由(contrib)的軟件和非自由軟件成為了可能。

Debian 是一堆Linux 發行版之母。 舉幾個例子:

  • Damn Small Linux
  • KNOPPIX
  • Linux Advanced
  • MEPIS
  • Ubuntu
  • 64studio (不再活躍開發)
  • LMDE

Debian 是世界上最大的非商業 Linux 發行版。它主要是由C編寫的(32.1%)， 一併的還有其他70多種語言。

Debian 開發語言貢獻表，圖片來源: Xmodulo

Debian 項目包含6，850萬行代碼， 以及 450萬行空格和註釋。

國際空間站放棄了 Windows 和紅帽子， 進而換成了 Debian - 在上面的宇航員使用落後一個版本的穩定發行版， 目前是 squeeze; 這麼做是為了穩定程度以及來自 Debian 社區的雄厚幫助支持。

黑色星期三 ​

2002 年十一月二十日， Twente 大學的網絡運營中心(NOC)着火。 當地消防部門放棄了服務器區域。 NOC維護着satie.debian.org 的網站服務器， 這個網站包含了安全、非美國相關的存檔、新維護者資料、數量報告、資料庫等等；這一切都化為了灰燼。 之後這些服務由 Debian 重建了。

未來版本 ​

下一個待發布版本是 Debian 9， 項目代號 – Stretch， 它會帶來什麼還是個未知數。 滿心期待吧!

有很多發行版在 Linux 發行版的歷史上出現過一瞬間然後很快消失了。 在多數情況下， 維護一個日漸龐大的項目是開發者們面臨的挑戰。 但這對 Debian 來説不是問題。 Debian 項目有全世界成百上千的開發者、維護者。 它在 Linux 誕生的之初起便一直存在。

Debian 在 Linux 生態環境中的貢獻是難以用語言描述的。 如果 Debian 沒有出現過， 那麼 Linux 世界將不會像現在這樣豐富和用户友好。 Debian 是為數不多可以被認為安全可靠又穩定的發行版，是作為網絡服務器完美選擇。

這僅僅是 Debian 的一個開始。 它走過了這麼長的征程， 並將一直走下去。 未來即是現在！ 世界近在眼前！ 如果你到現在還從來沒有使用過 Debian， 我只想問， 你還再等什麼? 快去下載一份鏡像試試吧， 我們會在此守候遇到任何問題的你。
