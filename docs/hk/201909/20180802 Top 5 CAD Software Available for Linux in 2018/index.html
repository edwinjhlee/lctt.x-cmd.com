Linux 上 5 個最好 CAD 軟件 ​

計算機輔助設計 (CAD) 是很多工程流程的必不可少的部分。CAD 用於建築、汽車零部件設計、航天飛機研究、航空、橋樑施工、室內設計，甚至服裝和珠寶設計等專業領域。

在 Linux 上並不原生支持一些專業級 CAD 軟件，如 SolidWorks 和 Autodesk AutoCAD。因此，今天，我們將看看排名靠前的 Linux 上可用的 CAD 軟件。預知詳情，請看下文。

Linux 可用的最好的 CAD 軟件 ​

在我們查看這份 Linux 的 CAD 軟件列表前，你應該記住一件事，在這裏不是所有的應用程序都是開源軟件。我們也將包含一些非自由和開源軟件的 CAD 軟件來幫助普通的 Linux 用户。

我們為基於 Ubuntu 的 Linux 發行版提供了安裝操作指南。對於其它發行版，你可以檢查相應的網站來了解安裝程序步驟。

該列表沒有任何特殊順序。在第一順位的 CAD 應用程序不能認為比在第三順位的好，以此類推。

1、FreeCAD ​

對於 3D 建模，FreeCAD 是一個極好的選擇，它是自由 (免費和自由) 和開源軟件。FreeCAD 堅持以構建機械工程和產品設計為目標。FreeCAD 是多平台的，可用於 Windows、Mac OS X+ 以及 Linux。

儘管 FreeCAD 已經是很多 Linux 用户的選擇，應該注意到，FreeCAD 仍然是 0.17 版本，因此，不適用於重要的部署。但是最近開發加速了。

  • FreeCAD

FreeCAD 並不專注於 direct-2D 繪圖和真實形狀的動畫，但是它對機械工程相關的設計極好。FreeCAD 的 0.15 版本在 Ubuntu 存儲庫中可用。你可以通過運行下面的命令安裝。

sudo apt install freecad

為獲取新的每日構建（目前 0.17），打開一個終端（ctrl+alt+t），並逐個運行下面的命令。

sudo add-apt-repository ppa:freecad-maintainers/freecad-daily
sudo apt update
sudo apt install freecad-daily

2、LibreCAD ​

LibreCAD 是一個自由開源的、2D CAD 解決方案。一般來説，CAD 是一個資源密集型任務，如果你有一個相當普通的硬件，那麼我建議你使用 LibreCAD ，因為它在資源使用方面真的輕量化。LibreCAD 是幾何圖形結構方面的一個極好的候選者。

作為一個 2D 工具，LibreCAD 是好的，但是它不能在 3D 模型和渲染上工作。它有時可能不穩定，但是，它有一個可靠的自動保存，它不會讓你的工作浪費。

  • LibreCAD

你可以通過運行下面的命令安裝 LibreCAD。

sudo apt install librecad

3、OpenSCAD ​

OpenSCAD 是一個自由的 3D CAD 軟件。OpenSCAD 非常輕量和靈活。OpenSCAD 不是交互式的。你需要‘編程’模型，OpenSCAD 來解釋這些代碼來渲染一個可視化模型。在某種意義上説，它是一個編譯器。你不能直接繪製模型，而是描述模型。

OpenSCAD 是這個列表上最複雜的工具，但是，一旦你瞭解它，它將提供一個令人愉快的工作經歷。

  • OpenSCAD

你可以使用下面的命令來安裝 OpenSCAD。

sudo apt-get install openscad

4、BRL-CAD ​

BRL-CAD 是最老的 CAD 工具之一。它也深受 Linux/UNIX 用户喜愛，因為它與模組化和自由的 *nix 哲學相一致。

BRL-CAD 始於 1979 年，並且，它仍然在積極開發。現在，BRL-CAD 不是 AutoCAD，但是對於像熱穿透和彈道穿透等等的運輸研究仍然是一個極好的選擇。BRL-CAD 構成 CSG 的基礎，而不是邊界表示。在選擇 BRL-CAD 時，你可能需要記住這一點。你可以從它的官方網站下載 BRL-CAD 。

  • BRL-CAD

5、DraftSight (非開源) ​

如果你習慣在 AutoCAD 上作業。那麼，DraftSight 將是完美的替代。

DraftSight 是一個在 Linux 上可用的極好的 CAD 工具。它有相當類似於 AutoCAD 的工作流，這使得遷移更容易。它甚至提供一種類似的外觀和感覺。DrafSight 也兼容 AutoCAD 的 .dwg 文件格式。 但是，DrafSight 是一個 2D CAD 軟件。截至當前，它不支持 3D CAD 。

儘管 DrafSight 是一款起價 149 美元的商業軟件。在 DraftSight 網站上可獲得一個免費版本。你可以下載 .deb 軟件包，並在基於 Ubuntu 的發行版上安裝它。為了開始使用 DraftSight ，你需要使用你的電子郵件 ID 來註冊你的免費版本。

  • DraftSight

榮譽提名 ​

  • 隨着雲計算技術的巨大發展，像 OnShape 的雲 CAD 解決方案已經變得日漸流行。
  • SolveSpace 是另一個值得一提的開源軟件項目。它支持 3D 模型。
  • 西門子 NX 是一個在 Windows、Mac OS 及 Linux 上可用的工業級 CAD 解決方案，但是它貴得離譜，所以，在這個列表中被忽略。
  • 接下來，你有 LeoCAD，它是一個 CAD 軟件，在軟件中你使用樂高積木來構建東西。你使用這些信息做些什麼取決於你。

我對 Linux 上的 CAD 的看法 ​

儘管在 Linux 上游戲變得流行，我總是告訴我的鐵桿遊戲朋友堅持使用 Windows。類似地，如果你是一名在你是課程中使用 CAD 的工科學生，我建議你使用學校規定的軟件 (AutoCAD、SolidEdge、Catia)，這些軟件通常只在 Windows 上運行。

對於高級專業人士來説，當我們討論行業標準時，這些工具根本達不到標準。

對於想在 WINE 中運行 AutoCAD 的那些人來説，儘管一些較舊版本的 AutoCAD 可以安裝在 WINE 上，它們根本不執行工作，小故障和崩潰嚴重損害這些體驗。

話雖如此，我高度尊重上述列表中軟件的開發者的工作。他們豐富了 FOSS 世界。很高興看到像 FreeCAD 一樣的軟件在近些年中加速開發速度。
