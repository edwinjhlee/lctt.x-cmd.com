2019 年最好的 Linux 發行版 ​

哪個是最好的 Linux 發行版呢？這個問題是沒有明確的答案的。這就是為什麼我們按各種分類彙編了這個最佳 Linux 列表的原因。

有許多 Linux 發行版，我甚至想不出一個確切的數量，因為你會發現很多不同的 Linux 發行版。

其中有些只是另外一個的複製品，而有些往往是獨一無二的。這雖然有點混亂——但這也是 Linux 的優點。

不用擔心，儘管有成千上萬的發行版，在這篇文章中，我已經列出了目前最好的 Linux 發行版。當然，這個列表是主觀的。但是，在這裏，我們試圖對發行版進行分類——每個發行版本都有自己的特點的。

  • 面向初學者的 Linux 用户的最佳發行版
  • 最佳 Linux 服務器發行版
  • 可以在舊計算機上運行的最佳 Linux 發行版
  • 面向高級 Linux 用户的最佳發行版
  • 最佳常青樹 Linux 發行版

注： 該列表沒有特定的排名順序。

面向初學者的最佳 Linux 發行版 ​

在這個分類中，我們的目標是列出開箱即用的易用發行版。你不需要深度學習，你可以在安裝後馬上開始使用，不需要知道任何命令或技巧。

Ubuntu ​

Ubuntu 無疑是最流行的 Linux 發行版之一。你甚至可以發現它已經預裝在很多筆記本電腦上了。

用户界面很容易適應。如果你願意，你可以根據自己的要求輕鬆定製它的外觀。無論哪種情況，你都可以選擇安裝一個主題。你可以從瞭解更多關於如何在 Ubuntu 安裝主題的的信息來起步。

除了它本身提供的功能外，你會發現一個巨大的 Ubuntu 用户在線社區。因此，如果你有問題——可以去任何論壇（或版塊）尋求幫助。如果你想直接尋找解決方案，你應該看看我們對 Ubuntu 的報道（我們有很多關於 Ubuntu 的教程和建議）。

  • Ubuntu

Linux Mint ​

Linux Mint Cinnamon 是另一個受初學者歡迎的 Linux 發行版。默認的 Cinnamon 桌面類似於 Windows XP，這就是為什麼當 Windows XP 停止維護時許多用户選擇它的原因。

Linux Mint 基於 Ubuntu，因此它具有適用於 Ubuntu 的所有應用程序。簡單易用是它成為 Linux 新用户首選的原因。

  • Linux Mint

elementary OS ​

elementary OS 是我用過的最漂亮的 Linux 發行版之一。用户界面類似於蘋果操作系統——所以如果你已經使用了蘋果系統，則很容易適應。

該發行版基於 Ubuntu，致力於提供一個用户友好的 Linux 環境，該環境在考慮性能的同時儘可能美觀。如果你選擇安裝 elementary OS，這份在安裝 elementary OS 後要做的 11 件事的清單會派上用場。

  • elementary OS

MX Linux ​

大約一年前，MX Linux 成為眾人矚目的焦點。現在（在發表這篇文章的時候），它是 DistroWatch.com 上最受歡迎的 Linux 發行版。如果你還沒有使用過它，那麼當你開始使用它時，你會感到驚訝。

與 Ubuntu 不同，MX Linux 是一個基於 Debian 的日益流行的發行版，採用 Xfce 作為其桌面環境。除了無與倫比的穩定性之外，它還配備了許多圖形用户界面工具，這使得任何習慣了 Windows/Mac 的用户易於使用它。

此外，軟件包管理器還專門針對一鍵安裝進行了量身定製。你甚至可以搜索 Flatpak 軟件包並立即安裝它（默認情況下，Flathub 在軟件包管理器中是可用的來源之一）。

  • MX Linux

Zorin OS ​

Zorin OS 是又一個基於 Ubuntu 的發行版，它又是桌面上最漂亮、最直觀的操作系統之一。尤其是在Zorin OS 15 發佈之後——我絕對會向沒有任何 Linux 經驗的用户推薦它。它也引入了許多基於圖形用户界面的應用程序。

你也可以將其安裝在舊電腦上，但是，請確保選擇“Lite”版本。此外，你還有“Core”、“Education”和 “Ultimate”版本可以選擇。你可以選擇免費安裝 Core 版，但是如果你想支持開發人員並幫助改進 Zorin，請考慮獲得 Ultimate 版。

Zorin OS 是由兩名愛爾蘭的青少年創建的。你可以在這裏閲讀他們的故事。

  • Zorin OS

Pop!_OS ​

Sytem76 的 Pop!_OS 是開發人員或計算機科學專業人員的理想選擇。當然，不僅限於編碼人員，如果你剛開始使用 Linux，這也是一個很好的選擇。它基於 Ubuntu，但是其 UI 感覺更加直觀和流暢。除了 UI 外，它還強制執行全盤加密。

你可以通過文章下面的評論看到，我們的許多讀者似乎都喜歡（並堅持使用）它。如果你對此感到好奇，也應該查看一下我們關於 Phillip Prado 的 Pop!_OS 的動手實踐的文章。

（LCTT 譯註：這段推薦是原文後來補充的，因為原文下面很多人在評論推薦。）

  • Pop!_OS

其他選擇 ​

深度操作系統 和其他的 Ubuntu 變種（如 Kubuntu、Xubuntu）也是初學者的首選。如果你想尋求更多的選擇，你可以看看。（LCTT 譯註：我知道你們肯定對將深度操作系統列入其它不滿意——這個鍋歸原作者。）

如果你想要挑戰自己，你可以試試 Ubuntu 之外的 Fedora —— 但是一定要看看我們關於 Ubuntu 和 Fedora 對比的文章，從桌面的角度做出更好的選擇。

最好的服務器發行版 ​

對於服務器來説，選擇 Linux 發行版取決於穩定性、性能和企業級支持。如果你只是嘗試，則可以嘗試任何你想要的發行版。

但是，如果你要為 Web 服務器或任何重要的組件安裝它，你應該看看我們的一些建議。

Ubuntu 服務器 ​

根據你的需要，Ubuntu 為你的服務器提供了不同的選項。如果你正在尋找運行在 AWS、Azure、谷歌雲平台等平台上的優化解決方案，Ubuntu Cloud 是一個很好的選擇。

無論是哪種情況，你都可以選擇 Ubuntu 服務器包，並將其安裝在你的服務器上。然而，Ubuntu 在雲上部署時也是最受歡迎的 Linux 發行版（根據數字判斷——來源1、來源2）。

請注意，除非你有特殊要求，我們建議你選擇 LTS 版。

  • Ubuntu Server

紅帽企業版 Linux（RHEL） ​

紅帽企業版 Linux（RHEL）是面向企業和組織的頂級 Linux 平台。如果我們按數字來看，紅帽可能不是服務器領域最受歡迎的。但是，有相當一部分企業用户依賴於 RHEL (比如聯想)。

從技術上講，Fedora 和紅帽企業版是相關聯的。無論紅帽要支持什麼——在出現在 RHEL 之前，都要在 Fedora 上進行測試。我不是定製需求的服務器發行版專家，所以你一定要查看他們的官方文檔以瞭解它是否適合你。

  • RHEL

SUSE Linux 企業服務器（SLES） ​

別擔心，不要把這和 OpenSUSE 混淆。一切都以一個共同的品牌 “SUSE” 命名 —— 但是 OpenSUSE 是一個開源發行版，目標是社區，並且由社區維護。

SUSE Linux 企業服務器（SLES）是基於雲的服務器最受歡迎的解決方案之一。為了獲得管理開源解決方案的優先支持和幫助，你必須選擇訂閲。

  • SLES

CentOS ​

正如我提到的，對於 RHEL 你需要訂閲。而 CentOS 更像是 RHEL 的社區版，因為它是從 RHEL 的源代碼中派生出來的。而且，它是開源的，也是免費的。儘管與過去幾年相比，使用 CentOS 的託管提供商數量明顯減少，但這仍然是一個很好的選擇。

CentOS 可能沒有加載最新的軟件包，但它被認為是最穩定的發行版之一，你可以在各種雲平台上找到 CentOS 鏡像。如果沒有，你可以選擇 CentOS 提供的自託管鏡像。

  • CentOS

其他選擇 ​

你也可以嘗試 Fedora Server或Debian作為上述發行版的替代品。

舊電腦的最佳 Linux 發行版 ​

如果你有一台舊電腦，或者你真的不需要升級你的系統，你仍然可以嘗試一些最好的 Linux 發行版。

我們已經詳細討論了一些最好的輕量級 Linux 發行版。在這裏，我們將只提到那些真正突出的東西（以及一些新的補充）。

Puppy Linux ​

Puppy Linux 實際上是最小的發行版本之一。剛開始使用 Linux 時，我的朋友建議我嘗試一下 Puppy Linux，因為它可以輕鬆地在較舊的硬件配置上運行。

如果你想在你的舊電腦上享受一次爽快的體驗，那就值得去看看。多年來，隨着一些新的有用特性的增加，用户體驗得到了改善。

  • Puppy Linux

Solus Budgie ​

在最近的一個主要版本——Solus 4 Fortitude 之後，它是一個令人印象深刻的輕量級桌面操作系統。你可以選擇像 GNOME 或 MATE 這樣的桌面環境。然而，Solus Budgie 恰好是我的最愛之一，它是一款適合初學者的功能齊全的 Linux發行版，同時對系統資源要求很少。

  • Solus

Bodhi ​

Bodhi Linux 構建於 Ubuntu 之上。然而，與Ubuntu不同，它在較舊的配置上運行良好。

這個發行版的主要亮點是它的 Moksha 桌面（這是 Enlightenment 17 桌面的延續）。用户體驗直觀且反應極快。即使我個人不用它，你也應該在你的舊系統上試一試。

  • Bodhi Linux

antiX ​

antiX 部分擔起了 MX Linux 的責任，它是一個輕量級的 Linux 發行版，為新的或舊的計算機量身定製。其用户界面並不令人印象深刻——但它可以像預期的那樣工作。

它基於 Debian，可以作為一個現場版 CD 發行版使用，而不需要安裝它。antiX 還提供現場版引導加載程序。與其他發行版相比，你可以保存設置，這樣就不會在每次重新啓動時丟失設置。不僅如此，你還可以通過其“持久保留”功能將更改保存到根目錄中。

因此，如果你正在尋找一個可以在舊硬件上提供快速用户體驗的現場版 USB 發行版，antiX 是一個不錯的選擇。

  • antiX

Sparky Linux ​

Sparky Linux 基於 Debian，它是理想的低端系統 Linux 發行版。伴隨着超快的用户體驗，Sparky Linux 為不同的用户提供了幾個特殊版本（或變種）。

例如，它提供了針對一組用户的穩定版本（和變種）和滾動版本。Sparky Linux GameOver 版非常受遊戲玩家歡迎，因為它包含了一堆預裝的遊戲。你可以查看我們的最佳 Linux 遊戲發行版 —— 如果你也想在你的系統上玩遊戲。

其他選擇 ​

你也可以嘗試 Linux Lite、Lubuntu、Peppermint 等輕量級 Linux 發行版。

面向高級用户的最佳 Linux 發行版 ​

一旦你習慣了各種軟件包管理器和命令來幫助你解決任何問題，你就可以開始找尋只為高級用户量身定製的 Linux 發行版。

當然，如果你是專業人士，你會有一套具體的要求。然而，如果你已經作為普通用户使用了一段時間——以下發行版值得一試。

Arch Linux ​

Arch Linux 本身是一個簡單而強大的發行版，具有陡峭的學習曲線。不像其系統，你不會一次就把所有東西都預先安裝好。你必須配置系統並根據需要添加軟件包。

此外，在安裝 Arch Linux 時，必須按照一組命令來進行（沒有圖形用户界面）。要了解更多信息，你可以按照我們關於如何安裝 Arch Linux 的指南進行操作。如果你要安裝它，你還應該知道在安裝 Arch Linux 後需要做的一些基本事情。這會幫助你快速入門。

除了多才多藝和簡便性之外，值得一提的是 Arch Linux 背後的社區非常活躍。所以，如果你遇到問題，你不用擔心。

  • Arch Linux

Gentoo ​

如果你知道如何編譯源代碼，Gentoo Linux 是你必須嘗試的版本。這也是一個輕量級的發行版，但是，你需要具備必要的技術知識才能使它發揮作用。

當然，官方手冊提供了許多你需要知道的信息。但是，如果你不確定自己在做什麼——你需要花很多時間去想如何充分利用它。

  • Gentoo Linux

Slackware ​

Slackware 是仍然重要的最古老的 Linux 發行版之一。如果你願意編譯或開發軟件來為自己建立一個完美的環境 —— Slackware 是一個不錯的選擇。

如果你對一些最古老的 Linux 發行版感到好奇，我們有一篇關於最早的 Linux 發行版可以去看看。

儘管使用它的用户/開發人員的數量已經顯著減少，但對於高級用户來説，它仍然是一個極好的選擇。此外，最近有個新聞是 Slackware 有了一個 Patreon 捐贈頁面，我們希望 Slackware 繼續作為最好的 Linux 發行版之一存在。

  • Slackware

最佳多用途 Linux 發行版 ​

有些 Linux 發行版既可以作為初學者友好的桌面又可以作為高級操作系統的服務器。因此，我們考慮為這樣的發行版編輯一個單獨的部分。

如果你不同意我們的觀點（或者有建議要補充），請在評論中告訴我們。我們認為，這對於每個用户都可以派上用場：

Fedora ​

Fedora 提供兩個獨立的版本：一個用於台式機/筆記本電腦（Fedora 工作站），另一個用於服務器（Fedora 服務器)。

因此，如果你正在尋找一款時髦的桌面操作系統，有點學習曲線，又對用户友好，那麼 Fedora 是一個選擇。無論是哪種情況，如果你正在為你的服務器尋找一個 Linux 操作系統，這也是一個不錯的選擇。

  • Fedora

Manjaro ​

Manjaro 基於 Arch Linux。不用擔心，雖然 Arch Linux 是為高級用户量身定製的，但Manjaro 讓新手更容易上手。這是一個簡單且對初學者友好的 Linux 發行版。用户界面足夠好，並且內置了一系列有用的圖形用户界面應用程序。

下載時，你可以為 Manjaro 選擇桌面環境。就個人而言，我喜歡 Manjaro 的 KDE 桌面。

  • Manjaro Linux

Debian ​

嗯，Ubuntu 是基於 Debian 的——所以它本身是一個非常好的發行版本。Debian 是台式機和服務器的理想選擇。

這可能不是對初學者最友好的操作系統——但你可以通過閲讀官方文檔輕鬆開始。Debian 10 Buster 的最新版本引入了許多變化和必要的改進。所以，你必須試一試！

總結 ​

總的來説，這些是我們推薦你去嘗試的最好的 Linux 發行版。是的，還有許多其他的 Linux 發行版值得一提，但是根據個人喜好，對每個發行版來説，取決於個人喜好，這種選擇是主觀的。

但是，我們也為 Windows 用户、黑客和脆弱性測試人員、遊戲玩家、程序員和偏重隱私者提供了單獨的發行版列表所以，如果你感興趣的話請仔細閲讀。

如果你認為我們遺漏了你最喜歡的 Linux 發行版，請在下面的評論中告訴我們你的想法，我們將更新這篇文章。
