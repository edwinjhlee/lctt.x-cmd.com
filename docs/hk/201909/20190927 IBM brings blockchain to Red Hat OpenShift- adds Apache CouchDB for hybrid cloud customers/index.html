IBM 將區塊鏈引入紅帽 OpenShift；為混合雲客户添加了Apache CouchDB ​

IBM 在其區塊鏈平台上增加了紅帽 OpenShift 支持，並將用於 Apache CouchDB 的 Kubernetes Operator 引入其混合雲服務中。

IBM 本週繼續推進其紅帽和開源集成工作，在其區塊鏈平台上添加了紅帽 OpenShift 支持，並在其混合雲服務產品之外為 Apache CouchDB 引入了 Kubernetes Operator。

在該公司的旗艦級企業 Kubernetes 平台 紅帽 OpenShift 上部署 IBM 區塊鏈 的能力，意味着 IBM 區塊鏈的開發人員將能夠在本地、公共雲或混合雲架構中部署安全軟件。

區塊鏈是一個分佈式資料庫，維護着一個不斷增長的記錄列表，可以使用哈希技術對其進行驗證，並且 IBM 區塊鏈平台包括用於構建、操作、治理和發展受保護的區塊鏈網絡的工具。

IBM 表示，其區塊鏈 / OpenShift 組合的目標客户面對的公司客户是：希望保留區塊鏈分類帳副本並在自己的基礎設施上運行工作負載以實現安全性，降低風險或合規性；需要將數據存儲在特定位置以滿足數據駐留要求；需要在多個雲或混合雲架構中部署區塊鏈組件。

自 7 月份完成對紅帽的收購以來，IBM 一直在圍繞紅帽基於 Kubernetes 的 OpenShift 容器平台構建雲開發生態系統。最近，這位藍色巨人將其新 z15 大型機與 IBM 的紅帽技術融合在一起，稱它將為紅帽 OpenShift 容器平台提供 IBM z/OS 雲代理。該產品將通過連接到 Kubernetes 容器為用户提供 z/OS 計算資源的直接自助訪問。

IBM 表示，打算在 IBM z 系列和 LinuxONE 產品上向 Linux 提供 IBM Cloud Pak 產品。Cloud Paks 是由 OpenShift 與 100 多種其他 IBM 軟件產品組成的捆綁包。LinuxONE 是 IBM 專為支持 Linux 環境而設計的非常成功的大型機系統。

IBM 表示，願景是使支持 OpenShift 的 IBM 軟件成為客户用來轉變其組織的基礎構建組件。

IBM 表示：“我們的大多數客户都需要支持混合雲工作負載以及可在任何地方運行這些工作負載的靈活性的解決方案，而用於紅帽的 z/OS 雲代理將成為我們在平台上啓用雲原生的關鍵。”

在相關新聞中，IBM 宣佈支持開源 Apache CouchDB，這是 Apache CouchDB 的 Kubernetes Operator，並且該 Operator 已通過認證可與紅帽 OpenShift 一起使用。Operator 可以自動部署、管理和維護 Apache CouchDB 部署。Apache CouchDB 是非關係型開源 NoSQL 資料庫。

在最近的 Forrester Wave 報告中，研究人員説：“企業喜歡 NoSQL 這樣的能力，可以使用低成本服務器和可以存儲、處理和訪問任何類型的業務數據的靈活的無模式模型進行橫向擴展。NoSQL 平台為企業基礎設施專業人士提供了對數據存儲和處理的更好控制，並提供了可加速應用程序部署的配置。當許多組織使用 NoSQL 來補充其關係資料庫時，一些組織已開始替換它們以支持更好的性能、擴展規模並降低其資料庫成本。”

當前，IBM 雲使用 Cloudant Db 服務作為其針對新的雲原生應用程序的標準資料庫。IBM 表示，對 CouchDB 的強大支持為用户提供了替代方案和後備選項。IBM 表示，能夠將它們全部綁定到紅帽 OpenShift Kubernetes 部署中，可以使客户在部署應用程序並在多個雲環境中移動數據時使用資料庫本地複製功能來維持對數據的低延遲訪問。

“我們的客户正在轉向基於容器化和微服務的架構，以提高速度、敏捷性和運營能力。在雲原生應用程序開發中，應用程序需要具有支持可伸縮性、可移植性和彈性的數據層。”IBM 院士兼雲資料庫副總裁 Adam Kocoloski 寫道，“我們相信數據可移植性和 CouchDB 可以大大改善多雲架構的功能，使客户能夠構建真正可在私有云、公共雲和邊緣位置之間移植的解決方案。”
