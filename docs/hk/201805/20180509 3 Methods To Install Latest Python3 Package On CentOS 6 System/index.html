在 CentOS 6 系統上安裝最新版 Python3 軟件包的 3 種方法 ​

CentOS 克隆自 RHEL，無需付費即可使用。CentOS 是一個企業級標準的、前沿的操作系統，被超過 90% 的網絡主機託管商採用，因為它提供了技術領先的服務器控制面板 cPanel/WHM。

該控制面板使得用户無需進入命令列即可通過其管理一切。

眾所周知，RHEL 提供長期支持，出於穩定性考慮，不提供最新版本的軟件包。

如果你想安裝的最新版本軟件包不在默認源中，你需要手動編譯源碼安裝。但手動編譯安裝的方式有不小的風險，即如果出現新版本，無法升級手動安裝的軟件包；你不得不重新手動安裝。

那麼在這種情況下，安裝最新版軟件包的推薦方法和方案是什麼呢？是的，可以通過為系統添加所需的第三方源來達到目的。

可供企業級 Linux 使用的第三方源有很多，但只有幾個是 CentOS 社區推薦使用的，它們在很大程度上不修改基礎軟件包。

這幾個推薦的源維護的很好，為 CentOS 提供大量補充軟件包。

在本教程中，我們將向你展示，如何在 CentOS 6 操作系統上安裝最新版本的 Python 3 軟件包。

方法 1：使用 Software Collections 源 （SCL） ​

SCL 源目前由 CentOS SIG 維護，除了重新編譯構建 Red Hat 的 Software Collections 外，還額外提供一些它們自己的軟件包。

該源中包含不少程序的更高版本，可以在不改變原有舊版本程序包的情況下安裝，使用時需要通過 scl 命令調用。

運行如下命令可以在 CentOS 上安裝 SCL 源：

# yum install centos-release-scl

檢查可用的 Python 3 版本：

# yum info rh-python35

運行如下命令從 scl 源安裝可用的最新版 python 3：

# yum install rh-python35

運行如下特殊的 scl 命令，在當前 shell 中啓用安裝的軟件包：

# scl enable rh-python35 bash

運行如下命令檢查安裝的 python3 版本：

# python --version
Python 3.5.1

運行如下命令獲取系統已安裝的 SCL 軟件包列表：

# scl -l
rh-python35

方法 2：使用 EPEL 源 (Extra Packages for Enterprise Linux） ​

EPEL 是 Extra Packages for Enterprise Linux 的縮寫，該源由 Fedora SIG （Special Interest Group）維護。

該 SIG 為企業級 Linux 創建、維護並管理了一系列高品質補充軟件包，受益的企業級 Linux 發行版包括但不限於紅帽企業級 Linux （RHEL）、 CentOS、 Scientific Linux （SL） 和 Oracle Linux （OL）等。

EPEL 通常基於 Fedora 對應代碼提供軟件包，不會與企業級 Linux 發行版中的基礎軟件包衝突或替換其中的軟件包。

推薦閲讀： 在 RHEL, CentOS, Oracle Linux 或 Scientific Linux 上安裝啓用 EPEL 源

EPEL 軟件包位於 CentOS 的 Extra 源中，已經默認啓用，故我們只需運行如下命令即可：

# yum install epel-release

檢查可用的 python 3 版本：

方法 3：使用 IUS 社區源 ​

IUS 社區是 CentOS 社區批准的第三方 RPM 源，為企業級 Linux （RHEL 和 CentOS） 5、 6 和 7 版本提供最新上游版本的 PHP、 Python、 MySQL 等軟件包。

IUS 社區源依賴於 EPEL 源，故我們需要先安裝 EPEL 源，然後再安裝 IUS 社區源。按照下面的步驟安裝啓用 EPEL 源和 IUS 社區源，利用該 RPM 系統安裝軟件包。

推薦閲讀： 在 RHEL 或 CentOS 上安裝啓用 IUS 社區源

EPEL 軟件包位於 CentOS 的 Extra 源中，已經默認啓用，故我們只需運行如下命令即可：

# yum install epel-release

下載 IUS 社區源安裝腳本：
