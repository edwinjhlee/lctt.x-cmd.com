初識 Python：全局、局部和非局部變量（帶示例） ​

全局變量 ​

在 Python 中，在函數之外或在全局範圍內聲明的變量被稱為全局變量。 這意味着，全局變量可以在函數內部或外部訪問。

我們來看一個關於如何在 Python 中創建一個全局變量的示例。

示例 1：創建全局變量 ​

python
x = "global"

def foo():
    print("x inside :", x)

foo()
    print("x outside:", x)

當我們運行代碼時，將會輸出：

x inside : global
x outside: global

在上面的代碼中，我們創建了 x 作為全局變量，並定義了一個 foo() 來打印全局變量 x。 最後，我們調用 foo() 來打印x的值。

倘若你想改變一個函數內的 x 的值該怎麼辦？

python
x = "global"

def foo():
    x = x * 2
    print(x)
foo()

當我們運行代碼時，將會輸出：

UnboundLocalError: local variable 'x' referenced before assignment

輸出顯示一個錯誤，因為 Python 將 x 視為局部變量，而 x 沒有在 foo() 內部定義。

為了運行正常，我們使用 global 關鍵字，查看 PythonGlobal 關鍵字以便了解更多。

局部變量 ​

在函數體內或局部作用域內聲明的變量稱為局部變量。

示例 2：訪問作用域外的局部變量 ​

python
def foo():
    y = "local"

foo()
print(y)

當我們運行代碼時，將會輸出：

NameError: name 'y' is not defined

輸出顯示了一個錯誤，因為我們試圖在全局範圍內訪問局部變量 y，而局部變量只能在 foo() 函數內部或局部作用域內有效。

我們來看一個關於如何在 Python 中創建一個局部變量的例子。

示例 3：創建一個局部變量 ​

通常，我們在函數內聲明一個變量來創建一個局部變量。

python
def foo():
    y = "local"
    print(y)

foo()

當我們運行代碼時，將會輸出：

local

讓我們來看看前面的問題，其中x是一個全局變量，我們想修改 foo() 內部的 x。

全局變量和局部變量 ​

在這裏，我們將展示如何在同一份代碼中使用全局變量和局部變量。

示例 4：在同一份代碼中使用全局變量和局部變量 ​

python
x = "global"

def foo():
    global x
    y = "local"
    x = x * 2
    print(x)
    print(y)

foo()

當我們運行代碼時，將會輸出（LCTT 譯註：原文中輸出結果的兩個 global 有空格，正確的是沒有空格）：

globalglobal
local

在上面的代碼中，我們將 x 聲明為全局變量，將 y 聲明為 foo() 中的局部變量。 然後，我們使用乘法運算符 * 來修改全局變量 x，並打印 x 和 y。

在調用 foo() 之後，x 的值變成 globalglobal了（LCTT 譯註：原文同樣有空格，正確的是沒有空格），因為我們使用 x * 2 打印兩次 global。 之後，我們打印局部變量y的值，即 local 。

示例 5：具有相同名稱的全局變量和局部變量 ​

python
x = 5

def foo():
    x = 10
    print("local x:", x)

foo()
print("global x:", x)

當我們運行代碼時，將會輸出：

local x: 10
global x: 5

在上面的代碼中，我們對全局變量和局部變量使用了相同的名稱 x。 當我們打印相同的變量時卻得到了不同的結果，因為這兩個作用域內都聲明瞭變量，即 foo() 內部的局部作用域和 foo() 外面的全局作用域。

當我們在 foo() 內部打印變量時，它輸出 local x: 10，這被稱為變量的局部作用域。

同樣，當我們在 foo() 外部打印變量時，它輸出 global x: 5，這被稱為變量的全局作用域。

非局部變量 ​

非局部變量用於局部作用域未定義的嵌套函數。 這意味着，變量既不能在局部也不能在全局範圍內。

我們來看一個關於如何在 Python 中創建一個非局部變量的例子。（LCTT 譯者注：原文為創建全局變量，疑為筆誤）

我們使用 nonlocal 關鍵字來創建非局部變量。

例 6：創建一個非局部變量 ​

python
def outer():
    x = "local"
    
    def inner():
        nonlocal x
        x = "nonlocal"
        print("inner:", x)
    
    inner()
    print("outer:", x)

outer()

當我們運行代碼時，將會輸出：

inner: nonlocal
outer: nonlocal

在上面的代碼中有一個嵌套函數 inner()。 我們使用 nonlocal 關鍵字來創建非局部變量。inner() 函數是在另一個函數 outer() 的作用域中定義的。

注意：如果我們改變非局部變量的值，那麼變化就會出現在局部變量中。
