4 個現在就該去裝的 Firefox 擴展 ​

合適的擴展能極大地增強你的瀏覽器功能，但是仔細的選擇也是很重要的。

正如我在關於 Firefox 擴展的原創文章中提到的，web 瀏覽器已成為許多用户計算機體驗的關鍵組件。現代瀏覽器已經發展成為功能強大且可擴展的平台，擴展可以添加或修改其功能。Firefox 的擴展是使用 WebExtensions API（一種跨瀏覽器開發系統）構建的。

在第一篇文章中，我問讀者：“你應該安裝哪些擴展？” 重申一下，這一決定主要取決於你如何使用瀏覽器，你對隱私的看法，你對擴展程序開發人員的信任程度以及其他個人偏好。自文章發表以來，我推薦的一個擴展（Xmarks）已經停止維護。另外，該文章收到了大量的反饋，在這篇更新中，這些反饋已經被考慮到。

我想再次指出，瀏覽器擴展通常需要能夠閲讀和（或）更改你訪問的網頁上的所有內容。你應該仔細考慮這一點。如果擴展程序修改了你訪問的所有網頁的訪問權限，那麼它可能成為鍵盤記錄程序、攔截信用卡信息、在線跟蹤、插入廣告以及執行各種其他惡意活動。這並不意味着每個擴展程序都會暗中執行這些操作，但在安裝任何擴展程序之前，你應該仔細考慮安裝源，涉及的權限，風險配置文件以及其他因素。請記住，你可以使用配置文件來管理擴展如何影響你的攻擊面 —— 例如，使用沒有擴展的專用配置文件來執行網上銀行等任務。

考慮到這一點，這裏有你可能想要考慮的四個開源 Firefox 擴展。

uBlock Origin ​

我的第一個建議保持不變。uBlock Origin 是一款快速、低內存消耗、廣泛的攔截器，它不僅可以攔截廣告，而且還可以執行你自己的內容過濾。 uBlock Origin 的默認行為是使用多個預定義的過濾器列表來攔截廣告、跟蹤器和惡意軟件站點。它允許你任意添加列表和規則，甚至可以鎖定到默認拒絕模式。儘管它很強大，但它已被證明是高效和高性能的。它將繼續定期更新，並且是該功能的最佳選擇之一。

Privacy Badger ​

我的第二個建議也保持不變。如果説有什麼區別的話，那就是自從我上一篇文章發表以來，隱私問題更被關注了，這使得這個擴展成為一個簡單的建議。顧名思義，Privacy Badger 是一個專注於隱私的擴展，可以攔截廣告和其他第三方跟蹤器。這是電子前哨基金會基金會（EFF）的一個項目，他們説：

Privacy Badger 的誕生是我們希望能夠推薦一個單獨的擴展，它可以自動分析和攔截任何違反用户同意原則的追蹤器或廣告；在用户沒有任何設置、有關知識或配置的情況下，它可以很好地運行；它是由一個明確為其用户而不是為廣告商工作的組織所產生的；它使用了算法的方法來決定什麼被跟蹤，什麼沒有被跟蹤。”

為什麼 Privacy Badger 會出現在這個列表上，它的功能與上一個擴展看起來很類似？因為一些原因：首先，它從根本上工作原理與 uBlock Origin 不同。其次，深度防禦的實踐是一項合理的策略。説到深度防禦，EFF 還維護着 HTTPS Everywhere 擴展，它自動確保 https 用於許多主流網站。當你安裝 Privacy Badger 時，你也可以考慮使用 HTTPS Everywhere。

如果你開始認為這篇文章只是對上一篇文章的重新討論，那麼以下是我的建議分歧。

Bitwarden ​

在上一篇文章中推薦 LastPass 時，我提到這可能是一個有爭議的選擇。這無疑屬實。無論你是否應該使用密碼管理器 —— 如果你使用，那麼是否應該選擇帶有瀏覽器插件的密碼管理器 —— 這是一個備受爭議的話題，答案很大程度上取決於你的個人風險狀況。我認為大多數普通的計算機用户應該使用一個，因為它比最常見的選擇要好得多：在任何地方都使用相同的弱密碼！我仍然相信這一點。

Bitwarden 自從我上次點評以後確實更成熟了。像 LastPass 一樣，它對用户友好，支持雙因素身份驗證，並且相當安全。與 LastPass 不同的是，它是開源的。它可以使用或不使用瀏覽器插件，並支持從其他解決方案（包括 LastPass）導入。它的核心功能完全免費，它還有一個 10 美元/年的高級版本。

Vimium-FF ​

Vimium 是另一個開源的擴展，它為 Firefox 鍵盤快捷鍵提供了類似 Vim 一樣的導航和控制，其稱之為“黑客的瀏覽器”。對於 Ctrl+x、 Meta+x 和 Alt+x，分別對應 <c-x>、<m-x> 和 <a-x>，默認值可以輕鬆定製。一旦你安裝了 Vimium，你可以隨時鍵入 ? 來查看鍵盤綁定列表。請注意，如果你更喜歡 Emacs，那麼也有一些針對這些鍵綁定的擴展。無論哪種方式，我認為鍵盤快捷鍵是未充分利用的生產力推動力。

額外福利: Grammarly ​

不是每個人都有幸在 Opensource.com 上撰寫專欄 —— 儘管你應該認真考慮為這個網站撰寫文章；如果你有問題，有興趣，或者想要一個導師，伸出手，讓我們聊聊吧。但是，即使沒有專欄撰寫，正確的語法在各種各樣的情況下都是有益的。試一下 Grammarly。不幸的是，這個擴展不是開源的，但它確實可以確保你輸入的所有東西都是清晰的 、有效的並且沒有錯誤。它通過掃描你文本中的常見的和複雜的語法錯誤來實現這一點，涵蓋了從主謂一致到文章使用，到修飾詞的放置這些所有內容。它的基本功能是免費的，它有一個高級版本，每月收取額外的費用。我在這篇文章中使用了它，它發現了許多我的校對沒有發現的錯誤。

再次説明，Grammarly 是這個列表中包含的唯一不是開源的擴展，因此如果你知道類似的高質量開源替代品，請在評論中告訴我們。

這些擴展是我發現有用並推薦給其他人的擴展。請在評論中告訴我你對更新建議的看法。
