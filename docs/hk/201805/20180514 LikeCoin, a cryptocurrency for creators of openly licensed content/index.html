LikeCoin，一種給開放式許可的內容創作者的加密貨幣 ​

在共創協議下授權作品和掙錢這二者不再是一種爭議。

傳統觀點認為，作家、攝影師、藝術家和其他創作者在共創協議Creative Commons和其他開放許可下免費共享內容的不會得到報酬。這意味着大多數獨立創作者無法通過在互聯網上發佈他們的作品來賺錢。而現在有了 LikeCoin：一個新的開源項目，旨在使這個讓藝術家們經常為了貢獻而不得不妥協或犧牲的常識成為過去。

LikeCoin 協議旨在通過創意內容獲利，以便創作者可以專注於創造出色的內容而不是出售它。

該協議同樣基於去中心化技術，它可以跟蹤何時使用內容，並使用 LikeCoin 這種 以太坊 ERC-20 加密貨幣通證來獎勵其創作者。它通過“創造性共識Proof of Creativity”算法進行操作，該算法一部分根據作品收到多少個“喜歡”，一部分根據有多少作品衍生自它而分配 LikeCoin。由於開放式授權的內容有更多機會被重複使用並獲得 LikeCoin 令牌，因此係統鼓勵內容創作者在共創協議Creative Commons許可下發布。

如何運作的 ​

當通過 LikeCoin 協議上傳創意片段時，內容創作者也將包括作品的元數據，包括作者信息及其 InterPlanetary 關聯數據（IPLD）。這些數據構成了衍生作品的家族圖譜；我們稱作品與其衍生品之間的關係為“內容足跡”。這種結構使得內容的繼承樹可以很容易地追溯到原始作品。

LikeCoin 通證會使用作品的衍生歷史記錄的信息來將其分發給創作者。由於所有創意作品都包含作者錢包的元數據，因此相應的 LikeCoin 份額可以通過算法計算並分發。

LikeCoin 可以通過兩種方式獲得獎勵：要麼由想要通過支付給內容創建者來表示讚賞的個人直接給予，或通過 Creators Pool 收集觀眾的“贊”的並根據內容的 LikeRank 分配 LikeCoin。基於在 LikeCoin 協議中的內容追蹤，LikeRank 衡量作品重要性（或者我們在這個場景下定義的創造性）。一般來説，一副作品有越多的衍生作品，創意內容的創新就越多，內容就會有更高的 LikeRank。 LikeRank 是內容創新性的量化者。

如何參與？ ​

LikeCoin 仍然非常新，我們期望在 2018 年晚些時候推出我們的第一個去中心化程序來獎勵共創協議Creative Commons的內容，並與更大的社區無縫連接。

LikeCoin 的大部分代碼都可以在 LikeCoin GitHub 倉庫中通過 GPL 3.0 許可證訪問。由於它仍處於積極開發階段，一些實驗代碼尚未公開，但我們會盡快完成。

我們歡迎功能請求、拉取請求、復刻和星標。請參與我們在 Github 上的開發，並加入我們在 Telegram 的討論組。我們同樣在 Medium、Facebook、Twitter 和我們的網站 like.co 發佈關於我們進展的最新消息。
