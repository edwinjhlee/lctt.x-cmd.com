微軟加入開放 3D 基金會，參與開源 3D 開發 ​

微軟已經以首席成員的身份加入了開放 3D 基金會Open 3D Foundation（O3DF），其他首席成員是 Adobe、AWS、華為、英特爾和 Niantic。微軟的參與為該項目帶來了大量的知識和思想引領，這表明了：通過行業合作，創造一個高保真、功能齊全、不受商業條件限制的開源 3D 引擎是多麼的關鍵。

微軟首席集團項目經理 Paul Oliver 將加入 O3DF 管理委員會，這表明他將致力於實現基金會的目標，即確保符合開放 3D 社區保持需求與輸入的平衡。基金會的戰略方向和對 3D 可視化、仿真計劃的管理，是由理事會與股東的創新互動來指導的。

“微軟在創意方面的根基很深，我們希望幫助所有的創作者，無論他們是誰、在哪裏、為哪個平台創作”，Oliver 如是説，“由 Linux 基金會創建的開放 3D 基金會，是朝着幫助更多世界各地的創作者邁出的美妙一步，我們很高興能成為其中的一員。”

微軟不斷致力於使遊戲製作民主化，並向全世界的遊戲創作者提供其工具和技術。加入開放 3D 基金會也反映出這一點。微軟去年通過 GitHub 向所有開發者發佈了其遊戲開發工具包，並正在通過與 O3DF 的新夥伴關係，擴大其向所有人開放技術的承諾。

O3DF 執行董事，兼 Linux 基金會的遊戲和數字媒體部總經理 Royal O'Brien 説：“我們很高興微軟以首席成員的身份加入開放 3D 基金會。有像微軟這樣傑出的行業資深公司做出貢獻，並幫助社區推動 3D 引擎的創新，這對開源社區和使用它的公司都是巨大的好處。”

via: https://www.opensourceforu.com/2022/05/microsoft-joins-the-open-3d-foundation-for-open-source-3d-development-promotion/
