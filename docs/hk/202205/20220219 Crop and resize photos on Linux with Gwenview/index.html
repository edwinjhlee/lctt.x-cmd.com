用 Gwenview 在 Linux 上裁剪和調整照片大小 ​

Gwenview 是一個優秀的照片編輯器，適合業餘攝影師在 Linux KDE 桌面上使用。

一張好的照片可以藴含很多信息。表面上它表達了你所看到的，但它也講述了你所經歷的。細微之處也能説明很多問題：你在拍照時選擇的角度、取景中隱約可見的的東西有多大，以及，相比之下，那些有意識選擇忽略的部分。

照片通常並不意味着記錄真實發生的事情，相反，它們會成為你（攝影師）如何看待發生的事情的洞察力。

這就是照片編輯如此普遍的原因之一。當你把照片發佈到你的在線圖片庫或社交網絡時，你不應該發佈一張不能準確表達照片所包含的感受的照片。但同樣的道理，你也不應該成為一個專業的照片合成師，而只是為了剪掉在最後時刻將頭伸進你的家庭快照的路人。如果你使用的是 KDE，你可以使用 Gwenview 這種休閒照片編輯器。

在 Linux 上安裝 Gwenview ​

如果你正在運行 KDE Plasma 桌面，你可能已經安裝了 Gwenview。如果你沒有安裝，或者你正在使用一個不同的桌面，而你想嘗試 Gwenview，那麼你可以用你的軟件包管理器安裝它。

我建議同時安裝 Gwenview 和 Kipi 插件集，它可以將 Gwenview 與幾個在線照片服務連接起來，這樣你就可以輕鬆上傳照片。在 Fedora、Mageia 和類似發行版上：

$ sudo dnf install gwenview kipi-plugins

在 Debian、Elementary 和類似版本上：

$ sudo apt install gwenview kipi-plugins

使用 Gwenview ​

Gwenview 通常有兩種啓動方式。你可以在 Dolphin 中點擊圖片文件，並選擇在 Gwenview 中打開它；或者你可以啓動 Gwenview，並在文件夾中尋找照片，Gwenview 或多或少可以充當你的文件管理器。第一種方法是直接的方法，很適合快速方便地預覽圖片文件。第二種方法是當你瀏覽大量照片，不確定哪一個版本的照片是“正確的”時，你可能會使用。

無論你如何啓動 Gwenview，界面和功能都是一樣的：右邊有一個工作區，左邊有一個面板。

（Seth Kenlon CC BY-SA 4.0, Photo courtesy Andrea De Santis）

在左邊的面板下面，有三個標籤：

  • 文件夾Folders：顯示你電腦上的文件夾的樹狀視圖，以便你可以瀏覽你的文件，尋找更多的照片。
  • 信息Information：提供關於你目前正在查看的照片的元數據。
  • 操作Operations：允許你對當前的照片進行小的修改，如在橫向和縱向之間旋轉、調整大小和裁剪等。

Gwenview 能理解文件系統，所以你可以按鍵盤上的右或左箭頭，查看文件夾中的上一張或下一張照片。

要離開單張照片視圖並查看一個文件夾中的所有圖片，請點擊頂部工具欄中的“瀏覽Browse”按鈕。

（Seth Kenlon，CC BY-SA 4.0）

你也可以同時擁有兩種視圖。點擊 Gwenview 底部的“縮略圖欄Thumbnail Bar”按鈕，可以以電影膠片的形式看到當前文件夾中的其他圖片，而當前選擇的照片則在主面板中。

（Seth Kenlon，CC BY-SA 4.0）

用 Gwenview 編輯照片 ​

數碼照片是很常見的，因此在網上發佈或與朋友分享之前，需要對照片進行細微的調整也是同樣常見。有非常好的應用可以編輯照片，事實上，其中最好的一個是另一個 KDE 應用，叫做 Krita（你可以在我的 給攝影者的 Krita 文章中閲讀我如何使用它來處理照片），但是小的調整不應該需要藝術學位。這正是 Gwenview 所確保的：用一個休閒但功能強大的應用進行簡單而快速的照片調整，並與你的 Plasma 桌面的其他部分整合。

我們大多數人對照片進行的最常見的調整是：

  • 旋轉：當你的相機沒有提供正確的元數據讓你的電腦知道一張照片是要以橫向還是縱向觀看時，你可以手動修復它。
  • 鏡像：許多筆記本電腦或面部攝像頭模仿鏡子，這很有用，因為這是我們習慣於看到自己的方式。但是，它會使文字逆轉。鏡像功能可以從右到左翻轉圖像。
  • 翻轉：在數碼相機和筆記本電腦上不太常見，但在手機上，無論你怎麼拿手機，使用倒置設備拍照的現象在屏幕翻轉的手機中並不少見。翻轉功能可將圖像旋轉 180 度。
  • 調整大小：數字圖像現在通常具有超高清尺寸，有時這比你需要的要多得多。如果你通過電子郵件發送照片或將其發佈在你想要優化加載時間的網頁上，你可以將尺寸（和相應的文件大小）縮小到更小的尺寸。
  • 裁剪：你有一張很棒的自己的照片，但不小心偶然發現了一個你認為不合適的人。用裁剪工具剪掉你不想要的所有東西。
  • 紅眼：當你的視網膜將相機的閃光燈反射回相機時，會得到紅眼效果。Gwenview 可以通過在可調節區域中對紅色通道進行去飽和和變暗來減少這種情況。

所有這些工具都在“操作Operations”側面板或“編輯Edit”菜單中可用。這些操作具有破壞性，因此在你進行更改後，單擊“另存為Save As”以保存圖像的 副本。

（Seth Kenlon，CC BY-SA 4.0，照片由 Elise Wilcox 提供)

分享照片 ​

當你準備好分享照片時，單擊頂部工具欄中的“分享Share”按鈕，或轉到“插件Plugins”菜單並選擇“導出Export”。Gwenview 與 Kipi 插件集成在一起，可以在 Nextcloud、Piwigo、普通舊電子郵件以及 Google Drive、Flickr、Dropbox 等服務共享照片。

Linux 上的照片編輯要點 ​

Gwenview 擁有桌面照片管理器的所有必需功能。如果你需要的不僅僅是基本功能，你可以在 Krita 或 Digikam 中打開一張照片，並根據需要進行重大修改。對於其他一切，從瀏覽、排名、標記和小調整，Gwenview 都很方便。
