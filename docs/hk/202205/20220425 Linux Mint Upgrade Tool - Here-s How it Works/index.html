實測 Linux Mint 升級工具 ​

我們通過實際升級測試了 Linux Mint 升級工具（mintupgrade GUI）。這是我們的發現。

這個工具正在開發中，可能包含錯誤，除非你想實驗一下，否則請不要在你的日常中使用它。

Linux Mint 升級工具 ​

Linux Mint 團隊 宣佈，他們建立了一個新的工具來升級 Linux Mint 的主要版本。它被稱為 “mintupgrade2”。它目前正在開發中，計劃用於升級主要版本。例如，從 Linux Mint 20 到 21，而不是小版本的升級。

雖然你可以使用標準的 apt 命令來升級版本，然而，Mint 團隊認為主要版本的升級是很棘手的。新用户很難順利升級，因為它涉及到終端和一套複雜的命令步驟。

此外，這個圖形用户界面是對 mintupgrade 程序的封裝，並帶有一些附加功能，它帶來了一套系統前檢查和一鍵修復的升級過程。

除此之外，mintupgrade 還會檢查你是否連接到電源、系統是否是最新的、磁盤空間的可用性等等。

為了讓大家瞭解它的外觀和工作情況，我們使用 LMDE 4 設置了一個測試平台做了個測試。

但在這之前，讓我快速介紹一下它的功能：

  • 完全由 GUI 驅動的升級過程
  • 多語言支持
  • 升級前檢查：系統備份、電源、磁盤空間、刪除的軟件包列表
  • 可配置
  • 提醒你來自上一個版本的孤兒軟件包
  • 給你修復問題的選項

它是如何工作的 ​

當我們通過命令 mintupgrade 運行這個 Mint 升級工具時，這個圖形用户界面程序友好的歡迎屏幕是一個很好的起點，它開啓了升級過程，然後它自己開始進行一系列的檢查。

除此之外，當它在你的系統中發現一些問題時，它會停下來並給你足夠的細節。當你點擊“修復”後，它就可以再次恢復進程。

不止如此。如果由於網絡或互聯網或任何其他問題而中斷，它也可以恢復升級過程。

最後，我們成功地將一個測試系統從 LMDE 4 升級到 LMDE 5。

如何獲得這個升級工具 ​

使用下面的命令，該工具的安裝很簡單。但正如該團隊所建議的，它現在處於 BETA 狀態，所以不要用它來進行正式場合的升級。

sudo apt update
sudo apt install mintupgrade

結束語 ​

最後，我認為這是 Linux Mint 團隊的最好的工具之一。正如你在上面看到的，它自己處理了許多錯誤。我所做的只是點擊“修復”按鈕。而這個工具足夠聰明，能夠理解所有的故障點，並負責補救。

mintupgrade 工具 將在 Linux Mint 21 “Vanessa” 發佈前發佈，大約在 2022 年第三季度末或第四季度初。
