開源為可持續發展技術提供新思路 ​

開源和社會對於更為穩定的技術演進的需求具有相同的目標，即實現一個更為可持續的未來。

在可持續發展和環境問題上，目前正在發生明確的變化。關注地球的狀況併為之做出努力已經成為主流思想。舉個例子，看看基於氣候的風險資本主義。氣候技術風險投資公司Climate Tech Venture Capital（CTVC）的氣候資本名單在過去兩年中增加了 一倍多。湧入的資本表明了人們對解決艱難的氣候挑戰的願望和意願。

人們想採取行動，這很好，我持相同態度！但我也看到了一個真正的風險：當人們急於採取行動並參與到其中時，他們可能會不知不覺地捲入洗綠運動中。

維基百科對 “洗綠greenwashing” 的定義稱其為 “一種營銷策略，其中綠色公關和綠色營銷被欺騙性地用來説服公眾，使其相信一個組織的產品、目標和政策是環保的”。在我看來，洗綠既是有意為之，也是無意中發生的。外面有很多想有所作為的好人，但對複雜的環境系統或圍繞可持續發展的問題的深度還不甚瞭解。

我們很容易落入這樣的陷阱，即認為通過植樹來抵消旅行或數據中心的排放等簡單的購買行為會使一些東西變得更加綠色。雖然這些努力是值得提倡的，而且植樹是改善可持續發展的一個可行的解決方案，但它們只是一個很好的開端，仍然需要進行更多的努力才能真正產生變革。

那麼，一個人或一個社區可以做些什麼來使數字技術真正地更加可持續？

“可持續性”對不同的人有不同的含義。我喜歡的最簡短的定義來自 1987 年的《布倫特蘭報告Bruntland Report》，該報告將其概括為 “既能滿足當代的需要，同時又不損及後代滿足其需要的發展模式”。可持續發展的核心是優先考慮長期思維。

可持續發展不僅僅是保護環境 ​

在可持續性的定義中，有三個相互關聯的關鍵支柱：

  1. 環境
  2. 經濟 / 政策
  3. 社會

關於可持續發展的討論越來越多地被氣候危機所主導，這是有道理的。隨着我們繼續通過不可逆轉的生態臨界點，減少世界上較富裕國家的碳排放的需求變得越來越緊迫。但真正的可持續性是一套更全面的體系，正如三大支柱所展示的那樣。

碳排放無疑是可持續性的一部分。許多人認為排放只是一個環境問題。只要從空氣中移除更多的碳，一切都會好起來。但社會問題也是可持續性的一部分。誰會受到這些碳排放的影響？誰將承受我們氣候變化帶來的最大影響？誰因海平面上升而失去了家園，或因天氣模式變化而失去了可靠的水源？這就是為什麼你可能聽説過 “氣候正義就是社會正義” 這句話。

僅僅把減碳看作是可持續發展會令你的視野被限定在碳上。我經常認為，氣候變化是社會在更大範圍內錯失可持續性的一個症狀。相反，關鍵是要解決首先導致氣候變化的根本原因。解決這些問題將使長期解決這些問題成為可能，而短期解決可能只會將問題推向另一個脆弱的邊緣。

其根本原因很複雜。但是，如果我追根溯源，我看到根源是由西方的主流價值觀和旨在延續這些價值觀的制度所驅動的。這些價值觀是什麼呢？一語概之，它們是快速增長和對利潤的攫取高於一切。

這就是為什麼關於可持續性的對話如果不包括社會問題或經濟的設計方式，就不會達成真正的解決方案。畢竟，社會和掌握權力的人決定了他們自己的價值觀是什麼，或者不是什麼。

我能做什麼？ ​

科技領域的許多人目前正致力於解決這些問題，並想知道怎樣行動更有意義。一個常見的方法是研究如何優化他們製造的技術，使其更有效地使用電力。世界上 60% 的電力仍然是通過燃燒化石燃料產生的，儘管可再生能源的發電能力不斷提高。但從邏輯上講，使用更少的電力意味着產生更少的碳排放。

是的，這是很有意義的，任何人都可以嘗試，立即就能生效。當用户加載一個頁面時，優化發送的資源，以發送更少的數據，將使用更少的能源。因此，優化服務器，使其在一天中的不同時段運行，例如，當有更多的可再生能源可用時運行，或刪除多餘信息的舊存儲，如分析數據或日誌。

但考慮到傑文Jevon的悖論：使某樣東西更有效率往往會導致使用更多的東西，而不是減少。當人們更容易和更便於使用某樣東西時，他們最終會使用更多。在某種角度，這是好的。性能更好的技術是一件好事，有助於提高包容性和觸及性，這對社會是有益的。但是，氣候變化和可持續性的長期解決方案需要圍繞社會和技術之間的關係進行更深入、更令人不適的對話。所有這些技術在為什麼和誰服務？它正在加速哪些行為和做法？

將技術的演進視為進步很正常，一些人認為：技術將把世界從氣候變化中拯救出來。一些聰明的人正在通過艱苦卓絕的努力改善這一問題，所以其他人不需要改變他們的方式。問題是，許多社區和生態系統已經在遭受更大的創傷。

例如，對更多更高速傳輸的數據的追求正在導致智利的一些社區沒有足夠的水來種植農作物。因為數據中心正在使用這些寶貴的水源。移動電話造成的污染有 70% 來自於其製造。製造移動設備併為其提供動力的鋰和鈷等原材料通常是從弱勢的社區中提取的，而這些社區幾乎沒有能力阻止製造商對其土地的破壞，當然也沒有分享所獲利潤。儘管如此，每兩年升級一次手機的做法已經變得很普遍了。

開源思路引領可持續發展之路 ​

現在是時候將數字技術的使用視為一種寶貴的資源，這對地球和（通常已經處於弱勢的）社區都有影響。

開源社區已經幫助人們認識到有另一種解決方案：開源。開源與我們更廣泛的社會為實現更可持續的未來而需要做的事情之間有巨大的相似之處。更加開放和包容是其中的一個關鍵部分。

我們還需要在社會的各個層面進行思維轉變，將數字技術視為有代價的增長，而不是我們今天看到的大量廉價和免費的東西。我們需要明智地將其優先用於對於社會而言最為重要的事情。更重要的是，我們需要關注並消除其創造和長期使用所帶來的危害，並與社會上的每個人公平地分享其創造的財富，無論他們是否是數字技術的使用者。這些事情不會在一夜之間發生，但它們是我們可以共同推動的事情，以便我們都能長期、可持續地享受數字技術的好處。
