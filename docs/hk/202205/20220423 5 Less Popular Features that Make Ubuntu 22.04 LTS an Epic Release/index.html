使 Ubuntu 22.04 LTS 成為史詩版本的 5 個不太流行的功能 ​

這是一份關於 Ubuntu 22.04 LTS 的次要特點的列表，這些特點使它成為迄今為止最好的 LTS 版本之一。

Canonical 的最新 LTS 版本 Ubuntu 的代號為 “Jammy Jellyfish” 受到了全球用户的好評。但是有數百個新的微小功能，以及一些不太流行的功能，沒有引起人們的注意。因此，這裏有五個 Ubuntu 22.04 的獨特功能，我們認為這些功能可以使它成為一個史詩般的版本。

Ubuntu 22.04 發佈 – 五個獨特的功能 ​

為數據驅動的方案進行了優化 ​

數據分析和處理是當今每個企業的核心。而要做到這一點，你需要巨大的計算能力。Ubuntu 22.04 LTS 帶來了開箱即用的 英偉達虛擬 GPU（vGPU） 驅動支持。這意味着你可以利用英偉達虛擬 GPU 軟件，使你能夠在虛擬機中使用從物理 GPU 服務器共享的 GPU 計算能力。

不僅如此，如果你的業務依賴於 SQL Server，Ubuntu LTS for Azure 帶來了 Ubuntu 中的 SQL Server，它由 “Micro$oft” 支持，提供優化的性能和可擴展性。

改進的活動目錄集成 ​

此外，許多企業在多個工作站中為整個企業用户部署 Ubuntu。而且，部署工作站策略以監測和控制用户訪問和各種關鍵業務控制非常重要。

活動目錄實現了基於策略的工作站管理（在 Ubuntu 20.04 中引入），在這個版本中得到了進一步改善。除此之外，這個版本還帶來了 ADsys 客户端，它有助於通過命令列遠程管理組策略、權限升級和遠程腳本執行。從這個版本開始，活動目錄現在也支持與高級組策略對象的安裝程序集成。

實時內核支持 ​

此外，在 Ubuntu 22.04 LTS 發佈期間，Canonical 宣佈的一個有趣的消息是，提供“實時”內核選項，現在是測試版。對於電信和其他行業來説，一個低延遲的操作系統對於時間敏感的工作是必需的。因此，考慮到這一點和滲透到這些領域的願景，Ubuntu 22.04 LTS 帶來了一個應用了 PREEMPT_RT 補丁的實時內核構建。它可用於 x86_64 和 AArch64 架構。

然而，該 補丁 還沒有在主線內核中出現，希望它能很快能出現。

最新的應用、軟件包和驅動程序 ​

除了上述變化之外，這個版本還帶來了大量的軟件包和工具鏈的升級。例如，這個版本帶來了基於各種用途的多種 Linux 內核類型，如 Ubuntu 桌面可以選擇使用 內核 5.17，而硬件啓用內核仍然是 5.15。

不僅如此，Ubuntu Server 採用長期支持版的 內核 5.15，而 Ubuntu Cloud 鏡像可以選擇使用與雲供應商合作的更優化的內核。

此外，如果你是英偉達用户，值得一提的是，ARM64 上的英偉達驅動的 Linux 限制模組現在已經可用（在 x86_64 中已經可用）。你可以使用 ubuntu-drivers 程序來安裝和配置英偉達驅動。

核心模組和子系統構成的完整的操作系統可以完美無缺地工作。因此，考慮到這一點，Ubuntu 22.04 LTS 對它們都進行了仔細的升級，以迎合這個很好的版本。以下是簡介：

GNU/Linux 核心：

  • GCC 11.2.0
  • binutils 2.38
  • glibc 2.35

編程工具鏈：

  • Python 3.10.4
  • Perl 5.34.0
  • LLVM 14
  • golang 1.18
  • rustc 1.58
  • OpenJDK 11（可選使用 OpenJDK 18）
  • Ruby 3.0
  • PHP 8.1.2
  • Apache 2.4.52
  • PostgreSQL 14.2
  • Django 3.2.12
  • MySQL 8.0
  • 更新的 NFS 以及 Samba Server
  • Systemd 249.11
  • OpenSSL 3.0

虛擬化：

  • qemu 6.2.0
  • libvirt 8.0.0
  • virt-manager 4.0.0

性能提升 ​

但這還不是全部。由於一些長期等待的更新，你應該體驗到更快的 Ubuntu 22.04 Jammy Jellyfish，這些體驗最終會在這個版本中出現。

首先，長期等待的 GNOME 桌面的 [三重緩衝代碼] 已經來到。當先前的幀緩衝落後時，三重緩衝會自動啓用，它在英特爾和樹莓派驅動中產生了更快的桌面性能。不僅如此，代碼還監控最後一幀，以便系統不會遇到過量緩衝的情況。

其次，改進的電源管理，在運行時對 AMD 和英偉達的 GPU 起作用，將幫助筆記本電腦用户。

此外，Wayland 現在是大多數系統的默認顯示服務器，除了英偉達 GPU 硬件默認為 X11。Wayland 為你提供了更快的跨應用的桌面體驗，包括網頁瀏覽器。

最後，定製的 GNOME 42 及其 獨特功能（例如平衡和省電電源配置文件）為重度筆記本電腦用户提供了更多優勢。此外，帶有淺色/深色外觀的新強調色和將選定的 GNOME 模組移植到 GTK4/libadwaita 只是這個史詩般的 Ubuntu 22.04 LTS 版本的一個補充。

結論 ​

總而言之，就上述所有內容的變化和許多其他方面而言，我相信這是 Canonical 發佈的最好的 LTS 版本之一。

我們希望它得到好評，並在未來能保持穩定。
