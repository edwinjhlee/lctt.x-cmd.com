Fedora Linux 36 發佈 ​

今天，我很高興與大家分享一個消息，它是成千上萬的 Fedora 項目貢獻者辛勤工作的成果：我們的最新版本 —— Fedora Linux 36，和大家見面了！

由社區開發，為社區服務 ​

通常當我寫這些公告時，我會談論版本中的一些很棒的技術變化。但這一次，我想把重點放在實現這些變化的社區上。Fedora 社區不是一羣孤立地工作的人 —— 我們是朋友。事實上，這也是我們的“四個理念Four Foundations”之一。

我們最新的“Fedora 朋友”之一，Juan Carlos Araujo 在一篇 Fedora 討論帖子 中説得很好：

除了功能、穩定性、特性、工作方式以及前沿性外，我認為決定一個發行版成敗的還有那些無形的東西，比如文檔和社區。而 Fedora 擁有這一切……尤其是無形的東西。

多年來，我們一直努力使 Fedora 成為一個包容和歡迎的社區。我們希望它成為經驗豐富的貢獻者和新手能一起工作的地方。就像我們希望 Fedora Linux 是一個既能吸引資深用户又能吸引新手的發行版一樣。

説到 Fedora Linux，讓我們看看新版本的一些亮點。像往常一樣，在從舊版本升級之前，請確保你的系統是最新的。這次尤其需要注意，因為我們在 F34/F35 更新中修復了一些非常重要的與升級有關的錯誤。如果不先應用這些更新，系統升級可能會失敗。

桌面改進 ​

Fedora 工作站專注於桌面體驗，尤其是面向那些希望獲得“剛剛好”的 Linux 系統體驗的用户。像往常一樣，Fedora 工作站採用最新的 GNOME 版本：GNOME 42。雖然 GNOME 42 不能完全解決生命、宇宙和一切問題，但它帶來了很多改進。許多應用程序都被移植到了 GTK 4，以改善風格和性能。它還附帶了兩個新的應用程序：文本編輯器Text Editor和控制台Console。它們的名字起得很貼切，所以你可以猜出它們是幹什麼的。文本編輯器是新的默認文本編輯器，而控制台可以在軟件倉庫中下載。

如果你使用了英偉達的專有圖形驅動，你的桌面會話現在將默認使用 Wayland 協議。這使你能夠在使用現代桌面管理器時，充分利用硬件加速。

當然，我們生產的不僅僅是 “Editions”。Fedora Spins 和 Labs 針對不同的受眾和使用場景。例如 Fedora Comp Neuro ，它為計算神經科學提供工具，以及 Fedora LXQt，它提供一個輕量級的桌面環境。並且，我們附加了可選架構：ARM AArch64、Power 和 S390x。

針對系統管理員的改進 ​

Fedora Linux 36 包含最新的 Ansible 版本。Ansible 5 將“引擎”拆分為 ansible-core 包和 collection 包。這使得維護更容易，並允許你只下載需要的集合。請參閲 Ansible 5 遷移指南 以瞭解如何更新你的 Playbook。

從 Fedora Server 36 開始，Cockpit 提供了一個用於配置和持續管理 NFS 及 Samba 共享的模組。這使得管理員可以通過 Cockpit 網頁界面（用於配置其他服務器屬性）來管理網絡文件共享。

其他更新 ​

無論你使用 Fedora Linux 的哪個衍生版，你都會得到開源世界所提供的最新成果。Podman 4.0 將在 Fedora Linux 36 中首次全面發佈。它帶來了大量變化和一個全新的網絡棧。不過，它也帶來了向下不兼容的 API 變化，所以請仔細閲讀 上游文檔。

遵循 Fedora 的 “爭先First” 理念，我們已經更新了關鍵的編程語言和系統庫包，包括 Ruby 3.1、Golang 1.18 和 PHP 8.1。

我們很高興你能試用新版本！請訪問 https://getfedora.org 並立即下載它吧！或者，如果你正在使用 Fedora Linux，請按照我們的 簡易升級説明 進行。想了解更多關於 Fedora Linux 36 新功能的信息，請查看 發行説明。

雖然不大可能會出現問題…… ​

但是，如果你真的遇到了問題，請訪問我們的 Ask Fedora 用户支持論壇。這裏有一個 常見問題 的分類。

謝謝大家 ​

感謝在本次發佈週期內為 Fedora 項目做出貢獻的成千上萬的人。Fedora 社區有你們，真好！請務必在 5 月 13 日至 14 日參加我們的 虛擬發佈派對！
