ONLYOFFICE 7.1 發佈，新增針對 ARM 的支持、新的 PDF 查看器 ​

ONLYOFFICE Docs 7.1 帶來了期待已久的針對文檔、電子表格以及演示文稿編輯器的更新。對 ARM 的支持更是畫龍點睛之筆。

ONLYOFFICE，被認為是 最佳的微軟 Office 替代品 之一，剛剛發佈了最新的 7.1 版本更新。

或許你不瞭解，ONLYOFFICE 可以在自託管的服務器（例如 Nextcloud）或者桌面上在線使用。

這個版本最為激動人心的變化就是初步支持了基於 ARM 的設備，例如樹莓派。

接下來請讓我們一起看看有什麼新的變化。

ONLYOFFICE 7.1 ： 新變化 ​

除了對 ARM 的支持，ONLYOFFICE 7.1 還提供瞭如下新功能：

  • 一個全新的 PDF、XPS 和 DjVu 文件查看器
  • 更方便和可定製的圖形選項
  • 電子表格打印預覽
  • 演示文稿中的動畫
  • 支持 SmartArt 對象

ARM 兼容 ​

樹莓派這樣的基於 ARM 的設備正變得越來越熱門，許多人已經期待了許久 ONLYOFFICE 對 ARM 架構的支持。

隨着 7.1 版本的發佈，ONLYOFFICE Docs 現在可以在所有 ARM64 設備上運行。由於 ARM 設備的效率和安全性的提高，我認為這將對 ONLYOFFICE 的未來產生很大的促進作用。

全新的 PDF、XPS 和 DjVu 文件查看器 ​

這是許多其他辦公軟件多年來的一個關鍵功能。從 ONLYOFFICE 7.1 開始，用户現在可以更方便地使用文檔編輯器來查看 PDF、XPS 和 DjVu 文件。

新的視圖選項卡為用户提供了一個頁面縮略圖視圖和一個導航欄，其視圖更為緊湊和簡化。

此外，用户現在還可以將 PDF 文件轉換為 DOCX 文件，以便對其進行編輯。因此，我們不用再額外打開其他軟件進行處理了，這將顯著優化現有的工作流並消除瓶頸。

選擇和編輯圖形更加方便 ​

圖形做為現代辦公軟件的特性，在許多時候並沒能發揮足夠的作用。儘管 ONLYOFFICE 擁有這些功能已經有一段時間了，但它們在使用時總是相當笨重。

在 ONLYOFFICE 7.1 中，重新設計的圖形選擇菜單使得這種情況得到了改變。這個新的菜單與微軟 Office 的同類產品非常相似，每個圖標都可以從菜單中看到。

此外，它現在可以顯示最近使用的圖形，使批量插入圖形更加容易。

圖形的最後一項改進是能夠使用鼠標來編輯它們。對於那些熟悉 Inkscape 等圖形設計軟件的人來説，這將會相當得心應手。通過簡單地拖動點，你將可以在短時間內創建一個獨特的形狀。

電子表格的打印預覽 ​

我相信每個人都發生過由於一個簡單的錯誤而導致打印出現問題的情況。此前其他程序早已經解決了這個問題，但在 ONLYOFFICE 電子表格編輯器中一直沒有這個功能。

新版本終於引入了“打印預覽”，這將會顯著改善上述的情況。

這並不算什麼十分新穎的更新，只是説它補齊了短板並且可以節省紙張和打印耗材。

改進的動畫頁面，便捷的剪切和複製 ​

針對需要經常使用演示文稿的用户而言，這個版本增加了一個單獨的動畫標籤，使動畫的插入變得更為容易。

ONLYOFFICE 7.1 演示文稿編輯器現在支持各種動畫，以及便捷地將一頁幻燈片移動以及複製的能力。

SmartArt 對象的支持 ​

SmartArt 是一種在文檔、演示文稿和電子表格中便捷地製作自定義圖形的工具。然而，它一直是微軟辦公軟件的一個功能。雖然其他各種應用程序對該格式有不同程度的支持，但它們並不能與微軟 Office 相媲美。

幸運的是，ONLYOFFICE 7.1 現在完全支持這種格式，並且沒有任何亂碼，彷彿原生的一般。用户將不再需要和以前一樣在將 SmartArt 圖形轉換為普通圖形和數字，便於無縫切換。

其他變化 ​

ONLYOFFICE 7.1 的其他重要改進包括：

  • 新的客户端語言：加利西亞語和阿塞拜疆語
  • 在受密碼保護的文件中，能夠在輸入密碼的同時查看密碼
  • OFORM 文件支持縮放選項
  • 能夠按用户組過濾評論
  • 支持金字塔圖表
  • 支持金字塔柱狀圖
  • 支持垂直和水平圓柱圖
  • 支持垂直和水平圓錐圖
  • 上下文菜單中的移動和複製幻燈片選項
  • 公式工具提示
  • 新的貨幣格式支持

若想了解全部新特性，請見 發佈日誌。

下載 ONLYOFFICE 7.1 ​

總的來説，ONLYOFFICE 7.1 是一個兼容 ARM 並且功能更為豐富的版本。

所有版本（企業版、開發版者、社區版）都有更新。
