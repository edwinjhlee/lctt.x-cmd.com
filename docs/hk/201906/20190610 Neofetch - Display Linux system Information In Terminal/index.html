Neofetch：在終端中顯示 Linux 系統信息 ​

Neofetch 是一個簡單但有用的命令列系統信息工具，它用 Bash 編寫。它會收集有關係統軟硬件的信息，並在終端中顯示結果。默認情況下，系統信息將與操作系統的 logo 一起顯示。但是，你可以進一步地自定義使用 ascii 圖像或其他任何圖片。你還可以配置 Neofetch 顯示的信息、信息的顯示位置和時間。Neofetch 主要用於系統信息的截圖。它支持 Linux、BSD、Mac OS X、iOS 和 Windows 操作系統。在這個簡短的教程中，讓我們看看如何使用 Neofetch 顯示 Linux 系統信息。

安裝 Neofetch ​

Neofetch 可在大多數 Linux 發行版的默認倉庫中找到。

在 Arch Linux 及其衍生版上，使用這個命令安裝它：

$ sudo pacman -S netofetch

在 Debian（Stretch / Sid）上：

$ sudo apt-get install neofetch

在 Fedora 27 上：

$ sudo dnf install neofetch

在 RHEL、CentOS 上：

啓用 EPEL 倉庫：

# yum install epel-relase

獲取 neofetch 倉庫：

# curl -o /etc/yum.repos.d/konimex-neofetch-epel-7.repo
https://copr.fedorainfracloud.org/coprs/konimex/neofetch/repo/epel-7/konimex-neofetch-epel-7.repo

然後，安裝 Neofetch：

# yum install neofetch

在 Ubuntu 17.10 和更新版本上：

$ sudo apt-get install neofetch

在 Ubuntu 16.10 和更低版本上：

$ sudo add-apt-repository ppa:dawidd0811/neofetch

$ sudo apt update

$ sudo apt install neofetch

在 NixOS 上：

$ nix-env -i neofetch

使用 Neofetch 顯示 Linux 系統信息 ​

Neofetch 非常簡單直接。讓我們看一些例子。

打開終端，然後運行以下命令：

$ neofetch

使用 Neofetch 顯示 Linux 系統信息

正如你在上面的輸出中所看到的，Neofetch 顯示了我的 Arch Linux 系統的以下詳細信息：

  • 已安裝操作系統的名稱，
  • 筆記本型號，
  • 內核詳細信息，
  • 系統運行時間，
  • 默認和其他軟件包管理器安裝的軟件數量
  • 默認 shell，
  • 屏幕分辨率，
  • 桌面環境，
  • 窗口管理器，
  • 窗口管理器的主題，
  • 系統主題，
  • 系統圖標，
  • 默認終端，
  • CPU 類型，
  • GPU 類型，
  • 已安裝的內存。

Neofetch 還有很多其他選項。我們會看到其中一些。

如何在 Neofetch 輸出中使用自定義圖像？ ​

默認情況下，Neofetch 將顯示你的操作系統 logo 以及系統信息。當然，你可以根據需要更改圖像。

要顯示圖像，Linux 系統應該安裝以下依賴項：

  1. w3m-img（用於顯示圖像。w3m-img 有時與 w3m 包捆綁在一起），
  2. Imagemagick（用於創建縮略圖），
  3. 支持 \033[14t 或者 xdotool 或者 xwininfo + xprop 或者 xwininfo + xdpyinfo 的終端。

大多數 Linux 發行版的默認倉庫中都提供了 W3m-img 和 ImageMagick 包。因此，你可以使用你的發行版的默認包管理器來安裝它們。

例如，運行以下命令在 Debian、Ubuntu、Linux Mint 上安裝 w3m-img 和 ImageMagick：

$ sudo apt install w3m-img imagemagick

以下是帶 w3m-img 支持的終端列表：

  1. Gnome-terminal，
  2. Konsole，
  3. st，
  4. Terminator，
  5. Termite，
  6. URxvt，
  7. Xfce4-Terminal，
  8. Xterm

如果你的系統上已經有了 kitty、Terminology 和 iTerm，那麼就無需安裝 w3m-img。

現在，運行以下命令以使用自定義圖像顯示系統信息：

$ neofetch --w3m /home/sk/Pictures/image.png

或者，

$ neofetch --w3m --source /home/sk/Pictures/image.png

示例輸出：

或者，你可以指向包含以下圖像的目錄。

$ neofetch --w3m <path-to-directory>

配置 Neofetch ​

當我們第一次運行 Neofetch 時，它默認會為每個用户在 $HOME/.config/neofetch/config.conf 中創建一個配置文件。它還會在 $HOME/.config/neofetch/config 中創建一個全局的 neofetch 配置文件。你可以調整此文件來告訴 neofetch 該顯示、刪除和/或修改哪些詳細信息。

還可以在不同版本中保留此配置文件。這意味着你只需根據自己的喜好自定義一次，並在升級到更新版本後使用相同的設置。你甚至可以將此文件共享給你的朋友和同事，使他擁有與你相同的設置。

要查看 Neofetch 幫助部分，請運行：

$ neofetch --help

就我測試的 Neofetch 而言，它在我的 Arch Linux 系統中完美地工作。它是一個非常方便的工具，可以在終端中輕鬆快速地打印系統的詳細信息。
