可以買到 Linux 電腦的 10 個地方 ​

你在找 Linux 筆記本嗎? 這裏列出一些出售 Linux 電腦或者是專注於 Linux 系統的電商。

如今市面上幾乎所有的電腦（蘋果除外）都預裝了 Windows 系統。Linux 使用者的慣常做法就是買一台這樣的電腦，然後要麼刪除 Windows 系統並安裝 Linux，要麼安裝 Linux 和 Windows 的雙系統。

但 Windows 系統並非無法避免。你其實也可以買到 Linux 電腦。

不過，既然可以輕鬆地在任何一台電腦上安裝 Linux，為什麼還要買一台預裝了 Linux 的電腦呢？下面列舉幾個原因：

  • 預裝 Windows 系統意味着你額外支付了 Windows 許可證的費用。你可以節省這筆開銷。
  • 預裝 Linux 的電腦都經過了硬件適配測試。你不需要擔心繫統無法正常運行 WiFi 或者藍牙，也不再需要親自去搞定這些事情了。
  • 購買 Linux 電腦相當於間接地支持了 Linux。更多的銷售額可以反應出對 Linux 產品的需求，也就可能會有更多商家提供 Linux 作為一種可以選擇的操作系統。

如果你正想買一台 Linux 的筆記本，不妨考慮一下我的建議。下面這些製造商或者商家都提供開箱即用的 Linux 系統。

可以買到 Linux 筆記本或者台式機的 10 個地方 ​

在揭曉這個提供預裝 Linux 電腦的商家的清單之前，需要先聲明一下。

請根據你的獨立決策購買。我在這裏只是簡單地列出一些售賣 Linux 電腦的商家，並不保證他們的產品質量、售後服務等等這些事情。

這也並不是一個排行榜。清單並不是按照某個特定次序排列的，每一項前面的數字只是為了方便計數，而並不代表名次。

讓我們看看你可以在哪兒買到預裝 Linux 的台式機或者筆記本吧。

1、戴爾 ​

戴爾提供 Ubuntu 筆記本已經有好幾年了。他們的旗艦產品 XPS 系列的亮點之一就是預裝了 Ubuntu 的開發者版本系列產品。

如果你讀過我的 戴爾 XPS Ubuntu 版本評測就知道我是很喜歡這款筆記本的。兩年多過去了，這個筆記本依然狀況良好，沒有性能惡化的跡象。

戴爾 XPS 是售價超過 1000 美元的昂貴設備。如果你的預算沒有這麼多，可以考慮戴爾更加親民的 Inspiron 系列筆記本。

值得一提的是，戴爾並沒有在它的官網上展示 Ubuntu 或者 Linux 筆記本產品。除非你知道戴爾提供 Linux 筆記本，你是不會找到它們的。

所以，去戴爾的官網上搜索關鍵字 “Ubuntu” 來獲取預裝 Ubuntu 的產品的信息吧。

支持範圍：世界上大部分地區。

  • 戴爾

2、System76 ​

System76 是 Linux 計算機世界裏的一個響亮的名字。這家總部設在美國的企業專注於運行 Linux 的高端技術設備。他們的目標用户羣體是軟件開發者。

最初，System76 在自己的機器上提供的是 Ubuntu 系統。2017 年，他們發佈了屬於自己的 Linux 發行版，基於 Ubuntu 的 Pop!_OS。從此以後，Pop!_OS 就是他們機器上的默認操作系統了，但是仍然保留了 Ubuntu 這個選擇。

除了性能之外，System76 還格外重視設計。他們的 Thelio 系列台式機 採用純手工木製設計。

你可以在 這裏 查看他們提供的 Linux 筆記本。他們同時也提供 基於 Linux 的迷你電腦 和 服務器。

值得一提的是，System76 在美國製造他們的電腦，而沒有使用中國大陸或者台灣這種常規的選擇。也許是出於這個原因，他們產品的售價較為高昂。

支持範圍：美國以及其它 60 個國家。在美國境外可能會有額外的關税。更多信息見這裏.

  • System76

3、Purism ​

Purism 是一個總部設在美國的企業，以提供確保數據安全和隱私的產品和服務為榮。這就是為什麼 Purism 稱自己為 “效力社會的公司”。

Purism 是從一個眾籌項目開始的，該項目旨在創造一個幾乎沒有任何專有軟件的高端開源筆記本。2015年，從這個 成功的 25 萬美元的眾籌項目 中誕生了 Librem 15 筆記本。

後來 Purism 發佈了一個 13 英寸的版本 Librem 13。Purism 還開發了一個自己的 Linux 發行版 Pure OS，該發行版非常注重隱私和安全問題。

Pure OS 在台式設備和移動設備上都可以運行，並且是 Librem 筆記本和Librem 5 Linux 手機 的默認操縱系統。

Purism 的零部件來自中國大陸、台灣、日本以及美國，並在美國完成組裝。他們的所有設備都有可以直接關閉的硬件開關，用來關閉麥克風、攝像頭、無線連接或者是藍牙。

支持範圍：全世界範圍國際免郵。可能需要支付額外的關税。

  • Purism

4、Slimbook ​

Slimbook 是一個總部設在西班牙的 Linux 電腦銷售商。Slimbook 在發行了 第一款 KDE 品牌筆記本之後成為了人們關注的焦點。

他們的產品不僅限於 KDE Neon。他們還提供 Ubuntu、Kubuntu、Ubuntu MATE、Linux Mint 以及包括 Lliurex 和 Max 這樣的西班牙發行版。你也可以選擇 Windows（需要額外付費）或者不預裝任何操作系統。

Slimbook 有眾多 Linux 筆記本、台式機和迷你電腦可供選擇。他們另外一個非常不錯的產品是一個類似於 iMac 的 24 英寸 擁有內置 CPU 的曲面顯示屏。

想要一台水冷 Linux 電腦嗎？Slimbook 的 Kymera Aqua 是合適之選。

支持範圍：全世界範圍，不過在郵費和關税上都可能產生額外費用。

  • Slimbook

5、TUXEDO ​

作為這個 Linux 電腦銷售商清單裏的另一個歐洲成員，TUXEDO 總部設在德國，主要服務德國用户，其次是歐洲用户。

TUXEDO 只使用 Linux 系統，產品都是“德國製造”，並且提供 5 年保修和終生售後支持。

TUXEDO 在 Linux 系統的硬件適配上下了很大功夫。並且如果你遇到了麻煩或者是想從頭開始，可以通過系統恢復選項，自動恢復出廠設置。

TUXEDO 有許多 Linux 筆記本、台式機和迷你電腦產品可供選擇。他們還同時支持 Intel 和 AMD 的處理器。除了電腦，TUXEDO 還提供一系列 Linux 支持的附件，比如擴展塢、DVD 和藍光刻錄機、移動電源以及其它外圍設備。

支持範圍：150 歐元以上的訂單在德國和歐洲範圍內免郵。歐洲外國家會有額外的運費和關税。更多信息見 這裏.

  • TUXEDO

6、Vikings ​

Vikings 的總部設在德國（而不是斯堪的納維亞半島，哈哈）。Vikings 擁有自由軟件基金會的認證，專注於自由友好的硬件。

Vikings 的 Linux 筆記本和台式機使用的是 coreboot 或者 Libreboot，而不是像 BIOS 和 UEFI 這樣的專有啓動系統。你還可以購買不運行任何專有軟件的 硬件服務器。

Vikings 還有包括路由器、擴展塢等在內的其它配件。他們的產品都是在德國組裝完成的。

支持範圍：全世界（除了朝鮮）。非歐洲國家可能會有額外關税費用。更多信息見這裏。

  • Vikings

7、Ubuntushop.be ​

不不！儘管名字裏有 Ubuntu，但這不是官方的 Ubuntu 商店。Ubuntushop 總部位於比利時，最初是銷售安裝了 Ubuntu 的電腦。

如今，你可以買到預裝了包括 Mint、Manjaro、elementrayOS 在內的 Linux 發行版的筆記本電腦。你還可以要求所購買的設備上安裝你所選擇的發行版。

Ubuntushop 的一個獨特之處在於，它的所有電腦都帶有默認的 Tails OS live 選項。即使你安裝了某個其它的 Linux 發行版作為日常使用的系統，也隨時可以選擇啓動到 Tails OS（不需要使用 live USB）。Tails OS 是一個基於 Debian 的發行版，它在用户註銷後會刪除所有使用痕跡，並且在默認情況下使用 Tor 網絡。

和此列表中的許多其他重要玩家不同，我覺得 Ubuntushop 所提供的更像是一種“家庭工藝”。商家手動組裝一個電腦，安裝 Linux 然後賣給你。不過他們也在一些可選項上下了功夫，比如説輕鬆的重裝系統，擁有自己的雲服務器等等。

你可以找一台舊電腦快遞給他們，就可以變成一台新安裝 Linux 的電腦，他們就會在你的舊電腦上安裝 輕量級 Linux 系統然後快遞回來，這樣你這台舊電腦就可以重新投入使用了。

支持範圍：比利時以及歐洲的其它地區。

  • Ubuntushop.be

8、Minifree ​

Minifree，是自由部門Ministry of Freedom的縮寫，他們是一家註冊在英格蘭的公司。

你可以猜到 Minifree 非常注重自由。他們提供安全以及注重隱私的電腦，預裝 Libreboot 而不是 BIOS 或者 UEFI。

Minifree 的設備經過了 自由軟件基金會 的認證，所以你可以放心買到的電腦都遵循了自由開源軟件的指導規則。

和這個清單中許多其它 Linux 筆記本銷售商不同，Minifree 的電腦並不是特別貴。花 200 歐元就可以買到一台預裝了 Libreboot 和 Trisquel GNU/Linux 的 Linux 電腦。

除了筆記本以外，Minifree 還有一系列的配件，比如 Libre 路由器、平板電腦、擴展塢、電池、鍵盤、鼠標等等。

如果你和 Richard Stallman 一樣，希望只運行 100% 自由的軟件的話，Minifree 就再適合不過了。

支持範圍：全世界。運費信息見 這裏。

  • Minifree

9、Entroware ​

Entroware 是另一個總部設在英國的銷售商，專注基於 Linux 系統的筆記本、台式機和服務器。

和這個清單裏的很多其它商家一樣，Entroware 也選擇 Ubuntu 作為 Linux 發行版。Ubuntu MATE 也是 Entroware Linux 筆記本的一種可選系統.

除了筆記本、台式機和服務器之外，Entroware 還擁有自己的 迷你電腦 Aura，以及一個 iMac 風格的內置 CPU 的顯示器 Ares.

支持範圍: 英國、愛爾蘭、法國、德國、意大利、西班牙。

  • Entroware

10、Juno ​

這是我們清單上的一個新的 Linux 筆記本銷售商。Juno 的總部同樣設在英國，提供預裝 Linux 的電腦。可選擇的 Linux 發行版包括 elementary OS、Ubuntu 和 Solus OS。

Juno 提供一系列的筆記本，以及一款叫做 Olympia 迷你電腦。和列表裏其它商家提供的大多數迷你電腦一樣，Olympia 也基本上相當於一個 Intel NUC。

Juno 的主要特色是 Juve，一款售價 299 美元的 Chromebook 的低成本替代品。它運行一個雙系統，包括 Solus 或者 elementray，以及一個基於安卓的電腦操作系統 Prime OS。

支持範圍：英國、美國、加拿大、墨西哥、南美和歐洲的大部分地區、新西蘭、亞洲和非洲的某些地區。更多信息見 這裏。

  • Juno Computers

榮譽獎 ​

我列舉了 10 個可以買到 Linux 電腦的地方，但其實還有一些其它類似的商店。清單裏放不下這麼多，並且它們其中的幾個似乎大多數商品都缺貨。不過我還是要在這裏稍微提一下它們，方便你自己查找相關信息：

  • ZaReason
  • Libiquity
  • StationX
  • Linux Certified
  • Think Penguin

包括宏碁和聯想在內的其它主流電腦生產商可能也有基於 Linux 系統的產品，所以你不妨也查看一下他們的產品目錄吧。
