優麒麟：Ubuntu 的官方中文版本 ​

讓我們來看看國外是如何看優麒麟的。

Ubuntu 有幾個官方特色版本，優麒麟（Ubuntu Kylin）是它們中的一個。在這篇文章中，你將瞭解到優麒麟，它是什麼，它為什麼被創建，它的特色是什麼。

麒麟操作系統最初由中華人民共和國的國防科技大學的院士在 2001 年開發。名字來源於麒麟，這是一種來自中國神話的神獸。

麒麟操作系統的第一個版本基於 FreeBSD，計劃用於中國軍方和其它政府組織。麒麟 3.0 完全基於 Linux 內核，並且在 2010 年 12 月發佈一個稱為 NeoKylin 的版本。

在 2013 年，Canonical (Ubuntu 的母公司) 與中華人民共和國的工業和信息化部 達成共識，共同創建和發佈一個針對中國市場特色的基於 Ubuntu 的操作系統。

優麒麟是什麼? ​

根據上述 2013 年的共識，優麒麟現在是 Ubuntu 的官方中國版本。它不僅僅是語言本地化。事實上，它決心服務中國市場，就像 Ubuntu 服務全球市場一樣。

優麒麟的第一個版本與 Ubuntu 13.04 一起到來。像 Ubuntu 一樣，優麒麟也有 LTS （長期支持）和非 LTS 版本。

當前，優麒麟 19.04 LTS 採用了 UKUI 桌面環境，修改了啓動動畫、登錄/鎖屏程序和操作系統主題。為給用户提供更友好的體驗，它修復了一些錯誤，帶有文件預覽、定時註銷等功能，最新的 WPS 辦公組件和 搜狗 輸入法集成於其中。

  • https://youtu.be/kZPtFMWsyv4

銀河麒麟 4.0.2 是一個基於優麒麟 16.04 LTS 的社區版本。它包含一些帶有長期穩定支持的第三方應用程序。它非常適合服務器和日常桌面辦公使用，歡迎開發者下載。麒麟論壇積極地獲取來自提供的反饋以及解決問題來找到解決方案。

UKUI：優麒麟的桌面環境 ​

UKUI 由優麒麟開發小組設計和開發，有一些非常好的特色和預裝軟件：

  • 類似 Windows 的交互功能，帶來更友好的用户體驗。安裝導向易於使用，用户可以快速使用優麒麟。
  • 控制中心對主題和窗口採用了新的設置。如開始菜單、任務欄、文件管理器、窗口管理器和其它的組件進行了更新。
  • 在 Ubuntu 和 Debian 存儲庫上都可用，為 Debian/Ubuntu 發行版和其全球衍生版的的用户提供一個新單獨桌面環境。
  • 新的登錄和鎖定程序，它更穩定和具有很多功能。
  • 包括一個反饋問題的實用的反饋程序。

麒麟軟件中心 ​

麒麟有一個軟件中心，類似於 Ubuntu 軟件中心，並被稱為優麒麟軟件中心。它是優麒麟軟件商店的一部分，該商店也包含優麒麟開發者平台和優麒麟存儲庫，具有一個簡單的用户界面，並功能強大。它同時支持 Ubuntu 和優麒麟存儲庫，並特別適用於由優麒麟小組開發的中文特有的軟件的快速安裝！

優客：一系列的工具 ​

優麒麟也有一系列被命名為優客的工具。在麒麟開始菜單中輸入 “Youker” 將帶來麒麟助手。如果你在鍵盤上按 “Windows” 按鍵，像你在 Windows 上一樣，它將打開麒麟開始菜單。

其它麒麟品牌的應用程序包括麒麟影音（播放器）、麒麟刻錄，優客天氣、優客 Fcitx 輸入法，它們更好地支持辦公工作和個人娛樂。

特別專注於中文 ​

通過與金山軟件合作，優麒麟開發者也致力於 Linux 版本的搜狗拼音輸入法、快盤和優麒麟版本的金山 WPS，並解決了智能拼音、雲存儲和辦公應用程序方面的問題。拼音 是中文字符的拉丁化系統。使用這個系統，用户用英文鍵盤輸入，但在屏幕上將顯示中文字符。

有趣的事實：優麒麟運行在中國超級計算機上 ​

眾所周知世界上最快的超級計算機 500 強都在運行 Linux。中國超級計算機天河-1和天河-2都使用優麒麟的 64 位版本，致力於高性能的並行計算優化、電源管理和高性能的虛擬化計算。

總結 ​

我希望你喜歡這篇優麒麟世界的介紹。你可以從它的官方網站獲得優麒麟 19.04 或基於 Ubuntu 16.04 的社區版本（銀河麒麟）。
