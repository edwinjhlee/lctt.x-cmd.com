Linux 9大 Podcast ​

簡介 ​

去年，我寫了一篇叫“Linux 的 Podcasts 和雜誌”，在其中，我列出了一些有關 Linux 的最好的 Podcasts 和雜誌。回看那篇文章，我感覺它本來可以列出更多，因為現在有許許多多的 Podcasts 配得上那個稱號。

下面的這個列表列出的是我最喜歡的基於 Linux 的 podcasts。排名不分次序，我認為它們都有各有特點。

現在你肯能會認為只有9個會有點奇怪，為什麼不是10個呢？當然所有這些事情都是10個10個地出現。那麼如果我加上第十個，那麼這就不再是一個貨真價實的列表了，因為我只有聽過9個 Podcasts。但是，你們不要猶豫在評論欄里加上你們自己的 Podcast。

1. Linux Action Show ​

官網：http://www.jupiterbroadcasting.com/tag/linux-action-show/

The Linux action show 由 Chris Fisher 和 Matt Hartley 來主持。

你可以在線觀看節目又或者下載或收聽 MP3 格式的節目。

他們的節目都非常有趣，並且主持們都非常樂觀和熱情。

節目包括新聞、精選、回饋和一個特色主題。

同時節目還包括髮掘 Linux 社區所發生的事情，並且你還會聽到你以前從來都沒有聽過的軟件。

節目的時間相對比較長，持續接近 2 個小時。這是一個非常適合你在工作時候收聽的好節目。

2. Linux Unplugged ​

官網：http://www.jupiterbroadcasting.com/show/linuxun/

我沒有騙你，這又是與他們兩個有關。

只不過 Linux Unplugged 是 Linux Action Show 的不太正式版，同時 Chris 和 Matt 希望在 Linux 環境之外嘗試新的東西。嘉賓和聊天室用户可用在節目中直接地互動。

看直播遠比看重播要爽，同樣，他們也會在每個星期傳遞相同的信息。

3. The Linux Link Tech Show ​

官網：http://tllts.org/

The Linux Link Tech Show 是一個不算很正式的節目，基本上，他是由一羣討論有關常見的 Linux 和生活的人組成的。

同樣這個節目也大概持續 2 個小時，並且比聽嘰嘰喳喳的 DJ 談論他們上星期喝得多醉有趣得多。

根據網站，主持每個星期都會有稍微的不同，他們有 Linc，Dann，Allan，Pat，Rich，Dan 和 Davey。

我聽了他們上一期的節目，他們討論了有關 Linux，GNU/Linux 等等的內容。當然，他們在下一期的節目中也會是不斷地討論討論討論。

4. Everyday Linux ​

官網：http://elementopie.com/everyday-linux-episodes

Everyday Linux 是由 Seth Anderson，Chirs Neves 和 Mark Cockrell 主持，並且討論與 Linux 有關和一些非 Linux 的話題。

同樣，節目時常大約 2 小時，內容涵蓋 Linux 新聞，發行版和軟件。

在上一期節目中，他們談論了有關 Plex 的文章，專利流氓和一個懷舊遊戲網站。在其中一節，一個傢伙談論了 Linux 在這一年是否完成了它的一些目標。

許多的討論都是關於 Linux 當經是否在市場上佔主導位置，並且是否包含台式電腦。沒有人能決定 ChromeOS 和 Android 是否只使用 Linux 作為基礎和我們應該使用 Linux，GNU/Linux 等等哪一種術語的古老的題目。

我經常在一些文章末尾得到一些評論，指明發行版並不是操作系統，它是發行版又或者 Linux 不是一個操作系統，GNU/Linux 才是。這看來似乎是永不結束的討論。

在好幾個月之前，我很幸運我能夠以嘉賓的身份在 Everyday Linux podcast 中登場。

5. Going Linux ​

官網：http://goinglinux.com/

Going Linux是由 Larry Bushey 和 Bill Smith 主持。

這節目顯得更加的正式，並且主持們對於 Linux 都有很深厚的認識。

節目大部分的時間都是由大眾來提問題，然後主持們儘可能簡潔地回答他們的問題。

這個節目非常值得收聽，因為通過它你至少能夠學到一點東西。

它比之前的節目平均要短 40 分鐘。

6. Ubuntu UK Podcast ​

官網：http://podcast.ubuntu-uk.org/

Ubuntu UK Podcast 是一個英國的 Podcast，由 Laura Cowen，Mark Johnson 和 Alan Pope 主持。

這個節目會快速地調侃一下有關 Linux 的事情，但是大多時間都是關於 Ubuntu。

節目開始是一些普通 Linux 新聞的摘要，然後接着就是有關 Ubuntu 的信息。

通常節目中都會有一個特色環節，並邀請嘉賓，輔導和命令列愛好者。完事之後會有一個反饋環節。

節目通常只有 30 分鐘，你會覺得時間過得飛一般快。

7. Linux Outlaws ​

官網：http://sixgun.org/linuxoutlaws

由 Fabian Scherschal 和 Dan Lynch 主持的 Linux Outlaws，是最具娛樂氣氛的 Podcast 之一。

你必須做好準備，因為你隨時都會聽到一連串的不雅用語，我説的是隨時都會聽到。

就像一些很好的搭檔一樣，那裏有滑稽的配角和戲劇演員。Dan 扮演配角，而 Fab 則扮演戲劇天才。

節目時長從 1 小時到 2 個半小時不等。

節目通常會談論過去一個星期有關 Linux 的新聞，其中覆蓋了從發行到信息安全等各方面的內容。

絕對值得收聽，尤其如果你不是一個特別容易被冒犯的人。

8. Linux Luddites ​

官網：http://linuxluddites.com/

Linux Luddites 是另外一個英國的 Podcast，由 Joe 和 Paddy 主持。

我在上星期只聽過一次他們的節目，但卻印象深刻。

節目內容包括這個星期的新聞（如果你像我一樣收聽多個 Podcasts，那你完全可以總結出聽過數遍相同的信息之後會怎麼樣），簡單地討論從 Distrowatch 獲取的發行版，反饋，等等。

在節目中我聽到了以一個新用户角度來看 Debian 且相當深入的內容。

他的觀點是關於讓人迷惑的 Debian 網站，安裝包和其他 Debian 的特色。

9. Mintcast ​

官網：http://mintcast.org/

Mintcast 是由 Rob，Scott 和 James 主持的並且與 Ubuntu UK Podcast 非常相像的 Podcast，不過他主要面向的是 Mint 的用户。

節目內容包括新聞和常見的特色環節例如談論 LXDE 或 XFCE 等等。

我必須承認的是我並沒有常常收聽這個 Podcast 因為我不是一個 Mint 的用户。

總結 ​

Podcasts 更多的是娛樂和推送新聞，並且相對於收聽普通的收音機，我更寧願選擇收聽 Podcasts。

感謝閲讀！
