在 Linux 下用 mkdir 命令來創建目錄和子目錄 ​

瞭解了用 ls 命令在目錄中列出條目後，現在我們要學習在 Linux 系統下創建目錄。在 Linux 下，我們可以使用 mkdir 命令。Mkdir 是“make directory” 的縮寫詞。

mkdir 是什麼呢 ​

Mkdir 是一個用來在 Linux 系統下創建目錄的命令。此命令屬於內建命令。

運行 mkdir 命令### ​

你可以在你的控制台直接鍵入 mkdir 來使用它。

$ mkdir

默認情況下，不帶任何參數運行 mkdir 命令會在當前目錄下創建目錄。下面是參考示例：

從上圖看出，我們創建了名為 office 的目錄。當我們運行 mkdir 命令時，我們位於 /home/pungki 目錄。所以這個新目錄 office 創建在/home/pungki目錄下。如果我們使用絕對路徑 - 例如：/usr/local - , 則 Linux 會在 /usr/local目錄下創建一個目錄。

當 Linux 發現想要創建的目錄已經存在, 那麼 Linux 會提示我們 Linux 無法創建它。

另外一個創建目錄的首要條件是， 在想要創建目錄的目標路徑下你必須具有訪問權限。當你無法取得權限時 mkdir 會報告這個錯誤。

創建多個目錄 ​

我們也可以同時創建多個目錄。比如我們要創建的目錄有 ubuntu, redhat 和 slackware。那麼語法會像這樣子:

$ mkdir ubuntu redhat slackware

添加包含子目錄的目錄 [譯註：遞歸地創建目錄] ​

當你要創建的目錄包含子目錄時，你需要使用 -p 參數。如果 mkdir 找不到父目錄，那麼這個參數會首先幫助創建父目錄。比如説我們要創建名為 letter 的目錄，在它的目錄下包含有子目錄 important。那麼語法會像這樣子：

$ mkdir -p letter/important

設置訪問權限 ​

使用 -m 參數，我們可以給即將生成的新目錄設置權限。示例如下：

$ mkdir -m=r-- letter

上面的命令會創建一個名為 letter 的目錄，同時為目錄所有者、用户組和其他用户針對該目錄賦予只讀權限

打印創建目錄的過程信息 ​

如果我們要查看信息，我們可以使用 -v 參數來實現。示例如下：

$ mkdir -v ubuntu redhat slackware

總結 ​

Mkdir 命令也屬於一個最基礎的命令，對於想要學習 Linux 的朋友這個命令必須掌握。像往常一樣，你可以鍵入man mkdir或mkdir --help來顯示 mkdir 的手冊頁面和更加深入的探討。
