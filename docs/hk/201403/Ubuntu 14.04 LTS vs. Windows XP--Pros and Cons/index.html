對決：Ubuntu 14.04 LTS 大戰 Windows XP ​

越來越多的人期待着 Ubuntu 14.04 LTS (Trusty Tahr) 的發佈，並希望她能在不改變用户習慣的前提下替代 Windows XP。 因此我們將在本文嘗試給大家分析下這個兩個系統的優缺點。

很多 Windows XP 用户在微軟宣佈四月份後即將停止對他們的操作系統提供安全更新後作出改變。他們像大多數改用 Linux 的用户一樣，有着大量的系統操作和兼容性方面各式各樣的問題。而事實是這些原 XP 用户可能顧慮太多了，理由如下：

安裝 ​

如果你在一生中哪怕就裝過一次 Windows，祝賀你，因為你已經知道該如何安裝 Ubuntu 這類的系統了。Ubuntu 為用户提供了一個很直觀而且沒有太多複雜選項的安裝界面。

唯一可能會使你疑惑的就是系統分區時出現的大量陌生詞彙了，比如“交換空間(swap)”和“EXT4文件系統”。不過好消息是在 Linux 下你或許永遠不需要多個分區了。

Ubuntu 安裝

驅動 ​

Windows 用户需要為新的硬件安裝驅動，比方説聊天時用的攝像頭。 某些驅動或許會由系統提供，但大多數的仍需要手動安裝。

在 Ubuntu 的驅動問題上，唯一可能需要擔心的就是顯卡驅動了。 首先你可能不清楚應該從哪裏改變現有驅動，而安裝一個新的驅動可能需要一些調整。 然而這剛好是你學習如何添加一個 PPA 源以及更新你的軟件包的好時機，而且這些操作都輕而易舉。

安裝私有驅動

主界面 ​

Ubuntu 在整體界面上還是和 Windows XP 有些區別的。儘管她更直觀，但總有些偷懶的用户還是會放棄探索如何使用這個新系統的精彩時光。

不過呢 Ubuntu 依然可以為這些“懶”用户們提供幾種看起來更像 Windows XP 的衍生版本，比如 Xubuntu 和 Lubuntu。 她們都是基於 Ubuntu 的而且提供基本相同的軟件。

Ubuntu 桌面

應用與安全 ​

或許你會覺得在 Windows XP 上安裝程序很容易。 不是麼？就雙擊一個安裝程序，然後狂按下一步（包括壓根沒人讀的那份最終用户許可協議），一個程序就這麼裝上了。

Ubuntu 下事情其實更簡單。只要打開 Ubuntu 軟件中心然後搜索你想要的應用，最後輕輕按下安裝，一切搞定！

有些情況下在 Windows XP 上安裝程序會很危險，尤其是在微軟終止提供安全補丁以後。 在 Ubuntu 上你將很難再見到你身邊的那堆病毒和流氓軟件，即使有病毒在 Linux 上出現也將非常短命。 只要程序有任何一個問題出現，立即就會有開發人員釋出補丁並修復。

不過呢，在 Ubuntu 上你也許不大可能會找全你在 Windows XP 上曾經用過的所有軟件。 但大部分知名軟件商都會提供 Linux 版本，不但如此你還可以在 Ubuntu 上找尋更多的相似軟件予以替代。

使用 Ubuntu 軟件中心安裝應用

遊戲 ​

也許 Windows XP 看起來更適合玩遊戲，但事實是大多數遊戲開發者將放棄去兼容一個即將消亡的系統。 而且 Valve 將進一切力量去支持 Linux 平台並將整個遊戲產業推向這個方向。

Linux 版 Steam 僅推出一年時間就有 500 多個遊戲上線而且這個趨勢沒有任何下降的跡象。 再過幾年，在遊戲方面 Linux 平台必將趕超 Windows。 所以現在就開始熟悉 Ubuntu 吧，如果你是個出色的玩家，就絕不應該放棄這個機會。

Linux 版《傳送門 2》

結論 ​

如果你是一個 Windows XP 用户但對使用 Linux 和 Ubuntu 有任何顧慮，建議你在升級到 Windows 7 或 8 之前再三考慮。 Linux 有所有你需要的功能，沒有任何理由不去使用一個基於她的操作系統。
