10 大必備 Ubuntu 應用：必備篇 ​

本文列出了 2022 年可以用於日常工作的 10 個 Ubuntu 必備應用。

我們經常忘記，有成千上萬的、可以與同類商業產品相媲美的自由開源應用。此外，若你是 Windows 用户，並考慮完全擺脱 Windows ，你也應該事先了解此類應用程序。

因此，在這篇“必備的 Ubuntu 應用”文章中，我們為急需這些信息的 Linux 用户列舉了 10 款應用。

這是這個系列的第三篇文章，如果你錯過了之前的文章，可以通過以下鏈接閲讀：

  • 第一篇
  • 第二篇

Guake ​

你是否想要在處理重要工作時使用快捷鍵打開一個終端？這款下拉式的終端程序 Guake 能夠幫你實現。如果你正忙於寫文章、剪輯視頻、在你最喜歡的代碼編輯器中寫代碼，並想要快速用終端檢查一些東西並返回到工作中，Guake 能夠幫助你。只用按 F12 終端就會立即出現，再次按 F12 它會消失，不用打開或關閉不同的終端。

在 Ubuntu 或其他發行版，你可以使用以下命令安裝。如需更多下載選項，請訪問 此頁面。

sudo apt install guake

  • 源碼

Safe Eyes ​

眼睛很寶貴，如果你是長時間使用平板或電腦的用户，你應該保護好眼睛。這裏有一款可以幫助你保護眼睛的應用 —— Safe Eyes ，能夠幫你減少並預防用眼過度。

Safe Eyes 這款應用會在你的工作期間為你提供“順時針轉動眼睛 10 秒”等活動的彈出式指令。

我認為它是每個人都應該嘗試使用的一款 Ubuntu 應用。

通過 PPA 可以很容易在 Ubuntu 上安裝 Safe Eyes 。你可以打開終端並使用以下命令安裝這款應用。

sudo add-apt-repository ppa:slgobinath/safeeyessudo apt updatesudo apt install safeeyes

更多下載選項，請訪問 此頁面。

Tusk ​

筆記應用有很多。雖然，包括 Ubuntu 在內的所有 Linux 發行版，都帶有一個基礎文本編輯器，但是想要高級的筆記功能，你需要一個專業應用。

Tusk 是適用於 Ubuntu/Linux 的新款印象筆記式桌面應用程序。它帶有大量主題，例如淺色、深褐色和深色。它具有以下功能：

  • 本地和全局自定義快捷鍵
  • 更新通知
  • 基於 Electron 的跨平台應用
  • 可伸縮的界面（放大和縮小）
  • 淺色、深褐色和深色主題
  • 聚焦模式和自動夜間模式
  • 將筆記導出為 HTML、PDF 和 Markdown 格式

該應用有用於 Linux 發行版的 AppImage 、Deb 和 RPM 文件等格式。你可以從以下鏈接下載 deb 文件並運行它以在 Ubuntu 中安裝它。有關其他下載選項，請訪問 此頁面。

下載 Tusk

Krita ​

如果你是一個藝術家並想在 Linux 上學習繪畫，那你一定要用 Krita 。Krita 擁有眾多繪畫工具，包含諸如壓感式繪畫等高級模式。此外，你也可以在觸屏設備上使 Krita 。它包含一些獨特的功能：

  • 自定義工具欄和停靠欄
  • 將工作區另存為文件
  • 深淺主題
  • 內置矢量引擎，海量畫筆
  • 帶穩定功能的畫筆引擎
  • 支持 PhotoShop 文件（PSD）
  • 支持全色系
  • 支持 Python 腳本擴展

在所有的 Linux 發行版的官方倉庫都有 Krita ，所以很容易安裝。在 Ubuntu 中，你可以在應用商店裏搜索並安裝。如果你更喜歡使用終端安裝，可以運行如下指令：

sudo apt install krita

Foliate ​

當你想到電子書閲讀器時，總是會想到 Calibre 。不過還有一款傑出的 GNOME 應用 —— Foliate 。Foliate 是用 GTK 編寫的新穎的電子書閲讀器，它帶來了令人讚歎的功能，例如自定義頁面的顏色、亮度、多欄支持等等。此外，它還支持 Epub、Amazon Kindle、FictionBook、CBA 和 Mobipocket 格式，讓你完全控制自己的收藏。

如果你想要一個漂亮而優美的電子書閲讀器，非它莫屬。

使用 Linux 發行版的 Flatpak 安裝 Foliate 很容易。首先，你需要 設置 Flatpak 並單擊下方鏈接進行安裝。

下載 Foliate

Bitwarden ​

平均而言，每個人至少有十幾個在線賬號和密碼。你越是精通技術，那麼你管理密碼的數量就會越多。使用密碼管理器能夠更好的保護你的數據以及密碼。那麼接下來這款應用，Bitwarden，是當今最好的管理密碼的應用。

Bitwarden 是一款自由開源的密碼管理器，能夠輕鬆幫助你生成、存儲並保存密碼。在 AES-256 加密的支持下，Bitwarden 能夠在不同設備，比如手機和平板自動同步密碼。

你可以從 此頁面 下載可執行安裝包文件。此外，如果你打算在你最喜歡的瀏覽器中使用它，也可以在該頁面中獲取擴展。

Brave Browser ​

Brave 是一款基於 Chromium 的以隱私為中心的瀏覽器。它非常適合希望完全控制其在線活動的用户。Brave 帶有內置廣告攔截器、隱身瀏覽、VPN 和 Tor 模式，可實現更多匿名瀏覽。

最近，Brave 還推出了電子郵件服務，你可以直接從瀏覽器訪問郵件。此外，它具備一些 Firefox 、 Chrome 以及 Safari 所沒有的優點。

在 Ubuntu 終端上安裝這款瀏覽器需要額外的命令。你可以 在此 找到相信的下載教程。

更多詳細信息，請瀏覽官方 主頁 。

Mailspring ​

如果你在找一款好用並高效的 Linux 桌面電子郵件客户端，並且想要它支持所有的電子郵件協議，那你應該試試 Mailspring 。

Mailspring 支持多個賬户、統一郵箱，並且支持觸控和手勢。它還支持微軟 Office 365 ，這是此電子郵件客户端在 Linux 系統中的最大優勢之一。此外，它具有快速檢索、翻譯、取消發送（郵件召回）以及內置的拼寫檢查等特徵，使得它成為最好的郵件客户端之一。

它還有一個付費版本，只需要每月付出少量費用，即可得到更多功能，例如創建公司簡介、鏈接跟蹤、閲讀回執、模板和洞察力功能。專業版中的洞察力功能提供了你在一天中何時收到更多電子郵件的詳細信息。

這款應用可以通過 Snap 和 Deb 文件在 Ubuntu 或其他相關 Linux 上安裝。

訪問官方 Snapcraft 頁面 獲取 Snap 包並安裝。

點擊 這裏 下載 deb 包。下載後，你可以雙擊 deb 文件通過 Ubuntu 應用商店程序安裝。

瀏覽以下鏈接瞭解 Mailspring 更多信息：

Blender ​

我肯定你聽説過 Blender 。 Blender 是一款自由開源的專業級圖形設計軟件，幾乎可以完成你的圖形項目的一切需求。

你可以創建動畫電影、視覺效果、藝術作品、3D 打印模型、動態圖形、交互式 3D 應用程序和計算機遊戲。 Blender 的功能包括 3D 建模、UV 展開、貼圖、光柵圖形編輯、套索和蒙皮、流體和煙霧模擬、粒子模擬、柔體模擬、雕刻、動畫、匹配移動、渲染、運動圖形、視頻編輯和合成。

它是一個專業級的應用程序，還是自由開源的。

想要在 Ubuntu 中輕鬆安裝，打開應用商店，搜索 Blender，然後點擊安裝。或者，你也可以打開終端窗口並運行以下命令進行安裝。

sudo apt install blender

該軟件適用於 Windows、macOS 和其他平台。你可以訪問 官方下載頁面 瞭解更多詳情。

Ungoogled Chromium ​

如果你想要一個沒有谷歌的應用和服務的乾淨瀏覽器，你應該試試 Ungoogled Chromium 瀏覽器。它是一個沒有谷歌集成服務的，提供了原裝 Chromium 體驗的替代品。

例如，它去除了代碼中的所有預編譯二進制文件和所有谷歌集成，並且還禁用了需要手動啓用的功能，以獲得更好控制。

或許一個合適的瀏覽器，才會有最好的 Chromium 體驗。

使用 Flatpak 安裝 Ungoogled Chromium 很容易。首先設置 Flatpak 然後使用下列命令安裝該瀏覽器：

flatpak install flathub com.github.Eloston.UngoogledChromium

瀏覽 官方 GitHub 頁面 獲取該瀏覽器更多信息。

Tilix ​

必備 Ubuntu 應用程序列表中的最後一個應用程序是 Tilix 。Tilix 是一個基於 GTK 的，平鋪式的終端仿真器。它帶有自定義標題、以及通知支持（用於命令補完）和透明背景圖像支持。此外，Tilix 還允許你在終端窗口中添加自定義圖像背景。最後，你可以在一個窗口中並排創建多個終端窗口。

這是一個用 GTK 編寫的高級終端，你可能會發現它很有用。

所有 Linux 發行版上都有它的安裝包。在 Ubuntu 或相關發行版，運行以下命令進行安裝：

sudo apt install tilix

更多信息請瀏覽 Tilix 主頁 。
