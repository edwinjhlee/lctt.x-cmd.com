什麼是霧計算？ ​

瞭解由我們生活中的所有連接設備組成的網絡。

在早期，計算機既笨重又昂貴，計算機用户很少，他們必須在計算機上的預留時間內親自來處理他們的打孔卡punchcard。被稱為 大型機Mainframe 的系統進行了許多創新，並在終端機terminal（沒有自己的 CPU 的桌面計算機）上實現了分時time-shared任務。

時至今日，強大的計算設備能做到 價格低至 35 美元，且大小不超過一張信用卡。這甚至還沒有涵蓋現代生活中負責收集和處理數據的所有小設備。從高層次的角度來看這些計算機的集合，你可以想像得到，所有這些設備多得像雲中的水滴一樣。

碰巧“雲計算cloud computing”一詞已經被佔用，因此需要為由物聯網（IoT）和其他具有戰略意義的服務器組成的網絡提供一個獨特的名稱。此外，如果已經有一個代表數據中心節點的雲，那麼在雲之外與我們交融的這些節點肯定有其獨特之處。

歡迎來到霧計算 ​

雲通過互聯網提供計算服務。構成雲的數據中心很大，但與潛在客户的數量相比相對較少。這表明當數據在雲及其眾多用户之間來回傳送時存在潛在的瓶頸。

相比之下，霧計算Fog Computing可以在數量上超過其潛在客户，而不會出現瓶頸，因為設備執行大部分數據的收集或計算。它是雲的外部“邊緣”，是雲落地的部分。

霧和邊緣計算 ​

霧計算和 邊緣計算edge computing 本質上是同義詞。兩者都與雲和物聯網密切相關，並做出相同的架構假設：

  • 你離 CPU 越近，數據傳輸就越快。
  • 像 Linux 一樣，小型專用計算機，可以“做一件事並把它做好”，這是一個強大的優勢（當然，我們的設備實際上不僅僅做一件事，但從高層次上看，你購買的用於監測健康的智能手錶本質上是在做“一”件事）。
  • 離線是不可避免的，但好的設備可以在此期間同樣有效地運行，然後在重新連接時同步。
  • 本地設備能比大型數據中心更簡單、更便宜。

邊緣網絡 ​

將霧計算視為與雲完全分離的實體很誘人，但它們畢竟是組成一個整體的兩個部分。雲需要數字企業的基礎設施，包括公共雲提供商、電信公司，甚至是運行自己服務的專業公司。本地化服務也很重要，可以在雲核心與其數以百萬計的客户之間提供中轉站waystations。

霧計算位於雲的邊緣，無論客户身在何處，都與他們緊密聯繫在一起。有時這是一個消費環境，例如你自己的家或汽車，而另一些時候這是一種商業利益，例如零售店中的價格監控設備或工廠車間的重要的安全傳感器。

霧計算就在你身邊 ​

霧計算由我們生活中的所有連接設備組成：無人機drone、電話、手錶、健身監視器、安全監視器、家庭自動化、便攜式遊戲設備、園藝自動化、天氣傳感器、空氣質量監視器等等。理想情況下，它提供的數據有助於建立一個更好、更明智的未來。有許多偉大的開源項目正朝着改善健康的方向而努力 —— 甚至只是讓生活變得更有趣一點兒 —— 這一切都得益於霧和雲計算。無論如何，我們的 工作是確保它 保持開放。
