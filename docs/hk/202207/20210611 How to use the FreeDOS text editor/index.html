如何使用 FreeDOS Edit ​

FreeDOS 提供了一個叫做 FreeDOS Edit 的用户友好的文本編輯器。

在任何操作系統中，編輯文件都是一項常有的任務。當你想去做一個某事的筆記、寫封信給朋友或升級一個系統配置 —— 你需要一個文本編輯器。FreeDOS 提供了一個用户友好的文本編輯器（也許沒啥想像力）叫做 “FreeDOS Edit”。

編輯文件 ​

最簡單的啓用 FreeDOS Edit 的方式就就是輸入 EDIT。它提供一個空的編輯器窗口。圖案背景顯示為一個空的“桌面”——提醒你沒有編輯任何文件。

就像多數 DOS 應用程序一樣，你可以按下你鍵盤上的 Alt 鍵來訪問 Edit 的菜單。這就激活了這個菜單。在你按下 Alt 後，Edit 將切換到“菜單”訪問方式，並高亮 “文件File” 菜單。如果你想要訪問菜單欄上的一個不同的菜單，可以使用左右方向鍵。按向下的方向鍵並按下回車鍵來“進入”菜單。

你注意到所有菜單標題的第一個字母是不同的顏色麼？這種高亮字母顯示了一種快捷方式。例如，“文件File”菜單的“F”高亮為紅色。所以你可以按下 Alt+F（Alt 和 F 同時按下），Edit 會顯示“文件File”菜單。

你可以使用“文件File”菜單來開始一個新的（空）文件，或打開一個存在的文件。讓我們開始一個新文件，使用方向鍵移動到“新建New“然後按下回車鍵。你也可以用 Ctrl+N （Ctrl 和 N 同時按下）打開一個新文件。

此後，編輯文件應該非常簡單。大多數熟悉的快捷鍵都可以在 FreeDOS Edit 中使用：Ctrl+C 複製文本，Ctrl+X 剪貼文本，和 Ctrl+V 將複製的或剪貼的文本粘貼到新的地方。如果你需要在一個長文檔中尋找一個特殊文本，按下 Ctrl+F。保存你的工作成果，請使用 Ctrl+S 以將變更提交到硬盤。

在 Edit 中編程 ​

如果你是個程序員，你也許會發現擴展的 ASCII 表是一個有用的工具。DOS 系統支持“拓展的” ASCII字符集，通常被稱之為“代碼頁 437”。0 到 127 的標準字符包括字母 A 到 Z（大寫和小寫）、數字和特殊字符，如標點符號。但是，從 128 到 255 的 DOS 拓展字符包括其它語言字符和“畫線”元素。DOS 程序員有時需要使用這些拓展 ASCII 字符，所以 FreeDOS Edit 可以很容易地查看所有 ASCII 碼和它們的相關字符的表格。

要查看這個 ASCII 表，請使用“工具Utilities”菜單，選擇“ASCII 表ASCII Table”菜單項，這將顯示一個包含該表格的窗口。

沿着左邊，這張表顯示十六進制值“00”到“F0”，頂部展示了單一值“0”到“F”。這些為每個字符的十六進制代碼提供了一個快速參考。例如，第一行（00）和第一列（0）中的項目具有十六進制值 00 + 0，即0x00（“NULL”值）。而第五行（40）和第二列（1）中的字符，其數值為 40 + 1，即 0x41（字母 “A”）。

當你在表格內移動光標高亮不同的字符時，你會看到表格底部的值發生變化，展示了字符的十進制、十六進制和八進制編碼。例如，移動光標以高亮在 C0 行和第 5 列的“行交叉”字符，顯示這個擴展字符的代碼為 197（十進制）、0xc5（十六進制）和 305（八進制）。在一個程序中，你可以通過輸入十六進制值 0xc5 或八進制“轉義代碼” \305 來引用這個擴展字符。

請隨意瀏覽 Edit 中的菜單，以發現其他不錯的功能。例如，“選項Options”菜單允許你更改 Edit 的行為和外觀。如果你喜歡使用更密集的顯示，可以使用“顯示Display”菜單（在“選項Options”下）將 Edit 設置為 25、43 或 50 行。你還可以強制 Edit 以單色（黑底白字）或反轉模式（白底黑字）顯示。
