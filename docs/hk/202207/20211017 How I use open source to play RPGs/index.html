我如何使用開源玩 RPG 遊戲 ​

為角色扮演遊戲的所有元素找到一個開源工具。

我玩過很多桌面角色扮演遊戲（RPG），無論是從頻率還是種類來説。一般來説，我更喜歡和朋友一起玩 RPG，但在過去的 2 年裏，我一直在玩網絡遊戲。（LCTT 校注：這裏的 RPG 遊戲指的是那種“傳統”的面對面的桌面遊戲，而非很多人最初接觸的 RPG 電子遊戲。）

起初，我不確定如何在線長期的進行遊戲。我知道有很多的工具可以實現，但直到我發現在線桌面遊戲的開源世界之前，這些工具沒有一個引起我的興趣。通過一小部分開源應用程序，我已經能夠在開源平台上進行我的所有遊戲。

這也是一年中的好時機，因為最近是 免費 RPG 日（LCTT 校注：今年的這個節日在 7 月 23 日舉辦）。在免費 RPG 日，桌面角色扮演遊戲行業的發行商們會免費發放遊戲，鼓勵玩家嘗試新遊戲和新冒險。儘管它在 2020 年被取消了，但今年它又作為現場活動迴歸，並通過 Dungeon Crawl Classics 和 Paizo 的免費 RPG 示例下載提供了一些虛擬支持。

如果這個活動提供的虛擬產品還不夠，我還整理了一份 你可能尚未嘗試過的 5 個開源桌面 RPG 遊戲列表。

當你準備好開始玩遊戲時，請嘗試其中一些開源工具，看看它們能在多大程度上增強你的遊戲體驗。

聊天 ​

在線 RPG 遊戲最基本的（從技術上講，也是唯一的）要求是交流。這是遊戲的媒介：玩家需要一種説話的途徑。

有幾個不錯的選擇。我發現 Mumble 是對帶寬需求最低的工具。這是一個純語音聊天應用程序，可以使用非常高效的 Opus 編解碼器讓每個人一次交談數小時而不會中斷。

它在世界各地都運行有公共實例，所以下載 Mumble 客户端後，你可以加入其中任何一個開放的實例，並使用它來在線運行遊戲。有一個“按下通話”設置，你可以用此來消除背景噪音，當你的其他家庭成員在進行其它工作而不想被你的桌面會話打擾時，這個功能將會非常實用。

還有一個文本聊天客户端。我的遊戲組通常使用它來發布與遊戲相關的鏈接，但你也可以將其用於其它無關內容的交談，而讓口頭遊戲保持在主題上。

如果你的玩家更喜歡看到面部表情，或者只是習慣於視頻聊天網頁應用。那麼 Jitsi 是面對面圍坐在桌子旁聚會的絕佳替代品。Jitsi 和你曾經使用過的其它視頻聊天軟件幾乎一樣，甚至更簡單。你可以設置一個“房間”，邀請朋友，將陌生人拒之門外，並玩上幾個小時。靜音和關閉攝像都很直觀，界面很吸引人，並且還定期開發和推出了新功能。

Mumble 和 Jitsi 都有適用於台式機和移動設備的客户端，因此任何人都可以在任何設備上使用。

角色表 ​

我發佈了我的 數字角色表 解決方案，但任何 RPG 玩家都知道管理角色不僅僅是統計數據。

在延續多個會話的在線遊戲中，我發現每次遊戲之間有很長的停止時間。我突然想到，雖然我發現要求我的玩家在現場紙筆遊戲中計算損耗是不合理的，但當一切都是數字化時，要求他們跟蹤損耗很容易。

網上有很多可用的電子表格，但開源的選擇是 Ethercalc。由於其實例遍佈世界各地，因此很容易找到免費的 Ethercalc 主機。或者，你可以使用 Podman 或者 Docker 輕鬆安裝和運行你自己的實例。

Etherclac 提供了一些基本要素：一個共享的賬本，這樣玩家就可以跟蹤他們的團隊所攜帶的物品（以及在任何給定的時間持有該物品的人）、每件物品的重量和價值。當隊伍在遊戲過程中收集到戰利品時，就會輸入該物品，所以他們知道什麼自己何時會因為負擔過重而無法拿起新物品。

在不同的遊戲會話之間，可以引用和整理這份共享的電子表格，以便玩家（PC）知道哪些物品可以賣掉，哪些物品可以放入儲物袋，哪些物品可以在下一次會話發現更好的戰利品時安全的丟棄。

地圖 ​

Mythic Table 是一款開源的桌面遊戲共享地圖系統。這意味着你可以加載圖片作為遊戲地圖，並在地圖上移動數字標記以表示玩家角色所在的位置。

自從 上次我介紹了關於 Mythic Table 以來，它已經在 Kickstarter 上成功地進行了一次眾籌，以確保它的持續發展。它還增加了一些新功能，其中最引人注目的是“戰爭迷霧”功能，它允許地下城主掩蓋地圖並僅顯示玩家探索過的部分。

在過去的幾個月裏，我一直在 Mythic Table 上運行兩款遊戲，這是一款優秀且直觀的地圖系統。它還提供了一個數字骰子筒，所以如果你的玩家沒有骰子，或者你更喜歡在公開場合擲骰子，你就可以用它作為共享的骰子池。

你可以在 mythictable.com 上試用 Mythic Table，或者訪問他們在 Github 上的代碼庫。

開源的開放遊戲 ​

我使用的開源工具是通用的，因此它們適用於你想玩的任何遊戲系統。因為它們都是開源的，所以無論你的玩家使用什麼操作系統，他們都可以在線使用，並且它們都可以自託管。

如果你既是程序員又是遊戲玩家，請訪問他們的 Git 代碼倉庫，看看是否有任何你可以貢獻的東西。如果你是遊戲玩家或者遊戲管理員，在下次坐在數字版的遊戲桌前請嘗試使用一下這些工具。你可能會驚訝於你只需要很少的在線賬户就可以使用一些可用於遊戲的最佳應用程序。
