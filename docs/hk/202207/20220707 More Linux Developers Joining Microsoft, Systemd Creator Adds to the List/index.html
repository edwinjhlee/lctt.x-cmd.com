又有 Linux 開發者加入微軟，這次是 systemd 的創建者 ​

看來微軟拿了一手好牌，在 Linux 和開源方面取得行業成功。

出於某種原因，微軟在開源和 Linux 方面總是受到關注。

而且，當我們談論 Linux 開發者時，它也會成為焦點……為什麼會這樣？

微軟似乎正在為一系列的項目招聘大量 Linux 開發人員。而且，一個知名人物也加入了這個名單。

據 Phoronix 報道，systemd 和 PulseAudio 的創建者 Lennart Poettering，現在已在微軟工作，繼續專注於 systemd 的開發。

或許你不知道，Lennart 曾在紅帽工作，領導 PulseAudio 項目和其他一些事情。

除了 Lennart 之外，Python 之父 Guido Van Rossum 等一些關鍵的開發人員之前就加入了微軟。

（LCTT 譯註：據 Phoronix 總結，還有更多的開源開發者加入了（或加入過）微軟，這包括：GNOME 創建者 Miguel de Icaza 曾在 2016 年微軟收購 Xamarin 時受僱，到今年早些時候離開；Nat Friedman 作為 Xamarin 的成員在微軟收購後加入，後擔任微軟旗下的 GitHub 的 CEO；Gentoo Linux 創始人 Daniel Robbins 之前受僱於微軟；Steve French 作為 Linux CIFS/SMB2/SMB3 的維護者和 Samba 團隊的成員為微軟工作；以及大量的上游 Linux 開發者，如 Matteo Croce、Matthew Wilcox、Tyler Hicks、Shyam Prasad N、Michael Kelley、Christian Brauner 等等也曾被微軟僱傭。）

微軟在為最佳狀態做準備 ​

毫不奇怪，微軟希望提高其對基於開源的項目的關注，並儘可能有效地利用 Linux 為其業務服務。

Azure 平台對開源的利用最多，而且，不要忘了 Windows Subsystem for Linux（WSL）。

因此，微軟一直在招聘 Linux 開發人員。如果你想試試，你會在 微軟職業 欄目中找到很多與 Linux 有關的職位。

雖然這對微軟的產品線來説是一件大事，但它一般不會影響到 Linux 桌面用户。事實上，我認為，Linux 開發者得到的資源越多，由於他們工作角色轉換，他們可以幫助 Linux 生態系統更好地增強其願景。

當然，讓所有關鍵的 Linux 開發者都在微軟擁有的項目上工作並不是一件喜聞樂見的事情，但是，事實就是如此。

微軟正在做正確的事情 ​

這不僅僅是經濟上的回報，Linux 開發者加入微軟團隊的趨勢意味着他們在開源和 Linux 上的一些努力是成功的。

只要微軟努力改善 Linux 生態系統，我認為我們就沒有什麼可擔心的。

我不想被提醒“擁抱、擴展和熄滅Embrace, extend, and extinguish”（3E）。畢竟，這對所有公司來説都是生意。當涉及到賺錢的決定時，沒有人應該被認為是英雄。

因此，我們只能希望微軟在不久的將來為 Linux 開發者和用户準備好一些好東西。
