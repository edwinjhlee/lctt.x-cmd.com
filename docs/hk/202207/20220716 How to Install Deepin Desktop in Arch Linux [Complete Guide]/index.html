如何在 Arch Linux 中安裝深度桌面（DDE） ​

在本指南中，我們將解釋在 Arch Linux 中安裝漂亮的深度桌面（DDE）所需的步驟。

指南的第一部分解釋了安裝 Arch 基本系統的步驟。第二部分是在 Arch Linux 的基礎上安裝完整的深度桌面。

什麼是深度桌面（DDE）？ ​

深度操作系統 是一個基於 Debian 穩定分支的、功能豐富且漂亮的桌面環境。深度桌面環境（DDE）是深度操作系統自主開發的桌面環境。它由它自己的 dde-kwin 窗口管理器驅動。深度桌面帶有漂亮的停靠區和許多預裝的深度原生的應用程序。

這個令人眼花繚亂的桌面環境 可在 Arch 倉庫中找到；這篇文章介紹瞭如何在 Arch Linux 中安裝深度桌面。

本指南安裝深度桌面環境 20.1。然而，其他版本的步驟也應該是類似的。

第一部分：安裝 Arch Linux ​

如果你已經安裝了 Arch Linux，你可以跳過這一步，直接進入安裝深度桌面部分。

要快速安裝基本的 Arch Linux，請按照以下步驟進行。你也可以訪問 本指南 瞭解以雙啓動或在虛擬機上安裝 Arch Linux 的完整教程。

下載 Arch Linux ​

從下面的鏈接下載 Arch Linux 的 .iso 文件。這裏有磁力鏈和 BT 鏈接。一旦你下載好了，就把 ISO 寫入 U 盤。然後從該驅動器啓動。

下載 Arch Linux

如果你打算通過 GNOME Boxes、virt-manager 將其安裝為虛擬機鏡像 —— 那麼你不需要將其寫入 U 盤。

啓動和配置分區 ​

從 Arch Linux ISO 啓動後，你必須運行一系列的命令來安裝基本系統。

首先，運行下面的命令，找出設備的標識符。

fdisk -l

然後用此設備標識符，運行下面的命令，開始對你的磁盤進行分區。請確保根據你的系統而修改下面的 /dev/sda 參數。

cfdisk /dev/sda

在下一個提示中選擇 label type = dos。

選擇可用空間，並從底部選擇 “NEW” 選項。在這個例子中，我將創建三個分區，如下所示：

/dev/sda1 - 1G - for /boot
/dev/sda2 - 5G - for root
/dev/sda3 - 1G - for swap

在下一個屏幕中，提供啓動分區（/boot）的大小（在這個例子中，我給出了 1GB）。選擇它作為主分區。

對 5GB 大小的主根分區（/）重複同樣的步驟。

用同樣的步驟創建一個大小為 1G 的交換分區（你可以根據你的需要改變大小）。創建交換分區後，確保在底部選擇類型，並將其標記為 “Linux Swap/Solaris” 選項的交換分區。

完成後，用底部的 “Write” 選項將變化寫到磁盤上。確保你在寫之前做一個備份，因為這是你係統中的一個永久性的改變。

在你繼續之前，運行下面的命令來檢查。在這個例子中，你可以看到，列出了三個分區。

fdisk -l

依次運行下面的命令，在上面新創建的分區中格式化並創建一個 ext4 文件系統。確保你根據你的需要改變 /dev/sda1 和 /dev/sda2 參數。

mkfs.ext4 /dev/sda1
mkfs.ext4 /dev/sda2
mkswap /dev/sda3
swapon /dev/sda3

完成後，掛載系統並創建必要的目錄。

mount /dev/sda2 /mnt
mkdir /mnt/boot /mnt/var /mnt/home
mount /dev/sda1 /mnt/boot

同樣，確保你根據你的系統改變 /dev/sda1、/dev/sda2 和 /dev/sda3 參數。

安裝基本系統 ​

我希望你已經連接到互聯網了。如果沒有，請嘗試使用 USB 網卡或有線網絡連接，Arch 安裝程序會自動配置和檢測。如果你沒有可用的有線連接，請按照本指南使用 Arch Linux 安裝程序配置無線 Wi-Fi 網絡。

依次運行下面的命令，將基本系統安裝到掛載的分區中。下載的大小約為 400MB。

pacman -Syy
pacstrap /mnt base base-devel linux linux-firmware nano dhcpcd net-tools grub

一旦完成，生成一個文件系統表，沒有這個表你就無法啓動系統。

genfstab -U /mnt >> /mnt/etc/fstab

配置基本系統 ​

依次按照下面的命令來配置基本系統。這包括設置你的地區和語言，添加一個登錄用户，以及設置互聯網。

arch-chroot /mnt
nano /etc/locale.gen

去掉開頭的 #，取消對你選擇的語言環境的註釋。在本指南中，我選擇了 en_US.UTF-8 UTF-8。按 CTRL+O、回車和 CTRL+X 退出 nano。

使用以下方法生成語言環境數據。

locale-gen

使用下面的命令設置語言。

echo LANG=en_US.UTF-8 > /etc/locale.conf
export LANG=en_US.UTF-8

設置本地時區。

ln -s /usr/share/zoneinfo/America/New_York /etc/localtime

同樣，你可以根據你的需要來選擇它們。你可以通過以下命令列出本地時區。

ls /usr/share/zoneinfo
ls /usr/share/zoneinfo/America

依次使用下面的命令設置硬件時鐘、創建主機名並啓用互聯網的 DHCP。你可以根據你的想法把 debugpoint-pc 改為任何主機名。

hwclock --systohc --utc
echo debugpoint-pc > /etc/hostname
systemctl enable dhcpcd

下一步是設置 root 用户的密碼、創建一個管理員用户，並將該用户添加到 sudoers 文件中。

按照下面的命令依次進行。確保根據你的需要將用户名debugpoint 改為其他名稱。

passwd rootuseradd -m -g users -G wheel -s /bin/bash debugpointpasswd debugpoint

打開 sudoers 文件，添加以下幾行。

nano /etc/sudoers

添加下面幾行。由於你已經創建了 root 用户，該條目應該已經有了。

root ALL=(ALL) ALL
debugpoint ALL=(ALL) ALL

安裝 GRUB，建立初始的 Ramdisk 環境，並使用下面的命令卸載系統。

grub-install /dev/sda
grub-mkconfig -o /boot/grub/grub.cfg
mkinitcpio -p linux
exit

然後重新啓動你的系統。

umount /mnt/boot
umount /mnt
reboot

現在你已經成功地安裝了 Arch Linux 基本系統。現在是安裝完整的深度桌面的時候了。

第二部分：在 Arch Linux 中安裝深度桌面 ​

重新啓動後，從 GRUB 中選擇 Arch Linux。在 Arch Linux 的提示符下，開始依次運行以下命令。這些命令安裝 Xorg 服務器、Lightdm 顯示管理器和深度桌面組件。

對於所有的命令，使用默認的包版本，即在詢問時按回車。

安裝 Xorg 和顯示管理器。大約安裝大小為 80 MB。

sudo pacman -S --need xorg lightdm

安裝額外的組件和應用程序（約 550 MB）。

sudo pacman -S --need deepin deepin-extra

安裝完成後，通過修改 Lightdm 配置文件啓用深度歡迎頁。按照下面的命令。

nano /etc/lightdm/lightdm.conf

並添加下面這一行。保存該文件（CTRL+O、CTRL+X）。

greeter-session=lightdm-deepin-greeter

現在是時候把顯示管理器和網絡管理器作為服務啓用了。這樣，下次登錄時，它們就可以由 systemd 自動運行。

systemctl enable lightdm
systemctl enable NetworkManager

使用 reboot 命令重新啓動系統。

reboot

如果一切順利，你應該看到深度桌面的登錄提示。使用你剛剛在上面的步驟中創建的憑證登錄。你應該會看到最新的深度桌面環境。

總結 ​

我希望這個指南能幫助你在 Arch Linux 中安裝深度桌面。雖然它不是我的日常環境，我覺得深度的桌面在本質上有些慢。可能是因為有太多的顏色渲染和動畫，而且儘管它是建立在 Qt 上的，但沒有為深度桌面進行適當的優化。
