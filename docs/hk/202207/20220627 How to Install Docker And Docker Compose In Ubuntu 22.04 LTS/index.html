如何在 Ubuntu 22.04 LTS 中安裝 Docker 和 Docker Compose ​

在 Ubuntu 中使用 Docker Compose 安裝 Docker 引擎的分步指導。

在這篇文章中，我們將會明白 Docker 是什麼，如何 在 Ubuntu 中安裝 Docker 引擎 。此外，我們也將會明白如何 安裝 Docker Compose ，它是一個定義並運行多容器的 Docker 應用。

我們已經在 Ubuntu 22.04 LTS 中正式的測試了這份指南。然而，它也應該對舊版本如 20.04 LTS 和 18.04 LTS 有效。為了更好的安全性和穩定性，我推薦你使用最新的版本 —— Ubuntu 22.04 LTS 。

什麼是 Docker ？ ​

Docker 是一個快捷、輕便的系統級虛擬化技術，開發者和系統管理員可以使用它構建具備所有必要依賴項的應用程序，並將其作為一個包發佈。

Docker 與其他如 VMWare 、Xen 、以及 VirtualBox 等工具的虛擬化方式不同，每個虛擬機不需要單獨的客户操作系統。

所有的 Docker 容器有效地共享同一個主機系統內核。每個容器都在同一個操作系統中的隔離用户空間中運行。

Docker 容器可以在任何 Linux 版本上運行。比如説你使用 Fedora ，我用 Ubuntu 。我們能相互開發、共享並分發 Docker 鏡像。

你無需擔心操作系統、軟件以及自定義設置，任何事都不用擔心。只要我們的主機安裝了 Docker ，就能持續開發。簡言之，Docker 能夠在任何地方運行！

前文中你讀到了兩個詞：Docker 鏡像 和 Docker 容器 ，或許你在想它們的區別。

通俗地説，Docker 鏡像是一個描述容器應該如何表現的文件，而 Docker 容器是 Docker 鏡像的運行（或停止）狀態。

希望你能夠理解 Docker 的基礎概念。更多細節，你可以參考文章末尾的 Docker 官方指導手冊。

Docker 依賴項 ​

為了安裝並配置 Docker ，你的系統必須滿足下列最低要求：

  1. 64 位 Linux 或 Windows 系統
  2. 如果使用 Linux ，內核版本必須不低於 3.10
  3. 能夠使用 sudo 權限的用户
  4. 在你係統 BIOS 上啓用了 VT（虛擬化技術）支持 on your system BIOS（參考: 如何查看 CPU 支持 虛擬化技術（VT））
  5. 你的系統應該聯網

在 Linux ，在終端上運行以下命令驗證內核以及架構詳細信息：

$ uname -a

輸出樣例：

Linux Ubuntu22CT 5.15.35-3-pve #1 SMP PVE 5.15.35-6 (Fri, 17 Jun 2022 13:42:35 +0200) x86_64 x86_64 x86_64 GNU/Linux

正如上面你看到的那樣，我的 Ubuntu 系統內核版本是 5.15.35-3-pve 並且系統架構是 64 位（x86_64 x86_64 x86_64 GNU/Linux）。

注意： 這裏，我在 Proxmox 中使用 Ubuntu 22.04 容器。這是你看到上方內核版本中有 “pve” 字符的原因。如果你正在使用 Ubuntu 實體（或者虛擬）機，你將看到系統版本為 5.15.35-3-generic 。

內核版本需要不低於最低要求的版本，並且是 64 位機器。這樣不會有任何問題，我們能順利安裝並使用 Docker 。

請注意你使用哪一個 Ubuntu 系統不重要。並且你使用 Ubuntu 桌面或服務器版本，亦或者其他 Ubuntu 變種如 Lubuntu 、Kubuntu 、Xubuntu ，都不重要。

只要你的系統內核版本不低於 3.10 ，並且是 64 位系統，Docker 都會正常運行。

在 Ubuntu 22.04 LTS 中安裝 Docker ​

首先，更新你的 Ubuntu 系統。

1、更新 Ubuntu ​

打開終端，依次運行下列命令：

$ sudo apt update
$ sudo apt upgrade
$ sudo apt full-upgrade

2、添加 Docker 庫 ​

首先，安裝必要的證書並允許 apt 包管理器使用以下命令通過 HTTPS 使用存儲庫：

$ sudo apt install apt-transport-https ca-certificates curl software-properties-common gnupg lsb-release

然後，運行下列命令添加 Docker 的官方 GPG 密鑰：

$ curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg

添加 Docker 官方庫：

$ echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

使用命令更新 Ubuntu 源列表：

$ sudo apt update

3、安裝 Docker ​

最後，運行下列命令在 Ubuntu 22.04 LTS 服務器中安裝最新 Docker CE：

$ sudo apt install docker-ce docker-ce-cli containerd.io docker-compose-plugin

當然你也可以安裝其他版本 Docker 。運行下列命令檢查可以安裝的 Docker 版本：

$ apt-cache madison docker-ce

輸出樣例：

docker-ce | 5:20.10.17~3-0~ubuntu-jammy | https://download.docker.com/linux/ubuntu jammy/stable amd64 Packages
docker-ce | 5:20.10.16~3-0~ubuntu-jammy | https://download.docker.com/linux/ubuntu jammy/stable amd64 Packages

docker-ce | 5:20.10.13~3-0~ubuntu-jammy | https://download.docker.com/linux/ubuntu jammy/stable amd64 Packages

你可以挑選上面列表中的任何版本進行安裝。例如，安裝 5:20.10.16~ 3-0 ~ubuntu-jammy 這個版本，運行：

$ sudo apt install docker-ce=5:20.10.16~3-0~ubuntu-jammy docker-ce-cli=5:20.10.16~3-0~ubuntu-jammy containerd.io

安裝完成後，運行如下命令驗證 Docker 服務是否在運行：

讓我們繼續，測試 Docker 是否運行正常：

運行：

$ sudo docker run hello-world

5、作為非 root 用户運行 Docker （選做） ​

默認情況下，Docker 守護進程綁定到 Unix 套接字而不是 TCP 端口。由於 Unix 套接字由 root 用户擁有，Docker 守護程序將僅以 root 用户身份運行。因此，普通用户無法執行大多數 Docker 命令。

如果你想要在 Linux 中作為非 root 用户運行 Docker ，參考下方鏈接：

  • 如何在 Linux 中作為非 root 用户運行 Docker

我個人不這樣做也不推薦你這麼做。如果你不會在互聯網上暴露你的系統，那沒問題。然而，不要在生產系統中以非 root 用户身份運行 Docker 。

在 Ubuntu 中安裝 Docker Compose ​

Docker Compose 是一個可用於定義和運行多容器 Docker 應用程序的工具。使用 Compose，你可以使用 Compose 文件來配置應用程序的服務。然後，使用單個命令，你可以從配置中創建和啓動所有服務。

下列任何方式都可以安裝 Docker Compose 。

方式 1、使用二進制文件安裝 Docker Compose ​

從 這裏 下載最新 Docker Compose 。

當我在寫這篇文章時，最新版本是 2.6.1 。

運行下列命令安裝最新穩定的 Docker Compose 文件：

$ sudo curl -L "https://github.com/docker/compose/releases/download/v2.6.1/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose

如果有更新版本，只需要將上述命令中的 v2.6.1 替換為最新的版本號即可。請不要忘記數字前的 "v" 。

最後，使用下列命令賦予二進制文件可執行權限：

$ sudo chmod +x /usr/local/bin/docker-compose

運行下列命令檢查安裝的 Docker Compose 版本：

$ docker-compose version
Docker Compose version v2.6.1

方式 2、使用 Pip 安裝 Docker Compose ​

或許，我們可以使用 Pip 安裝 Docker Compose 。Pip 是 Python 包管理器，用來安裝使用 Python 編寫的應用程序。

參考下列鏈接安裝 Pip 。

  • 如何使用 Pip 管理 Python 包

安裝 Pip 後，運行以下命令安裝 Docker Compose。下列命令對於所有 Linux 發行版都是相同的！

$ pip install docker-compose

安裝 Docker Compose 後，使用下列命令檢查版本：

$ docker-compose --version

你將會看到類似下方的輸出：

docker-compose version 2.6.1, build 8a1c60f6

恭喜你！我們已經成功安裝了 Docker 社區版和 Docker Compose 。

安裝了 Docker，然後呢？查看本系列的下一篇文章，瞭解 Docker 基礎知識。

要在基於 RPM 的系統（例如 RHEL、Fedora、CentOS、AlmaLinux、Rocky Linux 和 openSUSE）中安裝 Docker，請參考以下鏈接。

  • 在 CentOS 中安裝 Docker

總結 ​

在這篇教程中，我們討論了 Docker 是什麼，如何在 Ubuntu 22.04 LTS Jammy Jellyfish 中安裝 Docker 。然後學習瞭如何通過運行 hello-world Docker 鏡像測試 Docker 是否成功安裝。最後，我們通過使用兩種不同的方式安裝 Docker Compose 作為本教程的結尾。
