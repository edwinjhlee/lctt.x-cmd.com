10 大必備 Ubuntu 應用：優選篇 ​

本文列出了 2022 年可以用於不同情況的 10 個 Ubuntu 優選應用。

如果你計劃永久的轉移到 Linux 系統上，你應該會很高興地知道在 Linux 上有數以千計的能與商業或付費應用媲美的應用。如果你是第一次使用 Linux 的 Windows 用户，你可能都沒有聽説過這些應用。

因此，在這一系列文章中，我們每一篇重點介紹一組 Ubuntu 應用，以增加 Linux 用户們的協作和認識。

這是 Ubuntu 應用程序系列的第二篇文章，如果你錯過了其他部分，可以在這裏閲讀：

  • 第一篇

1、OBS Studio ​

第一個應用是著名的 流媒體應用 —— OBS Studio 。這是一款自由開源的應用，主要用於互聯網上的流媒體應用。此外，你可以使用該應用創建一個複雜的流媒體項目，包括多源、覆蓋式橫幅等功能。

而且，由於它能夠支持“實時消息傳輸協議Real-Time Messaging Protocol”（RTMP），你可以使用它在 Facebook、Youtube、Twitch 以及其他支持的平台上進行流式傳輸。

這個有十年曆史的應用程序是 Linux 上最好的應用程序之一。

你可以在 OBS Studio 官網 瞭解更多的信息並下載，或者通過以下方式安裝。

通過 PPA 在 Ubuntu 和相關發行版上安裝：

sudo add-apt-repository ppa:obsproject/obs-studio
sudo apt update
sudo apt install obs-studio

如果你希望通過 Flatpak 安裝 ，首先 為 Flatpak 設置系統 然後 通過這個頁面安裝 。

在 Arch Linux 或者其他 Linux 版本，訪問 此頁面 瞭解。

2、Inkscape ​

這裏介紹的第二款應用是流行的 Inkscape。 Inkscape 是一個自由開源的矢量圖形編輯軟件。它主要用於創建可縮放的矢量圖形（SVG）。此外，它是一款一流的應用，可以使用基本的矢量形狀如矩形、多邊形、螺旋形等。你可以使用這些基本圖形以及輔助工具（見下文）創作一流的繪圖。

此外，只要你有足夠的技能，就可以使用 Inkscape 創作出 絕妙的動畫 。這是藝術家必備的一款應用。

你可以在 Inkscape 官網 下載並瞭解更多相關信息，或者通過以下方式下載。

通過 PPA 在 Ubuntu 和相關發行版上安裝：

sudo add-apt-repository ppa:inkscape.dev/stable
sudo apt update
sudo apt install inkscape

更多下載方式可以查看 此頁面 。

3、GIMP ​

GIMP 是 “GNU 圖像操作程序GNU Image Manipulation Program”的縮寫，它是一個光柵圖形編輯器，它有時候被視作 Linux 平台上的 Photoshop 替代品（值得商榷）。這款擁有 20 年曆史的應用適合於從基礎到高級的圖像編輯。此外，它支持圖層、濾鏡、裝飾和其它對攝影工作必不可少的高級圖像編輯功能。

官方主頁 是你瞭解更多關於 GIMP 的知識的最好的途徑，可以在官網下載或者通過以下方式安裝。

我推薦的方式是通過 Flatpak 下載最新版本 GIMP 。你可以為 Flatpak 設置 你的系統 然後 通過該頁面安裝 。

該頁面 提供了更多下載選項。

4、Spotify ​

Spotify 是一家專業提供音頻流媒體和媒體服務的提供商。它是最廣泛的音樂流媒體服務之一，有超過 400 萬的月活用户。

首先，你需要安裝客户端才能獲取 Spotify 流媒體服務。其次，如果你是移動用户，你可以通過 Google Play 商店或者蘋果應用商店獲取 Spotify 應用。

在 Linux 上安裝桌面客户端後你可以收聽上百萬首歌曲。你可以為不同的 Linux 發行版通過不同的方式安裝 Spotify 。

推薦你在 Ubuntu 或者其他 Linux 上使用 Snap 來安裝，你可以通過以下命令安裝：

snap install spotify

如果你偏愛原始的 deb 包，你可以通過以下命令安裝：

curl -sS https://download.spotify.com/debian/pubkey_5E3C45D7B312C643.gpg | sudo apt-key add -echo "deb http://repository.spotify.com stable non-free" | sudo tee /etc/apt/sources.list.d/spotify.list

你也可以使用非官方 Flatpak 包 進行安裝。

5、SimpleScreenRecorder ​

SimpleScreenRecorder 可能是最好的開源截屏工具。該應用程序易於使用並提供了各種功能。並且，其獨特的 3 步錄製屏幕的方法完全不需要學習。此外，你可以選擇整個屏幕、窗口或自定義形狀來記錄屏幕。

此外，你還可以指定音頻/視頻比特率、音頻源選項和不同的輸出選項。最後，它可以安裝在所有 Linux 發行版中。

官方頁面 囊括了更多的 SimpleScreenRecorder 信息，你也可以使用如下方式下載。

在 Ubuntu 或其他相關發行版中使用下面的 PPA 命令安裝該應用：

sudo apt-get updatesudo apt-get install simplescreenrecorder

訪問 此頁 獲取更多下載版本。

6、Calibre ​

Calibre 是一款可以在 Ubuntu、Linux Mint 以及其他 Linux 平台使用的自由開源的電子書庫管理應用程序。它擁有書庫管理、電子書格式轉換、同步你的電子書設備以及其他獨特的功能。你可以下載新聞和其他互聯網上的文章，並可以使用 Calibre 轉換成電子書格式。同時，它支持多種電子書格式進行管理。Calibre 是一款具有這些功能最好的電子書管理應用程序之一。

Calibre 主頁 提供了很多文件以及指導手冊，你也可以使用以下方式下載。

  • 下載 Linux 版本
  • 下載其他系統版本

7、Scribus ​

多年來，桌面出版已經發生了變化。現今，仍有一些桌面出版的應用程序和基於網頁的服務。Scribus 是早期的一款自由開源的桌面出版應用程序，可以在 Linux 發行版和其他操作系統中使用。此外，它基於 Qt，並帶來了吸引人的用户界面，讓你可以馬上投入學習。此外，初學者和專業人士都可以使用它來創建令人驚歎的 DTP 頁面。

並且它仍然在積極開發中。

你可以在 Scribus 的 官方頁面 瞭解更多信息並下載，或者通過以下方式安裝。

Scribus 位於 Ubuntu 和其他相關發行版的主要存儲庫中。你可以運行以下命令進行安裝：

sudo apt install scribus

該頁面 提供了其他下載選項。

8、MyPaint ​

第八個應用程序是 MyPaint 。MyPaint 是一個自由開源的繪圖程序，適用於數字藝術家。MyPaint 支持並可用於壓感平板電腦和設備。其獨特的無干擾設計可以讓你專注於繪圖而不是應用程序。此外，它還帶來了真實鉛筆和畫筆的仿真，提供了各種畫筆、顏色和圖層。

瀏覽 MyPaint 的 官方頁面 獲取更多信息，可以使用以下方式下載。

推薦使用 Flatpak 安裝 。你可以為 Flatpak 設置 系統 然後 通過該頁面安裝 。

該頁面 提供了其他下載選項。

9、LibreOffice ​

如果有任何專業的辦公套件可以和市場領導者微軟 Office 相媲美，那一定是文檔基金會的 LibreOffice 了 。它是所有 Linux 發行版的默認辦公套件。它帶有電子表格程序（Calc）、文字處理器（Writer）、演示文稿（Impress）和用來繪圖的 Draw。此外，它還帶來了一個數據庫系統 （Base）和用來撰寫數學公式的 Math。

除此之外， LibreOffice 提供兩個版本。其一是社區版，用於社區和一般用途，並帶有最新的功能和更新。第二是商務版，也稱企業版，更穩定，更適合專業工作。

LibreOffice 辦公套件已默認安裝在 Ubuntu 上。

LibreOffice 的官方文檔 很龐大，你可以通過各種方式瀏覽它們，包括在它 友好的論壇 。你可以 從此處 下載 LibreOffice。

如果你也想升級 LibreOffice ，你可以訪問 這裏 。

10、Cawbird ​

如果你是重度 Twitter 用户，你或許應考慮一款桌面應用。 Cawbird 是一款 Linux 發行版上的 Twitter 桌面程序。它是 Corebird 應用（已停止維護）的復刻，Cawbird 帶來了內嵌圖片、視頻預覽、列表支持等。此外，它可以在 Twitter 上進行全文搜索，並支持多個 Twitter 帳户。

但是，由於 Twitter API 的限制，它只能每兩分鐘刷新一次，此外，還有一些其他限制，例如沒有關注和取消關注的通知、阻止、靜音和其他功能。Twitter 強加了這些限制。

最後，你可以通過 該鏈接 在任何 Linux 發行版上下載 Cawbird 。
