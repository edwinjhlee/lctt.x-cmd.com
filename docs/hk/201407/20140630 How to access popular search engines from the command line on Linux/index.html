主流搜索引擎闖入Linux命令列世界 ​

（LCTT譯註：這裏，我們姑且認為您身處能夠訪問Internet的地方！）

為什麼會有人要從終端搜索互聯網上的東西？我不清楚，這裏頭可能有許多的原因。但是，因為沒人要求答案總比沒人知道答案少令人失望一點。這裏，列出了一些流行的搜索引擎的命令列工具，可以讓你們通過Linux終端來訪問它們。

1. Google ​

讓我們從一個巨頭開始吧：Bing！好吧，只是開個玩笑，事實上應該是Google。坦白講，你根本不需要使用命令列工具來進行Google搜索。只需要簡簡單單的一個命令：

$ xdg-open https://www.google.com/search?q="[query]"

它會打開網頁瀏覽器，並轉到合適的搜索頁面。然而，如果你想要的是從終端窗口查看搜索結果，而不是打開什麼網頁瀏覽器，那麼我推薦你使用cli-google。它是一個超級老古董了（最後一次更新是在2009年），但我喜歡它。這是一個簡單而直接的應用，它會忠實地幹好它應該乾的事。

安裝完cli-google後，你就可以開始用它來搜索了，它的輸出是那樣的五彩斑斕。你也可以調整搜索結果的數量和你想要的語言，你只需要在終端中敲入：

$ google

就可以看到所有的選項了。

2. YouTube ​

關於Google，有太多的東西要放進列表來。我會盡量簡明扼要，但絕不會放過該有的。對於許多人而言，YouTube是他們快速查找相關內容視頻的首選。要在終端中完成此事，我則鍾情於mps-youtube。這個軟件可以讓你在終端中搜索、下載視頻，創建播放列表，以及查看關於視頻的評論。安裝完mps-youtube後，你可以使用下面的命令來啓動：

$ mpsyt

然後，輸入 h 來查看選項。要查看簡明用法，你可以像下面這樣：

/[query]

來搜索你想知道的一切，然後輸入視頻的編號來聽聽它的聲音，或者輸入：

i [video-number]

來看看相關信息，也可以輸入：

d [video-number]

來下載它。如果你覺得光聽還不過癮，這裏還有更好玩的：

set player mplayer
set show_video True

現在，你可以在另外一個窗口裏頭用mplayer來播放視頻了。

3. 維基百科 ​

與Google一樣，對於維基百科，我也喜歡一個古老的腳本，它乾的不賴：cliWiki。安裝完後，趕緊運行一下看看：

$ cliwiki

然後，你就可以輸入你想要搜索的內容了。如果有直接匹配的條目，終端中就會顯示相關頁面了。哈，輸出內容可真夠長的，建議你還是用less命令來看吧。當然，這不是最高效的方法，但你的母的只是想要查看與關鍵詞相關的文本，那這就是你想要的。

4. 海盜灣 ​

現在，讓我們聊聊齷齪的東西。網上有很多意想不到的（也許你不覺得）工具，可以幫助你在命令列下查找海盜灣上的種子。而在這其中，pirate-get是我的最愛。它裏面藴藏了大量的選項，你可以通過下面的命令來發現它們：

$ pirate-get -h

但是還是簡單一些吧：

$ pirate-get --color -c [category] [query]

以上命令會返回與查詢內容相關的特定搜索類目中的結果，輸出結果也是彩色的！那裏頭，程序會提示你輸入你想要的結果的編號，輸入後就可以從磁鏈上下載種子了。簡單又容易，僅限於沒有版權的資料哦！

5. Twitter ​

Twitter是迎合潮流的一個很好的搜索引擎。我們已經在如何在命令列中訪問Twitter一文中介紹了它的用法，但是我個人更喜歡TTYtter。該工具及其強大，它應該有它自身的一席之地，而不再僅僅用於簡單搜索了。但在這裏，我只想把它當作搜索引擎使用。安裝並配置完後，你就可以登陸進去，並使用下面的命令來搜索了：

/search [query]

界面在視覺上有點粗糙，但是你很快會習慣的。注意，這裏頭只能用普通的文字，也可以用哈希標記。

最後來小結一下吧，這裏列出了我認為人們使用最多5大搜索引擎，這些搜索引擎都可以通過命令列來訪問。這裏Google圖像和Google地圖可能缺席了，但我想這些可能不能很好適應控制台環境吧。我也想要尋找一個音樂搜索引擎，但是沒有找到對於本列表“有價值的”。就像你可能已經注意到的那樣，列表中的工具在功能和選項上是良莠不齊的：其中一些很簡單，而另外一些則功能很複雜。但不管怎麼説，最後它們都還是完成了它們的任務。

列表中錯失了哪些搜索引擎？你還知道哪些沒有提到過的工具呢？請在文章評論中告訴我們吧。
