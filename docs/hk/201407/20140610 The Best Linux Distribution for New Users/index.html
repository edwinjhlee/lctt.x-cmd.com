適合新用户的最佳的Linux發行版 ​

這個爭論無疑給許多Linux用户帶來了麻煩。爭論的焦點一般不是哪個發行版是真正最適合新用户的，而是哪個發行版受這些爭論者的喜愛。如果我們撇開個人喜愛，我們會看到更清楚的一面。但即使這樣，明確的結論也會受到被新用户的需求和期望的影響。考慮到這點，我決定採取一個不同的方法來找出“對新用户來説最好的發行版”。我評判最好發行版的標準不僅是易用，而且還要具有由日益增長的移動界面風格所帶來的現代設計理念。

對於這次評測，我們對發行版有如下要求：

  • 非常友好
  • 包括，開箱即用，所有常用的應用程序
  • 包括某個形式的應用程序商店
  • 提供一個時尚的用户界面

讓我解釋一下各個標準

用户友好 ​

這是一個備受爭議的話題。但事實的真相是——新用户必須能夠選擇某種風格的Linux並開始使用，只需要很少或不需要解釋。如果必須很出太多解釋，那麼這個發行版便不是用户友好的。我不喜歡那些操作系統，但是幾乎任何用户都可以在近乎零指導的情況下坐在Windows 7或OS X桌面前並開始使用它。這是每一個Linux桌面都應當爭取去做的。

常用應用程序 ​

安裝好系統後用户不應該再去安裝必需的程序。那麼什麼是必需的呢？每年列表都會變短。目前，必備的程序列表如下：

  • 網頁瀏覽器：Chrome或者Firefox（對不起，根本不需要其他的瀏覽器）
  • 電子郵件客户端：Thunderbird是顯而易見的選擇。
  • Office辦公套件：LibreOffice。就這樣。
  • 音樂播放器：播放本地文件以及連接到流媒體服務（比如Spotify）。

這是幾乎所有用户需要的應用程序的簡表。

應用程序商店 ​

由於移動設備需求的日益增長，用户已經習慣了應用商店。Linux有應用商店很長時間了（Synaptic是最古老的一個）。沒有一個經深思熟慮做的應用商店，用户將會掙扎於在Linux環境中添加軟件。毫無疑問，這一點至關重要。

時尚的界面 ​

我已經多次提到移動設備的美化。由於iOS和Android，用户越來越喜歡時尚的界面。Linux的桌面需要進行效仿並且用獨特的、時尚的和易用的界面來吸引用户注意力。舊的風格在支持多觸控的移動世界裏不再有影響力。

排名前三的發行版 ​

以文中的標準，哪個發行版本滿足了（或超過）我們的需求？首先，讓我們來審查一下前三名的候選者。以下哪個滿足了（或超過）標準。

Ubuntu ​

Ubuntu Linux一直是用户友好型Linux的王者。開箱即用，尋找一個比它更迷人和易用的桌面（Unity）有點困難，甚至是對於那些對平台不熟悉的人也是這樣的。它的桌面佈局雖然與眾不同，但卻是合乎邏輯和很直觀的。對於在桌面環境中添加一個最強大的搜索工具，在Linux中Ubuntu Unity應當獲得最高成就。

Linux Mint ​

如果認為有一個篡奪王位的發行版，那它就是Linux Mint。Linux Mint做了更多桌面的標準方法，但是圖層華麗且多變使其從老舊的桌面隱喻中脱穎而出。Linux Mint基於Ubuntu，所以它得益於“老大哥”Ubuntu的穩定性和可靠性。

Linux Deepin ​

用户友好型列表中的新成員是Linux Deepin。這個相對較新的受歡迎的發行版來自中國，而且應該正視它所帶來的成就。為什麼這樣説？因為它使得Linux桌面轉變為藝術美；同時也保持了高水平的用户友好性。我期待它的新版本發佈將是個大事件。Linux Deepin使用的是GNOME 3桌面並將它重組得完全不同的，完全不可思議。

各發行版的比分 ​

在最佳的競爭者名單中，我們來比較一下每一個標準和等級。每個發行版的比分如下：對於每個標準，發行版排名從高到底（第一名得一分，最後一名得三分）。最後，總分決定誰是冠軍——最低得分獲勝。

用户友好性 ​

這可能是最嚴密的分類和最艱難的判別。每個發行版以不同的方法在用户友好性上都各有優勢。最後，我的排名是：

  1. Linux Mint

  2. Ubuntu Linux

  3. Linux Deepin

為什麼是這樣呢？Mint僅有微小的優勢，因為它的開始按鈕，任務欄和桌面圖標仍然使用舊的桌面風格。勝者的優勢很微小，Ubuntu和Linux Deepin要求的學習曲線近乎為零——甚至是對於小白們。

常用的應用程序 ​

這一類別難以判斷的唯一原因是因為每個發行版都包括所有必要的應用程序。雖然Linux Deepin目前提供的是金山Office（一個最好的移動辦公套件解決方案之一），它計劃在2014發行版本中默認使用LibreOffice。

關於常用程序的我的一個問題是音樂播放器。雖然我在線聽過很多音樂（使用Spotify客户端），但當我播放本地音樂時，總是使用Clementine。他們的默認播放器是：

  • Ubuntu: Rhythmbox
  • Linux Mint: Banshee
  • Linux Deepen: DMusic.

三者中，Banshee（圖1）提供了最多的功能，DMusic（圖2）提供了最好的界面，（令人驚訝的）Rhythmbox（圖3）目前最不穩定。

dmusic

rhythmbox

所以，他們得分多少？如下：

  1. Linux Mint

  2. Ubuntu Linux

  3. Linux Deepin

應用程序商店 ​

如果不分析這部分將難進行。為什麼呢？因為對於新用户應用商店可以輕易成就或是毀掉一個Linux發行版。總會有應用需求而且沒有用户想經過命令列的重重考驗。每個發行版都有自己的應用商店。

  • Ubuntu: Ubuntu軟件中心
  • Mint: 軟件管理器
  • Linux Deepin: Deepin軟件中心

應該説，這些工具中的每一個都是基於Ubuntu軟件中心的。奇怪的是Ubuntu軟件中心卻正好排在最底。主要原因是Ubuntu軟件中心太慢了——甚至在一個非常強大的機器上。

我將應用商店排名設為如下：

  1. Linux Deepin

  2. Linux Mint

  3. Ubuntu Linux

每個應用商店有非常相似的功能。Linux Deepin獲得第一的原因有兩個：界面易於控制而且程序開啓速度遠遠快於Ubuntu軟件中心和Mint軟件管理器。

時尚的界面 ​

在這部分Linux Mint遠遠落後。儘管它提供了一個華美的界面和有很淺的學習曲線，但相比之下它仍然是一個非常過時的桌面。甚至在強大的硬件（有強大的顯卡）上，Linux Mint仍然很容易被看成是來自90年代末的桌面。為了評判結果，我們必須看看是Ubuntu Linux還是Linux Deepin能帶我們走進未來。勝者是：

  1. Linux Deepin

  2. Ubuntu Linux

  3. Linux Mint

Linux Deepin使用GNOME 3來製作一個使用起來很漂亮的GNOME和OSX的混合體，你會認為你在處理一件互動的藝術品。

總冠軍 ​

雖然這是很初步的，對新用户來説最好的Linux發行版順序應該是：

  1. Linux Mint的總得分是7

  2. Linux Deepin的總得分是8

  3. Ubuntu Linux的總得分是9

如果你想知道關於這篇文章的作者觀點，要知道：我已經使用Ubuntu Linux很多年了（而且仍在用）。我最近一直在説“如果有一個Linux發行版能動搖我使用Ubuntu的想法，它便是Linux Deepin。”雖然我很欣賞Linux Mint，但我只是用它來進行測試。當説到對新用户最好的Linux發行版，Linux Mint是顯而易見的贏家。

這件事真正的真相是——你在使用這些桌面中任何一個都不會錯。他們都各有所長。如果你追求真正的美麗，使用Linux Deepin吧。如果你想要漂亮外觀與易用結合，那就使用Ubuntu Linux。如果你只想要簡單而且並不在乎漂亮的外觀，那就用Linux Mint。不管你選哪一個，這都是三贏的局面。

你怎麼認為？你會如何排這三個桌面的名次？或者，你是否會寫一個不同的Linux發行版，該發行版在外表上來説對新用户最好的？（還有原因是什麼？）
