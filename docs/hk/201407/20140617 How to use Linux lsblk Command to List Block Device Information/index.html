使用Linux的lsblk命令列出塊設備信息 ​

lsblk（列出塊設備）命令用於列出所有可用塊設備的信息，但是，它不會列出RAM盤的信息。塊設備有硬盤，閃存盤，CD-ROM等等。

如何安裝lsblk ​

lsblk命令包含在util-linux-ng包中，現在該包改名為util-linux。這個包帶了幾個其它工具，如dmesg。要安裝lsblk，請在此處下載util-linux包。

Fedora中安裝lsblk ​

Fedora用户可以通過以下方法來安裝該包：

$ sudo yum install util-linux-ng

該命令有幾個選項：

默認選項 ​

lsblk命令默認情況下將以樹狀列出所有塊設備。打開終端，並輸入以下命令：

$ lsblk

輸出如下：

7個欄目名稱如下：

NAME : 這是塊設備名。

MAJ:MIN : 本欄顯示主要和次要設備號。

RM : 本欄顯示設備是否可移動設備。注意，在本例中設備sdb和sr0的RM值等於1，這説明他們是可移動設備。

SIZE : 本欄列出設備的容量大小信息。例如298.1G表明該設備大小為298.1GB，而1K表明該設備大小為1KB。

RO : 該項表明設備是否為只讀。在本案例中，所有設備的RO值為0，表明他們不是隻讀的。

TYPE :本欄顯示塊設備是否是磁盤或磁盤上的一個分區。在本例中，sda和sdb是磁盤，而sr0是隻讀存儲（rom）。（LCTT譯註，此處sr0的RO項沒有標記為1，可能存在一些錯誤？）

MOUNTPOINT : 本欄指出設備掛載的掛載點。

列出所有設備 ​

默認選項不會列出所有空設備。要查看這些空設備，請使用以下命令：

$ lsblk -a

該選項將列出所有設備，包括空設備在內。

列出設備權限和屬主 ​

lsblk命令也可以用於列出一個特定設備的擁有關係，同時也可以列出組和模式。可以通過以下命令來獲取這些信息：

$ lsblk -m

列出指定設備 ​

該命令也可以只獲取指定設備的信息。這可以通過在提供給lsblk命令的選項後指定設備名來實現。例如，你可能對了解以字節顯示你的磁盤驅動器大小比較感興趣，那麼你可以通過運行以下命令來實現：

$ lsblk -b /dev/sda

或者，以下命令等同：

$ lsblk --bytes /dev/sda

以列表形式列出不帶頭的設備 ​

你也可以組合幾個選項來獲取指定的輸出。例如，你也許想要以列表格式列出設備，而不是默認的樹狀格式。你可能也對移除不同欄目名稱的標題感興趣。可以將兩個不同的選項組合，以獲得期望的輸出，命令如下：

$ lsblk -nl

或者，你可以使用下面的長選項，它們也能給出相同的輸出。

$ lsblk --noheadings --list

列出SCSI設備 ​

要獲取SCSI設備的列表，你只能使用-S選項。該選項是大寫字母S，不能和-s選項混淆，該選項是用來以顛倒的順序打印依賴的。

$ lsblk -S

lsblk列出SCSI設備，而-s是逆序選項（LCTT譯註：將設備和分區的組織關係逆轉過來顯示），其將給出如下輸出。輸入命令：

$ lsblk -s

或者

$ lsblk --inverse

你可以使用lsblk來獲取關於你的塊設備的更多信息，自己把它試着顯示出來吧！
