安裝Linux Mint 17後要做的20件事 ​

Linux Mint 17 Qiana Cinnamon ​

Linux Mint 17已經發佈，定名為Qiana。Mint是Linux最佳發行版之一，它定位於桌面用户，關注可用性和簡潔。它攜帶了風格迥異的桌面環境，如Mate以及Cinnamon，並基於不同的發行版，如Ubuntu或Debian。

在本文中，我們使用的是Linux Mint 17的cinnamon版本。要獲取更多關於Cinnamon版本的信息（包括下載鏈接），可以訪問 - http://linux.cn/article-3260-1.html

下載適合你係統的正確的iso，燒錄成dvd，或者也可以製作成usb啓動盤來啓動。安裝完畢，是時候來使用一些優化工具和基本應用程序來優化系統性能和體驗，讓你係統激情澎湃吧！

1. 更新系統 ​

第一件事情是重中之重，就是讓你的系統保持時刻最新。趕緊在終端中運行以下命令吧。

$ sudo apt-get update
$ sudo apt-get upgrade

或者，你也可以使用更新管理器（mintUpdate）來幹這事，你可以在菜單（Menu）> 管理（Administration）中找到它。

2. 找回舊壁紙 ​

每個Linux Mint發行版都自帶了一套最新的漂亮的壁紙。但是，你也可以安裝先前版本中的壁紙。

$ sudo apt-get install mint-backgrounds-*

3. 多安裝些瀏覽器 ​

Linux Mint 17默認安裝了firefox，你也可以獲得更多的瀏覽器，如Chronium和Google Chrome。

Chronium瀏覽器可以在倉庫中獲取。

$ sudo apt-get install chromium-browser

至於Google Chrome，請訪問google.com/chrome下載deb包，並使用gdebi來安裝。

# 64 位
$ wget https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
$ sudo gdebi google-chrome-stable_current_amd64.deb

# 32 位
$ wget https://dl.google.com/linux/direct/google-chrome-stable_current_i386.deb
$ sudo gdebi google-chrome-stable_current_i386.deb

4. 安裝Flash Player ​

Mint上默認安裝adobe flash插件包（adobe-flashplugin），因此，你可以在Firefox中暢玩flash遊戲，也可以盡情享受網頁版視頻了。

Google Chrome現在使用了基於flash player的Pepper API，而且該插件也內建於Chrome中，因此，你也不需要為它額外做任何事情了。

然而對於Chronium，基於flash player的Pepper沒有被囊括進來（因為它不是個自由組件），所以你需要手動安裝了。

安裝以下包來為Chronium安裝pepper flash player。它會自動從Google Chrome瀏覽器中下載pepper flash player並加入到Chronium中。

$ sudo apt-get install pepperflashplugin-nonfree

上面的命令應該幫你將flash player安裝到Chronium裏頭了。萬一下載失敗，你可以使用下面的命令重新進行安裝。

$ sudo dpkg-reconfigure pepperflashplugin-nonfree

5. 安裝多媒體解碼 ​

受限的額外包可以幫你安裝大多數基本的解碼，可以讓你播放像mp3這樣的格式。它也會幫你安裝微軟字體。

$ sudo apt-get install ubuntu-restricted-extras

要啓用加密dvd的回放，請安裝以下包。

$ sudo apt-get install libdvdread4
$ sudo /usr/share/doc/libdvdread4/install-css.sh

6. 安裝專有驅動 ​

如果你有一張Nvidia或者ati的圖形卡，或者broadcom的無線網卡，那麼請安裝廠商提供的專有驅動，這些驅動會為你帶來最佳的硬件性能。

要安裝Nvidia驅動，你可以參照先前的這篇文章

如何在Linux Mint上安裝最新的Nvidia驅動

7. 安裝Dropbox ​

Linux mint倉庫已經提供了dropbox的客户端軟件包，所以你不必滿世界找了。

$ sudo apt-get install dropbox python-gpgme

如果你還是比較喜歡從官方網站下載，那麼翻牆可直達https://www.dropbox.com/install?os=lnx，請遵照説明下載用於Ubuntu的deb安裝包。（LCTT譯註：牆內用户還是忽視此條吧。）

Copy是另外一個雲存儲解決方案，它也有本地Linux客户端。詳情可查閲copy.com，它也有ppa倉庫。

8. Skype ​

Skype可以在Ubuntu canonical合作倉庫中找到。

$ sudo apt-get install skype

9. 安裝rar和其它歸檔工具 ​

要想在Nemo這樣的文件管理器中通過上下文菜單創建rar歸檔，請安裝rar工具。安裝rar的同時，也可安裝其它幾個包以增加對其它歸檔格式的支持。

$ sudo apt-get install unace p7zip-rar sharutils rar arj lunzip lzip

10. 安裝剪貼板管理器 ​

剪貼板管理器允許你維護和訪問通過像Ctr+C這樣的操作拷貝的項目歷史，gnome下有很多的剪貼板管理器，像diodon，clipit，glipper，parcellite。

Diodon在cinnamon桌面上似乎存在一些問題，在歷史列表增長時會出現滾動條。Clipit和Gipper工作得很好，你也可以安裝

$ sudo apt-get install glipper
# 或者
$ sudo apt-get install clipit

然後，你可以從應用程序菜單中啓動它們，它們應該會在你每次登錄時啓動。

11. 優化桌面 ​

1. 修復系統托盤上的日期格式 ​

在底部面板右邊的時間小程序只顯示了時間，它也可以設置顯示日期。右擊底部面板右邊的日期-時間小程序，然後點擊配置，選中標有“使用自定義日期格式”的選框，然後填入

%B %e, %I:%M %p

這會以帶有AM/PM的12小時格式顯示月份名稱、日期和時間。

2. 安裝主題、擴展、小程序、桌面組件 ​

為你的桌面搞一些好東西玩玩。你可以在桌面區域放置一些桌面組件，在面板上放些小程序，為桌面效果添加一些擴展，以及為桌面設計安裝一些主題。

去系統設置吧，點擊指定的圖標，你可以看見一個可供選擇的列表。點擊“在線獲取更多”標籤來下載更多的好東西。

3. 修改Firefox的搜索引擎 ​

你也許注意到，Firefox默認選擇了Yahoo搜索引擎，而搜索引擎列表中並沒有Google。點擊“管理搜索引擎” > 獲取更多搜索引擎，它會帶你去http://www.linuxmint.com/searchengines.php。

向下拉動滾動條到商業搜索引擎部分，找到並點擊Google圖標。進入下一頁後，再次點擊搜索引擎列表，而這次你會看到“添加Google”選項，點擊它就可以用上Google搜索了。（LCTT譯註：牆內用户也請忽略此條。怒！）

12. 優化字體渲染 ​

Linux mint默認使用Dejavu Sans字體，它看起來真普通啊。你可以使用Droid和Noto字體獲得好看得多視覺享受。請參照我們先前的教程，它會一步一步帶你漸入佳境。如何在Linux Mint上獲得華麗好看的字體

13. Guake下拉終端 ​

下拉終端讓你可以通過點擊單個鍵來訪問終端，Guake就是這其中之一，它用於基於gtk的桌面。下拉終端按要求顯示/隱藏，並保持運行，因此你無需從菜單或者啓動器中打開終端了。這對於熱衷於終端的人來説，這是一個必不可少的工具。

$ sudo apt-get install guake

Guake需要配置，以便在每次登陸時啓動。首先，找到guake命令的路徑。

$ which guake
/usr/bin/guake

現在，把它添加到啓動程序列表中。出門左拐，請往系統設置 > 啓動程序，然後點擊添加。在對話框中填寫

名稱 - Guake下拉終端 命令 - /usr/bin/guake

點擊添加。現在Guake已經跑到你的運行程序列表中去了，並每次會自動啓動。

14. Uget下載管理器 ​

Uget是一個簡潔而健壯的跨平台下載管理器，在Linux上工作得很好。雖然它缺少分段下載文件功能，但是仍然是一個十分穩定的下載管理器。

$ sudo apt-get install uget

15. Deluge BitTorrent客户端 ​

Linux Mint自帶了Transmission，這是個簡潔而高效的torrent客户端。如果正在尋找一個更有特色的torrent客户端，那麼你可以試試deluge或者vuze（正式名稱是azureus），還可以試試qbittorent。

$ sudo apt-get install deluge-torrent

16. Hardinfo - 系統信息工具 ​

Hardinfo是一個十分便利的GUI工具，它可以用來報告大量完整的系統硬件信息。你可以通過它來集中查看處理器、內存、存儲設備、網絡配置、打印機、usb設備、聲音/視頻適配器等等信息。它具有測試和評估系統性能的功能。

$ sudo apt-get install hardinfo

17. 安裝MATE桌面環境 ​

除了Cinnamon，Linux Mint還自帶了另一個流行的桌面環境MATE（Maatay）桌面。如果你想試試，那麼就來安裝吧。

$ sudo apt-get install mint-meta-mate

現在你可以在登陸屏幕選擇MATE會話了。

18. 讓其它分區可寫 ​

如果你有其它ext分區，比如想用來存儲和備份文件，那麼你需要讓它們可寫，以免每次都要使用root特權。

首先，使用gksudo在文件管理器裏打開分區掛載目錄

$ gksudo nemo

導航到分區目錄，右擊去往屬性 > 權限標籤

賦予“目錄訪問” - 創建和刪除文件權限給用户、組和其它。

賦予“文件訪問” - 讀和寫權限給用户、組和其它。

對於NTFS分區，你不需要做此事。

19. 安裝Conky ​

Conky是一個輕量級系統監控工具，它通過桌面圖形組件顯示系統各種資源的統計數據，如cpu、內存、網絡等。它不是必須的，但是可以讓你的桌面更加絢麗奪目。

$ sudo apt-add-repository -y ppa:teejee2008/ppa
$ sudo apt-get update
$ sudo apt-get install conky-manager

從應用程序菜單啓動Conky管理器，並添加組件到桌面。也可以選中開機啓動選項來讓Conky開機啓動。

20. 安裝一些遊戲 ​

Linux確實有一些酷爽的遊戲，很具娛樂性，而且是免費的。注意，某些遊戲像supertuxkart和0ad要求專用的圖形處理器以優化性能。

# 0ad - 像帝國時代那樣的策略遊戲
$ aptitude search 0ad

# supertuxkart - 賽車遊戲
$ aptitude search supertuxkart

# openarena
$ aptitude search openarena

倉庫中還有更多的遊戲可供你安裝，像Alien arena, secret maryo chronicles, supertux, frozen bubbles等等。

清除 ​

做完這一切後，請為系統進行一次大掃除，移除一些不必要的包。

$ sudo apt-get autoremove

注 ​

為Google Chrome/Chronium提供Java小程序支持 ​

默認情況下已經安裝了"icedtea-plugin"，用以為firefox提供java小程序支持。

然而，Chrome和Chronium卻不再支持基於NPAPI的插件。因此java小程序，在沒有獲得基於Pepper api的java插件前，java小程序是不能在這些瀏覽器中工作的。要查看更多信息，請往這裏。

更多應用程序 ​

如果你正在為你的Mint盒子尋找更多的應用程序，那麼這裏列出了一部分更好的應用程序，所有這些都可以在軟件管理器中安裝。

  • Opera - 網頁瀏覽器
  • Gnome Encfs Manager - 管理使用Encfs加密的文件和文件夾
  • Smplayer - 多媒體播放器
  • Rhythmbox, Clementine - 音樂播放器
  • Openshot, Kdenlive - 視頻編輯器
  • Audacity - 音頻編輯器
  • Inkscape - 圖形和圖像編輯
  • Gparted - 分區編輯器
  • Gufw - 防火牆配置工具
  • qBittorrent, Vuze - Torrent客户端
  • Gwenview - 圖像瀏覽
  • Team viewer - 遠程桌面
  • Tv-maxe - 查看電視頻道
  • Grub Customizer - 修改GRUB啓動菜單設置
  • Linrunner TLP - 電源管理工具，對筆記本節電很有用
  • Virtualbox - 虛擬化
  • Kazam, recordMyDesktop - 桌面錄像/演示
  • Bleachbit - 通過刪除舊的/臨時文件釋放磁盤空間
  • Cheese - 使用網絡攝像頭拍照
  • Shutter - 帶有眾多功能的屏幕截圖工具

那麼，請選擇你喜歡的那些，並盡情享受Linux Mint吧！！
