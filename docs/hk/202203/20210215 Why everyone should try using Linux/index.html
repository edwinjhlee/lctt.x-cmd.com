為什麼每個人都可以試試 Linux ​

如果你對 Linux 有着充滿好奇，那開源社區可以讓你輕鬆上手 Linux。

如今，人們有更多的理由喜歡 Linux。在這裏，我會分享使用 Linux 的 21 個不同的理由。我們來討論討論，為什麼每個人都可以嘗試一下 Linux。

Linux 對外行人來説，好像是一個神秘的東西。每當人們説起 Linux，就覺得它是計算機管理員或者系統管理員使用的，但也在討論在筆記本電腦和手機上使用 Linux。技術網站上列出了 你需要知道 的 十大 Linux 命令，但也有很多人在討論 Linux 桌面（不止一個）是多麼令人激動。

那麼， Linux 到底是幹嘛的呢？

Linux 對可用性的支持是它眾多重要特性之一。如果你對 Linux 有着充滿好奇，那開源社區可以讓你輕鬆上手 Linux。

先嚐試 Linux 應用 ​

無論是從 Windows 換到 Linux、還是在 Windows 和 Mac 之間橫跳，亦或是從 Mac 換到 Linux，要想改變一個人的計算機操作系統的使用習慣是一件很難的事。雖然這件事很少會去討論，不過現在的電腦是一個比較個性化的東西，每個人都習慣於自己電腦當前的使用習慣，他們往往不願意去做太大的變化。對我來説，就算在工作電腦跟個人電腦中來回切換（兩者都運行相同的操作系統），也需要我調整我的心理和肌肉習慣，僅僅是因為兩個電腦針對不同的活動場景進行了優化。儘管我被附近的人稱為“很瞭解計算機的傢伙”（，我也這麼認為）。但如果我不得不更換我常用的操作系統，我會覺得自己的生產力跟舒適感將在一兩週內直線下降。不過這還是比較表層的，雖然我知道怎麼用其他的操作系統，但是我需要時間去形成新的直覺跟習慣，需要記住在新系統中，一些不起眼的配置選項的位置，還得知道要怎麼使用新的功能。

出於這個原因，我經常告訴那些對 Linux 感到新奇的人，學習 Linux 的第一步就是要去使用 Linux 的應用。實際上，Linux 上專用的應用程序不多，主要是因為 Linux 的大多數應用程序是開源的，因此熱衷於在所有平台之間移植。在 Linux 上的很多應用程序，可以在你目前的非 Linux 的平台上去嘗試。把替換你默認的應用程序作為一個目標，不管是出於習慣還是方便，都要用開源的等價物。

應用替換 ​

這個練習的目的是通過你最終要運行的應用軟件，來實現向 Linux 的軟過渡。一旦你習慣了一套新的應用程序，那麼在 Linux 系統上，除了系統設置和文件管理外，就沒有其他什麼要適應的了。

如果你還不確定哪個是自己常用的應用，只需看看你的最近使用的應用程序列表（如果你的系統上沒有最近使用應用的列表，那還等啥，趕緊換成 Linux 系統吧）。一旦你確定了必須使用的應用程序，可以看看我們的 應用替代方案 頁面，瞭解許多被視為與流行的專有應用程序等效的常用開源應用程序。

獲取 Linux ​

不是所有的開源軟件都能移植到其他平台，並從在 Linux 上運行而受益。如果你想最終切換到 Linux，那就得完成這個過渡。幸運的是，要安裝 Linux 就像下載它一樣簡單，幾乎就像是另一個開源程序一樣。

通常，Linux 的安裝鏡像提供了實時模式跟安裝模式兩種模式，這意味着你可以從 Linux 介質啓動，並且在實時模式下運行使用，而無需將系統安裝到計算機。這是瞭解操作系統的好方法，但因為只是一種臨時體驗，所以啓動後不會保留數據。但是，有些發行版，如 Porteus Linux，是專門為在 USB 上運行而設計的，這樣你的個人數據就能保存。我在鑰匙串上掛了一個 Porteus 的 U 盤，所以我無論在哪裏，我都有一個可以啓動的Linux 系統。

“最好的” Linux ​

一旦你決定開始安裝 Linux 系統，你會發現有很多 Linux 發行版都是免費的。如果你之前用的操作系統版本只有一兩個選擇（例如，家庭版或商業版），那麼你會對 Linux 操作系統有這麼多發行版感到困惑。不過，實際情況沒這麼複雜。Linux 就是 Linux，它的下載和安裝的不同“流派”沒有什麼太大的不同。像 Fedora、 Debian、Linux Mint 和 Elementary 這些大牌的系統廠商都提供了同樣的體驗，只是在重點略有不同。

  • Fedora 以軟件更新迭代快而出名
  • Linux Mint 可以輕鬆安裝缺失的驅動程序
  • Debian 因能提供長期的支持而受歡迎，因而更新是相對緩慢，但是可靠性很高
  • Elementary 提供了精美的桌面體驗和幾個定製的特殊應用程序

總而言之，所謂最好的“Linux 系統”，即是最適合你的 Linux 系統。而最適合你的 Linux，就是，在你嘗試過後，發現你所有的計算機功能仍然能按預期工作的 Linux。

獲取驅動程序 ​

大多數的驅動程序已經被捆綁在 Linux 的內核中了（或者作為內核模組），特別是在使用一到兩年前的計算機零件和外圍設備時常常如此。對於已經上市一段時間的設備，Linux 程序員有機會去開發驅動程序或者將公司的驅動程序集成到系統裏。我曾不止一次讓人驚訝，只需將 Wacom 圖形輸入板、遊戲控制器、打印機或掃描儀連接到我的 Linux 計算機中，不需要下載安裝驅動程序，而且幾乎不用配置，可以立即使用。

專有操作系統在處理設備驅動程序方面有兩種策略。要麼是限制用户在操作系統中使用的設備，要麼是付費給公司，讓他們編寫驅動程序並與設備一起提供。第一種方法有種讓人不適的限制性，但是大多數人（可悲的）習慣了某些設備只能在某些平台上運行的想法。而後一種方法，被認為是一種奢侈，但在實踐中，這種方法太過於依賴程序員。舊貨店有很多計算機外圍設備，雖然它們設備狀況良好，但卻基本上報廢了。因為設備製造商已經不再維護此設備在現代系統運行所需要的驅動程序了。

對於 Linux 來説，驅動程序要麼由製造設備的廠商來開發，要麼是由 Linux 的程序員來開發。這就可能會導致，某些驅動程序集成到操作系統的時間會被延遲（例如，新的設備可能要在發佈後六個月才能在 Linux 系統上運行），但它有一個明顯的優勢，即長期支持。

如果你發現有一個驅動程序還沒有進入發行版，那你可以等幾個月再試一次，有可能是驅動程序已經集成到了系統的鏡像裏了，或者可以到不同的發行版中找找有沒有你要的驅動程序。

為 Linux 付費 ​

通過購買預裝 Linux 的 PC 或者經過 Linux 認證的 PC，可以避免所有的選擇和關於兼容性的擔憂。一些供應商提供預裝 Linux 的計算機，如所有的 System76 和部分 Lenovo 型號。此外，所有的 Lenovo 型號都有 Linux 兼容性認證。

這是迄今為止嘗試使用 Linux 最簡單的方法。

邁向 Linux ​

這是一個挑戰，瀏覽自己電腦上安裝的每個應用程序，並找到潛在的對應開源替代程序。選擇一個你經常使用但不是每天都用的應用程序，在下次要用的時候換成開源的應用程序。花點時間學習新的應用程序，直到能夠將它作為你的新的默認程序，或者直到你確定需要嘗試一個新的選擇。

隨着你使用的開源產品越多，你就越準備好進入激動人心的 Linux 世界。最後，你會用上 Linux 桌面還有你最喜歡的開源應用程序。
