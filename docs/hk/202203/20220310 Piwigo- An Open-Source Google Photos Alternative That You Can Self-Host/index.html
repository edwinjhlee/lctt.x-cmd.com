Piwigo：一個你可以自行託管的開源谷歌照片替代品 ​

如果你想擺脱“谷歌照片”，Piwigo 是一個令人印象深刻的開源替代方案，能夠自我託管。讓我們來探討一下它的更多信息。

“谷歌照片”是備份你的照片和視頻的最流行的選擇之一。（LCTT 譯註：並不是……）

考慮到它是大多數安卓手機的默認選擇，使用谷歌照片管理照片/視頻是一種無縫體驗。

但是，如果你想從它那裏轉移到一些開源的、對隱私更友好的東西怎麼辦？不只是谷歌照片，還有其它一些照片託管平台也是專有的。

請看看 Piwigo，一個開源的 照片管理軟件 來幫助你。

Piwigo：你可以自行託管的開源照片庫 ​

Piwigo 是一個開源解決方案，可以幫助管理你的照片和視頻。

你可以選擇自己託管，控制你的數據，或者選擇雲託管（數據存儲在法國，有備份）。

順便説一句，該公司起源於法國。

不僅僅是針對個人，Piwigo 也為組織和團隊量身定做。

如果你擔心使用谷歌照片或類似服務上傳時的隱私政策，Piwigo 可以成為一個出色的替代品。

Piwigo 提供了一系列的功能和細粒度的控制來管理你的照片。

Piwigo 的功能 ​

雖然它是主流服務的一個可行的替代品，但它為個人和組織提供了先進的功能。

一些功能包括：

  • 通過雲託管（*.piwigo.com）獲得你的專用子域
  • 能夠批量下載
  • 創建相冊
  • 選擇照片來分配現有的相冊集
  • 通過鏈接分享照片
  • 用公共和私人模式進行訪問管理
  • 能夠對用户進行分組，以管理你的相冊或照片（對組織/團隊來説很有效）。
  • 基本分析，以跟蹤你的使用情況和使用的存儲空間
  • 支持向相冊/照片添加標籤
  • 支持深色模式
  • 能夠編輯照片的元數據
  • 過濾器，以快速找到照片/相冊
  • 支持 JPG/JPEG、PNG 和 GIF 文件（針對個人）
  • 支持所有文件類型（僅適用於企業使用）
  • 為個人用户提供無限的存儲空間
  • 支持自定義域名（即使是雲託管選項）
  • 插件可擴展功能
  • 支持主題
  • 移動支持（安卓和 iOS）

除了上述功能外，你還可以獲得改善用户管理和 Piwigo 的整體用户體驗的更多選項。

我使用其針對個人的雲託管選項（有 30 天的試用期）對其進行了快速測試。讓我分享我的一些見解，以幫助你在嘗試之前瞭解它們。

使用 Piwigo 來管理照片 ​

當你註冊一個賬户時，你可以指定你的自定義子域。

例如，我把我的測試賬户放在 ankushsoul.piwigo.com。

任何人都可以通過在他們的瀏覽器中輸入上述 URL 來訪問我公開分享的照片/相冊。

所以，最好是儘可能保持子域的名稱獨一無二。在這兩種情況下，你也可以將相冊/照片限制給登錄的用户（或你自己），其他人即使知道你的子域，也無法訪問你的照片。

你可以前往它的儀表板，檢查你的存儲使用情況和整體活動情況。

它有兩個激活的插件，一個用於內部功能，另一個默認用於打擊垃圾信息。

你會發現有很多插件可以加強批量管理，啓用管理員信息，激活相冊的評論，在你的相冊上添加到期時間，限制下載，以及訪問一些令人興奮的功能。

你可以花點時間瀏覽一下現有的插件選擇，評估一下它們與谷歌照片相比能有多大用處。

當然，你在任何主流的雲照片託管服務中都得不到這種控制。

所以，這很值得探索。

對於現有的其他功能，你可以管理多個用户，控制訪問，發送通知（通過電子郵件），還可以進行一些維護活動。

總的來説，用户體驗是相當好的。它可能沒有提供最現代的用户界面，但它可以工作，而且很容易管理。

注意：考慮到 Play Store 上的應用沒有收到最新的更新，移動體驗（在 Android 上）可能並不令人滿意。然而，你可以在他們的 GitHub 上找到最新版本的 APK 文件。

開始使用 Piwigo ​

我認為 Piwigo 非常適合各類人使用，從想組織照片的人，到想合作/分享圖片的用户，都可以使用。

如果你選擇自我託管，你應該查看它的 文檔 和探索 GitHub 頁面。

考慮到你獨自管理它，你將需要適當地維護實例，並對你的數據進行備份。

如果你選擇 雲託管選項（作為個人），定價從每年 39 歐元 開始，不限圖片文件上傳，如果你訂閲 3 年，價格會更便宜。

個人計劃沒有提到具體的存儲限制（無限）。因此，可以説你不應該有任何問題，除非你開始濫用該服務。

鑑於你在該服務中得到的控制權，大多數用户會更願意使用雲託管服務，而放棄像谷歌照片這樣的服務。

企業/組織的定價計劃將是昂貴的（每月）。然而，它支持企業的所有文件類型。
