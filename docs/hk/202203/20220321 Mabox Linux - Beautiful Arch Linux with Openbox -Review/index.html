Mabox Linux：帶有 Openbox 的美麗的 Arch Linux ​

Mabox Linux 是一個 Manjaro Linux 重製版，帶有一個輕量級的 Openbox 窗口管理器，已經預配置了主題和實用程序。我們將在這篇文章中點評這個發行版。

如果你喜歡窗口管理器，也喜歡基於滾動發佈的 Arch Linux，並且正在尋找一個具有這種組合的現成 Linux 發行版，可以試試 Mabox Linux。Mabox Linux 是建立在很棒的 Manjaro Linux 之上的，帶有 Openbox 窗口管理器和一些原生實用程序。

由於採用了 Openbox，這個 Linux 發行版在維持超輕量級的資源消耗的同時，也提供了一個漂亮的桌面。改編自 BunsenLabs，並受 Crunchbang 啓發的 Mabox Linux 工具也帶來了他們的一些應用。

讓我們來深入瞭解一下這個了不起的 Linux 發行版。

Mabox Linux 點評 ​

安裝和現場介質 ​

Mabox .ISO 的優勢之一是它在現場介質Live medium啓動過程中為你提供了自由和專有的驅動程序的兩種選擇。如果你的系統中有英偉達或其他硬件，這對你有幫助。

現場桌面Live desktop讓你可以通過 Calamares 安裝程序來安裝 Mabox。在標準硬件上，安裝大約需要 3 到 4 分鐘，在我的測試中沒有遇到錯誤。

安裝程序也會檢測測試設備中的其他操作系統。

具有自定義的外觀和感受 ​

Mabox 帶來了一個預配置的 Openbox 窗口管理器。這個搭配的版本看起來不錯，有深色外觀和帶面板的菜單。

頂部的面板是用 Tint2 構建的，分成兩個部分。左邊的面板為你提供了主菜單、文件管理器、網頁瀏覽器的快捷方式。面板上的鼠標左鍵和右鍵有不同的菜單。右邊的面板包含資源監視器、音量控制、截屏快捷方式和電源菜單。頂部面板不是連續的，在某些主題下，應用程序窗口會停留在頂部。

在桌面的右邊部分，預配置的 Conky 腳本可以給你提供系統信息，包括日期、時間、存儲和其他顯示。

歡迎窗口為你提供了關於設置、幫助和支持的快速啓動快捷方式，並有文檔鏈接。

窗口管理器適合於鍵盤操作，有時不便於用鼠標操作。但由於 Openbox 和預配置的 Mabox，你可以輕鬆地使用鼠標，同時通過靈巧的鍵盤快捷方式提高你的工作效率。

桌面上的右鍵菜單為你提供了輕鬆的搜索和啓動選項。

如果你不喜歡默認的外觀，你可以通過 Openbox 和 Tint2 面板配置工具，只需點擊幾下就可以自行定製。

Mabox 預設有不同的主題，包括面板和 Concky 腳本。你可以點擊並應用這些令人驚歎的 Mabox 主題。如果你不想陷入自己配置面板、顏色和 Conky 的麻煩中，這是一個很好的功能。

一套好的牆紙可以讓你隨時讓它在短時間內看起來更加美妙。

應用 ​

Mabox Linux 將所有必要的應用打包在其安裝鏡像中。以下是所包含的基本應用的簡單列表。

  • Terminator 終端
  • Xpad 快速寫字板
  • PCManFM 文件管理器
  • FSearch 桌面文件搜索
  • Flameshot 截圖工具
  • Geany 文本編輯器
  • Audacious 音樂播放器
  • Firefox 網頁瀏覽器

Mabox 還包括控制中心，以有效管理你的系統。Mabox 控制中心可以讓你添加/刪除應用、更新你的系統、啓動窗口管理組件的幾個配置窗口，諸如此類。

如果你找不到某個設置，你可以在 Mabox 控制中心通過其系統設置的邏輯分組輕鬆找到它們。

性能如何？ ​

Mabox Linux 的性能令人印象非常深刻。由於採用了 Openbox 窗口管理器，Mabox 只用了大約 350MB 多點的內存，而 CPU 在空閒狀態下徘徊在 2% 到 3%。

默認安裝需要大約 5.39GB 的磁盤空間，這對於預裝的這些應用和設置程序來説是不可思議的。

在如此優化下，以至於它消耗內存最多的應用是 Xorg，有 90MB。

所以，我想嘗試一下重度使用下的性能。而這個性能也是令人驚訝的。我打開了一個文件管理器、帶三個標籤的 Firefox、一個用於開發的文本編輯器、一個終端窗口和控制中心。在這樣的工作負荷下，Mabox 只消耗了大約 920MB 的內存和 6% 到 7% 的 CPU。

在 點評幾個發行版 的過程中，這是我第一次發現一個發行版在重度工作負荷下不超過 1GB 內存的情況。但在不同的使用情況下，結果可能有所不同。無論如何，這個指標還是令人印象深刻。

Mabox Linux 可以作為日常使用嗎？ ​

如果你對帶有窗口管理器的 Arch Linux 比較熟悉和適應，你可以把 Mabox Linux 作為日常使用。有幾個打包好的帶有窗口管理器的 Arch Linux 發行版，而 Mabox 是其中最好的一個。

總結 ​

我認為 Mabox Linux 團隊將所有組件與 Arch Linux 打包在一起，並呈現出一個漂亮的 Linux 發行版，做得非常好。它的外觀驚豔，而消耗的系統資源卻很少。有了基於 Arch Linux 的滾動發佈功能，我認為你可以信賴這個發行版的長期使用。

你可以從它的 官方網頁 下載 Mabox Linux。
