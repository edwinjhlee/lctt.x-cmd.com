復活的 C4C Linux 發行版 ​

Computers4Christians 項目以定製發行版的形式進行了改革，該發行版為有基督教信仰的人提供了軟件。

當我剛開始在這裏寫作時，我介紹了一個 基督徒的 Linux 發行版，距離現在已經有 6 個年頭了，讓我們來速覽一下這個項目在 6 年的時間裏都有哪些變化吧。

名字變了，性質也變了 ​

當我們第一次碰到 Computers4Christians，他們是一個基督教團體，通過安裝 Linux 系統來翻新舊電腦，並把它們捐贈給當地社區。他們大約捐贈了 1000 台翻新的舊電腦。該團體基於 Lubuntu 定製了自己的 Linux 版本，名字叫 “Computers4Christians Linux Project”。

今天，Computers4Christians 已經不再捐贈翻新的舊電腦了。取而代之的是，這三個開發者正在專注於開發重命名的 C4C Ubuntu。

當我問他們為什麼決定要繼續開發這個發行版時，他們回答説：

我們希望引導那些不信奉上帝的人與耶穌·基督建立真正的聯繫，並藉此發展一些信徒。任何人都可以，在幾乎任何電腦上，下載、運行臨場鏡像或者安裝我們的 Linux 發行版。C4C Ubuntu 用户可以通過多個版本的聖經、基督教教義、每日靈脩、基督教視頻和遊戲等方式聆聽上帝的教誨。我們祈禱每一次的下載、運行和安裝 C4C Ubuntu 鏡像，都能幫助用户走向基督，或是更接近上帝。“向軟弱的人，我就作軟弱的人，為要得軟弱的人；向甚麼樣的人，我就作甚麼樣的人。無論如何總要救些人。” —— 哥林多前書 9:22（網絡）

C4C Ubuntu 中都有什麼？ ​

當前版本的 C4C Ubuntu 基於最新的 Ubuntu LTS（20.04.4）構建。它使用 Xfce 桌面環境代替了 GNOME 桌面環境。我問他們為什麼決定基於 Ubuntu 而不是 Lubuntu。開發者 Eric Bradshaw 告訴我説，他們之所以切換到 Ubuntu，是因為 Lubuntu 的 LXQt 桌面環境有缺陷，而且它在舊電腦上表現不佳。

以下是 C4C Ubuntu 預裝的內容：

  • 主要的常用軟件：Catfish、FileZilla、GIMP、Gnash、GnuCash、Gufw、LibreOffice、OpenJDK Java 11、Pidgin、Pinta、Synaptic、Thunderbird 和 VLC。
  • 與基督教或聖經相關的軟件和媒體：十二使徒問答和記憶遊戲、聖經、聖經桌面版、8 個聖經知識遊戲、10 個聖經經文迷宮探索遊戲、Diatheke、117 個 Flash 聖經遊戲、24 個有趣的聖經故事、Verse、Wide Margin、西福斯聖經指南、新信徒和門徒的閲讀材料以及基督教視頻。
  • 聖經：有聲聖經（WEB）、AKJV、ASV、BBE、ERV、KJV、NHEB 和 WEB。註釋：MHC、NETnotesfree、Personal 和 TFG。每日靈脩：DBD 和 SME。詞典：MLStrong、Robinson、StrongsGreek 和 StrongsHebrew。通用書籍：MollColossions 和 Pilgram。地圖：ABSMaps、eBibleTeacherMaps、EpiphanyMaps、HistMidEast、KretzmannMaps、NETMaps、SmithBibleAtlas 和 SonLightFreeMaps。
  • 我們的背景圖片包括 150 張不同的“上帝的創造God's creation”，提供高清、標準和寬屏等尺寸大小。我們還提供快捷方式或啓動器，你可以在“基督教”子菜單中找到它們，點擊即可直達 37 個在線的基督教視頻集、音樂視頻集和 YouTube 頻道。
  • 預裝的 Firefox 上有數百個手工挑選和分類的書籤，不管你是要學習 Linux 還是要了解上帝，你都可以找到相關書籤。有一個叫 “FoxFilter” 的家長控制擴展可以幫助過濾掉網頁上不適當的內容，用户如果覺得有用，可以訂閲它。
  • C4C Ubuntu 團隊引入了 GNU Gnash 的 snap 包，它是一個 Flash 播放器。有了它，用户就可以玩預裝的 Flash 聖經遊戲了。

如果你想要嘗試 C4C Ubuntu，你可以在 這裏 找到下載鏈接。這個網站有很多關於他們的歷史版本信息。同時，開發團隊也在不斷更新這個網站。
