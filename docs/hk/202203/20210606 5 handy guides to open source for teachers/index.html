5 個為教師準備的方便的開源指南 ​

我們收集了一些最受歡迎的簡明指南，它們既能滿足你充分利用暑假的願望，又能滿足你為下一個學期做規劃的需要。

對一些老師來説，夏天到了，一個漫長的（希望也是放鬆的）假期也到了。所有我認識的老師都是自豪的終身學習者，儘管暑假過後，又有一個新學期會到來。為了幫助你充分利用暑假時間，與此同時也為即將到來的下一個學期做好準備，我們收集了一些最受歡迎的 簡明 指南。

如何讓你的學校做好準備（在新冠疫情下） ​

通過 在 Linux 上來完成所有相關工作，Robert Maynord 老師確保了他的學校為遠程學習做好了準備，甚至在疫情前他就這麼做了。雖然我們還不知道在今年剩下的時間裏會發生什麼，但是，如果説新冠疫情向世界展示了什麼，那就是 數字轉型（指把數字技術融入到教育的各個領域）不僅是可能的，而且對教師和學生來説都是有益的。你可能無權在技術層面上改變課堂的運作方式，但你仍然可以做很多小的改變，為學生創造更靈活的學習體驗。

為教師準備的終極開源指南 ​

通過本文，你可以學習如何在課堂上 融入開源原則。開源不僅僅和科技相關，它同時也關於知識共享、團隊協作以及為了一個共同目標而努力。你可以把你的教室變成一個共享的空間，讓學生們互相學習，就像他們向你學習一樣。閲讀開源，把開源付諸實踐，並鼓勵學生們積極參與。

8 個為虛擬教室準備的 WordPress 插件 ​

WordPress Web 平台是一個構建網站的強大工具。在教室裏，它可以作為教授 Web 技術、創意寫作和學術寫作的 一個很好的工具。它也可以被用來幫助遠程學習，或者是把日常的學校作業數字化。通過掌握 WordPress 的諸多 [附加功能]，你可以從中獲取到最大的教育收益。

教孩子們寫 Python（交互式遊戲） ​

開源工具可以幫助任何人以一種輕鬆有趣的方式開始學習 Python —— 那就是製作遊戲。當然，Python 涉及到很多方面的東西。別擔心，我們有一個課程可以帶你從安裝 Python 開始，通過簡單的文本代碼和 “海龜turtle” 繪圖遊戲開始你的第一步，一直到中級遊戲開發。

  1. 首先，安裝 Python，閲讀我們的 Python 入門文章，熟悉編程的概念。單單是這篇文章裏的內容就可以作為兩節或三節不同課程的基礎哦。
  2. 然後，如果你熟悉 Jupyter 庫的話，可以學習 使用 Python 和 Jupyter 來編寫一個簡單遊戲。
  3. 接着，你也可以 在這本 Python 電子書裏學到遊戲開發的知識，裏面會教你如何使用 Git、Python 和 PyGame 庫。當你學會了這些基礎內容，你可以看看 這本書裏的 "遊戲測試員" 的有趣創作集合。

如果 Python 對你或你的學生來説太難了，那麼看看 Thine 吧，它是一個簡單的基於 HTML 的交互式的講故事工具。

教孩子們玩樹莓派（編程） ​

我們的指南中有一篇 樹莓派入門指南，其中探索了各種幫助孩子們學習編程的資源。樹莓派的特點是它足夠便宜，只要花 35 美元，你就可以買到一個全功能的 Linux 電腦。然後你就在上面做任何事，不管是基本的 Python 學習還是搭建實際的網絡服務器，因此，它有着巨大的教育潛力。你完全可以為每一個學生都配一個樹莓派，或者你也可以讓班裏的學生共享一個樹莓派（Linux 是多用户操作系統，只要設置得當，所有的學生都可以同時使用這個樹莓派，直到你説服他們的家長購買更多樹莓派）。

一起學習 ​

開放課堂的關鍵之一是要勇敢地和學生一起學習。作為一個老師，你可能習慣了掌握所有的答案，但是數字世界是不斷改變和進化的。不要害怕 和 你的學生們一起學習 Python、Linux、樹莓派或者任何其他東西，一起學習新的基礎知識、小技巧和解決問題的新方式。開源是一種經過驗證的成功方法，所以不要只是教授開源而已，還要讓開源在你的課堂上得以運用。
