Gitter：面向開發者的跨平台開源社區平台 ​

一個為開發者量身定做的跨平台開源解決方案。你可以建立或加入現有的社區來進行協作和互動。

幾乎每個網絡用户都知道 Slack、Rocket.Chat、Trello、Nextcloud，以及其他一些用於工作溝通和協作的解決方案。

如果你喜歡用 FOSS 來進行團隊協作，我們也有一個 Slack 的開源替代品列表。

但是，作為一個軟件開發者，如果你偶然發現了一個開發者社區怎麼辦？

與 Reddit 或其他社交媒體上的社區不同，你可以進入一個開源平台，在那裏，開發者們遇見並就重要的開源項目進行合作。這對於社交協作和同行之間的互動來説，不是很令人興奮嗎？

Gitter（現在是 Element 的一部分，也是一個協作/聊天應用）的目標就是這樣。它是一個由開源技術驅動的社區平台（Matrix 協議）。

Gitter：使用開源技術連接的開發者社區 ​

Gitter 是一個令人興奮的聊天和網絡平台，有助於建立或加入現有社區。它可用於 Linux、macOS 和 Windows。

它是專門為開發者定製的，可以為他們各自的語言/項目，如 CSS、JavaScript、Bootstrap、NodeJS 等，進行合作/加入社區。

你也可以輕鬆地創建你的社區，而無需設置任何邀請服務。

該平台的關鍵亮點是，社區是完全開放的，可被搜索引擎索引。對於社區中的對話歷史，你不會被任何定價計劃所鎖定，你所需要查看的是歸檔。

而且，你在 Gitter 獲得的功能還有很多。

Gitter 的功能 ​

雖然 Gitter 最初是為開發者定製的，但如果你認為它的功能符合你的要求，你可以用它來建立任何類型的社區。

  • 由一個去中心化的 Matrix 網絡支持。
  • 可公開加入的社區。
  • 能夠將你的社區限制在選定的用户中。
  • 深色模式主題。
  • 訪問歸檔，輕鬆找到過去的對話。
  • 能夠導出信息/房間信息。
  • 從你的網絡中添加用户（例如，如果你使用 Twitter 登錄，你可以選擇從 Twitter 邀請用户到你的社區）。
  • 幾個可用的集成（GitHub、Bitbucket、Trello、GitLab、Docker Hub、Discourse 等）。
  • 支持 GitHub 風格的 Markdown。
  • 在同一社區下創建更多的房間，以保持事情的條理性。
  • 輕鬆地分享/嵌入聊天室的鏈接。
  • 帖子系統，以保持對話的整齊。
  • 刪除/報告信息的能力。

總之，Gitter 提供了適合不同社區的各種功能。

而且，通過 GitHub、GitLab 和其他一些網站的集成，它成為開發者和團隊的一個完美的合作選擇。

在 Linux 中安裝 Gitter.im ​

開發人員主要專注於網絡應用。因此，如果你想避免在你的 Linux 桌面上安裝任何東西，請前往 Gitter.im 並註冊/登錄以開始使用。

如果你想讓它成為一個桌面應用，你可以從其官方網站下載 DEB 包，或者可選擇 Snap 包和 Flatpak 包。

我在簡短的測試中嘗試了 Flatpak 包，它在 Ubuntu 20.04 LTS 上運行良好。你可以在你喜歡的任何一個 Linux 發行版上嘗試 Flatpak/Snap。

你也可以在你的移動設備上使用它。不幸的是，官方的 Gitter 移動應用已經不再維護。但是，你可以使用 Element 應用來登錄房間/社區，考慮到兩者都是由同一個去中心化的網絡（即Matrix）驅動的。

要了解更多信息，請瀏覽 GitLab 頁面或前往其網站。
