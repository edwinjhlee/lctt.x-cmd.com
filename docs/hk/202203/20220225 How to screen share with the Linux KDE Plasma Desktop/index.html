如何在 KDE Plasma 桌面進行屏幕共享 ​

krfb 和 krdc 的組合是使遠程 Linux 支持變得無挫折感的寶貴工具。

如果你曾經做過專業的或出於家庭義務的遠程支持，在待命支持時，解決問題只是第二步，更重要的是可見用户屏幕上的實際內容。有多少次你描述了複雜的桌面任務，後來才發現你的用户甚至還沒有打開他們的電腦？支持是重要的，但挫折感是真實的，對於需要支持的人和慷慨地試圖提供支持的人來説，這都是一種共同的經歷。我相信，作為學習新技能的一種方式，人們自己執行任務是很重要的，但也有一種説法是觀察專家應該如何做。這就是屏幕共享的作用，KDE Plasma 桌面已經內置了它。

網絡安全 ​

Plasma 桌面使用點對點的邀請模式進行屏幕共享。用户啓動一個應用，啓動一個虛擬網絡連接（VNC）服務器，這時，支持人員就可以遠程查看甚至控制計算機。如果這聽起來像是潛在的不安全，那是因為它可能就是，但有防火牆的干預。如果你是一個與你不在同一網絡上的人的支持人員，那麼你必須在屏幕共享工作之前建立一個從你的網絡到你的用户的網絡的安全通道。理想情況下，你會在緊急情況發生前完成這項工作。

  1. 配置用户的路由器，將 VNC 端口（默認為 5900，但你可以使用任何你喜歡的端口）路由到他們的計算機。
  2. 在用户的本地防火牆中打開一個服務，允許 VNC 流量（在你在第一步中指定的端口）。

遠程邀請 ​

為了啓動屏幕共享會話，用户必須啓動 krfb（表示 “KDE remote frame buffer”）應用。這將啓動一個 VNC 服務器，並創建一個臨時密碼。

krfb 使用的默認端口是 5900，但如果你需要，可以在 krfb 設置中改變。不過，這可能是你想提前做的事情，這樣你就可以避免向你的用户解釋如何改變協議的端口。

查看和控制 ​

當這個窗口打開時，你可以使用你喜歡的 VNC 客户端通過 VNC 登錄。KDE 有 krdc（表示 “KDE remote desktop client”）應用。在支持的計算機上，啓動它並向它提供目標 IP 地址。當你被提示輸入密碼時，輸入你正在連接的 krfb 會話中顯示的密碼。

連接上後，你就可以看到你用户的屏幕，你可以在他們遵循你的指示時引導他們。如果他們在遵循你的指示方面有困難，那麼你可以控制他們的鼠標，並演示如何做某事。默認情況下，krfb（即他們正在運行的應用）在將控制權交給你之前會徵求他們的同意。

幫助進行中 ​

能夠看到你的用户所看到的東西可以加速故障排除，減少支持電話雙方的挫折感。只要你事先為你的支持設置好網絡，krfb 和 krdc 的組合對於指導新用户完成 Linux 桌面發現之旅的 Linux 專業人士來説是很有價值的工具。
