嘗試 Nitrux 系統的六大理由 ​

Nitrux OS 是一個基於 Debian 的有趣的 Linux 發行版。還沒有試過嗎？我認為你應該試試。

Nitrux 系統也許算不上 Linux 的主流發行版本之一，但它絕對是一款極其獨特的產品。

2019 年，我們 採訪了 Nitrux 的創始人 Uri Herrera，瞭解到 Herrera 等人開發這款系統的初衷：超越傳統的 Linux 發行版。

自那之後，過了許久，我們終於迎來了 Nitrux 2.0 版本。

不要忘了，Nitrux 在去年 放棄基於 Ubuntu，而選擇了 Debian。

考慮到自 Nitrux 發行以來的數年間，也發生了許多變化，你應該嘗試一下這款系統。

這裏，我要分享一些體驗 Nitrux 系統 的理由：

1、Nitrux 不再基於 Ubuntu ​

人們一般都會推薦基於 Ubuntu 的 Linux 發行版本，來滿足日常所需。

當然，在我們 為新手推薦的 Linux 系統 中，也主要是許多基於 Ubuntu 的版本，但是請不要誤會。

我們之所以推薦基於 Ubuntu 的發行版本，唯一的理由在於它們簡單易用，支持大量的商業軟件。

所以，如果你不是剛開始使用 Linux 系統，同時也想嘗試既能讓你耳目一新，又不至於使你感到陌生，而且十分穩定的發行版，基於 Debian 的 Nirtux 是一個不錯的選擇。

你完全不需要在短期內迅速瞭解這款系統，就可以得心應手地使用終端來完成各項工作。

感興趣的話，可以參考我們的文章 Debian vs Ubuntu，瞭解更多。

2、專注 AppImage ​

AppImage 是一個通用的打包系統，這種軟件包不需要任何依賴。你不需要在 Linux 上安裝任何軟件包管理器或者依賴包，就可以直接運行 AppImage 應用。

AppImage 旨在打造便攜、高效的軟件包系統，省去安裝的步驟，與 Windows 系統的便攜版軟件非常相似。

Nitrux 操作系統專注 AppImage 應用軟件，為你帶來流暢的用户體驗。

NX 軟件中心是一個 GUI 程序，用户可以通過使用 Mauikit（該軟件中心的 UI 框架），安裝、管理 AppImage 應用程序。

3、基於 KDE 桌面環境的發行版 ​

Nitrux 操作系統是 搭載 KDE 桌面環境中最好的 Linux 發行版 之一。 如果你不喜歡 GNOME 或者其他開箱即用的桌面環境（DE），KDE 會是一個不錯的選擇。

也許你還不知道, 相較於其他桌面環境，KDE 可以在很多方面進行定製。

因此，在 KDE 桌面環境下，你可以毫不費力地打造自己的個性化桌面。

4、獨特的用户體驗 ​

Nitrux 的用户體驗結合了最好的 KDE 桌面環境與 Qt 技術，並對這些進行了調整，為你帶來全新的用户體驗。

雖然在使用 Nitrux 操作系統時，你不會覺得十分陌生，但是還是會感到有些許的不同。

即使你沒有對 Nitrux 系統做任何自定義的設置，開箱即用的體驗也足以讓它成為 最優雅的發行版 之一。

5、Maui Shell ​

Maui Shell 是 Nitrux 用户體驗的亮點之一。近來，Maui Shell 得到了進一步的完善，將這些呈現在了桌面端和移動端的融合界面上。

儘管 Maui Shell 目前還不成熟，但是外觀看起來十分大氣簡約，就像 System76 將要推出基於 Rust 的桌面環境 一樣令人興奮。

這也是我們推薦嘗試 Nitrux 操作系統最重要的原因之一。時間會證明，Nitrux 系統是否將會開啓桌面體驗的全新時代。

6、Xanmod 內核 ​

Xanmod 內核 是一個定製的主線 Linux 內核版本，對性能進行了適當的調整，附加了一些其他功能。有了它，你的桌面體驗一定能得到大幅提升。

自 2.0 版本起，Nitrux 操作系統選用 Xanmod 作為默認內核，為用户提供“升級版”的桌面體驗。

當然你也可以選擇其他 Linux 內核，比如 Liquorix 和 Libre，各擅勝場。

如果你不喜歡 Xanmod，也可以選擇長期支持版的主線內核。在 Nitrux 操作系統上，你完全可以無縫切換使用不同的內核。

總結 ​

誠然，從主流發行版轉到像 Nitrux 這樣的操作系統，需要考慮各種風險。

但是，我建議你好好考慮一番：

Nitrux 這樣的發行版熱衷於按照他們的願景來改進事情。

儘管背後沒有強大的企業和財力支撐，他們依然可以開發出這款令人驚豔的發行版、開發出 Maui 項目，以及別開生面的 Maui shell。

所以，我認為，我們也應該以己所能，盡己之力，支持這些優秀的發行版。

不過話説回來，每一款 Linux 發行版都會或多或少地存在一些問題。當你試用一款新的發行版時，你需要給它點兒時間，在最終將它作為日常使用的操作系統之前，慢慢地去適應它。

換言之，我推薦你在業餘時間試用 Nitrux 操作系統，或者直接裝個虛擬機來一探究竟。
