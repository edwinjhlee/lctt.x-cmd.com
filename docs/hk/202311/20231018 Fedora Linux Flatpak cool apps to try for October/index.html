10 月份在 Fedora Linux 上值得嘗試的酷炫 Flatpak應用 ​

本文介紹了 Flathub 中可用的項目以及安裝説明。

Flathub 是獲取和分發適用於所有 Linux 的應用的地方。它由 Flatpak 提供支持，允許 Flathub 應用在幾乎任何 Linux 發行版上運行。

請閲讀 “Flatpak 入門”。要啓用 flathub 作為你的 flatpak 提供商，請使用 flatpak 站點 上的説明。

Warehouse ​

Warehouse 是一個圖形程序，用於管理已安裝的 Flatpak 應用程序和 Flatpak 遠程應用。一些最重要的功能是：

  • 查看 Flatpak 信息
  • 管理用户數據
  • 批量操作
  • 剩餘數據管理
  • 管理遠程應用

你可以通過單擊網站上的安裝按鈕或手動使用以下命令來安裝 “Warehouse”：

flatpak install flathub io.github.flattool.Warehouse

Jogger ​

Jogger 是一款適用於 Gnome Mobile 的應用，用於跟蹤跑步和其他鍛鍊。它是用 GTK4、Libadwaita、Rust 和 Sqlite 構建的。儘管它的目標是 Gnome Mobile，但它在 Gnome Shell 下運行得很好，而且我發現它對於保存我的統計數據非常有用。其中一些功能是：

  • 使用 Geoclue 位置跟蹤鍛鍊
  • 從 Fitotrack 導出導入鍛鍊
  • 手動輸入鍛鍊
  • 查看鍛鍊詳情
  • 編輯鍛鍊
  • 刪除鍛鍊
  • 計算鍛鍊消耗的卡路里

你可以通過單擊網站上的安裝按鈕或使用以下命令手動安裝 “Jogger”：

flatpak install flathub xyz.slothlife.Jogger

Kooha ​

Kooha 是一個簡單的屏幕錄像機，具有簡約的界面。你只需單擊錄製按鈕即可，無需配置一堆設置。

Kooha 的主要特點包括：

  • 錄製麥克風、桌面音頻或同時錄製兩者
  • 支持 WebM、MP4、GIF 和 Matroska 格式
  • 選擇要錄製的監視器、窗口或屏幕的一部分
  • 多種來源選擇
  • 可配置的保存位置、指針可見性、幀速率和延遲
  • 它在 Wayland 上運行得很好。
flatpak install flathub io.github.seadve.Kooha

Warzone 2100 ​

誰不喜歡經典的 Linux 遊戲呢？

Warzone 2100 讓你指揮“計劃”部隊，在人類幾乎被核導彈摧毀後重建世界。

Warzone 2100 於 1999 年發行，由 Pumpkin Studios 開發，是一款開創性的創新型 3D 即時戰略遊戲。

2004 年，Eidos 與 Pumpkin Studios 合作，以 GNU GPL 條款發佈了遊戲的源代碼。此版本包含除音樂和遊戲內視頻序列之外的所有內容。當然，這些後來也被髮布。

該遊戲有一個問題：它使用舊的平台包（org.kde.Platform 6.4）。這意味着它需要更多的磁盤空間，但樂趣是值得的！

你可以通過單擊網站上的安裝按鈕或使用以下命令手動安裝 “Warzone 2100”：

flatpak install flathub net.wz2100.wz2100

Warzone 2100 也可以在 Fedora 倉庫中以 rpm 形式使用。
