rlxOS：一個獨立的不可變 Linux 發行版，具有 Xfce 桌面 ​

這是一款具有良好的外觀和感覺，獨立的不可變發行版。

不可變 Linux 發行版 的市場在穩步增長。

只在今年，我們就見證了像 Fedora Onyx、blendOS v3 這樣的新成員，以及 Ubuntu 24.04 LTS 將會出現的 基於 Snap 的不可變 Ubuntu 桌面。

在這篇 初次體驗 的文章裏，我們將探索 rlxOS，它是一款自行建制的不可變發行版。

現在，讓我們深入瞭解一下。

🚧 這個發行版相當新，可能無法作為日用主系統的替換產品。

rlxOS：概述 ⭐ ​

rlxOS 以從零開始構建為自豪，作為一個 獨立的 Linux 發行版，能更好地控制核心和工作部分。作為不可變的發行版，它實現了一種 滾動發佈 的方式，從而用户在面對大的更新時無需重新安裝。

其主要特點包括：

  • 不可變性
  • 利用 Ostree
  • 關注隱私
  • 原生支持 Flatpak

如果你還不知道，不可變發行版可以讓你在不影響系統核心的情況下進行變更。你可以將其視為分層變更，因此一個變更並不會影響另一個。

為了使這個實現，rlxOS 使用了一個軟件更新守護程序（swupd），這個程序保留了操作系統的兩個版本（在更改前後），你可以按照 文檔 進行一些在重啓後會消失的更改。

這個守護程序也會讓你有不同層的軟件包。根據官方網站，該功能在穩定版本中還未推出。

另外，你可以輕鬆地按照 文檔 設置 Distrobox 容器。

初次印象 👨‍💻 ​

我在使用 Ubuntu 上的 VirtualBox 的虛擬機（VM）上啓動了 rlxOS。安裝程序看起來非常舒服，它那種圓角矩形的感覺讓我想起了 GNOME 中 Adwaita 的主題風格。

我在進行過程中需要手動使用 GParted 對驅動器進行分區。首先，我在虛擬驅動器上建立了推薦的 msdos 分區表。

之後，我分了兩個不同大小的分區，一個是 ext4 文件系統的 39.5 GB 分區，另一個是 fat32 文件系統的 512 MB 分區。

在這之後，我需要確定 fat32 分區有 boot 和 esp 標記，這樣才能正確的安裝 rlxOS。

📋 通過右鍵點擊分區並選擇“管理標誌Manage Flags”來設定標記。

安裝程序還給出了關於分區的有效提示，將較大的一個標記為 Linux，將較小的一個標記為 EFI。

如果你打算在 Windows 系統旁邊安裝它，你需要小心分區的設定，因為我們還沒有在這裏進行過測試。

然後，確認屏幕會顯示出來，揭示一些重要的最後階段信息。我點擊 “應用Apply” 繼續進行。

然後，它需要花費一些時間才能完成安裝。但是，出於一些原因，我在安裝過程中能夠點擊 “下一步Next” 和 “上一步Back” 選項（我認為這些選項應是灰化的）。

我建議你讓安裝自然進行，不要調整其他任何事情，並等待如下所示的 “成功Success” 提示。

在重啓後，快速設置嚮導開始運行，我輸入了用户信息和密碼，然後再次重啓。

在重啓後看到了十分整潔的登錄界面，含有一張漂亮的壁紙，和標題欄常見的一些選項/信息。

登錄之後，我看到了一個非常熟悉的桌面界面，這個界面有一個類似 Windows 的應用啓動器，和一欄包含了有用的部件的任務欄，如語言、通知、網絡、節能模式等等。

然而，我立刻注意到rlxOS 預裝的應用程序非常的少。這可以看作一件好事，這取決於你問的人。

但是，我必須説，Xfce 的體驗看起來很好。

在我看來，他們可以至少添加任何一款 開源的微軟辦公套件替代品，諸如 LibreOffice 或 ONLYOFFICE，這樣這個發行版會有一個更為完整的體驗。但是，當然，這是一個新的發行版，無可挑剔。

查看設置應用，它似乎很好的與系統主題相匹配。

rlxOS使用 Xfce 作為其桌面，這是流行的且最小化的桌面環境之一。我測試的穩定版是運行定製化 Xfce 4.18。

如果你過去使用過 Xfce，你會發現 rlxOS 上的版本既熟悉又有些許不同。我用了一段時間，對其所提供的內容很滿意，比如多任務處理非常輕鬆，因為rlxOS 支持工作空間。

我只需要通過在任務欄中滾動/點擊可以輕鬆地在工作區之間切換。

儘管這個發行版在這裏那裏有些小問題，但是它值得一試。在實物機器上的你的體驗會比在 VM 上更好。

如果你對源代碼感興趣，或者你想要為其做出貢獻，你可以查閲其 GitHub 倉庫。
