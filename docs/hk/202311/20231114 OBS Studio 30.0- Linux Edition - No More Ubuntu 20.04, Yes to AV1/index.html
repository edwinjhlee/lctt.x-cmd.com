OBS Studio 30.0 發佈，增加 AV1 支持 ​

OBS Studio 30.0 對於 Linux 用户來説是一個重要的版本。

OBS Studio 無疑是 Linux 上最佳的錄屏軟件 之一，它深受眾多內容創作者的喜愛，他們使用它進行視頻錄製和流媒體直播。

近日的公告發布了一個全新的主要版本 —— OBS Studio 30，距離今年一月份的 上一次主要版本 已經近 11 個月。

接下來就讓我來一一為你介紹。

🆕 OBS Studio 30：新特性有哪些？ ​

作為一個主要版本，OBS Studio 30 帶來了一系列引人期待的改進，但是，也有一項變化可能令部分用户感到不滿。

這個版本的一些重要亮點包括：

  • 停止對 Ubuntu 20.04 的支持
  • 用户界面/體驗的提升
  • 視頻編碼能力的提升

停止對 Ubuntu 20.04 的支持 ​

隨着 OBS Studio 30 的發佈，對 Ubuntu 20.04 的支持不復存在。

做出這個決定的主要原因在於，開發者發現維護 Qt 5 越來越困難，這也相應影響了他們在改進 OBS 用户界面/用户體驗方面的工作。

實際上，Ubuntu 20.04 是唯一一個使用 Qt 5 運行 OBS 的第一方發行版，開發者表示，相比其他版本，這個發行版的用户基數已經在逐漸減少。

這並非一夜之間的改變，早在六月份，OBS Studio 就在其 GitHub 倉庫中公佈了這項改動。

目前，Ubuntu 20.04 的用户有兩個選擇，他們可以選擇 升級到 Ubuntu 22.04 或更高版本，或者轉用 OBS Studio 的 Flatpak 版本。

開發人員還提到了他們可能會在 2025 年 4 月左右停止對 Qt 6.2 和 Ubuntu 22.04 的支持。但是，你目前無需對此感到擔憂。你可以閲讀 官方公告 瞭解詳細的計劃。

用户界面/體驗的提升 ​

“停靠區Docks”菜單中新增了一項“全高窗口Full-Height docks”選項，這將方便集成 Twitch 和 YouTube 上直播時所見的長聊天窗口。

同時，狀態欄也進行了重新設計，以更結構化、有條理的形式展示同樣的信息，我個人非常喜歡這種改變。

老狀態欄有些棘手，在我直播或錄製期間，我經常會忘記它的存在 😆

在 OBS Studio 30 中也新增了一個“安全模式Safe Mode”，這種模式下，應用程序將在不加載任何第三方插件、腳本或 web sockets 的情況下啓動，以便對故障進行排除。

你可以通過兩種方式訪問到這個模式，一是當 OBS Studio 斷電意外關閉，另一種是在下圖所示的“幫助Help”菜單中手動啓動。

視頻編碼能力的提升 ​

OBS Studio 30 新增了對三種主要視頻編碼技術的支持，分別是 Intel QSV H264，高效視頻編碼（HEVC），以及 AV1。

許多使用 Linux 的內容創作者會讚賞 OBS 做出的這些改進。

🛠️ 更多的改變和改進 ​

除上述提及的點外，還有一些其他值得注意的改動：

  • 引入了WHIP/WebRTC 輸出。
  • 可通過拖拽調整過濾器順序。
  • 提供YouTube Live 控制室面板的支持。
  • 修復了在記錄高幀率視頻設備時出現日誌問題的錯誤。
  • 為 Decklink 增加了10 位捕獲和 HDR 回放的支持。

要獲得更多關於 OBS Studio 30 的詳細信息，你可以查看 官方發佈備註。

📥 下載 OBS Studio 30 ​

你可以前往 官方網站 下載 OBS Studio 的最新版本，其支持Linux，Windows 以及 macOS 平台。
