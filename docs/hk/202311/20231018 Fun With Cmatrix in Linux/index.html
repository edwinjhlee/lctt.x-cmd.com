在 Linux 中玩樂：Cmatrix 之旅 ​

玩得開心，安德森先生！

Cmatrix 是一款充滿樂趣的 Linux 和 Unix 系統命令列程序。它可以模仿經典電影《黑客帝國Matrix》系列中的場景，用綠色的字符流營造出雨一般的下落效果。

除了充滿視覺衝擊力的綠色字符流之外，你還可以發揮想像，利用這款有趣的命令做更多事情。

🚧 需要注意的是，Cmatrix 是一個 CPU 密集型的命令，所以請慎重使用它。

如何在 Ubuntu 及其他 Linux 系統中安裝 Cmatrix ​

Cmatrix 已經被收錄在幾乎所有主要的 Linux 發行版的官方庫中。如果你是 Ubuntu 用户，可以通過如下命令來安裝 Cmatrix：

sudo apt install cmatrix

對於 Fedora 用户，應該使用以下命令進行安裝：

sudo dnf install cmatrix

而對於 Arch Linux 用户，則可以使用 pacman 命令進行安裝：

sudo pacman -S cmatrix

Cmatrix 的基礎應用 ​

cmatrix 命令自身提供了豐富的選項，你可以自由改變默認的綠色字符流的外觀呈現。

加粗的字符 ​

你可以選擇使用 -b 選項，偶爾展示加粗的字符，

cmatrix -b

或者，你也可以調整設置，讓所有的字符都以加粗方式顯示，

cmatrix -B

異步滾動 ​

默認情況下，Cmatrix 會創建一個字符同步下落的顯示。但如果你想看到一個更為動態、視覺上更吸引人的顯示效果，就可以在代碼中操控字符的下落速度。

你可以這樣設置 Cmatrix，讓其進行異步滾動：

cmatrix -a

自定義字符下落速度 ​

你想讓字符下落的速度更快，或者更慢嗎？只需在 Cmatrix 中做出微小改動，就可以實現。

如想讓字符以更快的速度下落，你可以這樣設定：

cmatrix -u 2

在這裏，默認的屏幕更新延遲是 4，如果你把這個值降低，那麼字符下落的速度就會增加，反之則會減慢。所以，如果你想讓 Cmatrix 以更慢的速度運行，你可以這樣設置：

cmatrix -u 9

自定義顏色 ​

你可能想問，綠色能改嗎？當然，你想變成紫色也行。

運行 Cmatrix 的時候，你可以自由調整它的顏色。只需要使用 -C 選項，然後在後面添加你想要的顏色，如下所示：

cmatrix -C magenta

你可以任選綠色（green）、紅色（red）、藍色（blue）、白色（white）、黃色（yellow）、青色（cyan）、洋紅色（magenta）以及黑色（black）這些顏色。

其他可選設置 ​

選項對應功能
cmatrix -o舊式滾動模式
cmatrix -mLambda 模式：把所有的字符變為 lambda 符號
cmatrix -s屏保模式：按鍵有就自動退出
cmatrix -h調出幫助手冊

運行 Cmatrix 時的快捷鍵選項 ​

就算在啓動 Cmatrix 的時候你沒有添加任何選項，你仍可以在實際運行中隨時改變設置。下面就是一些可供你隨時選擇的選項。

隨時改變顏色 ​

當然，你無需重新啓動程序，就可以隨時改變顯示的顏色。但需要記住，不同的鍵位對應着不同的顏色。在 Cmatrix 未關閉的情況下，如果你按下了存儲在鍵位上的指令，顯示的顏色將會直接變更。

顏色相應鍵位
紅色!
綠色@
黃色#
藍色$
洋紅色%
青色^
白色&
黑色)

自由調整更新速度 ​

在 Cmatrix 運行的過程中，你可以按 0 到 9 的任何一位數字鍵來隨意改變當前的更新速度。

此外，Cmatrix 也有許多其他的選項可供你選擇，你可以在命令的 man 頁面裏面找到它們。

man cmatrix

彩虹魔法：Cmatrix 配合 lolcat ​

🚧 請注意，Cmatrix 本身就是 CPU 密集型的命令，所以在使用其他命令操控它的時候需特別小心。

你可以將 Cmatrix 和 lolcat 結合在一起使用，以此營造出一種更加有趣的視覺效果。如果你是 Ubuntu 的用户，可以通過如下的命令來安裝 lolcat：

sudo apt install lolcat

安裝完畢後，只需簡單地通過管道將 Cmatrix 連接到 lolcat，你便可以看到賞心悦目的彩虹效果了。

cmatrix | lolcat

當然，你也可以嘗試用 lolcat 來管理所有的 Cmatrix 的功能。

或者，你可以調出一個傾斜的彩虹條紋效果，為自己的視覺體驗增添一些新花樣。

cmatrix | lolcat -p 100

此外，只要輕輕一點，你就可以直接反轉現有的背景和前景顏色，使你的終端完全沉浸在五彩斑斕之中。

cmatrix | lolcat -i
