Linux 用户必備的 8 大網站 ​

這裏列舉的是我個人最喜歡的 Linux 網站，希望你也能喜歡。

既然你已經在關注我們，我們能為你解答大多數關於 Linux 的基礎需求。

然而，對 Linux 的學習總是無止境的，即便是對於資深的 Linux 專家也是如此。👨‍💻👩‍💻

實際上，一些網站和Blog內容對於 Linux 新手以及有經驗的用户都十分有用。

下面我就來列舉一些你或許應該收藏的優秀網站。

1、ArchWiki ​

ArchWiki 平台提供了各種信息。無論你是尋求關於工具、安全技術、安裝程序、桌面環境，或是其它任何主題的內容，你都可以在 ArchWiki 上找到相關的深入討論。

從技術角度講，ArchWiki 充當着 Arch Linux 發行版的文檔門户。不過，即使你並非 Arch Linux 的用户，你仍然可以在這裏找到教程、指南、常見問題解答（F.A.Q），以及大量其它的關鍵信息。

這些信息表述清晰，經過詳盡的審查以及更新，且易於理解。

ArchWiki

2、ExplainShell ​

ExplainShell 是一個非常有趣的平台，可以幫助你快速識別命令中所使用的參數。

通常，我們需要分別檢索手冊頁或者是命令信息。而有了 ExplainShell，這個過程就變得更高效，它能夠迅速為你提供所需的信息，同時為你提供對應的手冊頁鏈接。

它主要顯示從 Ubuntu 的手冊頁庫中提取的信息。所以，無論你是正在進行軟件安裝，進行 Git 提交，還是連接到 SSH，你都可以藉助 ExplainShell 來深入理解各種命令。

ExplainShell

3、Crontab.guru ​

如果你想要創建 cron 任務 以實現自動化，那麼 Crontab.guru 就是一款必備的便利網站。

只需輸入你計劃在 cron 任務中採用的表達式，即可獲取關於其是否會按預期工作的詳細反饋。對於正確的表達式，它將直接呈現你想通過 cron 任務設定的時間表。

除此之外，即使你是 cron 的新手，它也會在編輯器裏高亮表達月份/日期/星期的字段。

如果內容符合你的預期，就可以直接使用，或者編輯以修正並使用。

Crontab.guru

4. DistroWatch ​

DistroWatch 或許是每個 Linux 用户都耳熟能詳的網站。該網站以列舉當前熱門 Linux 發行版而聞名，一些用户甚至參考其流行度榜單，以瞭解自己偏愛的發行版是否位列其他版本之上。

在這裏，你可以獲取到最新發布的各種 Linux 發行版的更新信息，其中可能包括一些你此前未曾聽聞過的版本，以及新版本的簡要更改日誌。

如果你訂閲了它們的通訊，還可以收到發行版評論以及一些有關開發的新聞。對於希望跟蹤最新發行版的用户，這個網站值得你書籤收藏。

DistroWatch

5、Phoronix ​

Phoronix 是目前為止最老牌的 Linux 網站之一，專注於發佈面向硬件的內容。

無論你正尋找與最新處理器相關的 Linux 基準測試，還是 Linux 發行版的性能報告，你都可以在 Phoronix 上找到。除此之外，你還可以在這裏定期獲取到 Linux 世界的最新消息和開發動向。

Phoronix

6、Ubuntu Blog ​

Canonical 的Blog主要關注 Ubuntu、其開發動態、企業級更新以及其它技術性進展。

如何你希望瞭解關於 Ubuntu 的所有事情，那麼 Ubuntu Blog 就是你的最佳書籤。無論你是物聯網愛好者，還是利用 Ubuntu 進行機器人工程開發，總有新動態在發生。

坦白説，鑑於 Ubuntu 廣泛的應用，你無法從任何特定的Blog獲取所有這些更新信息。

Ubuntu Blog

7、GamingOnLinux ​

儘管我們也會覆蓋一些遊戲更新，併為你提供一個 遊戲指南，但是對於全面瞭解 Linux 遊戲和 Steam Deck 的一切，GamingOnLinux 是你的終極選擇。

不論是新的開發動態、新遊戲、SteamOS 的發佈、SteamVR，還是對 Linux 用户有重要影響的促銷信息，你都可以在這裏找到。

GamingOnLinux

8、Reddit 的 /r/Linux 子論壇 ​

雖然 Reddit 已經與過去有所不同，但其子論壇仍然值得關注。

/r/Linux 子論壇 是一個值得你收藏的社區，你可以在這裏讀到開源世界和 Linux 領域的最新動態。也許 Reddit 用户並沒有你想像中那麼友好，但如果你想隨時瞭解最新的變化，這個子論壇絕對值得你的收藏。

/r/Linux 子論壇

私貨：Linux 中國 ​

翻譯這篇文章時，我覺得應該將我們的網站也推薦給大家：

Linux 中國是一家立足中文開源愛好者社區的網站，已經持續為大家提供了十多年的關於開源、技術方面的內容。除了網站，我們還提供了同名的微信公眾號、知乎官方賬號。此外，我們在 BiliBili、YouTube、微博、抖音上也提供了短視頻內容；在喜馬拉雅上提供了音頻內容；以及，很多人都在訂閲的 RSS。

Linux 中國

順便説一句，我們現在提供了深色模式和文本模式，你試過了嗎？

我收藏了什麼？ ​

我很喜歡 Phoronix 帶來的硬件深度分析 和 Distrowatch 對新發行版項目的最新消息，因此這兩個網站一直位於我的收藏列表中。

而你需要收藏什麼呢？

事實上，如果你是 Ubuntu 的桌面用户，關注 Canonical 的Blog無疑能幫你瞭解最新版本的發佈和新功能的解讀。對於遊戲愛好者，GamingOnLinux 是你的一站式解決方案。

假如你是那種總想知道事物運作方式或本質的人，那麼，ArchWiki應該是你的首選。

當然，對於所有跟 Linux 相關的東西，我們會竭盡全力為你提供最佳的內容。所以，請別忘了也收藏我們哦！😉
