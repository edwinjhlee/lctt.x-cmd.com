Fedora 39 版本發佈，新亮相一款不可變版本 ​

Fedora 39 的發佈帶來了許多令人興奮的變化和完善。

Fedora 是眾多 Ubuntu 替代品中的熱門選擇，或者還可以説，用其來替換任何其他基於 Debian 的發行版都是一個理想的選擇。

每次升級後，Fedora 都會變得更好。現在讓我們看一下最新的 Fedora 39 有哪些重要更新。

接下來，我將向你展示這個版本都包含了哪些新功能。

🆕 Fedora 39 版本更新：都有哪些新內容？ ​

得益於穩健強大的 Linux 內核 6.5，Fedora 39 的發佈包含了眾多值得關注的新功能。其中一些關鍵的亮點包括：

  • 安裝程序的升級
  • GNOME 45
  • 應用/包的更新
  • Fedora Onyx

安裝程序的升級 ​

儘管安裝程序並未更換，我們在全新安裝 Fedora 時，會看到 一個新的歡迎屏幕。在更新後的 Fedora 38 ISO 中，你可能已經注意到了這一點。

此外，Fedora 的安裝程序現在支持更大的 EFI 系統分區，這個分區的 最小尺寸達到了 500 MB。這樣做是為了便於在現代硬件上進行固件更新，也為未來引導程序特性做好了準備。

你可能會在想，Anaconda Web UI 出了什麼情況？

其實，這個 UI 設計已經 計劃 在 Fedora 40 中推出了，我們都非常期待未來它的表現！

GNOME 45 ​

Fedora 39 引入了最近發佈的 GNOME 45。對於此次更新，我是期待已久。

早先的 “活動Activities” 按鈕已被替代，現在，你將看到一個 藥丸形狀的動態指示器，它可以清晰的顯示出當前的工作空間，以及其他可供切換的工作空間。

你可以通過滾動它或者點擊圓點來切換工作空間。

“設置Settings” 應用程序裏也陸續出現了一些新的變化，例如像 經過翻新的 “隱私Privacy” 標籤頁，以及在 “關於About” 菜單下新增的 “系統細節System Details” 子菜單。

此外，有一些新的核心應用程序，比如新的圖像查看器以及其他應用的更新，我強烈建議你查看我們所有關於 GNOME 45 的內容：

GNOME 45 發佈，棄用“活動”按鈕

應用/包的更新情況 ​

Fedora 39 同樣更新了一套應用程序和軟件包。主要的更新包括：

  • LibreOffice 7.6
  • LLVM 17
  • Golang 1.21
  • IBus 1.5.29
  • Perl 5.38
  • RPM 4.19
  • Python 3.12

Fedora Onyx 的介紹 ​

今年早些時候，Fedora 的不可變版本陣容迎來了一個新成員，叫做 “Fedora Onyx”。

那時，我們並不知道它的具體發佈日期，但現在，它終於在 Fedora 39 的版本更新中有所呈現。

這使得 Fedora 的不可變版本陣容 增長到了四個，其它分別是 Fedora Silverblue、Fedora Kinoite，以及 Fedora Sericea。

🛠️ 其他變化和改進 ​

其他的變化包括一些注目的內容：

  • Fedora 39 提供了一個綠色的 Bash 提示符。
  • 移除了 Fedora 工作站的自定義 Qt 主題設計。
  • 對於 Indic（印度）語言，實現了谷歌 Noto 字體。
  • Flatpak 不再使用模組進行構建，而是採用了一個獨立的構建目標。

你還可以通過我們針對 Fedora 39 特性 的報道和查閲 官方更改日誌 來更深入地瞭解這次的版本發佈。
