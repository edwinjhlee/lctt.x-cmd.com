開源可以用來做設計嗎？ ​

開源的超凡和強大毋庸置疑。從服務器到個人電腦桌面、移動設備，甚至到所謂的“物聯網”，開源在各個領域遍佈全球。然而有一個行業，傳統的專有閉源軟件解決方案依然佔據主導地位，並且通常特別昂貴，這就是設計產業。在這篇文章中，我們會大致描述一些自由及開源的替代軟件來拋磚引玉，看是否能代替你現在所用的設計工具集。也許你是一個剛起步的設計師，需要節省開支。也許你的經驗十分豐富，只是單純的想換一個更加“開放”的工作方式。讀下去，讓我們看看自由及開源軟件世界到底帶來了什麼！

繪圖 ​

在開源世界，有幾個可行且十分強大的工具，代替 Adobe 支持的主流產品。

GIMP ​

GIMP, 或者説  GNU 圖像處理程序GNU Image Manipulation Program 是一個非常強大的免費開源軟件，可替代 Adobe 公司的 PhotoShop 。它由一個相當強大的核心團隊開發和維護，為設計創造提供強大的圖片編輯工具，比如濾鏡、筆刷、修飾。如果你想使用 UX/UI 庫設計模型，GIMP 甚至可以處理 .PSD 文件。最後，GIMP 還可以用來做數字藝術、logo 等類似的東西。GIMP 可以免費下載並在 Linux、MacOS 和 Windows 上運行。

Inkscape ​

Inkscape 有一個宣傳語，代表着它的核心價值觀 —— “Draw Freely”，它是一個開源而自由的產品，可以替代 Adobe 公司的另一產品 —— 強大、專有而且昂貴的矢量程序 Illustrator 。Inkscape 提供了大量的設計和畫圖工具，易用的顏色拾取導航欄，濾鏡和漸變工具，還有很多很多。如果設計師下決心使用開源軟件解決方案，你可以在Blog和論壇帖子上找到非常好的在線文檔。和 GIMP 一樣，Inkscape 也可以免費下載並可在 Linux、MacOS 和 Windows 上運行。

想從經驗豐富的圖形和網頁設計師那裏學習更多關於這些開源工具的使用知識？請在 YouTube 網站上找一下這些人：

  • Nick Saporito （Nick 有很好的資源，介紹 Inkscape 的基本特性，涵蓋了圖標、網站或者圖形設計師日常會使用的基本功能）。
  • Irfan Prastinato （Irfan 的亮點是使用 Inkscape 專注於現代圖標的創作）。
  • Cameron Bohnstedt （Cameron 是一個數字藝術家，由於他很專業並且有豐富的經驗，開源工具（GIMP、Inkscape、Blender）的力量被真正的展示了出來。很有感染力，值得一看）。

網頁設計與開發 ​

要設計功能豐富、響應快速的網頁和原型時，這裏有幾個工具 —— 有些是開源的 —— 供設計師選擇。這些工具最近幾年一直在持續發展，在我看來，這應該是反映出了設計發展的趨勢是響應式網站設計要和我們生產的設備變化得一樣快。

Bootstrap ​

在我看來，Bootstrap 促進了響應式設計，甚至是“移動為先”的設計實現了跳躍式的突破。Boostrap 最初由 Twitter 開發人員 Mark Otto 和 Jacob Thornton 開發，是一個完全開源、完全可定製的開發框架，利用它你可以製作出滿足你的客户需求的網頁。有了 Bootstrap 就有了堅實的基礎， Bootstrap 4.0 目前正在進行內部測試，在穩定的 3.0 版本的基礎上做了大量的底層優化，包括 CSS 預處理器從 Less 換成 Sass，一個增強的網格系統，JavaScript 插件的重構等等。

Gravit ​

另一個自由開源的矢量程序 Gravit，它受到越來越多的關注。Gravit 可以在瀏覽器上運行，不僅是 Adobe Illustrator 在矢量方面的一個切實可行的替代品（儘管功能不是那麼豐富），也有望成為一個成熟的設計環境。不論是 logo 設計，還是移動應用、網站，任何東西你都可以拿來會進行設計。自從 Gravit 成為我在瀏覽器上的可選工具後，我最近一些工作就是靠它完成的，除此之外它還很強大，簡潔直觀。

一些免費但不開源的解決方案…… ​

Webflow ​

Webflow 是一個強大的全能網頁設計環境，可以在瀏覽器上運行。Webflow 的奇妙之處是設計網頁基本不需要寫代碼，當你設計時，它會在後台自動生成代碼。我發現 Webflow 的界面十分乾淨清爽，非常直觀。誠然，Webflow 沒有開源，但是免費版支持同時設計和開發兩個網頁項目。

Froont ​

另一個基於瀏覽器的網頁設計程序是 Froont。和 Webflow 相似, Froont 設計非常直觀簡潔，而且強大。利用 Froont，在任何相關設備上，你都可以高效地設計一個全新、獨一無二的響應式網站。和 Webflow 一樣，Froont 還允許設計師在需要的時候導出代碼。

Webflow 和 Froont 除了收費計劃外均有免費版，很適於一次設計一個站點，還可以將你的工作成果發佈到網上，如果你選擇的話。

文本編輯器 ​

有一些產品供想使用自由開源編輯器的設計師和開發者選擇，作為自己平常編寫代碼工具的替代品。

Atom ​

Atom 號稱為“面向 21 世紀的黑客專用編輯器”hackable editor for the 21st Century, 它是全功能的編輯器，看起來內置了完成工作所需的所有功能 —— 比如代碼自動補全、多功能視圖等。它的可玩性很高，用户可以以自己喜歡的方式對 Atom 進行自定義。Atom 有自己的包管理器, 用户可以下載成千上萬的軟件包進一步定製 Atom，添加獨一無二的功能。

結論 ​

當今時代，設計師不要被昂貴臃腫的專有軟件所束縛。使用一些自由開源的工具，具有開源意識的設計師有足夠多的選擇，為他們的客户創造漂亮、實用的設計作品。如果喜歡這篇文章就分享吧，也可以在下面評論你最喜歡的開源的設計工具！
