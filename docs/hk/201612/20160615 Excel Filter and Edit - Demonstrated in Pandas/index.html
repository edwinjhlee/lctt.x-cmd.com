Excel “過濾和編輯” - Pandas 中的示範操作 ​

介紹 ​

我聽許多人説我之前的關於 pandas 處理一般的 Excel 任務的文章對於幫助新的 pandas 用户將 Excel 處理過程轉化成對應的 pandas 代碼是有用的。這篇文章將會保持傳統，通過介紹不同的 pandas 使用 Excel 的過濾功能作為一個模型進行索引的例子來理解該處理過程。

大多數 pandas 的新手首先學到的東西就是基本的數據過濾。即使在過去的時間中使用 pandas 工作持續數月，我最近意識到我沒有在我每天的工作中使用過的 pandas 過濾的方法還有另外一個好處。也就是説，你可以過濾一組給定的列，而使用一個簡化的 pandas 的語法更新另一組列。這和我所説的 Excel 中的“過濾並編輯”很像。

這篇文章將會介紹一些基於各種條件過濾一個 pandas 數據幀並同時更新數據的例子。同時，我將更多的介紹一下 panda 的索引，和如何使用索引功能例如 .loc , .ix 和 .iloc 來簡單、快速基於簡單或者是複雜的條件來更新一個數據子集。

Excel: “過濾並編輯” ​

在數據透視表以外，在 EXCEL 頂部工具欄的工具之一是過濾器。這個簡單的工具允許用户通過不同的數據、文本與格式條件去快速過濾與排序數據。這裏是由幾個不同的條件過濾數據產生的樣本數據的基本截圖：

布爾檢索 ​

現在，我想通過 pandas 中一些布爾索引的細節來使你對這個問題有點感覺。如果你想要去理解 pandas 的在多數情況下的索引和數據選擇，那麼這是一個要理解的重要概念。這種想法可能看起來有點複雜，對新的 pandas 用户（可能對經驗豐富的用户來説太基礎），但我認為重要的是要花一些時間瞭解它。如果你掌握了這一概念，用 pandas 進行數據工作的基本過程將更簡單。

pandas 通過標籤、基於數字的位置或者一個布爾值（True/False）列表來支持索引（或者選擇數據）。使用一個布爾值的列表來選擇一個行被稱為布爾索引，將是本文其餘部分的重點。

我發現，我的 pandas 的工作流程往往側重於使用布爾值的列表選擇我的數據。換句話説，當我創建了 pandas 數據幀，我傾向於保持數據框架的默認索引。因此，該布爾索引本身並不具有真正意義，同時也不是簡單的選擇數據。

關鍵點 pandas 中布爾索引是選擇行的數據的強大的和有用的方法之一。

讓我們看一些示例的數據幀來幫助澄清在 pandas 中布爾索引做的是什麼。

首先，我們將創建一個來自 Python 的列表的非常小的數據幀，並使用它來展示布爾索引是如何工作的。

import pandas as pd
sales = [('account', ['Jones LLC', 'Alpha Co', 'Blue Inc', 'Mega Corp']),
         ('Total Sales', [150, 200, 75, 300]),
         ('Country', ['US', 'UK', 'US', 'US'])]
df = pd.DataFrame.from_items(sales)

|account |Total Sales |Country :--|:-- |:-- |: 0 |Jones LLC |150 |US 1 |Alpha Co |200 |UK 2 |Blue Inc |75 |US 3 |Mega Corp |300 |US

注意值 0-3，是怎麼樣會自動分配給行的？這些都是索引，在這個數據集它們不是特別有意義的，但對 pandas 是有用的，對於瞭解如下其他沒有描述的用例是重要的。

當我們引用布爾索引時，我們只是説，我們可以通過一個 True 或 Flse 的值的列表表示我們要查看的每一行。

在這種情況下，如果我們想查看Jones LLC、Blue Inc 和 Mega Corp 的數據，我們可以看到，True、False 列表看起來會像這樣：

indices = [True, False, True, True]

這沒什麼奇怪的，你可以通過把這個列表傳入到你的數據幀，你就看到它只會顯示該值是 True 的行：

df[indices]

|account |Total Sales |Country :--|:--|:--|:-- 0 |Jones LLC |150 |US 2 |Blue Inc |75 |US 3 |Mega Corp |300 |US

這裏是一個剛剛發生了什麼的示意圖:

手工創建索引列表是可以工作的，但是顯然對任何一個稍微大點的數據集來説卻不是可擴展的或非常有用的。幸運的是，pandas 可以用一個簡單的查詢語言創建這些布爾索引，對熟悉使用 Python （或任何語言）的人應該很容易。

例如，讓我們看看來自美國的所有銷售的行。如果我們執行一個基於 Country 列的 Python 表達式：

df.Country == 'US'
0     True
1    False
2     True
3     True
Name: Country, dtype: bool

這個例子顯示了 pandas 如何將你的 Python 的常規邏輯，把它應用到一個數據幀並返回一個布爾值列表。那麼這個布爾值的列表可以傳遞到數據幀來獲取相應的行。

在真正的代碼中，你不需要做這兩個步驟。簡潔的做這事的方法典型的看上去如下：

df[df["Country"] == 'US']

|account |Total Sales |Country :--|:--|:--|:-- 0 |Jones LLC |150| US 2 |Blue Inc |75 |US 3 |Mega Corp| 300| US

雖然這個概念很簡單，但你可以編寫非常複雜的邏輯，使用 Python 的威力來過濾數據。

關鍵點 在這個例子中， df[df.Country == 'US'] 等價於 df[df["Country"] == 'US'] ‘.’ 標記法是簡潔的但是在你列名中有空格時不會工作。

選擇需要的列 ​

現在，我們已經指出瞭如何選擇行的數據，我們如何控制顯示哪些列？在上面的例子中，沒有明確的方法完成這個。Pandas 能使用三種基於位置的索引支持這個用法：.loc 、iloc 和 .ix 。這些功能也允許我們在所看到的行之外挑選列。

關於什麼時候選擇使用 .loc 、iloc 或者是 .ix，在這裏很容易困惑。 快速總結的區別是:

  • .loc 用於標籤索引
  • .iloc 用於基於整數的位置
  • .ix 是一個快捷方式，它將嘗試使用標籤（比如 .loc）但失敗後將退而求其次使用基於整數的位置（比如 .iloc）

因此問題是我該使用哪個？我必須坦誠地説，我有的時候也會被這些搞混。我發現我最常使用 .loc 。主要是因為我的數據不適合於有意義的基於位置的索引（換句話説，我很少發現自己需要使用 .iloc），所以我堅持使用 .loc。

公平地講，每一個方法都有自己的用途，在許多情況下都是有用的。特別是處理多索引數據幀時。我不會在這篇文章中討論那個話題-也許在未來的博文會説。

現在我們已經涵蓋了這樣一個話題，讓我們來展示如何篩選一行的值的數據幀，具體選擇要顯示的列。

繼續我們的例子，如果我們只是想顯示對應於我們的索引的帳户名稱，該怎麼做？使用 .loc 很簡單：

df.loc[[True, True, False, True], "account"]
1     Alpha Co
2     Blue Inc
3    Mega Corp
Name: account, dtype: object

如果你想看到多個列，只需傳遞一個列表：

df.loc[[True, True, False, True], ["account", "Country"]]

| account |Country :--|:--|:-- 0 |Jones LLC| US 1 |Alpha Co |UK 3 |Mega Corp |US

真正的威力是當你在你的數據上創建更復雜的查詢。在這種情況下，讓我們展示所有的帳户名稱和 sales > 200 的國家：

df.loc[df["Total Sales"] > 200, ["account", "Country"]]

|account| Country :--|:--|:-- 3 |Mega Corp| US

這個過程可以看做有點相當於我們上面討論過的 Excel 過濾器。但是有更多的好處，你還可以限制你檢索的列數，而不僅僅是行。

編輯列 ​

所有這些都是好的背景知識，但當你使用一個類似的方法基於選擇的行來更新一個或多個列時，這個處理過程就真的是非常漂亮。

作為一個簡單的例子，讓我們增加一個 rate 列到我們的數據：

df["rate"] = 0.02

| account |Total Sales| Country |rate :--|:--|:--|:--|:-- 0 |Jones LLC |150 |US |0.02 1 |Alpha Co |200 |UK |0.02 2 |Blue Inc |75 |US |0.02 3 |Mega Corp |300 |US |0.02

假如説如果你賣了超過 100，你的利率是 5%。基本的過程是設置一個布爾索引來選擇列，然後將該值賦給利率列：

df.loc[df["Total Sales"] > 100, ["rate"]] = .05

| account |Total Sales| Country| rate :--|:--|:--|:--|:-- 0 |Jones LLC |150| US| 0.05 1 |Alpha Co |200 |UK |0.05 2 |Blue Inc |75| US |0.02 3 |Mega Corp |300| US| 0.05

希望你逐步看過這篇文章，這將對於幫助你理解這個語法是如何工作的是有意義的。現在你明白了“過濾並編輯”方法的基本原理。最後一節將介紹 Excel 和 pandas 這個過程的更多細節。

將這些組合在一起 ​

對於最後的例子，我們將創建一個簡單的佣金計算器，使用以下規則：

  • 所有的佣金計算在交易水平
  • 所有銷售的基礎佣金為 2%
  • 所有 shirt 都將獲得 2.5% 的佣金
  • 有個特殊的環節，在一個交易中銷售的數額 >10 的 belt 將得到 4% 的佣金
  • 所有在一個單一的 shoe 類交易中 > 1000 美元，有一個特別的 250 美元獎金加上一個 4.5% 的佣金

要在 Excel 中做到這一點，使用的過濾器和編輯方法：

  • 添加一個 2% 的佣金列
  • 添加一個 0 美元的獎金列
  • 過濾 shirts，並將 vale 改為 2.5%
  • 清除過濾器
  • 過濾數量 > 10 的 belt ，並將值更改為 4%
  • 清除過濾器
  • 過濾 > 1000 美元 shoe，並相應的增加佣金和獎金為 4.5% 和 250 美元

我不會顯示每一步的屏幕快照，但這裏是最後一個過濾器的屏幕快照：

總結 ​

感謝閲讀文章。 我發現，在學習如何使用 pandas 的新用户所面臨最大的挑戰之一，是根據他們基於 Excel 的知識，如何找出建立一個等效的基於 pandas 的解決方案。在許多情況下，pandas 的解決方案將是更健壯、更快、更容易審計和更強大的。然而，學習曲線需要花費一些時間。我希望這個展示瞭如何使用電子表格的過濾工具來解決一個問題的例子，將有助於那些剛剛在開始 pandas 之旅的同學們。祝你好運!
