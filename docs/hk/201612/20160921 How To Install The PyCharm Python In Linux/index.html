如何在 Linux 下安裝 PyCharm ​

簡介 ​

Linux 經常被看成是一個遠離外部世界，只有極客才會使用的操作系統，但是這是不準確的，如果你想開發軟件，那麼 Linux 能夠為你提供一個非常棒的開發環境。

剛開始學習編程的新手們經常會問這樣一個問題：應該使用哪種語言？當涉及到 Linux 系統的時候，通常的選擇是 C、C++、Python、Java、PHP、Perl 和 Ruby On Rails。

Linux 系統的許多核心程序都是用 C 語言寫的，但是如果離開 Linux 系統的世界， C 語言就不如其它語言比如 Java 和 Python 那麼常用。

對於學習編程的人來説， Python 和 Java 都是不錯的選擇，因為它們是跨平台的，因此，你在 Linux 系統上寫的程序在 Windows 系統和 Mac 系統上也能夠很好的工作。

雖然你可以使用任何編輯器來開發 Python 程序，但是如果你使用一個同時包含編輯器和調試器的優秀的集成開發環境（IDE）來進行開發，那麼你的編程生涯將會變得更加輕鬆。

PyCharm 是由 Jetbrains 公司開發的一個跨平台編輯器。如果你之前是在 Windows 環境下進行開發，那麼你會立刻認出 Jetbrains 公司，它就是那個開發了 Resharper 的公司。 Resharper 是一個用於重構代碼的優秀產品，它能夠指出代碼可能存在的問題，自動添加聲明，比如當你在使用一個類的時候它會自動為你導入。

這篇文章將討論如何在 Linux 系統上獲取、安裝和運行 PyCharm 。

如何獲取 PyCharm ​

你可以通過訪問https://www.jetbrains.com/pycharm/獲取 PyCharm 。

屏幕中央有一個很大的 'Download' 按鈕。

你可以選擇下載專業版或者社區版。如果你剛剛接觸 Python 編程那麼推薦下載社區版。然而，如果你打算發展到專業化的編程，那麼專業版的一些優秀特性是不容忽視的。

如何安裝 PyCharm ​

下載好的文件的名稱可能類似這種樣子 ‘pycharm-professional-2016.2.3.tar.gz’。

以 “tar.gz” 結尾的文件是被 gzip 工具壓縮過的，並且把文件夾用 tar 工具歸檔到了一起。你可以閲讀關於提取 tar.gz 文件指南的更多信息。

加快速度，為了解壓文件，你需要做的是首先打開終端，然後通過下面的命令進入下載文件所在的文件夾：

cd ~/Downloads

現在，通過運行下面的命令找到你下載的文件的名字：

ls pycharm*

然後運行下面的命令解壓文件：

tar -xvzf pycharm-professional-2016.2.3.tar.gz -C ~

記得把上面命令中的文件名替換成通過 ls 命令獲知的 pycharm 文件名。（也就是你下載的文件的名字）。上面的命令將會把 PyCharm 軟件安裝在 home 目錄中。

如何運行 PyCharm ​

要運行 PyCharm， 首先需要進入 home 目錄：

cd ~

運行 ls 命令查找文件夾名：

ls

查找到文件名以後，運行下面的命令進入 PyCharm 目錄：

cd pycharm-2016.2.3/bin

最後，通過運行下面的命令來運行 PyCharm：

sh pycharm.sh &

如果你是在一個桌面環境比如 GNOME 、 KDE 、 Unity 、 Cinnamon 或者其他現代桌面環境上運行，你也可以通過桌面環境的菜單或者快捷方式來找到 PyCharm 。

總結 ​

現在， PyCharm 已經安裝好了，你可以開始使用它來開發一個桌面應用、 web 應用和各種工具。

如果你想學習如何使用 Python 編程，那麼這裏有很好的學習資源值得一看。裏面的文章更多的是關於 Linux 學習，但也有一些資源比如 Pluralsight 和 Udemy 提供了關於 Python 學習的一些很好的教程。

如果想了解 PyCharm 的更多特性，請點擊這兒來查看。它覆蓋了從創建項目到描述用户界面、調試以及代碼重構的全部內容。
