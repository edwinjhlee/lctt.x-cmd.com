Arch Linux：DIY 用户的終極聖地，純粹主義者的最後避難所 ​

讓我們翻過一頁頁 Linux 的新聞報道，你會發現其中對一些冷門的 Linux 發行版的報道數量卻出乎預料的多。像 Elementary OS 和 Solus 這樣的新發行版因其華麗的界面而被大家所關注，而搭載 MATE 桌面環境的那些系統則因其簡潔性而被廣泛報道。

感謝像《黑客軍團》這樣的電視節目，我完全可以預料到關於 Kali Linux 系統的報道很快就會增加。

儘管有很多關於 Linux 系統的報道，然而有一個被廣泛使用的 Linux 發行版幾乎被大家完全遺忘了：Arch Linux 系統！

關於 Arch 的新聞報道很少的原因有很多，不僅僅是因為它很難安裝，而且你還得能在命令列下嫺熟地完成各種配置以使其正常運行。更糟糕的是，以大多數的用户的觀點來看，其困難是設計之初就沒有考慮過其複雜的安裝過程會令無數的菜鳥們望而卻步。

這的確很遺憾，在我看來，實際上一旦安裝完成後，Arch 比我用過的其它 Linux 發行版易用得多。

確實如此，Arch 的安裝過程很讓人蛋疼。有些發行版的安裝過程只需要點擊“安裝”後就可以放手地去幹其它事了。Arch 相對來説要花費更多的時間和精力去完成手動分區、手動掛載、生成 fstab 文件等。但是從 Arch 的安裝過程中，我們學到很多。它掀開帷幕，讓我們弄明白很多背後的東西。事實上，這層掩蓋底層細節的帷幕已經徹底消失了，在 Arch 的世界裏，你就是帷幕背後的主宰。

除了大家所熟知的難於安裝外，Arch 甚至沒有自己默認的桌面環境，雖然這有些讓人難以理解，但是 Arch 也因其可定製化而被廣泛推崇。你可以自行決定在 Arch 的基礎軟件包上安裝的任何東西。

![ARCH "DESKTOP" SCREENSHOT LINUX - OBVS VARIES DEPENDING ON USER ](https://regmedia.co.uk/2016/11/01/arch.jpg?x=648&y=364&infer_y=1 "ARCH "DESKTOP" SCREENSHOT LINUX - OBVS VARIES DEPENDING ON USER ")

雖然你可以視之為無限可定製性，但也可以説它完全沒有定製化。比如，不像 Ubuntu 系統那樣，Arch 中幾乎沒有修改過或是定製開發過的軟件包。Arch 的開發者從始至終都使用的是上游開發者提供的軟件包。對於部分用户來説，這種情況非常棒。比如，你可以使用“純粹”的 GNOME 桌面環境。但是，在某些情況下，定製的補丁可以解決一些上游開發者沒有處理的很多的缺陷。

由於 Arch 缺乏一些默認的應用程序和桌面系統，以至於很難形成一致的看法——或者根本不會有什麼真正的看法，因為我安裝的毫無疑問和你安裝的不會一樣。我可能選擇安裝最小化安裝配置 Openbox、tint2 和 dmenu，你可能卻是使用了最新版的 GNOME 桌面系統。我們都在使用 Arch，但我們的體驗卻是大相逕庭。對於任何發行版來説也有這種情況，但是其它大多數的 Linux 系統都至少有個默認的桌面環境。

然而對 Arch 的看法還是由很多共性的元素的。比如説，我使用 Arch 系統的主要原因是因為它是一個滾動更新的發行版。這意味着兩件事情。首先，Arch 會盡可能的使用最新的內核，只要它們可用，被認為穩定就行。這就意味着我可以在 Arch 系統裏測試一些在其它 Linux 發行版中難於測試的東西。滾動版另外一個最大的好處就是所有軟件更新就緒就會被即時發佈出來。這不僅意味着軟件包更新速度更快，而且意味着不會出現破壞掉系統的大規模更新。

很多用户因為 Arch 是一個滾動發行版認為它不太穩定。但是在我使用了 9 個多月之後，我並不贊同這種觀點。

然而，我從未因為一次升級系統而搞壞過任何東西。我確實有過回滾，因為系統啓動分區 /boot 沒有掛載，但是後來我發現那完全是自己操作上的失誤，我更新後而忘記寫入改變。一些暴露出來的缺陷（比如我關於戴爾 XPS 筆記本觸摸板又出現以前解決過的問題）很快被修復，並且更新速度要比其它非滾動發行版快得多。總的來説，我認為 Arch 滾動更新的發佈模式比其它我在用的發行版要穩定得多。唯一一點我要強調的是查閲維基上的資料，多關注你要更新的內容。

我懷疑 Arch 之所以沒那麼受歡迎，主要原因就是你必須要隨時小心你的操作。盲目的更新 Arch 系統是極其危險的。但是任何一個發行版的更新都有風險，你只是認為它沒有風險而已——因為你別無選擇。

Arch 的哲學理念是我支持它的另外一個最主要的原因。我認為 Arch 最吸引用户的一點就是：“（Arch）面向的是專業的 Linux 用户，或者是有 DIY 精神，願意查資料並解決問題的人”。

隨着 Linux 進一步納入主流，開發者們更需要順利地渡過每一個艱難的技術領域。那些晦澀難懂的專有軟件方面的經驗恰恰能反映出用户高深的技術能力。

儘管在這個時代聽起來有些怪怪的，但是事實上我們很多人更願意自己動手裝配一些東西。在這種情形下，Arch 將會是Linux DIY 用户的終極聖地。
