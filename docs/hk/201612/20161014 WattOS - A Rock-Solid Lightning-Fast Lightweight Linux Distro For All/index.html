WattOS：一個穩如磐石、快如閃電、面向所有人的輕量級 Linux 發行版 ​

Jack Wallen 將介紹一下是什麼讓 WattOS 這麼特別。 使用許可

Linux 領域裏的每個人不是聽説過就是使用過某個輕量級的 Linux 發行版。大家都知道我們不斷追求的是：佔用內存少，配置資源要求低，包含一個輕量級的桌面環境（或者窗口管理器），並且提供和其他發行版相似的桌面佈局，把賭注押在相同的需求之上。

這種發行版大多用來工作。有一個可以擊垮很多輕量級 Linux 發行版的問題，它們沒有真正含有一般用户完成工作需要的工具。結果就是，它們淪落為用來完成特殊任務（像數據恢復、做信息亭等）。

在某種程度上，WattOS 陷入了同樣的困境（它唯一含有的生產力工具是 PDF 閲讀器，而且它使用標準的“任務欄/開始菜單”象徵桌面）。然而幸運的是，WattOS 通過難以置信的運行速度、穩定性以及內置新立得包管理器彌補了這些缺點；所以，WattOS 可以很容易的成為一個適合所有人的輕量級 Linux 發行版。

到底是什麼讓 WattOS 如此特別，讓我們一起一探究竟。

內核 ​

事實上當我發現 WattOS 基於 kernel 4.4 內核時我非常吃驚。升級系統之後，執行 uname -r 命令可以看到是 4.4.0-38-generic。鑑於這個發行版的目的是讓老舊和運行卡頓的機器重獲新生，它和我的 Elementary OS Loki 發行版內置相同版本的內核真是一個可愛的驚喜。這意味着 WattOS 在新舊硬件上都會有良好的工作表現。

真正的驚喜不止於此，當你去 WattOS 的網站，你會同時發現 32 位和 64 位版本的下載地址（現在大多數新的發行版都傾向於放棄 32 位發行版本）。所以，不僅系統內核對新式硬件提供支持，而且系統發行版本的多種架構也能讓那些老式的 32 位機器重獲新生。

運行速度 ​

當安裝上 WattOS 的時候，有那麼一刻我對它有純粹的羨慕。WattOS 的運行速度快的令人難以置信。甚至當它的桌面版作為客户機在 VirtualBox 虛擬機平台工作時，運行速度依然遠遠超過了我的 Elementary OS Loki 桌面發行版。後來我才瞭解到當時運行的宿主機是 System76 Leopard，配置有水冷裝置的 i7 處理器和 16GB 的運行內存。分配給 WattOS 大約 2G 的內存，讓它看起來沒有什麼任務可以拖慢它。WattOS 的運行速度壯觀的令人難以訴説，它越來越成熟了。我從沒見過火狐瀏覽器能打開的這麼快。

接下來説説 LibreOffice 應用的啓動。由於想測試 LibreOffice 的啓動速度，所以我打開了新立得軟件包管理器，計劃安裝這一開源辦公軟件套件的佼佼者。

無果。

安裝 LibreOffice 的主要問題是缺少一個依賴軟件包 python3-uno，而且無論怎麼嘗試都無法安裝成功。然而，最後我在 LibreOffice 官方網站 上下載了 deb 格式的軟件包。把下載的文件解壓之後，cd 到 LibreOffice_5.2.2.2_Linux_x86-64_deb/DEBS/ 目錄下，最後通過執行 sudo dpkg -i *.deb 命令成功的安裝好了 LibreOffice。

LibreOffice 運行的怎麼樣呢？速度快到要瘋了。值得再提的是，我從沒見過這個應用能像在 WattOS 上運行的這麼快。點擊 LibreOffice Writer 的圖標，它花費的時間是在 Elementary OS Loki （已經很快了）主機上花費的一半。

桌面 ​

我個人偏愛於桌面向更加現代化的趨勢進行迭代。我是 Ubuntu 的 Unity 桌面，GNOME 3 桌面，以及（特別是） Elementary OS 的粉絲。所以使用古老風格桌面的主意意味着對我幾乎沒有吸引力。即便如此，WattOS 在把現代設計風格融入老式設計時做的非常好。舉例來説，默認的桌面主題（圖 1）。WattOS 的 UI 設計者巧妙設計了桌面主題，所以它沒有完全偏離 Windows XP 或者老式 Linux CDE 風格的窗口管理器的設計理念。

圖 1：WattOS 的文件管理器展示了有些現代化的主題 使用許可

關於 WattOS 的桌面（基於 LXDE）的確有一些要説的但以前從來沒説過，就是每個擁有像簡潔、直接，有足夠靈活度和自定義度這些特點的 Linux 桌面版，對每個使用過 Windows 95 的電腦使用者來説都會很熟悉。

驚喜之處，優點和缺點 ​

正像每個新的 Linux 桌面版的體驗那樣，WattOS 有讓人驚喜的地方，同時也有優點和缺點。首先，説説優點。

WattOS 除了絕對的速度（用一個簡單的 “WOW” 來評論），還在桌面上固定了一些特別的驚喜（大多數都是預置的應用）。額外的軟件中最好的是 KeePassX（一個極少被默認包含在桌面版的應用）。我認為密碼管理器應該默認安裝在每一個電腦桌面上，值得驕傲的是 WattOS 預裝了這個傑出的工具。

下一個討論的是預裝火狐瀏覽器。許多輕量級的發行版會預裝像 Surf 或者 Midori 這樣的瀏覽器。這兩個瀏覽器都不錯，但是它們的兼容性經常達不到像谷歌文檔這樣網站的要求。因為 WattOS 含有成熟的火狐瀏覽器，你會發現該系統的功能在火狐瀏覽器兼容的網站上表現的很完美。

最後，算不上好的意外。正如我已經提到的，在安裝 LibreOffice 時馬上就有了故障。然而安裝像 GIMP 這樣的軟件就很順利（所以我認為這是偶然問題）。除了這一個問題，我覺得默認桌面菜單有些混亂。例如，新立得軟件包管理器放在個性化菜單裏。我更願在主菜單中突出顯示項中看到它，並且加上類似“軟件安裝”（或任何其他新用户容易理解）的標籤。從我的視角來説，個性化菜單項應該用於放置配置該平台各種風格的工具，而不是安裝軟件的工具。

除此之外，若想在 WattOS 主攻方向上的找茬的話，特別是你要找一個面對老舊硬件 Linux 發行版時，你會發現這非常困難。

結論 ​

儘管 WattOS 主要為老舊硬件設計，但你完全可以把它運行在現代桌面電腦上，並且會運行的很好。根據零學習曲線，你很快就會熟悉 WattOS，並發現它運行極快而且穩定。試試這個小排量的 Linux 發行版吧，相信它會給你同樣深刻的印象。如果你發現 WattOS 運行的不夠快（發生了一些我沒有預料到的事），你完全可以去使用 Microwatt（一個更輕的輕量級發行版）。
