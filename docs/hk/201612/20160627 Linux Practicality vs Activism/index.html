Linux 的實用性 VS 行動主義 ​

我們使用 Linux 是因為它比其他操作系統更實用，還是其他更高級的理由呢？

運行 Linux 的最吸引人的事情之一就是它所提供的自由。 Linux 社區之間的分野在於我們如何看待這種自由。

對一些人來説，使用 Linux 可以享受到不受供應商限制或避免高昂的軟件成本的自由。大多數人會稱這個是一個實用性的考慮。而其它用户會告訴你，他們享受的是自由軟件的自由。那就意味着擁護支持自由軟件運動 Free Software Movement的 Linux 發行版，完全避免專有軟件和所有相關的東西。

在這篇文章中，我將帶你比較這兩種自由的區別，以及它們如何影響 Linux 的使用。

專有的問題 ​

大多數 Linux 用户有一個共同點，就是他們儘量避免使用專有軟件。對像我這樣的實用主義的愛好者來説，這意味着我能夠控制我的軟件支出，以及避免過度依賴特定供應商。當然，我不是一個程序員……所以我對安裝軟件的調整是十分微小的。但也有一些個別情況，對應用程序的小調整就意味着它要麼能工作，要麼不能。

還有一些 Linux 愛好者，傾向於避開專有軟件，因為他們覺得使用它們是不道德的。通常這裏主要的問題是使用專有軟件會剝奪或者乾脆阻礙你的個人自由。像這些用户更喜歡使用 Linux 發行版和軟件來支持 自由軟件理念 。雖然它與開源的概念相似並經常直接與之混淆，但它們之間還是有些差異的 。

因此，問題就在這裏：像我這樣的用户往往將便利性置於純粹的軟件自由的理念之上。不要誤會我的意思，像我這樣的人喜歡使用符合自由軟件理念的軟件，但我們也更有可能做出讓步（使用專有軟件），以完成特定的任務。

這兩種類型的 Linux 愛好者都喜歡使用非專有軟件的解決方案。但是，自由軟件倡導者根本不會去使用專有軟件，而實用主義用户會選擇具有最佳性能的工具。這意味着，在有些情況下，這些用户會在他們的非專有操作系統上運行專有應用或代碼。

最終，這兩種類型的用户都喜歡使用 Linux 所提供的非專有解決方案。但是，我們這樣做的原因往往會有所不同。有人認為那些不支持自由軟件的人是無知的。我不同意這種看法，我認為它是實用方便性的問題。那些喜歡實用方便性的用户根本不關心他們軟件的政治問題。

實用方便性 ​

當你問起絕大多數的人為什麼使用他們現在的操作系統，回答通常都集中於實用方便性。方便性可能體現在“它是我一直使用的系統”，乃至於“它運行了我需要的軟件”。 其他人可能進一步解釋説，軟件對他們使用操作系統的偏好影響不大，而是對操作系統的熟悉程度的問題，最後，還有一些特殊的“商業考慮”或硬件兼容性等問題也導致我們使用這個操作系統而不是另一個。

這可能會讓你們中許多人很驚訝，不過如今我運行桌面 Linux 最大的一個原因是由於我熟悉它。即使我能為別人提供 Windows 和 OS X 的支持，實際上我使用這些操作系統時感覺相當沮喪，因為它們根本就不是我習慣的用法。也因此我對那些 Linux 新手錶示同情，因為我太懂得踏入陌生的領域是怎樣的讓人惱火了。我的觀點是這樣的 —— 熟悉具有價值，而且熟悉加強了實用方便性。

現在，如果我們把它和一個自由軟件倡導者的需求來比較，你會發現這種人都願意學習新的甚至更具挑戰性的東西，以避免使用非自由軟件。對這種用户，我最讚賞的地方，就是他們堅定的採取少數人選擇的道路來堅持他們的原則，在我看來，這是十分值得讚賞的。

自由的價值 ​

我不羨慕那些自由軟件倡導者的一個地方，就是根據自由軟件基金會 Free Software Foundation規定的標準，為實現其自由，他們要始終使用 Linux 發行版和硬件而付出的額外工作。這意味着 Linux 內核需要擺脱專有的驅動支持，而且硬件不需要任何專有代碼。當然不是不可能的，但確實很難。

一個自由軟件倡導者可以達到的最好的情況是硬件是“自由兼容”的。有些供應商，可以滿足這一需求，但大多提供的硬件依賴於 Linux 兼容的專有固件。實用主義用户對自由軟件倡導者來説是個攪局者。

那麼這一切意味着的是，倡導者必須比實用主義的 Linux 愛好者，更加警惕。這本身並不一定是壞事，但如果是打算跳入自由軟件的陣營那就要考慮下了。比較而言，實用主義的用户可以不假思索地使用與 Linux 兼容的任何軟件或硬件。我不知道你是怎麼想的，但在我眼中這樣更輕鬆一點。

定義自由軟件 ​

這一部分可能會讓一部分人不高興，因為我不相信自由軟件只有一種。從我的立場，我認為真正的自由是能夠在一個特定情況下在所有可用的數據裏，用最適合這個人生活方式的方法來解決。

對我來説，我更喜歡使用能滿足我所有需求的 Linux 桌面，這包括使用非專有軟件和專有軟件。儘管有人認為專有軟件限制了我的個人自由，但我必須反駁這一點，因為我有優先使用它的自由，即選擇的自由。

或許，這也就是為什麼我更認同開源軟件 Open Source Software的理想，而不是堅持自由軟件運動Free Software movement的理念。我更願意和這樣的人羣在一起，他們不會花時間告訴我，我使用對我最適合的方式卻是錯誤的。根據我的經驗，這些開源的人羣僅僅是感興趣去分享自由軟件的優點，不帶有自由軟件的理想主義的激情。

我覺得自由軟件的概念很棒。而且對那些需要活躍在軟件政治，並向大眾指出使用專有軟件的缺陷的人來説，我認為 Linux ( GNU/Linux ) 行動是一個不錯的選擇。而像我這樣的實用主義用户可能從自由軟件的支持者轉向，如本文中所説。

當我介紹 Linux 的桌面時，我富有激情地分享它的實際優點。如果我成功地讓他們享受這一經歷，我鼓勵用户自己去發現自由軟件的觀點。但我發現大多數人使用 Linux 並不是因為他們想擁抱自由軟件，而僅僅是他們想要最好的用户體驗。也許只有我是這樣的觀點，很難説。

你怎麼認為呢？你是一個自由軟件倡導者嗎？也許你傾向於在桌面 Linux 發行版中使用專有軟件/代碼？那麼評論和分享您的 Linux 桌面體驗吧！
