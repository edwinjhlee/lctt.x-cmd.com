點評 Xubuntu 16.10：起步的好選擇 ​

簡介 ​

Xubuntu 一直是我最喜歡的發行版之一。與其它的 Linux 發行版相比，它的外觀看起來不那麼迷人，它當然也不會把你需要的軟件全部預裝上。

Xubuntu 能夠給你的就是一個良好的起點。

如果你是那種喜歡定製桌面和外觀的人，那麼 XFCE 絕對是適合於這種的最好的桌面環境。如果你的系統資源不足，或想讓桌面漂亮舒服， XFCE 還是一個很棒的選擇。

Xubuntu 之所以成領先於其它 Linux 發行版，就是因為它默認安裝 XFCE 桌面。

毫無疑問，在硬件兼容性、易用性、穩定性、易於安裝，以及擁有一個大型社區等方面，Ubuntu 是很難被超越的。Xubuntu 是 Ubuntu Linux 發行版的官方流派，因此你可以擁有所有 Ubuntu 的優點，除了用 XFCE 桌面代替 Unity 桌面。

你可以選擇性的安裝應用到你的發行版上，而不是像其它發行版那樣預裝了一堆你不需要的應用。Xubuntu 只附帶了一些必須的應用，在這麼小的核心之外的應用要靠你自己去找並安裝。

對我來説，以上就是我為什麼認為 Xubuntu 是最棒的發行版的原因。從簡單的基本安裝開始，然後按照你要的去定製就好了。

如何獲得 Xubuntu ​

你可以訪問 Xubuntu 的官網：http://xubuntu.org/。

你可以在這裏 http://xubuntu.org/getxubuntu/ 找到下載頁。

它有兩個版本，大多數人會選擇長期支持版本（LTS），除非你希望每六個月更新一次系統。而另一個版本是我今天要講的，它就是 16.10 版。

你既可以選擇一個種子文件來下載 ISO，也可以訪問它的鏡像源下載。

如果你選擇在鏡像源中下載，你需要點擊合適的 ISO 文件。比如 64 位的選擇 amd-64.iso 文件，而 32 位的選擇 i386.iso。

安裝 ​

像 Ubuntu 其它版本一樣，安裝 Xubuntu 相當直白。如果你曾經裝過一個版本，那麼基本上你可以安裝任何一個版本。

開始時選擇你的安裝語言。

你會被問到，是否需要同時安裝更新，是否要安裝第三方軟件，包括播放音樂的軟件和專有驅動。想要完成這些，你需要聯網。

再次，這也很直白，我們會在之後再次涉及到這些。

如果你有一個備用的未分配的磁盤分區和並且安裝了 Windows，您將看到可以選擇在已有 Windows 的情況下安裝 Xubuntu 並設置雙啓動。

您也可以選擇安裝 Xubuntu 作為唯一的操作系統，還可以選擇別的任何你喜歡的分區來安裝。

下一步是設置你所在的區域以確定你的時區。

接下來兩步是選擇語言和鍵盤設置，以確定鍵盤模式。

最後創建一個默認賬户，輸入你的名字、你計算機的名字、設置用户名和密碼。

Xubuntu 將會被安裝在你的電腦上了，你可以繼續往下看了。

第一印象 ​

Xubuntu 的初始界面只有一個面板位於藍色桌面的頂部。通過桌面上的圖標，你可以看到所有可用的驅動器。

畫面的頂部是個簡單的面板。

面板的左側角落有一個單獨的圖標（老鼠的樣子），點擊它後會出現一個時尚而輕量，但功能全面的菜單，它被稱為 Whisker（鬍鬚）菜單。

在右上角有着通知、電源、藍牙、網絡、音量和時鐘的圖標。

連接互聯網 ​

你可以通過點擊面板上的網絡圖標來連接互聯網。一個無線網絡的列表將會出現，你可以選擇一個點擊，並鍵入密碼，就可以連接了。

我是在我的聯想 Ideapad Y700 上安裝 Xubuntu 的，這個本子很現代，其上運行的許多發行版在無線網絡連接時會有些小問題，我不得不找些規避問題的方法。

但 Xubuntu 16.10 工作的很好，不需要做任何修改。

驅動 ​

為你的電腦尋找可用的附加驅動是十分必要的。

雖然默認的開源驅動是基本夠用的，但是如果你有着較好的顯卡，並且想獲得更好的圖形體驗，那就十分有必要去尋找專有驅動。

打開菜單，搜索附加驅動，你可以找到附加驅動設置界面。

如果看到你的顯卡驅動，但是它不工作，那麼我還是建議你用默認的顯卡驅動。

打印 ​

我有一個愛普生 WF-2630 無線打印機。 Xubuntu 能夠直接找到這台打印機，並安裝相關驅動。

我打印了測試頁，發現它的輸出非常合適。

網絡存儲 ​

我有一個跨無線網絡連接的 WD MyCloud 存儲設備。

可以通過默認的文件管理器 Thunar 來訪問這個設備。值得注意的是，我在網絡設備中找到了 WD MyCloud 設備，但是點擊它時顯示錯誤。

但是我打開 Windows 網絡文件夾時，WD MyCloud 也顯示出來了，而且我也能正常訪問該設備上的文件夾。

軟件 ​

我在文章開始時提到了，Xubuntu 配備了最少的應用集，不過它包含了你開始所需要的所有應用。

火狐瀏覽器是它的默認瀏覽器，Thunderbird 是默認的郵件客户端。

你也有一個全套的 LibreOffice 套件和 Parole 媒體播放器。

它也有一系列工具，比如圖片查看器、計算器、光盤刻錄工具，還有一個 BT 下載器。

我很高興，現在在大多數發行版上，Abiword 和 Gnumeric 都被忽略掉了，因為它們實在無關緊要。大多數人們最終會安裝 Libreoffice 的。

缺乏專門的音頻播放器這點比較奇怪。另外我需要提到的是我通常最終會安裝谷歌的 Chrome 瀏覽器，而不是使用Firefox。

本節的第一個圖片説明了原因。這張圖片裏，我試圖觀看 Google Play 商店的 “Curb Your Enthusiam” 視頻，可惜的是各種 DRM 和其它一些問題導致了視頻無法播放。

安裝軟件 ​

在 Ubuntu 16.04 以後的發行版上普遍存在的一個主要問題是有些程序無法在圖形安裝軟件中安裝。

比如在軟件管理器中找不到 Steam。

如果你使用命令列輸入 sudo apt-cache search steam 你會發現有這個軟件。

並不是只有 Steam 被遺漏了，其它軟件比如 Skype 同樣不能在圖形軟件管理工具中找到。

我真希望這個問題已經在所有 Ubuntu 發行版中解決了。

我最近還試用了 Kubuntu 16.04 ，發現它的叫做 Discover 的軟件工具完全無用，搜索根本不工作。

幸運的是，Xubuntu 上的軟件管理器可以安裝大多數軟件包，我利用它搜尋並裝上了 Quod Libet 音樂播放器。

順便説一下，如果你在安裝 Xubuntu 時選擇了同時安裝解碼器，那麼 MP3 播放也不會出現任何問題。

如果沒有安裝，那麼你需要打開終端模擬器，安裝 Xubuntu Restricted Extras 包。

Xubuntu 有一個相對較新的特性就是 XFDashboard 。它帶來了與 Gnome 桌面類似的 Dash 面板。你可以在上面添加啓動器和能夠讓應用快速啓動的鍵盤快捷鍵。

問題 ​

我在使用 Xubuntu （包括所有基於 Ubuntu 的發行版）時感受到的最大問題就是應用商店裏面找不到一些重要的應用。為啥沒有 Steam ？

在 Xubuntu 安裝時收到一個崩潰的錯誤，如下圖所示。

我沒有搞明白這個問題是怎麼回事，因為它沒有帶來任何副作用。安裝工作也沒有出岔子。

總結 ​

我不對 Xubuntu 點評更多，並不是因為我不喜歡它。事實上我是 Xubuntu 的大粉絲，並且我在另一個電腦上有一個它的深度定製版。

我使用電腦時，我希望瞭解發生了什麼，沒有比看到下面這種情況更讓人惱火的了。

認真的説，為啥會有人認為 windows 適合工作？似乎每隔一就會看到消息 “正在安裝(1/285)” ，於是當它自己更新時，你就失去了一個小時。而 Xubuntu（和其它發行版一樣）更新不會打斷你每天的工作。

事實是，Xubuntu 真的沒有什麼需要改變的，它可靠、穩定、不需要改變什麼（除了軟件管理器）。

我非常推薦 Xubuntu。

此外，我還得説去試一試 Peppermint OS、Linux Mint XFCE 或者 Manjaro XFCE 也是十分值得的。
