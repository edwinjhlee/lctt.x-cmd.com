在 Ubuntu 上安裝 VSCodium ​

不滿意 VS Code 中的遙測功能？安裝 VSCodium，它是 VS Code 的 100% 開源克隆。

VSCodium 是微軟 VS Code 的“完全開源版本”。

它基本上是 VS Code 的克隆，並去除了所有遙測痕跡。遙測是用於收集有關應用使用情況的數據。許多開發人員使用它來深入瞭解改進他們的應用。

從外觀和功能來看，這兩個編輯器是相同的。

在 Ubuntu 上安裝 VSCodium 有三種方法：

  1. 從發佈頁面下載 deb 文件進行安裝。缺點是你無法輕鬆更新它，因為你必須再次下載新的 deb 文件。
  2. 將第三方開發者倉庫添加到你的系統中（VSCodium 推薦的方式）。這樣，你還可以獲得 VSCodium 新版本的定期更新。
  3. 使用 snap 版本。如果你不厭惡 Snap 軟件包，這也許是最簡單的方法。

我不會討論第一種方法，因為它只是從 發佈頁面 下載並 安裝 deb 文件。

我們來看看另外兩種方法。

方法 1：通過添加外部倉庫來安裝 VSCodium ​

VSCodium 官方文檔引用了 Pavlo Rudy 的 GitLab 倉庫，它為你提供了 VSCodium 的持續更新版本。

📋 雖然我在這裏使用 Ubuntu，但這些步驟應該適用於 Debian 和其他基於 Debian 和 Ubuntu 的發行版。

以下是步驟。

在 Ubuntu 中打開終端 並使用以下命令獲取開發者的 GPG 簽名密鑰並將其添加到你的系統中。這樣，你的 Ubuntu 系統將信任該開發人員簽名的軟件包。

sudo wget https://gitlab.com/paulcarroty/vscodium-deb-rpm-repo/raw/master/pub.gpg -O /usr/share/keyrings/vscodium-archive-keyring.asc

下一步是將倉庫添加到 你係統的 sources.list 文件。這樣，你的 Ubuntu 系統就會知道應該從哪裏獲取包。

echo 'deb [signed-by=/usr/share/keyrings/vscodium-archive-keyring.asc ] https://paulcarroty.gitlab.io/vscodium-deb-rpm-repo/debs vscodium main'| sudo tee /etc/apt/sources.list.d/vscodium.list

正如你所看到的，該條目中的倉庫是由你在其上方添加的密鑰簽名的。

更新本地包緩存，以便你的系統能夠識別新添加的倉庫中的包。

sudo apt update

現在你已準備好在 Ubuntu 上安裝 VSCodium：

sudo apt install codium

是的，該軟件包名為 codium，而不是 vscodium。

很好！ 現在你可以在菜單中查找 “VSCodium” 並從那裏啓動應用：

現在你可以在 VSCodium 中享受編碼的樂趣。

更新 VSCodium ​

好處是你已將倉庫添加到系統中。當新的 VSCodium 發佈時，倉庫維護者會將新版本推送到倉庫，你應該在系統更新程序中看到新版本。

換句話説，保持你的 Ubuntu 系統更新，你就會擁有更新版本的 VSCodium。

刪除 VSCodium ​

如果你出於某種原因不想再使用它，可以使用以下命令將其刪除：

sudo apt remove codium

你可以將倉庫和簽名添加到你的系統中。

🚧 如果你對這些東西很在意，你也可以將它們從系統中刪除。使用 sudo 在 Linux 終端中刪除文件 時要小心一些。

sudo rm /usr/share/keyrings/vscodium-archive-keyring.asc

接下來，你還可以從 sources.list 中刪除倉庫：

sudo rm /etc/apt/sources.list.d/vscodium.list

你的主目錄中應該有一些與應用相關的本地文件，你可能還想刪除它們：

rm -r ~/.config/VSCodium

方法2：使用 Snap 安裝 VSCodium ​

💡 Snap 方法適用於任何 Linux 發行版，而不僅僅是 Ubuntu，只要 你在系統上啓用了 Snap 支持。

Snap 安裝方法比較簡單，步驟也較少。

打開終端並使用以下命令安裝 VSCodium Snap 包：

sudo snap install codium --classic

等待幾秒鐘，它會下載 Snap 軟件包，然後進行安裝。你將在屏幕上看到進度。

你如何 更新 Snap 版本的 VSCodium？Snap 應用每天自動更新多次。但是，如果應用正在運行，那麼不會更新。

因此，你也可以關閉任何正在運行的 VSCodium 實例並運行此命令來強制更新（如果有任何新版本）：

sudo snap refresh codium

如果你不喜歡它，可以使用以下命令輕鬆刪除它：

sudo snap remove codium

VS Code VS. VSCodium ​

主要區別在於，VSCodium 從 VS Code 中移除了遙測部分。除此之外，它就是這個微軟項目的克隆版，在外觀和功能上與著名的 VS Code 完全相同。

對於某些人來説，遙測可能是一個障礙，因此這個項目在開源社區中頗受歡迎。

下面是一篇關於 VS Code 遙測問題的好文章。
