Linux 如何挽救老舊電腦（和地球） ​

請不要丟棄你的舊電腦。讓我們跳過填埋場，利用 Linux 為它注入新的活力。

我的兩位孫子，Mint 和 Kasen，請求我幫助他們搭建遊戲電腦。他們的請求讓我感到非常欣喜。這不僅給了我一個與他們共度時光的美好機會，也讓我能夠幫助他們瞭解科技。同時，我能深入探討電腦對環境產生的影響。

等一下！這似乎有些離題，對吧？其實並非如此，本文就是為了闡述這個問題。

舊電腦的命運是什麼？ ​

關於舊電腦的處理（以及處理的原因）是我們討論的核心。首先，普通電腦通常在提供服務五年左右後被替換。理由何在？

我在一個名為《CHRON》的面向小企業的刊物的在線文章中找到 這樣一篇文章，電腦的壽命被建議在三至五年。這個建議的部分原因是，假定電腦在生命週期的這個階段開始變慢。這篇文章，以及其他的一些文章，都在鼓勵人們在大約同樣的時間段內更換更新、速度更快的電腦。當然，這些壓力主要來源於電腦和芯片的廠商，他們想要保持收入的增長。

再者，美國國税局也通過規定電腦所能完全折舊的時間是五年，以此間接強化了這個服務壽命的觀念。

我們首先來討論一下關於電腦會變慢的迷思。電腦實際上是不會變慢的，恆定的時鐘速度一直在運作。無論是 2.8GHz 還是 4.5GHz，當電腦忙碌時，它們總是以那個速度運行。當然，當電腦閒置或事情不多時，將會有意識地降低它的時鐘速度以節省電力。

電腦變慢並不是因為它們變老了。裝有 Windows 系統的電腦在使用過程中，會積累大量的惡意軟件、間諜軟件、廣告軟件和恐嚇軟件。這些垃圾軟件拖慢了電腦的運行。電腦用户逐漸認為這是正常的，安於電腦性能下降的境況。

Linux 馳騁救援 ​

作為朋友和熟人心目中的電腦專家，人們有時會將他們不再需要的舊電腦送給我。他們認為電腦運行速度慢，因此選擇交給我，並讓我在將它們帶到我家附近幾個街區的電子設備回收中心之前清除硬盤數據。我總是建議他們，那些三到五年的老電腦其實仍然可用，但他們似乎更傾向於花費金錢換新，而非學習一個新的操作系統。

我已經收到過幾台他人贈送的舊電腦。其中一個十分特別的是一台 Dell Optiplex 755，它配備了一個 2.33 GHz 的 Core 2 Duo 處理器以及 8GB 的 RAM。它的 BIOS 日期為 2010 年，所以現在大約應有 12 歲。這是我擁有的最老的電腦，我總是讓它忙個不停。我已經使用它好幾年了，且它從未變慢，這是因為我在它上面運行的是 Linux —— 如今是 Fedora 35。

如果你認為那是例外，那麼我給你更多例子。十年前的 2012 年，我為自己組裝了三台電腦，然後在它們所有上安裝了 Fedora。至今，它們還在順利運行，速度一如往昔。

這裏沒有例外，只有 Linux 系統在舊電腦上的正常運作。

使用 Linux 至少可以將電腦的使用壽命延長一倍，同時不需要任何額外花費。這就使得這些電腦在進入垃圾填埋場（最差情況）或回收中心（最好情況）之前，可以額外使用五到七年或更久。

只要我能找到這些電腦的替換零件，就可以使它們繼續運行，遠離任何垃圾處理或回收途徑。有些電腦的問題在於找到合適的零部件。

非標準硬件 ​

讓我們討論一下非標準硬件，以及你能在一些知名公司買到的電腦。正如我之前提到的，我有一台舊電腦是 Dell 的。Dell 是一家歷史悠久的企業。儘管我不會購買 Dell 的台式機或塔式電腦，但是我會接受捐贈或者作為禮物贈予的 Dell 電腦。我可以在這些舊電腦上安裝 Linux，去除 Windows，讓它們重新發揮作用。它們在我的家庭實驗室裏作為測試計算機使用，等等。

然而，Dell 使用了一些你無法輕鬆替換的非標準零部件。當你能找到零部件（如電源和主板）時，它們並不便宜。原因在於，這些製造商設計了搭載非標準電源和主板的系統，只適配他們自家的非標準機箱。這是一種保持收入增長的策略。如果你在市場上找不到這些零部件，你就得去原廠買，並且價格通常非常高。

舉例來説，我擁有的那台 Dell Optiplex 就使用了不符合通用標準的主板、機箱和電源。換句話説，Dell 的主板或電源可能無法適配我在當地電腦店或亞馬遜上購買的標準機箱。這些部件也不適合我孫子們會使用的遊戲機箱。主板和電源的安裝孔不會與標準機箱對齊。電源適配器不符合標準機箱中可用的空間。而主板上的 PCI 插槽和後板接口在標準機箱中的位置會不對，電源的連接器也與標準主板上的不匹配。

最後，那些非標準部件中的一個或多個終究會出現故障，你可能完全找不到替代品，或者至少找不到價格合理的替代品。在這種情況下，處理舊電腦並採購新電腦就變得合情合理了。

標準件組裝 ​

讓我們探討一下使用標準化部件進行電腦組裝，以及它們的長壽耐用如何適用於我正在幫助孫子們製造的遊戲電腦。

大部分主板採用的設計是標準化的，包括微型 ATX、ATX，以及擴展版的 ATX。這些主板在規定的位置上設置了安裝孔。許多孔位是重疊的，也就是説 ATX 主板上的孔位會和擴展版 ATX 主板的許多孔位對齊。這就意味着你可以在任何預鑽了用於標準主板孔位的機箱中安裝這些主板。這些主板都有標準的電源連接器，這意味着你可以配套使用任何標準電源。

在他們生日那天，我兩個孫子都送給了一款有標準主板安裝孔位的遊戲電腦機箱。這些孔位的螺紋是標準的，因此他們可以使用任何主板配套提供的黃銅支架螺絲在這些主板安裝孔位中。支架螺絲鎖定入主板，並且自身設有適配標準主板鎖定螺絲的標準螺紋孔。

這一切的結果就是他們可以在任何標準電腦機箱內，使用標準固定件和標準電源，安裝任何標準主板。

需要注意的是，內存、處理器以及插卡設備都是標準化的，但是它們需要和主板兼容。所以舊款主板配套的內存可能已經買不到了。在這種情況下，你需要新的主板、內存和處理器。然而，電腦的其他部分仍然可以完好使用。

如我所告訴 Mint 和 Kasen 的那樣，用全套標準部件組裝（或購買）電腦就意味着你永遠不需要買新電腦。我送給他們的這款優質機箱永遠不必更換。隨着時間的推移，可能有一些部件會出故障，但他們只需要換掉那些有缺陷的部件。這樣一來，通過不斷更新換代的標準部件，這些電腦將能經久耐用，且維護成本極低。如果有一個部件出故障，只需更換這一個部件，然後將故障部件回收。

這也極大地減少了你需要回收或者填入垃圾場的材料總量。

回收舊電腦配件 ​

我很幸運，生活在一個提供路邊回收服務的地方。這個服務雖然不包含電子設備，但周圍的多個地方都可以接受電子設備回收，我便住在其中一個地方附近。我已經把很多舊的、不能使用的電子設備送去回收，包括出了故障的電腦配件，但我從未送過整機。

我會將這些出了故障的部件分類，用舊的紙箱存起來。按類別分類——一箱是電子設備，另一箱是金屬，第三箱是電池，等等。這些箱子的內容與回收中心的分類相對應。等到一兩個箱子滿了，我就會送去回收。

結語 ​

即使在為這篇文章和我之前的自我教育做了大量的研究，仍難以確定回收的電腦和電腦配件最終會去哪裏。我所在附近的回收中心的網站指出，每種回收物料的運用都會依據它的經濟價值來決定。電腦含有大量有價值的金屬和稀土元素，因此總會被回收。

而這種回收是否以一種健康、環保的方式進行，這就是另一個話題了。到現在為止，我還無法追蹤到送去回收的電子設備最後都去了哪裏。我決定讓自己儘自己的一份力，同時也要儘量保證回收鏈的其他環節也要設置得當，高效運行。

為了地球，我們最好讓電腦儘可能長地運行。只更換故障的部件，能讓一台電腦比目前承認的壽命還要運行得更久，這顯著減少了我們需要填埋或回收的電子垃圾量。

當然，還要使用 Linux，這樣你的電腦就不會變慢了。
