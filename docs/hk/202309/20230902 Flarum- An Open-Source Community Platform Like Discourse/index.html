Flarum：一個像 Discourse 一樣的開源社區平台 ​

Flarum 可能是一個更好、更簡單，或者説更具創新性的 Discourse 替代品。更多信息可在此處獲取。新的一天，再來一次初次嘗試😎。

這次，我們為你帶來一個叫作 “Flarum” 的開源論壇軟件，它可以作為 Discourse 的備選方案。它的目標是提供一個免費、快速且易於使用的簡潔而具有可定製性的討論平台。

Flarum 還具有很高的可擴展性 ，允許進行大量的自定義。

當然，我們可以擁有的開源選項越多越好，對吧？

讓我們一起來看看它能提供什麼。

Flarum 概述⭐ ​

Flarum 是現已中止運營的 esoTalk 和 FluxBB 論壇軟件套件的繼任者。它以優化和快捷的性能為考量，提供了一整套良好的功能。

Flarum 主要使用 PHP 編程語言開發。它由志願者進行維護和管理，並依賴於社區的貢獻來推動其發展。

其主要亮點包括：

  • 高度優化
  • 響應式用户接口
  • 移動優先設計
  • 非常的靈活性

💡 Flarum 和 Discourse 使用了不同的技術棧，同時它們也有細微但實用的功能區別。

例如，Discourse 的時間線控制功能就是受到 Flarum 的啓發。

初步印象 👨‍💻 ​

我開始的測試是登錄 Flarum 的 官方論壇，使用的是我的 GitHub 賬户。

登錄後我進入了 首頁，那裏展示了所有帶有相關標籤的討論，並顯示了各討論的回覆數。

頂部菜單具有通常的搜索欄，還有查看草稿、通知、帶有用户名/頭像的菜單以及一些重要設定的選項。

首頁還包括一個側邊欄菜單，用户可以通過這個開始新的討論、訪問標籤，或者查看私有討論。

我必須説，我發現它和 Discourse 存在一些相似性，但這並不是什麼壞事！

這裏有一個讓我熟悉的時間線滾動條，我可以用它跳轉到帖子中的不同回覆。

然後有一個 “關注Follow” 按鈕，允許使用者選擇三種獨特的設置。其中一項是默認設置（沒有任何通知），另一個是獲得帖子通知，最後一個則是忽略某個帖子。

此後，我關注到用户如何互動回應某個帖子，它提供了三種方式，即“回覆Reply”該帖子，“喜歡Like”它或者“標記Flag”它並讓版主審閲。

回帖體驗也很好，編輯器上方會顯示實時預覽。它還提供了保存回覆至草稿、最小化編輯器、全屏編輯以及關閉編輯器等選項。

最後，我查看了用户設置，它完整地包括了通常的設置，並對通知提供了精細的控制。它還展示了與我的 Flarum 賬户關聯的第三方賬户。

總的來説，Flarum 與廣受歡迎的 Discourse 提供了相似的舒適體驗，它具有有益的特性差異，且其技術棧易於安裝和管理。

Flarum 經常更新，自從發佈以來，已經取得了長足的發展。它也是 Linux 服務器上最好的 開源論壇軟件 之一，事實已經證明了這一點。
