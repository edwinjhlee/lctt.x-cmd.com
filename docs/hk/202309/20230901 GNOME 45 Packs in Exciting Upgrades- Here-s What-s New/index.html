GNOME 45 引入激動人心的更新 ​

這裏列出了在 GNOME 45 中你可以期待的新特性和改進。

每次 GNOME 的主要版本更新對我來説都充滿了激動。

你可以始終期待看到 以 UI 為中心的變化、功能增強，以及核心應用的更新。

GNOME 44 引入了一些有趣的新功能，比如能夠檢查正在後台運行的應用、在文件選擇器中的縮略圖視圖等等。

GNOME 45 計劃於 9 月 20 日 發佈，但你已經可以在其 beta 版本中預覽到更新的功能集。現在，讓我們一起看看在 GNOME 45 中有哪些你可以期待的新內容。

GNOME 45：有哪些新變化？ ​

主要的亮點包括：

  • 新的核心應用
  • 系統設置中的新隱私中心
  • 系統設置中新的“關於About”面板
  • 日曆應用的新圖標
  • 對 Nautilus 文件管理器 UI 的微調

我將對所有這些改變進行分類，以幫助你更好的理解。那麼，讓我們立即開始：

Nautilus 的改善 ​

在過去，Nautilus 文件管理器沒有進行過任何 UI 調整。但是，在 GNOME 45 中，它做了一些微妙的 UI 改版，在側邊欄中你可以看到漢堡菜單。

總的來説，左側邊欄和窗口的其他部分更具區分度。

你還可以期待其性能提升和搜索功能的改善。

系統設置的變更 ​

自 GNOME 43 和 44 版本起，GNOME 在努力改進並清理系統設置Settings，以便在簡化系統設置選項的訪問性的同時，簡化所有的可用選項。

在這裏，“隱私Privacy”菜單已經改版，選項的展示更加有條理且易於訪問。

接下來，“關於About”區域也進行了調整，以便通過“系統詳細信息System Details”菜單展示技術信息，如下圖所示。

你需要點擊“系統詳細信息”來獲取關於操作系統和硬件的所有必要技術信息。

另外，為了讓 Linux 新手更輕鬆上手：

  • 在“用户User”面板中增加了彈出的説明，用於解釋自動登錄設置。
  • 向“分享Sharing”面板中的選項添加了説明，幫助用户理解可用選項。
  • “在線賬户Online Accounts”面板進行了一些改進，以提供更細粒度的控制。

新增的核心應用 ​

GNOME 45 使用了全新的 Loupe 圖像查看器 應用，替代了“GNOME 之眼Eye of GNOME”。

除此之外，你還可以期待出現“Snapshot”，這是一個新的攝像應用。它將替代“茄子Cheese”並重新命名為“相機Camera” 應用。

同時，GNOME 圖像Photos應用已被移除。

GNOME “軟件”應用的升級 ​

雖然 GNOME 軟件Software應用在初始階段並未呈現出明顯的 UI 變化，但它的價值實實在在地提升了。

包括以下一些值得注意的變化：

  • 當卸載 Flatpak 包時，會提示你是否移除相關聯的應用數據。
  • 又新增了一項指示器，用於通知哪些更新中包含了安全修復。
  • 系統更新下載時，會有通知提示。

核心應用的改進 ​

各種應用都已進行了更新。首先是“地圖Maps”應用，其中一些微妙的變化包括將縮放按鈕從標題欄移動到地圖的覆蓋層。

重構“變更路徑”的側邊欄，使其能夠適應觸摸屏顯示器，以及其它一般性的功能。

接下來是“天氣Weather”應用，其增大了默認窗口大小以容納所有温度計小部件。這款應用還可以記住你最後一次設定的窗口大小，便於在你下次打開時，直接展示該大小。

新的“控制台Console”應用現在讓你可以選擇自定義字體，並設有新的設置窗口。

總的來説，控制台在多項技術層面進一步優化。

“連接Connections”應用現在可以通過 RDP 連接複製/粘貼文本、圖像和文件。

同時，“計算器Calculator”現在支持更多貨幣，包括尼日利亞奈拉、牙買加元等。

其他改變 ​

許多其他改變可能並不很明顯，但確實存在。這些包括：

  • 文檔掃描應用已遷移至 GTK4。
  • 核心應用如文本編輯器、聯繫人、文件、網絡、日曆等的新應用樣式和 自適應行為。
  • 性能提升。
  • 在初次設置過程中對數據收集信息的改進。

如果需要更深入的瞭解 GNOME 45 的改變，可以查閲 發佈説明。

如何立即體驗 GNOME 45？ ​

可以在 Fedora 39 預發佈版 中獲得體驗。較安全的方式是通過 GNOME Boxes 嘗試 GNOME OS 夜間構建版。

Ubuntu 23.10 的日常構建可能很快就會（如果你正在閲讀這篇文章，則可能已經提供）集成 GNOME 45。

當然，最佳的體驗方式是等待 Fedora 39 的穩定版發佈，或者在 GNOME 45 發佈後立即在 Arch Linux 上進行安裝。
