Linux 上的最佳白板應用程序 ​

我們將介紹幾款可在 Linux 系統中使用的白板應用程序。我相信，這些信息對你將大有幫助。請繼續閲讀！

一般而言，數字白板是一種大型互動顯示面板的工具。比如：平板、大屏手機、觸控筆記本和表面顯示設備等，就是一些常見的白板設備類型。

假設教師使用了白板，你就可以使用觸控筆、手寫筆、手指甚至鼠標在設備屏幕上進行繪畫、書寫或操作元素。這意味着，你可以在白板上進行拖動、點擊、刪除和繪畫，就如同用筆在紙上一樣。

但是，要做到這一切，就需要一款軟件來支持這些功能，即實現觸控和顯示之間的精細協調。

現在的市面上，有很多商業應用都能完成這項工作。然而，在這篇文章中，我們將會重點介紹一些自由且開源的、並且可在 Linux 系統中運行的白板應用程序。

Linux 系統白板應用程序佳選 ​

1、Xournal++ ​

在我們的推薦名單上，第一個就是 Xournal++。我認為，這是此列表中最好的應用程序。它十分穩定，而且已經存在了一段時間。

Xournal++ 允許你進行書寫、繪畫，以及其他常見的在紙上進行的各種事情。它支持手寫、自定義熒光筆、橡皮擦等工具。此外，它還有其他諸多功能，例如：支持圖層，支持添加外部圖像，支持添加音頻，具有多頁特性等。

該應用程序兼容幾乎所有的壓敏輸入設備，例如 Wacom、Huion 和 XP-Pen。我曾在觸摸板筆記本上進行過測試，經過少量設置修改後，它就可以正常工作了。因此，你可以開始使用任何你手頭上的觸控設備。

Xournal++ 是使用 C++ 和 GTK3 進行編寫的。

對於 Linux 系統，你可以按下述步驟進行安裝。此程序是完全免費的，且適用於 Linux、macOS 和 Windows 系統。如果你想在移動設備上嘗試，也提供了 BETA 版本。

安裝步驟：

該應用程序可以通過 AppImage、Snap、Flatpak 和 deb 包進行安裝。同時，也可以通過 PPA 的方式，安裝至基於 Ubuntu/Debian 的系統。

特別的是，還為 Fedora、SUSE 和 Arch 提供了專用的安裝包。你只需要點擊下方的鏈接，就可以按你所需的格式，下載相應的執行程序。

下載 Xournal++

2、OpenBoard ​

我們接下來想要重點介紹的是 OpenBoard。這是一個簡潔易用的白板繪畫應用，它不會通過過多的選項干擾你的使用體驗。

該軟件非常適合初學者以及在線課程的初級學生來使用進行筆記。

OpenBoard 內置了豐富的功能，包括顏色、畫刷、文本、簡單的繪圖形狀，頁面支持等等。此應用基於 Qt 技術構建。

安裝步驟：

此應用僅為 Ubuntu 提供獨立的 deb 包。你可以通過以下鏈接下載。

3、Scrivano ​

Scrivano 是一款新推出的基於 Qt 技術的白板應用。其設計理念強調易用性，能在記筆記和其他繪畫活動中提供高效的功能表現。

它提供了一些獨特的功能，如吸附到網格、創建自定義貼紙、填充筆觸、激光選項等等。

此外，你還可以在此工具中導入 PDF 文件，並利用各種功能對其進行批註。

4、Notelab ​

NoteLab 是一款具有十年曆史的老牌白板應用。它是一個自由開源的應用，內含豐富的功能集，因此你可以理解這款應用的穩定性和廣受歡迎的程度。

以下是其中的部分特性：

  • 此應用支持所有常用的圖片格式作為導出選項，例如 SVG、PNG、JPG、BMP 等。
  • 提供了可配置的筆和紙的自定義選項
  • 內建的內存管理器，用於指定 NoteLab 所使用的內存量。
  • 不同格式的紙張可供選擇，如寬格式、大學格式和圖形紙。
  • 含所有標準繪圖工具。
  • 對任何筆記部分都可以進行調整大小、移動、刪除、改變顏色等多種操作。

然而，這是一個由 Java 編寫並以 .jar 文件形式發佈的應用，所以你需要 Java 運行環境來運行它。你可以參考我們的指南在 Linux 系統中安裝 Java 或 JRE。

  • 在基於 Ubuntu 的系統中安裝 Java/JRE 的方法
  • 在 Arch Linux 中安裝 Java/JRE 的方法

5、Rnote ​

我們此次要介紹的第五款應用叫做 Rnote。Rnote 是一款在觸屏設備上進行手寫筆記的絕佳應用程序。這款應用基於矢量圖像技術，不僅便於進行繪圖和註釋圖片，還方便對 PDF 文件進行標註。它支持本地的 .rnote 文件格式，並提供了 png、jpeg、SVG 和 PDF 的導入/導出選項。

Rnote 最酷的一項特性是它支持 Xournal++ 的文件格式（即本列表的首款應用程序），這使它成為必備的工具。

Rnote 使用 GTK4 和 Rust 進行開發，非常適合在 GNOME 桌面以及各類 Linux 系統上運行。

需要注意的是，該應用程序目前仍在開發中。

如何安裝：

此應用以 Flatpak 包的形式提供。你可以使用 此指南 為你的 Linux 系統安裝 Flatpak，然後點擊下方的按鈕進行安裝。

6、Lorien ​

Lorien 是一個能讓你利用多種工具創造個性化筆記的理想數字筆記本軟件。Lorien 是一個基於 Godot 遊戲引擎的跨平台、自由開源的“無限畫布繪圖/筆記”應用。這款應用十分適合於快速記取頭腦風暴會議中的筆記。

其工具箱相當標準，擁有自由手繪刷、橡皮擦、直線工具和選擇工具等。你可以移動或刪除你的筆劃部分——這些在運行時會被視為點的集合進行渲染。

如何安裝：

使用 Lorien 不需要安裝。你可以從下面的鏈接下載一個自我包含的可執行文件（下載 tar 文件）。下載後，解壓文件並雙擊即可運行。

7、Rainbow Board ​

Rainbow Board 是一款基於 Electron 和 React 的自由開源白板應用。通常，由於性能和臃腫的問題，人們並不喜歡 Electron 應用。但考慮到我們正在列出這個分類的應用，我認為值得一提。

它提供了一個標準的畫布，支持觸控和手寫輸入。工具箱包括刷子大小、顏色、填充顏色、字體以及撤銷和重做操作。你可以將你的繪製結果導出為 PNG 或 SVG 文件。

如何安裝：

此應用可以作為 Snap、Flatpak 或獨立的 deb 安裝程序下載。你可以從下面的鏈接中得到它們。
