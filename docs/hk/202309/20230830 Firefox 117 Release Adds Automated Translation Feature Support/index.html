Firefox 117 版本增加自動翻譯功能支持 ​

Firefox 117 版本為即將到來的升級帶來了必要的改進和新功能支持。

Firefox 是一款被許多人喜愛、卻被少數人討厭的瀏覽器。但是，作為基於 Chromium 的瀏覽器（例如 Chrome 和 Opera）的開源替代品，它不斷發展以為其武器庫添加新功能。

這一次，隨着 Firefox 117 的發佈，我們添加了一個有趣的附加功能，它已經準備了相當長一段時間了。

請允許我在本文中向你介紹這一點以及更多內容。讓我們開始。

🆕 Firefox 117：有什麼新變化？ ​

與大多數 Firefox 版本一樣，它也提供了很多功能。一些值得注意的亮點包括：

  • 新的注重隱私的本地翻譯功能（正在進行）。
  • 將信用卡自動填充功能擴展到更多地區。
  • YouTube 視頻列表現在可以使用屏幕閲讀器正確滾動。

雖然功能聽起來不錯，但讓我們關注翻譯功能。

注重隱私的翻譯 ​

如上面的演示，Firefox 現在具有內置翻譯工具。

它的主要賣點是所有語言翻譯都在本地進行，無需將你的數據發送到任何服務器進行處理。

該功能本來已經存在於 Firefox 中，由名為 “Firefox Translations” 的附加組件提供。

但是，當時 在 Mozilla 對引擎代碼庫進行內部安全審查後，由於其第三方依賴性，放棄將其直接將其集成到 Firefox 中。

幸運的是，現在我們有了合適的原生功能。但是，有一個問題。

🚧 感謝 Ghack，我發現翻譯功能在 Firefox 117 上默認處於禁用狀態。他們計劃逐步向用户推出該功能，並在下一個版本更新時默認禁用。

因此，為了測試它，我必須進入 about:config 手動啓用它，然後在高級首選項中啓用 browser.translations.enable 標誌。

🛠️ 其他更改和改進 ​

除此之外，還有一些值得注意的變化：

  • 各種安全更新。
  • macOS 用户現在可以控制控件和鏈接的選項卡功能。
  • 新的 CSS 兼容性工具提示增強了 Web 兼容性檢查。（對網絡開發人員有用）
  • 一個新的首選項，允許禁用按 Shift+右鍵單擊時出現的上下文菜單。

你可以瀏覽 發行説明 以更深入地瞭解此版本。

📥 獲取 Mozilla Firefox 117 ​

你可以從 FTP 門户 獲取最新版本的 Firefox。如果尚未提供，它應該很快就會在 官方網站 上提供。

Mozilla Firefox 117

對於現有安裝： 你可以通過在設置菜單中搜索“更新”，然後單擊“檢查更新”來更新它。
