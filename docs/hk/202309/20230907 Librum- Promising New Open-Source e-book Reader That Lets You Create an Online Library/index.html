Librum：為你打造在線圖書館的新興開源電子書閲讀器 ​

Librum，這是一個全新的，配備雲圖書館功能的電子書閲讀器。

你是不是酷愛閲讀？或者正在逐漸淪為書蟲？

放心，我們為你準備了絕佳的解決方案！

Librum 閲讀器，這是一個全新的電子閲讀器產品，它打造的閲讀環境 “能讓每個人都發現閲讀的樂趣，輕鬆愉快地閲讀”。

儘管它並非你通常會使用的那種離線閲讀器應用，但在 Linux 最佳電子閲讀器 的榜單上，很可能是候選之一。因為有了 Librum，你可以 充分發揮雲技術的優勢，任何時候，無論使用哪個設備，都能隨時訪問個人圖書館。

下面，就讓我來為你詳細介紹一下。

Librum：概覽 ⭐ ​

Librum 基本上是通過 QML 和 C++ 構建的，這款 開源的電子書閲讀器 允許你以直觀的界面將內容同步到雲端。

你可以免費開始使用，初次註冊便有 2GB 的雲存儲空間。此外，一些尚未最終確定的高級套餐也即將推出。

🚧 Librum 閲讀器目前正在積極開發中，尚未發佈穩定版。

Librum 還配有豐富的功能，其中一些突出之處包括：

  • 圖書館的個性化定製
  • 書籍的元數據編輯
  • 雲同步
  • 現代化的界面

推薦閲讀 📖

8 個 Linux 上的最佳電子書閲讀器

初步體驗 👨‍💻 ​

我首次嘗試在我的 Ubuntu 22.04 系統上運行 Librum。但是，在我使用該應用之前，我 必須先創建一個賬户，提供電子郵件地址和密碼。

雖然 Librum 的主打功能是基於雲的體驗，但我 還是希望它能有一個專門的離線模式，可以讓我在註冊之前做一些試用，或者作為一種可選擇的備用模式。

不過，我還是繼續前進，並登錄了這款應用。我使用 “添加書籍Add books” 功能導入了一些書籍，然後它們就在主頁標籤下被整齊地排列好，提供了對其排序、過濾或添加標籤的選項。

電子書的閲讀體驗 幾乎與你對現代閲讀器應用的期待一致，擁有最簡界面，還有放大文本、進入全屏模式等功能。

漢堡菜單的選項內含有一些基本功能。最上面三個選項可以讓你打印、保存或分享當前打開的電子書。

此外的選項還包括：文本轉語音功能、連續/垂直顯示頁面、反轉顏色、同步書籍，以及訪問設置菜單。

我也試用了一下 搜索功能：我可以快速地查找特定的詞彙，並可以高亮顯示所有結果、區分大小寫或搜索整個單詞。

目錄功能 也相當方便使用，你可以使用搜索欄查找特定章節。

以上就是我使用 Librum 閲讀器的電子書閲讀體驗。

但是等一下，這還沒完，還有更多的東西等着你去發現！

未來計劃的功能 📝 ​

我注意到還有很多功能正在開發中。

其中一個是 一個在應用內部的免費書店，計劃將提供超過 70,000 本的電子書籍；另一個是 統計頁面，將會顯示 個人的閲讀統計信息。

最後一個是 插件頁面，應該是提供 進一步增強 Librum 功能的插件。

預計在接下來的幾個月內會發布穩定版本。

開發者們還沒有明確説明即將推出的付費計劃具體會提供什麼。我個人猜測可能會提供更多的雲存儲空間和接入更多新奇的功能。

我推薦你關注他們的 新聞頁面，以便獲取有關 Librum 閲讀器的最新信息。

📥 獲取 Librum ​

目前，Librum 以 Flatpak 形式提供給 Linux 用户，並且還在為 Windows 和 macOS 用户開發對應版本。

轉到 官方網站 或 Flathub 商店 就可以獲取下載。
