微軟 Exchange 的一個開源替代方案 ​

開源用户現在有了一個強大的、功能齊全的羣件選擇。

多年來，微軟 Exchange 作為一個平台牢牢統治着羣件環境。然而，在 2020 年末，一個奧地利的開源軟件開發商推出了 grommunio，這是一個羣件服務器和客户端，其外觀和感覺讓 Exchange 和 Outlook 用户感到很熟悉。

grmmunio 項目可以很好地替代 Exchange。開發者以與微軟相同的方式將組件連接到平台上，它們支持 RPC （遠程過程調用）與 HTTP 協議。據開發者介紹，grommunio 還包括許多常見的羣件接口，如 IMAP、POP3、SMTP、EAS（Exchange ActiveSync）、EWS（Exchange Web Services）、CalDAV 和 CardDAV。有了這樣廣泛的支持，grommunio 可以順利地整合到現有的基礎設施中。

用户會注意到對 Outlook、Android 和 iOS 客户端來説幾乎沒有區別。當然，作為開源軟件，它也支持其他客户端。由於集成了原生的 Exchange 協議，Outlook 和智能手機與 grommunio 的通信就像與微軟 Exchange 服務器一樣。日常的企業用户可以繼續使用他們現有的客户端，而 grommunio 服務器則在後台安靜地運行。

不僅僅是郵件 ​

除了郵件功能外，grommunio 界面還提供了日曆系統。可以直接在日曆顯示中或在一個新標籤中點擊創建約會。這很直觀，正如你對現代工具的期望。用户可以創建、管理和分享日曆以及地址簿。私人聯繫人或普通聯繫人都支持，而且你可以與同事分享一切。

任務管理在左邊的下拉菜單中顯示任務列表，它們可以有一個所有者和多個合作者。你可以為每個任務指定截止日期、類別、附件和其他屬性。筆記可以以同樣的方式被管理並與其他團隊成員共享。

聊天、視頻會議和文件同步 ​

除了現代羣件的所有標準功能外，grommunio 還提供聊天、視頻會議和文件同步功能。它為企業實現了大規模的全面整合，具有極高的性能。對於開源的推動者來説，這是一個簡單的選擇，對於系統管理員來説，這是一個強大的選擇。因為 grommunio 的目標是整合而不是重新發明，所以所有的組件都是標準的開源工具。

用於高級視頻會議的 Jitsi 集成（Markus Feilner, CC BY-SA 4.0）

在 grommunio 會議功能的背後是 Jitsi，它以熟悉的用户界面順利地集成到 grommunio 的用户界面中。完全集成和集中管理的聊天功能是基於 Mattermost。

用於聊天的 Mattermost（Markus Feilner，CC BY-SA 4.0）

ownCloud 承諾提供企業級的文件共享和同步，在點擊“文件”按鈕後開始。

用於文件同步和交換的 ownCloud（Markus Feilner，CC BY-SA 4.0）

grommunio 項目有一個強大的管理界面，包括角色、域和組織管理、預測性監測和自助服務門户。基於 shell 的嚮導指導管理員完成安裝和從微軟 Exchange 遷移數據。開發團隊正在不斷努力，以實現更好的整合和更集中的管理，並隨之為管理員提供更好的工作流程。

grommunio 的管理界面（Markus Feilner, CC BY-SA 4.0）

探索 grommunio ​

grommunio 項目的目標很高，但它的開發者已經付出了努力，這一點很明顯。一家專門從事税務諮詢的德國託管服務機構最近宣佈，他們的客户可以使用 grommunio，這是一個德國數據保護法特別嚴厲的行業。grommunio 項目做得很好：將現有的、成功的概念乾淨地結合在一起，實現了開放、安全和符合隱私的通信。
