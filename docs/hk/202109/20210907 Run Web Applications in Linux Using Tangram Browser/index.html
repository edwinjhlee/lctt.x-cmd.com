使用 Tangram 瀏覽器在 Linux 中運行 Web 應用 ​

Tangram 是一個旨在幫助你在 Linux 中運行和管理 Web 應用的瀏覽器。一起來看看它是如何使用的吧。

對於一些工具來説，即使我們有許多 Linux 原生應用，但是許多人最終還是選擇使用 Web 應用。

他們也許是使用 Electron 構建的應用，或是直接在瀏覽器中打開的網頁，使用原生應用正在成為一種比較“傳統”的做法。

當然，不管在什麼平台運行 Web 應用都會佔用更多的系統資源。而且，考慮到每一個服務都正在提供基於 Web 的方式，而不是原生體驗，我們就需要一種有效管理 Web 應用的解決方案。

一款開源的 Linux 應用 Tangram 或許就是這個解決方案。

Tangram：專為 Web 應用設計的瀏覽器 ​

你可以選擇其他 優秀的瀏覽器 來運行 Web 應用，但是如果你想完全專注於 Web 應用體驗的瀏覽器，Tangram 是個不錯的選擇。

Tangram 的開發者從 GNOME Web、Franz 和 Rambox 中獲得了靈感。

沒有其他花裏胡哨的功能，只是能更改你的用户代理User Agent和管理你所登錄的 Web 應用。

它可以用於訪問多個社交媒體，聊天工具，工作協同應用等等。

Tangram 的特性 ​

考慮到 Tangram 是一個基於 WebKitGTK 的精簡化瀏覽器，它擁有的功能不算很多，下面是一些功能要點：

  • 重新排列側邊欄的標籤
  • 方便地將任何一個 Web 服務添加為 Web 應用程序
  • 調整用户代理（桌面端和移動端）
  • 使用鍵盤快捷鍵
  • 改變側邊欄（標籤欄）的位置

你所需要做的就是加載一個 Web 服務，登錄，然後點擊“完成”，將其添加為 Web 應用程序。

在 Linux 中安裝 Tangram ​

每個 Linux 發行版都可以通過 Flatpak 來安裝 Tangram，你也可以在 AUR 中找到它。

如果你想通過終端來安裝它，輸入以下命令：

flatpak install flathub re.sonny.Tangram

如果你的系統沒有啓用 Flatpak，你可以參考我們的 Flatpak 指南。

想要了解更多信息，請訪問 Tangram 的 Github 頁面。
