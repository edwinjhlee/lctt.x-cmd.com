如何在 Linux 系統設置打印機 ​

如果系統沒有自動檢測到你的打印機，這篇文章教你如何在 Linux 系統手動添加打印機。

即使未來已來，電子墨水e-ink和 AR 技術可以現實應用，我們還是會用到打印機的。打印機製造商還不能做到讓自己的專利打印機可以與各種計算機完全標準化傳遞信息，以至於我們需要各種打印機驅動程序，在任何操作系統上都是如此。電子電氣工程師協會信息科學與技術處（IEEE-ISTO）下屬的打印機工作組（PWG）和開放打印技術組織（OpenPrinting.org）長期合作致力於讓人們可以（使用任何型號打印機）輕鬆打印。帶來的便利就是，很多打印機可以不需要用户進行配置就可以自動被識別使用。

如果系統沒有自動檢測到你的打印機，你可以在這篇文章中找到如何在 Linux 系統手動添加打印機。文中假定你使用的是 GNOME 圖形桌面系統，其設置流程同樣適用於 KDE 或其他大多數桌面系統。

打印機驅動程序 ​

在你嘗試用打印機打印文件時，要先確認你的 Linux 系統上是不是已經安裝了更新的打印機驅動程序。

可以嘗試安裝的打印機驅動程序有三大類：

  • 作為安裝包提供的，捆綁在你的 Linux 系統上的開源 Gutenprint 驅動程序
  • 打印機製造商提供的專用驅動程序
  • 第三方開發提供的打印機驅動程序

開源打印機驅動程序庫可以驅動 700 多種打印機，值得安裝，這裏面可能就有你的打印機的驅動，説不定可以自動設置好你的打印機（，你就可以使用它了）。

安裝開源驅動程序包（庫） ​

有些 Linux 發行版已經預裝了開源打印機驅動程序包，如果沒有，你可以用包管理器來安裝。比如説，在 Fedora、CentOS、Magela 等類似發行版的 Linux 系統上，執行下面命令來安裝：

$ sudo dnf install gutenprint

惠普（HP）系列的打印機，還需要安裝惠普的 Linux 圖形及打印系統軟件包（HPLIP）。如在 Debian、Linux Mint 等類似的系統上，可以使用下面的命令：

$ sudo apt install hplip

安裝製造商提供的驅動程序 ​

很多時候因為打印機製造商使用了非標準的接口協議，這種情況開源打印機驅動程序就不能驅動打印機。另外的情況就是，開源驅動程序可以驅動打印機工作，但是會缺少供應商特有的某些性能。這些情況，你需要訪問製造商的網站，找到適合你的打印機型號的 Linux 平台驅動。安裝過程各異，仔細閲讀安裝指南逐步安裝。

如果你的打印機根本不被廠商支持，你或許也只能嘗試第三方提供的該型號打印機的驅動軟件了。這類第三方驅動程序不是開源的，但大多數打印機的專用驅動程序也不是。如果你需要額外花費從供應商那裏獲取幫助服務才能安裝好驅動並使用你的打印機，那是很心疼，或者你索性把這台打印機扔掉，至少你知道下次再也不會購買這個品牌的打印機了。

通用打印驅動系統（CUPS） ​

通用打印驅動系統Common Unix Printing System（CUPS）是由 Easy Software Products 公司於 1997 年開發的，2007 年被蘋果公司收購。這是 Linux 平台打印的開源基礎軟件包，大多數現代發行版都為它提供了一個定製化的界面。得益於 CUPS 技術，你可以發現通過 USB 接口連接到電腦的打印機，甚至連接在同一網絡的共享打印機。

一旦你安裝了需要的驅動程序包，你就能手工添加你的打印機了。首先，把打印機連接到運行的電腦上，並打開打印機電源。然後從“活動”屏幕或者應用列表中找到並打開“打印機”設置。

基於你已經安裝的驅動包，你的 Linux 系統有可能自動檢測識別到你的打印機型號，不需要額外的設置就可以使用你的打印機了。

一旦你在列表中找到你的打印機型號，設置使用這個驅動，恭喜你就可以在 Linux 系統上用它打印了。

（如果你的打印機沒有被自動識別，）你需要自行添加打印機。在“打印機”設置界面，點擊右上角的解鎖按鈕，輸入管理用户密碼，按鈕轉換成“添加打印機”按鈕。

然後點擊這個“添加打印機”按鈕，電腦會搜索已經連接的本地打印機型號並匹配相應驅動程序。如果要添加網絡共享打印機，在搜索框輸入打印機或者其服務器機的 IP 地址。

選中你想添加的打印機型號，點擊“添加”按鈕把打印機驅動加入系統，就可以使用它了。

在 Linux 系統上打印 ​

在 Linux 系統上打印很容易，不管你是在使用本地打印機還是網絡打印機。如果你計劃購買打印機，建議查看開放打印技術組織的（可支持打印機）資料庫（OpenPrinting.org），看看你想購買的打印機是不是有相應的開源驅動程序。如果你已經擁有一台打印機，你現在也知道怎樣在你的 Linux 系統上使用你的打印機了。

via: https://opensource.com/article/21/8/add-printer-linux
