5 個替代 Zoom 的開源軟件 ​

試試這些開源視頻會議服務之一。

我最近參加了 實用開源信息（POSI） 會議，它是在一個自由開源的視頻會議平台上舉行的。當我參加了一系列關於開源軟件的實際用途的精彩講座時，我意識到視頻會議在過去幾年裏已經變得非常普遍。

如果説開源做了什麼，那就是提供了選擇，現在越來越多的工人有了遠程工作的自由，在你的連接方式上有一個選擇是非常有意義的。

有時，你需要一個全功能的視頻會議應用，其中包括審核、演示模式和分組討論室，而其他時候，你想做的只是給朋友打一個快速電話，以便看到對方的臉。

Jitsi ​

Jitsi 是一個簡單、隨意、但強大的視頻通話平台。你可以自己託管它，也可以在 meet.jit.si 的公共實例上使用它。它有可定製的 URL，可以很容易地與你想見面的朋友分享鏈接、通話中的聊天、管理控制，和通話錄音。它的開發非常活躍，每年都會測試和發佈一大批新功能。它是 Opensource.com 用於我們每週會議的平台。

Signal ​

Signal 已經是一個流行的以安全為重點的聊天應用，最近它又增加了 團體視頻通話 的功能。視頻通話非常適合簡單的會議，而且因為你只能與你的 Signal 聯繫人列表中的其他人見面，所以不用擔心你的視頻通話會議上有不速之客。當你嘗試定位你應該參與開會的虛擬房間時，也沒有來回的“電話標籤”。這一切都發生在 Signal 中，因此無需猜測。

Signal 本身是非常直觀的，視頻功能非常適合其現有慣例。簡而言之，只要你的聯繫人在使用 Signal，這就是一個不費力的視頻通話平台。這是我用於個人聯繫的應用，我經常使用其視頻通話功能與朋友和家人聯繫。

P2p.chat ​

P2p.chat 是這些中最簡單的一個，無論是設計還是實現。通過 WebRTC 工作，p2p.chat 是一個 Web 應用，允許你直接連接到你正在呼叫的人，而不需要託管服務器。p2p.chat 的界面並不多，但這也是其吸引力的另一部分。沒有管理控制或演示模式，因為 p2p.chat 在很大程度上是科幻片中承諾的“視頻電話”：與遠方的人進行輕鬆的人對人（或人們對人們）視頻通話。

你可以使用自定義的 URL 來動態地創建一個會議空間，所以它們相對容易記憶（除了小的隨機部分）和輸入。我和不在 Signal 上的朋友使用 p2p.chat，它從未讓我失望過。

BigBlueButton ​

如果你需要嚴格的管理控制和極端的靈活性，BigBlueButton 是你正在尋找的解決方案，它專為教室、會議和演講而設計。有了 BigBlueButton，你可以讓所有與會者靜音，阻止和踢走一個與會者，創建分組討論室，創建協作式白板，共享屏幕，進行演講，以及記錄會議。與會者可以“舉起手”表示注意，並將他們的狀態設定為非語言交流方式。它很容易使用，但它是一個嚴肅的平台，適用於重點和非常大的羣體。我參加過一些使用 BigBlueButton 的技術會議，包括 實用開源信息（POSI）會議。

Wire ​

Wire 是尋找託管視頻聊天和羣件客户端的企業客户的絕佳選擇。它是 AGPL 許可，這個開源項目可用於桌面和服務器、安卓和 iOS。它具有視頻通話、發信和文件共享的功能，因此，即使是遠程會議，基本上也有親自開會的所有便利。你可以在有限的時間內免費試用 Wire，然後為你的公司購買一份支持合同。另外，你也可以自己託管它。

開源視頻聊天 ​

沒有理由滿足於由你可能不完全信任的公司託管的專有視頻通話。今天可用的開源選項對於與你的職業和個人生活中的所有人保持聯繫是非常好的。下次你想和朋友見面時，不妨試試這些解決方案之一。
