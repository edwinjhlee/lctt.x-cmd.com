滿足日常需求的應用（四）：音頻編輯器 ​

在過去，音頻編輯應用或數字音頻工作站digital audio workstation（DAW）只提供給專業人士使用，如唱片製作人、音響工程師和音樂家。但現在很多不是專業人士的人也需要它們。這些工具被用於演示文稿解説、視頻Blog，甚至只是作為一種愛好。現在尤其如此，因為有這麼多的在線平台，方便大家分享音頻作品，如音樂、歌曲、播客等。本文將介紹一些你可以在 Fedora Linux 上使用的開源音頻編輯器或 DAW。你可能需要安裝提到的軟件。如果你不熟悉如何在 Fedora Linux 中添加軟件包，請參閲我之前的文章安裝 Fedora 34 工作站後要做的事情。這裏列出了音頻編輯器或 DAW 類的一些日常需求的應用。

Audacity ​

我相信很多人已經知道 Audacity 了。它是一個流行的多軌音頻編輯器和錄音機，可用於對所有類型的音頻進行後期處理。大多數人使用 Audacity 來記錄他們的聲音，然後進行編輯，使其成品更好。其成品可以作為播客或視頻Blog的解説詞。此外，人們還用 Audacity 來創作音樂和歌曲。你可以通過麥克風或調音台錄製現場音頻。它還支持 32 位的聲音質量。

Audacity 有很多功能，可以支持你的音頻作品。它有對插件的支持，你甚至可以自己編寫插件。Audacity 提供了許多內置效果，如降噪、放大、壓縮、混響、回聲、限制器等。你可以利用實時預覽功能在直接聆聽音頻的同時嘗試這些效果。內置的插件管理器可以讓你管理經常使用的插件和效果。

詳情請參考此鏈接： https://www.audacityteam.org/

LMMS ​

LMMS（即 Linux 多媒體工作室Linux MultiMedia Studio）是一個全面的音樂創作應用。你可以從頭使用 LMMS 用你的電腦開始製作你的音樂。你可以根據自己的創意創造旋律和節拍，並通過選擇聲音樂器和各種效果使其更加完美。有幾個與樂器和效果有關的內置功能，如 16 個內置合成器、嵌入式 ZynAddSubFx、支持插入式 VST 效果插件、捆綁圖形和參數均衡器、內置分析器等等。LMMS 還支持 MIDI 鍵盤和其他音頻外圍設備。

詳情請參考此鏈接： https://lmms.io/

Ardour ​

Ardour 作為一個全面的音樂創作應用，其功能與 LMMS 相似。它在其網站上説，Ardour 是一個 DAW 應用，是來自世界各地的音樂家、程序員和專業錄音工程師合作的結果。Ardour 擁有音頻工程師、音樂家、配樂編輯和作曲家需要的各種功能。

Ardour 提供了完整的錄音、編輯、混音和輸出功能。它有無限的多聲道音軌、無限撤銷/重做的非線性編輯器、一個全功能的混音器、內置插件等。Ardour 還包含視頻播放工具，所以使用它為視頻項目創建和編輯配樂也很有幫助。

詳情請參考此鏈接： https://ardour.org/

TuxGuitar ​

TuxGuitar 是一款指法譜和樂譜編輯器。它配備了指法編輯器、樂譜查看器、多軌顯示、拍號管理和速度管理。它包括彎曲、滑動、顫音等各種效果。雖然 TuxGuitar 專注于吉他，但它也可以為其他樂器寫樂譜。它也能夠作為一個基本的 MIDI 編輯器。你需要對指法譜和樂譜有一定的瞭解才能使用它。

詳情請參考此鏈接： http://www.tuxguitar.com.ar/

總結 ​

本文章介紹了四款音頻編輯器，可以滿足你在 Fedora Linux 上日常使用的需求。其實，在 Fedora Linux 上還有很多音頻編輯器或者 DAW 供你選擇。你也可以使用 Mixxx、Rosegarden、Kwave、Qtractor、MuseScore、musE 等等。希望本文為你調查和選擇合適的音頻編輯器或者 DAW 提供幫助。如你有使用這些應用的經驗，請在評論中分享你的經驗。

via: https://fedoramagazine.org/apps-for-daily-needs-part-4-audio-editors/
