2021 年了，我們能推薦使用 Linux 來玩遊戲嗎？ ​

每天，Linux 都在進行不斷進步，以支持具有適當圖形支持的現代遊戲。但是，我們能推薦 Linux 用於遊戲嗎？

你經常會聽到 Linux 愛好者稱讚 Linux 上改進的遊戲功能。是的，考慮到在 Linux 桌面上支持現代遊戲所取得的進步，Linux 已經在遊戲方面獲得了很大的提升。

甚至 Lutris 的創造者在我們的採訪中也提到 Linux 在遊戲方面取得的進步簡直令人難以置信。

但是，這有什麼值得大肆宣傳的嗎？我們能向遊戲玩家推薦 Linux 嗎？ Linux 適合玩遊戲嗎？

此文中，我想分享一些關於在 Linux 系統上玩遊戲的的事情，並分享我對它的看法。

你可以在 Linux 上玩遊戲嗎？是的！ ​

如果有人曾經告訴過你，不能在 Linux 上玩遊戲，那是不對的。

你可以在 Linux 上玩各種遊戲而不會出現任何大的障礙。而且，在大多數情況下，它是可玩的，並且會提供很好的遊戲體驗。

事實上，如果你不知道從哪裏開始，我們有一份 Linux 遊戲終極指南 提供給你。

需要一個特定的 Linux 發行版才能玩遊戲嗎？ ​

並非如此。這取決於你想獲得多麼方便的體驗。

例如，如果你希望 Linux 發行版能夠與你的圖形驅動程序很好地配合，並獲得最新的硬件支持，那麼有一些發行版可以做到。同樣，如果你只是想用集成的 GPU 玩原生的 Linux 獨立遊戲，任何發行版都可以。

因此，在你開啓 Linux 遊戲之旅的同時，會有一些因素影響你對發行版的選擇。

不用擔心，為了幫助你，我們提供了一份有用的 最佳 Linux 遊戲發行版列表。

Linux 上的虛擬現實遊戲，唉…… ​

我確信 VR 遊戲還沒有完全普及。但是，如果你想要在 VR 頭盔上獲得激動人心的體驗，那麼選擇 Linux 作為你的首選平台可能不是一個好主意。

你沒有在 Linux 上獲得便利體驗所需的驅動程序或應用程序。沒有任何發行版可以幫助你解決此問題。

如果你想了解有關虛擬現實狀態的詳細信息，可以看看 Boiling Steam 上的Blog文章和 GamingOnLinux 上的使用 Valve 的 VR 頭盔的有趣體驗。

我已經提供了這些Blog文章的鏈接以供參考，但總而言之 —— 如果你想體驗 VR 遊戲，請避免使用 Linux（如果你實在太閒，請隨意嘗試）。

可以在 Linux 上玩 Windows 系統的遊戲嗎？ ​

可以，也不可以。

你可以使用 Steam Play 來玩 Windows 專屬的遊戲，但是它也存在一些問題，並不是每個遊戲都可以運行。

例如，我最終還是使用 Windows 來玩《地平線 4》。如果你喜歡汽車模擬或賽車遊戲，這是一款你可能不想錯過的傑作。

或許我們在不久的將來可以看到它通過 Steam Play 完美的運行，誰知道呢？

因此，可以肯定的是，你會遇到許多類似的遊戲，可能根本無法運行。這是殘酷的事實。

而且，要知道該遊戲是否可以在 Linux 上運行，請前往 ProtonDB 並搜索該遊戲，看看它是否至少具有 “黃金” 狀態。

帶有反作弊引擎的多人遊戲可以嗎？ ​

許多遊戲玩家更喜歡玩多人遊戲，如《Apex Legends》、《彩虹六號：圍攻》和《堡壘之夜》。

然而，一些依賴於反作弊引擎的流行遊戲還不能在 Linux 上運行。它仍然是一項進行中的工作，可能在未來的 Linux 內核版本中實現 —— 但目前還沒有。

請注意，像 《反恐精英：全球攻勢》、《Dota 2》、《軍團要塞 2》、《英靈神殿》等多人遊戲提供原生 Linux 支持並且運行良好！

我會推薦使用 Linux 來玩遊戲嗎？ ​

考慮到你可以玩很多 Windows 專屬的遊戲、原生的獨立遊戲，以及 Linux 原生支持的各種 AAA 遊戲，我能推薦初次使用者嘗試在 Linux 上玩遊戲。

但是，需要注意的是 —— 我建議你列出你想玩的遊戲列表，以確保它在 Linux 上運行沒有任何問題。否則，你最終都可能浪費大量時間進行故障排除而沒有結果。

不要忘記，我相信 Linux 上的 VR 遊戲是一個很大的問題。

而且，如果你想探索所有最新最好的遊戲，我建議你堅持使用 Windows 的遊戲電腦。

雖然我應該鼓勵更多的用户採用 Linux 作為遊戲平台，但我不會忽視為什麼普通消費者仍然喜歡使用 Windows 機器來玩遊戲的客觀事實。
