如何在 Linux 中捕獲並流式傳輸你的遊戲過程 ​

也許沒有那麼多鐵桿的遊戲玩家使用 Linux，但肯定有很多 Linux 用户喜歡玩遊戲。如果你是其中之一，並希望向世界展示 Linux 遊戲不再是一個笑話，那麼你會喜歡下面這個關於如何捕捉並且/或者以流式播放遊戲的快速教程。我在這將用一個名為 “Open Broadcaster Software Studio” 的軟件，這可能是我們所能找到最好的一種。

捕獲設置 ​

在頂層菜單中，我們選擇 “File” → “Settings”，然後我們選擇 “Output” 來設置要生成的文件的選項。這裏我們可以設置想要的音頻和視頻的比特率、新創建的文件的目標路徑和文件格式。這上面還提供了粗略的質量設置。

如果我們將頂部的輸出模式從 “Simple” 更改為 “Advanced”，我們就能夠設置 CPU 負載，以控制 OBS 對系統的影響。根據所選的質量、CPU 能力和捕獲的遊戲，可以設置一個不會導致丟幀的 CPU 負載設置。你可能需要做一些試驗才能找到最佳設置，但如果將質量設置為低，則不用太多設置。

接下來，我們轉到設置的 “Video” 部分，我們可以設置我們想要的輸出視頻分辨率。注意縮小過濾（downscaling filtering ）方式，因為它使最終的質量有所不同。

你可能還需要綁定熱鍵以啓動、暫停和停止錄製。這特別有用，這樣你就可以在錄製時看到遊戲的屏幕。為此，請在設置中選擇 “Hotkeys” 部分，並在相應的框中分配所需的按鍵。當然，你不必每個框都填寫，你只需要填寫所需的。

如果你對流式傳輸感興趣，而不僅僅是錄製，請選擇 “Stream” 分類的設置，然後你可以選擇支持的 30 種流媒體服務，包括 Twitch、Facebook Live 和 Youtube，然後選擇服務器並輸入 流密鑰。

設置源 ​

在左下方，你會發現一個名為 “Sources” 的框。我們按下加號來添加一個新的源，它本質上就是我們錄製的媒體源。在這你可以設置音頻和視頻源，但是圖像甚至文本也是可以的。

前三個是關於音頻源，接下來的兩個是圖像，JACK 選項用於從樂器捕獲的實時音頻， Media Source 用於添加文件等。這裏我們感興趣的是 “Screen Capture (XSHM)”、“Video Capture Device (V4L2)” 和 “Window Capture (Xcomposite)” 選項。

屏幕捕獲選項讓你選擇要捕獲的屏幕（包括活動屏幕），以便記錄所有內容。如工作區更改、窗口最小化等。對於標準批量錄製來説，這是一個適合的選項，它可在發佈之前進行編輯。

我們來探討另外兩個。Window Capture 將讓我們選擇一個活動窗口並將其放入捕獲監視器。為了將我們的臉放在一個角落，視頻捕獲設備用於人們可以在我們説話時可以看到我們。當然，每個添加的源都提供了一組選項來供我們實現我們最後要的效果。

添加的來源是可以調整大小的，也可以沿着錄製幀的平面移動，因此你可以添加多個來源，並根據需要進行排列，最後通過右鍵單擊執行基本的編輯任務。

過渡 ​

最後，如果你正在流式傳輸遊戲會話時希望能夠在遊戲視圖和自己（或任何其他來源）之間切換。為此，請從右下角切換為“Studio Mode”，並添加一個分配給另一個源的場景。你還可以通過取消選中 “Duplicate scene” 並檢查 “Transitions” 旁邊的齒輪圖標上的 “Duplicate sources” 來切換。 當你想在簡短評論中顯示你的臉部時，這很有幫助。

這個軟件有許多過渡效果，你可以按中心的 “Quick Transitions” 旁邊的加號圖標添加更多。當你添加它們時，還將會提示你進行設置。

總結 ​

OBS Studio 是一個功能強大的免費軟件，它工作穩定，使用起來相當簡單直接，並且擁有越來越多的擴展其功能的附加插件。如果你需要在 Linux 上記錄並且/或者流式傳輸遊戲會話，除了使用 OBS 之外，我無法想到其他更好的解決方案。你有其他類似工具的經驗麼？ 請在評論中分享也歡迎包含一個展示你技能的視頻鏈接。😃
