5 個需要知道的開源的軟件定義網絡（SDN）項目 ​

SDN 開始重新定義企業網絡。這裏有五個應該知道的開源項目。

縱觀整個 2016 年，軟件定義網絡（SDN）持續快速發展並變得成熟。我們現在已經超出了開源網絡的概念階段，兩年前評估這些項目潛力的公司已經開始了企業部署。如幾年來所預測的，SDN 正在開始重新定義企業網絡。

這與市場研究人員的觀點基本上是一致的。IDC 在今年早些時候公佈了 SDN 市場的一份研究，它預計從 2014 年到 2020 年 SDN 的年均複合增長率為 53.9％，屆時市場價值將達到 125 億美元。此外，“2016 技術趨勢Technology Trends 2016” 報告中將 SDN 列為 2016 年最佳技術投資。

IDC 網絡基礎設施副總裁，Rohit Mehra 説：“雲計算和第三方平台推動了 SDN 的需求，這預示着 2020 年的一個價值超過 125 億美元的市場。毫無疑問的是 SDN 的價值將越來越多地滲透到網絡虛擬化軟件和 SDN 應用中，包括虛擬化網絡和安全服務。大型企業現在正在數據中心體現 SDN 的價值，但它們最終會認識到其在分支機構和校園網絡中的廣泛應用。“

Linux 基金會最近發佈了其 2016 年度報告“開放雲指南：當前趨勢和開源項目”。其中第三份年度報告全面介紹了開放雲計算的狀態，並包含關於 unikernel 的部分。你現在可以下載報告了，首先要注意的是彙總和分析研究，説明了容器、unikernel 等的趨勢是如何重塑雲計算的。該報告提供了對當今開放雲環境中心的分類項目的描述和鏈接。

在本系列中，我們會研究各種類別，並提供關於這些領域如何發展的更多見解。下面，你會看到幾個重要的 SDN 項目及其所帶來的影響，以及 GitHub 倉庫的鏈接，這些都是從“開放雲指南”中收集的：

軟件定義網絡 ​

ONOS ​

開放網絡操作系統Open Network Operating System（ONOS）是一個 Linux 基金會項目，它是一個面向服務提供商的軟件定義網絡操作系統，它具有可擴展性、高可用性、高性能和抽象功能來創建應用程序和服務。

ONOS 的 GitHub 地址。

OpenContrail ​

OpenContrail 是 Juniper Networks 的雲開源網絡虛擬化平台。它提供網絡虛擬化的所有必要組件：SDN 控制器、虛擬路由器、分析引擎和已發佈的上層 API。其 REST API 配置並收集來自系統的操作和分析數據。

OpenContrail 的 GitHub 地址。

OpenDaylight ​

OpenDaylight 是 Linux 基金會旗下的 OpenDaylight 基金會項目，它是一個可編程的、提供給服務提供商和企業的軟件定義網絡平台。它基於微服務架構，可以在多供應商環境中的一系列硬件上實現網絡服務。

OpenDaylight 的 GitHub 地址。

Open vSwitch ​

Open vSwitch 是一個 Linux 基金會項目，是具有生產級品質的多層虛擬交換機。它通過程序化擴展設計用於大規模網絡自動化，同時還支持標準管理接口和協議，包括 NetFlow、sFlow、IPFIX、RSPAN、CLI、LACP 和 802.1ag。它支持類似 VMware 的分佈式 vNetwork 或者 Cisco Nexus 1000V 那樣跨越多個物理服務器分發。

OVS 在 GitHub 的地址。

OPNFV ​

網絡功能虛擬化開放平台Open Platform for Network Functions Virtualization（OPNFV）是 Linux 基金會項目，它用於企業和服務提供商網絡的 NFV 平台。它彙集了計算、存儲和網絡虛擬化方面的上游組件以創建 NFV 程序的端到端平台。

OPNFV 在 Bitergia 上的地址。

要了解更多關於開源雲計算趨勢和查看頂級開源雲計算項目完整列表，請下載 Linux 基金會的 “開放雲指南”。
