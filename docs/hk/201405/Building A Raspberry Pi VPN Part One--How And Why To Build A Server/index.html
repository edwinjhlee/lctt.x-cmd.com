在樹莓派上建立VPN（一）：如何以及為何建立一個VPN服務器？ ​

不要相信任何人，自己建立一個VPN服務器來加密Web數據從而躲過他人的窺視

雖然免費、未加密的無線AP遍地都是，但是你不應該連接這些AP來登陸你的網銀賬户，除非你對他人的窺視毫不在意。那麼對此的解決方案是什麼呢？一個虛擬專用網，也就是VPN(virtual private network)。

一個VPN可以使你的私有網絡拓展至公共場所，因此即使你連接着星巴克的 Wi-Fi，你的網絡瀏覽仍然保持着安全的加密。

有很多方法來建立VPN，包括免費以及付費的服務，但是每個解決方案都有其的優點以及缺點，這取決於VPN服務商運作的方式和服務商提供的VPN選項。

最簡單及最方便的保證數據安全的方法就是完全拋棄公共Wi-Fi。但是這個解決方案對於我來説有點極端了，一部分原因是在家裏建立一個VPN服務器相對容易以及划算，你只需要一個便宜的($35)小型的樹莓派。

我的樹莓派與智能手機差不多大小，並且它擁有一個VPN服務器所有應有的功能。這意味着不管我在哪裏，我可以通過安全的網絡來連接在家裏的電腦和家裏的內網來訪問共享的文件以及媒體。這個服務器在我最近去波士頓的旅途中使生活變得十分美好，在旅途中我仍然可以觀看儲存在家裏台式機上的視頻。

在這部分文章中，説實話我希望直接帶給你們一個設置樹莓派VPN的教程。問題是這個優秀教程並不存在，至少目前沒有一個適合大部分電腦用户的優秀教程。雖然有無數關於如何搭建樹莓派VPN的教程，但極少的教程會解釋這麼做的目的。

我閲讀了不少教程，並把好的部分整合入了這半篇教程中，來教授讀者如何搭建樹莓派VPN服務器。這個教程甚至連我都能理解，並完成如何搭建和為何搭建的學習。最重要的是，我認為Eric Jodoin的VPN教程更適合那些專家，但它使我的大腦直接宕機了...

那麼跟隨我鑽進加密法的兔子洞並且開始學習吧，無論你有多麼多疑，提出了創造VPNs的那個人更正是如此。

材料 ​

硬件 ​

Raspberry Pi Model B：以及使其工作所需要的所有硬件－一個常規電源供電器和一個放置的小盒子。小盒子可以避免樹莓派硬件意外短路而損壞－這個盒子甚至可以是一個自己摺疊的紙板箱。

SD card：我建議8GB及以上的容量，只是來保證你有必要的儲存空間。像所有樹莓派項目一樣，SD卡上應該要預裝上NOOBS。

五類網線：這根網線將連接樹莓派的以太網接口和你的路由器的以太網接口。

軟件 ​

Open VPN：這是一個開源VPN服務軟件，我們今天就要安裝它。

開始項目之前的準備 ​

  1. 你需要準備好NOOBS並且安裝完Raspbian。我在＂魚缸管理＂項目中對此做過一個一步步的教程。因此你也可以在那裏查看。

  2. 你需要為樹莓派設置一個在你家內網中的靜態IP地址。這一步驟取決於你路由器的型號，因此你可能需要閲讀你的路由器的説明書來完成這一步。如果你還沒有完成這一步，你可以參照ReadWrite的教程。

  3. 你需要啓用SSH。我們需要通過SSH與樹莓派進行連接，這是一個使我們能夠從另一台電腦連接樹莓派的工具。通過這種方法，我們在這個項目中不需要再為樹莓派單獨設置一個顯示屏以及無線鍵盤。再提一下，看看ReadWrite的教程。

  4. 你需要將路由器的1194端口映射至樹莓派的內網IP地址採用UDP協議，完成這一步的方法也決定於你路由器的型號，所以閲讀路由器説明書吧。如果你想用另一個端口或TCP協議，沒問題，只要將此教程中提及"UDP"的地方換為"TCP"，1194端口改為你需要的端口就行了。想必你也猜到了，ReadWrite為此也寫了一篇教程。

你可以從上文看出，我們現在在建立一些樹莓派的基礎概念，這也是為什麼在樹莓派上搭建VPN對初學者的第一個項目來説並不是適合。

簡單的一些警告 ​

我曾經喜歡直接拷貝網上教程中的代碼，但是當我自己測試這篇教程時，我發現直接的複製粘貼代碼會導致一些錯誤，原因是複製粘貼中出現的空行以及格式變化。如果你發現在此篇教程在實際操作時出現了一些問題，我的建議是先手動輸入代碼試試!

First Steps ​

  1. 啓動並修改樹莓派的密碼。如果你還在使用樹莓派的默認用户名(pi)和密碼(respberry)，那麼接下來的安全教程就完全沒有什麼意義了。

打開一個terminal/PuTTY 窗口輸入：

sudo passwd

將用户名以及密碼修改地既好記並難猜(微軟對此有一些建議)，不然的話為什麼要自找麻煩搭建一個私人網絡呢？

  1. 為了樹莓派的安全來進行軟件包的升級。輸入如下兩條命令：

    sudo apt-get update sudo apt-get upgrade

這應該不會花太多時間，而且為我們排除了之後可能會產生的問題。

  1. 接下來我們需要這個開源軟件(OpenVPN)了。輸入：

    sudo apt-get install openvpn

樹莓派會詢問確認，因為這用掉一點點儲存空間。但是由於我們已經準備了一張8GB及以上的SD卡，我們對此完全沒問題。

生成密鑰 ​

  1. 你當然不想讓任何發現你的VPN的人就可以連接，因此我們會為這個安全的地址準備一個來驗證身份的密鑰。這就像為你的家門準備一把鎖一樣。

OpenVPN自帶了Easy_RSA，一個輕量並容易的使用RSA加密方法的包。發明於1977年，RSA是第一個沿用至今仍舊可用的加密系統。加密的密鑰是公開的，解密的密鑰是保密的。如果你聽説過比特幣的工作原理，這些對你來説應該十分熟悉。

通過使用Easy_RSA，你可以使用軟件帶有的算法來生成一個獨一無二的密鑰。

首先獲得樹莓派的系統權限，就是將命令提示符中的"pi@raspberrypi"轉換成"root@raspberrypi"。

sudo -s

這句命令在現有的終端中再次創建了一個擁有root權限的終端實例。我們需要獲得root權限的原因是，如果我們沒有root權限，樹莓派將不會允許我們創建密鑰。

接下來，輸入：

cp -r /usr/share/doc/openvpn/examples/easy-rsa/2.0  /etc/openvpn/easy-rsa

在這句命令中，"cp"代表＂複製＂，"r"代表遞歸。這説明我們讓電腦執行：複製這個目錄以及此目錄下的所有文件結構及文件。

在/2.0和/etc中間的空格表示我們將第一個目錄地址的文件（一個實例文件）拷貝至第二個目錄地址，就是你讓OpenVPN尋找密鑰的地址。

cd /etc/openvpn/easy-rsa

  1. 接下來，我們需要"cd"，改變所在目錄(change directory)，來放置我們生成的Easy_RSA文件。一旦完成這步，我們需要打開文件/etc/openvpn/easy-rsa/vars來編輯。我們可以使用nano: nano /etc/openvpn/easy-rsa/vars，由於我們已經在此目錄下了，我們可以使用簡寫：

    nano vars

Nano是Raspbian中內置的文件編輯工具，當然也有其他工具提供給屌絲們，不過我們將在此教程中只使用nano。

現在，將你的 EASY_RSA 變量改為：

export EASY_RSA="/etc/openvpn/easy-rsa"

對我的環境來説，這是在第13行。

為什麼要修改這個變量呢？其實這是你在回答計算機的問題＂你想讓文件生成在哪裏？＂。在這個情況下，我們想要將其生成在我們保存key的同一個目錄，在這裏是easy-rsa文件樹的頂層。

在vars文件中我們還可以做一件事，如果你對黑衣眾們閲讀你的郵箱這件事十分在意的話，你可以將加密方法從1024-bit改至2048-bit。在vars文件中，它明顯的指出，＂偏執狂請將此改為2048！＂。

但是因為這個方法大大增長了生成密鑰的時間，我們不會在這個教程中使用它。保持下面這個樣子：

export KEY_SIZE=1024

按下Control+X來保存修改並退出nano。

加密 ​

  1. 現在該搭建CA證書和Root CA證書了。

在加密學中，一個授權機構(certificate authority (CA))是一個頒佈電子證書的存在。電子證書來證明公鑰的所有者。

你可能一直在使用它只是你自己不知道而已。舉個例子，當我登陸我的網銀賬户時，我可以在網頁地址前看到HTTPS字符。當我點擊HTTPS前的鎖時，我會看到一個叫做GeoTrust的公司驗證了我網銀頁面的合法性，因此我知道這不是一個釣魚欺詐網站。(當然最近的Heartbleed漏洞指出HTTPS並不是我們想得那麼安全)。

在樹莓派這個例子中，我作為我自己的授權機構，自己為OpenVPN簽字，而不是通過一個第三方公司。

cd /etc/openvon/easy-rsa

現在我們又改變了所在目錄，將下面命令一行接一行輸入終端：

source ./vars →　這個"source"加載你之前修改的文件(vars)。

./clean-all → 這會刪除之前所有的密鑰文件，如果有的話。如果在這個文件目錄下有你不想刪除的密鑰文件(比如這是你第二次嘗試這篇教程)，跳過這條命令。

./build-ca → 最後一條來生成你的授權機構。

再輸入第三條命令之後，樹莓派會彈出一堆選項，你可以填寫這些選項如果你願意的話－－國家名字，州名或省名，位置名，機構名，機構單位和電子郵件地址。如果你不想填寫，只要在每個選項出現時按"enter"就行了，樹莓派會使用默認值。下面的截屏展現了這些選項的長相：

現在你可以為你的服務器命名了。我很“創新”地將其命名為"Server"。你可以取任意的名字，不過別忘記輸入：

./build-key-server [Server_Name]

再次，樹莓派會給出一系列的選項，請隨便輸入，但注意以下幾個選項：

**Commom Name ** 必須是你為服務器取的名字。

A challenge password? 必須啥也不輸，回車即可。

Sign the certificate? [y/n] 廢話，你必須輸入"y"。

你接下來會看到一段消息説你的證書會在接下來的3650天中有效的信息。因此，如果你打算長期使用這個VPN的話，你必須在十年後重新走這個流程。

1 out of 1 certificate requests certified, commit? [y/n] 明顯，輸入"y"。

  1. 服務器端就這麼設置好了。現在該為各位用户生成密鑰了，或者説"客户"。我為家裏的計算機，平板，手機各生成了一個密鑰，總共有5個。不要以為在所有客户端使用同樣的密鑰就可以節省時間，這樣的話，一次只能有一個設備能訪問VPN。

    ./build-key-pass UserName

我發現採用用户名 Client1, Client2, Client3...十分方便

在這之後，更多信息會彈出!

Enter PEM pass phrase 設置其為你記得住的密碼！他會讓你輸入兩次，不會有幾率輸入錯誤。

A challenge password? 必須留空！

Sign the certificate? [y/n] 同樣籤十年。

cd keys
openssl rsa -in Client1.key -des3 -out Client1.3des.key

留意我們使用des3加密生成的字符串文件，des3是一個複雜加密算法會在每一個數據塊上運行3次，來防止駭客的暴力破解。OpenSSL 代表開源的加密套接字實現，是一個建立安全連接的標準方法。你需要為你生成的每一個客户端運行這一步。

有人會説這一步完全沒有必要，你可以跳過這一步。但是如果你通過Android或者iOS設備連接OpenVPN，那麼你必須要做這一步，不然的話目前版本在解析你的密鑰時會有一些困難產生。

Enter pass phrase for Client1.key

説實話，我用了和以前一樣的密碼。再輸入一遍，就想説的那樣。

現在我們已經創建了服務器證書以及至少一個客户端證書，輸入以下命令：

cd /etc/openvpn/easy-rsa/

或者

cd ..

兩種方法都會將你的所在目錄帶會/easy-rsa/。

  1. 現在該生成Diffie-Hellman key exange了。這是使你的VPN工作的關鍵代碼，一個使兩個沒有先前信息的雙方通過服務器交換密鑰的協議。像RSA一樣，這是現有的最早發明的加密系統。

    ./build-dh

這一步會花一些時間，甚至比2048-bit加密還要慢。而且沒有任何方法可以預測它運行的時間，因為這個算法使用的是隨機數並尋找一些特定的關係。事實上，在我寫這篇教程時，1024-bit加密只花了我5分鐘。

  1. 最後，我們要實現OpenVPN內建的服務阻斷攻擊(Denial of Service -- DoS)防護。你可能已經知道服務阻斷攻擊是駭客找到你的服務器地址後很有效的攻擊手段，這種攻擊通過生成大量的訪問請求來使你的服務器崩潰。

輸入以下代碼來生成靜態的HMAC(hash-based message authentication code)密鑰：

openvpn --genkey --secret keys/ta.key

最後收尾 ​

  1. 我們已經生成了密鑰以及來簽名的授權機構。剩下的只是如何告訴OpenVPN如何配置這個服務器了。

因為我們在樹莓派上使用在沒有圖形用户界面的Linux操作系統，我們需要生成一個.conf (configuration) 文件來告訴OpenVPN如何配置服務器，而不是通過圖形界面的選擇。用nano打開.conf文件：

nano /etc/openvpn/server.conf

我們在這個目錄下打開.conf文件的理由是，編輯完此文件會直接生成在/etc/openvpn的目錄中。但是你剛剛打開的這個文件是空的。將此地址中的配置複製入編輯器。在配置中我用大寫字符註釋了你必須要更改的地方，具體可以看註釋。按下 Control+X 來保存文件。

  1. 讓我們快速地編輯一下另一個配置文件。在默認配置下樹莓派並不會轉發網絡流量，我們需要另一個配置文件來使樹莓派啓用對我們新建網絡中的網絡流量的轉發。

    nano /etc/sysctl.conf

在文檔開頭處有註釋：＂取消下一行的註釋來啓用IPv4中的數據包轉發。＂("Uncomment the next line to enable packet forwarding for IPv4。")。我在下面的截圖中高亮了這部分。

刪除那一行前面的 # 來取消註釋這一行。這告訴樹莓派要對IPv4的數據包進行映射。當你取消註釋了這一行，樹莓派就擁有了作為互聯網的中繼而不是單單的接受者的權限，可以既接受併發送數據包。

按下 Control+X 來保存修改。通過以下命令啓用此配置：

sysctl -p

sysctl命令表示＂在運行中改變內核配置參數＂。-p 告訴計算機重新加載你剛剛修改的配置文件。

  1. 到這一步我們以及配置完了一個擁有互聯網訪問權限的工作中的服務器。但是我們還不能用它，用為樹莓派有內置的防火牆來限制傳輸入的網絡連接。

Raspbian的防火牆會在來路不明的互聯網源頭中保護你的樹莓派。我們仍然需要防火牆來保護我們，但是我們要在防火牆中挖一個OpenVPN樣子的洞，使OpenVPN的連接可以順利通過。

此外，Raspbian的防火牆會在重啓後默認進行重置。我們需要創建一個簡單的腳本使樹莓派記住每次重啓時對OpenVPN的連接進行允許。

nano /etc/firewall-openvpn-rules.sh

這是一個空文件，輸入以下內容：

#!/bin/sh

iptables -t nat -A POSTROUTING -s 10.8.0.0/24 -o eth0 -j SNAT --to-source 192.168.XX.X

不要忘記將默認IP地址改為你樹莓派的IP地址!

解釋下這條命令: 10.8.0.0 是客户端連接樹莓派VPN後樹莓派的默認地址。 "eth0"代表以太網接口。 如果你使樹莓派用無線連接互聯網的話將其改為"wlan0"， 當然我不建議你這麼做。 按下 Control+X 保存編輯。

為了安全考慮, 我們要改變/etc/firewall-openvpn-rules.sh的所有者，使此文件默認不可被運行。 首先將權限設定為700 (所有者可以讀、寫、執行)。 然後，我們會將此腳本的所有者改為root,，在Linux標準系統中，root代表系統管理員。

chmod 700 /etc/firewall-OpenVPN-rules.sh
chown root /etc/firewall-OpenVPN-ruels.sh

  1. 我們已經創建了一個在防火牆中開出OpenVPN形狀的洞，我們現在只需要將這個腳本插入到網絡interface初始化的代碼中，然後它就會在每次開機時運行了。

    nano /etc/network/interfaces

找到帶有"iface eth0 inet dchp"的那一行。 我們需要在這行之後的縮進中加上一行。 下面是這兩行，一行新加入，一行原來就存在，在完成之後它應該差不多像這樣：

iface eth0 inet dhcp
	pre-up /etc/firewall-openvpn-rules.sh

按下 Control+X 保存更改 (當你在使用nano的時候都應該這麼做)。

最後，再最後, 再最最後：重啓樹莓派。

sudo reboot

恭喜你！！vpn服務器就這麼搭建完成了，當然如果沒有客户端連接服務器的話，服務器也沒什麼用，因此你應該牢記你在第6步創建生成的用户名及密鑰。 接下來你可以繼續閲讀這篇教程的第二部分來學習如何創建加密的客户端。
