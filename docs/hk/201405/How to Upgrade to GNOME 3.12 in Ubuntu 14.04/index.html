Ubuntu 14.04下升級GNOME至3.12 ​

如果您的系統最近已升級至Ubuntu GNOME 14.04 LTS版本，那麼擁有穩定獨立的GNOME Shell無疑是您最佳的選擇

但我認為比較保守的用户會傾向於選擇默認向新手提供的穩定版本。你真想要了解如何在Ubuntu14.04升級GNOME至3.12嗎？

好的，接下來我將向你介紹如何完成。首先，我們需要先了解下來龍去脈。

默認採用GNOME 3.10的原因 ​

GNOME 3.12在3月底發佈後引發了一陣轟動而天馬行空的評論。儘管其上個月發佈的版本在Ubuntu 14.04 LTS版本之前已經逐步趨於穩定，卻仍不能從14.04包中直接安裝，這是為什麼呢?

簡單來説在開發週期中它出現太晚以至於沒有充足的時間來對它進行審查、測試並確保它已經更新至LTS命令發佈支持的標準及用户期望。默認至舊版發佈的3.10是有意義的，因為有專門的計劃來確保測試完整。

所以，正因為這樣不建議升級GNOME至3.12。

這樣清楚了嗎？接下來，讓我們進入下一個階段。

如何在Ubuntu 14.04升級GNOME至3.12### ​

確保你正在運行的GNOME版本是3.10 ​

為確保正確遵循本嚮導，需要在最新版本的Ubuntu(14.04 LTS)或Ubuntu GNOME下繼續操作。如果不是最新版本的話，請停止操作；你需要升級後再繼續。如果不這樣做，接下來將會有一系列複雜又麻煩的事情需要解決。

若你運行的是Ubuntu常規版本（例如帶有Unity），那麼需要在開始以下步驟前從Ubuntu軟件中心安裝GNOME 3.10。

按以下給出的鏈接選項準備好安裝程序。

  • [Ubuntu14.04LTS版本下安裝GNOME3.10]

增加GNOME 3.12 PPA ​

起初人們預想的是GNOME 3.12將會由標準GNOME Team PPA隨着 14.04 LTS 發佈。但3個星期過去了，卻什麼都沒有。這是因為一些小的3.10軟件包仍然沒有跟着發佈最新的3.12的包。

然而，GNOME Team Staging PPA確實涵蓋了升級用到的各種3.12版本包。開發者強調説，增加這個存檔會讓桌面系統‘運行流暢’，但現在包含的包並未‘準備好為大眾所使用’。

這兒假設您是一個PPA清理工具的行家，以上的一切都已明瞭，請繼續向下。首先，讓我們核對並安裝已發佈的更新：

sudo apt-get update && sudo apt-get dist-upgrade

按下回車鍵後等待安裝包程序。

一旦完成此過程或再沒有任何掛起的更新，就可以增加 GNOME Team Staging PPA了。為實現這項操作，打開新的命令列窗口輸入以下命令：

sudo add-apt-repository ppa:gnome3-team/gnome3-staging

sudo apt-get update && sudo apt-get dist-upgrade

升級過程開始前需要輸入密碼，同時需要注意此過程中命令列提示的信息。如果一切順利點擊‘y’鍵確認安裝。

附加內容 ​

為體驗真實的GNOME環境也許你想獲取一些新的GNOME應用，例如Polari IRC客户端、GNOME地圖和GNOME網頁瀏覽器。安裝這三個應用需要運行如下的命令：

sudo apt-get install epiphany-browser gnome-maps polari -y

在這些都安裝完成之後，你就可以安全的重啓了！

善後服務 ​

登錄 ​

如果你之前使用Unity,Xfce或別的桌面環境，不要忘記登錄前從登錄界面選擇GNOME會話。

回顧 ​

對我自己來説，Ubuntu 14.04下運行GNOME 3.12很流暢。升級後沒有出現任何諸如性能下降的問題，儘管我確實見到過在打開活動窗口時的奇怪罕見的顯示故障，並且在一個應用下發生的間歇性陰影消失現象。但隨着錯誤不斷消除這些都不是大問題。

3.12版本的性能等同於GNOME3.10；應用的打開方式交互性強且體驗並沒有明顯下降。

所有新的GNOME影音應用在PPA上並沒有現成的包，這讓人有點失望。當然有理由解釋這點(很可能需要新版本的視頻解碼器)。此外仍要注意的是一些GNOME擴展包在升級後不能繼續工作。

當然3.12因為測試不足，其中存在錯誤不可避免。若用户要求穩定性（或者希望保持系統工作時的高度統一和完整），可以繼續支持已通過測試的GNOME 3.10版本。

從GNOME 3.12 降至3.10版本 ​

但是如果想要體驗閃閃亮的新功能及最新發布的GNOME應用，那就試一試PPA平台吧。如果遇到了錯誤可以隨時使用PPA清理工具來降級至穩定版本。

sudo apt-get install ppa-purge

sudo ppa-purge ppa:gnome3-team/gnome3-staging
