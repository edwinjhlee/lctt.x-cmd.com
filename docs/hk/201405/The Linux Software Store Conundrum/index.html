Linux軟件商店的困境 ​

在調查了各種方案後，我認為Linux需要一個更好的在線軟件零售商店。

有好幾次，我懇求Ubuntu團隊考慮改善現在的Ubuntu軟件中心。它在舊電腦上幾乎就不能用，而就算在主流硬件平台，它採用的軟件安裝方式還有很大改善空間，尤其是付費軟件。

我希望這篇文章不僅能讓我們認真瞭解一下目前存在的搜索和安裝Linux軟件的方式，也許還可以最終找到一種處理付費軟件的方法。

Linspire曾經很接近 ​

不管你喜歡不喜歡被Xandros收購之前的Linspire公司，實際上，它早期時候建立的點擊運行軟件店(CNR)在當時已經超前了許多年。在CNR變成一個嘗試在所有發行版上處理所有事情的萬能工具之前，Linspire還是提供了我認為對新手最友好的Linux平台軟件安裝方式。甚至以現在的標準來衡量，在統一環境下輕鬆地安裝開源軟件(FoSS)和商業應用這一點上，"經典的"CNR仍值得一提。

把Steam當作軟件商店 ​

儘管在Linux桌面環境有很多"其他"可用的軟件商店，但實際上沒有哪個像Ubuntu軟件中心那樣支持付費應用。而我看到的唯一一個像Ubuntu軟件中心那樣可以在Linux桌面下發布付費應用的是Valve公司的Steam數字軟件管理器，作為發行付費Linux遊戲的商店而聞名。我發現Steam已經用來在其他平台發行軟件，所以我認為，Steam也完全可以為Linxu用户發行付費軟件。

不像其他軟件發佈工具，Steam專門設計了比其他Linux替代方案更為清晰的付費處理方式。而且，Steam用一種炫目的方式來展示遊戲和軟件的名字，所以，用户在瀏覽這些名字的時候能夠選中適合自己需求的應用。

我並沒有建議把Steam當作搜索開源軟件的最佳替代方案，我堅決反對這種想法。我的建議是，Steam可以成為一個專門處理擁有專利的應用或遊戲軟件的跨發行版的選擇。

誕生一個新生態系統 ​

現在，你也許認為我是一個堅決反對類似Ubuntu軟件中心這樣的軟件發佈工具。但事實是，我只是非常希望看到它被改善，並在儘可能多地開源軟件上獲得成功。再重申一下，儘管我覺得它還需要花點工夫，它還是一個不錯的搜索軟件的工具。但是就像我之前説過，總的來説，軟件中心的付費系統沒有提供良好的用户體驗。它響應很慢，實際上也沒有提供一個有效的工具來檢查付費軟件的新版本。

在這個舞台上，我認為Steam是毫無疑問的優勝者。而且如果我們能夠讓Steam更多地努力去推出人們實際上希望使用的付費軟件－而不僅只限於列出目前Linux系統已有的有限選擇－這將會帶來幾乎無限的需求。

想像一下這樣一個新的生態系統，付費軟件可以通過他們自己的發佈工具輕鬆的發佈而不用考慮具體的Linux發行版的依賴。Ubuntu，Arch，OpenSUSE，不管哪個發行版，我認為Steam是一個往Linux世界推出還未被移植軟件的工具。在新軟件被髮布和應用後，更多的會跟上。也許我們甚至會看到大牌露臉？比如Adobe Photoshop和Microsoft Office－如果有願意付費的用户，我想不到任何任何理由為什麼它們不會參與進來。

困難和挑戰 ​

在Steam能夠統一Linux世界軟件發佈之前還存在一些重要的挑戰。第一個挑戰來自Linux用户自身：我們保持懷疑和保留態度，而且一直在擔心，會不會是下一波"收費威脅"的到來。儘管Valve在通過Steam把遊戲發行到不同的Linux發行版上時受到了熱烈的歡迎，如果在各種軟件都積極地推銷過來時，我想這種"歡迎"會冷卻一點。

另一個閃過我腦海的擔心是，Valve是否會接受大量的"垃圾"應用，類似那些你可以在手機應用軟件世界看到的。沒有比在Steam商店裏看到無數的垃圾應用反而優秀應用很難找到這種事情更糟糕的了。我希望我們可以在付費軟件的數量和質量種尋找一個平衡。

沒有Steam－沒有問題? ​

我不是那種過於重視任意問題的單一解決方案的人，所以我承認，Steam本身也許並不是為Linux民眾發佈付費軟件的唯一方式。但是，我的問題就會變成：如果沒有Steam－還有其他方案嗎？我們已經看到類似Ubuntu的發行版正在嘗試提供付費軟件，但是很明顯，結果並沒有那麼好。

我也確實支持Ubuntu，他們所做的努力為軟件中心帶來了許多應用，多謝他們的應用開發者活動周。軟件中心是個很好的想法，對於那些休閒應用，每次看看發佈了哪些新應用也挺好玩的。但是，很可惜，它沒有吸引到Adobe和Microsoft來提供那些高需求軟件的非微軟和蘋果平台的版本。

最後，是否存在切實可行的替代方案讓付費軟件進入Linux世界呢？在企業領域，確實已經有了。

企業應用 ​

就我的個人經驗來説，我真的不認為付費軟件能夠在Linux桌面上站穩腳跟，但是我卻看到付費軟件在未來Linux服務器上的廣闊前景。像大多數Linux事物，是在服務器端賺的錢，靠的是提供服務和企業級產品。

所以就算Steam能夠整合成為一個付費應用的發佈平台，恐怕它也不能在企業領域獲得太多關注。另一方面，也許我們將來會重新再回到這裏，而Steam確實已經成為消費者發佈付費Linux軟件的地方，而不僅僅是優秀遊戲。
