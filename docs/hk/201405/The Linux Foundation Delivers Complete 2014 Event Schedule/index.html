Linux基金會發布了2014年全部活動安排 ​

Linux基金會改變了原有的活動計劃模式，提前公佈了一整年的所有活動安排。與此同時還發布了一部視頻，可以在這裏在線觀看：Linux基金會活動體驗。下面介紹一下今年的基金會活動重點關注方向的更多細節。

2014年活動安排，包括了北美和歐洲的LinuxCon和CloudOpen，以及Linux Foundation Collaboration Summit，Embedded Linux Conference，Android Builders Summit，和ApacheCon等等。今年北美的LinuxCon和CloudOpen會在芝加哥和Linux Kernel Summit一起合作舉行。歐洲的Linux Con和CloudOpen會在德國的杜塞爾多夫舉行，一起的還有Embedded Linux Conference, KVM Forum以及Linux Plumbers Conference。

“幾乎每一個技術部門或社區都渴望能在開放、協作式的開發過程中有所收穫。”Linux基金會的行政長官Jimm Zemlin在一份聲明中這樣説過，“如今，從類似汽車到生命科學再到賭博等各種行業都傾向於依靠共同的知識庫和Linux的成功以及開放式開發。”

下面是2014年Linux基金會活動安排中的亮點，包括一些有趣的雲計算活動：

OpenDaylight Summit ​

2014年2月4日－5日，凱悦酒店，加利福尼亞州聖克拉拉市。

為Software-Defined Networking (SDN)和Network Functions Virtualization (NFV)領域的社團，項目，產品，公司的開發人員和用户舉辦的一次技術峯會。

Linux Storage, Filesystem and MM Summit ​

2014年3月24日－25日，Meritage度假村，加利福尼亞州納帕谷。

僅限受邀人士的活動，會聚集Linux存儲，內存管理和文件系統棧方面工作的開發者和研究員。

Linux Foundation Collaboration Summit ​

2014年3月26日－28日，Meritage度假村，加利福尼亞州納帕谷。

僅限受邀人士的獨家峯會，會邀請包括關鍵內核開發人員，發行版維護人員，獨立軟件開發商，終端用户，系統供應商，以及其他社區組織參與聚會以及工作組會議，幫助解決如今Linux面臨的最緊急的問題。

ApacheCon ​

2014年4月7日－9日，威斯汀酒店，科羅拉多州丹佛市。

ApacheCon是唯一這樣做的活動，它專注於把100+ Apache Software Foundation項目社區以及其他各個組織的開源項目聚集到一個地方，來推動那些正在構建技術未來和代表了下一代軟件開發的工作。它主導了與許多當前最熱門的開源項目的合作，包括Apache自己的項目 比如Cassandra, Cordova, CloudStack, CouchDB, Geronimo, Hadoop, Hive, HTTP Server, Lucene, OpenOffice, Struts, Subversion and Tomcat，以及其他項目。

CloudStack Collaboration Conference North America ​

2014年4月9日－11日，威斯汀酒店，科羅拉多州丹佛市。

CloudStack Collaboration Conference North America聚集了建立和管理大型虛擬機網絡以及推進頂尖雲計算技術方面的開發人員，系統管理員以及運維專家。它為參與者們提供一個可以利用Apache CloudStack來推動他們工作的中性環境。

Embedded Linux Conference ​

2014年4月29日－5月1日，萬豪酒店，加利福尼亞州聖何塞市。

今年是該活動的10週年，對於在嵌入式產品中使用Linux的公司和開發者來説，它是最重要的廠商中立的技術會議。

Android Builders Summit ​

2014年4月29日－5月1日，萬豪酒店，加利福尼亞州聖何塞市。

為OEM廠商，設備製造商，系統集成商，系統定製者，以及正在成長的Android和Linux內核開發社區組織的技術峯會，

LinuxCon North America ​

2014年8月20日－22日，喜來登酒店，芝加哥市。

LinuxCon是北美地區最重要的年度技術會議，聚集了開發者，系統管理員，運維專家，業務負責人，以及更多專業人士，探討Linux社區的協作和教育機會。

CloudOpen North America ​

2014年8月20日－22日，喜來登酒店，芝加哥市。

CloudOpen聚集了驅動雲服務以及大數據生態環境的開源項目，產品以及公司，在一起分享傳統開源世界的成功案例。

LinuxCon Europe ​

2014年10月13日－15日，杜塞爾多夫會議中心，德國杜賽爾多夫。

歐洲LinuxCon聚集了歐洲的Linux社區，從開發者，系統管理員以及運維專家，到業務負責人，以及更多專業人士，探討Linux社區的協作和教育機會。之前的會議地點包括布拉格和巴塞羅那。

CloudOpen Europe ​

2014年10月13日－15日，杜塞爾多夫會議中心，德國杜賽爾多夫。

歐洲CloudOpen聚集了驅動雲服務以及大數據生態環境的開源項目，產品以及公司，在一起分享傳統開源世界的成功案例。

Embedded Linux Conference Europe ​

2014年10月13日－15日，杜塞爾多夫會議中心，德國杜賽爾多夫。

今年是該活動的10週年，對於在嵌入式產品中使用Linux的公司和開發者來説，它是最重要的廠商中立的技術會議。

想了解關於Linux基金會活動的更多信息，請訪問：http://events.linuxfoundation.org。
