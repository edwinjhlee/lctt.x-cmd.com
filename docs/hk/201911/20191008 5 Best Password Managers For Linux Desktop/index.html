5 個 Linux 桌面上的最佳密碼管理器 ​

密碼管理器是創建唯一密碼並安全存儲它們的有用工具，這樣你無需記住密碼。瞭解一下適用於 Linux 桌面的最佳密碼管理器。

密碼無處不在。網站、論壇、Web 應用等，你需要為其創建帳户和密碼。麻煩在於密碼，為各個帳户使用相同的密碼會帶來安全風險，因為如果其中一個網站遭到入侵，黑客也會在其他網站上嘗試相同的電子郵件密碼組合。

但是，為所有新帳户設置獨有的密碼意味着你必須記住所有密碼，這對普通人而言不太可能。這就是密碼管理器可以提供幫助的地方。

密碼管理應用會為你建議/創建強密碼，並將其存儲在加密的資料庫中。你只需要記住密碼管理器的主密碼即可。

主流的現代瀏覽器（例如 Mozilla Firefox 和 Google Chrome）內置了密碼管理器。這有幫助，但是你只能在瀏覽器上使用它。

有一些第三方專門的密碼管理器，其中一些還提供 Linux 的原生桌面應用。在本文中，我們將篩選出可用於 Linux 的最佳密碼管理器。

繼續之前，我還建議你仔細閲讀 Linux 的免費密碼生成器，來為你生成強大的唯一密碼。

Linux 密碼管理器 ​

可能的非 FOSS 警報！

我們優先考慮開源軟件（有一些專有軟件，請不要討厭我！），並提供適用於 Linux 的獨立桌面應用（GUI）。專有軟件已高亮顯示。

1、Bitwarden ​

主要亮點：

  • 開源
  • 免費供個人使用（可選付費升級）
  • 雲服務器的端到端加密
  • 跨平台
  • 有瀏覽器擴展
  • 命令列工具

Bitwarden 是 Linux 上最令人印象深刻的密碼管理器之一。老實説，直到現在我才知道它。我已經從 LastPass 切換到了它。我能夠輕鬆地從 LastPass 導入數據，而沒有任何問題和困難。

付費版本的價格僅為每年 10 美元。這似乎是值得的（我已經為個人使用進行了升級）。

它是一個開源解決方案，因此沒有任何可疑之處。你甚至可以將其託管在自己的服務器上，併為你的組織創建密碼解決方案。

除此之外，你還將獲得所有必需的功能，例如用於登錄的兩步驗證、導入/導出憑據、指紋短語（唯一鍵）、密碼生成器等等。

你可以免費將帳户升級為組織帳户，以便最多與 2 個用户共享你的信息。但是，如果你想要額外的加密存儲以及與 5 個用户共享密碼的功能，那麼付費升級的費用低至每月 1 美元。我認為絕對值得一試！

  • Bitwarden

2、Buttercup ​

主要亮點：

  • 開源
  • 免費，沒有付費方式。
  • 跨平台
  • 有瀏覽器擴展

這是 Linux 中的另一個開源密碼管理器。Buttercup 可能不是一個非常流行的解決方案。但是，如果你在尋找一種更簡單的保存憑據的方法，那麼這將是一個不錯的開始。

與其他軟件不同，你不必對懷疑其雲服務器的安全，因為它只支持離線使用並支持連接 Dropbox、[OwnCloud] 8、Nextcloud 和 WebDAV 等雲服務。

因此，如果需要同步數據，那麼可以選擇雲服務。你有不同選擇。

  • Buttercup

3、KeePassXC ​

主要亮點：

  • 開源
  • 簡單的密碼管理器
  • 跨平台
  • 沒有移動設備支持

KeePassXC 是 KeePassX 的社區分支，它最初是 Windows 上 KeePass 的 Linux 移植版本。

除非你沒意識到，KeePassX 已經多年沒有維護。因此，如果你在尋找簡單易用的密碼管理器，那麼 KeePassXC 是一個不錯的選擇。KeePassXC 可能不是最漂亮或最好的密碼管理器，但它確實可以做到該做的事。

它也是安全和開源的。我認為這值得一試，你説呢？

  • KeePassXC

4、Enpass （非開源） ​

主要亮點：

  • 專有軟件
  • 有許多功能，包括對“可穿戴”設備支持。
  • Linux 完全免費（具有付費支持）

Enpass 是非常流行的跨平台密碼管理器。即使它不是開源解決方案，但還是有很多人依賴它。因此，至少可以肯定它是可行的。

它提供了很多功能，如果你有可穿戴設備，它也可以支持它，這點很少見。

很高興能看到 Enpass 積極管理 Linux 發行版的軟件包。另外，請注意，它僅適用於 64 位系統。你可以在它的網站上找到[官方的安裝説明] 17。它需要使用終端，但是我按照步驟進行了測試，它非常好用。

  • Enpass

5、myki （非開源） ​

主要亮點：

  • 專有軟件
  • 不使用雲服務器存儲密碼
  • 專注於本地點對點同步
  • 能夠在移動設備上用指紋 ID 替換密碼

這可能不是一個受歡迎的建議，但我發現它很有趣。它是專有軟件密碼管理器，它讓你避免使用雲服務器，而是依靠點對點同步。

因此，如果你不想使用任何雲服務器來存儲你的信息，那麼它適合你。另外值得注意的是，用於 Android 和 iOS 的程序可讓你用指紋 ID 替換密碼。如果你希望便於在手機上使用，又有桌面密碼管理器的基本功能，這似乎是個不錯的選擇。

但是，如果你選擇升級到付費版，這有個付費計劃供你判斷，絕對不便宜。

嘗試一下，讓我們知道它如何!

  • myki

其他一些值得説的密碼管理器 ​

即使沒有為 Linux 提供獨立的應用，但仍有一些密碼管理器值得一提。

如果你需要使用基於瀏覽器的（擴展）密碼管理器，建議你嘗試使用 LastPass、Dashlane 和 1Password。LastPass 甚至提供了 Linux 客户端（和命令列工具）。

如果你正在尋找命令列密碼管理器，那你應該試試 Pass。

Password Safe 也是種選擇，但它的 Linux 客户端還處於 beta 階段。我不建議依靠 “beta” 程序來存儲密碼。還有 Universal Password Manager，但它不再維護。你可能也聽説過 Password Gorilla，但並它沒有積極維護。

總結 ​

目前，Bitwarden 似乎是我個人的最愛。但是，在 Linux 上有幾個替代品可供選擇。你可以選擇提供原生應用的程序，也可選擇瀏覽器插件，選擇權在你。

如果我有錯過值得嘗試的密碼管理器，請在下面的評論中告訴我們。與往常一樣，我們會根據你的建議擴展列表。
