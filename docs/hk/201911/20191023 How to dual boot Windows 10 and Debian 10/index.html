如何擁有一個 Windows 10 和 Debian 10 的雙系統 ​

在無數次勸説自己後，你終於做出了一個大膽的決定，試試 Linux。不過，在完全熟悉 Linux 之前，你依舊需要使用 Windows 10 系統。幸運的是，通過一個雙系統引導設置，能讓你在啓動時，選擇自己想要進入的系統。在這個指南中，你會看到如何 如何雙重引導 Windows 10 和 Debian 10。

前提條件 ​

在開始之前，確保你滿足下列條件:

  • 一個 Debian 10 的可引導 USB 或 DVD
  • 一個快速且穩定的網絡（為了安裝更新以及第三方軟件）

另外，記得注意你係統的引導策略（UEFI 或 Legacy），需要確保兩個系統使用同一種引導模式。

第一步：在硬盤上創建一個空餘分區 ​

第一步，你需要在你的硬盤上創建一個空餘分區。之後，這將是我們安裝 Debian 系統的地方。為了實現這一目的，需要使用下圖所示的磁盤管理器：

同時按下 Windows + R 鍵，啓動“運行程序”。接下來，輸入 diskmgmt.msc，按回車鍵。

這會啓動“磁盤管理”窗口，它會顯示你 Windows 上所有已有磁盤。

接下來，你需要為安裝的 Debian 系統創建空餘空間。為此，你需要縮小其中一個磁盤（卷）上的分區，從而創建一個未分配的新分區。在這個例子裏，我會從 D 盤中創建一個 30 GB 的新分區。

為了縮小一個卷，右鍵點擊它，然後選中選項 “縮小Shrink volume...”。

在彈出窗口中，定義你想縮小的空間大小。記住，這是將來要安裝 Debian 10 的磁盤空間。我選擇了 30000MB（大約 30 GB）。壓縮完成後，點擊“縮小Shrink”。

在縮小操作結束後，你會看到一個如下圖所示的未分配分區：

完美！現在可以準備開始安裝了。

第二步：開始安裝 Debian 10 ​

空餘分區已經創建好了，將你的可引導 USB 或安裝 DVD 插入電腦，重新啓動系統。記得更改 BIOS 中的引導順序，需要在啓動時按住功能鍵（通常，根據品牌不同，是 F9、F10 或 F12 中的某一個）。 這一步驟，對系統是否能進入安裝媒體來説，至關重要。保存 BIOS 設置，並重啓電腦。

如下圖所示，界面會顯示一個新的引導菜單：點擊 “Graphical install”。

下一步，選擇你的偏好語言，然後點擊 “繼續Continue”。

接着，選擇你的地區，點擊“繼續Continue”。 根據地區，系統會自動選擇當地對應的時區。如果你無法找到你所對應的地區，將界面往下拉， 點擊“其他Other”後，選擇相對應位置。

而後，選擇你的鍵盤佈局。

接下來，設置系統的主機名，點擊 “繼續Continue”。

下一步，確定域名。如果你的電腦不在域中，直接點擊 “繼續Continue”按鈕。

然後，如圖所示，設置 root 密碼，點擊 “繼續Continue”。

下一步驟，設置賬户的用户全名，點擊 “繼續Continue”。

接着，設置與此賬户相關聯的用户名。

下一步，設置用户密碼，點擊“繼續Continue”。

然後，設置時區。

這時，你要為 Debian10 安裝創建分區。如果你是新手用户，點擊菜單中的第一個選項，“使用最大的連續空餘空間Use the largest continuous free space”，點擊“繼續Continue”。

不過，如果你對創建分區有所瞭解的話，選擇“手動Manual” 選項，點擊 “繼續Continue”。

接着，選擇被標記為 “空餘空間FREE SPACE” 的磁盤，點擊 “繼續Continue” 。接下來，點擊“創建新分區Create a new partition”。

下一界面，首先確定交換空間大小。我的交換空間大小為 2GB，點擊 “繼續Continue”。

點擊下一界面的 “主分區Primary”，點擊“繼續Continue”。

選擇在磁盤 “初始位置beginning” 創建新分區後，點擊繼續。

選擇 “Ext 4 日誌文件系統Ext 4 journaling file system”，點擊 “繼續Continue”。

下個界面選擇“交換空間swap space” ，點擊 “繼續Continue”。

選中 “完成此分區設置done setting the partition”，點擊 “繼續Continue”。

返回磁盤分區界面，點擊 “空餘空間FREE SPACE”，點擊 “繼續Continue”。

為了讓自己能輕鬆一點，選中 “自動為空餘空間分區Automatically partition the free space”後，點擊 “繼續Continue”。

接着點擊 “將所有文件存儲在同一分區（新手用户推薦）All files in one partition (recommended for new users)”。

最後， 點擊 “完成分區設置，並將改動寫入磁盤Finish partitioning and write changes to disk” ，點擊 “繼續Continue”。

確定你要將改動寫入磁盤，點擊 “是Yes”。

而後，安裝程序會開始安裝所有必要的軟件包。

當系統詢問是否要掃描其他 CD 時，選擇 “否No” ，並點擊 “繼續Continue”。

接着，選擇離你最近的鏡像站點地區，點擊 “繼續Continue”。

然後，選擇最適合你的鏡像站點，點擊“繼續Continue”。

如果你打算使用代理服務器，在下面輸入具體信息，沒有的話就留空，點擊 “繼續Continue”。

隨着安裝進程的繼續， 你會被問到，是否想參加一個軟件包用途調查。你可以選擇任意一個選項，之後點擊“繼續Continue”，我選擇了“否No”。

在軟件選擇窗口選中你想安裝的軟件包，點擊“繼續Continue”。

安裝程序會將選中的軟件一一安裝，在這期間，你可以去喝杯咖啡休息一下。

系統將會詢問你，是否要將 grub 的引導裝載程序安裝到主引導記錄表（MBR）上。點擊 “是Yes”，而後點擊 “繼續Continue”。

接着，選中你想安裝 grub 的硬盤，點擊“繼續Continue”。

最後，安裝完成，直接點擊 “繼續Continue”。

你現在應該會有一個列出 Windows 和 Debian 的 grub 菜單。為了引導 Debian 系統，往下選擇 Debian。之後，你就能看見登錄界面。輸入密碼之後，按回車鍵。

這就完成了！這樣，你就擁有了一個全新的 Debian 10 和 Windows 10 雙系統。
