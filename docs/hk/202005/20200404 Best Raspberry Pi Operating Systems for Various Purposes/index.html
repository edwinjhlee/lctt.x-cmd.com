用於各種用途的最佳樹莓派操作系統 ​

樹莓派 是一款不可缺少的單板電腦，在很多工作中都能派上用場。不相信？只要看看這個樹莓派項目列表，就能瞭解這個小小的設備能做什麼。

考慮到樹莓派用途這麼多，為它選擇一個合適的操作系統就極其重要。當然，你可以用 Linux 做很多事，但專門為特定目的配置的操作系統可以為你節省大量的時間和精力。

因此，本文中我要介紹一些專門為樹莓派量身定製的流行且實用的操作系統。

由於有樹莓派鏡像工具，安裝任何操作系統到樹莓派上都很容易 ​

在 SD 卡上安裝樹莓派操作系統比以前容易得多。你只需下載樹莓派鏡像就可以快速地安裝任何樹莓派操作系統。請看下面的官方視頻，你就知道有多簡單。

  • HOW TO INSTALL RASPBIAN OS to your Raspberry Pi with ease - Raspberry Pi Imager

你也可以使用 NOOBS（新開箱即用軟件New Out Of the Box Software）在樹莓派上輕鬆安裝各種的操作系統。你還可以從他們的 NOOBS 官方下載頁面提到的支持的零售商列表中獲得預裝 SD 卡。

歡迎在他們的官方文檔中瞭解更多關於安裝操作系統的信息。

  • 下載樹莓派操作系統

現在你知道了怎麼安裝它（以及從哪兒獲取），讓我來重點介紹幾個有用的樹莓派操作系統，希望對你有所幫助。

適用於樹莓派的各種操作系統 ​

請注意，我花了一些精力篩選出了那些被積極維護的樹莓派操作系統項目。如果某個項目在不久的將來會停止維護，請在評論區告訴我，我會更新本文。

另一件事是，我關注到現在最新的版本是樹莓派 4，但是下面的列表不應被認為是樹莓派 4 的操作系統列表，這些系統應該也能用於樹莓派 3、3B+ 和其他變種，但是請參照項目的官方網站了解詳細信息。

注意： 排名不分先後。

1、Raspbian OS：官方的樹莓派操作系統 ​

Raspbian OS 是官方支持的樹莓派板卡操作系統。它集成了很多工具，用於教育、編程以及其他廣泛的用途。具體來説，它包含了 Python、Scratch、Sonic Pi、Java 和其他一些重要的包。

最初，Raspbian OS 是基於 Debian 的，並預裝了大量有用的包。因此，當你安裝 Raspbian OS 後，你可能就不需要特意安裝基本工具了 — 你會發現大部分工具已經提前安裝好了。

Raspbian OS 是被積極地維護着的，它也是最流行的樹莓派操作系統之一。你可以使用 NOOBS 或參照官方文檔來安裝它。

  • Raspbian OS

2、Ubuntu MATE：適合通用計算需求 ​

儘管 Raspbian 是官方支持的操作系統，但它的特點不是最新、最大的軟件包。因此，如果你想更快的更新，想用最新的包，你可以試試 Ubuntu MATE 的樹莓派版本。

Ubuntu MATE 的樹莓派定製版是值得安裝的非常不錯的輕量級發行版。它還被廣泛用於 NVIDIA 的 Jetson Nano。換言之，你可以在樹莓派的很多場景下使用它。

為了更好地幫助你，我們還有一份詳細的教程：怎樣在樹莓派上安裝 Ubuntu MATE。

  • Ubuntu MATE for Raspberry Pi

3、Ubuntu Server：把樹莓派作為一台 Linux 服務器來使用 ​

如果你計劃把你的樹莓派當作項目的某個服務器來使用，那麼安裝 Ubuntu Server 會是一個不錯的選擇。

Ubuntu Server 有 32 位和 64 位的鏡像。你可以根據你的板卡類型（是否支持 64 位）來選擇對應的操作系統。

然而，值得注意的一點是 Ubuntu Server 不是為桌面用户定製的。因此，你需要留意 Ubuntu Server 默認不會安裝圖形用户界面。

  • Ubuntu Server

4、LibreELEC：適合做媒體服務器 ​

我們已經有一個 Linux 下可用的媒體服務器軟件，LibreELEC 在列表中。

它是一個很棒的輕量級操作系統，讓你可以在樹莓派上安裝 KODI。你可以嘗試使用樹莓派鏡像工具來安裝它。

你可以很容易地找到他們的官方下載頁面，並找到適合你板卡的安裝鏡像。

  • LibreELEC

5、OSMC：適合做媒體服務器 ​

OSMC 是另一個 Linux 下流行的媒體服務器軟件。如果要把樹莓派板作為媒體中心設備，那麼 OSMC 是你可以向他人推薦的操作系統之一。

類似 LibreELEC，OSMC 也運行 KODI，可以幫助你管理你的媒體文件和欣賞你已有的素材。

OSMC 沒有正式提及對樹莓派 4 的支持。因此，如果你的樹莓派是樹莓派 3 或更早的版本，那麼應該沒有問題。

  • OSMC

6、RISC OS：最初的 ARM 操作系統 ​

RISC OS 最初是為 ARM 設備打造的，至今已有近 30 年左右的歷史。

如果你想了解，我們也有篇詳細介紹 RISC OS 的文章。簡而言之，RISC OS 也是為諸如樹莓派的現代基於 ARM 的單板計算機定製的。它的用户界面很簡單，更專注於性能。

同樣的，這並不是為樹莓派 4 量身定做的。因此，如果你的樹莓派是 3 或更早的版本，你可以試一下。

  • RISC OS

7、Mozilla WebThings Gateway：適合 IoT 項目 ​

作為 Mozilla 的 IoT 設備的開源實現的一部分，WebThings Gateway 讓你可以監控和控制所有連接的 IoT 設備。

你可以參考官方文檔來檢查所需的環境，遵照指導把安裝到樹莓派上。它確實是適合 IoT 應用的最有用的樹莓派操作系統之一。

  • WebThings Gateway

8、Ubuntu Core：適合 IoT 項目 ​

Ubuntu Core 是又一個樹莓派操作系統，適用於潛在的 IoT 應用，或者只是測試一下 Snap。

Ubuntu Core 是專門為 IoT 設備或者具體來説是樹莓派定製的。我不會刻意宣傳它 —— 但是 Ubuntu Core 是一款適合樹莓派板卡的安全操作系統。你可以自己嘗試一下！

  • Ubuntu Core

9、DietPi：輕量級樹莓派操作系統 ​

DietPi 是一款輕量級的 Debian 操作系統，它還宣稱比 “Raspbian Lite” 操作系統更輕量。

雖然它被視作一款輕量級的樹莓派操作系統，但它提供了很多功能，可以在多個使用場景中派上用場。從簡單的軟件安裝包到備份解決方案，還有很多功能值得探索。

如果你想安裝一個低內存佔用而性能相對更好的操作系統，你可以嘗試一下 DietPi。

  • DietPi

10、Lakka Linux：打造復古的遊戲主機 ​

想讓你的樹莓派變成一個復古的遊戲主機？

Lakka Linux 發行版本最初是建立在 RetroArch 模擬器上的。因此，你可以立刻在樹莓派上獲得所有的復古遊戲。

如果你想了解，我們也有一篇介紹 Lakka Linux 的文章。或者直接上手吧！

  • Lakka

11、RetroPie：適合復古遊戲 ​

RetroPie 是另一款可以讓樹莓派變成復古遊戲主機的樹莓派操作系統。它提供了幾個配置工具，讓你可以自定義主題，或者調整模擬器即可擁有最好的復古遊戲。

值得注意的是它不包含任何有版權的遊戲。你可以試一下，看看它是怎麼工作的！

  • RetroPie

12、Kali Linux：適合低成本滲透 ​

想要在你的樹莓派上嘗試和學習一些道德黑客技巧嗎？Kali Linux 會是最佳選擇。是的，Kali Linux 通常在最新的樹莓派一發布就會支持它。

Kali Linux 不僅適合樹莓派，它也支持很多其他設備。嘗試一下，玩得愉快！

  • Kali Linux

13、OpenMediaVault：適合網絡附加存儲（NAS） ​

如果你想在極簡的硬件上搭建 NAS 解決方案，樹莓派可以幫助你。

OpenMediaVault 最初是基於 Debian Linux 的，提供了大量功能，如基於 Web 的管理能力、插件支持，等等。它支持大多數樹莓派型號，因此你可以嘗試下載並安裝它！

  • OpenMediaVault

14、ROKOS：適合加密挖礦 ​

如果你對加密貨幣和比特幣很感興趣，那麼 ROKOS 會吸引你。

ROKOS 是基於 Debian 的操作系統，基本上可以讓你把你的樹莓派變成一個節點，同時預裝了相應的驅動程序和軟件包。當然，在安裝之前你需要了解它是怎麼工作的。因此，如果你對此不太瞭解，我建議你先調研下。

  • ROKOS

15、Alpine Linux：專注於安全的輕量級 Linux ​

當今年代，很多用户都在尋找專注於安全和隱私的發行版本。如果你也是其中一員，你可以試試在樹莓派上安裝 Alpine Linux。

如果你是個樹莓派新手，它可能不像你想像的那樣對用户友好（或者説對初學者來説容易上手）。但是，如果你想嘗試一些不一樣的東西，那麼你可以試試 Alpine Linux 這個專注於安全的 Linux 發行版本。

  • Alpine Linux

16、Kano OS：適合兒童教育的操作系統 ​

如果你在尋找一款能讓學習變得有趣還能教育兒童的樹莓派操作系統，那麼 Kano OS 是個不錯的選擇。

它正在積極維護中，而且 Kano OS 上的桌面集成的用户體驗相當簡單，玩起來也很有趣，可以讓孩子們從中學習。

  • Kano OS

17、KDE Plasma Bigscreen：把普通電視轉換為智能電視 ​

這是 KDE 一個正在開發中的項目。在樹莓派上安裝 KDE “等離子大屏” 後，你可以把普通電視變成智能電視。

你不需要特殊的遙控器來控制電視，你可以使用普通的遙控器。

“等離子大屏”也集成了 MyCroft 開源 AI 作為聲控。

這個項目還在測試階段，所以如果你想嘗試，可能會有一些錯誤和問題。

  • Plasma Bigscreen

18、Manjaro Linux：為你提供多功能的桌面體驗 ​

如果你想在樹莓派上尋找一個基於 Arch 的 Linux 發行版，那麼 Manjaro Linux 應該是一個很好的補充，它可以做很多事情，適合一般的計算任務。

Manjaro Linux ARM 版也支持最新的樹莓派 4。它為你的樹莓派或任何樹莓派替代品提供了 XFCE 和 KDE Plasma 變體。

此外，它似乎還提供了樹莓派設備上最快/最好的體驗之一。如果你還沒試過，那就試試吧!

  • Manjaro ARM

19、Volumio：作為一個開源音樂播放器使用 ​

想做一個廉價的音樂發燒友系統？Volumio 應該可以幫到你。

它是一個自由而開源的操作系統（GitHub），還支持集成多個設備的能力。你可以通過一個簡單的 Web 控制界面，對所有連接的設備進行管理。除了免費版之外，它還提供了一個高級版，可以讓你獲得獨家功能。

它也確實支持最新的樹莓派 4。所以，如果你對調整已有的家庭立體聲系統有一定的興趣，想要獲得最佳的音質，不妨試試這個。

  • Volumio

20、FreeBSD ​

不想使用 Linux 發行版？不用擔心，你也可以用 FreeBSD 在樹莓派上安裝一個類 UNIX 操作系統。

如果你不知道的話，我們有一篇關於 FreeBSD 項目的詳細文章。

一旦你按照他們的官方説明安裝好之後，你可以利用它來進行任何 DIY 實驗，或者只是把它作為一個輕量級的桌面系統來完成特定的任務。

  • FreeBSD

21、NetBSD ​

NetBSD 是另一個令人印象深刻的類 UNIX 操作系統，你可以在樹莓派上安裝。它的目標是成為一個跨多個系統的便攜式操作系統。

如果你在其他系統中使用過它，你可能已經知道它的好處了。然而，它不僅僅是一個輕量級的便攜式操作系統，它的特點是擁有一套有用的功能，可以完成各種任務。

  • NetBSD

結語 ​

我相信還有很多為樹莓派定製的操作系統 — 但是我盡力列出了被積極維護的最流行的或最有用的操作系統。
