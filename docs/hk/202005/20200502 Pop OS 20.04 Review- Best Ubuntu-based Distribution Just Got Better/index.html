Pop!_OS 20.04 點評：最好的基於 Ubuntu 的發行版越來越好了 ​

Pop!_OS 20.04 是一款令人印象深刻的基於 Ubuntu 的 Linux 發行版。我在這篇評論中回顧了其主要的新功能，並分享了我對最新版本的體驗。

現在，Ubuntu 20.04 LTS 及其官方變體版本已經發布了 - 是時候看看 System76 的 Pop!_OS 20.04 了，這是基於 Ubuntu 的最好的發行版之一。

老實説，Pop!_OS 是我最喜歡的 Linux 發行版，主要用於我做的所有事情。

現在，Pop!_OS 20.04 終於來了。是時候來看看它提供了哪些功能，以及你是否應該升級？

Pop!_OS 20.04 LTS 中有什麼新東西？ ​

從視覺上看，Pop!_OS 20.04 LTS 與 Pop!_OS 19.10 並沒有太大的區別。然而，你可以發現幾個新功能和改進。

但是，如果你之前使用的是 Pop!_OS 18.04 LTS，則可以發現有很多東西可以嘗試。

隨着 GNOME 3.36 的到來，及其帶來的一些新功能，Pop!_OS 20.04 成為了一個令人激動的版本。

總的來説，以下是一些主要的亮點。

  • 自動窗口平鋪
  • 新的應用程序切換器和啓動器
  • 在 Pop!_Shop 中增加了對 Flatpack 的支持。
  • GNOME 3.36
  • Linux 內核 5.4
  • 改進的混合圖形支持

雖然聽起來很有趣，但我們還是來了解一下詳細的變化，以及到目前為止 Pop!_OS 20.04 的體驗如何。

Pop!_OS 20.04 中的用户體驗提升 ​

毫無疑問，很多 Linux 發行版都提供了開箱即用的用户體驗。同樣的，Ubuntu 20.04 LTS 也有一流的改進和功能。

而對於 System76 的 Pop!_OS，他們總是試圖更進一步。並且，大多數新功能旨在通過提供有用的功能來改善用户體驗。

在這裏，我將介紹一些改進，其中包括 GNOME 3.36 和 Pop!_OS 特有的一些功能。

支持系統托盤圖標 ​

總算是有了！這可能不是什麼大的改變 —— 但 Pop!_OS 以前沒有支持系統托盤圖標（或小程序圖標）。

隨着 20.04 LTS 的發佈，默認情況就有了系統托盤，不需要任何擴展。

依靠系統托盤圖標的程序可能並不多 —— 但它仍然是重要的東西。

就我而言，我以前無法在 Pop!_OS 19.10 上使用 ActivityWatch —— 但現在可以了。

自動窗口平鋪 ​

自動窗口平鋪是我一直想嘗試的東西 —— 但從來沒花時間使用過 i3 這樣的平鋪窗口管理器來設置它，更別説是 Regolith 桌面了。

在 Pop!_OS 20.04 中，你就不需要這樣做了。自動窗口平鋪功能已經內置，無需設置。

它還提供了“顯示活動提示”的選項，也就是説，它將高亮顯示活動窗口以避免混淆。而且，你還可以調整窗口之間的間隙。

你可以在他們的官方視頻中看到它是如何工作的：

  • System76 Pop!_OS 20.04 - Auto Tiling

而且，我得説，這是 Pop!_OS 20.04 上最大的新增功能之一，有可能幫助你更有效地進行多任務處理。

即使每次使用該功能都很方便，但為了最大程度地利用它，最好是使用一個大於 21 英寸的顯示屏（至少）! 而且，因為這個原因 —— 我真的很想把我的顯示器也升級一下!

新的擴展應用 ​

Pop!_OS 內置了一些獨特的 GNOME 擴展。但是，你不需要用 GNOME Tweaks 來管理擴展。

新增加的 “Extensions” 應用可以讓你在 Pop!_OS 20.04 上配置和管理擴展程序。

改進的通知中心 ​

在新的 GNOME 3.36 中，通知中心的外觀經過了改進。這裏，我啓用了黑暗模式。

新的應用程序切換器 & 啓動器 ​

你仍然可以用 ALT+TAB 或 Super+TAB 來瀏覽正在運行的應用程序。

但是，當你有很多事情要做的時候，這很耗時。所以，在 Pop!_OS 20.04上，你可以使用 Super+ / 激活應用程序切換器和啓動器。

一旦你習慣了這個快捷鍵，它將是非常方便的東西。

除此以外，你可能會發現 Pop!_OS 20.04 上的圖標/窗口在視覺上有許多其它細微的改進。

新的登錄界面 ​

嗯，這是 GNOME 3.36 帶來的一個明顯的變化。但是，它看起來確實很不錯!

Pop!_Shop 支持 Flatpak ​

通常，Pop!_Shop 已經是一個非常有用的東西了，包括它自有的在內，它帶有一個巨大的軟件倉庫。

現在，在 Pop!_OS 20.04 中，你可以用 Pop!_Shop 安裝任何可用軟件的 Debian 包或 Flatpak（通過 Flathub） —— 當然，前提是某個軟件有 Flatpak 軟件包。

如果你沒有使用 Pop!_OS 20.04，你可能要看看如何在 Linux 上使用 Flatpak。

就我個人而言，我並不是 Flatpak 的粉絲，但有些應用如 GIMP 需要你安裝 Flatpak 包才能獲得最新版本。所以，在 Pop!_Shop 上直接支持了 Flatpak 絕對是一件好事。

鍵盤快捷鍵更改 ​

如果你習慣了 Pop!_OS 19.10 或更早的版本上現有的鍵盤快捷鍵，這可能會讓你很煩。

不管是哪種情況，有幾個重要的鍵盤快捷鍵變化可能會改善你的體驗，如下：

  • 鎖定屏幕：Super + L 改為 Super + Escape。
  • 移動工作區：Super + 上/下箭頭鍵 改為 Super + CTRL + 上/下箭頭鍵。
  • 關閉窗口：Super + W 變更為 Super + Q。
  • 切換最大化：Super +向上箭頭 改為 Super + M。

Linux 內核 5.4 ​

與其他大多數最新的 Linux 發行版相似，Pop!_OS 20.04 搭載了 Linux 內核 5.4。

所以，很明顯，你可以期望獲得對 exFAT 支持、改進的 AMD 圖形兼容性以及它附帶所有其他功能。

性能提升 ​

儘管 Pop!_OS 並不稱自己是輕量級的 Linux 發行版，但它仍然是一個資源節約型的發行版。而且，有了 GNOME 3.36 的支持，它的速度應該足夠快了。

考慮到我已經將 Pop!_OS 作為主要發行版使用已經一年多了，我從來沒有遇到過性能問題。這就是你安裝了 Pop!_OS 20.04 之後的資源使用情況（取決於你的系統配置）。

給你一個作為參考，我的台式機配置包括 i5-7400 處理器、16GB 內存（2400MHz）、NVIDIA GTX 1050ti 顯卡和 SSD。

我不是一個系統基準測試的忠實擁護者，因為除非你去嘗試，否則它並不能讓你知道特定的應用或遊戲的性能。

你可以試試 Phoronix 測試套件來分析你的系統表現。但是，Pop!_OS 20.04 LTS 應該是一個很爽快的體驗！

軟件包更新 & 其他改進 ​

儘管每個基於Ubuntu的發行版都受益於Ubuntu 20.04 LTS的改進，但也有一些 Pop!_OS 特有的錯誤修復和改進。

除此之外，一些主要的應用程序/包（如 Firefox 75.0）也已經更新到了最新版本。

到現在為止，應該沒有任何嚴重的錯誤，至少對我來説沒有。

你可以在 GitHub 上查看他們的開發進度，以瞭解他們在測試期間已經修復的問題和發佈後即將修復的問題。

下載 & 支持 Pop!_OS 20.04 ​

在這個版本中，System76 終於增加了一個可選的訂閲模式來支持 Pop!_OS 的開發。

你可以免費下載 Pop!_OS 20.04 —— 但如果你想支持他們，我建議你只需要 $1/月就可以訂閲。

  • Pop!_OS 20.04

我對 Pop OS 20.04 的看法 ​

我必須提到的是，我正在為最新的 20.04 版本提供全新的牆紙。但是，這沒什麼大不了的。

有了窗口平鋪功能、支持 flatpak，以及眾多其他改進，到目前為止，我對 Pop!_OS 20.04 的體驗是一流的。另外，很高興看到他們在一些流行軟件的開箱即用支持上突出了他們對創意專業人士的關注。

Ubuntu 20.04 的所有優點，再加上 System76 的一些額外的加料，讓我印象深刻!
