扫码关注官方微信公众号获取开源软件和 x-cmd 的最新用法与独家资讯

#: subject: (Now You Can Run Linux Apps in Windows (Thanks to WSL)) #: via: (https://itsfoss.com/run-linux-apps-windows-wsl/) #: author: (Ankush Das https://itsfoss.com/author/ankush/)

現在你可以在 Windows 中運行 Linux 應用了 ​

微軟最近的 “Build 2020” 開發者大會公佈了一些有趣的公告。我不確定這該令人興奮還是該令人懷疑 —— 但是微軟，你現在比以往任何時候都受到我們的關注。

同時，在所有的這些公告中，能夠在 WSL（Windows Subsystem for Linux）上運行 GUI 應用程序的功能備受關注。

更不要忘了 Xamrin.Forms 更名為 MAUI 的尷尬結局，它與 Nitrux Linux 的 Uri Herrera 的現有開源項目（Maui Project）名字衝突。

以防你不清楚，WSL 是一種環境，可讓你在 Windows 10 中獲得 Linux 控制台的體驗。它也是在 Windows 中運行 Linux 命令的最佳方法之一。

正如 Liam Dawe 認為的那樣，通過Blog文章（DirectX ❤ Linux）發佈的公告可能是隻是個公關誘餌。但是，仍然值得一提。

WSL 上對 Linux GUI 應用程序的支持 ​

最近，Microsoft 在在線開發者大會上宣佈了 WSL（即 WSL 2）的一系列新功能。

Windows 包管理器、Windows 終端 1.0，以及其他一些功能的引入是其亮點。

但是， WSL 2 對 GPU 硬件加速的支持非常重要。

那麼，是否意味着你可以使用 WSL 在 Windows 上運行 Linux 應用程序呢？看起來像是。

微軟計劃通過使用全新的 Linux 內核驅動程序 dxgkrnl 來實現它。為了給你一個技術性的簡報, 我在這裏引用他們的公告中的描述：

dxgkrnl 是一個全新的 Linux 內核驅動程序，它將 /dev/dxg 設備提供給用户模式的 Linux。 /dev/dxg 提供了一組 IOCTL，它們與 Winodws 上的原生 WDDM D3DKMT 內核服務層非常相似。Linux 內核中的 dxgkrnl 通過 VM 總線連接到 Windows 主機上，並使用此 VM 總線連接與物理 GPU 進行通訊。

我不是這方面的專家，但這意味着 WSL 上的 Linux 應用程序將與原生的 Windows 應用程序一樣可以訪問 GPU。

針對 GUI 應用程序的支持將在今年秋季的晚些時候提供（而不是 2020 年 5 月的更新） —— 所以我們要看看什麼時候提供。

微軟專門針對的是那些希望在 Windows 上輕鬆使用 Linux IDE 的開發人員。谷歌也在瞄準同樣的用户羣，將 GUI Linux 應用程序引入到 Chromebook。

那麼，對於那些堅持使用 Windows 的用户來説，這是個好消息。但是，這是真的嗎？

微軟愛上了 Linux —— 真的嗎？ ​

他們在 Windows 上整合 Linux 環境來擁抱 Linux 及其優勢的努力，絕對是一件好事。

但是，它真的能給桌面 Linux 用户帶來什麼好處呢？到目前為止，我還沒有看到任何實際的好處。

在這裏，你可以有不同的看法。但是，我認為 WSL 的開發對於 Linux 桌面用户來説沒有真正的價值。至少，到目前為止沒有。

有趣的是，Linux Unplugged podcast 上有人強調了微軟的舉動，認為這與他們的 EEE（擁抱、延伸和撲滅Embrace, extend, and extinguish）的思路是一致的。

可能吧，誰知道呢？當然，他們為實現這一目標而付出的努力值得讚賞 —— 同時又令人感到興奮和神秘。

這是否以為着 Windows 用户將不必再轉到 Linux? ​

微軟之所以在其平台上集成 Linux，是因為他們知道 Liunx 的能力，也知道開發人員（或用户）喜歡使用它的原因。

但是，隨着 WSL 2 的更新，如果這種情況持續下去，我傾向於同意 Abhishek 的看法：

最終，桌面 Linux 將被限制在 Windows 下，成為桌面應用程序……

好吧，當然，原生的體驗暫時還是比較好的。而且，很難看到現有的 Linux 桌面用户會使用 Windows 來將其替代。但是，這仍然值得擔心。

你如何看待這一切？我不認為 WSL 對於被迫使用 Windows 的用户有什麼好處 —— 但是，從長遠來看，你認為微軟在 WSL 方面的進展本質上是敵意還是對 Linux 有幫助？

在評論中讓我知道你的想法！
