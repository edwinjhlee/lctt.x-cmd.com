Mozilla 貢獻者為大眾創建糖尿病項目 ​

我的開源生涯從我還是一名高中生開始，我總想着自己能成為一名黑客，沒有什麼惡意的，只是喜歡鑽研代碼和硬件那種。我第一次接觸開源是2001年，我安裝了我的第一個Linux發行版Lindows。當然，我也是Mozilla Firefox的早期用户。

由於我很早使用Linux，我用的第一個版本是 Lindows 1.0.4（如果我沒記錯的話），我就立即愛上了它。我沒在Lindows上呆太久，而是活躍於多個發行版（Debian, Puppy Linux, SUSE, Slackware, Ubuntu），多年來我一直每天使用着開源軟件，從青少年時候直到我成年。

最後，我堅持使用Ubuntu。大概是在Hardy Heron（LCTT 譯註：Ubuntu8.04 LTS）發佈時候，我開始第一次為Ubuntu做些貢獻，在IRC頻道和當地社區幫助那些需要幫助的用户。我是通過Ubuntu認識開源的，它在我心裏總有着特殊的意義。Ubuntu背後的社區的是非常多樣化的、熱情的、友好的，每個人都做些共享，是他們共同的目標也是個人目標，這成為他們為開源貢獻的動力。

在為Ubuntu貢獻一段時間後，我開始了為一些上游項目作貢獻，比如Debian、GNOME、 Ganeti，還有許多其他的開源項目。在過去的幾年裏，我為超過40個開源項目貢獻過，有些小的，也有很大的。

在Ubuntu項目方向上有些變化之後，我最終覺得，這不僅對於我是一個嘗試新東西的機遇，而且也是我給一些新東西貢獻的時候。所以我在2009年參與了Mozilla項目，在IRC幫忙，最終通過參與Mozilla WebFWD program，成為一名團隊成員，然後是Mozilla Reps Program，Mozilla DevRel Program，剛過兩年時間，我成為了火狐社區的發佈經理，負責監督Firefox Nightly和Firefox ESR的發佈。相比其他開源項目，在為Mozilla貢獻中會獲得更多有益的經驗。在所有我參與過的開源社區中，Mozilla是最不同的，最大的也是最友好的。

這些年來，關於開源我覺得，我越來越遵循自由軟件價值觀、捍衞隱私和許可協議合規，以及在開放的氛圍下工作。我相信這三個主題對於開源來説是非常重要的，雖然許多人並沒在意到提倡它們是很重要的。

今天在這，我已不再是別人的開源項目的全職貢獻者。最近我被診斷出患有糖尿病，我看到了開源軟件中健康軟件不是很豐富這一缺口。確實，它不像其它開源軟件應用如Linux發行版或瀏覽器那樣活躍。

我最近創立了自己的開源項目Glucosio，帶給人們糖尿病管理和研究的開源軟件。經過幾年來對開源項目的貢獻，和見識過的多種組織結構，使得我作為項目領導能夠得心應手。我對於Glucosio的未來很興奮，但最重要的是未來的開源將在醫療健康領域發展的如何。

醫療保健軟件的創新具有很大潛力，我想我們很快就會看到用於改善醫療衞生保健的開源新方案。
