當初你為何使用 Linux？ ​

Linux 越來越流行，很多 OS X 或 Windows 用户都轉移到 Linux 陣營了。但是你知道是什麼讓他們開始使用 Linux 的嗎？一個 Reddit 用户在網站上問了這個問題，並且得到了很多有趣的回答。

一個名為 SilverKnight 的用户在 Reddit 的 Linux 版塊上問了如下問題：

我知道這個問題肯定被問過了，但我還是想聽聽年輕一代使用 Linux 的原因，以及是什麼讓他們堅定地成為 Linux 用户。

我無意阻止大家講出你們那些精彩的 Linux 故事，但是我還是對那些沒有經歷過什麼精彩故事的新人的想法比較感興趣。

我27歲，半吊子 Linux 用户，這些年裝過不少發行版，但沒有投入全部精力去玩 Linux。我正在找更多的、能讓我全身心投入到 Linux 潮流的理由，或者説激勵。

詳見 Reddit

以下是網站上的回覆：

DoublePlusGood：我12歲開始使用 Backtrack（現在改名為 Kali），因為我想成為一名黑客（LCTT 譯註：原文“1337 haxor”，1337 是 leet 的火星文寫法，意為'火星文'，haxor 為 hackor 的火星文寫法，意為'黑客'，另一種寫法是 1377 h4x0r，滿滿的火星文文化）。我現在一直使用 ArchLinux，因為它給我無限自由，讓我對我的電腦可以為所欲為。

Zack：我記得是12、3歲的時候使用 Linux，現在15歲了。

我11歲的時候就對 Windows XP 感到不耐煩，一個簡單的功能，比如關機，TMD 都要讓我耐心等着它慢慢完成。

在那之前幾個月，我在 freenode IRC 聊天室參與討論了一個遊戲，它是一個開源項目，大多數用户使用 Linux。

我不斷聽到 Linux 但當時對它還沒有興趣。然而由於這些聊天頻道（大部分在 freenode 上）談論了很多編程話題，我就開始學習 python 了。

一年後我嘗試着安裝 GNU/Linux （主要是 ubuntu）到我的新電腦（其實不新，但它是作為我的生日禮物被我得到的）。不幸的是它總是不能正常工作，原因未知，也許硬盤壞了，也許灰塵太多了。

那時我放棄自己解決這個問題，然後纏着老爸給我的電腦裝上 Ubuntu，他也無能為力，原因同上。

在追求 Linux 一段時間後，我打算拋棄 Windows，使用 Linux Mint 代替 Ubuntu，本來沒抱什麼希望，但 Linux Mint 竟然能跑起來！

於是這個系統我用了6個月。

那段時間我的一個朋友給了我一台虛擬機，跑 Ubuntu 的，我用了一年，直到我爸給了我一台服務器。

6個月後我得到一台新 PC（現在還在用）。於是起想折騰點不一樣的東西。

我打算裝 openSUSE。

我很喜歡這個系統。然後在聖誕節的時候我得到樹莓派，上面只能跑 Debian，還不能支持其它發行版。

Cqz：我9歲的時候有一次玩 Windows 98，結果這貨當機了，原因未知。我沒有 Windows 安裝盤，但我爸的一本介紹編程的雜誌上有一張隨書附贈的光盤，這張光盤上剛好有 Mandrake Linux 的安裝軟件，於是我瞬間就成為了 Linux 用户。我當時還不知道自己在玩什麼，但是玩得很嗨皮。這些年我雖然在電腦上裝了多種 Windows 版本，但是 FLOSS 世界才是我的家（LCTT 譯註：FLOSS —— Free/Libre and Open Source Software，自由/開源軟件）。現在我只把 Windows 裝在虛擬機上，用來玩遊戲。

Tosmarcel：15歲那年對'編程'這個概念很好奇，然後我開始了哈佛課程'CS50'，這個課程要我們安裝 Linux 虛擬機用來執行一些命令。當時我問自己為什麼 Windows 沒有這些命令？於是我 Google 了 Linux，搜索結果出現了 Ubuntu，在安裝 Ubuntu 的時候不小心把 Windows 分區給刪了。。。當時對 Linux 毫無所知，適應這個系統非常困難。我現在16歲，用 ArchLinux，不想用回 Windows，我愛 ArchLinux。

Micioonthet：第一次聽説 Linux 是在我5年級的時候，當時去我一朋友家，他的筆記本裝的就是 MEPIS（Debian的一個比較老的衍生版），而不是 XP。

原來是他爸爸是個美國的社會學家，而他全家都不信任微軟。我對這些東西完全陌生，這系統完全沒有我熟悉的軟件，我很疑惑他怎麼能使用。

我13歲那年還沒有自己的筆記本電腦，而我另一位朋友總是抱怨他的電腦有多慢，所以我打算把它買下來並修好它。我花了20美元買下了這台裝着 Windows Vista 系統、跑滿病毒、完全無法使用的惠普筆記本。我不想重裝討厭的 Windows 系統，記得 Linux 是免費的，所以我刻了一張 Ubuntu 14.04 光盤，馬上把它裝起來，然後我被它的高性能給震精了。

“我的世界（Minecraft）”（由於它允許運行在 JAVA 上，所以當時它是 Linux 下為數不多的幾個遊戲之一）在 Vista 上只能跑5幀每秒，而在 Ubuntu 上能跑到25幀。

我到現在還會偶爾使用一下那台筆記本，Linux 可不會在乎你的硬件設備有多老。

之後我把我爸也拉入 Linux 行列，我們會以很低的價格買老電腦，裝上 Linux Mint 或其他輕量級發行版，這省了好多錢。

Webtm：我爹每台電腦都會裝多個發行版，有幾台是 opensuse 和 Debian，他的個人電腦裝的是 Slackware。所以我記得很小的時候一直在玩 debian，但沒有投入很多精力，我用了幾年的 Windows，然後我爹問我有沒有興趣試試 debian。這是個有趣的經歷，在那之後我一直使用 debian。而現在我不用 Linux，轉投 freeBSD，5個月了，用得很開心。

完全控制自己的系統是個很奇妙的體驗。開源界有好多酷酷的軟件，我認為在自己解決一些問題並且利用這些工具解決其他事情的過程是最有趣的。當然穩定和高效也是吸引我的地方。更不用説它的保密級別了。

Wyronaut：我今年18，第一次玩 Linux 是13歲，當時玩的 Ubuntu，為啥要碰 Linux？因為我想搭一個“我的世界”的服務器來和小夥伴玩遊戲，當時“我的世界”可是個新鮮玩意兒。而搭個私服需要用 Linux 系統。

當時我還是個新手，對着 Linux 的命令列有些傻眼，因為很多東西都要我自己處理。還是多虧了 Google 和維基，我成功地在多台老 PC 上部署了一些簡單的服務器，那些早已無人問津的老古董機器又能發揮餘熱了。

跑過遊戲服務器後，我又開始跑 web 服務器，先是跑了幾年 HTML，CSS 和 PHP，之後受 TheNewBoston 視頻的誤導轉到了 JAVA。

一週後放棄 JAVA 改用 Python，當時學習 Python 用的書名叫《Learn Python The Hard Way》，作者是 Zed A. Shaw。我花了兩週學完 Python，然後開始看《C++ Primer》，因為我想做遊戲開發。看到一半（大概500頁）的時候我放棄了。那個時候我有點討厭玩電腦了。

這樣中斷了一段時間之後，我決定學習 JavaScript，讀了2本書，試了4個平台，然後又不玩了。

現在到了不得不找一所學校並決定畢業後找什麼樣工作的糟糕時刻。我不想玩圖形界面編程，所以我不會進遊戲行業。我也不喜歡畫畫和建模。然後我發現了一個涉及網絡安全的專業，於是我立刻愛上它了。我挑了很多 C 語言的書來度過這個假期，並且複習了一下數學來迎接新的校園生活。

目前我玩 archlinux，不同 PC 上跑着不同任務，它們運行很穩定。

可以説 Linux 帶我進入編程的世界，而反過來，我最終在學校要學的就是 Linux。我估計會終生感謝 Linux。

Linuxllc：你們可以學學像我這樣的老頭。

扔掉 Windows！扔掉 Windows！扔掉 Windows！給自己一個堅持使用 Linux 的理由，那就是完全，徹底，遠離，Windows。

我在 2003 年放棄 Windows，只用了5天就把所有電腦跑成 Linux，包括所有的外圍設備（LCTT 譯註：比如打印機？）。我不玩 Windows 裏的遊戲，只玩 Linux 裏的。

Highclass：我28歲，不知道還是不是你要找的年輕人類型。

老實説我對電腦挺感興趣的，當我還沒接觸'自由軟件哲學'的時候，我認為 free 是免費的意思。我也不認為命令列界面很讓人難以接受，因為我小時候就接觸過 DOS 系統。

我第一個發行版是 Mandrake，在我11歲還是12歲那年我把家裏的電腦弄得亂七八糟，然後我一直折騰那台電腦，試着讓我自己的技能提升一個台階。現在我在一家公司全職使用 Linux。（請允許我聳個肩）。

Matto：我的電腦是舊貨市場淘回來的，裝 XP，跑得慢，於是我想換個系統。Google 了一下，發現 Ubuntu。當年我15、6歲，現在23了，就職的公司內部使用 Linux。

IBM 的 Linux 大型機 ​

IBM 很久前就用 Linux 了。現在這家公司退推出一款機器專門使用 Ubuntu，機器名叫 LinuxOne。

Ron Miller 在 TecchCrunch Blog上説：

新的大型機包括兩款機型，都是以企鵝名稱命名的（Linux 的吉祥物就是一隻企鵝，懂18摸的命名用意了沒？）第一款叫帝企鵝，使用 IBM z13 機型，我們早在1月份就介紹過了。另一款稍微小一點，名叫跳巖企鵝，供入門級買家使用。

也許你會以為大型機就像恐龍一樣早就滅絕了，但世界上許多大型機構中都還在使用它們，它們還健在。作為發展雲技術戰略的一部分，數據分析與安全有望於提升 Ubuntu 大型機的市場，這種大型機能提供一系列開源的企業級軟件，比如 Apache Spark，Node.js，MongoDB，MariaDB，PostgreSQL 和 Chef。

大型機還會存在於客户預置的數據中心中，但是市場的大小取決於會有多少客户使用這種類似於雲服務的系統。Mauri 解釋道，IBM 正在尋求增加大型機銷量的途徑，與 Canonical 公司合作，鼓勵使用開源工具，都能為大型機打開一個小的，卻能賺錢的市場。

你為什麼要放棄 Windows10 而選擇 Linux ​

自從 Windows10 出來以後，各種媒體都報道過它的隱藏間諜功能。ZDNet 列出了一些放棄 Windows10 的理由。

SJVN 在 ZDNet 的報告：

你試試關掉 Windows10 的數據分享功能，壞消息來了：window10 會繼續把你的數據分享給微軟公司。請選擇 Linux 吧。

你可以有很多方法不讓 Windows10 泄露你的秘密，但你不能阻止它交談。Cortana，win10 小娜，語音助手，就算你把她關了，她也會把數據發給微軟公司。這些數據包括你的電腦 ID，微軟用它來識別你的 PC 機。

所以如果這些泄密給你帶來了煩惱，你可以使用老版本 Windows7，或者換到 Linux。然而，當 Windows7 不再提供技術支持的那天到來，如果你還想保留隱私，最終你還是隻能選擇 Linux。

這裏還有些小眾的桌面系統能保護你的隱私，比如 BSD 家族的 FreeBSD，PCBSD，NetBSD，eComStation，OS/2。但是，最好的選擇還是 Linux，它提供最低的學習曲線。
