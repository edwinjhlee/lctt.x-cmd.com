一步一腳印：GNOME十八年進化史 ​

注：youtube 視頻

GNOME （GNU Object Model Environment）由兩位墨西哥的程序員 Miguel de Icaza 和 Federico Mena 始創於1997年8月15日。GNOME 自由軟件計劃由志願者和全職開發者來開發一個桌面環境及其應用程序。GNOME 桌面環境的所有部分都由開源軟件組成，並且支持Linux， FreeBSD， OpenBSD 等操作系統。

現在就讓我穿越到1997年來看看 GNOME 的第一個版本：

GNOME 1 ​

GNOME 1.0 (1997) – GNOME 發佈的第一個重大版本

GNOME 1.2 “Bongo”，2000

GNOME 1.4 “Tranquility”， 2001

GNOME 2 ​

GNOME 2.0， 2002

重大更新，基於 GTK+ 2。引入了人機界面指南（Human Interface Guidelines）。

GNOME 2.2 2003

改進了多媒體和文件管理器。

GNOME 2.4 “Temujin”, 2003

首次發佈 Epiphany 瀏覽器，增添了輔助功能（accessibility）。

GNOME 2.6， 2004

Nautilus 成為主要的文件管理工具，同時引入了新的 GTK+ 對話框。作為對這個版本中變化的結果，創建了一個存在時間不久的分叉版本：GoneME。

GNOME 2.8， 2004

改良了對可移動設備的支持，並新增了 Evolution 郵件應用。

GNOME 2.10， 2005

減小了內存需求和提升了性能。增加了新的面板小應用（調製解調器控制、磁盤掛載器和回收站組件）以及 Totem 影片播放器和 Sound Juicer CD抓取工具。

GNOME 2.12， 2005

改進了 Nautilus，改進了應用程序間的剪切/粘貼功能和 freedesktop.org 的整合。 新增 Evince PDF 閲讀器；新默認主題 Clearlooks；菜單編輯器、鑰匙環管理器和管理員工具。基於 GTK+2.8，支持 Cairo。

GNOME 2.14， 2006

性能提升（某些情況下超過 100%）；增強用户界面的易用性；GStreamer 0.10 多媒體框架。增加了 Ekiga 視頻會議應用、Deskbar 搜索工具、Pessulus 權限管理器、快速切換用户功能和 Sabayon 系統管理員工具。

GNOME 2.16， 2006

性能提升。增加了 Tomboy 筆記應用、Baobab 磁盤用量分析應用、Orca 屏幕閲讀器以及 GNOME 電源管理程序（延長了筆記本電池壽命）。改進了 Totem、Nautilus。Metacity 窗口管理器的合成（compositing）支持。新的圖標主題。基於 GTK+ 2.0 的全新打印對話框。

GNOME 2.18， 2007

性能提升。增加了 Seahorse GPG 安全應用，可以對郵件和本地文件進行加密。Baobab 改進了環狀圖表顯示方式的支持。Orca 屏幕閲讀器。改進了 Evince、Epiphany、GNOME 電源管理、音量控制。增加了兩款新遊戲：GNOME 數獨和 glChess 國際象棋。支持 MP3 和 AAC 音頻解碼。

GNOME 2.20， 2007

發佈十週年版本。Evolution 增加了備份功能。改進了 Epiphany、EOG、GNOME 電源管理。Seahorse 中的鑰匙環密碼管理功能。增加：在 Evince 中可以編輯PDF文檔、文件管理界面中整合了搜索模組、自動安裝多媒體解碼器。

GNOME 2.22， 2008

新增 Cheese 應用，它是一個可以截取網絡攝像頭和遠程桌面圖像的工具。Metacity 支持基本的窗口合成（compositing）。引入 GVFS（LCTT譯註：GNOME Virtual file system，GNOME 虛擬文件系統）。改善了Totem 播放 DVD 和 YouTube 的效果，支持播放 MythTV。時鐘小應用支持國際化。在 Evolution 中新增了谷歌日曆以及為信息添加標籤的功能。改進了 Evince、Tomboy、 Sound Juicer 和計算器。

GNOME 2.24， 2008

新增了 Empathy 即時通訊軟件。Ekiga 升級至3.0版本。Nautilus 支持標籤式瀏覽，更好的支持了多屏幕顯示方式和數字電視功能。

GNOME 2.26， 2009

新增光盤刻錄應用 Brasero。簡化了文件分享的流程。改進了媒體播放器的性能。支持多顯示器和指紋識別器。

GNOME 2.28， 2009

增加了 GNOME 藍牙模組。改進了 Epiphany 網頁瀏覽器、Empathy 即時通訊軟件、時間追蹤器和輔助功能。GTK+ 升級至2.18版本。

GNOME 2.30， 2010

改進了 Nautilus 文件管理器、Empathy 即時通訊軟件、Tomboy、Evince、時間追蹤器、Epiphany 和 Vinagre。藉助 GVFS 通過 libimobiledevice（LCTT 譯註：支持iOS®設備跨平台使用的工具協議庫)部分地支持了 iPod 和 iPod Touch 設備。

GNOME 2.32， 2010

新增 Rygel 媒體分享工具和 GNOME 色彩管理器。改進了 Empathy 即時通訊軟件、Evince、Nautilus 文件管理器等。由於計劃於2010年9月發佈3.0版本，因此大部分開發者的精力都由2.3x轉移至了3.0版本。

GNOME 3 ​

GNOME 3.0， 2011

引入 GNOME Shell，這是一個重新設計的、具有更簡練更集中的選項的框架。基於 Mallard 標記語言的話題導向型幫助系統。支持窗口並列堆疊。啓用新的視覺主題和默認字體。採用 GTK+ 3.0，具有更好的語言綁定、主題、觸控以及多平台支持。去除了那些長期棄用的 API。

GNOME 3.2、 2011

支持在線帳户、“瀏覽器”應用。新增通訊錄應用和文檔文件管理器。“文件管理器”支持快速預覽。較大的整合，文檔更完善，以及對外觀的改善和各種性能提升。

GNOME 3.4, 2012

全新外觀的 GNOME 3 應用程序：“文件”、Epiphany（更名為“瀏覽器”）、“GNOME 通訊錄”。可以在活動概覽中搜索本地文件。支持應用菜單。煥然一新的界面元素：新的顏色拾取器、重新設計的滾動條、更易使用的旋鈕以及可隱藏的標題欄。支持平滑滾動。全新的動態壁紙。在系統設置中改進了對 Wacom 數位板的支持。更簡便的擴展應用管理。更好的硬件支持。面向主題的幫助文檔。在 Empathy 中提供了對視頻電話和動態信息的支持。更好的輔助功能：提升 Orca 整合度，增強高對比度模式，以及全新的縮放設置。大量的應用增強和對細節的改進。

GNOME 3.6, 2012

全新設計的核心元素：新的應用按鈕和改進的活動概覽佈局。新的登錄和鎖定界面。重新設計的通知欄。通知現在更智能，可見性更高，同時更容易關閉。改進了系統設置的界面和設定邏輯。用户菜單默認顯示關閉電源操作。整合的輸入方式。輔助功能一直開啓。新的應用：Boxes 桌面虛擬化，曾在 GNOME 3.4中發佈過預覽版。Clocks 時鐘，可以顯示世界時間。更新了磁盤用量分析、Empathy 和字體查看器的外觀。改進了 Orca 對布萊葉盲文的支持。 在“瀏覽器”中，用最常訪問頁面取代了之前的空白起始頁，增添了更好的全屏模式並使用了 WebKit2 測試版引擎。 Evolution 開始使用 WebKit 顯示郵件內容。 改進了“磁盤”功能。 改進了“文件”應用（即之前的 Nautilus），新增諸如最近訪問的文件和搜索等功能。

GNOME 3.8, 2013

令人耳目一新的核心組件：新應用界面可以分別顯示常用應用及全部應用。窗口布局得到全面改造。新的屏幕即現式（OSD）輸入法開關。通知和信息現在會對屏幕邊緣的點擊作出回應。為那些喜歡傳統桌面的用户提供了經典模式。重新設計了設置界面的工具欄。新的初始化引導流程。“GNOME 在線帳户”添加了對更多供應商的支持。“瀏覽器”正式啓用 WebKit2 引擎，有了一個新的私密瀏覽模式。“文檔”支持雙頁模式並且整合了 “Google 文檔”。“通訊錄”的 UI 升級。“GNOME 文件”、“GNOME Boxes”和“GNOME 磁盤”都得到了大幅改進。集成了 ownCloud。兩款全新的 GNOME 核心應用：“GNOME 時鐘”和“GNOME 天氣”。

GNOME 3.10, 2013

全新打造的系統狀態區，能夠更直觀的縱覽全局。一系列新應用，包括 “GNOME 地圖”、“GNOME 備忘錄”、 “GNOME 音樂”和“GNOME 照片”。新的基於位置的功能，如自動時區和世界時鐘。支持高分辨率及智能卡。 基於 GLib 2.38 提供了對 D-Bus 的支持。

GNOME 3.12, 2014

改進了概覽中的鍵盤導航和窗口選擇，基於易用性測試對初始設置進行了修改。有線網絡圖標重新回到了狀態欄上，在“應用”視圖中可以自定義應用文件夾。在大量應用的對話框中引入了新的 GTK+ 小工具，同時使用了新的 GTK+ 標籤風格。“GNOME 視頻”，“GNOME 終端”以及 Gedit 都改用了全新外觀，更貼合 HIG（LCTT 譯註：Human Interface Guidelines，人機界面指南）。在 GNOME Shell 的終端仿真器中提供了搜索預測功能。增強了對 “GNOME 軟件”和高分辨率顯示屏的支持。提供了新的錄音工具。增加了新的桌面通知接口。在向 Wayland 移植的進度中達到了可用的程度，可用選擇性地預覽體驗。

GNOME 3.14, 2014

更炫酷的桌面環境效果，改善了對觸摸屏的支持。“GNOME 軟件”可以管理安裝的插件。在“GNOME 照片”中可以訪問 “Google 相冊”。重繪了 Evince、數獨、掃雷和天氣應用的用户界面，同時增加了一款叫做 Hitori 的 GNOME 遊戲。

GNOME 3.16, 2015

33000 處改變。主要的修改包括 UI 的配色方案從黑色變成了炭黑色。 增加了即現式滾動條。通知窗口中整合了日曆應用。對“文件”，圖像查看器和“地圖”等大量應用進行了微調。可以預覽應用程序。進一步從 X11 向 Wayland 移植。
