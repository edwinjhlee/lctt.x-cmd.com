3 個純文本記事工具 ​

記筆記很重要，而純文本是一種簡單、中性的方式。這裏有三個工具，你可以在不失去純文本的簡易和便攜性的前提下，給你的筆記加點東西。

在前幾年，這個年度系列涵蓋了單個的應用。今年，我們除了關注 2021 年的策略外，還將關注一體化解決方案。歡迎來到 2021 年 21 天生產力的第五天。

純文本是最具彈性的文檔格式。純文本文檔體積小，可以在機器之間快速傳輸，並且可以在任意設備上閲讀。因此，在純文本文檔中做筆記是很有意義的。

然而，純文本也僅是純文本。我們生活在一個富文本世界中，我們仍然需要標題、列表以及區分一個章節和另一個章節的方法。幸運的是，我們有幾種方法可以添加這些元素，而不需要在純文本文檔中添加複雜的標記。

Markdown ​

Markdown （Kevin Sonney, CC BY-SA 4.0）

由 Aaron Schwartz 和 John Gruber 創建的 Markdown，是我如今每天使用最多的格式。從讀寫 README 文件、文檔、記筆記，甚至源代碼註釋，Markdown 讓我可以在不犧牲輕鬆閲讀文檔的能力的情況下添加格式。

此外，Markdown 還有幾個“擴展版本”，以允許那些不屬於原始設計的項目。特別是，GitHub 風格的 Markdown 由於其在同名的源碼控制網站中的使用而異常流行。

許多文件編輯器都支持 Markdown 高亮顯示，不需要額外的附加組件或工作。

AsciiDoc ​

AsciiDoc （Kevin Sonney, CC BY-SA 4.0）

由 Stuart Rackham 創建的 AsciiDoc 是向純文本文檔添加富文本元素的另一種方式。AsciiDoc 有許多生成文檔、書籍和論文的功能。然而，這並不意味着它不能被用來做筆記。有很多環境（特別是在教育和研究領域），能夠快速將筆記轉換為更“正式”的格式是很有幫助的。

AsciiDoc 也有很多工具可以將文本轉換為其他格式進行協作。還有一些附加組件可以從不同的源導入數據，並將其放入最終的文檔中，或者處理特殊的格式，如 MathML 或 LaTeX。

Org 模式 ​

ORG-Mode （Kevin Sonney, CC BY-SA 4.0）

説到文本格式，我不能不提 Org 模式。它最初是為 GNU Emacs 設計的，現在已經成為筆記、待辦事項、文檔等常用的純文本格式之一。Org 模式可以在包括 Vim 在內的眾多文本編輯器中編寫和使用。Org 模式簡單、易學，是我最喜歡的筆記文本格式之一。

最後，選擇 Markdown、AsciiDoc 或 Org 模式作為純文本筆記，是確保它們可以在任何地方被閲讀和更新的一種方式。如果你和我一樣，你會發現自己在做紙質筆記的時候，也會使用同樣的語法！
