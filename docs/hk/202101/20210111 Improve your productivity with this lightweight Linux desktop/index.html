ElementaryOS：使用這個輕量級 Linux 桌面提高你的工作效率 ​

ElementaryOS 提供了一個快速、輕量、高效的桌面，讓你在新的一年裏保持工作效率。

在前幾年，這個年度系列報道了各個應用程序。今年，我們將在 2021 年尋求幫助的策略之外，還將關注一站式解決方案。歡迎來到 2021 年 21 天生產力的第一天。

當尋求提高生產率的工具時，很容易將幾乎能用但不能完全很好地發揮作用的應用集合在一起。在過去的幾年裏，我們已經談到了單個的電子郵件應用、日曆應用、記事本應用等等。不過，總會有些麻煩。要麼需要自定義腳本，要麼需要複雜的導出/導入步驟才能使一個工具工作。

ElementaryOS 是一個完整的桌面，具有美觀、實用、高效的環境。

ElementaryOS 桌面 （Kevin Sonney， CC BY-SA 4.0）

ElementaryOS 是一個基於流行的 Ubuntu Linux 發行版的“按需付費”開源項目。對於過去安裝過 Ubuntu 的人來説，初始設置和安裝會非常熟悉。然而，一旦登錄，體驗就會很不一樣。

ElementaryOS 使用 Gala 窗口管理器和 Pantheon shell。這兩個都是專門為 Elementary 開發的。安裝後，桌面非常精簡，它只提供了少量的輕量級應用。這些應用包括 Web 瀏覽器、終端、郵件客户端和日曆客户端。它還有一個應用中心，允許你安裝 Elementary 團隊策劃的免費和商業應用。

ElementaryOS 的郵件和日曆應用（Kevin Sonney， CC BY-SA 4.0）

郵件和日曆這兩個應用看起來很熟悉，因為這兩個應用已經被其他發行版使用了一段時間。郵件是作為 Geary 的復刻分支開始的，而日曆在其他地方則被稱為 Maya。兩者的設置非常簡單。兩款應用默認僅使用用户名/密碼認證，所以需要雙因素認證的用户需要一些額外的步驟。兩者的界面都異常輕巧快速。

應用中心（Kevin Sonney，CC BY-SA 4.0）

ElementaryOS 默認不包含待辦事項或記事本應用。這時，應用中心就可以發揮作用了。在應用中心中，有大量的應用可以填補空白。其中有兩款應用真的很出色。第一個是 Planner，一款簡潔、輕量級的待辦事項管理器。它支持多個列表、計劃和重複性任務、項目和子項目。它還可以與流行的在線應用 Todoist 同步，但這不是必需的。

應用中心的第二款應用是 Notes-Up，這是一款使用 Markdown 寫富文本格式的筆記應用。它允許用户在多個筆記本中創建多個筆記，並且有“查看”和“編輯”選項，這樣你就可以預覽最終文檔的樣子。同樣，這款應用快速、輕量而且非常簡約，與 ElementaryOS 的整體外觀和感覺保持一致。

Planner 和 Notes-up （Kevin Sonney，CC BY-SA 4.0）

如果你不喜歡默認應用，Elementary 基於 Ubuntu LTS，因此如果你需要使用其他應用，整個 Ubuntu 應用生態系統都可以使用。不過總的來説，ElementaryOS 默認提供了一個快速、輕量、高效的桌面，讓你在新的一年裏保持高效。
