2021 的 8 個開源軟件速查表 ​

當那個討厭的命令就在你的指間，但是就是想不起來，一個方便的速查表就可以拯救你。這份速查表清單涵蓋了從編程語言到協作工具的各種內容。

有時候，你需要一個簡短的提示。你知道自己想做什麼，但就是想不起具體怎麼做。這時候速查表就派上用場了。在這篇文章中，我給大家提供了 MariaDB 和 MySQL 的速查表。這個速查表對於偶爾使用資料庫的人來説是非常有用的。接下來，我列出了兩個樹莓派速查表。第一張可以讓你入門這台單板計算機。一旦你有了一定的基礎知識，就可以把它變成一個家庭實驗室，可以開始使用 Kubernetes 進行容器管理。一定要同時看看下一張速查表，因為它涵蓋了 kubectl 工具。接下來，有一個很棒的 Emacs 的速查表，以及還有一個 C 編程語言的速查表。最後，這個列表以兩個非常實用的速查表結束：協作工具和開源替代品。

下面是這份清單：

MariaDB 和 MySQL 速查表 ​

MariaDB 是一個企業級資料庫。學習 MariaDB 是使用它來管理 Web 應用程序或編程語言庫的重要一步。這個 MariaDB 和 MySQL 速查表涵蓋了連接到服務器、分析數據和其他關鍵活動的有用命令。本速查表上的命令對交互式提示符和 SQL 腳本有效，但很多內容推斷可以用於編程庫。

樹莓派：如何入門 ​

自 2012 年以來，樹莓派一直是學習編程技能、構建硬件項目、進行家庭自動化和創建應用程序的必備工具。它實惠的價格使它對任何技能水平的開源愛好者都有吸引力。這本可下載的指南將為你提供挑選樹莓派、保持更新、使用它進行 Linux 遊戲、為社區做貢獻等方面的提示，讓你獲得成功。

在你的樹莓派家庭實驗室上運行 Kubernetes ​

由於樹莓派單板計算機的經濟性和多功能性，建立一個家庭實驗室變得越來越容易。你可以用樹莓派做成千上萬的事情，包括實驗 Kubernetes。在這本電子書中，作者 Chris Collins 演示瞭如何開始在樹莓派上運行 Kubernetes。本指南的每個部分都可以單獨學習，也可以作為一個整體項目來學習。無論你的日常工作是什麼，閲讀這些教程並按照自己的節奏進行嘗試，一定會提升你的雲技術實力。

kubectl 速查表 ​

kubectl 是維護 Kubernetes 集羣的強大命令列工具。這個 2 頁的速查表涵蓋了常用的命令，讓你超越一般的集羣管理。它分為三個不同的部分，包括基本命令、故障排除命令和高級命令。掌握這九個關鍵的 kubectl 命令，可以幫助你排除故障和管理 Kubernetes 集羣。

Emacs 速查表 ​

要記住每一個 Emacs 的快捷鍵幾乎是不可能的。通過這個速查表，你可以熟悉最常見的組合，從而提高工作效率。當你有這個指南在身邊時，你可以不用擔心忘記 Emacs 鍵盤快捷鍵。通過學習這個速查表中演示的基本鍵盤快捷鍵，成為 Emacs 高手。

C 語言編程速查表 ​

C 是一種直接的編譯編程語言。許多其他編程語言從 C 語言中借用了概念，如果你想學習 Lua、C++、Java 或 Go 等編程語言，C 語言是一個很好的起點。Jim Hall 的這份雙面速查表包含了所有的基礎知識，因此你可以立即獲得 C 語法的所有要領。通過下載這個速查表來學習 C 語言，並將語法要領隨身攜帶。

5 個開源協作工具 ​

Kevin Sonney 的生產力指南通過五個開源工具教程讓協作變得輕而易舉。下載的速查表所涉及的工具包括開源郵件客户端、Google Docs 的替代方案等。讓團隊溝通不暢成為過去，迎接團隊生產力的提升。

開放源碼軟件替代方案速查表 ​

在我們廣闊的開源世界裏，有很多通用的專有軟件工具的替代品。然而，有時要找到合適的開源替代品以滿足你的特定需求是令人生畏的。這就是為什麼我們整理了這一頁的速查表，涵蓋了主要的軟件工具類別，包括團隊聊天、文件共享、文字處理等。我們並沒有止步於辦公工具。我們還包括遊戲、社交媒體和個人理財的頂級開源應用。通過這個速查表，可以快速找到常見的專有軟件工具的替代品。

總結 ​

這個列表涵蓋了很多主題。在我們的下載頁面上可以查看更多的速查表和指南。請在下面的評論中告訴我們你最喜歡的是哪一個。不要忘了為你最喜歡的開源工具寫和提交速查表。
