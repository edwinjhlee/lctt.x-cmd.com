5 個適用於 Linux 的流式音頻播放器 ​

當我工作的時候，我會一直在後台播放音樂。大多數情況下，這些音樂是以黑膠唱片的形式在轉盤上旋轉。但有時我不想用這種單純的方法聽音樂時，我會選擇聽流媒體音頻應用程序的方式。然而，由於我工作在 Linux 平台上，所以我只可以使用在我的操作系統上運行良好的軟件。幸運的是，對於想在 Linux 桌面聽流式音頻的人來説，有很多工具可以選擇。

事實上，Linux 為音樂流媒體提供了許多可靠的產品，我將重點介紹我最喜歡的五種用於此任務的工具。警告一句，並不是所有的玩意都是開源的。但是如果你不介意在你的開源桌面上運行一個專有的應用程序，你有一些非常棒的選擇。讓我們來看看有什麼可用的。

Spotify ​

Linux 版的 Spotify 不是那種在你啓動就閃退的愚蠢的、半生不熟的應用程序，也沒有閹割什麼功能。事實上，Spotify 的 Linux 版本與其他平台上的版本完全相同。使用 Spotify 流媒體客户端，你可以收聽音樂和播客、創建播放列表、發現新的藝術家等等。Spotify 界面（圖 1）非常易於導航和使用。

圖 1：Spotify 界面可以很容易地找到新的音樂和舊的收藏。

你可以使用 snap（使用 sudo snap install Spotify 命令）安裝 Spotify，也可以使用以下命令從官方存儲庫安裝 Spotify：

sudo apt-key adv --keyserver hkp://keyserver.ubuntu.com:80 --recv-keys 931FF8E79F0876134EDDBDCCA87FF9DF48BF1C90
sudo echo deb http://repository.spotify.com stable non-free | sudo tee /etc/apt/sources.list.d/spotify.list
sudo apt-get update
sudo apt-get install spotify-client

一旦安裝，你就可以登錄你的 Spotify 帳户，這樣你就可以開始聽好聽的音樂，以幫助激勵你完成你的工作。如果你已在其他設備上安裝了 Spotify（並登錄到同一帳户），則可以指定音樂應該流式傳輸到哪個設備（通過單擊 Spotify 窗口右下角附近的“可用設備”圖標）。

Clementine ​

Clementine 是 Linux 平台上最好的音樂播放器之一。Clementine 不僅允許用户播放本地存儲的音樂，還可以連接到許多流媒體音頻服務，例如：

  • Amazon Cloud Drive
  • Box
  • Dropbox
  • Icecast
  • Jamendo
  • Magnatune
  • RockRadio.com
  • Radiotunes.com
  • SomaFM
  • SoundCloud
  • Spotify
  • Subsonic
  • Vk.com
  • 或其他有趣的電台

使用 Clementine 有兩個注意事項。首先，你必須使用最新版本（因為某些軟件庫中可用的構建版本已過時，並且不會安裝必要的流式處理插件）。第二，即使是最新的構建版本，一些流媒體服務也不會像預期的那樣工作。例如，接入 Spotify 頻道時，你只能使用最熱門的曲目（而無法使用播放列表，或搜索歌曲的功能）。

使用 Clementine 互聯網流媒體服務時，你會發現其中有很多你從來沒有聽説過的音樂家和樂隊（圖 2）。

圖 2：Clementine 互聯網廣播是尋找新音樂的好方法。

Odio ​

Odio 是一個跨平台的專有應用程序（可用於 Linux、MacOS 和 Windows），它允許你流式傳輸各種類型的互聯網音樂站。廣播的內容是取自 www.radio-browser.info，而應用程序本身在為你呈現流方面做了令人難以置信的工作（圖 3）。

圖 3：Odio 接口是你能找到的最好的接口之一。

Odio 讓你很容易找到獨特的互聯網廣播電台，甚至可以把你找到並收藏的電台添加到你的庫中。目前，在 Linux 上安裝 Odio 的唯一方法是通過 Snap。如果你的發行版支持 snap 軟件包，請使用以下命令安裝此流應用程序：

sudo snap install odio

安裝後，你可以打開應用程序並開始使用它。無需登錄（或創建）帳户。Odio 的設置非常有限。實際上，它只提供了在設置窗口中選擇暗色主題或亮色主題的選項。然而，儘管它可能功能有限，但 Odio 是在 Linux 上播放互聯網廣播的最佳選擇之一。

StreamTuner2 ​

Streamtuner2 是一個優秀的互聯網電台 GUI 工具。使用它，你可以流式播放以下音樂：

  • Internet radio stations
  • Jameno
  • MyOggRadio
  • Shoutcast.com
  • SurfMusic
  • TuneIn
  • Xiph.org
  • YouTube

Streamtuner2 提供了一個很好的界面（如果不是有點過時的話），可以很容易地找到和播放你喜愛的音樂。StreamTuner2 的一個警告是，它實際上只是一個用於查找你想要聽到的流媒體的 GUI。當你找到一個站點時，雙擊它打開與流相關的應用程序。這意味着你必須安裝必要的應用程序，才能播放流媒體。如果你沒有合適的應用程序，你就不能播放流媒體。因此，你將花費大量的時間來確定要為某些流媒體安裝哪些應用程序（圖 4）。

圖4：配置 Streamtuner2 需要一個堅強的心臟。

VLC ​

很長一段時間以來，VLC 一直被稱為 Linux 最好的媒體播放工具。這是有充分理由的，因為幾乎所有你丟給它的東西它都能播放。其中包括流媒體廣播電台。雖然你無法讓 VLC 連接到 Spotify 這樣的網站，但你可以直接訪問互聯網廣播，點擊播放列表，而 VLC 毫無疑問可以打開它。考慮到目前有很多互聯網廣播電台，你在尋找適合自己口味的音樂方面不會有任何問題。VLC 還包括可視化工具、均衡器（圖 5）等工具。

圖 5：VLC 可視化工具和均衡器特性。

VLC 唯一需要注意的是，你必須有一個你希望聽到的互聯網廣播的 URL，因為這個工具本身並不能進行管理。但是有了這些鏈接，你就找不到比 VLC 更好的媒體播放器了。

這些工具軟件怎麼來的 ​

如果這五個工具都不太不適合你的需要，我建議你打開你發行版的應用商店，搜索一個適合你的。有很多工具可以製作流媒體音樂、播客等等，不僅可以在 Linux 上實現，而且很簡單。
