為什麼 Ubuntu 放棄 Unity？創始人如是説 ​

Mark Shuttleworth 是 Ubuntu 的創始人

Ubuntu 之前在 4 月份宣佈決定放棄 Unity 讓包括我在內的所有人都大感意外。

現在，Ubuntu 的創始人 Mark Shuttleworth 分享了關於 Ubuntu 為什麼會選擇放棄 Unity 的更多細節。

答案可能會出乎意料……

或許不會，因為答案也在情理之中。

為什麼 Ubuntu 放棄 Unity？ ​

上週（10 月 20 日）Ubuntu 17.10 已經發布，這是自 2011 年引入 Unity 以來，Ubuntu 第一次沒有帶 Unity 桌面發佈。

當然，主流媒體對 Unity 的未來感到好奇，因此 Mark Shuttleworth 向 eWeek 詳細介紹了他決定在 Ubuntu 路線圖中拋棄 Unity 的原因。

簡而言之就是他把驅逐 Unity 作為節約成本的一部分，旨在使 Canonical 走上 IPO 的道路。

是的，投資者來了。

但是完整採訪提供了更多關於這個決定的更多內容，並且披露了放棄曾經悉心培養的桌面對他而言是多麼艱難。

“Ubuntu 已經進入主流” ​

Mark Shuttleworth 和 Sean Michael Kerner 的談話，首先提醒了我們 Ubuntu 有多麼偉大：

“Ubuntu 的美妙之處在於，我們創造了一個對終端用户免費，並圍繞其提供商業服務的平台，在這個夢想中，我們可以用各種不同的方式定義未來。

我們確實已經看到，Ubuntu 在很多領域已經進入了主流。”

但是受歡迎並不意味着盈利，Mark 指出：

“我們現在所做的一些事情很明顯在商業上是不可能永遠持續的，而另外一些事情無疑商業上是可持續發展的，或者已經在商業上可持續。

只要我們還是一個純粹的私人公司，我們就有完全的自由裁量權來決定是否支持那些商業上不可持續的事情。”

Shuttleworth 説，他和 Canonical 的其他“領導”通過協商一致認為，他們應該讓公司走上成為上市公司的道路。

為了吸引潛在的投資者，公司必須把重點放在盈利領域 —— 而 Unity、Ubuntu 電話、Unity 8 以及融合convergence不屬於這個部分：

“[這個決定]意味着我們不能讓我們的名冊中擁有那些根本沒有商業前景實際上卻非常重大的項目。

這並不意味着我們會考慮改變 Ubuntu 的條款，因為它是我們所做的一切的基礎。而且實際上，我們也沒有必要。”

“Ubuntu 本身現在完全可持續發展” ​

錢可能意味着 Unity 的消亡，但會讓更廣泛的 Ubuntu 項目健康發展。正如 Shuttleworth 解釋説的：

“我最為自豪的事情之一就是在過去的 7 年中，Ubuntu 本身變得完全可持續發展。即使明天我被車撞倒，而 Ubuntu 也可以繼續發展下去。

這很神奇吧？對吧？這是一個世界級的企業平台，它不僅完全免費，而且是可持續的。

這主要要感謝 Jane Silber。” （LCTT 譯註：Canonical 公司的 CEO）

雖然桌面用户都會關注桌面，但比起我們期待的每 6 個月發佈的版本，對 Canonical 公司的關注顯然要多得多。

失去 Unity 對桌面用户可能是一個沉重打擊，但它有助於平衡公司的其他部分：

“除此之外，我們在企業中還有巨大的可能性，比如在真正定義雲基礎設施是如何構建的方面，雲應用程序是如何操作的等等。而且，在物聯網中，看看下一波的可能性，那些創新者們正在基於物聯網創造的東西。

所有這些都足以讓我們在這方面進行 IPO。”

然而，對於 Mark 來説，放棄 Unity 並不容易，

“我們在 Unity 上做了很多工作，我真的很喜歡它。

我認為 Unity 8 工程非常棒，而且如何將這些不同形式的要素結合在一起的深層理念是非常迷人的。”

“但是，如果我們要走上 IPO 的道路，我不能再為將它留在 Canonical 來爭論了。

在某個階段你們應該會看到，我想我們很快就會宣佈，沒有 Unity， 我們實際上已經幾乎打破了我們在商業上所做的所有事情。”

在這之後不久，他説公司可能會進行第一輪用於增長的投資，以此作為轉變為正式上市公司前的過渡。

但 Mark 並不想讓任何人認為投資者會 “毀了派對”：

“我們還沒淪落到需要根據風投的指示來行動的地步。我們清楚地看到了我們的客户喜歡什麼，我們已經找到了適用於雲和物聯網的很好的市場着力點和產品。”

Mark 補充到，Canonical 公司的團隊對這個決定 “無疑很興奮”。

“在情感上，我不想再經歷這樣的過程。我對 Unity 做了一些誤判。我曾天真的認為業界會支持一個獨立自由平台的想法。

但我也不後悔做過這件事。很多人會抱怨他們的選擇，而不去創造其他選擇。

事實證明，這需要一點勇氣以及相當多的錢去嘗試和創造這些選擇。”

OMG! IPO? NO! ​

在對 Canonical（可能）成為一家上市公司的觀念進行爭辯之前，我們要記住，RedHat 已經是一家 20 年之久的上市公司了。GNOME 桌面和 Fedora 在沒有任何 “賺錢” 措施的干預下也都活得很不錯。

Canonical 的 IPO 不太可能對 Ubuntu 產生突然的引人注目的的改變，因為就像 Shuttleworth 自己所説的那樣，這是其它所有東西得以成立的基礎。

Ubuntu 是已被認可的。這是雲上的頭號操作系統。它是世界上最受歡迎的 Linux 發行版（除了 Distrowatch 排名）。並且它似乎在物聯網上也有巨大的應用前景。

Mark 説 Ubuntu 現在是完全可持續發展的。

隨着一個迎接 Ubuntu 17.10 到來的熱烈招待會，以及一個新的 LTS 將要發佈，事情看起來相當不錯……
