如何輕鬆記住 Linux 命令 ​

Linux 新手往往對命令列心存畏懼。部分原因是因為需要記憶大量的命令，畢竟掌握命令是高效使用命令列的前提。

不幸的是，學習這些命令並無捷徑，然而在你開始學習命令之初，有些工具還是可以幫到你的。

history ​

首先要介紹的是命令列工具 history，它能幫你記住那些你曾經用過的命令。包括應用最廣泛的 Bash 在內的大多數 Linux shell，都會創建一個歷史文件來包含那些你輸入過的命令。如果你用的是 Bash，這個歷史文件就是 /home/<username>/.bash_history。

這個歷史文件是純文本格式的，你可以用任意的文本編輯器打開來瀏覽和搜索。

apropos ​

確實存在一個可以幫你找到其他命令的命令。這個命令就是 apropos，它能幫你找出合適的命令來完成你的搜索。比如，假設你需要知道哪個命令可以列出目錄的內容，你可以運行下面命令:

shell
apropos "list directory"

這就搜索出結果了，非常直接。給 “directory” 加上覆數後再試一下。

shell
apropos "list directories"

這次沒用了。apropos 所作的其實就是搜索一系列命令的描述。描述不匹配的命令不會納入結果中。

還有其他的用法。通過 -a 標誌，你可以以更靈活的方式來增加搜索關鍵字。試試這條命令:

shell
apropos "match pattern"

你會覺得應該會有一些匹配的內容出現，比如 grep 對嗎? 然而，實際上並沒有匹配出任何結果。再説一次，apropos 只會根據字面內容進行搜索。

現在讓我們試着用 -a 標誌來把單詞分割開來。（LCTT 譯註：該選項的意思是“and”，即多個關鍵字都存在，但是不需要正好是連在一起的字符串。）

shell
apropos "match" -a "pattern"

這一下，你可以看到很多期望的結果了。

apropos 是一個很棒的工具，不過你需要留意它的缺陷。

ZSH ​

ZSH 其實並不是用於記憶命令的工具。它其實是一種 shell。你可以用 ZSH 來替代 Bash 作為你的命令列 shell。ZSH 包含了自動糾錯機制，能在你輸入命令的時候給你予提示。開啓該功能後，它會提示你相近的選擇。在 ZSH 中你可以像往常一樣使用命令列，同時你還能享受到極度安全的網絡以及其他一些非常好用的特性。充分利用 ZSH 的最簡單方法就是使用 Oh-My-ZSH。

速記表 ​

最後，也可能是最間的方法就是使用 速記表。

有很多在線的速記表，比如這個 可以幫助你快速查詢命令。

為了快速查詢，你可以尋找圖片格式的速記表，然後將它設置為你的桌面牆紙。

這並不是記憶命令的最好方法，但是這麼做可以幫你節省在線搜索遺忘命令的時間。

在學習時依賴這些方法，最終你會發現你會越來越少地使用這些工具。沒有人能夠記住所有的事情，因此偶爾遺忘掉某些東西或者遇到某些沒有見過的東西也很正常。這也是這些工具以及因特網存在的意義。
