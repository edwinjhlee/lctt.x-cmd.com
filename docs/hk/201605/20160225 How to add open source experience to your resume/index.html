怎樣將開源經歷添加到你的簡歷中去 ​

在這篇文章中，我將會分享我的方法，讓大家利用開源貢獻在技術領域的求職中脱穎而出，成為強有力的候選者。

凡事預則立，不預則廢。在你即將進入一個新的領域或者正準備熬夜修訂你的簡歷之前，清楚地定義你正在尋找的工作的特徵是值得的。你的簡歷是一部有説服力的作品，因此你必須瞭解你的觀眾，從而讓它發揮出所有的潛力。看你簡歷的可能是任何需要你的技能並且能在預算之內聘用你的人。當編輯簡歷的時候，讀一讀你的簡歷上的內容，同時想像一下，以他們的角度怎麼看待這份簡歷。你看起來像是一個“你”將會聘用的候選人嗎？

我個人認為，對於目標職位的理想候選人所表現出來的關鍵特徵，列出一張清單是很有幫助的。我結合了個人經驗、閲讀工作招聘信息、詢問相同角色的同事等方面來收集這個清單。LinkedIn 和各種會議是尋求一些樂意提供這種建議的人的很好的地方。一些人喜歡談論他們自己，那麼通過邀請他們講述他們自己的一些故事可以幫助你來拓展你的知識面，這樣大家都會感覺很好。當你和其他人談論他們的職業路線時，你不僅將會明白怎樣去得到你想要從事的工作，而且還能知道你應該避免那些容易讓你失去工作機會的特徵或行為。

例如，對於一個不太資深的工作位置來説，關鍵特徵列表可能如下所示：

###技術方面：

  • 擁有 CI (持續集成) 方面的經驗，特別是 Jenkins
  • 深厚的腳本編寫背景，如 Python 和 Ruby
  • 精通 Eclipse IDE
  • 基本的 Git 和 Bash 知識

###個人而言：

  • 自我驅動的學習者
  • 良好的交流和文檔技巧
  • 在團隊開發方面富有經驗（團隊成員）
  • 精通事件跟蹤的工作流

###儘管去申請職位

記住，你沒有必要為了得到一份工作而去滿足上面的工作描述列表中列出的每個標準。

工作細節（JD）描述了這個角色，讓你一開始就知道你即將簽約併為之工作幾年的公司的全部信息，並且這份工作並不會讓你覺得有什麼挑戰性，或者要求你去拓展你的技能。如果你對你無法滿足清單上的技能列表而感到緊張，那麼檢查一下自己是否有來自其他方面的經歷並能與之媲美的技能。例如，即使有些人從來沒有使用過 Jenkins，那他也可能從之前使用過 Buildbot 或者 travis CI 的項目經驗中明白持續集成測試的原則。

如果你正在申請一家大型公司，他們可能擁有一個專門的部門和一套完整的篩選過程來確保他們不會聘用任何不能勝任職位的候選人。也就是説，在你求職的過程中，你所能做的只是提交申請，而決定是否拒絕你是公司管理層的工作。不要過早地將工作拒之門外。

現在你已經知道了你的任務是什麼，並且還知道你將需要讓面試官印象深刻的技巧。下一步要做的取決於你已有的經驗。

製造已經存在的事物之間的關聯 ​

列出一張你過去幾年曾經參與過的所有項目。下面是一條快速得到這張清單的方法，跳轉到你的 Github profile 中的Repositories標籤頁，並且過濾掉 fork 過來的項目。除此之外，檢查下你的清單上是否有曾經處於領導地位的Organizations。如果你已經有了一份簡歷，那麼請確保你已經將你所有的經歷都列在了上面。

考慮下任何一個你曾經作為一個潛在的領導經歷並擁有過特權的 IRC 頻道。檢查下你的 Meetup 和Eventbrite 賬號，並將你曾經組織過或者作為志願者參與過的活動添加到你的清單上。瀏覽你前幾年的日程並且標註所有志願服務，或者有作為導師的經歷，又或者參與過的公共演講。

現在進入了比較艱難的環節了，將清單上列出的必備技能與個人經歷列表上的內容一一對照，我喜歡給該工作所需要的每個特徵用一個字母或者數字作為標記，然後在每一段你經歷或參與過並表現出了某一特徵的地方標記相同的符號。當你不太確定的時候，那就毫不猶豫地標記上它，儘管這樣做更像是在吹噓，但也好過顯示出你的無能。

在我們寫簡歷的時候常常被這樣的情況所困擾，就是我們不願冒着過分吹噓自己的技能的風險。通常應該這樣去想，“那些組織了聚會的人會表現出了更好的領導才能和計劃技巧嗎？”，而不是“當我組織了這個聚會的時候我是否展示出了這些技巧？”。

如果你已經充分了解了你在過去的一兩年裏的業餘時間都是怎麼度過的，而且你寫了很多代碼，那麼你可能現在正面臨着一個令人奇怪的問題，你已經擁有了太多的經驗以至於一張紙的簡歷已經無法容納下這些經驗了。那麼，如果那些列在你的清單上的經驗，但無法證明你嘗試去表現的任何技能的話，那麼請扔掉它們吧。如果這份已經被縮短的簡歷清單上的內容仍然超過一張單頁紙的容量的話，那麼將你的經驗按照一定的優先級排序，例如根據與所需技術的相關經歷或豐富經驗。

在這一方面，顯而易見，如果你想要磨練一個獨特的技能，那麼你就需要一個不錯的經歷。考慮使用一個類似 OpenHatch 的問題聚合器，並用它來尋找一個通過使用你從沒使用過的工具和技術來鍛鍊你的技能的開源項目。

讓你的簡歷更加漂亮 ​

一份簡歷是否美觀取決於它的簡潔度、清晰度和佈局。每一段經歷都應該通過足夠的信息來展示給讀者，並讓他們立刻明白為什麼你要將它包含進去，而且恰到好處。每種類型的信息都應該使用一致的文檔格式來表示，一份含有斜體格式的日期或者右對齊的或者與整體風格不協調的部分絕對會讓人分心。

使用工具來給你的簡歷排版會使之前設定的目標更加容易實現。我喜歡使用 LaTeX，因為它的宏系統能夠使可視化一致性變得更加容易，並且大量的面試官都能一眼就認出它。你的工具的選擇可能是 LibreOffice 或者 HTML，這取決於你的技能和你希望怎樣去發佈你的簡歷。

記住一點，一份以電子方式提交的簡歷可以通過關鍵字被瀏覽到。因此，當你需要描述你的工作經歷的時候使用和工作招聘告示一樣的英文縮寫對你的求職會有很大的幫助。為了讓你的簡歷更加容易被面試官看到，首先就要放上最重要的信息。

程序員通常難以在為文檔排版時量化平衡和佈局。我最喜歡的修改和評估我的文檔中的空格是否處於正確位置的技術，就是全屏顯示我的 PDF 或者打印出來，然後在鏡子裏面查看它。如果你正在使用 LibreOffice Writer，保存一份你的簡歷的副本，然後將你的簡歷中的字體換成一種你看不懂的語言。這兩種技術都強制將你從閲讀的內容中脱離出來，讓你以一種新的方式查看文檔的整體佈局。他們把你從一個“那句話措辭不當！”這樣的批評轉到了注意如“在這行上只有一個字，看起來挺逗”之類的事情。

最後，再次檢查你的簡歷是否在它將要的展示的多媒體上看起來完全正確。如果你以網頁的形式發佈它，那麼在不同屏幕大小的瀏覽器中測試它的效果。如果它是一份 PDF 文檔，那麼在你的手機或者你的朋友的電腦上打開它，並確保它所需要的字體都是可用的。

###接下來的步驟

最後，不要讓你辛苦做出來的簡歷內容浪費了，將它完整的複製到你的 LinkedIn 帳號上（完全使用招聘公告中的流行詞），然後毫無疑問招聘人員就會找到你了。儘管他們描述的工作內容並不是恰好適合你，但是你可以利用他們的時間和興趣來得到關於你的簡歷中有哪些地方好與不好的反饋信息。
