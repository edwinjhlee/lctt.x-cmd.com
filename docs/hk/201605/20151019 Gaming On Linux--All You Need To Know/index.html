Linux上的遊戲：所有你需要知道的 ​

我能在 Linux 上玩遊戲嗎 ？

這是打算投奔 Linux 陣營的人最經常問的問題之一。畢竟，在 Linux 上面玩遊戲經常被認為有點難以實現。事實上，一些人甚至考慮他們能不能在 Linux 上看電影或者聽音樂。考慮到這些，關於 Linux 的平台的遊戲的問題是很現實的。

在本文中，我將解答大多數 Linux 新手關於在 Linux 中打遊戲的問題。例如 Linux 下能不能玩遊戲，如果能的話，在哪裏下載遊戲或者如何獲取有關遊戲的信息。

但是在此之前，我需要説明一下。我不是一個 PC 上的玩家或者説我不認為我是一個在 Linux 桌面遊戲玩家。我更喜歡在 PS4 上玩遊戲並且我不關心 PC 上的遊戲甚至也不關心手機上的遊戲（我沒有給我的任何一個朋友安利糖果傳奇）。這也就是你很少能在 It's FOSS 上很少看見關於 Linux 上的遊戲的原因。

所以我為什麼要提到這個主題？

因為別人問過我幾次有關 Linux 上的遊戲的問題並且我想要寫出來一個能解答這些問題的 Linux 遊戲指南。注意，在這裏我不只是討論在 Ubuntu 上玩遊戲。我討論的是在所有的 Linux 上的遊戲。

我能在 Linux 上玩遊戲嗎 ？ ​

是，但不是完全是。

“是”，是指你能在Linux上玩遊戲；“不完全是”，是指你不能在 Linux 上玩 ‘所有的遊戲’。

感到迷惑了嗎？不必這樣。我的意思是你能在 Linux 上玩很多流行的遊戲，比如反恐精英以及地鐵：最後的曙光等。但是你可能不能玩到所有在 Windows 上流行的最新遊戲，比如實況足球 2015 。

在我看來，造成這種情況的原因是 Linux 在桌面系統中僅佔不到 2%，這樣的佔比使得大多數開發者沒有開發其遊戲的 Linux 版的動力。

這就意味指大多數近年來被提及的比較多的遊戲很有可能不能在 Linux 上玩。不要灰心。還有別的方式在 Linux 上玩這些遊戲，我們將在下面的章節中討論這些方法。但是，在此之前，讓我們看看在 Linux 上能玩的遊戲的種類。

要我説的話，我會把那些遊戲分為四類：

  1. Linux 原生遊戲
  2. Linux 上的 Windows 遊戲
  3. 瀏覽器裏的遊戲
  4. 終端裏的遊戲

讓我們以最重要的一類， Linux 的原生遊戲開始。

1. 在哪裏去找 Llinux 原生遊戲 ？### ​

原生遊戲指的是官方支持 Linux 的遊戲。這些遊戲有原生的 Linux 客户端並且能像在 Linux 上的其他軟件一樣不需要附加的步驟就能安裝在 Linux 上面（我們將在下一節討論）。

所以，如你所見，有一些為 Linux 開發的遊戲，下一個問題就是在哪能找到這些遊戲以及如何安裝。我將列出一些讓你玩到遊戲的渠道。

Steam ​

“Steam 是一個遊戲的分發平台。就如同 Kindle 是電子書的分發平台， iTunes 是音樂的分發平台一樣， Steam 也具有那樣的功能。它提供購買和安裝遊戲，玩多人遊戲以及在它的平台上關注其他遊戲的選項。其上的遊戲被 DRM 所保護。”

兩年以前，遊戲平台 Steam 宣佈支持 Linux ，這在當時是一個大新聞。這是 Linux 上玩遊戲被嚴肅對待的一個跡象。儘管這個決定更多地影響了他們自己的基於 Linux 遊戲平台以及一個獨立 Linux 發行版 Steam OS ，這仍然是令人欣慰的事情，因為它給 Linux 帶來了一大堆遊戲。

我已經寫了一篇詳細的關於安裝以及使用 Steam 的文章。如果你想開始使用 Steam 的話，讀讀那篇文章。

  • 在 Linux 上安裝以及使用 Steam

GOG.com ​

GOG.com 是另一個與 Steam 類似的平台。與 Steam 一樣，你能在這上面找到數以百計的 Linux 遊戲，併購買和安裝它們。如果遊戲支持好幾個平台，你可以在多個操作系統上安裝他們。你可以隨時遊玩使用你的賬户購買的遊戲。你也可以在任何時間下載。

GOG.com 與 Steam 不同的是前者僅提供沒有 DRM 保護的遊戲以及電影。而且，GOG.com 完全是基於網頁的，所以你不需要安裝類似 Steam 的客户端。你只需要用瀏覽器下載遊戲然後安裝到你的系統上。

Portable Linux Games ​

Portable Linux Games 是一個集聚了不少 Linux 遊戲的網站。這家網站最特別以及最好的點就是你能離線安裝這些遊戲。

你下載到的文件包含所有的依賴（僅需 Wine 以及 Perl）並且他們也是與平台無關的。你所需要的僅僅是下載文件並且雙擊來啓動安裝程序。你也可以把文件儲存起來以用於將來的安裝。如果你網速不夠快的話，我很推薦你這樣做。

Game Drift 遊戲商店 ​

Game Drift 是一個只專注於遊戲的基於 Ubuntu 的 Linux 發行版。但是如果你不想只為遊戲就去安裝這個發行版的話，你也可以經常去它的在線遊戲商店去看哪個遊戲可以在 Linux 上運行並且安裝他們。

Linux Game Database ​

如其名字所示，Linux Game Database是一個收集了很多 Linux 遊戲的網站。你能在這裏瀏覽諸多類型的遊戲並從遊戲開發者的網站下載/安裝這些遊戲。作為這家網站的會員，你甚至可以為遊戲打分。 LGDB 有點像 Linux 遊戲界的 IMDB 或者 IGN.

Penguspy ​

此網站由一個不想用 Windows 玩遊戲的玩家創立。Penguspy 聚集了一些 Linux 下最好的遊戲。在這裏你也能分類瀏覽遊戲，如果你喜歡這個遊戲的話，你可以跳轉到遊戲開發者的網站去下載安裝。

軟件源 ​

看看你自己的發行版的軟件源。其中可能有一些遊戲。如果你用 Ubuntu 的話，它的軟件中心裏有一個遊戲的分類。在一些其他的發行版裏也有，比如 Linux Mint 等。

2. 如何在 Linux 上玩 Windows 的遊戲 ？### ​

到現在為止，我們一直在討論 Linux 的原生遊戲。但是並沒有很多 Linux 上的原生遊戲，或者更準確地説，火的不要不要的遊戲大多不支持 Linux，但是都支持 Windows PC 。所以，如何在 Linux 上玩 Windows 的遊戲？

幸好，由於我們有 Wine 、 PlayOnLinux 和 CrossOver 等工具，我們能在 Linux 上玩不少的 Windows 遊戲。

Wine ​

Wine 是一個能使 Windows 應用在類似 Linux ， BSD 和 OS X 上運行的兼容層。在 Wine 的幫助下，你可以在 Linux 下安裝以及使用很多 Windows 下的應用。

在 Ubuntu 上安裝 Wine或者在其他 Linux 上安裝 Wine 是很簡單的，因為大多數發行版的軟件源裏都有它。這裏也有一個很大的 Wine 支持的應用的資料庫供您瀏覽。

CrossOver ​

CrossOver 是 Wine 的增強版，它給 Wine 提供了專業的技術上的支持。但是與 Wine 不同， CrossOver 不是免費的。你需要購買許可。好消息是它會把更新也貢獻到 Wine 的開發者那裏並且事實上加速了 Wine 的開發使得 Wine 能支持更多的 Windows 上的遊戲和應用。如果你可以接受每年支付 48 美元，你可以購買 CrossOver 並得到他們提供的技術支持。

PlayOnLinux ​

PlayOnLinux 也基於 Wine 但是執行程序的方式略有不同。它有着更好用的，不同的界面。與 Wine 一樣，PlayOnLinux 也是免費使用。你可以在開發者自己的資料庫裏查看它支持的應用以及遊戲。

3. 網頁遊戲 ​

不必説你也應該知道有非常多的基於網頁的遊戲，這些遊戲都可以在任何操作系統裏運行，無論是 Windows ，Linux ，還是 OS X 。大多數讓人上癮的手機遊戲，比如帝國之戰就有官方的網頁版。

除了這些，還有 Google Chrome 在線商店，你可以在 Linux 上玩更多的這些遊戲。這些 Chrome 上的遊戲可以像一個單獨的應用一樣安裝並從應用菜單中打開，一些遊戲就算是離線也能運行。

4. 終端遊戲 ​

使用 Linux 的一個附加優勢就是可以使用命令列終端玩遊戲。我知道這不是最好的玩遊戲的方法，但是在終端裏玩貪吃蛇或者 2048 很有趣。在這個Blog中有一些好玩的的終端遊戲。你可以瀏覽並安裝你喜歡的遊戲。

如何保證遊戲的版本是最新的 ？### ​

當你瞭解了不少的在 Linux 上你可以玩到的遊戲以及你如何使用他們，下一個問題就是如何保持遊戲的版本是最新的。對於這件事，我建議你看看下面的Blog，這些Blog能告訴你 Linux 遊戲世界的最新消息：

  • Gaming on Linux：我認為我把它叫做 Linux 遊戲專業門户並沒有錯誤。在這你可以得到關於 Linux 的遊戲的最新的傳言以及新聞。它經常更新， 還有由 Linux 遊戲愛好者組成的優秀社區。
  • Free Gamer：一個專注於免費開源的遊戲的Blog。
  • Linux Game News：一個提供很多的 Linux 遊戲的升級的 Tumbler Blog。

還有別的要説的嗎？ ​

我認為讓你知道如何開始在 Linux 上的遊戲人生是一個好事。如果你仍然不能被説服，我推薦你做個雙系統，把 Linux 作為你的主要桌面系統，當你想玩遊戲時，重啓到 Windows。這是一個對遊戲妥協的解決辦法。
