KDE、GNOME 和 XFCE 桌面比較 ​

這麼多年來，很多人一直都在他們的 linux 桌面端使用 KDE 或者 GNOME 桌面環境。在這兩個桌面環境多年不斷發展的同時，其它的桌面也在持續增加它們的用户規模。舉個例子説，在輕量級桌面環境下，XFCE 一舉成為了最受歡迎的桌面環境，相較於 LXDE 缺少的優美視覺效果，默認配置下的 XFCE 在這方面就可以打敗前者。XFCE 提供的功能特性都能在 GNOME2 下得到，然而，在一些較老的計算機上，它的輕量級的特性卻能取得更好的效果。

桌面主題定製 ​

用户完成安裝之後，XFCE 看起來可能會有一點無趣，因為它在視覺上還缺少一些吸引力。但是，請不要誤解我的話， XFCE 仍然擁有漂亮的桌面，但是對於大多數剛剛接觸 XFCE 桌面環境的人來説，可能它看起來像香草一樣普普通通。不過好消息是當我們想要給 XFCE 安裝新的主題的時候，這會是一個十分輕鬆的過程，因為你能夠快速的找到你喜歡的 XFCE 主題，之後你就可以將它解壓到一個合適的目錄中。從這一點上來説，XFCE 自帶的一個放在“外觀”下的重要的圖形界面工具可以幫助用户更加容易的選擇中意的主題，這可能是目前在 XFCE 上這方面最好用的工具了。如果用户按照上面的建議去做的話，對於想要嘗試使用 XFCE 的任何用户來説都將不存在困難。

在 GNOME 桌面上，用户也可以按照類似上面的方法去做。不過，其中最主要的不同點就是在你做之前，用户必須手動下載並安裝 GNOME Tweak Tool。當然，對於使用來説都不會有什麼障礙，但是對於用户來説，使用 XFCE 安裝和激活主題並不需要去額外去下載安裝各種調整工具，這可能是他們無法忽略的一個優勢。而在 GNOME 上，尤其是在用户已經下載並安裝了 GNOME Tweak tool 之後，你仍將必須確保你已經安裝了“用户主題擴展”。

同 XFCE 一樣，用户需要去搜索並下載自己喜歡的主題，然後，用户可以再次使用 GNOME Tweak tool，並點擊該工具界面左邊的“外觀”按鈕，接着用户便可以直接查看頁面底部並點擊文件瀏覽按鈕，然後瀏覽到那個壓縮的文件夾並打開。當完成這些之後，用户將會看到一個告訴用户已經成功應用了主題的對話框，這樣你的主題便已經安裝完成。然後用户就可以簡單的使用下拉菜單來選擇他們想要的主題。和 XFCE 一樣，主題激活的過程也是十分簡單的，然而，對於因為要使用一個新的主題而去下載一個沒有預先安裝到系統裏面的應用，這種情況也是需要考慮的。

最後，就是 KDE 桌面主題定製的過程了。和 XFCE 一樣，不需要去下載額外的工具來安裝主題。從這點來看，讓人有種XFCE 可能要被 KDE 戰勝了的感覺。不僅在 KDE 上可以完全使用圖形用户界面來安裝主題，而且甚至只需要用户點擊獲取新主題的按鈕就可以找到、查看新的主題，並且最後自動安裝。

然而，我們應該注意到 KDE 相比 XFCE 而言，是一個更加健壯完善的桌面環境。當然，對於主要以極簡設計為目的的桌面來説，缺失一些更多的功能是有一定的道理的。為此，我們要為這樣優秀的功能給 KDE 加分。

MATE 不是一個輕量級的桌面環境 ​

在繼續比較 XFCE、GNOME3 和 KDE 之前，對於老手我們需要澄清一下，我們沒有將 MATE 桌面環境加入到我們的比較中。MATE 可被看作是 GNOME2 的另一個衍生品，但是它並沒有主要作為一款輕量級或者快捷桌面出現。相反，它的主要目的是成為一款更加傳統和舒適的桌面環境，並使它的用户在使用它時就像在家裏一樣舒適。

另一方面，XFCE 生來就是要實現他自己的一系列使命。XFCE 給它的用户提供了一個更輕量而仍保持吸引人的視覺體驗的桌面環境。然後，對於一些認為 MATE 也是一款輕量級的桌面環境的人來説，其實 MATE 真正的目標並不是成為一款輕量級的桌面環境。這兩種選擇在各自安裝了一款好的主題之後看起來都會讓人覺得非常具有吸引力。

桌面導航 ​

XFCE 除了桌面，還提供了一個醒目的導航器。任何使用過傳統的 Windows 或者 GNOME 2/MATE 桌面環境的用户都可以在沒有任何幫助的情況下自如的使用新安裝的 XFCE 桌面環境的導航器。緊接着，添加小程序到面板中也是很顯眼的。就像找一個已經安裝的應用程序一樣，直接使用啓動器並點擊你想要運行的應用程序圖標就行。除了 LXDE 和 MATE 之外，還沒有其他的桌面的導航器可以做到如此簡單。不僅如此，更好的是控制面板的使用是非常容易使用的，對於剛剛使用這個新桌面的用户來説這是一個非常大的好處。如果用户更喜歡通過老式的方法去使用他們的桌面，那麼 GNOME 就不合適。通過熱角而取代了最小化按鈕，加上其他的應用排布方式，這可以讓大多數新用户易於使用它。

如果用户來自類似 Windows 這樣的桌面環境，那麼這些用户需要摒棄這些習慣，不能簡單的通過鼠標右擊一下就將一個小程序添加到他們的工作空間頂部。與此相反，它可以通過使用擴展來實現。GNOME 是可以安裝拓展的，並且是非常的容易，這些容易之處體現在只需要用户簡單的使用位於 GNOME 擴展頁面上的 on/off 開關即可。不過，用户必須知道這個東西，才能真正使用上這個功能。

另一方面，GNOME 正在它的外觀中體現它的設計理念，即為用户提供一個直觀和易用的控制面板。你可能認為那並不是什麼大事，但是，在我看來，它確實是我認為值得稱讚並且有必要被提及的方面。KDE 給它的用户提供了更多的傳統桌面使用體驗，並通過提供相似的啓動器和一種更加類似的獲取軟件的方式的能力來迎合來自 Windows 的用户。添加小部件或者小程序到 KDE 桌面是件非常簡單的事情，只需要在桌面上右擊即可。唯一的問題是 KDE 中這個功能不好發現，就像 KDE 中的其它東西一樣，對於用户來説好像是隱藏的。KDE 的用户可能不同意我的觀點，但我仍然堅持我的説法。

要增加一個小部件，只要在“我的面板”上右擊就可以看見面板選項，但是並不是安裝小部件的一個直觀的方法。你並不能看見“添加部件”，除非你選擇了“面板選項”，然後才能看見“添加部件”。這對我來説不是個問題，但是對於一些用户來説，它變成了不必要的困惑。而使事情變得更復雜的是，在用户能夠找到部件區域後，他們後來發現一種稱為“活動”的新術語。它和部件在同一個地方，可是它在自己的區域卻是另外一種行為。

現在請不要誤解我，KDE 中的活動特性是很不錯的，也是很有價值的，但是從可用性的角度看，為了不讓新手感到困惑，它更加適合於放在另一個菜單項。用户各有不同，但是讓新用户多測試一段時間可以讓它不斷改進。對“活動”的批評先放一邊，KDE 添加新部件的方法的確很棒。與 KDE 的主題一樣，用户不能通過使用提供的圖形用户界面瀏覽和自動安裝部件。這是一個有點神奇的功能，但是它這樣也可以工作。KDE 的控制面板可能和用户希望的樣子不一樣，它不是足夠的簡單。但是有一點很清楚，這將是他們致力於改進的地方。

因此，XFCE 是最好的桌面環境，對嗎？ ​

就我自己而言，我在我的計算機上使用 GNOME、KDE，並在我的辦公室和家裏的電腦上使用 Xfce。我也有一些老機器在使用 Openbox 和 LXDE。每一個桌面的體驗都可以給我提供一些有用的東西，可以幫助我以適合的方式使用每台機器。對我來説，Xfce 是我的心中的摯愛，因為 Xfce 是一個我使用了多年的桌面環境。但對於這篇文章，我是用我日常使用的機器來撰寫的，事實上，它用的是 GNOME。

這篇文章的主要思想是，對於那些正在尋找穩定的、傳統的、容易理解的桌面環境的用户來説，我還是覺得 Xfce 能提供好一點的用户體驗。歡迎您在評論部分和我們分享你的意見。
