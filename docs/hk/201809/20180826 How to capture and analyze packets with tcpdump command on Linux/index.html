如何在 Linux 上使用 tcpdump 命令捕獲和分析數據包 ​

tcpdump 是一個有名的命令列數據包分析工具。我們可以使用 tcpdump 命令捕獲實時 TCP/IP 數據包，這些數據包也可以保存到文件中。之後這些捕獲的數據包可以通過 tcpdump 命令進行分析。tcpdump 命令在網絡層面進行故障排除時變得非常方便。

tcpdump 在大多數 Linux 發行版中都能用，對於基於 Debian 的Linux，可以使用 apt 命令安裝它。

# apt install tcpdump -y

在基於 RPM 的 Linux 操作系統上，可以使用下面的 yum 命令安裝 tcpdump。

# yum install tcpdump -y

當我們在沒用任何選項的情況下運行 tcpdump 命令時，它將捕獲所有接口的數據包。因此，要停止或取消 tcpdump 命令，請鍵入 ctrl+c。在本教程中，我們將使用不同的實例來討論如何捕獲和分析數據包。

示例：1）從特定接口捕獲數據包 ​

當我們在沒用任何選項的情況下運行 tcpdump 命令時，它將捕獲所有接口上的數據包，因此，要從特定接口捕獲數據包，請使用選項 -i，後跟接口名稱。

語法：

# tcpdump -i {接口名}

示例：5）捕獲數據包並將其保存到文件（-w 選項） ​

使用 tcpdump 命令中的 -w 選項將捕獲的 TCP/IP 數據包保存到一個文件中，以便我們可以在將來分析這些數據包以供進一步分析。

語法：

# tcpdump -w 文件名.pcap -i {接口名}

注意：文件擴展名必須為 .pcap。

假設我要把 enp0s3 接口捕獲到的包保存到文件名為 enp0s3-26082018.pcap。

[root@compute-0-1 ~]# tcpdump -w enp0s3-26082018.pcap -i enp0s3

上述命令將生成如下所示的輸出，

[root@compute-0-1  ~]# tcpdump -w enp0s3-26082018.pcap -i enp0s3
tcpdump: listening on enp0s3, link-type EN10MB (Ethernet), capture size 262144 bytes
^C841 packets captured
845 packets received by filter
0 packets dropped by kernel
[root@compute-0-1  ~]# ls
anaconda-ks.cfg enp0s3-26082018.pcap
[root@compute-0-1  ~]#

捕獲並保存大小大於 N 字節的數據包。

[root@compute-0-1  ~]# tcpdump -w enp0s3-26082018-2.pcap greater 1024

捕獲並保存大小小於 N 字節的數據包。

[root@compute-0-1  ~]# tcpdump -w enp0s3-26082018-3.pcap less 1024

示例：6）從保存的文件中讀取數據包（-r 選項） ​

[root@compute-0-1 ~]# tcpdump -r enp0s3-26082018.pcap

使用 tcpdump 命令只捕獲兩台主機之間的 SSH 數據包流，

[root@compute-0-1  ~]# tcpdump -w ssh-comm-two-hosts.pcap -i enp0s3 src 169.144.0.1 and port 22 and dst 169.144.0.20 and port 22

示例：13）捕獲兩台主機之間（來回）的 UDP 網絡數據包 ​

語法：

# tcpdump -w -s -i udp and \(host and host \)
[root@compute-0-1  ~]# tcpdump -w two-host-comm.pcap -s 1000 -i enp0s3 udp and \(host 169.144.0.10 and host 169.144.0.20\)
