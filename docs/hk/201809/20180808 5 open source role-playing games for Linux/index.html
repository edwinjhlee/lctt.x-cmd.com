五個 Linux 上的開源角色扮演遊戲 ​

換一個新的身份，並用這些開源的角色扮演遊戲探索新世界。

遊戲是 Linux 的傳統弱項之一，感謝 Steam、GOG 和其他的遊戲開發商將商業遊戲移植到了多個操作系統，Linux 的這個弱項在近幾年有所改觀，但是這些遊戲通常都不是開源的。當然，這些遊戲可以在開源系統上運行，但是對於開源的純粹主義者來説這還不夠好。

那麼，有沒有一款能讓只使用自由開源軟件的人在不影響他們開源理念的情況下也能享受到可靠遊戲體驗的精緻遊戲呢？

當然有啦！雖然開源遊戲不太可能和擁有大量開發預算的 3A 級大作相媲美，但有許多類型的開源遊戲也很有趣，而且它們可以直接從大多數主要的 Linux 發行版的倉庫中進行安裝。即使某個遊戲沒有被某些倉庫打包，你也可以很簡單地從這個遊戲的官網下載它，並進行安裝和運行。

這篇文章着眼於角色扮演遊戲，我已經寫過關於街機遊戲、棋牌遊戲、益智遊戲，以及賽車和飛行遊戲。在本系列的最後一篇文章中，我打算覆蓋戰略遊戲和模擬遊戲這兩方面。

Endless Sky ​

Endless Sky 是 Ambrosia Software 的 Escape Velocity 系列的開源克隆品。玩家乘坐一艘宇宙飛船，在不同的世界之間旅行來運送貨物和乘客，並在沿途中承接其他任務，或者玩家也可以變成海盜，並從其他貨船中偷取貨物。這個遊戲讓玩家自己決定要如何去體驗這個遊戲，以太陽系為背景的超大地圖是非常具有探索性的。Endless Sky 是那些違背正常遊戲類別分類的遊戲之一。但這個兼具動作、角色扮演、太空模擬和交易這四種類型的遊戲非常值得一試。

如果要安裝 Endless Sky ，請運行下面的命令。

在 Fedora 上：

dnf install endless-sky

在 Debian/Ubuntu 上：

apt install endless-sky

FreeDink ​

FreeDink 是 Dink Smallwood 的開源版本，Dink Smallwood 是一個由 RTSoft 在 1997 年發售的動作角色扮演遊戲。Dink Smallwood 在 1999 年時變為了免費遊戲，並在 2003 年時公佈了源代碼。在 2008 年時，遊戲的數據除了少部分的聲音文件，都在開源協議下進行了開源。FreeDink 用一些替代的聲音文件替換了缺少的那部分文件，來提供了一個完整的遊戲。遊戲的玩法類似於任天堂的塞爾達傳説系列。玩家控制的角色和 Dink Smallwood 同名，他在從一個任務地點移動到下一個任務地點的時候，探索這個充滿隱藏物品和隱藏洞穴的世界地圖。由於這個遊戲的年齡，FreeDink 不能和現代的商業遊戲相抗衡，但它仍然是一個擁有着有趣故事的有趣的遊戲。遊戲可以通過 D-Mods 進行擴展，D-Mods 是提供額外任務的附加模組，但是 D-Mods 在複雜性、質量，和年齡適應性上確實有很大的差異。遊戲主要適合青少年，但也有部分額外組件適用於成年玩家。

要安裝 FreeDink ，請運行下面的命令。

在 Fedora 上：

dnf install freedink

在 Debian/Ubuntu 上：

apt install freedink

ManaPlus ​

從技術上講，ManaPlus 本身並不是一個遊戲，它是一個訪問各種大型多人在線角色扮演遊戲的客户端。The Mana World 和 Evol Online 是兩款可以通過 ManaPlus 訪問的開源遊戲，但是遊戲的服務器不在那裏。這個遊戲的 2D 精靈圖像讓人想起超級任天堂遊戲，雖然 ManaPlus 支持的遊戲沒有一款能像商業遊戲那樣受歡迎的，但它們都有一個有趣的世界，並且在絕大部分時間裏都有至少一小部分玩家在線。一個玩家不太可能遇到很多的其他玩家，但通常都能有足夠的人一起在這個 MMORPG 遊戲裏進行冒險，而不是一個需要連接到服務器的單機遊戲。Mana World 和 Evol Online 的開發者聯合起來進行未來的開發，但是對於目前而言，Mana World 的歷史服務器和 Evol Online 提供了不同的遊戲體驗。

要安裝 ManaPlus，請運行下面的命令。

在 Fedora 上：

dnf install manaplus

在 Debian/Ubuntu 上：

apt install manaplus

Minetest ​

使用 Minetest 來在一個開放式世界裏進行探索和創造，Minetest 是 Minecraft 的克隆品。就像它所基於的 Minecraft 一樣，Minetest 提供了一個開放的世界，玩家可以在這個世界裏探索和創造他們想要的一切。Minetest 提供了各種各樣的方塊和工具，對於想要一個比 Minecraft 更加開放的遊戲的人來説，Minetest 是一個很好的替代品。除了基本的遊戲之外，Minetest 還可以通過額外的模組進行可擴展，增加更多的選項。

如果要安裝 Minetest ，請運行下面的命令。

在 Fedora 上：

dnf install minetest

在 Debian/Ubuntu 上：

apt install minetest

NetHack ​

NetHack 是一款經典的 Roguelike 類型的角色扮演遊戲，玩家可以從不同的角色種族、分類和陣營中進行選擇，來探索這個多層次的地下城。這個遊戲的目的就是找回 Yendor 的護身符，玩家從地下層的第一層開始探索，並嘗試向下一層移動，每一層都是隨機生成的，這樣每次都能獲得不同的遊戲體驗。雖然這個遊戲只具有 ASCII 圖形和基本圖形，但是遊戲玩法的深度能夠彌補畫面的不足。玩家如果想要更好一些的畫面的話，可能就需要去查看 NetHack 的 Vulture 了，這個方式可以提供更好的圖像、聲音和背景音樂。

如果要安裝 NetHack ，請運行下面的命令。

在 Fedora 上：

dnf install nethack

在 Debian/Ubuntu 上：

apt install nethack-x11 or apt install nethack-console
