Linux 虛擬機與 Linux 現場鏡像版 ​

Linux 虛擬機與 Linux 現場鏡像版各有優勢，也有不足。

首先我得承認，我非常喜歡頻繁嘗試新的 Linux 發行版本。然而，我用來測試它們的方法根據每次目標而有所不同。在這篇文章中，我們來看看兩種運行 Linux 的模式：虛擬機或現場鏡像版live image。每一種方式都存在優勢，但是也有一些不足。

首次測試一個全新的 Linux 發行版 ​

當我首次測試一個全新 Linux 發行版時，我使用的方法很大程度上依賴於我當前所擁有的 PC 資源。如果我使用台式機，我會在一台虛擬機中運行該發行版來測試。使用這種方法的原因是，我可以下載並測試該發行版，不只是在一個現場環境中，而且也可以作為一個帶有持久存儲的安裝的系統。

另一方面，如果我的 PC 不具備強勁的硬件，那麼通過 Linux 的虛擬機安裝來測試發行版是適得其反的。我會將那台 PC 壓榨到它的極限，誠然，更好的是使用現場版的 Linux 映像，而不是從閃存驅動器中運行。

體驗新的 Linux 發行版本的軟件 ​

如果你有興趣查看發行版本的桌面環境或可用的軟件，那使用它的現場鏡像版就沒錯了。一個現場版環境可以提供給你所預期的全局視角、其所提供的軟件和用户體驗的整體感受。

公平的説，你也可以在虛擬機上達到同樣的效果，但是它有一點不好，如果這麼做會讓更多數據填滿你的磁盤空間。畢竟這只是對發行版的一個簡單體驗。記得我在第一節説過：我喜歡在虛擬機上運行 Linux 來做測試。用這個方式我就能看到如何去安裝它、分區是怎麼樣的等等，而使用現場鏡像版時你就看不到這些。

這種體驗方式通常表明你只想對該發行版本有個大致瞭解，所以在這種情況下，這種只需要付出最小的精力和時間的方式是一種不錯的辦法。

隨身攜帶一個發行版 ​

這種方式雖然不像幾年前那樣普遍，這種隨身攜帶一個 Linux 發行版的能力也許是出於對某些用户的考慮。顯然，虛擬機安裝對於便攜性並無太多幫助。不過，現場鏡像版實際上是十分便攜的。現場鏡像版可以寫入到 DVD 當中或複製到一個閃存盤中而便於攜帶。

從 Linux 的便攜性這個概念上展開來説，當要在一個朋友的電腦上展示 Linux 如何工作，使用一個閃存盤上的現場鏡像版也是很方便的。這可以使你能演示 Linux 如何豐富他們的生活，而不用必須在他們的 PC 上運行一個虛擬機。使用現場鏡像版這就有點雙贏的感覺了。

選擇做雙引導 Linux ​

這接下來的方式是個大工程。考慮一下，也許你是一個 Windows 用户。你喜歡玩 Linux，但又不願意冒險。除了在某些情況下會出些狀況或者識別個別分區時遇到問題，雙引導方式就沒啥挑剔的。無論如何，使用 Linux 虛擬機或現場鏡像版都對於你來説是一個很好的選擇。

現在，我在某些事情上採取了奇怪的立場。我認為長期在閃存盤上運行現場鏡像版要比虛擬機更有價值。這有兩個原因。首先，您將會習慣於真正運行 Linux，而不是在 Windows 之上的虛擬機中運行它。其次，您可以設置閃存盤以包含持久存儲的用户數據。

我知道你會説用一個虛擬機運行 Linux 也是如此，然而，使用現場鏡像版的方式，你絕不會因為更新而被破壞任何東西。為什麼？因為你不會更新你的宿主系統或者客户系統。請記住，有整個 Linux 發行版本被設計為持久存儲的 Linux 發行版。Puppy Linux 就是一個非常好的例子。它不僅能運行在要被回收或丟棄的個人 PC 上，它也可以讓你永遠不被頻繁的系統升級所困擾，這要感謝該發行版處理安全更新的方式。這不是一個常規的 Linux 發行版，而是以這樣的一種方式封閉了安全問題——即持久存儲的現場鏡像版中沒有什麼令人擔心的壞東西。

Linux 虛擬機絕對是一個最好的選擇 ​

在我結束這篇文章時，讓我告訴你。有一種場景下，使用 Virtual Box 等虛擬機絕對比現場鏡像版更好：記錄 Linux 發行版的桌面環境。

例如，我製作了一個視頻，裏面介紹和點評了許多 Linux 發行版。使用現場鏡像版進行此操作需要我用硬件設備捕獲屏幕，或者從現場鏡像版的軟件倉庫中安裝捕獲軟件。顯然，虛擬機比 Linux 發行版的現場鏡像版更適合這項工作。

一旦你需要採集音頻進行混音，毫無疑問，如果您要使用軟件來捕獲您的點評語音，那麼您肯定希望擁有一個宿主操作系統，裏面包含了一個起碼的捕獲環境的所有基本需求。同樣，您可以使用硬件設備來完成所有這一切，但如果您只是做兼職的視頻/音頻捕獲， 那麼這可能要付出成本高昂的代價。

Linux 虛擬機 VS. Linux 現場鏡像版 ​

你最喜歡嘗試新發行版的方式是哪些？也許，你是那種可以很好地格式化磁盤、將風險置之腦後的人，所以這裏説的這些都是沒用的？

我在網上互動的大多數人都傾向於遵循我上面提及的方法，但是我很想知道哪種方式更加適合你。點擊評論框，讓我知道在體驗 Linux 發行版世界最偉大和最新的版本時，您更喜歡哪種方法。
