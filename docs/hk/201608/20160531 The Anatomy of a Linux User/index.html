深入理解 Linux 用户 ​

一些新的 GNU/Linux 用户很清楚 Linux 不是 Windows，但其他人對此則不甚瞭解，而最好的發行版設計者們則會謹記着這兩種人的存在。

Linux 的核心 ​

不管怎麼説，Nicky 看起來都不太引人注目。她已經三十歲了，卻決定在離開學校多年後回到學校學習。她在海軍待了六年，後來接受了一份老友給她的新工作，想試試這份工作會不會比她在軍隊的工作更有前途。這種換工作的事情在戰後的軍事後勤處非常常見。我正是因此而認識的她。她那時是一個八個州的貨車運輸業中介組織的區域經理，而那會我在達拉斯跑肉品包裝工具的運輸。

Nicky 和我在 2006 年成為了好朋友。她很外向，幾乎每一個途經她負責的線路上的人她都樂於接觸。我們經常星期五晚上相約去一家室內激光槍戰中心打真人 CS。像這樣一次就打三個的半小時戰役對我們來説並不鮮見。或許這並不像彩彈遊戲（LCTT 譯註：一種軍事遊戲，雙方以汽槍互射彩色染料彈丸，對方被擊中後衣服上會留下彩色印漬即表示“被消滅”——必應詞典）一樣便宜，但是它很有臨場感，還稍微有點恐怖遊戲的感覺。某次活動的時候，她問我能否幫她維修電腦。

她知道我在為了讓一些貧窮的孩子能擁有他們自己的電腦而奔走，當她抱怨她的電腦很慢的時候，我開玩笑地説她可以給比爾蓋茨的 401k 計劃交錢了（LCTT 譯註：401k 計劃始於20世紀80年代初，是一種由僱員、僱主共同繳費建立起來的完全基金式的養老保險制度。此處隱喻需要購買新電腦而向比爾蓋茨的微軟公司付費軟件費用。）。Nicky 卻説這是瞭解 Linux 的最佳時間。

她的電腦是品牌機，是個帶有 Dell 19'' 顯示器的 2005 年中款的華碩電腦。不幸的是，這台電腦沒有好好照料，上面充斥着所能找到的各種關都關不掉的工具欄和彈窗軟件。我們把電腦上的文件都做了備份之後就開始安裝 Linux 了。我們一起完成了安裝，並且確信她知道了如何分區。不到一個小時，她的電腦上就有了一個“金閃閃”的 PCLinuxOS 桌面。

在她操作新系統時，她經常評論這個系統看起來多麼漂亮。她並非隨口一説；她為眼前光鮮亮麗的桌面着了魔。她説她的桌面漂亮的就像化了“彩妝”一樣。這是我在安裝系統期間特意設置的，我每次安裝 Linux 的時候都會把它打扮的漂漂亮亮的。我希望這些桌面讓每個人看起來都覺得漂亮。

大概第一週左右，她通過電話和郵件問了我一些常規問題，而最主要的問題還是她想知道如何保存她 OpenOffice 文件才可以讓她的同事也可以打開這些文件。教一個人使用 Linux 或者 Open/LibreOffice 的時候最重要的就是教她保存文件。大多數用户在彈出的對話框中直接點了保存，結果就用默認的開放文檔格式（Open Document Format）保存了，這讓他們吃了不少苦頭。

曾經有過這麼一件事，大約一年前或者更久，一個高中生説他沒有通過期末考試，因為教授不能打開包含他的論文的文件。這引來了一些讀者的激烈評論，大家都不知道這件事該怪誰，這孩子沒錯，而他的教授，似乎也沒錯。

我認識的一些大學教授他們每一個人都知道怎麼打開 ODF 文件。另外，那個該死的微軟在這方面做得真 XX 的不錯，我覺得微軟 Office 現在已經能打開 ODT 或者 ODF 文件了。不過我也不確定，畢竟我從 2005 年就沒用過 Microsoft Office 了。

甚至在過去糟糕的日子裏，微軟公開而悍然地通過產品綁架的方式來在企業桌面領域推行他們的軟件時，我和一些微軟 Office 的用户在開展業務和洽談合作時從來沒有出現過問題，因為我會提前想到可能出現的問題並且不會有僥倖心理。我會發郵件給他們詢問他們正在使用的 Office 版本。這樣，我就可以確保以他們能夠讀寫的格式保存文件。

説回 Nicky ，她花了很多時間學習她的 Linux 系統。我很驚奇於她的熱情。

當人們意識到需要拋棄所有的 Windows 的使用習慣和工具的時候，學習 Linux 系統就會很容易。甚至在告訴那些淘氣的孩子們如何使用之後，再次回來檢查的時候，他們都不會試圖把 .exe 文件下載到桌面上或某個下載文件夾。

在我們通常討論這些文件的時候，我們也會提及關於更新的問題。長久以來我一直反對在一台機器上有多個軟件安裝系統和更新管理軟件。以 Mint 來説，它完全禁用了 Synaptic 中的更新功能，這讓我失去興趣。但是即便對於我們這些仍然在使用 dpkg 和 apt 的老傢伙們來説，睿智的腦袋也已經開始意識到命令列對新用户來説並不那麼温馨而友好。

我曾嚴正抗議並強烈譴責 Synaptic 功能上的削弱，直到它説服了我。你記得什麼時候第一次使用的新打造的 Linux 發行版，並擁有了最高管理權限嗎？ 你記得什麼時候對 Synaptic 中列出的大量軟件進行過梳理嗎？你記得怎樣開始安裝每個你發現的很酷的程序嗎？你記得有多少這樣的程序都是以字母"lib"開頭的嗎？

我也曾做過那樣的事。我安裝又弄壞了好幾次 Linux，後來我才發現那些庫（lib）文件是應用程序的螺母和螺栓，而不是應用程序本身。這就是 Linux Mint 和 Ubuntu 幕後那些聰明的開發者創造了智能、漂亮和易用的應用安裝器的原因。Synaptic 仍然是我們這些老玩家愛用的工具，但是對於那些在我們之後才來的新手來説，有太多的方式可以讓他們安裝庫文件和其他類似的包。在新的安裝程序中，這些文件的顯示會被摺疊起來，不會展示給用户。真的，這才是它應該做的。

除非你要準備好了打很多支持電話。

現在的 Linux 發行版中藏了很多智慧的結晶，我也很感謝這些開發者們，因為他們，我的工作變得更容易。不是每一個 Linux 新用户都像 Nicky 這樣富有學習能力和熱情。她對我來説就是一個“裝好就行”的項目，只需要為她解答一些問題，其它的她會自己研究解決。像她這樣極具學習能力和熱情的用户的畢竟是少數。這樣的 Linux 新人任何時候都是珍稀物種。

很不錯，他們都是要教自己的孩子使用 Linux 的人。
