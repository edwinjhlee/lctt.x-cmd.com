Ubuntu 14.04 上 最好的 GNOME Shell 主題 ​

最好的方式來自定義你的 Linux 桌面就是使用自定義主題。假如你在 Ubuntu 14.04 中安裝 GNOME 或 在 Ubuntu 14.10 中安裝了 GNOME，你或許想改變默認的主題以呈現出不同的外觀。在這裏，為了幫助你完成該任務，我已經編制好了一個列表—— Ubuntu 或其他已經安裝了 GNOME shell 的 Linux 操作系統中，最好的 GNOME Shell 主題 。但在我們揭曉這份列表之前， 讓我們先了解如何在 GNOME shell 中安裝和應用新的主題。

在 GNOME Shell 中安裝主題 ​

要在帶有 GNOME 桌面的 Ubuntu 中安裝新的主題，你可以使用 Gnome Tweak Tool，它可以在 Ubuntu 軟件庫中得到。打開一個終端窗口並使用如下命令：

sudo apt-get install gnome-tweak-tool

或者，你可以通過把主題放置到 ~/.themes 目錄中來使用。如果你需要，我已經寫了一個關於 如何安裝和使用 GNOME shell的具體教程。

最好的 GNOME Shell 主題 ​

下面列舉的主題都已經在 GNOME Shell 3.10.4 上進行了測試，但對於任何版本的 GNOME 3 或更高的版本，它們應該同樣適用。需要指出的是，這些主題並沒有按照任何優先順序排列。下面就讓我們看看這些最好的 GNOME 主題：

Numix ​

任何沒有提到 Numix 主題 的列表都是不完整的。這個主題是如此地受歡迎以至於 Numix 團隊開發出一個新的 Linux 操作系統， Ozon。考慮到他們的設計作品 Numix 主題，把不久將發行的 Ozon 稱為 最美麗的 Linux 操作系統 也不為過。

使用下面的命令，在基於 Ubuntu 的發行版本中安裝 Numix 主題：

sudo apt-add-repository ppa:numix/ppa
sudo apt-get update
sudo apt-get install numix-icon-theme-circle

Elegance Colors ​

另一個美麗主題來自 Numix 團隊成員之一 Satyajit Sahoo。Elegance Colors 擁有自己的 PPA (譯者注： 即 Personal Package Archive 的縮寫) 使得你可以輕鬆安裝它：

sudo add-apt-repository ppa:satyajit-happy/themes
sudo apt-get update
sudo apt-get install gnome-shell-theme-elegance-colors

Moka ​

Moka 是另一個迷人的主題，它總是位於美麗的主題列表之中。它是由 Unity Tweak Tool 的開發者所設計。 Moka 是你一定要嘗試的主題:

sudo add-apt-repository ppa:moka/stable
sudo apt-get update
sudo apt-get install moka-gnome-shell-theme

Viva ​

基於 GNOME 的默認主題 Adwaita， Viva 是一個帶有黑色和橙色陰影的美麗主題。你可以從下面的鏈接中下載 Viva：

  • Download Viva GNOME Shell Theme

Ciliora-Prima ​

以前它以 Zukitwo Dark 的名字為人們熟知， Ciliora-Prima 是一個擁有方塊圖標的主題，可使用的三種版本之間彼此略有不同。你可以從下面的鏈接中下載它們：

  • Download Ciliora-Prima GNOME Shell Theme

Faience ​

Faience 作為一個受歡迎的主題已經有一段時間了。你可以通過下面的 PPA 為 GNOME 3.10 及更高版本安裝 Faience：

sudo add-apt-repository ppa:tiheum/equinox
sudo apt-get update
sudo apt-get install faience-theme

Paper [不完善] ​

自從 Google 提出 Material Design，人們一直為之瘋狂。Paper GTK 主題受 Google Material design 啓發，作者為 Sam Hewitt( Moka 項目開發者之一)；它正處於開發中，這意味着當前你還不能擁有 Paper 的最好體驗。假如你和我一樣，具有一點實驗精神，你絕對可以試一試。

sudo add-apt-repository ppa:snwh/pulp
sudo apt-get update
sudo apt-get install paper-gtk-theme

以上就是我的列表。如果你正試着給你的 Ubuntu 換一個不同的模樣，你也應該試試這個列表： Ubuntu 14.04 中最好的圖標主題。

你是怎樣找到這份 最好的 GNOME shell 主題 列表的呢？在上面列舉的主題中，哪個是你最中意的？ 如果它沒有在這裏列出，請一定在評論中告訴我們哪個是你心目中最好的 GNOME shell 主題 。
