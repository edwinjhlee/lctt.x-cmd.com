為什麼 Mac 用户不選擇 Linux ​

Linux 與 Mac 用户至少有一個共同點：他們都不太喜歡用 Windows。但除了這點外，二者再也無法達成其他共識，只得分道揚鑣。為什麼 Mac 用户不選擇 Linux 呢？是什麼因素致使 Mac 用户做出了這種選擇的？

Datamation 就此問題做了一番調查，並試圖進行解答。Datamation 的結論是，所有原因都只歸結於眾多應用及工作流程，而非操作系統的關係：

…某些事例表明，嘗試用新應用代替現有應用，並不是很實際 - 對工作流程和整體實用性來説都是如此。但不幸的是，蘋果在這些方面做得非常好。因此，在幾乎不可能改變這些事實的情況下，想要拉攏那些 Mac忠實用户實在是很大的挑戰。

不過老實來説，除了 Web 開發者，我還沒見過 Mac 用户僅僅為了避免升級到 OS X Yosemite 而 “ en masse”(法語：共同，一起) 嘗試變更他們的工作流程。誠然，經歷過 Yosemite 更新後 - 考慮過權限的用户應該會發現這方面已經變得非常令人討厭。並且，OS X 除了在 UI 方面的微小變化，幾乎沒有改變，針對現有 Mac 用户的核心工作流程也在最大程度上保持了原樣。

但，我相信 Linux 在未來將會繼續保持多樣化特點。Linux 會繼續成長，但絕不是經過精確計量般得一成不變。

我大體上同意 Datamation 關於應用和工作流程重要性的結論，在選擇操作系統時這兩方面是必須要考慮顧及的。但我認為對 Mac 用户來説，選擇 Mac 有比這兩方面更重要的因素。我相信是不同的心態造就了 Linux 和 Mac 用户，並且我認為這才是為什麼 Mac 用户不選擇 Linux 的真實原因。

控制權才是 Linux 用户最看重的地方 ​

Linux 用户傾向於控制電腦上的所有細節，他們試圖作出一切能做的努力使操作系統變成他們想要的樣子。但這種方式並不適用於 OS X 以及其他任何蘋果的產品。如果你使用了蘋果的產品，就意味着絕大多數情況下，你只能按照蘋果預先設定的模式來使用它們。

對 Mac（以及 iOS）用户來説這沒什麼，因為他們似乎並不在乎生活在蘋果那圍牆高築的花園裏，僅僅使用那些蘋果給予他們的標準和選擇。但這對絕大多數 Linux 用户來説是完全不能接受的。Linux 的新用户通常來自 Windows，正是從那裏，他們開始厭惡那些告訴他們什麼才叫操作系統，並試圖限制操作系統權限的東西。

自從他們嚐到使用自由的 Linux 系統所帶來的甜頭之後，他們就再也不會回到蘋果或者微軟的監牢裏去了。即使在他們死後，把 Linux 從他們那冰冷僵硬的手指中撬出來，他們也不會接受蘋果和微軟為他們定製的操作系統。

但絕大部分 Mac 用户不會有這樣的意志和決心。對他們來説當蘋果升級 OS X 時放棄他們現有的習慣方式是非常容易的。在蘋果那圍牆高築的花園裏，即使他們不滿意蘋果的變化，他們也會迅速地接受。

因此，對控制權的渴望是 Mac 用户與 Linux 用户的最大不同。但我並未把它視為一個問題，儘管這反映出使用電腦的兩類用户截然不同的態度。

Mac 用户離不開蘋果的技術支持 ​

Linux 用户與 Mac 用户的區別也體現在 Linux 用户並不介意親自維護自己的電腦。雖然維護電腦及控制操作系統都是很大的責任，但 Linux 用户還是願意獨自承擔，願意通過自己的力量使他們的系統工作得更棒更有效率，並且深入瞭解操作系統是每一位 Linux 用户都樂衷的事情。

當 Linux 用户遇到問題時，他們會迅速地嘗試自己來解決問題。如果這不奏效的話，他們會在網上搜索其他Linux用户的解決方案，並不斷進行嘗試，直到問題解決。

但 Mac 用户卻不大會這樣。這也許是為什麼蘋果零售店如此火爆、為什麼如此多的 Mac 用户在拿到新 Mac 的時候會選擇購買蘋果維護服務的原因。Mac 用户會很輕易得帶着 TA 的電腦去蘋果零售店，走進天才吧並要求蘋果的工作人員為其查看和修復電腦。

絕大多數 Linux 用户連想都不會想這種事情。誰會願意讓一個你都不認識的傢伙碰你的電腦並維修它呢？

因此對 Mac 用户來説，很難拋棄過去可以從蘋果那裏得到的技術支持，轉而使用 Linux。這種選擇會令某些 Mac 用户覺得自己的電腦將變得非常脆弱、容易被攻擊，他們如同離開母親懷抱的嬰兒般充滿了無助感。

Mac 用户喜愛蘋果的硬件 ​

Datamation 發表的文章中主要研究了軟件方面的原因，但我認為硬件因素同樣對 Mac 用户有很大影響。絕大部分 Mac 用户非常喜愛蘋果的硬件。TA 們購買 Mac 並不僅僅是為了 OS X。蘋果那精美的工藝設計也是 Mac 用户購買時着重考慮的一點。Mac 用户願意支付高價購買電腦，因為他們認為這樣絕對是物有所值的。

另一方面，Linux 用户似乎並不會考慮這些東西。我認為他們更關注電腦的花費，而不太在意電腦的外觀和設計。對他們來説，花費最少的金錢來獲取儘可能好的硬件才是最重要的。他們並不像 Mac 用户一樣熱衷於電腦的外觀，因此這一點並不是他們在購買電腦時考慮的地方。

我認為對於硬件的兩種不同觀點是沒有高低之分的。這僅僅和用户的不同需求有關，僅僅會在他們購買電腦時影響他們，或者對某些 Linux 用户來説只是因為他們想要自己組裝電腦而已。兩種觀點只是因為出發點不同、對於電腦的真正價值體現所在之處的理解不同罷了。

當然在 Mac 上運行 Linux 是可能的，直接運行或者間接地通過虛擬機運行。因此真心喜歡蘋果硬件的 Mac 用户是可以選擇在 Mac 上安裝 Linux 的。

Linux 發行版太多了不知道選哪個？ ​

另一個讓 Mac 用户無法選擇 Linux 的原因是：要從眾多 Linux 發行版當中選擇一個實在是太困難了。在大多數 Linuxer 並不抗拒的多元化發行版時代，沒有相關知識的 Mac 用户會對如何選擇感到十分困惑。

我認為，隨着時間的推移，Mac 用户可以學習並找出最適合自己的發行版。但在短時間內，尤其是長時期得使用 OS X 之後，這是一個艱鉅的任務。我不認為這個問題是無法克服的，但卻有必要在這裏提一下。

當然我們可以給大家提供資源，推薦參考 DistroWatch 還有我們的Blog Desktop Linux Reviews，這都有助於 Mac 用户找到適合的 Linux 發行版。再説一條，網上有很多諸如“最好的 Linux 發行版”等類似的文章，當 Mac 用户想要尋找適合自己使用的發行版時可以參考一下。

但有蘋果顧客購買 Mac 的其中一個原因是蘋果硬件軟件協調統一起來的簡便性和易用性。所以我不確定有多少 Mac 用户願意花費時間找出適合自己的 Linux 發行版。也許是否要使用 Linux 確實會令TA們考慮一陣子了。

Mac 用户是蘋果，Linux 用户是橘子 ​

Mac 用户與 Linux 用户分道揚鑣我認為並沒有什麼不妥。我認為我們只是在談論兩類完全不同的人羣，這是一件好事，因為兩類人羣都在按自己喜歡的方式去使用操作系統和軟件。讓 Mac 用户和 Linux 用户各自沉浸在 OS X 和 Linux 中吧，希望他們都能高興，都能對自己的電腦滿意。

也許 Mac 用户會偶然走入 Linux 的世界並開始轉向 Linux，但我認為絕大多數時候，兩類人都願意呆在不同的世界並不與對方接觸。通常來説我並不會隨意比較二者，尤其是你已經自己拿定主意的時候，況且這只不過是選蘋果還是選橘子的問題罷了。
