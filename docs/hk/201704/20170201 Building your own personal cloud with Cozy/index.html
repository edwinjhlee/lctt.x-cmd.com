使用 Cozy 搭建個人雲 ​

Image by : Pixabay. Modified by Opensource.com. CC BY-SA 4.0

我認識的大部分人為了他們的日曆、電子郵件、文件存儲等，都會使用一些基於 Web 的應用。但是，如果像我這樣，對隱私感到擔憂、或者只是希望將你自己的數字生活簡單化為一個你所控制的地方呢？ Cozy 就是一個朝着健壯的自主雲平台方向發展的項目。你可以從 GitHub 上獲取 Cozy 的源代碼，它採用 AGPL 3.0 協議。

安裝 ​

安裝 Cozy 非常快捷簡單，這裏有多種平台的 簡單易懂的安裝指令。在我的測試中，我使用 64 位的 Debian 8 系統。安裝需要幾分鐘時間，然後你只需要到服務器的 IP 地址註冊一個賬號，就會加載並準備好默認的應用程序集。

要注意的一點 - 安裝假設沒有正在運行任何其它 Web 服務，而且它會嘗試安裝 Nginx web 服務器。如果你的服務器已經有網站正在運行，配置可能就比較麻煩。我是在一個全新的 VPS（Virtual Private Server，虛擬個人服務器）上安裝，因此比較簡單。運行安裝程序、啓動 Nginx，然後你就可以訪問雲了。

Cozy 還有一個 應用商店，你可以從中下載額外的應用程序。有一些看起來非常有趣，例如 Ghost Blog平台 以及開源維基 TiddlyWiki。其目的，顯然是允許把其它很多好的應用程序集成到這個平台。我認為你要看到很多其它流行的開源應用程序提供集成功能只是時間問題。此刻，已經支持 Node.js，但是如果也支持其它應用層，你就可以看到很多其它很好的應用程序。

其中可能的一個功能是從安卓設備中使用免費的安卓應用程序訪問你的信息。當前還沒有 iOS 應用，但有計劃要解決這個問題。

現在，Cozy 已經有很多核心的應用程序。

主要 Cozy 界面

文件 ​

和很多分支一樣，我使用 Dropbox 進行文件存儲。事實上，由於我有很多東西需要存儲，我需要花錢買 DropBox Pro。對我來説，如果它有我想要的功能，那麼把我的文件移動到 Cozy 能為我節省很多開銷。

我希望如此，而它真的可以。我被 Cozy 應用程序內建的基於 web 的文件上傳和文件管理工具所驚訝。拖拽功能正如你期望的那樣，界面也很乾淨整潔。我在上傳事例文件和目錄、隨處跳轉、移動、刪除以及重命名文件時都沒有遇到問題。

如果你想要的就是基於 web 的雲文件存儲，那麼你已經有了。對我來説，它缺失的是 DropBox 具有的選擇性的文件目錄同步功能。在 DropBox 中，如果你拖拽一個文件到目錄中，它就會被拷貝到雲，幾分鐘後該文件在你所有同步設備中都可以看到。實際上，Cozy 正在研發該功能，但此時它還處於 beta 版，而且只支持 Linux 客户端。另外，我有一個稱為 Download to Dropbox 的 Chrome 擴展，我時不時用它抓取圖片和其它內容，但當前 Cozy 中還沒有類似的工具。

文件管理界面

從 Google 導入數據 ​

如果你正在使用 Google 日曆和聯繫人，使用 Cozy 安裝的應用程序很輕易的就可以導入它們。當你授權對 Google 的訪問時，會給你一個 API 密鑰，把它粘貼到 Cozy，它就會迅速高效地進行復制。兩種情況下，內容都會被打上“從 Google 導入”的標籤。對於我混亂的聯繫人，這可能是件好事情，因為它使得我有機會重新整理，把它們重新標記為更有意義的類別。“Google Calendar” 中所有的事件都導入了，但是我注意到其中一些事件的時間不對，可能是由於兩端時區設置的影響。

聯繫人 ​

聯繫人功能正如你期望的那樣，界面也很像 Google 聯繫人。儘管如此，還是有一些不好的地方。例如，和你的智能手機的同步是通過 CardDAV 完成的，這是用於共享聯繫人數據的標準協議，但安卓手機並不原生支持該技術。為了把你的聯繫人同步到安卓設備，你需要在你的手機上安裝一個應用。這對我來説是個很大的打擊，因為我已經有很多類似這樣的古怪應用程序了（例如 工作的郵件、Gmail 以及其它郵件，我的天），我並不想安裝一個不能和我智能手機原生聯繫人應用程序同步的軟件。如果你正在使用 iPhone，你直接就能使用 CradDAV。

日曆 ​

對於日曆用户來説好消息就是安卓設備支持這種類型數據的交換格式 CalDAV。正如我導入數據時提到的，我的一些日曆時間的時間不對。在這之前我在和其它日曆系統進行遷移時也遇到過這個問題，因此這對我並沒有產生太大困擾。界面允許你創建和管理多個日曆，就像 Google 那樣，但是你不能訂閲這個 Cozy 實例之外的其它日曆。該應用程序另一個怪異的地方就是它的一週從週一開始，而且你不能更改。通常來説，我從週日開始我的一週，因此能更改從週一開始的功能對我來説非常有用。設置對話框並沒有任何設置；它只是告訴你如何通過 CalDAV 連接的指令。再次説明，這個應用程序接近我想要的，但 Cozy 做的還不夠好。

照片 ​

照片應用讓我印象深刻，它從文件應用程序借鑑了很多東西。你甚至可以把一個其它應用程序的照片文件添加到相冊，或者直接通過拖拽上傳。不幸的是，一旦上傳後，我沒有找到任何重新排序和編輯照片的方法。你只能把它們從相冊中刪除。應用有一個通過令牌鏈接進行分享的工具，而且你可以指定一個或多個聯繫人。系統會給這些聯繫人發送邀請他們查看相冊的電子郵件。當然還有很多比這個有更豐富功能的相冊應用，但在 Cozy 平台中這算是一個好的起點。

Photos 界面

總結 ​

Cozy 目標遠大。他們嘗試搭建一個你能部署任意你想要的基於雲服務的平台。它已經到了成熟期嗎？我並不認為。對於一些重度用户來説我之前提到的一些問題很嚴重，而且還沒有 iOS 應用，這可能阻礙用户使用它。不管怎樣，繼續關注吧 - 隨着研發的繼續，Cozy 有一家代替很多應用程序的潛能。
