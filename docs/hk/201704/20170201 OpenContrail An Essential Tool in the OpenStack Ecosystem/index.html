OpenContrail：一個 OpenStack 生態中的重要工具 ​

OpenContrail 是用於 OpenStack 雲計算平台的 SDN 平台，它正在成為管理員需要具備的技能的重要工具。

[Creative Commons Zero] 1 Pixabay

整個 2016 年，軟件定義網絡（SDN）迅速發展，開源和雲計算領域的眾多參與者正幫助其獲得增長。結合這一趨勢，用在 OpenStack 雲計算平台上的流行的 SDN 平台 OpenContrail 正成為許多管理員需要具備的技能的重要工具。

正如管理員和開發人員在 OpenStack 生態系統中圍繞着諸如 Ceph 等重要工具提升技能一樣，他們將需要擁抱 OpenContrail，它是由 Apache 軟件基金會全面開源並管理的軟件。

考慮到這些，OpenStack 領域中最活躍的公司之一 Mirantis 已經宣佈對 OpenContrail 的提供商業支持和貢獻。該公司提到：“添加了 OpenContrail 後，Mirantis 將會為與 OpenStack 一起使用的開源技術，包括用於存儲的 Ceph、用於計算的 OpenStack/KVM、用於 SDN 的 OpenContrail 或 Neutron 提供一站式的支持。”

根據 Mirantis 公告，“OpenContrail 是一個使用基於標準協議構建的 Apache 2.0 許可項目，為網絡虛擬化提供了所有必要的組件 - SDN 控制器、虛擬路由器、分析引擎和已發佈的上層 API，它有一個可擴展 REST API 用於配置以及從系統收集操作和分析數據。作為規模化構建，OpenContrail 可以作為雲基礎設施的基礎網絡平台。”

有消息稱 Mirantis 收購了 TCP Cloud，這是一家專門從事 OpenStack、OpenContrail 和 Kubernetes 管理服務的公司。Mirantis 將使用 TCP Cloud 的雲架構持續交付技術來管理將在 Docker 容器中運行的 OpenContrail 控制面板。作為這項工作的一部分，Mirantis 也會一直致力於 OpenContrail。

OpenContrail 的許多貢獻者正在與 Mirantis 緊密合作，他們特別注意了 Mirantis 將提供的支持計劃。

“OpenContrail 是 OpenStack 社區中一個重要的項目，而 Mirantis 很好地容器化並提供商業支持。我們團隊正在做的工作使 OpenContrail 能輕鬆地擴展並更新，並與 Mirantis OpenStack 的其餘部分進行無縫滾動升級。 ” Mirantis 的工程師總監和 OpenContrail 諮詢委員會主任 Jakub Pavlik 説：“商業支持也將使 Mirantis 能夠使該項目與各種交換機兼容，從而為客户提供更多的硬件和軟件選擇。”

除了 OpenContrail 的商業支持外，我們很可能還會看到 Mirantis 為那些想要學習如何利用它的雲管理員和開發人員提供的教育服務。Mirantis 已經以其 OpenStack 培訓課程而聞名，並將 Ceph 納入了培訓課程中。

在 2016 年，SDN 種類快速演變，並且對許多部署 OpenStack 的組織也有意義。IDC 最近發佈了 SDN 市場的一項研究，預計從 2014 年到 2020 年 SDN 市場的年均複合增長率為 53.9％，屆時市場價值將達到 125 億美元。此外，“Technology Trends 2016” 報告將 SDN 列為組織最佳的技術投資之一。

IDC 網絡基礎設施總裁 Rohit Mehra 説：“雲計算和第三方平台推動了 SDN 的需求，它將在 2020 年代表一個價值超過 125 億美元的市場。絲毫不用奇怪的是 SDN 的價值將越來越多地滲透到網絡虛擬化軟件和 SDN 應用中，包括虛擬化網絡和安全服務。大型企業在數據中心中實現 SDN 的價值，但它們最終將會認識到其在橫跨分支機構和校園網絡的廣域網中的廣泛應用。”

同時，Linux 基金會最近宣佈發佈了其 2016 年度報告“開放雲指導：當前趨勢和開源項目”。第三份年度報告全面介紹了開放雲計算，並包含一個關於 SDN 的部分。

Linux 基金會還提供了軟件定義網絡基礎知識（LFS265），這是一個自定進度的 SDN 在線課程，另外作為 Open Daylight 項目的領導者，另一個重要的開源 SDN 平台正在迅速成長。
