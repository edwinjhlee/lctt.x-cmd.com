bmon：Linux 下一個強大的網絡帶寬監視和調試工具 ​

bmon 是類 Unix 系統中一個基於文本，簡單但非常強大的 網絡監視和調試工具，它能抓取網絡相關統計信息並把它們以用户友好的格式展現出來。它是一個可靠高效的帶寬監視和網速估測工具。

它能使用各種輸入模組讀取輸入，並以各種輸出模式顯示輸出，包括交互式文本用户界面和用於腳本編寫的可編程文本輸出。

推薦閲讀： 監控 Linux 性能的 20 個命令列工具

在 Linux 上安裝 bmon 帶寬監視工具 ​

幾乎所有 Linux 發行版的默認倉庫中都有 bmon 軟件包，可以從默認包管理器中輕鬆安裝，但可用的版本可能比較舊。

$ sudo yum install bmon      [On RHEL/CentOS/Fedora]
$ sudo dnf install bmon      [On Fedora 22+]
$ sudo apt-get install bmon  [On Debian/Ubuntu/Mint]

另外，你也可以從 https://pkgs.org/download/bmon 獲取對應你 Linux 發行版的 .rpm 和 .deb 軟件包。

如果你想要最新版本（例如版本 4.0）的 bmon，你需要通過下面的命令從源碼構建。

在 CentOS、RHEL 和 Fedora 中

$ git clone https://github.com/tgraf/bmon.git
$ cd bmon
$ sudo yum install make libconfuse-devel libnl3-devel libnl-route3-devel ncurses-devel
$ sudo ./autogen.sh
$ sudo./configure
$ sudo make
$ sudo make install

在 Debian、Ubuntu 和 Linux Mint 中

$ git clone https://github.com/tgraf/bmon.git
$ cd bmon
$ sudo apt-get install build-essential make libconfuse-dev libnl-3-dev libnl-route-3-dev libncurses-dev pkg-config dh-autoreconf
$ sudo ./autogen.sh
$ sudo ./configure
$ sudo make
$ sudo make install

如何在 Linux 中使用 bmon 帶寬監視工具 ​

通過以下命令運行它（初學者説明：RX 表示每秒接收數據，TX 表示每秒發送數據）：

$ bmon

按 d 鍵可以查看更詳細的帶寬使用情況的圖形化統計信息，參考下面的截圖。

按 Shift + ? 可以查看快速指南。再次按 Shift + ? 可以退出（指南）界面。

bmon – 快速指南

通過 Up 和 Down 箭頭鍵可以查看特定網卡的統計信息。但是，要監視一個特定的網卡，你也可以像下面這樣作為命令列參數指定。

推薦閲讀： 監控 Linux 性能的 13 個工具

選項 -p 指定了要顯示的網卡，在下面的例子中，我們會監視網卡 enp1s0：

$ bmon -p enp1s0

bmon – 監控以太網帶寬

要查看每秒位數而不是每秒字節數，可以像下面這樣使用 -b 選項：

$ bmon -bp enp1s0

我們也可以像下面這樣按秒指定刷新間隔時間：

$ bmon -r 5 -p enp1s0

如何使用 bmon 的輸入模組 ​

bmon 有很多能提供網卡統計數據的輸入模組，其中包括：

  1. netlink - 使用 Netlink 協議從內核中收集網卡和流量控制統計信息。這是默認的輸入模組。
  2. proc - 從 /proc/net/dev 文件讀取網卡統計信息。它被認為是傳統界面，且提供了向後兼容性。它是 Netlink 接口不可用時的備用模組。
  3. dummy - 這是用於調試和測試的可編程輸入模組。
  4. null - 停用數據收集。

要查看關於某個模組的其餘信息，可以像下面這樣使用 help 選項調用它：

$ bmon -i netlink:help

下面的命令將啓用 proc 輸入模組運行 bmon：

$ bmon -i proc -p enp1s0

如何使用 bmon 輸出模組 ​

bmon 也使用輸出模組顯示或者導出上面輸入模組收集的統計數據，輸出模組包括：

  1. curses - 這是一個交互式的文本用户界面，它提供實時的網上估計以及每個屬性的圖形化表示。這是默認的輸出模組。
  2. ascii - 這是用於用户查看的簡單可編程文本輸出。它能顯示網卡列表、詳細計數以及圖形到控制台。當 curses 庫不可用時這是默認的備選輸出模組。
  3. format - 這是完全腳本化的輸出模式，供其它程序使用 - 意味着我們可以在後面的腳本和程序中使用它的輸出值進行分析。
  4. null - 停用輸出。

像下面這樣通過 help 選項獲取更多的模組信息。

$ bmon -o curses:help

下面的命令會用 ascii 輸出模式運行 bmon：

$ bmon -p enp1s0 -o ascii

bmon – Ascii 輸出模式

我們也可以用 format 輸出模式，然後在腳本或者其它程序中使用獲取的值：

$ bmon -p enp1s0 -o format

bmon – Format 輸出模式

想要其它的使用信息、選項和事例，可以閲讀 bmon 的 man 手冊：

$ man bmon

訪問 bmon 的 Github 倉庫：https://github.com/tgraf/bmon。
