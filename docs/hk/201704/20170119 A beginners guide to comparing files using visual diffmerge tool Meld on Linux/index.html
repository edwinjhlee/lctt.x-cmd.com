Linux 系統上的可視化比較與合併工具 Meld ​

我們已經講過 Linux 中一些基於命令列的比較和合並工具，再來講解該系統的一些可視化的比較與合併工具也很合理。首要的原因是，不是每個人都習慣使用命令列，而且對於某些人來説，基於命令列的比較工具可能很難學習和理解。

因此，我們將會推出關於可視化工具 Meld 的系列文章。

在跳到安裝和介紹部分前，我需要説明這篇教程裏所有的指令和用例是都是可用的，而且它們已經在 Ubuntu 14.04 中測試過了，我們使用的 Meld 版本是 3.14.2。

關於 Meld ​

Meld 主要是一個可視化的比較和合並的工具，目標人羣是開發者（當然，我們將要講到的其它部分也會考慮到最終用户）。這個工具同時支持雙向和三向的比較，不僅僅是比較文件，還可以比較目錄，以及版本控制的項目。

“Meld 可以幫你回顧代碼改動，理解補丁，”其官網如是説。“它甚至可以告知你如果你不進行合併將會發生什麼事情。”該工具使用 GPL v2 協議進行授權。

安裝 Meld ​

如果你用的是 Ubuntu 或者其它基於 Debian 的 Linux 分支，你可以用以下命令下載安裝 Meld：

sh
sudo apt-get install meld

或者你也可以用系統自帶的包管理軟件下載這個工具。比如在 Ubuntu 上，你可以用 Ubuntu 軟件中心（Ubuntu Software Center），或者用 Ubuntu 軟件，它從 Ubuntu 16.04 版本開始取代了 Ubuntu 軟件中心。

當然，Ubuntu 官方倉庫裏的 Meld 版本很有可能比較陳舊。因此如果你想要用更新的版本，你可以在這裏下載軟件包。如果你要用這個方法，你要做的就是解壓下載好的軟件包，然後運行 bin 目錄下的 meld 程序。

~/Downloads/meld-3.14.2/bin$ ./meld

以下是 Meld 依賴的軟件，僅供參考：

  • Python 2.7 (Python 3.3 開發版)
  • GTK+ 3.14
  • GLib 2.36
  • PyGObject 3.14
  • GtkSourceView 3.14
  • pycairo

就像上面的截圖那樣明白，Meld 也可以進行三向比較，但是在這一系列文章的第一部分，我們只會講更常用的雙向比較。

接着，選擇你想要比較的文件，點擊“比較”（Compare）按鈕。軟件會在兩邊分別打開兩個文件，高亮不同的行（以及不同的部分）。

兩個文件的不同之處在第二行，差別在於 file2 文件的第二行多了一個 3。你看到的黑色箭頭是用來進行合併或修改的操作的。該例中，向右的箭頭將會把 file2 文件的第二行改成文件 file1 中對應行的內容。左向箭頭做的事情相反。

做完修改後，按下 Ctrl+s 來保存。

仔細觀察，圖中的這個欄包含幾個不同顏色的區塊。這些區塊是用來讓你對文件之間的差異有個大概的瞭解。“每一個着色的區塊表示一個部分，這個部分可能是插入、刪除、修改或者有差別的，取決於區塊所用的顏色。”官方文檔是這樣説的。

這些是你使用 Meld 時做的一般性的事情：可以用標準的 Ctrl+f 組合鍵在編輯區域內進行查找，按 F11 鍵讓軟件進入全屏模式，再按 Ctrl+r 來刷新（通常在所有要比較的文件改變的時候使用）。

以下是 Meld 官方網站宣傳的重要特性：

  • 文件和目錄的雙向及三向比較
  • 輸入即更新文件的比較
  • 自動合併模式，按塊改動的動作讓合併更加簡單
  • 可視化讓比較文件更簡單
  • 支持 Git，Bazaar，Mercurial，Subversion 等等

注意還不僅僅只有以上所列的。網站上有個專門的特性頁面，裏面提到了 Meld 提供的所有特性。這個頁面列出的所有特性分為幾個部分，以該軟件是用來做文件比較、目錄比較、版本控制還是處於合併模式下為基礎進行劃分。

和其它軟件相似，有些事情 Meld 做不到。官方網站上列出了其中的一部分：“當 Meld 展示文件之間的差異時，它同時顯示兩個文件，看起來就像在普通的文本編輯器中。它不會添加額外的行，讓左右兩邊文件的特殊改動處於同樣的行數。沒有做這個事情的選項。”

總結 ​

我們剛剛瞭解到的不過是皮毛，因為 Meld 還能做很多事情。考慮到這是教程系列的第一部分，這也挺不錯的。這僅僅是讓你瞭解 Meld 的作用，你可以配置它，忽略一些特定類型的改動，讓它移動，複製或者刪除文件之間的個別差異，也可以從命令列啓動它。在即將退出的系列教程中，我們將會講述所有這些重要功能。
