使用 LXDE 的 8 個理由 ​

考慮使用輕量級桌面環境 LXDE 作為你 Linux 桌面的理由

Image by : opensource.com

去年年底，升級到 Fedora 25 所裝的新版本 KDE Plasma 給我帶來了嚴重問題，讓我難以完成任何工作。出於兩個原因我決定嘗試其它 Linux 桌面環境。第一，我需要完成我的工作。第二，一心使用 KDE 已經有很多年，我認為是時候嘗試一些不同的桌面了。

我第一個嘗試了幾周的替代桌面是 Cinnamon，我在 1 月份介紹過它。這次我已經使用了 LXDE（輕量級 X11 桌面環境(Lightweight X11 Desktop Environment)）大概 6 周，我發現它有很多我喜歡的東西。這是我使用 LXDE 的 8 個理由。

1、 LXDE 支持多個面板 ​

和 KDE 以及 Cinnamon 一樣，LXDE 支持包括系統菜單、應用啓動器的面板，以及顯示正在運行應用圖標的任務欄。我第一次登錄到 LXDE 時，面板的配置看起來異常熟悉。LDXE 看起來已經根據我的 KDE 配置情況為我準備好了喜歡的頂部和底部面板，並包括了系統托盤設置。頂部面板上的應用程序啓動器看似來自 Cinnamon 。面板上的東西使得啓動和管理程序變得容易。默認情況下，只在桌面底部有一個面板。

打開了 Openbox 配置管理器的 LXDE 桌面。這個桌面還沒有更改過，因此它使用了默認的顏色和圖標主題。

2、 Openbox 配置管理器提供了一個用於管理和體驗桌面外觀的簡單工具。 ​

它為主題、窗口修飾、多個顯示器的窗口行為、移動和調整窗口大小、鼠標控制、多桌面等提供了選項。雖然這看起來似乎很多，但它遠不如配置 KDE 桌面那麼複雜，儘管如此 Openbox 仍然提供了絕佳的效果。

3、 LXDE 有一個強大的菜單工具 ​

在桌面偏好（Desktop Preference）菜單的高級（Advanced）標籤頁有個有趣的選項。這個選項的名稱是 “點擊桌面時顯示窗口管理器提供的菜單（Show menus provided by window managers when desktop is clicked）”。選中這個複選框，當你右擊桌面時，會顯示 Openbox 桌面菜單，而不是標準的 LXDE 桌面菜單。

Openbox 桌面菜單包括了幾乎每個你可能想要的菜單選項，所有都可從桌面便捷訪問。它包括了所有的應用程序菜單、系統管理、以及首選項。它甚至有一個菜單包括了所有已安裝的終端模擬器應用程序的列表，因此係統管理員可以輕易地啓動他們喜歡的終端。

4、 LXDE 桌面的設計乾淨簡單 ​

它沒有任何會妨礙你完成工作的東西。儘管你可以添加一些文件、目錄、應用程序的鏈接到桌面，但是沒有可以添加到桌面的小部件。在我的 KDE 和 Cinnamon 桌面上我確實喜歡一些小部件，但它們很容易被覆蓋住，然後我就需要移動或者最小化窗口，或者使用 “顯示桌面（Show Desktop）” 按鈕清空整個桌面才能看到它們。 LXDE 確實有一個 “圖標化所有窗口（Iconify all windows）” 按鈕，但我很少需要使用它，除非我想看我的壁紙。

5、 LXDE 有一個強大的文件管理器 ​

LXDE 默認的文件管理器是 PCManFM，因此在我使用 LXDE 的時候它成為了我的文件管理器。PCManFM 非常靈活、可以配置為適用於大部分人和場景。它看起來沒有我常用的文件管理器 Krusader 那麼可配置，但我確實喜歡 Krusader 所沒有的 PCManFM 側邊欄。

PCManFM 允許打開多個標籤頁，可以通過右擊側邊欄的任何條目或者單擊圖標欄的新標籤圖標打開。PCManFM 窗口左邊的位置（Places）面板顯示了應用程序菜單，你可以從 PCManFM 啓動應用程序。位置（Places）面板上面也顯示了一個設備圖標，可以用於查看你的物理存儲設備，一系列帶按鈕的可移除設備允許你掛載和卸載它們，還有可以便捷訪問的主目錄、桌面、回收站。位置（Places）面板的底部包括一些默認目錄的快捷方式，例如 Documents、Music、Pictures、Videos 以及 Downloads。你也可以拖拽其它目錄到位置（Places）面板的快捷方式部分。位置（Places） 面板可以換為正常的目錄樹。

6、 如果在現有窗口後面打開，新窗口的標題欄會閃爍 ​

這是一個在大量現有窗口中定位新窗口的好方法。

7、 大部分現代桌面環境允許多個桌面，LXDE 也不例外 ​

我喜歡使用一個桌面用於我的開發、測試以及編輯工作，另一個桌面用於普通任務，例如電子郵件和網頁瀏覽。LXDE 默認提供兩個桌面，但你可以配置為只有一個或者多個。右擊桌面切換器（Desktop Pager）配置它。

通過一些有害但不是破壞性的測試，我發現最大允許桌面數目是 100。我還發現當我把桌面數目減少到低於我實際已經在使用的 3 個時，不活動桌面上的窗口會被移動到桌面 1。多麼有趣的發現！

8、 Xfce 電源管理器是一個小巧但強大的應用程序，它允許你配置電源管理如何工作 ​

它提供了一個標籤頁用於通用配置，以及用於系統、顯示和設備的標籤頁。設備標籤頁顯示了我係統上已有設備的表格，例如電池供電的鼠標、鍵盤，甚至我的 UPS（不間斷電源）。它顯示了每個設備的詳細信息，包括廠商和系列號，如果可用的話，還有電池充電狀態。當我寫這篇Blog的時候，我 UPS 的電量是 100%，而我羅技鼠標的電量是 75%。 Xfce 電源管理器還在系統托盤顯示了一個圖標，因此你可以從那裏快速瞭解你設備的電池狀態。

關於 LXDE 桌面還有很多喜歡的東西，但這些就是抓住了我的注意力，它們也是對我使用現代圖形用户界面工作非常重要、不可或缺的東西。

我注意到奇怪的一點是，我一直沒有弄明白桌面（Openbox）菜單的 “重新配置（Reconfigure）” 選項是幹什麼的。我點擊了幾次，從沒有注意到有任何類型的任何活動表明該選項實際起了作用。

我發現 LXDE 是一個簡單但強大的桌面。我享受使用它寫這篇文章的幾周時間。通過允許我訪問我想要的應用程序和文件，同時在其餘時間保持不會讓我分神，LXDE 使我得以高效地工作。我也沒有遇到任何妨礙我完成工作的問題——當然，除了我用於探索這個好桌面所花的時間。我非常推薦 LXDE 桌面。

我現在正在試用 GNOME 3 和 GNOME Shell，並將在下一期中報告。
