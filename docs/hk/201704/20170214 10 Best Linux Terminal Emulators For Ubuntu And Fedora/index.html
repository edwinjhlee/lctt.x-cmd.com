10 個常見的 Linux 終端仿真器 ​

對於 Linux 用户來説，最重要的應用程序之一就是終端仿真器。它允許每個用户獲得對 shell 的訪問。而 Bash 是 Linux 和 UNIX 發行版中最常用的 shell，它很強大，對於新手和高級用户來説，掌握 bash 都很有必要。因此，在這篇文章中，你可以瞭解 Linux 用户有哪些優秀的終端仿真器可以選擇。

1、Terminator ​

這個項目的目標是創造一個能夠很好排列終端的有用工具。它受到一些如 gnome-multi-term、quadkonsole 等程序的啓發，重點是以網格的形式排列終端。

特性瀏覽 ​

  • 以網格形式排列終端
  • Tab 設定
  • 通過拖放重新排布終端
  • 大量的快捷鍵
  • 通過 GUI 參數編輯器保存多個佈局和配置文件
  • 同時對任意組合的終端進行輸入

你可以通過下面的命令安裝 Terminator：

sudo apt-get install terminator

2、Tilda － 一個可以下拉的終端 ​

Tilda 的獨特之處在於它不像一個普通的窗口，相反，你可以使用一個特殊的熱鍵從屏幕的頂部拉下和收回它。 另外，Tilda 是高度可配置的，可以自定義綁定熱鍵，改變外觀，以及其他許多能夠影響 Tilda 特性的選項。

在 Ubuntu 和 Fedora 上都可以使用包管理器安裝 Tilda，當然，你也可以查看它的 GitHub 倉庫。

3、Guake ​

Guake 是一個和 Tilda 或 yakuake 類似的下拉式終端仿真器。如果你知道一些關於 Python、Git 和 GTK 的知識的話，你可以給 Guake 添加一些新的特性。 ​ Guake 在許多發行版上均可用，所以如果你想安裝它，你可以查看你的版本倉庫。

特性瀏覽 ​

  • 輕量
  • 簡單易用且優雅
  • 將終端自然地集成到 GUI 之中
  • 當你使用的時候出現，一旦按下預定義熱鍵便消失（默認情況下是 F12）
  • 支持Compiz 透明
  • 多重 Tab
  • 豐富的調色板
  • 還有更多……

主頁: http://guake-project.org/

4、ROXTerm ​

如果你正在尋找一個輕量型、高度可定製的終端仿真器，那麼 ROXTerm 就是專門為你準備的。這是一個旨在提供和 gnome-terminal 相似特性的終端仿真器，它們都基於相同的 VTE 庫。它的最初設計是隻佔用很小的資源並且能夠快速啓動，它具有比 gnome-terminal 更強的可配置性，更加針對經常使用終端的 “Power” 用户。

http://roxterm.sourceforge.net/index.php?page=index&lang=en

5、XTerm ​

Xterm 是 Linux 和 UNIX 系統上最受歡迎的終端仿真器，因為它是 X 窗口系統的默認終端仿真器，並且很輕量、很簡單。

6、Eterm ​

如果你正在尋找一個漂亮、強大的終端仿真器，那麼 Eterm 是你最好的選擇。Eterm 是一個彩色 vt102 終端仿真器，被當作是 Xterm 的替代品。它按照自由選擇的哲學思想進行設計，將盡可能多的權利、靈活性和自由交到用户手中。

官網： http://www.eterm.org/

7、Gnome Terminal ​

Gnome Terminal 是最受歡迎的終端仿真器之一，它被許多 Linux 用户使用，因為它默認安裝在 Gnome 桌面環境中，而 Gnome 桌面很常用。它有許多特性並且支持大量主題。

在許多 Linux 發行版中都默認安裝有 Gnome Terminal，但你如果沒有的話，也可以使用你的包管理器來安裝它。

8、Sakura ​

Sakura 是一個基於 GTK 和 VTE 的終端仿真器。它是一個只有很少依賴的終端仿真器，所以你不需要先安裝一個完整的 GNOME 桌面才能有一個像樣的終端仿真器。

你可以使用你的包管理器來安裝它，因為 Sakura 在絕大多數發行版中都是可用的。

9、LilyTerm ​

LilyTerm 是一個基於 libvte 的終端仿真器，旨在快速和輕量，是 GPLv3 授權許可的。

特性瀏覽 ​

  • 低資源佔用
  • 多重 Tab
  • 配色方案豐富
  • 支持超鏈接
  • 支持全屏
  • 還有更多的……

10、Konsole ​

如果你是一名 KDE 或 Plasma 用户，那麼你一定知道 Konsole，因為它是 KDE 桌面的默認終端仿真器，也是我最喜愛的終端仿真器之一，因為它很舒適易用。

它在 Ubuntu 和 fedora 上均可用，但如果你在使用 Ubuntu (Unity)，那麼你需要選擇別的終端仿真器，或者你可以考慮使用 Kubuntu 。

結論 ​

我們是 Linux 用户，根據自己的需求，可以有許多選擇來挑選更好的應用。因此，你可以選擇最好的終端來滿足個人需求，雖然你也可以選擇另一個 shell 來滿足個人需求，比如你也可以使用 fish shell。
