2016 年度頂級開源創作工具 ​

無論你是想修改圖片、編譯音頻，還是製作動畫，這裏的自由而開源的工具都能幫你做到。

圖片來源 : opensource.com

幾年前，我在 Red Hat 總結會上做了一個簡單的演講，給與會者展示了 2012 年度開源創作工具。開源軟件在過去幾年裏發展迅速，現在我們來看看 2016 年的相關領域的軟件。

核心應用 ​

這六款應用是開源的設計軟件中的最強王者。它們做的很棒，擁有完善的功能特徵集、穩定發行版以及活躍的開發者社區，是很成熟的項目。這六款應用都是跨平台的，每一個都能在 Linux、OS X 和 Windows 上使用，不過大多數情況下 Linux 版本一般都是最先更新的。這些應用廣為人知，我已經把最新特性的重要部分寫進來了，如果你不是非常瞭解它們的開發情況，你有可能會忽視這些特性。

如果你想要對這些軟件做更深層次的瞭解，或許你可以幫助測試這四個軟件 —— GIMP、Inkscape、Scribus，以及 MyPaint 的最新版本，在 Linux 機器上你可以用 Flatpak 軟件輕鬆地安裝它們。這些應用的每日構建版本可以按照指令 通過 Flatpak 的“每日構建的繪圖應用（Nightly Graphics Apps）”得到。有一件事要注意：如果你要給每個應用的 Flatpak 版本安裝筆刷或者其它擴展，用於移除這些擴展的目錄將會位於相應應用的目錄 ~/.var/app 下。

GIMP ​

GIMP 在 2015 年迎來了它的 20 週歲，使得它成為這裏資歷最久的開源創造型應用之一。GIMP 是一款強大的應用，可以處理圖片，創作簡單的繪畫，以及插圖。你可以通過簡單的任務來嘗試 GIMP，比如裁剪、縮放圖片，然後循序漸進使用它的其它功能。GIMP 可以在 Linux、Mac OS X 以及 Windows 上使用，是一款跨平台的應用，而且能夠打開、導出一系列格式的文件，包括在與之相似的軟件 Photoshop 上廣為應用的那些格式。

GIMP 開發團隊正在忙着 2.10 發行版的工作；2.8.18 是最新的穩定版本。更振奮人心的是非穩定版，2.9.4，擁有全新的用户界面，旨在節省空間的符號式圖標和黑色主題，改進了顏色管理，更多的基於 GEGL 的支持分離預覽的過濾器，支持 MyPaint 筆刷（如下圖所示），對稱繪圖，以及命令列批次處理。想了解更多信息，請關注 完整的發行版註記。

Inkscape ​

Inkscape 是一款富有特色的矢量繪圖設計軟件。可以用它來創作簡單的圖形、圖表、佈局或者圖標。

最新的穩定版是 0.91 版本；與 GIMP 相似，能在預發佈版 0.92pre3 版本中找到更多有趣的東西，其發佈於 2016 年 11 月。最新推出的預發佈版的突出特點是 梯度網格特性（gradient mesh feature）（如下圖所示）；0.91 發行版裏介紹的新特性包括：強力筆觸（power stroke） 用於完全可配置的書法筆畫（下圖的 “opensource.com” 中的 “open” 用的就是強力筆觸技術），畫布測量工具，以及 全新的符號對話框（如下圖右側所示）。（很多符號庫可以從 GitHub 上獲得；Xaviju's inkscape-open-symbols set 就很不錯。）_對象_對話框是在改進版或每日構建中可用的新特性，整合了一個文檔中的所有對象，提供工具來管理這些對象。

Scribus ​

Scribus 是一款強大的桌面出版和頁面佈局工具。Scribus 讓你能夠創造精緻美麗的物品，包括信封、書籍、雜誌以及其它印刷品。Scribus 的顏色管理工具可以處理和輸出 CMYK 格式，還能給文件配色，可靠地用於印刷車間的重印。

1.4.6 是 Scribus 的最新穩定版本；1.5.x 系列的發行版更令人期待，因為它們是即將到來的 1.6.0 發行版的預覽。1.5.3 版本包含了 Krita 文件（*.KRA）導入工具； 1.5.x 系列中其它的改進包括了表格工具、文本框對齊、腳註、導出可選 PDF 格式、改進的字典、可駐留邊框的調色盤、符號工具，和豐富的文件格式支持。

MyPaint ​

MyPaint 是一款用於數位屏的快速繪圖和插畫工具。它很輕巧，界面雖小，但快捷鍵豐富，因此你能夠不用放下數位筆而專心於繪圖。

MyPaint 1.2.0 是其最新的穩定版本，包含了一些新特性，諸如 直觀上墨工具 用來跟蹤鉛筆繪圖的軌跡，新的填充工具，層分組，筆刷和顏色的歷史面板，用户界面的改進包括暗色主題和小型符號圖標，以及可編輯的矢量層。想要嘗試 MyPaint 裏的最新改進，我建議安裝每日構建版的 Flatpak 構建，儘管自從 1.2.0 版本沒有添加重要的特性。

Blender ​

Blender 最初發佈於 1995 年 1 月，像 GIMP 一樣，已經有 20 多年的歷史了。Blender 是一款功能強大的開源 3D 製作套件，包含建模、雕刻、渲染、真實材質、套索、動畫、影像合成、視頻編輯、遊戲創作以及模擬。

Blender 最新的穩定版是 2.78a。2.78 版本很龐大，包含的特性有：改進的 2D 蠟筆（Grease Pencil） 動畫工具；針對球面立體圖片的 VR 渲染支持；以及新的手繪曲線的繪圖工具。

要嘗試最新的 Blender 開發工具，有很多種選擇，包括：

  • Blender 基金會在官方網址提供 非穩定版的每日構建版。
  • 如果你在尋找特殊的開發中特性，graphicall.org 是一個適合社區的網站，能夠提供特殊版本的 Blender（偶爾還有其它的創造型開源應用），讓藝術家能夠嘗試體驗最新的代碼。
  • Mathieu Bridon 通過 Flatpak 做了 Blender 的一個開發版本。查看它的Blog以瞭解詳情：Flatpak 上每日構建版的 Blender

Krita ​

Krita 是一款擁有強大功能的數字繪圖應用。這款應用貼合插畫師、印象藝術家以及漫畫家的需求，有很多附件，比如筆刷、調色板、圖案以及模版。

最新的穩定版是 Krita 3.0.1，於 2016 年 9 月發佈。3.0.x 系列的新特性包括 2D 逐幀動畫；改進的層管理器和功能；豐富的常用快捷鍵；改進了網格、嚮導和圖形捕捉；還有軟打樣。

視頻處理工具 ​

關於開源的視頻編輯工具則有很多很多。這這些工具之中，Flowblade 是新推出的，而 Kdenlive 則是構建完善、對新手友好、功能最全的競爭者。對你排除某些備選品有所幫助的主要標準是它們所支持的平台，其中一些只支持 Linux 平台。它們的軟件上游都很活躍，最新的穩定版都於近期發佈，發佈時間相差不到一週。

Kdenlive ​

Kdenlive，最初於 2002 年發佈，是一款強大的非線性視頻編輯器，有 Linux 和 OS X 版本（但是 OS X 版本已經過時了）。Kdenlive 有用户友好的、基於拖拽的用户界面，適合初學者，又有專業人員需要的深層次功能。

可以看看 Seth Kenlon 寫的 Kdenlive 系列教程，瞭解如何使用 Kdenlive。

  • 最新穩定版: 16.08.2 (2016 年 10 月)

Flowblade ​

2012 年發佈, Flowblade，只有 Linux 版本的視頻編輯器，是個相當不錯的後起之秀。

  • 最新穩定版: 1.8 (2016 年 9 月)

Pitivi ​

Pitivi 是用户友好型的自由開源視頻編輯器。Pitivi 是用 Python 編寫的（“Pitivi” 中的 “Pi”來源於此），使用了 GStreamer 多媒體框架，社區活躍。

  • 最新穩定版: 0.97 (2016 年 8 月)
  • 通過 Flatpak 獲取 最新版本

Shotcut ​

Shotcut 是一款自由開源的跨平台視頻編輯器，[早在 2004 年]就發佈了，之後由現在的主要開發者 Dan Dennedy 重寫。

  • 最新穩定版: 16.11 (2016 年 11 月)
  • 支持 4K 分辨率
  • 僅以 tar 包方式發佈

OpenShot Video Editor ​

始於 2008 年，OpenShot Video Editor 是一款自由、開源、易於使用、跨平台的視頻編輯器。

  • 最新穩定版: 2.1 (2016 年 8 月)

其它工具 ​

SwatchBooker ​

SwatchBooker 是一款很方便的工具，儘管它近幾年都沒有更新了，但它還是很有用。SwatchBooler 能幫助用户從各大製造商那裏合法地獲取色卡，你可以用其它自由開源的工具處理它導出的格式，包括 Scribus。

GNOME Color Manager ​

GNOME Color Manager 是 GNOME 桌面環境內建的顏色管理器，而 GNOME 是某些 Linux 發行版的默認桌面。這個工具讓你能夠用色度計為自己的顯示設備創建屬性文件，還可以為這些設備加載/管理 ICC 顏色屬性文件。

GNOME Wacom Control ​

The GNOME Wacom controls 允許你在 GNOME 桌面環境中配置自己的 Wacom 手寫板；你可以修改手寫板交互的很多選項，包括自定義手寫板靈敏度，以及手寫板映射到哪塊屏幕上。

Xournal ​

Xournal 是一款簡單但可靠的應用，可以讓你通過手寫板手寫或者在筆記上塗鴉。Xournal 是一款有用的工具，可以讓你簽名或註解 PDF 文檔。

PDF Mod ​

PDF Mod 是一款編輯 PDF 文件很方便的工具。PDF Mod 讓用户可以移除頁面、添加頁面，將多個 PDF 文檔合併成一個單獨的 PDF 文件，重新排列頁面，旋轉頁面等。

SparkleShare ​

SparkleShare 是一款基於 git 的文件分享工具，藝術家用來協作和分享資源。它會掛載在 GitLab 倉庫上，你能夠採用一個精妙的開源架構來進行資源管理。SparkleShare 的前端通過在頂部提供一個類似下拉框界面，避免了使用 git 的複雜性。

攝影 ​

Darktable ​

Darktable 是一款能讓你開發數位 RAW 文件的應用，有一系列工具，可以管理工作流、無損編輯圖片。Darktable 支持許多流行的相機和鏡頭。

Entangle ​

Entangle 允許你將數字相機連接到電腦上，讓你能從電腦上完全控制相機。

Hugin ​

Hugin 是一款工具，讓你可以拼接照片，從而製作全景照片。

2D 動畫 ​

Synfig Studio ​

Synfig Studio 是基於矢量的二維動畫套件，支持位圖原圖，在平板上用起來方便。

Blender Grease Pencil ​

我在前面講過了 Blender，但值得注意的是，最近的發行版裏重構的蠟筆特性，添加了創作二維動畫的功能。

Krita ​

Krita 現在同樣提供了二維動畫功能。

音頻編輯 ​

Audacity ​

Audacity 在編輯音頻文件、記錄聲音方面很有名，是用户友好型的工具。

Ardour ​

Ardour 是一款數字音頻工作軟件，界面中間是錄音，編輯和混音工作流。使用上它比 Audacity 要稍微難一點，但它允許自動操作，並且更高端。（有 Linux、Mac OS X 和 Windows 版本）

Hydrogen ​

Hydrogen 是一款開源的電子鼓，界面直觀。它可以用合成的樂器創作、整理各種樂譜。

Mixxx ​

Mixxx 是四倉 DJ 套件，讓你能夠以強大操控來 DJ 和混音歌曲，包含節拍循環、時間延長、音高變化，還可以用 DJ 硬件控制器直播混音和銜接。

Rosegarden ​

Rosegarden 是一款作曲軟件，有樂譜編寫和音樂作曲或編輯的功能，提供音頻和 MIDI 音序器。（LCTT 譯註：MIDI 即 Musical Instrument Digital Interface 樂器數字接口）

MuseScore ​

MuseScore 是樂譜創作、記譜和編輯的軟件，它還有個樂譜貢獻者社區。

其它具有創造力的工具 ​

MakeHuman ​

MakeHuman 是一款三維繪圖工具，可以創造人型的真實模型。

Natron ​

Natron 是基於節點的合成工具，用於視頻後期製作、動態圖象和設計特效。

FontForge ​

FontForge 是創作和編輯字體的工具。允許你編輯某個字體中的字形，也能夠使用這些字形生成字體。

Valentina ​

Valentina 是用來設計縫紉圖案的應用。

Calligra Flow ​

Calligra Flow 是一款圖表工具，類似 Visio（有 Linux，Mac OS X 和 Windows 版本）。

資源 ​

這裏有很多小玩意和彩蛋值得嘗試。需要一點靈感來探索？這些網站和論壇有很多教程和精美的成品能夠激發你開始創作：

1、 pixls.us： 攝影師 Pat David 管理的Blog，他專注於專業攝影師使用的自由開源的軟件和工作流。 2、 David Revoy 's Blog： David Revoy 的Blog，熱愛自由開源，非常有天賦的插畫師，概念派畫師和開源倡議者，對 Blender 基金會電影有很大貢獻。 3、 The Open Source Creative Podcast: 由 Opensource.com 社區版主和專欄作家 Jason van Gumster 管理，他是 Blender 和 GIMP 的專家， 《Blender for Dummies》 的作者，該文章正好是面向我們這些熱愛開源創作工具和這些工具周邊的文化的人。 4、 Libre Graphics Meeting: 自由開源創作軟件的開發者和使用這些軟件的創作者的年度會議。這是個好地方，你可以通過它找到你喜愛的開源創作軟件將會推出哪些有意思的特性，還可以瞭解到這些軟件的用户用它們在做什麼。
