5 個開源 RSS 訂閲閲讀器 ​

Image by : Rob McDonald on Flickr. Modified by Opensource.com. CC BY-SA 2.0.

你平時使用 RSS 閲讀器麼？ ​

   

四年前當 Google Reader 宣佈停止的時候，許多“技術專家”聲稱 RSS 訂閲將會結束。

對於某些人而言，社交媒體和其他聚合工具滿足了 RSS、Atom 以及其它格式的閲讀器的需求。但是老技術絕對不會因為新技術而死，特別是如果新技術不能完全覆蓋舊技術的所有使用情況時。技術的目標受眾可能會有所改變，人們使用這個技術的工具也可能會改變。

但是，RSS 並不比像 email、JavaScript、SQL 資料庫、命令列或者十幾年前告訴我的其它時日無多的技術消失的更快。（黑膠專輯的銷售額去年剛剛達到了其 25 年的頂峯，這不是個奇蹟麼？）只要看看在線 Feed 閲讀器網站 Feedly 的成功，就能瞭解 RSS 閲讀器仍然有市場。

事實是，RSS 和相關的 Feed 格式比任何廣泛使用的嘗試替換它的東西還要多才多藝。作為一名閲讀消費者，對於我來説沒有比它更簡單的方法了，我可以閲讀大量的出版信息，並且是用我選擇的客户端格式化的，我可以確認看到發佈的每一條內容，同時不會顯示我已經閲讀過的文章。而作為發佈者，這是一種比我使用過的大多數發佈軟件都簡單的格式，開箱即用，它可以讓我的信息遞交給更多的人，並且可以很容易地分發多種不同類型的文檔格式。

所以 RSS 沒有死。RSS 長存！我們最後一次是在 2013 年回顧了開源 RSS 閲讀器選擇，現在是更新的時候了。這裏是我關於 2017 年開源 RSS 訂閲閲讀器的一些最佳選擇，每個在使用上稍微不同。

Miniflux ​

Miniflux 是一個極度簡約的基於 Web 的 RSS 閲讀器，但不要將其特意的輕設計與開發人員的懶惰混淆。它目的是構建一個簡單而有效的設計。Miniflux 的思想似乎是將程序弱化，以便讓讀者可以專注於內容，在大量臃腫的 web 程序中我們會特別欣賞這一點。

但輕便並不意味着缺乏功能。其響應式設計在任何設備上看起來都很好，並可以使用主題、API 接口、多語言、固定書籤等等。

Miniflux 的 源代碼以 GPLv3 Affero 許可證在 GitHub 中發佈。如果你不想自行託管，則可以支付每年 15 美元的託管計劃。

RSSOwl ​

RSSOwl 是一個跨平台的桌面 Feed 閲讀器。它用 Java 編寫，在風格和感覺上它像很多流行的桌面郵件客户端。它具有強大的過濾和搜索功能、可定製的通知，以及用於排序 Feed 的標籤。 如果你習慣使用 Thunderbird 或其他桌面閲讀器進行電子郵件發送，那麼在 RSSOwl 中你會感到賓至如歸。

可以在 GitHub 中找到 Eclipse Public 許可證下發布的 RSSOwl 的源代碼。

Tickr ​

Tickr 在這個系列中有點不同。它是一個 Linux 桌面客户端，但它不是傳統的瀏覽-閲讀形式。相反，它會將你的 Feed 標題如滾動新聞那樣在桌面橫欄上滾動顯示。對於想要從各種來源獲得最新消息的新聞界來説，這是一個不錯的選擇。點擊標題將在你選擇的瀏覽器中打開它。它不像這個列表中的其他程序那樣是專門的閲讀客户端，但是如果比起閲讀每篇文章，你對閲讀標題更感興趣，這是一個很好的選擇。

Tickr 的源代碼和二進制文件以 GPL 許可證的形式在這個網站上可以找到。

Tiny Tiny RSS ​

如果缺少了 Tiny Tiny RSS，那麼很難稱之為這是一個現代化的 RSS 閲讀器列表。它是最受歡迎的自主託管的基於 Web 的閲讀器，它功能豐富：支持OPML 導入和導出、鍵盤快捷鍵、共享功能、主題界面、插件支持、過濾功能等等。

Tiny Tiny RSS 還有官方的 Android客户端，讓你可以隨時隨地閲讀。

Tiny Tiny RSS 的 Web 版本和 Android 源代碼以 GPLv3 許可 在 GitLab 上發佈。

Winds ​

Winds 是一個建立在 React 之上的看起來很現代化的自託管的 web 訂閲閲讀器。它利用稱為 Stream 的機器學習個性化 API，幫助你根據當前的興趣找到可能感興趣的更多內容。這有一個在線顯示版本，因此你可以在下載之前先嘗試。這是一個只有幾個月的新項目，也許評估它是否能取代我日常的 Feed 閲讀器還太早，但這當然是一個我感興趣關注的項目。

Winds 的源代碼 以 MIT 許可證在 GitHub 上發佈。

這些當然不是僅有的選擇。RSS 是一個相對易於解析、文檔格式良好的格式，因此有許許多多因為不同的需求而建立的各種 Feed 閲讀器。這有一個很長的自託管的開源 Feed 閲讀器列表，除了我們列出的之外你還可能會考慮使用它們。我們希望你能在下面的評論欄與我們分享你最喜歡的 RSS 閲讀器。
