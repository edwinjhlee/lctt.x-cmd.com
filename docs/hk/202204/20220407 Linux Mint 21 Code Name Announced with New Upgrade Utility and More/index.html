Linux Mint 21 公佈了代號、新的升級工具及更多內容 ​

Mint 團隊公佈了即將到來的 Linux Mint 21 的代號、一個用於輕鬆升級的工具，以及令團隊驚歎的 Warpinator 使用案例。

Linux Mint 21 公告和其他更新 ​

首先，Linux Mint 21 的代號是 “Vanessa”，它將基於 Ubuntu 22.04 LTS Jammy Jellyfish。像往常一樣，它將提供三個旗艦版本：Xfce、Cinnamon 和 MATE。

其次，很明顯，Mint 團隊將選擇 Ubuntu 22.04 LTS 作為 Linux Mint 21 的基礎以獲得長期支持。它將採用 5.15 版本的 Linux 內核，這是一個長期支持版的內核。

除此之外，項目負責人 Clement Lefebvre 還宣佈了 一個新的升級工具（mintupgrade2），這樣一來，計劃升級到 Linux Mint 21 的用户可以更輕鬆地完成升級步驟。根據歷史經驗，升級到 Mint 的主要版本是一個涉及大量終端操作的複雜過程，這對普通用户來説通常是困難的。

因此，考慮到其用户基礎，Mint 團隊為用户開發這個升級工具還是很有必要的。Clement Lefebvre 承諾，新的工具將是完全圖形化的，附帶有易於管理的步驟和説明。它將支持語言的本地化，還將為複雜的升級過程提供預先檢查，同時也將為用户提供易於理解的可配置的指南。

這個工具將成為從 Linux Mint 20 升級到 21 的主要工具，它會在五、六月份左右發佈。此外，這個新工具承諾提供關於自定義 PPA 和孤兒包的警告，以減少你在升級前的擔憂。老實説，這將是 Mint 團隊為其用户帶來的最好的工具之一。

其他更新 ​

除了以上更新外，團隊還提到，文件傳輸工具 Warpinator 被世界上的多個用户用於一些奇怪的需求 —— 這是團隊之前從未想過的。例如，有人用 Warpinator 在 Windows 和 V 社的 Steam Deck 遊戲機之間傳輸文件，參見 這個視頻。

説到這裏，Warpinator 現在提供了一個 針對 iOS 用户的測試發行版。你現在可以在你的蘋果系統與任何其他系統之間快速傳輸文件，包括安卓、Linux 和 Windows。Mint 團隊開發的這個應用真不錯。

你可以在官方Blog中閲讀關於 Linux Mint 21 的公告和更多內容。
