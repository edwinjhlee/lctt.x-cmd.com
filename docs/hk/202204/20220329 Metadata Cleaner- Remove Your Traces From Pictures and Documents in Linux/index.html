Metadata Cleaner：在 Linux 中清除你在圖片和文件中的痕跡 ​

擺脱元數據對增強隱私至關重要。Metadata Cleaner 是一個開源的 Linux 應用，可以幫助你做到這一點。讓我們在這裏探討更多。

元數據無處不在，它在文檔中、在信息中、在圖片中，在各種文件中。

當你檢查一個文件的屬性時，你可以很容易地訪問元數據。

然而，用户在共享文件之前，往往不注重消除或擺脱元數據。主要是因為他們可能不知道有什麼簡單的工具可以使這項工作更容易。

Metadata Cleaner 就是這樣一個供 Linux 用户使用的工具。

Metadata Cleaner：輕鬆擺脱你的元數據 ​

Metadata Cleaner 幫助你刪除與元數據相關的信息的痕跡。它利用 mat2 來刪除元數據。

換句話説，你可以將這個 GUI 當成 mat2 的前端。

例如，一張照片包括拍攝地點、使用的相機、鏡頭信息等信息。

雖然這對某些人來説可能是有用的信息，但如果你想保持各種細節的私密，你就需要刪除元數據。

文件的情況也是如此。刪除元數據可以確保提高隱私性，無論是對你的業務還是個人使用。

你可以添加目標文件，並使用 Metadata Cleaner 處理它們，使它們得到清理。

注意：在清理之前，你必須保留一份文件的備份。擺脱你的元數據可能會導致你的文件發生劇烈的變化，比如無法選擇 PDF 文件中的文本，壓縮圖片等。

Metadata Cleaner 的特性 ​

Metadata Cleaner 是一個簡單的工具，具有一些有用的功能。讓我在下面提到它的主要亮點：

  • 能夠添加多個文件進行清理。
  • 檢查每個添加的文件的元數據信息。
  • 查看與每個添加的文件相關的元數據信息的數量。
  • 一鍵式清理，最大限度地去除元數據。
  • 有一個輕量級的清理模式，不會對文件造成很大影響。
  • 支持鍵盤快捷鍵。
  • 可以從內部創建一個新的窗口。
  • 你可以添加整個文件夾來處理多個文件。

在 Linux 中安裝 Metadata Cleaner ​

Metadata Cleaner 是以 Flatpak 包 的形式提供的。因此，考慮到你 設置了 Flatpak 或者你已經啓用了它，你可以在任何 Linux 發行版上安裝它。

你可以在終端使用以下命令來安裝它（如果你沒有軟件中心集成）：

flatpak install flathub fr.romainvigier.MetadataCleaner

你可以到它的 網站 或 GitLab 頁面 去探索更多關於它的信息。
