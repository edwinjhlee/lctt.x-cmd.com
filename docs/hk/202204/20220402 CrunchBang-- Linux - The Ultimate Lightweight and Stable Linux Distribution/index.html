CrunchBang++ Linux —— 極致輕量和穩定的 Linux 發行版本 ​

我們來對基於 Debian 的、由 Openbox 驅動的輕量級 Linux 髮型版本 Crunchbang++ Linux 進行了評測，併為你提供瞭如何使用它的指導。

CrunchBang 項目已經停止維護，CrunchBang++ Linux 是這個獨特的項目的繼承者。早期的 CrunchBang Linux 很受歡迎，因為它使用非常少的系統資源，對低端硬件也很友好。而 CrunchBang++ 也有一個 32 位的安裝程序（現在很少見），可以在過時的硬件或 PC 上正常運行。

在我們之前介紹 頂級輕量級 Linux 發行版 的文章中，有讀者評論想讓我們介紹 CrunchBang++。因此，我們想從性能、無障礙訪問和其他因素等方面對這個超級輕量級的 Linux 發行版做一個深入的研究。讓我們深入瞭解一下。

CrunchBang++ Linux 測評 ​

現場介質和安裝 ​

目前為止，CrunchBang++ 基於最新的 Debian 11 Bullseye，並提供 32 位和 64 位 ISO 變體。你可以從其 官方網站 下載。本文中，我們使用 64 位的安裝程序，其大小為 1.6 GB，與當今流行的 Linux 發行版的 ISO 大小相比，是很小的。例如，最新的 Ubuntu 64 位桌面 ISO 就很大，已經超過了 3.2 GB。

安裝程序的啓動菜單提供了測試現場鏡像Live Image和啓動安裝程序的選項。你可以先從現場鏡像開始。但是，你不能從現場介質安裝！相反，你必須再次啓動並選擇重新安裝選項。現場桌面Live desktop的用户 ID 和密碼都是 “live”。

在物理機和虛擬機（virt-manager）上的安裝都很順利。CrunchBang++ 使用 Debian 的原生安裝程序，這有點複雜。但你可以按照屏幕上的指示輕鬆地安裝它。如果你不熟悉 Debian 安裝程序，你可以參照我們的 Debian 安裝指南。

在虛擬機和物理系統上安裝過程平均需要約 5 到 10 分鐘。

桌面初窺 ​

CrunchBang++ 給你經典的 Openbox 窗口管理器體驗。登錄屏幕出乎意料的乾淨和完美，只有輸入憑證的選項。

如果你是第一次運行它，有一個歡迎腳本會引導你檢查網速，更新你的系統，等等。

Openbox 本身是快速和乾淨的。桌面以其預先配置的 SBPP Openbox 主題帶來了一個整潔的外觀，其組件如下：

  • gmrun：一個輕量的應用程序啓動器
  • Tint2：桌面頂層的控制面板
  • dmenu：動態菜單系統

你可以通過右鍵菜單的簡單配置選項來配置它們。

默認情況下，可以通過頂部面板切換兩個工作區。頂部面板也有基本的托盤圖標以滿足你的需要。

  • 音量控制
  • 網絡連接
  • 語言工具
  • 電量監控
  • 剪貼板管理

作為一個窗口管理器，這裏沒有應用程序視圖。但有了 gmrun 應用程序啓動器，啓動任何應用程序都超級容易。當你需要啓動任何應用程序時，Openbox 右鍵菜單會給你所有的選項。

無障礙訪問和應用程序 ​

CrunchBang++ 只包括最低限度的應用程序，以保持 ISO 和安裝的輕便。以下是預裝的應用程序。

  • GIMP
  • Thunar 文件管理器
  • Catfish 文件搜索
  • Gnumeric
  • VLC 媒體播放器
  • Filezilla
  • 遠程桌面客户端
  • Transmission Torrent 客户端
  • Screenshot 工具
  • Geany 文本編輯器

強大的 Synaptic 軟件包管理器會滿足你所有的軟件需求。LibreOffice 不是默認安裝的，所以你需要單獨安裝它。沒有用於集中設置的工具，所以有時你可能會覺得缺少一個設置管理器。

性能和資源佔用情況 ​

CrunchBang++ 的性能對於輕量級發行版來説是完美的。

這個發行版使用了 585 MB 的內存，空閒狀態下 CPU 佔用為 1%。如果你讓系統在非活動狀態下運行一個小時或更長時間，內存佔用會進一步減少到 350 MB 左右。這是一個令人印象深刻的指標。

為了測試重壓工作負載，我們在 CrunchBang++ 中打開了以下應用程序的一個實例：

  • Firefox 兩個標籤頁
  • Thunar 文件管理器
  • GIMP
  • Gnumeric
  • 文本編輯器
  • 終端
  • Catfish 文件搜索

整個工作負載佔用內存 1.07 GB，CPU 佔用為 5% - 7%。

這個發行版的默認安裝佔用了 4 GB 的硬盤空間。

連接性 ​

我們對它進行了下面列出的各種連接性測試。除了藍牙，它通過了每一項測試。

  • Wi-Fi 檢測和連接 —— 完美通過測試
  • 它在多個顯示器和分辨率配置下能正確工作（由於有預裝的 ARandR）
  • 自動檢測 USB（即使在虛擬機模式下） —— 正常通過測試

沒有用於藍牙的啓用、發現和連接的工具（有點像 Xfce 桌面）。所以，如果你安裝一個實用程序，你應該都能搞定。

CrunchBang++ 的一些缺點 ​

在我看來，這個 Linux 發行版應該由有一些經驗的用户來使用，他們在 Linux 中遇到的問題一般都能通過查閲資料解決，並且在需要時也能自如地使用終端。

我還發現了一些我認為默認安裝需要（而沒有安裝）的項目。在這個發行版中沒有辦法配置鼠標、鍵盤。沒有預裝任何工具。然而，你可以通過終端對它們進行調整。你可能需要安裝額外的應用程序來配置這些。

在“最近使用的應用程序”的右鍵菜單和 Nitrogen 壁紙更換器中有些錯誤。然而，對於你的日常使用來説，它們並不是一個障礙。

所以，總的來説，我認為它很穩定，儘管有所缺失，但可以很好地工作。

總結 ​

在結束對 CrunchBang++ 的測評時，我不得不説它是一個高效和實用的 Linux 發行版。它可能不是一個閃閃發光的桌面，但它是一個穩定的、生產級的 Linux 發行版，可以在任何硬件上運行。你可以很容易地把它作為你的日常使用系統，並在不用重裝你的整個系統的情況下使用它多年。CrunchBang++ 是貢獻者們創造出的偉大的軟件。
