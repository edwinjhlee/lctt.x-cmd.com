在 Linux 桌面上安裝隱私友好的 Signal ​

自從我們報道將 Signal 作為即時通訊軟件的理想選擇以來，已經過去一年多了。雖然具有隱私意識的人和靜態技術的人已經意識到了這個了不起的軟件的存在，與此同時，在最近的 WhatsApp 隱私政策更新之後，Signal 更是得到了很多人的褒獎。

無論什麼原因，如果你對 Signal 一無所知，想知道是否能在桌面上使用 Signal，那麼答案是肯定的。你可以在 Linux、Windows 和 macOS 系統以及智能手機上安裝 Signal。

我不打算強調 Signal 的功能，因為你可能已經有所瞭解。我只想向你展示在 Linux 桌面上安裝 Signal 的不同方法：

  • 用 Snap 包在 Liunx 上安裝 Signal（Snap 應用程序需要更長的時間來加載，但可以獲得自動更新和輕鬆的安裝）
  • 用 apt 包在基於 Debian 和 Ubuntu 的發行版上安裝 Signal（添加軟件庫需要額外的操作，但已安裝的應用程序會自動更新）
  • 用 AUR 在 Arch 和 Manjaro Linux 上安裝 Signal
  • 用 Flatpak 包在 Fedora 等 Linux 系統上安裝 Signal

你可以基於你的發行版和偏好來選擇這些安裝方法的其中一種：

方法 1：用 Snap 包在 Linux 上安裝 Signal ​

如果你正在使用 Ubuntu，你可以在軟件中心找到 Signal 桌面版程序的 Snap 格式的軟件包。

或者，你可以在任何 有 Snap 包支持功能的 Linux 發行版 上 使用 Snap 命令 安裝 Signal。

sudo snap install signal-desktop

你可以使用 snap remove 命令或者從軟件中心刪除它。

有些人不喜歡 Snap 包是因為它們啓動時間太長。好消息是你能夠使用 apt 命令來安裝 Signal。下一節我們討論它。

方法 2：通過 apt 在基於 Debian 和 Ubuntu 的發行版上安裝 Signal（使用官方 Signal 倉庫） ​

這裏是你在 Debian、Ubuntu、Linux Mint、elementary OS 和基於 Debian/Ubuntu 的其他發行版中安裝 Signal 必須遵循的步驟。你可以 複製這些命令並將其粘貼到終端。

第一件事是得到官方 Signal 倉庫的 GPG 密鑰，並且把它加入到你的 APT 包管理器可信任的密鑰中。

wget -O- https://updates.signal.org/desktop/apt/keys.asc | sudo apt-key add -

密鑰添加之後，你可以將倉庫安全的添加的你的系統中。不要因為倉庫名稱使用了 xenial 就驚慌失措。它可以在 Ubuntu 18.04、20.04 和更新的版本以及 Debian、Mint 等系統中工作。

echo "deb [arch=amd64] https://updates.signal.org/desktop/apt xenial main" | sudo tee -a /etc/apt/sources.list.d/signal-xenial.list

藉助 Linux 的 tee 命令，在 /etc/apt/sources.list.d 目錄下你將會有一個叫做 signal-xenial.list 的新文件。這個新文件有 Signal 倉庫信息即 deb [arch=amd64] https://updates.signal.org/desktop/apt xenial main。

既然你已經添加了倉庫，那麼來更新緩存並安裝 Signal 桌面程序吧：

sudo apt update && sudo apt install signal-desktop

一旦安裝成功，在程序菜單找到 Signal 然後啓動它。

由於你已經添加了倉庫，你安裝的 Signal 程序將會伴隨系統日常更新而自動更新。

享受在 Linux 桌面上使用 Signal 加密通訊的樂趣吧。

刪除 Signal ​

如果我不分享給你刪除的步驟，那麼指南是不完整的。讓我們看一下。

首先，刪除該程序：

sudo apt remove signal-desktop

你可以留下它，也可以從系統中刪除 Signal 倉庫。對你來説是都是可以的。倉庫繼續在系統裏的話，你可以輕鬆的再次安裝 Signal。如果你刪除了倉庫的話，你得按照之前的步驟再次重新添加倉庫。

如果你也想同時刪除掉 Signal 倉庫，你可以選擇圖形化方法，通過“軟件和更新”工具，在那裏刪除它。

或者，你可以用 rm 命令來刪除這個文件：

rm -i /etc/apt/sources.list.d/signal-xenial.list

方法 3：用 AUR 在 Arch 和 Manjaro Linux 上安裝 Signal ​

通過 AUR 在 基於 Arch 的 Linux 發行版 上安裝 Signal 是有效的。如果你在 Manjaro 上使用 Pamac 並且啓用了 AUR，在包管理器裏你可以找到 Signal。

否則，你可以經常 使用 AUR 輔助工具。

sudo yay -Ss <package-name>

我相信你能夠在相似的功能中刪除 Signal。

方法 4：用 Flatpak 包在 Fedora 等 Linux 系統上安裝 Signal ​

Signal 沒有 RPM 的安裝文件。然而，Flatpak 包是有的，你可以在 Fedora 上用它來安裝 Signal。

flatpak install flathub org.signal.Signal

一旦安裝成功，你可以從菜單中運行它，或者在終端中輸入以下命令：

flatpak run org.signal.Signal

Signal 和 Telegram 是拋棄掉 WhatsApp 的兩個主流而可行的選擇。這兩個軟件都提供原生的 Linux 桌面程序。
