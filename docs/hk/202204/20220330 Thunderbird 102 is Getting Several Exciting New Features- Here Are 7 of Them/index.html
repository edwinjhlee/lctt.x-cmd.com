7 個 即將發佈的 Thunderbird 102 版本的新功能 ​

Thunderbird 102 將帶來有用的新功能以及 UI/UX 升級。在此查看其中最精彩的內容！

毫無疑問，Thunderbird 是 Linux 上最好的 電子郵件客户端 之一。

它是 Mozilla 基金會的一個開源產品，是一個具有強大功能的可靠的電子郵件客户端。

在 最近的更新 中，它已經新增了一些功能以及視覺上的改進。

現在，隨着 Thunderbird 102 版本即將發佈，它將添加更多激動人心的功能。

在一條 推特討論 中，Thunderbird 分享了所有關於此次更新的信息。我在這裏挑選其中的關鍵亮點介紹一下。

Thunderbird 102：更新了什麼？ ​

Thunderbird 102 版本將是一次重大升級，它增加了一些有用的功能，預期發佈時間 為 2022 年 6 月 28 日。其中包括下面這幾個變化：

  • 空間工具欄
  • 新的地址簿
  • 支持 Matrix 協議
  • 鏈接預覽卡片
  • 賬户設置中心
  • 導入/導出
  • 重新設計的郵件標題欄

這聽起來不錯吧，這裏還有一些關於以上變化的更多細節。

1. 空間工具欄 ​

新的“空間工具欄Spaces Toolbar”位於左邊的側邊欄中，它將不同的活動以圖標的形式分隔開來。

你可以更容易地在電子郵件客户端內的多個標籤間導航，也可以更容易地管理它們。

你也可以摺疊工具欄，讓它作為一個圖標顯示在標籤欄中，為你節省一些屏幕空間。

2. 新的地址簿 ​

地址簿有了新的外觀，它應該能幫助你輕鬆找到你的聯繫人，並與他們進行互動。

聯繫人信息的整體佈局看起來更容易訪問，它提供了你想知道的所有細節，理應也能為你提供良好的用户體驗。

3. 支持 Matrix 協議 ​

Matrix 是一個流行的分佈式開源聊天協議。因此，在 Thunderbird 102 版本中，你將能夠開箱即用 Matrix 的聊天功能，非常輕鬆。

Matrix 最初只在測試版中作為實驗性功能提供。

你可以期待它在未來的進一步完善。

4. 鏈接預覽卡片 ​

鏈接預覽將幫助用户建立對鏈接內容的預期，有助於改善用户體驗。

而且，對於像 Thunderbird 這樣的直截了當的電子郵件客户端，我從未指望它會提供鏈接預覽這樣的功能，直到現在。

每當你在電子郵件編輯器email composer中添加一個鏈接時，你都可以選擇將其轉換為豐富的鏈接預覽。

5. 賬户設置中心 ​

對於任何服務/應用程序來説，有一個簡單的設置過程都是極其重要的。

Thunderbird 102 版本改進了所有賬户設置功能的體驗，如添加賬户、管理日曆、導入配置文件等。

6. 默認的導入/導出功能 ​

到目前為止，你都必須依靠一個插件來導入/導出個人資料數據。

而在 Thunderbird 102 版本中，導入/導出功能將是開箱即用的，無需使用附加組件。

7. 重新設計的郵件標題 ​

郵件的標題/主題得到了細微的升級，以更好地突出重要信息，並使其在導航時能夠快速響應。

其他變化 ​

除了以上的關鍵亮點外，你還可以得到許多技術升級和錯誤修復。

例如，OpenPGP 的用户體驗和用户交互也得到了升級，同時還有一個新的存儲格式：Maildir。

你對 Thunderbird 102 版本即將新增的功能有什麼看法嗎？你對 Thunderbird 的用户體驗/用户交互升級感到興奮嗎？請在下方的評論區中説説你的想法，或只是簡單説聲“謝謝”。
