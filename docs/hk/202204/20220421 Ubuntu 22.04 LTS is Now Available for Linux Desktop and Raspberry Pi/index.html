Ubuntu 22.04 LTS 發佈！ ​

Ubuntu 22.04 LTS 帶來了許多驚喜，還帶來了 GNOME 42，以及 Canonical 的新品牌/標誌。

迫不及待地想嘗試 Ubuntu 22.04 LTS？那麼，它終於可以下載和升級了。（LCTT 譯註：升級還要等幾天，還存在一些小問題）

它帶來了 大量令人印象深刻的功能，其中 GNOME 42 和樹莓派桌面支持是其主要亮點。

現在，它已經就緒。在你決定嘗試之前，讓我們花點時間來看看這個版本最重要的變化。

Ubuntu 22.04 LTS 的新變化 ​

Ubuntu 22.04 是一次主要版本升級，其包括了桌面環境的改進、視覺上的變化和一些新增的功能。

如果你正在使用 Ubuntu 20.04 LTS，想知道它們之間的區別，你可以查看我們的《Ubuntu 20.04 vs Ubuntu 22.04 LTS》文章來了解。

毫無疑問，這是一個 長期支持Long-Term Support （LTS）版本。所以，你可以期待它維護更新到 2027 年，也就是五年的支持。一些最顯著的變化包括：

1、強調色的選擇 ​

雖然大多數基於 Ubuntu 的 Linux 發行版提供了設置強調色的功能，但你必須使用 GNOME 優化GNOME Tweaks 才能做到。

現在，在 Ubuntu 22.04 中，你可以輕鬆地設置你所選擇的強調色，它會影響到文件夾、通知區和桌面體驗的其他元素。

2、GNOME 42 ​

期待已久的桌面環境升級來了。雖然 Ubuntu 22.04 的 GNOME 實現並不提供水平停靠區，但會有其它好處加成。

你應該能夠在 Ubuntu 22.04 LTS 中體驗到所有 GNOME 42 的優點。不幸的是，你仍然會發現幾個版本號是 41 的應用程序。

開發者提到，他們需要更多的時間來測試使用 libadwaita 的應用程序。

話雖如此，在你繼續閲讀時，我也會提到 GNOME 42 所帶來的有趣的更多功能。

3、新的屏幕截圖工具 ​

與 Ubuntu 20.04 LTS 不同，你不能用 PrtScrn（或任何其他指定的快捷鍵）來直接抓拍全屏圖片。

相反，如果你按下快捷鍵來截圖，就會彈出來這個新的截圖工具。

這不僅體驗更加直觀，而且還支持屏幕錄製。因此，這是一個相當令人激動的變化！

4、深色模式的改進 ​

雖然我們已經有了深色模式，但它並不是一個完美的系統級實現。

感謝 elementary OS 6，GNOME 42 受到啓發，實現了系統級的深色模式，更好地融合在一起以保持一致性。

5、Firefox 變成了 Snap 版本 ​

從 deb 包到 Snap 的過渡已經進行了一段時間了。

在 Ubuntu 22.04 中，Firefox 現在將默認以 Snap 包出現，在 Mozilla 的共同努力下，旨在推動更快的安全更新，並確保無需維護許多東西即可實現跨發行版的支持。

沙盒化的 Firefox 體驗也應該可以提供更好的安全性。

你可以在這個 論壇帖子 中閲讀更多關於該決定背後的信息。

6、桌面圖標出現在底部 ​

默認情況下，桌面圖標可以在右上角的區域看到，靠近停靠區。

現在，在 Ubuntu 22.04 中，默認的桌面圖標位置已經被改為底部。你可以通過“外觀Appearance”設置中的選項來改變這一點。

7、縮小停靠區的能力 ​

如果你不喜歡停靠區佔據了整個左側區域，你可以改變它。

你需要禁用“外觀Appearance”調整中停靠區設置下的“面板Panel”模式，如下圖所示：

這將分離出停靠區，並提供現代桌面體驗的浮動效果。

8、樹莓派桌面支持 ​

Ubuntu 22.04 是第一個也可用於樹莓派的桌面 LTS 版本。

隨着 zswap 的引入，樹莓派的性能應該會在 Ubuntu 22.04 中得到顯著提升。

它甚至可以 在 2GB 的樹莓派 4 變體型號上運行。你可以在你的樹莓派上測試這些改進。

9、使用 Ubuntu Advantage ​

Ubuntu Advantage 是為企業和商家提供的高級訂閲，無需重新啓動即可獲得重要的安全更新。

對於大多數桌面用户來説，這不是什麼有用的東西。然而，如果你想獲得 Ubuntu Advantage 訂閲，並將你的系統接駁到它，你可以通過導航到“軟件 & 更新Software & Updates”下的 Livepatch 部分輕鬆做到這一點。

10、Linux 內核 5.17 和 Linux 內核 5.15 LTS ​

Linux 內核 5.15 LTS 是一個重要的升級，它改進了 NTFS 驅動，對即將到來的英特爾獨立顯卡提供了初步支持，並有更多的性能改進。

對於你的桌面計算機，你應該注意到 Linux 內核 5.15 開箱即用。

Ubuntu 服務器版也採用了 Linux 內核 5.15 LTS。

然而，Ubuntu 22.04 也在最新一代認證設備（OEM）上使用了 Linux 內核 5.17。

因此，在這個版本中，Ubuntu 根據產品的不同打包了多個內核。

11、RISC-V 的現場鏡像 ​

從 Ubuntu 22.04 開始，你會發現單獨的可用 RISC-V 架構的現場鏡像live image。

其他變化 ​

除了上面提到的主要變化外，升級後的其他一些重大變化包括。

  • 較新的軟件包，如 OpenSSL 3.0、Ruby 3.0、Python 3.10、PHP 8.1 等。
  • 更新的應用程序，包括 Firefox 99、LibreOffice 7.3 和Thunderbird 91。

你可以看一下它的 官方發佈説明 來探索所有的技術變化。

下載或升級到 Ubuntu 22.04 LTS ​

如果你想通過使用 ISO 進行全新安裝來體驗新的 LTS 版本，請前往下面鏈接的官方網站進行下載。

下載 Ubuntu 22.04 LTS

而當它的更新可用時，你可以參考我們的 升級指南。

注意： 你可以進行全新的安裝，但是你還不能升級到 Ubuntu 22.04 LTS（由於 snapd 和 update-notifier 軟件包的錯誤有待修復）。你應該在接下來的幾天裏收到更新通知。
