elementary OS 系統走到頭了嗎？ ​

Cassidy James 是 elementary OS 系統的創始人，根據他最近的聲明得知他已經辭職。下面是我們對這一話題的看法，以及可能的未來。

早在十年前，當 elementary OS 首次發佈時，它率先帶領 Linux 桌面領域邁出了新的一步。Cassidy 有一個願景，從那時只有開發者和貢獻者在使用的 Linux 桌面，到全世界用户都能夠使用它。它的 Pantheon 桌面是最好的桌面之一，從一開始就是為美學和生產力而設計的。

多年來，elementary OS 已經成長起來了。它的用户羣和受歡迎程度一直在增加，因為它的穩定性、基於 Ubuntu 長期支持版，對於那些希望在 Linux 中擁有類似 macOS 的用户界面的人來説，是一個完美的桌面。它的基於 Flatpak 的應用商店也是在 Linux 生態系統中最好的應用商店之一，具有一套精心打造的應用程序。

如果你用免費軟件經營公司，除非你有一個在背後支撐的企業和其它盈利模式，否則這些優勢和良好的用户反饋，是無法變成盈利的。

為什麼會出現這種情況，這是 elementary OS 系統的終點嗎？ ​

elementary OS 有一個 “付費下載” 的收入模式，這是自願的。但是疫情已經兩年了，這方面的銷售收入也在下降，該公司的領導層為了維持公司運轉，已經削減了全職員工的工資和醫療福利。

“自從我全職投入 elementary 公司以來，每一個版本的銷售業績都要比上一個表現要好，直到 OS 6 和 6.1 的業績表現遠遠低於預期，部分原因是持續的全球疫情，人們看起來在能免費下載操作系統的時候，不再想支付可選的金額來下載它。很明顯，我們需要重新確定我們公司財務的優先次序，同時堅定我們的開源、以隱私為中心和道德的籌資信念。”Cassidy 在他的告別信中説道。

全球經濟在疫情的打擊下，所有人和事都無法倖免。elementary OS 6 Odin 的發佈並不順利。有一些錯誤、英偉達顯卡的問題和其他問題，全球疫情和貢獻的減少也影響了軟件的質量。這最終影響到了自願付費下載的收入。

自願付費下載模式、GitHub 的贊助，用來維持企業運轉和大型項目是遠遠不夠的。如果你看看其他的主流開源項目，如 Fedora Linux、GNOME、KDE Plasma，它們都有來自 Red Hat、IBM、Google 等大企業的大量贊助。而這是有原因的，這些大公司都從這些開源項目中獲得商業利益。但是對於 elementary OS 來説，情況就有點不同了。

Cassidy 又寫道，“結果，Dani 要求我辭職，並完全離開 elementary。在我尋找另一個職位時，這並不是我的本意，但是 Dani 一直堅持（要我離開）。最後，我決定，最好的行動方案確實是我繼續前行；我放棄了我對 elementary 十多年的激情，接受了 Dani 的提議，讓她成為 elementary 公司唯一的、100% 的所有者。我已經簽署了我的辭呈。從今天起，她現在擁有公司的所有股份和責任。我祝願她在延續公司的遺產方面取得最好的成績。”

展望未來 ​

確實，我能在告別信中感受到 Cassidy 的感情。放棄你多年來建立的項目和激情是不容易的。那裏有你在為社區獲得更大利益的願景而投入的無數個日日夜夜。你的感情與之相連。放棄並不容易。

沒有人能夠預測未來。所以，我們不知道在未來的日子裏 elementary OS 系統作為一個項目會發生什麼。當情況發生了，開源公司最終會成為一個有更多受眾和貢獻者的社區項目。我覺得新的領導人需要看看 elementary OS 在 Linux 發行版或桌面領域方面的未來路線圖。

因為帶有 GTK4/libadwaita 的 GNOME 42+ 看起來很有前途，elementary OS 可能會因為 GNOME 而失去用户羣。在這種情景下，唯一的賣點只有 Pantheon 桌面，這就需要更多的打磨和市場化能力，同時新的領導層也需要尋找更好的收入模式。

我們希望，作為一個社區，elementary OS 能夠繼續推出新版本，如果必要的話，讓它成為沒有 GitHub 贊助牆的社區項目。而我認為尋找企業基金和捐贈也可以成為維持項目運行的長期選擇之一。

任何開源項目都不應該停止。我希望新的領導層能夠找到更好的收入模式來維持這個項目。只要思想不滑坡，方法總比困難多。

所以，關於這整個情況你有什麼看法？在下方評論讓我知道。
