Xfce Terminal 1.0.0：時隔一年後的一次功能豐富的重大升級 ​

在其上一個主要版本發佈一年後，Xfce Terminal 1.0.0 終於來了。興奮地想了解一下新的改進嗎？讓我們來看看！

作為幾乎在所有采用 Xfce 的發行版上流行的終端模擬器，Xfce Terminal 剛剛由新的維護者（及新的版本計劃）發佈了它的第一次重大升級。

讓我們來看看這個版本的一些亮點。

新的維護者和版本管理方案 ​

Igor Zakharov 從 2016 年到 2020 年一直在領導它的開發工作。不幸的是，在 2021 年它就沒有被維護過，直到新的維護者 Sergios Anestis Kefalidis（也是 Thunar 文件管理器的開發者）接手。

而且，自從 Sergios 接管了這個項目後，版本管理方案也發生了變化。經過與社區的協商，採用了 Thunar 的舊版本計劃。

例如，1.1.x 版本將是開發版本，而 1.2.0 版本將是下一個主要升級版本。

現在，隨着 Xfce Terminal 1.0.0 的發佈，一些令人興奮的新特性已經被納入。

新特性 ​

Xfce Terminal 1.0.0 的一些新特性包括：

  • 改進了自定義選項
  • 支持疊加滾動條
  • 命令列選項的改進
  • 更多使用 XfceTitledDialog

更好的自定義選項 ​

和現在許多應用的更新一樣，Xfce Terminal 1.0.0 包括大量新的自定義選項。也許我最喜歡的是，圖像背景功能現在有一個“填充”風格選項。伴隨着這一點的是暫時禁用不安全的粘貼對話框的能力，它也被改造了。

最後，Xfce Terminal 也成為首批支持新的 Xfce 快捷鍵編輯器的應用之一。因此，用户不再需要潛心研究配置文件，而是有了一個可以使用的簡單 UI。

有了這麼多新的定製選項，我相信很多人都會對一個只是包含這些的版本感到滿意。但是！開發者設法加入了更多令人興奮的新功能，其中下一個是改進的命令列參數。

更好的命令列參數 ​

在這個版本中，修復了 -tab 和 -window 命令列參數，變得更加直觀。這修復了 Xfce Terminal 中一個 長期存在的錯誤，它已經存在了近 6 年。

儘管等待了很久，但現在它已經被修復了。遲到總比不到好，是吧？

不管怎麼説，看到每一個新版本的錯誤被修復總是很好的，這個趨勢在這裏繼續。

更多使用 Xfce 專用的小工具 ​

雖然我相信很多用户可能會認為這是一個退步，但 Xfce Terminal 使用更多的 Xfce 專用小工具帶來了很多好處。雖然這對非 Xfce 用户確實意味着要安裝更多的依賴關係，但它意味着與 Xfce 更好的整合。

可以説，大多數的 Xfce Terminal 用户都堅持使用同樣的 Xfce 桌面環境。所以，這種改變應該會帶來更大的一致性和用户體驗的改善。

其他變化 ​

這個版本的其他變化包括：

  • “輸出滾動”偏好設定的改進
  • 右鍵點擊行為的自定義選項
  • 為縮小代碼庫而進行的代碼重寫

關於完整的功能列表，請隨時參考 發佈説明。發佈説明中還提到了下一個主要版本的未來計劃，即 v1.2.0。

總結 ​

總的來説，Xfce Terminal 1.0.0 看起來是一個不錯的版本，也説明了其新的維護者的奉獻精神。

如果你想試試 Xfce Terminal 1.0.0，它應該會在接下來的幾周內進入你的發行庫，如果現在還沒有的話。
