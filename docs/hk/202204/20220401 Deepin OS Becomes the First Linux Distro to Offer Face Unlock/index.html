深度操作系統成為首個支持人臉解鎖的 Linux 發行版 ​

在提供現代桌面體驗方面，深度佔據了領先地位。

在深度問世時，人們都為它純粹的漂亮界面而驚歎。

隨着時間的推移，開發人員越來越有經驗，他們把重點轉移到了系統設計和功能上，力求在這些方面和其他的商業操作系統看齊，我指的是 Windows 和 macOS。深度是首個支持安卓應用和雲同步等功能的發行版。

相信我，這是一件好事情。

Linux 發行版以各種桌面環境的形式向大眾提供。深度看起來很主流，可以吸引年輕羣體。

中國的深度開發團隊的也有相同目標，因此深度發佈了 20.5 版本，該版本主要亮點是面部識別。

深度操作系統 20.5 的新功能 ​

新版本根據用户的反饋增加了幾個功能。穩定的內核版本現在已經升級到 5.15.24，並修復幾個錯誤，以加強系統安全性。

讓我們來看看這個版本還有哪些新功能吧。

Linux 上有了面部解鎖 ​

是的，我知道 Linux 上早就有面部解鎖的相關消息了。畢竟，我曾經寫過一篇關於 在 Linux 發行版中使用類似 Howdy 的軟件來支持面部解鎖功能 的詳細指南。

然而，那些軟件更多的是一種個性化定製，是為那些有經驗的、愛折騰的用户準備的。

深度現在提供基於人臉的生物識別認證方法。它可以在有內置攝像頭的筆記本電腦上工作。

你需要先在控制中心錄入人臉信息，此後，你就可以用你的人臉 ID 登錄系統。

用户可在應用商店中反饋 ​

你現在可以直接在應用商店中提交對某個應用的反饋。

這還不算完。當你有應用程序的安裝和更新問題時，你可以在應用程序中直接向官方支持提交問題，並獲得解決方案（如果開發者提供了的話）。

改進的郵件應用 ​

深度郵件應用現在支持了自定義文件夾管理。它還可以在網絡重新連接後自動接收郵件。郵件應用的框架和插件已經替換成了當下流行的 Vue + TinyMCE。

現在，你可以通過點擊系統通知直接跳轉到到新郵件。為提高工作效率，你可以置頂常用郵件與合併郵件。你也可以預覽郵件附件。

可以“釘住”的屏幕截圖 ​

你現在可以使用內置的屏幕截圖工具來“釘住”截圖。這樣一來，捕獲的屏幕截圖就會固定在其他應用程序窗口的頂部。從而，你可以同時使用其他應用程序，以提高你的工作效率。另外，置頂的屏幕截圖是可以移動的。

其他變化 ​

下面是 Deepin 20.5 新版本中的一些其他變化：

  • Linux 穩定內核更新到了 5.15.24
  • 可以為一個有線網絡適配器設置多個 IP
  • 優化了無線網絡的密碼認證交互
  • 系統搜索現在可以使用文件類型和擴展名作為關鍵詞
  • 設備管理器允許你禁用或啓用設備
  • 瀏覽 docx 文件的文檔查看器得到了性能優化

還有許多我沒有提到的小功能和改進。你可以在 版本發佈説明 中瞭解這些內容。
