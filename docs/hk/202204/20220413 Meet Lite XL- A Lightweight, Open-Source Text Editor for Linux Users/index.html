Lite XL：為 Linux 用户提供的輕量級、開源的文本編輯器 ​

你是否在尋找一個新的文本編輯器替代品？你應該試試這個輕量、簡潔、快速、功能豐富、可擴展性極強的編輯器。

當然，有很多文本編輯器或代碼編輯器可以使用。一些流行的包括 Eclipse、Visual Studio Code、PyCharm、Atom、IntelliJ，以及 Sublime Text。

但是你想嘗試一些有趣的東西，完全專注於給你一個極簡的體驗嗎？

來認識一下 Lite XL 編輯器。

説實話，在上週之前我對它一無所知。但是，它以其 極簡主義的設計 和它 在編碼時有多麼快 成功地驚到了我，但最重要的事實是它與 Visual Studio Code 相似。

所以，在開始之前，讓我告訴你，如果你是一個 Visual Studio Code 粉絲，你絕對應該試試 Lite XL。它可能不是絕對的替代品，而是類似使用場景的精簡版。

Lite XL：用 Lua 編寫的輕量級文本編輯器 ​

Lite XL 是一個用 Lua 編寫的有趣的開源文本編輯器（特別是為建立輕量級應用而定製）。

它也可用於 Windows、Linux 和 macOS。但是，有這麼多 現代文本編輯器，為什麼還要有個 Lite XL？

通常情況下，大多數時候我們並不關心文本編輯器會消耗我們系統的資源。然而，在創建 Bash、Python 或任何其他類型的腳本時，你會依賴文本編輯器，而它的資源效率越高越好。

當然，文本編輯器並不像其他一些應用那樣對資源要求很高。但是，如果這對你很重要的話，我觀察到的情況是這樣的：

Lite XL 只使用了 3MB 的磁盤，並消耗了大約 20MB 內存，而 Visual Studio Code 使用將近 550MB 內存。

你能看到這些類似的編輯器之間的這種奇妙的差別嗎？

不僅僅是資源使用量，它也是高度可定製的。

請注意，在不同的系統配置下，資源佔用的統計數字會有所不同。

Lite XL 的特點 ​

根據現有的官方信息，其最受歡迎的一些功能包括：

  • 跨平台： 它目前可以在 Windows、Linux 和 macOS 上使用。
  • 輕量級： 正如我們之前所描述的，它的使用量幾乎沒有超過 10MB 的內存。
  • 可擴展： 作為一個極簡的產品，並不意味着不能定製。Lite XL 可以通過一些可用的插件來擴展其功能，例如，類似 Visual Studio Code 的智能提示。
  • 多光標編輯： 在 Lite XL 中，你可以使用多個光標進行編輯，這聽起來很美妙。
  • 集成的終端： 像 Visual Studio Code 一樣，Lite XL 實現了它的終端。
  • 支持高分辨率顯示。
  • 更多的顏色主題。
  • 支持硬件加速渲染。

如何在 Linux 中安裝 Lite XL ​

Lite XL 為 Linux 發行版提供了一個 AppImage 文件。你可以按照我們的 AppImage 指南 來開始使用。

你可以在其 GitHub 倉庫 中找到這個 AppImage 文件。

當你前往其 GitHub 發佈區，直接進入 “資產Assets” 區並下載 LiteXL_x86_64.Appimage 文件。

AppImage 文件將被下載到你的下載目錄中，因此，在雙擊該文件之前，請驗證它是否允許作為程序執行。

這就好了! 現在你可以雙擊該文件，開始在你的系統中使用 Lite XL。
