LibreWolf vs Firefox：誰是真的隱私英雄 ​

Firefox 是最好的跨平台 開源網頁瀏覽器 之一。

更不用説，它是那些基於 Chromium 的瀏覽器的唯一可行的替代品（也許？）

LibreWolf 是另一個有趣的選擇，它最初是 Firefox 瀏覽器的一個復刻，試圖比 Firefox 瀏覽器做得更好，以增強開箱即用的隱私/安全性。

但是，選擇 LibreWolf 而不是 Firefox 真的有用嗎？有哪些不同之處？讓我們來看一看。

用户界面 ​

鑑於 LibreWolf 是 Firefox 的一個復刻，其用户界面是相同的，只是有一些細微的變化。

例如，它在書籤菜單中沒有到 Firefox 網站的鏈接，並且去除了 “添加到 PocketAdd to Pocket” 按鈕。

取而代之的是，你可以在地址欄的右邊找到一個擴展的圖標和下載管理器。

是的，你不再需要前往菜單來訪問下載的內容。

如果你認為 Firefox 中的額外功能令人煩惱，那麼 LibreWolf 應該是一種乾淨的體驗。

搜索供應商 ​

默認情況下，Firefox 使用谷歌作為其搜索引擎，因為它們是官方合作伙伴，也就是説，谷歌付費成為了默認搜索引擎。

雖然你可以很輕鬆地將默認的搜索供應商改為 DuckDuckGo、Startpage 或其他任何東西，但默認的搜索供應商對大多數用户來説仍然很重要。

而對於 LibreWolf，它的默認的搜索引擎是 DuckDuckGo。眾所周知，它是最好的尊重隱私的搜索引擎之一。

應該注意的是，注重隱私的搜索引擎在某些使用情況下可能不如谷歌好。因此，如果搜索引擎的選擇對你來説並不是個問題，Firefox 瀏覽器可以説是很好。

但是，如果你想對自己的搜索歷史保密，LibreWolf 的默認搜索供應商肯定是一個更好的選擇。

強化隱私 ​

Mozilla Firefox 具有令人難以置信的可定製性。如果你想付出努力，你可以在 Firefox 上增強你的數字隱私。

然而，如果你想避免投入大量時間來調整 Firefox 的體驗，LibreWolf 可能是一個不錯的選擇。

LibreWolf 具有一些開箱即用的最佳設置，以確保你擺脱網上的跟蹤器，以獲得安全的在線體驗。

例如，它的默認帶有 UBlock 內容攔截器，以消除跟蹤你在線活動的跟蹤器/腳本。其默認的搜索引擎是 DuckDuckGo，在一定程度上也有幫助。

此外，LibreWolf 還啓用了 Firefox 增強跟蹤保護的嚴格模式。換句話説，它可以積極地阻止跟蹤器，這可能會導致一些網頁不能像預期那樣工作。

雖然 LibreWolf 建議不要改變這些設置，但如果你發現在此設置下網頁被破壞，你可以選擇使用 Firefox。

Firefox 使用啓用的基本保護來擺脱常見的追蹤器，而不會破壞網頁的用户體驗。

除了這些設置外，LibreWolf 還默認在退出時刪除 Cookie 和網站數據。如果你想繼續登錄網站並迅速恢復你的瀏覽會話，這可能會很煩人。

對於 Firefox，它確實具有相同的選項，但它默認情況下仍然是禁用的。因此，如果你想避免調整內置設置以獲得方便的體驗，你應該選擇 Firefox。

難怪 Firefox 仍然是 Linux 的最佳瀏覽器 之一。相比增強隱私，大多數用户更喜歡方便，同時還能跨平台使用瀏覽器。

谷歌安全瀏覽 ​

“谷歌安全瀏覽Google Safe Browsing”是一項有用的服務，可以警告、標記可疑網站的惡意活動。

大多數瀏覽器使用它來實現安全的用户體驗。你不需要成為發現釣魚/惡意軟件網站的專家，谷歌安全瀏覽可以幫助你發現它們。

Mozilla Firefox 使用它的另一個名字 “釣魚保護Phishing Protection”，它是默認啓用的。

然而，在 LibreWolf 中，“谷歌安全瀏覽”服務默認是禁用的，以避免連接到谷歌服務。你可以啓用它，但它不是用户通常在設置瀏覽器時會注意到的東西。

因此，如果你在避免惡意網站方面需要更多幫助，Firefox 應該是一個很好的開箱即用的解決方案。如果你對這些很清楚，你可以使用 LibreWolf，並在需要時啓用該設置。

附加功能 ​

LibreWolf 可以擺脱 Firefox 上的任何附加產品。

例如，默認情況下，LibreWolf 與 Mozilla 服務器沒有任何連接。這也意味着 LibreWolf 擺脱了遙測。它所反映的一些變化包括：

  • LibreWolf 中沒有同步/簽到功能。
  • 沒有 “添加到 Pocket” 的按鈕
  • 你不會在擴展頁面上加載 Mozilla 的附加組件/主題。

如果你想使用 Mozilla 帳户來同步你的歷史記錄/書籤和瀏覽器數據，Firefox 是最好的選擇。如果你需要，還有 Firefox VPN。

但是，如果你不信任任何 Mozilla 服務並希望在你的瀏覽器上切斷與它們的任何連接，那麼 LibreWolf 就是你的朋友。

跨平台支持 ​

Firefox 可用於 Android 和 iOS，並且適用於各種屏幕尺寸和設備。

不幸的是，LibreWolf 僅限於 macOS、Windows、OpenBSD 和 Linux 等桌面平台。

基於社區 vs 由組織支持 ​

LibreWolf 是一個由社區支持的項目，由一些熱情的貢獻者維護，旨在促進隱私、安全和用户自由。

如果你更喜歡 LibreWolf 提供的產品，那麼使用它應該不是問題。即使是一個小團隊，他們也會關注最新的 Firefox 版本並儘快推送更新。

相比之下，Mozilla 基金會是一個更大的組織，並且一直在樹立非凡的榜樣來促進可定製性、隱私和安全性。

Firefox 會比 LibreWolf 更快地收到更新，如果你擔心瀏覽器的安全性，這是一個重要方面。

Firefox 屬於一個大組織並沒有嚴重的缺點，但是 Mozilla 為其用户提出的未來可能會有一些你可能不喜歡的決定（或變化）。

但是，LibreWolf 作為一個社區項目，會優先考慮用户偏好。

總結 ​

如果方便是你在意的，你需要同步/登錄賬户功能、Mozilla 的特定功能，以及基本的隱私保護，Mozilla Firefox 應該更適合你。

如果你不想要開箱即用的雲同步功能、附加功能和以隱私為中心的核心設置，LibreWolf 將是完美的解決方案。

在性能方面，兩者都應該提供類似的體驗。由於某種原因，基準測試（Basemark 3.0、Speedometer 2.0）不適用於 LibreWolf，因此我沒有提供任何性能比較圖表。

我更喜歡使用 Firefox，因為我確實需要基於帳户的同步的便利性，而不需要積極的阻止功能。然而，對於那些想要放棄 Firefox 或者只是想嘗試一些專注於用户自由和隱私的東西的人來説，LibreWolf 是一個可靠的選擇。
