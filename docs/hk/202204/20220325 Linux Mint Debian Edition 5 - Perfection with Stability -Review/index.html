Linux Mint Debian Edition（LMDE） 5 – 完美穩定 ​

我們對最近發佈的 Linux Mint Debian Edition 5（LMDE 5）的性能、穩定性和用户友好性等方面進行了評測。這裏是我們的發現。

在 Linux Mint Debian Edition LMDE 4（Debbie）發佈兩年多後，Linux Mint 團隊宣告了 Linux Mint Debian Edition LMDE 5（LMDE 5）的發佈。LMDE 5 基於 Debian 11 Bullseye ，它帶來了長期支持的 Linux 內核 5.10 和 Debian 軟件包源。除內核版本以外，大多數的應用程序和軟件包與 Linux Mint 20.3 幾乎完全相同。

讓我們深入瞭解一下。

LMDE 5 評測 ​

我們測試 Linux Mint Debian Edition 5（LMDE 5）是在現有的較舊的硬件下：

  • 英特爾酷睿 i3 第一代
  • 4GB DDR3 內存
  • 博通芯片
  • 英偉達® GeForce® 315M
  • 固態硬盤

ISO 下載、現場介質和安裝 ​

從新設計的 Linux Mint 網站找到並下載 ISO 文件是很容易的。現場介質Live media啓動很順利，通過桌面上的安裝圖標啓動了安裝程序。

LMDE 使用的一款修改版的 Debian 安裝器。它不是 Calamares 。普通的 Debian 安裝器是很難操作的，[在我看來] 有點 讓新用户感到困惑 。但是，Linux Mint 團隊使其非常容易安裝，只需幾個步驟，並從 Debian 安裝器中移除了所有使人困惑的選項。

你只需要提供安裝位置、鍵盤佈局、名字和密碼，就可以開始安裝了。安裝器的分區系統使用 GParted ，它很方便好用。

因此，在我的測試的虛擬機和物理機硬件中，安裝過程都很順利。

在物理機系統中安裝花費了 4 到 5 分鐘，而虛擬機系統中的安裝時間約為 3 分鐘。

第一印象 ​

如果你熟悉 Linux Mint 早期的 Cinnamon 桌面，那麼你不會在這個 Debian 版本中找到什麼不同。它們是一樣的。如果你是第一次使用 Linux Mint 的 Cinnamon 桌面環境，那麼在你完成你的安裝後，你會看到一個漂亮而乾淨的桌面。

桌面圖標、完美調整過的顏色和主題、底部任務欄、系統托盤，這一切都配合有序，讓你能夠立刻上手。

不管你使用低端還是高端的硬件，LMDE 都能快速響應，應用程序能夠很好的工作。應用程序的切換和整體桌面的響應都很可靠。

你得到的是經過良好測試的應用程序和軟件包，而基於 Debian 的穩定性，很少會出現故障。這意味着不必擔心軟件包的衝突、更新缺失，以及 Linux 系統的常見問題。

預裝的應用程序 ​

Linux Mint（不僅僅是 Debian 版本）的優勢之一是它的預裝的應用程序。許多 Linux 發行版由於 ISO 大小等原因，在 ISO 安裝程序中不包括必要的應用程序。

但是，Linux Mint 團隊全心全意為它們的用户考慮，打包了所有你需要的必要應用程序。這照顧到了大多數用户的需求。它有助於減少最終用户在安裝 LMDE 5 後搜索和安裝兼容應用程序方面的負擔。

例如，在 LMDE 5 中，已默認安裝下面的必備軟件，隨時待用：

  • 繪圖應用
  • 多媒體：Celluloid 媒體播放器、Hypnotix、Rythmbox
  • Torrent 客户端：Transmission 3.0
  • 完整的辦公套件：LibreOffice 7.0
  • Email 客户端：Thunderbird 91.0
  • 網頁瀏覽器：Firefox 97.0

這不是所有。對於下面的所有的具體使用情況，你都會得到一個專門的原生應用程序。用户不需要為這些尋找一個單獨的應用程序：

  • 屏幕截圖和屏幕保護程序
  • 減少眼睛疲勞的工具
  • USB 格式化工具和鏡像寫入器
  • 便籤
  • Synaptic 軟件包管理器
  • 系統備份和恢復
  • 防火牆工具

LMDE5 的性能表現怎麼樣? ​

看到一個發行版按照預期的表現，總是令人感興趣的。而 LMDE 5 的性能表現遠超預期。

在空閒狀態下，它消耗 750 MB 的內存和 2% 的 CPU 。

接下來，我使用下面的任務讓它完成繁重的工作負載：

  • Firefox（打開三個標籤頁，其中一個播放 YouTube 視頻）
  • LibreOffice Calc（打開一個表格）
  • 繪圖應用程序（打開一個實例）
  • 設置
  • 一個終端窗口
  • 文件管理器

在上述的工作負載中，它消耗了大約 1.5 GB 的內存和 14% 的 CPU 。顯然，大部分的資源都被 Firefox 消耗了。

在我看來，這是一個完美的指標，而且對舊硬件進行了很好的優化分配。上述指標是在物理機系統上測量的。

連接性 ​

連接性是任何操作系統的不可或缺的一部分。LMDE 5 能夠連接到 Wi-Fi（使用一款老舊的博通芯片）和連接到藍牙音箱，而不需任意的額外調整。

在我的測試期間，音量控制與藍牙守護進程配合得很好。

此外，我們也測試了 USB 接口設備的熱插拔，它們可以自動偵測和掛載，而沒有遇到任何問題。

所以，沒有什麼意外，這也是意料之中的。

有什麼錯誤嗎？ ​

我在測試期間沒有遇到任何錯誤。一切都運行良好。

但是當我關閉我的物理測試系統的筆記本蓋板時，我發現一個錯誤。在它進入待機狀態後，不能將其喚醒。我無法看到登錄屏幕，屏幕是黑色的，沒有任何光標。我必須因重啓才能進入系統。

這可能是我測試設備上的特定硬件設備的問題。我相信它在新的硬件系統上不會有任何的問題。

總結 ​

總結一下 LMDE 5 的評測，它顯然是最穩定、最優化的 Linux 發行版。如果你計劃在未來兩年或更長的時間段內使用一款用於日常用途的系統，你可以信賴這個版本。因此，如果你需要一款非基於 Ubuntu 的穩定的、快速的、低維護率的長期日用系統，並運行在你的舊機器或新機器上，這會是一個完美的選擇。請試試。

你可以 在官方網站上 下載 LMDE 5 。

感謝閲讀。
