使用 netstat 查看你的 Linux 服務器網絡連接 ​

netstat 命令為你的 Linux 服務器提供了監測和網絡故障排除的重要觀察手段。

在 之前的文章中，我分享了一些管理你的個人 Linux 服務器的首要步驟。我簡要的提到了監測網絡連接的監聽端口，我想通過 Linux 系統的 netstat 命令來擴展開講講。

服務監測和端口掃描是標準的行業慣例。有很好的軟件，如 Prometheus 協助這個過程自動化，SELinux 協助上下文和保護系統訪問權限。然而，我相信瞭解你的服務器是如何連接到其他網絡和設備的，是建立正常服務器基準的關鍵，能夠幫助你識別有可能表明錯誤和入侵等異常情況。作為一個初學者，我已經掌握了 netstat 命令為我的服務器提供了監測和網絡故障排除的重要觀察手段。

netstat 和類似的一些網絡監測工具被歸入 net-tools 軟件包 裏，用來顯示關於活動連接的信息。因為運行在開放的端口的服務往往容易被利用，定期進行網絡監測能夠幫助你及早探測到可疑的活動。

安裝 netstat ​

netstat 經常預裝在 Linux 發行版上。如果 netstat 沒有在你的服務器上安裝，用你的包管理器安裝它。下面是在基於 Debian 的系統上：

$ sudo apt-get install net-tools

在基於 Fedora 的系統上：

$ dnf install net-tools

使用 netstat ​

就其本身而言，netstat 命令顯示了全部建立成功的連接。你可以使用 netstat 的參數指定進一步預期的輸出。舉個例子，要顯示所有監聽和非監聽的連接，使用 --all（-a 為簡寫）的參數。這將返回許多結果，所以在例子中我用管道符輸出給 head 命令來顯示輸出的前 15 行：

tcp        0      0 *:ipp                   *:*                     LISTEN

要只顯示 TCP 端口，使用 --all 和 --tcp 參數，或者簡寫成 -at ：

$ netstat -at | head -n 5
Active Internet connections (servers and established)
Proto Recv-Q Send-Q Local Address   Foreign Address  State      
tcp        0      0 *:27036         *:*              LISTEN      
tcp        0      0 localhost:27060 *:*              LISTEN      
tcp        0      0 *:16001         *:*              LISTEN

要只顯示 UDP 端口，使用 --all 和 --udp 參數，或者簡寫成 -au ：

$ netstat -au | head -n 5
Active Internet connections (servers and established)
Proto Recv-Q Send-Q Local Address     Foreign Address    State      
udp        0      0 *:27036           *:*                                
udp        0      0 10.0.1.222:44741  224.0.0.56:46164   ESTABLISHED
udp        0      0 *:bootpc

接下來的步驟 ​

一旦你運行了 netstat 命令，你就可以採取措施來保護你的系統，確保只有你主動使用的服務在你的網絡上被監聽。

  1. 識別通常被利用的端口和服務。一般來説，關閉你實際不使用的端口。
  2. 留意不常見的端口號，認識瞭解在你係統上使用的合法端口。
  3. 密切注意 SELinux 錯誤。有時你需要做的只是更新上下文，以匹配你對系統做的合法更改，但是要閲讀錯誤警告，以確保 SELinux 提醒你的不是可疑或者惡意的活動。

如果你發現一個端口正在運行一個可疑的服務，或者你只是簡單的想要關閉你不再使用的端口，你可以遵從以下這些步驟，通過防火牆規則手動拒絕端口訪問：

如果你在使用 firewall-cmd ，運行這些命令：

$ sudo firewall-cmd –remove-port=<port number>/tcp
$ sudo firewall-cmd –runtime-to-permanent

如果你在使用 UFW，運行以下的命令：

$ sudo ufw deny <port number>

下一步，使用 systemctl 來停止這個服務：

$ systemctl stop <service>

理解 netstat ​

netstat 是一個快速收集你的服務器網絡連接信息的有用工具。定期網絡監測是瞭解你的系統的重要組成部分，對幫助你保持你的系統安全有着重要意義。將這一步納入你的日常管理中，你可以使用類似 netstat 或者 ss ，以及 Nmap 等開源端口掃描器或者 Wireshark 等嗅探器 ，它們都允許設定 計劃任務。

隨着服務器存儲了大量的個人數據，確保個人服務器的安全日益重要。通過了解你的服務器怎樣連接到互聯網，你可以降低你的機器的風險，同時你仍可以在數字時代大量的連接中獲得益處。
