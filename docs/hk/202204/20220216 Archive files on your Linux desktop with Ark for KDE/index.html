使用 KDE 的 Ark 在 Linux 桌面上歸檔文件 ​

在 KDE 上創建、檢查和擴展壓縮的檔案。

當我完成一個項目時，我經常喜歡把為這個項目創建的所有文件放到一個檔案中。這不僅可以 節省空間，而且可以讓這些文件遠離我的視線，防止它們在我使用 find 和 grep 搜索我當前想要的文件時作為結果出現。一旦文件被歸檔，它們就會被你的文件系統視為一個單獨的對象，這意味着你不能像瀏覽普通文件夾那樣來瀏覽它們。你可以把它們解壓縮來列出檔案的內容，或者打開一個終端，運行適當的歸檔命令，比如 tar 命令。又或者你可以使用一個像 Ark 這樣的應用程序來列出、預覽、修改和管理你的檔案。

在 Linux 上安裝 Ark ​

KDE Plasma 桌面預裝了 Ark，你也可以從軟件包管理器中獲取。在 Fedora、Mageia 和類似的系統中，你可以運行：

$ sudo dnf install ark

在 Debian、Elementary 和類似的系統中，你可以運行：

$ sudo apt install ark

你也可以從 Flathub 上 獲取並安裝它的 Flatpak 包。

創建一個檔案 ​

熟悉歸檔的最好方法就是自己創建一個檔案，然後探索它。所有的這些都可以通過 Ark 來完成。

首先，從你的應用程序菜單中啓動 Ark，然後進入“檔案Archive”菜單，選擇“新建New”。

（圖源 Seth Kenlon / CC BY-SA 4.0）

給你的檔案設置一個文件名，使用默認的壓縮設置，並將檔案保存到你的主目錄。

Ark 不會自動創建空的檔案，但在你設置好名稱和位置後，只要你向其中添加文件，Ark 就會立即創建一個檔案。

要向即將建立的檔案中添加文件，只需將該文件拖入 Ark 窗口即可。

（圖源 Seth Kenlon / CC BY-SA 4.0）

歸檔有兩個好處：合併和壓縮。通過把文件添加到檔案裏，你將許多文件整合到了同一個地方。因為它們已經存在於檔案中，所以，如果你想要擺脱這些文件的干擾，你完全以把原始的副本刪除掉。

要查看你通過壓縮文件節省了多少磁盤空間，你可以進入“檔案Archive”菜單，選擇“屬性Properties”。它會顯示出文件在歸檔前/後的大小，同時還有很多其他有用的元數據。

（圖源 Seth Kenlon / CC BY-SA 4.0）

Ark 可以做的事情還有很多，但是現在先關閉 Ark，假裝你已經使用完畢。你的檔案會存放在你聲明保存它的位置（在這個例子中，它的名字是 example.tar.gz，位於我的用户主目錄中。）

查看檔案中的文件 ​

Ark 可以打開任何檔案，就像打開一個普通的文件夾一樣。要在 Ark 中打開一個檔案，只需在文件管理器中左鍵點擊它（單擊/雙擊，取決於你的系統設置）。你也可以右鍵點擊它，並選擇“用 Ark 打開Open with Ark”。

一旦檔案在 Ark 中打開，你就可以在文件管理器中進行大部分操作，包括刪除文件、添加新文件、預覽文件內容等等。

從檔案中刪除文件 ​

有時候，你會把一個文件放到一個你不需要的檔案中。此時，當你想從檔案中刪除一個文件時，你可以右鍵單擊該文件並選擇“刪除Delete”。

（圖源 Seth Kenlon / CC BY-SA 4.0）

向檔案中添加文件 ​

向檔案中添加文件是更加容易的。你只需從文件管理器中把該文件拖拽到 Ark 裏。另外，你也可以選擇 Ark 右鍵菜單中“添加文件Add Files”。

從檔案中提取單個文件 ​

當處理一個檔案時，許多人會選擇解開整個檔案，然後尋找他們真正需要的一兩個文件。對於小型檔案，這勉強説得過去，但對於大型檔案來説，這會佔用你大量的時間和磁盤空間，哪怕只是暫時的。

有了 Ark，你可以只提取你需要的文件，只要把它們從 Ark 窗口拖到你要保存的地方就行。另外，你也可以選擇右鍵菜單中的“提取Extract”。

預覽檔案中的文件 ​

事實上，你並不總是需要提取文件。如果你只是需要快速查看一個文件，Ark 或許可以向你展示一個文件的預覽，而不需要將其解壓到你的硬盤上。

要預覽一個文件，在 Ark 中雙擊它即可。

（圖源 Seth Kenlon / CC BY-SA 4.0）

開始歸檔吧 ​

在 Linux 桌面上管理檔案是非常簡單和直觀的。Ark 是一個很好的歸檔工具，許多其他的 Linux 桌面也有類似的工具。因此，即使你不使用 Ark，其他類似的工具也能幫助到你。對我來説，歸檔很大程度上讓我保持了文件的有條不紊、節約了磁盤空間。Ark 的存在使得我們可以很方便地和檔案打交道。
