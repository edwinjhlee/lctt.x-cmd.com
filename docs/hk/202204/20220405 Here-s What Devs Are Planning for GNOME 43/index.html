開發者對於 GNOME 43 的計劃 ​

GNOME 43 及以後的開發計劃令人振奮，以下是你可以期待的：……

GNOME 42 剛剛發佈不久。

儘管它是 GNOME 41 之後的一次令人興奮的升級，但你可能無法在每個主流 Linux 發行版上找到它（除了 OpenSUSE、Arch 和 Clear Linux）。

Fedora 36 和 Ubuntu 22.04 應該是採用 GNOME 42 的最受歡迎的選擇，它們將在接下來的幾周發佈。

接下來是什麼？沒錯，就是 GNOME 43。

GNOME 43：計劃中的新功能 ​

在一篇 博文 中，GNOME 開發者 Chris Davis 分享了一些 GNOME 43 及之後版本計劃中的變更。

我在這裏介紹其中的一些主要亮點。

請注意，這裏提到的計劃變更或改進可能會在 GNOME 43 中首次亮相，也可能不會。

全局強調色 ​

隨着 Libadwaita 的引入，現在有可能增加一個全局強調色的功能。

你不必依賴發行版來提供使用強調色的能力（比如 Ubuntu 22.04 中添加了這個功能）。

有了強調色，GNOME 桌面體驗可以更加個性化。此外，它將不僅僅侷限於預設，同時也支持自定義強調色，應用開發者可以考慮支持它。

重新着色 API ​

這對終端用户來説可能不是特別有趣，但它將幫助應用開發者提供預設的顏色方案，讓他們的應用更好地協調各種強調色。

正如這篇博文所説：

開發者可以使用重新着色 API，以編程方式改變他們應用程序中的顏色，並讓依賴的顏色自動更新。他們將能夠輕鬆地創建預設，從而實現許多功能。例如，根據文本視圖的顏色方案來改變窗口的顯示顏色。

有了 libadwaita 1.0 中的 CSS，這在技術上已經可以實現。然而，API 可以幫助開發者更容易地使用這個功能。

自適應的 Nautilus 文件管理器 ​

Nautius 文件管理器將得到一些升級，比如針對移動尺寸的自適應設計，其中包含一個新的文件選擇器模式。

它將幫助 GNOME 平台跟上新功能，而不需要依賴 GTK 的文件選擇器，因為它不支持 GNOME 的所有功能，比如收藏文件。

新的圖片瀏覽器（Loupe）和屏幕截圖註釋 ​

一個新的圖片瀏覽器正在開發中，名字叫 Loupe。它由 Rust 編寫，使用了 GTK4 和 libadwaita。

這個圖片瀏覽器的目標是自適應、對觸摸板和觸摸屏友好，並且易於使用。你可以期待它與 Nautilus 集成，以遵循文件管理器中任何文件夾的排序設置。

除了系統集成之外，新的圖片瀏覽器還將會有一些功能升級，主要是在基本的圖片編輯方面，比如剪裁、旋轉和註釋。

有了註釋的能力，它可以與截圖流程很好地配合，允許你在沒有任何第三方程序的情況下進行屏幕截圖並進行註釋。

磁盤使用情況分析器的新設計（用 Rust 重寫） ​

磁盤使用情況分析器目前是用 Vala 編寫的。

雖然它能完成預期的工作，但是按照現在的實現方式，它不具備很大的潛力。

因此，開發計劃中包括了使用 Rust 來重寫它，這應該會在可預見的未來改善它，提供最好的性能。

不僅僅侷限於其核心，它還將得到一個設計上的大調整（類似於上面的演示圖），以爭取讓用户體驗更加現代化。

其他改進措施 ​

隨着開發的進行，我們應該會知道更多關於 GNOME 外觀和其他方面計劃中的變更。

當我們瞭解到更多關於 GNOME 43 的功能時，我將會更新這篇文章。

如果你對技術細節感到好奇，你可以閲讀 Chris 的博文。你也可以贊助他為 GNOME 做的工作，以及其他任何相關的東西。
