在樹莓派 3 上安裝 Fedora ​

在樹莓派上運行 Fedora。

樹莓派基金會這幾年來生產了很多型號。本文的安裝過程已經在第三代樹莓派上進行了測試：3B v1.2 和 B+（較舊的 樹莓派 2 和新的 樹莓派 4 都還沒有測試）。這些是已經發布了幾年的信用卡大小的樹莓派。

獲取硬件 ​

你需要一些硬件組件，包括樹莓派。你不需要任何 HaT（安裝在頂部的硬件） 板或 USB 天線。如果你使用過樹莓派，那麼可能會有這些。

  • 當前網絡。也許是你的家庭實驗室。
  • 網線。連接當前網絡到樹莓派
  • 樹莓派 3，型號 B 或 B+。
  • 電源。
  • 8 GB 或更大容量的 micro-SD 卡。
  • 鍵盤和顯示器。

鍵盤和顯示器共同組成本地控制台。即使沒有控制台，也能進行操作（儘管很複雜），例如設置自動安裝然後通過網絡連接。在 Fedora 首次啓動時，本地控制台可輕鬆回應配置問題。同樣，在 AP 配置期間出錯可能會破壞網絡配置，從而阻止遠程用户連入。

下載 Fedora Minimal ​

  • 查找 Fedora 的其他可選架構鏡像。
  • 下載 ARM® aarch64 架構鏡像。

Fedora Minimal 鏡像是 Fedora 的其他可選下載之一，它有所有必需的核心軟件包和網絡軟件包（嗯，是幾乎，注意下面的 dnsmasq）。該鏡像包含一個現成的文件系統，它已經安裝了 400 多個軟件包。此最小鏡像不包括流行的軟件包，像開發環境、互聯網服務或桌面。這些類型的軟件不是這裏所必需的，如果安裝它們，可能會佔用過多的內存。

Fedora Minimal 原始鏡像可安裝在小型 SD 卡上，並在少於 1GB 的內存中運行（這些舊的樹莓派有 1GB 的內存）。

下載文件的名稱類似於 Fedora-Minimal-32-1.6.aarch64.raw.xz。該文件已壓縮，大小約為 700MB。文件解壓縮後為 5GB。這是一個 ext4 文件系統，它大部分是空的：已使用約 1GB，空餘 4GB。這些空的空間是壓縮文件比未壓縮的原始文件小得多的原因。

複製到 micro-SD 卡 ​

  • 將鏡像複製到 micro-SD 卡。

這可能比聽起來更復雜，而且會帶來痛苦的體驗。找到一個良好的 micro-SD 卡需要花費精力。然後是將卡插到計算機的挑戰。也許你的筆記本電腦有全尺寸的 SD 卡插槽，你還需要卡適配器，或者你需要一個 USB 適配器。然後，在進行復制時，操作系統可能會幫助你，也可能會妨礙你。你可能很幸運有 Fedora Media Writer，或使用這些 Linux 命令：

unxz ./Fedora-Minimal-32-1.6.aarch64.raw.xz
dd if=./Fedora-Minimal-32-1.6.aarch64.raw of=/dev/mmcblk0 bs=8M status=progress oflag=direct

安裝 Fedora ​

  • 連接樹莓派、電源線、網線和 micro-SD 卡。
  • 打開電源。
  • 當圖形芯片通電時，看見彩色框。
  • 等待 anaconda 安裝程序啓動。
  • 回答 anaconda 的設置問題。

操作系統的初始配置需要幾分鐘的時間。等待啓動需要花費幾分鐘，還需要花費一些時間填寫 anaconda 的文本安裝程序的問題。在下面的例子中，用户名為 nick，並且還是管理員（wheel 組的成員）。

恭喜你！你的樹莓派已啓動並可運行。

更新軟件 ​

  • 用 dnf update 更新軟件包。
  • 通過 systemctl reboot 重啓。

多年來，很多人為使樹莓派正常工作付出了很多工作。使用最新的軟件，以確保你從他們的辛勤工作中受益。如果你跳過此步驟，你可能會發現有些東西無法正常工作。

此次更新下載並安裝了約一百個軟件包。由於存儲設備是 micro-SD 卡，因此寫入新軟件的過程很慢。這就是 90 年代使用存儲器的感覺。

可以擺弄的東西 ​

如果你想擺弄的話，此時可以設置其他一些內容。這都是可選的。試試這些。

  • sudo hostnamectl set-hostname raspi 替換 localhost 主機名。
  • 用 ip addr 查找 IP 地址。
  • 嘗試 SSH 登錄，甚至使用 ssh-copy-id 設置基於密鑰的登錄。
  • 使用 systemctl poweroff 關機。
