OnionShare：一個安全共享文件的開源工具 ​

OnionShare 是一個自由開源工具，它利用 Tor 網絡安全和匿名地共享文件。

已經有很多在線服務可以安全地共享文件，但它可能不是完全匿名的。

此外，你必須依靠一個集中式服務來共享文件，如果服務決定像 Firefox Send 那樣關閉，那你不能真正依靠它來一直安全地共享文件。

考慮到這些，OnionShare 是一個讓人驚歎的開源工具，它讓你使用 Tor Onion 服務來共享文件。它應該是所有云端文件共享服務的一個很好的替代品。

讓我們來看看它提供了什麼以及它是如何工作的。

OnionShare: 通過 Tor 匿名分享文件 ​

OnionShare 是一款有趣的開源工具，可用於 Linux、Windows 和 macOS。

它可以讓你安全地將文件直接從你的電腦分享給接收者，而不會在這個過程中暴露你的身份。你不必註冊任何帳户，它也不依賴於任何集中式存儲服務。

它基本上是在 Tor 網絡上的點對點服務。接收者只需要有一個 Tor 瀏覽器就可以下載/上傳文件到你的電腦上。如果你好奇的話，我也建議你去看看我們的 Tor 指南來探索更多關於它的內容。

讓我們來看看它的功能。

OnionShare 的功能 ​

對於一個只想要安全和匿名的普通用户來説，它不需要調整。不過，如果你有需要，它也有一些高級選項。

  • 跨平台支持（Windows、macOS和 Linux）。
  • 發送文件
  • 接收文件
  • 命令列選項
  • 發佈洋葱站點
  • 能夠使用橋接（如果你的 Tor 連接不起作用）
  • 能夠使用持久 URL 進行共享（高級用户）。
  • 隱身模式（更安全）

你可以通過 GitHub 上的官方用户指南來了解更多關於它們的信息。

在 Linux 上安裝 OnionShare ​

你應該可以在你的軟件中心找到 OnionShare 並安裝它。如果沒有，你可以在 Ubuntu 發行版上使用下面的命令添加 PPA：

sudo add-apt-repository ppa:micahflee/ppa
sudo apt update
sudo apt install -y onionshare

如果你想把它安裝在其他 Linux 發行版上，你可以訪問官方網站獲取 Fedora 上的安裝説明以及構建説明。

  • 下載 OnionShare

OnionShare 如何工作？ ​

完成後，它加載並連接到 Tor 網絡。

共享文件 ​

你只需要在電腦上添加你要分享的文件，然後點擊 “Start sharing”。

完成後，右下角的狀態應該是 “Sharing”，然後會生成一個 OnionShare 地址（自動複製到剪貼板），如下圖所示。

現在接收方需要的是 OnionShare 的地址，它看上去是這樣的。

http://onionshare:xyz@jumbo2127k6nekzqpff2p2zcxcsrygbnxbitsgnjcfa6v47wvyd.onion

接着 Tor 瀏覽器開始下載文件。

值得注意的是，下載完成後（文件傳輸完成），文件共享就會停止。到時候也會通知你。

所以，如果你要再次分享或與他人分享，你必須重新分享，並將新的 OnionShare 地址發送給接收者。

允許接收文件 ​

如果你想生成一個 URL，讓別人直接上傳文件到你的電腦上（要注意你與誰分享），你可以在啓動 OnionShare 後點擊 Receive Files 標籤即可。

你只需要點擊 “Start Receive Mode” 按鈕就可以開始了。接下來，你會得到一個 OnionShare 地址（就像共享文件時一樣）。

發佈洋葱站點 ​

如果你想的話，你可以直接添加文件來託管一個靜態的洋葱網站。當然，正因為是點對點的連接，所以在它從你的電腦上傳輸每個文件時，加載速度會非常慢。

我試着用免費模板測試了一下，效果很好（但很慢）。所以，這可能取決於你的網絡連接。

總結 ​

除了上面提到的功能，如果需要的話，你還可以使用命令列進行一些高級的調整。

OnionShare 的確是一款令人印象深刻的開源工具，它可以讓你輕鬆地匿名分享文件，而不需要任何特殊的調整。
