如何在Ubuntu 13.10中升級GNOME 到 3.10? ​

Ubuntu 13.10 中配備了GNOME 3.8桌面。 儘管它相比Unity是一個可靠穩定以及有特色的替代品，但這個版本還是過時了。

GNOME桌面的最新版本在2013年9月發佈，隨之而來的是一系列改進的功能、應用程序和可用性的調整。從對高分辨率屏幕的支持到客户端應用窗口上的美化，GNOME 3.10無疑是一個引人注目的升級版本。

好消息是：假設你正在運行Ubuntu 13.10，擁有不錯的網絡操作和命令列水平，那麼你無需繼續使用一個過時版本的GNOME。

在Ubuntu 13.10 上如何升級到GNOME 3.10 ​

為了那些愛略過前言直奔主題的讀者，我還要重申兩點:

要使用本方法安裝GNOME 3.10，需運行 Ubuntu 13.10版本。

GNOME 3.10還未在 Ubuntu 13.10上測試，所以升級風險自負。

首先，讓我們添加GNOME 3 的PPA到Ubuntu的軟件資源中。這個操作可以使用圖形界面完成，但使用命令更容易一些。

打開一個新的終端窗口，鍵入下列命令，在需要時輸入你的用户密碼：

sudo add-apt-repository ppa:gnome3-team/gnome3-next && sudo apt-get update

添加完PPA並更新包列表後，我們就可以繼續，開始安裝GNOME 3.10了。運行下列命令，當彈出提示時再次輸入你的用户密碼：

sudo apt-get update && sudo apt-get install gnome-shell ubuntu-gnome-desktop

獲取並安裝所有必要的包和組件會花一點時間，所以請耐心一點。

在安裝過程中，在終端將會彈出一個提示，要求你選擇一種顯示管理器，默認使用的是“登錄窗口”。

這個決定完全取決於你；UBuntu的Unity Greeter和GNOME的顯示管理器都能讓你很輕鬆地在桌面會話之間切換（如果你想保持在Unity界面或者另一個桌面將很方便），但僅僅只有GDM提供給GNOME特定的功能，譬如鎖屏通知。

當你確定選擇後，使用上下鍵選擇，然後敲擊‘確認/返回’鍵以確認。安裝便會繼續進行。

增加額外的功能 ​

GNOME 3.10還有一些不錯的新特性和應用-包括GNOME天氣，音樂盒及地圖 以及其它各種各樣的改變。因為並不是所有的特性都足夠穩定以致於可以被包含在我們之前添加的GNOME 3 PPA中，所以如果你想使用它們，就需要利用到兩個額外的GNOME PPA。

現在，你需要意識到很重要的是，在這些倉庫裏的一些包據説有穩定性問題。這些問題大多是小問題，譬如應用程序崩潰和損壞。但還是有潛在的可能，導致像使GNOME完全崩潰這樣的重大問題。

除開這個警告不説，在終端裏打開一個新的選項卡，輸入下列命令：

sudo add-apt-repository ppa:gnome3-team/gnome3-staging
sudo add-apt-repository ppa:gnome3-team/gnome3
sudo apt-get update && sudo apt-get dist-upgrade

為了添加一些之前提到的很酷的應用，運行這個命令：

sudo apt-get install gnome-weather gnome-music gnome-maps cheese gnome-documents

這樣之後，就搞定了！

你可能會想先註銷然後重新登錄（記得選擇“GNOME”會話）以確保改動都已經正確生效了。

細小的差別 ​

如果你在不卸載Unity的情況下安裝GNOME 3.10，那麼有一些注意事項。

首先，你會發現在系統設置裏“Online Accounts”有兩個入口。其中，有鑰匙圖標的是Unity版的，另一個有插孔符號的是GNOME版的。

一些應用程序可能會要求你往Unity中添加賬户（Shotwell, Gwibber, Empathy），有一些可能是要求往GNOME中添加(Evolution, Documents, Contacts)。

“通知”和“搜索”入口是GNOME專有的，它們讓你挑選哪些應用程序和資源能夠顯示通知或出現在活動區。

卸載GNOME 3.10 ​

假如你已經嘗試了GNOME 3.10，但不喜歡它。這時該怎麼辦？

使用一個叫做“PPA Purge”的命令列工具，移除GNOME 3.10 是一個相當簡單的過程。這個工具可以在Ubuntu軟件中心裏找到，是目前為止自動移除或降級從PPA安裝的包的最容易的方法。

  • 從Ubuntu軟件中心安裝PPA Purge

為了使用這個工具，我們需要返回終端然後鍵入下面命令，要留意任何出現在降級過程中的提示。

sudo ppa-purge ppa:gnome3-team/gnome3-next

如果你也添加了其它可選的PPA，你也需要清除它們：

sudo ppa-purge ppa:gnome3-team/gnome3-staging
sudo ppa-purge ppa:gnome3-team/gnome3

完成後，你就剩下了原來的 GNOME 3.8 桌面。如果你不再想保留GNOME Shell了，你可以執行下列命令去卸載它：

sudo apt-get remove gnome-shell ubuntu-gnome-desktop

最後，手動移除任何在降級之後可能殘留的應用程序（譬如，Epiphany and GNOME Documents），然後重啓。
