為什麼在 2021 年我仍然推薦你使用 Linux ​

在某些領域，Linux 確實要比 Windows 和 macOS 更加優秀。人們正在意識到這一點，而且 Linux 也在桌面操作系統市場上變得愈發流行。

當然，目前大多數桌面操作系統用户仍然對 Windows 或者 macOS 推崇備至，但是也有着越來越多的用户開始嘗試新的 Linux 發行版，看看他們是否可以從原來的系統切換到 Linux 系統。

他們可能已經聽過 用 Linux 作為桌面操作系統 的一些優秀案例，又或者是僅僅想要去嘗試一些與原先不同的事物，誰知道呢？

在這裏，我將為你解釋為什麼在 2021 年我仍然推薦你使用 Linux。

Linux 真棒，但是究竟是什麼讓其在 2021 年值得推薦呢？ ​

如果已經知道了 使用 Linux 的優點，你可能就知道接下來我會説些什麼。

1、你不需要購買許可證 ​

你必須付費才能獲得 Windows 10 許可證。

雖然有更便宜的選擇，如獲得 OEM 密鑰。但是，如果你不願意通過一些地下網站，而是從官方網站獲得許可證，那麼僅授權使用 1 台 PC 的家庭版就至少需要花費 140 美元。

當然，macOS 是一個完全不同的模式（你需要購買先進的硬件才能使用 macOS）——所以我們才會一直使用微軟的 Windows。

關鍵是，在失業的浪潮中，配置一台新電腦是一個挑戰。此外，你還需要花錢購買操作系統的許可證，但是你卻可以在多台計算機上免費使用 Linux。

是的，你不需要為 Linux 獲取許可證密鑰。你可以輕鬆下載 Linux 發行版，並根據需要將其安裝在儘可能多的設備上。

不要擔心，如果你不瞭解 Linux 發行版，你可以看看我們的 最好的 Linux 發行版 列表。

2、重新喚醒你的 PC 並節省資金 ​

全球芯片短缺 已經嚴重影響了電腦組件的價格，特別是顯卡。並不是簡單的價格上升，而是你不得不支付 2 到 5 倍的零售價來購得顯卡。

當然，如果你沒有電腦，現在配置一個新的電腦可能是難以置信的挑戰，但如果你有一箇舊電腦的話，選擇在上面運行 Windows 10 將會是十分卡頓的。

如果你不想要 Windows 系統，那 macOS 呢？入門級 Mac 系統將會花費至少 1100 美金，甚至更多，這取決於你住在哪裏。對許多人來説，這會是一筆昂貴的開銷。

你肯定需要升級你的系統 —— 但是如果我説 Linux 可以讓你的舊電腦重新派上用場，能為你省錢呢？

你將能夠在你認為無法運行最新版本的微軟 Windows 的電腦上運行 Linux。是的，就是這樣的。

Linux 是一個資源高效型的操作系統，可在各種較舊的系統配置上運行。

所有你需要做的只是參考我們的列表 輕量級 Linux 發行版，並選擇一個你喜歡的。

3、通過再次利用系統來減少電子浪費 ​

考慮到電子廢物正在全球不斷產生，尤其是由加密礦工產生的，我們可以儘量減少浪費。除非你真正需要新的硬件，否則最好將現有硬件設備重新用於新任務。

而且，多虧了 Linux，你可以將舊電腦或單片機轉變成媒體服務器或個人 Nextcloud 服務器。

你可以在現有硬件上使用 Linux 做更多工作。

因此，這將顯著降低對新硬件的需求，並讓你高效地重複使用現有的設備。

4、遠離病毒和惡意軟件 ​

在遠程工作無處不在的時代，病毒和惡意軟件顯著增加。因此，即使你想平靜地工作，你最終也可能受到惡意軟件的影響。

Windows 和 macOS 比以往任何時候都更容易受到惡意軟件的影響。但是，對於 Linux？這是不太可能的。

Linux 發行版會定期修補，以確保最佳安全性。

此外，正因為用户羣體小，攻擊者就不會花太多時間製作欺騙 Linux 用户的病毒或軟件。因此，在使用 Linux 時遇到某種形式的惡意軟件的機會較小。

5、沒有強制更新 ​

在一個人們壓力倍增的時代，強制更新然後發現計算機無法啓動可能是一大煩惱。

至少，Windows 用户的情況就是這樣。

但是，使用 Linux，你可以繼續使用你的系統，而無需在後台強制下載任何更新。

你的操作系統只有你能決定。

當你想要更新你的 Linux 發行版本時，你可以選擇更新，也可以不更新，它可以一直保持不更新的狀態並且不會打擾你，除非你有很長一段時間沒有更新。

總結 ​

這些只是我能想到的幾個原因之一，Linux 作為操作系統的選擇在 2021 年比以往任何時候都更值得被推薦。

當然，這也取決於你的要求，這些好處可能不會體現在在你的用例中。但是，如果你確實不瞭解 Linux，至少，現在你可以評估你的需求，重新作出選擇。

除了上述幾點之外，你還能想到什麼？請在下面的評論中告訴我。
