KTorrent：KDE 上的一個非常有用的 BitTorrent 應用 ​

Linux 中有各種各樣的 BitTorrent 應用。但是，找到一個好的、提供許多功能的應用將可以為你節省一些時間。

KDE 的 KTorrent 就是這樣一個為 Linux 打造的 BitTorrent 應用。

雖然 Linux 有好幾個 torrent 客户端，但我最近發現 KTorrent 對我而言很合適。

KTorrent: 適用於 Linux 的開源 BitTorrent 客户端 ​

KTorrent 是一個成熟的 torrent 客户端，主要為 KDE 桌面定製。無論你使用什麼桌面環境，它都能很好地工作。

當然，使用 KDE 桌面，你可以得到一個無縫的用户體驗。

讓我們來看看它的所有功能。

KTorrent 的功能 ​

對於普通的 torrent 用户來説，擁有一套全面的功能使事情變得簡單。而 KTorrent 也不例外。在這裏，我將列出 KTorrent 的主要亮點：

  • 在一個隊列中添加 torrent 下載
  • 能夠控制每次下載（或整體）的速度限制
  • 視頻和音頻文件預覽選項
  • 支持導入下載的文件（部分/全部）
  • 在下載多個文件時，能夠對 torrent 下載進行優先排序
  • 為多文件 torrent 選擇要下載的特定文件
  • IP 過濾器，可選擇踢走/禁止對端。
  • 支持 UDP 跟蹤器
  • 支持 µTorrent 對端
  • 支持協議加密
  • 能夠創建無跟蹤器的 torrent
  • 腳本支持
  • 系統托盤集成
  • 通過代理連接
  • 增加了插件支持
  • 支持 IPv6

KTorrent 看起來可以作為一個日常使用的 torrent 客户端，在一個地方管理所有的 torrent 下載。

除了上面提到的功能外，它還對客户端的行為提供了很大的控制。例如，調整下載/暫停/跟蹤器的指示顏色。

如果你想禁用完成 torrent 下載時的聲音或得到活動通知，你還可以設置通知。

雖然像協議加密支持這樣的功能可能無法取代一些 最好的私有專用網絡 服務，但它對桌面客户端來説是一個重要的補充。

在 Linux 中安裝 KTorrent ​

KTorrent 應該可以通過包管理器（如 Synaptic）或默認的倉庫獲得。你也可以在你的軟件中心找到它並輕鬆安裝。

除此之外，它還在 Flathub 上提供了一個適用於任何 Linux 發行版的 Flatpak 官方包。如果你需要幫助，我們有一個 Flatpak 指南 供參考。

如果你喜歡的話，你也可以嘗試可用的 snap包。

要探索更多關於它和源碼的信息，請前往它的 官方 KDE 應用頁面。

  • KTorrent

結束語 ​

KTorrent 是 Linux 中一個出色的 torrent 客户端。我在我的 Linux Mint 系統的 Cinnamon 桌面上試用了它，它運行得很好。

我喜歡它的簡單和可配置性。儘管我不是每天都在使用 torrent 客户端，但在我短暫的測試中，我沒有發現 KTorrent 有什麼奇怪的地方。

你認為 KTorrent 作為 Linux 的 torrent 客户端怎麼樣？你喜歡用什麼呢？
