用慣 Linux 的人第一次用 Windows 或 macOS 會怎樣? ​

Windows 用户在轉換到 Linux 的過程中會遇到很多問題。如果反過來，一個一直用 Linux 的用户第一次用 Windows 或 macOS 會遇到什麼問題呢?

還記得 YouTube 頻道 Linus Tech Tips 中 Linus Sebastian 嘗試在 Linux 上玩遊戲 的場面嗎? 儘管終端顯示了明顯的警告, 他最後還是把他的桌面環境刪掉了。

考慮到 Sebastian 日常用 Windows 玩遊戲, 換到 Linux 肯定需要一定的時間。

所以，這是 Linux 的問題嗎? 還是 Sebastian 搞錯了?

難道説，任何對操作系統不熟悉的用户在第一次嘗試使用該系統的時候都會遇到問題?

接下來，你可以從不同的角度去了解 Linux 用户第一次使用 Windows 或者 macOS 的感受。

Linux 用户第一次用 Windows 或 macOS 會非常容易？還是會和 Sebastian 用 Linux 時一樣感覺糟糕？

這肯定是非常有趣的話題……

一位 DevOps 高級工程師 Scott Williams 在一系列推文中假想了 Linux 用户第一次用 Windows 或 macOS 的場面。

在 Windows 11 上怎麼啓用 TPM 2.0？ ​

如何安裝 Windows 的最新版本 Windows 11？

Scott Williams：
今晚，看我在能不能在這台用了 4 年的筆記本電腦上啓用 TPM2.0 並運行 Windows 11。這台電腦支持 Intel PTT，所以應該會很順利吧？

怎樣啓用 TPM 2.0? 如何在 BIOS 菜單中找到它? 啓用 TPM 2.0 安全嗎? 我是否需要刷一個更新的 BIOS? 更新 BIOS 的過程中是否會弄壞我的主版？

這些就是些每個 Linux 用户（甚至是 macOS/Windows 用户）將系統升級到 Windows 11 時都會遇到的一些問題。

Linux 用户從來沒有必要做如此奇怪的事情來讓系統正常工作。即使是在 2022 年。但是 Windows 11 需要你在升級前瞭解 BIOS 設置和 TPM 芯片的情況。

雖然 Scott 提到的是舊筆記本電腦，但值得注意的是，即使是最新的主板（比如 Z590），你可能也需要調整 BIOS 設置或者刷一個版本更高的 BIOS 版本才能支持 Windows 11。

由於更新 BIOS 有一定的風險，這種事情即使是對於懂技術的用户也是很不方便。

我需要用殺毒軟件嗎？用哪個？ ​

雖説蘋果的 XProtect 和 Windows Defender 能提供基本保護，但對於想要更好保護的用户來説，在殺毒軟件方面有幾個選擇：

Scott Williams：
所以我究竟需不需要裝殺毒軟件？裝哪個？

網上有那麼多選擇和軟文，用户很難確定那個殺毒軟件最好，已經為之付費是否值得。

而 Linux 用户就會這麼想: 我竟然還要安裝這個? 不會很浪費性能嗎? 我需要這麼多安全防護功能嗎? Windows 不是一個安全的操作系統嗎？

macOS 和 iCloud:一個愛情故事？ ​

Scott Williams：
iCloud 是什麼？我怎麼把它刪掉？

Linux 用户們並不喜歡集成的雲服務。他們寧願掛載一個網盤（或網絡存儲器）。

即使他們選擇了網盤，也應該按照用户的意圖來工作。但是，在 macOS 上，你會經常被提示要使用 iCloud，同時 Siri 還會跳出來搗亂。

Linux 用户清理註冊表 ​

原先使用 Linux 的新手 Windows 用户為了能優化系統性能去清理註冊表，但在面對那麼多清理註冊表和優化系統以提高性能的工具和選項時，可能會以一個沒有反應的 Windows 而告終。

Scott Williams：
Reddit上有些人説需要“清理註冊表”，我按照幾個教程刪除了一些東西，然後現在我的 Windows 變得很奇怪。

即使在 2022 年，對於應該在什麼時候手動或者用工具清理註冊表還是沒有明確的規定。

雖説資深 Linux 用户喜歡在嘗試新東西前關注細節。但如果 GUI 中沒有恰當的警告或提示，還怎麼知道所有的注意事項呢。

經常需要重啓 ​

雖説不像 Linux 的重啓那樣，Windows 的重啓可以修復問題。不過，我到底要在更新 Windows 或者安裝軟件後重啓多少次啊？

Scott Williams：
第一次嘗試 Windows 或 macOS 的 Linux 用户是這樣的：
“究竟需要安裝多少個版本的 .NET? 已經重啓了多少次了？”
“為什麼我的 Adobe 版本不支持這個版本的 macOS? 難怪那麼多人在用 macOS 時會遇到麻煩。蘋果公司需要修復這個問題了。”

每次我重啓的時候後台運行的程序都被幹掉了。

為什麼 Windows 就不能在檢測新安裝的程序或者更新的時候簡單地刷新一下，而不是重啓呢。Windows 為什麼反着來呢。

這些東西還需要花錢? 我有 Windows 許可證還不夠？ ​

Linux 主要是自由和開源軟件構成的，因此預裝的工具也是免費的。

所以, 一個用慣那些工具的用户就不得不突然需要花錢買一個 Windows 許可證，而且還要支付軟件費用。

微軟是不是太貪婪了呢？

默認就缺少必須的軟件包 ​

在安裝完 Windows 後我連壓縮包都解壓不了？Windows 真的是現代操作系統嗎?

macOS 配置多顯示器 ​

Scott Williams：
怎樣讓我的顯示器在 macOS 上工作呢？

在 Linux 上配置多顯示器非常輕鬆。但在 macOS 上完全不是那回事。

總結 ​

歸根到底，這要看用户的標準和你熟悉的內容。Windows 和 macOS 經常被看作標準的桌面系統。

然而相比之下，大多數人除了知道 Linux 很難用外，對有關 Linux 的東西瞭解甚少。

不過，你只要掌握使用 Linux 的要領，就像你掌握 Windows、macOS 那樣，用 Linux 桌面環境就很輕鬆了。

只不過在用 Linux 的過程會遇到各種各樣的問題，但你只要有耐心就能享受整個過程了。

Linux 本身沒有什麼問題，是其他系統用户未能熟悉 Linux 的問題。我們並不希望 Linux 變成 Windows，也不希望 Windows 表現得像 Linux，任何操作系統都應該“做它自己”。

但話又説回來，不應該因為一個長期使用 Windows 的用户在最初使用時沒有良好的體驗就把 Linux 排除在外，因為同樣的情況也可能發生在一個長期使用 Linux 的用户嘗試 Windows/MacOS 時。
