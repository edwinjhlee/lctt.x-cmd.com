哇！Torvalds 為自己的 Apple M2 Macbook 專門修改了 Fedora Linux ​

Linus Torvalds 讓 Fedora Linux Workstation 36 成功運行在 Apple Macbook Air M2 上。666！

Linus Torvalds 喜歡寫代碼和修復代碼。當然，這是他的技術專長。

如果你知道的話，他就是那個因為買不起 UNIX，轉頭就創造了 Linux 的傢伙。

出於類似的原因，他還在 BitKeeper 不再免費使用後構建了 Git。

即使在今天，他仍繼續着他的動手精神和“沒有我解決不了的問題”的態度。

他設法在他的 Apple Macbook Air M2 上運行了 Fedora Linux 36 Workstation 版本。

注意：從 Asahi Linux 的 Hector Martin 那裏得知，Linus Torvalds 似乎在這裏使用了 Leif 的工具包。所以，你可能想多了，他並沒有從頭開始做所有事情來讓它發揮作用。

多虧了 ZDNet 對 Torvalds 的 採訪，我們才發現了這一激動人心的考驗。

Apple M2 芯片上的 Fedora Linux ​

Apple Macbook Air 是一款出色的筆記本電腦。但是，它不能完全按照消費者想要的方式運行 Linux。

然而，Linus Torvalds 似乎是使 Linux 運行在蘋果電腦上的天才。

儘管蘋果基於 ARM 的 M2 芯片沒有 Fedora 移植，但他還是做到了。

請注意，這並不意味着你可以立即在 Macbook Air M2 上運行 Fedora Linux。它只適合像 Torvalds 這樣的 Linux 高手才能使其工作。

他説，即使沒有圖形加速和在 GNOME 桌面環境中缺少某些圖形效果（例如屏幕調光），這種體驗也很出色。

我喜歡這種方式，它使顯示更加迅捷。我可能也會在我的其他機器上關掉這些。

事實上，總的來説，這是一項令人興奮的成就！

Apple 芯片上 Linux 的現狀 ​

不僅是 Linus Torvalds，而且每個人都對 Apple M1/M2 芯片的性能印象深刻。

事實上，他利用 Macbook Air M2 發佈了 Linux 內核 5.19。

Linus Torvalds 使用 Apple MacBook 硬件發佈 Linux Kernel 5.19

儘管我們很想嘗試一下，但 Apple 的 M2 還沒有為 Linux 做好準備。

幸運的是，像 Asahi Linux 這樣的項目一直在不斷改進對 Apple 芯片的支持。他們還設法使 Linux 在最新的 Apple M2 芯片上運行。

而且，在 Linux 創造者的努力下，我們應該很快就能在 Macbook 上看到完整的 Linux 體驗。

到目前為止，你可以使其與 Asahi Linux 一起使用，但對於大多數用户來説，它仍然無法取代它作為日常辦公系統。
