11 個有趣的 Firefox 瀏覽器擴展，改善你的瀏覽體驗 ​

1

我想我們都同意，Firefox 是 Linux 的最佳瀏覽器 之一。

而且錦上添花的是，你可以用一些擴展來提高你的瀏覽體驗! 也許甚至可以將 Facebook 隔離在容器中？😉

在我推薦一些優秀的 Firefox 瀏覽器擴展之前，讓我給你一些提示。

安裝 Firefox 擴展前須知 ​

我們都知道的一件事是 盲目地安裝瀏覽器擴展可能是極其有害的。那麼如何確定瀏覽器擴展是否可以安全使用？

由於本文是關於 Firefox 擴展的，我們將重點放在 Firefox 的市場（獲取擴展的官方渠道）。

雖然沒有什麼是 100% 安全的，但有幾件事可以檢查：

  • 擴展的徽章：尋找“推薦”或“By Firefox”徽章；忽略包含警告徽章/圖標的擴展。
  • 菜單和評論：雖然僅此一項並不能提供太多保證，但這是你可以在其他方面考慮的一件事。此外，關注評論的數量可以幫助你瞭解它在用户中是否足夠受歡迎。
  • 擴展的權限：某些擴展需要諸如“訪問瀏覽器標籤頁”、“導航時訪問瀏覽器動作”等權限。記下這一點並確定你對哪些權限的舒適程度。
  • 最後更新日期：有時，即使是優秀的、知名的擴展也不會更新。這沒關係，但對於像密碼管理器、廣告攔截器這樣的擴展來説，這很重要。應始終謹慎使用超過 2 個月沒更新的擴展。
  • 擴展發佈者：始終確保擴展的發佈者是你信任的人，或者已經發布了你信任的擴展。

話雖如此，讓我們來看看一些可以改善你的網絡瀏覽體驗的擴展。

9 個開源擴展可改善你的 Mozilla Firefox 體驗

1、Facebook Container ​

主要亮點：

  • 由 Mozilla Firefox 團隊製作
  • 平均評分為 4.5 星（3,500 多條評論）
  • 定期更新

每個人都討厭 Facebook，但很少有人願意從自己的網站上刪除 Facebook 的跟蹤元素。所以 Mozilla 引用了一個滅霸的片段 —— “好吧，我自己做”，併為 Firefox 用户創建了這個擴展。

顧名思義，為 Facebook 創建了一個隔離容器（與 Docker 無關）。所有與 Facebook 相關的東西都發生在這個孤立的容器中。 這最終使社交媒體巨頭更難追蹤你。

安裝 Facebook Container

2、uBlock Origin ​

主要亮點：

  • Mozilla 推薦的擴展
  • 4.8 星的平均評分（14,000 多條評論）
  • 定期更新

uBlock Origin 是 Firefox 最知名和最受信任的“廣告攔截”擴展之一。是的，它主要用於屏蔽廣告，但因為它的基本任務是屏蔽你的網絡瀏覽器中的元素，所以它可以屏蔽很多項目。廣告，是的，還有網絡跟蹤器、加密貨幣礦工、彈出窗口等。

雖然它的權限可能看起來有點過分，但這背後是有原因的。該擴展需要“在導航期間訪問瀏覽器活動”和“訪問所有網站的數據”等權限，以便它可以評估每個查詢並阻止那些看起來有害或無用的查詢。

安裝uBlock Origin

3、Bitwarden ​

主要亮點：

  • Mozilla 推薦的擴展
  • 平均評分為 4.8 星（6000 多條評論）

Bitwarden 應該是每個人的首選密碼管理器。它為移動端、網頁端和 PC 端提供免費同步支持，還可以安全地存儲筆記，幫助生成用户名和密碼、自動填充用户信息等等。最重要的是，它使用 GPL-3.0 許可證。誰不喜歡自由開源軟件？

Bitwarden 擁有我會在密碼管理器中尋找的一切。如果你想升級到高級版，只需 10 美元。 我強烈推薦這個 Firefox 擴展！

安裝 Bitwarden

4、LanguageTool ​

主要亮點：

  • Mozilla 推薦的擴展
  • 平均評分為 4.7 星（2900 多條評論）
  • 定期更新

你是否想要 Grammarly 的開源替代品？雖然我在使用 Grammarly 時沒有任何問題，但我真正喜歡和首選的是自由開源軟件。LanguageTool 是一款出色的工具，可用於檢查拼寫錯誤等語法不一致、使用不同的拼寫（color 與 colour）、常見的混淆詞（then 與 than），你還可以使用它獲得同義詞庫。

根據我使用此擴展的經驗，它幾乎可以在所有文本上可靠地工作。毫無問題。該擴展最大的兩個特點如下：

  • 支持超過 25 種語言。支持的語言列在“關於此擴展程序”部分的底部。
  • 使用此擴展無需註冊！

安裝 LanguageTool

5、Tranquikity Reader ​

想像一下，你正在閲讀互聯網上的一篇文章，網頁頂部和底部有兩個橫幅廣告，整個右側都是廣告，底部的廣告橫幅是自動播放的視頻。你打開廣告攔截器，但視頻繼續播放。有時橫幅中沒有廣告，但它們仍然佔用了寶貴的屏幕空間。你是否感覺很煩惱？

別擔心，看，Firefox 的 Tranquility Reader 擴展可以解決這個問題。此擴展程序刪除了“額外的”元素，如照片、視頻、廣告、社交媒體共享按鈕等。它為你提供了一個乾淨的 UI，只有文本，因此你可以專注於閲讀。

Tranquility Reader 擴展具有以下統計信息：

  • Mozilla 推薦的擴展
  • 平均評分為 4.6 星（200 條評論）
  • 不經常更新但積極維護

安裝 Tranquility

6、Enhancer for YouTube ​

主要亮點：

  • Mozilla 推薦的擴展
  • 平均 4.7 星評級（9,000 多條評論）

它是 Firefox 中眾多 Youtube 增強擴展之一。它為 YouTube 播放器添加了一些按鈕，允許進行更多的自定義。你可以獲得諸如更改分辨率、控制播放速度、使用鼠標滾輪控制音頻音量等功能。

你可以在其 官方網頁 上找到有關該擴展程序的更多信息。

安裝 Enhancer for YouTube

7、Tomato Clock ​

當你上網時，跟蹤你的時間、生產力和理智是至關重要的。尤其是當你正在研究一個主題並陷入困境時，你應該休息一下，但你會過於投入，以至於你可能會忘記時間。

Tomato Clock 擴展正如它的名字，它是一個時鐘定時器。一個“番茄”有 25 分鐘長，根據你對屏幕上顯示的內容的心理投入而感覺或長或短。完成 25 分鐘後，你將收到一個瀏覽器通知，通知你時間的流逝。

主要亮點：

  • Mozilla 推薦的擴展
  • 它的平均評分為 4.5 星（300 多條評論）
  • 使用 GPL v3.0 許可證

安裝 Tomato Clock

8、Search by Image ​

關鍵亮點：

  • Mozilla 推薦的擴展
  • 平均評分為 4.6 星（1,100 多個評論）
  • 對你上傳的媒體採用了合理的 隱私政策

當你搜索“紅色蘭博基尼”一詞時，你會得到紅色蘭博基尼的圖片。但是，如果你不知道它是什麼車呢？這個擴展允許你使用圖像而不是文字術語來搜索圖像，並顯示類似的結果或該圖像的來源地。

你可以通過以下方式選擇圖片進行搜索：

  • 選擇 URL：這使你可以直接點擊顯示在網頁上的圖像。
  • 網頁截圖：選擇網頁上的一個特定區域，以便進行反向圖像搜索。
  • 本地圖片：從計算機的本地驅動器（而不是網頁）上傳一個現有的圖像。
  • URL：粘貼圖像的 URL 以進行反向圖像搜索。

安裝 Search by Image

9、Dictionary Anywhere ​

主要亮點：

  • Mozilla 推薦的擴展
  • 平均 4.3 星評級（260 條評論）
  • 不定期更新

有一個無障礙的字典從來都不是一件壞事！當然，我已經被 macOS 的“壓感查詢”功能寵壞了。當我使用 Linux 時，Firefox 的 Dictionary Anywhere 擴展確實彌補了這一點。我需要做的就是雙擊一個詞，然後定義就會彈出來！

目前，支持的語言只有英語、西班牙語、德語和法語。請注意，這個擴展不能在 Firefox 的閲讀模式下工作。這是因為腳本不允許在這種模式下執行。

一個小瑕疵是，這使得在一個可編輯的文本中“雙擊並選擇整個單詞”變得略微惱人。這是為方便性付出的一個小代價。

此外，如果你想要一個積極維護的擴展，這將使你失望。

下載 Dictionary Anywhere

10、Vimium-FF ​

主要亮點：

  • 平均評分 4.8 星（400 多條評論）
  • 實驗性擴展

如果你是 Vim 用户，我就不需要向你解釋了，自己去試試吧！你會回來感謝我的。

對於那些不知道這個擴展做什麼的人，它允許你僅使用 Vim 樣式的鍵在 Firefox 中導航。按 J 鍵向下滾動、K 鍵向上滾動、X 鍵關閉當前選項卡、T 鍵打開一個新選項卡，以及各種其他鍵盤快捷鍵。

雖然這個擴展有“實驗性”標誌，但在過去一兩年的使用經驗中，我沒有遇到任何問題。

下載 Vimium-FF

11、FireShot ​

FireShot 是一個非常簡單的 Firefox 擴展，它允許你將完整的網頁截圖並保存為長圖或 PDF 文件，最重要的是，你還可以在截圖上註釋（哈哈哈）！但是註釋功能只能在 Windows 上使用，真是太可惜了！

它沒有 Firefox 的“推薦”徽章。 因此，你可以在決定使用它之前在其附加頁面上探索更多有關它的信息。

下載 FireShot
