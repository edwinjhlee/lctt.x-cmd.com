Komikku: 一個自由開源的 Linux 日漫閲讀器 ​

喜歡閲讀漫畫書嗎？有 大量可用於 Linux 的漫畫閲讀器。

但是，為日漫Manga量身定做的東西呢？

我想我找到了一個適合閲讀漫畫的完美應用，它可以管理它們，也可以下載它們進行離線使用。我最近發現的這個應用叫做 Kommiku。

讓我提一下這個應用的主要亮點，並幫助你在 Linux 上開始使用它。

Komikku: 一個 Linux 專用的日漫閲讀器 ​

Komikku 是一個開源的日漫閲讀器，且僅有 Linux 應用。

它主要是為配合 GNOME 桌面環境而定製的，但你也可以在運行 其他桌面環境 的 Linux 發行版上使用它。

許多 PDF 或 電子書閲讀器，如 Bookworm、Calibre 和 Foliate 都支持漫畫書格式。

然而，Komikku 用户會有更多的功能，以獲得閲讀漫畫的良好體驗。

例如，Komikku 可在線和離線觀看日漫。此外，你可以從支持的服務器上下載它。

Komikku 的特點 ​

Komikku 的一些最佳功能包括：

  • 從幾十個支持的服務器進行在線閲讀。
  • 離線閲讀已下載的日漫。
  • 按類別組織你的日漫庫。
  • 從右到左、從左到右、垂直和網絡漫畫閲讀模式。
  • 幾種類型的導航（鍵盤方向鍵、通過鼠標左右滑動或點擊（觸摸板/觸摸屏）、滾輪和滑動手勢（觸摸板和觸摸屏）。
  • 自動更新漫畫。
  • 自動下載新章節。
  • 閲讀歷史。
  • 淺色和深色主題。
  • 自適應設計（能夠從桌面工作站擴展到移動電話）。
  • 鍵盤快捷鍵。

安裝 ​

Komikku 可在 Flathub 上找到。因此，你可以把它安裝在任何 Linux 發行版上。

不過，你需要 在你的系統上設置 Flatpak 並啓用 Flathub 倉庫。

當你在系統上設置了 Flatpak，你可以通過軟件中心搜索它，或者從你的終端安裝它。

要使用終端安裝 Komikku，請輸入以下命令：

flatpak install flathub info.febvre.Komikku

Komikku 的原生包也可用於 Arch Linux 和 Fedora 等發行版。以下是安裝它們的命令：

對於 Arch Linux（在 AUR 中可用）：

yay -Syu komikku

對於 Fedora（在官方倉庫中可用）：

sudo dnf install komikku

在其 GitLab 頁面上可以查看 Komikku 的源代碼以及從源代碼構建它的説明。可以前往其官方網頁瞭解更多信息。

總結 ​

我發現 Komikku 非常直觀乾淨。我注意到在線服務器並不總是工作，經常有一些小故障，但管理離線漫畫和將你的藏品分類是毫不費力的。

所有這些都要感謝 Valéry Febvre（Komikku 的開發者），我們有了另一個有用的 Linux 應用。如果你喜歡這個應用，你可以考慮向該項目捐款。
