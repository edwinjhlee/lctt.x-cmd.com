一個值得關注的開源軟件 Penpot 將成為 Figma 可靠的替代品！ ​

Penpot 是一個自由開源的解決方案，能夠替代 Figma 或類似的設計工具。你怎麼看？

Adobe 以高達 200 億美元的價格收購了流行的設計工具 Figma。

像往常一樣，大型科技公司通過收購企業來消除競爭。因此，這並不完全是一個令人興奮的消息。

但是，令人興奮的是，我們遇到了一個自由開源的設計工具，它從 Figma 中獲得靈感並且做得更好！

Penpot：正在開發中的自由開源的設計工具 ​

Penpot Penpot 是一個正在積極開發的開源項目。將近兩年前，它在 ProductHunt 上推出，目前處於測試階段。

Penpot 值得關注的地方：

  • 自由開源（當然）。
  • 可以選擇自託管。
  • 跨平台。
  • 使用 SVG 作為原生格式。
  • 基於 Web。
  • 具有行業標準功能（受 Figma 啓發）。

你可以觀看其官方視頻以瞭解其基礎知識：

Penpot 的主要亮點是使用 SVG 作為其原生格式。使用 SVG 文件，你可以獲得與許多矢量圖形編輯工具很好的兼容性。

因此，你保存下來的文件，同樣可以被其他的圖片編輯軟件打開，而不會被其專有的格式鎖定在一個特定的軟件上。

Penpot 為你提供絕對最佳的開放標準。

Penpot 的 CEO，Pablo Ruiz-Múzquiz 提到了更多：

如果你在存儲層面上採用 SVG（開放標準，支持 Web，移動互聯網等），你馬上就可以將你所有的 Penpot 設計與你的代碼庫整合起來。由於採用了 SVG 而不是另一種封閉的格式，你可以對設計本身的實際表現進行修改。這為設計師和開發人員打開了巨大的機會之門。另外，SVG 意味着我們免費地就為低代碼提供了支持。你可以在 Penpot 中選擇任何元素並查看它的 SVG（和 CSS）形式，知道它實際上是什麼，無需翻譯。這給設計師和開發人員之間帶來了更值得信賴的關係，並允許前端開發人員嘗試他們的設計技能。

所以，使用 SVG 作為原生格式有很多優勢！

目前，該項目處於測試階段，且在項目中有大量熟練的貢獻者不斷改進。

這可以讓它變成 Figma 最有用的開源替代品，讓設計工具突破了大型技術公司。

你可以自行託管它或使用雲應用程序對其進行測試。在其官方網站上註冊以學習和試驗它。

你還可以查看其 GitHub 頁面 以探索更多信息。

Penpot

這也讓我想起了 Akira，它的目標是成為一個用於 UI 和 UX 設計的原生 Linux 應用程序。它仍處於早期開發階段，但當涉及 Linux 或開源計劃時，這種努力總是受到讚賞。
