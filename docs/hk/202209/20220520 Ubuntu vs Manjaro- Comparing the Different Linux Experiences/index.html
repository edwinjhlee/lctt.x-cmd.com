Ubuntu 和 Manjaro：比較兩種不同的 Linux 發行版體驗 ​

Ubuntu 是基於 Debian 最流行的桌面和服務器 Linux 發行版。

Manjaro 是基於 Arch 量身定製的 Linux 發行版。

兩者在用户體驗以及功能上都大相逕庭。

然而，將 Manjaro 的 GNOME 版和 Ubuntu 放到一起比較時，其中一個共同點是 桌面環境。

但它們到底有什麼不同？Manjaro 的包管理器會更好用嗎？Ubuntu 和 Manjaro 上的軟件生態怎麼樣？

接下來，我們來看看兩個 Linux 發行版在某些關鍵問題上的差異。

發行週期 ​

Ubuntu 根據你選擇的版本不同提供了兩個發行週期。如果你選擇的是長期支持版本Long Term Support（LTS），那麼你在至少未來五年內都會收到安全維護更新。

假如你安裝了 Ubuntu 22.04 ，那麼你在 2027 年 4 月 之前都能獲取更新。

因此，我們更推薦普通桌面用户使用 LTS 版本。

如果你想要更新更好的體驗，你可以選擇每九個月更新一次的非 LTS 版本。例如 Ubuntu 21.04、 Ubuntu 21.10、Ubuntu 22.10。

需要注意的是，非 LTS 版本涉及的更改可能會影響你的工作流程以及用户體驗。因此並不推薦所有人都去使用非 LTS 版本。

選擇 Manjaro Linux 時你將會獲得滾動發佈的更新，因此你不必擔心對你使用版本的支持過期。它會通過定期更新升級到最新的可用版本。

由於滾動發行週期的原因，你可以快速獲取到最新的軟件包。因此如果你想使用某個軟件的歷史版本，Manjaro 或許並不適合你。

桌面環境 ​

Ubuntu 特別提供了一個定製版的 GNOME 桌面。它可能不是最新的，但如果你使用較新的 Ubuntu 版本，它基本上包含的就是最新的 GNOME 桌面環境。

Canonical（Ubuntu 背後的公司）並不提供其它桌面環境。

但如果你想在 Ubuntu 上使用其它桌面環境，你可以選擇包含了 KDE、Budgie、LXQt、MATE 以及 XFCE 等桌面環境的 Ubuntu 官方 風味版Flavour。與提供了其他桌面環境的非官方版或更新的特色版Spin的 Ubuntu 相比，它們是經過良好測試且穩定的 Ubuntu Linux 發行版。

但是這些 Ubuntu 風味版沒有五年的軟件支持；相反，你只能受限地得到對 LTS 版本的三年支持。

如果使用 Manjaro，你可以選擇官方提供的三個版本：XFCE、KDE 和 GNOME。 無論桌面環境如何，你都會使用滾動發佈模式。

當然你也可以使用 Manjaro 的一些社區版本，如 Budgie、MATE、LXQt。

包管理器以及軟件生態 ​

在上述這兩類發行版中，找到大多數必要的 Linux 應用是沒問題的。

不過，Manjaro Linux 使用 Pamac 作為其包管理器而獲得了更快速的體驗。

與 Ubuntu 上的應用商店相比，Manjaro Linux 在快速安裝/更新軟件方面提供了更好的體驗。而且，它還支持開箱即用的 Flatpak/Snap，如果你只需一鍵即可啓用它們。

Ubuntu 比較重視 Snap 軟件包，你會發現一些應用程序預裝為 Snap 軟件包（如 Firefox 瀏覽器）。

對於 Manjaro Linux 來説，你可以根據自身需求決定是否啓用 Flatpak/Snap。

在使用 Ubuntu 時，其應用商店提供的 Linux 應用並不是最好的。取決於你的系統配置和使用年限，它會變得越來越慢。

除此之外，Manjaro Linux 還可以訪問 AUR，它可以獲得你在 Ubuntu 應用商店中可能找不到的幾乎所有軟件。

因此，就軟件生態系統和包管理器而言，Manjaro Linux 的確要比 Ubuntu 有更多的優勢。

易用性和目標用户 ​

Ubuntu 桌面主要是為了易於使用而量身定製的。它專注於提供最佳的軟件和硬件兼容性組合，讓所有計算機用户都可以使用 Ubuntu Linux，而無需瞭解 Linux 世界中的大部分內容。

即使有人不知道 Linux 上的“包管理器”是什麼，在他們使用它時也可以完全把它作為 Windows/macOS 的完美替代品。

當然，我們也有一個指南來幫助你 安裝最新的 Ubuntu 後要做的事情。

Manjaro Linux 也是為桌面用户使用量身定製的。但是它並不適合首次使用 Linux 的用户使用。

它旨在簡化 Arch Linux 的操作。因此主要面向想要使用 Arch Linux 的 Linux 用户，但是增加了一些便利性。

穩定性 ​

Ubuntu LTS 版本主要關注穩定性和可靠性，因此你也可以在服務器上部署它們。

相比之下，Manjaro Linux 可能沒有提供現成的的穩定性。你在 Manjaro Linux 中安裝軟件包時需要更加仔細，同時密切注意你的配置，以確保更新不會破壞你的系統。

對於 Ubuntu 用户來説則無需擔心軟件更新，尤其是在考慮 LTS 版本時，更新通常不會破壞你的系統。

個性化 ​

Ubuntu 特別提供了一個由 Canonical 為最終用户設置的定製 GNOME 桌面。雖然你可以自由定製你的 Linux 發行版的各個方面，但 Ubuntu 開箱即用提供定製很少。

Ubuntu 多年來一直在改進，最近增加了 在 Ubuntu 22.04 LTS 中添加強調色 的能力。 但是它仍然還有很長的路要走。

如果你想獲得個性化的桌面體驗，你只能藉助 GNOME Tweak 等軟件來實現。

對比 Manjaro GNOME，你也只能使用相同的工具來自定義桌面。

Manjaro 還對外觀進行了一些自定義調整。但是它提供了更多組件來更改佈局和其他一些選項。

在個性定製方面，你在 Manjaro 和 Ubuntu 上的體驗大致相同。

如果你想要更多自定義選項，Manjaro Linux 可能是一個不錯的選擇。但是如果你只想要個性化體驗而不需要太多的改變，Ubuntu 應該就足夠了。

臃腫的軟件 ​

這對每個人來説可能都不是什麼大問題。但如果你不喜歡預裝許多應用程序，那麼 Ubuntu 可能會令你感到麻煩。

雖然可以隨時刪除不需要的應用程序。但是你會發現隨 Ubuntu 一起安裝的軟件和服務還有很多。

使用 Manjaro 時，你在安裝時只需要安裝最基礎的內容即可。它們堅持使用最基礎的實用程序，最大限度地減少預裝的軟件包數量。因此，Manjaro 很少會和軟件臃腫聯繫到一起。

但是你在默認安裝的 Manjaro 上可能找不到你最喜歡的 Linux 軟件。因此，如果你想在安裝後立即使用一些你喜歡的軟件，Ubuntu 可能是一個不錯的選擇。

性能 ​

雖然 Ubuntu 改進了其系統表現，甚至可以在 2 GB 內存的樹莓派上運行，但它仍然不是性能最好的 Linux 發行版。

當然，性能確實取決於你選擇使用的桌面環境。

但是與 Manjaro 的 GNOME 版本相比，Manjaro 提供了更快捷的體驗。

需要注意的是，性能和動畫首選項的用户體驗還取決於你的系統配置。例如，Manjaro 的推薦系統要求（1GB 內存和 1GHz 處理器）給了你使用舊電腦的機會。

但是，對於 Ubuntu，在撰寫本文時，你至少需要 4GB 內存 和 2GHz 雙核處理器，才能獲得理想的桌面體驗。

文檔 ​

考慮到 Ubuntu 的受歡迎程度，Ubuntu 更易於使用，並且對新用户來説可能更舒適。

Ubuntu 的文檔 即使不是最好也足夠好了。

談到 Manjaro Linux，他們有一個 維基，其中包含基礎信息和深入的指南來幫助你入門。

總的來説，Arch Linux 的文檔 非常細緻，幾乎每個人（甚至是老手）都會參考它來尋求幫助。

Arch Linux 的文檔在很大程度上也適用於 Manjaro Linux，因此在文檔方面，使用 Manjaro Linux 比 Ubuntu 更有優勢。

結束語 ​

作為兩個完全不同的 Linux 發行版，它們服務於各種類型的用户。你可以選擇你感興趣的任意一個並嘗試去使用它來判斷它是否適合你。

但是，如果你想避免對系統進行任何更改，並專注於你的工作，那麼 Ubuntu 應該是一個明智的選擇。

而如果 Ubuntu 的性能對你的體驗有相當大的影響，你應該去嘗試 Manjaro。 你可以閲讀我的 關於從 Ubuntu 切換到 Manjaro 的初步想法。
