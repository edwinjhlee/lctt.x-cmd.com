你的舊電腦是 “過時” 了，還是使用 Linux 的機會？ ​

很多時候，老舊的電腦往往被打上 “過時” 的標籤。Linux 改變了這一現狀。翻新舊電腦，讓它重新為需要它的人所用。

你可能經常聽到有人説某個電腦、平板電腦或智能手機 “過時了”。當你聽到這樣的説法時，花一分鐘問問自己：“這個人説的是個人觀點還是事實？”

很多時候他們的陳述是主觀觀點。讓我解釋一下為什麼。

當有人説一台電腦 “過時” 時，他們往往是從自己的角度出發的。因此，如果你是一名專業技術人員，一台使用了五年的電腦可能確實已經過時。但對於一個逃離戰爭或饑荒的難民家庭來説，這台五年前的電腦過時了嗎？可能不會。對你來説過時的電腦，對別人來説可能是夢寐以求的電腦。

我是如何用 Linux 翻新舊電腦的 ​

我在這方面有些經驗。在過去的 25 年裏，我一直把老舊電腦帶給那些沒有電腦的人。我的一名二年級學生，由祖母撫養長大，五年前從斯坦福大學畢業了。另一位學生，我在 2007 年給他送去了一台佈滿灰塵的 Windows XP 台式機，去年她從耶魯大學畢業。這兩名學生都利用捐贈的電腦實現了自我發展。後一位學生在中學畢業前，打字速度就超過了每分鐘 50 個單詞。我把捐贈電腦送到她家時，她還在讀三年級，當時她的家庭還負擔不起網絡服務。因此，她有效地利用時間學習觸摸打字技巧。我在這個 YouTube 視頻 中記錄了她的故事。

我再分享一件連我自己都難以相信的軼事。幾年前，我在 eBay 上花 20 美元買了一台戴爾筆記本電腦。這枱筆記本電腦是 2002 年的頂級筆記本電腦。我在上面安裝了 Linux Mint，並添加了一個 USB WiFi 適配器，這枱筆記本電腦就這樣重生了。我把這個故事記錄在 YouTube 視頻中，名為 “我的 20 美元 eBay 筆記本電腦”。

在視頻中，你可以看到這枱筆記本電腦正在上網。它的速度並不快，但比我們在 20 世紀 90 年代末使用的撥號上網電腦要快得多。我會將其描述為功能正常。有人可以用這台 2002 年的筆記本電腦撰寫博士論文。論文讀起來就像用昨天發佈的電腦寫的一樣好。這枱筆記本電腦應該擺放在公共場所，讓人們近距離看到 2002 年的電腦仍然可以使用。眼見為實。這難道不是真理嗎？

那麼 2008 年、2009 年和 2010 年那些著名的 “上網本” 怎麼樣？它們肯定已經過時了吧？沒那麼快了吧！如果你在它們身上安裝 32 位 Linux，它們就可以使用最新版本的 Chromium 網頁瀏覽器上網衝浪，而 Chromium 瀏覽器仍然支持 32 位操作系統（不過谷歌 Chrome 瀏覽器不再支持 32 位操作系統）。使用這些上網本的學生可以觀看可汗學院Khan Academy的視頻，使用谷歌文檔Google Docs提高寫作能力。將這些上網本連接到更大的液晶屏幕上，學生就可以使用 LibreOffice Draw 或 Inkscape 這兩個我最喜歡的開源圖形程序來提高技能。如果你感興趣，我有一個 使用 Linux 重振上網本的視頻。上網本也非常適合郵寄到海外，比如利比里亞的學校、海地的醫院、索馬里的食品分發點，或者其他任何捐贈技術可以發揮巨大作用的地方。

你知道翻新的上網本在哪裏會受到歡迎嗎？在那些向烏克蘭難民敞開心扉和家園的社區。他們在儘自己的一份力量，我們也應該儘自己的一份力量。

開源讓老舊電腦重獲新生 ​

許多技術專業人士生活在特權的泡沫中。當他們宣稱某項技術 “過時” 時，可能並沒有意識到他們把這種觀點當作事實所造成的傷害。不瞭解開源如何讓舊電腦重新煥發生機的人，正在宣判這些電腦的死刑。面對這種情況，我不會袖手旁觀。你也不應該袖手旁觀。

對於宣稱電腦過時的人，一個簡單的回答是：“有時舊電腦可以重獲新生。我聽説開源就是一種方法。”

如果你很瞭解對方，不妨分享本文列出的一些 YouTube 視頻鏈接。如果有機會，請花點時間去見見那些無法獲得所需技術的個人或家庭。這次會面將以你意想不到的方式豐富你的生活。
