LibreOffice 和 OpenOffice 的相似與不同之處 ​

對兩個最受歡迎的開源辦公軟件的比較。瞭解 LibreOffice 和 OpenOffice 之間的相似與不同之處。

LibreOffice 與 OpenOffice 是兩個流行的微軟辦公套件的 開源替代品。

如果你正在尋找一個具備文字處理、電子表格、演示和其他幾個程序的開源辦公套件，那麼這兩個辦公軟件都可以推薦。

然而，要充分利用這些辦公套件，你應該瞭解它們之間的差異，以決定哪個最適合你。

你應該使用 LibreOffice 還是 OpenOffice？它們之間有什麼區別？在這裏，我將更詳細地探討這些問題。

LibreOffice vs. OpenOffice：起源 ​

OpenOffice 是由 昇陽微系統Sun Microsystems 開發的項目。它是（他們最初收購的）與微軟辦公套件競爭的 StarOffice 的開源版本。

後來，甲骨文Oracle 收購了昇陽微系統，並最終放棄了 OpenOffice.org（OOo），將代碼庫交給了 Apache。

在 Apache 開始維護它時，該辦公套件的名稱被更改為 “OpenOffice” 或 “Apache OpenOffice”。

在這個過渡期間，出於擔心 Oracle 會停止該項目，文檔基金會The Document Foundation 復刻了 OpenOffice.org，創建了 LibreOffice。

因此，LibreOffice 是作為 OpenOffice.org 的替代品而創建的。

但是，現在 OpenOffice 仍然存在並得到積極維護（LCTT 譯註：不是），為什麼你應該選擇 LibreOffice？OpenOffice 不夠好嗎？它們之間有什麼相似之處？

LibreOffice 和 Apache OpenOffice 有什麼共同之處？ ​

LibreOffice 和 Apache OpenOffice 有一些共同之處：

如果你只需要創建基本文檔、電子表格或演示文稿，並不需要進行任何複雜操作或快捷方式來提高生產力，那麼你可以使用它們中的任何一個。

簡單來説，如果你在 Linux、Windows 和 macOS 上需要一個開源辦公套件，這兩個軟件都可以勝任。

LibreOffice 和 Apache OpenOffice 都能夠打開包括微軟的 DOCX、PPT 等在內的各種文件格式。

但是，當你需要不同的功能、用户界面、文件格式兼容性、導出能力和其他特性時，它們之間的相似之處就會逐漸消失。

當然，如果你開始廣泛使用它們，你將會注意到它們之間的差異。

為了節省你的麻煩，讓我在這裏重點指出這些差異：

安裝和平台可用性 ​

用户體驗的第一步是安裝過程和平台可用性。

如果安裝複雜且不支持多個平台，那麼這個程序就令人失望。

在這種情況下，LibreOffice 和 Apache OpenOffice 官方支持 Linux、Windows 和 macOS。

至於移動平台，你可以在谷歌 Play 商店（安卓）和蘋果應用商店（iOS）上找到基於 LibreOffice 的 Collabora Office。考慮到 Collabora 是 LibreOffice 的商業合作伙伴，它幾乎可以視為 LibreOffice 的官方移植版。

而對於移動設備上的 OpenOffice，雖然你也可以使用其他社區/第三方移植版替代，但它沒有官方移植版可用。

現在你已經瞭解了支持的平台，它們的安裝是否容易？

對於 Linux，LibreOffice 在官方軟件庫中可用，並在軟件中心和軟件包管理器中列出。因此，你只需點擊幾下即可在 Linux 系統上安裝它。

不幸的是，OpenOffice 的安裝過程比較麻煩。它不在軟件庫中，軟件中心中也找不到它。而且，如果你已經預先安裝了 LibreOffice，則在嘗試安裝 OpenOffice 之前必須先刪除任何痕跡（以避免安裝衝突）。

你需要從其網站下載官方軟件包（根據你的 Linux 發行版），然後解壓縮，並使用一些命令來在 Linux 上安裝 OpenOffice。

對於 Windows 和 macOS，安裝非常簡單，你只需 下載安裝包，然後按照屏幕上的指示進行操作即可。

LibreOffice 還提供了另一種方式 可供獲取（通過合作伙伴），即通過微軟商店和 Mac 應用商店。不過，你需要支付費用。其中的一部分將捐贈給文檔基金會，一部分用於 LibreOffice 的開發。

還要注意，由於 Collabora Office，你也可以在 Chromebook 上使用 LibreOffice。

總而言之，LibreOffice 提供了更好的平台可用性和更輕鬆的安裝過程，這使得 OpenOffice 成為一個不太推薦的選擇。

用户體驗 ​

LibreOffice 提供了一個令人愉悦的用户界面，與現代標準相融合。LibreOffice 在大多數現代硬件上看起來都很好，不論你使用的是 2K 顯示器還是 4K 顯示器。

你可以從主啓動器快速訪問所有工具，這是一種良好的體驗。Writer、Calc 和其他程序提供了一個易於使用且看起來井然有序的界面。

Apache OpenOffice 提供的是一個過時的用户界面。因此，如果你正在尋找一個現代化的開源辦公套件，LibreOffice 是首選。

當然，一些用户喜歡經典的用户界面，因為他們對此很熟悉，並且在舊硬件上的使用受到限制。

換句話説，OpenOffice 仍然可用，但對於大多數現代用户來説可能不是一種直觀的體驗。

如果你仔細比較用户界面元素，這將取決於你閲讀本文時可用的最新版本。因此，我們避免進行具體的視覺比較。

特點 ​

強大的功能集的需求取決於你處理的文件類型。

默認情況下，OpenOffice 和 LibreOffice 均提供以下程序：

  • Math（科學公式）
  • Writer（文檔）
  • Impress（演示文稿）
  • Draw（繪圖、流程圖等）
  • Calc（電子表格）
  • Base（資料庫）

無論你使用文字處理器（Writer）、電子表格（Calc）還是演示文稿（Impress），你都可以獲得相同的標準功能。

然而，如果你處理需要訪問更多模板、函數、導入/導出選項和高級格式設置的複雜文檔，LibreOffice 會更優秀一些。

文件格式兼容性 ​

OpenOffice 支持幾乎與 LibreOffice 相同的文件擴展名。

但是，LibreOffice 還支持一些 OpenOffice 不支持的文件格式導出。

例如，你可以在 OpenOffice 中打開 .DOCX 文件，但無法保留文件擴展名保存/導出該文件。

你只能將其保存為 .odt/.doc./.ott 等幾種類似的文件格式。

同樣，你無法得到對 .xslx 和 .pptx 的支持，這些是通常用於電子表格和演示文稿的現代文件格式。

當然，如果你不依賴於這些文件格式，可以嘗試使用 OpenOffice。然而，與使用較新文件格式的用户進行協作時，你將遇到可能影響你工作的兼容性/格式設置問題。

考慮到 OpenOffice 缺乏許多功能，依賴它來訪問較新的文件格式可能不明智；由於不良的兼容性，你可能會丟失重要的細節。

更新 ​

為了提高你使用該程序的效率並獲得增強的性能、新功能和安全修復，建議選擇定期獲得更新的軟件工具。

從技術上講，兩者都會定期獲得更新。但是，OpenOffice 僅限於修復錯誤和進行小型更新。

LibreOffice 的開發活動更加活躍，頻繁修復錯誤/進行小型更新，定期進行較大的升級，增加新功能和改善用户體驗。

難怪 LibreOffice 給 Apache 寫了一封公開信，請求停止開發 OpenOffice 並將這些資源轉用於幫助 LibreOffice 的開發。

企業支持和在線協作選項 ​

有了 Collabora Office，你可以獲得企業支持，並能夠在工作場所使用 LibreOffice。通過 Collabora Online，你還可以在服務器上部署 LibreOffice 以實現協作工作空間。

遺憾的是，Apache OpenOffice 沒有任何企業支持選項。因此，如果有的話，它最適合家庭用户使用。

許可 ​

對於使用這些程序並無任何許可問題，也不會阻止或使你不願使用它們。然而，這些信息對於項目的貢獻者可能會有所幫助。

LibreOffice 使用 Mozilla Public License v2.0 許可證，而 Apache OpenOffice 則使用 Apache License 2.0 許可證。

LibreOffice vs. OpenOffice：應該選擇哪個？ ​

基於現代設計、更多功能和對較新文件格式的支持，LibreOffice 是一個易於推薦的選擇。

OpenOffice 可以是適用於熟悉舊版辦公套件界面，且希望在 32 位系統中無障礙運行的用户的解決方案。在 LibreOffice 由於某些原因無法正常工作的情況下，OpenOffice 應該作為備選方案。

我們可以告訴你選擇取決於個人喜好，但如果你經常處理文檔，如果我不説 LibreOffice 是更好的選擇，那麼我顯然不夠誠懇。
