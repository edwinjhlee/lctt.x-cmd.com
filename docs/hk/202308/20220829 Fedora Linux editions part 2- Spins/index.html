Fedora Linux 的家族（二）：定製版 ​

使用 Linux 的一個好處是可以選擇多種不同的桌面環境。Fedora Linux 官方的 Workstation 版本默認使用 GNOME 作為桌面環境，但是你可以通過 Fedora 定製版Spin 選擇另一個桌面環境作為默認環境。本文將更詳細地介紹 Fedora Linux 定製版。你可以在我之前的文章《Fedora Linux 的各種版本》中找到所有 Fedora Linux 變體的概述。

KDE Plasma 桌面 ​

這個 Fedora Linux 定製版使用 KDE Plasma 作為默認的桌面環境。KDE Plasma 是一個優雅的桌面環境，非常易於定製。因此，你可以根據自己的喜好自由地定製桌面的外觀。你可以定製你喜歡的主題，安裝所需的小部件，更換圖標、字體，根據個人喜好定製面板，並從社區安裝各種擴展功能。

Fedora Linux KDE Plasma 桌面預裝了許多常用的應用程序。你可以使用 Firefox、Kontact、Telepathy、KTorrent 和 KGet 上網。LibreOffice、Okular、Dolphin 和 Ark 可滿足你的辦公需求。而針對多媒體需求，該版本提供了 Elisa、Dragon Player、K3B 和 GwenView 等多個應用程序。

Fedora Linux KDE Plasma 桌面

XFCE 桌面 ​

這個版本非常適合那些希望在外觀定製和性能之間取得平衡的用户。XFCE 本身被設計為快速輕巧，但仍具有吸引人的外觀。這個桌面環境逐漸受到老舊設備用户的歡迎。

Fedora Linux XFCE 安裝了多種適合日常需求的應用程序，包括 Firefox、Pidgin、Gnumeric、AbiWord、Ristretto、Parole 等。Fedora Linux XFCE 還提供了一個系統設置菜單，讓你更輕鬆地配置 Fedora Linux。

更多信息請訪問此鏈接:

Fedora Linux XFCE 桌面

LXQT 桌面 ​

這個版本帶有一個輕量級的 Qt 桌面環境，專注於現代經典的桌面體驗，而不會降低系統性能。這個 Fedora Linux 版本包含基於 Qt5 工具包的應用程序，並採用 Breeze 主題。你可以通過內置的應用程序如 QupZilla、QTerminal、FeatherPad、qpdfview、Dragon Player 等來進行各種日常活動。

更多信息請訪問此鏈接:

Fedora Linux LXQT 桌面

MATE-Compiz 桌面 ​

Fedora Linux MATE Compiz 桌面是 MATE 和 Compiz Fusion 的組合。MATE 桌面環境使這個 Fedora Linux 版本能夠通過優先考慮生產力和性能來發揮最佳效果。同時，Compiz Fusion 使用 Emerald 和 GTK+ 主題為系統提供了美觀的 3D 外觀。這個 Fedora Linux 版本還配備了各種流行的應用程序，如 Firefox、LibreOffice、Parole、FileZilla 等。

更多信息請訪問此鏈接:

Fedora Linux MATE Compiz 桌面

Cinnamon 桌面 ​

由於其用户友好的界面，Fedora Linux Cinnamon 桌面非常適合那些可能對 Linux 操作系統不太熟悉的用户。你可以輕鬆理解如何使用這個 Fedora Linux 版本。這個定製版內置了各種準備好供你日常使用的應用程序，如 Firefox、Pidgin、GNOME Terminal、LibreOffice、Thunderbird、Shotwell 等。你可以使用 Cinnamon 設置應用來配置你的操作系統。

更多信息請訪問此鏈接:

Fedora Linux Cinnamon 桌面

LXDE 桌面 ​

Fedora Linux LXDE 桌面擁有一個快速運行的桌面環境，但設計旨在保持低資源使用。這個定製版專為低配置硬件設計，如上網本、移動設備和舊電腦。Fedora Linux LXDE 配備了輕量級和流行的應用程序，如 Midori、AbiWord、Osmo、Sylpheed 等。

更多信息請訪問此鏈接:

Fedora Linux LXDE 桌面

SoaS 桌面 ​

SoaS 是 “Sugar on a Stick” 的縮寫。Fedora Linux Sugar 桌面是一個面向兒童的學習平台，因此它具有非常簡單的界面，易於兒童理解。這裏的 “stick” 是指一個隨身驅動器或存儲“棒”。這意味着這個操作系統體積緊湊，可以完全安裝在一個隨身 U 盤上。學童可以將他們的操作系統攜帶在隨身 U 盤上，這樣他們可以在家、學校、圖書館和其他地方輕鬆使用。Fedora Linux SoaS 擁有各種有趣的兒童學習應用程序，如 Browse、Get Books、Read、Turtle Blocks、Pippy、Paint、Write、Labyrinth、Physic 和 FotoToon。

更多信息請訪問此鏈接:

Fedora Linux Sugar 桌面

i3 Tiling WM ​

Fedora Linux 的 i3 Tiling WM 定製版與其他不太相同。這個 Fedora Linux 定製版不使用桌面環境，而只使用窗口管理器。所使用的窗口管理器是 i3，它是 Linux 用户中非常受歡迎的平鋪式窗口管理器。Fedora i3 定製版適用於那些更注重使用鍵盤進行交互而非鼠標或觸摸板的用户。這個 Fedora Linux 定製版配備了各種應用程序，如 Firefox、NM Applet、brightlight、azote、htop、mousepad 和 Thunar。

Fedora Linux i3 Tiling WM

結論 ​

Fedora Linux 通過 Fedora Linux 定製版提供了大量的桌面環境選擇。你只需選擇一個 Fedora 定製版，即可享受你選擇的桌面環境以及其內置的即用應用程序。你可以在 https://spins.fedoraproject.org/ 找到關於 Fedora 定製版的完整信息。
