終端基礎：Linux 終端入門 ​

想了解 Linux 命令列的基礎知識嗎？ 這是一個帶有實踐方法的教程系列。

Linux 終端可能令人生畏。這塊黑色的屏幕只能使用命令。很容易讓人感到迷失。

問題是 Linux 命令列是一個很大的話題。你只需使用命令即可管理整個系統。我的意思是，這就是系統管理員、網絡工程師和許多其他工作的角色。

本教程集的目的不是讓你做好工作準備。它旨在為你提供 Linux 命令列之旅的起點。 它將為你提供足夠的能力來使用終端並瞭解一些基本知識，例如讀取文件和編輯文件。

由於這只是開始，所以大部分教程都屬於“文件操作”類別。這是大多數 Linux 書籍和課程的起點。

📋 最好的學習方法就是自己動手。我以“實踐模式”編寫了這些教程，以便你可以在 Linux 系統上參照這些示例。本系列的每一章都包含一些示例練習來鍛鍊。跟着學、多練習，你很快就能熟練掌握 Linux 命令列。
