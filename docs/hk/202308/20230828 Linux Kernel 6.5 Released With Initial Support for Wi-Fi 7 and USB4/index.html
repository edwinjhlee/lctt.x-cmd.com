Linux 內核 6.5 發佈，首次支持 Wi-Fi 7 和 USB4 ​

Linux 內核 6.5 進行了一系列的改善，閲讀此文以瞭解詳情。

新版的 Linux 內核已經發布！

Linux 6.5 內核 已經推出，此次更新在 Linux 6.4 內核的基礎上進行了進一步的開發，帶來了值得注意的改變和新特性。

Linus Torvalds 表示，這是一次相對順暢的發佈：

上週並沒有發生任何異常或驚人的事情，因此沒有理由延遲 6.5 版的發佈。

我仍有這樣一個擔憂，似乎是因為許多人都在度假，部分導致整體狀態比較平靜。但目前這次發佈進展順利，所以這可能只是我多慮了。上週的最大更新就僅僅是對我們自我測試的幾次修訂。

🆕 Linux 內核 6.5：新增了哪些功能？ ​

需要説明的是，這次發佈的版本不是長期支持（LTS）版本。如果你期望使用最新的功能，那麼這個版本就是為你準備的。否則，除非此版本解決了你關心的特定問題或者能有效提升性能，否則沒有升級的必要。

以下是新版內核發佈的主要亮點：

  • AMD FreeSync 視頻的即插即用支持
  • AMD CPU 默認啓用 P-State 主動模式
  • 對 USB4 v2 和 WiFi 7 的初步支持
  • ASUS ROG Ally 音效優化

開箱即用的 AMD FreeSync 視頻支持 ​

在這次發佈中，重新引入的一項優秀功能是默認開啓的 AMD FreeSync 視頻模式支持。此特性在 Linux 內核 5.8 版本中首次引入，後因錯誤而被回滾。

啓用 AMD FreeSync 模式後，通過將顯示器的刷新率與顯卡的幀率相匹配，可以顯著減少遊戲及視頻中的屏幕撕裂和遲滯現象。

用技術詞彙來描述，當它在 Linux 內核 5.8 版本中首次發佈時，它的描述是：

這個補丁集啓用了 FreeSync 視頻模式的使用場景，這樣用户空間可以請求一個 FreeSync 兼容的視頻模式，因此，切換到此模式不會觸發屏幕黑屏。

這對內容創作者和遊戲玩家都非常有用。

但請注意，你需要一個兼容 FreeSync 的顯示器和顯卡才能充分利用它。

AMD CPU 默認啓用 P-State 主動模式 ​

現代 AMD CPU，特別是那些基於 Zen 2 及更新架構構建的，將默認採用 amd-pstate 作為 CPU 性能調整驅動。之前，CPU 的頻率調整機制默認由 CPUFreq 負責。

現在，amd-pstate 提供了三種模式：主動、被動和引導式自主模式。在這次發佈中，默認啓用了主動模式，從而取代了之前 Linux 內核 6.4 版本中使用的引導式自主模式。

據 Phoronix 的一些 基準測試 結果顯示，發現 amd-pstate 的性能優於 CPUFreq。

你可以參考這個 提交 瞭解更多詳情。

ASUS ROG Ally 聲音優化 ​

ASUS ROG Ally 是一款使用 AMD Z1 和 Z1 Extreme SoCs 驅動的 Windows 手持式遊戲電腦，直接競爭的對手是非常知名的 Steam Deck。它在今年七月發佈。

使用 Linux 的遊戲玩家如果擁有 ASUS ROG Ally，可以期待看到一個針對系統音頻設備的修補發佈，感謝這個 提交。

對 USB4 v2 & WiFi 7 的初始支持 ​

下一代無線標準 - WiFi 7 - 的開發工作已經進行了一段時間。WiFi 7 支持 6Ghz 頻段，最大數據傳輸速率達到 23 Gbps！

與此同時，下一代 USB4 標準的開發工作也已開始。USB4 支持 80 Gbps 的數據傳輸速率！

通過對 WiFi 的這個 合併 和對 WiFi 7 的 拉取請求，對二者的早期支持已經被嵌入到 Linux 6.5 內核中。

🛠️ 其他改動與提升 ​

除了主要的亮點外，還有一些值得一提的更新：

  • 對英特爾 P-State 的 CPU 進行了縮放修復
  • 對 Btrfs 的性能進行了改進，以及其他存儲優化
  • 對最新的 Xbox 控制器增加了 Rumble 支持
  • 對 AMD Radeon RX 7000 系列顯卡進行了超頻支持
  • 對 AMD 和英特爾圖形驅動進行了各種優化和改進
  • 和以往一樣，更多的 Rust 代碼轉換

官方發佈公告 將給出自從上一個候選版釋放以後的摘要。如果你對技術細節有興趣，不妨參考 變更日誌。

安裝 Linux 內核 6.5 ​

如果你使用像 Arch 這樣的滾動更新發行版，可以很容易地升級至 Linux 內核 6.5。在新版本發佈後的一段時間，這些發行版本會提供最新的內核。

另一方面，使用 Ubuntu 及其衍生版本的用户，可以期待在 Ubuntu 23.10 版本中看到這次的 Linux 內核發佈。如果你使用的是像 Pop OS 和 Linux Lite 這樣的發行版，可能會更早的見到這版內核發佈。

但是如果你希望在基於 Ubuntu 的系統裏快速嘗試，可以按照我們的指南進行（請注意，這是自行承擔風險！👀）。

你可以在它的 官方網站 上下載最新的 Linux 內核 的 Tarball（發佈之後可能需要一段時間才能下載到）。
