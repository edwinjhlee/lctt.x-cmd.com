Dropbox 在 Linux 上終止除了 Ext4 之外所有文件系統的同步支持 ​

Dropbox 正考慮將同步支持限制為少數幾種文件系統類型：Windows 的 NTFS、macOS 的 HFS+/APFS 和 Linux 的 Ext4。

Dropbox 是最受歡迎的 Linux 中的雲服務之一。很多人都在使用 Linux 下的 Dropbox 同步客户端。但是，最近，一些用户在他們的 Dropbox Linux 桌面客户端上收到一條警告説：

“移動 Dropbox 文件夾位置， Dropbox 將在 11 月停止同步“

Dropbox 將僅支持少量文件系統 ​

一個 Reddit 主題強調了一位用户在 Dropbox 論壇上查詢了該消息後的公告，該消息被社區管理員標記為意外新聞。這是回覆中的內容：

“大家好，在 2018 年 11 月 7 日，我們會結束 Dropbox 在某些不常見文件系統的同步支持。支持的文件系統是 Windows 的 NTFS、macOS 的 HFS+ 或 APFS，以及Linux 的 Ext4。

Dropbox 官方論壇

Dropbox 官方確認支持文件系統的限制

此舉旨在提供穩定和一致的體驗。Dropbox 還更新了其桌面要求。

那你該怎麼辦？ ​

如果你在不受支持的文件系統上使用 Dropbox 進行同步，那麼應該考慮更改位置。

Linux 僅支持 Ext4 文件系統。但這並不是一個令人擔憂的新聞，因為你可能已經在使用 Ext4 文件系統了。

在 Ubuntu 或其他基於 Ubuntu 的發行版上，打開磁盤應用並查看 Linux 系統所在分區的文件系統。

檢查 Ubuntu 上的文件系統類型

如果你的系統上沒有安裝磁盤應用，那麼可以使用命令列瞭解文件系統類型。

如果你使用的是 Ext4 文件系統並仍然收到來自 Dropbox 的警告，請檢查你是否有可能收到通知的非活動計算機/設備。如果是，將該系統與你的 Dropbox 帳户取消連接。

Dropbox 也不支持加密的 Ext4 嗎？ ​

一些用户還報告説他們在加密 Ext4 文件系統同步時也收到了警告。那麼，這是否意味着 Linux 的 Dropbox 客户端只支持未加密的 Ext4 文件系統？這方面 Dropbox 沒有官方聲明。

你使用的是什麼文件系統？你也收到了警告嗎？如果你在收到警告後仍不確定該怎麼做，你應該前往該方案的官方幫助中心頁面。
