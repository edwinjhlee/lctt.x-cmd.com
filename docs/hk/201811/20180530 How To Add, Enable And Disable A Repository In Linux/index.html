如何在 CentOS 中添加、啓用和禁用一個倉庫 ​

在基於 RPM 的系統上，例如 RHEL、CentOS 等，我們中的許多人使用 yum 包管理器來管理軟件的安裝、刪除、更新、搜索等。

Linux 發行版的大部分軟件都來自發行版官方倉庫。官方倉庫包含大量免費和開源的應用和軟件。它很容易安裝和使用。

由於一些限制和專有問題，基於 RPM 的發行版在其官方倉庫中沒有提供某些包。另外，出於穩定性考慮，它不會提供最新版本的核心包。

為了克服這種情況，我們需要安裝或啓用需要的第三方倉庫。對於基於 RPM 的系統，有許多第三方倉庫可用，但所建議使用的倉庫很少，因為這些不會替換大量的基礎包。

建議閲讀：

  • 在 RHEL/CentOS 系統中使用 YUM 命令管理包
  • 在 Fedora 系統中使用 DNF (YUM 的分支) 命令來管理包
  • 命令列包管理器和用法列表
  • Linux 包管理器的圖形化工具

這可以在基於 RPM 的系統上完成，比如 RHEL, CentOS, OEL, Fedora 等。

  • Fedora 系統使用 dnf config-manager [options] [section …]
  • 其它基於 RPM 的系統使用 yum-config-manager [options] [section …]

如何列出啓用的倉庫 ​

只需運行以下命令即可檢查系統上啓用的倉庫列表。

對於 CentOS/RHEL/OLE 系統：

# yum repolist
Loaded plugins: fastestmirror, security
Loading mirror speeds from cached hostfile
repo id                                                       repo name                                                                 status
base                                                          CentOS-6 - Base                                                           6,706
extras                                                        CentOS-6 - Extras                                                            53
updates                                                       CentOS-6 - Updates                                                        1,255
repolist: 8,014

對於 Fedora 系統：

# dnf repolist

如何在系統中添加一個新倉庫 ​

每個倉庫通常都提供自己的 .repo 文件。要將此類倉庫添加到系統中，使用 root 用户運行以下命令。在我們的例子中將添加 EPEL 倉庫 和 IUS 社區倉庫，見下文。

但是沒有 .repo 文件可用於這些倉庫。因此，我們使用以下方法進行安裝。

對於 EPEL 倉庫，因為它可以從 CentOS 額外倉庫獲得，所以運行以下命令來安裝它。

# yum install epel-release -y

對於 IUS 社區倉庫，運行以下 bash 腳本來安裝。

# curl 'https://setup.ius.io/' -o setup-ius.sh
# sh setup-ius.sh

如果你有 .repo 文件，在 RHEL/CentOS/OEL 中，只需運行以下命令來添加一個倉庫。

# yum-config-manager --add-repo http://www.example.com/example.repo

Loaded plugins: product-id, refresh-packagekit, subscription-manager
adding repo from: http://www.example.com/example.repo
grabbing file http://www.example.com/example.repo to /etc/yum.repos.d/example.repo
example.repo                                             |  413 B     00:00
repo saved to /etc/yum.repos.d/example.repo

對於 Fedora 系統，運行以下命令來添加一個倉庫：

# dnf config-manager --add-repo http://www.example.com/example.repo
adding repo from: http://www.example.com/example.repo

如果在添加這些倉庫之後運行 yum repolist 命令，你就可以看到新添加的倉庫了。Yes，我看到了。

注意：每當運行 yum repolist 命令時，該命令會自動從相應的倉庫獲取更新，並將緩存保存在本地系統中。

如何在系統中啓用一個倉庫 ​

當你在默認情況下添加一個新倉庫時，它將啓用它們的穩定倉庫，這就是為什麼我們在運行 yum repolist 命令時獲取了倉庫信息。在某些情況下，如果你希望啓用它們的測試、開發或存檔倉庫，使用以下命令。另外，我們還可以使用此命令啓用任何禁用的倉庫。

如果你想同時啓用多個倉庫，使用以下格式。這個命令將啓用 epel、epel-testing 和 ius 倉庫：

# yum-config-manager --enable epel epel-testing ius

對於 Fedora 系統，運行下面的命令來啓用倉庫：

# dnf config-manager --set-enabled epel-testing

如何在系統中禁用一個倉庫 ​

對於 Fedora 系統，運行以下命令來啓用一個倉庫：

# dnf config-manager --set-disabled epel-testing

或者，可以通過手動編輯適當的 repo 文件來完成。為此，打開相應的 repo 文件並將值從 enabled=0 改為 enabled=1（啓用倉庫）或從 enabled=1 變為 enabled=0（禁用倉庫）。

即從：

[epel]
name=Extra Packages for Enterprise Linux 6 - $basearch
#baseurl=http://download.fedoraproject.org/pub/epel/6/$basearch
mirrorlist=https://mirrors.fedoraproject.org/metalink?repo=epel-6&arch=$basearch
failovermethod=priority
enabled=0
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-EPEL-6

改為：

[epel]
name=Extra Packages for Enterprise Linux 6 - $basearch
#baseurl=http://download.fedoraproject.org/pub/epel/6/$basearch
mirrorlist=https://mirrors.fedoraproject.org/metalink?repo=epel-6&arch=$basearch
failovermethod=priority
enabled=1
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-EPEL-6
