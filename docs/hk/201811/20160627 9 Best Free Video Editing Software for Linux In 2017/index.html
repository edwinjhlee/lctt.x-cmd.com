Linux 上最好的 9 個免費視頻編輯軟件（2018） ​

概要：這裏介紹 Linux 上幾個最好的視頻編輯器，介紹它們的特性、利與弊，以及如何在你的 Linux 發行版上安裝它們。

我們曾經在一篇短文中討論過 Linux 上最好的照片管理應用，Linux 上最好的代碼編輯器。今天我們將討論 Linux 上最好的視頻編輯軟件。

當談到免費視頻編輯軟件，Windows Movie Maker 和 iMovie 是大部分人經常推薦的。

很不幸，上述兩者在 GNU/Linux 上都不可用。但是不必擔心，我們為你彙集了一個最好的視頻編輯器清單。

Linux 上最好的視頻編輯器 ​

接下來讓我們一起看看這些最好的視頻編輯軟件。如果你覺得文章讀起來太長，這裏有一個快速摘要。

視頻編輯器主要用途類型
Kdenlive通用視頻編輯自由開源
OpenShot通用視頻編輯自由開源
Shotcut通用視頻編輯自由開源
Flowblade通用視頻編輯自由開源
Lightworks專業級視頻編輯免費增值
Blender專業級三維編輯自由開源

DaVinci專業級視頻處理編輯免費增值
VidCutter簡單視頻拆分合並自由開源

1、 Kdenlive ​

Kdenlive 是 KDE 上的一個自由且開源的視頻編輯軟件，支持雙視頻監控、多軌時間線、剪輯列表、自定義佈局、基本效果，以及基本過渡效果。

它支持多種文件格式和多種攝像機、相機，包括低分辨率攝像機（Raw 和 AVI DV 編輯）、mpeg2、mpeg4 和 h264 AVCHD（小型相機和便攜式攝像機）、高分辨率攝像機文件（包括 HDV 和 AVCHD 攝像機）、專業攝像機（包括 XDCAM-HD™ 流、IMX™ (D10) 流、DVCAM (D10)、DVCAM、DVCPRO™、DVCPRO50™ 流以及 DNxHD™ 流）。

如果你正尋找 Linux 上 iMovie 的替代品，Kdenlive 會是你最好的選擇。

Kdenlive 特性：

  • 多軌視頻編輯
  • 多種音視頻格式支持
  • 可配置的界面和快捷方式
  • 使用文本或圖像輕鬆創建切片
  • 豐富的效果和過渡
  • 音頻和視頻示波器可確保鏡頭絕對平衡
  • 代理編輯
  • 自動保存
  • 廣泛的硬件支持
  • 關鍵幀效果

優點：

  • 通用視頻編輯器
  • 對於那些熟悉視頻編輯的人來説並不太複雜

缺點：

  • 如果你想找的是極致簡單的編輯軟件，它可能還是令你有些困惑
  • KDE 應用程序以臃腫而臭名昭著

安裝 Kdenlive ​

Kdenlive 適用於所有主要的 Linux 發行版。你只需在軟件中心搜索即可。Kdenlive 網站的下載部分提供了各種軟件包。

命令列愛好者可以通過在 Debian 和基於 Ubuntu 的 Linux 發行版中運行以下命令從終端安裝它：

sudo apt install kdenlive

2、 OpenShot ​

OpenShot 是 Linux 上的另一個多用途視頻編輯器。OpenShot 可以幫助你創建具有過渡和效果的視頻。你還可以調整聲音大小。當然，它支持大多數格式和編解碼器。

你還可以將視頻導出至 DVD，上傳至 YouTube、Vimeo、Xbox 360 以及許多常見的視頻格式。OpenShot 比 Kdenlive 要簡單一些。因此，如果你需要界面簡單的視頻編輯器，OpenShot 是一個不錯的選擇。

它還有個簡潔的開始使用 Openshot 文檔。

OpenShot 特性：

  • 跨平台，可在 Linux、macOS 和 Windows 上使用
  • 支持多種視頻，音頻和圖像格式
  • 強大的基於曲線的關鍵幀動畫
  • 桌面集成與拖放支持
  • 不受限制的音視頻軌道或圖層
  • 可剪輯調整大小、縮放、修剪、捕捉、旋轉和剪切
  • 視頻轉換可實時預覽
  • 合成，圖像層疊和水印
  • 標題模板，標題創建，子標題
  • 利用圖像序列支持2D動畫
  • 3D 動畫標題和效果
  • 支持保存為 SVG 格式以及矢量標題和可信證
  • 滾動動態圖片
  • 幀精度（逐步瀏覽每一幀視頻）
  • 剪輯的時間映射和速度更改
  • 音頻混合和編輯
  • 數字視頻效果，包括亮度，伽瑪，色調，灰度，色度鍵等

優點：

  • 用於一般視頻編輯需求的通用視頻編輯器
  • 可在 Windows 和 macOS 以及 Linux 上使用

缺點：

  • 軟件用起來可能很簡單，但如果你對視頻編輯非常陌生，那麼肯定需要一個曲折學習的過程
  • 你可能仍然沒有達到專業級電影製作編輯軟件的水準

安裝 OpenShot ​

OpenShot 也可以在所有主流 Linux 發行版的軟件倉庫中使用。你只需在軟件中心搜索即可。你也可以從官方頁面中獲取它。

在 Debian 和基於 Ubuntu 的 Linux 發行版中，我最喜歡運行以下命令來安裝它：

sudo apt install openshot

3、 Shotcut ​

Shotcut 是 Linux 上的另一個編輯器，可以和 Kdenlive 與 OpenShot 歸為同一聯盟。雖然它確實與上面討論的其他兩個軟件有類似的功能，但 Shotcut 更先進的地方是支持 4K 視頻。

支持許多音頻、視頻格式，過渡和效果是 Shotcut 的眾多功能中的一部分。它也支持外部監視器。

這裏有一系列視頻教程讓你輕鬆上手 Shotcut。它也可在 Windows 和 macOS 上使用，因此你也可以在其他操作系統上學習。

Shotcut 特性：

  • 跨平台，可在 Linux、macOS 和 Windows 上使用
  • 支持各種視頻，音頻和圖像格式
  • 原生時間線編輯
  • 混合並匹配項目中的分辨率和幀速率
  • 音頻濾波、混音和效果
  • 視頻轉換和過濾
  • 具有縮略圖和波形的多軌時間軸
  • 無限制撤消和重做播放列表編輯，包括歷史記錄視圖
  • 剪輯調整大小、縮放、修剪、捕捉、旋轉和剪切
  • 使用紋波選項修剪源剪輯播放器或時間軸
  • 在額外系統顯示/監視器上的外部監察
  • 硬件支持

你可以在這裏閲它的更多特性。

優點：

  • 用於常見視頻編輯需求的通用視頻編輯器
  • 支持 4K 視頻
  • 可在 Windows，macOS 以及 Linux 上使用

缺點：

  • 功能太多降低了軟件的易用性

安裝 Shotcut ​

Shotcut 以 Snap 格式提供。你可以在 Ubuntu 軟件中心找到它。對於其他發行版，你可以從此下載頁面獲取可執行文件來安裝。

4、 Flowblade ​

Flowblade 是 Linux 上的一個多軌非線性視頻編輯器。與上面討論的一樣，這也是一個自由開源的軟件。它具有時尚和現代化的用户界面。

用 Python 編寫，它的設計初衷是快速且準確。Flowblade 專注於在 Linux 和其他自由平台上提供最佳體驗。所以它沒有在 Windows 和 OS X 上運行的版本。Linux 用户專享其實感覺也不錯的。

你也可以查看這個不錯的文檔來幫助你使用它的所有功能。

Flowblade 特性：

  • 輕量級應用
  • 為簡單的任務提供簡單的界面，如拆分、合併、覆蓋等
  • 大量的音視頻效果和過濾器
  • 支持代理編輯
  • 支持拖拽
  • 支持多種視頻、音頻和圖像格式
  • 批量渲染
  • 水印
  • 視頻轉換和過濾器
  • 具有縮略圖和波形的多軌時間軸

你可以在 Flowblade 特性裏閲讀關於它的更多信息。

優點：

  • 輕量
  • 適用於通用視頻編輯

缺點：

  • 不支持其他平台

安裝 Flowblade ​

Flowblade 應當在所有主流 Linux 發行版的軟件倉庫中都可以找到。你可以從軟件中心安裝它。也可以在下載頁面查看更多信息。

另外，你可以在 Ubuntu 和基於 Ubuntu 的系統中使用一下命令安裝 Flowblade：

sudo apt install flowblade

5、 Lightworks ​

如果你在尋找一個具有更多特性的視頻編輯器，這就是你想要的。Lightworks 是一個跨平台的專業視頻編輯器，可以在 Linux、Mac OS X 以及 Windows上使用。

它是一款屢獲殊榮的專業非線性編輯（NLE）軟件，支持高達 4K 的分辨率以及 SD 和 HD 格式的視頻。

Lightworks 可以在 Linux 上使用，然而它不開源。

Lightwokrs 有兩個版本：

  • Lightworks 免費版
  • Lightworks 專業版

專業版有更多功能，比如支持更高的分辨率，支持 4K 和藍光視頻等。

這個頁面有廣泛的可用文檔。你也可以參考 Lightworks 視頻嚮導頁的視頻。

Lightworks 特性：

  • 跨平台
  • 簡單直觀的用户界面
  • 簡明的時間線編輯和修剪
  • 實時可用的音頻和視頻FX
  • 可用精彩的免版税音頻和視頻內容
  • 適用於 4K 的 Lo-Res 代理工作流程
  • 支持導出 YouTube/Vimeo，SD/HD視頻，最高可達4K
  • 支持拖拽
  • 各種音頻和視頻效果和濾鏡

優點：

  • 專業，功能豐富的視頻編輯器

缺點：

  • 免費版有使用限制

安裝 Lightworks ​

Lightworks 為 Debian 和基於 Ubuntu 的 Linux 提供了 DEB 安裝包，為基於 Fedora 的 Linux 發行版提供了RPM 安裝包。你可以在下載頁面找到安裝包。

6、 Blender ​

Blender 是一個專業的，工業級的開源跨平台視頻編輯器。它在製作 3D 作品的工具當中較為流行。Blender 已被用於製作多部好萊塢電影，包括蜘蛛俠系列。

雖然最初設計用於製作 3D 模型，但它也具有多種格式視頻的編輯功能。

Blender 特性：

  • 實時預覽、亮度波形、色度矢量顯示和直方圖顯示
  • 音頻混合、同步、擦洗和波形可視化
  • 最多32個軌道，用於添加視頻、圖像、音頻、場景、面具和效果
  • 速度控制、調整圖層、過渡、關鍵幀、過濾器等

你可以在這裏閲讀更多相關特性。

優點：

  • 跨平台
  • 專業級視頻編輯

缺點：

  • 複雜
  • 主要用於製作 3D 動畫，不專門用於常規視頻編輯

安裝 Blender ​

Blender 的最新版本可以從下載頁面下載。

7、 Cinelerra ​

Cinelerra 從 1998 年發佈以來，已被下載超過 500 萬次。它是 2003 年第一個在 64 位系統上提供非線性編輯的視頻編輯器。當時它是 Linux 用户的首選視頻編輯器，但隨後一些開發人員丟棄了此項目，它也隨之失去了光彩。

好消息是它正回到正軌並且良好地再次發展。

如果你想了解關於 Cinelerra 項目是如何開始的，這裏有些有趣的背景故事。

Cinelerra 特性：

  • 非線性編輯
  • 支持 HD 視頻
  • 內置框架渲染器
  • 各種視頻效果
  • 不受限制的圖層數量
  • 拆分窗格編輯

優點：

  • 通用視頻編輯器

缺點：

  • 不適用於新手
  • 沒有可用的安裝包

安裝 Cinelerra ​

你可以從 SourceForge 下載源碼。更多相關信息請看下載頁面。

8、 DaVinci Resolve ​

如果你想要好萊塢級別的視頻編輯器，那就用好萊塢正在使用的專業工具。來自 Blackmagic 公司的 DaVinci Resolve 就是專業人士用於編輯電影和電視節目的專業工具。

DaVinci Resolve 不是常規的視頻編輯器。它是一個成熟的編輯工具，在這一個應用程序中提供編輯，色彩校正和專業音頻後期製作功能。

DaVinci Resolve 不開源。類似於 LightWorks，它也為 Linux 提供一個免費版本。專業版售價是 $300。

DaVinci Resolve 特性：

  • 高性能播放引擎
  • 支持所有類型的編輯類型，如覆蓋、插入、波紋覆蓋、替換、適合填充、末尾追加
  • 高級修剪
  • 音頻疊加
  • Multicam Editing 可實現實時編輯來自多個攝像機的鏡頭
  • 過渡和過濾效果
  • 速度效果
  • 時間軸曲線編輯器
  • VFX 的非線性編輯

優點：

  • 跨平台
  • 專業級視頻編輯器

缺點：

  • 不適用於通用視頻編輯
  • 不開源
  • 免費版本中有些功能無法使用

安裝 DaVinci Resolve ​

你可以從這個頁面下載 DaVinci Resolve。你需要註冊，哪怕僅僅下載免費版。

9、 VidCutter ​

不像這篇文章討論的其他視頻編輯器，VidCutter 非常簡單。除了分割和合並視頻之外，它沒有其他太多功能。但有時你正好需要 VidCutter 提供的這些功能。

VidCutter 特性：

  • 適用於Linux、Windows 和 MacOS 的跨平台應用程序
  • 支持絕大多數常見視頻格式，例如：AVI、MP4、MPEG 1/2、WMV、MP3、MOV、3GP、FLV 等等
  • 界面簡單
  • 修剪和合並視頻，僅此而已

優點：

  • 跨平台
  • 很適合做簡單的視頻分割和合並

缺點：

  • 不適合用於通用視頻編輯
  • 經常崩潰

安裝 VidCutter ​

如果你使用的是基於 Ubuntu 的 Linux 發行版，你可以使用這個官方 PPA（LCTT 譯註：PPA，個人軟件包檔案，PersonalPackageArchives）：

sudo add-apt-repository ppa:ozmartian/apps
sudo apt-get update
sudo apt-get install vidcutter

Arch Linux 用户可以輕鬆的使用 AUR 安裝它。對於其他 Linux 發行版的用户，你可以從這個 Github 頁面上查找安裝文件。

哪個是 Linux 上最好的視頻編輯軟件？ ​

文章裏提到的一些視頻編輯器使用 FFmpeg。你也可以自己使用 FFmpeg。它只是一個命令列工具，所以我沒有在上文的列表中提到，但一句也不提又不公平。

如果你需要一個視頻編輯器來簡單的剪切和拼接視頻，請使用 VidCutter。

如果你需要的不止這些，OpenShot 或者 Kdenlive 是不錯的選擇。他們有規格標準的系統，適用於初學者。

如果你擁有一台高端計算機並且需要高級功能，可以使用 Lightworks 或者 DaVinci Resolve。如果你在尋找更高級的工具用於製作 3D 作品，你肯定會支持選擇 Blender。

這就是在 Ubuntu、Linux Mint、Elementary，以及其它發行版等 Linux 上最好的視頻編輯軟件的全部內容。向我們分享你最喜歡的視頻編輯器。
