10 個最值得關注的樹莓派Blog ​

如果你正在計劃你的下一個樹莓派項目，那麼這些Blog或許有幫助。

網上有很多很棒的樹莓派愛好者網站、教程、代碼倉庫、YouTube 頻道和其他資源。以下是我最喜歡的十大樹莓派Blog，排名不分先後。

1、Raspberry Pi Spy ​

樹莓派粉絲 Matt Hawkins 從很早開始就在他的網站 Raspberry Pi Spy 上撰寫了大量全面且信息豐富的教程。我從這個網站上直接學到了很多東西，而且 Matt 似乎也總是涵蓋到眾多主題的第一個人。在我學習使用樹莓派的前三年裏，多次在這個網站得到幫助。

值得慶幸的是，這個不斷採用新技術的網站仍然很強大。我希望看到它繼續存在下去，讓新社區成員在需要時得到幫助。

2、Adafruit ​

Adafruit 是硬件黑客中知名品牌之一。該公司製作和銷售漂亮的硬件，並提供由員工、社區成員，甚至 Lady Ada 女士自己編寫的優秀教程。

除了網上商店，Adafruit 還經營一個Blog，這個Blog充滿了來自世界各地的精彩內容。在Blog上可以查看樹莓派的類別，特別是在工作日的最後一天，會在 Adafruit Towers 舉辦名為 Friday is Pi Day 的活動。

3、Recantha 的 Raspberry Pi Pod ​

Mike Horne（Recantha）是英國一位重要的樹莓派社區成員，負責 CamJam 和 Potton Pi＆Pint（劍橋的兩個樹莓派社團）以及 Pi Wars （一年一度的樹莓派機器人競賽）。他為其他人建立樹莓派社團提供建議，並且總是有時間幫助初學者。Horne 和他的共同組織者 Tim Richardson 一起開發了 CamJam Edu Kit （一系列小巧且價格合理的套件，適合初學者使用 Python 學習物理計算）。

除此之外，他還運營着 Pi Pod，這是一個包含了世界各地樹莓派相關內容的Blog。它可能是這個列表中更新最頻繁的樹莓派Blog，所以這是一個把握樹莓派社區動向的極好方式。

4. Raspberry Pi 官方Blog ​

必須提一下樹莓派基金會的官方Blog，這個Blog涵蓋了基金會的硬件、軟件、教育、社區、慈善和青年編碼俱樂部的一系列內容。Blog上的大型主題是家庭數字化、教育授權，以及硬件版本和軟件更新的官方新聞。

該Blog自 2011 年 運行至今，並提供了自那時以來所有 1800 多個帖子的 存檔 。你也可以在 Twitter 上關注@raspberrypi_otd，這是我用 Python 創建的機器人（教程在這裏：Opensource.com）。Twitter 機器人推送來自Blog存檔的過去幾年同一天的樹莓派帖子。

5、RasPi.tv ​

另一位開創性的樹莓派社區成員是 Alex Eames，通過他的Blog和 YouTube 頻道 RasPi.tv，他很早就加入了樹莓派社區。他的網站為很多創客項目提供高質量、精心製作的視頻教程和書面指南。

Alex 的網站 RasP.iO 製作了一系列樹莓派附加板和配件，包括方便的 GPIO 端口引腳、電路板測量尺等等。他的Blog也拓展到了 Arduino、WEMO 以及其他小網站。

6、pyimagesearch ​

雖然不是嚴格的樹莓派Blog（名稱中的“py”是“Python”，而不是“樹莓派”），但該網站的 樹莓派欄目 有着大量內容。 Adrian Rosebrock 獲得了計算機視覺和機器學習領域的博士學位，他的Blog旨在分享他在學習和製作自己的計算機視覺項目時所學到的機器學習技巧。

如果你想使用樹莓派的相機模組學習面部或物體識別，來這個網站就對了。Adrian 在圖像識別領域的深度學習和人工智能知識和實際應用是首屈一指的，而且他編寫了自己的項目，這樣任何人都可以進行嘗試。

7、Raspberry Pi Roundup ​

這個Blog由英國官方樹莓派經銷商之一 The Pi Hut 進行維護，會有每週的樹莓派新聞。這是另一個很好的資源，可以緊跟樹莓派社區的最新資訊，而且之前的文章也值得回顧。

8、Dave Akerman ​

Dave Akerman 是研究高空熱氣球的一流專家，他分享使用樹莓派以最低的成本進行熱氣球發射方面的知識和經驗。他會在一張由熱氣球拍攝的平流層照片下面對本次發射進行評論，也會對個人發射樹莓派熱氣球給出自己的建議。

查看 Dave 的Blog，瞭解精彩的臨近空間攝影作品。

9、Pimoroni ​

Pimoroni 是一家世界知名的樹莓派經銷商，其總部位於英國謝菲爾德。這家經銷商製作了著名的 樹莓派彩虹保護殼，並推出了許多極好的定製附加板和配件。

Pimoroni 的Blog佈局與其硬件設計和品牌推廣一樣精美，博文內容非常適合創客和業餘愛好者在家進行創作，並且可以在有趣的 YouTube 頻道 Bilge Tank 上找到。

10、Stuff About Code ​

Martin O'Hanlon 以樹莓派社區成員的身份轉為了樹莓派基金會的員工，他起初出於樂趣在樹莓派上開發“我的世界”作弊器，最近作為內容編輯加入了樹莓派基金會。幸運的是，馬丁的新工作並沒有阻止他更新Blog並與世界分享有益的趣聞。

除了“我的世界”的很多內容，你還可以在 Python 庫、Blue Dot 和 guizero 上找到 Martin O'Hanlon 的貢獻，以及一些總結性的樹莓派技巧。

via: https://opensource.com/article/18/8/top-10-raspberry-pi-blogs-follow
