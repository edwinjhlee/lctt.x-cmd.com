使用極簡瀏覽器 Min 瀏覽網頁 ​

並非所有 web 瀏覽器都要做到無所不能，Min 就是一個極簡主義風格的瀏覽器。

現在還有開發新的 Web 瀏覽器的需要嗎？即使現在瀏覽器領域已經成為了寡頭市場，但仍然不斷湧現出各種前所未有的瀏覽器產品。

Min 就是其中一個。顧名思義，Min 是一個小的瀏覽器，也是一個極簡主義的瀏覽器。但它麻雀雖小五臟俱全，而且還是一個開源的瀏覽器，它的 Apache 2.0 許可證引起了我的注意。

讓我們來看看 Min 有什麼值得關注的方面。

開始 ​

Min 基於 Electron 框架開發，值得一提的是，Atom 文本編輯器也是基於這個框架開發的。它提供 Linux、MacOS 和 Windows 的安裝程序，當然也可以從 GitHub 獲取它的源代碼自行編譯安裝。

我使用的 Linux 發行版是 Manjaro，但沒有完全匹配這個發行版的安裝程序。還好，我通過 Manjaro 的包管理器也能安裝 Min。

安裝完成後，在終端就可以直接啓動 Min。

Min 號稱是更智能、更快速的瀏覽器。經過嘗試以後，我覺得它比我在其它電腦上使用過的 Firefox 和 Chrome 瀏覽器啓動得更快。

而使用 Min 瀏覽網頁的過程則和 Firefox 或 Chrome 一樣，只要再地址欄輸入 URL，回車，就好了。

Min 的功能 ​

儘管 Min 不可能帶有 Firefox 或 Chrome 等瀏覽器得所有功能，但它也有可取之處。

Min 和其它瀏覽器一樣，支持頁面選項卡。它還有一個稱為 Tasks 的功能，可以對打開的選項卡進行分組。

DuckDuckGo 是我最喜歡的搜索引擎，而 Min 的默認搜索引擎恰好就是它，這正合我意。當然，如果你喜歡另一個搜索引擎，也可以在 Min 的偏好設置中配置你喜歡的搜索引擎作為默認搜索引擎。

Min 沒有使用類似 AdBlock 這樣的插件來過濾你不想看到的內容，而是使用了一個名為 EasyList 的內置的廣告攔截器，你可以使用它來屏蔽腳本和圖片。另外 Min 還帶有一個內置的防跟蹤軟件。

類似 Firefox，Min 有一個名為叫做 Reading List 的閲讀模式。只需點擊地址欄中的對應圖標，就可以去除頁面中的大部分無關內容，讓你專注於正在閲讀的內容。網頁在閲讀列表中可以保留 30 天。

Min 還有一個專注模式，可以隱藏其它選項卡並阻止你打開新的選項卡。在專注模式下，如果一個 web 頁面中進行工作，需要多點擊好幾次才能打開一個新頁面。

Min 也有很多快捷鍵讓你快速使用某個功能。你可以在 GitHub 上找到這些這些快捷鍵的參考文檔，也可以在 Min 的偏好設置中進行更改。

我發現 Min 可以在 YouTube、Vimeo、Dailymotion 等視頻網站上播放視頻，還可以在音樂網站 7Digital 上播放音樂。但由於我沒有賬號，所以沒法測試是否能在 Spotify 或 Last.fm 等這些網站上播放音樂。

Min 的弱點 ​

Min 確實也有自己的缺點，例如它無法將網站添加為書籤。替代方案要麼是查看 Min 的搜索歷史來找回你需要的鏈接，要麼是使用一個第三方的書籤服務。

最大的缺點是 Min 不支持插件。這對我來説不是一件壞事，因為瀏覽器啓動速度和運行速度快的主要原因就在於此。當然也有一些人非常喜歡使用瀏覽器插件，Min 就不是他們的選擇。

總結 ​

Min 算是一箇中規中矩的瀏覽器，它可以憑藉輕量、快速的優點吸引很多極簡主義的用户。但是對於追求多功能的用户來説，Min 就顯得相當捉襟見肘了。

所以，如果你想擺脱當今多功能瀏覽器的束縛，我覺得可以試用一下 Min。
