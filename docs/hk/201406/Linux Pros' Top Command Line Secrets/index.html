Linux大神們的頂級命令列秘訣 ​

好吧，LinuxBlog圈這裏這周相對比較平靜，給網民們一個拖了很久的機會集體喘口氣吧，去享受一下龍舌蘭、燕尾服、雞尾酒帶來的歡快吧，然後評估一下過去幾周來發生的和自由開放軟件相關的事件吧。

“你是否曾經在聽一張專輯的時候想過‘夥計，這聽起來不錯，但是我希望它能經常從用户空間過渡到內核空間去！’”粉絲們在Facebook上寫道，“我們會全力支持你的。我們的專輯現在完全可以作為一個可加載的Linux內核模組來播放。”

Linux女孩曾經認為她自己已經完全進入Linux世界了，但是她現在卻意識到她的想法是錯誤的。謝謝你們，粉絲們，是你們讓生活一直這麼有趣！

‘命令列秘訣’ ​

説到有趣，沒什麼比圍坐在吧枱前談論行業內的事情來度過平靜的一週更帶勁了，而上週搞了一次。LinuxBlog圈內的生活很愜意。

座談會內容是《Linux之聲》——那本炫目出世的新雜誌，讀者也許記得它是去年年底發佈的——而談話的主題恰恰就是命令列秘訣

Linux女孩太激動了。

‘它打算渲染大多數網頁’ ​

“有很多使用命令列的真正的好理由，”《Linux之聲》的策劃者寫道，“它是讓你和計算機進行交互的強大而簡明的方法“

“然而，我想花點時間來看看它裏頭一些更為晦澀的用法（有人會説毫無意義，不值得去做了）。“他們補充説。

雜誌首先列出的是elinks網頁瀏覽器：“它可能看起來沒有它的競爭對手那樣光彩照人，但它的目標是能夠渲染大多數網頁。”他們解釋道，“它也有着極客時尚，當你需要快速檢查你是否能從只能通過SSH訪問的計算機上去訪問網頁時，它就會派上用場了。“

之後談到的包含了從維基百科上查閲一些定義等其它一些實用的小建議。

'對維護很重要' ​

“命令列的小技巧很有趣，真的很有趣。”比如，Google+博主亞歷桑德魯：埃伯索爾滿懷熱情地説，“但是他們忘了cowsay，它可以用來在黑漆漆的終端裏博你一笑。“

”命令列對於維護很重要。“他補充説，”大家可以使用bash腳本來自動化，只需按幾個快捷鍵（或者只要一個就行）來完成複雜的任務。”

其它命令列秘訣，埃伯索爾會把它們放進原來的列表的包括sl（蒸汽機車），以及這些這些奇怪的點子：

* % cat "food in cans"
cat: can't open food in cans
* % nice man woman
No manual entry for woman.
* % [Where is Jimmy Hoffa?
Missing ].
* % make love
Make: Don't know how to make love. Stop.
* % man: why did you get a divorce?
man:: Too many arguments.

'最珍貴的精華' ​

“命令列秘訣？根本沒這玩意。”博主羅伯特：伯格森告訴Linux女孩道，”失望了吧，新手？那就猛敲‘help’吧。還想要點提示？隨便‘man’個什麼吧。想更多來點不同？敲‘ls /bin /sbin /usr/bin /usr/sbin | less’，隨便撿幾個寶貝命令出來，整晚地‘man’去吧。我已經幹那活超過十年了，到現在還玩得不亦樂乎。”

伯格森記不得多久以前他發現了‘ssh’，但是“它是自由/開源軟件世界中最璀璨的寶石了。“他説。

”ssh的強大力量在於，你可以在一台計算機上輸入命令獲得快樂，你更可以在100台計算機上幹同樣的事情來獲得100倍的快樂。“他補充道，”當然，要輸入100次命令可不是鬧着玩的。所以，學習一下通過ssh安全地無密碼登陸，可以讓ssh的遠程登陸透明化。“

'帶着尊重來用吧' ​

當然，”就像幹任何快樂的事一樣，有人會沉迷於搞破壞。“伯格森警告道，”作為root用户，你可以輸入命令來刪除所有的東西，或者把這一切搞亂。“

”這是核彈按鈕，就像全球領袖處理世界事務一樣，在按下那個鍵之前一定要三思而後行，評估幹這事所產生的結果，帶着尊重和高尚的動機來使用它。“他補充道。

”我曾經刪除了一個文件系統，因為我的大拇指在輸入一個命令時不小心蹭到了空格鍵。“伯格森總結道，”坦白地説，這種蠢事我只幹過一次。“

'很強大' ​

Google+博主貢薩洛：貝拉斯科C不那麼熱情。

“即使GUI工具更易用，在*nix領域，命令列仍然很強大。“他告訴Linux女孩，”甚至一些高級MacOS用户也用它們。”

對於貢薩洛：貝拉斯科C他自己而言，“我想要掌握的唯一一些命令是進程控制和殺死命令，想要使用ctrl+alt+退格鍵，因為我可以用來處理給我造成麻煩的那個進程，我還想要掌握tar.gz文件的管理——那玩意到現在還讓我頭痛。“他説。

'你正在做錯事' ​

最後一點，但並非不重要，SoylentNews博主hairyfeet有一個完全不同的觀點。

“我只想談一件事情來充實一下命令列界面這個報道：如果你不幹IT，而且做着一些重複的事情，而這些事情只是很簡單、很原始地去記錄一些有用的事情，但你還在用命令列，那麼‘你在走一條不歸路’“hairyfeet告訴Linux女孩，”命令列界面沒什麼神奇——它只是1970年代以來的一個圖形化界面！“

今天，有很多“有用的圖形化界面，這要多虧了CPU速度的提升和內存的增加，而不是一美元店裏的廉價手錶——我們甚至有IDE和腳本語言，大大超過70年代那些古董，可以在廣域網或者局域網上工作，並與操作系統最底層交互，一切都在變得更易用，這多虧了智能感應和自動完成這樣的技術。“他解釋説，”所以上天作證，如果你不是那3%的系統管理員，工作在以字節計數的世界裏，你會把那一堆垃圾從陳年舊帳中翻出來？

這是Hairyfeet的最佳命令列建議？“不要——被21世紀那些不切實際的想法所左右，學學怎樣真正來使用語言和工具吧。“他總結道，”讓命令列成為泡影，把軟盤都扔進歷史的垃圾桶吧。“

本文作者Katherine Noyes總是盡忠職守扮演好她的Linux女孩，那件斗篷她從2007穿到現在了。作為一個白天舉止温和的女記者，她晚上像逛夜店一樣，為了搜尋最新的小道消息，在LinuxBlog圈上灌水。你也能在 Twitter和Google+上找到她。
