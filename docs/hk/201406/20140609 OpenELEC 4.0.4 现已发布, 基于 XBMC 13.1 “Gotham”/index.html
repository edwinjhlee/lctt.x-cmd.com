嵌入式多媒體中心 OpenELEC 4.0.4 ​

![] (http://i1-news.softpedia-static.com/images/news2/OpenELEC-4-0-4-Is-Out-and-Based-on-XBMC-13-1-quot-Gotham-quot-445802-2.jpg)

OpenELEC 4.0.4已經發布，它是一個專門設計運行XBMC的嵌入式系統，一個開放源代碼的娛樂媒體中心。它構建 XBMC 13.1 基礎之上。

OpenELEC 開發商非常密切地跟着 XBMC 的產品開發週期，目前已經發布了他們的最新的 4.0.4 的版本。它基於 XBMC 13.1 "Gotham"，並且開發者們做了一些自己的改動。

“此版本包括一些bug修正、安全修復和來自於 OpenELEC 4.0.3 的改進。除了通常的錯誤修正和軟件包更新，我們已經使用最新的補丁文件升級 XBMC 至最新的 XBMC 13.1 (final)。這個版本包含了在 XBMC 13.0 發佈之後的很多已知問題的修復（其中有些我們已包括 OpenELEC 4.0.0中）。”

“我們在popcornmix的幫助下發現並修復了一些和樹莓派相關內核問題、 固件和 XBMC 代碼中的問題，非常感謝他的幫助 ！OpenELEC 4.0.4 現在是一個穩定版本，包含了OpenELEC 4.0系列的bug修正和安全漏洞修復 。”開發商的官方網站上如是寫道。

OpenELEC 4.0.4 界面更加美觀而且更新和修復了許多問題。例如，e2fsprogs 已更新到版本 1.42.10、 bluez 已更新到版本 5.19、 fontconfig 版本更新到 2.11.1，也默認集成了 systemd 213 和修復了一些安全問題的gnutls 3.2.12，而且使用了一個新的 Linux 內核3.14.5。

此外，DVB T2 已經添加了對 GeniaTech T220 / August T210 設備的支持，由於其驅動程序尚不完善而允許禁用WOL、也添加了尚不完善的"e1000e"驅動，樹莓派的支持補丁已更新。

如果你已經有一箇舊版的 OpenELEC，你可能需要考慮升級的系統而不是從頭開始安裝它。如果想順利地完成安裝，至少應該是 3.2 版本。

如果您嘗試從舊版本操作系統的更新，您可能發現一些插件和插件都不再工作。所以最明智的辦法就是，在嘗試升級之前備份你的系統。

以 XBMC 13.1 "Gotham" 版本為基，配有 Android 硬件解碼、 許多樹莓派和 Android 速度方面的改善，立體 3D 渲染，更好的觸摸屏支持，改進了 UPnP 功能，很多的音頻引擎的改進，更好地字幕搜索、 對開發者增加的如 Python 和 JSON RPC API等 ，FFmpeg 1.2，還有更多。

查閲官方 [公告] 1 的更改和改進的完整列表。
