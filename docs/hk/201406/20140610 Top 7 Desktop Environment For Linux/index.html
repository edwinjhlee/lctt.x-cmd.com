Linux 平台七大桌面環境通覽 ​

通常的 Linux 發行版都使用 KDE 或者 GNOME 作為默認的桌面環境。它們都給用户提供了一個原始的並且有吸引力的桌面，並且內置了各式各樣的多媒體軟件、系統程序、遊戲、實用程序、網頁開發工具、編程工具等等。這兩個桌面致力於提供給用户一個擁有類似於 Windows 操作系統體驗的尖端計算環境，而不是如何更少的佔用系統資源。

如果你正在使用 Ubuntu (或者其他Linux發行版) 並且厭倦了始終使用 Unity 桌面，那麼你應該看看這些可以替代 Unity 的選擇。我收集了 7 種桌面環境。它們都很棒。在你讀完這篇文章之後，請試着使用它們吧。

Mate ​

MATE 是 GNOME2 的一個分支。它提供了一個自然且吸引人的桌面環境。它是 Linux 和其它類 Unix 工作環境中的傳統工作框架的代表。MATE 在保留傳統的桌面體驗的同時正在不斷進步使用新的技術。

在 Ubuntu 14.04 中，可以直接從 Ubuntu 軟件中心獲取 MATE 桌面。

KDE ​

KDE 是另一個類似於 GNOME 一樣的重量級桌面環境。它在本文章所提及的7種桌面環境中被認為是最華麗最重量級的一個。它同樣是一個類似於 Windows 的桌面，在這一點上沒有什麼特殊的變化。不過 KDE 非常有特點，但是隨之而來的是可以通過大量的設置來提升你的桌面體驗。同樣的，有很多關於 KDE 的話題，所以你可以很舒服的使用 KDE，並讓它以你希望的方式工作。

Cinnamon ​

Cinnamon 是一個基於 Gtk+ 的環境。它最初作為 GNOME Shell 的一個用户界面分支，由 Linux Mint 為其創建的。 Cinnamon 的核心設計目標是讓桌面終端和觸屏設備都能完美操作。無論是使用鼠標，還是使用觸摸屏都可以獲得同樣便捷的操作。不像 KDE Plasma 工作空間，只有一種圖形用户體驗。當前版本—— Cinnamon 2.0 於2013年10月10日發佈。

Unity ​

Unity 是 GNOME 桌面環境的一個界面，由 Canonical 公司創建，用於 Ubuntu 系統中。Unity 最初現身於 Ubuntu 10.10 的上網本版本中。它起初打算充分利用上網本的屏幕空間，例如一個豎直的應用啓動器和一個節省空間的多功能頂部菜單欄。Unity 不像 GNOME、KDE、 Xfce 或者 LXDE 是許多軟件的合集，它是為了可用性而開發的。

GNOME Shell ​

GNOME 提供了桌面核心接口例如交換窗口，啓動應用程序以及顯示提示。它利用先進的圖形硬件來實現吸引人的、創新的界面思想，提供了愉悦簡單的用户體驗。GNOME Shell 定義了 GNOME 3 的客户體驗。

作為 GNOME 的一個重要組成部分， GNOME Shell 的穩定版本首次發佈於2011年3月3日。

Xfce ​

Xfce 是一個輕量級的桌面環境，圍繞 GTK 框架實現。它看起來很像 Gnome 2 和 MATE，然而 Xfce 是它們的輕量級替代品。相較於 KDE 和 GNOME 3 而言，Xfce 非常輕量級，所以它對於運行輕量級的工具或者那些希望實現最大執行效率的框架使用者來説是理想的環境。它還不是可以獲得的最輕量級的選擇 - 請繼續往下看 - 然而，Xfce 的確完成了執行效率和功能的平衡。

LXDE ​

LXDE 顯然是桌面環境中最輕量級的選擇，至少在傳統的桌面標準中是這樣。這個基於 GTK 的桌面環境使用了很多輕量級的選擇替代了默認的應用（例如 Abiword, Gnumeric, 而不是 LibreOffice）。它沒有提供炫目的視覺震撼 ，總體感覺也不是特別的棒，沒有高級的設置。但是，LXDE 仍然提供了漂亮的桌面和完整的功能。當你需要快速簡潔時，它就是你的選擇。
