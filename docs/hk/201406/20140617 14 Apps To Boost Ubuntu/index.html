14個可以提升Linux桌面體驗的應用程序 ​

轉戰到Ubuntu，或者是別的流行的Linux發行版，不僅僅是操作系統的操作方式的改變，更多的是你還需要一些能支持你完成工作的好的應用。

在這篇文章中，我將分享一些我精選出來不可或缺的應用程序，並談談在我的日常工作中如何有效地使用它們。

日常使用的應用程序 ​

一般當説到Linux桌面上的應用，我總是將這些應用劃分為兩大類，頻繁使用的和一些別的應用。下邊我為大家介紹的是一些自己日常使用的應用。

1） Firefox — 有時我也會使用用其他的瀏覽器，但最近火狐瀏覽器已經成為我可以長期信賴的朋友。可靠的、 安全的、 跨平台的，火狐瀏覽器完全滿足了我的日常衝浪需求。

除了訪問書籤和網頁，我還依靠火狐瀏覽器來處理我的各種部署在局域網服務器上的工作，如 Plex, Zoneminder, 路由器/WEB應用防火牆, 及我的文件服務器。所有這些均可以使用火狐瀏覽器進行訪問。

2） Parcelite— 如果沒有一個像樣的剪貼板管理器我簡直沒法開始工作，至少對我來説，你無法找到在GNOME 下的Parcelite有什麼不足。使用簡單，易於訪問而且它提供了很多的有用的選項。Parcelite選項應有盡有，包括了從熱鍵設置到空格處理方式。儘管已經有很多的剪貼板管理器，但它們卻很難擊敗 Parcelite。

3） Bittorrent Sync — 我已經使用過了各種開源替代方案進行文件同步，但是他們在正式發佈之前還需要進行進一步開發。應該説Bittorrent Synchas從來沒有讓我失望過。它運行和安裝都很簡單和方便，這多虧了新的GUI的實現，而且 Bittorrent Sync 允許我快速地從一台機器到另外一台機器傳輸巨大的視頻文件，而無需浪費時間去將大量的文件同步到“雲端”。

我還發現它是與別人分享大型文件的最佳方法，在分享的同時能一直保持 IP 地址和目錄的隱蔽。儘管有許多的替代品，我仍然堅定地成為了Bittorrent Sync的骨灰粉絲。

4） System Monitor — 因為TOP實在是滾動地太快了，所以我個人更喜歡一個具有選項卡式的 GUI，因為它能夠讓我的眼睛更輕鬆些。使用 GNOME 的系統監視器，我可以很快地發現一個失控的進程，並且輕鬆地kill掉它而不需吹灰之力。與TOP這樣的終端程序不同的是，我可以實時的以圖形化的方式去查看我的 CPU、 內存和磁盤的使用情況。作為一個擁有正常視覺的人，很難找到一個比用條形圖來展示我還擁有多少的空間的更好方式。當然這也同樣適用於其它的實時資源使用情況的監視。

5） PulseAudioControl — 每一天，我總是需要在多個聲音設備之間來回穿梭。有時我需要將其中一個設為默認設備，然後卻可能會從火狐瀏覽器音頻完全切換到到另一個設備。因為我想控制我的儘可能多的音頻，然後我就發現 PulseAudioControl是一個無價的工具。

一些別的軟件 ​

在本節中，我將分享我使用，但可能並不一定是每天都使用的應用程序。許多這些應用程序都是開放源代碼的，有一些不是，但是它們對我個人都非常具有價值。

6） Skype — 無論是撥入Jupiter Broadcasting 收聽每週共同主持的播客，或者只是簡單聯繫一個業務，Skype 見證了互聯網視頻會議的發展史。測試完成無數的替代品後，我總是會發現自己還是終回到了Skype。即使有真的很棒的開源選擇像Ekiga 和 Jitsi，而在最後Skype總是與大家同在 —— 切換到Skype是一件很幸運的事。

7）Kdenlive — 我使用兩個不同的視頻編輯器，當我要處理一個需要大量編輯的視頻剪輯項目的時候，Kdenlive是我用於圖片合成和編輯大型的複雜的視頻的工具。我已經成功地在 Kdenlive 裏邊做過6個素材軌道的編輯，但同樣的負載量早已經讓別的視頻剪輯軟件崩潰了。

8）OpenShot — 大多數情況下，我會將OpenShot作為視頻剪輯任務的首選神兵利器。快速的編輯和兩個素材軌道工作區讓你可以流暢而操作簡單。我還發現它提供了很棒的無與倫比的特效。調製標題效果和超讚的的視頻轉場效果使OpenShot在我自己的視頻項目上成為一款超棒的視頻製作軟件。

9）SpiderOak — 在使用了無數雲備份服務這麼多年後， SpiderOak 已經成為了我的至愛。易於安裝和使用，我超喜歡它所提供的增量選項而且使用起來是如此的簡單。只需一次設置，不再操心，之後SpiderOak將會挑起你的文件搬運大任。

10） Dropbox — 許多年來，我已經與Dropbox 愛恨交織。儘管它的跨平台特性這意味着我可以從任何位置訪問文件，我慢慢地發現我自己越來越少依賴這個基於雲計算的備份解決方案。儘管如此，它允許我從任何 web 瀏覽器中訪問文件，即使是從我不經常使用的計算機，這使得拋棄 Dropbox 更是難上加難。

11） Writer — 自從我第一次在Windows的OpenOffice裏面使用過它之後，我一直都在使用Writer。今天，我使用LibreOffice 所帶的Writer來滿足我的需求，它可以做一切一個文字處理器可以做的事情。現在，公正地説，一些專有的辦公套件可能會提供附加功能在Writer中是沒有的，但是99%的人需要的功能在Writer這裏都有。就我個人而言，我會永遠是一個LibreOffice Writer粉。

12）SimpleScreenRecorder — 多年來，我發現自己使用 SimpleScreenRecorder遠超過其他同類軟件，它能很好支持多監視器模式，再加上它甚至可以捕獲基於 OpenGL 的應用程序的視頻。易於使用和可靠的 SimpleScreenRecorder 讓我的工作更加得心應手。我把它推薦給那些只是偶爾需要，懶得使用其它屏幕捕捉軟件的同學們。

13）SimpleScan — 當我需要掃描文檔的時候，我一點都不想將大把大把的時間花費在配置的臃腫的程序上。 Simple Scan 可以在這方面做得很好。智能的SANE掃描資料庫，Simple Scan將與市面上的任何掃描儀或多功能一體打印機/掃描儀很好的進行協作。此外還有一點好處就是它會設置成的最佳分辨率，當然你還可以很方便手動調整任何你需要的設置。

14）Baobab（磁盤使用分析器） — 我不斷聽到關於如何硬盤價格已回落。這或許沒錯，但現實卻是我卻囊中羞澀。這意味着我需要充分利用我能利用的所有硬盤空間，為了實現這個目的，我使用 Baobab 來觀察我在我的硬盤上的可用空間，而且還可以直觀地看到到底是哪一個目錄正在蠶食我寶貴的硬盤空間。

真正的具有生產力的軟件 ​

談到我所依賴的這些軟件，我們真正關心的是他們能為我們完成什麼樣的任務，而不是它們所擁有的光輝頭銜和自身的許可證。linux不需要軟件的傳奇時代早已過去。多數的計算機上的工作，除了有限的幾個例外，大都可以在linux桌面上輕鬆地如我所説的那樣完成。

很明顯有一些對於你來説是必不可少的軟件，但是也許不是我必須用的。你所倚重的軟件是什麼？您可在下方進行評論並與我們的讀者進行分享那些優秀的軟件。
