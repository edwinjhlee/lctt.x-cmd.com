Linux：使用bash刪除目錄中的特定文件 ​

我是一名Linux新用户。現在我需要清理一個下載目錄中的文件，其實我就是想從～/Download/文件夾刪去除了以下格式的文件外所以其它文件：

  • *.iso - 所有的iso格式的文件。
  • *.zip - 所有zip格式的文件。

我如何在一個基於Linux，OS X 或者 Unix-like 系統上的bash shell中刪除特定的文件呢？

Bash shell 支持豐富的文件模式匹配符例如：

    • － 匹配所有的文件。
  • ？ － 匹配文件名中的單個字母。
  • [...] － 匹配封閉括號中的任何一個字母。

策略 #1: 見識一下擴展的模式匹配符 ​

這裏你需要用系統內置的shopt命令來開啓shell中的extglob選項，然後你就可以使用擴展的模式符了，這些模式匹配符如下：

  1. ?(模式列表) － 匹配零次或一次給定的模式。
  2. *(模式列表) － 匹配零次或多次給定的模式。
  3. +(模式列表) － 至少匹配一次給定的模式。
  4. @(模式列表) － 匹配一次給定的模式。
  5. !(模式列表) － 不匹配給定模式。

一個模式列表就是一個或多個用 | 分開的模式（文件名）。

首先要打開extgolb選項：

shopt -s extglob

在Bash中刪掉除.zip和.iso文件以外的所有文件 ​

rm 命令的語法格式為：

## 僅保留 file1 文件 ##
rm  !(file1)
 
## 僅保留 file1 和 file2 文件## 
rm  !(file1|file2)
 
## 僅保留 zip 文件 ##
rm  !(*.zip)
 
## 僅保留 zip 和 iso 文件 ##
rm  !(*.zip|*.iso)

## 你也可以使用完整的目錄 ##
rm /Users/vivek/!(*.zip|*.iso|*.mp3)
 
## 也可以傳遞參數 ##
rm [選項]  !(*.zip|*.iso)
rm -v  !(*.zip|*.iso)
rm -f  !(*.zip|*.iso)
rm -v -i  !(*.php)

最後，關閉 extglob 選項方法如下：

shopt -u extglob

策略 #2: 使用bash的 GLOBIGNORE 變量刪除指定文件以外的所有文件 ​

摘自 bash(1) 手冊頁:

這是一個用冒號分開的模式列表，通過路徑展開方式定義了要忽略的文件集合。如果一個匹配到路徑展開模式的文件也匹配GLOBIGNORE中的模式，那麼它會從匹配列表中移除。

要刪除所有文件只保留 zip 和 iso 文件，應如下設置 GLOBIGNORE：

## 只在 BASH 中可行 ##
cd ~/Downloads/
GLOBIGNORE=*.zip:*.iso
rm -v *
unset GLOBIGNORE

策略 #3: 用 find 命令刪除所有其它文件僅保留 zip 和 iso 文件 ​

如果你正在使用 tcsh/csh/sh/ksh 或者其它shell，你可以在Unix－like系統上試着用下面find命令的語法格式來刪除文件：

find /dir/ -type f -not -name '匹配模式' -delete

或者

## 對於怪異的文件名可以使用 xargs ##
find /dir/ -type f -not -name '匹配模式' -print0 | xargs -0 -I {} rm {}
find /dir/ -type f -not -name '匹配模式' -print0 | xargs -0 -I {} rm [選項] {}

想要刪除 ～/source 目錄下除 php 以外的文件，鍵入：

find ~/sources/ -type f -not -name '*.php' -delete

或者

find ~/sources/ -type f -not -name '*.php' -print0 | xargs -0 -I {} rm -v {}

只保留 *.zip 和 *.iso 文件的語法如下：

find . -type f -not \( -name '*zip' -or -name '*iso' \) -delete

更多信息參見bash command man page和find command man page。
