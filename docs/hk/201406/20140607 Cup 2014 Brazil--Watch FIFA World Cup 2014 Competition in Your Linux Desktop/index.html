在linux桌面上觀看2014年巴西世界盃比賽！ ​

足球是世界上受眾最廣和觀眾最多的運動，現代足球起源於英國。足球運動員平均每場比賽要跑6個多英里。上屆南非世界盃有近10億的電視觀眾，而今年的的觀賽數量預計還要增加。

2014年第20界世界盃在巴西舉行，時間安排為從6月12號開始持續到7月13號，共有32個國家參加這項賽事。

愛足球的小夥子們，我們將要介紹一款可以提供最新的賽況以及你喜歡的球隊的進球數信息的應用程序，它叫做“icup 2014 Brazil”。下面讓我們介紹它的特點，用法和安裝等。

iCup 2014 Brazil

什麼是“icup 2014 Brazil” ​

“icup 2014 Brazil”簡單的説是一個應用程序，在linux桌面為你提供2014年世界盃的最新比賽賽況。

“icup 2014 Brazil”的特點### ​

  • 自適應的用户界面，比如自動縮放
  • 迅速查看戰績
  • 支持Facebook、twitter和Google+社交分享功能
  • 支持Retina顯示輸出
  • 實時跟蹤比賽結果
  • 包括32個國家的國歌小工具配合露天廣場效果很不錯
  • 內置日曆和時區工具，實時的顯示當天數據，圖像化展示最新的戰況和得分
  • 支持代理

平台和框架支持 ​

這款軟件可以運行在Mac、windows和linux上，特別提醒，在Linux上，它是為x86的CPU設計的，雖然它也可以在x64的平台上安裝，不過我們需要做一下設置。

在不同平台的技術規範 ​

  • 實時結果，日曆，數據分組，第二階段整合，社交網絡連接和多語言支持，這些支持全平台
  • Retina顯示支持，這個不支持windows和linux，僅支持Mac OS
  • 詳細的統計-支持linux。在windows和Mac需要捐贈才行
  • 聲音小工具-支持MAC和linux，windows不確定

重要: 上面的特點都支持，一些具體的特性除了linux外都不是免費提供的，這是為了支付服務器和帶寬費用。對於linux用户來説，任何細節不需要關心，高興的用去吧。

Linux下安裝“icup 2014 Brazil” ​

首先去“icup 2014 Brazil”官方下載頁面下載你電腦平台的軟件版本

32位下的安裝步驟 ​

# cd Downloads/
# tar xvf iCup_2014_FREE-Brazil_1.1_linux.tar.bz2 
# cd iCup\ 2014\ FREE\ -\ Brazil\ 1.1/
# chmod 755 iCup\ 2014\ FREE\ -\ Brazil

如上文所説，這個應用程序只為X86架構設計，為了在64位架構下安裝32位的軟件，我們需要在系統上安裝一些軟件包：GTK+2和libstdc++.so.6。

不只是這款軟件，一大堆Linux下的軟件不支持64位架構，例如Skype，我們也需要這樣調整我們的系統來安裝這些軟件。

在64位系統下 ​

安裝GTK+2和libstdc++so.6，用如下apt或者yum命令

$ sudo apt-get install libgtk2.0-0 libstdc++6 		[在基於Debian系統上執行這個命令]

如果有報錯的話，運行下面的命令來解決

$ sudo apt-get -f install

# yum install gtk2 libstdc++				[在基於Redhat系統上執行這個命令]

需要的軟件包安裝完後，就可以在64位系統下安裝32位的軟件了，進入你的下載目錄，找到“icup 2014 Brazil”安裝包然後執行下面的命令

# cd Downloads/
# tar xvf iCup_2014_FREE-Brazil_1.1_linux.tar.bz2 
# cd iCup\ 2014\ FREE\ -\ Brazil\ 1.1/
# chmod 755 iCup\ 2014\ FREE\ -\ Brazil

然後，進入軟件所在目錄，雙擊可執行文件啓動軟件。下面的截屏圖中看不到所有的信息，因為本文寫作時2014年世界盃現在還沒開始呢，開始後我們就能看到結果了。
