[初級] 如何在 Ubuntu 中安裝 Vivaldi 瀏覽器 ​

你將在本篇新手教程中學習如何在 Ubuntu、Debian 及其他 Linux 發行版中安裝 Vivaldi 網頁瀏覽器，同時本教程也將介紹如何更新和卸載該軟件。

Vivaldi 是一款日益流行的網頁瀏覽器。它基於 Chromium 內核，因此它擁有和 Chrome 類似的功能，但它也新增了一些其他特色功能，讓這款瀏覽器與眾不同、更為直觀。

它內置了標籤組、廣告攔截、鼠標手勢、筆記管理，甚至還有命令連鎖。你甚至可以藉助切分視圖來一次性瀏覽多個頁面。當然，相比於 Chrome，Vivaldi 更加尊重你的隱私。

Manjaro Linux 近期使用 Vivaldi 取代 Firefox 作為其部分變體的默認瀏覽器，你可以從這件事來了解 Vivaldi 瀏覽器的受歡迎程度。

如果你想嘗試一下這款瀏覽器的話，接下來讓我告訴你，如何在 Linux 上安裝 Vivaldi。你將瞭解到：

  • 安裝 Vivaldi 的 GUI 和命令列方式
  • 將 Vivaldi 更新到最新版本的技巧
  • 在 Ubuntu 中卸載 Vivaldi 的方式

非自由軟件警告！

Vivaldi 並非完全的開源軟件。它的 UI 界面是閉源的。之所以在這裏介紹這款瀏覽器，是因為 Vivaldi 團隊正努力讓該軟件在 Linux 平台上可用。

方式 1：在 Ubuntu 中安裝 Vivaldi [GUI 方式] ​

好消息是，Vivaldi 提供了預先構建好的安裝包，包括 Ubuntu/Debian 的 DEB 文件，以及 Fedora、Red Hat、SUSE 的 RPM 文件。

它支持 32 位和 64 位平台，也支持 像樹莓派之類的 ARM 設備。

安裝過程非常簡單。你只需要前往 Vivaldi 的官網下載正確的安裝包文件，雙擊打開，然後安裝，大功告成。

我將詳細介紹在 Ubuntu/Debian 下的安裝過程。對於其他類型的發行版，你可以使用類似的步驟。

第 1 步：下載 Vivaldi ​

前往 Vivaldi 的下載頁面，下載支持 Ubuntu 的 DEB 格式安裝包。

  • 下載 Vivaldi

第 2 步：安裝剛剛下載的 DEB 文件 ​

前往你剛剛下載 DEB 文件的下載文件夾。安裝 DEB 文件 非常簡單，只需要雙擊打開，或者右鍵後使用軟件中心打開即可。

這將打開軟件中心，在這裏可以看到安裝 Vivaldi 的選項。點擊安裝按鈕即可。

你將需要輸入系統賬户的密碼，輸入密碼授權後，Vivaldi 很快就能完成安裝，隨後安裝按鈕也變成了移除按鈕。這表明 Vivaldi 已經安裝完成了。

第 3 步：使用 Vivaldi ​

按下 Super（Windows）鍵打開系統菜單，搜索 Vivaldi，然後單擊 Vivaldi 的圖標。

首次啓動時，你將看到如下界面。

既然你已經知道了這個方法，那我接下來將展示在 Ubuntu/Debian 使用終端安裝 Vivaldi 的方法。

方式 2：藉助終端，在 Ubuntu/Debian 上安裝 Vivaldi ​

打開終端，確認你已經安裝了用於 在命令列下下載文件 的 wget。

sudo apt install wget

接下來，獲取 Vivaldi 倉庫的公鑰並添加到系統，以讓系統信任該來源的軟件包。如果你感興趣的話，你可以閲讀 關於在 Ubuntu 添加第三方軟件倉庫的文章。

wget -qO- https://repo.vivaldi.com/archive/linux_signing_key.pub | sudo apt-key add -

添加完該密鑰後，再添加 Vivaldi 的倉庫：

sudo add-apt-repository 'deb https://repo.vivaldi.com/archive/deb/ stable main'

現在距離完成也只有一步之遙了。更新軟件倉庫緩存並安裝 Vivaldi。

sudo apt update && sudo apt install vivaldi-stable

大功告成。現在，前往系統菜單搜索並啓動 Vivaldi 吧。

在 Ubuntu 中更新 Vivaldi ​

GUI 和命令列這兩種方式都會在系統裏添加 Vivaldi 的倉庫。這意味着，只要 Vivaldi 發佈了新版本，你就可以在系統更新中一併獲取 Vivaldi 的更新。

一般情況下，你更新 Ubuntu 系統時，如果 Vivaldi 發佈了新版本，那麼 Vivaldi 也同時會被更新。

在 Ubuntu 中卸載 Vivaldi ​

如果你不喜歡 Vivaldi 或者不再使用，你可以直接卸載。現在，如果你想 在 Ubuntu 中卸載軟件，你可能會想到軟件中心，但軟件中心不會查找到外部和第三方的軟件包。

目前你必須使用終端卸載 Vivaldi，即便你是使用 GUI 方式安裝的。其實這也很簡單，打開終端，輸入以下命令：

sudo apt remove vivaldi-stable

sudo 會 在 Ubuntu 中給予你 root 權限。你需要輸入當前賬户的密碼。輸入密碼時，你可能不會在屏幕上看見輸入密碼的痕跡。這是正常現象，直接輸入密碼即可，隨後 Vivaldi 將被卸載。

希望這篇關於如何在 Linux 安裝 Vivaldi 的教程對你有用。
