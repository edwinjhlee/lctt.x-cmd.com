Linux 上 5 個基於 Chromium 的瀏覽器 ​

谷歌瀏覽器可能不是 Linux 用户的最佳瀏覽器。在這裏，我們探討了 Linux 平台的其他潛在選擇。

想擺脱谷歌？想為你的 Linux 系統尋找可能比谷歌瀏覽器（和類似的）更好的瀏覽器？

幸運的是，有多個谷歌瀏覽器的替代品，你可以試試。

它們中的每一個都帶來了一些有趣的東西，同時也保持了 Chrome 所特有的奇妙兼容性。請繼續閲讀，瞭解這些瀏覽器的更多信息。

比谷歌瀏覽器更好的選擇 ​

注：雖然 自由和開源軟件在取代科技巨頭方面扮演着關鍵角色，但除了谷歌瀏覽器之外，Linux 上的任何選擇都是一個好的開始。因此，你也會發現一些非 FOSS 的選擇。

在我看來，Chrome 的最佳替代品是基於 Chromium 的瀏覽器，這意味着它們與 Chrome 共享相同的基因。這樣做的好處是，它們已經擁有與 Chrome 相同的功能，同時有更多時間來增加自己的功能。

另外，如果你願意，你可以瞭解一下不基於 Chromium 的 Chrome 開源替代品。

無論如何，即使谷歌瀏覽器的替代品對你來説並不優越，也值得嘗試遠離科技巨頭。

我們收集了一些在各方面與 Chrome 相當或更好的瀏覽器。閒話少説，以下是我挑選的五款比 Chrome 本身更好的類似 Chrome 的瀏覽器：

  • UnGoogled Chromium
  • Brave
  • Edge
  • Vivaldi
  • Opera

這份名單沒有排名順序。

1、UnGoogled Chromium ​

特點：

  • 移除針對谷歌域名的功能
  • 在運行時阻止對 Google 的內部請求
  • 從源代碼中剝離谷歌的二進制文件
  • 許多新的命令列開關和 chrome://flags 條目
  • 強制所有彈出式窗口為標籤

對於那些隱私愛好者來説，UnGoogled Chromium 瀏覽器將是一個天賜良機。雖然它可能看起來與 Chrome 相同，但它有許多隱私方面的調整。

顧名思義，對於 Chrome 瀏覽器的用户來説，最大的倒退將是沒有谷歌的服務集成。但這也意味着不再有對谷歌的內部請求、谷歌網址跟蹤等等。

它沒有吹噓任何非凡的東西來保護你的隱私，但它應該比谷歌瀏覽器更好。

你也可以選擇通過 chrome://flags 設置來探索和切換隱私設置。

總而言之，UnGoogled Chromium 提供了一種熟悉的瀏覽體驗，同時還加入了一套隱私功能。它是可靠的，而且還與 Chrome 擴展程序龐大的生態系統兼容。

2、Brave ​

特點：

  • 內置廣告攔截器
  • 更快的頁面加載時間
  • Brave 獎勵計劃
  • 能夠在設備之間進行同步
  • 支持 Chrome Web 商店

當 Brave 在 2016 年首次登上舞台時，世界各地的人們都震驚於它的隱私和性能特點。在發佈時，這包括了一個內置的廣告屏蔽器和一個新的用户界面。

從那時起，該瀏覽器有了更多的功能，包括獎勵計劃和 Tor 整合。這使得它成為增長最快的瀏覽器之一。

3、Edge ​

特點：

  • 支持 Chrome Web 商店
  • 兒童瀏覽模式（額外的保護和更簡單的用户界面）
  • 良好的 PDF 編輯工具
  • 內置優惠券搜索器
  • 閲讀模式
  • 內置密碼生成器

當微軟 Edge 在 2015 年首次與 Windows 10 一起發佈時，它因緩慢和有缺陷而被廣泛批評。然而，在 2020 年初，它使用 Chromium Web 引擎完全重新制作了。

這也是 Chrome 瀏覽器所基於的引擎，這提供了現代和快速的瀏覽體驗。這種轉變的一個好處是 Web 瀏覽器能夠在許多不同的平台上運行，從 Windows 7 和 macOS 到 Ubuntu 和其他基於 Linux 的發行版。

我知道，如果你因為某些原因討厭微軟，這可能不會吸引你 —— 但 Linux 版的微軟 Edge 是谷歌 Chrome 瀏覽器的一個重要替代品。

4、Vivaldi ​

特點：

  • 內置翻譯器
  • Vivaldi Email（Beta）
  • Feed 閲讀器（Beta）
  • Vivaldi 日曆（Beta）
  • 可高度定製的用户界面
  • 內置廣告攔截器
  • 支持 Chrome Web 商店
  • 標籤分組
  • 分屏標籤

Vivaldi 於 2016 年首次發佈，它在瀏覽器大戰中迅速崛起。它最初是為對 Presto 佈局引擎 過渡不滿的 Opera 用户設計的，它已經成功地重新實現了 Opera 過渡到 Chromium 期間失去的許多功能。

令人驚訝的是，它在基於 Chromium 的情況下還能做到這一點（正是 Opera 放棄這些功能的原因）。

最新的 Vivaldi 4.0 版本 也為高級用户提供了一些功能。

雖然它不是 100% 的自由軟件，但其 93% 的源代碼是可用的，只有用户界面是專有的。考慮到 Vivaldi 的開發團隊積極關注着 Linux 用户的改進，Vivaldi 提供了大量的功能，這可能是一個值得權衡的結果。

5、Opera ​

特點：

  • 內置虛擬專用網絡
  • 輕鬆訪問社交媒體
  • 內置加密貨幣錢包
  • 欺詐和惡意軟件保護
  • 高度可見的網站安全徽章

雖然 Opera 從未成為 Web 瀏覽器之王，但它一直存在於關於使用何種瀏覽器的爭論中。它最初是基於其內部的 Presto 佈局引擎的，在 2013 年切換到 Chromium。

不幸的是，這一轉換意味着 Opera 團隊被迫放棄了其最知名的一些功能，為 Vivaldi 和 Firefox 等替代品填補 Opera 留下的空間鋪平道路。

這並不是説 Opera 缺乏功能，它包含了許多功能。

總結 ​

在這裏，我們列出了為 Linux 桌面平台上用户量身定做的瀏覽器。

無論你是想要更多的功能、更好的用户界面，還是想要幫助你擺脱谷歌的束縛，都有一個選擇適合你。

由於所有這些瀏覽器都是基於 Chromium 的，它們都能像 Chrome 一樣提供良好的兼容性和用户體驗。因此，請切換到這些類似 Chrome 的瀏覽器中，享受它們各自賦予的自由吧。
