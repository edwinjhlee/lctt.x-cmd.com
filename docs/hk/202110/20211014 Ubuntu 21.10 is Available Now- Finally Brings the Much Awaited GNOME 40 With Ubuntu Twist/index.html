Ubuntu 21.10 版現已發佈！終於帶來了 Ubuntu 特色的 GNOME 40 ​

Ubuntu 21.10 是一個激動人心的版本，包含了 GNOME 40 和幾個顯著的變化。準備已經駛向了 Ubuntu 22.04 LTS 嗎？

Ubuntu 21.10 是下一個大型 LTS 更新之前的最後一個非 LTS 版本。代號為 Impish Indri 的 Ubuntu 21.10 將被支持九個月，直到 2022 年 7 月。

除非你想嘗試最新和最棒的功能，否則你應該堅持使用 Ubuntu 20.04 LTS 並等待 Ubuntu 22.04 LTS。

現在你可以下載 Ubuntu 21.10 並在你的系統上安裝，讓我重點介紹一下這次更新的幾個亮點。

Ubuntu 21.10 “Impish Indri” 有何新變化？ ​

Ubuntu 21.10 出爐時有幾個重大變化。一些最有影響的改進包括：

  • 新的安裝程序
  • 增加了 GNOME 40
  • 拋棄了混合主題，選擇了淺色/深色主題
  • 包括 Linux 內核 5.13
  • 加入了支持藍牙 LDAC 的 PulseAudio 15
  • 帶有 Nvidia 專有驅動程序的 Wayland 會話

GNOME 40 可以説是 Ubuntu 中令人耳目一新的變化，但你只有在體驗之後才能知道。為了讓你快速感受一下，下面是這個版本中你可以期待的所有變化。

粉飾一新的安裝程序 ​

雖然 Ubuntu 的安裝程序很容易使用，對新手也很友好，但 Canonical 希望通過對安裝程序進行視覺和技術上的改造，使其更上一層樓。

開發團隊利用 Flutter 使安裝程序在所有其他 Ubuntu 口味和系統配置中保持一致。

GNOME 40 ​

Ubuntu 的桌面體驗與 GNOME 40 融為一體，沒有提供任何混亂的佈局。停靠區依然存在，水平活動概覽也與之無縫銜接。

當然，GNOME 40 中的所有改進，如核心應用程序的更新、工作區的改變等等，都會延續到 Ubuntu 21.10 中，只是 Canonical 做了一些改動。

就我個人而言，我並不喜歡 GNOME 40 的工作流程，但你可能會想體驗一下。

主題的變化 ​

我喜歡改進後的顏色方案，其目的是為了更好地與 Canonical 的 Ubuntu 品牌相融合。

然而，當涉及到與應用程序和整體主題選擇的一致性時，混合（標準）主題是有點問題的。

在 Ubuntu 21.10 中，你會看到深色和淺色主題，而淺色是開箱即用的默認選擇。如果你想進一步瞭解，你可以閲讀我們的 過去的報道以更多瞭解這一變化。

Linux 內核 5.13 ​

Linux 內核 5.13 的加入增加了對未來的英特爾和 AMD 芯片的支持，以及對蘋果 M1 的初步支持。

你可以就一步瞭解 Linux 內核 5.13 的信息，但總的來説，它應該給你更好的硬件兼容性。

PulseAudio 15 支持藍牙 LDAC ​

考慮到現在有更多的藍牙耳機支持 LDAC，當你在桌面上使用 Ubuntu 21.10 時，你可以利用這一功能。

別擔心，如果你不想嘗試非 LTS 版本，Ubuntu 22.04 LTS 將包括同樣的改進。所以，你必須耐心等待，直到明年才能利用這一點。

除此之外，PulseAudio 15 還帶來了一系列的改進，你可以參考它的 官方更新日誌以瞭解更多信息 。

Wayland 會話與 NVIDIA 專有驅動程序 ​

現在，即使你使用 NVIDIA 專有的驅動程序，如果你需要也可以切換到 Wayland 會話。

Ubuntu 21.10 中的其他變化 ​

Ubuntu 21.10 版本為其雲鏡像、樹莓派支持和安全性帶來了一系列高質量的變化。

其中一些值得注意的變化包括：

  • Firefox 默認採用 Snap
  • LibreOffice、Thunderbird 更新
  • Ubuntu Sever 的改進
  • 新的 PHP 默認為 8.0.8

如果你想探索所有的技術細節，你可能想參考一下 官方發佈説明。

下載並升級到 Ubuntu 21.10 ​

你可以選擇全新安裝或使用軟件升級器 從 Ubuntu 21.04 升級 到 Ubuntu 21.10。

請注意，如果你正在使用 Ubuntu 20.04 LTS，建議等待下一個 LTS 版本，除非你知道自己在做什麼。
