Linux Mint 和 Fedora：應該使用哪一個？ ​

Linux Mint 是一個 為初學者定製的流行的 Linux 發行版，同時為用户提供了與 Windows 類似的體驗。事實上，它有 一些地方比 Ubuntu 做的更好，這使它成為每一類用户的合適選擇。

它是基於 Ubuntu 的，完全由社區所支持。

另一方面，Fedora 是一個嚐鮮發行版，它專注於納入令人興奮的變化，最終使其成為紅帽企業 Linux（RHEL）的一部分。

與 Linux Mint 不同，Fedora 並不完全專注於個人（或非開發者）使用。即使他們提供了一個工作站版本，其目標也是開發者和有經驗的 Linux 用户。

Fedora 或 Mint，應該根據什麼選擇？ ​

雖然我們知道 Fedora 並不是完全面向 Linux 新手的，但許多用户喜歡使用 Fedora 作為他們的日常系統。因此，在這篇文章中，我們將闡明兩者之間的一些區別，以幫助你選擇一個在你的台式機上使用的操作系統。

系統要求 & 硬件兼容性 ​

在選擇任何 Linux 發行版之前，你都應該看一下它的系統要求，並檢查硬件兼容性。

在這方面，Linux Mint 和 Fedora 都需要至少 2GB 的內存、20GB 的磁盤空間，以及 1024 x 768 分辨率的顯示器來獲得入門級的體驗。

是的，官方文件可能提到 1GB 內存就可以起步，但要看實際使用情況。除非你有一台復古的電腦，想為一個特定的目的恢復它，否則它就不在考慮範圍之內。

在技術上，兩者都支持現代的和陳舊的硬件，你只有在安裝時才會知道軟件/驅動是否支持它。除非你有一個特殊的外圍設備或具有特殊功能的硬件組件，否則硬件支持可能不是什麼大問題。

Linux Mint 19 系列仍然提供了對 32 位系統的支持，你可以使用它到 2023 年 4 月。而 Fedora 已經不支持 32 位系統了。

軟件更新週期 ​

Linux Mint 專注於長期發佈版（LTS），支持時間為五年。它的維護方式與 Ubuntu 相同。但沒有像 Ubuntu 那樣提供付費的擴展支持。

Fedora 不提供 LTS 版本，而是每 6 個月推送一次新的更新，每個版本都會得到 13 個月的軟件支持。如果你願意，你可以跳過一個版本。

如果你只是想安裝一個可以使用多年的 Linux 發行版，而不在乎是不是最新的技術/功能，那麼 Linux Mint 是個不錯的選擇。

但是，如果你想要最新的和最偉大的 Linux 技術（在一些罕見的情況下，這也可能破壞你的計算體驗），並接受適應 Fedora 推動的重大變化，Fedora 可以是一個選擇。

桌面環境的選擇 ​

Linux Mint 提供三種不同的 桌面環境：MATE、Cinnamon 和 Xfce。它們有相同的更新週期，並從發佈之日起支持 5 年。

儘管 Fedora 不提供 LTS 版本，但你可以通過 Fedora spins 的形式選擇各種桌面。你可以得到 KDE、LXQt、MATE、Cinnamon、LXDE，以及一個內置 i3 平鋪窗口管理器的版本。

所以，如果你想有更多的選擇，Fedora 可以是一個相當令人激動的選擇。

軟件可用性 ​

Linux Mint（或 Ubuntu）的默認軟件庫提供了大量可以安裝的軟件，而 Fedora 的默認軟件庫只堅持提供開源軟件。

不僅僅限於此，Linux Mint 還配備了 Synaptic 軟件包管理器，這是一個令人印象深刻的安裝軟件的輕量級工具。

儘管你可以 在 Fedora 中啓用第三方軟件庫，但這又是一個額外的步驟。而且，RPM Fusion 存儲庫可能沒有 Ubuntu 的 universe 存儲庫那麼龐大。

所以，對於 Linux Mint 來説，總的來説，你可以得到更多可安裝的軟件包和各種安裝軟件的方法，開箱即用。

使用和安裝的便利性 ​

對於一個 Linux 的新嫩用户來説，Ubuntu 或任何基於 Ubuntu 的發行版通常都是一個很好的開端。

從 Ubuntu 的安裝體驗，到 安裝軟件 的簡便性，同時還可以選擇 LTS 版本，這讓初學者覺得很方便。

而且，藉助 Ubiquity 安裝程序，Linux Mint 自然也有與 Ubuntu 相同的好處，因此，它的學習曲線最小，易於安裝，易於使用。

雖然從表面上看 Fedora 並不複雜，但安裝選項、軟件包管理器以及默認存儲庫中缺乏的軟件可能是一個耗時的因素。

如果你沒有嘗試過，我建議你試試我們的 VirtualBox 版的 Fedora 安裝指南。這是一個測試安裝體驗的好方法，然後再在你的任何生產系統上進行嘗試。

開箱即用的體驗 ​

最省事的體驗通常是令人愉快的選擇。嗯，對大多數人來説。

現在，你需要明白，根據硬件配置的不同，每個用户最終可能會有不同的“開箱即用”體驗。

但是，作為參考，讓我給你舉個 Fedora 和 Linux Mint 的例子。

考慮到我的電腦上使用的是 NVIDIA GPU，我需要安裝專有的驅動程序以獲得最佳性能。

而且，當我啓動 Linux Mint 時，使用“驅動程序管理器”應用程序，安裝驅動程序相當容易。

但是，對於 Fedora，即使我按照我們的 在 Fedora 中安裝 Nvidia 驅動程序 的指南，我在重啓時還是出現了一個錯誤。

不僅如此，由於某些原因，我的有線網絡似乎沒有被激活，因此，我沒有互聯網連接。

是的，當你遇到問題時，你總是可以嘗試着去排除故障，但是對於 Linux Mint，我不需要這麼做。所以，根據我的經驗，我會推薦 Linux Mint，它有更好的開箱體驗。

文檔 ​

如果你依賴於文檔資源並想在這個過程中挑戰自己，獲得不錯的學習經驗，我推薦你去看看 Fedora 的文檔。

你會發現最近和最新的 Fedora 版本的最新信息，這是件好事。

另一方面，Linux Mint 的文檔 沒有定期更新，但在你想深入挖掘時很有用。

社區支持 ​

你會得到一個良好的社區支持。Linux Mint 的論壇 是一個很基礎的平台，容易使用並能解決問題。

Fedora 的論壇 是由 Discourse 驅動的，它是最 流行的現代開源論壇軟件 之一。

企業與社區的角度 ​

Fedora 得到了最大的開源公司 紅帽 的支持 —— 因此你可以得到良好的持續創新和長期的支持。

然而，正因為 Fedora 並不是為日常電腦用户而建立的，每一個版本的選擇都可能完全影響你的用户體驗。

另一方面，Linux Mint 完全由一個充滿激情的 Linux 社區所支持，專注於使 Linux 在日常使用中更加容易和可靠。當然，它依賴於 Ubuntu 作為基礎，但如果社區不喜歡上游的東西，Linux Mint 也會做出大膽的改變。

例如，Linux Mint 與 Ubuntu 官方發行版不同，默認情況下禁用了 snap。所以，如果你想使用它們，你就必須 在 Linux Mint 中啓用 snap。

總結 ​

如果你想為你的家用電腦選擇一個沒有問題的、易於使用的操作系統，我的建議是 Linux Mint。但是，如果你想體驗最新的、最偉大的 Linux 操作系統，同時在你的 Linux 學習經歷中進行一次小小的冒險，Fedora 可以是一個不錯的選擇。

雖然每個操作系統都需要某種形式的故障排除，沒有什麼能保證你的硬件完全不出問題，但我認為 Linux Mint 對大多數用户來説可能沒有問題。

在任何情況下，你可以重新審視上面提到的比較點，看看什麼對你的電腦最重要。
