helloSystem：一款類似 Mac 的 FreeBSD 系統 ​

最近，helloSystem 的開發者發佈了他們操作系統的最新版本。helloSystem 是一個較新的項目，希望以 FreeBSD 為基礎創建一個簡單易用的操作系統。讓我們來看看這對你我意味着什麼。

helloSystem 簡介 ​

你們中的大多數人可能以前從未聽説過 helloSystem。該項目是由 AppImage 的創建者 Simon Peter 在去年年初啓動的。Simon 的目標是創建一個“友好的 自由桌面 操作系統，重點是簡單、簡約優雅和可用性。”

Simon 從上世紀 80 、90 年代更為簡單的操作系統中獲得了靈感，特別是 早期的 MacOS，比如 System 1。如果你只是看一下系統運行的截圖，你可能會想説，“我不明白這有什麼好大驚小怪的。有一堆 Linux 發行版或主題，看起來就像 MacOS。”

該項目不僅僅是看起來像 MacOS，它想回歸到更簡單、更容易使用的設計。據 其網站 上講，“helloSystem 是一個面向創作者的桌面系統，注重簡單、優雅和實用性。它的設計遵循 ‘少而精’ 的理念。它的目的是為 ‘普通人’ 提供一個系統，歡迎從 Mac 切換過來的人”。你可以通過觀看 Simon 在 FOSDEM 21 上的演講，瞭解更多關於他對 helloSystem 計劃的想法。

就像 Suckless 項目 一樣，Simon 創建了一個 “歡迎和不歡迎的技術” 列表。被批准的技術清單包括：

  • Qt
  • mDNSResponder
  • Python
  • Go

“不受歡迎的技術”清單包括 Simon 認為“太複雜或被認為不美觀”的東西。這些技術包括：

  • 觸摸
  • btrfs
  • Gnome
  • GTK
  • 客户端窗口裝飾
  • Wayland
  • Pipewire
  • XDG 桌面規範
  • 與原始字體在度量上兼容的字體，但不試圖在視覺上與原始字體相似
  • 最終用户應用程序的包管理器
  • 配置文件、IP 地址
  • D-Bus
  • 通過限制用户或應用程序可以做的事情而提供的安全性
  • Polkit
  • 大寫鎖定鍵
  • 本地文件的 URI

helloSystem 如何工作 ​

我最好解釋一下 helloSystem 的工作方式。就像 MacOS 一樣，桌面在屏幕頂部有一個全局菜單，底部有一個 Dock。與 MacOS 的 Finder 一樣，helloSystem 也有一個文件管理器（名為 Filer），它也負責窗口管理。

在左上方，你會發現一個 “系統System” 菜單，你可以用它來訪問應用程序。（你也可以在左上角的搜索框中輸入應用程序的名稱。）helloSystem 只安裝了幾個開箱即用的基本應用程序。如果你點擊一個未安裝的應用程序，helloSystem 會下載並安裝該應用程序的 AppImage。

helloSystem 基於 FreeBSD 12.2。它默認啓用了 ZFS。它沒有密碼或用户賬户系統，但這並不意味着他們無視安全。據 其網站 講，“這並不是説一般的安全問題不重要。而是説它需要以一種不會限制設備的合法用户（所有者）真正 ‘擁有’ 該設備的方式來實現。”

最新版本中的新功能 ​

最新版本的 helloSystem 包括不少圖形方面的更新和小的變化，包括：

  • 從 Openbox 切換到 KWin 窗口管理器
  • 合理的窗口標題居中
  • 當窗口被拖到屏幕邊緣時，會縮放到一定大小，類似於 “Aero Snap”。
  • 簡化了 “桌面設置Desktop Settings” 的用户界面；現在更改會立即應用
  • 移除文件管理器中的標籤以簡化用户界面
  • 為菜單添加新的電池小程序，以顯示電池充電量
  • 桌面上的垃圾箱圖標不再有 “移動到垃圾箱Move to Trash” 的上下文菜單項
  • 最小化窗口和取消最小化窗口時的動畫
  • 窗口大小調整時的動畫
  • 調整內核配置以優化聲音
  • 簡化了文件管理器中的 “獲取信息Get Info” 對話框

你可以在 這裏 看到其餘的變化。你也可以從同一個鏈接下載最新的 .iso 文件。試一試，讓我們知道你的想法。
