10 個使用 Cinnamon 作為 Linux 桌面環境的理由 ​

Cinnamon 是一個讓人懷舊 GNOME 2 的 Linux 桌面環境，它靈活、快速，並提供了種種的功能。

最近我安裝了 Fedora 25，我覺得當前的 KDE Plasma 版本並不穩定。在我決定嘗試其它的桌面之前一天崩潰了好幾次。在我安裝了幾個其它的桌面，並每個嘗試了幾個小時後，我最終決定在 Plasma 打上補丁並且穩定之前就使用 Cinnamon 了。以下是我所發現的。

Cinnamon 簡介 ​

在 2011，帶有新的 GNOME Shell 的 GNOME 3 發佈了，新的界面馬上引來了或正或反的反饋。許多用户以及開發者非常喜歡原先的 GNOME 界面，因此有多個組織復刻了它，其中一個結果就是 Cinnamon。

開發 GNOME 3 的 GNOME shell 背後的原因之一是許多原先的 GNOME 用户界面組件不再活躍開發了。這同樣也是 Cinnamon 以及其他 GNOME 復刻項目的問題。 Linux Mint 項目是 Cinnamon 的一個首要推動者，因為 GNOME 是 Mint 的官方桌面環境。Mint 開發者已經將 Cinnamon 推進到了不需要 GNOME 本身的地步，Cinnamon 已經是一個完全獨立的桌面環境，它保留了許多用户喜歡的 GNOME 界面的功能。

圖 1：打開系統設置工具的默認 Cinnamon 桌面。

Cinnamon 3.2 是當前發佈版本。除了 Mint，Cinnamon 還在許多發行版中可用，包括 Fedora、Arch、Gentoo、Debian 和 OpenSUSE 等。

使用 Cinnamon 的理由 ​

這是我的使用 Cinnamon 的 10 個重要理由：

  1. 集成。 桌面的選擇並不取決於在較長時間內是否有為它寫的應用。我使用過的所有應用程序，不管它是在哪個桌面下寫的，它都可以在任何其它桌面上運行正常，Cinnamon 也不例外。要運行那些為 KDE、GNOME 或其他桌面編寫的程序所需要的庫都有，可以在 Cinnamon 上面順滑地使用這些程序。

  2. 外觀。 讓我們面對它，外觀是很重要的。Cinnamon 有一個明快的、乾淨的外觀，它使用了易於閲讀的字體以及顏色的組合。桌面沒有不必要的阻礙，你可以使用“系統設置” => “桌面” 菜單配置顯示在桌面上的的圖標。這個菜單還允許你指定是否在主監視器、次監視器或者所有監視器上顯示桌面圖標。

  3. 桌面組件。 桌面組件是一些小型的、可以添加到桌面的單一用途的程序。只有一些是可用的，但是你可以從 CPU 或者磁盤監視器、天氣應用、便利貼、桌面相簿、時間和日期等之中選擇。我喜歡時間和日期桌面組件，因為它比 Cinnamon 面板中的小程序易於閲讀。

  4. 速度。 Cinnamon 快速又敏捷。程序加載和顯示很快。桌面自身在登錄時加載也很快，雖然這只是我的主觀體驗，並沒有基於時間測試。

  5. **配置。 ** Cinnamon 不如 KDE Plasma 那樣可配置，但是也要比我第一次嘗試它的時候有更多的配置。Cinnamon 控制中心提供了許多桌面配置選項的集中訪問。它有一個主窗口，可以從它啓動特定功能的配置窗口。可以很容易地在 “系統設置” 的 “主題” 的可用外觀中選擇新的外觀。你可以選擇窗口邊框、圖標、控件、鼠標指針和桌面基本方案。其它選擇還包括字體和背景。我發現這些配置工具中有許多是我遇到的最好的。它有適量的桌面主題，從而能夠顯著改變桌面的外觀，而不會像 KDE 那樣面臨選擇困難。

  6. Cinnamon 面板。 Cinnamon 面板，即工具欄，最初的配置非常簡單。它包含用於啓動程序的菜單、基本的系統托盤和應用程序選擇器。這個面板易於配置，並且添加新的程序啓動器只需要定位你想要添加到主菜單的程序，右鍵單擊程序圖標，然後選擇“添加到面板”。你還可以將啓動器圖標添加到桌面本身，以及 Cinnamon 的 “收藏” 的啓動欄中。你還可以進入面板的編輯模式並重新排列圖標。

  7. 靈活性。 有時可能很難找到最小化或者隱藏的正在運行的程序，如果有許多正在運行的應用程序，則在工具欄的程序選擇器上查找它可能會有挑戰性。 在某種程度上，這是因為程序並不總是有序地排在選擇器中使其易於查找，所以我最喜歡的功能之一就是可以拖動正在運行的程序的按鈕並將其重新排列在選擇器上。這可以使查找和顯示屬於程序的窗口更容易，因為現在它們現在在我放的位置上。

    Cinnamon 桌面還有一個非常好的彈出菜單，你可以右鍵單擊訪問。此菜單有一些常用任務，例如訪問桌面設置、添加桌面組件以及其他與桌面相關的任務。

    其它菜單項之一是 “創建新文檔”，它使用位於 ~/Templates 目錄中的文檔模板，並列出它們中的每一個。只需點擊要使用的模板，使用這個模板的文檔就會使用默認的 Office 程序創建。在我的情況下，那就是 LibreOffice。

  8. 多工作空間。 Cinnamon 像其他桌面環境一樣提供了多個桌面。Cinnamon 稱它為“工作區”。工作區選擇器位於 Cinnamon 面板中並展示每個工作區的窗口概覽。窗口可以在工作區之間移動或指定到所有工作區。我確實發現工作區選擇器有時候會比窗口位置的顯示慢一些，所以我將工作區選擇器切換為顯示工作區編號，而不是在工作區中顯示窗口概覽。

  9. Nemo。 大部分桌面因種種目而使用它們自己偏好的默認程序，Cinnamon 也不例外。我偏好的桌面文件管理器是 Krusader，但是 Cinnamon 默認使用 Nemo，因此在測試中我就用它了。我發現我很喜歡 Nemo。它有一個美麗乾淨的界面，我喜歡大部分功能並經常使用。它易於使用，同時對我的需求也足夠靈活。雖然 Nemo 是 Nautilus 的復刻，但是我發現 Nemo 更好地被集成進了 Cinnamon 環境。Nautilus 界面看上去沒有與 Cinnamon 很好集成，與 Cinnamon 不太和諧。

  10. 穩定性。  Cinnamon 非常穩定且可用。

總結 ​

Cinnamon 是 GNOME 3 桌面的復刻，它看上去像一個前所未有的 GNOME 桌面。它的發展看起來是符合邏輯的改進， Cinnamon 開發者認為需要在提升和擴展 GNOME 的同時保留它的獨特性以及被大家非常喜歡的特性。它不再是 GNOME 3 - 它是不同的並且是更好的。Cinnamon 看上去很棒，並且對我而言也工作得很好，並且從 KDE 這個我仍舊非常喜歡的環境切換過來也很順暢。我花費了幾天時間學習 Cinnamon 的差異如何使我的桌面體驗更好，並且我非常高興瞭解這個很棒的桌面。

雖然我喜歡 Cinnamon，但我仍然喜歡體驗其它的環境，我目前正切換到 LXDE 桌面，並已經用了幾個星期。在我使用一段時間時候，我會分享我的 LXDE 體驗。
