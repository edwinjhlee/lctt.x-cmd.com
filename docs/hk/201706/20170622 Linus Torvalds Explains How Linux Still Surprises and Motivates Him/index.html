Linus Torvalds 説 Linux 仍然驚訝和激勵着他 ​

Linus Torvalds 和 VMware 開源負責人 Dirk Hohndel 上週在中國 LinuxCon 上進行了一次“爐邊聊天”。

週一，Linus Torvalds 首次來到中國參加在北京召開的 LinuxCon + ContainerCon + CloudOpen。在近 2000 名觀眾面前，Linus Torvalds 和 VMware 開源負責人 Dirk Hohndel 進行了進行了一次“爐邊聊天”，談及是什麼在驚訝和激勵着他，以及有志的開源開發者們該如何上手。下面是他們談話中的一些亮點。

Linux 開發中有什麼令人驚訝的事情? ​

“我覺得有趣的是我認為已經穩定的代碼仍然在不斷的得到改進，有些東西我們已經很多年沒有碰了，然後有人來改進了它們，或者在我以為根本就不會有人用的東西上提交了 Bug 報告。我們有了新的硬件，開發了新的功能，但是 25 年後，我們仍然有老的、非常基礎的東西，並且人們依然在關心和改善着它們。”

什麼在激勵着他 ​

“我真的很喜歡我正在做的事情。我喜歡醒來時有一個在技術上有趣而富有挑戰性並且不太緊張的工作，因此我可以長時間的為此工作；或者做一些我感覺我正在做一個真正有影響的事情，做一些不僅僅是對我來説有意義的事情。

“我偶爾在工作中休息一下，例如我在 Git 上工作兩到三週的時候就開始休息了。但是每次休息的時間比較長我都會感到無聊厭倦。當我出去潛水一週，就想着要回來，我從沒有感覺我需要一個更長的假期。”

（LCTT 譯註：此處“在 Git 上工作” 是指 Linus 在 Git 版本倉庫裏面開發 Linux 內核，而非開發 Git 軟件——事實上，Linus 在早期開發完 Git 的原型之後，主要的 Git 開發已經有別人接手了，雖然他被稱之為 Git 之父。而“潛水”是真的指潛水運動，Linus 喜好玩潛水運動。）

Linux 的未來領導力 ​

“我們的工作進程不會只是 25 年，我們仍然有非常強大的維護團隊。我們常常抱怨我們沒有足夠的維護者 - 這是真的，我們只有數十名頂級維護者做日常合併的工作，這對於一個開源項目來説是一個非常強大的團隊。而且隨着這些頂級維護者慢慢變老變胖，我們不斷有新人進來。一個新人成長為一個頂級維護者需要幾年的時間，因此我不覺得我們應該為 Linux 的下一個 20 年擔心。”

Linux 會被替代嗎？ ​

“或許會有一些新的項目將來會並且表明他們比我們做的更好，但是我不擔心這個。有很多非常成功的 Linux 的分支（fork），人們不會把它們看作是分支是因為他們很和諧。如果有人想要改變一切並且讓內核變得更好，我的感覺是，幹吧，證明你自己。我可能覺得那是一個壞主意，但是你可以證明我是錯的。”

（LCTT 譯註：此處所説的分支，應該是指類似 Android、AGL 等 Linux 分支並沒有分裂 Linux 生態，而是彼此補充。）

對 Git 的想法 ​

“我對 Git 的廣泛傳播感到非常的驚訝。顯然我非常高興，它驗證了我對分佈式開發的看法。然而那時，已經有如此之多的源碼版本控制工具，很難再去推出一個新的版本控制系統。我預計它主要限於內核開發 - 因為它是針對我們所做的。”

“在剛開始的三到四年裏，關於 Git 的抱怨是它如此的與眾不同，難以使用。大約五年前，事情發生了改變。有足夠多的項目和開發者開始使用 Git ，它變得不再與眾不同；人們習慣於使用 Git 。他們開始利用這種開發模式，使用 Git 的安全感，意味着任何東西都不會損壞或者丟失。”

“在某些方面，Git 比 Linux 更為人所知。Linux 常常被隱藏起來，例如安卓手機就運行在 Linux 之上，但是你並不知道。但是使用 Git 時，你確切地知道你在使用 Git 。”

分支 Linux ​

“當我坐下來開始寫 Git ，一個首要的原則就是你應該能 fork 並且在此基礎上做你自己的事情。如果你有友好的 fork（能證明我錯了，並且能夠改進內核），在這種情況下，人們可以回來説我們實際上改進了內核，這沒有什麼不好的感覺。我會採納你的改進並且將其合併進來。這就是為什麼你應該鼓勵 fork 。你也想讓良好的回饋變得很簡單。”

開源開發者應該如何開始 ​

“於我而言，我總是自我激勵，知道自己想要做什麼，我從來沒有被告知要去做什麼。我不確定我的例子是否適合人們效仿。如果你是一個新手程序員，你可以從成千上萬的開源項目中找到你所感興趣的，你可以長期關注這個項目，去了解它的代碼，以至於你可以在某個部分的代碼上可以成為專家，不需要是整個項目。沒有人是整個內核的專家，但是你可以很好地瞭解其中的一個領域。”

“如果你能成為社區的一份子，能提交補丁，那將不僅僅是編程，而是有開源社會方面的意義。你作為一個程序員提升了你自己並且和外界聯繫了起來。你基本上可以向外展示 - 我做了這些改進，我有能力在我的社區或者工作上走得更遠。你不得不花費一定的時間來學習一個項目，但是你將有一個巨大的上升空間 - 不僅僅是從職業方面，而且在你的生活中有一個驚人的項目。”
