AWS 雲服務清單 ​

認識 71 個 AWS 雲服務的術語 ! 通過了解 AWS 世界中使用的術語開始你的 AWS 雲服務使用生涯 !

AWS，即亞馬遜 Web 服務Amazon Web Services，是一個提供了一系列按使用計費的 web 服務的雲平台。 它是迄今為止最為著名的雲平台之一。由於其靈活性、有效性、彈性、可測量性和無須維護，所以有一些企業正逐步把他們的業務遷移到雲端。 由於許多公司目前在使用這些服務，所以對於系統管理員和運維人員來説應該瞭解一下 AWS。

這篇文章旨在列出這些 AWS 提供的服務並且解釋在 AWS 中出現的術語。

截止到目前為止（2017 年 3 月），AWS 提供了分為 17 組的共計 71 種服務：

計算型服務 ​

這是一個提供了虛擬服務器配置功能的服務，即所謂的雲計算。它提供了包括以下這一系列的服務。

  1. EC2：EC2 代表彈性計算雲。這種服務提供了可根據個人需求擴展的 [虛擬機][11]。
  2. EC2 容器服務：其高性能，高可擴展性使其可在 EC2 集羣環境中運行服務。
  3. Lightsail：該服務使用户非常容易地啓動和管理虛擬服務器（EC2）。
  4. Elastic Beanstalk：該服務能夠自動管理你的應用程序的容量配置、負載平衡、擴展以及健康監控從而減少你的管理壓力。
  5. Lambda：它允許你只在你需要的時候運行代碼而不用去管理服務器。
  6. Batch：它使用户能夠以自定義的管理方式運行計算工作負載（批處理）。

存儲型服務 ​

它是一種雲存儲服務，即由 Amazon 提供的雲存儲設施。 該組服務包括：

  1. S3：S3 代表簡單存儲服務（3 個 S）。 它給你提供了在線存儲服務，你可隨時從任何地方存儲/檢索任何數據。
  2. EFS：EFS 代表彈性文件系統。 它是一個可以和 EC2 服務器一起使用的在線存儲服務。
  3. Glacier：它是一種低成本/低性能數據存儲解決方案，主要針對存檔或長期備份。
  4. Storage Gateway：這種服務的接口會將你的內部應用程序（託管在 AWS 之外）與 AWS 存儲連接。

資料庫 ​

AWS 還提供在其基礎設施上託管資料庫，以便客户可以利用亞馬遜最先進的技術來獲得更快/高效/安全的數據處理。 該組包括：

  1. RDS：RDS 代表關係資料庫服務。 用於在雲上設置，操作和管理關係資料庫。
  2. DynamoDB：其 NoSQL 資料庫提供了快速處理和高可擴展性。
  3. ElastiCache：這是一種為你的 Web 應用程序管理內存緩存以便更快運行它們的方案 ！
  4. Redshift：它是一個巨大的（PB 級）的完全可升級的雲端數據倉庫服務。

網絡 & 內容分發 ​

由於 AWS 提供雲端的 EC2 服務器，因此網絡相關內容也將在出現在這裏。 內容分發用於向位於最近位置的用户提供文件。 現如今有許多非常有名的加速網站。

  1. VPC：VPC 代表虛擬私有云。 它是你自己的虛擬網絡，是你的專用 AWS 帳户。
  2. CloudFront：這是 AWS 的內容分發網絡（CDN）服務。
  3. Direct Connect：它是將數據中心/場所與 AWS 連接起來的網絡方式，以提高吞吐量，降低網絡成本，並避免由於基於互聯網的連接而導致的連接問題。
  4. Route 53：它是一個雲端的域名系統的 DNS Web 服務。

遷移 ​

它提供了一系列服務來幫助你實現本地服務到 AWS 的遷移工作。 這包括 ：

  1. Application Discovery Service：專門用於分析您的服務器、網絡、應用程序以幫助/加速遷移的服務。
  2. DMS：DMS 指的是資料庫遷移服務。 它用於將數據從本地資料庫遷移到 EC2 上託管的 RDS 或 DB。
  3. Server Migration：也稱為 SMS（服務器遷移服務）是一種無代理服務，將您的工作負載從本地移動到 AWS。
  4. Snowball： 當你想要使用物理存儲設備（而不是基於互聯網/基於網絡的傳輸）將大量數據傳入/遷出 AWS 時，你應該使用它。

開發者工具 ​

顧名思義, 這是一系列幫助開發者簡化在雲端編碼的服務。

  1. CodeCommit：它是一個安全的、可擴展的、可管理的源代碼管理服務，用於託管代碼倉庫。
  2. CodeBuild：這是一個雲端的代碼生成器。主要用於執行、測試代碼和構建部署軟件包。
  3. CodeDeploy：這是一個可在 AWS 服務器或本地進行自動化應用程序部署的部署服務。
  4. CodePipeline：這個部署服務可以使編碼人員可以在發佈之前將其應用程序可視化。
  5. X-Ray：它可以使用事件調用分析應用程序。

管理工具 ​

這是一組可幫助你管理 AWS 上的 Web 服務的服務。

  1. CloudWatch：監控你的 AWS 資源或應用程序的監控服務。
  2. CloudFormation：基礎設施即代碼！以集體有序的方式管理 AWS 架構的方式。
  3. CloudTrail：AWS 帳户的審計和合規工具。
  4. Config : AWS 的資源清單、配置歷史記錄和配置更改通知，以實現安全性和治理。
  5. OpsWorks：它可以自動化地配置，部署 EC2 或內部部署計算。
  6. Service Catalog：創建和管理被批准在你/公司帳户中使用的 IT 服務目錄。
  7. Trusted Advisor：它的 AWS AI 可以通過審查你的 AWS 基礎設施使你的 AWS 基礎設施更好，更省錢。
  8. Managed Service：提供持續的基礎設施管理。

安全性、身份和合規 ​

這是一組很重要的 AWS 服務以確保你的 AWS 空間的安全性。

  1. IAM：IAM 即身份和訪問管理，控制用户訪問你的 AWS 資源和服務。
  2. Inspector：自動安全評估可幫助你在 AWS 上的應用安全和合規。
  3. Certificate Manager：為 AWS 應用程序提供，管理和部署 SSL / TLS 證書。
  4. Directory Service：相當於 AWS 的 Microsoft Active Directory。
  5. WAF & Shield：WAF 即 Web 應用防火牆。 監控和控制對 CloudFront 或負載均衡器上的內容的訪問。
  6. Compliance Reports：AWS 基礎設施空間的合規報告，以確保您的應用程序符合您的策略。

數據分析 ​

AWS 空間的數據分析服務，以幫助您查看、計劃和對帳户中的事件採取行動。

  1. Athena：它是一個基於 SQL 查詢的服務，用於分析 S3 存儲的數據。
  2. EMR：EMR 的全寫是 Elastic Map Reduce。 是一個主要用於大數據處理和分析的服務。
  3. CloudSearch：AWS 在應用和服務中的搜索功能。
  4. Elasticsearch Service：它可以創建一個域並在 AWS Cloud 中部署、操作和擴展 Elasticsearch 集羣。
  5. Kinesis：這種服務可以實現實時的大量流數據處理。
  6. Data Pipeline：它可以幫助我們在不同的 AWS 服務之間實現數據遷移。
  7. QuickSight：收集、分析和呈現 AWS 的業務數據。

人工智能 ​

AWS 的 AI!

  1. Lex：它可以幫助我們在一些使用語音和文本的應用中構建會話界面。
  2. Polly：這是一個提供文字到語音轉換的服務。
  3. Rekognition：使您能夠將圖像分析添加到應用程序。
  4. Machine Learning：它具有學習數據中的模式的算法。

物聯網 ​

這個服務保證了 AWS 在不同設備上的高可用性。

  1. AWS IoT：它使聯網硬件設備與 AWS 的應用程序能夠交互。

遊戲開發 ​

顧名思義，這個服務旨在遊戲開發。

  1. Amazon GameLift：該服務旨在部署、管理用於會話的多人遊戲的專用遊戲服務器。

移動服務 ​

這是一組主要針對手持設備的服務。

  1. Mobile Hub：幫助您創建移動應用的後台功能並將其集成到移動應用。
  2. Cognito：在連接了互聯網設備上控制移動用户的身份驗證和 AWS 的訪問。
  3. Device Farm：移動應用測試服務使你可以在 Android 上託管的真實手機上跨 Android、iOS 測試應用。
  4. Mobile Analytics：在 AWS 上測量、跟蹤和分析移動應用數據。
  5. Pinpoint：針對性的推送通知和移動互動。

應用服務 ​

這是一組可以和你在 AWS 上的應用一起使用的服務。

  1. Step Functions：定義和使用應用程序中的各種功能。
  2. SWF：SWF 代表簡單的工作流服務。其雲工作流程管理可幫助開發人員在應用程序生命週期的不同階段進行協調和貢獻。
  3. API Gateway：幫助開發人員創建、管理和託管 API。
  4. Elastic Transcoder：幫助開發人員將媒體文件轉換為在各種設備上可以播放的格式。

消息 ​

AWS 中的通知和消息服務。

  1. SQS：SQS 表示簡單隊列服務。完全管理的消息隊列服務，用於在 AWS 中的服務和應用之間進行通信。
  2. SNS：SNS 代表簡單通知服務。 為 AWS 用户推送通知服務，提醒他們有關其在 AWS 空間中的服務。
  3. SES：SES 代表簡單電子郵件服務。 這是 AWS 為自己的客户提供高性價比的電子郵件服務。

企業生產率 ​

一組幫你提高業務生產率的服務。

  1. WorkDocs：協同文件共享、存儲和編輯服務。
  2. WorkMail：安全的商務郵件、日程服務。
  3. Amazon Chime：在線的企業會議！

桌面和應用程序流式傳輸 ​

實現桌面應用程序通過雲端進行流傳輸。

  1. WorkSpaces：完全管理且安全的雲計算服務。
  2. AppStream 2.0：來自雲端的流式桌面應用。
