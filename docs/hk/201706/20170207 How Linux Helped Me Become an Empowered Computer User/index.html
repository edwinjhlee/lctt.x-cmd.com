Linux 讓我對電腦有了更深刻的理解 ​

我花了大量時間和耐心在 Linux 上，我的朋友們都能為我證明這點。説起來你可能不信，兩年前我還根本不知道 Linux 是什麼，放棄 Windows 轉投 Linux 更是不可能。

雖然轉投 Linux 這事有點跳躍，但事後證明這是很明智的選擇。口説無憑，分析一下我的路線可能會更有説服力一點。通過這個路線來説説我是怎麼從小白到精通 Linux 桌面系統的。

安全意識的覺醒 ​

兩年前我也是像一般的 Windows 用户一樣，在 Windows 操作系統下工作。雖然我也有跟進了解主流的科技新聞的習慣，但是對計算機我也説不上深刻了解。

2013 年夏天，美國國家安全局的一份情報項目報告讓我對個人隱私安全的態度迅速發生了變化。愛德華斯諾登揭露的網絡監控的廣度令人不安，而且也凸顯出，我們大多數人——甚至不知道如何做——來保護自己的隱私。

在之前我沒有對電腦或它們在我的個人事務中所扮演的角色作出任何特別的考慮，我開始意識到控制一個人的數字生活，以及控制它的設備的重要性。

按理來説下一步應該是確定該怎麼去做。雖然我制訂的目標似乎是合乎邏輯的，但要實現它並不簡單。在接下來的幾個月裏，我把自己的空閒時間花在了互聯網上，尋找關於隱私保護、加密以及其它任何可以保護我的技術的指南。

專家們説想逃避情報機構的監控幾乎是不可能的。然而，這些專家們也會告訴你，能幫你避開那怕只是避開那麼一丟丟的監視 -- 在較小的機構中有相當比例的監控更有可能針對普通民眾 -- 唯一可行的辦法就是使用開源軟件。

Linux，我很快意識到需要去了解它，因為它是這些開源軟件的頭頭。

閉源與開源 ​

在進一步的研究中，我開始熟悉開源軟件的一些特點。我們每天使用的軟件的絕大多數 -- 從聊天軟件到操作系統，包括Windows -- 它們都是開源軟件的對立面：它們是閉源的。

例如，當微軟的開發人員在 Windows 上進行開發工作時，他們會用一些編程語言編寫源代碼，並且只在他們的團隊內部流傳這些代碼。當他們準備發佈軟件時，他們會編譯它，將它從人類可讀的代碼轉換成計算機運行的 1 和 0，面對這些機器碼，即使是最聰明的人也很難逆向工程到原始源代碼。

在這種模式下，只有軟件的開發者才知道這些軟件實際在做些什麼，有沒有私底下監控用户行為。

開源軟件會提供軟件的源代碼和編譯好的二進制代碼給公眾下載使用。不論是不是每個用户都有能力去閲讀這些源代碼，評估它們的安全性和隱私性，這都不重要。因為源代碼是公開的，總有那麼一部分人有這個能力做這些事，一但他們發現這些代碼有問題他們就能及時通知其它用户，讓公眾一起來監督這些開源軟件的行為，讓那些故意隱藏的惡意代碼片段或者非故意的代碼漏洞能及時被發現並處理掉。

經過徹底的研究之後，很明顯，唯一能保證我的隱私和用户的自主權的操作系統就是那些具備透明開放的源代碼哲學的操作系統。一位知識淵博的朋友和隱私倡導者推薦的最多的是 Linux。如果這是必須的話，我已經準備好接受一個艱難的過渡，但是我對隱私的重要性的信念給了我信心去嘗試。

嬰兒學步 ​

雖然我決心轉向 Linux 的是急切的，但飯得一口吃，路也得一步一步走。我是最開始是從安裝 Ubuntu 開始的 —— 一個容易配置對初學者很友好的 Linux 發行版 —— 在我的老筆記本電腦上它與原有的 Windows 相處融洽井水不犯河水。

每次啓動我的電腦時，我都能選擇 Ubuntu 或 Windows ，這樣我就能在 Linux 上找到自己的下腳點，同時保留熟悉的 Windows 以防前者可能缺失的一些輔助性功能。

不久後，一個硬盤驅動器損壞嚴重讓我無法再繼續享受這個設置，不過我認為這是一個機會，讓我考慮一下買一台 Linux 的新筆記本電腦。由於 Linux 對標準的英特爾處理器、圖形卡和無線適配器的驅動程序支持得很好，所以我買了一台聯想的 ThinkPad。

我做了一個全新的開始，完全擦除我的新機器上的 Windows ，安裝了 Debian ，這是一個廣泛兼容和穩定的發行版，Ubuntu 就是基於它衍生出來的。我不僅在沒有熟悉的 Windows 安全網絡的情況下挺過來了，我還在不斷的進步提高。我很快就沉浸在以前神秘的命令列世界裏。

在我用了一年的 Linux 操作系統之後，我又進行了一次冒險，安裝了 Arch Linux ，它需要一個更加複雜的手動用户安裝過程，並帶有完全的磁盤加密。那天晚上，我和一位 Linux 資深管理人士一起安裝了 Arch ，這標誌着我生命中最值得驕傲的成就之一。

在這個過程中，我面臨着挑戰 -- 有時，在Windows上無縫工作的應用程序需要額外的步驟或需要安裝必要的驅動 -- 但是我克服了它們，或者説繞過它們，繼續按照我自己的節奏摸索 Linux。

全速前進 ​

就我而言，那時我才真正開始進行我的學習。我用 Linux 來駕馭計算機，並確保它可以為我工作，不過最讓我着迷的是它提供對系統進行修改的自由和個性化處理。

作為一個開源操作系統，Linux 是無限開放的。儘管我最初期望花時間閲讀安全實踐（我現在仍然這麼做），但我也發現自己深入到配置面板中，並把所有的顏色、圖標和菜單都列出來，只是這樣而已。

我花了一些時間去適應，但我越是投入到新事物中，我就變得越自信，越好奇。

自從在這條路上走了兩年多以後，我在電腦上從來沒有像今天這麼多的感受。我不能像我想要的那樣去個性化 Windows，另外依據我從開源社區學到的東西來看，我也不能完全信任它。

有一個叫電腦的東西，它曾經只是我的的一件不起眼的硬件設備，現在它和我之間的關係變得非常美妙 —— 超越記者和他的筆記本、也超越小提琴家和他的小提琴的關係。

我甚至為自己的手機不像我的筆記本電腦那樣是真正的 Linux 而感到悲哀，我都不知道我能對它做些什麼。不管怎麼樣，我將繼續對我的 Arch 系統進行優化，只要有機會我將會再去發現新的領域並探索新的可能性。
