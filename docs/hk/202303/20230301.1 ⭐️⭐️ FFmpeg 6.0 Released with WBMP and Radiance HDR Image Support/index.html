FFmpeg 6.0 發佈：支持 WBMP 和 Radiance HDR 圖像 ​

開源多媒體框架 FFmpeg 6.0 現已發佈，帶來了更新和改進。

流行的開源多媒體框架 FFmpeg 6.0 現已發佈。這個主要的版本現在已可下載，並在多媒體項目中使用。其亮點變化包括兩個新的圖像格式支持，許多編解碼器和其他增強功能。

下面是一個快速回顧。

FFmpeg 6.0 新增內容 ​

主要變化 ​

這個版本的主要亮點是對兩種新圖像格式的支持。Radiance HDR 圖像（RGBE）為用户在圖像處理中提供了更好的色彩深度和動態範圍。FFmpeg 6.0 現在包括對 WBMP（無線應用協議位圖） 圖像格式的支持，這在移動設備和網絡應用中是常用的圖像格式。

在 FFmpeg 6.0 中，新的 -shortest_buf_duration 選項允許用户為音頻和視頻緩衝區設置一個最小的持續時間，這可以確保在輸出文件中使用最短的緩衝區時間。

從 FFmpeg 6.0 開始，線程必須被內置到軟件中才能運行。在這個版本中，每個複用器都在一個單獨的線程中運行。這提高了性能，使同時處理多個流的效率更高。

FFmpeg 6.0 中的 cropdetect（裁剪檢測）過濾器現在包括一個新的模式，可以根據運動向量和邊緣檢測裁剪區域，為用户提供更精確的視頻裁剪控制。

過濾器 ​

在這個版本中，大量的過濾器得到了更新，這將通過新的功能簡化你的多媒體項目和工作流程。下面是一個快速的變化列表：

  • ddagrab 過濾器現在支持桌面複製視頻捕獲，允許用户直接從他們的桌面上捕獲視頻。
  • a3dscope 過濾器為用户提供了音頻信號的 3D 範圍顯示，允許更精確的音頻編輯和處理。
  • backgroundkey 過濾器允許用户刪除或替換視頻片段中的背景，為視頻編輯提供更大的靈活性。
  • showcwt 多媒體過濾器允許用户將連續小波變換系數可視化，提供對信號和圖像處理的洞察力。
  • corr 視頻過濾器對視頻幀進行二維交叉關聯，提供更精確的運動估計和穩定。
  • ssim360 視頻過濾器計算兩個視頻幀之間的 結構相似度指數（SSIM），為衡量 360 度視頻的視頻質量提供了一個指標。

編解碼器 ​

在這個版本中，編解碼器的更新是非常多的。

首先，FFmpeg 6.0 現在支持 NVENC AV1 編碼，允許用户使用英偉達最新的壓縮技術對視頻進行編碼。MediaCodec 解碼器現在支持 NDKMediaCodec，為安卓設備提供更好的兼容性。其次，增加了一個新的 MediaCodec 編碼器，允許在安卓設備上進行視頻編碼時進行硬件加速。

在此基礎上，該版本包括了對 QSV（快速同步視頻）的 oneVPL 支持，在英特爾 CPU 上進行視頻編碼時提供了更好的性能和質量。QSV AV1 編碼器允許用户在英特爾 CPU 上使用硬件加速對 AV1 視頻進行編碼。

這個版本引入了對 10/12 位 422、10/12 位 444 HEVC 和 VP9 的 QSV 編解碼支持，為用户提供更好的視頻質量和性能。WADY DPCM 解碼器和解複用器允許用户使用 WADY DPCM（差分脈衝編碼調製）格式對音頻進行解碼和解複用，這種格式通常用於視頻遊戲配樂。

此外，現在還有一個 CBD2 DPCM 解碼器，它允許用户使用 CBD2（共軛結構代數編碼簿差分脈衝編碼調製）格式解碼音頻。這種格式通常用於電信和語音編碼應用。

其他變化 ​

這個變化清單很龐大，其中還包括 FFmpeg 程序的新 CLI 選項和其他錯誤修復。你可以在 GitHub 上閲讀詳細的 變更日誌。

下載和安裝 ​

對於 Debian、Ubuntu 和相關的發行版，這個版本應該在幾天內到達。請在 Debian 跟蹤頁 中留意。

對於 Fedora、RHEL、CentOS，你可以通過 RPM Fusion 倉庫獲得這個版本。如果你已經設置了 RPM Fusion，請更新你的系統以獲得它。

源代碼和其他下載都可以在 這裏 下載。

另外，你可以在這裏查看我們的獨家文章中如何安裝FFmpeg和基本使用方法。

如何在 Ubuntu 和其他 Linux 中安裝 FFmpeg

總結 ​

有了 Radiance HDR 圖像支持等新功能，以及對各種編解碼的改進支持，FFmpeg 6.0 為用户提供了強大的音頻和視頻處理工具。

新的過濾器變化提供了先進的音頻和視頻處理能力，從去除或替換視頻中的背景到執行運動估計和穩定。

總的來説，這是一個重要的里程碑式的更新，為音頻和視頻處理工作負載提供了更好的性能和更大的靈活性。
