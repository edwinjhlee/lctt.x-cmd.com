Ubuntu 23.04 “Lunar Lobster” 的最佳新功能 ​

介紹最新的 Ubuntu 23.04 “Lunar Lobster” 版本，它包含了大量的新功能和改進。

代號為 “月球龍蝦Lunar Lobster” 的 Ubuntu 23.04 是 2023 年的第一個短期版本，它將被支持 9 個月，直到 2024 年 1 月。這個版本採用了新的軟件包和技術來改進 Ubuntu 的核心後台和進展工作。在某種程度上，許多變化是作為明年的 LTS 版本（Ubuntu 24.04）的準備工作而被確定的。

它的開發週期幾乎接近結束。截至發稿時，測試版已經凍結。所以，現在是探索這個版本的新功能的好時機。

但在此之前，先來看看即將到來的里程碑：

  • 測試版凍結： 2023 年 3 月 27 日
  • 測試版發佈： 2023 年 3 月 30 日
  • 候選版本：2023 年 4 月 13 日
  • 最終版本：2023 年 4 月 20 日

Ubuntu 23.04 的新功能 ​

新的桌面安裝程序 ​

Ubuntu 新的基於 Rust 的桌面安裝程序終於可以在這個版本中體驗了。這項工作歷經了兩年多的時間。在經歷了許多障礙和關鍵錯誤的修復後，現在已經穩定到可以在正式版本中發佈。從這個版本開始，經典的 Ubiquity 被全新的安裝程序所取代，如下面一組圖片所示：

然而，正如我從一些消息來源聽到的，舊的 Uqiuity 將繼續保留（直到明年）。但我不完全確定舊的安裝程序將如何啓動。因為默認的 立付介質Live Media 會啓動新的安裝程序。

與舊安裝程序的相比，新的有一些變化。首先，相對於舊的 Uqiuity 對話框和小工具控制，外觀和感覺更加現代。

關於分區的摘要細節現在作為一個單獨的頁面出現，而不是一個彈出框。

此外，Ubuntu 23.04 現在在安裝前會詢問深色/淺色模式選項。我不確定這樣做的必要性，因為 Ubuntu 已經在一個單獨的應用程序中定義了一些開箱步驟。

GNOME 44 桌面 ​

Ubuntu 23.04 桌面版採用了 GNOME 44。這個版本的 GNOME 44 帶來了一堆長期等待的更新。例如，在這個版本中，你可以在本地文件選取器對話框中體驗到圖像預覽。此外，文件應用得到了期待已久的缺失功能，即原生的文件夾展開視圖（樹狀視圖）。你可以使用下面的設置來啓用它。

在 GNOME 44 中的其他關鍵變化包括：文件應用現在支持在粘貼圖像數據時創建文件，改進的無障礙設置頁面可以提供更好的導航，以及大大改進的 GNOME 網頁瀏覽器。

精簡 ISO 鏡像 ​

這是一個令人驚訝的舉動，Ubuntu 團隊在這個版本中 引入 一個官方的精簡 ISO 鏡像（不到 200MB）。一旦發佈，你可以使用這個精簡 ISO 鏡像來創建自定義的 Ubuntu Linux。截至發稿時，我們還沒有得到這個精簡鏡像的日常構建 ISO。

然而，Xubuntu 團隊 已經發布了 一個精簡 ISO 鏡像，我嘗試了一下。同樣地，所有的官方風味版都有望得到他們自己的精簡 ISO 文件。

更多的信息將在未來幾天內到達。

多用 Snap，少用 Flatpak ​

一些與 Snap 和 Flatpak 相關的重要變化即將到來，你應該為此做好準備。

首先，推行更多的 Snap 包是顯而易見的，因為官方 Telegram 桌面應用程序現在在 Ubuntu 中使用 Snap 包。

此外，Ubuntu 計劃將 Steam 桌面客户端作為 Snap 包發佈，該客户端 目前正在測試中。Steam 桌面客户端現在以原生 deb 和 Flatpak 包的形式提供。Steam Snap 預計將在今年年底到來，而不是在這個版本中。

與此同時，默認的 Flatpak 和 Flathub 集成現在已經正式從所有支持的 Ubuntu 官方風味版中 移除。這個決定在網上引起了一些 “討論”。

因此，從這個版本開始，Ubuntu MATE 和 Kubuntu 將不會默認搭載 Flatpak/Flathub。然而，你可以通過 只需幾個步驟 安裝它。

新的應用程序 ​

Ubuntu 23.04 的默認應用程序集合一如既往地進行了升級。然而，你可能會注意到一些關鍵的變化。

首先，LibreOffice 可能看起來有點不同。LibreOffice 團隊最近改變了默認的圖標主題，在 Ubuntu GNOME 的桌面環境中，它看起來非常棒。

在這個版本中包含的 LibreOffice 7.5 中， Writer 有一個改進的書籤模組，Calc 電子表格有了新的數字格式，Impress 有了新的表格設計風格等等。

你可以在這裏閲讀更多關於 LibreOffice 7.5 的功能。

Ubuntu 23.04 中其他應用程序的總結：

  • Firefox 111（Snap）
  • LibreOffice 7.5
  • Transmission 3.0
  • Shotwell 圖像查看器 0.30

官方風味版 ​

對於所有的教育工作者和學生來説，有一個好消息。從 23.04 版本開始，Edubuntu 將 正式出現。它是 Ubuntu 官方風味版列表中的另一個補充。Edubuntu 可能會有一個更大的 ISO 文件（大約 5GB），並安裝了所有與教育有關的 FOSS 軟件。我將會有一篇單獨的文章來點評這個風味版。

此外，如下的風味版都有其對應的桌面環境：

  • 配備 KDE Plasma 5.27 的 Kubuntu
  • 配備 Xfce 4.18 的 Xubuntu
  • 配備 MATE 1.26.1 的 Ubuntu MATE
  • 配備 LXQt 1.2 的 Lubuntu
  • 配備 Budgie 10.7 的 Ubuntu Budgie

Ubuntu Budgie 23.04 帶來了一些令人興奮的功能，如邊緣平鋪、熱角等。

內核和工具鏈更新 ​

截至發稿時，每日構建副本都是 Linux 內核 6.1。然而，在內核凍結（2023 年 4 月 6 日）之前，目前的主線內核 6.2 可能會到達 Ubuntu 23.04。Linux 內核 6.2 改進了對 GPU、CPU、端口和 Rust 更新的支持。

在核心部分，Python 3.11 現在可以在 Ubuntu 23.04 中開箱即用。你不需要再單獨 安裝 Python 3.11。值得一提的是，Python 3.12 版本將在今年發佈，目前正在進行多次 RC 測試。

其他工具鏈的更新如下：

  • GCC 13
  • GlibC 2.37
  • Ruby 3.1
  • golang 1.2
  • LLVM 16

總結 ​

總之，新的 Ubuntu 23.04 有望為桌面用户提供更流暢、更無縫的體驗。

從改進的安全功能到增強的生產力工具和應用程序，這次更新肯定會讓 Ubuntu 的愛好者和粉絲感到高興。無論你是經驗豐富的用户還是 Ubuntu 生態系統的新手，這個版本都值得一看。

最後，Ubuntu 23.04 將於 2023 年 4 月 20 日發佈。
