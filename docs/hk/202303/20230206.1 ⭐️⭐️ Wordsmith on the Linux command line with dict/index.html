在 Linux 命令列上使用 dict 文字工具 ​

Linux 上的 dict 命令對作家來説非常有用，可以為他們的選詞提供大量的字典和同義詞。

作為一個作家，我經常需要確定單詞的正確拼寫或定義。我還需要使用詞庫來尋找替代詞，這些詞的內涵可能與我可能使用的詞有些不同。因為我經常使用 Linux 命令列和文本模式工具來完成我的大部分工作，所以使用命令列詞典是有意義的。

我非常喜歡使用命令列，原因有很多，其中最主要的原因是它對我來説更有效率。它也比任何一本或多本實體紙質字典，都要全面得多。我使用 Linux 的 dict 命令已經很多年了，我已經開始依賴它了。

在 Linux 上安裝 dict ​

dict 程序在 Fedora 上沒有默認安裝，但它很容易安裝。以下是如何在 Fedora 或類似發行版上安裝：

$ sudo dnf install dictd

在 Debian 和類似發行版上，你還必須安裝字典定義：

$ sudo apt install dictd dict-gcide

不需要額外的配置。這個非常簡單的 /usr/share/doc/dictd/dict1.conf 文件指定了字典資料庫的遠程服務器。這個工具使用字典服務器協議（DICT），端口為 2628。

在 Linux 上使用 dict ​

在終端會話中，以非 root 用户的身份，輸入 dict <word> 來獲取一個或多個字典和詞庫的定義列表。例如，以這種方式查找 memory 這個詞。

$ dict memory | less
6 definitions found

字典 ​

dict 命令使用一些在線字典，包括法律和技術字典。許多語言的字典也是可用的。你可以“列出”可用的字典資料庫，如下面所示：

你可以用 -d 選項指定單個字典：

$ dict -d gcide

總結 ​

有時使用詞庫中的詞彙並不是最好的寫作方法，因為它可能會混淆你的意思。但我確實發現 dict 命令在為特定的意思選擇最好的詞方面有極大的幫助。它還能確保我使用的單詞拼寫正確。

關於 dict 的信息很匱乏。 這個 URL http://www.dict.org/ 只提供了一個基於網絡的字典界面。手冊頁涵蓋了語法。但是這個命令是一個有用的、有趣的命令，可以隨身攜帶。我承認在發現 dict 命令後，我花了很多時間嘗試不同的東西，看看結果會是什麼。我就是那個通讀百科全書和字典的孩子。是的，我是_那個_孩子。除了在寫作或閲讀時是一個有用的工具外，dict 也可以是一個有趣的工具來滿足一下好奇心。
