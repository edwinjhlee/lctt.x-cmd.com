Linux 上 5 款最好的 EPUB 閲讀器 ​

你正在尋找 Linux 上最好的 EPUB 閲讀器？這裏是為你準備的最好的自由開源的 EPUB 閲讀器。

你是一位熱衷於閲讀電子書的 Linux 用户嗎？如果，是的，你必然知道在 Linux 發行版上的默認文檔閲讀器不能滿足你作為一名書蟲的所有要求。

EPUB 是一種廣泛使用的開放電子書格式，大多數的電子書閲讀器都支持。值得慶幸的是，在 Ubuntu 軟件中心和其它存儲庫中有一些 EPUB 閲讀器應用程序，你可以自由下載它們。.

但是，請記住，僅有幾個好用的閲讀器。並不是有很多！

在這篇文章中，我們將討論在 Ubuntu Linux 上的最好的 EPUB 閲讀器，這將增強你的閲讀體驗。我們也將探討它們的特色功能和優點，以便你可以選擇一個適合你的應用程序。

但是，在此之前，你認為在一個 “令人滿意的” EPUB 閲讀器中，應該有哪些功能呢？

在一款 EPUB 閲讀器中所應該有的功能 ​

  • 用户界面：一款好的 EPUB 閲讀器應該有一個簡單易懂的用户界面，它會使導航和自定義你的閲讀體驗變得簡單。你並不是在閲讀一本實體書，因此，對於 “實體書” 的閲讀體驗來説，用户界面是極其重要的！
  • 自定義：擁有自定義字體大小、字體類型、背景顏色和其它設置的能力，它們將增強你的閲讀體驗。
  • 書架：書架是一種很方便的特色功能，它允許你組織你的 EPUB 文件和保持追蹤你的閲讀進度。
  • 註釋：在你的 EPUB 文件中，高亮顯示、下劃線和添加註釋是一種很重要的特色功能，它會幫助你記住重點。
  • 同步：如果你在多台設備上閲讀 EPUB 文件，同步你的閲讀進度和書籤是非常重要的，可以避免丟失你的追蹤進度.

現在，讓我們看看為 Ubuntu 和其它的 Linux 發行版提供的最好的 EPUB 閲讀器，它們都涉及上述所有的特色功能。

在 Ubuntu 和其它 Linux 發行版上的最好的 EPUB 閲讀器 ​

Calibre ​

在這份列表上的第一款閲讀器是 Calibre ，它是最好的和最完善的電子書管理解決方案。它是一款功能強大的 EPUB 閲讀器，也提供電子書管理工具。它在用户中是一種流行的選擇，因為它有豐富的特色功能集，包括：轉換 EPUB 文件到不同的格式、編輯 EPUB 文件，甚至創建你自己的 EPUB 文件的功能。Calibre 也有一個用户友好的界面，允許你自定義你的閲讀體驗。

Calibre 正在持續更新，每個月都會有大量的特色功能和增強的功能。它的開發活動是非常活躍的，它是這份列表中最好的一個。

功能摘要：

  • 支持多種電子書設備（基於安卓、iOS 的設備）
  • EPUB 閲讀器和管理器
  • 為你的電子書庫評級和標記
  • 從互聯網獲取電子書的元數據
  • 從流行的新聞源處閲讀新聞，並製作電子書！
  • 使用自動轉換器來上傳電子書到 Kindle 和其它的閲讀器（當然，也可以下載）
  • 內置可購買電子書的瀏覽器

你可以從其官方網站下載 Calibre 。或者，你可以為你的 Linux 發行版 設置 Flatpak & Flathub ，並單擊下面的按鈕（或使用命令）來安裝：

使用 Flatpak 來安裝 Calibre

flatpak install com.calibre_ebook.calibre

針對其它的下載選項（Windows、macOS 和原生的 Linux 軟件包），請訪問 這個網頁。

Foliate ​

我們在先前的 最佳的 Ubuntu 應用程序（第 3 部分） 系列中介紹了 Foliate 。它是一款輕量現代的 EPUB 閲讀器，它提供了一系列的自定義選項。它是基於 GTK4 的，並且與 GNOME 桌面環境無縫集成。它有一個平滑且易於導航的界面，並且有自定義字體大小、字體類型和行距的功能。

Foliate 也包含：一種針對夜間閲讀的深色模式，一個調整內置顏色温度的選項，用以減少眼睛疲勞。

功能摘要：

  • 沉浸式視圖，主頂部工具條在閲讀時自動隱藏
  • 列入目錄視圖，支持從主要的電子書網站直接下載
  • 多屏視圖 – 雙頁面視圖和滾動視圖
  • 自定義字體和行距
  • 內置亮度控制，僅應用於應用程序本身！
  • 閲讀進度滑塊
  • 支持書籤和註釋
  • 在書中搜索
  • 快速字典查找

下載 Okular 的最好方式是使用 Flatpak 來下載。針對你的系統設置 Flatpak & Flathub ，並使用下面的鏈接（或使用下面提到的命令）來安裝它：

使用 Flatpak 來安裝 Foliate

flatpak install com.github.johnfactotum.Foliate

要學習更多關於 Foliate 的信息，訪問官方 網站。

Okular ​

KDE 自帶的文檔閲讀器是 Okular ，它也支持 EPUB 文件。它是一款功能豐富的應用程序，它提供了一系列自定義選項，包括：字體大小、字體類型和背景顏色。Okular 也有內置註釋功能，你可以使用它來註釋你的 EPUB 文件。它也支持很多文件格式：

  • EPUB
  • PDF
  • DjVU
  • 圖形文件: JPEG 、PNG 、GIF 、Tiff 、WebP
  • 漫畫文件: CBR 和 CBZ

不過，你不能使用 Okular 來管理收藏或下載電子書。

你可以在 Ubuntu 及其相關發行版中安裝 Okular ：

sudo apt install okular

針對 Fedora 及其相關發行版：

sudo dnf install okular

如果你更喜歡 Flatpak ，將你的系統設置為 Flatpak ，並使用下面的鏈接（或使用下面提到的命令）來安裝 Flatpak：

使用 Flatpak 格式安裝 Okular

flatpak install org.kde.okular

Bookworm ​

在這份列表上的下一個 EPUB 閲讀器是 Bookwork ，在我看來，它完全被低估了。它確實是一款 elementary OS 的應用程序，但是，對於所有的 Linux 發行版來説都是可以安裝的。

它有簡潔的界面，並提供一系列自定義選項，包括字體大小、字體類型和背景顏色。Bookworm 也允許你將你的 EPUB 文件組織到集合中，並保持追蹤你的閲讀進度。

另外，你可以使用一個內置的標籤編輯器和評分系列來輕鬆地管理你的 EPUB 書籍。此外，它也支持註釋、搜索、章節和鍵盤導航。

不可缺少的是，它支持 EPUB 、MOBI 、PDF 、EB2 、CBR 和 CBZ 文件。

安裝是很容易的。如果你是一名 elementary OS 用户，你可以在 應用中心AppCenter 中搜索 “bookworm” 。

針對 Ubuntu 及其相關發行版，你可以使用下面的 PPA 來安裝它：

sudo add-apt-repository ppa:bookworm-team/bookwormsudo 
apt-get update
sudo apt-get install com.github.babluboy.bookworm

如果你更喜歡 Flatpak ，將你的系統設置為 Flathub 和 Flatpak ，並使用下面的鏈接來安裝它：

flatpak install com.github.babluboy.bookworm

要學習更多的信息，訪問官方 網站。

FBReader ​

在這份最好的 EPUB 閲讀器列表中最後一款應用程序是 FBReader 。在你繼續閲讀之前，注意：它在 2015 年以前是開源軟件。但是，它現在是閉源軟件，不過，有一個開發者 SDK 是可用的。

它是一款流行的多功能的 EPUB 閲讀器，所有的 Linux 發行版都可以獲取使用。它有一個簡單且用户友好的界面，允許你自定義你的閲讀體驗。FBReader 也支持各種電子書格式，包括：EPUB 、MOBI 、FB2 和 HTML 。它也提供一種書架特色功能，允許你組織你的電子書和保持追蹤你的閲讀進度。

FBRedaer 也支持在你的設備之間雲同步你的庫。

在 Linux 上安裝 FBReader 是有一些難度的，因為它只提供 Snap 軟件包。你可以在 針對 Snap 設置你的系統 後，使用 snap 來安裝它，如下所示。

sudo snap install fbreader

要學習更多關於 FBReader 的信息，訪問官方 網站。

在 Linux 上的更多的 EPUB 閲讀器 ​

Koodo reader ​

它是一個相當新的自由及開源的 EPUB 閲讀器，帶有大量的特色功能。並且它也看起來極好。唯一的問題是，它是使用 Javascript 、HTML 和 TypeScript 構建的。因此，它不是原生的應用程序，但是它是很快的。你可能會想嘗試一下。在 Linux 上，Koodo reader 提供 AppImage 、本機的 deb 和 RPM 文件。

你可以 在這裏下載 ，這裏是一些截屏。

這裏還有另外的兩個 EPUB 閲讀器，但是，不幸的是，它們已經不再繼續開發了。

  • GNOME Books
  • epub CLI reader

總結 ​

總而言之，在 Linux 上有幾個可用的 EPUB 閲讀器，它們提供大量的特色功能來增強你的閲讀體驗。如果你正在尋找一個功能豐富的 EPUB 閲讀器，Calibre 是一個極好的選擇，它也可以作為一個電子書管理器工具。Foliate 和 Bookworm 是一個輕量的現代的應用程序，非常適合那些看重自定義選項的人。

我希望通過上述的比較和詳細的描述，你現在可以為你自己選擇最好的 EPUB 閲讀器了。
