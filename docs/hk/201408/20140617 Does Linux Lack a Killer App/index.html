Linux 缺乏一款殺手級應用程序嗎？ ​

Linux 最需要的就是遊戲， Hyperlogos 的博主 Martin Espinoza 如是説。然而，“如果您把它限定到一款應用程序的話，最需要的很可能仍是 Photoshop 。儘管大家都在談論 GIMP 已經變得多麼多麼強大，但它的易用性仍然是個悲催的噩夢；雖然開源社區有些相關的文檔，但 GIMP 仍是處在缺乏文檔的可憐狀態。”

這些日子這兒越來越熱了，Linux Blog世界和 FOSS 論壇的粉絲們都蜂擁入帶有破窗的休息室，邊吹着冷空調，邊討論此話題。

甚至是 Linux Girl，這些天也被這些越來越多的潮流所衝擊，正在 blogobar 上尋求能使其降温的慰籍，而且越來越頻繁。

雖然她們這樣做比較正確，但或許她們已經錯過了最鮮最美味可口的辯論大餐。“Linux 缺少什麼樣的殺手級應用程序？”這個問題已經擴大化了,關於此的討論越演越烈，已經超出以往任何時候。

“開源軟件世界的軟件是如此令人難以置信的豐富，幾乎涵蓋了所有的領域，” Linux Voice 的 Mike Saunders 開頭説到。“我們有桌面端的、服務端的、開發相關的及多媒體工具等一大筆來自開源世界的財富可以選擇 -- 其中的某些還是在相關領域中最好的呢。”

“但還缺少什麼嗎？” Sanders 接下來提出可爭議的話題。“是不是存在一款殺手級應用程序，它會使你的主機不能 24x7 小時的在運行？”

參與者圍繞着吧枱考慮這話題的時候，出現了短暫的間歇。Linux Girl 也享受着這短暫的平靜，但並沒有持續多久。

'取決於您的所需' ​

“很久以前，Linux 需要很多東西，” Google+ 的博主 Alessandro Ebersol 發言了。“當任何軟件和廚房水槽都遷移到雲端的那些日子，做任何的事情都得考慮多平台兼容性。”

“我想説的是我們缺少遊戲，但這種情況也正在被改變，” Ebersol 説道。“所以我覺得我們並不是那麼迫切的需要一個殺手級應用了。”

“殺手級應用程序？取決於你想用計算機做什麼，” consultant 和 Slashdot Blog的 Gerhard Mack 認為。“如果您正準備擬稿做設計，那麼殺手級應用程序就是 AUTOCAD 。但對其它行業來説殺手級應用程序將是別的。”

'企業平台空間' ​

Google+ Blog的 Kevin O'Brien 有相似的觀點。

“在消費級存在的應用程序不算太多，” O'Brien 説。“我雖然會抱怨遊戲或者 Nvidia 驅動程序，並且我看還沒有任何東西能真正替代 Quicken。（譯者注：Quicken 是一款家庭及個人財務管理軟件，可管理個人及家庭的日常收支、銀行卡、支票、信用卡及税務等財務信息，有着豐富的功能和簡單快捷的操作。）但對我來説最大的不同是企業平台空間。”

“微軟就擁有企業平台空間，沒有什麼比得過 Outlook/Exchange 服務, Sharepoint 等這些應用的，”他斷言到。“我猜測部分原因可能是真正關心這些的開源開發者很少很少。”

'浪潮正發生改變' ​

與其説是“缺乏應用程序”這種情況，不如説是“臨界的質量不夠”的問題，Google+ Blog Gonzalo Velasco C. 建議説。

比起五年前，現在用 Linux 的人已經越來越多了，他指出；但同時很人都依賴於非 Linux 友好的應用程序。

“雖然每個人都在使用 Skype ，但一大半的應用程序都是基於 GNU/Linux 協議的，從簡單易用的 Pidgin(我的最愛)到 Ekiga 和通用 VoIP 等等，” Gonzalo Velasco C. 解釋説。“一些用户仍宣稱他們需要 PhotoShop，並不想花時間來掌握和改進 GIMP、Inkscape、Bender 及其它的。”

“曾經是很缺乏遊戲，“但這狀況正發生改變，主要是（但並不是唯一）因為 Valve 的勇敢開創 SteamOS 之舉，”他補充道。

'零售貨架空間' ​

“我認為這段時期根本就沒有‘殺手級’應用程序，”Robert Pogson Blog上的觀點。“在 Debian GNU/Linux 系統上，有 40000以上 的軟件包，雖然我的 PC 只安裝了 3000 多的軟件，但我一樣都不缺。我有多個瀏覽器、編輯器、編譯器/解釋器、多個操作平台和像 KVM 這樣的虛擬機，我可以根據需要在多個操作系統和不同版本的軟件中盡情玩樂。”

“在局域網內，我可以把多台機器當做一台機器來使用，” Pogson 補充道。“在局域網內我能從任何機器上訪問存儲在任意節點的資源。還有什麼不能滿足的嗎？”

"有些説法，幾個專業人士告訴我，在 GNU/Linux 上的視頻和圖像編輯是有點弱，”他説。 “GIMP 正在比特級別的圖像上改進，所以應該不算了。Lightworks（譯者注：好萊塢級專業電影編輯軟件） 最終會被當做 FLOSS（譯者注：自由/開源軟件：世界影響研究） 發佈，所以視頻應該不算。”

"儘管如此，在 IT 行業中還有特少數的專業功能軟件，”他指出。“很多普通用户幾十年都不會使用那些極其特殊的應用程序軟件，所有我認為 GNU/Linux 系統已經不需要什麼了。”

但是真正的殺手在市場上，在零售商店缺乏貨架空間，Pogson 斷言到。“只要解決這問題，GNU/Linux 必定蓬勃發展。”

'Linux 已經輸給 OS X' ​

Chris Travers，一名工作於 LedgerSMB 的博主，有不同的觀點。

“我認為殺手級應用程序並不是關鍵問題，”他開始説到。“真正的問題是，雖然跟 BSD 系統一樣，Linux 正在佔據服務器市場，但在桌面市場 Linux 已經普遍輸於 OS X 了。Linux 用户正在尋找開放的桌面系統。”

Linux “既需要微軟的增長勢頭，又需要 OS X 系統的精緻用户界面和引人入勝的細節設計，”Travers 説到。“這些遲早會來有的。”

文檔問題 ​

“Linux 並不是缺少殺手級應用程序” -- "缺少的是一如既往的打磨拋光，" Hyperlogos 的博主 Martin Espinoza 認為。“根本就沒有 Linux 的桌面環境能像 Windows XP 系統那樣精雕細琢，更別説是 Windows 7 系統了。”

"除了可以用臃腫複雜的 GNOME 或 KDE 的色拉一樣的小部件，難道還要用擁有極其可怕的文件管理器和非常原始的面板的 Xface 或 LXDE 嗎？" Espinoza 增加道。"GNOME 僅僅只是非常接近 DE。真正的 DE 是十分簡潔的，還會隱藏他們的存在。"

Windows 也僅僅是“表現的比較好，”他斷言説。

不過，如果 Linux 要獲得廣泛的接受的話，“最缺的正是遊戲，”Espinoza 説到。“如果您把它限定到一款應用程序的話，最需要的很可能仍是 Photoshop 。儘管大家都在談論 GIMP 已經變得多麼多麼強大，但它的易用性仍然是個悲催的噩夢；雖然開源社區有些相關的文檔，但 GIMP 仍是處在缺乏文檔的可憐狀態。”

"GIMP “也許能做 Photoshop 能做的大部分事情，但我很可能並不知道，”Espinoza 的結論。“我想，如果我花了幾個小時逛論壇就可以找出如何使用 GIMP 了。這就是大多數開源軟件項目失敗的地方，包括那些認為他們是真的是有了足夠多的説明文檔的。”

'易用和有技術支持' ​

SoylentNews 的博主 hairyfeet 定義説易用和有技術支持就是 “殺手級應用”。

“嗯，一個新手安裝好一個看起來很漂亮的 Linux 發行版系統，它工作得也很正常；但問題是它不會一直正常工作或一直都讓人賞心悦目，”他解釋到。“第一個更新，哎喲！WPA V2 無線網用不了了。第二個更新呢，像脈衝嘔吐一樣，聲音沒了。還有第一個‘升級’？呃，都不需要繼續了！”

“這正是 Linux 欠缺而 Windows 和 OS X 已經具有的：易用性及技術支持，”hairyfeet 結束道。“相同的時段有 15 款以上的 Linux 發行版本跟僅僅只是一款 Windows 發行版本所獲得的技術支持生命週期能一樣嗎？不好意思的説，您們的產品不是同一重量級的 -- 您是拿高中棒球賽跟職業聯賽在比較。”

'Windows 8' ​

最後但並非是不重要的，Linux Rants 的博主 Mike Stone 提供了一個讓人驚訝的建議。

“這些年 Linux 缺乏的殺手級應用是 Windows 8，”Stone 打趣説。

"説真的，我認為並沒有一個特定的應用程序可以被稱為'殺手級應用'，“他説，”Linux 需要有更多的主流應用的支持，而這將意味着 Photoshop 和微軟的 Office 是必須具有的。值得慶幸的是，微軟已經做了最大的努力以使 Office 可以跨平台，至於 Photoshop 的話大多數人並不需要的。"

Linux "應該是很爭議性的話題，上面我所説的 Windows 8 僅僅只是個玩笑，"他總結説。“基於 Linux 的應用程序正如火如荼，而當前的 Windows 系統明顯不受歡迎。祈禱我們能很快就看到這一變化。”
