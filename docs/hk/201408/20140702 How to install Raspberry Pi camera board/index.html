如何安裝樹莓派攝像頭模組 ​

樹莓派攝像頭模組(Pi Cam)發售於2013年5月。其第一個發佈版本配備了500萬像素的傳感器，通過排線鏈接樹莓派上的CSI接口。而Pi Cam的第二個發佈版本——也被叫做Pi NoIR中，配備了相同的傳感器，但沒有紅外線過濾裝置。因此第二版的攝像頭模組就像安全監控攝像機一樣，可以觀測到近紅外線的波長(700 - 1000 nm)，不過當然同時也就犧牲了一定的顯色性。

本文將會展示如何在樹莓派上安裝攝像頭模組。我們將使用第一版攝像頭模組來演示。在安裝完攝像頭模組之後，你將會使用三個應用程序來訪問這個模組：raspistill, raspiyuv 和raspivid。其中前兩個應用用來捕捉圖像，第三個應用來捕捉視頻。raspistill 工具生成標準的圖片文件，例如 .jpg 圖像，而 raspiyuv 可以通過攝像頭生成未處理的 raw 圖像文件。

安裝樹莓派攝像頭模組 ​

按照以下步驟來將樹莓派攝像頭模組連接搭配樹莓派：

  1. 找到 CSI 接口(CSI接口在以太網接口旁邊)，掀起深色膠帶。

  2. 拉起 CSI 接口擋板。

  3. 拿起你的攝像頭模組，將貼在鏡頭上的塑料保護膜撕掉。確保黃色部分的PCB(有字的一面)是安裝完美的（可以輕輕按一下黃色的部分來保證安裝完美）。

  4. 將排線插入CSI接口。記住，有藍色膠帶的一面應該面向以太網接口方向。同樣，這時也確認一下排線安裝好了之後，將擋板拉下。

好了，現在你的 Pi Cam 已經準備就緒，可以拍攝照片或視頻了。

在樹莓派上啓用攝像頭模組 ​

在安裝完攝像頭模組之後，首先要確認你已經升級了樹莓派系統並應用了最新的固件。可以輸入以下命令來操作：

$ sudo apt-get update
$ sudo apt-get upgrade

運行樹莓派配置工具來激活攝像頭模組：

$ sudo raspi-config

移動光標至菜單中的 "Enable Camera（啓用攝像頭）"，將其設為Enable（啓用狀態）。完成之後重啓樹莓派。

安裝完攝像頭模組後的完成照：

通過攝像頭模組拍照 ​

在重啓完樹莓派後，我們就可以使用Pi Cam了。要用它來拍攝照片的話，可以從命令列運行raspistill：

$ raspistill -o keychain.jpg -t 2000

這句命令將在 2000ms 後拍攝一張照片，然後保存為 keychain.jpg。下面就是一張由 Pi Cam 拍攝的我的小熊公仔鑰匙鏈。

raspiyuv 工具用法差不多，只不過拍攝得到的是一張未處理過的raw圖像。

通過攝像頭模組拍視頻 ​

想要用攝像頭模組拍一段視頻的話，可以從命令列運行 raspivid 工具。下面這句命令會按照默認配置(長度5秒，分辨率1920x1080，比特率 17Mbps)拍攝一段視頻。

$ raspivid -o mykeychain.h264

如果你想改變拍攝時長，只要通過 "-t" 選項來設置你想要的長度就行了（單位是毫秒）。

$ raspivid -o mykeychain.h264 -t 10000

使用 "-w" 和 "-h" 選項將分辨率降為 1280x720...

$ raspivid -o mykeychain.h264 -t 10000 -w 1280 -h 720

raspivid 的輸出是一段未壓縮的 H.264 視頻流，而且這段視頻不含聲音。為了能被通常的視頻播放器所播放，這個 raw 的 H.264 視頻還需要轉換。可以使用 gpac 包中所帶有的 MP4Box 應用。

在 Raspbian 上安裝 gpac，輸入命令：

$ sudo apt-get install -y gpac

然後將這段 raw 的 H.264 格式的視頻流轉換為每秒30幀的 .mp4 格式視頻：

$ MP4Box -fps 30 -add keychain.h264 keychain.mp4

視頻長度為10秒，使用默認分辨率以及比特率。下面是一段通過 Pi Camera 拍攝的一段實例視頻。

如果想要獲取 raspistill, raspiyuv 和 raspivid 的完整命令列選項，不加任何選項直接運行以上命令即可。
