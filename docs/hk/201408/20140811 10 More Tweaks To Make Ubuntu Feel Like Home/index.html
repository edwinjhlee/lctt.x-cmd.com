10個調整讓Ubuntu賓至如歸 ​

不久前我提供給大家12個調整Ubuntu的小建議。 然而，已經是一段時間以前的事情了，現在我們又提出了另外10個建議，能夠使你的Ubuntu賓至如歸。

這10個建議執行起來十分簡單方便，那就讓我們開始吧！

1. 安裝 TLP ​

我們不久前涉及到了TLP, 這是一款優化電源設置的軟件，可以讓你享受更長的電池壽命。之前我們深入的探討過TLP， 並且我們也在列表中提到這軟件真不錯。要安裝它，在終端運行以下命令：

sudo add-apt-repository -y ppa:linrunner/tlp && sudo apt-get update && sudo apt-get install -y tlp tlp-rdw tp-smapi-dkms acpi-call-tools && sudo tlp start

上面的命令將添加必要的倉庫，更新包的列表以便它能包含被新倉庫提供的包，安裝TLP並且開啓這個服務。

2. 系統負載指示器 ​

給你的Ubuntu桌面添加一個系統負載指示器能讓你快速瞭解到你的系統資源佔用率。 如果你不想在桌面上添加這個技術圖表，那麼可以不要添加， 但是對於那些對它感興趣的人來説，這個擴展真是很好。 你可以運行這個命令去安裝它：

sudo apt-get install indicator-multiload

然後在Dash裏面找到它並且打開。

3. 天氣指示器 ​

Ubuntu過去提供內置的天氣指示器，但是自從它切換到Gnome 3以後，就不再默認提供了。你需要安裝一個獨立的指示器來代替。 你可以通過以下命令安裝它：

sudo add-apt-repository -y ppa:atareao/atareao && sudo apt-get update && sudo apt-get install -y my-weather-indicator

這將添加另外一個倉庫，更新包的列表，並且安裝這個指示器。然後在Dash裏面找到並開啓它。

4. 安裝 Dropbox 或其他雲存儲解決方案 ​

我在我所有的Linux系統裏面都安裝過的一個軟件，那就是Dropbox。沒有它，真的就找不到家的感覺，主要是因為我所有經常使用的文件都儲存在Dropbox中。安裝Dropbox非常直截了當，但是要花點時間執行一個簡單的命令。 在開始之前，為了你能在系統托盤裏看到Dropbox的圖標，你需要運行這個命令：

sudo apt-get install libappindicator1

然後你需要去Dropbox的下載頁面，接着安裝你已下載的.deb文件。現在你的Dropbox應該已經運行了。

如果你有點討厭Dropbox, 你也可以嘗試使用Copy 或者OneDrive。兩者提供更多免費存儲空間，這是考慮使用它們的很大一個原因。比起OneDrive我更推薦使用Copy，因為Copy能工作在所有的Linux發行版上。

5. 安裝Pidgin和Skype ​

和朋友們保持聯繫特別好，並且如果你使用即時通訊，那麼你很幸運。 Pidgin和Skype在Linux都十分出色，它們都能連接所有主要網絡。安裝Pidgin就像運行這個命令一樣簡單：

sudo apt-get install pidgin

安裝Skype也很簡單 — 你僅僅需要去Skype的下載頁面並且下載你Ubuntu12.04對應架構的.deb文件就可以了。

6. 移除鍵盤指示器 ​

在桌面上顯示鍵盤指示器可能讓一些人很苦惱。對於講英語的人來説，它僅僅顯示一個“EN”，這可能是惱人的，因為很多人不需要改變鍵盤佈局或者被提醒他們正在使用英語。要移除這個指示器，選擇系統設置，然後文本輸入，接着去掉“在菜單欄顯示當前輸入源”的勾。 （譯註:國人可能並不適合這個建議。）

7. 迴歸傳統菜單### ​

在Ubuntu切換到Unity之前，它使用Gnome 2 作為默認的桌面環境。 這包含一個簡單的菜單去訪問已安裝的應用，菜單包含的很多分類，比如： 遊戲，辦公， 互聯網，等等。 你可以用另外一個簡單的包找回這個“傳統菜單” 。要安裝它，運行這個命令：

sudo add-apt-repository -y ppa:diesch/testing && sudo apt-get update && sudo apt-get install -y classicmenu-indicator

8. 安裝Flash和Java ​

在之前的文章中我提到了安裝解碼器和Silverlight，我應該也提到了Flash和Java是它們所需要的主要插件，雖然有時可能它們可能被遺忘。要安裝它們只需運行這個命令：

sudo add-apt-repository -y ppa:webupd8team/java && sudo apt-get update && sudo apt-get install oracle-java7-installer flashplugin-installer

安裝Java需要新增倉庫，因為Ubuntu不再包含它的專利版本（大多數人為了最好的性能推薦使用這個版本），而是使用開源的OpenJDK。

9. 安裝VLC ​

默認的媒體播放器Totem十分優秀但是它依賴很多獨立安裝的解碼器才能很好的工作。我個人推薦你安裝VLC媒體播放器， 因為它包含所有解碼器並且實際上它支持世界上每一種媒體格式。要安裝它，僅僅需要運行如下命令：

sudo apt-get install vlc

10. 安裝PuTTY (或者不) ​

最近，如果你出於SSH的需要而使用PuTTY，你有兩個選擇：為Linux安裝PuTTY，或者直接使用終端。如果你想使用終端安裝PuTTY，需要用到這個命令：

sudo apt-get install putty

然而，並不需要直接安裝它，因為你可以使用這個命令來連接任何遠程主機。

ssh username@this.domain.here

用你想要連接的用户名來替換掉“username”，然後用主機的直接域名或者IP地址替換掉“this.domain.here” 都可以。

你推薦如何調整？ ​

補充了這10個調整，你應該感覺你的Ubuntu真的有家的感覺，這很容易建立起或擊潰你的Linux體驗。有許多不同的方式去定製你自己的體驗去讓它更適合你的需要；你只需自己尋找來發現你想要的東西。

您有什麼其它的調整和建議想和讀者分享？在評論中告訴我們吧！
