Linux中一些最優秀的瀏覽器 ​

本文討論Linux桌面一些最優秀瀏覽器的優缺點，討論對象包括Firefox，Chrome和其它瀏覽器。

選擇一款最棒的Linux瀏覽器來滿足你所需僅費些許功夫：Linux桌面網頁瀏覽器和在其它流行的桌面上一樣已經發展了多年，隨着它們的發展，其優點和缺點都被慢慢發現。優缺點涉及從新功能到被破壞的擴展程序等各方面。本文中，我將在迷茫之中充當你的嚮導來幫助你發現適合你的最棒的Linux瀏覽器。

Firefox ​

– Firefox成為一款Linux用户友好的瀏覽器已經很長時間了。 它在32位和64位的Linux上都可用，同時Firefox提供豐富的擴展程序可供選擇。它是一款裝載快速，易於使用的瀏覽器，在Linux用户中很流行。

優點: 如果Firefox沒有被預裝在某個Linux發行版的話，它也能很方便地從大多數常見Linux軟件倉庫中安裝。上千種供選擇的擴展程序可以讓你的firefox極富個性化。幾乎能夠合適地渲染所有的 網頁（包括政府網站和銀行網站）。

另外很重要的一點：Firefox尊重你的隱私。Firefox有一項直白的隱私政策，和谷歌可不是一回事。因此，大多數用户能放心地讓Firefox查看他們的日常瀏覽記錄，然而，其他的某些瀏覽器可能會對用户的隱私有一些受利益驅使的興趣。Firefox也非常適用於web開發者，這得感謝內嵌入Firefox的元素檢查工具。

缺點: 不久之前，我發現Firefox的頻繁更新會破壞我的擴展程序。這就意味着每次在我更新Firefox前得檢查我最喜歡的一些擴展程序是否與新的Firefox兼容。

老實説，這讓我重新考慮該把誰作為我的默認上網瀏覽器。為了做到合理，Mozilla在每次更新Firefox時都會向擴展程序開發者發出郵件通知。在這些郵件中，開發者會被告知有哪些改動以及怎樣做來使一切運動流暢。

Chrome/Chromium ​

– Google升級它的瀏覽器為Chrome，然而自從Chromium被作為Chrome的開發基礎後我就傾向於把Chromium和Chrome視為一類。不像Firefox，Chrome/Chromium進入Linux比較晚，直到Chrome被大多數人意識到是最快的瀏覽器後Linux使用者才覺得它值得一試。

優點: 即使是在今天，Chrome也是超快的。雖然最近很多瀏覽器的升級使它有了競爭對手，但在速度方面Chrome/Chrommium還從未輸過。Chrome/Chromium支持的擴展程序數量豐富甚至質量更好，而且升級Chrome/Chromium對它的擴展程序並沒有影響。這就意味着，不像Firefox，我不需要去處理擴展程序的不兼容性。和Firefox一樣，Chrome/Chromium也有內嵌入瀏覽器的元素檢查工具。和其它瀏覽器一起試驗同步功能後，只有Chrome/Chromium 證明了它是安全可靠的。在我看來，Chrome/Chromium的同步功能毫無疑問是眾多瀏覽器中最好的。

缺點: Chrome/Chromium有時候不能正確地渲染網頁。有這樣一些很少見的情形，一些網站比如Ebay不能被正確地渲染。舉個例子，假如我在新建一個Ebay提交，有時候會缺少某些網頁按鈕。我還發現有時候當一個打開的標籤頁正在執行大型腳本時Chrome/Chromium會完全卡住。比如Google Plus 和 Facebook這樣的網站就是最常見的例子。

Qupzilla ​

– 説到輕量級瀏覽器時，我認為Qupzilla是最棒的。基於webkit，它能在很小的資源佔用下提供相當好的網頁渲染支持。

優點: 如果你需要一款現代化的能正確渲染網頁，並大體上能提供可靠的網絡瀏覽體驗的瀏覽器，那麼對於輕量的桌面環境來説，Qupzilla是你的理想選擇。它相當輕巧，能夠在老計算機上非常穩定地運行。Qupzilla預裝了Access keys 和 GreaseMonkey插件(但沒有被啓用）。

同Firefox和Chrome/Chromium一樣，Qupzilla也提供元素檢查工具。最後，由於Qupzilla預裝了Adblock插件，這就無疑使得它成為我心中的輕量級瀏覽器冠軍。

缺點: HTML5 “視頻”標籤在Qupzilla上好像無法可靠地運行。而且，為了觀看Flash視頻，你得進入首選項並且在Webkit插件區域的擴展程序中鈎去Click to Flash選項, 在HTML5 “視頻”標籤還是完全損壞的情況下，這個未經深思熟慮的設計實質上使得Flash無法直接播放。

Midori ​

– 我喜歡把Midori叫做輕量級的Chrome。和Goolge的瀏覽器一樣，Midori通過它的“漢堡式”菜單給用户提供極簡風格的體驗，漢堡式菜單相當棒因為它佔用的瀏覽器空間更少。在沒有其它瀏覽器信條的情況下你不僅能獲得穩定的上網體驗，而且Midori也是相當快速。

優點: Midori快速，輕量，接近於開箱即用。它能夠正確地渲染網頁而且能夠很好地瀏覽像YOUTUBE一樣的網站。我認為Midori最棒的地方就是內嵌入瀏覽器的瀏覽器設置功能和網頁應用快捷方式。舉個例子，你可以很簡單地在你的桌面上建立一個Gmail或Facebook的快捷方式。你也可以創建另外的瀏覽器設置，而不用新建立一個Linux用户帳號。

缺點: 雖然也提到過Midori的用户擴展程序，但可用的擴展程序並不出色。另外，用户得費些許功夫來習慣Midora的佈局。 比如它給瀏覽過的網站還弄個垃圾桶-有沒有搞錯？

Opera ​

– Opera長時間是被誤解的瀏覽器之一。很早以前，Opera瀏覽器在所有Linux社區的反對下提供了Linux平台下的支持。不過後來還好，Opera成為了服務Linux用户的一個快速，和諧的瀏覽器，它也有很豐富的設置選項。

優點: 快速，用户自定性選項豐富。你可以在瀏覽器中發送和接收從RSS 訂閲到電子郵件等等，Opera 可以讓你很方便得獲取炫麗的瀏覽器主題。Opera提供一個豐富的拓展倉庫來供你選擇擴展程序。我們不僅能從Opera閲讀RSS 訂閲和電子郵件，我們還能使用Opera的擴展套件功來能重温使用Mozilla Suite的日子。也許最重要的是，Opera Turbo -能極大提高你的上網速度，它通過對瀏覽內容的選擇性壓縮來給用户提供一個更快的上網體驗。

缺點: 首次運行配置很多服務會很麻煩。Opera Turbo對你的上網體驗有些許影響——比如YouTube，可能無法顯示視頻的縮略圖。Opera提供如此之多的設置選項可能令業餘使用者手足無措。。最後一點，Opera是閉源軟件，作為桌面瀏覽器它不是很好地被認可。大多數愛好者僅把它當作一款手機瀏覽器。

哪款瀏覽器適合你？ ​

有這麼多棒極了的選擇，很難説哪個適合你。對我來説，由於我每天工作需的一些特定擴展程序，所以我很依賴於Firefox和Chromium。對於一些低端機子或是上網本，我的建議是先試試Midori，如果不合適的話，再回頭看看Qupzilla。

那麼Linux上的其它瀏覽器怎麼樣呢？比如Epiphany或是Konqueror？像這樣的瀏覽器也很棒，但是我對我上面所提到的瀏覽器印象深刻。上面所列舉的都是我經常使用的瀏覽器，我覺得它們有些地方很出色並且我很開心地向朋友和家人都推薦它們。

介紹完了以上幾款，請您在下面的評論區域中和我們分享您喜愛的瀏覽器，這樣其他人也許可以從您喜愛的瀏覽方式中得到啓發。 ​
