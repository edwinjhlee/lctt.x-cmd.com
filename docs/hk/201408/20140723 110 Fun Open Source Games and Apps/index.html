translating by disylee 20140701 110 Fun Open Source Games and Apps 110款有趣的開源遊戲和應用 ​

讓我們再次慶祝，這個夏天伴隨着一系列最好的開源遊戲到來。我們已經更新了去年的列表，把新開發的添加進來，與此同時把一些不再處於積極開發之中的舊遊戲從列表中剔除。你能從其中找到街機、棋盤、休閒、拼圖、益智、第一人稱射擊遊戲、音樂、競速、角色扮演、冒險、模擬和戰略遊戲等，也有少量其實並非真正的遊戲的應用程序，但它們同樣非常有趣。

今年，有比以往有更多的開源遊戲可用於移動設備上，主要是安卓設備。這種趨勢，很有希望在未來幾年一直保存下去。

請注意，這個列表並不是排行榜。這些應用程序被分別歸類，並在每個類別中按照字母順序排列。

如果你想給明年的遊戲列表推薦一個遊戲，請隨時在下面的評論區中留言。

街機遊戲 ​

1. 安迪的超級大公園 ​

你乘坐在過山車上躲避着障礙物，同時去抓取氣球。其中有25個基礎關卡，加上18個你可以通過獲得高分來解鎖的額外關卡。可使用操作系統：Windows，Linux或者安卓。

2. Armagetron Advanced ​

一個3D復刻電影《創（Tron）》的遊戲，這個遊戲的挑戰是讓你操控你的輕型摩托，讓對手們比你自己更早地撞上牆。它支持單機模式和最多可16人蔘與的網絡模式。適用操作系統：Windows，Linux，OS X或者安卓。

3. BZFlag ​

也就是眾所周知的“戰場奪旗”，BZflag是一個熱門的在線坦克遊戲。它自1992年開始開發，現在具備了3D畫面、多種遊戲模式和多人競爭比賽等特性。適用操作系統：Windows，Linux，OS X或者安卓。

4. [Chromium B.S.U.] 5 ​

別被這個名字騙過了，它和Chromium瀏覽器沒有任何關係。這是一款快節奏的縱向卷軸射擊遊戲，它的難點在於如何進行合理的設置，以讓遊戲中的戰鬥能在15分鐘內結束。適用操作系統：Windows，Linux。

5. 埃德加的傳説 ​

埃德加的傳説是一個老式平台的遊戲，主角必須通過克服障礙、打倒敵人來完成他的任務。它包含了許多不同的武器和大量的關卡。適用操作系統：Windows，Linux和OS X。

6. JVGS ​

比起非常精細的畫面，JVGS選擇了採用最抽象的方式，用簡筆畫風格貫穿全部畫面，看起來就像使用鉛筆手工繪製而成。在這個不尋常的遊戲中，主角是一個失去記憶的詩人。適用操作系統：Windows，Linux和OS X。

7. 失重 ​

這個以太空為背景的街機射擊遊戲，帶領玩家前往8002年的未來，在未來世界中他們必須完成各種各樣的任務。可以一提的是，這個遊戲也可以在安卓和IOS中使用，但並不是免費的。適用操作系統有：Windows，Linux和OS X。

8. 開源索尼克 ​

在刺蝟索尼克遊戲的基礎上，開源索尼克新增了協作的玩法，即玩家用户可以同時控制3個角色。原始的遊戲版本只有兩個關卡，但是很多遊戲粉絲們已經創建了不少可玩的額外模組。適用操作系統：Windows, Linux和OS X.

9. Powermanga ​

類似於老式街機遊戲《小蜜蜂》，Powermanga是一款2D的、縱向卷軸的太空射擊遊戲。它擁有超過41個關卡，並能夠在更舊的硬件環境上運行。適用操作系統：Linux。

10. 焦土戰爭3D ​

焦土戰爭3D是DOS遊戲《焦土戰爭》的一個現代重製版，最引人矚目的是它出色的畫面。你可以玩單機模式，或者連接到它的許多網絡服務器之一，來進行多玩家聯機模式。適用操作系統：Windows, Linux和 OS X.

11. 索尼克機器大戰 2 ​

另一款基於刺蝟索尼克的平台遊戲，SRB2是一款採用了Doom引擎創建的3D平台遊戲。它包括了3個不同的可操控角色和超過20個關卡。適用操作系統：Linux。

12. 超級Tux ​

超級Tux很像經典的馬里奧兄弟遊戲，不過是以Linux的小企鵝Tux作為主人公。這是一個2D橫向卷軸的平台遊戲，其中有9種不同的敵人和26個關卡可以玩。適用操作系統：Windows, Linux和OS X.

13. Those Funny Funguloids ​

這個獨一無二的遊戲讓玩家挑戰在太空中收集蘑菇。該網站稱：“此前從未有收集蘑菇的遊戲能如此有趣。至少不是在外太空。它比起遊戲更像是一種生活方式，相信我。”適用操作系統：Windows和Linux.

14. Teeworlds ​

這個在線遊戲將自己描述成一個“懷舊多人射擊遊戲”。它是一個橫向卷軸的2D遊戲，可支持多達16名玩家和許多不同的遊戲模式。適用操作系統：Windows, Linux和 OS X.

15. X摩托 ​

在這個遊戲中，你要騎着一輛摩托車闖過一個橫向卷軸地圖，同時收集草莓並躲開兇殘的“肇事者”。它玩起來比看起來要難！適用操作系統：Windows, Linux和 OS X.

16. 鼯鼠弗蘭基! ​

使用Blender開源3D動畫工具開發，鼯鼠弗蘭基的特色是角色來源於開源電影Peach。玩家必須操控弗蘭基——一隻蜜袋鼯鼠，或者Momo——一隻猴子，在非常精美的3D環境中跳過、繞過或者穿過各種障礙物。適用操作系統： Windows, Linux和 OS X.

棋盤遊戲 ​

17. 統治 ​

基於Java的《統治》為你的PC或安卓設備帶來了棋盤遊戲《Risk》。最新版本中通過谷歌遊戲服務的支持，讓你能與你的Google+好友們進行實時的多人遊戲。適用操作系統：Windows, Linux, OS X和 Android.

18. GNU 西洋雙陸棋 ​

這個“世界級”的西洋雙陸棋引擎，當你每次挑戰它的時候，它都會變得更強，並且它能夠分析你的戰術來幫助你玩得更好。它的界面很棒，並且還支持個性化定製。適用操作系統：Windows，Linux和OS X。

19. 3D 拼字遊戲 ​

在這個拼字遊戲的變體版本中，你可以選擇自己的圖板——經典版、超級拼字版、3D拼字版或者你自定義的圖板。玩家可以與AI對戰，或者連接到在線服務器上進行多人遊戲。適用操作系統：Windows, Linux和 OS X.

20. PokerTH ​

這個高品質的德州撲克應用程序擁有優秀的、可定製的界面。想要在線玩並看看你相對於其他玩家的排名，可以前往Poker-Heroes.com在線註冊。適用操作系統：Windows，Linux和OS X，Android系統。

21. PySolFC ​

你知道單人紙牌遊戲有超過1000種玩法嗎？這個大合輯包含“使用52張紙牌的國際標準紙牌遊戲、使用78張紙牌的塔羅紙牌遊戲、8張或10張一套的印度雙骰遊戲、花札遊戲、矩陣遊戲、麻將遊戲和一種原創的基於十六進制的紙牌遊戲”。適用操作系統: Windows, Linux和 OS X.

休閒解謎遊戲 ​

22. 2048 ​

在這個簡單卻容易上癮的益智遊戲中，玩家需要來回挪動方塊來合併數字等。當你將數字累加到2048時，你就贏了。適用操作系統：在線，IOS或者安卓。

23. 枱球 ​

《枱球》這個遊戲的目標是希望做到足夠真實，讓你在沒有一張可用的枱球桌時也夠能進行台球杆的運動練習。它擁有一個好看的3D界面，同時也可以在沒有良好圖形處理能力的系統中以2D形式運行。適用操作系統：Linux。

24. 立方體列車 ​

鋪設鐵軌來連接隧道和橋樑，同時採取各種策略繞過障礙物。你可以挑戰其中大量的內置關卡，或者自己創建一個。適用操作系統：Windows，Linux或者OS X。

25. Enigma ​

類似於以前《Oxyd and Rock'n'Roll》系列遊戲，《Enigma》讓玩家挑戰從迷宮、陷阱、激光束和其它障礙之間找出配對的石頭。這個遊戲擁有1000多個關卡，這是一款能讓你沉迷很長很長時間的解密遊戲。適用操作系統：Windows，Linux和OS X。

26. Fish Fillets NG ​

在這個解謎遊戲中，玩家必須嘗試在70個關卡中分別找到一條安全的通關路徑。一路上，魚類和其它水下居民會對玩家的操作提出幽默的解説。適用操作系統：Windows, Linux和 OS X.

27. 冰凍泡泡 ​

作為最古老的泡泡射擊遊戲之一，冰凍泡沫以Linux小企鵝Tux和超過100個單人遊戲關卡為特色。你也可以通過局域網或者互聯網對陣2~5個玩家。適用操作系統：Windows和Linux。

28. GnomeGames ​

這個合輯包含了15個不同的休閒遊戲，這些遊戲你都可以只花五分鐘或更少的時間來玩。它包括了數獨、一個掃雷遊戲、麻將和一個版本的黑白棋等等。適用操作系統：Linux。

29. 番茄炸彈超人 ​

10分鐘內，你能夠粉碎多少個西紅柿？這個“特別閒的時候玩的東西”和《Those Funny Funguloids》由同一個的團隊打造。適用操作系統： Windows和 Linux.

30. KDE 遊戲 ​

這是一個KDE桌面上的休閒遊戲合輯。它包含了一個變體紙牌遊戲、一個版本的打磚塊、一個高爾夫遊戲、一個版本的Risk、一個掃雷，還有數獨等等。適用操作系統：Windows和Linux。

31. Neverball ​

在這個遊戲中，玩家必須傾斜地板去引導球通過障礙場地。這個遊戲包括許多關卡，並且你可以設計自己的關卡。適用操作系統：Windows, Linux和 OS X。

32. 瘋狂小企鵝 ​

在90年代時，你是否曾經花費數個小時去玩《瘋狂小旅鼠》？如果是這樣的話，《瘋狂小企鵝》就是為你而設計的。它是《瘋狂小旅鼠》的一個復刻版（使用企鵝替代了旅鼠），有77個關卡。適用操作系統：Windows, Linux和 OS X.

33. 推倒 ​

這個解謎遊戲的特色是，讓螞蟻來推倒具有各種不同圖案的多米諾骨牌。玩家必須讓所有多米諾骨牌倒下，並將一個特殊的觸發信號發送至出口，這樣才能進入下一關。適用操作系統：Windows。

34. Zaz ​

這是另一款泡泡射擊遊戲，《Zaz》讓你挑戰射擊一些沿着預定路線前進的小球。其獨到之處是你的發射器也是沿着一條預定路徑移動着的，這樣就讓各種操作變得更難一些了。適用操作系統：Windows和Linux。

益智遊戲 ​

35. ChildsPlay ​

《ChildsPlay》專為5歲及以下的兒童設計，能夠幫助指導他們發音、字母、數字和基礎的鍵盤技巧。它也包括了一些遊戲，例如記憶遊戲、打磚塊和吃豆豆。適用操作系統：Windows，Linux和OS X。

36. GBrainy ​

通過《GBrainy》中的邏輯、詞彙、數學和記憶遊戲，來鍛鍊你的思維。它對於所有年齡段的玩家來説，都會十分有趣並且有益頭腦。適用操作系統：Windows和 Linux.

37. GCompris ​

專為2~10歲的兒童設計，《GCompris》包含了超過100種不同的遊戲，其中大多數是教育性質的。它包括數學、地理、科學、閲讀、敲鍵盤和藝術遊戲，再加上國際象棋、數獨、記憶遊戲等等。適用操作系統：Wwindows和Linux。

38. TuxMath ​

在即將到來的彗星殺死企鵝之前迅速地解決數學問題。這個簡單的遊戲能夠強化小學年齡段學生們的數學能力。適用操作系統：Windows, Linux和 OS X.

第一人稱射擊遊戲 ​

39. 外星人競技場 ​

被設計為“以彈藥對抗彈藥”的《外星人競技場》是有着復古科幻主題的一場緊張的死亡競爭射擊槍戰。許多不同的網站為聯機遊戲提供了託管服務器，也有很多記錄了各種遊戲技巧等等的粉絲網站。適用操作系統：Linux, Windows和 OS X.

40. AssaultCube ​

因其輕量級，即使擁有非常不錯的真實感畫面，AssaultCube仍然能在更舊的硬件設備上運行。它支持單人和多人遊戲，包括了26張不同的地圖和12種不同的遊戲模式。適用操作系統：Linux，Wwindows和OS X。

41. 經典 Nexuiz ​

下載量超過600萬次，《Nexuiz》是最熱門的開源射擊遊戲之一。幾年前，該遊戲發佈了一個新的閉源版本，不過你仍然可以通過上面的鏈接從SourceForge下載經典版本。適用操作系統：Windows, Linux和OS X.

42. OpenArena ​

這個多人遊戲是雷神之錘3競技場的復刻，特色是擁有13種不同的武器、51個競技場、18個玩家角色和12種遊戲類型。該項目的擁有者發出警告，“由於暴力和偶爾的不健康內容，它不適合17歲以下的孩子玩”。適用操作系統：Windows, Linux和 OS X.

43. 紅食 ​

這個休閒的第一人稱射擊遊戲獲得了極高的評價。其特色是包含跑酷、衝撞、衝刺要素，擁有多種遊戲模式和一個內置的關卡編輯器。適用操作系統：Windows, Linux和 OS X.

44. Tremulous ​

這個屢獲殊榮的遊戲是將即時戰略遊戲元素和第一視角射擊遊戲混合而成。玩家可以選擇扮演外星人或者人類，目標則始終是消滅其它隊的對手。適用操作系統：Windows, Linux, OS X和 XBox.

45. TrueCombat ​

《TrueCombat》宣稱要成為“也許永遠是最好的免費寫實系戰術射擊遊戲”。這是一個敵對雙方進行對抗戰的現代背景戰鬥模擬器。請注意，為了使用它，你還需要安裝《重返德軍總部：深入敵後（見下）》。操作系統：Windows, Linux和 OS X。

46. Unvanquished ​

從《Tremulous》分支出來，《Unvanquished》專注於“科技高度發展的人類對抗適應能力超強的外星人羣體”。它正處於積極開發中，每個月都會發布新版本。適用操作系統：Windows, Linux和 OS X。

47. Warsow ​

這款自稱在“Web上節奏最快的運動遊戲”，Warsow是一個卡通風格的射擊遊戲，它的特色是”手持火箭炮的豬和扛着激光器賽博朋克風人物”。於大多數射擊遊戲的不同之處是，它並未充斥着血和內臟，並將遊戲重心放在了移動上。適用操作系統：Windows，Linux和OS x.

48. 重返德軍總部：深入敵後 ​

雖然已經有不少專攻德軍總部的遊戲，不過這一個是開源的。這是一個背景為第二次世界大戰時代的遊戲，當時軸心國正與盟軍對抗。適用操作系統：Windows，Linux,OS X。

49. 扁蝠俠的世界 ​

基於Quake引擎開發，這個射擊遊戲充滿了有稜角的卡通風格。可用的網絡服務器相當少，不過您也可以離線玩。（LCTT譯註：遊戲譯名中的“扁蝠俠”並不是打錯字，而是這個遊戲的原名“Padman”就是故意取自蝙蝠俠“Batman”的梗）適用操作系統：Windows和Linux。

50. Xonotic ​

Xonotic是源於經典版《Nexuiz》的分支。它擁有超過22種不同的地圖，16種武器和大量不同的遊戲模式。適用操作系統：Windows, Linux和OS X.

51. 零彈道 ​

一部分是第一人稱射擊，一部分是坦克大戰，零彈道的遊戲背景設計在一個風景如畫的山區環境中，並已經擁有超過81個坦克體系可用。可以進行死亡競賽、團隊死亡競賽或獨特的beaconstrike模式。適用操作系統：Windows、Linux 和 OS X。

音樂遊戲 ​

52. Frets on Fire ​

Frets on Fire這個遊戲很像《吉它英雄》，它甚至能夠使用《吉它英雄》的歌曲來玩（當然其它歌曲也同樣可用）。不必為自己沒有一個吉它控制器而擔心——你也可以用鍵盤來玩。適用操作系統：Windows, Linux和 OS X.

53. StepMania ​

這是一個免費版的《Dance Dance Revolution》，它讓玩家嘗試挑戰跟上樂曲的節拍。你既可以使用跳舞毯（如果你有的話）來跳，也可以只用鍵盤來玩。適用操作系統：Windows, Linux/Unix, OS X或者 XBox.

54. Ultrastar Deluxe ​

如果卡拉OK是你的菜，那麼你也應該會喜歡《Ultrastar Deluxe》。在這個遊戲中，你必須以準確的調子和正確的節拍獨立去唱歌。它包含了超過10000歌曲。適用操作系統： Windows, Linux和OS X.

競速遊戲 ​

55. Extreme Tux Racer ​

《Tux Racer》是一款早年廣受歡迎的遊戲，其特色是Linux的小企鵝Tux用肚皮從山坡上滑下。《Extreme Tux Racer》為如今的遊戲玩家升級了這款經典遊戲。適用操作系統：Windows, Linux和OS X.

56. 競速夢想 ​

這個自動賽車遊戲《TORCS》（見下文）分支版本的特色，是擁有更好的UI界面以及許多新車和賽道。與《TORCS》同樣，其視覺效果非常出色。適用操作系統：Windows和 Linux.

57. SuperTuxKart ​

這款卡通風格賽車遊戲的特點是讓Linux小企鵝Tux與它的小夥伴們來駕駛卡丁車。引導它們沿着賽道前進，同時避開一堆障礙物的撞擊吧。適用操作系統：Windows, Linux和 OS X.

58. TORCS ​

TROCS是"The Open Racing Care Simulator”的縮寫，它是一款已有大量粉絲基礎的傑出的寫實系賽車遊戲。單獨賽車或與眾多賽道之一上的朋友們競賽都是可選的。適用操作系統：Windows, Linux和 OS X.

59. 無限特技飛車 ​

由經典DOS遊戲《特技飛車》啓發，《無限特技飛車》要求玩家超控車輛越過毀壞的橋樑、跳台、圓環、螺旋及其它障礙。它提供了設計你獨有賽道的選項，允許你來創造需要更加瘋狂特技的賽道。操作系統：Windows，Linux和OS X。

60. VDrift ​

作為一款競速賽車的模擬所能做到的極致，VDrift以一個真實的物理引擎帶領玩家們來到了漂移賽車的世界。它包含了超過45種車輛，超過45條賽道，並且對大量種類的遊戲控制器提供了支持。適用操作系統Windows，Linux，OS X。

角色扮演和冒險遊戲 ​

61. 穿越火線 ​

有時被形容為《NetHack》和《Gauntlet》的結合，《穿越火線》是一款畫面十分舊派的街機冒險遊戲。它擁有超過3000張不同的地圖和超過150種不同的怪物。適用操作系統：Windows, Linux和 OS X.

62. Epic Inventor ​

Epic Inventor將自己描述為一款"橫向卷軸動作RPG"。它在簡約、像素風格的畫面和開放性上類似於Minecraft。適用操作系統：Windows和 Linux.

63[Excalibur: Morganna's Revenge] 64 ​

這部穿越時空的史詩級大作，讓你扮演一位未來世界的太空陸戰隊員，必須穿越回到亞瑟王和卡梅洛特城的年代。它的畫面表現並沒什麼特別出彩之處（想想 Minecraft)，但是故事情節和遊戲性都很贊。適用操作系統: Windows, Linux和OS X.

64. Flare ​

靈感來源於《暗黑破壞神》，這個角色扮演遊戲將重心放在了戰鬥上。它目前還只發布了alpha版本，不過已經可以玩。適用操作系統：Windows, Linux和 OS X.

65. Lips of Suna ​

僅供成年人玩的這款"半開玩笑的動作RPG"充滿了“暴力、黃段子、裸體以及其它你大概再也不會在別的遊戲中看到的主題”。它提供了大量的操作和不斷變化的場景。適用操作系統：Windows和 Linux.

66. The Mana World ​

這是一款大型的多人網絡角色扮演遊戲（MMORPG),但其實沒有想像中那麼大規模。（在我寫下這段文字的時候有31個人正在玩這個遊戲。）不過，它仍然是一個很好的嘗試，去創造了一個充滿怪物、任務和小遊戲並不斷擴大的世界。適用操作系統：Windows，Linux和OS X。

67. NetHack ​

（LCTT譯註：此處原文鏈接有誤，和上個遊戲的鏈接地址一樣了）

遊戲史上經典之一，NetHack是一款畫面十分簡約的複雜地圖探索遊戲。它被稱為有史以來最好的100個視頻遊戲之一。適用操作系統： Windows, Linux, 和經典Mac.

68. PlaneShift ​

遊戲背景設在一個名為Yliakum的奇幻世界，這個獨特的在線角色扮演遊戲的特色，是有10個不同的種族和一個擁有自己經濟、政府、宗教和法律的發達世界。雖然已經可玩，不過這款遊戲還處在開發早期階段。適用操作系統：Windows, Linux和 OS X.

69. Ryzom ​

作為較好的開源MMORPG之一，已獲讚譽的《Ryzom》將世界觀設在名為Atys的樹狀星球上，其上有許多不同種族生存交流，並且有時會發生衝突。你可以免費來玩，不過那些選擇了捐贈款項的玩家會得到一些額外的特別福利。適用操作系統：Windows, Linux和 OS X.

70. Stendhal ​

這款在線角色扮演遊戲旨在做得比大多數同類遊戲更加友好。其網站稱,"你也許會被請求去協助保護土地、拯救窮人、治癒病人、讓某人開心 解決難題，或只是簡單地伸出援手"。適用操作系統：Windows, Linux和OS X.

71. Summoning Wars ​

可允許最多8人一起玩的奇幻角色扮演遊戲。在Youtube上有一個該作的預告片，讓你能夠看到它的運行效果。適用操作系統：Windows, Linux和 OS X.

模擬遊戲 ​

72. FlightGear ​

極其寫實的《FlightGear》，是一款頂尖的飛行模擬器，甚至能匹敵專業軟件。它包含了整個世界的精確地形，以及20,000多個機場和眾多飛機的逼真模型。適用操作系統：Windows, Linux, OS X和其它。

73. Golems ​

有了這個物理模擬器，你可以創建任何你想創建的東西，並觀察它在真實世界中將會有何表現。它在幫助學習基礎機械、製造機器人、以及發明各種玩意上真是太棒了。適用操作系統：Windows, Linux和 OS X.

74. LinCity NG ​

在原本的《模擬城市》基礎上，《LinCity NG》讓玩家挑戰去建造一個擁有繁榮經濟的可持續發展大都市。需要注意的是，由於這個遊戲是基於早年的代碼，他的畫面更接近早期的DOS遊戲。適用操作系統：Windows, Linux和 OS X.

75. Micropolis/OLPC SimCity ​

另一款《模擬城市》的模仿作，Micropolis是一個基於Java開發的城市模擬器。它同樣也是以相當老派的畫面為特性，而不是像較新的城市模擬遊戲那樣採用3D畫面。適用操作系統：Windows, Linux和 OS X.

76. Minetest ​

與《Minecraft》極其相似，《Minetest》的遊戲背景被設置一個擁有各種基礎搭建模組的無垠世界中。玩家可以探索、挖掘或加工一些自己需要的新物件。適用操作系統： Windows, Linux和 OS X.

77. Pioneer ​

《Pioneer》將自己描述為“一個孤獨的太空冒險遊戲”。它將玩家傳送到一個開放的世界中，在這個世界裏他們可以決定他們想做什麼以及去哪裏。適用操作系統：Windows, Linux和 OS X.

78. Oolite ​

基於《Elite》的《Oolite》是一個太空模擬器，在其中你可以與其他航天員進行進行交易或捲入一場戰鬥。這個遊戲已經存在了相當長的時間，有許多擴展包可以使用。適用操作系統：Windows, Linux和 OS X.

79. OpenCity ​

這款3D城市模擬遊戲並不打算成為《模擬城市》的復刻版，不過還是提供了一種類似的玩法。它還相當基礎，不過已經可玩。適用操作系統：Windows, Linux和 OS X.

80. OpenTTD ​

基於《運輸大亨Deluxe》，OpenTTD邀請玩家去建立一個運輸帝國。它可同時支持多達255個玩家，並且在原本的TTD基礎上以許多方式進行了改善。適用操作系統： Windows, Linux和 OS X.

81. Rigs of Rods ​

這款擁有獨有的“軟體”物理引擎的交通工具模擬遊戲，享有十分活躍而熱情的粉絲基礎。使用它來創造海陸空的交通工具，並駕駛他們前往或飛往全國各地吧。適用操作系統：Windows, Linux和 OS X.

82. 模擬交通 ​

這款交通模擬遊戲支持連接到遍佈世界的遊戲服務器進行聯網遊戲。使用大巴、卡車、火車、電車、船隻、飛機、單軌鐵車、磁懸浮列車或者其它交通工具將人們或者貨物運送到他們想抵達的地方去。適用操作系統：Windows, Linux和 OS X.

83. Vega Strike ​

這是另一款可以讓你在跨越星系進行交易或戰鬥的太空模擬遊戲。你既可以選擇沿貿易路線飛行、接受賞金獵人任務、轉行當海盜，也可以僅僅只是探索浩瀚的太空。適用操作系統：Windows, Linux和 OS X.

戰略遊戲 ​

84. 0 A.D. ​

在當前的第16個alpha發佈版中，0 A.D.是一個優秀的致力於還原歷史的文明建設類遊戲。玩家可以選擇迦太基人、凱爾特人、希臘人、伊比利亞人、孔雀王朝時代的古印度人、波斯人或羅馬人進行遊戲。適用操作系統：Linux, Windows 和 OS X.

85. Advanced Strategic Command ​

這款回合制戰略遊戲基於《戰島》系列遊戲。玩家們在格子型的地圖上戰鬥，可選單機遊戲模式或者多人遊戲模式。適用操作系統：Windows 和 Linux.

86. 韋諾之戰 ​

這款回合制戰術策略遊戲讓玩家置身於神話世界，並在其中為爭奪王位而戰。獸人、精靈、巫師以及上百種其他類似的奇幻角色共同居住於這一巨大的環境之中。支持單人遊戲和多人遊戲。適用操作系統：Linux，Windows，OS X，IOS。

87. BosWars ​

這款未來風的實時戰略遊戲需要玩家去建設能源存儲設施和經濟體系，來支持其軍事戰鬥。玩家可以與電腦對戰，或通過局域網來進行多人遊戲。適用操作系統：Windows，Linux，BSD，OS X。

88. CommanderStalin ​

這個《BosWars》的變體版本將背景設置在斯大林時期的蘇聯。為了迎擊不可避免的納粹襲擊而進行準備吧！適用操作系統：Windows和Linux。

89. FreeCol ​

受到《Colonization》和《文明》這兩款遊戲的啓發，《FreeCol》是一款回合制文明建設戰略遊戲。你將從1492年的新大陸開始遊戲，最終依靠自由宣言建立一個獨立的國家獲得勝利。適用操作系統：Windows, Linux和OS X.

90. FreeCiv ​

同樣也是受到《文明》的啓發，這款回合制戰略遊戲將從石器時代開始，並結束於太空時代。它包含50種可操控單位和541個國家，並附帶了許多各種可玩的劇本。適用操作系統：Windows, Linux和 OS X.

91. FreeOrion ​

雖然它並不是復刻或重製，《FreeOrion》大體上還是基於《銀河霸主》系列遊戲的。它是一款以太空為背景的回合制戰略遊戲。適用操作系統：Windows, Linux和 OS X.

92. Glest ​

這款實時戰略遊戲中，科技的力量與魔法的力量進行着大戰。雖然它仍然提供下載，但是現在大多數的Linux發行版本包含的是它的分支版本《Megaglest》（見下文），而不是這個更舊點兒的項目。適用操作系統：Windows和 Linux.

93. Globulation 2 ​

這個實時文明建設戰略遊戲旨在減少微觀管理、允許玩家將精力集中於戰略上。支持單機或多人遊戲，並且還有關卡編輯器。適用操作系統：Windows和 Linux.

94. 刺蝟大作戰 ​

比較輕鬆的戰略遊戲之一，《刺蝟大作戰》的特色是以“模樣滑稽的粉色刺蝟們擁有着能從地獄一路戰鬥至太空般的氣勢”，支持31種環境，48套既有地圖，可無限隨機生成的地圖，55種武器，280種服裝，並且能支持多達8個玩家。適用操作系統：Linux, OS X和iOS.

95. Kernel Panic ​

以數碼空間為背景的《Kernel Panic》是一款有着與《創》相似畫面風格的實時戰略遊戲。所有資源都是免費的，因此玩家不必在經濟建設上耗費心思——只需專注與其他駭客在網絡中戰鬥。適用操作系統：Linux和 Windows。

96. Liquid War ​

追溯至2002年時，《Liquid War》被評為最“最新穎的Linux遊戲”，並且如今仍然值得一玩。為了吞噬敵人而操控一支你的液體大軍吧。適用操作系統： Windows, Linux和 OS X.

97. MegaGlest ​

這個《Glest》的分支版本在原來的科技與魔法之外增加了5個新的隊伍：埃及，印度，挪威，波斯和羅馬。它提供了17種不同的地圖類型，有單機和多人遊戲模式，併為新手提供了教程。適用操作系統：Windows和 Linux.

98. 不列顛治下和平 ​

（LCTT譯註：原文遊戲名稱中的“Brittanica”為筆誤，實際是“Britanica”） 這款潛艇戰略遊戲最多可支持4名玩家適用同一塊鍵盤同時戰鬥。操作非常簡單易學（你只需使用一個按鈕），不過遊戲過程可以玩得非常激烈。適用操作系統：Windows, Linux和 OS X.

99. Spring: 1944 ​

這款二戰戰略遊戲提供了十分逼真的單位和強度。可選擇美國、德國、蘇聯和英國來進行遊戲。適用操作系統：Linux。

100. 不明飛行物：異形入侵 ​

在未來的70年中，一個秘密組織為了從兇惡外星人的侵略之中保護地球而戰。玩家可在單機或多人戰鬥中扮演人類或者外星人。適用操作系統：Windows, Linux和 OS X.

101. Unknown Horizons ​

在這個文明建設戰略遊戲中，核心是建立一個強大的經濟體制。剛開始遊戲時，你身在一個孤島之上，只有屈指可數的移民和資源，需要去努力建造一個欣欣向榮的城市。適用操作系統：Windows, Linux和 OS X.

102. 戰爭地帶2100 ​

你能在核破壞後重建地球嗎？這個遊戲提供了一棵非常龐大的科技樹，並支持單人模式或者多人模式。適用操作系統：Windows, Linux,和OS X.

103. Widelands ​

受《工人物語2》啓發，《Widelands》又是一款讓玩家挑戰去建立文明的實時戰略遊戲。它的特色是具有3種部落——野蠻人、帝國人和亞特蘭蒂斯人，並且與大多數文明遊戲不同，玩家不需要告知每個單位去做什麼，而是下達命令、指派代表，更接近一個現實中的統治者。適用操作系統：Windows, Linux和 OS X.

104. Zero-K ​

在這個快速移動的實時戰略遊戲中，機器人軍隊進行着一場永無休止的戰鬥。主要特性是包含超過100種不同的單位、現代化的經濟體系、逼真的物理引擎、地球化等等。適用操作系統： Windows和 Linux.

105. Zombies ​

你能夠在在殭屍殺了你之前殺死所有殭屍嗎？這款回合制的遊戲擁有令人上癮的遊戲過程，以及允許玩家決定血腥程度的設置。適用操作系統：OS X、

有趣的非遊戲類 ​

106. Celestia ​

對於天文學愛好者和以宇航員為目標的人來説，這款軟件無疑是至臻完美的，《Celestia》能夠讓你看到在已知的宇宙中任何時間、任何地點上看到的星空。用它進行一場前往木星的快速旅行，或為你夜晚的觀測畫出星圖吧。適用操作系統：Windows, Linux和 OS X.

107. Electric Sheep ​

受到Philip K. Dick的小説《機器人會夢見電子羊嗎？》的啓發，這個屏保將你的系統與數以千計的其它系統連接，來創建抽象的圖案和花紋。投票支持你喜歡的圖案，它們便會出現得更頻繁一些。適用操作系統：Windows, Linux, OS X, 安卓和 iOS.

108. LCARS 24 ​

如果你家裏有一台舊的PC（誰沒有呢），何不把它變成一個《星際迷航》主題的交互工具。有了這個應用，你就能得到一個看起來就像是從進取號上拆下來的鬧鐘和文件管理器。適用操作系統：Windows和 DOS.

109. Stellarium ​

把你的PC變成一個天文館。《Stellarium》能夠展示地球上任何時間任何地點看到的夜空，並且它也被許多天文館採用來增強他們的展示。適用操作系統：Windows, Linux和 OS X.

110. Tux Paint ​

《Tux Paint》讓學齡前兒童在電腦上創作自己的“圖畫”變得更加容易。它的特色是擁有一個有大按鈕、有趣音效和友好角色的用户界面。適用操作系統：Windows, Linux和 OS X.
