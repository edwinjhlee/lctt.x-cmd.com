鮮為人知的 Apache Mesos 項目幫助 Mesosphere 公司得到了千萬美元投資 ​

Mesosphere，一家試圖圍繞鮮為人知的 Apache Mesos 項目開展商業活動的公司，剛剛從 Andreessen Horowitz 那裏獲得了 1000 萬美元投資。以下是為什麼這個項目能夠吸引如此鉅款的原因。

事實上 Mesos 這款自動擴放軟件已經出現了五年了。據 Mesosphere 的CEO及聯合創始人 Florian Leibert 所述，Mesos 已經在 Twitter 內已經管理了超過 50,000 個以上的CPU。此外， EBay, AirBnB, Netflix 還有 HubSpot 也是這款軟件的使用者。

當那些互聯網巨頭髮現 Mesos 的時候，這項技術卻並不為大多數企業所知。但它確實可以滿足一些公司在他們內部的數據中心上應用公共雲的一些技術的需求。

Mesos 管理集羣機器，根據需要自動擴放應用。它在每台機器上只依賴很少的軟件，它由一個主調度程序協調。據 Leibert 所説，其CPU 佔用為 0 並且幾乎不消耗任何內存。在其工作的每台機器上的該軟件會向調度程序報告關於虛擬機或者服務器的容量信息，接着調度程序向目標機器分派任務。

“如果一項任務終斷並且沒有返回任何結果，主調度程序知道如何重新調度它和它所用的資源在哪裏。” Mesosphere 的資深副總裁 Matt Trifiro 説。

Mesos 能自動擴放一系列的任務，包括 Hadoop 資料庫，Ruby on Rails 節點，以及 Cassandra 。

使用 Mesos 使得 Hubspot 削減了一半的 AWS(Amazon Web Services) 的費用支出，Liebert 説道。這是因為 Mesos 能夠在目標機器之間有效地分配作業量的原因。

然而，Mesos 更有可能應用到那些試圖真正地在內部創建一個類 AWS 環境的企業，一位來自 451 Research 的分析員 Jay Lyman 説。AWS 提供一些自動擴放工具，但大多數公司對於在公共雲基礎設施上運行所有東西還是感到不安。與此同時，他們並不想着反對他們的開發者採用 AWS 那樣的公共雲中可用的優異性能。他們希望他們的私有云能集成這些可用的優點。

“如你所見，類似 AWS 風格的界面風格，與監控、命令、操控以及穩定性相融合，” Liebert 繼續説道。

Mesos 既可以在一個私有云上也可以在 AWS 上運行，向企業提供最有效率地使用其內部雲的方法，並在需要擴放時自動切換到 AWS 去。

但是，從另外的方面説 Mesos 也是有一些缺點的。它並不能運行任何 Windows 操作系統或者比較古老的應用比如説 SAP 軟件。

不過，Lyman 説，“假如一個團隊擁有長時期使用雲的經歷，他們大概早就對 Linux 操作系統情有獨鍾了。”

在將來，Mesosphere 能夠支持 Windows 操作系統是很有可能的。最初，像 Puppet 和 Chef 這樣的技術也只支持 Linux 操作系統，Lyman 表示。“這只是早期 Mesosphere 的特性。現在它還是不太成熟，” 他又説道。

Mesosphere 正瞄向大部分使用現代編程技術構建了越來越多的運行於 Linux 的應用的企業，以及 Twitter 和 Netflix 這種在初創時還沒有 Mesos 類似技術的第一代 Web 2.0 公司。“這是早期兩類最常見的客户概況，” Trifiro 説。

年終之前，Mesosphere 希望發佈包含文檔的商業產品，通過技術支持與頒發許可證來獲得營收。Mesosphere 已開發一款名為 Marathon 的大規模擴放編制工具，並且支持 Docker 集成。它現在免費提供打包好的 Mesos 發行版，希望以此佔有未來的市場。

Mesosphere 同時也正在為少數早期的顧客工作。它幫助 HubSpot 實施有關 Mesos 的搭建。

Mesosphere 在這個領域並不唯一。Rightscale，Scalr 以及現在歸 Dell 所有的 Enstratius，全都提供了一些各種版本的擴放或雲管理技術。Mesosphere 強調説，Mesos 及其公司自己開發的技術在單獨機器中創建服務器集羣方面的表現遠勝於市場上的其他同類軟件。來自 Andreessen 的新投資一定會幫助 Meos 獲得更大的動力。
