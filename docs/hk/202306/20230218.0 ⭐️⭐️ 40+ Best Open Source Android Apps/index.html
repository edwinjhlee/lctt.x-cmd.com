40 個最佳開源安卓應用程序 ​

最好的開源安卓應用程序。替換專有應用，享受更好的體驗！

無論是智能手機、桌面電腦還是物聯網設備，開源軟件在某種形式上無處不在。

雖然安卓是一個開源項目，但你可以在上面找到專有和開源的應用程序。除了你可能已經使用的流行專有安卓應用程序，開源安卓應用程序可以作為更好的替代品，它尊重你的隱私。

在這裏，我為你精選了最好的開源安卓應用程序，可以作為日常使用的應用。

希望這個列表對你分享給他人時有所幫助！

📋 列出的開源應用程序可以在谷歌 Play 商店、F-Droid 商店或開發者的官方網站/平台上找到。你應始終使用官方推薦源來下載和安裝 APK。

鍵盤應用 ​

當你發送短信或搜索信息時，鍵盤應用程序是你最常接觸的應用程序。

當然，像 SwiftKey 這樣的應用也許在以前還不錯，但現在它們已經稍顯普通了。此外，選擇一個尊重你的隱私、符合預期（沒有任何花哨的功能）的開源鍵盤應用程序才是明智的選擇。一些最佳選項包括：

1、Simple Keyboard ​

如其名稱所示，Simple Keyboard 是一個 極簡的選項，適合想要沒有花哨功能的簡單鍵盤應用程序的用户。它是谷歌默認鍵盤應用程序 Gboard 的出色替代品。

但如果你想要主題自定義和一些額外的控件，它可能會讓你失望。

📥 GitHub

📥 F-Droid

📥 Play 商店

2、AnySoftKeyboard ​

AnySoftKeyboard 是我的最愛，它擁有我需要的所有基本功能，包括 主題自定義、快速文本和手勢支持。

如果你想要一個簡單的鍵盤體驗，它可以很簡單；如果你要求更多的功能，它也可以是一個合適工具。

📥 GitHub

📥 F-Droid

📥 Play 商店

3、OpenBoard ​

你可以將 OpenBoard 視為 不依賴谷歌二進制文件的安卓默認鍵盤應用程序。

因此，如果你喜歡 Gboard，但討厭其與谷歌服務的關聯，你可以使用 OpenBoard，它是一個簡單而有效的鍵盤應用程序。

📥 GitHub

📥 F-Droid

📥 Play 商店

文件管理器應用程序 ​

每個智能手機制造商都會裝載其自己品牌的文件管理器。根據你的智能手機，你可能已經有了三星的“我的文件”或小米的“文件管理器”。

不幸的是，默認的文件管理器應用程序（包括谷歌的“文件”）可能不是最好的選擇。此外，它們收集了你可能不想共享的一些使用數據。

一些最佳的開源文件管理器選項包括：

1、Amaze File Manager ​

Amaze File Manager 是一個不錯的開源替代品，類似於 Solid Explorer 和 EX 文件管理器。

你可以得到 Material Design 的用户界面，以及剪切、複製、刪除、壓縮、解壓等基本功能。此外，你還可以調整主題。

📥 GitHub

📥 F-Droid

📥 Play 商店

2、Simple File Manager ​

Simple File Manager 是一個有用的應用程序，由一個專注於製作“簡單”移動工具的開發團隊開發。

它是一個輕巧而多功能的文件管理器，具有基本的文件管理功能。

📥 GitHub

📥 F-Droid

📥 Play 商店

3、Little File Manager ​

只想要一個瀏覽和訪問文件的小應用？Little 文件管理器應該是一個不錯的選擇，它讓你能夠像複製粘貼文件那樣做基本操作。

📥 GitHub

📥 F-Droid

網頁瀏覽器 ​

想要使用隱私友好和開源的移動瀏覽器瀏覽網頁嗎？這些選項應該很適合：

1、Firefox ​

Mozilla Firefox 可能是桌面和移動用户 最喜歡的開源瀏覽器。

在安卓上，他們做得很出色，讓它成為一個令人愉悦、快速、隱私保護的體驗。你也可以嘗試 Firefox 的變體，比如 “Firefox Focus”，它是一個簡單的應用程序，退出後會刪除你的歷史記錄。

📥 GitHub

📥 Play 商店

2、DuckDuckGo Private Browser ​

DuckDuckGo Private Browser 是由 隱私友好的搜索引擎 巨頭開發的一個令人興奮的選項。

你可以得到一個極簡的用户體驗，其中包含一些特殊的 DuckDuckGo 功能，比如 應用程序追蹤保護和電子郵件保護。

📥 GitHub

📥 F-Droid

📥 Play 商店

3、Bromite ​

Bromite 是一個安卓上的 Chromium 復刻，具有 隱私增強和廣告攔截功能。

你可以從其官方網站或 GitHub 頁面下載 APK。另外，你可以將其存儲庫添加到 F-Droid 中來安裝和管理更新。

📥 GitHub

📥 F-Droid

📥 網站

4、Tor 瀏覽器 ​

Tor 瀏覽器基於 Firefox，但具有 增強的安全性和隱私保護。

它可能不會提供你最好的用户體驗，但如果你想在瀏覽會話中獲得最大的隱私保護，Tor 瀏覽器可能是一個不錯的選擇。

📥 GitLab

📥 Play 商店

多平台同步或文件共享應用 ​

無論你想要同步通知、播放音樂，還是分享文件/剪貼板內容，你可能不想使用帶有侵入式廣告和差勁的隱私實踐的文件共享應用，以下這些應用可能能夠幫助你更好地完成這些任務：

1、KDE Connect ​

KDE Connect 是一個流行的開源應用程序，可以讓你連接跨設備，例如你的 Linux PC 和安卓手機，以共享剪貼板內容、文件、URL 和通知。

如果你使用 基於 KDE 的發行版，則已經默認安裝了此應用程序。

📥 GitHub

📥 F-Droid

📥 Play 商店

2、LocalSend ​

LocalSend 幫助你將文件發送到附近設備（跨平台）。它是谷歌 Play 商店上幾個 Shareit 克隆品的簡單、無廣告的開源替代品。

有趣的是，它還支持 macOS、Windows 和 Linux，對許多用户而言，這可以是共享文件的一站式解決方案。

📥 GitHub

📥 F-Droid

📥 Play 商店

3、Warpinator（非官方） ​

如果你想要一個移動端的 Linux Mint Warpinator 工具，可以試試這個。

即使 Linux Mint 開發人員也正式提到了它，但是請將其視為同名的非官方版本。

📥 GitHub

📥 F-Droid

📥 Play 商店

4、Zorin Connect ​

如果你想要類似於 KDE Connect 但具有略微更好一些的用户體驗的替代品，可以考慮使用 Zorin Connect。

它提供相同的功能，包括控制音樂和視頻播放、發送文件、控制鼠標以及將手機用作幻燈片演示遠程控制器。

📥 GitHub

📥 F-Droid

📥 Play 商店

播客或有聲讀物播放器 ​

如果你想要在沒有任何干擾的情況下聽播客，並擁有簡單的用户體驗，以下這些開源播客應用程序應該可以幫助你：

1、AntennaPod ​

AntennaPod 是一個 功能強大的開源播客管理器和播放器，可以讓你訪問全球各種各樣的播客。

你可以使用 RSS URL、iTunes 播客資料庫或 OPML 文件很容易地添加（導入和導出）你的源。

📥 GitHub

📥 F-Droid

📥 Play 商店

2、Voice ​

Voice 是一個簡單的播放器，可以讓你輕鬆地播放和管理有聲讀物。它的 用户體驗簡單且高效，可以讓你專注於聽有聲讀物而不是其他功能。

📥 GitHub

📥 F-Droid

📥 Play 商店

RSS 閲讀器 ​

在網上獲取所有信息或將其組織成列表可能很困難。不過，RSS 閲讀器總是可以幫助你優雅地完成這個任務。

如果你已經厭倦了像 Feedly 或 Inoreader 等應用的付款方式，你可以簡單地將你的 RSS 源添加/導入到以下這些應用程序中：

1、Feeder ​

Feeder 是我最喜歡的安卓 RSS 閲讀器應用程序，它提供了 良好的用户體驗和一些自定義選項 來過濾/組織你的源。

它支持深色模式，所以你可以輕鬆地獲取信息而不會累着眼睛。

📥 GitLab

📥 F-Droid

📥 Play 商店

2、Read You ​

Read You 是一個相對較新加入 RSS 閲讀器類別的應用程序，此外它遵循了谷歌的新 Material You UI 風格。

它具備你需要的 RSS 閲讀器的所有基本功能，並提供愉悦的用户體驗。

📥 GitHub

📥 F-Droid

3、NewsBlur ​

需要一個完整的開源新聞閲讀器嗎？NewsBlur 是一個非常有趣的解決方案，它具備一組基本功能，可以滿足你的需求。

它旨在成為谷歌 Reader 的替代品。值得一試！

📥 GitHub

📥 F-Droid

📥 Play 商店

vPN 應用程序 ​

對於大多數 vPN 服務，你將不得不信任公司或服務來保護你的隱私。

然而，如果你使用開源 vPN 應用程序，則可以獲得一定程度的透明度，瞭解客户端的工作方式。因此，與專有的 vPN 應用程序相比，開源 vPN 應用程序可能證明更好的選擇。

1、ProtonVPN ​

ProtonVPN 是 隱私關注的 vPN 服務中最受歡迎的選擇之一。與其他 vPN 應用程序相比,它提供有用的功能，如跟蹤器阻止、安全核心服務器等，以提升隱私保護。

與其他一些 vPN 不同，Proton 的整個產品都是開源的，這使得它成為一個不錯的選擇。

📥 GitHub

📥 F-Droid

📥 Play 商店

2、Mullvad ​

Mullvad 是一個 獨特的 vPN 提供商，不需要太多的個人信息。它生成一個獨特的隨機數字來分配給你一個帳户，你只需要使用你的付款信息來訂閲。

Mullvad 的應用程序是開源的，對於不喜歡 ProtonVPN 的用户來説，它可能是一個很好的選擇。

📥 GitHub

📥 F-Droid

📥 Play 商店

3、IVPN ​

IVPN 以其 極度誠實的營銷 而聞名。在購買之前，它會告訴你是否需要購買 vPN。

該應用程序是開源的，提供基本功能和簡單的用户體驗。

📥 GitHub

📥 F-Droid

📥 Play 商店

漫畫閲讀器 ​

1、Tachiyomi ​

Tachiyomi 是一款 極受歡迎的自由開源的漫畫閲讀器，適用於安卓。

你可以從各種來源瀏覽內容或閲讀下載的漫畫，同時能夠使用分類來組織你的庫。閲讀器可以進行調整以符合你的體驗，還支持淺色/深色主題。

📋 你可以在 Tachiyomi 的 GitHub 發佈區中找到最新的 APK。

📥 GitHub

📥 網站

2、Kotatsu ​

Kotatsu 是另一個適用於 安卓 的開源漫畫閲讀器。你可以瀏覽在線目錄、組織你閲讀的漫畫，並獲得具有離線支持的優化閲讀器。

它採用現代的 Material You 用户界面，可以提供更好的體驗。

📥 GitHub

📥 網站

3、Seeneva ​

需要一個智能的漫畫書閲讀器嗎？Seeneva 是一個不太受歡迎但表現不錯的選擇。

它支持各種漫畫書歸檔格式，如 CBZ、CBR、CB7 等。

📥 GitHub

📥 F-Droid

📥 Play 商店

音樂播放器 ​

從技術上講，如果你只想播放音樂，那麼默認的音樂播放器應該也可以勝任。但是，如果你想要組織你的庫並且擁有一個簡單的音樂播放體驗，以下這些應用程序可能非常適合：

1、Simple Music Player ​

Simple Music Player 是由開發 Simple File Manager 應用程序的同一團隊開發的另一個實用程序。

雖然它提供了一個簡單的體驗，但它具有 直觀的用户界面，可以選擇分組文件、自定義顏色方案，並享受音樂。

📥 GitHub

📥 F-Droid

📥 Play 商店

2. Vanilla Music ​

Vanilla Music 是一個乾淨的開源音樂播放器，支持最常見的音頻格式，並提供基本的功能。

📥 GitHub

📥 F-Droid

📥 Play 商店

筆記應用 ​

筆記可以是個人的或隨手的記錄。然而，使用一個嚴格保護隱私併為你提供更好的安全性的筆記應用是必要的。你可能會寫一些敏感的內容，不應該在隱私控制做得很差的筆記應用中分享這些信息。

1、Joplin ​

Joplin 是一款出色的開源筆記應用程序，也可用於桌面平台。

你可以將你的筆記存儲在本地、加密、同步等等來組織它們。用户體驗可能不是最直觀的，但如果你想要一個開源的、功能豐富的筆記應用，Joplin 不會讓你失望。

📥 GitHub

📥 F-Droid

📥 Play 商店

2、Standard Notes ​

Standard Notes 是一個 方便的選項，提供了默認的端到端加密，並將你的數據存儲在雲端。

你可以選擇高級版來擴展其功能。不過，基本功能應該足夠讓你開始使用。

📥 GitHub

📥 F-Droid

📥 Play 商店

3、Simplenote ​

Simplenote 是一款易於使用的筆記應用，由 WordPress 的開發公司 Automattic 開發。

如果你不想要花哨的功能或龐大的設置選項，這是最好的開源應用程序，可在多個設備之間同步筆記。

📥 GitHub

📥 Play 商店

2FA 和密碼應用程序 ​

管理密碼和雙因素身份驗證代碼非常重要。特別是當我們看到類似 LastPass 的專有密碼管理器經常出現安全漏洞時，你怎麼能信任它們呢？

因此，你可以嘗試使用開源選項，以獲得更好的隱私和透明度，從而放心。

1、KeePassDX ​

KeePassDX 是一個簡單且強大的密碼管理器，適用於不想將其數據與雲同步的用户。

你可以創建資料庫、導出/導入它們，並在任何地方管理你的密碼。它與 KeePassXC 兼容，後者是 Linux 上最好的密碼管理器之一。

📥 GitHub

📥 F-Droid

📥 Play 商店

2、Bitwarden ​

Bitwarden 是 最受歡迎的開源密碼管理器，可以在設備和瀏覽器（帶擴展）之間同步。你也可以在這裏存儲 2FA 令牌。

與上述密碼管理器不同，它同步到雲端。但是，它提供行業標準的保護措施和更高級的功能，以保護你的數據。此外，與其他專有密碼管理器相比，Bitwarden 的高級套餐價格實惠。

📥 GitHub

📥 F-Droid

📥 Play 商店

3、Aegis Authenticator ​

需要一個 開源的 Authy 替代品 嗎？Aegis Authenticator 可能是一個不錯的解決方案，支持行業標準的 2FA 令牌。

📥 GitHub

📥 F-Droid

📥 Play 商店

電子郵件 ​

如果你正在尋找增強隱私和安全性的方法，開源電子郵件應用程序是必不可少的。我們的推薦包括以下應用程序：

1、K-9 Mail（或 Thunderbird） ​

K-9 Mail 是一個在安卓上非常受歡迎的開源電子郵件客户端，具有所有基本功能。

在 2022 年，K-9 Mail 的項目維護者加入了 Thunderbird，利用 Mozilla 的資源和專業知識改進 K-9 體驗。因此，K-9 Mail 最終將變成 Thunderbird 的移動應用程序。

📥 GitHub

📥 F-Droid

📥 Play 商店

2、FairEmail ​

FairEmail 是另一個支持 Gmail、Outlook 等帳户的開源電子郵件客户端。

它提供一個簡單的用户界面和許多實用功能。

📥 GitHub

📥 F-Droid

📥 Play 商店

3、Tutanota ​

Tutanota 是一項 加密電子郵件服務。如果你想要增強隱私和安全性，你可以使用它的移動應用程序。

通過高級訂閲，你可以解鎖某些功能。否則，你可以免費使用它。

📥 GitHub

📥 F-Droid

📥 Play 商店

4、Proton Mail ​

Proton Mail 是另一個 受歡迎的加密電子郵件服務。這可能提供更好的用户體驗（這是我喜歡的）。

這兩個選項都是隱私關注者的絕佳推薦。

📥 GitHub

📥 Play 商店

視頻播放器 ​

如果你需要處理不同的文件格式在移動設備上觀看媒體，那麼開源視頻播放器應該會很有用。嘗試以下選項：

1、VLC ​
