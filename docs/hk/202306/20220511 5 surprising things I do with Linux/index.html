5 個令人驚訝的 Linux 用途 ​

Linux 主導着大多數互聯網、大部分雲計算和幾乎所有的超級計算機。我也喜歡在 Linux 上進行遊戲、辦公工作和發揮創造力。

當你習慣於一個操作系統時，很容易將其他操作系統看作是“應用程序”。如果你在桌面上使用一種操作系統，你可能會認為另一種操作系統是人們用來運行服務器的應用程序，而又一種操作系統是用來玩遊戲的應用程序，依此類推。有時我們會忘記操作系統是計算機管理無數任務的部分（從技術上講，每秒數百萬個任務），它們通常設計成能夠執行各種任務。當有人問我 Linux 能做什麼 時，我通常會問他們想讓它做什麼。這沒有一個單一的答案，所以這裏有五個讓我驚訝的 Linux 用途。

1、用 Linux 進行激光切割 ​

在離我最近的創客空間裏，有一台巨大的工業機器，大約和一張沙發一樣大小，可以根據一個簡單的線條圖設計文件來切割各種材料。這是一台強大的激光切割機，令我驚訝的是，我第一次使用它時發現它只需要通過 USB 線連接到我的 Linux 筆記本電腦上。事實上，在許多方面，與許多台式打印機相比，連接這台激光切割機更容易，因為許多台式打印機需要過於複雜和臃腫的驅動程序。

使用 Inkscape 和 一個簡單的插件，你可以為這台工業激光切割機設計切割線條。你可以為你的樹莓派筆記本設計一個外殼，使用這些知識共享的設計方案來建造 一個密碼鎖盒、切割一個店面標牌，或者你心目中的其他任何想法。而且，你可以完全使用開源軟件來完成這些操作。

2、在 Linux 上進行遊戲 ​

開源遊戲一直都有，最近一段時間也有一些備受矚目的 Linux 遊戲。我建造的第一台遊戲電腦就是一台 Linux 電腦，我覺得我邀請過來一起玩沙發合作遊戲的人們都沒有意識到他們是在 Linux 上進行遊戲。這是一種流暢順滑的體驗，而且取決於你願意在硬件上花費多少，可能上無止境吧。

更重要的是，不僅遊戲正在進入 Linux，整個平台也在進一步發展。Valve 推出的 Steam Deck 是一款非常受歡迎的掌上游戲機，它運行的是 Linux。更好的是，許多開源軟件也在 Steam 上發佈，包括 Blender 和 Krita，這鼓勵了更廣泛的採用。

3、在 Linux 上進行辦公工作 ​

Linux，就像生活一樣，並不總是刺激的。有時，你需要一台計算機來完成一些普通的事情，比如支付賬單、制定預算，或者為學校寫論文或工作寫報告。無論任務是什麼，Linux 都可以作為一台日常的桌面電腦。你可以在 Linux 上進行“平常”的工作。

不僅侷限於知名的應用程序。我在優秀的 LibreOffice 套件中做了很多工作，但在我最舊的電腦上，我使用更簡潔的 Abiword。有時，我喜歡試試 KDE 的官方套件 Calligra，當需要進行精確的 設計工作（包括 專門的過程式設計工作）時，我使用 Scribus。

使用 Linux 進行日常任務最好的地方在於，最終沒有人知道你用了什麼工具來完成最終產品。你的工具鏈和工作流程屬於你自己，結果和封閉的、非開源軟件產生的結果一樣好，甚至更好。我發現，使用 Linux 進行日常任務讓這些任務對我來説更有趣，因為開源軟件本質上允許我開發達到自己預期結果的路徑。我可以嘗試創建解決方案，幫助我 高效完成工作，或者幫助我 自動化重要任務，但我也享受系統的靈活性。我不想去適應我的工具鏈，而是調整我的工具，使它們為我工作。

4、在 Linux 上進行音樂製作 ​

我是一個業餘音樂家，在開始將所有制作工作轉移到計算機之前，我擁有幾台合成器、音序器和多軌錄音機。我轉向計算機音樂之所以用了比較長的時間，是因為我覺得它對我來説不夠模組化。當你習慣於將物理設備互相連接，通過濾波器、效果器、混音器和輔助混音器來路由聲音時，全功能應用程序看起來有點令人失望。

並不是説全功能應用程序沒有受到欣賞。我喜歡能夠打開一個應用程序，如 LMMS，它恰好擁有我想要的一切。然而，在實際使用中，似乎沒有一個計算機音樂應用程序真正擁有我所需要的一切。

當我轉向 Linux 時，我發現它以模組化為基本原則構建了一個龐大的音樂製作環境。我找到了 音序器、合成器、混音器、錄音器、補丁台等的應用程序。我可以在計算機上建立自己的工作室，就像我在現實生活中建立自己的工作室一樣。在 Linux 上，音頻製作得到了飛速發展，今天，開源 應用程序 可以作為統一的控制中心，同時保留了從系統其他位置提取聲音的可擴展性。對於像我這樣的拼貼式製作人來説，這是一個夢幻般的工作室。

5、在 Linux 上進行復古計算 ​

我不喜歡扔掉舊電腦，因為很少有舊電腦是真正報廢的。通常，舊電腦只是被世界其他部分“超越”了。操作系統變得過於臃腫，舊電腦無法處理，因此你不再能獲得操作系統和安全更新，應用程序開始要求你的舊電腦沒有的資源，等等。

我傾向於 收留舊電腦，將它們用作實驗室機器或家庭服務器。最近，我發現在舊電腦上添加一塊固態硬盤作為根分區，並使用 XFCE 或類似的輕量級桌面環境，使得即使是十年前的電腦，也可以愉快地用於期望的工作。平面設計、網頁設計、編程、定格動畫等任務在低配置機器上都是小菜一碟，更不用説簡單的辦公工作了。有了 Linux 驅動的機器，真不知道為什麼企業還要升級。

每個人都有自己喜歡的“救援”發行版。我個人喜歡 Slackware 和 Mageia，它們都還發布了 32 位的安裝鏡像。Mageia 也是基於 RPM 的，所以你可以使用像 dnf 和 rpmbuild 這樣的現代打包工具。

多説一句：Linux 服務器 ​

好吧，我承認在服務器上使用 Linux 並不令人驚訝。實際上，對於那些瞭解 Linux 但自己不使用 Linux 的人來説，當提到 “Linux” 時，數據中心通常是他們首先想到的。然而，這種假設的問題在於它似乎明顯地認為 Linux 在服務器上應該表現出色，好像 Linux 根本不需要努力一樣。這是一種令人讚賞的情緒，但實際上，Linux 在服務器上表現出色是因為全球開發團隊付出了巨大努力，讓 Linux 在其所從事的工作上特別有效。

Linux 之所以成為強大的操作系統，主要是因為它驅動着大部分互聯網、主導着大部分雲計算、幾乎所有現有的超級計算機以及更多應用領域。Linux 並非止步不前，儘管它有着豐富的歷史，但它並沒有深陷傳統而無法進步。新技術正在不斷發展，Linux 也是這一進步的一部分。現代 Linux 適應了不斷變化的世界對增長需求的要求，使得系統管理員能夠為全世界的人們提供網絡服務。

這並不是 Linux 的全部能力，但也絕非小小的成就。

Linux 並不那麼令人驚訝 ​

我還記得第一次遇到一個從小就使用 Linux 的人的事情。在我使用 Linux 的大部分時間裏，這種情況似乎很少發生，但最近這種情況相對較為普遍。我記得最令人驚訝的一次是遇到一個年輕的女士，帶着幼兒，看到我當時穿着的那件極客風格的 T 恤衫，她隨意地提到她也使用 Linux，因為她從小就接觸它。這實際上讓我有點嫉妒，但隨後我想起，在我成長的過程中，桌面電腦上根本沒有 Unix 的 存在。然而，想到 Linux 在過去幾十年裏的輕鬆發展，確實令人愉快。成為其中的一員更是樂趣無窮。
