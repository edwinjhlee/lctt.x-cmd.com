你的筆記本電腦上有哪些貼紙？ ​

你的筆記本電腦就像一塊空白的畫布，可以用來展示個性化的裝飾。你最喜歡的貼紙是什麼？參與我們的調查，然後看看其他開源愛好者都説了些什麼。

去年 12 月剛剛換了工作用的筆記本電腦後，我意識到我有多麼喜歡給我的工作設備貼貼紙。這些貼紙有些是過去活動的紀念品，有些是我熱衷的項目的標誌，還有一些則只是為了好玩！

因為好奇別人的筆記本上貼了什麼，我對周圍的同事朋友問了一圈。

無障礙倡導者 ​

這是我的工作筆記本電腦（你能看出我對 Drupal 的熱愛嗎）。我最喜歡的貼紙是有輪椅的 Druplicon... 當 Drupal 8 發佈時，我們把這個標誌 和輪椅結合在一起，因為我所在的機構專注於無障礙性。

— AmyJune Hineline

充滿活力的 Java ​

自從我還是個孩子的時候，我的電腦和其他東西上就一直有貼紙。我認為我最喜歡的要麼是 “Tux”，要麼是 “Linux Inside”。它們大多與領域相關，只有一些不相關的。在右下角，我有一個運行在“湯姆貓”上的 Java 貼紙（哈哈）- 這是我職業生涯中花費大部分時間的領域。

— Alan Formy-Duval

實用目的 ​

嗯，我沒有貼任何貼紙。然而，我在我的兩台筆記本電腦上粘了絨麪條，用來固定我的移動硬盤，這樣我在公交車上玩遊戲時就不會掉落了。我還粘了一個鎖槽。

— Rikard Grossman-Nielsen

保持外觀 ​

雖然這不是最裝飾得最多的筆記本電腦，但我喜歡這套集合（你知道的，很難在沒有旅行的情況下獲得更多！）

我最喜歡的是“最後一個提交的人是維護者”。這是對維護狀態的諷刺性評論，也承諾代碼將因此而繼續存在。

主要是關於我使用或貢獻的事物，我認為有意義，或者只是覺得這個貼紙很棒。

— John 'Warthog9' Hawley

蓋掉 Windows ​

我從不在筆記本電腦上貼貼紙，因為對我來説，真正酷的貼紙似乎都是我沒有的那些（一個脾氣暴躁的老人説的）。

但是我孩子們在高中時用過的那台舊的組裝計算機，一台擁有 3GHz Core Duo 處理器和 8GB 內存的機器上貼着一個我幾年前在温哥華的 Linux 基金會開源峯會上拿到的 Open Mainframe 貼紙。我相當喜歡那個貼紙。

還有，因為在我的生活中，Control 鍵位於 A 鍵旁邊，而不是在底部行，所以我周圍有一些鍵盤上有一個 CTRL 貼紙在 CapsLock 鍵上，還有一個 CAPS 貼紙在 Control 鍵上，它們與 GNOME 調整工具中的 交換 Ctrl 和 CapsLock 選項 一起使用。

最後，過去我會剝掉那些帶有 Windows 標誌的貼紙，因為當時我唯一的選擇是購買帶有 Windows 税的計算機，並用 Linux 貼紙覆蓋上面的膠片。同樣，對於帶有 Windows 標誌的 Super 鍵的鍵盤，我也會這樣做。

紀念品 ​

迄今為止，Kanopi 貼紙是我最喜歡的貼紙。它不僅閃閃發光，而且呈現出七彩光澤，它時刻提醒我這家公司是多麼令人驚奇。他們真的把員工放在首位，並在選擇與 Kanopi 的整體公司使命和願景相符的客户項目時非常周到。

Curt V8 貼紙是對一位親密朋友的紀念。他熱愛福特，而我丈夫喜歡雪佛蘭。這種有趣的競爭導致我們在車庫裏亂放着福特和雪佛蘭的物品，這取決於我們在哪家住。每次我看到這個仿製的福特貼紙時，我都會微笑，因為我生活在一個雪佛蘭家族。

各種貼紙代表了我們多年來的家庭冒險。約會之夜，朋友，家庭公路旅行，驚險的徒步探險（天使閣），以及我年幼孩子爭取從每個城市和州獲得一張警察貼紙的動力。

—Kristine Strange

會議福利品 ​

龍是 我所就讀大學的吉祥物。我還貼了一些 Gilmore Girls 和咖啡貼紙。

這是我女兒房門的照片，上面貼滿了我多年來從各種會議上帶回來的貼紙。

— Cindy Williams

貼上雞 ​

這是我非工作用的筆記本電腦。我的工作筆記本電腦基本上被覆蓋在一層蜂窩狀的六邊形貼紙中，上面印有我們的產品、我使用和支持的開源項目，以及至少一個 Opensource.com 的六邊形貼紙。 : )

我無法挑出最喜歡的，因為它們都是我喜歡的，否則我就不會把它們貼在我隨身攜帶的筆記本電腦上。我特別喜歡雞、渡鴉和手持刀具的 Sergi the Cat。

—Kevin Sonney

美食趣味 ​

我過去經常在筆記本電腦上貼滿貼紙。去年買的這台電腦很快就貼滿了：

我最喜歡的是杯子蛋糕和甜甜圈標誌，因為是我自己畫的。我剛剛購買了一台 System76 的 Darter Pro 筆記本電腦，我非常喜歡它。我得到了一堆很酷的貼紙，但我一直不確定是否要把它們貼在筆記本上。我不知道為什麼。

— DJ Billings

保持簡潔 ​

我在我的筆記本電腦上不貼很多貼紙，但目前正在使用的這枱筆記本上貼着我最喜歡的兩個貼紙，它是 System76 的 Darter Pro。

—Don Watkins

生活的必需品 ​

我還包括了我的水瓶。我想我更喜歡那些貼紙。

啤酒，狗，音樂，牛角麪包。我還需要什麼？

— Katie Sanders

我的座右銘 ​

我最喜歡的貼紙是 “yeet or be yeeted”。

— Faye Polson

大蒜 ​

大部分貼紙都是專業的，但 “Greetings from Hamunaptra”、“City of the Dead” 貼紙隱晦地參考了我最喜歡的電影之一《木乃伊The Mummy》（1999），是由 Brendan Fraser 和 Rachel Weisz 主演的。

旗幟和 “Blackbeard's Bar & Grill” 貼紙指的是對我完全痴迷的 “Our Flag Means Death”。

而大蒜則是我朋友商店的 Cosmic Garlic 貼紙。大蒜在民間被用作各種疾病的草藥療法，所以在疫情期間把它放在筆記本電腦上似乎是一件好事。

— Tiffany Bridge

開源項目 ​

我通常會貼上我使用、貢獻或欽佩的項目的貼紙。統計數據顯示，我的筆記本電腦現在應該被覆蓋了更多的貼紙。我已經三年沒參加科技會議了，所以進展比以往慢一點。

— Seth Kenlon

Drupal 裝點一新 ​

我會添加一些代表我在技術領域的貼紙。所以我會包括我所參與的組織、我參加過的活動和我支持的項目。

見到人們筆記本電腦上的 Drupal 熊總是很有趣，因為我設計了它。

請注意，我所有的貼紙都貼在筆記本電腦外殼上以便保存。

— April Sides

對 WordPress 狂熱 ​

我很難選出最喜歡的，但可能是 “Michelle wapuu”！她就是我！

貼紙 “I press all the words” 和 “WordPress is my super power” 是來自 WordCamp Rochester，所以它們對我來説很重要。

基本上，如果我和某個貼紙有淵源（比如我在營地演講過），或者我只是喜歡它，我就會貼上它！

— Michelle Frechette

對藝術的熱衷 ​

我非常偏愛藝術貼紙。在電腦上看到藝術作品讓我想起認識的人和使用這台電腦時的經歷。

我最喜歡的是我的伴侶給我的悲傷表情 Midsommar 貼紙。第一次看完電影后，我們在劇院外花了幾個小時討論它，一直討論到深夜。直到今天我們還在提到它。

— Jonathan Daggerhart

自定義外觀 ​

我在 2019 年買了一台新的旅行筆記本電腦，自那以後一直保持着原樣，因為我沒有參加任何活動。我的工作筆記本電腦上有一個女神 Ereshkigal 的定製外觀貼紙，我以她的名字來命名這台電腦。

— Sallie Goetsch

GNU Emacs ​

一個 GNU Emacs 的貼紙。

— Sachin Patil

Opensource.com ​

在看到大家的回覆後，也許收到了非常聰明的社區經理寄來的一些很酷的貼紙...

好吧，好吧，我投降了！AmyJune、Don 和 Sachin 説服我在筆記本電腦上貼一個貼紙。

這是一張顯示我筆記本電腦上獨特貼紙的照片：

— Chris Hermansen

貼紙和開源 ​

你不必為你的計算機貼滿貼紙。這不是必須的，當然這也不能説明你比其他人更或更少熱愛開源。但如果你喜歡一個開源項目，很有可能它有一款貼紙可以用來裝飾你的計算機（或者你的門、水瓶或 USB 麥克風）。請放心，如果你熱愛開源，同時你也喜歡貼紙，那兩者之間有很強的交集！
