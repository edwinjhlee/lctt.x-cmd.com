“發行版快閃”的七宗罪 ​

你在“發行版快閃”中做錯了什麼？你能做得更好嗎？當然可以。在這裏，我們告訴你如何做。

“發行版快閃Distro hopping” 是指經常嘗試新的 Linux 發行版，以尋找樂趣或找到適合你的完美髮行版的習慣。

畢竟，有着 數百種 Linux 發行版，而且時不時就有新的版本出現。你可能會擔心錯過它們，而去嘗試 Linux 社區的最新潮流。

無論你為何這樣做，不管你喜歡與否，人們會犯下一些錯誤，這讓“發行版快閃”的體驗變得糟糕。

這些錯誤是什麼？讓我帶你一一瞭解：

1、不進行備份 ​

嗯，你想要更換髮行版，由於過於興奮，你毫不猶豫就切換了。

但是，如果你沒有備份重要的、經常訪問的數據，你可能需要重新配置系統和組織你需要的數據。

所以，如果你有備份，無論你做什麼，你需要的數據始終可訪問，並幫助你在發行版之間快速的跳來跳去。

2、不檢查顯卡的驅動支持 ​

用户常常忽略發行版與其系統中的顯卡的兼容性，而抱怨發行版有問題。

你必須確保你的發行版對你的顯卡有開箱即用的支持。

如果你像我一樣有一塊英偉達顯卡，你應該只選擇提供帶有英偉達支持的 ISO，或在啓動菜單中內置了該支持的發行版。

例如，在 Linux Mint 上你需要 安裝英偉達驅動。雖然大部分情況下這是一個簡單且沒什麼麻煩的過程，但並不是每個人都願意為之付出努力。你也可以選擇 Pop!_OS 或 Ubuntu，它們默認情況下與英偉達顯卡兼容良好。

3、抱有過高期望 ​

沒有誰能完美地挑選出你需要和你可能喜歡的東西。

所以，不要聽從他人的建議。自己進行研究，選擇你想嘗試的下一個發行版。

即使你知道你想要什麼，也不要期望新的發行版一定會比你當前的發行版更好。各個發行版在許多方面都有所不同。

你的下一個發行版可能解決了你遇到的問題，但也可能會帶來你沒有預料到的新問題。 最好假設你可能會遇到你沒有預料到的困擾。

所以，如果你要進行“發行版快閃”，請先繫好安全帶。

4、在物理機上安裝發行版 ​

不要安裝新的發行版來替換你當前的發行版。

如果你直接在你的計算機上更換髮行版，可能會導致一些問題，你可能需要先花時間修復這些問題，甚至在瞭解或體驗 Linux 發行版的最佳部分之前就要這樣做。

相反，你應該使用 立付Live環境 或 虛擬機 來嘗試發行版。

通常，你可以從啓動菜單或“試用Try”選項中進入立付環境，以在安裝 Linux 發行版之前測試一下。

另外，你可以嘗試使用 虛擬機來運行 Linux 發行版。通過使用虛擬機，你可以學習該發行版並進行各種測試，而無需麻煩地更改主機系統。

通過這個選項，你無需改變你的主機系統。你可以測試所有基本要素，如 網絡連接、應用程序可用性、預裝工具 等等，而無需放棄當前的發行版。

5、忽視你的使用場景 ​

發行版太多反而讓事情變得混亂。

一個發行版的某個部分或特性可能引起了你的注意，這讓你認為其他部分也適合你。

你接下來想要嘗試的任何發行版應該完全符合你的需求才行。如果它提供了更多或不同的功能，對你來説不一定是好處。

例如，一個發行版可能提供更多的可定製性，這一般是很好的。但如果你不需要那麼多控制權，那些提供的選項可能會讓你感到不知所措，或者很快對你來説就會像是無用軟件。

你可以瞭解一下有哪些 最佳 Linux 發行版，並根據文章中提到的特點對它們進行分析。

6、更換日常工具 ​

除了發行版，一些用户還更換了他們每天使用的工具。

考慮到工具對你的用户體驗有重大影響，它最終會改變你的工作流程。你可能這樣做是為了嘗試新東西，但你應該堅持那些始終適合你的工具。

也許你已經用上了 最佳基本應用程序，為什麼要改變呢？

只有當工具在新的發行版上無法按預期工作時，你才應該尋找替代方案。

7、不選擇桌面環境 ​

有幾件事可以幫助你縮小在系統上安裝 Linux 發行版的選擇。

其中之一就是 桌面環境。

當然，在選擇一個桌面環境之前，你應該瞭解一下有哪些 最佳桌面環境。一旦選擇了一個，與你想要嘗試帶有任何桌面環境的發行版相比，你就不必頻繁切換髮行版。

你應該停止“發行版快閃”嗎？ ​

你想要探索不同的發行版，並找到最適合自己的一個，這並沒有錯。

然而，如何從一個發行版“快閃”到另一個發行版可能會讓這個過程變得麻煩，並且你可能會抱怨。

你應該 遵循本文中提到的上述要點，在想要切換之前使用 虛擬機 嘗試新的發行版。

現在，你應該能在“發行版快閃”的過程中獲得順滑的體驗了。
