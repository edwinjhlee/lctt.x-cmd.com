棄 Ubuntu 轉 Manjaro 一週後的使用體驗 ​

通常，我用的是基於 Ubuntu 的發行版進行工作，如 Pop!_OS、Zorin OS、Linux Mint 或 Ubuntu 本身。

它們不會干擾我的工作，同時又提供了順滑的軟件更新。更不用説，它們與我使用的英特爾-英偉達系統相容性良好。

所有的一切（可能是主觀的）都能開箱即用。

然而，最近我決定在實體機上切換到 Arch Linux（我大部分時間都是在虛擬機上使用它）。

結果，我最終選擇使用了 Manjaro Linux（一款基於 Arch 的發行版）。

我選擇 Manjaro Linux 的原因 ​

令我驚訝的是，即使是使用 Arch Linux 的立付 USB，我甚至無法解決 “nouveau DRM: core notifier timeout” 錯誤，更別提繼續安裝了。是的，我知道有嚮導式的 Arch Linux 安裝程序，但是不論怎麼樣，連接的顯示器都會閃爍並突出顯示這個錯誤。

解決這個問題的最好辦法是不使用我的最近剛剛升級的英偉達顯卡。

很遺憾，我更喜歡英偉達的顯卡……

AMD 的 RX 6600 XT 的價格與 RTX 3060 Ti 相當；對於 1440p 來説，購買那款顯卡是沒有意義的。

因此，在我這個情況下，RTX 3060 Ti 可能是問題所在。

雖然我找到了一些解決問題的方法，但是我太懶了。我只是想看看能否在不用付出太多努力的情況下體驗一下 Arch Linux。

所以，我做了以下的事情：

下一個最佳選擇就是嘗試任何一個專門簡化了麻煩的 最佳的基於 Arch 的發行版，對吧？

這就是 Manjaro Linux 登場的地方。

Manjaro Linux 是一款流行的基於 Arch 的發行版，並且我注意到每次更新時都有各種改進（在虛擬機上使用時）。

此外，我喜歡 Manjaro 默認主題的強調色，很適合我的桌面體驗。

所以，我決定試試看……

Manjaro Linux: 起步有點困難 ​

使用專有的英偉達驅動程序安裝 Manjaro 時我沒有遇到任何問題。然而，最近的一個小版本更新，Manjaro Linux 21.2.6， 把我的系統弄亂了。

我無法訪問登錄界面和 TTY（我只能看到主板製造商的標誌）

因此，我只能使用最新的 ISO 重新安裝 Manjaro Linux，到目前為止一切都還好（千萬別出問題）。

在我使用 Manjaro Linux 的過程中，我注意到了一些事情，有好有壞。

在這裏，我分享一些我的經歷。如果你還沒有嘗試過，這些經驗應該對你幫助很大，可以讓你更多地瞭解它。

1、簡單的安裝 ​

基於 Arch 的發行版的主要亮點是使安裝過程變得簡單。對我來説，完全沒有遇到任何問題。

在我的第二塊硬盤上安裝 Manjaro Linux 是一件輕而易舉的事情。引導加載程序正確配置，顯示了 Manjaro 主題的啓動菜單，讓我可以選擇 Windows/Manjaro Linux 進行雙啓動。

2、Manjaro 歡迎頁 ​

當嘗試新東西時，歡迎體驗在用户體驗中佔據了一大部分重要性。在這方面，Manjaro Linux 沒有讓人失望。

如果你仔細關注歡迎屏幕上提供的信息，你可以獲得所有必要的信息。

GNOME 佈局管理器能讓你選擇一個合適的佈局，使你更加舒適。

3、包管理器快速且功能豐富 ​

考慮到 GNOME 是我最喜歡的桌面環境，我在軟件中心（甚至是像 Pop!_Shop 這樣特定於發行版的商店）上有過糟糕的經歷。

雖然它們可以完成工作，但有時它們對我的期望反應不及預期。

在 Manjaro Linux 中，我發現安裝了 Pamac 作為包管理器。這似乎是 在 Manjaro Linux 上安裝和卸載軟件的最佳方式之一。

根據我的經驗，它在安裝和卸載軟件時非常快速。在安裝某些軟件時，你還會收到關於軟件包衝突或是否需要替換/刪除某些軟件包的提示。當你安裝某些東西時，包管理器提供了關於可選/必需依賴項的大量信息。

總體來説，體驗非常流暢，沒有出現任何麻煩。為了提升體驗，包管理器還可以通過調整 pamac 的偏好設置，快速啓用對 Flatpaks/Snaps/AUR 的支持。

所以，你不必使用終端或不同的軟件商店。一切都可在一個統一的平台下獲得，這大大節省了時間。

4、嘗試 ZSH Shell ​

我習慣於在基於 Ubuntu 的發行版上使用 Bash shell。然而，Manjaro Linux 默認使用 Zsh shell。我相信 Zsh 比 Bash 更好，不過我很快會在另一篇文章中介紹並深入比較。

換句話説，我可以直接嘗試不同的東西。令我興奮的是，終端提示符和遵循 Manjaro 品牌的Shell（或終端）的主題也採用了 Manjaro 的強調色，非常令人印象深刻！

因此，我沒有必要在此處 自定義終端的外觀。

要了解更多信息，你可以查看一些關於 Zsh 是什麼 以及 如何安裝它 的信息。

5、缺乏官方軟件支持 ​

我希望這個情況能夠很快改善。但目前來説，許多軟件/工具只提供對 Ubuntu 和 Fedora 的官方支持。

你可以在各種工具中找到官方的 DEB/RPM 包，但它們都不能直接在 Manjaro Linux 上使用。

你得依賴 Arch Linux 倉庫或 AUR 中提供的軟件包。

幸運的是，很有可能在 AUR 或社區或發行版開發者維護的倉庫中找到所需的軟件。就像我能夠在 Manjaro Linux 上運行 Insync，並使用文件管理器的集成擴展。

然而，由於缺乏對該平台的官方支持，你可能會錯過一些功能或快速更新。

當然，如果你依賴於 Flatpak 或 Snap 軟件包，這對你來説應該不是個問題。此外，如果你是 Linux 的新手，你可以參考我們的 Flatpak 指南 獲取更多信息。

6、缺少分數縮放 ​

我有一個由 1080p 和 1440p 分辨率組成的雙顯示器。因此，分數縮放很有幫助，但我可以不用它來操作。

要在 Manjaro 上啓用分數縮放，你需要安裝支持 X11 縮放的 Mutter 和 GNOME 控制中心軟件包。這些軟件包包括：

  • mutter-x11-scaling
  • gnome-control-center-x11-scaling

這將替換你現有的 Mutter 和 GNOME 控制中心軟件包。因此，你將失去桌面的默認主題/強調色設置。

你可能需要使用 GNOME “調整Tweaks”應用來將一切調整正確。但是，這可能會令人感覺麻煩。

總結 ​

總體而言，我喜歡在 Manjaro Linux 上的桌面體驗。如果那個更新沒有搞壞我的系統，我認為我會繼續使用 Manjaro Linux 作為我的新日常操作系統。
