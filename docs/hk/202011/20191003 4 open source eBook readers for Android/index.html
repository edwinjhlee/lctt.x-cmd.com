四款安卓開源電子書閲讀器 ​

你在尋找新的電子書閲讀軟件嗎？來看看這四款適用於安卓的可靠的開源電子書閲讀器吧。

誰不想有一個好的閲讀體驗？與其將時間浪費在社交媒體或即時消息軟件上，不如在自己的安卓手機或平板上閲讀一本書、雜誌或其他文檔。

要做到這一點，你需要的是一個適合的電子書閲讀軟件。接下來讓我們來看一看四款可靠的、開源安卓電子書閲讀器。

Book Reader ​

那我們先從我最喜歡的一款開源安卓電子書閲讀器開始：Book Reader。它基於現在專有的 FBReader 應用的開源老版本。像 FBReader 的早期版本一樣，Book Reader 小而簡單，但是好用。

優點：

  • 易於操作。
  • 該應用界面遵循安卓的 Material Design 指南，因此非常乾淨。
  • 你可以為電子書添加書籤，並將文本分享至你設備上的其他應用。
  • 不斷提供除英語外的其他語言的支持。

缺點

  • Book Reader 的自定義選項較少。
  • 沒有內置詞典或支持外部詞典的功能。

支持的電子書格式：

Book Reader 支持 EPUB、.mobi、PDF、DjVu、HTML、純文本、 Word 文檔、RTF 和 FictionBook。

Book Reader 的源碼在 GNU GPL 3.0 下授權，你可以在GitLab中找到它。

Cool Reader ​

Cool Reader 是一個靈活易用的電子書軟件。雖然我覺得該軟件的圖標會讓想起 Windows vista 中的圖標，但它確實有一些好用的功能。

優點

  • 高度自定義，你可以更改字體、行寬、段間距、連字符、字體大小、頁邊距以及背景色。
  • 你可以覆蓋書中的樣式表。我發現這對於兩三本將所有文本設置為小寫字母的書很有用。
  • 它會在設備啓動時自動搜尋設備中的新書資源。你也可以查閲古騰堡計劃和互聯網檔案館中的書籍。

缺點

  • Cool Reader 的界面並不是極簡或者説最現代化的。
  • 雖然它開箱即用，但實際上你需要調整一些配置來更舒適地使用 Cool Reader。
  • 應用的默認詞典是專有的，儘管你可以用開源的詞典來替換掉它。

支持的電子書格式：

你可以使用 Cool Reader 來瀏覽 EPUB、小説、純文本、RTF、HTML、CHM 和 TCR（Psion 系列掌上電腦的電子書格式）文件。

Cool Reader 的源碼在 GNU GPL 2 下授權，你可以在 Sourceforge 中找到它。

KOReader ​

KOReader 最初是為了 E Ink 電子書閲讀器創建的，但後來發現它可用於安卓。在測試它時，我發現 KOReader 在同等程度下既有用又令人沮喪。很明顯它絕不是一款不好的應用，但不會是我的首選。

優點

  • 高度自定義。
  • 支持多種語言。
  • 它允許你使用詞典（若你已安裝）或者 Wikipedia（若你已連接至網絡）來查單詞。

缺點

  • 每一本書你都需要改變設置。在你打開一本新書時，KOReader 不會記住相關設置
  • 它的界面會讓人覺得是一款專門的電子書閲讀器。該應用沒有安卓的外形和感受。

支持的電子書格式：

你可以查閲 PDF、DjVu、CBT、以及 CBZ 電子書。它也支持 EPUB、小説、.mobi、Word 文檔、文本文件和 CHM 文件。

Cool Reader 的源碼在 GNU Affero GPL 3.0 下授權，你可以在 GitHub 上找到它。

Booky McBookface ​

是的，這確實是這款電子書閲讀器的名字。它是這篇文章中最基礎的電子書閲讀器，但不要因此（或者這個傻乎乎的名字）使你失望。Booky McBookface 易於使用，並且有一件事它做的很好。

優點

  • 沒有多餘的裝飾。只有你和你的電子書。
  • 界面簡潔。
  • 在安卓啓動欄中的長按軟件圖標會彈出一個菜單，你可以從中打開正在閲讀的最後一本書、獲得未讀書籍的列表、或者查找並打開設備上的一本書。

缺點

  • 軟件中幾乎沒有配置選項——你可以更改字體大小和亮度，僅此而已。
  • 你需要使用屏幕底部的按鈕瀏覽電子書。點擊屏幕邊緣無法操作。
  • 無法為電子書添加書籤。

支持的電子書格式

你可以使用該軟件閲讀 EPUB 格式、HTML 文檔，或純文本格式的電子書。

Booky McBookface 的源碼在 GNU GPL 3.0 下授權，你可以在 GitHub 中找到它。

你有最喜歡的安卓開源電子書閲讀器嗎？在社區中留言分享一下吧。
