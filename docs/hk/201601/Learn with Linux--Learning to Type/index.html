與 Linux 一起學習：學習打字 ​

  • 與 Linux 一起學習: 使用這些 Linux 應用來征服你的數學學習

Linux 提供大量的教學軟件和工具，面向各個年級以及不同年齡段，提供大量學科的練習實踐，其中大多數是可以與用户進行交互的。本“與 Linux 一起學習”系列就來介紹一些教學軟件。

很多人都要打字，操作鍵盤已經成為他們的第二天性。但是這些人中有多少是依然使用兩個手指頭來快速地按鍵盤的？即使學校有教我們使用鍵盤的方法，我們也會慢慢地拋棄正確的打字姿勢，養成只用兩個大拇指玩鍵盤的習慣。（LCTT 譯註：呃，你確認是拇指而不是食指？）

下面要介紹的兩款軟件可以幫你掌控你的鍵盤，然後你就可以讓你的手指跟上你的思維，這樣你的思維就不會被打斷了。當然，還有很多更炫更酷的軟件可供選擇，但本文所選的這兩款是最簡單、最容易上手的。

TuxType （或者叫 TuxTyping） ​

TuxType 是給小孩子玩的。在一些有趣的遊戲中，小學生們可以通過完成一些簡單的練習來 Get “雙手打字以示清白”的新技能。

Debian 及其衍生版本（包含所有 Ubuntu 衍生版本）的標準軟件倉庫都有 TuxType，使用下面的命令安裝：

sudo apt-get install tuxtype

軟件開始時有一個簡單的 Tux 界面和一段難聽的 midi 音樂，幸運的是你可以通過右下角的喇叭按鈕把聲音調低了。(LCTT 譯註：Tux 就是那隻 Linux 吉祥物，Linus 説它的表情被設計成剛喝完啤酒後的滿足感，見《Just For Fun》。)

最開始處的兩個選項“Fish Cascade”和“Comet Zap”是打字遊戲，當你開始遊戲時，你就投入到了這個課程。

第3個選項為“Lessions”,提供40多個簡單的課程，每個課程會增加一個字母讓你來練習，練習過程中會給出一些提示，比如應該用哪個手指按鍵盤上的字母。

更高級點的，你可以練習輸入句子。不知道為什麼，句子練習被放在“Options”選項裏。（LCTT 譯註：句子練習第一句是“The quick brown fox jumps over the lazy dog”，包含了26個英文字母，可用於檢測鍵盤是否壞鍵，也是練習英文打字的必備良藥啊。）

這個遊戲讓玩家打出單詞來幫助 Tux 吃到小魚或者幹掉掉下來的流星，訓練速度和精確度。

除了練習有趣外，這些遊戲還可以訓練玩家的拼寫、速度、手眼配合能力，因為你如果認真在玩的話，必須盯着屏幕，不看鍵盤打字。

GNU typist (gtype) ​

對於成年人或有打字經驗的人來説，GNU Typist 可能更合適，它是一個 GNU 項目，基於控制台操作。

GNU Typist 也在大多數 Debian 衍生版本的軟件庫中，運行下面的命令來安裝：

sudo apt-get install gtype

你估計不能在應用菜單裏找到它，只能在終端界面上執行下面的命令來啓動：

gtype

界面簡單，沒有廢話，直接提供課程內容，玩家選擇就是了。

課程直截了當，內容詳細。

在交互練習的過程中，如果你輸入錯誤，會將錯誤位置高亮顯示。不會像其他漂亮界面分散你的注意力，你可以專注於練習。每個課程的右下角都有一組統計數據來展示你的表現，如果你犯了很多錯誤，就可能無法通過關卡了。

簡單練習只需要你重複輸入一些字符，而高階練習需要你輸入整個句子。

總結 ​

如果你想練練自己的打字水平，Linux 上有很多軟件給你用。本文介紹的兩款軟件界面簡單但內容豐富，能滿足絕大多數打字愛好者的需求。如果你正在使用、或者聽説過其他的優秀打字練習軟件，請在評論欄貼出來，讓我們長長姿勢。
