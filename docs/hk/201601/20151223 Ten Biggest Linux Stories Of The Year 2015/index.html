2015年 Linux 世界的十個大事件 ​

2015年已經過去，我在這裏（It's FOSS)發表《2015年的大事件》系列。這個系列的第一篇文章為《2015年 Linux 世界的十個大事件》。這些事件在 Linux 世界中產生了極大的影響，無論它們是積極的還是消極的。

我總結了2015發生的十件產生了最大影響的事件。讓我們來看看：

2015年度十大 Linux /開源相關事件 ​

補充一句，以下這些事件沒有按照時間順序排列。

微軟與 Linux 的結盟 ​

在9月下旬，所有人聽到微軟構建了自己的 Linux 發行版這個消息時都大吃一驚。其在後來被揭露，這其實是一個微軟開發的用於它的 Azure cloud switches 的軟件。

但故事還沒結束。微軟真的與 Canonical（Ubuntu Linux 的母公司）達成合作來開發 HDInsight，這是微軟在 Azure 上構建的 Hadoop 大數據服務。 Ubuntu 是微軟在其上部署應用的第一個 Linux 系統。

微軟會繼續保持它與 Linux 的關係嗎？ 還是在使用 Linux 達到其目的（Azure）就會收手？只有時間能告訴我們一切。

微軟發佈適用於 Linux 的 Visual Studio Code ​

在微軟發佈 Linux 發行版引起喧囂之前，微軟扔下了另一枚炸彈——發佈 Linux 版 Visual Studio Code, 與其一併發佈的還有 Windows 版以及 OS X 版。儘管 Visual Studio Code 並不是開源的，從某種意義上講，發佈 Linux 版本仍然是 Linux 用户的勝利。（LCTT 譯註：此處原文消息有誤，Visual Studio Code 已開源。）無論如何，Linus Torvalds 曾説過一句很著名的話：“如果微軟給 Linux 開發過一款應用的話，這就意味着我已經贏了”。

你可以看這個教程來學習如何在 Ubuntu 中安裝 Visual Studio Code。

蘋果公司開源編程語言 Swift ​

在向 Linux 及開源“示愛”方面，蘋果公司也不甘示弱。蘋果用來製作 iOS 應用的首選編程語言 Swift，現已開源並移植到 Linux 中。雖然其還在測試中，但你已經可以輕易地在 Ubuntu 中安裝 Swift。

但是，蘋果就是蘋果，它開始吹噓其為“第一個視開源開發為公司關鍵的軟件開發策略的計算機公司巨頭（原文如此）”。

Ubuntu 手機終於發佈 ​

Ubuntu 手機終於在今年年初發布。因其早期使用者及開發者，Ubuntu 深受 Ubuntu 社區喜愛。主流智能機用户仍然迴避它，主要是因為該系統還在重度開發中。對於 Ubuntu 手機的問世，2016年將成為決定性的一年。

Jolla 遭受經濟危機 ​

Jolla 是 Sailfish OS 這個基於 Linux 的智能手機系統的幕後公司，它遭受了嚴重的財政困難。這導致了一半的Jolla 員工被裁。

Jolla 在2014年針對它的平板電腦完成了一次非常成功的眾籌，顯然，他們將大部分預算都花在了 Sailfish OS 的開發上，而在主要投資者退出後，公司正在掙扎以求生存。

不過有一個好消息，Jolla 成功拿到了一些雄厚的資金，而且他們已經繼續運營了。

Firefox OS 已死 ​

作為安卓的開源替代品，Mozila 的移動操作系統 Firefox OS 在去年底慢性死亡。本打算在發展中國家售賣低至25美金的智能手機，可基於 Firefox OS 的手機卻一直沒有流行起來。我認為主要原因是它的硬件配置不高，以及它缺少流行應用。

在十二月，Mozilla 宣佈其將停止開發 Firefox OS，並停止出售 Firefox 智能手機。

雖然沒有正式宣佈過，我認為 Tizen，這個 Linux 基金會旗下的基於 Linux 的移動操作系統，也已經消失了。我沒有看到任何關於 Tizen 開發的消息，而且 Linux 基金會從未推動過它的開發。Tizen 何時死亡只是一個時間問題。（LCTT 譯註：此處原文消息有誤，Tizen 在2015年發佈了 3.0 版本。）

“Ubuntu 家族”內訌 ​

五月份時，Kubuntu 項目的領導者 Jonathan Riddell 被 Ubuntu 社區委員會強制要求下台，這引起了很多激烈的討論。Jonathan 曾質問 Ubuntu 所收捐款的使用情況，他抱怨 Kubuntu 從未見到過這些錢。

這導致了兩方的互相譴責。最終。Ubuntu 的大老闆，Mark Shuttleworth 要求 Jonathan 下台。

女性 Linux 內核開發者因“野蠻的溝通方式”而退出 ​

Linux 之父 Linus Torvalds 以其粗俗的語言而著稱。Linux 內核開發者 Sarah Sharp 也因為嘴快心直而聞名。

Sarah Sharp 曾在2013年與 Linus Torvalds 公開爭執，建議 Linus 將“語言暴力”趕出郵件列表。但 Linus 也沒有委婉地回覆她。

那是在2013年。2015年，Sarah 宣佈她正在逐步停止她在內核社區的工作，因為他們的交流方式缺乏基本禮儀，並且野蠻而充滿褻瀆。

這一舉動讓人們開始討論 Linux 內核社區是否真的應該改變他們的行為方式，還是 Sarah 做的太過分了。

Unity 遊戲編輯器移植到 Linux平台 ​

儘管在 Linux 上玩遊戲仍是 Linux 用户們的阿克琉斯之踵，而在遊戲引擎 Unity 宣佈其正在測試Linux 下的遊戲編輯器時整個社區都沸騰了。因為在渲染圖像時，Linux 是一個最流行的選擇，所以我們推測這將使遊戲開發者向 Linux 靠攏。不過，Unity 是否真的會推出一個最終版本的遊戲編輯器，這個問題還未被證實。

政府機構採用開源軟件 ​

歐洲數個城市的管理機構決定拋棄先前的軟件，並使用其開源的替代品。大多數城市管理機構將 Microsoft Office 替換為 LibreOffice 或 OpenOffice. 一些城市管理機構和公立學校也在跟進，將 Microsoft Windows 換成 Linux。

對於這一行為，削減成本是一個重要的因素，因為城市管理機構通過採用開源軟件省下了無數歐元。

大學也並沒有在採用開源軟件的道路上落後。這一年，我們聽到了大學如何拋棄 Photoshop 改用 Krita 以及大學使用開源 Office 軟件的消息。

總結 ​

與其他年一樣，2015年同樣有許多令 Linux 愛好者感到積極或消極的時刻。我們看到 Linux 的競爭者，如微軟和蘋果，向 Linux 靠攏，政府機構採用開源軟件。同時，我們還見證了 Firefox 智能手機系統的失敗。我想説，這真是喜憂參半的一年。

你認為呢？我希望你們分享你所認為對於 Linuxer 們來説最重要的新聞，和你們對這一年的整體感受。
