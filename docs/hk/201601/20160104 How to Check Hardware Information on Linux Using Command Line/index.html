Linux 系統下查看硬件信息命令大全 ​

有許多命令可以用來查看 Linux 系統上的硬件信息。有些命令只能夠打印出像 CPU 和內存這一特定的硬件組件信息，另外一些命令可以查看多種硬件組件的信息。

這個教程可以帶大家快速瞭解一下查看各種硬件設備的信息和配置詳情的最常用的命令。

lscpu ​

lscpu命令能夠查看 CPU 和處理單元的信息。該命令沒有任何其他選項或者別的功能。

lscpu

運行該命令會看到下面輸出：

lspci ​

lspci是另一個命令列工具，可以用來列出所有的 PCI 總線，還有與 PCI 總線相連的設備的詳細信息，比如 VGA 適配器、顯卡、網絡適配器、usb 端口、SATA 控制器等。

lspci

你可以看到類似下圖的輸出信息。

可以通過運行下面的命令來過濾出特定設備的信息：

lspci -v | grep "VGA" -A 12

運行上面的命令可以看到類似下圖的關於顯卡的信息。

lshw ​

lshw是一個通用的工具，可以列出多種硬件單元的詳細或者概要的信息，比如 CPU、內存、usb 控制器、硬盤等。lshw能夠從各個“/proc”文件中提取出相關的信息。

lshw -short

lsscsi ​

通過運行下面的命令可以列出像硬盤和光驅等 scsi/sata 設備的信息：

lsscsi

會得到類似下面的輸出。

lsusb ​

lsusb命令能夠列出 USB 控制器和與 USB 控制器相連的設備的詳細信息。默認情況下，lsusb命令只打印出概要信息。可以通過使用-v參數打印每一個usb端口的詳細信息。

lsusb

可以看到下面輸出。

Inxi ​

Inxi是一個 bash 腳本，能夠從系統的多個來源和命令獲取硬件信息，並打印出一個非技術人員也能看懂的友好的報告。

默認情況下，Ubuntu 上沒有安裝inxi。可以通過運行下面命令來安裝Inxi：

sudo apt-get install inxi

安裝完Inxi之後，通過運行下面命令能夠得到硬件相關的信息：

inxi -Fx

能夠得到類似下圖的輸出。

df ​

df命令能夠列出不同分區的概要信息、掛載點、已用的和可用的空間。

可以在使用df命令的時候加上-H參數。

df -H

會得到下面的輸出。

Free ​

通過使用free命令可以查看系統中使用的、閒置的和 RAM 的總體數量。

free -m

會看到下面輸出。

Dmidecode ​

dmidecode命令與其他命令不同。該命令是從硬件中的 DMI 表中讀取信息的。

要查看處理器的信息，運行下面命令：

sudo dmidecode -t processor

要查看內存的信息，運行下面命令：

sudo dmidecode -t memory

要查看 bios 的信息，運行下面命令：

sudo dmidecode -t bios

Hdparm ​

hdparm命令可以用來顯示像硬盤這樣的 sata 設備的信息。

sudo hdparm

可以看到下面的輸出。

總結 ​

每個命令都有不同的方式來獲取硬件的信息。在查看特定的硬件信息的時候，可以嘗試使用不同的方式。上面所有的命令列工具在大部分的 Linux 發行版本中都是可以使用的，可以很容易的從倉庫中獲取安裝。
