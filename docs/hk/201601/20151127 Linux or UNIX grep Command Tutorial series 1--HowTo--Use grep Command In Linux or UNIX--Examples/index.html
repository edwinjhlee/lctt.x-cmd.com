grep 命令系列：如何在 Linux/UNIX 中使用 grep 命令 ​

我該怎樣在 Linux、Apple OS X 及其他類 UNIX 系統中使用 grep 命令，你能給我展示一些簡單的例子嗎？

grep 命令用來搜索文本，或從給定的文件中搜索行內包含了給定字符串或單詞的文件。通常來説，grep 顯示匹配到的行。使用 grep 來搜索包括一個或多個正則表達式匹配到的文本行，然後只顯示匹配到的行。grep 被視作在 Linux/ Unix 系統中最有用的命令之一。

你知道嗎 ​

grep 這個名字，來源於一個 Unix/Linux 中的古老的文本編輯器 ed 中執行相似操作的命令：

g/re/p

grep 命令的語法 ​

語法如下所示:

grep 'word' 文件名
grep 'word' 文件1 文件2 文件3
grep '字符串1 字符串2'  文件名
cat 某個文件 | grep '某個東西'
command | grep '某個東西'
command 選項1 | grep '數據'
grep --color '數據' 文件名

###怎麼樣使用 grep 來搜索一個文件###

搜索 /etc/passwd 文件下的 boo 用户,輸入:

$ grep boo /etc/passwd

輸出內容:

foo:x:1000:1000:foo,,,:/home/foo:/bin/ksh

可以使用 grep 去強制忽略大小寫。例如，使用 -i 選項可以匹配 boo, Boo, BOO 和其他組合：

$ grep -i "boo" /etc/passwd

遞歸使用 grep ​

你可以遞歸地使用 grep 進行搜索。例如，在文件目錄下面搜索所有包含字符串“192.168.1.5”的文件

$ grep -r "192.168.1.5" /etc/

或者是：

$ grep -R "192.168.1.5" /etc/

示例輸出:

/etc/ppp/options:# ms-wins 192.168.1.50
/etc/ppp/options:# ms-wins 192.168.1.51
/etc/NetworkManager/system-connections/Wired connection 1:addresses1=192.168.1.5;24;192.168.1.2;

你會看到搜索到 192.168.1.5 的結果每一行都前綴以找到匹配的文件名（例如：/etc/ppp/options）。輸出之中包含的文件名可以加 -h 選項來禁止輸出：

$ grep -h -R "192.168.1.5" /etc/

或者

$ grep -hR "192.168.1.5" /etc/

示例輸出:

# ms-wins 192.168.1.50
# ms-wins 192.168.1.51
addresses1=192.168.1.5;24;192.168.1.2;

使用 grep 去搜索文本 ​

當你搜索 boo 時，grep 命令將會匹配 fooboo，boo123, barfoo35 和其他所有包含 boo 的字符串，你可以使用 -w 選項去強制只輸出那些僅僅包含那個整個單詞的行（LCTT譯註：即該字符串兩側是英文單詞分隔符，如空格，標點符號，和末端等，因此對中文這種沒有斷字符號的語言並不適用。）。

$ grep -w "boo" file

使用 grep 命令去搜索兩個不同的單詞 ​

使用 egrep 命令如下:

$ egrep -w 'word1|word2' /path/to/file

（LCTT 譯註：這裏使用到了正則表達式，因此使用的是 egrep 命令，即擴展的 grep 命令。）

統計文本匹配到的行數 ​

grep 命令可以通過加 -c 參數顯示每個文件中匹配到的次數：

$ grep -c 'word' /path/to/file

傳遞 -n 選項可以輸出的行前加入匹配到的行的行號：

$ grep -n 'root' /etc/passwd

示例輸出:

1:root:x:0:0:root:/root:/bin/bash
1042:rootdoor:x:0:0:rootdoor:/home/rootdoor:/bin/csh
3319:initrootapp:x:0:0:initrootapp:/home/initroot:/bin/ksh

反轉匹配（不匹配） ​

可以使用 -v 選項來輸出不包含匹配項的內容，輸出內容僅僅包含那些不含給定單詞的行，例如輸出所有不包含 bar 單詞的行：

$ grep -v bar /path/to/file

UNIX/Linux 管道與 grep 命令 ​

grep 常常與管道一起使用，在這個例子中，顯示硬盤設備的名字：

# dmesg | egrep '(s|h)d[a-z]'

顯示 CPU 型號：

# cat /proc/cpuinfo | grep -i 'Model'

然而，以上命令也可以按照以下方法使用，不使用管道:

# grep -i 'Model' /proc/cpuinfo

示例輸出:

model		: 30
model name	: Intel(R) Core(TM) i7 CPU       Q 820  @ 1.73GHz
model		: 30
model name	: Intel(R) Core(TM) i7 CPU       Q 820  @ 1.73GHz

如何僅僅顯示匹配到內容的文件名字? ​

使用 -l 選項去顯示那些文件內容中包含 main() 的文件名：

$ grep -l 'main' *.c

最後，你可以強制 grep 以彩色輸出：

$ grep --color vivek /etc/passwd
