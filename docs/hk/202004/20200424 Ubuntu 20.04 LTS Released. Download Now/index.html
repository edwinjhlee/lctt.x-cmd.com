Ubuntu 20.04 LTS 下載及新特性 ​

Ubuntu 20.04 LTS Focal Fossa 終於發佈了。以下是 Ubuntu 20.04 的新功能和下載鏈接，以及Ubuntu 20.04的官方風味版。

等待終於結束了。Ubuntu 20.04 LTS 終於來了，可以下載了！

如果你已經在使用 Ubuntu 19.10，你可能發現沒有太多明顯的差異 —— 但我所看到的改進清單確實令人印象深刻。

如果你想知道有什麼新的東西，我將會提到這個版本的幾個主要亮點。

Ubuntu 20.04 有什麼新特性？ ​

與之前的 18.04 LTS 版本相比，Ubuntu 20.04 LTS 有很多視覺上的改變，同時也包括了一些底層的改進。

當然，隨着 GNOME 3.36 的加入，視覺上的重大升級和性能上的提升是相當明顯的。以下是一段視頻，重點介紹了 Ubuntu 20.04 中的新功能。

  • What's New in Ubuntu 20.04 Take a Look at the Top Features

如果你有興趣的話，你也可以深入到我們的文章中去看看，重點介紹 Ubuntu 20.04 的新功能。

不管是哪種情況，讓我來給你介紹一些亮點。

  • GNOME 3.36 是默認的桌面系統
  • 性能提高了很多
  • 新的 Yaru 主題很華麗，也有黑暗模式。
  • 你不會再看到亞馬遜應用程序，它已經永遠消失了!
  • 改進的 ZFS 支持
  • 你可以獲得最新的 Linux 內核 5.4（LTS）
  • 增加了對 exFAT 的支持
  • 改進硬件和圖形支持
  • 更新軟件 Python 3.8.2
  • Wireguard 已被移植到 Linux 內核5.4，可以在 Ubuntu 20.04 上使用。

如果你想看詳細的功能介紹，請觀看這段視頻，重點介紹 20.04 LTS 的最佳功能。

  • Top 7 Best Features You'll Love in Ubuntu 20.04

如果你是 Ubuntu 的新手，對 Ubuntu 20.04 有疑問，我們也為你提供了一篇快速的 Ubuntu 20.04 FAQ 文章。

從 18.04 和 19.10 升級到 Ubuntu 20.04 ​

如果你已經在使用 Ubuntu 18.04 或 19.10，你可以從系統中輕鬆升級到 Ubuntu 20.04。

這樣一來，當你開始使用新版本的時候，你的文件和大部分的應用程序設置都會保持原樣，而無需從 ISO 中重新安裝。

你可以閲讀此詳細教程來學習如何將 Ubuntu 升級到新版本。

請注意，如果你使用的是 Lubuntu 18.04，請不要升級到 Lubuntu 20.04。Lubuntu 18.04 使用的是 Lxde 桌面，而後面的版本使用的是 LXQt 桌面。這樣升級可能會導致衝突和系統崩潰。

下載 Ubuntu 20.04 LTS ​

你可以抓取 ISO 或 torrent 文件，這取決於你喜歡什麼。

  • Ubuntu 20.04 LTS (ISO)
  • Ubuntu 20.04 LTS (Torrent)

請按照本教程學習如何安裝 Ubuntu。

下載Ubuntu 20.04 LTS官方版下載 ​

如果你想在不同的桌面環境下得到 Ubuntu 的官方版本，請按照下面的鏈接進行操作。

  • Ubuntu MATE 20.04 LTS
  • Kubuntu 20.04 LTS
  • Xubuntu 20.04 LTS
  • Ubuntu Budgie 20.04 LTS
  • Ubuntu Studio 20.04 LTS
  • Lubuntu 20.04 LTS

如果你沒有在各自的官方網站上找到最新的 ISO/torrent 文件，只需前往 cdimages.ubuntu.com 找到所有的版本。

接下來，導航到“發行版名稱” -> “releases” -> “20.04” -> “release”，然後你應該可以找到列出的 ISO 和 torrent 文件的鏈接。

如果你有問題，請參考這篇文章，它回答了關於 Ubuntu 20.04 的常見問題。如果你要安裝，請查看我們推薦的安裝 Ubuntu 20.04 之後要做的事情。
