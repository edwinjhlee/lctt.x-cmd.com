Bodhi Linux 5.1 一覽: 略有不同的輕量化 Linux ​

Bodhi Linux 是一個基於 Ubuntu 的輕量級 Linux 發行版。與其他大多數發行版不同，Bodhi 使用自己的 Moksha 桌面，並專注於為你提供一個可以在舊計算機上運行的最簡設置。

什麼是 Bodhi Linux? ​

Bodhi Linux 最早於 2011 年推出。它以“簡約、高效和用户自定義”為設計理念。開發人員旨在提供一個“實用但不臃腫的系統”。因此，它使用輕量級的 Moksha 桌面，只預裝了基本的應用程序。這一做法是為了給用户一個穩定的平台來構建他們想要的系統。它基於最新版的 Ubuntu 長期支持版本。

Moksha 桌面 ​

起初 Bodhi 是裝載着 Enlightenment 桌面環境的。Bodhi Linux 一直被認為是“Enlightenment 系的” Linux 發行版。事實上，“Bodhi”（菩提）這個詞是基於梵文的“開悟 enlightenment”。

然而，當 Enlightenment 18 版本發佈以後，這一切都改變了。該版本是如此的糟糕，以至於它並沒有集成到 Bodhi 中。Enlightenment 19 發佈後修復了一些問題，但仍然存在一些不足。

在嘗試與 Enlightenment 開發團隊合作卻毫無進展之後，Bodhi 開發者在 2015 年復刻了 Enlightenment 17。新的桌面環境被命名為 Moksha，它是基於梵文單詞“解脱、解放或釋放”。你可以在 GitHub 上找到它的代碼。

5.1.0 有什麼新特性？ ​

  • Bodhi Linux 5.1 Trailer

Bodhi 5.1.0 是這兩年內發佈的第一個版本，也是基於 Ubuntu 18.04 的第二個版本。除了更新包，它還有新的默認圖標和主題。該版本對默認應用程序做了幾處更改。預裝版 Leafpad 取代了 epad 並且 GNOME Web（也被稱為 Epiphany）代替了 [Midori][14]。刪除了 eepDater 系統更新器。

目前有[四個不同的版本][15]的 Bodhi5.1.0 可以[下載][16]: 標準版Standard、硬件支持版Hwe、兼容版Legacy 和軟件包版AppPack。

  • 標準適用於過去十年內電腦配置。它不推送內核更新。
  • 硬件支持版是 Bodhi 家族的新成員，其設計用來包括對更新的硬件的支持，並會接收到內核更新。5.1 版本的使用的是 5.3.0-42 內核。
  • 兼容版是僅有的 32 位版本。它使用“較舊的 4.9.0-6-686 Linux 內核，該內核針對舊的（15 年以上）硬件進行了優化。這個內核也不包括許多老系統不支持的 PAE 擴展。”
  • 軟件包版是為那些想要一個開箱即用的全載系統的人準備的，並預裝了許多應用程序。

Bodhi Linux 的系統要求 ​

最低系統要求：

  • 500 MHz 處理器
  • 256 MB 內存
  • 5 GB 的硬盤存儲空間

推薦系統要求：

  • 1.0 GHz 處理器
  • 512 MB 內存
  • 10 GB 的硬盤存儲空間

體驗 Bodhi Linux ​

![Old Bodhi Linux][17]

由於它是基於 Ubuntu 的，所以安裝 Bodhi 非常簡單。當我登錄到 Bodhi 後，新的主題和圖標集讓我大吃一驚。上次我安裝 Bodhi（包括幾個月前的 5.0）時，我認為它需要換一個新的外觀。之前的主題並沒有什麼問題，但看起來像是二十一世紀初的東西。新的主題使它看起來更具現代感。

![Bodhi Linux 5.1][18]

我也很高興看到 Midori 瀏覽器被 GNOME Web 所取代。我不是 [Midori 瀏覽器][19]的粉絲。對我來説，它總是顯得功能太少了。（不過，隨着 [Midori Next][20] 的推出，這種情況可能會改變。）GNOME Web 更像是我需要的網頁瀏覽器。最重要的是它帶有 Firefox Sync，這樣我就可以同步我所有的書籤和密碼了。

與許多 Linux 發行版不同，Bodhi 並沒有一個獨立的軟件中心。相反，如果你點擊 AppCenter 圖標，它會打開瀏覽器，並導航到 Bodhi 網站的軟件中心頁面 [AppCenter 頁面][21]。這裏的應用程序是按類別排序的，它們中的大多數是[輕量級應用程序][22]。

![Bodhi Linux Appcenter][23]

如果你點擊其中一個頁面並點擊“安裝”，（在你輸入密碼之後）Bodhi 就會安裝它。這是通過一個名為 [apturl][24] 的小程序實現的，它是“是一個非常簡單的從網頁瀏覽器安裝軟件包的方法”。它非常靈巧，我希望更多基於 Ubuntu 的發行版使用它。

總的來説，我喜歡 Moksha 桌面。它堅持我們幾十年來看到的桌面風格（這是我最喜歡的）。它不會影響你，卻很容易改變和定製。我唯一懷念的是，當我按下超級鍵時，應用程序菜單不打開。但我猜你不可能擁有生活中的一切。

結語 ​

我對最近發佈的 Bodhi Linux 感到十分驚喜。過去，我經常折騰它。並且我一直很喜歡它，但最近的這個版本是迄今為止最好的。在某種程度上，他們打破了 Bodhi 只適合老系統的想法，加入了對較新內核的支持。

如果你想換換個環境，同時又想在 Ubuntu 的世界裏尋找新的風景，那就試試Bodhi Linux吧。
