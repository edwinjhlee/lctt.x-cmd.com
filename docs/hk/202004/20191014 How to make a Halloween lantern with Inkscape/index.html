如何使用 Inkscape 製作萬聖節燈籠 ​

使用開源軟件為你最喜歡的萬聖節鬼屋製作一個有趣和怪異的裝飾品。

使用開源軟件裝飾一個獨一無二的萬聖節燈籠！

通常，燈籠的一部分結構體是不透明的，以阻擋內部的光線。燈籠之所以成為燈籠，是因為其去掉了一些東西 ：從結構體上切開的窗口，這樣光線就可以射出。雖然對於照明來説不實用，但是一個有着怪異形狀窗口和隱藏暗色輪廓的燈籠卻可以令人興奮，並創造出很多樂趣。

這篇演示如何使用 Inkscape 創建你自己的燈籠。如果還沒有 Inkscape ，在 Linux 上，你可以從軟件庫中安裝它，在 MacOS 和 Windows 上，你可以從Inkscape 網站 上下載它.

使用材料 ​

  • 模板（A4 或信紙大小）
  • 卡片紙（黑色是傳統色）
  • 描圖紙（可選）
  • 裁紙刀、尺子、切割墊板（可使用工藝切割機/激光切割機代替）
  • 工藝膠
  • LED 茶燈"蠟燭"

安全注意事項：這個項目只使用電池操作的蠟燭。

理解模板 ​

首先，從上面的鏈接下載你所在區域（A4 或信紙）的合適的模板，然後在 Inkscape 中打開它。

灰白色的棋盤格背景是透明的（從技術角度來説，它是 alpha 通道。）

黑色基板構成了燈籠。現在，沒有窗口可以讓光線穿過；燈籠有一個非鏤空的黑色基板。你將在 Inkscape 中使用並集和差集選項來數字化的設計窗口。

藍色虛線表示折線。橙色實線表示參考線。採光窗口不應該放在橙色盒子的外面。

模板的左側是你可以在你設計中使用的一些預先製作好的對象。

創建一個窗口或形狀 ​

  1. 創建一個看起來像你想要的窗口樣式的對象。可以使用 Inkscape 左側工具欄中的一些形狀工具來創建對象。此外，你可以下載共創或公共領域的剪貼畫，並導入 PNG 文件到你的項目中。

  2. 當你對對象的形狀滿意時，在頂部菜單中選擇“路徑” -> “對象轉化成路徑” 將其轉換為一個路徑（而不是一個形狀，Inkscape 視其為兩種不同的對象）。

  3. 在基板形狀的上面放置對象。

  4. 選擇對象和黑色基板。通過先單擊一個，並按住 Shift 按鍵，再選擇另一個來完成。

  5. 從頂部菜單選擇“路徑” -> “差集” 來從基板的對象中移除形狀。這將創建燈籠中的一個窗口。

添加對象到窗口中 ​

在製作了一個窗口後，你可以添加對象到其中來創建一個場景。

提示：

  • 所有的對象，包括文本，必須連接到燈籠的基板，否則，在切割後會掉落下來，並留下一片空白。
  • 避免小而複雜的細微之處。即使使用激光切割機或工藝切割機等機器，也很難切割這些細微之處。

  1. 創建或導入一個對象。

  2. 放置對象到窗口內，以便它至少接觸基板的兩側。

  3. 選擇對象後，從頂部菜單選擇“連接” -> “對象轉化成路徑”。

  4. 選擇對象和黑色基板，通過在按住 Shift 按鍵的同時單擊每一個來完成。

  5. 選擇“路徑” -> “並集”來使對象和基板合二為一。

添加文本 ​

文本既可以從基板剪出文字來創建一個窗口（就像我對星星所做的那樣），或者也可以添加到一個窗口上（它可以阻擋來自燈籠內部的光線）。如果你要創建一個窗口，只需要執行下面的步驟 1 和步驟 2，然後使用“差集”來從基板移除文本。

  1. 從左側邊欄中選擇文本工具來創建文本。粗體字體效果最好。

  2. 選擇你的文本，然後從頂部菜單選擇“路徑” -> “對象轉化成路徑”。這將轉換文本對象為一個路徑。注意，這個步驟意味着你將不能再編輯該文本，所以，只有當你確定你擁有想要的單詞後，執行這個步驟。

  3. 在你轉換文本後，你可以按鍵盤上的 F2 來激活節點編輯器工具，當選擇使用這個工具時，可以清楚地顯示文本的節點。

  4. 取消文本分組。

  5. 調整每個字母，以便使其與相鄰字母或基板稍微重疊。

  6. 為將所有的字母彼此連接，並連接到基板，重新選擇所有文本和基板，然後選擇“路徑” -> “並集”。

準備打印 ​

下面是手工切割燈籠的説明。如果使用激光切割機或工藝切割機，遵循硬件所需要的技巧來準備好你的文件。

  1. 在“圖層”面板中，單擊“安全”圖層旁邊的“眼睛”圖標來隱藏安全線。如果你看不到圖層面板，通過頂部菜單選擇“圖層” -> “圖層”來顯示它。

  2. 選擇黑色基板。在“填充和筆劃”面板中，設置填充為“X”（意味着不填充），設置“筆劃”為純黑色（對於喜歡十六進制的粉絲來説是 #000000ff ）。

  3. 使用“文件” -> “打印”來打印你的圖案。

  4. 使用一把工藝刀和直尺，小心地繞着每一條黑線切割。在藍色虛線上輕劃，然後摺疊。

  5. 要完成窗口的製作，剪切描圖紙為每個窗口的大小，然後粘貼它到燈籠的內側。

  6. 在折條處把燈籠的邊粘在一起。

  7. 接通電池供電的 LED 蠟燭，並放置它到你燈籠中。

現在你的燈籠已經完成了，準備好點亮你的鬼屋了。
