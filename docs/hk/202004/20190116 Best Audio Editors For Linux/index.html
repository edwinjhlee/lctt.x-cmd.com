Linux 上的最佳音頻編輯工具推薦 ​

在 Linux 上，有很多種音頻編輯器可供你選用。不論你是一個專業的音樂製作人，還是隻想學學怎麼做出超棒的音樂的愛好者，這些強大的音頻編輯器都是很有用的工具。

對於專業級的使用，我總是建議使用 DAW（數碼音頻工作站）。但並不是每個人都需要全部的功能，所以你也應該瞭解一些最簡單的音頻編輯器。

在本文中，我們將討論幾款 DAW 和基礎的音頻編輯器，而且它們都是在 Linux 和（可能）其它操作系統上可以使用的自由開源的解決方案。

Linux 上的最佳音頻編輯器 ​

我們不會關注 DAW 提供的所有功能，而只是關注基本的音頻編輯功能。不過，你仍然可以把以下內容看作是 Linux 的最佳 DAW 名單。

安裝説明：你可以在 AppCenter 或軟件中心中找到所有提到的音頻編輯器或 DAW。如果你在這兩個地方沒有找到它們，請前往它們的官方網站獲取更多信息。

1、Audacity ​

Audacity 是 Linux 中最基本音頻編輯器之一，但是它也很強大。它是一個自由開源的跨平台工具。肯定已經有很多人瞭解這個軟件了。

現在的它相比它最初流行的時候有了很大的改進。我記得我以前試着通過從音頻中去除人聲來製作卡拉 OK 伴奏。現在有些時候，你仍然可以這麼做。

特性：

它還支持包含 VST 效果的插件。當然，你不應該期望它支持 VST 樂器。

  • 通過麥克風或混音器進行現場錄製
  • 支持同時從多種音頻格式的多個文件中批量導出/導入內容
  • 支持 LADSPA、LV2、Nyquist、VST 和 Audio Unit 的效果插件
  • 使用簡單，帶有剪切、粘貼、刪除和拷貝的功能
  • 可觀測聲音頻率的頻譜模式

2、LMMS ​

LMMS 是一個自由開源的（跨平台）數碼音頻工作站。它包括所有基本的音頻編輯功能以及許多高級功能。

你可以混音、組合音頻，或使用 VST 設備創造音頻。LMMS 支持這些功能。此外，它還自帶一些樣本音頻、預設、VST 設備和特效來幫助你起步。此外，你還可以得到一個頻譜分析儀，以便進行高級的音頻編輯工作。

特性：

  • 基於 MIDI 的音符回放
  • 支持 VST 設備
  • 原生支持多采樣
  • 內置壓縮器、限制器、延遲功能、混響功能、失真功能和低音增強器

3、Ardour ​

Ardour 是另一個自由開源的數碼音頻工作站。只要你有音頻接口，Ardour 就支持它的使用。當然，你也可以無限地添加多聲道音軌。這些多聲道音軌也可以被指派到不同的混音帶，以方便編輯和錄音。

你也可以導入一個視頻，編輯其中的音頻，然後導出新的視頻。它提供了許多內置插件，並且支持 VST 插件。

特性：

  • 非線性編輯
  • 垂直窗口堆疊，便於導航
  • 靜默消除功能strip silence，推拉修剪功能push-pull trimming，和用以短暫片段或基於基於音符開始的編輯的 Rhythm Ferret。

4、Cecilia ​

Cecilia 不是一個普通的音頻編輯器。它的使用者一般是音效設計師或者正在努力成為音效設計師的人。 Cecilia 實際上是一個音頻信號處理環境。它可以讓你的作品餘音繞樑。

你還可以得到內置的音效與合成模組和插件。Cecilia 為一個明確的目的而生：如果你正在找音效設計工具，這是你的不二之選！

特性：

  • 利用模組來完成更多工作（UltimateGrainer —— 最先進的顆粒化處理工具，RandomAccumulator —— 記錄變量速度的累加器，UpDistoRes——通過上採樣和諧振低通濾波器創造失真效果的工具）
  • 自動保存調製設定

5、Mixxx ​

如果你想要在混合和錄製一些東西的同時能夠有一個虛擬的 DJ 工具，Mixxx 將是完美的工具。你可以用到 BPM、音調，並使用主同步功能來匹配歌曲的節奏和節拍。另外，不要忘記它也是一個 Linux 的自由開源的軟件。

它還支持自定義 DJ 設備。所以，如果你有 DJ 設備或者 MIDI，你可以用這個工具錄製你的現場混音。

特性：

  • 播送和錄製你的歌曲的 DJ 混音
  • 可以連接到你的設備並且現場演奏
  • 音調檢測和 BPM 檢測

6、Rosegarden ​

Rosegarden 是另一個令人讚歎的 Linux 的自由開源的音頻編輯器。它既不是一個功能齊全的 DAW，也不是一個基本的音頻編輯工具。它是兩者的混合體，並帶有一些縮減的功能。

我不會向專業人士推薦這款軟件，但如果你經營家庭音樂工作室或只是想體驗一下，這將是 Linux 上可以安裝的最好的音頻編輯器之一。

特性：

  • 樂譜編輯
  • 錄音、混音以及採樣

小結 ​

這些是你可以找到的 Linux 上的最棒的一些音頻編輯器了。不論你是需要 DAW，一個剪切/粘貼的編輯工具，或者僅僅想要一個擁有基礎的混音和錄音功能的音頻編輯工具，上述軟件都能夠滿足你的需求。

如果在這篇文章中我們遺漏了你最喜歡的一些音頻工具，可以在原文下方評論中回覆告訴我們。
