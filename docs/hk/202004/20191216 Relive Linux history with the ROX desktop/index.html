用 ROX 桌面重温 Linux 歷史 ​

這篇文章是 Linux 桌面 24 天特別系列的一部分。如果你想來一次有趣的時光之旅，ROX 桌面非常值得一試。

ROX 桌面已經不再積極開發，而它的遺留問題至今仍然存在，但即使在它活躍開發的時候，它也是一個另類的 Linux 桌面。當其他的桌面感覺與舊式的 Unix 或 Windows 界面大致相似時，ROX 則屬於 BeOS、AmigaOS 和 RISC OS 桌面陣營。

它專注於拖放式操作（這使得它的可訪問性對某些用户來説並不理想）、點擊式操作、彈出式上下文菜單，以及一個獨特的應用程序目錄系統，無需安裝即可運行本地應用程序。

安裝 ROX ​

如今，ROX 基本上都被遺棄了，只剩下一點殘渣碎片留給用户自己去收集整理。幸運的是，這個難題相對來説比較容易解決，但是當你在發行版的軟件倉庫中找到 ROX 桌面的碎片時，不要被迷惑了，因為那並不是 ROX 桌面全部的碎片。ROX 常用的部分 —— 文件管理器（ROX-Filer）和終端（ROXTerm） —— 似乎在大多數流行的發行版軟件倉庫中都有存在，你可以將它們作為獨立的應用程序安裝（並使用）。然而，要運行 ROX 桌面，你必須同時安裝 ROX-Session 和它所依賴的庫。

我在 Slackware 14.2 上安裝了 ROX，但它應該可以在任何 Linux 或 BSD 系統上運行。

首先，你必須從其版本庫中安裝 ROX-lib2。你要安裝 ROX-lib2，按照它的理念，只需下載tarball、解壓，然後將 ROX-lib 目錄移動到 /usr/local/lib 下就行。

接下來，你要安裝 ROX-Session。這可能需要從源碼中編譯，因為它很可能不在你的軟件倉庫中。編譯過程需要編譯工具，這些工具在 Slackware 上是默認提供的，但在其他發行版中往往會被省略，以節省初始下載空間。根據你的發行版不同，你必須安裝的包的名稱也不同，所以請參考文檔來了解具體內容。例如，在 Debian 發行版中，你可以在 Debian 的 wiki 中瞭解構建需求，而在 Fedora 發行版中，請參考 Fedora 的文檔。安裝了構建工具後，執行自定義的 ROX-Session 構建腳本。

$ ./AppRun

這個腳本會自己管理構建和安裝，並提示你需要 root 權限，以在你的登錄屏上將其添加為一個選項。

如果你還沒有從你的軟件庫中安裝 ROX-Filer，請在繼續之前安裝。

這些組件共同組成了一個完整的 ROX 桌面。要登錄到新桌面，請從當前桌面會話中註銷。默認情況下，你的會話管理器（KDM、GDM、LightDM 或 XDM，視你的設置而定）會繼續登錄到你之前的桌面，所以在登錄前必須覆蓋。

ROX 桌面特性 ​

ROX 桌面默認情況下很簡單，屏幕底部有一個面板，桌面上有一個通往主目錄的快捷方式圖標。面板中包含了一些常用位置的快捷方式。這就是 ROX 桌面的全部功能，至少在安裝後就是這樣。如果你想要時鐘、日曆或系統托盤，你需要找到提供這些功能的應用程序。

雖然沒有任務欄，但當你將窗口最小化時，它就會成為桌面上的一個臨時圖標。你可以點擊該圖標，將其窗口恢復到以前的大小和位置。

面板也可以進行一些修改。你可以在其中放置不同的快捷方式，甚至可以創建自己的小程序。

它沒有應用菜單，也沒有上下文菜單中的應用快捷方式。相反，你可以手動導航到 /usr/share/applications，或者你可以將你的應用目錄或目錄添加到 ROX 面板中。

ROX 桌面的工作流程集中在鼠標驅動上，讓人聯想到 Mac OS 7.5 和 8 系統。通過 ROX-filer，你可以管理權限、文件管理、內省introspection、腳本啓動、後台設置，以及幾乎所有你能想到的東西，只要你有足夠的耐心，就可以實現點擊式的交互。對於高級用户來説，這似乎很慢，但 ROX 設法讓它變得相對無痛，而且非常直觀。

應用程序目錄、AppRun 和 AppImage ​

ROX 桌面有一個優雅的慣例，按照此慣例，包含一個名為 AppRun 的腳本的目錄就可以像一個應用程序一樣被執行。這意味着，要製作一個 ROX 應用程序，你所要做的就是將代碼編譯到一個目錄中，將一個名為AppRun 的腳本放在該目錄的根目錄下，來執行你所編譯的二進制文件，然後將該目錄標記為可執行即可。ROX-Filer 會按照你設置的方式來顯示一個目錄，並以特殊的圖標和顏色顯示一個目錄。當你點擊一個應用程序目錄，ROX-Filer 會自動運行裏面的 AppRun 腳本。它的外觀和行為就像一個已經安裝好的應用程序，但它是在用户的主目錄下的本地目錄，不需要特殊的權限。

這是一個方便的功能，但它是那些你使用時感覺很好的小功能之一，因為它很容易做到。它絕不是必要的，它只是比在本地建立一個應用程序，將目錄隱藏在某個不顯眼的地方，並建立一個快速的 .desktop 文件作為你的啓動器，要領先了幾步。然而，應用程序目錄的概念已經當做靈感被 AppImage 打包系統所 借鑑。

為什麼應該試試 ROX 桌面 ​

把 ROX 設置好並使用是有些困難的，它似乎真的被拋棄了。然而，它的遺產在今天以多種方式繼續存在，它是 Linux 歷史上的一段迷人而有趣的歷史。它可能不會成為你的主要桌面，但如果你想來一次有趣的回溯之旅，那麼 ROX 非常值得一試。探索它、定製它，看看它包含了哪些巧妙的想法。也許還有一些隱藏的寶石可以讓開源社區受益。
