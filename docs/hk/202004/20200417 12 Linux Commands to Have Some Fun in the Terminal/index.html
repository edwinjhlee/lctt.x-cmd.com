12 個有趣的 Linux 終端命令 ​

你覺得 Linux 終端裏只有無趣的工作嗎？那你一定不知道下面這些有趣的 Linux 命令吧。

Linux 終端是用來完成複雜的工作的，我們有很多有用的 linux 命令奇技淫巧來幫助你。

但是，你知道你還可以用終端來做很多有趣的事嗎？如果你不知道，沒關係，大多數 Linux 用户也都只把終端視為一個用來管理系統和開發工作的交互界面。

然而，如果你知道這裏有些你可以在終端玩的基於終端的遊戲和 ASCII 碼遊戲，你一定會大吃一驚。

在這篇文章中，我將會探索一些有趣的、可笑的、荒謬的命令來讓你可以在終端中找點樂子！

用這些命令在 Linux 終端中找點樂子 ​

你可能會覺得這些命令荒謬或沒用，但是有一些還是可以被好好利用的。

我已經放上了 Ubuntu/Debian 的安裝指令，如果你使用基於 Ubuntu 的發行版，請確保啓用 universe 倉庫，因為大多數命令不在主倉庫中。

如果你使用 Arch、Fedora、SUSE、Solus 或者其他非 Ubuntu 的發行版，請使用你的發行版包管理工具去安裝這些有趣的 Linux 命令。

1、在終端開一輛火車 ​

讓我們坐上火車，來一場説走就走的旅行的，沒錯，就是字面意思！

sl 命令可以讓你在終端運行一輛火車。

安裝方法：

sudo apt install sl

完成後，你只要在終端輸入下面的命令就可以開始：

sl

很精彩，對吧？但等等，我們還沒結束！你還可以讓你的火車飛起來，只要加上參數 -F，波特先生，請飛吧：

sl -F

這樣會讓火車長出翅膀飛出終端窗口！

2、給你的 Linux 終端加上黑客帝國效果 ​

還記得科幻電影黑客帝國嗎？終端裏掉落的綠色字符成為了黑客帝國的標誌形象。

你也可以在你的 Linux 電腦裏有這樣的黑客帝國數字雨！你只需要安裝 cmatric 然後在終端輸入它就行。

在 Debian/Ubuntu Linux 上安裝 cmatrix:

sudo apt install cmatrix

現在，你要做的就是輸入下面的命令，在終端就會有黑客帝國屏幕了：

cmatrix

按下 Ctrl+C 來停止它，黑客先生。

3、燃起來 ​

拿好滅火器，因為接下來你要在你的終端裏點火了！

想安裝它，你要輸入：

sudo apt install libaa-bin

完成後，你輸入下面的命令，你的終端就會燃起一團火焰：

aafire

按下 Ctrl+C 來停止它。

4、幸運餅乾命令 ​

想知道你的運氣怎樣但身邊沒有幸運餅乾？

別擔心，你只需在終端打出 fortune 然後按下回車。終端將會隨機顯示出一個幸運語，就像你從幸運餅乾裏得到的一樣。

安裝它：

sudo apt install fortune

完成後，只要在命令列打出下面的內容，你就會知道你的運氣怎樣：

fortune

這是一個你可以實際使用的命令。你可以用它作為每日消息，這樣在多用户環境下，每個用户登錄後都會得到一個“幸運餅乾”。

你也可以把它添加到 bashrc 文件，這樣當你登進終端你就會看到了。

5、寵物愛好者？這是給你準備的 ​

oneko 是一個有趣的命令，可以把你的光標變成一隻老鼠，然後創造一隻好奇的貓，一旦你移動光標，就會來追你。這不僅侷限於終端。當貓追逐光標時，你可以繼續工作。

如果你家裏有孩子這一定很有趣。

用下面的命令安裝 oneko：

sudo apt install oneko

用下面的命令運行它：

oneko

如果你不喜歡貓，喜歡狗，輸入：

oneko -dog

它有很多種小寵物，你可以用 oneko -help 獲取信息。按下 Ctrl+C 終止它。

6、有個小兄弟在看着你 ​

xeyes 是一個很小的 GUI 程序，它可以繪製出一雙眼睛一直盯着你！它會不斷跟隨你的鼠標光標，運行命令自己看看！

你可以用下面命令安裝：

sudo apt install xeyes

然後這樣用它：

xeyes

按下 Ctrl+C 終止它。

7、讓終端幫你講話 ​

打開你的揚聲器，你來試試這個命令，eSpeak 是一個有趣的命令，它可以讓你的終端説話。是的，你沒聽錯。

先安裝這個包：

sudo apt install espeak

接下來，你只需要輸入在命令列中輸入你想聽到的話：

espeak "Type what your computer says"

無論你在雙引號裏面填什麼，你的電腦都會複述出來！它就像在 Linux 中的 echo 命令，但不是打印出來，而是説出來。

8、Toilet（但與洗手間無關） ​

這聽起來有點奇怪，是的。但是，這只是一個命令，用來將文本轉換成大的 ASCII 字符。

用這個命令安裝 toilet：

sudo apt install toilet

完成後，你只需輸入：

toilet sample text you want

我也不知道為啥這個小程序叫 Toilet。

9、那個牛説什麼？ ​

cowsay 是一個在終端中用 ASCII 字符展示出一頭牛的命令。通過這個命令，你可以控制牛説出你想説的話。

別糾結聲音，它只展示文本（就是你看漫畫書一樣）。

安裝 cowsay：

sudo apt install cowsay

安裝完成後，你只要輸入：

cowsay "your text"

無論你在雙引號裏填什麼，你的牛都會説！我看到一些系統管理員用它來展示每天的消息。你也可以這樣，你甚至可以把它和 fortune 命令結合。

10、旗幟 ​

banner 命令與 toilet 命令相似，但它限制最多隻能打印 10 個字符。

你可以這樣安裝 banner 命令：

sudo apt install sysvbanner

然後這樣運行：

banner "Welcome"

替換雙引號裏的內容，你將會得到你想要的展示內容。

11、Yes ​

yes 命令幫助你在循環中自動響應直到終止命令。這個命令將會一直打印相同的內容。如果你想快速生成大量垃圾文本，那麼此命令將像超級按鈕一樣工作。

你也可以使用它為命令提供 yes 應答（如果提示應答時）。例如，apt upgrade 命令會要求你確認，你可以像這樣使用它：

yes | sudo apt upgrade

你不需要安裝任何包，yes 命令已經存在了。

想要終止 yes 命令循環，只需按下 CTRL+C。

12、得到一個新的身份 ​

要生成一個隨機的假身份嗎？我推薦你用 rig 命令。你在終端運行它，就會生成一個假的身份。

用這個命令安裝 rig：

sudo apt install rig

只需像這樣輸入：

rig

它可能被用在腳本或者 web 應用中展示隨機信息，但我自己還沒做過什麼。

結尾 ​

我希望你會喜歡這個有趣的 Linux 命令列表。你最喜歡哪個命令呢？你還知道其他有趣的命令嗎？請在評論部分與我們分享。
