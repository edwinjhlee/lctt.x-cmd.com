塑造 Linux 歷史的 10 個時刻 ​

自 1991 年誕生以來，Linux 已經走了漫長的一段路，而這些事件標誌着它的發展。

在 2018 年 8 月，Opensource.com 發佈了一項包含七個選項的民意測驗，詢問讀者：Linux 歷史上最重要的時刻是什麼？我覺得我需要擴大這個清單，並提出我認為的 10 個在塑造 Linux 歷史上發揮了重要作用的時刻。

1、Linus 發佈 Linux ​

Linus Torvalds 最初是在 1991 年將 Linux 當成一個業餘愛好發佈到世上的。結果這個業餘愛好成了他的職業！

2、出現 Linux 發行版 ​

1993 年，出現了幾個 Linux 發行版，需要特別指出的有 Debian、Red Hat 和 Slackware。這個時刻之所以重要是因為它們證明了 Linux 在市場認可度和開發水平方面的成就，使其能夠在 1990 年代動盪的操作系統戰爭、瀏覽器戰爭和協議戰爭中生存下來。相反，那時許多成熟的、商業的和專有的產品並沒有活過千禧年之交！

3、IBM 斥巨資投注 Linux ​

2000 年，IBM 宣佈將在 Linux 上投資 10 億美元。Richard Richtmyer 在他的 CNN Money 有關投資的文章 中寫道：“這一聲明強調了藍色巨人對 Linux 的承諾，標誌着將這個替代操作系統推向主流商業市場的重大進展。”

4、好萊塢接納 Linux ​

在 2002 年，整個好萊塢電影業似乎都採用了 Linux。迪尼斯、夢工廠 和 工業光魔 都在那一年開始用 Linux 製作電影。

5、Linux 得到政府認可 ​

2003 年，美國政府對 Linux 的接受是它的又一個重要時刻。紅帽 Linux 被授予美國防部通用操作環境（COE）認證。這很重要，因為政府（特別是情報和軍事機構）對計算機系統有非常嚴格的要求，以防止攻擊和支持國家安全。這為其他機構使用 Linux 打開了大門。在那年晚些時候，美國國家氣象局宣佈，它將用運行 Linux 的新計算機代替過時的系統。

6、我管理的系統 ​

這個“時刻”確實是我個人經歷的集合。隨着在 2000 年代我的職業發展，我發現自己管理的幾種類型的系統和設備都運行着 Linux。我在 VMware ESX、F5 Big-IP、Check Point UTM Edge、Cisco ASA 和 PIX 這些地方發現了 Linux。這使我意識到 Linux 確實可行並且可以繼續存在下去。

7、Ubuntu ​

2004 年，Mark Shuttleworth 創立了 Canonical，該公司基於 Debian 發行版提供了易於使用的 Linux 桌面：Ubuntu Linux。我認為 Ubuntu Linux 幫助擴展了桌面 Linux 安裝基數。從休閒的家庭用户到專業軟件開發人員，它使 Linux 出現在更多人面前。

8、Google 的 Linux ​

Google 發行了兩種基於 Linux 內核的操作系統：2008 年中期的 Android 移動操作系統和 2011 年在 Chromebook 上運行的 Chrome OS。在那之後，已經售出了數百萬部 Android 手機和 Chromebook。

9、雲計算即 Linux ​

在過去這十年左右的時間裏，雲計算已經從互聯網計算的宏偉願景變成了我們如何個人和專業地使用計算機的全新方式。雲計算領域中的主要參與者都是構建於 Linux 之上的，包括 Amazon Web Services（AWS）、Google Cloud Services（GCS） 和 Linode。即使在一些我們不能確信的地方（例如 Microsoft Azure），也很好地支持運行 Linux 工作負載。

10、我的汽車運行着 Linux ​

你的也一樣！許多汽車製造商幾年前開始引入 Linux。這導致了名為 汽車級 Linux（AGL） 的協作開源項目的形成。豐田和斯巴魯等主要汽車製造商已經聯合開發基於 Linux 的汽車娛樂、導航和引擎管理系統。

分享你的最愛 ​

這是我從貫穿我的職業生涯的 Linux 文章和事件的檔案庫中提取出來的主觀清單，因此可能還有其他更值得注意的時刻。請分享你的評論吧。
