GNOME OS：一個並不是適合所有人的 Linux 發行版 ​

每當 GNOME 的一個重要版本到來時，總是很想盡快試用它。但是，要想第一時間進行測試，主要還是得依靠 Fedora Rawhide 開發分支。

然而，開發分支並不總是讓人放心的，所以，用來嘗試最新的 GNOME 並不是最方便的解決方案。這裏，我所説的測試，並不僅僅是指用户的測試，同時也能夠用於開發者對設計變更進行測試。

所以，最近來了個大救星 GNOME OS，讓測試的過程變得輕鬆起來。但是，它到底是什麼，怎麼安裝呢？讓我們一起來看看吧。

什麼是 GNOME OS？ ​

GNOME OS 並不是一個獨立完整的 Linux 發行版。事實上，它根本不基於任何東西。它是一個不完整的參考系統，只是為了讓 GNOME 桌面工作。它僅僅是一個可啓動的虛擬機鏡像，在 GNOME 進入任何發行版的倉庫之前，為調試和測試功能而量身定做的。

在 GNOME 的Blog中，有一篇提到了它：

GNOME OS 旨在通過提供一個用於開發、設計和用户測試的工作系統，來更好地促進 GNOME 的開發。

如果你好奇的話，你可以看看 GNOME 星球上的一篇 Blog文章 來了解關於 GNOME OS 的更多信息。

如果它不是一個成熟的 Linux 發行版，那麼它是用來幹什麼的？ ​

值得注意的是，每一次新的提交都可以創建一個新的 GNOME OS 鏡像，所以它應該會使測試過程變得高效，並幫助你在開發週期的早期測試並發現問題。

不要忘了，設計者不再需要自己構建軟件來測試 GNOME Shell 或任何其他核心模組。這為他們節省了時間和整個 GNOME 開發週期。

當然，不僅限於開發者和技術測試人員，它還可以讓記者們拿到最新的和最棒的東西，來報道 GNOME 下一個版本或它是如何成型的。

媒體和 GNOME 團隊也得到了一個很好的機會，藉助於 GNOME OS，他們可以準備視頻、圖片兩種形式的視覺資料來宣傳此次發佈。

如何安裝 GNOME OS？ ​

要輕鬆安裝 GNOME OS，你需要先安裝 GNOME Boxes 應用程序。

安裝 GNOME Boxes ​

Boxes 是一款簡單的虛擬化軟件，它不提供任何高級選項，但可以讓你輕鬆安裝操作系統鏡像來快速測試。它是專門針對桌面終端用户的，所以使用起來也很方便。

要在任何 Linux 發行版上安裝它，你可以利用 Flathub 的 Flatpak 包。如果你不知道 Flatpak，你可能需要閲讀我們的《在 Linux 中安裝和使用 Flatpak》指南。

你也可以在任何基於 Ubuntu 的發行版上直接在終端上輸入以下內容進行安裝：

sudo apt install gnome-boxes

一旦你安裝了 Boxes，從這裏安裝 GNOME OS 就相當容易了。

安裝 GNOME OS ​

安裝好 Boxes 後，你需要啓動程序。接下來，點擊窗口左上角的 “+” 標誌，然後點擊 “操作系統下載”，如下圖所示。

這個選項可以讓你直接下載鏡像文件，然後就可以繼續安裝它。

你所需要做的就是搜索 “GNOME”，然後你應該會找到可用的每夜構建版。這可以確保你正在嘗試最新和最優秀的 GNOME 開發版本。

另外，你也可以前往 GNOME OS 每夜構建網站 下載系統鏡像，然後在 Boxes 應用中選擇 “運行系統鏡像文件” 選擇該 ISO，如上圖截圖所示，繼續安裝。

考慮到你沒有單獨下載鏡像。當你點擊後，應該會開始下載，並且會出現一個進度條。

完成後，如果需要，它會要求你自定義配置，讓你創建虛擬機，如下圖所示。

你可以根據你可用的系統資源來定製資源分配，但應該可以使用默認設置。

點擊 “創建”，就會直接開始 GNOME OS 的安裝。

選擇“使用現有的版本”，然後繼續。接下來，你必須選擇磁盤（保持原樣），然後同意擦除你所有的文件和應用程序（它不會刪除本地計算機上的任何東西）。

現在，它將簡單地重新格式化並安裝它。然後就完成了。它會提示你重啓，重啓後，你會發現 GNOME OS 已經安裝好了。

它會像其他 Linux 發行版一樣簡單地啓動，並要求你設置一些東西，包括用户名和密碼。然後，你就可以開始探索了。

如果你想知道它的樣子，它基本上就是最新的 GNOME 桌面環境。在 GNOME 40 正式發佈之前，我用 GNOME OS 做了一個 GNOME 40 的概述視頻。

結束語 ​

GNOME OS 絕對是對開發者、設計師和媒體有用的東西。它可以讓你輕鬆地測試最新的 GNOME 開發版本，而無需投入大量的時間。

我可以很快地測試 GNOME 40，就是因為這個。當然，你要記住，這並不是一個可以在物理設備上安裝的完整功能的操作系統。他們有計劃讓它可以在物理機器上運行，但就目前而言，它只是為虛擬機量身定做的，尤其是使用 GNOME Boxes。

GNOME Boxes 並沒有提供任何高級選項，所以設置和使用它變得相當容易。如果體驗太慢的話，你可能要調整一下資源，但在我的情況下，總體來説是一個不錯的體驗。
