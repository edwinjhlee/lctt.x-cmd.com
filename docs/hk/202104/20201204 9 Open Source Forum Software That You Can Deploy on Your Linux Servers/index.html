11 個可以部署在 Linux 服務器上的開源論壇軟件 ​

是否想要建立社區論壇或客户支持門户站點？以下是一些可以在服務器上部署的最佳開源論壇軟件。

就像我們的論壇一樣，重要的是建立一個讓志趣相投的人可以討論，互動和尋求支持的平台。

論壇為用户（或客户）提供了一個空間，讓他們可以接觸到在互聯網上大多數情況下不容易找到的東西。

如果你是一家企業，則可以聘請開發人員團隊並按照自己的方式建立自己的論壇，但這會增加大量預算。

幸運的是，有幾個令人印象深刻的開源論壇軟件，你只需要將其部署在你的服務器上就萬事大吉了！在此過程中，你將節省很多錢，但仍能獲得所需的東西。

在這裏，我列出了可以在 Linux 服務器上安裝的最佳開源論壇軟件列表。

建立社區門户的最佳開源論壇軟件 ​

如果你尚未建立過網站，則在部署論壇之前，可能需要看一下 某些開源網站創建工具。

注意： 此列表沒有特定的排名順序。

1、Discourse（現代、流行） ​

Discourse 是人們用來部署配置討論平台的最流行的現代論壇軟件。實際上，It's FOSS 社區 論壇使用了 Discourse 平台。

它提供了我所知道的大多數基本功能，包括電子郵件通知、審核工具、樣式自定義選項，Slack/WordPress 等第三方集成等等。

它的自託管是完全免費的，你也可以在 GitHub 上找到該項目。如果你要減少將其部署在自託管服務器上的麻煩，可以選擇 Discourse 提供的託管服務（肯定會很昂貴）。

2、Talkyard（受 Discourse 和 StackOverflow 啓發） ​

Talkyard 是完全免費使用的，是一個開源項目。它看起來很像 Discourse，但是如果你深入瞭解一下，還是有區別的。

你可以在這裏獲得 StackOverflow 的大多數關鍵功能，以及在論壇平台上期望得到的所有基本功能。它可能不是一個流行的論壇解決方案，但是如果你想要類似於 Discourse 的功能以及一些有趣的功能，那麼值得嘗試一下。

你可以在他們的 GitHub 頁面 中進一步瞭解它。

3、Forem （一種獨特的社區平台，正在測試中） ​

你可能以前沒有聽説過 Forem，但它支持了 dev.to（這是一個越來越受歡迎的開發者社區網站）。

它仍然處於測試階段，所以你或許不會選擇在生產服務器上實驗。但是，你可以通過在他們的官方網站上填寫一個表格並與他們取得聯繫，讓他們為你託管。

儘管沒有官方的功能列表來強調所有的東西，但如果我們以 dev.to 為例，你會得到許多基本的特性和功能，如社區列表、商店、帖子格式化等。你可以在他們的 公告帖子 中閲讀更多關於它提供的內容，並在 GitHub 上探索該項目。

4、NodeBB（現代化、功能齊全） ​

NodeBB 是一個基於 Node.js 的開源論壇軟件。它的目標是簡單、優雅和快速。首先，它面向有託管計劃的組織和企業。但是，你也可以選擇自己託管它。

你還可以獲得實時本地分析功能，以及聊天和通知支持。它還提供一個 API，可以將其與你的現有產品集成。它還支持審核工具和打擊垃圾郵件的工具。

你可以獲得一些開箱即用的第三方集成支持，例如 WordPress、Mailchimp 等。

請在他們的 GitHub 頁面 或官方網站上可以進一步瞭解它。

5、Vanilla 論壇（面向企業） ​

Vanilla 論壇 主要是一款以企業為中心的論壇軟件，它的基本功能是為你的平台打造品牌，為客户提供問答，還可以對帖子進行投票。

用户體驗具有現代的外觀，並且已被像 EA、Adobe 和其他一些大公司使用。

當然，如果你想嘗試基於雲的 Vanilla 論壇（由專業團隊管理）以及對某些高級功能的訪問權，可以隨時申請演示。無論哪種情況，你都可以選擇社區版，該社區版可以免費使用大多數最新功能，但需要自己託管和管理。

你可以在他們的官方網站和 GitHub 頁面 上進一步瞭解它。

6、bbPress （來自 WordPress） ​

bbPress 是一個可靠的論壇軟件，由 WordPress 的創建者建立。旨在提供一個簡單而迅速的論壇體驗。

用户界面看起來很老舊，但易於使用，它提供了你通常在論壇軟件中需要的基本功能。審核工具很好用，易於設置。你可以使用現有的插件擴展功能，並從幾個可用的主題中進行選擇以調整論壇的外觀。

如果你只想要一個沒有花哨功能的簡單論壇平台，bbPress 應該是完美的。你也可以查看他們的 GitHub 頁面 瞭解更多信息。

7、phpBB（經典論壇軟件） ​

如果你想要傳統的論壇設計，只想要基本功能，則 phpBB 軟件是一個不錯的選擇。當然，你可能無法獲得最佳的用户體驗或功能，但是作為按傳統設計的論壇平台，它是實用的並且非常有效。

尤其是，對於習慣使用傳統方式的用户而言，這將是一種簡單而有效的解決方案。

不僅僅是簡單，而且在一般的託管供應商那裏，它的設置也是非常容易的。在任何共享主機平台上，你都能獲得一鍵式安裝功能，因此也不需要太多的技術知識來進行設置。

你可以在他們的官方網站或 GitHub 頁面 上找到更多有關它的信息。

8、Simple Machines 論壇（另一個經典） ​

與 phpBB 類似，Simple Machines 論壇 是另一種基本（或簡單）的論壇。很大程度上你可能無法自定義外觀（至少不容易），但是默認外觀是乾淨整潔的，提供了良好的用户體驗。

就個人而言，相比 php BB 我更喜歡它，但是你可以前往他們的 官方網站 進行進一步的探索。同樣，你可以使用一鍵安裝方法在任何共享託管服務上輕鬆安裝 Simple Machines 論壇。

9、FluxBB（古典） ​

FluxBB 是另一個簡單、輕量級的開源論壇。與其他的相比，它可能維護的不是非常積極，但是如果你只想部署一個只有很少幾個用户的基本論壇，則可以輕鬆嘗試一下。

你可以在他們的官方網站和 GitHub 頁面 上找到更多有關它的信息。

10、MyBB（不太流行，但值得看看） ​

MyBB 是一款獨特的開源論壇軟件，它提供多種樣式，並包含你需要的基本功能。

從插件支持和審核工具開始，你將獲得管理大型社區所需的一切。它還支持類似於 Discourse 和同類論壇軟件面向個人用户的私人消息傳遞。

它可能不是一個流行的選項，但是它可以滿足大多數用例，並且完全免費。你可以在 GitHub 上得到支持和探索這個項目。

11、Flarum（測試版） ​

如果你想要更簡單和獨特的論壇，請看一下 Flarum。它是一款輕量級的論壇軟件，旨在以移動為先，同時提供快速的體驗。

它支持某些第三方集成，也可以使用擴展來擴展功能。就我個人而言，它看起來很漂亮。我沒有機會嘗試它，你可以看一下它的 文檔，可以肯定它具有論壇所需的所有必要功能的特徵。

值得注意的是 Flarum 是相當新的，因此仍處於測試階段。你可能需要先將其部署在測試服務器上測試後，再應用到生產環境。請查看其 GitHub 頁面 瞭解更多詳細信息。

補充：Lemmy（更像是 Reddit 的替代品，但也是一個不錯的選擇） ​

一個用 Rust 構建的 Reddit 的聯盟式論壇的替代品。它的用户界面很簡單，有些人可能覺得它不夠直觀，無法獲得有吸引力的論壇體驗。

其聯盟網絡仍在構建中，但如果你想要一個類似 Reddit 的社區平台，你可以很容易地將它部署在你的 Linux 服務器上，並制定好管理規則、版主，然後就可以開始了。它支持跨版發帖（參見 Reddit），以及其他基本功能，如標籤、投票、用户頭像等。

你可以通過其 官方文檔 和 GitHub 頁面 探索更多信息。

總結 ​

大多數開源論壇軟件都為基本用例提供了幾乎相同的功能。如果你正在尋找特定的功能，則可能需要瀏覽其文檔。

就個人而言，我推薦 Discourse。它很流行，外觀現代，擁有大量的用户基礎。
