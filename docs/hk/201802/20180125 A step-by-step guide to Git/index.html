手把手指導您使用 Git ​

如果您從未使用過 Git，甚至可能從未聽説過它。莫慌張，只需要一步步地跟着這篇入門教程，很快您就會在 GitHub 上擁有一個全新的 Git 倉庫。

在開始之前，讓我們先理清一個常見的誤解：Git 並不是 GitHub。Git 是一套版本控制系統（或者説是一款軟件），能夠協助您跟蹤計算機程序和文件在任何時間的更改。它同樣允許您在程序、代碼和文件操作上與同事協作。GitHub 以及類似服務（包括 GitLab 和 BitBucket）都屬於部署了 Git 程序的網站，能夠託管您的代碼。

步驟 1：申請一個 GitHub 賬户 ​

在 GitHub.com 網站上（免費）創建一個賬户是最簡單的方式。

選擇一個用户名（比如説，octocat123），輸入您的郵箱地址和密碼，然後點擊 Sign up for GitHub。進入之後，您將看到下方插圖的界面：

步驟 2：創建一個新的倉庫 ​

一個倉庫（ repository），類似於能儲存物品的場所或是容器；在這裏，我們創建倉庫存儲代碼。在 + 符號（在插圖的右上角，我已經選中它了） 的下拉菜單中選擇 New Repository。

給您的倉庫命名（比如説，Demo）然後點擊 Create Repository。無需考慮本頁面的其他選項。

恭喜！您已經在 GitHub.com 中建立了您的第一個倉庫。

步驟 3: 創建文件 ​

當倉庫創建完畢後，界面將和下方一致：

不必驚慌，它比看上去簡單。跟緊步驟。忽略其他內容，注意截圖上的 “...or create a new repository on the command line,”。

在您的計算機中打開終端。

鍵入 git 然後回車。如果命令列顯示 bash: git: command not found，在您的操作系統或發行版 安裝 Git 命令。鍵入 git 並回車檢查是否成功安裝；如果安裝成功，您將看見大量關於使用該命令的説明信息。

在終端內輸入：

mkdir Demo

這個命令將會創建一個名為 Demo 的目錄（文件夾）。

如下命令將會切換終端目錄，跳轉到 Demo 目錄：

cd Demo

然後輸入：

echo "#Demo" >> README.md

創建一個名為 README.md 的文件，並寫入 #Demo。檢查文件是否創建成功，請輸入：

cat README.md

這將會為您顯示 README.md 文件的內容，如果文件創建成功，您的終端會有如下顯示：

使用 Git 程序告訴您的電腦，Demo 是一個被 Git 管理的目錄，請輸入：

git init

然後，告訴 Git 程序您關心的文件並且想在此刻起跟蹤它的任何改變，請輸入：

git add README.md

步驟 4：創建一次提交 ​

目前為止，您已經創建了一個文件，並且已經通知了 Git，現在，是時候創建一次提交commit了。提交可以看作是一個里程碑。每當完成一些工作之時，您都可以創建一次提交，保存文件當前版本，這樣一來，您可以返回之前的版本，並且查看那時候的文件內容。無論何時您修改了文件，都可以對文件創建一個上一次的不一樣的新版本。

創建一次提交，請輸入：

git commit -m "first commit"

就是這樣！剛才您創建了包含一條註釋為 “first commit” 的 Git 提交。每次提交，您都必須編輯註釋信息；它不僅能協助您識別提交，而且能讓您理解此時您對文件做了什麼修改。這樣到了明天，如果您在文件中添加新的代碼，您可以寫一句提交信息：“添加了新的代碼”，然後當您一個月後回來查看提交記錄或者 Git 日誌（即提交列表），您還能知道當時的您在文件夾裏做了什麼。

步驟 5: 將您的計算機與 GitHub 倉庫相連接 ​

現在，是時候用如下命令將您的計算機連接到 GitHub 倉庫了：

git remote add origin https://github.com/<your_username>/Demo.git

讓我們一步步的分析這行命令。我們通知 Git 去添加一個叫做 origin （起源）的，擁有地址為 https://github.com/<your_username>/Demo.git（它也是您的倉庫的 GitHub 地址） 的 remote （遠程倉庫）。當您提交代碼時，這允許您在 GitHub.com 和 Git 倉庫交互時使用 origin 這個名稱而不是完整的 Git 地址。為什麼叫做 origin？當然，您可以叫點別的，只要您喜歡（慣例而已）。

現在，我們已經將本地 Demo 倉庫副本連接到了其在 GitHub.com 遠程副本上。您的終端看起來如下：

此刻我們已經連接到遠程倉庫，可以推送我們的代碼 到 GitHub.com（例如上傳 README.md 文件）。

執行完畢後，您的終端會顯示如下信息：

然後，如果您訪問 https://github.com/<your_username>/Demo，您會看到截圖內顯示的情況：

就是這麼回事！您已經創建了您的第一個 GitHub 倉庫，連接到了您的電腦，並且從你的計算機推送（或者稱：上傳）一個文件到 GitHub.com 名叫 Demo 的遠程倉庫上了。下一次，我將編寫關於 Git 複製（從 GitHub 上下載文件到你的計算機上）、添加新文件、修改現存文件、推送（上傳）文件到 GitHub。
