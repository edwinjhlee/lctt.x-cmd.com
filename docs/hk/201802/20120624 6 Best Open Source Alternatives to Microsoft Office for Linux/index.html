6 個 Liunx 平台下最好的替代 Microsoft Office 的開源辦公軟件 ​

概要：還在 Linux 中尋找 Microsoft Office 嗎? 這裏有一些最好的在 Linux 平台下替代 Microsoft Office 的開源軟件。

辦公套件是任何操作系統的必備品。很難想像沒有 Office 軟件的桌面操作系統。雖然 Windows 有 MS Office 套件，Mac OS X 也有它自己的 iWork，但其他很多辦公套件都是專門針對這些操作系統的，Linux 也有自己的辦公套件。

在本文中，我會列舉一些在 Linux 平台替代 Microsoft Office 的辦公軟件。

Linux 最好的 MS Office 開源替代軟件 ​

在我們看 MS Office 的替代軟件之前，我們先來看看在一個像樣的辦公套件中有一些什麼:

  • 文字處理器
  • 電子表格
  • 演示功能

我知道 Microsoft Office 提供了比上述三種工具更多的工具，但事實上，您主要使用這三個工具。開源辦公套件並不限於只有這三種產品。其中有一些套件提供了一些額外的工具，但我們的重點將放在上述工具上。

讓我們看看在 Linux 上有什麼辦公套件:

6. Apache OpenOffice ​

Apache OpenOffice 或簡單的稱為 OpenOffice 有一段名稱/所有者變更的歷史。 它於 1999 年由 Sun Microsystems 公司開發，後來改名為 OpenOffice，將它作為一個與 MS Office 對抗的自由開源的替代軟件。 當 Oracle 在 2010 年收購 Sun 公司後，一年之後便停止開發 OpenOffice。 最後是 Apache 支持它，現在被稱為 Apache OpenOffice。

Apache OpenOffice 可用於多種平台，包括 Linux、Windows、Mac OS X、Unix、BSD。 除了 OpenDocument 格式外，它還支持 MS Office 文件。 辦公套件包含以下應用程序：Writer、Calc、Impress、Base、Draw、Math。

安裝 OpenOffice 是一件痛苦的事，因為它沒有提供一個友好的安裝程序。另外，有傳言説 OpenOffice 開發可能已經停滯。 這是我不推薦的兩個主要原因。 出於歷史目的，我在這裏列出它。

5. Feng Office ​

Feng Office 以前被稱為 OpenGoo。 這不是一個常規的辦公套件。 它完全專注於在線辦公，如 Google 文檔一樣。 換句話説，這是一個開源協作平台。

Feng Office 不支持桌面使用，因此如果您想在單個 Linux 桌面上使用它，這個可能無法實現。 另一方面，如果你有一個小企業、一個機構或其他組織，你可以嘗試將其部署在本地服務器上。

4. Siag Office ​

Siag 是一個非常輕量級的辦公套件，適用於類 Unix 系統，可以在 16MB 的系統上運行。 由於它非常輕便，因此缺少標準辦公套件中的許多功能。 但小即是麗，不是嗎？ 它具有辦公套件的所有必要功能，可以在輕量級 Linux 發行版上“正常工作”。它是 Damn Small Linux 默認安裝軟件。（LCTT 譯註：根據官網，現已不是默認安裝軟件）

3. Calligra Suite ​

Calligra，以前被稱為 KOffice，是 KDE 中默認的 Office 套件。 它支持 Mac OS X、Windows、Linux、FreeBSD 系統。 它也曾經推出 Android 版本。 但不幸的是，後續沒有繼續支持 Android。 它擁有辦公套件所需的必要應用程序以及一些額外的應用程序，如用於繪製流程圖的 Flow 和用於項目管理的 Plane。

Calligra 最近的發展產生了相當大的影響，很有可能成為 LibreOffice 的替代品。

2. ONLYOFFICE ​

ONLYOFFICE 是辦公套件市場上的新玩家，它更專注於協作部分。 企業（甚至個人）可以將其部署到自己的服務器上，以獲得類似 Google Docs 之類的協作辦公套件。

別擔心，您不是必須將其安裝在服務器上。有一個免費的開源桌面版本 ONLYOFFICE。 您甚至可以獲取 .deb 和 .rpm 二進制文件，以便將其安裝在 Linux 桌面系統上。

1. LibreOffice ​

當 Oracle 決定停止 OpenOffice 的開發時，是文檔基金會將其複製分發，這就是我們所熟知的 Libre-Office。從那時起，許多 Linux 發行版都將 OpenOffice 替換為 LibreOffice 作為它們的默認辦公應用程序。

它適用於 Linux，Windows 和 Mac OS X，這使得在跨平台環境中易於使用。 和 Apache OpenOffice 一樣，這也包括了除了 OpenDocument 格式以外的對 MS Office 文件的支持。 它還包含與 Apache OpenOffice 相同的應用程序。

您還可以使用 LibreOffice 作為 Collabora Online 的協作平台。 基本上，LibreOffice 是一個完整的軟件包，無疑是 Linux、Windows 和 MacOS 的最佳 Microsoft Office 替代品。
