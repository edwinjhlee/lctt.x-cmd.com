五個值得現在安裝的火狐插件 ​

合適的插件能大大增強你瀏覽器的功能，但仔細挑選插件很重要。本文有五個值得一看的插件。

對於很多用户來説，網頁瀏覽器已經成為電腦使用體驗的重要環節。現代瀏覽器已經發展成強大、可拓展的平台。作為平台的一部分，_插件_能添加或修改瀏覽器的功能。火狐插件的構建使用了 WebExtensions API ，這是一個跨瀏覽器的開發系統。

你應該安裝哪一個插件？一般而言，這個問題的答案取決於你如何使用你的瀏覽器、你對於隱私的看法、你信任插件開發者多少以及其他個人喜好。

首先，我想指出瀏覽器插件通常需要讀取和（或者）修改你瀏覽的網頁上的每項內容。你應該_非常_仔細地考慮這件事的後果。如果一個插件有修改所有你訪問過的網頁的權限，那麼它可能記錄你的按鍵、攔截信用卡信息、在線跟蹤你、插入廣告，以及其他各種各樣邪惡的行為。

並不是每個插件都偷偷摸摸地做這些事，但是在你安裝任何插件之前，你要慎重考慮下插件安裝來源、涉及的權限、你的風險數據和其他因素。記住，你可以從個人數據的角度來管理一個插件如何影響你的攻擊面（ LCTT 譯註：攻擊面是指入侵者能嘗試獲取或提取數據的途徑總和）——例如使用特定的配置、不使用插件來完成例如網上銀行的操作。

考慮到這一點，這裏有你或許想要考慮的五個火狐插件

uBlock Origin ​

ublock Origin 可以攔截廣告和惡意網頁，還允許用户定義自己的內容過濾器。

uBlock Origin 是一款快速、內存佔用低、適用範圍廣的攔截器，它不僅能屏蔽廣告，還能讓你執行你自己定製的內容過濾。uBlock Origin 默認使用多份預定義好的過濾名單來攔截廣告、跟蹤器和惡意網頁。它允許你任意地添加列表和規則，或者鎖定在一個默認拒絕的模式。除了強大之外，這個插件已被證明是效率高、性能好。

Privacy Badger ​

Privacy Badger 運用了算法來無縫地屏蔽侵犯用户準則的廣告和跟蹤器。

正如它名字所表明，Privacy Badger 是一款專注於隱私的插件，它屏蔽廣告和第三方跟蹤器。EFF （LCTT 譯註：EFF 全稱是電子前哨基金會Electronic Frontier Foundation，旨在宣傳互聯網版權和監督執法機構）説：“我們想要推薦一款能自動分析並屏蔽任何侵犯用户準則的跟蹤器和廣告，而 Privacy Badger 誕生於此目的；它不用任何設置、知識或者用户的配置，就能運行得很好；它是由一個明顯為用户服務而不是為廣告主服務的組織出品；它使用算法來確定正在跟蹤什麼，而沒有跟蹤什麼。”

為什麼 Privacy Badger 出現在這列表上的原因跟 uBlock Origin 如此相似？其中一個原因是 Privacy Badger 從根本上跟 uBlock Origin 的工作不同。另一個原因是縱深防禦的做法是個可以遵循的合理策略。

LastPass ​

LastPass 是一款用户友好的密碼管理插件，支持雙因子認證。

這個插件對於很多人來説是個有爭議的補充。你是否應該使用密碼管理器——如果你用了，你是否應該選擇一個瀏覽器插件——這都是個熱議的話題，而答案取決於你的風險資料。我想説大部分不關心的電腦用户應該用一個，因為這比起常見的選擇：每一處使用相同的弱密碼，都好太多了。

LastPass 對於用户很友好，支持雙因子認證，相當安全。這家公司過去出過點安全事故，但是都處理得當，而且資金充足。記住使用密碼管理器不是非此即彼的命題。很多用户選擇使用密碼管理器管理絕大部分密碼，但是保持了一點複雜性，為例如銀行這樣重要的網頁採用了精心設計的密碼和多因子認證。

Xmarks Sync ​

Xmarks Sync 是一款方便的插件，能跨實例同步你的書籤、打開的標籤頁、配置項和瀏覽器歷史。如果你有多台機器，想要在桌面設備和移動設備之間同步、或者在同一台設備使用不同的瀏覽器，那來看看 Xmarks Sync 。（注意這款插件最近被 LastPass 收購）

Awesome Screenshot Plus ​

Awesome Screenshot Plus 允許你很容易捕獲任意網頁的全部或部分區域，也能添加註釋、評論、使敏感信息模糊等。你還能用一個可選的在線服務來分享圖片。我發現這工具在網頁調試時截圖、討論設計和分享信息上很棒。這是一款比你預期中發現自己使用得多的工具。

Awesome Screenshot Plus 允許你容易地截下任何網頁的部分或全部內容。

我發現這五款插件有用，我把它們推薦給其他人。這就是説，還有很多瀏覽器插件。我很感興趣社區用户們正在使用哪些插件，請在評論中讓我知道。

via: https://opensource.com/article/18/1/top-5-firefox-extensions
