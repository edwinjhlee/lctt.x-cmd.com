如何為數字貨幣定價 ​

預測數字貨幣價格是一場愚人遊戲，然而我想試試。單一數字貨幣價值的驅動因素目前太多，而且含糊不清，無法根據任何一點進行評估。或許新聞正報道説比特幣呈上升趨勢，但與此同時，有黑客攻擊或是交易所 API 錯誤，就讓比特幣的價格下跌。以太坊看起來不夠智能？誰知道呢，也許第二天就建立一個新的更智能的 DAO（LCTT 譯註：區塊鏈上，基於激勵的經濟協調機制，以代碼作為表達，通過互聯網進行傳輸，允許人們參與數字企業的風險&回報（即分配），代幣創建了 DAO 參與者之間的經濟鏈接）將吸引大量參與者。

那麼，您該如何投資呢？又或是更準確的講，您下注在哪種數字貨幣上呢？

理解什麼時候買賣和持有數字貨幣，關鍵是使用與評估開源項目價值的相關工具。這已經一次又一次地被提及了，但是為了理解當前數字貨幣的快速發展，您必須回到 Linux 悄然興起的時候。

互聯網泡沫期間，Linux 出現在大眾視野中。那時候，如果您想建立一個 Web 服務器，您必須將一台 Windows 服務器或者 Sun Sparc 工作站運送到一個服務器託管機房，在那裏它將為傳送 Pets.com（LCTT 譯註：一個在線寵物商店，藉着互聯網繁榮的機會崛起，在互聯網泡沫破裂時倒閉）的 HTML 頁面而做出努力。與此同時，Linux 就像運行在微軟和 Sun 公司平行路徑上的貨運列車一樣，可以讓開發人員使用日新月異的操作系統和工具集，快速、輕鬆地構建一次性項目。相比之下，解決方案提供商的花費比軟硬件支出少得多，很快，所有科技巨頭的業務由軟件轉向了服務提供，例如 Sun 公司。

Linux 的萌發促使整個開源市場蓬勃發展起來。但是有一個關鍵的問題，您無法從開源軟件中賺錢。您可以提供服務，也可以銷售使用開源組件的產品，但早期開源者主要是為了提升自我，而不是為了賺錢。

數字貨幣幾乎完全遵循 Linux 的老路，但數字貨幣具有一定貨幣價值。因此，當您在為一個區塊鏈項目工作時，您不是為了公共利益，也不是為了編寫自由軟件的樂趣，而是您寫它的時候期望得到一大筆錢。因此，這掩蓋了許多程序員的價值判斷。那些給您帶來了 Python、PHP、Django 和 Node.js 的人們回來了……而現在他們正在通過編程賺錢。

審查代碼庫 ​

今年將是代幣銷售和數字貨幣領域大清算的一年。雖然許多公司已經能夠擺脱糟糕的或不可用的代碼庫，但我懷疑開發人員是否能讓未來的公司擺脱如此雲山霧罩的東西。可以肯定地説，我們可以期待像這樣詳細描述 Storj 代碼庫不足之處的文章成為規範，這些評論會讓許多所謂的“ICO” 們（LCTT 譯註：代幣首次發行融資）陷入困境。雖然規模巨大，但 ICO 的資金渠道是有限的，在某種程度上不完整的項目會被更嚴格的審查。

這是什麼意思呢？這意味着要了解數字貨幣，您必須像對待創業公司那樣對待它。您要看它是否有一個好團隊？它是否是一個好產品？是否能運作？會有人想要使用它嗎？現在評估整個數字貨幣的價值還為時過早，但如果我們假設代幣將成為未來計算機互相支付的方式，這就讓我們擺脱了許多疑問。畢竟，2000 年沒有多少人知道 Apache 會在一個競爭激烈的市場上，幾乎擊敗其他所有的 Web 服務器，或者像 Ubuntu 一樣常見以至於可以隨時可以搭建和拆毀它們。

理解數字貨幣價值的關鍵是忽視泡沫、炒作、恐懼、迷惑和懷疑心理，而是關注其真正的效用。您認為有一天您的手機會為另外一個手機付款，比如遊戲內的額外費用嗎？ 您是否認為信用卡系統會在互聯網出現後消失？您是否期望有一天，在生活中花費一點點錢，讓自己過得更加舒適？然後，通過一切手段，購買並持有您認為將來可能會使您的生活過得更舒適的東西。如果您認為通過 TCP/IP 互聯網的方式並不能夠改善您的生活（或是您對其沒有足夠的瞭解），那麼您可能就不會關注這些。納斯達克總是開放的，至少在銀行的營業時間。

好的，下面是我的預測。

預測 ​

以下是我在考慮加密貨幣的“投資”時應該考慮的事項評估。在我們開始之前，先講下注意事項：

  • 數字貨幣不是真正的貨幣投資，而是投資在未來的技術。這就好比：當您購買數字貨幣時，我們像是在進取號星艦Starship Enterprise的甲板上交換“星際信用Galactic Credit”（LCTT 譯註:《星球大戰》電影中的一種貨幣）一般。 這是數字貨幣的唯一不可避免的未來。雖然您可以強制將數字貨幣附加到各種經濟模式中，對其抱有樂觀的態度，整個平台是技術烏托邦，並假設各種令人興奮和不可能的事情將在未來幾年來到。如果您有多餘的現金，您喜歡《星球大戰》，那麼您就可以投資這些“黃金”。如果您的兄弟告訴您相關信息，結果您用信用卡買了比特幣，那麼您可能會要度過一段啃饅頭的時間。
  • 不要相信任何人。沒有擔保，除了提供不是投資建議的免責聲明，而且這絕不是對任何特定數字貨幣的背書，甚至是普遍概念，但我們必須明白，我在這裏寫的任何東西都可能是錯誤的。事實上，任何關於數字貨幣的文章都可能是錯誤的，任何試圖賣給您吹得天花亂墜的代幣的人，幾乎肯定是騙子。總之，每個人都是錯的，每個人都想要得到您的錢，所以要非常、非常小心。
  • 您也可以持有。如果您是在 18000 美元的價位買的比特幣，您最好還是繼續持有下去。 現在您就好像正處於帕斯卡賭注。（LCTT 譯註：論述——我不知道上帝是否存在，如果他不存在，作為無神論者沒有任何好處，但是如果他存在，作為無神論者我將有很大的壞處。所以，寧願相信上帝存在）是的，也許您因為數字貨幣讓您賠錢而生氣，但也許您只是因為您的愚蠢和自大，但現在您不妨保持信仰，因為沒有什麼是必然的，或者您可以承認您是有點過於熱切。雖然現在您被懲罰，但要相信有比特幣之神在注視着您。最終您需要深吸一口氣，同意這一切都相當怪異，並堅持下去。

現在回過頭來評估數字貨幣。

比特幣 —— 預計明年的漲幅將超過目前的低點。此外，世界各地的證券交易委員會和其他聯邦機構也會開始以實際行動調整加密貨幣的買賣。現在銀行開玩笑説，他們想要降低數字貨幣的風險。因此，比特幣將成為數字黃金，成為投機者穩定，乏味但充滿波動的避風港。儘管所有都不能用作真正的貨幣，但對於我們所需要的東西來説，這已經足夠了，我們也可以期待量子計算的產品去改變最古老，最熟悉的加密貨幣的面貌。

以太坊 —— 只要創造者 Vitalik Buterin 不再繼續潑冷水，以太坊在價格上可以維持在上千美元。像一個懊悔的維克多·弗蘭肯斯坦Victor Frankenstein（LCTT 譯註：來自《維克多·弗蘭肯斯坦》電影的一名角色），Buterin 傾向於做出驚人的事情，然後在網上詆譭他們，這種自我鞭策在充滿泡沫和謊言的空間中實際上是非常有用的。以太坊是最接近我們有用的加密貨幣，但它本質上仍然是分佈式應用。這是一個很有用，很聰明的方法，可以很容易地進行實驗，但是，沒有人用新的分佈式數據存儲或應用程序取代舊系統。總之，這是一個非常令人興奮的技術，但是還沒有人知道該用它做什麼。

以太坊的價格將何去何從？它將徘徊在 1000 美元左右，今年可能高達 1500 美元，但這是一個原則性的科技項目，但卻不是一個保值產品。

競爭幣（LCTT 譯註：除比特幣，以太幣之外的所有的數字幣，亦稱之為山寨幣） —— 泡沫的標誌之一是當普通人説“我買不起比特幣，所以我買了萊特幣”這樣的話時。這正是我從許多人那裏聽到的，就好像説“我買不起漢堡，所以我買了一斤木屑，我想孩子們會吃的，對不對？”那您要自擔風險。競爭幣對於很多人來説是一個風險非常低遊戲，就好比您根據一個算法創造出某個競爭幣，在市值達到一定水平時賣出，那麼您可以賺取一筆不錯的利潤。況且，大多數競爭幣不會在一夜之間消失。 我誠實地推薦以太坊而不是競爭幣，但是如果您死磕競爭幣，那祝您玩得開心。

代幣 —— 這是數字貨幣變得有趣的地方。代幣需要研究機構和高校對技術有深入的瞭解，才能真正的評估。我見過的許多代幣都是一場賭博，價格暴漲暴跌。我不會給其命名，但是經驗法則是，如果您在公開市場上買了一個代幣，那麼您可能已經錯過了賺錢的機會。截至 2018 年 1 月，代幣銷售，莊家開始投資一個代幣幾美分，最後得到百倍的回報。雖然許多創始人談論他們的產品的神奇之處和他們的團隊的強大，但是就是為了單車變摩托，把價值 4 美分一個的代幣升值為 20 美分，再升值成一美元。您將收益乘以數百萬，就能看到它的吸引力了。

答案很簡單：找到您喜歡的幾個項目並潛藏在他們的社區中。評估團隊是否有實力，並且很早就知道該如何進入。將錢投入後就當扔掉幾個月或幾年。但無法保證，因為代幣理念太過超前，以至於無法對其評估。

您正在閲讀這篇文章，是因為您希望在這錯綜複雜的環境下得到一個方向。沒關係，我已經跟許多數字貨幣創始人交談，知道現在許多人不知道的事情，並且知道合謀和骯髒交易的準則。因此，像我們這樣的人，要慢慢地分批購買，就會開始明白這究竟是怎麼一回事，也許會從數字貨幣投資中獲利。當數字貨幣的潛力被完全發掘，我們會得到一個像 Linux 一樣的時代。
