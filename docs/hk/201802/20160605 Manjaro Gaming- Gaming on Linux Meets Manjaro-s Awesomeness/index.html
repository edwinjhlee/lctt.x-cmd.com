Manjaro Gaming：當 Manjaro 的才華遇上 Linux 遊戲 ​

在 Linux 上玩轉游戲? 沒錯，這是非常可行的，我們正致力於為遊戲人羣打造一個新的 Linux 發行版。

Manjaro Gaming 是一個專門為遊戲人羣設計的，帶有 Manjaro 所有才能的發行版。之前用過 Manjaro Linux 的人一定知道為什麼這對於遊戲人羣來説是一個如此好的一個消息。

Manjaro 是一個 Linux 發行版，它基於最流行的 Linux 發行版之一 —— Arch Linux。 Arch Linux 因它的前沿性所帶來的輕量、強大、高度定製和最新的體驗而聞名於世。儘管這些都非常贊，但是也正是因為 Arch Linux 提倡這種 DIY （do it yourself）方式，導致一個主要的缺點，那就是用户想用好它，需要處理一定的技術問題。

Manjaro 把這些要求全都剝離開去，讓 Arch 對新手更親切，同時也為老手提供了 Arch 所有的高端與強大功能。總之，Manjaro 是一個用户友好型的 Linux 發行版，工作起來行雲流水。

Manjaro 會成為一個強大並且極度適用於遊戲的原因：

  • Manjaro 自動檢測計算的硬件（例如，顯卡）
  • 自動安裝必要的驅動和軟件（例如，顯示驅動）
  • 預安裝播放媒體文件的編碼器
  • 專用的軟件庫提供完整測試過的穩定軟件包。

Manjaro Gaming 打包了 Manjaro 的所有強大特性以及各種小工具和軟件包，以使得在 Linux 上做遊戲即順暢又享受。

優化 ​

Manjaro Gaming 做了一些優化：

  • Manjaro Gaming 使用高度定製化的 XFCE 桌面環境，擁有一個黑暗風格主題。
  • 禁用睡眠模式，防止用手柄上玩遊戲或者觀看一個長過場動畫時計算機自動休眠。

軟件 ​

維持 Manjaro 工作起來行雲流水的傳統，Manjaro Gaming 打包了各種開源軟件包，提供遊戲人羣經常需要用到的功能。其中一部分軟件有：

  • KdenLIVE：用於編輯遊戲視頻的視頻編輯軟件
  • Mumble：給遊戲人羣使用的視頻聊天軟件
  • OBS Studio：用於錄製視頻或在 Twitch 上直播遊戲用的軟件
  • OpenShot：Linux 上強大的視頻編輯器
  • PlayOnLinux：使用 Wine 作為後端，在 Linux 上運行 Windows 遊戲的軟件
  • Shutter：多種功能的截圖工具

模擬器 ​

Manjaro Gaming 自帶很多的遊戲模擬器：

  • DeSmuME：Nintendo DS 任天堂 DS 模擬器
  • Dolphin Emulator：GameCube 和 Wii 模擬器
  • DOSBox：DOS 遊戲模擬器
  • FCEUX：任天堂娛樂系統（NES）、 紅白機（FC）和 FC 磁盤系統（FDS）模擬器
  • Gens/GS：世嘉模擬器
  • PCSXR：PlayStation 模擬器
  • PCSX2：Playstation 2 模擬器
  • PPSSPP：PSP 模擬器
  • Stella：Atari 2600 VCS （雅達利）模擬器
  • VBA-M：Gameboy 和 GameboyAdvance 模擬器
  • Yabause：世嘉土星模擬器
  • ZSNES：超級任天堂模擬器

其它 ​

還有一些終端插件 —— Color、ILoveCandy 和 Screenfetch。也包括帶有 Retro Conky（LCTT 譯註：復古 Conky）風格的 Conky 管理器。

注意：上面提到的所有功能並沒有全部包含在 Manjaro Gaming 的現行發行版中（版本 16.03）。部分功能計劃將在下一版本中納入 —— Manjaro Gaming 16.06（LCTT 譯註：本文發表於 2016 年 5 月）。

下載 ​

Manjaro Gaming 16.06 將會是 Manjaro Gaming 的第一個正式版本。如果你現在就有興趣嘗試，你可以在 Sourceforge 的項目頁面中下載。去那裏然後下載它的 ISO 文件吧。
