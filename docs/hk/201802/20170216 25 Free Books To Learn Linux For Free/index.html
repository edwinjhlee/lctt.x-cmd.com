25 個學習 Linux 的免費資源 ​

在這篇文章中，我將與你分享免費學習 Linux 的最佳資源。這個集合包括了網站、在線視頻課程和免費電子書。

如何學習 Linux ？

這可能是 Facebook Linux 用户組中最常見的問題。

“如何學習 Linux”這個看起來簡單的問題的答案並不簡單。

問題在於不同的人對於學習 Linux 有不同的意義。

  • 比如有人從來沒有使用過 Linux，無論是命令列還是桌面版本，那個人可能只是想知道更多關於它的信息。
  • 比如有人使用 Windows 作為桌面，但必須在工作中使用 Linux 命令列，那個人可能對學習 Linux 命令感興趣。
  • 比如有人已經使用過一段時間的 Linux，而且懂得一些基礎，但他/她可能想要更上一層樓。
  • 比如有人只是對 Linux 特定的發行版本感興趣。
  • 比如有人想要提升或學習幾乎與 Linux 命令列差不多的 Bash 腳本。
  • 比如有人想要從事一個 Linux 系統管理員的職業，或者想提高他/她的系統管理技能。

你看，“我如何學習 Linux”的答案取決於你追求什麼樣的 Linux 知識。為此，我收集了大量能用來學習 Linux 的資源。

這些免費的資源包括電子書、視頻課程、網站等。這些資源分成幾個子類別，以便當你試圖學習 Linux 時可以很容易地找到你想要的東西。

再者，這裏沒有學習 Linux 的最好方式。這完全取決於你如何去學習 Linux，通過在線門户網站、下載電子書、視頻課程或者其他。

讓我們看看你能如何學習 Linux。

免責聲明 : 這裏列舉的所有書都可以合法的下載。 據我所知，這裏提到的資源都是官方的資源。但是，如果你發現它不是，請讓我知道以便我可以採取適當的措施。

1. 對於完全新手學習 Linux 的免費資料 ​

也許你剛剛從朋友那裏或者從網上的討論中聽到了 Linux。關於 Linux 的炒作讓你對 Linux 很感興趣，你被互聯網上的大量信息所淹沒，不知道在哪裏尋找更多的關於 Linux 的知識。

不用擔心，我們中的大多數，即使不是全部，都經過過這個階段。

Linux 基金會關於 Linux 的介紹 [視頻課程] ​

如果你對於什麼是 Linux 和如何開始學習 Linux 完全沒有概念的話，我建議你從學習 Linux 基金會在 edX 上提供的免費的視頻課程開始。它可以看做“維護” Linux 的組織的一個官方課程——是的，這個組織是由 Linux 之父 Linus Torvalds 所背書的。

  • Introduction To Linux

Linux 旅程 [網站] ​

不是官方的，也許不是很受歡迎。但是這個小網站對於初學者來説是一個 Linux 學習的完美場所。

該網站設計精美，並根據主題組織得很好。它給你提供了能夠在閲讀完一個片段或章節後的進行的互動式測驗。我的建議是收藏這個網站：

  • Linux Journey

《5 天學習 Linux》 [電子書] ​

這本出色的書針對 FOSS 讀者來説完全的免費，這完全得感謝 Linux Training Academy。

為完全的新手而寫，這本免費的 Linux 電子書給了你一個關於 Linux 的概述、常用的 Linux 指令和你開始學習 Linux 所需要的其他東西。

你能夠從下面的網頁下載該書：

  • Learn Linux In 5 Days

《Linux 新手終極指南》 [電子書] ​

這是一本面向 Linux 初學者的免費下載的電子書。該電子書從解釋什麼是 Linux 開始，並提供了將 Linux 作為桌面的更多實際使用經驗。

您可以從下面的鏈接下載最新版本的電子書：

  • The Ultimate Linux Newbie Guide

2. 初學者進階的免費書籍 ​

本節列出了那些已經“完成”的 Linux 電子書。

我的意思是，這些之中的大部分就像是專注於 Linux 的每個方面的學術教科書。你可以作為一個絕對的新手閲讀這些書，或者你也可以作為一箇中級的 Linux 用户來深入學習。即使你已經是專家級，你也可以把它們作為參考。

《Linux 介紹》 [電子書] ​

《Linux 介紹》是 Linux 文檔計劃的免費電子書，而且它是最熱門的 Linux 免費電子書之一。即使我認為其中的部分段落需要更新，它仍然是一本非常好的電子書，可以教你 Linux、Linux 的文件系統、命令列、網絡和其他相關的東西。

  • Introduction To Linux

《Linux 基礎》 [電子書] ​

這本由 Paul Cobbaut 編寫的免費的電子書可以教你關於 Linux 的歷史、安裝和你需要知道的基本的 Linux 命令。你能夠從下列鏈接上得到這本書：

  • Linux Fundamentals

《Linux 高級編程》 [電子書] ​

顧名思義，這是一本面向想要或者正在開發 Linux 軟件的高級用户的書。它闡釋了那些複雜的功能，比如多進程、多線程、進程間通信以及和硬件設備的交互。

跟着這本書學習會幫你開發一個更快速、更可靠、更安全的使用 GNU/Linux 系統全部功能的項目。

  • Advanced Linux Programming

《LFS》 [電子書] ​

如果你認為自己對 Linux 有足夠的瞭解，並且你是一個專業人士，那麼為什麼不創建自己的 Linux 版本呢？ Linux From Scratch（LFS）是一個完全基於源代碼，為你構建你自定義的 Linux 系統提供手把手的指導。

可以把它叫做 DIY Linux ，它是一個把你的 Linux 專業知識提高到新的高度的方法。

這裏有許多的關於這個項目的子項目，你能夠在這個網站上查看和下載。

  • Linux From Scratch

3. 學習 Linux 命令和 Shell 腳本的免費電子書 ​

Linux 的真正強大在於命令列，如果你想要征服 Linux，你必須學習命令列和shell。

事實上，如果你必須在你的工作中使用 Linux 終端，那麼熟悉 Linux 命令列實際上會幫助你完成任務，也有可能幫助你提高你的職業生涯（因為你會更有效率）。

在本節中，我們將看到各種 Linux 命令方面的免費電子書。

《GNU/Linux 命令列工具總覽》 [電子書] ​

這本 Linux 文檔項目中的電子書是接觸 Linux 命令列並開始熟悉 Shell 腳本的好地方。

  • GNU/Linux Command−Line Tools Summary

《GNU Bash 參考手冊》 [電子書] ​

這是一本可以從 GNU 網站下載的免費電子書。 就像名字暗示的那樣, 它涉及 Bash Shell （如果我能這麼叫的話）。這本書超過了 175 頁，而且它包括了許多在 Bash 裏和 Linux 有關的主題。

你能夠從下面的鏈接中獲取：

  • Bash Reference Manual

《Linux 命令列》 [電子書] ​

這本 500 多頁的由 William Shotts 編寫的免費電子書，對於那些認真學習 Linux 命令列的人來説，是一本必須擁有的書。

即使你認為你已經瞭解了 Linux，你還是會驚訝於這本書能教你很多東西。

它涵蓋了從初學者到高級的東西。我敢打賭讀完這本書之後你會成為一個更好的 Linux 用户。請下載這本書並且隨時攜帶它。

  • The Linux Command Line

《Bash 入門指南》 [電子書] ​

如果你想從 Bash 腳本開始，這可能對於你來説是一個很好的助手。 這本電子書也是基於 Linux 文檔項目的，它是編寫 《Linux 介紹》的電子書的作者（本文前面討論過）。

  • Bash Guide for Beginners

《Bash 腳本高級指南》 [電子書] ​

如果你認為你已經瞭解了基本的 Bash 腳本知識，並且你想把你的技能提高到一個新的水平，這本書就是你所需要的。這本書有超過 900 頁的各種高級命令和舉例。

  • Advanced Bash-Scripting Guide

《AWK 編程語言》 [電子書] ​

這不是一本很美觀的書，但是如果你真的想要深入學習腳本，這本雖舊但是依然很棒的書會很有幫助。

  • The AWK Programming Language

《Linux 101 技巧》 [電子書] ​

這本 270 多頁的書來自“The Geek Stuff”，通過易於跟蹤學習的例子教給你 Linux 命令列基礎。你能夠從下列的鏈接獲取:

  • Linux 101 Hacks

4. 特定發行版的免費學習資料 ​

這個章節專注於特定 Linux 發行版的材料。到目前為止，我們看到的都是以常規的方式學習 Linux，更多的關注於文件系統、命令和其他的核心內容。

這些書，在另一方面，可以被認為是用户手冊或者開始學習各種各樣的 Linux 發行版的指南。所以如果你正在使用或準備使用一個特定的 Linux 發行版，你可以參考這些資源。是的，這些書更加關注 Linux 桌面。

我還想補充的是，大部分的 Linux 發行版有它們自己的大量的 wiki 或者文檔。你能夠從網上隨時找到它們。

《Ubuntu 用户指南》 [電子書] ​

不用説，這本書是針對 Ubuntu 用户的。這是一個獨立的項目，以免費電子書的形式提供 Ubuntu 的用户指南。它對於每個版本的 Ubuntu 都有更新。

這本書被叫做用户指南因為它是由一步步的指導組成的，而且受眾目標是對於 Ubuntu 完全新手的。所以，你會了解到 Unity 桌面，以及怎樣逐漸使用它而且查找應用等等。

如果你從來沒有使用過 Ubuntu Unity ，那麼這是一本你必須擁有的書，因為它幫助你理解怎樣在日常中使用 Ubuntu。

  • Ubuntu Manual

《面向 Linux Mint：直接告訴我就行！》 [電子書] ​

一本非常基本的關於 Linux Mint 的電子書。它告訴你怎麼樣在虛擬機中安裝 Linux Mint，怎麼樣去查找軟件，安裝更新和自定義 Linux Mint 桌面。

你能夠在下面的鏈接下載電子書：

  • Just Tell Me Damnit!

《Solus Linux 用户指南》 [電子書] ​

注意！這本書過去是 Solus Linux 的官方用户指南，但是我找不到 Solux 項目的網站上在哪裏有提到它。我不知道它是不是已經過時了。儘管如此，反正不要錢，多少學習一點 Solus Linux。

  • Solus Linux User Guide

5. 面向系統管理員的免費電子書 ​

這個章節主要關注於系統管理員——開發者的超級英雄。我已經列了一部分會真正幫助那些已經是系統管理者或者想要成為系統管理者的免費的電子書。我還得説，你必須要關注基本的 Linux 命令列，因為它會使你的工作更加簡單。

《The Debian 管理手冊》 [電子書] ​

如果你使用 Debian Linux 作為你的服務器，這本書就是你的聖經。這本書從 Debian 的歷史、安裝、包管理等等開始，接着覆蓋一些主題，比如説 LAMP、虛擬機、存儲管理和其他核心系統管理。

  • The Debian Administration's Handbook

《高級 Linux 系統管理》 [電子書] ​

如果在準備 LPI 認證，那麼這本書是一本理想的書。這本書的涉及系統管理員必要的主題，所以瞭解 Linux 命令列是前置條件。

  • Advanced Linux System Administration

《Linux 系統管理》 [電子書] ​

Paul Cobbaut 編寫的另一本免費的電子書。370 頁長的的書包括了網絡、磁盤管理、用户管理、內核管理、庫管理等等。

  • Linux System Administration

《Linux 服務器》 [電子書] ​

又一本來自 linux-training.be 的 Paul Cobbaut 編寫的電子書。這本書包括了 Web 服務器、MySQL、DHCP、DNS、Samba 和其他文件服務器。

  • Linux Servers

《Linux 網絡》 [電子書] ​

網絡是系統管理者的麪包和黃油，這本也是由 Paul Cobbaut 編寫的書是一本好的參考資料。

  • Linux Networking

《Linux 存儲》 [電子書] ​

這本由 Paul Cobbaut（對，還是他）編寫的書詳細解釋了 Linux 的磁盤管理，而且介紹了許多其他的和存儲相關的技術。

  • Linux Storage

《Linux 安全》 [電子書] ​

這是這個書單裏最後一本由 Paul Cobbaut 編寫的書。安全是系統管理員最重要的工作之一。這本書關注文件權限、ACL、SELinux、用户和密碼等等。

  • Linux Security

你有什麼最喜愛的 Linux 資料嗎？ ​

我知道這是一個不錯的免費 Linux 電子書集合，但是它可以做的更好。

如果你有學習 Linux 方面有更大幫助的其它資料，請務必和我們共享。請注意只共享合法的下載資料，以便我可以根據你的建議更新這篇文章而不會有任何問題。
