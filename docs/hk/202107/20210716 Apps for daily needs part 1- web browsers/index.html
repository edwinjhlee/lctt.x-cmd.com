滿足日常需求的應用（一）：Web 瀏覽器 ​

滿足日常需求的重要應用之一是 Web 瀏覽器。這是因為上網是大多數人在電腦前進行的一項活動。本文將介紹一些你可以在 Fedora Linux 上使用的開源 Web 瀏覽器。你需要安裝上述軟件。本文提到的所有瀏覽器都已經在官方的 Fedora 軟件庫中提供。如果你不熟悉如何在 Fedora Linux 中添加軟件包，請參閲我之前的文章 安裝 Fedora 34 工作站後要做的事情。

Firefox ​

火狐Firefox是一個快速且注重隱私的瀏覽器，可以在許多設備上使用。它是由 Mozilla 創建的，是一個具有完整功能的瀏覽器，提供許多擴展。你可以為你的火狐瀏覽器添加許多強大的功能和有用的特性。它只使用適量的內存來創造一個流暢的體驗，使你的電腦保持對其他任務的響應。你可以創建一個賬户，讓你在多個設備上共享配置，所以你不需要在每個設備上設置火狐瀏覽器。

火狐瀏覽器提供以下功能：

  • 隱私瀏覽模式
  • 阻止廣告跟蹤器
  • 密碼管理器
  • 設備之間的同步
  • 畫中畫

關於火狐瀏覽器的更多信息可在此鏈接中找到：https://www.mozilla.org/en-US/firefox

GNOME Web ​

GNOME Web 是 GNOME 桌面（Fedora 工作站的默認桌面環境）的一個瀏覽器。如果你使用 GNOME 作為默認桌面環境的 Fedora 工作站，它可能非常適合作為你的主瀏覽器。這個瀏覽器有一個簡單、乾淨、漂亮的外觀。GNOME Web 的功能比 Firefox 少，但對於普通用途來説已經足夠了。

GNOME Web 提供了以下功能：

  • 隱身模式
  • GNOME 桌面集成
  • 內置廣告攔截器
  • 智能跟蹤預防

關於 GNOME Web 的更多信息可以在這個鏈接中找到：https://wiki.gnome.org/Apps/Web

Chromium ​

Chromium 是一個來自 Chromium 項目的開源 Web 瀏覽器，它有一個極簡的用户界面。它的外觀與 Chrome 相似，因為它實際上是作為 Chrome 和其他幾個瀏覽器的基礎。許多人使用 Chromium 是因為他們已經習慣了 Chrome。

Chromium 提供以下功能：

  • 隱身模式
  • 擴展程序
  • 密碼的自動填寫

關於 Chromium 瀏覽器的更多信息可在此鏈接中找到：https://www.chromium.org/Home

qutebrowser ​

這個瀏覽與上面提到的稍有不同，qutebrowser 是一個以鍵盤為中心的瀏覽器，具有精簡的 GUI。因此，你不會發現通常在其他瀏覽器中的按鈕，如返回、主頁、重新加載等。相反，你可以用鍵盤輸入命令來運行 qutebrowser 中的功能。它使用 Vim 風格的鍵綁定，所以它適合 Vim 用户。如果你有興趣在上網時獲得不同的體驗，你應該試試這個瀏覽器。

qutebrowser 提供以下功能：

  • 廣告屏蔽
  • 隱私瀏覽模式
  • 快速書籤

關於 qutebrowser 瀏覽器的更多信息可在此鏈接中找到：https://qutebrowser.org/

總結 ​

每個人在使用互聯網時都有不同的需求，特別是在瀏覽方面。本文中提到的每個瀏覽器都有不同的功能。因此，請選擇適合你日常需求和喜好的瀏覽器。如果你使用的是本文中提到的瀏覽器，請在評論中分享你的故事。如果你使用的是其他的瀏覽器，請説一下。希望這篇文章能幫助你選擇在 Fedora 上滿足你日常需求的瀏覽器。

via: https://fedoramagazine.org/apps-for-daily-needs-part-1-web-browsers/
