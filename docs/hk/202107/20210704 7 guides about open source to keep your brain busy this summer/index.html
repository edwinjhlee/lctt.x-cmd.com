讓你的大腦在這個夏天保持忙碌的 7 本開源指南 ​

下載我們的免費指南之一：開發一個基於 Python 的電子遊戲；使用開源工具來讓你的生活井井有條；完成家庭自動化項目；或嘗試你的樹莓派家用實驗室。

（LCTT 譯註：opensource.com 的免費電子書需要免費註冊一個用户才能下載。）

開啓一個新的樹莓派項目 ​

近十年來，樹莓派一直俘獲着開源愛好者的心和手。你可以用樹莓派做無數的項目，無論是 監控你的花園、設置家長監控（尤其是在那些漫長的夏天），甚至從你自己的後院 跟蹤飛機。如果這些很酷的項目激起了你的興趣，但你的樹莓派仍在吃灰，那麼你需要下載我們的指南來促使你開始行動。在你知道它之前，你需要學習 如何管理它們，因為你將與很多樹莓派一起工作！

下載：《如何開始使用你的樹莓派》

設計你的開源智能家庭 ​

一個聰明且有用的方式去使用樹莓派的方式是去設計你的智能家庭。使用家庭助手或其他的開源工具，你的家可以按你自己的設置進行自動化而無需藉助第三方平台。作者 Steve Ovens 用這本家庭自動化集錦的手寫電子書來指導你的每一步工作。

下載：《使用開源工具實現家庭自動化的實用指南》

將事情梳理地井井有條 ​

可能你並沒做好準備使得你的家庭完全自動化，但是你可能會對梳理你的思維有興趣。為什麼不從你的 to-do 列表開始呢？在貢獻者 Kevin Sonney 的生產力指導下，你將會熟悉六個開源工具的使用，從而幫你把事情安排得井井有條。一旦你完成了他的教程，你就會感到事情井井有條，在這個夏天終於有時間放鬆了。

下載：《六個可以將事情梳理地井井有條的開源工具》

學習如何寫代碼 ​

電腦無處不在。能吐槽一下很多編程語言對初學者不是很友好嗎？

有許多為初學者設計的編程語言。Bash 是 Linux 和 macOS 終端中使用的相同的腳本語言，如果你新開始寫代碼，Bash 將會是一個偉大的開始。你可以以 互動的方式學習它，之後下載我們的電子書以瞭解更多。

下載：《Bash 編程指南》

用 Python 寫一個遊戲 ​

另一個初學者喜歡的編程語言是 Python。它不僅受到僅僅學習編碼的中小學生的歡迎，還被專業程序員用來做 網站開發、視頻編輯 以及 雲端自動化。無論你最終的目標是什麼，開始學習 Python 的一個有趣的方式是編寫一個自己的遊戲。

下載：《Python 遊戲開發指南》

發現使用 Jpuyter 的巧妙方法 ​

為了讓 Python 具有交互性且易於分享，Jupyter 項目提供了基於 Web 的發展環境。你可以在“筆記本”文件中寫代碼，然後將其發送給其他用户，以便他們輕鬆複製和可視化你所做的。它是代碼、文檔和演示文稿的完美組合，而且非常靈活。下載 Moshe Zadka 的多方面指南瞭解更多關於 Jupyter。

下載：《使用 Jupyer 的六種驚豔方式》

在你的家庭實驗室裏嘗試 Kubernetes ​

現在，你已經在你的樹莓派上安裝了 Linux，已經登錄，已設置新用户並 配置了 sudo 使得能夠進入管理員模式，你正在 運行所有你需要的服務 。之後呢？

如果你對 Linux 和服務器管理感到滿意，你的下一步可能是雲服務。可以讀一下 Chris Collins 的電子書，從你的家庭實驗室的舒適中瞭解所有關於容器，吊艙和集羣的信息。

下載: 《在你的樹莓派家庭實驗室上運行 Kubernetes》
