Jim Hall，你覺得 Fedora 怎麼樣? ​

我們最近採訪了 Jim Hall，瞭解他是如何使用 Fedora 的。這個 Fedora 雜誌 系列 中的一篇。該系列介紹了 Fedora 用户以及他們如何使用 Fedora 來完成任務。如果你對本系列的後繼採訪感興趣，請通過 反饋表 與我們聯繫。

Jim Hall 是誰？ ​

Jim Hall 曾擔任高等教育和政府部門的首席信息官超過 8 年，最近創辦了諮詢公司 Hallmentum。他的大部分工作包括培訓、研討會和指導，幫助新的 IT 領導者發展領導技能，也幫助當前的 IT 領導者更好地發揮領導力。除了諮詢，Jim 還擔任大學的兼職教師，目前教授管理信息系統（MIS）和技術與專業寫作課程。

Jim 是如何成長的? Jim 童年時代的英雄來自電視和電影，包括蝙蝠俠和漢索羅。Jim 長期以來最喜歡看的電影是《星球大戰：新希望》。Jim 説：“我是一個星球大戰迷。”Jim 最喜歡吃意大利菜，“我喜歡意大利菜！我最喜歡的意大利菜可能是燉雞”。Jim 的觀點是，誠實、創造力、想像力、好奇心和開放性是一個人所能擁有的五個好品質。

他喜歡寫作，非常好的是他的日常工作主要是寫作。他花了很多時間為像 OpenSource.com、 CloudSavvy IT 和 Linux Magazine 等網站撰寫“如何”類文章。現在他正在寫一本關於 C 編程的書。除了寫作，他還玩電子遊戲來放鬆。他有一台 PlayStation 4 遊戲機，大多數週六下午他都會坐在電視機前玩遊戲。

Fedora 社區 ​

Jim 從 1993 年開始使用 Linux。他的第一個 Linux 發行版是 Softlanding Linux System（SLS）1.03，運行 Linux 內核 0.99，補丁級別 11。“從那以後，我一直是家裏的全職 Linux 用户”。Jim 在很久以前參加了 Fedora Core 時代的一個 Linux 會議之後，開始更多參與到 Fedora 中。Jim 在這遇見了 Tom “Spot” Callaway，他們開始談論 Fedora。“Spot 鼓勵我用另一種方式來做貢獻：找到 bug 並報告它們。這就是我參與測試所有 Beta 版本的原因”。

Jim 想在 Fedora 改變什麼? 他想在 getfedora.com 上看到一個倒計時，告訴大家新的 Beta 版本或新的完整版本是什麼時候發佈的，這是 Fedora 項目的一個改變。並且 Jim 想讓人們都知道，使用 Fedora 是多麼容易。“對開源做出貢獻最具挑戰性的事情是，弄清楚如何做出他們的第一個貢獻。”Jim 補充道，“我不知道我和其他開發人員一樣是‘Fedora 項目成員’。我只是個用户。但是作為一個從 1993、1994 年就開始參與開發開源軟件的人，我努力成為社區中一個有用的成員。因此，我利用一切機會嘗試新的 Fedora 版本，甚至是 Beta 版，如果我發現問題，就會告訴大家。”

你用什麼硬件？ ​

Jim 目前正在運行一台 ThinkCentre M720 Tiny。它配置了第 8 代酷睿 i3-8100T（3.10GHz，6MB 緩存）、32GB（16GB + 16GB）DDR4 2666MHz、英特爾顯卡、256GB 固態硬盤 PCIe-NVME Opal M.2、英特爾 8265 802.11AC 和 藍牙 4.2。他的顯示器是華碩 VE248H。 Jim 説：“這一切在Fedora上都很好用！”。

他使用 Perixx Periboard-512 人體工程學經典分體式鍵盤，它從 1998 年開始取代了他最初的微軟 Natural Keyboard Elitee PS/2 鍵盤。Jim 説： “我有時候會把我的 Perixx 鍵盤換成 Unicomp 的 IBM Model M USB 克隆鍵盤。我很喜歡這種帶有扣動式彈簧動作的點擊式鍵盤。我的是‘灰白色’，所以它有種經典的外觀和感覺”

你用什麼軟件？ ​

Jim 目前運行的是 Fedora 33，之前是 Fedora 33 Beta 和 Fedora 32。Jim 説：“我使用 GNOME 3 作為我的桌面。我發現默認設置適合我的大多數需求，所以我沒有加載任何 GNOME 擴展，但我確實使用‘設置’和 ‘GNOME Tweaks’ 調整了一些東西。所以我沒有做什麼大的改變。例如，我將默認用户界面字體改為使用 Droid Sans Regular 字體。並且我用‘設置’來改變鍵盤快捷鍵，用 Alt-Tab 鍵來切換窗口，而不是切換應用程序。我是在 Alt-Tab 工作流程中長大的，所以我已經習慣了。”他使用火狐和谷歌瀏覽器來作為他的 Web 瀏覽器。

為了經營他的諮詢業務，Jim 依賴於一套應用程序：

  • 使用 LibreOffice 去寫他的書。例如，他去年出版了 《Coaching Buttons》，他完全使用 LibreOffice 來寫這本書。最近他寫了一本關於 用 C 語言編寫 FreeDOS 程序的書 也用了 LibreOffice 。
  • INKSCAPE 為他創建了矢量格式的公司標誌。他的標誌可以完美地放大縮小，從文件上的小角落圖像到大幅面的海報或橫幅。並且 INKSCAPE 允許他導出各種通用格式。Jim 説他的廣告合作伙伴很欣賞 INKSCAPE 可以輸出到EPS（Encapsulated Postscript），這使得在產品上打印他的標誌變得很容易。
  • GIMP 用於其他圖形，例如閃屏圖片。“我的閃屏圖片是我們公司的標誌被放在了背景照片上，在我需要額外裝飾的地方，比如印刷材料，我用它來替代普通標誌。我也在我的網站上使用了閃屏圖片的一個版本”。
  • QEMU 用來運行虛擬機，在他那裏可以啓動 FreeDOS。“我喜歡使用 QEMU，因為我可以在命令列中設置所有需要的選項，這使我在配置虛擬機時有了很大的靈活性。為了更方便，我將所有選項放入到一個腳本中，用它來運行QEMU，每次都是相同的選項”。
  • Scribus 是用來打印產品的。Scribus 很容易用來創建具有“全出血”的印刷品，這意味着任何顏色的背景都會與紙張的邊緣重疊。全出血需要一個特殊的打印準備文件，與打印區域重疊。它甚至還提供了切割標記，以便打印機準確地知道要修剪的位置。
