在 Linux 桌面中開始使用 Lumina ​

本文是 24 天 Linux 桌面特別系列的一部分。Lumina 桌面是讓你使用快速、合理的基於 Fluxbox 桌面的捷徑，它具有你無法缺少的所有功能。

多年來，有一個名為 PC-BSD 的基於 FreeBSD 的桌面操作系統（OS）。它旨在作為一個常規使用的系統，因此值得注意，因為 BSD 主要用於服務器。大多數時候，PC-BSD 默認帶 KDE 桌面，但是 KDE 越來越依賴於 Linux 特定的技術，因此 PC-BSD 越來越從 KDE 遷離。PC-BSD 變成了 Trident，它的默認桌面是 Lumina，它是一組小部件，它們使用與 KDE 相同的基於 Qt 的工具包，運行在 Fluxbox 窗口管理器上。

你可以在 Linux 發行版的軟件倉庫或 BSD 的 ports 樹中找到 Lumina 桌面。如果你安裝了 Lumina 並且已經在運行另一個桌面，那麼你可能會發現有冗餘的應用（兩個 PDF 閲讀器、兩個文件管理器，等等），因為 Lumina 包含一些集成的應用。如果你只想嘗試 Lumina 桌面，那麼可以在虛擬機如 GNOME Boxes 中安裝基於 Lumina 的 BSD 發行版。

如果在當前的操作系統上安裝 Lumina，那麼必須註銷當前的桌面會話，才能登錄到新的會話。默認情況下，會話管理器（SDDM、GDM、LightDM 或 XDM，取決於你的設置）將繼續登錄到以前的桌面，因此你必須在登錄之前覆蓋該桌面。

Lumina 桌面 ​

Lumina 提供了一個簡單而輕巧的桌面環境。屏幕底部有一個面板，它的左側是應用菜單，中間是任務欄，右邊是系統托盤。桌面上有圖標，可以快速訪問常見的應用和路徑。

除了這個基本的桌面結構外，Lumina 還有自定義文件管理器、PDF 查看器，截圖工具、媒體播放器、文本編輯器和存檔工具。還有一個配置程序可以幫助你自定義 Lumina 桌面，並且右鍵單擊桌面可以找到更多配置選項。

Lumina 與幾個 Linux 輕量級桌面非常相似，尤其是 LXQT，不同之處在於 Lumina 完全不依賴於基於 Linux 的桌面框架（例如 ConsoleKit、PolicyKit、D-Bus 或 systemd）。對於你而言，這是否具有優勢取決於所運行的操作系統。畢竟，如果你運行的是可以訪問這些功能的 Linux，那麼使用不使用這些特性的桌面可能就沒有多大意義，還會減少功能。如果你運行的是 BSD，那麼在 Fluxbox 中運行 Lumina 部件意味着你不必從 ports 安裝 Linux 兼容庫。

為什麼要使用 Lumina ​

Lumina 設計簡單，它沒有很多功能，但是你可以安裝 Fluxbox 你喜歡的組件（用於文件管理的 PCManFM、各種 LXQt 應用、Tint2 面板等）。在開源中，開源用户喜歡尋找不要重複發明輪子的方法（幾乎與我們喜歡重新發明輪子一樣多）。

Lumina 桌面是讓你使用快速、合理的基於 Fluxbox 桌面的捷徑，它具有你無法缺少的所有功能，並且你很少需要調整細節。試一試 Lumina 桌面，看看它是否適合你。
