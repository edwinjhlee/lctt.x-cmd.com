Dell XPS 13 7390：最好的 Linux 桌面筆記本 ​

曾經，我們必須進行大量研究、閲讀大量評論，才能找到一種在所選的 Linux 桌面發行版上可以以最少的麻煩工作的機器。而如今，這種日子已經一去不復返了，幾乎每台機器都可以運行 Linux。Linux 內核社區在設備驅動程序支持方面做得非常出色，可以使一切都開箱即用。

不過，有的是可以運行 Linux d 機器，有的是運行 Linux 的機器。戴爾計算機屬於後一類。五年前，Barton George 在戴爾內部啓動了一項計劃，將桌面版 Linux 引入到消費級的高端戴爾系統。從一台機器開始，到現在整套從產品線的高端筆記本電腦和台式機都可以運行 Linux。

在這些機器中，XPS 13 是我的最愛。儘管我需要一個功能強大的台式機來處理 4K UHD、多機位視頻製作，但我還需要一台超便攜的筆記本電腦，可以隨身攜帶，而不必擔心笨重的背包和充電器。XPS 13 也是我的第一台筆記本電腦，陪了我 7 年多。因此，是的，這還有一個懷舊因素。

戴爾幾乎每年都會更新其 XPS 產品線，並且最新的產品展示宣佈於 10 月。[XPS 13（7390）] 4 是該系列的增量更新，而且戴爾非常樂意向我寄來一台測評設備。

它由 6 核 Core i7-10710U CPU 所支持。它配備 16GB 內存和 1TB SSD。在 1.10 GHz 的基本頻率（可以超頻到 4.1 GHz）的情況下，這是一台用於常規工作負載的出色機器。它沒有使用任何專用的 GPU，因此它並不適合進行遊戲或從源代碼進行編譯的 Gentoo Linux 或 Arch Linux。但是，我確實設法在上面運行了一些 Steam 遊戲。

如果你想運行 Kubernetes 集羣、AI 框架或虛擬現實，那麼 Precision 系列中還有更強大的機器，這些機器可以運行 Red Hat Enterprise Linux 和 Ubuntu。

該機器的底盤與上一代相同。邊框保持與上一代一樣的薄，依舊比 MacBook 和微軟的 Surface Pro 薄。

它具有三個端口，其中兩個是 USB-C Thunderbolt 3，可用於連接 4K 顯示器、USB 附件以及用於對等網絡的計算機之間的高速數據傳輸。

它還具有一個 microSD 插槽。作為視頻記者，SD 卡插槽會更有用。大量使用樹莓派的用户也會喜歡這種卡。

它具有 4 個麥克風和一個改進的攝像頭，該攝像頭現在位於頂部（再見，鼻孔攝像頭！）。

XPS 13（7390）光滑纖薄。它的重量僅為 2.7 磅（1.2kg），可以與蘋果的 MacBook Air 相提並論。 這台機器可以成為你的旅行伴侶，並且可以執行日常任務，例如檢查電子郵件、瀏覽網絡和寫作。

其 4K UHD 屏幕支持 HDR，這意味着你將可以盡享《The Mandalorian》的全部美妙之處。另外，車載揚聲器並沒有那麼好，聽起來有些沉悶。它們適合進行視頻聊天或休閒的 YouTube 觀看，但是如果你想在今年晚些時候觀看《The Witcher》劇集，或者想欣賞 Amazon、Apple Music 或 YouTube Music 的音樂，則需要耳機或外接揚聲器。

但是，在插入充電線之前，你可以能使用這台機器多少時間？在正常工作量的情況下，它為我提供了大約 7-8 個小時的電池續航時間：我打開了幾個選項卡瀏覽網絡，只是看看電影或聽音樂。多任務處理，尤其是各種 Web 活動，都會加速消耗電池電量。在 Linux 上進行一些微調可能會給你帶來更多的續航時間，而在 Windows 10 上，我可以使用 10 多個小時呢！

作為仍在從事大量寫作工作的視頻記者，我非常喜歡鍵盤。但是，我們這麼多年來在 Linux 台式機上聽到的觸控板故事一直沒變：它與 MacBook 或 Windows 上的品質相差甚遠。這或許有一天能改變。值得稱道的是，他們確實發佈了可增強體驗的觸控板驅動程序，但我沒有運行此係統隨附的提供的 Ubuntu 18.04 LTS。我全新安裝了 Ubuntu 19.10，因為 Gnome 在 18.04 中的運行速度非常慢。我嘗試過 openSUSE Tumbleweed、Zorin OS、elementary OS、Fedora、KDE neon 和 Arch Linux。一切正常，儘管有些需要額外的努力才能運行。

那麼，該系統適用於誰？顯然，這是給那些想要設計精良的、他們信賴的品牌的高端機器的專業人士打造的。適用於喜歡 MacBook Air，但更喜歡 Linux 台式機生態系統的用户。適用於那些希望使用 Linux 來工作，而不是使 Linux 可以工作的人。

我使用這台機器一週的時間，進一步説明了為什麼我如此喜歡戴爾的 XPS 系列。它們是目前最好的 Linux 筆記本電腦。這款 XPS 13（7390），你值得擁有！
