23 款開源的聲音、視覺生產工具 ​

無論你是要進行音頻、圖形、視頻、動畫還是它們的任意組合，都有一個開源工具可以幫助你產生專業水平的結果。

“開源”在雲基礎設施、網站託管、嵌入式設備和其他領域已經建立的相當完善。很少數人知道開源在生產專業級的聲音視覺素材上也是一個不錯的選擇。

作為一名產品經理（有時候也是市場支持），我為終端用户提供很多內容：文檔、文章、視頻教學，甚至是展台物料、白皮書、採訪等等。我找到了很多可以幫我製作音頻、視頻、排版、截屏的開源軟件。人們選擇開源軟件而不是專有軟件的原因有很多，而我也為以下人羣編制了一份開源音視頻工具清單：

  • 想要入坑 GNU/Linux，但需要在原來的操作系統上慢慢從使用跨平台軟件開始
  • 熱愛開源，但對音視頻開源軟件所知甚少，不知道該如何選擇
  • 想要為創造力充電而探索新的工具，並且不想使用其他人使用過的方法工具
  • 存在某些其他的原因使用開源音視頻解決方案（如果是你，不妨在評論裏分享一下）

幸運的是，存在着很多開源的音視頻創作軟件，也存在着很多硬件來支持這些應用。本文清單裏的所有軟件都符合以下標準：

  • 跨平台
  • 開源（軟件和驅動）
  • 穩定
  • 積極維護
  • 良好的文檔與技術支持

我將清單中的解決方案劃分為圖形、音頻、視頻和動畫。注意，本文中提到的應用程序並不完全等同於一些有名的私有軟件，它們需要花時間來學習，並且可能需要改變你的工作流程，但是學習新的工具能夠讓體驗全新的創造方式。

圖形 ​

我製作過很多出版和網站使用的圖形，包括徽標、橫幅、視頻節目、草圖。這裏是一些我用過的開源應用，也包括一同使用的硬件。

軟件 ​

1、Inkscape（矢量圖）

Inkscape 是一款不錯的矢量圖編輯器，用來製作 RGB 顏色空間下的 SVG 和 PDF 文件。（它可以製作 CMYK 圖像，但不是主要用途）它是為 web 應用製作 SVG 格式的地圖和圖表的人的救命稻草。你不僅可以使用集成的 XML 編輯器打開文件，也可以用它查看對象的所有參數。但有一個缺點：它在 Mac 上的優化不是很好。有很多樣例，可以看Inkscape 畫廊。

2、GIMP（圖片編輯器）

GIMP 是我最喜歡的圖片編輯程序，它包括了色彩調整、裁剪和拉伸，並且（尤其是）對於網頁使用的文件大小進行了優化（很多使用 Photoshop 的同事讓我幫他們做這最後一步）。你也可以從頭製作並繪製一張圖片，但 GIMP 並不是我最喜歡用來做這件事的工具。在 GIMP Artists on DevianArt 上查看眾多的樣例。

3、Krita（數字繪畫）

當你桌子上擺着一個漂亮的 Wacom 數位板，你肯定想試試真正的數字繪畫應用。Krita 就是你創作漂亮插畫所需要的工具。在 Krita 畫廊 裏看看我説的東西吧。

4、Scribus（桌面印刷系統）

你可以使用 Scribus 來創建一個完整的文檔，或者只是把用 Inkscape 或 Libre Office 製作的 PDF 從 RGB 轉換到 CMYK。有一個功能我非常喜歡：你可以試着模擬視覺障礙人士使用 Scribus 時的體驗。當我發送 PDF 文件給商業印刷公司時全指望 Scribus。儘管出版社可能使用像 InDesign 這樣的私有軟件創建文檔，但如果你用 Scribus 正確的完成一份文檔，那麼打印時就不會出現任何問題。免費建議：第一次發送文件給印刷公司時，不要告訴印刷公司創建該文檔所使用的軟件。你可以在 Scribus 教程中尋找創建文檔的例子。

5、RawTherapee（RAW 圖像開發工具）

RawTherapee 是我所知道唯一跨平台可替代 Lightroom 的軟件。你可以將相機調整到 RAW 模式，然後使用 RawTherapee 來修圖。它提供了非常強大的引擎和對圖片沒有破壞的編輯器。例如，可以見 Raw Therapee 截圖。

6、LibreOffice Draw（桌面印刷系統）

儘管你可能認為 LibraOffice Draw 不是一款專業的桌面印刷解決方案，但它仍然能夠在很多情況下幫助你。例如，製作其他人（儘管是那些不懂圖形軟件的人）以後可以修改的白皮書、圖表或海報。它不僅方便使用，而且當創建有趣的文檔時也是 Impress 或 PowerPoint 的絕佳替代軟件。

圖形硬件 ​

繪圖板

Wacom 數位板（和兼容設備）通常支持所有的操作系統。

顏色校正

顏色校正產品通常可用於所有操作系統，也包括了 GNU/Linux。Datacolor 生產的 Spyder 在所有平台上都有應用程序的支持。

掃描儀和打印機

圖形藝術家需要輸出（無論是打印還是電子版）的顏色是精確的。但是真正跨平台的設備，以及所有平台都易於安裝的驅動，並不像你想的那樣普遍。你的最佳選擇是兼容 TWAIN 的掃描儀和兼容 Postscript 的打印機。以我的經驗，Epson 和 Xerox 的專業級掃描儀和打印機更不容易出現驅動問題，並且它們通常也是開箱即用，擁有漂亮精確的顏色。

音頻 ​

有許多可供音樂家、視頻製作者、遊戲製作者、音樂出版商等等人羣選擇的開源音頻軟件。這裏有一些我曾經用來進行內容創作與聲音錄製時所使用的軟件。

軟件 ​

7、Ardour（數字音頻錄製）

對錄音與編輯來説，最專業級的工具選擇當然是唾手可得的 Ardour。聽起來很棒，它的混音部分非常的完整靈活，能夠提供給你喜歡的插件，並且易於回放、編輯、對比修改。我經常用它進行聲音錄製和視頻混音。要找出一些使用 Ardour 錄製好的音樂並不容易，因為音樂家們很少表明他們使用的軟件。然而，你可以查看它的截圖和一些特性來了解它的功能。

（如果你在尋求一種聲音製作方面的“模擬體驗”，你可以試試 Harrison Mixbus，它並不是一個開源項目，但是高度基於 Ardour，擁有模擬顯示的終端。我非常喜歡用它進行工作，我的客户也喜歡用它製作的聲音。Mixbus 也是跨平台的）

8、Audacity （聲音編輯）

Audacity 屬於“瑞士軍刀”級的聲音製作軟件。它並不完美，但你幾乎可以用它做所有的事情。加上非常易於使用，任何人都能在幾分鐘之內上手。像 Ardour 一樣，很難找到一份歸功於 Audacity 的作品，但你可以從這些截圖中瞭解如何使用它。

9、LMMS （音樂製作）

LMMS，設計作為 FL Studio 的替代品，也許使用並不那麼廣泛，但它非常完整並易於使用。你可以使用自己最喜歡的插件，使用“鋼琴鍵”編輯樂器，使用步定序器step sequencer播放鼓點，混合音軌...幾乎能做任何事情。在我沒有時間為音樂家錄音的時候我就使用它為視頻創建聲音片段。查看最好的 LMMS 榜單來看看一些例子。

10、Mixxx （DJ，音樂混音）

如果你需要強大的混音和播放 DJ 軟件，Mixxx 就可以滿足你的需求。它與大多數 MIDI 控制器、唱片、專用聲卡所兼容。你可以用它管理音樂庫、添加音效，做一些有趣的事情。查看它的功能來了解它是如何工作的。

音頻接口硬件 ​

儘管你可以使用任何一個計算機的聲卡錄製音頻，但要錄製的很好，就需要一個音頻接口——一個錄製高質量音頻輸入的專用的外部聲卡。對於跨平台兼容性來説，大多數“兼容 USB”和“兼容 iOS”的音頻接口設備應該都能錄製 MIDI 或其他音頻。下面是一些我用過的一些有名氣的跨平台設備。

Behringer U-PHORIA UMC22

UMC22 是你可以考慮的最便宜的選擇。但它的前置放大器噪音太大，音腔box質量也比較低。

Presonus AudioBox USB

AudioBox USB 是第一個兼容 USB（因此也跨平台）的錄音系統。它非常的耐用，經常在二手市場也能見到。

Focusrite Scarlett

Scarlett 在我看來是目前最高質量的跨平台聲卡。不同種類的設備可以涵蓋 2-18 個輸入/輸出端口。你可以在二手市場找到它的最初版本，而最新的第二代具有更好的前置放大器與規格。2i2 型號是我經常使用的那一款。

Arturia AudioFuse

AudioFuse 幾乎可以讓你接入任何設備，從麥克風到黑膠唱片機再到各種數字輸入設備。它具有優質的聲音與良好的設計，也是我目前用的最多的一款設備。它是跨平台的，但目前配置軟件還不能在 GUN/Linux 上使用。即使我把它從 Windows 電腦上斷開，它仍然保留着我的配置。但是講真，Arturia，勞煩認真考慮做一個 Linux 的軟件。

MIDI 控制器 ​

MIDI 控制器是一種樂器——例如電子琴、鼓墊等等。可以讓你控制音樂軟件或者硬件。現有的大多數 USB MIDI 控制器都跨平台併兼容主流的錄音編輯軟件。基於網頁的教程可以幫你對不同的軟件進行配置。儘管找到有關在 GNU/Linux 上配置的信息可能比較困難，但它們仍然是可以使用的。我用過許多 Akai 和 M-Audio 設備，沒有任何問題。在買樂器之前最好先試一下，至少去聽一下它們的音質或體驗一下按鍵觸感。

音頻編解碼器 ​

音頻編解碼器壓縮或解壓數字音頻，用盡可能小的文件大小獲得最佳質量的聲音。幸運的是，用於收聽或流媒體播放的編解碼器恰好是開源的：FLAC。Ogg Vorbis 是另一個值得了解的開源音頻編解碼器；在相同的比特率下比 MP3 好的多。如果你需要輸出不同的音頻格式，我建議通常存檔最好質量的音頻，然後再壓縮成特定的版本。

視頻 ​

視頻對於品牌的傳播是影響巨大的。即使你不是一個視頻專家，學習一些基礎的東西也是非常明智的。

軟件 ​

11、VLC （視頻播放器與轉換器）

最初是為流媒體而開發的，VLC 現在因能夠在所有設備上讀取所有的視頻格式被人們熟知。它非常的實用，例如，你可以使用它將視頻轉換成其他編解碼格式或容器，也可以用來恢復破損的視頻。

12、OpenShot （視頻編輯）

OpenShot 是一個簡單的軟件，但它卻可以製作出很好的效果，尤其是在短視頻上。（在編輯或改善音質方面有一定的限制，但它也能夠完成）我非常喜歡它的移動、拉伸、裁剪工具；用它創建視頻的開頭或結尾，導出之後使用更復雜的編輯器進行編輯，非常的完美。你可以在 OpenShot 的網站上看這些例子（並獲取更多信息）。

13、Shotcut （視頻編輯）

我認為 Shotcut 是比 OpenShot 更完整一些的工具——它在你的操作系統上比起其他較為基礎的編輯器更具有競爭力，並且它支持 4K 分辨率，具有專業的解碼器。嘗試一下，我相信你會愛上它的。你可以在這些視頻教程裏看一些範例。

14、Blender Velvets （視頻編輯、合成、特效）

儘管這一章節不是本文的學習重點，但 Blender Velvets 是你能找到的最強大的解決方案之一。它是由一些視頻創作者所製作的一系列擴展工具和腳本的合集，是通過 Blender 3D 製作軟件轉換成的 2D 視頻編輯器。儘管它的複雜度意味着不是我的首選視頻編輯器，但你仍可以在 YouTube 和其他網站上找到它的教程，並且一旦你學習了它，你就能通過它做任何事情。觀看這個視頻教程來了解它的功能與運作方式。

15、Natron（合成）

我不使用 Natron，但我聽説它廣受好評。它是 Adobe After Effects 的替代品，但運作方式並不同。想了解更多可以觀看一些視頻教程，比如這些 Natron 的 YouTube 頻道。

16、OBS （實時編輯、錄製、流媒體）

Open Broadcaster Software（OBS）是一個領先的在 YouTube 或 Twitch 上進行現場錄製或現場直播電子競技、電視遊戲的解決方案。我經常使用它記錄用户的屏幕、會議和聚會。要獲取更多信息，查看我曾經在 Opensource.com 上寫的關於錄製現場彙報的教程，第一部分：選擇你的設備和第二部分：軟件安裝。

視頻硬件 ​

結論先行：你需要一個強大的工作站以及快速的硬盤和更新的軟件和驅動。

圖形處理單元（GPU）

一部分包含在清單裏的軟件比如 Blender 和 Shotcut 使用 OpenGL 和硬件加速，這些都高度依賴 GPU。我建議你使用可以負擔起的最強大的 GPU。我所使用過的 AMD 和 Nvidia 都有着良好的體驗，這取決於使用的平台。不要忘記安裝最新的驅動。

硬盤

大體上來説，越快越大的硬盤，對視頻越好。不要忘記在軟件裏配置好正確的路徑。

視頻錄製硬件

  • Blackmagic Design: Blackmagic 提供了非常好的、專業級的視頻錄製和回放硬件。驅動支持 Mac、Windows 和 GNU/Linux（但不是所有的發行版）
  • Epiphan: 在 Epiphan 的專業級 USB 視頻錄製設備中有一款新型產品，它適用於 HDMI 和高分辨率的屏幕。然而，你也可以在二手市場找到舊的 VGA 設備，因為他們還在繼續為 GNU/Linux 和 Windows 上提供專用的驅動程序。

視頻編解碼 ​

不幸的是，使用開源的編解碼器仍然很困難。例如，許多相機使用專有的編解碼器錄製 H.264 的視頻和 AC3 的音頻，組成稱為 AVCHD 的格式。因此，我們必須務實，儘可能利用現有資源。

好消息是內容產業正在步向開源的編解碼器來避免一些費用，並使用開源標準。對於出版和流媒體，谷歌的 WebM 便是一款優秀的開源編解碼器，並且大多數視頻編輯器可以導入這種格式。同樣地， GoPro的超高分辨率和 360° 視頻編解碼器 Cineform 現在也進行了開源。希望更多的設備和供應商將會在不久之後使用它。

2D 和 3D 動畫 ​

動畫不是我的專業領域，因此我問了從事於動畫內容生產的朋友一些建議並加入到清單中，他的工作包含兒童電影和連續劇。

軟件 ​

17、Blender （3D 模型和渲染）

Blender 是頂級的開源跨平台 3D 建模和渲染軟件。你可以直接在 Blender 中完成整個項目的工作，或者使用它為電影或視頻創建 3D 效果。你能夠在網上找到許多視頻教程，因此即使它不是一個簡單的軟件，但也非常容易上手。Blender 是一個非常活躍的項目，經常還會製作一些微電影來展示他們的技術。你可以在 Blender Open Movies 上觀看。

18、Synfig Studio （2D 動畫）

第一次用 Synfig 時，它讓我想起了那個不錯的 Macromedia 老式 Flash 編輯器。在那之後，它已經發展成一個全功能的 2D 動畫工作室。你可以使用它製作宣傳故事、商業廣告、演示、開場或結尾動畫以及視頻中的轉場，或者甚至用它製作全動畫的電影。見 Synfig 作品集。

19、TupiTube （定格 2D 動畫）

使用 TupiTube 是一個學習基本 2D 動畫的極好方法。你可以將一系列繪畫或其他圖片轉換成一個視頻或者創建一個 GIF 循環動畫。它是一個相當簡單的軟件，但非常完整。查看 TupiTude 的 YouTube 頻道獲取一些教程和範例。

硬件 ​

動畫製作使用與圖形設計相同的硬件，因此查看第一小結中的硬件清單獲取一些建議。

有一點需要注意：你要用一個強大的 GPU 來進行 3D 建模和渲染。選擇可能有些限制，因為這取決於你使用的平台或電腦製造商，但是不要忘記安裝最新的驅動。謹慎選擇你的顯卡：它們非常昂貴，並且在大型的 3D 項目中至關重要，尤其是在渲染步驟中。

Linux 上的選擇 ​

如果你是 GUN/Linux 用户，那麼我為你提供了更多不錯的選擇。它們並不是完全跨平台的，但部分擁有 Windows 版本，還有一些可以在 Mac 上使用 Macports 安裝。

20、Kdenlive （視頻編輯）

伴隨着最新版本的發佈（幾個月之前），Kdenlive 成為了我最喜歡的視頻編輯器，尤其是當我在 Linux 機器上處理一些長視頻的時候。如果你經常使用流行的非線性視頻編輯器，Kdenlive（全稱是 KDE 非線性視頻編輯器KDE Non-Linear Video Editor）對你來説將非常簡單。它擁有很棒的視頻和音頻特效，強大的細節處理能力。並且在 BSD 和 MacOS（儘管它對準的是 GNU/Linux）都能使用，還有望移植到 Windows 上。

21、Darktable （RAW 圖像開發）

Darktable 是一款由攝影師製作的非常完整的 DxO PhotoLab 替代品。一些研究型項目使用它當做開發平台並測試一些圖像處理算法。它是一個非常活躍的項目，我已經等不及的見到它的跨平台版本了。

22、MyPaint （digital painting數字繪畫）

MyPaint 就像數字繪畫領域的 light table（LCTT 譯註：集成開發環境）。它在 Wacom 設備上表現良好，並且它的筆刷引擎尤其值得讚賞，因此 GIMP 開發人員正在密切的關注它。

23、Shutter （桌面截圖）

當我寫這篇教程的時候，我使用了許多截圖來進行展示。我最喜歡的 GNU/Linux 截圖工具就是 Shutter。事實上，我都找不到在 Windows 或 Mac 上能與之抗衡的一些功能。有一點小遺憾：我很期待 Shutter 在將來能夠增加新的功能來創建幾秒動態的 GIF 截圖。

我希望這些足以説服你開源軟件是一種非常卓越且可行的音視頻內容生產解決方案。如果你正在使用其他開源軟件，或者對於使用跨平台軟件和硬件進行音視頻項目有好的建議，請在評論中分享你的觀點。
