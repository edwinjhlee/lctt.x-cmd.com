如何為 Linux 桌面配置 Openbox ​

本文是 24 天 Linux 桌面特別系列的一部分。Openbox 窗口管理器佔用很小的系統資源、易於配置、使用愉快。

你可能不知道你使用過 Openbox 桌面：儘管 Openbox 本身是一個出色的窗口管理器，但它還是 LXDE 和 LXQT 等桌面環境的窗口管理器“引擎”，它甚至可以管理 KDE 和 GNOME。除了作為多個桌面的基礎之外，Openbox 可以説是最簡單的窗口管理器之一，可以為那些不想學習那麼多配置選項的人配置。通過使用基於菜單的 obconf 的配置應用，可以像在 GNOME 或 KDE 這樣的完整桌面中一樣輕鬆地設置所有常用首選項。

安裝 Openbox ​

你可能會在 Linux 發行版的軟件倉庫中找到 Openbox，也可以在 Openbox.org 中找到它。如果你已經在運行其他桌面，那麼可以安全地在同一系統上安裝 Openbox，因為 Openbox 除了幾個配置面板之外，不包括任何捆綁的應用。

安裝後，退出當前桌面會話，以便你可以登錄 Openbox 桌面。默認情況下，會話管理器（KDM、GDM、LightDM 或 XDM，這取決於你的設置）將繼續登錄到以前的桌面，因此你必須在登錄之前覆蓋該選擇。

配置 Openbox 桌面 ​

默認情況下，Openbox 包含 obconf 應用，你可以使用它來選擇和安裝主題、修改鼠標行為、設置桌面首選項等。你可能會在倉庫中發現其他配置應用，如 obmenu，用於配置窗口管理器的其他部分。

構建你自己的桌面環境相對容易。它有一些所有常見的桌面組件，例如系統托盤 stalonetray、任務欄 Tint2 或 Xfce4-panel 等幾乎你能想到的。任意組合應用，直到擁有夢想的開源桌面為止。

為何使用 Openbox ​

Openbox 佔用的系統資源很小、易於配置、使用起來很愉悦。它基本不會讓你感覺到阻礙，會是一個容易熟悉的系統。你永遠不會知道你面前的桌面環境秘密使用了 Openbox 作為窗口管理器（知道如何自定義它會不會很高興？）。如果開源吸引你，那麼試試看 Openbox。
