應用推薦：來自 KDE 的 Falkon 開源 Web 瀏覽器 ​

Falkon 是基於 QtWebEngine 的 Web 瀏覽器，它以前稱為 Qupzilla。在本週的“應用推薦”中，我們來看看這個開源軟件。

Falkon：適用於 Linux（和 Windows）的開源 Web 瀏覽器 ​

首先，Falkon 並不是一款新的 Web 瀏覽器。它自 2010 年以來一直在開發中，但被稱為 Qupzilla。2017 年，QupZilla 移到 KDE 旗下，並更名為 Falkon。處於 KDE 旗下意味着項目會按照 KDE 標準積極維護。

它使用 QtWebEngine 渲染引擎，這是 Chromium 核心的簡化版本。

在本文中，我將仔細研究它提供的功能以及與 Linux 上其他主流 Web 瀏覽器的不同之處。

Falkon 瀏覽器的功能 ​

我認為它可能不是流行的瀏覽器，但我發現它足以瀏覽現代 Web 服務。讓我重點介紹 Falkon 的主要功能，如果你覺得它很有趣，請嘗試一下。

簡單的用户界面 ​

我知道這不完全是一項“功能”，但是用户體驗（UX）至關重要。儘管是輕量級的瀏覽器，但你會擁有一個不錯的界面。你不會覺得使用的是一款源自 2000 年早期的瀏覽器。

AdBlock 擴展 ​

它附帶了 AdBlock 擴展程序，如果你想在瀏覽網站時擺脱廣告，它的效果很好。你還可以自定義 AdBlock 擴展的行為。

DuckDuckGo 作為默認搜索引擎 ​

如果你不喜歡使用 Google，那麼這是一件好事，它將這個主打隱私的搜索引擎設為默認搜索引擎。

會話管理器 ​

Falkon 在瀏覽器菜單的可用選項中包含了一個有用的會話管理器。你可以用它還原特定的近期會話，這應該能派上用場。

擴展支持 ​

它確實支持添加擴展，但你不能從 Chrome/Firefox 插件市場添加擴展。你只能選擇有限的一組擴展。

主題支持 ​

Falkon 還允許你在某種程度上自定義外觀。如果要更改瀏覽器的外觀，可以嘗試一下。

其他基本設置 ​

我還嘗試了其他設置/功能，例如添加書籤或管理密碼。或者，管理網頁的通知。我還試了 YouTube，沒有任何問題。

當然，這不是一個詳盡的評測。但是，Falkon 確實擁有瀏覽器中需要的所有基本功能（除非你有特定要求）。

安裝 Falkon 瀏覽器 ​

你可以在軟件中心輕鬆找到 Falkon 瀏覽器。如果沒有，你可以從它的官方下載頁面中找到 Flatpak/Snap 包。你還可以在下載頁面上找到 Windows 的安裝程序。

Download Falkon Browser

總結 ​

作為 KDE 產品，Falkon 是為 KDE 桌面環境量身定製的。一些 KDE 發行版（例如 OpenMandriva）使用 Falkon 作為默認的 Web 瀏覽器。

Falkon 瀏覽器適合那些正在尋求輕巧且功能豐富的 Web 瀏覽器的人。值得嘗試的另一個替代是 Midori。

我認為，除非你需要大量的擴展、跨平台同步並且需要訪問某些特定於瀏覽器的網站，不然它是一個很好的替代瀏覽器。
