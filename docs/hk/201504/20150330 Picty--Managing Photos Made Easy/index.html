Picty:讓圖片管理變簡單 ​

關於Picty ​

Picty是個免費，簡單，卻強大的照片收藏管理器，它可以幫助你管理你的照片。它是圍繞着元數據管理和圖像無損處理設計的。Picty目前同時支持在線（基於網頁的）和離線（本地的）收藏集。在本地的收藏集中，圖片將被保存在一個本地的文件夾及其子文件夾中。為了加快用户主目錄裏圖片的查詢速度，它會維持一個數據庫。在在線（基於網頁的）收藏集中，你可以通過網頁瀏覽器上傳並分享圖片。擁有適當權限的個人用户可以把圖片分享給任何人，而且用户可以同時打開多個收藏集，收藏集也可以分享給多個用户。有個簡單的界面可以通過傳輸插件在收藏集之間傳輸圖片。

你可以從你的相機或任何設備中下載任何數量的照片。除此之外，Picty允許你在下載前瀏覽在你相機裏的圖片集。Picty是個輕量級的應用，界面清爽。它支持Linux和Windows平台。

功能 ​

  • 支持大相片集（20000張以上）。
  • 同時打開多個收藏集，還可以在它們之間傳照片。
  • 收藏集包括：
    • 本地文件系統中保存圖片的文件夾。
    • 相機、電話及其他媒體設備中的圖片。
    • 圖片保存服務（目前支持Flickr）
  • Picty不是把相片“導入”到它的資料庫中，它僅僅提供了一個界面來訪問它們，不管它們保存在哪。為了保持迅速的反應以及能使你在離線時瀏覽圖片的能力，Picty會保存縮略圖和元數據的緩存。
  • 以業界標準格式Exif、IPTC和Xmp讀寫元數據。
  • 無損的方法：
    • Picty把所有改變包括圖像編輯以元數據的方式寫入。例如，一個圖片可以以任何方式剪切保存，原來的圖像仍然保存在該文件裏。
    • 修改會保存在Picty的收藏集緩存中直到你把你對元數據的修改保存到圖片中，所以你能很容易撤銷你不喜歡的未保存的修改。
  • 基本圖片編輯功能：
    • 目前支持基本的圖像增強，如亮度、對比度、色彩、剪切以及矯正。
    • 將要推出一些工具改進及更多工具。（紅眼消除、拉伸、彎曲、噪聲消除）
  • 圖片標籤：
    • 使用標準的IPTC和Xmp關鍵詞為圖片做標籤。
    • 一個樹狀標籤圖讓你能很容易的管理標籤和在收藏集內導航。
  • 文件夾視圖：
    • 按照目錄的結構對你的圖片收藏集進行導航
  • 支持多屏顯示
    • Picty可以設置成讓你在一個屏幕上瀏覽你的收藏集同時在另一個屏幕上全屏顯示圖片。
  • 可個性化
    • 可以為外部工具創建快捷方式
    • 支持插件——目前提供的功能中有許多（標籤和文件夾視圖以及所有的圖片編輯工具）都可以通過插件提供。
    • 使用Python編寫——內置電池(batteries included)！

安裝方法 ​

1、從PPA安裝 ​

Picty開發人員為Ubuntu這樣的基於 Debian的發行版創建了一個PPA，讓安裝更簡單。

要在Ubuntu和它的衍生版上安裝，請運行以下命令：

sudo add-apt-repository ppa:damien-moore/ppa
sudo apt-get update
sudo apt-get install picty

2、從源文件安裝 ​

此外，你還可以從源文件安裝。首先安裝如下依賴項。

sudo apt-get install bzr python-pyinotify python-pyexiv2 python-gtk2 python-gnome2 dcraw python-osmgpsmap python-flickrapi

然後，使用下面這個命令得到最新版本：

bzr branch lp:picty

要運行Picty，先轉到Picty所在的目錄，然後輸入：

cd picty
bin/picty

要想更新到最新版，請運行：

cd picty
bzr pull

使用方法 ​

可以從目錄或Unity Dash啓動Picty。

你可以選擇已存在的收藏集、設備或目錄。這裏讓我們創建一個新收藏集 ，請先點擊新收藏集（New Collection）按鈕。進入收藏集，然後瀏覽到你保存圖片的地方。最後，點擊創建（Create）按鈕。

你可以對每張圖片進行修改，旋轉，添加/移除標籤，設置描述。只需右擊任何一個圖片然後愛做什麼做什麼。

訪問下面這個Google組可以得到更多關於Picty相片管理器的信息和支持。

  • http://groups.google.com/group/pictyphotomanager

乾杯！
