Debian 8 "Jessie" 發佈 ​

2015年4月25日 ，在經歷了近24個月的持續開發之後，Debian 項目自豪地宣佈最新的穩定版本8的發佈（代號 “Jessie” ），歸功於Debian安全團隊和Debian長期支持團隊的工作，該版本將在接下來的5年內獲得支持。

“Jessie” 與新的默認 init 系統 systemd 一同到來。systemd 套件提供了許多激動人心的特性，如更快的啓動速度、系統服務的 cgroups 支持、以及獨立出部分服務的可能性。不過，sysvinit init系統在 “Jessie” 中依然可用。

在 “Wheezy” 中引入的 UEFI 支持（“Unified Extensible Firmware Interface”，統一的可擴展固件接口）同樣在 “Jessie” 中得到了大幅改進。其中包含了許多已知固件 bug 的臨時性解決方案，支持32位系統上的UEFI，也支持64位內核運行在32位 UEFI 固件上（後者僅被包含在我們的 amd64/i386 “multi-arch” 安裝介質中）。

自上個版本發佈以來，Debian 項目的成員同樣對我們的支持服務做出了重要改進。其中之一是可瀏覽所有 Debian 的源碼，該服務目前放在 sources.debian.net。當然，在超過20000個源碼包裏想要找到正確的文件確實令人望而生畏。因此，我們同樣十分高興地上線 Debian 代碼搜索，它放在 codesearch.debian.net。這兩項服務都由一個完全重寫並且更加反應敏捷的包追蹤系統提供。

該版本包含大量的軟件包更新，如：

  • Apache 2.4.10
  • Asterisk 11.13.1
  • GIMP 2.8.14
  • 一個GNOME桌面環境 3.14 的升級版本
  • GCC 編譯器 4.9.2
  • Icedove 31.6.0 (一個 Mozilla Thunderbird 的再發布版本)
  • Iceweasel 31.6.0esr (一個 Mozilla Firefox 的再發布版本)
  • KDE Plasma Workspaces 和 KDE Applications 4.11.13
  • LibreOffice 4.3.3
  • Linux 3.16.7-ctk9
  • MariaDB 10.0.16 和 MySQL 5.5.42
  • Nagios 3.5.1
  • OpenJDK 7u75
  • Perl 5.20.2
  • PHP 5.6.7
  • PostgreSQL 9.4.1
  • Python 2.7.9 和 3.4.2
  • Samba 4.1.17
  • Tomcat 7.0.56 和 8.0.14
  • Xen Hypervisor 4.4.1
  • Xfce 4.10桌面環境
  • 超過43000個其它可供使用的軟件包，從將近20100個源碼包編譯而來

與如此之多的軟件包選擇和照例的廣泛架構支持，Debian 再次向它的目標：成為通用操作系統邁出正確的一步。Debian 適用於各種不同情形：從桌面系統到上網本；從開發服務器到集羣系統；以及資料庫，web，或存儲服務器。同時，在此基礎之上的質量保證工作，如對 Debian 上所有包的自動安裝和升級測試，讓 “Jessie” 可以滿足用户擁有一個穩定的 Debian 版本的高期望值。

總共支持十種架構：32位PC/Intel IA-32(i386)，64位PC/Intel EM64T / x86-64 (amd64)，Motorola/IBM PowerPC (舊硬件的powerpc和新的64位ppc64el(little-endian))，MIPS (mips 大端和 mipsel小端)，IBM S/390 (64位 s390x)以及 ARM 新老32位硬件的armel和armhf，加上給新64位 “AArch64” 架構的arm64。

想嘗試一下？ ​

如果你僅僅是想在不安裝的情況下體驗 Debian 8 “Jessie”，你可以使用一個特殊的鏡像，即 live 鏡像，可以用在 CD，U 盤以及網絡啓動設置上。最先只有 amd64 和 i386 架構提供這些鏡像。Live 鏡像同樣可以用來安裝 Debian。更多信息請訪問 Debian Live 主頁。

但是如果你想安裝 Debian 到你的計算機的話，有不少安裝媒介可供你選擇，如藍光碟，DVD，CD 以及 U 盤，或者從網絡安裝。有幾種桌面環境：GNOME，KDE Plasma 桌面及 Plasma 應用，Xfce 以及 LXDE，它們可以從CD鏡像中安裝，也可以從 CD/DVD 的啓動菜單裏選擇想要的桌面環境。另外，同樣提供了多架構 CD 和 DVD，可以從單一磁盤選擇安裝不同架構的系統。或者你還可以創建可啓動 U 盤安裝媒介（參看安裝指南獲得更多細節）。對雲用户，Debian 還提供了預構建 OpenStack 鏡像可供使用。

安裝鏡像現在同樣可以通過 bittorrent（推薦下載方式），jigdo 或 HTTP 下載，查看Debian 光盤獲得更進一步的信息。“Jessie” 不久將提供實體 DVD，CD-ROM，以及無數供應商的藍光碟。

升級 Debian ​

如果從前一個版本 Debian 7（代號 “Wheezy” ）升級到 Debian 8，大部分配置情況 apt-get 包管理工具都能夠自動解決。Debian 系統一如既往地能夠就地無痛升級，無需強制停機。強烈推薦閲讀發行註記和安裝指南來了解可能存在的問題，並瞭解安裝和升級建議。發行註記會在發佈後的幾周內進一步改進，並翻譯成其他語言。

關於 Debian ​

Debian 是一個自由操作系統，由成千上萬來自全世界的志願者通過互聯網協作開發。Debian 項目的關鍵力量是它的志願者基礎，它對 Debian 社羣契約和自由軟件的貢獻，以及對提供最好的操作系統可能的承諾。Debian 8是其前進方向上又一重要一步。

聯繫信息 ​

獲取更多信息，請訪問 Debian 主頁 https://www.debian.org/ 或發送電子郵件至press@debian.org。
