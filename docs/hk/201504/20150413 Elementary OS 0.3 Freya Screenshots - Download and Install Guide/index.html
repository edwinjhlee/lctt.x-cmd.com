直擊 Elementart OS 0.3 Freya - 下載和安裝指南 ​

Elementary OS是一個以Ubuntu為基礎的輕量級操作系統，廣受歡迎。目前已經發行了三個版本，而第四個版本將會以即將到來的Ubuntu16.04為基礎開發。

  • Jupiter (0.1): 第一個Elementary OS穩定發行版基於Ubuntu 10.10，在2011年三月發佈。
  • Luna (0.2): Elementary OS第二個穩定發行版基於Ubuntu 12.04，於2012年11月發佈。
  • Freya (0.3): Elementary OS第三個穩定發行版基於Ubuntu 14.04的，2015年二月8號發佈。
  • Loki (0.4): 未來Elementary OS第四版，計劃以Ubuntu16.04為基礎，並且提供更新服務直到2021年。

Freya是目前最新的Elementary OS版本（0.3）。最初是被命名為ISIS，但是後來改了，是為了避免與同名的恐怖組織產生任何的聯繫。Freya有一些非常不錯的預裝應用。

突出的特性 ​

這裏列舉了一些特性，但並非Elementary OS 0.3的所有特性。

  • 更好的交互性消息通知，可在通知設定面板設定系統級別的“Do Not Disturb（不要打擾）”模式。
  • 最新版Elementary OS提供更好的emoji表情支持，及內置替換了網頁應用中的微軟核心字體。
  • Privacy模式是一個新的防火牆工具，易於使用，可以幫助保護電腦免遭惡意腳本和應用的攻擊。
  • 統一風格的登入和鎖定界面。
  • 改進了界面效果和功能的應用中心菜單，包括快速操作列表，搜索拖放，支持快速數學計算。
  • 重新設計的多任務視圖提供更多以應用為中心的功能。
  • 更新了軟件棧（Linux 3.16， Gtk 3.14 和Vala 0.26），更好的支持和增強了最新開發的應用。
  • UEFI支持。
  • 通過新的聯網助手，WiFi連接變得更容易。

安裝Elementary OS 0.3 (Freya) ​

下載Elementary OS 0.3的ISO文件，並且寫入到一個USB啓動盤或者DVD/CD。支持32位和64位的架構。當計算機從Elementary OS ISO文件啓動後，有兩個選項可用，或不安裝而僅試用，或直接安裝到計算機裏。這裏選擇第二項。Elmentary OS也可以與已有操作系統並存安裝，構成雙重啓動。

在進行下面的步驟之前會檢查系統要求和資源有效性。如果你的系統有足夠的資源，點擊繼續。

安裝嚮導提供許多安裝形式。選取最適合你的選項，通常大多數都選用第一個選項：“擦除磁盤以安裝Elementary”。選擇該選項，必須保證你的原有數據都已經正確備份了，因為磁盤（分區）將會被擦除，其上所有的數據將會丟失。

接下來的對話框顯示了Elementary OS所使用和需要格式化的磁盤分區列表，確保數據完整後點擊繼續。

選擇你的地理位置，確定時區，點擊繼續。

選擇你的語言，點擊繼續。

填入你的信息，選擇一個高強度的超級用户/管理員密碼，點擊繼續。

當你的信息提供後，核心安裝進程就會啓動，正在安裝的組件的詳細信息會在一個小對話框裏隨進度條一閃而過。

恭喜你！最新的Elementary OS 0.3 (Freya)已經安裝完成了。此時需要重啓來更新和完整註冊，恭喜。

啓動時，Elementary OS將顯示它優雅的logo，然後會出現密碼保護的管理員登入和遊客訪問選項。遊客訪問有相當多的限制功能，而且沒有安裝軟件的權限。

下圖是新安裝的Elementary OS 0.3的畫面。

個性化桌面 ​

Elementary OS 0.3以其輕巧和美觀而為我們熟知，每個人有自己獨特的審美觀和計算機使用習慣。桌面反映出每一個計算機使用者的個人偏好。如其他操作系統一樣，Elementary OS 0.3也提供了許多選項來個性化配置桌面，包括壁紙，字體大小，主題等等。

基本的個性化配置，點擊Applications > System Settings > Desktop

我們可以改變壁紙，泊板（dock）和啓用桌面熱角。

默認提供了很少的壁紙，更多的可以從網上下載或者從你的相機傳輸過來。

Elementary OS真正的美麗在於優雅的泊板。桌面上沒有任何圖標，泊板上的應用圖標顯示逼真，通過它可以快速訪問常用應用。

用户可以定製桌面的四個角的功能。

通過安裝elementary tweaks工具來更深入的個性化定製。

可以使用如下命令，將穩定的個人軟件包檔案（PPA）添加到高級軟件包管理工具（APT）倉庫。

sudo add-apt-repository ppa:mpstark/elementary-tweaks-daily

一旦軟件包添加到倉庫後，我們需要用以下命令更新倉庫

sudo apt-get update

更新倉庫後，我們就可以安裝elementary-tweaks，用以下命令完成

sudo apt-get install elementary-tweaks

我們可以在Application > System Settings下的個人區域的看到增加了一個Tweaks項目。它現在可以給我們提供更多的個性化定製選項。

為了進一步定製，我們也安裝了gnome桌面系統的tweak工具，演示解鎖桌面。

sudo apt-get install gnome-tweak-tool

總結 ​

Elementary OS十分接近Linux發行版Ubuntu，它的優缺點兩方面也都十分相似。Elementary OS在外觀和體驗上都十分輕巧和優雅，並且正在快速地走向成熟。它有潛力成為Windows和OS X操作系統之外的第三選擇。最新的Elementary OS 0.3（Freya）以其良好的功能基礎而迅速流行。想了解更多信息，最近的更新和下載，請訪問其官方網站。
