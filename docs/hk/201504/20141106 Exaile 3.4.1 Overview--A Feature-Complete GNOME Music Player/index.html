Exaile 3.4.1 概覽：一個全功能的GNOME音樂播放器 ​

Exaile 在過去兩年顯得有些平靜，也許只有一個或者兩個穩定版發佈，但儘管如此，在功能方面，它是一個和Rhythmbox或者Banshee相匹敵的全功能GNOME音樂播放器。不過，在過去的兩個月，在"We’re not dead yet"的口號下，他們推出了一個新的穩定版3.4，同時在11月1日還推出了3.4.1增量版本。事實上，Exaile有很多的功能，我可以繼續寫很多的文章而不是在一篇文章裏全部介紹到，就讓我們來看一下一些最顯著的特點吧。

Exaile是基於GTK-2，用Python寫的音樂播放器，它能很好地兼容GNOME，有和舊的Amarok1.4或者Clementine非常類似的界面，以及一些很好的功能。界面主要由兩個面板組成，兩個都支持標籤。左邊的面板提供對音樂集，網絡音頻，智能和自定義播放列表，文件瀏覽，播客，組標籤以及歌詞的訪問，窗口的主要部分是播放列表(支持多個列表，以標籤方式組織的播放列表)和控制按鈕。

Exaile的界面和Clementine或者Amarok1.4非常相似，可以顯示或者隱藏左邊的標籤。

版本3.4增加了很多新的主要功能和更改，而3.4.1是一個小的bug修復版本。版本3.4的新功能包括類似Icecast的新插件，歌詞同步，播放列表分析器，Soma.fm，以及新的更簡單的插件API。用户界面和一般操作也作了修改，包括可以在多個面板顯示播放列表，關閉左邊的面板以及更好的BPM用户界面集成。

Exaile的功能幾乎不盡其數。你可以在音樂集中組織音樂，聽播客，對音樂進行評分，編輯標籤，查看文件屬性，排列歌曲，查看歌曲和封面，按照多種方式排序播放列表，更改播放行為和外觀風格。

首選項窗口允許配置Exaile的各個方面，包括啓用或者禁用插件，外觀，系統托盤集成或者播放模式。外觀設置允許你更改標籤的佈局，顯示或者隱藏便籤欄，啓用或者禁用透明性或者禁用啓動畫面。

系統托盤集成提供了一個快速播放或者暫停音樂，對音樂評分或者更改音樂列表播放模式(隨機，重複或者動態)的菜單。

我相信Exaile數不盡的功能使它成為音樂播放器的完美選擇，尤其是對於GNOME用户。每個用户都會對豐富多樣的選項和高度可配置的方式感到滿意。

在Ubuntu 14.04 和 14.10上安裝Exaile 3.4.1 ​

從源碼編譯並安裝和簡單明瞭。首先獲取依賴包：

sudo apt-get build-dep exaile
sudo apt-get install python-gst0.10

從下載頁面(或者直接點擊這裏)下載源碼包，然後解壓：

tar -xf exaile-3.4.1.tar.gz

更改工作目錄到exaile-3.4.1然後運行下面的命令：

make
sudo make install

二進制可執行文件將被安裝為 /usr/local/bin/exaile.
