在Linux上安裝使用‘Go for it！’備忘軟件 ​

你在 Linux 桌面是如何管理任務和備忘的？我喜歡用 Ubuntu 的粘帖便籤很久了。但是我要面對與其他設備同步的麻煩，特別是我的智能手機。這就是我為什麼選擇使用 Google Keep 的原因了。

Google Keep 是一款功能豐富的軟件，我十分喜愛，而且喜歡到把它叫做 Linux 的 Evernote 地步。但是並不是每個人都喜歡一款功能豐富的備忘錄軟件。極簡主義是目前的主流，很多人喜歡。如果你是極簡主義的追求者之一，而且正在尋找一款開源的備忘錄軟件，那麼你應該試一試 Go For It！。

Go For It！高效的Linux桌面軟件 ​

Go For It！是一款簡潔的備忘軟件，藉助定時提醒幫助你專注於工作。所以，當你添加一個任務到列表後，可以附上一個定時器。到設定時間後，它就會提醒你去做任務。你可以看看其帥哥開發者 Manuel Kehl 製作的視頻（youtube 視頻） ： https://www.youtube.com/watch?v=mnw556C9FZQ

安裝 Go For It！### ​

要在 Ubuntu 15.04,14.04 和其他基於 Ubuntu 的Linux 發行版，如Linux Mint， elementary OS Freya 等上面安裝 Go For It！請使用這款軟件官方的 PPA：

sudo add-apt-repository ppa:mank319/go-for-it
sudo apt-get update
sudo apt-get install go-for-it

你也可以下載 .deb 包，Windows 安裝包和源代碼，鏈接如下：

  • Download source code
  • Download .deb binaries
  • Download for Windows

在Linux桌面使用 Go For It！### ​

Go For It！使用真心方便。你只需添加任務到列表中，任務會自動存入 todo.txt 文件中。

每個任務默認定時25分鐘。

任務一旦完成，就會被自動存檔到 done.txt 文件中。根據設置，它會在規定的時間間隔或者任務過期前不久，發送桌面提醒：

你可以從配置裏面修改所有的偏好。

目前一切都看着挺好。但是在智能手機上使用體驗怎樣呢？如果你不能使它在不同設備間同步，那這款高效軟件就是不完整的。好消息是 Go For It！是基於 todo.txt 的，這意味着你可以用第三方軟件和像 Dropbox 一樣的雲服務來使用它。

在安卓手機和平板上使用Go For It！ ​

在這裏你需要做一些工作。首先的首先，在 Linux 和你的安卓手機上安裝 Dropbox，如果之前沒有安裝的話。下一步你要做的就是要配置 Go For It！和 修改 todo.txt 的目錄到 Dropbox 的路徑下。

然後，你得去下載 Simpletask Andriod app。這是免費的應用。安裝它。當你第一次運行 Simletask 的時候，你會被要求關聯你的賬號到 Dropbox：

一旦你完成了 Simpletask 與 Dropbox 的關聯，就可以打開應用了。如果你已經修改了 Go For It 的配置，將文件保存到Dropbox 上，你就應該可以在 Simpletask 裏看到。而如果你沒有看到，點擊應用底部的設置，選擇 Open Todo file 的選項：

現在，你應該可以看到 Simpletask 同步的任務了。

總結 ​

對於 Simpletask，你就可以以類似標記語言工具的風格使用它。對於小巧和專注而言，Go For It！是一款不錯的備忘軟件。一個乾淨的界面是額外的加分點。如果擁有它自己的手機應用就更好了，但是我們也有臨時替代方案了。

底層來講，Go For It! 不會運行在後台。這就是説，你不得不讓它一直保持運行。它甚至沒有一個最小化的按鈕，這有一點小小的煩擾。我想要看到的是有一個小的指示程序，運行在後台，並且快速進入主面板，這肯定會提升其可用性。

試試 Go For It！吧，分享一下你的使用體驗。在 Linux 桌面上,你還使用了哪些其他的備忘軟件？比起其他你最喜歡的同類應用，Go For It！怎麼樣？
