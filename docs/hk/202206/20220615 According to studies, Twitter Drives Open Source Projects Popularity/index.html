扫码关注官方微信公众号获取开源软件和 x-cmd 的最新用法与独家资讯

有研究表明，推特能夠推動開源項目的普及 ​

由 HongBo Fang 博士領導的研究團隊發現，推特是一種吸引更多人關注和貢獻 GitHub 開源項目的有效方式。Fang 博士在國際軟件工程會議上發表了這項名為“‘這真是太棒了！’估計推文對開源項目受歡迎程度和新貢獻者的影響”的研究，並獲得了傑出論文獎。這項研究顯示，發送和一個項目有關的推文，導致了該項目受歡迎程度增加了 7%（在 GitHub 上至少增加了一個星標），貢獻者數量增加了 2%。一個項目收到的推文越多，它收到的星標和貢獻者就越多。

Fang 説：“我們已經意識到社交媒體在開源社區中變得越來越重要，吸引關注和新的貢獻者將帶來更高質量和更好的軟件。”

大多數開源軟件都是由志願者創建和維護的。參與項目的人越多，結果就越好。開發者和其他人使用該軟件、報告問題並努力解決這些問題。然而，不受歡迎的項目有可能得不到應有的關注。這些勞動力（幾乎都是志願者），維護了數百萬人每天依賴的軟件。例如，幾乎每個 HTTPS 網站都使用開源的 OpenSSL 保護其內容。Heartbleed 是 OpenSSL 中發現的一個安全漏洞，在 2014 年被發現後，企業花費了數百萬美元來修復它。另一個開源軟件 cURL 允許連接的設備相互發送數據，並安裝在大約 10 億台設備上。開源軟件之多，不勝枚舉。

此次“推特對提高開源項目的受歡迎程度和吸引新貢獻者的影響”的研究，其實是 “Vasilescu 數據挖掘與社會技術研究實驗室”（STRUDEL）的一個更大項目的其中一部分，該研究着眼於如何建立開源社區並且其工作更具可持續性。畢竟，支撐現代技術的數字基礎設施、道路和橋樑都是開源軟件。如果維護不當，這些基礎設施可能會崩潰。

研究人員檢查了 44544 條推文，其中包含指向 2370 個開源 GitHub 存儲庫的鏈接，以證明這些推文確實吸引了新的星標和項目貢獻者。在這項研究中，研究人員使用了一種科學的方法：將推特上提及的 GitHub 項目的星標和貢獻者的增加，與推特上未提及的一組項目進行了比較。該研究還描述了高影響力推文的特徵、可能被帖子吸引到項目的人的類型，以及這些人與通過其他方式吸引的貢獻者有何不同。來自項目支持者而不是開發者的推文最能吸引注意力。請求針對特定任務或項目提供幫助的帖子會收到更高的回覆率。推文往往會吸引新的貢獻者，他們是 GitHub 的新手，但不是經驗不足的程序員。還有，新的關注可能不會帶來新的幫助。

提高項目受歡迎程度也存在其缺點，研究人員討論後認為，它的潛在缺點之一，就是注意力和行動之間的差距。更多的關注通常會導致更多的功能請求或問題報告，但不一定有更多的開發者來解決它們。社交媒體受歡迎程度的提高，可能會導致有更多的“巨魔”或“有毒行為”出現在項目周圍。
