GitHub Copilot 現已可供所有人使用，但並非所有人都喜歡它 ​

GitHub Copilot 來了，它能幫助程序員，為他們提供人工智能的編碼建議，不過，它是否會讓事情變得更糟呢？

在 2021 年，我曾花了好幾個小時來翻閲 GitHub Copilot 文檔，試圖弄清楚如何能夠加入它的技術預覽計劃。還好，這一切都得到了回報，我成功加入了預覽計劃。

而現在，它終於可供所有人使用啦！

如果你還不知道的話，GitHub Copilot 是一個 AI 助手，可幫助你更快、更高效地編寫代碼。

我能想到的最類似的東西，就是你手機上的（輸入法的）自動完成功能。不過，與自動完成功能不同，GitHub Copilot 編寫代碼，就相當於是在完成整段的句子。

Copilot 現已可供大眾使用 ​

正如我在前面提到的，Copilot 已經處於技術預覽階段將近一年了。這意味着，GitHub 只允許非常有限數量的開發者免費使用它，以換取同意 GitHub 監控他們的使用情況，從而改進程序的最終版本。

看起來 GitHub 終於滿意地向公眾發佈了它。現在，任何擁有 GitHub 帳户的人都應該能夠使用它，儘管需要付出一定的代價（我很快就會在下面提到）。

公告 中提到：

直到不久前，人工智能都沒有能夠幫助改進代碼，開發軟件的過程幾乎完全是手動的。現在，這種情況正在改變。今天，我很高興地宣佈，我們正在向所有個人開發者提供 GitHub Copilot。你的 AI 配對程序員來啦。

—— Thomas Dohmke，GitHub CEO

Copilot 作為免費的編輯器擴展，已經幫助數百萬開發者加快了他們的編程速度。然而，它確實是有代價的，無論是直接的還是間接的。

GitHub Copilot 定價 ​

與幾乎所有令人興奮的新技術一樣，Copilot 對某些人來説可能過於昂貴。它將花費你 10 美元/月或 100 美元/年。

如果你是開源項目維護者或經過驗證的學生，那麼你可以免費使用它。

GitHub Copilot 不道德嗎？ ​

圍繞 GitHub Copilot 產品的爭議巨大且令人擔憂。從技術上講，這個人工智能是使用大家託管在 GitHub 上的代碼來進行訓練的。

因此，基本上，GitHub 是通過使用你的代碼來提供一個新產品（如果你願意的話，還可以加點料）。而且，關於 Copilot，可別忘了，自由軟件基金會（FSF）也 建議 不要在 GitHub 上託管代碼。

我們知道，企業總是喜歡利用事物，但有些人認為這應該不會直接損害託管在 GitHub 上的項目/代碼。

但是，是這樣嗎？

簡而言之，在 Copilot 發佈後，許多開發者都分享説，他們發現 GitHub Copilot 生成了受版權保護的代碼：

我試了下 GitHub Copilot，這是一項付費服務​​，來看看它是否會使用帶有限制性許可證的存儲庫的代碼。我檢查了它，看看它是否有我在之前僱主那裏編寫的代碼，該代碼有一個許可證，只允許其用於免費遊戲，並且需要附加許可證。是的，它確實有。

當然，如果我們查看 GitHub Copilot 的常見問題解答（FAQ），其中提到：

GitHub 不擁有 GitHub Copilot 生成的建議。您在 GitHub Copilot 的幫助下編寫的代碼屬於您自己，由您自己負責。

所以説，你為一項服務付了費，最終卻為你的項目增加了不便和更多的工作？

在我看來，就簡化開發者的任務而言，這聽起來一點兒也不令人興奮。
