隱藏功能！在 DuckDuckGo 搜索引擎中，你可以做這 25 件有趣的事情 ​

比起無處不在的 Google，有些搜索引擎替代品更加尊重隱私，而 DuckDuckGo 就是其中之一。

最近，這個搜索引擎有了很大的改進，搜索一般網頁十分順暢。在搜索本地地點方面，則還遠不及 Google。

不過，DuckDuckGo（簡稱為 DDG）有一些很酷的功能，大部分用户還沒注意到。如果你是一位 DDG 狂熱粉，你可能會喜歡用這些小技巧來提升你的搜索體驗。

1、跳轉到特定網頁 ​

在你最喜歡的網站名稱前輸入 ! 即可直接進入這個網站。則類似於 Google 的 “運氣不錯” 功能，但用 DDG 的話來説，這就叫 “歎號搜索”。

有一些網站有縮寫形式，開始輸入時便會提示。

在網站名後面輸入搜索詞，就可以直接抵達那個網站的搜索結果處。

2、文本轉 ASCII ​

Figlet 是一個 有趣的 Linux 命令，可以將任意文本轉換為漂亮的 ASCII 畫格式。

在任意搜索詞前輸入 figlet，就會顯示 ASCII 輸出。無需打開終端。

3、檢查社交媒體的狀態 ​

在某個人的 Twitter 名前加上 @，就會顯示 TA 的狀態（關注者等）。

4、生成強密碼 ​

輸入 password 並加上需要的字符數，就可以生成一個獨特的強密碼。

5、生成隨機密碼短語 ​

輸入 random passphrase 可生成一段密碼短語，通常長度為 4 個詞。

6、獲取一份速查表 ​

在需要看速查表的搜索詞後面，可輸入 cheatsheet。如果要搜索的東西有速查表，就會立即顯示在搜索頁面。

7、通過色碼獲取顏色 ​

輸入 color 並加上你想查的顏色的十六進制碼，便可顯示這個顏色。

8、生成隨機數 ​

搜索 random number 會輸出一個 0 到 1 之間的隨機數。

你也可以指定需要的範圍。

9、轉換為二進制等形式 ​

輸入一個二進制數並加上 binary，可將其從二進制轉換為十進制。

類似地，它也能用於十六進制和八進制，但我不清楚它們的處理邏輯。

10、尋找韻詞 ​

輸入 what rhymes with 並帶上要找同韻詞的詞語。作詩能力變強了，對吧？

11、獲取拉馬努金數、圓周率等常數 ​

輸入想獲取數值的常數名，便可在搜索結果中看到它。

12、查詢現在誰在太空中 ​

輸入 people in space 獲取當前在太空中的人員名單。同時還會顯示他們在太空中居住的時間。

13、查詢網頁是否無法訪問 ​

如果你想知道某個網站是你無法訪問了，還是大家都無法訪問了，只需在搜索詞中輸入 is xyz.com down。

14、獲取特定話題的名言 ​

輸入一個詞並帶上 quotes，就會顯示與這個詞相關的名言。

15、獲取佔位文本 ​

搜索 lorem ipsum 就可以獲取 5 段佔位文本。對 Web 開發者應該會有用。

16、獲取任意月份的日曆 ​

在年、月、日後面輸入 calendar，就會為你顯示該月份的交互式日曆。

17、生成二維碼 ​

在文字、鏈接等後面輸入 qr，就會生成對應的二維碼。

18、獲取一些 CSS 動畫 ​

搜索 css animations 以獲取一些 CSS 動畫例子。

19、展開短鏈接 ​

如果有一個 Bitly 鏈接或其他短鏈接，但不確定它指向哪裏，不必再跳轉到充滿垃圾信息的網頁了，只需展開短鏈接，看看真正的網址。

在短鏈接後面輸入關鍵詞 expand，就會顯示真正的目標 URL。

20、獲取特殊字符的 HTML 代碼 ​

搜索 html chars，可以獲取一份很長的列表，上面有 HTML 實體及其描述，按下後會在結果中顯示更多信息。

21、我用這東西幹啥？ ​

這功能沒什麼用。如果你輸入 why should I use this? ，它就會在搜索結果頂部顯示 cause it's awesome。顯然，DuckDuckGo 在説他自己。

22、轉換大小寫 ​

大小寫都可轉換。lowercase <大寫搜索詞> 就會顯示小寫的結果

uppercase <小寫搜索詞> 就會顯示大寫的結果。

23、編碼 URL ​

搜索 encode 並加上 URL，就會給出編碼後的結果

24、Motherboard ​

搜索 Motherboard 就會看見左側的 DuckDuckGo 的 logo 變了。它會顯示選好的幾個隨機 logo。

25、獲取 HTML 色碼 ​

搜索 color codes 便可獲得一份顏色表。一樣，這個功能多為 Web 開發者和設計師所用。

還有很多別的··· ​

我的夥伴 Sreenath 想到本貼的主意。他説 DuckDuckGo 中還有許多 “彩蛋”，我覺得沒錯。但全部列出來有諸多不便。

如果你知道更多這樣有趣的 DDG 搜索功能，請在評論中分享。如果你又發現了你喜歡的搜索功能，也提出來吧。
