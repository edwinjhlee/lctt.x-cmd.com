移動版 GNOME Shell：希望之始，期望滿滿 ​

GNOME 開發人員在最近的一篇博文中提出了將 GNOME Shell 完全移植到手機上的想法。下面是我對這個項目的一些看法。

移動版 GNOME Shell ​

作為一個桌面環境，GNOME 在過去的十年中發展成為了 GNOME 40。GNOME 40 是一個重要的版本，它以一種現代的方式改變了完整的用户界面設計。

看着 GNOME 40 的設計方式，你可能會覺得 Shell 和它的底層技術已經為小屏幕做好了準備。手勢驅動的工作區、圖標網格和停靠區 —— 在某種程度上感覺更接近於像安卓這樣的移動操作系統，而不是桌面環境。

此外，系統托盤、日曆、通知和原生的應用程序，可以有效地在較小尺寸的設備上工作。得益於 GTK4 和 libadwaita，其設計是響應式的，應用程序和控件的外觀與移動平台很匹配。

在 GNOME 40 之後，GNOME 開發者為較小尺寸的設備（如平板電腦和手機）設計了幾個 GNOME Shell 的概念驗證。

為什麼是現在？ ​

任何項目的開發和研究工作都要花費時間和金錢。雖然有來自主要科技公司對 GNOME 的捐贈，但這次有一個 “原型基金Prototype Fund” 幫助該團隊繼續進行這項努力。原型基金 是德國教育部（BMBF）支持公共利益軟件的資助項目。

包括什麼？ ​

設計一個完整的移動用户界面，並將其與移動操作系統整合是一個非常複雜的項目。它需要一個精心設計的願景來支持成千上萬的移動硬件和用户支持。更不用説，用户在移動設備上的隱私和安全問題了。

因此，有了這個基金，團隊可以集中精力進行概念驗證，以滿足 GNOME Shell 中一些基本的用户互動。

  • 啓動器
  • 應用程序網格
  • 輕掃、手勢和導航
  • 用手機鍵盤搜索
  • 檢測屏幕大小和支持屏幕旋轉
  • 工作空間和多任務
  • 設置
  • 屏幕鍵盤

始終要記住的是，移動體驗遠不止用户界面這麼簡單。另外，GNOME 本身並不是一個操作系統。它由底層的穩定的操作系統組成，它提供了非常需要的隱私和安全。另外，“應用商店”的概念也是如此。手機制造商需要與 GNOME 開發者合作，讓他們的產品採用這個概念。

進展如何？ ​

在寫這篇文章時，團隊給我們快速演示了取得的進展。在下面的視頻中可以看到：

複雜的任務是識別觸摸屏手機中的各種手勢。例如，你可能會使用長觸摸、短觸摸、雙指輕掃和拖動，以及許多隻有在小尺寸設備中才可行的可能性。這需要在各自的 GNOME Shell 組件中推倒重構。

而完全在現有的 GNOME Shell 基礎上開發它們是很有挑戰性的工作。

此外，該團隊使用著名的 Pinephone Pro 進行開發和測試。Pinephone 已經是一個商業產品，裝有 “友商” KDE Plasma 手機和其他 Linux 操作系統。

結語 ​

如果一切按計劃進行，我們可能在一個完整的開源手機中獲得原生的 GNOME 體驗。而你可以重新擁有你的隱私!

另外，我不確定 Phosh（它也是基於 GNOME 的）會發生什麼。雖然 Phosh 是由 Purism 開發和管理的，但看看 GNOME Shell 在移動設備上的努力和 PHosh 在未來一段日子的發展方向將是很有趣的。
