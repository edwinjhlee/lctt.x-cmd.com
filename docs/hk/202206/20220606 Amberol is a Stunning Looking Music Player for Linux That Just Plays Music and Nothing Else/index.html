Amberol 是一款外觀漂亮的 Linux 音樂播放器，只播放音樂，不做其他事情 ​

雖然音樂世界被流媒體服務所主導，但這並沒有阻止開發者為桌面電腦創建音樂播放器。

最近，我發現了一個外觀漂亮的新的 Linux 桌面音樂播放器。它名為 Amberol，我被它的美麗所震撼。

看起來不錯，不是嗎？讓我們仔細看看它。

Amberol，Linux 上的可愛的音樂播放器 ​

看起來不錯是它所做的兩件（或幾件）事情中的一件。另一件事是播放音樂。

這就是它，Amberol 沒有額外的花哨（和有用）的功能，如生成專輯封面、元數據編輯、歌詞顯示或播放列表和庫管理。

這些功能也不像是會在未來的版本中加入。Amberol 只想播放音樂。就是這樣。

令人驚歎的用户界面 ​

Amberol 和大多數新的 GNOME 應用一樣，是用 Rust 和 GTK 編寫的。

它有一個自適應的用户界面，可以根據你正在播放的專輯顏色來改變顏色。漸變效果給了它一個現代、時尚的外觀，肯定會成為你的 Linux 美化Ricing截圖的一部分。

由於其 UI 沒有傳統的手柄和菜單，它給應用一個統一的外觀。

播放列表 ​

它會從你添加的文件夾中的文件自動生成一個播放列表，顯示在左手邊的側邊欄。

你可以在左上角看到整個播放列表將播放多長時間的音樂。點擊“勾選”符號，你可以選擇歌曲，並從播放列表中刪除它們。

如果你願意，可以隱藏播放列表的側邊欄。

音樂播放選項 ​

你可以在界面上看到歌曲的進度。該播放器與鍵盤上的媒體控制按鈕整合得很好。你可以用專用的媒體鍵來播放、暫停和改變曲目（如果你的系統上有）。

Amberol 為你提供了一些播放音樂的選項。你可以打開隨機播放功能，按隨機順序播放音樂。你也可以單曲循環，直到你厭倦它。

底部的漢堡菜單讓你可以選擇添加文件或文件夾，並顯示可用的鍵盤快捷方式。

你也可以從這裏禁用 UI 顏色變化以配合專輯封面。

在 Linux 上安裝 Amberol ​

Amberol 是 以 Flatpak 形式提供的。請確保 你的系統已啓用 Flatpak 支持。

要安裝 Amberol，請打開終端並使用以下命令：

flatpak install flathub io.bassi.Amberol

安裝完畢後，在菜單中搜索該應用，並點擊啓動。

第一次運行時，它會要求你添加音樂文件或文件夾。你也可以拖放文件播放。

總結 ​

就個人而言，我更喜歡流媒體服務，因為我沒有本機音樂珍藏。但我知道有的人有大量的 CD 收藏，現在都保存在硬盤上。

Amberol 是一個外觀漂亮的應用，對於播放本機音樂來説，它足夠好。最吸引人的是它基於專輯封面的自適應用户界面。

請你試試它，並在評論區分享你的經驗。
