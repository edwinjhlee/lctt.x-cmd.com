馬克·沙特爾沃思 – Ubuntu 背後的那個男人 ​

馬克·理查德·沙特爾沃思（Mark Richard Shuttleworth） 是 Ubuntu 的創始人，也被稱作 Debian 背後的人（之一）。他於 1973 年出生在南非的韋爾科姆（Welkom）。他不僅是個企業家，還是個太空遊客——他是第一個前往太空旅行的非洲獨立國家的公民。

馬克曾在 1996 年成立了一家名為 Thawte 的互聯網商務安全公司，那時他還在開普敦大學（ University of Cape Town）的學習金融和信息技術。

2000 年，馬克創立了 HBD（Here be Dragons （此處有龍/危險）的縮寫，所以其吉祥物是一隻龍），這是一家投資公司，同時他還創立了沙特爾沃思基金會（Shuttleworth Foundation），致力於以獎金和投資等形式給社會中有創新性的領袖提供資助。

“移動設備對於個人電腦行業的未來而言至關重要。比如就在這個月，相對於平板電腦的發展而言，傳統 PC 行業很明顯正在萎縮。所以如果我們想要涉足個人電腦產業，我們必須首先涉足移動行業。移動產業之所以有趣，是因為在這裏沒有盜版 Windows 操作系統的市場。所以如果你為你的操作系統贏得了一台設備的市場份額，這台設備會一直使用你的操作系統。在傳統 PC 行業，我們時不時得和“免費”的 Windows 產生競爭，這是一種非常微妙的挑戰。所以我們現在的重心是圍繞 Ubuntu 和移動設備——手機和平板——以圖與普通用户建立更深層次的聯繫。”

— 馬克·沙特爾沃思

2002 年，他在俄羅斯的星城（Star City）接受了為期一年的訓練，隨後作為聯盟號 TM-34 任務組的一員飛往了國際空間站。再後來，在面向有志於航空航天或者其相關學科的南非學生羣體發起了推廣科學、編程及數學的運動後，馬克 創立了 Canonical Ltd。此後直至2013年，他一直在領導 Ubuntu 操作系統的開發。

現今，沙特爾沃思擁有英國與南非雙重國籍並和 18 只可愛的鴨子住在英國的 Isle of Man 小島上的一處花園，一同的還有他可愛的女友 Claire，兩條黑色母狗以及時不時經過的羊羣。

“電腦不僅僅是一台電子設備了。它現在是你思維的延續，以及通向他人的大門。”

— 馬克·沙特爾沃思

馬克·沙特爾沃思的早年生活### ​

正如我們之前提到的，馬克出生在南非的奧蘭治自由邦（Orange Free State）的韋爾科姆（Welkom）。他是一名外科醫生和護士學校教師的孩子。他在西部省預科學校就讀並在 1986 年成為了學生會主席，一個學期後就讀於 Rondebosch 男子高中，再之後入學 Bishops Diocesan 學院並在 1991 年再次成為那裏的學生會主席。

馬克在開普敦大學（ University of Cape Town）拿到了金融和信息系統的商業科學雙學士學位，他在學校就讀時住在 Smuts Hall。作為學生，他也在那裏幫助安裝了學校的第一條宿舍互聯網接入。

“無數的企業和國家已經證明，引入開源政策能提高競爭力和效率。在不同層面上創造生產力對於公司和國家而言都是至關重要的。”

— 馬克·沙特爾沃思

馬克·沙特爾沃思的職業生涯 ​

馬克在 1995 年創立了 Thawte，公司專注於數字證書和互聯網安全，然後在 1999 年把公司賣給了 VeriSign，賺取了大約 5.75 億美元。

2000 年，馬克創立了 HBD 風險資本公司，成為了商業投資人和項目孵化器。2004 年，他創立了 Canonical Ltd. 以支持和鼓勵自由軟件開發項目的商業化，特別是 Ubuntu 操作系統的項目。直到 2009 年，馬克才從 Canonical CEO 的位置上退下。

“在 DDC (LCTT 譯註：一個 Debian GNU/Linux 開發者聯盟) 的早期，我更傾向於讓擁護者們放手去做，看看能發展出什麼。”

— 馬克·沙特爾沃思

Linux、自由開源軟件與馬克·沙特爾沃思 ​

在 90 年代後期，馬克曾作為一名開發者參與 Debian 操作系統項目。

2001 年，馬克創立了沙特爾沃思基金會，這是個紮根南非的、非贏利性的基金會，專注於贊助社會創新、免費/教育用途開源軟件，曾贊助過自由烤麪包機（Freedom Toaster）（LCTT 譯註：自由烤麪包機是一個可以給用户帶來的 CD/DVD 上刻錄自由軟件的公共信息亭）。

2004 年，馬克通過出資開發基於 Debian 的 Ubuntu 操作系統返回了自由軟件界，這一切也經由他的 Canonical 公司完成。

2005 年，馬克出資建立了 Ubuntu 基金會並投入了一千萬美元作為啓動資金。在 Ubuntu 項目內，人們經常用一個朗朗上口的名字稱呼他——“SABDFL ：自封的生命之仁慈獨裁者（Self-Appointed Benevolent Dictator for Life）”。為了能夠找到足夠多的高手開發這個巨大的項目，馬克花費了 6 個月的時間從 Debian 郵件列表裏尋找，這一切都是在他乘坐在南極洲的一艘破冰船——赫列布尼科夫船長號（Kapitan Khlebnikov）——上完成的。同年，馬克買下了 Impi Linux 65% 的股份。

“我呼籲電信公司的掌權者們儘快開發出跨洲際的高效信息傳輸服務。”

— 馬克·沙特爾沃思

2006 年，KDE 宣佈沙特爾沃思成為 KDE 的第一讚助人（first patron）——彼時 KDE 最高級別的贊助。這一讚助協議在 2012 年終止，取而代之的是對 Kubuntu 的資金支持，這是一個使用 KDE 作為默認桌面環境的 Ubuntu 變種。

2009 年，Shuttleworth 宣佈他會從 Canonical 的 CEO 上退位以更好地關注合作關係、產品設計和客户。從 2004 年起擔任公司 COO 的珍妮·希比爾（Jane Silber）晉升為 CEO。

2010 年，馬克由於其貢獻而被開放大學（Open University）授予了榮譽學位。

2012 年，馬克和肯尼斯·羅格夫（Kenneth Rogoff）一同在牛津大學與彼得·蒂爾（Peter Thiel）和加里·卡斯帕羅夫（Garry Kasparov）就創新悖論（The Innovation Enigma）展開辯論。

2013 年，馬克和 Ubuntu 一同被授予澳大利亞反個人隱私大哥獎（Austrian anti-privacy Big Brother Award），理由是默認情況下， Ubuntu 會把 Unity 桌面的搜索框的搜索結果發往 Canonical 服務器（LCTT 譯註：因此侵犯了個人隱私）。而一年前，馬克曾經申明過這一過程進行了匿名化處理。

“所有主流 PC 廠家現在都提供 Ubuntu 預安裝選項，所以我們和業界的合作已經相當緊密了。但那些 PC 廠家對於給買家推廣新東西這件事都很緊張。如果我們可以讓 PC 買家習慣 Ubuntu 的平板/手機操作系統的體驗，那他們也應該更願意買預裝 Ubuntu 的 PC。沒有哪個操作系統是通過抄襲模仿獲得成功的，Android 很棒，但如果我們想成功的話我們必須給市場帶去更新更好的東西（LCTT 譯註：而不是改進或者模仿 Android）。如果我們中沒有人追尋未來的話，我們將陷入停滯不前的危險。但如果你嘗試去追尋未來了，那你必須接受不是所有人對未來的預見都和你一樣這一事實。”

— 馬克·沙特爾沃思

馬克·沙特爾沃思的太空之旅 ​

馬克在 2002 年作為世界第二名自費太空遊客而聞名世界，同時他也是南非第一個旅行太空的人。這趟旅行中，馬克作為俄羅斯聯盟號 TM-34 任務的一名乘員加入，併為此支付了約兩千萬美元。2 天后，聯盟號宇宙飛船抵達了國際空間站，在那裏馬克呆了 8 天並參與了艾滋病和基因組研究的相關實驗。同年晚些時候，馬克隨聯盟號 TM-33 任務返回了地球。為了參與這趟旅行，馬克花了一年時間準備與訓練，其中有 7 個月居住在俄羅斯的星城。

在太空中，馬克與納爾遜·曼德拉（Nelson Mandela）和另一個 14 歲的南非女孩米歇爾·福斯特（Michelle Foster） （她問馬克要不要娶她）通過無線電進行了交談。馬克禮貌地迴避了這個結婚問題，但在巧妙地改換話題之前他説他感到很榮幸。身患絕症的女孩福斯特通過夢想基金會（ Dream foundation）的贊助獲得了與馬克和納爾遜·曼德拉交談的機會。

歸來後，馬克在世界各地做了旅行，並和各地的學生就太空之旅發表了感言。

“粗略的統計數據表明 Ubuntu 的實際用户依然在增長。而我們的合作方——戴爾、惠普、聯想和其他硬件生產商，以及遊戲廠商 EA、Valve 都在加入我們——這讓我覺得我們在關鍵的領域繼續領先。”

— 馬克·沙特爾沃思

馬克·沙特爾沃思的交通工具 ​

馬克有他自己的私人客機龐巴迪全球特快（Bombardier Global Express），雖然它經常被稱為 Canonical 一號，但事實上此飛機是通過 HBD 風險投資公司註冊擁有的。塗畫在飛機側面的龍圖案是 HBD 風投公司的吉祥物 ，名叫 Norman。

與南非儲備銀行的法律衝突 ​

在從南非轉移 25 億南非蘭特去往 Isle of Man 的過程中，南非儲備銀行徵收了 2.5 億南非蘭特的税金。馬克上訴了，經過冗長的法庭唇槍舌戰，南非儲備銀行被勒令返還 2.5 億徵税，以及其利息。馬克宣佈他會把這 2.5 億存入信託基金，以用於幫助那些上訴到憲法法院的案子。

“離境徵税倒也不和憲法衝突。但離境徵税的主要目的不是提高税收，而是通過監管資金流出來保護本國經濟。”

— Dikgang Moseneke 法官

2015 年，南非憲法法院修正了低級法院的判決結果，並宣佈了上述對於離岸徵税的理解。
