混合雲計算的 9 大關鍵趨勢 ​

自從幾年前雲計算的概念受到IT界的關注以來，公有云、私有云和混合雲這三種雲計算方式都有了可觀的演進。其中混合雲計算方式是最熱門的雲計算方式，在接受調查的公司中，有88%的公司將混合雲計算擺在至關重要的地位。

混合雲計算的疾速演進意味着一兩年前的傳統觀念已經過時了。為此，我們詢問了幾個行業分析師，混合雲在2016年的走勢將會如何，我們得到了幾個比較有意思的答案。

  1. 2016年可能是我們將混合雲投入使用的一年。

混合雲從本質上來説依賴於私有云，這對企業來説是比較難實現的。事實上，亞馬遜，谷歌和微軟的公有云已經進行了大量的投資，並且起步也比較早。私有云拖了混合雲發展和使用的後腿。

私有云沒有得到這麼多的投資，這是有私有云的性質決定的。私有云意味着維護和投資你自己的數據中心。而許多公有云提供商正在推動企業減少或者消除他們的數據中心。

然而，得益於 OpenStack 的發展和微軟的 Azure Stack ，這兩者基本上就是封裝在一個盒子裏的私有云，我們將會看到私有云慢慢追上公有云的發展步伐。支持混合雲的工具、基礎設施和架構也變得更加健壯。

  1. 容器，微服務和 unikernels 將會促進混合雲的發展。

分析師預言，到2016年底，這些原生雲技術會或多或少成為主流的。這些雲技術正在快速成熟，將會成為虛擬機的一個替代品，而虛擬機需要更多的資源。

更重要的是，他們既能工作在在線場景，也能工作在離線場景。容器化和編排允許快速的擴大規模，進行公有云和私有云之間的服務遷移，使你能夠更容易移動你的服務。

  1. 數據和相關性佔據核心舞台。

所有的雲計算方式都處在發展模式。這使得雲計算變成了一個技術類的故事。諮詢公司 Avoa稱，隨着雲趨於成熟，數據和相關性變得越來越重要。起初，雲計算和大數據都是關於怎麼得到儘可能多的數據，然後他們擔心如何處理這海量的數據。

2016年，相關組織將會繼續錘鍊如何進行數據收集和使用的相關技術。在必須處理的技術和文化方面仍然有待提高。但是2016年應該重新將關注點放在從各個方面考慮的數據重要性上，發現最相關的信息，而不只是數據的數量。

  1. 雲服務將超越按需工作負載。

AWS(Amazon Web Services) 起初是提供給程序員或者是開發人員能夠快速啓動虛擬機、做一些工作然後離線的一個地方。本質上是按需使用，要花費更多的錢才能讓這些服務持續運行、全天候工作。

然而，IT 公司正開始作為服務代理，為內部用户提供各種 IT 服務。可以是內部 IT 服務，公有云基礎架構提供商，平台服務和軟件服務。

他們將越來越多的認識到像雲管理平台這樣的工具的價值。雲管理平台可以提供針對不同服務的基於策略的一致性管理。他們也將看到像提高可移植性的容器等技術的價值。然而，雲服務代理，在不同雲之間快速移動工作負載從而進行價格套利或者類似的原因，仍然是行不通的。

  1. 服務提供商轉變成了雲服務提供商。

到目前為止，購買雲服務成了直銷模式。AWS EC2 服務的使用者通常變成了購買者，要麼通過官方認證渠道，要麼通過影子 IT。但是隨着雲服務越來越全面，提供的服務菜單越來越複雜，越來越多的人轉向了經銷商，服務提供商轉變成了他們 IT 服務的購買者。

2nd Watch (2nd Watch 是為企業提供雲管理的 AWS 的首選合作伙伴)最近的一項調查發現，在美國將近85%的 IT 高管願意支付一個小的溢價從渠道商那裏購買公有云服務，如果購買過程變得不再那麼複雜。根據調查，這85%的高管有五分之四的願意支付額外的15%或者更多。三分之一的受訪高管表示，這些有助於他們購買、使用和管理公有云服務。

  1. 物聯網和雲對於2016年的意義好比移動和雲對2012年的意義。

物聯網獲得了廣泛的關注，更重要的是，物聯網已經從測試場景進行了實際應用。雲的分佈式特性使得雲成為了物聯網非常重要的一部分，對於工業物聯網，與後端系統交互的機械和重型設備，混合雲將會成為最自然的驅動者，連接，數據採集和處理將會發生在混合雲環境中，這得益於私有云在安全和隱私方面的好處。

  1. NIST 對雲的定義開始瓦解。

2011年，美國國家標準與技術研究院發佈了“ NIST 對於雲計算的定義”（PDF），這個定義成為了私有云、公有云、混合雲和 aaS 模板的標準定義。

然而隨着時間的推移，定義開始改變。IaaS 變得更加複雜，開始支持 OpenStack，Swift 對象存儲和神經網絡這樣的項目。PaaS 似乎正在消退，因為 PaaS 和傳統的中間件開發幾乎無異。SaaS，只是通過瀏覽器進行訪問的應用，也正在失去發展動力，因為許多 app 和服務提供了許多雲接口，你可以通過各種手段調用接口，不僅僅通過瀏覽器。

  1. 分析變得更加重要

對於混合雲計算來説，分析將會成為一個巨大的增長機遇，雲計算具有規模大、靈活性高的優勢，使得雲計算非常適合需要海量數據的分析工作。對於某些分析方式，比如高度敏感的數據，私有云仍然是主導地位，但是私有云也是混合雲的一部分。因此，無論如何，混合雲計算勝出。

  1. 安全仍然是一個非常緊迫的問題。

隨着混合雲計算在2016年的發展，以及對物聯網和容器等新技術的引進，這同時也增加了更多的脆弱可攻破的地方，從而導致數據泄露。先增加使用新技術的趨勢，然後再去考慮安全性，這種問題經常發生，同時還有缺少經驗的工程師不去考慮系統的安全問題，總有一天你會嚐到災難的後果的。

當一項新技術出來，管理規範總是落後於安全問題產生後，然後我們才考慮去保護技術。容器就是一個很鮮明的例子。你可以從 Docker 下載各種示例容器，但是你知道你下載的東西來自哪裏麼？在人們在對容器內容不知情的情況下下載並運行了容器之後，Docker 不得不重新加上安全驗證。

像 Path 和 Snapchat 這樣的移動技術在智能手機市場火起來之後也出現了重大的安全問題。一項新技術被惡意利用無可避免。所以安全研究人員需要通過各種手段來保證新技術的安全性，很有可能在部署之後才會發現安全問題。
