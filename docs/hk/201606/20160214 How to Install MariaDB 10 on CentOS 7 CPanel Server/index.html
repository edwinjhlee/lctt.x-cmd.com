在 CentOS 7 CPanel 服務器上安裝 MariaDB 10 ​

MariaDB 是一個增強版的、開源的 MySQL 替代品。它主要由 MariaDB 社區在維護，採用 GPL v2 授權許可。軟件的安全性是 MariaDB 開發者的主要焦點。他們保持為 MariaDB 的每個版本發佈安全補丁。當有任何安全問題被發現時，開發者會盡快修復並推出 MariaDB 的新版本。

MariaDB 的優勢 ​

  • 完全開源
  • 快速且透明的安全版本
  • 與 MySQL 高度兼容
  • 性能更好
  • 比 MySQL 的存儲引擎多

在這篇文章中，我將談論關於如何在 CentOS7 CPanel 服務器上升級 MySQL5.5 到最新的 MariaDB 。在安裝前先完成以下步驟。

先決條件: ​

1. 停止當前 MySQL 服務 ​

2. 在升級之前將所有配置文件和資料庫轉移 ​

轉移資料庫的存儲路徑和 MySQL 的配置文件

root@server1 [~]# cp -Rf /var/lib/mysql /var/lib/mysql-old

root@server1 [/var/lib/mysql]# cat /etc/my.cnf
[mysqld]
default-storage-engine=MyISAM
innodb_file_per_table=1
max_allowed_packet=268435456
open_files_limit=10000

root@server1 [~]#mv /etc/my.cnf /etc/my.cnf-old

3. 從服務器上刪除和卸載 MySQL 所有的 RPM 包 ​

運行以下命令來禁用 MySQL RPM 的目標（target）。通過運行此命令，cPanel 將不再處理 MySQL 的更新，並在系統上將這些 RPM 版本標記為已卸載。

/scripts/update_local_rpm_versions --edit target_settings.MySQL50 uninstalled
/scripts/update_local_rpm_versions --edit target_settings.MySQL51 uninstalled
/scripts/update_local_rpm_versions --edit target_settings.MySQL55 uninstalled
/scripts/update_local_rpm_versions --edit target_settings.MySQL56 uninstalled

現在運行以下命令：

/scripts/check_cpanel_rpms --fix --targets=MySQL50,MySQL51,MySQL55,MySQL56

移除服務器上所有已有的 MySQL RPM 來為 MariaDB 的安裝清理環境。請看下面的輸出：

通過這些步驟，我們已經卸載了現有的 MySQL RPM，並做了標記來防止 MySQL的更新，服務器的環境已經清理，然後準備安裝 MariaDB。

開始安裝吧，我們需要根據 CentOS 和 MariaDB 的版本為 MariaDB 創建一個 yum 軟件庫。下面是我的做法！

安裝步驟： ​

第1步：創建 YUM 軟件庫。#### ​

root@server1 [~]# vim /etc/yum.repos.d/MariaDB.repo
[mariadb]
name = MariaDB
baseurl = http://yum.mariadb.org/10.0/centos7-amd64/
gpgkey=https://yum.mariadb.org/RPM-GPG-KEY-MariaDB
gpgcheck=1
root@server1 [/etc/yum.repos.d]# cat /etc/yum.repos.d/MariaDB.repo
[mariadb]
name = MariaDB
baseurl = http://yum.mariadb.org/10.0/centos7-amd64/
gpgkey=https://yum.mariadb.org/RPM-GPG-KEY-MariaDB
gpgcheck=1

第2步：打開 /etc/yum.conf 並修改如下行： ​

刪除這一行：

exclude=courier* dovecot* exim* filesystem httpd* mod_ssl* mydns* mysql* nsd* php* proftpd* pure-ftpd* spamassassin* squirrelmail*

替換為：

exclude=courier* dovecot* exim* filesystem httpd* mod_ssl* mydns* nsd* proftpd* pure-ftpd* spamassassin* squirrelmail*

重要

需要確保我們已經從 exclude 列表中移除了 MySQL 和 PHP。

第3步：運行以下命令來安裝 MariaDB 和相關的包。 ​

root@server1 [~]#yum install MariaDB-server MariaDB-client MariaDB-devel php-mysql

第7步：運行 EasyApache，重建 Apache/PHP 以支持 MariaDB，並確保所有 PHP 的模組保持不變。#### ​

root@server1 [~]#/scripts/easyapache --build

重要

如果你在安裝 MariaDB 之後忘記重建 Apache/PHP，將會報如下庫錯誤：

root@server1 [/etc/my.cnf.d]# php -v
php: error while loading shared libraries: libmysqlclient.so.18: cannot open shared object file: No such file or directory
