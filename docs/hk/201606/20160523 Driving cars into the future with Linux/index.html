與 Linux 一同駕車奔向未來 ​

當我駕車的時候並沒有這麼想過，但是我肯定喜歡一個配有這樣系統的車子，它可以讓我按下幾個按鈕就能與我的妻子、母親以及孩子們語音通話。這樣的系統也可以讓我選擇是否從雲端、衞星廣播、以及更傳統的 AM/FM 收音機收聽音樂流媒體。我也會得到最新的天氣情況，以及它可以引導我的車載 GPS 找到抵達下一個目的地的最快路線。車載娛樂系統（In-vehicle infotainment），業界常稱作 IVI，它已經普及出現在最新的汽車上了。

前段時間，我乘坐飛機跨越了數百英里，然後租了一輛汽車。令人愉快的是，我發現我租賃的汽車上配置了類似我自己車上同樣的 IVI 技術。毫不猶豫地，我就通過藍牙連接把我的聯繫人上傳到了系統當中，然後打電話回家給我的家人，讓他們知道我已經安全抵達了，然後我的主機會讓他們知道我正在去往他們家的路上。

在最近的新聞綜述中，Scott Nesbitt 引述了一篇文章，説福特汽車公司因其開源的智能設備連接（Smart Device Link）（SDL）從競爭對手汽車製造商中得到了足夠多的回報，這個中間件框架可以用於支持移動電話。 SDL 是 GENIVI 聯盟的一個項目，這個聯盟是一個非營利性組織，致力於建設支持開源車載娛樂系統的中間件。據 GENIVI 的執行董事 Steven Crumb 稱，他們的成員有很多，包括戴姆勒集團、現代、沃爾沃、日產、本田等等 170 個企業。

為了在同行業間保持競爭力，汽車生產企業需要一箇中間設備系統，以支持現代消費者所使用的各種人機界面技術。無論您使用的是 Android、iOS 還是其他設備，汽車 OEM 廠商都希望自己的產品能夠支持這些。此外，這些的 IVI 系統必須有足夠適應能力以支持日益變化的移動技術。OEM 廠商希望提供有價值的服務，並可以在他們的 IVI 之上增加服務，以滿足他們客户的各種需求。

步入 Linux 和開源軟件 ​

除了 GENIVI 在努力之外，Linux 基金會也贊助支持了車載 Linux（Automotive Grade Linux）（AGL）工作組，這是一個致力於為汽車應用尋求開源解決方案的軟件基金會。雖然 AGL 初期將側重於 IVI 系統，但是未來他們希望發展到不同的方向，包括遠程信息處理（telematics）、抬頭顯示器（HUD）及其他控制系統等等。 現在 AGL 已經有超過 50 名成員，包括捷豹、豐田、日產，並在其最近發佈的一篇公告中宣稱福特、馬自達、三菱、和斯巴魯也加入了。

為了瞭解更多信息，我們採訪了這一新興領域的兩位領導人。具體來説，我們想知道 Linux 和開源軟件是如何被使用的，並且它們是如何事實上改變了汽車行業的面貌。首先，我們將與 Alison Chaiken 談談，她是一位任職於 Peloton Technology 的軟件工程師，也是一位在車載 Linux 、網絡安全和信息透明化方面的專家。她曾任職於 Alison Chaiken 公司、諾基亞和斯坦福直線性加速器。然後我們和 Steven Crumb 進行了交談，他是 GENIVI 執行董事，他之前從事於高性能計算環境（超級計算機和早期的雲計算）的開源工作。他説，雖然他再不是一個程序員了，但是他樂於幫助企業解決在使用開源軟件時的實際業務問題。

採訪 Alison Chaiken (by Deb Nicholson) ​

你是如何開始對汽車軟件領域感興趣的？ ​

我曾在諾基亞從事於手機上的 MeeGo 產品，2009 年該項目被取消了。我想，我下一步怎麼辦？其時，我的一位同事正在從事於 MeeGo-IVI，這是一個早期的車載 Linux 發行版。 “Linux 在汽車方面將有很大發展，” 我想，所以我就朝着這個方向努力。

你能告訴我們你在這些日子裏工作在哪些方面嗎？ ​

我目前正在啓動一個高級巡航控制系統的項目，它用在大型卡車上，使用實時 Linux 以提升安全性和燃油經濟性。我喜歡在這方面的工作，因為沒有人會反對提升貨運的能力。

近幾年有幾則汽車被黑的消息。開源代碼方案可以幫助解決這個問題嗎？ ​

我恰好針對這一話題準備了一次講演，我會在南加州 Linux 2016 博覽會上就 Linux 能否解決汽車上的安全問題做個講演 （講演稿在此）。值得注意的是，GENIVI 和車載 Linux 項目已經公開了他們的代碼，這兩個項目可以通過 Git 提交補丁。（如果你有補丁的話），請給上游發送您的補丁！許多眼睛都盯着，bug 將無從遁形。

執法機構和保險公司可以找到很多汽車上的數據的用途。他們獲取這些信息很容易嗎？ ​

好問題。IEEE-1609 專用短程通信標準（Dedicated Short Range Communication Standard）就是為了讓汽車的 WiFi 消息可以安全、匿名地傳遞。不過，如果你從你的車上發推，那可能就有人能夠跟蹤到你。

開發人員和公民個人可以做些什麼，以在汽車技術進步的同時確保公民自由得到保護？ ​

電子前沿基金會（ Electronic Frontier Foundation）（EFF）在關注汽車問題方面做了出色的工作，包括對哪些數據可以存儲在汽車 “黑盒子”裏通過官方渠道發表了看法，以及 DMCA 規定 1201 如何應用於汽車上。

在未來幾年，你覺得在汽車方面會發生哪些令人激動的發展？ ​

可以拯救生命的自適應巡航控制系統和防撞系統將取得長足發展。當它們大量進入汽車裏面時，我相信這會使得（因車禍而導致的）死亡人數下降。如果這都不令人激動，我不知道還有什麼會更令人激動。此外，像自動化停車輔助功能，將會使汽車更容易駕駛，減少汽車磕碰事故。

我們需要做什麼？人們怎樣才能參與？ ​

車載 Linux 開發是以開源的方式開發，它運行在每個人都能買得起的廉價硬件上（如樹莓派 2 和中等價位的 Renesas Porter 主板）。 GENIVI 汽車 Linux 中間件聯盟通過 Git 開源了很多軟件。此外，還有很酷的 OSVehicle 開源硬件汽車平台。

只需要不太多的預算，人們就可以參與到 Linux 軟件和開放硬件中。如果您感興趣，請加入我們在 Freenode 上的IRC #automotive 吧。

採訪 Steven Crumb (by Don Watkins) ​

GENIVI 在 IVI 方面做了哪些巨大貢獻？ ​

GENIVI 率先通過使用自由開源軟件填補了汽車行業的巨大空白，這包括 Linux、非安全關鍵性汽車軟件（如車載娛樂系統（IVI））等。作為消費者，他們很期望在車輛上有和智能手機一樣的功能，對這種支持 IVI 功能的軟件的需求量成倍地增長。不過不斷提升的軟件數量也增加了建設 IVI 系統的成本，從而延緩了其上市時間。

GENIVI 使用開源軟件和社區開發的模式為汽車製造商及其軟件提供商節省了大量資金，從而顯著地縮短了產品面市時間。我為 GENIVI 而感到激動，我們有幸引導了一場革命，在緩慢進步的汽車行業中，從高度結構化和專有的解決方案轉換為以社區為基礎的開發方式。我們還沒有完全達成目標，但是我們很榮幸在這個可以帶來實實在在好處的轉型中成為其中的一份子。

你們的主要成員怎樣推動了 GENIVI 的發展方向？ ​

GENIVI 有很多成員和非成員致力於我們的工作。在許多開源項目中，任何公司都可以通過通過技術輸出而發揮影響，包括簡單地貢獻代碼、補丁、花點時間測試。前面説過，寶馬、奔馳、現代汽車、捷豹路虎、標緻雪鐵龍、雷諾/日產和沃爾沃都是 GENIVI 積極的參與者和貢獻者，其他的許多 OEM 廠商也在他們的汽車中採用了 IVI 解決方案，廣泛地使用了 GENIVI 的軟件。

這些貢獻的代碼使用了什麼許可證？ ​

GENIVI 採用了一些許可證，包括從（L）GPLv2 到 MPLv2 和 Apache2.0。我們的一些工具使用的是 Eclipse 許可證。我們有一個公開許可策略，詳細地説明了我們的許可證偏好。

個人或團體如何參與其中？社區的參與對於這個項目邁向成功有多重要？ ​

GENIVI 的開發完全是開放的（projects.genivi.org），因此，歡迎任何有興趣在汽車中使用開源軟件的人蔘加。也就是説，公司可以通過成員的方式加入該聯盟，聯盟以開放的方式資助其不斷進行開發。GENIVI 的成員可以享受各種各樣的便利，在過去六年中，已經有多達 140 家公司參與到這個全球性的社區當中。

社區對於 GENIVI 是非常重要的，沒有一個活躍的貢獻者社區，我們不可能在這些年開發和維護了這麼多有價值的軟件。我們努力讓參與到 GENIVI 更加簡單，現在只要加入一個郵件列表就可以接觸到各種軟件項目中的人們。我們使用了許多開源項目採用的標準做法，並提供了高品質的工具和基礎設施，以幫助開發人員賓至如歸而富有成效。

無論你是否熟悉汽車軟件，都歡迎你加入我們的社區。人們已經對汽車改裝了許多年，所以對於許多人來説，在汽車上修修改改是自熱而然的做法。對於汽車來説，軟件是一個新的領域，GENIVI 希望能為對汽車和開源軟件有興趣的人打開這扇門。
