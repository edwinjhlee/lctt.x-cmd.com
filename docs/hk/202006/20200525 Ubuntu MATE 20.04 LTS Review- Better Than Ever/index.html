Ubuntu MATE 20.04 LTS：士別三日，當刮目相待 ​

Ubuntu MATE 20.04 LTS 無疑是最流行的 Ubuntu 官方特色版本之一。

不僅僅是我，這份Ubuntu 20.04 調查報告也持同樣觀點。不過不管流行與否，它都是一個令人印象深刻的 Linux 發行版，尤其是用在較舊的硬件上時。事實上，它也是可用的最輕量的 Linux 發行版之一。

所以，我想在一個虛擬機中嘗試一下，為你提供一個概覽，這樣你可以瞭解其中有何值得期盼的變化，以及是否值得嘗試。

在 Ubuntu MATE 20.04 LTS 中有什麼新功能？ ​

  • video

Ubuntu MATE 20.04 LTS 的主要亮點應該是增加了 MATE Desktop 1.24。

你可以期待 MATE Desktop 1.24 中的所有新特色都被打包到 Ubuntu MATE 20.04 中。除此之外，還有很多重要的變化、改進和增補。

這是 Ubuntu MATE 20.04 中變化的概述：

  • 新增 MATE Desktop 1.24
  • 大量視覺改進
  • 數十處錯誤修復
  • 基於 Linux 內核 5.4 系列
  • 添加了實驗性的 ZFS 支持
  • 添加了來自 Feral Interactive 的 GameMode
  • 一些軟件包更新

現在，為了更好地瞭解 Ubuntu MATE 20.04，我將給你提供更多的細節。

用户體驗改善 ​

考慮到越來越多的用户傾向於在桌面上使用 Linux，而用户體驗在桌面中起着至關重要的作用。

如果有一些易於使用和令人愉悦的東西，那麼第一印象就會有很大不同。

對於 Ubuntu MATE 20.04 LTS，我沒有感到失望。就我個人而言，我是最新的 GNOME 3.36 的粉絲。我喜歡在我 Pop!_OS 20.04 上使用它，但是隨着 MATE 1.24 的出現，使得 Ubuntu MATE 也同樣具有很好的體驗。

你會看到窗口管理器有一些重大更改，包括：增加了用於重新調整大小的隱形邊框，HiDPI 圖標渲染，重新設計了 ALT+TAB 工作區切換器的彈出窗口和一些其它的更改，這些是最新的 MATE 1.24 桌面環境的一部分。

此外， MATE Tweak 也得到了一些貼心的改進，即使你更改桌面的佈局，也可以保留用户偏好。新的 MATE 歡迎屏幕也會告知用户更改桌面佈局的能力，因此，用户無需不斷摸索就能知道這個變化。

此外，我最喜歡的新增功能之一是可以預覽最小化的應用程序。

不過，我必須指出，並不是每個應用程序都可以如預期般的工作。因此，這個功能是有缺陷的，還需要改進。

應用程序新增或升級 ​

在 MATE 20.04 中，你會注意到有一個新的固件更新器，它是 fwupd 的 GTK 前端。你可以使用這個更新器來輕鬆地管理你的固件驅動。

這個版本也使用 Evolution 替換了 Thunderbird 電子郵件客户端。儘管 Thunderbird 是一個非常流行的電子郵件客户端，但是 Evolution 與 MATE 桌面集成得更好，並且證明它更有用。

考慮到我們已經搭載了 MATE 1.24，你也將發現一個新的時間和日期管理應用程序。不僅如此，如果你需要一個放大鏡，Ubuntu MATE 20.04 還內置了 Magnus。

Ubuntu MATE 20.04 也包括了眾多預安裝的軟件包/應用程序的升級包。

儘管這些是小的增補，但卻能在很大程度上幫助發行版變得更有用。

Linux Kernel 5.4 ​

Ubuntu MATE 20.04 帶有 2019 年最後一個主要的穩定版內核，即 Linux 內核 5.4。

使用該內核，你可以獲得原生的 exFAT 支持、改進的硬件支持。更不用説，擁有 WireGuard VPN 的支持也是一件極好的事。

所以，你會注意到 Linux Kernel 5.4 的眾多好處，包括內核鎖定功能。如果你好奇，你可以閲讀我們關於 Linux Kernel 5.4 的新聞報道來了解更多的細節。

增加了 Feral Interactive 的 GameMode ​

以將遊戲帶到 Linux 平台而聞名的 Feral Interactive 帶來了一款實用的命令列工具，即 GameMode。

它沒有提供圖形界面，但是在啓動一個遊戲前，你可以使用命令列請求臨時性的系統優化。

雖然這可能不會給每個系統都帶來很大的不同，而是給玩遊戲提供了更多的資源，並且 GameMode 可以確保你獲得必要的優化。

實驗性的 ZFS 安裝選項 ​

你可以使用 ZFS 作為根文件系統了。值得注意的是，它是一個實驗性的功能，如果你不確定自己在做什麼，那麼就不應該使用它。

要更好地瞭解 ZFS，我建議你閲讀我們的一篇文章，John Paul 所寫的《ZFS 是什麼》的文章。

性能和其它的改進 ​

Ubuntu MATE 是一款完美的輕量級發行版，同時也是一款適合現代台式機的發行版。

在這個評測中，我沒有運行任何特殊的基準測試工具，以一個普通用户來説，我在虛擬機設置中沒有發現任何性能問題。我在一台使用了一顆 i5-7400 處理器、配備 GTX 1050 顯卡和 16 GB 內存的主機系統上進行了測試。並且，我將 7 GB 的內存 + 768 MB 的顯存 + 2 個處理器核心分配給了虛擬機。

如果你要自己測試它，請隨時告訴我你對它的感覺如何。

總的來説，除了所有主要的改進之外，還有一些細微的改變/修復/改進，使得 Ubuntu MATE 20.04 LTS 成為了一個很好的升級版本。

我應該升級嗎? ​

如果你正在運行 Ubuntu MATE 19.10，你應該立即升級它，因為它的支持將在 2020 年 6 月結束。

對於 Ubuntu MATE 18.04 用户（支持到 2021 年 4 月）來説，這取決於你的需求。如果你需要最新發布版本的功能，你應該選擇立即升級它。

但是，如果你不一定需要新的功能，你可以查看現存的錯誤列表 並加入 Ubuntu MATE 社區 來了解更多最新發布版本的問題。

在你做完必要的研究後，你可以繼續升級你的系統到 Ubuntu MATE 20.04 LTS，它將支持到 2023 年 4 月。
