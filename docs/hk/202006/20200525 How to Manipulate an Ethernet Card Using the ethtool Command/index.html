如何使用 ethtool 命令管理以太網卡 ​

ethtool 用於查看和修改網絡設備（尤其是有線以太網設備）的驅動參數和硬件設置。你可以根據需要更改以太網卡的參數，包括自動協商、速度、雙工和局域網喚醒等參數。通過對以太網卡的配置，你的計算機可以通過網絡有效地進行通信。該工具提供了許多關於接駁到你的 Linux 系統的以太網設備的信息。

在這篇文章中，我們將告訴你如何更改以下的參數以及如何查看這些參數。這篇文章將幫助你在 Linux 系統中排除與以太網卡相關的問題。

下面的信息將幫助你瞭解以太網卡的工作原理。

  • 半雙工：半雙工模式允許設備一次只能發送或接收數據包。
  • 全雙工：全雙工模式允許設備可以同時發送和接收數據包。
  • 自動協商：自動協商是一種機制，允許設備自動選擇最佳網速和工作模式（全雙工或半雙工模式）。
  • 速度：默認情況下，它會使用最大速度，你可以根據自己的需要改變它。
  • 鏈接檢測：鏈接檢測可以顯示網卡的狀態。如果顯示為 no，請嘗試重啓網卡。如果鏈路檢測仍顯示 no，則檢查交換機與系統之間連接的線纜是否有問題。

如何在 Linux 上安裝 ethtool ​

默認情況下，大多數系統上應該已經安裝了 ethtool。如果沒有，你可以從發行版的官方版本庫中安裝。

對於 RHEL/CentOS 6/7 系統，請使用 yum 命令 安裝 ethtool：

$ sudo yum install -y ethtool

對於 RHEL/CentOS 8 和 Fedora 系統，請使用 dnf 命令 安裝 ethtool：

$ sudo yum install -y ethtool

對於基於 Debian 的系統，請使用 apt 命令 或 apt-get 命令 安裝 ethtool：

$ sudo apt-get install ethtool

對於 openSUSE 系統，使用 zypper 命令 安裝 ethtool：

$ sudo zypper install -y ethtool

對於 Arch Linux 系統，使用 pacman 命令 安裝 ethtool：

$ sudo pacman -S ethtool

如何檢查 Linux 上的可用網絡接口 ​

你可以使用 ip 命令或 ifconfig 命令（在現代發行版中已被淘汰）來驗證可用的、活動的網卡的名稱和其他細節：

# ip a

如何檢查 Linux 上的網卡（NIC）信息 ​

掌握了以太網卡名稱後，就可以使用 ethtool 命令輕鬆查看其詳細信息，如下所示。

在 Linux 系統中，每個網卡（NIC）都被分配了唯一的名稱，如 ethX、enpXXX 等。

  • 舊的 Linux 發行版使用的是 eth[X] 格式。例如，RHEL 6 和它們的舊版本。
  • 現代的 Linux 發行版使用 enp[XXX] 或 ens[XXX] 格式。例如，大多數現代 Linux 發行版都使用這種格式，包括 RHEL 7、Debian 10、Ubuntu 16.04 LTS。

如何改變以太網設備的速度 ​

你可以根據需要改變以太網的速度。當你進行此更改時，網卡將自動掉線，你需要使用 ifup 命令 或 ip 命令或 nmcli 命令將其重新上。

# ethtool -s eth0 speed 100
# ip link set eth0 up

如何在 Linux 上啓用/禁用以太網卡的自動協商？ ​

你可以使用 ethtool 命令中的 autoneg 選項啓用或禁用自動協商，如下圖所示：

# ethtool -s eth0 autoneg off
# ethtool -s eth0 autoneg on

如何同時更改多個參數 ​

如果你想使用 ethtool 命令同時更改以太網卡的多個參數，請使用下面的格式：

Syntax:
ethtool –s [device_name] speed [10/100/1000] duplex [half/full] autoneg [on/off]
# ethtool –s eth0 speed 1000 duplex full autoneg off

如何檢查特定網卡的自動協商、RX 和 TX ​

要查看關於特定以太網設備的自動協商等詳細信息，請使用以下格式：

# ethtool -a eth0

如何從多個設備中識別出特定的網卡（閃爍網卡上的 LED） ​

如果你想識別一個特定的物理接口，這個選項非常有用。下面的 ethtool 命令會使 eth0 端口的 LED 燈閃爍：

# ethtool -p eth0

如何在 Linux 中永久設置這些參數 ​

在系統重啓後，你使用 ethtool 所做的更改將被默認恢復。

要使自定義設置永久化，你需要更新網絡配置文件中的值。根據你的 Linux 發行版，你可能需要將此值更新到正確的文件中。

對於基於 RHEL 的系統。你必須使用 ETHTOOL_OPTS 變量：

# vi /etc/sysconfig/network-scripts/ifcfg-eth0

ETHTOOL_OPTS="speed 1000 duplex full autoneg off"

對於基於 Debian 的系統：

# vi /etc/network/interfaces

post-up ethtool -s eth0 speed 1000 duplex full autoneg off
