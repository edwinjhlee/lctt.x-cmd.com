Linux Lite 5.0 發佈，帶有 UEFI 支持和其他重大改進 ​

Linux Lite 是適合 Windows 用户的最佳 Linux 發行版之一。 不僅限於此，它還是最受歡迎的輕量級 Linux 發行版之一。

基於 Ubuntu 18.04 的 Linux Lite 4.x 系列雖然不錯，但沒有 UEFI 支持。 但是現在基於 Ubuntu 20.04 的 Linux Lite 5.0 終於來了，我很高興看到這些變化！

在本文中，我們將介紹 Linux Lite 5.0 的新增功能。

Linux Lite 5.0：關鍵變更 ​

即使 Linux Lite 從 2.x 就開始支持 UEFI，但他們總是默認發佈非 UEFI 的。

但是，在 Linux Lite 5.0 中，他們終於增加了開箱即用的 UEFI 默認支持以及許多重大改進。讓我們看看發生了什麼變化：

UEFI 支持 ​

Linux Lite 5.0 支持開箱即用的 UEFI。但是，他們建議禁用安全啓動，即使該功能可以工作。

你可以看看他們的論壇文章，以瞭解更多信息。此外，你還可以在新的內置幫助手冊中找到有關此的更多信息。

基於 Ubuntu 的發行版，沒有隱藏的遙測 ​

如果你正在尋找基於 Ubuntu 的 Linux 發行版，且沒有任何隱藏的遙測功能，那麼 Linux Lite 5.0 似乎是理想的選擇。

在發佈公告中，他們在變更日誌中提到了它，並提供了截圖：

GUFW 防火牆替換為 firewalld ​

你可能已經讀過在 Linux 上使用 GUFW 設置防火牆，但從 Linux Lite 5.0 開始，它已由 firewalld 取代。

似乎 GUFW 不能像 firewalld 那樣配置。因此，他們決定替換它。

默認情況下，它是禁用的。但是，你可以按照幫助手冊中的教程選擇啓用它。

新的 Whisker 菜單 ​

Whisker 菜單已更新至最新可用的軟件包（v2.4.4）。 除了更新之外，你還可以注意到安裝更新現在被固定在收藏夾。

HiDPI 設置 ​

如果需要，你會發現從設置菜單中設置 HiDPI 非常容易。

已添加 XFCE 屏幕保護程序 ​

在 Linux Lite 5.0 中，你還將注意到添加了 XFCE 屏幕保護程序，默認情況下它處於禁用狀態。

這是一個簡單的補充，對於一直想要屏幕保護程序並能夠對其進行調整的用户而言，這將很有用。

其他重要改進 ​

除了上面提到的關鍵要點外，還有其他一些改進對於 Linux Lite 5.0 用户而言應該是很方便的。我在這裏列出其中一些：

  • Mousepad 替換 Leafpad
  • 新的更新通知
  • 在即時啓動時進行完整性檢查
  • 對幫助手冊的重大改進
  • Lite 軟件中用 Chrome 取代了 Chromium
  • 新的佈局選項
  • Lite 歡迎頁面和 Lite 用户管理器現在更新到 GTK3 和 Python3。
  • 歡迎頁面添加了新的選擇：選擇深色或淺色主題、UEFI 和安全啓動、反饋
  • 改進的 Lite 小部件

如果你想進一步瞭解更改，可以在其官方公告中找到詳細的更改列表。

總結 ​

我認為 Linux Lite 5.0 比以往任何時候要好，並且隨着最近新增的功能，對於許多新 Linux 用户來説，它也是一個絕佳的選擇。
