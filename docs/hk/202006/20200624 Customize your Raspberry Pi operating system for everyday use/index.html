定製用於日常使用的樹莓派系統 ​

安裝精簡版樹莓派系統，讓你的樹莓派更加輕盈。

你有一個運行樹莓派系統Raspberry Pi OS（以前稱為 Raspbian）操作系統的樹莓派Raspberry Pi，你肯定知道，它是一個非常棒的小型電腦，有一個很好的操作系統，對於初學者來説，它包括了你可能想要的一切。然而，一旦你熟悉了它，並且想用它幹一些別的事情的時候，你可能不想要那個默認囊括了一切組件的操作系統。

在這種情況下，你兩個選擇：要麼你可以絞盡腦汁地把所有你不需要的東西都刪乾淨，要麼你還可以用精簡版樹莓派系統Raspberry Pi OS Lite來構建專門為你的需求而定製的輕量級操作系統。我的建議是，用第二種方法，既簡便又節省時間。

Raspberry Pi OS Lite ​

“精簡版Lite”的樹莓派系統Raspberry Pi OS其實沒什麼特別的，就是一個基於最新版本的 Debian 的最小化鏡像。這個鏡像僅包含了操作系統核心和啓動到命令列的部分，而不會進入圖形桌面。可以將這個作為你的定製樹莓派系統的基礎。這之後的所有東西都是建立在這個核心之上的。

前往樹莓派基金會的網站上下載這個輕量級鏡像。下載完成後，查看詳細的安裝指南，這裏面介紹了在 Linux、Windows 或者 macOS 下如何燒製樹莓派操作系統的 SD 卡。

如果你計劃用樹莓派作為一個極簡系統來運行一些腳本和服務的話，差不多這麼多就夠了。如果你還想幹更多事，那繼續往下讀。

X Window ​

首先，如果偶爾需要通過圖形用户界面（GUI）連接到你的樹莓派，安裝一個窗口系統還是不錯的。

X Window 系統，有時候稱為 X11，是 Unix 操作系統上一個常見的基本窗口系統。X11 提供了一套 GUI 桌面環境的基本框架。它可以讓你通過窗口、鼠標和鍵盤與計算機交互。

安裝 X Window ​

下面這一行安裝了能讓 X11 運行的最少的包。

sudo apt install -y --no-install-recommends xserver-xorg-core xserver-xorg xfonts-base xinit

如果使用 --no-install-recommends，則只安裝了主要的一些依賴（Depends 字段中的包）。這樣可以節省很多空間，因為沒有安裝那些建議卻不一定需要的包。

進階：使用 Xfce 桌面環境 ​

如果你願意，可以就此停下了，然後開始使用 X Window 作為你的桌面。不過，我並不建議這麼做。X Window 自帶的這種最小化的窗口管理工具走的是極簡主義風格，某種程度上讓人感覺過時了。相反，我建議安裝現代化的桌面環境，比如説像 Xfce、GNOME 或者 KDE。當用在微型計算機上時，我更傾向於 Xfce 而不是其他的，因為它就是為資源有限的系統設計的，而且你可以通過主題、圖標或者其他東西對它進行定製。

安裝 Xfce ​

安裝 Xfce 桌面環境相當簡單。只需要：

sudo apt install -y --no-install-recommends xfce4 desktop-base lightdm

這就夠了。你現在安裝了 X Window（X11）和 Xfce 了。現在是時候來定製一下環境並且安裝一些核心應用了。

核心應用 ​

目前為止，你已經安裝了 X Window（X11）、Xfce 桌面環境和 LightDM（一個 Xfce 自帶的顯示管理器）。現在，你已經有了一個可以啓動並且正常使用的輕量級的完整系統。不過，在徹底完成之前，我還是喜歡裝一些核心應用。

下面這條命令安裝了一個終端程序、Audacious 音頻播放器、Ristretto 圖像瀏覽器、Mousepad 文本編輯器、File Roller 存檔管理器和 Thunar 容量管理器。

sudo apt install -y --no-install-recommends xfce4-terminal audacious ristretto
sudo apt install -y --no-install-recommends mousepad file-roller thunar-volman

其他可選項 ​

其他一些你可能想安裝的東西，包括一個好的網絡管理器、任務管理器、PDF 閲讀器和通知工具，以及桌面背景管理器、截圖工具、一些新的圖標和光標主題。簡單來説，如果樹莓派是你的首選系統，這些都算是日常工作的一些補充。

sudo apt install -y --no-install-recommends network-manager xfce4-taskmanager xfce4-notifyd
sudo apt install -y --no-install-recommends  xpdf gnome-icon-theme dmz-cursor-theme

下一步該做什麼？ ​

如果一切都正常工作的話，你現在就有一個基於 Xfce 和 Debian Lite 超輕量級操作系統的樹莓派了。我建議現在你去 Xfce 網站上查看其它很酷的好東西，這些你都可以安裝並使用。下一步做什麼完全由你決定！
