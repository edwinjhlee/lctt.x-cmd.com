Linux Mint 20 發佈前一窺 ​

Ubuntu 20.04 LTS 版本發佈了。這對 Linux Mint 用户來説也是一個好消息。一個新的 Ubuntu LTS 版本意味着新的 Linux Mint 主要版本也將很快隨之出現。

為什麼這麼説呢？因為 Linux Mint 是基於 Ubuntu 的長期支持（LTS）版本的。Mint 18 系列是基於 Ubuntu 16.04 LTS，Mint 19 是基於 Ubuntu 18.04 LTS 等等。

與 Ubuntu 不同，Linux Mint 沒有固定的發佈時間表。根據以往的趨勢，我可以做出一個明智的猜測，Linux Mint 20 應該會在今年 6 月發佈。

Linux Mint 20 “Ulyana” 即將推出的新功能 ​

讓我們來看看代號為 Ulyana 的 Linux Mint 20 中提出的一些主要新功能和變化。

1. 提高 Nemo 文件管理器的性能 ​

Nemo 文件管理器計劃中的性能改進之一是它處理縮略圖的方式。你可能還沒有意識到，但縮略圖的生成需要相當多的系統資源（以及磁盤空間）。試着打開一個有幾千張圖片的文件夾，你會發現 CPU 的消耗會上升。

在 Linux Mint 20 中，其目標是優先考慮內容和導航，並儘可能地延遲縮略圖的渲染。這意味着在縮略圖渲染之前，文件夾的內容會以通用圖標顯示出來。這不會讓人覺得賞心悦目，但你會注意到性能的改善。

2. 兩種煥然一新的顏色變體 ​

默認情況下，Linux Mint 是綠色/薄荷色的風格。還有一些其它的顏色點綴。Linux Mint 20 新添加了兩種可愛的的粉紅色和青藍色。

3. 沒有過度偏重於 Snap 包 ​

Ubuntu 20.04 將 snap 包的優先級放在了通常的 apt 包之前。事實上，如果你在 Ubuntu 20.04 中使用 apt 命令安裝 Chromium 瀏覽器時，它會自動安裝 snap 版本。

Linux Mint 團隊顯然對此不滿意，他們確認 Mint 20 將不會安裝 snaps 或 snapd。它還將禁止 apt 使用 snapd。

你仍然可以自己手動安裝 snap 包。只是不會由 apt 來安裝它們。

4. 有了這個新工具，跨網絡共享文件變得很簡單。 ​

Linux Mint 20 將提供一個新的 GUI 工具，可以輕鬆地在本地網絡上共享文件，而無需任何額外的配置。

5. 更好地整合了 Electron 應用程序的桌面 ​

Electron 是一個開源框架，它允許使用 Web 技術構建跨平台的桌面應用程序。有些人稱它為懶惰的方法，因為應用程序運行在 Chromium 瀏覽器之上。然而，這可以讓開發人員輕鬆地將他們的應用程序提供給 Linux（和 macOS）。Linux 上的 Slack 就是眾多這樣的例子之一。

Linux Mint 20 將對 Electron 應用提供更好的支持，並改進系統托盤和桌面通知的集成。

6. 改進的支持多顯示器的比例縮放功能 ​

一個提議的改變是在 Linux Mint 20 中加入支持多顯示器的比例縮放功能。如果你有一個 HiDPI 和非 HiDPI 顯示器的組合，你可以為它們每一個選擇不同的分辨率、刷新率和不同的分數縮放。

在 Mint 20 的登錄屏幕，可以讓你跨多個顯示器拉伸顯示背景。

7. 改進對 Nvidia Optimus 的支持 ​

在 Mint 20 中，Nvidia prime 小程序會顯示 GPU 渲染器。你也可以直接從系統托盤中的菜單中選擇切換到哪塊卡。

你也可以使用 Nvidia “On-Demand” 模式。在這種模式下，將使用英特爾卡來渲染會話。而如視頻播放器或視頻編輯器這樣的兼容應用程序可以在應用程序菜單中打開時使用 Nvidia GPU。

8. 不再支持 32 位 ​

雖然 Ubuntu 18.04 在兩年前就放棄了 32 位 ISO，但 Linux Mint 19 系列一直提供 32 位 ISO 的下載和安裝。

這種情況在 Linux Mint 20 中有所改變。Linux Mint 20 已經沒有 32 位版本了。這是因為 32 位支持從 Ubuntu 20.04 中完全消失了。

還有什麼？ ​

Cinnamon 4.6 桌面版的發佈帶來了很多視覺上的變化。

在 Ubuntu 20.04 中，應該會有一些“引擎蓋下”的變化，比如 Linux Kernel 5.4，取消了 Python 2 的支持，加入 Wireguard VPN 等。

隨着開發的進展，我會在本文中更新更多的功能。敬請期待。
