如何在 Linux 桌面上使用 Gifine 錄製 GIF 動畫？ ​

不用我説，你也知道 GIF 動畫在過去幾年發展迅速。人們經常在線上文字交流時使用動畫增添趣味，同時這些動畫在很多其他地方也顯得非常有用。

在技術領域使用動畫能夠很快的描述出現的問題或者返回的錯誤。它也能很好的展現出一個軟件應用產品的特性。你可以在進行線上座談會或者在進行公司展示時使用 GIF 動畫，當然，你可以在更多的地方用到它。

現在，假設你的電腦桌面上打開了多個應用程序，或者無論出於什麼目的，你想製作一個 GIF 動畫來記錄桌面上一個應用程序窗口的操作過程。你應該怎麼做呢？顯然，你需要一個工具來完成這件事。

如果你正在尋找了這樣一個可以記錄桌面上部分區域的工具，並且它可以自動把錄屏轉化成 GIF 動畫； 現在，本教程會介紹一個 Linux 命令列工具來實現你的需求。

開始之前，你必須知道在本教程中所有的例子都是在 Ubuntu 14.04 上測試過的，它的 Bash 版本是 4.3.11(1) 。

Gifine ​

這個工具的主頁是 Gifine 。它基於 GTK 工具包，是用 MoonScript 使用 lgi 庫編寫的。Gifine 不僅能夠錄屏、創建動畫或視頻，而且能夠用它來把幾個小型動畫或視頻拼接在一起。

引述這個工具的開發者的話：“你可以加載一個視頻幀的目錄或者選擇一個桌面的區域進行錄屏。你加載了一些視頻幀後，可以連續查看它們，並裁剪掉不需要的部分。最終完成錄屏後可以導出為 gif 或者 mp4 文件。”

Gifine 下載/安裝/配置 ​

在指引你下載和安裝 Gifine 之前，應該指出安裝這個工具時需要安裝的依賴包。

首先需要安裝的依賴包是 FFmpeg , 這個軟件包是一種記錄、轉化和流化音頻以及視頻的跨平台解決方案。使用下列命令安裝這個工具;

sudo apt-get install ffmpeg

接下來是圖像處理系統 GraphicsMagick。這個工具的官網説：“它提供了一個穩健且高效的工具和庫的集合，支持讀寫並且可以操作超過 88 種主要的圖像格式，比如：DPX、 GIF、 JPEG、 JPEG-2000、 PNG、 PDF、 PNM 以及 TIFF 等。”

通過下面的命令安裝：

sudo apt-get install graphicsmagick

接下來的需要的工具是 XrectSel 。在你移動鼠標選擇區域的時候，它會顯示矩形區域的座標位置。我們只能通過源碼安裝 XrectSel ，你可以從 這裏 下載它。

如果你下載了源碼，接下來就可以解壓下載的文件，進入解壓後的目錄中。然後，運行下列命令：

./bootstrap

如果 configure 文件不存在，就需要使用上面的命令

./configure --prefix /usr

make

make DESTDIR="$directory" install

最後的依賴包是 Gifsicle 。這是一個命令列工具，可以創建、編輯、查看 GIF 圖像和動畫的屬性信息。下載和安裝 Gifsicle 相當容易，你只需要運行下列命令：

sudo apt-get install gifsicle

這些是所有的依賴包。現在，我們開始安裝 Gifine 。使用下面的命令完成安裝。

sudo apt-get install luarocks

sudo luarocks install --server=http://luarocks.org/dev gifine

請注意第二個命令可能會返回下列錯誤：

No package 'gobject-introspection-1.0' found

你可以用下列命令安裝這個包：

sudo apt-get install libgirepository1.0-dev

然後，再一次運行 'luarocks install' 命令。

Gifine 使用 ​

完成安裝之後可以使用下面的命令運行這個工具：

gifine

這個應用程序的 UI 是這樣的：

這裏你可以進行兩種操作：錄視頻幀或者加載視頻幀。如果你單擊了錄製矩形區域（Record rectange）按鈕，你的鼠標指針處會變成一個 + ，這樣便可以在你的屏幕上選擇一個矩形區域。一旦你選擇了一個區域，錄屏就開始了，錄製矩形區域（Record rectange）按鈕就會變成停止錄製（Stop recording）按鈕。

單擊停止錄製（Stop recording）完成錄屏，會在 Gifine 窗口出現一些按鈕。

用户界面的上半部分顯示已經錄製的視頻幀，你可以使用它下面的滑塊進行逐幀瀏覽。如果你想要刪除第 5 幀之前或第 50 幀之後的所有幀數，你可以使用裁剪左邊（Trim left of） 和裁剪右邊（Trim rigth of）按鈕進行裁剪。也有可以刪除特定幀數和減半刪除幀數的按鈕，當然，你可以重置所有的裁剪操作。

完成了所有的裁剪後，可以使用保存 GIF（Save GIF...） 或保存 MP4（Save MP4...） 按鈕將錄屏保存為動畫或者視頻；你會看到可以設置幀延遲、幀率以及循環次數的選項。

記住，“錄屏幀不會自動清除。如果你想重新加載，可以在初始屏幕中使用加載目錄（load directory）按鈕在 '/tmp' 目錄中找到它們。“

總結 ​

Gifine 的學習曲線並不陡峭 —— 所有的功能都會以按鈕、文本的形式體現出來。

對我來説，最大的問題是安裝 —— 需要一個個安裝它的依賴包，還要處理可能出現的錯誤，這會困擾很多人。否則，從整體上看，Gifine 絕對稱得上是一個不錯的工具，如果你正在尋找這樣的工具，不妨一試。

已經是 Gifine 用户？到目前為止你得到了什麼經驗？在評論區告訴我們。
