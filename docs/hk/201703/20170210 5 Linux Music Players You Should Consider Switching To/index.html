5 款值得嘗試的 Linux 音樂播放器 ​

目前 Linux 上有幾十個音樂播放器，這使得找到一個最好用的變成很困難。之前我們已經回顧了其中的一些播放器，如 Cantata，Exaile，甚至不那麼出名的 Clementine，Nightingale 和 Quod Libet。

在本篇文章中我將涵蓋更多的 Linux 音樂播放器，在某些方面甚至比之前介紹過的那些播放器表現更好。

1、 Qmmp ​

Qmmp 並不是特性最豐富的（或最穩定的） Linux 音樂播放器，但卻是我最喜歡的一款，這也是為什麼我把它放在第一個。我知道有更好的播放器，但我就是喜歡這款並且最常使用它。它確實會崩潰，並且也有許多它不能播放的文件，但不管怎樣我依然最愛它。上圖！

Qmmp 是 Linux 上的 WinAMP。它（相對）輕量並且具有一個像樣的特性集。因為 WinAMP 伴隨着我的成長，並且我很喜歡它的鍵盤快捷鍵，當在 Linux 上有一個像 WinAMP 的播放器對我來説是個驚喜。對於音頻格式，Qmmp 能夠播放大部分流行的格式，如 MPEG1 layer 2/3、Ogg Vorbis 和 Opus、原生的 FLAC/Ogg FLAC、Musepack、WavePack、音軌模組（mod、s3m、it、xm 等等）、ADTS AAC、CD 音頻、WMA、Monkey’s Audio（以及 FFmpeg 庫提供的其他格式）、Midi、SID 和 Chiptune 格式（AY、GBS、GYM、HES、KSS、NSF、NSFE、SAP、SPC、VGM、VGZ 和 VTX）。

2、 Amarok ​

Amarok 是 KDE 的音樂播放器，當然你也可以把它用在其他的桌面環境。它是 Linux 上最古老的音樂播放器之一。這也許是它很流行的原因，雖然我個人並不是非常喜歡它。

Amarok 能播放大量的音頻格式，但它的主要優勢是豐富的插件。這個軟件附帶大量文檔，不過它最近沒有更新。Amarok 也由於與各種 Web 服務，如 Ampache、Jamendo Service、Last.fm、Librivox、MP3tunes、Magnatune 以及 OPML 播客目錄的整合而聞名。

3、 Rhythmbox ​

既然我剛剛提到了 Amarok 和 KDE 音樂播放器，那接下來讓我們轉向 Gnome 的默認音樂播放器， Rhythmbox 。因為它與 Gnome 一起提供，所以你能猜到它是一款流行的軟件。它不僅是一款音樂播放器，同時也是一款音樂管理軟件。它支持 MP3 和 OGG，以及十幾種其他的文件格式，也包括網絡收音機、iPod 服務整合、音頻文件播放、音頻 CD 刻錄和回放、音樂分享以及播客。總而言之，它是款不賴的播放器，但這不意味着你會最喜歡它。試用一下，看看自己是否喜歡。如果不喜歡，就往下看看吧。

4、 VLC ​

雖然 VLC 是以視頻播放器而聞名，但單從它支持最多的解碼器這一點來看，它也是一款非常棒的音樂播放器。它無法播放的文件，你也不太可能能用其他播放器打開。VLC 具有高度定製性，並且擁有很多擴展。它能夠在 Windows，Linux，Mac OS X，Unix，iOS，Android 等等平台運行。

我個人不喜歡 VLC 的一點是它佔用太多資源。並且我曾用它打開過一些文件，但回放質量離一流水準還差的很遠。這個軟件在播放一些其他播放器不難應付的文件時，經常會無故關閉。但很可能與播放器沒多大關係，可能是文件本身的問題。儘管 VLC 不屬於我常用的程序，我仍然由衷的推薦它。

5、 Cmus ​

如果你鍾愛命令列程序，那麼 Cmus 會是你的菜。你能用它來播放 Ogg Vorbis、MP3、FLAC、Opus、Musepack、WavPack、WAV、AAC、MP4、音頻 CD 以及 ffmpeg 支持的所有格式（WMA、APE、MKA、TTA、SHN 等等）和 libmodplug。你也可以用它來播放 Shoutcast 或者 Icecast 的音頻流。它不是特性最豐富的音樂播放器，但它擁有所有的基礎及進階功能。它的主要優勢是非常輕量，並且它的內存需求真的很小。

所有的這些音樂播放器都很棒，都有擅長的方面。我沒辦法説出哪一款是最好的，這更多取決於個人喜好和需要。這些播放器大多要麼做為發行版的默認選項安裝，要麼可以在包管理器中輕鬆找到。只要打開新立得、軟件中心或你的發行版中使用的任意包管理器，搜索並安裝它們。你也可以使用命令列，或只要雙擊從網站上下載的安裝文件。使用何種方法取決於你。

via: https://www.maketecheasier.com/linux-music-players-to-check-out/
