遊戲版 Linux ：Ubuntu GamePack ​

很多 Linux 愛好者喜歡用他們的 Linux 系統玩遊戲，看起來似乎並不需要一個可以玩遊戲的操作系統。UALinux 是一家推廣使用 GNU/Linux 的烏克蘭公司。UALinux 開發了一個 Ubuntu 版本填補了這一空白，並把這個基於 Ubuntu 16.04 的操作系統（OS）命名為 Ubuntu GamePack .

內容 ​

（Linux 上的）遊戲現在已經相當豐富，而遊戲公司宣稱可以訪問超過 22,381 款遊戲。

這個 GamePack 包括 Lutris 和 Steam 兩部分，允許您訪問發行版廠商提供的特定遊戲服務。

對於基於 Windows 的遊戲，可以用 PlayOnLinux，WINE 和 CrossOver 轉換到 Linux 上運行。

對於 DOS 遊戲，您可以在 DosBox 中運行遊戲，這是一個 Linux 的 DOS 模擬器

也安裝了 Sparky APTus Gamer ，可以訪問眾多主機遊戲模擬器。 模擬器包括：

*  AdvanceMENU - AdvanceMAME、 AdvanceMESS、 MAME、 MESS、 xmame、 Raine 以及其他的模擬器的前端 *  Atari800 - Atari 8 位系統、XE 遊戲系統和 Atari 5200 超級系統的模擬器

  • DeSmuME - 任天堂 DS 模擬器
  • Desura - 支持 Windows、Linux 和 X 系統的數字化分發平台 - 在線安裝器
  • DOSBox - 支持 BeOS、Linux、Mac X、OS2 和 Windows 的 DOS 模擬器
  • DOSEMU - 支持 Linux 的 DOS 模擬器
  • ePSXe - 增強的 PSX 模擬器
  • FCEUX - 任天堂娛樂系統（NES）、紅白機（Famicom）和紅白機磁盤系統（FDS）模擬器（仿真器）
  • FS-UAE - 跨平台的 Amiga 模擬器
  • GNOME Video Arcade - 簡化的 MAME 前端
  • Hatari - 支持 Linux 和其他系統的 Atari ST、STE、TT 和 Falcon 模擬器（仿真器）
  • Higan - 任天堂 SNES、NES、Gameboy、Gameboy Color 和 Gameboy Advance 的模擬器
  • Kega_Fusion - 世嘉 SG/SC/SF，主系統、Master System、 Game Gear、 Genesis/Megadrive、 SVP、 Pico、 SegaCD/MegaCD 模擬器
  • MAME - 忠實重現了許多街機效果的硬件模擬器
  • Mednafen - Atari Lynx、GameBoy、NES、SNES、PC-FX、世嘉，索尼遊戲站等系統
  • MESS - 各種主機和計算機遊戲的模擬器
  • Nestopia - 任天堂娛樂系統/紅白機模擬器
  • PCSX - 索尼遊戲站模擬器
  • PlayOnLinux - Wine 前端
  • PPSSPP - PPSSPP 是支持 Windows、MacOS、Linux 和 Android 的開源 PSP 仿真器
  • Steam - Steam 軟件分發服務的啓動器 - 在線安裝程序
  • Stella -用於 SDL 和 X Window 系統的 Atari 2600 仿真器
  • VisualBoyAdvance - 全功能 Game Boy Advance 的模擬器
  • Virtual Jaguar - 用於 Atari 的 infamous Jaguar 主機遊戲的跨平台模擬器
  • Wine - Windows 二進制在 Linux 中運行
  • Winetricks - 一個用於 WINE 的 POSIX shell 腳本的軟件包管理器，能夠很容易安裝一些 Windows軟件
  • Yabause - 世嘉土星32位遊戲機模擬器
  • ZSNES - 超級任天堂娛樂系統模擬器

GamePack 還包括被一些遊戲所必須的 Oracle java 和 Adobe Flash。

如果這是一個你感興趣的操作系統，請繼續閲讀，看看如何下載它。

下載 ​

下載此操作系統鏡像的主要地方是 UALinux 。其下載鏈接是： https://ualinux.com/en/download/category/25-ubuntu-gamepack。由於此鏈接來自國外，所以下載速度很慢。另一種選擇是利用種子文件下載此操作系統。如果你沒有種子下載程序，你可以下載“Transmission”。有了種子下載程序後，你可以通過 https://zooqle.com/ubuntu-gamepack-16-04-i386-amd64-январь-2017-pc-vkn99.html下載。這個種子文件下載可以下載 64 位和 32 位 的 ISO 鏡像文件。

（下載的）文件大小取決於您需要的架構。64 位操作系統 ISO 鏡像文件大小是 2.27 GB，而 32 位的操作系統 ISO 鏡像文件大小是 2.13 GB。   如果下載了你所用的 ISO 鏡像文件，你可以利 ISO 文件創建一個可啓動的 DVD 安裝 GamePack ，或者你可以使用 “USB Image Writer”把 ISO 寫入到優盤，並利用此優盤安裝系統。   硬件需求和 Ubuntu 16.04 保持一致：

  • 2 GHz 雙核處理器或者更高
  • 2 GB 系統內存
  • 25 GB 的磁盤空間
  • 用於安裝介質的 DVD 驅動器或者 USB 端口
  • 在線遊戲系統（如 Steam）需要互聯網接入。

不用説，對於遊戲玩家來説，肯定希望擁有比這些“最低配置”要求更高的系統配置。更多的內存將是一個有把握的選擇，也應該有一款顯存大一點的正統顯卡。

您如果有了硬件系統和系統的特定 32位 或者 64 位 ISO 文件，那麼接下來就可以安裝操作系統了。   ###安裝過程

當你用安裝介質的 ISO 鏡像文件啓動了系統，您就可以準備進行下一步了。

從 Ubuntu Gamepack 介質啓動，你會看到一個類似圖 1 的屏幕。

圖 1

一旦加載完畢，安裝程序就可以繼續安裝了。圖 2 顯示下一屏，可以定製語言，接下來是安裝或者體驗 Gamepack。如果你願意，你可以點擊 “Try Ubuntu” 在不改變硬盤內容的情況下把它加載到內存中來試試它。

圖 2

接下來繼續選擇 ‘Install Ubuntu’ 進行安裝了。

下一個屏幕，如圖 3 所示，你可以在安裝 Ubuntu 時指定是否下載 Ubuntu 的任何更新。您還可以選擇安裝第三方的軟件，如：圖形、WiFi、Flash、 MP3 和其他更新。   當定製好你的系統後，就可以點擊“Continue”   

圖 3

接下來，您必須指定驅動器將如何配置使用，如圖 4 所示。如果您計劃使用整個驅動器，那麼可以更容易地設置，選擇此驅動器即可，然後單擊“Install Now”。

圖 4

接下來在圖 5 中可以根據提示確認所選擇硬件配置。如果同意以上的更改，請單擊“Continue”。   

圖 5

接下來，如圖 6 所示，你將按照提示選擇時區，選擇完畢後點擊“Continue”。

圖 6

接下來，如圖 7 所示一個窗口，需要您設置默認的鍵盤佈局。選擇適合您的正確的佈局後並按“Continue”。

圖 7

最後一個配置屏幕是為您設置一個用户帳户，如圖 8 所示。鍵入您的姓名、計算機名、用户名、密碼並選擇您需要鍵入密碼登錄系統的方式。您還可以為該用户設置加密主目錄。

圖 8

安裝將按指定來設置驅動器。安裝文件將從引導媒體複製到硬盤驅動器，如圖 9 所示。所有內容複製到硬盤並設置好，您將被提示移除引導介質並允許重新啓動系統。

圖 9

重新啓動後，您需要選擇要求用户登錄，會得到類似於圖 10 的屏幕。輸入指定的用户密碼登錄到 Ubuntu Gamepack。

圖 10

當你登錄到 Ubuntu Gamepack 你應該嘗試執行可能需要的軟件升級。打開一個終端並輸入以下兩個命令：

sudo apt-get update && sudo apt-get upgrade

Any updates which are not installed should be installed to bring the GamePack system up-to-date.

任何沒有安裝的更新都應該安裝，以便 GamePack 系統保持更新。

現在，只要看看菜單，找到你想玩的遊戲就行了，打開模擬器或其它像 Steam 的遊戲服務 。

希望你喜歡 Gamepack 並且玩得高興！
