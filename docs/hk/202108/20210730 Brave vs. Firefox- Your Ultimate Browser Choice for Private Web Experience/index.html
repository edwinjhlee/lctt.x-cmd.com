Brave vs. Firefox：你的私人網絡體驗的終極瀏覽器選擇 ​

Web 瀏覽器經過多年的發展，從下載文件到訪問成熟的 Web 應用程序，已經有了長足的發展。

對於很多用户來説，Web 瀏覽器是他們如今完成工作的唯一需要。

因此，選擇合適的瀏覽器就成為了一項重要的任務，它可以幫助改善你多年來的工作流程。

Brave vs. Firefox ​

Brave 和 Mozilla Firefox 是兩個最受到關注隱私的用户和開源愛好者歡迎的 Web 瀏覽器。

考慮到兩者都非常注重隱私和安全，讓我們看看它們到底能提供什麼，以幫助你決定應該選擇哪一個。

以下是我所使用的比較指標：

用户界面 ​

用户界面是使用瀏覽器時的工作流程和體驗的最大區別。

當然，你會有你的個人偏好，但它看起來越容易使用、越輕快、越乾淨，就越好。

首先，Brave 與 Chrome 和微軟 Edge 有着相似的外觀和感受。它提供了一種簡潔的體驗，具有精簡的 UI 元素，所有的基本選項都可以通過瀏覽器菜單訪問。

它也提供了一個暗色主題。恰到好處的動畫使得互動成為一種愉快的體驗。

要定製它，你可以選擇使用 Chrome Web 商店中的主題。

説到 Mozilla Firefox，多年來它經歷了幾次重大的重新設計，其最新的用户界面試圖提供與 Chrome 更接近的體驗。

Firefox 瀏覽器的設計看起來令人印象深刻，並提供了乾淨利落的用户體驗。如果需要的話，你還可以選擇一個暗色主題，此外還有其它幾個主題可供下載使用。

這兩個 Web 瀏覽器都能提供良好的用户體驗。

如果你想要一個熟悉的體驗，但又具有一絲獨特之處，Mozilla Firefox 是一個不錯的選擇。

但是，如果你想獲得更快捷的體驗、更好的動畫感受，Brave 更有優勢。

性能 ​

實際上，我發現 Brave 加載網頁的速度更快，整體的用户體驗感覺很輕快。

Firefox 瀏覽器倒不是非常慢，但它絕對感覺比 Brave 慢。

為了給你一些參考，我還利用 Basemark 運行了一個基準測試，看看事實上是否真的如此。

你可以使用其他的瀏覽器基準測試工具來測試一下，但我用 Basemark 進行了各種測試，所以我們在這篇文章中會用它。

Firefox 瀏覽器成功獲得了 630 的得分，而 Brave 以大約 792 的得分取得了更好的成績。

請注意，這些基準測試是在沒有安裝任何瀏覽器擴展程序的情況下，以默認的瀏覽器設置進行的。

當然，你的分數可能會有所不同，這取決於你在後台進行的工作和你係統的硬件配置。

這是我在 i5-7400、16GB 內存和 GTX 1050ti GPU 配置的桌面電腦上得到的結果。

一般來説，與大多數流行的瀏覽器相比，Brave 瀏覽器是一個快速的瀏覽器。

這兩者都佔用了相當大的系統資源，而且在一定程度上隨着標籤數量、訪問的網頁類型和使用的攔截擴展的種類而變化。

例如，Brave 在默認情況下會主動阻止廣告，但 Firefox 在默認情況下不會阻止顯示廣告。而且，這也影響了系統資源的使用。

瀏覽器引擎 ​

Firefox 瀏覽器在自己的 Gecko 引擎基礎上，使用來自 servo 研究項目 的組件來進行改進。

目前，它基本上是一個改進的 Gecko 引擎，其項目名稱是隨着 Firefox Quantum 的發佈而推出的 “Quantum”。

另一方面，Brave 使用 Chromium 的引擎。

雖然兩者都有足夠的能力處理現代 Web 體驗，但基於 Chromium 的引擎更受歡迎，Web 開發人員通常會在基於 Chrome 的瀏覽器上定製他們的網站以獲得最佳體驗。

另外，有些服務恰好只支持基於 Chrome 的瀏覽器。

廣告 & 追蹤器阻止功能 ​

正如我之前提到的，Brave 在阻止跟蹤器和廣告方面非常積極。默認情況下，它已經啓用了屏蔽功能。

Firefox 瀏覽器也默認啓用了增強的隱私保護功能，但並不阻止顯示廣告。

如果你想擺脱廣告，你得選擇火狐瀏覽器的 “嚴格隱私保護模式”。

也就是説，火狐瀏覽器執行了一些獨特的跟蹤保護技術，包括“全面 Cookie 保護”，可以為每個網站隔離 Cookie 並防止跨站 Cookie 跟蹤。

這是在 Firefox 86 中引入的技術，要使用它，你需要啓用 “嚴格隱私保護模式”。

總的來説，Brave 可能看起來是一個更好的選擇，而 Mozilla Firefox 提供了更好的隱私保護功能。

容器 ​

當你訪問 Facebook 時，Firefox 還提供了一種藉助容器來隔離網站活動的方法。換句話説，它可以防止 Facebook 跟蹤你的站外活動。

你還可以使用容器來組織你的標籤，並在需要時分離會話。

Brave 沒有提供任何類似的功能，但它本身可以阻止跨站追蹤器和 cookie。

獎勵 ​

與 Firefox 不同，Brave 通過屏蔽網絡上的其他廣告來提供自己的廣告網絡。

當你選擇顯示 Brave 的隱私友好型廣告時，你會得到可以放到加密貨幣錢包裏的通證獎勵，而你可以用這些通證來回饋你喜歡的網站。

雖然這是擺脱主流廣告的一個很好的商業策略，但對於不想要任何形式的廣告的用户來説，這可能沒有用。

因此，Brave 以獎勵的形式提供了一個替代方案，即使你屏蔽了廣告，也可以幫助網站發展。如果這是你欣賞的東西，Brave 將是你的一個好選擇。

跨平台可用性 ​

你會發現 Brave 和 Firefox 都有 Linux、Windows 和 macOS 版本，也有用於 iOS 和 Android 的移動應用程序。

對於 Linux 用户來説，Firefox 瀏覽器捆綁在大多數的 Linux 發行版中。而且，你也可以在軟件中心裏找到它。除此之外，還有一個 Flatpak 包可用。

Brave 不能通過默認的軟件庫和軟件中心獲得。因此，你需要按照官方的説明來添加私有倉庫，然後 把 Brave 安裝在你的 Linux 發行版中。

同步 ​

通過 Mozilla Firefox，你可以創建一個 Firefox 賬户來跨平台同步你的所有數據。

Brave 也可以讓你跨平台同步，但你需要能訪問其中一個設備才行。

因此，Firefox 的同步更方便。

另外，你可以通過 Firefox 的賬户訪問它的“虛擬專用網絡”、數據泄露監控器、電子郵件中繼，以及密碼管理器。

服務集成 ​

從一開始 Firefox 就提供了更多的服務集成，包括 Pocket、“虛擬私有網絡”、密碼管理器，還有一些新產品，如 Firefox 中繼。

如果你想通過你的瀏覽器訪問這些服務，Firefox 將是你的方便選擇。

雖然 Brave 確實提供了加密貨幣錢包，但它並不適合所有人。

同樣，如果你喜歡使用 Brave Search，在使用 Brave 瀏覽器時，由於用户體驗的原因，你可能體驗會更順滑。

可定製性 & 安全性 ​

Firefox 瀏覽器在可定製性方面大放異彩。你可以通過眾多選項來調整體驗，也可以控制你的瀏覽器的隱私/安全。

自定義的能力使你可以讓 Firefox 比 Brave 瀏覽器更安全。

而加固 Firefox 瀏覽器是一個我們將討論的單獨話題。略舉一例，Tor 瀏覽器 只是一個定製的 Firefox 瀏覽器。

然而，這並不意味着 Brave 的安全性更低。總的來説，它是一個安全的瀏覽器，但你確實可以通過 Firefox 瀏覽器獲得更多的選擇。

擴展支持 ​

毫無疑問，Chrome Web 商店提供了更多的擴展。

因此，如果你是一個使用大量擴展（或不斷嘗試新擴展）的人，Brave 明顯比 Firefox 更有優勢。

可能 Firefox 的擴展清單不是最大的，但它確實支持大多數的擴展。對於常見的使用情況，你很少能找到一個 Firefox 中沒有的擴展。

你應該選擇那個？ ​

如果你希望儘量兼容現代的 Web 體驗，並希望有更多的擴展，Brave 瀏覽器似乎更合適。

另一方面，Firefox 瀏覽器是日常瀏覽的絕佳選擇，它具有業界首創的隱私功能，併為不懂技術的用户提供了方便的同步選項。

在選擇它們中的任何一個時會有一些取捨。因此，你需要優先考慮你最想要的東西。
