如何選擇一台 Linux 手機 ​

未來取代安卓或 iOS 的可能是 Linux 手機，但如今，有哪些選擇可以嘗試一下呢？

雖然安卓是基於 Linux 內核的，但它經過了大量修改。因此，這意味着它不是一個完全意義上的基於 Linux 的操作系統。

谷歌正在努力使安卓內核更接近主線 Linux 內核，但這仍然是一個遙遠的夢想。

那麼，在這種情況下，如果你正在尋找一款 Linux 手機、一款由 Linux 操作系統驅動的智能手機，有哪些可以選擇呢？

這並不是一個容易做出的決定，因為你的選擇非常有限。因此，我試圖推薦一些最好的、不同於主流選擇的 Linux 手機。

如今你可以使用的頂級 Linux 手機 ​

值得注意的是，這裏提到的 Linux 手機或許無法取代你的安卓或 iOS 設備。因此，在做出購買決定之前，請確保你做了一些背景研究。

注意： 你需要仔細檢查這些 Linux 手機是否可以購買到、預期的發貨日期和使用風險。它們大多數只適合於發燒友或早期試用者。

1、PinePhone ​

PinePhone 是最有性價比和最受歡迎的選擇之一，我覺得它是一個有前途的 Linux 手機。

它並不侷限於單一的操作系統。你可以嘗試使用帶有 Plasma mobile OS 的 Manjaro、UBports、Sailfish OS 等系統。PinePhone 的配置不錯，它包括一個四核處理器和 2G 或3G 的內存。它支持使用可啓動的 microSD 卡來幫助你安裝系統，還可選 16/32GB eMMC 存儲。

其顯示屏是一個基本的 1440×720p IPS 屏幕。你還可以得到特殊的隱私保護，如藍牙、麥克風和攝像頭的斷路開關。

PinePhone 還為你提供了使用六個可用的 pogo 引腳添加自定義的硬件擴展的方式。

其基本版（2GB 內存和 16GB 存儲）默認加載了 Manjaro，價格為 149 美元；而融合版（3GB 內存和 32GB 存儲）價格為 199 美元。

2、Fairphone ​

與這個清單上的其他選擇相比，Fairphone 在商業上是成功的。它不是一款 Linux 智能手機，但它具有定製版的安卓系統，即 Fairphone OS，並且可以選擇 開源安卓系統替代品 之一 /e/ OS。如果你想使用 Linux 操作系統，也有一些社區移植版本，但可能有點碰運氣。

Fairphone 有兩個不同的版本，提供了一些不錯的配置規格。你會發現 Fairphone 3+ 有一個 4800 萬像素的相機傳感器和一個全高清顯示屏。另外，你還會發現先進的高通處理器為該設備提供了動力。

他們專注於製造可持續發展的智能手機，並使用了一定量的回收塑料製造。這也為了方便維修。

因此，它不僅是一個非主流智能手機的選擇，而且如果你選擇了它，你也將為保護環境出了力。

3、Librem 5 ​

Librem 5 是一款非常注重用户隱私的智能手機，同時它採用了開源的操作系統，即 PureOS，並非基於安卓。

它所提供的配置規格還不錯，有 3GB 內存和四核 Cortex A53 芯片組。但是，這無法與主流選擇相競爭。因此，你可能不會覺得它物美價廉。

它的目標是那些對尊重隱私的智能手機感興趣的發燒友。

與其他產品類似，Librem 5 也專注於通過提供用户可更換的電池使手機易於維修。

在隱私方面，你會注意到有藍牙、相機和麥克風的斷路開關。他們還承諾了未來幾年的安全更新。

4、Pro 1X ​

Pro 1X 是一款有趣的智能手機，同時支持 Ubuntu Touch、Lineage OS 和安卓。

它不僅是一款 Linux 智能手機，而且是一款帶有獨立 QWERTY 鍵盤的手機，這在現在是很罕見的。

Pro 1 X 的配置規格不錯，包括了一個驍龍 662 處理器和 6GB 內存。它還帶有一塊不錯的 AMOLED 全高清顯示屏。

它的相機不是特別強大，但在大多數情況下應該是足夠了。

5、Volla Phone ​

Volla Phone 是一個有吸引力的產品，運行在 UBports 的 Ubuntu Touch。

它配備了預製的 “虛擬專用網絡” ，並專注於簡化用户體驗。它的操作系統是定製的，因此，可以快速訪問所有重要的東西，而無需自己組織。

它的配置規格令人印象深刻，包括了一個八核聯發科處理器和 4700 毫安時的電池。你會得到類似於一些最新的智能手機上的設計。

總結 ​

Linux 智能手機不是到處都能買到的，當然也還不適合大眾使用。

因此，如果你是一個發燒友，或者想支持這種手機的發展，你可以考慮購買一台。
