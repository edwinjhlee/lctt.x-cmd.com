Firefox 失去了近 5000 萬用户：令人擔憂的原因 ​

2018 年以來，Mozilla 的火狐瀏覽器正在大面積流失用户，為什麼用户正在遠離它？這是否值得擔心？

Mozilla 的 Firefox 是基於 Chromium 內核的瀏覽器的唯一流行替代品。

它一直是 Linux 用户，以及每個平台上注重隱私的用户的默認選擇。

然而，即便憑藉着大量優勢成為最好的 Web 瀏覽器之一，Firefox 近幾年逐漸流失了它的影響力。

實話實説，我們都不需要藉助統計數據來論證這一點，因為我們當中的許多人就已經轉向其它 Chromium 內核的瀏覽器，或者 Chromium 本身，而不是 Firefox 和 Google Chrome。

不過，我在 Reddit 上偶然發現了由 u/nixcraft 寫的一篇帖子，這篇帖子強調了 Firefox 的用户數從 2018 年來不斷下降的原因。

而令人驚訝的是，這篇帖子的原始信息來源就是 Firefox 的公開數據報表。

根據官方數據統計，在 2018 年底，其報告的（月度）活躍人數達到了 2.44 億。

但，到了 2021 年第二季度，這個數字降到了 1.98 億。

由此可以得出，Firefox 的用户基數下降了高達 4600 萬。

Firefox 的衰落確實令人擔憂，但也很明顯 ​

鑑於在 2021 年以隱私為重點的工具在其用户羣體中大量出現，Mozilla 的 Firefox 用户基數正面臨着不斷下降。

尤其是在 Firefox 設法引入一些業界首創的隱私功能之後。呵，是不是很諷刺？

如果你從來沒有使用過 Firefox，或者已經遷移至其他瀏覽器許久，這篇 關於 Brave 和 Firefox 瀏覽器的比較 表明，到目前為止，Firefox 其實還是一個可靠的瀏覽器。

所以，為什麼許多用户遷移到了 Chromium 內核的瀏覽器，尤其是 Chrome 呢？

我這裏馬上就想到了這幾點：

  • Google Chrome 是 Android 設備上的默認瀏覽器
  • Microsoft Edge 是 Windows 設備上的默認瀏覽器（因此自然就有巨大的市場份額）
  • Google.com（最大的搜索引擎）建議用户安裝 Google Chrome（實際上是一種潛在的反競爭手段）
  • 一些 Web 服務只兼容基於 Chromium 的瀏覽器

除此之外，Firefox 可能也做錯了這幾件事：

  • 不斷以大修的方式來破壞用户體驗
  • 近年來缺乏顯著的性能改進

當然，沒有哪個瀏覽器是完美的，但這是什麼值得擔心的事嗎？嗯，我覺得是的。

為什麼你應該擔憂 ​

Mozilla 的 Firefox 是基於 Chromium 的瀏覽器的唯一可行的競爭品。如果 Firefox 消失了，用户就會失去其它瀏覽器內核的選擇。

我相信你會同意，縱容壟斷是有害的，因此我們需要一些 Google Chromium 引擎的替代品。

實際上，相當多的網站會根據基於 Chromium 的瀏覽器來優化用户體驗。

因此，如果用户量下降的趨勢一直持續下去，我們這樣的用户可能就會被迫適應新的工作流程而改用其他瀏覽器。

即使忽略掉 Google 的 Chromium 引擎在互聯網的主導地位，或者認為 Chrome 之類的瀏覽器在技術上更好，Firefox 仍舊十分珍貴。因為它至少提供了更多的個性化功能，也不斷改進隱私體驗，與其他的都不一樣。

換句話説，我們可能會（被迫）失去許多好的東西，而這一切僅僅是因為其他競爭對手都選擇基於 Chromium 內核，或者從事反競爭活動。

也許，你現在對 Firefox 很失望而想轉向其他瀏覽器。當然，這是你自己的選擇。

但是，待到 Firefox 因為各種使其衰落的因素而徹底消失後，你又該何去何從呢？

因此，為了讓一切保持平衡，我認為我們應該不斷反抗科技巨頭的反競爭行為，並且開始使用 Mozilla Firefox（不論是什麼身份，甚至是作為備用瀏覽器）。

當然，Mozilla 也需要面對這種情況做出什麼措施了。

當他們忙於添加隱私網絡服務、郵件中繼和其他服務集成時，Mozilla 在用户體驗改善方面做的並不成功。

至少，我是這麼認為的。多年來，我一直使用 Firefox 作為主力瀏覽器，但我最終還是會偶爾轉向其他瀏覽器，尤其是每次 Firefox 界面進行大幅度更改後。

你怎麼看？ ​

我很想知道你對此有何想法，以及你認為究竟是什麼因素導致了 Firefox 用户數的下降。

你更喜歡將哪款瀏覽器作為你的主力瀏覽器？在評論區中告訴我吧！
