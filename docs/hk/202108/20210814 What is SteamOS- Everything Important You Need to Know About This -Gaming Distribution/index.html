SteamOS 是什麼？關於這款“遊戲發行版”你所要知道的事 ​

SteamOS 是一款基於 Linux 的操作系統，旨在提供來自 Steam 自己的遊戲商店順滑的遊戲體驗。

雖然它已經存在了許久，但有幾件事你應該知道。

在這篇文章中，我們將回答許多 SteamOS 相關的常見問題。

SteamOS 是什麼？ ​

SteamOS 是由遊戲分發平台 Steam 開發的 Linux 發行版。它並是一款像 Debian、Linux Mint 或者 Ubuntu 那樣的泛用型桌面操作系統，即便你確實可以使用桌面功能。默認情況下，SteamOS 的界面類似於遊戲機，因為 SteamOS 旨在成為專為 Steam 遊戲設備定製的操作系統，如 Steam Machine（已停產）和 Steam Deck。

你確實也可以在任何 Linux 發行版和其他平台安裝 Steam 客户端，但 SteamOS 更是為了提供類似遊戲機的體驗，方便你玩 Steam 上的遊戲。

SteamOS 基於哪個 Linux 發行版？ ​

作為基於 Linux 的系統，SteamOS 最初基於 Debian 8 開發。隨着 Valve 的全新 Steam Deck 掌機發布，SteamOS 的最新版本（SteamOS 3.0）將基於 Arch Linux 開發，因為 Arch 支持滾動更新。

SteamOS 的開發團隊也相信，SteamOS 基於 Arch Linux 更有利於快速推送更新和優化 Steam Deck。

SteamOS 的系統要求 ​

理想情況下，符合以下最低要求的設備都應該可以正常運行 SteamOS：

  • Intel / AMD 的 64 位 CPU
  • 4GB 或更高的運行內存（RAM）
  • 250GB 或更大的磁盤
  • NVIDIA / Intel / AMD 的顯卡
  • 用於安裝介質的 USB 或者 DVD

（LCTT 譯註：本段內容僅針對 SteamOS 2.0。）

SteamOS 能否在你的電腦上正常運作？ ​

SteamOS（2.0 版本）內置了支持特定硬件的驅動程序。

理論上 SteamOS 可以在任何電腦上運行，但目前官方並沒有支持最新的硬件。

SteamOS 只是又一款 Linux 發行版嗎？ ​

SteamOS 嚴格來説已經是現有的 適合遊戲的 Linux 發行版 之一。但與其他發行版不同的是，SteamOS 並不是為了泛用型桌面而設計的。你確實可以安裝 Linux 程序，但 SteamOS 支持的軟件包極為有限。

總之，它並不適合替代普通 Linux 桌面系統。

SteamOS 現在還在積極維護中嗎？ ​

是，但又不是。

SteamOS 基於 Debian 8 許久，目前沒有任何更新。

如果你正期望將 SteamOS 安裝到你的個人設備上，那麼目前公開發布的版本（SteamOS 2.0）已經處於不再維護的狀態。

不過，Valve 目前正在為 Steam Deck 維護 SteamOS 3.0。因此，可能不久 SteamOS 就可以用於你的桌面了。

你是否推薦使用 SteamOS 來玩電腦遊戲嗎？ ​

不推薦。 在 Windows 和其它 Linux 發行版面前，SteamOS 並不是你應該選擇的替代品。

雖然 SteamOS 主要是為遊戲定製的，但在拿它玩遊戲之前，你還需要了解許多注意事項。

所有遊戲都可以在 SteamOS 上玩嗎？ ​

不。 SteamOS 需要依賴 Proton 兼容層才能讓 Windows 平台的遊戲正常運行。

當然，如今藉助同樣的底層技術，在 Linux 裏玩遊戲 已經成為了可能，但至少在我寫這篇文章時，你並不能讓 Steam 上架的所有遊戲都可以在 Linux 中運行。

雖然大部分遊戲都可以運行，但這並不意味着你遊戲庫裏的所有遊戲都能正常遊玩。

如果你想玩 Steam 支持的遊戲，以及僅限於 Linux 平台的遊戲，那還是值得一試的。

SteamOS 是否開源？ ​

是的（SteamOS 2.0）。

SteamOS 操作系統是開源的，你可以在 官方倉庫 中找到源碼。

不過，你用來玩遊戲的 Steam 客户端是專有的。

值得注意的是，SteamOS 3.0 目前仍處於開發階段，因此你無法獲得它的源代碼和任何公開進展。

SteamOS 是否免費使用？ ​

目前你暫時無法找到可供公眾使用的最新版 SteamOS，但它基本上是免費的。基於 Debian 的舊版 SteamOS 可在其 官方網站 上獲取。

我能找到內置 SteamOS 的遊戲主機嗎？ ​

SteamOS 最初是為 Steam Machine 這款 Steam 自家的 PlayStation/Xbox 風格的遊戲機定製的操作系統。2015 年 Steam Machine 發佈後並沒有在市場上獲得成功，最終停產。

目前，唯一一款預裝 SteamOS 的設備是備受矚目的 Steam Deck。

待到 SteamOS 開放針對其它設備的下載後，你就可以看到有硬件廠商銷售預裝 SteamOS 的遊戲設備了。

但，至少目前來看，你不應該相信任何不知名的製造商提供開箱即用的 SteamOS。

下一代 SteamOS 能否使 Linux 成為遊戲的可行選擇？ ​

是的，絕對是的。

Linux 可能不是外界所推薦的遊戲選擇，但如果你樂意的話，你也可以查看 我們所推薦的 Linux 遊戲發行版。最後，如果 SteamOS 下了狠心，讓每款遊戲都能在 Steam Deck 上運行，那麼桌面 Linux 用户也將終於可以體驗到所有曾經不支持的 Steam 遊戲了。
