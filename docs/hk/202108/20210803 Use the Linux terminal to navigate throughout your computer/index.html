使用 Linux 終端瀏覽你的計算機 ​

學習在 Linux 終端中從一個目錄切換到另一個目錄。

要在圖形界面中瀏覽你的計算機上的文件夾，你可能習慣於打開一個窗口來“進入”你的計算機，然後雙擊一個文件夾，再雙擊一個子文件夾，如此反覆。你也可以使用箭頭按鈕或按鍵來回溯。

而要在終端中瀏覽你的計算機，你可以利用 cd 命令。你可以使用 cd .. 回到 上一級 目錄，或者使用 cd ./另一個/文件夾的/路徑 來跳過許多文件夾進入一個特定的位置。

你在互聯網上已經使用的 URL 的概念，實際上直接來自 POSIX。當你瀏覽某個網站的一個特定頁面時，比如 http://www.example.com/tutorials/lesson2.html，你實際上做的是進入 /var/www/imaginarysite/tutorials/ 目錄，並打開一個叫 classic2.html 的文件。當然，你是在 Web 瀏覽器中打開它的，瀏覽器會將所有那些看起來奇怪的 HTML 代碼解釋成漂亮的文本和圖片。但這兩者的思路是完全一樣的。

如果你把你的計算機看成是互聯網（或者把互聯網看成是計算機會更合適），那麼你就能理解如何在你的文件夾和文件中遨遊了。如果從你的用户文件夾（你的家目錄，或簡記為 ~）開始，那麼你想切換到的文件夾都是相對於這個文件夾而言的：

$ cd ~/Documents
$ pwd
/home/tux/Documents

$ cd ..
$ pwd
/home/tux

這需要一些練習，但一段時間後，它會變得比你打開和關閉窗口、點擊返回按鈕和文件夾圖標快得多。

用 Tab 鍵自動補全 ​

鍵盤上的 Tab 鍵可以自動補全你開始輸入的文件夾和文件的名字。如果你要 cd 到 ~/Documents 文件夾，那麼你只需要輸入 cd ~/Doc，然後按 Tab 鍵即可。你的 Shell 會自動補全 uments。這不僅僅是一個令人愉快的便利工具，它也是一種防止錯誤的方法。如果你按下 Tab 鍵而沒有任何東西自動補全，那麼可能你 認為 存在於某個位置的文件或文件件實際上並不存在。即使有經驗的 Linux 用户也會試圖切換到一個當前目錄下不存在的文件夾，所以你可以經常使用 pwd 和 ls 命令來確認你確實在你認為你在的目錄、以及你的當前目錄確實包含了你認為它包含的文件。
