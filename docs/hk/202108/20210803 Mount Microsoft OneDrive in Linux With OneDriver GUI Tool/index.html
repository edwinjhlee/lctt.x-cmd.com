用 OneDriver GUI 工具在 Linux 中掛載微軟 OneDrive ​

在 Windows 上，微軟提供了一個 免費雲存儲服務 OneDrive。它與 Windows 集成，你可以通過你的微軟賬户獲得 5GB 的免費存儲空間。

這在 Windows 上很好用，但和谷歌一樣，微軟也沒有在 Linux 桌面上提供 OneDrive 的本地客户端。

當然，你可以通過瀏覽器訪問你的 OneDrive 數據。除此以外，還有一些其他的方法可以在 Linux 上訪問 OneDrive。

你可以使用像 Insync 這樣的高級服務，或者選擇用 rclone 在 Linux 上使用 OneDrive 這種稍微複雜的命令列方式。

最近，我發現了另一個工具，它稍有不同，使用起來也更簡單。不出所料，它叫 OneDriver。

OneDriver：在你的 Linux 系統上掛載 OneDrive ​

OneDriver 是一個自由而開源的工具，允許你在 Linux 系統上掛載 OneDrive 文件。

請記住，它不會像 OneDrive 在 Windows 系統上那樣同步文件。它將 OneDrive 文件掛載在本地的掛載點上。你通過網絡訪問這些文件。

然而，它確實提供了一種混合方法。你在掛載的 OneDrive 中打開的文件也被下載到系統中。這意味着，你也可以離線訪問打開的文件。如果你沒有連接到互聯網，這些文件將成為只讀。

如果你在本地對文件做任何修改，並且連接到互聯網，它就會反映到 OneDrive 上。

我注意到，在 GNOME 上的 Nautilus 文件管理器中，它會自動下載當前文件夾中的圖像。在我的印象中，它們只有在我打開它們時才會被下載。

另一件事是，Nautilus 一開始會建立縮略圖緩存。OneDriver 在開始的時候可能會覺得有點慢，有點耗費資源，但最終會好起來。

哦！你也可以掛載多個 OneDrive 賬户。

安裝和使用 OneDriver ​

要在 Ubuntu 20.04（和 Linux Mint 20 系列）上安裝 OneDriver，你可以使用 OneDriver 開發者的這個 PPA：

sudo add-apt-repository ppa:jstaf/onedriver
sudo apt update
sudo apt install onedriver

對於 Ubuntu 21.04，你可以下載 其 PPA 中的 DEB 文件 來使用它。

在 Fedora 上，你可以添加這個 COPR：

sudo dnf copr enable jstaf/onedriver
sudo dnf install onedriver

Arch 用户可以在 AUR 中找到它。

安裝後，在菜單中搜索 OneDriver，然後從這裏啓動它。

首次運行時，它會給出一個奇怪的空界面。點擊 “+” 號，選擇一個文件夾或創建一個新的文件夾，OneDrive 會掛載在那裏。在我的例子中，我在我的家目錄下創建了一個名為 One_drive 的新文件夾。

當你選擇了掛載點後，你會被要求輸入你的微軟憑證。

登錄後，你可以在掛載的目錄中看到 OneDrive 的文件。

完成這些後，你可以在應用界面上看到你的 OneDrive 賬户。點擊旁邊的勾按鈕，以在重啓後自動掛載 OneDrive。

總的來説，OneDriver 是一個可以在 Linux 上訪問 OneDrive 的不錯的免費工具。它可能無法像 高級 Insync 服務 那樣提供完整的同步設施，但對於有限的需求來説，它做得不錯。

如果你使用這個漂亮的工具，請分享你的使用經驗。如果你喜歡這個項目，也許可以給它一個 GitHub 上的星標。
