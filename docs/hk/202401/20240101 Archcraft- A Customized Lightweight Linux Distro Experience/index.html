Archcraft：定製的輕量級 Linux 發行版 ​

Archcraft 是一個令人印象深刻的發行版，具有定製的開箱即用體驗。

我們告別了 2023 年，這一年充滿了令人興奮的發行版和應用發佈。就連人工智能也席捲了世界，大型科技公司爭先恐後地想要分得一杯羹。

儘管如此，我們現在必須向前看。😃

我們以一個有趣的、基於 Arch 的 Linux 發行版 “Archcraft” 開啓這一年，它號稱“只是又一個 Linux 發行版”，但只需要 500 MB 內存就能運行。

那麼，讓我們深入看看它能提供什麼。

Archcraft：概述 ⭐ ​

作為一個 輕量級 Linux 發行版，Archcraft 基於 Arch Linux 構建，為用户提供了直接的發行版體驗，不需要太多配置。

大多數東西都是預先配置好的，用户只需安裝，然後可以隨心所欲地使用他們的系統。這要歸功於 Archcraft 的以下主要功能：

  • 滾動發佈週期
  • 對 AUR 的內置支持
  • 預安裝的窗口管理器

初步印象 👨‍💻 ​

為了體驗 Archcraft，我 使用 VirtualBox 將其加載到 虛擬機 上，它能夠立即檢測到它是一個 Arch Linux（64 位）操作系統。

啓動後，出現一個“歡迎”應用，其中包含訪問用户指南或運行安裝的選項，使用 Archcraft 的 兩個安裝程序之一進行安裝。

一個是我們都知道和喜愛的傳統 Calamares 安裝程序，另一個是 ABIF（Arch 基本安裝框架），這是基於命令列的安裝程序，推薦更高級的用户使用。

我使用 Calamares 進行安裝，在安裝過程中，我看到了一個菜單，讓我選擇窗口管理器。我選擇了 “Both”，這樣就安裝了 Openbox 和 bspwm。

📋 我選擇了 Calamares，因為一隻貓跑過我的鍵盤，讓我選擇了它。😼

安裝進行得很順利，我能夠毫無問題地啓動 Archcraft。然後我就開始探索它。

如下所示，桌面屏幕非常簡潔，頂部有一個狀態欄，底部有一個方便的停靠欄，用於啓動應用。

狀態欄也有一些非常簡潔的選項；從左到右，你將找到帶有 Archcraft 徽標的 應用啓動器、工作區切換器、一些系統使用信息、時間/日期、音樂播放器控件、音量滑塊、網絡使用信息和電源按鈕。

當我單擊系統使用信息時，我看到了 Alacritty，它是 Linux 頂級終端模擬器 之一，它向我顯示了所有活動進程，以及它們正在使用哪些資源。

然後我查看了 Archcraft 上的預裝壁紙，令我驚訝的是，Rick 向我豎起了中指。

我必須説，我對此笑得很開心。我現在知道 Morty 的感受了。😂

然後，我查看了應用程序啓動器，裏面裝了很多有用的應用。在如此簡約的發行版中看到這些令人印象深刻。

我還可以搜索命令，甚至瀏覽不同目錄中的文件。

“設置”應用易於使用，並將所有重要選項集中在一處。還能想要什麼呢？

因此，總而言之，我想説 Archcraft 是一個非常 用户友好的基於 Arch 的發行版，很容易上手。隨着開發的進展，它應該會像好酒一樣隨着時間越來越好。

如果你願意，你還可以通過訪問其 GitHub 倉庫 為 Archcraft 的開發做出貢獻。

📥 下載 Archcraft ​

除了其旗艦版本（使用 openbox/bspwm），還提供了兩種其他口味，“Archcraft XFCE” 和 “Archcraft LXDE”。在其 官方網站 上探索它們。
