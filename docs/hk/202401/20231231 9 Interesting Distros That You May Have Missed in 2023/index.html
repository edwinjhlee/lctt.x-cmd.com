你可能錯過的 2023 年 9 個值得關注的 Linux 發行版 ​

你在 2023 年發現了哪些新的發佈版本？有沒有哪個發行版讓你眼前一亮？

在 2023 年我們看到許多現有的 Linux 發行版得到了進步，同時還出現了一些全新的、對不變性等特性有着特殊關注的發行版。

雖然有許多為 高級用户設計的發行版，以及一些 對初學者十分友好的發行版，但在 2023 年仍有一些發行版沒有得到廣泛關注。這些發行版各有特色，不同尋常。

下面，就讓我來介紹下你可能漏掉的 9 個有趣的 Linux 發行版。

1、Zinc ​

Zinc 是一個基於 Ubuntu 的乾淨利落的發行版，它配備了 XFCE 和 Nemo 文件管理器，是一個新推出的產品，致力於提供無需過多配置就能順利使用的體驗。

Zinc

2、Bazzite ​

你是否想過一款專為遊戲打造的 Linux 發行版呢？Bazzite 就是如此，它是一個基於 Fedora 的，專為 Linux 遊戲制定的發行版。

它提供了預裝的英偉達專有驅動程序，用來運行安卓應用的 Waydroid 系統，甚至有為 Steam Deck 專門定製的 ISO。

Bazzite

3、Exodia OS ​

Exodia OS 是一個基於 Arch Linux，專門為網絡安全愛好者設計的 Linux 發行版。這個操作系統可以做到高度的擴展性，由一支網絡安全專家團隊開發，而且預裝了許多網絡安全工具，還支持與微軟 PowerShell 的整合等功能。

Exodia OS 也很可能成為一個不錯的 Kali Linux 替代品！

Exodia OS

4、risiOS ​

risiOS 是另一款基於 Fedora 的優秀髮行版，被 認為 是當前最好的發行版之一。它的目標是提供簡單易用的用户體驗，同時整合了一些引人注目的圖形界面工具。

它內置多款實用應用程序。你還可以添加 “網絡應用”，讓你無需打開瀏覽器就能直接從桌面訪問網站。

risiOS

5、EasyOS ​

EasyOS 的開發者將其描述為一種 “新範式”。這對一個 Linux 發行版來説，似乎是一個相當大的口號。然而，這個宣稱似乎相當可靠。

它是一款對容器友好，且主要使用內存來處理存儲操作的發行版，這也導致了應用和容器的啓動速度非常快。

EasyOS

6、CachyOS ​

CachyOS 是一款基於 Arch 的發行版，適合大多數用户，提供了諸如多重桌面環境、優化過的 Linux 內核版本、及基於 GUI/CLI 的安裝方式等特性。

整體的設計和感覺也較為出色，上述鏈接中的評論中有更多細節。

CachyOS

7、rlxOS ​

是時候介紹一款 不可變的 Linux 發行版 了。rlxOS 是一款獨立發行版，着重於對操作系統的核心和工作部件提供更強控制。

它採用了一種滾動式的 發佈策略，讓你在有重大更新時，無需重新安裝它。rlxOS 也積極關注隱私，原生支持 Flatpaks。

rlxOS

8、carbonOS ​

carbonOS 是另一款 獨立 Linux 發行版，重點是提供直觀的用户體驗。它搭載了 GNOME 桌面環境，包含一些引人注目的特性，如原子式的更新、對 Flatpak/容器的優先支持，以及優秀的使用體驗等。

carbonOS

9、blendOS ​

最後，我們講述 blendOS。這款發行版的目標宏大：一個致力於替代現有的所有 Linux 發行版的發行版，具有不可變的特性。

為了實現這樣的目標，blendOS 支持大多數流行的包管理器，如 apt、dnf、pacman、yum、yay，支持多種桌面環境，並且在桌面上整合了 Flathub 應用商店。

blendOS

至此，這個列表就介紹完了。2023 年對新的發行版來説，是個豐富而忙碌的一年，我已經迫不及待地想看看 2024 年會湧現出怎樣的創新。

💬 那麼你呢，你打算試試這份列表中的哪條？或者，我有沒有漏掉其他值得關注的發行版呢？
