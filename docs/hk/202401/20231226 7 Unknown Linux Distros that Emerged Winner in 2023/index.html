2023 年嶄露頭角的 7 款不為人知的 Linux 發行版 ​

這些發行版在 2023 年引起了人們的關注！

每年我們都會推出一些令人興奮的新發行版，它們嘗試以不同的方式工作，或者提供一些有意義的東西，而不僅僅是“又一個發行版”。

同樣，在 2023 年，我們也有一些引起了大家關注的發行版，即使它們不像一些 最佳 Linux 發行版 那樣流行。

如果你一直關注我們，你可能知道今年也有一些新的 不可變 Linux 發行版。不過，並不是所有的新版都成為了今年的贏家。

那麼，今年有哪些成功的發行版發佈呢？ 讓我重點介紹最好的幾個：

1、Vanilla OS ​

Vanilla OS 是一個基於 Ubuntu 的不可變發行版。

它與其他基於 Ubuntu 的發行版不同。你可以選擇在它上面玩遊戲、創建開發工作環境，或者只是把它作為可靠的日常使用的操作系統。

你可以根據自己的意願配置系統，而不會破壞體驗。

儘管不可變性對許多人來説可能是一個新概念，但 Vanilla OS 提供了易於使用的用户體驗，同時在幕後嘗試有趣的事情。

2、XeroLinux ​

XeroLinux 可以讓新手輕鬆擁有一個漂亮的 Arch Linux 系統。

當然，如果你從未使用過 Linux 發行版，那麼它可能不是你合適的起始選擇。然而，如果你知道在系統上使用 Arch Linux 時需要一些幫助，XeroLinux 可以讓你完美地做到這一點。

它不僅具有開箱即用的出眾外觀，而且還提供了精細定製的體驗。

3、Ubuntu Unity ​

Ubuntu Unity 最初是一個非官方的提供 Unity 的 Ubuntu 重混版，旨在促進 Unity7 桌面環境的復興，如今已成為 Ubuntu 的官方派生版本之一。

它在 2023 年大放異彩，一些 Linux 用户體驗了 Unity 桌面環境（這是 17.10 之前 Ubuntu 的默認環境）。

4、Crystal Linux ​

Crystal Linux 是一個基於 Arch 的發行版，內置 GNOME 桌面。它旨在利用最新技術，同時提供熟悉的用户界面。

如果你想在 Arch 發行版之上體驗定製的 GNOME 體驗，Crystal Linux 就是答案。在撰寫本文時，它仍處於測試階段。

但是，它包含了幫助你開始日常體驗的所有要素（儘管我建議你不要在生產中使用它）。

5、Bazzite ​

Bazzite 是一個基於 Fedora 的 Linux 發行版，可讓你更輕鬆地在桌面或 Steam Deck 上玩遊戲。

通過包含專有的圖形驅動程序和預裝的應用（例如 Mission Center 和 Discover Overlay），它使其成為一種有趣的入門體驗。

你可以根據你的用途（流媒體、遊戲等）選擇要安裝的應用集。

與其他 Linux 發行版相比，它支持各種遊戲硬件，例如 Xbox 控制器、Razer 設備等。

6、Fedora Asahi Remix ​

我們每個人都關注 Asahi Linux 項目，它讓 Linux 在蘋果芯片上成為可能。

而且，從他們的旗艦發行版 Fedora Asahi Remix 開始，他們已經成功做到了這一點。如果你想在最新的蘋果芯片設備上使用 Linux，你可以安裝 Fedora Asahi Remix。

它配備了 KDE Plasma 桌面，可以選擇使用 GNOME 45，以及其他可幫助你入門的自定義選項。

不要忘記，你將獲得只有 Wayland 的體驗，並且支持使用 XWayland 的 X11 應用。

7、CachyOS ​

是的，許多基於 Arch 的發行版確實在 2023 年成功地引起了人們的關注。

CachyOS 就是其中的又一個。

與其他發行版不同，它主要專注於為你提供快速、優化過的 Linux 體驗以及安全性改進。CachyOS 利用高級 BORE 調度程序 和使用優化指令和 LTO 編譯的內核，為你提供最佳性能。

它可能不是一個適合初學者的發行版，但你可以通過選擇各種桌面環境來開始，包括一些 窗口管理器。

總結 ​

通常是那些被低估的發行版，成功地為 Linux 用户帶來了令人興奮和有用的東西。而這些發行版可能是你從來所不知道的。

當然，對於大多數人來説，堅持使用熱門的 Linux 發行版會更安全。然而，如果你想嘗試一些不同的東西來改變，鮮為人知的發行版可能會給你帶來新鮮空氣。
