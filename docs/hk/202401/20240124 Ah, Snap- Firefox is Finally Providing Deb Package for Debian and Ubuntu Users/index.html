好消息！Mozilla 終於官方提供了 Firefox Deb 包 ​

Linux 現在有了 Mozilla Firefox 的新原生包。

我帶來了一個好消息！Mozilla 為 Firefox 推出了新的 .deb 包，這是為 Ubuntu、Debian 以及其他 基於 Debian 的發行版 專門提供的。

現在，你能輕鬆擺脱那些啓動速度讓人困擾的其他包格式（比如説 Snap 包）了。跟隨我一起探索下如何在 Linux 系統中安裝這個新包！

Firefox 的 .deb 包：有何新特性？ ​

這個全新的 Linux 包由 Mozilla 從頭打造，為用户帶來了一個原生的 .deb 包，類似於 Snap 或 Flatpak，直接開箱即用。

此前，所有提供的 Firefox .deb 包都是由與 Mozilla 無關的個人或組織維護的。如今，我們終於迎來了官方版本。

關於新版發佈，Mozilla 補充説：

25 年來，Mozilla 一直以開發自由開源的網絡瀏覽器而聞名。因為 Firefox 瀏覽器是開源的，所以我們能深入瞭解 Firefox 的所有細節，包括如何從中獲得最大優勢。

儘管 Firefox 已經在性能上下足了功夫，使用這個 .deb 包應該能讓你進一步提升利用這些優化的效果。

你也許在想，怎麼更新呢？

事實上，Mozilla 推出了一個新的 APT 倉庫，與 Firefox 的發佈流程同步。這樣，只要 Firefox 有新發布，你就會收到更新，而你只需要重啓 Firefox 就能應用這些更新。

很便捷，不是嗎？我很喜歡他們做的這一做法，我現在正在考慮是否從我現在已安裝的 Flatpak 包切換到 .deb 包，不過這只是我個人的看法。

如何安裝 Firefox 的官方 .deb 包？ ​

想要從 Mozilla 安裝最新 .deb 版本，你可以參考下面的步驟在你的 Ubuntu、Debian 或其他基於 Debian 的系統上操作。

如果你已安裝了 Firefox 的 Snap 版本，就可以運行下列命令將其從系統中完全移除：

🚧 運行這些命令會完全刪除所有關於 Snap 版本的 Firefox 的數據，一定要小心操作！

sudo snap disable firefox
sudo snap remove --purge firefox

接下來，通過運行下面的命令，我們來創建一個存儲 APT 倉庫密鑰的目錄：

sudo install -d -m 0755 /etc/apt/keyrings

現在，導入 Mozilla 的 APT 倉庫簽名密鑰：

wget -q https://packages.mozilla.org/apt/repo-signing-key.gpg -O- | sudo tee /etc/apt/keyrings/packages.mozilla.org.asc > /dev/null

接着，你需要運行以下命令：

gpg -n -q --import --import-options import-show /etc/apt/keyrings/packages.mozilla.org.asc | awk '/pub/{getline; gsub(/^ +| +$/,""); print "\n"$0"\n"}'

確保在運行命令後，指紋匹配此內容：

35BAA0B33E9EB396F59CA838C0BA5CE6DC6315A3

然後，將 Mozilla 的 APT 倉庫添加到你的源列表：

echo "deb [signed-by=/etc/apt/keyrings/packages.mozilla.org.asc] https://packages.mozilla.org/apt mozilla main" | sudo tee -a /etc/apt/sources.list.d/mozilla.list > /dev/null

接下來，需要優先從 Mozilla 倉庫選擇安裝包，你可以通過以下方式設置 APT：

echo '
Package: *
Pin: origin packages.mozilla.org
Pin-Priority: 1000
' | sudo tee /etc/apt/preferences.d/mozilla

最後，運行下列命令，再在提示時輸入 Y 來確認安裝：

sudo apt update && sudo apt install firefox

好了，你此時已經成功在 Linux 系統上安裝了 Firefox 的官方 .deb 包！

這就是我之前提到的最後一步，輸入 Y 後，安裝將會繼續進行，完成安裝後，Firefox 就能在你的系統上看到了。

另外，Firefox 還有安裝各種的語言包的方式，我強烈建議你讀一下 官方文檔瞭解詳情。
