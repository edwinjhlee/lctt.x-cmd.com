Parch Linux：一個簡潔易用的基於 Arch 的發行版 ​

這是一個簡約直觀的基於 Arch 的發行版，無需繁瑣的開箱定製。

最近，我在尋求一些最佳的 基於 Arch 的 Linux 發行版。

在瀏覽過我們過去的報道，並進行了一番搜索之後，我找到了一些頗為出色的發行版。

其中 Archcraft 這款發行版讓我眼前一亮，它極具用户友好性。我希望能有更多類似 Archcraft 的發行版，幸運的是，在幾天前，我發現了 Parch Linux。

一起來看看這個引人入勝的發行版，它“力圖做到美觀、易用、輕量、快捷且穩定”。

Parch Linux：概述 ⭐ ​

Parch Linux 是 一款面向 Linux 新手和經驗者的開源輕量級發行版。它以 Arch Linux 為基礎，為用户提供了清新的體驗。

一些 關鍵特點 包括：

  • 直觀的用户界面
  • 採用滾動更新機制
  • 集成 pacman 包管理器
  • 少量的定製以增強用户體驗

初體驗 👨‍💻 ​

我在 虛擬機 上嘗試安裝了 Parch GNOME 版本，整個過程十分簡單明瞭。點擊 “歡迎” 應用程序的一鍵“安裝 Parch”按鈕即可啓動 Calamares 安裝程序。

儘管外觀和感覺有所不同，但此次的安裝體驗，確是你能從 Calamares 那裏預期的。

我依次設置了時區、鍵盤佈局，然後開始設置用户，輸入常見的信息，如用户名、密碼、計算機的名稱等。

熟悉的 磁盤分區 步驟也隨之而來，諸如 ext4 、 btrfs 、 jfs 、 xfs 、 f2fs 和 reiser 等文件系統皆在選項之中。

所有的設置就位後，安裝程序開始運行，屏幕底部出現了進度條，屏幕中心處是 Parch Linux 的徽標。

安裝完成後，系統重新啓動到了這個美麗的桌面，GNOME 45.1 的全新工作區切換器和更新後的快速設置菜單等新功能一覽無餘。

我在想還有沒有其他的壁紙。你可以在一些帶有 Parch Linux 徽標的壁紙中找到一些有趣的選擇。

不忘記，停靠欄已經對齊到了屏幕的左側。

我還發現 Parch Linux 提供了一套 實用的應用程序，包含諸如 GParted、KeePassXC、Vim，以及 GNOME 的一些常見應用，比如圖像瀏覽、視頻播放、地圖查看等。

這個發行版內置了最新的核心包 Pacman 6.0.2，使用 pacman -Syu 命令即可獲取最新的包。

然後，我注意到了與默認 GNOME 終端不同的終端模擬器。

Parch Linux 採用了 Blackbox 終端，這是一個精緻的 GTK4 終端，用於滿足喜歡極簡終端模擬器的用户。

總的來説，我喜歡 Parch Linux 所提供的一切。

當然，在任何基於 Arch 的發行版上，你都可以自定義所有的東西。

但我認為，Parch Linux 在 Arch Linux 的基礎上打造出更簡單的用户體驗，並且刻意做了一些定製，這對新的 Linux 用户來説，是有益的。

📥 下載 Parch Linux ​

儘管我試驗的是 GNOME 版本，但還有其他更多版本可供選擇。比如 Parch KDE、Parch XFCE、Parch Cinnamon 等。

所以，如果你要獲取 Parch Linux 的任何版本，你可以直接訪問其 官方網站 或者 FOSS Torrents 頁面。
