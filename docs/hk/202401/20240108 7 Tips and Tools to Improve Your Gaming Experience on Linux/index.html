在 Linux 上提升遊戲體驗的 7 個有效建議及工具 ​

下面是一些極好的建議來讓你的 Linux 系統遊戲體驗更上一層樓。

多虧了各種新工具的誕生和 Linux 發行版在用户體驗上的改進，目前已有成千上萬的遊戲可以在 Linux 系統中運行。

無論你是使用主流的 Linux 發行版還是 專為遊戲設計的 Linux 發行版，你都能在 Linux 中享受遊戲的樂趣。

然而，為了得到流暢的遊戲體驗，有一些你需要遵循的工具，技巧和方法。在這篇文章中，我會為你詳細介紹一些。

1、選擇合適的電子遊戲 ​

最首要的一步就是找到一款你熱愛，且在 Linux 上運行流暢的遊戲。

假設你購買或下載了一款最初為 Windows 系統製作的遊戲，可能不論你使用何種工具，都無法在 Linux 系統中成功運行。而你最終只會挫敗地想 “Linux 不適合遊戲” 😔

那麼，該如何避免這類問題呢？

首先，你需要查閲你想要購買或下載的遊戲可以在哪些平台上運行。如果遊戲支持 Linux 或 Steam OS 系統，那就沒問題了。

你還可以查看該遊戲是否已經被添加到 Steam Deck 驗證列表 中。

無論哪種情況，你都可以逛一逛 ProtonDB，在那兒搜索你所關注的遊戲，看看其他用户對其的評價和打分。如果大部分評論聽起來都令人信服，或者説這款遊戲很值得嘗試，那你就可以放心購買或下載了。

2、不要選擇知名度較低的發行版 ​

如果你希望得到社區或者使用 Linux 的朋友們的支持與幫助，請使用那些並非某某人業餘項目的 Linux 發行版。

我建議你從 最佳 Linux 發行版 中作出選擇。

最好的是，選擇一款 長期支持版 以確保穩定的使用體驗。

3、別為 Linux 遊戲搭建頂級配置 PC ​

我知道聽起來有點令人失望。但為了確保最大的兼容性以及無憂的遊戲體驗，最理想的狀況是選用前一代的硬件而不是最新的。

利用這種方式，你還可以享受到大額的折扣，省下大筆錢！別忘了，在決定購買前，還可參閲其他 PC 硬件狂熱愛好者的評論。

這個建議尤其適用於新硬件，那些剛剛發佈沒幾個月的。

當然，你可以冒險嘗試最新的硬件組件。但遊戲可能會崩潰，或以其他方式出問題。而且，你也可能無法獲取到關於這些硬件組件的可靠評論，從而做出明智的選擇。

4、開啓 Steam Play ​

如果你一直都是 Linux 原生遊戲的粉絲，你可能想要 安裝 Steam 遊戲商店 並開啓 Proton 兼容層，在 Linux 上運行那些僅供 Windows 系統的遊戲。

你可以參考我前面提到的 ProtonDB 或者 Steam Deck 的驗證列表，來確認該遊戲是否能在 Linux 上流暢運行。

在安裝了 Steam 以後，如果你想 開啓 Steam Play，可以參照我們的指南操作。

5、沒有 Steam？不必擔憂！ ​

儘管 Steam 提供了跨平台的卓越順暢的遊戲體驗。

但如果你不想僅限於 Steam，還想要能訪問像 Epic 遊戲商店這樣的商店中的遊戲，你可以考慮安裝 Lutris 這樣的工具。

我們為你準備了一份詳盡的指南，來幫助你 在 Linux 下使用 Epic 遊戲商店，並學習使用此工具（和其他替代工具）。

不用擔心，如果你偏愛 GOG 的無數字版權管理（DRM）遊戲，我們同樣為你準備了指南，指導你使用 Lutris 這樣的工具在 Linux 下玩 GOG 遊戲。

6、使用 MangoHud 跟蹤遊戲性能 ​

你是否希望在遊戲中同時監控你的硬件性能和遊戲性能？

藉助 MangoHud，你可以得到一個信息層，顯示 FPS、CPU/GPU 的温度、顯存使用情況等信息，這與在 Windows 下利用英偉達 GeForce Experience 或者 MSI Afterburner 的效果相似。

安裝十分簡單，對於像 Fedora、Debian 和 Arch 這樣的發行版，提供了 Flatpak 和其他形式的二進制文件。你可以在它的 GitHub 頁面 上了解更多關於它的使用方法。

7、已經買好遊戲硬件了嗎？馬上進行配置！ ​

可惜的是，並不是所有的發燒友級遊戲硬件都能在 Linux 下進行詳細調整，至少，不能和在 Windows 下一樣。

例如，你可以使用圖形界面工具 piper 進行遊戲鼠標的配置。

同理，如果你想要控制或者 調整 Razer 設備上的燈光，你可以在這裏找到我們的快速教程進行學習。

不只是設備，需要監控你的 PC 中的一體式水冷（AIO）或者其他散熱硬件嗎？你可以試試 CoolerControl（以前稱為 Coolero）。

監控組件的温度對於獲得流暢的遊戲體驗至關重要。因此，你可以選擇工具如 CoolerControl 和 MangoHud，或者手動監控你的系統資源。

結束語 ​

除了上述的所有建議，你還應該微調遊戲內的設置以在你的系統上獲得沉浸式體驗。當然，這依賴於個人用户的偏好，所以沒有通用的解決方案。

別忘了，如果你是新手，那麼不妨讀一讀我們的 Linux 遊戲指南。
