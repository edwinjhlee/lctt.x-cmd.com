Midori 瀏覽器將整合自己的開源搜索引擎強勢歸來 ​

Midori 網頁瀏覽器還是活躍的，即將到來的更新整合了一個開源搜索引擎！

幾年前，Midori 是一個相當受歡迎的輕量級開源網頁瀏覽器。

有些人認為它已經終止了，不知道它是否還在活動。

好消息是：

作為一個 自由開源的 產品，Midori 網頁瀏覽器是活躍的（在測試階段）、可用的 。

它是一個基於 Chromium 的以 Electron 構建的瀏覽器，但沒有谷歌的東西和隱私保護功能。

💡 2019 年，該項目被終止，並與 Astian 合併為一個移動瀏覽器，當時我們並沒有立即得到消息該瀏覽器是否將捲土重來或保持開源。

此外，在即將到來的瀏覽器更新中，他們計劃將自己的開源搜索引擎 AstianGO 與之整合。🤯

這與 Brave（及其搜索引擎）有些類似，但 Brave Search 不是開源的。

AstianGO：開源搜索引擎 ​

在一個 Reddit 帖子 中，來自 Astian 的某個人宣佈計劃在 Midori 網頁瀏覽器中集成一個開源搜索引擎，即 AstianGO，並在下次更新時加入。

源代碼還沒有發佈，應該可以通過 這個 GitLab 頁面 獲得。

透露的細節不多，但以下是他們提到的內容：

我們已經實現並開發了一個完全開源的搜索引擎，沒有使用第三方的 API，它不存儲用户的 IP 地址，不存儲搜索歷史。我們把這個搜索引擎稱為 AstianGO，這個搜索引擎是用 PHP 開發的，它是自我託管的，儘管它還沒有一個集成的更新系統，人們可以把它部署在他們的服務器上。

該搜索引擎使用來自谷歌、Qwant 和 Brave Search 的數據來提供結果。你可以看看它的 FAQ 來了解它的工作原理。

其他的瀏覽器，有些集成了以隱私為重點的搜索引擎，有些承諾提供隱私保護功能。

當然，這個搜索引擎看起來是一個正在進行的工作。

但是，一個開源的網頁瀏覽器，帶有隱私保護的搜索引擎（也是開源的），可能對大多數用户來説是帶有太多不確定性。

Midori 的目標是通過這一補充來改變這一狀況。

Midori 網頁瀏覽器的狀態 ​

這聽起來不錯，但我認為這並沒有充分的計劃。

有一個 AppImage 和一個 .deb包 可用。它也可用於其他平台。

我試着從它的 下載頁面 安裝 Midori 瀏覽器（.deb 包），但我無法在 Ubuntu 22.04 LTS 上安裝它 🚫

AppImage 文件可以使用 ✅

下載頁面沒有反映出所有的信息來告知 Linux 發行版的支持情況；它只是提到了 Debian x64，並沒有完全翻譯成英文。

所以，我不確定我們是否可以推薦使用該瀏覽器。

當然，考慮到它還在測試階段，你不應該依賴它。你可以瀏覽它的 GitLab 頁面 來了解更多。

思考？ ​

我認為一個新的開源搜索引擎是一件好事。我仍然不確定 Linux 的 Midori 網頁瀏覽器是否可以推薦，我需要通過測試才能在將來推薦它。
