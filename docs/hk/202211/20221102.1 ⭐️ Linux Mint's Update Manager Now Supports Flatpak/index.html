Linux Mint 的更新管理器現在支持 Flatpak ​

Linux Mint 的更新管理器變得更有用了！

Linux Mint 的更新管理器是該發行版的一個重要組成部分，它使新用户可以獲得更為方便簡易的體驗。

最近的一次更新 Linux Mint 21 推出了許多改進，包括更新管理器對 Flatpak 的支持。

你只需要更新你的系統就可以獲得這些改進。

⭐ 更新管理器中支持 Flatpak ​

是的，你沒看錯。這終於實現了。

Flatpak 支持已被添加到更新管理器中，用户只需單擊幾下就能更新 Flatpak 應用程序和運行時。

這將為進一步改善用户體驗的統一更新體驗提供了幫助。

這對新用户來説很有好處，他們不需要熟悉終端命令就能更新 Flatpak。此外，你不需要將 Flatpak 與軟件中心集成（對於 GNOME 而言）。

換句話説，Linux Mint 團隊增強了你使用 Flatpak 應用程序的體驗。

除了對 Flatpak 的支持，本次更新還包括對 Linux Mint 21 的更多增強，這是一個開箱即用的更新。

這些改進包括：

對角欄的改進 ​

Linux Mint 21 中的 角欄Corner Bar 添加了兩項新特性：

  • 能夠在角欄設置左鍵點擊和中鍵點擊的動作；你可以配置它以顯示桌面、工作區選擇器或桌面。
  • 一個允許你將鼠標懸停在角欄上以顯示桌面的新選項。

Nemo 的更新 ​

Nemo 文件管理器做了一些調整；現在，當文件被選中時，只會高亮顯示文件名，而不是圖標和文件名。

如果你還不知道, 你也可以通過我們建議的一些調整來增強 Nemo 文件管理器的體驗：

調整 Linux 中的 Nemo 文件管理器，讓它更好用的 15 種方法

此外，桌面圖標被垂直翻轉，桌面上下文菜單中添加了一個新的快捷方式，可以快速打開顯示設置。

更少的密碼提示 ​

這是很多人可能喜歡的另一個用户體驗調整。

當刪除 Flatpak 或任何快捷方式或本地應用程序時，它將不再要求你輸入密碼。

類似地，在新立得（LCTT 譯註：Linux 下的一個包管理工具）和更新管理器的情況下，將使用 pkexec 來記住密碼。

這樣，用户就不需要每次執行多個操作時都輸入密碼。

你可以瀏覽 Linux Mint 月度Blog 以瞭解其它變化。
