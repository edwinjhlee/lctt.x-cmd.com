Fedora Linux 37 發佈 ​

今天我很興奮地與大家分享成千上萬的 Fedora 項目貢獻者的辛勤工作成果：Fedora Linux 37 版本來了！讓我們看看這個最新版本給你帶來了什麼。一如既往，在從以前的版本升級之前，你應該確保你的系統是完全最新的。迫不及待地想開始了嗎？在你閲讀的同時 下載！

下載 Fedora Linux 37

兩個新的版本 ​

Fedora 的各個“版本Edition”是針對某一特定“市場”的旗艦產品。在 Fedora Linux 37 中，我們增加了兩個新版本：Fedora CoreOS 是你可能還記得的 Atomic Host 的後續版本。從 Project Atomic 和 CoreOS 的初始的工作中汲取營養，它提供了一種自動更新機制，以託管基於容器的工作負載。通過原子更新和簡單的回滾，它為你的基礎設施增加了安全感。

Fedora Cloud 也作為一個版本回來了。雲計算工作組的活動已經重新開始了。Cloud 版本提供了一個很棒的 Fedora 基礎，可以在你喜歡的公共或私有云中運行。AMI 將在本週晚些時候在 AWS 市場上提供，在社區頻道上現在已經可以使用。請查看 此網站 以瞭解可以在其他雲供應商或你自己的雲上運行的鏡像！

桌面的改進 ​

Fedora Workstation 專注於桌面體驗。像往常一樣，Fedora Workstation 採用了最新的 GNOME 版本。GNOME 43 在設置中包括一個新的設備安全面板，為用户提供關於系統中硬件和固件的安全信息。在上一個版本的基礎上，更多的 GNOME 核心應用程序被移植到了最新版本的 GTK 工具包，提供了更好的性能和現代的外觀。

在這個版本中，我們做了一些改變，讓你的安裝變得更精簡。我們把 Firefox 瀏覽器的語言包分成了子包。這意味着如果你不需要本地化，你可以刪除 firefox-langpacks 包。gettext 的運行包（幫助其他包產生多語言文本的工具）被分割成一個單獨的、可選擇的子包。

當然，我們生產的不僅僅是“版本”。Fedora 定製版Spins 和 實驗室Labs 針對的是不同的受眾和使用情況，包括 Fedora Comp Neuro ，它為計算神經科學提供工具，以及像 Fedora LXQt 這樣的桌面環境，它提供一個輕量級桌面環境。而且，別忘了我們的備用架構。ARM AArch64、Power 和 S390x。

系統管理方面的改進 ​

Fedora Server 現在可以生成一個 KVM 磁盤鏡像，使在虛擬機中運行 Server 更加容易。如果你已經禁用了 SELinux（沒關係 —— 我們仍然愛你！），你可以在影響較小的情況下重新開啓它。自動標籤現在以並行方式運行，使 “fixfiles” 操作更快。

為了跟上密碼學的發展，這個版本引入了一個 TEST-FEDORA39 策略，預覽了計劃在未來版本中的變化。新策略之一是不再使用 SHA-1 簽名。研究人員早就知道這種哈希值（就像之前的 MD5 一樣）在許多安全方面的使用是不安全的。

在未來，我們可能會將 SHA-1 從 Fedora Linux 可接受的安全算法列表中移除。（正如 TEST-FEDORA39 這個名字所暗示的那樣，也許最快也要到明年。）不過我們知道如今 SHA-1 哈希值仍然在使用。新的策略可以幫助你現在就測試你的關鍵應用程序，這樣你就可以做好準備。請嘗試一下，並讓我們知道你在哪裏遇到了問題。

説到密碼學，openssl1.1 包現在已經廢棄了。它還能用，但我們建議你更新你的代碼，以使用 openssl 3。

其他更新 ​

樹莓派 4 現在在 Fedora Linux 中得到了正式支持，包括圖形加速。在 ARM 的其他方面，Fedora Linux 37 放棄了對 ARMv7 架構（也被稱為 arm32 或 armhfp）的支持。

在我們的“First”基礎上，我們已經更新了關鍵的編程語言和系統庫包，包括 Python 3.11、Golang 1.19、glibc 2.36 和 LLVM 15。

我們很高興你能試用這個新版本！請到 https://getfedora.org/ 下載。或者如果你已經在運行 Fedora Linux，請按照 簡易升級説明。更多關於 Fedora Linux 37 的新功能的信息，請看 發行説明。

在不太可能發生的情況下... ​

如果你遇到了問題，請訪問我們的 Ask Fedora 用户支持論壇。這裏有一個 常見問題 的分類。

謝謝大家 ​

感謝在這個發佈週期為 Fedora 項目做出貢獻的成千上萬的人。我們很高興 Fedora 社區有你們。
