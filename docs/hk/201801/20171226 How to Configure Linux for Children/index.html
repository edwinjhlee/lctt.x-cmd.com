如何配置一個小朋友使用的 Linux ​

如果你接觸電腦有一段時間了，提到 Linux，你應該會聯想到一些特定的人羣。你覺得哪些人在使用 Linux？別擔心，這就告訴你。

Linux 是一個可以深度定製的操作系統。這就賦予了用户高度控制權。事實上，家長們可以針對小朋友設置出一個專門的 Linux 發行版，確保讓孩子不會在不經意間接觸那些高危地帶。但是相比 Windows，這些設置顯得更費時，但是一勞永逸。Linux 的開源免費，讓教室或計算機實驗室系統部署變得容易。

小朋友的 Linux 發行版 ​

這些為兒童而簡化的 Linux 發行版，界面對兒童十分友好。家長只需要先安裝和設置，孩子就可以完全獨立地使用計算機了。你將看見多彩的圖形界面，豐富的圖畫，簡明的語言。

不過，不幸的是，這類發行版不會經常更新，甚至有些已經不再積極開發了。但也不意味着不能使用，只是故障發生率可能會高一點。

1. Edubuntu ​

Edubuntu 是 Ubuntu 的一個分支版本，專用於教育事業。它擁有豐富的圖形環境和大量教育軟件，易於更新維護。它被設計成初高中學生專用的操作系統。

2. Ubermix ​

Ubermix 是根據教育需求而被設計出來的。Ubermix 將學生從複雜的計算機設備中解脱出來，就像手機一樣簡單易用，而不會犧牲性能和操作系統的全部能力。一鍵開機、五分鐘安裝、二十秒鐘快速還原機制，以及超過 60 個的免費預裝軟件，ubermix 就可以讓你的硬件變成功能強大的學習設備。

3. Sugar ​

Sugar 是為“每個孩子一台筆記本（OLPC）計劃”而設計的操作系統。Sugar 和普通桌面 Linux 大不相同，它更專注於學生課堂使用和教授編程能力。

注意 ：很多為兒童開發的 Linux 發行版我並沒有列舉，因為它們大都不再積極維護或是被長時間遺棄。

為小朋友過篩選內容的 Linux ​

只有你，最能保護孩子拒絕訪問少兒不宜的內容，但是你不可能每分每秒都在孩子身邊。但是你可以設置“限制訪問”的 URL 到內容過濾代理服務器（通過軟件）。這裏有兩個主要的軟件可以幫助你。

1、 DansGuardian ​

DansGuardian，一個開源內容過濾軟件，幾乎可以工作在任何 Linux 發行版上，靈活而強大，需要你通過命令列設置你的代理。如果你不深究代理服務器的設置，這可能是最強力的選擇。

配置 DansGuardian 可不是輕鬆活兒，但是你可以跟着安裝説明按步驟完成。一旦設置完成，它將是過濾不良內容的高效工具。

2、 Parental Control: Family Friendly Filter ​

Parental Control: Family Friendly Filter 是 Firefox 的插件，允許家長屏蔽包含色情內容在內的任何少兒不宜的網站。你也可以設置不良網站黑名單，將其一直屏蔽。

你使用的老版本的 Firefox 可能不支持 網頁插件，那麼你可以使用 ProCon Latte 內容過濾器。家長們添加網址到預設的黑名單內，然後設置密碼，防止設置被篡改。

3、 Blocksi 網頁過濾 ​

Blocksi 網頁過濾 是 Chrome 瀏覽器插件，能有效過濾網頁和 Youtube。它也提供限時服務，這樣你可以限制家裏小朋友的上網時間。

閒趣 ​

給孩子們使用的計算機，不管是否是用作教育，最好都要有一些遊戲。雖然 Linux 沒有 Windows 那麼好的遊戲性，但也在奮力追趕。這有建議幾個有益的遊戲，你可以安裝到孩子們的計算機上。

  • Super Tux Kart（競速卡丁車）
  • GCompris（適合教育的遊戲）
  • Secret Maryo Chronicles（超級馬里奧）
  • Childsplay（教育/記憶力遊戲）
  • EToys（兒童編程）
  • TuxTyping（打字遊戲）
  • Kalzium（元素週期表）
  • Tux of Math Command（數學遊戲）
  • Pink Pony（Tron 風格競速遊戲）
  • KTuberling（創造遊戲）
  • TuxPaint（繪畫）
  • Blinken（記憶力 遊戲）
  • KTurtle（編程指導環境）
  • KStars（天文館）
  • Marble（虛擬地球）
  • KHangman（猜單詞）

結論：為什麼給孩子使用 Linux？ ​

Linux 以複雜著稱。那為什麼給孩子使用 Linux？這是為了讓孩子適應 Linux。在 Linux 上工作給瞭解系統運行提供了很多機會。當孩子長大，他們就有隨自己興趣探索的機會。得益於 Linux 如此開放的平台，孩子們才能得到這麼一個極佳的場所發現自己對計算機的畢生之戀。
