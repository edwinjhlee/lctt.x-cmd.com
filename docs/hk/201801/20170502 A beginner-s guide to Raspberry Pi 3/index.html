樹莓派 3 的新手指南 ​

這個教程將幫助你入門樹莓派 3Raspberry Pi 3。

這篇文章是我的使用樹莓派 3 創建新項目的每週系列文章的一部分。該系列的這個第一篇文章專注於入門，它主要講安裝 Raspbian 和 PIXEL 桌面，以及設置網絡和其它的基本組件。

你需要： ​

  • 一台樹莓派 3
  • 一個 5v 2mAh 帶 USB 接口的電源適配器
  • 至少 8GB 容量的 Micro SD 卡
  • Wi-Fi 或者以太網線
  • 散熱片
  • 鍵盤和鼠標
  • 一台 PC 顯示器
  • 一台用於準備 microSD 卡的 Mac 或者 PC

現在有很多基於 Linux 操作系統可用於樹莓派，你可以直接安裝它，但是，如果你是第一次接觸樹莓派，我推薦使用 NOOBS，它是樹莓派官方的操作系統安裝器，它安裝操作系統到該設備的過程非常簡單。

在你的電腦上從 這個鏈接 下載 NOOBS。它是一個 zip 壓縮文件。如果你使用的是 MacOS，可以直接雙擊它，MacOS 會自動解壓這個文件。如果你使用的是 Windows，右鍵單擊它，選擇“解壓到這裏”。

如果你運行的是 Linux 桌面，如何去解壓 zip 文件取決於你的桌面環境，因為，不同的桌面環境下解壓文件的方法不一樣，但是，使用命令列可以很容易地完成解壓工作。

$ unzip NOOBS.zip

現在，在你的 PC 上插入 Micro SD 卡，將它格式化成 FAT32 格式的文件系統。在 MacOS 上，使用磁盤實用工具去格式化 Micro SD 卡：

在 Windows 上，只需要右鍵單擊這個卡，然後選擇“格式化”選項。如果是在 Linux 上，不同的桌面環境使用不同的工具，就不一一去講解了。在這裏我寫了一個教程，在 Linux 上使用命令列界面 去格式化 SD 卡為 Fat32 文件系統。

在你的卡格式成了 FAT32 格式的文件系統後，就可以去拷貝下載的 NOOBS 目錄的內容到這個卡的根目錄下。如果你使用的是 MacOS 或者 Linux，可以使用 rsync 將 NOOBS 的內容傳到 SD 卡的根目錄中。在 MacOS 或者 Linux 中打開終端應用，然後運行如下的 rsync 命令：

rsync -avzP /path_of_NOOBS /path_of_sdcard

一定要確保選擇了 SD 卡的根目錄，在我的案例中（在 MacOS 上），它是：

rsync -avzP /Users/swapnil/Downloads/NOOBS_v2_2_0/ /Volumes/U/

或者你也可以拷貝粘貼 NOOBS 目錄中的內容。一定要確保將 NOOBS 目錄中的內容全部拷貝到 Micro SD 卡的根目錄下，千萬不能放到任何的子目錄中。

現在可以插入這張 MicroSD 卡到樹莓派 3 中，連接好顯示器、鍵盤鼠標和電源適配器。如果你擁有有線網絡，我建議你使用它，因為有線網絡下載和安裝操作系統更快。樹莓派將引導到 NOOBS，它將提供一個供你去選擇安裝的分發版列表。從第一個選項中選擇 Raspbian，緊接着會出現如下圖的畫面。

在你安裝完成後，樹莓派將重新啓動，你將會看到一個歡迎使用樹莓派的畫面。現在可以去配置它，並且去運行系統更新。大多數情況下，我們都是在沒有外設的情況下使用樹莓派的，都是使用 SSH 基於網絡遠程去管理它。這意味着你不需要為了管理樹莓派而去為它接上鼠標、鍵盤和顯示器。

開始使用它的第一步是，配置網絡（假如你使用的是 Wi-Fi）。點擊頂部面板上的網絡圖標，然後在出現的網絡列表中，選擇你要配置的網絡併為它輸入正確的密碼。

恭喜您，無線網絡的連接配置完成了。在進入下一步的配置之前，你需要找到你的網絡為樹莓派分配的 IP 地址，因為遠程管理會用到它。

打開一個終端，運行如下的命令：

ifconfig

現在，記下這個設備的 wlan0 部分的 IP 地址。它一般顯示為 “inet addr”。

現在，可以去啓用 SSH 了，在樹莓派上打開一個終端，然後打開 raspi-config 工具。

sudo raspi-config

樹莓派的默認用户名和密碼分別是 “pi” 和 “raspberry”。在上面的命令中你會被要求輸入密碼。樹莓派配置工具的第一個選項是去修改默認密碼，我強烈推薦你修改默認密碼，尤其是你基於網絡去使用它的時候。

第二個選項是去修改主機名，如果在你的網絡中有多個樹莓派時，主機名用於區分它們。一個有意義的主機名可以很容易在網絡上識別每個設備。

然後進入到接口選項，去啓用攝像頭、SSH、以及 VNC。如果你在樹莓派上使用了一個涉及到多媒體的應用程序，比如，家庭影院系統或者 PC，你也可以去改變音頻輸出選項。缺省情況下，它的默認輸出到 HDMI 接口，但是，如果你使用外部音響，你需要去改變音頻輸出設置。轉到樹莓派配置工具的高級配置選項，選擇音頻，然後選擇 “3.5mm” 作為默認輸出。

[小提示：使用箭頭鍵去導航，使用回車鍵去選擇]

一旦應用了所有的改變， 樹莓派將要求重新啓動。你可以從樹莓派上拔出顯示器、鼠標鍵盤，以後可以通過網絡來管理它。現在可以在你的本地電腦上打開終端。如果你使用的是 Windows，你可以使用 Putty 或者去讀我的文章 - 怎麼在 Windows 10 上安裝 Ubuntu Bash。

在你的本地電腦上輸入如下的 SSH 命令：

ssh pi@IP_ADDRESS_OF_Pi

在我的電腦上，這個命令是這樣的：

ssh pi@10.0.0.161

輸入它的密碼，你登入到樹莓派了！現在你可以從一台遠程電腦上去管理你的樹莓派。如果你希望通過因特網去管理樹莓派，可以去閲讀我的文章 - 如何在你的計算機上啓用 RealVNC。

在該系列的下一篇文章中，我將講解使用你的樹莓派去遠程管理你的 3D 打印機。
