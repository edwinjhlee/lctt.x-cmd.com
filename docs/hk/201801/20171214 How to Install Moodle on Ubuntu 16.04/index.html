怎樣在 Ubuntu 下安裝 Moodle（“魔燈”） ​

這是一篇關於如何在 Ubuntu 16.04 上安裝 Moodle （“魔燈”）的逐步指南。Moodle （模組化面向對象動態學習環境Modular-object-oriented dynamic learning environment的縮寫）是一種自由而開源的學習管理系統，為教師、學生和管理員提供個性化的學習環境。Moodle 由 Moodle 項目創建，由 Moodle 總部統一領導和協調。

Moodle 有很多非常實用的功能，比如：

  • 現代和易於使用的界面
  • 個性化儀表盤
  • 協作工具和活動
  • 一體式日曆
  • 簡單的文本編輯器
  • 進度跟蹤
  • 公告
  • 不勝枚舉…

在本教程中，我們將指導您在 Ubuntu 16.04 VPS 上利用 Apache web 服務器、MySQL 和 PHP 7 安裝最新版本的 Moodle。（LCTT 譯註：在 Ubuntu 的後繼版本上的安裝也類似。）

1、 通過 SSH 登錄 ​

首先，利用 root 用户通過 SSH 登錄到 Ubuntu 16.04 VPS：

ssh root@IP_Address -p Port_number

2、 更新操作系統軟件包 ​

運行以下命令更新系統軟件包並安裝一些依賴軟件：

apt-get update && apt-get upgrade
apt-get install git-core graphviz aspell

3、 安裝 Apache Web 服務器 ​

利用下面命令，從 Ubuntu 軟件倉庫安裝 Apache Web 服務器：

apt-get install apache2

4、 啓動 Apache Web 服務器 ​

一旦安裝完畢，啓動 Apache 並使它能夠在系統啓動時自動啓動，利用下面命令：

systemctl enable apache2

5、 安裝 PHP 7 ​

接下來，我們將安裝 PHP 7 和 Moodle 所需的一些額外的 PHP 模組，命令是：

apt-get install php7.0 libapache2-mod-php7.0 php7.0-pspell php7.0-curl php7.0-gd php7.0-intl php7.0-mysql php7.0-xml php7.0-xmlrpc php7.0-ldap php7.0-zip

6、 安裝和配置 MySQL 資料庫服務器 ​

Moodle 將大部分數據存儲在資料庫中，所以我們將利用以下命令安裝 MySQL 資料庫服務器：

apt-get install mysql-client mysql-server

安裝完成後，運行 mysql_secure_installation 腳本配置 MySQL 的 root 密碼以確保 MySQL 安全。

以 root 用户登錄到 MySQL 服務器，併為 Moodle 創建一個數據庫以及能訪問它的用户，以下是具體操作指令：

mysql -u root -p
mysql> CREATE DATABASE moodle;
mysql> GRANT ALL PRIVILEGES ON moodle.* TO 'moodleuser'@'localhost' IDENTIFIED BY 'PASSWORD';
mysql> FLUSH PRIVILEGES;
mysql> \q

一定要記得將上述 PASSWORD 替換成一個安全性強的密碼。

7、 從 GitHub 倉庫獲取 Moodle ​

接下來，切換當前工作目錄，並從 GitHub 官方倉庫中複製 Moodle：

cd /var/www/html/
git clone https://github.com/moodle/moodle.git

切換到 moodle 目錄，檢查所有可用的分支：

cd moodle/
git branch -a

選擇最新穩定版本（當前是 MOODLE_34_STABLE ），運行以下命令告訴 git 哪個分支可以跟蹤或使用：

git branch --track MOODLE_34_STABLE origin/MOODLE_34_STABLE

並切換至這個特定版本：

git checkout MOODLE_34_STABLE

Switched to branch 'MOODLE_34_STABLE'
Your branch is up-to-date with 'origin/MOODLE_34_STABLE'.

為存儲 Moodle 數據創建目錄：

mkdir /var/moodledata

正確設置其所有權和訪問權限：

chown -R www-data:www-data /var/www/html/moodle
chown www-data:www-data /var/moodledata

8、 配置 Apache Web 服務器 ​

使用以下內容為您的域名創建 Apache 虛擬主機：

nano /etc/apache2/sites-available/yourdomain.com.conf

 	ServerAdmin admin@yourdomain.com
 	DocumentRoot /var/www/html/moodle
 	ServerName yourdomain.com
 	ServerAlias www.yourdomain.com

	Options Indexes FollowSymLinks MultiViews
	AllowOverride All
	Order allow,deny
	allow from all

 	ErrorLog /var/log/httpd/yourdomain.com-error_log
 	CustomLog /var/log/httpd/yourdomain.com-access_log common

保存文件並啓用虛擬主機：

a2ensite yourdomain.com

Enabling site yourdomain.com.
To activate the new configuration, you need to run:
 service apache2 reload

最後，重啓 Apache Web 服務器，以使配置生效：

service apache2 reload

9、 接下來按照提示完成安裝 ​

現在，點擊 “http://yourdomain.com”（LCTT 譯註：在瀏覽器的地址欄裏輸入以上域名以訪問 Apache WEB 服務器），按照提示完成 Moodle 的安裝。有關如何配置和使用 Moodle 的更多信息，您可以查看其官方文檔。

如果您使用我們的優化的 Moodle 託管主機服務，您不必在 Ubuntu 16.04 上安裝 Moodle，在這種情況下，您只需要求我們的專業 Linux 系統管理員在 Ubuntu 16.04 上安裝和配置最新版本的 Moodle。他們將提供 24×7 及時響應的服務。（LCTT 譯註：這是原文作者——一個主機託管商的廣告~）

PS. 如果你喜歡這篇關於如何在 Ubuntu 16.04 上安裝 Moodle 的帖子，請在社交網絡上與你的朋友分享，或者留下你的回覆。謝謝。
