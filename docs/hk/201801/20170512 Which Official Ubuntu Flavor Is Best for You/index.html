哪一種 Ubuntu 官方版本最適合你？ ​

Ubuntu Budgie 只是為數不多的 Ubuntu 官方認可的特色版本flavor之一。Jack Wallen（傑克沃倫）將講述一下它們之間的重要的區別。

Ubuntu Linux 有一些官方認可的特色版本flavor，還有一些衍生版本derivative distribution：

  • Kubuntu - KDE 桌面版 Ubuntu
  • Lubuntu - LXDE 桌面版 Ubuntu
  • Mythbuntu - MythTV 版 Ubuntu
  • Ubuntu Budgie - Budgie 桌面版 Ubuntu
  • Xubuntu - Xfce 桌面版 Ubuntu

就在不久前（本文寫於 2017 年 5 月），官方的 Ubuntu Linux 包括了其自己打造的 Unity 桌面版和第六個被認可的特色版本：Ubuntu GNOME —— Ubuntu 的 GNOME 桌面環境。

當馬克·沙特爾沃思Mark Shuttleworth決定要否決 Unity 的時候，這個選擇對於 Canonical 來説就很明顯了——是為了讓 GNOME 成為 Ubuntu Linux 的官方桌面環境。從 Ubuntu 18.04（2018 年 4 月）開始，我們將僅剩下這個官方發行版和四種官方認可的特色版本。(LCTT 譯註：從 17.10 就沒有 Unity 版本了）

對於那些已經融入 Linux 社區的人來説，就像一些非常簡單的數學問題一樣——你知道你喜歡哪個 Linux 桌面，在 Ubuntu、Kubuntu、Lubuntu、Mythbuntu、Ubuntu Budgie 和 Xubuntu 之間做出選擇不要太容易了。但那些還沒有被灌輸 Linux 思想的人可不會認為這是一個如此簡單的決定。

為此，我認為幫助新用户決定選擇對他們來説哪個特色版本最好可能是至關重要的。畢竟，從一開始就選擇一個不合適的發行版是一種不太理想的體驗。

因此，如果你正考慮選擇哪個 Ubuntu 的特色版本，如果你想讓你的體驗儘可能地不痛苦，請繼續往下看。

Ubuntu ​

我將從 Ubuntu 的官方特色版本開始。我會有點扭曲時間線，跳過 Unity 不談，直接進入即將到來的基於 GNOME 的發行版（LCTT 譯註：本文寫作半年後發佈的 Ubuntu 17.10 是第一個官方的 GNOME Ubuntu 發行版）。除了 GNOME 是一個極其穩定且易於使用的桌面環境之外，選擇官方的特色版本的一個很好的理由是：支持服務。這個 Ubuntu 的官方特色版本是由 Canonical 提供商業支持的。您可以每年花費 $150.00 為 Ubuntu 桌面版購買 官方支持服務。當然，對於這一級別的支持，最少要購買 50 個桌面的支持服務。而對於個人來説，最好的支持是 Ubuntu 論壇，Ubuntu 文檔，或者社區幫助維基。

在商業支持之外，選擇 Ubuntu 官方特色版本的原因是，如果你想要一個現代的、功能齊全的桌面的話，它是非常可靠和易用的。 GNOME 被設計成完美地適合桌面和筆記本電腦桌面的平台（圖 1）。與它的前代的 Unity 不同，GNOME 可以更方便地定製以適合你的需要。如果你不喜歡擺弄桌面，不要擔心，GNOME 工作的很好。事實上，GNOME 開箱即用的體驗也許是市場上最優秀的桌面之一，甚至可以與 Mac OS X 媲美（或者更好）。如果修補和調整是你的主要的興趣所在，你會發現 GNOME 在一定程度上是受限制的。 GNOME 調整工具和GNOME Shell 擴展只會比你想要的提供的更多。

圖 1：帶有 Unity 味道 GNOME 桌面也許就會是我們在 Ubuntu 18.04 上所看到的。

Kubuntu ​

K 桌面環境K Desktop Environment（即 KDE）與 GNOME 長期並存，有時被誤解為一個較少見的桌面。但隨着 KDE Plasma 5 的發佈，情況發生了變化。KDE 已經成為一個強大的、高效的、穩定的桌面，它正在一步步地成為最好的桌面系統。但是你為什麼要選擇 Kubuntu 而不是 Ubuntu 官方版本呢？這個問題的答案很簡單——你習慣了 Windows XP / 7 桌面模式。開始菜單、任務欄、系統托盤，等等，KDE 擁有這些乃至更多，所有的這些都會讓你覺得你在使用過去和現在的最好的技術。事實上，如果你正在尋找一款最像 Windows 7 的 Ubuntu 官方特色版本，除了它你就找不到更好的了。

Kubuntu 的優點之一是，你會發現它比你以前使用過的任何 Windows 版本都靈活，而且同樣可靠/友好。不要覺得因為 KDE 提供的桌面有點類似於 Windows 7，它就沒有現代特色。事實上，Kubuntu 對類 Windows 7 的界面進行了很好的處理，並更新了它以滿足更現代的審美（圖 2）。

圖 2: Kubuntu 在老式用户體驗上提供了現代感受。

Ubuntu 官方版本並不是提供桌面支持的唯一特色版本。Kubuntu 用户也可以購買商業支持。注意，它不便宜，一個小時的支持服務將花費你 103.88 美元。

Lubuntu ​

如果你正在尋找一個易於使用的桌面，要非常快（以便舊硬件感受如新），而且要比你曾經使用的任何桌面都靈活，那麼 Lubuntu 就是你想要的。對 Lubuntu 唯一的警告是，你看到更加空蕩的桌面，也許你已經習慣了。Lubuntu 使用 LXDE 桌面，並包含一個延續了輕量級主題的應用程序列表。因此，如果你想在桌面上尋找極速快感的體驗，Lubuntu 可能是個不錯的選擇。

然而，對 Lubuntu 有一個提醒，對於一些用户來説，這可能會影響他們選擇它。由於 Lubuntu 的低配，其預先安裝的應用程序可能無法勝任任務。例如，取而代之成熟的辦公套件的是，您將發現 AibWord 字處理器和 Gnumeric 圖表工具。別誤會，這兩個都是很好的工具。然而，如果你正在尋找一款適合商業使用的軟件，你會發現它們缺乏友好的支持。另一方面，如果你想要安裝更多的以工作為中心的工具（例如 LibreOffice），Lubuntu 包括了新立得軟件包管理器可以簡化第三方軟件的安裝。

和有限的默認軟件一起，Lubuntu 提供了一個簡單易用的桌面（圖 3），任何人都可以馬上開始使用，幾乎沒有學習曲線。

圖 3：Lubuntu 軟件的貧乏，換來的是速度和簡單性。

Mythbuntu ​

Mythbuntu 在這裏是一種奇怪的鳥，因為它不是真正的桌面變體。相反，Mythbuntu 是 Ubuntu 多媒體工場設計的一個特殊的特色版本。使用 Mythbuntu 需要電視調諧器和電視輸出卡。而且，在安裝過程中，還需要採取一些額外的步驟（如選擇如何設置前端/後端，以及設置您的紅外遙控器）。

如果您碰巧擁有該硬件（以及創建您自己的由 Ubuntu 驅動的娛樂系統的願望），Mythbuntu 就是您想要的發行版。一旦安裝了 Mythbuntu，就會提示您通過設置採集卡、錄製設置、視頻源和輸入連接（圖4）。

圖 4：準備設置 Mythbuntu。

Ubuntu Budgie ​

Ubuntu Budgie 是一個新加入到官方特色版本列表的小成員。它使用 Budgie 桌面，這是一個非常漂亮和現代的 Linux 操作系統，它可以滿足任何類型的用户。Ubuntu Budgie 的目標是創建一個優雅簡潔的桌面界面。而這個任務已經完成了。如果你正在尋找一個漂亮的桌面，想在非常穩定的 Ubuntu Linux 平台上工作，你只需看看 Ubuntu Budgie 就可以了。

在 Ubuntu 上添加這個特殊的版本到官方版本列表中是 Canonical 的一個聰明的舉動。隨着 Unity 的消失，他們需要一個能提供 Unity 的優雅的桌面。Budgie 的定製非常簡單，其所包含的軟件列表可以讓你立即開始工作和上網瀏覽。

而且，與許多用户在 Unity 中遇到的學習曲線不同，Ubuntu Budgie 的開發者/設計者們做了一件非常出色的工作，讓我們保有 Ubuntu 的熟悉感。點擊“開始”按鈕，會顯示一個相當標準的應用程序菜單。Budgie 還包括一個易於使用的 Dock（圖 5），它包含了用於快速訪問的應用程序啓動器。

圖 5：這是一個漂亮的桌面。

在 Ubuntu Budgie 中發現的另一個很好的功能是側邊欄可以快速顯示和隱藏。這個側邊欄包含了小應用和通知。有了這個功能，你的桌面就會變得非常有用，同時還免除雜亂。

最後，如果你在尋找一個稍有不同，但又非常現代的桌面——其特色與功能在其他發行版本中找不到 —— 那麼 Ubuntu Budgie 就是你想要的。

Xubuntu ​

另一種很好地提供了低配支持的 Ubuntu 官方特色版本是 Xubuntu。Xubuntu 和 Lubuntu 的區別在於， Lubuntu 使用 LXDE 桌面，而 Xubuntu 使用Xfce。差別就是這個輕量級桌面，它比 Lubuntu 更具可配置性，也包括了更適合商務的 LibreOffice 辦公套件。

Xubuntu 對任何人來説都是開箱即用的，無論是否有經驗。但是，不要認為看起來熟悉就意味着這個 Ubuntu 特色版本可以讓你馬上隨心所欲。如果你既想要 Ubuntu 傳統的開箱即用，也想要經過大量調整成為一個更現代的桌面， 那麼 Xubuntu 就是你想要的。

我一直很喜歡 Xubuntu 的一個非常方便的附加功能（就像之前的 Enlightenment），就是通過在桌面的任何地方右鍵點擊打開“開始”菜單（圖 6），這樣可以非常有效的提高使用效率。

圖 6：Xubuntu 可以通過右鍵點擊桌面的任何地方來打開“開始”菜單。

選擇由你 ​

總有一款 Ubuntu 的特色版本可以滿足所需——選擇哪一個取決於你。你自己可以問一下這些問題，例如:

  • 你有什麼需要？
  • 你喜歡與哪種類型的桌面交互？
  • 你的硬件老化了嗎？
  • 你喜歡 Windows XP / 7的感覺嗎？
  • 你想要一個多媒體系統嗎？

你對以上問題的回答將會很好地決定 Ubuntu 的哪一種特色版本適合你。好消息是，任何選擇都不能算錯。
