10 款 Linux 平台上最好的 LaTeX 編輯器 ​

簡介：一旦你克服了 LaTeX 的學習曲線，就沒有什麼比 LaTeX 更棒了。下面介紹的是針對 Linux 和其他平台的最好的 LaTeX 編輯器。

LaTeX 是什麼？ ​

LaTeX 是一個文檔製作系統。與純文本編輯器不同，在 LaTeX 編輯器中你不能只寫純文本，為了組織文檔的內容，你還必須使用一些 LaTeX 命令。

LaTeX 編輯器一般用在出於學術目的的科學研究文檔或書籍的出版，最重要的是，當你需要處理包含眾多複雜數學符號的文檔時，它能夠為你帶來方便。當然，使用 LaTeX 編輯器是很有趣的，但它也並非總是很有用，除非你對所要編寫的文檔有一些特別的需求。

為什麼你應當使用 LaTeX? ​

好吧，正如我前面所提到的那樣，使用 LaTeX 編輯器便意味着你有着特定的需求。為了搗騰 LaTeX 編輯器，並不需要你有一顆極客的頭腦。但對於那些使用一般文本編輯器的用户來説，它並不是一個很有效率的解決方法。

假如你正在尋找一款工具來精心製作一篇文檔，同時你對花費時間在格式化文本上沒有任何興趣，那麼 LaTeX 編輯器或許正是你所尋找的那款工具。在 LaTeX 編輯器中，你只需要指定文檔的類型，它便會相應地為你設置好文檔的字體種類和大小尺寸。正是基於這個原因，難怪它會被認為是 給作家的最好開源工具 之一。

但請務必注意： LaTeX 編輯器並不是自動化的工具，你必須首先學會一些 LaTeX 命令來讓它能夠精確地處理文本的格式。

針對 Linux 平台的 10 款最好 LaTeX 編輯器 ​

事先説明一下，以下列表並沒有一個明確的先後順序，序號為 3 的編輯器並不一定比序號為 7 的編輯器優秀。

1、 LyX ​

LyX 是一個開源的 LaTeX 編輯器，即是説它是網絡上可獲取到的最好的文檔處理引擎之一。LyX 幫助你集中於你的文章，並忘記對單詞的格式化，而這些正是每個 LaTeX 編輯器應當做的。LyX 能夠讓你根據文檔的不同，管理不同的文檔內容。一旦安裝了它，你就可以控制文檔中的很多東西了，例如頁邊距、頁眉、頁腳、空白、縮進、表格等等。

假如你正忙着精心撰寫科學類文檔、研究論文或類似的文檔，你將會很高興能夠體驗到 LyX 的公式編輯器，這也是其特色之一。 LyX 還包括一系列的教程來入門，使得入門沒有那麼多的麻煩。

2、 Texmaker ​

Texmaker 被認為是 GNOME 桌面環境下最好的 LaTeX 編輯器之一。它呈現出一個非常好的用户界面，帶來了極好的用户體驗。它也被稱之為最實用的 LaTeX 編輯器之一。假如你經常進行 PDF 的轉換，你將發現 TeXmaker 相比其他編輯器更加快速。在你書寫的同時，你也可以預覽你的文檔最終將是什麼樣子的。同時，你也可以觀察到可以很容易地找到所需要的符號。

Texmaker 也提供一個擴展的快捷鍵支持。你有什麼理由不試着使用它呢？

3、 TeXstudio ​

假如你想要一個這樣的 LaTeX 編輯器：它既能為你提供相當不錯的自定義功能，又帶有一個易用的界面，那麼 TeXstudio 便是一個完美的選擇。它的 UI 確實很簡單，但是不粗糙。 TeXstudio 帶有語法高亮，自帶一個集成的閲讀器，可以讓你檢查參考文獻，同時還帶有一些其他的輔助工具。

它同時還支持某些酷炫的功能，例如自動補全，鏈接覆蓋，書籤，多游標等等，這使得書寫 LaTeX 文檔變得比以前更加簡單。

TeXstudio 的維護很活躍，對於新手或者高級寫作者來説，這使得它成為一個引人注目的選擇。

4、 Gummi ​

Gummi 是一個非常簡單的 LaTeX 編輯器，它基於 GTK+ 工具箱。當然，在這個編輯器中你找不到許多華麗的選項，但如果你只想能夠立刻着手寫作， 那麼 Gummi 便是我們給你的推薦。它支持將文檔輸出為 PDF 格式，支持語法高亮，並幫助你進行某些基礎的錯誤檢查。儘管在 GitHub 上它已經不再被活躍地維護，但它仍然工作地很好。

5、 TeXpen ​

TeXpen 是另一個簡潔的 LaTeX 編輯器。它為你提供了自動補全功能。但其用户界面或許不會讓你感到印象深刻。假如你對用户界面不在意，又想要一個超級容易的 LaTeX 編輯器，那麼 TeXpen 將滿足你的需求。同時 TeXpen 還能為你校正或提高在文檔中使用的英語語法和表達式。

6、 ShareLaTeX ​

ShareLaTeX 是一款在線 LaTeX 編輯器。假如你想與某人或某組朋友一同協作進行文檔的書寫，那麼這便是你所需要的。

它提供一個免費方案和幾種付費方案。甚至來自哈佛大學和牛津大學的學生也都使用它來進行個人的項目。其免費方案還允許你添加一位協作者。

其付費方案允許你與 GitHub 和 Dropbox 進行同步，並且能夠記錄完整的文檔修改歷史。你可以為你的每個方案選擇多個協作者。對於學生，它還提供單獨的計費方案。

7、 Overleaf ​

Overleaf 是另一款在線的 LaTeX 編輯器。它與 ShareLaTeX 類似，它為專家和學生提供了不同的計費方案。它也提供了一個免費方案，使用它你可以與 GitHub 同步，檢查你的修訂歷史，或添加多個合作者。

在每個項目中，它對文件的數目有所限制。所以在大多數情況下如果你對 LaTeX 文件非常熟悉，這並不會為你帶來不便。

8、 Authorea ​

Authorea 是一個美妙的在線 LaTeX 編輯器。當然，如果考慮到價格，它可能不是最好的一款。對於免費方案，它有 100 MB 的數據上傳限制和每次只能創建一個私有文檔。而付費方案則提供更多的額外好處，但如果考慮到價格，它可能不是最便宜的。你應該選擇 Authorea 的唯一原因應該是因為其用户界面。假如你喜愛使用一款提供令人印象深刻的用户界面的工具，那就不要錯過它。

9、 Papeeria ​

Papeeria 是在網絡上你能夠找到的最為便宜的 LaTeX 在線編輯器，如果考慮到它和其他的編輯器一樣可信賴的話。假如你想免費地使用它，則你不能使用它開展私有項目。但是，如果你更偏愛公共項目，它允許你創建不限數目的項目，添加不限數目的協作者。它的特色功能是有一個非常簡便的畫圖構造器，並且在無需額外費用的情況下使用 Git 同步。假如你偏愛付費方案，它賦予你創建 10 個私有項目的能力。

10、 Kile ​

位於我們最好 LaTeX 編輯器清單的最後一位是 Kile 編輯器。有些朋友對 Kile 推崇備至，很大程度上是因為其提供某些特色功能。

Kile 不僅僅是一款編輯器，它還是一款類似 Eclipse 的 IDE 工具，提供了針對文檔和項目的一整套環境。除了快速編譯和預覽功能，你還可以使用諸如命令的自動補全 、插入引用，按照章節來組織文檔等功能。你真的應該使用 Kile 來見識其潛力。

Kile 在 Linux 和 Windows 平台下都可獲取到。

總結 ​

所以上面便是我們推薦的 LaTeX 編輯器，你可以在 Ubuntu 或其他 Linux 發行版本中使用它們。

當然，我們可能還遺漏了某些可以在 Linux 上使用並且有趣的 LaTeX 編輯器。如若你正好知道它們，請在下面的評論中讓我們知曉。
