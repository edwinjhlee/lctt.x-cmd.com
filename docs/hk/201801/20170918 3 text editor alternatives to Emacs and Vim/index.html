3 個可以替代 Emacs 和 Vim 的文本編輯器 ​

Vim 和 Emacs 對於 Linux 桌面上進行文本編輯顯然是重量級的，但是它們並非唯一之選。

Emacs 和 Vim 的粉絲們，在你們開始編輯器之爭之前，請你們理解，這篇文章並不是為了貶低諸位最喜歡的編輯器。我是一個 Emacs 愛好者，但是也很喜歡 Vim。

就是説，我認為 Emacs 和 Vim 並不適合所有人。也許 編輯器之爭 略顯幼稚，讓很多人失望了。也許他們只是想要有一個不太苛刻的現代化的編輯器。

如果你正尋找可以替代 Emacs 或者 Vim 的編輯器，請繼續閲讀下去。這裏有三個可能會讓你感興趣的編輯器。

Geany ​

你可以用 Geany 編輯 LaTeX 文檔

Geany 是一個古老的編輯器，當我還在過時的硬件上運行輕量級 Linux 發行版的時候，Geany 就是一個優秀的的編輯器。Geany 開始用於我的 LaTeX 編輯，但是很快就成為我所有的文本編輯的編輯器了。

儘管 Geany 號稱是輕量且快速的 IDE（集成開發環境），但是它絕不僅僅是一個技術人的工具。Geany 輕便快捷，即便是在一個過時的機器或是 運行 Linux 的 Chromebook 也能輕鬆運行起來。無論是從編輯配置文件到維護任務列表或日誌，從寫文章或書籍到編寫代碼和腳本，Geany 都能輕鬆勝任。

插件 給 Geany 帶來一些額外的魅力。這些插件拓展了 Geany 的功能，讓你編碼或是處理一些標記語言變得更高效，幫助你處理文本，甚至做拼寫檢查。

Atom ​

使用 Atom 編輯網頁

在文本編輯器領域，Atom 後來居上。很短的時間內，Atom 就獲得了一批忠實的追隨者。

Atom 的定製功能讓其擁有如此的吸引力。如果有一些技術癖好，你完全可以在這個編輯器上隨意設置。如果你不僅僅是沉迷技術，Atom 也有 一些主題 ，你可以用來更改編輯器外觀。

千萬不要低估 Atom 數以千計的 拓展包。它們能在不同功能上拓展 Atom，能根據你的愛好把 Atom 轉化成合適的文本編輯器或是開發環境。Atom 不僅為程序員提供服務。它同樣是適用於 作家的文本編輯器。

Xed ​

使用 Xed 編輯文章

可能對用户體驗來説，Atom 和 Geany 略顯臃腫。也許你只想要一個輕量級，一個不要太簡陋也不要有太多很少使用的特性的編輯器，如此看來，Xed 正是你所期待的。

如果 Xed 你看着眼熟，那是因為它是 MATE 桌面環境中 Pluma 編輯器上的分支。我發現相比於 Pluma，Xed 可能速度更快一點，響應更靈敏一點——不過，因人而異吧。

雖然 Xed 沒有那麼多的功能，但也不至於太糟。它有紮實的語法高亮，略強於一般的搜索替換和拼寫檢查功能以及單窗口編輯多文件的選項卡式界面。

其他值得發掘的編輯器 ​

我不是 KDE 痴，當我工作在 KDE 環境下時， KDevelop 就已經是我深度工作時的首選了。它很強大而且靈活，又沒有過大的體積，很像 Genany。

雖然我還沒感受過對它的喜愛，但是我認識的幾個人都用 Brackets 感受到了。它很強大，而且不得不承認它的 拓展 真的很實用。

被稱為 “開發者的編輯器” 的 Notepadqq ，總讓人聯想到 Notepad++。雖然它的發展仍處於早期階段，但至少它看起來還是很有前景的。

對於那些只有簡單的文本編輯器需求的人來説，Gedit 和 Kate 相比是極好的。它絕不是太過原始的編輯器——它有足夠完成大型文本編輯的功能。無論是 Gedit 還是 Kate 都以速度和易上手而稱名。

你有其他 Emacs 和 Vim 之外的摯愛編輯器麼？方便的話留言分享。
