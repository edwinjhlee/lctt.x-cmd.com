遷移到 Linux：圖形操作環境 ​

這篇文章對 Linux 圖形環境做了一番介紹，展示了在不同的 Linux 發行版上的各種選擇。

這是我們遷移到 Linux 系統系列的第三篇文章。如果你錯過了先前的兩篇，這裏有兩文的鏈接《入門介紹》 和 《磁盤、文件、和文件系統》。本文中，我們將討論圖形操作環境。在 Linux 系統中，你可以依照喜好選擇並且定製一個圖形界面，你有很大的選擇餘地，這也是 Linux 優越的體驗之一。

一些主流的 Linux 圖形界面包括：Cinnamon、Gnome、KDE Plasma、Xfce 和 MATE，總之這裏有很多選擇。

有一點經常混淆 Linux 新手，雖然某個 Linux 系統分配了一個缺省的圖形環境，但是一般你可以隨時更換這個圖形界面。這和 Windows 或 Mac OS 的慣用者的定勢思維不同。安裝圖形環境是一件獨立的事情，很多時候，Linux 和其圖形環境的連接並不緊密。此外，你在一個圖形環境構建運行的程序同樣適用於另一個圖形環境。比如説一個為 KDE Plasma 圖形環境編寫的應用程序完全適用於 Gnome 桌面圖形環境。

由於人們熟悉 Windows 和 MacOS 系統，部分 Linux 操作系統的圖形環境在一定程度上嘗試着去模仿它們，但另一些 Linux 圖形界面則是獨特的。

下面，我將就一些不同的 Linux 發行版，展示幾個 Linux 圖形環境。如果你不確定應該採用那個 Linux 發行版，那我建議你從 Ubuntu 開始，獲取其長期支持（LTS）的版本（Ubuntu 16.04.3 LTS 正在開發）。Ubuntu 穩定且真的非常好用。

由 Mac 過渡 ​

Elementary OS 發行版提供了和 Mac 系統風格很接近的界面。它的默認圖形環境被稱作 Pantheon，是一款很適合 Mac 用户過渡使用的圖形環境。這款圖形界面發行版的屏幕底部有一個停靠欄，專為極簡者使用而設計。為了保持簡約的風格，很多默認的應用程序甚至都不會有自己的菜單。相反，它們的按鈕和控件在應用程序的標題欄上（圖 1）。

圖 1： Elementary OS Pantheon.

Ubuntu 發行版提供的一個默認的圖形界面，也和 Mac 相似。Ubuntu 17.04 或者更老的版本都使用 Unity 圖形環境，Unity 停靠欄的默認位置在屏幕的左邊，屏幕頂部有一個全局應用程序共享的菜單欄。

由 Windows 過渡 ​

ChaletOS 亦步亦趨模仿 Windows 界面，可以幫助 Windows 用户輕鬆的過渡到 Linux。ChaletOS 使用的圖形環境是 Xfce（圖 2）。在屏幕的左下角有一個開始（主）菜單和搜索欄。屏幕的右下角是一個桌面圖標和一些通知信息。這看起來和 Windows 非常像，乍一看，可能都會以為桌面跑的是 Windows。

圖 2： ChaletOS with Xfce.

Zorin OS 發行版同樣嘗試模仿 Windows。 Zorin OS 使用的 Gnome 的改進桌面，工作起來和 Windows 的圖形界面很相似。左下角的開始按鈕、右下角的通知欄和信息通知欄。開始按鈕會彈出一個和 Windows 無異的應用程序列表和搜索框。

獨有的圖形環境 ​

Gnome 桌面（圖 3）是最常用的圖形環境之一。許多發行版將 Gnome 作為默認的圖形環境。Gnome 並不打算模仿 Windows 或是 MacOS，而是以其自身的優雅和易用為目標。

圖 3：openSUSE with Gnome.

Gnome 桌面環境從版本 2 到 版本 3 發生了鉅變，Cinnamon 環境為消除該改變帶來的不利影響而創造。儘管 Cinnamon 和前輩 Gnome 2 外觀不相似，但是它依舊嘗試提供一個簡約的界面，而且它的功能和 Windows XP 類似。

MATE 圖形環境直接模仿於 Gnome 2，在它的屏幕頂部有一個用作設置和存放應用的菜單欄，底部提供了一個應用程序運行選項卡和一些其他組件。

KDE plasma 圍繞組件界面而構建，組件可以安裝在桌面或是面板上（圖 4）。

圖 4: 安裝了 KDE Plasma 的 Kubuntu 操作系統。

沒有那個圖形環境比另外一個更好。不同的風格適用不同的用户風格。另外，如果選擇太多無從下手，那就從 Ubuntu 開始吧。

相似與不同 ​

不同的操作系統處理方式不同，這會給使用者的過渡帶來挑戰。比如説，菜單欄可能出現在不同的位置，然後設置有可能用不同的選項入口路徑。我列舉了一些相似或不同地方來幫助減少 Linux 調整。

鼠標 ​

Linux 的鼠標通常和 Windows 與 MacOS 的工作方式有所差異。在 Windows 或 Mac，雙擊標籤，你幾乎可以打開任何事物，而這在 Linux 圖形界面中很多都被設置為單擊。

此外在 Windows 系統中，你通常通過單擊窗口獲取焦點。在 Linux，很多窗口的焦點獲取方式被設置為鼠標懸停，即便鼠標懸停下的窗口並不在屏幕頂端。這種微妙的差異有時候會讓人很吃驚。比如説，在 Windows 中，假如有一個後台應用（不在屏幕頂層），你移動鼠標到它的上面，不點擊鼠標僅僅轉動鼠標滾輪，頂層窗口會滾動。而在 Linux 中，後台窗口（鼠標懸停的那個窗口）會滾動。

菜單 ​

應用菜單是電腦程序的一個主要集中位置，最近似乎可以調整移動菜單欄到不礙事的地方，甚至乾脆完全刪除。大概，當你遷移到 Linux，你可能找不到你期待的菜單。應用程序菜單會像 MacOS一樣出現在全局共享菜單欄內。和很多移動應用程序一樣，該菜單可能在“更多選項”的圖標裏。或者，這個菜單幹脆被完全移除被一個按鈕取代，正如在 Elementary OS Pantheon 環境裏的一些程序一樣。

工作空間 ​

很多 Linux 圖形環境提供了多個工作空間。一個工作空間包含的正在運行的程序窗口充盈了整個屏幕。切換到不同的工作空間將會改變程序的可見性。這個概念是把當前項目運行使用的全部應用程序分組到一個工作空間，而一些為另一個項目使用的應用程序會被分組到不同的工作空間。

不是每一個人都需要甚至是喜歡工作空間，但是我提到它是因為，作為一個新手，你可能無意間通過一個組合鍵切換了工作空間，然後，“喂！我的應用程序哪去了?” 如果你看到的還是你熟悉的桌面壁紙，那你可能只是切換了工作空間，你所有的應用程序還在一個工作空間運行，只是現在不可見而已。在很多 Linux 環境中，通過敲擊 Alt+Ctrl 和一個箭頭（上、下、左或右）可以切換工作空間。很有可能發現你的應用程序一直都在另一個工作空間裏運行。

當然，如果你剛好喜歡工作空間（很多人都喜歡），然後你就發現了一個 Linux 很有用的默認功能。

設置 ​

許多 Linux 圖形環境提供一些類型的設置程序或是面板讓你在機器上配置設置。值得注意的是類似 Windows 和 MacOS，Linux 可以配置好很多細節，但不是所有的詳細設置都可以在設置程序上找到。但是這些設置項已經足夠滿足大部分典型的桌面系統，比如選擇桌面壁紙，改變熄屏時間，連接打印機等其他一些設置。

和 Windows 或者 MacOS 相比，Linux 的應用程序設置的分組或是命名都有不同的方式。甚至同是 Linux 系統，不同的圖形界面也會出現不同的設置，這可能需要時間適應。當然，在你的圖形環境中設置配置的問題可以通過在線查詢這樣不錯的方法解決。

應用程序 ​

最後，Linux 的應用程序也可能不同。你可能會發現一些熟悉的應用程序，但是對你來説更多的將會是嶄新的應用。比如説，你能在 Linux 上找到 Firefox、Chrome 和 Skype。如果不能找到特定的應用程序，通常你能使用一些替代程序。如果還是不能，那你可以使用 WINE 這樣的兼容層來運行 Windows 的應用程序。

在很多 Linux 圖形環境中，你可以通過敲擊 Windows 的標誌鍵來打開應用程序菜單欄。在其他一些情況中，你不得不點擊開始（主）按鈕或應用程序菜單。很多圖形環境中，你可以通過分類搜索到應用程序而不一定需要它的特定程序名。比如説，你要使用一個你不清楚名字的編輯器程序，這時候，你可以在應用程序菜單欄鍵的搜索框中鍵入“editor”字樣，它將為你展示一個甚至更多的被認為是編輯器類的應用程序。

為幫你起步，這裏列舉了一點可能成為 Linux 系統使用的替代程序。

請注意，Linux 提供了大量的滿足你需求的選擇，這張表裏列舉的一點也不完整。
