利用 Resetter 將 Ubuntu 系發行版重置為初始狀態 ​

這個 Resetter 工具可以將 Ubuntu、 Linux Mint （以及其它基於 Ubuntu 的發行版）返回到其初始配置。

有多少次你投身於 Ubuntu（或 Ubuntu 衍生版本），配置某項內容和安裝軟件，卻發現你的桌面（或服務器）平台並不是你想要的結果。當在機器上產生了大量的用户文件時，這種情況可能會出現問題。既然這樣，你有一個選擇，你要麼可以備份你所有的數據，重新安裝操作系統，然後將您的數據複製回本機，或者也可以利用一種類似於 Resetter 的工具做同樣的事情。

Resetter 是一個新的工具（由名為“gaining”的加拿大開發者開發），用 Python 和 PyQt 編寫，它將會重置 Ubuntu、Linux Mint（和一些其他的，基於 Ubuntu 的衍生版）回到初始配置。Resetter 提供了兩種不同的復位選擇：自動和自定義。利用自動方式，工具就會完成以下內容：

  • 刪除用户安裝的應用軟件
  • 刪除用户及家目錄
  • 創建默認備份用户
  • 自動安裝缺失的預裝應用軟件（MPIA）
  • 刪除非默認用户
  • 刪除 snap 軟件包

自定義方式會：

  • 刪除用户安裝的應用程序或者允許你選擇要刪除的應用程序
  • 刪除舊的內核
  • 允許你選擇用户進行刪除
  • 刪除用户及家目錄
  • 創建默認備份用户
  • 允許您創建自定義備份用户
  • 自動安裝缺失的預裝應用軟件（MPIA）或選擇 MPIA 進行安裝
  • 刪除非默認用户
  • 查看所有相關依賴包
  • 刪除 snap 軟件包

我將帶領您完成安裝和使用 Resetter 的過程。但是，我必須告訴你這個工具非常前期的測試版。即便如此， Resetter 絕對值得一試。實際上，我鼓勵您測試該應用程序並提交 bug 報告（您可以通過 GitHub 提交，或者直接發送給開發人員的電子郵件地址 gaining7@outlook.com)。

還應注意的是，目前僅支持的衍生版有：

  • Debian 9.2 （穩定）Gnome 版本
  • Linux Mint 17.3+（對 Mint 18.3 的支持即將推出）
  • Ubuntu 14.04+ （雖然我發現不支持 17.10）
  • Elementary OS 0.4+
  • Linux Deepin 15.4+

説到這裏，讓我們安裝和使用 Resetter。我將在 Elementary OS Loki 平台展示。

安裝 ​

有幾種方法可以安裝 Resetter。我選擇的方法是通過 gdebi 輔助應用程序，為什麼？因為它將獲取安裝所需的所有依賴項。首先，我們必須安裝這個特定的工具。打開終端窗口併發出命令：

sudo apt install gdebi

一旦安裝完畢，請將瀏覽器指向 Resetter 下載頁面，並下載該軟件的最新版本。一旦下載完畢，打開文件管理器，導航到下載的文件，然後單擊（或雙擊，這取決於你如何配置你的桌面） resetter_XXX-stable_all.deb 文件（XXX 是版本號）。gdebi 應用程序將會打開（圖 1）。點擊安裝包按鈕，輸入你的 sudo 密碼，接下來 Resetter 將開始安裝。

圖 1：利用 gdebi 安裝 Resetter

當安裝完成，準備接下來的操作。

使用 Resetter ​

記住，在這之前，必須備份數據。別怪我沒提醒你。

從終端窗口發出命令 sudo resetter。您將被提示輸入 sudo密碼。一旦 Resetter 打開，它將自動檢測您的發行版（圖 2）。

圖 2：Resetter 主窗口

我們將通過自動重置來測試 Resetter 的流程。從主窗口，點擊 Automatic Reset（自動復位）。這款應用將提供一個明確的警告，它將把你的操作系統（我的實例，Elementary OS 0.4.1 Loki）重新設置為出廠默認狀態（圖 3）。

*圖 3：在繼續之前，Resetter 會警告您。 *

單擊“Yes”，Resetter 會顯示它將刪除的所有包（圖 4）。如果您沒有問題，單擊 OK，重置將開始。

圖 4：所有要刪除的包，以便將 Elementary OS 重置為出廠默認值。

在重置過程中，應用程序將顯示一個進度窗口（圖 5）。根據安裝的數量，這個過程不應該花費太長時間。

圖 5：Resetter 進度窗口

當過程完成時，Resetter 將顯示一個新的用户名和密碼，以便重新登錄到新重置的發行版（圖 6）。

圖 6：新用户及密碼

單擊 OK，然後當提示時單擊“Yes”以重新啓動系統。當提示登錄時，使用 Resetter 應用程序提供給您的新憑證。成功登錄後，您需要重新創建您的原始用户。該用户的主目錄仍然是完整的，所以您需要做的就是發出命令 sudo useradd USERNAME （ USERNAME 是用户名）。完成之後，發出命令 sudo passwd USERNAME （USERNAME 是用户名）。使用設置的用户/密碼，您可以註銷並以舊用户的身份登錄（使用在重新設置操作系統之前相同的家目錄）。

我的成果 ​

我必須承認，在將密碼添加到我的老用户（並通過使用 su 命令切換到該用户進行測試）之後，我無法使用該用户登錄到 Elementary OS 桌面。為了解決這個問題，我登錄了 Resetter 所創建的用户，移動了老用户的家目錄，刪除了老用户（使用命令 sudo deluser jack），並重新創建了老用户（使用命令 sudo useradd -m jack）。

這樣做之後，我檢查了原始的家目錄，只發現了用户的所有權從 jack.jack 變成了 1000.1000。利用命令 sudo chown -R jack.jack /home/jack，就可以容易的修正這個問題。教訓是什麼？如果您使用 Resetter 並發現無法用您的老用户登錄（在您重新創建用户並設置一個新密碼之後），請確保更改用户的家目錄的所有權限。

在這個問題之外，Resetter 在將 Elementary OS Loki 恢復到默認狀態方面做了大量的工作。雖然 Resetter 處在測試中，但它是一個相當令人印象深刻的工具。試一試，看看你是否有和我一樣出色的成績。
