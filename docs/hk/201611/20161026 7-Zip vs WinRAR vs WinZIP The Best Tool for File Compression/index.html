7-Zip vs WinRAR vs WinZIP： 最好的文件壓縮工具對比 ​

在拳擊界裏有阿里、弗雷澤和福爾曼。在遊戲機界裏有任天堂、索尼和微軟，在 PC 壓縮軟件領域裏有7-Zip、WinRAR 和 WinZIP。我要發動這個軟件的對決嗎？也許，不管怎麼説它一直是一個重要的軟件。

這三個程序有同樣的功能，你可以獲取一堆你電腦上的文件然後打包壓縮它們到一個歸檔，壓縮它們的文件大小，直到有人決定取出它們。它們都易於使用，但是哪個做的更好？我拿它們做了一個測試來找出答案。

注意：雖然還有很多其它的壓縮格式，但 Winzip、7Zip 和 WinRAR 是三個 Windows 上最流行的壓縮工具。那就是為什麼我們只對比這三個工具。

注意：為了測試，我壓縮了一堆未壓縮的視頻文件，總計佔用 1.3GB 的空間。我還使用最好的壓縮設置來測試它們而不是默認的設置。對於每個項目，我描述瞭如何使這些設置。

7-Zip 出了免費這一大招 ​

值得一説的是，開源的 7-Zip 是免費的，沒有附加條件的這一塊已經擁有優勢。WinRAR 本質上是免費的，除了你必須忍受每次打開它時惱人的提示告訴你試用過期了。（你付款主要是為了擺脱這個提示。）而另一方面，WinZip 在試用期結束後會鎖定你。

WinZip ​

在今天的世界裏，我們莫名其妙地期望的一切與軟件相關的都是免費的，與我們的預期相悖，WinZip 大膽的在試用期後收費 £25.95。不過，也許是因為它比競爭對手做得更好，才讓其標上這麼大膽的價格標籤？讓我們來看看。

WinZip 有一個選項可以把文件壓縮成 .zipx 格式，它生成擁有比 .zip 和其它競爭者更高的壓縮比。要做到這一點，選擇並右鍵單擊要壓縮文件，然後單擊“WinZip - >添加到壓縮”文件。當 WinZip 打開後，選擇“壓縮類型”下的“.Zipx”，然後開始壓縮。

這裏是我們使用兩種 WinZip 壓縮方法的結果：

  • .Zip: 855MB (34% 壓縮)
  • .Zipx: 744MB (43% 壓縮)

WinRAR ​

WinRAR 壓縮的文件是 RAR 格式（這是它自己獨有的名字），也有一些技巧可以獲得最大的壓縮。

一旦你選擇要壓縮文件，右擊它們，請單擊“添加到壓縮文件”，然後勾選“創建可靠的歸檔”複選框。下一步，單擊“壓縮方式”的下拉列表，將其更改為“最佳”。WinRAR 的還有一個叫做 RAR5 的明顯增強的壓縮方法，所以我測試了這一點，以及標準的壓縮方法。下面是我們得到的：

  • .rar: 780MB (40% 壓縮)
  • .rar5: 778MB (40% 壓縮)

7-Zip ​

它沒有評估版或付費版，但是隨之而來的壓縮質量如何？要正確測試它，選擇要壓縮文件，右擊它們，選擇“添加到壓縮文件”，然後選擇7-Zip。

在新的窗口中更改壓縮方法 LZMA2（如果你有一個 4 核或更強的 CPU），壓縮級別設置為極端，然後壓縮！這裏的結果：

  • .7z: 758MB (42% 壓縮)

結論 ​

基於以上結果，我將繼續堅持使用 7-zip。和技術上的“贏家” WinZip 比，這 1% 差別的壓縮水平不足以為此花錢。

或許你並不想下載任何第三方軟件，在這種情況下，你可以使用 Windows 的內置壓縮工具。要使用它，只需右鍵單擊任何你想壓縮的文件，選擇“發送到”，然後“壓縮文件夾”。它只把文件壓縮到 892 MB的水平（31％），但它更便捷快速，而且是免費和內置的，所以我們還有抱怨嗎？
