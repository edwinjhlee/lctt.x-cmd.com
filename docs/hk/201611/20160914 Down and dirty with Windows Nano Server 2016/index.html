一起來看看 Windows Nano Server 2016 ​

對於遠程 Windows 服務器管理，Nano Server 是快速的功能強大的工具，但是你需要知道你在做的是什麼。

下面談論即將到來的 Windows Server 2016 的 Nano 版本，帶遠程管理和命令列設計，考慮到了私有云和數據中心。但是，談論它和動手用它區別還是很大的，讓我們深入看下去。

沒有本地登錄，且所有的程序、工具和代理都是 64 位，安裝升級快捷，只需要非常少的時間就能重啓。它非常適合做計算節點（無論在不在集羣）、存儲主機、DNS 服務器、IIS web 服務器，以及在容器中提供主機服務或者虛擬化的客户操作系統。

Nano 服務器也並不是太好玩的，你必須知道你要完成什麼。你會看着遠程的 PowerShell 的連接而不知所措，但如果你知道你要做什麼的話，那它就非常方便和強大。

微軟為設置 Nano 服務器提供了一個快速入門手冊 ，在這我給大傢俱體展示一下。

首先，你必須創建一個 .vhd 格式的虛擬磁盤文件。在步驟一中，我有幾個文件不在正確的位置的小問題，Powershell 總是提示不匹配，所以我不得不反覆查找文件的位置方便我可以用 ISO 信息（需要把它拷貝粘貼到你要創建 .vhd 文件的服務器上）。當你所有的東西都位置正確了，你可以開始創建 .vhd 文件的步驟了。

步驟一：嘗試運行 New-NanoServerImage 腳本時，很多文件路徑錯誤，我把文件位置的問題搞定後，就能進行下去創建 .vhd 文件了（如圖所示）

接下來，你可以用創建 VM 嚮導在 Hyper-V 裏面創建 VM 虛擬機，你需要指定一個存在的虛擬磁盤同時指向你新創建的 .vhd 文件。（步驟二）

步驟二：連接虛擬磁盤（一開始創建的）

當你啓動 Nano 服務器的時候，你或許會發現有內存錯誤，提示你已經分配了多少內存，如果你還有其他 VM 虛擬機的話， Hyper-V 服務器剩餘了多少內存。我已經關閉了一些虛機以增加可用內存，因為微軟説 Nano 服務器最少需要 512M 內存，但是它又推薦你至少 800M，最後我分配了 8G 內存因為我給它 1G 的時候根本不能用，為了方便，我也沒有嘗試其他的內存配置。

最後我終於到達登錄界面，到達 Nano Server Recovery Console 界面（步驟三），Nano 服務器的基本命令界面。

步驟三：Nano 服務器的恢復窗口

本來我以為進到這裏會很美好，但是當我弄明白幾個細節（如何加入域，彈出個磁盤，添加用户），我明白一些配置的細節，用幾個參數運行 New-NanoServerImage cmdlet 會變得很簡單。

然而，當你的服務器運行時，也有辦法確認它的狀態，就像步驟四所示，這一切都始於一個遠程 PowerShell 連接。

步驟四：從 Nano 服務器恢復窗口得到的信息，你可以從遠程運行一個 Powershell 連接。

微軟展示瞭如何創建連接，但是嘗試了四個不同的方法，我發現 MSDN 提供的是最好的方式，步驟五展示。

步驟五：創建到 Nano 服務器的 PowerShell 遠程連接

提示：創建遠程連接，你可以用下面這條命令：

Enter-PSSession –ComputerName "192.168.0.100"-Credential ~\Administrator.

如果你提前知道這台服務器將要做 DNS 服務器或者集羣中的一個計算節點，可以事先在 .vhd 文件中加入一些角色和特定的軟件包。如果不太清楚，你可以先建立 PowerShell 連接，然後安裝 NanoServerPackage 並導入它，你就可以用 Find-NanoServerPackage 命令來查找你要部署的軟件包了（步驟六）。

步驟六：你安裝完並導入 NanoServerPackage 後，你可以找到你需要啓動服務器的工具以及設置的用户和你需要的一些其他功能包。

我測試了安裝 DNS 安裝包，用 Install-NanoServerPackage –Name Microsoft-NanoServer-DNS-Package 這個命令。安裝好後，我用 Enable-WindowsOptionalFeature –Online –FeatureName DNS-Server-Full-Role 命令啓用它。

之前我並不知道這些命令，之前也從來沒運行過，也沒有弄過 DNS，但是現在稍微研究一下我就能用 Nano 服務器建立一個 DNS 服務並且運行它。

接下來是用 PowerShell 來配置 DNS 服務器。這個複雜一些，需要網上研究一下。但是它也不是那麼複雜，當你學習了使用 cmdlet ，就可以用 Add-DNSServerPrimaryZone 添加 zone，用 Add-DNSServerResourceRecordA 命令在 zone 中添加記錄。

做完這些命令列的工作，你可能需要驗證是否起效。你可以快速瀏覽一下 PowerShell 命令，沒有太多的 DNS 命令（使用 Get-Command 命令）。

如果你需要一個圖形化的配置，你可以從一個圖形化的主機上用圖形管理器打開 Nano 服務器的 IP 地址。右擊需要管理的服務器，提供你的驗證信息，你連接好後，在圖形管理器中右擊然後選擇 Add Roles and Features，它會顯示你安裝好的 DNS 服務，如步驟七所示。

步驟七：通過圖形化界面驗證 DNS 已經安裝

不用麻煩登錄服務器的遠程桌面，你可以用服務器管理工具來進行操作。當然你能驗證 DNS 角色不代表你能夠通過 GUI 添加新的角色和特性，它有命令列就足夠了。你現在可以用 Nano 服務器做一些需要的調整了。
