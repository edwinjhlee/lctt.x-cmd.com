何時 NGINX 將取代 Apache？ ​

NGINX 和 Apache 兩者都是主流的開源 web 服務器，但是據 NGINX 的首席執行官 Gus Robertson 所言，他們有不同的使用場景。此外還有微軟，其 web 服務器 IIS 在活躍網站的份額在 20 年間首次跌破 10%。

Apache 是最受歡迎的 web 服務器，不過 NGINX 正逐漸增長，而微軟的 IIS 幾十年來首次跌破 10%。

NGINX 已經成為第二大 web 服務器。它在很久以前就已經超越了微軟 IIS，並且一直在老大 Apache 的身後窮追不捨。但是，NGINX 的首席執行官Gus Roberston 在接受採訪時表示，Apache 和 NGINX 的用户羣體不一樣。

“我認為 Apache 是很好的 web 服務器。NGINX 和它的使用場景不同，”Robertson 説。“我們沒有把 Apache 當成競爭對手。我們的用户使用 NGINX 來取代硬件負載均衡器和構建微服務，這兩個都不是 Apache 的長處。”

事實上，Robertson 發現許多用户同時使用了這兩種開源的 web 服務。“用户會在 Apache 的上層使用 NGINX 來實現負載均衡。我們的架構差異很大，我們可以提供更好的併發 web 服務。”他還表示 NGINX 在雲環境中表現更優秀。

他總結説，“我們是唯一一個仍然在持續增長的 web 服務器，其它的 web 服務器都在慢慢縮小份額。”

這不太準確。根據 Netcraft 十月份的網絡服務器調查，Apache 當月的活躍網站增加得最多，獲得了 180 萬個新站點，而 NGINX 增加了 40 萬個新站點，排在第二位。

這些增長，加上微軟損失的 120 萬個活躍站點，導致微軟的活躍網站份額下降到 9.27%，這是他們第一次跌破 10%。Apache 的市場份額提高了 0.19%，並繼續領跑市場，現在坐擁 46.3% 的活躍站點。儘管如此，多年來 Apache 一直在緩慢下降，而 NGINX 現在上升到了 19%。

NGINX 的開發者正在努力創造他們的核心開放（open-core ）的商業 web 服務器 —— NGINX Plus，通過不斷的改進使其變得更有競爭力。NGINX Plus 最新的版本是 NGINX Plus 11 版（R11），該服務器易於擴展和自定義，並支持更廣泛的部署。

這次最大的補充是 動態模組 的二進制兼容性。也就是説為 開源 NGINX 軟件 編譯的動態模組也可以加載到 NGINX Plus。

這意味着你可以利用大量的第三方 NGINX 模組 來擴展 NGINX Plus 的功能，借鑑一系列開源和商業化生產的模組。開發者可以基於支持 NGINX Plus 的內核創建自定義擴展、附加組件和新產品。

NGINX Plus R11 還增強了其它功能：

  • 提升 TCP/UDP 負載均衡 —— 新功能包括 SSL 服務器路由、新的日誌功能、附加變量以及改進的代理協議支持。這些新功能增強了調試功能，使你能夠支持更廣泛的企業應用。
  • 更好的 IP 定位 —— 第三方的 GeoIP2 模組現在已經通過認證，並提供給 NGINX Plus 用户。這個新版本提供比原來的 GeoIP 模組更精準和豐富的位置信息。
  • 增強的 nginScript 模組 —— nginScript 是基於 JavaScript 的 NGINX Plus 的下一代配置語言。新功能可以讓你在流（TCP/UDP）模組中即時修改請求和響應數據。

最終結果？NGINX 準備繼續與 Apache 競爭頂級 web 服務器的寶座。至於微軟的 IIS？它將逐漸淡出市場。
