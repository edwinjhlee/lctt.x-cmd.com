誰需要 GUI？—— Linux 終端生存之道 ​

完全在 Linux 終端中生存並不容易，但這絕對是可行的。

處理常見功能的最佳 Linux shell 應用 ​

你是否曾想像過完完全全在 Linux 終端裏生存？沒有圖形桌面，沒有現代的 GUI 軟件，只有文本 —— 在 Linux shell 中，除了文本還是文本。這可能並不容易，但這是絕對可行的。我最近嘗試完全在 Linux shell 中生存30天。下邊提到的就是我最喜歡用的 shell 應用，可以用來處理大部分的常用電腦功能（網頁瀏覽、文字處理等）。這些顯然有些不足，因為純文本操作實在是有些艱難。

在 Linux 終端裏發郵件 ​

要在終端裏發郵件，選擇有很多。很多人會推薦 mutt 和 notmuch，這兩個軟件都功能強大並且表現非凡，但是我卻更喜歡 alpine。為何？不僅是因為它的高效性，還因為如果你習慣了像 Thunderbird 之類的 GUI 郵件客户端，你會發現 alpine 的界面與它們非常相似。

在 Linux 終端裏瀏覽網頁 ​

我有一個詞要告訴你：w3m。好吧，我承認這並不是一個真實的詞。但 w3m 的確是我在 Linux 終端的 web 瀏覽器選擇。它能夠很好的呈現網頁，並且它也足夠強大，可以用來在像 Google+ 之類的網站上發佈消息（儘管方法並不有趣）。 Lynx 可能是基於文本的 Web 瀏覽器的事實標準，但 w3m 還是我的最愛。

在 Linux 終端裏編輯文本 ​

對於編輯簡單的文本文件，有一個應用是我最的最愛。不！不！不是 emacs，同樣，也絕對不是 vim。對於編輯文本文件或者簡要記下筆記，我喜歡使用 nano。對！就是 nano。它非常簡單，易於學習並且使用方便。當然還有更多的軟件具有更多功能，但 nano 的使用是最令人愉快的。

在 Linux 終端裏處理文字 ​

在一個只有文本的 shell 之中，“文本編輯器” 和 “文字處理程序” 實在沒有什麼大的區別。但是像我這樣需要大量寫作的，有一個專門用於長期寫作的軟件是非常必要的。而我最愛的就是 wordgrinder。它由足夠的工具讓我愉快工作——一個菜單驅動的界面（使用快捷鍵控制）並且支持 OpenDocument、HTML 或其他等多種文件格式。

在 Linux 終端裏聽音樂 ​

當談到在 shell 中播放音樂（比如 mp3，ogg 等），有一個軟件絕對是衞冕之王：cmus。它支持所有你想得到的文件格式。它的使用超級簡單，運行速度超級快，並且只使用系統少量的資源。如此清潔，如此流暢。這才是一個好的音樂播放器的樣子。

在 Linux 終端裏發送即時消息 ​

當我在想如果可以在終端裏發送即時消息會是什麼樣子的時候，我的思緒瞬間爆發了。你可能知道 Pidgin——一個支持多種協議的 IM 客户端，它也有一個終端版，叫做“finch”，你可以使用它來同時鏈接多個網絡、同時和幾個人聊天。而且，它的界面也和 Pidgin 極為相似。多麼令人驚歎啊！想要使用 Google 環聊（Google Hangouts）就試試 hangups。它有一個非常漂亮的分頁式界面，並且效果非常好。認真來説，除了一些可能需要的 emoji 表情和嵌入式圖片外，在終端裏發送即時消息真的是一個很好的體驗。

在 Linux 終端裏發佈推文 ​

這不是開玩笑！由於 rainbowstream 的存在，我們已經可以在終端裏發佈推文了。儘管我時不時遇到一些 bug，但整體上，它工作得很好。雖然沒有網頁版 Twitter 或官方移動客户端那麼好用，但這是一個終端版的 Twitter，來試一試吧。儘管它的功能還未完善，但是用起來還是很酷，不是嗎？

在 Linux 終端裏看 Reddit 新聞 ​

不管如何，在命令列中享受 Reddit 新聞時間真的感覺很棒。使用 rtv 真是一個相當愉快的體驗。不管是閲讀、評論，還是投票表決，它都可以。其體驗和在網頁版有一定相似。

在 Linux 終端裏管理進程 ​

可以使用 htop。與 top 相似，但更好用、更美觀。有時候，我打開 htop 之後就讓它一直運行。沒有原因，就是喜歡！從某方面説，它就像將音樂可視化——當然，這裏顯示的是 RAM 和 CPU 的使用情況。

在 Linux 終端裏管理文件 ​

在一個純文本終端裏並不意味着你不能享受生活之美好。比方説一個出色的文件瀏覽和管理器。這方面，Midnight Commander 是很好用的。

在 Linux 終端裏管理終端窗口 ​

如果要在終端裏工作很長時間，就需要一個多窗口終端了。它是這樣一個軟件 —— 可以將用户終端會話分割成一個自定義網格，從而可以同時使用和查看多個終端應用。對於 shell，它相當於一個平鋪式窗口管理器。我最喜歡用的是 tmux。不過 GNU Screen 也很好用。學習怎麼使用它們可能要花點時間，但一旦會用，就會很方便。

在 Linux 終端裏進行講稿演示 ​

這類軟件有 LibreOffice、Google slides、gasp 或者 PowerPoint。我在講稿演示軟件花費很多時間，很高興有一個終端版的軟件。它稱做“文本演示程序（tpp）”。很顯然，沒有圖片，只是一個使用簡單標記語言將放在一起的幻燈片展示出來的簡單程序。它不可能讓你在其中插入貓的圖片，但可以讓你在終端裏進行完整的演示。
