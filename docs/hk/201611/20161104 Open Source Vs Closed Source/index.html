開源 vs. 閉源 ​

開源操作系統和閉源操作系統之間有諸多不同。這裏我們僅寥書幾筆。

開源是什麼？自由！ ​

這是用户需要知道的最重要的一點。無論我是否打算修改代碼，其他人出於善意的修改都不應受到限制。且如果用户喜歡，他們可以分享這個軟件。使用開源軟件，這些都是可能的。

閉源操作系統的許可條款很是嚇人。但真的所有人都會看嗎？不，許多用户只是點了一下‘Accept’ 而已。

價格 ​

幾乎所有的開源操縱系統是免費的。僅有自願性質的捐款。且只需有個一個 CD/DVD 或 USB 就能將系統安裝到所有你想要安裝的電腦上。

閉源操作系統相較於開源 OS 就貴了許多，如果你用它來構建 PC，每台 PC 得你花不少於 $100。

我們可以用花在閉源軟件上的錢去買更好的東西。

選擇 ​

開源操作系統的發行版有很多。如果你不中意眼下的這個，你可以嘗試其他的發行版，總能找到適合你的那一個。

諸如 Ubuntu studio、Bio Linux、Edubuntu、Kali Linux、Qubes、SteamOS 這些發行版，就是針對特定用户羣產生的發行版。

閉源軟件有“選擇”這種説法嗎？我覺得是沒有的。

隱私 ​

開源操作系統無需收集用户數據信息。不會根據用户的個性顯示廣告，也不會把你的信息賣給第三方機構。如果開發者需要資金，他們會要求捐助，或是在他們的網頁上打廣告。廣告的內容也會與 Linux 相關，對我們有益無害。

你一定知道那個主流的閉源操作系統（名字就不寫了，大家都知道的），據説因為收集用户信息這件事，導致多數用户關閉了他們的免費更新服務。多數該系統的用户為了避免升級，將更新功能關閉，他們寧可承擔安全風險也不要免費更新。

安全 ​

開源軟件大多安全。究其緣由不僅有市場佔有率低這個原因，其本身的構成方式就比較安全。例如， Qubes Os 是最安全的操作系統之一，它將運行的軟件相互隔離。

閉源操作系統向易用性妥協，使其變得愈發脆弱。

硬件支持 ​

我們中有大多數人，家裏還放着那些不想丟的舊 PC，這時一個輕量級的發行版可能會讓這些老傢伙們重獲新生。你可以試試在文章 5 個適合舊電腦的輕量級 Linux 中羅列的那些輕量級操作系統發行版。基於 Linux 的系統幾乎包含所有設備的驅動，所以基本不需要你親自尋找、安裝驅動。

閉源操作系統時不時中止對舊硬件的支持，迫使用户去購買新的硬件。我們還不得不親自尋找、安裝驅動。

社區支持 ​

幾乎所有的開源操作系統都有用户論壇，你可以在那裏提問題，並從別的用户那裏得到答案。大家在那裏分享技巧和竅門，互幫互助。有經驗的 Linux 用户往往樂於幫助新手，為此他們常常不遺餘力。

閉源操作系統社區和開源操作系統社區簡直無法相提並論。提出的問題常常得不到回答。

商業化 ​

在操作系統上掙錢是非常困難的。（開源）開發者一般通過用户的捐款和在網站上打廣告來掙錢。捐款主要用於支付主機的開銷和開發者的薪水。

許多閉源操作系統，不僅僅通過出售軟件的使用許可這種方式來賺錢，還會推送廣告大賺一票。

垃圾應用 ​

我承認有些開源操作系統會提供一些我們可能一輩子都不會用到的應用，有些人認為他們是垃圾應用。但是也有發行版只提供最小安裝，其中就不包含這些不想要的軟件。所以，這不是真正的問題。

而所有的閉源操作系統中都包含廠商安裝的垃圾應用，強制你安裝，就像在安裝一個乾淨系統一樣。

開源軟件更像是一門哲學。一種分享和學習的方式。甚至還有益於經濟。

我們已經將我們知曉的羅列了出來。如果你覺得我們還漏了些什麼，可以評論告訴我們。
