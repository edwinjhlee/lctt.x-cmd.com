2016 年 Linux 下五個最佳視頻編輯軟件 ​

概要: 在這篇文章中，Tiwo 討論了 Linux 下最佳視頻編輯器的優缺點和在基於 Ubuntu 的發行版中的安裝方法。

在過去，我們已經在類似的文章中討論了 Linux 下最佳圖像管理應用軟件，Linux 上四個最佳的現代開源代碼編輯器。今天，我們來看看 Linux 下的最佳視頻編輯軟件。

當談及免費的視頻編輯軟件，Windows Movie Maker 和 iMovie 是大多數人經常推薦的。

不幸的是，它們在 GNU/Linux 下都是不可用的。但是你不必擔心這個，因為我們已經為你收集了一系列最佳的視頻編輯器。

Linux下最佳的視頻編輯應用程序 ​

接下來，讓我們來看看 Linux 下排名前五的最佳視頻編輯軟件：

1. Kdenlive ​

Kdenlive 是一款來自於 KDE 的自由而開源的視頻編輯軟件，它提供雙視頻監視器、多軌時間軸、剪輯列表、可自定義的佈局支持、基本效果和基本轉換的功能。

它支持各種文件格式和各種攝像機和相機，包括低分辨率攝像機（Raw 和 AVI DV 編輯）：mpeg2、mpeg4 和 h264 AVCHD（小型攝像機和攝像機）；高分辨率攝像機文件，包括 HDV 和 AVCHD 攝像機；專業攝像機，包括 XDCAM-HD^TM 流、IMX^TM （D10）流、DVCAM（D10）、DVCAM、DVCPRO^TM 、DVCPRO50^TM 流和 DNxHD^TM 流等等。

你可以在命令列下運行下面的命令安裝 :

sudo apt-get install kdenlive

或者，打開 Ubuntu 軟件中心，然後搜索 Kdenlive。

2. OpenShot ​

OpenShot 是我們這個 Linux 視頻編輯軟件列表中的第二選擇。 OpenShot 可以幫助您創建支持過渡、效果、調整音頻電平的電影，當然，它也支持大多數格式和編解碼器。

您還可以將電影導出到 DVD，上傳到 YouTube、Vimeo、Xbox 360 和許多其他常見的格式。 OpenShot 比 Kdenlive 更簡單。 所以如果你需要一個簡單界面的視頻編輯器，OpenShot 會是一個不錯的選擇。

最新的版本是 2.0.7。您可以從終端窗口運行以下命令安裝 OpenShot 視頻編輯器：

sudo apt-get install openshot

它需要下載 25 MB，安裝後需要 70 MB 硬盤空間。

3. Flowblade Movie Editor ​

Flowblade Movie Editor 是一個用於 Linux 的多軌非線性視頻編輯器。它是自由而開源的。 它配備了一個時尚而現代的用户界面。

它是用 Python 編寫的，旨在提供一個快速、精確的功能。 Flowblade 致力於在 Linux 和其他自由平台上提供最好的體驗。 所以現在沒有 Windows 和 OS X 版本。

要在 Ubuntu 和其他基於 Ubuntu 的系統上安裝 Flowblade，請使用以下命令：

sudo apt-get install flowblade

4. Lightworks ​

如果你要尋找一個有更多功能的視頻編輯軟件，這會是答案。 Lightworks 是一個跨平台的專業的視頻編輯器，在 Linux、Mac OS X 和 Windows 系統下都可用。

它是一個獲獎的專業的非線性編輯（NLE）軟件，支持高達 4K 的分辨率以及標清和高清格式的視頻。

該應用程序有兩個版本：Lightworks 免費版和 Lightworks 專業版。不過免費版本不支持 Vimeo（H.264 / MPEG-4）和 YouTube（H.264 / MPEG-4） - 高達 2160p（4K UHD）、藍光和 H.264 / MP4 導出選項，以及可配置的位速率設置，但是專業版本支持。

  • Lightworks 免費版
  • Lightworks 專業版

專業版本有更多的功能，例如更高的分辨率支持，4K 和藍光支持等。

怎麼安裝Lightworks？ ​

不同於其他的視頻編輯器，安裝 Lightwork 不像運行單個命令那麼直接。別擔心，這不會很複雜。

  • 第1步 – 你可以從 Lightworks 下載頁面下載安裝包。這個安裝包大約 79.5MB。請注意：這裏沒有32 位 Linux 的支持。
  • 第2步 – 一旦下載，你可以使用 Gdebi 軟件包安裝器來安裝。Gdebi 會自動下載依賴關係 :
  • 第3步 – 現在你可以從 Ubuntu 儀表板或您的 Linux 發行版菜單中打開它。
  • 第4步 – 當你第一次使用它時，需要一個賬號。點擊 “Not Registerd?” 按鈕來註冊。別擔心，它是免費的。
  • 第5步 – 在你的賬號通過驗證後，就可以登錄了。

現在，Lightworks 可以使用了。

需要 Lightworks 的視頻教程？ 在 Lightworks 視頻教程頁得到它們。

5. Blender ​

Blender 是一個專業的，工業級的開源、跨平台的視頻編輯器。在 3D 作品的製作中，是非常受歡迎的。 Blender 已被用於幾部好萊塢電影的製作，包括蜘蛛俠系列。

雖然最初是設計用於製作 3D 模型，但它也可以用於各種格式的視頻編輯和輸入能力。 該視頻編輯器包括：

  • 實時預覽、亮度波形、色度矢量示波器和直方圖顯示
  • 音頻混合、同步、擦除和波形可視化
  • 多達 32 個插槽用於添加視頻、圖像、音頻、場景、面具和效果
  • 速度控制、調整圖層、過渡、關鍵幀、過濾器等

最新的版本可以從 Blender 下載頁下載.

哪一個是最好的視頻編輯軟件？ ​

如果你需要一個簡單的視頻編輯器，OpenShot、Kdenlive 和 Flowblade 是一個不錯的選擇。這些軟件是適合初學者的，並且帶有標準規範的系統。

如果你有一個高性能的計算機，並且需要高級功能，你可以使用 Lightworks。如果你正在尋找更高級的功能， Blender 可以幫助你。

這就是我寫的 5 個最佳的視頻編輯軟件，它們可以在 Ubuntu、Linux Mint、Elementary 和其他 Linux 發行版下使用。 請與我們分享您最喜歡的視頻編輯器。
