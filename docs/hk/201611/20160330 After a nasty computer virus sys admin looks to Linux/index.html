病毒過後，系統管理員投向了 Linux ​

我開源事業的第一筆，是我在 2001 年作為一名兼職系統管理員，為大學工作的時候。成為了那個以教學為目的，不僅僅在大學中，還在學術界的其他領域建立商業案例研究的小組的一份子。

隨着團隊的發展，漸漸地開始需要一個由文件服務、intranet 應用，域登錄等功能構建而成的健壯的局域網。 我們的 IT 基礎設施主要由跑着 Windows 98 的計算機組成，這些計算機對於大學的 IT 實驗室來説已經太老了，就重新分配給了我們部門。

初探 Linux ​

一天，作為大學IT採購計劃的一部分，我們部門收到了一台 IBM 服務器。 我們計劃將其用作 Internet 網關，域控制站，文件服務器和備份服務器，以及 intranet 應用程序主機。

拆封後，我們注意到它附帶了紅帽 Linux 的 CD。 我們的 22 人團隊（包括我）對 Linux 一無所知。 經過幾天的研究，我找到了一位朋友的朋友，一位以 Linux RTOS （Linux 的實時操作系統領域）編程為生的人，求助他如何安裝。

光看着那朋友用 CD 驅動器載入第一張安裝 CD 並進入 Anaconda 安裝系統，我的頭都暈了。 大約一個小時，我們完成了基本的安裝，但仍然沒有可用的 internet 連接。

又花了一個小時的折騰才使我們連接到互聯網，但仍沒有域登錄或 Internet 網關功能。 經過一個週末的折騰，我們可以讓我們的 Windows 98 機器作為 Linux PC 的代理，終於構出了一個正常工作的共享互聯環境。 但域登錄還需要一段時間。

我們用龜速的電話調製解調器下載了 Samba，並手動配置它作為域控制站。文件服務也通過 NFS Kernel Server 開啓了，隨後為 Windows 98 的網絡鄰居創建了用户目錄並進行了必要的調整和配置。

這個設置完美運行了一段時間，直到最終我們決定開始使用 Intranet 應用管理時間表和一些別的東西。 這個時候，我已經離開了該組織，並把大部分系統管理員的東西交給了接替我的人。

再遇 Linux ​

2004 年，我又重新裝回了 Linux。我的妻子經營的一份獨立員工安置業務，使用來自 Monster.com 等服務的數據來打通客户與求職者的交流渠道。

作為我們兩人中的計算機好點的那個，在計算機和互聯網出故障的時候，維修就成了我的分內之事。我們還需要用許多工具嘗試，從堆積如山的簡歷中篩選出她每天必須看的。

Windows BSoD（藍屏） 早已司空見慣，但只要我們的付費數據是安全的，那就還算可以容忍。為此我將不得不每週花幾個小時去做備份。

一天，我們的電腦中了毒，並且通過簡單的方法無法清除。我們並不瞭解磁盤上的數據發生了些什麼。當磁盤徹底掛掉後，我們插入了一週前的輔助備份磁盤，但是一週後它也掛了。我們的第二個備份直接拒絕啓動。是時候尋求專業幫助了，所以我們把電腦送到一家靠譜的維修店。兩天以後，我們被告知一些惡意軟件或病毒已經將某些種類的文件擦除殆盡，其中包括我們的付費數據。

這是對我妻子的商業計劃的一個巨大的打擊，同時意味着丟失合同並耽誤了賬單。我曾短期出國工作，並在台灣的 Computex 2004 購買了我的第一台筆記本電腦。 預裝的是 Windows XP，但我還是想換成 Linux。 我知道 Linux 已經為桌面端做好了準備，Mandrake Linux （曼德拉草） 是一個很不錯的選擇。 我第一次安裝就很順利。所有工作都執行的非常漂亮。我使用 OpenOffice 來滿足我寫作，演示文稿和電子表格的需求。

我們為我們的計算機買了新的硬盤驅動器，併為其安裝了 Mandrake Linux。用 OpenOffice 替換了 Microsoft Office。 我們依靠 Web 郵件來滿足郵件需求，並在 2004 年的 11 月迎來了 Mozilla Firefox。我的妻子馬上從中看到了好處，因為沒有崩潰或病毒/惡意軟件感染！更重要的是，我們告別了困擾 Windows 98 和 XP 的頻繁崩潰問題。 她一直使用這個發行版。

而我，開始嘗試其他的發行版。 我愛上了 distro-hopping （LCTT 譯註：指在不同版本的 Linux 發行版之間頻繁切換的 Linux 用户）和第一時間嘗試新發行版的感覺。我也經常會在 Apache 和 NGINX 上嘗試和測試 Web 應用程序，如 Drupal、Joomla 和 WordPress。現在我們 2006 年出生的兒子，在 Linux 下成長。 也對 Tux Paint，Gcompris 和 SMPlayer 非常滿意。
