一個老奶奶的嘮叨：當年我玩 Linux 時…… ​

在很久以前，那時還沒有 Linux 系統。真的沒有！之前也從未存在過。不像現在，Linux 系統隨處可見。那時有各種流派的 Unix 系統、有蘋果的操作系統、有微軟的 Windows 操作系統。

比如説 Windows，它的很多東西都改變了，但是依然保持不變的東西的更多。儘管它已經增加了 20GB 以上的鬼知道是什麼的東西，但是 Windows 還是大體保持不變（除了不能在 DOS 的提示下實際做些什麼了）。嘿，誰還記得 Gorilla.bas 那個出現在 DOS 系統裏的炸香蕉的遊戲嗎？多麼美好的時光啊！不過互聯網卻不會忘記，你可以在 Kongregate.com 這個網站玩這個遊戲的 Flash版本。

蘋果系統也改變了，從一個鼓勵你 hack 的友善系統變成了一個漂亮而密實的、根本不讓你打開的小盒子，而且還限制了你使用的硬件接口。1998 年：軟盤沒了。2012 年：光驅沒了。而 12 英寸的 MacBook 只有一個單一的 USB Type-C 接口，提供了電源、藍牙、無線網卡、外部存儲、視頻輸出和其它的一些配件的接口。而你要是想一次連接多個外設就不得不揹着一堆轉接器，這真是太令人抓狂了！然後就輪到耳機插孔了，沒錯，這唯一一個蘋果世界裏留着的非專有的標準硬件接口了，也註定要消失了。（LCTT 譯註：還好，雖然最新的 IPhone 7 上沒有耳機插孔了，但是新發布的 Macbook 上還有）

還有一大堆其它的操作系統，比如：Amiga、BeOS、OS/2 ，如果你願意的話，你能找到幾十個操作系統。我建議你去找找看，太容易找到了。Amiga、 BeOS 和 OS/2 這些系統都值得關注，因為它們有強大的功能，比如 32 位的多任務和高級圖形處理能力。但是市場的影響擊敗了強大的系統性能，因此技術上並不出眾的 Apple 和 Windows 操作系統統治了市場的主導地位，而那些曾經的系統也逐漸銷聲匿跡了。

然後 Linux 系統出現了，世界也因此改變了。

第一款電腦 ​

我曾經使用過的第一款電腦是 Apple IIc ，大概在 1994年左右，而那個時候 Linux 系統剛出來 3 年。這是我從一個朋友那裏借來的，用起來各方面都還不錯，但是很不方便。所以我自己花了將近 500 美元買了一台二手的 Tandy 牌的電腦。這對於賣電腦的人來説是一件很傷心的事，因為新電腦要花費雙倍的價錢。那個時候，電腦貶值的速度非常快。這個電腦當時看起來強勁得像是個怪物：一個英特爾 386SX 的 CPU，4MB的內存，一個 107MB 的硬盤，14 英寸的彩色 CRT 顯示器，運行 MS-DOS 5 和 Windows 3.1 系統。

我曾無數次的拆開那個可憐的怪物，並且多次重新安裝 Windows 和 DOS 系統。因為 Windows 桌面用的比較少，所以我的大部分工作都是在 DOS 下完成的。我喜歡玩血腥暴力的視頻遊戲，包括 Doom、Duke Nukem、Quake 和 Heretic。啊！那些美好的，讓人心動的 8 位圖像！

那個時候硬件的發展一直落後於軟件，因此我經常升級硬件。現在我們能買到滿足我們需求的任何配置的電腦。我已經好多年都沒有再更新我的任何電腦硬件了。

《比特雜誌（Computer bits）》 ​

回到那些曾經輝煌的年代，電腦商店佈滿大街小巷，找到本地的一家網絡服務提供商（ISP）也不用走遍整個街區。ISP 那個時候真的非比尋常，它們不是那種冷冰冰的令人討論的超級大公司，而是像美國電信運營商和有線電視公司這樣的好朋友。他們都非常友好，並且提供各種各樣的像 BBS、文件下載、MUD （多玩家在線遊戲）等的額外服務。

我花了很多的時間在電腦商店購買配件，但是很多時候我一個女人家去那裏會讓店裏的員工感到吃驚，我真的很無語了，這怎麼就會讓一些人看不慣了。我現成已經是一位 58 歲的老傢伙了，但是他們還是一樣的看不慣我。我希望我這個女電腦迷在我死之前能被他們所接受。

那些商店的書架上擺滿了《比特雜誌（Computer bits）》。有關《比特雜誌》的歷史刊物可以在互聯網檔案庫（Internet Archive）中查到。《比特雜誌》是當地一家免費報紙，有很多關於計算機方面的優秀的文章和大量的廣告。可惜當時的廣告沒有網絡版，因此大家不能再看到那些很有價值的關於計算機方面的詳細信息了。你知道現在的廣告商們有多麼的抓狂嗎？他們埋怨那些安裝廣告過濾器的人，致使科技新聞變成了偽裝的廣告。他們應該學習一下過去的廣告模式，那時候的廣告裏有很多有價值的信息，大家都喜歡閲讀。我從《比特雜誌》和其它的電腦雜誌的廣告中學到了所有關於計算機硬件的知識。《電腦購買者雜誌（Computer Shopper）》更是非常好的學習資料，其中有上百頁的廣告和很多高質量的文章。

《比特雜誌》的出版人 Paul Harwood 開啓了我的寫作生涯。我的第一篇計算機專業性質的文章就是在《比特雜誌》發表的。 Paul，彷彿你一直都在我的身旁，謝謝你。

在互聯網檔案庫中，關於《比特雜誌》的分類廣告信息已經幾乎查詢不到了。分類廣告模式曾經給出版商帶來巨大的收入。免費的分類廣告網站 Craigslist 在這個領域獨佔鰲頭，同時也扼殺了像《比特雜誌》這種以傳統的報紙和出版為主的雜誌行業。

其中有一些讓我最難以忘懷的記憶就是一個 12 歲左右的吊兒郎當的小屁孩，他臉上掛滿了對我這種光鮮亮麗的女人所做工作的不屑和不理解的表情，他在我鍾愛的電腦店裏走動，遞給我一本《比特雜誌》，當成給初學者的一本好書。我翻開雜誌，指着其中一篇我寫的關於 Linux 系統的文章給他看，他説“哦，我明白了”。他尷尬的臉變成了那種正常生理上都不可能呈現的顏色，然後很倉促地夾着尾巴溜走了。(不是的，我親愛的、誠實的讀者們，他不是真的只有 12 歲，而應該是 20 來歲。他現在應該比以前更成熟懂事一些了吧！）

發現 Linux ​

我第一次瞭解到 Linux 系統是在《比特雜誌》上，大概在 1997 年左右。我一開始用的一些 Linux操作系統版本是 Red Hat 5 和 Mandrake Linux（曼德拉草）。 Mandrake 真是太棒了，它是第一款易安裝型的 Linux 系統，並且還附帶圖形界面和聲卡驅動，因此我馬上就可以玩 Tux Racer 遊戲了。不像那時候大多數的 Linux 迷們，因為我之前沒接觸過 Unix系統，所以我學習起來比較難。但是一切都還順利吧，因為我學到的東西都很有用。相對於我在 Windows 中的體驗，我在 Windows 中學習的大部分東西都是徒勞，最終只能放棄返回到 DOS 下。

玩轉電腦真是充滿了太多的樂趣，後來我轉行成為計算機自由顧問，去幫助一些小型公司的 IT 部門把數據遷移到 Linux 服務器上，這讓 Windows 系統或多或少的失去一些用武之地。通常情況下我們都是在背地裏偷偷地做這些工作的，因為那段時期微軟把 Linux 稱為毒瘤，誣衊 Linux 系統是一種共產主義，用來削弱和吞噬我們身體裏的珍貴血液的陰謀。

Linux 贏了 ​

我持續做了很多年的顧問工作，也做其它一些相關的工作，比如：電腦硬件修理和升級、佈線、系統和網絡管理，還有運行包括 Apple、Windows、Linux 系統在內的混合網絡。Apple 和 Windows 系統故意不兼容對方，因此這兩個系統真的是最頭疼，也最難整合到同一網絡中。但是在 Linux 系統和其它開源軟件中最有趣的一件事是總有一些人能夠處理這些廠商之間的兼容性問題。

現在已經大不同了。在系統間的互操作方面一直存在一些兼容性問題，而且也沒有桌面 Linux 系統的 1 級 OEM 廠商。我覺得這是因為微軟和蘋果公司在零售行業在大力壟斷造成的。也許他們這樣做反而幫了我們幫大忙，因為我們可以從 ZaReason 和 System76 這樣獨立的 Linux 系統開發商得到更好的服務和更高性能的系統。他們對 Linux 系統都很專業，也特別歡迎我們這樣的用户。

Linux 除了在零售行業的桌面版系統佔有一席之地以外，從嵌入式系統到超級計算機以及分佈式計算系統等各個方面都佔據着主要地位。開源技術掌握着軟件行業的發展方向，所有的軟件行業的前沿技術，比如容器、集羣以及人工智能的發展都離不開開源技術的支持。從我的第一台老式的 386SX 電腦到現在，Linux 和開源技術都取得了巨大的進步。

如果沒有 Linux 系統和開源，這一切都不可能發生。
