現在 Linux 運行在 99.6% 的 TOP500 超級計算機上 ​

簡介：雖然 Linux 在桌面操作系統只有 2% 的市場佔有率，但是對於超級計算機來説，Linux 用 99% 的市場佔有率輕鬆地獲取了統治地位。

Linux 運行在超過 99% 的 TOP500 超級計算機上，這並不會讓人感到驚訝。2015 年我們報道過“Linux 正運行在超過 97% 的 TOP500 超級計算機上”，今年 Linux 表現得更好。

這些信息是由獨立組織 Top500 收集的，每兩年他們會公佈已知的最快的 500 台超級計算機的細節。你可以打開這個網站，用以下條件篩選所需要的信息：國家、使用的操作系統類型、所有者等。別擔心，我將會從這份表格中篩選整理出今年幾個有趣的事實。

Linux 運行在 500 台超級計算機中的 498 台 ​

如果要將上面的百分比細化到具體數量的話，500 台超級計算機中的 498 台運行着 Linux。剩餘的兩台超級計算機運行着基於 Unix 的操作系統。直到去年，還有一台超級計算機上在運行 Windows，今年的列表中沒有出現 Windows 的身影。或許，這些超級計算機沒一台能運行 Windows 10（一語雙關）。

總結一下今年表單上 TOP500 超級計算機所運行操作系統情況：

  • Linux: 498
  • Unix: 2
  • Windows: 0

還有一份總結，它清晰展現了每年 Linux 在 TOP500 超級計算機的份額的變化情況。

  • 2012 年: 94%
  • 2013 年: 95%
  • 2014 年: 97%
  • 2015 年: 97.2%
  • 2016 年: 99.6%
  • 2017 年: ???

另外，最快的前380台超級計算機運行着 Linux，包括在中國的那台最快的超級計算機。排名第 386 和第 387 的超級計算機運行着 Unix，它們同樣來自中國。（←_←）

其他關於最快的超級計算機的有趣數據 ​

除去 Linux，我在表單中還找到了幾個有趣的數據想跟你分享。

  • 全球最快的超級計算機是神威太湖之光. 它位於中國的國家超級計算無錫中心。它有着 93PFlops 的速度。
  • 全球第二快的超級計算機是中國的天河二號，第三的位置則屬於美國的 Titan。
  • 在速度前十的超級計算機中，美國佔據了 5 台，日本和中國各有 4 台，瑞士有 1 台。
  • 美國和中國都各有 171 台超級計算機進入了 TOP500 的榜單中。
  • 日本有 27 台，法國有 20 台，印度、俄羅斯和沙特阿拉伯各有 5 台進入了榜單中。

有趣的事實，不是嗎？你能點擊這裏篩選出屬於自己的榜單來獲得更多信息。現在我很開心來宣傳 Linux 運行在 99% 的 TOP500 超級計算機上，期待下一年能有 100% 的更好成績。

當你在閲讀這篇文章時，請在社交平台上分享這篇文章，這是 Linux 的一個成就，我們引以為豪~ 😛
