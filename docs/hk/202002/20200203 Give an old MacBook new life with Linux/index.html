用 Linux 讓舊 MacBook 煥發新生 ​

Elementary OS 的最新版本 Hera 是一個令人印象深刻的平台，它可以讓過時的 MacBook 得以重生。

當我安裝蘋果的 MacOS Mojave 時，它使我以前可靠的 MacBook Air 慢得像爬一樣。我的計算機發售於 2015 年，具有 4 GB 內存、i5 處理器和 Broadcom 4360 無線卡，但是對於我的日常使用來説，Mojava 有點過分了，它不能和 GnuCash 一起工作，這激起了我重返 Linux 的慾望。我很高興能重返，但是我深感遺憾的是，我的這台出色的 MacBook 被閒置了。

我在 MacBook Air 上嘗試了幾種 Linux 發行版，但總會有缺陷。有時是無線網卡；還有一次，它缺少對觸摸板的支持。看了一些不錯的評論後，我決定嘗試 Elementary OS 5.0（Juno）。我用 USB 製作了啓動盤，並將其插入 MacBook Air 。我來到了一個現場live桌面，並且操作系統識別出了我的 Broadcom 無線芯片組 —— 我認為這可能行得通！

我喜歡在 Elementary OS 中看到的內容。它的 Pantheon 桌面真的很棒，並且其外觀和使用起來的感覺對 Apple 用户來説很熟悉 —— 它的顯示屏底部有一個擴展塢，並帶有一些指向常用應用程序的圖標。我對我之前期待的預覽感到滿意，所以我決定安裝它，然後我的無線設備消失了。真的很令人失望。我真的很喜歡 Elementary OS ，但是沒有無線網絡是不行的。

時間快進到 2019 年 12 月，當我在 Linux4Everyone 播客上聽到有關 Elementary 最新版本 v.5.1（Hera） 使 MacBook 復活的評論時，我決定用 Hera 再試一次。我下載了 ISO ，創建了可啓動驅動器，將其插入電腦，這次操作系統識別了我的無線網卡。我可以在上面工作了。

我非常高興我輕巧又功能強大的 MacBook Air 通過 Linux 煥然一新。我一直在更詳細地研究 Elementary OS，我可以告訴你我印象深刻的東西。

Elementary OS 的功能 ​

根據 Elementary 的Blog，“新設計的登錄和鎖定屏幕問候語看起來更清晰、效果更好，並且修復了以前問候語中報告的許多問題，包括輸入焦點問題，HiDPI 問題和更好的本地化。Hera 的新設計是為了響應來自 Juno 的用户反饋，並啓用了一些不錯的新功能。”

“不錯的新功能”是在輕描淡寫 —— Elementary OS 擁有我見過的最佳設計的 Linux 用户界面之一。默認情況下，系統上的“系統設置”圖標位於擴展塢上。更改設置很容易，很快我就按照自己的喜好配置了系統。我需要的文字大小比默認值大，輔助功能是易於使用的，允許我設置大文字和高對比度。我還可以使用較大的圖標和其他選項來調整擴展塢。

按下 Mac 的 Command 鍵將彈出一個鍵盤快捷鍵列表，這對新用户非常有幫助。

Elementary OS 附帶的 Epiphany Web 瀏覽器，我發現它非常易於使用。它與 Chrome、Chromium 或 Firefox 略有不同，但它已經綽綽有餘。

對於注重安全的用户（我們應該都是），Elementary OS 的安全和隱私設置提供了多個選項，包括防火牆、歷史記錄、鎖定，臨時和垃圾文件的自動刪除以及用於位置服務開/關的開關。

有關 Elementray OS 的更多信息 ​

Elementary OS 最初於 2011 年發佈，其最新版本 Hera 於 2019 年 12 月 3 日發佈。 Elementary 的聯合創始人兼 CXO 的 Cassidy James Blaede 是操作系統的 UX 架構師。 Cassidy 喜歡使用開放技術來設計和構建有用、可用和令人愉悦的數字產品。

Elementary OS 具有出色的用户文檔，其代碼（在 GPL 3.0 下許可）可在 GitHub 上獲得。Elementary OS 鼓勵參與該項目，因此請務必伸出援手並加入社區。
