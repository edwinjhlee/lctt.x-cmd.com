從監獄到 Python ​

入獄後，開源編程是如何提供機會的。

不到一年前，我還在聖昆廷州立監獄服刑，我是無期徒刑。

我高三的時候，我搶劫了一個人並向他開了槍。現在，我經過一段時間才意識到並承認自己做錯了，這是在經歷了陪審團審判並看到我的行為帶來的惡果後，我知道需要改變自己，我也確實做到了。儘管我對我的行為表示懊悔，但我畢竟開槍打了一個人，並差點殺了他。做這樣的事是有後果的，這是理所當然的。所以在我 18 歲的時候，我被判了終身監禁。

監獄是一個非常可怕的地方；我是不推薦你去的。但是我必須去，所以我去了。我不告訴你具體的細節，但你可以放心，這是一個沒有太多動機去改變的地方，許多人在這裏養成的壞習慣比他們過去在別處養成的更多。

我是幸運兒之一。當我在服刑的時候，發生了一些不同尋常的事情。我開始想像自己出獄後的的未來，雖然在這之前，我還是已經在那裏度過了我整個成年生活。

現在你想想：我是黑人，只受過高中教育。我沒有工作經歷，如果我離開監獄，在被釋放前，我還是一個被定罪的重罪犯。當每個僱主看到我的簡歷，都不會有“我需要僱用這個人”想法，我認為是正常的。

我不知道我的選擇是什麼，但我已經下定決心了。我需要做些活下去的事情，並且這和我入獄前的生活一點也不像。

Python 之路 ​

最終，我被關在了聖昆廷州立監獄，我不知道我為何幸運地被關在那裏。聖昆廷提供了幾個自助和教育編程項目。這些改造機會幫助囚犯使他們擁有在獲釋後避免再次犯罪的技能。

作為其中一個編程項目的一部分，2017 年我通過聖昆廷媒體項目認識了傑西卡·麥凱拉。傑西卡是編程語言 Python 的愛好者，她開始向我推薦 Python 有多棒，以及它是剛起步的人學習的完美語言。這就是故事變得比小説更精彩的地方。

感謝 @northbaypython 讓 @ShaStepter 和我重複 @pycon 的主題演講，讓他們被錄製下來。我很榮幸與大家分享：

傑西卡向我介紹了一些 Python 視頻教程，這些教程是她為一家名叫 O’Reilly Media 的公司做的，課程是在線的，如果我能接觸到它們，那該有多好呀。不幸的是，在監獄裏上網是不可能的。但是，我遇到了一個叫 Tim O’Reilly 的人，他最近剛來到聖昆廷。在他訪問之後，Tim 從他的公司 O’Reilly Media 公司向監獄的編程班捐贈了大量內容。最終，我拿到了一款平板電腦，上面有傑西卡的 Python 教程，並學會了如何使用這些 Python 教程進行編碼。

真是難以置信。背景和生活與我完全不同的陌生人把這些聯繫在一起，讓我學會了編碼。

對 Python 社區的熱愛 ​

在這之後，我開始經常和傑西卡見面，她開始告訴我關於開源社區的情況。我瞭解到，從根本上説，開源社區就是關於夥伴關係和協作的社區。之所以如此有效，是因為沒有人被排除在外。

對我來説，一個努力尋找自己定位的人，我所看到的是一種非常基本的愛——通過合作和接受的愛，通過接觸的愛，通過包容的愛。我渴望成為其中的一部分。所以我繼續學習 Python，不幸的是，我無法獲得更多的教程，但是我能夠從開源社區收集的大量書面知識中獲益。我讀一切提到 Python 的東西，從平裝本到晦澀難懂的雜誌文章，我使用平板電腦來解決我讀到的 Python 問題。

我對 Python 和編程的熱情不是我的許多同齡人所共有的。除了監獄編程課上的極少數人之外，我認識的其他人都沒有提到過編程；一般囚犯都不知道。我認為這是因為有過監禁經歷的人無法接觸編程，尤其是如果你是有色人種。

監獄外的 Python 生活 ​

然而，在 2018 年 8 月 17 日，我得到了生命中的驚喜。時任州長的傑裏·布朗將我 27 年的刑期減刑，在服刑將近 19 年後，我被釋放出獄了。

但現實情況是，這也是為什麼我認為編程和開源社區如此有價值。我是一名 37 歲的黑人罪犯，沒有工作經歷，剛剛在監獄服刑 18 年。我有犯罪史，並且現存偏見導致沒有多少職業適合我。但是編程是少數例外之一。

現在，監禁後重返社會的人們迫切需要包容，但當談及工作場所的多樣性以及對多樣性的需求時，你真的聽不到這個羣體被提及或包容。

還有什麼:

1、背景調查：詢問他們在你的公司是如何使用的。

2、初級角色：刪除虛假的、不必要的先決條件，這些條件將排除有記錄的合格人員。

3、積極拓展：與當地再就業項目合作，創建招聘渠道。

pic.twitter.com/WnzdEUTuxr

—傑西卡·麥凱拉（@jessicamckellar）2019 年 5 月 12 日

因此，我想謙卑地挑戰開源社區的所有程序員和成員，讓他們圍繞包容和多樣性展開思考。今天，我自豪地站在你們面前，代表一個大多數人都沒有想到的羣體——以前被監禁的人。但是我們存在，我們渴望證明我們的價值，最重要的是，我們期待被接受。當我們重返社會時，許多挑戰等待着我們，我請求你們允許我們有機會展示我們的價值。歡迎我們，接受我們，最重要的是，包容我們。
