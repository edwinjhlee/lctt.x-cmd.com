體驗 /e/ OS：開源的去谷歌化的安卓 ​

/e/ 安卓操作系統是一個以隱私為導向的去谷歌化的移動操作系統，是 Lineage OS 的復刻，由 Mandrake Linux（現在的 Mandriva Linux）的創建者 Gaël Duval 於 2018 年中期創立。

儘管安卓在 2007 年成為了一個開源項目，但當安卓得到普及時，谷歌使用專有軟件取代了一些操作系統元素。/e/ 基金會用 MicroG 取代了其中的專有的應用程序和服務，這是一個開源的替代框架，可以最大限度地減少跟蹤和設備活動。

我們收到的 Fairphone 3 預裝了 /e/ OS，這是一個來自 /e/ 基金會的 以道德的方式創造的智能手機。我使用了一個月這個設備，然後把它返還給了他們，我將分享我對這個隱私設備的體驗。我忘了截圖，所以我將分享來自官方網站的通用圖片。

在道德的 Fairphone 設備上體驗 /e/ 移動操作系統 ​

在我進一步説明之前，讓我澄清一下，Fairphone 3 並不是使用 /e/ 的唯一選擇。如果你要從他們那裏購買設備，/e/ 基金會會給你 一些智能手機的選擇。

你不需要購買設備來使用 /e/ OS。按照 /e/ 基金會的説法，你可以 在 100 多個支持的設備上使用它。

儘管我很喜歡使用 Fairphone 3，而且我的個人信仰與 Fairphone 的宣言一致，但我不會把注意力放在設備上，而只是放在 /e/ OS 上。

有評級隱私的應用程序 ​

我把 Fairphone 3 作為我的日常使用設備用了幾天時間，以比較與我的“普通”安卓手機在現實中的使用情況。

首先，我想看看我使用的所有應用程序是否都可以在 /e/ 基金會創建的“應用商店”上找到。/e/ 應用商店包含有隱私評級的應用程序。

我可以找到許多應用程序，包括來自谷歌的應用程序。這意味着，如果有人真的想使用一些谷歌的服務，它仍然可以作為一個選項來下載。儘管與其他安卓設備不同，沒有強行將谷歌服務塞進你的嘴裏。

雖然有很多應用程序，但我無法找到我在英國使用的手機銀行應用程序。我不得不承認，手機銀行應用程序可以在一定程度上促進便利。作為替代方案，我不得不在需要時進入電腦使用網上銀行平台。

從可用性的角度來看，/e/ OS 可以取代我的“標準”安卓操作系統，但會有一些小插曲，比如銀行應用程序。

如果不是谷歌的，那是什麼？ ​

想知道 /e/ OS 使用哪些基本的應用程序，而不是谷歌的那些？這裏有一個快速列表：

  • 魔法地球 —— 逐向道路導航
  • 瀏覽器 —— Chromium 的一個非谷歌復刻版本
  • 郵件 —— K9-mail 的一個復刻
  • 短信 —— QKSMS 的一個復刻
  • 照相機 —— OpenCamera 的一個復刻
  • 天氣 —— GoodWeather 的一個復刻
  • OpenTasks —— 任務組織者
  • 日曆：Etar calendar 的一個復刻

Bliss Launcher 和整體設計 ​

/e/ OS 的默認啓動程序被稱為 “Bliss Launcher”，其目的是為了獲得有吸引力的外觀和感覺。對我來説，這個設計感覺與 iOS 相似。

通過向左滑動面板，你可以訪問 /e/ 選擇的一些有用的小工具。

  • 搜索：快速搜索預裝的應用程序或搜索 Web
  • APP 建議：前 4 個最常用的應用程序將出現在這個小部件上
  • 天氣：天氣小部件顯示的是當地的天氣。它不會自動檢測位置，需要進行配置。
  • 編輯：如果你想在屏幕上有更多的小部件，你可以通過點擊“編輯”按鈕添加它們。

去谷歌化和麪向隱私的操作系統 ​

如前所述，/e/ 操作系統是一個去谷歌化的操作系統，它基於 Lineage OS 的開源核心。所有的谷歌應用程序已經被刪除，谷歌服務已經被 MicroG 框架所取代。/e/ OS 仍然與所有的安卓應用兼容。

主要的隱私功能：

  • 谷歌搜索引擎已被 DuckDuckGo 等替代品取代
  • 谷歌服務已被 microG 框架所取代
  • 使用替代的默認應用程序，而不是谷歌應用程序
  • 取消了對谷歌服務器的連接檢查
  • NTP 服務器已被替換為標準的 NTP 服務：pool.ntp.org
  • DNS 默認服務器由 9.9.9.9 取代，可以根據用户的選擇進行編輯
  • 地理定位是在 GPS 的基礎上使用 Mozilla 定位服務

隱私聲明

請注意，使用由 /e/ 基金會提供的智能手機並不自動意味着無論你做什麼都能保證你的隱私。分享你的個人信息的社交媒體應用程序應在你的意識下使用。

結論 ​

我成為安卓用户已經超過十年了。/e/ OS 給我帶來了積極的驚喜。關注隱私的用户可以發現這個解決方案非常吸引人，而且根據所選擇的應用程序和設置，可以再次感覺到使用智能手機的安全。

如果你是一個有隱私意識的技術專家，並且能夠自己找到解決問題的方法，我向你推薦它。對於那些習慣於谷歌主流服務的人來説，/e/ 生態系統可能會讓他們不知所措。
