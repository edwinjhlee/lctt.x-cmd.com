每個人都應該嘗試 Linux 的 21 個理由 ​

遊戲、交易、預算、藝術、編程等等，這些都只是任何人都可以使用 Linux 的眾多方式中的一種。

當我在度假時，我經常會去一家或者多家的二手書店。我經常能夠找到我想讀的一本好書，而且我總是以 “我在度假；我應該用這本書來犒勞自己” 來為不可避免的購買行為辯護。這很有效，我用這種方式獲得了一些我最喜歡的書。但是，買一本好書在生活中很常見，這個理由經不起推敲。事實上，我不需要為買一本好書來找理由。事情都是這樣的，我可以在任何時候做我想做的事。但不知何故，有一個理由似乎確實能讓這個過程更有趣。

在我的日常生活中，我會收到很多關於 Linux 的問題。有時候我會不自覺地滔滔不絕地講述開源軟件的歷史，或者共享資源的知識和利益。有時候，我會設法提到一些我喜歡的 Linux 上的特性，然後對這些好處進行逆向工程以便它們可以在其它的操作系統上享用。這些討論經常是有趣且有益的，但只有一個問題：這些討論都沒有回答大家真正要問的問題。

當一個人問你關於 Linux 的問題時，他們經常希望你能夠給他們一些使用 Linux 的理由。當然，也有例外。從來沒有聽過“Linux”的人們可能會問一些字面定義。但是當你的朋友或者同事吐露出他們對當前的操作系統有些不滿意的時候，解釋一下你為什麼喜歡 Linux 可能更好，而不是告訴他們為什麼 Linux 是一個比專有系統更好的選擇。換句話説，你不需要銷售演示，你需要的是度假照片（如果你是個書蟲的話，也可以是度假時買的一本書）。

為了達到這個目的，下面是我喜歡 Linux 的 21 個原因，分別在 21 個不同的場合講給 21 個不同的人。

遊戲 ​

説到玩電腦，最明顯的活動之一就是玩遊戲，説到玩遊戲，我很喜歡。我很高興花一個晚上玩一個 8 位的益智遊戲或者 epic 工作室的一個 AAA 級遊戲。其它時候，我還會沉浸在棋盤遊戲或者角色扮演遊戲（RPG）中。

這些我都是 在 Linux 系統的電腦上做的。

辦公 ​

一種方法並不適合所有人。這對帽子和辦公室工作來説都是如此。看到同事們被困在一個不適合他們的單一工作流程中，我感到很痛苦，我喜歡 Linux 鼓勵用户找到他們喜歡的工具。我曾使用過的應用大到套件（例如 LibreOffice 和 OpenOffice），小到輕量級文字處理器（如 Abiword），再到最小的文本編輯器（利用 Pandoc 進行轉換）。

不管我周圍的用户被限制在什麼範圍內，我都可以 自由地使用可以在我的電腦上工作的最好的工具，並且以我希望的方式工作。

選擇 ​

開源最有價值的特性之一是用户在使用這些軟件的時候是可以信任它的。這種信任來自於好友網絡，他們可以閲讀他們所使用的應用程序和操作系統的源代碼。也就是説，即使你不知道源代碼的好壞，你也可以在 開源社區 中結交一些知道的朋友。這些都是 Linux 用户在探索他們運行的發行版時建立的重要聯繫。如果你不信任構建和維護的發行版的社區，你可以去找其它的發行版。我們都是這樣做的，這是有許多發行版可供選擇的優勢之一。

Linux 提供了可選擇的特性。一個強大的社區，充滿了真實的人際關係，結合 Linux 提供的選擇自由，所有這些都讓用户對他們運行的軟件有信心。因為我讀過一些源碼，也因為我信任哪些維護我沒讀過的代碼的人，所以我信任 Linux。

預算 ​

做預算並不有趣，但是很重要。我很早就認識到，在業餘時間做一些不起眼的工作，就像我學會了一種 免費 的操作系統（Linux！）一樣。預算不是為了追蹤你的錢，而是為了追蹤你的習慣。這意味着無論你是靠薪水生活，還是正在計劃退休，你都應該 保持預算。

如果你在美國，你甚至可以 用 Linux 來交税。

藝術 ​

不管你是畫畫還是做像素藝術、編輯視頻 還是隨性記錄，你都可以在 Linux 上創建出色的內容。我所見過的一些最優秀的藝術作品都是使用一些非“行業標準”的工具隨意創作出來的，並且你可能會驚訝於你所看到的許多內容都是基於同樣的方式創造出來的。Linux 是一個不會被宣揚的引擎，但它是具有強大功能的引擎，驅動着獨立藝術家和大型製作人。

嘗試使用 Linux 來 創作一些藝術作品。

編程 ​

聽着，用 Linux 來編程幾乎是定論。僅次於服務器管理，開源和 Linux 是一個明顯的組合。這其中有 許多原因，但我這裏給出了一個有趣的原因。我在發明新東西時遇到了很多障礙，所以我最不希望的就是操作系統或者軟件工具開發包（SDK）成為失敗的原因。在 Linux 上，我可以訪問一切，字面意義上的一切。

封包 ​

當他們在談編程的時候，沒有人談封包。作為一個開發者，你必須將你的代碼提供給您的用户，否則你將沒有任何用户。Linux 使得開發人員可以輕鬆地 發佈應用程序，用户也可以輕鬆地 安裝這些應用程序。

令很多人感到驚訝的是 Linux 可以像運行本地程序一樣運行許多 Windows 應用程序。你不應該期望一個 Windows 應用可以在 Linux 上執行。不過，許多主要的通用應用要麼已經在 Linux 上原生存在，要麼可以通過名為 Wine 的兼容層運行。

技術 ​

如果你正在找一份 IT 工作，Linux 是很好的第一步。作為一個曾經為了更快地渲染視頻而誤入 Linux 的前藝術系學生，我説的是經驗之談。

尖端技術發生在 Linux 上。Linux 驅動着大部分的互聯網、世界上最快的超級計算機以及雲本身。現在，Linux 驅動着 邊緣計算，將雲數據中心的能力與分散的節點相結合，以實現快速響應。

不過，你不需要從最頂層開始。你可以學習在筆記本電腦或者台式機上自動完成任務，並通過一個 好的終端 遠程控制系統。

Linux 對你的新想法是開放的，並且 可以進行定製。

分享文件 ​

無論你是一個新手系統管理員，還是僅僅是要將一個將文件分發給室友，Linux 都可以使 文件共享變得輕而易舉。

多媒體 ​

在所有關於編程和服務器的討論中，人們有時把 Linux 想像成一個充滿綠色的 1 和 0 的黑屏。對於我們這些使用它的人來説，Linux 也能 播放你所有的媒體，這並不令人驚訝。

易於安裝 ​

以前從來沒有安裝過操作系統嗎？Linux 非常簡單。一步一步來，Linux 安裝程序會手把手帶你完成操作系統的安裝，讓你在一個小時內感覺到自己是個電腦專家。

來安裝 Linux 吧!

試一試 Linux ​

如果你還沒有準備好安裝 Linux，你可以 試一試 Linux。不知道如何開始？它沒有你想像的那麼嚇人。這裏給了一些你 一開始需要考慮的事情。然後選擇下載一個發行版，並想出你自己使用 Linux 的 21 個理由。
