為什麼要切換到 Linux 系統？我該怎麼做？ ​

是時候做出改變了。

讓 Ubuntu，一個簡單易用的 Linux 版本，來掌管你的電腦。

當你在選購電腦的時候，你可能會在 Windows 和 macOS 之間猶豫，但是可能基本不會想到 Linux。儘管如此，這個名氣沒那麼大的操作系統仍然擁有龐大而忠誠的粉絲。因為它相對於它的競爭者，有很大的優勢。

不管你是完全不瞭解 Linux，或是已經嘗試過一兩次，我們希望你考慮一下在你的下一台筆記本或台式機上運行 Linux，或者可以和現存系統做個雙啓動。請繼續閲讀下去，看是不是時候該切換了。

什麼是 Linux? ​

如果你已經非常熟悉 Linux，可以跳過這個部分。對於不熟悉的其他人，Linux 是一個免費的開源操作系統，所有人都可以去探索它的代碼。技術上來説，術語“Linux”説的只是內核，或者核心代碼。不過，人們一般用這個名字統稱整個操作系統，包括界面和集成的應用。

因為所有人都可以修改它，Linux 有非常自由的可定製性，這鼓舞了很多程序員製作併發布了自己的系統——常稱為發行版distro。這些不同口味的系統，每一個都有自己特色的軟件和界面。一些比較有名的發行版，模仿了熟悉的 Windows 或 macOS 操作系統，比如 Ubuntu、 Linux Mint 和 Zorin OS。當你準備選擇一個發行版時，可以去它們官網看一下，試試看是不是適合自己。

為了製作和維護這些 Linux 發行版，大量的開發者無償地貢獻了自己的時間。有時候，利潤主導的公司為了拓展自己的軟件銷售領域，也會主導開發帶有獨特特性的 Linux 版本。比如 Android（它雖然不能當作一個完整的 Linux 操作系統）就是以基於 Linux 內核的，這也是為什麼它有很多不同變種的原因。另外，很多服務器和數據中心也運行了 Linux，所以很有可能這個操作系統託管着你正在看的網頁。

有什麼好處？ ​

首先，Linux 是免費而且開源的，意味着你可以將它安裝到你現有的電腦或筆記本上，或者你自己組裝的機器，而不用支付任何費用。系統會自帶一些常用軟件，包括網頁瀏覽器、媒體播放器、圖像編輯器和辦公軟件，所以你也不用為了查看圖片或處理文檔再支付其他額外費用。而且，以後還可以免費升級。

Linux 比其他系統能更好的防禦惡意軟件，強大到你都不需要運行殺毒軟件。開發者們在最早構建時就考慮了安全性，比如説，操作系統只運行可信的軟件。而且，很少有惡意軟件針對這個系統，對於黑客來説，這樣做沒有價值。Linux 也並不是完全沒有任何漏洞，只不過對於一般只運行已驗證軟件的家庭用户來説，並不用太擔心安全性。

這個操作系統對硬件資源的要求比起數據臃腫的 Windows 或 macOS 來説也更少。一些發行版不像它們名氣更大的表兄弟，默認集成了更少的組件，開發者特別開發了一些，比如 Puppy Linux 和 Linux Lite，讓系統儘可能地輕量。這讓 Linux 非常適合那些家裏有很老的電腦的人。如果你的遠古筆記本正在原裝操作系統的重壓下喘息，試試裝一個 Linux，應該會快很多。如果不願意的話，你也不用拋棄舊系統，我們會在後面的部分裏解釋怎麼做。

儘管你可能會需要一點時間來適應新系統，不過不用太久，你就會發現 Linux 界面很容易使用。任何年齡和任何技術水平的人都可以掌握這個軟件。而且在線的 Linux 社區提供了大量的幫助和支持。説到社區，下載 Linux 也是對開源軟件運動的支持：這些開發者一起工作，並不收取任何費用，為全球用户開發更優秀的軟件。

我該從哪兒開始？ ​

Linux 據説只有專家才能安裝。不過比起前幾年，現在安裝並運行操作系統已經非常簡單了。

首先，打開你喜歡的發行版的網站，按照上面的安裝指南操作。一般會需要燒錄一張 DVD 或者製作一個帶有必要程序的 U 盤，然後重啓你的電腦，執行這段程序。實際上，這個操作系統的一個好處是，你可以將它直接安裝在可插拔的 U 盤上，我們有一個如何把電腦裝在 U 盤裏的完整指南。

如果你想在不影響原來舊系統的情況下運行 Linux，你可以選擇從 DVD 或 U 盤或者電腦硬盤的某個分區（分成不同的區來獨立運行不同的操作系統）單獨啓動。有些 Linux 發行版在安裝過程中會幫你自動處理磁盤分區。或者你可以用磁盤管理器 （Windows）或者磁盤工具 （macOS）自己調整分區。

這些安裝説明可能看上去很模糊，但是不要擔心：每個發行版都會提供詳細的安裝指引，雖然大多數情況下過程都差不多。比如，如果你想安裝 Ubuntu（最流行的家用 Linux 發行版中的一個），可以參考這裏的指引。（在安裝之前，你也可以嘗試運行一下）你需要下載最新的版本，燒錄到 DVD 或是 U 盤裏，然後再用光盤或 U 盤引導開機，然後跟隨安裝嚮導裏的指引操作。安裝完成時提示安裝額外軟件時，Ubuntu 會引導你打開合適的工具。

如果你要在一台全新的電腦上安裝 Linux，那沒什麼需要特別留意的。不過如果你要保留舊系統的情況下安裝新系統，我們建議你首先備份自己的數據。在安裝過程中，也要注意選擇雙啓動選項，避免擦除現有的系統和文件。你選好的發行版的介紹裏會有更詳細的説明：你可以在這裏查看 Zorin OS 的完整介紹，這裏有 Linux Mint的，其他發行版的介紹在他們各自的網站上也都會有。

就這些了！那麼，你準備好試試 Linux 了嗎？
