Adobe 軟件的最佳 Linux 替代品 ​

你是一名正在尋找 Adobe 的替代品的 Linux 用户嗎？那你不是一個人。如果你是一個狂熱的平面設計師，那麼你可能很擅長避開昂貴的 Adobe 產品。不過，對於 Adobe 來説，Linux 用户通常是其支持最不利的。因此，Adobe 的替代品是必須的 —— 但是最好的選擇是什麼？

這最終要看具體的 Adobe 程序和你希望完成的事情。幸運的是，由於需求是所有發明之母，有人響應了這些號召。其結果是出現了一系列高效的 Adobe 替代品。

Evince (Adobe Acrobat Reader) ​

就像 Adobe Acrobat Reader 一樣，Evince 是一個“支持多種文檔格式的文檔查看器”。例如，用户可以使用 Evince 作為 PDF 查看器。它還支持各種漫畫書格式（cbr、cbz、cb7 和 cbt）。你可以在 Evince 網站上找到支持格式的完整列表。

對於 Evince ，Linux 用户不用高估，也不用貶低，它就是個標準的查看器。你可以在需要時前往官方網站進行更新。

Pixlr (Adobe Photoshop) ​

關於 Pixlr 的很棒的一點是這個 Adobe 替代品的各種工具可以在線獲得。如果你有一個互聯網連接，那麼你就有一個強大的圖像編輯工作區。

Pixlr Editor 是 Photoshop 的一個功能強大的替代品，你可以使用圖層和相關效果。它還有一些漂亮的繪圖和顏色編輯工具。Pixlr Express 沒有這麼多功能，因為它主要用於圖像增強、調整顏色和清晰度，並增加一些 Instagram 適用的效果！

你可以通過 Pixlr 完成的任務簡直不可置信，而且完全免費的。

Inkscape (Adobe Illustrator) ​

Inkscape是另一個值得推薦的免費 Adobe 替代品。它主要作為一個“專業的矢量圖形編輯器”。除了 Illustrator，Inkscape 也與 Corel Draw、Freehand 和 Xara X 的功能差不多。

它的矢量設計工具可用於製作 logo 和“高可伸縮性”藝術品。Inkscape 包含繪圖、形狀和文本工具。圖層工具允許你鎖定、分組或隱藏單個圖層。

Pinegrow Web Editor (Adobe Dreamweaver) ​

Pinegrow Web Editor 是 Dreamweaver 在 Linux 上的絕佳替代品。該程序可讓你在桌面上直接製作 HTML 網站。

不僅是使用代碼創建（而且需要稍後預覽），Pinegrow 可以提供詳細的可視化編輯體驗。你可以直接查看和測試你的 HTML 項目，實時瞭解鏈接是否正常工作，或者圖片是否在它該在的地方。Pinegrow 還附帶了 WordPress 主題構建器。

免費試用 30 天。如果你喜歡，你可以一次性支付 $49 購買。

Scribus (Adobe InDesign) ​

Scribus 可能是最接近 Adobe InDesign 的替代品。根據開發者的説法，你應該認真考慮使用 Scribus，因為它是可靠和免費的。

實際上，Scribus 不僅僅是一個出色的桌面出版工具，也是一個很好的自出版工具。當你可以自己做高質量的雜誌和書籍時，為什麼要依靠昂貴的商業軟件來創建？Scribus 目前允許設計師使用一個 200 色的調色板，下一個穩定版中承諾將會加倍顏色數。

digiKam (Adobe Lightroom) ​

digiKam 也許是目前 Linux 用户最好的 Lightroom 替代品。功能包括導入照片、整理圖片集、圖像增強、創建幻燈片等功能。

它的時尚設計和先進的功能是真正用心之作。實際上，digiKam 背後的人是攝影師們。不僅如此，他們希望在 Linux 中完成在 Lightroom 能做的任何工作。

Webflow (Adobe Muse) ​

Webflow 是另一個可以證明你無需下載軟件而可以完成很多事的網站。這是一個非常方便的 Adobe Muse 替代品，Webflow 是創建高響應式網站設計的理想選擇。

Webflow 的最好的一方面是你不需要自己編寫代碼。你只需拖放圖像並寫入文本。Webflow 為你做了所有雜事。你可以從頭開始構建網站，也可以使用各種模板。雖然是免費的，但是其高級版本還提供了額外的功能，如能夠輕鬆地導出 HTML 和 CSS 以在其他地方使用。

Tupi (Adobe Animate) ​

Tupi 是 Adobe Animate 的替代品，或者也可以用於那些不太熱衷於 Flash 的人。當然，Tupi 的作者説這並不是與 Flash 競爭。然而，其使用 HTML5 的能力使其成為了理想的替代品。

在 PC 或平板電腦上繪製 2D 動畫。不確定如何開始？使用網站的 YouTube 教程瞭解如何製作剪貼畫動畫以及更多。

Black Magic Fusion (Adobe After Effects) ​

Black Magic Fusion 註定是 Adobe After Effects 的替代者。這個視覺效果軟件歷經了大約 25 年的開發！Fusion 通常用於在好萊塢電影和電視節目中製造令人印象深刻的效果 —— 這靠的是其豐富而時尚的功能。

Fusion 通過使用節點，即那些“代表效果、過濾器和其他處理的小圖標”工作。將這些節點連接在一起，創建一系列複雜的視覺效果。該程序包括許多功能，如圖片修飾、對象跟蹤和令人興奮的 3D 效果。

你可以選擇免費版或者 $995 的 Fusion Studio。為了幫助你決定，你可以比較免費和高級版的 Fusion 功能。

總結 ​

如你所見，這些遠不止於是 Adobe 替代品。由於開源的緣故，顯著提升的替代品的不斷地發佈。我們很快就會看到一個僅為 Linux 用户創建的完整套件。在此之前，你可以隨意選擇這些替代品。
