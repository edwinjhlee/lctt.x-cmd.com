運行在樹莓派和 Arduino 上的開源社交機器人套件 ​

Thecorpora 的發佈的 “Q.bo One” 機器人基於 RPi 3 和 Arduino，並提供立體相機、麥克風、揚聲器，以及視覺和語言識別。

2010 年，作為一個開源概念驗證和用於探索 AI 在多傳感器、交互式機器人的能力的研究項目，機器人開發商 Francisco Paz 及它在巴塞羅那的 Thecorpora 公司推出了首款 Qbo “Cue-be-oh” 機器人。在今年 2 月移動世界大會上的預覽之後，Thecorpora 把它放到了 Indiegogo 上，與 Arrow 合作推出了第一個批量生產的社交機器人版本。

Q.bo One 的左側

Q.bo One 的頂部

像原來一樣，新的 Q.bo One 有一個帶眼睛的球形頭（雙立體相機）、耳朵（3 個麥克風）和嘴（揚聲器），並由 WiFi 和藍牙控制。 Q.bo One 也同樣採用開源 Linux 軟件和開放規格硬件。然而，它不是使用基於 Intel Atom 的 Mini-ITX 板，而是在與 Arduino 兼容的主板相連的 Raspberry Pi 3 上運行 Raspbian。

Q.bo One 側視圖*

Q.bo One 於 7 月中旬在 Indiegogo 上架，起價為 369 美元（早期買家）或 399 美元，有包括內置的樹莓派 3 和基於 Arduino 的 “Qboard” 控制器板。它還有售價 $499 的完整套裝。目前，Indiegogo 上的眾籌目標是 $100,000，現在大概達成了 15%，並且它 12 月出貨。

更專業的機器人工程師和嵌入式開發人員可能會想要使用價值 $99 的只有樹莓派和 Qboard PCB 和軟件的版本，或者提供沒有電路板的機器人套件的 $249 版本。使用此版本，你可以用自己的 Arduino 控制器替換 Qboard，並將樹莓派 3 替換為另一個 Linux SBC。該公司列出了 Banana Pi、BeagleBone、Tinker Board 以及即將退市的 Intel Edison，作為兼容替代品的示例。

Q.bo One 套件

與 2010 年的 Qbo 不同，Q.bo One 除了球面頭部之外無法移動，它可以在雙重伺服系統的幫助下在底座上旋轉，以便跟蹤聲音和動作。Robotis Dynamixel 舵機同樣開源，樹莓派基於 TurtleBot 3 機器人工具包，除了左右之外，還可以上下移動。

Q.bo One 細節

Qboard 細節

Q.bo One 類似於基於 Linux 的 Jibo “社交機器人”，它於 2014 年在 Indiegogo 眾籌，最後達到 360 萬美元。然而，Jibo 還沒有出貨，最近的推遲迫使它在今年的某個時候發佈一個版本。

Q.bo One

我們大膽預測 Q.bo One 將會在 2017 年接近 12 月出貨。核心技術和 AI 軟件已被證明，而樹莓派和 Arduino 技術也是如此。Qboard 主板已經由 Arrow 製造和認證。

開源設計表明，即使是移動版本也不會有問題。這使它更像是滾動的人形生物 Pepper，這是一個來自 Softbank 和 Aldeberan 類似的人工智能對話機器人。

Q.bo One 自原始版以來添加了一些技巧，例如由 20 個 LED 組成的“嘴巴”， 它以不同的、可編程的方式在語音中模仿嘴唇開合。如果你想點擊機器人獲得關注，那麼它的頭上還有三個觸摸傳感器。但是，你其實只需要説話就行，而 Q.bo One 會像一個可卡犬一樣轉身並凝視着你。

接口和你在樹莓派 3 上的一樣，它在我們的 2017 黑客電路板調查中消滅了其他對手。為樹莓派 3 的 WiFi 和藍牙安裝了天線。

Q.bo One 軟件架構

Q.bo One 及 Scratch 編程

Qboard（也稱為 Q.board）在 Atmel ATSAMD21 MCU 上運行 Arduino 代碼，並有三個麥克風、揚聲器、觸摸傳感器、Dynamixel 控制器和用於嘴巴的 LED 矩陣。其他功能包括 GPIO、I2C接口和可連接到台式機的 micro-USB 口。

Q.bo One 可以識別臉部和追蹤移動，機器人甚至可以在鏡子中識別自己。在雲連接的幫助下，機器人可以識別並與其他 Q.bo One 機器人交談。機器人可以在自然語言處理的幫助下回答問題，並通過文字轉語音朗讀。

可以使用 Scratch 編程，它是機器人的主要功能，可以教孩子關於機器人和編程。機器人也是為教育者和製造者設計的，可以作為老年人的伴侶。

基於 Raspbian 的軟件使用 OpenCV 進行視覺處理，並可以使用各種語言（包括 C++）進行編程。該軟件還提供了 IBM Bluemix、NodeRED 和 ROS 的鈎子。大概你也可以整合 Alexa 或 Google Assistant語音代理，雖然 Thecorpora 沒有提及這一點。

更多信息

Q.bo One 在 7 月中旬在 Indiegogo 上架，起價為完整套件 $369 和完整組合 $499 。出貨預計在 2017 年 12 月。更多信息請參見 Q.bo One 的 Indiegogo 頁面 和Thecorpora 網站。
