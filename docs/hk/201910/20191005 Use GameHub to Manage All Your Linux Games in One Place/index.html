用 GameHub 集中管理你 Linux 上的所有遊戲 ​

你在 Linux 上是怎麼玩遊戲的呢? 讓我猜猜，要不就是從軟件中心直接安裝，要不就選 Steam、GOG、Humble Bundle 等平台，對吧？但是，如果你有多個遊戲啓動器和客户端，又要如何管理呢？好吧，對我來説這簡直令人頭疼 —— 這也是我發現 GameHub 這個應用之後，感到非常高興的原因。

GameHub 是為 Linux 發行版設計的一個桌面應用，它能讓你“集中管理你的所有遊戲”。這聽起來很有趣，是不是？下面讓我來具體説明一下。

集中管理不同平台 Linux 遊戲的 GameHub ​

讓我們看看，對玩家來説，讓 GameHub 成為一個不可或缺的 Linux 應用的功能，都有哪些。

Steam、GOG & Humble Bundle 支持 ​

它支持 Steam、GOG 和 Humble Bundle 賬户整合。你可以登錄你的 GameHub 賬號，從而在你的庫管理器中管理所有遊戲。

對我來説，我在 Steam 上有很多遊戲，Humble Bundle 上也有一些。我不能確保它支持所有平台，但可以確信的是，主流平台遊戲是沒有問題的。

支持原生遊戲 ​

有很多網站專門推薦 Linux 遊戲，並支持下載。你可以通過下載安裝包，或者添加可執行文件，從而管理原生遊戲。

可惜的是，現在無法在 GameHub 內搜索 Linux 遊戲。如上圖所示，你需要分別下載遊戲，隨後再將其添加到 GameHub 中。

模擬器支持 ​

用模擬器，你可以在 Linux 上玩復古遊戲。正如上圖所示，你可以添加模擬器（並導入模擬的鏡像）。

你可以在 RetroArch 查看已有的模擬器，但也能根據需求添加自定義模擬器。

用户界面 ​

當然，用户體驗很重要。因此，探究下用户界面都有些什麼，也很有必要。

我個人覺得，這一應用很容易使用，並且黑色主題是一個加分項。

手柄支持 ​

如果你習慣在 Linux 系統上用手柄玩遊戲 —— 你可以輕鬆在設置裏添加，啓用或禁用它。

多個數據提供商 ​

因為它需要獲取你的遊戲信息（或元數據），也意味着它需要一個數據源。你可以看到下圖列出的所有數據源。

這裏你什麼也不用做 —— 但如果你使用的是 steam 之外的其他平台，你需要為 IDGB 生成一個 API 密鑰。

我建議只有出現 GameHub 中的提示/通知，或有些遊戲在 GameHub 上沒有任何描述/圖片/狀態時，再這麼做。

兼容性選項 ​

你有不支持在 Linux 上運行的遊戲嗎？

不用擔心，GameHub 上提供了多種兼容工具，如 Wine/Proton，你可以利用它們來玩遊戲。

我們無法確定具體哪個兼容工具適用於你 —— 所以你需要自己親自測試。然而，對許多遊戲玩家來説，這的確是個很有用的功能。

GameHub: 如何安裝它呢？ ​

首先，你可以直接在軟件中心或者應用商店內搜索。 它在 “Pop!_Shop” 之下。所以，它在絕大多數官方源中都能找到。

如果你在這些地方都沒有找到，你可以手動添加源，並從終端上安裝它，你需要輸入以下命令：

sudo add-apt-repository ppa:tkashkin/gamehub
sudo apt update
sudo apt install com.github.tkashkin.gamehub

如果你遇到了 “add-apt-repository command not found” 這個錯誤，你可以看看，add-apt-repository not found error.這篇文章，它能幫你解決這一問題。

這裏還提供 AppImage 和 FlatPak 版本。 在官網 上，你可以針對找到其他 Linux 發行版的安裝手冊。

同時，你還可以從它的 GitHub 頁面下載之前版本的安裝包.

GameHub

如何在 GameHub 上管理你的遊戲？ ​

在啓動程序後，你可以將自己的 Steam/GOG/Humble Bundle 賬號添加進來。

對於 Steam，你需要在 Linux 發行版上安裝 Steam 客户端。一旦安裝完成，你可以輕鬆將賬號中的遊戲導入 GameHub。

對於 GOG & Humble Bundle，登錄後，就能直接在 GameHub 上管理遊戲了。

如果你想添加模擬器或者本地安裝文件，點擊窗口右上角的 “+” 按鈕進行添加。

如何安裝遊戲？ ​

對於 Steam 遊戲，它會自動啓動 Steam 客户端，從而下載/安裝遊戲（我希望之後安裝遊戲，可以不用啓動 Steam！）

但對於 GOG/Humble Bundle，登錄後就能直接、下載安裝遊戲。必要的話，對於那些不支持在 Linux 上運行的遊戲，你可以使用兼容工具。

無論是模擬器遊戲，還是本地遊戲，只需添加安裝包或導入模擬器鏡像就可以了。這裏沒什麼其他步驟要做。

注意 ​

GameHub 是相當靈活的一個集中游戲管理應用。 用户界面和選項設置也相當直觀。

你之前是否使用過這一應用呢？如果有，請在評論裏寫下你的感受。

而且，如果你想嘗試一些與此功能相似的工具/應用，請務必告訴我們。
