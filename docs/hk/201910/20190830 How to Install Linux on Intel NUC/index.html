在 Intel NUC 上安裝 Linux ​

在上週，我買了一台 InteL NUC。雖然它是如此之小，但它與成熟的桌面型電腦差別甚小。實際上，大部分的基於 Linux 的微型 PC 都是基於 Intel NUC 構建的。

我買了第 8 代 Core i3 處理器的“準系統barebone” NUC。準系統意味着該設備沒有 RAM、沒有硬盤，顯然也沒有操作系統。我添加了一個 Crucial 的 8 GB 內存條（大約 33 美元）和一個 240 GB 的西數的固態硬盤（大約 45 美元）。

現在，我已經有了一台不到 400 美元的電腦。因為我已經有了一個電腦屏幕和鍵鼠套裝，所以我沒有把它們計算在內。

我買這個 Intel NUC 的主要原因就是我想在實體機上測試各種各樣的 Linux 發行版。我已經有一個 樹莓派 4 設備作為一個入門級的桌面系統，但它是一個 ARM 設備，因此，只有少數 Linux 發行版可用於樹莓派上。（LCTT 譯註：新發布的 Ubuntu 19.10 支持樹莓派 4B）

這個文章裏的亞馬遜鏈接是（原文的）受益連接。請參閲我們的受益政策。

在 NUC 上安裝 Linux ​

現在我準備安裝 Ubuntu 18.04 長期支持版，因為我現在就有這個系統的安裝文件。你也可以按照這個教程安裝其他的發行版。在最重要的分區之前，前邊的步驟都大致相同。

第一步：創建一個 USB 啓動盤 ​

你可以在 Ubuntu 官網下載它的安裝文件。使用另一個電腦去創建一個 USB 啓動盤。你可以使用像 Rufus 和 Etcher 這樣的軟件。在 Ubuntu上，你可以使用默認的啓動盤創建工具。

第二步：確認啓動順序是正確的 ​

將你的 USB 啓動盤插入到你的電腦並開機。一旦你看到 “Intel NUC” 字樣出現在你的屏幕上，快速的按下 F2 鍵進入到 BIOS 設置中。

在這裏，只是確認一下你的第一啓動項是你的 USB 設備。如果不是，切換啓動順序。

如果你修改了一些選項，按 F10 鍵保存退出，否則直接按下 ESC 鍵退出 BIOS 設置。

第三步：正確分區，安裝 Linux ​

現在當機器重啓的時候，你就可以看到熟悉的 Grub 界面，可以讓你試用或者安裝 Ubuntu。現在我們選擇安裝它。

開始的幾個安裝步驟非常簡單，選擇鍵盤的佈局，是否連接網絡還有一些其他簡單的設置。

你可能會使用常規安裝，默認情況下會安裝一些有用的應用程序。

接下來的是要注意的部分。你有兩種選擇：

  • “擦除磁盤並安裝 UbuntuErase disk and install Ubuntu”：最簡單的選項，它將在整個磁盤上安裝 Ubuntu。如果你只想在 Intel NUC 上使用一個操作系統，請選擇此選項，Ubuntu 將負責剩餘的工作。
  • “其他選項Something else”：這是一個控制所有選擇的高級選項。就我而言，我想在同一 SSD 上安裝多個 Linux 發行版。因此，我選擇了此高級選項。

如果你選擇了“擦除磁盤並安裝 UbuntuErase disk and install Ubuntu”，點擊“繼續Continue”，直接跳到第四步，

如果你選擇了高級選項，請按照下面剩下的部分進行操作。

選擇固態硬盤，然後點擊“新建分區表New Partition Table”。

它會給你顯示一個警告。直接點擊“繼續Continue”。

現在你就可以看到你 SSD 磁盤裏的空閒空間。我的想法是為 EFI bootloader 創建一個 EFI 系統分區。一個根（/）分區，一個主目錄（/home）分區。這裏我並沒有創建交換分區。Ubuntu 會根據自己的需要來創建交換分區。我也可以通過創建新的交換文件來擴展交換分區。

我將在磁盤上保留近 200 GB 的可用空間，以便可以在此處安裝其他 Linux 發行版。你可以將其全部用於主目錄分區。保留單獨的根分區和主目錄分區可以在你需要重新安裝系統時幫你保存裏面的數據。

選擇可用空間，然後單擊加號以添加分區。

一般來説，100MB 足夠 EFI 的使用，但是某些發行版可能需要更多空間，因此我要使用 500MB 的 EFI 分區。

接下來，我將使用 20GB 的根分區。如果你只使用一個發行版，則可以隨意地將其增加到 40GB。

根目錄（/）是系統文件存放的地方。你的程序緩存和你安裝的程序將會有一些文件放在這個目錄下邊。我建議你可以閲讀一下 Linux 文件系統層次結構來了解更多相關內容。

填入分區的大小，選擇 Ext4 文件系統，選擇 / 作為掛載點。

接下來是創建一個主目錄分區，我再説一下，如果你僅僅想使用一個 Linux 發行版。那就把剩餘的空間都使用完吧。為主目錄分區選擇一個合適的大小。

主目錄是你個人的文件，比如文檔、圖片、音樂、下載和一些其他的文件存儲的地方。

既然你創建好了 EFI 分區、根分區、主目錄分區，那你就可以點擊“現在安裝Install Now”按鈕安裝系統了。

它將會提示你新的改變將會被寫入到磁盤，點擊“繼續Continue”。

第四步：安裝 Ubuntu ​

事情到了這就非常明瞭了。現在選擇你的分區或者以後選擇也可以。

接下來，輸入你的用户名、主機名以及密碼。

看 7-8 分鐘的幻燈片就可以安裝完成了。

一旦安裝完成，你就可以重新啓動了。

當你重啓的時候，你必須要移除你的 USB 設備，否則你將會再次進入安裝系統的界面。

這就是在 Intel NUC 設備上安裝 Linux 所需要做的一切。坦白説，你可以在其他任何系統上使用相同的過程。

Intel NUC 和 Linux 在一起：如何使用它？ ​

我非常喜歡 Intel NUC。它不佔用太多的桌面空間，而且有足夠的能力去取代傳統的桌面型電腦。你可以將它的內存升級到 32GB。你也可以安裝兩個 SSD 硬盤。總之，它提供了一些配置和升級範圍。

如果你想購買一個桌面型的電腦，我非常推薦你購買使用 Intel NUC 迷你主機。如果你不想自己安裝系統，那麼你可以購買一個基於 Linux 的已經安裝好的系統迷你主機。
