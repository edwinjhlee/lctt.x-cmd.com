期待已久的 Linux Mint 21 發佈 ​

Linux Mint 終於發佈了基於 Ubuntu 22.04 LTS 的 “Vanessa”，並帶來了很多有用的改進。

Linux Mint 是 最受歡迎的 Linux 發行版之一。它使用 Ubuntu 作為其基礎，特別是它基於 長期支持 的 Ubuntu 版本，以獲得長達 5 年的軟件支持。

現在，我們有一個新的版本升級，即 Linux Mint 21 “Vanessa”，它基於 4 月份最新發布的 Ubuntu 22.04 LTS 版本。因此，用户可以預期它的安全更新可以支持到 2027 年。

讓我們來看看這個版本的亮點。

Linux Mint 21 Vanessa 的新亮點 ​

它採用了穩定的、改進的 Linux 5.15 LTS 內核，Linux Mint 21 帶來了一系列新的增加、變化和完善。

現有用户的升級工具 ​

現有的 Mint 20.3 用户可以使用新的基於 GUI 的升級工具輕鬆更新他們的系統。

用户會看到一個需要安裝或升級的新軟件包的列表，這也包括了對你可能手動添加的第三方 PPA 庫的檢查。

新的藍牙管理器 ​

Blueman 現在取代了圖形界面的 GNOME 藍牙管理器 Blueberry。

之所以這樣做，主要是因為 Blueman 提供了更多的功能和連接選項，以及對多種桌面環境的更好支持。此外，Blueman 的用户界面與 Linux Mint 完美地融合在一起。

Blueman 包括一些高級選項，可能大多數用户用不到，但它是一個好工具。

新的進程監控托盤圖標 ​

不管是對於資深用户還是初級用户來説，一個非常有用的功能是引入了一個新的托盤圖標，可以監控進程！

這個托盤圖標將通知用户是否有任何自動化進程（如更新和系統快照）在後台運行。

當系統變得緩慢時，Mint 用户將很容易知道該去哪裏找到問題！

增強的縮略圖支持 ​

以前，一些文件類型沒有任何縮略圖顯示，這樣的用户體驗不是很好。

為了解決這個問題，這個版本引入了一個新的項目 xapp-thumbnails，併為包括 AppImage、ePub、MP3、RAW 圖片和 WebP 在內的文件類型帶來了縮略圖支持。

XApp 的改進 ​

以前的 Timeshift 備份工具現在成為了一個 XApp，並由 Mint 團隊正式維護。此外，在 rsync 模式下，如果快照導致磁盤上的可用空間少於 1GB，則會計算出下一次快照所需的空間並跳過下一次快照。

Xviewer、Warpinator、Thingy 和 WebApp 管理器也有了其他改進。

Cinnamon 5.4.2 ​

Linux Mint 的旗艦桌面環境 Cinnamon 得到了良好的內部升級。

默認的窗口管理器 Muffin 現在重新基於較新的 Mutter 3.36 代碼庫開發。

窗口 UI 也有一些細微的改進，包括主題和動畫。

其他增加的功能和改進 ​

其他一些變化包括：

  • 改進了對 AppImage 的支持，這與 Ubuntu 22.04 不同
  • 目錄中出現了一組新的漂亮的壁紙

你可以在我們專門的 Linux Mint 21 功能 文章中探索更多關於它的新亮點。

獲取 Linux Mint 21 ​

如果你正在使用 Mint 20.3，你應該能在幾天內升級到 Mint 21。圖形化的更新過程應該會在幾天後出現。

你可以選擇從 Linux Mint 的下載頁面下載 ISO，進行全新安裝。

獲取 Linux Mint 21

如果你的網絡速度慢或不穩定，你也可以 用這個種子鏈接。

享受新鮮的 Mint 吧 🙂
