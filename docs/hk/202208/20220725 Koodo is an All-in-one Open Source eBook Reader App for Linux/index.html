Koodo：一款適用於 Linux 的一體化開源電子書閲讀器應用 ​

有幾個可供桌面 Linux 用户使用的 電子書閲讀器。

幾乎所有發行版都帶有可以打開 PDF 文件的文檔閲讀器。它還可能支持其他文件格式，例如 epub 或 Mobi，但不一定。

這就是為什麼需要像 Foliate 和 Calibre 這樣的專門應用來閲讀和管理各種格式的電子書的原因。

最近，我遇到了另一個開源軟件，它為電子書閲讀器提供了幾個令人興奮的功能。

Koodo：它有你能想到的一切 ​

Koodo 是一款多合一的開源電子書閲讀器，具有幫助你更好地管理和閲讀電子書的功能。它是一個跨平台應用，你可以在 Linux、Windows 和 macOS 上下載。你甚至可以 在瀏覽器中使用它。

它的用户界面看起來很現代，可能是因為它是一個 Electron 應用。你必須導入書籍並將它們添加到 Koodo。它不按文件夾導入書籍。不過，你可以選擇多個文件進行導入。書太多了？可以將一些添加到你的收藏夾以便快速訪問。

我使用了 AppImage 格式的軟件包，但由於未知原因，它沒有顯示文件的縮略圖。

它支持流行的電子書文件格式，如 PDF、Mobi 和 Epub。但不止這些，它還支持 CBR、CBZ 和 CBT 等漫畫書格式，它還支持更多。它還可以閲讀 FictionBooks（.fb2）、Markdown 和富文本格式（RTF）以及微軟 Office Word 文檔（.docx）。

除了支持很多文件格式外，它還提供了多種功能來改善你的閲讀體驗。

你可以高亮顯示文本並使用文本註釋對其進行註釋。你還可以在當前文檔或谷歌上搜索選定的文本。

你可以從主應用窗口的側邊欄中訪問高亮顯示的文本和註釋。

也有文本到語音和翻譯選定文本的選項。但是，這兩個功能在我的測試中都不起作用。我使用的是 Koodo 的 AppImage 版本。

Koodo 支持各種佈局。你可以以單列、雙列或連續滾動佈局閲讀文檔。對於 ePub 和 Mobi 格式，它會自動以雙列布局打開。對於 PDF，默認選擇單列布局。

你可以根據自己的喜好自定義 UI。更改字體、大小、段落間距、文本顏色、背景顏色、行間距、亮度等。

Koodo 支持夜間閲讀模式以及五個不同的主題。你可以根據自己的喜好在主題之間切換。

你還可以使用 Dropbox 或其他支持 Webdav 協議的 雲服務 跨設備同步你的書籍和閲讀數據（如高亮、筆記等）。

在 Linux 上獲取 Koodo ​

如果你想體驗一下 Koodo，你可以試試它的在線版本。你可以在瀏覽器中使用 Koodo。你的數據本地存儲在瀏覽器中，如果你清理瀏覽器緩存，你會丟失數據（高亮、筆記等，但不會丟失計算機上存儲的書籍）。

在線嘗試 Koodo

如果你喜歡它的功能，可以選擇在您的計算機上安裝 Koodo。

Linux 用户有多種選擇。你有 Debian 和基於 Ubuntu 的發行版的 deb 文件、Red Hat 和 Fedora 的 RPM，以及面向所有發行版的 Snap、AppImage 和可執行文件。

你可以從項目主頁獲取你選擇的安裝程序。

下載 Koodo

總結 ​

Koodo 並不完美。它有大量功能，但並非所有功能都能完美運行，正如我在測試中發現的那樣。

儘管如此，它仍然是一個很好的應用，有可能在用户中流行起來。只有少數幾個應用包含如此多的功能。

感謝 Koodo 開發人員為桌面用户創建了一個有前途的開源應用。

你可以 訪問該項目的倉庫 來查看源代碼、報告 bug 或者通過給項目加星來向開發者表達喜愛。
