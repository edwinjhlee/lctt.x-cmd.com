淺議 Firefox 多賬户容器 ​

隨着在設備上使用各種程序的用户的需求變得越來越複雜，程序本身也需要跟上用户的現實需求和未來期望。

我發現我每天需要的東西是一個在網頁瀏覽器保持登錄多個賬號的簡單方法。我 可以 根據需要對我的每個賬號進行登錄和註銷操作，但在短時間內切換多個賬號時，這變得非常乏味。

最初，我使用谷歌瀏覽器，它擁有管理多個帳户的能力。這很有效，但管理起來略顯繁瑣，而且明明只需 一個 谷歌賬號就能搞定的事卻要創建一個新的谷歌賬號來完成，這顯得有點兒笨拙。

這是我轉而使用 Firefox 多賬户容器Multi-Account Containers 功能的原因。它不僅比我在谷歌 Chrome 瀏覽器上的設置靈活得多，而且我還使用了由我的瀏覽器開發者自己創建的工具，從而在整體上獲得了更流暢和更簡單的體驗。

Firefox 中的多帳户容器是什麼？ ​

如果你想將數字生活的各個部分彼此分開，多賬户容器也非常有效。通過使用容器，你在一個容器中的瀏覽活動不會與其他容器共享。這種隔離意味着你可以在不同容器中登錄同一網站上的兩個不同帳户。你的登錄會話、網站偏好和跟蹤數據將被限制在你使用某個網站的容器中。

它還有什麼其他優勢？想像一下，你在亞馬遜或其他電子商務網站上購物。你瀏覽了一些商品，但沒有購買任何東西。現在，如果你瀏覽網絡，你會看到與你瀏覽的產品相關的廣告。儘管有廣告攔截器，一些網站仍會顯示廣告。使用容器，你可以將你的購物網站與其他網站分開。（LCTT 校注：甚至根據你的瀏覽歷史，你再次訪問同一網站時看到的價格可能會被“宰熟”——反覆瀏覽代表了你的購買傾向。）

再給大家分享一個例子。Firefox 默認提供一個 Facebook 容器。默認情況下，此容器包括 Facebook、Messenger 和 Instagram 網站。這意味着當你打開這三個網站中的任何一個時，它們都只會在“Facebook 容器”中打開。因此，Facebook 將無法跟蹤你在其他網站上的活動。

這是 很少有人知道或使用的 Firefox 功能 之一。

使用多賬户容器 ​

安裝 Firefox 多賬户容器是一個非常簡單的過程，只需點擊幾下。

首先，前往 Firefox 附加組件網站上的 擴展程序頁面。之後你唯一需要做的就是單擊 “添加到 Firefox” 按鈕。

安裝完成！現在我們可以實際使用一下這個新的擴展。

可能你還沒有注意到，你的搜索欄右側應該會出現一個新圖標：

這是你將用於與 Firefox 多帳户容器交互的圖標。如果你單擊該圖標，你將看到一個小菜單：

讓我們使用這個擴展嘗試一些例子，看看多賬户容器是如何工作的。

設置容器 ​

首先，我們需要生成一個容器。點擊多賬户容器菜單中的 `管理容器Manage Containers，然後點擊 新建容器New Container。

接着輸入新容器的名稱，選擇顏色和圖標。然後，點擊 “OK” 保存新容器。

大功告成！我們現在可以返回主菜單在新容器中打開一個新選項卡：

觀察容器工作 ​

現在讓我們看看容器在使用時實際做了什麼。

我們將在一個普通的瀏覽器選項卡中訪問 Linode 管理網站，我已經在其中登錄：

現在讓我們嘗試在 Firefox 容器中打開相同的頁面，此時我被重定向到 Linode 登錄頁面：

為什麼我被重定向了？因為現在我沒有登錄。這就是 Firefox 容器的樂趣之一：在一個瀏覽器會話中登錄後，再進入一個容器，就好像你以前從未訪問過該站點一樣。

如果你在容器內完成對某個網站的登錄，你從容器中訪問該網站時將會保持登錄狀態。你還可以使用此功能從容器內登錄網站，從而使該網站的所有數據與你的正常瀏覽器數據相隔開。

注意：你的瀏覽器歷史記錄本身之類的內容仍會暴露給你的正常瀏覽器會話。容器功能只是提供了一種方法來分離本文中提到的登錄帳户等內容。

總結 ​

對於那些在乎自己的隱私，或者只是想真正嘗試對其系統的安全性進行嚴格控制的人來説，多賬户容器被證明是一個很棒的功能。

例如，你可以在容器內登錄你的谷歌帳户，谷歌永遠不會知悉你在容器外的信息。 對擁有多個帳户的人來説，此擴展程序是一個不錯的選擇。有了它無需為你要使用的每樣東西創建單獨的瀏覽器帳户。

好了，這就是 Firefox 的多帳户容器的基本知識。
