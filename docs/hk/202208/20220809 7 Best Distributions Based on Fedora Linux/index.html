7 個基於 Fedora Linux 的最佳發行版 ​

有幾十個基於 Ubuntu 的發行版可用。從 面向初學者的發行版 到 漂亮的發行版，Ubuntu 主導着 Linux 桌面空間。

如果通用發行版還不夠的話，你還會發現一些 奇怪的基於 Ubuntu 的發行版。

我不打算參與 Ubuntu 與 Fedora 的辯論。我只是説如果你想在 Fedora 領域中嘗試一些東西，我可以列出一些選項。

請記住，我不會列出面向服務器的 Linux 發行版。此處的列表適用於 桌面 Linux 用户。

該列表沒有特定的排名順序，並且提到的選項可能並不總是適合新用户。因此，在第一次安裝任何基於 Fedora 的發行版之前，請確保你瀏覽了文檔。

1、Fedora 定製版 ​

Fedora 有很多定製版spin，但沒有 Ubuntu 那麼多。

Fedora 定製版 不是基於 Fedora 的獨立發行版，而只是具有 不同桌面環境 或採用平鋪窗口管理器的不同版本的 Fedora。

如果你不喜歡默認的 GNOME 桌面環境，你可以下載其中一種。

一些可用的選項是：

  • Fedora KDE Plasma
  • Fedora i3 平鋪窗口管理器
  • Fedora LXQt
  • Fedora LXDE
  • Fedora MATE-COMPIZ
  • Fedora Cinnamon 版

2、Nobara ​

當你在找 遊戲發行版 時，列表將由 Debian 和 Arch 衍生產品佔據主導地位。因此，如果你正在尋找基於 Fedora 且具有相同效果的遊戲發行版，那麼 Nobara 就是你所需要的。

Nobara 是由 Proton GE 的維護者製作的遊戲發行版，他也是 Lutris 開發團隊的成員，因此你可以期待開箱即用的下一代遊戲體驗！

為了帶來更好的體驗，Nobara 在 Fedora 上預先應用了 30 多個補丁程序，以及一組遊戲工具，包括 Lutris、GOverlay、Stream 和 ProtonUp。

3、Ultramarine ​

基於 Fedora 的發行版，開箱即用，適用於普通用户，它就是 Ultramarine！

Ultramarine 預裝了一堆工具，包括 Flathub、RPM fusion 和該發行版自己的專用倉庫。

你將獲得一個預配置的桌面，使其看起來賞心悦目，因此你不再需要花費額外的時間進行調整。

此外，對於那些在 Fedora 基礎上尋求 Pantheon 和 Budgie 桌面環境的微調體驗的人來説，Ultramarine 是完美的選擇。

4、RisiOS ​

“一個支持 Web 應用的 Fedora。”

這是一種描述 RisiOS 的方式，但等等，不止如此。

從 Bash 腳本的用户 GUI 到歡迎屏幕，你只需單擊幾下即可準備好系統，RisiOS 讓 Fedora 的使用更加輕鬆！

RisiOS 還為你提供與 Linux Mint 相同的 Web 應用管理器，而且非常棒。

但是在你跳轉到下載頁面之前，要記住一件事是 RisiOS 仍處於測試階段（如網站所説的 Big beta），你可能會遇到一些小問題。

5、Qubes OS ​

Qubes OS 是一個有趣的 Linux 發行版，它讓你可以自由選擇要用作基礎的操作系統。它也提供了一個 Fedora 模板，並且他們會定期維護它。

事實上，Qubes OS 也是一個 注重隱私的 Linux 發行版。因此，你可以在使用基於 Fedora 的產品時獲得最新技術，而且完全自由。

值得注意的是，Qubes OS 需要大量系統資源和至少 8-16 GB 的內存才能使用，並且具有挑戰性的學習曲線。

6、Berry Linux ​

Berry Linux 是一個簡單的基於 Fedora 的發行版，你可以直接從 CD 或任何其他介質啓動。它支持自動硬件檢測，並且似乎定期維護。

Berry Linux 提供對英語和日語的支持。它預裝了一些媒體播放器、照片編輯應用和基本應用。

7、ClearOS ​

它不是 來自 Intel 的 Clear Linux 項目，儘管聽起來很相似。

ClearOS 是基於 Fedora 的發行版，專為服務器環境量身定製，或幫助你在 HP 支持的家庭網絡上運行 IT 相關任務和流式傳輸音樂/視頻。你必須根據自己的要求同時購買家庭版/企業版。

如果你不想購買而想自己管理，還有一個社區版。

你的看法 ​

長期使用 Linux 的用户可能還記得 Korora 和 Chapeau 發行版。它們曾經在 Fedora 用户中很受歡迎，但從那時起這些項目就停止了。

雖然 Fedora 本身很棒，但我並不反對衍生發行版。看看 Linux Mint 的成功。它是 Ubuntu 的衍生產品，但已經獲得瞭如此好的用户羣。誰知道這些基於 Fedora 的發行版是否會像 Mint 一樣流行？

我缺失了任何基於 Fedora 的活躍發行版嗎？你如何看待 Fedora 衍生版及其定製版本？ 在下面的評論中告訴我！
