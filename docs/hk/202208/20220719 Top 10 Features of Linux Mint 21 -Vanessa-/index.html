Linux Mint 21 “Vanessa” 的 10 大特色 ​

我們總結了 Linux Mint 21 “Vanessa” 的 10 大特色，你可以看看有哪些是為你而準備的。

Linux Mint 21 “Vanessa” 是 Linux Mint 的第 36 個發佈版本，它帶來了一系列特色，以及對桌面上的有用改善。這些特色散落在 Cinnamon 桌面、內核變化、Xapps 更新等處。

我在這份 Linux Mint 21 的重要特色列表對它們做了個總結。

Linux Mint 21 “Vanessa” 的重要特色 ​

1、Ubuntu 22.04 及其相關更新 ​

也許最重要的變化就是 Linux Mint 21 的基礎了，它現在基於 Ubuntu 22.04 “Jammy Jellyfish” 。上一次的主要版本，即 Linux Mint 20 “Ulyana” ，是基於四年前發佈的 Ubuntu 20.04 “Focal Fossa” 。滄海桑田，現在與 2020 年的世界已然完全不同。

因此，大量的軟件包、版本升級、新的性能改善 —— 所有的這些底層更新都來到了 Linux Mint 21 。這包括最新的長期支持的 Linux 內核 5.15 ，這帶來了更多硬件系列的支持、以及針對編程、開發和網絡的工具鏈的更新。

2、Timeshift 備份工具的重大變化 ​

幾個月前，Mint 開發團隊 宣佈 ：他們將接管著名的備份工具 Timeshift，並將其作為一個 “XApps” 繼續開發。這是一個重大變化。你可能會問為什麼？

好吧，Timeshift 工具的開發者 Tony George 正忙於其它的項目。你可能聽説過 Linux 的 “TeeJeeTech” 應用。它是由 Tony 創建的，並且有一些很酷的應用。因此，他沒有足夠多的時間來專注於 Timeshift 的開發和改進。

説到這裏，由於 Linux Mint 現在在維護它，這個發佈版本帶來了一些新的功能，例如，在 rsync 模式（不是 btrfs 模式）時，現在 Timeshift 可以確定進行下一次備份需要多少磁盤空間。此外，如果它看到磁盤空間在備份後小於 1 GB ，會停止備份過程。

3、WebP 支持 ​

WebP 圖像是谷歌為 Web 創建的一種相當新的圖像格式。它帶來了更好的壓縮率，在保持與傳統的 JPEG 和 PNG 圖片相當的良好質量的同時，減少了文件大小。

在 Linux 桌面支持 WebP（如查看圖像、縮略圖或編輯）需要 額外安裝 一些軟件包。考慮到其流行程度，Linux Mint 開發團隊為桌面應用及這個衍生發行版帶來了開箱即用的 WebP 支持。

這意味着，在 Nemo 文件管理器中可以顯示 WebP 圖像的縮略圖，並可以在 xviewer 中查看它們。Mint 開發團隊總是優先考慮到最終用户，而諸如 Ubuntu 之類的其它發行版在默認支持 WebP 方面仍然落後。不僅如此，新的應用程序 xapp-thumbnailers 現在還能幫助 Nemo 文件管理器預覽更多的文件類型，如：

  • ePub
  • 帶有專輯封面的 MP3
  • RAW 圖像
  • AppImage

4、進程監視器 ​

一個名稱為 進程監視器process monitor 的小巧方便的工具，將會告知你係統中正在發生什麼。當你的系統正在自動更新或通過 Timeshift 備份時，系統托盤上的這個小圖標就會顯示出來。在這些情況下，你的系統可能會變慢，而這個漂亮的圖標可以告訴你原因。

5、改善打印支持 ​

Linux Mint 針對硬件設備配置了各種驅動程序，默認情況下就支持打印機。這個版本的 Mint 帶來 網絡打印協議Internet Printing Protocol（IPP）支持，可以免驅動進行打印和掃描。

另外，它也默認安裝了 HP 的驅動程序 HPLIP 的最新版本 3.21.12 。

所有的這些變化都簡化了打印機和掃描儀的使用，而像你這樣的最終用户可以輕鬆地打印和掃描。這是一個 Linux 發行版的一個重要的方面，但並不是總是能順利工作的。在 點評過很多發行版 後，我發現很多發行版無法檢測到打印機，乃至不能打印。

很高興看到 Mint 開發團隊對這個關鍵功能做出了貢獻。

6、窗口動畫更新 ​

窗口和桌面動畫效果有一些相當大的變化。首先，合併了窗口和桌面的效果設置。先前，是在不同的部分對動畫進行細微的控制。

最後，還有一個可以禁用或啓用在整個桌面上的所有動畫的全局開關，給予你更多的控制選項。

我相信這是一個經過精心設計的、可以讓人更清楚地瞭解的對話框和高級選項。

7、Mutter 重新構建 ​

讓我們來看一下隨 Linux Mint 21 而來的 Cinnamon 桌面環境版本 5.4。它是最新的 Cinnamon 發佈版本，Mint 是第一個將其帶給用户的的發行版（除了傳統的 Arch Linux 用户，他們得到它 有點超早）。

最後，開發團隊對 Cinnamon 5.4 中的窗口管理器 Muffin 根據上游的 Mutter 進行了重新構建。由於 Muffin 最初是從 Mutter 復刻出來的，所以它總是落後於上游的 Mutter 的功能，即使是有一些後期移植的改變。為使 Muffin 儘可能地接近 Mutter 代碼庫，團隊在包含的特色功能、錯誤修復及清理方面付出了大量的努力。

因此，在未來，更容易從 Mutter 上游移植變化和在需要的時候清理 Muffin。

8、窗口管理器和 GTK 主題 ​

伴隨着 Muffin 的變化，開發團隊也將 GNOME 控制中心的一些顯示設置移動到了 Cinnamon 控制中心。此外，在 Cinnamon 5.4 中，來自 csd-xrandr 的顯示配置移動到了 Muffin 窗口管理器中。顯然，你不會在顯示設置窗口中看到什麼不同。不過，在縮放顯示或在高分辨率窗口中時，你可能會發現一些性能的提升，以及錯誤或問題更少一些。

Mint 開發團隊在 Cinnamon 5.4 引入的另外一個關鍵變化是，在應用程序中實現 GTK 窗口的統一渲染。先前，如果一個 GTK 應用程序使用了標題欄，那麼對話框會是一個 CSD （客户端樣式）和 GTK 主題的混合體.

現在隨着 Cinnamon 5.4 的到來，所有的窗口都使用 GTK 主題進行渲染，而不再與它們的設計相關聯。於是，傳統的 Metacity 主題也被拋棄。

順便説一句，我喜歡 Metacity 及其 “傳統外觀”，它們是 GNOME 的早期 產物 。

9、軟件包管理器更新 ​

跟隨 Debian、KDE Plasma 桌面的趨勢，Linux Mint 也開始保護你的系統不會卸載重要的依賴關係軟件包。

當你嘗試卸載軟件包時，Mint 現在會檢查依賴關係，並檢查重要的桌面軟件包是否將會被移除。

如果發現這種情況，你將會得到一條阻止你繼續卸載軟件包的錯誤信息。

在另一方面，當成功地卸載一個軟件包時，它會清理所有與之同時安裝的依賴軟件包。

10、禁用 systemd OOMD 服務 ​

自從 Ubuntu 22.04 LTS 發佈以來，有一些對內存不足守護進程（systemd-oomd）不好的反饋。網上的很多用户都 報告 説：在沒有任何警告或用户干預的情況下，會突然關閉應用程序（例如 Firefox）。進一步的調查表明，systemd-oomd 的實現情況“不是很好”。

理論上説，systemd-oomd.service 會監視你的系統的內存不足的情況，並且它有權殺死任何多過消耗系統資源的進程。Ubuntu 開發團隊並沒有和用户強調這一點，最後導致了不愉快的用户的體驗。

基於這一認識，Linux Mint 21 決定 不提供 這種服務，禁用它。因為 Linux Mint 的用户羣體是普通用户、學生等，如果應用程序意外關閉，對用户來説將是一種不好的體驗。

11、其它變化 ​

最後，讓我們歸納一些微小卻有影響的變化來結束這篇 Linux Mint 21 特色介紹。

  • 默認的文檔閲讀器應用程序 Xreader 現在能夠進行微小注釋。這是一個很方便的功能。

  • WebApp 管理器現在帶來了一些自定義的瀏覽器參數。

  • Warpinator 文件傳輸器實用工具現在可以向你顯示來自 Windows 、Android 和 iOS 設備上的其它的源文件。

  • Mint 將 Firefox 瀏覽器打包為 .deb 版本，而不是 Ubuntu 22.04 LTS 中的默認 .Snap 版本。感謝 Mint 開發團隊，用户不必為卸載 Jammy 中的 Firefox 的 .Snap 版本的而運行 一套複雜的命令。

  • 批量重命名應用程序 Thingy 在用户界面上做了一些改善。

  • GRUB2 的操作系統檢測程序（os-prober）現在能夠檢測出你的硬件系統上所有的操作系統（對雙啓動或多啓動有用）。

  • 藍牙管理器 Blueman 取代了 Blueberry ，為連接和管理你的藍牙設備帶來了其它的功能。

  • 最後，在這個發佈版本中也有為你的新桌面而準備的新壁紙。

沒有變化的部分 ​

從表明上來看，你可能會覺着 Linux Mint 21 的絕大部分功能與先前的版本相同。默認桌面外觀和默認壁紙保持不變。Xfce 和 MATE 桌面也沒有發佈任何重要的功能。因此，它們是完全一樣的。此外，默認圖標主題、應用程序菜單等等都可能會給你一種似曾相識的感覺。

總結 ​

總體來説，最終用户需要的是一套完好的特色功能，而不是花哨的手勢之類的東西。鑑於此，對初學者或最終用户來説，Linux Mint 是當今最好的 Linux 發行版。至此，這篇 Linux Mint 21 特色的總結就此結束了。
