13 個 Linux 桌面的最佳深色 GTK 主題 ​

在任何的 Linux 發行版上，你都有近乎無限的定製選項，在視覺上最明顯的區別就是定製的主題。讓我們來看看一些具有深色模式的 GTK 主題。

是的，我們在過去曾介紹過 最佳 Linux 主題，但這一篇是專門介紹深色主題的。曾幾何時，只有程序員和系統管理員喜歡深色模式，但現在已經不是這樣了。深色模式也受到了普通人的喜愛，因此我為像你這樣的 Linux 桌面用户編制了這個深色主題列表。

如果你不熟悉設置桌面環境的主題，你可以看看我們的 在 GNOME 中安裝主題 指南。

本文僅供參考，這並不是一個排名列表。

1、McMojave ​

McMojave 是一個 GTK 主題，其靈感來自於 macOS 風格的用户界面。顯然這個主題是提供給深色模式的，但它也有淺色模式，嗯……，提供給任何可能想要它的人。

McMojave GTK 主題顯然支持基於 GTK 的桌面環境，如 Pantheon、Gnome、XFCE、Mate 等。但是，這個主題也 適用於 KDE 用户。

為了讓你的桌面環境看起來與 macOS 非常相似，你還可以安裝 McMojave 圓形圖標主題 以獲得更完整的體驗。

2、Yaru ​

Yaru 是 Ubuntu 的默認 GTK（GNOME）主題。該主題的深灰色點綴着橙色，及少許黑色讓我覺得很有吸引力。

現在，你可以讓 Arch Linux 上的 GNOME 看起來像 Ubuntu。( ͡° ͜ʖ ͡°)

3、Pop ​

Pop GTK 主題 是由 System76 為他們基於 Ubuntu 的 Linux 發行版 Pop!_OS 創建的主題。

如果你喜歡 System76 對 GNOME 在深色模式下的表現，你可以在你選擇的 Linux 發行版中試用 Pop GTK 主題。

如果想獲得完整的 Pop-esque 的外觀和感覺，在安裝主題的同時，還可以安裝 System76 提供的 Pop 圖標。

4、Nordic ​

你是一個喜歡簡單的、有點扁平化的設計方法以及一些灰色或更多灰色的人嗎？不妨看看這個基於 北歐風調色板 的主題。

Nordic GTK 主題給你的正是這樣的感覺。一個基於北歐風調色板的 GTK 主題，設計簡單。

5、Ultimate-Maia ​

Ultimate-Maia 是一個基於 Google 的 Material 主題 設計理念的 GTK 主題。這個主題有一個精細而獨特的外觀和感覺，特別是有各種不同的強調色可供選擇。

6、Graphite ​

Graphite 是一個 GTK 主題，它為你的桌面環境（尤其是 GNOME）提供了一個完全獨特的外觀，同時保持了你的桌面環境的獨特性，就像以前一樣。這是一個值得一看的東西。

7、Qogir ​

Qogir 是一個採用了扁平化設計的 GTK 主題。Qogir 主題為你提供的不僅僅是標題按鈕、複選框、單選按鈕、開關等自定義選項。

8、Layan ​

你會很高興知道，這個列表中還包括 Layan，這是一個強調平滑、圓角的 GTK 主題，帶有氣泡的美感。Layan 主題也繼承了 Google 的 Material 設計 指導方針的設計理念。

9、Juno ​

Juno 是我發現的另一個最好的對深色模式友好的 GTK 主題之一。有些人可能喜歡它的漆黑本質，有些人可能不喜歡。但是，如果你有一台 OLED 筆記本或電腦顯示屏，Juno 感覺是為你而生的。

10、Ant 主題 ​

Ant 是一個 GTK 主題，它從 macOS 的佈局和用户界面元素中獲得了一些靈感，在我看來，Ant 主題很好地實現了這一切。

11、Equilux ​

Equilux 主題給你一個漂亮的主題，帶有精細的深色模式。這個主題能很好地與 GNOME 及 GNOME 的復刻融合在一起。我不會太多地描述這個主題，它簡單而優雅。

12、Orchis-dark ​

Orchis Orchis-dark 是超酷的 Orchis 主題的深色變體。它為桌面提供了帶有圓角和流暢界面的 iOS/macOS 觸感。只需看一眼，你就可以立即猜到。

13、Elementary X ​

Elementary X 是基於 elementary OS 團隊為定製 GNOME 外觀而開發的 GTK 主題。順便説一句，elementary OS 是一個基於 Ubuntu 的 Linux 發行版。

總結 ​

這篇文章中列出的主題都是非常漂亮的，而且你的選擇也不限於這裏列出的那些。還有其他成千上萬的主題。

如果你喜歡一個主題，請在下面評論。如果你正在使用一個我沒有提到的主題，也請留下評論。
