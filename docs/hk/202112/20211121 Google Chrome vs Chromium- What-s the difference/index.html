Chrome 與 Chromium 有何不同？ ​

Chrome 瀏覽器是最流行的網頁瀏覽器。無論你是否喜歡使用它，Chrome 都能提供良好的用户體驗。

儘管它可以在 Linux 上使用，但它不是一個開源的網頁瀏覽器。

而且，如果你喜歡 Chrome 的外觀和感覺，但又想使用一個開源的解決方案，Chromium 是一個選擇。

但是，Chrome 瀏覽器不是基於 Chromium 的嗎？（是的。）而且，它也是由谷歌開發的吧？（也是的。）

那麼，Chrome 和 Chromium 之間有什麼區別呢？在這篇文章中，我們將深入瞭解它們，並介紹一些對它們進行比較的基準。

用户界面 ​

Chrome 和 Chromium 的用户界面非常相似，除了一些細微的區別。

例如，我注意到 Chrome 的系統標題欄和邊框一開始就被默認禁用了。相比之下，在我測試的時候，Chromium 默認啓用了它們。

你還可以注意到在 Chrome 的地址欄裏有一個分享按鈕，而在 Chromium 上卻沒有。

這並不是大的視覺差異，而只是根據現有的功能進行了一系列的 UI 調整。所以，你可以預期它們的用户體驗類似，而在底層有所不同。如果你在意用户界面，這兩款瀏覽器應該都很適合你。

開源與專有代碼 ​

Chromium 是完全開源的，這意味着任何人都可以（根據許可證）按照自己的意願使用和修改代碼。你可以在其 GitHub 鏡像 上查看其源代碼。

這就是為什麼你會發現有許多 基於 Chromium 的瀏覽器，如 Brave、Vivaldi 和 Edge。

有這麼多的選擇，你可以選擇你最喜歡的那個。

另一方面，Chrome 在 Chromium 中加入了剛剛專有的代碼，使 Chrome 成為了專有瀏覽器。例如，人們可以復刻 Brave，但不能復刻谷歌 Chrome，而限制使用其中的谷歌特定代碼/工作。

對於終端用户來説，開源與否並不影響用户體驗。然而，對於一個開源項目，你可以得到更多的透明度，而不需要依靠公司來溝通他們打算改變什麼，以及他們在瀏覽器上做什麼。

所以，是的，如果你不喜歡專有代碼，Chromium 就是你的選擇。

功能差異 ​

谷歌不希望其競爭對手擁有類似的能力，這並不奇怪。因此，谷歌一直在 鎖定 Chromium 並在其中禁用了很多谷歌特有的能力。

因此，你會發現這兩個瀏覽器的能力有一些差異。

不僅如此，由於 Chromium 是開源的，你可能會注意到一些不便之處。別擔心，我將在下面指出其中的關鍵差異。

ChromeChromium
有簽到和同步功能無簽到和同步功能
支持媒體編解碼器以使用 Netflix需要手動安裝編解碼器

對於初學者來説，在 Chromium 中不再能使用由谷歌支持的登錄/同步功能。它曾經支持簽到和同步，直到谷歌決定將其從開源項目中刪除。

接下來，Chrome 內置了對高質量媒體編解碼器的支持。因此，你可以加載來自 Netflix 的內容。但是，在 Chromium 中沒有這些。

從技術上講，Chromium 並不包括 Widevine 內容解密模組。因此，你需要手動安裝所需的編解碼器，以使大部分東西都能工作。

不過，你在這兩個瀏覽器上你都可以播放蘋果音樂等平台的內容，應該不會有任何問題。

安裝及最新更新 ​

你可以在幾乎任何平台上安裝 Chrome。Linux 也不例外。只需前往其官方網站，抓取 DEB/RPM 包即可快速安裝。安裝後的應用程序也會自動更新。

有幾個平台上安裝 Chromium 並不那麼簡單。曾經有一段時間，一些 Linux 發行版將 Chromium 作為默認瀏覽器。那是過去的日子了。

即使在 Windows 上，Chromium 的安裝和更新也不像 Chrome 那樣順利。

在 Linux 上，安裝 Chromium 則完全是另一回事。像 Ubuntu 這樣的流行發行版把它打包成一個沙盒式的 Snap 應用程序。

即使你試圖用終端安裝它，希望能從 APT 庫中得到它，但它又是一個 Snap。

使用 Snap 軟件包，你可能會面臨與你的自定義桌面主題相融合的問題。Snap 應用程序的啓動時間也會更長。

而且，如果你構建它並手動安裝 Chromium，你就得手動更新它。

隱私角度 ​

Chrome 對大多數用户來説應該足夠好了。但是，如果你擔心你的隱私，Chrome 會追蹤使用信息和一些與瀏覽有關的信息。

最近，谷歌推出了一個新的 Chrome API，可以讓網站檢測到你什麼時候閒着，什麼時候不閒着。雖然這是一個巨大的隱私問題，但並不是唯一的問題。

谷歌不斷試驗新的追蹤用户的方法；例如，正如 EFF 所指出的那樣，谷歌的 FLoC 實驗並不受歡迎。

從技術上講，他們聲稱他們想增強用户的隱私，而同時仍然提供廣告機會。然而，就目前而言，這是一個不可能實現的任務。

相比之下，Chromium 在隱私方面的表現應該要好得多。然而，如果你討厭你的瀏覽器中有任何與谷歌有關的東西，即使是最輕微的遙測，你應該試試 UnGoogled Chromium。

它是 Chromium，但沒有任何谷歌組件。

瀏覽器性能 ​

有各種各樣的瀏覽器基準，可以讓你瞭解到一個瀏覽器處理任務的能力如何。

考慮到網站上的高級網站應用和資源密集型的 JavaScript，如果一個網頁瀏覽器的性能不好，當你打開許多活動的標籤時，你的體驗就會明顯很糟糕。

JetStream 2 和 Speedometer 2 是兩個流行的基準，可以給你處理各種任務和響應能力的性能估計。

除此之外，我還試用了 Basemark Web 3.0，它也是測試各種指標並給你一個綜合分數。

總體而言，Chrome 在此獲勝。

但是，值得注意的是，在運行瀏覽器時，你的系統資源和後台進程會對性能產生不同的影響。因此，也要考慮到這一點。

你應該選擇哪個？ ​

之所以存在對瀏覽器的選擇，是因為用户喜歡不同的東西。Chrome 提供了一個良好的功能集和用户體驗。如果你以某種形式使用由谷歌提供的服務，Chrome 是一個簡單的推薦。

然而，如果你擔心隱私和專有代碼，Chromium 或 UnGoogled Chromium，或任何其他基於 Chromium 的瀏覽器，如 Brave，可以是一個不錯的選擇。

這就是我在比較 Chrome 和 Chromium 時的全部看法。我願意接受你的意見。評論區都是你的。
