Vivaldi 5.0 發佈！ ​

對於那些喜歡在桌面和安卓系統上進行定製和增加功能的用户來説，Vivaldi 5.0 是一個令人興奮的版本。

Vivaldi 是一個基於 Chromium 的網頁瀏覽器，可用於 Linux（及其他平台）。它因其增強功能和多任務特性而廣為人知。這使它成為 Linux 上最好的網頁瀏覽器 之一，特別是對於高級用户來説。

隨着 Vivaldi 5.0 的發佈（以紀念其 5 週年），它推出了一系列重大功能增加和改進。

讓我們來看看 Vivaldi 的新版本有什麼特點。

Vivaldi 5.0 的新功能 ​

請注意，Vivaldi 除了其用户界面之外大部分是 開源 的。然而，他們傾向於把重點放在 Linux 平台的改進上肯定是件好事。

以下是你可以在 Vivaldi 5.0 發現的變化：

Vivaldi 主題 ​

主題一直是 Vivaldi 最好的功能之一，不僅僅是因為它有各種預裝的主題，而是你可以定製你的主題或編輯預裝的主題。

它的主題編輯器已經更新，有更多可以定製的選項。你現在可以編輯顏色、邊角、背景和設置來定製主題。以前，你必須單獨編輯背景圖片，而現在新的主題編輯器應該很方便使用。

而且，並不止於此，你已經創建好了你的主題？

現在，你可以使用新的“導出主題Export Theme”選項輕鬆地生成一個 ZIP 文件，與任何人分享你的主題。同樣地，你也可以導入一個主題。

更進一步地，你可以把你新設計的主題提交到他們的 社區畫廊。你也可以從那裏找到其他用户的主題，並安裝它們。

新的翻譯面板 ​

在 Vivaldi 4.0 發佈時，他們引入了由 Lingvanex 提供的內置翻譯功能。

現在，通過側邊欄中新的“翻譯面板Translate Panel”，你可以快速添加一個文本片段並進行翻譯，而無需翻譯整個網頁。

Vivaldi 的側面板以提高多任務處理能力而聞名，而這個功能的增加應該會加強這一點。

如果你想翻譯更多的片段呢？當然，你肯定不想一直繼續複製粘貼它們！

對於這個特殊的需求，Vivaldi 還引入了一個“一步自動翻譯one-step auto-translate”選項。一旦啓用該選項，突出顯示你在網頁中想要的文本，它的翻譯將立即出現在側面板上。這聽起來很酷！

在彈出式窗口中查看下載 ​

雖然 Vivaldi 在很多方面都令人印象深刻，但對於用户來説，其關注下載進度的能力並不那麼直觀。你必須到側面板（或“下載”）中去檢查下載的進度。

相比之下，在其他網頁瀏覽器中，你可以在你的擴展程序旁邊找到一個按鈕。

在 Vivaldi 5.0 中，你終於可以使用地址欄中的一個按鈕來檢查下載進度，點擊該按鈕將打開一個彈出窗口來顯示你的下載進度。

為安卓用户提供的增強功能 ​

Vivaldi 的安卓版也有了重大更新和期待已久的功能。

安卓用户現在可以使用桌面用户已經在使用的 “兩級標籤堆棧Two-level Tab Stacks”。

也許，這對任何安卓手機瀏覽器來説都是第一次！

對於那些不知道的人來説，這個功能有助於將標籤頁組合在一起，產生兩級。這有助於避免多個標籤擠在一起。

可配置的“標籤欄Tab Bar”現在多了兩個選項。例如，背景標籤上用於關閉的“X”按鈕可以被移除（為更多的標籤騰出空間）。用户還可以將標籤簡單地顯示為收藏夾，因此沒有標題，也沒有“X”按鈕。

因此，你有很多管理你的安卓移動設備上的標籤的方法。

雖然這很有趣，但我不太確定對用户來説，在小屏幕上摻雜兩級標籤堆棧的感覺如何。

平板電腦和 Chromebook 用户也將享受到用户界面更新的待遇。平板電腦和 Chromebook 用户現在可以使用經典的“側面板Side Panel”，以組織瀏覽器的佈局，儘量減少雜亂。

這一功能的增加可以使 Vivaldi 成為平板電腦用户的有力選擇。

其他改進 ​

除了關鍵的亮點之外，你可以發現速度的改進和錯誤的修復。

要探索更多，你可以查看其 桌面版 和 安卓版 的官方Blog文章。

總結 ​

Vivaldi 無疑是一個會關注其用户需求和網頁體驗的瀏覽器。對於喜歡更多定製和功能的用户來説，最新的版本聽起來很令人感興趣。

你可以從官方網站下載可用的 DEB/RPM 包並進行安裝。
