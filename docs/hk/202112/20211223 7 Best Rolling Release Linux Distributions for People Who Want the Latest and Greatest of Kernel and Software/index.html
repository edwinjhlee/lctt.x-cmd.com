7 個最好的 Linux 滾動發行版 ​

林林總總的 Linux 發行版可以根據它們的特點、功能、預期用户羣等分為不同的類別。在這篇文章中，我將列出一些最好的滾動發佈的 Linux 發行版。

你知道什麼是 滾動發佈的發行版 嗎？這些發行版不會等待 6 個月或更長時間才發佈一個新的版本，提供給你更新的 Linux 內核、桌面環境和其他主要軟件組件。它們會在這些組件發佈後很快就進行更新。你不必將你的發行版從一個主要版本升級到下一個版本，因為你的發行版會定期得到升級。

現在你已經知道了，讓我們來看看一些最好的滾動發佈的 Linux 發行版。

你可以在桌面上使用的最佳滾動發行版 ​

是的，這個列表主要是針對桌面用户。這裏列出的一些發行版可能有服務器版本，但這不是這裏的重點。

請注意，這並不是一個排名表。

1、openSUSE Tumbleweed ​

老派的 openSUSE 多年來一直按部就班地順着版本號發佈他們的系統。但在幾年前，他們決定改變他們的產品，創建了 openSUSE Leap 和 Tumbleweed。

openSUSE Leap 採用的是版本式發佈，每隔幾年就會有一個新的版本，而 Tumbleweed 則是滾動式發佈，新的軟件在發佈後不久就會出現在這個系統中。

openSUSE Tumbleweed 對於那些想留在紅帽 RPM 陣營的人來説是一個很好的選擇。openSUSE 有多樣化的生態系統，它有一個巨大的軟件庫，Zypper 和 YaST 為你的軟件包管理提供了很多選擇。

2、Arch Linux ​

毋庸置疑，Arch Linux 是最流行的滾動發佈版本。它幾乎就是滾動發佈的同義詞。

Arch Linux 在 Linux 用户中具有崇高地位的原因有很多。我認為這更多是與 安裝 Arch Linux 後的成就感有關，因為即使是安裝程序，它都很別人不一樣。

Arch 在其軟件庫中正式提供了一大批軟件。而 AUR 則通過社區的努力，幾乎使所有其他的 Linux 軟件都可以使用。

如果你對 Linux 有一定的經驗，想挑戰自己的水平，這是一個不錯的選擇。

3、Manjaro Linux ​

Manjaro 基本上是免除了所有麻煩的 Arch Linux。

它是基於 Arch Linux 的，所以它具有 Arch Linux 的大部分優點。你可以得到 Pacman 和 AUR 的滾動發佈模式。同時，Manjaro 有圖形化的安裝程序、基於 GUI 的軟件包管理器和其他圖形化工具來改善你的桌面體驗。

Manjaro 更容易安裝，也更容易使用。對於那些想舒適地呆在 Arch 領域的人來説是個不錯的選擇。

注意: 還有 許多其他基於 Arch Linux 的優秀髮行版，但我無法將其列入此列表中。如果你願意，你可以試試 Garuda Linux、EndeavourOS 和其他許多基於 Arch 的發行版。

4、Solus Linux ​

和 Manjaro 一樣，Solus 也是一個 “謹慎” 的滾動發行版。與 Manjaro 不同的是，它不是基於 Arch 的。它是從頭開始創建的，使用的是 eopkg 軟件包管理器。Solus 因創造了現代而直觀的 Budgie 桌面環境備受讚譽。

像其他滾動發佈的發行版一樣，一旦你安裝了 Solus，你就不需要升級到下一個版本的發行版（也可以像 ISO 刷新一樣進行全新安裝，帶有更新的軟件包）。

萬一有欠缺的軟件包也可以用 Snap 應用程序來補足。

如果你想要一些不同的東西，但又不至於複雜到讓你感到不舒服，那麼 Solus 是一個不錯的選擇。

5、Debian Testing ​

你沒有想到吧？Debian 以其對穩定性的關注而聞名，以至於其穩定的有時就像是陳舊，因為它提供的軟件版本已經相當老舊。

但那是針對穩定分支的。Debian 有幾個分支，其中一個叫做 Testing 分支。

看起來 Testing 是某種測試版、不穩定的版本，但這並不完全正確。Debian Testing 其實是下一個 Debian 穩定版本。實際的開發分支是 Debian Unstable（即 Sid）。Debian Testing 介於不穩定版和穩定版分支之間，它會在穩定版之前添加新的功能。

有些人在配置 Debian 時，在源列表中加入 testing。這使得他們的 Debian 系統永遠停留在測試階段。這是一種滾動發佈的模式，Debian 用户可以不必離開舒適的 APT 和 deb 軟件包管理系統。

6、Void Linux ​

這是一個不尋常的、不太出名的發行版。Void 也是從頭開始創建的，也就是説，它不是基於 Arch、Red Hat 或 Debian。

它是滾動發佈的，但不像 Arch 那樣激進。它優先考慮的是穩定性。這意味着當新的版本發佈時，你不需要升級版本，但你也不會在最新的桌面環境版本一發布就得到它。

與其他發行版不同的另一點是，它使用 runit 作為初始化系統。

總的來説，如果你是一個有經驗的 Linux 用户，Void 是一個不錯的選擇。

7、Gentoo Linux ​

另一個是你的同行們警告過的 專家級 Linux 發行版 之一。

Gentoo 不是每個人都能享用的茶或咖啡（無論你喜歡哪一種）。從安裝到配置再到軟件包管理都需要一定的專業知識和時間。

但是它有一個小眾的專家用户羣，他們會在編譯一切需要的組件時廢寢忘食。

如果你覺得其他發行版都不夠有挑戰性，Gentoo 可能是你的選擇。

你對滾動發佈的發行版有什麼建議？ ​

正如我之前提到的，我在這裏特意將其他基於 Arch 的發行版排除在外，否則列表中就只有 Arch 的衍生產品了。

但你可以自由地投出你的推薦，即使它是基於 Arch 的。評論區都是你的。
