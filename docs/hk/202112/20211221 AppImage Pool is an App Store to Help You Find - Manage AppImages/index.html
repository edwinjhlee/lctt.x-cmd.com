AppImage Pool：一個幫助你尋找和管理 AppImage 的應用商店 ​

這是一個管理和尋找 AppImage 應用的有趣的 GUI 前端。讓我們來了解一下它！

我們有很多關於 AppImage 的歷史和製作它 的信息。如果你是 Linux 的新手，你也應該看看我們的 AppImage 使用指南。

AppImage 使應用可以很容易地在不同的發行版上運行，而不需要安裝依賴關係或任何東西。

然而，與 Flatpak 的 Flathub 不同，你可能找不到一個瀏覽 AppImage 應用的門户。

Nitrux OS 中的 NX 軟件中心做了類似的工作，但它不能輕易安裝在其他發行版上。因此，AppImage Pool 作為 AppImage 應用的應用商店上場了，你可以安裝在任何 Linux 發行版上。

AppImage Pool：一個管理和尋找 AppImage 應用的 GUI 前端 ​

AppImage Pool 是一個使用 Flutter 構建的 GUI 前端，它從 AppImageHub 獲取應用數據，並讓你快速搜索、下載和管理 AppImage 應用。

它並不託管任何 AppImage 文件，但它可以讓你從項目的 GitHub 頁面下載可用的 AppImage 文件。

當你試圖下載一個 AppImage 文件時，它會從應用的 GitHub 發佈頁列出所有下載方式。

我不確定它是否僅限於來自 GitHub 的項目，但你可以在 AppImageHub 門户 中找到各種不同方式。

AppImage Pool 的特點 ​

AppImage 是一個簡單直白的應用商店，可以讓你搜索、下載和管理 AppImage 文件。

其中一些功能包括：

  • 能夠下載特定版本的 AppImage 文件
  • 按類別過濾應用
  • 下載進度圖標
  • 管理所有已安裝的 AppImages
  • 查看下載歷史

考慮到該應用是使用 Flutter 構建的，它給人帶來了快捷的用户體驗。

如果你是一個開發者，這鼓勵了你使用它製作一個應用的話，你也可以 在 Linux 中安裝 Flutter。

在 Linux 中安裝 AppImage Pool ​

由於明顯的原因，開發者提供了一個可供下載的 AppImage 文件。

你也可以選擇從 Flathub 中 安裝它的 Flatpak 包。如果你想測試它即將發佈的任何版本，也有一個每夜構建的 AppImage 版本。

在其 GitHub 頁面 上可以瞭解關於它的更多信息。

  • AppImage Pool 下載

使用 AppImage Pool 的感受 ​

該應用可以如預期的工作。然而，我注意到，列出的一些應用沒有下載鏈接或任何相關信息。

畢竟，這些數據是來自於 AppImageHub 的。

另外，你可能會覺得奇怪，有些應用只列出了預發佈的 AppImage 文件，比如 Blender。

雖然這也是可以選擇項目發佈分支的一個優勢，但我認為我不會下載預發佈包。

總的來説，找到一個能讓人輕鬆下載和管理 AppImages 的東西是件好事。

我建議你試一試，並在下面的評論區告訴我你的想法。
