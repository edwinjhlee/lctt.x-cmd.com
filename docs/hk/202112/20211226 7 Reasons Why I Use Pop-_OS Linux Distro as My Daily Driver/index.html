我把 Pop!_OS Linux 作為主要系統的 7 個原因 ​

Pop!_OS 是向 Linux 初學者和遊戲玩家的熱門推薦。但是，Pop!_OS 從其他基於 Ubuntu 的發行版中脱穎而出的原因有哪些？為什麼你應該考慮把它作為你電腦日常使用的系統？

三年前，我從 Ubuntu 轉到了 Pop!_OS，從那時起它就成了我的日常系統。

讓我為你指出選擇它作為你的日常操作系統的好處。

選擇 Pop!_OS 而不是其他 Linux 發行版的原因 ​

請注意，這裏列出的一些原因可能是主觀的，完全取決於你想要什麼，以及你期望的桌面體驗。

考慮到這一點，讓我強調一下為什麼我選擇 Pop!_OS 作為我的主要操作系統，而不是其他 Linux 發行版。

1、單獨的 NVIDIA/AMD ISO ​

如果你有一個裝有 Nvidia GPU 的機器，使用 Nouveau（Nvidia 顯卡的開源驅動程序）來使其工作是不可行的。

好吧，你的顯示器可以工作，但你不能發揮你的顯卡的優勢。

例如，你會在幾乎所有需要利用 GPU 的任務中遇到卡頓和性能問題。

因此，專有的 Nvidia 驅動程序是解決這些問題的唯一解決方案。

而且，為了讓添加專有驅動程序能夠開箱即用，發行版需要將其包含在 ISO 中，或者提供一個單獨的 ISO，其中包含 Nvidia 最新可用的專有驅動程序。

雖然你肯定可以手動安裝專有驅動程序，但這並不是完美的體驗。

順便説一句，對於大多數流行的 Linux 發行版，這個過程應該與 在 Linux Mint 中安裝 Nvidia 驅動程序 類似。

請注意，有時你需要排除故障或重新安裝正確的（或較早的驅動版本）才能正確使用 Nvidia 顯卡。

但是，如果你有單獨的 ISO 來支持 Nvidia 的系統或 Nvidia 圖形安裝模式（如 Zorin OS），那就可以消除手動安裝 Nvidia 驅動程序的麻煩。

這不僅僅是為了方便使用，而是 Pop!_OS 通過提供幫助性的 Nvidia ISO 做到了開箱即用。

當我試圖手動安裝專有驅動程序時，我曾在 Linux Mint、Ubuntu 和其他一些發行版上遇到過問題。因此，Pop!_OS 對於我帶有 Nvidia 顯卡的系統來説，設置起來非常容易。

2、自動平鋪管理器 ​

如果沒有平鋪管理器，你需要不斷地拖放（和移動）你的活動窗口來組織它們以便快速訪問。

因此，一個窗口平鋪管理器可以方便地自動組織你啓動的應用程序的活動窗口。

當然，使用平鋪管理器的體驗會因你的屏幕尺寸而不同，但即使你有一個尺寸不大的 27 英寸顯示屏，它也應該會有明顯的體驗改善。

我自己一直在使用它，即使沒有大顯示器（或雙顯示器設置）。

我從來沒有在筆記本電腦上使用過它，但整天工作時，擁有一個自動窗口平鋪管理器（你可以啓用/禁用）聽起來是一個有用的功能。

它有助於提高你的多任務處理能力，而不一定要移動到不同的工作空間。

3、使用的便利性 ​

為什麼你認為 Ubuntu 是 最好的 Linux 發行版 之一？

多年來，它一直設法提供易於使用的現代桌面體驗。

令人印象深刻的是，System76 已經設法將 Pop!_OS 的用户體驗在 Ubuntu 的基礎上提升了一個檔次。

因此，Pop!_OS 不僅僅是另一個 Ubuntu 發行版，它的應用啓動器、應用庫、塢站、工作區定製以及其他各種優化都帶來了獨特的桌面體驗。

對於我的使用情況而言，它感覺比 Ubuntu 更好。別忘了，它還包括一些工具，比如 Popsicle，這些工具在以後的工作中會很方便。

4、較新的 Linux 內核 ​

Ubuntu 可能不具有最新和最棒的 Linux 內核，特別是它的 LTS 版本時。

然而，Pop!_OS 盡力提供最新的 Linux 內核版本，即使是在 LTS 版本中。例如，Ubuntu 20.04.3 LTS 包含了 Linux 內核 5.11，但 Pop!_OS 20.04 LTS 具有 Linux 內核 5.13。

對於大多數用户來説，這可能不是什麼大問題，但是 Pop!_OS 比其他大多數 Linux 發行版更快地推送了更新的 Linux 內核。

如果你想讓你的最新和最棒的硬件與 Linux 發行版很好地配合工作，Pop!_OS 是一個絕妙的選擇。

5、應用程序啓動器 ​

應用程序啓動器在快速啓動應用程序或在活動窗口之間進行導航時非常方便。

使用快捷方式（也可能是鏈接到它的宏，就像我使用的那樣）調用啓動器的能力，使它成為啓動應用程序和在它們之間進行導航的最快捷的方式之一。

當然，你可以安裝像 Ulauncher 這樣的工具來實現同樣的目的。不過，它是預先配置、開箱即用的，不需要任何故障排除，這很方便。

6、快速升級過程 ​

儘管升級 Linux 發行版通常是無憂無慮的，但 Pop!_OS 在每次更新時都盡力完善和改進這個過程。

例如，在 Pop!_OS 21.10 中，他們引入了一些改進措施，以防止升級過程中的衝突，並使其成為一個順暢的過程。

事實上，我從 Pop!_OS 21.04 升級到 21.10 只需點擊幾下，沒有遇到任何問題。

7、努力改善現代桌面體驗 ​

Pop!_OS 可能不是一個 輕量級 Linux 發行版，但它專注於為現代桌面用户提供一流的體驗。

雖然有很多適合老式電腦的 Linux 發行版，但以新一代硬件為目標同樣重要。

System76 也在他們的最新筆記本硬件配置上測試過該發行版，Pop!_OS 在這方面表現得非常好。

此外，Pop!_OS 還提供了開箱即用的調整功能，使用户在操作系統方面的體驗變得簡單。雖然 Linux 就是不斷調整和控制你的系統，但 Pop!_OS 似乎成功地使它成為一個主流選擇和一個可行的 Ubuntu 替代品，這可能對一些人來説更好。

補充：軟件包更新 ​

System76 最近在 Pop!_OS 21.10 版本 中從 Launchpad 轉向了自己的軟件庫。

這應該能讓他們更快地推送更新，並控制軟件包以確保用户的最佳體驗。

這也應該使 Pop!_Shop 更加有用。因此，這是又一個在我的機器上繼續使用 Pop!_OS 的理由。

總結 ​

Pop!_OS 在很多地方做的很好。

如果你對選擇一個易於使用、與最新硬件兼容、適合各種使用情況的 Linux 發行版感到困惑，我會推薦 Pop!_OS。

上述原因是我堅持使用它的原因，即使在我曾經嘗試切換到 Zorin OS 和 Linux Mint 幾個月。
