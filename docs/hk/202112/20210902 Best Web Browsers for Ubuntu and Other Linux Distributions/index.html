適用於 Linux 的最佳網頁瀏覽器 ​

沒有所謂的完美的網頁瀏覽器。這完全取決於你喜歡什麼以及你用它來做什麼。

但對於 Linux 上的網頁瀏覽器，你有哪些最佳選擇呢？

在這篇文章中，我試圖給出你在 Ubuntu 和其他 Linux 系統上使用的最佳網頁瀏覽器。

注： 我們已經在 Ubuntu 上嘗試和測試了這些瀏覽器。但是，你應該能夠在你選擇的任何 Linux 發行版上安裝它。

Linux 上的頂級網頁瀏覽器 ​

每個瀏覽器都有其獨特之處。而且，對於 Linux 平台，也有一些有趣的獨家選擇。

在你看到這個列表之前，請注意這不是一個排名列表。列在第 1 位的瀏覽器不應該被認為比第 2 位、第 3 位或第 10 位的更好。

非自由開源軟件警報！

這裏提到的一些應用程序不是開源的。它們被列在這裏是因為它們在 Linux 上可用，而文章的重點是 Linux。我們也有一個單獨的 開源的網頁瀏覽器的專門列表。

1、Vivaldi ​

優點

  • 可快速訪問網頁應用程序的側邊欄
  • 集成了日曆和電子郵件
  • 獨特的標籤管理
  • Pomodoro 功能（時鐘計時器）
  • 有移動應用程序

缺點

  • 當使用各種功能時，資源佔用很重
  • 不是 100% 開源的

Vivaldi 是一個令人印象深刻的瀏覽器，它越來越多地得到了 Linux 用户的關注。

雖然它不是 100% 開源的，但你可以在網上找到它的大部分源代碼（除了它的用户界面）。

隨着 Vivaldi 4.0 的發佈，他們更加註重改善 Linux 用户的體驗。你可以設置時鐘計時器以提高你的工作效率，使用內置翻譯來翻譯網頁，跟蹤你的日曆活動，為網頁應用程序添加快捷方式，並通過這個瀏覽器為多種任務發揮到極致。

即使它是一個快速的網頁瀏覽器，我也不會覺得它是“最快”或最輕量級的。你需要大量的內存，才能在你工作時發揮它的所有的功能。

總之，它是一個功能豐富的網頁瀏覽器。因此，如果你需要有儘可能多的功能來完成多種任務，Vivaldi 可以是你的選擇。

如何在 Linux 上安裝 Vivaldi？ ​

Vivaldi 提供了 .deb 和 .rpm 兩種軟件包，讓你可以直接在 Linux 系統中安裝它。

如果你是 Linux 的新手，你可以參考我們的資源來 安裝 Deb 文件 和 安裝 RPM 文件。

2、Mozilla Firefox ​

優點

  • 隱私保護
  • 不基於 Chrome 引擎
  • 開源
  • Firefox 帳户服務

缺點

  • 用户體驗會隨着重大更新而改變

Firefox 是大多數 Linux 發行版的默認網頁瀏覽器。因此，它顯然是一個開箱即用的瀏覽器。

除了是開源的，它還提供一些最好的隱私保護功能。而且，通過正確的設置，你可以把它變成類似於 Tor 瀏覽器（它也是基於 Firefox 的）這樣的最安全的瀏覽器之一。

不僅僅是它的安全性，當你用你的 Firefox 賬户登錄時，它還集成了有用的功能，如 Pocket（保存網頁並稍後閲讀）、VPN、電子郵件別名、漏洞監控等。

如何在 Linux 上安裝 Firefox？ ​

它應該已經預裝在你的 Linux 發行版中了。但是，如果它不存在，你可以在軟件中心搜索它，或者用終端的以下命令來安裝它：

sudo apt install firefox

3、Chromium ​

優點

  • Chrome 瀏覽器的開源替代品
  • 與 Chrome 瀏覽器的功能相似

缺點

  • 缺少 Chrome 瀏覽器提供的某些功能

Chromium 是 Chrome 瀏覽器的開源替代品，也是許多其他基於 Chrome 的瀏覽器的基礎。

如果你不想使用 Chrome 瀏覽器，Chromium 是你在 Linux 上獲得相同體驗的最佳選擇。

儘管谷歌控制着 Chromium，並且 一直鎖定着 Chrome，但對於 Linux 系統來説，它是一個不錯的選擇。

如何在 Linux 上安裝 Chromium？ ​

你應該可以在軟件中心輕鬆找到它。但是，如果你需要幫助，可以參考我們的 Chromium 安裝指南。

4、谷歌 Chrome ​

優點

  • 與谷歌服務的無縫整合

缺點

  • 不是開源的

Chrome 瀏覽器 是一個優秀的網頁瀏覽器，除非你不想選擇谷歌的專有解決方案或產品。

你可以得到所有的基本功能，並且能夠整合所有的谷歌服務。如果你喜歡在安卓系統上使用 Chrome 瀏覽器，並希望在多個平台上進行同步，那麼它是桌面 Linux 的明顯選擇。

如果你在使用谷歌服務的同時尋找一個簡單而強力的網頁瀏覽器，Chrome 瀏覽器可以是一個不錯的選擇。

如何在 Linux 上安裝 Chrome 瀏覽器？ ​

Chrome 瀏覽器提供 Deb 和 RPM 包，可以讓你在任何基於 Ubuntu 或 Fedora/openSUSE 發行版上安裝。

如果你在安裝方面需要幫助，我應該向你指出我們關於 在 Linux 上安裝 Chrome 瀏覽器 的指南。

5、Brave ​

優點

  • 隱私保護功能
  • 性能

缺點

  • 沒有基於賬户的同步

Brave 瀏覽器是最受歡迎的 Linux 瀏覽器之一。

它是一個開源項目，基於 Chromium。它提供幾個有用的隱私保護功能，並以其極快的性能而聞名。

與其他瀏覽器不同的是，即使你屏蔽了網站上的廣告，你也可以獲得獎勵。你收集的獎勵只能用於回饋你喜歡的網站。這樣一來，你在屏蔽廣告的同時也得到了對網站的支持。

你可以期待以最小的資源佔用獲得更快的用户體驗。

如果你需要在兩者之間做出決定，我們也有一篇詳細的 關於 Brave 和 Firefox 的比較文章。

如何在 Linux 上安裝 Brave？ ​

與其他一些網頁瀏覽器不同，你不能直接在軟件中心找到軟件包。你需要在終端輸入一些命令來安裝該瀏覽器。

不用擔心，你可以按照我們的 安裝 Brave 瀏覽器的説明 來進行。

6、Opera ​

優點

  • 內置免費的 VPN
  • 額外的功能

缺點

  • 不是開源的

雖然 Opera 不是最流行的選擇，但它對 Linux 用户來説絕對是一個有用的瀏覽器。

它有一個內置的 VPN 和廣告攔截器。因此，在 Opera 瀏覽器的幫助下，你應該會得到基本的隱私保護。

你可以直接從側邊欄快速訪問流行的聊天信使，而不需要啓動單獨的應用程序或窗口。這種側邊欄的聊天信使網頁應用與 Vivaldi 類似，但用户體驗明顯不同。

總的來説，如果你想要一個免費的 VPN 作為其他基本瀏覽功能之外的獎勵，它是一個不錯的選擇。

值得注意的是，Opera 提供了一個獨特的 Opera GX 瀏覽器，讓你在使用瀏覽器並同時進行遊戲活動時可以調整或強制限制系統資源。在寫這篇文章的時候，該功能還在開發 Linux 版本，如果在你讀到這篇文章的時候，它已經可以使用了，這可能是一個很好的選擇。

如何安裝 Opera？ ​

Opera 為 Linux 提供了 Deb 包。你只需前往其官方網站下載並安裝即可。

7、微軟 Edge ​

優點

  • 為同時也使用 Linux 的 Windows 用户提供了方便的選擇。

缺點

  • 不是開源的

微軟 Edge 在受歡迎程度上已經超過了 Mozilla Firefox。不僅僅是因為它是默認的 Windows 瀏覽器，而是它在基於 Chrome 瀏覽器的同時，還提供了很有前景的網頁體驗。

微軟 Edge 已經發布了面向 Linux 的穩定版。它目前運行良好，但缺乏一些的通常可用於 Windows 的功能。

總的來説，你應該會發現大部分的基本功能都是可用的。

如果你使用 Windows 和 Linux 作為你的桌面平台，微軟 Edge 可以考慮作為首選的網頁瀏覽器。

如何在 Linux 上安裝微軟 Edge？ ​

現在，你可以通過微軟 Edge 的官方網頁獲得 Deb/RPM 文件並安裝它。

你也可以看看我們關於 在 Linux 上安裝微軟 Edge 的方法。

Linux 獨有的網頁瀏覽器 ​

考慮到安全更新和未來升級，大多數用户喜歡堅持使用主流選項，但也有一些不同的選項。而且，有些是 Linux 用户專屬的。

8、GNOME Web（Epiphany） ​

優點

  • 精簡
  • 開源

缺點

  • 缺少許多功能
  • 沒有跨平台支持

Epiphany 瀏覽器 是 GNOME 的默認瀏覽器。elementary OS 也將其作為默認的網頁瀏覽器。

它是一個精簡的瀏覽器，提供了一個乾淨和優雅的用户體驗。你不能同步你的書籤或歷史記錄，所以如果你想備份或轉移到其他瀏覽器，你需要手動導出它們。

如何安裝 GNOME Web？ ​

你可能會發現它預裝在一些 Linux 發行版中。如果沒有，你可以用它的 Flatpak 包 來在任何 Linux 發行版上安裝最新版本。

9、Falkon ​

優點

  • 基於 Firefox 的替代品

缺點

  • 不能替代 Firefox
  • 沒有跨平台支持

Falkon 是一個基於 Firefox 的瀏覽器，考慮到了隱私問題。它對於基本的網頁瀏覽應該是足夠好的，但它可能不是你日常使用的解決方案。

你可以在我們專門的 關於 Falkon 瀏覽器的文章 中瞭解更多關於它的信息並獲得安裝説明。

10、Nyxt ​

優點

  • 高度的可定製性
  • 重點關注鍵盤操作

缺點

  • 適用於某些用户
  • 缺乏跨平台支持

Nyxt 是一個有趣的網頁瀏覽器，為資深的鍵盤用户而建立。你可以使用鍵盤快捷鍵來瀏覽和導航網頁。

要了解更多關於它的信息和安裝説明，請瀏覽我們關於 Nyxt 瀏覽器 的詳細文章。
