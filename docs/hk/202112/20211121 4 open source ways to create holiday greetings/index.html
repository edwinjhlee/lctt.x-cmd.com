創建節日問候的 4 種開源方式 ​

開源工具和資源為任何節日提供了創造性的可能性。

節日再次來臨，今年我決定用 開源方式 來慶祝。就像一個特別有名的假期忙人一樣，我有一個長長的節日任務清單（我打算再三檢查）：製作一張賀卡（帶地址的明信片）寄給家人和朋友，用合適的節日歌曲製作照片蒙太奇或視頻，並裝飾我的虛擬辦公室。有很多開源的應用和資源使我的工作更容易。以下是我使用的東西。

Inkscape 和剪貼畫 ​

我最喜歡的資源之一是 FreeSVG.org（前身是 Openclipart.org）。這裏很容易找到你喜歡的節日，包括光明節、聖誕節、新年等等。這些剪貼畫都是由像你我這樣的用户貢獻的，並且是 CC0 版權，所以你甚至不需要提供署名。當然，在可能的情況下，我還是會註明出處，以確保 FreeSVG 和它的藝術家們獲得知名度。

下面是 FreeSVG 的一些剪貼畫的例子：

openclipart.com， CC0 1.0

使用 Inkscape 的文本路徑工具，我在圖片上添加了我自己的文字，我把它用在卡片上。如果再做些工作，我還可以把這個圖形用在一些定製的杯子或餐墊上。

Don Watkins， CC BY-SA 4.0

文字處理 ​

LibreOffice Writer 可以用來製作賀卡和海報，然後在你的家中使用或分發給你的朋友和家人。使用 LibreOffice Calc 創建一個關於你的家人和朋友的資料庫，然後利用這一資源，用郵件合併功能簡化製作郵件標籤的過程。

創作共用的圖片和圖形 ​

search.creativecommons.org 上也有藝術品。注意許可證類型：對任何需要署名的東西給予適當的致謝。這張圖片（“Thanksgiving Dealies”）來自創作共用圖片搜索。它的作者是 Martin Cathrae，並在 CC BY-SA 2.0 下授權，因此它可以在相同的許可證下被改編、重複使用和分享。

Martin Cathrae， CC BY-SA 2.0

我拿着這張相同的圖片，用 GIMP 在上面添加了一些我自己的文字。你可以用 Inkscape 來做同樣的事情。

Don Watkins，CC BY-SA 4.0

創作共用Creative Commons提供了大量的圖片，在你的下一次 視頻會議 期間，可以這些圖片作為一個節日背景。

視頻和實時流媒體 ​

你也可以把這些圖片與你自己的一些圖片結合起來，用 OpenShot 視頻編輯器創建一個簡短的視頻剪輯。你可以通過使用 Audacity 錄製一個單獨的音軌，輕鬆添加旁白。可以在 Audacity 中添加聲音效果，保存到文件中，並導入到 OpenShot 視頻編輯器的配樂中。尋找 合法的背景音樂 來添加到你的視頻中。

使用 開源廣播軟件（OBS） 來直播你的假期聚會。使用 OBS 可以輕鬆地為你的朋友和家人呈現引人入勝的假期節目，或者你可以將節目另存為 Matroska 或 MP4 文件以供日後觀看。

閲讀材料 ​

古騰堡計劃Project Gutenberg是一個用來分享免費節日閲讀材料的很好的來源。狄更斯的《聖誕頌歌》 就是這樣一種資源，它可以在網上輕鬆閲讀，也可以下載成 EPUB 或你最喜歡的電子閲讀器的格式。你還可以找到免版税的閲讀材料，如 Librivox 的“光的盛宴”，採用 MP3 格式，因此可以下載並在你喜歡的瀏覽器或媒體播放器中播放。

節日樂趣 ​

節日裏最重要的一點是，它們是與朋友和家人一起的放鬆和歡樂時光。如果你有家人對計算機感到好奇，花點時間與他們分享一些你最喜歡的開源資源。
