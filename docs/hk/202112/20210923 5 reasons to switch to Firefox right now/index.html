馬上改用 Firefox 的 5 個理由 ​

19 年前，Mozilla Firefox 發佈了 0.1 版。

Mozilla Firefox 是一個讓我對開源大開眼界應用程序。這肯定不是轉折點，而是幾個開源應用程序逐漸吸引我注意力，這是累積效應的的一小部分。並且這最終導致我轉向 Linux，並且從未回頭。自從切換到 Firefox（這發生在我有意識地轉向開源之前）以來，我一直是一個狂熱的 Firefox 用户。我的手機一直是 Firefox OS 的手機，直到這個項目被放棄。不過，有趣的是，我並不特別地認為自己是 Firefox 的 粉絲 。我從那時到現在一直在使用 Firefox，是因為從許多方面來説它都是最佳的瀏覽器。接下來是我認為應該馬上 改用 Firefox 的五個原因。

1、Firefox 專注隱私 ​

Firefox 的維護者是 Mozilla 基金會，這是一個完全不以你的個人數據為動機的非營利組織。Mozilla 不關心你搜索的內容、訪問的網站或你網站上使用的時間。這不是 Mozilla 的商業模式，但它顯然是許多其他流行瀏覽器的商業模式。

即使你不反對瀏覽器以隱私為由跟蹤你的活動，你可能也曾有過這樣的經歷：只是一次性購買過某件不尋常的禮物，就導致你訪問的每個網站都試圖向你出售該物品。互聯網很大，所以有時根據用户的興趣來重組它似乎是一個好主意。我承認，如果我所有的搜索都可以“開源”給它們，可能會提供更相關的結果。但話又説回來，我寧願主動選擇這種優化，而不是讓它以及許多其他未知因素一起，在我的控制之外為我做出決定。

Mozilla 的數據政策是這樣的: 儘量少拿、保持安全、毫無隱藏。

不止如此，Firefox 還提供了帳户 監控，這是 Mozilla 的一項可選服務，如果你的任何在線帳户因大規模數據泄露而受到損害，它就會提醒你。另外，Mozilla 使用開源的 Wireguard 提供付費 VPN 服務，因此無論何時何地你都可以安全瀏覽。

2、Firefox 可以使用容器 ​

很難相信的是，曾經有一段時間，當時領先的網頁瀏覽器沒有標籤頁功能。在上世紀 90 年代末和本世紀 00 年代初，當你想同時訪問兩個網頁時，你必須打開兩個單獨的瀏覽器窗口。Firefox（以及之前的 Mozilla 瀏覽器）是標籤頁界面的早期使用者。

標籤頁是現在瀏覽器的標配，但是通過 Firefox 的擴展，標籤頁界面的功能有了有趣的新變化。由 Mozilla 自己開發的 Firefox 多帳户容器插件 可以將每個標籤頁變成瀏覽器中的一個隔離的“容器”。

例如，假設你的僱主使用谷歌應用，但你信不過谷歌接觸你的個人信息。你可以使用多賬户容器插件來隔離你的工作活動，以便谷歌僅觸及你的職業生活，而無法訪問你日常生活的任何部分。

你甚至可以使用兩個不同的帳户打開同一個網站，此外由於標籤頁是用顏色標識的，因此無論你是要隔離網站還是隻是在瀏覽器中添加新的視覺提示，這都很有幫助。

3、Firefox 的用户界面設計 ​

儘管我們人類可能對新事物更感興趣，但在熟悉又可靠的東西中我們能找到更多的舒適感。多年以來，Firefox 不斷更新其界面，並且擁有了相當多的創新，而這些創新現在已經成為非官方的行業標準。但就總體來説，它一直保持不變。Firefox 的用户界面保留了你認為理所當然的所有標準慣例。

當你下載文件時，系統會提示你選擇讓 Firefox 如何處理該文件。根據你的選擇，你可以在適當的應用程序中打開文件或將其保存到硬盤驅動器。你可以選擇讓 Firefox 記住你的選擇並作為你將來的選擇，或者讓它繼續提示你。

當你需要應用程序菜單時，可以在現代的“漢堡包式”的菜單中找到它，或者你可以按 Alt 鍵在 Firefox 的窗口頂部顯示傳統菜單。

無論你是否是 Firefox 的長期用户，Firefox 中的一切都看起來很熟悉，因為它建立在多年的用户界面設計經驗之上。在它可以創新的地方，它就會去創新，但是如果這些創新會違反直覺，它就會廢棄這種創新。

4、Firefox 的開發者工具 ​

回溯萬維網的早期，你可以瀏覽到任何網站並查看其源代碼。僅僅這樣做幾次就很有可能學習到 HTML 的知識。一切都是公開的、透明的、顯而易見的，而且相對簡單的。

互聯網已經逐漸演變成為一個強大的 基於雲的超級計算機，現在從網站中提取有意義的上下文有時需要的不僅僅是其底層標記的文本轉儲。為了確保每個人都可以對網站的功能進行逆向工程（和正向工程），Firefox 在瀏覽器中集成了一套功能強大的開發工具。

雖然這最初是基於 Firefox 的創新（在 2006 年推出的 Firebug），但現在許多瀏覽器都有開發者工具功能。然而，並非所有的開發者工具都一樣，正是 Firefox 的開發者面板使 Firefox 成為我進行網頁設計和用户體驗測試的首選瀏覽器。

5、Firefox 是開源的 ​

最為重要的是，Firefox 是完全開源的。這是一個優秀的瀏覽器，並且對你毫無隱藏。除了保持互聯網開放，教育人們瞭解互聯網，並推廣日常工作的開源解決方案之外，它沒有別有用心的動機。

你可以為 Firefox 做出貢獻。你可以對你不喜歡的部分提交報告。你可以看到與互聯網交互時運行的代碼。幾十年來，Firefox 一直在支持開放互聯網。它忠於其自身的原則，並且可以説已經迫使幾個競爭對手走向開源。如果 Firefox 沒有抬高公眾的期望，它們可能不會選擇開源。

Firefox 是現代互聯網上的具有影響力的力量，它是一款優秀的瀏覽器。Firefox 可以在你的桌面和移動設備上運行，因此想讓自己輕鬆一點，就安裝個 Firefox 吧。
