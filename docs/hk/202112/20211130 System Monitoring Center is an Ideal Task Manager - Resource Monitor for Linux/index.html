系統監控中心：一個理想的 Linux 任務管理器和資源監視器 ​

“系統監控中心”是一個多合一的開源應用，不用使用多種工具就可以監控基本的系統資源情況。

在 Linux 上以圖形方式監控系統資源可能體驗不是很好，這些與你的桌面環境相配套的系統監控工具可能細節有限。

例如，GNOME 的系統監視器不顯示 CPU 頻率和温度。

此外，Linux 的默認系統監控程序通常以簡單為目標，而不是提供詳細的信息。

“系統監控中心System Monitoring Center” 是一個有用的 GUI 工具，它提供了大量必要的信息。在這篇文章中，讓我給你詳細介紹一下它。

系統監控中心：顯示基本系統統計信息的 Linux 應用 ​

系統監控中心是一個基於 GTK3 和 Python 3 的外觀時尚的應用，它為你提供了你想要的所有資源使用數據。

在我的例子中，我想在使用系統監控工具時關注 CPU 的頻率，但 GNOME 的系統監控工具提供不了幫助。所以，這個應用就非常有用了。

該應用的用户體驗良好，並提供了大量的信息和功能。讓我重點介紹一下它的主要功能。

寫這篇文章時，該應用程序仍處於測試階段。因此，你可能會遇到一些錯誤。然而，我在簡短的測試中沒有注意到任何問題。

系統監控中心的功能 ​

首先，它可以讓你查看 CPU、內存、磁盤、網絡、GPU 和傳感器的單獨統計數據。

你可以在該工具中看到以下細節信息：

  • 顯示 CPU 狀態，包括頻率
  • 能夠顯示平均使用率或每個核心的使用率
  • 可以選擇 CPU 頻率和其他統計的精度
  • 能夠改變圖表的顏色
  • 按用户過濾系統進程並輕鬆管理它們
  • 切換一個浮動的摘要小部件，以快速獲得信息
  • 顯示磁盤使用信息和連接的驅動器
  • 在同一個應用中顯示詳細的系統信息
  • 控制啓動服務和程序
  • 能夠控制狀態更新的時間間隔
  • 應用本身的系統資源使用率較低
  • 適應系統主題

雖然它為每個標籤（或組件）提供了大量的選項和自定義功能，但我希望它能在未來的更新中包括 RAM 頻率等東西。

然而，考慮到它可以同時取代磁盤使用分析器和 neofetch 等終端工具，其餘的數據似乎非常有用。

請注意，如果你有多個機箱風扇、獨立的排風扇或 AIO，你可能無法得到風扇的數據。温度也可能有或沒有，但 CPU 的温度應該是可見的。

在 Linux 中安裝系統監控中心 ​

你可以使用可用的 deb 包在任何基於 Ubuntu 的發行版上輕鬆安裝它。

不幸的是，沒有可用的其他軟件包，只有一個 ZIP 文件，你得手動構建和編譯才能安裝它。你在 ZIP 文件中可以找到一個腳本來構建 RPM 包。

deb 文件可以通過 SourceForge 獲得。你點擊下面的按鈕來下載它，或者在他們的 GitLab 頁面 找到。

  • 下載系統監控中心

總結 ​

系統監控中心是一個開源應用，可以讓用户詳細瞭解他們的系統資源，並幫助管理進程。

對於許多 Linux 用户來説，這是一個非常需要的應用，不需要使用單獨的終端/GUI 程序就可以提供詳細的信息。
