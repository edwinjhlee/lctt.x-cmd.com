為開放實踐圖書館做出貢獻的 7 種方式 ​

向開放實踐圖書館做出貢獻是參與全球實踐者社區的一種有趣方式，這些實踐者都願意分享他們的知識並改進他們自己的工作方式。

開放實踐圖書館 是一個社區驅動的實踐集合，以支持團隊的協作。“實踐” 是一種行為或一個 “技巧”，是團隊用來改善他們實現目標的方式。有時這些目標是技術性的，如編程和 IT，但所有的團隊都可以用來幫助定義他們的實踐。無論你是教師、活動策劃者、銷售人員還是藝術家，這個過程都很重要。對於一個團隊，站在同一起跑線上是至關重要的，而這正是開放實踐圖書館可以幫助你做到的。

該圖書館借鑑了來自不同背景的從業者的經驗。如果你是一個敏捷開發從業者或用户體驗研究員，你可能會對該圖書館中的一些實踐感到熟悉。作為一個系統管理員、網站可靠性工程師或軟件開發人員，你也可能認出一些你自己的工具包中的實踐。

為了支持跨職能的團隊共同建立他們的協作技能，開放實踐圖書館向所有人開放，讓他們使用、學習、分享，甚至貢獻，無論他們的角色或工作職能如何。許多人在使用這個圖書館的時候，驚訝地發現他們可以為其做出貢獻！因此，下面我將介紹一下你可以為開放實踐圖書館做出貢獻的七種不同方式，然後探討一下你可能為之貢獻的三個原因。

1、添加評論 ​

分享你使用該實踐的經驗。它對你有用嗎？你會改變什麼嗎？對其他使用該實踐的人有什麼建議嗎？請登錄評論系統，與社區展開討論。

方法： 在每個實踐頁面的底部都有一個評論區。

要加入評論對話，你必須在 Hyvor Talk 上註冊一個賬户。

2、傳播消息 ​

向其他人介紹開放實踐圖書館並邀請他們也來貢獻力量，以幫助開放實踐圖書館社區的發展。可以在 Twitter、Instagram 上找到實踐圖書館，並收聽 該播客。

3、添加你最喜歡的實踐 ​

你是一個擁有久經考驗的方法的實踐者，而圖書館裏還沒有涉及這個方法嗎？如果能與大家分享，那就太好了。請注意，這些內容是在創意共享許可下授權的，以確保其開放給所有人使用並與他人分享。請查看該圖書館的 編輯風格指南，瞭解更多關於如何為其撰寫一篇實踐。

OK，準備好了嗎？

從菜單中選擇 添加一個實踐Add a Practice。

這將使你進入內容管理系統（CMS）的登錄頁面。該圖書館使用開源的 Netlify CMS 來管理投稿。

選擇 用 Netlify 身份登錄Login with Netlify Identity。

然後點擊 使用 GitHub 繼續Continue with GitHub。

接下來，用你的 GitHub 信息登錄，或者（免費）創建一個賬户。

登錄後，選擇 新的實踐New Practice，這將使你進入一個表格，可以將實踐添加到集合中。

一旦你起草了新的實踐，你還需要把你的名字和 GitHub 用户名添加到 CMS 中，以便在 實踐Practice 頁面上顯示。從 快速添加Quick add 菜單中選擇 作者Author，或者從 集合 Collections 菜單中選擇 作者Author，然後選擇 新作者New Author。

4、添加一個有用的資源或鏈接 ​

點擊 改進此實踐Improve this Practice 按鈕，找到 我們喜歡的鏈接links we love部分。發佈網址、添加描述、並選擇類別（例如，視頻、Blog）。

你可以搜索你想改進的實踐，例如，“Affinity Mapping”。

然後點擊實踐名稱，打開編輯頁面。

5、看到一個錯別字？ ​

點擊 改進此實踐Improve this Practice 按鈕，直接去修改它吧

6、在 GitHub 上添加一個議題 ​

看到有什麼不對的地方嗎？對某個功能有建議？請讓社區知道。

如何做： 到 議題頁面 並登錄 GitHub 來添加一個新議題。

7、幫助處理網站的代碼 ​

在 GitHub 上有一個累積的議題，列出了網站上需要幫助的地方。如果你想捲起袖子，幫助修復錯誤 或開發新功能 —— 你甚至還可以貢獻代碼。

總結 ​

為什麼要貢獻？這裏有三個原因供你考慮。

  1. “寓學於教”是一句古老的羅馬諺語。

    通過寫下來並與他人分享，你會加深自己對所使用的實踐的理解。對該實踐的來源背景做一些研究，幫助註明原始來源，並找到其使用的例子。

  2. 提高你的寫作技巧。

    通過遵循編輯風格指南，你正在學習調整你的自然寫作風格以適應特定的標準。這是一項有價值的基本溝通技巧，你可以在一系列的環境中應用。

  3. 展示領導力。

    通過與一個開放的全球社區分享你的知識和專長，你可以幫助他人成長並從你的深度經驗中學習。

向開放實踐圖書館貢獻 是參與全球開放的實踐者社區的一種有趣而簡單的方式，這些實踐者都願意分享他們的知識，並試圖改善他們自己的工作方式。
