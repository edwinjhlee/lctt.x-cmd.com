2021 年的 12 件 Linux 大事 ​

現在，是時候回顧一下今年影響 Linux 和 Linux 用户的一些大事了。

2021 年即將結束。Linux 今年屢有大事，雖然並不全是好消息。

讓我來分享一些來自 Linux 世界的大事，這些事件對普通的 Linux 用户，特別是桌面 Linux 用户有一定的影響。

1、RMS 重返自由軟件基金會 ​

自由軟件基金會Free Software Foundation（FSF）的創始主席 Richard Stallman（RMS）在 2019 年因媒體的抨擊而被迫辭職。然而，這位標誌性的嬉皮士技術人在今年 3 月份的 LibrePlanet 活動中出人意料地 宣佈復出。

雖然自由軟件運動是 Stallman 在 80 年代發起的，並創立了自由軟件基金會（FSF），但這次他是以董事會成員之一的身份迴歸的，而不是以主席的身份。

這段插曲使開源世界再次分裂。許多組織和開發者反對他的迴歸。但與此同時，Stallman 也得到了 來自非美國開發者的壓倒性支持。

儘管 Stallman 已經道歉，但許多來自 GNOME 和開源推進計劃Open Source Initiative的人 主張撤換整個 FSF 董事會。

許多主要的贊助商因此斷絕了與 FSF 的關係，但 FSF 在財政困難的情況下仍在堅持。2021 年即將結束，Stallman 仍然活躍在他 30 多年前創立的組織的董事會中。

2、Arch Linux 引入了一個安裝程序 ​

不過不是圖形化的。

你可能已經知道，安裝 Arch Linux 並不像安裝 Ubuntu 或 Fedora 那樣簡單。沒有圖形化的安裝程序。一切都必須通過命令列來完成，但即使是這樣，你也必須參考一些文檔。

Arch Linux 試圖通過提供一個用來指導你的安裝腳本來改善這種情況。

當然，它不像圖形化的安裝那麼舒服，但至少有指導的 Arch Linux 安裝總比沒有好。

這個 archinstall 腳本可以在較新的 Arch Linux ISO 中找到，你可以在安裝 Arch Linux 時在 TTY 中輸入 archinstall 來使用它。

3、微軟 Edge 瀏覽器登陸 Linux ​

它已經測試一年多了，但在 2021 年我們終於看到了 微軟基於 Chromium 的 Linux 版 Edge 瀏覽器的最終穩定版。

我知道一些 Linux 用户徹底反對接觸任何微軟的東西，這當然很好。它只是為 Linux 上長長的可用網頁瀏覽器列表增加了一個選擇。在 Windows 系統上使用 Edge 的人現在有能力在 Linux 上使用和同步他們的瀏覽器活動。

一些 在 Linux 上安裝了 Edge 瀏覽器 的用户發現它出乎意料地好。就個人而言，比起其他瀏覽器，我還是更喜歡 Firefox，但如果 Edge 能把超高清或全高清的 Netflix 流媒體帶到 Linux 上，它可能會成為我的輔助瀏覽器。

4、CentOS 替代品的崛起 ​

紅帽公司去年震驚了 Linux 世界，它決定 幹掉穩定的 CentOS，轉而支持滾動發佈的 CentOS Stream。

這催生了 幾個 CentOS 替代發行版。其中獲得了最多人氣和 CentOS 市場份額的兩個發行版是 Rocky Linux 和 Alma Linux。

Rocky Linux 是由 Gregory M. Kurtzer 創建的，他是 CentOS 的最初的創建者。

Alma Linux 是由 CloudLinux 創建的，它是一家提供了基於 CentOS 的服務器和內核補丁服務的企業。

這兩個發行版已經佔領了 CentOS 留下的市場。紅帽公司向小型企業免費提供 RHEL 許可證的計劃 並沒有那麼成功。

5、Steam Deck ​

Valve 發佈了一款名為 Steam Deck 的掌上游戲設備。它產生了相當大的反響，預購即售罄。

它與 Linux 有什麼關係？有兩個：

首先，Steam Deck 運行在基於 Arch Linux 的定製 Steam OS 上。考慮到這些遊戲將在基於 Linux 的操作系統上運行，這給桌面 Linux 上的遊戲也帶來了希望。

第二，Steam 聲稱所有的遊戲（無論它們是否只在 Windows 上運行）都將可以在 Steam Deck 上運行。這個口號太大了，但是 Steam 已經開始驗證能在 Deck 上運行的遊戲。這可能意味着經過 Deck 驗證的遊戲在桌面 Linux 上應該也能正常運行。

6、反作弊引擎正式支持 Linux ​

對 Linux 玩家來説這是又一個 2021 年的大新聞。Epic Games 為其 Easy-Anti Cheat 服務增加了完整的 Linux 支持，以及官方 SteamPlay（或 Proton）和 Wine 兼容性。

Easy-Anti-Cheat 是 Epic 提供的業界領先的反作弊服務，可以防止多人 PC 遊戲中的黑客攻擊和作弊。

這是一個重大舉措，因為 Linux 遊戲玩家經常被禁止參與許多流行的多人遊戲，如《堡壘之夜》、《戰地》。隨着反作弊支持的加入，在 Linux 上玩主流多人遊戲變得更加容易。

7、GNOME 40 ​

GNOME 40 是一個激進的版本。幾乎和 GNOME 3 一樣激進。

不，將版本號從 3.38 跳到 40 並不是關鍵因素。

GNOME 40 換成了三指輕掃的水平佈局。這種水平方式使得第 40 版在用户界面和用户體驗上與之前的版本有很大不同。

8、內核 5.15 中支持 NTFS ​

這可能看起來沒什麼，但 Linux 內核中對 NTFS 文件系統的適當驅動支持對許多人來説是件大事，特別是對於共享分區來説。

之前，NTFS 文件系統是在用户空間（FUSE）中藉助 ntfs-3g 軟件包使用的。這意味着數據的讀取和寫入速度很慢。

原生的驅動程序改善了 Linux 中 NTFS 文件系統的性能。

9、Linux 已經 30 歲了 ​

Linux 內核比許多 Linux 用户都要老。它誕生於 1991 年 9 月，當時芬蘭計算機科學專業的學生 Linus Torvalds 宣佈了這個 “愛好項目”，它本應不是 “大而專業” 的。

Torvalds 以 Linux 項目作為他的畢業論文取得了他的碩士學位。Torvalds 不可能知道他的 “愛好” 將成為今天 IT 世界的支柱和一個成功的開源項目的代表。

10、Linus Tech Tips 對 Linux 桌面的實驗 ​

這是另一位將 Linux 推上風口浪尖的 Linus。

Linus Sebastian 是頂級的技術 YouTuber 之一，他開始挑戰日常使用 Linux 30 天的目標。

一個擁有數百萬訂閲者的流行 YouTuber 使用了 Linux。這是一個前所未有的機會，是桌面 Linux 被數百萬 Windows 用户看到的一次大公關。

但是它出了問題。實際上，是可怕的錯誤。

Linus Sebastian 在 Linux 上遇到了困難。他遇到了各種困難，最後在試圖安裝 Steam 的時候毀掉了他的 Pop!_OS 系統。

我不知道 Torvalds 是否看到了那些視頻，這個與他同名的人在他的造物中苦苦掙扎。

11、蘋果的 M1 Mac 上的 Linux ​

一個蘋果讓世界認識了重力（儘管它已經存在）。一個蘋果讓世界認識了 ARM 處理器（儘管它也已經存在）。

蘋果公司基於 ARM 的 M1 系列因其性能提升而在用户中大受歡迎。有一個專門的項目 Asahi 正在努力使 Linux 可以在蘋果 M1 設備上運行。

2021 年，Asahi Linux 取得了一些良好的進展。他們的工作也將使其他發行版受益。

12、Windows 11 發佈 ​

為什麼 Windows 11 的發佈與 Linux 有關呢？因為不是所有的現有系統都有資格運行 Windows 11。這意味着當 Windows 10 支持結束時，將有一大批設備運行一個過時的操作系統。他們中的一些人會轉移到 Linux。

不要認為我過於樂觀。當 Windows XP 支持結束時，我已經看到了這種流亡。一些 Linux Mint 和 Zorin OS 用户曾經是 Windows XP 的移民。

讓我們希望 2022 年對我們所有人都好一些 ​

2020 年開始的 COVID-19 流行病在今年繼續困擾着世界。看看 Omicron 變種的傳播情況，2022 年的情況看起來也不太樂觀。

但是，讓我們不要太悲觀，慶祝新的一年，希望明年對桌面 Linux 用户和其他所有人會更好。
