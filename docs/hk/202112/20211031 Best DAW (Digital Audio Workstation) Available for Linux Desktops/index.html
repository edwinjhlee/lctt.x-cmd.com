最佳 Linux 桌面 DAW（數字音頻工作站） ​

數字音頻工作站Digital Audio Workstation（DAW）可以讓你錄音、混音和製作音樂。對於商業用途，有幾個主流的選擇可以考慮，它們通常被認為是行業標準。

像 Steinberg 的 Nuendo/Cubase、ProTools、Ableton Live 和 FL Studio 這樣成熟的音樂 DAW 是最流行（也是最昂貴）的解決方案。然而，它們並不能用於 Linux。

因此，當用在 Linux 上時，你只能根據現有的選項做出不同的選擇。而在這裏，我的目的是幫助你找出 Linux 上最好的音樂 DAW。

在使用 Linux 上的 DAW 之前要記住的事情 ​

儘管你可以達到與 Windows/MacOS 系統相同的效果，但在選擇使用 Linux 的 DAW 之前，你應該知道一些要點。

如果你是專業人士，並且使用過 Linux，你可能已經知道了這些。但是，對於新的 Linux 用户，這可以幫助你做出決定：

  • 許多音頻接口沒有正式支持 Linux。所以，你可能要在開始之前檢查一下兼容性和音頻設置過程。
  • 流行的音頻插件可能無法直接工作。你必須得尋找替代品或嘗試使用 Wine（這是一個耗時的過程）。
  • 即插即用的情況可能不存在。各種任務都需要手動設置。

總的來説，在 Linux 中使用 DAW 時，有一些先決條件。它可能不能簡單地安裝然後就能開始製作音樂。所以，在選擇 Linux 作為 DAW 的首選平台之前，你需要了解這些。

請注意，有幾個 可用於 Linux 的音頻編輯器，但不是所有的都可以作為一個成熟的 DAW 使用。

現在你知道了這些注意事項，讓我提一下目前最好的 Linux DAW。

非 FOSS 警報！

這裏提到的應用並不全是開源的。它們被列在這裏是因為它們在 Linux 上可用，而這篇文章的重點是 Linux。

雖然可用於 Linux 的 DAW 可能有許多，但為了確保你得到最好的硬件/軟件兼容性，以及易於使用的界面，我們將我們的列表限制在流行的選項上。

1、Ardour ​

Ardour 是最流行的開源 DAW，可用於 Linux。它也可用於 Windows 和 macOS。

它是音樂家、音頻工程師和作曲家的一個合適選擇。你可以獲得編輯樂譜和錄製/混合歌曲的所有基本能力。

它自帶幾個插件支持。但是，你需要通過在插件管理器中手動添加它們到混音器中。另外，你可以選擇通過指定路徑來添加外部 VST3 插件。如果你想從中提取音頻或同步，Ardour 還支持視頻時間線。

在 Linux 中安裝 Ardour ​

與其他付費版 DAW 不同，你不需要支付高昂的價格就可以使用它。你所需要做的就是購買一個低至 1 美元/月的訂閲，只要你的訂閲是有效的，你就可以繼續訪問這個程序和它的更新。

如果你對訂閲不感興趣，你可以選擇一次性付款，這可以讓你獲得小版本更新和下一個主要版本（取決於你支付的金額）。

最重要的是，如果你喜歡測試即將到來的功能和改進，你還可以訪問其開發（或每日）構建版本。

對於 Linux 發行版，它提供了一個 .run 文件，你可以輕鬆地從終端啓動。

2、LMMS ​

LMMS 是一個自由開源的 DAW，可用於 Linux 和其他平台。

與其他一些 DAW 相比，LMMS 在專業人員所需的專業方面可能有所欠缺。

然而，如果你剛剛開始創作音樂，或者需要一些無需購買/訂閲就可以使用的東西，它應該可以滿足你的一些功能需求。換句話説，它是一個合適的歌曲編輯 DAW。

如果你是從另一個平台上的 DAW 遷移來的，它的用户界面可能不太容易熟悉。但是，當你習慣了它，它就很容易使用了。

它還支持鋼琴音符標籤，以幫助你獲得音樂製作體驗。

在 Linux 中安裝 LMMS ​

你可以選擇下載一個 AppImage 文件，它可以在你選擇的任何 Linux 發行版上工作。它的配置相當簡單，所以你只需要指定一個工作目錄就可以開始了。

3、Bitwig Studio ​

Bitwig Studio 是流行的主流音樂 DAW 之一，也支持 Linux。與本列表中的其他 DAW 相比，Bitwig 提供了更好的跨平台支持和硬件集成。

即使你可能堅持使用 Linux 進行音樂製作，但擁有跨平台的支持，以便在你出門在外也可以繼續你的工作，對一些人來説這也是一個重要的因素。

Bitwig 包括各種創意工具來處理音頻文件和信號。所以，它完全可以滿足專業要求。

在 Linux 中安裝 Bitwig Studio ​

它提供了一個傳統的 DEB 包用於安裝。你可以在“演示模式”下免費使用它，但它不允許你保存和導出任何東西。Bitwig Studio 在 Flathub 上還有一個 Flatpak 包。

要解鎖所有的功能，你需要以 $399 的價格購買它。

4、REAPER ​

Reaper 是一個可用於 Linux 的經濟型 DAW。它提供了一個簡單的用户界面和所有的基本功能。

和 Bitwig Studio 相比，它可能沒有提供很多開箱即用的插件和功能，但它應該足以滿足大多數通常的需求，如調製、自動化、使用 VST 插件等等。

儘管我沒有親自使用過它，但 Reaper 聲稱它是高度可定製的，並提供了與各種硬件的良好兼容性。

在 Linux 中安裝 Reaper ​

與其他選擇不同，Reaper 提供了一個 tar 包，你需要解壓和安裝。它包括一個腳本文件。因此，當你解壓後，在該文件夾中打開終端或在終端中進入該文件夾，然後用以下命令執行該腳本：

./install-reaper.sh

當你安裝它時，該腳本也會生成一個用於卸載的腳本。所以，在安裝時一定要仔細選擇文件夾，並確保在需要時能找到它。

在你需要購買它之前，你可以沒有任何限制的免費使用它，最長可達 60 天。所以，如果你想在購買 DAW 之前徹底測試一下，我覺得這是一件非常好的事情。

個人使用的費用是 $60，如果你需要用於商業用途，則需要 $225。

總結 ​

不幸的是，找不到太多可用於 Linux 的 DAW 。你可以嘗試用 Wine 來運行一些流行的音樂 DAW，但我不確定成功率有多少。

無論是哪種情況，這裏提到的這些對於大多數用户來説應該是綽綽有餘了。
