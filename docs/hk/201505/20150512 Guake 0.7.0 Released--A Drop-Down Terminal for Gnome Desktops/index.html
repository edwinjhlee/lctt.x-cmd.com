一個用於Gnome桌面的下拉式終端： Guake 0.7.0 發佈 ​

Linux的命令列是最好、最強大的東西，它使新手着迷，併為老手和極客的提供極其強大的功能。那些在服務器和生產環境下工作的人早已認識到了這個事實。有趣的是，Linux終端是Linus Torvald在1991年寫內核時實現的第一批功能之一。

終端是個強大的工具，由於它沒有什麼可調整的部分，所以十分可靠。終端介於控制台環境和GUI環境之間。終端自身作為一個GUI程序，運行在桌面環境下。有許多終端是適用於特定的桌面環境的，其它的則是通用的。Terminator, Konsole, Gnome-Terminal, Terminology, XFCE terminal, xterm都是些常用的終端模擬器。

您可以從下面的鏈接中獲得一份使用最廣泛的終端模擬器的列表。

  • 20 Useful Terminals for Linux

前幾日上網時，我偶遇了名為‘Guake’的終端程序，它是用於gnome的終端模擬器。儘管這並不是我第一次聽到Guake。實際上，我在大約一年前便知道了這個應用程序，但不知怎麼搞的，我那時沒有寫寫Guake，再後來我便漸漸忘掉了Guake，直到我再一次聽到Guake。所以，最終，這篇文章誕生了。我將給你講講Guake的功能，在Debian、Ubuntu、Fedora上的安裝過程以及一些測試。

什麼是Guake？ ​

Guake是應用於Gnome環境的下拉式終端。主要由Python編寫，使用了一些C，它以GPL2+許可證發佈，適用於Linux以及類似的系統。Guake的靈感來源於電腦遊戲Quake（雷神之錘）中的終端，Quake的終端能通過按下特定按鍵（默認為F12）從屏幕上滑下來，並在按下同樣的鍵後滑上去。

值得注意的是，Guake並不是第一個這樣的應用。Yakuake（Yet Another Kuake）是一個運行於KDE的終端模擬器，Tilda是一個用GTK+寫成的終端模擬器。它們的靈感都來自於雷神之錘那上下滑動的終端。

Guake的功能 ​

  • 輕量級
  • 簡單而優雅
  • 功能眾多
  • 強大
  • 美觀
  • 將終端平滑地集成於GUI中
  • 在按下預定義的鍵後出現/消失
  • 支持熱鍵、標籤、透明化背景，這使得它適合所有Gnome用户
  • 可配置各種方面
  • 包括許多顏色的調色板
  • 設定透明度的快捷方式
  • 通過Guake配置，可在啓動時運行一個腳本
  • 可以在多個顯示器上運行

Guake 0.7.0最近發佈，它帶來了一些修正以及上面提到的一些功能。完整的版本歷史和源代碼包可以在這裏找到。

在Linux中安裝Guake終端 ​

如果您對從源碼編譯Guake感興趣，您可以從上面的鏈接處下載Guake，並在安裝前進行編譯。

然而Guake可以在許多的發行版中通過添加額外的倉庫來安裝。這裏，我們將在Debian、Ubuntu、Linux Mint和Fedora下安裝Guake。

首先從倉庫獲取最新的軟件包列表，並從默認的倉庫安裝Guake，如下所示：

---------------- 在 Debian, Ubuntu 和 Linux Mint 上 ----------------
$ sudo apt-get update
$ apt-get install guake

---------------- 在 Fedora 19 及其以後版本 ----------------
# yum update
# yum install guake

安裝後，可以從另一個終端中啓動Guake：

$ guake

在啓動它後，便可以在Gnome桌面中使用F12（默認配置）來拉下、收回終端。

看起來非常漂亮，尤其是透明背景。滑下來...滑上去...滑下來...滑上去...執行命令，打開另一個標籤，執行命令，滑上去...滑下來...（作者已沉迷其中）

Guake實戰

如果您的壁紙或活動窗口的顏色和Guake的顏色有些不搭。您可以改變您的壁紙，減少透明度或者改變Guake的顏色。

下一步便是進入Guake的配置，根據每個人的需求修改設置。可以通過應用菜單或者下面的命令來運行Guake的配置。

$ guake --preferences

結論 ​

這個項目即不是太年輕也不是太古老，因此它已經達到了一定的成熟度，足夠可靠，可以開箱即用。像我這樣需要在GUI和終端間頻繁切換的人來説，Guake是一個福利。我不需要管理一個多餘的窗口，頻繁的打開和關閉，使用tab在大量打開的應用程序中尋找終端或切換到不同的工作區來管理終端，現在我需要的只有F12。

我認為對任何同時使用GUI和終端的Linux用户來説，Guake都是必須的工具。同樣的，我會向任何想要在系統中結合使用GUI和終端的人推薦它，因為它既平滑又沒有任何障礙。
