5 個基於Linux命令列的文件下載和網站瀏覽工具 ​

Linux命令列是GNU/Linux中最神奇迷人的部分，它是非常強大的工具。命令列本身功能多樣，多種內建或者第三方的命令列應用使得Linux變得更加健壯和強大。Linux Shell支持多種不同類型的網絡應用，無論是BT下載軟件，專用下載器或者互聯網衝浪。

5個命令列互聯網工具

這裏我們介紹了5個很好的命令列互聯網工具，它們非常有用，也很容易上手。

1. rTorrent ​

rTorrent是基於文本，用C++編寫，追求高性能的Torrent客户端。支持大部分標準的Linux發行版，包括FreeBSD和Mac OS X。

安裝rTorrent ​

# apt­-get install rtorrent    (基於 APT 的系統)

# yum install rtorrent        (基於 YUM 的系統)

在終端中用下面的命令檢查rtorrent是否正確安裝

# rtorrent

rTorrent命令列工具

rTorrent的功能 ​

一些有用的快捷鍵和使用方法

  • CTRL+ q – 退出rTorrent應用程序
  • CTRL+ s – 開始下載
  • CTRL+ d – 停止運行中的下載或者移除已完成的下載
  • CTRL+ k – 停止並關閉運行中的下載
  • CTRL+ r – 在上傳/下載種子之前進行Hash檢查
  • CTRL+ q – 執行兩次這個命令，rTorrent會直接退出而不發送“停止”信號
  • Left Arrow Key – 跳到上一屏幕
  • Right Arrow Key – 跳到下一屏幕

2. Wget ​

Wget是GNU項目的一部分，名字由World Wide Web (WWW)衍生而來。Wget是用來遞歸下載、離線查看本地服務器HTML文件一個很好的工具，它可用於Windows， Mac，以及Linux等大部分平台。Wget能通過HTTP，HTTPS和FTP下載文件。另外，能鏡像整個網站，支持代理瀏覽以及暫停/回覆下載使得它更為有用。

安裝Wget ​

由於是GNU項目的一部分，Wget捆綁在大部分標準Linux發行版中，不再需要獨立下載安裝。如果默認沒有安裝，你也可以使用apt或者yum安裝。

# apt­-get install wget        (基於 APT 的系統)

# yum install wget        (基於 YUM 的系統)

Wget的一些基本用法 ​

使用wget下載一個單獨的文件.

# wget http://www.website-name.com/file

遞歸下載整個網站.

# wget -r http://www.website-name.com

從一個網站下載指定類型的文件(例如 pdf 和 png).

# wget -r -A png,pdf http://www.website-name.com

Wget是一個很棒的工具，它允許在資源有限的機器上自定義或者過濾下載。這是鏡像一個網站(Yahoo.com)的wget下載截圖。

3. cURL ​

cURL是在多種協議上傳輸數據的命令列工具。cURL是支持FTP, HTTP, FTPS, TFTP, TELNET, IMAP, POP3等協議的客户端應用。cURL是一個不同於wget 的簡單下載器，和其它的相比，它支持LDAP，POP3。cURL也很好的支持代理下載，暫停下載以及恢復下載。

安裝cURL ​

在軟件倉庫或者已安裝軟件中，cURL在大部分發行版中默認是可用的。如果沒有安裝，運行apt或者yum從軟件倉庫中獲取需要的安裝包。

# apt­-get install curl        (基於 APT 的系統)

# yum install curl        (基於 YUM 的系統)

cURL的基本使用方法

# curl www.tecmint.com

4. w3m ​

W3m是GPL協議下發布的基於文本的web瀏覽器。W3m支持表格，幀，顏色，SSL連接以及內聯圖像。W3m以快速瀏覽而出名。

安裝w3m ​

W3m在大部分Linux發行版中也是默認可用的。如果不可用的話可以用apt或者yum獲取需要的安裝包。

# apt­-get install w3m        (基於 APT 的系統)

# yum install w3m        (基於 YUM 的系統)

w3m的基本使用方法 ​

# w3m www.tecmint.com

基於文本的web瀏覽器w3m

5. Elinks ​

Elinks是基於文本的免費瀏覽器，用於Unix及基於Unix的系統。Elinks支持 HTTP，HTTP Cookies以及支持瀏覽Perl和Ruby腳本（LCTT 譯註：應該是指 CGI）。也很好的支持選項卡瀏覽。最棒的是它支持鼠標、彩色以及支持一系列的協議，例如HTTP, FTP, SMB, Ipv4 和 Ipv6。

安裝Elinks ​

Elinks在大部分Linux發行版上是默認可用的。如果不是的話，可以通過apt或者yum安裝。

# apt­-get install elinks    (基於 APT 的系統)

# yum install elinks        (基於 YUM 的系統)

Elinks的基本使用方法

# elinks www.tecmint.com

Elinks命令列瀏覽互聯網
