多雲融合和安全集成推動 SD-WAN 的大規模應用 ​

2022 年 SD-WAN 市場 40% 的同比增長主要來自於包括 Cisco、VMWare、Juniper 和 Arista 在內的網絡供應商和包括 AWS、Microsoft Azure，Google Anthos 和 IBM RedHat 在內的服務提供商之間的緊密聯繫。

越來越多的雲應用，以及越來越完善的網絡安全性、可視化特性和可管理性，正以驚人的速度推動企業軟件定義廣域網software-defined WAN（SD-WAN）的部署。

IDC（LCTT 譯註：International Data Corporation）公司的網絡基礎架構副總裁 Rohit Mehra 表示，根據 IDC 的研究，過去一年中，特別是軟件和基礎設施即服務（SaaS 和 IaaS）產品推動了 SD-WAN 的實施。

例如，IDC 表示，根據其最近的客户調查結果，有 95％ 的客户將在兩年內使用 SD-WAN 技術，而 42％ 的客户已經部署了它。IDC 還表示，到 2022 年，SD-WAN 基礎設施市場將達到 45 億美元，此後每年將以每年 40％ 的速度增長。

“SD-WAN 的增長是一個廣泛的趨勢，很大程度上是由企業希望優化遠程站點的雲連接性的需求推動的。” Mehra 説。

思科最近撰文稱，多雲網絡的發展正在促使許多企業改組其網絡，以更好地使用 SD-WAN 技術。SD-WAN 對於採用雲服務的企業至關重要，它是園區網、分支機構、物聯網、數據中心 和雲之間的連接中間件。思科公司表示，根據調查，平均每個思科的企業客户有 30 個付費的 SaaS 應用程序，而他們實際使用的 SaaS 應用會更多——在某些情況下甚至超過 100 種。

這種趨勢的部分原因是由網絡供應商（例如 Cisco、VMware、Juniper、Arista 等）（LCTT 譯註：這裏的網絡供應商指的是提供硬件或軟件並可按需組網的廠商）與服務提供商（例如 Amazon AWS、Microsoft Azure、Google Anthos 和 IBM RedHat 等）建立的關係推動的。

去年 12 月，AWS 為其雲產品發佈了關鍵服務，其中包括諸如 AWS Transit Gateway 等新集成技術的關鍵服務，這標誌着 SD-WAN 與多雲場景關係的日益重要。使用 AWS Transit Gateway 技術，客户可以將 AWS 中的 VPC（虛擬私有云Virtual Private Cloud）和其自有網絡均連接到相同的網關。Aruba、Aviatrix Cisco、Citrix Systems、Silver Peak 和 Versa 已經宣佈支持該技術，這將簡化和增強這些公司的 SD-WAN 產品與 AWS 雲服務的集成服務的性能和表現。

Mehra 説，展望未來，對雲應用的友好兼容和完善的性能監控等增值功能將是 SD-WAN 部署的關鍵部分。

隨着 SD-WAN 與雲的關係不斷發展，SD-WAN 對集成安全功能的需求也在不斷增長。

Mehra 説，SD-WAN 產品集成安全性的方式比以往單獨打包的廣域網安全軟件或服務要好得多。SD-WAN 是一個更加敏捷的安全環境。SD-WAN 公認的主要組成部分包括安全功能，數據分析功能和廣域網優化功能等，其中安全功能則是下一代 SD-WAN 解決方案的首要需求。

Mehra 説，企業將越來越少地關注僅解決某個具體問題的 SD-WAN 解決方案，而將青睞於能夠解決更廣泛的網絡管理和安全需求的 SD-WAN 平台。他們將尋找可以與他們的 IT 基礎設施（包括企業數據中心網絡、企業園區局域網、公有云 資源等）集成更緊密的 SD-WAN 平台。他説，企業將尋求無縫融合的安全服務，並希望有其他各種功能的支持，例如可視化、數據分析和統一通信功能。

“隨着客户不斷將其基礎設施與軟件集成在一起，他們可以做更多的事情，例如根據其局域網和廣域網上的用户、設備或應用程序的需求，實現一致的管理和安全策略，並最終獲得更好的整體使用體驗。” Mehra 説。

一個新興趨勢是 SD-WAN 產品包需要支持 SD-branch 技術。 Mehra 説，超過 70％ 的 IDC 受調查客户希望在明年使用 SD-Branch。在最近幾周，Juniper 和 Aruba 公司已經優化了 SD-branch 產品，這一趨勢預計將在今年持續下去。

SD-Branch 技術建立在 SD-WAN 的概念和支持的基礎上，但更專注於滿足分支機構中局域網的組網和管理需求。展望未來，SD-Branch 如何與其他技術集成，例如數據分析、音視頻、統一通信等，將成為該技術的主要驅動力。
