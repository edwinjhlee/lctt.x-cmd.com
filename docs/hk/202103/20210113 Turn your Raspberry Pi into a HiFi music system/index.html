把你的樹莓派變成一個 HiFi 音樂系統 ​

為你的朋友、家人、同事或其他任何擁有廉價發燒設備的人播放音樂。

在過去的 10 年裏，我大部分時間都是遠程工作，但當我走進辦公室時，我坐在一個充滿內向的同伴的房間裏，他們很容易被環境噪音和談話所幹擾。我們發現，聽音樂可以抑制辦公室的噪音，讓聲音不那麼擾人，用愉快的音樂提供一個愉快的工作環境。

起初，我們的一位同事帶來了一些老式的有源電腦音箱，把它們連接到他的桌面電腦上，然後問我們想聽什麼。它可以工作，但音質不是很好，而且只有當他在辦公室的時候才可以使用。接下來，我們又買了一對 Altec Lansing 音箱。音質有所改善，但沒有什麼靈活性。

不久之後，我們得到了一台通用 ARM 單板計算機（SBC），這意味着任何人都可以通過 Web 界面控制播放列表和音箱。但一塊普通的 ARM 開發板意味着我們不能使用流行的音樂設備軟件。由於非標準的內核，更新操作系統是一件很痛苦的事情，而且 Web 界面也經常出現故障。

當團隊壯大並搬進更大的房間後，我們開始夢想着有更好音箱和更容易處理軟件和硬件組合的方法。

為了用一種相對便宜、靈活、音質好的方式解決我們的問題，我們用樹莓派、音箱和開源軟件開發了一個辦公室 HiFi。

HiFi 硬件 ​

用一個專門的 PC 來播放背景音樂就有點過分了。它昂貴、嘈雜（除非是靜音的，但那就更貴了），而且不環保。即使是最便宜的 ARM 板也能勝任這個工作，但從軟件的角度來看，它們往往存在問題。樹莓派還是比較便宜的，雖然不是標準的計算機，但在硬件和軟件方面都有很好的支持。

接下來的問題是：用什麼音箱。質量好的、有源的音箱很貴。無源音箱的成本較低，但需要一個功放，這需要為這套設備增加另一個盒子。它們還必須使用樹莓派的音頻輸出；雖然可以工作，但並不是最好的，特別是當你已經在高質量的音箱和功放上投入資金的時候。

幸運的是，在數以千計的樹莓派硬件擴展中，有內置數字模擬轉換器（DAC）的功放。我們選擇了 HiFiBerry 的 Amp。它在我們買來後不久就停產了（被採樣率更好的 Amp+ 型號取代），但對於我們的目的來説，它已經足夠好了。在開着空調的情況下，我想無論如何你也聽不出 48kHz 或 192kHz 的 DAC 有什麼不同。

音箱方面，我們選擇了 Audioengine P4，是在某店家清倉大甩賣的時候買的，價格超低。它很容易讓我們的辦公室房間充滿了聲音而不失真（並且還能傳到我們的房間之外，有一些失真，隔壁的工程師往往不喜歡）。

HiFi 軟件 ​

在我們舊的通用 ARM SBC 上我們需要維護一個 Ubuntu，使用一個固定的、古老的、在軟件包倉庫外的系統內核，這是有問題的。樹莓派操作系統包括一個維護良好的內核包，使其成為一個穩定且易於更新的基礎系統，但它仍然需要我們定期更新 Python 腳本來訪問 Spotify 和 YouTube。對於我們的目的來説，這有點過於高維護。

幸運的是，使用樹莓派作為基礎意味着有許多現成的軟件設備可用。

我們選擇了 Volumio，這是一個將樹莓派變成音樂播放設備的開源項目。安裝是一個簡單的一步步完成的過程。安裝和升級是完全無痛的，而不用辛辛苦苦地安裝和維護一個操作系統，並定期調試破損的 Python 代碼。配置 HiFiBerry 功放不需要編輯任何配置文件，你只需要從列表中選擇即可。當然，習慣新的用户界面需要一定的時間，但穩定性和維護的便捷性讓這個改變是值得的。

播放音樂並體驗 ​

雖然大流行期間我們都在家裏辦公，不過我把辦公室的 HiFi 安裝在我的家庭辦公室裏，這意味着我可以自由支配它的運行。一個不斷變化的用户界面對於一個團隊來説會很痛苦，但對於一個有研發背景的人來説，自己玩一個設備，變化是很有趣的。

我不是一個程序員，但我有很強的 Linux 和 Unix 系統管理背景。這意味着，雖然我覺得修復壞掉的 Python 代碼很煩人，但 Volumio 對我來説卻足夠完美，足夠無聊（這是一個很好的“問題”）。幸運的是，在樹莓派上播放音樂還有很多其他的可能性。

作為一個終端狂人（我甚至從終端窗口啓動 LibreOffice），我主要使用 Music on Console（MOC）來播放我的網絡存儲（NAS）中的音樂。我有幾百張 CD，都轉換成了 FLAC 文件。而且我還從 BandCamp 或 Society of Sound 等渠道購買了許多數字專輯。

另一個選擇是 音樂播放器守護進程（MPD）。把它運行在樹莓派上，我可以通過網絡使用 Linux 和 Android 的眾多客户端之一與我的音樂進行遠程交互。

音樂不停歇 ​

正如你所看到的，創建一個廉價的 HiFi 系統在軟件和硬件方面幾乎是無限可能的。我們的解決方案只是眾多解決方案中的一個，我希望它能啓發你建立適合你環境的東西。
