不懂代碼的人也可以乾的 4 種技術工作 ​

對於不是工程師的人來説也有很多技術工作可以做。本文作為本系列的第二篇，就具體闡述這些工作。

在 本系列的第一篇文章 中，我解釋了技術行業如何將人員和角色劃分為“技術”或“非技術”類別，以及與此相關的問題。科技行業使得那些對科技感興趣但不懂編程的人很難找到適合自己的角色。

如果你對技術或開源感興趣，但對編程不感興趣，這也有一些工作適合你。科技公司的任何一個職位都可能需要一個精通科技但不一定會寫代碼的人。但是，你確實需要了解術語並理解產品。

我最近注意到，在諸如技術客户經理、技術產品經理、技術社區經理等職位頭銜上增加了“技術”一詞。這反映了幾年前的趨勢，即在頭銜上加上“工程師”一詞，以表示該職位的技術需要。過了一段時間，每個人的頭銜中都有“工程師”這個詞，這樣的分類就失去了一些吸引力。

當我坐下來寫這些文章時，Tim Banks 的這條推特出現在我的通知欄上：

已經將職業生涯規劃為技術行業的非開發人員（除了信息安全、數據科學/分析師、基礎設施工程師等以外的人員）的女性，你希望知道的事情有哪些，有價值的資源有哪些，或者對希望做出類似改變的人有哪些建議？

—— Tim Banks is a buttery biscuit (@elchefe) December 15，2020

這遵循了我第一篇文章中的建議：Tim 並不是簡單地詢問“非技術角色”；他提供了更重要的詳細描述。在 Twitter 這樣的媒體上，每一個字符都很重要，這些額外的字符會產生不同的效果。這些是技術角色。如果為了節約筆墨，而簡單的稱呼他們為“非技術人員”，會改變你的原意，產生不好的影響。

以下是需要技術知識的非工程類角色的示例。

技術作者 ​

技術作者的工作 是在兩方或多方之間傳遞事實信息。傳統上，技術作者提供有關如何使用技術產品的説明或文檔。最近，我看到術語“技術作者”指的是寫其他形式內容的人。科技公司希望一個人為他們的開發者讀者寫Blog文章，而這種技巧不同於文案或內容營銷。

需要的技術技能：

  • 寫作
  • 特定技術或產品的用户知識或經驗
  • 快速跟上新產品或新特性的速度的能力
  • 在各種環境中創作的技能

適合人羣：

  • 可以清楚地提供分步説明
  • 享受合作
  • 對活躍的聲音和音樂有熱情
  • 喜歡描述事物和解釋原理

產品經理 ​

產品經理 負責領導產品戰略。職責可能包括收集客户需求並確定其優先級，撰寫業務案例，以及培訓銷售人員。產品經理跨職能工作，利用創造性和技術技能的結合，成功地推出產品。產品經理需要深厚的產品專業知識。

所需技術技能：

  • 掌握產品知識，並且會配置或運行演示模型
  • 與產品相關的技術生態系統知識
  • 分析和研究技能

適合以下人羣：

  • 享受制定戰略和規劃下一步的工作
  • 在不同的人的需求中可以看到一條共同的線索
  • 能夠清楚地表達業務需求和要求
  • 喜歡描述原因

數據分析師 ​

數據分析師負責收集和解釋數據，以幫助推動業務決策，如是否進入新市場、瞄準哪些客户或在何處投資。這個角色需要知道如何使用所有可用的潛在數據來做出決策。我們常常希望把事情簡單化，而數據分析往往過於簡單化。獲取正確的信息並不像編寫查詢 select all limit 10 來獲取前 10 行那麼簡單。你需要知道要加入哪些表。你需要知道如何分類。你需要知道是否需要在運行查詢之前或之後以某種方式清理數據。

所需技術技能：

  • 瞭解 SQL、Python 和 R
  • 能夠看到和提取數據中的樣本
  • 瞭解事物如何端到端運行
  • 批判性思維
  • 機器學習

適合以下人羣：

  • 享受解決問題的樂趣
  • 渴望學習和提出問題

開發者關係 ​

開發者關係 是一門相對較新的技術學科。它包括 開發者代言人 developer advocate、開發者傳道者developer evangelist和開發者營銷developer marketing等角色。這些角色要求你與開發人員溝通，與他們建立關係，並幫助他們提高工作效率。你向公司倡導開發者的需求，並向開發者代表公司。開發者關係可以包括撰寫文章、創建教程、錄製播客、在會議上發言以及創建集成和演示。有人説你需要做過開發才能進入開發者關係。我沒有走那條路，我知道很多人沒有。

所需技術技能：

這些將高度依賴於公司和具體角色。你需要部分技能（不是全部）取決於你自己。

  • 瞭解與產品相關的技術概念
  • 寫作
  • 教程和播客的視頻和音頻編輯
  • 説話

適合以下人羣：

  • 有同情心，想要教導和授權他人
  • 可以為他人辯護
  • 你很有創意

無限的可能性 ​

這並不是一個完整的清單，並沒有列出技術領域中所有的非工程類角色，而是一些不喜歡每天編寫代碼的人可以嘗試的工作。如果你對科技職業感興趣，看看你的技能和什麼角色最適合。可能性是無窮的。為了幫助你完成旅程，在本系列的最後一篇文章中，我將與這些角色的人分享一些建議。
