Guake 終端：一個靈感來自於 FPS 遊戲的 Linux 終端 ​

使用 Guake 終端這個可自定義且強大的適合各種用户的工具快速訪問你的終端。

Guake 終端：GNOME 桌面中自上而下終端 ​

Guake 是一款為 GNOME 桌面量身定做的終端模擬器，採用下拉式設計。

它最初的靈感來自於一款 FPS 遊戲（Quake）中的終端。儘管它最初是作為一個快速和易於使用的終端而設計的，但它的功能遠不止於此。

Guake 終端提供了大量的功能，以及可定製的選項。在這裏，我將重點介紹終端的主要功能，以及如何將它安裝到你的任何 Linux 發行版上。

Guake 終端的特點 ​

  • 按下鍵盤快捷鍵（F12）以覆蓋方式在任何地方啓動終端
  • Guake 終端在後台運行，以便持久訪問
  • 能夠橫向和縱向分割標籤頁
  • 從可用的 shell 中（如果有的話）更改默認的 shell
  • 重新對齊
  • 從多種調色板中選擇改變終端的外觀
  • 能夠使用 GUI 方式將終端內容保存到文件中
  • 需要時切換全屏
  • 你可以輕鬆地保存標籤，或在需要時打開新的標籤
  • 恢復標籤的能力
  • 可選擇配置和學習新的鍵盤快捷鍵，以快速訪問終端和執行任務
  • 改變特定選項卡的顏色
  • 輕鬆重命名標籤，快速訪問你需要的內容
  • 快速打開功能，只需點擊一下，就可直接在終端中用你最喜歡的編輯器打開文件
  • 能夠在啓動或顯示 Guake 終端時添加自己的命令或腳本。
  • 支持多顯示器

只是出於樂趣，你可以做很多事情。但是，我也相信，高級用户可以利用這些功能使他們的終端體驗更輕鬆，更高效。

就我用它來測試一些東西和寫這篇文章的時候，説實話，我覺得我是在召喚終端。所以，我絕對覺得它很酷！

在 Linux 上安裝 Guake ​

在 Ubuntu、Fedora 和 Arch 的默認倉庫中都有 Guake 終端。

你可以按照它的官方説明來了解你可以使用的命令，如果你使用的是基於 Ubuntu 的發行版，只需輸入：

sudo apt install guake

請注意，使用這種方法可能無法獲得最新版本。所以，如果你想獲得最新的版本，你可以選擇使用 Linux Uprising 的 PPA 來獲得最新版本：

sudo add-apt-repository ppa:linuxuprising/guake
sudo apt update
sudo apt install guake

無論是哪種情況，你也可以使用 Pypi 或者參考官方文檔或從 GitHub 頁面獲取源碼。
