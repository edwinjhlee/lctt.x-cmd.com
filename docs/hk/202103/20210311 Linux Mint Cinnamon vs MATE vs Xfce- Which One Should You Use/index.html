Cinnamon vs MATE vs Xfce：你應該選擇那一個 Linux Mint 口味？ ​

Linux Mint 無疑是 最適合初學者的 Linux 發行版之一。尤其是對於剛剛邁向 Linux 世界的 Windows 用户來説，更是如此。

2006 年以來（也就是 Linux Mint 首次發佈的那一年），他們開發了一系列的提高用户的體驗的 工具。此外，Linux Mint 是基於 Ubuntu 的，所以你有一個可以尋求幫助的龐大的用户社區。

我不打算討論 Linux Mint 有多好。如果你已經下定決心 安裝Linux Mint，你可能會對它網站上的 下載部分 感到有些困惑。

它給了你三個選擇：Cinnamon、MATE 和 Xfce。不知道該如何選擇嗎？我將在本文中幫你解決這個問題。

如果你是個 Linux 的絕對新手，對上面的東西一無所知，我建議你瞭解一下 什麼是 Linux 桌面環境。如果你能再多花點時間，請閲讀這篇關於 什麼是 Linux，以及為什麼有這麼多看起來相似的 Linux 操作系統 的優秀解釋。

有了這些信息，你就可以瞭解各種 Linux Mint 版本之間的區別了。如果你不知道該選擇哪一個，通過這篇文章，我將幫助你做出一個有意識的選擇。

你應該選擇哪個 Linux Mint 版本？ ​

簡單來説，可供選擇的有以下幾種：

  • Cinnamon 桌面：具有現代感的傳統桌面。
  • MATE 桌面：類似 GNOME 2 時代的傳統外觀桌面。
  • Xfce 桌面：一個流行的輕量級桌面環境。

我們來逐一看看 Mint 的各個變種。

Linux Mint Cinnamon 版 ​

Cinnamon 桌面是由 Linux Mint 團隊開發的，顯然它是 Linux Mint 的主力版本。

早在近十年前，當 GNOME 桌面選擇了非常規的 GNOME 3 用户界面時，人們就開始了 Cinnamon 的開發，通過復刻 GNOME 2 的一些組件來保持桌面的傳統外觀。

很多 Linux 用户喜歡 Cinnamon，就是因為它有像 Windows 7 一樣的界面。

性能和相應能力 ​

Cinnamon 桌面的性能比過去的版本有所提高，但如果沒有固態硬盤，你會覺得有點遲鈍。上一次我使用 Cinnamon 桌面是在 4.4.8 版，開機後的內存消耗在 750MB 左右。現在的 4.8.6 版有了很大的改進，開機後減少了 100MB 內存消耗。

為了獲得最佳的用户體驗，應該考慮雙核 CPU，最低 4GB 內存。

優勢 ​
  • 從 Windows 無縫切換
  • 賞心悦目
  • 高度 可定製
劣勢 ​
  • 如果你的系統只有 2GB 內存，可能還是不夠理想

附加建議：如果你喜歡 Debian 而不是 Ubuntu，你可以選擇 Linux Mint Debian 版（LMDE）。LMDE 和帶有 Cinnamon 桌面的 Debian 主要區別在於 LMDE 向其倉庫提供最新的桌面環境。

Linux Mint Mate 版 ​

MATE 桌面環境 也有類似的故事，它的目的是維護和支持 GNOME 2 的代碼庫和應用程序。它的外觀和感覺與 GNOME 2 非常相似。

在我看來，到目前為止，MATE 桌面的最佳實現是 Ubuntu MATE。在 Linux Mint 中，你會得到一個定製版的 MATE 桌面，它符合 Cinnamon 美學，而不是傳統的 GNOME 2 設定。

性能和響應能力 ​

MATE 桌面以輕薄著稱，這一點毋庸置疑。與 Cinnamon 桌面相比，其 CPU 的使用率始終保持在較低的水平，換言之，在筆記本電腦上會有更好的電池續航時間。

雖然感覺沒有 Xfce 那麼敏捷（在我看來），但不至於影響用户體驗。內存消耗在 500MB 以下起步，這對於功能豐富的桌面環境來説是令人印象深刻的。

優勢 ​
  • 不影響 功能 的輕量級桌面
  • 足夠的 定製化 可能性
劣勢 ​
  • 傳統的外觀可能會給你一種過時的感覺

Linux Mint Xfce 版 ​

Xfce 項目始於 1996 年，受到了 UNIX 的 通用桌面環境（CDE） 的啓發。Xfce 是 “XForms Common Environment” 的縮寫，但由於它不再使用 XForms 工具箱，所以名字拼寫為 “Xfce”。

它的目標是快速、輕量級和易於使用。Xfce 是許多流行的 Linux 發行版的主要桌面，如 Manjaro 和 MX Linux。

Linux Mint 提供了一個精緻的 Xfce 桌面，但即使是黑暗主題也無法與 Cinnamon 桌面的美感相比。

性能和響應能力 ​

Xfce 是 Linux Mint 提供的最精簡的桌面環境。通過點擊開始菜單、設置控制面板或探索底部面板，你會發現這是一個簡單而又靈活的桌面環境。

儘管我覺得極簡主義是一個積極的屬性，但 Xfce 並不是一個養眼的產品，反而留下的是比較傳統的味道。但對於一些用户來説，經典的桌面環境才是他們的首選。

在第一次開機時，內存的使用情況與 MATE 桌面類似，但並不盡如人意。如果你的電腦沒有配備 SSD，Xfce 桌面環境可以讓你的系統復活。

優勢 ​
  • 使用簡單
  • 非常輕巧，適合老式硬件
  • 堅如磐石的穩定
劣勢 ​
  • 過時的外觀
  • 與 Cinnamon 相比，可能沒有那麼多的定製化服務

總結 ​

由於這三款桌面環境都是基於 GTK 工具包的，所以選擇哪個純屬個人喜好。它們都很節約系統資源，對於 4GB 內存的適度系統來説，表現良好。Xfce 和 MATE 可以更低一些，支持低至 2GB 內存的系統。

Linux Mint 並不是唯一提供多種選擇的發行版。Manjaro、Fedora和 Ubuntu 等發行版也有各種口味 可供選擇。

如果你還是無法下定決心，我建議先選擇默認的 Cinnamon 版，並嘗試 在虛擬機中使用 Linux Mint。看看你是否喜歡這個外觀和感覺。如果不喜歡，你可以用同樣的方式測試其他變體。如果你決定了這個版本，你可以繼續 在你的主系統上安裝它。
