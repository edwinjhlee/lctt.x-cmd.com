Qalculate! ：全宇宙最好的計算器軟件 ​

十多年來，我一直都是 GNU-Linux 以及 Debian 的用户。隨着我越來越頻繁的使用桌面環境，我發現對我來説除了少數基於 web 的服務以外我的大多數需求都可以通過 Debian 軟件庫裏自帶的桌面應用解決。

我的需求之一就是進行單位換算。儘管有很多很多在線服務可以做這件事，但是我還是需要一個可以在桌面環境使用的應用。這主要是因為隱私問題以及我不想一而再再而三的尋找在線服務做事。為此我搜尋良久，直到找到 Qalculate!。

Qalculate! 最強多功能計算器應用 ​

這是 aptitude 上關於 Qalculate! 的介紹，我沒法總結的比他們更好了：

強大易用的桌面計算器 - GTK+ 版

Qalculate! 是一款外表簡單易用，內核強大且功能豐富的應用。其功能包含自定義函數、單位、高計算精度、作圖以及可以輸入一行表達式（有容錯措施）的圖形界面（也可以選擇使用傳統按鈕）。

這款應用也發行過 KDE 的界面，但是至少在 Debian Testing 軟件庫裏，只出現了 GTK+ 版的界面，你也可以在 GitHub 上的這個倉庫裏面看到。

不必多説，Qalculate! 在 Debian 的軟件源內處於可用狀態，因此可以使用 apt 命令或者是基於 Debian 的發行版比如 Ubuntu 提供的軟件中心輕鬆安裝。在 Windows 或者 macOS 上也可以使用這款軟件。

Qalculate! 特性一覽 ​

列出全部的功能清單會有點長，請允許我只列出一部分功能並使用截圖來展示極少數 Qalculate! 提供的功能。這麼做是為了讓你熟悉 Qalculate! 的基本功能，並在之後可以自由探索 Qalculate! 到底還能幹什麼。

使用 Qalculate! ​

Qalculate! 的使用不是很難。你甚至可以在裏面寫簡單的英文。但是我還是推薦先閲讀手冊以便充分發揮 Qalculate! 的潛能。

qalc 是 Qalculate! 的命令列版 ​

你也可以使用 Qalculate! 的命令列版 qalc：

$ qalc 62499836 byte to gibibyte
62499836 * byte = approx. 0.058207508 gibibyte

$ qalc 40 degree celsius to fahrenheit
(40 * degree) * celsius = 104 deg*oF

Qalculate! 的命令列界面可以讓不喜歡 GUI 而是喜歡命令列界面（CLI）或者是使用無頭結點（沒有 GUI）的人可以使用 Qalculate!。這些人大多是在服務器環境下工作。

如果你想要在腳本里使用這一軟件的話，我想 libqalculate 是最好的解決方案。看一看 qalc 以及 qalculate-gtk 是如何依賴於它工作的就足以知曉如何使用了。

再提一嘴，你還可以瞭解下如何根據一系列數據繪圖，其他應用方式就留給你自己發掘了。不要忘記查看 /usr/share/doc/qalculate/index.html 以獲取 Qalculate! 的全部功能。

註釋：注意 Debian 更喜歡 gnuplot，因為其輸出的圖片很精美。

附加技巧：你可以通過在 Debian 下通過命令列感謝開發者 ​

如果你使用 Debian 而且喜歡哪個包的話，你可以使用如下命令感謝 Debian 下這個軟件包的開發者或者是維護者：

reportbug --kudos $PACKAGENAME

因為我喜歡 Qalculate!，我想要對 Debian 的開發者以及維護者 Vincent Legout 的卓越工作表示感謝：

reportbug --kudos qalculate

建議各位閲讀我寫的關於如何使用報錯工具在 Debian 中上報 BUG的詳細指南。

我覺得這個軟件少了些物理常數，但我想不起來缺了哪些。我覺得它沒有太多有關流體動力學的東西，再就是少了點部分化合物的光吸收係數，但這些東西只對我這個化學家來説比較重要，我不知道這些是不是對別人來説也是特別必要的。自由能可能也是。

最後，我分享的關於 Qalculate! 的介紹十分簡陋，其實際功能與你的需要以及你的想像力有關係。希望你能喜歡 Qalculate!
