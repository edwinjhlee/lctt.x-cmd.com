fdisk：Linux 下管理磁盤分區的利器 ​

一塊硬盤可以被劃分成一個或多個邏輯磁盤，我們將其稱作分區。我們對硬盤進行的劃分信息被儲存於建立在扇區 0 的分區表（MBR 或 GPT）中。

Linux 需要至少一個分區來當作根文件系統，所以我們不能在沒有分區的情況下安裝 Linux 系統。當我們創建一個分區時，我們必須將它格式化為一個適合的文件系統，否則我們就沒辦法往裏面儲存文件了。

要在 Linux 中完成分區的相關工作，我們需要一些工具。Linux 下有很多可用的相關工具，我們曾介紹過 Parted 命令。不過，今天我們的主角是 fdisk。

人人都喜歡用 fdisk，它是 Linux 下管理磁盤分區的最佳利器之一。它可以操作最大 2TB 的分區。大量 Linux 管理員都喜歡使用這個工具，因為當下 LVM 和 SAN 的原因，並沒有多少人會用到 2TB 以上的分區。並且這個工具被世界上許多的基礎設施所使用。如果你還是想創建比 2TB 更大的分區，請使用 parted 命令 或 cfdisk 命令。

對磁盤進行分區和創建文件系統是 Linux 管理員的日常。如果你在許多不同的環境中工作，你一定每天都會重複幾次這項操作。

Linux 內核是如何理解硬盤的？ ​

作為人類，我們可以很輕鬆地理解一些事情；但是電腦就不是這樣了，它們需要合適的命名才能理解這些。

在 Linux 中，外圍設備都位於 /dev 掛載點，內核通過以下的方式理解硬盤：

  • /dev/hdX[a-z]: IDE 硬盤被命名為 hdX
  • /dev/sdX[a-z]: SCSI 硬盤被命名為 sdX
  • /dev/xdX[a-z]: XT 硬盤被命名為 xdX
  • /dev/vdX[a-z]: 虛擬硬盤被命名為 vdX
  • /dev/fdN: 軟盤被命名為 fdN
  • /dev/scdN or /dev/srN: CD-ROM 被命名為 /dev/scdN 或 /dev/srN

什麼是 fdisk 命令？ ​

fdisk 的意思是 固定磁盤Fixed Disk 或 格式化磁盤Format Disk，它是命令列下允許用户對分區進行查看、創建、調整大小、刪除、移動和複製的工具。它支持 MBR、Sun、SGI、BSD 分區表，但是它不支持 GUID 分區表（GPT）。它不是為操作大分區設計的。

fdisk 允許我們在每塊硬盤上創建最多四個主分區。它們中的其中一個可以作為擴展分區，並下設多個邏輯分區。1-4 扇區作為主分區被保留，邏輯分區從扇區 5 開始。

如何在 Linux 下安裝 fdisk？ ​

fdisk 作為核心組件內置於 Linux 中，所以你不必手動安裝它。

如何使用 fdisk 創建一個磁盤分區？ ​

如果你希望新建磁盤分區，請參考下面的步驟。比如我希望在 /dev/sdc 中新建四個分區（三個主分區和一個擴展分區），只需要執行下文的命令。

首先，請在操作 “First sector” 的時候先按下回車，然後在 “Last sector” 中輸入你希望創建分區的大小（可以在數字後面加 KB、MB、G 和 TB）。例如，你希望為這個分區擴容 1GB，就應該在 “Last sector” 中輸入 +1G。當你創建三個分區之後，fdisk 默認會將分區類型設為擴展分區，如果你希望創建第四個主分區，請輸入 p 來替代它的默認值 e。

如何在 Linux 下格式化分區或建立文件系統？ ​

在計算時，文件系統控制了數據的儲存方式，並通過 索引節點Inode Tables 來檢索數據。如果沒有文件系統，操作系統是無法找到信息儲存的位置的。

在此，我準備在 /dev/sdc1 上創建分區。有三種方式創建文件系統：

shell
$ sudo mkfs.ext4 /dev/sdc1
或
$ sudo mkfs -t ext4 /dev/sdc1
或
$ sudo mke2fs /dev/sdc1

mke2fs 1.43.5 (04-Aug-2017)
Creating filesystem with 262144 4k blocks and 65536 inodes
Filesystem UUID: c0a99b51-2b61-4f6a-b960-eb60915faab0
Superblock backups stored on blocks: 
	32768, 98304, 163840, 229376

Allocating group tables: done                            
Writing inode tables: done                            
Creating journal (8192 blocks): done
Writing superblocks and filesystem accounting information: done

當你在分區上建立文件系統時，以下重要信息會同時被創建：

  • Filesystem UUID: UUID 代表了通用且獨一無二的識別符，UUID 在 Linux 中通常用來識別設備。它 128 位長的數字代表了 32 個十六進制數。
  • Superblock: 超級塊儲存了文件系統的元數據。如果某個文件系統的超級塊被破壞，我們就無法掛載它了（也就是説無法訪問其中的文件了）。
  • Inode: Inode 是類 Unix 系統中文件系統的數據結構，它儲存了所有除名稱以外的文件信息和數據。
  • Journal: 日誌式文件系統包含了用來修復電腦意外關機產生下錯誤信息的日誌。

如何在 Linux 中掛載分區？ ​

在你創建完分區和文件系統之後，我們需要掛載它們以便使用。我們需要創建一個掛載點來掛載分區，使用 mkdir 來創建一個掛載點。

shell
$ sudo mkdir -p /mnt/2g-new

如果你希望進行臨時掛載，請使用下面的命令。在計算機重啓之後，你會丟失這個掛載點。

shell
$ sudo mount /dev/sdc1 /mnt/2g-new

如果你希望永久掛載某個分區，請將分區詳情加入 fstab 文件。我們既可以輸入設備名稱，也可以輸入 UUID。

使用設備名稱來進行永久掛載：

# vi /etc/fstab

/dev/sdc1 /mnt/2g-new ext4 defaults 0 0

使用 UUID 來進行永久掛載（請使用 blkid 來獲取 UUID）：

$ sudo blkid
/dev/sdc1: UUID="d17e3c31-e2c9-4f11-809c-94a549bc43b7" TYPE="ext2" PARTUUID="8cc8f9e5-01"
/dev/sda1: UUID="d92fa769-e00f-4fd7-b6ed-ecf7224af7fa" TYPE="ext4" PARTUUID="eab59449-01"

# vi /etc/fstab
