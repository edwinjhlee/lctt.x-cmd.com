14 個依然很棒的 Linux ASCII 遊戲 ​

基於文本的（或者我應該説是基於終端的）遊戲在十年前非常流行 —— 當時還沒有像戰神God Of War、荒野大鏢客：救贖 2Red Dead Redemption 2或蜘蛛俠Spiderman這樣的視覺遊戲大作。

當然，Linux 平台有很多好遊戲 —— 雖然並不總是“最新和最好”。但是，有一些 ASCII 遊戲，卻是你永遠不會玩膩的。

你或許不相信，有一些 ASCII 遊戲被證明是非常容易上癮的（所以，我可能需要一段時間才能繼續寫下一篇文章，或者我可能會被解僱？ —— 幫幫我！）

哈哈，開個玩笑。讓我們來看看最好的 ASCII 遊戲吧。

注意：安裝 ASCII 遊戲可能要花費不少時間（有些可能會要求你安裝其他依賴項或根本不起作用）。你甚至可能會遇到一些需要你從源代碼構建的 ASCII 遊戲。因此，我們只篩選出那些易於安裝和運行的產品 —— 不用費勁。

在運行和安裝 ASCII 遊戲之前需要做的事情 ​

如果你沒有安裝的話，某些 ASCII 遊戲可能需要你安裝 Simple DirectMedia Layer。因此，以防萬一，你應該先嚐試安裝它，然後再嘗試運行本文中提到的任何遊戲。

要安裝它，你需要鍵入如下命令：

sudo apt install libsdl2-2.0
sudo apt install libsdl2_mixer-2.0

Linux 上最好的 ASCII 遊戲 ​

如下列出的遊戲排名不分先後。

1、戰爭詛咒 ​

戰爭詛咒Curse of War是一個有趣的策略遊戲。一開始你可能會發現它有點令人困惑，但一旦你掌握了，就會喜歡上它。在啓動遊戲之前，我建議你在其 主頁 上查看該遊戲規則。

你將建設基礎設施、保護資源並指揮你的軍隊進行戰鬥。你所要做的就是把你的旗幟放在一個合適的位置，讓你的軍隊來完成其餘的任務。不僅僅是攻擊敵人，你還需要管理和保護資源以幫助贏得戰鬥。

如果你之前從未玩過任何 ASCII 遊戲，請耐心花一些時間來學習它、體驗它的全部潛力。

如何安裝？ ​

你可以在官方軟件庫裏找到它。鍵入如下命令來安裝它：

sudo apt install curseofwar

2、ASCII 領域 ​

討厭策略遊戲？不用擔心，ASCII 領域ASCII Sector是一款具有空間環境的遊戲，可讓你進行大量探索。

此外，不僅僅侷限於探索，你還想要採取一些行動嗎？也是可以的。當然，雖然戰鬥體驗不是最好的，但它也很有趣。當你看到各種基地、任務和探索時，會讓你更加興奮。你會在這個小小的遊戲中遇到一個練級系統，你必須賺取足夠的錢或進行交易才能升級你的宇宙飛船。

而這個遊戲最好的地方是你可以創建自己的任務，也可以玩其他人的任務。

如何安裝？ ​

你需要先從其 官方網站 下載並解壓縮歸檔包。完成後，打開終端並輸入這些命令（將 “Downloads” 文件夾替換為你解壓縮文件夾所在的位置，如果解壓縮文件夾位於你的主目錄中，則忽略它）：

cd Downloads
cd asciisec
chmod +x asciisec
./asciisec

3、DoomRL ​

你肯定知道經典遊戲“毀滅戰士DOOM”，所以，如果你想把它像 Rogue 類遊戲一樣略微體驗一下，DoomRL 就是適合你的遊戲。它是一個基於 ASCII 的遊戲，這或許讓你想不到。

這是一個非常小的遊戲，但是可以玩很久。

如何安裝？ ​

與你對 “ASCII 領域”所做的類似，你需要從其 下載頁面 下載官方歸檔文件，然後將其解壓縮到一個文件夾。

解壓縮後，輸入以下命令：

cd Downloads // navigating to the location where the unpacked folder exists
cd doomrl-linux-x64-0997
chmod +x doomrl
./doomrl

4、金字塔建造者 ​

金字塔建造者Pyramid Builder 是一款創新的 ASCII 遊戲，你可以通過幫助建造金字塔來提升你的文明。

你需要指導工人耕種、卸載貨物、並移動巨大的石頭，以成功建造金字塔。

這確實是一個值得下載的 ASCII 遊戲。

如何安裝？ ​

只需前往其官方網站並下載包以解壓縮。提取後，導航到該文件夾並運行可執行文件。

cd Downloads
cd pyramid_builder_linux
chmod +x pyramid_builder_linux.x86_64
./pyramid_builder_linux.x86_64

5、DiabloRL ​

如果你是一位狂熱的遊戲玩家，你一定聽説過暴雪的暗黑破壞神Diablo 1 代，毫無疑問這是一個精彩的遊戲。

現在你有機會玩一個該遊戲的獨特演繹版本 —— 一個 ASCII 遊戲。DiabloRL 是一款非常棒的基於回合制的 Rogue 類的遊戲。你可以從各種職業（戰士、巫師或盜賊）中進行選擇。每個職業都具有一套不同的屬性，可以帶來不同遊戲體驗。

當然，個人偏好會有所不同，但它是一個不錯的暗黑破壞神“降級版”。你覺得怎麼樣？

6、Ninvaders ​

Ninvaders 是最好的 ASCII 遊戲之一，因為它是如此簡單，且可以消磨時間的街機遊戲。

你必須防禦入侵者，需要在它們到達之前擊敗它們。這聽起來很簡單，但它極具挑戰性。

如何安裝？ ​

與“戰爭詛咒”類似，你可以在官方軟件庫中找到它。所以，只需輸入此命令即可安裝它：

sudo apt install ninvaders

7、帝國 ​

帝國Empire這是一款即時戰略遊戲，你需要互聯網連接。我個人不是實時戰略遊戲的粉絲，但如果你是這類遊戲的粉絲，你可以看看他們的 指南 來玩這個遊戲，因為學習起來非常具有挑戰性。

遊戲區域包含城市、土地和水。你需要用軍隊、船隻、飛機和其他資源擴展你的城市。通過快速擴張，你可以通過在對方動作之前摧毀它們來捕獲其他城市。

如何安裝？ ​

安裝很簡單，只需輸入以下命令：

sudo apt install empire

8、Nudoku ​

喜歡數獨遊戲？好吧，你也有個 Nudoku 遊戲，這是它的克隆。這是當你想放鬆時的一個完美的消磨時間的 ASCII 遊戲。

它為你提供三個難度級別：簡單、正常和困難。如果你想要挑戰電腦，其難度會非常難！如果你只是想放鬆一下，那麼就選擇簡單難度吧。

如何安裝？ ​

安裝它很容易，只需在終端輸入以下命令：

sudo apt install nudoku

9、Nethack ​

最好的地下城式 ASCII 遊戲之一。如果你已經知道一些 Linux 的 ASCII 遊戲，我相信這是你的最愛之一。

它具有許多不同的層（約 45 個），並且包含一堆武器、卷軸、藥水、盔甲、戒指和寶石。你也可以選擇“永久死亡”模式來玩試試。

在這裏可不僅僅是殺戮，你還有很多需要探索的地方。

如何安裝？ ​

只需按照以下命令安裝它：

sudo apt install nethack

10、ASCII 滑雪 ​

ASCII 滑雪ASCII Jump 是一款簡單易玩的遊戲，你必須沿着各種軌道滑動，同時跳躍、改變位置，並儘可能長時間地移動以達到最大距離。

即使看起來很簡單，但是看看這個 ASCII 遊戲視覺上的表現也是很神奇的。你可以從訓練模式開始，然後進入世界盃比賽。你還可以選擇你的競爭對手以及你想要開始遊戲的山丘。

如何安裝？ ​

只需按照以下命令安裝它：

sudo apt install asciijump

11、Bastet ​

不要被這個名字誤導，它實際上是俄羅斯方塊遊戲的一個有趣的克隆。

你不要覺得它只是另一個普通的俄羅斯方塊遊戲，它會為你丟下最糟糕的磚塊。祝你玩得開心！

如何安裝？ ​

打開終端並鍵入如下命令：

sudo apt install bastet

12、Bombardier ​

Bombardier 是另一個簡單的 ASCII 遊戲，它會讓你迷上它。

在這裏，你有一架直升機（或許你想稱之為飛機），每一圈它都會降低，你需要投擲炸彈才能摧毀你下面的街區/建築物。當你摧毀一個街區時，遊戲還會在它顯示的消息裏面添加一些幽默。很好玩。

如何安裝？ ​

Bombardier 可以在官方軟件庫中找到，所以只需在終端中鍵入以下內容即可安裝它：

sudo apt install bombardier

13、Angband ​

一個很酷的地下城探索遊戲，界面整潔。在探索該遊戲時，你可以在一個屏幕上看到所有重要信息。

它包含不同種類的種族可供選擇角色。你可以是精靈、霍比特人、矮人或其他什麼，有十幾種可供選擇。請記住，你需要在最後擊敗黑暗之王，所以儘可能升級你的武器並做好準備。

如何安裝？ ​

直接鍵入如下命令：

sudo apt install angband

14、GNU 國際象棋 ​

為什麼不下盤棋呢？這是我最喜歡的策略遊戲了！

但是，除非你知道如何使用代表的符號來描述下一步行動，否則 GNU 國際象棋可能很難玩。當然，作為一個 ASCII 遊戲，它不太好交互，所以它會要求你記錄你的移動並顯示輸出（當它等待計算機思考它的下一步行動時）。

如何安裝？ ​

如果你瞭解國際象棋的代表符號，請輸入以下命令從終端安裝它：

sudo apt install gnuchess

一些榮譽獎 ​

正如我之前提到的，我們試圖向你推薦最好的（也是最容易在 Linux 機器上安裝的那些） ASCII 遊戲。

然而，有一些標誌性的 ASCII 遊戲值得關注，它們需要更多的安裝工作（你可以獲得源代碼，但需要構建它/安裝它）。

其中一些遊戲是：

  • Cataclysm: Dark Days Ahead
  • Brogue
  • Dwarf Fortress

你可以按照我們的 從源代碼安裝軟件的完全指南 來進行。
