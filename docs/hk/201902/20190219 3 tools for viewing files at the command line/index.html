在命令列查看文件的 3 個工具 ​

看一下 less、Antiword 和 odt2xt 這三個實用程序，它們都可以在終端中查看文件。

我常説，你不需要使用命令列也可以高效使用 Linux —— 我知道許多 Linux 用户從不打開終端窗口，並且也用的挺好。然而，即使我不認為自己是一名技術人員，我也會在命令列上花費大約 20% 的計算時間，包括操作文件、處理文本和使用實用程序。

我經常在終端窗口中做的一件事是查看文件，無論是文本還是需要用到文字處理器的文件。有時使用命令列實用程序比啓動文本編輯器或文字處理器更容易。

下面是我在命令列中用來查看文件的三個實用程序。

less ​

less 的美妙之處在於它易於使用，它將你正在查看的文件分解為塊（或頁面），這使得它們更易於閲讀。你可以使用它在命令列查看文本文件，例如 README、HTML 文件、LaTeX 文件或其他任何純文本文件。我在上一篇文章中介紹了 less。

要使用 less，只需輸入：

less file_name

通過按鍵盤上的空格鍵或 PgDn 鍵向下滾動文件，按 PgUp 鍵向上移動文件。要停止查看文件，按鍵盤上的 Q 鍵。

Antiword ​

Antiword 是一個很好地實用小程序，你可以使用它將 Word 文檔轉換為純文本。只要你想，還可以將它們轉換為 PostScript 或 PDF。在本文中，讓我們繼續使用文本轉換。

Antiword 可以讀取和轉換 Word 2.0 到 2003 版本創建的文件（LCTT 譯註：此處疑為 Word 2000，因為 Word 2.0 for DOS 發佈於 1984 年，而 WinWord 2.0 發佈於 1991 年，都似乎太老了）。它不能讀取 DOCX 文件 —— 如果你嘗試這樣做，Antiword 會顯示一條錯誤消息，表明你嘗試讀取的是一個 ZIP 文件。這在技術上説是正確的，但仍然令人沮喪。

要使用 Antiword 查看 Word 文檔，輸入以下命令：

antiword file_name.doc

Antiword 將文檔轉換為文本並顯示在終端窗口中。不幸的是，它不能在終端中將文檔分解成頁面。不過，你可以將 Antiword 的輸出重定向到 less 或 more 之類的實用程序，一遍對其進行分頁。通過輸入以下命令來執行此操作：

antiword file_name.doc | less

如果你是命令列的新手，那麼我告訴你 | 稱為管道。這就是重定向。

odt2txt ​

作為一個優秀的開源公民，你會希望儘可能多地使用開放格式。對於你的文字處理需求，你可能需要處理 ODT 文件（由諸如 LibreOffice Writer 和 AbiWord 等文字處理器使用）而不是 Word 文件。即使沒有，也可能會遇到 ODT 文件。而且，即使你的計算機上沒有安裝 Writer 或 AbiWord，也很容易在命令列中查看它們。

怎樣做呢？用一個名叫 odt2txt 的實用小程序。正如你猜到的那樣，odt2txt 將 ODT 文件轉換為純文本。要使用它，運行以下命令：

odt2txt file_name.odt

與 Antiword 一樣，odt2txt 將文檔轉換為文本並在終端窗口中顯示。和 Antiword 一樣，它不會對文檔進行分頁。但是，你也可以使用以下命令將 odt2txt 的輸出管道傳輸到 less 或 more 這樣的實用程序中：

odt2txt file_name.odt | more

你有一個最喜歡的在命令列中查看文件的實用程序嗎？歡迎留下評論與社區分享。
