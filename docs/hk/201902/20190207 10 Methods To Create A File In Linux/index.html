在 Linux 上創建文件的 10 個方法 ​

我們都知道，在 Linux 上，包括設備在內的一切都是文件。Linux 管理員每天應該會多次執行文件創建活動（可能是 20 次，50 次，甚至是更多，這依賴於他們的環境）。如果你想 在Linux上創建一個特定大小的文件，查看前面的這個鏈接。

高效創建一個文件是非常重要的能力。為什麼我説高效？如果你瞭解一些高效進行你當前活動的方式，你就可以事半功倍。這將會節省你很多的時間。你可以把這些有用的時間用到到其他重要的事情上。

我下面將會介紹多個在 Linux 上創建文件的方法。我建議你選擇幾個簡單高效的來輔助你的工作。你不必安裝下列的任何一個命令，因為它們已經作為 Linux 核心工具的一部分安裝到你的系統上了。

創建文件可以通過以下六個方式來完成。

  • >：標準重定向符允許我們創建一個 0KB 的空文件。
  • touch：如果文件不存在的話，touch 命令將會創建一個 0KB 的空文件。
  • echo：通過一個參數顯示文本的某行。
  • printf：用於顯示在終端給定的文本。
  • cat：它串聯並打印文件到標準輸出。
  • vi/vim：Vim 是一個向上兼容 Vi 的文本編輯器。它常用於編輯各種類型的純文本。
  • nano：是一個簡小且用户友好的編輯器。它複製了 pico 的外觀和優點，但它是自由軟件。
  • head：用於打印一個文件開頭的一部分。
  • tail：用於打印一個文件的最後一部分。
  • truncate：用於縮小或者擴展文件的尺寸到指定大小。

在 Linux 上使用重定向符（>）創建一個文件 ​

標準重定向符允許我們創建一個 0KB 的空文件。它通常用於重定向一個命令的輸出到一個新文件中。在沒有命令的情況下使用重定向符號時，它會創建一個文件。

但是它不允許你在創建文件時向其中輸入任何文本。然而它對於不是很勤勞的管理員是非常簡單有用的。只需要輸入重定向符後面跟着你想要的文件名。

$ > daygeek.txt

使用 ls 命令查看剛剛創建的文件。

$ ls -lh daygeek.txt
-rw-rw-r-- 1 daygeek daygeek 0 Feb 4 02:00 daygeek.txt

在 Linux 上使用 touch 命令創建一個文件 ​

touch 命令常用於將每個文件的訪問和修改時間更新為當前時間。

如果指定的文件名不存在，將會創建一個新的文件。touch 不允許我們在創建文件的同時向其中輸入一些文本。它默認創建一個 0KB 的空文件。

$ touch daygeek1.txt

使用 ls 命令查看剛剛創建的文件。

$ ls -lh daygeek1.txt
-rw-rw-r-- 1 daygeek daygeek 0 Feb 4 02:02 daygeek1.txt

在 Linux 上使用 echo 命令創建一個文件 ​

echo 內置於大多數的操作系統中。它常用於腳本、批處理文件，以及作為插入文本的單個命令的一部分。

它允許你在創建一個文件時就向其中輸入一些文本。當然也允許你在之後向其中輸入一些文本。

$ echo "2daygeek.com is a best Linux blog to learn Linux" > daygeek2.txt

使用 ls 命令查看剛剛創建的文件。

$ ls -lh daygeek2.txt
-rw-rw-r-- 1 daygeek daygeek 49 Feb 4 02:04 daygeek2.txt

可以使用 cat 命令查看文件的內容。

$ cat daygeek2.txt
2daygeek.com is a best Linux blog to learn Linux

你可以使用兩個重定向符 (>>) 添加其他內容到同一個文件。

$ echo "It's FIVE years old blog" >> daygeek2.txt

你可以使用 cat 命令查看添加的內容。

$ cat daygeek2.txt
2daygeek.com is a best Linux blog to learn Linux
It's FIVE years old blog

在 Linux 上使用 printf 命令創建一個新的文件 ​

printf 命令也可以以類似 echo 的方式執行。

printf 命令常用來顯示在終端窗口給出的字符串。printf 可以有格式説明符、轉義序列或普通字符。

$ printf "2daygeek.com is a best Linux blog to learn Linux\n" > daygeek3.txt

使用 ls 命令查看剛剛創建的文件。

$ ls -lh daygeek3.txt
-rw-rw-r-- 1 daygeek daygeek 48 Feb 4 02:12 daygeek3.txt

使用 cat 命令查看文件的內容。

$ cat daygeek3.txt
2daygeek.com is a best Linux blog to learn Linux

你可以使用兩個重定向符 (>>) 添加其他的內容到同一個文件中去。

$ printf "It's FIVE years old blog\n" >> daygeek3.txt

你可以使用 cat 命令查看這個文件中添加的內容。

$ cat daygeek3.txt
2daygeek.com is a best Linux blog to learn Linux
It's FIVE years old blog

在 Linux 中使用 cat 創建一個文件 ​

cat 表示串聯concatenate。在 Linux 經常用於讀取一個文件中的數據。

cat 是在類 Unix 系統中最常使用的命令之一。它提供了三個與文本文件相關的功能：顯示一個文件的內容、組合多個文件的內容到一個輸出以及創建一個新的文件。（LCTT 譯註：如果 cat 命令後如果不帶任何文件的話，下面的命令在回車後也不會立刻結束，回車後的操作可以按 Ctrl-C 或 Ctrl-D 來結束。）

$ cat > daygeek4.txt
2daygeek.com is a best Linux blog to learn Linux
It's FIVE years old blog

使用 ls 命令查看創建的文件。

$ ls -lh daygeek4.txt
-rw-rw-r-- 1 daygeek daygeek 74 Feb 4 02:18 daygeek4.txt

使用 cat 命令查看文件的內容。

$ cat daygeek4.txt
2daygeek.com is a best Linux blog to learn Linux
It's FIVE years old blog

如果你想向同一個文件中添加其他內容，使用兩個連接的重定向符（>>）。

$ cat >> daygeek4.txt
This website is maintained by Magesh M, It's licensed under CC BY-NC 4.0.

你可以使用 cat 命令查看添加的內容。

$ cat daygeek4.txt
2daygeek.com is a best Linux blog to learn Linux
It's FIVE years old blog
This website is maintained by Magesh M, It's licensed under CC BY-NC 4.0.

在 Linux 上使用 vi/vim 命令創建一個文件 ​

vim 是一個向上兼容 vi 的文本編輯器。它通常用來編輯所有種類的純文本。在編輯程序時特別有用。

vim 中有很多功能可以用於編輯單個文件。

$ vi daygeek5.txt

2daygeek.com is a best Linux blog to learn Linux
It's FIVE years old blog

使用 ls 查看剛才創建的文件。

$ ls -lh daygeek5.txt
-rw-rw-r-- 1 daygeek daygeek 75 Feb 4 02:23 daygeek5.txt

使用 cat 命令查看文件的內容。

$ cat daygeek5.txt
2daygeek.com is a best Linux blog to learn Linux
It's FIVE years old blog

在 Linux 上使用 nano 命令創建一個文件 ​

nano 是一個編輯器，它是一個自由版本的 pico 克隆。nano 是一個小且用户友好的編輯器。它複製了 pico 的外觀及優點，並且是一個自由軟件，它添加了 pico 缺乏的一系列特性，像是打開多個文件、逐行滾動、撤銷/重做、語法高亮、行號等等。

$ nano daygeek6.txt

2daygeek.com is a best Linux blog to learn Linux
It's FIVE years old blog
This website is maintained by Magesh M, It's licensed under CC BY-NC 4.0.

使用 ls 命令查看創建的文件。

$ ls -lh daygeek6.txt
-rw-rw-r-- 1 daygeek daygeek 148 Feb 4 02:26 daygeek6.txt

使用 cat 命令來查看一個文件的內容。

$ cat daygeek6.txt
2daygeek.com is a best Linux blog to learn Linux
It's FIVE years old blog
This website is maintained by Magesh M, It's licensed under CC BY-NC 4.0.

在 Linux 上使用 head 命令創建一個文件 ​

head 命令通常用於輸出一個文件開頭的一部分。它默認會打印一個文件的開頭 10 行到標準輸出。如果有多個文件，則每個文件前都會有一個標題，用來表示文件名。

$ head -c 0K /dev/zero > daygeek7.txt

使用 ls 命令查看創建的文件。

$ ls -lh daygeek7.txt
-rw-rw-r-- 1 daygeek daygeek 0 Feb 4 02:30 daygeek7.txt

在 Linux 上使用 tail 創建一個文件 ​

tail 命令通常用來輸出一個文件最後的一部分。它默認會打印每個文件的最後 10 行到標準輸出。如果有多個文件，則每個文件前都會有一個標題，用來表示文件名。

$ tail -c 0K /dev/zero > daygeek8.txt

使用 ls 命令查看創建的文件。

$ ls -lh daygeek8.txt
-rw-rw-r-- 1 daygeek daygeek 0 Feb 4 02:31 daygeek8.txt

在 Linux 上使用 truncate 命令創建一個文件 ​

truncate 命令通常用作將一個文件的尺寸縮小或者擴展為某個指定的尺寸。

$ truncate -s 0K daygeek9.txt

使用 ls 命令檢查創建的文件。

$ ls -lh daygeek9.txt
-rw-rw-r-- 1 daygeek daygeek 0 Feb 4 02:37 daygeek9.txt
