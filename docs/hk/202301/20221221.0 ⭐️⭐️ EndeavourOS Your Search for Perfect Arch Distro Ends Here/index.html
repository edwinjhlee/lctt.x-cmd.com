EndeavourOS：你對完美的 Arch 發行版的搜尋到此為止 ​

我們整體點評了最近發佈的 EndeavourOS “Cassini”。

每年，個人和小型團隊們推出了數以百計的 Linux 發行版。它們大多是 Debian、Ubuntu、Fedora 或 Arch Linux 的直接衍生品，再加上一些定製的東西。這也難怪每年都有因為缺乏貢獻、願景和堅持而死亡的發行版。

三年前，作為已停止的 Antergos 項目的延續，一個由貢獻者們組成的小團隊發起了 EndeavourOS 項目。從那時起，由於其安裝簡單，用户體驗和功能，它已經變得很受歡迎。

點評 EndeavourOS ​

如果你曾經試過它，你就會很明顯地發現，他們花了很多心血來開發這個發行版。這個發行版的口號是成為一個面向大眾的 “通用” Arch Linux 發行版，摒棄了新用户對 Arch Linux 安裝的恐懼，以及使用 Arch 時的優越感。

如果你曾經嘗試過 EndeavourOS，你一定會 “感覺” 到作為一個 Arch 發行版，對最終用户來説，在桌面上執行的事情是多麼的 “容易”。

安裝和可供選擇的桌面 ​

通過 “獨有的” Calamares 安裝程序，它的安裝變得超級簡單。除此之外，EndeavourOS 團隊還特別注意在安裝步驟中為你提供了大部分的選項。例如，無需用户干預的臨場介質直接啓動。它會啓動歡迎屏幕。歡迎屏幕要做的事就是提供讓你在系統中安裝它所有必要選項。

默認情況下，ISO 提供了一個輕量級的 Xfce 桌面。然而，EndeavourOS 也為你提供了各種桌面環境和窗口管理器（見下文）。而且它們都經過測試，可以正常工作。如果你在安裝過程中連接到了互聯網，你可以通過 Calamares 安裝程序來安裝這些。這意味着你不需要在基本的 Xfce 設置後重新安裝它們。

此外，如果你是一個資深用户，只想安裝一個基本的 Arch Linux，不需要任何桌面，那也是可以的。只要在安裝時使用 “無桌面No desktop” 選項就可以了!

儘管 Arch Linux 最近創建了一個自動腳本 archinstall 來使安裝更容易，但通過 EndeavourOS 的 ISO 來獲得 Arch 的基本安裝仍然更快、更容易。

此外，你可以在三個選項中選擇：GRUB、systemd-boot 或 “無啓動器no bootloader”，這是 EndeavourOS “Cassini” 版本的亮點功能之一。此外，你還可以選擇你要安裝的軟件包（僅在線模式支持）。例如，你可能需要一個基本的系統來開始使用。或者，你可能想安裝一些與視頻/音頻或開發工作有關的應用程序。所有這些你都可以在這個版本中選擇。

安裝通過檢測我的測試機中安裝的其他操作系統而完成，很順利。在“Cassini” 版本中，該團隊還將 mkinitcpio 換成了 dracut，以獲得更好的性能，減少啓動相關問題的失敗。

“Xfce” 旗艦版的桌面體驗 ​

第一次登錄後，你會再次看到歡迎程序，其中有一個 “安裝後” 可以做的項目列表。開發人員提供了一個非常周到的列表。這包括改變牆紙、更新 Arch 鏡像、安裝英偉達驅動等初始任務。許多 Linux 發行版都有一個歡迎程序，但我認為這個程序是一個完善的軟件包。

默認的外觀是你能得到的定製的最好的 Xfce 桌面。通過定製，它成為一個外觀良好的發行版，遠非默認的 Xfce 可比。定製包括 GRUB 菜單、登錄屏幕和桌面等等。

Xfce 主菜單配置了更多的項目，終端略帶透明，使用 Qogir 圖標主題。所有這些變化都輔以令人驚歎的壁紙和 Arc-Darker 默認 Xfce 主題。

性能 ​

儘管有桌面環境，Arch Linux 的性能總是更好。它總是令人感覺更快，因為它的內部並不臃腫。除此之外，Xfce 桌面 4.18 在 “Cassini” 版本中還做了額外的性能優化，你可以在瀏覽桌面的時候感受到。

在空閒狀態下，它使用了大約 700MB 的內存和平均 4% 的 CPU 佔用。這是性能基線。資源使用量可能會根據你打開的應用程序的數量而增加。在我之前對 EndeavourOS 的點評中，其性能表現也類似。

不僅如此，它在默認的 Xfce 安裝中只使用了 4GB 的磁盤空間。然而，你可能需要安裝額外的重型軟件，如 LibreOffice、GIMP 或 KDenlive，這將佔用更多磁盤空間。

在 EndeavourOS 中執行日常任務有多容易？ ​

EndeavourOS 的一大特點是一些基於 Python 的 GUI 工具，可以使你在 Arch Linux 中的生活變得簡單。例如，你可以從 Arch 和 EndeavourOS 的軟件倉庫中獲得更新通知、一鍵從 AUR 安裝軟件、一鍵更新鏡像和你的系統。你不需要從終端運行任何命令。這對 Arch Linux 的新用户來説是一個很大的幫助。

處理滾動發佈的獨特方式，以實現穩定性 ​

Arch Linux 作為一個滾動發佈的發行版，往往會出現故障。例如，在 Arch 主倉庫的每個月的內核更新期間，一些系統可能會出現故障。由於它的受歡迎程度和開發者的主動性，如果出現問題，你會得到通知和相關的解決方法。

最近 Arch Linux 中的 GRUB 問題，給用户帶來了大量的啓動問題，EndeavourOS 團隊通過適當的溝通，給用户提供瞭解決方法，真的 處理得很好。

因此，如果你最終遇到一個不穩定的系統，你也不會真的迷失。

此外，Pacman 的配置已被定製過，使用 EndeavourOS 選擇的鏡像，以確保你的體驗是完美的。

對開源硬件和 ARM 的正式支持 ​

在這個 EndeavourOS “Cassini” 版本中，官方支持了 Pinebook Pro 筆記本電腦。該團隊在 Manjaro 軟件包的基礎上與 Pine64 團隊合作，為你提供了獨家的 Arch 軟件包，使該筆記本開箱即用。此外， EndeavourOS ARM 鏡像也可用於樹莓派 4。

社區幫助 ​

EndeavourOS 最大的好處之一是社區幫助 —— 這是即時的！這主要是指其專門的 Telegram 頻道，在那裏你可以在幾分鐘內得到對你的 EndeavourOS 的任何問題的回應。我曾經去過這個頻道，管理員/貢獻者們都很友好，很有幫助。

此外，你也可以從官方論壇和其他社交渠道獲得幫助。

總結 ​

在結束對 EndeavourOS 的 “Cassini” 版本 的點評時，我想説這是一個構建得最好的發行版，而且組織良好。開發者和團隊有一個建立通用的 Arch Linux 發行版的清晰路線圖。另外，通過對 ARM 和 Pinebook Pro 的支持以及其他舉措，其願景也很明確。

總而言之，對於每一個希望在 Arch Linux 中擁有一個運行時間更長、更穩定的系統的人來説，這是一個完美的發行版。

你可以從 官方網站 下載 EndeavourOS。
