不普通的普通操作系統：Vanilla OS 穩定版發佈了！ ​

Vanilla OS 已經準備好讓你嘗試！在這裏瞭解令人興奮的地方。

Vanilla OS 是一個基於 Ubuntu 的發行版，旨在為用户提供一個具有隨需應變能力和自由選擇軟件包的 GNOME 體驗。（LCTT 譯註：Vanilla —— “香草”，因為作為太普通的香料，所以也有“普普通通”的意思。）

經過幾個月的測試，Vanilla OS 的第一個版本 終於以 Vanilla 22.10 Kinetic 的形式出現了，其提供了原汁原味的 GNOME 43。

在最近的一次採訪中，我們問創建者：“很多人認為我們已經有太多的發行版了。為什麼還要有 Vanilla OS？”，Mirko Brombin，分享了一些有趣的見解享。請看下面我們與他的對話，探索關於 Vanilla OS 的令人興奮的事情：

“不要害怕做出貢獻”：Mirko Brombin 談 Vanilla OS 和其他未來項目

Vanilla OS 有幾個特點，你可能會覺得有幫助，請允許我向你介紹一下。

主要亮點 ​

作為一個新的發行版，Vanilla OS 有一個裝備精良的功能集，你可能會喜歡。一些值得注意的亮點包括：

  • 原生安裝程序
  • Vanilla OS 首次設置First Setup 功能
  • Vanilla OS 控制中心
  • apx 軟件包管理器
  • 隨需應變能力

原生安裝程序 ​

Vanilla OS 有一個用 GTK4 和 libadwaita 編寫的原生的安裝程序，它取代了該操作系統在早期開發階段時使用的 Calamares 安裝程序。

之前，他們還宣佈將使用來自 Crystal Linux 團隊的 Jade 安裝程序。

但是，他們改變了主意，選擇在現有的 Vanilla 首次設置 項目之上建立 Vanilla 安裝程序。

Vanilla OS 首次設置 ​

Vanilla OS 的安裝完成後，你會看到一個快速設置屏幕，上面用各種語言寫着 “歡迎”。

然後它將帶你完成各種設置，如選擇顏色方案，選擇你想要的軟件包管理器，是否要安裝受限制的編解碼器，等等。

我必須説，這很方便！ 😃️

Vanilla OS 控制中心 ​

這個圖形化工具使你能夠對操作系統進行修改，如運行關鍵更新和安裝額外的驅動程序。

隨需應變的不變性 ​

正如上面 Vanilla OS 的創始人所展示的，這個操作系統可以提供完全的不變性和原子性，允許你在兩個根分區（A/B）之間進行交易。

你問這是什麼意思？ 🤔

嗯，這意味着你的系統的核心部分被鎖定，以防止任何不必要的變化，特別是那些由損壞的應用程序或錯誤的更新引起的變化。

Vanilla OS 使用 ABRoot 來實現這一目標，之前，他們曾嘗試使用 Almost，但結果並不理想。

它還有一個智能更新功能，他們解釋如下：

VSO（Vanilla System Operator）是一個工具，它將定期檢查更新，然後如果設備沒有處於大量使用狀態，就在後台下載和安裝。事實上，VSO 檢查是否滿足某些檢查條件，如資源是否空閒（CPU/RAM），連接是否允許，電池是否至少有 30% 的電量等。

更新是通過 ABroot 應用的，並在下一次重啓時得到修補，而不需要花費額外時間。

apx 軟件包管理器 ​

Vanilla OS 帶有 apx 工具，允許你在不修改根文件系統的情況下在管理的容器內安裝軟件包。

下載 Vanilla OS ​

如果你認為 Vanilla OS 解決了你在 Ubuntu 上遇到的問題，並且想要一個原汁原味的 GNOME 體驗，那就來試試吧。

你可以在其 官方Blog文章 中瞭解更多關於 Vanilla OS 22.10 的信息。
