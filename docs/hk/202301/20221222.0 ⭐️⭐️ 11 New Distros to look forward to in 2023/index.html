2023 年值得期待的 11 個新發行版 ​

你對 2023 年有什麼期待？試試這些發行版吧！

是時候向 2022 年説再見了！📆

2022 年有很多發行版發佈，其中有一些非常出色。

隨着人們越來越關注用户體驗和性能，Linux 發行版在過去的一年中有了顯著的發展。

對於你我這樣的最終用户，可以有幾個選擇。你可以嘗試一些 對初學者友好的選項 或者嘗試一些 面向資深用户的發行版。

在本文中，我將重點介紹一些你可以嘗試一下看看的新發行版。這些發行版可能不一定能取代現有的流行發行版。但是，如果你想嘗試一些新的東西，可以試試列表中的這些。

所以，你在 2023 年可以期待什麼？🤔

好吧，為了回答這個問題，讓我們踏上發行版之旅吧！

💡 新的發行版可能不適合生產環境。如果你不介意嘗試新的東西，可以嘗試這些選項。

1、Vanilla OS ​

Vanilla OS 是一個基於 Ubuntu 的發行版，它是 Bottles 的創建者 Mirko Brombin 的心血結晶。

它旨在提供一個具有乾淨、原生的 GNOME 體驗，以及按需不變性on-demand immutability和優秀的首次安裝體驗。

LCTT 譯註：按需不變性on-demand immutability，指一個可以按需讓文件不可更改的功能，用於確保系統文件不會被隨意更新。 可參考 此鏈接。

如果你想嘗試一些新的東西並且想嘗試一下按需不變性這個令 Vanilla OS 如此獨特的功能，可以嘗試一下這個發行版。

它還沒有穩定版本，在一段時間內也不會有，預計將在 2023 年進行許多改進。

Vanilla OS

2、XeroLinux ​

這個興趣項目 XeroLinux 是 Steve（即 TechXero）啓動的，這個項目並不打算成為一個主流發行版，也沒有各種花裏胡哨的東西。

這個 “養眼” 版的 Arch Linux 衍生版提供了令人愉快的開箱即用體驗和一些令人興奮的功能。

如果你希望獲得更加易用的 Arch Linux 體驗，可以嘗試這個。

從 2023 年 1 月起，XeroLinux 將切換到每月發佈的計劃。所以，你可以期待 2023 年有很多更新！

XeroLinux

3、Crystal Linux ​

Crystal Linux 是一個即將發佈的基於 Arch 的發行版，它希望提供一個易於使用的桌面體驗，以及現代 Linux 技術。

在目前的狀態下，它可能不適合新手，而具有 Linux 使用經驗的人更有可能喜歡它。

所以，就目前而言，我建議已經熟悉 Linux 的用户可以嘗試一下 Crystal Linux。

我預計 Crystal Linux 將在 2023 年有一個穩定版本，該版本將具有許多功能和改進，而這些功能和改進都是基於目前可用的 beta 版本。

Crystal Linux

4、TUXEDO OS ​

TUXEDO OS 是一個由 TUXEDO 計算機公司（一個專注 Linux 的硬件製造商）提供的基於 Ubuntu 的發行版。

它提供了 KDE Plasma 桌面環境，還有一些額外的功能，例如用於微調硬件的 TUXEDO 控制中心，以及一個用於解決驅動程序與缺少軟件包的問題的配置服務 TUXEDO Tomte。

如果你想要一個不同的 KDE 驅動的體驗，我建議你嘗試一下。

最開始，它只作為預裝系統在 TUXEDO 的筆記本和台式電腦上提供。

但是後來，它在 2022 年 9 月獲得了一個通用版本，稱為 “TUXEDO OS 1”。它將在 2023 年獲得大量更新。

TUXEDO OS

5、EuroLinux ​

EuroLinux 是一個具有企業級特性的、基於 RHEL 的發行版。它以可靠的軟件包提供了穩定性和安全性。

它基於 RHEL 9，可以提供與其他 基於 RHEL 的服務器發行版（如 Rocky Linux，CentOS，AlmaLinux 等）的無縫兼容性。

它旨在以熟悉的用户界面佈局吸引 Windows 和 macOS 用户，在屏幕底部提供了一個半透明的菜單欄。

你應該嘗試一下，因為整個軟件包相當充分，可以同時滿足 Linux 和 Windows/macOS 用户的需要。

它現在已經發布了穩定版本，也在 2023 年有更新計劃。

EuroLinux

6、Zinc ​

Zinc 是一個 基於 Ubuntu 的發行版，經過了調整後提供了一個獨特的體驗。現有的 Ubuntu 用户可能會驚訝於它所提供的內容。

它基於 Xubuntu 的最新 LTS 版本，使用了 XFCE 桌面環境，並對其進行了許多改進，例如集成的 Linux AppImage 支持、deb-get 包安裝程序、BTRFS 作為默認文件系統等。

如果你正確的配置了它，它可以成為你的日用操作系統的替代品。

它遵循穩定的發佈模式，因此你可以期待 2023 年的重大更新！

Zinc

7、CachyOS ​

CachyOS 嘗試使 Arch Linux 變得對初學者更加友好，讓任何人都可以使用。它很受歡迎，因為它具有高度的可定製性，而且還擁有最新的軟件。

它旨在為你提供一個快速、安全且易於使用的操作系統。

該操作系統適用於想要試驗和嘗試新事物的用户。

CachyOS 是一個滾動發佈的發行版，因此你可以期待它在 2023 年獲得大量更新。

CachyOS

8、risiOS ​

在基於 Arch 和 Ubuntu 的 Linux 發行版的海洋中，risiOS 是一道難得的風景。

該項目基於 Fedora Linux，其起源於美國西雅圖。

它使用 GNOME 桌面環境 為用户提供了一個高度可定製的體驗，同時還提供了 自定義的 ZSH 版本。

如果你希望嘗試一個基於 Fedora 的發行版，這可能是你的新選擇！

risiOS 會在穩定版本間隔中推送一些小更新。在 2023 年，它還有更多的東西可以提供給你。

risiOS

9、Exodia OS ​

#$**！又是一個基於 Arch 的 Linux 發行版？

是的。🤭 好吧，看起來今年我們已經受夠了基於 Arch 的發行版了，這並不一定是壞事！

認識一下 Exodia OS，一個基於 Arch 的 Linux 發行版，旨在為安全領域的用户提供高度可定製的體驗。

其功能包括為各種網絡安全領域預裝的工具、命令列界面應用、ElKowars wacky widgets （EWW）、Zsh 等。

如果你是一個網絡安全專家或愛好者，你可以試試！

他們為三個不同的使用場景提供了三個版本。你可以期待他們在 2023 年繼續推送必要的更新和功能添加。

Exodia OS

10、Kumandar Linux ​

乍一看，你可能會認為這是 Windows 7，但如果仔細觀察，你會發現這是 Kumandar Linux。

它基於Debian 11，並使用自定義的 XFce 版本。

該名稱在中文中的含義為 “指揮官”，以向開發者的第一台電腦 Commodore VIC20 致敬。

如果你喜歡 Windows 7，但想在 Linux 上體驗同樣的體驗，那麼你可以試試！

目前，該系統只發布了早期的候選版本。但是，你可以期待在 2023 年發佈穩定版本，希望如此！

Kumander

11、Ubuntu Unity ​

今年早些時候，Ubuntu Unity 被宣佈為 Ubuntu 的官方版本，是 Ubuntu 的一個翻版。

它使用了 2010 - 2017 年間 Ubuntu 中使用的 Unity 桌面界面，該界面後來被 Canonical 使用 GNOME 取代。

開發工作如火如荼，年輕的首席開發人員正在推動更新和增加新功能。

想要嘗試不同風格的 Ubuntu 的用户可以試試這個系統。它提供了 LTS 和非 LTS 版本。

Ubuntu Unity
