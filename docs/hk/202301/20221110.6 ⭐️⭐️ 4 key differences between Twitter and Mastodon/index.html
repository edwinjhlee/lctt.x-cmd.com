Twitter 和 Mastodon 的四個關鍵區別 ​

Mastodon 並不是一家公司。所有 Mastodon 實例都由各自所屬服務器的貢獻者負責支持維護的。以下是它的一些其他優勢。

社交媒體並不總是社交性的，有時我們還需要足夠的推動力來改變我們工作和閲讀的內容。我在 2008 年開始使用 Twitter 作為 RSS 閲讀器的替代品，這徹底顛覆了我那時的閲讀和學習方式。世界各地的教育家和自由與開放源碼（FOSS）倡導者的推文讓我瞭解並參與到一個無與倫比的學習網絡中。但這在過去的六年間，事情發生了變化，以及最近它的所有權發生了變化，造成我閲讀的內容更多是由算法驅動的，而不是出於我個人的興趣和選擇。在幾年前的 Opensource.com 記者編輯碰頭會中，Seth Kenlon 建議我試試 Mastodon。於是我在 2019 年加入了 Fosstodon。Fosstodon 是一個專為喜歡自由和開源軟件的同好們搭建的實例。

Mastodon 與 Twitter 對比 ​

作為一個墨守成規的人，改變對我來説並不容易，儘管 Twitter 變得越來越讓人厭倦，我還一直在使用。可是到了 2022 年的春天，Twitter 的出售危機讓我重新考慮使用 Fosstodon 了。

1、收藏而不是點贊 ​

Mastodon 的界面與 Twitter 很相似。但在 Mastodon上，你不是“點贊”一個帖子，而是通過點擊帖子下方的星標來“收藏”一個帖子。

2、分享帖子 ​

在 Twitter 上，重新分享是“轉推retweet”，但在 Mastodon，它是“轉嘟boost”。你可以點擊帖子下方的雙箭頭圖標來轉嘟。

3、Mastodon 實例 ​

任何人都可以運行一個 Mastodon 實例，這讓不同的實例上發展出了獨特的社區（類似在 Twitter 上圍繞特定標籤形成的社區，不過 Mastodon 也有標籤），有些實例有一套獨特的規則。舉個例子，和我以前的社交網絡不同，Fosstodon 上採取了內容審核制度。最初這讓我覺得有些嚴格，我發了一個與自由與開放源碼軟件無關的帖子，然後帖子就被刪除了。我被告知的刪除原因是，我沒有給帖子打上 “內容警告”。這惹怒了我，於是我嘗試尋找別的實例，發現了幾個更符合我胃口的。其中一個是 Mastodon.social，另一個是 Scholar.social，前者是一個泛用的實例，沒有預設的發帖主題，後者則是一個學術專用的實例。當然，他們也都制定有嚴格的行為規範。

每個實例都有規則，雖然在表述上略有不同，但都清楚地説明了可以接受和不可接受的行為。Fosstodon 公佈了它的 行為規範，確立了站點的規則和預期。

4、開源社交網絡 ​

如果你也想運行自己的 Mastodon 實例或協助開發一個，好消息是，Mastodon 是開源的。它使用 AGPLv3 許可證，它的源代碼可以在 Git 倉庫 獲得。Mastodon 使用 ActivityPub 協議與世界各地的服務器通信。

Mastodon 不是互聯網上的單一的網站，而是一系列橫跨全球並相互通信的網站們。這個聯邦網絡被稱為 “聯邦宇宙Fediverse”。不像其他社交網站有單一的所有者，任何人都可以在服務器上運行 Mastodon 或者其他 ActivityPub 協議網站。

從用户的角度來看，這一開始時其實並不重要。你可以在任何 Mastodon 實例上註冊，然後連接到其餘所有的實例。

不過，這種分佈式設計是有其好處的。如果你碰見一個實例上的社區內容你不想看，你可以從屏蔽該實例中的某個用户，或者屏蔽整個實例。

過去的一個月裏，我又回到了 Fosstodon，主要還是因為我熱衷開源。我很享受在 Fosstodon 上分享開源內容，而 Fosstodon 上的其他用户也都能樂於看到關於自由和開源軟件的帖子。當我有一些內容不適合在 Fosstodon 上分享時，我會分享到 Scholar.social 或者 Mastodon.social 上。

不是所有的實例都有關注的主題，即便是那些有主題的實例，主題常常也是僅作參考，而不是嚴格作為刪帖的依據。如果你有特定的興趣，也許就能找到一個圍繞這個話題建立的社區，然後馬上就能收穫及時的關注。當然，你也依然能夠與其他實例的用户交流。

試試 Mastodon ​

Mastodon 不是一家公司，所有 Mastodon 實例都是由各自所屬的服務器的貢獻者負責支持維護的。有些能很容易地通過 Patreon 或 PayPal 提供支持。

我發現，聯邦宇宙是個很温馨的地方，把快樂帶回給了社交網絡。你加入了 Mastodon 了嗎？有沒有什麼收穫？請在評論中告訴我們。
