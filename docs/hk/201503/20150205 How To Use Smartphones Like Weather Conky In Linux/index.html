如何在 Linux 中使用類似智能手機外觀的 Conky 天氣插件 ​

智能手機都擁有一些平滑地融入手機外觀的天氣小插件，現在幸虧有了 Flair Weather Conky，你便可以在你的 Linux 桌面中擁有像智能手機一樣的天氣外觀。我們將使用一個 GUI 工具Conky Manager 在 Linux 中輕鬆地管理 Conky。那就先讓我們看看如何在 Ubuntu 14.10，14.04、Linux Mint 17 及其他 Linux 發行版本中安裝 Conky Manager 吧。

安裝 Conky Manager ​

打開一個終端並使用下面的命令：

sudo add-apt-repository ppa:teejee2008/ppa
sudo apt-get update
sudo apt-get install conky-manager

你可以閲讀這篇關於如何在 Linux 中使用 Conky Manager 的文章。

確保 curl 已被安裝 ​

請確保 curl 已被安裝。如果沒有安裝它，可以使用下面的命令來安裝：

sudo apt-get install curl

下載 Flair Weather Conky ​

從下面的鏈接下載 Flair Weather Conky 的腳本：

  • 下載 Flair Weather Conky 的腳本

在 Conky Manager 中使用 Flair Weather Conky 腳本 ​

步驟 1: ​

同你在 Ubuntu 14.04 中安裝主題一樣，在你的家目錄中應該有一個 .conky 目錄。假如你使用命令列，我想我不需要告訴你如何找到這個目錄。對於新手，請用文件管理器切換到你的家目錄下，並按 Ctrl+H 來 在 Ubuntu 中顯示隱藏文件。在這裏查找 .conky 文件夾，假如沒有這個文件夾，則創建一個。

步驟 2: ​

在 .conky 目錄中，解壓下載到的 Flair Weather 文件。請注意在默認情況下它會自動解壓到一個名為 .conky 目錄下。所以請進入這個目錄，將其中的 Flair Weather 文件夾從中取出，然後將它粘貼到真正的 .conky 目錄下。

步驟 3: ​

Flair Weather 使用 Yahoo 的天氣服務，但它不能自動地識別你的位置。你需要手動地編輯它。到Yahoo 天氣 網頁，然後通過鍵入你的城市/Pin 碼來得到你所在城市的位置 ID號。你可以從網頁地址欄中取得位置 ID 號。

步驟 4: ​

打開 Conky Manager，它應該能夠讀取新安裝的 Conky 腳本。這裏有兩款樣式可用，黑色主題或亮麗主題。你可以選擇你偏愛的那一款。當你選擇後，你就可以在桌面上看到 conky 的顯示了。

在 Flair Weather 中，默認位置被設定為 Melbourne。你必須手動編輯 conky 文件來修改。

步驟 5: ​

在上面的截圖中，你可以看到有一個編輯選定 conky 腳本的選項，在打開的編輯器中，查找 location 或 WOEID ，更換它為你在 步驟 3 中得到的位置 ID 號。然後重啓 Conky。

在上面查找的相同位置，假如你將u=c 替換為u=f，則温度的單位將從攝氏温標改為華氏温標 。不要忘了重啓 Conky 來查看已經做出的修改。

可能的故障排除 ​

在 Ubuntu 14.04 和 Ubuntu 14.10 中，假如你發現 Conky 展示的時間有重疊現象，則請編輯 conky 腳本。查找下面的這些行：

## cairo-compmgr
own_window_type override
own_window_argb_visual no

然後將內容更換為下面的這些行：

## cairo-compmgr
own_window_type dock
own_window_argb_visual no

保存更改並重啓 conky。這就應該解決了這個問題。感謝 Jesse(這個 Conky 腳本的開發者)給我們提供了這個解決方法和為其他相關問題給予的支持。

嘗試一下 ​

在這篇文章中，我們實際上學到了不少東西。我們見證瞭如何輕鬆地使用任何 Conky 腳本，如何編輯腳本以及如何使用 Conky Manager 來達到不同的目的。我希望這些對你有用。

需要留心的是，Ubuntu 14.10 用户可能會看到重疊的時間數字。請在開發者 Jesse 絕妙的Google + 主頁 中報告任何相關的問題。

我已經向你展示了在我的系統上 Flair Weather conky 外觀的截圖。現在是該你嘗試它並炫耀你的桌面的時間了。
