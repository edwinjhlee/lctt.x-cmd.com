10種將開源用於商業的最佳途徑 ​

開源為大大小小的商業帶來了一些顯著的效益 -- 但是你可能會對某些用途感到驚訝。

技術上已經發生了一些必然性的改變。舉個例子，開源軟件以它的方式進入到了你的工作之中。10 年前，這也許還能稱為一個問題。現在呢？則已經無法避免開源技術的使用 -- 也沒有理由要去避免。有如此多強大（和必需的）的方方面面技術，開源在許多方面已經成為了技術的救世主。但是你哪一塊的工作最適合開源軟件呢？當然，這個問題的答案會因公司而異。然而許多的應用幾乎可以適用於每個場景中。

讓我們來看看這10種可能是最佳的使用方法，它們可以幫助你的公司成長，帶給你從未體驗過的靈活性與可靠性，或者僅僅是幫你節省一筆可觀的預算。

1: 服務器軟件 ​

如果你還在微軟的 IIS 平台苦苦掙扎，那麼你需要體驗一下 Apache。這款旗艦級開源軟件是這個星球上使用最廣泛的網頁服務器軟件之一。Apache 免費、極其可靠、易於管理，而且不像 IIS 一樣需要大量的資源。然而，開源並不侷限於網頁服務器。如果你需要在公司內使用 SMB 來共享資源，可以試試 Samba， Samba 4甚至集成了活動目錄（AD），所以你不需要擔心在Samba服務器上建立單獨的用户賬號。

2: 開發 ​

用開源開發是很簡單的事。PHP，Rails，Perl -- 開源上面的開發語言和開發的工具（從集成開發環境到調試）都很多。為開源或者開源工具做開發可以有很多種選擇（如同使用商業軟件開發一樣）。開源軟件與商業軟件最大的不同之處在於開源可以接觸到軟件源代碼。在自由開源軟件（FOSS，free open source software）的世界裏，代碼都是公開的。對許多開發者來説，Linux操作系統有他們開發和構建所需要的一切（特別那些沒有一個成熟環境來寫代碼的人而言）。如果你需要圖形用户界面（GUI）的開發工具，開源也能滿足你。

3: 安全 ​

通往安全的道路是充滿挑戰的，但還是很多途徑可以達到。你可以選擇“安全盒子”的解決方案，跟隨Cisco（一個可靠的解決方案）的節奏，或者你可以藉助iptables打造最適合你需求的安全。是的，開源的安全之路會需要更多的時間去配置（有很高的學習壁壘），但是結果通常是不錯的。這裏甚至不強調一種觀點，就一般來説，在桌面上使用開源比起大多數封閉的系統而言是一個更安全的平台。在桌面上部署Linux，你的安全痛點會大大降低。

4: 桌面 ​

Linux 桌面是大多數人不認可的地方。儘管如此，你必須考慮一個事實，那就是你每天的工作流程已經經歷了一個主要的思維模式的轉換。我們現在做的大部分事情都是通過網絡瀏覽器。那麼為什麼不將Linux部署到桌面上呢？不但可以能做如今要做的許多工作，而且不用遭受病毒，惡意軟件和能破壞系統的更新。它不完美 -- 但哪個平台敢説完美？但是它很強大，最後，還可以節省你的開支。這是一個雙贏的結局。

5: 工作流程 ​

每一種工作都依賴於工作流程。對於某些工作來説，一個流暢的工作流程又取決於所用的工具。開源已經登上這個舞台了。CRM（客户關係管理），HRM（人力資源管理），ERP（企業資源計劃），BI（商業智能），BPM（業務流程管理） …… 只要你叫得出名字，開源就可以做到幾乎你能想到的每一種可能 -- 並且幹得不錯。藉助於Pentaho, Collabtive和SugarCRM, 開源可以在任何時候與最新的源工具保持同步。

6: 協作 ​

沒有一起合作項目的能力，你的員工就不能幹好工作。所以你選擇的協作工具是十分重要的。你會在開源的世界裏發現大量的優質協作工具。Cyn.in 社區版, Zimbra 開源版和Kolab都是不錯的協作工具，但這僅僅是開源世界裏的三個代表而已。

7: 大數據 ​

以前説到大數據的時候，往往不會想到開源。多虧了SUSE的努力，大數據和開源現在可以攜手共進了。許多如內存數據和內核熱補丁的發明創建，使得開源成為大數據一個理想的解決方案。它可以完美地滿足大數據在平台上所需的大量要求，而封閉的軟件則達不到如此靈活的水平。

8: 雲 ​

雲的主要玩家都是開源的。Red Hat, Ubuntu, SUSE, Amazon, Rackspace -- 他們都提供雲服務，而且認為開源是雲配置的最好解決方案。但是，如果你不想用大公司的服務，仍然有很多後起之秀如OwnCloud，你可以選擇OwnCloud的託管雲方案，或者建立自己的一套。

9: 多媒體 ​

如果你的公司做播客或為產品發佈製作視頻，開源可以為你提供服務。藉助像Audacity和OpenShot這樣的工具，你可以對音頻和視頻做你需要的任何處理 -- 而且十分的廉價。實際上，你會感覺到很難再去找到比Audacity更好的播客工具，或者比OpenShot更易用的視頻編輯器。沒有太大的學習壁壘，或者閉源軟件工具所要求的高額費用，開源的軟件在幫助你創造專業水準的作品方面已經做得很好了。

10: 電子商務 ​

如果你做在線銷售，如果不嘗試一下像PrestaShop之類的工具，你就太懈怠了。PrestaShop是最強大的電子商務解決方案之一，易於獲取 -- 不需要許可證。 PrestaShop有你可能想要的所有功能（而且有些你可能都沒有想過），這個開源平台已經在任何水平上超出了電子商務的範疇。

FOSS 之於商業 ​

開源已經不再侷限於商業交流的範圍了。在許多情況下，FOSS已經主導這種交流。如果你已經在尋找將開源解決方案運用的領域，看上面的10條就行了。

該你了 ​

你已經將開源用到你的工作中了嗎？如果是，屬於哪一條方法呢？
