讓你玩轉 Ubuntu 桌面的十一件武器 ​

無論你是一個相對的新手還是經驗豐富的專家，我們都想從我們的操作系統中得到更多的東西。正如大多數現代的操作系統，相比於乍一看呈現出的內容，Ubuntu 還有更多東西可以向我們提供。

從調整和優化 Unity 桌面的外觀、行為、性能到執行系統維護，這裏有大量的實用工具和應用可以幫助你調整 Ubuntu ，隨時滿足你的需求。

注意： Ubuntu 總是配備了‘合理的默認設置’（即工作良好的選項），以達到開箱即用，這些默認設置適合大多數人，並且它們都是經過了測試、採用及推薦等過程的。

但一個尺碼並不適合所有人。對於我們當中的能工巧匠和實驗主義者來説，默認設置只是他們定製系統的起點。

所以，無需更多的嘮叨， 這裏有 11 個極好的實用工具可以幫助你增強 Ubuntu 使用體驗。

Unity Tweak Tool ​

我將以這個列表中最重要的一個工具: Unity Tweak Tool 來開始這次的介紹。融匯了各種定製選項，Unity Tweak Tool 提供了一系列針對 Ubuntu 和 Unity 桌面的系統綜合調整功能。

它被各種開關、切換和控制器塞得滿滿的，使得你可以任意設置從 Unity 桌面的外觀到 Unity 的行為之類的任何東西。你可以使用它快速簡便地改變 GTK 主題和圖標集、設置熱區、調整啓動器圖標尺寸、增加或移除工作區，以及 ---特別地---開啓 Unity 桌面中被巧妙隱藏的“通過點擊最小化”的功能。

它是免費的，可直接從 Ubuntu 軟件中心裏找到， Unity Tweak Tool 是非常值得保留在你的口袋裏的工具之一。

Unity 隱私指示器 ​

隱私是一個非常、非常重要的事，事實也恰恰如此，但這個話題要比二進制還難以説明白。讓一些數據或習慣，比如説你經常打開的應用，在本地被記錄下來，這或許會讓你感到高興，但對於你在 Dash 中的搜索數據被髮送到第三方服務機構(儘管這些數據或許是匿名的)這類事情，你就高興不起來了。

隱私指示器 是一個幫助你時刻跟蹤 Ubuntu桌面系統中有哪些文件、目錄和服務正被獲取、記錄及搜索的實用工具。

通過快速的點擊被添加到桌面面板上的‘眼睛’圖標，你可以：

  • 開啓或關閉在線搜索結果，使用 Zeitgeist 記錄系統活動，存儲 HUD 使用記錄和啓用 Ubuntu GeoIP 服務
  • 快速清理 Zeitgeist 日誌、 ALT-F2 歷史、最近訪問文件等等的記錄數據
  • 展示或隱藏桌面圖標及面板上顯示的用户名

上述的最後一條的功能似乎不應該出現在這個應用程序中，但對於那些要分享截圖或截屏的人來説，這將會泄露更少的隱私。

  • 從這裏下載隱私指示器 (.deb)

Unity 櫥窗 ​

Android, iOS, OS X, Chrome OS, 和 GNOME Shell 都有應用櫥窗, 藉助一個極好的第三方應用，Unity 也可以實現類似功能。

“Unity 櫥窗” 允許你將 Unity 啓動器中的應用分組到實用的櫥窗中，--- 如遊戲，辦公，社交等。不必打開 Dash，你就可以快速啓動你喜愛的應用，這非常適合你的工作流。

每一個 ‘櫥窗’其實上是一個打開在圖標附近的應用窗口，但總體效果看上去就像是一個 OS X 風格的“堆棧”或 Android 的分組框。

櫥窗的圖標可以自定義或根據櫥窗內的應用來自動生成。已有的櫥窗可以修改和重新組織、重命名以及如下的更多選擇：

  • 根據你的喜好創建任意多的櫥窗
  • 選擇自定義或自動生成櫥窗圖標
  • 可選擇 3 種櫥窗樣式
  • 為添加到櫥窗中的應用設定自定義圖標
  • 編輯現有櫥窗

咖啡因（Caffeine） ​

對於我們中的許多人來説，咖啡因是必需品，而不僅僅是飲料。而這裏的“咖啡因”則提供了一個快速，温和的方式來避免屏保/鎖屏佔據屏幕。它的有用程度將取決於你的環境(即你係統的怪癖)，並且儘管它不像以前那樣好用，它仍然值得你嘗試一下。

下載咖啡因（Caffeine）

系統監控指示器 ​

假如你是一個狀態迷，即一個喜歡密切關注程序，進程和硬件的狀態的人， Linux 很容易滿足你的需求。從 Conky 的配置到終端命令，並不缺少監視你的 CPU 使用情況、網絡流量或 GPU 温度的方法。

但至今為止，我最喜愛的應用是系統監控指示器（也被叫做多負載指示器），它可從 Ubuntu 軟件中心獲得。它也有着大量的配置選項。

  • 點擊這個鏈接，在 Ubuntu 中下載 ‘系統監控指示器’

針對 Linux 筆記本電腦的省電工具 ​

TLP ​

當提到便攜式設備上的電池使用效率時，Linux 發行版的聲譽並不算好。

如果你的 Linux 筆記本在重新充電前，電池只夠讓你從沙發走到廚房的話，那麼這裏有幾個你可以試試的工具。

TLP 是最受歡迎的確保延長 Linux 筆記本的電池壽命的自動化後台工具之一，它是通過調整系統進程和硬件的設置及行為來達成省電的，例如 啓動 Wi-Fi 省電模式， PCI 總線設備的實時電量管理和處理器的降頻調整。

在 Ubuntu 14.04 LTS 以及後續發行版本中可以使用 TLP 專用的 PPA 來安裝它，通過它的‘一下搞定’的設置就能用起來。在我們之中的高級用户可以潛心研究並根據你自己的硬件來調整設置，一個關於 TLP 的完整指導 wiki 使得設置更加容易。

Laptop Mode Tools ​

假如 TLP 聽起來有一點複雜，這也並沒有什麼可羞恥的，這裏有一個更簡單的替代品： Laptop Mode Tools。 這個軟件包可從 Ubuntu 軟件中心直接安裝，且本身設置好了一系列合理的默認設置(Wi-Fi,藍牙等等)。

切記，Laptop Mode Tools 不能和 TLP 同時被安裝在電腦中。

  • Ubuntu 軟件中心裏的 Laptop Mode Tools

Intel 顯卡驅動安裝工具 ​

對於那些運行 Intel 顯卡硬件，並想使得這些硬件發揮出最佳性能的人來説，Intel 顯卡安裝工具是必須擁有的。 它使得查找並安裝最新的 Intel GPU 驅動變得不再是一件痛苦和大費周折的事，因為這無需 PPA 或任何的終端使用知識。

  • 下載針對 Linux平台的 Intel 顯卡驅動安裝器 0.7 版本

硬件信息 ​

假如你計劃升級你的 PC 或想替換一個壞掉的零部件，你需要知道一些特定的硬件信息，例如 RAM 類型，CPU插座類型 或查看哪個 PCI 槽是可用的等信息。

I-Nex可以使得找出這些以及其他的系統具體配置變得更加容易。使用它來查找你的主板型號、S.M.A.R.T.(注：為 Self-Monitoring, Analysis and Reporting Technology 的縮寫，經常寫為 SMART ) 狀態，以及你想的出的很多東西！

  • 可從 Launchpad 瞭解到更多關於 I-Nex 的信息

磁盤空間可視化程序 ​

在這個硬盤以 TB 計數的時代，我們或許不必同以前一樣對硬盤空間的使用三思而後行。但對於那些使用小容量的 SSD，分成多個分區或在一個擁有固定大小的虛擬磁盤的虛擬機上工作的人來説，總有“應該釋放一些額外空間是必要的”這種想法的時候。

GNOME Disks，在 Ubuntu 中被默認安裝，使得查找佔用最大磁盤空間的罪魁禍首變得容易。對於定位隱藏的日誌、緩存和視頻文件，它是非常完美的工具。

BleachBit (Cruft Cleaner) ​

Windows 用户可能對像 CCleaner 之類的應用很熟悉，它可以掃描並清理垃圾文件、空白文件夾、臃腫的緩存以及陳舊的軟件包。在 Ubuntu 上，一個相似的快速且毫不費力的一鍵式清理方法可以試試 BleachBit 。

它是一個強大的工具，所以一定要注意你正在清理什麼。不要漫無目的地確認每個選項框；不是所有的東西它都可以清理。所以請合理地使用它，當你對某個選項有疑問時，就跳過它。

  • 從 Ubuntu 軟件中心裏安裝 BleachBit
