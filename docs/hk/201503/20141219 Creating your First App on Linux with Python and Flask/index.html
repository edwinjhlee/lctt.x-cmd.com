在Linux上使用Python和Flask創建你的第一個應用 ​

無論你在linux上娛樂還是工作，這對你而言都是一個使用python來編程的很好的機會。回到大學我希望他們教我的是Python而不是Java，這學起來很有趣且在實際的應用如yum包管理器中很有用。

本篇教程中我會帶你使用python和一個稱為flask的微型框架來構建一個簡單的應用，來顯示諸如每個進程的內存使用，CPU百分比之類有用的信息。

前置需求 ​

Python基礎、列表、類、函數、模組。HTML/CSS (基礎)。

學習這篇教程你不必是一個python高級開發者，但是首先我建議你閲讀 https://wiki.python.org/moin/BeginnersGuide/NonProgrammers 。

在Linux上安裝Python 3 ​

在大多數Linux發行版上Python是默認安裝的。下面的你命令可以讓你看到安裝的版本。

sh
[root@linux-vps ~]# python -V
Python 2.7.5

我們會使用3.x的版本來構建我們的app。根據Python.org所説，現在只對這個版本進行改進，而且不向後兼容Python 2。

注意: 在開始之前，我強烈建議你在虛擬機中嘗試這個教程，因為Python是許多Linux發行版的核心組件，任何意外都可能會損壞你的系統。

以下步驟是基於紅帽的版本如CentOS（6和7），基於Debian的版本如UbuntuMint和Resbian可以跳過這步，Pythonn 3應該默認已經安裝了。如果沒有安裝，請用apt-get而不是yum來安裝下面相應的包。

sh
[leo@linux-vps] yum groupinstall 'Development Tools'
[leo@linux-vps] yum install -y zlib-dev openssl-devel sqlite-devel bzip2-devel
[leo@linux-vps] wget https://www.python.org/ftp/python/3.4.2/Python-3.4.2.tgz
[leo@linux-vps] tar -xvzf Python-3.4.2.tgz
[leo@linux-vps] cd Python-3.4.2
[leo@linux-vps] ./configure
[leo@linux-vps] make
# 推薦使用 make altinstall 以覆蓋當前的 python 庫
[leo@linux-vps]   make altinstall

成功安裝後，你應該可以用下面的命令進入Python3.4的shell了。

sh
[leo@linux-vps]# python3.4
Python 3.4.2 (default, Dec 12 2014, 08:01:15)
[GCC 4.8.2 20140120 (Red Hat 4.8.2-16)] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>> exit ()

使用pip來安裝包 ​

Python有它自己的包管理去，與yum和apt-get相似。你將需要它來下載、安裝和卸載包。

sh
[leo@linux-vps] pip3.4 install "packagename"    
[leo@linux-vps] pip3.4 list
[leo@linux-vps] pip3.4 uninstall "packagename"

Python虛擬環境 ​

在Python中虛擬環境是一個放置你的項目的依賴環境的目錄。這是一個將帶有不同的依賴環境的項目隔離的好辦法。它可以讓你不用sudo命令就能安裝包。

sh
[leo@linux-vps] mkdir python3.4-flask
[leo@linux-vps] cd python3.4-flask 
[leo@linux-vps python3.4-flask] pyvenv-3.4 venv

要創建虛擬環境你需要使用“pyvenv-3.4”命令。上述命令會在venv文件夾的內部創建一個名為lib的目錄，這裏會安裝項目所依賴的包。這裏同樣會創建一個bin文件夾容納該環境下的pip和python可執行文件。

為我們的Linux系統信息項目激活虛擬環境 ​

sh
[leo@linux-vps python3.4-flask] source venv/bin/activate
[leo@linux-vps python3.4-flask] which pip3.4
~/python3.4-flask/venv/bin/pip3.4
[leo@linux-vps python3.4-flask] which python3.4
~/python3.4-flask/venv/bin/python3.4

使用pip安裝flask ​

讓我們繼續安裝第一個模組flask框架，它可以處理訪問路由和渲染顯示我們app的模板。

sh
[leo@linux-vps python3.4-flask]pip3.4 install flask

在flask中創建第一個應用 ​

第一步：創建你app的目錄 ​

sh
[leo@linux-vps python3.4-flask] mkdir  app
[leo@linux-vps python3.4-flask] mkdir app/static
[leo@linux-vps python3.4-flask] mkdir app/templates

在python3.4-flask文件夾中創建一個名為app的文件夾，它包含了兩個子文件夾“static”和“templates”。我們的Python腳本會放在app文件夾，像css/js這類文件會在static文件夾，template文件夾會包含我們的html模板。

第二步：在app文件夾內部創建一個初始化文件 ​

sh
[leo@linux-vps python3.4-flask] vim app/_init_.py
from flask import Flask
    
app = Flask(__name__)
from app import index

這個文件會創建一個Flask的新的實例，並加載我們存儲在index.py文件中的python程序——這個文件我們之後會創建。

sh
[leo@linux-vps python3.4-flask]vim app/index.py
from app import app

@app.route('/')
def index():
    import subprocess
    cmd = subprocess.Popen(['ps_mem'],stdout=subprocess.PIPE,stderr=subprocess.PIPE)
    out,error = cmd.communicate()
    memory = out.splitlines()    
        
    return

flask中的訪問路由通過“路由裝飾器”處理。它用於將一個 URL 綁定到函數。

sh
@app.route('/')
@app.route('/index')

要在python中運行shell命令，你可以使用Subprocess模組中的Popen類。

sh
subprocess.Popen(['ps_mem'],stdout=subprocess.PIPE,stderr=subprocess.PIPE)

這個類會使用一個列表作為參數，列表的第一項默認是可執行的程序，下一項會是參數，這裏是個另外一個例子。

sh
subprocess.Popen(['ls', ‘-l’],stdout=subprocess.PIPE,stderr=subprocess.PIPE)

stdout和stderr會相應地存儲命令的輸出和錯誤。你可以使用Popen的communicate方法來訪問輸出。

sh
    out,error = cmd.communicate()

要更好地用html模板顯示輸出，我會使用splitlines()方法，

    memory = out.splitlines()

關於subprocess模組更多的信息會在教程的最後給出。

第三步：創建一個html模板來顯示我們命令的輸出。 ​

要做到這個我們使用flask中的Jinja2模板引擎來為我們渲染。

最後你的index.py文件應該看起來像這樣：

    from flask import render_template
    from app import app
    
    def index():
     import subprocess
     cmd = subprocess.Popen(['ps_mem'],stdout=subprocess.PIPE,stderr=subprocess.PIPE)
     out,error = cmd.communicate()
     memory = out.splitlines()     
       
    return render_template('index.html', memory=memory)

現在在你的模板目錄下創建一個index.html模板，flask會自動搜索這個目錄下的模板。

[leo@linux-vps python3.4-flask]vim app/templates/index.html


Memory usage per process

{% for line in memory %}
    {{ line.decode('utf-8') }} 

    {% endfor %}

Jinja2模板引擎允許你使用 {{ … }} 分隔符來輸出結果，{% … %}來做循環和賦值。我使用“decode()”方法來格式化。

第四步：運行app ​

sh
[leo@linux-vps python3.4-flask]vim run.py
from app import app
app.debug = True
app.run(host='174.140.165.231', port=80)

上面的代碼會在debug模式下運行app。如果你不指定 IP 地址和端口，默認則是localhost:5000。

sh
    [leo@linux-vps python3.4-flask] chmod +x run.py
    [leo@linux-vps python3.4-flask] python3.4 run.py

我已經加了更多的代碼來顯示CPU、I/O和平均負載。

你可以在這裏瀏覽完整的代碼。
