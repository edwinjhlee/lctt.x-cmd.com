dupeGuru - 直接從硬盤中查找並移除重複文件 ​

簡介 ​

對我們來説，磁盤被裝滿是棘手問題之一。無論我們如何小心謹慎，我們總可能將相同的文件複製到多個不同的地方，或者在不知情的情況下，重複下載了同一個文件。因此，遲早你會看到“磁盤已滿”的錯誤提示，若此時我們確實需要一些磁盤空間來存儲重要數據，以上情形無疑是最糟糕的。假如你確信自己的系統中有重複文件，那麼 dupeGuru 可能會幫助到你。

dupeGuru 團隊也開發了名為 dupeGuru 音樂版 的應用來移除重複的音樂文件，和名為 dupeGuru 圖片版 的應用來移除重複的圖片文件。

1. dupeGuru (標準版) ​

需要告訴那些不熟悉 dupeGuru 的人，它是一個免費、開源、跨平台的應用，其用途是在系統中查找和移除重複文件。它可以在 Linux, Windows, 和 Mac OS X 等平台下使用。通過使用一個快速的模糊匹配算法，它可以在幾分鐘內找到重複文件。同時，你還可以調整 dupeGuru 使它去精確查找特定文件類型的重複文件，以及從你想刪除的文件中，清除某種文件。它支持英語、 法語、 德語、 中文 （簡體）、 捷克語、 意大利語、亞美尼亞語、俄語、烏克蘭語、巴西語和越南語。

在 Ubuntu 14.10/14.04/13.10/13.04/12.04 中安裝 dupeGuru ​

dupeGuru 開發者已經構建了一個 Ubuntu PPA (Personal Package Archives)來簡化安裝過程。想要安裝 dupeGuru，依次在終端中鍵入以下命令：

sudo apt-add-repository ppa:hsoft/ppa
sudo apt-get update
sudo apt-get install dupeguru-se

使用 ​

使用非常簡單，可從 Unity 面板或菜單中啓動 dupeGuru。

點擊位於底部的 + 按鈕來添加你想掃描的文件目錄。點擊 掃描 按鈕開始查找重複文件。

一旦所選目錄中含有重複文件，那麼它將在窗口中展示重複文件。正如你所看到的，在下面的截圖中，我的下載目錄中有一個重複文件。

現在，你可以決定下一步如何操作。你可以刪除這個重複的文件，或者對它進行重命名，抑或是 複製/移動 到另一個位置。為此，選定該重複文件，或在菜單欄中選定寫有“僅顯示重複”選項 ，如果你選擇了“僅顯示重複”選項，則只有重複文件在窗口中可見，這樣你便可以輕鬆選擇並刪除這些文件。點擊“操作”下拉菜單，最後選擇你將執行的操作。在這裏，我只想刪除重複文件，所以我選擇了“移動標記文件到垃圾箱”這個選項。

接着，點擊“繼續”選項來移除重複文件。

2. dupeGuru 音樂版 ​

dupeGuru 音樂版 或簡稱 dupeGuru ME，它的功能與 dupeGuru 類似。它擁有 dupeGuru 的所有功能，但它包含更多的信息列 （如比特率，持續時間，標籤等）和更多的掃描類型（如帶有字段的文件名，標籤以及音頻內容）。和 dupeGuru 一樣，dupeGuru ME 也運行在 Linux、Windows 和 Mac OS X 中。

它支持眾多的格式，諸如 MP3、WMA、AAC (iTunes 格式)、OGG、FLAC，以及失真率較少的 AAC 和 WMA 格式等。

在 Ubuntu 14.10/14.04/13.10/13.04/12.04 中安裝 dupeGuru ME ​

現在，我們不必再添加任何 PPA，因為在前面的步驟中，我們已經進行了添加。所以在終端中鍵入以下命令來安裝它：

sudo apt-get install dupeguru-me

使用 ​

你可以從 Unity 面板或菜單中啓動它。dupeGuru ME 的使用方法、操作界面以及外觀和正常的 dupeGuru 類似。添加你想掃描的目錄並選擇你想執行的操作。重複的音樂文件就會被刪除。

3. dupeGuru 圖片版 ​

dupeGuru 圖片版,或簡稱為 duepGuru PE，是一個在你的電腦中查找重複圖片的工具。它和 dupeGuru 類似，但獨具匹配重複圖片的功能。dupeGuru PE 可運行在 Linux、Windows 和 Mac OS X 中。

dupeGuru PE 支持 JPG、PNG、TIFF、GIF 和 BMP 等圖片格式。所有的這些格式可以被同時比較。Mac OS X 版的 dupeGuru PE 還支持 PSD 和 RAW (CR2 和 NEF) 格式。

在 Ubuntu 14.10/14.04/13.10/13.04/12.04 中安裝 dupeGuru PE ​

由於我們已經添加了 PPA，我們也不必為 dupeGuru PE 再次添加。只需運行如下命令來安裝它。

sudo apt-get install dupeguru-pe

使用 ​

就使用方法，操作界面和外觀而言，它與 dupeGuru，dupeGuru ME 類似。我就納悶為什麼開發者為不同的類別開發了不同的版本。我想如果開發一個結合以上三個版本功能的應用，或許會更好。

啓動它，添加你想掃描的目錄，並選擇你想執行的操作。就這樣，你的重複文件將被清除。

如果因為任何的安全問題而不能移除某些重複文件，請記下這些文件的位置，通過終端或文件管理器來手動刪除它們。

歡呼吧！
