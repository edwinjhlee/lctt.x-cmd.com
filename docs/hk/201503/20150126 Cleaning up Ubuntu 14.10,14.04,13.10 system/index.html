如何清理你的 Ubuntu 14.10/14.04/13.10 系統 ​

前面我們已經討論了如何清理 Ubuntu GNU/Linux 系統，這篇教程將在原有教程的基礎上，增加對新的 Ubuntu 發行版本的支持，並介紹更多的工具。

假如你想清理你的 Ubuntu 主機，你可以按照以下的一些簡單步驟來移除所有不需要的垃圾文件。

移除多餘軟件包 ​

這又是一個內置功能，但這次我們不必使用新得立包管理軟件(Synaptic Package Manager)，而是在終端中達到目的。

現在，在終端窗口中鍵入如下命令：

sudo apt-get autoclean

這便激活了包清除命令。這個命令所做的工作是： 自動清除那些當你安裝或升級程序時系統所緩存的 .deb 包(即清除 /var/cache/apt/archives 目錄，不過只清理過時的包)。如果需要使用清除命令，只需在終端窗口中鍵入以下命令：

sudo apt-get clean

然後你就可以使用自動移除命令。這個命令所做的工作是：清除那些 在系統中被某個已經卸載的軟件 作為依賴所安裝的軟件包。要使用自動移除命令，在終端窗口中鍵入以下命令：

sudo apt-get autoremove

移除不需要的本地化數據 ​

為達到此目的，我們需要安裝 localepurge 軟件，它將自動移除一些不需要的本地化數據（LCTT 譯註：即各種語言翻譯）。這個軟件是一個簡單的腳本，它將從那些不再需要的本地化文件和本地化聯機手冊( man pages ) 所佔用的空間中回收磁盤空間。這個軟件將在任何 apt 安裝命令運行時 被自動激活。

在 Ubuntu 中安裝 localepurge

sudo apt-get install localepurge

在通過 apt-get install 安裝任意軟件後， localepurge 將移除所有不是使用你係統中所設定語言的翻譯文件和翻譯的聯機手冊。

假如你想設置 localepurge，你需要編輯 /ect/locale.nopurge 文件。

根據你已經安裝的軟件，這將為你節省幾兆的磁盤空間。

例子：-

假如我試着使用 apt-get 來安裝 dicus軟件：

sudo apt-get install discus

在軟件安裝完畢之後，你將看到如下提示：

localepurge: Disk space freed in /usr/share/locale: 41860K

移除孤包 ​

假如你想移除孤包，你需要安裝 deborphan 軟件：

在 Ubuntu 中安裝 deborphan :

sudo apt-get install deborphan

使用 deborphan ​

打開終端並鍵入如下命令即可:

sudo deborphan | xargs sudo apt-get -y remove --purge

使用 GtkOrphan 來移除孤包 ​

GtkOrphan (一個針對 debian 系發行版本的 Perl/Gtk2 應用) 是一個分析用户安裝過程狀態並查找孤立庫文件的圖形化工具，它為 deborphan 提供了一個 GUI 前端，並具備移除軟件包的功能。

在 Ubuntu 中安裝 GtkOrphan ​

打開終端並運行如下命令：

sudo apt-get install gtkorphan

使用 Wajig 移除孤包 ​

Wajig是 Debian 包管理系統中一個簡單的軟件包管理前端。它將 apt、apt-cache、 dpkg、 /etc/init.d 中的腳本等 通過一個單一命令集成在一起，它的設計初衷是使用簡單和為它的所有功能提供豐富的文檔。

通過適當的 sudo配置，大多數（如果不是全部）的軟件包安裝和創建等任務可以通過一個用户 shell 來完成。Wajig 也適用於一般的系統管理。另外，一個 Gnome GUI 命令 gjig也被囊括在這個軟件包之中。

在 Ubuntu 中安裝 Wajig ​

打開終端並運行如下命令：

sudo apt-get install wajig

Debfoster --- 跟蹤你在安裝過程中的操作 ​

debfoster 將會維護一個列有被明確需要安裝的軟件包的列表，但不包括那些作為某個軟件的依賴而被安裝的軟件包。參數是完全可選的，你甚至可以使得在 dpkg 和/或 apt-get 每次運行之後馬上激活 debfoster 。

另外，你還可以在命令列中使用 debfoster 來安裝或移除某些特定的軟件包。那些後綴為 --- 的軟件包將會被移除，而沒有後綴的軟件包將會被安裝。

假如一個新的軟件包或 debfoster 注意到作為某個軟件包的依賴的軟件包是一個孤包，則 debfoster 將會詢問你下一步如何操作。若你決定保留這個孤包， debfoster 將只會進行記錄並繼續安裝過程；若你覺得這個軟件包不足以引起你的興趣，在 debfoster 詢問這個問題後，它將移除這個軟件包。進一步的，如果你的決定使得其他的軟件包變為孤包，更多的提問將會接踵而來。

在 Ubuntu 中安裝 debfoster ​

打開終端並運行如下命令：

sudo apt-get install debfoster

使用 debfoster ​

為了創建一個初始跟蹤文件，可以使用如下命令：

sudo debfoster -q

你總可以編輯 /var/lib/debfoster/keepers 文件，來定義那些你想留在系統中的軟件包。

為了編輯這個文件，可以鍵入：

sudo vi /var/lib/debfoster/keepers

要強制使 debfoster 去移除所有沒有被列在上面這個文件的軟件包，或安裝作為某些列在這個文件中的軟件包的依賴，它也同時會添加所有在這個列表中沒有被安裝的軟件包。若要根據這個列表來執行相關操作，只需執行：

sudo debfoster -f

若需要跟蹤你新安裝的軟件包，你需要時不時地執行如下命令：

sudo debfoster

xdiskusage -- 查看你的硬盤空間都去哪兒了 ​

圖形化地展示磁盤使用情況的 du。xdiskusage 是一個用户友好型的程序，它將為你展示你所有磁盤的使用情況。 它是在 Phillip C. Dykstra 所寫的 “xdu” 程序的基礎上設計的。做了一些修改以使得它可以為你運行 “du”命令，並顯示磁盤的剩餘空間，並且假如你想清晰地瞭解你的磁盤空間都去哪兒了，它還可以生成一個 PostScript 格式的名為 display.xdiskusage 的文件。

在 Ubuntu 中安裝 xdiskusage ​

只需使用如下命令：

sudo apt-get install xdiskusage

若你想打開這個應用，你需要使用如下命令：

sudo xdiskusage

一旦這個應用被打開，你將看到如下圖所示的界面：

Bleachbit ​

BleachBit 能快速地釋放磁盤空間並不知疲倦地保護你的隱私。它可以釋放緩存，刪除 cookie，清除 Internet 上網歷史，粉碎臨時文件，刪除日誌，丟棄你所不知道存在何處的垃圾。為 Linux 和 Windows 系統而設計，它支持擦除清理數以千計的應用程序，如 Firefox, Internet Explorer, Adobe Flash, Google Chrome, Opera, Safari 等等。除了簡單地刪除文件，BleachBit 還包括許多高級功能，諸如粉碎文件以防止恢復，擦除磁盤空間來隱藏被其他應用程序所刪除文件的痕跡，為火狐“除塵”，使其速度更快等。比免費更好，BleachBit 是一個開源軟件。

在 Ubuntu 中安裝 Bleachbit ​

打開終端並運行如下命令：

sudo apt-get install bleachbit
