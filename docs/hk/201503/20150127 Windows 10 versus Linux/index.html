Windows 10 VS Linux ​

前陣子 Windows 10 好像佔據了絕大部分頭條，甚至在一些Linux圈裏也是一樣。最具代表性的是 betanews.com 的 Brian Fagioli 説 Windows 10 已經為 Linux 桌面系統敲響了喪鐘，Microsoft 如今宣佈將為忠實的 Windows 用户免費提供 Windows 10，Steven J. Vaughan-Nichols 説這是一個最新的開源公司，然後 Matt Hartley 比較了 Windows 10 和 Ubuntu，Jesse Smith 從 Linux 用户的視角對 Windows 10 做出評估。

Windows 10，在 Microsoft 聲明説將免費提供給 Windows 7 及以上用户，這件事成為如今大家閒聊的熱門話題。在 Linuxland 這裏，也沒有被忽視。betanews.com 的 Brian Fagioli，一個自封的 Linux 粉絲，如今這樣説，“ Windows 10 把門徹底關上了。Linux 桌面元年將永遠不會到來，歇歇吧。”Fagioli解釋説 Microsoft 傾聽了用户的抱怨而且並不只是記錄一下，還更好地解決了這些問題。他説 Linux 錯失了由 Windows 8 不受歡迎以及巨大失敗帶來的機會。然後他總結，拜 Windows 10 所賜，處於邊緣地帶的我們只能接受一個“破碎的夢”。

不過，來自聞名的 Distrowatch.com 的 Jesse Smith 説 Microsoft 並沒有提供一個很明顯的下載方式，不過確實可行而且它也升級了。安裝程序非常簡單，除了分區功能很有限甚至有點嚇人。在最終啓動進入 Windows 10 後，Smith説界面佈局很“鬆散”，沒有 Win7 裏被很多人討厭的大量分散注意的元素，開始菜單又回來了，取消了歡迎屏幕。據Smith所説，還有一個很類似 Ubuntu 和 Android 的新的包管理程序，不過需要 Microsoft 在線賬户才可以使用。Smith的總結裏有這樣一條，“感覺 Windows 10 像是 Android 的早期 beta 版本，一個設計成時刻保持在線的消費者操作系統。而不像是一個我能用來完成工作的操作系統。”

Smith的完整文章裏比較了 Windows 10 和 Linux 的大量細節，不過 Matt Hartley 發表了一份實在的 Windows 10 vs Linux 的報告。他説兩者的安裝程序都很直觀和簡單，Windows 的雙啓動仍然沒那麼容易，Windows 默認提供了加密而 Ubuntu 只提供了配置選項。在桌面方面 Hartley 説 Windows 10 “糾結地丟棄了它 Windows 8 的根。”他覺得 Windows 10 的 Windows 商店比 Ubuntu 的漂亮很多，但是實在不喜歡通過“一切都是卡片”的方式來查看新安裝的應用。Hartley這樣總結，“首先是它將為大量 Windows 用户提供免費升級。這意味着大大降低了進入和升級門檻。第二，看起來 Microsoft 這次真的在全力以赴地傾聽他們的用户需求了。”

Steven J. Vaughan-Nichols 如今聲稱 Microsoft 是最新的開源公司；不僅因為它將發佈 Windows 10 的免費升級，而且 Microsoft 正在從一個軟件公司轉型為一個軟件服務公司。然後，據 Vaughan-Nichols 所説，Microsoft 需要開源來完成這次轉型。從Novell/SUSE開始，他們已經致力於這一塊兒好多年了。不僅如此，他們也發佈過開源軟件（不管什麼目的）。Vaughan-Nichols總結，“很多人不這麼認為，但是Microsoft——就是Microsoft——已經成為一家開源公司。”
