7 個我希望在 Ubuntu 22.04 LTS 看到的變化 ​

Ubuntu 22.04 即將面世。但是，你對它的發佈有什麼期望？在這裏，我分享一些我希望看到的東西。

隨着 Ubuntu 22.04 LTS 的到來，我們都在急切地等待着體驗 Ubuntu 22.04 引入的功能。

在沒有對 Ubuntu 22.04 進行全面親身體驗的情況下，我不能確定它是否令人印象深刻。但是，我確實對我想在 Ubuntu 22.04 中看到的東西有一些想法。

現在提出一些修改要求可能有點太晚了，但我還是希望能有最好的結果。

一些重點包括：

1、在所有的應用程序中保持一致的主題形象 ​

任何試圖在 Ubuntu 上安裝 KDE 應用的人都會知道，主題不一致的情況比比皆是。更糟糕的是，Libadwaita 的加入只會讓更多的應用程序顯得格格不入。

為了解決這個問題，我認為需要一個替代解決方案組合。

首先，默認採用 Ubuntu 的 Yaru 主題的定製 Libadwaita 將使幾乎所有為 Gnome 和 GTK 構建的應用程序再次保持一致。然而，這仍然不能解決 Qt/KDE 應用程序的問題。

對於這些，需要一個類似於 Kvantum 的解決方案。儘管 Kvantum 有點“難”，但我真的相信，一個有 Canonical（Ubuntu 的母公司）全力支持的解決方案能夠克服 Kvantum 所面臨的所有挑戰。

Ubuntu 的外觀和感覺是其決定性的特徵之一，關鍵是要在每個應用程序中保持這種外觀，以確保其視覺吸引力。

2、使用 GNOME 40 中引入的水平停靠區 ​

儘管有些激進，Gnome 40 是 Gnome 向未來的一次飛躍，有幾個令人興奮的功能。然而，這些創新的功能中有許多並沒有進入 Ubuntu 22.10。

其中最值得注意的是水平停靠區。對我來説，我發現它極大地提高了我的工作效率，因為我不必再像以前那樣把鼠標移到屏幕的左邊。我相信很多 Ubuntu 用户同意我的觀點，但是 Canonical 堅持認為左邊的位置是最好的。

我不是説他們應該把停靠區移到底部，這畢竟是 Ubuntu 的一個決定性特徵，只是給用户一個這樣的選擇而已。Ubuntu 在設置程序中已經有一個自定義“外觀”部分，所以我認為在那裏增加一個簡單的切換開關不會太難。

3、找回混合主題 ​

升級到 Ubuntu 21.10 後，我很失望地發現 混合主題選項消失了。雖然這只是個小問題，但我確實發現自己很懷念這個選項，並不斷地想辦法把它找回來。

我認為，讓用户有能力輕鬆地定製他們的桌面是很重要的，把這個選項帶回來對改善這個問題有很大的幫助。

我理解他們想擺脱它是因為 Ubuntu 和 GNOME 默認主題顏色的衝突。但是，我喜歡它原來的樣子。

4、改造後的軟件中心 ​

隨着 Canonical 不斷推動人們使用 snap 應用程序（一種與所有發行版兼容的通用打包格式），創建一個新的軟件中心將是有意義的。

雖然 Snap 商店已經存在，但它只是 Gnome 軟件的一個復刻，而它以其速度慢和 bug 多而出名。

隨着 Gnome 41 的發佈，這一點在一定程度上得到了緩解，儘管這些改進不太可能被包含在 Ubuntu 22.04 中。

如果有一個新的軟件中心誕生，或者現有的軟件中心得到重大改造，我將會很高興。

如果 Ubuntu 要推出一個新的應用程序商店，它可能會使用 Flutter 來構建，就像他們的新安裝程序。雖然我個人並不喜歡 Ubuntu 開始轉向 Flutter 的決定，但這將有助於確保其所有變體的一致性。

5、改進的自定義選項 ​

有些人喜歡保持簡單，而有些人則喜歡自定義選項來改變外觀/感覺。

Ubuntu 22.04 LTS 不需要引入任何瘋狂的東西，但是簡單地在默認情況下增加一些額外的控制，你可以在 GNOME 調整 中找到，應該可以做到這一點。

目前，外觀調整是相當有限的，我們可以使用更多的選項。

6、讓 Snap 應用程序少一些 ​

我知道，我知道。Snap 應用程序無處不在，而且它們與多個發行版兼容。但是，它們的速度也更慢，而且只能從專有的 Snap 商店安裝。

當然，你可以選擇 Flatpak 和預建的二進制文件。但是，Snap 的專有方式仍然是許多用户不喜歡的。

另一方面，Ubuntu 的原生 Apt 軟件包管理器 速度更快，而且有更多的應用程序可用。這導致了用户體驗的明顯改善，儘管這種改善在各發行版中並不連續。

不幸的是，Snap 實際上是由 Ubuntu 背後的同一個團隊開發的，所以刪除它是相當不可能的。

7、卸載應用程序的統一方式 ​

Ubuntu 在為終端用户提供便利方面有着很好的聲譽。

為了對抗 Linux 軟件包的碎片化，Ubuntu 能否引入一種輕鬆卸載應用程序的方法，無論是 Flatpak/Deb/Snap？

考慮到外面有各種各樣的軟件包，現在是時候讓我們有一個處理所有軟件包的單一解決方案了。

在 Ubuntu 22.04 LTS 中不太可能看到它的解決方案，但我希望在下一個版本中能做到！

總結 ​

很明顯，你可能不會看到所有這些期望的事情在下一個版本中發生。然而，即使 Ubuntu 22.04 LTS 在這個方向上做了一些努力，我們也有希望在未來的版本中看到它們。
