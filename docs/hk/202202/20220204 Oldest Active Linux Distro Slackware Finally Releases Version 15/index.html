最古老的活躍 Linux 發行版 Slackware 終於發佈了第 15 版 ​

帶着 Linux 內核 5.15 LTS 和 KDE Plasma 5.23 的最新改進，Slackware 15.0 已經來到。

歡呼吧！Linux 粉絲們會很高興地知道，傳奇發行版 Slackware 在很久之後發佈了一個新版本。或許你不知道，Slackware 上一個版本的發佈要追溯到 2016 年。

當開發者在去年（2021 年）2 月宣佈 Slackware 15.0 的計劃時，整個 Linux 社區都為此感到興奮。

從年初的 Alpha 版本開始，在過去的一年裏，開發人員在 Slackware Linux 15.0 的開發中取得了快速進展。經過一段時間後，他們發佈了其最後一個候選版本，但現在它發佈了！

讓我們來看看 Slackware 15.0 有哪些新內容。

Slackware 15.0 的新內容 ​

如前所述，Slackware 15.0 有許多變化。不要忘了，在最終發佈之前，它可是發佈了一個測試版和兩個候選發佈版（RC）。

如果你一直在關注我們的報道，早在去年 4 月份你就可能已經看到了我們的 測試版 報道。

在測試版 / RC 版中，還有一些東西沒有被披露。因此，在這裏，我們會介紹它的所有重要內容。

Linux 內核 5.15 LTS ​

Slackware 15 的主要亮點是增加了最新的 Linux 內核 5.15 LTS。這與我們在測試版中注意到的 Linux 內核 5.10 LTS 相比，有了很大的飛躍。

值得注意的是，Slackware 團隊在確定使用 Linux 內核 5.15.19 之前測試了數百個 Linux 內核版本。在發佈説明中提到：

在最終宣佈 Slackware 15.0 穩定版的過程中，我們在過去一年裏實際上構建了超過 400 個不同的 Linux 內核版本（相比之下，我們在開發 Slackware 14.2 時測試了 34 個內核版本）。在 Greg Kroah-Hartman 確認 5.15.19 版內核將獲得至少到 2023 年 10 月（很可能比這更久）的長期支持後，我們最終選擇了它。

如果你感到好奇，Linux 內核 5.15 帶來了一些更新，如增強的 NTFS 驅動支持和對英特爾 / AMD 處理器以及蘋果 M1 芯片的改進。它還增加了對英特爾第 12 代處理器的初步支持。

總的來説，有了 Linux 內核 5.15 LTS，對於這個最古老的活躍 Linux 發行版，你應該會得到良好的硬件兼容性。

Linux 內核提供了兩種版本，一種是帶驅動的，不需要 initrd；另一種是依靠 initrd 來加載內核模組。發行説明中提到了更多關於它的內容：

像往常一樣，內核提供了兩種類型：通用內核和巨型內核。巨型內核包含足夠多的內置驅動程序，在大多數情況下不需要 initrd 來啓動系統。通用內核需要使用 initrd 來加載掛載根文件系統所需的內核模組。使用通用內核可以節省一些內存，並可能避免一些啓動時的警告。我強烈建議使用通用內核以獲得最佳的內核模組兼容性。

KDE Plasma 5.23 和 Xfce 4.16 ​

談到 KDE，你應該會發現 KDE Plasma 軟件包更新到了 5.23，而 KDE 框架則更新到了 5.88 版本。

KDE Plasma 5.23 是 KDE 的 25 週年紀念版，包括了 UI 的改進，以及一系列細微的變化來改善用户體驗。

除此之外，Slackware 15 還配備了 Xfce 4.16 作為桌面環境選項之一。

對 PipeWire 和 Wayland 的支持 ​

作為 PulseAudio 的替代品，Slackware 15 加入了對 PipeWire 的支持。

而且，對於那些想擺脱 X11 的用户來説，對 Wayland 的支持也在這個版本中出現。

32 位支持 ​

因為 Slackware 是 適合 32 位系統的 Linux 發行版 之一，最新版本提供了特定的內核版本來支持它。

從技術上講，有 SMP 和非 SMP 內核，分別用於單核和多核處理器。

建議使用 SMP 內核以獲得更好的性能和內存管理，但是如果你的處理器比奔騰 3 還要老，非 SMP 內核應該會派上用場。

其他改進 ​

一些技術上的升級包括 GCC 編譯器升級到 11.2.0 版本。相當多的安全和錯誤也得到了解決。

公告上還説，開發人員正專注於將 Python 更新到 3.3.4 版本，以修復 Samba 的構建。

其他基本軟件包和應用程序，如網絡管理器、OpenSSH、Krita、Falkon 瀏覽器和 Ocular 也得到了升級。Mozilla Firefox 和 Thunderbird 也被更新到它們最新的可用軟件包。

如果你想獲得這個版本的所有技術細節，你可以查看 官方更新日誌。其它一些重要的內容包括：

  • 改進了 Slackware pkgtools，使軟件安裝體驗無障礙，消除了並行衝突。
  • Slackware 15 首次包括一個 make_world.sh 腳本，以幫助從源代碼重建整個操作系統。
  • 增加了更多的腳本，以方便重建安裝程序和內核包。
  • 拋棄了 Qt4，轉而使用 Qt5。
  • 增加了對特權訪問管理Privileged Access Management（PAM）的支持，以支持那些不支持影子shadow密碼的較新項目。

值得注意的是，你不能簡單地從 Slackware 14.2 升級。因此，最好是進行一次全新的安裝。

  • Slackware 15 x86_64： ftp://ftp.slackware.com/pub/slackware-iso/slackware64-15.0-iso
  • Slackware 15 x86_32： ftp://ftp.slackware.com/pub/slackware-iso/slackware-15.0-iso

無論是哪種情況，你都應該保留一份數據備份，如果你對使用新的 ISO 安裝不感興趣，可以嘗試按照 官方升級説明 來進行。

總結 ​

Slackware 是最古老的仍然活躍的 Linux 發行版，我很高興看到 Slackware 有了新的版本。

雖然它仍然推薦給有經驗的用户或手工愛好者使用，但最新的 Slackware 15.0 也支持 UEFI 和舊系統。如果你正在尋求冒險，並希望為你的桌面安裝一個獨特的 Linux 發行版，你可以試試 Slackware 15。
