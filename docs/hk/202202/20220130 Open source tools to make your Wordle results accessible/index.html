無障礙分享你的 Wordle 結果的開源工具 ​

分享你的 Wordle 結果是有趣的。嘗試這些開源技巧讓它們可以無障礙分享。

Wordle 似乎在社交媒體上到處出現。Wordle 是一個快速的文字遊戲，你可以每天玩一次，你可以很容易地通過社交媒體與朋友分享結果。

Wordle 的目的是猜測一個秘密單詞。要進行猜測，需要輸入一個單詞，然後 Wordle 在一個由彩色編碼的表情符號組成的網格中顯示你的猜測結果。綠色表示一個字母在正確的位置。黃色表示密語中包含該字母，但它在錯誤的位置。灰色表示該字母根本就不在這個詞中。

人們通過將產生的字母網格粘貼到社交媒體上來分享他們在遊戲中的進展，這很容易做到，因為這個網格只是 一組表情符號。然而，表情圖標和表情符存在無障礙問題。雖然它們很容易複製和粘貼，但對於生活在低視力或色盲的人來説，共享的結果可能很難看清。灰色、黃色、綠色的顏色對一些人來説可能很難區分。

受到與 Mike Lim 談話的啓發，我在互聯網上做了一些探究，發現了一些提示，包括一個幫助改善共享遊戲結果的無障礙性的開源項目。

使用一個開源的無障礙應用 ​

wa11y 應用 的使用很簡單。你可以在 這裏 找到 wa11y GitHub 項目。複製你的 Wordle 結果並將其粘貼到應用中，它就會將你的結果轉換為文字。

你可以簡單地勾選複選框來包含表情符號，以表示成功猜測，但該項目維護者不建議這樣做。輔助技術非常喜歡錶情符號，以至於它會讀取每一個表情符號。內聯地、全部讀取。儘管技術圈喜歡閲讀它們，但使用輔助技術的人可能會發現它很麻煩，並經常放棄有幾個以上的表情符號的信息。

提供無障礙圖片 ​

也許你不能使用 wa11y 應用，但仍然想確保你的結果是無障礙訪問的。你可以進行截圖，上傳圖片，並添加替代文本。你有幾種方法可以做到這一點：

  • 附上圖片，並在信息欄中寫上替代文本。
  • 附上圖片並深入到你的特定社交媒體應用的無障礙選項中，啓用替代文本並從那裏添加。開源社交網絡 Mastodon 默認啓用實際的替代文本。
  • @AltTxtReminder 是一個你可以關注的賬户，當你忘記時，它會提醒你為圖片添加替代文本。

如果你分享了默認結果，你總是可以選擇在表情符號之前添加替代文本。這樣，你的受眾就可以獲得文字信息，但在重複的表情符號變得繁瑣之前，可以中止信息的其餘部分。

總結 ​

Wordle 是最近互聯網上的一個熱門遊戲，所以在分享你的結果時，一定要記住無障礙分享。有一些使用開源技術的簡單方法可以使你的結果更容易與大家分享。
