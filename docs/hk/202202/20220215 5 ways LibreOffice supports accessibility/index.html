LibreOffice 支持無障礙輔助的 5 種方式 ​

試試 LibreOffice 中的這些無障礙功能之一。你可能會發現更好的或替代的方式來完成日常工作。

LibreOffice.org 是我首選的生產力套件，我在過去已經介紹了我如何將它作為一個 圖形化辦公套件 以及 終端命令 使用。

在這篇文章中，我想着重介紹 LibreOffice 如何支持使用無障礙輔助技術的人。

鼠標 ​

鼠標是一項重要的發明，但它並不是對每個人都同樣有效。例如，那些不能在屏幕上看到鼠標指針的人，或者不能在他們的桌子上實際操作鼠標的人，從鼠標中獲益不多。

為了考慮到人們與電腦互動方式的不同，你可以在沒有鼠標的情況下使用 LibreOffice。與應用中的大多數無障礙功能一樣，這個功能對任何人都有幫助。即使你自己是一個鼠標用户，有時你也不想把你的手從鍵盤上移開。能夠在“打字模式”下觸發特定的 LibreOffice 動作，對於忙碌的打字員來説真的很方便。

你可以使用 Alt 鍵和菜單名稱中的一個觸發字母來打開 LibreOffice 主菜單中的每一個項目。在默認情況下，你不會看到這些觸發字母，但當你按下 Alt 鍵時，它們就會出現。

要打開文件File菜單，按住 ALT+F。要打開格式Format菜單，按住 ALT+O。當菜單被打開後，你就可以釋放按鍵。

在你打開一個菜單後，該菜單中的每個項目都有一個觸發字母，或者你可以使用鍵盤上的箭頭鍵導航到該項目並按下回車。

要關閉一個菜單而不做任何事情，按 Esc 鍵。

不用鼠標就能改變一個字體 ​

LibreOffice 界面中的所有東西都可以從菜單中獲得，即使你認為它只是工具欄中的一個元素。例如，你通常可能會將鼠標移動到格式化工具欄來改變字體，但你也可以通過選擇文本，然後打開格式Format菜單並選擇字符Character來打開字符對話框來改變字體。你可以使用 Tab、箭頭 和 回車 鍵來瀏覽這個對話框。

這裏需要注意的是，你可以在一個應用中使用許多不同的路徑來達到同一個目標。每個場景都可能有不同的最佳路徑，所以在處理任務時不要想得太線性。

常見的快捷方式 ​

這裏有一些 LibreOffice Writer 的快捷鍵：

  • F2：公式欄
  • Ctrl+F2：插入字段
  • F3：自動文本
  • F5: 打開/關閉導航
  • Shift+F5：將光標移到上次保存文件時的位置
  • Ctrl+Shift+F5：打開導航，進入頁面
  • F7：拼寫
  • F8：同義詞

以下是電子表格的快捷鍵：

  • Ctrl+Home：返回到 A1 單元格
  • Ctrl+End：移到最後一個包含數據的單元格
  • Home：將光標移到當前行的第一個單元格
  • End：將光標移到當前行的最後一個單元格
  • Shift+Home：選擇從當前單元格到當前行的第一個單元格的單元格

LibreOffice 的文檔非常豐富，通過按鍵盤上的 Alt+H 或 F1 可以很容易地獲取。

無障礙設置 ​

關於更多的無障礙設置，請進入工具Tools菜單，選擇選項Options。在選項對話框中，在左邊的欄目中展開 LibreOffice 類別，然後點擊無障礙Accessibility。

選項包括：

  • 在只讀文本文件中使用文本選擇光標：這允許你在只讀文檔中移動，就像你可以編輯它一樣，限制了你實際可以做的選擇和複製文本。
  • 允許動畫圖像：不是每個人都希望在工作時在他們的文檔中出現移動的圖像。你可以在這裏進行調整。
  • 允許動畫文本：與圖像一樣，動畫文本樣式對一些人來説是有趣的，而對另一些人來説則是分散注意力或令人困惑的。

也有高對比度主題的選項。如果你在你的操作系統上使用高對比度模式，LibreOffice 會自動檢測並改變它的主題來匹配。

鍵盤快捷方式 ​

你可以通過設置自己的鍵盤快捷鍵來定製你與 LibreOffice 的交互方式。進入工具Tools菜單，選擇自定義Customize（或者直接按 Alt+T，然後按 C）。

選擇鍵盤Keyboard標籤，必要時按箭頭鍵或用鼠標點擊它（如果你還在使用鼠標）。

對所有人開放 ​

讓開源的應用無障礙化有利於所有的用户。通過嘗試 LibreOffice 中的無障礙功能，你可能會發現更好的或替代性的方法來完成日常任務。無論你是否“需要”該功能，無障礙功能提供了選擇。試試其中的一些，因為你可能會發現你喜歡的東西。如果你有一個 LibreOffice（或任何你喜歡的開源應用）似乎沒有提供的要求，在其錯誤跟蹤系統中提交一個功能請求來讓該項目知道。
