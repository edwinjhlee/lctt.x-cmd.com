Kile：來自 KDE 的交互式跨平台 LaTeX 編輯器 ​

Kile 是 Linux 上最好的 LaTeX 編輯器之一，來自 KDE。讓我們來看一看它提供了什麼？

你可以用 TeX/LaTeX 編輯器處理各種文件。不僅僅限於科學研究，你還可以添加你的代碼、開始寫書（學術/創作）、或者起草文章。

如果你經常處理 LaTeX 文檔，一個具有預覽選項和若干功能的交互式解決方案應該會很方便。

Kile 是 KDE 提供選擇之一，可用於 Linux 和其他平台。事實上，它是 可用於 Linux 的最佳 LaTeX 編輯器 之一，我們決定重點介紹一下它。

一個開源的集成 LaTeX 編輯器 ​

Kile 可能不是最受歡迎的選擇，但它確實因其提供的東西而脱穎而出。

如果你正在尋找一個簡單的 LaTeX 編輯器，它可能不是完美的選擇。然而，它盡力為你提供友好的體驗，同時從一開始就為你提供指導。

讓我重點強調以下特點。

Kile 的特點 ​

正如我提到的，Kile 是一個功能豐富的 LaTeX 編輯器。如果你是 TeX/LaTeX 文檔的新手，它可能會讓你不知所措，但它仍然值得探索。

其主要特性包括：

  • 設置嚮導可以輕鬆開始使用 LaTeX 編輯器。
  • 可用的模板可以節省文件大綱的時間。
  • 自動完成 LaTeX 命令。
  • 在不離開窗口的情況下，一鍵編譯和預覽你的文檔。
  • 上百種預設模式來定義文檔的類型（JSON、R 文檔、VHDL、HTML 等）。
  • 日誌查看器。
  • 轉換文檔的能力。
  • 添加/刪除和轉換 PDF 文件的 PDF 嚮導工具。
  • 反向和正向搜索功能。
  • 創建項目以組織文件集合。
  • 大量的 LaTeX 選項，無需鍵入任何東西即可添加所需的命令（如創建一個列表，添加一個數學函數等）。
  • 在各章或各節中輕鬆導航。
  • 使用小窗口預覽瀏覽整個文件（如果文件太大需要滾動）。

除了這些，你還可以配置外觀，調整鍵盤快捷鍵，找到各種編碼支持等。

此外，設置嚮導（以及應用內的其他嚮導）的存在使用户體驗變得輕而易舉。

在 Linux 中安裝 Kile ​

你應該可以在默認的 Linux 倉庫和軟件中心找到 Kile。對於 KDE，你應該看到它被列在“發現”中。

不幸的是，它不提供 Flatpak 或 Snap 包。所以，你將不得不依靠從倉庫中獲得的標準軟件包。

如果你依賴終端（基於 Ubuntu），你可以輸入以下命令安裝：

sudo apt install kile

對於 Windows 用户，你可以在 微軟商店 中找到它。

如果你感到好奇，你可以查看 源代碼 或訪問官方網站。

總結 ​

作為一個 LaTeX 用户，你應該發現所有這些選項對高效的編輯經體驗都很有用。如果你是 TeX/LaTeX 文檔的新手，你仍然可以使用它的模板、快速函數、自動完成功能，使體驗變得簡單。
