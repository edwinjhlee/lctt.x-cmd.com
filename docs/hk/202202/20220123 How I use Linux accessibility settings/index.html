我如何使用 Linux 的無障礙設置 ​

不同的 Linux 系統以不同的方式處理輔助技術。 這裏是一些對視覺、聽覺、打字等有用的設置。

當我在 20 世紀 90 年代開始使用 Linux 時，我已經 40 多歲了，無障礙性accessibility不是我非常關注的問題。然而現在，當我快到 70 歲時，我的需求已經改變了。幾年前，我從 System76 購買了一個全新的 Darter Pro，它的默認分辨率是 1920x1080，而且也是高 DPI。系統附帶了 Pop!_OS，我發現我必須修改它才能看到顯示屏上的圖標和文字。謝天謝地，桌面上的 Linux 已經變得比 90 年代更容易使用了。

我需要輔助技術，特別是在視覺和聽覺方面。還有一些我不使用的領域，但對需要幫助打字、指點、點擊和手勢的人來説是有用的。

不同的系統，如 Gnome、KDE、LXDE、XFCE 和其他系統，對這些輔助技術的處理方式不同。這些輔助性的調整大多可以通過 “設置Settings” 對話框或鍵盤快捷鍵來實現。

更多無障礙選項 ​

在 Fedora 35 上，無障礙訪問也是熟悉的。打開 “設置Settings” 菜單，選擇讓 “總是顯示無障礙菜單Always show Accessibility Menu” 圖標在桌面上可見。我通常會切換 “大字體Large Text”，除非我在一個大顯示器上。還有許多其他選項，包括 “縮放Zoom”、“屏幕閲讀器Screen Reader” 和 “聲音鍵Sound Keys”。這裏有一些：

有一些 Linux 發行版是專門為需要無障礙支持的人設計的。Accessible Coconut 就是這樣一個發行版。Coconut 基於 Ubuntu Mate 20.04，並默認啓用了屏幕閲讀器。它裝載了 Ubuntu Mate 的默認應用。Accessible Coconut 是 Zendalona 的作品，該公司專門開發自由開源的無障礙應用。他們所有的應用都是以 GPL 2.0 許可證發佈的，包括 iBus-Braille。該發行版包括屏幕閲讀器、各種語言的打印閲讀、六鍵輸入、打字輔導、放大器、電子書揚聲器等等。

Gnome 無障礙套件 是一個開源軟件庫，是 Gnome 項目的一部分，為實現無障礙功能提供 API。你可以通過訪問他們的維基來參與 Gnome 無障礙團隊。KDE 也有一個 無障礙項目 和一個支持該項目的 應用 列表。你可以通過訪問他們的 維基 來參與 KDE 無障礙項目。XFCE 也為用户提供了相關資源。Fedora 項目維基 也有一個可以安裝在操作系統上的無障礙應用的列表。

Linux 適合所有人 ​

自 20 世紀 90 年代以來，Linux 已經有了長足的進步，其中一個很大的進步就是對無障礙的支持。很高興知道隨着 Linux 用户的不斷變化，操作系統也可以和我們一起變化，並做出許多不同的支持選項。
