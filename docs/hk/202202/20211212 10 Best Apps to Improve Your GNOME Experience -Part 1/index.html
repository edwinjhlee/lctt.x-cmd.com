10 個提升 GNOME 體驗的最佳應用程序（一） ​

我們將給你詳細介紹 10 個最好的 GNOME 應用程序，它們可以幫助你在這個神奇的桌面上順滑地工作。

網上有數百個基於 GTK 的應用程序，它們大多沒什麼名聲，不那麼流行。這些應用程序被設計用來簡化你的 GNOME 桌面體驗，提供原生應用程序的感受。本系列文章的目的是為了提高這些應用程序的普及率，同時鼓勵更多的用户參與和開發。

在這個《最佳 GNOME 應用程序》的系列文章中，我們將重點介紹一些或已知道、或不知道的基於 GTK 的原生應用程序，它們是專門為 GNOME 增加功能設計的。

在這篇文章中，我們介紹了以下 GNOME 應用程序：

  • Geary - 電子郵件客户端
  • Notejot - 簡易筆記
  • Hydrapaper - 支持多顯示器的牆紙
  • Solanum - 番茄時鐘客户端
  • Cawbird - Twitter 客户端
  • News Flash - RSS 閲讀器
  • Fragments - BitTorrent 客户端
  • MetadataCleaner - 清潔各種文件的元數據
  • Kooha - 屏幕記錄器
  • Metronome - 節拍器

Geary - 電子郵件客户端 ​

當提到 Linux 桌面上的原生電子郵件客户端 時，大家想到的都是 Thunderbird。然而，如果你想在電子郵件客户端中獲得更多的原生感受，那麼你可以試試 Geary。Geary 是一個基於 GTK+ 的電子郵件客户端，它帶給你的功能包括對話視圖、郵件合併、只需兩步的輕鬆設置、支持 IMAP/SMTP、用於撰寫郵件的富文本編輯器以及許多很酷的功能。

你可以輕鬆地將其配置為你的默認電子郵件客户端，並用自定義配置選項來設置主要的電子郵件服務提供商，如 Gmail、雅虎、Outlook。

下面是你如何安裝它的方法。

  • 適用於 Debian/Ubuntu：sudo apt install geary
  • 適用於 Fedora 和相關發行版：sudo dnf install geary
  • 設置 Flatpak，然後 通過 Flathub 安裝

Notejot - 簡單筆記 ​

想要一個“超簡單”的 GNOME 記事本應用？那麼 Notejot 就是你正在尋找的應用程序。這款靈巧的記事應用程序以其精心製作的直觀的單窗口用户界面而顯得非常出色。這款應用程序帶來的功能包括多個筆記、筆記本功能、彩色筆記、標準文本格式等。這是一個完美的 GNOME 記事小程序。

Hydrapaper - 用於多顯示器的壁紙更換器 ​

這個 GTK 應用程序對於那些使用多顯示器的人來説是一個福音。當你把多個顯示器連接到一個系統時，所有的顯示器都會顯示相同的壁紙。但是如果你想在這些顯示器上顯示不同的圖片，那麼你可以使用這個叫做 Hydrapaper 的應用程序。這個 GTK 應用程序，很好地集成到了 GNOME 桌面，併為你提供了以下功能：

  • 預覽顯示器的 ID 和它們所顯示的內容
  • 添加你的圖片文件夾並在應用程序中瀏覽
  • 收藏選項可以快速選擇你最喜歡的一個壁紙
  • 五種壁紙模式（縮放、黑色背景的適合/居中、模糊背景的適合/居中）。
  • 隨機壁紙模式
  • 命令列選項，可以通過腳本來擴展它

下面是如何安裝這個應用程序。

  • 適用於 Debian/Ubuntu：sudo apt install hydrapaper
  • 適用於 Fedora 和相關發行版：sudo dnf install hydrapaper
  • Arch 用户可以在 設置 yay 後通過 AUR 安裝它：yay -S hydrapaper-git
  • 你也可以在 設置 好 Flatpak 之後，通過 Flathub 安裝

Solanum - 番茄時鐘客户端 ​

下一個 GNOME 應用程序叫做 Solanum，它是一個基於 番茄時鐘技術 的時間跟蹤應用程序。該技術是將你的時間分成 25 分鐘的小塊，間隔有 5 分鐘的休息時間，這被稱為一個“番茄Pomodoro”。4 個番茄之後，你可以休息更長時間。

這個應用程序可以幫助你做到這一點。Solanum 有一個非常簡單的用户界面，在一個帶有計時器的圈中顯示“番茄”。切換“開始/停止”按鈕幫助管理你的時間。這是一個非常有用的工具，特別是如果你在管理時間方面面臨困難。

Cawbird - Twitter 客户端 ​

Cawbird 是一個基於 GTK 的 Twitter 客户端，用於 GNOME 桌面。它是那個在 Twitter API 變化後停止使用的 Corebird 的一個復刻。這款應用非常適合你的 GNOME 桌面，並且擁有 Twitter 網站的所有功能。從資源上看，它是輕量級的。如果你是 Twitter 的忠實用户，那麼你可以試試這個應用。

以下是安裝步驟。

  • Ubuntu/Debian，請使用 openSUSE 提供的 預編譯 DEB 包
  • Fedora 及相關發行版：sudo dnf install cawbird
  • 對於 Arch Linux，你可以通過以下方式安裝它：pacman -Syu cawbird
  • 以 Flatpak 方式安裝
  • 以 Snap 方式安裝

News Flash - RSS 閲讀器 ​

News Flash 是最好的 GNOME 應用程序之一，用於閲讀你喜愛的網站的 RSS 提要。這個應用程序對你的 GNOME 桌面來説是完美的，因為它提供了很多功能。它能為你的新消息、未讀消息提供彈出式通知，支持深色模式等。下面是對其功能的快速總結：

也許最令人興奮的功能是能夠直接在應用程序本身內部閲讀文章，即使該 內容源feed 不提供完整文章。它會試圖從 URL 中獲取文本，並在應用程序窗口中顯示（沒有圖像）。

  • 集成了流行的內容源
  • 用 OPML 導入和導出內容源
  • 支持暗色模式
  • 讀者模式
  • 書籤、搜索、導出文章選項
  • 在設置中給你提供應用程序使用了多少磁盤空間來存儲內容源的詳細信息。

  • 如果你在 Arch Linux 中，你可以 設置 Yay AUR 助手，然後使用下面的命令來安裝：yay -S newsflash

Fragments 是一個簡單的 BitTorrent 桌面客户端，構建在 GTK 上。雖然我們已經有了 Transmission 這個完美的 BitTorrent 客户端，它有獨立的 GTK 和 QT 用户界面。但在 GNOME 桌面上有一個更簡單的 BitTorrent 客户端也無妨，對嗎？Fragments 有一個簡單的界面，符合 GNOME 設計準則，並提供了 BitTorrent 客户端所需的所有功能。它也支持磁力鏈。

MetadataCleaner - 從各種文件中清理元數據 ​

有沒有遇到過這樣的情況：你需要從文件中刪除某些信息，比如由誰創建，或者通過什麼軟件創建。例如，如果你有一張用 GIMP 創建的圖片，該文件包含一個默認的文本（除非你刪除它）：“由 GIMP 創建”。另外，圖片可能包含位置細節、時間戳、相機信息等等。而刪除這些信息需要一些特定的應用程序，並需付出額外的努力。

MetedataCleaner 應用程序就是做這個的。它可以幫助你從文件中刪除這些信息。當你用這個應用程序打開一個文件時，它會讀取並給你一個元數據的列表。你所需要做的就是點擊“清潔Clean”按鈕，然後你就有了清理過的文件。對於 GNOME 來説，這樣一個有用的工具。

Kooha - 屏幕錄像機 ​

如果你正在為 GNOME 桌面尋找一個快速而簡單的屏幕錄像機，那麼不妨試試 Kooha。這個應用程序是最好的 GNOME 應用程序之一，提供輕鬆的記錄體驗。這個工具支持硬件加速、定時器、多源輸入和許多高級功能。下面是功能摘要：

  • 可選擇多顯示器中任一顯示器或任何窗口
  • 硬件加速的編碼
  • 可選擇錄製屏幕的區域
  • 記錄麥克風和電腦的聲音
  • 記錄的延遲定時器
  • 支持 WebM、mp4、gif、mkv 文件類型
