Linux BitTorrent 客户端 Fragments 2.0 全新發布 ​

Fragments 2.0 的發佈使其成為 Linux 發行版中最方便用户使用的 BitTorrent 客户端之一。讓我們來看看有什麼新變化。

Fragments 是 Linux 上最好的 BitTorrent 客户端之一。

最新的 Fragments 2.0 是一個重大升級，它使用 Rust、GTK 4 和 Libadwaita 從頭開始完全重寫。

除了技術上的改進之外，你還會發現一些新的功能和改進的用户界面。

讓我重點介紹一下它的變化。

Fragments 2.0 的新變化 ​

最近，Gnome 應用程序的生態系統經歷了一些大規模的變化。在這個變化的最前沿是向 Gtk4 和 Libadwaita 的過渡。不幸的是，這種變化並不小，許多應用程序需要從頭開始重建，以支持這些新標準。

與許多其他應用程序開發者一起，Fragment 的開發者 Felix Häcker 決定從頭開始重建 Fragments，現在作為 Fragments 2.0 發佈。因此，我們現在得到了一個改進的 Linux 的 BitTorrent 客户端。

其中的一些改進包括。

  • 一個基於 Libadwaita 的漂亮的新用户界面
  • 新的模組化架構
  • 能夠被用作遠程 Fragments / Transmission 會話的遠程控制
  • 新的偏好對話框有更多的選項
  • 能夠查看有關網絡的統計數據

一個新的用户界面 ​

Fragments 2.0 現在有一個基於 Libadwaita 的新 UI。補充一句，Libadwaita 是 GTK4 對 Gnome 應用程序的一個擴展。它有幾個優點，最明顯的是在所有 Gnome 應用程序中具有一致的外觀。

它比舊的主題更加扁平和圓潤，我覺得，看起來非常時尚。

你可以得到一個外觀簡潔的 BitTorrent 應用程序，易於瀏覽，你也可以快速訪問一些基本的選項。

新的模組化架構 ​

雖然不能直接看到，但 Fragments 2.0 具有一個全新的模組化架構。在內部，該應用程序的所有不同部分都是模組化的。雖然這起初看起來沒有那麼大的影響，但我可以看到它對用户和開發者都有深遠的影響。

首先，它應該意味着更容易維護，希望能讓開發人員花更多時間在新功能和錯誤修復上。其次，它也應該意味着應用程序的更大穩定性。如果 Fragments 的一個部分崩潰了，應用程序的其他部分應該保持工作，希望不會對用户產生任何重大影響。

這只是我想到的這個新架構的兩個好處，我相信還可以有更多。

新的首選項對話框 ​

最後，Fragments 2.0 引入了幾個經常要求的設置選項。在這些選項中，我認為最重要的是能夠改變尚未完全下載的種子的默認文件夾。

雖然仍然不像它的一些替代品那樣可以定製，但這些新增功能可以幫助你調整設置以適應你的要求。

其中一些選項包括：

  • 添加種子後自動啓動它們
  • 啓用/禁用下載隊列
  • 可定製的對等體限制
  • 網絡端口設置
  • 自動端口轉發的切換

控制遠程 Fragments / Transmission 會話 ​

遠程控制你的下載的能力可以產生相當大的影響。隨着 Fragments 2.0，該應用程序終於獲得了類似的功能，允許用户遠程控制其他安裝的 Fragments 和 Transmission 客户端。

這對使用單獨的下載服務器的人來説非常有用，因為他們往往不能直接訪問它。

雖然這在其他應用程序中一直提供的，但這一功能被直接整合到 Fragments 中，使得它成為一個對高級用户有用的 BitTorrent 客户端！

其他改進措施 ​

除了所有這些大的變化之外，還有一些錯誤的修復和一些新的能力。

一些關鍵的亮點包括：

  • 添加的種子的磁力鏈可以被複制到剪貼板上
  • 可以查看關於當前會話的統計數據（速度、總下載數據等）

你可以在其 GitLab 頁面 上探索更多關於 Fragments 2.0 的信息。

下載 Fragments 2.0 ​

Fragments 是以 Flatpak 應用程序的形式提供的。如果你的 Linux 發行版沒有內置的支持，你可以通過我們的 Flatpak 指南 來設置 Flatpak。

  • Fragments（Flathub）

你可以嘗試在你的軟件中心搜索它（啓用 Flatpak 集成）或在終端鍵入以下命令：

flatpak install flathub de.haeckerfelix.Fragments

Fragments 2.0.1（有一些小的修正）也可以在其 GitLab 頁面上找到，但還沒有反映在 Flathub 上。

如果你在使用 Fragments 2.0 時有問題，你可能想等更新版本進入 Flathub。
