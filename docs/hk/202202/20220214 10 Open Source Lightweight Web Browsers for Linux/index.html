10 個適用於 Linux 的開源輕量級網頁瀏覽器 ​

有很多適用於 Linux 的網頁瀏覽器，其中很多都是基於 Chromium，但我們也有一個 不基於 Chromium 的瀏覽器 的列表。

最近，一位讀者要求推薦一款輕量級網頁瀏覽器，因此我專門做了一些快速實驗。以下是我的發現。

適用於 Linux 的輕量級網頁瀏覽器 ​

我沒有進行任何基準測試，因為可能適用於一個系統的東西可能不適用於其他系統。這篇文章是基於我的經驗和觀點。

還有一點需要注意的是，一些輕量級網頁瀏覽器的擴展功能可能有限。如果你依賴賬户同步等功能並使用大量的瀏覽器擴展，這些瀏覽器可能無法滿足你的需要。但是，你仍然可以嘗試使用其中一些作為你的輔助瀏覽器。

還有一件事！這不是一個排名表。排名第二的瀏覽器不應該被認為比排名第五的更好。

注意：

瀏覽器是通往很多東西的通道。你不應該使用一個不積極開發或僅由一個開發商維護的晦澀的網頁瀏覽器，尤其用於銀行和購物。在這種情況下，堅持使用主流瀏覽器，如 Firefox、Brave、Vivaldi、Chrome/Chromium 更好。

1、Viper（蝰蛇） ​

該瀏覽器專注於隱私、極簡主義和定製，已成為一個強大的輕量級瀏覽器，在這裏你可以進行你想要的一切搜索。在我看來，它是一個必不可少的瀏覽器，具有標籤休眠支持、安全自動填寫管理、全屏支持等基本功能。

這不是一個普通的瀏覽器，但如果你是一個極簡主義的粉絲，也許這個瀏覽器適合你。

  • 下載：Viper

2、Nyxt ​

“黑客的強力瀏覽器” 是 Nyxt 的官方網頁對它自己的描述；説實話，它很不錯。

儘管它不是唯一面向鍵盤的網頁瀏覽器；它的獨特之處在於，你可以在這個瀏覽器中覆蓋和重新配置每一個類、方法和函數。它也有一個內置的命令列工具。難怪它被稱為“黑客的強力瀏覽器”。

Nyxt 使用的是一個簡單的計算機編程環境，它接受單一的用户輸入，執行它們，並將結果返回給用户；就像最著名的 REPL（讀取-評估-打印循環） 一樣。

  • 下載：Nyxt

3、Lynx（猞猁） ​

我肯定會説這是為 命令列 愛好者準備的，因為這個神奇的瀏覽器可以讓你 從你的 Linux 終端上網。沒錯！你可以在你的終端中啓動它來輕鬆訪問互聯網。

當然，它消耗的資源更少，但你不應該指望獲得從 Firefox 或 Brave 等常規瀏覽器中相同的瀏覽體驗。

你知道嗎？這是一個最古老的網絡瀏覽器，它始於 1992 年，至今仍在維護。

  • Lynx

4、SeaMonkey（海猴） ​

這個是另一個多合一的導航器，但 SeaMonkey 包括什麼呢？SeaMonkey 增加了電子郵件客户端、網站內容源閲讀器、HTML 編輯器、IRC 聊天和網絡開發工具等特性，以及其他一些特性。

我想説 SeaMonkey 是 Firefox 的一個不可思議的復刻，就像 Librewolf。正如其網頁所説，它使用了許多與 Mozilla Firefox 相同的源代碼。

  • 下載：SeaMonkey

5、Waterfox（水狐） ​

説實話，當我在個人電腦上試用 Waterfox 瀏覽器時，我對它的性能和速度感到震驚。我是一個信奉極簡主義的人，我想這就是為什麼我這麼喜歡它。這個瀏覽器的一個了不起的特點是，它支持 Chrome、Firefox 和 Opera 的擴展。

因此，如果你想嘗試一個新的快速、安全的瀏覽器，而又不離開你最喜歡的擴展，Waterfox 將是一個完美的選擇。

  • 下載：Waterfox

6、Pale Moon（蒼月） ​

這是另一個基於 Firefox 代碼的網頁瀏覽器，具有隱私、安全、完全可定製和針對現代處理器優化等特點。對我來説，一個看起來很有趣的特點是，它繼續支持 NPAPI 插件，如 Silverlight、Flash 和 Java。這些插件在其他瀏覽器（如 Chrome 和微軟 Edge）中一直沒有得到維護。

在這種情況下，如果你喜歡的一些網頁因 Flash 等插件的停止維護而受到影響，也許 Pale Moon 可以讓它們重新恢復。

  • 下載：Pale Moon

7、Falkon ​

Falkon 是一個 KDE 瀏覽器，它與一個叫做 QtWebEngine 的技術一起工作，該技術提供了一個渲染引擎。它包括側邊欄中的書籤和歷史記錄等功能，並默認帶來了一個廣告攔截器，它可以幫助你防止來自網站的追蹤。

順便説一句，這個瀏覽器最初只是為了教育目的而開始開發的；但現在，你可以在你的日常生活中使用它。我邀請你嘗試它，並與我們分享你的經驗。

  • 下載：Falkon

8、Epiphany（頓悟） ​

這個導航器通常被稱為 “GNOME Web”，它是一個專注於 Linux 體驗的原生網頁瀏覽器，它有一個簡單的用户瀏覽界面。當然，簡單並不意味着功能不強。

它顯示網頁的技術類似於 Mozilla 項目中使用的佈局引擎，它最重要的一些特點是：

  • 可定製的用户界面
  • 有 60 多種語言版本
  • Cookie 管理
  • 用於執行命令、Python 腳本、分組標籤、選擇你的樣式表的擴展

如果你正在尋找一個簡單而簡約的瀏覽器，並且專門針對 Linux，那就是它了。

  • 下載：GNOME Web

9、Otter（水獺） ​

如果你還記得幾年前 Opera 12 的模樣，這個瀏覽器會讓你想起這個用户界面。這個瀏覽器的主要目的是為實驗用户提供強大的工具，而不影響他們繼續瀏覽。

我注意到的一些有趣和重要的事情是，社區對持續貢獻源代碼的承諾，以改進這個瀏覽器。

如果你在 Linux 中瀏覽時正在尋找一個快速、安全和強大的瀏覽器，這個是一個不錯的選擇。

  • 下載：Otter

10、Midori（日文的“翠綠”） ​

以前有一個流行的瀏覽器叫 Midori，但在它與 Astian 項目 合併後，它的發展方向發生了變化。然而，由於 Snap 商店的存在，你仍然可以在你的 Linux 發行版上安裝它。

它的三個最強大的功能是：

  • 支持 Adblock 過濾列表
  • 隱私瀏覽
  • 管理 Cookie 和腳本

但真正讓我震驚的是，它可以讓你瞬間打開 1000 個標籤，並能輕鬆創建網頁應用；這後兩個事實是來自 它在 Snapcraft 的頁面。

  • 下載：Midori

結論 ​

記住，找到完美的瀏覽器將取決於你的需要和資源。總的來説，這一切都要歸結為適合你的東西。

使用 輕量級應用程序 是當你的系統在硬件方面處於低水平時獲得更好的計算體驗的一種方式。

我避開了其他一些瀏覽器，比如 Brave 或 Vivaldi，因為我的重點是在 Linux 上不太流行的輕量級網頁瀏覽器。如果你知道還有一些你經常使用的瀏覽器，請在評論區提到它們。

如果這篇文章對你有幫助，請花點時間在社交媒體上分享；你也可以對開源有所作為。
