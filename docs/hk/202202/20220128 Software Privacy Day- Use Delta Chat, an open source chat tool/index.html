Delta Chat：一個開源的聊天工具 ​

最好的聊天應用是一個不屬於聊天應用的應用。

請考慮一下，當用户的數據被髮布到互聯網上，或通過互聯網發佈時，他們的數據究竟去了哪裏。古老的聊天應用是互聯網通信領域的一個手工行業，似乎在潮流中起起落落。人們使用聊天應用進行各種形式的對話，大多數人不會想到機器人正在記錄和監控他們所説的話，無論是為了有效地定位廣告還是隻是為了建立一個檔案供將來使用。這使得聊天應用特別容易受到不良的隱私做法的影響，但幸運的是，現在有幾個開源的、注重隱私的應用，如 Signal、Rocket.Chat 和 Mattermost。我運行過 Mattermost 和 Rocket.Chat，我也在使用 Signal，但我最興奮的應用是 Delta Chat，這個聊天服務非常方便，甚至不使用聊天服務器。相反，Delta Chat 使用的是你已經使用的最大規模和最多樣化的開放信息系統：它使用電子郵件，通過聊天應用發送和接收信息，並以 Autocrypt 的端到端加密為特色。

安裝 Delta Chat ​

Delta Chat 使用標準的電子郵件協議作為它的後端，但對於作為普通用户的你和我來説，它的外觀和行為完全像一個聊天應用。也就是説你需要安裝一個開源的 Delta Chat 應用。

在 Linux 上，你可以從 Flatpak 包或你的軟件庫中安裝 Delta Chat。

在 macOS 和 Windows 上，從 delta.chat/downloads 下載一個安裝程序。

在安卓系統上，你可以從 Play Store 或開源的 F-droid 倉庫 安裝 Delta Chat。

在 iOS 系統中，從 App Store 安裝 Delta Chat。

因為 Delta Chat 使用電子郵件來傳遞信息，所以如果你不在你的聊天應用中，你也可以在收件箱中收到信息。是的，即使沒有安裝 Delta Chat，你也可以使用 Delta Chat！

配置 Delta Chat ​

當你第一次啓動 Delta Chat 時，你必須登錄到你的電子郵件賬户。這往往是 Delta Chat 最難的部分，因為它要求你瞭解你的電子郵件服務器的詳細信息，或者在你的電子郵件提供商的安全設置中創建一個“應用密碼”。

如果你使用的是自己的服務器，並且所有配置都是默認的（993 端口用於 IMAP 接收，465 端口用於 SMTP 發出，啓用了 SSL/TLS），那麼你可以直接輸入你的電子郵件地址和密碼，然後繼續。

如果你運行自己的服務器，但你有自定義設置，那麼點擊“高級Advanced”按鈕，輸入你的設置。如果你使用一個不尋常的子域來用作你的郵件服務器，或一個自定義端口，或一個複雜的登錄和密碼配置，你可能需要這樣做。

如果你使用的是 Gmail、Fastmail、Yahoo 或類似的電子郵件供應商，那麼你必須創建一個應用密碼，這樣你就可以通過 Delta Chat 而不是網絡瀏覽器登錄到你的賬户。許多電子郵件供應商限制登錄，以避免無休止的機器人和腳本試圖用暴力手段進入人們的賬户，所以對你的供應商來説，Delta Chat 看起來很像機器人。當你授予 Delta Chat 特殊權限時，你就是在提醒你的電子郵件提供商，從一個遠程應用發出大量的短信息是預期的行為。

每個電子郵件提供商都有不同的提供應用密碼的方式，但 Fastmail（在我看來）是最簡單的：

  1. 進入“設置Settings”
  2. 點擊“密碼和安全Passwords & Security”
  3. 在“第三方應用Third-party apps”的旁邊，點擊“添加Add”按鈕

驗證你的密碼，並創建一個新的應用密碼。使用你創建的應用密碼登錄 Delta Chat。

使用 Delta Chat 聊天 ​

當你克服了登錄的障礙，剩下的就很容易了。因為 Delta Chat 只使用電子郵件，你可以通過電子郵件地址而不是通過聊天程序的用户名或電話號碼來添加朋友。從技術上講，你可以在 Delta Chat 上添加任何電子郵件地址。畢竟，它只是一個有特定使用場景的電子郵件應用。不過，告訴你的朋友 Delta Chat 是很有禮貌的，而不是期望他們通過他們的電子郵件客户端與你進行隨意的聊天。

無論你是在手機還是在電腦上運行這個應用，其外觀都與你所期望的聊天應用完全一樣。你可以發起聊天，發送消息，並通過加密文本與朋友閒聊。

開始聊天 ​

Delta Chat 是去中心化的、完全加密的，並依賴於一個成熟的基礎設施。多虧 Delta Chat，你可以選擇你和你的聯繫人之間的服務器，你可以在私下裏交流。沒有需要安裝的複雜的服務器，沒有需要維護的硬件。這是一個看似複雜問題的簡單解決方案，而且是開源的。我們有充分的理由去嘗試它。
