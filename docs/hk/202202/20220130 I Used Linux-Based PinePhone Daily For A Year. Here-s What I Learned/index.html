我的一年的 PinePhone 日常使用體驗 ​

它不是每個人的理想選擇，但作為一個 Linux 愛好者，我喜歡用它做實驗。

當 Pine64 在 2019 年發佈 PinePhone 時，沒有人能夠預見它將對移動 Linux、桌面 Linux 和隱私產生巨大的影響。

作為 少數專為運行桌面 Linux 而設計的手機 之一，它具有低端安卓手機的所有功能，同時又具有筆記本電腦的多功能性。不幸的是，桌面 Linux 就是這樣：它是為台式機設計的，而不是為手機設計的。

幸運的是，由於 GNOME、KDE、Pine64 和眾多 Linux 社區的驚人力量，全新的桌面環境、應用程序和發行版應運而生。其中一些比較知名的包括 Plasma Mobile、Phosh、Megapixels 和Mobian。

有了這些所有關鍵的部分，Pine64 需要做的就是銷售 PinePhone，他們確實也賣出了 PinePhone。每一輪社區版（每個都預裝了不同的發行版）的預購都收到了數千份訂單，其中之一就是我的。

自從我在 2020 年 12 月收到我的設備後，PinePhone 一直是我日常生活中的重要組成部分，我在 2021 年全年都把它作為我的日常設備。以下是我使用它的經驗。

它的性能就像糖漿一樣 ​

PinePhone 採用了全志 a64 系統芯片，它的功率只夠完成最基本的手機任務。即使是簡單的事情，如打開火狐瀏覽器，也需要將近 20 秒的時間，這無疑要“歸功於”它僅有的 4 個核心。這與現代中高端安卓手機形成鮮明對比，所有這些手機都有至少 2GHz 的 8 核處理器。

幸運的是，社區再次介入，對數以千計的小型軟件實施了優化。雖然性能仍然不如安卓系統的競爭對手，但這確實意味着 PinePhone 對於大多數手機任務來説是非常適用了，甚至在通過附帶的底座使用外部顯示器時，也可以使用一些面向桌面的應用程序。

即使它在這裏和那裏可能會有一點卡頓，PinePhone 在大多數情況下都有足夠的能力。但是電池呢？它真的能續航一整天嗎？

電池續航……沒問題 ​

雖然我很想説，由於 PinePhone 的低功耗組件，電池續航想必是超棒的。但不幸的是，情況並非如此，即使在實施了所有節電改進措施後也是如此。

經過一夜的充電，我通常在早上閲讀新聞，然後在午餐時間再讀一些。儘管這相當於不到一個小時的屏幕開啓時間，但電池仍然持續下降約 35%，使我在下午只剩下 65%。幸運的是，這並不是一個大問題，尤其是調製解調器的深度睡眠功能工作得很好。

補充一句，幾乎所有的移動電話都會將其調製解調器放入深度睡眠模式，這基本上是關閉一切除了接收電話和短信所需的功能。然後，當你接到一個電話時，調製解調器會喚醒自己和 SoC，然後開始響鈴。

根據我的經驗，PinePhone 上深度睡眠的實施絕對很棒，沒有錯過任何一個電話。因此，考慮到其糟糕的開屏續航時間，PinePhone 的關屏續航相當驚人。我在最少使用的情況下，電池壽命一直能保持在 60 小時以上，這是我的 Galaxy S20 FE 無法比擬的。

不要期望有什麼漂亮的照片 ​

PinePhone 僅有的 500 萬像素後置攝像頭和更小的 200 萬像素前置攝像頭，不要指望能拍出專業級別的照片。甚至許多 USB 網絡攝像頭也能提供更好的圖像質量，以及更多的常規功能。見鬼，PinePhone 的攝像頭甚至不能夠拍攝視頻！

它所做的少量後期處理確實有助於提升一點照片質量，儘管還不足以讓它們適合發到社交媒體上。作為比較，這裏是用 iPhone 4S（2011 年）和 PinePhone（2019 年）拍攝的同一張照片。

在古老的 SoC、普普通通的電池續航和可憐的相機之間，很明顯 PinePhone 的硬件絕對不是它的強項。但軟件能拯救它嗎？

桌面環境還是移動環境？ ​

在這個移動 Linux 的世界裏，主要有三種桌面環境領域，它們是：

  • Plasma Mobile
  • Phosh
  • Lomiri

在我日常使用 PinePhone 的過程中，我大約花了 4 個月的時間使用每個環境。在這段時間裏，我發現它們的功能、問題和成熟度各有不同，我會在這裏討論這些問題。

Plasma Mobile ​

早在 2015 年 Plasma 5 發佈之後，Plasma Mobile 已經默默地在後台開發了近 7 年。從最初的發佈到 PinePhone 的發佈，Plasma Mobile 背後的團隊成功地創造了一個相當可用的移動桌面環境。

然而，隨着 PinePhone 的發佈，這一切都改變了。困擾 Plasma Mobile 的許多錯誤已經被解決了，而且也在改進用户界面方面付出了巨大的努力。

作為一個 KDE 項目，Plasma Mobile 廣泛使用了 Kirigami，這導致了一個極其一致和移動友好的應用生態系統。此外，許多先前就有的 KDE 應用程序也能完美地擴展到該平台。

由於 Maui 項目剛剛發佈了他們的 Maui Shell，這個應用生態系統得到了進一步的擴展（更多信息即將發佈）。由於他們強大的實用程序套件，Plasma Mobile 是一個真正的安卓替代品。

然而，這並不是説 Plasma Mobile 是完美的。即使到了 2022 年，仍有一些殘餘的錯誤和問題。然而，這被其成熟的應用生態系統、對手勢的廣泛使用和對移動體驗的專注所抵消。

Phosh ​

Phosh 主要由 Purism 開發，是相當於 Plasma Mobile 的 GTK。它最初是為 Librem 5 打造的，自 2018 年以來一直在開發。由於只有 4 年的歷史，你可能會認為 Phosh 是不成熟的，但這與事實相差甚遠。

事實上，在超過 3 個月的時間裏，我從未遇到過 Phosh 的崩潰，相比之下，Plasma Mobile 沒幾天崩潰一次。當然，由於建立在 GTK 和其他 Gnome 技術之上，Phosh 有許多可用的應用程序。一些流行的應用程序可以完美地工作，包括：

  • Firefox
  • Geary
  • Headlines（Reddit 應用程序）
  • Megapixels（相機應用）
  • Gnome 地圖

此外，許多為 Plasma Mobile 設計的應用程序也能完美運行，儘管它們使用 Kirigami。不幸的是，雖然有許多 GTK 應用程序，但它們並不像 Kirigami 應用程序一樣適合各種環境，所以開發者必須專門使他們的應用程序與 Phosh 和 PinePhone 兼容。

此外，GTK 主要是一個面向桌面的 UI 工具包，這意味着諸如手勢等功能，甚至讓應用程序能夠適應屏幕的功能，充其量是零散的，最糟糕的是不存在。

不過幸運的是，Purism 在默認的 Gnome 應用程序中投入了大量的工作，這些應用程序都是完全可用的，而且速度很快。

總的來説，Phosh 是非常可靠的，特別是對於台式機和筆記本電腦上的 Gnome 用户。然而，它也因為缺乏核心的移動功能和優化的應用程序而受到阻礙。

Lomiri ​

我懷疑你是否聽説過它，因為它最近才改了名字。它以前被稱為 Unity 8，是 Ubuntu Touch 操作系統的默認桌面環境。它也可以在 Manjaro ARM 上使用。

由於使用 Qt Quick 構建，它可能是 PinePhone 最成熟的桌面環境。它很好地利用了手勢來實現核心系統功能，並且有大量專門為它製作的應用程序。

然而，它的缺點是隻能在 Ubuntu Touch 上使用，因為沒有一個應用程序被移植到 Manjaro。因此，它的用户受制於 Ubuntu Touch 的“鎖定”風格，類似於安卓和 iOS。

雖然這對典型的用户來説可能是件好事，但 PinePhone 的用户一般都是喜歡控制自己設備的手工愛好者，而 Ubuntu Touch 則使其變得更加困難。

操作系統 ​

與任何以 Linux 為主的設備一樣，它有大量的發行版和操作系統可用。在寫這篇文章的時候，Pine64 維基列出了 21 個單獨的操作系統，它們的完整度各有不同。

然而，在這些不同的操作系統中，有四個我在 PinePhone 上有很好的體驗：

  • Manjaro ARM
  • Mobian
  • SailfishOS
  • Ubuntu Touch

雖然我不打算詳細介紹它們，但它們都是很好的選擇，對於大多數任務來説都是完美的功能。除了 SailfishOS 之外，它們都是開源的，而 SailfishOS 大部分是開源的。

關於安卓應用程序的説明 ​

正如你現在可能已經猜到的，應用程序的支持可能有點問題。即使看到 PinePhone 上有近 400 個確認可以使用的應用程序，但與安卓和 iOS 的數百萬個應用程序相比，這也是相形見絀。

幸運的是，有一些方法可以解決這個問題，最簡單的是使用兼容層來模擬安卓應用。在這方面，Anbox 已經成為幾年來的首選。

Anbox ​

如果説 WINE 是 Windows 的兼容層，那麼 Anbox 對 Android 也是如此。安裝後，或打開它，因為它預裝在許多發行版中，就像運行一個命令來安裝一個 APK 文件一樣簡單。

從這裏開始，該應用程序的行為就像任何 Linux 應用程序一樣，儘管在性能上有很大的影響。

最近，有一羣人決定解決這個問題，創建了一個名為 Waydroid 的新項目。

Waydroid ​

Waydroid 是為 PinePhone 開發的安卓模擬器的最新嘗試，即使在這個早期階段，它看起來也非常有發展前景。由於安卓應用可以直接在硬件上運行，它的性能相當驚人，特別是與 Anbox 相比。

因此，許多極為流行的應用程序都能完美運行，如 F-Droid 和 Aurora 商店。

此外，通過 Waydroid 安裝的應用程序被很好地整合到 Linux 中，它們能夠像其他應用程序一樣被打開和關閉。

我對 PinePhone 的總體看法 ​

在我使用它的過程中，我花時間使用了幾乎所有可用於它的不同操作系統，以及每個桌面環境。正如我之前所説，它的性能一般都很差，儘管 Lomiri 和 Plasma Mobile 足夠流暢。

我不經常拍照，所以相機的使用頻率很低。然而，當我拍攝照片時，它們通常夠用了，即使相片質量並不特別高。

總的來説，我認為 PinePhone 的最大弱點實際上是它的電池續航。這是因為即使只是打開它查看一下時間，也會喚醒調製解調器，導致電池迅速耗盡，除非我儘量不打開它。

幸運的是，我總是確保隨身攜帶一塊備用電池，我可以通過取下後蓋換入。此外，我還可以插入一張 SD 卡，用作額外的存儲空間或測試新的操作系統。

正如預期的，PinePhone 並不防水，但我發現在雨中使用它似乎沒有任何損害，儘管你的經歷可能有所不同。當我在室內時，我經常發現自己會藉助它附帶的底座來使用它的外部顯示器。

在這種設置下，我對 PinePhone 作為一台筆記本電腦的能力感到驚訝。我經常發現自己可以在 LibreOffice 中編輯文件，甚至有一次還能用 Kdenlive 編輯了一段視頻！

總的來説，即使有一些不足，我與 PinePhone 相處的這一年也很順利，我從來沒有發現自己對安卓的渴望。

獲得 PinePhone ​

如果你想獲得一台 PinePhone，下面有一個按鈕，可以帶你到 Pine64 的網站。在寫這篇文章的時候，有兩種型號可供選擇，一種是 16GB 的存儲空間和 2GB 的內存。另一個型號有 32GB 的存儲空間和 3GB 的內存。（LCTT 譯註：應該是不向中國發貨的。）

本評論中使用的型號是 3GB 版本，價格為 199 美元。2GB 型號的價格為 149 美元。
