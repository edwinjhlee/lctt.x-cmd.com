Bottles：在 Linux 上輕鬆安裝 Windows 應用程序 ​

隨着最新發布的更新，Bottles 正在成為一個近乎完美的解決方案，無需任何特別的努力就可以在 Linux 上安裝 Windows 應用程序。

你可以 使用 Wine 在 Linux 上安裝 Windows 應用程序，但它並不適用所有的應用程序。此外，它還需要你手動配置東西。那麼，有什麼簡單的選擇呢？

雖然 CrossOver 一直在盡力使這個過程更容易，但還另一個解決方案：Bottles。

隨着 Bottles 的最新發布，它的目標是更加順滑地以最小的調整來運行你喜歡的 Windows 應用程序。

Bottles 2022.2.14 的新變化 ​

該版本帶來了一些新功能、改進和大量的錯誤修復。讓我強調一下以下關鍵變化：

安裝程序 ​

以下是開發者對新功能的介紹：

這些是由 Bottles 解釋的指令集，以重現程序的安裝。這個過程是由維護者寫在清單文件中的，他們能夠按照同樣的步驟安裝程序。

簡單來説，這些一鍵式安裝程序會自動安裝軟件，而不需要你手動調整什麼。這類似於 Lutris 幫助遊戲玩家安裝一個需要大量調整的遊戲。

目前只有不多的幾個安裝程序，主要是第三方遊戲啓動程序。用户如果想安裝像 Origin 這樣的程序，可以簡單地在他們的首選“瓶子”中進入安裝程序部分，點擊下載按鈕。（LCTT 譯註：“瓶子”指一個虛擬環境。）

開發人員還承諾，你可以期待很快有更多的安裝程序。

一個專門的應用程序商店 ​

為了展示可用的安裝程序，他們在其官方網站上推出了一個 應用商店。它包含了所有可用安裝程序的列表和必要的信息，如依賴性、配置和支持的架構。用户可以期待更多有用的功能，如評論功能很快就會到來。

需要注意的一點是，並不是所有的安裝程序都能完美無缺地工作。因此，開發者引入了一種叫做“等級”的東西，指的是安裝的程序的順利工作的程度。分級範圍從銅級到白金級，與 Wine 的兼容性評級方式非常相似。

用户可以放心，每個安裝程序至少都可以運行該程序並執行程序所需完成的主要功能。但除非安裝程序被評為白金級，否則用户應該對錯誤、圖形故障和崩潰的出現有所預期。此外，安裝程序也會與還原點一起工作。

新的搜索欄 ​

擁有多個“瓶子”的用户現在可以使用全新的搜索功能來尋找特定的“瓶子”。請注意，它在默認情況下是隱藏的，如果你至少安裝了 10 個“瓶子”，就會自動啓用。

我覺得，作為搜索欄的基本功能應該已經實現了，總比沒有強！

“瓶子”的自定義路徑 ​

以前，用户不能為“瓶子”設置自定義路徑。在這個版本中，用户可以在偏好部分中實現這一功能。如果用户的存儲空間不足，並計劃使用一個單獨的驅動器，這非常有幫助。

請注意，Flatpak 用户得專門為 Bottles 啓用權限，以訪問 Flatpak 環境之外的任何位置。你也可以試試 Flatseal 來管理 Flatpak 的權限。

改進和錯誤修復 ​

除了主要的功能升級外，還有一些有用的全面改進，一些值得強調的有：

  • 可用於非 Flapak 軟件包的運行環境，可通過首選項中的核心部分安裝。
  • 用户現在能夠使用內置的任務管理器終止正在進行的進程。
  • 用户還可以從位於上下文菜單中的終端中啓動程序。
  • 已經有了對 Gamescope 和 dxvk-async 組件的支持。

這個版本中也修復了各種基本的錯誤。其中包括 Flatpak 版本中游戲模式的修復，以及 DXVK 版本的改變，刪除了初始備份。

你可以參考他們的 官方發佈説明 來了解更多的技術細節。

總結 ​

Bottles 的目標是成為每個運行 Windows 軟件的 Linux 用户的必備應用。而且，有了所有這些改進，它看起來很有前景！
