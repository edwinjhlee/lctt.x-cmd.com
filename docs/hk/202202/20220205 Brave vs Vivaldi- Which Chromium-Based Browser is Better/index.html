Brave vs Vivaldi：哪個瀏覽器更好？ ​

毫無疑問，Brave 是一款出色的開源網頁瀏覽器。它也是 適用於 Linux 的最佳網頁瀏覽器 之一。

另一方面，Vivaldi 憑藉其強勁的自定義能力和標籤頁管理功能，在 Linux 用户羣中獲得了不錯的聲譽。

Vivaldi 是否值得一試？它開源嗎？為什麼你會更喜歡 Brave 而不是它？或者，是否應該考慮使用 Vivaldi 呢？

在此，我將解答上述所有問題，並對這兩款瀏覽器進行並列比較。

用户界面 ​

雖然這兩款網頁瀏覽器都是基於開源的 Chromium 代碼，但是它們提供了不同的用户體驗。

Brave 專注於提供簡潔的外觀，而 Vivaldi 則盡力提供更多的功能。

如果你不想受到過多幹擾，只想專心瀏覽網頁，那麼 Brave 應該能給你提供清爽的體驗。

不過，Brave 也為你提供了定製現有界面的選項，例如使用更寬的地址欄、顯示完整 URL、顯示標籤搜索按鈕、顯示或隱藏主頁按鈕等。

説到主題，Brave 默認提供了亮色和暗色兩款主題，同時也支持 Chrome 應用商店中的主題。

反觀另一邊，Vivaldi 默認情況下看上去似乎有點滿滿當當的 —— 能夠快速訪問的側邊欄、地址欄右邊的搜索框，再加上瀏覽器底部還有更多要素。

Vivaldi 默認也提供了更多主題。別忘了，你可以無縫地編輯、定製主題，而 Brave 可沒有這種功能。

對於那些想要一款簡潔明瞭，同時可以自定義的瀏覽器的人來説，Brave 就是合適的推薦項。而對於那些需要豐富的界面和大量設置項的用户來説，Vivaldi 是個不錯的選擇。

完全開源 vs 99% 開源 ​

Brave 是完全開源的，可以免費 / 自由使用。你可以在 GitHub 上查看它的源代碼，如果需要的話還可以復刻Fork一份代碼以用於實驗和測試。

Vivaldi 的話，呃……只能説是幾乎開源。整個瀏覽器基於 Chromium 開發，而修改過的 Chromium 源代碼可以在它的官網中找到。不過，這款瀏覽器的用户界面卻是專有的。

為確保提供獨特的用户體驗，並保持對它的控制權，Vivaldi 決定將用户界面閉源。

不過，他們在一篇 博文 中解釋得很清楚。

標籤頁管理 ​

對於大多數用户來説，這可能不算是一個比較標準，但考慮到 Vivaldi 以其標籤頁管理功能而著名，因此這一點仍舊值得比較。

在你打開了許多標籤頁時，標籤頁管理就會大有用場。如果你只開了少量的標籤頁，那你不需要同時考慮標籤頁管理，但它仍舊十分有用。

有了 Vivaldi，你可以體驗兩級堆疊標籤欄，同時還可以擁有多個堆疊標籤組。你還可以將標籤欄從瀏覽器的頂部移動到左、右、底部。

標籤的默認行為都可以修改。緊湊標籤組可以修改為摺疊式，標籤寬度可以更改，按鈕可選擇顯示或隱藏，還有許多配置項。

Brave 同樣可以分組標籤、指定顏色、命名標籤組，以及展開、摺疊標籤組，以便管理。

不過，在 Brave 裏就沒有 Vivaldi 那樣的兩級標籤欄，以及自定義標籤行為的功能。

此外，我個人認為 Brave 的標籤管理（在開啓暗色模式時）看上去有點混亂不堪。

當然，你可以決定新標籤頁展示什麼內容，但這遠遠不及 Vivaldi 大量選項那麼有用。

所以，在標籤頁管理這一方面，Vivaldi 明顯完勝。不過，一切仍取決於你的實際需求。如果你不在多個標籤頁中反覆橫跳，那你其實也不需要什麼額外的東西。

其他功能 ​

兩款瀏覽器都提供了所有基本功能，但你仍舊可以發現許多區別。

Brave 支持 IPFS 協議，你也可以使用 Brave 獎勵功能，並通過由 Brave 提供的尊重隱私的廣告來獲取獎勵。這些獎勵可作為贊助費用，以支持網站的創作者。這些獎勵同樣也可以用於購買來自合作伙伴的 Brave 周邊。

Brave 搜索是 Brave 瀏覽器的默認搜索引擎。雖然這款搜索引擎並非開源，但 Brave 搜索所帶來的功能足以使其成為其他隱私保護型搜索引擎的適當替代品。

來到 Vivaldi 這邊，它提供了大量額外功能，包括側邊欄的 Web 面板、番茄鍾、頁面平鋪、日曆集成、電子郵箱集成、RSS 訂閲等。

側邊欄（或者叫 Web 面板）允許你快速訪問內容，不需額外新建標籤或窗口，讓你輕鬆進行多任務處理，而不會失去對當前活躍標籤的專注。

當然，它還有內置的翻譯功能，讓你能在不懂網站的語言時擺脱谷歌翻譯。

除了這些功能以外，Vivaldi 允許你修改鍵盤快捷鍵、鼠標手勢，以及大量快捷命令。在 Brave 裏可沒有這些東西。

因此，我認為 Vivaldi 對於喜歡鍵盤快捷鍵的人來説是一個不錯的選擇。

隱私一角 ​

Vivaldi 專注於提供隱私友好型網絡體驗，就和 Brave 一樣。它內置了原生的廣告 / 跟蹤攔截保護，以及專門用於自行調整體驗的隱私設置。

就如上方的截圖那樣，你可以選擇啓用或禁用谷歌的安全服務，隱藏輸入歷史，修改歷史記錄的存儲行為，並修改默認的網站權限。

Brave 同樣給你類似的控制級別，當然也有更高級的設置項，比如修改 WebRTC IP 處理政策，以及消息推送服務控制。

如果你單純想要攔截跟蹤器和廣告的功能，那麼兩款瀏覽器都有。不過，如果你更擔心某項特定需求，那你可以試着查看它們的設置項，然後自行決定。

性能 ​

一如既往，我藉助一些知名的基準工具來測試瀏覽器的性能，例如：JetStream 2、Speedometer 2.0 和 Basemark Web 3.0。

我使用 Pop!_OS 21.10 作為我的 Linux 發行版，而測試的瀏覽器版本為 Vivaldi 5.0.2497.51 穩定版 和 Brave 97.0.4692.99。

在這些基準跑分測試中，Brave 總體更快，但 Vivaldi 在 Speedometer 2.0 中得分更高。

作為參考，我後台沒有運行任何程序，只運行了瀏覽器。電腦配置為 英特爾 15-11600K @4.7GHz、32GB 3200 MHz 內存、英偉達 1050Ti 顯卡。

因此，兩款瀏覽器都應該能帶來快速、便捷的網絡體驗。

安裝 ​

Vivaldi 在它的 官網 提供了最新的 DEB/RPM 軟件包，而且同樣支持 ARM 設備。不過目前穩定版本的 Vivaldi 暫時不提供 Flatpak 和 Snap 版本。

另一邊，Brave 並沒有直接在官網提供這些軟件包。你必須 在終端中輸入一組命令 以安裝 Brave，至少這是官方推薦的安裝方式。

你也能下載 Snap 版軟件包，但這並非是最佳方法，官方也承認有許多問題存在。

但無論如何，你都可以查閲我們的 在 Fedora 上安裝 Brave 的指南 以獲得幫助。

最終結論 ​

如果説到開源瀏覽器，那 Brave 佔絕對優勢，畢竟它是完全開源的。不過，Vivaldi 對於隱私型網絡體驗的承諾，以及對 Linux 平台的重視，反而更具吸引力。

從功能上看，Vivaldi 的標籤頁管理功能已經是極具競爭力的選擇，它可以幫助你在大量標籤中更加遊刃有餘。

需要注意的是，Vivaldi 的雙顯示器體驗似乎不太友好（至少在我這邊是這樣的）。目前來看，Vivaldi 在我的雙顯示器環境下出現卡頓，甚至無響應，但在單顯示器上從來沒有這種情況。

而 Brave 就沒有這種問題。因此，建議你自行測試一下。

Brave 提供簡潔和快速的體驗，Vivaldi 則更適合那些喜歡更多自定義配置和豐富界面的用户。

考慮到 Vivaldi 標籤頁管理功能確實能省下不少時間，我會選擇 Vivaldi，不過我最後還是換回了 Firefox，至少等到 Vivaldi 能夠在雙顯示器環境下流暢運行。

你又會選擇哪款呢？歡迎在評論區留言，讓我瞭解你的想法。
