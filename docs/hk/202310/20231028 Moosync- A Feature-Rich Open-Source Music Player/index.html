Moosync：一款充滿特色的開源音樂播放器 ​

Moosync 音樂播放器是一個適用於本地收藏與流媒體音樂的魅力十足的跨平台應用。

想聽好音樂嗎？🎶

首次亮相的跨平台開源音樂播放器 Moosync ，希望成為“歡迎全社區參與”的音樂播放器。

過去我們曾介紹過像 Harmonoid 和 MusicPod 這樣的應用，但是它們主要是專注於離線使用。

與之不同的是，Moosync 的獨特之處。讓我告訴你為什麼。

Moosync：概況 ⭐ ​

Moosync 是一個主要基於 Vue 和 TypeScript 編程語言開發的音樂播放器。

Moosync 高度可定製且支持 YouTube、Spotify 以及 LastFM 等多種服務。其關鍵特性包含：

  • 支持顯示歌詞
  • 無廣告播放
  • 支持本地音樂文件

初次體驗 👨‍💻 ​

在我在我的 Ubuntu 系統上安裝它之後，我開始了快速設置嚮導。

首先設定我的音樂庫的位置，它將會從此處獲取本地音樂文件，過程包含了許多步驟。

然後，顯示了可以連接的服務選項。

我試圖連接我的 Spotify 賬户，然而儘管我向 Moosync 提供了需要的信息，操作無法成功。不過幸運的是，這一步並非必要，所以我選擇跳過。

隨後，它顯示了空白的 “所有歌曲All Songs” 標籤頁，由於目前我未連接任何服務或者本地文件，所以這裏是空的。

考慮我沒有本地音樂或 Spotify 音樂，我點擊了 YouTube 過濾器並搜尋我喜歡的曲目以填充 Moosync。

搜索功能還包括歌曲、藝術家、播放列表和專輯的過濾器。

我可以以右鍵點擊單曲，並添加至播放隊列或者立即播放。除此之外還有其他選項，會有所不同。

我在 Spotify 資料庫進行搜索時，嘗試做相同操作，但不幸的是，我必須要登錄 Spotify 才能在 Moosync 使用它 這一計劃之前被擱置。

📋 如果你在尋找更好的 Spotify 支持，我建議你嘗試一下 BlackHole 這個音樂應用。

而我選擇繼續，去瞭解這個音樂播放器。進入 “隊列Queue” 標籤頁或者點擊應用程序右下角向上指向的箭頭都可以訪問它。

整齊的佈局使人感到熟悉和舒適。

在 “所有歌曲All Songs” 標籤頁，我添加進 Moosync 的所有歌曲都在這，我可以選擇從列表開頭播放，或者添加到當前隊列，甚至可以在其中隨機播放 100 首歌曲。

在 “播放列表Playlists” 標籤頁，我保存的所有來自 YouTube 的播放清單都在這。它還提供了本地文件和 YouTube 間的排序選項。

在 “專輯Albums” 標籤頁，我保存的所有專輯都以一個整齊的網格佈局排列。

類似的，“藝術家Artists” 標籤頁展示了我添加到 Moosync 庫的藝術家。出於某種原因，它沒有加載縮略圖。

“類別Genres” 標籤頁我也跳過了，因為它似乎不能正常工作。

最後是 “探索Explore” 標籤頁，這裏顯示了我聽過多少分鐘的音樂。

此外，你可以在 Moosync 中找到許多有用的自定義設置來優化你的使用體驗。

首先在 “主題Theme”設置中，你可以在三個主題和兩種佈局視圖中選擇，還有選項上傳或設計自定義主題。

應用還有許多擴展，一種是在 Discord 上開啓豐富的存在支持，另一種是與 Soundcloud 集成，此外還有很多。

顯然，Moosync 支持鍵盤快捷方式，你可以根據個人的喜好進行設置。

在我寫這篇文章的時候，Moosync 這裏和那裏都有一些小瑕疵，但我認為它作為 最適合 Linux 的音樂播放器之一 的競爭者非常有競爭力。

📥 下載 Moosync ​

Moosync 適用於 Linux，Windows 以及 macOS。你可以在其官方網站下載你需要的安裝包。

Moosync

對於 Linux 用户，你也可以在 Flathub 商店，Snap 商店 和 AUR 下載 Moosync。

你還可以瀏覽他們的 GitHub 倉庫，獲取源代碼以及更多信息。
