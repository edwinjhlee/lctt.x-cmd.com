Geany 2.0 發佈使其成為更通用的文本編輯器和 IDE ​

Geany 2.0 帶來了新的文件類型和其他改進。

Geany 被認為是 Linux 上最好的 Python IDE 之一，它是一個基於 GTK3 工具包的開源、輕量級 IDE。

考慮到 Geany 的功能集對各種用户的吸引力，它也可以算作 Linux 上 Notepad++ 的替代品之一。

現在，新版本已以 “Geany 2.0” 的形式推出，提供了許多改進。

讓我們看看有什麼。

🆕 Geany 2.0：有什麼新變化？ ​

Geany 版本的亮點可以分為兩個不同的部分，主要涵蓋界面和對文件類型的更好支持。

文件類型升級 ​

通過更新 基本類型，改進了 Kotlin 的文件類型配置。同樣，對於 Python ，針對 Python 3 重寫了標準庫標籤創建腳本，並改進了對 ctags 文件格式的支持。

最後，Geany 添加了對 AutoIt 和 GDScript 等新文件類型的**支持，並更新了 Nim 和 PHP 的文件類型配置，以解決一些長期存在的問題。

界面改進 ​

Geany 2.0 在文檔列表的側邊欄中提供了新的樹視圖。它是默認啓用的，因此你無需執行任何操作。

當你有大量單獨的文件需要檢查時，它非常實用。你還可以摺疊特定文件夾以最大程度地減少混亂。

編譯器消息現在使用深色主題友好的顏色，以便你可以輕鬆閲讀消息。這在深夜編碼時應該很有幫助。

此外，一個新的確認對話框添加到整個會話的“搜索和替換”功能中，並且添加了一個選項以在符號樹中顯示符號，而無需類別組。

🛠️ 其他變化 ​

除了上述內容之外，還有一些值得注意的變化：

  • Geany 現在需要 GTK 3.24。
  • 你現在可以滾動文檔選項卡。
  • 更新了多種語言的翻譯。
  • 修復了文件類型更改時的關鍵詞着色問題。
  • 現在默認啓用“更改歷史記錄”功能。

有關此版本的更多詳細信息，你可以瀏覽官方發行説明。

📥 下載 Geany 2.0 ​

由於它是 跨平台 IDE，Geany 2.0 可用於 Linux、Windows 和 macOS。你可以前往 Flathub 商店或其 官方網站下載你選擇的包。
