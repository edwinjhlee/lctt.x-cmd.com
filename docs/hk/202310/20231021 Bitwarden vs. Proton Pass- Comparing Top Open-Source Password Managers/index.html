Bitwarden 與 Proton Pass：頂級開源密碼管理器的比較 ​

你最鍾愛哪一個開源密碼管理器？

Bitwarden 和 Proton Pass 是兩個傑出的開源密碼管理器。

Bitwarden 已經成為一個可靠的選擇，運行穩定已經超過六年了，而 Proton Pass 則是較新的參與者。

你應該選哪一個呢？是選擇已被大眾信任的密碼管理器還是選擇由以隱私為導向的 Proton 新開發的產品?

我一直使用 Bitwarden 和帶高級特性的 Proton Pass。主要使用的是 Bitwarden，但自 Proton Pass 推出後我也在試用它。

在這裏，我會分享我對兩者的使用體驗，以及在選擇密碼管理器時需要了解的一些注意事項。

應用場景和應用程序的可用性 ​

選用密碼管理器時，應用程序的可用情況和你的使用場景起着重要角色。

你需要提些問題給自己：

  • 我在哪些地方（如桌面、移動設備或網頁瀏覽器）需要密碼管理器？
  • 它有提供哪些額外功能？
  • 是否堅持使用一個服務滿足多種功能需求？

我會在文章的後半部分詳細闡述這些功能特性。但首先，你需要確定你想在哪裏使用密碼管理器，以及是否希望單獨保持密碼管理器服務。

Proton Pass ​

在編寫本文時，Proton Pass 僅以 瀏覽器擴展 形式存在，同時提供給 移動平台 使用。

你可以為 Mozilla Firefox、Google Chrome、Brave、Edge 及其它基於 Chrome 的瀏覽器獲取擴展。你也可以選擇在你的 安卓或 iOS 設備上安裝它。

✅ 如果你不需要桌面應用的密碼管理器，同時希望繼續使用 Proton 提供的全部服務，那麼 Proton Pass 是一個適合的選擇。

Bitwarden ​

反之，Bitwarden 可以作為 桌面應用，支持在 Windows、 macOS、Linux 上運行。

此外，你可以為 Google Chrome、Firefox、Vivaldi, Opera、Edge、Tor 和 DuckDuckGo for Mac 獲取相應的擴展。

對於移動平台來説，Bitwarden 支持 iPhone、Apple Watch 和安卓手機。你也可以從 F-Droid 安裝到安卓設備上。

還不僅限於這些，你可以將 Bitwarden 作為一款 網頁應用，或通過 命令列接口 來使用。

✅ 如果你需要一個能夠在多個平台上無縫使用的密碼管理器，那麼 Bitwarden 就是你完美的選擇。

用户體驗 ​

Bitwarden ​

Bitwarden 的用户體驗簡潔且低調。

以下是瀏覽器插件的界面樣式：

雖然用户界面隨着年份的推移有所改進建，但始終忠於其核心理念，也就是 注重簡潔而不是華麗的 UI。

它不會打擾你的操作，始終提供熟悉的用户體驗。

你可以在預設的 “dark”、“light”、“solarized dark” 和 “nord” 主題間自由切換。

無論你正在使用桌面應用、移動應用還是瀏覽器擴展，它都能給你帶來同樣的便利。

Proton Pass ​

Proton Pass 在其佈局方面 頗具特色 ，每次你訪問該擴展時，它都會給出一個詳細的憑證概覽。

有些用户可能更傾向於 現代化的 UI 處理方式，這完全看你的個人喜好。

我個人更傾向於 Bitwarden 的傳統設計方式。

價格 ​

你可以免費開始使用這兩種服務。

Bitwarden 和 Proton Pass 在其免費計劃中都不限制存儲的登錄憑證數量和可使用設備的數量。

如果你需要包括緊急訪問、家庭共享、安全存儲、二次驗證、電子郵箱別名隱藏等特性，你需要升級為高級版。

Bitwarden 的年費僅為 10 美元，而其家庭計劃（包含六個賬户）的年費為 40 美元。這個價格對大多數人來説是極其實惠的。

相比之下，Proton Pass 的價格較高，其 Plus 計劃的年費為 47.88 歐元。

不過，如果你使用了所有其他 Proton 的服務，並選擇了 Proton 的無限制訂閲，你就可以獲得包括 Proton Pass、Mail、VPN、Drive 和 Calendar 在內的高級特性。

功能 ​

這兩個密碼管理器功能都十分完善，因此每一種都能提供人們所需要的核心特性。

它們共同擁有的特性包括：

  • 密碼生成器
  • 安全筆記
  • 自動填充
  • 卡片信息和登錄憑證
  • 便於隨時獲取憑證的手機應用

接下來，讓我來突出一下根據我個人的使用經驗，每一種服務各自獨特的優點：

Bitwarden ​

Bitwarden 的一項關鍵功能是其 “發送Send” 功能，它允許你發送一個文件（最大 500 MB）或一段文本/便箋給任何人，這都是通過一個安全連接實現的，並且在整個過程中都實現了端到端的加密。這項功能可以在 桌面應用、擴展插件和網頁保險庫 中使用。

你可以通過添加一段只有接收者知道的密碼短語來保護這個鏈接。還有更多的自定義選項，例如設定鏈接的過期時間，或在文件被下載後銷燬鏈接。

我不認為這是一種安全發送文件的方法，更多的是適合發送私人文件（如電子郵件附件）和文本文件。

接下來，Bitwarden 提供了一個 家庭計劃，允許你與 其他五個賬户 共享一個訂閲。Proton Pass 並沒有此類服務。

我想着重強調的另一個功能是：緊急訪問。

因為密碼管理器儲存了你所有的登錄信息，它就是一個包含 所有你的訪問密鑰 的地方。你可以設置緊急訪問功能，以方便你信任的朋友或者家庭成員在你不幸出現緊急狀況後訪問你的密碼。

當然，在授權用户訪問你的賬户之前，你可以設定一個期限以確認或拒絕這個訪問請求。如果你沒有采取任何行動，那麼這個訪問權限將會授予你的信任用户。

📋 緊急聯繫人選項只能在 網絡保險庫 中訪問。

值得注意的是： 這兩種服務的密碼生成器都包含歷史記錄，但 Bitwarden 保留歷史時間更長，而 Proton Pass 只保留一天的歷史記錄。

其他功能差異包括：

  • 導出為 .CSV 文件
  • 調整自動填充行為
  • 訪問網絡保險庫
  • 桌面應用
  • 記錄身份信息

對於所有列出的功能，在我使用 Bitwarden 的過程中，我都沒有遇到任何重大的問題。

我唯一注意到的問題：有時在我的安卓手機上，自動填充功能並沒有在鍵盤應用中作為建議顯示。當然，這取決於各個智能手機制造商提供的定製安卓體驗，因此不一定是 Bitwarden 特有的問題。

Proton Pass ​

如果我們從“功能數量”上進行比較，Bitwarden 會佔據優勢。

但是，作為一個以隱私為重點的工具，Proton Pass 實現了密碼管理器所有你需要的重要功能，甚至超越了這些。

得益於對 SimpleLogin 的專業研究，Proton Pass 支持生成電子郵件別名。

如果你不太瞭解：SimpleLogin 是最受歡迎的 工具之一，用於保護你的電子郵件地址。

所以，當 Proton Pass 集成了這個功能後，用户可以 便捷地創建電子郵件別名，並同時保存登錄信息。你在 Proton Pass 上註冊的電子郵件將會是實際的電子郵件地址。

我希望他們提供一個設定新的目標電子郵件地址的選項，這將使 Proton Pass 的額外費用更具價值。

此外，如果你是一位使用了部分或所有 Proton 服務的用户，使用 Proton Pass 將會是一種良好的用户體驗。因為你無需為其他平台切換或註冊。

使用 Proton Pass 還可以獲得基本的 導入/導出，控制某些安全措施，修改密碼管理器行為 的功能。

因此，對於 Proton 用户而言，Proton Pass 可以是一種一站式的解決方案。

是的，我暫時沒有注意到任何關於其移動應用的問題，Proton Pass 到目前為止很好。

你應該選擇哪個？ ​

考慮到它們的共性，這主要取決於你個人的使用體驗、預算（如果選擇付費），以及功能集。

對於我個人的使用，我暫時沒有看到 Proton Pass 替換 Bitwarden 的需要。

然而，如果我決定購買 Proton 的無限制訂閲，或是更加投入到 Proton 的各項服務中去，我可能會放棄 Bitwarden。
