Ubuntu MATE 23.10發佈： 一個適度的升級 ​

Ubuntu MATE 23.10 發佈了！

在所有的 Ubuntu 版本中，Ubuntu MATE 的升級總是非常有趣的。

不過，最近發佈的 Ubuntu MATE 決定堅持小幅改動，並進行預期的軟件包升級和修復。你可能知道為什麼！

對於不瞭解的讀者：這是為了開發我們去年報道過的 計劃中的 Debian MATE 定製版。

説到這裏，讓我重點介紹一下這些變化。

💡 Ubuntu MATE 23.10 將支持九個月，直至 2024 年 7 月。

Ubuntu MATE 23.10：有什麼新功能？ ​

Ubuntu MATE 23.10 受益於 Ubuntu 23.10 推出的所有好東西。

此外，這裏還有一些改進：

  • MATE 桌面更新至 v1.26.2。
  • 添加更多人工智能生成的壁紙。
  • 應用更新。

MATE 桌面升級 ​

在最新的 MATE 桌面 1.26.2 中，你將獲得大量錯誤修復和一些小的改進。

升級包括以下內容：

  • 更新 MATE 用户指南 v1.26.2-1
  • 改進門户支持
  • 改進系統監視器，以便從 /usr/libexec 獲取 libexec 文件
  • 修正 MATE 會話管理器，使其更好地與系統監視器配合使用
  • mate-utils 1.26.1-1 修復了內存泄漏問題

額外的人工智能生成的壁紙 ​

雖然你已經可以從 Ubuntu 23.10 更新合集 中下載一些有趣的壁紙，但在這裏你還能獲得額外的壁紙（如上面的截圖所示）。

Simon Butcher 是使用前沿的 Diffusion 模型製作這款壁紙的人，他提到：

由於牛頭人是一種想像中的生物，因此對其的解釋往往千差萬別。我想製作一個具有漫畫小説風格的強大生物圖像，儘管不像許多描述那樣令人毛骨悚然。

最新開源的 Stable Diffusion XL 基本模型在更高分辨率下進行了訓練，質量上的差異非常明顯，尤其是在整體一致性和細節方面，同時減少了圖像中的解剖不規則性。圖像是使用 Linux 和英偉達 A100 80GB GPU 在本地製作的，從最初的文本提示開始，使用 img2img、修復和放大功能進行完善。

Linux 內核 6.5 ​

當然，Linux 內核 6.5 還能為硬件帶來更好的兼容性、新代組件和其他改進。

其他改進 ​

主要的應用程序升級包括 Firefox 118、Celluloid 0.25、Evolution 3.50 和 LibreOffice 7.6.1。

所有這些都將改善用户體驗。

📥 獲取 Ubuntu MATE 23.10 ​

你可以從 官方網站 或 Ubuntu 倉庫 下載 Ubuntu MATE 23.10 ISO。

Ubuntu MATE 23.10

如果你是現有用户並希望升級，請按照 發佈説明 中的官方説明進行操作。
