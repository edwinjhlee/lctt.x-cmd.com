任務中心：一款流暢的 Linux 系統監控應用 ​

這是一款為 Linux 打造的用户友好的系統監控應用。讓我們一起來了解！

假如有一天，你發現你的系統開始運行緩慢，你的發行版的默認的系統監控應用又無法給與幫助，你會如何處理？

我能理解當你在試圖找出是什麼進程引起你的系統運行緩慢，而系統監控器卻無法提供幫助是何等煩惱的事。

在此，我初步介紹的這個工具，或許就是你需要的。這就是 “任務中心Mission Center”，一個為 Linux 打造的系統監控器，旨在提供實用的功能。

下文將一一展示這個應用可以做什麼，以及它的一些限制。

🚧 這個應用還是非常新的，處於積極的開發中。所以，預計會有一些變動。

⭐ 任務中心：概述 ​

主要使用 內存安全的 Rust 編程語言 編寫的 任務中心 是一款可以讓你監控 CPU、內存、磁盤、網絡以及 GPU 的系統監控器。

它的幾個關鍵特性包括：

  • 實時監控每個線程的 CPU 使用情況。
  • 有能力監控 RAM 和 Swap 的使用狀況。
  • 提供應用和進程的詳細使用信息。
  • 監控網絡的利用率和傳輸速度。

👨‍💻 初步印象 ​

我在一個運行着 Ubuntu 22.04 LTS 的系統上進行了測試，由於這款應用 提供了 Flatpak 安裝方式，使得整個安裝過程相當簡潔。

我不得不説，任務中心 看起來和 Windows 11 上的任務管理器大體相似，這並不算是壞事。這種界面佈局十分適合以用户友好的方式展示所有重要的信息。

我首先查看的是系統監控的 “性能Performance” 部分中的 CPU 標籤。它向我提供了我處理器的所有關鍵信息，並配有一個能展示實時 CPU 使用率的圖表。

我還能切換到 “邏輯處理器logical processors” 視圖，以便觀察每個線程的 CPU 使用情況。只需在圖表上進行右鍵點擊並進入 “改變視圖Change Graph To” 菜單即可切換。

我接下來查看的是 “內存Memory” 標籤，它提供了一個內存使用的實時圖表，以及兩個正在使用的 RAM 模組的實用信息。

然後我查看了 “硬盤Disk” 標籤。即便我在我的系統中有多個存儲硬盤，但我只在 Ubuntu 上使用了 “Disk 4”。我對其進行了使用率檢查，顯示出來的似乎是實時的磁盤使用數據。

不過，據開發者所述，當前硬盤使用率的百分比仍在開發中，因此，現在的數據可能尚不準確。

最後，我查看了 “以太網Ethernet” 標籤。它向你展示了有關係統的網絡活動的實時圖表，包括了下載和上傳活動的兩個信息點。

然而，它對於應用的網絡數據使用情況，目前還是沒有應用級的網絡數據信息。這個功能，開發者正 在着手開發。

接下來，我查看了 “應用Apps” 部分。這裏包含了系統中運行的大部分（甚至全部）應用和進程。它不有展示了應用/進程的全部有用信息，包括 PID、CPU 使用、內存和磁盤使用情況。

你還能在任何一個應用/進程上進行右鍵點擊，來選擇 停止應用/進程 或 強制停止應用/進程。

我還調整了任務中心應用的一些設置，比如：

  • 調整所有實時圖表的更新頻率
  • 設定合併進程統計數據
  • 記住我在 “應用Apps” 部分所使用的排序順序。

我注意到一個缺失的數據，關於我的 GPU。任務中心未能檢測到我的英偉達 GPU。

這是可以理解的，因為 GPU 的支持目前仍然處於實驗階段，僅支持 AMD 和英偉達的 GPU。

📥 獲取任務中心 ​

任務中心可以在 Flathub 商店 或者 GitLab 上獲得，如果你更傾向於從源碼來構建的話。
