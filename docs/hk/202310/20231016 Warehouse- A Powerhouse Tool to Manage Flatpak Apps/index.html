Warehouse：管理 Flatpak 應用的強大工具 ​

你是否使用 Flatpak 應用？Warehouse 可以讓你更輕鬆。

有一個應用，可以為你提供有關 Flatpak 應用的所有重要信息，以及管理它的工具，這不是很好嗎？

這一次你很幸運！

在這次的首次嘗試中，我們有一個有趣的應用程序，名為 “Warehouse”，它可以幫助你管理 Flatpak 應用。

我們以前介紹過一個類似的應用，名為 “Flatseal”，但它更側重於管理 Flatpak 的權限。

讓我們看看 Warehouse 提供了哪些功能。

Warehouse：概述 ⭐ ​

開發人員將其稱為“多功能工具箱”，Warehouse 可用於管理 Flatpak 用户數據、查看 Flatpak 的信息，甚至批量管理系統上安裝的 Flatpaks。

它主要使用 Python 語言編寫，具有以下主要特點：

  • 輕鬆管理用户數據
  • 批量操作功能
  • 清除殘餘數據

初步印象 👨‍💻 ​

我一開始是在我的 Ubuntu 系統上測試 Warehouse。從 Flathub 上安裝它很簡單。

打開後，顯示了所有已安裝的 Flatpak 應用的列表。它們都以有序的方式排列。

在我看來，如果它們添加了切換到網格佈局的選項，會看起來更好。

📋 你是否對列在 Firefox 之上的應用感到好奇？我們最近介紹過它，它是一個名為 “Mission Center” 的系統監控應用。

接下來，我查看了 Flatpak 應用的屬性，我點擊應用旁邊的“信息”標誌，打開了應用屬性窗口。

它提供了有關應用程序的各種信息，從名稱、描述、應用 ID，一直到活動提交和安裝大小。

類似地，我可以點擊“垃圾桶”圖標，要麼完全卸載 Flatpak 應用，要麼為將來重新安裝保留用户數據，並恢復設置/內容。

Warehouse 還具有搜索功能，允許你搜索特定的應用。當你安裝了很多 Flatpak 應用時，這可能會很有用。

只需點擊應用程序左上角的放大鏡圖標即可開始搜索。

你還可以設置過濾器，以應用甚至運行時（系統完成各種任務所需的）進行排序。

點擊應用程序左上角的“漏斗”圖標以開始篩選。

然後，我查看了批量操作功能。我首先點擊了應用右上方的“勾號”標誌。

然後，我就可以選擇多個應用，執行複製信息、刪除應用數據和卸載它們等操作。

應用程序右下角的三個小按鈕可以方便地執行上述操作。

之後，我進入菜單，其中有一些重要選項。

第一個選項“從文件安裝Install from file”允許我使用 .flatpakref 文件安裝 Flatpak 應用。

在安裝過程中，它問我是要為特定用户安裝，還是要為使用系統的所有人安裝。我選擇了後者。

隨後，我查看了“管理殘餘數據Manage Leftover Data”選項。它向我顯示了一箇舊的 Flatpak 應用留下了多少數據。

我可以選擇通過“安裝Install”選項重新安裝應用並恢復數據，也可以使用“垃圾桶Trash”選項徹底清除系統中的任何痕跡。有時，殘留數據會佔用大量空間。

如果你經常安裝/刪除應用，那麼你的系統中可能會有很多剩餘數據。

如果你想管理 Flatpak 倉庫，可以前往“管理遠程倉庫Manage Remotes”選項，該選項允許你添加或刪除它們。

雖然你可以在 Fedora 和其他一些發行版的軟件中心完成這項工作，但在一個應用中就能獲得所有基本功能，這將是一種無縫體驗。

最後，你還可以使用大量的“鍵盤快捷鍵”，通過鍵盤快速瀏覽應用的所有功能。
