Cloudflare 推出免費的、更注重隱私的替代驗證碼系統 ​

Cloudflare 最終提出了一種可結束視覺難題的解決方案。

自 去年 以來，Cloudflare 一直在研發一種更加註重隱私的驗證碼（CAPTCHA）替代系統。

可惡的驗證碼（尤其是谷歌的 reCAPTCHA）的問題是其無必要地收集用户數據、延遲體驗時間、在網絡導航中造成不便。

當然，驗證碼在一定程度上具有其用處。如果我聲稱它一無是處，無疑會顯得無知。然而，隨着技術的發展，以及為了提供無縫體驗，我們所有的 隱私保護工具 都在不斷進步，我們也需要一個連貫的系統來保護網站免受機器人的侵擾。

令人感興趣的是，Cloudfare 設法整合了一項每個人都可以免費使用作為替代品的技術，那就是Cloudflare Turnstile。和每個 Cloudflare 的產品一樣，你可以得到一個 "Enterprise" 計劃，能夠移除其品牌標識，並做一些其他操作。

Cloudflare Turnstile：徹底擺脱驗證碼！ ​

有了 Cloudflare Turnstile，你將永遠不再需要解答任何視覺難題。

一開始，即使是它的自家隱私優先的驗證碼系統也會向部分用户展示難題。

現在，所有這些都已被他們的新產品替換。你只需進行一次點擊，就可以驗證你是人類：

為了確保隱私保護目標的實現，Cloudflare 作出了以下説明：

我們創立 Turnstile 就是為了保護隱私。Turnstile 達到了 電子隱私指令ePrivacy Directive、GDPR 及 CCPA 的合規性要求，也符合我們自己嚴格的隱私承諾。此外，Cloudflare 的 FedRAMP Moderate 授權套餐、"Cloudflare for Government" 現在也包括 Turnstile。我們並不依賴於追蹤用户數據，比如用户訪問過其他哪些網站，來判斷用户是人還是機器人。我們的業務是保護網站，而不是賣廣告，因此，運營商可以放心部署 Turnstile，知道他們的用户數據安全無虞。

此外，Cloudflare 認為，即使不向用户提供任何交互元素，它也能比現有的驗證碼系統更有效。它可以保護網站免受機器人流量，以及欺詐行為的侵害。

所以，有些人可能甚至不會看到人類驗證的挑戰，因為 Cloudflare 已經通過後台進行了一系列的檢查和分析以發現可疑行為。

有什麼更讓人興奮的嗎？

所有這些都是免費提供的。任何不使用 Cloudflare 作為防火牆或 CDN 的網站或平台，只需添加幾行代碼，即可選擇使用本服務。
