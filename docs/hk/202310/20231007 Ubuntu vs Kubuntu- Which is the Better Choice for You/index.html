Ubuntu 與 Kubuntu：哪一個更適合你？ ​

對於 Ubuntu 和其相關版本如 Kubuntu 的選擇可能會令人迷惑。那就讓我們簡化這個選擇過程吧。

Ubuntu 是桌面用户最選擇的 Linux 發行版。其特色是一個定製的 GNOME 桌面，可以提供流暢的用户體驗。振奮人心！

而另一方面，Kubuntu 是 Ubuntu 發行版家族 中的一員，特色在於其 KDE Plasma 桌面。

本質上，這兩種發行版非常類似，主要區別在於 桌面環境。

那麼，它二者有何明顯不同點？是否一個比另外一個更好？對於你來説，何種發行版更為適合？

接下來，我們將比較下它們之間的主要不同，並提供一些基本信息以助你做出選擇。

📋 本篇文章的對比依據是 Ubuntu 23.04 以及 Kubuntu 23.04。隨着未來版本的發佈，可能會有一些變動，我們也會持續進行更新。

桌面環境 ​

Ubuntu 的特色在於使用了 GNOME 桌面的定製外觀。對於新的 Linux 用户來説，這個佈局獨特且易用。

它並不與 Fedora Linux 的原生 GNOME 體驗完全相同。Ubuntu 的桌面環境體驗經過了一些改動。

Kubuntu 提供了原生的 KDE Plasma 體驗。對於從 Windows 平台轉換來的用户，佈局會感到相當熟悉，包含開始菜單、系統小工具等等。

如果你嘗試過任何其他帶有 KDE Plasma 桌面的發行版，其體驗應該差不多。

它們都是一些極為出色的 桌面環境，所以，你基於各種佈局、定製性和特性選擇它們中的哪一個都沒有什麼問題。

💡 根據發行版版本，例如 長期支持版（LTS）還是非 LTS，桌面環境及特徵集會有所不同。

舉例來説，如果你選擇像 Ubuntu 23.10 或 Kubuntu 23.10 這樣的非 LTS 版本，你可以獲得更新的桌面版本 —— GNOME 45 或 KDE Plasma 5.27。

而對於 Ubuntu 22.04 LTS，提供的則是稍舊一些的桌面版本—— GNOME 42 或 KDE Plasma 5.24。

軟件管理 ​

由於 Ubuntu 和 Kubuntu 其核心都是 Ubuntu（或 Debian），因此可以期待在這兩個版本上安裝同樣的應用程序。

但是，你用來管理或安裝應用程序的應用商店在每個版本中都是不同的。

對於 Ubuntu，它使用 軟件中心Software Center 或者 Ubuntu 應用中心Ubuntu App Center（從 Ubuntu 23.10 開始的新版本），默認集成了 Snap。因此，如果你更傾向於使用 Snap 而不是 Flatpak，Ubuntu 就可以提供以無縫的安裝體驗。

想要使用 Flathub 的包，你可以按照我們的 Flatpak 使用指南 進行操作，但 Ubuntu 的軟件管理器並未提供整合。

提及 Kubuntu，你得到的軟件管理器是 “發現Discover” 應用。你也可以從軟件倉庫以及 Snap 包中安裝應用。

與 Ubuntu 的軟件商店相較，“發現”應用在輕鬆整合 Flatpak 方面更具靈活性。

你只需多擊幾下，就可以在設置菜單中通過 Flatpak 後端插件 在“發現”應用裏列出來自 Flathub 的應用。

軟件與功能點差異 ​

有些用户更注重在特定發行版中能做什麼，以及開箱即用的軟件工具。

他們並不在意桌面佈局或鎖屏和登錄屏幕的界面如何。他們只在乎功能特性，就如你在這裏看到的圖片展示的那樣。

📋 可用的功能會依據發行版的版本和軟件而有所不同。然而，我相信，一些讓它們各自獨特之處值得你瞭解，這些可能有助於你的選擇。

一些重要的功能點如下：

  • Kubuntu 的默認屏幕截圖工具提供了註釋和編輯功能，而 Ubuntu 則沒有這功能。
  • Kubuntu 的文件管理器比 Ubuntu 的包含更多的特性。
  • 作為桌面環境選項，Kubuntu 提供了更多的預裝應用。
  • 相比於 Ubuntu，Kubuntu 提供了更多的外觀定製選項。
  • Kubuntu 默認使用 KDE “連接Connect” 應用連接你的移動設備。你也可以在 Ubuntu 進行相同的安裝以獲取這個功能。
  • 在 Ubuntu 上，簡易化並自動化的工作空間增加功能易於改進工作流。你可以在 Kubuntu 上增加虛擬桌面，但需手動操作。
  • Ubuntu 具有快捷切換到深色/淺色模式的功能。
  • Ubuntu 針對經常被海量選項所困擾的用户，更加註重簡單易用的操作方式。

發佈週期 ​

如 Ubuntu 18.04 和 Ubuntu 22.04 這類的 Ubuntu LTS 版本，會在其發佈之日後的五年內接受軟件更新和安全補丁。

此外，如果你希望長期使用同一版本，你可以選擇開通 Ubuntu Pro 訂閲（個人使用免費），它將為你提供額外五年的更新支持。

而對於非 LTS 版本，如 Ubuntu 22.10 和 Ubuntu 23.04，則會提供九個月的維護更新。

💡 對大部分用户來説，我們推薦使用 LTS 版本。只有在你準備好在九個月之後升級你的系統，以獲取最新最好的軟件時，才推薦嘗試非 LTS 版本。

如果你對這些術語感到不熟，我建議你閲讀我們的一些資源，深入理解發布週期：

  • Ubuntu 的生命週期終止期指的是什麼？
  • 長期支持版是什麼意思？

總的來説，選擇 Ubuntu，你可以獲得相當長的支持選項。

大部分用户可能會認為，由於 Kubuntu 是 Ubuntu 的官方發行版，它們應該具有相同的更新週期。遺憾的是，並非如此。

在 Kubuntu 中，其長期支持版從發佈之日起僅支持三年。非長期支持版的更新維護期僅為九個月。並無任何擴展軟件更新期的選項。

例如，安裝 Ubuntu 後，你或許可以立即選擇深色或淺色模式，然而在 Kubuntu 中這樣的選項並不可用。

系統資源使用 ​

這裏不會有贏家或輸家，但基本上，Kubuntu 上的桌面環境（KDE Plasma）更輕量也更注重性能。

Ubuntu 的 GNOME 則設計得直觀，為你提供了順暢的用户體驗。

你應該選擇哪個？ ​

在選擇一個適合日常使用的 Linux 發行版時，你的工作流以及佈局都是需要考慮的因素。

如果你熟悉 Windows 平台，Kubuntu 應是一個好選擇（甚至是從 Windows 平台轉換過來的用户）。

如果你理解並樂意接受 GNOME 的佈局，Ubuntu 可以為你提供簡單且現代的體驗。

但不管是哪種情況，如果你希望能有高度的可定製性和大量實用工具，Kubuntu 會是一個理想的選擇。反而，如果你更偏愛簡約清晰的佈局，選擇 Ubuntu 一定不會錯。
