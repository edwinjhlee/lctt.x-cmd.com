Linux 內核 6.6 版本蒞臨，帶來諸多變化 ​

筆記本的支持得到了提升，服務器性能得到了改進，更多內容一一揭曉。

又到了迎接 Linux 內核新版本發佈的時刻！

Linux 內核 6.6 的發佈，是一次大規模更新，針對各類筆記本、網絡硬件、處理器等提供了大量全方位的改良。

Linus Torvalds 表示：

各種各樣的修復散佈各處，除了針對 r8152 驅動的一些重要修復外，其它的都相當小型。下面是上週的簡短日誌，供所有想要一探究竟、瞭解更多細節的讀者。日誌篇幅短小，可以快速翻閲。

🆕 Linux 內核 6.6：都有哪些新元素？ ​

在我們開始之前，需要提醒大家，這一次發佈的是非長期支持版本，因此不是每個人都必須進行升級，除非你想要享受最新、最棒的版本。

總的來説，讓我們來看看這次發佈版本的亮點：

  • 針對英特爾芯片的優化
  • 對筆記本的更佳支持
  • 網絡改進
  • AMD 芯片性能提升

針對英特爾芯片的優化 ​

Linux 內核 6.6 版本新增了對英特爾的神經處理單元（NPU）的支持，這樣的技術原先被稱作通用處理器。

這項技術預計將於今年晚些時候，隨着英特爾的“Meteor Lake”芯片亮相而首次公開登場。這些 NPU 將被專門用於處理人工智能工作負載。

英特爾甚至已經開始對即將發佈的 “Arrow Lake”芯片進行NPU 支持的初步工作了！

此外，還新增了對英特爾的 Shadow Stack 的支持，因為他們的 控制流執行技術（CET）被引入到了內核中。其主要目的是防止現代英特爾 CPU（從 Tiger Lake 起）上的返回導向編程（ROP）攻擊。

對筆記本的更佳支持 ​

對於惠普筆記本，現在你可以直接在 Linux 中對 BIOS 進行管理了，這要歸功於 “HP-BIOSCFG” 驅動的實現。

根據報道，從 2018 年起出產的惠普筆記本應該都可以支持這個驅動程序。

對於聯想筆記本，驅動程序已經更新，為更多的 IdeaPad 筆記本添加了鍵盤背光控制**。

同樣，對於華碩筆記本，現在 ROG Flow X16（2023 年款）遊戲筆記本，當屏幕翻轉時可以正確地啓用平板模式。

網絡改進 ​

在網絡方面，Linux 內核 6.6 版本帶來了對如 Atheros QCA8081、MediaTek MT7988、MediaTek MT7981，NXP TJA1120 PHY 等新型硬件的支持。

同時，各類驅動程序也進行了升級，例如 高通 Wi-Fi 7 （ath12k）驅動程序，它現在支持 Extremely High Throughput（EHT）PHY。

此外，針對各類 Realtek（rtl8xxxu）Wi-Fi 芯片啓用了 AP 模式。

關於特定於網絡的變動，你可以在這個 拉取請求 中查閲更多的詳細信息。

AMD 芯片的性能提升 ​

隨着 Linux 內核 6.6 的發佈，AMD 的開發人員推出了兩項尚未正式公開的新技術的支持。

一項技術是對他們即將推出的 “FreeSync Panel Replay” 技術的支持，這一技術只用於遊戲筆記本抖動屏，可以自動降低刷新率以節省電力和降低 GPU 工作負載。

另一項技術被稱為 “動態提速控制”，這是一項能夠提高某些 Ryzen SoC 性能的功能，但關於它的更多細節比較少。

關於它的實施，你可以在這個 補丁序列 中查閲更多的信息。

🛠️ 其他的變化與改進 ​

其他方面，還包括一些值得注意的變動：

  • 針對 龍芯 的大量新特性。
  • Rust 工具鏈 升級至 v1.71.1 版本。
  • 對 RISC-V 和 Btrfs 的多項改進。
  • 完全移除了 無線 USB 和 Ultra-Wideband 的代碼。
  • 對 英偉達、英特爾 和 AMD 的開源圖形驅動程序 的眾多優化。

你可以在 更新日誌 中查閲更詳細的信息。

安裝 Linux 內核 6.6 版本 ​

如果你的體驗是像 Arch 或 Fedora 那類的滾動發行版，升級過程非常簡單。

你只需要稍等片刻，因為這些發行版在發佈更新時需要一些時間。

對於其他的用户，你可以等待主要版本更新，或者根據我們的指南在 Ubuntu 中升級至最新的主線 Linux 內核：

在 Ubuntu 上安裝最新的主線 Linux 內核

你可以在 官方網站 下載最新的 Linux 內核的 tarball （發佈後可能需要些時間才能得到）。
