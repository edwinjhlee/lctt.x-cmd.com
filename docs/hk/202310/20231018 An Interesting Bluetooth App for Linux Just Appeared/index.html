Overskride：剛剛出現的一款有趣的 Linux 藍牙應用！ ​

通過這個全新的應用可以實現所有藍牙功能！

一款適用於 Linux 的新應用已經出現，它可能是滿足你所有藍牙需求的一站式應用。

這款名為 “Overskride” 的開源應用首次發佈。儘管它還處於開發階段，但已經提供了一些不錯的功能。

請允許我帶你看一下。

Overskride：可以期待什麼？ ​

Overskride 將會吸引 Rust 愛好者，因為它主要是用 Rust 語言編寫的，帶有 GTK4/libadwaita 風格。

根據開發人員的説法，它是一個簡單的藍牙和 Obex 客户端 （未來計劃），無論使用什麼桌面環境或窗口管理器都可以工作。

一些主要功能包括：

  • 信任/阻止設備。
  • 能夠發送/接收文件。
  • 設置連接超時時間。
  • 支持配置適配器。

查看上面的截圖，你可以看到自定義藍牙設備和連接的所有基本選項，包括適配器名稱。

當然，考慮到這是該應用的第一次發佈，人們不應該抱有太高的期望。因此，還有改進的空間。

以下是 Overskride 的一些預覽，以查看它提供的功能。

我在 Ubuntu 22.04 LTS 和 GNOME 42.9 上使用提供的 Flatpak 包進行安裝。在此安裝上運行似乎沒有任何問題。

Overskride 能夠檢測到我的智能手機，並提供多種配置選項。

你可以將設備添加到受信任列表或阻止列表、重命名併發送文件。

我嘗試了文件傳輸功能，但在此之前，我必須使用 Flatseal 允許訪問用户文件，以便它可以讀取我係統上的文件。

我在手機上接受文件傳輸後，傳輸開始。速度還可以，文件確實完整地到達那裏，沒有任何問題。

我必須説，在其首次發佈時，開發人員為我們提供了一個有用的實用程序。我很高興看到其未來版本將提供什麼樣的改進。

一位 Reddit 用户 詢問 是否有任何計劃支持顯示無線耳機的電池百分比。對此，開發人員提到這樣做很棘手，因為 每個設備都遵循不同的規範，這使得這一目標更難實現。

📥 獲得 Overskride ​

目前，Overskride 只能通過 GitHub 倉庫 以 Flatpak 軟件包的形式提供。或者，你也可以從源代碼開始編譯。

Overskride (GitHub)

我希望開發者在發佈穩定版本後將其發佈在 Flathub 上，以便用户可以使用。
