現在，使用 Mozilla Firefox 的理由又增加了一條！ ​

Firefox 正在不斷取得進展，讓我們一起看看最新的變化吧！

Mozilla Firefox 是一款極棒的開源多平台瀏覽器，一直以來都以提供最佳的隱私保護功能而廣受好評。

更值得一提的是，它成為了大多數 Linux 發行版的默認瀏覽器，使得它成為了 Linux 用户的自然之選。

Firefox 當前的狀況 ​

儘管 Firefox 一直以隱私優先的策略，並且是 谷歌 Chrome 的最佳開源替代品 之一，它仍然被大眾所冷落。

這聽起來令人失望，不是嗎？

的確是的，就以市場份額來説，谷歌 Chrome 佔據了 63.56%，而 Firefox 用户僅佔據了 2.94% —— 這是來自 StatCounter 的統計數據。

為什麼會這樣？

詳細來説，你可以回顧一下 Firefox 在 2021 年幾乎損失了 5000 萬用户。

簡而言之：Mozilla Firefox 已經盡其所能，但似乎仍然不足以吸引公眾的注意。

Firefox 的用户體驗在不斷改善 ​

幸運的是，在過去的兩年中，Mozilla Firefox 似乎專注於一步步提升用户體驗，並比平常更多地向公眾展示自己。

例如，他們正在為 Firefox 117 提供 自動翻譯功能支持。

總的來説，最近的更新已經簡化了用户界面，併為 我為什麼總是會回到 Firefox 提供了更多理由。

當然，Firefox 已經提供了 Firefox Relay（保護你電子郵箱的工具 之一）等隱私特性。但是，並非每個用户都在乎那些改善了安全性的底層優化。

許多用户希望能夠通過網頁瀏覽器無縫的使用他們喜愛的網絡服務。這無疑是用户體驗的核心部分。

Mozilla Firefox 就是一款能提供這一體驗的強大且安全的瀏覽器。

如果瀏覽器能滿足網民使用他們最喜歡或是主流服務的體驗需求，那麼 Firefox 就能保留旗下用户，甚至吸引更多新用户。

谷歌的網絡服務在 Firefox 上運行得比以前更好了 ​

好消息是：Mozilla 正在全力以赴做出改變！

在最近的 Blog文章 中，他們宣佈，谷歌 Meet 以及其他谷歌服務如 Workspace、Voice、YouTube、Keep、地圖、翻譯以及相冊 在 Firefox 上運行得比以往任何時候都要好。

他們為此與谷歌的 Workspace 團隊一直保持着緊密的合作，他們這樣寫道：

如果你正在考慮切換，但擔心兼容性問題，你可以放心 —— 谷歌的服務在 Firefox 上工作得相當出色，我們也在不斷的努力滿足你的日新月異的需求。

他們還分享了谷歌 Meet 在 Firefox 上改善後的一些使用體驗截圖。現在，只需使用 Firefox 115 和更高版本，你就可以在加入視頻通話前後應用視效（或背景）。

許多網絡用户都一直在使用谷歌的服務，如果他們在 Firefox 上的用户體驗也很棒，那麼 Firefox 就可能成為一個適合他們替代 Chrome 的選擇。

所以，谷歌的網絡服務在 Firefox 上的體驗得到了改進？

這又是一個使用 Firefox 的理由。

我認為，Mozilla 為了與谷歌 Chrome 及其他競方保持競爭力，並增強用户對流行網絡服務的網絡體驗，這麼做是明智之舉。
