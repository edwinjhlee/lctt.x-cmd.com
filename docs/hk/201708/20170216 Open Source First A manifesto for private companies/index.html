開源優先：私營公司宣言 ​

這是一個宣言，任何私人組織都可以用來構建其協作轉型。請閲讀並讓我知道你的看法。

我在 Linux TODO 小組中作了一個演講使用了這篇文章作為我的材料。對於那些不熟悉 TODO 小組的人，他們是在商業公司支持開源領導力的組織。相互依賴是很重要的，因為法律、安全和其他共享的知識對於開源社區向前推進是非常重要的。尤其是因為我們需要同時代表商業和公共社區的最佳利益。

“開源優先”意味着我們在考慮供應商出品的產品以滿足我們的需求之前，首先考慮開源。要正確使用開源技術，你需要做的不僅僅是消費，還需要你的參與，以確保開源技術長期存在。要參與開源工作，你需要將工程師的工作時間分別分配給你的公司和開源項目。我們期望將開源貢獻意圖以及內部協作帶到私營公司。我們需要定義、建立和維護一種貢獻、協作和擇優工作的文化。

開放花園開發 ​

我們的私營公司致力於通過對技術界的貢獻，成為技術的領導者。這不僅僅是使用開源代碼，成為領導者需要參與。成為領導者還需要與公司以外的團體（社區）進行各種類型的參與。這些社區圍繞一個特定的研發項目進行組織。每個社區的參與就像為公司工作一樣。重大成果需要大量的參與。

編碼更多，生活更好 ​

我們必須對計算資源慷慨，對空間吝嗇，並鼓勵由此產生的凌亂而有創造力的結果。允許人們使用他們的業務的這些工具將改變他們。我們必須有自發的互動。我們必須通過協作來構建鼓勵創造性的線上以及線下空間。無法實時聯繫對方，協作就不能進行。

通過精英體制創新 ​

我們必須創建一個精英階層。思想素質要超過羣體結構和在其中的職位任期。按業績晉升鼓勵每個人都成為更好的人和僱員。當我們成為最好的壞人時, 充滿激情的人之間的爭論將會發生。我們的文化應該有鼓勵異議的義務。強烈的意見和想法將會變成熱情的職業道德。這些想法和意見可以來自而且應該來自所有人。它不應該改變你是誰，而是應該關心你做什麼。隨着精英體制的進行，我們會投資未經許可就能正確行事的團隊。

項目到產品 ​

由於我們的私營公司擁抱開源貢獻，我們還必須在研發項目中的上游工作和實現最終產品之間實現明確的分離。項目是研發工作，快速失敗以及開發功能是常態。產品是你投入生產，擁有 SLA，並使用研發項目的成果。分離至少需要分離項目和產品的倉庫。正常的分離包含在項目和產品上工作的不同社區。每個社區都需要大量的貢獻和參與。為了使這些活動保持獨立，需要有一個客户功能以及項目到產品的 bug 修復請求的工作流程。

接下來，我們會強調在私營公司創建、支持和擴展開源中的主要步驟。

技術上有天賦的人的學校 ​

高手必須指導沒有經驗的人。當你學習新技能時，你將它們傳給下一個人。當你訓練下一個人時，你會面臨新的挑戰。永遠不要期待在一個位置很長時間。獲得技能，變得強大，通過學習，然後繼續前進。

找到最適合你的人 ​

我們熱愛我們的工作。我們非常喜歡它，我們想和我們的朋友一起工作。我們是一個比我們公司大的社區的一部分。我們應該永遠記住招募最好的人與我們一起工作。即使不是為我們公司工作，我們將會為我們周圍的人找到很棒的工作。這樣的想法使僱用很棒的人成為一種生活方式。隨着招聘變得普遍，那麼審查和幫助新員工就會變得容易了。

即將寫的 ​

我將在我的Blog上發佈關於每個宗旨的更多細節，敬請關注。
