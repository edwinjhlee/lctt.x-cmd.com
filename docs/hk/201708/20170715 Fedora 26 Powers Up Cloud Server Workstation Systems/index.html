Fedora 26 助力雲、服務器、工作站系統 ​

Fedora 項目 7 月份宣佈推出 Fedora 26, 它是全面開放源代碼的 Fedora 操作系統的最新版本。

Fedora Linux 是 Red Hat Enterprise Linux（RHEL）的社區版本。Fedora 26 包含一組基礎包，形成針對不同用户的三個不同版本的基礎。

Fedora 原子主機版Atomic Host Edition 是用於運行基於容器的工作的操作系統。Fedora 服務器版Server將 Fedora Server OS 安裝在硬盤驅動器上。Fedora 工作站版Workstation是一款用於筆記本電腦和台式機的用户友好操作系統，它適用於廣泛的用户 - 從業餘愛好者和學生到企業環境中的專業人士。

所有這三個版本都有共同的基礎和一些共同的優點。所有 Fedora 版本每年發行兩次。

Fedora 項目是創新和新功能的測試基地。Fedora 項目負責人 Matthew Miller 説，有些特性將在即將發佈的 RHEL 版本中實現。

他告訴 LinuxInsider：“Fedora 並沒有直接參與這些產品化決策。Fedora 提供了許多想法和技術，它是 Red Hat Enterprise Linux 客户參與並提供反饋的好地方。”

強力的軟件包 ​

Fedora 開發人員更新和改進了所有三個版本的軟件包。他們在 Fedora 26 中進行了許多錯誤修復和性能調整，以便在 Fedora 的用例中提供更好的用户體驗。

這些安裝包包括以下改進：

  • 更新的編譯器和語言，包括 GCC 7、Go 1.8、Python 3.6 和 Ruby 2.4；
  • DNF 2.0 是 Fedora 下一代包管理系統的最新版本，它與 Yum 的向後兼容性得到改善；
  • Anaconda 安裝程序新的存儲配置界面，可從設備和分區進行自下而上的配置；
  • Fedora Media Writer 更新，使用户可以為基於 ARM 的設備（如 Raspberry Pi）創建可啓動 SD 卡。

Endpoint Technologies Associates 的總裁 Roger L. Kay 指出，雲工具對於使用雲的用户必不可少，尤其是程序員。

他對 LinuxInsider 表示：“Kubernetes 對於在混合雲中編程感興趣的程序員來説是至關重要的，這可能是目前業界更重要的發展之一。雲，無論是公有云、私有云還是混合雲 - 都是企業計算未來的關鍵。”

Fedora 26 原子主機亮相 ​

Linux 容器和容器編排引擎一直在普及。Fedora 26 原子主機提供了一個最小佔用的操作系統，專門用於在裸機到雲端的環境中運行基於容器的工作任務。

Fedora 26 原子主機更新大概每兩週發佈一次，這個時間表可以讓用户及時跟上游創新。

Fedora 26 原子主機可用於 Amazon EC2 。OpenStack、Vagrant 鏡像和標準安裝程序 ISO 鏡像可在 Fedora 項目網站上找到。

最小化的 Fedora 原子的容器鏡像也在 Fedora 26 上首次亮相。

雲託管 ​

最新版本為 Fedora 26 原子主機提供了新功能和特性：

  • 容器化的 Kubernetes 作為內置的 Kubernetes 二進制文件的替代品，使用户更容易地運行不同版本的容器編排引擎；
  • 最新版本的 rpm-ostree，其中包括支持直接 RPM 安裝，重新加載命令和清理命令;
  • 系統容器，它提供了一種在容器中的 Fedora 原子主機上安裝系統基礎設施軟件（如網絡或 Kubernetes）的方法；
  • 更新版本的 Docker、Atomic和 Cockpit，用於增強容器構建，系統支持和負載監控。

根據 Fedora 項目的 Miller 所言，容器化的 Kubernetes 對於 Fedora 原子主機來説是重要的，有兩個重要原因。

他解釋説：“首先，它可以讓我們從基礎鏡像中刪除它，減小大小和複雜度。第二，在容器中提供它可以輕鬆地在不同版本中切換，而不會破環基礎，或者為尚未準備好進行改變的人造成麻煩。”

服務器端服務 ​

Fedora 26 服務器版為數據中心運營提供了一個靈活的多角色平台。它還允許用户自定義此版本的 Fedora 操作系統以滿足其獨特需求。

Fedora 26 服務器版的新功能包括 FreeIPA 4.5，它可以改進容器中運行的安全信息管理解決方案，以及 SSSD 文件緩存，以加快用户和組查詢的速度。

Fedora 26 服務器版月底將增加稱為 “Boltron” 的 Fedora 模組化技術預覽。作為模組化操作系統，Boltron 使不同版本的不同應用程序能夠在同一個系統上運行，這實質上允許將前沿運行時與穩定的資料庫配合使用。

打磨工作站版 ​

對於一般用户的新工具和功能之一是更新的 GNOME 桌面功能。開發將獲得增強的生產力工具。

Fedora 26 工作站版附帶 GNOME 3.24 和眾多更新的功能調整。夜光根據時間細微地改變屏幕顏色，以減少對睡眠模式的影響。LibreOffice 5.3 是開源辦公生產力套件的最新更新。

GNOME 3.24 提供了 Builder 和 Flatpak 的成熟版本，它為開發人員提供了更好的應用程序開發工具，它可以方便地訪問各種系統，包括 Rust 和 Meson。

不只是為了開發 ​

根據 Azul Systems 的首席執行官 Scott Sellers 的説法，更新的雲工具將納入針對企業用户的 Linux 發行版中。

他告訴 LinuxInsider：“雲是新興公司以及地球上一些最大的企業的主要開發和生產平台。”

Sellers説：“鑑於 Fedora 社區的前沿性質，我們預計在任何 Fedora 版本中都會強烈關注雲技術，Fedora 26 不會不令人失望。”

他指出，Fedora 開發人員和用户社區的另一個特點就是 Fedora 團隊在模組化方面所做的工作。

Sellers 説：“我們將密切關注這些實驗功能。”

支持的升級方式 ​

Sellers 説 Fedora 的用户超過其他 Linux 發行版的用户，很多都有興趣升級到 Fedora 26，即使他們不是重度雲端用户。

他説：“這個發行版的主要優點之一就是能提前看到先進的生產級別技術，這些最終將被整合到 RHEL 中。Fedora 26 的早期評論表明它非常穩定，修復了許多錯誤以及提升了性能。”

Fedora 的 Miller 指出，有興趣從早期 Fedora 版本升級的用户可能比擦除現有系統安裝 Fedora 26 更容易。Fedora 一次維護兩個版本，中間還有一個月的重疊。

他説：“所以，如果你在用 Fedora 24，你應該在下個月升級。幸運的 Fedora 25 用户可以隨時升級，這是 Fedora 快速滾動版本的優勢之一。”

更快的發佈 ​

用户可以安排自己升級，而不是在發行版製作出來時進行升級。

也就是説，Fedora 23 或更早版本的用户應該儘快升級。社區不再為這些版本發佈安全更新
