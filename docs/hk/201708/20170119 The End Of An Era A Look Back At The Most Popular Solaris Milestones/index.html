一個時代的結束：Solaris 系統的那些年，那些事 ​

現在看來，Oracle 公司正在通過取消 Solaris 12 而終止 Solaris 的功能開發，這裏我們要回顧下多年來在 Phoronix 上最受歡迎的 Solaris 重大事件和新聞。

這裏有許多關於 Solaris 的有趣／重要的回憶。

在 Sun Microsystems 時期，我真的對 Solaris 很感興趣。在 Phoronix 上我們一直重點關注 Linux 的同時，經常也有 Solaris 的文章出現。 Solaris 玩起來很有趣，OpenSolaris／SXCE 是偉大的產物，我將 Phoronix 測試套件移植到 Solaris 上，我們與 Sun Microsystems 人員有密切的聯繫，也出現在 Sun 的許多活動中。

在那些日子裏 Sun 有一些相當獨特的活動...

不幸的是，自從 Oracle 公司收購了 Sun 公司， Solaris 就如墜入深淵一樣。最大的打擊大概是 Oracle 結束了 OpenSolaris ，並將所有 Solaris 的工作轉移到專有模式...

在 Sun 時代的 Solaris 有很多美好的回憶，所以 Oracle 在其計劃中抹去了 Solaris 12 之後，我經常在 Phoronix 上翻回去看一些之前 Solaris 的經典文章，期待着能從 Oracle 聽到 “Solaris 11” 下一代的消息，重啓 Solaris 項目的開發。

雖然在後 Solaris 的世界中，看到 Oracle 對 ZFS 所做的事情以及他們在基於 RHEL 的 Oracle Enterprise Linux 上下的重注將會很有趣，但時間將會告訴我們一切。

無論如何，這是回顧自 2004 年以來我們最受歡迎的 Solaris 文章：

2016/12/1 Oracle 或許會罐藏 Solaris ​

Oracle 可能正在拔掉 Solaris 的電源插頭，據一些新的傳聞説。

2013/6/9 OpenSXCE 2013.05 拯救 Solaris 社區 ​

作為 Solaris 社區版的社區復興，OpenSXCE 2013.05 出現在網上。

2013/2/2 Solaris 12 可能最終帶來 Radeon KMS 驅動程序 ​

看起來，Oracle 可能正在準備發佈自己的 AMD Radeon 內核模式設置（KMS）驅動程序，並引入到 Oracle Solaris 12 中。

2012/10/4 Oracle Solaris 11.1 提供 300 個以上增強功能 ​

Oracle昨天在舊金山的 Oracle OpenWorld 會議上發佈了 Solaris 11.1 。

2012/1/9 Oracle 尚未澄清 Solaris 11 內核來源 ​

一個月前，Phoronix 是第一個注意到 Solaris 11 內核源代碼通過 Torrent 站點泄漏到網上的信息。一個月後，甲骨文還沒有正式評論這個情況。

2011/12/19 Oracle Solaris 11 內核源代碼泄漏 ​

似乎 Solaris 11的內核源代碼在過去的一個週末被泄露到了網上。

2011/8/25 對於 BSD，Solaris 的 GPU 驅動程序的悲慘狀態 ​

昨天在郵件列表上出現了關於幹掉所有舊式 Mesa 驅動程序的討論。這些舊驅動程序沒有被積極維護，支持復古的圖形處理器，並且沒有更新支持新的 Mesa 功能。英特爾和其他開發人員正在努力清理 Mesa 核心，以將來增強這一開源圖形庫。這種清理 Mesa，對 BSD 和 Solaris 用户也有一些影響。

2010/8/13 告別 OpenSolaris，Oracle 剛剛把它幹掉 ​

Oracle 終於宣佈了他們對 Solaris 操作系統和 OpenSolaris 平台的計劃，而且不是好消息。OpenSolaris 將實際死亡，未來將不會有更多的 Solaris 版本出現 - 包括長期延期的 2010 年版本。Solaris 仍然會繼續存在，現在 Oracle 正在忙於明年發佈的 Solaris 11，但僅在 Oracle 的企業版之後才會發佈 “Solaris 11 Express” 作為 OpenSolaris 的類似產品。

2010/2/22 Oracle 仍然要對 OpenSolaris 進行更改 ​

自從 Oracle 完成對 Sun Microsystems 的收購以來，已經有了許多變化，這個 Sun 最初支持的開源項目現在已經不再被 Oracle 支持，並且對其餘的開源產品進行了重大改變。 Oracle 表現出並不太開放的意圖的開源項目之一是 OpenSolaris 。 Solaris Express 社區版（SXCE）上個月已經關閉，並且也沒有預計 3 月份發佈的下一個 OpenSolaris 版本（OpenSolaris 2010.03）的信息流出。

2007/9/10 Solaris Express 社區版 Build 72 ​

對於那些想要在 “印第安納項目” 發佈之前嘗試 OpenSolaris 軟件中最新最好的軟件的人來説，現在可以使用 Solaris Express 社區版 Build 72。Solaris Express 社區版（SXCE）Build 72 可以從 OpenSolaris.org 下載。同時，預計將在下個月推出 Sun 的 “印第安納項目” 項目的預覽版。

2007/9/6 ATI R500/600 驅動要支持 Solaris 了? ​

雖然沒有可用於 Solaris/OpenSolaris 或 * BSD 的 ATI fglrx 驅動程序，現在 AMD 將向 X.Org 開發人員和開源驅動程序交付規範，但對於任何使用 ATI 的 Radeon X1000 “R500” 或者 HD 2000“R600” 系列的 Solaris 用户來説，這肯定是有希望的。將於下週發佈的開源 X.Org 驅動程序距離成熟尚遠，但應該能夠相對容易地移植到使用 X.Org 的 Solaris 和其他操作系統上。 AMD 今天宣佈的針對的是 Linux 社區，但它也可以幫助使用 ATI 硬件的 Solaris/OpenSolaris 用户。特別是隨着印第安納項目的即將推出，開源 R500/600 驅動程序移植就只是時間問題了。

2007/9/5 Solaris Express 社區版 Build 71 ​

Solaris Express 社區版（SXCE）現已推出 Build 71。您可以在 OpenSolaris.org 中找到有關 Solaris Express 社區版 Build 71 的更多信息。另外，在 Linux 內核峯會上，AMD 將提供 GPU 規格的消息，由此產生的 X.Org 驅動程序將來可能會導致 ATI 硬件上 Solaris/OpenSolaris 有所改善。

2007/8/27 Linux 的 Solaris 容器 ​

Sun Microsystems 已經宣佈，他們將很快支持適用於 Linux 應用程序的 Solaris 容器。這樣可以在 Solaris 下運行 Linux 應用程序，而無需對二進制包進行任何修改。適用於 Linux 的 Solaris 容器將允許從 Linux 到 Solaris 的平滑遷移，協助跨平台開發以及其他優勢。當該支持到來時，這個時代就“快到了”。

2007/8/23 OpenSolaris 開發者峯會 ​

今天早些時候在 OpenSolaris 論壇上發佈了第一次 OpenSolaris 開發人員峯會的消息。這次峯會將在十月份在加州大學聖克魯斯分校舉行。 Sara Dornsife 將這次峯會描述為“不是與演示文稿或參展商舉行會議，而是一個親自參與的協作工作會議，以計劃下一期的印第安納項目。” 伊恩·默多克（Ian Murdock） 將在這個“印第安納項目”中進行主題演講，但除此之外，該計劃仍在計劃之中。 Phoronix 可能會繼續跟蹤此事件，您可以在 Solaris 論壇上討論此次峯會。

2007/8/18 Solaris Express 社區版 Build 70 ​

名叫 "Nevada" 的 Solaris Express 社區版 Build 70 (SXCE snv_70) 現在已經發布。有關下載鏈接的通知可以在 OpenSolaris 論壇中找到。還有公佈了其網絡存儲的 Build 71 版本，包括來自 Qlogic 的光纖通道 HBA 驅動程序的源代碼。

2007/8/16 IBM 使用 Sun Solaris 的系統 ​

Sun Microsystems 和 IBM正在舉行電話會議，他們剛剛宣佈，IBM 將開始在服務器上使用 Sun 的 Solaris 操作系統。這些 IBM 服務器包括基於 x86 的服務器系統以及 Blade Center 服務器。官方新聞稿剛剛發佈，可以在 sun 新聞室閲讀。

2007/8/9 OpenSolaris 不會與 Linux 合併 ​

在舊金山的 LinuxWorld 2007 上，Andrew Morton 在主題演講中表示， OpenSolaris 的關鍵組件不會出現在 Linux 內核中。事實上，莫頓甚至表示 “非常遺憾 OpenSolaris 活着”。OpenSolaris 的一些關鍵組件包括 Zones、ZFS 和 DTrace 。雖然印第安納州項目有可能將這些項目轉變為 GPLv3 項目... 更多信息參見 ZDNET。

2007/7/27 Solaris Xen 已經更新 ​

已經有一段時間了，Solaris Xen 終於更新了。約翰·萊文（John Levon）表示，這一最新版本基於 Xen 3.0.4 和 Solaris “Nevada” Build 66。這一最新版本的改進包括 PAE 支持、HVM 支持、新的 virt-manager 工具、改進的調試支持以及管理域支持。可以在 Sun 的網站上找到 2007 年 7 月 Solaris Xen 更新的下載。

2007/7/25 Solaris 10 7/07 HW 版本 ​

Solaris 10 7/07 HW 版本的文檔已經上線。如 Solaris 發行註記中所述，Solaris 10 7/07 僅適用於 SPARC Enterprise M4000-M9000 服務器，並且沒有 x86/x64 版本可用。所有平台的最新 Solaris 更新是 Solaris 10 11/06 。您可以在 Phoronix 論壇中討論 Solaris 7/07。

2007/7/16 來自英特爾的 Solaris 電信服務器 ​

今天宣佈推出符合 NEBS、ETSI 和 ATCA 合規性的英特爾體系的 Sun Solaris 電信機架服務器和刀片服務器。在這些新的運營商級平台中，英特爾運營商級機架式服務器 TIGW1U 支持 Linux 和 Solaris 10，而 Intel NetStructure MPCBL0050 SBC 也將支持這兩種操作系統。今天的新聞稿可以在這裏閲讀。

然後是 Solaris 分類中最受歡迎的特色文章：

Ubuntu vs. OpenSolaris vs. FreeBSD 基準測試 ​

在過去的幾個星期裏，我們提供了幾篇關於 Ubuntu Linux 性能的深入文章。我們已經開始提供 Ubuntu 7.04 到 8.10 的基準測試，並且發現這款受歡迎的 Linux 發行版的性能隨着時間的推移而變慢，隨之而來的是 Mac OS X 10.5 對比 Ubuntu 8.10 的基準測試和其他文章。在本文中，我們正在比較 Ubuntu 8.10 的 64 位性能與 OpenSolaris 2008.11 和 FreeBSD 7.1 的最新測試版本。

NVIDIA 的性能：Windows vs. Linux vs. Solaris ​

本週早些時候，我們預覽了 Quadro FX1700，它是 NVIDIA 的中端工作站顯卡之一，基於 G84GL 內核，而 G84GL 內核又源於消費級 GeForce 8600 系列。該 PCI Express 顯卡提供 512MB 的視頻內存，具有兩個雙鏈路 DVI 連接，並支持 OpenGL 2.1 ，同時保持最大功耗僅為 42 瓦。正如我們在預覽文章中提到的，我們將不僅在 Linux 下查看此顯卡的性能，還要在 Microsoft Windows 和 Sun 的 Solaris 中測試此工作站解決方案。在今天的這篇文章中，我們正在這樣做，因為我們測試了 NVIDIA Quadro FX1700 512MB 與這些操作系統及其各自的二進制顯示驅動程序。

FreeBSD 8.0 對比 Linux、OpenSolaris ​

在 FreeBSD 8.0 的穩定版本發佈的上週，我們終於可以把它放在測試台上，並用 Phoronix 測試套件進行了全面的瞭解。我們將 FreeBSD 8.0 的性能與早期的 FreeBSD 7.2 版本以及 Fedora 12 和 Ubuntu 9.10 還有 Sun OS 端的 OpenSolaris 2010.02 b127 快照進行了比較。

Fedora、Debian、FreeBSD、OpenBSD、OpenSolaris 基準測試 ​

上週我們發佈了第一個 Debian GNU/kFreeBSD 基準測試，將 FreeBSD 內核捆綁在 Debian GNU 用户的 Debian GNU/Linux 上，比較了這款 Debian 系統的 32 位和 64 位性能。 我們現在擴展了這個比較，使許多其他操作系統與 Debian GNU/Linux 和 Debian GNU/kFreeBSD 的 6.0 Squeeze 快照直接進行比較，如 Fedora 12，FreeBSD 7.2，FreeBSD 8.0，OpenBSD 4.6 和 OpenSolaris 2009.06 。

AMD 上海皓龍：Linux vs. OpenSolaris 基準測試 ​

1月份，當我們研究了四款皓龍 2384 型號時，我們在 Linux 上發佈了關於 AMD 上海皓龍 CPU 的綜述。與早期的 AMD 巴塞羅那處理器 Ubuntu Linux 相比，這些 45nm 四核工作站服務器處理器的性能非常好，但是在運行 Sun OpenSolaris 操作系統時，性能如何？今天瀏覽的是 AMD 雙核的基準測試，運行 OpenSolaris 2008.11、Ubuntu 8.10 和即將推出的 Ubuntu 9.04 版本。

OpenSolaris vs. Linux 內核基準 ​

本週早些時候，我們提供了 Ubuntu 9.04 與 Mac OS X 10.5.6 的基準測試，發現 Leopard 操作系統（Mac）在大多數測試中的表現要優於 Jaunty Jackalope （Ubuntu），至少在 Ubuntu 32 位是這樣的。我們今天又回過來進行更多的操作系統基準測試，但這次我們正在比較 Linux 和 Sun OpenSolaris 內核的性能。我們使用的 Nexenta Core 2 操作系統將 OpenSolaris 內核與 GNU/Ubuntu 用户界面組合在同一個 Ubuntu 軟件包中，但使用了 Linux 內核的 32 位和 64 位 Ubuntu 服務器安裝進行測試。

Netbook 性能：Ubuntu vs. OpenSolaris ​

過去，我們已經發布了 OpenSolaris vs. Linux Kernel 基準測試以及類似的文章，關注 Sun 的 OpenSolaris 與流行的 Linux 發行版的性能。我們已經看過高端 AMD 工作站的性能，但是我們從來沒有比較上網本上的 OpenSolaris 和 Linux 性能。直到今天，在本文中，我們將比較戴爾 Inspiron Mini 9 上網本上的 OpenSolaris 2009.06 和 Ubuntu 9.04 的結果。

NVIDIA 圖形：Linux vs. Solaris ​

在 Phoronix，我們不斷探索 Linux 下的不同顯示驅動程序，在我們評估了 Sun 的檢查工具並測試了 Solaris 主板以及覆蓋其他幾個領域之後，我們還沒有執行圖形驅動程序 Linux 和 Solaris 之間的比較。直到今天。由於印第安納州項目，我們對 Solaris 更感興趣，我們決定終於通過 NVIDIA 專有驅動程序提供我們在 Linux 和 Solaris 之間的第一次定量圖形比較。

OpenSolaris 2008.05 向 Solaris 提供了一個新面孔 ​

2月初，Sun Microsystems 發佈了印第安納項目的第二個預覽版本。對於那些人來説，印第安納州項目是 Sun 的 Ian Murdock 領導的項目的代號，旨在通過解決 Solaris 的長期可用性問題，將 OpenSolaris 推向更多的台式機和筆記本電腦。我們沒有對預覽 2 留下什麼深刻印象，因為它沒有比普通用户感興趣的 GNU/Linux 桌面更有優勢。然而，隨着 5 月份推出的 OpenSolaris 2008.05 印第安納項目發佈，Sun Microsystems 今天發佈了該操作系統的最終測試副本。當最後看到項目印第安納時， 我們對這個新的 OpenSolaris 版本的最初體驗是遠遠優於我們不到三月前的體驗的。

快速概覽 Oracle Solaris 11 ​

Solaris 11 在週三發佈，是七年來這個前 Sun 操作系統的第一個主要更新。在過去七年中，Solaris 家族發生了很大變化，OpenSolaris 在那個時候已經到來，但在本文中，簡要介紹了全新的 Oracle Solaris 11 版本。

OpenSolaris、BSD & Linux 的新基準測試 ​

今天早些時候，我們對以原生的內核模組支持的 Linux 上的 ZFS 進行了基準測試，該原生模組將被公開提供，以將這個 Sun/Oracle 文件系統覆蓋到更多的 Linux 用户。現在，儘管作為一個附加獎勵，我們碰巧有了基於 OpenSolaris 的最新發行版的新基準，包括 OpenSolaris、OpenIndiana 和 Augustiner-Schweinshaxe，與 PC-BSD、Fedora 和 Ubuntu相比。

FreeBSD/PC-BSD 9.1 針對 Linux、Solaris、BSD 的基準 ​

雖然 FreeBSD 9.1 尚未正式發佈，但是基於 FreeBSD 的 PC-BSD 9.1 “Isotope”版本本月已經可用。本文中的性能指標是 64 位版本的 PC-BSD 9.1 與 DragonFlyBSD 3.0.3、Oracle Solaris Express 11.1、CentOS 6.3、Ubuntu 12.10 以及 Ubuntu 13.04 開發快照的比較。
