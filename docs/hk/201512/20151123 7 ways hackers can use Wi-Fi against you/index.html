黑客利用 Wi-Fi 攻擊你的七種方法 ​

黑客利用 Wi-Fi 侵犯你隱私的七種方法 ​

Wi-Fi — 啊，你是如此的方便，卻又如此的危險！

這裏給大家介紹一下通過Wi-Fi連接“慷慨捐贈”你的身份信息的七種方法和反制措施。

利用免費熱點 ​

它們似乎無處不在，而且它們的數量會在接下來四年裏增加三倍。但是它們當中很多都是不值得信任的，從你的登錄憑證、email 甚至更加敏感的賬户，都能被黑客用“嗅探器（sniffers）”軟件截獲 — 這種軟件能截獲到任何你通過該連接提交的信息。防止被黑客盯上的最好辦法就是使用VPN（虛擬私有網virtual private network），它加密了你所輸入的信息，因此能夠保護你的數據隱私。

網上銀行 ​

你可能認為沒有人需要被提醒不要使用免費 Wi-Fi 來操作網上銀行, 但網絡安全廠商卡巴斯基實驗室表示全球超過100家銀行因為網絡黑客而損失9億美元，由此可見還是有很多人因此受害。如果你確信一家咖啡店的免費 Wi-Fi 是正規的，想要連接它，那麼你應該向服務員確認網絡名稱。其他人在店裏用路由器設置一個開放的無線連接，並將它的網絡名稱設置成店名是一件相當簡單的事。

始終開着 Wi-Fi 開關 ​

如果你手機的 Wi-Fi 開關一直開着的，你會自動被連接到一個不安全的網絡中去，你甚至都沒有意識到。你可以利用你手機中基於位置的 Wi-Fi 功能，如果有這種功能的話，那它會在你離開你所保存的網絡範圍後自動關閉你的 Wi-Fi 開關並在你回去之後再次開啓。

不使用防火牆 ​

防火牆是你的第一道抵禦惡意入侵的防線，它能有效地讓你的電腦網絡保持通暢並阻擋黑客和惡意軟件。你應該時刻開啓它除非你的殺毒軟件有它自己的防火牆。

瀏覽非加密網頁 ​

説起來很難過，世界上排名前100萬個網站中55%是不加密的，一個未加密的網站會讓一切傳輸數據暴露在黑客的眼中。如果一個網頁是安全的，你的瀏覽器則會有標明（比如説火狐瀏覽器是一把灰色的掛鎖，Chrome 瀏覽器則是個綠鎖圖標）。但是即使是安全的網站不能讓你免於被劫持的風險，他們能通過公共網絡從你訪問過的網站上竊取 cookies，無論是不是正規網站。

不更新你的安全防護軟件 ​

如果你想要確保你自己的網絡是受保護的，就更新路由器固件。你要做的就是進入你的路由器管理頁面去檢查，通常你能在廠商的官方網頁上下載到最新的固件版本。

不保護你的家用 Wi-Fi ​

不用説，設置一個複雜的密碼和更改無線連接的默認名都是非常重要的。你還可以過濾你的 MAC 地址來讓你的路由器只識別那些確認過的設備。
