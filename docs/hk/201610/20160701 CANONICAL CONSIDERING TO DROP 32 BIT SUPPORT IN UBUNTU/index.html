Canonical 正考慮移除 Ubuntu 的 32 位支持 ​

之前，Dimitri John Ledkov 在 Ubuntu 郵件列表 發送了一則消息，稱將在 Ubuntu 18.10 中取消 32 位支持。他説越來越多的軟件已經有了 64 位支持，而且為古老的 32 位架構提供安全支持將變得更加困難。

Ledkov 同時表示，構建 32 位鏡像並不是沒有成本的，而要耗費 Canonical 不少的資源。

構建 32 位鏡像並不是“免費的”，它的代價就是佔用了我們的構建服務器資源、QA 和校驗時間。儘管我我們有可擴展的構建環境，但 32 位支持還需要為所有包進行構建和自動測試，而且 ISO 也需要在我們的各種架構上進行測試。同時這還會佔據大量的鏡像空間和帶寬。

Ledkov 計劃着，Ubuntu 16.10、17.04、17.10 還會繼續提供 32 位內核、網絡安裝器和雲鏡像，但移除桌面版和服務器版的 32 位 ISO 鏡像。18.04 LTS 將會移除 32 位內核、網絡安裝器和雲鏡像，但在 64 位架構中兼容運行 32 位程序。然後在 18.10 中結束 32 位支持，並將傳統的 32 位應用放在 snap、容器和虛擬機中。

但是，Ledkov 的這份計劃還未被大家接受，但它表明了 32 位支持遲早要被遺棄。（LCTT 譯註：我們已經知道 16.10 依舊有 32 為支持。）

好消息 ​

當然，使用 32 位系統的用户也不必傷心。這個並不會影響用於拯救老式電腦的發行版。Ubuntu MATE 的創建者 Martin Wimpress 在 Googl+ 的討論中透露，這些改變這是影響着主線上的 Ubuntu 而已。

18.04 將繼續存在 32 位架構支持，分支版本可以繼續選擇構建 32 位鏡像。但還是會存在安全隱患，一些大型應用，如 Firefox、Chromium、LibreOffice，已經凸顯了在一些舊版的 LTS 的更新安全問題。所以，這些分支版本需要注意其 32 位支持期限。

思考 ​

從安全的角度，我可以理解他們為什麼要移除 32 位支持，但是這可能會導致一部分人離開主線 Ubuntu 而投入另一個喜愛的發行版或者另一種架構的懷抱。值得慶幸的是，我們還可以選擇 輕量級 Linux 發行版。
