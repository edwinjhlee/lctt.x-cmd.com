有理想，有追求的系統管理員會在 Linux 中成長 ​

我第一次看到運行着的 Linux 操作系統是在我的首份工作時，大約是在 2001 年。當時我在澳大利亞的一家汽車業供應商擔任客户經理，和公司的 IT 工程師共用一間辦公室。他做了一台 CD 刻錄工作站（一個可以同時刻錄好幾張 CD 的巨大的東西），然後我們可以把汽車零配件目錄刻錄到 CD 並送給客户。刻錄工作站最初是為 Windows 設計的，但是他一直沒能讓刻錄機正常工作。最終他放棄在 Windows 上使用的念頭並且換成在 Linux 上使用，刻錄機完美工作了。

對我來説，Linux 的一切都是晦澀難懂的。大部分工作都在看起來像 DOS（LCTT 譯註：磁盤操作系統，早期的個人電腦操作系統） 的命令列下完成，但它更加強大（後來我才認識到這一點）。我從 1993 年就開始使用 Mac 電腦，在那個時候，在我看來命令列界面有點過時了。

直到幾年後——我記得是 2009 年，我才真正的認識 Linux。那時我已經移民荷蘭並且在一家零售供應商那裏找到了工作。那是一個只有 20 人的小公司，我除了做一個關鍵客户經理的正常工作，還無意間成了個一線 IT 技術支持。只要東西有了故障，他們總是會在花大價錢請外部 IT 顧問之前先來詢問我。

我的一個同事因為點擊了一封似乎來自 DHL（LCTT 譯註：全球著名的郵遞和物流集團 Deutsche Post DHL 旗下公司） 的電子郵件所附帶的一個 .exe 文件而受到了一次網絡釣魚攻擊。（是的，這的確發生了。）他的電腦被完全入侵了，他什麼事都做不了。甚至完全格式化電腦都不起作用，好像病毒只靠它醜陋的腦袋就能活下來。我在後來才瞭解到這種情況可能是病毒被複制到了 MBR（主引導記錄）裏。而此時，為了節約成本，公司已經終止了和外部 IT 顧問的合同。

於是我幫助同事安裝了 Ubuntu 操作系統讓他繼續工作，這的確很有效。他的電腦再次嗡嗡的運轉了，而且我找到了他們工作必需的所有應用。我承認，從某些方面來説這不是最優雅的解決方案，不過他（包括我）喜歡這個操作系統的流暢度和穩定性。

然而我的同事在 Windows 世界形成的觀念根深蒂固，他無法習慣新的使用方式，開始不停的抱怨。（很耳熟吧？）

雖然我的同事不能忍受新的使用方式，但我發現到這對我這個 Mac 用户已經不是一個問題。它們之間有很多相似點，我被迷住了。所以我在我工作用的筆記本電腦上又安裝了一個 Ubuntu 組成雙系統，我的工作效率提高了，讓機器做我想做的事也變得更容易。從那時起我有規律的使用了幾個 Linux 發行版，但我最喜歡 Ubuntu 和 Elementary。

當時我失業了，因此我有大量的時間給自己充電。由於我一直對 IT 行業很感興趣，所以我致力於研究對 Linux 操作系統的管理。但是目前得到一個展示學識的機會太難了，因為我多年來所學的 95% 都不能簡單的通過郵寄一份簡歷展示出來。我需要一個入職面試來展示我所知道的東西，所以我進行了 Linux 認證得到證書，希望能給我一些幫助。

我對開源做貢獻已經有好一陣子了。剛開始時是為 xTuple ERP（LCTT 譯註：世界領先的開源 ERP 軟件）做翻譯工作（英語譯德語），現在已經轉為在 Twitter 上做 Mozilla 的“客户服務”，提交 bug 報告等。我為自由和開源軟件做推廣宣傳（取得了不同程度的成功）並且盡我所能在財政方面支持一些 FOSS（LCTT 譯註：自由及開源軟件）倡導組織（DuckDuckGo、bof.nl、EFF、GIMP、LibreCAD、維基百科以及其他）。目前我也在準備設立一個本地的隱私咖啡館（LCTT 譯註：這是荷蘭的一個旨在強化網上個人隱私安全的咖啡館/志願者組織，參見： https://privacycafe.bof.nl/）。

除此之外，我已經開始寫我的第一本書。這應該是一本涉及計算機隱私和安全領域的簡易實用手冊，適用於普通計算機用户，我希望它能在今年年底自主出版。（這本書遵循知識共享許可協議 CC。）至於這本書的內容，正如你預料的那樣我會詳細解釋為什麼隱私如此重要，以及“我沒有什麼需要隱藏“這種思想錯的有多麼離譜。但是最主要的部分還是指導讀者如何避免讓人討厭的廣告追蹤，加密你的硬盤和郵件，通過 OTR（LCTT 譯註：一種安全協議，為即時通訊提供加密保護）網上聊天，如何使用 TOR（LCTT 譯註：第二代洋葱路由，可以在因特網上進行匿名交流）等等。雖然起初説這是一個手冊，但我儘量會使用隨和的語調來敍述，並且會根據精彩的我親身經歷的故事讓它更加通俗易懂。

我依然愛着我所有的 Mac，只要買得起（主要因為它那偉大的構造），我還會使用它們，但是我的 Linux 一直在虛擬機裏完成我的幾乎所有的日常工作。沒有什麼不可思議的，不是自誇：文檔編輯（LibreOffice 和 Scribus），建立我的網頁和Blog（Wordpress 和 Jekyll），編輯圖片（Shotwell 和 Gimp），聽音樂（Rhythmbox），以及幾乎其他任何工作。

不論我最後怎麼找到工作，Linux 永遠都是我必用的操作系統。
