ORWL：能夠刪除被篡改數據的小型開源計算機 ​

在當今這個信息時代，安全是最重要的。恐怕沒有人會希望自己的重要數據落入到壞人的手裏。但是即便是無安全防護的硬件同樣面臨不少威脅，而大多數時候人們還只是對軟件採取安全防護措施。ORWL 就是來改變這件事的。

ORWL 是什麼？ ​

ORWL 宣稱是社區裏“造得最安全的家用電腦”。 它是一台小型的飛碟形計算機，在設計上全面考慮了物理安全性。物理安全很重要，因為一旦有人獲得了從物理上訪問你的計算機的途徑，那麼就 Game Over 了，這是信息安全專業人員中的一個老生常談。

ORWL 的基本規格包括英特爾 Skylake M3 處理器、USB-C 和微型 HDMI 接口、8GB 內存、120G 固態硬盤、藍牙、Wifi 和 NFC 技術。目前它支持的操作系統有 Ubuntu 16.04、Qubes OS，以及 Windows 10 等，開箱即用。你只需要有一個顯示器，鍵盤和鼠標就可以開始使用它了。

ORWL 是開源的 ​

ORWL 是完全開源的。這意味着，如果有人想設計一台自己的計算機或者對 ORWL 作出改進的話，原理圖和設計文件、軟件、固件、所有東西都是可以獲取的。

ORWL 是如何工作的？ ​

ORWL 使用自加密固態硬盤（SSD）。一個安全微控制器集成到其主板上來產生和存儲加密密匙。一旦核實了系統的完整性和已驗證用户，它就使用密匙來解密固態硬盤（SSD）。無論對 ORWL 進行任何類型的篡改，密匙都會立即刪除固態硬盤（SSD）上的無用數據

為了完成身份驗證，ORWL 有一個使用和智能卡類似技術的密匙卡。它使用 NFC 技術來驗證用户，同時使用藍牙來檢測用户是否在當前使用範圍內。如果用户不在附近（不在使用範圍內），ORWL 將會自動鎖定。

整個 ORWL 系統被包裹在一個到處伴有壓力開關的活動翻蓋網格里。安全微控制器持續監控專用慣性測量部件，活動翻蓋網格，內部温度和電源輸入電壓，以用於檢測篡改。這將防止訪問內部組件，比如試圖破壞翻蓋將會觸發安全微控制器從而刪除加密密匙。此外，出於安全考慮，動態隨機存儲器（DRAM）也焊有外殼。

這並不是全部安全防護措施，ORWL 還有更多詳細的措施來確保設備絕對的物理安全性，包括冷啓動防護，直接存儲器訪問（DMA）攻擊防禦等。

更多信息可以在 ORWL 引導頁找到。這兒是一個關於它如何工作的快速視頻。

ORWL 是信息安全的最終答案嗎？ ​

令人沮喪的是，ORWL 並不是信息安全的最終答案。ORWL 只能為計算機提供物理安全，儘管這很強大並且看起來極酷（totally ninja），但是還有許多來自其他方面的攻擊會損壞你的系統。然而，ORWL 確實從整體上提高了計算機的安全性。

你認為 ORWL 怎麼樣？通過評論讓我們知道你的想法。
