開源新聞綜述：GNOME 和 KDE 達成合作、Nvidia 開源 GPU 文檔 ​

不要錯過兩週以來最大的開源頭條新聞。

在本期開源新聞綜述中，我們將介紹兩種新的強大數據可視化工具、Nvidia 開源其 GPU 文檔、激動人心的新工具、確保自動駕駛汽車的固件安全等等！

GNOME 和 KDE 在 Linux 桌面上達成合作夥伴 ​

Linux 在桌面計算機上一直處於分裂狀態。在最近的一篇公告中稱，“兩個主要的 Linux 桌面競爭對手，GNOME 基金會 和 KDE 已經同意合作。”

這兩個組織將成為今年 11 月在巴塞羅那舉辦的 Linux App Summit（LAS）2019 的贊助商。這一舉措在某種程度上似乎是對桌面計算不再是爭奪支配地位的最佳場所的回應。無論是什麼原因，Linux 桌面的粉絲們都有新的理由希望未來出現一個標準化的 GUI 環境。

新的開源數據可視化工具 ​

這個世界上很少有不是由數據驅動的。除非數據以人們可以互動的形式出現，否則它並不是很好使用。最近開源的兩個數據可視化項目正在嘗試使數據更有用。

第一個工具名為 Neuroglancer，由 Google 的研究團隊創建。它“使神經科醫生能夠在交互式可視化中建立大腦神經通路的 3D 模型。”Neuroglancer 通過使用神經網絡追蹤大腦中的神經元路徑並構建完整的可視化來實現這一點。科學家已經使用了 Neuroglancer（你可以從 GitHub 取得）通過掃描果蠅的大腦來建立一個交互式地圖。

第二個工具來自一個不太能想到的的來源：澳大利亞信號理事會。這是該國家類似 NSA 的機構，它“開源了內部數據可視化和分析工具之一。”這個被稱為 Constellation 的工具可以“識別複雜數據集中的趨勢和模式，並且能夠擴展到‘數十億輸入’。”該機構總幹事邁克•伯吉斯表示，他希望“這一工具將有助於產生有利於所有澳大利亞人的科學和其他方面的突破。”鑑於它是開源的，它可以使整個世界受益。

Nvidia 開始發佈 GPU 文檔 ​

多年來，圖形處理單元（GPU）製造商 Nvidia 並沒有做出什麼讓開源項目輕鬆開發其產品的驅動程序的努力。現在，該公司通過發佈 GPU 硬件文檔向這些項目邁出了一大步。

該公司根據 MIT 許可證發佈的文檔可在 GitHub 上獲取。它涵蓋了幾個關鍵領域，如設備初始化、內存時鐘/調整和電源狀態。據硬件新聞網站 Phoronix 稱，開發了 Nvidia GPU 的開源驅動程序的 Nouveau 項目將是率先使用該文檔來推動其開發工作的項目之一。

用於保護固件的新工具 ​

似乎每週都有的消息稱，移動設備或連接互聯網的小設備中出現新漏洞。通常，這些漏洞存在於控制設備的固件中。自動駕駛汽車服務 Cruise 發佈了一個開源工具，用於在這些漏洞成為問題之前捕獲這些漏洞。

該工具被稱為 FwAnalzyer。它檢查固件代碼中是否存在許多潛在問題，包括“識別潛在危險的可執行文件”，並查明“任何錯誤遺留的調試代碼”。Cruise 的工程師 Collin Mulliner 曾幫助開發該工具，他説通過在代碼上運行 FwAnalyzer，固件開發人員“現在能夠檢測並防止各種安全問題。”
