LiVES 視頻編輯器 3.0 有了顯著的改善 ​

我們最近列出了一個最佳開源視頻編輯器的清單。LiVES 是這些開源視頻編輯器之一，可以免費使用。

即使許多用户還在等待 Windows 版本的發行，但在剛剛發行的 LiVES 視頻編輯器 Linux 版本中（最新版本 v3.0.1）進行了一個重大更新，包括了一些新的功能和改進。

在這篇文章裏，我將會列出新版本中的重要改進，並且我將會提到在 Linux 上安裝的步驟。

LiVES 視頻編輯器 3.0：新的改進 ​

總的來説，在這次重大更新中 LiVES 視頻編輯器旨在提供更加平滑的回放、防止意外崩潰、優化視頻錄製，以及讓在線視頻下載器更加實用。

下面列出了變化：

  • 如果需要渲染的話，可以靜默渲染直到到視頻播放完畢。
  • 改進回放插件為 openGL，提供更加平滑的回放。
  • 重新啓用了 openGL 回放插件的高級選項。
  • 在所有幀的 VJ/預解碼中允許“Enough”
  • 重構了在回放時的時基計算的代碼（a/v 同步更好）。
  • 徹底修復了外部音頻和音頻，提高了準確性並減少了 CPU 佔用。
  • 進入多音軌模式時自動切換至內部音頻。
  • 重新顯示效果映射器窗口時，將會正常展示效果狀態（on/off）。
  • 解決了音頻和視頻線程之間的衝突。
  • 現在可以對在線視頻下載器，可以對剪輯大小和格式進行修改並添加了更新選項。
  • 對實時效果實例實現了引用計數。
  • 大量重寫了主界面，清理代碼並改進許多視覺效果。
  • 優化了視頻播放器運行時的錄製功能。
  • 改進了 projectM 過濾器封裝，包括對 SDL2 的支持。
  • 添加了一個選項來逆轉多軌合成器中的 Z-order（後層現在可以覆蓋上層了）。
  • 增加了對 musl libc 的支持
  • 更新了烏克蘭語的翻譯

如果你不是一位高級視頻編輯師，也許會對上面列出的重要更新提不起太大的興趣。但正是因為這些更新，才使得“LiVES 視頻編輯器”成為了最好的開源視頻編輯軟件。

在 Linux 上安裝 LiVES 視頻編輯器 ​

LiVES 幾乎可以在所有主要的 Linux 發行版中使用。但是，你可能並不能在軟件中心找到它的最新版本。所以，如果你想通過這種方式安裝，那你就不得不耐心等待了。

如果你想要手動安裝，可以從它的下載頁面獲取 Fedora/Open SUSE 的 RPM 安裝包。它也適用於其他 Linux 發行版。

  • 下載 LiVES 視頻編輯器

如果你使用的是 Ubuntu（或其他基於 Ubuntu 的發行版），可以安裝由 Ubuntuhandbook 維護的非官方 PPA。

下面由我來告訴你，你該做些什麼：

1、啓動終端後輸入以下命令：

sudo add-apt-repository ppa:ubuntuhandbook1/lives

系統將提示你輸入密碼用於確認添加 PPA。

2、完成後，你現在可以輕鬆地更新軟件包列表並安裝 LiVES 視頻編輯器。以下是需要你輸入的命令段：

sudo apt update
sudo apt install life-plugins

3、現在，它開始下載並安裝這個視頻編輯器，等待大約一分鐘即可完成。

總結 ​

Linux 上有許多視頻編輯器。但它們通常被認為不能用於專業編輯。而我並不是一名專業人士，所以像 LiVES 這樣免費的視頻編輯器就足以進行簡單的編輯了。
