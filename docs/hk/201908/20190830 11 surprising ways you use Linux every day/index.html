你可能意識不到的使用 Linux 的 11 種方式 ​

什麼技術運行在 Linux 上？你可能會驚訝於日常生活中使用 Linux 的頻率。

現在 Linux 幾乎可以運行每樣東西，但很多人都沒有意識到這一點。有些人可能知道 Linux，可能聽説過超級計算機運行着這個操作系統。根據 Top500，Linux 現在驅動着世界上最快的 500 台計算機。你可以轉到他們的網站並搜索“Linux”自己查看一下結果。

NASA 運行在 Linux 之上 ​

你可能不知道 Linux 為 NASA（美國國家航空航天局）提供支持。NASA 的 Pleiades 超級計算機運行着 Linux。由於操作系統的可靠性，國際空間站六年前從 Windows 切換到了 Linux。NASA 甚至最近給國際空間站部署了三台運行着 Linux 的“Astrobee”機器人。

電子書運行在 Linux 之上 ​

我讀了很多書，我的首選設備是亞馬遜 Kindle Paperwhite，它運行 Linux（雖然大多數人完全沒有意識到這一點）。如果你使用亞馬遜的任何服務，從亞馬遜彈性計算雲（Amazon EC2） 到 Fire TV，你就是在 Linux 上運行。當你問 Alexa 現在是什麼時候，或者你最喜歡的運動隊得分時，你也在使用 Linux，因為 Alexa 由 Fire OS（基於 Android 的操作系統）提供支持。實際上，Android 是由谷歌開發的用於移動手持設備的 Linux，而且佔據了當今移動電話的76％ 的市場。

電視運行在 Linux 之上 ​

如果你有一台 TiVo，那麼你也在運行 Linux。如果你是 Roku 用户，那麼你也在使用 Linux。Roku OS 是專為 Roku 設備定製的 Linux 版本。你可以選擇使用在 Linux 上運行的 Chromecast 看流媒體。不過，Linux 不只是為機頂盒和流媒體設備提供支持。它也可能運行着你的智能電視。LG 使用 webOS，它是基於 Linux 內核的。Panasonic 使用 Firefox OS，它也是基於 Linux 內核的。三星、菲利普斯以及更多廠商都使用基於 Linux 的操作系統支持其設備。

智能手錶和平板電腦運行在 Linux 之上 ​

如果你擁有智能手錶，它可能正在運行 Linux。世界各地的學校系統一直在實施一對一系統，讓每個孩子都有自己的筆記本電腦。越來越多的機構為學生配備了 Chromebook。這些輕巧的筆記本電腦使用 Chrome OS，它基於 Linux。

汽車運行在 Linux 之上 ​

你駕駛的汽車可能正在運行 Linux。 汽車級 Linux（AGL） 是一個將 Linux 視為汽車標準代碼庫的項目，它列入了豐田、馬自達、梅賽德斯-奔馳和大眾等汽車製造商。你的車載信息娛樂（IVI）系統也可能運行 Linux。GENIVI 聯盟在其網站稱，它開發了“用於集成在集中連接的車輛駕駛艙中的操作系統和中間件的標準方法”。

遊戲運行在 Linux 之上 ​

如果你是遊戲玩家，那麼你可能正在使用 SteamOS，這是一個基於 Linux 的操作系統。此外，如果你使用 Google 的眾多服務，那麼你也運行在 Linux上。

社交媒體運行在 Linux 之上 ​

當你刷屏和評論時，你可能會意識到這些平台正在做的很多工作。也許 Instagram、Facebook、YouTube 和 Twitter 都在 Linux 上運行並不令人驚訝。

此外，社交媒體的新浪潮，去中心化的聯合社區的聯盟節點，如 Mastodon、GNU Social、Nextcloud（類似 Twitter 的微博平台）、Pixelfed（分佈式照片共享）和Peertube（分佈式視頻共享）至少默認情況下在 Linux 上運行。由於開源，它們可以在任何平台上運行，這本身就是一個強大的優先級。

商業和政務運行在 Linux 之上 ​

與五角大樓一樣，紐約證券交易所也在 Linux 上運行。美國聯邦航空管理局每年處理超過 1600 萬次航班，他們在 Linux 上運營。美國國會圖書館、眾議院、參議院和白宮都使用 Linux。

零售運行在 Linux 之上 ​

最新航班座位上的娛樂系統很可能在 Linux 上運行。你最喜歡的商店的 POS 機可能正運行在 Linux 上。基於 Linux 的 Tizen OS 為智能家居和其他智能設備提供支持。許多公共圖書館現在在 Evergreen 和 Koha 上託管他們的綜合圖書館系統。這兩個系統都在 Linux 上運行。

Apple 運行在 Linux 之上 ​

如果你是使用 iCloud 的 iOS 用户，那麼你也在使用運行在 Linux 上的系統。Apple 公司的網站在 Linux 上運行。如果你想知道在 Linux 上運行的其他網站，請務必使用 Netcraft 並檢查“該網站運行在什麼之上？”的結果。

路由器運行在 Linux 之上 ​

在你家裏將你連接到互聯網的路由器可能正運行在 Linux 上。如果你當前的路由器沒有運行 Linux 而你想改變它，那麼這裏有一個優秀的方法。

如你所見，Linux 從許多方面為今天的世界提供動力。還有什麼運行在 Linux 之上的東西是人們還沒有意識到的？請讓我們在評論中知道。
