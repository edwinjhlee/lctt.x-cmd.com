Saron Yitbarek：隨着新版 Windows 的發佈，很明顯，微軟從蘋果那裏學到了蘋果從施樂那裏學來的所有想法。喬布斯很易怒。他的關於偉大藝術家如何偷竊的畢加索名言被別人學去了，而且恐怕蓋茨也正是這麼做的。[00:15:30] 據報道，當喬布斯怒斥蓋茨偷了他們的東西時，蓋茨回應道：“史蒂夫，我覺得這更像是我們都有一個叫施樂的富有鄰居，我闖進他家偷電視機，卻發現你已經偷過了”。蘋果最終以竊取 GUI 的外觀和風格為名起訴了微軟。這個案子持續了好幾年，但是在 1993 年，第 9 巡迴上訴法院的一名法官最終站在了微軟一邊。[00:16:00] Vaughn Walker 法官宣佈外觀和風格不受版權保護。這是非常重要的。這一決定讓蘋果在無法壟斷桌面計算的界面。很快，蘋果短暫的領先優勢消失了。以下是 Steven Levy 的觀點。

Steven Levy：他們之所以失去領先地位，不是因為微軟方面竊取了知識產權，而是因為他們無法鞏固自己在上世紀 80 年代擁有的更好的操作系統的優勢。坦率地説，他們的電腦索價過高。[00:16:30] 因此微軟從 20 世紀 80 年代中期開始開發 Windows 系統，但直到 1990 年開發出的 Windows 3，我想，它才真正算是一個為黃金時期做好準備的版本，才真正可供大眾使用。[00:17:00] 從此以後，微軟能夠將數以億計的用户遷移到圖形界面，而這是蘋果無法做到的。雖然蘋果公司有一個非常好的操作系統，但是那已經是 1984 年的產品了。

Saron Yitbarek：現在微軟主導着操作系統的戰場。他們佔據了 90% 的市場份額，並且針對各種各樣的個人電腦進行了標準化。操作系統的未來看起來會由微軟掌控。此後發生了什麼？[00:17:30] 1997 年，波士頓 Macworld 博覽會上，你看到了一個幾近破產的蘋果，一個謙遜的多的史蒂夫·喬布斯走上舞台，開始談論夥伴關係的重要性，特別是他們與微軟的新型合作伙伴關係。史蒂夫·喬布斯呼籲雙方緩和關係，停止火拼。微軟將擁有巨大的市場份額。從表面看，我們可能會認為世界和平了。但當利益如此巨大時，事情就沒那麼簡單了。[00:18:00] 就在蘋果和微軟在數十年的爭鬥中傷痕累累、最終敗退到死角之際，一名 21 歲的芬蘭計算機科學專業學生出現了。幾乎是偶然地，他徹底改變了一切。

我是 Saron Yitbarek，這裏是代碼英雄。

正當某些科技巨頭正忙着就專有軟件相互攻擊時，自由軟件和開源軟件的新領軍者如雨後春筍般湧現。[00:18:30] 其中一位優勝者就是理查德·斯托爾曼Richard Stallman。你也許對他的工作很熟悉。他想要有自由軟件和自由社會。這就像言論自由一樣的自由free，而不是像免費啤酒一樣的免費free。早在 80 年代，斯托爾曼就發現，除了昂貴的專有操作系統（如 UNIX）外，就沒有其他可行的替代品。因此他決定自己做一個。斯托爾曼的自由軟件基金會Free Software Foundation開發了 GNU，當然，它的意思是 “GNU's not UNIX”。它將是一個像 UNIX 一樣的操作系統，但不包含所有的 UNIX 代碼，而且用户可以自由共享。

[00:19:00] 為了讓你體會到上世紀 80 年代自由軟件概念的重要性，從不同角度來説擁有 UNIX 代碼的兩家公司，AT&T 貝爾實驗室AT&T Bell Laboratories以及UNIX 系統實驗室UNIX System Laboratories威脅將會起訴任何看過 UNIX 源代碼後又創建自己操作系統的人。這些人是次級專利所屬。[00:19:30] 用這兩家公司的話來説，所有這些程序員都在“精神上受到了污染”，因為他們都見過 UNIX 代碼。在 UNIX 系統實驗室和伯克利軟件設計公司Berkeley Software Design之間的一個著名的法庭案例中，有人認為任何功能類似的系統，即使它本身沒有使用 UNIX 代碼，也侵犯版權。Paul Jones 當時是一名開發人員。他現在是數字圖書館 ibiblio.org 的主管。

Paul Jones：[00:20:00] 任何看過代碼的人都受到了精神污染是他們的觀點。因此幾乎所有在安裝有與 UNIX 相關操作系統的電腦上工作過的人以及任何在計算機科學部門工作的人都受到精神上的污染。因此，在 USENIX 的一年裏，我們都得到了一寫帶有紅色字母的白色小別針，上面寫着“精神受到了污染”。我們很喜歡帶着這些別針到處走，以表達我們跟着貝爾實驗室混，因為我們的精神受到了污染。

Saron Yitbarek：[00:20:30] 整個世界都被精神污染了。想要保持純粹、保持事物的美好和專有的舊哲學正變得越來越不現實。正是在這被污染的現實中，歷史上最偉大的代碼英雄之一誕生了，他是一個芬蘭男孩，名叫林納斯·託瓦茲Linus Torvalds。如果這是《星球大戰》，那麼林納斯·託瓦茲就是我們的盧克·天行者Luke Skywalker。他是赫爾辛基大學一名温文爾雅的研究生。[00:21:00] 有才華，但缺乏大志。典型的被逼上梁山的英雄。和其他年輕的英雄一樣，他也感到沮喪。他想把 386 處理器整合到他的新電腦中。他對自己的 IBM 兼容電腦上運行的 MS-DOS 操作系統並不感冒，也負擔不起 UNIX 軟件 5000 美元的價格，而只有 UNIX 才能讓他自由地編程。解決方案是託瓦茲在 1991 年春天基於 MINIX 開發了一個名為 Linux 的操作系統內核。他自己的操作系統內核。

Steven Vaughan-Nichols：[00:21:30] 林納斯·託瓦茲真的只是想找點樂子而已。

Saron Yitbarek：Steven Vaughan-Nichols 是 ZDNet.com 的特約編輯，而且他從科技行業出現以來就一直在寫科技行業相關的內容。

Steven Vaughan-Nichols：當時有幾個類似的操作系統。他最關注的是一個名叫 MINIX 的操作系統，MINIX 旨在讓學生學習如何構建操作系統。林納斯看到這些，覺得很有趣，但他想建立自己的操作系統。[00:22:00] 所以，它實際上始於赫爾辛基的一個 DIY 項目。一切就這樣開始了，基本上就是一個大孩子在玩耍，學習如何做些什麼。[00:22:30] 但不同之處在於，他足夠聰明、足夠執着，也足夠友好，讓所有其他人都參與進來，然後他開始把這個項目進行到底。27 年後，這個項目變得比他想像的要大得多。

Saron Yitbarek：到 1991 年秋季，託瓦茲發佈了 10000 行代碼，世界各地的人們開始評頭論足，然後進行優化、添加和修改代碼。[00:23:00] 對於今天的開發人員來説，這似乎很正常，但請記住，在那個時候，像這樣的開放協作是對微軟、蘋果和 IBM 已經做的很好的整個專有系統的道德侮辱。隨後這種開放性被奉若神明。託瓦茲將 Linux 置於 GNU 通用公共許可證（GPL）之下。曾經保障斯托爾曼的 GNU 系統自由的許可證現在也將保障 Linux 的自由。Vaughan-Nichols 解釋道，這種融入到 GPL 的重要性怎麼強調都不過分，它基本上能永遠保證軟件的自由和開放性。

Steven Vaughan-Nichols：[00:23:30] 事實上，根據 Linux 所遵循的許可協議，即 GPL 第 2 版，如果你想販賣 Linux 或者向全世界展示它，你必須與他人共享代碼，所以如果你對其做了一些改進，僅僅給別人使用是不夠的。事實上你必須和他們分享所有這些變化的具體細節。然後，如果這些改進足夠好，就會被 Linux 所吸收。

Saron Yitbarek：[00:24:00] 事實證明，這種公開的方式極具吸引力。埃裏克·雷蒙德Eric Raymond 是這場運動的早期傳道者之一，他在他那篇著名的文章中寫道：“微軟和蘋果這樣的公司一直在試圖建造軟件大教堂，而 Linux 及類似的軟件則提供了一個由不同議程和方法組成的巨大集市，集市比大教堂有趣多了。”

tormy Peters：我認為在那個時候，真正吸引人的是人們終於可以把控自己的世界了。

Saron Yitbarek：Stormy Peters 是一位行業分析師，也是自由和開源軟件的倡導者。

Stormy Peters：[00:24:30] 當開源軟件第一次出現的時候，所有的操作系統都是專有的。如果不使用專有軟件，你甚至不能添加打印機，你不能添加耳機，你不能自己開發一個小型硬件設備，然後讓它在你的筆記本電腦上運行。你甚至不能放入 DVD 並複製它，因為你不能改變軟件，即使你擁有這張 DVD，你也無法複製它。[00:25:00] 你無法控制你購買的硬件/軟件系統。你不能從中創造出任何新的、更大的、更好的東西。這就是為什麼開源操作系統在一開始就如此重要的原因。我們需要一個開源協作環境，在那裏我們可以構建更大更好的東西。

Saron Yitbarek：請注意，Linux 並不是一個純粹的平等主義烏托邦。林納斯·託瓦茲不會批准對內核的所有修改，而是主導了內核的變更。他安排了十幾個人來管理內核的不同部分。[00:25:30] 這些人也會信任自己下面的人，以此類推，形成信任金字塔。變化可能來自任何地方，但它們都是經過判斷和策劃的。

然而，考慮到到林納斯的 DIY 項目一開始是多麼的簡陋和隨意，這項成就令人十分驚訝。他完全不知道自己就是這一切中的盧克·天行者。當時他只有 21 歲，一半的時間都在編程。但是當魔盒第一次被打開，人們開始給他反饋。[00:26:00] 幾十個，然後幾百個，成千上萬的貢獻者。有了這樣的眾包基礎，Linux 很快就開始成長。真的成長得很快。甚至最終引起了微軟的注意。他們的首席執行官史蒂夫·鮑爾默Steve Ballmer將 Linux 稱為是“一種癌症，從知識產權得角度來看，它傳染了接觸到得任何東西 ”。Steven Levy 將會描述 Ballmer 的由來。

Steven Levy：[00:26:30] 一旦微軟真正鞏固了它的壟斷地位，而且它也確實被聯邦法院判定為壟斷，他們將會對任何可能對其構成威脅的事情做出強烈反應。因此，既然他們對軟件收費，很自然得，他們將自由軟件得出現看成是一種癌症。他們試圖提出一個知識產權理論，來解釋為什麼這對消費者不利。

Saron Yitbarek：[00:27:00] Linux 在不斷傳播，微軟也開始擔心起來。到了 2006 年，Linux 成為僅次於 Windows 的第二大常用操作系統，全球約有 5000 名開發人員在使用它。5000 名開發者。還記得比爾·蓋茨給蘋果公司的備忘錄嗎？在那份備忘錄中，他向蘋果公司的員工們論述了與他人合作的重要性。事實證明，開源將把夥伴關係的概念提升到一個全新的水平，這是比爾·蓋茨從未預見到的。

[00:27:30] 我們一直在談論操作系統之間的大戰，但是到目前為止，並沒有怎麼提到無名英雄和開發者們。在下次的代碼英雄中，情況就不同了。第二集講的是操作系統大戰的第二部分，是關於 Linux 崛起的。業界醒悟過來，認識到了開發人員的重要性。這些開源反叛者變得越來越強大，戰場從桌面轉移到了服務器領域。[00:28:00] 這裏有商業間諜活動、新的英雄人物，還有科技史上最不可思議的改變。這一切都在操作系統大戰的後半集內達到了高潮。
