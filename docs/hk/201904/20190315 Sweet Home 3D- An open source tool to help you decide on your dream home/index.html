Sweet Home 3D：一個幫助你尋找夢想家庭的開源工具 ​

室內設計應用可以輕鬆渲染你喜歡的房子，不管是真實的或是想像的。

我最近接受了一份在弗吉尼亞州的新工作。由於我妻子一直在紐約工作，看着我們在紐約的房子直至出售，我有責任出去為我們和我們的貓找一所新房子。在我們搬進去之前她看不到新房子。

我和一個房地產經紀人簽約，並看了幾間房子，拍了許多照片，寫下了潦草的筆記。晚上，我會將照片上傳到 Google Drive 文件夾中，我和我老婆會通過手機同時查看這些照片，同時我還要記住房間是在右邊還是左邊，是否有風扇等。

由於這是一個相當繁瑣且不太準確的展示我的發現的方式，我因此去尋找一個開源解決方案，以更好地展示我們未來的夢想之家將會是什麼樣的，而不會取決於我的模糊記憶和模糊的照片。

Sweet Home 3D 完全滿足了我的要求。Sweet Home 3D 可在 Sourceforge 上獲取，並在 GNU 通用公共許可證下發布。它的網站信息非常豐富，我能夠立即啓動並運行。Sweet Home 3D 由總部位於巴黎的 eTeks 的 Emmanuel Puybaret 開發。

繪製內牆 ​

我將 Sweet Home 3D 下載到我的 MacBook Pro 上，並添加了 PNG 版本的平面樓層圖，用作背景底圖。

在此處，使用 Rooms 面板跟蹤圖案並設置“真實房間”尺寸是一件簡單的事情。在我繪製房間後，我添加了牆壁，我可以定製顏色、厚度、高度等。

現在我畫完了“內牆”，我從網站下載了各種“傢俱”，其中包括實際的傢俱以及門、窗、架子等。每個項目都以 ZIP 文件的形式下載，因此我創建了一個包含所有未壓縮文件的文件夾。我可以自定義每件傢俱和重複的物品比如門，可以方便地複製粘貼到指定的地方。

在我將所有牆壁和門窗都佈置完後，我就使用這個應用的 3D 視圖瀏覽房屋。根據照片和記憶，我對所有物體進行了調整，直到接近房屋的樣子。我可以花更多時間添加紋理，附屬傢俱和物品，但這已經達到了我需要的程度。

完成之後，我將該項目導出為 OBJ 文件，它可在各種程序中打開，例如 Blender 和 Mac 上的“預覽”中，方便旋轉房屋並從各個角度查看。視頻功能最有用，我可以創建一個起點，然後在房子中繪製一條路徑，並記錄“旅程”。我將視頻導出為 MOV 文件，並使用 QuickTime 在 Mac 上打開和查看。

我的妻子能夠（幾乎）能看到所有我看到的，我們甚至可以開始在搬家前佈置傢俱。現在，我所要做的就是把行李裝上卡車搬到新家。

Sweet Home 3D 在我的新工作中也是有用的。我正在尋找一種方法來改善學院建築的地圖，並計劃在 Inkscape 或 Illustrator 或其他軟件中重新繪製它。但是，由於我有平面地圖，我可以使用 Sweet Home 3D 創建平面圖的 3D 版本並將其上傳到我們的網站以便更方便地找到地方。

開源犯罪現場？ ​

一件有趣的事：根據 Sweet Home 3D 的Blog，“法國法醫辦公室（科學警察）最近選擇 Sweet Home 3D 作為設計規劃表示路線和犯罪現場的工具。這是法國政府建議優先考慮自由開源解決方案的具體應用。“

這是公民和政府如何利用開源解決方案創建個人項目、解決犯罪和建立世界的又一點證據。
