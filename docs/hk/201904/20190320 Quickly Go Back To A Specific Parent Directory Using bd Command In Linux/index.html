在 Linux 中使用 bd 命令快速返回到特定的父目錄 ​

兩天前我們寫了一篇關於 autocd 的文章，它是一個內置的 shell 變量，可以幫助我們在沒有 cd 命令的情況下導航到目錄中。

如果你想回到上一級目錄，那麼你需要輸入 cd ..。

如果你想回到上兩級目錄，那麼你需要輸入 cd ../..。

這在 Linux 中是正常的，但如果你想從第九級目錄回到第三級目錄，那麼使用 cd 命令是很糟糕的。

有什麼解決方案呢？

是的，在 Linux 中有一個解決方案。我們可以使用 bd 命令來輕鬆應對這種情況。

什麼是 bd 命令？ ​

bd 命令允許用户快速返回 Linux 中的父目錄，而不是反覆輸入 cd ../../..。

你可以列出給定目錄的內容，而不用提供完整路徑 ls bd Directory_Name。它支持以下其它命令，如 ls、ln、echo、zip、tar 等。

另外，它還允許我們執行 shell 文件而不用提供完整路徑 bd p/shell_file.sh。

如何在 Linux 中安裝 bd 命令？ ​

除了 Debian/Ubuntu 之外，bd 沒有官方發行包。因此，我們需要手動執行方法。

對於 Debian/Ubuntu 系統，使用 APT-GET 命令或APT 命令來安裝 bd。

$ sudo apt install bd

對於其它 Linux 發行版，使用 wget 命令下載 bd 可執行二進制文件。

$ sudo wget --no-check-certificate -O /usr/local/bin/bd https://raw.github.com/vigneshwaranr/bd/master/bd

設置 bd 二進制文件的可執行權限。

$ sudo chmod +rx /usr/local/bin/bd

在 .bashrc 文件中添加以下值。

$ echo 'alias bd=". bd -si"' >> ~/.bashrc

運行以下命令以使更改生效。

$ source ~/.bashrc

要啓用自動完成，執行以下兩個步驟。

$ sudo wget -O /etc/bash_completion.d/bd https://raw.github.com/vigneshwaranr/bd/master/bash_completion.d/bd  
$ sudo source /etc/bash_completion.d/bd

我們已經在系統上成功安裝並配置了 bd 實用程序，現在是時候測試一下了。

我將使用下面的目錄路徑進行測試。

運行 pwd 命令或 dirs 命令，亦或是 tree 命令來了解你當前的路徑。

daygeek@Ubuntu18:/usr/share/icons/Adwaita/256x256/apps$ pwd
或
daygeek@Ubuntu18:/usr/share/icons/Adwaita/256x256/apps$ dirs

/usr/share/icons/Adwaita/256x256/apps

我現在在 /usr/share/icons/Adwaita/256x256/apps 目錄，如果我想快速跳轉到 icons 目錄，那麼只需輸入以下命令即可。

daygeek@Ubuntu18:/usr/share/icons/Adwaita/256x256/apps$ bd icons
/usr/share/icons/
daygeek@Ubuntu18:/usr/share/icons$

甚至，你不需要輸入完整的目錄名稱，也可以輸入幾個字母。

daygeek@Ubuntu18:/usr/share/icons/Adwaita/256x256/apps$ bd i
/usr/share/icons/
daygeek@Ubuntu18:/usr/share/icons$

注意：如果層次結構中有多個同名的目錄，bd 會將你帶到最近的目錄。（不考慮直接的父目錄）

如果要列出給定的目錄內容，使用以下格式。它會打印出 /usr/share/icons/ 的內容。

$ ls -lh `bd icons`
或

如果要在父目錄中的某個位置執行文件，使用以下格式。它將運行 shell 文件 /usr/share/icons/users-list.sh。

$ `bd i`/users-list.sh
或
daygeek@Ubuntu18:/usr/share/icons/Adwaita/256x256/apps$ `bd icon`/users-list.sh
daygeek

如果你位於 /usr/share/icons/Adwaita/256x256/apps 中，想要導航到不同的父目錄，使用以下格式。以下命令將導航到 /usr/share/icons/gnome 目錄。

$ cd `bd i`/gnome
或
daygeek@Ubuntu18:/usr/share/icons/Adwaita/256x256/apps$ cd `bd icon`/gnome
daygeek@Ubuntu18:/usr/share/icons/gnome$

如果你位於 /usr/share/icons/Adwaita/256x256/apps ，你想在 /usr/share/icons/ 下創建一個新目錄，使用以下格式。

$ daygeek@Ubuntu18:/usr/share/icons/Adwaita/256x256/apps$ sudo mkdir `bd icons`/2g

daygeek@Ubuntu18:/usr/share/icons/Adwaita/256x256/apps$ ls -ld `bd icon`/2g
drwxr-xr-x 2 root root 4096 Mar 16 05:44 /usr/share/icons//2g

本教程允許你快速返回到特定的父目錄，但沒有快速前進的選項。

我們有另一個解決方案，很快就會提出，請保持關注。
