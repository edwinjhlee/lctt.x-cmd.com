12 個最佳 GNOME（GTK）主題 ​

讓我們來看一些漂亮的 GTK 主題，你不僅可以用在 Ubuntu 上，也可以用在其它使用 GNOME 的 Linux 發行版上。

對於我們這些使用 Ubuntu 的人來説，默認的桌面環境從 Unity 變成了 Gnome 使得主題和定製變得前所未有的簡單。Gnome 有個相當大的定製用户社區，其中不乏可供用户選擇的漂亮的 GTK 主題。最近幾個月，我不斷找到了一些喜歡的主題。我相信這些是你所能找到的最好的主題之一了。

Ubuntu 和其它 Linux 發行版的最佳主題 ​

這不是一個詳細清單，可能不包括一些你已經使用和喜歡的主題，但希望你能至少找到一個能讓你喜愛的沒見過的主題。所有這裏提及的主題都可以工作在 Gnome 3 上，不管是 Ubuntu 還是其它 Linux 發行版。有一些主題的屏幕截屏我沒有，所以我從官方網站上找到了它們的圖片。

在這裏列出的主題沒有特別的次序。

但是，在你看這些最好的 GNOME 主題前，你應該學習一下 如何在 Ubuntu GNOME 中安裝主題。

1、Arc-Ambiance ​

Arc 和 Arc 變體主題已經出現了相當長的時間，普遍認為它們是最好的主題之一。在這個示例中，我選擇了 Arc-Ambiance ，因為它是 Ubuntu 中的默認 Ambiance 主題。

我是 Arc 主題和默認 Ambiance 主題的粉絲，所以不用説，當我遇到一個融合了兩者優點的主題，我不禁長吸了一口氣。如果你是 Arc 主題的粉絲，但不是這個特定主題的粉絲，Gnome 的外觀上當然還有適合你口味的大量的選擇。

  • 下載 Arc-Ambiance 主題

2、Adapta Colorpack ​

Adapta 主題是我所見過的最喜歡的扁平主題之一。像 Arc 一樣，Adapata 被很多 Linux 用户廣泛採用。我選擇這個配色包，是因為一次下載你就有數個可選擇的配色方案。事實上，有 19 個配色方案可以選擇，是的，你沒看錯，19 個呢！

所以，如果你是如今常見的扁平風格/材料設計風格Material Design Language的粉絲，那麼，在這個主題包中很可能至少有一個能滿足你喜好的變體。

  • 下載 Adapta Colorpack 主題

3、Numix Collection ​

啊，Numix! 讓我想起了我們一起度過的那些年！對於那些在過去幾年裝點過桌面環境的人來説，你肯定在某個時間點上遇到過 Numix 主題或圖標包。Numix 可能是我愛上的第一個 Linux 現代主題，現在我仍然愛它。雖然經過這些年，但它仍然魅力不失。

灰色色調貫穿主題，尤其是默認的粉紅色高亮，帶來了真正乾淨而完整的體驗。你可能很難找到一個像 Numix 一樣精美的主題包。而且在這個主題包中，你還有很多可供選擇的餘地，簡直不要太棒了！

  • 下載 Numix Collection 主題

4、Hooli ​

Hooli 是一個已經出現了一段時間的主題，但是我最近才偶然發現它。我是很多扁平主題的粉絲，但是通常不太喜歡材料設計風格的主題。Hooli 像 Adapta 一樣吸取了那些設計風格，但是我認為它和其它的那些有所不同。綠色高亮是我對這個主題最喜歡的部分之一，並且，它在不衝擊整個主題方面做的很好。

  • 下載 Hooli 主題

5、Arrongin/Telinkrin ​

福利：二合一主題！它們是在主題領域中的相對新的競爭者。它們都吸取了 Ubuntu 接近完成的 “communitheme” 的思路，並帶它到了你的桌面。這兩個主題我能找到的唯一真正的區別就是顏色。Arrongin 以 Ubuntu 家族的橙色顏色為中心，而 Telinkrin 則更偏向於 KDE Breeze 系的藍色，我個人更喜歡藍色，但是兩者都是極好的選擇！

  • 下載 Arrongin/Telinkrin 主題

6、Gnome-osx ​

我不得不承認，通常，當我看到一個主題有 “osx” 或者在標題中有類似的內容時我就不會不期望太多。大多數受 Apple 啓發的主題看起來都比較雷同，我真不能找到使用它們的原因。但我想這兩個主題能夠打破這種思維定式：這就是 Arc-osc 主題和 Gnome-osx 主題。

我喜歡 Gnome-osx 主題的原因是它在 Gnome 桌面上看起來確實很像 OSX。它在融入桌面環境而不至於變的太扁平方面做得很好。所以，對於那些喜歡稍微扁平的主題的人來説，如果你喜歡紅黃綠按鈕樣式（用於關閉、最小化和最大化），這個主題非常適合你。

  • 下載 Gnome-osx 主題

7、Ultimate Maia ​

曾經有一段時間我使用 Manjaro Gnome。儘管那以後我又回到了 Ubuntu，但是，我希望我能打包帶走的一個東西是 Manjaro 主題。如果你對 Manjaro 主題和我一樣感受相同，那麼你是幸運的，因為你可以帶它到你想運行 Gnome 的任何 Linux 發行版！

豐富的綠色顏色，Breeze 式的關閉、最小化、最大化按鈕，以及全面雕琢過的主題使它成為一個不可抗拒的選擇。如果你不喜歡綠色，它甚至為你提供一些其它顏色的變體。但是説實話……誰會不喜歡 Manjaro 的綠色呢？

  • 下載 Ultimate Maia 主題

8、Vimix ​

這是一個讓我激動的主題。它是現代風格的，吸取了 macOS 的紅黃綠按鈕的風格，但並不是直接複製了它們，並且減少了多變的主題顏色，使之成為了大多數主題的獨特替代品。它帶來三個深色的變體和幾個彩色配色，我們中大多數人都可以從中找到我們喜歡的。

  • 下載 Vimix 主題

9、Ant ​

像 Vimix 一樣，Ant 從 macOS 的按鈕顏色中吸取了靈感，但不是直接複製了樣式。在 Vimix 減少了顏色花哨的地方，Ant 卻增加了豐富的顏色，在我的 System 76 Galago Pro 屏幕看起來絢麗極了。三個主題變體的變化差異大相逕庭，雖然它可能不見得符合每個人的口味，它無疑是最適合我的。

  • 下載 Ant 主題

10、Flat Remix ​

如果你還沒有注意到這點，對於一些關注關閉、最小化、最大化按鈕的人來説我就是一個傻瓜。Flat Remix 使用的顏色主題是我從未在其它地方看到過的，它採用紅色、藍色和橙色方式。把這些添加到一個幾乎看起來像是一個混合了 Arc 和 Adapta 的主題的上面，就有了 Flat Remix。

我本人喜歡它的深色主題，但是換成亮色的也是非常好的。因此，如果你喜歡稍稍透明、風格一致的深色主題，以及偶爾的一點點顏色，那 Flat Remix 就適合你。

  • 下載 Flat Remix 主題

11、Paper ​

Paper 已經出現一段時間。我記得第一次使用它是在 2014 年。可以説，Paper 的圖標包比其 GTK 主題更出名，但是這並不意味着它自身的主題不是一個極好的選擇。即使我從一開始就傾心於 Paper 圖標，我不能説當我第一次嘗試它的時候我就是一個 Paper 主題忠實粉絲。

我覺得鮮亮的色彩和有趣的方式被放到一個主題裏是一種“不成熟”的體驗。現在，幾年後，Paper 在我心目中已經長大，至少可以這樣説，這個主題採取的輕快方式是我非常欣賞的一個。

  • 下載 Paper 主題

12、Pop ​

Pop 在這個列表上是一個較新的主題，是由 System 76 的人們創造的，Pop GTK 主題是前面列出的 Adapta 主題的一個分支，並帶有一個匹配的圖標包，圖標包是先前提到的 Paper 圖標包的一個分支。

該主題是在 System 76 發佈了 他們自己的發行版 Pop!_OS 之後不久發佈的。你可以閲讀我的 Pop!_OS 點評 來了解更多信息。不用説，我認為 Pop 是一個極好的主題，帶有華麗的裝飾，併為 Gnome 桌面帶來了一股清新之風。

  • 下載 Pop 主題

結束語 ​

很明顯，我們有比文中所描述的主題更多的選擇，但是這些大多是我在最近幾月所使用的最完整、最精良的主題。如果你認為我們錯過一些你確實喜歡的主題，或你確實不喜歡我在上面描述的主題，那麼在下面的評論區讓我們知道，並分享你喜歡的主題更好的原因！
