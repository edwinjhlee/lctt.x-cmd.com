哦，不！Fedora 正在放棄對流行的視頻編解碼器的支持 ​

Fedora 37（和 36）可能不再允許你使用一些流行的編解碼器來方便地使用視頻的圖形加速功能。

Fedora 是一個流行的 Linux 發行版，迎合了那些希望在他們的工作站（和服務器）上使用最先進技術的用户。

它沒有搭載任何專有組件，默認情況下堅持使用完全開源的軟件庫。

雖然這對一些人來説已經很不方便了，但現在看來，另一個變化可能會困擾期待 Fedora 37 的用户。

最近在 Fedora 上的一個 Mesa 的提交 告訴我們，由於法律問題，H.264、H.265 和 VC-1 編解碼器的視頻加速 API（VAAPI）的支持已經被禁用。

這一變化可能也會被回傳到 Fedora 36。

💡 H.264 是大多數視頻行業使用的主流視頻編解碼器。

例如，蘋果公司廣泛使用 H.264 編解碼器，用於 iPhone 手機拍攝的照片和視頻。你可以閲讀此 文檔 來了解更多。

Fedora 項目論壇的一位成員 首先發現 了 Fedora 中的這一變化，他將其描述為 “F36 的一大退步”。

這對 Fedora 用户來説是壞消息嗎？ ​

是的，基本上是的。

主要是，它將影響使用開源驅動程序的 AMD GPU 用户，阻止他們使用 GPU 加速 來播放需要使用這些編解碼器的視頻內容。

此外，它還會影響到 任何使用開源圖形驅動的用户，即使他們在英特爾芯片上運行 iGPU。Fedora 開發者還沒有對此提供任何澄清，但你可以自己測試一下。

如果你在英偉達顯卡上使用專有驅動程序，你就沒有什麼可擔心的。

運行舊硬件的用户也可能有問題，他們的系統可能不支持這些編解碼器。

這些編解碼器最常用在你從 BT 或各種服務中下載的視頻中，這些視頻還沒有轉移到更新一代的編解碼器（如 AV1 和 VP9）。

我相信，這是互聯網上的大部分視頻的情況。

一些流媒體平台也使用這些編解碼器在其各自的平台上提供內容，這可能導致用户在試圖通過其服務訪問內容時面臨問題。

這是否影響到每個人？ ​

如果你是那些觀看 YouTube 視頻的人，不使用任何需要這些編解碼器的視頻的平台或下載它們，你就不會有任何問題。

Fedora 正在避免法律上的麻煩 ​

還沒有人起訴 Fedora 或強迫他們這樣做。然而，正如 Phoronix 所指出的，Mesa 的一個變化最近允許開發者選擇性地禁用編解碼器，以幫助避免法律糾紛和軟件專利衝突。

因此，為了避免法律上的混亂，Fedora 進行了這一改變。

H.264 和 H.265 的專利屬於一家名為 MPEG LA 的公司，該公司專門用於持有視頻編解碼器和顯示標準領域的專利。

而 VC-1 的專利屬於 SMPTE，這是一個由媒體和娛樂機構的專業人士管理的團體。

考慮到用户在購買顯卡時已經支付了使用這些編解碼器的許可，我們仍然不確定為什麼會這樣。你可以在 Fedora 的法律列表會話 中閲讀更多相關信息。

可能的解決方法是什麼？ ​

顯然，你必須依賴基於 CPU 的解碼了。當然，你也可以使用官方或第三方的 Mesa 構建版本。

Flatpak 應用程序可能允許你觀看圖形加速的視頻內容而沒有問題。但是，這要取決於軟件的維護者。

但是，對於大多數用户來説，這可能是一個不方便的解決方案。

另一個解決方法可能是在旨在包含第三方應用程序的 RPM Fusion 倉庫中單獨包含支持 VAAPI 的編解碼器。

然而，負責 Fedora RPM Fusion 倉庫的開發者對維護 Fedora Mesa 3D 的復刻版本不感興趣。該開發者提到：

rpmfusion 基本上沒有興趣去打包和維護它，而且保持倉庫與 Fedora 同步對我來説也不是一個優先事項。
