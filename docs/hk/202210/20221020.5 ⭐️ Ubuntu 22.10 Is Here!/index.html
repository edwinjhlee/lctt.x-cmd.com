Ubuntu 22.10 的新變化 ​

Ubuntu 22.10 是一個令人印象深刻的版本，它擁有新的快速切換功能、應用程序散佈，以及更多。

Ubuntu 22.10 “充滿活力的捻角羚Kinetic Kudu”來了。它帶來了許多重大的改進，特別是 Linux 內核 5.19 和 GNOME 43 的體驗。

當然，這是一個經過定製的 GNOME 體驗，現有的 Ubuntu 用户會很熟悉。

那麼，Ubuntu 22.10 都有哪些新變化呢？讓我們一起來看看。

Ubuntu 22.10 的新變化 ​

除了 GNOME 43 之外，Ubuntu 22.10 還包括：

  • 一個改進的 設置Settings 應用程序。
  • 經典的 Unity 應用程序散佈模式Spread Mode的復活。
  • 一些著名的應用程序被移植到 GTK4 和 Libadwaita。
  • 全系統支持 WebP。
  • PipeWire 採樣管默認的音頻服務器。
  • Linux 內核 5.19。

💡 Ubuntu 22.10 將被支持九個月，直到 2023 年 7 月。如果你想要穩定而不是功能，你應該更願意使用 LTS 版本。

🎨 視覺改進 ​

當第一次測試一個新版本時，視覺上的變化總是最先被注意到的。在 Ubuntu 22.10 中尤其如此，這要歸功於 GNOME 43 所帶來的重大改進。

首先，我們有全新的快速設置菜單，它取代了舊的、相當笨拙的系統菜單。與安卓、iOS 和 Windows 11 中的菜單類似，這個新增的菜單允許你打開和關閉 Wi-Fi 和藍牙，所有這些都無需進入設置Settings應用程序。

當然，在這個版本中我們還得到了全新的壁紙。

對於這個變化，我除了喜歡並希望從社區中看到更多這樣的設計之外，沒有什麼別的可説的。

此外，更多的應用程序被移植到了 GTK4，包括對 Nautilus 文件管理器的改進。

一些有價值的新增功能包括：

  • 拖動並選擇文件的能力（橡皮筋選擇）。
  • 自適應視圖與一個緊湊的窗口。
  • 新的文件上下文菜單。

你可以通過我們的詳細報道來探索 Nautilus 的改進。

👴 應用程序散佈回來了！ ​

我不太喜歡的 GNOME 的一個部分是多窗口應用程序的切換，我相信很多其他用户都有這樣的不滿。

幸運的是，Ubuntu 22.10 現在提供了一個很好的解決方案，對於長期用户來説應該是很熟悉的。終於，在 2017 年放棄對 Unity 的支持五年後，Ubuntu 的開發者們又把應用程序散佈Spread帶了回來。

這是一個重大的改進，我很驚訝 GNOME 自己沒有這樣做。

🛠️ 設置的改進 ​

雖然不是大多數人日常使用的應用程序，但系統設置System Settings是 GNOME 體驗的一個核心部分。考慮到這一點，看到它接受了一次重大的視覺改造，以及移植到了 GTK 4 和 Libadwaita，真是太棒了。

因此，它現在變得更好看了，而且是自適應的，這意味着它在任何尺寸下都能很好地工作，甚至在像 PinePhone 這樣的 Linux 手機上也能很好地工作!

另一個與設置有關的變化是增加了一個新的 “Ubuntu 桌面設置Ubuntu Desktop Settings”菜單項。這提供了一個單一的、統一的地方來定製和改變你所有的 Ubuntu 特定設置。

Linux 內核 5.19 ​

Ubuntu 22.10 還帶來了一個更新的內核，即 Linux 內核 5.19。這個版本的改進相當少，儘管它確實帶來了對一些下一代硬件的改進支持。

你應該注意到這是 Linux 5.x 系列的最後一個版本，因為 Linux 內核下一個版本跳到了 6.0。

其他變化 ​

總的來説有幾個細微的調整。但其中一些基本的調整包括：

  • 圖像應用程序默認支持 .WebP 圖像格式。
  • GNOME 文本編輯器是默認編輯器。你可以安裝 gedit 並使其成為默認的。
  • GNOME 圖書應用程序已經不再可用。Ubuntu 推薦 Foliate 作為替代。
  • 不再默認安裝 To Do 應用程序，並且它有了一個新的名字，“Endeavour”。
  • GNOME 終端仍然是默認的終端應用。如果需要，可以安裝 GNOME 控制台。
  • 更新了 Firefox 104、Thunderbird 102 和 Libreoffice 7.4 等應用程序。
  • 更多的應用程序已經被移植到 GTK4，特別是 Nautilus。

ℹ️ 注意，我們的列表集中在對桌面終端用户重要的變化上。如果你想知道更多關於服務器和其他使用情況的變化/更新，請參考 官方發佈説明。

下載 Ubuntu 22.10 ​

你可以從 Ubuntu 的中央鏡像庫 或其 官方網站 下載最新的 ISO。

**官方網站/倉庫可能需要一段時間來提供 ISO 的下載。
