類似 Notion 的 Markdown 筆記應用黑曜石推出測試版 ​

黑曜石 1.0 做了重新設計，帶來了有價值的新功能。

黑曜石Obsidian 是一款強大的筆記應用，可以用來製作知識圖譜，同時還提供 Notion 類似的功能。

在 1.0 更新之前，我們已經有一篇關於它的 詳細文章。

黑曜石 1.0 的發佈標誌着該應用在桌面和移動體驗方面的發展邁出了關鍵一步。

💡 黑曜石不是一個開源的應用程序，但可以在 Linux 上使用。

讓我們來看看它的桌面版提供的新功能。

🆕 黑曜石 1.0 的新功能 ​

1.0 版本增加了大量的新功能、主要的視覺變化和錯誤修復，其中一些亮點包括：

  • 改良的用户界面
  • 新的外觀設置
  • 帶有標籤堆疊的標籤功能
  • 大修的主題畫廊
  • 各種錯誤的修復

🎨 用户界面的改造 ​

用户界面已經得到了全面改造，這使得用户體驗更加直觀和強大。

除此之外，黑曜石現在還有一個專門的外觀設置部分。它包含了切換顯示內聯標題、標籤標題欄、改變重點顏色等選項的設置。

帶有標籤堆疊的標籤功能 ​

現在你可以在黑曜石中打開多個標籤，並使用熱鍵來幫助你在忙碌的一天中完成多個任務。

一個額外的好處是，即使你退出黑曜石，它也會記住你曾經打開的標籤和你在這些標籤中的活動狀態。

標籤也可以分組形成堆疊，並在它們之間進行切換，從而使工作空間變得更加整齊。

🛠️ 其他變化 ​

其他值得一提的變化包括：

  • 改變縮放級別的能力
  • 改進了黑曜石的同步
  • 內存泄漏修復
  • 用於摺疊行的摺疊命令

你可以通過 發佈説明，以及 發佈公告 來了解更多的細節。

📥 下載黑曜石 1.0 ​

你可以到 官方網站 下載黑曜石 1.0。在手機上，也可以在谷歌應用商店和蘋果的應用商店上找到它。

為 Linux 用户提供了三個軟件包：AppImage、Flatpak 和 Snap。

開發者還澄清説，他們不會向個人用户收取黑曜石的使用費。
