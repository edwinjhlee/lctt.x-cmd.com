3 步在 Linux 上安裝 JDBC ​

安裝 Java，使用 Maven 安裝 JDBC，並安裝資料庫。然後，你就可以在 Java 代碼中與資料庫進行交互了。

當你編寫一個應用時，需要數據存儲是很常見的。有時你要存儲你的應用需要的素材數據，其他時候你要存儲用户數據，包括偏好和保存的數據。存儲數據的一種方式是在資料庫中，為了在你的代碼和資料庫之間進行通信，你需要為你的語言提供一個數據庫綁定或連接器。對於 Java 來説，一個常見的資料庫連接器是 JDBC（Java 資料庫連接Java database connectivity）。

1、安裝 Java ​

當然，要使用 Java 進行開發，你還必須安裝 Java。對於 Linux、macOS 和 WSL 或 Cygwin，我推薦 SDKman。對於 Windows，你可以從 developers.redhat.com 下載 OpenJDK。

2、使用 Maven 安裝 JDBC ​

JDBC 是一種 API，通過語句 import java.sql.* 導入到你的代碼中，但要使其有用，你必須安裝資料庫驅動和資料庫以與之交互。你使用的資料庫驅動和要通信的資料庫必須匹配：要與 MySQL 交互，你需要 MySQL 驅動，要與 SQLite3 交互，你必須具有 SQLite3 驅動等等。

在本文中，我使用 PostgreSQL，但所有主流資料庫，包括 MariaDB 和 SQLite3，都有 JDBC 驅動程序。

你可以從 jdbc.postgresql.org 下載 JDBC for PostgreSQL。我使用 Maven 來管理 Java 依賴項，因此我將它包含在 pom.xml 中（調整 Maven Central 上的當前版本號）：

<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <version>42.5.0</version>
</dependency>

3、安裝資料庫 ​

你必須安裝要通過 JDBC 連接的資料庫。有幾個非常好的開源資料庫，但是我只能為這篇文章選擇一個，所以我選擇了 PostgreSQL。

要在 Linux 上安裝 PostgreSQL，請使用你的軟件倉庫。在 Fedora、CentOS、Mageia 和類似設備上：

$ sudo dnf install postgresql postgresql-server

在 Debian、Linux Mint、Elementary 和類似平台上：

$ sudo apt install postgresql postgresql-contrib

資料庫連接 ​

如果你不使用 PostgreSQL，同樣的一般過程也適用：

  1. 安裝 Java。
  2. 為你選擇的資料庫找到 JDBC 驅動，並將其包含在你的 pom.xml 文件中。
  3. 在你的開發系統上安裝資料庫（服務器和客户端）。

三個步驟，你就可以開始編寫代碼了。
