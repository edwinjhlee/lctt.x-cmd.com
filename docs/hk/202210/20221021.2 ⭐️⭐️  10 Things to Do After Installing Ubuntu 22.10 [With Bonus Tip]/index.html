安裝 Ubuntu 22.10 後要做的 10 件事 ​

以下是我們安裝 Ubuntu 22.10 “Kinetic Kudu”（GNOME 版）後，推薦做的 10 件事列表。

Ubuntu 22.10 帶來了很多令人興奮的新功能，例如 GNOME 43、最新的內核、重新設計的托盤菜單、文件應用的功能和 Pipewire 等 新功能。

我相信你已經迫不及待地想嘗試 Ubuntu 22.10 上的這些新功能了。

但是請先等一等。

在你前往享受你新安裝的 Ubuntu 22.10 之前，我要向你推薦一個不容錯過的 Ubuntu 定製技巧列表。

安裝 Ubuntu 22.10 後要做的 10 件事 ​

1、更新你的系統 ​

安裝好 Ubuntu 22.10 後，第一件要做的事就是更新你的系統。因為時差的原因，最新的 ISO 鏡像通常不會包括所有的系統更新。所以，你要打開一個終端窗口，並運行以下命令，來更新你的系統。

sudo apt update && sudo apt upgrade

上述命令執行完成後，你就可以進行下一步啦。

2、刪除 Firefox Snap，並安裝 Flatpak 或者 deb 版本的 Firefox ​

自去年發佈的 Ubuntu 21.10 版本以來，默認的網頁瀏覽器 Firefox 開始以 Snap 軟件包的形式出現。如果你是普通用户，這可能不是一個問題或者需要擔心的事情。但是出於幾個原因，例如 Snap 軟件包的 Firefox 啓動時間較長、且當 Firefox 有後台更新時，會有不必要的 Snap 更新通知等等原因，導致許多用户不太喜歡 Firefox 的 Snap 軟件包。

因此，你可以按照 我寫的另一篇操作指南，來完全刪除 Firefox 的 Snap 軟件包。這一過程有點複雜，需要花費一點時間。刪除完成後，再從個人軟件包存檔（PPA）安裝 deb 版本的 Firefox，或者使用 Flatpak 版本 的 Firefox。

這是一個可選的動作，你也可以跳過這一步驟。

3、安裝並啓用 Flatpak ​

雖然，幾乎所有最新的 Linux 發行版都會默認安裝 Flatpak，但是 Ubuntu 並沒有默認安裝 Flatpak，這是因為 Ubuntu 使用了它自己的沙箱技術 Snap。

但 Flatpak 這一應用程序還是最適合於每個人。Flatpak 能夠幫助你快速安裝多個應用程序，並在使用過程中無需擔心依賴性和其他事情。

大多數 Flatpak 應用程序都在集中的倉庫 Flathub 中。

要在 Ubuntu 22.10 中啓用 Flatpak 應用程序，請按照以下命令進行操作。

sudo apt install flatpakflatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakreporeboot

如果你想進一步瞭解關於此安裝過程的更多信息，請閲讀我們不久前發佈的 指南。

4、查看隱私設置 ​

我建議你在安裝 Ubuntu 後，手動退出任何數據收集項。大家都知道，無論怎麼努力嘗試，在互聯網上保護自己的隱私都很困難。因此，這些小步驟很重要。

要配置隱私項，請打開“設置Settings”並選擇“隱私Privacy”。然後查看隱私菜單下列出的項目。

此外，請確保禁用對 Ubuntu 服務器的後台報告。需要運行以下命令來手動禁用，因為在設置中沒有禁用它的選項。

sudo ubuntu-report -f send no

5、探索 GNOME 43 的功能 ​

在 Ubuntu 22.10 版本中，最具視覺和功能性的變化是 GNOME 43。因為 GNOME 43 有一些根本性和核心變化，所以它會影響每個人和他們的工作。GNOME 43 帶來了一個新的藥丸形狀的托盤菜單，並更新了文件應用和 GNOME Web 等原生應用程序的功能。

請查看更為詳細的 GNOME 43 功能 一文，以瞭解更多信息，或者你也可以自己探索 GNOME 43。

6、確保音頻可以與 Pipewire 配合使用 ​

如果你經常使用音頻，或者你的工作範圍涉及到聲音捕獲、播放等內容，請確保在 Ubuntu 22.10 中，你的音頻在有線或藍牙情況下都能正常工作。

因為 Ubuntu 22.10 這個版本中的音頻服務器是多年來第一次發生了變化，傳統的 PulseAudio 被現代的 Pipewire 所取代。因此，請務必進行驗證音頻是否能正常使用。

7、安裝其他軟件包 ​

確保你可以在 Ubuntu 桌面上播放所有視頻和音頻格式是很重要的。如果你在設置期間跳過了額外的軟件包安裝，可以通過以下命令進行安裝。

sudo apt install ubuntu-restricted-extras

這可以解決 Ubuntu 中的任何視頻或音頻的播放問題，特別是 GNOME 視頻無法播放的情況（因為GNOME 視頻在默認情況下將無法播放任何內容）。

8、安裝基本的應用程序 ​

帶有 GNOME 的 Ubuntu 基礎版本只有非常基本的應用程序。因此，在你使用 Ubuntu 之前，你需要安裝一些其他必要的應用程序。

由於每個人的工作範圍不同，每個人所需的應用程序也都不同。因此，在這裏我僅提供一個通用的應用程序的列表，我認為你可以把這些應用程序都安裝上，因為這些應用程序對所有人來説都很常用。

  • GIMP – 進階的照片編輯器
  • VLC – 無需額外編解碼器即可播放任何內容的媒體播放器
  • Leafpad – 輕量級文本編輯器（甚至比默認的文本編輯器 gedit 還要更輕量級）
  • Synaptic – 更好的軟件包管理器

安裝這些應用程序的命令：

sudo apt install -y gimp vlc leafpad synaptic

9、獲取一些 GNOME 擴展 ​

你可以使用幾個很酷的擴展程序，來擴展 GNOME 43 的功能，包括自定義頂部欄、托盤、更改 adwaita 外觀等等。首先，使用下面的命令通過 Flatpak 來安裝 GNOME 擴展管理器。

flatpak install flathub com.mattjakeman.ExtensionManager

安裝完成後，你就可以在 GNOME 擴展管理器中搜索你想要的任何擴展了。以下是一些必要擴展，你可以用它們來快速擴展 GNOME 43 的功能，我認為它們非常適合你全新的 Ubuntu 桌面。你只需在擴展管理器應用程序中，搜索這些名稱即可。

  • Caffeine
  • Custom Hot Corners
  • Dash to Dock
  • Blur my shell
  • Gradients
  • Hide Activities Button
  • Net speed simplified

10、準備備份 ​

我們總是在我們遇到困難時，才覺得有必要備份。所以，請確保從一開始你就為備份做好了準備。理想的備份應用程序是 Timeshift，它很容易安裝和使用。

以下是你可以從終端安裝 Timeshift 的一組命令。安裝完成後，你可以打開 Timeshift，並按照屏幕上的説明，設置備份了。

sudo add-apt-repository -y ppa:teejee2008/ppasudo apt-get updatesudo apt-get install timeshift

額外小技巧 ​

如果你想進一步定製你新安裝的 Ubuntu 系統，以下是一些額外的小技巧。

安裝漂亮的字體 ​

字體是一個很小卻影響很大的設置項。雖然，Ubuntu 自帶有好用的“Ubuntu regular”字體。

但是，你也可以從 Ubuntu 的官方倉庫中安裝一些其他漂亮的字體。以下是安裝字體的一些命令。

sudo apt install fonts-roboto fonts-cascadia-code fonts-firacode

安裝完成後，你可以使用 GNOME Tweak 工具，來更改字體。

安裝 TLP ​

如果你經常使用筆記本電腦，那麼你要好好愛惜電腦的電池。雖然電池用久了總是會損壞的，但你可以採取一些步驟，來減緩電池的老化。TLP 是 Linux 中自動優化電池使用、減緩電池老化的最好的程序之一。你可以使用以下命令來安裝 TLP。

sudo apt install tlp

我建議你將電池的電量始終保持在 50% 至 80% 之間。不要過度充電或讓電池電量消耗到 50% 以下，也不要給電腦連續插電。

總結 ​

以上就是安裝桌面 Ubuntu 22.10 後要做的 10 件事啦。
