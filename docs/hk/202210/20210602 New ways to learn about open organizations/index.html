瞭解開放組織的新途徑 ​

通過參與兩個令人興奮的新項目來慶祝開放組織社區的六週年。

2021 年 6 月 2 日，開放組織Open Organization社區慶祝其成立六週年。這是六年來（上百篇的）文章、（一系列的）書籍、（具有啓發性的）對話、（我們所 喜歡的）教學和學習。我們非常自豪地成為一個充滿活力的開放專家和領導者的社區，致力於將 開放原則 帶到大大小小的組織。事實上，許多 開放組織大使Open Organization Ambassadors 以幫助他人變得更加開放為職業，我們的社區仍然致力於幫助各行業的領導者以開放的心態和行為融入他們的社區和環境中。

去年 是開放組織項目的一個 成長 和 發展 時期。今年，我們將在這一勢頭的基礎上繼續努力。今天，我們很自豪地介紹兩項新的倡議——當然，也邀請你的參加。

開啓，調整，開放 ​

首先，我們很高興地宣佈：我們社區的工作有了一個全新的場所。OpenOrgTV。這不僅僅是一個新的平台。它也是另一種媒介的實驗：視頻。

在我們的頻道上，我們將舉辦各種對話 —— 從深層次的書評到社區圓桌會議。首先，請查看“開放領導力對話Open Leadership Conversations”系列，其中包括對某些富有洞察力的領導者的採訪，提供他們對根據開放原則進行領導的意義的觀點。或者觀看我們的 Q&A 式寫作節目 “問大使Ask the Ambassadors”，由社區專家回答你關於組織文化和設計的問題。也想參與這個節目嗎？在我們的 新的專門的論壇 中向社區成員提交你的問題。

整個月，我們都會介紹 開放組織大使Open Organization Ambassadors，讓你終於可以看到他們的面孔，並聽到你多年來閲讀的故事、案例研究和採訪背後的聲音。

定義開放領導力 ​

自從我們幾年前發佈它以來，開放組織定義Open Organization Definition 已成為更好地理解開放組織文化和設計本質的組織指導框架（並且我們已經做了很多工作來 教導其他人）。隨着時間的推移，我們甚至開發了 一個成熟度模型 來操作該定義，因此組織可以評估自己的開放程度並制定具體計劃以變得 更加 開放。

現在，我們認為是時候將這項工作更進一步了。

但是，開放組織社區不僅僅是平台、工具或項目的任何組合。它是所有人都熱情地一起工作，以幫助傳播開放原則和實踐。

受我們自己經驗、紅帽 和 Mozilla 等開放組織已有的框架、多年研究和採訪該領域的開放領袖的啓發，以及我們對更好地理解開放領導力如何 真正 發揮作用的渴望，我們很高興公佈一份全新文件的早期草案：開放領導力定義Open Leadership Definition。

本文檔概述了建立開放型組織，並使其成為思想開放的人能夠成長和茁壯成長的地方的各類領導者所特有的心態和行為。它建立在開放領導力定義Open Leadership Definition的基礎上，解釋了開放型領導者如何體現和倡導開放型組織的特徵，如透明度、包容性、適應性、協作性和社區性。

而且我們渴望與世界分享。

從今天開始（在接下來的兩週內），我們將收集你對我們文件草案的見解和意見。我們渴望聽到你的想法，並將接受你的意見的 整體 或片段。你可以對文件的個別部分或整個文件提出意見。請查看下面的鏈接。我們期待着聽到你的意見。

聯繫我們 ​

當然，你仍然可以在所有常見的地方找到我們的社區，如：

  • 我們的項目網站，你通往整個開放組織項目和社區的門户。
  • 我們的對話中心，在這裏你可以與社區成員互動，提出問題，瞭解新項目，尋找資源，並幫助他人。
  • 我們的 GitHub 組織，我們一直在公開研究新項目，並邀請你加入我們
  • 我們在 Opensource.com 的發表頻道，我們在這裏為各地區和各行業的從業人員發佈最新的分析、案例研究、訪談和資源。
  • 我們的 Twitter 和 LinkedIn 平台，我們將在這裏分享我們的最新進展，並促進新的對話。

但開放組織社區不僅僅是平台、工具或項目的任何組合。 是 人，所有人都熱情地一起工作以幫助傳播開放的原則和實踐。正是這些人使我們的社區如此偉大。

六年來一直如此，並將永遠保持下去。
