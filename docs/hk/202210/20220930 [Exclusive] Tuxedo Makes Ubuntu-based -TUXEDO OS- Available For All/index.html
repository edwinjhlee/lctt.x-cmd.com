Tuxedo 已對所有用户開放基於 Ubuntu 的 TUXEDO OS ​

TUXEDO OS 是一個基於 Ubuntu 的 Linux 發行版，旨在將 TUXEDO 在 Linux 方面的專業知識也帶給非 TUXEDO 用户。

又一個基於 Ubuntu 的 Linux 發行版？😕

不完全是！TUXEDO 計算機公司 是一家硬件製造商，以其專注於 Linux 的筆記本電腦和計算機而聞名。

TUXEDO OS 與 Ubuntu 之間存在着一些有趣的差異。

雖然他們已經在筆記本電腦/計算機上提供預裝 TUXEDO OS 的選項，但是它並未對所有人開放。

終於，他們決定將其發行版的第一個版本作為 TUXEDO OS 1 開放，該版本現已可供下載。

這也意味着你可以在自己的非 TUXEDO 系統上試用它。

所以這個思路很像 System76 的 Pop!_OS，所以這並不算一件壞事 👌

搭配 KDE 的 TUXEDO OS 1 ​

TUXEDO OS 1 是基於 Ubuntu 22.04 LTS 的; 所以它應該可以直接在大多數設備上運行。

與 System76 的 Pop!_OS 不同，TUXEDO OS 搭載了 KDE Plasma 5.24.6。因此，它應當提供了一個 Windows 用户也較為熟悉的用户界面。

但是，TUXEDO OS 還包括一些額外的功能，例如 TUXEDO 控制中心，用於微調你的硬件（CPU/風扇等），以及 TUXEDO Tomte，一個用於解決驅動程序/缺少包問題的配置服務，但是它或許能，或許不能在其他硬件配置上工作。

説到這裏，讓我們看看 TUXEDO OS 及其提供的功能。

TUXEDO OS，基於 KDE 的定製化 Ubuntu 體驗 ​

用户體驗正如預期一樣，與任何基於 KDE 的 Ubuntu 發行版相同。

📣 我將 TUXEDO OS（預覽版）用做我的主要系統來體驗它。

你會在應用和菜單上發現帶有紅色調的 TUXEDO 徽標。它還具有令人耳目一新的壁紙。

除了定製化的 KDE Plasma 主題，還有一些其他的變化，例如：

  • 它使用了 PipeWire 作為聲音服務器，而不是 PulseAudio。
  • GRUB 中啓用了 os-prober 功能，讓用户可以方便地檢測已安裝的其他操作系統。
  • .deb 作為首選的軟件包格式，而 Snap 默認情況下被禁用。
  • 從 NetworkManagerConnectivity 檢查中移除了 Canonical 的鏈接。

軟件可用性？ ​

你可以通過 “發現Discover” 應用來找到所有流行的軟件工具，其中包括 Ubuntu 的倉庫和 TUXEDO 的倉庫。

它包含了 Firefox、Thunderbird、LibreOffice、VLC、Lutris 和 Heroic Games Launcher 等必備應用程序。所以我認為你不會覺得它們很臃腫。

我還注意到它默認啓用了 Flatpak 集成。

你可以在他們的 官方網頁 上了解有關可用軟件的更多信息。

這也給我們帶來了一個重要的亮點 ​

❌ TUXEDO OS 不會默認安裝 Snap。對於 Firefox，它會像 Linux Mint 一樣附帶 deb 包安裝。

✅ 值得注意的是，TUXEDO OS 22.04 LTS 附帶了 Nvidia 驅動程序。

因此，我可以毫不費力地將它安裝在帶有 RTX 3060 Ti 顯卡的系統上。

TUXEDO 附加功能 ​

如上所述，TUXEDO OS 附帶了一些專為增強 Tuxedo 硬件的體驗而量身定製的附加功能。

控制中心是監控你的系統、選擇電源配置文件、控制外部水冷（TUXEDO Aquaris）等的絕佳工具。

雖然控制中心不是為非 TUXEDO 設備量身定製的，但它在大多數情況下仍然能夠正常工作。

還有一個 TUXEDO WebFAI Creator 程序（定製的 BalenaEtcher）來燒錄用於操作系統安裝的 U 盤。

還有，不要忘記 TUXEDO Tomte，它無法在我的系統上運行，但可以很完美的在 TUXEDO 設備上作為配置服務運行：

下載 TUXEDO OS 1 ​

TUXEDO OS 帶來了非常精緻的體驗。TUXEDO 背後的團隊在讓 Linux 運行在他們的一些最新筆記本電腦上擁有豐富的經驗。因此，使用他們的 Linux 發行版，你可以對自己的體驗充滿信心。

如果你有興趣，還可以找到關於 TUXEDO OS 入門 的官方文章。

如果你希望獲得一個基於 KDE 的定製化 Ubuntu 體驗，TUXEDO OS 1 是一個不錯的選擇。

你可以通過使用它來支持他們的計劃，這可能會讓你決定購買一台 TUXEDO 設備；你永遠不知道以後會發生什麼，對吧？

你可以從其官方網站下載它，並在下方的評論區中分享你的想法。
