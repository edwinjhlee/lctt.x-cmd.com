Cinnamon 2.8 新變化一覽 ​

除了Gnome和KDE外，Cinnamon是另一個很多人使用的桌面環境。它是由創作Linux Mint的團隊製作的，並且可以被安裝在許多其他發行版上。該桌面環境的最新版本 - Cinnamon 2.8 - 於去年底發佈，此版本修復了許多的Bug、做了許多改進並添加了一些新功能。

我將仔細介紹該發行版本的主要改進，以及如何更新到Cinnamon 2.8或者第一次安裝它。

對Applets的改進 ​

在此版本中，對面板中已有的Applets做了若干的改進。

聲音 Applet ​

聲音Applet經過修正，目前可以顯示音軌信息並且可以在音頻文件的藝術家封面上面進行媒體控制。對於支持拖動的音樂播放器來説（例如Banshee），會有一個進度條顯示同樣的播放進度，您可以用它來改變音軌位置。在applet的面板上右擊將顯示對輸入和輸出設備靜音的選項。

電源 Applet ​

電源applet則會使用電池製造商的數據而不是通用名稱來顯示每一個連接的電池和設備。

窗口縮略圖 ​

在Cinnamon 2.8中，可以在鼠標懸停於面板裏窗口列表時展示窗口縮略圖。如果您不喜歡該功能，您還可以關閉該選項。

工作區切換 Applet ​

添加工作區切換applet到您的面板將為您顯示一個代表該工作區的可視化圖像，一些矩形嵌套顯示在其中，代表您的窗口的位置。

系統托盤 ​

Cinnamon 2.8支持在系統托盤中顯示應用程序指示器。您可以很容易地在設置中禁用它，這將強制應用程序到以前使用狀態圖標的方式。

視覺改進 ​

Cinnamon 2.8還做了很多視覺上的改進。經典的切換器和Alt + Tab預覽切換器都被精細打磨，有了顯著的改進，同時修復了Alt + F2對話框的bug，並賦予了它更好的命令自動補全功能。

而且，傳統的最小化窗口時動畫效果的問題現已被解決，並可用於多個面板。

Nemo 的改進 ​

Cinnamon默認的文件管理器也修復了一些bug，並有了新的“快速重命名”的功能，用於重命名文件和文件夾。可以通過兩次點擊文件或文件夾並在兩次點擊之間進行簡短的停頓以重命名文件。

Nemo也會自動地檢測縮略圖存在的問題，並提示您快速地修復它們。

其他值得注意的改進 ​

  • Applets如今會在它們被更新的時候自動地重新加載一次。
  • 對於多個監視器的支持有了顯著的提高。
  • 對話框窗口有了改進，並且會附加到它的父窗口上。
  • HiDPI檢測有了改進。
  • QT5應用程序現在看起來更加原生並使用了默認的GTK主題。
  • 窗口管理和渲染性能有了提升。
  • 修復了許多bug。

如何獲得 Cinnamon 2.8 ​

如果您在運行Linux Mint，您會在更新Linux Mint 17.3 “Rosa”Cinnamon版本的時候獲得Cinnamon 2.8的更新。BETA版本現在已經放出，因此，如果您想立刻嘗試新的軟件，您可以試試。

對於Arch的用户來説，Cinnamon 2.8已經在Arch的官方倉庫了，您可以通過更新軟件包和系統級的更新獲得Cinnamon的最新版本。

最後，對於Ubuntu用户來説，您可以通過下面的命令安裝或更新Cinnamon 2.8：

sudo add-apt-repository -y ppa:moorkai/cinnamon
sudo apt-get update
sudo apt-get install cinnamon
