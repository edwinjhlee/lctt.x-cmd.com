沒有 Linux 和開源軟件的世界會變得怎麼樣 ​

Linux 基金會針最近對人們關於 “沒有 Linux 的世界” 系列短片所提出的問題做了回應，解答了包括沒有 Linux 和其他的開源軟件的因特網會變得怎麼樣等問題。

假如 Linux —— 這個開源的操作系統內核 —— 不曾出現過，我們現在的世界是否會是另一番景象。會不會沒有了因特網，或者沒有了電影？這些都是觀看 Linux 基金會 正在連續播出的 “沒有 Linux 的世界” 系列短片的觀眾提出來的問題。

假如你錯過了觀看這些短片也不要緊，“沒有 Linux 的世界” 系列短片是一個搞笑短片的集合，裏邊描述了沒有了 Linux （或者説沒有開源軟件）的世界發生的事情。這些短片強調了 Linux 在 電影製作 以及 因特網服務 中充當的角色。

為了揭示該系列短片的一些主張、傾向和隱藏元素，Linux 基金會副主席 Jennifer Cloer 最近在 The VAR Guy 上回應了關於該短片的一些問題。以下是她的原話解答。

最新一集短片 —— Sam 和 Annie 一起看電影。假如沒有 Linux，我們現在的熒屏是不是也和短片中的一樣？ ​

在第 4 集劇情中，我們惡搞了一下電影 “阿凡達（Avatar）”。不管你喜歡還是討厭，現實中的 “阿凡達（Avatar）” 在熒屏上的效果還是讓人記憶深刻的。在沒有 Linux 的世界中，電影的效果就變得非常醜陋，但是我們並不知道它有多難看，因為那已經是最好的了。但實際上，“阿凡達（Avatar）” 是使用 Linux 來進行效果製作的。Weta 數碼使用了當時世界上最大的 Linux 集羣來給電影做效果渲染和 3D 建模。據報道，指環王（Lord of the Rings）、神奇四俠（Fantastic Four）和金剛（King Kong）等電影都用到了 Linux。我希望該短片能引起人們關注，因為它所做的這方面的工作還並不廣為人知。

很多人對短片的原始劇情進行了批判，其中就包括“沒有 Linux 將沒有因特網”的劇情的指責。你對此持什麼樣的看法？ ​

我們很喜歡人們在短片剛上映就進行激烈的辯論。該短片上映當天就超過了 100,000 的觀眾，這引起了人們對 Linux 在社會中扮演的角色以及對全世界的社區貢獻者和維護者的關注。當然了，沒有 Linux 的話，因特網也是會出現的，只是不會像當前我們所熟知的互聯網那麼成熟而已。每一個短片都對 Linux 在我們每天生活中扮演的角色進行了大膽且有趣的描述。我們希望，這些短片能夠把關於 Linux 的故事推廣到全世界的人的心裏去。

為什麼 Sam 和 Annie 的那隻貓叫做 String？ ​

該短片系列中沒有一處劇情是隨意的。仔細的觀看的話，你就會發現其中關於 Linux 和極客們的各種玩笑。小貓 String 是我們的 Linux.com 主編 Libby Clark 以弦理論（string theory）親自來命名的。在物理學裏，弦理論（string theory）是一個理論框架，它用一個叫做弦（String）的一維對象替換了粒子物理學中粒子狀的粒子。弦理論（string theory）描述了這些弦（String）如何在空間傳播以及相互影響。就像 Sam、Annie 和 String 在那個沒有 Linux 的世界裏的關係那樣。

我們期待已久的下兩集是什麼樣的，特別是，最後那集什麼時候上映？ ​

在第 5 集短片中，我們將到太空並體驗一下沒有 Linux 的世界對太空探索的影響。這就像是一場瘋狂的騎行。在短片的最後，我們最終還是會見到沒有 Linux 的世界裏的 Linus。貫穿整個短片系列，裏邊已經給出關於結局的線索，我在這就不能給太多提示了，因為還有好多人在找線索比賽中繼續尋找着。並且我也不能給你們説出關於結局短片的上映日期。你們要自己跟進 #WorldWithoutLinux 主題帖來獲取更多信息。

你可給一些關於第 4 集短片相關線索的提示嗎？ ​

在該短片中有另外一個關於免費漢堡餐廳（Free Burger Restaurant）的線索。在那個沒有 Linux 的世界裏，Linux 最後還是以一種很隱秘的方式出現了，可以説，就像是以另一種語言來解讀 Linux。當然，這只是為了好玩，String 也以另外一個模樣出現。

那麼，該系列短片達到你所想要的效果了嗎？ ​

是的，達到了。我們很高興看到人們分享並參與到這些故事中去。我們希望向那些可能不知道 Linux 的人傳達更多關於 Linux 的故事並瞭解到 Linux 在當今世界中是無處不在的。全部的短片就是為了把這些關於 Linux 的真相推廣給大家，並感謝那些全球性社區的開發者和公司對 Linux 的支持，Linux 使得一切成為可能。
