2016：如何選擇 Linux 發行版 ​

不管是在企業級應用還是在消費者領域，2015 對於 Linux 來説都是極其重要的一年。作為一個從 2005 年就開始使用 Linux 的老用户，我有幸見證了 Linux 過去這 10 年裏的重大發展，並且，我相信它在 2016 年裏會更加令人激動。在這篇文章裏，我會挑選幾個將在 2016 年裏大放光彩的最佳發行版給大家介紹一下。

強勢歸來的發行版：openSUSE ​

SUSE 是 openSUSE 發行版背後的公司，同時也是起步最早的 Linux 公司；它在 Linus Torvalds 發佈 Linux 的第二年就成立了。該公司的成立實際上早於現在的 Linux 公司之王 —— Red Hat。同時 SUSE 也是 openSUSE 社區發行版的發起者和贊助商。

2015 年，openSUSE 的開發團隊決定向 SUSE Linux 企業版 (SLE) 靠攏，以便讓用户可以獲得企業服務器特性的發行版——類似於 CentOS 和 Ubuntu 那樣。因此，openSUSE 變成了 openSUSE Leap，一個直接基於 SLE SP1 的發行版。

兩個發行版共用相同的基礎代碼，相互受益 —— SUSE 會選用 openSUSE 中好的代碼，反之亦然。如此，openSUSE 也放棄了原本常規的發佈週期，新版本與 SLE 同步發行。這意味着每個版本將會有更長的生命週期。

這樣做的結果是，openSUSE 就成了一個非常重要的發行版，因為潛在的 SLE 用户現在可以使用 openSUSE Leap 了。不過，這還不是全部，openSUSE 同樣也有發行版 Tumbleweed —— 一個純淨的滾動式版本。所以，用户們可以選擇使用很穩定的 openSUSE Leap 或者經常更新的 openSUSE Tumbleweed。

在我的記憶中，還沒有其他的發行版做了這樣一個令人印象深刻的強勢歸來。

最高可定製性的發行版：Arch Linux ​

Arch Linux 是目前最好的滾動式更新的發行版。好吧，我可能有些偏見，因為我是一名 Arch Linux 用户 ( LCTT 譯註：譯者也是 Arch Linux 用户，它的定製性真的很好)。然而，我認為它好的真正原因是 Arch 在很多其他領域也都表現的非常優越，並且這才是我為什麼用它作為主系統的原因。

  • 對於那些想要學習 Linux 方方面面的用户來説，Arch Linux 無疑是一個絕佳的選擇。因為你需要手動安裝所有自己需要的東西，這樣你會慢慢學到 Linux 系統的所有細節。

  • Arch 是一個可高度定製發行版。任何桌面環境 (DE) 都沒有了 “Arch” 的原味。你能夠得到的只是一個基礎系統，然後你可以在上邊構建你所想要的發行版。無論好壞，也不像 openSUSE 或者 Ubuntu 那樣，Arch 沒有額外的補丁或者集成環境。你得到的基本就是上游開發者所創建的原始軟件。

  • Arch Linux 同時也是最好的滾動式更新的發行版之一。它需要經常保持着更新。用户所運行的基本上是最新的軟件，當然，也可以通過非穩定倉庫運行預發行版的軟件。

  • Arch 聞名於擁有為數眾多的優秀文檔。Arch Wiki 是我用以瞭解所有 Linux 相關事情的完整資源。

  • Arch 中，我最喜歡的是，它提供了“任何”其他發行版中可用的的包和軟件，同時還要感謝 AUR (Arch User Repository，Arch 用户倉庫)。

最美觀的發行版：elementary OS ​

不同的發行版會有不同的關注點——多數情況下表現為技術的不同。在大多數的 Linux 發行版中，外觀和用户感覺並非他們優先考慮的事情 —— 這通常是桌面環境需要考慮的事情。

elementary OS 正在嘗試改變這一事實。在這個發行版中，設計是佔據重要位置，並且原因明顯——這個發行版是由那些以在 Linux 世界創建漂亮圖標而聞名的設計人員所開發的。

elementary OS 相當注重整體外觀和用户感覺。開發者創建了他們自己的組件，包括桌面環境。此外，他們只會選擇那些符合設計規範的應用來加入到軟件倉庫。你可以發現 elementary OS 有很濃重的 Mac OS X 氣息。

最好的新晉發行版：Solus ​

Solus 最近獲得非常大的關注程度。它是一個看起來中規中矩、從零開始構建的操作系統，它並非 Debian 或者 Ubuntu 的衍生版本。它使用的 Budgie 桌面環境同樣是從零開始構建的，但它的目標是兼容 Gnome。Solus 和 Google 的 Chrome OS 一樣——一切從簡。

我個人沒怎麼玩過 Solus，但它看起來很有前途。Solus 實際上並不是一個 “新” 系統。它曾以不同的形式和名稱存在了很長時間，但直到 2015 年整個項目才以現在這個新名稱重歸大眾視野。

最好的雲操作系統：Chrome OS ​

Chrome OS 可能不會成為你的典型 Linux 發行版，畢竟它是基於瀏覽器的操作系統，主要用以在線使用。但由於它基於 Linux ，任何人都可以獲取其源碼進行編譯，它同樣是一個吸引人的系統。我每天都使用 Chrome OS，它是一個優秀、不用自己維護並且總是保持最新狀態的系統，每個人都可以單純地用它來進行 web 相關的用途。Chrome OS 和 Android 對於推動 Linux 在 PC 市場和移動市場的佔有率有着不可或缺的功勞。

最好的筆記本計算機操作系統：Ubuntu MATE ​

大多數的筆記本計算機都沒有高端的硬件，假如你運行了一個很耗費資源的桌面環境，那麼你可能沒有足夠的系統資源或電量來維持你的使用 —— 因為基本上被操作系統自身消耗了。於是我找到了 Ubuntu MATE 這個優秀的系統。它是輕量級的環境，但提供了能讓你擁有不錯體驗的所有軟件。也幸好它的輕量級設計，大部分的系統資源都留來給你的軟件使用，讓你依舊可以完成一些繁重的任務。我認為它對於低端硬件來説是最好的發行版。

為老舊硬件支持而生的發行版：Lubuntu ​

假如你身邊擁有一些過時的筆記本或 PC，給它安裝 Lubuntu 來獲得重生吧。Lubuntu 使用的是 LXDE 桌面環境，但該項目與 Razor Qt 合併之後，變成了 LXQt。儘管最新的版本 15.04 依舊使用 LXDE，但之後的版本將會使用 LXQt。Lubuntu 對於老舊硬件來説是最合適不過的系統了。

為物聯網 (IoT) 而生的發行版：Snappy Ubuntu Core ​

Snappy Ubuntu Core 是為物聯網 (IoT) 及此類設備而生的 Linux 操作系統。該系統擁有巨大潛力，它可以將我們身邊絕大多數的東西 —— 如路由器、咖啡機和無人機等——變成智能設備。讓它更有趣的是，軟件管理更新的方式以及為增加安全而提供的容器化支持。

為桌面系統而生的發行版：Linux Mint Cinnamon ​

Linux Mint Cinnamon 對於台式機和一些有強大硬件的筆記本來説是最好的操作系統。我一般把它叫做 Linux 世界裏的 Mac OS X。老實説，由於 Cinnamon 的不穩定，我在很長一段時間內並不是 Linux Mint 的忠實粉絲。但是，在開發者使用Ubuntu LTS (Long Term Support，長期支持)作為基礎版本之後，該發行版就變得難以想像的穩定。因為開發者不必花費精力來跟上 Ubuntu 的開發進度，他們現在可以將所有精力放到提升 Cinnamon 上。

為遊戲而生的發行版：Steam OS ​

對於桌面版 Linux 來説，玩遊戲同樣是短板。很多用户為了能夠玩遊戲，安裝了 Linux 和 Windows 雙系統。而 Valve 則嘗試改變這個局面。Valve 是一個遊戲發行商，它提供一個可以在不同平台上運行遊戲的客户端。並且，Valve 也同樣創建了它自己的開源操作系統——Steam OS——為了創建一個基於 Linux 的遊戲平台。截至 2015 年底，它的合作伙伴開始把搭載了 Steam OS 的機器推向市場。

為隱私而生的發行版：Tails ​

在充斥着大量監控和營銷者的跟蹤 (對目標內容進行的匿名跟蹤通常是可接受的）的歲月，隱私保護就變成了一個重要問題。如果你想脱離政府或者市場機構的監控和跟蹤，那麼你需要一款始終考慮到隱私問題的操作系統。

在出於保護隱私的考慮上，沒有任何一款系統可以超越 Tails。它是一款基於 Debian 的發行版，並且在設計之初就考慮了隱私和匿名的支持。Tails 非常優秀，而且據報道説，NSA 認為這是對他們的監控的主要威脅之一。

為多媒體制作而生的發行版：Ubuntu Studio ​

基於 Linux 的操作系統有一個明顯的弱點，那就是對多媒體制作的支持並不友好。所有專業級應用基本只能運行在 Windows 或者 Mac OS X 上。Linux 系統從來都不缺乏像樣的音頻/視頻製作軟件，但這樣還是遠遠不夠的。應該要有一款輕量級的桌面環境，使得那些寶貴的系統資源——如 CPU 和 RAM——儘量少佔用，以便用於多媒體制作。目前，Ubuntu Studio 對多媒體制作的支持最好。它使用了 Xfce 桌面環境，並且有各種各樣的音頻、視頻以及圖像編輯應用。

最好的企業發行版：SLE/RHEL ​

企業級用户並不會通過瀏覽像這樣的文章來了解他們的服務器該運行什麼發行版。他們通常非常明確地知道該到哪裏獲取信息：即 Red Hat Enterprise Linux 或 SUSE Linux Enterprise。這兩個名字已經成了企業服務器的代名詞了。同時，這些公司也都通過創新來推動將一切都容器化和變成軟件定義的。

最好的服務器操作系統：Debian/CentOS ​

假如你在考慮自己運行一台服務器，但有不希望支付 RHEL 或者 SLE 授權的費用，那麼 Debian 或者 CentOS 將是你最好的選擇。這兩個發行版是社區主導的服務器操作系統，具有不可動搖的地位。並且它們有着長期支持，你不必擔憂需要經常去升級系統。

最好的移動操作系統：Plasma Mobile ​

儘管，基於 Linux 的 Android 系統稱雄於移動操作系統市場，但是大多數的開源社區——也包括我在內——也仍然強烈希望能有一個發行版可以為移動設備提供傳統 Linux 的桌面應用。同時，這樣的一個發行版由開源社區來維護會比由商業公司來維護好的多，只有這樣，用户才能成為這個發行版的關注點，而不是由公司的商業目標來決定這個發行版的發展趨勢。KDE 的 Plasma Mobile 剛好實現了我們的願望。

這個基於 Kubuntu 的發行版始於 2015 年。因為 KDE 社區以堅守標準和為公眾開發應用而聞名，我非常期待 Plasma Mobile 能夠一直堅持下去。

為 ARM 設備而生的發行版：Arch Linux ARM ​

隨着 Android 系統的成功，我們的生活也圍繞者越來越多的 ARM 設備——從樹莓派 (Raspberry Pi) 到 Chromebook 以及 Nvidia Shield。為 Intel/AMD 架構的 CPU 而編寫的傳統發行版並不能夠在這些 ARM 架構的設備上運行。而一些為 ARM 而編寫的發行版卻僅僅只能在特定的硬件上運行，比如只能運行在樹莓派 (Raspberry Pi) 上的 Raspbian 系統。這就是為什麼 Arch Linux ARM (ALARM) 讓人眼前一亮的原因。它是一個基於 Arch Linux 的純粹由社區主導的發行版，可以在樹梅派 (Raspberry Pi)、Chromebook、Android 設備以及 Nvidia Shield 等設備上運行。同時，更好的是，也由於 AUR，你可以安裝很多在其他發行版可能無法獲取的軟件。

結論 ​

在我寫完本文的時候，連我自己都震驚了。能夠在 Linux 的世界裏為大家寫點東西真的是很令人激動。不必去管 Linux 統治桌面電腦的時代是否會到來，我們都要一樣享受自己使用 Linux 的每一刻快樂時光。
