給 Linux 新手的最佳發行版 ​

Jack Wallen 為來自不同環境的新手們挑選出專門為他們設計的發行版。CC0社區。

一個很古老的問題，找到適合的 Linux 發行版比簡單的指出哪種 Linux 版本受歡迎更重要。為什麼這麼説？

讓我們設置一個情景：你有一位用户，很有可能，他過去大多數時候都是在 Windows 或者 Mac 系統上工作，他們想讓你給他們一個選擇的替代品。現在，你想要在很短的時間裏直截了當的説明 Linux 系統的工作方式並突出它的強大性和靈活性。

但是，請記住，最重要的一個方面是他們必須能夠 get it，即開箱即用。

這就是為什麼我們經常需要花費時間來找出哪種版本是最適合新手的 -- 因為把新手們帶入 Linux 系統是傳播 Linux 並增加 Linux 用户的最好方式。

對於新手來説最好的版本是什麼？這次，我將要花費一定時間來説明對於來自不同環境的用户哪種版本才是最適合的。此外，你也可以查看我在 2017 最好的發行版中列出的發行版。

從 Windows 7 到 Linux：ZorinOS ​

當 Windows 8 發佈以後，有一個理由讓如此多的用户依然堅持使用 Windows 7， 那就是熟悉度。用户們已經在相同的桌面環境上工作了十幾年，他們不想轉移到 Windows 8 這種更以觸摸屏為主的平台上。所以，你會去選擇哪種版本呢？你首先必須要考慮的是桌面環境。為什麼？因為這是你能夠立刻吸引上這些 Windows 7 用户的地方。對於這個任務，還有什麼版本會比 ZorinOS 更好呢？

ZorinOS 就是專門作為 Windows 和 Mac 系統的替代品而設計的，所以它下了很大的功夫來模仿 Windows 和 Mac 桌面的外觀和感覺。事實上，除了 ZorinOS 以外，你很難找到一個別的 Linux 版本，能夠完美的從 Windows 7 轉移到 Linux 系統上，同時保留 Linux 系統如此強大、靈活的平台。

除了桌面環境（圖片 1）以外， 因為 ZorinOS 完全基於 Ubuntu 系統，所以在其“外表”下面， ZorinOS 和 Ubuntu 以同樣的方式工作（所以基本不用去擔心硬件不能夠被檢測到）。同時伴有已經就緒的軟件，你便有了針對來自 Windows 7 用户的最完美的 Linux 版本。

圖片 1：類 Windows 7 的 ZorinOS 桌面，準備開始服務。使用許可

請注意：然而， ZorinOS 有兩個版本： Zorin Ultimate 和 Zorin Core 。 Zorin Core 是免費的，但它不包含幾乎所有你能夠在 Zorin Ultimate 中找到的軟件。如果你想要一個適合於所有來自 Windows 7 用户的開箱即用的版本，那麼我強烈推薦購買 Zorin Ultimate（大約需要花費 20 美元）。當然，如果你不想花錢購買 Ultimate 版本，你也可以從 Core 版本包含的軟件包管理工具中安裝幾乎所有你需要的東西。

從 Windows 8 到 Linux ： Ubuntu GNOME ​

讓我們來看看 Windows 8， 它帶來了一個以觸摸屏為中心的環境，改變了用户與電腦互動的方式。老式的啓動菜單、面板、系統托盤桌面已經被觸摸屏環境界面所取代。如果你正在找一個能給 Linux 新手們帶來不同體驗的最好環境，同時功能也要是最好的，那麼沒有比 Ubuntu GNOME 更合適的了。

Ubuntu GNOME 是 Ubuntu 和 GNOME（圖 2）這兩個世界之間最好的融合。用一個現代、優雅、簡潔並且用户友好的桌面代替了 Unity 界面， 因此 Ubuntu GNOME 不會給任何來自 Windows 8 的用户造成太多的麻煩。該版本不僅基於最新的長期支持版的 Ubuntu 發行版（支持期會很長），同時使用了 GNOME 桌面的最新穩定版本 － 這意味着用户將能夠享受到難以置信的穩定體驗。

圖片 2 ：在 Ubuntu GNOME 中可以發現，在優雅而又簡潔。 使用許可

從 Mac 到 Linux ： Elementary OS ​

毫無疑問，這一場的絕對贏家是 Elementary OS。儘管 Elementary OS 在外觀和感覺上所達到的效果和 OS X 桌面非常相似，但實際還有更多優秀的地方。 Elementary OS 同樣是基於 Linux 系統的，只不過是它採取了很多 Mac X 桌面的設計元素。

任何的 Mac 用户使用 Elementary OS 的桌面環境（圖片 3）都會感覺就像是“在家一樣”（使用 Mac 一樣）。伴有如此熟悉的文檔，同時包含一個熟悉的應用菜單， Elementary OS 總是位於我的‘最佳發行版列表’的頂部。如果我們正在和 Mac 用户討論遷移，那麼沒有比 Elementary OS 更好的 Mac 替代品了。

圖片 3 ：Elementary OS 桌面的榮耀。使用許可

有一件事情 Mac 用户們將會非常感激，那就是 Elementary OS 的開發者們很好的保持了桌面的一致性。從 dock， 到面板、菜單、到包括的應用，你找不到任何一個看起來或感覺沒有歸屬感的單一元素。

我將在這兒説一個關於 Elementary OS 的預警。你需要安裝一個好的瀏覽器（因為它自帶安裝的 Epiphany-a 瀏覽器沒有得到許多常用站點的支持），同時，你需要從官方的 LibreOffice 網站下載安裝包來安裝 LibreOffice （因為在 Elementary OS 的軟件中心找到的安裝包已經有些過時了）。

從 Android 到 Linux：Ubuntu ​

這似乎有點像是一個延伸話題，但考慮到 Android 在全球市場中佔主導地位，所以你可能遇到一個來自以移動設備為中心的用户，他可能需要一個 Linux 桌面，從而讓他一直感覺像是‘在家’一樣。對於我來説， Ubuntu 是最顯然的贏家。為什麼？和其他系統相比， Ubuntu Unity 在桌面上做出了很傑出的工作，它使得桌面感覺像是一個包羅萬象的界面。如果你願意，那麼可以包含在線搜索結果（默認情況下禁用），這是在幾乎每個移動環境中均可找到的東西。同樣， Unity HUD 菜單系統（圖片 4）是在任何界面系統中所能找到的最獨一無二的菜單系統之一。通過 Unity HUD 菜單系統，用户可以更少的依賴鼠標（就像他們過去在 Android 支持的移動設備上工作一樣）。

圖片 4： 使用中的 Unity HUD 。使用許可

當然， Ubuntu 也提供了市場上最穩定的桌面平台，所以用户體驗近乎完美。

總有一款 Linux 發行版適合你 ​

有一件很重要的事情需要記住，那就是總有一款 Linux 發行版適合你。但是對於那些來自特殊環境的人，我強烈推薦找到一個最喜愛的 Linux 版本，從而能夠幫助他們無縫過渡。給自己一個機會嘗試一下，看看你是否可以輕鬆體驗到開源和 Linux 的強大。
