Linux 系統管理員 2017 年的 10 個新決心 ​

當我們告別 2016 時，也到時間定下我們的 新年決心 了。不管你身為 Linux 系統管理員的經驗水平如何，我們認為，制定接下來 12 個月的成長目標是很值得的。

如果你還沒什麼想法，我們將會在這篇文章分享 10 個簡單的專業提升決心，你可以為 2017 年考慮一下。

1、 決定更自動化 ​

你沒必要忙得像頭無頭蒼蠅，每天忙於解決可預見的問題。如果你發現自己每天都花費時間在執行重複的任務，你有必要現在就停下來。

在瞭解了所有基於 Linux 而且開源的工具後，你可以儘可能地自動化你的 Linux 任務來給自己一些休閒的時間。

你會發現，接下來的幾個決心會幫你在工作上朝着這個目標前進。所以繼續看下去吧。

另外，幫自己一個忙，花費幾分鐘來瀏覽我們免費的電子書部分吧。

你將有機會下載與Bash shell 腳本編程相關的書籍來提升你的技能。開心地自動化！

2、 學習一門新的腳本語言 ​

雖然每一個系統管理員應該熟練地使用 Bash 寫腳本，但考慮一下其它更現代化、健壯性更強的工具也是很重要的，例如 Python。

不要只是相信我們説的話 —— 看看不久前我們發佈的兩篇關於 Python 的系列文章。你將會意識到，與其它語言相比，Python 帶來了面向對象編程的力量，使您寫出更短、健壯性更強的腳本。

3、 學習一門新的編程語言 ​

除了學習一門新的腳本語言，（你也可以）決定花費點時間來開始學習或者提升你的編程技能。不確定從何處開始？今年的 Stackoverflow 開發者調查表明 Javascript 連續第三年引領最流行語言的榜單。

其他經典例如 Java 和 C 也值得考慮。來看我們 2016 年最好的編程課程。

4、 註冊一個 Github 賬户並且定期更新 ​

特別是如果你是一個編程新手，你應該考慮一下在 Github 上展示你的成果。通過允許別人去復刻你的腳本或者程序，你就能提高知識水平，並通過別人的幫助創造出更復雜的軟件。

在《如何安裝和註冊 Github 帳號》一文中瞭解更多。

5、 向一個開源項目做貢獻 ​

在 Github 上向一個開源項目做貢獻，這是另一個學習或者提高一門新腳本語言或者編程語言能力的好辦法。

如果這吸引到了你的興趣，點擊 Explore Github 頁面。這裏你能按熱度或者編程語言瀏覽倉庫，你能在這裏面找到一些有趣的事情來做。

在此基礎上，你將因回饋社區而獲得滿足感。

6、 每月嘗試一個新的發行版 ​

經常會有新的發行版或者分支出現，你有不同的選項以供選擇。誰知道你夢想中的發行版是否就在近前，而你還沒發現它？每個月去一次 Distrowatch 然後選擇一個新的發行版。

也別忘了訂閲 Techmint 來獲取新發行版的消息。

如果你想要嘗試一個新的發行版，希望我們的評論能幫你做出決定。也可以點擊我們這裏關於最好的 Linux 發行版的文章：

  • 2016年最好的 5 個注重安全的 Linux 發行版
  • 2016年最值得期待的 Linux 發行版
  • 2015年最流行的 10個 Linux 發行版

7、 參加一個 Linux 或者開源會議。 ​

如果你住在由 Linux 基金會贊助的會議舉辦地附近，我強烈建議你去參加會議。

這不僅將會給你一個提高 Linux 知識的機會，而且將是個見見其他開源專家的機會。

8、 從 Linux 基金會的免費或付費課程中學習 ​

Linux 基金會分別通過 edX.org 和他們自己的門户，不斷地提供免費或付費課程。

免費課程的話題包括（但不僅限於）Linux 介紹、雲基礎設施技術介紹和 OpenStack 介紹。

另一方面，付費課程包括 LFCS 認證 和 LFCE 認證 考試的準備，給開發者的 Linux ，內核內部構件，Linux 安全，性能試驗，高可用性及其他。

另外，他們對企業課程有折扣，所以嘗試去説服你上司來為你和你同事的訓練付費。還有，也會提供週期性的免費在線研討會，所以別忘了訂閲他們的 newsletters！

你也可以考慮下看看我們最棒的在線 Linux 訓練課程。

9、 每週在 Linux 論壇上回答特定數量的問題 ​

另一個回饋社區的好方法是幫助那些剛開始使用 Linux 的人。你將會發現網上的 Linux 論壇上有許多人正在尋找着答覆。

牢記你曾經也是像他們那樣是個新手，試着換位思考。

10、 教一個孩子或少年使用 Linux ​

如果我能回到 20 年前，我希望我能有台電腦，有個能在青年時學習 Linux 的機會。

我也希望我能比當年還早很多地開始編程。毫無疑問，這樣事情就會簡單許多。我認為給孩子和青年教授至少是基礎的 Linux 和編程技巧（我對我的孩子這樣做）是個重要的嘗試。

教育成長中的一代如何有效地使用開源技術將會給他們選擇的自由，而他們會因此永遠感激你。

總結 ​

在這篇文章裏我們分享了 10 個適合系統管理員的可能新年決心。Tecmint.com 祝你在朝着目標的工作順順利利，希望你能在 2017 年成為我們網站的常客。
