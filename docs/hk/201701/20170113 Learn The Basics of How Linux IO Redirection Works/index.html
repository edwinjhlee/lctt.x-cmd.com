Linux I/O 重定向基礎 ​

Linux 管理的一個最重要並且有趣的話題是 I/O 重定向。此功能在命令列中使你能夠將命令的輸入輸出取自或送到文件中，或者可以使用管道將多個命令連接在一起以形成所謂的“命令管道”。

我們運行的所有命令基本上產生兩種輸出：

  • 命令結果 - 程序產生的數據，以及
  • 程序狀態和錯誤消息，用來通知用户程序的執行細節。

在 Linux 和其他類 Unix 系統中，有三個默認文件（名稱如下），這些文件也由 shell 使用文件描述符號標識：

  • stdin 或 0 - 它連接鍵盤，大多數程序從此文件讀取輸入。
  • stdout 或 1 - 它連接屏幕，並且所有程序將其結果發送到此文件
  • stderr 或 2 - 程序將狀態/錯誤消息發送到此文件，它也連接到屏幕上。

因此，I/O 重定向允許你更改命令的輸入源以及將輸出和錯誤消息發送到其他地方。這可以通過 < 和 > 重定向操作符來實現。

如何在 Linux 中重定向標準輸出到文件中 ​

如下面的示例所示，你可以重定向標準輸出，這裏，我們要存儲 top 命令的輸出以供以後檢查：

$ top -bn 5 >top.log

其中標誌的含義：

  • -b - 讓 top 以批處理模式運行，以便你可以將其輸出重定向到一個文件或另一個命令。
  • -n - 指定命令終止前的迭代次數。

你可以使用 cat 命令來查看 top.log 文件的內容：

$ cat top.log

要將命令輸出附加在文件後面，請使用 >> 操作符。

例如，要將 top 命令的輸出追加在上面的 top.log 文件中，特別是在腳本（或命令列）中，請輸入下面的那行：

$ top -bn 5 >>top.log

注意： 也可以使用文件描述符數字，上面的重定向命令等同於：

$ top -bn 5 1>top.log

如何在 Linux 中重定向標準錯誤到文件中 ​

要重定向命令的標準錯誤，你需要明確指定文件描述符 2，以便讓 shell 瞭解你正在嘗試做什麼。

例如，下面的 ls 命令將在沒有 root 權限的普通系統用户執行時產生錯誤：

$ ls -l /root/

你可以重定向標準錯誤到文件中：

$ ls -l /root/ 2>ls-error.log
$ cat ls-error.log

重定向標準錯誤到文件中

為了將標準錯誤附加在文件後，使用下面的命令：

$ ls -l /root/ 2>>ls-error.log

如何重定向標準輸出及標準錯誤到一個文件中 ​

還可以將命令的所有輸出（包括標準輸出和標準錯誤）捕獲到單個文件中。這可以用兩種可能的方式，通過指定文件描述符來完成：

1、 第一種是相對較舊的方法，其工作方式如下：

$ ls -l /root/ >ls-error.log 2>&1

上面的命令意思是 shell 首先將 ls 命令的輸出發送到文件 ls-error.log（使用 >ls-error.log），然後將所有寫到文件描述符 2（標準錯誤）的錯誤消息重定向到文件 ls-error.log（使用2>＆1）中。（LCTT 譯註：此處原文有誤，徑改。）這表示標準錯誤也被髮送到與標準輸出相同的文件中。

2、 第二種並且更直接的方法是：

$ ls -l /root/ &>ls-error.log

你也可以這樣將標準輸出和標準錯誤附加到單個文件後：

$ ls -l /root/ &>>ls-error.log

如何將標準輸入重定向到文件中 ​

大多數（如果不是全部）命令從標準輸入獲得其輸入，並且標準輸入默認連接到鍵盤。

要從鍵盤以外的文件重定向標準輸入，請使用 < 操作符，如下所示：

$ cat <domains.list

重定向文件到標準輸入中

如何重定向標準輸入/輸出到文件中 ​

你可以如下在 sort 命令中 同時執行標準輸入、標準輸出的重定向：

$ sort <domains.list >sort.output

如何使用管道進行 I/O 重定向 ​

要將一個命令的輸出重定向為另一個命令的輸入，你可以使用管道，這是用於構建複雜操作命令的有力方法。

例如，以下命令將列出最近修改的前五個文件。

$ ls -lt | head -n 5

選項的意思是：

  • -l - 啓用長列表格式
  • -t - 最新修改的文件首先顯示
  • -n - 指定要顯示的標題行數

構建管道的重要命令 ​

在這裏，我們將簡要回顧一下構建命令管道的兩個重要命令，它們是：

xargs 用於從標準輸入構建和執行命令列。下面是使用 xargs 的管道示例，此命令用於將文件複製到 Linux 中的多個目錄：

$ echo /home/aaronkilik/test/ /home/aaronkilik/tmp | xargs -n 1 cp -v /home/aaronkilik/bin/sys_info.sh

複製文件到多個目錄

選項含義：

  • -n 1 - 讓 xargs 對每個命令列最多使用一個參數，併發送到 cp命令
  • cp - 複製文件
  • -v - 顯示 cp 命令的進度。

有關更多的使用選項和信息，請閲讀 xargs 手冊頁：

$ man xargs

tee 命令從標準輸入讀取，並寫入到標準輸出和文件中。我們可以演示 tee 如何工作：

$ echo "Testing how tee command works" | tee file1

tee 命令示例

文件或文本過濾器通常與管道一起用於有效地操作 Linux 文件，來以強大的方式來處理信息，例如命令的重組輸出（這對於生成有用的 Linux 報告是必不可少的）、修改文件中的文本和其他的 Linux 系統管理任務。
