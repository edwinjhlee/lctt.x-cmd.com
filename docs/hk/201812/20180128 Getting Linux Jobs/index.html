Linux 求職建議 ​

通過對招聘網站數據的仔細研究，我們發現，即使是非常有經驗的 Linux 程序員，也會在面試中陷入困境。

這就導致了很多優秀並且有經驗的人無緣無故地找不到合適的工作，因為如今的就業市場需要我們有一些手段來提高自己的競爭力。

我有兩個同事和一個表哥，他們都有 RedHat 認證，管理過比較大的服務器機房，也都收到過前僱主的認真推薦。

可是，在他們應聘的時候，所有的這些證書、本身的能力、工作經驗好像都沒有起到任何作用，他們所面對的招聘廣告是某人從技術詞彙中臨時挑選的一些“技能片段”所組成的。

現如今，禮貌變得過時了，不回應變成了發佈招聘廣告的公司的新溝通方式。

這同樣也意味着大多公司的招聘或者人事可能會錯過非常優秀的應聘者。

我之所以敢説的如此肯定，是因為現在招聘廣告大多數看上去都非常的滑稽。

Reallylinux.com 另一位特約撰稿人 Walter ，發表過一篇關於 招聘廣告瘋掉了 的文章。

他説的也許是對的，可是我認為 Linux 工作應聘者可以通過注意招聘廣告的三個關鍵點避免落入陷阱。

首先，很少會有 Linux 系統管理員的招聘廣告只針對 Linux 有要求。

一定要注意很少有 Linux 系統管理員的職位是實際在服務器上跑 Linux的，反而，很多在搜索 “Linux 管理員” 得到的職位實際上是指大量的 *NX 操作系統的。

舉個例子，有一則關於 Linux 管理員 的招聘廣告：

該職位需要為建立系統集成提供支持，尤其是 BSD 應用的系統安裝...

或者有一些其他的要求：

有 Windows 系統管理經驗的。

最為諷刺的是，如果你在應聘面試的時候表現出專注於 Linux 的話，你可能不會被聘用。

另外，如果你直接把 Linux 寫在你的特長或者專業上，他們可能都不會仔細看你的簡歷，因為他們根本區分不了 UNIX、BSD、Linux。

最終的結果就是，如果你太老實，只在簡歷上寫了 Linux，你可能會被直接過掉，但是如果你把 Linux 改成 UNIX/Linux 的話，可能會走得更遠。

我有兩個同事最後修改了他們的簡歷，然後獲得了更好的面試機會，雖然依舊沒有被聘用，因為大多數招聘廣告其實已經內定人員了，這些招聘信息被放出來僅僅是為了表現出他們有招聘的想法。

第二點，公司裏唯一在乎系統管理員職位的只有技術主管，其他人包括人事或管理層根本不關心這個。

我記得有一次開會旁聽的時候，聽見一個執行副總裁把服務器管理人員説成“一毛錢一打的人”，這種想法是多麼的奇怪啊。

諷刺的是，等到郵件系統出故障，電話交換機連接時不時會斷開，或者核心商業文件從企業內網中消失的時候，這些總裁又是最先打電話給系統管理員的。

或許如果他們不整天在電話留言中説那麼多空話，或者不往郵件裏塞滿妻子的照片和旅行途中的照片的話，服務器可能就不會崩潰。

請注意，招聘 Linux 運維或者服務器管理員的廣告被放出來是因為公司技術層認為有迫切的需求。你也不需要和人事或者公司高層聊什麼，搞清楚誰是招聘的技術經理然後打電話給他們。

你需要直接聯繫他們因為“有些技術問題”是人事回答不了的，即使你只有 60 秒的時間可以和他們交流，你也必須抓住這個機會和真正有需求並且懂技術的人溝通。

那如果人事的漂亮 MM 不讓你直接聯繫技術怎麼辦呢？

開始記得問人事一些技術性問題，比如説他們的 Linux 集羣是如何建立的，它們運行在獨立的虛擬機上嗎？這些技術性的問題會讓人事變得不耐煩，最後讓你有機會問出“我能不能直接聯繫你們團隊的技術人員”。

如果對方的回答是“應該可以”或者“稍後回覆你”，那麼他們可能已經在兩週前就已經計劃好了找一個人來填補這個空缺，比如説人事部員工的未婚夫。他們只是不希望看起來太像裙帶主義，而是帶有一點利己主義的不確定主義。

所以一定要記得花點時間弄清楚到底誰是發佈招聘廣告的直接技術負責人，然後和他們聊一聊，這可能會讓你少一番胡扯並且讓你更有可能應聘成功。

第三點，現在的招聘廣告很少有完全真實的內容了。

我以前見過一個招聘具有高級別專家也不會有的專門知識的初級系統管理員的廣告，他們的計劃是列出公司的發展計劃藍圖，然後找到應聘者。

在這種情況下，你應聘 Linux 管理員職位應該提供幾個關鍵性信息，例如工作經驗和相關證書。

訣竅在於，用這些關鍵詞儘量裝點你的簡歷，以匹配他們的招聘信息，這樣他們幾乎不可能發現你缺失了哪個關鍵詞。

這並不一定會讓你成功找到一份工作，但它可以讓你獲得一次面試機會，這也算是一個巨大的進步。

通過理解和應用以上三點，或許可以讓那些尋求 Linux 管理員工作的人能夠比那些只有一線地獄機會的人領先一步。

即使這些建議不能讓你馬上得到面試機會，你也可以利用這些經驗和意識去參加貿易展或公司主辦的技術會議等活動。

我強烈建議你們也經常參加這種活動，尤其是當它們比較近的話，可以給你一個擴展人脈的機會。

請記住，如今的職業人脈已經失去了原來的意義了，現在只是可以用來獲取“哪些公司實際上在招聘、哪些公司只是為了給股東帶來增長的表象而在職位方面撒謊”的小道消息。
