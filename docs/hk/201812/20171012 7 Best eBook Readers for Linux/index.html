7 個最佳 Linux 電子書閲讀器 ​

摘要： 本文中我們涉及一些 Linux 最佳電子書閲讀器。這些應用提供更佳的閲讀體驗甚至可以管理你的電子書。

最近，隨着人們發現在手持設備、Kindle 或者 PC 上閲讀更加舒適，對電子圖書的需求有所增加。至於 Linux 用户，也有各種電子書應用滿足你閲讀和整理電子書的需求。

在本文中，我們選出了七個最佳 Linux 電子書閲讀器。這些電子書閲讀器最適合 pdf、epub 和其他電子書格式。

我提供的是 Ubuntu 安裝説明，因為我現在使用它。如果你使用的是非 Ubuntu 發行版，你能在你的發行版軟件倉庫中找到大多數這些電子書應用。

1. Calibre ​

Calibre 是 Linux 最受歡迎的電子書應用。老實説，這不僅僅是一個簡單的電子書閲讀器。它是一個完整的電子書解決方案。你甚至能通過 Calibre 創建專業的電子書。

通過強大的電子書管理和易用的界面，它提供了創建和編輯電子書的功能。Calibre 支持多種格式和與其它電子書閲讀器同步。它也可以讓你輕鬆轉換一種電子書格式到另一種。

Calibre 最大的缺點是，資源消耗太多，因此作為一個獨立的電子閲讀器來説是一個艱難的選擇。

特性 ​

  • 管理電子書：Calibre 通過管理元數據來排序和分組電子書。你能從各種來源下載一本電子書的元數據或創建和編輯現有的字段。
  • 支持所有主流電子書格式：Calibre 支持所有主流電子書格式併兼容多種電子閲讀器。
  • 文件轉換：在轉換時，你能通過改變電子書風格，創建內容表和調整邊距的選項來轉換任何一種電子書格式到另一種。你也能轉換個人文檔為電子書。
  • 從 web 下載雜誌期刊：Calibre 能從各種新聞源或者通過 RSS 訂閲源傳遞故事。
  • 分享和備份你的電子圖書館：它提供了一個選項，可以託管你電子書集合到它的服務端，從而你能與好友共享或用任何設備從任何地方訪問。備份和導入/導出特性可以確保你的收藏安全和方便攜帶。

安裝 ​

你能在主流 Linux 發行版的軟件庫中找到它。對於 Ubuntu，在軟件中心搜索它或者使用下面的命令：

sudo apt-get install calibre

2. FBReader ​

FBReader 是一個開源的輕量級多平台電子書閲讀器，它支持多種格式，比如 ePub、fb2、mobi、rtf、html 等。它包括了一些可以訪問的流行網絡電子圖書館，那裏你能免費或付費下載電子書。

特性 ​

  • 支持多種文件格式和設備比如 Android、iOS、Windows、Mac 和更多。
  • 同步書集、閲讀位置和書籤。
  • 在線管理你圖書館，可以從你的 Linux 桌面添加任何書到所有設備。
  • 支持 Web 瀏覽器訪問你的書集。
  • 支持將書籍存儲在 Google Drive ，可以通過作者，系列或其他屬性整理書籍。

安裝 ​

你能從官方庫或者在終端中輸入以下命令安裝 FBReader 電子閲讀器。

sudo apt-get install fbreader

或者你能從這裏抓取一個以 .deb 包，並在你的基於 Debian 發行版的系統上安裝它。

3. Okular ​

Okular 是另一個開源的基於 KDE 開發的跨平台文檔查看器，它已經作為 KDE 應用發佈的一部分了。

特性 ​

  • Okular 支持多種文檔格式像 PDF、Postscript、DjVu、CHM、XPS、ePub 和其他。
  • 支持在 PDF 文檔中評論、高亮和繪製不同的形狀等。
  • 無需修改原始 PDF 文件，分別保存上述這些更改。
  • 電子書中的文本能被提取到一個文本文件，並且有個名為 Jovie 的內置文本閲讀服務。

備註：查看這個應用的時候，我發現這個應用在 Ubuntu 和它的衍生系統中不支持 ePub 文件格式。其他發行版用户仍然可以發揮它全部的潛力。

安裝 ​

Ubuntu 用户可以在終端中鍵入下面的命令來安裝它：

sudo apt-get install okular

4. Lucidor ​

Lucidor 是一個易用的、支持 epub 文件格式和在 OPDS 格式中編目的電子閲讀器。它也具有在本地書架裏組織電子書集、從互聯網搜索和下載，和將 Web 訂閲和網頁轉換成電子書的功能。

Lucidor 是 XULRunner 應用程序，它向您展示了具有類似火狐的選項卡式佈局，和存儲數據和配置時的行為。它是這個列表中最簡單的電子閲讀器，包括諸如文本説明和滾動選項之類的配置。

你可以通過選擇單詞並右擊“查找單詞”來查找該單詞在 Wiktionary.org 的定義。它也包含 web 訂閲或 web 頁面作為電子書的選項。

你能從這裏下載和安裝 deb 或者 RPM 包。

5. Bookworm ​

Bookworm 是另一個支持多種文件格式諸如 epub、pdf、mobi、cbr 和 cbz 的自由開源的電子閲讀器。我寫了一篇關於 Bookworm 應用程序的特性和安裝的專題文章，到這裏閲讀：Bookworm：一個簡單而強大的 Linux 電子閲讀器

安裝 ​

sudo apt-add-repository ppa:bookworm-team/bookworm
sudo apt-get update
sudo apt-get install bookworm

6. Easy Ebook Viewer ​

Easy Ebook Viewer 是又一個用於讀取 ePub 文件的很棒的 GTK Python 應用。具有基本章節導航、從上次閲讀位置繼續、從其他電子書文件格式導入、章節跳轉等功能，Easy Ebook Viewer 是一個簡單而簡約的 ePub 閲讀器.

這個應用仍然處於初始階段，只支持 ePub 文件。

安裝 ​

你可以從 GitHub 下載源代碼，並自己編譯它及依賴項來安裝 Easy Ebook Viewer。或者，以下終端命令將執行完全相同的工作。

sudo apt install git gir1.2-webkit-3.0 libwebkitgtk-3.0-0 gir1.2-gtk-3.0 python3-gi
git clone https://github.com/michaldaniel/Ebook-Viewer.git
cd Ebook-Viewer/
sudo make install

成功完成上述步驟後，你可以從 Dash 啓動它。

7. Buka ​

Buka 主要是一個具有簡單而清爽的用户界面的電子書管理器。它目前支持 PDF 格式，旨在幫助用户更加關注內容。擁有 PDF 閲讀器的所有基本特性，Buka 允許你通過箭頭鍵導航，具有縮放選項，並且能並排查看兩頁。

你可以創建單獨的 PDF 文件列表並輕鬆地在它們之間切換。Buka 也提供了一個內置翻譯工具，但是你需要有效的互聯網連接來使用這個特性。

安裝 ​

你能從官方下載頁面下載一個 AppImage。如果你不知道如何做，請閲讀如何在 Linux 下使用 AppImage。或者，你可以通過命令列安裝它：

sudo snap install buka

結束語 ​

就我個人而言，我發現 Calibre 最適合我的需要。當然，Bookworm 看起來很有前途，這幾天我經常使用它。不過，電子書應用的選擇完全取決於你的喜好。
