學習 Linux/*BSD/Unix 的 30 個最佳在線文檔 ​

手冊頁（man）是由系統管理員和 IT 技術開發人員寫的，更多的是為了作為參考而不是教你如何使用。手冊頁對於已經熟悉使用 Linux、Unix 和 BSD 操作系統的人來説是非常有用的。如果你僅僅需要知道某個命令或者某個配置文件的格式那麼你可以使用手冊頁，但是手冊頁對於 Linux 新手來説並沒有太大的幫助。想要通過使用手冊頁來學習一些新東西不是一個好的選擇。這裏有將提供 30 個學習 Linux 和 Unix 操作系統的最佳在線網頁文檔。

值得一提的是，相對於 Linux，BSD 的手冊頁更好。

#1：Red Hat Enterprise Linux（RHEL） ​

RHEL 是由紅帽公司開發的面向商業市場的 Linux 發行版。紅帽的文檔是最好的文檔之一，涵蓋從 RHEL 的基礎到一些高級主題比如安全、SELinux、虛擬化、目錄服務器、服務器集羣、JBOSS 應用程序服務器、高可用性集羣（HPC）等。紅帽的文檔已經被翻譯成 22 種語言，發佈成多頁面 HTML、單頁面 HTML、PDF、EPUB 等文件格式。好消息同樣的文檔你可以用於 Centos 和 Scientific Linux（社區企業發行版）。這些文檔隨操作系統一起下載提供，也就是説當你沒有網絡的時候，你也可以使用它們。RHEL 的文檔涵蓋從安裝到配置器羣的所有內容。唯一的缺點是你需要成為付費用户。當然這對於企業公司來説是一件完美的事。

  1. RHEL 文檔：HTML/PDF格式（LCTT 譯註：此鏈接需要付費用户才可以訪問）
  2. 是否支持論壇：只能通過紅帽公司的用户網站提交支持案例。

關於 CentOS Wiki 和論壇的説明 ​

CentOS（社區企業操作系統Community ENTerprise Operating System）是由 RHEL 提供的自由源碼包免費重建的。它為個人電腦或其它用途提供了可靠的、免費的企業級 Linux。你可以不用付出任何支持和認證費用就可以獲得 RHEL 的穩定性。CentOS的 wiki 分為 Howto、技巧等等部分，鏈接如下：

  1. 文檔：wiki 格式
  2. 是否支持論壇：是

#2：Arch 的 Wiki 和論壇 ​

Arch linux 是一個獨立開發的 Linux 操作系統，它有基於 wiki 網站形式的非常不錯的文檔。它是由 Arch 社區的一些用户共同協作開發出來的，並且允許任何用户添加或修改內容。這些文檔教程被分為幾類比如説優化、軟件包管理、系統管理、X window 系統還有獲取安裝 Arch Linux 等。它的官方論壇在解決許多問題的時候也非常有用。它有總共 4 萬多個註冊用户、超過 1 百萬個帖子。 該 wiki 包含一些 其它 Linux 發行版也適用的通用信息。

  1. Arch 社區文檔：Wiki 格式
  2. 是否支持論壇：是

#3：Gentoo Linux Wiki 和論壇 ​

Gentoo Linux 基於 Portage 包管理系統。Gentoo Linux 用户根據它們選擇的配置在本地編譯源代碼。多數 Gentoo Linux 用户都會定製自己獨有的程序集。 Gentoo Linux 的文檔會給你一些有關 Gentoo Linux 操作系統的説明和一些有關安裝、軟件包、網絡和其它等主要出現的問題的解決方法。Gentoo 有對你來説 非常有用的論壇，論壇中有超過 13 萬 4 千的用户，總共發了有 5442416 個文章。

  1. Gentoo 社區文檔：手冊 和 Wiki 格式
  2. 是否支持論壇：是

#4：Ubuntu Wiki 和文檔 ​

Ubuntu 是領先的台式機和筆記本電腦發行版之一。其官方文檔由 Ubuntu 文檔工程開發維護。你可以在從官方文檔中查看大量的信息，比如如何開始使用 Ubuntu 的教程。最好的是，此處包含的這些信息也可用於基於 Debian 的其它系統。你可能會找到由 Ubuntu 的用户們創建的社區文檔，這是一份有關 Ubuntu 的使用教程和技巧等。Ubuntu Linux 有着網絡上最大的 Linux 社區的操作系統，它對新用户和有經驗的用户均有助益。

  1. Ubuntu 社區文檔：wiki 格式
  2. Ubuntu 官方文檔：wiki 格式
  3. 是否支持論壇：是

#5：IBM Developer Works ​

IBM Developer Works 為 Linux 程序員和系統管理員提供技術資源，其中包含數以百計的文章、教程和技巧來協助 Linux 程序員的編程工作和應用開發還有系統管理員的日常工作。

  1. IBM 開發者項目文檔：HTML 格式
  2. 是否支持論壇：是

#6：FreeBSD 文檔和手冊 ​

FreeBSD 的手冊是由 FreeBSD 文檔項目FreeBSD Documentation Project所創建的，它介紹了 FreeBSD 操作系統的安裝、管理和一些日常使用技巧等內容。FreeBSD 的手冊頁通常比 GNU Linux 的手冊頁要好一點。FreeBSD 附帶有全部最新手冊頁的文檔。 FreeBSD 手冊涵蓋任何你想要的內容。手冊包含一些通用的 Unix 資料，這些資料同樣適用於其它的 Linux 發行版。FreeBSD 官方論壇會在你遇到棘手問題時給予幫助。

  1. FreeBSD 文檔：HTML/PDF 格式
  2. 是否支持論壇：是

#7：Bash Hackers Wiki ​

這是一個對於 bash 使用者來説非常好的資源。Bash 使用者的 wiki 是為了歸納所有類型的 GNU Bash 文檔。這個項目的動力是為了提供可閲讀的文檔和資料來避免用户被迫一點一點閲讀 Bash 的手冊，有時候這是非常麻煩的。Bash Hackers Wiki 分為各個類，比如説腳本和通用資料、如何使用、代碼風格、bash 命令格式和其它。

  1. Bash 用户教程：wiki 格式

#8：Bash 常見問題 ​

這是一個為 bash 新手設計的一個 wiki。它收集了 IRC 網絡的 #bash 頻道里常見問題的解決方法，這些解決方法是由該頻道的普通成員提供。當你遇到問題的時候不要忘了在 BashPitfalls 部分檢索查找答案。這些常見問題的解決方法可能會傾向於 Bash，或者偏向於最基本的 Bourne Shell，這決定於是誰給出的答案。大多數情況會盡力提供可移植的（Bourne）和高效的（Bash，在適當情況下）的兩類答案。

  1. Bash 常見問題：wiki 格式

#9: Howtoforge - Linux 教程 ​

Blog作者 Falko 在 Howtoforge 上有一些非常不錯的東西。這個網站提供了 Linux 關於各種各樣主題的教程，比如説其著名的“最佳服務器系列”，網站將主題分為幾類，比如説 web 服務器、linux 發行版、DNS 服務器、虛擬化、高可用性、電子郵件和反垃圾郵件、FTP 服務器、編程主題還有一些其它的內容。這個網站也支持德語。

  1. Howtoforge： html 格式
  2. 是否支持論壇：是

#10：OpenBSD 常見問題和文檔 ​

OpenBSD 是另一個基於 BSD 的類 Unix 計算機操作系統。OpenBSD 是由 NetBSD 項目分支而來。OpenBSD 因高質量的代碼和文檔、對軟件許可協議的堅定立場和強烈關注安全問題而聞名。OpenBSD 的文檔分為多個主題類別，比如説安裝、包管理、防火牆設置、用户管理、網絡、磁盤和磁盤陣列管理等。

  1. OpenBSD：html 格式
  2. 是否支持論壇：否，但是可以通過 郵件列表 來諮詢

#11: Calomel - 開源研究和參考文檔 ​

這個極好的網站是專門作為開源軟件和那些特別專注於 OpenBSD 的軟件的文檔來使用的。這是最簡潔的引導網站之一，專注於高質量的內容。網站內容分為多個類，比如説 DNS、OpenBSD、安全、web 服務器、Samba 文件服務器、各種工具等。

  1. Calomel 官網：html 格式
  2. 是否支持論壇：否

#12：Slackware 書籍項目 ​

Slackware Linux 是我的第一個 Linux 發行版。Slackware 是基於 Linux 內核的最早的發行版之一，也是當前正在維護的最古老的 Linux 發行版。 這個發行版面向專注於穩定性的高級用户。 Slackware 也是很少有的的“類 Unix” 的 Linux 發行版之一。官方的 Slackware 手冊是為了讓用户快速開始瞭解 Slackware 操作系統的使用方法而設計的。 這不是説它將包含發行版的每一個方面，而是為了説明它的實用性和給使用者一些有關係統的基礎工作使用方法。手冊分為多個主題，比如説安裝、網絡和系統配置、系統管理、包管理等。

  1. Slackware Linux 手冊：html 格式、pdf 和其它格式
  2. 是否支持論壇：是

#13：Linux 文檔項目（TLDP） ​

Linux 文檔項目Linux Documentation Project旨在給 Linux 操作系統提供自由、高質量文檔。網站是由志願者創建和維護的。網站分為具體主題的幫助、由淺入深的指南等。在此我想推薦一個非常好的文檔，這個文檔既是一個教程也是一個 shell 腳本編程的參考文檔，對於新用户來説這個 HOWTO 的列表也是一個不錯的開始。

  1. Linux 文檔工程 支持多種查閲格式
  2. 是否支持論壇：否

#14：Linux Home Networking ​

Linux Home Networking 是學習 linux 的另一個比較好的資源，這個網站包含了 Linux 軟件認證考試的內容比如 RHCE，還有一些計算機培訓課程。網站包含了許多主題，比如説網絡、Samba 文件服務器、無線網絡、web 服務器等。

  1. Linux home networking 可通過 html 格式和 PDF（少量費用）格式查閲
  2. 是否支持論壇：是

#15：Linux Action Show ​

Linux Action Show（LAS) 是一個關於 Linux 的播客。這個網站是由 Bryan Lunduke、Allan Jude 和 Chris Fisher 共同管理的。它包含了 FOSS 的最新消息。網站內容主要是評論一些應用程序和 Linux 發行版。有時候也會發布一些和開源項目著名人物的採訪視頻。

  1. Linux action show 支持音頻和視頻格式
  2. 是否支持論壇：是

#16：Commandlinefu ​

Commandlinefu 列出了各種有用或有趣的 shell 命令。這裏所有命令都可以評論、討論和投票（支持或反對）。對於所有 Unix 命令列用户來説是一個極好的資源。不要忘了查看評選出來的最佳命令。

  1. Commandlinefu 支持 html 格式
  2. 是否支持論壇：否

#17：Debian 管理技巧和資源 ​

這個網站包含一些只和 Debian GNU/Linux 相關的主題、技巧和教程，特別是包含了關於系統管理的有趣和有用的信息。你可以在上面貢獻文章、建議和問題。提交了之後不要忘記查看最佳文章列表裏有沒有你的文章。

  1. Debian 系統管理 支持 html 格式
  2. 是否支持論壇：否

#18: Catonmat - Sed、Awk、Perl 教程 ​

這個網站是由Blog作者 Peteris Krumins 維護的。主要關注命令列和 Unix 編程主題，比如説 sed 流編輯器、perl 語言、AWK 文本處理工具等。不要忘了查看 sed 介紹、sed 含義解釋，還有命令列歷史的權威介紹。

  1. catonmat 支持 html 格式
  2. 是否支持論壇：否

#19：Debian GNU/Linux 文檔和 Wiki ​

Debian 是另外一個 Linux 操作系統，其主要使用的軟件以 GNU 許可證發佈。Debian 因嚴格堅持 Unix 和自由軟件的理念而聞名，它也是很受歡迎並且有一定影響力的 Linux 發行版本之一。 Ubuntu 等發行版本都是基於 Debian 的。Debian 項目以一種易於訪問的形式提供給用户合適的文檔。這個網站分為 Wiki、安裝指導、常見問題、支持論壇幾個模組。

  1. Debian GNU/Linux 文檔 支持 html 和其它格式訪問
  2. Debian GNU/Linux wiki
  3. 是否支持論壇：是

#20：Linux Sea ​

Linux Sea 這本書提供了比較通俗易懂但充滿技術（從最終用户角度來看）的 Linux 操作系統的介紹，使用 Gentoo Linux 作為例子。它既沒有談論 Linux 內核或 Linux 發行版的歷史，也沒有談到 Linux 用户不那麼感興趣的細節。

  1. Linux sea 支持 html 格式訪問
  2. 是否支持論壇: 否

#21：O'reilly Commons ​

O'reilly 出版社發佈了不少 wiki 格式的文章。這個網站主要是為了給那些喜歡創作、參考、使用、修改、更新和修訂來自 O'Reilly 或者其它來源的素材的社區提供資料。這個網站包含關於 Ubuntu、PHP、Spamassassin、Linux 等的免費書籍。

  1. Oreilly commons 支持 Wiki 格式
  2. 是否支持論壇：否

#22：Ubuntu 袖珍指南 ​

這本書的作者是 Keir Thomas。這本指南（或者説是書籍）對於所有 ubuntu 用户來説都值得一讀。這本書旨在向用户介紹 Ubuntu 操作系統和其所依賴的理念。你可以從官網下載這本書的 PDF 版本，也可以在亞馬遜買印刷版。

  1. Ubuntu pocket guide 支持 PDF 和印刷版本.
  2. 是否支持論壇：否

#23: Linux: Rute User's Tutorial and Exposition ​

這本書涵蓋了 GNU/LINUX 系統管理，主要是對主流的發佈版本比如紅帽和 Debian 的説明，可以作為新用户的教程和高級管理員的參考。這本書旨在給出 Unix 系統的每個面的簡明徹底的解釋和實踐性的例子。想要全面瞭解 Linux 的人都不需要再看了 —— 這裏沒有涉及的內容。

  1. Linux: Rute User's Tutorial and Exposition 支持印刷版和 html 格式
  2. 是否支持論壇：否

#24：高級 Linux 編程 ​

這本書是寫給那些已經熟悉了 C 語言編程的程序員的。這本書採取一種教程式的方式來講述大多數在 GNU/Linux 系統應用編程中重要的概念和功能特性。如果你是一個已經對 GNU/Linux 系統編程有一定經驗的開發者，或者是對其它類 Unix 系統編程有一定經驗的開發者，或者對 GNU/Linux 軟件開發有興趣，或者想要從非 Unix 系統環境轉換到 Unix 平台並且已經熟悉了優秀軟件的開發原則，那你很適合讀這本書。另外，你會發現這本書同樣適合於 C 和 C++ 編程。

  1. 高級 Linux 編程 支持印刷版和 PDF 格式
  2. 是否支持論壇：否

#25: LPI 101 Course Notes ​

LPIC 1、2、3 級是用於 Linux 系統管理員認證的。這個網站提供了 LPI 101 和 LPI 102 的測試訓練。這些是根據 GNU 自由文檔協議GNU Free Documentation Licence（FDL）發佈的。這些課程材料基於 Linux 國際專業協會的 LPI 101 和 102 考試的目標。這個課程是為了提供給你一些必備的 Linux 系統的操作和管理的技能。

  1. LPI 訓練手冊 支持 PDF 格式
  2. 是否支持論壇：否

#26: FLOSS 手冊 ​

FLOSS 手冊是一系列關於自由和開源軟件以及用於創建它們的工具和使用這些工具的社區的手冊。社區的成員包含作者、編輯、設計師、軟件開發者、積極分子等。這些手冊中説明了怎樣安裝使用一些自由和開源軟件，如何操作（比如設計和維持在線安全）開源軟件，這其中也包含如何使用或支持自由軟件和格式的自由文化服務手冊。你也會發現關於一些像 VLC、 Linux 視頻編輯、 Linux、 OLPC / SUGAR、 GRAPHICS 等軟件的手冊。

  1. 你可以瀏覽 FOSS 手冊 支持 Wiki 格式
  2. 是否支持論壇：否

#27：Linux 入門包 ​

剛接觸 Linux 這個美好世界？想找一個簡單的入門方式？你可以下載一個 130 頁的指南來入門。這個指南會向你展示如何在你的個人電腦上安裝 Linux，如何瀏覽桌面，掌握最主流行的 Linux 程序和修復可能出現的問題的方法。

  1. Linux 入門包支持 PDF 格式
  2. 是否支持論壇：否

#28：Linux.com - Linux 信息來源 ​

Linux.com 是 Linux 基金會的一個產品。這個網站上提供一些新聞、指南、教程和一些關於 Linux 的其它信息。利用全球 Linux 用户的力量來通知、寫作、連接 Linux 的事務。

  1. 在線訪問 Linux.com
  2. 是否支持論壇：是

#29: LWN ​

LWN 是一個注重自由軟件及用於 Linux 和其它類 Unix 操作系統的軟件的網站。這個網站有周刊、基本上每天發佈的單獨文章和文章的討論對話。該網站提供有關 Linux 和 FOSS 相關的開發、法律、商業和安全問題的全面報道。

  1. 在線訪問 lwn.net
  2. 是否支持論壇：否

#30: NetBSD ​

NetBSD 是另一個基於 BSD Unix 操作系統的自由開源操作系統。NetBSD 項目專注於系統的高質量設計、穩定性和性能。由於 NetBSD 的可移植性和伯克利式的許可證，NetBSD 常用於嵌入式系統。這個網站提供了一些 NetBSD 官方文檔和各種第三方文檔的鏈接。

  1. 在線訪問 netbsd 文檔，支持 html、PDF 格式
  2. 是否支持論壇：否
