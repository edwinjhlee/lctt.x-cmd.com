樹莓派在辦公室的 11 種用法 ​

我知道你在想什麼：樹莓派只能用在修修補補、原型設計和個人愛好中。它實際不能用在業務中。

毫無疑問，這台電腦的處理能力相對較低、易損壞的 SD 卡、缺乏電池備份以及支持的 DIY 性質，這意味着它不會是一個能在任何時候執行最關鍵的操作的專業的、已安裝好、配置好的商業服務器的可行替代品。

但是它電路板便宜、功耗很小、小到幾乎適合任何地方、無限靈活 —— 這實際上是處理辦公室一些基本任務的好方法。

而且，更好的是，已經有一些人完成了這些項目並很樂意分享他們是如何做到的。

DNS 服務器 ​

每次在瀏覽器中輸入網站地址或者點擊鏈接時，都需要將域名轉換為數字 IP 地址，然後才能顯示內容。

通常這意味着向互聯網上某處 DNS 服務器發出請求 —— 但你可以通過本地處理來加快瀏覽速度。

你還可以分配自己的子域，以便本地訪問辦公室中的計算機。

這裏瞭解它是如何工作的。

廁所佔用標誌 ​

在廁所排過隊嗎？

這對於那些等待的人來説很煩人，花在處理它上面的時間會耗費你在辦公室的工作效率。

我想你希望在辦公室裏也懸掛飛機上那個廁所有人的標誌。

Occu-pi 是一個非常簡單的解決方案，使用磁性開關和樹莓派來判斷螺栓何時關閉，並在 Slack 頻道中更新“廁所在使用中” —— 這意味着整個辦公室的人都可以看一眼電腦或者移動設備知道是否有空閒的隔間。

針對黑客的蜜罐陷阱 ​

黑客破壞了網絡的第一個線索是一些事情變得糟糕，這應該會嚇到大多數企業主。

這就是可以用到蜜罐的地方：一台沒有任何服務的計算機位於你的網絡，將特定端口打開，偽裝成黑客喜歡的目標。

安全研究人員經常在網絡外部部署蜜罐，以收集攻擊者正在做的事情的數據。

但對於普通的小型企業來説，這些作為一種絆腳石部署在內部更有用。因為普通用户沒有真正的理由想要連接到蜜罐，所以任何發生的登錄嘗試都是正在進行搗亂的非常好的指示。

這可以提供對外部人員入侵的預警，並且也可以提供對值得信賴的內部人員的預警。

在較大的客户端/服務器網絡中，將它作為虛擬機運行可能更為實用。但是在無線路由器上運行的點對點的小型辦公室/家庭辦公網絡中，HoneyPi 之類的東西是一個很小的防盜報警器。

打印服務器 ​

聯網打印機更方便。

但更換所有打印機可能會很昂貴 —— 特別是如果你對現有的打印機感到滿意的話。

將樹莓派設置為打印服務器可能會更有意義。

網絡附加存儲（NAS） ​

將硬盤變為 NAS 是樹莓派最早的實際應用之一，並且它仍然是最好的之一。

這是如何使用樹莓派創建 NAS。

工單服務器 ​

想要在預算不足的情況下在服務枱中支持工單？

有一個名為 osTicket 的完全開源的工單程序，它可以安裝在你的樹莓派上，它甚至還有隨時可用的 SD 卡鏡像。

數字標牌 ​

無論是用於活動、廣告、菜單還是其他任何東西，許多企業都需要一種顯示數字標牌的方式 —— 而樹莓派的廉價和省電使其成為一個非常有吸引力的選擇。

[這有很多可供選擇的選項。] 8

目錄和信息亭 ​

FullPageOS 是一個基於 Raspbian 的 Linux 發行版，它直接引導到 Chromium 的全屏版本 —— 這非常適合導購、圖書館目錄等。

基本的內聯網 Web 服務器 ​

對於託管一個面向公眾的網站，你最好有一個託管帳户。樹莓派不適合面對真正的網絡流量。

但對於小型辦公室，它可以託管內部業務維基或基本的公司內網。它還可以用作沙箱環境，用於試驗代碼和服務器配置。

這裏是如何在樹莓派上運行 Apache、MySQL 和 PHP。

滲透測試器 ​

Kali Linux 是專為探測網絡安全漏洞而構建的操作系統。通過將其安裝在樹莓派上，你就擁有了一個超便攜式穿透測試器，其中包含 600 多種工具。

你可以在這裏找到樹莓派鏡像的種子鏈接。

絕對要小心只在你自己的網絡或你有權對它安全審計的網絡中使用它 —— 使用此方法來破解其他網絡是嚴重的犯罪行為。

VPN 服務器 ​

當你外出時，依靠的是公共無線互聯網，你無法控制還有誰在網絡中、誰在窺探你的所有流量。這就是為什麼通過 VPN 連接加密所有內容可以讓人放心。

你可以訂閲任意數量的商業 VPN 服務，並且你可以在雲中安裝自己的服務，但是在辦公室運行一個 VPN，這樣你也可以從任何地方訪問本地網絡。

對於輕度使用 —— 比如偶爾的商務旅行 —— 樹莓派是一種強大的，節約能源的設置 VPN 服務器的方式。（首先要檢查一下你的路由器是不是不支持這個功能，許多路由器是支持的。）

這是如何在樹莓派上安裝 OpenVPN。

無線咖啡機 ​

那麼，為什麼不將辦公室的咖啡機變成可以精確控制温度和無線連接的智能咖啡機呢？
