TLP：一個可以延長 Linux 筆記本電池壽命的高級電源管理工具 ​

筆記本電池是針對 Windows 操作系統進行了高度優化的，當我在筆記本電腦中使用 Windows 操作系統時，我已經意識到這一點，但對於 Linux 來説卻不一樣。

多年來，Linux 在電池優化方面取得了很大進步，但我們仍然需要做一些必要的事情來改善 Linux 中筆記本電腦的電池壽命。

當我考慮延長電池壽命時，我沒有多少選擇，但我覺得 TLP 對我來説是一個更好的解決方案，所以我會繼續使用它。

在本教程中，我們將詳細討論 TLP 以延長電池壽命。

我們之前在我們的網站上寫過三篇關於 Linux 筆記本電池節電工具 的文章：PowerTOP 和 電池充電狀態。

TLP ​

TLP 是一款自由開源的高級電源管理工具，可在不進行任何配置更改的情況下延長電池壽命。

由於它的默認配置已針對電池壽命進行了優化，因此你可能只需要安裝，然後就忘記它吧。

此外，它可以高度定製化，以滿足你的特定要求。TLP 是一個具有自動後台任務的純命令列工具。它不包含GUI。

TLP 適用於各種品牌的筆記本電腦。設置電池充電閾值僅適用於 IBM/Lenovo ThinkPad。

所有 TLP 設置都存儲在 /etc/default/tlp 中。其默認配置提供了開箱即用的優化的節能設置。

以下 TLP 設置可用於自定義，如果需要，你可以相應地進行必要的更改。

TLP 功能 ​

  • 內核筆記本電腦模式和髒緩衝區超時
  • 處理器頻率調整，包括 “turbo boost”/“turbo core”
  • 限制最大/最小的 P 狀態以控制 CPU 的功耗
  • HWP 能源性能提示
  • 用於多核/超線程的功率感知進程調度程序
  • 處理器性能與節能策略（x86_energy_perf_policy）
  • 硬盤高級電源管理級別（APM）和降速超時（按磁盤）
  • AHCI 鏈路電源管理（ALPM）與設備黑名單
  • PCIe 活動狀態電源管理（PCIe ASPM）
  • PCI(e) 總線設備的運行時電源管理
  • Radeon 圖形電源管理（KMS 和 DPM）
  • Wifi 省電模式
  • 關閉驅動器托架中的光盤驅動器
  • 音頻省電模式
  • I/O 調度程序（按磁盤）
  • USB 自動暫停，支持設備黑名單/白名單（輸入設備自動排除）
  • 在系統啓動和關閉時啓用或禁用集成的 wifi、藍牙或 wwan 設備
  • 在系統啓動時恢復無線電設備狀態（從之前的關機時的狀態）
  • 無線電設備嚮導：在網絡連接/斷開和停靠/取消停靠時切換無線電
  • 禁用 LAN 喚醒
  • 掛起/休眠後恢復集成的 WWAN 和藍牙狀態
  • 英特爾處理器的動態電源降低 —— 需要內核和 PHC-Patch 支持
  • 電池充電閾值 —— 僅限 ThinkPad
  • 重新校準電池 —— 僅限 ThinkPad

如何在 Linux 上安裝 TLP ​

TLP 包在大多數發行版官方存儲庫中都可用，因此，使用發行版的 包管理器 來安裝它。

對於 Fedora 系統，使用 DNF 命令 安裝 TLP。

$ sudo dnf install tlp tlp-rdw

ThinkPad 需要一些附加軟件包。

$ sudo dnf install https://download1.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm
$ sudo dnf install http://repo.linrunner.de/fedora/tlp/repos/releases/tlp-release.fc$(rpm -E %fedora).noarch.rpm
$ sudo dnf install akmod-tp_smapi akmod-acpi_call kernel-devel

安裝 smartmontool 以顯示 tlp-stat 中 S.M.A.R.T. 數據。

$ sudo dnf install smartmontools

對於 Debian/Ubuntu 系統，使用 APT-GET 命令 或 APT 命令 安裝 TLP。

$ sudo apt install tlp tlp-rdw

ThinkPad 需要一些附加軟件包。

$ sudo apt-get install tp-smapi-dkms acpi-call-dkms

安裝 smartmontool 以顯示 tlp-stat 中 S.M.A.R.T. 數據。

$ sudo apt-get install smartmontools

當基於 Ubuntu 的系統的官方軟件包過時時，請使用以下 PPA 存儲庫，該存儲庫提供最新版本。運行以下命令以使用 PPA 安裝 TLP。

$ sudo add-apt-repository ppa:linrunner/tlp
$ sudo apt-get update
$ sudo apt-get install tlp

對於基於 Arch Linux 的系統，使用 Pacman 命令 安裝 TLP。

$ sudo pacman -S tlp tlp-rdw

ThinkPad 需要一些附加軟件包。

$ pacman -S tp_smapi acpi_call

安裝 smartmontool 以顯示 tlp-stat 中 S.M.A.R.T. 數據。

$ sudo pacman -S smartmontools

對於基於 Arch Linux 的系統，在啓動時啓用 TLP 和 TLP-Sleep 服務。

$ sudo systemctl enable tlp.service
$ sudo systemctl enable tlp-sleep.service

對於基於 Arch Linux 的系統，你還應該屏蔽以下服務以避免衝突，並確保 TLP 的無線電設備切換選項的正確操作。

$ sudo systemctl mask systemd-rfkill.service
$ sudo systemctl mask systemd-rfkill.socket

對於 RHEL/CentOS 系統，使用 YUM 命令 安裝 TLP。

$ sudo yum install tlp tlp-rdw

安裝 smartmontool 以顯示 tlp-stat 中 S.M.A.R.T. 數據。

$ sudo yum install smartmontools

對於 openSUSE Leap 系統，使用 Zypper 命令 安裝 TLP。

$ sudo zypper install TLP

安裝 smartmontool 以顯示 tlp-stat 中 S.M.A.R.T. 數據。

$ sudo zypper install smartmontools

成功安裝 TLP 後，使用以下命令啓動服務。

$ systemctl start tlp.service
