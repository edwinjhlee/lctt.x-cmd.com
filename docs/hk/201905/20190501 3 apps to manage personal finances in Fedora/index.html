3 款在 Fedora 中管理個人財務的應用 ​

網上有很多可以用來管理你個人財務的服務。雖然它們可能很方便，但這通常也意味着將你最寶貴的個人數據放在你無法監控的公司。也有些人對這些不太在意。

無論你是否在意，你可能會對你自己系統上的應用感興趣。這意味着如果你不想，你的數據永遠不會離開自己的計算機。這三款之一可能就是你想找的。

HomeBank ​

HomeBank 是一款可以管理多個賬户的全功能軟件。它很容易設置並保持更新。它有多種方式畫出你的分類和負債，以便你可以看到資金流向何處。它可以通過官方 Fedora 倉庫下載。

要安裝 HomeBank，請打開“軟件中心”，搜索 “HomeBank”，然後選擇該應用。單擊“安裝”將其添加到你的系統中。HomeBank 也可以通過 Flatpak 安裝。

KMyMoney ​

KMyMoney 是一個成熟的應用，它已經存在了很長一段時間。它有一系列穩定的功能，可幫助你管理多個帳户，包括資產、負債、税收等。KMyMoney 包含一整套用於管理投資和進行預測的工具。它還提供大量報告，以瞭解你的資金運作方式。

要安裝它，請使用軟件中心，或使用命令列：

$ sudo dnf install kmymoney

GnuCash ​

用於個人財務的最受歡迎的免費 GUI 應用之一是 GnuCash。GnuCash 不僅可以用於個人財務。它還有管理企業收入、資產和負債的功能。這並不意味着你不能用它來管理自己的賬户。從查看在線教程和指南開始瞭解。

打開“軟件中心”，搜索 “GnuCash”，然後選擇應用。單擊“安裝”將其添加到你的系統中。或者如上所述使用 dnf install 來安裝 “gnucash” 包。

它現在可以通過 Flathub 安裝，這使得安裝變得簡單。如果你沒有安裝 Flathub，請查看 Fedora Magazine 上的這篇文章瞭解如何使用它。這樣你也可以在終端使用 flatpak install gnucash 命令。
