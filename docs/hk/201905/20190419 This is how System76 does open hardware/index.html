System76 是如何打造開源硬件的 ​

是什麼讓新的 Thelio 台式機系列與眾不同。

大多數人對他們電腦的硬件一無所知。作為一個長期的 Linux 用户，當我想讓我的無線網卡、視頻卡、顯示器和其他硬件與我選擇的發行版共同運行時，也一樣遇到了挫折。商業品牌的硬件通常使判斷這些問題變得很困難：為什麼以太網驅動、無線驅動或者鼠標驅動和我們預期的不太一樣？隨着 Linux 發行版變得成熟，這可能不再是問題，但是我們仍能發現觸控板和其它外部設備的怪異行為，尤其是當我們對底層的硬件知道的不多時。

像 System76 這樣的公司致力於解決這些問題，以提升 Linux 用户體驗。System76 生產了一系列的 Linux 筆記本、台式機和服務器，甚至提供了它自己的 Linux 發行版 Pop! OS 作為客户的一個選擇。最近我有幸參觀了 System76 在 Devnver 的工廠並揭開它的新台式機產品線 Thelio 的神秘面紗。

關於 Thelio ​

System76 宣稱 Thelio 的開源硬件子板（被命名為木星之後的第 5 個衞星的名字 Thelio Io）是它在市場上獨特的特點之一。Thelio Io 取得了開源硬件協會的認證 OSHWA #us000145，並且有 4 個用於存儲的 SATA 端口和一個控制風扇和用於電源按鈕控制的嵌入式控制器。Thelio IO SAS 取得了 OSHWA #us000146 認證，並且有 4 個用於存儲的 U.2 端口，沒有嵌入式控制器。在展示時，System76 顯示了這些組件如何調整風扇通過底盤來優化部件的性能。

該控制器還管理電源鍵，和圍繞該電源鍵的 LED 光環，當被按下時它以 100% 的亮度發光。這提供了觸覺和視覺上的確認：該主機已經啓動電源了。當電腦在使用中，該按鈕被設置為 35% 的亮度，當在睡眠模式，它的亮度在 2.35% 和 25% 之間跳動。當計算機關閉後，LED 保持朦朧的亮度，因此能夠在黑暗的房間裏找到電源控制。

Thelio 的嵌入式控制器是一個低功耗的 ATmega32U4 微控制器，並且控制器的設置可以使用 Arduino Micro 進行原型設計。Thelio Io 主板變化的多少取決於你購買哪種 Thelio 型號。

Thelio 可能是我見過的設計的最好的電腦機箱和系統。如果你曾經親身體驗過在一個常規的 PC 的內部進行操作的話，你可能會同意我的觀點。我已經做了很多次了，因此我能以自己過往的糟糕經歷來證明這點。

為什麼做開源硬件？ ​

該主板是在 KiCAD 設計的，你可以在 GitHub 上按 GPL 許可證訪問 Thelio 所有的設計文件。因此，為什麼一個與其他 PC 製造商競爭的公司會設計一個獨特的接口並公開授權呢？可能是該公司認識到開源設計及根據你的需要調整和分享一個 I/O 主板設計的能力的價值，即便你是市場上的競爭者。

在 Thelio 發佈會 Don Watkins 與 System76 的 CEO Carl Richell 談話。

我問 System76 的設計者和 CEO Carl Richell，該公司是否擔心過公開許可它的硬件設計意味着有人可以採取它的獨特設計並用它來將 System76 驅逐出市場。他説：

開源硬件對我們所有人都有益。這是我們未來提升技術的方式，並且使得每個人獲取技術更容易。我們歡迎任何想要提高 Thelio 設計的人來這麼做。開源該硬件不僅可以幫助我們更快的改進我們的電腦，並且能夠使我們的消費者 100% 信任他們的設備。我們的目標是儘可能地移除專利功能，同時仍然能夠為消費者提供一個有競爭力的 Linux 主機。

我們已經與 Linux 社區一起合作了 13 年之久，來為我們的筆記本、台式機、服務器創造一個完美順滑的體驗。我們長期專注於為 Linux 社區提供服務，提供給我們的客户高水準的服務，我們的個性使 System76 變得獨特。

我還問 Carl 為什麼開源硬件對 System76 和 PC 市場是有意義的。他回覆道：

System76 創立之初的想法是技術應該對每個人是開放和可獲取的。我們還沒有到達 100% 開源創造一個電腦的程度，但是有了開源硬件，我們邁出了接近目標的必不可少的一大步。

我們生活在技術變成工具的時代。計算機在各級教育和很多行業當中是人們的工具。由於每個人特定的需要，每個人對於如何提升電腦和軟件作為他們的主要工具有他們自己的想法。開源我們的計算機可以讓這些想法成為現實，從而反過來促進技術成為一個更強大的工具。在一個開源環境中，我們持續迭代來生產更好的 PC。這有點酷。

我們總結了我們討論的關於 System76 技術路線的對話，包含了開源硬件 mini PC，甚至是筆記本。在 System76 品牌下的已售出的 mini PC 和筆記本是由其他供應商製造的，並不是基於開源硬件的（儘管它們用的是 Linux 軟件，是開源的）。

設計和支持開放式硬件是 PC 產業中的變革者，也正是它造就了 System76 的新 Thelio 台式機電腦產品線的不同。
