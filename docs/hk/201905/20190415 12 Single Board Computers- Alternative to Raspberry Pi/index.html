12 個可替代樹莓派的單板機 ​

正在尋找樹莓派的替代品？這裏有一些單板機可以滿足你的 DIY 渴求。

樹莓派是當前最流行的單板機。你可以在你的 DIY 項目中使用它，或者用它作為一個成本效益高的系統來學習編代碼，或者為了你的便利，利用一個流媒體軟件運行在上面作為流媒體設備。

你可以使用樹莓派做很多事，但它不是各種極客的最終解決方案。一些人可能在尋找更便宜的開發板，一些可能在尋找更強大的。

無論是哪種情況，我們都有很多原因需要樹莓派的替代品。因此，在這片文章裏，我們將討論最好的 12 個我們認為能夠替代樹莓派的單板機。

滿足你 DIY 渴望的樹莓派替代品 ​

這個列表沒有特定的順序排名。鏈接的一部分是贊助鏈接。請閲讀我們的贊助政策。

1、Onion Omega2+ ​

只要 $13，Omega2+ 是這裏你可以找到的最便宜的 IoT 單板機設備。它運行 LEDE（Linux 嵌入式開發環境）Linux 系統 —— 這是一個基於 OpenWRT 的發行版。

由於運行一個自定義 Linux 系統，它的組成元件、花費和靈活性使它完美適合幾乎所有類型的 IoT 應用。

你可以在亞馬遜商城的 Onion Omega 套件或者從他們的網站下單，可能會收取額外的郵費。

關鍵參數：

  • MT7688 SoC
  • 2.4 GHz IEEE 802.11 b/g/n WiFi
  • 128 MB DDR2 RAM
  • 32 MB on-board flash storage
  • MicroSD Slot
  • USB 2.0
  • 12 GPIO Pins

查看官網

2、NVIDIA Jetson Nano Developer Kit ​

這是來自 NVIDIA 的只要 $99 的非常獨特和有趣的樹莓派替代品。是的，它不是每個人都能充分利用的設備 —— 只為特定的一組極客或者開發者而生。

NVIDIA 使用下面的用例解釋它：

NVIDIA® Jetson Nano™ Developer Kit 是一個小的、強大的計算機，可以讓你並行運行多個神經網絡的應用像圖像分類、對象偵察、圖像分段、語音處理。全部在一個易於使用的、運行功率只有 5 瓦特的平台上。

nvidia

因此，基本上，如果你正在研究 AI 或者深度學習，你可以充分利用開發設備。如果你很好奇，該設備的產品計算模組將在 2019 年 7 月到來。

關鍵參數：

  • CPU: Quad-core ARM A57 @ 1.43 GHz
  • GPU: 128-core Maxwell
  • RAM: 4 GB 64-bit LPDDR4 25.6 GB/s
  • Display: HDMI 2.0
  • 4 x USB 3.0 and eDP 1.4

查看官網

3、ASUS Tinker Board S ​

ASUS Tinker Board S 不是大多數人可負擔得起的樹莓派的替換設備 （$82，亞馬遜商城)，但是它是一個強大的替代品。它的特點是它有你通常可以發現與標準樹莓派 3 一樣的 40 針腳的連接器，但是提供了強大的處理器和 GPU。同樣的，Tinker Board S 的大小恰巧和標準的樹莓派3 一樣大。

這個板子的主要亮點是 16 GB eMMC （用外行術語説，它的板上有一個類似 SSD 的存儲單元使它工作時運行的更快。） 的存在。

關鍵參數：

  • Rockchip Quad-Core RK3288 processor
  • 2 GB DDR3 RAM
  • Integrated Graphics Processor
  • ARM® Mali™-T764 GPU
  • 16 GB eMMC
  • MicroSD Card Slot
  • 802.11 b/g/n, Bluetooth V4.0 + EDR
  • USB 2.0
  • 28 GPIO pins
  • HDMI Interface

查看網站

4、ClockworkPi ​

如果你正在想方設法組裝一個模組化的復古的遊戲控制台，Clockwork Pi 可能就是你需要的，它通常是 GameShell Kit 的一部分。然而，你可以 使用 $49 單獨購買板子。

它緊湊的大小、WiFi 連接性和 micro HDMI 端口的存在使它成為許多方面的選擇。

關鍵參數：

  • Allwinner R16-J Quad-core Cortex-A7 CPU @1.2GHz
  • Mali-400 MP2 GPU
  • RAM: 1GB DDR3
  • WiFi & Bluetooth v4.0
  • Micro HDMI output
  • MicroSD Card Slot

查看官網

5、Arduino Mega 2560 ​

如果你正在研究機器人項目或者你想要一個 3D 打印機 —— Arduino Mega 2560 將是樹莓派的便利的替代品。不像樹莓派，它是基於微控制器而不是微處理器的。

在他們的官網，你需要花費 $38.50，或者在在亞馬遜商城是 $33。

關鍵參數：

  • Microcontroller: ATmega2560
  • Clock Speed: 16 MHz
  • Digital I/O Pins: 54
  • Analog Input Pins: 16
  • Flash Memory: 256 KB of which 8 KB used by bootloader

查看官網

6、Rock64 Media Board ​

用與你可能想要的樹莓派 3 B+ 相同的價格，你將在 Rock64 Media Board 上獲得更快的處理器和雙倍的內存。除此之外，如果你想要 1 GB RAM 版的，它提供了一個比樹莓派更便宜的替代品，花費更少，只要 $10 。

不像樹莓派，它沒有無線連接支持，但是 USB 3.0 和 HDMI 2.0 的存在使它與眾不同，如果它對你很重要的話。

關鍵參數：

  • Rockchip RK3328 Quad-Core ARM Cortex A53 64-Bit Processor
  • Supports up to 4GB 1600MHz LPDDR3 RAM
  • eMMC module socket
  • MicroSD Card slot
  • USB 3.0
  • HDMI 2.0

查看官網

7、Odroid-XU4 ​

Odroid-XU4 是一個完美的樹莓派的替代品，如果你有能夠稍微提高預算的空間（$80-$100 甚至更低，取決於存儲的容量）。

它確實是一個強大的替代品並且體積更小。支持 eMMC 和 USB 3.0 使它工作起來更快。

關鍵參數：

  • Samsung Exynos 5422 Octa ARM Cortex™-A15 Quad 2Ghz and Cortex™-A7 Quad 1.3GHz CPUs
  • 2Gbyte LPDDR3 RAM
  • GPU: Mali-T628 MP6
  • USB 3.0
  • HDMI 1.4a
  • eMMC 5.0 module socket
  • MicroSD Card Slot

查看官網

8、PocketBeagle ​

它是一個難以置信的小的單板機 —— 幾乎和樹莓派Zero 相似。然而它的價格相當於完整大小的樹莓派 3。主要的亮點是你可以用它作為一個 USB 便攜式信息終端，並且進入 Linux 命令列工作。

關鍵參數：

  • Processor: Octavo Systems OSD3358 1GHz ARM® Cortex-A8
  • RAM: 512 MB DDR3
  • 72 expansion pin headers
  • microUSB
  • USB 2.0

查看官網

9、Le Potato ​

由 Libre Computer 出品的 Le Potato，其型號是 AML-S905X-CC。它需要花費你 $45。

如果你花費的比樹莓派更多的錢，你就能得到雙倍內存和 HDMI 2.0 接口，這可能是一個完美的選擇。儘管，你還是不能找到嵌入的無線連接。

關鍵參數：

  • Amlogic S905X SoC
  • 2GB DDR3 SDRAM
  • USB 2.0
  • HDMI 2.0
  • microUSB
  • MicroSD Card Slot
  • eMMC Interface

查看官網

10、Banana Pi M64 ​

它自帶了 8G 的 eMMC —— 這是替代樹莓派的主要亮點。因此，它需要花費 $60。

HDMI 接口的存在使它勝任 4K。除此之外，Banana Pi 提供了更多種類的開源單板機作為樹莓派的替代。

關鍵參數：

  • 1.2 Ghz Quad-Core ARM Cortex A53 64-Bit Processor-R18
  • 2GB DDR3 SDRAM
  • 8 GB eMMC
  • WiFi & Bluetooth
  • USB 2.0
  • HDMI

查看官網

11、Orange Pi Zero ​

Orange Pi Zero 相對於樹莓派來説難以置信的便宜。你可以在 Aliexpress 或者亞馬遜上以最多 $10 就能夠獲得。如果稍微多花點，你能夠獲得 512 MB RAM。

如果這還不夠，你可以花費大概 $25 獲得更好的配置，比如 Orange Pi 3。

關鍵參數：

  • H2 Quad-core Cortex-A7
  • Mali400MP2 GPU
  • RAM: Up to 512 MB
  • TF Card support
  • WiFi
  • USB 2.0

查看官網

12、VIM 2 SBC by Khadas ​

由 Khadas 出品的 VIM 2 是最新的單板機，因此你能夠在板上得到藍牙 5.0 支持。它的價格範圍從 $99 的基礎款到上限 $140。

基礎款包含 2 GB RAM、16 GB eMMC 和藍牙 4.1。然而，Pro/Max 版包含藍牙 5.0，更多的內存，更多的 eMMC 存儲。

關鍵參數：

  • Amlogic S912 1.5GHz 64-bit Octa-Core CPU
  • T820MP3 GPU
  • Up to 3 GB DDR4 RAM
  • Up to 64 GB eMMC
  • Bluetooth 5.0 (Pro/Max)
  • Bluetooth 4.1 (Basic)
  • HDMI 2.0a
  • WiFi

總結 ​

我們知道有很多不同種類的單板機電腦。一些比樹莓派更好 —— 它的一些小規格的版本有更便宜的價格。同樣的，像 Jetson Nano 這樣的單板機已經被裁剪用於特定用途。因此，取決於你需要什麼 —— 你應該檢查一下單板機的配置。

如果你知道比上述提到的更好的東西，請隨意在下方評論來讓我們知道。
