如何管理你的 Linux 環境變量 ​

Linux 用户環境變量可以幫助你找到你需要的命令，無須瞭解系統如何配置的細節而完成大量工作。而這些設置來自哪裏和如何被修改它們是另一個話題。

在 Linux 系統上的用户賬户配置以多種方法簡化了系統的使用。你可以運行命令，而不需要知道它們的位置。你可以重新使用先前運行的命令，而不用發愁系統是如何追蹤到它們的。你可以查看你的電子郵件，查看手冊頁，並容易地回到你的家目錄，而不用管你在文件系統中身在何方。並且，當需要的時候，你可以調整你的賬户設置，以便其更符合你喜歡的方式。

Linux 環境設置來自一系列的文件：一些是系統範圍（意味着它們影響所有用户賬户），一些是處於你的家目錄中的配置文件裏。系統範圍的設置在你登錄時生效，而本地設置在其後生效，所以，你在你賬户中作出的更改將覆蓋系統範圍設置。對於 bash 用户，這些文件包含這些系統文件：

/etc/environment
/etc/bash.bashrc
/etc/profile

以及一些本地文件：

~/.bashrc
~/.profile # 如果有 ~/.bash_profile 或 ~/.bash_login 就不會讀此文件
~/.bash_profile
~/.bash_login

你可以修改本地存在的四個文件的任何一個，因為它們處於你的家目錄，並且它們是屬於你的。

雖然你可能會看到大量的輸出，上面顯示的第一大部分用於在命令列上使用顏色標識各種文件類型。當你看到類似 *.tar=01;31: 這樣的東西，這告訴你 tar 文件將以紅色顯示在文件列表中，然而 *.jpg=01;35: 告訴你 jpg 文件將以紫色顯現出來。這些顏色旨在使它易於從一個文件列表中分辨出某些文件。你可以在《在 Linux 命令列中自定義你的顏色》處學習更多關於這些顏色的定義，和如何自定義它們。

當你更喜歡一種不加裝飾的顯示時，一種關閉顏色顯示的簡單方法是使用如下命令：

$ ls -l --color=never

這個命令可以簡單地轉換到一個別名：

$ alias ll2='ls -l --color=never'

你也可以使用 echo 命令來單獨地顯現某個設置。在這個命令中，我們顯示在歷史緩存區中將被記憶命令的數量：

$ echo $HISTSIZE
1000

如果你已經移動到某個位置，你在文件系統中的最後位置會被記在這裏：

PWD=/home/shs
OLDPWD=/tmp

作出更改 ​

你可以使用一個像這樣的命令更改環境設置，但是，如果你希望保持這個設置，在你的 ~/.bashrc 文件中添加一行代碼，例如 HISTSIZE=1234。

$ export HISTSIZE=1234

“export” 一個變量的本意是什麼 ​

導出一個環境變量可使設置用於你的 shell 和可能的子 shell。默認情況下，用户定義的變量是本地的，並不被導出到新的進程，例如，子 shell 和腳本。export 命令使得環境變量可用在子進程中發揮功用。

添加和移除變量 ​

你可以很容易地在命令列和子 shell 上創建新的變量，並使它們可用。然而，當你登出並再次回來時這些變量將消失，除非你也將它們添加到 ~/.bashrc 或一個類似的文件中。

$ export MSG="Hello, World!"

如果你需要，你可以使用 unset 命令來消除一個變量：

$ unset MSG

如果變量是局部定義的，你可以通過加載你的啓動文件來簡單地將其設置回來。例如：

$ echo $MSG
Hello, World!
$ unset $MSG
$ echo $MSG

$ . ~/.bashrc
$ echo $MSG
Hello, World!

小結 ​

用户賬户是用一組恰當的啓動文件設立的，創建了一個有用的用户環境，而個人用户和系統管理員都可以通過編輯他們的個人設置文件（對於用户）或很多來自設置起源的文件（對於系統管理員）來更改默認設置。
