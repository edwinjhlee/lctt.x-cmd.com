Speek!：一個使用 Tor 的開源聊天應用程序 ​

一個有趣的、開源的私人通訊軟件，它利用 Tor 來保證你的通信安全和私密。

Speek 是一種網絡通訊服務，它利用多種技術保證網絡聊天的私密性。

它是端到端加密的、去中心化和開源的。

毫無疑問，它的目標是將自己定位為 WhatsApp 的替代品 之一和 Linux 上的 Signal 的競爭對手。

那麼，它到底如何呢？ 讓我們一起來仔細看看細節。

Speek! 適用於 Linux 和安卓的點對點即時消息應用程序 ​

（LCTT 譯註： 點對點Peer-to-Peer，又稱對等式網絡，是無中心服務器、依靠 對等點peer 交換信息的互聯網絡體系，它的作用在於，減低以往網路傳輸中的節點，以降低資料遺失的風險。）

Speek!（名稱中帶有感嘆號）是一種加密的聊天軟件，旨在抗審查，同時保護數據隱私。

你也可以認為它是 Session 的替代品，但有一些區別。

與其他可用的通訊軟件相比，它是一個相當新的競爭對手。但是如果你想嘗試開源的解決方案，它應該作為候選者。

雖然 Speek! 聲稱能保持匿名，但如果你需要的是完全匿名的話，你應該始終注意自己在設備上的活動。因為你需要考慮的不僅僅是即時通訊軟件。

Speek! 利用去中心化的 Tor 網絡來保證安全性和私密性。不僅如此，這樣做可以讓你無需電話號碼就能使用服務。你只需要你的 Speek ID 就可以與人聯繫，而別人很難知道你的 ID。

（LCTT 譯註：Tor 是一個可以實現匿名通信的自由軟件。其名源於 洋葱路由器The Onion Router 的英文縮寫。）

Speek! 的亮點 ​

Speek! 的一些主要亮點包括：

  • 端到端加密：除收件人外，沒有人可以查看你的消息。
  • 通過 TOR 路由流量：使用 TOR 路由消息，增強隱私。
  • 沒有中央服務器：增加了對審查的抵抗力，因為很難關閉服務。此外，沒有針對黑客的單一攻擊點。
  • 無需註冊：無需共享任何個人信息即可開始使用該服務。你只需要一個公鑰來識別/添加用户。
  • 自毀聊天：當你關閉應用程序時，消息會自動刪除。增添了額外的隱私和安全性。
  • 無元數據：它會在你交換消息時消除任何元數據。
  • 私人文件共享：你還可以使用該服務安全地共享文件。

下載適用於 Linux 和其他平台的 Speek! ​

你可以從他們的 官方網站 下載 Speek!。

在撰寫本文時，Speek! 僅適用於 Linux、安卓、macOS 和 Windows。

對於 Linux，你會找到一個 AppImage 文件。如果你不知道 AppImage，可以參考我們的 AppImage 指南 來運行該應用程序。

另外，Google Play 商店 上的安卓應用程序還比較早期。因此，你在嘗試使用它時可以期待一下它的改進。

關於 Speek! 的用户體驗 ​

這個應用的用户體驗非常令人滿意，包含了所有必備的功能。它可以更好，但已經很不錯了。

嗯，關於 Speek! 的 GUI 沒什麼好説的。GUI 非常極簡風。它的核心是一個聊天應用程序，而它做得恰如其分。沒有動態，沒有附近的人，沒有不必要的附加組件。

在我使用這個應用程序的有限時間裏，我很滿意它的功能。它提供的功能使其成為一款出色的聊天應用程序，可通過其背後的所有技術提供安全和私密的消息傳遞體驗。

如果將它與一些商業上更成功的聊天軟件進行比較，它在功能上存在不足。但話又説回來，Speek! 的設計就不是一個只關注用户體驗的時尚聊天應用。

因此，我只向注重隱私的用户推薦 Speek!。如果你想要平衡用户體驗和功能，你可能希望繼續使用像 Signal 這樣的私人聊天軟件。
