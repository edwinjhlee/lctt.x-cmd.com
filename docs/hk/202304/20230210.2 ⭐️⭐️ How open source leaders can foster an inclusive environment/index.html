開源項目領導者可以如何營造包容的環境 ​

那些被你領入社區的人，有一天也會向其他人伸出援手。

開源領導者可以通過創造歸屬感、提供機會和表示支持來為新來者創造包容性社區。他們瞭解提交代碼和與其他社區成員建立聯繫的複雜性。創造包容性社區可以建立信譽並獲得影響力。這種經驗對於想要參與但不知道從哪裏開始的貢獻者來説是無價的。

幾年前，當我開始管理一個活躍於 Linux 內核社區的團隊時，我發現自己因為沒有任何內核經驗而感到處境困難。複雜的代碼庫、龐大的電子郵件歸檔和高風險的交流讓我感到害怕。當我團隊中的新內核開發人員表達了類似的感受時，我意識到我的感覺在團隊裏普遍存在。對於那些支持貢獻者或想自己做出貢獻的人來説，入門的道路並不總是清晰的，甚至可能感覺遙不可及。

4 個策略建立包容性領導力 ​

開源領導者可以通過為那些希望融入社區的人創造途徑來發揮自己的影響力。本文涵蓋的策略可應用於正式的 指導 或 輔導 關係，但同樣適用於日常互動。在培養環境的包容性時，看似微不足道的交流往往會產生最重要的影響。

懷着好奇心接近了解新人 ​

經驗較少或來自非傳統背景的人可能會以意想不到或不同的方式解決問題。在應對這些差異時，如果用妄加評論或批評的方式，可能會在知識曲線通常很陡峭的社區中創造一個不安全的學習環境。例如，Linux 內核的長期貢獻者瞭解社區豐富的歷史，這意味着他們不需要明説就能理解社區的決策和反應。新的貢獻者必須積累這方面的知識，但只有當他們感到安全，並願意冒必要的風險來發展自己的技能時，他們才能有效地做到這一點。

開源領導者可以通過帶着好奇心去接近新人來支持他們學習。你可以問他們這樣的問題，“你能幫我理解一下你為什麼採用這種方法嗎？”而不是直接宣佈提議的解決方案“對或錯”。問題打開了一個繼續學習的對話，而不是關閉那些值得探索的重要方面的想法。這個過程也拓寬了領導者的視野，他們可以通過考慮新的觀點來學習。

發現並分享學習機會 ​

開源領導者可以確定適合其他人的項目，使他們可以獲得技術專長和學習社區流程。在為他人創造機會的同時，領導者也為自己創造了更多機會。這是因為他們有更多時間探索新的嘗試，同時通過分派任務繼續推進他們的工作。隨着領導者的成長，他們幫助周圍的人取得成功的能力變得與他們的直接貢獻一樣重要。

要知道 失敗 是學習的一部分，因此你要考慮找一些新手失敗後不會造成嚴重後果的項目。例如，在 Linux 內核中，代碼庫的某些部分的小改動可能會造成災難性的後果。考慮可以實現小小的勝利的項目，以幫助新來者在沒有高風險的情況下建立信心並感到掌控感。通過會議、電子郵件論壇或任何涉及如何參與到社區裏的宣傳活動分享這些想法，讓人們更容易獲取到這些信息。

展現你脆弱的一面 ​

擁有更多的經驗並不意味着你知道一切。通常情況下，即使是與我共事過的最有經驗的 Linux 內核貢獻者也會被未知子系統中的新挑戰擊敗。經驗不足的社區成員通常會認為經驗豐富的社區成員已經瞭解了一切。但是，經驗就是要善於找出你不知道的東西。如果你處於權威地位或者被認為是專家，你可以通過分享個人掙扎和堅持的經驗來表現你脆弱的一面，這樣做可以鼓勵那些和你有着類似感受的人。

為他人做擔保 ​

向你的人脈介紹新來的成員。在激發他們興趣的領域裏，讓新成員和在這個領域內具有專業知識的社區成員建立聯繫。在公共論壇上説出他們的名字，並稱贊他們所做的出色工作。作為受人尊敬的領導者，你的支持可以幫助他們在社區內建立聯繫和信任。

通過樹立社區包容性，我們可以擁有豐富多樣的社區。我希望開源領導者會考慮這些建議，因為你提拔到社區的人未來的某天也會同樣向別人伸出援手。
