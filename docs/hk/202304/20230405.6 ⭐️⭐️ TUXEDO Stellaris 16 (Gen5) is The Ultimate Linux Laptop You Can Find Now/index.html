TUXEDO Stellaris 16（Gen5）是目前所能找到的終極 Linux 筆記本電腦 ​

這款筆記本電腦擁有 RTX 4090 和 i9 處理器等規格，可謂驚人！你覺得呢？

TUXEDO 電腦是 Linux 領域的一個著名品牌，它提供了不同價格/性能的可定製的 Linux 筆記本和台式電腦。

順便説一句，它是值得信賴的 購買 Linux 電腦 的地方之一。

在最近的公告中，他們推出了 Stellaris 16 英寸筆記本電腦的下一個進化版。

我必須説，這可以成為 Framework 最近宣佈的高性能 16 英寸筆記本電腦的有力挑戰者。

讓我們來看看它。

TUXEDO Stellaris 16 Gen 5 概覽 ​

這款筆記本電腦的主要亮點是，它採用了英偉達最新、最強大的 RTX40 系列 筆記本 GPU，提供了強大的圖形性能和功能。

搭配了英特爾的頂級處理器 i9 13900HX，其 24 個核心可以在高達 157W TDP（睿頻）的情況下超頻到 極快的 5.40 GHz，這是一個引人注目的組合。

但請記住，為了充分發揮筆記本電腦的運行潛力，TUXEDO 建議使用 他們的外部水冷卻解決方案，TUXEDO Aquaris，它可以通過磁力連接到筆記本電腦的背面。

📋 在訂購該筆記本電腦時，你必須為此支付額外費用。

該處理器在沒有全速運行時，基本 TDP 為 55W，時鐘速度為 3.90GHz。

對於這樣一台輕薄的筆記本電腦來説，這仍然是一個不錯的性能數字！ 😮

Stellaris 16 - Gen5 筆記本電腦的一些其它關鍵亮點如下：

  • 外殼 1是由鋁和塑料的組合組成。
  • 一個 240 赫茲的 16 英寸 IPS 顯示屏，支持英偉達 G-SYNC。
  • GPU 最高可選英偉達 RTX 4090。
  • 高達 64GB DDR5，5600MHz 的內存（2x32GB）。
  • 99Wh 的電池，允許運行時間長達 10 小時（空閒），在典型負載下約 6-7 小時。

TUXEDO Stellaris 16：是什麼讓它成為強者？ ​

Stellaris 16 - Gen5 筆記本電腦上的高端硬件不僅吸引了遊戲玩家，也吸引了其他各種用户，如內容創作者、AI/ML 工程師、UI/UX 藝術家等等。

那麼，是什麼讓它囊括如此完整的用户羣體呢？

嗯，是在各種可能的設置中自由選擇。

首先，你可以從 RTX 4060 這種相對平靜的 GPU 到瘋狂的 RTX 4090 中挑選，其間還有 RTX 4070 和 RTX 4080 可選。

然後是鍵盤選項，你可以選擇他們新增加的 櫻桃 MX Ultra-Low Profile 機械鍵盤，以獲得打字時的觸覺和聽覺感受，或者通常的靜音薄膜鍵盤。

你還可以從廣泛的鍵盤佈局清單中挑選，包括英語、德語、西班牙語、匈牙利語，以及更多，還有帶有背光的 TUX 超級鍵。

內存也不例外。你可以在兩個性能層之間做出選擇。一個是 “性能” 層，提供 DDR5 RAM，以迅速的 4800 MHz 運行，一個是 “高性能” 層，提供 DDR5 RAM，以令人瞠目的 5600 MHz 運行。

這些層級提供最大 64GB 的內存，採用來自 SK 海力士、三星和美光的內存條。

至於存儲，兩個 PCIe 4.0 x4 的 M.2 2280 SSD 插槽，配備各種三星 SSD。其陣容從三星 970 EVO Plus 開始，中間是三星 980，極速的三星 980 Pro 是該系列的頂配。

📋 在兩個 M.2 插槽都插滿的情況下，最多可實現 4TB 的存儲。

除此之外，Stellaris 16 - Gen5 具有 Wi-Fi 6E 和藍牙 5.3，並預裝了 TUXEDO OS，除非你在購買時選擇不同的操作系統，如 Ubuntu 22.04 LTS、Kubuntu 22.04 LTS、Ubuntu Budgie 22.04 LTS 和 Windows 11 Home/Pro 等。

什麼時候可以買到和價格 ​

TUXEDO Stellaris 16 - Gen5 現在可預購，在 4 月底開始交付。

基本配置的價格為 1763.87 歐元，配備 i9 處理器、RTX 4060、運行頻率為 5600 MHz 的 16GB 內存（2x 8GB），500GB 三星 980 固態硬盤和 TUXEDO 操作系統。

預購

前往 官方商店列表，並開始按照你的要求進行配置吧。
