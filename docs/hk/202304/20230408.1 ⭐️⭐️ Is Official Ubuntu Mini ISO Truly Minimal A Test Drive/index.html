官方的 Ubuntu 精簡 ISO 真的“精簡”嗎？ ​

Ubuntu 23.04 “Lunar Lobster” 新推出的精簡安裝程序到底有多精簡呢？一起來看看吧。

幾周前，Canonical/Ubuntu 開發者 確認了 Ubuntu 23.04 Lunar Lobster 將引入官方的精簡版安裝程序。對於那些等待 Ubuntu Linux 官方精簡安裝程序的用户來説，這是個好消息，因為 Canonical/Ubuntu 此前從未對任何精簡 ISO 鏡像提供官方支持。

雖然在 Ubuntu 18.04 時期有一些非官方性質的舊版精簡 ISO 鏡像，但它們都已經停止維護。鑑於 Ubuntu Linux 的熱門程度，這種無法獲取精簡安裝程序的情況已阻礙部分用户的選擇。

正如公告所言，Canonical 現在已經為 Ubuntu 23.04 Lunar Lobster 版本推出了官方精簡安裝程序，這也意味着那些希望安裝輕量版本 Ubuntu Linux 用户的等待終於結束了。

我試運行了該 測試版 ISO 鏡像（LCTT 校注：本文原文發佈於 Ubuntu 23.04 正式版發佈之前）。下面是我發現的一些東西。

在最新的 Beta 版本中，官方的 Ubuntu 精簡版 ISO 安裝程序現已提供試用。“Lunar Lobster”版本的官方 ISO 鏡像大小為 113 MB，這確實很小。

當你首次啓動該精簡 ISO 時，你將可以選擇兩個主要選項 —— 針對服務器版本和桌面版本的安裝選項。目前我用於試運行的測試版精簡 ISO 顯示了 Ubuntu 22.04 LTS 和 Ubuntu 22.10 Kinetic Kudu —— 於去年發佈。不過，先暫時忽略這些文本標識吧。

我首先嚐試安裝桌面版本。令人驚訝的是，它運行了一個下載器，以獲取用於標準桌面安裝的所有軟件包。精簡桌面版的選項需要從互聯網下載超過 3GB 的軟件包，而且用時很長。考慮到我的位置與 Ubuntu 服務器狀態，我的下載測試花費了大量時間。

如果你將使用精簡 Ubuntu ISO 安裝桌面所需的時間與精力與常規下載進行比較，那精簡版反而慢許多，並佔用大量系統資源。舉個例子，在安裝程序運行時，下載的完整 Ubuntu 桌面版也同時存儲於內存當中。

因此，精簡版的最小內存大小要求為 8GB。如果你沒有 8GB 內存，你就無法運行該安裝程序。而另一邊，如果你藉助標準的 torrent 文件下載 Ubuntu 桌面版，那麼用於啓動安裝程序的最小內存要求則為 4GB。

下載完成後，安裝程序將啓動立付Live Ubuntu 系統，在這裏，你將可以和平常一樣安裝帶有 GNOME 桌面的 Ubuntu 桌面版。這根本沒有區別。

來到服務器選項，我在精簡安裝程序裏選擇了 Ubuntu 22.04 LTS 服務器版本。令我驚訝的是，服務器安裝選項也需要至少 8GB 內存才能開始安裝。基於該版本，它下載了約 1.8GB 的軟件包。之後，它啓動了正常的 Ubuntu 服務器版安裝程序。這與常規的服務器版安裝過程也是毫無區別。

綜上可知，精簡版桌面安裝程序僅僅只是一個下載完整桌面版或服務器版鏡像的 CLI 前端界面，僅此而已。這款安裝程序的主要用途可能是 Ubuntu 桌面版或服務器版的聯網安裝。但，再次強調，你需要穩定的網絡連接，以便下載所需內容。

與之相似的是，Xubuntu 團隊在幾周前 提供了 精簡版 ISO，它只包含基本的 Ubuntu，以及不含任何額外程序的原生 Xfce 桌面。

也就是説，這款安裝程序恐怕和你從名字裏所想的不太一樣。如果他們能提供一款僅包含必要的 Ubuntu 組件，且不含桌面環境、Snap 等要素的“真·精簡 ISO”，那會更好；就像不含任何桌面組件的原生 Arch 安裝那樣。

你可以從 該頁面 下載精簡 ISO。
