可以替代微軟 Exchange 的 5 個開源軟件 ​

不再將就於微軟 Exchange 這一專有軟件，試一試這些基於 Linux 系統的電子郵件和羣件服務吧。

幾十年來，微軟 Exchange 一直統治着電子郵件和羣件服務市場。作為領頭羊，它主宰着企業界，無處不在的 Outlook 郵件客户端已成為羣件的事實標準。由於 Exchange 與微軟的 Office 產品緊密聯繫，無論是桌面客户端還是移動客户端，微軟用户都可以輕鬆使用各種生產力軟件和功能。

然而，許多公司對於將數據存儲在微軟的雲中也心存疑慮。在本文中，我將介紹一些開源替代產品及其優勢。這不僅與如何不再受供應商控制和降低成本有關，更關乎使用具有開放標準和不同安全級別的軟件 —— 用於組件服務器本身及其背後的操作系統。

本文中介紹的這五個替代產品都是基於 Linux 的。 雖然 grommunio、Kopano、Nextcloud、ownCloud 和 OX App Suite 在功能上差異很大，吸引到的企業類型各不相同，但它們都提供免費版本，並可選擇購買付費支持服務和附加組件。所有產品都可以在本地或雲端運行。最重要的是，所有供應商都為其軟件提供 SaaS（軟件即服務Software as a Service）解決方案。

grommunio ​

grommunio，以前被稱為 grammm，在 AGPLv3 許可下發布的。它由奧地利同名公司開發和支持。與 Exchange 不同，grommunio 提供符合標準的郵件服務器，以及功能齊全的羣件解決方案，具有電子郵件、聯繫人、日曆、任務、文件共享等功能。grommunio 適用於各種開源和專有郵件客户端，如 Windows Mail、Outlook、Android、Apple Mail/iOS、Thunderbird 等，並支持舊的 RPC over HTTP 協議和 Outlook 標準協議 MAPI over HTTP。除此之外還包含：用於移動設備的 Exchange ActiveSync 和各種標準協議，如 CalDAV（日曆）、CardDAV（地址簿）、IMAP、POP3、SMTP 和 LDAP，以及活動目錄（用於同步用户帳户）。

外部對接的開源應用程序還提供了一些微軟的 API 或協議不支持的功能。例如，開發人員合併了 Jitsi（視頻和音頻電話軟件）、Mattermost（聊天軟件）以及文件共享和同步（ownCloud）。除此之外，grommunio 還配備了基本的移動設備管理軟件（MDM）。

grommunio 的設計面向各種不同的用户，並且與 Exchange 一樣，它支持資料庫分片（資料庫在多個主機之間的水平分佈）。靈活的存儲後端允許管理員通過添加其他服務器或雲帳户來擴展他們的設置。grommunio 僅將 MySQL 資料庫用於元數據，而所有“內容”（例如郵件和羣件對象）都存儲在每個用户的 SQLite 資料庫中。有關底層架構的更多信息，請查看 該製造商的網站。

其社區版是免費的，其中包括所有的 grommunio 功能並支持多達五個用户帳户。

Kopano ​

來自德國和荷蘭的軟件製造商 Kopano 出品的 Kopano，也採用 AGPLv3 許可，基於 Zarafa 軟件堆棧。與其前身不同，Kopano 的目標不只是成為 Exchange 的替代品。相反，它提供一個完整的羣件解決方案，除了電子郵件、聯繫人、日曆、任務、筆記和文檔編輯這些標準功能外，它還包括實時通信。Kopano 可以與 許多其他平台、應用程序和服務交互，其中一些通過插件就能輕鬆實現。對於視頻會議，Kopano 團隊基於 WebRTC 開發了自己的開源解決方案：Kopano Meet 提供端到端加密，在 Windows、macOS、Linux、Android 和 iOS 客户端都適用。

Outlook 客户端通過 ActiveSync（Z-Push 庫）或 Kopano OL Extension（KOE）來同步移動數據，KOE 是已經包含了 ActiveSync 的加強版。Kopano 提供本機 Web 客户端（WebApp）、移動設備客户端（Mobility）以及支持 Windows、Linux 和 macOS 的桌面版本（DeskApp）。它可以通過 IMAP、CalDAV 和 CardDAV 連接其他客户端。所有直接連接到 Kopano 服務器的應用程序都使用 SOAP（簡單對象訪問協議Simple Object Access Protocol）中的 MAPI。

Kopano Groupware 和 Kopano ONE（Kopano Groupware 的特別版）都提供免費的社區版本。 Kopano Meet 還可以作為應用程序或容器下載。

Nextcloud ​

Nextcloud 在斯圖加特和柏林（德國）都有辦事處，採用 AGPLv3 許可。與 ownCloud 或 Dropbox 一樣，用户可以通過桌面（Windows、Linux 和 macOS）、網絡瀏覽器或本地應用程序（Android 和 iOS）訪問該軟件套件。從 18 版本開始，Nextcloud 除了擁有 Nextcloud Files（文件同步和共享）還包括了 Nextcloud Talk（通話、聊天和網絡會議）和 Nextcloud Groupware（日曆、聯繫人和郵件），並更名為 Nextcloud Hub。

用户和羣組管理通過 OpenID 或 LDAP 進行。Nextcloud 支持各種存儲後端，例如 FTP、S3 和 Dropbox。Nextcloud 可與多種資料庫管理系統配合使用，包括 PostgreSQL、MariaDB、SQLite 和 Oracle 資料庫。管理員可以通過 Nextcloud 應用程序商店 中的 200 多個應用程序擴展功能，其中包括實時通信、音頻和視頻聊天、任務管理、郵件等等。

Nextcloud 是完全免費的。最重要的是，該公司提供了 Nextcloud Enterprise 版本（針對企業部署進行了預配置、優化和強化）

ownCloud ​

ownCloud 是由位於德國紐倫堡的 ownCloud GmbH 公司開發和維護的具有文件同步、共享和內容協作功能的軟件。它的客户端-服務器軟件的核心和許多社區應用程序都是在 AGPLv3 下發布的。一些擴展功能的企業應用程序以 ownCloud 商業許可證（OCL）的形式授權。

ownCloud 主要是一款內容協作軟件，包括在線辦公文檔編輯、日曆、聯繫人同步等功能。移動客户端支持 Android 和 iOS，桌面應用可以和 Windows、macOS 和 Linux 的原生文件管理器結合使用。它允許訪問 Web 界面，無需安裝專用客户端軟件。ownCloud 支持 WebDAV、CalDAV 和 CardDAV 協議。LDAP 協議也包含其中，但 ownCloud 也可以連接到支持 OpenID Connect 身份驗證標準的其他身份提供者。

ownCloud 可以整合微軟 Office Online Server、Office 365 和微軟 Teams，同時為微軟 Outlook 和 eM 客户端提供可用插件。如有必要，外部存儲功能可連接到不同的存儲提供商，例如 Amazon S3、Dropbox、微軟 SharePoint、Google Drive、Windows 網絡驅動器（SMB）和 FTP。該供應商還為企業客户提供額外的功能，如端到端加密、勒索軟件和防病毒保護等（請參閲 完整功能列表）。

社區版免費且 100% 開源。

OX App Suite ​

Open-Xchange 成立於 2005 年，總部位於德國奧爾佩和紐倫堡。今天，OX 在多個歐洲國家、美國和日本設有辦事處。OX App Suite 是一個模組化的電子郵件、通信和協作平台，主要為電信公司、託管公司和其他提供基於雲的服務的提供商而設計。

OX 後端在 GPLv2 協議下發布，前端（UI）在 AGPLv3 下發布。用户可以通過他們喜歡的瀏覽器（完全個性化的門户）或移動應用程序（Android 和 iOS）訪問應用程序套件。或者，原生客户端（移動設備和台式機）也可用於 OX Mail 和 OX Drive。得益於 CardDAV 和 CalDAV 擴展、Exchange Active Sync 和適用於 Android 的 OX Sync App，聯繫人、日曆和任務得以同步。

OX App Suite 包含用於電子郵件、聯繫人、日曆和任務的應用程序。 還有其他工具和擴展可用，其中一些是開源的，一些功能則要付費，包括 OX Documents（文本文檔、電子表格、演示文稿）、OX Drive（管理、共享和同步文件）、OX Guard（電子郵件和文件加密）等等。如需完整列表，請訪問 OX 網站的 一般條款和條件。

該應用免費提供有限功能的社區版。

開源電子郵件和羣件 ​

電子郵件和羣件服務並不是必須花（很多）錢才可獲得，當然也沒有必要滿足於在別人的服務器上託管的專有解決方案。如果你不太熱衷於管理職責，那麼上述的這五個 Exchange 開源替代品都可以作為 SaaS 解決方案使用。另外，所有供應商都提供專業技術支持，你可以在本地運行軟件，一切盡在你的掌握中，但你卻不會感覺自己孤軍無援。
