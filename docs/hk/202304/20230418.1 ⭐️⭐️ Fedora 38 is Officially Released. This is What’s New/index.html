Fedora 38 正式發佈 ​

Fedora Linux 的最新版本 Fedora 38 已經發布，帶來了一系列令人興奮的新功能和更新。以下是其中的一些亮點。

Fedora Linux 是一個流行的發行版，提供最新的軟件包和技術。它是一個由紅帽公司贊助的社區驅動的項目，是在主流 Linux 發行版之前領先採用新技術和功能的先驅。

它的 2023 年的第一個版本現在已經可以下載和升級。雖然我在我的文章中介紹過了它的功能亮點，但讓我給你再摘要介紹一下。

Fedora 38 工作站的新內容 ​

讓我們從 Fedora 38 工作站版開始，它默認提供的是 GNOME 桌面。Fedora 38 工作站採用 GNOME 44 版本的桌面環境，為用户提供了正宗的 GNOME 體驗，因為 Fedora Linux 工作站搭載的是原汁原味的 GNOME。

在 GNOME 44 中最重要的更新之一是系統托盤菜單中的後台應用程序功能。這個功能在主應用程序窗口不可見時非常有用，許多應用程序和用户都藉助了該功能。Fedora 38 還包括了 “文件Files”（即 Nautilus）應用程序中的擴展文件夾視圖，現在它可以在列表視圖中使用。

此外，Fedora 38 還改進了文件打開對話框，可以在網格視圖佈局中顯示圖像預覽，這個功能人們已經等待了十年之久。這些變化和改進之外，GNOME 44 中還有許多其他較小的改進。

除了 GNOME，Fedora 38 還有作為 “定製版Spin” 的其他桌面環境，比如 KDE Plasma、Xfce、LXQt 和 MATE。

KDE Plasma 版的 Fedora 38 採用了 Plasma 5.27 桌面版本，其中包括平鋪窗口功能、多顯示器顯示的強大設置、Wayland 更新以及一個全新的歡迎屏幕。

Fedora 38 Xfce 版中包含了 Xfce 4.18 的桌面。經過近兩年的時間，這是一個功能方面的大規模發佈，包括了重新打造的 Thunar 文件管理器，它帶有分割視圖、圖像預覽、強大的 FTP 設置和更多面板調整。

其他風格的桌面，如 LXQt 1.2.0 和 MATE 1.26 在 Fedora 38 也是最新的版本。Fedora LXQt 定製版正在為用户引入一個 Arch64 ISO 鏡像。

由於 i3 窗口管理器定製版的流行，Fedora 在 Fedora 38 中引入了一個官方的 Sway 定製版。喜歡低內存佔用的精簡桌面的用户現在可以享受 Sway 了，它帶來了出色的 Wayland 支持。

經過幾個月的開發，一個官方的 Fedora Budgie 定製版在 Fedora 38 中首次出現。它由 Solus 項目開發的，是一個輕量級但功能豐富的桌面環境，看起來很專業，併為菜單/圖標驅動的桌面提供了一種替代。這個版本帶來了 Budgie 桌面 10.7.2 版本中令人興奮的功能更新。

Fedora 38 現在可以不受限制地使用 Flathub 的軟件包，這是一個最廣泛的 Flatpak 應用集合。以前，用户必須改變過濾器才能從“軟件”應用中訪問 Flathub 軟件包。然而，現在所有的 Flathub 軟件包都可以在“軟件”應用中使用，其中優先考慮 Fedora 核心軟件包。

Fedora 38 中默認的 systemd 單元關機計時器從 2 分鐘變為 45 秒。這一改變解決了一個有問題的服務會導致系統關閉過程停滯 2 分鐘，給用户帶來不必要的等待的問題。團隊將觀察實際的反饋和用户體驗，並可能在未來的版本中將其減少到 15 秒。

出於安全考慮，現在默認情況下，從一個大端架構（s390x）以外的不同的大小端系統連接到 X 服務器（X.Org 或 XWayland）是禁用的。然而，用户可以創建自定義配置來允許它。

所以，這就是關於 Fedora 38 的主要亮點。你可以在我的重要專題 文章 中瞭解更多細節。

如何升級到 Fedora 38 ​

你可以依次運行以下命令來升級到最新版本。詳細的升級指南 放在這裏。

sudo dnf update
sudo dnf upgrade --refresh
sudo dnf install dnf-plugin-system-upgrade
sudo dnf system-upgrade download --releasever=38
sudo dnf system-upgrade reboot
