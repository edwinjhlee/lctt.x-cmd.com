使用這個開源的會計應用來管理你的小企業 ​

用 GnuCash 跟蹤客户和發票的情況。

GnuCash 是一個強大而靈活的會計工具，可用於小企業的發票和會計。它的許多功能使它特別適合這一目的，包括跟蹤支出和收入、生成報告和管理發票的能力。此外，GnuCash 是自由開源的，這使得資源有限的小企業也可以使用它。在這篇文章中，我會討論 GnuCash 的特點，使你可以很容易地在自己的小企業中開始使用它。

幾年前，我開始使用 GnuCash 進行個人財務管理，但發現它也可以作為我的小企業的一個有用工具。在我企業的大部分時間裏，我一直在使用一個專有的解決方案。我逐漸厭倦了被迫定期升級以獲取我的小企業的發票和報表。轉而使用 GnuCash，使我能夠在不犧牲任何功能的情況下，將我的小企業會計與我的個人財務相結合。

在 Linux 上安裝 GnuCash ​

你可以從你的倉庫中安裝 GnuCash。在 Debian、Elementary 和類似的軟件上：

$ sudo apt install gnucash

在 Fedora、CentOS、Mageia 和類似系統上：

$ sudo dnf install gnucash

企業版 GnuCash ​

GnuCash 帶有一個賬户設置嚮導，可以幫助你建立一個普通的商業賬户配置。要訪問它：

  • 啓動 GnuCash。
  • 點擊 “文件File” 菜單，選擇 “新文件New File”。

按照屏幕上出現的 GnuCash 助手來創建你的新商業賬户文件。

屏幕上的説明將指導你完成設置業務的過程。單擊 “助手Assistant” 窗口右上角的 “下一步Next”。系統會提示你輸入公司名稱、地址、聯繫信息和你自己選擇的公司 ID。你還必須選擇默認税表和日期格式。

下一個頁面提示你選擇貨幣，有大量的貨幣支持。

然後提示你選擇你要創建的賬户。選擇創建 “企業賬户Business Accounts” 的選項。你可以隨時定製賬户列表，GnuCash 提供了 大量的文檔，幫助你更好地根據個人需求進行定製。

完成助手，然後單擊 GnuCash “助手” 窗口右上角的 “應用Apply”。

添加客户 ​

GnuCash 的頂部菜單有一個標有 “業務Business” 的菜單項。該菜單上的第一個項目是 “客户Customers”，其次是 “客户概覽Customers Overview”。在這裏你可以查看你所有客户的列表。

下一個項目是 “新客户New Customer”。這是你輸入新客户的地方。對話框為客户信息提供了一個位置，包括帳單信息、運輸地址、電子郵件地址、電話號碼等。

創建一個發票 ​

添加客户後，你可以開始創建發票的過程。點擊 “業務” 菜單，選擇 “客户”，然後點擊 “新發票New Invoice”。

付款處理也很簡單。這位於 “業務” 菜單中。選擇 “客户”，然後 “處理付款Process Payment”。

你在做生意了 ​

如果你的業務需要，“業務” 菜單還包括輸入供應商和僱員的選項。有一個菜單項用於銷售税和許多其他選項，以確保你符合當地的要求。

使用 GnuCash，你的數據不是以專有格式存儲的，所以如果你需要，你可以在將來遷移到任何其他平台。數據存儲的開放標準，特別是當這些數據是法律要求的時候，是很重要的，可以讓你完全擁有你的商業歷史。使用 GnuCash 使你能控制你的小企業。
