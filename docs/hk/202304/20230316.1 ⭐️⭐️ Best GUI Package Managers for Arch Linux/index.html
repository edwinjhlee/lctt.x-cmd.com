Arch Linux 的最佳 GUI 包管理器 ​

讓我們點評一些最好的 Arch Linux GUI 包管理器。選擇最符合你需求的。

由於其可定製性、靈活性和尖端功能，Arch Linux 是高級用户和開發人員中最受歡迎和使用最廣泛的 Linux 發行版之一。

由於其極簡設計，在 Arch Linux 中安裝軟件的主要方式是使用終端通過命令列界面 （CLI）。

但並不是每個人都喜歡使用終端。基於圖形用户界面（GUI）的包管理器是這些人的必備程序。有幾個可選的包管理器。讓我們瞭解一些比較流行的。

在 Arch Linux 上尋找基於 GUI 的包管理器要考慮什麼？ ​

在為 Arch Linux 選擇基於 GUI 的包管理器時，必須考慮幾個因素：

首先，它應該有一個乾淨易用的界面，對初學者來説很直觀。

其次，它應該支持所有包管理操作，例如安裝、刪除、更新和搜索包。

第三，它應該具有高級功能，例如依賴項解析和對 AUR 包的支持。

最後，它應該是輕量級的，不會佔用太多的系統資源。

Arch Linux 的最佳 GUI 包管理器 ​

1、Pamac ​

此列表中的第一個 GUI 包管理器是 Pamac，它由 Manjaro Linux 團隊開發。具有漂亮且用户友好的界面，使其超級易於使用。

其直觀的界面使用户可以輕鬆安裝、刪除和更新軟件包。它建立在支持 AUR 的 libalpm 之上。Pamac 還支持 Snap 和 Flatpak 的 appstream:/// 協議。因此，你可以直接從 appstream 鏈接啓動該應用安裝程序。此外，它還具有高級功能，例如依賴項解析和對 AUR 包的支持。此外，Pamac 是輕量級的，不會佔用太多系統資源。

使用其 GUI，你可以瀏覽 Arch 倉庫，還可以根據其功能查看應用。Pamac GUI 中有單獨的部分，可以使你能夠刪除和卸載包，包括孤立的包。

它是最好的 GUI 包管理器之一。

Pamac 安裝很容易。它在 Arch 用户倉庫（AUR）中可用。你可以 安裝 Yay AUR 助手或任何其他助手來安裝它。這是使用 Yay 安裝的命令。該軟件包位於 此處。如果你正在運行 Manjaro Linux，它應該已經存在。

yay -S pamac-aur-git

2、Octopi ​

接下來的 GUI 包管理器是 Octopi，它是另一個漂亮的工具。它是使用 Qt 構建的，並帶有一個高效的 GUI。在功能方面，它是一個非常先進的工具。

使用 Octopi，你可以搜索包、安裝它們，當然也可以刪除它們。此外，你可以查看直接從 Arch 倉庫中獲取的每個包的詳細信息。例如，包版本、最後更新日期、新聞和其他信息。

此外，它允許你查看包的 PKGBUILD 信息。如果你想進一步調查包，這是一個很好的功能。

最後，它是超輕量級的，不會佔用大量系統資源。我認為 Octopi 完全被低估了，它是 Arch Linux 功能豐富的軟件管理器之一。

它在 AUR 中可用，你可以使用 Yay 或任何 AUR 助手安裝它。

yay -S --needed octopi

3、GNOME “軟件”應用 ​

此列表中的第三個是你可能已經知道的 GNOME “軟件Software”應用。它是 Ubuntu、Fedora 和許多其他發行版的默認軟件管理器。基於 GTK4，它支持所有類型的包，如 .deb、.rpm、Flatpak 和 Snap。在 Arch Linux 中，它支持主 Arch 倉庫，包括用户倉庫（AUR）。

但是，與此列表中的其他應用程序相比，它對系統資源的佔用可能有點大。但它是一個現代的包管理器，可以很好地用於各種場景。

安裝很簡單，因為它在主 Arch 倉庫中可用。你可以從終端使用以下命令安裝它。

sudo pacman -S --needed gnome-software

4. KDE “發現”應用 ​

我個人最喜歡的是 KDE “發現Discover”應用 ，它是 KDE Plasma 團隊中最好的軟件管理器之一。如果你使用過 Kubuntu 或任何其他 KDE Plasma 桌面，那麼你已經熟悉它了。

“發現”應用支持所有主要的打包格式，包括 deb、rpm、Flatpak 和 Snap。它有一個定義明確的軟件及其來源信息頁面。你還可以按應用名稱搜索或按應用類別瀏覽目錄。

對於 Arch Linux，它可以從主 Arch 倉庫和 AUR 中獲取包和信息。

你可以在 Arch Linux 中使用以下命令安裝它。

sudo pacman -S --needed discover

5、Bauh ​

Bauh 是一個相對較新的基於 GUI 的 Arch Linux 包管理器。它具有簡單且用户友好的界面，使用户可以輕鬆管理他們的包。

它的主窗口為你提供了在 Arch Linux 系統中管理應用程序的所有選項。主搜索框使你能夠搜索應用程序。此外，你可以通過類型瀏覽，例如僅查看 Flatpak、AUR 等包。

此外，使用 Bauh 的主 GUI，你可以逐個降級和更新軟件包，查看軟件包信息，甚至直接啓動應用。

良好設計的設置面板為你提供了所需的所有自定義選項。

在系統中 設置 AUR 之後，你可以使用以下命令安裝它。

yay -S --needed bauh

還有幾個 ​

還有一些其他的包管理器可以在 Arch Linux 中使用。這是其中的一小部分。這些不是那麼流行。但它們也可以作為替代方案。

  • Apper：使用 PackageKit 的應用和包管理器（來自 KDE 團隊）
  • tkPacman：使用 Tcl/Tk 構建的 pacman 輕量級 GUI

最後，你可以在官方 Arch Wiki 中閲讀更多相關信息。

總結 ​

在本文中，我們討論了一些適用於 Arch Linux 的最佳基於 GUI 的包管理器，包括 Pamac、Octopi、GNOME “軟件”應用、KDE “發現”應用 和 Bauh。

這些包管理器中的每一個都有自己的優點和缺點，因此你可以選擇最適合你需求的那個。

如果你要我推薦，我建議你試試這些：Pamac、Octopi 和 Bauh。它們都是很好的。
