Xubuntu 23.04 的最佳新功能 ​

一些很酷的功能將在 Xubuntu 23.04 “Lunar Lobster” 版本中出現。

Xubuntu 23.04，基於即將發佈的 Ubuntu 23.04 “Lunar Lobster”，將於 2023 年 4 月 20 日到達。這個最新版本建立在 Linux 內核 6.2 上，帶來了最新的硬件、CPU、GPU 和文件系統支持。

從改進的小程序到更強大的 Thunar 文件管理器，Xubuntu 23.04 提供了大量的改進和錯誤修復，通過所有 Linux 桌面的 “OG” —— Xfce 4.18，提供了更精煉的用户體驗。

如果你正在使用之前的 Xubuntu 22.10，那麼你可能會注意到桌面環境的明顯變化。Xubuntu 22.10 以開發版 Xfce 4.17 為特色，並帶有來自 Xfce 4.18 少量功能。

考慮到這一點，讓我們來看看 Xubuntu 23.04 “Lunar Lobster” 的最佳新功能。

Xubuntu 23.04 的最佳新功能 ​

Xfce 4.18 更新 ​

這個版本中的一個重要變化是對 Xfce 桌面環境的更新。Xubuntu 23.04 基於 2022 年 12 月發佈的 最新的 Xfce 4.18。Xfce 4.18 是該桌面環境的一個重要里程碑，提供了對 GTK4 的更新、對 Wayland 的初始支持以及對核心原生應用的改造，更新量很大。

頂部主面板已經更新了新的設置和調整，而整體外觀仍與早期版本相同。一些默認的面板小程序在這個版本中也被改變了，而桌面圖標、右鍵上下文菜單和項目保持不變。

面板首選項得到了增強，有兩個新的選項。首先，面板的長度現在是以像素為單位，而不是百分比。其次，增加了一個新的選項，“保持面板在窗口上方”，允許用户將窗口對話放到面板後面。在早期版本中，應用程序窗口只能達到面板邊緣。

在 Xfce 4.18 中對時鐘小程序的設置進行了大修。用户終於可以改變 Xfce 時鐘小程序的字體風格，並且有四個時鐘佈局選項：只顯示日期，只顯示時間，日期和時間，以及時間和日期。

Thunar 文件管理器的更新 ​

由於在 Google Summer of Code 2022 期間所做的工作，用户現在可以在 Thunar 的嵌入式側邊欄中看到圖片預覽，或者在獨立模式下出現在右側的新面板中，這可以通過偏好設置進行更改。

Thunar 的設置也得到了加強，增加了一個新的標籤用於定製鍵盤快捷鍵。用户現在可以直接指定新的組合鍵，並從這個標籤中改變現有的組合鍵。

一個新的搜索圖標已經取代了工具欄中的重載按鈕，當點擊它時，它會在地址欄中調出搜索，用用户的搜索關鍵詞進行遞歸搜索。重載按鈕已被移至 “查看View” 菜單。另一個新項目，“最近Recent”，已被添加到左邊的導航欄。同時，元數據被組織得更好了（從逗號分隔換成豎線分隔），一個新的上下文菜單項允許用户選擇他們想要的選項。

Thunar 的主菜單也發生了重大變化。引入了一個新的 “書籤Bookmarks” 菜單，允許用户將當前文件夾作為快捷方式添加到側邊欄中。“編輯Edit”菜單現在包括 “撤銷Undo” 和 “重做Redo” 選項，而 “前往Go” 菜單則有 “最近”和 “按文件搜索Search for the file”選項。

Thunar 還首次通過 “視圖View” 菜單項增加了分割視圖，使用户能夠在視圖面板中拖放項目。另外，為了組織你的文件夾以加快工作流程，Thunar 還為你的文件夾及其名稱引入了背景顏色。

除了 Xfce 4.18 的功能外，Xubuntu 23.04 還為窗口管理器和桌面的提供了更多的錯誤修復和性能改進。這些改進是在底層進行的；用户可以期待一個更精巧的 Xfce 桌面體驗。

雖然 Xfce 桌面核心和本地應用程序的 Wayland 遷移工作已經開始，但它仍然遠遠沒有準備好。因此，這個 Xubuntu 23.04 可能是未來 Wayland 工作的基礎，希望可以出現在下一個 Xubuntu LTS 之前。雖然，考慮到 Xfce 團隊的規模和其他方面，這不太有信心。

最小化 ISO ​

正如我之前所報道的，Xubuntu 23.04 也引入了一個最小化的 ISO 鏡像，其中只有基本的 Xfce 桌面組件，沒有任何額外的預裝軟件。你可以試試這個最小化的 ISO，為你的工作流程建立你自己的桌面設置。

最小化的 ISO 大小目前為 1.9GB，團隊正在努力在未來的版本中進一步減少它。

你可以在 這篇文章中 閲讀更多關於 Xubuntu 最小化 ISO 的信息。

Flathub 和 Snap ​

幾周前，Canonical 宣佈已決定從所有 Ubuntu 官方風味版中默認刪除 Flatpak 支持。因此，在 Xubuntu 23.04 中，你將不會默認安裝 Flatpak。

Ubuntu 自己的 Snap 將默認安裝所有相關組件，以運行幾個 Snap 應用程序，如 Firefox。

但是，在 Xubuntu 中設置 Flatpak 和 Flathub 非常容易，只需要兩個命令。

其他變化和總結 ​

在核心方面，Xubuntu 23.04 基於 Linux 內核 6.2 主線版本，它帶來了對領先製造商的最新 CPU/GPU 產品的支持。此外，這個內核版本還引入了內存優化、安全修復和許多附件支持。

應用程序棧和 GNOME 組件的更新如下：

  • Firefox 111.0（Snap）
  • Thunderbird 102.9
  • Thunar 4.18.4
  • Parole media player 4.18
  • LibreOffice 7.5
  • GNOME Software 44.0
  • Catfish file search 4.16.4
  • Transmission 3.0

在核心部分，Python 3.11 現在可以在 Xubuntu 23.04 中開箱即用。你不需要再單獨 安裝 Python 3.11 了。值得一提的是，Python 3.12版本將在今年發佈，目前正在進行多個 RC 測試。下面是這個版本中核心模組的總結：

  • Python 3.11
  • GCC 13
  • GlibC 2.37
  • Ruby 3.1
  • golang 1.2
  • LLVM 16

總結 ​

總之，Xubuntu 23.04 是一個重要的版本，具有 Xfce 4.18 桌面環境的若干改進和功能。由於專注於提高用户體驗，Xubuntu 用户可以享受到最新的 Linux 內核、改進後的 Thunar 文件管理器以及其他一些調整和變化。

這將是 Xubuntu 對每個人來説最好的版本之一。
