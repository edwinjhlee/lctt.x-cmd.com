Linux Mint 的發行週期 ​

你可能知道，Linux Mint 是一個基於 Ubuntu 的發行版。

Ubuntu 每六個月發佈一個新版本，但 Linux Mint 並不遵循六個月一次的發行模式。

Linux Mint 以 Ubuntu LTS（長期支持long term support）版本作為其基礎。Ubuntu 的 LTS 版本每兩年發佈一次，所以 你也會每兩年得到一個 Mint 的大版本更新（比如 Mint 19, 20, 21 等）。

與 Ubuntu LTS 版本一樣，Linux Mint 的大版本也被支持五年。雖然在這期間有三個小更新版本（比如 Mint 20.1、20.2、20.3）。

與 Ubuntu 相比，多久能得到一次 Linux Mint 的升級？你應該在什麼時候等待 Linux Mint 的升級？當有新版本的時候，你應該升級到新版本嗎？

在這裏，讓我重點介紹一下這些 Linux Mint 的發行週期的重要細節。

Linux Mint 的發行週期 ​

Ubuntu 每兩年發佈一個長期支持版本。之後很快就會有一個 Mint 版本出現。換句話説，你每兩年就會得到一個新的 Mint 版本。

所以，Linux Mint 20 是在 2020 年基於 Ubuntu 20.04 發行的，Mint 21 是在 2022 年基於 Ubuntu 22.04 發行的。

與 Ubuntu 不同，Mint 沒有嚴格的發行時間表。沒有事先確定的發行日期。新版本在其開發者認為準備好的時候就會到來。

小版本 ​

在 Mint 的兩個大版本發佈之間，有三個小版本，每隔 6 個月發佈一次。

即 Mint 20（即 20.0）是在 2020 年 6 月發佈的。Mint 20.1 在 2020 年 12 月，Mint 20.2 在 2021 年 6 月，Mint 20.3 在 2021 年 12 月。在這之後，Mint 團隊將致力於開發下一個大版本。

這些小版本會更新什麼？比如，一個新版本的桌面環境，主要包含用户圖形界面的視覺變化。它有時也可能提供新的應用程序。

升級到小版本是可選的。你可以選擇繼續使用 20.1，而不升級到 20.2 和 20.3。這是那些不喜歡頻繁（在圖形界面上）改變他們系統的人的首選。

在最後一個消版本發佈（XX.03）之後，你的系統將只得到已安裝軟件的安全和維護更新。你不會得到桌面環境和其他一些軟件（如 GIMP 或 LibreOffice）的新的大版本更新。

支持週期 ​

並非所有基於 Ubuntu 的發行版都能為你提供與 Canonical 的 Ubuntu 相同的週期性更新優勢。許多基於 Ubuntu 的發行版和 官方的衍生版本 提供了最長 3 年的支持。

幸運的是，對於 Linux Mint 來説，你可以得到和 Ubuntu 一樣的更新福利。

每個 Linux Mint 版本的支持期為 5 年，在此之後，你必須升級到下一個版本，或者重新安裝較新的版本。

例如，Mint 20 是在 2020 年發佈的，比 Ubuntu 20.04 晚幾個月。Ubuntu 20.04 LTS 被支持到 2025 年，因此 Mint 20 系列也被支持到 2025 年。

一個系列的所有小版本都支持到同一日期。Mint 20.1、20.2 和 20.3 都將被支持到 2025 年。

同樣地，Ubuntu 22.04 LTS 將被支持到 2027 年 4 月。你可以期待 Linux Mint 21 系列（它基於 Ubuntu 22.04）的更新週期到相同的時間線。

總結一下：

  • 你每兩年得到一個新的 Linux Mint 大版本
  • 每個大版本的支持週期為 5 年
  • 每個大版本（XX 版）在下一個大版本之前都會有三個小版本（XX.1、XX.2、XX.3）
  • 小版本（XX.1，XX.2，XX.3）與大版本（XX）的支持時間相同

你什麼時候應該升級 Linux Mint？ ​

這完全取決於你，

每兩年會有一個新的大版本。你可以選擇在那時升級它，或者你可以在整個五年的生命週期內保持你目前的版本。

除非你想獲得最新的功能和改進，你可以選擇不把你的 Linux Mint 安裝升級到另一個大版本。

對於小版本，你可以選擇更新，也可以不更新。比如，20 到 20.1 或 20.1 到 20.2。即使你不使用最新的小版本，你仍然會得到重要的安全和維護更新。

你可以參考我們的 Linux Mint 升級指南 以尋求幫助。

Linux Mint 的版本劃分和命名 ​

與 Ubuntu 發行版不同，Linux Mint 有一個不同的編號方案。Linux Mint 喜歡在每一個 Ubuntu LTS 版本中提升編號。

換句話説:

Linux Mint 19 → Ubuntu 18.04 LTS

Linux Mint 20 → Ubuntu 20.04 LTS

Linux Mint 21 → Ubuntu 22.04 LTS

所以，你應該避開以下的混淆：

Linux Mint 20 基於 Ubuntu 20.04 並不意味着 Linux Mint 21 將基於 Ubuntu 21.04。

此外，每個版本都有三個小版本，帶有內核的小更新和一些 Linux Mint 應用程序的潛在升級。

現在，來看看它的命名方案：

每個 Linux Mint 版本，無論是小的還是大的，都有一個代號。通常，它是一個女性的名字，通常源自希臘或拉丁語。

和 Ubuntu 一樣，代號也有一個模式。大版本的代號是按字母順序遞增的。當涉及到小版本時，你會發現新的名字會以相同的字母開頭。

例如，Mint 20 被稱為 Ulyana，20.1 為 Ulyssa，20.2 為 Uma，而 20.3 為 Una。同樣地，Mint 19 系列的代號以 T 開頭。

在寫這篇文章的時候，Mint 21（最新版本）的代號以 V 開頭，21 系列的第一個版本叫 Vanessa。

在 Mint 21 系列中至少還會有三個小版本，它們將每六個月發佈一次，直到 2024 年的下一個 Mint 大版本。而它們都將有一個以字母 V 開頭的代號。

薄荷留香 ​
