開源領域中姐妹情誼和盟友關係的力量 ​

“站在巨人的肩膀上”不僅是指開源，而且是指通過承認女性先驅和領導者在該領域的作用，在技術中建立姐妹情誼的基礎。

兩年多前，我從藝術家轉職成為一名 軟件開發人員。我不是單憑一己之力做到的。 我得到了 PyLadies Berlin 的支持，PyLadies Berlin 是一個國際志願者團體的柏林本地分會，旨在支持女性從事技術工作。

我們習慣了“職業變化”這個詞，就好像它是一個軌跡的中斷。但根據我的經驗，事實並非如此。一個人無法抹去自己過去的點點滴滴，而多樣化背景帶來的豐富性可以造就爆發點。個體的人生旅程雖然通常與計算機科學毫無相關，卻擔起了令科技對社會有所影響的職責，併為技術行業帶來豐富性和創造力。

作為一名藝術家，我得到了自由，並打開了探索從建築到科學等多個領域的大門。我大部分的藝術經歷發生在巴西的黑客空間裏，這裏充斥着自由及開源軟件Free/Libre Open Source Software（FLOSS）的思想，即開放的自由共享文化。如今，由於一些不屬於本文討論範圍的意識形態和實踐原因，最常見的術語是“開源”。對我來説幸運的是，我的職業轉變始於一次在 開源項目辦公室Open Source Program Office（OSPO）的實習，它讓我的轉變經歷感覺——幾乎可以説——像回家一樣。

放在巨人的肩膀上 ​

我們都受益於開源。無論你是否編碼，你所使用的軟件都依賴於它。由於這是一種開放的文化，一切都建立在他人的工作之上，所以經常聽到“站在巨人的肩膀上”這個表述，指的是我們的進步都建立在前人的工作和貢獻之上。 這突出了從他人的經驗和成就中學習的重要性。

這篇文章旨在揭示我站在誰的肩膀上。這不僅是為了表達我對他們的感激之情，也是為了回答我在接受 JSParty 的 Kevin Ball 和 Christopher Hiller 採訪時被問到的一個問題：你能做些什麼來改善周圍環境的多樣性？

“站在巨人的肩膀上”不僅是指開源，而且是指通過承認女性先驅和領導者在該領域的作用，在技術中建立姐妹情誼的基礎。通過承認在我們之前的女性所做的貢獻，我們可以從她們所面臨的挑戰中獲得靈感和洞察力，並從她們掙脱束縛的經驗中學習。通過這種方式，我們“站在巨人的肩膀上”，以她們的工作為基礎，為女性和 被低估的 技術人員創造更具包容性和支持性的環境。

通過相互支持，認識到從他人經驗中學習的重要性，並形成一個支持網絡，我們可以共同努力克服挑戰，通過創造更公平的環境，為所有人建設更美好的未來。通過這樣做，我們正在創造新的巨人，供其他人在未來立足。

組織一個當地社區: Meili Triantafyllidi 和 Jessica Greene ​

我加入了 PyLadies Berlin，它由 Meili 於 2013 年創立。Jessica 是組織者之一，她是 Ecosia 的一名初級軟件工程師。成為社區組織者意味着利用你個人的空閒時間和熱情，盡力創建一個安全的、支持性的網絡和學習空間。這些工作包括尋找舉辦地點、宣傳活動、策劃主題、尋找演講者，最重要的是，傾聽社區的需求。

作為多元文化城市的新人並試圖在城市中找到自己的位置，我感到 PyLadies 與其説是一個學習 Python 的地方，不如説是一個讓我感受到被歡迎和被理解的中心。

根據我們常常聽到的敍述，科技領域是每個人都在前往的新希望之地，有無限的崗位需求、切換國家的自由和高薪的職業。其他行業沒有提供這種服務，或者至少沒有達到這種規模。專注於帶來多樣性空間的社區提供了使這對每個人都成為現實的可能性。

每個活動都以社區公告、包含議程的簡單幻燈片以及類似活動的宣傳開始。當時我聽聞的兩個活動引導我走上了我的職業道路：Rail Girls Summer of Code 計劃和 FrauenLoop。因為感覺有必要回饋當初給予了我支持的社區，我成為了共同組織者之一。

搭建人際關係網和學習專業知識: FrauenLoop ​

FrauenLoop 由 Nakeema Stefflbauer 博士於 2016 年創立，致力於改變歐盟科技公司的面貌。該項目分為 3 個月的週期，由每週的晚間課程和週末研討會組成，以培訓在科技行業裏沒有人際關係網的女性。

學習課程是圍繞女性的專業需求開發的，從以技術行業為重點的課程到女性舉辦的關於科技行業如何真正運作以及如何成功立足的研討會。一些常見的話題包括薪資談判和練習技術面試。最近，為了應對裁員，柏林技術工人聯盟舉辦了一場研討會，揭開如何對公司解僱流程提出質疑的神秘面紗。

研討會聚焦於女性，尤其是移民羣體，她們正處於家庭狀況和職業轉變的階段，真正準備好去尋找工作了。

和 Nakeema 在一起本身就給我帶來了靈感。該項目提供了理解編程和學習網頁開發基礎知識的起點。但最重要的是，你與項目中的其他人建立了聯繫，他們是 PyLadies 未來的共同組織者、演講者、業餘項目的導師和朋友。

FrauenLoop 還為其學生提供了回去擔任導師的機會。對我來説，這是決定我前進道路的轉折點。做了一年多的導師，增強了我對自己的信心，也鞏固了我自己的學習。受到幫助他人學習這一責任的挑戰，你不可避免要一直學習。

在那裏我遇到了 Victoria Hodder，她是我申請 Rail Girls Summer of Code 時的搭檔。

多元化項目：從 Rail Girls Summer of Code 到 Ecosia Summer of Code ​

Rail Girls Summer of Code 是一項面向女性和非二元性別程序員的全球獎學金計劃，入選的申請者將獲得為期三個月的獎學金，以從事現有的開源項目。該計劃活躍於 2013 年到 2020 年。

申請以一個團隊為單位進行提交，即來自同一個城市的兩個人。雖然這是一個遠程項目，但有一個本地同行確保了問責制和相互支持。

除了同伴，項目還需要有一個辦公的地方，一個適合工作三個月的環境。這個地方可以是你的家、聯合辦公空間、工作辦公室，或者最好的情況下是培訓公司。雖然培訓公司除了提供工作空間外沒有其他義務，但它讓我們與當地公司聯繫起來，併為我們提供了一個空間，讓我們能夠與我們想進入的行業內的人建立知名度和關係網。

我在 PyLadies Berlin 的聯合組織者 Jessica 通過該項目開啓了她在科技領域的職業生涯。她提議 Ecosia（她當時也是現在所任職的公司）擔任兩個團隊的指導工作，其中一個是我和 Victoria 的團隊（我們專注於網絡開發），另一個是 Taciana Cruz 和 Karina Cordeiro 的團隊（他們專注於數據）。

在三個月的申請期內，大流行來勢洶洶。在參與 if-me 項目後，我和維多利亞被 某種程度上 選入了 the Rail Girls 項目。因為是 某種程度上 被選中的，我們與 Rail Girls 的溝通在選拔後期變得非常混亂，最終他們在最後一刻取消了項目。

我們當時都崩潰了。大流行的重壓給我們帶來了沉重打擊，它不僅粉碎了我們獲得一份有償工作的機會，而且粉碎了長期以來養成的開始新職業的夢想。

當時還是初級軟件開發人員的 Jessica懂我們的處境，因此她挺身而出，她沒有感到無能為力，而是站出來表明自己的立場。除了為適應個人新角色所付出的努力，她還給自己安排了更多工作，並創建了 Ecosia Summer of Code 這一項目。

Ecosia 無法支付獎學金，但 Jessica 開發了一個導師計劃。該計劃利用公司的可用資源，提供高素質專業人士的指導，以填補我們的知識空白。由於 Victoria 和 Karina 因為需要有報酬的工作而放棄了項目，Taciana 和我設法繼續進行個人項目。我們找到了可以一起努力並相互支持的共同主題。

大約一年後，其中一位導師 Jakiub Fialla 邀請我去她的公司聊聊開源。我與其他一些人依然保持着聯繫，時不時地，當他們舉辦 PyLadies Berlin 活動時，我會順便過去見見他們。如此甜蜜。

贊助多樣性: Coyotiv 項目和它的創始人 Armagan Amcalar ​

當 Rail Girls 項目被取消時，我在 Instagram 上看到一篇關於訓練營的帖子，該訓練營提供全棧網絡開發計劃獎學金。

申請流程很簡單，所以我就申請了。我很快收到了一份自發的面試邀請。當時的我感到沮喪、凌亂又絕望，沒有任何準備就參加了面試，所以我全程非常誠實。整個面試的談話同樣坦誠，對此我深表感激。

面試官是 Coyotiv 軟件工程學院 的創始人 Armagan Amcalar。具有音樂背景的Armagan 富有創造力，對周圍的世界有着批判性的思考。這所學校是在他為柏林的 Women Techmakers 提供免費速成課程三年後創辦的。他沒有死記硬背多樣性演講，而是根據它採取行動，為所有全職參與者提供獎學金。

我獲得了獎學金，並與其他四個人（其中 3 名女性）一起組成了第一批學生。訓練營持續了高強度的 17 周。它對改變我對代碼的看法極為重要。與我嘗試學習的其他地方不同，Armagan 並不關心我們選擇什麼編程框架。相反，這一切都是為了理解我們在做什麼，並將軟件工程視為一種創造性的、強大的工具來塑造我們生活的世界。我得到的不僅僅是獎學金，我還收穫了一個朋友和終身導師，他為我提供華麗轉身的機會，打開了一扇通往美好生活的大門。

你是不是覺得我的反應太誇張了？你可以問問我身邊的人。我的搭檔此時已經認識我大約 14 年了，他是這樣評價我的變化的：我變得紀律嚴明，充滿活力，一路走來我對學到的東西感到高興，就軟件及其相關的事物進行深入對話，不再困惑矛盾，我放棄了終生的藝術事業，轉而找到了人生的目標。由於我的變化實在驚人，他參加了我後面的幾屆訓練營項目。

學校為我提供了技術知識、面試培訓、簡歷支持和公開演講培訓。畢業不僅僅要求開發個人的全棧項目，還必須通過在 npm 上發佈一個庫來回饋開源，因為有如此多的軟件是基於開源構建的。Node 包管理器（npm）是一個 JavaScript 包存儲庫，允許你通過在基於 Javascript 的項目中輕鬆安裝代碼來重用代碼。儘管我參與自由軟件運動和開源已經十多年了，但我從沒想過我可以用實際代碼回饋它。

我的貢獻 ​

彩虹企鵝 就這樣誕生了。它是一個 npm 庫，可以在開發人員敲代碼時發送激勵信息。 也許它不是一個非常實用的工具。但對我來説它依然是個必要的工具，這基於我個人的經歷——我經歷過學習編碼的挫折，為 if-me 項目做出貢獻，而且從其他學習者那裏聽到了許多類似的故事。

通過我在這些編程社區的經歷，我瞭解到編程遠不止一行行的代碼，擁有盟友是多麼強大和有必要。無論你是誰或你自認為了解什麼，自由和開源軟件社區中都有機會。你的參與不一定要是大動作，因為盟友們的小小貢獻加起來遠大於一個人貢獻的總和。邁出第一步。在開源領域中找到你的盟友。
