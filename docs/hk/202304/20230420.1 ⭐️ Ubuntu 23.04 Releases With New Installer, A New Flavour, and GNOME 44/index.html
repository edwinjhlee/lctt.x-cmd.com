Ubuntu 23.04 發佈：新安裝程序、新風味版和 GNOME 44 ​

Ubuntu 23.04 增加了 GNOME 44 的魔力，並有一些自己的調整和改進。請看下文。

每年的這個時候，都會有新的 Ubuntu 版本發佈：Ubuntu 23.04 來了。

然而，這並不是一個 長期支持版本。所以，代號為 月球龍蝦Lunar Lobster 的 Ubuntu 23.04 並不適合所有人。

如果你想要最新和最棒的發行版，並且不介意在一年內再次升級你的系統，那麼這個版本適合你。而如果你想在幾年內堅持使用一個版本，你應該繼續使用 Ubuntu 20.04 LTS 或 Ubuntu 22.04 LTS。

現在，繼續説説 Ubuntu 23.04 的亮點：

💡 Ubuntu 23.04 將被支持 九個月，直到 2024 年 1 月。如果你想在其壽命結束後得到一個最新的安全系統，你可以升級到 Ubuntu 23.10（即將推出的版本）。

⭐ Ubuntu 23.04：有什麼新內容？ ​

該版本最重要的改進包括以下內容：

  • 新的現代化安裝程序
  • Steam Snap 晉升為穩定版
  • GNOME 44
  • 文件管理器的改進
  • Linux 內核 6.2
  • 傳統和最小化 ISO
  • 新的 Cinnamon 風味版

📋 這 不是 一個 長期支持 版本。因此，對於大多數人來説，你不需要升級。只有當你想要最新的和最棒的 Linux 發行版，同時願意在一年內再次升級的時候，它才是你要的。

基於 Flutter 的默認安裝程序 ​

Canonical 一直在開發一個由 Subiquity 支持的現代化的安裝程序，它的外觀感覺看起來不錯。

這個安裝程序被打包成了一個 Snap 包，而最小化的安裝方式在這個新改造下也變得更快。

這個新的安裝程序還旨在向新用户提供有意義的信息，同時改善用户體驗。一些幻燈片、動畫和加載屏幕將看起來完全不同。

總體而言，安裝體驗應該更快、更直觀。

Steam Snap 現已晉升為穩定版 ​

上個月，我們 報道 了 Canonical 正在尋找用户來測試 Ubuntu 的 Steam Snap 應用。

隨着 Ubuntu 23.04 的到來，等待已經結束了！Steam Snap 應用現在被推廣到了穩定頻道。

所以，現在你可以在 Steam 新 Snap 應用的幫助下無憂無慮地運行新老遊戲了。雖然這是為 Ubuntu 量身定做的，但你也可以用其他任何發行版來嘗試，通過 Steam 改善你的遊戲體驗。

你可以查看我們的 Linux 遊戲指南 以獲得進一步的幫助。

GNOME 44 ​

GNOME 44，從其核心上分為你帶來了一些根本變化，比如一個具有新能力的、更加互動的快速菜單。

比如説：

  • 快速藍牙切換可以查看/管理設備，而無需進入設置頁面
  • 監控後台應用程序

當然，Canonical 調整了原本的 GNOME 44 體驗，不像你在 Fedora 38 中發現的那樣原汁原味。但是你可以在這裏探索 GNOME 44 的詳細變化：

7 個值得關注的 GNOME 44 功能

傳統的和最小化 ISO ​

Ubuntu 將首次單獨提供一個最小化 ISO，它需要互聯網連接才能在機器上成功安裝 Ubuntu 23.04。

還有一個傳統的 ISO 提供了舊的安裝程序，供那些適應它的用户使用。

新的 Cinnamon 風味版和 Edubuntu 的復活 ​

當然，每一個 Ubuntu 風味版都會隨着新的 23.04 版本的發佈而得到升級。

Cinnamon 風味版是隨着這個版本的發佈而新增加的。因此，如果你喜歡使用 Cinnamon 桌面而不是 GNOME，你可以下載 Ubuntu Cinnamon 風味版。

此外，以前的 Ubuntu 的一個官方版本，Edubuntu，現在已經復活了。

你可以在 Ubuntu 的網站 上找到列出的官方風味版。

文件管理器的改進 ​

作為 GNOME 44 改進的一部分，文件管理器（Nautilus）已經得到了改進。

你可以期待更好的性能和打開可展開文件夾的能力（是的，這個功能在 Ubuntu 22.10 中被放棄後又回來了）。

Linux 內核 6.2 ​

為了幫助你跟上最新的硬件兼容性和改進，Ubuntu 23.04 配備了 Linux 內核 6.2。

這個內核版本增加了對英特爾 Arc 圖形卡的全面支持、Nouveau 驅動更新，以及其他增強功能。

🛠️ 其他變化 ​

此外，一些細微的變化可以提升 Ubuntu 的體驗。其中一些包括以下內容：

  • 在軟件中心搜索 Snap 時支持分類
  • Ubuntu 字體更新
  • Telegram 應用程序以 Snap 提供，不再有 Deb 包
  • 固件更新器作為一個單獨的應用程序加入到 Snap 商店中
  • PostgreSQL 15、Rclone 1.60.1、NetworkManager 1.42、Ruby 3.1
  • Qemu v7.2.0，支持 RISC-V
  • 更新的應用程序： Firefox 111、LibreOffice 7.5.2、Thunderbird 102.9

你可以參考 官方發佈説明，瞭解更多關於 Ubuntu 服務器和物聯網版變化的細節。

📥 下載 Ubuntu 23.04 ​

前往 官方網站 獲取最新的 ISO，或者使用 Ubuntu 鏡像庫 來獲取它。
