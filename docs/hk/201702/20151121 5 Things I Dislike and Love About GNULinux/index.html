GNU/Linux，愛憎由之 ​

首先，我能確定本文提及的內容一定會造成激烈的辯論，從之前那篇 我討厭 GNU/Linux 的五個理由 – 你呢，愛還是恨？ 的頁底評論區就可見一斑。

也因此，我在此沒有使用恨 (hate) 這個詞，那會讓我感覺很不舒服，所以我覺得用不喜歡 (dislike) 來代替更合適。

關於 Linux，我所不喜歡的 5 件事。

也就是説，請讀者記住，文中的觀點完完全全出於我個人和自身的經歷，而這些想法和經歷可能會和他人的相似，也可能相去甚遠。

此外，我也意識到，這些所謂的不喜歡（dislike）是與經驗相關的，Linux 就是這個樣子。然而，但正是這些事實阻礙了新用户做出遷移系統的決定。

像從前一樣，隨時留下評論並展開討論，或者提出任何其他符合本文主題的觀點。

不喜歡理由之一：從 Windows 遷移到 Linux 對用户來説是個陡峭的學習曲線 ​

如果説使用 Windows 已經成為了你生活中不可缺少的一個部分，那麼你在 Linux 電腦上安裝一個新軟件之前，還必須要習慣和理解諸如遠程倉庫（repository）、依賴關係（dependency）、包（package）和包管理器（package manager）等概念。

不久你也會發現，僅僅使用鼠標點擊一個可執行程序是很難完成某個程序的安裝的。或者由於一些原因，你沒有可用的網絡，那麼安裝一個你想要的軟件會是一件非常累人的任務。

不喜歡理由之二：獨立學習使用仍存在困難 ​

類似理由一，事實上，最開始獨立學習 Linux 知識的時候，很多人都會覺得那是一個巨大挑戰。儘管網上有數以千萬計的教程和 大量的好書，但初學者也會因此煩了選擇困難症，不知從何開始學習。

此外，數不清的社區 (比如：linuxsay.com) 論壇中都有大量的有經驗用户為大家無償提供（通常都是這樣的）解答，但不幸的是，這些問題的解答並不完全可信、或者與新用户的經驗和知識層面不匹配，導致用户無法理解。

事實上，因為有太多的發行版系列及其衍生版本可以獲取，這使得我們有必要向第三方機構付費，讓他們指引我們走向 Linux 世界的第一步、瞭解這些發行版系列之間的相同點以及區別。

不喜歡理由之三：新老系統/軟件遷移問題 ​

一旦你下定決心開始使用 Linux，那麼無論是在家裏或是辦公室，也無論是個人版或者企業級，你都要完全從舊系統向新系統遷移，然後要考慮這些年來你所使用的軟件在 Linux 平台上的替代產品。

而這確實令人矛盾不已，特別是要面對相同類型（比如文本處理器、關係型資料庫系統、圖形套件等) 的多個不同程序，而又沒有受過專業指導和訓練，那麼很多人都下定不了決心要使用哪個好。

除非有可敬的有經驗用户或者教學視頻進行指導，否則存在太多的軟件實例給用户進行選擇，真的會讓人走進誤區。

不喜歡理由之四：缺乏硬件廠商的驅動支持 ​

恐怕沒有人能否認這樣的事實，Linux 走過了漫長的歷史，它的第一個內核版本公佈已經有 20 多年了（LCTT 譯註：準確説是將近 26 年了，1991.10.05 - 2017.02，相信現今很多我們這些 Linux 用户在第一個內核版本公佈的時候都還沒出生，包括譯者在內）。隨着越來越多的設備驅動編譯進每次發佈的穩定內核中、越來越多的廠商開始支持研究和開發兼容 Linux 的設備驅動，Linux 用户們不再會經常遇到設備運行不正常的情況了，但還是會偶爾遭遇的。

並且，如果你的個人計算或者公司業務需要一個特殊設備，但恰巧又沒有現成的 Linux 驅動，你還得困在 Windows 或者其他有驅動支持的其他系統。

儘管你經常這樣提醒自己：“閉源軟件真他媽邪惡！”，但事實上的確有閉源軟件，並且不幸的是，出於商業需求我們多數情況還是被迫使用它。

不喜歡理由之五：Linux 的主要力量仍在於服務器 ​

這麼説吧，我加入 Linux 陣營的主要原因是多年前它將一台老電腦生機煥發並能夠正常使用讓我看到了它的前景。花費了一段時間來解決不喜歡理由之一、之二中遇到的那些問題，並且成功使用一台 566 MHz 賽揚處理器、10 GB IDE 硬盤以及僅有 256 MB 內存的機器搭載 Debian Squeeze 建立起一個家庭文件/打印/ Web 服務於一體的服務器之後，我非常開心。

當我發現即便是處於高負載的情況，htop 顯示 系統資源消耗才勉強到達一半，這令非常我驚喜。

你可能已經不停在再問自己，文中明明説的是不喜歡 Linux，為什麼還提這些事呢？答案很簡單，我是需要一個比較好的 Linux 桌面發行版來運行在一台相對老舊的電腦上。當然我並不指望能夠有那麼一個發行版可以運行上述提到那種硬件特徵的電腦上，但我的確沒有發現有任何一款外觀漂亮的可定製桌面系統能運行在 1 GB 內存以下的電腦中，如果可以，其速度大概比鼻涕蟲還慢吧。

我想在此重申一下：我是説“我沒發現”，而非“不存在”。可能某天我會發現一個較好的 Linux 桌面發行版能夠用在我房間裏那台壽終正寢的筆記本上。如果那天真的到來，我將首先刪除這篇文章，並向它豎起大拇指。

總而言之 ​

在本文中，我也嘗試了提及 Linux 在某些地方仍需不斷改進。我是一名幸福的 Linux 用户，並由衷地感謝那些傑出的社區不斷為 Linux 系統、組件和其他功能做出貢獻。我想重複一下我在本文開頭説的 —— 這些明顯的不足點，如果從適當的角度去看也是一種優勢，或者也快了吧。

在那到來之前，讓我們相互支持，一起學習並幫助 Linux 成長和傳播。隨時在下方留下你的評論和問題 —— 我們期待你不同的觀點。
