如何在 Ubuntu 上使用 ADB 備份 Android 數據 ​

備份 Android 系統上的應用數據、文本信息等等是非常乏味的，有時還很昂貴。電子市場的許多應用都承諾可以備份數據，但效果不佳或者需要付昂貴費用。你是否知道有一種更好的方法可以來做這件事，並且在你的電腦上就可以完成？

Android 自帶一套開發工具。有許多種開發工具，但人們最為感興趣的項目是 ADB（或者叫做 Android 調試橋 Android Debug Bridge）。它允許用户通過命令列直接訪問任何 Android 設備。有了這個工具，一切皆有可能 - 包括備份整個 Android 設備。在這篇文章中，將討論如何在 Ubuntu 系統上完成這件事。

注：這篇教程是針對 Ubuntu Linux 系統的。不過， ADB 在 Windows 系統和 Mac 上也是可用的，也可以在這些平台上對 Android 數據進行備份。下載針對 Windows 和 Mac 的 ADB 版本。

安裝 ADB 並啓用 USB 調試 ​

打開一個終端窗口，然後輸入下面的命令來安裝 ADB，它將與 Android 進行會話。

sudo apt install adb

在系統上安裝好 ADB 工具以後，需要在 Android 內部啓動調試。首先打開 Android 的設置Settings區域。然後一直滾動到底部找到“關於手機About Phone”並點擊。這將打開“電話狀態Phone status”頁。在這一頁面上再次滾動到底部，找到“版本號Build number”並點擊七次，從而啓動開發者模式。

為了進入開發者設置Developer Settings，按設備上的返回鍵返回上一頁面。在“設置”中將會出現一個新的選項：“開發者選項Developer options”。點擊它進入開發者設置區域。滾動頁面直到看到 “Android 調試Android debugging”（或它的一些其他名稱），點擊它啓用設置。

備份 ​

使用 ADB 創建一個備份就如同運行一個命令一樣簡單。首先，用一根與 Android 設備匹配的 USB 線將 Android 設備連接到電腦上。然後打開終端運行下面的命令：

adb start-server

這將啓動 ADB 服務器。運行這個命令時，要快速解鎖 Android 設備，因為 ADB 將強制出現一個確認窗口，必須選擇接受後才可繼續。

要啓動備份進程，打開終端，然後執行下面的備份命令。該命令將讀取 Android 上的文本信息以及其他應用數據，然後存入加密文件中。

adb backup -apk -shared -all -f backup-file.adb

當運行備份命令時，Android 會在啓動備份進程前提示用户查看 Android 並設置加密文件的密碼。請輸入一個強壯而容易記住的密碼。然後，點擊“備份我的數據”按鈕。備份過程將會花費一定時間。備份完成以後，在目錄 /home/username/ 中會出現一個叫做 backup-file.adb 的文件。

恢復備份 ​

要恢復備份，首先啓用 ADB 服務器（像上面提到的一樣），然後運行下面這個命令來還原備份數據：

adb restore backup-file.adb

再次轉到 Android， 因為 ADB 將提示用户輸入密碼。這次，不是創建一個密碼，而是需要輸入之前創建的那個密碼。在點擊 “恢復我的數據restore my data” 以後，恢復進程就開始了。耐心點，因為這可能需要一定時間。

結論 ​

沒有多少 Android 用户知道這樣備份數據，但是 ADB 的確很強大。利用它甚至可以獲得對設備的 root 訪問。事實上，利用這個工具還可以做很多的事情，需要更多的文章來討論它。
