加速老舊 Ubuntu 系統的技巧 ​

你的 Ubuntu 系統可以運行得如此順暢，以至於你會奇怪為什麼沒有早一些從那些桌面加載很慢的操作系統（比如 Windows）轉過來。Ubuntu 在大多數現代化的機器上都能夠很順暢的運行，一些更老的機器使用 Ubuntu 系統的一些變種版本，比如 Lubuntu、Xubuntu 和 Ubuntu MATE，同樣給人留下了深刻印象。極少的情況下，你對 Ubuntu 桌面的使用體驗會越來越糟。如果非常不走運，你的 Ubuntu 系統並沒有像你所希望的那樣運行順暢，那麼你可以做一些事情來提高系統性能和響應速度。

不過首先我們來看一看為什麼電腦會運行得很慢？下面是我列舉的一些原因：

  1. 電腦陳舊
  2. 安裝了太多的應用
  3. 系統裏的一些東西壞了
  4. 還有更多的原因...

現在讓我們來看一些改善這個問題的技巧。

1、 交換值Swappiness ​

如果你的系統有一個交換分區，那麼這個技巧對你是最適合的（注：交換分區不建議為固態驅動器，因為這樣會縮短驅動器的使用壽命）。交換分區可以幫助系統，特別是內存容量較低的系統，來管理系統內存。將數據寫入交換分區（硬盤）比寫入內存要慢一些，所以你可以通過減少 swappiness 值來限制數據寫入交換分區的頻率。默認情況下， Ubuntu 的 swappiness 值是 60%， 所以你可以通過下面的命令將它減至 10%：

sudo bash -c "echo 'vm.swappiness = 10' >> /etc/sysctl.conf"

2、 停止索引 ​

索引的目的是加快搜索結果，但另一方面，索引會導致較老配置的系統出現一些問題。為了停止索引，輸入下面的命令來移除索引工具：

sudo apt-get purge apt-xapian-index

3、 管理啓動應用startup applications ​

啓動應用會對系統性能造成很大的影響。當你安裝一些應用以後，這些應用會添加啓動項，從而當你啓動系統的時候它們也跟着啓動，但你可以移除這些應用以提高系統性能。通過在 Unity 窗口搜索打開 “啓動應用”。絕大多數自啓動選項都會被隱藏，所以在終端輸入下面的命令使它們可見然後你就可以停止某些 “啓動應用”了：

sudo sed -i "s/NoDisplay=true/NoDisplay=false/g" /etc/xdg/autostart/\*.desktop

4、 嘗試預載入 ​

預載入（preload） 是一個守護進程/後台服務，它可以監控系統上使用的應用程序，它會將所需要的二進制庫在其需要加載到內存前就預先載入，以便應用程序啓動得更快。在終端輸入下面的命令安裝預載入：

sudo apt-get install preload

5、 選擇更加輕量型的應用 ​

你在 Ubuntu 桌面上使用什麼應用程序呢？有更輕量的替代品嗎？如果有，就替換成它們——如果它們也能滿足你的需求的話。 LibreOffice 能夠給你最好的辦公體驗，但是它的替代品，比如 Abiword 能夠很大程度的改善系統性能。

6、 切換到一個更加輕量型的桌面環境 ​

你在 Ubuntu 系統上使用的桌面環境是 Unity 或 KDE 嗎？這些桌面環境對系統的要求很高。相反，你可以在當前桌面環境之外同時安裝一個 LxQt 或者 XFCE 環境，然後切換到它們。或者，你也可以換到 Ubuntu 的不同變種版本，比如 Lubuntu 或 Xubuntu ，從而享受更快的體驗。

7、 清理系統垃圾 ​

儘管 Ubuntu 系統不會變得像 Windows 系統那麼慢，但它還是會變慢。清除系統裏不需要的文件可以改善系統性能。嘗試使用 Ubuntu Tweak 工具中的 Janitor 工具來清理系統。還有一個 Bleachbit 工具也可用來清理系統。

同時請閲讀 - Bleachbit - CCleaner 的一個替代品

8、 嘗試重新安裝 ​

有時，一些東西可能壞了，清理垃圾或者使用上面提到的大多數技巧都沒用。這時，你唯一的選擇就是備份文件，然後嘗試重新安裝。

9、 升級硬件 ​

我列表上的最後一個技巧是升級硬件。在絕大多數情況下，這是可以的。如果可以這樣做，那將極大的提高系統性能。你可以增加已安裝的內存， 從傳統磁盤切換到固態驅動器或者升級你的處理器，特別是如果你在台式電腦上運行 Ubuntu 系統，這將極大提高系統性能。

結論 ​

我希望這些技巧能夠陪伴你走很長的一段路，讓你的 Ubuntu 桌面以一個令人印象深刻的速度運行。注意，你不需要嘗試所有的技巧，只需要找到一個適合你的情況的技巧，然後觀察系統響應如何變化。你還知道其他提高 Ubuntu 系統性能的技巧嗎？請在評論裏分享給我們。
