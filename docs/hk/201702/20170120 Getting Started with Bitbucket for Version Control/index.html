Bitbucket 版本控制入門指南 ​

在互聯網成為一個巨大的、世界性的現象之前，開發團隊常常被限制在一個小的物理空間內。如果公司沒有資金支持的話，與世界另一方的人合作是一個非常昂貴或幾乎不可能的夢想。

幸運的是，情況不再是這樣了。互聯網誕生了基於網絡的解決方案，允許公司組成合作團體，包括彼此相距數千英里的人。

自從 2008 年首次推出以來，Bitbucket 已成為使用 Mercurial 或 Git 版本控制系統（VCS）的開發人員團隊中越來越受歡迎的選擇。

它既提供免費帳户，帶有不限數量的私人存儲庫（每個賬户最多 5 個用户），也提供多種付費計劃，允許每個帳户有更多用户。此外，標記為“公開”的倉庫對可以編輯或讀取其內容的人數沒有限制。

註冊 Bitbucket ​

要使用 Bitbucket，你需要建立一個免費帳户。要這樣做，請進入 https://bitbucket.org/， 然後單擊免費開始Get started for free按鈕。

首先，你需要輸入有效的電子郵件地址，然後點擊繼續。 你的電子郵件帳户將被驗證，如果一切正常，你將被提示輸入所需的密碼。完成後，再次點擊 繼續，然後檢查你的電子郵件收件箱，以確認你的帳户是否已創建：

Bitbucket 註冊

驗證電子郵件地址後，系統會要求你確定用户名。 然後將創建你的帳户，你將會進入 Bitbucket 面板，在那裏開始創建團隊、項目和倉庫：

Bitbucket 面板

如你所見，你可以在幾分鐘內註冊 Bitbucket。Atlassian 的人簡化了這個過程，以便你可以把你的時間真正用在 Bitbucket 上 - 我們下面會進一步講。

使用 Bitbucket ​

讓我們瀏覽下注冊 Bitbucket 之後必須要做的事情。它們都在頂部菜單中：

探索 Bitbucket 功能

1). 創建一個團隊，通過允許多個 Bitbucket 用户共享一個賬號計劃的方式鼓勵協作。 ​

這將允許他們輕鬆管理團隊擁有的倉庫。要創建團隊，請輸入團隊名稱，並確保團隊標識不存在。接下來，輸入你要添加到羣組的人員的電子郵件地址，並指明是否要將其設為管理員。最後，單擊創建：

Bitbucket – 創建一個團隊

2) 創建或導入一個倉庫 ​

如果你已經使用基於 Git 的解決方案，你可以輕鬆地將你的倉庫導入 Bitbucket。否則，你可以從頭創建一個。讓我們看看在每種情況下你需要做什麼。

要創建新的倉庫，請單擊倉庫Repositories菜單中的創建倉庫Create repository選項。為新倉庫和要分組到的項目選擇一個名稱。接下來，指明是否要將其設置為 private 並指定類型（Git 或 Mercurial）。最後，單擊創建倉庫：

Bitbucket – 創建一個新倉庫

要導入已有倉庫，請從倉庫下拉菜單中選擇導入Import倉庫。要開始導入，請指定源，輸入 URL 和所需的登錄憑據（如果需要）。

最後，選擇新的倉庫設置，然後單擊導入倉庫。忽略有關在指定 URL 處找不到倉庫的警告，因為它是虛擬的，僅用於演示目的：

Bitbucket – 導入已有代碼

就是這樣，很簡單吧。

在 Bitbucket 中使用倉庫 ​

創建一個新倉庫或者導入一個倉庫後，它會在面板上展示出來。這時就能執行一些常規操作，如克隆、創建分支、pull request、提交修改、添加 README 文件等等：

Bitbucket – 倉庫概覽

如果想了解如何用倉庫工作，或者想要提升你的 git 技能，可以參考 Bitbucket 官方文檔。

總結 ​

如你所見，不管你是版本管理的新手還是老手，Bitbucket 都能使管理變得更簡單。如果你對本文有任何疑問或評論，請不要猶豫讓我們知道。我們期待聽到你的聲音！
