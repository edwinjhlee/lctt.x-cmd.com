當今需要安裝 Linux 的五大理由 ​

如果你在閲讀本文，那麼你可能是一個 Linux 新手或者是 Linux 的潛在用户。又或者我猜的都不對，你只是好奇於我所説的當今需要安裝 Linux 的五大理由。

不管如何，我都歡迎你來看看我做出的解釋。如果説你能夠讀完全文，記得使用下邊的評論功能分享你的想法。

建議閲讀： 關於 GNU/Linux，我所喜惡的五件事

聲明：以下列出的理由並非按照重要性順序排列。也就是説，你可以從上到下或者以你願意的順序來進行閲讀。

理由 1 – Linux 自由、免費 ​

在 Linux 這個生態系統中，“自由、免費 (free)” 有兩種含義：1) 自由使用（Free as in freedom） 以及 2) 免費使用（Free as in beer）。

第一個含義意味着，你可以自由使用 Linux 做你想要的任何事，比如個人使用或者商業用途。

第二個含義表明這樣一個事實，多數 (99%) 的 Linux 發行版 (或者説，不同風格的 Linux) 都可以免費的下載和運行在大多數電腦上。

建議閲讀： 2016 年最流行的 Linux 發行版

商業發行版經常應用到企業環境，以便獲取其後公司的技術支持。紅帽公司著名的 紅帽企業級 Linux 就是這樣一個例子。

Linux 自由、免費

理由 2 – Linux 可以使老舊設備起死回生 ​

是的，你沒看錯。如果你有一部老舊電腦已經積滿灰塵，因為它已經無法滿足其他操作系統的硬件要求，那麼 Linux 可以幫你拯救它。以我的經驗來説，我第一台電腦 (2000 年末，我母親給我的高中畢業禮物) 作為家庭服務器已經連續運行 5 年了 —— 一直在使用 Debian 最新的穩定版。

建議閲讀： 老舊電腦和筆記本值得嘗試的 6 個 Linux 發行版

Linux 支持老舊設備

理由 3 – Linux 是學習計算機如何工作的最好工具 ​

即使是新手，訪問並與電腦硬件進行交互也是相對容易的。通過諸如 dmesg （從內核中列出相關信息）等 命令列工具加上一點耐心，你可以很容易瞭解從你按下電源開關到加載好一個完整可用的系統到底發生了哪些事情。當然，這只是其中一個例子。

學習 Linux

理由 4 – Linux 是學習編程的最好工具 ​

我常常説，要是我早些認識 Linux 該多好。安裝好系統之後，它就具備了開始學習 Python 編程 的必備工具。作為當今最流行的面向對象的編程語言之一，Python 在多所頂尖大學裏都是計算機科學專業的主修課程。

學習 Linux 及 Python 編程

理由 5 – 大量自由的世界一流軟件 ​

當然，我知道這與 理由 1 多少有些相似，但我還是決定將其列為一個獨立的理由。為何？因為這為我們強調了這樣一個事實，我們今天所使用的軟件大多數是來自於大量志願者的努力。

是的，寫出這些優秀軟件的人員從中不掙一分錢。在某些情況下，也有些公司為軟件的開發和維護提供資金。

建議閲讀： 2015 年我找到的 20 款自由開源的軟件

Linux 系統是相當穩定的，所以他們都想要將他們的軟件運行其中。這就是為什麼很多公司願意為 Linux 生態系統做出大量貢獻的原因 (指捐贈或者提供人力)。

自由開源軟件
