Ubuntu 13.10評論：日趨完善，一個偉大的Linux桌面系統 ​

摘要：Ubuntu 13.10也許並不是最激動人心的桌面Linux，但它卻非常可靠，擁有許多有用的新特性。

許多桌面發燒友至今仍然對Ubuntu轉用Unity耿耿於懷，另外有些人不喜歡Ubuntu的母公司Canonical一意孤行，用Mir代替更主流的Wayland，還有些人不喜歡Ubuntu將本地搜索與Web搜索合併在一起。我想説，那又怎樣！

Ubuntu 13.10即將發佈，本文只是預熱。

讓我來告訴你們，什麼是事實！回首2011年4月，Ubuntu的創始人Mark Shuttleworth曾經説過，Ubuntu新的發展方向是，“為普通消費者帶來快樂、自由、創新、性能和安全，而這些正是Linux平台中一直所缺少的東西”。如今，他做到了！

Ubuntu 13.10，代號“俏皮的蠑螈(Saucy Salamander)”，已經進入發佈前的最後階段。的確，Ubuntu也許不是那些每天熱衷於編譯內核代碼的Linux專家們所喜愛的桌面Linux，因為它本就不是為那些人準備的。

Ubuntu是一個所有人，甚至包括我那81歲的老岳母，都能使用的Linux桌面操作系統。基於這個角度，Ubuntu已經成功了，而下週最終發佈的新版本，對於那些僅僅只是想學習使用一台電腦的新人來説，其意義絕不亞於一場勝利。

為了目睹新版的Ubuntu是如何做到這一點的，我在兩套系統上分別安裝運行了beta版和RC版。第一套測試環境是我2007年產的Dell Inspiron 530S，搭載2.2GHz Intel奔騰 E2200雙核處理器、4G內存、500GSATA串口硬盤，集成Intel 3100GMA顯示芯片組。第二套測試環境是2008年入手的Gateway DX4710，搭載2.5GHz Intel酷睿2四核處理器，6G內存，1T串口硬盤，同樣集成了Intel GMA 3100顯卡。

安裝過程小菜一碟。首先説明一下，我並沒有嘗試在有Windows 8 Secure Boot鎖定的系統上安裝Ubuntu，如果你想嘗試的話，這裏有如何安裝Ubuntu與Win8雙系統的教程，如果是其他使用統一可擴展固件接口(Unified Extensible Firmware Interface - UEFI)的系統，也可以看下這個教程。

安裝過程中有個不錯的新功能，就是安裝的同時你可以登錄或創建一個免費Ubuntu One的雲端服務賬户。Ubuntu One是一款類似Dropbox的存儲服務，提供5G免費空間，商業版費用為39.95美刀，提供20G空間和音樂流媒體支持。該服務除了完美集成在Ubuntu系統中，你也可以在Windows、Mac OS、Android和IOS系統中使用它。

首先，安裝完成後，我注意到的第一件事是，在我這兩台老電腦上，Ubuntu 13.10運行非常流暢，就像在頂級配置的電腦上運行一樣。（譯者表示，這樣的配置竟然還叫老電腦，讓譯者的1G內存情何以堪，你們有考慮過老閃龍的感受嗎！）如果你的機子比我的還老，跑Windows 7以上的系統都嫌慢，並且比較在意即將結束的XP官方支持，可以考慮一下Ubuntu，或者其他易於上手的Linux發行版，比如Mint。

再來看看核心部分。首先，“俏皮的蠑螈”運行Linux 3.11 內核。

在此基礎上，再看看顯示引擎，本來大家預測的是Mir，但是PC上的Mir暫時還沒有準備好迎來它的黃金時期。內有Ubuntu家族中諸如Kubuntu的反對，外有Intel的抵制，Mir需要同時面對“內憂外患”。

最後的結果就是13.10將仍然默認使用老舊的Xorg-server 1.4.3。如果你富有冒險精神，可以選擇嘗試一下Mir。如果你想要在智能手機上運行Ubuntu，也就是傳説中的Ubuntu Touch，恰好，你就可以用到Mir。

如果你是一個開發者，這是個大問題。但如果只是普通用户，你根本不必在意。例如，Valve公司基於Ubuntu的Steam系統上線後，Ubuntu仍將是最棒的Linux遊戲平台。

在圖形架構之上，Ubuntu搭載的是基於Unity 7接口的GNOME 3.8。最新的Unity 8強調使用屏幕邊緣來控制計算機設備，但Unity 8只將在Ubuntu Touch 13.10中使用，默認並不會加入桌面版的13.10。

如果確實不習慣Unity，你也可以方便地在安裝時去掉它。或者，你也可以使用其他Ubuntu家族的Linux發行版，例如面向KDE用户的Kubuntu，Cinnamon粉絲喜歡的Mint，又或者專門針對LXDE愛好者的Lubuntu。搭載Unity的Ubuntu主要為新手用户提供，你完全可以挑選你喜歡的任一款Ubuntu桌面系統。

在新版Ubuntu的軟件包最終敲定之前，人們都以為它會選用Google的Chrome瀏覽器的開源版本Chromium。但是最終，它還是選擇了Firefox 24作為默認瀏覽器。

其他應用程序都將是Ubuntu或Linux桌面用户熟悉的面孔。辦公套件為LibreOffice 4.12；郵件客户端為Thunderbird 24；照片編輯有Gimp 2.8.6，默認的音樂播放器為Rhythmbox 2.99.1。

對新用户來説，最值得一提的新特性將是Smart Scopes(之前叫做Lens)。Lens最初被提出來的時候，其功能只是根據本地Unity Dash的搜索結果對Amazon的搜索結果進行整合。原本是作為默認功能的，但最終該特性被改為了可選。

在Ubuntu 13.10中，當你使用Unity Dash搜索時，不但可以使用Amazon，還可以選擇Facebook、Google、Yelp以及其他多個在線Web頁面。

它是如何工作的呢？當你在Unity Dash中輸入一個搜索條目時，Ubuntu會嘗試猜測最佳匹配項。例如，如果我搜索“最炫民族風”，它除了在我的電腦中搜索，還會在Web的音樂分類下進行搜索。

其中每個分類都有多個源或scopes，例如選擇“參考”分類，會自動對應維基百科、在線詞典Wordnik和Zotero(一個Linux下的類似筆記管理軟件)這三個源。

擔心基於Web的搜索會泄露個人隱私？Ubuntu已經通過匿名搜索和匿名結果解決了這一問題。

如果説你仍然不想從桌面直接進行Web搜索，別擔心，你可以在“設置/安全與隱私/搜索”中將它們全部關閉。或者，我建議通過以下步驟，只使用你信任的搜索引擎：

  • 打開應用程序源（屌絲青年可以使用快捷鍵，Win鍵+A）
  • 往下“滾”，一直滾到Dash插件
  • 選擇“See X more results.”
  • 選擇你想要禁止的源
  • 點擊“Disable”

坦白講，經過一些修改，我很喜歡這個新功能，當然，Ubuntu 13.10的其他部分我也很喜歡。

經過幾個星期的試用，Ubuntu 13.10一直運行良好。對我來説，它是一個流暢、安全、使用方便的桌面Linux。

儘管Unity不太合我個人的胃口，但我仍然認為，Shuttleworth已經成功地打造了一款所有人都可以使用的Linux桌面系統。不相信我？自己下載俏皮的蠑螈試試看吧~
