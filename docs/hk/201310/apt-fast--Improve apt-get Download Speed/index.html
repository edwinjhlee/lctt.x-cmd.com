apt-fast：飛一般的apt-get ​

apt-fast是一個為 apt-get 和 aptitude 做的“ shell腳本封裝 ”，通過對每個包進行併發下載的方式可以大大減少APT的下載時間。apt-fast使用aria2c或axel下載管理器來減少APT下載時間。就像傳統的apt-get包管理器一樣，apt-fast支持幾乎所有的apt-get功能，如， install , remove , update , upgrade , dist-upgrade 等等，並且更重要的是它也支持proxy。

###在Ubuntu上安裝apt-fast

使用以下PPA去安裝apt-fast。apt-fast開發者説：“ 一些發行版，如PCLinux已經在他們默認的倉庫中包括了apt-fast 。” 我希望它將來也包含在Ubuntu/Debian的默認倉庫中。

添加apt-fast的PPA，在終端中輸入以下命令。

sudo add-apt-repository ppa:apt-fast/stable

用命令更新源：

sudo apt-get update

使用命令安裝apt-fast：

sudo apt-get install apt-fast

在安裝期間，它將要求你輸入下載包的最大鏈接數。

在下一個對話框裏面，會問你是否要禁止apt-fast的確認對話框。選擇No並繼續安裝。如果你選擇Yes，apt-fast在安裝軟件包時不會問你確認與否。

我發現 aria2 下載管理器已經隨着apt-fast的安裝而自動安裝。所以，你不必單獨安裝aria2。

如果你想重新配置apt-fast選項，你可以使用命令：

sudo dpkg-reconfigure apt-fast

###用法

與apt-get功能相似，我們可以使用：

apt-fast install package

apt-fast remove package

apt-fast update

apt-fast upgrade

apt-fast dist-upgrade

及更多命令。

工作中的apt-fast包管理器：

###創建別名（可選）

編輯 ~/.bashrc 文件在末尾添加下面這行。

alias apt-get='apt-fast'

或者簡單運行以下命令在你的 ~/.bashrc 中添加它。

sudo echo "alias apt-get='apt-fast'" >> ~/.bashrc

從現在每當你運行apt-get命令去移除，更新和升級包時，它將在後台自動使用apt-fast。聽起來很酷吧？

在測試期間，當下載包時我發現它與apt-get相比非常快。試一試，你一定會贊同我的看法。感謝閲讀！！
