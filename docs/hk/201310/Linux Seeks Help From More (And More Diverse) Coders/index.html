Linux正尋求更多更加多樣化的程序猿和程序媛們 ​

Sarah Sharp(照片中的白富美)和Linus Torvalds(右起第二位)在LinuxCon大會上。照片提供：Linux基金會

上週三，Linus Torvalds和來自Intel的程序媛Sarah Sharp終於面對面坐在了一起。這是他們倆自郵件風波之後的第一次公開會面。（所謂郵件風波，前段時間，他倆就對待Linux程序員時是否該講禮貌的問題而在Linux內核圈子的郵件列表中公開叫板。）

但這次面對面的會面，他倆之間並沒有產生任何火花。他們甚至都沒有提到Sharp這個夏天剛剛發起的議題。

本次Linux大會在新奧爾良召開並全程網絡直播，Sharp在大會的演講中迴避了所有爭議性話題，但她還是向聽眾們表達，Linux需要尋找新的方法為它的心臟——內核——尋找更多願意為之做出貢獻的人。

談及到貢獻量大小時，她説，“我們帶動了很多人加入到內核開發中來，但是這些人很多隻是‘一次性’工作。因此，我們真的需要找到一種方法，好讓人們在內核的項目中做的更多更持久，我們需要更多一對一師徒間的傳幫帶。”

‘我們需要找到一種方法，例如一對一師徒傳幫帶，好讓人們在內核的項目中做的更多更持久。’

— Sarah Sharp

Torvalds承認，儘管在有些方面內核工作看起來很難，但實際上寫寫代碼併入內核其實是很容易的。“人們總説內核多麼多麼難，但同時，只需看看相關數據，並不能説很難涉足。”

Linux基金會公佈的數字顯示，從2005年至今已有10000多位開發者為Linux內核做出了貢獻。這是一個龐大的數字，但社區仍然遠未達到多元化的程度，仍然需要大量新鮮血液。Sharp就是在內核項目中工作的極少數女性之一，她估計內核開發者中程序媛只佔到1%-2%。另外，程序員中的少數民族數量並不清楚。

早在7月份，Sharp就指出，一些程序員可能會因為內核圈子裏粗魯無禮的氛圍而感到不快。如果某些人無法適應這種長久以來在開發領域中佔統治地位的白種男人文化，他們是非常鬱悶和沮喪的。

Torvalds有埋怨人嘴不饒人的習慣，這個夏天，Sharp曾因此在內核郵件列表中公開向Torvalds叫板。Sharp在郵件列表推送中寫道：“Linus，你滿嘴髒話，公然踐踏別人的感情，你是最惡毒的毒舌婦，沒有之一。”

但Torvalds卻説，他最不喜歡的就是“一本正經”，恰好非企業自由化的Linux幫他遠離了這些。從家裏到辦公室，從車庫到浴缸，他可以在地球上的任何地方掌控Linux最重要的核心組件。

遲早Torvalds和Sharp會討論清楚他倆之間的不同。也許就在下個月的艾丁伯格Linux內核閉門高層會議上他倆就會好好聊一聊，只是我們可能就沒有機會聽到了。

儘管Linux大部分都是由白種男人們寫就，但是社區正在朝着改變的方向艱難前進。Sharp自己就協調了一個實習生計劃，用來幫助女程序媛加入開源項目。（當時在大會上，她説現場就有兩位她的程序媛小夥伴也來參會，為的就是能在這裏找份工作）。同時，這也是LinuxCon有史以來的首次，有妹紙在午餐會上出現。

此次大會共有60位左右的女性參會，Linux基金會的一位女發言人Jennifer Cloer説，“我真沒想到會有這麼多妹紙……”。

對了，還有件事值得一提。從去年開始，LinuxCon已經開始提供女性尺碼的大會T恤了。

東部時間2013年9月19日17:55 更正：稍早的一篇報道中寫道，今年是第一年LinuxCon大會提供女性T恤。其實他們從去年2012年就已開始。特此更正。
