點評Linux平台上的音樂播放器Audacious 3.4 ​

在Linux平台上，雖然音樂播放器軟件多如牛毛，但是稱得上音樂播放器這個名稱的為數不多。Audacious是一款非常知名的軟件，並且就是這些能被叫做音樂播放器的少數軟件之一。

###版本點評：Audacious 3.4

Audacious是一款開源的音樂播放器軟件。 作為XMMS播放器軟件的分支，Audacious播放器可以隨心所欲的播放你的音樂，並且不會搶佔其他任務的系統資源。 在你的所有音樂庫裏，你可以進行拖動文件夾和放置私人的歌曲文件、搜索歌手和專輯或者編輯你的自定義播放列表等操作。

特性:

  • 聆聽CD
  • 簡潔的播放列表
  • 清爽的界面
  • 輕量級的系統資源利用
  • 多種音效設置
  • 大量的plugins

在Linux平台上並不缺乏音樂播放器軟件，但每過去一年，這種類型的軟件定義變得越來越模糊。開發商正在實驗新的東西，他們嘗試着模仿其他平台的軟件以及從其他平台複製有特色的功能過來。

今天在用的大多數播放器，至少是一些主要的發佈版本，已經嘗試着加入一些功能，並不僅僅是一個簡單的媒體播放器。開發商已經實現了在線電台、廣播，甚至在界面上就可以直接購買音樂的功能。

雖然這種創新是值得提倡的，但在音頻播放器上做的太過火了。開發商已經忘記了這軟件的主要作用。雖然不用打開網絡瀏覽器就能購買音樂很不錯，但是一款音頻播放軟件不應該把此功能當作核心。

我們現在看看Audacious，一款在Linux平台上的“老校友”式的音頻播放軟件，仍在更新及增加新血液，它不會為了要得到所有第三方服務而改變核心功能。

###安裝

有複雜的和簡單的兩種方式來安裝Audacious。複雜的方式即從源代碼開始編譯安裝，其實沒有必要這樣做。如果選擇從源代碼編譯開始，那麼以後的更新都要用相同的方法來做，這將是非常繁瑣的過程。

我們已經在Ubuntu 13.10 (Saucy Salamander)系統上安裝了Audacious 3.4。雖然Ubuntu 13.10系統仍然處於測試階段，但是除了一個異常外它已經被證實是一個穩定的操作系統。

這個軟件的最新版本是在官方源已經可用，可以通過Ubuntu軟件中心安裝或使用終端來安裝。通常，我們建議用後一種方式，因為Ubuntu軟件中心需要一些依賴的軟件登錄，即使它們是免費的，而且最好看看在安裝過程中具體的發生了什麼。

打開終端，輸入如下的命令：

sudo apt-get install audacious

當所有的包都已安裝結束，像平時一樣，打開Unity Dash，鍵入應用程序的名稱，你就能找到這個播放器的快捷圖標。

###總結

如果您正在尋找傳統但也包含了一些新的功能的音頻播放器，你應該試試Audacious。

該軟件有一個簡單的界面，它幾乎不佔用任何系統資源，沒有任何花裏胡哨的功能，這也正是它的風格。Audacious播放音樂，就這樣，一點也不突兀。

優點

我最喜歡Audacious的就是它清爽乾淨，而不是偽裝簡單的界面。從一開始，你會發現，一切都已經設計了這樣一種方式，你幾乎不可能會犯任何錯誤。

不像它的一些競爭對手軟件（對，我説的就是Rythmbox），為了導入一個簡單的文件夾，你將四處摸索此功能所在何處。它不會用各樣的排序你的音樂庫的方式來打擾用户，顯示歌曲信息的方式也很舒服。

它還配備了一個非常簡單和高效的懸停界面，當你想看到一首歌的細節，但你不想點擊該特定項目，這是非常有用的。

Audacious還配備了三個不同的可以使老用户回到以前所用的“真正的”音頻播放器的可視化模型，並且所有的都可以修改和定製。

所有你期望一個媒體播放器所具有的其他選項，它都具有，談論他們不是主要目的。您可以導入播放列表，設置重複播放，甚至還有一個非常簡單和良好的均衡器。

Audacious的優勢之一是默認包括的音效，如去除人聲，採樣率轉換器，通道混合器，速度和間距，以及更多。

從偏好設置裏，大量的插件也可以被激活，如：專輯封面，歌詞，狀態圖標，GNOME快捷鍵以及其它的一些等等。請注意，所有這些插件在默認情況下是禁用的，他們得由用户手工開啓，以便使界面乾淨漂亮。

不足

關於此軟件的評論，我可能會有點主觀，因為我真的不能忍受過於複雜的音頻播放器，Audacious正對我的胃口。但是，説句公道話，我曾經是愛過能夠添加排序字段的播放列表功能的。

這款應用還具備第二個“Winamp”模式的特性，這使它看起來像Windows平台上的Winamp播放器，不幸的是，每次我試着激它的時候Audacious崩潰了，但也可能是因為Ubuntu13.10目前還不穩定。
