GIMP 3.0 中值得期待的 8 項新功能和改進 ​

將帶來重大改進的 GIMP 3.0 是最令人期待的版本之一。根據它最近的開發版本，這是一個預期的功能列表。

GIMP 是可在 Linux 上使用的 最佳免費圖像編輯器 之一。不僅僅適用於那些想要 Adobe 套件的免費替代品的用户，許多專業人士也使用 GIMP 進行藝術創作、設計和照片編輯。

儘管 GIMP 提供了許多必要的功能和選項，但在各種平台上已經出現了許多現代替代品，其中在一些方面已經超過了 GIMP。

不過，GIMP 3.0 可能是一個扭轉局面的版本，它將使 GIMP 成為最好的現代產品之一，可與現有的商業對手相競爭。

本文將討論預期出現在 GIMP 3.0 版本的功能。

GIMP 3.0 值得期待的頂級功能 ​

隨着 GIMP 3.0 的版本發佈，其開發版本增加了很多改進。

你或許想看到早期開發版本中的所有功能/變化，但我們將在本文中只能介紹其中重要的亮點。

1、基於 GTK3 的用户界面 ​

GIMP 3.0 將帶來基於 GTK3 的用户界面的重新打造的視覺享受。除了改進的外觀和感受，你還可以看到一些新的小工具。

別忘了，愛德華•斯諾登也認為 GIMP 需要進行 UI 大修。所以，GIMP 3.0 即使最終沒有成為一種視覺享受，也應該在某種形式上有所改善。

在以前的 GIMP 版本中，它並不支持高像素密度的顯示器。雖然可以使用，但如果你有一個更高分辨率的屏幕，GIMP 看起來就不夠好。

現在，隨着 GTK3 的加入，它增加了對高像素密度顯示器的支持。你所要做的就是設置你的操作系統的首選縮放/分辨率，GIMP 應該可以支持它了。

2、Wayland 支持 ​

向 GTK3 的過渡應該能提供更好的 Wayland 支持。因此，如果你開始使用 Wayland 桌面會話，GIMP 3.0 應該可以讓你毫無問題地使用該應用程序。

3、多層選擇 ​

最關鍵的新增功能之一是可以選擇多個圖層。

雖然這是一個需要很長時間才能完成的功能，但它終於在 GIMP 3.0 版本中實現了。

有了這個功能，人們可以輕鬆地管理和組織他們的工程中的幾個圖層。

根據現有的信息，他們正式提到了這個變化：

可停靠的圖層現在完全可以進行多選，使用通常的交互方式進行多項目選擇（“Shift + 點擊”用於選擇一系列圖層，“Ctrl + 點擊”用於選擇或取消選擇不相鄰的層）。組織操作現在可以對所有選定的圖層起作用，即你可以一次性移動、重新排序、刪除、複製、合併（以及更多...）所有選定的圖層。

換句話説，你可以選擇多個圖層，並同時對它們進行批量操作。

例如，你可以裁剪、移動、使用合併的圖層中的顏色選擇工具，並使用這個功能執行更多操作。

在發表這篇文章時，我注意到，根據他們的開發Blog，這是一個正在進行的工作，有一些限制。希望在穩定版中，多層選擇可以完美地工作。

4、新的插件 API ​

插件 API 保留了所有的基本功能，但也引入了一些新的改進。

因此，新的插件 API 應該不會對開發者造成任何破壞，而應該可以讓他們把插件輕鬆地移植到 GIMP 3.0 應用程序上。

他們的開發版本中提到了一些改進：

  • 擺脱了對象 ID，轉而使用真實的對象。特別是在 GIMP 3 中，GimpImage、GimpItem、GimpDrawable、GimpLayer、GimpVectors、GimpChannel 和 GimpPDB 都是對象（其他類別的對象已經存在或以後可能加入）。
  • 路徑現在被當作 GFile 來處理，這意味着使用 GLib/GIO API。
  • GIMP API 應該可以完全支持各種語言（Python 3、JavaScript、Lua、Vala 等）。

5、繪畫選擇工具 ​

前景選擇工具不會消失。然而，他們正在開發一個新的實驗性的“繪畫選擇”工具，它可以讓你逐步選擇和繪製使用畫筆的區域。

繪畫選擇工具的目的還在於克服前景選擇工具對大圖像的限制，並解決內存/穩定性問題。

考慮到它被列為實驗性工具，我們不能確定它是否能進入穩定版，但它已經有了新的圖標，你可以找到這個工具。

6、Windows Ink 支持 ​

當然，我們在這裏討論的都是 Linux。但是，GIMP 是一個流行的跨平台工具。

所以，為了吸引更多的用户，最好為專業人士或設計師使用的工具提供硬件支持。

GIMP 3.0 現在支持 Windows Ink 開箱即用，這要歸功於它引入的 GTK3。你會從管理輸入設備的設置中找到使用 Windows Ink API 的選項。

7、改進手勢支持 ​

GIMP 並不是筆記本電腦用户的最佳選擇，或者更準確地説，不是觸摸板/觸摸屏用户的最佳選擇。

然而，隨着 GIMP 3.0 增加了手勢支持，可以捏住畫布放大/縮小，這種情況可能會有所改善。

我們還可能在最終版本中看到更多的手勢支持，但截至 2.99.8 版本，也就是最新的開發版本，還沒有新的手勢。

8、改進的文件格式支持 ​

GIMP 3.0 現在支持 JPEG-XL 文件格式，能夠加載/導出帶有灰度和 RGB 顏色配置文件的 .jxl 文件。

對 Adobe Photoshop 工程文件的支持也得到了改進。它現在可以處理大於 4GB 的 PSD 文件，同時加載多達 99 個通道。

除此以外，對 WebP 和 16 位 SGI 圖像的支持也得到了改進。

總結 ​

看看 GIMP 的開發Blog，看起來他們幾乎已經完成了最終版本。然而，他們並沒有透露任何特定的發佈日期時間表。

所以，一旦他們解決了錯誤並完成了改進，它就會到來。

你期待 GIMP 3.0 嗎？它看起來是一個有希望的下一代版本嗎？
