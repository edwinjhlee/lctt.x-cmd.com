Linux 內核的發佈時間表是什麼？它的支持時間是多久？ ​

Linux 內核很複雜。我説的甚至不是代碼的問題。

Linux 內核的代碼本身很複雜，但你不需要為這個問題而煩惱。我説的是 Linux 內核的發佈時間表。

一年內多久發佈一個新的內核版本？內核被支持多長時間？還有一些 LTS（長期支持）內核，LTS Linux 內核的支持時間有多長？

問題是，雖然這些問題看起來很簡單，但答案卻不簡單。

這些問題沒有一個直接明瞭的答案，需要做一些解釋，這就是我在這篇文章中要做的。

Linux 內核發佈時間表：有嗎？ ​

短的回答是，每兩到三個月就有一個新的內核版本發佈。長的回答是，這不是一個硬性規定。

這個意思是，你經常會看到每兩到三個月就有一個新的內核版本發佈。這是內核維護者團隊的目標，但並沒有規定新版本必須在前一個版本的 8 周後準時發佈的期限。

新的內核版本（通常）是由 Linus Torvalds 在它準備好的時候發佈的。通常是每 2 到 3 個月發佈一次。該版本被宣佈為“穩定”，一般以 X.Y 的格式編號。

但這並不是 X.Y 開發的結束。穩定版會有更多的小版本以進行錯誤的修復。這些小版本在穩定版的內核上又增加了一個點，就像是 X.Y.Z。

雖然 X.Y（通常）是由 Linux 創造者 Linus Torvalds 發佈的，但是維護穩定的 X.Y 內核、合併錯誤修復和發佈 X.Y.Z 版本的責任是由另外的內核開發者負責的。

一個內核版本支持多長時間？ ​

和發佈一樣，一個內核版本支持多長時間也沒有固定的日期和時間表。

一個普通的穩定內核版本通常會被支持兩個半月到三個月，這取決於下一個穩定內核版本的發佈時間。

例如，穩定版內核 5.14 會在穩定版內核 5.15 發佈後的幾周內達到 生命末期。結束支持是由該穩定內核版本的維護者在 Linux 內核郵件列表中宣佈的。用户和貢獻者會被要求切換到新發布的穩定版本。

但這隻適用於正常的穩定內核版本，還有 LTS（長期支持）內核版本，它們的支持期要比 3 個月長得多。

LTS 內核：它支持多長時間？ ​

LTS 內核也沒有固定的發佈時間表。通常，每年都有一個 LTS 內核版本，一般是當年的最後一個版本，它至少會被支持兩年。但同樣，這裏也沒有固定的規則。

LTS 內核的維護者可以同意某個 LTS 內核的維護時間超過通常的兩年。這個協議是根據必要性和參與的人員來達成的。

這種情況經常發生在 Android 項目中。由於兩年的時間不足以讓製造商結束對他們的硬件和軟件功能的支持，你經常會發現一些 LTS 內核會被支持六年之久。

你可以 在 Linux 內核網站上 找到這個信息。

你的發行版可能沒有跟隨通常的 Linux 內核版本 ​

如果你檢查你的 Linux 內核版本，你可能會發現 你的發行版使用了一箇舊的內核。也有可能該發行版提供的內核已經在內核網站上被標記為到達了生命末期。

不要驚慌。你的發行版會負責修補內核的錯誤和漏洞。除非你真的在使用一個不知名的 Linux 發行版，否則你可以相信你的發行版會保持它的安全和健全。

如果你有足夠的理由，比如為了支持更新的硬件，你可以自由地在你使用的任何發行版或 Ubuntu 中安裝最新的 Linux 內核 。

如果你想了解更多細節，我已經 在這裏解釋了為什麼你的發行版使用過時的 Linux 內核。

沒有直接明瞭的答案 ​

正如你所看到的，對於 Linux 內核發佈時間表的問題，沒有直接明瞭的答案。一切都是暫定的。

在我看來，好的方面是，如果你使用一個常規的 Linux 發行版，你不需要為 Linux 內核版本的發佈或終止而煩惱。那是由你的發行版處理的事情。

我希望你對 Linux 內核的發佈週期有了更多的瞭解，或者是我把你搞糊塗了。無論是哪種情況，請在評論區告訴我你的觀點。
