成為為開源做貢獻的技術寫手的四個建議 ​

你的開源貢獻將會向潛在僱主表明，你會主動尋求學習、成長和挑戰自我的機會。

不管你是一個對技術寫作有所涉足的技術愛好者，還是一個想要轉職為職業技術寫手的成熟技術專家，你都可以構建你的技術寫作作品集，並將你的開源貢獻作為作品集的一部分。為開源項目寫作是一件有趣、靈活且低風險的事情。按照自己的時間安排來為你感興趣的項目做貢獻，你將會為社區是多麼熱情或你對社區產生影響的速度而感到驚喜。

你的開源貢獻將會向潛在僱主表明，你會主動尋求學習、成長和挑戰自我的機會。和任何事情一樣，你需要從某個地方開始。為開源項目做貢獻可以讓你在展示你的才華的同時學到新技巧、新技術。另外，為開源項目寫作能讓你接觸到新的社區、跨越時區與新鮮面孔合作，並建立你的社交網絡。當你挖掘到新的開源機會後，你的簡歷將更搶眼，讓你在其他候選人中脱穎而出。以下是為開源做出貢獻的四個建議，這可以讓你走向技術寫作的職業生涯。

學習行業工具 ​

作為開始，我建議先熟悉 Git，並建立 GitLab 和 GitHub 帳號，然後尋找一個趁手的文本編輯器。我個人喜歡使用開源工具 Atom。關於 Git，它能從網絡上獲取到豐富的免費學習資源，包括一些優秀的互動教程。你不需要成為一個 Git 高手才能深入開源世界。我建議先學習一些基本操作，然後讓你的技能隨着你的貢獻逐漸成長。

找到一個項目 ​

為開源做貢獻最難的部分大概是找到一個項目來做貢獻。你可以查看 Up For Grabs 並找一些感興趣的項目。First Timers Only 有更多的起步資源。別猶豫，聯繫項目維護者來了解更多有關於項目的東西，並瞭解他們在何處需要幫助。請堅持下去。找到一個適合你的項目可能會花費一些時間。

告別“冒充者綜合症” ​

一個常見的誤區是你必須是一個程序員才能為開源項目做貢獻。作為一個沒有工程或計算機科學領域有關證書的、自學成材的貢獻者，我能保證事實並非如此。文檔往往開發項目中最價值但最被忽視的部分。這些項目經常缺少人手和資源來建立完善的、高質量的文檔。這給你展現了一個絕佳機會來參與提交拉取請求或歸檔該項目的議題。你可以做到的！

（LCTT 譯註：冒充者綜合症Impostor Syndrome，又稱自我能力否定傾向，指個體按照客觀標準評價為已經獲得了成功或取得成就，但是其本人卻認為這是不可能的，他們沒有能力取得成功，感覺是在欺騙他人，並且害怕被他人發現此欺騙行為的一種現象。）

從小處開始 ​

查看你感興趣的項目的倉庫，找到可能存在的貢獻指南並遵循。然後，尋找更新 README 文檔或提交修改錯別字的機會。沒有什麼貢獻是微不足道的。項目維護者可能會為這些幫助感到高興，而你也將會因把你提交的第一個的拉取請求收錄進你的技術寫作作品集而感到愉悦。
