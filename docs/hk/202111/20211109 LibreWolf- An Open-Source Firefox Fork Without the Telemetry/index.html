自由之狼：一個沒有遙測的開源火狐復刻 ​

LibreWolf 是一個火狐瀏覽器的復刻，它關注於隱私和安全，消除了遙測並增加了其他好處。讓我們來了解一下它。

火狐Firefox 是 Linux 上最好的網頁瀏覽器之一。然而，一些用户並不喜歡其中的遙測機制。

除此之外，有些人更喜歡一個開箱即用的、為最佳隱私和安全而調整過的瀏覽器，即使火狐瀏覽器是提供了最好的定製功能的瀏覽器之一。

如果你不想要火狐瀏覽器的干擾功能，想要一個無需你親自調整的私密網絡體驗，LibreWolf（自由之狼）或許就是答案。

LibreWolf：更好的火狐？ ​

假設你想使用火狐，而不使用火狐的帳户同步的能力和其他一些火狐特有的功能，如 “添加到 Pocket” 按鈕。在這種情況下，LibreWolf 可以是一個不錯的選擇。

不同於其他火狐瀏覽器的復刻（例如，Basilisk 瀏覽器），它是定期更新的。而且，它只專注於提供私密的網頁瀏覽體驗，而不影響你在火狐中所希望得到的用户體驗。

LibreWolf 的特點 ​

LibreWolf 為安全的網頁瀏覽體驗提供了一套相當有用的開箱即用的功能。讓我強調其中的一些特點：

  • 移除遙測功能
  • 不使用火狐賬户進行雲同步
  • 私密搜索供應商，如 Searx、Qwant（DuckDuckGo 被設置為默認）
  • 包含 uBlock Origin 以阻止腳本/廣告
  • 沒有 “添加到 Pocket” 按鈕
  • 主頁上默認沒有贊助/推薦的內容
  • 從設置中刪除火狐狀態條snippets，它用於在新標籤中添加新聞/提示
  • 沒有贊助的快捷提示
  • 追蹤保護默認設置為“嚴格”模式
  • Cookies 和歷史記錄設置為關閉瀏覽器時刪除
  • 默認啓用 HTTPS-only 模式

正如你所注意到的，LibreWolf 的目標是提供一個更清潔和有利於隱私的體驗，而不需要調整任何東西。

如果你不想反覆登錄網絡服務和瀏覽歷史記錄來回憶你的瀏覽活動，一些選項如退出時清除 cookies/歷史記錄可能會很不方便。

所以，如果你想從火狐切換到 LibreWolf，你可能想在決定之前測試一下網頁瀏覽體驗。

在 Linux 中安裝 LibreWolf ​

對於任何 Linux 發行版，你可以使用 AppImage 文件或 Flathub 的 Flatpak 包。

如果你不知道，你可以參考我們關於 使用 AppImage 的指南和 Flatpak 的資源 。

對於 Arch Linux 用户，它也可以在 Arch 用户倉庫（AUR） 中找到。

也可以在他們的 官方網站 或 GitLab 頁面 中找到其他安裝説明。
