只有 4MB？如何修復 Etcher 和 Rufus 創建 Linux USB 後“破壞”的 USB ​

情況是這樣的。你用 Etcher 或者 Rufus 工具在 Windows 或者 Linux 中創建了一個可啓動的、Live Linux USB。

你用它來安裝 Linux，USB 的目的已經達到了。現在你想格式化這個 USB，用它來進行常規的數據傳輸或存儲。

你把它插入你的 Windows 系統，令你吃驚的是，這個 USB 的磁盤容量只有 4MB。

你試圖格式化它，但它可能不會讓你這麼做。即使你設法格式化它，USB 的大小現在也從通常的 8GB、16GB 或 32GB 縮減到只有 4MB。

你失去了你的 USB 嗎？並非如此。你的 USB 並沒有完全被破壞。你仍然可以用一個小技巧來格式化它，並舒適地使用它。

讓我告訴你如何在 Windows 和 Linux 中把可啓動的 USB 恢復到可用的狀態。

格式化由 Rufus 或 Etcher 創建的 Live Linux USB （在 Windows 下） ​

你在 Windows 中看到只有 4MB 的磁盤空間。你知道為什麼嗎？因為在創建 Live Linux USB 時，該工具在 FAT32 文件系統中創建了一個 4MB 的 EFI 分區。其他的分區是在 Linux 的 Ext4 文件系統中，而這是不被 Windows 識別的。

這就是為什麼你的 Windows 系統只看到 4MB 的 EFI 分區，並顯示 USB 大小為 4MB。

總而言之，你需要做的是刪除 USB 盤上的所有分區，用刪除現有分區後得到的空閒空間創建一個新的 NTFS 或 FAT32 分區。這就行了。

讓我展示一下詳細的步驟。

步驟 1： ​

進入 Windows 菜單，尋找“磁盤管理”工具。

啓動這個工具，它將顯示你電腦上存在的所有磁盤。當然，這包括插入的 USB。

選擇正確的磁盤是非常重要的。從 U 盤的大小或“可移動”的標籤中辨別出它是哪一個。

步驟 2： ​

我們的想法是刪除 U 盤上的任何現有分區。未分配的空間不能被刪除，但這也沒關係。

在該分區上點擊右鍵，然後點擊“刪除卷Delete Volume”。

當要求你確認時，按“是Yes”。

你的目標是隻有一個未分配的空間塊。當你看到它時，右擊它並點擊“新建簡單卷……New Simple Volume...”來創建一個分區。

接下來的步驟很簡單。點擊“下一步Next >”，選擇整個可用空間，給它分配一個字母，選擇文件系統（FAT32 或 NTFS），並將其格式化。

完成後，你會看到 USB 已經恢復到正常狀態，你可以開始向它複製粘貼數據。

你現在可以像以前一樣使用你的 USB 了。

這些步驟是針對 Windows 的。如果你使用 Linux 呢？

在 Linux 上格式化 Live USB ​

我注意到，由 Etcher 和這類工具創建的 Live USB 經常拒絕被文件管理器中的右鍵格式化選項正確格式化。

除此之外，你可以像在 Windows 中那樣做：刪除現有的分區，用整個可用空間創建一個新的分區。

這裏使用 GNOME “磁盤” 工具。它已經安裝在 Ubuntu 和許多其他 Linux 發行版上。

同樣，確保你在這裏選擇了外部 USB 盤。

你會看到 U 盤上的各種分區。試着從上面的菜單中格式化該磁盤。

如果這不起作用，逐個刪除分區，然後把整個 USB 作為自由空間。

當你創建了整個自由空間後，點擊 “+” 號，在上面創建一個 NTFS 或 FAT32 文件系統的分區。

用 NTFS（或 FAT32）創建分區，給它起個合適的名字，然後你就可以像以前一樣使用這個 USB 了。

總結 ​

像 Rufus 和 Etcher 這樣的工具並沒有真正破壞你的 USB。這就是它們的功能，通過在磁盤上創建一個不同的文件系統。但這樣一來，Windows 操作系統就不能正確理解它。

好在只需付出一點努力就可以修復。我希望你也能夠修復它。如果沒有，請與我分享你的問題，我將盡力幫助你。
