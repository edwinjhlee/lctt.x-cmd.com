Annotator：為 Linux 圖片添加基本註解 ​

一款令人興奮和有用的註解工具，為 Linux 系統提供額外的功能。

談及圖像處理和編輯，有很多工具可用。然而，像 GIMP 這樣的工具不一定能解決所有問題。

GIMP 確實為初學者和高級用户提供了大量的功能，但要學習一些東西並對圖像進行視覺增強功能的應用可能很費時。

Annotator 是一個令人印象深刻的開源工具，可以讓你能輕鬆完成很多事情。

Annotator：開源圖像註解工具 ​

Annotator 幫你快速添加形狀、文本和其他視覺元素。這對各種使用情況都很有用。

這個工具提供了一個簡單的用户界面並且易於使用。而且，你還可以通過各種你想要的功能來增強圖像。

Annotator 的功能 ​

不侷限於圖片增強，你還可以通過 Annotator 獲得一些其他功能。其中的一些主要功能是：

  • 能夠添加文本
  • 自定義文本的顏色，調整大小，調整高亮的顏色等
  • 使用放大鏡工具來關注圖像中的某個特定點
  • 調整放大鏡以改變角度和大小
  • 添加視覺圖標來表達一些東西
  • 使用鉛筆來書寫，這對觸控板用户很有用
  • 模糊工具來模糊重要或不必要的細節
  • 計數器圖標來突出圖像中重要的任何種類的順序
  • 支持多種字體
  • 調整形狀和文本的邊界寬度和線條
  • 可用各種形狀，如箭頭、圓圈和星星
  • 能夠調整圖像的大小和裁剪圖像

在 Linux 中安裝 Annotator ​

Annotator 通常可在 elementaryOS 的應用中心找到。但幸運的是，它是一個 Flatpak 包，所以你可以在任何 Linux 發行版上安裝它。

你所需要做的就是前往應用中心商店的鏈接，然後使用軟件安裝程序下載/打開 Flatpak ref 文件。如果你需要幫助，我們的 Flatpak 指南 中有更多相關信息。

Annotator

要從源代碼構建或探索更多關於它的信息，你可以查看它的 GitHub 頁面。

關於使用 Annotator 的想法 ​

我發現它對我的工作很有用，因為我們每天都需要處理各種截圖。而且，描述性越詳細，圖片就越能讓我們的讀者理解。

通常情況下，我使用 Flameshot 作為我的截圖工具，並通過它添加可用的註解。還有其他 可用於 Linux 的截圖工具，但我更喜歡 Flameshot 的快速註解功能。

然而，你不能使用 Flameshot 或其他任何截圖工具來為現有的圖片添加註解。

因此，Annotator 在編輯現有的截圖或任何其他所需的圖像時就顯得非常方便。

在我短暫的使用過程中，它的所有功能都運行良好，不過我希望可以編輯和調整文字的大小，使之更加直觀。

如果你需要為系統上的圖像添加高亮/註解，我建議你試一試。請在下面的評論中告訴我你的想法。
