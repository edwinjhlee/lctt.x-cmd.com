Motrix：一個漂亮的跨平台開源下載管理器 ​

一個開源的下載管理器，提供了一個簡潔的用户界面，同時提供了跨平台操作的所有基本功能。在這裏瞭解關於它的更多信息。

Linux 下有大量的下載管理器。如果你想下載一些東西並可以管理它們，你可以選擇任何一個可用的下載管理器。

然而，如果你想要一個好看的下載管理器，提供現代的用户體驗，同時又不影響功能設置，我有個軟件你可能會喜歡。

看看 Motrix：一個功能豐富的開源下載管理器 ​

Motrix 是一個不折不扣的下載管理器，開箱即用，外觀簡潔。它是自由開源軟件。

你可以選擇在 Linux、Windows 和 macOS 中使用。

它也可以成為一些 Linux 中的 torrent 客户端 的潛在替代品。

讓我強調一些關鍵的功能以及安裝説明。

Motrix 的特點 ​

你應該能找到所有你通常在下載管理器中期待的功能。下面是它們的列表：

  • 跨平台支持
  • 易於使用的界面
  • BitTorrent 的選擇性下載
  • 自動更新 tracker 列表
  • UPnP 及 NAT-PMP 端口映射
  • 多個下載任務（最多 10 個）
  • 在一個任務中最多支持 64 個線程
  • 能夠設置速度限制
  • 可選擇改變用户代理
  • 支持系統托盤
  • 黑暗模式
  • 支持多國語言

總的來説，它在處理 torrent 文件時工作得很好，也能從剪貼板上檢測到下載鏈接。在下載文件之前可以直接訪問高級選項，所以這應該是很方便的。

在我短暫的測試中，我在 Ubuntu 上以 Snap 包使用它時沒有發現任何問題。

在 Linux 中安裝 Motrix ​

你有多種安裝 Motrix 的選項。因此，你應該能夠在你選擇的任何 Linux 發行版上安裝它。

它主要提供了一個 AppImage 供下載。但是，它還有 Flatpak 包，並可在 Snap 商店找到它。

如果你使用的是 Ubuntu，你可以通過軟件中心找到它。

除了這些，它也在 AUR 中提供給 Arch Linux 用户。在任何一種情況下，你都可以從他們的 GitHub 發佈欄 獲得 DEB/RPM 包。

你可以在他們的官方網站和 GitHub 頁面上找到下載鏈接和更多安裝的信息。

  • Motrix

總結 ​

Motrix 提供了所有你想要的下載管理器中的好東西，額外還有一個現代的用户體驗。

我建議你試試把它作為你的下載管理器，看看它是否能取代你目前的工具。我很想知道你的 Linux 系統上常用的下載管理器。請在下面的評論中告訴我更多關於它的信息。
