在 Linux 上用 Kdenlive 編輯視頻 ​

嘗試用這個 KDE 程序做專業的視頻編輯。

無論是雪日、季節性假期，或是任何假期，都是在你電腦前專心發揮創造力的好時候。我最喜歡的一種消遣就是剪視頻。有時，我為了講個故事來剪；其他時候，我則是為了表達我的心情、觀點、為我發現或創作的音樂提供視覺效果。也許這是因為我在學校為從事這一領域的職業學習了剪視頻，或就只是因為我喜歡強大的開源工具。至今，我最喜歡的視頻剪輯程序是優秀的 Kdenlive，這是一個強大而專業的剪輯工具，提供了直觀的工作流、大量的特效和轉場。

在 Linux 上安裝 Kdenlive ​

Kdenlive 可以通過大部分的 Linux 發行版的包管理器安裝。在 Fedora、Mageia 或類似的發行版：

$ sudo dnf install kdenlive

在 Elementary、Mine 或其他基於 Debian 的發行版：

$ sudo apt install kdenlive

不過，我用 Flatpak 來安裝 Kdenlive。

如何籍視頻講故事 ​

到底“編輯”視頻是什麼意思？

剪輯視頻有些誇張的誤解。當然，它是使鴻篇鉅製的大片影響全世界數百萬人的過程，但當你在你的筆記本前坐下時，你不必那樣想。剪輯視頻就是一個十分簡單的，移除“壞的”部分，直到只剩下“好的”部分的工作。

什麼是“好”鏡頭還是“壞”鏡頭，完全取決於你自己的品味，甚至可能根據你想用你的創作 “説” 的內容而改變。如果你在剪輯你在後院發現的野生動物的鏡頭，你可能會剪掉那些突出你的垃圾桶或你踩着耙子的鏡頭。剩下的部分肯定會使你的後院看起來像一個神奇的秘密花園，裏面有蜂鳥、蝴蝶、好奇的兔子和一隻俏皮的狗。另一方面，留下這些 “壞” 鏡頭，你就可以創造一部喜劇，講述一個郊區人在清理垃圾時，踩到了耙子上，把所有的動物都嚇跑了，總之是在搗亂。這沒有對錯之分。無論你切掉什麼，沒有人知道曾經存在過。無論你保留什麼，都會有一個故事。

導入鏡頭 ​

當你啓動 Kdenlive，你會有個空項目。Kdenlive 窗口包括在左上角 項目箱Project Bin、一個在中間的信息框，以及一個在右上的 項目監視器Project Monitor。在下面的是十分重要的部分—— 時間軸Timeline。時間軸是創建你的故事的地方。在你的項目結束時，時間軸中的所有內容都是你的觀眾所看到的。這就是你的影片。

在你開始在你的時間軸上構建故事前，你需要一些素材。假設你已經從相機或手機上獲得了一些視頻，你必須在項目箱中增加一些素材。右鍵點擊項目箱面板的空位置，然後選擇 添加素材或文件夾Add Clip or Folder。

裁剪鏡頭 ​

Kdenlive 中有許多方式來裁剪視頻鏡頭。

三點式編輯 ​

以前，創建素材的正式方式是“三點式編輯”，包括如下幾點：

  1. 在 素材監視器Clip Monitor 中打開一個視頻素材，找到你希望視頻開始的點，然後點鍵盤上的 l 來標記 開始。
  2. 然後找你想讓視頻停止的點，並按 O 來標記 結束。
  3. 從素材監視器拖動視頻素材到 Kdenlive 窗口底部的時間軸上的某一個位置。

這個方法依然在某些環境中保有重要地位，但對於很多用户來説太“書面化”了。

軸內編輯 ​

另一個編輯的方法是拖動切片到 Kdenlive 的時間軸面板，並拖動切片的邊緣，直到只留下好的部分。

離切的藝術 ​

另一種編輯技巧是 離切cut-away。這是個重要的技巧，它不只幫助你跳過視頻切片中的壞的部分，而且可以為你的觀眾增加背景信息。在電影和電視中，你已經見過了許多離切，即使你不理解它。每當熒幕上的人看驚訝地抬頭，然後你就能看到他們的視角，這就是離切。當一個新聞主播提到你們城市中的一處地方，然後那個地方的鏡頭跟隨其後，這也是離切。

你可以輕易的在 Kdenlive 中完成離切操作，因為 Kdenlive 時間軸是疊層式的。默認情況下，Kdenlive 中有四個 “軌道track” ——最上面的兩個分給視頻，而下面的兩個給伴奏的音頻。當你在時間軸上放置視頻素材，放在較高的視頻軌道上的優先於放在下面的軌道。這意味着你可以在功能上編輯掉視頻軌道的鏡頭，只需要通過在較高的軌道上放些更好的素材就行。

導出你的電影 ​

當你的編輯都完成後，你可以導出你的電影，然後來把它發佈到網上，讓其他人看到。要做到這一點，點擊在 Kdenlive 窗口頂端工具欄上的 渲染Render 按鈕。在顯現的 渲染Rendering 窗口中，選擇你的視頻託管服務支持的格式。WEBM 格式是近日很普遍的一種格式，除了是開源的，它也是可用於分發和存檔的最佳格式之一。它能支持 4K、立體圖像、廣色域等更多的特性。而且所有的主流瀏覽器都可以播放它。

渲染需要時間，這取決於你的項目長度、你作出了多少編輯、以及你電腦的性能。

一個長效的解決方案 ​

當我寫這篇文章的時候，正好在十年前的今天，我發表了 關於 Kdenlive 的六篇介紹文章 。令我驚訝的是，這意味着我成為 Kdenlive 用户的時間比我在電影學院學習的專有編輯器的時間還要長。這是令人印象深刻的長壽，而且我今天仍然在使用它，因為它的靈活性和可靠性是其他編輯器無法比擬的。糟糕的是，我所學過的專有視頻編輯器甚至都不存在了，至少不再以同樣的形式存在（這讓我希望我在一個開源平台上學習編輯！）。

Kdenlive 是一個功能強大的編輯器，有很多功能，但不要讓這些嚇倒你。我的介紹系列在今天和十年前一樣相關而準確，在我看來，這是一個真正可靠的應用程序的特徵。如果你想選擇 Kdenlive 作為視頻編輯器，一定要下載我們的 速查表，這樣你就可以熟練使用鍵盤快捷鍵，減少點擊次數，使編輯過程無縫進行。

現在去講你的故事吧！
