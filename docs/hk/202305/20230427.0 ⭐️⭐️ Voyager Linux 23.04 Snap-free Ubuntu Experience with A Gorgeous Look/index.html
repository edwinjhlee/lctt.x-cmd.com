Voyager Linux 23.04：具有華麗外觀且無 Snap 的 Ubuntu 體驗 ​

新版本的 Voyager Linux 23.04 已經來到，我率先試駕以瞭解更多信息。

在我去年年初上次 測評 時，它還是一個嶄露頭角的發行版，提供了很棒的 Ubuntu LTS 體驗。從那時起，這個發行版的方向發生了一些變化。因此，我覺得是時候進行另一輪試駕了。

順便説一句，Voyager Linux 基於 Ubuntu Linux，針對 GNOME 桌面進行了出色的定製。之前，它只跟隨 Ubuntu 長期支持（LTS）版本發佈，但從去年開始，它也可跟隨短期 Ubuntu 版本發佈。

在 Ubuntu 23.04 “Lunar Lobster” 發佈後，Voyager 團隊宣佈發佈了 Voyager 23.04。

Voyager Linux 23.04 測評 ​

與 Voyager 22.04 版本相比，此版本的 ISO 大小增加了約 30%。這可能主要是由於 Ubuntu 自己的軟件包庫。安裝很順利，但安裝程序需要至少 24 GB 的存儲空間（硬性要求）。但是，它使用舊的 Uniquity 安裝程序，而不是新的基於 Flutter 的 Ubuntu 安裝程序。

外觀及使用感受 ​

如果你運行的是早期版本的 Voyager Linux，你首先會注意到新版的外觀精美。GNOME 桌面現在更具個性化，使用了 “Kora” 主題和許多擴展程序。

在底部，你可以看到默認的程序塢，並通過 “Blur my shell” 擴展將其變成了透明的。此外，這一版本還預裝了一系列擴展，並通過適當的設置啓用，以便讓 GNOME 桌面更好看。

值得重點一提的擴展是非常棒的 “Arc Menu”，可以下拉訪問所有系統應用程序和資源。此外，“Dash to Dock”、“Blur my shell” 和 “Battery Indicator” 也是一些很有用的擴展應用。以下是 Voyager Linux 23.04 中預裝的擴展列表：

  • Arch menu
  • Battery time
  • Blur my shell
  • Burn my windows
  • Caffeine
  • Clipboard history
  • Compiz alike magic lamp effect
  • Compiz windows effect
  • Custom hot corners – Extended
  • Dash to Dock
  • Desktop Cube
  • EasyScreenCast
  • Gradient Top Bar
  • Lock keys
  • Replace Activities Label
  • Screen Rotate
  • SettingsCenter
  • Simple net speed
  • Space Bar
  • Sur Clock
  • Use Avatar in Quick Settings

所有這些都使桌面在美觀的同時超級高效。

應用、Snap 和 Flatpak ​

儘管 Voyager Linux 是基於 Ubuntu 的，但默認情況下完全不包含 Snap。此外，Voyager Linux 23.04 也沒有支持 Ubuntu 從該版本開始刪除 Flatpak 的決定。因此，總而言之，Voyager Linux 23.04 中默認支持的是 Flatpak，而沒有任何 Snap 的痕跡。不僅如此，Firefox 網絡瀏覽器是由原生 deb 模組打包的，而不是 Snap 版本。

應用程序列表很龐大且健全。主要應用程序包括 Gedit 文本編輯器、“文件”應用、Firefox 網絡瀏覽器、GIMP 和 LibreOffice 套件。還包括 Thunderbird 電子郵件客户端、Remmina 遠程連接應用程序、Transmission Torrent 客户端和 Pidgin 通訊軟件。

Voyager 包括 Pitivi、MPV 和 Rhythmbox，均可用於播放視頻和音樂。對於工作和文檔處理，它提供了地圖、日曆、Foliate 閲讀器應用程序、KeePassXC 和 Scrcpy 安卓屏幕鏡像工具。

由於主 ISO 文件包括了 Xfce 和 GNOME 桌面，因此你也可以體驗一些原生 Xfce 應用程序。

Box Voyager ​

Voyager Linux 帶有自己的很棒的小應用，稱為 “Box Voyager”，它讓你可以一鍵訪問所有桌面自定義設置。它有一個配置項列表，你可以直接使用此應用程序啓動相應的設置。

此外，要進行更多自定義設置，你可以使用 Voyager Linux 中預裝的多個 Conky 主題。 無需面對安裝和配置 Conky 的麻煩。（LCTT 譯註：Conky 是一個應用於桌面環境的系統監視軟件，可以在桌面上監控系統運行狀態、網絡狀態等一系列參數，而且可自由定製。）

性能表現 ​

安裝了所有定製和擴展後，其性能表現令人印象深刻。它在閒置時佔用 1.3 GB 的內存，CPU 使用率為 1%。但是，隨着你安裝和打開更多應用程序，性能指標可能會上升。

然而，由於預裝了許多應用程序和 Xfce 桌面，它的安裝需要大約 14 GB 的磁盤空間。另外，正如我之前提到的，整個安裝需要 24 GB 的可用磁盤空間。

總結 ​

在測評了 Voyager Linux 23.04 之後，我相信它是一個理想的、可以日常使用的非 Snap Ubuntu 變體。如果你不喜歡 Ubuntu GNOME 的默認外觀，並且正在尋找具有穩定的 Ubuntu 長期支持/短期基礎，且設計吸引人的預配置發行版，那麼 Voyager Linux 可能是你的完美選擇。

此外，最棒的是在同樣的 Ubuntu 基礎上還有一個 Xfce 桌面可以選擇。試一試吧。

你可以在其 官方網站 下載 Voyager Linux。
