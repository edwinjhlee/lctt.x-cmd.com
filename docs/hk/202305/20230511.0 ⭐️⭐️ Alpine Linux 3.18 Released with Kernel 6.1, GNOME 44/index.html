Alpine Linux 3.18 發佈 ​

Alpine Linux 3.18 發佈，其內核版本升級至 6.1，同時更新了 GNOME 44。

Alpine Linux 是一款注重輕量化和安全性的發行版，最新版本 Alpine Linux 3.18.0 的發佈標誌着正式推出 v3.18 穩定版系列。該版本包含了許多令人興奮的更新和改進，為用户帶來了許多新功能、功能增強以及流行軟件組件的最新版本。

此次 Alpine Linux 3.18 的一個重要亮點是引入了 Linux 內核 6.1，該版本自帶初步的 Rust 支持和最新的 GPU 和 CPU 更新。此外，Alpine Linux 3.18.0 還通過驗證模組的真實性和完整性來增強系統安全性。但需要注意的是，默認情況下模組驗證並未強制執行，因此支持具有 AKMS 的第三方模組無縫運行。

除了升級的內核，Alpine Linux 3.18 還配備了 musl libc 1.2.4，在 DNS 解析器中包含了 TCP 回退功能。此功能增強了網絡通信的魯棒性，並確保在有挑戰性的網絡環境中實現可靠的 DNS 解析。

開發人員將會很高興地發現，此版本還更新了流行編程語言的版本。包括 Python 3.11、Ruby 3.2、和 Node.js (current) 20.1，提供了強大的工具包，用於創建各種應用，這些語言版本的更新帶來了各種性能改進、錯誤修復以及新功能，豐富了開發體驗。

圖形桌面環境 GNOME 在 Alpine Linux 3.18 中也得到了顯著升級，升級到了 GNOME 44。此版本的 GNOME 引入了本地後台應用、“文件”應用中一直被期待的圖像預覽功能，以及其他一些更新，你可以在我詳細的 功能概覽頁面 中瞭解。

Alpine Linux 3.18 中其他值得一提的更新還包括添加了 Go 1.20、KDE Plasma 5.27 和 Rust 1.69。這些的更新確保開發人員可訪問最新的工具和框架，以創建前沿的應用。

Alpine Linux 3.18 還通過 tiny-cloud 引入了實驗性的無人值守安裝支持。該功能允許自動化且精簡的部署，使系統管理員能夠更輕鬆地在多台機器上設置和配置 Alpine Linux。tiny-cloud 功能為雲和虛擬化環境中的高效和可擴展的部署打開了新的可能性。

此外，Alpine Linux 3.18 在軟件包大小方面做出了顯著優化。所有 ppc64le、x86 和x86_64 的軟件包都與 DT_RELR 鏈接，從而減小了已編譯二進制文件的大小。此優化有助於節省存儲空間，並有助於更快的軟件包安裝和低資源消耗。

為了進一步優化安裝過程，Alpine Linux 3.18 現在提供了單獨的 Python 預編譯文件（pyc）軟件包。這意味着用户可以選擇僅安裝必要的組件，通過排除 pyc 文件節省寶貴的磁盤空間。
