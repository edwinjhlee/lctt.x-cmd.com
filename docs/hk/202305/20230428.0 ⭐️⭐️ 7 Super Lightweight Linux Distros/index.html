7 個超輕量級 Linux 發行版 ​

值得試一試這些超級小的、輕量級的 Linux 發行版。

Linux 發行版的多樣性不是缺點，而是有益的特性。

無論你的需求是在舊硬件或者存儲空間有限的系統上運行 Linux，還是需要佔用最少磁盤空間同時又能處理特定任務，在這裏都可以找到適合你的選項。

因此，讓我重點介紹一些用於此類場景的超輕量級 Linux 發行版。

📋 需要注意的是，對系統要求較低和佔用存儲空間較小的發行版可能無法為所有人提供便利的桌面體驗，你可能需要做一些調整。

1、Tiny Core ​

Tiny Core，又名 The Core x86 Project，是一款模組化的 Linux 發行版，提供了幾種變體的超小型 ISO 文件。

其中最小的是 “Core” 版（17 MB），只提供命令列界面和一些工具，沒有任何圖形桌面環境。其次是 TinyCore（23 MB），它包括基本系統和圖形桌面環境的 GUI 擴展。

最後一個，CorePlus ISO（248 MB）是為新用户量身定製的，它支持無線網絡、提供可選的多種窗口管理器，以及一些來幫助安裝發行版的其他 GUI 工具。

該發行版的大小多年來一直在增長。但是，它仍然令人印象深刻。

2、Puppy Linux ​

Puppy Linux 是一個因其文件大小極小和易用性而廣受歡迎的 Linux 發行版。它是本列表中最古老的選項，起源可以追溯到 2003 年。

其 ISO 文件大小為 300-400 MB，具體取決於你選擇的變體。

是的，Puppy Linux 不是單個 Linux 發行版。該項目使用其他發行版，並使用其系統構建器重建它們，添加其應用並進行配置，以使 ISO 最終的大小通常小於 500 MB。

你能找到 Ubuntu、Raspbian 和 Slackware 的 Puppy Linux 變體，包括 32 位和 64 位版本。

3、SliTaz ​

SliTaz 是一款有趣的 滾動發佈的發行版，提供了所有必要的內容，以獲得可用的桌面體驗。

而所有這些都放在只有 43MB 的 ISO 中。令人驚訝，對吧！與 TinyCore 不同，你可以得到圖形用户界面，同時節省大量存儲空間。

SliTaz 完全是從頭開始構建的，因此它一款獨立發行版。它可能不適合初學者，但它確實包含一些實用程序，可幫助你安裝必備軟件，並以最小的學習曲線入門。

4、Bodhi Linux ​

Bodhi Linux 是基於 Ubuntu 的流行的 輕量級 Linux 發行版 之一。如果你想要一個輕量級的選擇和便捷的用户體驗，搭載 Moksha 桌面的 Bodhi Linux 就是答案。

其 ISO 文件的大小小於 900 MB。因此，是的，它可能不是各種替代方案中最輕量級的，但如果你不想犧牲使用體驗，那麼選擇它一定不會錯。

5、AntiX Linux ​

AntiX Linux 基於 Debian 穩定分支構建。它是 支持 32 位系統的發行版 之一。

它提供了多個變體，包括：Full、Base、Core 和 net。Full 版略大於 1GB，包含許多預裝的應用。帶有 GUI（窗口管理器）的 Base 大約為 800 MB。

其他版本不提供 GUI，ISO 文件小於 500 MB。

如果你不知道，AntiX Linux 支持兩種不同的初始化系統 SysVinit 或 runit。因此，AntiX Linux 也是 無 Systemd 發行版 之一。

6、Porteus Linux ​

Porteus Linux 是一款針對最小硬件優化的發行版，其 ISO 鏡像大小不到 300 MB。

它支持 32 位和 64 位系統。Porteus 基於 Slackware，提供了兩個版本，一個用於桌面，另一個用於信息亭（網絡終端）。

你可以使用 Porteus 攜帶的多種桌面環境，包括 GNOME 和 KDE，在這麼小的包中獲得熟悉的桌面體驗。

7、ArchBang Linux ​

ArchBang 是一款基於 Arch 的發行版，它使用 i3 窗口管理器，不到 1GB ISO 文件提供了輕量級體驗。

如果您想使用一種帶有某些額外便利的極簡 Arch Linux 體驗，那麼 ArchBang 是一個不錯的選擇。

你可以參照我們的 ArchBang 安裝指南 開始使用。

此外，如果你想自定義 ArchBang Linux 的外觀，可以參考我們的 i3 自定義指南。

節省你的系統資源以獲得快速體驗 ​

如果你想節省系統資源並仍然能夠執行基本任務，那麼這些發行版是你安裝的最佳選擇。

考慮到缺少預安裝的應用和實用程序，你可能無法在其中一些發行版上完成所有操作。但是，我們精心挑選的選擇應該可以為你提供可用的桌面體驗。
