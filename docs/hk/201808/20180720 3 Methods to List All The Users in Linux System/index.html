列出 Linux 系統上所有用户的 3 種方法 ​

通過使用 /etc/passwd 文件，getent 命令，compgen 命令這三種方法查看系統中用户的信息

大家都知道，Linux 系統中用户信息存放在 /etc/passwd 文件中。

這是一個包含每個用户基本信息的文本文件。當我們在系統中創建一個用户，新用户的詳細信息就會被添加到這個文件中。

/etc/passwd 文件將每個用户的基本信息記錄為文件中的一行，一行中包含 7 個字段。

/etc/passwd 文件的一行代表一個單獨的用户。該文件將用户的信息分為 3 個部分。

* 第 1 部分：`root` 用户信息
* 第 2 部分：系統定義的賬號信息
* 第 3 部分：真實用户的賬户信息

第一部分是 root 賬户，這代表管理員賬户，對系統的每個方面都有完全的權力。

第二部分是系統定義的羣組和賬户，這些羣組和賬號是正確安裝和更新系統軟件所必需的。

第三部分在最後，代表一個使用系統的真實用户。

在創建新用户時，將修改以下 4 個文件。

* `/etc/passwd`： 用户賬户的詳細信息在此文件中更新。
* `/etc/shadow`： 用户賬户密碼在此文件中更新。
* `/etc/group`： 新用户羣組的詳細信息在此文件中更新。
* `/etc/gshadow`： 新用户羣組密碼在此文件中更新。

方法 1 ：使用 /etc/passwd 文件 ​

使用任何一個像 cat、more、less 等文件操作命令來打印 Linux 系統上創建的用户列表。

/etc/passwd 是一個文本文件，其中包含了登錄 Linux 系統所必需的每個用户的信息。它保存用户的有用信息，如用户名、密碼、用户 ID、羣組 ID、用户 ID 信息、用户的家目錄和 Shell 。

/etc/passwd 文件將每個用户的詳細信息寫為一行，其中包含七個字段，每個字段之間用冒號 : 分隔：

# cat /etc/passwd
root:x:0:0:root:/root:/bin/bash
bin:x:1:1:bin:/bin:/sbin/nologin
daemon:x:2:2:daemon:/sbin:/sbin/nologin
adm:x:3:4:adm:/var/adm:/sbin/nologin
lp:x:4:7:lp:/var/spool/lpd:/sbin/nologin
sync:x:5:0:sync:/sbin:/bin/sync
shutdown:x:6:0:shutdown:/sbin:/sbin/shutdown
halt:x:7:0:halt:/sbin:/sbin/halt
mail:x:8:12:mail:/var/spool/mail:/sbin/nologin
ftp:x:14:50:FTP User:/var/ftp:/sbin/nologin
postfix:x:89:89::/var/spool/postfix:/sbin/nologin
sshd:x:74:74:Privilege-separated SSH:/var/empty/sshd:/sbin/nologin
tcpdump:x:72:72::/:/sbin/nologin
2gadmin:x:500:10::/home/viadmin:/bin/bash
apache:x:48:48:Apache:/var/www:/sbin/nologin
zabbix:x:498:499:Zabbix Monitoring System:/var/lib/zabbix:/sbin/nologin
mysql:x:497:502::/home/mysql:/bin/bash
zend:x:502:503::/u01/zend/zend/gui/lighttpd:/sbin/nologin
rpc:x:32:32:Rpcbind Daemon:/var/cache/rpcbind:/sbin/nologin
2daygeek:x:503:504::/home/2daygeek:/bin/bash
named:x:25:25:Named:/var/named:/sbin/nologin
mageshm:x:506:507:2g Admin - Magesh M:/home/mageshm:/bin/bash

7 個字段的詳細信息如下。

  • 用户名 （magesh）： 已創建用户的用户名，字符長度 1 個到 12 個字符。
  • 密碼（x）：代表加密密碼保存在 `/etc/shadow 文件中。
  • **用户 ID（506）：代表用户的 ID 號，每個用户都要有一個唯一的 ID 。UID 號為 0 的是為 root 用户保留的，UID 號 1 到 99 是為系統用户保留的，UID 號 100-999 是為系統賬户和羣組保留的。
  • **羣組 ID （507）：代表羣組的 ID 號，每個羣組都要有一個唯一的 GID ，保存在 /etc/group 文件中。
  • **用户信息（2g Admin - Magesh M）：代表描述字段，可以用來描述用户的信息（LCTT 譯註：此處原文疑有誤）。
  • **家目錄（/home/mageshm）：代表用户的家目錄。
  • **Shell（/bin/bash）：代表用户使用的 shell 類型。

你可以使用 awk 或 cut 命令僅打印出 Linux 系統中所有用户的用户名列表。顯示的結果是相同的。

# awk -F':' '{ print $1}' /etc/passwd
or
# cut -d: -f1 /etc/passwd

方法 2 ：使用 getent 命令 ​

getent 命令顯示 Name Service Switch 庫支持的資料庫中的條目。這些庫的配置文件為 /etc/nsswitch.conf。

getent 命令顯示類似於 /etc/passwd 文件的用户詳細信息，它將每個用户詳細信息顯示為包含七個字段的單行。

# getent passwd
root:x:0:0:root:/root:/bin/bash
bin:x:1:1:bin:/bin:/sbin/nologin
daemon:x:2:2:daemon:/sbin:/sbin/nologin
adm:x:3:4:adm:/var/adm:/sbin/nologin
lp:x:4:7:lp:/var/spool/lpd:/sbin/nologin
sync:x:5:0:sync:/sbin:/bin/sync
shutdown:x:6:0:shutdown:/sbin:/sbin/shutdown
halt:x:7:0:halt:/sbin:/sbin/halt
mail:x:8:12:mail:/var/spool/mail:/sbin/nologin
ftp:x:14:50:FTP User:/var/ftp:/sbin/nologin
postfix:x:89:89::/var/spool/postfix:/sbin/nologin
sshd:x:74:74:Privilege-separated SSH:/var/empty/sshd:/sbin/nologin
tcpdump:x:72:72::/:/sbin/nologin
2gadmin:x:500:10::/home/viadmin:/bin/bash
apache:x:48:48:Apache:/var/www:/sbin/nologin

mysql:x:497:502::/home/mysql:/bin/bash

named:x:25:25:Named:/var/named:/sbin/nologin

7 個字段的詳細信息如上所述。（LCTT 譯註：此處內容重複，刪節）

你同樣可以使用 awk 或 cut 命令僅打印出 Linux 系統中所有用户的用户名列表。顯示的結果是相同的。
