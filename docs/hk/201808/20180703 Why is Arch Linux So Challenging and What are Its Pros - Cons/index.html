為什麼 Arch Linux 如此“難弄”又有何優劣? ​

Arch Linux 於 2002 年發佈，由 Aaron Grifin 領頭，是當下最熱門的 Linux 發行版之一。從設計上説，Arch Linux 試圖給用户提供簡單、最小化且優雅的體驗，但它的目標用户羣可不是怕事兒多的用户。Arch 鼓勵參與社區建設，並且從設計上期待用户自己有學習操作系統的能力。

很多 Linux 老鳥對於 Arch Linux 會更瞭解，但電腦前的你可能只是剛開始打算把 Arch 當作日常操作系統來使用。雖然我也不是權威人士，但下面幾點優劣是我認為你總會在使用中慢慢發現的。

1、優點： 定製屬於你自己的 Linux 操作系統 ​

大多數熱門的 Linux 發行版（比如 Ubuntu 和 Fedora）很像一般我們會看到的預裝系統，和 Windows 或者 MacOS 一樣。但 Arch 則會更鼓勵你去把操作系統配置的符合你的品味。如果你能順利做到這點的話，你會得到一個每一個細節都如你所想的操作系統。

缺點： 安裝過程讓人頭疼 ​

Arch Linux 的安裝 別闢蹊徑——因為你要花些時間來微調你的操作系統。你會在過程中瞭解到不少終端命令和組成你係統的各種軟件模組——畢竟你要自己挑選安裝什麼。當然，你也知道這個過程少不了閲讀一些文檔/教程。

2、優點： 沒有預裝垃圾 ​

鑑於 Arch 允許你在安裝時選擇你想要的系統部件，你再也不用煩惱怎麼處理你不想要的一堆預裝軟件。作為對比，Ubuntu 會預裝大量的軟件和桌面應用——很多你不需要、甚至卸載之前都不知道它們存在的東西。

總而言之，Arch Linux* 能省去大量的系統安裝後時間。Pacman**，是 Arch Linux 默認使用的優秀包管理組件。或者你也可以選擇 Pamac 作為替代。

3、優點： 無需繁瑣系統升級 ​

Arch Linux 採用滾動升級模型，簡直妙極了。這意味着你不需要操心升級了。一旦你用上了 Arch，持續的更新體驗會讓你和一會兒一個版本的升級説再見。只要你記得‘滾’更新（Arch 用語），你就一直會使用最新的軟件包們。

缺點： 一些升級可能會滾壞你的系統 ​

雖然升級過程是完全連續的，你有時得留意一下你在更新什麼。沒人能知道所有軟件的細節配置，也沒人能替你來測試你的情況。所以如果你盲目更新，有時候你會滾壞你的系統。（LCTT 譯註：別擔心，你可以‘滾’回來 ;D ）

4、優點： Arch 有一個社區基因 ​

所有 Linux 用户通常有一個共同點：對獨立自由的追求。雖然大多數 Linux 發行版和公司企業等掛鈎極少，但也並非沒有。比如 基於 Ubuntu 的衍生版本們不得不受到 Canonical 公司決策的影響。

如果你想讓你的電腦更獨立，那麼 Arch Linux 是你的夥伴。不像大多數操作系統，Arch 完全沒有商業集團的影響，完全由社區驅動。

5、優點： Arch Wiki 無敵 ​

Arch Wiki 是一個無敵文檔庫，幾乎涵蓋了所有關於安裝和維護 Arch 以及關於操作系統本身的知識。Arch Wiki 最厲害的一點可能是，不管你在用什麼發行版，你多多少少可能都在 Arch Wiki 的頁面裏找到有用信息。這是因為 Arch 用户也會用別的發行版用户會用的東西，所以一些技巧和知識得以泛化。

6、優點： 別忘了 Arch 用户軟件庫 （AUR） ​

Arch 用户軟件庫Arch User Repository （AUR）是一個來自社區的超大軟件倉庫。如果你找了一個還沒有 Arch 的官方倉庫裏出現的軟件，那你肯定能在 AUR 裏找到社區為你準備好的包。

AUR 是由用户自發編譯和維護的。Arch 用户也可以給每個包投票，這樣後來者就能找到最有用的那些軟件包了。

最後: Arch Linux 適合你嗎？ ​

Arch Linux 優點多於缺點，也有很多優缺點我無法在此一一敍述。安裝過程很長，對非 Linux 用户來説也可能偏有些技術，但只要你投入一些時間和善用 Wiki，你肯定能邁過這道坎。

Arch Linux 是一個非常優秀的發行版——儘管它有一些複雜性。同時它也很受那些知道自己想要什麼的用户的歡迎——只要你肯做點功課，有些耐心。

當你從零開始搭建完 Arch 的時候，你會掌握很多 GNU/Linux 的內部細節，也再也不會對你的電腦內部運作方式一無所知了。

歡迎讀者們在評論區討論你使用 Arch Linux 的優缺點？以及你曾經遇到過的一些挑戰。
