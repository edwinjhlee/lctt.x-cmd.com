Mu 入門：一個面向初學者的 Python 編輯器 ​

相識 Mu —— 一個可以使學生學習 Python 更輕鬆的開源編輯器。

Mu 是一個給初學者的 Python 編輯器，它旨在使學習體驗更加愉快。它使學生​​能夠在早期體驗成功，這在你學習任何新知識的時候都很重要。

如果你曾試圖教年輕人如何編程，你會立即把握到 Mu 的重要性。大多數編程工具都是由開發人員為開發人員編寫的，不管他們的年齡如何，它們並不適合初學者。然而，Mu 是由老師為學生寫的。

Mu 的起源 ​

Mu 是 Nicholas Tollervey 的心血結晶（我聽過他 5 月份在 PyCon2018 上發言）。Nicholas 是一位受過古典音樂訓練的音樂家，在擔任音樂老師期間，他在職業生涯早期就開始對 Python 和開發感興趣。他還寫了 Python in Education，這是一本可以從 O'Reilly 下載的免費書。

Nicholas 曾經尋找過一個更簡單的 Python 編程界面。他想要一些沒有其他編輯器（甚至是 Python 附帶的 IDLE3 編輯器 ）複雜性的東西，所以他與 Raspberry Pi 基金會（贊助他的工作）的教育總監 Carrie Ann Philbin 合作開發了 Mu 。

Mu 是一個用 Python 編寫的開源程序（在 GNU GPLv3 許可證下）。它最初是為 Micro:bit 迷你計算機開發的，但是其他老師的反饋和請求促使他將 Mu 重寫為通用的 Python 編輯器。

受音樂啓發 ​

Nicholas 對 Mu 的啓發來自於他教授音樂的方法。他想知道如果我們按照教授音樂的方式教授編程會如何，並立即看出了差別。與編程不同，我們沒有音樂訓練營，我們也不會書上學習如何演奏樂器，比如説如何演奏長笛。

Nicholas 説，Mu “旨在成為真實的東西”，因為沒有人可以在 30 分鐘內學習 Python。當他開發 Mu 時，他與老師一起工作，觀察編程俱樂部，並觀看中學生使用 Python。他發現少即多，保持簡單可以改善成品的功能。Nicholas 説，Mu 只有大約 3,000 行代碼。

使用 Mu ​

要嘗試它，下載 Mu 並按照 [Linux、Windows 和 Mac OS] 8的簡易安裝説明進行操作。如果像我一樣，你想[在 Raspberry Pi 上安裝] 9，請在終端中輸入以下內容：

$ sudo apt-get update
$ sudo apt-get install mu

從編程菜單啓動 Mu。然後你就可以選擇如何使用 Mu。

菜單使用和理解非常簡單，這實現了 Mu 的目標 —— 讓編寫代碼對初學者簡單。

在 Mu 用户的網站上可找到教程和其他資源。在網站上，你還可以看到一些幫助開發 Mu 的志願者的名字。如果你想成為其中之一併為 Mu 的發展做出貢獻，我們非常歡迎您。
