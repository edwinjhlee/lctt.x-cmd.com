那些奇特的 Linux 發行版本 ​

從大多數消費者所關注的諸如 Ubuntu，Fedora，Mint 或 elementary OS 到更加複雜、輕量級和企業級的諸如 Slackware，Arch Linux 或 RHEL，這些發行版本我都已經見識過了。除了這些，難道沒有其他別的了嗎？其實 Linux 的生態系統是非常多樣化的，對每個人來説，總有一款適合你。下面就讓我們討論一些稀奇古怪的小眾 Linux 發行版本吧，它們代表着開源平台真正的多樣性。

Puppy Linux ​

它是一個僅有一個普通 DVD 光盤容量十分之一大小的操作系統，這就是 Puppy Linux。整個操作系統僅有 100MB 大小！並且它還可以從內存中運行，這使得它運行極快，即便是在老式的 PC 機上。 在操作系統啓動後，你甚至可以移除啓動介質！還有什麼比這個更好的嗎？ 系統所需的資源極小，大多數的硬件都會被自動檢測到，並且它預裝了能夠滿足你基本需求的軟件。在這裏體驗 Puppy Linux 吧.

Suicide Linux(自殺 Linux) ​

這個名字嚇到你了嗎？我想應該是。 ‘任何時候 -注意是任何時候-一旦你遠程輸入不正確的命令，解釋器都會創造性地將它重定向為 rm -rf / 命令，然後擦除你的硬盤’。它就是這麼簡單。我真的很想知道誰自信到將Suicide Linux 安裝到生產機上。 警告：千萬不要在生產機上嘗試這個！ 假如你感興趣的話，現在可以通過一個簡潔的DEB 包來獲取到它。

PapyrOS ​

它的 “奇怪”是好的方面。PapyrOS 正嘗試着將 Android 的 material design 設計語言引入到新的 Linux 發行版本上。儘管這個項目還處於早期階段，看起來它已經很有前景。該項目的網頁上説該系統已經完成了 80%，隨後人們可以期待它的第一個 Alpha 發行版本。在該項目被宣告提出時，我們做了 PapyrOS 的小幅報道，從它的外觀上看，它甚至可能會引領潮流。假如你感興趣的話，可在 Google+ 上關注該項目並可通過 BountySource 來貢獻出你的力量。

Qubes OS ​

Qubes 是一個開源的操作系統，其設計通過使用安全分級（Security by Compartmentalization）的方法，來提供強安全性。其前提假設是不存在完美的沒有 bug 的桌面環境。並通過實現一個‘安全隔離（Security by Isolation）’ 的方法，Qubes Linux試圖去解決這些問題。Qubes 基於 Xen、X 視窗系統和 Linux，並可運行大多數的 Linux 應用，支持大多數的 Linux 驅動。Qubes 入選了 Access Innovation Prize 2014 for Endpoint Security Solution 決賽名單。

Ubuntu Satanic Edition ​

Ubuntu SE 是一個基於 Ubuntu 的發行版本。通過一個含有主題、壁紙甚至來源於某些天才新晉藝術家的重金屬音樂的綜合軟件包，“它同時帶來了最好的自由軟件和免費的金屬音樂” 。儘管這個項目看起來不再積極開發了， Ubuntu Satanic Edition 甚至在其名字上都顯得奇異。 Ubuntu SE (Slightly NSFW)。

Tiny Core Linux ​

Puppy Linux 還不夠小？試試這個吧。 Tiny Core Linux 是一個 12MB 大小的圖形化 Linux 桌面！是的，你沒有看錯。一個主要的補充説明：它不是一個完整的桌面，也並不完全支持所有的硬件。它只含有能夠啓動進入一個非常小巧的 X 桌面，支持有線網絡連接的核心部件。它甚至還有一個名為 Micro Core Linux 的沒有 GUI 的版本，僅有 9MB 大小。Tiny Core Linux。

NixOS ​

它是一個資深用户所關注的 Linux 發行版本，有着獨特的打包和配置管理方式。在其他的發行版本中，諸如升級的操作可能是非常危險的。升級一個軟件包可能會引起其他包無法使用，而升級整個系統感覺還不如重新安裝一個。在那些你不能安全地測試由一個配置的改變所帶來的結果的更改之上，它們通常沒有“重來”這個選項。在 NixOS 中，整個系統由 Nix 包管理器按照一個純功能性的構建語言的描述來構建。這意味着構建一個新的配置並不會重寫先前的配置。大多數其他的特色功能也遵循着這個模式。Nix 相互隔離地存儲所有的軟件包。有關 NixOS 的更多內容請看這裏。

GoboLinux ​

這是另一個非常奇特的 Linux 發行版本。它與其他系統如此不同的原因是它有着獨特的重新整理的文件系統。它有着自己獨特的子目錄樹，其中存儲着所有的文件和程序。GoboLinux 沒有專門的包資料庫，因為其文件系統就是它的資料庫。在某些方面，這類重整有些類似於 OS X 上所看到的功能。

Hannah Montana Linux ​

它是一個基於 Kubuntu 的 Linux 發行版本，它有着漢娜·蒙塔娜（ Hannah Montana） 主題的開機啓動界面、KDM(KDE Display Manager)、圖標集、ksplash、plasma、顏色主題和壁紙(I'm so sorry)。這是它的鏈接。這個項目現在不再活躍了。

RLSD Linux ​

它是一個極其精簡、小巧、輕量和安全可靠的，基於 Linux 文本的操作系統。開發者稱 “它是一個獨特的發行版本，提供一系列的控制台應用和自帶的安全特性，對黑客或許有吸引力。” RLSD Linux.

我們還錯過了某些更加奇特的發行版本嗎？請讓我們知曉吧。
