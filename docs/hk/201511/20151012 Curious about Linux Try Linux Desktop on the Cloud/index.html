好奇 Linux？試試雲端的 Linux 桌面 ​

Linux 在桌面操作系統市場上只佔據了非常小的份額，從目前的調查結果來看，估計只有2%的市場份額；對比來看，豐富多變的 Windows 系統佔據了接近90%的市場份額。對於 Linux 來説，要挑戰 Windows 在桌面操作系統市場的壟斷，需要有一個讓用户學習不同的操作系統的簡單方式。如果你相信傳統的 Windows 用户會再買一台機器來使用 Linux，那你就太天真了。我們只能去試想用户重新分區，設置引導程序來使用雙系統，或者跳過所有步驟回到一個最簡單的方法。

我們實驗過一系列讓用户試操作 Linux 的無風險的使用方法，不涉及任何分區管理，包括 CD/DVD 光盤、USB 存儲棒和桌面虛擬化軟件等等。通過實驗，我強烈推薦使用 VMware 的 VMware Player 或者 Oracle VirtualBox 虛擬機，對於桌面操作系統或者便攜式電腦的用户，這是一種安裝運行多操作系統的相對簡單而且免費的的方法。每一台虛擬機和其他虛擬機相隔離，但是共享 CPU、內存、網絡接口等等。虛擬機仍需要一定的資源來安裝運行 Linux，也需要一台相當強勁的主機。但對於一個好奇心不大的人，這樣做實在是太麻煩了。

要打破用户傳統的使用觀念是非常困難的。很多 Windows 用户可以嘗試使用 Linux 提供的自由軟件，但也有太多要學習的 Linux 系統知識。這會花掉他們相當一部分時間才能習慣 Linux 的工作方式。

當然了，對於一個第一次在 Linux 上操作的新手，有沒有一個更高效的方法呢？答案是肯定的，接着往下看看雲實驗平台。

LabxNow ​

LabxNow 提供了一個免費服務，方便廣大用户通過瀏覽器來訪問遠程 Linux 桌面。開發者將其加強為一個用户個人遠程實驗室（用户可以在系統裏運行、開發任何程序），用户可以在任何地方通過互聯網登入遠程實驗室。

這項服務現在可以為個人用户提供2核處理器，4GB RAM和10GB的固態硬盤，運行在128G RAM的4 AMD 6272處理器上。

配置參數: ​

  • 系統鏡像：基於 Ubuntu 14.04 的 Xface 4.10，RHEL 6.5，CentOS(Gnome桌面)，Oracle
  • 硬件: CPU - 1核或者2核；內存: 512MB, 1GB, 2GB or 4GB
  • 超快的網絡數據傳輸
  • 可以運行在所有流行的瀏覽器上
  • 可以安裝任意程序，可以運行任何程序 – 這是一個非常棒的方法，可以隨意做實驗學習你想學的任何知識，沒有 一點風險
  • 添加、刪除、管理、制定虛擬機非常方便
  • 支持虛擬機共享，遠程桌面

你所需要的只是一台有穩定網絡的設備。不用擔心虛擬專用系統（VPS）、域名、或者硬件帶來的高費用。LabxNow提供了一個在 Ubuntu、RHEL 和 CentOS 上實驗的非常好的方法。它給 Windows 用户提供一個極好的環境，讓他們探索美妙的 Linux 世界。説得深入一點，它可以讓用户隨時隨地在裏面工作，而沒有了要在每台設備上安裝 Linux 的壓力。點擊下面這個鏈接進入 www.labxnow.org/labxweb/。

另外還有一些其它服務（大部分是收費服務）可以讓用户使用 Linux，包括 Cloudsigma 環境的7天使用權和Icebergs.io （通過HTML5實現root權限）。但是現在，我推薦 LabxNow。
