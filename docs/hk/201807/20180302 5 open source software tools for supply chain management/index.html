供應鏈管理方面的 5 個開源軟件工具 ​

跟蹤您的庫存和您需要的材料，用這些供應鏈管理工具製造產品。

本文最初發表於 2016 年 1 月 14 日，最後的更新日期為 2018 年 3 月 2 日。

如果你正在管理着處理實體貨物的業務，供應鏈管理 是你的業務流程中非常重要的一部分。不論你是經營着一個只有幾個客户的小商店，還是在世界各地擁有數以百萬計客户和成千上萬產品的世界財富 500 強的製造商或零售商，很清楚地知道你的庫存和製造產品所需要的零部件，對你來説都是非常重要的事情。

保持對貨品、供應商、客户的持續跟蹤，而且所有與它們相關的變動部分都會受益於這些用來幫助管理工作流的專門軟件，而在某些情況下需要完全依賴這些軟件。在本文中，我們將去了解一些自由及開源的供應鏈管理方面的軟件，以及它們的其中一些功能。

供應鏈管理比單純的庫存管理更為強大。它能幫你去跟蹤貨物流以降低成本，以及為可能發生的各種糟糕的變化來制定應對計劃。它能夠幫你對出口合規性進行跟蹤，不論是否是出於法律要求、最低品質要求、還是社會和環境責任。它能夠幫你計劃最低供應量，讓你能夠在訂單數量和交付時間之間做出明智的決策。

由於其本質決定了許多供應鏈管理軟件是與類似的軟件捆綁在一起的，比如，客户關係管理（CRM）和 企業資源計劃管理 （ERP）。因此，當你選擇哪個工具更適合你的組織時，你可能會考慮與其它工具集成作為你的決策依據之一。

Apache OFBiz ​

Apache OFBiz 是一套幫你管理多種業務流程的相關工具。雖然它能管理多種相關問題，比如，分類、電子商務網站、會計和 POS，它在供應鏈管理方面的主要功能關注於倉庫管理、履行、訂單和生產管理。它的可定製性很強，但是，對應的它需要大量的規劃去設置和集成到你現有的流程中。這就是它適用於中大型業務的原因之一。項目的功能構建於三個層面：展示層、業務層和數據層，它是一個彈性很好的解決方案，但是，再強調一遍，它也很複雜。

Apache OFBiz 的源代碼在其 項目倉庫 中可以找到。Apache OFBiz 是用 Java 寫的，並且它是按 Apache 2.0 許可證 授權的。

如果你對它感興趣，你也可以去查看 opentaps，它是在 OFBiz 之上構建的。Opentaps 強化了 OFBiz 的用户界面，並且添加了 ERP 和 CRM 的核心功能，包括倉庫管理、採購和計劃。它是按 AGPL 3.0 授權使用的，對於不接受開源授權的組織，它也提供了商業授權。

OpenBoxes ​

OpenBoxes 是一個供應鏈管理和存貨管理項目，最初的主要設計目標是為了醫療行業中的藥品跟蹤管理，但是，它可以通過修改去跟蹤任何類型的貨品和相關的業務流。它有一個需求預測工具，可以基於歷史訂單數量、存儲跟蹤、支持多種場所、過期日期跟蹤、銷售點支持等進行預測，並且它還有許多其它功能，這使它成為醫療行業的理想選擇，但是，它也可以用於其它行業。

它在 Eclipse 公開許可證 下可用，OpenBoxes 主要是由 Groovy 寫的，它的源代碼可以在 GitHub 上看到。

OpenLMIS ​

與 OpenBoxes 類似，OpenLMIS 也是一個醫療行業的供應鏈管理工具，但是，它專用設計用於在非洲的資源缺乏地區使用，以確保有限的藥物和醫療用品能夠用到需要的病人上。它是 API 驅動的，這樣用户可以去定製和擴展 OpenLMIS，同時還能維護一個與通用基準代碼的連接。它是由洛克菲勒基金會開發的，其它的貢獻者包括聯合國、美國國際開發署、和比爾 & 梅林達·蓋茨基金會。

OpenLMIS 是用 Java 和 JavaScript 的 AngularJS 寫的。它在 AGPL 3.0 許可證 下使用，它的源代碼在 GitHub 上可以找到。

Odoo ​

你可能在我們以前的 ERP 項目 榜的文章上見到過 Odoo。事實上，根據你的需要，一個全功能的 ERP 對你來説是最適合的。Odoo 的供應鏈管理工具主要圍繞存貨和採購管理，同時還與電子商務網站和 POS 連接，但是，它也可以與其它的工具連接，比如，與 frePPLe 連接，它是一個開源的生產計劃工具。

Odoo 既有軟件即服務（SaaS）的解決方案，也有開源的社區版本。開源的版本是以 LGPL 版本 3 下發行的，源代碼在 GitHub 上可以找到。Odoo 主要是用 Python 來寫的。

xTuple ​

xTuple 標稱自己是“為成長中的企業提供供應鏈管理軟件”，它專注於已經超越了其傳統的小型企業 ERP 和 CRM 解決方案的企業。它的開源版本稱為 Postbooks，添加了一些存貨、分銷、採購、以及供應商報告的功能，它提供的核心功能是會計、CRM、以及 ERP 功能，而它的商業版本擴展了製造和分銷的 功能。

xTuple 在 CPAL 下使用，這個項目歡迎開發者去復刻它，為基於存貨的製造商去創建其它的業務軟件。它的 Web 應用核心是用 JavaScript 寫的，它的源代碼在 GitHub 上可以找到。

就這些，當然了，還有其它的可以幫你處理供應鏈管理的開源軟件。如果你知道還有更好的軟件，請在下面的評論區告訴我們。
