Linux 上的五個開源益智遊戲 ​

用這些有趣好玩的遊戲來測試你的戰略能力。

遊戲一直是 Linux 的弱點之一。由於 Steam、GOG 和其他將商業遊戲引入多種操作系統的努力，這種情況近年來有所改變，但這些遊戲通常不是開源的。當然，這些遊戲可以在開源操作系統上玩，但對於純粹開源主義者來説還不夠好。

那麼，一個只使用開源軟件的人，能否找到那些經過足夠打磨的遊戲，在不損害其開源理念的前提下，提供一種可靠的遊戲體驗呢？當然可以。雖然開源遊戲歷來不太可能與一些藉由大量預算開發的 AAA 商業遊戲相匹敵，但在多種類型的開源遊戲中，有很多都很有趣，可以從大多數主要 Linux 發行版的倉庫中安裝。即使某個特定的遊戲沒有被打包成特定的發行版本，通常也很容易從項目的網站上下載該遊戲以便安裝和遊戲。

這篇文章着眼於益智遊戲。我已經寫過街機風格遊戲和棋牌遊戲。 在之後的文章中，我計劃涉足賽車，角色扮演、戰略和模擬經營遊戲。

Atomix ​

Atomix 是 1990 年在 Amiga、Commodore 64、MS-DOS 和其他平台發佈的 Atomix 益智遊戲的開源克隆。Atomix 的目標是通過連接原子來構建原子分子。單個原子可以向上、向下、向左或向右移動，並一直朝這個方向移動，直到原子撞上一個障礙物——水平牆或另一個原子。這意味着需要進行規劃，以確定在水平上構建分子的位置，以及移動單個部件的順序。第一關是一個簡單的水分子，它由兩個氫原子和一個氧原子組成，但後來的關卡是更復雜的分子。

要安裝 Atomix，請運行以下命令:

  • 在 Fedora： dnf install atomix
  • 在 Debian/Ubuntu： apt install atomix

Fish Fillets - Next Generation ​

Fish Fillets - Next Generation 是遊戲 Fish fillet 的 Linux 移植版本，它於 1998 年在 Windows 發佈，源代碼在 2004 年以 GPL 許可證發佈。遊戲中，兩條魚試圖將物體移出道路來通過不同的關卡。這兩條魚有不同的屬性，所以玩家需要為每個任務挑選合適的魚。較大的魚可以移動較重的物體，但它更大，這意味着它不適合較小的空隙。較小的魚可以適應那些較小的間隙，但它不能移動較重的物體。如果一個物體從上面掉下來，兩條魚都會被壓死，所以玩家在移動棋子時要小心。

要安裝 Fish fillet——Next Generation，請運行以下命令:

  • 在 Fedora：dnf install fillets-ng
  • 在 Debian/Ubuntu： apt install fillets-ng

Frozen Bubble ​

Frozen Bubble 是一款街機風格的益智遊戲，從屏幕底部向屏幕頂部的一堆泡泡射擊。如果三個相同顏色的氣泡連接在一起，它們就會被從屏幕上移除。任何連接在被移除的氣泡下面但沒有連接其他任何東西的氣泡也會被移除。在拼圖模式下，關卡的設計是固定的，玩家只需要在泡泡掉到屏幕底部的線以下前將泡泡從遊戲區域中移除。該遊戲街機模式和多人模式遵循相同的基本規則，但也有不同，這增加了多樣性。Frozen Bubble 是一個標誌性的開源遊戲，所以如果你以前沒有玩過它，玩玩看。

要安裝 Frozen Bubble，請運行以下命令：

  • 在 Fedora: dnf install frozen-bubble
  • 在 Debian/Ubuntu: apt install frozen-bubble

Hex-a-hop ​

Hex-a-hop 是一款基於六角形瓦片的益智遊戲，玩家需要將所有的綠色瓦片從水平面上移除。瓦片通過移動被移除。由於瓦片在移動後會消失，所以有必要規劃出穿過水平面的最佳路徑，以便在不被卡住的情況下移除所有的瓦片。但是，如果玩家使用的是次優路徑，會有撤銷功能。之後的關卡增加了額外的複雜性，包括需要跨越多次的瓦片和使玩家跳過一定數量的六角彈跳瓦片。

要安裝 Hex-a-hop，請運行以下命令：

  • 在 Fedora: dnf install hex-a-hop
  • 在 Debian/Ubuntu: apt install hex-a-hop

Pingus ​

Pingus 是 Lemmings 的開源克隆。這不是一個精確的克隆，但遊戲非常相似。小動物（Lemmings 裏是旅鼠，Pingus 裏是企鵝）通過關卡入口進入關卡，開始沿着直線行走。玩家需要使用特殊技能使小動物能夠到達關卡的出口而不會被困住或者掉下懸崖。這些技能包括挖掘或建橋。如果有足夠數量的小動物進入出口，這個關卡將成功完成，玩家可以進入下一個關卡。Pingus 為標準的 Lemmings 添加了一些額外的特性，包括一個世界地圖和一些在原版遊戲中沒有的技能，但經典 Lemmings 遊戲的粉絲們在這個開源版本中仍會感到自在。

要安裝 Pingus，請運行以下命令：

  • 在 Fedora: dnf install pingus
  • 在 Debian/Ubuntu: apt install pingus
