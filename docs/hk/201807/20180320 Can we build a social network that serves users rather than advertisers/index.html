扫码关注官方微信公众号获取开源软件和 x-cmd 的最新用法与独家资讯

我們能否建立一個服務於用户而非廣告商的社交網絡？ ​

找出 Human Connection 是如何將透明度和社區放在首位的。

如今，開源軟件具有深遠的意義，在推動數字經濟創新方面發揮着關鍵作用。世界正在快速徹底地改變。世界各地的人們需要一個專門的、中立的、透明的在線平台來迎接我們這個時代的挑戰。

開放的原則也許是讓我們達成這一目標的方法。如果我們用開放的思維方式將數字創新與社會創新結合在一起，會發生什麼？

這個問題是我們在 Human Connection 工作的核心，這是一個具有前瞻性的，以德國為基礎的知識和行動網絡，其使命是創建一個服務於全球的真正的社交網絡。我們受到這樣一種觀念為指引，即人類天生慷慨而富有同情心，並且他們在慈善行為上茁壯成長。但我們還沒有看到一個完全支持我們的自然趨勢，與樂於助人和合作以促進共同利益的社交網絡。Human Connection 渴望成為讓每個人都成為積極變革者的平台。

為了實現一個以解決方案為導向的平台的夢想，讓人們通過與慈善機構、社區團體和社會變革活動人士的接觸，圍繞社會公益事業採取行動，Human Connection 將開放的價值觀作為社會創新的載體。

以下是有關它如何工作的。

首先是透明 ​

透明是 Human Connection 的指導原則之一。Human Connection 邀請世界各地的程序員通過在 Github 上提交他們的源代碼共同開發平台的源代碼（JavaScript、Vue、nuxt），並通過貢獻代碼或編程附加功能來支持真正的社交網絡。

但我們對透明的承諾超出了我們的發展實踐。事實上，當涉及到建立一種新的社交網絡，促進那些讓世界變得更好的人之間的真正聯繫和互動，分享源代碼只是邁向透明的一步。

為促進公開對話，Human Connection 團隊舉行定期在線公開會議。我們在這裏回答問題，鼓勵建議並對潛在的問題作出回應。我們的 Meet The Team 活動也會記錄下來，並在事後向公眾開放。通過對我們的流程，源代碼和財務狀況完全透明，我們可以保護自己免受批評或其他潛在的不利影響。

對透明的承諾意味着，所有在 Human Connection 上公開分享的用户貢獻者將在 Creative Commons 許可下發布，最終作為數據包下載。通過讓大眾知識變得可用，特別是以一種分散的方式，我們創造了一個多元化社會的機會。

有一個問題指導我們所有的組織決策：“它是否服務於人民和更大的利益？”我們用聯合國憲章UN Charter和“世界人權宣言Universal Declaration of Human Rights”作為我們價值體系的基礎。隨着我們的規模越來越大，尤其是即將推出的公測版，我們必須對此任務負責。我甚至願意邀請 Chaos Computer Club （LCTT 譯註：這是歐洲最大的黑客聯盟）或其他黑客俱樂部通過隨機檢查我們的平台來驗證我們的代碼和行為的完整性。

一個合作的社會 ​

以一種以社區為中心的協作方法來編寫 Human Connection 平台是超越社交網絡實際應用理念的基礎。我們的團隊是通過找到問題的答案來驅動：“是什麼讓一個社交網絡真正地社會化？”

一個拋棄了以利潤為導向的算法、為最終用户而不是廣告商服務的網絡，只能通過轉向對等生產和協作的過程而繁榮起來。例如，像 Code Alliance 和 Code for America 這樣的組織已經證明了如何在一個開源環境中創造技術，造福人類並變革現狀。社區驅動的項目，如基於地圖的報告平台 FixMyStreet，或者為 Humanitarian OpenStreetMap 而建立的 Tasking Manager，已經將眾包作為推動其使用的一種方式。

我們建立 Human Connection 的方法從一開始就是合作。為了收集關於必要功能和真正社交網絡的目的的初步數據，我們與巴黎索邦大學University Sorbonne的國家東方語言與文明研究所National Institute for Oriental Languages and Civilizations（INALCO）和德國斯圖加特媒體大學Stuttgart Media University合作。這兩個項目的研究結果都被納入了 Human Connection 的早期開發。多虧了這項研究，用户將擁有一套全新的功能，讓他們可以控制自己看到的內容以及他們如何與他人的互動。由於早期的支持者被邀請到網絡的 alpha 版本，他們可以體驗到第一個可用的值得注意的功能。這裏有一些：

  • 將信息與行動聯繫起來是我們研究會議的一個重要主題。當前的社交網絡讓用户處於信息階段。這兩所大學的學生團體都認為，需要一個以行動為導向的組件，以滿足人類共同解決問題的本能。所以我們在平台上構建了一個“Can Do”功能。這是一個人在閲讀了某個話題後可以採取行動的一種方式。“Can Do” 是用户建議的活動，在“採取行動Take Action”領域，每個人都可以實現。
  • “Versus” 功能是另一個成果。在傳統社交網絡僅限於評論功能的地方，我們的學生團體認為需要採用更加結構化且有用的方式進行討論和爭論。“Versus” 是對公共帖子的反駁，它是單獨顯示的，並提供了一個機會來突出圍繞某個問題的不同意見。
  • 今天的社交網絡並沒有提供很多過濾內容的選項。研究表明，情緒過濾選項可以幫助我們根據日常情緒駕馭社交空間，並可能通過在我們希望僅看到令人振奮的內容的那一天時，不顯示悲傷或難過的帖子來潛在地保護我們的情緒健康。

Human Connection 邀請改革者合作開發一個網絡，有可能動員世界各地的個人和團體將負面新聞變成 “Can Do”，並與慈善機構和非營利組織一起參與社會創新項目。

訂閲我們的每週時事通訊以瞭解有關開放組織的更多信息。
