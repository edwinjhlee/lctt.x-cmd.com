15 個適用於 MacOS 的開源應用程序 ​

鍾愛開源的用户不會覺得在非 Linux 操作系統上使用他們喜愛的應用有多難。

只要有可能的情況下，我都會去選擇使用開源工具。不久之前，我回到大學去攻讀教育領導學碩士學位。即便是我將喜歡的 Linux 筆記本電腦換成了一台 MacBook Pro（因為我不能確定校園裏能夠接受 Linux），我還是決定繼續使用我喜歡的工具，哪怕是在 MacOS 上也是如此。

幸運的是，它很容易，並且沒有哪個教授質疑過我用的是什麼軟件。即然如此，我就不能秘而不宣。

我知道，我的一些同學最終會在學區擔任領導職務，因此，我與我的那些使用 MacOS 或 Windows 的同學分享了關於下面描述的這些開源軟件。畢竟，開源軟件是真正地自由和友好的。我也希望他們去了解它，並且願意以很少的一些成本去提供給他們的學生去使用這些世界級的應用程序。他們中的大多數人都感到很驚訝，因為，眾所周知，開源軟件除了有像你和我這樣的用户之外，壓根就沒有銷售團隊。

我的 MacOS 學習曲線 ​

雖然大多數的開源工具都能像以前我在 Linux 上使用的那樣工作，只是需要不同的安裝方法。但是，經過這個過程，我學習了這些工具在 MacOS 上的一些細微差別。像 yum、DNF、和 APT 在 MacOS 的世界中壓根不存在 —— 我真的很懷念它們。

一些 MacOS 應用程序要求依賴項，並且安裝它們要比我在 Linux 上習慣的方法困難很多。儘管如此，我仍然沒有放棄。在這個過程中，我學會了如何在我的新平台上保留最好的軟件。即便是 MacOS 大部分的核心也是 開源的。

此外，我的 Linux 的知識背景讓我使用 MacOS 的命令列很輕鬆很舒適。我仍然使用命令列去創建和拷貝文件、添加用户、以及使用其它的像 cat、tac、more、less 和 tail 這樣的 實用工具。

15 個適用於 MacOS 的非常好的開源應用程序 ​

  • 在大學裏，要求我使用 DOCX 的電子版格式來提交我的工作，而這其實很容易，最初我使用的是 OpenOffice，而後來我使用的是 LibreOffice 去完成我的論文。
  • 當我因為演示需要去做一些圖像時，我使用的是我最喜歡的圖像應用程序 GIMP 和 Inkscape。
  • 我喜歡的播客創建工具是 Audacity。它比起 Mac 上搭載的專有應用程序更加簡單。我使用它去錄製訪談和為視頻演示創建配樂。
  • 在 MacOS 上我最早發現的多媒體播放器是 VideoLan (VLC)。
  • MacOS 內置的專有視頻創建工具是一個非常好的產品，但是你也可以很輕鬆地去安裝和使用 OpenShot，它是一個非常好的內容創建工具。
  • 當我需要在我的客户端上分析網絡時，我在我的 Mac 上使用了易於安裝的 Nmap (Network Mapper) 和 Wireshark 工具。
  • 當我為圖書管理員和其它教育工作者提供培訓時，我在 MacOS 上使用 VirtualBox 去做 Raspbian、Fedora、Ubuntu 和其它 Linux 發行版的示範操作。
  • 我使用 Etcher.io 在我的 MacBook 上製作了一個引導盤，下載 ISO 文件，將它刻錄到一個 U 盤上。
  • 我認為 Firefox 比起 MacBook Pro 自帶的專有瀏覽器更易用更安全，並且它允許我跨操作系統去同步我的書籤。
  • 當我使用電子書閲讀器時，Calibre 是當之無愧的選擇。它很容易去下載和安裝，你甚至只需要幾次點擊就能將它配置為一台 教室中使用的電子書服務器。
  • 最近我給中學的學生教 Python 課程，我發現它可以很容易地從 Python.org 上下載和安裝 Python 3 及 IDLE3 編輯器。我也喜歡學習數據科學，並與學生分享。不論你是對 Python 還是 R 感興趣，我都建議你下載和 安裝 Anaconda 發行版。它包含了非常好的 iPython 編輯器、RStudio、Jupyter Notebooks、和 JupyterLab，以及其它一些應用程序。
  • HandBrake 是一個將你家裏的舊的視頻 DVD 轉成 MP4 的工具，這樣你就可以將它們共享到 YouTube、Vimeo、或者你的 MacOS 上的 Kodi 服務器上。

現在輪到你了：你在 MacOS（或 Windows）上都使用什麼樣的開源軟件？在下面的評論區共享出來吧。
