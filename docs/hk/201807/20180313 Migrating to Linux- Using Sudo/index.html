遷移到 Linux：使用 sudo ​

sudo 機制可以讓你輕鬆以普通用户偶爾執行管理任務。讓我們來學習一下。

本文是我們關於遷移到 Linux 的系列文章的第五篇。如果你錯過了之前的那些，你可以在這裏趕上：

第1部分 - 入門介紹第2部分 - 磁盤、文件和文件系統第3部分 - 圖形操作環境第4部分 - 命令列

你可能一直想了解 Linux。也許它在你的工作場所使用，如果你每天使用它，你的工作效率會更高。或者，也許你想在家裏的某些計算機上安裝 Linux。無論是什麼原因，這一系列文章都是為了讓過渡更容易。

與許多其他操作系統一樣，Linux 支持多用户。它甚至支持多個用户同時登錄。

用户帳户通常會被分配一個可以存儲文件的家目錄。通常這個家目​​錄位於：

/home/<login name>

這樣，每個用户都有存儲自己的文檔和其他文件的獨立位置。

管理任務 ​

在傳統的 Linux 安裝中，常規用户帳户無權在系統上執行管理任務。典型的安裝 Linux 的系統會要求用户以管理員身份登錄以執行某些任務，而不是為每個用户分配權限以執行各種任務。

Linux 上的管理員帳户稱為 root。

Sudo 解釋 ​

從歷史上看，要執行管理任務，必須以 root 身份登錄，執行任務，然後登出。這個過程有點乏味，所以很多人以 root 登錄並且整天都以管理員身份工作。這種做法可能會導致災難性的後果，例如，意外刪除系統中的所有文件。當然，root 用户可以做任何事情，因此沒有任何保護措施可以防止有人意外地執行影響很大的操作。

創建 sudo 工具是為了使你更容易以常規用户帳户登錄，偶爾以 root 身份執行管理任務，而無需登錄、執行任務然後登出。具體來説，sudo 允許你以不同的用户身份運行命令。如果你未指定特定用户，則假定你指的是 root 用户。

sudo 可以有複雜的設置，允許用户有權限使用 sudo 運行某些命令，而其他的不行。通常，安裝的桌面系統會使創建的第一個帳户在 sudo 中有完全的權限，因此你作為主要用户可以完全管理 Linux 安裝。

使用 Sudo ​

某些安裝 Linux 的系統設置了 sudo，因此你仍需要知道 root 帳户的密碼才能執行管理任務。其他人，設置 sudo 輸入自己的密碼。這裏有不同的哲學。

當你嘗試在圖形環境中執行管理任務時，通常會打開一個要求輸入密碼的對話框。輸入你自己的密碼（例如，在 Ubuntu 上）或 root 帳户的密碼（例如，Red Hat）。

當你嘗試在命令列中執行管理任務時，它通常只會給你一個 “permission denied” 錯誤。然後你在前面用 sudo 重新運行命令。例如：

systemctl start vsftpd
Failed to start vsftpd.service: Access denied

sudo systemctl start vsftpd
[sudo] password for user1:

何時使用 Sudo ​

以 root 身份運行命令（在 sudo 或其他情況下）並不總是解決權限錯誤的最佳解決方案。雖然將以 root 身份運行會消除 “permission denied” 錯誤，但有時最好尋找根本原因而不是僅僅解決症狀。有時文件擁有錯誤的所有者和權限。

當你在嘗試一個需要 root 權限來執行操作的任務或者程序時使用 sudo。如果文件恰好由另一個用户（包括 root 用户）擁有，請不要使用 sudo。在第二種情況下，最好正確設置文件的權限。

通過 Linux 基金會和 edX 的免費“Linux 介紹”課程瞭解有關 Linux 的更多信息。
