LCTT - Linux 中国 (linux.cn) 镜像站点正式上线，汇聚高质量翻译文章

LCTT 介绍 ​

LCTT 是 "Linux 中国翻译组"Linux.cn Translation Team 的简称，负责从国外优秀媒体翻译 Linux 相关的技术、资讯、杂文等内容。

从 2012 年开始，LCTT 开始 https://linux.cn 上发布翻译的文章。随着时间的推移，LCTT 的翻译工作逐渐发展壮大，成为了一个活跃的开源社区。

遗憾的是，LCTT 已经于 2024 年伴随 Linux 中国开源社区停止运营而停止运作。关于停运方面的信息，请查看 Linux 中国的公告。

在此，向所有参与 LCTT 的志愿者们致以诚挚的感谢，感谢你们为开源社区做出的贡献。希望大家在未来的日子里继续支持开源事业，传播自由软件的理念。

LCTT 托管 ​

LCTT 的文章质量很高，虽已历经数年，但仍有很多文章值得阅读和学习。然而，Linux.cn 的停运 ( 后面转向至镜像站 linux.net.cn )，使我们面临错失这一批优秀文章的威胁。在参阅「尾声：Linux 中国开源文章数据集」后，我们决定基于 LCTT 托管在 GitHub 上的开源文章库，采用 x-cmd 网站组织方式进行整理和托管，共计 7969 篇文章。

在这个过程中，我们也咨询了 Linux 中国创始人的意见，非常感谢老王的支持和鼓励！

其它 LCTT 的镜像 ​

  • Linux.cn 的官方镜像: https://linux.net.cn
  • Linux Joy: https://linuxjoy.com/

如果还有其它的镜像，欢迎在该贴子的评论告知。如果想获取更多建议或者交流，请通过 x-cmd 交流群或者社区 联系我们。

使用本网站的快捷搜索过滤列表以及搜索引擎 ​

我们提供了一个快速过滤交互列表，用户可以通过标题关键字快速过滤出感兴趣的文章。

  1. 用户可以通过点击输入框或者使用快捷键 > 进行搜索关键字过滤感兴趣的文章进行阅读
  2. 接着可以通过 键盘上下键↑↓ 和回车键↵ 进行文章浏览。

如果关键词没有在标题命中，可以点击旁边的搜索引擎图标，直接打开搜索引擎中搜索在 lctt.x-cmd.com 中的相关内容。截至 2025年4月25日，bing、google、duckduckgo 等搜索引擎已开始了对 lctt.x-cmd.com 的索引收录。
